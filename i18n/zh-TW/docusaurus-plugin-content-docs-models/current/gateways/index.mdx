# Gateway Provider

Gateway Provider 整合多個模型 Provider，提供快取、速率限制、分析及自動容錯移轉等功能。如果你需要可觀測性、成本管理，或想簡化多個 Provider 的存取方式，可以使用閘道。

## 自訂閘道 {/* #custom-gateways */}

如要連接私有 LLM 部署或整合特定 Provider，可以建立自訂閘道。實作細節請參閱[自訂閘道](/models/gateways/custom-gateways)。

## 需要手動註冊的閘道 {/* #gateways-you-register-yourself */}

這些閘道預設不會註冊。請將它們傳入 `new Mastra({ gateways })`。只有註冊在該 Mastra 執行個體上的 Agent 才能解析這些閘道的模型 ID。

* [Azure OpenAI](/models/gateways/azure-openai)：透過 `AzureOpenAIGateway` 註冊私有 Azure OpenAI 部署
