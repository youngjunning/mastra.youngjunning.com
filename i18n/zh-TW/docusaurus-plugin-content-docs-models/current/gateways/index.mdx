# 網關Provider

網關Provider聚合了多個模型Provider，並新增了快取、速率限制、分析和自動故障轉移等功能。當您需要可觀察性、成本管理或簡化的多Provider存取權時，請使用網關。

## 自訂網關 {/* #custom-gateways */}

為私人 LLM 部署或專業Provider整合建立自訂網關。看[Custom Gateways](/models/gateways/custom-gateways) for implementation details.

## 您自己註冊的網關 {/* #gateways-you-register-yourself */}

預設情況下，這些網關未註冊。將它們傳遞給`new Mastra({ gateways })`. Their model IDs only resolve for agents registered on that instance.
