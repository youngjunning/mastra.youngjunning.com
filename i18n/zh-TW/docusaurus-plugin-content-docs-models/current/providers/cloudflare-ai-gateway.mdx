Cloudflare AI Gateway 可透過 AI SDK 使用。安裝對應的 Provider 套件後，即可在 Mastra 中使用其模型。

如需此 Provider 的詳細說明，請參閱 [AI SDK Cloudflare AI Gateway Provider 文件](https://ai-sdk.dev/providers/community-providers/cloudflare-ai-gateway)。

Cloudflare AI Gateway 並未接入模型路由器，因此無法解析 `cloudflare-ai-gateway/<model>` 這類模型字串。請將 `ai-gateway-provider` 提供的模型執行個體傳入 Agent 的 `model` 選項。

如需在 Mastra Agent 中使用此 Provider，請參閱 [Agent 概覽文件](/docs/agents/overview)。

npm install ai-gateway-provider
