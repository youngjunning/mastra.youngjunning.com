QVAC 可透過 AI SDK 使用。安裝對應的 Provider 套件後，即可在 Mastra 中使用其模型。

如需此 Provider 的詳細說明，請參閱 [AI SDK QVAC Provider 文件](https://ai-sdk.dev/providers/community-providers/qvac)。

QVAC isn't a model router provider, so model strings like `qvac/<model>` don't resolve. Pass a model instance from `@qvac/ai-sdk-provider` to the agent's `model` option instead.

如需在 Mastra Agent 中使用此 Provider，請參閱 [Agent 概覽文件](/docs/agents/overview)。
