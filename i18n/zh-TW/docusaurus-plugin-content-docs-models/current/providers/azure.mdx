# <img src="https://models.dev/logos/azure.svg" alt="Azure 標誌" className="inline w-8 h-8 mr-2 align-middle dark:invert dark:brightness-0 dark:contrast-200" />Azure

Azure 可透過 AI SDK 使用。安裝對應的 Provider 套件後，即可在 Mastra 中使用其模型。

如需此 Provider 的詳細說明，請參閱 [AI SDK Azure Provider 文件](https://ai-sdk.dev/providers/ai-sdk-providers/azure)。

Azure 並未接入模型路由器，因此無法解析 `azure/<model>` 這類模型字串。請將 `@ai-sdk/azure` 提供的模型執行個體傳入 Agent 的 `model` 選項。

部分已接入路由器的 Provider 提供在 Azure 上託管的模型，例如 [LLM Gateway](/models/providers/llmgateway-providers) 的 `llmgateway-providers/azure/gpt-5.4`、[Eden AI](/models/providers/edenai) 的 `edenai/azure/gpt-4.1-nano`。請使用 Provider 列出的完整 ID。省略前綴後，剩下的 `azure/...` 將無法解析。若要透過模型路由器存取自己的 Azure OpenAI 部署，請註冊 [Azure OpenAI Gateway](/models/gateways/azure-openai)。

如需在 Mastra Agent 中使用此 Provider，請參閱 [Agent 概覽文件](/docs/agents/overview)。
