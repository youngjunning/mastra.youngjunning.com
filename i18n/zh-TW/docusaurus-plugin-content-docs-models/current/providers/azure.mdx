# <img src="https://models.dev/logos/azure.svg" alt="Azure 標誌" className="inline w-8 h-8 mr-2 align-middle dark:invert dark:brightness-0 dark:contrast-200" />Azure

Azure 可透過 AI SDK 使用。安裝對應的 Provider 套件後，即可在 Mastra 中使用其模型。

如需此 Provider 的詳細說明，請參閱 [AI SDK Azure Provider 文件](https://ai-sdk.dev/providers/ai-sdk-providers/azure)。

Azure isn't a model router provider, so model strings like `azure/<model>` don't resolve. Pass a model instance from `@ai-sdk/azure` to the agent's `model` option instead.

Some router providers serve Azure-hosted models, for example `llmgateway-providers/azure/gpt-5.4` from [LLM Gateway](/models/providers/llmgateway-providers) and `edenai/azure/gpt-4.1-nano` from [Eden AI](/models/providers/edenai). Use the full ID the provider lists, including its prefix. Dropping the prefix leaves an `azure/...` ID that doesn't resolve. To use your own Azure OpenAI deployments through the model router, register the [Azure OpenAI gateway](/models/gateways/azure-openai).

如需在 Mastra Agent 中使用此 Provider，請參閱 [Agent 概覽文件](/docs/agents/overview)。
