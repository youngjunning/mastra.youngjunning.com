# 部署者

Deployer 透過打包程式碼和管理環境檔案來處理獨立 Mastra 應用程式的部署，同時透過 Hono 框架為應用程式提供服務。具體實作必須為特定的部署目標定義部署方法。

## 使用範例 {/* #usage-example */}

如果您想建立自訂部署程序，您可以擴充抽象`Deployer` class and implement the `deploy`方法與您的特定部署邏輯。這是一個例子：

```typescript
import { Deployer } from '@mastra/deployer'

class CustomDeployer extends Deployer {
  constructor() {
    super({ name: 'custom-deployer' })
  }

  async deploy(outputDirectory: string): Promise<void> {
    // Prepare the output directory
    await this.prepare(outputDirectory)

    // Bundle the application
    await this._bundle('server.ts', 'mastra.ts', {
      projectRoot: process.cwd(),
      outputDirectory,
    })

    // Custom deployment logic
  }
}
```

## 核心理念 {/* #core-concepts */}

### 部署生命週期 {/* #deployment-lifecycle */}

Deployer 抽象類別實作了結構化的部署生命週期：

1. **初始化**：部署器使用名稱進行初始化，並建立一個 Deps 實例用於依賴管理。
2. **環境設定**： 這`getEnvFiles` method identifies the environment files (`.env`, `.env.local`, `.env.production`) to be used during deployment.
3. **準備**： 這`prepare` method (inherited from Bundler) cleans the output directory and creates necessary subdirectories.
4. **捆綁**： 這`_bundle` method (inherited from Bundler) packages the application code and its dependencies.
5. **部署**：摘要`deploy` method is implemented by subclasses to handle the actual deployment process.

### 環境檔案管理 {/* #environment-file-management */}

Deployer 類別包括透過以下方式對環境文件管理的內建支持`getEnvFiles` method. This method:

* 依預先定義的順序尋找環境文件，優先順序從最低到最高：`.env`, `.env.local`, `.env.production`
* 按該順序傳回存在的每個文件，因此後面的文件中的值會覆蓋前面的文件
* 如果未找到環境文件，則傳回空數組

```typescript oxfmt:false
getEnvFiles(): Promise<string[]> {
  const possibleFiles = ['.env', '.env.local', '.env.production'];
  const fileService = new FileService();

  return Promise.resolve(fileService.getExistingFiles(possibleFiles));
}
```

### 捆綁與部署關係 {/* #bundling-and-deployment-relationship */}

Deployer 類別擴展了 Bundler 類，在捆綁和部署之間建立了明確的關係：

1. **捆綁作為先決條件**：捆綁是部署的先決步驟，其中應用程式程式碼被打包成可部署的格式。
2. **共享基礎設施**：捆綁和部署共享公共基礎設施，例如依賴管理和檔案系統操作。
3. **專門的部署邏輯**：雖然捆綁側重於程式碼打包，但部署添加了用於部署捆綁程式碼的特定環境的邏輯。
4. **可擴展性**：摘要`deploy` method allows for creating specialized deployers for different target environments.
