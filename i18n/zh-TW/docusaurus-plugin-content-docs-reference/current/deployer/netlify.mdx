# Netlify部署器

這`NetlifyDeployer`這類透過調整 Mastra 的輸出來處理打包、配置和部署，以建立伺服器的最佳化版本。它擴展了基礎[`Deployer`](/reference/deployer/)具有 Netlify 特定功能的類別。它使您能夠在 Netlify 無伺服器功能或邊緣功能中執行 Mastra。

## 安裝 {/* #installation */}

使用`NetlifyDeployer`, you need to install the `@mastra/deployer-netlify` package:

```bash npm2yarn
npm install @mastra/deployer-netlify@latest
```

## 使用範例 {/* #usage-example */}

進口`NetlifyDeployer` and set it as the deployer in your Mastra configuration:

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
// highlight-next-line
import { NetlifyDeployer } from '@mastra/deployer-netlify'

export const mastra = new Mastra({
  // highlight-next-line
  deployer: new NetlifyDeployer(),
})
```

## 建構函數選項 {/* #constructor-options */}

* `target?: 'serverless' | 'edge'`：為 Netlify 部署目標。預設為`'serverless'`.
  * `'serverless'`： 標準[Netlify Functions](https://docs.netlify.com/functions/overview/) (Node.js runtime, 60s default timeout).
  * `'edge'`: [Netlify Edge Functions](https://docs.netlify.com/build/edge-functions/overview/) (Deno-based runtime that runs at the edge closest to users without a fixed timeout).

### 邊函數範例 {/* #edge-functions-example */}

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { NetlifyDeployer } from '@mastra/deployer-netlify'

export const mastra = new Mastra({
  deployer: new NetlifyDeployer({
    target: 'edge',
  }),
})
```

## 輸出 {/* #output */}

運行後`mastra build`, the deployer generates a `.netlify` folder. The build output includes all agents, tools, and workflows of your project, alongside a `config.json` file that configures the [Netlify Frameworks API](https://docs.netlify.com/build/frameworks/frameworks-api/).

### 無伺服器輸出（預設） {/* #serverless-output-default */}

```bash
your-project/
└── .netlify/
    └── v1/
        ├── config.json
        └── functions/
            └── api/
                ├── index.mjs
                ├── package.json
                └── node_modules/
```

這`config.json` file contains:

```json
{
  "functions": {
    "directory": ".netlify/v1/functions",
    "node_bundler": "none",
    "included_files": [".netlify/v1/functions/**"]
  },
  "redirects": [
    {
      "force": true,
      "from": "/*",
      "to": "/.netlify/functions/api/:splat",
      "status": 200
    }
  ]
}
```

### 邊緣輸出 {/* #edge-output */}

```bash
your-project/
└── .netlify/
    └── v1/
        ├── config.json
        └── edge-functions/
            ├── index.mjs
            ├── package.json
            └── node_modules/
```

這`config.json` file contains:

```json
{
  "edge_functions": [
    {
      "function": "index",
      "path": "/*"
    }
  ]
}
```
