# 文字轉語音 (TTS)

Mastra 的文字轉語音 (TTS) 功能提供統一 API，可透過不同 Provider 將文字合成語音。
在應用程式中整合 TTS，可透過自然的語音互動提升使用者體驗、改善視障使用者的無障礙體驗，並建立更具吸引力的多模態介面。

TTS 是語音應用程式的核心元件，與 STT（語音轉文字）共同構成語音互動系統的基礎。較新的模型支援 STS（[語音轉語音](./speech-to-speech)），可用於即時互動，但成本較高。

## 設定 {/* #configuration */}

要在 Mastra 中使用 TTS，初始化語音 Provider 時須提供 `speechModel`，其中可包含以下參數：

- **`name`**: 要使用的 TTS 模型。
- **`apiKey`**: 用於驗證身分的 API 金鑰。
- **Provider 專屬選項**: 特定語音 Provider 可能要求或支援的其他選項。

**`speaker`** 選項可選擇語音合成所用的聲音。各 Provider 提供的聲音在**音色多樣性**、**品質**、**聲音風格**及**多語言支援**方面各有特色。

**行為**：上述參數皆為選填。可以使用語音 Provider 的預設設定，實際預設值取決於所用的 Provider。

```typescript
const voice = new OpenAIVoice({
  speechModel: {
    name: 'tts-1-hd',
    apiKey: process.env.OPENAI_API_KEY,
  },
  speaker: 'alloy',
})

// If using default settings the configuration can be simplified to:
const voice = new OpenAIVoice()
```

## 可用的 Provider {/* #available-providers */}

Mastra 支援多種文字轉語音 Provider，各自具備不同功能及聲音選項。可依應用程式需求選擇：

- [**OpenAI**](/integrations/voice/openai#voice): 提供語調與表現自然的高品質語音
- [**Azure**](/integrations/voice/azure): Microsoft 的語音服務，提供多種聲音與語言
- [**ElevenLabs**](/integrations/voice/elevenlabs): 提供富有情感、可細緻控制的逼真語音
- [**Google**](/integrations/voice/google#speech): Google 的語音合成服務，支援多種語言
- [**Cloudflare**](/integrations/voice/cloudflare): 針對低延遲應用程式最佳化的邊緣語音合成服務
- [**Deepgram**](/integrations/voice/deepgram): 準確度高的 AI 語音技術
- [**Speechify**](/integrations/voice/speechify): 著重易讀性與無障礙體驗的文字轉語音服務
- [**Sarvam**](/integrations/voice/sarvam): 專注印度語系語言與口音
- [**Murf**](/integrations/voice/murf): 提供可自訂參數的錄音室等級配音

每個 Provider 都有獨立套件，可依需求安裝：

```bash
pnpm add @mastra/voice-openai@latest  # Example for OpenAI
```

## 使用 speak 方法 {/* #using-the-speak-method */}

TTS 主要透過 `speak()` 方法將文字轉換為語音。呼叫時可傳入選項，指定聲音及其他 Provider 專屬設定：

```typescript
import { Agent } from '@mastra/core/agent'
import { OpenAIVoice } from '@mastra/voice-openai'

const voice = new OpenAIVoice()

const agent = new Agent({
  id: 'voice-agent',
  name: 'Voice Agent',
  instructions: 'You are a voice assistant that can help users with their tasks.',
  model: '__GATEWAY_OPENAI_MODEL__',
  voice,
})

const { text } = await agent.generate('What color is the sky?')

// Convert text to speech to an Audio Stream
const readableStream = await voice.speak(text, {
  speaker: 'default', // Optional: specify a speaker
  properties: {
    speed: 1.0, // Optional: adjust speech speed
    pitch: 'default', // Optional: specify pitch if supported
  },
})
```

## 儲存語音輸出 {/* #save-speech-output */}

`speak()` 方法會傳回音訊串流。如需儲存產生的語音供日後播放或處理，可將串流以管線方式寫入檔案：

```typescript
import { createWriteStream } from 'fs'
import path from 'path'

const audio = await agent.voice.speak('Hello, world!')
const filePath = path.join(process.cwd(), 'agent.mp3')
const writer = createWriteStream(filePath)

audio.pipe(writer)

await new Promise<void>((resolve, reject) => {
  writer.on('finish', () => resolve())
  writer.on('error', reject)
})
```

如需進一步瞭解 Agent 使用的語音 Provider，請參閱 [Mastra 語音概覽](/reference/voice/overview)。
