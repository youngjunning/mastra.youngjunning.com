# MastraVoice

MastraVoice 是定義 Mastra 語音服務核心介面的抽象基底類別。OpenAI、Deepgram、PlayAI、Speechify 等語音提供者都會擴充此類別，以實作各自的功能。此類別也支援透過 WebSocket 連線進行即時語音互動。

```typescript
      speaker: config.speaker,
      realtimeConfig: config.realtimeConfig,

  // Implement required abstract methods
  async speak(
    input: string | NodeJS.ReadableStream,
    options?: { speaker?: string },
  ): Promise<NodeJS.ReadableStream | void> {
    // Implement text-to-speech conversion
  }

  async listen(
    audioStream: NodeJS.ReadableStream,
    options?: unknown,
  ): Promise<string | NodeJS.ReadableStream | void> {
    // Implement speech-to-text conversion
  }

  async getSpeakers(): Promise<Array<{ voiceId: string; [key: string]: unknown }>> {
    // Return list of available voices
  }

  // Optional speech-to-speech methods
  async connect(): Promise<void> {
    // Establish WebSocket connection for speech-to-speech communication
  }

  async send(audioData: NodeJS.ReadableStream | Int16Array): Promise<void> {
    // Stream audio data in speech-to-speech
  }

  async answer(): Promise<void> {
    // Trigger voice provider to respond
  }

  addTools(tools: Array<unknown>): void {
    // Add tools for the voice provider to use
  }

  close(): void {
    // Close WebSocket connection
  }

  on(event: string, callback: (data: unknown) => void): void {
    // Register event listener
  }

  off(event: string, callback: (data: unknown) => void): void {
    // Remove event listener
  }
}
```

## 抽象方法 {/* #abstract-methods */}

這些方法必須由擴充 MastraVoice 的類別實作。

### `speak()` {/* #speak */}

使用設定的語音合成模型將文字轉換為語音。

```typescript oxfmt:false
abstract speak(
  input: string | NodeJS.ReadableStream,
  options?: {
    speaker?: string;
    [key: string]: unknown;
  }
): Promise<NodeJS.ReadableStream | void>
```

目的：

* 接收文字輸入，並透過提供者的文字轉語音服務轉換為語音
* 同時支援字串與串流輸入
* 可透過選項覆寫預設說話者／語音
* 傳回可播放或儲存的音訊資料串流
* 若透過觸發 'speaking' 事件處理音訊，則可能傳回 void

### `listen()` {/* #listen */}

使用設定的語音辨識模型將語音轉換為文字。

```typescript oxfmt:false
abstract listen(
  audioStream: NodeJS.ReadableStream | unknown,
  options?: {
    [key: string]: unknown;
  }
): Promise<string | NodeJS.ReadableStream | void>
```

目的：

* 接收音訊串流（或提供者專屬的其他音訊輸入），並透過提供者的語音轉文字服務轉換為文字
* 支援提供者專屬的轉錄設定選項
* 可傳回完整的轉錄文字或轉錄文字串流
* 並非所有提供者都支援此功能，例如 PlayAI 與 Speechify
* 若透過觸發 'writing' 事件處理轉錄結果，則可能傳回 void

## 可選方法 {/* #optional-methods */}

這些方法提供預設實作；支援即時語音互動的提供者可以覆寫它們。

### `getSpeakers()` {/* #getspeakers */}

傳回提供者支援的可用語音清單。

```typescript oxfmt:false
getSpeakers(): Promise<Array<{ voiceId: string; [key: string]: unknown }>>
```

目的：

* 從提供者取得可用語音／說話者清單
* 預設實作傳回空陣列；提供者可覆寫此方法，列出自己的語音
* 每個語音至少必須具有 voiceId 屬性
* 提供者可為每個語音加入其他中繼資料
用於尋找可供文字轉語音使用的語音

### `connect()` {/* #connect */}



```typescript oxfmt:false
connect(config?: unknown): Promise<void>
```

目的：

* 初始化與語音服務的通訊連線
* 使用 send() 或 answer() 等功能前必須呼叫
* 傳回在連線建立後履行的 Promise
* 設定視提供者而定

### `send()` {/* #send */}

將音訊資料即時串流傳送給語音提供者。

```typescript oxfmt:false
send(audioData: NodeJS.ReadableStream | Int16Array): Promise<void>
```

目的：

* 將音訊資料傳送給語音提供者即時處理
* 適用於麥克風持續輸入等連續音訊串流情境
* 支援 ReadableStream 與 Int16Array 音訊格式
* 呼叫此方法前必須先建立連線

### `answer()` {/* #answer */}

觸發語音提供者產生回應。

```typescript oxfmt:false
answer(options?: Record<string, unknown>): Promise<void>
```

目的：

* 通知語音提供者產生回應
* 接受選用的提供者專屬選項
* 用於即時對話中提示 AI 產生回應
* 回應會透過事件系統發出，例如 'speaking' 事件

### `addTools()` {/* #addtools */}

為語音提供者加入對話時可用的 Tool。

```typescript oxfmt:false
addTools(tools: Array<Tool>): void
```

目的：

* 加入語音提供者在對話期間可用的 Tool
* Tool 可擴充語音提供者的功能
* 具體實作視提供者而定

### `close()` {/* #close */}

中斷 WebSocket 或 WebRTC 連線。

```typescript oxfmt:false
close(): void
```

目的：

* 關閉與語音服務的連線
* 清理資源並停止進行中的即時處理
* 不再使用語音執行個體時應呼叫此方法

### `on()` {/* #on */}

註冊語音事件監聽器。

```typescript oxfmt:false
on<E extends VoiceEventType>(
  event: E,
  callback: (data: E extends keyof VoiceEventMap ? VoiceEventMap[E] : unknown) => void,
): void
```

目的：

* 註冊在指定事件發生時呼叫的回呼函式
* 標準事件包括 'speaking'、'writing' 與 'error'
* 提供者也可以觸發自訂事件
事件資料結構取決於事件類型

### `off()` {/* #off */}

移除事件監聽器。

```typescript oxfmt:false
off<E extends VoiceEventType>(
  event: E,
  callback: (data: E extends keyof VoiceEventMap ? VoiceEventMap[E] : unknown) => void,
): void
```

目的：

* 移除先前註冊的事件監聽器
* 不再需要事件處理函式時，用於清理它們

## 遙測支援 {/* #telemetry-support */}

MastraVoice 透過 `traced` 方法提供內建遙測支援，此方法會在呼叫其他方法時追蹤效能並監控錯誤。

## 注意事項 {/* #notes */}

* MastraVoice 是抽象類別，無法直接建立執行個體
* 實作類別必須具體實作抽象方法 `speak()` 與 `listen()`
* 此類別為不同語音服務提供者提供一致的介面
* 語音互動功能為選用，具體取決於提供者
* 事件系統支援即時互動中的非同步通訊
* 所有方法呼叫的遙測資料都會自動處理
