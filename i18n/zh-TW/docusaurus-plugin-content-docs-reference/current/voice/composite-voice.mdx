# 複合語音

CompositeVoice 類別可讓您組合不同的語音Provider以進行文字轉語音和語音轉文字操作。當您想要為每個操作使用最佳的Provider時，這特別有用 - 例如，使用 OpenAI 進行語音轉文本，使用 PlayAI 進行文本轉語音。

CompositeVoice 支援 Mastra 語音Provider和 AI SDK 模型Provider

## 方法 {/* #methods */}

### `speak()` {/* #speak */}

使用配置的語音Provider將文字轉換為語音。

<PropertiesTable
  content={[
{

  type: 'string | NodeJS.ReadableStream',
  description: 'Text to convert to speech',
  isOptional: false,
},
{
  name: 'options',
  type: 'object',
  description: 'Provider-specific options passed to the speaking provider',
  isOptional: true,
},
]}
/>

筆記：

* 如果配置了即時提供程序，它將處理呼叫；否則使用說話的Provider
* 拋出一個`MastraError` only when neither a realtime nor a speaking provider is configured
* 選項被傳遞給處理呼叫的Provider
* 返回音訊資料流，或者`void` when a realtime provider handles the call

### `listen()` {/* #listen */}

* 拋出一個`MastraError` only when neither a realtime nor a listening provider is configured
* 選項被傳遞給處理呼叫的Provider
* 傳回一個字串或轉錄文字流，取決於Provider，或者`void` when a realtime provider emits results through events

### `getSpeakers()` {/* #getspeakers */}

傳回來自即時Provider的可用語音列表，或在未配置即時Provider時傳回來自講話Provider的可用語音列表，其中每個節點包含：

<PropertiesTable
  content={[
{
  name: 'voiceId',
  type: 'string',
  description: 'Unique identifier for the voice',
  isOptional: false,
},
{
  name: 'key',
  type: 'value',
  description: 'Additional voice properties that vary by provider (e.g., name, language)',
  isOptional: true,
},
]}
/>

筆記：

* 如果已配置，則從即時Provider傳回語音，否則從語音Provider傳回語音
* 拋出一個`MastraError` when neither a realtime nor a speaking provider is configured
* 每個語音物件至少有一個 voiceId 屬性
* 其他語音屬性取決於Provider

## 使用範例 {/* #usage-examples */}

### 使用 Mastra 語音Provider {/* #using-mastra-voice-providers */}

```typescript
import { CompositeVoice } from '@mastra/core/voice'
import { OpenAIVoice } from '@mastra/voice-openai'
import { PlayAIVoice } from '@mastra/voice-playai'

// Create voice providers
const openai = new OpenAIVoice()
const playai = new PlayAIVoice()

// Use OpenAI for listening (speech-to-text) and PlayAI for speaking (text-to-speech)
const voice = new CompositeVoice({
  input: openai,
  output: playai,
})

// Convert speech to text using OpenAI
const text = await voice.listen(audioStream)

// Convert text to speech using PlayAI
const audio = await voice.speak('Hello, world!')
```

### 使用AI SDK模型Provider {/* #using-ai-sdk-model-providers */}

您可以將 AI SDK 轉錄和語音模型直接傳遞給 CompositeVoice：

```typescript
import { CompositeVoice } from '@mastra/core/voice'
import { openai } from '@ai-sdk/openai'
import { elevenlabs } from '@ai-sdk/elevenlabs'

// Use AI SDK models directly - they will be auto-wrapped
const voice = new CompositeVoice({
  input: openai.transcription('whisper-1'), // AI SDK transcription
  output: elevenlabs.speech('eleven_turbo_v2'), // AI SDK speech
})

// Works the same way as with Mastra providers
const text = await voice.listen(audioStream)
const audio = await voice.speak('Hello from AI SDK!')
```

### 混搭 {/* #mix-and-match */}

您可以將 Mastra Provider與 AI SDK 模型結合：

```typescript
import { CompositeVoice } from '@mastra/core/voice'
import { PlayAIVoice } from '@mastra/voice-playai'
import { groq } from '@ai-sdk/groq'

const voice = new CompositeVoice({
  input: groq.transcription('whisper-large-v3'), // AI SDK for STT
  output: new PlayAIVoice(), // Mastra for TTS
})
```
