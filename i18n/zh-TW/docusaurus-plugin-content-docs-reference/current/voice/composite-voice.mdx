# CompositeVoice

CompositeVoice 類別可組合不同的語音 Provider，分別處理文字轉語音與語音轉文字。需要為兩項操作選用不同 Provider 時特別實用，例如以 OpenAI 將語音轉為文字，再以 PlayAI 將文字轉為語音。

CompositeVoice 同時支援 Mastra 語音 Provider 與 AI SDK 模型 Provider。

## 方法 {/* #methods */}

### `speak()` {/* #speak */}

使用已設定的語音輸出 Provider 將文字轉為語音。

  isOptional: true,

說明：

- 若已設定即時 Provider，便由它處理呼叫；否則使用語音輸出 Provider。
- 只有即時 Provider 與語音輸出 Provider 都未設定時，才會擲出 `MastraError`。
- 選項會原樣傳給實際處理呼叫的 Provider。
- 回傳音訊資料串流；由即時 Provider 處理時回傳 `void`。

### `getSpeakers()` {/* #getspeakers */}

回傳可用語音清單：已設定即時 Provider 時從它取得，否則從語音輸出 Provider 取得。清單中的每個物件都包含：

<PropertiesTable
  content={[
{
  name: 'voiceId',
  type: 'string',
  description: '語音的唯一識別碼',
  isOptional: false,
},
{
  name: 'key',
  type: 'value',
  description: '因 Provider 而異的其他語音屬性（例如名稱、語言）',
  isOptional: true,
},
]}
/>

說明：

- 已設定即時 Provider 時回傳它的語音，否則回傳語音輸出 Provider 的語音。
- 即時 Provider 與語音輸出 Provider 都未設定時，會擲出 `MastraError`。
- 每個語音物件至少具有 voiceId 屬性。
- 其他語音屬性取決於 Provider。

## 使用範例 {/* #usage-examples */}

### 使用 Mastra 語音 Provider {/* #using-mastra-voice-providers */}

```typescript
import { CompositeVoice } from '@mastra/core/voice'
import { OpenAIVoice } from '@mastra/voice-openai'
import { PlayAIVoice } from '@mastra/voice-playai'

// Create voice providers
const openai = new OpenAIVoice()
const playai = new PlayAIVoice()

// Use OpenAI for listening (speech-to-text) and PlayAI for speaking (text-to-speech)
const voice = new CompositeVoice({
  input: openai,
  output: playai,
})

// Convert speech to text using OpenAI
const text = await voice.listen(audioStream)

// Convert text to speech using PlayAI
const audio = await voice.speak('Hello, world!')
```

### 使用 AI SDK 模型 Provider {/* #using-ai-sdk-model-providers */}

可以直接將 AI SDK 轉錄模型與語音模型傳給 CompositeVoice：

```typescript
import { CompositeVoice } from '@mastra/core/voice'
import { openai } from '@ai-sdk/openai'
import { elevenlabs } from '@ai-sdk/elevenlabs'

// Use AI SDK models directly - they will be auto-wrapped
const voice = new CompositeVoice({
  input: openai.transcription('whisper-1'), // AI SDK transcription
  output: elevenlabs.speech('eleven_turbo_v2'), // AI SDK speech
})

// Works the same way as with Mastra providers
const text = await voice.listen(audioStream)
const audio = await voice.speak('Hello from AI SDK!')
```

### 混合使用 {/* #mix-and-match */}

可以搭配使用 Mastra Provider 與 AI SDK 模型：

```typescript
import { CompositeVoice } from '@mastra/core/voice'
import { PlayAIVoice } from '@mastra/voice-playai'
import { groq } from '@ai-sdk/groq'

const voice = new CompositeVoice({
  input: groq.transcription('whisper-large-v3'), // AI SDK for STT
  output: new PlayAIVoice(), // Mastra for TTS
})
```
