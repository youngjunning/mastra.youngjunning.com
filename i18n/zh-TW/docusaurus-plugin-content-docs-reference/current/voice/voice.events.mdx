# 語音事件

語音 Provider 會在即時語音互動期間發出事件。你可以使用 [voice.on()](./voice.on) 方法監聽這些事件；建立即時互動語音應用程式時，這些事件尤其重要。

## 注意事項 {/* #notes */}

* 並非每個語音 Provider 都支援所有事件
* 確切的 payload 結構可能因 Provider 而異
* 對於非即時 Provider，大多數事件不會發出
* 事件對於建立響應對話狀態的互動式 UI 非常有用
* 不再需要事件監聽器時，建議使用 [voice.off()](./voice.off) 方法將其移除
