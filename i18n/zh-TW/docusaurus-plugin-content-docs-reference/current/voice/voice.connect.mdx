# voice.connect()

`connect()` 方法建立 WebSocket 或 WebRTC 連線，以實現即時語音對話。使用 `send()` 或 `answer()` 等其他即時功能前，必須先呼叫此方法。

## 使用範例 {/* #usage-example */}

```typescript
import { OpenAIRealtimeVoice } from '@mastra/voice-openai-realtime'
import Speaker from '@mastra/node-speaker'

const speaker = new Speaker({
  sampleRate: 24000,
  channels: 1,
  bitDepth: 16,
})

const voice = new OpenAIRealtimeVoice({
  apiKey: process.env.OPENAI_API_KEY,
  speaker: 'alloy',
})
// Connect to the real-time service
await voice.connect()
// Now you can use real-time features
voice.on('speaker', stream => {
  stream.pipe(speaker)
})
```

## 連線失敗 {/* #connection-failures */}

對於 OpenAI Realtime，`connect()` 會等待 WebSocket 開啟且伺服器建立工作階段。如果連線失敗、伺服器在握手期間回報錯誤，或工作階段就緒前通訊端關閉，Promise 會被拒絕。握手無回應時，預設在 15,000 毫秒後逾時。

請直接捕獲連線失敗。監聽 `error` 事件不能代替處理被拒絕的 Promise：

```typescript
import { OpenAIRealtimeVoice } from '@mastra/voice-openai-realtime'

const voice = new OpenAIRealtimeVoice({
  apiKey: process.env.OPENAI_API_KEY,
  connectTimeoutMs: 30_000,
})

try {
  await voice.connect()
} catch (error) {
  console.error('Could not connect to the realtime service:', error)
}
```

握手失敗後，通訊端會關閉，待處理的等待也會清除。可以在同一實例上重新呼叫 `connect()`。

## 與 `CompositeVoice` 配合使用 {/* #using-with-compositevoice */}

使用 `CompositeVoice` 時，`connect()` 會將選項傳遞給已設定的即時 Provider；如果沒有設定即時 Provider，則會抛出異常：

```typescript
import { CompositeVoice } from '@mastra/core/voice'
import { OpenAIRealtimeVoice } from '@mastra/voice-openai-realtime'
const realtimeVoice = new OpenAIRealtimeVoice()
const voice = new CompositeVoice({
  realtime: realtimeVoice,
})
// This will use the OpenAIRealtimeVoice provider
await voice.connect()
```

## 注意事項 {/* #notes */}

* 只有支持語音對話的即時語音 Provider 實現此方法
* 继承基础 `connect()` 實現的 Provider 只會记錄調试消息並完成呼叫，不會建立連線
* 使用 `send()` 或 `answer()` 等其他即時方法前必須先建立連線
* 使用完語音實例後，請呼叫 `close()` 清理資源
* 部分 Provider 可能會在連線斷開後自動重連，具體取決於其實現
* 連線錯誤通常以異常形式抛出，應捕獲並處理
