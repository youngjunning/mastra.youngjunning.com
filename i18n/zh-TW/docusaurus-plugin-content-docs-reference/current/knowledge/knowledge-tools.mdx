# Knowledge 工具

Knowledge 為 Agent 提供六種 Tool。Agent 取得哪些 Tool，取決於 Knowledge 的 `tools` 與 `pinnedContext` 選項，或傳給 [`createTools()`](/reference/knowledge/knowledge-class#createtools) 的工具群組。關於 Agent 如何使用這些工具，請參閱 [Agent 與工具](/docs/knowledge/agents-and-tools)。

| 群組 | 工具 | 啟用條件 |
| - | - | - |
| 讀取 | `knowledge_list`, `knowledge_search`, `knowledge_read` | `tools: true` 或 `tools: { read: true }` |
| 寫入 | `knowledge_page`, `knowledge_note` | `tools: true` 或 `tools: { write: true }` |
| 固定情境 | `knowledge_pin` | `pinnedContext` |

每種 Tool 都依據本次執行持有的作用域，以及 Knowledge 宣告賦予的角色執行操作。若執行未持有任何作用域，就會失敗並回傳：

```text
Knowledge tools need run scopes: give the agent or the call `scopes`, or run it with Memory.
```

Tool 錯誤會以工具結果回傳給模型，而不會擲出例外。執行無權讀取的頁面或筆記會視同不存在：錯誤只會指出找不到，不會指出存取遭拒。

:::alpha

Knowledge 目前處於 alpha 階段，API 可能隨版本變動。

:::

## 頁面參照 {/* #page-references */}

名為 `page` 的參數（以及 `into`、`parent`、`from`）接受下列任一形式：

- 頁面 ID。
- 作用域本身頁面的作用域位址，例如 `org:acme`。
- 頁面路徑 `<scope>#<key>[/<key>…]`，例如 `policy:acme#refund-policy` 或 `org:acme#policies/refund`。
- 完全相符的頁面名稱。

在頁面路徑中，`/` 位於 `#` 前時表示子作用域，`/` 位於其後時表示子頁面。頁面部分開頭、結尾及重複的斜線會被忽略，因此 `org:acme#policies/` 與 `org:acme#policies` 指向同一頁面。路徑在使用時解析；頁面移動後只能透過新路徑存取。

若名稱符合多個可讀取的頁面，操作會遭拒，並回傳候選頁面的參照：

```text
Knowledge page name "Chargeback Playbook" is ambiguous; use one of these refs: team:acme:billing#chargeback-playbook, team:acme:support#chargeback-playbook.
```

工具結果使用 `ref` 識別每個頁面；上述參數均接受下列形式：

- 作用域頁面使用作用域位址。
- 每一層都有 key 的頁面使用完整路徑，例如 `docs:acme#guides/observability/logging`。
- 其他情況使用頁面 ID。

讀取不存在的頁面時，結果會依 `ref` 列出最多三個相近的項目。

## `knowledge_search` {/* #knowledge_search */}

搜尋本次執行可讀取的頁面與筆記。

查詢會拆成單字，並忽略引號。比對時不區分大小寫，每個查詢詞都可符合單字的一部分，因此 `refund` 能符合 `refunds`。頁面的名稱、描述或內文只要包含任一查詢詞就會符合；筆記則依自身文字比對。

關鍵字結果依下列順序排序：

1. 名稱包含完整查詢內容的頁面。
1. 其他頁面：先依符合的查詢詞數量排序，再依出現位置排序（名稱優先於描述，描述優先於內文），最後依最近更新時間排序。
1. 筆記：先依符合的查詢詞數量排序，再依新舊排序。

存取權限與 `scope` 會在排序前篩選結果；`limit` 在篩選與排序後才生效。若 Knowledge 執行個體設定了 `vector` 與 `embedder`，關鍵字與語意搜尋結果會依排名合併，上述順序便不再適用。

回傳 `{ results }`，每筆為 `{ type: 'page', page }` 或 `{ type: 'note', page, note }`。這些搜尋也會回傳 `more`：

`scope` 只接受作用域位址。傳入 `docs:acme#billing` 等頁面參照會遭拒，並提示使用 `knowledge_list`。

回傳 `{ from?, entries, nextCursor?, more? }`。`from` 為 `{ ref, name }`。每個項目為 `{ ref, name, depth, children, scope? }`；包含 `description` 時，`descriptions` 為 `true`。`depth` 為 1 表示起點的子頁面；`children` 計算可讀取的子頁面（對作用域還包括子作用域）；`scope` 為 `true` 表示作用域。

完整讀取會回傳 `{ page, notes, children, childScopes?, mentionedIn, nextCursor?, mentionedInCursor?, more? }`，內文位於 `page`。遭截斷的內容會列在 `more`，並說明如何繼續讀取：

- **內文。** 若內文未超過讀取上限（預設 1,000 個 token，除非透過 [`tools.read.maxTokens`](/reference/knowledge/knowledge-class#constructor-options) 調整），會以 `page.body` 回傳。較長的內文會以 `page.lines` 回傳，附有行號（`12│text`），並包含所涵蓋行的 `page.range` 與 `page.lineCount`。`more` 會指出從何處繼續讀取，例如 `body: showing lines 1–40 of 412. Read on with from: {"line":41}.`
- **首次讀取長頁面。** 若內文包含標題，一般讀取（未指定 `section` 或 `from`）會先提供整頁概覽：`page.lines` 在讀取上限內分配篇幅，顯示每個標題、行號及標題下的開頭幾行；省略的行以 `⋯ lines a–b` 標示，截斷的行以 `…` 標示。結果包含 `page.lineCount`，但沒有 `page.range`，因此不能直接寫回。請先依 `section` 或 `from` 讀取，再以該次讀取回傳的 `range` 編輯。若沒有標題，或標題多到超出上限，則會回傳附 `page.range` 的開頭幾行，並透過 `page.outline` 列出尚未讀到的標題（最多約 500 個 token）。
- **筆記與提及。** 完整讀取最多取得 `limit` 則筆記及 `limit` 則提及此頁面的筆記。只要已取得的筆記未超過 1,000 個 token，兩份清單就會隨結果回傳。較長的清單會改以 `notesLeftOut` 或 `mentionedInLeftOut` 表示已取得的筆記數；`more` 會提示以 `notes: true` 或 `mentionedIn: true` 單獨讀取。若筆記總數超過 `limit`，`more` 中的數量與 token 估計只涵蓋已取得的部分，實際清單更長。
- **子頁面與子作用域。** 超過 `limit` 時，`more` 會提示使用 `knowledge_list` 列出其餘內容。

`range` 的結構為 `{ start: { line, col? }, end: { line, col? } }`。行號從 1 開始。只有單行過長、無法一次讀完時，讀取結果才會包含從 0 開始的 `col`；結束位置的 `col` 不包含在範圍內。將此範圍傳給 `knowledge_page` 即可替換這些行。

`match` 會回傳 `matches`，每筆包含 `{ range, lines }`。符合結果超過讀取上限（預設 1,000 個 token）時，`more` 會提供繼續讀取的行號，例如 `match: stopped at about 1,000 tokens; more matches from line 120. Read again with the same match and from: {"line":120}.`

`outline`、`section`、`match` 與 `from` 只回傳對應的內文，不含筆記、子頁面或提及筆記。`outline`、`section` 與 `match` 最多只能傳入其中一個。`notes`、`mentionedIn` 及兩種游標只回傳相應筆記，不含內文，也不能與內文選項組合：

```text
knowledge_read: read notes or mentionedIn on their own, without outline, section, match or from.
```

對 `body` 的寫入若未指定 `range`，且已儲存的內文超過單次讀取上限（預設 1,000 個 token），會遭拒。以下情況也會拒絕 `range`：缺少 `expectedVersion`、起點晚於終點、範圍超出內文末尾，或範圍涵蓋的內容超過從其首行開始單次讀取所能回傳的內容：

```text
Lines 1–150 run past what one knowledge_read from line 1 shows, so this can't be a range a read gave you. Edit the body part by part: write each part back with the range its own read returned.
```

若 `body` 仍包含讀取時加上的行號，寫入會遭拒：`This body still has the line numbers a knowledge_read put in front of each line ("12│"). Write the text without them.`

| 操作 | 所需角色 |
| - | - |
| 建立（`write` 未傳入 `page`） | `contributor`，在 `scope` 上 |
| 編輯（`write` 傳入 `page`） | 頁面作用域的 `editor` |
| 在同一作用域內移動 | 頁面作用域的 `editor` |
| 移動至其他作用域 | `owner`，在頁面作用域與目標 `scope` 上 |
| 合併 | 被合併頁面的作用域需有 `owner`；保留頁面 `into` 的作用域若相同需有 `editor`，若不同則需有 `owner`，因為子頁面會移至該處 |
| 刪除 | 頁面作用域的 `owner` |

在作用域的 `pages` 中宣告的範本頁面，無論執行持有什麼角色，都可以編輯、加註筆記或作為合併目標，但不能移動、作為被合併頁面或刪除。

作用域頁面的名稱與描述來自設定，因此對作用域頁面執行 `write` 只會修改內文；作用域頁面不能移動、合併或刪除。

`delete` 會從讀取、搜尋與固定情境中移除頁面。有子頁面的頁面、作用域頁面及範本頁面都不能刪除。

```text

Editing a page needs at least one of name, description or body.
Editing a page takes no scope, parent or key; use op "move" to relocate it.
Moving a page needs the destination scope.
Merging needs into: the page that remains.
"Escalation" has child pages; move or delete them first.
"org:acme" is a scope page; scope pages can't be moved, merged or deleted.
"org:acme" is a scope page; its name and description come from config, so only its body can be written.
Knowledge page "org:acme#policies/escalation" not found.
Knowledge page key "a/b" must not contain "/", "#" or "%"
Knowledge page key "escalation" already exists under page aa8f6099-6111-4952-b9cb-04cb97eb2bb5. Keys are unique among siblings; pick another key or move one of the pages.
"org:acme#policies/refund" is declared in config; change the scope's pages to move it.
"org:acme#policies/refund" is declared in config; change the scope's pages to remove it.
Editing a page needs editor on "team:acme:support"; this run has viewer there.
Moving a page across scopes needs owner on "org:acme"; this run has editor there.
Merging a page away needs owner on "team:acme:support"; this run has editor there.
Merging a page across scopes needs owner on "team-public:acme:support"; this run has editor there.
Deleting a page needs owner on "org:acme"; this run has editor there.

```

| 操作 | 所需角色 |
| - | - |
| `add` | 頁面作用域及每個標記作用域的 `contributor` |

移除筆記後再新增，會產生新的筆記 ID。錯誤範例：

```text
Adding a note needs page and text.
Adding a note needs scope: the stamp scopes.
Adding a note needs contributor on "team:acme:support"; this run has viewer there.
Removing a note needs editor on "team:acme:support"; this run has viewer there.
Knowledge note text exceeds the 250 token limit; split it into separate notes or put long-form text in the page body
```

## `knowledge_pin` {/* #knowledge_pin */}

將頁面或其下的頁面清單固定到每次執行的每一輪情境中，也可以取消固定；接收內容的執行須持有任一受眾作用域。固定內容的傳遞仰賴 Memory。請參閱[固定情境](/docs/knowledge/pinned-context)。

<PropertiesTable
  content={[
  { name: 'op', type: "'pin' | 'unpin'", description: '要執行的操作。' },
  { name: 'page', type: 'string', description: '要固定或取消固定的頁面。' },
  { name: 'audience', type: 'string[]', description: '接收固定內容的執行所持有的作用域位址。' },
{
  name: 'kind',
  type: "'page' | 'list'",
  description:
      '`page` 固定頁面。`list` 固定其下的頁面清單。每個頁面可分別擁有這兩種固定項，並各自固定或取消固定。',
  isOptional: true,
  defaultValue: "'page'",
},
{
  name: 'depth',
  type: 'number',
  description:
      '`list` 固定項顯示頁面下方的層級數，1 至 3。再次固定清單會設定新的深度。僅適用於 `op: "pin"` 且 `kind: "list"`。',
  isOptional: true,
  defaultValue: '1',
},
]}
/>

固定或取消固定頁面時，需要頁面作用域的 `editor`，並且必須持有每個受眾作用域，或在其上擁有 `editor`。固定頁面只會送達可讀取它的執行；固定清單也只顯示該執行可讀取的頁面。固定清單需要支援儲存固定項種類的儲存配接器版本。舊版配接器仍支援固定頁面，但會在寫入前拒絕固定清單。

```text
Pinning a page needs editor on "policy:acme"; this run has viewer there.
Pinning for "role:acme:sales" needs holding it or editor on it; this run has neither.
Pin audience "project:x" does not match a declared scope type.
```

## 各操作所需權限 {/* #what-each-operation-needs */}

| 操作 | 角色 | 適用範圍 |
| - | - | - |
| 搜尋、讀取、列出 | `viewer` | 頁面作用域 |
| 建立頁面 | `contributor` | `scope` |
| 編輯頁面 | `editor` | 頁面作用域 |
| 在同一作用域內移動 | `editor` | 頁面作用域 |
| 移動至其他作用域 | `owner` | 兩個作用域 |
| 合併 | `owner` | 被合併的頁面 |
| | `editor` | 同一作用域內保留的頁面 |
| | `owner` | 其他作用域內保留的頁面 |
| 刪除頁面 | `owner` | 頁面作用域 |
| 新增筆記 | `contributor` | 頁面作用域及每個標記作用域 |
| 重新標記或移除筆記 | `editor` | 頁面作用域（每個新標記作用域還需 `contributor`） |
| 固定或取消固定頁面或清單 | `editor` | 頁面作用域，且須對每個受眾有相應權限 |

若呼叫目標在可存取範圍內、但需要更高角色權限，錯誤會指出所需角色：

```text
Adding a note needs contributor on "team:acme:support"; this run has viewer there.
```
