# Tool使用說明

當知識將Tool附加到Agent時，它還會添加一個簡短的指令區塊來解釋如何使用它們。每個部件僅在其Tool開啟時才包含在內：

* **讀**告訴Agent：
  * 搜尋方式`knowledge_search` before answering, and read a page with `knowledge_read` before relying on it.
  * 列出範圍或部分`knowledge_list` to see how it's organized.
  * 首先閱讀整個長頁面，然後從顯示的標題中閱讀所需的部分。
  * 跟隨`more` instead of assuming a result was complete.
  * 引用頁面或註釋它所使用的內容，並在沒有找到任何內容時說明這一點。
  * 當他們意見不一致時，請顯示兩個註釋及其日期。
* **寫**告訴Agent：
  * 每個註釋添加一個持久事實`knowledge_note`, on the page it's about.
  * 在建立頁面之前新增到現有頁面。
  * 將長文本（例如操作手冊）放入頁面正文中`knowledge_page`.
  * 將變更記錄為新的註明日期的註釋，並僅刪除錯誤的註釋。
* **針腳**告訴Agent：
  * 僅固定常設指示、持久偏好和嚴格約束，無需提出要求即可應用。
  * 保持固定頁面簡短，一旦頁面不再真實，就取消固定頁面。

文字僅取決於開啟的Tool以及您的覆蓋範圍。它從不依賴運行的範圍、固定頁面或搜尋結果，因此它不會破壞提示快取。

：：：阿爾法

知識處於阿爾法階段。其 API 可能會在不同版本之間變更。

## 覆蓋指令 {/* #override-the-instructions */}

```typescript
import { Knowledge, knowledgeMemoryScopes } from '@mastra/core/knowledge'

const knowledge = new Knowledge({
  id: 'company',
  tools: true,
  scopes: { ...knowledgeMemoryScopes() },
  // instructions: false, to remove the block
  // instructions: 'Your own text', to replace it
  instructions: ({ read, write, pins }) => `${read}\n${write}\n${pins}\nAlways answer in French.`,
})
```

此函數接收每個部分的預設文字為`read`, `write` and `pins`, with an empty string for parts that are off. Return the same string for the same inputs, or the prompt cache stops working.

若要在您自己連接Tool時新增區塊，請調用`knowledge.getInstructions({ read: true, write: true, pinnedContext: false })`.
