# Tool 使用說明

Knowledge 將 Tool 加入 Agent 時，也會新增一段簡短說明，解釋這些 Tool 的用法。只有啟用對應 Tool 時，才會包含相應部分：

* **讀取**指示 Agent：
  * 回答前使用 `knowledge_search` 搜尋；依賴某個頁面前，先使用 `knowledge_read` 閱讀該頁面。
  * 使用 `knowledge_list` 列出 scope 或章節，瞭解其組織方式。
  * 對於長頁面，先通讀全文，再依顯示的標題閱讀所需章節。
  * 跟隨 `more` 繼續取得結果，不要假設目前結果已經完整。
  * 引用所使用的頁面或 note；若未找到任何內容，也應明確說明。
  * 如果兩個 note 內容衝突，應同時顯示它們與各自日期。
* **寫入**指示 Agent：
  * 使用 `knowledge_note` 在相關頁面中為每個 note 記錄一項可長期保留的事實。
  * 建立新頁面前，優先補充現有頁面。
  * 使用 `knowledge_page` 將操作手冊等長篇內容寫入頁面本文。
  * 將變更記錄為附日期的新 note，且只刪除錯誤的 note。
* **固定內容**指示 Agent：
  * 只固定無須詢問即可適用的長期指示、持久偏好與明確限制。
  * 保持固定頁面簡短；頁面內容不再成立時，應取消固定。

這些文字只取決於啟用的 Tool 與你的覆寫設定，不依賴這次執行的 scope、固定頁面或搜尋結果，因此不會破壞 prompt 快取。

:::alpha

Knowledge 目前處於 alpha 階段，其 API 可能在不同版本之間變更。

:::

## 覆蓋指令 {/* #override-the-instructions */}

```typescript
import { Knowledge, knowledgeMemoryScopes } from '@mastra/core/knowledge'

const knowledge = new Knowledge({
  id: 'company',
  tools: true,
  scopes: { ...knowledgeMemoryScopes() },
  // instructions: false, to remove the block
  // instructions: 'Your own text', to replace it
  instructions: ({ read, write, pins }) => `${read}\n${write}\n${pins}\nAlways answer in French.`,
})
```

此函式透過 `read`、`write` 與 `pins` 接收各部分的預設文字；未啟用的部分會收到空字串。相同輸入必須傳回相同字串，否則 prompt 快取將失效。

自行連接 Tool 時，如需加入這段說明，請呼叫 `knowledge.getInstructions({ read: true, write: true, pinnedContext: false })`。
