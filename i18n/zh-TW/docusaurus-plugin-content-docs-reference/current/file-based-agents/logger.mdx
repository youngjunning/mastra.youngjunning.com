# 日誌記錄器

Mastra 從 `src/mastra/` 目錄下的 `logger.ts` 檔案載入專案的[日誌記錄器](/docs/observability/logging)。檔案預設匯出的記錄器會取代 Agent、Workflow 和其他元件所用的內建 `ConsoleLogger`。

本頁說明如何透過檔案設定記錄器。日誌層級、傳輸方式和 Provider 的詳細資料請見[日誌記錄](/docs/observability/logging)。

## 快速入門 {/* #quickstart */}

建立 `src/mastra/logger.ts`，並預設匯出日誌記錄器，例如 [`PinoLogger`](/reference/logging/pino-logger)。

```typescript title="src/mastra/logger.ts"
import { PinoLogger } from '@mastra/loggers'

export default new PinoLogger({
  name: 'Mastra',
  level: 'info',
})
```

Mastra 會先註冊日誌記錄器，再設定儲存、可觀測性及檔案式 Agent。這些元件在初始化時會使用該記錄器寫入日誌。

## 檔案設定與程式碼設定的優先順序 {/* #precedence-with-code */}

程式碼中的日誌設定優先於 `logger.ts`。在 `src/mastra/index.ts` 以 `new Mastra({ logger })` 傳入 `logger`，或以 `logger: false` 停用日誌時，Mastra 會忽略 `logger.ts` 並發出警告。整個專案只需要一個記錄器時，可使用 `logger.ts`。若設定取決於執行時期如何組合元件，請透過程式碼註冊。
