# 處理器

基於文件的Agent發現[processors](/docs/agents/processors)從它的`processors/`目錄。使用此頁面進行基於文件的約定；使用內建處理器、自訂處理器、流行為和高級模式的處理器指南。

文件下`processors/input/` run before messages reach the model. Files under `processors/output/` run after the model responds. Each file default-exports one [`Processor`](/reference/processors/processor-interface)，檔案名稱成為其發現密鑰。

## 快速入門 {/* #quickstart */}

透過將處理器檔案放置在下面來新增輸入處理器`processors/input/`:

```typescript title="src/mastra/agents/weather/processors/input/pii.ts"
import { PIIDetector } from '@mastra/core/processors'

export default new PIIDetector({
  strategy: 'block',
})
```

該處理器在用戶訊息到達模型之前運行。

## 新增輸出處理器 {/* #add-an-output-processor */}

輸出處理器非常適合在返回模型響應之前對其進行過濾或轉換。此範例從最終回應中編輯 PII。

```typescript title="src/mastra/agents/weather/processors/output/redact.ts"
import { PIIDetector } from '@mastra/core/processors'

export default new PIIDetector({
  strategy: 'redact',
})
```

## 訂購 {/* #ordering */}

發現的處理器添加在中定義的任何處理器之後[`config.ts`](/reference/file-based-agents/config). That means config processors run first.

```text title="Ordering"
config.inputProcessors → processors/input/* → model
model → config.outputProcessors → processors/output/* → response
```

如果`config.inputProcessors` or `config.outputProcessors` is a function, discovered processors of that type are ignored with a warning because function-valued processors can't be statically merged.

如果`config.ts` exports a `new Agent()` instead of a config object, Mastra uses that agent as-is. Discovered files under `processors/input/` and `processors/output/` are ignored with a warning, so set `inputProcessors` and `outputProcessors` on the `Agent` instead.

## 配置的優先權 {/* #precedence-with-config */}

使用`config.ts` for processors that need to be created at runtime or shared across agents. Use file-based processors for static, per-agent processors that should be reviewed alongside the agent.

優先順序是：

1. 功能價值`config.inputProcessors` or `config.outputProcessors`
2. 數組值`config.inputProcessors` or `config.outputProcessors`
3. 發現以下文件`processors/input/` or `processors/output/`

參觀[`Processor` reference](/reference/processors/processor-interface) for the full interface.
