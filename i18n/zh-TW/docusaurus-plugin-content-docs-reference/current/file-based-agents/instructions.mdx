# 指示

Agent的指令保留其始終在線的系統提示：模型每次都會讀取它。使用它們來定義Agent的身份、語氣、角色和站立規則。

將它們寫入Agent根目錄下的兩個檔案之一。使用`instructions.md` when the prompt is fixed text. Use `instructions.ts`當提示需要程式碼時，例如當它是從共享常數建置或根據請求解析時。

說明始終在上下文中，因此請保留它們以確保適用於每個請求的穩定行為。将任何有条件的、大型的或以行动为导向的东西移入[`tools/`](/reference/file-based-agents/tools) or [`skills/`](/reference/file-based-agents/skills), which the model uses only when relevant.

## 快速入門 {/* #quickstart */}

添加一個`instructions.md` at the agent root. Whatever you write becomes the prompt, so the shortest version is a single sentence.

```markdown title="src/mastra/agents/weather/instructions.md"
You are a helpful weather assistant. Answer questions about current conditions and forecasts.
```

## 說明包含哪些內容 {/* #what-goes-in-instructions */}

有效的指令涵蓋了Agent行為中在請求之間不會改變的部分：

* 角色和身份
* 語氣和風格
* 常設規則
* 輸出格式

將有條件的、大型的或以行動為導向的指導移入[`tools/`](/reference/file-based-agents/tools) or [`skills/`](/reference/file-based-agents/skills), which the model uses only when relevant.

## TypeScript 中的說明 {/* #instructions-in-typescript */}

使用`instructions.ts` when markdown can't express the prompt. The file default-exports a string, a system message, a non-empty array of strings or system messages, or a function returning one, and `agentInstructions()` types the export without changing it.

當提示在程式碼中組裝時導出字串，例如從與應用程式的其餘部分共享的常數：

```typescript title="src/mastra/agents/weather/instructions.ts"
import { agentInstructions } from '@mastra/core/agent'
import { SUPPORTED_UNITS } from '../../constants'

export default agentInstructions(`
You are a helpful weather assistant.
Report conditions using one of these units: ${SUPPORTED_UNITS.join(', ')}.
`)
```

當提示取決於請求時匯出函數。 Mastra 每次都會呼叫它並傳遞請求上下文：

```typescript title="src/mastra/agents/support/instructions.ts"
import { agentInstructions } from '@mastra/core/agent'

export default agentInstructions(({ requestContext }) => {
  const tier = requestContext.get('tier') ?? 'standard'
  return `You are a support agent. Treat this as a ${tier}-tier customer.`
})
```

該函數可以是`async`. Alongside `requestContext`, it receives `mastra`, the Mastra instance the agent is registered with, so it can read from storage or another registered primitive before returning the prompt. `mastra` is optional in the function type, so guard its use (for example, `mastra?.getStorage()`).

這兩個檔案也可以存在於[subagent](/reference/file-based-agents/subagents) directory, which follows the same rules.

## 建構時行為 {/* #build-time-behavior */}

`instructions.md`和`instructions.ts` reach the deployed agent differently:

* `instructions.md`：Mastra 讀取檔案並在建置時將其內容內聯到生成的程式碼中。
* `instructions.ts`：生成的程式碼導入模組，因此它像任何其他 TypeScript 檔案一樣捆綁在一起，並且可以從專案的其餘部分導入。

在下面`mastra dev`, editing either file triggers a rebuild. In a deployed app neither file is read from disk at runtime, so changes take effect after the next build.

## 配置的優先權 {/* #precedence-with-config */}

指令可以來自`instructions.ts`, `instructions.md`, or the `instructions` field in [`config.ts`](/reference/file-based-agents/config):

* 運行時定義的（函數）`instructions` in `config.ts` wins over both files.
* 否則`instructions.ts` wins over `instructions.md`.
* `instructions.md`戰勝靜電`instructions` string in `config.ts`.
* 如果不存在，則建置失敗並命名Agent目錄。

在多個位置定義指令會記錄一條警告，其中列出了兩個來源的名稱以及哪個來源獲勝。每個Agent保留一個來源。
