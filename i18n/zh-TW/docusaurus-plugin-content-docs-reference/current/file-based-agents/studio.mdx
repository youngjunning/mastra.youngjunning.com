# Studio

Mastra 從 `src/mastra/` 目錄下的 `studio.ts` 檔案載入 [Studio](/docs/studio/overview) 設定。檔案預設匯出的 `StudioConfig` 物件用於身分驗證與授權，決定誰可以存取 Studio，以及通過驗證的使用者可以執行哪些操作。

本頁說明如何透過檔案設定 Studio。驗證 Provider、角色型存取控制（RBAC）與細粒度授權（FGA）請見 [Studio 身分驗證與授權](/docs/studio/auth)。

## 快速入門 {/* #quickstart */}

本機開發不需要 `studio.ts`。啟動開發伺服器後，即可開啟 Studio。

```bash npm2yarn
npm run dev
```

在本機開發時，開啟 Studio 不需要驗證。若要保護共用或正式環境的部署，請新增 `studio.ts`。

## 新增身分驗證 {/* #add-authentication */}

使用驗證 Provider，讓使用者必須登入才能存取 Studio。此範例使用 [WorkOS](/integrations/auth/workos)。

```typescript title="src/mastra/studio.ts"
import { MastraAuthWorkos } from '@mastra/auth-workos'
import type { StudioConfig } from '@mastra/core/server'

export default {
  auth: new MastraAuthWorkos(),
} satisfies StudioConfig
```

驗證 Provider 會確認使用者的身分。若要限制使用者登入後可以執行的操作，請在同一份設定中加入 RBAC 或 FGA。完整範例請見 [Studio 身分驗證與授權](/docs/studio/auth)。

## 檔案設定與程式碼設定的優先順序 {/* #precedence-with-code */}

透過程式碼註冊的 Studio 設定優先於 `studio.ts`。整個專案只需要一組 Studio 設定時，可以使用 `studio.ts`。若驗證取決於執行時期如何組合元件，請在 `src/mastra/index.ts` 透過程式碼註冊。
