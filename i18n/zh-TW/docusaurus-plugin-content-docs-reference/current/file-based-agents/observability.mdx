# 可觀測性

Mastra 從 `src/mastra/` 目錄下的 `observability.ts` 檔案載入[可觀測性](/docs/observability/overview)設定。檔案預設匯出的 `Observability` 實例會為專案設定追蹤、日誌、指標及回饋。

本頁說明如何透過檔案設定可觀測性。訊號模型、匯出器、儲存及多組設定請見[可觀測性概觀](/docs/observability/overview)和[可觀測性設定](/docs/observability/overview#configuration)。

## 快速入門 {/* #quickstart */}

建立 `src/mastra/observability.ts`，並預設匯出 `Observability` 實例。

```typescript title="src/mastra/observability.ts"
import { MastraStorageExporter, Observability } from '@mastra/observability'

export default new Observability({
  configs: {
    default: {
      serviceName: 'mastra',
      exporters: [new MastraStorageExporter()],
    },
  },
})
```

## 可觀測性與儲存 {/* #observability-and-storage */}

`observability.ts` 指定要收集哪些訊號，以及要將訊號匯出到哪裡。[`storage.ts`](/reference/file-based-agents/storage) 設定可持久保存可觀測性紀錄的專案儲存實例。各訊號的儲存支援情形請見[可觀測性訊號支援](/docs/observability/overview#signal-support)。

## 檔案設定與程式碼設定的優先順序 {/* #precedence-with-code */}

透過程式碼註冊的可觀測性設定優先於 `observability.ts`。整個專案只需要一組設定時，可以使用 `observability.ts`。若設定取決於執行時期如何組合元件，請在 `src/mastra/index.ts` 透過程式碼註冊。
