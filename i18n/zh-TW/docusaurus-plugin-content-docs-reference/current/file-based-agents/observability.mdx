# 可觀察性

馬斯特拉配置[observability](/docs/observability/overview)從一個`observability.ts`直接在下面的文件`src/mastra/`。該文件預設導出一個`Observability`為專案設定追蹤、日誌記錄、指標和回饋的實例。

使用此頁面進行基於文件的約定。有關訊號模型、匯出器、儲存和多配置設置，請參閱[observability overview](/docs/observability/overview) and [observability configuration](/docs/observability/overview#configuration).

## 快速入門 {/* #quickstart */}

創造`src/mastra/observability.ts` and default-export an `Observability` instance:

```typescript title="src/mastra/observability.ts"
import { MastraStorageExporter, Observability } from '@mastra/observability'

export default new Observability({
  configs: {
    default: {
      serviceName: 'mastra',
      exporters: [new MastraStorageExporter()],
    },
  },
})
```

## Observability和存儲 {/* #observability-and-storage */}

`observability.ts`配置收集哪些訊號以及將其匯出到何處。[`storage.ts`](/reference/file-based-agents/storage) configures the project store that can persist observability records. For storage support by signal, see [observability signal support](/docs/observability/overview#signal-support).

## 程式碼優先權 {/* #precedence-with-code */}

代碼註冊的Observability勝出`observability.ts`. Use `observability.ts` when one project-wide configuration is enough. Use code registration when setup depends on runtime wiring in `src/mastra/index.ts`.
