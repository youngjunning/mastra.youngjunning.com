# 伺服器

Mastra 配置其 HTTP[server](/docs/server/overview)從一個`server.ts`直接在下面的文件`src/mastra/`。伺服器將Agent程式、Workflow和其他註冊原語公開為 REST 端點，並且檔案預設匯出相同的內容`ServerConfig`你會傳遞給的形狀[`new Mastra()`](/reference/core/mastra-class).

使用此頁面進行基於文件的約定。有關伺服器功能、中間件、自訂路由、產生的 API 文件和部署行為，請參閱[Server overview](/docs/server/overview).

## 快速入門 {/* #quickstart */}

創造`src/mastra/server.ts` and default-export a `ServerConfig` object:

```typescript title="src/mastra/server.ts"
import type { ServerConfig } from '@mastra/core/server'

export default {
  port: 4111,
  host: '0.0.0.0',
} satisfies ServerConfig
```

## 常用配置 {/* #common-configurations */}

`server.ts`可以配置與程式碼註冊相同的伺服器選項：

|需要|使用|
| - | - |
|綁定部署平台位址 |`host` and `port` |
| Restrict browser access | `cors` |
| Add webhooks or health checks | `apiRoutes` |
| Enable generated API docs | `build.openAPIDocs` and `build.swaggerUI` |

看[Mastra server](/docs/server/overview), [middleware](/docs/server/middleware), and [custom API routes](/docs/server/custom-api-routes) for examples.

## 程式碼優先權 {/* #precedence-with-code */}

代碼註冊伺服器配置獲勝`server.ts`. Routes added during startup, such as channel webhooks, are preserved when file-based server config is applied.
