# 伺服器

Mastra 從 `src/mastra/` 目錄下的 `server.ts` 檔案載入 HTTP [伺服器](/docs/server/overview)設定。伺服器會將 Agent、Workflow 和其他已註冊的元件公開為 REST 端點。檔案預設匯出的 `ServerConfig` 與傳給 [`new Mastra()`](/reference/core/mastra-class) 的設定結構相同。

本頁說明如何透過檔案設定伺服器。伺服器功能、中介軟體、自訂路由、自動產生的 API 文件及部署行為請見[伺服器概觀](/docs/server/overview)。

## 快速入門 {/* #quickstart */}

建立 `src/mastra/server.ts`，並預設匯出 `ServerConfig` 物件。

```typescript title="src/mastra/server.ts"
import type { ServerConfig } from '@mastra/core/server'

export default {
  port: 4111,
  host: '0.0.0.0',
} satisfies ServerConfig
```

## 常用設定 {/* #common-configurations */}

`server.ts` 支援與程式碼註冊相同的伺服器設定選項。

| 用途 | 設定選項 |
| - | - |
| 繫結至部署平台的位址 | `host` 和 `port` |
| 限制瀏覽器存取 | `cors` |
| 新增 Webhook 或健康檢查 | `apiRoutes` |
| 啟用 API 文件產生功能 | `build.openAPIDocs` 和 `build.swaggerUI` |

範例請見 [Mastra 伺服器](/docs/server/overview)、[中介軟體](/docs/server/middleware)與[自訂 API 路由](/docs/server/custom-api-routes)。

## 檔案設定與程式碼設定的優先順序 {/* #precedence-with-code */}

透過程式碼註冊的伺服器設定優先於 `server.ts`。套用檔案式伺服器設定時，啟動期間新增的路由（例如頻道 Webhook）會保留。
