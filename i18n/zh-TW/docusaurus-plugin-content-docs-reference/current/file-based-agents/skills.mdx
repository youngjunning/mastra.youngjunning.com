# Skills

檔案式 Agent 從 `skills/` 目錄探索 Skill，並在建置時將其打包。Skill 是可重複使用的流程或參考資料，Agent 可在相關情境下載入，不必將所有細節都放進每次都會使用的提示。

本頁介紹檔案式慣例。程式碼定義的 Skill 請參閱 [Agent Skill](/docs/skills)；`SKILL.md` 封裝格式請參閱 [Workspace Skill](/docs/sandbox/skills)。

## 快速開始 {/* #quickstart */}

最簡單的 Skill 是 `skills/` 底下的一個 Markdown 檔案。預設以檔名作為 Skill 名稱；若 frontmatter 設定了 `name`，則以該值為準。`description` 告訴 Agent 何時載入此 Skill。

```markdown title="src/mastra/agents/weather/skills/temperature-units.md"
---
description: Use when reporting temperatures or comparing forecast units.
---

Always report temperatures in Celsius and Fahrenheit. Include the user's preferred unit first when known.
```

## Skill、Tool 與 instructions {/* #skills-vs-tools-vs-instructions */}

| 需求 | 使用 | 原因 |
| - | - | - |
| 每次都會使用的身分、語氣或規則 | [`instructions.md`](/reference/file-based-agents/instructions) | 模型每一輪都應看到這些指引。 |
| 具有輸入與輸出的可呼叫操作 | [`tools/`](/reference/file-based-agents/tools) | 模型需要執行程式碼或呼叫 API，包括會產生副作用的操作。 |
| 僅在需要時載入的詳細參考資料或流程 | `skills/` | 模型只在特定任務中需要完整指引。 |

## Skill 格式 {/* #skill-formats */}

Mastra 支援三種檔案式 Skill 格式：

| 格式 | 適用情境 |
| - | - |
| TypeScript/JavaScript 模組 | 希望透過程式碼預設匯出 [`createSkill()`](/reference/agents/createSkill) 的結果。 |
| 包含 `SKILL.md` 的目錄套件 | Skill 除了指引，還有 `references/` 底下的輔助檔案。 |
| 單一 Markdown 檔案 | Skill 是一個包含 frontmatter 與指引的 Markdown 檔案。 |

封裝的 Skill 必須提供 `description`，並將其寫在 `SKILL.md` 的 frontmatter 中；單檔 Markdown Skill 的 frontmatter 也必須提供 `description`。描述應說明何時使用此 Skill，而不只是列出內容。

## 載入內容 {/* #what-gets-loaded */}

檔案式 Agent 的 Skill 會在建置時加入產生的套件，因此部署後的 Agent 不會再從磁碟讀取。

對於封裝的 Skill，Mastra 會讀取：

- `SKILL.md`，取得中繼資料與指引。
- `references/` 底下的直屬檔案，作為輔助參考內容。

參考檔案以檔名為鍵。探索 Skill 時會略過 `references/` 底下的符號連結檔案與目錄。

## 與設定的優先順序 {/* #precedence-with-config */}

探索到的 Skill 會與 `skills` 設定中的 Skill 合併，該設定位於 [`config.ts`](/reference/file-based-agents/config)。若名稱衝突，以 `config.skills` 為準，並記錄警告。

若 `config.skills` 是函式，探索到的 Skill 會被忽略並記錄警告，因為無法靜態合併函式形式的 Skill。
