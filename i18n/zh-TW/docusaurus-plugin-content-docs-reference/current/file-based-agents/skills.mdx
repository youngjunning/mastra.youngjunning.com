# 技能

基於文件的Agent從其自身發現技能`skills/`目錄並在建置時捆綁它們。技能是客服人員可以在相關時加載的可重用程式或參考材料，而不是將每個細節放入始終在線的提示中。

使用此頁面進行基於文件的約定。有關程式碼定義的技能，請參閱[Agent skills](/docs/skills). For the `SKILL.md`封裝格式見[工作空間技能](/docs/sandbox/skills).

## 快速入門 {/* #quickstart */}

最簡單的技巧就是下面的一個markdown文件`skills/`. The filename becomes the skill name unless the frontmatter sets `name`, which takes precedence. The `description` tells the agent when to load it.

```markdown title="src/mastra/agents/weather/skills/temperature-units.md"
---
description: Use when reporting temperatures or comparing forecast units.
---

Always report temperatures in Celsius and Fahrenheit. Include the user's preferred unit first when known.
```

## 技能 vs Tool vs 說明 {/* #skills-vs-tools-vs-instructions */}

|需要|使用|為什麼 |
| - | - | - |
|總是在線的身份、語氣或規則 |[`instructions.md`](/reference/file-based-agents/instructions) | The model should see the guidance every turn. |
| Callable action with inputs and outputs | [`tools/`](/reference/file-based-agents/tools) | The model needs to execute code or call APIs, including operations that perform side effects. |
| Detailed reference or procedure loaded when relevant | `skills/` | The model only needs the full guidance for specific tasks. |

## 技能形式 {/* #skill-formats */}

Mastra 支援三種基於文件的技能格式：

|格式|當 | 時使用它
| - | - |
| TypeScript/JavaScript 模組 |您想要預設導出[`createSkill()`](/reference/agents/createSkill) result from code. |
| Packaged `SKILL.md` directory | The skill has instructions plus supporting files under `references/`. |
| Flat markdown file | The skill is one markdown file with frontmatter and instructions. |

對於打包技能來說，`description` is required in `SKILL.md` frontmatter. Flat markdown skills also require `description` in frontmatter. Write when to use the skill, not only what the skill contains.

## 加載什麼 {/* #what-gets-loaded */}

基於檔案的Agent技能會在建置時添加到生成的捆綁包中，因此部署的Agent程式不會從磁碟讀取它們。

對於打包技能，Mastra 寫道：

* `SKILL.md`用於元資料和說明。
* 直接下的文件`references/` as supporting reference content.

參考檔案按檔案名稱鍵入。下的符號連結檔案和目錄`references/` are skipped during discovery.

## 配置的優先權 {/* #precedence-with-config */}

發現的技能可以與任何技能融合`skills` in [`config.ts`](/reference/file-based-agents/config). On a name collision, `config.skills` wins and a warning is logged.

如果`config.skills` is a function, discovered skills are ignored with a warning because function-valued skills can't be statically merged.
