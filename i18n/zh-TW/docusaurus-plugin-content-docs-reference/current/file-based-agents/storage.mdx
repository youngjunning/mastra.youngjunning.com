# 儲存

Mastra 從 `src/mastra/` 目錄下的 `storage.ts` 檔案載入專案的預設[儲存](/docs/storage)。檔案預設匯出的儲存實例會取代 Memory、Workflow、可觀測性與其他儲存領域所用的內建記憶體儲存。

本頁說明如何透過檔案設定儲存。後端選擇、儲存領域、資料保留和 Provider 的詳細資料請見[儲存概觀](/docs/storage)。

## 快速入門 {/* #quickstart */}

若要將資料儲存在本機檔案，可使用 [`LibSQLStore`](/integrations/databases/libsql)。

```typescript title="src/mastra/storage.ts"
import { LibSQLStore } from '@mastra/libsql'

export default new LibSQLStore({
  id: 'mastra-storage',
  url: 'file:./mastra.db',
})
```

Mastra 會先註冊儲存實例，再註冊檔案式 Agent 和 Workflow。需要儲存的元件會連結到此實例，取代預設的記憶體儲存。

## 正式環境的儲存後端 {/* #production-backends */}

`storage.ts` 可匯出任何 Mastra 儲存配接器，例如 LibSQL、PostgreSQL 或 MongoDB。設定方式、Provider 支援及結構描述細節請見[儲存概觀](/docs/storage)、[可觀測性訊號支援](/docs/observability/overview#signal-support)和[儲存參考](/reference/storage/overview)。

## 檔案設定與程式碼設定的優先順序 {/* #precedence-with-code */}

透過程式碼註冊的儲存設定優先於 `storage.ts`。整個專案只需要一個儲存實例時，可以用 `storage.ts`。若設定取決於執行時期如何組合元件，請在 `src/mastra/index.ts` 透過程式碼註冊。
