# Tool

基於文件的Agent發現Tool`.ts`和`.js`直接位於其下的文件`tools/`目錄。每個發現的檔案都是在建置時匯入的，並且必須預設匯出一個Tool。Agent的任何Tool`tools`選項接受作品，例如[`createTool()`](/reference/tools/create-tool)結果或 Vercel AI SDK`tool()`。不帶副檔名的檔名成為模型可以呼叫的Tool鍵。

使用此頁面進行基於文件的約定。有關Tool架構、執行選項、輸出整形和批准選項，請參閱[`createTool()` reference](/reference/tools/create-tool).

## 快速入門 {/* #quickstart */}

將每個文件一個Tool放置在`tools/`. This file is exposed to the agent as `get_weather`.

```typescript title="src/mastra/agents/weather/tools/get_weather.ts"
import { createTool } from '@mastra/core/tools'
import { z } from 'zod'

export default createTool({
  id: 'get_weather',
  description: 'Get the current weather for a location.',
  inputSchema: z.object({
    location: z.string(),
  }),
  outputSchema: z.object({
    location: z.string(),
    temperatureCelsius: z.number(),
    conditions: z.string(),
  }),
  execute: async ({ location }) => {
    return { location, temperatureCelsius: 21, conditions: 'sunny' }
  },
})
```

## 整理Tool {/* #organizing-tools */}

每個Tool使用一個檔案。以模型應採取的動作命名檔案：

* 使用`get_weather.ts`, `search_docs.ts`, or `create_ticket.ts`.
* 避免模​​糊的名稱，例如`helper.ts`, `api.ts`, or `utils.ts`.
* 將測試放在Tool旁邊`*.test.ts` or `*.spec.ts`. Discovery ignores those files.
* 將共享幫助程式碼保留在外部`tools/` or in files that don't match the discovered extensions under `tools/`.

由於嵌套目錄不會被發現為Tool，因此請使用明確的檔案名稱前綴而不是子資料夾對相關Tool進行分組，例如`calendar_create_event.ts` and `calendar_list_events.ts`.

## Tool選項 {/* #tool-options */}

基於文件的約定僅控制Tool所在的位置及其註冊方式。選項來自Tool本身。對於使用以下Tool建立的Tool`createTool()`:

* 使用`description` to tell the model when to call the tool.
* 使用`inputSchema` and `outputSchema` for structured inputs and outputs.
* 使用`toModelOutput` when the model should see a different shape than the raw value returned from `execute`.
* 使用`requireApproval` when a tool needs human confirmation before execution.

請參閱[`createTool()` reference](/reference/tools/create-tool) for all options and [tool approval](/docs/harness/agent-controller#approve-tools-and-resume-suspensions) for the approval flow. Vercel AI SDK tools use the [AI SDK `tool()` API](https://ai-sdk.dev/docs/reference/ai-sdk-core/tool) instead.

## 運行時邊界 {/* #runtime-boundary */}

當Agent呼叫Tool時，Tool代碼會在您的應用程式/伺服器運行時運行。如果Tool需要檔案系統或 shell 隔離，請呼叫[workspace](/reference/file-based-agents/workspace) or sandbox APIs explicitly.

## 配置的優先權 {/* #precedence-with-config */}

發現的Tool與任何Tool合併`tools` in [`config.ts`](/reference/file-based-agents/config). On a key collision, `config.tools` wins and a warning is logged.

如果`config.tools` is a function, discovered tools are ignored with a warning because function-valued tools can't be statically merged.
