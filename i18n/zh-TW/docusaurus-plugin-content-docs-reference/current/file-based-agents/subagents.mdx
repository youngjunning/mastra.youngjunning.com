# 子Agent

基於文件的Agent可以聲明**subagents**，它委託給的專業兒童Agent。父模型將每個子Agent視為以子Agent目錄命名的委託Tool，並呼叫該Tool來移交任務。子Agent的結果回到父對話。

使用此頁面進行基於文件的約定。有關更廣泛的委託模式、掛鉤、記憶體隔離、Tool批准傳播和評分，請參閱[Supervisor agents](/docs/subagents).

## 快速入門 {/* #quickstart */}

為每個子Agent程式聲明目錄`subagents/`:

```text title="Subagent layout"
src/mastra/agents/
└── supervisor/
    ├── config.ts
    ├── instructions.md
    └── subagents/
        └── researcher/
            ├── config.ts
            ├── instructions.md
            └── tools/
                └── search.ts
```

馬斯特拉組裝`researcher` as its own agent and wires it into the supervisor's `agents` map. The parent model can delegate to it by using the generated `researcher` delegation tool.

子Agent的`config.ts` must set a non-empty `description`. The parent model reads this when deciding whether to delegate.

```typescript title="src/mastra/agents/supervisor/subagents/researcher/config.ts"
import { agentConfig } from '@mastra/core/agent'

export default agentConfig({
  model: '__GATEWAY_OPENAI_MODEL__',
  description: 'Researches a topic and returns cited findings.',
})
```

## 模型如何委託 {/* #how-the-model-delegates */}

子Agent的`description` is routing text for the parent model. Write it like a [tool description](/reference/file-based-agents/tools#tool-options): explain what the subagent does and when to delegate to it.

當發現的子Agent未提供非空描述時，建置會失敗。例外情況是父母的`config.ts` exports a `new Agent()`: its `subagents/` directory is ignored with a warning, so no description check runs. Set `agents` on the `Agent` instead.

## 隔離 {/* #isolation */}

子Agent是隔離的。子Agent程式不會繼承其父Agent的Tool、技能、工作空間、記憶體、處理器或子Agent程式。每個孩子都是獨立的Agent，有自己的目錄。

如果多個Agent應共享相同的依賴項，請在程式碼中定義它並透過每個Agent程式的配置分配它。

## 嵌套 {/* #nesting */}

子Agent可以聲明自己的`subagents/` directories, nesting up to three levels below the top-level agent. A `subagents/` directory nested deeper is ignored with a warning.

```text title="Nested subagents"
src/mastra/agents/
└── supervisor/            # depth 0
    └── subagents/
        └── researcher/    # depth 1
            └── subagents/
                └── summarizer/ # depth 2
```

## 命名規則 {/* #naming-rules */}

* 子Agent ID 與父Agent的Tool鍵之一衝突是一個建置錯誤。
* 同一父Agent程式下的重複子Agent ID 是建置錯誤。
* 如果子Agent ID 也存在於父Agent ID 中`config.agents`, the `config.agents` entry wins and logs a warning.
* 如果`config.agents` is a function, discovered subagents are ignored with a warning because they can't be statically merged.

## 例子 {/* #example */}

該主管負責協調研究和寫作流程。這`researcher` subagent owns search tools, while the `writer` subagent owns a workspace for drafting files.

```text title="Research supervisor"
src/mastra/agents/
└── research-supervisor/
    ├── config.ts
    ├── instructions.md
    └── subagents/
        ├── researcher/
        │   ├── config.ts
        │   ├── instructions.md
        │   └── tools/
        │       └── search_web.ts
        └── writer/
            ├── config.ts
            ├── instructions.md
            └── workspace/
                └── draft-template.md
```

```typescript title="src/mastra/agents/research-supervisor/config.ts"
import { agentConfig } from '@mastra/core/agent'

export default agentConfig({
  model: '__GATEWAY_OPENAI_MODEL__',
})
```

```markdown title="src/mastra/agents/research-supervisor/instructions.md"
You coordinate research and writing.

Delegate fact gathering to `researcher`. Delegate final drafting to `writer`.
```

```typescript title="src/mastra/agents/research-supervisor/subagents/researcher/config.ts"
import { agentConfig } from '@mastra/core/agent'

export default agentConfig({
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  description: 'Use to gather facts, sources, and concise research notes for a topic.',
})
```

```typescript title="src/mastra/agents/research-supervisor/subagents/writer/config.ts"
import { agentConfig } from '@mastra/core/agent'

export default agentConfig({
  model: '__GATEWAY_OPENAI_MODEL__',
  description: 'Use to turn research notes into a structured draft.',
})
```
