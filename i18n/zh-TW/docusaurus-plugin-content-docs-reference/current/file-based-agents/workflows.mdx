# Workflow

Mastra 發現專案級Workflow`.ts`和`.js`文件下`src/mastra/workflows/`。此約定的範圍不限於一個Agent：每個具有預設匯出的檔案都將成為已註冊的Workflow，並且檔案名稱將成為Workflow金鑰。

使用此頁面進行基於文件的約定。有關步驟、模式、控制流程、流程、狀態和Workflow執行，請參閱[Workflows overview](/docs/workflows/overview).

## 快速入門 {/* #quickstart */}

下創建一個文件`src/mastra/workflows/`, build the workflow with [`createWorkflow()`](/reference/workflows/workflow), and default-export it.

```typescript title="src/mastra/workflows/daily-report.ts"
import { createStep, createWorkflow } from '@mastra/core/workflows'
import { z } from 'zod'

const collectInputs = createStep({
  id: 'collect-inputs',
  inputSchema: z.object({ topic: z.string() }),
  outputSchema: z.object({ topic: z.string(), audience: z.string() }),
  execute: async ({ inputData }) => ({
    topic: inputData.topic,
    audience: 'engineering',
  }),
})

const writeSummary = createStep({
  id: 'write-summary',
  inputSchema: z.object({ topic: z.string(), audience: z.string() }),
  outputSchema: z.object({ report: z.string() }),
  execute: async ({ inputData }) => ({
    report: `Daily report about ${inputData.topic} for ${inputData.audience}.`,
  }),
})

const dailyReport = createWorkflow({
  id: 'daily-report',
  inputSchema: z.object({ topic: z.string() }),
  outputSchema: z.object({ report: z.string() }),
})
  .then(collectInputs)
  .then(writeSummary)
  .commit()

export default dailyReport
```

Mastra 將此Workflow註冊在`daily-report` key.

## 程式碼優先權 {/* #precedence-with-code */}

基於文件的Workflow與註冊的Workflow合併[`new Mastra()`](/reference/core/mastra-class). On a key collision, the code-registered workflow wins.
