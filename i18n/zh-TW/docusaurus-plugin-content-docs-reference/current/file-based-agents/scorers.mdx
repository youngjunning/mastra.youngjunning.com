# 得分手

基於文件的Agent發現[scorers](/docs/evals/overview)從它的`scorers/`目錄。使用此頁面進行基於文件的約定；使用內建記分器、自訂記分器和採樣的記分器指南。

下的每個文件`scorers/` default-exports one scorer, and the filename becomes its key. The default export is either a [`MastraScorer`](/reference/evals/create-scorer) or a `{ scorer, sampling }`入口。

## 快速入門 {/* #quickstart */}

透過將文件放置在特工的下方來添加記分員`scorers/` directory. This example uses a [custom scorer](/docs/evals/custom-scorers):

```typescript title="src/mastra/agents/weather/scorers/relevance.ts"
import { createScorer } from '@mastra/core/evals'

export default createScorer({
  id: 'relevance',
  description: 'Scores how relevant the response is',
}).generateScore(() => 1)
```

記分員已登記在`weather` agent under the key `relevance`, the same as adding it to `config.scorers`.

## 取樣 {/* #sampling */}

若要控制得分手的跑動頻率，請預設匯出`{ scorer, sampling }` entry instead of a bare scorer:

```typescript title="src/mastra/agents/weather/scorers/relevance.ts"
import { createScorer } from '@mastra/core/evals'

const relevance = createScorer({
  id: 'relevance',
  description: 'Scores how relevant the response is',
}).generateScore(() => 1)

export default {
  scorer: relevance,
  sampling: { type: 'ratio', rate: 0.5 },
}
```

## 配置的優先權 {/* #precedence-with-config */}

發現的記分器將與中定義的記分器合併[`config.ts`](/reference/file-based-agents/config). On a key collision, `config.scorers` wins with a warning. If `config.scorers` is a function, discovered scorers are ignored with a warning because function-valued scorers can't be statically merged.

當按鍵衝突時，優先順序是：

1. 功能價值`config.scorers`
2. 創紀錄的價值`config.scorers`
3. 發現以下文件`scorers/`

已發現的非碰撞記分器將保留。

訪問[`createScorer()`](/reference/evals/create-scorer) for the full scorer interface.
