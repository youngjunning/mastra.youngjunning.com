# 記憶

基於文件的Agent得到[memory](/docs/memory/overview)從一個`memory.ts`預設導出的文件[`Memory`](/reference/memory/memory-class)實例。使用此頁面進行基於文件的約定；使用記憶體文件進行訊息歷史記錄、語意回憶、儲存和處理器。

沒有`memory.ts` or `config.memory`, the agent has no memory by default. Each `generate()` or `stream()`通話開始時不會記住對話狀態，除非您自己傳遞先前的上下文。

## 快速入門 {/* #quickstart */}

創造`memory.ts` next to the agent's `config.ts`:

```typescript title="src/mastra/agents/weather/memory.ts"
import { Memory } from '@mastra/memory'

export default new Memory()
```

導出的實例成為Agent的實例`memory`. If your app configures a storage provider on the main Mastra instance, memory data is stored there. See [storage](/docs/storage) for more information.

使用相同的`resource` and `thread` values when calling the agent to continue a conversation:

```typescript title="src/app/weather-chat.ts"
const response = await weatherAgent.generate('Remember that I prefer Celsius.', {
  memory: {
    resource: 'user-123',
    thread: 'weather-chat',
  },
})
```

## 配置記憶體 {/* #configure-memory */}

將選項傳遞給`new Memory()` when the default behavior isn't enough.

```typescript title="src/mastra/agents/weather/memory.ts"
import { Memory } from '@mastra/memory'

export default new Memory({
  options: {
    lastMessages: 20,
    workingMemory: {
      enabled: true,
      scope: 'resource',
    },
  },
})
```

參觀[`Memory` reference](/reference/memory/memory-class) for constructor options. Use these pages for related memory features:

* [貯存](/docs/storage)：配置記憶體資料的持久化。
* [語意回憶](/docs/memory/semantic-recall)：透過語意檢索相關的過去訊息。
* [記憶體處理器](/docs/memory/memory-processors)：在記憶體將訊息新增至模型上下文之前過濾、修剪或轉換訊息。

## 配置的優先權 {/* #precedence-with-config */}

`config.memory`戰勝`memory.ts`. If neither is present, the assembled file-based agent has no memory. See [`config.ts` precedence](/reference/file-based-agents/config#precedence) for the full merge table.
