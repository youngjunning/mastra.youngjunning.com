# mountAgentControllerOnMastra()

`mountAgentControllerOnMastra()` 會建構 Mastra Code 的 Agent 控制器（即 [Mastra Code](https://code.mastra.ai) 背後的程式碼 Agent，包含模式、工具、記憶和執行緒管理），並將它註冊到由伺服器管理的 [Mastra](/reference/core/mastra-class) 執行個體。你可以用它向自己的 UI（網頁應用程式、編輯器或機器人）提供 Mastra Code Agent；每個用戶端透過回傳的 [`AgentController`](/reference/agent-controller/agent-controller-class) 建立或恢復獨立工作階段。

若要自行建構 `Mastra` 執行個體（例如在可部署的進入點檔案中），請使用同一套件的 `prepareAgentControllerMount()`；它會回傳建構參數及 `finalize()` 回呼。

## 使用範例 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { mountAgentControllerOnMastra } from '@mastra/code-sdk'

const { mastra, controller } = await mountAgentControllerOnMastra({
  cwd: process.cwd(),
})

// Each client drives its own session
const session = await controller.createSession({ resourceId: 'user-123' })
```

## 提交署名 {/* #commit-attribution */}

使用 `coAuthor` 設定程式碼 Agent 提交指引中的 `Co-Authored-By` 尾註：

```typescript title="src/mastra/index.ts"
const { mastra, controller } = await mountAgentControllerOnMastra({
  cwd: process.cwd(),
  coAuthor: {
    name: 'my-coding-app',
    email: 'my-coding-app@example.com',
  },
})
```

兩個欄位都可省略。省略時使用 SDK 預設值：名稱為 `mastra-platform[bot]`，電子郵件為 `284800079+mastra-platform[bot]@users.noreply.github.com`。

`mastracode` 終端應用程式將名稱設為 `mastracode`，Factory 則設為 `mastra-platform[bot]`。兩者使用相同的預設電子郵件，因此 GitHub 會將尾註解析為同一個機器人帳號，而原始提交訊息仍保留應用程式名稱。

傳入現有的 `mastra`，即可將控制器掛載到已承載其他元件的 Mastra 執行個體：

```typescript
import { Mastra } from '@mastra/core/mastra'
import { mountAgentControllerOnMastra } from '@mastra/code-sdk'

const mastra = new Mastra({/* ... */})

const { controller } = await mountAgentControllerOnMastra({ mastra })
```

## 外掛中的巢狀控制器 {/* #nested-controllers-in-plugins */}

如果外掛在同一程序中啟動另一個控制器，必須借用主機的儲存空間，不能用自己的原生 SQLite 程式庫再次開啟相同的資料庫檔案。

### `context.getStorage()` {/* #contextgetstorage */}

`MastraCodePluginContext` 上這個可選的存取方法會回傳主機的 `storage`（`MastraCompositeStore`）、`storageBackend`（`'libsql' | 'pg'`）和可選的 `vector`（`MastraVector`）。請在工具執行時呼叫它，再將回傳的物件傳給 `bootLocalAgentController()`：

```typescript
import { bootLocalAgentController } from '@mastra/code-sdk'
import type { MastraCodePluginContext } from '@mastra/code-sdk/plugin'

async function bootNestedController(context: MastraCodePluginContext) {
  const sharedStorage = context.getStorage?.()
  if (!sharedStorage) {
    throw new Error('This plugin requires host-provided shared storage.')
  }
  return bootLocalAgentController({ cwd: context.cwd, ...sharedStorage })
}
```

這些執行個體由主機持有。使用完畢後，請停止巢狀控制器的 worker 並銷毀其控制器，但不要關閉借用的儲存空間，也不要呼叫它的儲存維護方法。如果舊版主機未提供存取方法，不要改為再次開啟相同的資料庫檔案。
