# mountAgentControllerOnMastra()

這`mountAgentControllerOnMastra()`函數建構Mastra CodeAgent控制器（背後的編碼Agent[馬斯特拉代碼](https://code.mastra.ai)，及其模式、Tool、記憶體和線程管理）並將其註冊到伺服器擁有的[馬斯特拉](/reference/core/mastra-class)實例。使用它為您自己的 UI（Web 應用程式、編輯器、機器人）提供 Mastra Code Agent服務：每個客戶端透過傳回的傳回值來建立或恢復自己的隔離會話[`AgentController`](/reference/agent-controller/agent-controller-class).

建構`Mastra` instance yourself (for example in a deployable entry file), use `prepareAgentControllerMount()` from the same package, which returns the constructor args plus a `finalize()` callback.

## 使用範例 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { mountAgentControllerOnMastra } from '@mastra/code-sdk'

const { mastra, controller } = await mountAgentControllerOnMastra({
  cwd: process.cwd(),
})

// Each client drives its own session
const session = await controller.createSession({ resourceId: 'user-123' })
```

## 提交歸因 {/* #commit-attribution */}

使用`coAuthor` to set the `Co-Authored-By` trailer in coding-agent commit guidance:

```typescript title="src/mastra/index.ts"
const { mastra, controller } = await mountAgentControllerOnMastra({
  cwd: process.cwd(),
  coAuthor: {
    name: 'my-coding-app',
    email: 'my-coding-app@example.com',
  },
})
```

這兩個欄位都是可選的。省略的欄位使用 SDK 預設值：`mastra-platform[bot]` for the name and `284800079+mastra-platform[bot]@users.noreply.github.com` for the email.

這`mastracode` terminal app sets its name to `mastracode`, and Factory sets its name to `mastra-platform[bot]`. Both use the same default email, so GitHub resolves their trailers to the same bot account while the raw commit message retains the app name.

透過現有的`mastra` to mount the controller onto a Mastra instance that already hosts other primitives:

```typescript
import { Mastra } from '@mastra/core/mastra'
import { mountAgentControllerOnMastra } from '@mastra/code-sdk'

const mastra = new Mastra({/* ... */})

const { controller } = await mountAgentControllerOnMastra({ mastra })
```

## 插件中的嵌套控制器 {/* #nested-controllers-in-plugins */}

在同一進程中啟動另一個控制器的插件必須借用主機的存儲，而不是使用自己的本機 SQLite 庫開啟相同的資料庫檔案。

### `context.getStorage()` {/* #contextgetstorage */}

可選的存取器`MastraCodePluginContext` returns the host's `storage` (`MastraCompositeStore`), `storageBackend` (`'libsql' | 'pg'`), and optional `vector` (`MastraVector`). Call it when the tool runs, then pass the returned object to `bootLocalAgentController()`:

```typescript
import { bootLocalAgentController } from '@mastra/code-sdk'
import type { MastraCodePluginContext } from '@mastra/code-sdk/plugin'

async function bootNestedController(context: MastraCodePluginContext) {
  const sharedStorage = context.getStorage?.()
  if (!sharedStorage) {
    throw new Error('This plugin requires host-provided shared storage.')
  }
  return bootLocalAgentController({ cwd: context.cwd, ...sharedStorage })
}
```

主機擁有這些實例。停止嵌套控制器的工作執行緒並在完成後銷毀其控制器，但不要關閉借用的儲存或呼叫其儲存維護方法。如果存取器在較舊的主機上不可用，請不要回退到開啟相同的資料庫檔案。
