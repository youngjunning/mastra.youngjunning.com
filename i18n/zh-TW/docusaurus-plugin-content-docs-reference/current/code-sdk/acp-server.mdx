# ACP伺服器

Mastra Code 透過Agent客戶端協定 (ACP) 提供編碼Agent對話服務。 ACP 用戶端將伺服器作為子進程啟動，並透過標準輸入和輸出交換換行符號分隔的 JSON-RPC 訊息。標準錯誤帶有診斷訊息。

該伺服器將編輯器或其他 ACP 用戶端連接到 Mastra Code。若要將 Mastra Agent連接到外部 ACP 伺服器，請使用[ACP connection](/docs/connections/acp).

## 啟動伺服器 {/* #start-the-server */}

隨著`mastracode` CLI installed, configure your client to launch:

```bash
mastracode --acp
```

接受命令和參數欄位的客戶端可以使用：

```json
{
  "command": "mastracode",
  "args": ["--acp"]
}
```

初始化後，客戶端調用`session/new` with an absolute `cwd` and an `mcpServers` array. The response includes the session ID and configuration choices. Send that ID with subsequent prompts and configuration requests.

## 驗證 {/* #authentication */}

`session/new`返回一個`auth_required` error when no model provider is configured, so clients can offer the methods from the `initialize` response:

|方法 ID |類型 |行為 |
| - | - | - |
|`openai-codex` | Agent | Opens the browser to sign in with a ChatGPT Plus or Pro subscription. |
| `kimi-for-coding` | Agent | Opens the browser to approve a Kimi For Coding device sign-in. |
| `xai` | Agent | Opens the browser to approve an xAI device sign-in. |
| `anthropic` | Terminal | Runs `mastracode login --provider anthropic`使用 Claude Pro 或 Max 訂閱登入。 |
|`github-copilot`|終端|跑步`mastracode login --provider github-copilot`使用 GitHub Copilot 登入。 |
|`mastracode-login`|終端|跑步`mastracode login`選擇任何Provider或儲存 API 金鑰。 |

終端方法僅提供給通告終端機驗證的用戶端。

對於Agent方法，`authenticate` runs the sign-in inside the server process and returns after the credentials are saved. If a provider needs typed input, such as a code to paste, the request fails and asks you to run `mastracode login` in a terminal.

伺服器進程環境中的 API 金鑰也算是已配置的Provider。 ACP 會話不載入項目`.env` files into the shared process environment. New sessions pick up saved credentials without restarting the server. When the default model's provider isn't configured, a new session starts on the default model of a provider that is, such as `anthropic/claude-fable-5` after an Anthropic sign-in.

## 會話和 MCP 伺服器 {/* #sessions-and-mcp-servers */}

每個會話都有自己的運行時和工作目錄。伺服器使用 stdio 或 HTTP 連接客戶端提供的模型上下文協定 (MCP) 伺服器。舊版 SSE 伺服器不受支援並傳回無效參數錯誤。 Stdio 程序接收會話的工作目錄和提供的環境變數。 HTTP 連線接收提供的標頭。重複的伺服器名稱和失敗的客戶端-伺服器初始化回傳錯誤。

提示和配置變更在會話中按順序運行。不同的會話可以同時運行。`session/cancel` stops the requested session's active turn and cancels its queued prompts.

## 模型和推理控制 {/* #model-and-reasoning-controls */}

這`session/new` response exposes `configOptions` for models, modes, and reasoning effort. Use values from the returned choices with `session/set_config_option`:

```typescript
await connection.setSessionConfigOption({
  sessionId,
  configId: 'thought_level',
  value: 'high',
})
```

模型選擇保留其完整的Provider路由 ID，並忽略沒有配置憑證的Provider。即使發現未傳回會話的已儲存模型，該模型仍然可用。模式和模型變更等待目前回合完成。

推理選擇遵循所選模型的策略。Provider可以調整所要求的等級。每個會話在啟動時都會讀取一次預設設定。模式變更和顯式推理選擇仍然有效。啟動一個新會話以取得對設定檔的編輯。

遺產`session/set_mode` and `session/set_model` requests are also supported.

## 技能指令 {/* #skill-commands */}

之後`session/new` response, the server advertises workspace skills through `available_commands_update`. Clients can offer `/skill/<name>` completions before the first prompt. The server refreshes the list before subsequent prompts and sends an update when it changes.

以文字提示形式發送命令，後面接著可選說明：

```typescript
await connection.prompt({
  sessionId,
  prompt: [{ type: 'text', text: '/skill/review Check the current changes' }],
})
```

伺服器將技能的說明和資源清單新增至回合。它使用 Mastra Code 的專案和全域技能目錄。重複名稱選擇Workspace目錄順序中的第一個使用者可呼叫檔案。技能標記`user-invocable: false` are hidden and rejected when explicitly invoked. Missing skills return an invalid-parameters error without starting inference.

終端命令如`/goal` aren't exposed as ACP commands.

## 權限和錯誤 {/* #permissions-and-errors */}

預設情況下，Tool批准和沙箱存取請求通過客戶端的權限 UI。被拒絕的Tool不會執行。取消掛起的權限請求會記錄中止先前的拒絕，因此稍後的回合不會重播該要求。不支援自由文字Tool問題。這`ask_user` tool is disabled.

輔助塊包含輔助輸出。使用者提示和內部系統訊號不會作為助理回復發出。Provider失敗回傳 JSON-RPC 錯誤。代幣限制回報`max_tokens`, content-filter refusals return `refusal`, and cancellation returns `cancelled`.

## 支援的協定設定檔 {/* #supported-protocol-profile */}

伺服器支援 ACP v1 初始化、新會話、文字提示、文字資源、助手和Tool更新、權限、取消、設定和命令發現。它不會通告會話載入。影像、音訊和二進位資源提示傳回無效參數錯誤。

儲存庫的 ACP 一致性閘根據固定的上游模式驗證訊息，並使用本機模型和 MCP 裝置來測試建置的 SDK。這些檢查涵蓋了已實施的設定檔。它們不是上游認證、每個可選 ACP 功能的保證，也不是在客戶端中測試即時Provider身份驗證的替代品。
