# ArthurExporter

使用 OpenTelemetry 與 OpenInference 語意慣例，將 Tracing 資料傳送至 [Arthur Engine](https://github.com/arthur-ai/arthur-engine)。

## 建構函式 {/* #constructor */}

```typescript oxfmt:false
new ArthurExporter(config: ArthurExporterConfig)
```

## `ArthurExporterConfig` {/* #arthurexporterconfig */}

```typescript
type ArthurExporterConfig = Omit<OtelExporterConfig, 'provider' | 'exporter'> & {
  apiKey?: string
  endpoint?: string
  taskId?: string
  headers?: Record<string, string>
}
```

繼承 `OtelExporterConfig` 中除了 `provider` 與 `exporter` 以外的設定項目，包括：

- `timeout?: number` - 匯出逾時時間，單位為毫秒（預設值：30000）
- `batchSize?: number` - 每批的 Span 數量（預設值：512）
- `logLevel?: LogLevel | 'debug' | 'info' | 'warn' | 'error'` - 記錄器層級（預設值：WARN）
- `resourceAttributes?: Record<string, any>` - 自訂資源屬性

### 中繼資料透傳 {/* #metadata-passthrough */}

非保留的 Span 屬性會序列化至 OpenInference 的 `metadata` 酬載。可透過 `tracingOptions.metadata` 加入這些屬性（例如 `companyId`、`tier`）。`input`、`output`、`sessionId`、執行緒與使用者 ID，以及 OpenInference ID 等保留欄位會自動排除。

## 方法 {/* #methods */}

### `exportTracingEvent` {/* #exporttracingevent */}

```typescript oxfmt:false
async exportTracingEvent(event: TracingEvent): Promise<void>
```

將 Tracing 事件匯出至已設定的端點。

### export {/* #export */}

```typescript oxfmt:false
async export(spans: ReadOnlySpan[]): Promise<void>
```

使用 OpenTelemetry 分批匯出 Span，並遵循 OpenInference 語意慣例。

### flush {/* #flush */}

```typescript oxfmt:false
async flush(): Promise<void>
```

立即將緩衝區中的所有 Span 匯出至已設定的端點，同時維持匯出器運作。適用於無伺服器環境，可確保執行階段結束前完成匯出。

### shutdown {/* #shutdown */}

```typescript oxfmt:false
async shutdown(): Promise<void>
```

清空待處理資料並關閉用戶端。

## 使用方式 {/* #usage */}

### 零設定（使用環境變數） {/* #zero-config-using-environment-variables */}

```typescript
import { ArthurExporter } from '@mastra/arthur'

// Set ARTHUR_API_KEY and ARTHUR_BASE_URL (optionally ARTHUR_TASK_ID)
const exporter = new ArthurExporter()
```

### 明確設定 {/* #explicit-configuration */}

```typescript
import { ArthurExporter } from '@mastra/arthur'

const exporter = new ArthurExporter({
  apiKey: process.env.ARTHUR_API_KEY!,
  endpoint: 'http://localhost:3030',
  taskId: process.env.ARTHUR_TASK_ID, // Optional
})
```

## `OpenInference` 語意慣例 {/* #openinference-semantic-conventions */}

ArthurExporter 實作適用於生成式 AI 應用程式的 [OpenInference 語意慣例](https://github.com/Arize-ai/openinference/tree/main/spec)，為不同可觀測性平台提供標準化的 Trace 結構。

## 標籤支援 {/* #tags-support */}

ArthurExporter 支援以標籤分類及篩選 Trace。標籤只會套用至根 Span，並對應到 OpenInference 原生的 `tag.tags` 語意慣例。

### 使用方式 {/* #usage-1 */}

```typescript
const result = await agent.generate('Hello', {
  tracingOptions: {
    tags: ['production', 'experiment-v2', 'user-request'],
  },
})
```

### 標籤的儲存方式 {/* #how-tags-are-stored */}

標籤儲存在 OpenInference 的 `tag.tags` 屬性中：

```json
{
  "tag.tags": ["production", "experiment-v2", "user-request"]
}
```
