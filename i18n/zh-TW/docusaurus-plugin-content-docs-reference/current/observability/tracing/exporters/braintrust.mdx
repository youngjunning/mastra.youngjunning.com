# BraintrustExporter

將 Tracing 資料傳送至 Braintrust，用於評估與可觀測性。

## 建構函式 {/* #constructor */}

```typescript oxfmt:false
new BraintrustExporter(config: BraintrustExporterConfig)
```

## `BraintrustExporterConfig` {/* #braintrustexporterconfig */}

```typescript
interface BraintrustExporterConfig extends BaseExporterConfig {
  apiKey?: string
  endpoint?: string
  projectName?: string
  braintrustLogger?: Logger<true>
  currentSpan?: () => Span | undefined
  tuningParameters?: Record<string, any>
}
```

繼承 `BaseExporterConfig`，其中包含：

- `logger?: IMastraLogger` - 日誌記錄器實例
- `logLevel?: LogLevel | 'debug' | 'info' | 'warn' | 'error'` - 日誌等級（預設：INFO）

## 方法 {/* #methods */}

### `exportTracingEvent` {/* #exporttracingevent */}

```typescript oxfmt:false
async exportTracingEvent(event: TracingEvent): Promise<void>
```

將追蹤事件匯出至 Braintrust。

### export {/* #export */}

```typescript oxfmt:false
async export(spans: ReadOnlySpan[]): Promise<void>
```

批次將 Span 匯出至 Braintrust。

### flush {/* #flush */}

```typescript oxfmt:false
async flush(): Promise<void>
```

強制將緩衝中的所有 Span 傳送至 Braintrust，而不關閉匯出器。適用於需要在執行環境終止前確認 Span 已匯出的無伺服器環境。

### shutdown {/* #shutdown */}

```typescript oxfmt:false
async shutdown(): Promise<void>
```

傳送待處理資料並關閉用戶端。

## 用法 {/* #usage */}

### 零設定（使用環境變數） {/* #zero-config-using-environment-variables */}

```typescript
import { BraintrustExporter } from '@mastra/braintrust'

// Reads from BRAINTRUST_API_KEY, BRAINTRUST_ENDPOINT
const exporter = new BraintrustExporter()
```

### 明確設定 {/* #explicit-configuration */}

```typescript
import { BraintrustExporter } from '@mastra/braintrust'

const exporter = new BraintrustExporter({
  apiKey: process.env.BRAINTRUST_API_KEY,
  projectName: 'my-ai-project',
})
```

## Span 類型對應 {/* #span-type-mapping */}

| Span 類型 | Braintrust 類型 |
| - | - |
| `MODEL_GENERATION` | `llm` |
| `MODEL_CHUNK` | `llm` |
| `TOOL_CALL` | `tool` |
| `MCP_TOOL_CALL` | `tool` |
| `PROVIDER_TOOL_CALL` | `tool` |
| `WORKFLOW_CONDITIONAL_EVAL` | `function` |
| `WORKFLOW_WAIT_EVENT` | `function` |
| 其他所有類型 | `task` |

## 成本追蹤 {/* #cost-tracking */}

若 Span 設有 `metrics.estimated_cost`，Braintrust 會將其視為成本；否則會根據 Token 用量指標及自身的模型價格估算成本。只有模型生成的成本中繼資料同時符合以下條件時，匯出器才會為該 Span 設定 `metrics.estimated_cost`：

- `costContext.costMetadata.source` 為 `'provider_reported'`，表示成本由模型供應商回報，例如 OpenRouter 和 Vercel AI Gateway。
- `costContext.costUnit` 為 `'USD'`。
- `costContext.estimatedCost` 是大於 `0` 的有限數。

Mastra 自行估算的成本不會匯出，因此 Braintrust 會依自身的模型價格為這些 Span 估價。供應商回報的成本為 `0` 時也會略過。Vercel AI Gateway 對自備金鑰的請求回報 `0`，但模型供應商仍會收費，此時 Braintrust 的估算更接近實際費用。無論哪種情況，Span 中繼資料都會保留完整的 `costContext`。
