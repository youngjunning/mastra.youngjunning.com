# 智囊團出口商

將追蹤資料傳送到 Braintrust 進行評估和可觀察。

## 建構函數 {/* #constructor */}

```typescript oxfmt:false
new BraintrustExporter(config: BraintrustExporterConfig)
```

## `BraintrustExporterConfig` {/* #braintrustexporterconfig */}

```typescript
interface BraintrustExporterConfig extends BaseExporterConfig {
  apiKey?: string
  endpoint?: string
  projectName?: string
  braintrustLogger?: Logger<true>
  currentSpan?: () => Span | undefined
  tuningParameters?: Record<string, any>
}
```

延伸`BaseExporterConfig`, which includes:

* `logger?: IMastraLogger`- 記錄器實例
* `logLevel?: LogLevel | 'debug' | 'info' | 'warn' | 'error'`- 日誌等級（預設：INFO）

## 方法 {/* #methods */}

### `exportTracingEvent` {/* #exporttracingevent */}

```typescript oxfmt:false
async exportTracingEvent(event: TracingEvent): Promise<void>
```

將追蹤事件匯出到 Braintrust。

### 出口 {/* #export */}

```typescript oxfmt:false
async export(spans: ReadOnlySpan[]): Promise<void>
```

批次匯出到 Braintrust。

### 沖水 {/* #flush */}

```typescript oxfmt:false
async flush(): Promise<void>
```

強制將所有緩衝跨度刷新到 Braintrust，而無需關閉導出器。在無伺服器環境中很有用，您需要確保在執行時間終止之前導出跨度。

### 關閉 {/* #shutdown */}

```typescript oxfmt:false
async shutdown(): Promise<void>
```

刷新待處理資料並關閉客戶端。

## 用法 {/* #usage */}

### 零配置（使用環境變數） {/* #zero-config-using-environment-variables */}

```typescript
import { BraintrustExporter } from '@mastra/braintrust'

// Reads from BRAINTRUST_API_KEY, BRAINTRUST_ENDPOINT
const exporter = new BraintrustExporter()
```

### 明確配置 {/* #explicit-configuration */}

```typescript
import { BraintrustExporter } from '@mastra/braintrust'

const exporter = new BraintrustExporter({
  apiKey: process.env.BRAINTRUST_API_KEY,
  projectName: 'my-ai-project',
})
```

## 成本追蹤 {/* #cost-tracking */}

智囊團使用跨度`metrics.estimated_cost` as its cost when the field is set, and estimates the cost from token metrics and its own model prices when it isn't. The exporter sets `metrics.estimated_cost` on a model generation span only when the generation's cost metadata meets every condition:

* `costContext.costMetadata.source`是`'provider_reported'`, meaning the model provider returned the cost, as OpenRouter and Vercel AI Gateway do.
* `costContext.costUnit`是`'USD'`.
* `costContext.estimatedCost`是一個大於的有限數`0`.

Mastra 自己的成本估算不會導出，因此 Braintrust 以其模型價格對這些跨度進行定價。報告的成本為`0` is skipped as well. Vercel AI Gateway reports `0` for bring-your-own-key requests, which your model provider still bills, and Braintrust's estimate is closer to that charge. The span metadata keeps the full `costContext` in every case.
