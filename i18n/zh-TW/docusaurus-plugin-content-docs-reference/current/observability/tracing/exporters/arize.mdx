# 阿里茲出口商

將追蹤資料傳送到 Arize Phoenix 或 Arize AX，以及任何支援 OpenInference 語意約定的相容 OpenTelemetry 的可觀察性平台。

## 建構函數 {/* #constructor */}

```typescript oxfmt:false
new ArizeExporter(config: ArizeExporterConfig)
```

## `ArizeExporterConfig` {/* #arizeexporterconfig */}

```typescript
type ArizeExporterConfig = Omit<OtelExporterConfig, 'provider'> & {
  // Phoenix / OpenTelemetry configuration
  endpoint?: string
  apiKey?: string

  // Arize AX configuration
  spaceId?: string

  // Common configuration
  projectName?: string
  headers?: Record<string, string>
}
```

繼承自`OtelExporterConfig` (excluding `provider`），其中包括：

* `timeout?: number`- 匯出超時以毫秒為單位（預設值：30000）
* `batchSize?: number`- 每批的跨度數（預設值：512）
* `logLevel?: LogLevel | 'debug' | 'info' | 'warn' | 'error'`- 日誌等級（預設：警告）
* `resourceAttributes?: Record<string, any>`- 自訂資源屬性

### 元資料透傳 {/* #metadata-passthrough */}

非保留的跨距屬性被序列化到 OpenInference 中`metadata` payload. Add them via `tracingOptions.metadata` (e.g., `companyId`, `tier`). Reserved fields such as `input`, `output`, `sessionId`、執行緒/使用者 ID 和 OpenInference ID 會自動排除。

## 方法 {/* #methods */}

### `exportTracingEvent` {/* #exporttracingevent */}

```typescript oxfmt:false
async exportTracingEvent(event: TracingEvent): Promise<void>
```

將追蹤事件匯出到配置的端點。

### 出口 {/* #export */}

```typescript oxfmt:false
async export(spans: ReadOnlySpan[]): Promise<void>
```

使用 OpenTelemetry 和 OpenInference 語意約定進行批次匯出。

### 沖水 {/* #flush */}

```typescript oxfmt:false
async flush(): Promise<void>
```

強制將任何緩衝的跨度刷新到配置的端點，而不關閉導出器。在無伺服器環境中很有用，您需要確保在執行時間終止之前導出跨度。

### 關閉 {/* #shutdown */}

```typescript oxfmt:false
async shutdown(): Promise<void>
```

刷新待處理資料並關閉客戶端。

## 用法 {/* #usage */}

### 零配置（使用環境變數） {/* #zero-config-using-environment-variables */}

```typescript
import { ArizeExporter } from '@mastra/arize'

// For Phoenix: Set PHOENIX_COLLECTOR_ENDPOINT, PHOENIX_API_KEY, PHOENIX_PROJECT_NAME
// For Arize AX: Set ARIZE_SPACE_ID, ARIZE_API_KEY, ARIZE_PROJECT_NAME
const exporter = new ArizeExporter()
```

### 鳳凰配置 {/* #phoenix-configuration */}

```typescript
import { ArizeExporter } from '@mastra/arize'

const exporter = new ArizeExporter({
  endpoint: 'http://localhost:6006/v1/traces',
  apiKey: process.env.PHOENIX_API_KEY, // Optional for local Phoenix
  projectName: 'my-ai-project',
})
```

### Arize AX 配置 {/* #arize-ax-configuration */}

```typescript
import { ArizeExporter } from '@mastra/arize'

const exporter = new ArizeExporter({
  spaceId: process.env.ARIZE_SPACE_ID!,
  apiKey: process.env.ARIZE_API_KEY!,
  projectName: 'my-ai-project',
})
```

## `OpenInference`語意約定 {/* #openinference-semantic-conventions */}

ArizeExporter 實現[OpenInference Semantic Conventions](https://github.com/Arize-ai/openinference/tree/main/spec) for generative AI applications, providing standardized trace structure across different observability platforms.

## 標籤支援 {/* #tags-support */}

ArizeExporter 支援追蹤標記以進行分類和過濾。標籤僅應用於根跨距並映射到本機 OpenInference`tag.tags` semantic convention.

### 用法 {/* #usage-1 */}

```typescript
const result = await agent.generate('Hello', {
  tracingOptions: {
    tags: ['production', 'experiment-v2', 'user-request'],
  },
})
```

### 標籤如何存儲 {/* #how-tags-are-stored */}

使用 OpenInference 儲存標籤`tag.tags` attribute:

```json
{
  "tag.tags": ["production", "experiment-v2", "user-request"]
}
```
