# 數據狗導出器

將追蹤資料傳送到 Datadog 的 LLM Observability 產品以進行監控和分析。

:::注意
如果你也使用`dd-trace` APM auto-instrumentation and need it correctly parented under Mastra spans, use the [數據狗橋](/reference/observability/tracing/bridges/datadog)反而。導出器在執行完成後發送LLM Observability數據，因此它不參與`dd-trace`的直播範圍。
:::

## 建構函數 {/* #constructor */}

```typescript oxfmt:false
new DatadogExporter(config: DatadogExporterConfig)
```

## 方法 {/* #methods */}

### `exportTracingEvent` {/* #exporttracingevent */}

```typescript oxfmt:false
async exportTracingEvent(event: TracingEvent): Promise<void>
```

將追蹤事件匯出到 Datadog LLM Observability。

### 沖水 {/* #flush */}

```typescript oxfmt:false
async flush(): Promise<void>
```

強制將任何緩衝的跨度刷新到 Datadog，而不關閉導出器。在無伺服器環境中很有用，您需要確保在執行時間終止之前導出跨度。

刷新是盡力而為：dd-trace 從後台編寫器發送 LLM Observability數據，並且無法等待請求，因此`flush()` waits `flushGraceMs` (default 2000 ms) after asking dd-trace to flush. Each flush that sent new data costs that full wait, so a serverless handler that awaits `flush()` per request pays it per request. Raise it if spans from short-lived processes are missing in Datadog, or set it to `0` to skip the wait when something else keeps the process alive.

### 關閉 {/* #shutdown */}

```typescript oxfmt:false
async shutdown(): Promise<void>
```

刷新待處理資料並關閉導出器。取消任何掛起的清理計時器並停用 LLM 可觀察性。

## 用法 {/* #usage */}

### 零配置（使用環境變數） {/* #zero-config-using-environment-variables */}

```typescript
import { DatadogExporter } from '@mastra/datadog'

// Reads from DD_LLMOBS_ML_APP, DD_API_KEY, DD_SITE, DD_ENV
const exporter = new DatadogExporter()
```

### 明確配置 {/* #explicit-configuration */}

```typescript
import { DatadogExporter } from '@mastra/datadog'

const exporter = new DatadogExporter({
  mlApp: 'my-llm-app',
  apiKey: process.env.DD_API_KEY,
  site: 'datadoghq.com',
  env: 'production',
})
```

### 使用本地 Datadog Agent {/* #with-local-datadog-agent */}

```typescript
const exporter = new DatadogExporter({
  mlApp: 'my-llm-app',
  agentless: false, // Use local Datadog Agent
  env: 'production',
})
```

## 跨距映射 {/* #span-mapping */}

Mastra 跨距類型對應到 Datadog LLM Observability跨距類型：

|馬斯特拉 SpanType |資料狗種類 |
| - | - |
|`AGENT_RUN` | `agent` |
| `MODEL_GENERATION` | `workflow` |
| `MODEL_STEP` | `llm` |
| `TOOL_CALL` | `tool` |
| `MCP_TOOL_CALL` | `tool` |
| `PROVIDER_TOOL_CALL` | `tool` |
| `WORKFLOW_RUN` | `workflow`|
|所有其他類型 |`task` |

所有未映射的跨度類型（包括`MODEL_CHUNK`, `WORKFLOW_STEP`, `GENERIC`, and future span types) automatically default to `task`.

## 環境變數 {/* #environment-variables */}

導出器從這些環境變數中讀取配置：

|變數|描述 |
| - | - |
|`DD_API_KEY` | Datadog API key |
| `DD_LLMOBS_ML_APP` | ML application name |
| `DD_SITE` | Datadog site |
| `DD_ENV` | Environment name |
| `DD_LLMOBS_AGENTLESS_ENABLED` | Set to 'false' or '0' to use local agent |
