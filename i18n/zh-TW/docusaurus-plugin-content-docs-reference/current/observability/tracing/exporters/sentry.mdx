# 哨兵導出器

使用 OpenTelemetry 語意約定將追蹤資料傳送到 Sentry 以進行 AI 追蹤和監控。

## 建構函數 {/* #constructor */}

```typescript oxfmt:false
new SentryExporter(config: SentryExporterConfig)
```

## `SentryExporterConfig` {/* #sentryexporterconfig */}

```typescript
interface SentryExporterConfig extends BaseExporterConfig {
  dsn?: string
  environment?: string
  tracesSampleRate?: number
  release?: string
  options?: Partial<Sentry.NodeOptions>
}
```

延伸`BaseExporterConfig`, which includes:

* `logger?: IMastraLogger`- 記錄器實例
* `logLevel?: LogLevel | 'debug' | 'info' | 'warn' | 'error'`- 日誌等級（預設：INFO）

## 方法 {/* #methods */}

### `exportTracingEvent` {/* #exporttracingevent */}

```typescript oxfmt:false
async exportTracingEvent(event: TracingEvent): Promise<void>
```

將追蹤事件匯出到 Sentry。處理 SPAN\_STARTED、SPAN\_UPDATED 和 SPAN\_ENDED 事件。

### 沖水 {/* #flush */}

```typescript oxfmt:false
async flush(): Promise<void>
```

強制將任何掛起的跨距刷新到 Sentry，而不關閉匯出器。等待最多 2 秒以發送待處理的資料。在無伺服器環境中很有用，您需要確保在執行時間終止之前導出跨度。

### 關閉 {/* #shutdown */}

```typescript oxfmt:false
async shutdown(): Promise<void>
```

在關閉 Sentry 連線之前結束所有活動範圍並清除內部狀態。等待最多 2 秒以發送待處理的資料。

## 用法 {/* #usage */}

### 零配置（使用環境變數） {/* #zero-config-using-environment-variables */}

```typescript
import { SentryExporter } from '@mastra/sentry'

// Reads from SENTRY_DSN, SENTRY_ENVIRONMENT, SENTRY_RELEASE
const exporter = new SentryExporter()
```

### 明確配置 {/* #explicit-configuration */}

```typescript
import { SentryExporter } from '@mastra/sentry'

const exporter = new SentryExporter({
  dsn: process.env.SENTRY_DSN,
  environment: 'production',
  tracesSampleRate: 1.0,
  release: '1.0.0',
})
```

### 帶採樣 {/* #with-sampling */}

```typescript
const exporter = new SentryExporter({
  dsn: process.env.SENTRY_DSN,
  environment: 'production',
  tracesSampleRate: 0.1, // Send 10% of transactions to Sentry (recommended for high-load backends)
})
```

### 使用自訂哨兵選項 {/* #with-custom-sentry-options */}

```typescript
const exporter = new SentryExporter({
  dsn: process.env.SENTRY_DSN,
  environment: 'production',
  options: {
    integrations: [
      // Custom Sentry integrations
    ],
    beforeSend: event => {
      // Custom event processing
      return event
    },
  },
})
```

## 跨距映射 {/* #span-mapping */}

Mastra 跨距類型對應到 Sentry 操作：

|馬斯特拉 SpanType |哨兵行動|
| - | - |
|`AGENT_RUN` | `gen_ai.invoke_agent` |
| `MODEL_GENERATION` | `gen_ai.chat` |
| `MODEL_STEP` | *(skipped)* |
| `MODEL_CHUNK` | *(skipped)* |
| `TOOL_CALL` | `gen_ai.execute_tool` |
| `MCP_TOOL_CALL` | `gen_ai.execute_tool` |
| `PROVIDER_TOOL_CALL` | `gen_ai.execute_tool` |
| `WORKFLOW_RUN` | `workflow.run` |
| `WORKFLOW_STEP` | `workflow.step` |
| `WORKFLOW_CONDITIONAL` | `workflow.conditional` |
| `WORKFLOW_CONDITIONAL_EVAL` | `workflow.conditional` |
| `WORKFLOW_PARALLEL` | `workflow.parallel` |
| `WORKFLOW_LOOP` | `workflow.loop` |
| `WORKFLOW_SLEEP` | `workflow.sleep` |
| `WORKFLOW_WAIT_EVENT` | `workflow.wait` |
| `PROCESSOR_RUN` | `ai.processor` |
| `GENERIC` | `ai.span` |

跳過 MODEL\_STEP 和 MODEL\_CHUNK 跨度以簡化追蹤層次結構。他們的資料被聚合到 MODEL\_GENERATION 範圍內。

## 環境變數 {/* #environment-variables */}

導出器從這些環境變數中讀取配置：

|變數|描述 |
| - | - |
|`SENTRY_DSN` | Data Source Name - tells the SDK where to send events |
| `SENTRY_ENVIRONMENT` | Deployment environment name |
| `SENTRY_RELEASE` | Version of your code deployed |

## `OpenTelemetry`屬性 {/* #opentelemetry-attributes */}

導出器設定這些標準 OpenTelemetry 屬性：

**通用屬性（所有跨度）：**

* `sentry.origin`: `auto.ai.mastra` (identifies spans from Mastra)
* `ai.span.type`：Mastra 跨度類型
* `gen_ai.conversation.id`：聊天線程標識符，設定自`metadata.threadId` to group spans in Sentry's Conversations view

**MODEL\_GENERATION 跨度：**

* `gen_ai.operation.name`: `chat`
* `gen_ai.system`: 模型Provider
* `gen_ai.request.model`：型號識別符
* `gen_ai.request.messages`：輸入訊息/提示（JSON）
* `gen_ai.response.model`：響應模型
* `gen_ai.response.text`：輸出文字
* `gen_ai.response.tool_calls`：生成期間進行的Tool呼叫（JSON 陣列）
* `gen_ai.usage.input_tokens`：輸入令牌數量
* `gen_ai.usage.output_tokens`：輸出令牌數
* `gen_ai.usage.total_tokens`: 代幣總數
* `gen_ai.request.stream`: 串流標誌
* `gen_ai.request.temperature`：溫度參數
* `gen_ai.completion_start_time`：第一個令牌時間

**TOOL\_CALL 範圍：**

* `gen_ai.operation.name`: `execute_tool`
* `gen_ai.tool.name`：Tool標識符
* `gen_ai.tool.type`: `function`
* `gen_ai.tool.call.id`：Tool調用ID
* `gen_ai.tool.input`：Tool輸入
* `gen_ai.tool.output`：Tool輸出
* `tool.success`：成功標誌

**AGENT\_RUN 跨距：**

* `gen_ai.operation.name`: `invoke_agent`
* `gen_ai.agent.name`：Agent標識符
* `gen_ai.pipeline.name`: Agent姓名
* `gen_ai.agent.instructions`：Agent說明
* `gen_ai.response.model`：兒童時代的典範
* `gen_ai.response.text`：子代的輸出
* `gen_ai.usage.*`：子代的代幣使用情況
