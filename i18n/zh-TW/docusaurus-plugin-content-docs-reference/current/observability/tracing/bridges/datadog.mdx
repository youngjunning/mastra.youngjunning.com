# 數據狗橋

：：：警告

Datadog 橋目前**experimental**. APIs and configuration options may change in future releases.

:::

啟用 Mastra 追蹤和 Datadog 之間的雙向整合。建立原生`dd-trace` APM spans in real time so that auto-instrumented operations inside tools and processors are correctly nested under their parent Mastra span. Emits LLM Observability data through `dd-trace`'s pipeline when spans end.

## 建構函數 {/* #constructor */}

```typescript oxfmt:false
new DatadogBridge(config?: DatadogBridgeConfig)
```

## 方法 {/* #methods */}

### `createSpan` {/* #createspan */}

```typescript oxfmt:false
createSpan(options: CreateSpanOptions<SpanType>): SpanIds | undefined
```

在跨度構造期間由 Mastra Observability實例呼叫。透過以下方式急切地創建 dd-trace APM 跨度`tracer.startSpan()` and returns Mastra-compatible identifiers. The returned IDs are used by Mastra throughout the span's lifetime. The dd-trace span object is stored internally and used for scope activation.

**返回：** `SpanIds | undefined` - `{ spanId, traceId, parentSpanId }`, or `undefined` if the bridge is disabled.

### `executeInContext` {/* #executeincontext */}

```typescript oxfmt:false
executeInContext<T>(spanId: string, fn: () => Promise<T>): Promise<T>
```

在 Mastra span 的 dd-trace 上下文中執行非同步函數。函數內部執行的 dd-trace 自動偵測操作（HTTP、資料庫等）將成為該跨度的父級。

### `flush` {/* #flush */}

```typescript oxfmt:false
async flush(): Promise<void>
```

將任何緩衝的 LLM Observability資料強制刷新到 Datadog，而無需關閉橋接器。在無伺服器環境中很有用，您需要確保在執行時間終止之前匯出資料。

刷新是盡力而為：dd-trace 從後台編寫器發送 LLM Observability數據，並且無法等待請求，因此`flush()` waits `flushGraceMs` (default 2000 ms) after asking dd-trace to flush, then flushes the APM exporter. Each flush that sent new data costs that full wait, so a serverless handler that awaits `flush()` per request pays it per request. Raise it if spans from short-lived processes are missing in Datadog, or set it to `0` to skip the wait when something else keeps the process alive.

### `shutdown` {/* #shutdown */}

```typescript oxfmt:false
async shutdown(): Promise<void>
```

強製完成任何未正確關閉的 APM 範圍並刷新待處理的 LLM Observability資料。然後它會禁用整合並清除所有內部狀態。

## 使用範例 {/* #usage-examples */}

### 基本用法 {/* #basic-usage */}

```typescript
import tracer from 'dd-trace'

tracer.init({
  service: process.env.DD_SERVICE || 'my-mastra-app',
  env: process.env.DD_ENV || 'production',
})

import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { DatadogBridge } from '@mastra/datadog'

const mastra = new Mastra({
  observability: new Observability({
    configs: {
      default: {
        serviceName: 'my-mastra-app',
        bridge: new DatadogBridge({
          mlApp: process.env.DD_LLMOBS_ML_APP!,
        }),
      },
    },
  }),
  agents: { myAgent },
})
```

### 無Agent模式（僅LLM可觀察性，無本地Agent） {/* #agentless-mode-llm-observability-only-no-local-agent */}

如果您沒有本機 Datadog Agent 並且只需要 LLM Observability數據，請啟用無Agent模式：

```typescript
new DatadogBridge({
  mlApp: process.env.DD_LLMOBS_ML_APP!,
  apiKey: process.env.DD_API_KEY!,
  agentless: true,
})
```

注意：APM 資料無法在無Agent模式下傳送。如果您只需要LLM可觀察性資料而不需要`dd-trace` APM, the [Datadog Exporter](/reference/observability/tracing/exporters/datadog) is a simpler choice.

### 與其他出口商 {/* #with-additional-exporters */}

該橋可以與非 Datadog 導出器結合使用，將追蹤發送到其他目的地：

```typescript
import { Mastra } from '@mastra/core'
import { Observability, MastraStorageExporter } from '@mastra/observability'
import { DatadogBridge } from '@mastra/datadog'

const mastra = new Mastra({
  observability: new Observability({
    configs: {
      default: {
        serviceName: 'my-mastra-app',
        bridge: new DatadogBridge({
          mlApp: process.env.DD_LLMOBS_ML_APP!,
        }),
        exporters: [
          new MastraStorageExporter(), // Studio access
        ],
      },
    },
  }),
})
```

:::注意
不要合併`DatadogBridge` with `DatadogExporter` in the same configuration. Both emit to LLM Observability and would double-write the same data.
:::

## 設定要求 {/* #setup-requirements */}

DatadogBridge 需要`dd-trace` to be initialized before any other imports so its auto-instrumentation can patch HTTP, database, and framework libraries at load time.

請參閱[DatadogBridge Guide](/integrations/observability/datadog#bridge) for complete setup instructions, including dd-trace initialization, bundler externals, and agent configuration.

## 跨距映射 {/* #span-mapping */}

Mastra 跨距類型對應到 Datadog LLM Observability跨距類型：

|馬斯特拉 SpanType |資料狗種類 |
| - | - |
|`AGENT_RUN` | `agent` |
| `MODEL_GENERATION` | `workflow` |
| `MODEL_STEP` | `llm` |
| `TOOL_CALL` | `tool` |
| `MCP_TOOL_CALL` | `tool` |
| `WORKFLOW_RUN` | `workflow` |
| All other types | `task` |

## 標籤支援 {/* #tags-support */}

`tracingOptions.tags`值成為結構化的LLM可觀察性註解標籤：`key:value` entries are split into key/value pairs, and tags without a colon are set to `true`.

```typescript
const result = await agent.generate('Hello', {
  tracingOptions: {
    tags: ['production', 'instance_name:career-scout-api'],
  },
})
```

這會產生：

```json
{
  "production": true,
  "instance_name": "career-scout-api"
}
```

## 環境變數 {/* #environment-variables */}

橋接器從這些環境變數中讀取配置：

|變數|描述 |
| - | - |
|`DD_API_KEY` | Datadog API key (only required for agentless mode) |
| `DD_LLMOBS_ML_APP` | ML application name |
| `DD_SITE` | Datadog site |
| `DD_ENV` | Environment name |
| `DD_LLMOBS_AGENTLESS_ENABLED` | Set to `'true'` or `'1'` to enable agentless mode |
