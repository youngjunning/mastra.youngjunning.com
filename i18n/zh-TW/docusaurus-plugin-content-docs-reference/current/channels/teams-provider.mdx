# TeamsProvider

`TeamsProvider` 透過 Bot Framework 將 Mastra Agent 接入 Microsoft Teams。將其註冊至 `Mastra.channels` 後，即可管理機器人安裝、接收經 JWT 驗證的活動 Webhook，並透過調適型卡片與串流回覆，將 Teams 對話交由對應的 Agent 處理。

此 Provider 支援兩種互斥的憑證模式：

- **自行管理**：使用現有的 Azure Bot 註冊，並提供其 `appId` 與 `appPassword`。將機器人的訊息端點指向該安裝的 Webhook URL。
- **委託佈建**：提供能依 scope 取得管理者憑證的 `tokenResolver`。呼叫 `connect(agentId)` 後，系統會為每個 Agent 佈建專屬機器人：透過 Microsoft Graph 建立 Entra 應用程式和用戶端密鑰，再透過 Teams Developer Portal API 註冊機器人，並將訊息端點指向 Mastra 伺服器。

## 使用範例 {/* #usage-example */}

以下範例使用既有的 Azure Bot 註冊，以自行管理模式接入：

```typescript title="src/mastra/index.ts"
import { Agent } from '@mastra/core/agent'
import { Mastra } from '@mastra/core/mastra'
import { TeamsProvider } from '@mastra/teams'

const supportAgent = new Agent({
  id: 'support',
  name: 'Support agent',
  instructions: 'Help users with product questions.',
  model: 'openai/gpt-5-mini',
})

const teams = new TeamsProvider({
  baseUrl: 'https://your-app.example.com',
  appId: process.env.TEAMS_APP_ID,
  appPassword: process.env.TEAMS_APP_PASSWORD,
})

export const mastra = new Mastra({
  agents: { supportAgent },
  channels: { teams },
})

await teams.connect('support')
```

將機器人註冊的訊息端點指向該安裝的 `messagingEndpoint`，例如 `https://your-app.example.com/teams/events/<webhookId>`。

委託佈建模式使用管理者憑證，為每個 Agent 建立機器人：

```typescript title="src/mastra/index.ts"
import { TeamsProvider, TEAMS_GRAPH_SCOPE } from '@mastra/teams'

const teams = new TeamsProvider({
  baseUrl: 'https://your-app.example.com',
  tokenResolver: async scope => {
    // Return an access token minted for the requested audience:
    // Microsoft Graph or the Teams Developer Portal API.
    return fetchManagerToken(scope)
  },
})
```

## 憑證模式與權杖對象 {/* #credential-modes-and-token-audiences */}

Teams 機器人的佈建涉及兩種權杖對象，因此委託模式下的 `tokenResolver` 會收到應為其申請權杖的 scope：

| Scope 常數 | 對象 | 用途 |
| - | - | - |
| `TEAMS_GRAPH_SCOPE` | Microsoft Graph | 為每個 Agent 建立 Entra 應用程式及用戶端密鑰 |
| `TEAMS_DEV_PORTAL_SCOPE` | Teams Developer Portal API | 建立和刪除機器人註冊 |

管理者憑證只在佈建時使用。每個機器人都有自己的用戶端密鑰，密鑰會加密存入安裝儲存空間；執行階段則使用該 Agent 專屬密鑰向 Bot Framework 驗證身分。

直接提供憑證（`appId`/`appPassword`）與使用 `tokenResolver` 互斥。型別檢查及 `configure()`、`connect()` 的執行階段檢查都會強制執行此限制。

## 方法 {/* #methods */}

### 安裝生命週期 {/* #installation-lifecycle */}

#### `connect(agentId, options?)` {/* #connectagentid-options */}

將 Agent 接入 Microsoft Teams。實際行為取決於憑證模式：

- **委託佈建**（`tokenResolver`）：先透過 Microsoft Graph 為該 Agent 建立 Entra 應用程式和用戶端密鑰，再透過 Teams Developer Portal 註冊機器人，並將訊息端點指向目前的伺服器。傳回指向 Developer Portal 的 `{ type: 'deep_link' }`，以便將機器人封裝為 Teams 應用程式並安裝。若 Developer Portal 操作失敗，會回復先前建立的 Entra 應用程式。
- **自行管理且已提供憑證**（於本次呼叫傳入或使用 Provider 預設值）：請求 Bot Framework 權杖以驗證憑證，儲存安裝資料並傳回 `{ type: 'immediate' }`。
- **自行管理但未提供憑證**：儲存待完成的安裝資料，並傳回指向 Teams Developer Portal 的 `{ type: 'deep_link' }`。

傳回：`Promise<ChannelConnectResult>`

若 Agent 已連線、其他 Agent 已使用同一機器人、Microsoft 拒絕憑證，或委託佈建模式缺少註冊訊息端點所需的 `baseUrl`，此方法會擲出錯誤。

#### `disconnect(agentId)` {/* #disconnectagentid */}

中斷 Agent 與 Microsoft Teams 的連線。對於此 Provider 在委託模式下佈建的機器人，系統會盡力刪除 Developer Portal 中的註冊與 Entra 應用程式。即使控制平面操作失敗，仍會移除本機安裝資料。

#### `listInstallations()` {/* #listinstallations */}

列出供編輯器 UI 使用的公開安裝資訊，不含密鑰。

傳回：`Promise<ChannelInstallationInfo[]>`

#### `getInstallation(agentId)` {/* #getinstallationagentid */}

取得 Agent 的完整安裝資料，包括用戶端密鑰。若該 Agent 沒有 Teams 安裝資料，則傳回 `null`。

傳回：`Promise<TeamsInstallation | null>`

### 設定與狀態 {/* #configuration-and-status */}

#### `configure(credentials)` {/* #configurecredentials */}

更新 Provider 的執行階段設定。傳入 `appId`/`appPassword` 可修改後續 `connect()` 呼叫預設使用的機器人憑證；傳入 `baseUrl`/`apiUrl` 可讓 Provider 或轉接器指向其他主機；傳入 `null` 可清除預設憑證。

在委託佈建模式下，若傳入 `appId` 或 `appPassword`，此方法會擲出錯誤，因為系統會為每個 Agent 分別佈建機器人憑證。

#### `initialize()` {/* #initialize */}

從儲存空間還原安裝資料：為每個作用中的機器人重建轉接器，並注入 `AgentChannels`，讓 Agent 立即收到事件。重複呼叫不會產生額外效果。

#### `isConfigured()` {/* #isconfigured */}

檢查是否至少有一個機器人已註冊並處於作用中狀態。

傳回：`boolean`

#### `getInfo()` {/* #getinfo */}

傳回供編輯器 UI 探索 Provider 的中繼資料，包括 `connect()` 選項的 schema。若有可用憑證或作用中的安裝資料，`isConfigured` 即為 `true`。

傳回：`ChannelPlatformInfo`

#### `getAdapter(installationId)` {/* #getadapterinstallationid */}

若指定的安裝處於作用中狀態，取得其正在使用的 `TeamsAdapter`。

傳回：`TeamsAdapter | undefined`

#### `getRoutes()` {/* #getroutes */}

傳回一條無須預先驗證的 `POST /teams/events/:webhookId` 路由。轉接器會驗證傳入請求的 Microsoft JWT 簽章，並確認其對象是機器人的 `appId`。`webhookId` 只用於路由，不含密鑰。

傳回：`ApiRoute[]`
