# RingSignals

`RingSignals` 將 Ring 門鈴與攝影機連接至 Agent。它接收 Ring Webhook，將每個事件以[通知訊號](/reference/signals/notifications)傳送到 Agent 執行緒，並加入 `ring_snapshot` 與 `ring_clip` Tool，供 Agent 取得事件媒體。它也提供 Ring 帳號連結及 Webhook 呼叫所需的路由。

關於 Ring Developer Console 與 ring.com 的設定，請參閱 [Ring 整合指南](/integrations/channels/ring)。

## 使用範例 {/* #usage-example */}

```typescript title="src/mastra/agents/home-agent.ts"
import { Agent } from '@mastra/core/agent'
import { Memory } from '@mastra/memory'
import { RingSignals } from '@mastra/ring-signals'

export const homeAgent = new Agent({
  id: 'home-agent',
  name: 'Home Agent',
  instructions: 'Watch the front door and say briefly whether each event needs attention.',
  model: '__GATEWAY_OPENAI_MODEL__',
  memory: new Memory(),
  signals: [
    new RingSignals({
      events: {
        device_offline: { priority: 'low', summary: 'Device went offline.', coalesce: true },
      },
      tools: {
        clip: { visibleToModel: true },
      },
    }),
  ],
})
```

已連結的帳號會儲存在頻道儲存網域。Mastra 執行個體需要設定儲存適配器。

## 事件 {/* #events */}

Ring 會傳送下列事件類型。未列於 `DEFAULT_RING_EVENTS` 的事件預設停用，必須在 `events` 中設定才會啟用。

| 事件 | 觸發條件 | 預設優先順序 | 預設摘要 |
| - | - | - | - |
| `button_press` | 門鈴按鈕被按下 | `high` | 門鈴被按下。 |
| `motion_detected` | 裝置攝影機偵測到動作 | `medium` | 偵測到動作。 |
| `device_added` | 應用程式取得裝置存取權限 | 已停用 | |
| `device_removed` | 應用程式不再能存取裝置 | 已停用 | |
| `device_online` | 裝置上線 | 已停用 | |
| `device_offline` | 裝置離線 | 已停用 | |
| `app_integration_added` | Ring 帳號連結應用程式 | 已停用 | |
| `app_integration_removed` | Ring 帳號取消連結應用程式 | 已停用 | |
| `subscription_activated` | Ring 付費訂閱或試用開始 | 已停用 | |
| `subscription_deactivated` | Ring 付費訂閱或試用結束 | 已停用 | |

裝置事件有 `deviceId` 與 `timestamp` 屬性。訂閱事件沒有 `timestamp`；應用程式整合事件與訂閱事件沒有 `deviceId`。動作事件另有 `motionType`：啟用 Ring Smart Alerts 時為 `human`、`vehicle`、`package_delivery` 或 `other_motion`，未啟用時為 `motion`。

部分事件即使未啟用也會產生副作用。`app_integration_removed` 會刪除該帳號已儲存的權杖；`subscription_deactivated` 會記錄媒體不再可用的警告。

### `RingWebhookEvent` {/* #ringwebhookevent */}

Ring 為每個事件傳送的 Webhook 負載。`target` 函式與 `attributes` 函式都在 `events` 中收到它。

```typescript
type RingWebhookEvent = {
  meta: {
    version: string
    time: string
    request_id: string
    account_id?: string
  }
  data: {
    id: string
    type: RingEventType
    attributes: {
      source: string
      source_id?: string
      source_type?: string
      timestamp?: number
      sub_type?: RingMotionType | RingSubscriptionType
      plan_id?: string | null
      expires_at?: string
      component_ids?: string[]
    }
  }
}
```

- `meta.account_id`：與事件相關的 Ring 帳號。
* `data.type`：事件類型，來自上表。
- `data.attributes.source`：裝置事件使用裝置 ID；`app_integration_added` 與 `app_integration_removed` 使用帳號 ID；訂閱事件使用 `subscriptions`。
* `data.attributes.source_id`：訂閱 ID，針對訂閱事件。
- `data.attributes.source_type`：來源類型；裝置事件為 `devices`，應用程式整合事件為 `users`。
- `data.attributes.timestamp`：事件發生時間，以 Unix 紀元毫秒計。訂閱事件沒有此欄位。
- `data.attributes.sub_type`：動作事件的原因：`human`、`vehicle`、`package_delivery`、`other_motion`；若未啟用 Smart Alerts，則為 `motion`。訂閱事件則為 `paid` 或 `trial`。
- `data.attributes.plan_id`：訂閱事件中的訂閱方案 ID；試用時為 `null`。
- `data.attributes.expires_at`：計費週期或試用結束的時間，使用 ISO 8601 日期格式。`subscription_activated` 事件一律包含此欄位。
* `data.attributes.component_ids`：涉及的攝像頭，在擁有多個攝像頭的設備上。

## 路由 {/* #routes */}

註冊 Agent 時，這些路由會加入 Mastra 伺服器。它們不使用 Mastra 驗證：Webhook 由 Ring 簽章驗證，帳號連結由 Ring 連結 nonce 驗證，媒體連結由簽章與到期時間驗證。權杖路由本身沒有驗證機制；它會將每個授權碼傳給 Ring，由 Ring 拒絕非其核發的代碼。請在伺服器 Middleware 中對 `<routePrefix>/token` 進行速率限制。

每個執行個體都需要獨立的 `routePrefix`。若兩個執行個體使用相同前綴，Mastra 只會註冊第一個的路由並記錄警告，第二個不會收到 Ring 事件。

| 路由 | 用途 |
| - | - |
| `GET <routePrefix>/link` | 帳號連結網址：完成連結並顯示結果。 |
| `GET <routePrefix>/home` | 應用程式首頁網址：以純文字傳回 `Ring Signals`。 |
| `POST <routePrefix>/token` | 權杖交換網址：將授權碼換成權杖。 |
| `POST <routePrefix>/webhook` | Webhook 網址：接收 Ring 事件。 |
| `GET <routePrefix>/media/:kind/:deviceId/:timestamp` | 提供帶簽章的快照與影片片段連結。 |

## 方法 {/* #methods */}

### `subscribeThread(target, deviceId)` {/* #subscribethreadtarget-deviceid */}

將 Ring 裝置的事件傳送到指定執行緒。未訂閱的裝置使用 `target` 選項。多個執行緒可訂閱同一裝置，每個執行緒都會收到所有事件。訂閱儲存在記憶體中，伺服器重新啟動後會遺失。

```typescript
ringSignals.subscribeThread({ resourceId: 'user-1', threadId: 'front-door' }, deviceId)
```

返回：`SignalSubscription`

停止將 Ring 裝置事件傳送到指定執行緒。

傳回：`boolean`；若執行緒已訂閱，則為 `true`。

## 匯出內容 {/* #exports */}

`@mastra/ring-signals` 也會匯出：

- `DEFAULT_RING_EVENTS`：預設的 `events` 設定。
- `DEFAULT_RING_INSTRUCTIONS`：兩個 Tool 的預設系統指令。
- `buildRingInstructions({ snapshot, clip })`：為啟用的 Tool 產生系統指令，可用來擴充預設文字。
- `RingApiClient` 與 `RingApiError`：分別是 Ring Partner API 用戶端及其擲出的錯誤。
- 型別：`RingSignalsOptions`、`RingEventType`、`RingEventNotification`、`RingMotionType`、`RingSubscriptionType`、`RingWebhookEvent`、`RingTargetResolver`、`RingToolsOptions`、`RingSnapshotToolOptions`、`RingClipToolOptions`、`RingAttachmentOption` 與 `RingMaxAttachmentBytesOption`。
