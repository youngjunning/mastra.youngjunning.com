# 振鈴訊號

`RingSignals`將 Ring 門鈴和攝影機連接到Agent。它接收 Ring webhooks，將每個事件作為Agent線程傳遞到Agent線程[通知訊號](/reference/signals/notifications)，並添加`ring_snapshot`和`ring_clip`Tool，以便Agent商可以取得事件的媒體。它還為帳戶連結和 Webhooks 的路由 Ring 呼叫提供服務。

有關 Ring 開發者控制台和ring.com 中的設置，請參閱[Ring integration guide](/integrations/channels/ring).

## 使用範例 {/* #usage-example */}

```typescript title="src/mastra/agents/home-agent.ts"
import { Agent } from '@mastra/core/agent'
import { Memory } from '@mastra/memory'
import { RingSignals } from '@mastra/ring-signals'

export const homeAgent = new Agent({
  id: 'home-agent',
  name: 'Home Agent',
  instructions: 'Watch the front door and say briefly whether each event needs attention.',
  model: '__GATEWAY_OPENAI_MODEL__',
  memory: new Memory(),
  signals: [
    new RingSignals({
      events: {
        device_offline: { priority: 'low', summary: 'Device went offline.', coalesce: true },
      },
      tools: {
        clip: { visibleToModel: true },
      },
    }),
  ],
})
```

關聯帳戶保存在通道儲存域中。 Mastra 實例需要儲存適配器。

## 活動 {/* #events */}

Ring 傳送這些事件類型。無需報名的活動`DEFAULT_RING_EVENTS` are disabled until you configure them in `events`.

|活動 |傳送時間 |預設優先權 |預設摘要 |
| - | - | - | - |
|`button_press` | The doorbell button is pressed | `high` | Doorbell was pressed. |
| `motion_detected` | A device camera detects motion | `medium` | Motion was detected. |
| `device_added` | A device becomes accessible to your app | Disabled | |
| `device_removed` | A device is no longer accessible to your app | Disabled | |
| `device_online` | A device comes online | Disabled | |
| `device_offline`|裝置離線 |已停用 | |
|`app_integration_added`| Ring 帳戶連結您的應用程式 |已停用 | |
|`app_integration_removed`| Ring 帳戶取消與您的應用程式的連結 |已停用 | |
|`subscription_activated`| Ring 付費訂閱或試用開始 |已停用 | |
|`subscription_deactivated`| Ring 付費訂閱或試用結束 |已停用 | |

設備事件有`deviceId` and `timestamp` attributes. Subscription events have no `timestamp`, and app integration and subscription events have no `deviceId`. Motion events also have `motionType`: `human`, `vehicle`, `package_delivery`, or `other_motion` when Ring Smart Alerts are on, and `motion` when they're off.

有些事件也有副作用，無論是否啟用。`app_integration_removed` deletes the account's stored tokens, and `subscription_deactivated` logs a warning that media is no longer available.

### `RingWebhookEvent` {/* #ringwebhookevent */}

Ring 為每個事件發送的 Webhook 負載。這`target` function and the `attributes` function in `events` receive it.

```typescript
type RingWebhookEvent = {
  meta: {
    version: string
    time: string
    request_id: string
    account_id?: string
  }
  data: {
    id: string
    type: RingEventType
    attributes: {
      source: string
      source_id?: string
      source_type?: string
      timestamp?: number
      sub_type?: RingMotionType | RingSubscriptionType
      plan_id?: string | null
      expires_at?: string
      component_ids?: string[]
    }
  }
}
```

* `meta.account_id`：與事件關聯的環帳戶。
* `data.type`：事件類型，來自上表。
* `data.attributes.source`：設備事件的設備ID、設備事件的帳戶ID`app_integration_added` and `app_integration_removed`, or `subscriptions` for subscription events.
* `data.attributes.source_id`：訂閱 ID，針對訂閱事件。
* `data.attributes.source_type`: 來源種類:`devices` for device events, `users` for app integration events.
* `data.attributes.timestamp`：事件發生的時間，以紀元毫秒為單位。它在訂閱事件中遺失。
* `data.attributes.sub_type`：導致運動事件的原因：`human`, `vehicle`, `package_delivery`, `other_motion`, or `motion` when Smart Alerts are off. `paid` or `trial` on subscription events.
* `data.attributes.plan_id`：訂閱計劃 ID，關於訂閱事件。`null` for trials.
* `data.attributes.expires_at`：計費週期或試用結束時，採用 ISO 8601 日期。始終存在於`subscription_activated`.
* `data.attributes.component_ids`：涉及的攝像頭，在擁有多個攝像頭的設備上。

## 路線 {/* #routes */}

當Agent註冊時，這些路由將會新增到 Mastra 伺服器。他們不使用 Mastra 身份驗證。 Webhook 使用 Ring 的簽名進行驗證，帳戶連結使用 Ring 的連結隨機數進行驗證，媒體連結使用其簽名和到期時間進行驗證。令牌路由沒有自己的檢查：它將每個代碼傳送到 Ring，而 Ring 拒絕它未發出的代碼。速率限制`<routePrefix>/token` in your server's middleware.

每個實例都需要自己的`routePrefix`. When two instances use the same prefix, Mastra registers only the first instance's routes and logs a warning. The second instance gets no Ring events.

|路線 |目的|
| - | - |
|`GET <routePrefix>/link` | Account Link URL. Finishes linking and shows the result. |
| `GET <routePrefix>/home` | App Homepage URL. Returns `Ring Signals` as plain text. |
| `POST <routePrefix>/token` | Token Exchange URL. Exchanges an authorization code for tokens. |
| `POST <routePrefix>/webhook` | Webhook URL. Receives Ring events. |
| `GET <routePrefix>/media/:kind/:deviceId/:timestamp` | Serves signed snapshot and clip links. |

## 方法 {/* #methods */}

### `subscribeThread(target, deviceId)` {/* #subscribethreadtarget-deviceid */}

將事件從環設備傳送到特定執行緒。沒有訂閱的設備使用`target` option. Several threads can subscribe to the same device, and each one receives every event. Subscriptions are kept in memory and are lost when the server restarts.

```typescript
ringSignals.subscribeThread({ resourceId: 'user-1', threadId: 'front-door' }, deviceId)
```

返回：`SignalSubscription`

停止從環設備向執行緒發送事件。

返回：`boolean`, `true` if the thread was subscribed.

## 出口 {/* #exports */}

`@mastra/ring-signals`還出口：

* `DEFAULT_RING_EVENTS`:預設`events` configuration.
* `DEFAULT_RING_INSTRUCTIONS`：兩個Tool的預設系統指令。
* `buildRingInstructions({ snapshot, clip })`：為啟用的Tool建立系統指令。使用它來擴展預設文字。
* `RingApiClient`和`RingApiError`: A client for the Ring Partner API and the error it throws.
* 類型：`RingSignalsOptions`, `RingEventType`, `RingEventNotification`, `RingMotionType`, `RingSubscriptionType`, `RingWebhookEvent`, `RingTargetResolver`, `RingToolsOptions`, `RingSnapshotToolOptions`, `RingClipToolOptions`, `RingAttachmentOption`, and `RingMaxAttachmentBytesOption`.
