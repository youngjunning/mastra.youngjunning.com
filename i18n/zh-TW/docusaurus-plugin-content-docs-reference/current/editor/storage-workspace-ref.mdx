# StorageWorkspaceRef

`StorageWorkspaceRef` 是用於將 Workspace 附加至已儲存 Agent 的可辨識聯集型別。它可以透過 ID 指向已在 Mastra 執行階段註冊的 Workspace、內嵌 Workspace 快照，或指定已於 `MastraEditor.workspaces` 註冊的 Workspace Provider 來建立 Workspace。

[`BuilderAgentDefaults.workspace`](https://agent-builder.mastra.ai/reference/builder-agent-defaults) 與已儲存的 Agent 紀錄都會使用此型別。

## 使用範例 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { MastraEditor } from '@mastra/editor'

// Variant 1 — reference a runtime workspace by id
new MastraEditor({
  builder: {
    enabled: true,
    configuration: {
      agent: {
        workspace: { type: 'id', workspaceId: 'builder-workspace' },
      },
    },
  },
})

// Variant 2 — inline a workspace snapshot
new MastraEditor({
  builder: {
    enabled: true,
    configuration: {
      agent: {
        workspace: {
          type: 'inline',
          config: {
            name: 'inline-builder-workspace',
            filesystem: {
              provider: 'local',
              config: { basePath: './agent-files' },
            },
          },
        },
      },
    },
  },
})

// Variant 3 — build the workspace with a registered workspace provider
new MastraEditor({
  workspaces: { 'my-provider': myWorkspaceProvider },
  builder: {
    enabled: true,
    configuration: {
      agent: {
        workspace: {
          type: 'provider',
          provider: 'my-provider',
          config: { region: 'us-east-1' },
        },
      },
    },
  },
})
```

## 還原執行階段物件 {/* #hydration */}

`StorageWorkspaceRef` 會在呼叫 `mastra.editor.agent.getById()` 時延遲解析，呼叫 `list()` 時則不會。Editor 會從 `MastraEditor.filesystems` / `MastraEditor.sandboxes` 尋找檔案系統與 Sandbox Provider，並建立執行階段的 `Workspace`。若缺少 Provider，系統會發出警告並省略該 Workspace。對於 `{ type: 'provider' }` 參照，Editor 會呼叫 `createWorkspace(config)`，此方法屬於已在 `MastraEditor.workspaces` 註冊的 Provider；Provider 未註冊時會擲出錯誤。
