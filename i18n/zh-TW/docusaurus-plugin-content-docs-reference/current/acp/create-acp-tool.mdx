# createACPTool()

`createACPTool()` 建立 Mastra Tool，將 `task` 字串傳給相容 Agent Client Protocol（ACP）的程式設計 Agent，並將最終 ACP 回應作為 `output` 傳回。適用於由父 Agent 決定何時以 Tool 呼叫 ACP Agent 的情境。

如果想將 ACP Agent 註冊為 Mastra 子 Agent，請使用 [`AcpAgent` 類別](/reference/acp/acp-agent)。

## 使用範例 {/* #usage-example */}

建立程式碼編輯 Tool，並將其註冊至父 Agent：

```typescript title="src/mastra/agents/code-supervisor.ts"
import { createACPTool } from '@mastra/acp'
import { Agent } from '@mastra/core/agent'

const codeAgentTool = createACPTool({
  id: 'code-agent',
  description: 'Use an ACP-compatible coding agent to inspect and edit code',
  command: 'acp-agent',
  args: ['--stdio'],
  cwd: process.cwd(),
})

export const codeSupervisor = new Agent({
  id: 'code-supervisor',
  name: 'Code Supervisor',
  instructions: 'Use the code-agent tool when a task requires repository inspection or code edits.',
  model: '__GATEWAY_OPENAI_MODEL__',
  tools: {
    codeAgentTool,
  },
})
```

## 會話生命週期 {/* #session-lifecycle */}

每次執行 Tool 都會建立 ACP 連線並啟動設定的 `command`。它會先初始化 ACP 用戶端並建立 ACP 工作階段，再傳送 `task`，使用 ACP `session/prompt` 方法。

預設情況下，執行 Tool 時建立的 ACP 連線會將 `persistSession` 設為 `true`。若要讓 ACP 處理程序在每次提示完成後立即停止，請設定 `persistSession: false`。

若需要能跨多次呼叫重複使用，並可明確控制工作階段生命週期的 ACP 子 Agent 執行個體，請使用 [`AcpAgent`](/reference/acp/acp-agent#session-lifecycle)。

## 權限處理 {/* #permission-handling */}

ACP Agent 繼續執行前，可能要求用戶端選擇一個權限選項。預設情況下，`@mastra/acp` 會選擇 ACP Agent 傳回的第一個選項，沒有可用選項時則取消。

傳入 `onPermissionRequest`，檢查請求並傳回自訂權限回應：

```typescript title="src/mastra/agents/code-agent.ts"
import { createACPTool } from '@mastra/acp'

export const codeAgentTool = createACPTool({
  id: 'code-agent',
  description: 'Use an ACP-compatible coding agent',
  command: 'acp-agent',
  args: ['--stdio'],
  async onPermissionRequest(request) {
    const allowOption = request.options.find(option => option.name === 'Allow')

    if (!allowOption) {
      return { outcome: { outcome: 'cancelled' } }
    }

    return {
      outcome: {
        outcome: 'selected',
        optionId: allowOption.optionId,
      },
    }
  },
})
```

使用此回呼函式執行本機政策或檢查權限請求標題，也可以將決策交給自己的核准流程。

## 擴展方法 {/* #extension-methods */}

某些 ACP Agent 會在標準 ACP 請求集之外呼叫用戶端的自訂擴充方法。預設用戶端會以「Method not found」錯誤拒絕未知方法，可能導致 Agent 的當前回合中止。

傳入 `createClient` 可擴充或取代預設用戶端。此回呼函式接收預設用戶端，並傳回連線要使用的用戶端：

```typescript title="src/mastra/agents/code-agent.ts"
import { createACPTool } from '@mastra/acp'

export const codeAgentTool = createACPTool({
  id: 'code-agent',
  description: 'Use an ACP-compatible coding agent',
  command: 'acp-agent',
  args: ['--stdio'],
  createClient: defaultClient =>
    Object.assign(defaultClient, {
      async extMethod(method: string, params: Record<string, unknown>) {
        return {}
      },
      async extNotification(method: string, params: Record<string, unknown>) {},
    }),
})
```

如果還需要修改標準處理函式，請傳回完全自訂的 `Client` 實作。`Client` 型別由 `@mastra/acp` 重新匯出。
