# 分類器處理器

`ClassifierProcessor` 是一種混合處理器：它對訊息文字執行 [`Classifier`](/reference/classifier/classifier)，並將具型別的答案傳給 `onResult`。在 `onResult` 中，呼叫 `abort(reason)` 可觸發 tripwire 並中止請求；呼叫 `filter()` 可捨棄目前的內容並繼續處理；不呼叫這兩個方法則允許內容通過。分類器會提供機率、選項和分數等判斷依據，具體如何處置由 `onResult` 中的應用程式政策決定。

中止原因一律是呼叫端提供的字串。中止訊息不會包含 Provider 產生的文字。

## 使用範例 {/* #usage-example */}

```typescript
import { Classifier } from '@mastra/core/classifier'
import { typeSafeAi } from '@ai-sdk/typesafe-ai'
import { ClassifierProcessor } from '@mastra/core/processors'

const safety = new Classifier({
  id: 'safety',
  model: typeSafeAi.decisionModel('__AI_SDK_TYPESAFE_DECISION_MODEL__'),
  questions: {
    unsafe: {
      type: 'boolean',
      criteria: { true: 'The message is unsafe', false: 'The message is safe' },
    },
  },
})

const processor = new ClassifierProcessor({
  classifier: safety,
  onResult: (answers, { abort }) => {
    if ((answers.unsafe.probability ?? 1) > 0.8) abort('Message rejected by safety policy')
  },
  lastMessageOnly: true,
})
```

決策模型可能拒絕回答某個問題。拒絕回答時，答案為 `{ type: 'refusal' }`，不包含 `choice`、`score` 或 `probability`。上述範例將拒絕回答視為不安全。

多個判斷條件可以共用一個 `onResult`；若需要使用不同的分類器，也可以分別建立處理器。請為每個處理器指定唯一的 `id`。具有相同 `id` 的處理器實例會共用單次執行的狀態，包括已累積的串流片段。

```typescript
inputProcessors: [
  new ClassifierProcessor({
    id: 'safety-check',
    classifier: safety,
    onResult: (a, { abort }) => {
      if ((a.unsafe.probability ?? 1) > 0.8) abort('Rejected by safety policy')
    },
  }),
  new ClassifierProcessor({
    id: 'topic-check',
    classifier: topic,
    onResult: (a, { abort }) => {
      if (a.topic.type === 'refusal' || a.topic.choice === 'other') abort('Support questions only')
    },
  }),
]
```

## 各階段的行為 {/* #behavior-by-phase */}

| 階段 | 不呼叫任何方法 | `abort(reason)` | `filter()` |
| - | - | - | - |
| 輸入（`inputProcessors`） | 訊息通過 | 在呼叫 LLM 前中止 | 從上下文移除訊息 |
| 輸出結果（`outputProcessors`） | 訊息通過 | 中止回應 | 從回應移除訊息 |
| 串流輸出（`outputProcessors`） | 輸出片段 | 中止串流 | 不輸出片段 |

沒有文字內容的訊息會直接通過，不會呼叫分類器。

## 稽核決策 {/* #audit-decisions */}

每次呼叫分類器後，`onResult` 執行完畢，`onDecision` 就會收到一個 `ClassifierProcessorDecision`。分類器呼叫失敗時也會產生決策紀錄。

```typescript
const processor = new ClassifierProcessor({
  classifier: safety,
  onResult: (answers, { abort }) => {
    if ((answers.unsafe.probability ?? 1) > 0.8) {
      abort('Message rejected by safety policy', { metadata: { policy: 'unsafe' } })
    }
  },
  onDecision: async decision => {
    await auditLog.insert({
      threadId: decision.ids.threadId,
      messageId: decision.ids.messageId,
      tenantId: decision.requestContext?.get('tenantId'),
      outcome: decision.outcome,
      answers: decision.result ? decision.result.answers : null,
      error: decision.result ? null : String(decision.error),
      durationMs: decision.durationMs,
    })
  },
})
```

`ClassifierProcessorDecision` 包含以下欄位：

```typescript
type ClassifierProcessorDecision = {
  processorId: string
  classifierId: string
  phase: 'input' | 'output' | 'stream'
  // 'aborted' when onResult called abort(), or when the call failed under errorStrategy 'strict'
  outcome: 'allowed' | 'filtered' | 'aborted'
  // Text sent to the classifier, after maxInputLength truncation
  state: ClassifierState
  // Set when the classifier answered
  result?: ClassifierResult
  // Set when the classifier call failed
  error?: unknown
  // Set when outcome is 'aborted', with the same reason and metadata as the tripwire the caller receives
  tripwire?: { reason: string; metadata?: unknown }
  // Duration of the classifier call, including retries
  durationMs: number
  ids: {
    runId?: string
    threadId?: string
    resourceId?: string
    messageId?: string
    traceId?: string
    spanId?: string
  }
  requestContext?: RequestContext
}
```

哪些 ID 會被設定，取決於處理階段：

| 階段 | ID |
| - | - |
| 輸入與輸出結果 | `messageId`；若 Agent 使用 Memory，還包括 `threadId` 和 `resourceId` |
| 串流輸出 | `runId`；若 Agent 使用 Memory，還包括 `threadId` 和 `resourceId` |

`threadId` 和 `resourceId` 來自 Agent 的 Memory 選項。若未使用 Memory，處理器會先從訊息讀取，再從請求上下文的 `MASTRA_THREAD_ID_KEY` 和 `MASTRA_RESOURCE_ID_KEY` 鍵讀取。啟用執行追蹤時會設定 `traceId` 和 `spanId`，其中 `spanId` 對應處理器的 span。

處理器會等待 `onDecision` 完成，再繼續傳遞內容。在串流階段，每個文字片段都會呼叫一次；寫入作業過慢會延遲每個片段的輸出。耗時較長的寫入應排入佇列，而不是等待完成。`onDecision` 擲出的錯誤會被記錄，但不會改變處理結果。

若 `onResult` 擲出非 tripwire 錯誤，或使用者在分類器呼叫期間停止串流回應，`onDecision` 就不會被呼叫。停止回應也會取消分類器呼叫，但持久化 Agent 除外。

## 擴充使用範例 {/* #extended-usage-examples */}

### 限定主題範圍 {/* #topic-scoping */}

```typescript title="src/mastra/agents/support-agent.ts"
import { Agent } from '@mastra/core/agent'
import { Classifier } from '@mastra/core/classifier'
import { typeSafeAi } from '@ai-sdk/typesafe-ai'
import { ClassifierProcessor } from '@mastra/core/processors'

const topic = new Classifier({
  id: 'topic',
  model: typeSafeAi.decisionModel('__AI_SDK_TYPESAFE_DECISION_MODEL__'),
  questions: {
    topic: {
      type: 'choice',
      criteria: {
        billing: 'Questions about invoices or payments',
        account: 'Questions about account settings',
        other: 'Anything else',
      },
    },
  },
})

export const agent = new Agent({
  id: 'support-agent',
  name: 'support-agent',
  instructions: 'You help customers with billing and account questions.',
  model: '__GATEWAY_OPENAI_MODEL__',
  inputProcessors: [
    new ClassifierProcessor({
      classifier: topic,
      lastMessageOnly: true,
      onResult: (answers, { abort }) => {
        if (answers.topic.type === 'refusal' || answers.topic.choice === 'other') {
          abort('This assistant only handles billing and account questions')
        }
      },
    }),
  ],
})
```

### 輸出品質關卡 {/* #output-quality-gate */}

```typescript title="src/mastra/agents/quality-gated-agent.ts"
import { Agent } from '@mastra/core/agent'
import { Classifier } from '@mastra/core/classifier'
import { typeSafeAi } from '@ai-sdk/typesafe-ai'
import { ClassifierProcessor } from '@mastra/core/processors'

const quality = new Classifier({
  id: 'quality',
  model: typeSafeAi.decisionModel('__AI_SDK_TYPESAFE_DECISION_MODEL__'),
  questions: {
    quality: {
      type: 'score',
      instructions: 'Rate how well the response answers the user',
      criteria: ['Off-topic', 'Partial', 'Complete'],
    },
  },
})

export const agent = new Agent({
  id: 'quality-gated-agent',
  name: 'quality-gated-agent',
  instructions: 'You are a helpful assistant',
  model: '__GATEWAY_OPENAI_MODEL__',
  outputProcessors: [
    new ClassifierProcessor({
      classifier: quality,
      onResult: (answers, { filter }) => {
        if ((answers.quality.score ?? 0) < 1) filter()
      },
    }),
  ],
})
```

### 註冊分類器 {/* #registered-classifier */}

先將分類器註冊到 `Mastra` 實例，再透過鍵或 ID 引用。處理器會在首次使用時解析該分類器。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Classifier } from '@mastra/core/classifier'
import { typeSafeAi } from '@ai-sdk/typesafe-ai'

export const mastra = new Mastra({
  classifiers: {
    safety: new Classifier({
      id: 'safety',
      model: typeSafeAi.decisionModel('__AI_SDK_TYPESAFE_DECISION_MODEL__'),
      questions: {/* ... */},
    }),
  },
})
```

```typescript title="src/mastra/processors/safety-processor.ts"
import { ClassifierProcessor } from '@mastra/core/processors'

type SafetyQuestions = {
  unsafe: { type: 'boolean' }
}

const processor = new ClassifierProcessor<SafetyQuestions>({
  classifier: 'safety',
  onResult: (answers, { abort }) => {
    if ((answers.unsafe.probability ?? 1) > 0.8) abort('Message rejected by safety policy')
  },
})
```

透過字串引用已註冊的分類器時，無法從註冊的實例推導答案型別。請將其問題對應表作為 `ClassifierProcessor` 的型別引數傳入，以便為 `answers` 參數指定型別。
