# 技能處理器

這`SkillsProcessor`是一個**輸入處理器**將可用技能新增至系統訊息中`<available_skills>`列表，因此模型知道存在哪些技能，並且可以使用`skill`Tool。Agent在其Workspace或自己的Workspace時自動添加它`skills`選項提供技能，因此您只需自行配置即可變更技能的呈現方式。

和`injectCatalog: false`, it replaces the list with a short instruction to find skills with `skill_search` and load them with `skill`. Use this when the list costs too many tokens. See [Turn off the skills list](/docs/sandbox/skills#turn-off-the-skills-list).

這`skill`, `skill_search`, and `skill_read` tools come from the agent, not from this processor, and stay available in both modes. To replace them with on-demand `search_skills` and `load_skill` tools instead, use [`SkillSearchProcessor`](/reference/processors/skill-search-processor). Configure one or the other, not both.

## 使用範例 {/* #usage-example */}

```typescript
import { SkillsProcessor } from '@mastra/core/processors'

const skills = new SkillsProcessor({
  workspace,
  format: 'markdown',
})
```

## 擴充使用範例 {/* #extended-usage-example */}

```typescript title="src/mastra/agents/skill-agent.ts"
import { Agent } from '@mastra/core/agent'
import { SkillsProcessor } from '@mastra/core/processors'
import { Workspace, LocalFilesystem } from '@mastra/core/workspace'

const workspace = new Workspace({
  filesystem: new LocalFilesystem({ basePath: './project' }),
  skills: ['skills'],
  bm25: true,
})

const agent = new Agent({
  id: 'skill-agent',
  name: 'skill-agent',
  instructions: 'You are a helpful assistant.',
  model: '__GATEWAY_OPENAI_MODEL__',
  workspace,
  inputProcessors: [new SkillsProcessor({ injectCatalog: false })],
})
```

關閉清單後，Agent可以透過搜尋來尋找技能。`skill_search` works without any search setup; for larger collections, configure [BM25 or vector search](/docs/sandbox/search) on the workspace to improve ranking, as in the example above. The agent workflow is:

1. Agent收到用戶訊息
2. Agent來電`skill_search` with keywords (e.g., "release notes")
3. Agent檢討結果和通話`skill` with the skill name
4. Agent遵循加載技能的指示
