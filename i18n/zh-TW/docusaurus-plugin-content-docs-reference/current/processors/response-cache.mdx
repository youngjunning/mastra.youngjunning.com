# 回應快取

:::測試版

在 API 穩定之前，可能會在沒有重大版本更新的情況下發生重大變更。

:::

`ResponseCache`是一個輸入處理器，用於在Agent循環內的請求/回應邊界上快取 LLM 回應。它掛鉤到`processLLMRequest` for cache lookup and short-circuits on a hit. It uses `processLLMResponse`寫出完整的回覆。

快取鍵源自已解析的`LanguageModelV2Prompt` Mastra is about to send to the model (i.e. *after* memory has loaded and earlier input processors have transformed the prompt) so two users with different memory contexts produce different cache keys. Each step in an agentic tool loop is independently cached.

不存在用於回應快取的Agent級選項。登記`ResponseCache` explicitly on `inputProcessors`. Per-call overrides flow through `RequestContext` via [`ResponseCache.context()`](#static-helpers)和[`ResponseCache.applyContext()`](#static-helpers).

## 使用範例 {/* #usage-example */}

```typescript
import { Agent } from '@mastra/core/agent'
import { InMemoryServerCache } from '@mastra/core/cache'
import { ResponseCache } from '@mastra/core/processors'

const cache = new InMemoryServerCache()

const agent = new Agent({
  id: 'search-agent',
  name: 'Search Agent',
  instructions: 'You answer questions concisely.',
  model: '__GATEWAY_OPENAI_MODEL_BASE__',
  inputProcessors: [new ResponseCache({ cache, ttl: 600 })],
})

// First call hits the LLM and writes to the cache.
await agent.generate('What is the capital of France?')

// Second identical call replays the cached response.
await agent.generate('What is the capital of France?')

// Force a fresh call but still update the cache.
await agent.generate('What is the capital of France?', {
  requestContext: ResponseCache.context({ bust: true }),
})
```

看[Response caching](/docs/agents/processors#response-caching) for the conceptual overview, scoping rules, and recommended deployment patterns.

## 靜態助手 {/* #static-helpers */}

`ResponseCache`公開兩個靜態助手，用於設定每次呼叫覆蓋`RequestContext`. The helpers keep the underlying context key a private implementation detail: prefer them over reading/writing the raw key.

### `ResponseCache.context(options)` {/* #responsecachecontextoptions */}

打造一個新鮮的`RequestContext` preloaded with per-call response cache overrides.

```typescript
await agent.stream('hello', {
  requestContext: ResponseCache.context({ key: 'custom', bust: true }),
})
```

### `ResponseCache.applyContext(requestContext, options)` {/* #responsecacheapplycontextrequestcontext-options */}

將每次呼叫響應快取覆蓋合併到現有的`RequestContext`. Returns the same context for chaining.

```typescript
const ctx = new RequestContext()
ctx.set('caller-meta', { userId: 'u-123' })
ResponseCache.applyContext(ctx, { bust: true })
await agent.stream('hello', { requestContext: ctx })
```

## 助手導出 {/* #helper-exports */}

* `buildResponseCacheKey(inputs)`：預設使用的確定性哈希。重新匯出它以覆蓋各個字段，同時保留標準密鑰形狀的其餘部分。
* `DEFAULT_RESPONSE_CACHE_TTL_SECONDS`:預設`ttl` (`300`).
* `RESPONSE_CACHE_CONTEXT_KEY`： 這`RequestContext` key the static helpers write to. Exposed for advanced cases (e.g. clearing the override mid-pipeline). Prefer the helpers.
