# 訊息歷史記錄

這`MessageHistory`是一個**混合處理器**它處理訊息歷史記錄的檢索和持久化。輸入時，它從儲存中獲取歷史訊息並將其添加到對話中。在輸出時，它將新訊息保存到儲存中。

## 使用範例 {/* #usage-example */}

```typescript
import { MessageHistory } from '@mastra/core/processors'

const processor = new MessageHistory({
  storage: memoryStorage,
  lastMessages: 50,
})
```

## 擴充使用範例 {/* #extended-usage-example */}

```typescript title="src/mastra/agents/memory-agent.ts"
import { Agent } from '@mastra/core/agent'
import { MessageHistory } from '@mastra/core/processors'
import { PostgresStore } from '@mastra/pg'

const storage = new PostgresStore({
  id: 'pg-storage',
  connectionString: process.env.DATABASE_URL,
})

export const agent = new Agent({
  id: 'memory-agent',
  name: 'memory-agent',
  instructions: 'You are a helpful assistant with conversation memory',
  model: '__GATEWAY_OPENAI_MODEL__',
  inputProcessors: [
    new MessageHistory({
      storage,
      lastMessages: 100,
    }),
  ],
  outputProcessors: [
    new MessageHistory({
      storage,
    }),
  ],
})
```

## 行為 {/* #behavior */}

### 輸入處理 {/* #input-processing */}

1. 檢索`threadId` from the request context
2. 從儲存中取得歷史訊息（按建立日期降序排列）
3. 過濾掉系統訊息（它們不應儲存在資料庫中）
4. 將歷史訊息與傳入訊息合併，避免按 ID 重複
5. 新增歷史消息`source: 'memory'` tag

### 輸出處理 {/* #output-processing */}

1. 檢索`threadId` from the request context
2. 跳過持久性，如果`readOnly` is set in memory config
3. 從訊息中過濾掉不完整的Tool調用
4. 將新的用戶輸入和助理回應訊息儲存到儲存中
5. 更新線程的`updatedAt` timestamp
