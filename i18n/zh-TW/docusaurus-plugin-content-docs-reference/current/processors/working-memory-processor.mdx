# 工作記憶

這`WorkingMemory`是一個**輸入處理器**將工作記憶體資料作為系統訊息注入。它從儲存中檢索持久性資訊並將其格式化為 LLM 的指令，使Agent程式能夠在對話中維護有關使用者的上下文。

## 使用範例 {/* #usage-example */}

```typescript
import { WorkingMemory } from '@mastra/core/processors'

const processor = new WorkingMemory({
  storage: memoryStorage,
  scope: 'resource',
  template: {
    format: 'markdown',
    content: `# User Profile
- **Name**:
- **Preferences**:
- **Goals**:
`,
  },
})
```

## 擴充使用範例 {/* #extended-usage-example */}

```typescript title="src/mastra/agents/personalized-agent.ts"
import { Agent } from '@mastra/core/agent'
import { WorkingMemory, MessageHistory } from '@mastra/core/processors'
import { PostgresStore } from '@mastra/pg'

const storage = new PostgresStore({
  id: 'pg-storage',
  connectionString: process.env.DATABASE_URL,
})

export const agent = new Agent({
  id: 'personalized-agent',
  name: 'personalized-agent',
  instructions: 'You are a helpful assistant that remembers user preferences',
  model: '__GATEWAY_OPENAI_MODEL__',
  inputProcessors: [
    new WorkingMemory({
      storage,
      scope: 'resource',
      template: {
        format: 'markdown',
        content: `# User Information
- **Name**:
- **Location**:
- **Preferences**:
- **Communication Style**:
- **Current Projects**:
`,
      },
    }),
    new MessageHistory({ storage, lastMessages: 50 }),
  ],
  outputProcessors: [new MessageHistory({ storage })],
})
```

## 行為 {/* #behavior */}

### 輸入處理 {/* #input-processing */}

1. 檢索`threadId` and `resourceId` from the request context
2. 根據範圍，從以下任一位置取得工作記憶體：
   * 線程元資料 (`scope: 'thread'`)
   * 資源記錄（`scope: 'resource'`)
3. 解析模板（來自Provider、選項或預設）
4. 根據模式產生系統指令：
   * **普通模式**：包括儲存和更新資訊的指南，以及模板結構和當前數據
   * **唯讀模式** (`readOnly: true`): Includes only the current data as context without update instructions
5. 將指令新增為系統訊息`source: 'memory'` tag

### 工作記憶更新 {/* #working-memory-updates */}

工作記憶更新是透過`updateWorkingMemory` tool provided by the Memory class, not through this processor. The processor only handles injecting the current working memory state into conversations.

### 預設模板 {/* #default-template */}

如果未提供模板，處理器將使用預設的 Markdown 模板，其中包含以下欄位：

* 名字、姓氏
* 地點、職業
* 興趣、目標
* 事件、事實、項目
