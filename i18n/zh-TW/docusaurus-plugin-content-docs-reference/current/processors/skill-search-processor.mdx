# SkillSearchProcessor

`SkillSearchProcessor` 是一種**輸入處理器**，支援依需求探索及載入 Skill。它不會像 `SkillsProcessor` 那樣事先將所有 Skill 中繼資料注入系統提示，而是提供 `search_skills` 與 `load_skill` 兩個中介工具，讓 Agent 依需求尋找並載入 Skill。當 Workspace 有大量 Skill 時，可減少上下文 token 用量。

若只想隱藏 Skill 清單，同時保留標準的 `skill`、`skill_read` 和 `skill_search` 工具，請改用 `SkillsProcessor` 並設定 `injectCatalog: false`。請參閱[關閉 Skill 清單](/docs/sandbox/skills#turn-off-the-skills-list)。

預設情況下，若只加入 `SkillSearchProcessor`，且 Agent 使用啟用 Skill 的 `Workspace`，Agent 會依需求使用 Skill：

* 不會自動加入預設的預先載入式 `SkillsProcessor`。
* 提供 `search_skills` 和 `load_skill`，用於探索 Skill 並載入其說明。
* 隱藏功能重疊的 `skill` 與 `skill_search` 工具。
* `skill_read` 仍可使用，讓 Agent 讀取參考資料、腳本及素材等 Skill 附屬檔案。

若明確同時設定 `SkillsProcessor` 和 `SkillSearchProcessor`，Agent 會保留預先載入式 `skill` 與 `skill_search` 工具，作為可選的使用方式。

## 使用範例 {/* #usage-example */}

```typescript
import { SkillSearchProcessor } from '@mastra/core/processors'

const skillSearch = new SkillSearchProcessor({
  workspace,
  search: {
    topK: 5,
    minScore: 0.1,
  },
})
```

## 延伸使用範例 {/* #extended-usage-example */}

```typescript title="src/mastra/agents/skill-agent.ts"
import { Agent } from '@mastra/core/agent'
import { SkillSearchProcessor } from '@mastra/core/processors'
import { Workspace, LocalFilesystem } from '@mastra/core/workspace'

const workspace = new Workspace({
  filesystem: new LocalFilesystem({ basePath: './project' }),
  skills: ['skills'],
  bm25: true,
})

const skillSearch = new SkillSearchProcessor({
  workspace,
  search: {
    topK: 5,
    minScore: 0.1,
  },
})

const agent = new Agent({
  id: 'skill-agent',
  name: 'skill-agent',
  instructions:
    'You are a helpful assistant. Use search_skills to find relevant skills, then load_skill to load their instructions.',
  model: '__GATEWAY_OPENAI_MODEL__',
  workspace,
  inputProcessors: [skillSearch],
})
```

Agent 的工作流程如下：

1. Agent 收到使用者訊息
1. Agent 使用關鍵字（例如 "api design"）呼叫 `search_skills`
1. Agent 檢視結果，並使用 Skill 名稱呼叫 `load_skill`
1. Skill 說明會在下一輪以系統訊息呈現
1. Agent 遵循已載入 Skill 的說明

## Workspace 檔案工具 {/* #workspace-file-tools */}

`SkillSearchProcessor` 會將 Skill 說明載入對話，不會阻止 Workspace 檔案工具讀取檔案。

使用 `skill_read` 讀取已載入 Skill 的附屬檔案，例如 `references/`、`scripts/` 或 `assets/` 下的檔案。

將 `mastra_workspace_read_file` 等 Workspace 檔案工具保留給明確需要檢視或編輯檔案的流程。一般執行任務時，Agent 不必再次讀取同一個 `SKILL.md` 檔案，因為 `load_skill` 已成功載入其說明。

## 與 SkillsProcessor 比較 {/* #compared-to-skillsprocessor */}

| | SkillsProcessor | SkillSearchProcessor |
| - | - | - |
| 擴充方式 | 預先注入所有 Skill | 依需求探索 |
| 上下文用量 | 隨 Skill 數量增加 | 固定（僅包含已載入的 Skill） |
| Agent 工作流程 | Skill 一律可見 | Agent 依需求搜尋及載入 |
| 適用情境 | 少量 Skill（\< 10） | 大量 Skill（10 個以上） |
