# 技能搜尋處理器

這`SkillSearchProcessor`是一個**輸入處理器**這使得按需技能發現和載入成為可能。而不是預先將所有技能元資料註入系統提示符號（例如`SkillsProcessor`），它為Agent提供了兩個元Tool（`search_skills`和`load_skill`）讓它按需查找並加載技能。當Workspace具有許多技能時，這會減少上下文令牌的使用。

隱藏技能清單但保持標準`skill`, `skill_read`, and `skill_search` tools, use `SkillsProcessor` with `injectCatalog: false` instead. See [Turn off the skills list](/docs/sandbox/skills#turn-off-the-skills-list).

預設情況下，當您僅附加`SkillSearchProcessor` to an agent with a skill-enabled `Workspace`, the agent treats skills as on-demand:

* 預設急切`SkillsProcessor` isn't auto-added.
* `search_skills`和`load_skill` are exposed for discovery and instruction loading.
* 重疊`skill` and `skill_search` tools are hidden.
* `skill_read`保持可用，以便Agent可以讀取支援技能文件，例如參考、腳本和資產。

如果您明確配置`SkillsProcessor` alongside `SkillSearchProcessor`, the agent preserves the eager `skill` and `skill_search` tools as an opt-in path.

## 使用範例 {/* #usage-example */}

```typescript
import { SkillSearchProcessor } from '@mastra/core/processors'

const skillSearch = new SkillSearchProcessor({
  workspace,
  search: {
    topK: 5,
    minScore: 0.1,
  },
})
```

## 擴充使用範例 {/* #extended-usage-example */}

```typescript title="src/mastra/agents/skill-agent.ts"
import { Agent } from '@mastra/core/agent'
import { SkillSearchProcessor } from '@mastra/core/processors'
import { Workspace, LocalFilesystem } from '@mastra/core/workspace'

const workspace = new Workspace({
  filesystem: new LocalFilesystem({ basePath: './project' }),
  skills: ['skills'],
  bm25: true,
})

const skillSearch = new SkillSearchProcessor({
  workspace,
  search: {
    topK: 5,
    minScore: 0.1,
  },
})

const agent = new Agent({
  id: 'skill-agent',
  name: 'skill-agent',
  instructions:
    'You are a helpful assistant. Use search_skills to find relevant skills, then load_skill to load their instructions.',
  model: '__GATEWAY_OPENAI_MODEL__',
  workspace,
  inputProcessors: [skillSearch],
})
```

AgentWorkflow為：

1. Agent收到用戶訊息
2. Agent來電`search_skills` with keywords (e.g., "api design")
3. Agent檢討結果和通話`load_skill` with the skill name
4. 該技能的說明將在下一回合顯示為系統訊息
5. Agent遵循加載技能的指示

## Workspace文件Tool {/* #workspace-file-tools */}

`SkillSearchProcessor`將技能說明載入到對話中。它不會阻止Workspace檔案Tool讀取檔案。

使用`skill_read` for supporting files that belong to a loaded skill, such as files under `references/`, `scripts/`, or `assets/`.

保留Workspace文件Tool，例如`mastra_workspace_read_file` for explicit file inspection or editing workflows. During normal task execution, the agent doesn't need to read the same `SKILL.md` file after `load_skill` succeeds.

## 與技能處理器相比 {/* #compared-to-skillsprocessor */}

| |技能處理器 |技能搜尋處理器 |
| - | - | - |
|縮放|預先註入所有技能 |按需發現|
|上下文使用 |隨著技能數量的增加而增長 |恆定（僅加載技能）|
|AgentWorkflow |技能始終可見 |Agent根據需要進行搜尋和載入 |
|最適合 |技能很少 (\< 10) |許多技能（10+）|
