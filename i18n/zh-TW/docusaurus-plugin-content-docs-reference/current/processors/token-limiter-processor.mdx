# TokenLimiterProcessor

`TokenLimiterProcessor` 限制訊息中的 Token 數量。根據 `trimMode`，它可以充當提示處理器、輸入處理器或輸出處理器：

- **提示處理器**（`processLLMRequest`）：在預設的 `best-fit` 和 `contiguous` 裁剪模式下，每次模型呼叫前都會限制傳送給 Provider 的提示 Token 數量，覆蓋 Agent 執行迴圈的每一步。此前的提示處理器（例如 `ToolCallFilter`）完成轉換後才會計量，因此只統計實際傳給模型的 Token。工具呼叫與工具結果訊息會作為一組保留或移除；裁剪僅對本次請求生效，不修改已儲存的訊息。
- **輸入處理器**（`processInput`）：在 `memory-only` 裁剪模式下，於 Agent 執行迴圈開始前篩選歷史訊息，優先保留較新的訊息，使其適合上下文視窗
- **輸出處理器**：透過串流或非串流處理限制生成回覆的 Token 數量，並可設定超限處理策略

## 使用範例 {/* #usage-example */}

```typescript
import { TokenLimiterProcessor } from '@mastra/core/processors'

const processor = new TokenLimiterProcessor({
  limit: 1000,
  strategy: 'truncate',
  countMode: 'cumulative',
})
```

## 輸出流行為 {/* #output-stream-behavior */}

作為輸出處理器，只有承載生成輸出的部分會計入上限：`text-delta` 和 `object`。生命週期部分（例如 `step-start`）、推理增量、回應中繼資料以及工具部分（`tool-call`、`tool-result`）既不會計數，也不會被暫扣，因此工具呼叫始終會到達 Agent 執行迴圈並得到執行。

使用預設的 `truncate` 策略時，首次暫扣輸出時，處理器會在流中發出一個臨時的 `data-token-limit-reached` 部分：

```typescript oxfmt:false
for await (const part of stream.fullStream) {
  if (part.type === 'data-token-limit-reached') {
    console.log('output truncated at', part.data.limit, 'tokens')
  }
}
```

## 媒體 Token 計數 {/* #media-token-counting */}

圖片和檔案附件的 Token 數量透過估算得出，而非逐個分詞統計；這包括 `file` 訊息部分以及形如 `{ data, mediaType }` 的工具結果。圖片按每張固定值估算；其他媒體按解碼後的位元組數估算。遠端 URL 和 Provider 檔案 ID 因為無法在本地獲知大小，會使用固定的後備值。base64 等編碼載荷不會被當作文字計數，以免虛高的計數導致歷史記錄被不必要地裁剪。

## 錯誤行為 {/* #error-behavior */}

裁剪輸入時，`TokenLimiterProcessor` 會在以下情況下拋出 `TripWire` 錯誤：

- **訊息為空**：如果沒有可處理的非系統訊息，則拋出 TripWire，因為不能在沒有訊息的情況下傳送 LLM 請求。
- **系統訊息超限**：如果僅系統訊息就超過 Token 上限，則拋出 TripWire，因為不能只傳送系統訊息，而沒有使用者或助手訊息。
- **沒有訊息可容納**：如果剩餘 Token 預算容納不了任何訊息，則拋出 TripWire，因為不能傳送沒有訊息的 LLM 請求。

```typescript
import { TripWire } from '@mastra/core/agent'

try {
  await agent.generate('Hello')
} catch (error) {
  if (error instanceof TripWire) {
    console.log('Token limit error:', error.message)
  }
}
```

## 擴展範例 {/* #extended-usage-example */}

### 用作輸入處理器（限制上下文視窗） {/* #as-an-input-processor-limit-context-window */}

使用 `inputProcessors` 限制傳送給模型的歷史訊息數量，以保持在上下文視窗上限內：

```typescript title="src/mastra/agents/context-limited-agent.ts"
import { Agent } from '@mastra/core/agent'
import { Memory } from '@mastra/memory'
import { TokenLimiterProcessor } from '@mastra/core/processors'

export const agent = new Agent({
  id: 'context-limited-agent',
  name: 'context-limited-agent',
  instructions: 'You are a helpful assistant',
  model: '__GATEWAY_OPENAI_MODEL__',
  memory: new Memory({/* ... */}),
  inputProcessors: [
    new TokenLimiterProcessor({ limit: 4000 }), // Limits historical messages to ~4000 tokens
  ],
})
```

### 用作逐步處理器（限制多步驟 Token 增長） {/* #as-a-per-step-processor-limit-multi-step-token-growth */}

當 Agent 跨多個步驟使用工具時（例如 `maxSteps > 1`），每一步都會累積之前步驟的對話歷史。`TokenLimiterProcessor` 會在每一步實施上限，並在此前的提示處理器執行後，計量即將傳送的提示。要統計模型實際收到的提示，請將限制器註冊在 `ToolCallFilter` 等會縮短提示的處理器之後：

```typescript title="src/mastra/agents/multi-step-agent.ts"
import { Agent } from '@mastra/core/agent'
import { TokenLimiterProcessor } from '@mastra/core/processors'

export const agent = new Agent({
  id: 'multi-step-agent',
  name: 'multi-step-agent',
  instructions: 'You are a helpful research assistant with access to tools',
  model: '__GATEWAY_OPENAI_MODEL__',
  inputProcessors: [
    new TokenLimiterProcessor({ limit: 8000 }), // Applied at every step
  ],
})

// Each tool call step will be limited to ~8000 input tokens
const result = await agent.generate('Research this topic using your tools', {
  maxSteps: 10,
})
```

處理器 Workflow 不會執行 `processLLMRequest`。因此，放在處理器 Workflow 中的 `TokenLimiterProcessor` 會在 `processInputStep` 中裁剪已儲存的訊息，此時 `ToolCallFilter` 等提示處理器尚未從請求中移除內容。要統計模型實際收到的提示，請將限制器直接添加到 `inputProcessors`。

### 用作輸出處理器（限制回覆長度） {/* #as-an-output-processor-limit-response-length */}

使用 `outputProcessors` 限制生成回覆的長度：

```typescript title="src/mastra/agents/response-limited-agent.ts"
import { Agent } from '@mastra/core/agent'
import { TokenLimiterProcessor } from '@mastra/core/processors'

export const agent = new Agent({
  id: 'response-limited-agent',
  name: 'response-limited-agent',
  instructions: 'You are a helpful assistant',
  model: '__GATEWAY_OPENAI_MODEL__',
  outputProcessors: [
    new TokenLimiterProcessor({
      limit: 1000,
      strategy: 'truncate',
      countMode: 'cumulative',
    }),
  ],
})
```
