# BatchPartsProcessor

`BatchPartsProcessor` 是一種**輸出 Processor**，將多個串流片段合併後發送，以降低串流時的發送頻率。它可以減少網路負擔，並將較小的文字片段合併後呈現給使用者；你也可以控制發送時機，改善串流效能。

## 使用範例 {/* #usage-example */}

```typescript
import { BatchPartsProcessor } from '@mastra/core/processors'

const processor = new BatchPartsProcessor({
  batchSize: 5,
  maxWaitTime: 100,
  emitOnNonText: true,
})
```

## 擴充使用範例 {/* #extended-usage-example */}

```typescript title="src/mastra/agents/batched-agent.ts"
import { Agent } from '@mastra/core/agent'
import { BatchPartsProcessor } from '@mastra/core/processors'

export const agent = new Agent({
  id: 'batched-agent',
  name: 'batched-agent',
  instructions: 'You are a helpful assistant',
  model: '__GATEWAY_OPENAI_MODEL__',
  outputProcessors: [
    new BatchPartsProcessor({
      batchSize: 5,
      maxWaitTime: 100,
      emitOnNonText: true,
    }),
  ],
})
```
