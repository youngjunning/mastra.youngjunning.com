# AgentsMDInjector

`AgentsMDInjector` 會在模型步驟前載入目錄指令。它依時間由新到舊掃描訊息清單中已完成的 Tool 呼叫，並根據呼叫的路徑參數，在對應目錄及其上層目錄尋找 `AGENTS.md`、`CLAUDE.md` 或 `CONTEXT.md`。

```typescript
import { AgentsMDInjector } from '@mastra/core/processors'

const injector = new AgentsMDInjector({ maxTokens: 1000 })
```

將此處理器加入 Agent 的 `inputProcessors`。每次呼叫最多注入一則新的指令提醒，並將其儲存為持久化的 `reactive` 訊號。搜尋會略過已載入的路徑，直到找到尚未涵蓋的指令檔案。

## `ReminderFileReader` {/* #reminderfilereader */}

讀取器同時控制檔案存取及可選的路徑識別資訊。如果指令檔案位於虛擬檔案系統或可信任的 Git 參照，而非目前的 checkout，請透過 `getReader` 回傳對應的讀取器。

`getPathIdentity` 用於搜尋期間的去重、忽略靜態指令中的路徑，以及處理已儲存提醒的中繼資料或標記中的路徑。它不會改寫讀取位址、輸出的路徑、指令內容或儲存內容。它必須能處理先前提醒及目前 Tool 呼叫中的路徑，包括目前 checkout 中已不存在的檔案。

預設的本機讀取器會解析檔案系統別名以供比較。若在實例層級覆寫任何檔案系統操作，或使用未實作 `getPathIdentity` 的自訂讀取器，則只會依路徑文字比較，不會為識別路徑額外查詢主機檔案系統。

對於可信任的 Git 參照讀取器，應以標準專案根目錄及檔案相對於該目錄的路徑識別檔案。不要解析受 checkout 控制的下層符號連結：即使 checkout 讓可信任參照中的兩個不同檔案指向同一個實體檔案，兩者仍應視為不同檔案。

## 可見性與信任 {/* #visibility-and-trust */}

即使呼叫端使用[串流排除選項](/reference/streaming/agents/stream)隱藏提醒的訊號區塊，提醒仍會保留在模型脈絡和儲存內容中。排除選項不能作為指令的信任邊界。請透過 `isEnabled` 和可信任的讀取器控制是否載入 checkout 中的指令。
