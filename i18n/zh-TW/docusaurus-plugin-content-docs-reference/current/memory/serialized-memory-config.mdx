# SerializedMemoryConfig

`SerializedMemoryConfig` 是 [`Memory`](/reference/memory/memory-class) 設定中可序列化為 JSON 的部分，儲存在 Agent 紀錄中。執行時會將其還原為 `Memory` 執行個體，所需的向量儲存空間與嵌入模型 ID 則透過已設定的 `Mastra` 執行個體解析。

[`BuilderAgentDefaults.memory`](https://agent-builder.mastra.ai/reference/builder-agent-defaults) 和 `EditorAgentNamespace.create({ memory })` 都使用此型別。

## 使用範例 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { MastraEditor } from '@mastra/editor'

new MastraEditor({
  builder: {
    enabled: true,
    configuration: {
      agent: {
        memory: {
          observationalMemory: true,
          options: { lastMessages: 50 },
        },
      },
    },
  },
})
```
