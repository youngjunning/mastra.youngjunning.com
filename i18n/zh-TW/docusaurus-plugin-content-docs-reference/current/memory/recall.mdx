# 記憶體.recall()

這`Memory.recall()`方法從特定線程檢索訊息，支援分頁、過濾選項和語義搜尋。

## 使用範例 {/* #usage-example */}

```typescript
const { messages } = await memory.recall({
  threadId: 'thread-123',
  perPage: 20,
})
```

## 訊號可見度 {/* #signal-visibility */}

`hideSignals`過濾此呼叫傳回的訊息，而不是底層儲存或後續模型請求。普通訊息仍然可用。此選項不是安全邊界，並且不會更改訊號傳遞或持久性策略，例如`ifActive`, `ifIdle`, or `transient`.

### 預設值和優先權 {/* #defaults-and-precedence */}

| `hideSignals` | `includeSystemReminders` | Returned signals |
| - | - | - |
| Omitted | Omitted or `false` | Existing reminder-hidden history |
| Omitted | `true` | All signals |
| `false`或者`[]`|任意值 |所有訊號 |
|`true`|任意值 |沒有可辨識的訊號，包括遺留提醒|
|非空列表 |任意值 |除符合類型外的所有 |

不像[agent streams](/reference/streaming/agents/stream), recall continues to hide reminders by default for compatibility. The deprecated `includeSystemReminders` flag only applies when `hideSignals` is omitted.

```typescript
const all = await memory.recall({
  threadId: 'thread-123',
  hideSignals: false,
})

const withoutSignals = await memory.recall({
  threadId: 'thread-123',
  hideSignals: true,
})

const withoutReminders = await memory.recall({
  threadId: 'thread-123',
  hideSignals: ['reactive', 'system-reminder'],
})
```

### 儲存類型和遺留訊息 {/* #stored-types-and-legacy-messages */}

回憶匹配**exact stored type**, without alias normalization. For example, `['reactive']` doesn't exclude a row encoded as `system-reminder`, and `['user']` doesn't exclude one encoded as `user-message`. Modern streams and subscriptions normalize these aliases instead. Use `['reactive', 'system-reminder']` to exclude both reminder representations across these APIs.

中的公認類型`data-signal` or `data-user-message` part takes precedence over signal metadata and legacy reminder markers. Signal-role messages can also encode their type in `content.metadata.signal.type`. Unknown types and malformed signal parts don't match exclusions, including `hideSignals: true`.

如果不存在可識別的編碼類型，則按照現有舊提醒規則分類的訊息將被視為`system-reminder`, not `reactive`. These rules include user messages with `systemReminder` or `dynamicAgentsMdReminder` metadata, or a first text part starting with `<system-reminder`. Such rows remain visible with `['reactive']` and are excluded with `['system-reminder']`.

### 分頁和 API 範圍 {/* #pagination-and-api-scope */}

過濾發生在儲存查詢和分頁之後。一個頁面可以包含少於`perPage` messages, or none, without changing `total`, `hasMore`, or page offsets. Totals still describe the underlying query, not the filtered messages.

此選項適用於進程內`memory.recall()` calls. HTTP and client-js contracts don't expose `hideSignals` in this release.

## 元資料過濾 {/* #metadata-filtering */}

使用`filter.metadata` to match shallow scalar metadata stored on messages:

```typescript
const { messages } = await memory.recall({
  threadId: 'thread-123',
  filter: {
    metadata: {
      category: 'billing',
      escalated: true,
      priority: 2,
      archivedAt: null,
    },
  },
})
```

所有元資料條目均採用 AND 語意組合。訊息必須以精確的類型相等性來匹配每個鍵和值。`null` matches metadata that's explicitly set to `null`. It doesn't match a missing key.

元資料過濾器僅支援淺標量值：`string`, finite `number`, `boolean`, and `null`. Nested objects, arrays, `NaN`, and infinities aren't supported. Metadata keys must start with a letter or underscore and contain only alphanumeric or underscore characters. The limit is 128 characters. Reserved prototype keys such as `__proto__`, `constructor`, and `prototype` aren't allowed. Performance depends on the storage backend. Arbitrary metadata filters may require scanning candidate messages, so narrow the query with `threadId`, `resourceId`, or `dateRange` when possible.

## 擴充使用範例 {/* #extended-usage-example */}

```typescript title="src/test-memory.ts"
import { mastra } from './mastra'

const agent = mastra.getAgent('agent')
const memory = await agent.getMemory()

// Retrieve messages with pagination
const { messages } = await memory!.recall({
  threadId: 'thread-123',
  perPage: 50,
  vectorSearchString: 'What messages are there?',
  include: [
    {
      id: 'msg-123',
    },
    {
      id: 'msg-456',
      withPreviousMessages: 3,
      withNextMessages: 1,
    },
  ],
  threadConfig: {
    semanticRecall: true,
  },
})

console.log(messages) // MastraDBMessage[]

// Fetch all messages without pagination
const allMessages = await memory!.recall({
  threadId: 'thread-123',
  perPage: false, // Fetch all
})

// Convert to AI SDK format if needed
import { toAISdkV5Messages } from '@mastra/ai-sdk/ui'
const uiMessages = toAISdkV5Messages(messages)
```
