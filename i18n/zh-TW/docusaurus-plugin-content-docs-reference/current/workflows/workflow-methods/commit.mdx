# Workflow.commit()

`.commit()` 會定稿 Workflow 定義，讓它可以執行。請在加入步驟之後、建立執行個體之前呼叫。若仍有尚未提交的步驟變更，建立執行個體時會擲出錯誤。

## 使用範例 {/* #usage-example */}

```typescript
workflow.then(step1).commit()
```
