# Workflow.commit()

這`.commit()`方法最終確定Workflow定義並準備執行。新增步驟之後、建立運行之前調用它。在具有未提交步驟變更的Workflow上建立執行會引發錯誤。

## 使用範例 {/* #usage-example */}

```typescript
workflow.then(step1).commit()
```
