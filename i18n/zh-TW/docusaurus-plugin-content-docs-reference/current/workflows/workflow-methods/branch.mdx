# Workflow\.branch()

`.branch()` 方法在 Workflow 步驟之間建立條件分支，可依上一步結果選擇不同路徑。所有條件為 `true` 的分支都會執行；各條件獨立求值，因此重疊條件會執行多個分支。只應執行一個分支時，請使用互斥條件。

## 使用範例 {/* #usage-example */}

```typescript
workflow.branch([
  [async () => true, step1],
  [async () => false, step2],
])
```
