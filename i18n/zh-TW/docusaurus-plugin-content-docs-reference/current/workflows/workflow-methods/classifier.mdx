# Workflow\.classifier()

`.classifier()` 方法將已設定的 [`Classifier`](/reference/classifier/classifier) 加入為宣告式 Workflow 步驟，並傳回可繼續鏈式呼叫的 Workflow。此步驟輸出可安全序列化為 JSON 的 `{ answers, usage }` 物件，供後續步驟和 [`.branch()`](/reference/workflows/workflow-methods/branch) 等現有控制流程方法使用。

## 使用範例 {/* #usage-example */}

```typescript filename="src/mastra/workflows/ticket-triage.ts"
import { createWorkflow } from '@mastra/core/workflows'
import { z } from 'zod'

const workflow = createWorkflow({
  id: 'ticket-triage',
  inputSchema: z.object({ message: z.string() }),
  outputSchema: z.any(),
})
  .map({ message: { initData: true, path: 'message' } })
  .classifier(router)
  .branch([
    [async ({ inputData }) => inputData.answers.route.choice === 'billing', billingStep],
    [async ({ inputData }) => inputData.answers.route.choice === 'support', supportStep],
    [async () => true, fallbackStep],
  ])
  .commit()
```

傳入 Classifier 實例後，下游步驟可推斷問題鍵與選項的字面值型別。Classifier 的問題必須在建構時設定。

## 輸入映射 {/* #input-mapping */}

Classifier 會評估前一步驟的完整輸出。可加入 [`.map()`](/reference/workflows/workflow-methods/map) 並置於 `.classifier()` 之前，以選取或調整輸入結構。

```typescript
workflow
  .map({
    message: { initData: true, path: 'message' },
    locale: { initData: true, path: 'locale' },
  })
  .classifier(router)
```

映射使用與其他 Workflow 步驟相同、經過驗證的路徑語法，並保留在序列化後的 Workflow 圖中。

## 輸出 {/* #output */}

* 選項類答案透過 `answers.<question>.choice` 提供結果，也可能包含 `probabilities`。
* 評分類答案透過 `answers.<question>.score` 提供結果，也可能包含 `probabilities`。
* 布林類答案將原始 `P(true)` 值作為 `answers.<question>.probability` 傳回。用於路由時須明確設定門檻。
* 遭拒答的問題會傳回 `{ type: 'refusal' }`，不含 `choice`、`score` 或 `probability`。
* `usage` 包含標準化的 token 用量。

## 重試和錯誤 {/* #retries-and-errors */}

`maxRetries` 控制 Classifier 模型呼叫的重試次數。`retries` 控制 Workflow 步驟的重試次數。Workflow 的中止訊號會傳給 Classifier；Classifier 發生錯誤會使步驟失敗。`.classifier()` 不採用故障時放行的行為。

## 透過 ID 引用分類器 {/* #referencing-a-classifier-by-id */}

將 Classifier 註冊在執行該 Workflow 的同一個 `Mastra` 實例上：

```typescript filename="src/mastra/index.ts"
import { Mastra } from '@mastra/core'

export const mastra = new Mastra({
  classifiers: { router },
  workflows: { workflow },
})
```

使用具型別的字串參照時，請明確指定已設定的問題型別：

```typescript
workflow.classifier<typeof router.questions>('router')
```
