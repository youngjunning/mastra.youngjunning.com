# Workflow.agent()

這`.agent()`方法新增Agent程式作為聲明性步驟。該步驟接受`{ prompt: string }`作為輸入和返回`{ text: string }`預設情況下。使用`.map()`在Agent根據Workflow資料建立提示之前。

與包裝Agent不同`createStep()`, `.agent()` records a declarative entry in the workflow graph. This makes the workflow portable: the same graph can be serialized and persisted as a [dynamic workflow](/docs/workflows/dynamic-workflows).

## 使用範例 {/* #usage-example */}

```typescript filename="src/mastra/workflows/test-workflow.ts"
workflow
  .map({ prompt: mapVariable({ initData: workflow, path: 'topic' }) })
  .agent(testAgent)
  .commit()
```

## 結構化輸出 {/* #structured-output */}

預設情況下，該步驟的輸出是`{ text: string }`. Pass `structuredOutput.schema` to make the step return that shape instead. The schema becomes the step's output schema, so later steps chain against it with full type safety:

```typescript filename="src/mastra/workflows/test-workflow.ts"
import { z } from 'zod'

workflow
  .agent(testAgent, {
    structuredOutput: {
      schema: z.object({
        subtopics: z.array(z.string()),
      }),
    },
  })
  .commit()
```

## 透過 ID 引用Agent {/* #referencing-an-agent-by-id */}

傳遞一個字串來引用已註冊的Agent程式而不導入它。當Workflow運行時，Agent必須在 Mastra 實例上註冊：

```typescript filename="src/mastra/workflows/test-workflow.ts"
workflow.agent('test-agent', { maxSteps: 3 }).commit()
```

## 持久Agent步驟 {/* #persisting-agent-steps */}

Workflow構建`.agent()` serialize to the same declarative entries that [dynamic workflows](/docs/workflows/dynamic-workflows) use. Only `structuredOutput.schema` (stored as JSON Schema), `retries`, and `metadata` round-trip through storage. Options that hold functions, such as `onFinish` or a function-valued `toolChoice`, throw an error when the workflow is stored.
