# Workflow\.agent()

`.agent()` 方法會將 Agent 加入為宣告式步驟。步驟接受 `{ prompt: string }` 作為輸入，預設傳回 `{ text: string }`。如需根據 Workflow 資料建立 prompt，請在 Agent 步驟之前使用 `.map()`。

與使用 `createStep()` 封裝 Agent 不同，`.agent()` 會在 Workflow 圖中記錄宣告式項目。因此，相同的圖可以序列化，並作為[動態 Workflow](/docs/workflows/dynamic-workflows) 持久化。

## 使用範例 {/* #usage-example */}

```typescript filename="src/mastra/workflows/test-workflow.ts"
workflow
  .map({ prompt: mapVariable({ initData: workflow, path: 'topic' }) })
  .agent(testAgent)
  .commit()
```

## 結構化輸出 {/* #structured-output */}

步驟預設輸出 `{ text: string }`。傳入 `structuredOutput.schema` 後，步驟會改為傳回該 schema 指定的結構。此 schema 亦會成為步驟的輸出 schema，讓後續步驟在完整的型別檢查下串接：

```typescript filename="src/mastra/workflows/test-workflow.ts"
import { z } from 'zod'

workflow
  .agent(testAgent, {
    structuredOutput: {
      schema: z.object({
        subtopics: z.array(z.string()),
      }),
    },
  })
  .commit()
```

## 透過 ID 參照 Agent {/* #referencing-an-agent-by-id */}

傳入字串即可參照已註冊的 Agent，無須匯入其實例。Workflow 執行時，該 Agent 必須已在 Mastra 實例註冊：

```typescript filename="src/mastra/workflows/test-workflow.ts"
workflow.agent('test-agent', { maxSteps: 3 }).commit()
```

## 持久化 Agent 步驟 {/* #persisting-agent-steps */}

使用 `.agent()` 建立的 Workflow 會序列化為與[動態 Workflow](/docs/workflows/dynamic-workflows) 相同的宣告式項目。只有 `structuredOutput.schema`（以 JSON Schema 儲存）、`retries` 和 `metadata` 能在儲存後還原。儲存 Workflow 時，包含函式的選項（例如 `onFinish` 或值為函式的 `toolChoice`）會發生錯誤。
