# Workflow.dowhile()

這`.dowhile()`方法在滿足條件時執行步驟。在評估條件之前，它始終至少運行該步驟一次。第一次評估條件時，`iterationCount`是`1`.

## 使用範例 {/* #usage-example */}

```typescript
workflow.dowhile(step1, async ({ inputData }) => true)
```
