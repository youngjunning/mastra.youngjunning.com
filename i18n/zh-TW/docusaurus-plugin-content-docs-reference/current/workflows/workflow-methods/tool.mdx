# Workflow.Tool()

這`.tool()`方法新增一個Tool作為聲明性步驟。應用Tool本身的輸入和輸出模式，因此上一步驟的輸出必須滿足Tool的輸入模式。使用`.map()`如果資料不匹配，則轉換資料。

與包裝Tool不同`createStep()`, `.tool()` records a declarative entry in the workflow graph. This makes the workflow portable: the same graph can be serialized and persisted as a [dynamic workflow](/docs/workflows/dynamic-workflows).

## 使用範例 {/* #usage-example */}

```typescript filename="src/mastra/workflows/test-workflow.ts"
workflow.tool(testTool).commit()
```

## 透過 ID 引用Tool {/* #referencing-a-tool-by-id */}

傳遞一個字串來引用已註冊的Tool而不導入它。當Workflow運行時，必須在 Mastra 實例上註冊該Tool：

```typescript filename="src/mastra/workflows/test-workflow.ts"
workflow.tool('lookup-customer', { retries: 2 }).commit()
```

## 保留Tool步驟 {/* #persisting-tool-steps */}

Workflow構建`.tool()` serialize to the same declarative entries that [dynamic workflows](/docs/workflows/dynamic-workflows) use. Only `retries` and `metadata` round-trip through storage. A function-valued `scorers` option throws an error when the workflow is stored.
