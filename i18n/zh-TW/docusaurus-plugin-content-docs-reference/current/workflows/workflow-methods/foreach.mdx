# Workflow.foreach()

`.foreach()` 方法會建立迴圈，對陣列中的每個項目執行一個步驟。它一律傳回各次迭代輸出組成的陣列，並保留輸入項目的原始順序。

## 使用範例 {/* #usage-example */}

```typescript
workflow.foreach(step1, { concurrency: 2 })
```

## 行為 {/* #behavior */}

### 執行與等待 {/* #execution-and-waiting */}

不論並行設定為何，`.foreach()` 都會先處理完所有項目，再執行下一個步驟。預設的 `concurrency: 1` 會依序處理項目；較大的值會分批並行處理，但下一個步驟仍須等待所有批次完成。

如果每個項目都需要執行多項操作，請以巢狀 Workflow 作為步驟。這樣可將同一項目的操作放在一起，比串接多個 `.foreach()` 呼叫更清楚。範例請參閱 [foreach 中的巢狀 Workflow](/docs/workflows/control-flow#nested-workflows-inside-foreach)。

### 輸出結構 {/* #output-structure */}

`.foreach()` 一律輸出陣列。輸出陣列中的每個元素，對應輸入陣列中相同索引項目的處理結果。

```typescript
// Input: [{ value: 1 }, { value: 2 }, { value: 3 }]
// Step adds 10 to each value
// Output: [{ value: 11 }, { value: 12 }, { value: 13 }]
```

### 在 `.foreach()` 後使用 `.then()` {/* #using-then-after-foreach */}

在 `.foreach()` 後串接 `.then()` 時，下一個步驟會收到整個輸出陣列作為輸入。您可以在該步驟彙總或一併處理所有結果。

```typescript
workflow
  .foreach(processItemStep) // Output: array of processed items
  .then(aggregateStep) // Input: the entire array
  .commit()
```

### 在 `.foreach()` 後使用 `.map()` {/* #using-map-after-foreach */}

使用 `.map()` 轉換輸出陣列，再將結果傳給下一個步驟：

```typescript
workflow
  .foreach(processItemStep)
  .map(async ({ inputData }) => ({
    total: inputData.reduce((sum, item) => sum + item.value, 0),
    count: inputData.length,
  }))
  .then(nextStep)
  .commit()
```

### 串接多個 `.foreach()` 呼叫 {/* #chaining-multiple-foreach-calls */}

串接多個 `.foreach()` 呼叫時，每次呼叫都會處理前一步輸出的陣列：

```typescript
workflow
  .foreach(stepA) // If input is [a, b, c], output is [A, B, C]
  .foreach(stepB) // Operates on [A, B, C], output is [A', B', C']
  .commit()
```

如果 `.foreach()` 內的步驟傳回陣列，整體輸出就會是陣列的陣列。使用 `.map()` 搭配 `.flat()` 將其攤平：

```typescript
workflow
  .foreach(chunkStep) // Output: [[chunk1, chunk2], [chunk3, chunk4]]
  .map(async ({ inputData }) => inputData.flat()) // Output: [chunk1, chunk2, chunk3, chunk4]
  .foreach(embedStep)
  .commit()
```

### 串流期間的進度事件 {/* #progress-events-during-streaming */}

使用 `run.stream()` 時，foreach 步驟會在每次迭代完成後發出 `workflow-step-progress` 事件。您無須等待整個 foreach 完成，就能即時追蹤進度。

```typescript
const run = await workflow.createRun()
const stream = run.stream({ inputData })

for await (const chunk of stream) {
  if (chunk.type === 'workflow-step-progress') {
    console.log(`${chunk.payload.completedCount}/${chunk.payload.totalCount}`)
    // e.g. "1/3", "2/3", "3/3"
  }
}
```

### 恢復單次迭代 {/* #resuming-a-single-iteration */}

當 `.foreach()` 內的步驟暫停時，各次迭代會個別暫停。將 `forEachIndex` 傳入 [`run.resume()`](../run-methods/resume)，即可使用各自的 `resumeData`，一次恢復一項迭代。省略 `forEachIndex` 則會以相同資料恢復所有已暫停的迭代。

```typescript
await run.resume({
  step: 'approve',
  resumeData: { ok: true },
  forEachIndex: 1,
})
```
