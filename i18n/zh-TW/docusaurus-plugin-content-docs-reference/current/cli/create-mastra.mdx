# create-mastra

建立獨立的 Mastra 專案。預設情況下，`create-mastra` 會安裝預設起始專案，並依所選模型 Provider 完成設定。

```bash npm2yarn
npx create-mastra@latest
```

## 建立方式 {/* #creation-modes */}

### 預設起始專案 {/* #default-starter */}

預設起始專案會建立 Agent 執行框架，包含 Workspace 工具、記憶、任務追蹤、網頁存取、週期排程、儲存與可觀測性。你可以選擇 Mastra Gateway、OpenAI、Anthropic、Gemini 或 xAI 作為模型 Provider。

同時提供專案名稱與 Provider，即可略過互動提示建立專案。此範例使用 Anthropic；你也可以傳入 `openai`、`google`、`xai` 或 `mastra`。若使用 `mastra`，還需傳入 `--llm-api-key` 才能略過瀏覽器登入；請參閱 [Mastra Gateway](#mastra-gateway)：

```bash npm2yarn
npx create-mastra@latest my-mastra-project --llm anthropic
```

省略 `--llm` 可透過互動方式選擇 Provider，並可選擇輸入其 API 金鑰。互動設定也會詢問是否將專案連結至 Mastra 平台。啟用後，指令會在瀏覽器開啟驗證流程，建立與本機專案同名的平台專案，再將 `MASTRA_PLATFORM_ACCESS_TOKEN` 與 `MASTRA_PROJECT_ID` 寫入 `.env`。

### Mastra Gateway {/* #mastra-gateway */}

選擇 **Mastra Gateway**，即可使用同一把金鑰呼叫所有模型。指令會開啟瀏覽器供你登入 Mastra，建立 Gateway API 金鑰，並將其寫入 `.env`，變數名稱為 `MASTRA_GATEWAY_API_KEY`。Agent 使用的模型名稱以 `mastra/` 為前綴，例如 `mastra/openai/gpt-6.1-sol`。

模型呼叫會依 token 數量從 Gateway 點數扣款。若餘額為 $0，指令會提供開啟 Mastra 控制台 Add credits 頁面的選項；你可以選擇儲值金額，也可啟用自動儲值。設定程序會在你操作時繼續，最後的摘要也會再次提供該頁面的連結。

若要不登入而使用現有 Gateway 金鑰，請透過 `--llm-api-key` 傳入：

```bash npm2yarn
npx create-mastra@latest my-mastra-project --llm mastra --llm-api-key <your-gateway-key>
```

### 範本 {/* #template */}

使用範本 slug 或公開的 GitHub URL：

```bash npm2yarn
npx create-mastra@latest my-mastra-project --template agent-harness
```

```bash npm2yarn
npx create-mastra@latest my-mastra-project --template https://github.com/mastra-ai/template-agent-harness
```

不填寫範本值，即可透過互動方式選擇範本：

```bash npm2yarn
npx create-mastra@latest my-mastra-project --template
```

範本作者自行管理其相依套件、模型、環境變數與原始碼。`create-mastra` 不會套用 `--llm` 或 `--llm-api-key`。

### 空白專案骨架 {/* #empty-scaffold */}

使用 `--empty` 建立不含 Provider、Agent、範例、模型 SDK 或環境檔案的專案：

```bash npm2yarn
npx create-mastra@latest my-empty-project --empty
```

## 自動設定 {/* #automatic-setup */}

安裝相依套件後，指令會：

1. 偵測 `PATH` 中受支援的程式開發助理，並安裝 Mastra Skills。若未偵測到，則安裝通用 Skills。
1. 若目前目錄與產生的專案都不在 Git 儲存庫內，則建立初始 Git 提交。

使用 `--no-skills` 或 `--no-git` 可略過對應步驟。Skills 或 Git 設定失敗只會顯示警告，不會刪除已成功建立的專案。

## 衝突和驗證 {/* #conflicts-and-validation */}

- `--empty` 與 `--template` 不能同時使用。
- `--llm` 與 `--llm-api-key` 僅適用於預設起始專案。
- 專案名稱必須是安全的小寫單層目錄名稱，且目標目錄不能已存在。

建立任何專案檔案前，指令會拒絕無效的選項、專案名稱與 GitHub URL。未知的範本名稱會在擷取範本清單後遭拒絕，CLI 隨後會列出可用範本。

## 遙測 {/* #telemetry */}

Mastra 會收集匿名的 CLI 使用資訊，例如作業系統、Mastra 版本與 Node.js 版本。你可以查看[分析功能原始碼](https://github.com/mastra-ai/mastra/blob/main/packages/cli/src/analytics/index.ts)。

設定 `MASTRA_TELEMETRY_DISABLED=1` 可停用遙測：

```bash
MASTRA_TELEMETRY_DISABLED=1 npx create-mastra@latest my-project --empty
```
