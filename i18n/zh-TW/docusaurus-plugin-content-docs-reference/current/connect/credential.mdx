# 憑證（）

取得平台連接的原始憑證，用於產生的Tool集未涵蓋的自訂交互，例如您自己驅動Provider SDK 或 MCP 伺服器。

```typescript
import { credential } from '@mastra/connect'

const cred = await credential('c_yourconnectionid')

if (cred.type === 'oauth2') {
  startSdkSession(cred.accessToken)
} else if (cred.type === 'api_key') {
  startSdkSession(cred.apiKey)
} else if (cred.type === 'two_step') {
  startSdkSession(cred.token)
}
```

返回：`Promise<ConnectionCredential>`, a discriminated union:

```typescript
type ConnectionCredential =
  | {
      type: 'oauth2'
      accessToken: string
      expiresAt: string | null
      secondaryAccessTokens?: Record<string, { accessToken: string; expiresAt: string | null }>
    }
  | { type: 'api_key'; apiKey: string }
  | { type: 'two_step'; token: string; expiresAt: string | null }
```

OAuth2 憑證可以包括`secondaryAccessTokens` for additional API audiences, keyed by the provider's connection-config field name. Each token has its own expiry.

大多數應用程式應該更喜歡[`tools()`](/reference/connect/tools), which keeps credentials entirely on the platform.

## 憑證處理 {/* #credential-handling */}

傳回的憑證授予對Provider帳戶的直接存取權並繞過Agent程式的護欄。不要記錄它們或將它們嵌入Agent輸出中。 OAuth2 和`two_step` tokens can expire. Check their `expiresAt` fields, including those of secondary access tokens, and re-fetch the credential when needed.

使用此函數不支援的憑證類型的連線（例如基本驗證）會拋出例外`unsupported_credential_type`.

## 錯誤 {/* #errors */}

投擲`MastraConnectError` with a `code` property:

|程式碼|當 |
| - | - |
|`invalid_options` | An option is invalid, for example an empty `resourceId` or one longer than 256 characters after trimming |
| `missing_access_token` | No platform token configured |
| `connection_not_found` | The connection doesn't exist or isn't accessible |
| `unsupported_credential_type` | The connection's credential type can't be returned |
| `unauthorized`|平台拒絕代幣 (401/403) |
|`platform_error`|任何其他平台回應失敗：非 2xx 狀態或無法解析的正文。網路層級獲取失敗不會被包裝並顯示為運行時自身的錯誤，而不會出現`code` |
