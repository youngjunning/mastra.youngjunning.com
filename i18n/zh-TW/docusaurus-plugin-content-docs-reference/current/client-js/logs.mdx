# 日誌API

日誌 API 提供了存取和查詢 Mastra 中的系統日誌和偵錯資訊的方法。

## 取得日誌 {/* #getting-logs */}

使用選用過濾檢索系統日誌：

```typescript
const logs = await mastraClient.listLogs({
  transportId: 'transport-1',
})
```

## 取得特定運行的日誌 {/* #getting-logs-for-a-specific-run */}

檢索特定執行運行的日誌：

```typescript
const runLogs = await mastraClient.getLogForRun({
  runId: 'run-1',
  transportId: 'transport-1',
})
```
