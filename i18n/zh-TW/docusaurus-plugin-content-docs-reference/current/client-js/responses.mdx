# OpenAI 回應 API

這個與 OpenAI 相容、由 Agent 支援的介面，讓你能透過回應 API 使用 Mastra Agent。它提供透過 Mastra Agent 建立、擷取、串流傳輸及刪除回應的方法。

這些路由是以 Mastra Agent、記憶及儲存機制為基礎的轉接介面。使用 `agent_id` 選擇處理請求的 Mastra Agent。你可以傳入 `model`，針對單次請求覆寫 Agent 設定的模型；省略時則使用 Agent 已設定的模型。

已儲存的回應也會傳回 `conversation_id`。在 Mastra 中，這是記憶中的原始 `threadId`。

此 API 目前仍在實驗階段。

## 使用範例 {/* #usage-example */}

```typescript
import { MastraClient } from '@mastra/client-js'

const client = new MastraClient({
  baseUrl: 'http://localhost:4111',
})

const response = await client.responses.create({
  agent_id: 'support-agent',
  input: 'Summarize this ticket',
  store: true,
})

console.log(response.output_text)
```

## 方法 {/* #methods */}

### 生命週期 {/* #lifecycle */}

#### `create(params)` {/* #createparams */}

建立回應。

```typescript
const response = await client.responses.create({
  agent_id: 'support-agent',
  input: 'Summarize this ticket',
})
```

**傳回：** 省略 `stream` 或將其設為 `false` 時，傳回 `Promise<ResponsesResponse>`。

設定 `stream: true` 時，`create()` 會傳回由 SSE 格式事件資料組成的非同步可迭代物件：

```typescript
const stream = await client.responses.create({
  agent_id: 'support-agent',
  input: 'Summarize this ticket',
  stream: true,
})

for await (const event of stream) {
  if (event.type === 'response.output_text.delta') {
    process.stdout.write(event.delta)
  }
}
```

串流回應也可能包含 Tool 事件。Tool 呼叫串流會使用 `response.output_item.added`、`response.function_call_arguments.delta`、`response.function_call_arguments.done` 和 `response.output_item.done` 事件。Tool 結果會以 `function_call_output` 項目呈現，其 ID 為 `<toolCallId>:output`。

**傳回：** `Promise<ResponsesStream>`。

#### `retrieve(responseId, requestContext?)` {/* #retrieveresponseid-requestcontext */}

擷取已儲存的回應。

```typescript
const response = await client.responses.retrieve('msg_123')
```

**傳回：** `Promise<ResponsesResponse>`。

#### `delete(responseId, requestContext?)` {/* #deleteresponseid-requestcontext */}

刪除已儲存的回應。

```typescript
const deleted = await client.responses.delete('msg_123')
```

**傳回：** `Promise<{ id: string; object: "response"; deleted: true }>`

#### `stream(params)` {/* #streamparams */}

建立串流回應。

```typescript
const stream = await client.responses.stream({
  agent_id: 'support-agent',
  input: 'Say hello',
})

for await (const event of stream) {
  console.log(event.type)
}
```

**傳回：** `Promise<ResponsesStream>`。

## 已儲存的回應與對話 {/* #stored-responses-and-conversations */}

已儲存的回應同時包含 `response.id` 與 `conversation_id`。

* `response.id` 是回應 ID。對於已儲存且由 Agent 支援的回應，這是持久儲存的助理訊息 ID。
* `conversation_id` 是 Mastra 的原始執行緒 ID。

若要從先前已儲存的回應繼續，請使用 `previous_response_id`。若要直接指定已知的執行緒，請使用 `conversation_id`。

```typescript
const first = await client.responses.create({
  agent_id: 'support-agent',
  input: 'Start a support thread',
  store: true,
})

const second = await client.responses.create({
  agent_id: 'support-agent',
  conversation_id: first.conversation_id!,
  input: 'Add a follow-up to the same thread',
  store: true,
})
```

若要直接建立、擷取、刪除或檢視底層的 OpenAI 回應 API 對話，請使用 [`client.conversations`](/reference/client-js/conversations)。

## 函數呼叫（Tool） {/* #function-calling-tools */}

`response.tools` 包含此請求可使用的函式定義。

如果模型呼叫函式，該呼叫會與最終的助理 `message` 一起，以 `function_call` 和 `function_call_output` 項目的形式出現在 `response.output` 中。

設定 `stream: true` 時，函式呼叫也會以回應串流事件的形式送出。從 `response.function_call_arguments.delta` 事件讀取部分參數片段；若要取得最終參數內容與 Tool 名稱，優先使用 `response.function_call_arguments.done`。從 `response.output_item.done` 事件讀取已完成的 `function_call` 與 `function_call_output` 項目。Tool 輸出項目的 ID 為 `<toolCallId>:output`。

## 結構化輸出 {/* #structured-output */}

需要 JSON 輸出時，請使用 `text.format`。

* `json_object` 啟用 JSON 模式。
* `json_schema` 啟用受 schema 約束的結構化輸出。

兩種格式都會在助理訊息內容中傳回 JSON。需要嚴格執行 schema 約束時，請使用 `json_schema`；只需要有效的 JSON 輸出時，請使用 `json_object`。

```typescript
const response = await client.responses.create({
  agent_id: 'support-agent',
  input: 'Return a structured support ticket summary.',
  text: {
    format: {
      type: 'json_schema',
      name: 'ticket_summary',
      schema: {
        type: 'object',
        properties: {
          summary: { type: 'string' },
          priority: { type: 'string' },
        },
        required: ['summary', 'priority'],
        additionalProperties: false,
      },
    },
  },
})
```

## Provider支援的請求 {/* #provider-backed-requests */}

需要傳入 Mastra 未在回應層統一處理的 Provider 專屬選項時，請使用 `providerOptions`。

```typescript
const response = await client.responses.create({
  agent_id: 'support-agent',
  input: 'Continue this exchange',
  providerOptions: {
    openai: {
      previousResponseId: 'resp_123',
    },
  },
})
```

## 回應結構 {/* #response-shape */}

傳回的回應物件包含：

* `id`：回應 ID
* `output`：輸出項目，例如助理 `message`、`function_call` 和 `function_call_output`
* `output_text`：將助理文字輸出串接起來的便捷取值屬性
* `tools`：為此請求設定的 Tool 定義
* `conversation_id`：已儲存回應的原始執行緒 ID
* `text`：請求指定的文字輸出格式（如有）
