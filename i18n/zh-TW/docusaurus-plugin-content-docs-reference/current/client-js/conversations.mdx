# OpenAI Responses API Conversations

OpenAI Responses API Conversations 介面以 Responses API 形式提供 Mastra Agent 的對話管理功能，可在 Mastra 中建立、取得、刪除及檢視以執行緒為基礎的對話。

此 API 是 [OpenAI Responses API](/reference/client-js/responses) 的延伸。已儲存的 Responses 呼叫會回傳 `conversation_id`；在 Mastra 中，這個值就是記憶系統的原始 `threadId`。如需直接操作該執行緒，請使用 `client.conversations`。

此 API 目前仍處於實驗階段。

## 與 OpenAI Responses 的關係 {/* #relationship-to-openai-responses */}

使用 OpenAI Responses API 產生內容並延續對話：

```typescript
const response = await client.responses.create({
  agent_id: 'support-agent',
  input: 'Start a support thread',
  store: true,
})

console.log(response.conversation_id)
```

如需檢視或管理已儲存的執行緒，請使用 Conversations API：

```typescript
const conversation = await client.conversations.retrieve(response.conversation_id!)
const items = await client.conversations.items.list(response.conversation_id!)
```

## 使用範例 {/* #usage-example */}

```typescript
import { MastraClient } from '@mastra/client-js'

const client = new MastraClient({
  baseUrl: 'http://localhost:4111',
})

const conversation = await client.conversations.create({
  agent_id: 'support-agent',
})

console.log(conversation.id)
```

## 方法 {/* #methods */}

### 生命週期 {/* #lifecycle */}

#### `create(params)` {/* #createparams */}

為指定的 Agent 建立新的對話執行緒。

```typescript
const conversation = await client.conversations.create({
  agent_id: 'support-agent',
  title: 'Billing support',
})
```

**回傳：** `Promise<Conversation>`。

#### `retrieve(conversationId, requestContext?)` {/* #retrieveconversationid-requestcontext */}

透過執行緒 ID 取得對話。

```typescript
const conversation = await client.conversations.retrieve('thread_123')

console.log(conversation.thread)
```

**回傳：** `Promise<Conversation>`。

#### `delete(conversationId, requestContext?)` {/* #deleteconversationid-requestcontext */}

透過執行緒 ID 刪除對話。

```typescript
const deleted = await client.conversations.delete('thread_123')

console.log(deleted.deleted)
```

**回傳：** `Promise<ConversationDeleted>`。

### 對話項目 {/* #items */}

#### `items.list(conversationId, requestContext?)` {/* #itemslistconversationid-requestcontext */}

列出對話中已儲存的項目。

```typescript
const items = await client.conversations.items.list('thread_123')

console.log(items.data)
```

**回傳：** `Promise<ConversationItemsPage>`。

## 回應結構 {/* #response-shape */}

`create()` 和 `retrieve()` 回傳包含以下欄位的對話物件：

- `id`：原始執行緒 ID
- `object`：固定為 `'conversation'`
- `thread`：已儲存的執行緒紀錄

`delete()` 回傳：

- `id`：原始執行緒 ID
- `object`：固定為 `'conversation.deleted'`
- `deleted`：固定為 `true`

`items.list()` 回傳：

- `object`：固定為 `'list'`
- `data`：對話項目，例如 `message`、`function_call` 和 `function_call_output`
- `first_id`：本頁第一個項目的 ID
- `last_id`：本頁最後一個項目的 ID
- `has_more`：目前固定為 `false`。`items.list()` 單次回應最多回傳 1000 個項目。
