# 圖爾索存儲

使用`@mastra/turso`將 Mastra Agent、Workflow、記憶體和其他儲存域儲存在本地[圖爾索資料庫](https://github.com/tursodatabase/turso)文件。

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/turso
```

## 用法 {/* #usage */}

```typescript
import { Mastra } from '@mastra/core/mastra'
import { TursoStore } from '@mastra/turso'

export const mastra = new Mastra({
  storage: new TursoStore({
    id: 'local-storage',
    path: './mastra.db',
  }),
})
```

## 建構函數選項 {/* #constructor-options */}

* `id`（必需）：儲存實例的唯一識別碼。
* `path`（必需，除非`client` is provided): Path to the local database file.
* `client`：使用相容的 SQLite 用戶端，而不是建立本機 Turso 用戶端。
* `readonly`：以唯讀模式開啟資料庫。
* `fileMustExist`：打開資料庫檔案之前要求其存在。
* `timeout`：連線超時（以毫秒為單位）。
* `defaultQueryTimeout`：預設查詢超時時間（以毫秒為單位）。
* `tracing`：本機驅動程式追蹤等級：`info`, `debug`, or `trace`.
* `experimental`：啟用本機 Turso 資料庫實驗功能。
* `maxRetries`：可重試寫入的最大重試次數。
* `initialBackoffMs`：初始重試延遲（以毫秒為單位）。
* `disableInit`：停用自動儲存初始化。
* `retention`：支援的儲存域的保留策略。

## 平台支援 {/* #platform-support */}

本機驅動程式支援arm64上的macOS、x64上的Windows以及x64和arm64上基於glibc的Linux。使用`getTursoDatabaseSupport()` when your application needs to choose a fallback on unsupported systems.

```typescript
import { getTursoDatabaseSupport } from '@mastra/turso'

const support = getTursoDatabaseSupport()
if (!support.supported) {
  console.warn(support.reason)
}
```

## 實驗特點 {/* #experimental-features */}

預設情況下停用實驗性 Turso 資料庫功能。僅啟用您的應用程式所需的功能。

```typescript
const storage = new TursoStore({
  id: 'multiprocess-storage',
  path: './mastra.db',
  experimental: ['multiprocess_wal'],
})
```

`@mastra/turso`提供本地檔案 Mastra 儲存。它不連接到遠端 libSQL 資料庫，也不包含向量儲存。
