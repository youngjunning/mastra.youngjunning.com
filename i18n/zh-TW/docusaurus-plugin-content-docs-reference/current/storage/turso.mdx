# Turso 儲存空間

使用 `@mastra/turso`，將 Mastra Agent、Workflow、記憶體及其他儲存空間網域儲存至本機 [Turso Database](https://github.com/tursodatabase/turso) 檔案。

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/turso
```

## 用法 {/* #usage */}

```typescript
import { Mastra } from '@mastra/core/mastra'
import { TursoStore } from '@mastra/turso'

export const mastra = new Mastra({
  storage: new TursoStore({
    id: 'local-storage',
    path: './mastra.db',
  }),
})
```

## 建構函式選項 {/* #constructor-options */}

* `id`（必填）：儲存空間執行個體的唯一識別碼。
* `path`（必填，除非提供 `client`）：本機資料庫檔案的路徑。
* `client`：使用相容的 SQLite 用戶端，而不建立原生 Turso 用戶端。
* `readonly`：以唯讀模式開啟資料庫。
* `fileMustExist`：要求資料庫檔案在開啟前已存在。
* `timeout`：連線逾時時間（毫秒）。
* `defaultQueryTimeout`：預設查詢逾時時間（毫秒）。
* `tracing`：原生驅動程式的 tracing 層級：`info`、`debug` 或 `trace`。
* `experimental`：要啟用的 Turso Database 原生實驗性功能。
* `maxRetries`：可重試寫入的最大重試次數。
* `initialBackoffMs`：初始重試延遲（以毫秒為單位）。
* `disableInit`：停用自動儲存初始化。
* `retention`：支援之儲存空間網域的保留政策。

## 平台支援 {/* #platform-support */}

原生驅動程式支援 arm64 macOS、x64 Windows，以及 x64 與 arm64 的 glibc Linux。應用程式需要在不受支援的系統上選擇備援方案時，請使用 `getTursoDatabaseSupport()`。

```typescript
import { getTursoDatabaseSupport } from '@mastra/turso'

const support = getTursoDatabaseSupport()
if (!support.supported) {
  console.warn(support.reason)
}
```

## 實驗性功能 {/* #experimental-features */}

Turso Database 的實驗性功能預設停用。請只啟用應用程式所需的功能。

```typescript
const storage = new TursoStore({
  id: 'multiprocess-storage',
  path: './mastra.db',
  experimental: ['multiprocess_wal'],
})
```

`@mastra/turso` 提供以本機檔案為基礎的 Mastra 儲存空間。它不會連線至遠端 libSQL 資料庫，也不包含向量儲存空間。
