# 複合儲存

`MastraCompositeStore`可以組成來自不同Provider的儲存域。當您需要不同的資料庫用於不同的目的時，請使用它。例如，使用 LibSQL 作為內存，使用 PostgreSQL 作為Workflow。

## 安裝 {/* #installation */}

`MastraCompositeStore`包含在`@mastra/core`:

```bash npm2yarn
npm install @mastra/core@latest
```

您還需要安裝您想要組成的儲存Provider：

```bash npm2yarn
npm install @mastra/pg@latest @mastra/libsql@latest @mastra/mongodb@latest
```

## 儲存域 {/* #storage-domains */}

Mastra 將儲存組織成域，每個域處理特定類型的資料。每個域可以由不同的儲存適配器支持，並且域類別從每個儲存包導出。

|網域 |描述 |
| - | - |
|`memory` | Conversation persistence for agents. Stores threads (conversation sessions), messages, resources (user identities), and working memory (persistent context across conversations). |
| `workflows` | Workflow execution state. When workflows suspend for human input, external events, or scheduled resumption, their state is persisted here to enable resumption after server restarts. |
| `scores` | Evaluation results from Mastra's evals system. Scores and metrics are persisted here for analysis and comparison over time. |
| `observability`|遙測資料包括軌跡和跨度。Agent交互、Tool呼叫和 LLM 請求生成收集到追蹤中的跨度，用於偵錯和效能分析。 |
|`agents`|儲存的Agent的Agent配置。允許在運行時定義和更新Agent，而無需部署程式碼。 |
|`datasets`|用於實驗運行的評估資料集。儲存資料集定義、架構和版本化專案。 |
|`experiments`|實驗運行和每項實驗結果連結到資料集和目標。 |

：：：筆記

`MastraCompositeStore`接受上述所有域密鑰，但儲存適配器支援因軟體包而異。您可以在每個網域中混合使用適配器，但僅限於由這些適配器實作和匯出的網域。例如，`memory: new MemoryLibSQL(...)` and `workflows: new WorkflowsPG(...)` is valid because both packages export those domain classes.

:::

## 用法 {/* #usage */}

### 基本構成 {/* #basic-composition */}

直接從每個商店包導入域類別並組合它們：

```typescript title="src/mastra/index.ts"
import { MastraCompositeStore } from '@mastra/core/storage'
import { WorkflowsPG, ScoresPG } from '@mastra/pg'
import { MemoryLibSQL } from '@mastra/libsql'
import { Mastra } from '@mastra/core'

export const mastra = new Mastra({
  storage: new MastraCompositeStore({
    id: 'composite',
    domains: {
      memory: new MemoryLibSQL({ url: 'file:./local.db' }),
      workflows: new WorkflowsPG({ connectionString: process.env.DATABASE_URL }),
      scores: new ScoresPG({ connectionString: process.env.DATABASE_URL }),
    },
  }),
})
```

### 使用預設存儲 {/* #with-a-default-storage */}

使用`default` to specify a fallback storage, then override specific domains:

```typescript title="src/mastra/index.ts"
import { MastraCompositeStore } from '@mastra/core/storage'
import { PostgresStore } from '@mastra/pg'
import { MemoryLibSQL } from '@mastra/libsql'
import { Mastra } from '@mastra/core'

const pgStore = new PostgresStore({
  id: 'pg',
  connectionString: process.env.DATABASE_URL,
})

export const mastra = new Mastra({
  storage: new MastraCompositeStore({
    id: 'composite',
    default: pgStore,
    domains: {
      memory: new MemoryLibSQL({ url: 'file:./local.db' }),
    },
  }),
})
```

### 混合後端 {/* #mixed-backends */}

使用每個儲存包中的域類別將不同的域路由到不同的後端。以下範例將記憶體和Workflow狀態儲存在 MongoDB 中，然後將可觀察性路由到 ClickHouse：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraCompositeStore } from '@mastra/core/storage'
import { ObservabilityStorageClickhouse } from '@mastra/clickhouse'
import { MemoryStorageMongoDB, WorkflowsStorageMongoDB } from '@mastra/mongodb'

export const mastra = new Mastra({
  storage: new MastraCompositeStore({
    id: 'composite',
    domains: {
      memory: new MemoryStorageMongoDB({
        uri: process.env.MONGODB_URI,
        dbName: 'mastra_memory',
      }),
      workflows: new WorkflowsStorageMongoDB({
        uri: process.env.MONGODB_URI,
        dbName: 'mastra_workflows',
      }),
      observability: new ObservabilityStorageClickhouse({
        url: process.env.CLICKHOUSE_URL,
        username: process.env.CLICKHOUSE_USERNAME,
        password: process.env.CLICKHOUSE_PASSWORD,
      }),
    },
  }),
})
```

### 停用域 {/* #disabling-a-domain */}

將域設定為`false` to disable it. A disabled domain doesn't fall back to `default`, so data for that domain isn't persisted:

```typescript title="src/mastra/index.ts"
import { MastraCompositeStore } from '@mastra/core/storage'
import { PostgresStore } from '@mastra/pg'
import { Mastra } from '@mastra/core'

const pgStore = new PostgresStore({
  id: 'pg',
  connectionString: process.env.DATABASE_URL,
})

export const mastra = new Mastra({
  storage: new MastraCompositeStore({
    id: 'composite',
    default: pgStore,
    domains: {
      // don't persist traces and spans
      observability: false,
    },
  }),
})
```

## 初始化 {/* #initialization */}

`MastraCompositeStore`獨立初始化每個配置的域。傳到Mastra班時，`init()` is called automatically:

```typescript title="src/mastra/index.ts"
import { MastraCompositeStore } from '@mastra/core/storage'
import { MemoryPG, WorkflowsPG, ScoresPG } from '@mastra/pg'
import { Mastra } from '@mastra/core'

const storage = new MastraCompositeStore({
  id: 'composite',
  domains: {
    memory: new MemoryPG({ connectionString: process.env.DATABASE_URL }),
    workflows: new WorkflowsPG({ connectionString: process.env.DATABASE_URL }),
    scores: new ScoresPG({ connectionString: process.env.DATABASE_URL }),
  },
})

export const mastra = new Mastra({
  storage, // init() called automatically
})
```

如果直接使用存儲，則調用`init()` explicitly:

```typescript
import { MastraCompositeStore } from '@mastra/core/storage'
import { MemoryPG } from '@mastra/pg'

const storage = new MastraCompositeStore({
  id: 'composite',
  domains: {
    memory: new MemoryPG({ connectionString: process.env.DATABASE_URL }),
  },
})

await storage.init()

// Access domain-specific stores via getStore()
const memoryStore = await storage.getStore('memory')
const thread = await memoryStore?.getThreadById({ threadId: '...' })
```

## 關閉連接 {/* #closing-connections */}

`close()`釋放組合使用的儲存的連接，包括`default` and `editor` stores and any domain with its own client. Each store closes once even if it backs several domains. When the composite is passed to the Mastra class, `shutdown()` calls `close()`:

```typescript title="src/mastra/index.ts"
import { MastraCompositeStore } from '@mastra/core/storage'
import { PostgresStore } from '@mastra/pg'
import { Mastra } from '@mastra/core'

const pgStore = new PostgresStore({
  id: 'pg-storage',
  connectionString: process.env.DATABASE_URL,
})

export const mastra = new Mastra({
  storage: new MastraCompositeStore({ id: 'composite', default: pgStore }),
})

process.on('SIGTERM', async () => {
  // Releases the Postgres pool, so the process can exit
  await mastra.shutdown()
})
```

您建置的僅用於提供網域的儲存無法透過組合存取。保留對它的引用並自行關閉它：

```typescript title="src/mastra/index.ts"
import { MastraCompositeStore } from '@mastra/core/storage'
import { ClickhouseStore } from '@mastra/clickhouse'
import { PostgresStore } from '@mastra/pg'
import { Mastra } from '@mastra/core'

const pgStore = new PostgresStore({
  id: 'pg-storage',
  connectionString: process.env.DATABASE_URL,
})

const clickhouseStore = new ClickhouseStore({
  id: 'clickhouse-storage',
  url: process.env.CLICKHOUSE_URL,
  username: process.env.CLICKHOUSE_USERNAME,
  password: process.env.CLICKHOUSE_PASSWORD,
})

export const mastra = new Mastra({
  storage: new MastraCompositeStore({
    id: 'composite',
    default: pgStore,
    domains: { observability: clickhouseStore.stores?.observability },
  }),
})

process.on('SIGTERM', async () => {
  await mastra.shutdown()
  await clickhouseStore.close()
})
```

## 使用案例 {/* #use-cases */}

### 針對不同工作負載的單獨資料庫 {/* #separate-databases-for-different-workloads */}

使用本地資料庫進行開發，同時將生產資料保存在託管服務中：

```typescript
import { MastraCompositeStore } from '@mastra/core/storage'
import { MemoryPG, WorkflowsPG, ScoresPG } from '@mastra/pg'
import { MemoryLibSQL } from '@mastra/libsql'

const storage = new MastraCompositeStore({
  id: 'composite',
  domains: {
    // Use local SQLite for development, PostgreSQL for production
    memory:
      process.env.NODE_ENV === 'development'
        ? new MemoryLibSQL({ url: 'file:./dev.db' })
        : new MemoryPG({ connectionString: process.env.DATABASE_URL }),
    workflows: new WorkflowsPG({ connectionString: process.env.DATABASE_URL }),
    scores: new ScoresPG({ connectionString: process.env.DATABASE_URL }),
  },
})
```

### 用於可觀察性的專門存儲 {/* #specialized-storage-for-observability */}

可觀察性資料很快就會壓倒生產中的通用資料庫。單一Agent互動可以產生數百個跨度，高流量應用程式每天可以產生數千個追蹤。

**[克利克屋](/integrations/databases/clickhouse)**&#x5EFA;議用於生產可觀察性，因為它針對大容量、寫入量大的分析工作負載進行了最佳化。使用複合儲存將可觀察性路由到 ClickHouse，同時將其他資料保留在主資料庫中：

```typescript
import { MastraCompositeStore } from '@mastra/core/storage'
import { MemoryPG, WorkflowsPG, ScoresPG } from '@mastra/pg'
import { ObservabilityStorageClickhouseVNext } from '@mastra/clickhouse'

const storage = new MastraCompositeStore({
  id: 'composite',
  domains: {
    memory: new MemoryPG({ connectionString: process.env.DATABASE_URL }),
    workflows: new WorkflowsPG({ connectionString: process.env.DATABASE_URL }),
    scores: new ScoresPG({ connectionString: process.env.DATABASE_URL }),
    observability: new ObservabilityStorageClickhouseVNext({
      url: process.env.CLICKHOUSE_URL,
      username: process.env.CLICKHOUSE_USERNAME,
      password: process.env.CLICKHOUSE_PASSWORD,
    }),
  },
})
```

：：：筆記

`ObservabilityStorageClickhouseVNext`是當前的可觀測域實作。遺產`ObservabilityStorageClickhouse` class is also exported and remains supported for projects that haven't migrated. See the [ClickHouse storage reference](/integrations/databases/clickhouse) for details.

:::

### 用於多副本集群的複製 ClickHouse {/* #replicated-clickhouse-for-multi-replica-clusters */}

對於具有多個副本的自管理 ClickHouse 集群，設置`replication` so Mastra emits `ReplicatedMergeTree` engines and applies `ON CLUSTER` to its DDL:

```typescript
import { MastraCompositeStore } from '@mastra/core/storage'
import { MemoryPG, WorkflowsPG, ScoresPG } from '@mastra/pg'
import { ObservabilityStorageClickhouseVNext } from '@mastra/clickhouse'

const storage = new MastraCompositeStore({
  id: 'composite',
  domains: {
    memory: new MemoryPG({ connectionString: process.env.DATABASE_URL }),
    workflows: new WorkflowsPG({ connectionString: process.env.DATABASE_URL }),
    scores: new ScoresPG({ connectionString: process.env.DATABASE_URL }),
    observability: new ObservabilityStorageClickhouseVNext({
      url: process.env.CLICKHOUSE_URL,
      username: process.env.CLICKHOUSE_USERNAME,
      password: process.env.CLICKHOUSE_PASSWORD,
      replication: {
        cluster: 'production_cluster',
        // Optional (defaults shown):
        // zookeeperPath: '/clickhouse/tables/{shard}/{database}/{table}',
        // replicaName: '{replica}',
      },
    }),
  },
})
```

不設定`replication` on ClickHouse Cloud. Cloud rewrites `MergeTree` to `SharedMergeTree` server-side. See the [ClickHouse storage reference](/integrations/databases/clickhouse) for the full config shape and operator notes.

：：：筆記

當使用不支援可觀察性的儲存Provider（例如 Convex、DynamoDB 或 Cloudflare）時，也需要這種方法。請參閱[MastraStorageExporter documentation](/docs/observability/integrations/exporters/mastra-storage#storage-provider-support) for the full list of supported providers.
