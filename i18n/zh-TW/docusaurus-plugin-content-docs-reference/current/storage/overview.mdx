# 儲存

Mastra 儲存按資料領域組織，每個資料領域管理一組表或集合。具體使用全部還是部分資料領域，取決於介接器及配置。

## 儲存資料領域 {/* #storage-domains */}

`MastraCompositeStore` 可以路由以下資料領域鍵：

並非所有儲存介接器都實現了每個資料領域。如果介接器包導出了相應資料領域類，可以通過復合儲存為不同資料領域混用介接器。

| 資料領域 | 說明 |
| - | - |
| `memory` | 對話持久化：訊息、執行緒和資源（包括工作記憶）。 |
| `workflows` | 用於暫停和恢復的 Workflow 運行快照。 |
| `workflowDefinitions` | 持久化的[動態 Workflow](/docs/workflows/dynamic-workflows) 定義（Beta）；啓動時加載並實時註冊。 |
| `scores` | 評估運行產生的評分記錄。 |
| `observability` | 可觀測性導出器和 Studio 使用的 Trace 與 Span。 |
| `datasets` | 實驗使用的數據集記錄、帶版本的條目及數據集版本。 |
| `experiments` | 實驗運行及各條目的實驗結果。 |
| `agents` | Mastra Editor 使用的已保存 Agent 定義及其版本。 |
| `promptBlocks` | Mastra Editor 使用的已保存提示塊及其版本。 |
| `scorerDefinitions` | Mastra Editor 使用的已保存 Scorer 定義。 |
| `mcpClients` | Mastra Editor 使用的已保存 MCP 用戶端配置。 |
| `mcpServers` | Mastra Editor 使用的已保存 MCP 伺服器配置。 |
| `workspaces` | Mastra Editor 使用的已保存工作區配置。 |
| `skills` | Mastra Editor 使用的已保存 Skill 及其版本。 |
| `favorites` | 使用者對已保存實體的收藏。 |
| `blobs` | 以 SHA-256 哈希為鍵的內容尋址 Blob，保存 Skill 版本所需的檔案內容。 |
| `backgroundTasks` | 背景任務狀態，包括建立、狀態更新和清理。 |
| `schedules` | 排程器輪詢的排程，用於觸發 Workflow 和 Agent 運行。 |
| `channels` | 多平台集成的頻道安裝項與配置。 |
| `harness` | Harness 會話記錄。 |
| `toolProviderConnections` | 使用者為 Tool Provider 連接指定的名稱。 |
| `notifications` | 通知記錄。 |
| `threadState` | 每個執行緒持久化的狀態，例如任務列表和目標。 |
| `knowledge` | 知識圖譜節點及記錄（實驗性）。 |

下面的 Schema 定義涵蓋已記錄的內置數據庫表，分別屬於 `memory`、`workflows`、`scores` 和 `observability`。其他資料領域以及非數據庫介接器使用各自實現的儲存結構。
