# Agent.streamUntilIdle()

**添加於：** `@mastra/core@1.29.0`

:::警告\[已棄用]

`streamUntilIdle()`已棄用。使用`stream()` with the `untilIdle`選項改為：

```ts
const result = await agent.stream('Research solana for me', {
  untilIdle: true,
  memory: { thread: 't1', resource: 'u1' },
})
```

經過`untilIdle: { maxIdleMs: 60_000 }` to configure the idle timeout.

:::

`streamUntilIdle()`串流傳輸Agent程式的回應並保持串流打開，直到運行期間分派的每個後台任務完成。當任務完成時，其結果將被寫入內存，並且Agent循環會自動重新進入，以便法學碩士可以對其做出反應。一旦沒有任務正在運行並且沒有完成排隊，流就會關閉。

當Agent分派後台任務（通常是長時間運行的Tool或子Agent）並且您需要跨越初始回應的單一流時使用它**plus** every continuation triggered by a task completion. For foreground-only runs or if you prefer to manage the continuation manually (manually prompt agent to process the result), use [`Agent.stream()`](./stream).

## 使用範例 {/* #usage-example */}

```ts
const stream = await agent.streamUntilIdle('Research solana for me', {
  memory: { thread: 't1', resource: 'u1' },
})

for await (const chunk of stream.fullStream) {
  // chunks from the initial turn AND any continuation turns triggered by
  // background task completions flow through here
}
```

：：：筆記

`streamUntilIdle()`需要兩個[`BackgroundTaskManager`](/reference/configuration#backgroundtasks) and a [memory](/docs/memory/overview) backend. Without either, it uses a plain `agent.stream()` call.

:::

### 聚合屬性警告 {/* #aggregate-properties-caveat */}

`streamUntilIdle()`返回第一回合的Agent`MastraModelOutput`. Only `fullStream` is replaced with a combined stream that spans every continuation. Every other property (`text`, `toolCalls`, `toolResults`, `finishReason`, `messageList`, and `getFullOutput()`) resolves against the **first turn's** internal buffer.

如果您需要所有延續的聚合視圖，請使用`fullStream` yourself and accumulate.

## 延續行為 {/* #continuation-behavior */}

在內部，`streamUntilIdle()`:

1. 透過運行初始轉彎`agent.stream(...)` and pipes its `fullStream` into the outer stream.
2. 訂閱已解析記憶體範圍的後台任務完成事件。
3. 將每個終端事件排隊（`background-task-completed`, `background-task-failed`, `background-task-cancelled`, `background-task-suspended`) and, when the outer wrapper is idle between turns, re-invokes `agent.stream([], ...)` with a directive listing the completed `toolCallId`s. The continuation turn flows into the same outer stream.
4. 一旦沒有任務正在運行並且沒有完成排隊，則關閉外部流。

## 擴充使用範例 {/* #extended-usage-example */}

### 限制輪次之間的空閒時間 {/* #cap-idle-time-between-turns */}

```ts title="index.ts"
const stream = await agent.streamUntilIdle('Kick off the long jobs', {
  memory: { thread: 't1', resource: 'u1' },
  maxIdleMs: 60_000, // close the stream after 1 minute of idleness between turns
})

for await (const chunk of stream.fullStream) {
  if (chunk.type === 'background-task-completed') {
    console.log('Task complete:', chunk.payload.taskId)
  }
}
```

### 跨延續聚合文本 {/* #aggregate-text-across-continuations */}

```ts title="index.ts"
const stream = await agent.streamUntilIdle('Research and summarize', {
  memory: { thread: 't1', resource: 'u1' },
})

let fullText = ''
for await (const chunk of stream.fullStream) {
  if (chunk.type === 'text-delta') {
    fullText += chunk.payload.text
  }
}
```
