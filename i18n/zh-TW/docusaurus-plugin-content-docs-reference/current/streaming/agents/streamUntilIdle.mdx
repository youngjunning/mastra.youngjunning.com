# Agent.streamUntilIdle()

**新增於：** `@mastra/core@1.29.0`

:::warning[已棄用]

`streamUntilIdle()` 已棄用。請改用 `stream()`，並設定 `untilIdle` 選項：

```ts
const result = await agent.stream('Research solana for me', {
  untilIdle: true,
  memory: { thread: 't1', resource: 'u1' },
})
```

傳入 `untilIdle: { maxIdleMs: 60_000 }` 即可設定閒置逾時。

:::

`streamUntilIdle()` 以串流方式傳回 Agent 的回應，並保持串流開啟，直到本次執行派出的所有背景任務完成。任務完成後，結果會寫入記憶體，Agent 迴圈會自動再次執行，讓 LLM 處理該結果。當沒有任務執行、也沒有待處理的完成事件時，串流才會關閉。

當 Agent 派出背景任務（通常是耗時較長的 Tool 或子 Agent），而你希望單一串流同時涵蓋初始回應**以及**任務完成後觸發的所有後續執行時，可使用此方法。若只有前景任務，或你想手動管理後續執行（手動提示 Agent 處理結果），請使用 [`Agent.stream()`](./stream)。

## 使用範例 {/* #usage-example */}

```ts
const stream = await agent.streamUntilIdle('Research solana for me', {
  memory: { thread: 't1', resource: 'u1' },
})

for await (const chunk of stream.fullStream) {
  // chunks from the initial turn AND any continuation turns triggered by
  // background task completions flow through here
}
```

:::note

`streamUntilIdle()` 同時需要 [`BackgroundTaskManager`](/reference/configuration#backgroundtasks) 與[記憶體](/docs/memory/overview)後端。缺少任一項時，會改為呼叫一般的 `agent.stream()`。

:::

### 彙總屬性注意事項 {/* #aggregate-properties-caveat */}

`streamUntilIdle()` 傳回代理物件，其底層是第一次執行的 `MastraModelOutput`。只有 `fullStream` 會替換為涵蓋所有後續執行的合併串流。其他屬性（`text`、`toolCalls`、`toolResults`、`finishReason`、`messageList` 與 `getFullOutput()`）都只讀取**第一次執行**的內部緩衝區。

若需要彙總所有後續執行的結果，請自行讀取並累積 `fullStream`。

## 後續執行行為 {/* #continuation-behavior */}

`streamUntilIdle()` 的內部流程：

1. 透過 `agent.stream(...)` 執行初始回合，並將其 `fullStream` 接入外層串流。
2. 訂閱已確定的記憶體範圍內背景任務的完成事件。
3. 將每個終止狀態事件（`background-task-completed`、`background-task-failed`、`background-task-cancelled`、`background-task-suspended`）加入佇列。外層包裝器在回合之間閒置時，會再次呼叫 `agent.stream([], ...)`，並附上列出已完成 `toolCallId` 的指令。後續回合會進入同一個外層串流。
4. 當沒有任務執行且完成事件佇列為空時，關閉外層串流。

## 延伸使用範例 {/* #extended-usage-example */}

### 限制回合之間的閒置時間 {/* #cap-idle-time-between-turns */}

```ts title="index.ts"
const stream = await agent.streamUntilIdle('Kick off the long jobs', {
  memory: { thread: 't1', resource: 'u1' },
  maxIdleMs: 60_000, // close the stream after 1 minute of idleness between turns
})

for await (const chunk of stream.fullStream) {
  if (chunk.type === 'background-task-completed') {
    console.log('Task complete:', chunk.payload.taskId)
  }
}
```

### 彙總各次後續執行的文字 {/* #aggregate-text-across-continuations */}

```ts title="index.ts"
const stream = await agent.streamUntilIdle('Research and summarize', {
  memory: { thread: 't1', resource: 'u1' },
})

let fullText = ''
for await (const chunk of stream.fullStream) {
  if (chunk.type === 'text-delta') {
    fullText += chunk.payload.text
  }
}
```
