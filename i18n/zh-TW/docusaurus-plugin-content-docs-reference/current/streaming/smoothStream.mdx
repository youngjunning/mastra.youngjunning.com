# `smoothStream()`

`smoothStream()`建立一個實驗性轉換流，在以一致的區塊形式發出文字和推理增量之前緩衝它們。當模型發出不均勻的增量時，使用它可以使串流響應以更穩定的速度顯示。

非文字區塊不變地通過。任何緩衝的內容都會在Tool、控製或完成區塊之前發出。

## 使用範例 {/* #usage-example */}

管道Agent`fullStream` through the transform:

```typescript title="src/stream-agent.ts"
import { smoothStream } from '@mastra/core/stream'

const result = await agent.stream('Explain how rainbows form')

const stream = result.fullStream.pipeThrough(
  smoothStream({
    delayInMs: 20,
    chunking: 'word',
  }),
)

for await (const chunk of stream) {
  if (chunk.type === 'text-delta') {
    process.stdout.write(chunk.payload.text)
  }
}
```

轉換僅更改管道流。原始 Promise 屬性和回調`MastraModelOutput`, such as `result.text` and `onChunk`，保持模型的原始塊計時。

## AI SDK路線 {/* #ai-sdk-routes */}

進口`smoothStream()` from `@mastra/ai-sdk` to smooth an agent before `handleChatStream()` converts its output to AI SDK UI chunks:

```typescript title="app/api/chat/route.ts"
import { handleChatStream, smoothStream } from '@mastra/ai-sdk'
import { createUIMessageStreamResponse } from 'ai'
import { mastra } from '@/src/mastra'

export async function POST(req: Request) {
  const params = await req.json()
  const stream = await handleChatStream({
    mastra,
    agentId: 'weatherAgent',
    params,
    experimentalTransform: smoothStream({
      delayInMs: 20,
      chunking: 'word',
    }),
  })

  return createUIMessageStreamResponse({ stream })
}
```

這`@mastra/ai-sdk` export returns a reusable transform factory so route configuration creates a fresh `TransformStream` for every request. The `@mastra/core/stream` export returns a `TransformStream` for direct use with `pipeThrough()`.

可重用工廠也可以傳遞給`Agent.stream()`:

```typescript
import { smoothStream } from '@mastra/ai-sdk'

const result = await agent.stream('Explain how rainbows form', {
  experimentalTransform: smoothStream({ delayInMs: 20 }),
})

for await (const chunk of result.fullStream) {
  // Consume the transformed Mastra chunks.
}
```

這`chunking` option accepts:

* `'word'`：發出完整的單詞，包括尾隨空格。
* `'line'`：透過每個換行符號發出內容。
* `RegExp`：透過第一場比賽發出內容。
* `Intl.Segmenter`：使用區域設定感知分段，這對於單字之間沒有空格的語言很有用。
* `SmoothStreamChunkDetector`：使用目前緩衝區呼叫函數。此函數傳回一個要發出的非空前綴，或者`null` or `undefined` to wait for more content.

## 自訂分塊 {/* #custom-chunking */}

使用正規表示式定義區塊邊界：

```typescript
const stream = result.fullStream.pipeThrough(
  smoothStream({
    chunking: /[^,]*,\s*/,
  }),
)
```

使用`Intl.Segmenter` for locale-aware segmentation:

```typescript
const stream = result.fullStream.pipeThrough(
  smoothStream({
    chunking: new Intl.Segmenter('ja', { granularity: 'word' }),
  }),
)
```

當區塊邊界取決於自訂邏輯時，請使用偵測器函數。傳回值必須是緩衝區的前綴：

```typescript
const stream = result.fullStream.pipeThrough(
  smoothStream({
    chunking: buffer => {
      const boundary = buffer.indexOf('. ')
      return boundary === -1 ? null : buffer.slice(0, boundary + 2)
    },
  }),
)
```

## 退貨 {/* #returns */}

`TransformStream<ChunkType<OUTPUT>, ChunkType<OUTPUT>>`

變換發出平滑的`text-delta` and `reasoning-delta` chunks. It preserves chunk identifiers, run identifiers, sources, and metadata.
