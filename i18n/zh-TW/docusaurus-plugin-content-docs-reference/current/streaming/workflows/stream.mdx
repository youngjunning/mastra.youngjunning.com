# 運行.stream()

這`.stream()`方法支援來自Workflow的即時響應流。它返回一個`ReadableStream`直接事件。

## 使用範例 {/* #usage-example */}

```typescript
const run = await workflow.createRun()

const stream = await run.stream({
  inputData: {
    value: 'initial data',
  },
})

for await (const chunk of stream) {
  console.log(chunk)
}
```

## 擴充使用範例 {/* #extended-usage-example */}

```typescript
const run = await workflow.createRun()

const stream = run.stream({
  inputData: {
    value: 'initial data',
  },
})

// Iterate over stream events (you can iterate over stream directly or use stream.fullStream)
for await (const chunk of stream) {
  console.log(chunk)
}

// Access the final result
const result = await stream.result
console.log('Final result:', result)

// Access token usage
const usage = await stream.usage
console.log('Token usage:', usage)

// Check current status
console.log('Status:', stream.status)
```

## 直播事件 {/* #stream-events */}

流程在Workflow執行期間發出事件類型。每個事件都有一個`type` field and a `payload` containing relevant data:

* **`workflow-start`**：Workflow開始執行
* **`workflow-step-start`**: 一個步驟開始執行
* **`workflow-step-output`**：步驟的自訂輸出
* **`workflow-step-progress`**`completedCount`, `totalCount`, `currentIndex`, `iterationStatus`, and optional `iterationOutput`)
* **`workflow-step-result`**：步驟完成並有結果
* **`workflow-finish`**：Workflow執行完成並帶有使用情況統計資料。為了成功運行，`payload.finalWorkflowResult` carries the workflow's final result so stream consumers don't need a follow-up fetch
