# Run.observeStream()

`.observeStream()` 為仍在執行的 Workflow 開啟新的 `ReadableStream`，讓你在原始串流無法使用時繼續觀察事件。

## 使用範例 {/* #usage-example */}

```typescript
const run = await workflow.createRun()

run.stream({
  inputData: {
    value: 'initial data',
  },
})

const stream = await run.observeStream()

for await (const chunk of stream) {
  console.log(chunk)
}
```

## 傳回值 {/* #returns */}

`ReadableStream<ChunkType>`

## 串流事件 {/* #stream-events */}

Workflow 執行時，串流會發出以下事件。每個事件皆有 `type` 欄位和包含相關資料的 `payload`。

* **`workflow-start`**：Workflow 開始執行
* **`workflow-step-start`**：某個步驟開始執行
* **`workflow-step-output`**：步驟發出的自訂輸出
* **`workflow-step-result`**：步驟執行完畢並傳回結果
* **`workflow-finish`**：Workflow 執行完畢並提供用量統計。執行成功時，`payload.finalWorkflowResult` 包含 Workflow 的最終結果
