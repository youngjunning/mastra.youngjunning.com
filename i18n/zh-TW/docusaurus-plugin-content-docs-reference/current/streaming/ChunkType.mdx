# 區塊類型

這`ChunkType`type 定義了可以在Agent程式的流回應期間發出的流塊的 Mastra 格式。

## 基本屬性 {/* #base-properties */}

除自訂之外的所有區塊`data-*` chunks include these base properties:

### 數據用戶消息待處理 {/* #data-user-message-pending */}

當執行緒接受轉向或排隊後續操作（在Agent使用它之前）時發出的瞬態用戶訊息投影。訂閱者可以立即顯示輸入，然後將其與交付的內容進行協調`data-user-message` chunk by `data.id`.

該區塊不會儲存到對話歷史記錄中。`data.metadata.status` is `pending` for a steer that joins the active run and `queued` for a follow-up that runs afterward.

```typescript
type UserMessagePendingChunk = {
  type: 'data-user-message-pending'
  runId: string
  traceId?: string
  from: ChunkFrom
  metadata?: Record<string, any>
  transient: true
  data: AgentSignalDataPart['data'] & {
    metadata: Record<string, unknown> & {
      status: 'pending' | 'queued'
    }
  }
}
```

僅在刪除輸入後才發出區塊，確認刪除而不是取消請求。它仍然是暫時的，不會保存到對話歷史記錄中。

type UserMessageCancelledChunk = {
  type: 'data-user-message-cancelled'

### 執行緒運行狀態 {/* #thread-run-status */}

`ThreadRunStatusChunk`獨立於儲存的訊息重播來報告運行結果。它是從導出的`@mastra/core/stream` and emitted only when `subscribeToThread()` receives `withRunStatus: true`. The option defaults to `false`.

即時輸出先於其狀態。`success`, `failed`, and `aborted` are final outcomes. `suspended` is resumable, so the same run can later emit more output and a final outcome. A status doesn't close the subscription.

和`withInitialHistory`, `thread-history` arrives first. Opted-in late subscribers then receive one outcome per still-retained finished run, including runs outside that history page. Final outcomes are deduplicated within a subscription. Suspensions are deduplicated per execution segment. Reconnecting can redeliver outcomes. Recovery depends on PubSub retention and isn't a permanent audit log. See [Thread streams](/docs/signals/thread-streams#detect-when-a-run-finishes).

## 使用範例 {/* #usage-example */}

```typescript
const stream = await agent.stream('Hello')

for await (const chunk of stream.fullStream) {
  switch (chunk.type) {
    case 'text-delta':
      console.log('Text:', chunk.payload.text)
      break

    case 'tool-call':
      console.log('Calling tool:', chunk.payload.toolName)
      break

    case 'tool-result':
      console.log('Tool result:', chunk.payload.result)
      break

    case 'reasoning-delta':
      console.log('Reasoning:', chunk.payload.text)
      break

    case 'finish':
      console.log('Finished:', chunk.payload.stepResult.reason)
      console.log('Usage:', chunk.payload.output.usage)
      break

    case 'error':
      console.error('Error:', chunk.payload.error)
      break
  }
}
```
