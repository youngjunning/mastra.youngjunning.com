# deleteExperiment()

**自以下版本加入：** `@mastra/core@1.4.0`

先刪除實驗產生的可觀測性 Trace，再刪除實驗及其結果紀錄。刪除 Trace 需要 `@mastra/core@1.65.0` 或更新版本，並會連帶刪除透過 Trace ID 關聯的 Span、指標、日誌、評分與回饋。如果可觀測性儲存空間不支援刪除 Trace，Trace 會保留，系統會記錄警告。

要使用 `dataset.deleteExperiment()`，須先取得 `Dataset` 執行個體。沒有資料集參照時，使用 `mastra.datasets.deleteExperiment()` 依實驗 ID 刪除；資料集刪除後留下的孤立實驗也適用。

## 從資料集中刪除 {/* #delete-from-a-dataset */}

```typescript
import { Mastra } from '@mastra/core'

const mastra = new Mastra({/* storage config */})
const dataset = await mastra.datasets.get({ id: 'dataset-id' })

await dataset.deleteExperiment({ experimentId: 'experiment-id' })
```

實驗必須屬於該資料集。實驗不存在或屬於其他資料集時，會擲出 `EXPERIMENT_NOT_FOUND`。

## 在沒有資料集引用的情況下刪除 {/* #delete-without-a-dataset-reference */}

```typescript
import { Mastra } from '@mastra/core'

const mastra = new Mastra({/* storage config */})

await mastra.datasets.deleteExperiment({
  experimentId: 'experiment-id',
  organizationId: 'organization-id',
  projectId: 'project-id',
})
```

管理器方法不要求實驗仍與資料集關聯。若資料集刪除時已清除實驗的 `datasetId`，可用此方法刪除該孤立實驗。

提供 `organizationId` 或 `projectId` 時，刪除作業僅限於對應範圍。租戶資訊不符時，作業會直接略過且不報錯。

## Trace 刪除支援 {/* #trace-deletion-support */}

刪除結果紀錄前，Mastra 會收集其中的 Trace ID，以便連帶刪除。如果儲存空間不支援可觀測性功能或刪除 Trace，Trace 會保留，系統會記錄警告，但仍會刪除實驗及其結果紀錄。

如果刪除 Trace 因其他原因失敗，呼叫會在刪除實驗及其結果紀錄之前遭到拒絕。Trace 每批刪除 1,000 筆，因此失敗前可能已有部分 Trace 被刪除。再次呼叫即可完成刪除。
