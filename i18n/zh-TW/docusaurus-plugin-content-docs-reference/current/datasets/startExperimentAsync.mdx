# dataset.startExperimentAsync()

**新增於：** `@mastra/core@1.4.0`

以非同步方式啟動實驗（即發即棄），並立即傳回實驗 ID 與 `'pending'` 狀態。實驗會在背景執行。

## 使用範例 {/* #usage-example */}

```typescript
import { Mastra } from '@mastra/core'

const mastra = new Mastra({/* storage config */})

const dataset = await mastra.datasets.get({ id: 'dataset-id' })

// Start experiment without waiting
const { experimentId, status } = await dataset.startExperimentAsync({
  targetType: 'agent',
  targetId: 'my-agent',
  scorers: ['accuracy'],
})

console.log(`Experiment ${experimentId} started with status: ${status}`)

// Check progress later
const experiment = await dataset.getExperiment({ experimentId })
if (!experiment) throw new Error('Experiment not found')
console.log(`Current status: ${experiment.status}`)
```

## 參數 {/* #parameters */}

接收 `StartExperimentConfig`，與 [`dataset.startExperiment()`](/reference/datasets/startExperiment) 使用的設定相同。

當 `persistence.experiments` 設為 `'none'` 時，`startExperimentAsync()` 不會持久化實驗記錄、進度更新或個別項目結果。分數是否持久化仍由 `persistence.scores` 分開控制。如果沒有實驗事件觀察器，這次執行即為即發即棄，實驗 API 無法回報它最後完成或失敗。

如果呼叫端需要傳回的摘要，請使用同步的 [`startExperiment()`](/reference/datasets/startExperiment)。實驗事件觀察器可以接收生命週期事件與最終摘要。
