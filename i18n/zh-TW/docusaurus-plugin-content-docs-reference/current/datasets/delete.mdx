# DatasetsManager.delete()

**新增於** `@mastra/core@1.4.0`

依 ID 刪除資料集及其所有項目和版本。曾使用該資料集執行的實驗會保留，但會解除關聯，並將實驗的 `datasetId` 和 `datasetVersion` 設為 `null`。使用資料庫作為後端的儲存配接器也會刪除這些實驗的結果。

## 使用範例 {/* #usage-example */}

```typescript
import { Mastra } from '@mastra/core'

const mastra = new Mastra({/* storage config */})

await mastra.datasets.delete({ id: 'dataset-id' })
```

若提供 `organizationId` 或 `projectId`，刪除作業只會在指定範圍內生效。租戶不符時，系統不會刪除資料，也不會回報錯誤。
