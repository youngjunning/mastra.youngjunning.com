# DatasetsManager.compareExperiments()

**加入版本：** `@mastra/core@1.4.0`

比較兩個或更多實驗，依資料項目和評分器產生比較結果。至少需要兩個實驗 ID。

## 使用範例 {/* #usage-example */}

```typescript
import { Mastra } from '@mastra/core'

const mastra = new Mastra({/* storage config */})

const comparison = await mastra.datasets.compareExperiments({
  experimentIds: ['exp-baseline', 'exp-prompt-v2', 'exp-new-model'],
  baselineId: 'exp-baseline',
})

console.log(`Baseline: ${comparison.baselineId}`)

for (const item of comparison.items) {
  console.log(`Item ${item.itemId}:`)
  console.log(`  Input: ${JSON.stringify(item.input)}`)

  for (const [expId, result] of Object.entries(item.results)) {
    if (!result) {
      console.log(`  ${expId}: did not run this item`)
      continue
    }
    console.log(
      `  ${expId}: output=${JSON.stringify(result.output)}, scores=${JSON.stringify(result.scores)}`,
    )
  }
}
```

## 回傳值 {/* #returns */}

以下情況會拋出 `MastraError`，其 ID 為 `COMPARE_INVALID_INPUT`：

* `experimentIds` 包含的不同 ID 少於 2 個。
* `baselineId` 不在 `experimentIds` 中。舊版會直接忽略未知的 `baselineId`，而不會報錯。

## HTTP 路由 {/* #http-route */}

`POST /api/datasets/:datasetId/compare` 會呼叫此方法。此路由接受 `experimentIds` 中 2 至 10 個 ID；亦仍接受已棄用的 `{ experimentIdA, experimentIdB }` 請求本文，此時比較兩個實驗，並以 `experimentIdA` 為基準。
