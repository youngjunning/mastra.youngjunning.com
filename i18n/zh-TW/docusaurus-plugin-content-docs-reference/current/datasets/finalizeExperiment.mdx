# 資料集.finalizeExperiment()

**新增於：** `@mastra/core@1.61.0`

完成透過 [`createExperiment()`](/reference/datasets/createExperiment) 建立的呼叫端驅動實驗，無論是否設定 target。Mastra 會根據持續保存的結果資料列在伺服器端計算最終計數，並將實驗標記為 `'completed'`。已是 `'failed'` 的實驗會原樣傳回並維持失敗，呼叫端不必自行維護完成狀態。

計數以資料項為單位，因此即使一個資料項有多次嘗試，仍滿足 `succeededCount + failedCount + skippedCount === totalItems`：

* `succeededCount`：至少完成一次嘗試且未出現錯誤的項目
* `failedCount`：已提交但每次嘗試都出錯的項目
* `skippedCount`：從未提交的資料集項目（任何嘗試）

嘗試級別的詳細資訊仍然可以透過[`listExperimentResults()`](/reference/datasets/listExperimentResults).

終結是冪等的：在已經完成或失敗的實驗上呼叫它會傳回儲存的記錄而無需重新計算。

## 使用範例 {/* #usage-example */}

```typescript
const experiment = await dataset.finalizeExperiment({ experimentId })

console.log(experiment.status) // 'completed'
console.log(experiment.succeededCount)
console.log(experiment.failedCount)
console.log(experiment.skippedCount)
```

## 傳回值 {/* #returns */}

傳回 `Promise<Experiment>`，即包含最终狀態、計數和 `completedAt` 時間戳記的更新後實驗記錄。
