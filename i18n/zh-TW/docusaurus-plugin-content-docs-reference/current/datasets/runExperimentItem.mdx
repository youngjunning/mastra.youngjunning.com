# 資料集.runExperimentItem()

**添加於：** `@mastra/core@1.61.0`

在伺服器端執行一個實驗專案：針對此專案執行實驗目標，執行已解析的記分器，並更新插入由下列鍵控的結果行`(experimentId, itemId, attempt)`.

專為調用者驅動的循環而構建，其中耐用的編排器（例如臨時Workflow）為每個項目分散一個調用，並擁有重試和超時。重試的呼叫收斂於同一行。需要透過以下方式使用目標創建實驗[`createExperiment()`](/reference/datasets/createExperiment).

計分器以與本機運作相同的優先權進行解析：實驗`scorers` win over item `scorerIds`, which win over dataset `scorerIds`.

## 使用範例 {/* #usage-example */}

```typescript
const { experimentId } = await dataset.createExperiment({
  targetType: 'agent',
  targetId: 'translation-agent',
  scorers: ['accuracy'],
})

const { result, scores } = await dataset.runExperimentItem({
  experimentId,
  itemId: 'item-1',
})

console.log(result.output)
console.log(scores)
```

每個呼叫只執行一次該項目，沒有內部重試循環。在無目標實驗中調用它會拋出異常`EXPERIMENT_HAS_NO_TARGET`. Use [`submitExperimentResult()`](/reference/datasets/submitExperimentResult) for those. Calls after finalization throw `EXPERIMENT_ALREADY_FINALIZED`, and an `itemId` that isn't visible at the pinned dataset version throws `DATASET_ITEM_NOT_FOUND`.
