# dataset.runExperimentItem()

**加入版本：** `@mastra/core@1.61.0`

在伺服器端執行單一實驗項目：以該項目執行實驗目標、執行解析後的評分器，並依 `(experimentId, itemId, attempt)` 更新或插入結果紀錄。

此方法適用於由呼叫端控制的迴圈：具持久性的協調器（例如 Temporal Workflow）為每個項目分派一次呼叫，並負責重試與逾時。重試呼叫會寫入同一筆紀錄。實驗必須透過 [`createExperiment()`](/reference/datasets/createExperiment) 建立並設定目標。

評分器的解析優先順序與原生執行相同：實驗的 `scorers` 優先於項目的 `scorerIds`，後者又優先於資料集的 `scorerIds`。

## 使用範例 {/* #usage-example */}

```typescript
const { experimentId } = await dataset.createExperiment({
  targetType: 'agent',
  targetId: 'translation-agent',
  scorers: ['accuracy'],
})

const { result, scores } = await dataset.runExperimentItem({
  experimentId,
  itemId: 'item-1',
})

console.log(result.output)
console.log(scores)
```

每次呼叫只執行該項目一次，內部不會重試。對未設定目標的實驗呼叫時會擲出 `EXPERIMENT_HAS_NO_TARGET`；這類實驗請使用 [`submitExperimentResult()`](/reference/datasets/submitExperimentResult)。實驗定案後呼叫會擲出 `EXPERIMENT_ALREADY_FINALIZED`；若 `itemId` 在固定的資料集版本中不可見，則會擲出 `DATASET_ITEM_NOT_FOUND`。
