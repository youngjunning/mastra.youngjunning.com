# 用人工智慧構建

有關使用 Mastra 技能和 CLI 進行日常 AI 輔助開發的信息，請參閱[Develop](/docs/develop#build-with-ai)。本頁介紹了讓編碼Agent存取 Mastra 文件的其他方法。

## 嵌入式包文檔 {/* #embedded-package-docs */}

Mastra 軟體包隨附嵌入式文檔`dist/docs`. When you install a Mastra package, your AI agent can read these files directly from `node_modules` to understand the package's APIs and patterns.

每個`dist/docs` includes:

* `SKILL.md`：符合技能標準的技能文件
* `references/`：包含與套件相關的文件檔案的資料夾
* `assets/SOURCE_MAP.json`：將公共導出連結到其位置的來源映射文件`node_modules`

## 上下文文件 {/* #context-files */}

Mastra 提供根[`llms.txt`](https://mastra.ai/llms.txt) file that contains an overview of all available documentation pages.

若要在一個請求中載入多個頁面，請使用`llms-full.txt` bundles. They contain the full Markdown of every page in sidebar order:

* [`/llms-full.txt`](https://mastra.ai/llms-full.txt)：所有文檔
* [`/docs/llms-full.txt`](https://mastra.ai/docs/llms-full.txt):文件
* [`/models/llms-full.txt`](https://mastra.ai/models/llms-full.txt)： 型號
* [`/integrations/llms-full.txt`](https://mastra.ai/integrations/llms-full.txt)：集成
* [`/reference/llms-full.txt`](https://mastra.ai/reference/llms-full.txt)： 參考

完整的捆綁包很大，因此當您只需要部分文件時，最好選擇部分捆綁包或單獨的頁面。

每個文檔頁面也有自己的`llms.txt` file. These files are streamlined markdown files. At the end of each docs page you'll find a link to the corresponding `llms.txt` file.

添加`/llms.txt` to any Mastra docs URL to access it. You can also request it by adding a `.md` extension to the end of the URL.

範例為[introduction page](/docs):

* [`/docs/llms.txt`](https://mastra.ai/docs/llms.txt)
* [`/docs.md`](https://mastra.ai/docs.md)

## MCP 文件伺服器 {/* #mcp-docs-server */}

：：：警告

不建議將 MCP 文件伺服器用於日常開發。使用[Mastra skill](/docs/develop#mastra-skills) instead because it's more up to date and performs better.

:::

這`@mastra/mcp-docs-server` package provides direct local access to Mastra’s full documentation via the [Model Context Protocol (MCP)](https://modelcontextprotocol.io/docs/getting-started/intro). It works with Cursor, Windsurf, Cline, Claude Code, VS Code, Codex or any tool that supports MCP.

這些Tool旨在幫助Agent程式檢索精確的、特定於任務的信息，無論您是向Agent添加功能還是構建新項目，還是探索某些內容的工作原理。

如果您無法使用本機 MCP 伺服器並需要連線到遠端伺服器，請使用下列 URL：`https://mastra.mcp.kapa.ai`. You need to authenticate with your Google Account (only an anonymous ID is transmitted) for rate-limiting purposes. If possible, Mastra recommends using a local MCP server for better performance and reliability.

### 安裝 {/* #installation */}

這[`create-mastra`](/reference/cli/create-mastra) command doesn't configure the MCP docs server. Add the server manually when you need MCP-specific tools such as the migration tool.

如果下面沒有針對您的Tool的具體說明，您也許可以使用此通用 JSON 配置來新增 MCP 伺服器。

```json title="mcp.json"
{
  "mcpServers": {
    "mastra": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "@mastra/mcp-docs-server@latest"]
    }
  }
}
```

#### 克勞德·代碼 CLI {/* #claude-code-cli */}

使用終端命令安裝：

```bash
claude mcp add --scope project mastra -- npx -y @mastra/mcp-docs-server@latest
```

這將創建一個專案範圍的`.mcp.json` file if one doesn't already exist. You can use the same command when using Claude Code as a [Visual Studio Code extension](https://code.claude.com/docs/en/vs-code#connect-to-external-tools-with-mcp).

[有關將 MCP 伺服器與 Claude Code 結合使用的更多信息](https://docs.claude.com/en/docs/claude-code/mcp)

#### OpenAI Codex CLI {/* #openai-codex-cli */}

1. 從終端註冊：

   ```bash
   codex mcp add mastra-docs -- npx -y @mastra/mcp-docs-server@latest
   ```

2. 跑步`codex mcp list` to confirm the server shows as `enabled`.

[有關將 MCP 伺服器與 OpenAI Codex 結合使用的更多信息](https://developers.openai.com/codex/mcp)

#### 游標 {/* #cursor */}

選擇下面的按鈕進行安裝：

[![Install MCP Server](https://cursor.com/deeplink/mcp-install-light.svg)](cursor://anysphere.cursor-deeplink/mcp/install?name=mastra\&config=eyJjb21tYW5kIjoibnB4IC15IEBtYXN0cmEvbWNwLWRvY3Mtc2VydmVyIn0%3D)

#### 反重力 {/* #antigravity */}

Google Antigravity 是一個Agent優先的開發平台，支援 MCP 伺服器存取外部文件、API 和專案上下文。

1. 開啟您的反重力 MCP 設定檔：

   * 點選**Agent session** and select the **“…” dropdown** at the top of the editor’s side panel, then select **MCP Servers** to access the **MCP Store**.
   * 您可以透過 Antigravity 中的 MCP Store 介面存取它。

2. 若要新增自訂 MCP 伺服器，請選擇**Manage MCP Servers** at the top of the MCP Store and select **View raw config** in the main tab.

3. 新增 Mastra MCP 伺服器配置：

   ```json
   {
     "mcpServers": {
       "mastra-docs": {
         "command": "npx",
         "args": ["-y", "@mastra/mcp-docs-server"]
       }
     }
   }
   ```

4. 儲存配置並重新啟動Antigravity

配置完成後，Mastra MCP 伺服器會向反重力Agent程式公開以下內容：

* Mastra 的索引文件和 API 模式，支援在程式碼產生期間以程式設計方式檢索相關上下文
* 存取 Mastra Docs 中儲存的範例程式碼片段和使用模式
* 用於編輯器中錯誤處理和調試參考的結構化數據
* 有關當前 Mastra 專案模式的元數據，用於程式碼建議和完成

MCP 伺服器將出現在 Antigravity 的 MCP 商店中，您可以在其中管理其連線狀態和身份驗證（如果需要）。

[有關使用具有反重力功能的 MCP 伺服器的更多信息](https://antigravity.google)

#### 視覺工作室程式碼 {/* #visual-studio-code */}

1. 創建一個`.vscode/mcp.json` file in your workspace
2. 插入以下配置：

   ```json title=".vscode/mcp.json"
   {
     "servers": {
       "mastra": {
         "type": "stdio",
         "command": "npx",
         "args": ["-y", "@mastra/mcp-docs-server@latest"]
       }
     }
   }
   ```

儲存配置後，啟用伺服器：

1. 打開命令面板。
2. 跑步**MCP: List Servers**.
3. 選擇**mastra**, then select **Enable**.

MCP Tool可在 Visual Studio Code 的Agent模式下使用。選擇 Copilot 窗格中的Tool按鈕以查看可用的Tool。

[有關將 MCP 伺服器與 Visual Studio Code 結合使用的詳細信息](https://code.visualstudio.com/docs/copilot/customization/mcp-servers)

#### 風帆衝浪 {/* #windsurf */}

   ```json title="~/.codeium/windsurf/mcp_config.json"

     "mcpServers": {
       "mastra": {
         "command": "npx",

       }
     }
   ```

3. 儲存配置並重新啟動 Windsurf

[有關將 MCP 伺服器與 Windsurf 結合使用的更多信息](https://docs.windsurf.com/windsurf/cascade/mcp#mcp-config-json)

#### 開放程式碼 {/* #opencode */}

您可以在您的[OpenCode configuration](https://opencode.ai/docs/config/) under `mcp`. Create an `opencode.jsonc` file in your project root with the following content:

```json title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "mastra": {
      "type": "local",
      "command": ["npx", "-y", "@mastra/mcp-docs-server@latest"],
      "enabled": true
    }
  }
}
```

[有關將 MCP 伺服器與 OpenCode 結合使用的更多信息](https://opencode.ai/docs/mcp-servers)

### 用法 {/* #usage */}

配置完成後，您可以向 AI Tool詢問有關 Mastra 的問題或指示其採取行動。對於這些步驟，它將從 Mastra 的 MCP 伺服器獲取最新資訊。

**新增功能：**

* “向我的Agent商添加評估並編寫測試”
* 「給我寫一個執行以下操作的Workflow`[task]`"
* 「製作一個新Tool，讓我的Agent商能夠訪問`[3rd party API]`"

**詢問整合：**

* 「Mastra 可以與 AI SDK 搭配使用嗎？
  我怎樣才能在我的`[React/Svelte/etc]` project?"
* 「馬斯特拉是否支持`[provider]` speech and voice APIs? Show me an example in my code of how I can use it."

**調試或更新現有程式碼：**

* “我遇到了Agent內存錯誤，最近是否有任何相關更改或錯誤修復？”
* 「工作記憶在 Mastra 中的表現如何以及我如何使用它來做`[task]`? It doesn't seem to work the way I expect."
* 「我看到有新的Workflow功能，請向我解釋一下，然後更新`[workflow]` to use them."

### 故障排除 {/* #troubleshooting */}

1. **伺服器未啟動**
   * 確保[npx](https://docs.npmjs.com/cli/v11/commands/npx) is installed and working.
   * 檢查是否有衝突的 MCP 伺服器。
   * 驗證您的設定檔語法。

2. **Tool呼叫失敗**
   * 重新啟動 MCP 伺服器和/或您的 IDE。
   * 更新到最新版本的 IDE。
