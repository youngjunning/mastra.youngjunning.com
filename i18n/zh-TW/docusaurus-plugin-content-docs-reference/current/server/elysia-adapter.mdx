# Elysia 轉接器

`@mastra/elysia` 套件提供伺服器轉接器，讓 Mastra 可搭配 [Elysia](https://elysiajs.com) 執行。

:::info

關於轉接器的基本概念、建構函式選項及初始化流程，請參閱[伺服器轉接器](/docs/server/server-adapters)。

:::

## 安裝 {/* #installation */}

安裝 Elysia 轉接器與 Elysia 框架：

```bash npm2yarn
npm install @mastra/elysia@latest elysia
```

## 使用範例 {/* #usage-example */}

```typescript title="server.ts"
import { Elysia } from 'elysia'
import { MastraServer } from '@mastra/elysia'
import { mastra } from './mastra'

const app = new Elysia()
const server = new MastraServer({ app, mastra })

await server.init()

app.listen(3000)

console.log('Server running on http://localhost:3000')
```

`init()` 不會啟動 Mastra 的背景工作程序。若要執行[排程 Workflow](/docs/workflows/scheduled-workflows)、Agent 排程或事件監聽器，請在伺服器開始監聽後呼叫 `await mastra.startWorkers()`。請參閱[啟動背景工作程序](/docs/server/server-adapters#start-background-workers)。

## 新增自訂路由 {/* #adding-custom-routes */}

直接在 Elysia 應用程式中新增路由：

```typescript title="server.ts"
import { Elysia } from 'elysia'
import { MastraServer } from '@mastra/elysia'
import { mastra } from './mastra'

const app = new Elysia()
const server = new MastraServer({ app, mastra })

// Before init - runs before Mastra middleware
app.get('/early-health', () => ({ status: 'ok' }))

await server.init()

// After init - has access to Mastra context
app.get('/custom', ({ mastra }) => {
  return { agents: Object.keys(mastra.listAgents()) }
})
```

:::tip

在 `init()` 之前新增的路由執行時沒有 Mastra 上下文。如需存取 Mastra 實例與請求上下文，請在 `init()` 之後新增路由。

:::

若需要由 Mastra 管理驗證，以及 `requiresAuth` 等路由中繼資料，建議使用 [`registerApiRoute()`](/reference/server/register-api-route)。對於直接掛載在 `app` 上的原生 Elysia 路由，請使用 `createAuthMiddleware()`：

```typescript title="server.ts"
import { Elysia } from 'elysia'
import { createAuthMiddleware, MastraServer } from '@mastra/elysia'
import { mastra } from './mastra'

const app = new Elysia()
const server = new MastraServer({ app, mastra })

await server.init()

app.get('/custom/protected', async ctx => {
  const authResponse = await createAuthMiddleware({ mastra })(ctx)
  if (authResponse) return authResponse

  const user = ctx.requestContext.get('user')
  return { user }
})

app.get('/custom/public', async ctx => {
  const authResponse = await createAuthMiddleware({ mastra, requiresAuth: false })(ctx)
  if (authResponse) return authResponse

  return { ok: true }
})
```

當驗證 Provider 更新過期的工作階段時，`createAuthMiddleware()` 會將更新後的工作階段回應標頭（例如 `Set-Cookie`）附加至回應，錯誤回應也包含在內。`MastraServer` 會在 `init()` 期間註冊 `applyAuthRefreshHeaders` 掛鉤，因此在 `init()` 之後新增的路由，會同時傳回這些標頭及路由本身設定的 Cookie。

若未透過 `MastraServer` 使用 `createAuthMiddleware()`，請在定義路由前自行註冊此掛鉤：

```typescript title="server.ts"
import { Elysia } from 'elysia'
import { applyAuthRefreshHeaders, createAuthMiddleware } from '@mastra/elysia'
import { mastra } from './mastra'

const app = new Elysia()
  .onAfterHandle({ as: 'global' }, applyAuthRefreshHeaders)
  .onError({ as: 'global' }, applyAuthRefreshHeaders)

app.get('/custom/protected', () => ({ ok: true }), {
  beforeHandle: createAuthMiddleware({ mastra }),
})
```

## 存取上下文 {/* #accessing-context */}

在 `init()` 之後註冊的 Elysia 處理函式中，可從處理函式的上下文存取 Mastra 上下文：

```typescript title="server.ts"
app.get('/custom', ({ mastra, requestContext, abortSignal }) => {
  const agent = mastra.getAgent('myAgent')
  const user = requestContext.get('user')

  return { agent: agent.name, user, aborted: abortSignal.aborted }
})
```

可用的上下文鍵：

| 鍵 | 說明 |
| - | - |
| `mastra` | Mastra 實例 |
| `requestContext` | 請求上下文對照表 |
| `abortSignal` | 請求取消訊號 |
| `registeredTools` | 可用的 Tool |
| `taskStore` | A2A 操作的任務儲存區 |
| `customRouteAuthConfig` | 針對各路由覆寫的驗證設定 |
| `user` | 設定驗證後，`requestContext` 中已通過驗證的使用者 |

## OpenAPI 輔助函式 {/* #openapi-helpers */}

若要將 Mastra 產生的 OpenAPI 文件傳給 `@elysiajs/openapi` 等 Elysia 工具，請使用 `getMastraOpenAPIDoc()`：

```typescript title="server.ts"
import { openapi } from '@elysiajs/openapi'
import { Elysia } from 'elysia'
import { getMastraOpenAPIDoc, MastraServer } from '@mastra/elysia'
import { mastra } from './mastra'

const app = new Elysia()
const server = new MastraServer({ app, mastra })

await server.init()

app.use(
  openapi({
    documentation: getMastraOpenAPIDoc(server),
  }),
)
```

若需為同一個伺服器實例重新產生快取中的文件，請呼叫 `clearMastraOpenAPICache(server)`。

## MCP 支援 {/* #mcp-support */}

Elysia 轉接器透過 Streamable HTTP，在 `/api/mcp/:serverId/mcp` 路徑提供每個已註冊的 MCP 伺服器。

## 手動初始化 {/* #manual-initialization */}

若需自訂中介軟體的執行順序，請分別呼叫各個方法，而不要呼叫 `init()`。詳情請參閱[手動初始化](/docs/server/server-adapters#manual-initialization)。
