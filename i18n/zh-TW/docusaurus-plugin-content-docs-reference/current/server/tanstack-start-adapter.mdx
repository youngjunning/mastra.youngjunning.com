# TanStack Start 適配器

`@mastra/tanstack-start` 套件可將 Mastra 掛載到 TanStack Start 應用程式。適配器的一般概念請參閱[伺服器適配器](/docs/server/server-adapters)。

## 安裝 {/* #installation */}

安裝 TanStack Start 適配器及其 Hono 同儕相依套件：

```bash npm2yarn
npm install @mastra/tanstack-start@latest hono
```

## 使用範例 {/* #usage-example */}

在涵蓋所有路徑的 splat 路由中掛載適配器：

```typescript title="src/routes/api/$.ts"
import { createStartRouteHandler } from '@mastra/tanstack-start'
import { createFileRoute } from '@tanstack/react-router'
import { mastra } from '../../mastra'

export const Route = createFileRoute('/api/$')({
  server: {
    handlers: createStartRouteHandler({ mastra }),
  },
})
```

`prefix` 預設為 `/api`，且必須與 splat 路由的掛載路徑一致。例如，若掛載在 `src/routes/api/mastra/$.ts`，請使用 `createStartRouteHandler({ mastra, prefix: '/api/mastra' })`。

## 簽名 {/* #signature */}

```typescript
function createStartRouteHandler(options: StartRouteHandlerOptions): StartRouteHandlers
```

## 傳回值 {/* #return-value */}

傳回 `StartRouteHandlers` 物件，包含 `GET`、`POST`、`PUT`、`DELETE`、`PATCH`、`OPTIONS` 和 `HEAD` 屬性。每個屬性都是符合以下簽章的處理函式：

```typescript
(context: StartHandlerContext) => Response | Promise<Response>
```

上下文型別包含傳入的請求與 splat 路由參數：

```typescript
type StartHandlerContext = {
  request: Request
  params: Record<string, string>
}
```

## Serverless 部署與延遲初始化 {/* #serverless-deployments--lazy-initialization */}

適配器會同步匯出路由處理函式，並在收到首個請求時建立底層 Hono 應用程式與 `MastraServer`。初始化後的應用程式會在同一程序中供後續請求重用，因此無須在頂層進行非同步初始化，也能支援 serverless 執行環境。

它與 [Next.js 適配器](/reference/server/next-adapter)共用以 Hono 為基礎的 `MastraServer` 核心。A2A 端點使用記憶體內的任務儲存，因此任務狀態只會在程序存續期間保留，不會在不同 serverless 實例之間共用。

## 請求主體大小限制 {/* #body-size-limit */}

請求主體的預設大小上限為 4.5 MB。超出上限的請求會收到 `{ error: 'Request body too large' }`。

設定 `server.bodySizeLimit` 即可調整 `Mastra` 實例的請求主體大小上限。

## 中介軟體 {/* #middleware */}

透過 `server.middleware` 或 `setServerMiddleware()` 設定的中介軟體會在適配器以 Hono 為基礎的伺服器中執行；標記為 `requiresAuth: false` 等框架公開路由除外。請參閱[伺服器中介軟體](/docs/server/middleware)。
