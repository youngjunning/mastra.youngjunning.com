# NestJS 轉接器

`@mastra/nestjs` 套件提供 NestJS 模組，讓 Mastra 在以 Express 為基礎的 NestJS 平台上執行。

v1 刻意只支援 Express。如果 Nest 使用其他 HTTP 轉接器啟動，`MastraModule` 會在啟動時擲出錯誤，不會嘗試僅完成部分整合。關於轉接器的一般概念，請參閱[伺服器轉接器](/docs/server/server-adapters)。

## 安裝 {/* #installation */}

安裝 NestJS 轉接器，並確認應用程式使用 Express 平台：

```bash npm2yarn
npm install @mastra/nestjs@latest
```

## 使用範例 {/* #usage-example */}

```typescript title="src/app.module.ts"
import { Module } from '@nestjs/common'
import { MastraModule } from '@mastra/nestjs'
import { mastra } from './mastra'

@Module({
  imports: [
    MastraModule.register({
      mastra,
    }),
  ],
})
export class AppModule {}
```

:::note

`MastraModule` 會註冊涵蓋所有路由的控制器（`@All('*')`）。如果在應用程式的其他模組之前匯入，它可能攔截不相關的路由並回傳 404。為避免衝突，請最後匯入 `MastraModule`，或將其掛載在專用前綴下，例如 `/api/v1/mastra`。

:::

```typescript title="src/main.ts"
import { NestFactory } from '@nestjs/core'
import { AppModule } from './app.module'

async function bootstrap() {
  const app = await NestFactory.create(AppModule)
  await app.listen(3000)
}

bootstrap()
```

Mastra 路由預設掛載在 `/api` 下。可以用 `prefix` 變更此前綴。

## 非同步註冊 {/* #async-registration */}

```typescript title="src/app.module.ts"
import { Module } from '@nestjs/common'
import { ConfigModule, ConfigService } from '@nestjs/config'
import { MastraModule } from '@mastra/nestjs'
import { Mastra } from '@mastra/core/mastra'

@Module({
  imports: [
    ConfigModule.forRoot(),
    MastraModule.registerAsync({
      imports: [ConfigModule],
      useFactory: (config: ConfigService) => ({
        mastra: new Mastra({
          agents: {
            greeter: {
              name: 'greeter',
              description: 'Greets the user',
              model: config.get('MASTRA_MODEL', '__GATEWAY_OPENAI_MODEL_LUNA__'),
            },
          },
        }),
        prefix: config.get('MASTRA_PREFIX', '/api'),
      }),
      inject: [ConfigService],
    }),
  ],
})
export class AppModule {}
```

## 存取 Mastra {/* #accessing-mastra */}

在服務中使用 `MASTRA` Token 或 `MastraService`：

```typescript
import { Injectable, Inject } from '@nestjs/common'
import { MASTRA, MastraService } from '@mastra/nestjs'
import type { Mastra } from '@mastra/core/mastra'

@Injectable()
export class AgentService {
  constructor(@Inject(MASTRA) private readonly mastra: Mastra) {}
}

@Injectable()
export class WorkflowService {
  constructor(private readonly mastraService: MastraService) {}
}
```

## 啟動背景 Worker {/* #start-background-workers */}

`MastraModule` 不會啟動 Mastra 的背景 Worker。若未啟動，[排程 Workflow](/docs/workflows/scheduled-workflows)、Agent 排程及事件監聽器都不會執行。應用程式開始監聽後，請呼叫 `mastra.startWorkers()`：

```typescript title="src/main.ts"
import { NestFactory } from '@nestjs/core'
import { MASTRA } from '@mastra/nestjs'
import type { Mastra } from '@mastra/core/mastra'
import { AppModule } from './app.module'

async function bootstrap() {
  const app = await NestFactory.create(AppModule)
  app.enableShutdownHooks()
  await app.listen(3000)

  try {
    await app.get<Mastra>(MASTRA).startWorkers()
  } catch (error) {
    console.error('Failed to start background workers', error)
    await app.close()
    process.exit(1)
  }
}

bootstrap()
```

此模組的關閉程序會等待處理中的請求完成，但不會停止 Mastra。若要停止 Worker 並等待執行中的 Workflow 結束，請在關閉鉤子中呼叫 `mastra.shutdown()`。等待時間受 `drainTimeout` 限制（預設 5 秒）；逾時仍未結束的執行會被放棄，並顯示警告：

```typescript title="src/mastra-lifecycle.service.ts"
import { Inject, Injectable, type OnApplicationShutdown } from '@nestjs/common'
import { MASTRA } from '@mastra/nestjs'
import type { Mastra } from '@mastra/core/mastra'

@Injectable()
export class MastraLifecycleService implements OnApplicationShutdown {
  constructor(@Inject(MASTRA) private readonly mastra: Mastra) {}

  async onApplicationShutdown() {
    await this.mastra.shutdown()
  }
}
```

將 `MastraLifecycleService` 加入已匯入 `MastraModule` 的模組之 `providers`。只有呼叫 `app.enableShutdownHooks()` 後，關閉鉤子才會執行。

詳細資訊請參閱[啟動背景 Worker](/docs/server/server-adapters#start-background-workers)。

## MCP 路由 {/* #mcp-routes */}

MCP 端點位於 API 前綴下：

* `POST /api/mcp/:serverId/mcp`

## 健康狀態路由 {/* #health-routes */}

為相容於基礎設施，這些維運端點刻意不加前綴：

* `GET /health`
* `GET /ready`
* `GET /info`
