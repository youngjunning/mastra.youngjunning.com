# Next.js 適配器

這`@mastra/next`套件將 Mastra 安裝在 Next.js App Router 應用程式中。看[伺服器適配器](/docs/server/server-adapters)對於一般適配器概念。

## 安裝 {/* #installation */}

安裝 Next.js 適配器及其 Hono 對等相依性：

```bash npm2yarn
npm install @mastra/next@latest hono
```

## 使用範例 {/* #usage-example */}

在包羅萬象的 App Router 路由中安裝適配器：

```typescript title="app/api/[...mastra]/route.ts"
import { createNextRouteHandler } from '@mastra/next'
import { mastra } from '@/mastra'

export const { GET, POST, PUT, DELETE, PATCH, OPTIONS, HEAD } = createNextRouteHandler({
  mastra,
})
```

這`prefix` option defaults to `/api` and must match the catch-all route's mount path. For example, when mounting at `app/api/mastra/[...mastra]/route.ts`, use `createNextRouteHandler({ mastra, prefix: '/api/mastra' })`.

## 簽名 {/* #signature */}

```typescript
function createNextRouteHandler(options: NextRouteHandlerOptions): NextRouteHandlers
```

## 傳回值 {/* #return-value */}

返回一個`NextRouteHandlers` object with `GET`, `POST`, `PUT`, `DELETE`, `PATCH`, `OPTIONS`， 和`HEAD`特性。每個屬性都是具有以下簽名的處理程序：

```typescript
(request: Request) => Response | Promise<Response>
```

## 無伺服器部署和延遲初始化 {/* #serverless-deployments--lazy-initialization */}

適配器同步導出其路由處理程序，然後建立底層 Hono 應用程式並`MastraServer` when the first request arrives. That initialized app is reused for subsequent requests in the same process, which supports serverless runtimes without top-level asynchronous initialization.

A2A 端點使用記憶體中的任務儲存。任務狀態僅在進程的生命週期內持續，且不在無伺服器執行個體之間共用。

## 體型限制 {/* #body-size-limit */}

請求正文的預設限制為 4.5 MB。超過接收限制的請求`{ error: 'Request body too large' }`.

放`server.bodySizeLimit` on the `Mastra` instance to configure the limit.

## 中介軟體 {/* #middleware */}

中介軟體配置為`server.middleware` or `setServerMiddleware()` runs through the adapter's Hono-based server, except on framework-public routes such as those marked `requiresAuth: false`. See [Server middleware](/docs/server/middleware).
