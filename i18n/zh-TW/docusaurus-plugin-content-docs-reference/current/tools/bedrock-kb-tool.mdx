# 建立BedrockKBTool()

這`createBedrockKBTool()`函數建立一個從 Amazon Bedrock 知識庫檢索相關文件的Tool。它支援託管搜尋配置和Agent程式檢索（查詢分解和託管重新排名），並自動回退到標準檢索。

## 使用範例 {/* #usage-example */}

```typescript
import { createBedrockKBTool } from '@mastra/rag'

const kbTool = createBedrockKBTool({
  knowledgeBaseId: 'YOUR_KB_ID',
  region: 'us-west-2',
  numberOfResults: 5,
  useAgenticRetrieval: true,
})
```

### 與Agent {/* #with-an-agent */}

```typescript
import { Agent } from '@mastra/core/agent'
import { createBedrockKBTool } from '@mastra/rag'

const kbTool = createBedrockKBTool({
  knowledgeBaseId: 'YOUR_KB_ID',
})

const agent = new Agent({
  name: 'KnowledgeAssistant',
  instructions: 'Use the knowledge base tool to answer questions.',
  model: myModel,
  tools: { kb: kbTool },
})
```

|領域 |類型 |描述 |
| - | - | - |
|`content` | `string` | The text content of the retrieved passage. |

|`metadata` | `Record<string, unknown>`|來自檢索結果的附加元資料。 |

## 檢索方式 {/* #retrieval-modes */}

### Agent檢索（預設） {/* #agentic-retrieval-default */}

什麼時候`useAgenticRetrieval` is `true` (default), the tool uses `AgenticRetrieveStreamCommand` which:

* 將複雜查詢分解為子查詢
* 跨多次檢索
* 應用程式託管重新排名以獲得更好的結果

如果Agent程式檢索失敗（例如，較舊的 SDK、權限），它會自動回退到標準託管檢索。

### 標準託管檢索 {/* #standard-managed-retrieval */}

什麼時候`useAgenticRetrieval` is `false`, the tool uses `RetrieveCommand` with `managedSearchConfiguration` for direct single-pass retrieval.

## 基於使用者的存取控制 {/* #user-based-access-control */}

放`userId` in the Mastra request context to forward it as the Bedrock `userContext.userId`. This supports knowledge bases that enforce document-level access control. The request context value overrides the default `userId` configured on the tool.

```typescript
import { RequestContext } from '@mastra/core/request-context'

const requestContext = new RequestContext()
requestContext.set('userId', 'user-123')

await agent.generate('Find my private documents', { requestContext })
```

## 所需的 IAM 權限 {/* #required-iam-permissions */}

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": ["bedrock:Retrieve", "bedrock:AgenticRetrieveStream"],
      "Resource": "arn:aws:bedrock:*:*:knowledge-base/*"
    }
  ]
}
```
