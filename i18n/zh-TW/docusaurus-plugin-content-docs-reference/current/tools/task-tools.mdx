# 任務Tool

四個與Agent程式無關的內建Tool，用於管理Agent程式運行的結構化任務清單。任務清單持久化在執行緒範圍內`threadState`儲存域並投影到Agent上[狀態訊號](/docs/signals/state-signals)車道，以便它生存[觀察記憶](/docs/memory/observational-memory)截斷。

任務追蹤需要記憶體支援的線程（`threadId` + `resourceId`). Without memory the tools return an error explaining that task tracking requires agent memory.

推薦的設定是[`TaskSignalProvider`](/reference/signals/task-signal-provider), which bundles all four tools and the `TaskStateProcessor` in a single registration. See [Built-in tools](/docs/agents/tools#task-tracking) for the conceptual guide.

## 使用範例 {/* #usage-example */}

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { Memory } from '@mastra/memory'
import { TaskSignalProvider } from '@mastra/core/signals'

const agent = new Agent({
  id: 'coder',
  name: 'Coder',
  instructions: 'Track your progress with the task tools.',
  model,
  memory: new Memory(),
  signals: [new TaskSignalProvider()],
})
```

或直接導入Tool。`taskWriteTool`, `taskUpdateTool`, `taskCompleteTool`, and `taskCheckTool` are the export names; `task_write`, `task_update`, `task_complete`， 和`task_check`是模型在Tool呼叫和追蹤中看到的Tool ID：

```typescript title="src/mastra/agents/index.ts"
import { taskWriteTool, taskUpdateTool, taskCompleteTool, taskCheckTool } from '@mastra/core/tools'
import { Agent } from '@mastra/core/agent'
import { Memory } from '@mastra/memory'

const agent = new Agent({
  id: 'coder',
  name: 'Coder',
  instructions: 'Track your progress with the task tools.',
  model,
  memory: new Memory(),
  tools: { taskWriteTool, taskUpdateTool, taskCompleteTool, taskCheckTool },
})
```

## `task_write` {/* #task_write */}

建立或替換整個任務清單。每次呼叫都會替換先前的列表。

### 輸入模式 {/* #input-schema */}

<PropertiesTable
  content={[
{
  name: 'tasks',
  type: 'TaskItemInput[]',
  description: 'The complete updated task list.',
  isOptional: false,
  properties: [
    {
      type: 'TaskItemInput',
      parameters: [
        {
          name: 'id',
          type: 'string',
          description:
            "Stable task identifier (e.g. 'task_investigate_tests'). Keep this unchanged across updates. Auto-generated when omitted.",
          isOptional: true,
        },
        {
          name: 'content',
          type: 'string',
          description: "Task description in imperative form (e.g. 'Fix authentication bug').",
        },
        {
          name: 'status',
          type: "'pending' | 'in_progress' | 'completed'",
          description: 'Current task status.',
        },
        {
          name: 'activeForm',
          type: 'string',
          description: "Present continuous form shown during execution (e.g. 'Fixing authentication bug').",
        },
      ],
    },
  ],
},
]}
/>

### 輸出 {/* #output */}

返回一個`TaskToolResult` with a human-readable `content` summary, the full `tasks` array with assigned IDs, and an `isError` flag.

### 行為 {/* #behavior */}

* ID 在一次呼叫中必須是唯一的。重複的明確 ID 會產生一個後備。
* 當重寫現有清單時省略 ID 時，一個明確的匹配任務將重複使用其先前的 ID 以保持穩定性。
* 只能有一項任務`in_progress` status at a time. Submitting multiple `in_progress` tasks returns an error.

## `task_update` {/* #task_update */}

透過其穩定 ID 更新一項任務。僅包括已變更的欄位。

### 輸入模式 {/* #input-schema-1 */}

<PropertiesTable
  content={[
{
  name: 'id',
  type: 'string',
  description: 'The stable task identifier to update.',
  isOptional: false,
},
{
  name: 'content',
  type: 'string',
  description: 'New task description in imperative form.',
  isOptional: true,
},
{
  name: 'status',
  type: "'pending' | 'in_progress' | 'completed'",
  description: 'New task status.',
  isOptional: true,
},
{
  name: 'activeForm',
  type: 'string',
  description: 'New present continuous form.',
  isOptional: true,
},
]}
/>

至少其中之一`content`, `status`, or `activeForm` is required.

### 行為 {/* #behavior-1 */}

* 當更新將任務設定為`in_progress`, any other `in_progress` task is automatically demoted to `pending`.
* 當未找到 ID 時，傳回可用任務 ID 的錯誤。

## `task_complete` {/* #task_complete */}

### 行為 {/* #behavior-2 */}

## `task_check` {/* #task_check */}
