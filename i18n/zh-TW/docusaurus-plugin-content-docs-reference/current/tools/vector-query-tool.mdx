# 建立向量查詢Tool()

這`createVectorQueryTool()`函數創建了一個對向量儲存進行語義搜尋的Tool。它支援過濾、重新排名、特定於資料庫的配置，並與向量儲存後端整合。

## 基本用法 {/* #basic-usage */}

```typescript
import { createVectorQueryTool } from '@mastra/rag'
import { ModelRouterEmbeddingModel } from '@mastra/core/llm'

const queryTool = createVectorQueryTool({
  vectorStoreName: 'pinecone',
  indexName: 'docs',
  model: new ModelRouterEmbeddingModel('openai/text-embedding-3-small'),
})
```

### `QueryResult`物件結構 {/* #queryresult-object-structure */}

```typescript oxfmt:false
{
  id: string;         // Unique chunk/document identifier
  metadata?: any;     // All metadata fields (document ID, etc.)
  vector: number[];   // Embedding vector, or [] when unavailable
  score: number;      // Similarity score for this retrieval
  document: string;   // Full chunk/document text (if available)
}
```

`document`僅由向量存儲填充，其`query()` returns document content, such as Chroma, Elasticsearch, LanceDB, and MongoDB. For other stores, such as PgVector, it's an empty string. Read the chunk text from `sources[i].metadata?.text` (or whichever metadata key you stored it under). `metadata` is `undefined` when the store returns no metadata for a result.

## 結果處理 {/* #result-handling */}

該Tool根據使用者的查詢確定返回結果的數量，預設為 10 個結果。可以根據查詢要求進行調整。

## 帶過濾器的範例 {/* #example-with-filters */}

```typescript
const queryTool = createVectorQueryTool({
  vectorStoreName: 'pinecone',
  indexName: 'docs',
  model: new ModelRouterEmbeddingModel('openai/text-embedding-3-small'),
  enableFilter: true,
})
```

啟用過濾後，Tool會處理查詢以建立與語意搜尋結合的元資料過濾器。過程的工作原理如下：

1. 使用者使用特定的篩選器要求進行查詢，例如“尋找‘版本’欄位大於 2.0 的內容”
2. Agent分析查詢並建立適當的過濾器：
   ```typescript oxfmt:false
   {
      "version": { "$gt": 2.0 }
   }
   ```

這種Agent驅動的方法：

* 將自然語言查詢處理為篩選器規範
* 實現特定於向量存儲的過濾器語法
*

有關詳細的過濾器語法和特定於商店的功能，請參閱[Metadata Filters](../rag/metadata-filters) documentation.

[Agent-Driven Metadata Filtering](https://github.com/mastra-ai/mastra/tree/main/examples/basics/rag/filter-rag) example.

## 重新排名範例 {/* #example-with-reranking */}

```typescript
const queryTool = createVectorQueryTool({
  vectorStoreName: 'milvus',
  indexName: 'documentation',
  model: new ModelRouterEmbeddingModel('openai/text-embedding-3-small'),
  reranker: {
    model: '__GATEWAY_OPENAI_MODEL__',
    options: {
      weights: {
        semantic: 0.5, // Semantic relevance weight
        vector: 0.3, // Vector similarity weight
        position: 0.2, // Original position weight
      },
      topK: 5,
    },
  },
})
```

重新排名透過結合以下方式提高結果品質：

* 語意相關性：使用基於 LLM 的文本相似度評分
* 向量相似度：原始向量距離分數
* 位置偏差：考慮原始結果排序
* 查詢分析：根據查詢特徵進行調整

重新排序器處理初始向量搜尋結果並傳回針對相關性進行最佳化的重新排序清單。

### 運行時配置覆蓋 {/* #runtime-configuration-override */}

您可以在運行時覆蓋資料庫配置以適應不同的場景：

```typescript
import { RequestContext } from '@mastra/core/request-context'

const queryTool = createVectorQueryTool({
  vectorStoreName: 'pinecone',
  indexName: 'docs',
  model: new ModelRouterEmbeddingModel('openai/text-embedding-3-small'),
  databaseConfig: {
    pinecone: {
      namespace: 'development',
    },
  },
})

// Override at runtime
const requestContext = new RequestContext()
requestContext.set('databaseConfig', {
  pinecone: {
    namespace: 'production', // Switch to production namespace
  },
})

const response = await agent.generate('Find information about deployment', {
  requestContext,
})
```

運行時配置支援以下用例：

* 在環境之間切換（開發/暫存/生產）
* 根據負載調整效能參數
* 每個請求應用不同的過濾策略

## 無需 Mastra 伺服器即可使用 {/* #usage-without-a-mastra-server */}

該Tool可以單獨使用來檢索與查詢相符的文檔：

```typescript title="src/index.ts"
import { RequestContext } from '@mastra/core/request-context'
import { createVectorQueryTool } from '@mastra/rag'
import { PgVector } from '@mastra/pg'

const pgVector = new PgVector({
  id: 'pg-vector',
  connectionString: process.env.POSTGRES_CONNECTION_STRING!,
})

const vectorQueryTool = createVectorQueryTool({
  vectorStoreName: 'pgVector', // optional since we're passing in a store
  vectorStore: pgVector,
  indexName: 'embeddings',
  model: new ModelRouterEmbeddingModel('openai/text-embedding-3-small'),
})

const requestContext = new RequestContext()
const queryResult = await vectorQueryTool.execute({ queryText: 'foo', topK: 1 }, { requestContext })

console.log(queryResult.sources)
```

## 用於多租戶應用程式的動態向量存儲 {/* #dynamic-vector-store-for-multi-tenant-applications */}

對於每個租用戶都有獨立資料（例如，單獨的 PostgreSQL 模式）的多租用戶應用程序，您可以傳遞解析器函數而不是靜態向量儲存實例。此函數接收請求上下文，並可以傳回目前租戶的適當向量儲存：

```typescript title="src/index.ts"
import { createVectorQueryTool, VectorStoreResolver } from '@mastra/rag'
import { PgVector } from '@mastra/pg'
import { RequestContext } from '@mastra/core/request-context'

// Cache for tenant-specific vector stores
const vectorStoreCache = new Map<string, PgVector>()

// Resolver function that returns the correct vector store based on tenant
const vectorStoreResolver: VectorStoreResolver = async ({ requestContext }) => {
  const tenantId = requestContext?.get('tenantId')

  if (!tenantId) {
    throw new Error('tenantId is required in request context')
  }

  // Return cached instance or create new one
  if (!vectorStoreCache.has(tenantId)) {
    vectorStoreCache.set(
      tenantId,
      new PgVector({
        id: `pg-vector-${tenantId}`,
        connectionString: process.env.POSTGRES_CONNECTION_STRING!,
        schemaName: `tenant_${tenantId}`, // Each tenant has their own schema
      }),
    )
  }

  return vectorStoreCache.get(tenantId)!
}

const vectorQueryTool = createVectorQueryTool({
  indexName: 'embeddings',
  model: new ModelRouterEmbeddingModel('openai/text-embedding-3-small'),
  vectorStore: vectorStoreResolver, // Dynamic resolution!
})

// Usage with tenant context
const requestContext = new RequestContext()
requestContext.set('tenantId', 'acme-corp')

const result = await vectorQueryTool.execute(
  { queryText: 'company policies', topK: 5 },
  { requestContext },
)
```

這種模式類似於`Agent.memory` supports runtime-defined configuration and enables:

* **模式隔離**：每個租用戶的資料位於單獨的 PostgreSQL 模式中
* **資料庫隔離**：路由到每個租用戶的不同資料庫實例
* **動態配置**：根據請求上下文調整向量存儲設置

## Tool詳情 {/* #tool-details */}

該Tool是透過以下方式創建的：

* **ID**: `VectorQuery {vectorStoreName} {indexName} Tool`
* **輸入模式**：需要queryText和過濾器對象
* **輸出模式**：退貨`relevantContext` (array of chunk metadata) and `sources` (array of `QueryResult`)
