# submitPlanTool

這個內建 Tool 不依賴特定 Agent，可提交實作計畫供使用者審閱。Agent 會將計畫寫入 Markdown 檔案，再將檔案路徑傳給此 Tool。Tool 會暫停這次執行，直到使用者核准或拒絕計畫。

此 Tool 使用原生的 [Tool 暫停機制](/docs/agents/human-in-the-loop#runtime-suspension-with-suspend)：它呼叫 `suspend({ path })`，使 Agent 發出 `tool-call-suspended` 事件。主機端讀取計畫檔案並呈現給使用者，接著依照核准或拒絕的結果恢復執行。

如果在 Agent 執行過程之外呼叫，無法使用 `suspend`，此 Tool 會回傳一段包含檔案路徑、方便閱讀的備用文字。

## 使用範例 {/* #usage-example */}

將 `submitPlanTool` 加入 Agent 的 Tool 集合：

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { submitPlanTool } from '@mastra/core/tools'

const agent = new Agent({
  id: 'planner',
  name: 'Planner',
  instructions: 'Write a plan to a file before starting work, then submit it for approval.',
  model,
  tools: { submitPlanTool },
})
```

處理暫停和恢復：

```typescript title="src/run.ts"
import fs from 'node:fs'

const stream = await agent.stream('Refactor the auth module')

for await (const chunk of stream.fullStream) {
  if (chunk.type === 'tool-call-suspended' && chunk.payload.toolName === 'submit_plan') {
    const { path } = chunk.payload.suspendPayload
    const plan = fs.readFileSync(path, 'utf-8')
    console.log(plan)

    // Approve:
    const resumed = await agent.resumeStream({ action: 'approved' }, { runId: stream.runId })
    for await (const c of resumed.textStream) process.stdout.write(c)
  }
}
```

拒絕並回饋：

```typescript
await agent.resumeStream(
  { action: 'rejected', feedback: 'Add error handling steps' },
  { runId: stream.runId },
)
```

## 核准或拒絕後的行為 {/* #approval-behavior */}

* **核准：**Tool 向模型回傳 `"Plan approved. Proceed with implementation following the approved plan."`，通知模型計畫已獲核准，並請它依照該計畫繼續實作。
* **拒絕並提供意見：**Tool 將意見回傳給模型，並要求模型修改計畫後重新提交。
* **拒絕但未提供意見：**Tool 告知模型先等待使用者的下一則訊息，再修改計畫。

在 [AgentController](/docs/harness/agent-controller) 中使用時，計畫核准後，控制器會從目前模式切換至 `transitionsTo` 設定的模式。若未設定 `transitionsTo`，控制器會切換至其[解析出的預設模式](/reference/agent-controller/agent-controller-class#getdefaultmode)。詳情請參閱[模式](/docs/harness/agent-controller#switch-modes-and-models)。
