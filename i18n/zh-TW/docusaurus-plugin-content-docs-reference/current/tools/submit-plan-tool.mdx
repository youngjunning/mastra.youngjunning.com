# 提交計劃Tool

與Agent無關的內建Tool，可提交實施計劃以供使用者審核。Agent程式將計劃寫入 markdown 檔案並將檔案路徑傳遞給該Tool。該Tool會暫停運行，直到使用者批准或拒絕該計劃。

該Tool透過本機暫停[tool suspension](/docs/agents/human-in-the-loop#runtime-suspension-with-suspend) primitive: it calls `suspend({ path })`，這使得Agent髮出`tool-call-suspended`事件。主機讀取計劃檔案並將其呈現給使用者。然後它會以批准或拒絕的方式恢復。

當在Agent程式運行外部執行時（無`suspend` available), the tool returns a readable fallback string containing the file path.

## 使用範例 {/* #usage-example */}

添加`submitPlanTool` to an agent's toolset:

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { submitPlanTool } from '@mastra/core/tools'

const agent = new Agent({
  id: 'planner',
  name: 'Planner',
  instructions: 'Write a plan to a file before starting work, then submit it for approval.',
  model,
  tools: { submitPlanTool },
})
```

處理暫停和恢復：

```typescript title="src/run.ts"
import fs from 'node:fs'

const stream = await agent.stream('Refactor the auth module')

for await (const chunk of stream.fullStream) {
  if (chunk.type === 'tool-call-suspended' && chunk.payload.toolName === 'submit_plan') {
    const { path } = chunk.payload.suspendPayload
    const plan = fs.readFileSync(path, 'utf-8')
    console.log(plan)

    // Approve:
    const resumed = await agent.resumeStream({ action: 'approved' }, { runId: stream.runId })
    for await (const c of resumed.textStream) process.stdout.write(c)
  }
}
```

拒絕並回饋：

```typescript
await agent.resumeStream(
  { action: 'rejected', feedback: 'Add error handling steps' },
  { runId: stream.runId },
)
```

## 認可行為 {/* #approval-behavior */}

* **得到正式認可的：**&#x5DE5;具返回`"Plan approved. Proceed with implementation following the approved plan."` to the model.
* **被拒絕並回饋：**&#x8A72;Tool返回回饋並要求模型修改計劃並再次提交。
* **沒有回饋就被拒絕：**&#x8A72;Tool告訴模型在修改之前等待用戶的下一則訊息。

在內部使用時[AgentController](/docs/harness/agent-controller), plan approval switches from the current mode to the mode configured by `transitionsTo`. When no `transitionsTo` is configured, the controller switches to its [resolved default mode](/reference/agent-controller/agent-controller-class#getdefaultmode). See [Modes](/docs/harness/agent-controller#switch-modes-and-models) for details.
