# 詢問使用者Tool

與Agent無關的內建Tool，向使用者詢問問題並等待他們的回應。此Tool支援自由文字問題、單選提示和多選提示。

該Tool透過本機暫停[tool suspension](/docs/agents/human-in-the-loop#runtime-suspension-with-suspend) primitive: it calls `suspend()`帶有問題有效負載，這使得Agent髮出`tool-call-suspended`事件並持續運作狀態。繼續運行`agent.resumeStream(answer, { runId })`.

當在Agent程式運行外部執行時（無`suspend` available), the tool returns a readable fallback string containing the question and choices.

## 使用範例 {/* #usage-example */}

添加`askUserTool` to an agent's toolset:

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { askUserTool } from '@mastra/core/tools'

const agent = new Agent({
  id: 'assistant',
  name: 'Assistant',
  instructions: 'Ask the user for clarification when the request is ambiguous.',
  model,
  tools: { askUserTool },
})
```

處理暫停和恢復：

```typescript title="src/run.ts"
const stream = await agent.stream('Summarize my project')

for await (const chunk of stream.fullStream) {
  if (chunk.type === 'tool-call-suspended') {
    const { question, options, selectionMode } = chunk.payload.suspendPayload
    // Present the question to the user, collect their answer, then resume:
    const resumed = await agent.resumeStream('The main repo', { runId: stream.runId })
    for await (const c of resumed.textStream) process.stdout.write(c)
  }
}
```

對於多選提示，請使用字串陣列繼續：

```typescript
await agent.resumeStream(['Add tests', 'Update docs'], { runId: stream.runId })
```

## 恢復數據 {/* #resume-data */}

將使用者的答案傳遞給`agent.resumeStream()`:

* **自由文字和單選：**&#x4E00;個`string`.
* **多選：**&#x4E00;個`string[]` of selected option labels and any custom answer.

工廠和工作室報價**Other…** alongside the suggested options. Select it to turn that option into a text field and enter a custom answer, then select **Submit answer** or press Enter. Single-select prompts resume with the trimmed text as a string. Multi-select prompts resume with the selected labels followed by the trimmed custom text. You can submit custom text without selecting a suggested option.

如果**Other…** is selected, the text field must contain a non-empty answer. Leaving an empty or whitespace-only field unselects **Other…**. Unselecting **Other…** excludes the custom text from the response. The **Other…** label itself is never included in the resume data.
