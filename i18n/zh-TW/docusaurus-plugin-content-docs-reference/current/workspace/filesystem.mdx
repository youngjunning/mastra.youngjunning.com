# WorkspaceFilesystem

**加入版本：** `@mastra/core@1.1.0`

`WorkspaceFilesystem` 介面定義 Workspace 與檔案儲存空間的互動方式。

### `stat(path)` {/* #statpath */}

取得檔案或目錄的中繼資料。

```typescript
const stat = await filesystem.stat('docs/guide.md')
// { name: 'guide.md', path: 'docs/guide.md', type: 'file', size: 1234, createdAt: Date, modifiedAt: Date }
```

**傳回：** `Promise<FileStat>`

```typescript
interface FileStat {
  name: string // File or directory name (basename only)
  path: string // Path within the filesystem namespace; relative to basePath for LocalFilesystem
  type: 'file' | 'directory'
  size: number
  createdAt: Date
  modifiedAt: Date
  mimeType?: string
}
```

內建的 `read_file` Tool 會依據 `mimeType` 決定如何傳回檔案。類型符合 Tool 的 `mediaTypes` 選項的檔案，會以原生媒體內容傳回，大小上限為 `maxMediaBytes`。除非呼叫端傳入 `encoding`，較大的檔案只會傳回中繼資料。預設支援 PNG、JPEG、WebP 和 PDF。未符合 `mediaTypes` 的檔案，若沒有 `mimeType`、屬於文字類型，或類型為 `application/octet-stream`，則會以文字傳回。關於 `mediaTypes` 和 `maxMediaBytes` 選項，請參閱 [Agent Tool](/reference/workspace/workspace-class#filesystem-tools)。若自訂檔案系統始終未設定 `mimeType`，圖片和 PDF 也會以文字傳回。

只為檔案設定 `mimeType`，目錄則不設定。`LocalFilesystem` 使用 `@mastra/core/workspace` 中的 `getMimeType()` 依副檔名查詢類型。對於未知的副檔名，它會傳回 `application/octet-stream`。

```typescript
import { getMimeType } from '@mastra/core/workspace'

const mimeType = type === 'file' ? getMimeType(path) : undefined
```

### `walk(path, options?)` {/* #walkpath-options */}

由 Provider 原生執行遞迴目錄樹走訪，並盡量減少呼叫次數。實作此方法後，Workspace 的 `list_files` Tool 會使用它，無須對每個目錄分別呼叫一次 `readdir`；這對遠端 Provider（如 Sandbox、物件儲存空間）尤其重要。若 `walk` 擲出錯誤，Tool 會自動改用以 `readdir` 為基礎的走訪方式，並透過 Workspace 日誌記錄警告，因為備援方式需要對每個目錄分別呼叫一次。

```typescript
const entries = await filesystem.walk?.('.', { maxDepth: 3 })
// [{ name: 'index.ts', type: 'file', path: 'src/index.ts' }, ...]
```

### `grep(options)` {/* #grepoptions */}

由 Provider 原生執行內容搜尋（例如在 Sandbox 內使用 `rg` 或 `grep`）。實作此方法後，Workspace 的 `grep` Tool 會將搜尋交由它處理，無須下載所有檔案並在主機端搜尋。若某個模式無法原生執行，應擲出 `UnsupportedGrepPatternError`，讓呼叫端捕捉後改用主機端實作。此類備援會以 `info` 層級記錄；`grep` 的其他錯誤也會觸發備援，但會記錄警告，因為主機端搜尋需要讀取每個候選檔案。

```typescript
const results = await filesystem.grep?.({
  pattern: 'TODO',
  path: '.',
  caseSensitive: true,
  includeHidden: false,
})
// [{ path: 'src/index.ts', matches: [{ line: 3, column: 6, text: '// TODO: fix' }] }]
```
