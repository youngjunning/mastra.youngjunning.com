# Agent.getDefaultOptions()

可為 Agent 設定記憶體使用、輸出格式與迭代步數等預設選項。`.getDefaultOptions()` 會傳回這些預設值；若選項由函式提供，則先解析函式。除非呼叫時覆寫，否則這些選項會套用至所有 `stream()` 與 `generate()` 呼叫，也可用來檢查事先未知的 Agent 預設設定。

## 使用範例 {/* #usage-example */}

```typescript
await agent.getDefaultOptions()
```
