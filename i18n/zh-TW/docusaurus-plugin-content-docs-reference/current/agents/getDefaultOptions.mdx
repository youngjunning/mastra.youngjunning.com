# Agent.getDefaultOptions()

可以使用記憶體使用和輸出格式的預設選項來配置Agent。迭代步驟也可以配置。這`.getDefaultOptions()`方法傳回這些預設值，如果它們是函數則解析它們。这些选项适用于所有`stream()`和`generate()`除非被覆蓋，否則調用，並且對於檢查Agent的未知預設值很有用。

## 使用範例 {/* #usage-example */}

```typescript
await agent.getDefaultOptions()
```
