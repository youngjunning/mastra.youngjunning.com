# Agent.listWorkflows()

`.listWorkflows()` 取得 Agent 設定的 Workflow。若設定是函式，這個方法會先呼叫函式來取得 Workflow。Agent 可以透過這些 Workflow，依照預先定義的執行路徑完成複雜的多步驟程序。

## 使用範例 {/* #usage-example */}

```typescript
await agent.listWorkflows()
```
