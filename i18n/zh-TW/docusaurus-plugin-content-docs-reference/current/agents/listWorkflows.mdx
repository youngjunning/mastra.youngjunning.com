# Agent.listWorkflows()

這`.listWorkflows()`方法檢索為Agent程式配置的Workflow，如果它們是函數，則解析它們。這些Workflow使Agent程式能夠透過定義的執行路徑執行複雜的多步驟流程。

## 使用範例 {/* #usage-example */}

```typescript
await agent.listWorkflows()
```
