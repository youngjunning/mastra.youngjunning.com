# Agent.getDefaultStreamOptionsLegacy()

：：：警告

**已棄用**：此方法已棄用，僅適用於 V1 型號。對於 V2 型號，請使用新的[`.getDefaultOptions()`](./getDefaultOptions) method instead.

:::

可以為Agent程式配置記憶體使用和輸出格式的預設流選項。迭代步驟也可以配置。這`.getDefaultStreamOptionsLegacy()` method returns these defaults, resolving them if they're functions. These options apply to all `streamLegacy()` calls unless overridden and are useful for inspecting an agent’s unknown defaults.

## 使用範例 {/* #usage-example */}

```typescript
await agent.getDefaultStreamOptionsLegacy()
```
