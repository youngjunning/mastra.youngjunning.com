# Agent.getDefaultStreamOptionsLegacy()

：：：警告

**已棄用**：此方法已棄用且僅適用於 V1 模型。V2 模型請改用新的 [`.getDefaultOptions()`](./getDefaultOptions) 方法。

:::

可為 Agent 設定記憶體使用、輸出格式和迭代步數等預設串流選項。`.getDefaultStreamOptionsLegacy()` 會傳回這些預設值；若選項由函式提供，则先解析函式。除非呼叫时覆寫，否则這些選項會應用於所有 `streamLegacy()` 呼叫，也可用於檢查事先未知的 Agent 預設設定。

## 使用範例 {/* #usage-example */}

```typescript
await agent.getDefaultStreamOptionsLegacy()
```
