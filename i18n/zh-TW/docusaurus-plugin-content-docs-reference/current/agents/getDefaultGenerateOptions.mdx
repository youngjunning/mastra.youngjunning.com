# Agent.getDefaultGenerateOptionsLegacy()

：：：警告

**已棄用**：此方法已棄用，僅適用於 V1 型號。對於 V2 型號，請使用新的[`.getDefaultOptions()`](./getDefaultOptions) method instead.

:::

使用預設生成選項配置Agent，以控制模型行為和輸出格式，包括Tool和Workflow呼叫。這`.getDefaultGenerateOptionsLegacy()` method retrieves these defaults and resolves any functions. These options apply to all `generateLegacy()` calls unless overridden and are useful for inspecting an agent’s unknown defaults.

## 使用範例 {/* #usage-example */}

```typescript
await agent.getDefaultGenerateOptionsLegacy()
```
