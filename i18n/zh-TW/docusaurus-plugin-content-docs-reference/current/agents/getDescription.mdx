# Agent.getDescription()

`.getDescription()` 會讀取 Agent 設定中的描述，並以字串傳回其用途與能力的說明。

## 使用範例 {/* #usage-example */}

```typescript
agent.getDescription()
```

## 參數 {/* #parameters */}

此方法不接受參數。
