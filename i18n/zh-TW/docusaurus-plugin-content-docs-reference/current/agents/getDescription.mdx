# Agent.getDescription()

這`.getDescription()`方法检索为Agent配置的描述。此方法傳回描述Agent的目的和功能的字串描述。

## 使用範例 {/* #usage-example */}

```typescript
agent.getDescription()
```

## 參數 {/* #parameters */}

此方法不帶參數。
