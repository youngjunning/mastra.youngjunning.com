# Agent.listAgents()

這`.listAgents()`方法檢索為Agent配置的子Agent，如果它們是函數，則解析它們。這些子Agent程式使Agent程式能夠存取其他Agent程式並執行複雜的操作。

## 使用範例 {/* #usage-example */}

```typescript
await agent.listAgents()
```
