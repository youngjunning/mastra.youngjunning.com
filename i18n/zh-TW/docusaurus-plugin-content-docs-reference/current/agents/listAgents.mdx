# Agent.listAgents()

`.listAgents()` 取得 Agent 設定的子 Agent。若設定是函式，此方法會呼叫函式取得子 Agent。Agent 可以藉由這些子 Agent 執行較複雜的動作。

## 使用範例 {/* #usage-example */}

```typescript
await agent.listAgents()
```
