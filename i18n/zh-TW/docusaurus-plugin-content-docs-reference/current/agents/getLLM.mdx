# Agent.getLLM()

`.getLLM()` 方法取得為 Agent 設定的語言模型執行個體；若模型由函式提供，則會先解析該函式。也可傳入請求層級的 `model` 覆寫設定，而不會修改 Agent 已設定的模型。

## 使用範例 {/* #usage-example */}

```typescript
await agent.getLLM()
```

```typescript
await agent.getLLM({
  model: '__GATEWAY_OPENAI_MODEL__',
})
```
