# Agent.getVoice()

`.getVoice()` 取得 Agent 設定的語音 Provider。若設定是函式，就會呼叫該函式取得 Provider，以使用文字轉語音與語音轉文字功能。

## 使用範例 {/* #usage-example */}

```typescript
await agent.getVoice()
```
