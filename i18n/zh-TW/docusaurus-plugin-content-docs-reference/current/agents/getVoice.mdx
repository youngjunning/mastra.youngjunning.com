# Agent.getVoice()

這`.getVoice()`方法檢索為Agent配置的語音提供程序，如果它是函數，則解析它。此方法用於存取Agent的語音功能，以實現文字轉語音和語音到文字的功能。

## 使用範例 {/* #usage-example */}

```typescript
await agent.getVoice()
```
