# `.listSkills()`

傳回客服人員可用的所有技能的元數據，包括客服人員等級和Workspace技能。

## 使用範例 {/* #usage-example */}

```typescript title="src/routes/skills.ts"
import { agent } from '../mastra/agents'

const skills = await agent.listSkills()

for (const skill of skills) {
  console.log(`${skill.name}: ${skill.description}`)
}
```

## 傳回值 {/* #return-value */}

退貨`Promise<SkillMetadata[]>`.

每個條目都包含已發現技能的元資料：

```typescript
interface SkillMetadata {
  name: string
  description: string
  path: string
  license?: string
  compatibility?: unknown
  'user-invocable'?: boolean
  metadata?: Record<string, unknown>
}
```

## 合併行為 {/* #merging-behavior */}

當座席級技能和Workspace技能都配置時，`.listSkills()` returns the merged set. Agent-level skills take precedence on name conflicts. If both define a skill called `code-review`, only the agent-level version is returned.
