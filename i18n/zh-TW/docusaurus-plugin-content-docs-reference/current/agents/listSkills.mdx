# `.listSkills()`

傳回 Agent 可使用的所有 Skill 中繼資料，包含 Agent 層級及 Workspace 的 Skill。

## 使用範例 {/* #usage-example */}

```typescript title="src/routes/skills.ts"
import { agent } from '../mastra/agents'

const skills = await agent.listSkills()

for (const skill of skills) {
  console.log(`${skill.name}: ${skill.description}`)
}
```

## 傳回值 {/* #return-value */}

傳回 `Promise<SkillMetadata[]>`。

每個項目都包含一個已找到的 Skill 的中繼資料。

```typescript
interface SkillMetadata {
  name: string
  description: string
  path: string
  license?: string
  compatibility?: unknown
  'user-invocable'?: boolean
  metadata?: Record<string, unknown>
}
```

## 合併規則 {/* #merging-behavior */}

若同時設定了 Agent 層級和 Workspace 的 Skill，`.listSkills()` 會傳回合併結果。名稱相同時，以 Agent 層級的 Skill 為優先。若兩邊都有名為 `code-review` 的 Skill，就只會傳回 Agent 層級的版本。
