# Agent.getInstructions()

`.getInstructions()` 取得 Agent 設定的指令。若設定是函式，此方法會呼叫該函式。這些指令引導 Agent 的行為，並定義其能力與限制。

## 使用範例 {/* #usage-example */}

```typescript
await agent.getInstructions()
```
