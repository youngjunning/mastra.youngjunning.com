# Agent.listTools()

`.listTools()` 取得 Agent 設定的 Tool。若設定是函式，這個方法會呼叫該函式來取得 Tool。Tool 讓 Agent 能執行特定動作或存取外部系統。

## 使用範例 {/* #usage-example */}

```typescript
await agent.listTools()
```
