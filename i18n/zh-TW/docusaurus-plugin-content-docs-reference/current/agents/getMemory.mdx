# Agent.getMemory()

`.getMemory()` 取得與 Agent 關聯的 Memory 系統，讓 Agent 能在不同對話之間儲存和查詢資訊。

## 使用範例 {/* #usage-example */}

```typescript
await agent.getMemory()
```
