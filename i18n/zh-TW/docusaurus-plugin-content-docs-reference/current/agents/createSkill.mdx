# `createSkill()`

建立不需要檔案系統或 Workspace 的內嵌 Skill，可直接傳入 Agent 的 `skills` 設定。

傳回的物件實作 `Skill` 介面，可用於任何支援檔案系統 Skill 的位置。

## 使用範例 {/* #usage-example */}

```typescript title="src/mastra/skills.ts"
import { createSkill } from '@mastra/core/skills'

const reviewSkill = createSkill({
  name: 'code-review',
  description: 'Use when reviewing code changes.',
  instructions: `
    When reviewing code:
    1. Check for correctness
    2. Check for style consistency
    3. Look for potential bugs
  `,
  references: {
    'checklist.md': '# Review Checklist\n- No unused imports\n- Error handling present',
  },
})
```

## 傳回值 {/* #return-value */}

傳回 `InlineSkill` 物件，它實作了 `Skill` 介面：

```typescript
interface InlineSkill extends Skill {
  __inline: true
  __referenceContents: Record<string, string>
}
```

此 Skill 會取得 `inline/<name>` 形式的虛擬路徑（例如 `inline/code-review`）。

## 驗證 {/* #validation */}

`createSkill()` 使用與檔案系統 Skill 相同的規則驗證輸入：

- `name` 為必填，且必須是有效的 slug
- `description` 為必填

驗證失敗時會擲出 `Error`，並提供無效欄位的詳細資訊。

```typescript
// Throws: Invalid skill "": name: Skill name cannot be empty
createSkill({ name: '', description: 'test', instructions: 'test' })
```
