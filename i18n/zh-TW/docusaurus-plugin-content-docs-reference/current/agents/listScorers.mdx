# Agent.listScorers()

`.listScorers()` 取得 Agent 的評分設定。若設定是函式，此方法會呼叫該函式。你可以用這個方法存取用於評估 Agent 回覆和表現的評分系統。

## 使用範例 {/* #usage-example */}

```typescript
await agent.listScorers()
```
