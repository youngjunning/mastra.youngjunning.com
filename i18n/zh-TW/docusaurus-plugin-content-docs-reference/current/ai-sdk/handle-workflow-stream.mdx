# handleWorkflowStream()

此函式不依賴特定框架，可將 Workflow 執行以相容 AI SDK 的格式串流輸出。如需在 Hono 或 Mastra 內建的 [apiRoutes](/docs/server/custom-api-routes) 功能之外處理 Workflow 串流，可直接使用此函式。

`handleWorkflowStream()` 會回傳 `ReadableStream`，可透過 [`createUIMessageStreamResponse()`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/create-ui-message-stream-response) 將其包裝成回應。

`handleWorkflowStream()` 預設沿用 AI SDK v5 的行為。若應用程式的型別定義以 AI SDK v6 為準，請傳入 `version: 'v6'`。

若要在 Mastra 伺服器內建立 Workflow 路由，請使用 [`workflowRoute()`](/reference/ai-sdk/workflow-route)。

:::tip Workflow 中的 Agent 串流輸出

當 Workflow 步驟將 Agent 串流傳給 Workflow writer 時（例如 `await response.fullStream.pipeTo(writer)`），即使 Agent 在 Workflow 步驟內執行，其文字片段和 Tool 呼叫也會即時轉送到 UI 串流。

詳情請參閱 [Workflow 串流處理](/docs/workflows/overview#inspecting-workflow-stream-payloads)。

:::

## 使用範例 {/* #usage-example */}

以下為 Next.js App Router 範例：

```typescript title="app/api/workflow/route.ts"
import { handleWorkflowStream } from '@mastra/ai-sdk'
import { createUIMessageStreamResponse } from 'ai'
import { mastra } from '@/src/mastra'

export async function POST(req: Request) {
  const params = await req.json()
  const stream = await handleWorkflowStream({
    mastra,
    workflowId: 'weatherWorkflow',
    params,
  })
  return createUIMessageStreamResponse({ stream })
}
```
