# 處理網路流()

:::警告\[已棄用]

Agent網路已棄用，並將在未來版本中刪除。使用[supervisor agents](/docs/subagents) with `agent.stream()`或者`agent.generate()`反而。請參閱[遷移指南](/reference/migrations/network-to-supervisor)升級。

:::

與框架無關的處理程序，用於以 AI SDK 相容格式進行串流網路執行。當您需要處理Hono或Mastra自己以外的網路串流時，請直接使用此功能[apiRoutes](/docs/server/custom-api-routes) feature.

`handleNetworkStream()`返回一個`ReadableStream` that you can wrap with [`createUIMessageStreamResponse()`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/create-ui-message-stream-response).

`handleNetworkStream()`保留現有的 AI SDK v5/預設行為。如果您的應用程式是針對 AI SDK v6 輸入的，請傳遞`version: 'v6'`.

使用[`networkRoute()`](/reference/ai-sdk/network-route) if you want to create a network route inside a Mastra server.

## 使用範例 {/* #usage-example */}

Next.js 應用程式路由器範例：

```typescript title="app/api/network/route.ts"
import { handleNetworkStream } from '@mastra/ai-sdk'
import { createUIMessageStreamResponse } from 'ai'
import { mastra } from '@/src/mastra'

export async function POST(req: Request) {
  const params = await req.json()
  const stream = await handleNetworkStream({
    mastra,
    agentId: 'routingAgent',
    params,
  })
  return createUIMessageStreamResponse({ stream })
}
```
