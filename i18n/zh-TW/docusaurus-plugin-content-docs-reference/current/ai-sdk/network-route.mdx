# 網路路由()

:::警告\[已棄用]

Agent網路已棄用，並將在未來版本中刪除。使用[supervisor agents](/docs/subagents) with `agent.stream()`或者`agent.generate()`反而。請參閱[遷移指南](/reference/migrations/network-to-supervisor)升級。

:::

建立網路路由處理程序，用於以 AI SDK 格式進行串流網路執行。該函數註冊一個 HTTP`POST` endpoint that accepts messages and executes an agent network before streaming the response to the client in AI SDK-compatible format. Agent networks let a routing agent delegate tasks to other agents. Use this function inside a [custom API route](/docs/server/custom-api-routes).

使用[`handleNetworkStream()`](/reference/ai-sdk/handle-network-stream) if you need a framework-agnostic handler.

`networkRoute()`保留現有的 AI SDK v5/預設行為。如果您的應用程式是針對 AI SDK v6 輸入的，請傳遞`version: 'v6'`.

## 使用範例 {/* #usage-example */}

此範例顯示如何在以下位置設定網路路由`/network` endpoint that uses an agent with the ID `weatherAgent`.

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { networkRoute } from '@mastra/ai-sdk'

export const mastra = new Mastra({
  server: {
    apiRoutes: [
      networkRoute({
        path: '/network',
        agent: 'weatherAgent',
      }),
    ],
  },
})
```

您也可以使用基於運行時定義的Agent程式路由`agentId`. The URL `/network/weatherAgent` will resolve to the agent with the ID `weatherAgent`.

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { networkRoute } from '@mastra/ai-sdk'

export const mastra = new Mastra({
  server: {
    apiRoutes: [
      networkRoute({
        path: '/network/:agentId',
      }),
    ],
  },
})
```

## 附加配置 {/* #additional-configuration */}

您可以使用[`prepareSendMessagesRequest`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/use-chat#transport.default-chat-transport.prepare-send-messages-request) to customize the request sent to the network route, for example to pass additional configuration to the agent:

```typescript
const { error, status, sendMessage, messages, regenerate, stop } = useChat({
  transport: new DefaultChatTransport({
    api: 'http://localhost:4111/network',
    prepareSendMessagesRequest({ messages }) {
      return {
        body: {
          messages,
          // Pass memory config
          memory: {
            thread: 'user-1',
            resource: 'user-1',
          },
        },
      }
    },
  }),
})
```
