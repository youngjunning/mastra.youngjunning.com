# WorkflowSnapshotToStream()

轉換一個`WorkflowState`對象（由返回`workflow.getWorkflowRunById()`) 變成`ReadableStream`AI SDK UIMessage 資料部分。該流包含相同的`WorkflowDataPart`和`WorkflowStepDataPart`活著的塊[`workflowRoute()`](/reference/ai-sdk/workflow-route)產生。

當您想要使用渲染即時Workflow的相同 UI 元件來顯示已完成或暫停的Workflow運行時，請使用此選項。

## 使用範例 {/* #usage-example */}

Next.js App Router 端點，以串流的形式重播過去的Workflow：

```typescript title="app/api/workflow-replay/route.ts"
import { workflowSnapshotToStream } from '@mastra/ai-sdk'
import { createUIMessageStreamResponse } from 'ai'
import { mastra } from '@/src/mastra'

export async function GET(req: Request) {
  const { searchParams } = new URL(req.url)
  const runId = searchParams.get('runId')!

  const workflowRun = await mastra.getWorkflow('myWorkflow').getWorkflowRunById(runId)

  if (!workflowRun) {
    return new Response('Not found', { status: 404 })
  }

  const stream = workflowSnapshotToStream(workflowRun)
  return createUIMessageStreamResponse({ stream })
}
```

## 退貨 {/* #returns */}

`ReadableStream`：AI SDK UIMessage 資料部分的流，包含：

* 一個`start` marker
* 一個`WorkflowDataPart` with the workflow status and all step summaries
* 一個`WorkflowStepDataPart` for each step with its full output
* 一個`finish` marker

將此流傳遞給[`createUIMessageStreamResponse()`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/create-ui-message-stream-response) or `createUIMessageStream()` from the AI SDK.
