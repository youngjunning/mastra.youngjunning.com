# AI SDK

如果你已直接使用 [Vercel AI SDK](https://sdk.vercel.ai)，希望在不改用完整 Mastra Agent API 的情況下加入 [Processor](/docs/agents/processors) 或 [Memory](/docs/memory/memory-processors) 等 Mastra 功能，可以使用 [`withMastra()`](/reference/ai-sdk/with-mastra) 包裝任何 AI SDK 模型。這樣既可保留現有 AI SDK 程式碼，也能加入輸入／輸出處理及對話持久化，包括內容過濾。

:::tip

若要將 Mastra 與 AI SDK UI（例如 `useChat()`）搭配使用，請參閱 [AI SDK UI 指南](/integrations/agentic-ui/ai-sdk-ui)。

:::

## 安裝 {/* #installation */}

安裝 `@mastra/ai-sdk` 後即可使用 `withMastra()` 函式。

```bash npm2yarn
npm install @mastra/ai-sdk@latest
```

## 範例 {/* #examples */}

### 使用 Processor {/* #with-processors */}

Processor 可在訊息送往模型前（`processInput`）及收到回應後（`processOutputResult`）處理訊息。以下範例建立記錄各階段訊息數量的日誌 Processor，再用它包裝 OpenAI 模型。

```typescript title="src/example.ts"
import { openai } from '@ai-sdk/openai'
import { generateText } from 'ai'
import { withMastra } from '@mastra/ai-sdk'
import type { Processor } from '@mastra/core/processors'

const loggingProcessor: Processor<'logger'> = {
  id: 'logger',
  async processInput({ messages }) {
    console.log('Input:', messages.length, 'messages')
    return messages
  },
  async processOutputResult({ messages }) {
    console.log('Output:', messages.length, 'messages')
    return messages
  },
}

const model = withMastra(openai('gpt-5.4'), {
  inputProcessors: [loggingProcessor],
  outputProcessors: [loggingProcessor],
})

const { text } = await generateText({
  model,
  prompt: 'What is 2 + 2?',
})
```

### 使用 Memory {/* #with-memory */}

Memory 會在呼叫 LLM 前自動從儲存空間載入過往訊息，並在呼叫後儲存新訊息。以下範例設定 libSQL 儲存後端，以持久保存對話紀錄，並載入最近 10 則訊息作為上下文。

```typescript title="src/memory-example.ts"
import { openai } from '@ai-sdk/openai'
import { generateText } from 'ai'
import { withMastra } from '@mastra/ai-sdk'
import { LibSQLStore } from '@mastra/libsql'

const storage = new LibSQLStore({
  id: 'my-app',
  url: 'file:./data.db',
})
await storage.init()

const memoryStorage = await storage.getStore('memory')

const model = withMastra(openai('gpt-5.4'), {
  memory: {
    storage: memoryStorage!,
    threadId: 'user-thread-123',
    resourceId: 'user-123',
    lastMessages: 10,
  },
})

const { text } = await generateText({
  model,
  prompt: 'What did we talk about earlier?',
})
```

### 同時使用 Processor 和 Memory {/* #with-processors--memory */}

Processor 與 Memory 可一起使用。輸入 Processor 在 Memory 載入歷史訊息後執行；輸出 Processor 則在 Memory 儲存回應前執行。

```typescript title="src/combined-example.ts"
import { openai } from '@ai-sdk/openai'
import { generateText } from 'ai'
import { withMastra } from '@mastra/ai-sdk'
import { LibSQLStore } from '@mastra/libsql'

const storage = new LibSQLStore({ id: 'my-app', url: 'file:./data.db' })
await storage.init()

const memoryStorage = await storage.getStore('memory')

const model = withMastra(openai('gpt-5.4'), {
  inputProcessors: [myGuardProcessor],
  outputProcessors: [myLoggingProcessor],
  memory: {
    storage: memoryStorage!,
    threadId: 'thread-123',
    resourceId: 'user-123',
    lastMessages: 10,
  },
})

const { text } = await generateText({
  model,
  prompt: 'Hello!',
})
```
