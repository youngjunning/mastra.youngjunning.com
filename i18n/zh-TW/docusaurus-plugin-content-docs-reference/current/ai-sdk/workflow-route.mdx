# workflowRoute()

建立以 AI SDK 格式串流傳送 Workflow 執行結果的路由處理常式。此函式會註冊 HTTP `POST` 端點，接收輸入資料並執行 Workflow，再以相容 AI SDK 的格式將回應串流傳送至用戶端。請在[自訂 API 路由](/docs/server/custom-api-routes)中使用。

如需不依賴特定框架的處理常式，請使用 [`handleWorkflowStream()`](/reference/ai-sdk/handle-workflow-stream)。

`workflowRoute()` 維持現有的 AI SDK v5 預設行為。如果應用程式依照 AI SDK v6 的型別定義撰寫，請傳入 `version: 'v6'`。

:::tip Workflow 中的 Agent 串流

當 Workflow 步驟將 Agent 的串流導入 Workflow writer 時（例如 `await response.fullStream.pipeTo(writer)`），即使 Agent 在 Workflow 步驟內執行，其文字區塊和工具呼叫仍會即時轉送至 UI 串流。

詳情請參閱 [Workflow 串流傳輸](/docs/workflows/overview#inspecting-workflow-stream-payloads)。

:::

## 使用範例 {/* #usage-example */}

以下範例在 `/workflow` 端點設定 Workflow 路由，使用 ID 為 `weatherWorkflow` 的 Workflow。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { workflowRoute } from '@mastra/ai-sdk'

export const mastra = new Mastra({
  server: {
    apiRoutes: [
      workflowRoute({
        path: '/workflow',
        workflow: 'weatherWorkflow',
      }),
    ],
  },
})
```

也可以根據 `workflowId` 在執行階段選擇 Workflow。URL `/workflow/weatherWorkflow` 會對應至 ID 為 `weatherWorkflow` 的 Workflow。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { workflowRoute } from '@mastra/ai-sdk'

export const mastra = new Mastra({
  server: {
    apiRoutes: [
      workflowRoute({
        path: '/workflow/:workflowId',
      }),
    ],
  },
})
```

## 附加配置 {/* #additional-configuration */}

您可以使用 [`prepareSendMessagesRequest`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/use-chat#transport.default-chat-transport.prepare-send-messages-request) 自訂傳送至 Workflow 路由的請求，例如將額外設定傳入 Workflow：

```typescript
const { error, status, sendMessage, messages, regenerate, stop } = useChat({
  transport: new DefaultChatTransport({
    api: 'http://localhost:4111/workflow',
    prepareSendMessagesRequest({ messages }) {
      return {
        body: {
          inputData: {
            city: messages[messages.length - 1].parts[0].text,
          },
          // Or resumeData for resuming a suspended workflow
          resumeData: {
            confirmation: messages[messages.length - 1].parts[0].text,
          },
        },
      }
    },
  }),
})
```
