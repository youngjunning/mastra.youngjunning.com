# StagehandBrowser 類

`StagehandBrowser` 透過 [Stagehand](https://github.com/browserbase/stagehand) 提供 AI 瀏覽器自動化。它以自然語言指令完成互動，不必使用元素參照。

若希望 AI 根據自然語言理解並執行瀏覽器操作，可使用 `StagehandBrowser`。如需依元素參照進行確定性自動化，請參閱 [`AgentBrowser`](/reference/browser/agent-browser)。

## 使用範例 {/* #usage-example */}

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { StagehandBrowser } from '@mastra/stagehand'

const browser = new StagehandBrowser({
  headless: true,
  model: '__GATEWAY_OPENAI_MODEL__',
  selfHeal: true,
})

export const browserAgent = new Agent({
  id: 'browser-agent',
  name: 'Browser Agent',
  instructions: `You can browse the web using natural language.
Use stagehand_act to perform actions like "click the login button".
Use stagehand_extract to get data from pages.`,
  model: '__GATEWAY_OPENAI_MODEL__',
  browser,
})
```

## 工具 {/* #tools */}

`StagehandBrowser` 提供 7 個由 AI 驅動的瀏覽器自動化 Tool。

設定 `recording` 後，`StagehandBrowser` 還會加入 Beta 版的 `browser_record` 與 `browser_record_caption` Tool。請參閱[瀏覽器錄製（Beta）](/docs/browser#record-browser-sessions)。

核心 Tool：

|Tool|描述 |
| - | - |
| `stagehand_act` | 根據自然語言指令執行操作 |
| `stagehand_extract` | 從頁面擷取結構化資料 |
| `stagehand_observe` | 找出頁面上可用的元素 |
| `stagehand_navigate` | 導覽至網址 |
| `stagehand_tabs` | 管理瀏覽器分頁 |
| `stagehand_screenshot` | 擷取 PNG 截圖（預設僅檢視區；設定 `fullPage: true` 可擷取整頁） |
| `stagehand_close` | 關閉瀏覽器 |

若要排除特定 Tool，請在建構函式中傳入 `excludeTools`：

```typescript
const browser = new StagehandBrowser({
  excludeTools: ['stagehand_screenshot'],
})
```

## 工具參考 {/* #tool-reference */}

### `stagehand_act` {/* #stagehand_act */}

依自然語言指令執行操作。AI 會理解指令並執行相應的瀏覽器操作。

```text
// Tool input
{
  "instruction": "click the login button",
  "variables": { "username": "john" },
  "useVision": true,
  "timeout": 30000
}

// With variable substitution
{
  "instruction": "type %email% into the email field",
  "variables": { "email": "user@example.com" }
}
```

|參數|型別 |說明 |
| - | - | - |
| `instruction` | `string` | 自然語言指令（必填） |
| `variables` | `Record<string, string>` | 用來取代 %variableName% 的變數（選填） |
| `useVision` | `boolean` | 啟用視覺功能（選填） |
| `timeout` | `number` | 逾時時間，單位為毫秒（選填） |

**返回：**

```typescript
interface ActResult {
  success: boolean
  message?: string
  action?: string
  url?: string
}
```

### `stagehand_extract` {/* #stagehand_extract */}

使用自然語言指令從頁面擷取結構化資料。

```text
// Basic extraction
{
  "instruction": "extract all product names and prices"
}

// With schema for structured output
{
  "instruction": "extract the product information",
  "schema": {
    "type": "object",
    "properties": {
      "name": { "type": "string" },
      "price": { "type": "number" },
      "inStock": { "type": "boolean" }
    }
  }
}
```

**返回：**

```typescript
interface ExtractResult<T = unknown> {
  success: boolean
  data?: T
  hint?: string
  error?: string
  url?: string
}
```

### `stagehand_observe` {/* #stagehand_observe */}

找出頁面上可用的元素，傳回其選擇器與描述。

```text
// Find specific elements
{
  "instruction": "find all buttons related to checkout"
}

// Find all interactive elements
{
  "onlyVisible": true
}
```

|參數|型別 |說明 |
| - | - | - |
| `instruction` | `string` | 自然語言指令（選填；省略時尋找所有元素） |
| `onlyVisible` | `boolean` | 僅包含可見元素（選填） |
| `timeout` | `number` | 逾時時間，單位為毫秒（選填） |

**返回：**

```typescript
interface ObserveResult {
  success: boolean
  actions: StagehandAction[]
  url?: string
}

interface StagehandAction {
  selector: string
  description: string
  method?: string
  arguments?: string[]
}
```

### `stagehand_navigate` {/* #stagehand_navigate */}

前往指定網址。

```text
// Tool input
{
  "url": "https://example.com",
  "waitUntil": "domcontentloaded"
}
```

|參數|型別 |說明 |
| - | - | - |
| `url` | `string` | 要開啟的網址（必填） |
| `waitUntil` | `"load" \| "domcontentloaded" \| "networkidle"` | 判定導覽完成的時機（選填） |

### `stagehand_tabs` {/* #stagehand_tabs */}

管理瀏覽器分頁。

```text
// List all tabs
{ "action": "list" }

// Open new tab
{ "action": "new", "url": "https://example.com" }

// Switch to tab by index
{ "action": "switch", "index": 0 }

// Close tab by index (or current if omitted)
{ "action": "close", "index": 1 }
```

### `stagehand_screenshot` {/* #stagehand_screenshot */}

將目前頁面擷取為 PNG 截圖（預設僅檢視區；設定 `fullPage: true` 可擷取整頁）。傳回的圖片內容可由具備視覺能力的模型直接理解。若只需要文字或結構化資料，請使用 `stagehand_observe` 或 `stagehand_extract`。

```text
// Viewport only (default)
{}

// Full scrollable page
{ "fullPage": true }
```

|參數|型別 |說明 |
| - | - | - |
| `fullPage` | `boolean` | 擷取完整可捲動頁面，而非僅檢視區（選填；預設 false） |

### `stagehand_close` {/* #stagehand_close */}

關閉瀏覽器並釋放資源。

```text
// Tool input (no parameters required)
{}
```

## 使用 Browserbase {/* #using-browserbase */}

使用 Browserbase 在雲端執行 Stagehand：

```typescript
const browser = new StagehandBrowser({
  env: 'BROWSERBASE',
  apiKey: process.env.BROWSERBASE_API_KEY,
  projectId: process.env.BROWSERBASE_PROJECT_ID,
  model: '__GATEWAY_OPENAI_MODEL__',
})
```

## 模型設定 {/* #model-configuration */}

設定 Stagehand 操作所用的 AI 模型：

```typescript
// String format: "provider/model"
const browser = new StagehandBrowser({
  model: '__GATEWAY_OPENAI_MODEL__',
})

// Object format for custom configuration
const browser = new StagehandBrowser({
  model: {
    modelName: 'gpt-5.4',
    apiKey: process.env.OPENAI_API_KEY,
    baseURL: 'https://api.openai.com/v1',
  },
})
```

## AgentBrowser 與 StagehandBrowser {/* #agentbrowser-vs-stagehandbrowser */}

| 比較項目 | AgentBrowser | StagehandBrowser |
| - | - | - |
| **操作方式** | 確定性元素參照（`@e5`） | 自然語言 |
| **精確度** | 精確定位元素 | AI 理解指令 |
| **彈性** | 須先取得快照 | 可直接給出指令 |
| **適用情境** | 可重現的自動化 | 可適應變化的自動化 |
| **速度** | 較快（不需 AI 推論） | 較慢（需要 AI 推論） |

需要精確、可重現的自動化時，選擇 `AgentBrowser`；需要彈性的自然語言互動時，選擇 `StagehandBrowser`。
