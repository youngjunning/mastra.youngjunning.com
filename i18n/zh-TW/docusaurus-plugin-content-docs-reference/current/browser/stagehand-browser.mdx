# StagehandBrowser 類

這`StagehandBrowser`類別提供人工智慧驅動的瀏覽器自動化，使用[舞台工作人員](https://github.com/browserbase/stagehand)。它使用自然語言指令進行交互，而不是元素引用。

使用`StagehandBrowser` when you want AI to interpret and execute browser actions from natural language. For deterministic automation using element refs, see [`AgentBrowser`](/reference/browser/agent-browser).

## 使用範例 {/* #usage-example */}

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { StagehandBrowser } from '@mastra/stagehand'

const browser = new StagehandBrowser({
  headless: true,
  model: '__GATEWAY_OPENAI_MODEL__',
  selfHeal: true,
})

export const browserAgent = new Agent({
  id: 'browser-agent',
  name: 'Browser Agent',
  instructions: `You can browse the web using natural language.
Use stagehand_act to perform actions like "click the login button".
Use stagehand_extract to get data from pages.`,
  model: '__GATEWAY_OPENAI_MODEL__',
  browser,
})
```

## Tool {/* #tools */}

`StagehandBrowser`提供 7 個人工智慧驅動的瀏覽器自動化Tool。

什麼時候`recording` is configured, `StagehandBrowser` also adds the Beta `browser_record` and `browser_record_caption` tools. See [Browser recording (Beta)](/docs/browser#record-browser-sessions).

核心Tool：

|Tool|描述 |
| - | - |
|`stagehand_act` | Perform actions using natural language instructions |
| `stagehand_extract` | Extract structured data from pages |
| `stagehand_observe` | Discover useful elements on a page |
| `stagehand_navigate` | Navigate to a URL |
| `stagehand_tabs` | Manage browser tabs |
| `stagehand_screenshot` | Capture a screenshot as PNG (viewport by default; set `fullPage: true`為整頁）|
|`stagehand_close`|關閉瀏覽器 |

若要排除特定Tool，請傳遞`excludeTools` in the constructor:

```typescript
const browser = new StagehandBrowser({
  excludeTools: ['stagehand_screenshot'],
})
```

## Tool參考 {/* #tool-reference */}

### `stagehand_act` {/* #stagehand_act */}

使用自然語言指令執行操作。 AI 解釋您的指示並執行適當的瀏覽器操作。

```text
// Tool input
{
  "instruction": "click the login button",
  "variables": { "username": "john" },
  "useVision": true,
  "timeout": 30000
}

// With variable substitution
{
  "instruction": "type %email% into the email field",
  "variables": { "email": "user@example.com" }
}
```

|參數|型別 |說明 |
| - | - | - |
|`instruction` | `string` | Natural language instruction (required) |
| `variables` | `Record<string, string>` | Variables for %variableName% substitution (optional) |
| `useVision` | `boolean` | Enable vision capabilities (optional) |
| `timeout` | `number` | Timeout in ms (optional) |

**返回：**

```typescript
interface ActResult {
  success: boolean
  message?: string
  action?: string
  url?: string
}
```

### `stagehand_extract` {/* #stagehand_extract */}

使用自然語言指令從頁面中提取結構化資料。

```text
// Basic extraction
{
  "instruction": "extract all product names and prices"
}

// With schema for structured output
{
  "instruction": "extract the product information",
  "schema": {
    "type": "object",
    "properties": {
      "name": { "type": "string" },
      "price": { "type": "number" },
      "inStock": { "type": "boolean" }
    }
  }
}
```

**返回：**

```typescript
interface ExtractResult<T = unknown> {
  success: boolean
  data?: T
  hint?: string
  error?: string
  url?: string
}
```

### `stagehand_observe` {/* #stagehand_observe */}

發現頁面上有用的元素。傳回元素及其選擇器和描述的清單。

```text
// Find specific elements
{
  "instruction": "find all buttons related to checkout"
}

// Find all interactive elements
{
  "onlyVisible": true
}
```

|參數|型別 |說明 |
| - | - | - |
|`instruction` | `string` | Natural language instruction (optional, omit to find all) |
| `onlyVisible` | `boolean` | Only include visible elements (optional) |
| `timeout` | `number` | Timeout in ms (optional) |

**返回：**

```typescript
interface ObserveResult {
  success: boolean
  actions: StagehandAction[]
  url?: string
}

interface StagehandAction {
  selector: string
  description: string
  method?: string
  arguments?: string[]
}
```

### `stagehand_navigate` {/* #stagehand_navigate */}

導航到 URL。

```text
// Tool input
{
  "url": "https://example.com",
  "waitUntil": "domcontentloaded"
}
```

|參數|型別 |說明 |
| - | - | - |
|`url` | `string` | URL to open (required) |
| `waitUntil` | `"load" \| "domcontentloaded" \| "networkidle"` | When to consider navigation complete (optional) |

### `stagehand_tabs` {/* #stagehand_tabs */}

管理瀏覽器標籤。

```text
// List all tabs
{ "action": "list" }

// Open new tab
{ "action": "new", "url": "https://example.com" }

// Switch to tab by index
{ "action": "switch", "index": 0 }

// Close tab by index (or current if omitted)
{ "action": "close", "index": 1 }
```

### `stagehand_screenshot` {/* #stagehand_screenshot */}

將目前頁面截圖為PNG（預設為視口。設定`fullPage: true` for full-page capture). Returns image content that vision-capable models can interpret directly. Use `stagehand_observe` or `stagehand_extract` when you only need text or structured data.

```text
// Viewport only (default)
{}

// Full scrollable page
{ "fullPage": true }
```

|參數|型別 |說明 |
| - | - | - |
|`fullPage` | `boolean` | Capture the full scrollable page instead of only the viewport (optional, default: false) |

### `stagehand_close` {/* #stagehand_close */}

關閉瀏覽器並清理資源。

```text
// Tool input (no parameters required)
{}
```

## 使用瀏覽器庫 {/* #using-browserbase */}

使用 Browserbase 在雲端中運行 Stagehand：

```typescript
const browser = new StagehandBrowser({
  env: 'BROWSERBASE',
  apiKey: process.env.BROWSERBASE_API_KEY,
  projectId: process.env.BROWSERBASE_PROJECT_ID,
  model: '__GATEWAY_OPENAI_MODEL__',
})
```

## 型號配置 {/* #model-configuration */}

配置用於 Stagehand 操作的 AI 模型：

```typescript
// String format: "provider/model"
const browser = new StagehandBrowser({
  model: '__GATEWAY_OPENAI_MODEL__',
})

// Object format for custom configuration
const browser = new StagehandBrowser({
  model: {
    modelName: 'gpt-5.4',
    apiKey: process.env.OPENAI_API_KEY,
    baseURL: 'https://api.openai.com/v1',
  },
})
```

## AgentBrowser 與 StagehandBrowser {/* #agentbrowser-vs-stagehandbrowser */}

|方面|Agent瀏覽器 | Stagehand 瀏覽器 |
| - | - | - |
|**Approach** | Deterministic refs (`@e5`) | Natural language |
| **Precision** | Exact element targeting | AI interpretation |
| **Flexibility** | Requires a snapshot first | Direct instructions |
| **Use case** | Reproducible automation | Adaptive automation |
| **Speed** | Faster (no AI inference) | Slower (AI inference) |

選擇`AgentBrowser` for precise, reproducible automation. Choose `StagehandBrowser` for flexible, natural language interactions.
