# AgentBrowser 類別

`AgentBrowser` 類別透過 [agent-browser](https://github.com/vercel-labs/agent-browser) 函式庫提供確定性的瀏覽器自動化功能。它利用無障礙樹快照和元素參照（例如 `@e5`），讓互動精確且可重現。

需要可靠且確定性的瀏覽器自動化時，可使用 `AgentBrowser`。若要透過自然語言進行 AI 驅動的互動，請參閱 [`StagehandBrowser`](/reference/browser/stagehand-browser)。

## 使用範例 {/* #usage-example */}

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { AgentBrowser } from '@mastra/agent-browser'

const browser = new AgentBrowser({
  headless: true,
  viewport: { width: 1280, height: 720 },
  scope: 'thread',
})

export const browserAgent = new Agent({
  id: 'browser-agent',
  name: 'Browser Agent',
  instructions: `You can browse the web. Use browser_snapshot to see the page structure,
then interact with elements using their refs (e.g., @e5).`,
  model: '__GATEWAY_OPENAI_MODEL__',
  browser,
})
```

## 工具 {/* #tools */}

`AgentBrowser` 提供 16 個用於瀏覽器自動化的確定性 Tool。所有與元素互動的 Tool 都使用無障礙樹快照中的參照。

設定 `recording` 後，`AgentBrowser` 還會加入 Beta 版 `browser_record` 和 `browser_record_caption` Tool。請參閱[瀏覽器錄製（Beta）](/docs/browser#record-browser-sessions)。

### 核心工具 {/* #core-tools */}

| 工具 | 說明 |
| - | - |
| `browser_goto` | 前往 URL |
| `browser_snapshot` | 取得含元素參照的無障礙樹快照 |
| `browser_click` | 依參照點擊元素 |
| `browser_type` | 在元素中輸入文字 |
| `browser_press` | 按下鍵盤按鍵 |
| `browser_select` | 從下拉式選單選取選項 |
| `browser_scroll` | 捲動頁面或元素 |
| `browser_screenshot` | 擷取 PNG 螢幕截圖（預設僅檢視區；設定 `fullPage: true` 可擷取整頁） |
| `browser_close` | 關閉瀏覽器 |

### 延伸工具 {/* #extended-tools */}

| 工具 | 說明 |
| - | - |
| `browser_hover` | 將滑鼠游標移至元素上方 |
| `browser_back` | 返回上一頁 |
| `browser_dialog` | 處理瀏覽器對話方塊（alert、confirm、prompt） |
| `browser_wait` | 等待元素狀態變化 |
| `browser_tabs` | 管理瀏覽器分頁（列出、新增、切換、關閉） |
| `browser_drag` | 拖放元素 |
| `browser_evaluate` | 在頁面中執行 JavaScript（備用方式） |

若要排除特定 Tool，請在建構函式中傳入 `excludeTools`：

```typescript
const browser = new AgentBrowser({
  excludeTools: ['browser_screenshot'],
})
```

## 工具參考 {/* #tool-reference */}

### `browser_goto` {/* #browser_goto */}

前往 URL。

```text
// Tool input
{
  "url": "https://example.com",
  "waitUntil": "domcontentloaded",
  "timeout": 30000
}
```

| 參數 | 型別 | 說明 |
| - | - | - |
| `url` | `string` | 要開啟的 URL |
| `waitUntil` | `"load" \| "domcontentloaded" \| "networkidle"` | 將導覽視為完成的時機（選填） |
| `timeout` | `number` | 導覽逾時時間，單位為毫秒（選填） |

### `browser_snapshot` {/* #browser_snapshot */}

取得頁面的無障礙樹快照。回傳 `@e5` 等元素參照，供其他 Tool 使用。

```text
// Tool input
{
  "interactiveOnly": true,
  "maxDepth": 10
}
```

| 參數 | 型別 | 說明 |
| - | - | - |
| `interactiveOnly` | `boolean` | 僅包含可互動的元素（選填） |
| `maxDepth` | `number` | 樹狀結構的最大深度（選填） |

**輸出範例：**

```text
[document] Example Page
  [banner]
    [link @e1] Home
    [link @e2] About
  [main]
    [heading @e3] Welcome
    [textbox @e4] Search...
    [button @e5] Submit
```

### `browser_click` {/* #browser_click */}

使用快照中的參照點擊元素。

```text
{
  "ref": "@e5",
  "button": "left",
  "clickCount": 1,
  "modifiers": ["Control", "Shift"]
}
```

| 參數 | 型別 | 說明 |
| - | - | - |
| `ref` | `string` | 快照中的元素參照（必填） |
| `button` | `"left" \| "right" \| "middle"` | 滑鼠按鍵（選填） |
| `clickCount` | `number` | 點擊次數；按兩下時設為 2（選填） |
| `modifiers` | `string[]` | 輔助按鍵（選填） |

### `browser_type` {/* #browser_type */}

在輸入元素中輸入文字。

```text
// Tool input
{
  "ref": "@e4",
  "text": "search query",
  "clear": true,
  "delay": 50
}
```

| 參數 | 型別 | 說明 |
| - | - | - |
| `ref` | `string` | 快照中的元素參照（必填） |
| `text` | `string` | 要輸入的文字（必填） |
| `clear` | `boolean` | 是否先清除現有內容（選填） |
| `delay` | `number` | 每次按鍵之間的延遲，單位為毫秒（選填） |

### `browser_press` {/* #browser_press */}

按下鍵盤按鍵。

```text
// Tool input
{
  "key": "Enter",
  "modifiers": ["Control"]
}

// Key combinations
{ "key": "Control+a" }
{ "key": "Control+c" }
```

| 參數 | 型別 | 說明 |
| - | - | - |
| `key` | `string` | 按鍵名稱（例如 "Enter"、"Tab"、"Escape"、"Control+a"）（必填） |
| `modifiers` | `string[]` | 輔助按鍵（選填） |

### `browser_select` {/* #browser_select */}

從下拉式選單選取一個選項。提供 `value`、`label` 或 `index` 其中之一。

```text
// Tool input - by value
{
  "ref": "@e10",
  "value": "option-value"
}

// Tool input - by label
{
  "ref": "@e10",
  "label": "Option Text"
}

// Tool input - by index
{
  "ref": "@e10",
  "index": 0
}
```

### `browser_scroll` {/* #browser_scroll */}

捲動頁面或指定元素。

```text
// Tool input
{
  "direction": "down",
  "amount": 300,
  "ref": "@e15"
}
```

| 參數 | 型別 | 說明 |
| - | - | - |
| `direction` | `"up" \| "down" \| "left" \| "right"` | 捲動方向（必填） |
| `amount` | `number` | 捲動的像素數，預設為 300（選填） |
| `ref` | `string` | 要捲動的元素；省略時捲動頁面（選填） |

### `browser_hover` {/* #browser_hover */}

將滑鼠游標移至元素上方，以觸發懸停效果。

```text
// Tool input
{
  "ref": "@e7"
}
```

### `browser_back` {/* #browser_back */}

返回瀏覽器歷程記錄中的上一頁。

```text
// Tool input (no parameters required)
{}
```

### `browser_dialog` {/* #browser_dialog */}

處理瀏覽器對話方塊（alert、confirm、prompt）。點擊會觸發對話方塊的元素，再處理該對話方塊。

```text
// Tool input
{
  "triggerRef": "@e5",
  "action": "accept",
  "text": "response"
}
```

| 參數 | 型別 | 說明 |
| - | - | - |
| `triggerRef` | `string` | 觸發對話方塊的元素（必填） |
| `action` | `"accept" \| "dismiss"` | 處理對話方塊的動作（必填） |
| `text` | `string` | prompt 對話方塊的輸入文字（選填） |

### `browser_wait` {/* #browser_wait */}

等待元素達到指定狀態。

```text
// Tool input
{
  "ref": "@e20",
  "state": "visible",
  "timeout": 30000
}
```

| 參數 | 型別 | 說明 |
| - | - | - |
| `ref` | `string` | 要等待的元素參照（選填） |
| `state` | `"visible" \| "hidden" \| "attached" \| "detached"` | 要等待的狀態（選填） |
| `timeout` | `number` | 最長等待時間，單位為毫秒（選填） |

### `browser_tabs` {/* #browser_tabs */}

管理瀏覽器分頁。

```text
// List all tabs
{ "action": "list" }

// Open new tab
{ "action": "new", "url": "https://example.com" }

// Switch to tab by index
{ "action": "switch", "index": 0 }

// Close tab by index
{ "action": "close", "index": 1 }
```

### `browser_drag` {/* #browser_drag */}

將元素拖放至目標位置。

```text
// Tool input
{
  "sourceRef": "@e10",
  "targetRef": "@e20"
}
```

| 參數 | 型別 | 說明 |
| - | - | - |
| `sourceRef` | `string` | 要拖曳的元素（必填） |
| `targetRef` | `string` | 放置位置的目標元素（必填） |

### `browser_evaluate` {/* #browser_evaluate */}

在頁面環境中執行 JavaScript。其他 Tool 無法滿足需求時，可將其作為備用方式。

```text
// Tool input
{
  "script": "document.title",
  "returnValue": true
}
```

| 參數 | 型別 | 說明 |
| - | - | - |
| `script` | `string` | 要執行的 JavaScript（必填） |
| `returnValue` | `boolean` | 是否回傳執行結果（選填） |

### `browser_screenshot` {/* #browser_screenshot */}

將目前頁面擷取為 PNG 圖片（預設僅擷取檢視區；設定 `fullPage: true` 可擷取整頁）。回傳的圖片內容可供具備視覺能力的模型直接解讀。若只需要文字或結構化資料，請使用 `browser_snapshot`。

```text
// Viewport only (default)
{}

// Full scrollable page
{ "fullPage": true }

// Also save the PNG to the workspace
{ "path": "screenshots/home.png" }
```

| 參數 | 型別 | 說明 |
| - | - | - |
| `fullPage` | `boolean` | 擷取整個可捲動頁面，而非僅擷取檢視區（選填，預設：false） |
| `path` | `string` | 同時將 PNG 儲存至 Agent Workspace 中的此路徑。缺少的資料夾會自動建立。模型會得知檔案的儲存位置，或無法儲存的原因（例如 Agent 沒有 Workspace）。此操作遵循 Workspace 的檔案寫入設定：關閉寫入、需要核准或檔案系統為唯讀時，不會儲存檔案。無論是否儲存，都會回傳截圖（選填） |

### `browser_close` {/* #browser_close */}

關閉瀏覽器並清理資源。

```text
// Tool input (no parameters required)
{}
```

## 元素參照的運作方式 {/* #how-refs-work */}

`browser_snapshot` Tool 會回傳包含 `@e1`、`@e2` 等元素參照的無障礙樹。這些穩定的識別碼可供其他 Tool 使用：

1. 呼叫 `browser_snapshot` 查看頁面結構。
1. 找到要互動的元素。
1. 將該元素的參照傳給 `browser_type` 或 `browser_scroll` 等互動 Tool。

```text
// 1. Get snapshot
// Returns: [textbox @e4] Search... [link @e5] Home

// 2. Type in the search box
{ "tool": "browser_type", "input": { "ref": "@e4", "text": "mastra" } }

// 3. Navigate to home
{ "tool": "browser_goto", "input": { "url": "https://example.com" } }
```
