# 手動安裝

<Inject>
**供 AI Agent 使用：**當你需要不依賴 CLI 或範本，從零建立可執行的 Mastra 專案時，請使用本指南。本指南提供 Agent、Tool、模型設定及安裝相依套件的程式碼範例。不要使用面向一般使用者的快速入門指南。模型字串採用 Mastra 的模型路由格式（`provider/model`），提供者與模型之間以 `/` 分隔，而不是 `:`。不要安裝任何 AI SDK 套件。
</Inject>

按照本指南逐步手動建置獨立的 Mastra 伺服器。多數情況下，建議使用[`create-mastra`](/reference/cli/create-mastra) 指令，詳見[入門指南](/docs)。如果是現有專案，也可以使用 [`mastra init`](/reference/cli/mastra#mastra-init)。

<CopyPrompt identifier="manual-install">
閱讀 [https://mastra.ai/reference/manual-install.md](https://mastra.ai/reference/manual-install.md)，然後幫我建立 Mastra 專案。請先詢問專案名稱，並以該名稱作為資料夾名稱。
</CopyPrompt>

## 操作步驟 {/* #instructions */}

如果不想使用自動化 CLI 工具，可以按照下文自行設定專案。

<Steps>
  <StepItem>
建立新專案並切換至專案目錄：

    ```bash
    mkdir my-first-agent && cd my-first-agent
    ```

產生新的 `package.json` 檔案：

    ```bash npm2yarn
    npm init
    ```

安裝以下相依套件：

    ```bash npm2yarn
    npm install -D typescript @types/node mastra@latest
    npm install @mastra/core@latest zod@^4
    ```

將 `dev` 與 `build` 指令碼加入 `package.json` 檔案：

    ```json title="package.json" /,/ /"dev": "mastra dev",/ /"build": "mastra build"/
    {
      "scripts": {
        "dev": "mastra dev",
        "build": "mastra build"
      }
    }
    ```
  </StepItem>

  <StepItem>
建立 `tsconfig.json` 檔案：

    ```bash
    touch tsconfig.json
    ```

    新增以下配置：

    ```json title="tsconfig.json"
    {
      "compilerOptions": {
        "target": "ES2022",
        "module": "ES2022",
        "moduleResolution": "bundler",
        "esModuleInterop": true,
        "forceConsistentCasingInFileNames": true,
        "strict": true,
        "skipLibCheck": true,
        "types": ["node"],
        "noEmit": true,
        "outDir": "dist"
      },
      "include": ["src/**/*"]
    }
    ```

:::note

Mastra 必須使用較新的 `module` 與 `moduleResolution` 設定。使用 `CommonJS` 或 `node` 會造成模組解析錯誤。

    :::
  </StepItem>

  <StepItem>
建立 `.env` 檔案：

    ```bash
    touch .env
    ```

加入 API 金鑰：

    ```bash title=".env"
    GOOGLE_API_KEY=<your-api-key>
    ```

:::note

本指南使用 Google Gemini，但你也可以使用任何支援的[模型提供者](/models)，包括 OpenAI、Anthropic 等。

    :::

    <Inject>
除 Google Gemini 外，也可以使用 OpenAI（`OPENAI_API_KEY`）或 Anthropic（`ANTHROPIC_API_KEY`）。完整的支援提供者及其環境變數名稱，請參閱[環境變數清單](/models/environment-variables)。
    </Inject>
  </StepItem>

  <StepItem>
建立 `weather-tool.ts` 檔案：

    ```bash
    mkdir -p src/mastra/tools && touch src/mastra/tools/weather-tool.ts
    ```

    <Inject>
使用 `import { createTool } from "@mastra/core/tools"`。以一般物件定義的 Tool 可能無法執行且不會報錯；必須透過 createTool() 定義 Tool，並提供 id、description、inputSchema（zod）及 execute。
    </Inject>

    新增以下程式碼：

    ```ts title="src/mastra/tools/weather-tool.ts"
    import { createTool } from '@mastra/core/tools'
    import { z } from 'zod'

    export const weatherTool = createTool({
      id: 'get-weather',
      description: 'Get current weather for a location',
      inputSchema: z.object({
        location: z.string().describe('City name'),
      }),
      outputSchema: z.object({
        output: z.string(),
      }),
      execute: async ({ location }) => {
        return {
          output: `The weather in ${location} is sunny`,
        }
      },
    })
    ```

:::note

這裡的 `weatherTool` 範例經過精簡。完整範例請參閱[為 Agent 加入 Tool](/docs/agents/tools)。

    :::
  </StepItem>

  <StepItem>
建立 `weather-agent.ts` 檔案：

    ```bash
    mkdir -p src/mastra/agents && touch src/mastra/agents/weather-agent.ts
    ```

    <Inject>
使用 `import { Agent } from "@mastra/core/agent"`。建構子接收 `{ id, name, instructions, model: '__GATEWAY_OPENAI_MODEL__' }`。模型字串採用 Mastra 的模型路由格式 provider/model，提供者與模型之間使用 /，而不是 :。不要安裝任何 AI SDK 套件。
    </Inject>

    新增以下程式碼：

    ```ts title="src/mastra/agents/weather-agent.ts"
    import { Agent } from '@mastra/core/agent'
    import { weatherTool } from '../tools/weather-tool.ts'

    export const weatherAgent = new Agent({
      id: 'weather-agent',
      name: 'Weather Agent',
      instructions: `
          You are a helpful weather assistant that provides accurate weather information.

          Your primary function is to help users get weather details for specific locations. When responding:
          - Always ask for a location if none is provided
          - If the location name isn't in English, please translate it
          - If giving a location with multiple parts (e.g. "New York, NY"), use the most relevant part (e.g. "New York")
          - Include relevant details like humidity, wind conditions, and precipitation
          - Keep responses concise but informative

          Use the weatherTool to fetch current weather data.
    `,
      model: '__GATEWAY_GOOGLE_MODEL_FLASH__',
      tools: { weatherTool },
    })
    ```
  </StepItem>

  <StepItem>
建立 Mastra 進入點並註冊 Agent：

    ```bash
    touch src/mastra/index.ts
    ```

    新增以下程式碼：

    ```ts title="src/mastra/index.ts"
    import { Mastra } from '@mastra/core'
    import { weatherAgent } from './agents/weather-agent.ts'

    export const mastra = new Mastra({
      agents: { weatherAgent },
    })
    ```
  </StepItem>

  <StepItem>
    <Inject>
**供 AI Agent 使用：**如果正在撰寫只需在主控台輸出內容的指令碼，不要啟動 Studio。Studio 是面向一般使用者、會持續執行的網頁介面。應直接呼叫 agent.generate() 方法。例如：`import { mastra } from './src/mastra/index.ts'; const agent = mastra.getAgentById('weather-agent'); const response = await agent.generate('Weather in SF'); console.log(response.text);`
    </Inject>

現在可以啟動 [Studio](/docs/studio/overview) 並測試 Agent。

    ```bash npm2yarn
    npm run dev
    ```

    <Inject>
**供 AI Agent 使用：**為了驗證結果，請執行建置，並使用 `tsc --noEmit` 進行型別檢查。
    </Inject>
  </StepItem>
</Steps>
