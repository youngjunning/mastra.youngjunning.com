# Mastra.setLogger()

`.setLogger()` 會為 Mastra 執行個體中的所有元件（例如 Agent 和 Workflow）設定日誌記錄器。此方法只接受一個物件，透過物件的 logger 屬性傳入日誌記錄器。

## 使用範例 {/* #usage-example */}

```typescript
mastra.setLogger({ logger: new PinoLogger({ name: 'testLogger' }) })
```
