# Mastra.getMCPServerById()

這`.getMCPServerById()`方法透過其內在屬性檢索 MCP 伺服器實例`id`財產。若要透過登錄項目（設定中使用的金鑰）檢索，請使用`.getMCPServer()`反而。

## 使用範例 {/* #usage-example */}

```typescript
// Register an MCP server with a registry key
const myServer = new MCPServer({
  id: 'my-mcp-server',
  name: 'My Server',
  version: '1.0.0',
  tools: {/* ... */},
})

export const mastra = new Mastra({
  mcpServers: {
    customKey: myServer, // 'customKey' is the registry key
  },
})

// Retrieve by intrinsic ID
const server = mastra.getMCPServerById('my-mcp-server')

// Alternatively, retrieve by registry key
const serverByKey = mastra.getMCPServer('customKey')
```

## 筆記 {/* #notes */}

* 伺服器的`id` is slugified during construction, so `'myMcpServer'` becomes `'my-mcp-server'`
* 如果多個伺服器有相同的`id` but different versions, you must provide the `version` parameter to disambiguate
* 如果沒有`version` is provided and multiple versions exist, the method returns the first match
