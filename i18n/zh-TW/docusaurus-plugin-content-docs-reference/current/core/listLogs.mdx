# Mastra.listLogs()

`.listLogs()` 方法取得指定傳輸 ID 的所有記錄。此方法要求已設定的 logger 支援 `listLogs` 操作。

## 使用範例 {/* #usage-example */}

```typescript
mastra.listLogs('456')
```
