# Mastra.getDeployer()

`.getDeployer()` 會取得 Mastra 執行個體中已設定的部署器。

## 使用範例 {/* #usage-example */}

```typescript
mastra.getDeployer()
```

## 參數 {/* #parameters */}

此方法不接受參數。
