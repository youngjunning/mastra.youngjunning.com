# Mastra.getLogger()

`.getLogger()` 會取得 Mastra 執行個體中已設定的日誌記錄器。

## 使用範例 {/* #usage-example */}

```typescript
mastra.getLogger()
```

## 參數 {/* #parameters */}

此方法不接受參數。
