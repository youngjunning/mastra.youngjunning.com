# Mastra.getLogger()

這`.getLogger()`方法用於檢索已在 Mastra 實例中配置的記錄器實例。

## 使用範例 {/* #usage-example */}

```typescript
mastra.getLogger()
```

## 參數 {/* #parameters */}

此方法不接受任何參數。
