# getClassifierById()

`getClassifierById()` 會先依 `id` 屬性查詢分類器；若未找到，再依註冊時使用的鍵查詢。

## 使用範例 {/* #usage-example */}

```typescript
import { mastra } from './mastra'

const safety = mastra.getClassifierById('safety')
```

## 錯誤處理 {/* #error-handling */}

若沒有分類器符合指定的 id 或註冊鍵，此方法會擲出 `MastraError`，錯誤 ID 為 `MASTRA_GET_CLASSIFIER_BY_ID_NOT_FOUND`。
