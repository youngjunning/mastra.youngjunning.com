# getClassifierById()

這`getClassifierById()``id`屬性，然後回退到註冊金鑰。

## 使用範例 {/* #usage-example */}

```typescript
import { mastra } from './mastra'

const safety = mastra.getClassifierById('safety')
```

## 錯誤處理 {/* #error-handling */}

這個方法拋出一個`MastraError` with id `MASTRA_GET_CLASSIFIER_BY_ID_NOT_FOUND` if no classifier matches the specified id or key.
