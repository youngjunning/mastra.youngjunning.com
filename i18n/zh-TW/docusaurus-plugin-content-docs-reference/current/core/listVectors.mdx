# Mastra.listVectors()

這`.listVectors()`方法用於檢索已在 Mastra 實例中配置的所有向量儲存。

## 使用範例 {/* #usage-example */}

```typescript
mastra.listVectors()
```

## 參數 {/* #parameters */}

此方法不接受任何參數。
