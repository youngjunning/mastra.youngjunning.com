# Mastra.listVectors()

`.listVectors()` 會列出 Mastra 執行個體中已設定的所有向量儲存區。

## 使用範例 {/* #usage-example */}

```typescript
mastra.listVectors()
```

## 參數 {/* #parameters */}

此方法不接受參數。
