# Mastra.getStorage()

`.getStorage()` 會取得 Mastra 執行個體中已設定的儲存執行個體。

## 使用範例 {/* #usage-example */}

```typescript
mastra.getStorage()
```

## 參數 {/* #parameters */}

此方法不接受參數。
