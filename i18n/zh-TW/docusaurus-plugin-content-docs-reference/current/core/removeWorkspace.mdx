# Mastra.removeWorkspace()

`.removeWorkspace()` 會從 Mastra 的執行時期登錄表移除 Workspace。傳入 `{ destroy: true }` 即可在移除前銷毀該 Workspace。

## 使用範例 {/* #usage-example */}

```typescript
await mastra.removeWorkspace('workspace-123', { destroy: true })
```

## 傳回值 {/* #returns */}

<PropertiesTable
  content={[
{
  name: 'removed',
  type: 'Promise<boolean>',
  description: '移除成功時傳回 `true`。找不到該 ID 對應的 Workspace 時傳回 `false`。',
},
]}
/>

若 `destroy` 為 `true` 且 `workspace.destroy()` 擲出例外，呼叫傳回的 Promise 會以該例外遭到拒絕。Workspace 仍保留在登錄表中，呼叫端可重試清理。
