# Mastra.getAgentById()

`.getAgentById()` 根據 `id` 取得已註冊的 Agent。它會先依 `agent.id` 查找；若沒有相符項目，則改用 [`Mastra.getAgent()`](/reference/core/getAgent)，將傳入值視為 Agent 登錄表的鍵。

使用 `mastra.getAgentById(id)` 取得程式碼定義的 Agent；使用 `await mastra.getAgentById(id, version)` 取得指定版本的 Agent。

## 使用範例 {/* #usage-example */}

以下範例先註冊 Agent，再透過 ID 取得並使用它。

```typescript title="src/mastra/index.ts"
import { Agent } from '@mastra/core/agent'
import { Mastra } from '@mastra/core/mastra'

const supportAgent = new Agent({
  id: 'support-agent-id',
  name: 'Support Agent',
  instructions: 'Answer support questions clearly and concisely.',
  model: '__GATEWAY_OPENAI_MODEL__',
})

export const mastra = new Mastra({
  agents: {
    supportAgent,
  },
})

const agent = mastra.getAgentById('support-agent-id')

const response = await agent.generate('How can I reset my password?')
```
