# getClassifier()

`getClassifier()` 依註冊鍵取得 Mastra 實例中已註冊的分類器。若找不到對應的分類器，會擲出錯誤。

## 使用範例 {/* #usage-example */}

```typescript
import { mastra } from './mastra'

const safety = mastra.getClassifier('safety')

const result = await safety.decide({
  state: { content: 'A message to evaluate' },
})
```

## 錯誤處理 {/* #error-handling */}

若指定鍵未對應到已註冊的分類器，此方法會擲出 ID 為 `MASTRA_GET_CLASSIFIER_NOT_FOUND` 的 `MastraError`。
