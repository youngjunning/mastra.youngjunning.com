# Mastra.listWorkflows()

`.listWorkflows()` 會列出 Mastra 執行個體中已設定的所有 Workflow。你可以選擇傳入選項物件。

## 使用範例 {/* #usage-example */}

```typescript
mastra.listWorkflows()
```
