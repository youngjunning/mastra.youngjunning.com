# Mastra.listLogsByRunId()

`.listLogsByRunId()` 方法取得指定執行 ID 與傳輸 ID 的記錄。此方法要求已設定的 logger 支援 `listLogsByRunId` 操作。

## 使用範例 {/* #usage-example */}

```typescript
mastra.listLogsByRunId({ runId: '123', transportId: '456' })
```
