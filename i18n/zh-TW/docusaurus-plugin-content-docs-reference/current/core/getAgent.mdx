# Mastra.getAgent()

`.getAgent()` 依名稱取得 Agent，也可以傳入版本選擇條件。傳入該條件時，此方法會傳回 Promise。

## 使用範例 {/* #usage-example */}

```typescript
mastra.getAgent('testAgent')
```
