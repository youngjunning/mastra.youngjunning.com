# Mastra.getAgent()

這`.getAgent()`方法用於檢索Agent。此方法接受Agent程式的名稱和可選的版本選擇器。傳遞版本選擇器會傳回一個承諾。

## 使用範例 {/* #usage-example */}

```typescript
mastra.getAgent('testAgent')
```
