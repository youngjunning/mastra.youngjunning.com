# Mastra.setStorage()

`.setStorage()` 設定 Mastra 執行個體所用的儲存執行個體，只接受一個 `MastraCompositeStore` 參數。

## 使用範例 {/* #usage-example */}

```typescript
mastra.setStorage(
  new LibSQLStore({
    id: 'mastra-storage',
    url: ':memory:',
  }),
)
```
