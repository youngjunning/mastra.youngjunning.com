# Mastra.setStorage()

這`.setStorage()`方法用於設定Mastra實例的儲存實例。該方法接受單一`MastraCompositeStore`範圍。

## 使用範例 {/* #usage-example */}

```typescript
mastra.setStorage(
  new LibSQLStore({
    id: 'mastra-storage',
    url: ':memory:',
  }),
)
```
