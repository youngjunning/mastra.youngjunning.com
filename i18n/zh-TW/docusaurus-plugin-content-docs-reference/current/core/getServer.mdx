# Mastra.getServer()

`.getServer()` 會讀取 Mastra 執行個體中的伺服器設定。

## 使用範例 {/* #usage-example */}

```typescript
mastra.getServer()
```

## 參數 {/* #parameters */}

此方法不接受參數。
