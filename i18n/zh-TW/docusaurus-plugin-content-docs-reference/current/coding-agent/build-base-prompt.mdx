# 建構基礎提示()

`buildBasePrompt()`為編碼Agent程式建立共享基礎系統提示：使Agent程式成為良好編碼助手的行為指令。這需要一個`PromptContext`描述目前環境（項目、平台、git 分支、模式、模型）並以字串形式傳回提示。

產品特定的字串透過參數化`productName`, `coAuthorName`, and `coAuthorEmail`，這樣您就可以重新命名提示並提交預告片而無需分叉它。共同作者預設為`"mastra-platform[bot]"`和`"284800079+mastra-platform[bot]@users.noreply.github.com"`.

將此與[`createCodingAgent()`](/reference/coding-agent/create-coding-agent) when you build runtime-defined instructions for the agent.

## 使用範例 {/* #usage-example */}

從以下內容建立基本提示`PromptContext`:

```typescript title="src/mastra/prompt.ts"
import { buildBasePrompt } from '@mastra/core/coding-agent'

const prompt = buildBasePrompt({
  projectPath: process.cwd(),
  projectName: 'my-app',
  gitBranch: 'main',
  platform: process.platform,
  date: new Date().toDateString(),
  mode: 'build',
  modelId: '__GATEWAY_OPENAI_MODEL_BASE__',
  toolGuidance: '',
})
```

若要重新命名提示，請傳遞產品和共同作者欄位：

```typescript
const prompt = buildBasePrompt({
  // ...environment fields
  productName: 'Acme Coder',
  coAuthorName: 'Acme Bot',
  coAuthorEmail: 'bot@acme.dev',
})
```
