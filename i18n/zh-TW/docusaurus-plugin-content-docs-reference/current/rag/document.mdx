# MDocument

MDocument 類別用來處理 RAG 應用程式中的文件，主要方法是 `.chunk()` 與 `.extractMetadata()`。

## 實例方法 {/* #instance-methods */}

### `chunk()` {/* #chunk */}

將文件切分為區塊，並可選擇擷取中繼資料。

```typescript oxfmt:false
async chunk(
  params?: ChunkParams,
  options?: { observabilityContext?: ObservabilityContext },
): Promise<Chunk[]>
```

傳入 `observabilityContext`，可將分塊與中繼資料擷取的 span 附加到既有 Trace。

詳細選項請參閱 [chunk() 參考文件](./chunk)。

### `getDocs()` {/* #getdocs */}

回傳處理後的文件區塊陣列。

```typescript oxfmt:false
getDocs(): Chunk[]
```

### `getText()` {/* #gettext */}

回傳文件區塊中的文字字串陣列。

```typescript oxfmt:false
getText(): string[]
```

### `getMetadata()` {/* #getmetadata */}

回傳文件區塊中的中繼資料物件陣列。

```typescript oxfmt:false
getMetadata(): Record<string, any>[]
```

### `extractMetadata()` {/* #extractmetadata */}

使用指定的擷取器擷取中繼資料。詳情請參閱 [ExtractParams 參考文件](./extract-params)。

```typescript oxfmt:false
async extractMetadata(params: ExtractParams): Promise<MDocument>
```

## 範例 {/* #examples */}

```typescript
import { MDocument } from '@mastra/rag'

// Create document from text
const doc = MDocument.fromText('Your content here')

// Split into chunks with metadata extraction
const chunks = await doc.chunk({
  strategy: 'markdown',
  headers: [
    ['#', 'title'],
    ['##', 'section'],
  ],
  extract: {
    summary: true, // Extract summaries with default settings
    keywords: true, // Extract keywords with default settings
  },
})

// Get processed chunks
const docs = doc.getDocs()
const texts = doc.getText()
const metadata = doc.getMetadata()
```
