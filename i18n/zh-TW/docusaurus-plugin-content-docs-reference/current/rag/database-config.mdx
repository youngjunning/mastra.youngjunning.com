# 資料庫配置

這`DatabaseConfig`type 可讓您在使用向量查詢Tool時指定特定於資料庫的配置。這些配置使您能夠使用不同向量商店提供的功能和最佳化。

## 類型定義 {/* #type-definition */}

```typescript
export type DatabaseConfig = {
  pinecone?: PineconeConfig
  pgvector?: PgVectorConfig
  chroma?: ChromaConfig
  mongodb?: MongoDBConfig
  turbopuffer?: TurbopufferConfig
  [key: string]: any // Extensible for future databases
}
```

### `PgVectorConfig` {/* #pgvectorconfig */}

特定於 pgvector 擴充功能的 PostgreSQL 的設定選項。

**性能指南：**

* **埃夫**：從 topK 值的 2-4 倍開始，增加以獲得更好的準確性
* **探針**：從 1-10 開始，增加以更好地回憶
* **最低得分**：根據您的品質要求使用 0.5-0.9 之間的值

**使用案例：**

* 高負載場景的效能最佳化
* 品質過濾以刪除不相關的結果
* 微調搜尋精度與速度的權衡

    ### 運行時配置覆蓋 {/* #runtime-configuration-override */}

    ```typescript
    import { RequestContext } from '@mastra/core/request-context'

    // Initial configuration
    const vectorTool = createVectorQueryTool({
      vectorStoreName: 'pinecone',
      indexName: 'documents',
      model: embedModel,
      databaseConfig: {
        pinecone: {
          namespace: 'development',
        },
      },
    })

    // Override at runtime
    const requestContext = new RequestContext()
    requestContext.set('databaseConfig', {
      pinecone: {
        namespace: 'production',
      },
    })

    await vectorTool.execute({ queryText: 'search query' }, { mastra, requestContext })
    ```
  </TabItem>

  <TabItem value="multi-database" label="Multi-Database">
    ### 多資料庫配置 {/* #multi-database-configuration */}

    ```typescript
    import { RequestContext } from '@mastra/core/request-context'

    const vectorTool = createVectorQueryTool({
      vectorStoreName: 'pinecone',
      indexName: 'documents',
      model: embedModel,
    })

    // Select the store per request and pass only its matching config block
    const pineconeContext = new RequestContext()
    pineconeContext.set('vectorStoreName', 'pinecone')
    pineconeContext.set('databaseConfig', {
      pinecone: { namespace: 'default' },
    })

    const pgVectorContext = new RequestContext()
    pgVectorContext.set('vectorStoreName', 'pgVector')
    pgVectorContext.set('databaseConfig', {
      pgvector: { minScore: 0.8, ef: 150 },
    })

    await vectorTool.execute({ queryText: 'search query' }, { mastra, requestContext: pgVectorContext })
    ```

    ：：：筆記

    **多數據庫支持**：無論查詢哪個向量存儲，您配置的每個資料庫區塊的設定都會合併到查詢參數中。共用金鑰適用於執行查詢的任何商店。例如，`pgvector.minScore` is passed as `minScore`, which other stores such as LibSQL also read to filter results. Pass only the block for the vector store you query.

    :::
  </TabItem>

## 可擴展性 {/* #extensibility */}

這`DatabaseConfig` type is designed to be extensible. To add support for a new vector database:

```typescript
// 1. Define the configuration interface
export interface NewDatabaseConfig {
  customParam1?: string
  customParam2?: number
}

// 2. Extend DatabaseConfig type
export type DatabaseConfig = {
  pinecone?: PineconeConfig
  pgvector?: PgVectorConfig
  chroma?: ChromaConfig
  newdatabase?: NewDatabaseConfig
  [key: string]: any
}

// 3. Use in vector query tool
const vectorTool = createVectorQueryTool({
  vectorStoreName: 'newdatabase',
  indexName: 'documents',
  model: embedModel,
  databaseConfig: {
    newdatabase: {
      customParam1: 'value',
      customParam2: 42,
    },
  },
})
```

## 最佳實踐 {/* #best-practices */}

1. **環境配置**：針對不同的環境使用不同的命名空間或配置
2. **效能調優**：從預設值開始，然後根據您的具體需求進行調整
3. **質量過濾**：使用minScore過濾掉低品質結果
4. **運行時靈活性**：在運行時覆蓋運行時定義的場景的配置
5. **文件**：為團隊成員記錄您的特定配置選擇

## 遷移指南 {/* #migration-guide */}

現有的向量查詢Tool無需更改即可繼續工作。新增資料庫配置：

```diff
const vectorTool = createVectorQueryTool({
  vectorStoreName: 'pinecone',
  indexName: 'documents',
  model: embedModel,
+ databaseConfig: {
+   pinecone: {
+     namespace: 'production'
+   }
+ }
});
```
