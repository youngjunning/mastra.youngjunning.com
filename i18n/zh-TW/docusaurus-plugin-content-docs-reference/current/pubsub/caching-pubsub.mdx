# CachingPubSub

`CachingPubSub` 可包裝任何 [`PubSub`](/reference/pubsub/base) 實作，加入事件快取與重播功能。它會依主題快取每個已發布的事件，讓較晚連線或斷線重連的訂閱者先重播錯過的事件，再繼續接收即時事件。

若底層傳輸不保留歷史紀錄，例如 [`EventEmitterPubSub`](/reference/pubsub/event-emitter)，可用它建立可恢復的串流。已將事件持久化的傳輸（例如 [`RedisStreamsPubSub`](/reference/pubsub/redis-streams)）不需要此包裝器。

`CachingPubSub` 不會改變底層的批次處理能力：`subscribe()` 會將 `options.batch` 傳給內部 pub/sub，`supportsNativeBatching` 也與內部實作一致。若內部實作不支援批次處理，即使傳入 `options.batch`，事件仍會逐筆傳遞。

## 使用範例 {/* #usage-example */}

包裝內部 pub/sub，並提供用來儲存事件的伺服器快取。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { CachingPubSub, EventEmitterPubSub } from '@mastra/core/events'
import { InMemoryServerCache } from '@mastra/core/cache'

const cache = new InMemoryServerCache()
const pubsub = new CachingPubSub(new EventEmitterPubSub(), cache)

export const mastra = new Mastra({
  pubsub,
})
```

使用 `withCaching` 輔助函式也會得到相同類型的實例；直接在程式碼中包裝時更容易閱讀：

```typescript
import { withCaching, EventEmitterPubSub } from '@mastra/core/events'
import { InMemoryServerCache } from '@mastra/core/cache'

const pubsub = withCaching(new EventEmitterPubSub(), new InMemoryServerCache())
```

## 方法 {/* #methods */}

`CachingPubSub` 實作了 [`PubSub`](/reference/pubsub/base) 介面，並覆寫重播方法以讀取快取事件。以下方法說明其快取行為。

### `publish(topic, event)` {/* #publishtopic-event */}

先以連續索引快取事件，再將其發布至內部 pub/sub。

```typescript
await pubsub.publish('my-topic', {
  type: 'example',
  data: { value: 1 },
  runId: 'run-123',
})
```

### `subscribeWithReplay(topic, cb)` {/* #subscribewithreplaytopic-cb */}

先重播該主題的所有快取事件，再訂閱即時事件。

```typescript
await pubsub.subscribeWithReplay('my-topic', event => {
  console.log(event)
})
```

### `subscribeFromOffset(topic, offset, cb)` {/* #subscribefromoffsettopic-offset-cb */}

從 `offset` 開始重播快取事件，再訂閱即時事件。用戶端已知上次接收位置時可使用此方法，避免重播所有歷史事件。

```typescript
await pubsub.subscribeFromOffset('my-topic', 42, event => {
  console.log(event)
})
```

### `getHistory(topic, offset?)` {/* #gethistorytopic-offset */}

回傳該主題從 `offset` 開始的快取事件。

```typescript
const events = await pubsub.getHistory('my-topic', 0)
```

回傳值：`Promise<Event[]>`

### `clearTopic(topic)` {/* #cleartopictopic */}

移除該主題的快取事件與偏移量計數器，並將呼叫轉給內部 pub/sub，讓持久化傳輸（例如 [`RedisStreamsPubSub`](/reference/pubsub/redis-streams)）也能刪除保留的狀態。Mastra 的執行生命週期會在執行結束時自動呼叫此方法。

```typescript
await pubsub.clearTopic('my-topic')
```

## 函式 {/* #functions */}

### `withCaching(pubsub, cache, options?)` {/* #withcachingpubsub-cache-options */}

用來建立 `CachingPubSub` 的便利包裝函式。接受與建構函式相同的參數，並回傳新實例。

```typescript
import { withCaching, EventEmitterPubSub } from '@mastra/core/events'
import { InMemoryServerCache } from '@mastra/core/cache'

const pubsub = withCaching(new EventEmitterPubSub(), new InMemoryServerCache(), {
  keyPrefix: 'events:',
})
```

回傳值：`CachingPubSub`
