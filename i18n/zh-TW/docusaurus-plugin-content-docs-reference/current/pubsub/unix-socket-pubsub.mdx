# UnixSocketPubSub

`UnixSocketPubSub`是一個[`PubSub`](/reference/pubsub/base)使用 Unix 域套接字在單一主機上跨進程傳遞事件的實作。它選擇一個進程作為Agent，其他進程作為客戶端連接到它。如果經紀人退出，剩餘的用戶端會自動選擇新的經紀人。

當多個本地進程需要共享流時使用它，例如跨 Mastra Code 終端介面協調線程流。對於單一進程交付，請使用[`EventEmitterPubSub`](/reference/pubsub/event-emitter). For distributed delivery across hosts, use [`RedisStreamsPubSub`](/reference/pubsub/redis-streams) or [`GoogleCloudPubSub`](/reference/pubsub/google-cloud-pubsub).

`UnixSocketPubSub`是推送傳輸：事件到達時沒有讀取循環，因此 Mastra 不會為其運行拉取工作程序。

## 使用範例 {/* #usage-example */}

傳遞每個參與進程共享的套接字路徑。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { UnixSocketPubSub } from '@mastra/core/events'

export const mastra = new Mastra({
  pubsub: new UnixSocketPubSub('/tmp/mastra/events.sock'),
})
```

## 方法 {/* #methods */}

`UnixSocketPubSub`實施[`PubSub`](/reference/pubsub/base) contract. The method below is specific to this implementation.

### `close()` {/* #close */}

關閉套接字連接，並且當該實例是Agent時，釋放Agent角色。在正常關閉期間呼叫此方法。`close()` waits up to one second for lease releases that started before it. A release still blocked on another process's lock after that rejects with `UnixSocketPubSub is closed`. Lease operations started after `close()` throw.

```typescript
await pubsub.close()
```

## 經紀商選舉 {/* #broker-election */}

Agent程式是第一個將其套接字連結到共享路徑的進程。它在所有連接的客戶端之間路由事件，並且其他進程作為客戶端連接到它。每個候選者都以私有名稱綁定一個套接字，並將其硬連結到共享路徑。如果套接字已經存在，則連結會失敗，從而防止候選者意外替換活動Agent。

當Agent完全退出時，它會刪除共享路徑。然後客戶端重新連接，第一個將其套接字連結到位的客戶端將成為新的Agent。其餘客戶重新訂閱它。

被拒絕的連線本身不會觸發接管。客戶端首先進行退避重試。只有當套接字不斷拒絕連線時，用戶端才會取得獨佔鎖定檔案並取代它。只有當共用路徑仍指向其自己的套接字時，Agent程式才會刪除該共用路徑。如果Agent程式發現其路徑被刪除或替換，它將退出並作為客戶端重新加入。因此，最終位於不同套接字上的程序會再次匯聚到一個Agent上，而不是保持分裂狀態。
