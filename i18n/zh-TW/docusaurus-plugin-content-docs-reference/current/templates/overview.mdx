# 範本

本參考資料說明如何使用現有的 Mastra 範本並建立您自己的範本。它還涵蓋了向社區生態系統貢獻模板。

Mastra 範本是預先建立的專案結構，用於演示特定的用例和模式。他們提供：

* **工作範例**：完整、實用的 Mastra 應用程序
* **最佳實踐**：正確的項目結構和編碼約定
* **教育資源**：透過實際實施學習 Mastra 模式
* **快速入門**：引導專案比從頭開始建立更快

## 可用模板 {/* #available-templates */}

以下模板示範了網關優先的 Mastra 應用程式：

* `template-docs-expert`：透過 Gateway 網路搜尋、引文、記憶和結構化回應回答文件問題。
* `template-browser-agent`：使用 AgentBrowser 瀏覽、檢查網頁並與之互動。
* `template-meeting-notes`：將 Zoom 記錄或上傳的記錄轉換為包含決策和行動項目的結構化筆記。
* `template-company-knowledge`：將 Linear 和 Notion 內容索引到 pgvector 中並回答內部知識問題。
* `template-claw-assistant`：使用檔案系統、沙箱、瀏覽器和網路搜尋Tool操作Workspace。

## 使用模板 {/* #using-templates */}

### 安裝 {/* #installation */}

使用以下命令安裝模板`create-mastra` command:

```sh npm2yarn
npx create-mastra@latest my-project --template template-name
```

這將建立一個完整的專案並安裝其相依性。模板作者控制模型、提供程序依賴項、環境變數和原始程式碼。

### 設定過程 {/* #setup-process */}

安裝後：

1. **導航到專案目錄**:

   ```bash
   cd your-project-name
   ```

2. **配置環境變數**:

   ```bash
   cp .env.example .env
   ```

   編輯`.env` with required API keys as documented in the template's README.

3. **啟動開發伺服器**:

   ```sh npm2yarn
   npm run dev
   ```

### 模板結構 {/* #template-structure */}

所有模板都遵循以下標準化結構：

```text
your-template/
├── src/
│   └── mastra/
│       ├── agents/       # Agent definitions
│       ├── tools/        # Tool definitions
│       ├── workflows/    # Workflow definitions
│       └── index.ts      # Main Mastra config
├── .env.example          # Required environment variables
├── package.json
├── tsconfig.json
└── README.md
```
