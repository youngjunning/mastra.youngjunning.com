# 專案結構

使用 `create mastra` 指令建立的 Mastra 專案包含預設檔案和資料夾，協助你快速開始。

Mastra 雖然是框架，但基本上不限制檔案的組織方式或存放位置。CLI 提供適用於多數專案的預設結構，你可以依工作流程或團隊慣例調整，甚至將整個專案寫在單一檔案中。無論採用哪種結構，都應保持一致，讓程式碼易於維護和瀏覽。

## 預設專案結構 {/* #default-project-structure */}

使用 `create mastra` 指令建立的專案結構如下：

```bash
├── src/
│   └── mastra/
│       ├── agents/
│       │   └── agent.ts
│       ├── tools/
│       │   └── schedule-tools.ts
│       └── index.ts
├── .env.example
├── AGENTS.md
├── package.json
└── tsconfig.json
```

預設專案以 [Agent Harness 範本](https://github.com/mastra-ai/template-agent-harness)為基礎。你可以複製並調整這些預設檔案，快速建立自己的 Agent、Tool 和 Workflow 等。

### 資料夾 {/* #folders */}

Mastra 建議將程式碼依下列資料夾組織：

| 資料夾 | 說明 |
| - | - |
| `src/mastra` | Mastra 相關程式碼與設定的進入點。 |
| `src/mastra/agents` | 定義並設定 Agent 的行為、目標與 Tool。 |
| `src/mastra/workflows` | 定義協調 Agent 與 Tool 的多步驟 Workflow。 |
| `src/mastra/tools` | 建立可供 Agent 呼叫的可重複使用 Tool。 |
| `src/mastra/mcp` | 實作自訂 MCP server，與外部 Agent 分享 Tool。 |
| `src/mastra/scorers` | 定義用於持續評估 Agent 表現的 scorer。 |

Mastra 有兩個特殊的資料夾約定：

- `src/mastra/agents/<name>`：可以依檔案慣例定義 Agent，無須在程式碼中建構。詳見[以檔案定義 Agent](/docs/develop#file-based-agents)文件。
- `src/mastra/public`：建置時，此資料夾的內容會複製到 `.mastra/output`，以供執行階段提供服務。

### 頂層檔案 {/* #top-level-files */}

頂層檔案定義 Mastra 專案的設定、建置方式，以及與環境的連接方式。

| 檔案 | 說明 |
| - | - |
| `src/mastra/index.ts` | 設定及初始化 Mastra 的主要進入點。 |
| `.env.example` | 環境變數範本；複製為 `.env`，並加入私密的[模型 Provider](/models)金鑰。 |
| `AGENTS.md` | 供專案中的程式開發 Agent 使用的指示。 |
| `package.json` | 定義專案中繼資料、相依套件及可用的 npm scripts。 |
| `tsconfig.json` | 設定 TypeScript 選項，例如路徑別名、編譯器設定與建置輸出。 |
