# Mastra 類別

Mastra 類別已調整結構，限制從套件根路徑匯入，並改用 getter 方法取代直接存取屬性。

## 變更 {/* #changed */}

### 從頂層匯入改為子路徑匯入 {/* #top-level-imports-to-subpath-imports */}

`@mastra/core` 的主要入口現在只匯出 `Mastra` 與 `Config`。其他匯出皆移至子路徑。打包工具因此更容易移除未使用的程式碼，改善 tree shaking 效果並縮小套件大小。

遷移時，請將從 `@mastra/core` 匯入的其他符號改為從對應的子路徑匯入。

```diff
- import { Mastra, Agent, Workflow, createTool } from '@mastra/core';
+ import { Mastra, type Config } from '@mastra/core';
+ import { Agent } from '@mastra/core/agent';
+ import { Workflow } from '@mastra/core/workflows';
+ import { createTool } from '@mastra/core/tools';
```

:::tip[Codemod]

可以使用 Mastra 的 codemod CLI 自動更新程式碼：

```bash
npx @mastra/codemod@latest v1/mastra-core-imports .
```

:::

### 將 `experimental_auth` 改為 `auth` {/* #experimental_auth-to-auth */}

實驗性驗證設定已轉為穩定功能，表示 auth API 現已穩定，可用於正式環境。

遷移時，請將 Mastra 設定中的 `experimental_auth` 鍵重新命名為 `auth`。

```diff
  const mastra = new Mastra({
-   experimental_auth: {
+   auth: {
      provider: workos,
    },
  });
```

:::tip[Codemod]

可以使用 Mastra 的 codemod CLI 自動更新程式碼：

```bash
npx @mastra/codemod@latest v1/experimental-auth .
```

:::

### 所有 Mastra 基礎元件都必須提供 `id` 參數 {/* #required-id-parameter-for-all-mastra-primitives */}

所有儲存空間、向量儲存空間、Agent、Workflow、MCP Server、Processor、Scorer 與 Tool 現在都必須在初始化時提供 `id` 參數。必填 ID 使 Mastra API 更一致，也有助於避免 ID 衝突。

這些基礎元件現在也提供 `get`、`list` 與 `add` 函式。

遷移時，請為所有儲存空間及向量儲存空間實例加入 `id` 參數。如果多次建立同一儲存空間或向量儲存空間類別的實例，請確保每個實例的 ID 都不同。

```diff
- const storage = new LibSQLStore({
-   url: ':memory:',
- });
+ const storage = new LibSQLStore({
+   id: 'my-app-storage',
+   url: ':memory:',
+ });

- const vector = new PgVector({
-   connectionString: process.env.DATABASE_URL,
- });
+ const vector = new PgVector({
+   id: 'my-app-vector',
+   connectionString: process.env.DATABASE_URL,
+ });
```

為不同用途建立獨立實例時，請使用能說明用途且不重複的 ID：

```diff
  const agentMemory = new Memory({
    storage: new LibSQLStore({
-     url: 'file:./agent.db',
+     id: 'weather-agent-memory-storage',
+     url: 'file:./agent.db',
    }),
  });

  const mastra = new Mastra({
    storage: new LibSQLStore({
+     id: 'mastra-storage',
      url: ':memory:',
    }),
  });
```

### 取得所有實例的 API 從 `get<primitives>` 改為 `list<primitive>` {/* #primitive-plural-apis-changes-from-getprimitives-to-listprimitive */}

原本傳回某類基礎元件所有實例的 `get*` 函式，現已重新命名為 `list*`，以更準確反映用途。

```diff
- const agents = mastra.getAgents();
+ const agents = mastra.listAgents();
- const vectors = mastra.getVectors();
+ const vectors = mastra.listVectors();
- const workflows = mastra.getWorkflows();
+ const workflows = mastra.listWorkflows();
- const scorers = mastra.getScorers();
+ const scorers = mastra.listScorers();
- const mcpServers = mastra.getMCPServers();
+ const mcpServers = mastra.listMCPServers();
- const logsByRunId = await mastra.getLogsByRunId({ runId: 'id', transportId: 'id' });
+ const logsByRunId = await mastra.listLogsByRunId({ runId: 'id', transportId: 'id' });
- const logs = await mastra.getLogs('transportId');
+ const logs = await mastra.listLogs('transportId');
```

:::tip[Codemod]

可以使用 Mastra 的 codemod CLI 自動更新程式碼：

```bash
npx @mastra/codemod@latest v1/mastra-plural-apis .
```

:::

### 每種基礎元件都提供 `getById` 與 `get` 函式 {/* #each-primitive-has-a-getbyid-and-a-get-function */}

```typescript
mastra.getMCPServer('myServer') // Works (registry key)
mastra.getMCPServerById('my-mcp-server') // Works (intrinsic ID)
```

### Tool 註冊現在使用本身的 ID {/* #tool-registration-now-uses-intrinsic-ids */}

從 Agent 或 MCP Server 向 Mastra 實例自動註冊 Tool 時，現在會使用 Tool 本身的 `id`，而非設定物件中的鍵。這可避免多個 Agent 或 MCP Server 的 Tool 使用相同設定鍵時發生衝突。

遷移時，請將透過設定鍵參照 Tool 的程式碼改為使用 Tool 本身的 ID。

```diff
  const agent = new Agent({
    id: 'agent1',
    tools: {
      searchTool: weatherSearchTool,
    },
  });

- mastra.getTool('searchTool');
+ mastra.getTool(weatherSearchTool.id);
```
