# 處理器

處理器介面已更新為使用一致的命名模式與資料庫訊息類型。

## 變更 {/* #changed */}

### 處理器設定由 `name` 改為 `id` {/* #processor-configuration-from-name-to-id */}

處理器現在必須提供 `id` 欄位，不再以 `name` 作為必填欄位；`name` 現為選填欄位。新欄位讓處理器與 Scorer、Agent 等其他 Mastra 實體保持一致。

遷移時，請更新處理器定義，將 `id` 設為必填欄位。

```diff
  import type { InputProcessor } from '@mastra/core/processors';

  const processor: InputProcessor = {
-   name: 'my-processor',
+   id: 'my-processor',
+   name: 'My Processor', // optional
    processInput: async ({ messages }) => {
      // ...
    },
  };
```

### 處理器訊息類型由 `MastraMessageV2` 改為 `MastraDBMessage` {/* #processor-message-types-from-mastramessagev2-to-mastradbmessage */}

處理器訊息類型已由 `MastraMessageV2` 改為 `MastraDBMessage`。處理器與 Scorer 現在使用資料庫訊息格式及其類型。

遷移時，請更新處理器訊息類型的匯入與用法。

```diff
  import type { InputProcessor } from '@mastra/core/processors';
- import type { MastraMessageV2 } from '@mastra/core/agent';
+ import type { MastraDBMessage } from '@mastra/core/agent';

  const processor: InputProcessor = {
    id: 'my-processor',
-   processInput: async ({ messages }: { messages: MastraMessageV2[] }) => {
+   processInput: async ({ messages }: { messages: MastraDBMessage[] }) => {
      // ...
    },
  };
```

## 移除項目 {/* #removed */}

### 已棄用的輸入處理器匯出 {/* #deprecated-input-processor-exports */}

包含內建處理器在內的已棄用輸入處理器匯出，已從 `@mastra/core/agent/input-processors/processors` 移除。請改用 `@mastra/core/processors`。此變更將處理器類型統一到 `Processor` 介面下。

如果你使用了 `InputProcessor`，請將它替換為 `Processor`，後者實作了 `processInput` 函式。

```diff
- import { InputProcessor, ModerationProcessor } from '@mastra/core/agent/input-processors/processors';
+ import { Processor, ModerationProcessor } from '@mastra/core/processors';
```

### Memory 處理器匯出移至 core {/* #memory-processor-exports-moved-to-core */}

`@mastra/memory/processors` 匯出已移除。所有處理器現在都從 `@mastra/core/processors` 匯出，讓處理器匯出集中在同一位置。

遷移時，請將匯入路徑從 `@mastra/memory/processors` 更新為 `@mastra/core/processors`。

```diff
- import { TokenLimiter, ToolCallFilter } from '@mastra/memory/processors';
+ import { TokenLimiter, ToolCallFilter } from '@mastra/core/processors';
```
