# 命令列介面

透過刪除部署命令、配置標誌和啟動文件，CLI 得到了簡化。新增了新的遷移命令以幫助資料庫架構升級。

## 額外 {/* #added */}

### `mastra migrate`命令 {/* #mastra-migrate-command */}

一個新的`mastra migrate` command helps run database migrations when upgrading Mastra versions. This is particularly useful when upgrading from older versions that may have data incompatibilities.

```bash
npx mastra migrate
```

該命令會捆綁您的專案並在運行任何必要的遷移之前連接到您配置的儲存空間。它目前支援遷移重複的跨度條目，這可能會阻止建立唯一約束。

請參閱[Storage migration guide](/reference/migrations/upgrade-to-v1/storage#duplicate-spans-migration) for details on when this migration is needed.

## 已刪除 {/* #removed */}

### `mastra deploy`命令 {/* #mastra-deploy-command */}

這`mastra deploy` command has been removed from the CLI. This change simplifies the CLI by removing vendor-specific deployment logic.

若要遷移，請選擇其中一項[deployment platforms](/docs/deployment/overview) of your choice.

### `--env`標誌來自`mastra build` {/* #--env-flag-from-mastra-build */}

這`--env` flag has been removed from the `mastra build` command. This change simplifies the build command.

要遷移，請使用`mastra start --env <env>` to start the build output with a custom environment.

```diff
- mastra build --env production
+ mastra build
+ mastra start --env production
```

### `--port`標誌來自`mastra dev` {/* #--port-flag-from-mastra-dev */}

這`--port` flag has been removed from the `mastra dev` command. Port configuration is now handled through the Mastra instance configuration. This change centralizes port configuration.

要遷移，請使用`server.port` on the Mastra instance instead of the CLI flag.

```ts
const mastra = new Mastra({
  server: {
    port: 3001,
  },
})
```

### CLI 中的遙測選項 {/* #telemetry-options-from-cli */}

這`telemetry` option has been removed from CLI commands including the `--no-telemetry` / `-nt` flag. Telemetry configuration has been removed from the CLI. This change reflects the move of telemetry features to the observability package.

若要遷移，請從 CLI 指令中刪除遙測標誌。使用`@mastra/observability` for tracing features.
