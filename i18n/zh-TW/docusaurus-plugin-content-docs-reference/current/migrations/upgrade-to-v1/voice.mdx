# 語音

語音套件的命名從 speech 改為 voice，類別名稱與 API 方法也已更新。

## 變更 {/* #changed */}

### 語音設定屬性名稱 {/* #voice-configuration-property-names */}

為統一命名，語音設定屬性已重新命名：`speakProvider` 改為 `output`、`listenProvider` 改為 `input`、`realtimeProvider` 改為 `realtime`。新名稱反映各屬性在語音輸入與輸出中的用途。

移轉時，請更新具備語音功能的 Agent 所用的設定屬性名稱。

```diff
  const agent = new Agent({
    id: 'agent',
    voice: {
-     speakProvider: murfVoice,
-     listenProvider: deepgramVoice,
-     realtimeProvider: openaiRealtime,
+     output: murfVoice,
+     input: deepgramVoice,
+     realtime: openaiRealtime,
    },
  });
```

:::tip[Codemod]

你可以使用 Mastra 的 codemod CLI 自動更新程式碼：

```bash
npx @mastra/codemod@latest v1/voice-property-names .
```

:::
