# 部署

OpenAPI 規格端點已移至 `/api/openapi.json`，`CloudflareDeployer` 設定改用 `wrangler.json` 的標準欄位名稱。

## 變更 {/* #changed */}

### OpenAPI 規格端點移至 `/api/openapi.json` {/* #openapi-spec-endpoint-moved-to-apiopenapijson */}

OpenAPI 規格端點已從 `/openapi.json` 移至 `/api/openapi.json`，與所有 Mastra 內建路由一致，使用 `/api` 前綴。

如果你的指令碼或工具會讀取 OpenAPI 規格，請更新其中的 URL。

```diff
- GET /openapi.json
+ GET /api/openapi.json
```

### `CloudflareDeployer` 改用 `wrangler.json` 的標準欄位名稱 {/* #cloudflaredeployer-uses-standard-wranglerjson-property-names */}

`CloudflareDeployer` 建構函式現在接受 `wrangler.json` 的標準欄位名稱，取代自訂的 camelCase 名稱。部署器因此符合 Cloudflare 的官方設定格式，也能使用 Wrangler 的所有設定選項。

系統會在執行時期自動遷移已棄用的欄位，並在主控台顯示警告。請更新程式碼，改用新的欄位名稱。

```diff
  const deployer = new CloudflareDeployer({
-   projectName: 'my-worker',
+   name: 'my-worker',
-   d1Databases: [
+   d1_databases: [
      {
        binding: 'DB',
        database_name: 'my-db',
        database_id: 'xxx',
      },
    ],
-   kvNamespaces: [
+   kv_namespaces: [
      {
        binding: 'KV',
        id: 'yyy',
      },
    ],
  });
```

`workerNamespace` 已無用途，因此已移除。

完整的設定選項請見 [Wrangler 設定文件](https://developers.cloudflare.com/workers/wrangler/configuration/)。
