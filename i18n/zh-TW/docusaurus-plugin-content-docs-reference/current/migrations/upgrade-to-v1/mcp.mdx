# MCP

MCP（模型上下文協定）Tool 的執行上下文已重新整理，已棄用的用戶端類別亦已移除。

## 變更 {/* #changed */}

### `getMCPServers` 改為 `listMCPServers` {/* #getmcpservers-to-listmcpservers */}

`mastra.getMCPServers()` 已更名為 `mastra.listMCPServers()`。這項變更符合整個 API 的命名慣例：取得多個物件的方法以 `list` 為前綴。

遷移時，請將所有 `mastra.getMCPServers()` 呼叫改為 `mastra.listMCPServers()`。

```diff
- const servers = await mastra.getMCPServers();
+ const servers = await mastra.listMCPServers();
```

:::tip[Codemod]

您可以使用 Mastra 的 codemod CLI 自動更新您的程式碼：

```bash
npx @mastra/codemod@latest v1/mastra-plural-apis .
```

:::

### MCP Tool 的上下文屬性調整 {/* #mcp-tool-context-properties-organization */}

MCP Tool 的上下文屬性現在歸入 `context.mcp` 命名空間，讓 MCP 專屬功能集中於清晰的 API 介面。

遷移時，存取 `elicitation` 和 `extra` 等 MCP 專屬屬性應透過 `context.mcp`，而非直接從 context 參數取得。

```diff
  createTool({
    id: 'account-balance',
-   execute: async ({ context, elicitation, extra }) => {
-     await checkAuth(extra.authInfo);
-     const result = await elicitation.sendRequest({
-       message: `Is it ok to fetch account ${context.accountId}?`,
-     });
-   },
+   execute: async (inputData, context) => {
+     await checkAuth(context?.mcp?.extra.authInfo);
+     const result = await context?.mcp?.elicitation.sendRequest({
+       message: `Is it ok to fetch account ${inputData.accountId}?`,
+     });
+   },
  });
```

:::note

`context.mcp.elicitation.sendRequest()` 已棄用。在運行 `@mastra/mcp` 2.x、支援 MCP `2026-07-28` 版本的伺服器上呼叫此方法會擲出錯誤。對於這些伺服器，請呼叫 `context.suspend(payload)`；Tool 再次執行時，從 `context.resumeData` 讀取呼叫方的回覆。詳見[要求呼叫方輸入的 Tool 如何暫停與恢復](/reference/migrations/mcp-v2#tools-that-ask-the-caller-for-input-suspend-and-resume)。

:::

## 已刪除 {/* #removed */}

### 已棄用的 MCP 用戶端類別 {/* #deprecated-mcp-client-classes */}

`MastraMCPClient` 及相關已棄用的 API 已從 `@mastra/mcp` 移除，統一採用新的 MCP 用戶端 API。

遷移時，請使用新的 `MCPClient` 類別取代已棄用的類別。

```diff
- import { MastraMCPClient, MCPConfiguration } from '@mastra/mcp/client';
+ import { MCPClient } from '@mastra/mcp/client';

- const client = new MastraMCPClient({ ... });
- const config = new MCPConfiguration({ ... });
+ const client = new MCPClient({ ... });
```
