# RAG

RAG 套件已重新命名分塊參數，並縮小其型別範圍。

## 變更 {/* #changed */}

### 將 `keepSeparator` 改為 `separatorPosition` {/* #keepseparator-to-separatorposition */}

參數 `keepSeparator` 已改名為 `separatorPosition`，型別也已簡化。舊型別為 `boolean | 'start' | 'end'`，其中 `true` 其實等同於 `'start'`。新參數必須明確指定 `'start' | 'end'`，省略時會捨棄分隔符號。

遷移時，請依下表將 `keepSeparator` 改為 `separatorPosition`。

| 舊值 | 新值 |
| - | - |
|`keepSeparator: true` | `separatorPosition: 'start'` |
| `keepSeparator: 'start'` | `separatorPosition: 'start'` |
| `keepSeparator: 'end'` | `separatorPosition: 'end'` |
| `keepSeparator: false` | 移除參數 |
| 未提供參數 | 無須變更 |

```diff
  await doc.chunk({
    strategy: 'character',
    separator: '.',
-   keepSeparator: true,
+   separatorPosition: 'start',
  });

  await doc.chunk({
    strategy: 'character',
    separator: '.',
-   keepSeparator: 'end',
+   separatorPosition: 'end',
  });

  await doc.chunk({
    strategy: 'character',
    separator: '.',
-   keepSeparator: false,
+   // Parameter removed - separator is discarded by default
  });
```
