#

截至`v0.20.0`為了`@mastra/core`，以下變更適用。

## 舊版 API (AI SDK v4) {/* #legacy-apis-ai-sdk-v4 */}

原始方法已被重命名並保持向後相容性**AI SDK v4** and `v1` models.

* `.stream()` → `.streamLegacy()`
* `.generate()` → `.generateLegacy()`

## 標準API（AI SDK v5） {/* #standard-apis-ai-sdk-v5 */}

這些是目前具有完整功能的 API**AI SDK v5** and `v2` model compatibility.

* `.streamVNext()` → `.stream()`
* `.generateVNext()` → `.generate()`

## 遷移路徑 {/* #migration-paths */}

如果您已經在使用`.streamVNext()` and `.generateVNext()` use find/replace to change methods to `.stream()` and `.generate()` respectively.

如果您使用的是舊版`.stream()` and `.generate()`, decide whether you want to upgrade or not. If you don't, use find/replace to change to `.streamLegacy()` and `.generateLegacy()`.

選擇適合您需求的遷移路徑：

### 繼續使用AI SDK v4模型 {/* #keep-using-ai-sdk-v4-models */}

* 重命名你的所有`.stream()` and `.generate()` calls to `.streamLegacy()` and `.generateLegacy()` respectively.

> 無需進一步更改。

### 繼續使用AI SDK v5模型 {/* #keep-using-ai-sdk-v5-models */}

* 重命名你的所有`.streamVNext()` and `.generateVNext()` calls to `.stream()` and `.generate()` respectively.

> 無需進一步更改。

### AI SDK v4升級到v5 {/* #upgrade-from-ai-sdk-v4-to-v5 */}

* 將所有模型Provider包按主要版本進行升級。

> 這將確保它們現在都是 v5 模型。請按照以下指南了解主要差異並相應更新您的程式碼。

## 主要差異 {/* #key-differences */}

`.stream()` and `.generate()` methods differ from their legacy counterparts in behavior, compatibility, return types, and available options. This section highlights the most important changes you need to understand when migrating.

### 型號版本支持 {/* #model-version-support */}

**舊版 API**

* `.generateLegacy()`
* `.streamLegacy()`

只支持**AI SDK v4** models (`specificationVersion: 'v1'`)

**標準API**

* `.generate()`
* `.stream()`

只支持**AI SDK v5** models (`specificationVersion: 'v2'`)

> 這是在運行時透過明確的錯誤訊息強制執行的。

### 返回類型 {/* #return-types */}

**舊版 API**

* `.generateLegacy()`返回：`GenerateTextResult` or `GenerateObjectResult`

* `.streamLegacy()`返回：`StreamTextResult` or `StreamObjectResult`

有關詳細信息，請參閱以下 API 參考：

* [Agent.generateLegacy()](/reference/agents/generateLegacy)
* [Agent.streamLegacy()](/reference/streaming/agents/streamLegacy)

**標準API**

* `.generate()`
  * `format: 'mastra'`（預設）：返回`MastraModelOutput.getFullOutput()`
  * `format: 'aisdk'`：退貨`AISDKV5OutputStream.getFullOutput()`
  * 內部調用`.stream()` and awaits `.getFullOutput()`

* `.stream()`
  * `format: 'mastra'`（預設）：返回`MastraModelOutput<OUTPUT>`
  * `format: 'aisdk'`：退貨`AISDKV5OutputStream<OUTPUT>`

有關詳細信息，請參閱以下 API 參考：

* [Agent.generate()](/reference/agents/generate)
* [Agent.stream()](/reference/streaming/agents/stream)

### 格式控制 {/* #format-control */}

#### 舊版 API {/* #legacy-apis */}

不`format` option: Always return AI SDK v4 types

```typescript
// Mastra native format (default)
const result = await agent.stream(messages)
```

#### 標準API {/* #standard-apis */}

使用`format` option to choose output:

* `'mastra'`(預設)
* `'aisdk'`（相容AI SDK v5）

```typescript
// AI SDK v5 compatibility
const result = await agent.stream(messages, {
  format: 'aisdk',
})
```

### 標準 API 中的新選項 {/* #new-options-in-standard-apis */}

標準中提供以下選項`.stream()` and `generate()`, but **NOT** in their legacy counterparts:

* `format`- 選擇“mastra”或“aisdk”輸出格式：

  ```typescript
  const result = await agent.stream(messages, {
    format: 'aisdk', // or 'mastra' (default)
  })
  ```

* `system`- 自訂系統訊息（與說明分開）。

  ```typescript
  const result = await agent.stream(messages, {
    system: 'You are a helpful assistant',
  })
  ```

* `structuredOutput`- 透過模型覆蓋和自訂選項增強結構化輸出。
  * `jsonPromptInjection`- 用於覆寫將response\_format 傳遞給模型的預設行為。這會將上下文注入提示中，以強制模型傳回結構化輸出。
  * `model`- 如果新增模型，這將建立一個子Agent程式來建立來自主Agent程式的回應。主Agent程式將呼叫Tool並傳回文本，子Agent程式將傳回符合您提供的架構的物件。這是替代品`experimental_output`.
  * `errorStrategy`- 確定當輸出與模式不符時會發生什麼：

    * 'warn' - 記錄警告
    * 'strict' - 拋出錯誤
    * 'fallback' - 傳回您提供的後備值

    ```typescript
    const result = await agent.generate(messages, {
      structuredOutput: {
        schema: z.object({
          name: z.string(),
          age: z.number(),
        }),
        model: '__GATEWAY_OPENAI_MODEL__', // Optional model override for structuring
        errorStrategy: 'fallback',
        fallbackValue: { name: 'unknown', age: 0 },
        instructions: 'Extract user information', // Override default structuring instructions
      },
    })
    ```

* `stopWhen`- 靈活的停止條件（步數、令牌限制等）。

  ```typescript
  const result = await agent.stream(messages, {
    stopWhen: ({ steps, totalTokens }) => steps >= 5 || totalTokens >= 10000,
  })
  ```

* `providerOptions`- 特定於Provider的選項（例如特定於 OpenAI 的設定）

  ```typescript
  const result = await agent.stream(messages, {
    providerOptions: {
      openai: {
        store: true,
        metadata: { userId: '123' },
      },
    },
  })
  ```

* `onChunk`- 每個流塊的回調。

  ```typescript
  const result = await agent.stream(messages, {
    onChunk: chunk => {
      console.log('Received chunk:', chunk)
    },
  })
  ```

* `onError`- 錯誤回調。

  ```typescript
  const result = await agent.stream(messages, {
    onError: error => {
      console.error('Stream error:', error)
    },
  })
  ```

* `onAbort`

  ```typescript
  const result = await agent.stream(messages, {
    onAbort: () => {
      console.log('Stream aborted')
    },
  })
  ```

* `activeTools`- 指定哪些Tool在此執行中處於活動狀態。

  ```typescript
  const result = await agent.stream(messages, {
    activeTools: ['search', 'calculator'], // Only these tools will be available
  })
  ```

* `abortSignal`- 用於取消的 AbortSignal。

  ```typescript
  const controller = new AbortController()
  const result = await agent.stream(messages, {
    abortSignal: controller.signal,
  })

  // Later: controller.abort();
  ```

* `prepareStep`- 多步驟執行中每一步之前的回呼。

  ```typescript
  const result = await agent.stream(messages, {
    prepareStep: ({ step, state }) => {
      console.log('About to execute step:', step)
      return {/* modified state */}
    },
  })
  ```

* `requireToolApproval`- 所有Tool呼叫都需要批准。

  ```typescript
  const result = await agent.stream(messages, {
    requireToolApproval: true,
  })
  ```

### 已移動的舊選項 {/* #legacy-options-that-moved */}

* `temperature`和其他`modelSettings`.

  統一於`modelSettings`

  ```typescript
  const result = await agent.stream(messages, {
    modelSettings: {
      temperature: 0.7,
      maxTokens: 1000,
      topP: 0.9,
    },
  })
  ```

* `resourceId`和`threadId`.



  ```typescript
  const result = await agent.stream(messages, {
    memory: {
      resource: 'user-123',
      thread: 'thread-456',
    },
  })
  ```

### 已棄用或刪除的選項 {/* #deprecated-or-removed-options */}

* `experimental_output`

  使用`structuredOutput` instead to allow for tool calls and an object return.

  ```typescript
  const result = await agent.generate(messages, {
    structuredOutput: {
      schema: z.object({
        summary: z.string(),
      }),
      model: '__GATEWAY_OPENAI_MODEL__',
    },
  })
  ```

* `output`

  這`output` property is deprecated in favor of `structuredOutput`, to achieve the same results, omit the model and only pass `structuredOutput.schema`, optionally add `jsonPromptInjection: true` if your model doesn't natively support `response_format`.

  ```typescript
  const result = await agent.generate(messages, {
    structuredOutput: {
      schema: z.object({
        name: z.string(),
      }),
    },
  })
  ```

* `memoryOptions`

  使用`memory` instead.

  ```typescript
  const result = await agent.generate(messages, {
    memory: {},
  })
  ```

### 類型變化 {/* #type-changes */}

**舊版 API**

* `CoreMessage[]`

有關詳細信息，請參閱以下 API 參考：

* [Agent.generateLegacy()](/reference/agents/generateLegacy)
* [Agent.streamLegacy()](/reference/streaming/agents/streamLegacy)

**標準API**

* `ModelMessage[]`

  `toolChoice`使用AI SDK v5`ToolChoice` type.

  ```typescript
  type ToolChoice<TOOLS extends Record<string, unknown>> =
    | 'auto'
    | 'none'
    | 'required'
    | {
        type: 'tool'
        toolName: Extract<keyof TOOLS, string>
      }
  ```

有關詳細信息，請參閱以下 API 參考：

* [Agent.generate()](/reference/agents/generate)
* [Agent.stream()](/reference/streaming/agents/stream)
