# 從 AgentNetwork 遷移到`.network()`

截至`v0.20.0`為了`@mastra/core`，以下變更適用。

## AI SDK v4升級到v5 {/* #upgrade-from-ai-sdk-v4-to-v5 */}

* 將所有模型Provider包按主要版本進行升級。

：：：筆記

這將確保它們現在都是 v5 模型。

:::

## 需要記憶體 {/* #memory-is-required */}

* 現在Agent網路需要記憶體才能正常運作。

：：：筆記

您必須為Agent配置記憶體。

:::

## 遷移路徑 {/* #migration-paths */}

如果您使用的是`AgentNetwork` primitive, you can replace the `AgentNetwork` with `Agent`.

前：

```typescript
import { AgentNetwork } from '@mastra/core/network'

const agent = new AgentNetwork({
  name: 'agent-network',
  agents: [agent1, agent2],
  tools: { tool1, tool2 },
  model: '__GATEWAY_OPENAI_MODEL__',
  instructions: 'You are a network agent that can help users with a variety of tasks.',
})

await agent.stream('Find me the weather in Tokyo.')
```

後：

```typescript
import { Agent } from '@mastra/core/agent'
import { Memory } from '@mastra/memory'

const memory = new Memory()

const agent = new Agent({
  id: 'agent-network',
  name: 'agent-network',
  agents: { agent1, agent2 },
  tools: { tool1, tool2 },
  model: '__GATEWAY_OPENAI_MODEL__',
  instructions: 'You are a network agent that can help users with a variety of tasks.',
  memory,
})

await agent.network('Find me the weather in Tokyo.')
```

如果您使用的是`NewAgentNetwork` primitive, you can replace the `NewAgentNetwork` with `Agent`.

前：

```typescript
import { NewAgentNetwork } from '@mastra/core/network/vnext'

const agent = new NewAgentNetwork({
  id: 'agent-network',
  name: 'agent-network',
  agents: { agent1, agent2 },
  workflows: { workflow1 },
  tools: { tool1, tool2 },
  model: '__GATEWAY_OPENAI_MODEL__',
  instructions: 'You are a network agent that can help users with a variety of tasks.',
})

await agent.loop('Find me the weather in Tokyo.')
```

後：

```typescript
import { Agent } from '@mastra/core/agent'
import { Memory } from '@mastra/memory'

const memory = new Memory()

const agent = new Agent({
  id: 'agent-network',
  name: 'agent-network',
  agents: { agent1, agent2 },
  workflows: { workflow1 },
  tools: { tool1, tool2 },
  model: '__GATEWAY_OPENAI_MODEL__',
  instructions: 'You are a network agent that can help users with a variety of tasks.',
  memory,
})

await agent.network('Find me the weather in Tokyo.')
```
