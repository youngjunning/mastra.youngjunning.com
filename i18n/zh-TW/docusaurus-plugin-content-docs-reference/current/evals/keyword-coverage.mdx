# 關鍵字涵蓋率評分器

`createKeywordCoverageScorer()` 函式評估 LLM 輸出涵蓋輸入中重要關鍵字的程度。它會檢查關鍵字是否出現、是否符合，並忽略常見字詞和停用詞。

## 參數 {/* #parameters */}

`createKeywordCoverageScorer()` 函式不接受任何選項。

此函式回傳 MastraScorer 類別的實例。關於 `.run()` 方法及其輸入與輸出，請參閱 [MastraScorer 參考文件](./mastra-scorer)。

## 評分細節 {/* #scoring-details */}

評分器透過比對關鍵字來評估涵蓋率，具備以下特性：

- 過濾常見字詞和停用詞（例如「the」、「a」、「and」）
- 比對時不區分大小寫
- 處理詞形變化
- 特別處理技術術語和複合字詞

### 評分流程 {/* #scoring-process */}

1. 處理輸入與輸出中的關鍵字：
   - 過濾常見字詞和停用詞
   - 正規化大小寫與詞形
   - 處理特殊術語和複合字詞
1. 計算關鍵字涵蓋率：
   - 比對兩段文字中的關鍵字
   - 計算成功比對的數量
   - 計算涵蓋比例

最終分數：`(matched_keywords / total_keywords) * scale`

### 分數解讀 {/* #score-interpretation */}

涵蓋率分數介於 0 和 1 之間：

- **1.0**：完全涵蓋，所有關鍵字都出現。
- **0.7 至 0.9**：涵蓋率高，包含大部分關鍵字。
- **0.4 至 0.6**：部分涵蓋，包含部分關鍵字。
- **0.1 至 0.3**：涵蓋率低，僅比對到少量關鍵字。
- **0.0**：回應中未包含任何關鍵字。

### 特殊情況 {/* #special-cases */}

評分器也會處理以下特殊情況：

- 輸入與輸出為空：兩者皆為空時回傳 1.0，只有一者為空時回傳 0.0
- 單一字詞：視為一個關鍵字
- 技術術語：保留複合技術術語（例如「React.js」、「機器學習」）
- 大小寫差異：「JavaScript」可與「javascript」相符
- 常見字詞：評分時予以忽略，以聚焦有用的關鍵字

## 範例 {/* #example */}

評估輸入查詢與 Agent 回應之間的關鍵字涵蓋率：

```typescript title="src/example-keyword-coverage.ts"
import { runEvals } from '@mastra/core/evals'
import { createKeywordCoverageScorer } from '@mastra/evals/scorers/prebuilt'
import { myAgent } from './agent'

const scorer = createKeywordCoverageScorer()

const result = await runEvals({
  data: [
    {
      input: 'JavaScript frameworks like React and Vue',
    },
    {
      input: 'TypeScript offers interfaces, generics, and type inference',
    },
    {
      input:
        'Machine learning models require data preprocessing, feature engineering, and hyperparameter tuning',
    },
  ],
  scorers: [scorer],
  target: myAgent,
  onItemComplete: ({ scorerResults }) => {
    console.log({
      score: scorerResults[scorer.id].score,
    })
  },
})

console.log(result.scores)
```

關於 `runEvals` 的更多資訊，請參閱 [runEvals 參考文件](/reference/evals/run-evals)。

如需將此評分器加入 Agent，請參閱[評分器總覽](/docs/evals/overview#adding-scorers-to-agents)指南。
