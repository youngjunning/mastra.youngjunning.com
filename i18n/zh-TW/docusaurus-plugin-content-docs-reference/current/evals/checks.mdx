# 快速檢查

Quick Checks 是無須呼叫 LLM、可組合的輕量評分器，用來驗證常見的斷言。凡是使用評分器的地方，都能將它們加入現有的 `scorers: [...]` 陣列，包括 `runEvals`、即時評分、實驗與 Studio。

它們在內部都是標準的 `createScorer()` 執行個體，因此與其他評分器一樣，支援可觀測性、儲存及管線整合。

:::note[註冊檢查以持久化分數]

只有將檢查與 `storage` 一同註冊到 Mastra 執行個體，分數才會寫入分數儲存區。每種檢查都有固定的 id（例如 `checks.includes()` 對應 `check-includes`，`checks.calledTool()` 對應 `check-called-tool`）；因此，無論傳入什麼引數，註冊一個執行個體就能涵蓋該檢查的所有呼叫。請參閱[分數持久化](/docs/evals/overview#score-persistence)。

:::

## 使用範例 {/* #usage-example */}

```typescript title="src/evals/weather-checks.ts"
import { checks } from '@mastra/evals/checks'
import { runEvals } from '@mastra/core/evals'
import { myAgent } from '../agents'

const result = await runEvals({
  data: [{ input: 'What is the weather in Brooklyn?' }],
  target: myAgent,
  scorers: [
    checks.includes('sunny'),
    checks.calledTool('get_weather'),
    checks.toolOrder(['get_weather', 'summarize']),
    checks.noToolErrors(),
  ],
})

console.log(result.scores)
```

## 文字檢查 {/* #text-checks */}

### `checks.usedNoTools()` {/* #checksusednotools */}

如果 Agent 完全沒有呼叫 Tool，則得分為 1。

```typescript
checks.usedNoTools()
```

回傳值：未呼叫任何 Tool 時為 `1`，否則為 `0`。

### `checks.noToolErrors()` {/* #checksnotoolerrors */}

如果所有 Tool 呼叫都沒有進入錯誤狀態，則得分為 1。此檢查會偵測錯誤結果（存在 `result.error`）與未完成的 Tool 呼叫（`state === 'call'`）。

```typescript
checks.noToolErrors()
```

回傳值：所有 Tool 呼叫都成功時為 `1`，否則為 `0`。

## 與其他評分器組合使用 {/* #combining-checks-with-other-scorers */}

檢查可以與使用 LLM 或程式碼的評分器一起放入同一個 `scorers` 陣列：

```typescript title="src/evals/combined-eval.ts"
import { checks } from '@mastra/evals/checks'
import { createAnswerRelevancyScorer } from '@mastra/evals/scorers/prebuilt'
import { runEvals } from '@mastra/core/evals'
import { myAgent } from '../agents'

const result = await runEvals({
  data: [{ input: 'What is the weather in Brooklyn?' }],
  target: myAgent,
  scorers: [
    // Zero-LLM checks
    checks.includes('Brooklyn'),
    checks.calledTool('get_weather'),
    checks.noToolErrors(),
    // LLM-based scorer
    createAnswerRelevancyScorer({ model: '__GATEWAY_OPENAI_MODEL_LUNA__' }),
  ],
})
```

## 多輪對話中的行為 {/* #multi-turn-behavior */}

檢查會讀取累積的 `run.output`，因此在[多輪評估](/docs/evals/multi-turn)中可以看到每一輪。`checks.calledTool('get_weather', { times: 2 })` 會統計整段對話的呼叫次數，`checks.includes()` 則會搜尋所有助理文字。如果只要求特定輪次符合檢查，請使用該輪的 `turns[].scorers`。
