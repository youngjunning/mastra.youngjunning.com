# 答案相似度評分器

這`createAnswerSimilarityScorer()`函數建立一個評分器，用於評估Agent的輸出與真實答案的相似程度。此評分器專為 CI/CD 測試場景而設計，在這些場景中，您有預期的答案並希望確保隨著時間的推移保持一致性。

## 評分詳情 {/* #scoring-details */}

記分器使用多步驟流程：

1. **提煉**：將輸出和基本事實分解為語義單元
2. **分析**：比較單位並識別匹配、矛盾和差距
3. **分數**：計算加權相似度並懲罰矛盾
4. **原因**：生成人類可讀的解釋

分數計算：`max(0, min(1, base_score - contradiction_penalty - extra_info_penalty)) × scale`

`base_score`是每場比賽的積分總和，減去`missingPenalty` for each missing unit, divided by `ground_truth_units × (1 + exactMatchBonus)`. The score is 0 when the ground truth has no units.

## 例子 {/* #example */}

評估Agent回應在不同場景中與真實情況的相似性：

```typescript title="src/example-answer-similarity.ts"
import { runEvals } from '@mastra/core/evals'
import { createAnswerSimilarityScorer } from '@mastra/evals/scorers/prebuilt'
import { myAgent } from './agent'

const scorer = createAnswerSimilarityScorer({ model: '__GATEWAY_OPENAI_MODEL__' })

const result = await runEvals({
  data: [
    {
      input: 'What is 2+2?',
      groundTruth: '4',
    },
    {
      input: 'What is the capital of France?',
      groundTruth: 'The capital of France is Paris',
    },
    {
      input: 'What are the primary colors?',
      groundTruth: 'The primary colors are red, blue, and yellow',
    },
  ],
  scorers: [scorer],
  target: myAgent,
  onItemComplete: ({ scorerResults }) => {
    console.log({
      score: scorerResults[scorer.id].score,
      reason: scorerResults[scorer.id].reason,
    })
  },
})

console.log(result.scores)
```

欲了解更多詳情`runEvals`, see the [runEvals reference](/reference/evals/run-evals).

若要將此記分員新增至Agent，請參閱[Scorers overview](/docs/evals/overview#adding-scorers-to-agents) guide.
