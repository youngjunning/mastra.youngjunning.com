# 情境回憶評分器

這`createContextRecallScorer()`函數建立一個評分器，用於評估檢索到的上下文對真實參考答案中的主張的覆蓋程度。它透過檢查事實真相聲明的哪一部分可歸因於檢索到的上下文來衡量檢索完整性。

此評分器需要真實的參考答案，使其適合 CI 或測試環境中的標記資料集。什麼時候`groundTruth` isn't provided in the run, the scorer returns a score of 0 rather than throwing an error.

## RAG檢索評估 {/* #rag-retrieval-evaluation */}

非常適合評估 RAG 管道中的檢索完整性，其中：

* 您需要驗證檢索器是否獲取了所有必要的信息
* 您已用已知正確答案標記了資料集
* 您想要捕獲檢索器返回的回歸

## 資料集驅動的測試 {/* #dataset-driven-testing */}

針對策劃的測試集運行評估時使用：

* 帶有真實標記問題的 CI 管道
* A/B 測驗檢索策略
* 對覆蓋範圍的嵌入模型進行基準測試

任何一個`context` or `contextExtractor` must be provided. When both are provided, `contextExtractor` is used only if the run input and output are agent-shaped: the input must be an agent run-input object (`{ inputMessages, rememberedMessages, systemMessages, taggedSystemMessages }`) and the output must be a `MastraDBMessage[]`. Otherwise the scorer falls back to `context`.

## 評分詳情 {/* #scoring-details */}

### 聲明歸屬 {/* #claim-attribution */}

Context Recall 使用兩步驟 LLM 評估，然後進行確定性分數計算：

1. **索賠提取**：真實答案被分解為原子聲明
2. **歸因檢查**：每個聲明都會根據檢索上下文進行檢查以獲取支持

然後將分數計算為歸因索賠與總索賠的比率乘以規模。

### 評分公式 {/* #scoring-formula */}

```text
Context Recall = attributed_claims / total_claims × scale

Where:
- attributed_claims = number of ground-truth claims supported by the context
- total_claims = total number of claims extracted from the ground truth
- Attribution is binary: a claim is either supported (yes) or not (no)
```

### 分數解讀 {/* #score-interpretation */}

這些範圍採用預設值`scale` of 1. When using a custom scale, multiply accordingly.

* **0.9-1.0**：出色的回憶，上下文幾乎涵蓋了所有真實的說法
* **0.7-0.8**: 記得很好。大多數索賠均已涵蓋，但存在微小差距
* **0.4-0.6**：回憶能力中等，上下文缺少大量資訊
* **0.1-0.3**：記憶力差，大多數真實的說法在上下文中找不到
* **0.0**：不記得，上下文中沒有任何真實的說法

### 原因分析 {/* #reason-analysis */}

原因欄位解釋：

* 在上下文中發現了哪些真實的主張
* 缺少哪些聲明以及存在哪些資訊差距
* 支持歸因聲明的特定上下文片段

### 優化見解 {/* #optimization-insights */}

使用結果來：

* **提高檢索能力**：識別檢索器錯過的資訊類型
* **調整區塊大小**：確保區塊包含足夠的細節來涵蓋真實的聲明
* **評估嵌入**：測試不同的嵌入模型以獲得更好的資訊覆蓋
* **擴大知識庫**：新增涵蓋經常錯過的索賠的文件

### 計算範例 {/* #example-calculation */}

基本事實：“愛因斯坦出生於 1879 年。他發展了相對論。他獲得了諾貝爾獎。”

提取的索賠：3

* 「愛因斯坦出生於 1879 年」→ 歸因（上下文提到出生日期）
* 「愛因斯坦發展了相對論」→歸因（上下文涵蓋相對論）
* 「愛因斯坦獲得諾貝爾獎」 → 未註明出處（上下文未提及諾貝爾獎）

召回率 = 2/3 = 0.67

## 記分器配置 {/* #scorer-configuration */}

### 動態上下文提取 {/* #dynamic-context-extraction */}

```typescript
const scorer = createContextRecallScorer({
  model: '__GATEWAY_OPENAI_MODEL__',
  options: {
    contextExtractor: (input, output) => {
      const query = input?.inputMessages?.[0]?.content || ''
      const searchResults = vectorDB.search(query, { limit: 10 })
      return searchResults.map(result => result.content)
    },
    scale: 1,
  },
})
```

### 靜態情境評估 {/* #static-context-evaluation */}

```typescript
const scorer = createContextRecallScorer({
  model: '__GATEWAY_OPENAI_MODEL__',
  options: {
    context: [
      'Document 1: Einstein was born on 14 March 1879 in Ulm, Germany.',
      'Document 2: Einstein published the theory of special relativity in 1905.',
      'Document 3: Einstein moved to the United States in 1933.',
    ],
  },
})
```

## 例子 {/* #example */}

根據標記資料集評估 RAG 檢索完整性：

```typescript title="src/example-context-recall.ts"
import { runEvals } from '@mastra/core/evals'
import { createContextRecallScorer } from '@mastra/evals/scorers/prebuilt'
import { myAgent } from './agent'

const scorer = createContextRecallScorer({
  model: '__GATEWAY_OPENAI_MODEL__',
  options: {
    contextExtractor: (input, output) => {
      // Extract context from tool invocation results in the agent output
      return output
        .filter(msg => msg?.role === 'assistant')
        .flatMap(msg => msg?.content?.toolInvocations ?? [])
        .filter((tool: any) => tool.state === 'result')
        .map((tool: any) => JSON.stringify(tool.result))
    },
  },
})

const result = await runEvals({
  data: [
    {
      input: 'What are the health benefits of green tea?',
      groundTruth:
        'Green tea contains antioxidants that reduce inflammation, L-theanine that improves focus, and catechins that boost metabolism.',
    },
    {
      input: 'How does photosynthesis work?',
      groundTruth:
        'Photosynthesis converts sunlight into chemical energy using chlorophyll in chloroplasts, producing glucose and oxygen from carbon dioxide and water.',
    },
  ],
  scorers: [scorer],
  target: myAgent,
  onItemComplete: ({ scorerResults }) => {
    console.log({
      score: scorerResults[scorer.id].score,
      reason: scorerResults[scorer.id].reason,
    })
  },
})

console.log(result.scores)
```

欲了解更多詳情`runEvals`, see the [runEvals reference](/reference/evals/run-evals).

若要將此記分員新增至Agent，請參閱[Scorers overview](/docs/evals/overview#adding-scorers-to-agents) guide.

## 與上下文精度的比較 {/* #comparison-with-context-precision */}

選擇適合您需求的記分器：

|使用案例|情境回憶 |上下文精確度 |
| - | - | - |
|**What it measures** | Coverage of ground truth | Relevance of retrieved chunks |
| **Direction** | Ground truth → context | Context → ground truth |
| **Position sensitive** | No | Yes (rewards early placement) |
| **Requires ground truth** | Yes | Yes |
| **Failure mode caught** | Missing information | Irrelevant noise |

將兩者結合使用可以全面了解檢索品質：精確度可以捕捉上下文中的垃圾，召回可以捕捉空白。
