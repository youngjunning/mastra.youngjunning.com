# Rubric 評分器

**於以下版本新增：** `@mastra/evals@1.3.0`

`createRubricScorer()` 會建立以 LLM 為評審的評分器，依 rubric（評分準則清單）評量 Agent 的輸出。它回傳**二元**分數：只有所有必要準則都符合時才是 `1`，否則是 `0`。`reason` 會列出各項準則的判定結果，讓 Agent 清楚知道需要改善什麼。

此評分器可直接用於 [`isTaskComplete`](/reference/streaming/agents/stream)。`isTaskComplete` 會將 `score === 1` 視為「任務完成」，並把 `reason` 作為回饋加入對話；因此 Agent 會持續迭代，直到符合 rubric 或達到 `maxSteps`。

## 搭配 isTaskComplete 使用 {/* #usage-with-istaskcomplete */}

定義一次 rubric，並將評分器接入 `isTaskComplete`。Agent 會自行修正輸出，直到符合 rubric：

```typescript
import { Agent } from '@mastra/core/agent'
// highlight-next-line
import { createRubricScorer } from '@mastra/evals/scorers/prebuilt'

const supervisor = new Agent({
  id: 'supervisor',
  instructions: `You coordinate research and writing using specialized agents. Delegate to research-agent for facts, then writing-agent for content.`,
  model: '__GATEWAY_OPENAI_MODEL__',
  agents: { researchAgent, writingAgent },
})

// highlight-start
const rubricScorer = createRubricScorer({
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  criteria: [
    { description: 'The response includes an analysis section' },
    { description: 'The response includes concrete recommendations' },
  ],
})
// highlight-end

const stream = await supervisor.stream('Research AI in education', {
  maxSteps: 10,
  // highlight-start
  isTaskComplete: {
    scorers: [rubricScorer],
    strategy: 'all',
  },
  // highlight-end
})
```

## 字串形式的 rubric {/* #string-rubric */}

以換行分隔的字串會解析為各項準則，常見清單標記（`-`、`*`、`1.`）會被移除。每行都是一項必要準則：

```typescript
const rubricScorer = createRubricScorer({
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  criteria: `- All tests pass in the test suite
- The function is named find_duplicates and accepts a single list argument`,
})
```

## 選用準則 {/* #optional-criteria */}

將準則標記為選用後，它仍會被評分及報告，但不會影響任務是否完成：

```typescript
const rubricScorer = createRubricScorer({
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  criteria: [
    { description: 'Includes an analysis section', required: true },
    { description: 'Includes citations', required: false },
  ],
})
```

## 每次執行使用動態 rubric {/* #dynamic-rubric-per-run */}

若建立評分器時未傳入 `criteria`，評分器會從該次執行的請求內容、附加內容或輸入中尋找 `rubric` 值。因此，同一個評分器執行個體可在不同執行中使用不同 rubric，無須重新建立：

```typescript
const rubricScorer = createRubricScorer({
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
})

await supervisor.stream('Write find_duplicates', {
  isTaskComplete: { scorers: [rubricScorer] },
  requestContext: {
    rubric: '- All tests pass\n- The function is named find_duplicates',
  },
})
```

若找不到 rubric，評分器會回傳 `1`，不會阻止迴圈結束。

## 評分細節 {/* #scoring-details */}

評分器分兩個階段執行：

1. **評量**：評審模型會獨立評量各項準則，並回傳是否 `satisfied` 及其理由。
2. **計分**：只有評分器才回傳 `1`，前提是所有必要準則都為 `satisfied`；若未將任何準則標記為必要，則將所有準則視為必要。其他情況均回傳 `0`。

`reason` 會彙整評分結果並列出各項準則的判定，讓 Agent 在評分未通過時獲得具體回饋，而非籠統的「再試一次」。
