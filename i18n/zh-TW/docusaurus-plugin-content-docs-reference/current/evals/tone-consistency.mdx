# 語氣一致性評分器

這`createToneScorer()`函數評估文本的情感基調和情感一致性。它可以以兩種模式運行：將Agent輸出的情緒與非空進行比較`referenceTone`，或分析Agent輸出句子中的語氣穩定性。

## 評分詳情 {/* #scoring-details */}

評分者透過語氣模式分析和特定模式評分來評估情緒一致性。

### 評分流程 {/* #scoring-process */}

1. 分析音調模式：
   * 提取情緒特徵
   * 計算情緒分數
   * 測量音調變化
2. 計算特定於模式的分數：**Tone Consistency** (non-empty `referenceTone`):
   * 將輸出的情緒與`referenceTone` sentiment
   * 計算絕對情緒差異
   * 分數 = max(0, 1 - 情緒差異)**Tone Stability** (`referenceTone` omitted or empty):
   * 分析輸出句子中的情緒
   * 計算情緒方差
   * 分數 = max(0, 1 - 情緒變異數)

最終成績：`mode_specific_score`

### 分數解讀 {/* #score-interpretation */}

(0-1)

* 1.0：完美的音色一致性/穩定性
* 0.7-0.9：一致性強，變化小
* 0.4-0.6：中等一致性，有明顯變化
* 0.1-0.3：一致性較差，音調變化較大
* 0.0：沒有一致性－完全不同的色調

### `preprocessStepResult` {/* #preprocessstepresult */}

具有音調指標的對象：

* **回應情緒**：反應的情緒分數（比較模式）。
* **參考情緒**: 的情緒得分`referenceTone` (comparison mode).
* **不同之處**：情緒分數之間的絕對差異（比較模式）。
* **平均情緒**：句子之間的平均情緒（穩定模式）。
* **情緒方差**：句間情緒的變異數（穩定模式）。

## 例子 {/* #example */}

評估座席回應是否與正面的參考語氣相符：

```typescript title="src/example-tone-consistency.ts"
import { runEvals } from '@mastra/core/evals'
import { createToneScorer } from '@mastra/evals/scorers/prebuilt'
import { myAgent } from './agent'

const scorer = createToneScorer({
  referenceTone: 'We are happy to help and glad you had a great experience!',
})

const result = await runEvals({
  data: [
    { input: 'How was your experience with our service?' },
    { input: 'Tell me about the customer support' },
  ],
  scorers: [scorer],
  target: myAgent,
  onItemComplete: ({ scorerResults }) => {
    console.log({
      score: scorerResults[scorer.id].score,
    })
  },
})

console.log(result.scores)
```

欲了解更多詳情`runEvals`, see the [runEvals reference](/reference/evals/run-evals).

若要將此記分員新增至Agent，請參閱[Scorers overview](/docs/evals/overview#adding-scorers-to-agents) guide.
