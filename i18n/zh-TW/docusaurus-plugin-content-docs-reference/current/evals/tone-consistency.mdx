# 語氣一致性評分器

`createToneScorer()` 函數評估文字的情緒語氣及其一致性。它有兩種模式：將 Agent 輸出的情感傾向與非空的 `referenceTone` 比較，或分析輸出各句之間的語氣穩定性。

## 評分詳情 {/* #scoring-details */}

評分器分析語氣模式，並根據所選模式計算情感一致性評分。

### 評分流程 {/* #scoring-process */}

1. 分析語氣模式：
   * 提取情感特徵
   * 計算情緒分數
   * 測量語氣變化
2. 按模式計算評分：
   **語氣一致性**（`referenceTone` 非空）：
   * 比較輸出與 `referenceTone` 的情感傾向
   * 計算絕對情緒差異
   * 評分 = max(0, 1 - 情感差異)
   **語氣穩定性**（省略 `referenceTone` 或將其留空）：
   * 分析輸出句子中的情緒
   * 計算情緒變異數
   * 評分 = max(0, 1 - 情感變異數)

最終評分：`mode_specific_score`

### 分數解讀 {/* #score-interpretation */}

(0-1)

* 1.0：語氣完全一致／穩定
* 0.7-0.9：一致性較高，變化很小
* 0.4-0.6：一致性中等，存在明顯變化
* 0.1-0.3：一致性較差，語氣變化較大
* 0.0：完全不一致，語氣截然不同

### `preprocessStepResult` {/* #preprocessstepresult */}

包含語氣指標的對象：

* **responseSentiment**：回應的情緒分數（比較模式）。
* **referenceSentiment**： `referenceTone` 的情感評分（比較模式）。
* **difference**：情緒分數之間的絕對差異（比較模式）。
* **avgSentiment**：句子之間的平均情緒（穩定模式）。
* **sentimentVariance**：句子間情緒的變異數（穩定模式）。

## 範例 {/* #example */}

評估 Agent 回覆是否符合積極的參考語氣：

```typescript title="src/example-tone-consistency.ts"
import { runEvals } from '@mastra/core/evals'
import { createToneScorer } from '@mastra/evals/scorers/prebuilt'
import { myAgent } from './agent'

const scorer = createToneScorer({
  referenceTone: 'We are happy to help and glad you had a great experience!',
})

const result = await runEvals({
  data: [
    { input: 'How was your experience with our service?' },
    { input: 'Tell me about the customer support' },
  ],
  scorers: [scorer],
  target: myAgent,
  onItemComplete: ({ scorerResults }) => {
    console.log({
      score: scorerResults[scorer.id].score,
    })
  },
})

console.log(result.scores)
```

有關 `runEvals` 的詳情，請參閱 [runEvals 參考文檔](/reference/evals/run-evals)。

如需將此評分器添加到 Agent，請參閱[評分器概覽](/docs/evals/overview#adding-scorers-to-agents)。
