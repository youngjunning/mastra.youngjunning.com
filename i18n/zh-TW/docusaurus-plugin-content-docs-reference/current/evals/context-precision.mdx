# 上下文精確評分器

這`createContextPrecisionScorer()`函數建立一個評分器，用於評估檢索到的上下文片段的相關性和位置，以產生預期輸出。它使用**平均精度 (MAP)**&#x734E;勵將相關上下文置於序列較早位置的系統。

它對於以下用例特別有用：

## RAG系統評估 {/* #rag-system-evaluation */}

非常適合評估 RAG 管道中檢索到的上下文，其中：

* 上下文排序對於模型效能很重要
* 您需要衡量基本相關性以外的檢索質量
* 早期相關背景比後期相關背景更有價值

## 上下文視窗優化 {/* #context-window-optimization */}

在優化上下文選擇時使用：

* 有限的上下文視窗
* 代幣預算限制
* 多步驟推理任務

任何一個`context` or `contextExtractor` must be provided. `contextExtractor` is only called when the run input and output have agent shapes: the input has `inputMessages`, `rememberedMessages` and `systemMessages` arrays plus a `taggedSystemMessages` object, and the output is an array of messages. For any other input/output shape the scorer uses `context`. When neither is provided, the scorer throws.

如果你通過了`context`, the array must be non-empty. The constructor throws `Context array cannot be empty if provided` even when `contextExtractor` is also configured. When only `contextExtractor` is configured and the run isn't agent-shaped, there's no context to score against and evaluation throws `No context available for evaluation`.

## 評分詳情 {/* #scoring-details */}

### 平均精度 (MAP) {/* #mean-average-precision-map */}

上下文精度用途**Mean Average Precision** to evaluate both relevance and positioning:

1. **情境評估**：每個上下文片段都被分類為與生成預期輸出相關或不相關
2. **精密計算**：對於位置處的每個相關上下文`i`, precision = `relevant_items_so_far / (i + 1)`
3. **平均精度**：將所有精確度值相加並除以相關項目總數
4. **最終成績**：乘以比例因子並四捨五入到小數點後兩位

### 評分公式 {/* #scoring-formula */}

```text
MAP = (Σ Precision@k) / R

Where:
- Precision@k = (relevant items in positions 1...k) / k
- R = total number of relevant items
- Only calculated at positions where relevant items appear
```

### 分數解讀 {/* #score-interpretation */}

* **0.9-1.0**：出色的精確度 - 所有相關上下文均按順序排列
* **0.7-0.8**：精度高 - 最相關的上下文位置良好
* **0.4-0.6**：中等精度 - 相關上下文與不相關上下文混合在一起
* **0.1-0.3**：精度差 - 相關上下文很少或定位不當
* **0.0**: 沒有找到相關上下文

### 原因分析 {/* #reason-analysis */}

原因欄位解釋：

* 哪些上下文片段被認為是相關/不相關
* 定位如何影響 MAP 計算
* 評估中使用的具體相關性標準

### 優化見解 {/* #optimization-insights */}

使用結果來：

* **提高檢索能力**：排名前過濾掉不相關的上下文
* **優化排名**：確保相關背景儘早浮現
* **調整區塊大小**：平衡上下文細節與相關精度
* **評估嵌入**：測試不同的嵌入模型以獲得更好的檢索

### 計算範例 {/* #example-calculation */}

情境:`[relevant, irrelevant, relevant, irrelevant]`

* 位置 0：相關 → 精度 = 1/1 = 1.0
* 位置1：跳過（無關）
* 位置 2：相關 → 精度 = 2/3 = 0.67
* 位置3：跳過（無關）

平均MAP = (1.0 + 0.67) / 2 = 0.835 ≈**0.83**

## 記分器配置 {/* #scorer-configuration */}

### 動態上下文提取 {/* #dynamic-context-extraction */}

```typescript
const scorer = createContextPrecisionScorer({
  model: '__GATEWAY_OPENAI_MODEL__',
  options: {
    contextExtractor: (input, output) => {
      // Extract context dynamically based on the query
      const query = input?.inputMessages?.[0]?.content || ''

      // Example: Retrieve from a vector database
      const searchResults = vectorDB.search(query, { limit: 10 })
      return searchResults.map(result => result.content)
    },
    scale: 1,
  },
})
```

### 大上下文評估 {/* #large-context-evaluation */}

```typescript
const scorer = createContextPrecisionScorer({
  model: '__GATEWAY_OPENAI_MODEL__',
  options: {
    context: [
      // Simulate retrieved documents from vector database
      'Document 1: Highly relevant content...',
      'Document 2: Somewhat related content...',
      'Document 3: Tangentially related...',
      'Document 4: Not relevant...',
      'Document 5: Highly relevant content...',
      // ... up to dozens of context pieces
    ],
  },
})
```

## 例子 {/* #example */}

評估RAG系統上下文對不同查詢的檢索精度：

```typescript title="src/example-context-precision.ts"
import { runEvals } from '@mastra/core/evals'
import { createContextPrecisionScorer } from '@mastra/evals/scorers/prebuilt'
import { myAgent } from './agent'

const scorer = createContextPrecisionScorer({
  model: '__GATEWAY_OPENAI_MODEL__',
  options: {
    contextExtractor: (input, output) => {
      // Extract context from agent's retrieved documents
      return output.metadata?.retrievedContext || []
    },
  },
})

const result = await runEvals({
  data: [
    {
      input: 'How does photosynthesis work in plants?',
    },
    {
      input: 'What are the mental and physical benefits of exercise?',
    },
  ],
  scorers: [scorer],
  target: myAgent,
  onItemComplete: ({ scorerResults }) => {
    console.log({
      score: scorerResults[scorer.id].score,
      reason: scorerResults[scorer.id].reason,
    })
  },
})

console.log(result.scores)
```

欲了解更多詳情`runEvals`, see the [runEvals reference](/reference/evals/run-evals).

若要將此記分員新增至Agent，請參閱[Scorers overview](/docs/evals/overview#adding-scorers-to-agents) guide.

## 與上下文相關性的比較 {/* #comparison-with-context-relevance */}

選擇適合您需求的記分器：

|使用案例|上下文相關性 |上下文精度 |
| - | - | - |
|**RAG evaluation** | When usage matters | When ranking matters |
| **Context quality** | Nuanced levels | Binary relevance |
| **Missing detection** | ✓ Identifies gaps | ✗ Not evaluated |
| **Usage tracking** | ✓ Tracks utilization | ✗ Not considered |
| **Position sensitivity** | ✗ Position agnostic | ✓ Rewards early placement |
