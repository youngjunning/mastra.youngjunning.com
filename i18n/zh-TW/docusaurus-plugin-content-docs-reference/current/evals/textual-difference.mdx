# 文字差異評分器

`createTextualDifferenceScorer()` 函式透過序列比對衡量兩個字串之間的文字差異。它會提供差異的詳細資訊，包括將一段文字轉換為另一段文字所需的操作次數。

## 參數 {/* #parameters */}

`createTextualDifferenceScorer()` 函式不接受任何選項。

此函式會傳回 MastraScorer 類別的執行個體。有關 `.run()` 方法及其輸入與輸出的詳細資訊，請參閱 [MastraScorer 參考文件](./mastra-scorer)。

## 評分詳情 {/* #scoring-details */}

評分器會計算以下指標：

* **相似度比率**：根據文字之間的序列比對計算，範圍為 0–1
* **變更次數**：不相符操作的數量
* **長度差異**：文字長度的正規化差異
* **信心分數**：與長度差異成反比

### 評分流程 {/* #scoring-process */}

1. 分析文字差異：
   * 比對輸入與輸出的字元序列
   * 統計所需的變更操作次數
   * 衡量文字長度差異
2. 計算指標：
   * 計算相似度比率
   * 決定信心分數
   * 組合成加權分數

最終分數：`(similarity_ratio * confidence) * scale`

### 分數解讀 {/* #score-interpretation */}

文字差異評分介於 0 和 1 之間：

* **1.0**：兩段文字完全相同。
* **0.7 至 0.9**：差異較小，只需少量修改。
* **0.4 至 0.6**：差異中等，需要明顯修改。
* **0.1 至 0.3**：差異很大，需要大量修改。
* **0.0**：兩段文字完全不同。

## 範例 {/* #example */}

衡量 Agent 的預期輸出與實際輸出之間的文字差異：

```typescript title="src/example-textual-difference.ts"
import { runEvals } from '@mastra/core/evals'
import { createTextualDifferenceScorer } from '@mastra/evals/scorers/prebuilt'
import { myAgent } from './agent'

const scorer = createTextualDifferenceScorer()

const result = await runEvals({
  data: [
    {
      input: 'Summarize the concept of recursion',
      groundTruth:
        'Recursion is when a function calls itself to solve a problem by breaking it into smaller subproblems.',
    },
    {
      input: 'What is the capital of France?',
      groundTruth: 'The capital of France is Paris.',
    },
  ],
  scorers: [scorer],
  target: myAgent,
  onItemComplete: ({ scorerResults }) => {
    console.log({
      score: scorerResults[scorer.id].score,
      groundTruth: scorerResults[scorer.id].groundTruth,
    })
  },
})

console.log(result.scores)
```

有關 `runEvals` 的詳細資訊，請參閱 [runEvals 參考文件](/reference/evals/run-evals)。

如需將此評分器加入 Agent，請參閱[評分器總覽](/docs/evals/overview#adding-scorers-to-agents)指南。
