# 內容相似度評分器

`createContentSimilarityScorer()` 函式測量兩個字串的文字相似度，並以分數表示其相近程度。可設定是否忽略大小寫差異，以及如何處理空白字元。

## 參數 {/* #parameters */}

`createContentSimilarityScorer()` 函式接受一個選項物件，包含以下屬性：

## 評分細節 {/* #scoring-details */}

評分器透過字元層級比對和可設定的文字正規化，評估文字相似度。

### 評分流程 {/* #scoring-process */}

1. 將文字正規化：
   - 大小寫正規化（若 ignoreCase: true）
   - 空白字元正規化（若 ignoreWhitespace: true）
1. 使用字串相似度演算法比較處理後的字串：
   - 分析字元序列
   - 對齊詞彙邊界
   - 考量相對位置
   - 考量長度差異

最終分數：`similarity_value`（0 到 1，直接傳回字串相似度比較的結果）

## 範例 {/* #example */}

評估 Agent 預期輸出與實際輸出之間的文字相似度：

```typescript title="src/example-content-similarity.ts"
import { runEvals } from '@mastra/core/evals'
import { createContentSimilarityScorer } from '@mastra/evals/scorers/prebuilt'
import { myAgent } from './agent'

const scorer = createContentSimilarityScorer()

const result = await runEvals({
  data: [
    {
      input: 'Summarize the benefits of TypeScript',
      groundTruth:
        'TypeScript provides static typing, better tooling support, and improved code maintainability.',
    },
    {
      input: 'What is machine learning?',
      groundTruth:
        'Machine learning is a subset of AI that enables systems to learn from data without explicit programming.',
    },
  ],
  scorers: [scorer],
  target: myAgent,
  onItemComplete: ({ scorerResults }) => {
    console.log({
      score: scorerResults[scorer.id].score,
      groundTruth: scorerResults[scorer.id].groundTruth,
    })
  },
})

console.log(result.scores)
```

關於 `runEvals` 的詳細資訊，請參閱 [runEvals 參考](/reference/evals/run-evals)。

若要將此評分器加入 Agent，請參閱[評分器概覽](/docs/evals/overview#adding-scorers-to-agents)。

### 分數解讀 {/* #score-interpretation */}

相似度分數介於 0 和 1 之間：

- **1.0**: 完全相符，內容幾乎相同。
- **0.7 to 0.9**: 高度相似，用詞或結構只有些微差異。
- **0.4 to 0.6**: 中度相似，整體內容有重疊，但差異明顯。
- **0.1 to 0.3**: 相似度低，共通元素或意義較少。
- **0.0**: 完全不相似，內容截然不同。
