# MastraJwtAuth 類別

`MastraJwtAuth` 類別透過 JSON Web Token（JWT）為 Mastra 提供輕量級身分驗證機制。它使用共用密鑰或 JSON Web Key Set（JWKS）端點提供的公開金鑰驗證傳入的請求，並透過 `auth` 選項與 Mastra 伺服器整合。

## 使用範例 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraJwtAuth } from '@mastra/auth'

export const mastra = new Mastra({
  server: {
    auth: new MastraJwtAuth({
      secret: '<your-secret>',
    }),
  },
})
```

若要驗證身分提供者簽發的權杖，請傳入其 JWKS URL 和簽發者，而非共用密鑰：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraJwtAuth } from '@mastra/auth'

export const mastra = new Mastra({
  server: {
    auth: new MastraJwtAuth({
      jwksUri: 'https://auth.example.com/.well-known/jwks.json',
      issuer: 'https://auth.example.com/',
    }),
  },
})
```

## 使用者 ID {/* #user-id */}

已驗證使用者的 `id` 取自權杖的 `id` 宣告，或取自 `sub` 宣告（當權杖沒有 `id` 時）。RBAC 依此 `id` 查詢角色；除非設定 `mapUserToResourceId`，使用者建立的紀錄也歸其所有。請參閱 [JWT 提供者的使用者 ID](/docs/guides/authentication-identity#user-ids-from-jwt-providers)。
