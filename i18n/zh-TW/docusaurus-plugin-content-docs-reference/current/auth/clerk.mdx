# MastraAuthClerk 類

這`MastraAuthClerk`類別使用 Clerk 為 Mastra 應用程式提供身份驗證。它使用 Clerk 頒發的 JWT 令牌驗證傳入請求，並使用以下命令與 Mastra 伺服器集成`auth`選項。

## 使用範例 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraAuthClerk } from '@mastra/auth-clerk'

export const mastra = new Mastra({
  server: {
    auth: new MastraAuthClerk({
      jwksUri: process.env.CLERK_JWKS_URI,
      publishableKey: process.env.CLERK_PUBLISHABLE_KEY,
      secretKey: process.env.CLERK_SECRET_KEY,
    }),
  },
})
```

## 限制登入單一組織 {/* #restricting-login-to-a-single-organization */}

放`organizationId` or `organizationSlug` to only allow members of a specific Clerk organization to sign in. Non-members are rejected during authorization. Configure only one of the two. Setting both throws at startup, so login can't be granted to two different organizations.

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraAuthClerk } from '@mastra/auth-clerk'

export const mastra = new Mastra({
  server: {
    auth: new MastraAuthClerk({
      jwksUri: process.env.CLERK_JWKS_URI,
      publishableKey: process.env.CLERK_PUBLISHABLE_KEY,
      secretKey: process.env.CLERK_SECRET_KEY,
      organizationId: process.env.CLERK_ORGANIZATION_ID,
    }),
  },
})
```

## 使用者身分 {/* #user-id */}

經過身份驗證的用戶的`id` is the token's `id` claim, or its `sub` claim when the token has no `id`. RBAC looks up roles by this `id`，並且它擁有用戶創建的記錄，除非`mapUserToResourceId`已設定。看[來自 JWT Provider的用戶 ID](/docs/guides/authentication-identity#user-ids-from-jwt-providers).
