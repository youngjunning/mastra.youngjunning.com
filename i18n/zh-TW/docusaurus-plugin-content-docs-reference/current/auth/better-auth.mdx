# MastraAuthBetterAuth 類

這`MastraAuthBetterAuth`類別使用 Better Auth 為 Mastra 應用程式提供身份驗證。它使用 Better Auth 會話驗證傳入請求，並使用`auth`選項。

## 使用範例 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraAuthBetterAuth } from '@mastra/auth-better-auth'
import { betterAuth } from 'better-auth'

// Create your Better Auth instance
const auth = betterAuth({
  database: {
    provider: 'postgresql',
    url: process.env.DATABASE_URL,
  },
  emailAndPassword: {
    enabled: true,
  },
  baseURL: process.env.BETTER_AUTH_URL,
  secret: process.env.BETTER_AUTH_SECRET,
})

export const mastra = new Mastra({
  server: {
    auth: new MastraAuthBetterAuth({
      auth,
    }),
  },
})
```

## `BetterAuthUser`類型 {/* #betterauthuser-type */}

這`BetterAuthUser` type contains the session and user information returned by Better Auth:

```typescript
interface BetterAuthUser {
  session: Session & { activeOrganizationId?: string | null }
  user: User
}
```

* `session`：包含會話元資料的 Better Auth 會話物件。`activeOrganizationId` comes from the organization plugin. The provider registers that plugin only on the instance it builds itself. When you pass `auth`, add the plugin to that instance if you use organization features.
* `user`：經過身份驗證的用戶對象，包含用戶詳細信息

這`Session` and `User` types are exported by the Better Auth package.

## 匹配規則 {/* #matching-rules */}

* `public`和`protected` accept exact paths, wildcard patterns (like `/api/*`), and path params (like `/users/:id`).
* 對於特定方法的規則，請使用元組，例如`["/api/agents", ["GET", "POST"]]`.
* 如果一條路線與兩者都匹配`public` and `protected`, `public` wins and no auth is required, unless the route is marked `requiresAuth: true`. Those routes still authenticate.
* 如果兩者都不匹配，則路由在以下情況下需要身份驗證`/api/*` (the built-in default `protected` pattern) or is a custom route registered with `registerApiRoute()` that isn't marked `requiresAuth: false`, and other paths don't require auth.
