# 發展

一旦您有了 Mastra 項目，您就可以開發、運行和測試您的Agent程式了。

## 在本地運行 Mastra {/* #run-mastra-locally */}

查看Agent工作的最快方式是[Mastra Studio](/docs/studio/overview). From your project root, start Studio and the local development server with [`mastra dev`](/reference/cli/mastra#mastra-dev):

```bash npm2yarn
npx mastra dev
```

開放工作室於[`http://localhost:4111`](http://localhost:4111) to test your agent and inspect its runs.

開發伺服器還為您的Agent、Tool和Workflow公開 API。打開[`http://localhost:4111/api`](http://localhost:4111/api) to browse what's available, then connect your frontend using the [Mastra Client](/docs/server/mastra-client).

你的變化`src/mastra/` directory automatically restart the development server, so you don't need to restart it manually as you build.

## 用人工智慧構建 {/* #build-with-ai */}

Mastra 提供了一項技能和 CLI 來幫助您的編碼Agent編寫高品質的 Mastra 程式碼。

### 馬斯特拉技能 {/* #mastra-skills */}

AI 模型可能不具備 Mastra API 的最新知識。使用[Mastra skills](https://github.com/mastra-ai/skills) to give your coding agent implementation guidance and best practices, including instructions for fetching the latest Mastra documentation. Your coding agent will also be able to interact with [Mastra Factory](https://factory.mastra.ai).

手動安裝技能：

```bash npm2yarn
npx skills add mastra-ai/skills
```

定期更新技能以獲得最新指導：

```bash npm2yarn
npx skills update mastra
```



當您建立專案時[create mastra](/docs), the command automatically installs the Mastra skills so your coding agent can discover and use them.

:::

### 馬斯特拉 CLI {/* #mastra-cli */}

使用[`mastra` CLI](/reference/cli/mastra) to give your coding agent a feedback loop for testing updates and inspecting results. The CLI gives it access to agents, workflows, tools, memory, evals, traces, and logs.

例如，您的編碼Agent可以運行Agent，然後提取追蹤來檢查結果：

```bash
npx mastra api --url http://localhost:4111 agent run agent '{"messages":"Hello"}'
npx mastra api --url http://localhost:4111 trace list
```

記得安裝[Mastra skills](#mastra-skills) to teach your coding agent how to use the CLI.

## 專案結構 {/* #project-structure */}

採用框架時的首要決定之一是如何建立專案。我們建議將框架程式碼保留在`src/mastra/`, with related primitives grouped into their own files or folders. Use `src/mastra/index.ts` as the central place to configure and register them.

一個最小的項目可以如下所示：

```text
src/
  mastra/
    agents/
      agent.ts
    tools/
      tool.ts
    workflows/
      workflow.ts
    scorers/
      scorer.ts
    skills.ts
    index.ts
```

請參閱[project structure reference](/reference/project-structure) for the default layout and recommended conventions.

## 基於文件的Agent {/* #file-based-agents */}



基於文件的發現僅貫穿`mastra dev` or `mastra build`. If your app imports `mastra` directly, including through a web framework or server adapter, file-based agents aren't discovered. Register those agents in code or run Mastra as a separate server.

:::

:::提示\[📹觀看]

[如何創建您的第一個基於文件的Agent](https://www.youtube.com/watch?v=5Kfn-oYkJNg\&t=18s)

:::

透過基於檔案的Agent，Mastra 自動[discovers](/reference/file-based-agents/config#discovery-lifecycle) agents and related primitives from supported files under `src/mastra/`. You organize those files by convention instead of importing and registering each primitive on your [`Mastra`](/reference/core/mastra-class) instance.

檔案系統成為專案結構的直接表示，因此您和您的編碼Agent可以了解專案如何組合在一起，而無需追蹤所有內容如何在程式碼中連接在一起。

您可以在整個專案中使用基於文件的Agent，或與程式碼中定義的原語一起逐步採用它們。尚未支援所有 Mastra 功能或用例。

### 建立您的第一個Agent {/* #create-your-first-agent */}

基於檔案的Agent位於其自己的目錄中`src/mastra/agents/`. To create a working agent, add a `config.ts` file for its model and runtime options and an `instructions.md` file for its always-on prompt:

```text
src/mastra/agents/
  writing-assistant/
    config.ts
    instructions.md
```

目錄名稱成為Agent程式的預設名稱`id` and `name`. In this example, Mastra registers the agent as `writing-assistant`.

```typescript title="src/mastra/agents/writing-assistant/config.ts"
import { agentConfig } from '@mastra/core/agent'

export default agentConfig({
  model: '__GATEWAY_OPENAI_MODEL__',
})
```

```markdown title="src/mastra/agents/writing-assistant/instructions.md"
Rewrite text clearly and concisely.
```

跑步`npx mastra dev`, open Studio, and select `writing-assistant` to test it.

### 發現如何運作 {/* #how-discovery-works */}

Mastra 使用路徑來發現和命名基於檔案的功能。Agent目錄提供預設Agent`id` and `name`. For example, `tools/search_docs.ts` registers a tool as `search_docs`, while `skills/style-guide.md` registers a skill as `style-guide`. See the extension paths below.

### 延長您的Agent {/* #extend-your-agent */}

當您的Agent需要更多功能時新增檔案或目錄：

|路徑|新增了什麼 |
| - | - |
|[`tools/<tool-name>.ts`](/reference/file-based-agents/tools) | Functions the model can call |
| [`skills/<skill-name>.md`](/reference/file-based-agents/skills) | Detailed guidance the agent loads when relevant |
| [`memory.ts`](/reference/file-based-agents/memory) | Conversation history and working context |
| [`workspace.ts` and `workspace/`](/reference/file-based-agents/workspace) | Filesystem and shell access |
| [`subagents/<agent-id>/`](/reference/file-based-agents/subagents) | Specialist agents that the parent can delegate to |

將每個功能放在使用它的Agent旁邊。當開發伺服器啟動或重新啟動時，Mastra 會發現並註冊這些檔案。

瀏覽[file-based agents reference](/reference/file-based-agents/config) for all supported file conventions and configuration options.
