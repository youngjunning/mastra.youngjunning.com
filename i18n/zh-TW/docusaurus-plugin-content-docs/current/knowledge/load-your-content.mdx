# 載入自有內容

Agent 在工作時會將內容寫入 Knowledge。有些內容通常需要事先放好，例如產品文件或公司政策。你可以在自己的伺服器程式碼中使用 [`upsertPage()`](/reference/knowledge/knowledge-class#upsertpage) 與 [`addNote()`](/reference/knowledge/knowledge-class#addnote)，寫入初始內容。

Knowledge 目前尚未提供匯入工具。規劃中的匯入工具可讓 Knowledge 與你的其他系統保持同步。在此之前，請依照下方範例，從伺服器程式碼寫入初始內容。

:::alpha

Knowledge 目前處於 Alpha 階段，API 可能隨版本變動。

:::

## 宣告內容的範圍 {/* #declare-a-scope-for-the-content */}

為初始內容指定專用的範圍類型，並定義哪些對象可以讀取：

```typescript title="src/mastra/knowledge.ts"
import { Knowledge, knowledgeMemoryScopes } from '@mastra/core/knowledge'
import { LibSQLStore } from '@mastra/libsql'

export const knowledge = new Knowledge({
  id: 'company',
  storage: new LibSQLStore({ id: 'knowledge', url: 'file:./knowledge.db' }),
  scopes: {
    ...knowledgeMemoryScopes(),
    'docs:$orgId': {
      description: 'Product docs',
      belongsTo: 'org:$orgId',
      access: [{ principal: 'org:$orgId', role: 'viewer' }],
    },
  },
  tools: true,
})
```

`belongsTo` 會將文件放在範圍樹狀結構中的組織下。組織內的 Agent 可以讀取這些頁面，但無法修改。

## 寫入頁面 {/* #write-the-pages */}

將每份文件寫到該範圍中的一個路徑。例如，路徑 `guides/install` 會對應到頁面 `docs:acme#guides/install`，沿途缺少的頁面也會一併建立：

```typescript title="src/seed-docs.ts"
import { knowledge } from './mastra/knowledge'

type Doc = { slug: string; title: string; markdown: string }

export async function seedDocs(orgId: string, docs: Doc[]) {
  for (const doc of docs) {
    await knowledge.upsertPage({
      scope: `docs:${orgId}`,
      path: doc.slug,
      name: doc.title,
      body: doc.markdown,
      author: 'seed:docs',
    })
  }
}
```

執行時持有 `org:acme` 範圍的 Agent 現在可以搜尋並讀取這些頁面。若已設定 `vector` 與 `embedder`，`upsertPage()` 也會為各頁面產生嵌入向量，以支援[語意搜尋](/docs/knowledge/search#add-search-by-meaning)。

若要為頁面補上帶日期的事實或評論，可新增一則筆記。當目標頁面存在時，`[[docs:acme#releases/2026-12]]` 這個引用就會轉為連結：

```typescript title="src/seed-docs.ts"
await knowledge.addNote({
  scope: 'docs:acme',
  path: 'guides/install',
  text: 'Node 18 support ends on [[docs:acme#releases/2026-12]].',
  when: new Date('2026-11-01'),
  author: 'seed:docs',
})
```

這些方法供受信任的伺服器程式碼使用。它們不會檢查執行的範圍或存取規則，因此請勿從 Agent Tool 或沒有管理員層級驗證的路由呼叫。

## 讓內容保持同步 {/* #keep-content-in-sync */}

來源內容變動時，請重新執行初始化程式。`upsertPage()` 會更新有變動的頁面，略過未變動的頁面，因此重跑時不會重寫後者，也不會重新產生嵌入向量。

每次呼叫 `addNote()` 都會新增一則筆記，執行兩次初始化程式就會留下重複筆記。請只新增一次，或使用 [`updateNote()`](/reference/knowledge/knowledge-class#updatenote) 修改既有筆記。

從來源刪除的文件仍會留在 Knowledge 中，可用 [`removePage()`](/reference/knowledge/knowledge-class#removepage) 移除。如果頁面有子頁面，必須先移除子頁面。

## 後續步驟 {/* #next-steps */}

接著，[在 Studio 中開啟 Knowledge](/docs/studio/knowledge)，檢查載入的內容。如需完整的伺服器端寫入方法，請參閱 [`upsertPage()`](/reference/knowledge/knowledge-class#upsertpage) 及後續的方法說明。
