# 搜尋

Agent 透過 `knowledge_search` 尋找頁面，預設會比對關鍵字。本頁說明關鍵字搜尋如何找到頁面，以及如何加入語意搜尋。

:::alpha

Knowledge 目前處於 Alpha 階段，API 可能隨版本變更。

:::

## 搜尋如何找到頁面 {/* #how-search-finds-pages */}

`knowledge_search` 會將查詢中的詞彙與頁面名稱、說明、正文及筆記文字比對。頁面符合的查詢詞越多，排名越高。名稱中的詞彙權重高於說明，說明又高於正文。頁面排在筆記之前。

把使用者會搜尋的詞彙放在頁面名稱與說明中，就能讓頁面更容易被找到。完整排序規則請參閱 [`knowledge_search`](/reference/knowledge/knowledge-tools#knowledge_search)。

搜尋結果只會包含本次執行有權讀取的內容。

使用 `MongoDBStore` 時，如果執行可讀取許多範圍，請傳入 `scope`，以維持搜尋速度。省略 `scope` 時，搜尋會先收集本次執行能讀取的所有範圍，因此範圍越多，搜尋就越慢。

## 加入語意搜尋 {/* #add-search-by-meaning */}

傳入 `vector` 向量儲存與 `embedder` 後，除了比對關鍵字，也能依語意搜尋頁面和筆記。例如，搜尋「核銷」時，即使頁面只說明如何拿回代墊的款項，也能找到它。

```typescript title="src/mastra/knowledge.ts"
import { Knowledge, knowledgeMemoryScopes } from '@mastra/core/knowledge'
import { ModelRouterEmbeddingModel } from '@mastra/core/llm'
import { LibSQLStore, LibSQLVector } from '@mastra/libsql'

export const knowledge = new Knowledge({
  id: 'company',
  storage: new LibSQLStore({ id: 'knowledge', url: 'file:./knowledge.db' }),
  vector: new LibSQLVector({ id: 'knowledge-vector', url: 'file:./knowledge.db' }),
  embedder: new ModelRouterEmbeddingModel('__GATEWAY_OPENAI_EMBEDDING_MODEL__'),
  scopes: { ...knowledgeMemoryScopes() },
  tools: true,
})
```

這兩個參數要同時傳入或同時省略。[`embedderOptions`](/reference/knowledge/knowledge-class#constructor-options) 的用法與 Memory 相同。

`knowledge_search` 會依排名合併關鍵字與語意搜尋結果，因此語意相近的結果可能排在名稱相符的結果前面。每筆語意結果都會先依照本次執行的權限重新讀取。無法讀取的結果會被捨棄，不占名額。與 Alpha 階段的其他存取檢查相同，此機制無法保證形成[隔離邊界](/docs/knowledge/scopes-and-access)。搜尋最多檢查 1,000 筆語意候選結果，因此前面的相近結果多半無法讀取時，可能會漏掉後面可讀的結果。

寫入頁面或筆記時會產生嵌入向量。範圍頁面本身不會產生向量，但附加在上面的筆記會。長頁面會分段產生向量，搜尋結果仍只會列出同一頁面一次。大小限制請參閱[限制](/reference/knowledge/limits)。

Knowledge 不會為既有內容補建向量。在加入 `vector` 與 `embedder` 前寫入的頁面和筆記，要等內容變更後才可透過語意搜尋找到。

儲存中已有嵌入向量時，請避免更換嵌入模型。Knowledge 目前無法重新產生這些向量。

- **維度不同**。搜尋會改用新的索引，既有內容在變更前只能透過關鍵字找到。
- **維度相同**。搜尋會沿用舊向量，並與新模型產生的查詢向量比較。各頁面在變更前的比對效果會較差。

### 向量嵌入失敗時 {/* #when-embedding-fails */}

寫入頁面或筆記時，若產生或寫入向量失敗，Knowledge 會在約半秒、2 秒和 7.5 秒後重試。如此可因應資料庫縮減至零後需要幾秒喚醒的情況。若供應商將錯誤標示為不可重試，例如 API 金鑰無效，Knowledge 就不會重試。

如果每次嘗試都失敗，頁面或筆記仍會成功寫入，Mastra 會記錄警告。新增的內容只能透過關鍵字找到。更新過的內容則保留舊向量，因此語意搜尋仍會比對舊內容。兩種情況都會持續到下次寫入時有內容變更。若呼叫 `upsertPage()` 傳回 `unchanged`，便不會寫入資料，也不會為頁面產生向量。

如果搜尋期間嵌入模型或向量儲存發生錯誤，搜尋會傳回關鍵字結果並記錄警告。
