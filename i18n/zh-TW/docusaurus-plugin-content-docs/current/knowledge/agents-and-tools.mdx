# Agent 與工具

Agent 有兩種方式可使用 Knowledge。它可以視需要呼叫工具，搜尋、讀取及寫入頁面。也可以使用[釘選的上下文](/docs/knowledge/pinned-context)，讓選定的頁面出現在每一輪的上下文中，不必呼叫工具。本頁說明工具的用法。你可選擇要提供哪些工具給 Agent；每次呼叫允許執行的操作則由[範圍宣告](/docs/knowledge/scopes-and-access)決定。

:::alpha

Knowledge 目前處於 Alpha 階段，API 可能隨版本變動。

:::

## 啟用工具 {/* #turn-on-the-tools */}

讀取工具可讓 Agent 瀏覽、搜尋和讀取頁面。寫入工具可用來新增及修改頁面與筆記。各項工具的說明請見 [Knowledge 工具參考文件](/reference/knowledge/knowledge-tools)。

工具預設未啟用。設定 `tools: true` 即可啟用讀取與寫入工具：

```typescript title="src/mastra/knowledge.ts"
import { Knowledge, knowledgeMemoryScopes } from '@mastra/core/knowledge'

export const knowledge = new Knowledge({
  id: 'company',
  scopes: knowledgeMemoryScopes(),
  tools: true,
})
```

只根據 Knowledge 回答的 Agent（例如文件問答 Agent）只需要讀取工具：

```typescript
const knowledge = new Knowledge({
  id: 'docs',
  scopes: knowledgeMemoryScopes(),
  tools: { read: true },
})
```

釘選上下文時會提供釘選工具。請按照[釘選的上下文](/docs/knowledge/pinned-context)中的說明，設定 `pinnedContext: true` 來啟用工具。

## 將工具提供給 Agent {/* #attach-the-tools-to-an-agent */}

將 Knowledge 執行個體傳入 Agent 的 `knowledge` 選項。Agent 會取得已啟用的工具和簡短的使用說明，不必在你撰寫的指示中再說明這些工具：

```typescript title="src/mastra/agents/support-agent.ts"
import { Agent } from '@mastra/core/agent'
import { knowledge } from '../knowledge'

export const supportAgent = new Agent({
  id: 'support-agent',
  name: 'Support agent',
  instructions: 'Help customers with their orders.',
  model: '__GATEWAY_OPENAI_MODEL__',
  knowledge,
})
```

若要修改這些說明，請見[工具指示](/reference/knowledge/tool-instructions)。

### 手動加入工具 {/* #add-the-tools-yourself */}

你也可以將 Knowledge 工具和其他工具一起加到 Agent 的 `tools`。呼叫 [`createTools()`](/reference/knowledge/knowledge-class#createtools) 建立工具，再以 [`getInstructions()`](/reference/knowledge/knowledge-class#getinstructions) 取得使用說明，兩者都傳入相同的選項：

```typescript title="src/mastra/agents/docs-agent.ts"
import { Agent } from '@mastra/core/agent'
import { knowledge } from '../knowledge'

export const docsAgent = new Agent({
  id: 'docs-agent',
  name: 'Docs agent',
  instructions: `Answer from the company docs.\n\n${knowledge.getInstructions({ write: false, pinnedContext: false })}`,
  model: '__GATEWAY_OPENAI_MODEL__',
  tools: {
    ...knowledge.createTools({ write: false, pinnedContext: false }),
  },
})
```

這些選項會針對這個 Agent 覆寫執行個體的設定。此處以 `{ write: false, pinnedContext: false }` 讓 Agent 只取得讀取工具。如果省略 `pinnedContext: false`，且執行個體已啟用釘選上下文，Agent 也會取得 `knowledge_pin`。有無釘選工具都採用相同的存取檢查。

## 讀取頁面 {/* #read-pages */}

Agent 可使用讀取工具執行下列操作：

- 瀏覽範圍的組織結構。
- 依關鍵字搜尋頁面和筆記；[加入語意搜尋](/docs/knowledge/search#add-search-by-meaning)後也能依語意搜尋。
- 讀取頁面及其筆記，以及其他頁面上提及該頁的筆記。

長頁面會分段回傳。第一次讀取時會顯示頁面中的各層標題。Agent 可接著讀取需要的段落、從某一行繼續，或只讀取符合搜尋詞的行。

若找不到符合的內容，結果會明確指出。Agent 因此可以直接告訴使用者自己不知道答案，避免猜測。

預設每次讀取最多回傳頁面中的 1,000 個 token。對上下文視窗較大的模型，可以提高上限；對小型模型，則可以降低上限：

```typescript
const knowledge = new Knowledge({
  id: 'docs',
  scopes: knowledgeMemoryScopes(),
  tools: { read: { maxTokens: 3000 }, write: true },
})
```

## 寫入頁面 {/* #write-pages */}

Agent 可使用寫入工具執行下列操作：

- 新增、編輯、移動、合併或刪除頁面。
- 新增或移除筆記。筆記在頁面上記錄簡短的事實，並標示作者。筆記可以連結到其他頁面，誰能看到筆記則由其[標記](/docs/knowledge/scopes-and-access#note-visibility)決定。

Agent 會依頁面的讀者選擇範圍。供整個團隊使用的事實放在團隊範圍；單一使用者的事實放在該使用者的 `resource:` 範圍。

在長頁面中，Agent 只能編輯已讀取的行，因此不會覆寫沒讀過的部分。如果有人在 Agent 讀完這些行之後修改頁面，系統會拒絕這次編輯。

## 存取檢查 {/* #access-checks */}

啟用工具不會授予存取權限。Agent 只能使用這次執行本身持有的範圍，及依規則取得角色的範圍。其他範圍對 Agent 不可見。

Knowledge 會依當次執行在所涉範圍中的角色，檢查每一次工具呼叫。各角色可執行的操作請見[角色權限表](/docs/knowledge/scopes-and-access#access-rules-and-roles)。

呼叫遭拒時，程式碼不會擲出錯誤。模型會在工具結果中收到拒絕訊息，並可據此回應。
