# Workflow 執行器

Mastra 的 [Workflow](/docs/workflows/overview) 可以透過內建執行器執行，也可以部署至專用平台，由平台協調、監控並確保執行的可靠性。

## Inngest {/* #inngest */}

Inngest 是供開發者執行背景 Workflow 的平台，開發者無須自行管理基礎設施。將 Mastra Workflow 部署至 Inngest，即可重用已完成步驟的結果，並在失敗時自動重試。Inngest 也支援即時監控、暫停及恢復執行。

請參閱 [Inngest 部署指南](/integrations/deploy/inngest) 取得設定步驟，並參考 [Inngest Workflow 範例](https://github.com/mastra-ai/mastra/tree/main/examples/inngest) 查看完整實作。

## Temporal {/* #temporal */}

Temporal 是可協調長時間執行的 Workflow 的持久執行平台。Mastra Workflow 可以在 Temporal Worker 上執行。每個以 `createStep` 定義的步驟都會對應至一個 Temporal Activity，支援自動重試並持久保存狀態。

`@mastra/temporal` 套件仍處於實驗階段，尚不適合用於正式環境。設定步驟請參閱 [Temporal 部署指南](/integrations/deploy/temporal)。
