# 網頁框架

當 Mastra 與 Web 框架整合時，它會使用框架的標準部署流程與您的應用程式一起部署。請按照以下說明操作，確保您的 Mastra 整合正確部署。

:::警告
如果您要部署到雲端Provider，請勿使用[LibSQLStore](/integrations/databases/libsql) with a local `file:`或記憶體資料庫。本機資料庫需要檔案系統存取權限，並且與無伺服器平台不相容。將 LibSQLStore 指向遠端資料庫，例如 Turso。
:::

整合指南：

* [使用 Next.js](/integrations/frameworks/next-js)
* [與阿斯特羅](/integrations/frameworks/astro)

## 在 Vercel 上使用 Next.js {/* #with-nextjs-on-vercel */}

如果您已將 Mastra 與 Next.js 整合並計劃部署到 Vercel，請確保您的`next.config.ts` sets `serverExternalPackages: ["@mastra/*"]`. The [Next.js guide](/integrations/frameworks/next-js) adds it during setup. If your config doesn't have it, add it:

```typescript {4} title="next.config.ts"
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  serverExternalPackages: ['@mastra/*'],
}

export default nextConfig
```

## 與 Vercel 上的 Astro 一起 {/* #with-astro-on-vercel */}

如果您已將 Mastra 與 Astro 集成[by following our guide](/integrations/frameworks/astro) and plan to deploy to Vercel, add the Vercel adapter and server output to your `astro.config.mjs`:

```javascript {2,5-6} title="astro.config.mjs"
import { defineConfig } from 'astro/config'
import vercel from '@astrojs/vercel'

export default defineConfig({
  adapter: vercel(),
  output: 'server',
})
```

## 與 Netlify 上的 Astro 一起 {/* #with-astro-on-netlify */}

如果您已將 Mastra 與 Astro 集成[by following our guide](/integrations/frameworks/astro) and plan to deploy to Netlify, add the Netlify adapter and server output to your `astro.config.mjs`:

```javascript {2,5-6} title="astro.config.mjs"
import { defineConfig } from 'astro/config'
import netlify from '@astrojs/netlify'

export default defineConfig({
  adapter: netlify(),
  output: 'server',
})
```
