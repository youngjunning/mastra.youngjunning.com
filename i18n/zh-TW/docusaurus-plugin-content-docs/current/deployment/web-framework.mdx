# Web 框架

將 Mastra 整合到 Web 框架後，請沿用該框架的標準流程，將 Mastra 和應用程式一併部署。依下列說明設定，即可正確部署整合後的 Mastra。

:::warning
部署至雲端服務時，請勿讓 [LibSQLStore](/integrations/databases/libsql) 使用本機 `file:` 資料庫或記憶體內資料庫。本機資料庫需要存取檔案系統，與無伺服器平台不相容。請將 LibSQLStore 指向 Turso 等遠端資料庫。
:::

整合指南：

- [整合 Next.js](/integrations/frameworks/next-js)
- [整合 Astro](/integrations/frameworks/astro)

## 將 Next.js 部署至 Vercel {/* #with-nextjs-on-vercel */}

如果已將 Mastra 整合到 Next.js，並預計部署至 Vercel，請確認 `next.config.ts` 已設定 `serverExternalPackages: ["@mastra/*"]`。[Next.js 指南](/integrations/frameworks/next-js)已將此項列入設定步驟。若目前的設定缺少這一項，請補上：

```typescript {4} title="next.config.ts"
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  serverExternalPackages: ['@mastra/*'],
}

export default nextConfig
```

## 將 Astro 部署至 Vercel {/* #with-astro-on-vercel */}

如果已依照[整合指南](/integrations/frameworks/astro)將 Mastra 整合到 Astro，並預計部署至 Vercel，請在 `astro.config.mjs` 加入 Vercel 配接器，並設定伺服器輸出：

```javascript {2,5-6} title="astro.config.mjs"
import { defineConfig } from 'astro/config'
import vercel from '@astrojs/vercel'

export default defineConfig({
  adapter: vercel(),
  output: 'server',
})
```

## 將 Astro 部署至 Netlify {/* #with-astro-on-netlify */}

如果已依照[整合指南](/integrations/frameworks/astro)將 Mastra 整合到 Astro，並預計部署至 Netlify，請在 `astro.config.mjs` 加入 Netlify 配接器，並設定伺服器輸出：

```javascript {2,5-6} title="astro.config.mjs"
import { defineConfig } from 'astro/config'
import netlify from '@astrojs/netlify'

export default defineConfig({
  adapter: netlify(),
  output: 'server',
})
```
