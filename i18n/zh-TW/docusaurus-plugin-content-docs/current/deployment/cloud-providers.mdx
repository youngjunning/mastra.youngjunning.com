# 雲端服務供應商

你可以將 Mastra 應用程式部署到雲端服務供應商或無伺服器平台。Mastra 內建適用於 Vercel、Netlify 和 Cloudflare 的部署工具，你可以選擇使用這些工具將部署流程自動化。

## Mastra 平台 {/* #mastra-platform */}

Mastra 平台可將你的伺服器部署到雲端。詳細資訊請參閱 [Mastra 平台部署指南](/docs/mastra-platform/overview)。
