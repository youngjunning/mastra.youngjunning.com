# 雲端Provider

Mastra 應用程式可以部署到雲端Provider和無伺服器平台。 Mastra 包括適用於 Vercel、Netlify 和 Cloudflare 的可選內建部署程序，用於自動化部署流程。

## 馬斯特拉平台 {/* #mastra-platform */}

Mastra 提供了一个将服务器部署到云的平台。閱讀[Mastra platform deployment guide](/docs/mastra-platform/overview) to learn more.
