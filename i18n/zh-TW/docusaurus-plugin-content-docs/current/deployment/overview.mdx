# 部署

Mastra 應用程式可以部署到任何 Node.js 相容環境。您可以部署 Mastra 伺服器或與現有 Web 框架整合。其他選項包括雲端Provider和[Mastra platform](/docs/mastra-platform/overview)用於可觀察性、Studio 和伺服器部署。

## 運行時支援 {/* #runtime-support */}

Mastra 可以在以下任何執行時間環境中運作：

* Node.js`v22.13.0` or later
* 包子
* 德諾
* 雲耀

## 部署選項 {/* #deployment-options */}

### 馬斯特拉伺服器 {/* #mastra-server */}

馬斯特拉提供了[server](/docs/server/overview) powered by Hono that can be deployed independently. Use the `mastra build` command to build your application and deploy the output to your preferred VM, container, or PaaS platform.

當您需要完全控制基礎架構、長時間運行的進程或 WebSocket 連線時，請使用此選項。這[Mastra server deployment guide](/docs/deployment/mastra-server) provides more details.

### {/* #monorepo */}

將 Mastra 伺服器部署為 monorepo 設定的一部分，遵循與獨立部署相同的方法。

閱讀有關[monorepo deployment](/docs/deployment/monorepo).

### 馬斯特拉平台 {/* #mastra-platform */}

這[Mastra platform](/docs/mastra-platform/overview) provides three products for deploying, monitoring, and managing AI applications built with the Mastra framework:

* [**可觀察性**](/docs/mastra-platform/observability)：一個獨立的託管產品，用於跨 Mastra 專案和部署的可搜尋追蹤、日誌和指標
* [**工作室**](/docs/mastra-platform/studio)：用於測試Agent程式和運行Workflow以及檢查追蹤的託管可視環境
* [**伺服器**](/docs/mastra-platform/server)

了解更多信息[Mastra platform overview](/docs/mastra-platform/overview).

### 雲端Provider {/* #cloud-providers */}

Mastra 應用程式可以部署到雲端Provider和無伺服器平台。 Mastra 包括適用於 Vercel、Netlify 和 Cloudflare 的可選內建部署程序，可為每個平台建立應用程式。然後，您可以透過平臺本身部署建置輸出。

使用此選項進行自動擴展、最小化基礎架構管理，或當您已經在使用這些平台之一時。

### Sandbox {/* #sandbox */}

將 Mastra 伺服器部署到臨時Workspace沙箱（例如 Vercel Sandbox 或 E2B）中，並在幾秒鐘內獲得即時公共 URL。

使用此選項進行即時預覽、從 CI 管道部署、驗證Agent程式建置的應用程式或執行不受信任的每個使用者實例。閱讀[sandbox deployment guide](/docs/deployment/sandbox).

### 網路框架 {/* #web-framework */}

當 Mastra 與 Web 框架整合時，它會使用框架的標準部署流程與您的應用程式一起部署。以下指南涵蓋了特定於框架的部署配置要求。

將 Mastra 新增至現有 Next.js 或 Astro 應用程式時，請使用這些指南。

* [在 Vercel 上使用 Next.js](/docs/deployment/web-framework#with-nextjs-on-vercel)
* [與 Vercel 上的 Astro 一起](/docs/deployment/web-framework#with-astro-on-vercel)
* [與 Netlify 上的 Astro 一起](/docs/deployment/web-framework#with-astro-on-netlify)

## Workflow運行器 {/* #workflow-runners */}

預設情況下，Mastra Workflow使用內建執行引擎運作。對於需要託管基礎架構的生產工作負載，也可以將Workflow部署到專用平台，例如[Inngest](https://www.inngest.com) that provide step memoization and automatic retries, with real-time monitoring.

參觀[Workflow Runners guide](/docs/deployment/workflow-runners) for execution options and the [Inngest deployment guide](/integrations/deploy/inngest) for setup instructions.

## 勞工 {/* #workers */}

對於生產部署，Mastra 可以運行Workflow編排和 cron 調度，以及在與 API 伺服器分開的專用工作進程中執行後台Tool。這使您可以獨立擴展每個問題並隔離故障。看[Workers](/docs/deployment/workers) for details.
