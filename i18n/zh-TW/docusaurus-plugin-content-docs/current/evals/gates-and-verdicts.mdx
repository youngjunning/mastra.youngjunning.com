# 大門和判決

門和判決添加了嚴重性語義`runEvals`。蓋茲是必須得分為 1.0 的得分手，這是阻止跑動的硬性要求。閾值是追蹤指標的平均分數的下限和/或上限。判決將結果歸納為`passed`, `scored`， 或者`failed`.

## 何時使用門和判決 {/* #when-to-use-gates-and-verdicts */}

* 在 CI 中強制執行硬性要求（例如，「Agent必須呼叫正確的Tool」）
* 追蹤具有最小閾值的品質指標（例如，「忠實度高於 0.7」）
* 取得單一判決訊號（`passed`, `scored`, or `failed`) from an eval run without writing custom assertion logic
* 將「必須通過」的關卡與「最好有」的追蹤指標分開

## 快速入門 {/* #quickstart */}

```typescript title="src/evals/weather-eval.ts"
import { runEvals } from '@mastra/core/evals'
import { checks } from '@mastra/evals/checks'
import { weatherAgent } from '../agents'
import { faithfulnessScorer } from '../scorers'

const result = await runEvals({
  data: [{ input: 'What is the weather in Brooklyn?' }],
  target: weatherAgent,

  // Gates: must all score 1.0 or the run fails
  gates: [checks.calledTool('get_weather'), checks.noToolErrors()],

  // Scorers: tracked with optional thresholds
  scorers: [
    { scorer: faithfulnessScorer, threshold: 0.7 },
    checks.includes('Brooklyn'), // no threshold = tracked only
  ],
})

console.log(result.verdict) // 'passed' | 'scored' | 'failed'
```

## 判決如何運作 {/* #how-verdicts-work */}

處理所有資料項後，根據閘和閾值計算判決：

* `failed`：至少有一個閘的資料項平均值低於 1.0
* `scored`：所有門都通過了，但至少有一個閾值得分者未達到閾值
* `passed`：所有門得分為 1.0，並且滿足所有閾值

當沒有提供閘或閾值計分器時，以及當每個配置的閘和閾值都返回時，判決欄位將被省略`notScorable()` (no numeric evidence). In those cases `runEvals` still returns `scores` and `summary`.

## 蓋茲 {/* #gates */}

門是得分者通過`gates` field. They run before regular scorers on each data item. A gate must average a score of 1.0 across the data items it could score to pass. Items where the gate returns `notScorable()` are excluded from the average, and a gate that throws an error counts as 0 for that item.

```typescript title="src/evals/tool-gate.ts"
import { runEvals } from '@mastra/core/evals'
import { checks } from '@mastra/evals/checks'

const result = await runEvals({
  data: [{ input: 'What is the weather?' }],
  target: weatherAgent,
  gates: [checks.calledTool('get_weather')],
  scorers: [qualityScorer],
})

// result.gateResults: [{ id: 'check-called-tool', passed: true, score: 1 }]
```

任何得分手都充當大門。快速檢查非常適合，因為它們會傳回二進位 1/0 分數。訪問[runEvals() reference](/reference/evals/run-evals) for the full parameter and return type documentation.

### 僅登機口運行 {/* #gate-only-runs */}

`scorers`當至少提供一個門時，該門是可選的。這對於確定性 CI 檢查非常有用，您只關心通過/失敗門，不需要追蹤任何品質指標。

```typescript title="src/evals/gate-only.ts"
import { runEvals } from '@mastra/core/evals'
import { checks } from '@mastra/evals/checks'

const result = await runEvals({
  data: [{ input: 'What is the weather in Brooklyn?' }],
  target: weatherAgent,
  gates: [checks.calledTool('get_weather'), checks.noToolErrors()],
})
```

您必須提供至少一名得分手或門將，兩者都沒有的跑動不會引發錯誤。

## 閾值 {/* #thresholds */}

`{ scorer, threshold }` to set pass/fail bounds. The threshold is compared against the scorer's average score across scored data items. Results that return `notScorable()` are left out of the average.

一個`threshold` can be:

* **一個數字**：表示最低分數（等於或高於及格分數）：`{ scorer, threshold: 0.7 }`
* **一個對象與`min` and/or `max`**：對於基於範圍的檢查：`{ scorer, threshold: { max: 0.3 } }`

使用`max` for scorers where a high score is bad (e.g., hallucination, toxicity). Use `{ min, max }` when the score should fall within a specific band.

```typescript title="src/evals/threshold-example.ts"
import { runEvals } from '@mastra/core/evals'

const result = await runEvals({
  data: [{ input: 'Explain quantum computing' }],
  target: myAgent,
  scorers: [
    { scorer: faithfulnessScorer, threshold: 0.7 }, // min threshold (number shorthand)
    { scorer: hallucinationScorer, threshold: { max: 0.3 } }, // max threshold — high score = bad
    { scorer: verbosityScorer, threshold: { min: 0.3, max: 0.8 } }, // range threshold
    toneScorer, // bare scorer, no threshold — tracked only
  ],
})

// result.thresholdResults:
// [
//   { id: 'faithfulness', passed: true, averageScore: 0.85, threshold: 0.7 },
//   { id: 'hallucination', passed: true, averageScore: 0.1, threshold: { max: 0.3 } },
//   { id: 'verbosity', passed: false, averageScore: 0.9, threshold: { min: 0.3, max: 0.8 } },
// ]
```

裸得分手（無門檻）仍然出現在`result.scores` but doesn't affect the verdict.

## 在 CI 中使用判決 {/* #using-verdicts-in-ci */}

該判決為 CI 管道提供了一個信號：

```typescript title="src/evals/ci-check.ts"
import { runEvals } from '@mastra/core/evals'
import { checks } from '@mastra/evals/checks'

const result = await runEvals({
  data: testDataset,
  target: myAgent,
  gates: [checks.calledTool('search'), checks.noToolErrors()],
  scorers: [{ scorer: faithfulnessScorer, threshold: 0.7 }],
})

if (result.verdict === 'failed') {
  console.error(
    'Gate failures:',
    result.gateResults?.filter(g => !g.passed),
  )
  process.exit(1)
}

if (result.verdict === 'scored') {
  console.warn(
    'Threshold misses:',
    result.thresholdResults?.filter(t => !t.passed),
  )
}
```
