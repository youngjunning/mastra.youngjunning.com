# 快速檢查

快速檢查是可組合的微型評分器，用於常見的斷言，例如“輸出包含 X”或“Agent稱為Tool Y”。他們無需法學碩士即可立即運行並插入相同的`scorers: [...]`與其他得分手一樣排列。

## 何時使用快速檢查 {/* #when-to-use-quick-checks */}

當您需要快速、確定性斷言時，請使用快速檢查：

* 驗證輸出文字包含或排除特定字串
* 確認Agent呼叫（或避免）特定Tool
* 驗證Tool呼叫順序和計數限制
* 透過零成本二進位檢查控制 CI 管道
* 與基於 LLM 的評分器結合進行分層評估

對於主觀或語義評估，使用[LLM-based scorers](/docs/evals/built-in-scorers) instead.

## 快速入門 {/* #quickstart */}

```typescript title="src/evals/weather-checks.ts"
import { checks } from '@mastra/evals/checks'
import { runEvals } from '@mastra/core/evals'
import { weatherAgent } from '../agents'

const result = await runEvals({
  data: [{ input: 'What is the weather in Brooklyn?' }],
  target: weatherAgent,
  scorers: [checks.includes('Brooklyn'), checks.calledTool('get_weather'), checks.noToolErrors()],
})

console.log(result.scores)
// { 'check-includes': 1, 'check-called-tool': 1, 'check-no-tool-errors': 1 }
```

## 可用支票 {/* #available-checks */}

快速檢查分為以下幾類：

### 文字檢查 {/* #text-checks */}



|檢查 |它有什麼作用 |分數 |
| - | - | - |
|`checks.includes(str)` | Output contains substring | 1 or 0 |
| `checks.excludes(str)` | Output doesn't contain substring | 1 or 0 |
| `checks.equals(str)` | Output equals string (case-insensitive by default; pass `{ ignoreCase: false }` for an exact match) | 1 or 0 |
| `checks.matches(regex)` | Output matches regular expression | 1 or 0 |
| `checks.similarity(str)` | Dice coefficient similarity to string | 0-1 (or binary with `threshold`) |

### Tool呼叫檢查 {/* #tool-call-checks */}



|檢查 |它有什麼作用 |分數 |
| - | - | - |
|`checks.calledTool(name)` | Tool was called at least N times | 1 or 0 |
| `checks.didNotCall(name)` | Tool wasn't called | 1 or 0 |
| `checks.toolOrder([...])` | Tools called in expected order | 1 or 0 |
| `checks.maxToolCalls(n)` | No more than N tool calls total | 1 or 0 |
| `checks.usedNoTools()` | No tools called at all | 1 or 0 |
| `checks.noToolErrors()` | No tool invocations had errors | 1 or 0 |

## {/* #combining-checks-with-llm-scorers */}

檢查與基於法學碩士的評分員在一個單一的`runEvals` call. Use checks for deterministic gates and LLM scorers for qualitative evaluation:

```typescript title="src/evals/layered-eval.ts"
import { checks } from '@mastra/evals/checks'
import { createFaithfulnessScorer } from '@mastra/evals/scorers/prebuilt'
import { runEvals } from '@mastra/core/evals'
import { myAgent } from '../agents'

const result = await runEvals({
  data: [
    {
      input: 'What is the weather in Brooklyn?',
      context: ['Brooklyn weather data: sunny, 72°F'],
    },
  ],
  target: myAgent,
  scorers: [
    // Deterministic checks (instant, free)
    checks.includes('Brooklyn'),
    checks.calledTool('get_weather'),
    checks.excludes('error'),
    checks.noToolErrors(),

    // LLM-based scorer (semantic, costs tokens)
    createFaithfulnessScorer({ model: '__GATEWAY_OPENAI_MODEL_LUNA__' }),
  ],
})
```

## 在即時計分中使用檢查 {/* #using-checks-in-live-scoring */}

將檢查附加到Agent以進行持續監控：

```typescript title="src/agents/weather-agent.ts"
import { Agent } from '@mastra/core/agent'
import { checks } from '@mastra/evals/checks'

export const weatherAgent = new Agent({
  id: 'weather-agent',
  name: 'Weather Agent',
  instructions: 'Answer weather questions using the get_weather tool.',
  model: '__GATEWAY_OPENAI_MODEL__',
  tools: { get_weather: weatherTool },
  scorers: {
    noErrors: {
      scorer: checks.noToolErrors(),
      sampling: { type: 'ratio', rate: 1 },
    },
    mentionCity: {
      scorer: checks.includes('Brooklyn'),
      sampling: { type: 'ratio', rate: 0.5 },
    },
  },
})
```

## {/* #how-checks-work */}

每一張支票都是一個標準`createScorer()` instance with a `preprocess` step and a `generateScore` step. They follow the same [four-step pipeline](/docs/evals/custom-scorers#the-four-step-pipeline) as any other scorer:

1. **預處理**：從Agent運行中擷取並規範化相關資料（文字內容、Tool呼叫）
2. **產生分數**：將預處理結果轉換為分數（一般為二進位1或0）

因為檢查會跳過`analyze` and `generateReason` steps and make no LLM calls, they run in microseconds. Visit the [Quick Checks reference](/reference/evals/checks) for the full API, including all parameters and options for each check.
