# 快速檢查

Quick Checks 是可搭配使用的小型評分器，可驗證「輸出包含 X」或「Agent 呼叫了工具 Y」等常見條件。檢查不需要 LLM，會立即得出結果，可和其他評分器放在同一個 `scorers: [...]` 陣列中。

## 何時使用快速檢查 {/* #when-to-use-quick-checks */}

需要快速驗證結果明確的條件時，可使用 Quick Checks：

- 確認輸出文字包含或不含指定字串
- 驗證 Agent 有呼叫或未呼叫特定工具
- 驗證工具呼叫的順序與次數上限
- 以零成本、結果只有通過或不通過的檢查把關 CI 流程
- 搭配使用 LLM 的評分器，進行分層評估

需要主觀或語意評估時，請改用[以 LLM 為基礎的評分器](/docs/evals/built-in-scorers)。

## 快速入門 {/* #quickstart */}

```typescript title="src/evals/weather-checks.ts"
import { checks } from '@mastra/evals/checks'
import { runEvals } from '@mastra/core/evals'
import { weatherAgent } from '../agents'

const result = await runEvals({
  data: [{ input: 'What is the weather in Brooklyn?' }],
  target: weatherAgent,
  scorers: [checks.includes('Brooklyn'), checks.calledTool('get_weather'), checks.noToolErrors()],
})

console.log(result.scores)
// { 'check-includes': 1, 'check-called-tool': 1, 'check-no-tool-errors': 1 }
```

## 可用的檢查 {/* #available-checks */}

Quick Checks 有下列類別：

### 文字檢查 {/* #text-checks */}

這些評分器用來評估 Agent 的文字輸出：

| 檢查 | 用途 | 分數 |
| - | - | - |
| `checks.includes(str)` | 輸出包含子字串 | 1 或 0 |
| `checks.excludes(str)` | 輸出不含子字串 | 1 或 0 |
| `checks.equals(str)` | 輸出等於指定字串（預設忽略大小寫；傳入 `{ ignoreCase: false }` 即可精確比對） | 1 或 0 |
| `checks.matches(regex)` | 輸出符合規則運算式 | 1 或 0 |
| `checks.similarity(str)` | 以 Dice 係數衡量輸出與指定字串的相似度 | 0 到 1（設定 `threshold` 時只回傳 1 或 0） |

### 工具呼叫檢查 {/* #tool-call-checks */}

這些評分器會檢查 Agent 執行時的工具使用情形：

| 檢查 | 用途 | 分數 |
| - | - | - |
| `checks.calledTool(name)` | 指定工具至少被呼叫 N 次 | 1 或 0 |
| `checks.didNotCall(name)` | 沒有呼叫指定工具 | 1 或 0 |
| `checks.toolOrder([...])` | 工具呼叫符合預期順序 | 1 或 0 |
| `checks.maxToolCalls(n)` | 工具呼叫合計不超過 N 次 | 1 或 0 |
| `checks.usedNoTools()` | 完全沒有呼叫工具 | 1 或 0 |
| `checks.noToolErrors()` | 呼叫工具時沒有發生錯誤 | 1 或 0 |

## 搭配快速檢查與 LLM 評分器 {/* #combining-checks-with-llm-scorers */}

在同一次 `runEvals` 呼叫中，可以合併使用 Quick Checks 與 LLM 評分器。以 Quick Checks 把關有確定結果的條件，並由 LLM 評分器進行質化評估：

```typescript title="src/evals/layered-eval.ts"
import { checks } from '@mastra/evals/checks'
import { createFaithfulnessScorer } from '@mastra/evals/scorers/prebuilt'
import { runEvals } from '@mastra/core/evals'
import { myAgent } from '../agents'

const result = await runEvals({
  data: [
    {
      input: 'What is the weather in Brooklyn?',
      context: ['Brooklyn weather data: sunny, 72°F'],
    },
  ],
  target: myAgent,
  scorers: [
    // Deterministic checks (instant, free)
    checks.includes('Brooklyn'),
    checks.calledTool('get_weather'),
    checks.excludes('error'),
    checks.noToolErrors(),

    // LLM-based scorer (semantic, costs tokens)
    createFaithfulnessScorer({ model: '__GATEWAY_OPENAI_MODEL_LUNA__' }),
  ],
})
```

## 在即時評分中使用快速檢查 {/* #using-checks-in-live-scoring */}

將 Quick Checks 加入 Agent，即可持續監控：

```typescript title="src/agents/weather-agent.ts"
import { Agent } from '@mastra/core/agent'
import { checks } from '@mastra/evals/checks'

export const weatherAgent = new Agent({
  id: 'weather-agent',
  name: 'Weather Agent',
  instructions: 'Answer weather questions using the get_weather tool.',
  model: '__GATEWAY_OPENAI_MODEL__',
  tools: { get_weather: weatherTool },
  scorers: {
    noErrors: {
      scorer: checks.noToolErrors(),
      sampling: { type: 'ratio', rate: 1 },
    },
    mentionCity: {
      scorer: checks.includes('Brooklyn'),
      sampling: { type: 'ratio', rate: 0.5 },
    },
  },
})
```

## 快速檢查如何運作 {/* #how-checks-work */}

每項檢查都是標準的 `createScorer()` 執行個體，包含 `preprocess` 和 `generateScore` 步驟，遵循其他評分器採用的[四步驟流程](/docs/evals/custom-scorers#the-four-step-pipeline)：

1. **preprocess**：擷取並正規化 Agent 執行時的相關資料（文字內容、工具呼叫）。
1. **generateScore**：將前處理結果轉為分數（通常是 1 或 0）。

Quick Checks 略過 `analyze` 與 `generateReason`，也不呼叫 LLM，因此在微秒等級內即可完成。完整 API 以及各項檢查的參數和選項，請見[快速檢查參考文件](/reference/evals/checks)。
