# CI 跑動得分手

在 CI 管道中運行記分器可以提供可量化的指標，用於衡量Agent品質隨時間的變化。這`runEvals`函數透過您的Agent或Workflow處理多個測試案例並傳回總計分數。

## 基本設定 {/* #basic-setup */}

您可以使用任何支援ESM模組的測試框架，例如[Vitest](https://vitest.dev/), [Jest](https://jestjs.io/), or [摩卡](https://mochajs.org/).

## 建立測試用例 {/* #creating-test-cases */}

使用`runEvals` to evaluate your agent against multiple test cases. The function accepts an array of data items, each containing an `input` and optional `groundTruth` for scorer validation.

解決`target` with `mastra.getAgent()` or `mastra.getWorkflow()` rather than importing it directly. A directly imported agent or workflow has no Mastra instance attached, so registry lookups inside steps or tools (such as `mastra.getAgent('weatherAgent')`) fail, scores aren't persisted, and trace-based trajectory scoring is unavailable.

```typescript title="tests/weather-agent.test.ts"
import { describe, it, expect } from 'vitest'
import { runEvals } from '@mastra/core/evals'
import { mastra } from '../src/mastra'
import { locationScorer } from '../src/mastra/scorers/location-scorer'

describe('Weather Agent Tests', () => {
  it('should correctly extract locations from queries', async () => {
    const result = await runEvals({
      data: [
        {
          input: 'weather in Berlin',
          groundTruth: { expectedLocation: 'Berlin', expectedCountry: 'DE' },
        },
        {
          input: 'weather in Berlin, Maryland',
          groundTruth: { expectedLocation: 'Berlin', expectedCountry: 'US' },
        },
        {
          input: 'weather in Berlin, Russia',
          groundTruth: { expectedLocation: 'Berlin', expectedCountry: 'RU' },
        },
      ],
      target: mastra.getAgent('weatherAgent'),
      scorers: [locationScorer],
    })

    // Assert aggregate score meets threshold
    expect(result.scores['location-accuracy']).toBe(1)
    expect(result.summary.totalItems).toBe(3)
  })
})
```

## 了解結果 {/* #understanding-results */}

這`runEvals` function returns an object with:

* `scores`：所有測試案例中每個評分者的平均分數
* `summary.totalItems`：處理的測試案例總數

```typescript oxfmt:false
{
  scores: {
    'location-accuracy': 1.0,  // Average score across all items
    'another-scorer': 0.85
  },
  summary: {
    totalItems: 3
  }
}
```

## 多種測試場景 {/* #multiple-test-scenarios */}

為不同的評估場景建立單獨的測試案例：

```typescript title="tests/weather-agent.test.ts"
describe('Weather Agent Tests', () => {
  const weatherAgent = mastra.getAgent('weatherAgent')

  it('should handle location disambiguation', async () => {
    const result = await runEvals({
      data: [
        {
          input: 'weather in Berlin',
          groundTruth: {/* ... */},
        },
        {
          input: 'weather in Berlin, Maryland',
          groundTruth: {/* ... */},
        },
      ],
      target: weatherAgent,
      scorers: [locationScorer],
    })

    expect(result.scores['location-accuracy']).toBe(1)
  })

  it('should handle typos and misspellings', async () => {
    const result = await runEvals({
      data: [
        {
          input: 'weather in Berln',
          groundTruth: { expectedLocation: 'Berlin', expectedCountry: 'DE' },
        },
        {
          input: 'weather in Parris',
          groundTruth: { expectedLocation: 'Paris', expectedCountry: 'FR' },
        },
      ],
      target: weatherAgent,
      scorers: [locationScorer],
    })

    expect(result.scores['location-accuracy']).toBe(1)
  })
})
```
