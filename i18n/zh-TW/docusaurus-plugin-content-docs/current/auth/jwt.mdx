# JSON Web Token

`MastraJwtAuth` 類別使用 JSON Web Token（JWT），為 Mastra 提供輕量的身分驗證機制。它以共用密鑰驗證傳入的請求，並透過 `auth` 選項整合至 Mastra 伺服器。若要驗證身分提供者簽署的權杖，請使用 `jwksUri` 與 `issuer` 選項，詳見[參考文件](/reference/auth/jwt)。

## 安裝 {/* #installation */}

使用 `MastraJwtAuth` 類別前，請先安裝 `@mastra/auth` 套件。

```bash npm2yarn
npm install @mastra/auth@latest
```

## 建立 JWT {/* #creating-a-jwt */}

若要驗證送往 Mastra 伺服器的請求，需要有效的 JSON Web Token（JWT），並以 `MASTRA_JWT_SECRET` 簽署。

最簡單的方式是使用 [jwt.io](https://www.jwt.io/) 產生 JWT：

1. 選取 **JWT Encoder**。
1. 向下捲動至 **Sign JWT: Secret** 區段。
1. 輸入密鑰，例如 `supersecretdevkeythatishs256safe!`。
1. 按一下 **Generate example**，產生有效的 JWT。
1. 複製產生的權杖，在 `.env` 檔案中將它設為 `MASTRA_JWT_TOKEN` 的值。

## 使用範例 {/* #usage-example */}

產生 JWT 後，依照以下範例在 Mastra 伺服器設定 `MastraJwtAuth`：

```typescript {2,6-8} title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraJwtAuth } from '@mastra/auth'

export const mastra = new Mastra({
  server: {
    auth: new MastraJwtAuth({
      secret: process.env.MASTRA_JWT_SECRET,
    }),
  },
})
```

完整的設定選項請參閱 [MastraJwtAuth](/reference/auth/jwt)。

在 [Studio](/docs/studio/overview) 中開啟 **Settings**，於 **Headers** 下選取 **"Add Header"**。將標頭名稱設為 `Authorization`，值設為 `Bearer <your-jwt>`。

## 設定 `MastraClient` {/* #configuring-mastraclient */}

啟用 `auth` 後，透過 `MastraClient` 送往受保護路由的請求，必須在 `Authorization` 標頭中附上有效的 JWT：

```typescript {6} title="lib/mastra/mastra-client.ts"
import { MastraClient } from '@mastra/client-js'

export const mastraClient = new MastraClient({
  baseUrl: 'https://<mastra-api-url>',
  headers: {
    Authorization: `Bearer ${process.env.MASTRA_JWT_TOKEN}`,
  },
})
```

更多設定選項請參閱 [Mastra Client SDK](/docs/server/mastra-client)。

### 傳送需驗證身分的請求 {/* #making-authenticated-requests */}

設定好 `MastraClient` 後，你可以從前端應用程式傳送需驗證身分的請求，也可使用 `curl` 在本機快速測試：

<Tabs>
  <TabItem value="react" label="React">
    ```tsx title="src/components/test-agent.tsx"
    import { mastraClient } from '../../lib/mastra-client'

    export const TestAgent = () => {
      async function handleClick() {
        const agent = mastraClient.getAgent('weatherAgent')

        const response = await agent.generate('Weather in London')

        console.log(response)
      }

      return <button onClick={handleClick}>Test Agent</button>
    }
    ```
  </TabItem>

  <TabItem value="curl" label="cURL">
    ```bash
    curl -X POST http://localhost:4111/api/agents/weatherAgent/generate \
      -H "Content-Type: application/json" \
      -H "Authorization: Bearer <your-jwt>" \
      -d '{
        "messages": "Weather in London"
      }'
    ```
  </TabItem>
</Tabs>
