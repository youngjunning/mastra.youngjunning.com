# 簡單認證

這`SimpleAuth``@mastra/core/server`

## 使用案例 {/* #use-cases */}

* 本地開發和測試
* 簡單的API金鑰認證
* 整合完整身分Provider之前進行原型設計
* 具有靜態令牌的內部服務

## 安裝 {/* #installation */}

`SimpleAuth`包含在`@mastra/core` and requires no additional packages.

```typescript
import { SimpleAuth } from '@mastra/core/server'
```

## 使用範例 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { SimpleAuth } from '@mastra/core/server'

// Define your user type
type User = {
  id: string
  name: string
  role: 'admin' | 'user'
}

export const mastra = new Mastra({
  server: {
    auth: new SimpleAuth<User>({
      tokens: {
        'sk-admin-token-123': {
          id: 'user-1',
          name: 'Admin User',
          role: 'admin',
        },
        'sk-user-token-456': {
          id: 'user-2',
          name: 'Regular User',
          role: 'user',
        },
      },
    }),
  },
})
```

## 配置選項 {/* #configuration-options */}

|選項 |類型 |必填|說明 |
| - | - | - | - |
|`tokens` | `Record<string, TUser>` | Yes | Map of tokens to user objects |
| `headers` | `string \| string[]` | No | Additional headers to check for tokens |
| `name` | `string` | No | Provider name for logging |
| `authorizeUser` | `(user, request) => boolean \| Promise<boolean>`|沒有 |自訂授權功能 |
|`protected` | `(RegExp \| string)[]`|沒有 |需要身份驗證的路徑 |
|`public` | `(RegExp \| string)[]`|沒有 |繞過身份驗證的路徑 |

### 預設標頭 {/* #default-headers */}

SimpleAuth 預設會檢查這些標頭：

* `Authorization`（有或沒有`Bearer` prefix)
* `X-Playground-Access`

使用新增自訂標頭`headers` option:

```typescript
new SimpleAuth({
  tokens: {/* ... */},
  headers: ['X-API-Key', 'X-Custom-Auth'],
})
```

## 發出經過身份驗證的請求 {/* #making-authenticated-requests */}

將您的令牌包含在`Authorization` header:

```bash
curl -X POST http://localhost:4111/api/agents/myAgent/generate \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-admin-token-123" \
  -d '{"messages": "Hello"}'
```

或者沒有`Bearer` prefix:

```bash
curl -X POST http://localhost:4111/api/agents/myAgent/generate \
  -H "Content-Type: application/json" \
  -H "Authorization: sk-admin-token-123" \
  -d '{"messages": "Hello"}'
```

## 客製化授權 {/* #custom-authorization */}

新增基於角色或自訂的授權邏輯：

```typescript
import { SimpleAuth, getWebRequest } from '@mastra/core/server'

new SimpleAuth<User>({
  tokens: {
    'sk-admin-token': { id: '1', name: 'Admin', role: 'admin' },
    'sk-user-token': { id: '2', name: 'User', role: 'user' },
  },
  authorizeUser: (user, request) => {
    const webRequest = getWebRequest(request)
    const path = webRequest ? new URL(webRequest.url).pathname : ''

    // Only admins can access /admin routes
    if (path.includes('/admin')) {
      return user.role === 'admin'
    }
    return true
  },
})
```

## 環境變數 {/* #environment-variables */}

對於類似生產的設置，從環境變數載入令牌：

```typescript
const tokens: Record<string, User> = {}

// Load from environment
const adminToken = process.env.ADMIN_API_KEY
if (adminToken) {
  tokens[adminToken] = { id: 'admin', name: 'Admin', role: 'admin' }
}

const userToken = process.env.USER_API_KEY
if (userToken) {
  tokens[userToken] = { id: 'user', name: 'User', role: 'user' }
}

export const mastra = new Mastra({
  server: {
    auth: new SimpleAuth({ tokens }),
  },
})
```

## 和`MastraClient` {/* #with-mastraclient */}

使用您的令牌配置客戶端：

```typescript
import { MastraClient } from '@mastra/client-js'

const client = new MastraClient({
  baseUrl: 'http://localhost:4111',
  headers: {
    Authorization: 'Bearer sk-admin-token-123',
  },
})

const agent = client.getAgent('myAgent')
const response = await agent.generate('Hello')
```

## 限制 {/* #limitations */}



* 令牌儲存在記憶體中
* 沒有令牌過期或刷新
* 沒有加密驗證
* 所有令牌在啟動時必須已知

對於生產應用程序，請考慮使用[JWT](/docs/auth/jwt), [Clerk](/integrations/auth/clerk), [Auth0](/integrations/auth/auth0), or another identity provider.
