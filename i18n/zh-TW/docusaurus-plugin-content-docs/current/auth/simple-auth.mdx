# 簡易驗證

`SimpleAuth` 類別透過簡單的權杖與使用者對應關係來驗證身分。這個類別包含在 `@mastra/core/server` 中，適合開發、測試及基本的 API 金鑰驗證。

## 適用情境 {/* #use-cases */}

- 本機開發與測試
- 基本的 API 金鑰驗證
- 整合功能完整的身分提供者之前製作原型
- 使用靜態權杖的內部服務

## 安裝 {/* #installation */}

`SimpleAuth` 已包含在 `@mastra/core` 中，無須安裝其他套件。

```typescript
import { SimpleAuth } from '@mastra/core/server'
```

## 使用範例 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { SimpleAuth } from '@mastra/core/server'

// Define your user type
type User = {
  id: string
  name: string
  role: 'admin' | 'user'
}

export const mastra = new Mastra({
  server: {
    auth: new SimpleAuth<User>({
      tokens: {
        'sk-admin-token-123': {
          id: 'user-1',
          name: 'Admin User',
          role: 'admin',
        },
        'sk-user-token-456': {
          id: 'user-2',
          name: 'Regular User',
          role: 'user',
        },
      },
    }),
  },
})
```

## 設定選項 {/* #configuration-options */}

| 選項 | 型別 | 必填 | 說明 |
| - | - | - | - |
| `tokens` | `Record<string, TUser>` | 是 | 權杖與使用者物件的對應表。 |
| `headers` | `string \| string[]` | 否 | 額外用於查找權杖的標頭。 |
| `name` | `string` | 否 | 日誌使用的驗證提供者名稱。 |
| `authorizeUser` | `(user, request) => boolean \| Promise<boolean>` | 否 | 自訂授權函式。 |
| `protected` | `(RegExp \| string)[]` | 否 | 需要驗證身分的路徑。 |
| `public` | `(RegExp \| string)[]` | 否 | 可略過身分驗證的路徑。 |

### 預設檢查的標頭 {/* #default-headers */}

SimpleAuth 預設會檢查下列標頭。

- `Authorization`（可加上 `Bearer` 前綴，也可省略）
- `X-Playground-Access`

透過 `headers` 選項加入自訂標頭。

```typescript
new SimpleAuth({
  tokens: {/* ... */},
  headers: ['X-API-Key', 'X-Custom-Auth'],
})
```

## 傳送含驗證資訊的請求 {/* #making-authenticated-requests */}

在 `Authorization` 標頭中放入權杖。

```bash
curl -X POST http://localhost:4111/api/agents/myAgent/generate \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-admin-token-123" \
  -d '{"messages": "Hello"}'
```

也可以省略 `Bearer` 前綴。

```bash
curl -X POST http://localhost:4111/api/agents/myAgent/generate \
  -H "Content-Type: application/json" \
  -H "Authorization: sk-admin-token-123" \
  -d '{"messages": "Hello"}'
```

## 自訂授權 {/* #custom-authorization */}

你可以加入角色式授權或其他自訂授權邏輯。

```typescript
import { SimpleAuth, getWebRequest } from '@mastra/core/server'

new SimpleAuth<User>({
  tokens: {
    'sk-admin-token': { id: '1', name: 'Admin', role: 'admin' },
    'sk-user-token': { id: '2', name: 'User', role: 'user' },
  },
  authorizeUser: (user, request) => {
    const webRequest = getWebRequest(request)
    const path = webRequest ? new URL(webRequest.url).pathname : ''

    // Only admins can access /admin routes
    if (path.includes('/admin')) {
      return user.role === 'admin'
    }
    return true
  },
})
```

## 環境變數 {/* #environment-variables */}

若要讓設定接近正式環境，可從環境變數載入權杖。

```typescript
const tokens: Record<string, User> = {}

// Load from environment
const adminToken = process.env.ADMIN_API_KEY
if (adminToken) {
  tokens[adminToken] = { id: 'admin', name: 'Admin', role: 'admin' }
}

const userToken = process.env.USER_API_KEY
if (userToken) {
  tokens[userToken] = { id: 'user', name: 'User', role: 'user' }
}

export const mastra = new Mastra({
  server: {
    auth: new SimpleAuth({ tokens }),
  },
})
```

## 搭配 `MastraClient` 使用 {/* #with-mastraclient */}

在用戶端設定中指定權杖。

```typescript
import { MastraClient } from '@mastra/client-js'

const client = new MastraClient({
  baseUrl: 'http://localhost:4111',
  headers: {
    Authorization: 'Bearer sk-admin-token-123',
  },
})

const agent = client.getAgent('myAgent')
const response = await agent.generate('Hello')
```

## 限制 {/* #limitations */}

SimpleAuth 以簡易使用為設計目標，無法滿足正式環境的安全需求。

- 權杖儲存在記憶體內
- 沒有權杖到期或更新機制
- 不提供密碼學驗證
- 啟動時就必須備妥所有權杖

正式環境的應用程式可考慮採用 [JWT](/docs/auth/jwt)、[Clerk](/integrations/auth/clerk)、[Auth0](/integrations/auth/auth0) 或其他身分提供者。
