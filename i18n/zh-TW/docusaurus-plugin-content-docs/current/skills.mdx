# Agent Skill

Skill 是一組可重複使用的指示，讓 Agent 知道如何執行特定任務，並遵循 [Agent Skills 規格](https://agentskills.io)。

你可以透過 Agent 的 `skills` 直接設定 Skill，也可以在 [Workspace](/docs/sandbox/skills) 中設定。Agent 層級的 Skill 專屬於單一 Agent，可直接用程式碼定義，無需 Workspace。Workspace 會從檔案系統尋找 Skill，供使用該 Workspace 的所有 Agent 共用。本文說明如何定義和載入 Agent 層級的 Skill，以及如何依請求解析。

## 何時使用 Agent 層級的 Skill {/* #when-to-use-agent-level-skills */}

有下列需求時，可使用 Agent 層級的 Skill。

* 希望 Agent 可獨立運作，無需 Workspace。
* Skill 已定義在程式碼中，無需搜尋檔案系統。
* 正在開發內含 Agent 功能的套件或程式庫。
* 需要依各次請求的情境解析 Skill。

如要在整個專案中從檔案系統尋找 Skill，請使用 [Workspace Skill](/docs/sandbox/skills)。

## 快速入門 {/* #quickstart */}

直接在程式碼中定義一個 Skill，再將它加到 Agent。

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { createSkill } from '@mastra/core/skills'

const codeReview = createSkill({
  name: 'code-review',
  description: 'Use when reviewing code changes.',
  instructions: `
    When reviewing code:
    1. Check for correctness and edge cases
    2. Verify style consistency
    3. Look for potential bugs
  `,
})

export const reviewer = new Agent({
  id: 'reviewer',
  model: '__GATEWAY_OPENAI_MODEL__',
  instructions: 'You are a code review assistant.',
  // highlight-next-line
  skills: [codeReview],
})
```

Agent 會自動取得 `skill`、`skill_read` 和 `skill_search` 工具，因此能在對話中找出並載入 Skill。

## 定義內嵌 Skill {/* #defining-inline-skills */}

使用 `createSkill()`，即可完全以程式碼建立 Skill。

```typescript title="src/mastra/skills.ts"
import { createSkill } from '@mastra/core/skills'

export const releaseChecklist = createSkill({
  name: 'release-checklist',
  description: 'Use when preparing a release.',
  instructions: `
    ## Release Checklist
    1. Run the full test suite
    2. Update CHANGELOG.md
    3. Bump version numbers
    4. Create a git tag
  `,
  references: {
    'changelog-format.md': '# Changelog Format\nUse Keep a Changelog...',
  },
})
```

`references` 欄位可附上參考文件，供 Agent 透過 `skill_read` 工具讀取，作用和檔案系統 Skill 中的 `references/` 檔案相同。完整 API 請見 [`createSkill()` 參考文件](/reference/agents/createSkill)。

## 從檔案系統路徑載入 Skill {/* #filesystem-path-skills */}

直接指定磁碟上的 Skill 目錄即可，無需設定 Workspace。

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { createSkill } from '@mastra/core/skills'

export const agent = new Agent({
  id: 'my-agent',
  model: '__GATEWAY_OPENAI_MODEL__',
  skills: [
    './skills/code-review', // path to a SKILL.md directory
    './skills/testing', // another filesystem skill
    createSkill({/* ... */}), // inline skill
  ],
})
```

底層由 `LocalSkillSource` 處理檔案系統路徑，並依照 [Workspace Skill](/docs/sandbox/skills#skillmd-format) 的格式讀取 `SKILL.md` 檔案。

## 動態 Skill {/* #dynamic-skills */}

若要依請求解析 Skill，請傳入函式。

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { createSkill } from '@mastra/core/skills'

const devSkill = createSkill({
  name: 'dev-tools',
  description: 'Developer productivity tools.',
  instructions: '...',
})

const supportSkill = createSkill({
  name: 'support-guide',
  description: 'Customer support guidelines.',
  instructions: '...',
})

export const agent = new Agent({
  id: 'dynamic-agent',
  model: '__GATEWAY_OPENAI_MODEL__',
  // highlight-start
  skills: ({ requestContext }) => {
    const role = requestContext.get('userRole')
    if (role === 'developer') return [devSkill]
    return [supportSkill]
  },
  // highlight-end
})
```

解析函式接收 `{ requestContext, tracingContext }`，並回傳 `SkillInput[]` 陣列或 `Promise<SkillInput[]>`。

每個 `RequestContext` 只會執行一次解析函式。Agent 執行期間，函式會在 `resolve-skills` span 內執行。你可以像工具一樣透過 `tracingContext.currentSpan` 為自己的處理工作建立子 span。呼叫 `agent.listSkills()` 或伺服器的 Agent 端點等中繼資料讀取作業也會執行此函式，此時沒有 span，`tracingContext.currentSpan` 是 `undefined`。請讓函式快速回傳，並在使用 span 前確認它存在。

```typescript title="src/mastra/agents/index.ts"
skills: async ({ requestContext, tracingContext }) => {
  const span = tracingContext?.currentSpan?.createChildSpan({
    type: 'generic',
    name: 'entitlements-lookup',
  })
  const skills = await fetchSkillsFor(requestContext.get('userId'))
  span?.end()
  return skills
}
```

如需了解如何在 Agent 和 Workflow 中使用請求情境，請見 [Request Context](/docs/server/request-context)。

## 與 Workspace Skill 合併 {/* #merging-with-workspace-skills */}

如果 Agent 設定了 `skills`，而 Workspace 也有設定 Skill，兩組 Skill 會合併。有同名的 Skill 時，以 Agent 層級的設定為準。

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { Workspace, LocalFilesystem } from '@mastra/core/workspace'
import { createSkill } from '@mastra/core/skills'

const workspace = new Workspace({
  filesystem: new LocalFilesystem({ basePath: './workspace' }),
  skills: ['skills'], // provides "code-review" skill
})

const customReview = createSkill({
  name: 'code-review', // same name as workspace skill
  description: 'Custom review process.',
  instructions: '...',
})

export const reviewer = new Agent({
  id: 'reviewer',
  model: '__GATEWAY_OPENAI_MODEL__',
  workspace,
  skills: [customReview], // agent-level "code-review" wins
})
```

## 從程式碼存取 Skill {/* #programmatic-skill-access */}

例如在 Workflow 或 API 路由的應用程式碼中，可用 `agent.getSkill()` 及 `agent.listSkills()` 存取 Skill。

```typescript title="src/routes/skills.ts"
import { reviewer } from '../mastra/agents'

// Get a specific skill by name
const skill = await reviewer.getSkill('code-review')
if (skill) {
  console.log(skill.instructions)
}

// List all available skills
const allSkills = await reviewer.listSkills()
for (const meta of allSkills) {
  console.log(`${meta.name}: ${meta.description}`)
}
```

完整 API 請見 [`.getSkill()` 參考](/reference/agents/getSkill) 與 [`.listSkills()` 參考](/reference/agents/listSkills)。

## 儲存前驗證 Skill {/* #validating-skills-before-saving */}

若應用程式會透過工具、上傳或 shell 指令寫入 `SKILL.md` 檔案，請先用 `validateSkillContent()` 驗證內容。它採用和載入 Skill 時相同的規則，包括檢查 `name` 是否符合目錄名稱，並回傳結構化結果，不會拋出例外。

```typescript
import { validateSkillContent } from '@mastra/core/skills'

const result = validateSkillContent({ content: skillMarkdown, directoryName: 'code-review' })

if (!result.valid) {
  throw new Error(`Invalid skill:\n${result.errors.join('\n')}`)
}
// result.warnings lists non-blocking issues, such as very long instructions
```

若要驗證已解析的 frontmatter 物件，請使用 `validateSkillMetadata({ metadata, directoryName })`。
