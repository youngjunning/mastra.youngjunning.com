# 馬具

安全帶可讓Agent商追求長期、複雜的目標，同時保持其工作持久、可見且可操縱。它可以在重試和中斷時保留進度，同時為人員和其他系統提供檢查進度、新增上下文、批准操作、重定向Agent或停止Agent的方法。

只要工作持續進行，Agent安全帶就非常有用。常見的例子包括透過 CI 和審查進行更改的編碼Agent、軟體工廠（例如[Mastra Factory](https://factory.mastra.ai)) that coordinate many tasks in parallel, SRE agents that adapt as incidents evolve, and go-to-market agents that respond as accounts, signals, and conversations change.

在 Mastra 中，利用是指在單次不間斷運作之外管理Agent的一組功能。您可以單獨採用這些功能，也可以根據需要組合使用它們。

## 何時使用安全帶 {/* #when-to-use-a-harness */}

根據Agent商的需求選擇起點。您可以使用一種或多種功能。

|如果你想|從這裡開始 |為什麼 |
| - | - | - |
|透過客戶端斷開連線或伺服器重新啟動保持運作可用 |[Durable Agents](/docs/harness/durable-agents) | Persist run state and let clients reconnect to its stream. |
| Run slow tools, workflows, or subagents without blocking | [Background Tasks](/docs/harness/background-tasks) | Finish work asynchronously and return its result to the agent. |
| Keep an agent working until it reaches an objective | [Goals](/docs/harness/goals) | Evaluate a thread-scoped objective until it's complete or reaches its run budget. |
| Start work automatically at recurring times | [時間表](/docs/harness/schedules)|按 cron 計劃啟動隔離運行或將提示傳送到現有執行緒。 |
|新增上下文、重定向活動工作或喚醒空閒執行緒 |[訊號](/docs/signals/overview)|現在提供輸入或保留到下一回合。 |
|對 GitHub、Slack、持續整合或其他外部系統中的變更做出反應 |[訊號Provider](/docs/signals/signal-providers)|追蹤訂閱並將匹配事件轉發到Agent線程。 |
|建立具有會話、模式、狀態、批准和事件的互動式產品，或讓使用者引導、排隊後續工作和停止運行 |[Agent控制器](/docs/harness/agent-controller)|圍繞共享Agent運行時託管隔離會話，每個會話都有自己的運行控制項。 |
|提供Agent文件、外殼以及編碼Agent所需的預設設定 |[`createCodingAgent()`](/reference/coding-agent/create-coding-agent)|建立一個標準Agent，其中包含已配置的Workspace、任務追蹤和重試。 |
