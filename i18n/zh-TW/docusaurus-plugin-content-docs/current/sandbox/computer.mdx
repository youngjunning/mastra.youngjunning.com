# 電腦

運行桌面環境的沙箱可以公開螢幕截圖、滑鼠和鍵盤控制。當靜態配置的沙箱支援電腦功能時，Workspace會註冊電腦Tool。

[`DaytonaSandbox`](/integrations/sandboxes/daytona)和[`E2BDesktopSandbox`](/integrations/sandboxes/e2b-desktop)支援此功能。其他沙箱後端不註冊電腦Tool。解析器支援的沙箱不會註冊它們，因為Workspace在建立Tool清單時無法檢查已解析沙箱的功能。

## 電腦Tool {/* #computer-tools */}

|Tool|是否 |
| - | - |
|`mastra_workspace_computer_screenshot` | Captures the desktop as a PNG image and returns it to the model as native media. |
| `mastra_workspace_computer_click` | Presses and releases the left mouse button at pixel coordinates. |
| `mastra_workspace_computer_double_click`|在像素坐标处按鼠标左键两次。 |
|`mastra_workspace_computer_right_click`|在像素座標處按下並釋放滑鼠右鍵。 |
|`mastra_workspace_computer_move_mouse`|無需按按鈕即可將遊標移至像素座標。 |
|`mastra_workspace_computer_drag`|在兩點之間按下、拖曳和釋放。 |
|`mastra_workspace_computer_type`|在焦點元素中鍵入文字。 |
|`mastra_workspace_computer_press_key`|按下一個鍵或組合鍵，例如`Enter`或者`ctrl+s`. |
| `mastra_workspace_computer_scroll`|向上或向下捲動。 |
|`mastra_workspace_computer_get_screen_info`|取得螢幕尺寸和遊標位置。 |
|`mastra_workspace_computer_wait`|等待界面穩定。 |

## 配置計算機Tool {/* #configure-computer-tools */}

預設情況下，操作Tool會在每次操作後截取螢幕截圖。配置每個Tool的螢幕截圖行為：

```typescript title="src/mastra/workspaces.ts"
import { Workspace, WORKSPACE_TOOLS } from '@mastra/core/workspace'
import { E2BDesktopSandbox } from '@mastra/e2b-desktop'

const workspace = new Workspace({
  sandbox: new E2BDesktopSandbox(),
  tools: {
    [WORKSPACE_TOOLS.COMPUTER.CLICK]: {
      screenshotAfterAction: true,
      screenshotDelayMs: 1000,
    },
    [WORKSPACE_TOOLS.COMPUTER.TYPE]: {
      requireApproval: true,
    },
  },
})
```

電腦Tool接受相同的每個Tool`enabled` and `requireApproval` configuration as other workspace tools.
