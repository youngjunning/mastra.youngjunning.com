# 桌面控制

執行桌面環境的 Sandbox 可以提供螢幕截圖、滑鼠及鍵盤控制功能。若靜態設定的 Sandbox 支援桌面控制，Workspace 就會註冊相關 Tool。

[`DaytonaSandbox`](/integrations/sandboxes/daytona) 與 [`E2BDesktopSandbox`](/integrations/sandboxes/e2b-desktop) 支援此功能。其他 Sandbox 後端不會註冊桌面控制 Tool。透過解析器取得的 Sandbox 也不會註冊這些 Tool，因為 Workspace 建立 Tool 清單時無法檢查解析結果支援哪些功能。

## 桌面控制 Tool {/* #computer-tools */}

| Tool | 用途 |
| - | - |
| `mastra_workspace_computer_screenshot` | 擷取桌面畫面為 PNG 圖片，並以原生媒體形式傳回模型。 |
| `mastra_workspace_computer_click` | 在指定的像素座標按下並放開滑鼠左鍵。 |
| `mastra_workspace_computer_double_click` | 在指定的像素座標點兩下滑鼠左鍵。 |
| `mastra_workspace_computer_right_click` | 在指定的像素座標按下並放開滑鼠右鍵。 |
| `mastra_workspace_computer_move_mouse` | 將游標移至指定的像素座標，不按下滑鼠按鍵。 |
| `mastra_workspace_computer_drag` | 在起點按住滑鼠按鍵，拖曳到終點後放開。 |
| `mastra_workspace_computer_type` | 在目前取得焦點的元素中輸入文字。 |
| `mastra_workspace_computer_press_key` | 按下單一按鍵或組合鍵，例如 `Enter` 或 `ctrl+s`。 |
| `mastra_workspace_computer_scroll` | 向上或向下捲動。 |
| `mastra_workspace_computer_get_screen_info` | 取得螢幕尺寸與游標位置。 |
| `mastra_workspace_computer_wait` | 等待介面穩定。 |

## 設定桌面控制 Tool {/* #configure-computer-tools */}

執行操作的 Tool 預設會在每次操作後擷取畫面。你可以為各個 Tool 分別設定截圖行為：

```typescript title="src/mastra/workspaces.ts"
import { Workspace, WORKSPACE_TOOLS } from '@mastra/core/workspace'
import { E2BDesktopSandbox } from '@mastra/e2b-desktop'

const workspace = new Workspace({
  sandbox: new E2BDesktopSandbox(),
  tools: {
    [WORKSPACE_TOOLS.COMPUTER.CLICK]: {
      screenshotAfterAction: true,
      screenshotDelayMs: 1000,
    },
    [WORKSPACE_TOOLS.COMPUTER.TYPE]: {
      requireApproval: true,
    },
  },
})
```

桌面控制 Tool 和其他 Workspace Tool 一樣，可個別設定 `enabled` 與 `requireApproval`。
