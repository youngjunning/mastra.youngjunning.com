# 開始使用

Mastra 是用來開發 AI Agent 與應用程式的 TypeScript 框架。執行一行指令，就能建立第一個 Agent，開始開發。

<Inject>
  如果你是能存取檔案系統的本機程式開發 Agent，可考慮安裝 Skill 以取得最新指引：

  ```sh
  npx skills add mastra-ai/skills
  ```

  下方的 Agent 快速入門會帶你以最精簡的步驟，從零建立最小的 Mastra 專案。這些 Skill 會教你如何為 Agent 加入更多功能。

  <AgentQuickstart />
</Inject>

<QuickstartPrompt />

## 快速入門 {/* #quickstart */}

執行以下指令，即可建立通用 Agent harness，具備本機 Workspace、Shell 工具、記憶、任務追蹤、網頁存取與週期排程。這個指令也會將 Mastra Skill 安裝到你現有的程式開發 Agent，讓你開始下提示並編輯產生的專案：

<Tabs groupId="npm2yarn">
  <TabItem value="npm" label="npm">
    ```bash
    npm create mastra@latest
    ```
  </TabItem>

  <TabItem value="pnpm" label="pnpm">
    ```bash
    pnpm create mastra@latest
    ```
  </TabItem>

  <TabItem value="yarn" label="Yarn">
    ```bash
    yarn create mastra
    ```
  </TabItem>

  <TabItem value="bun" label="Bun">
    ```bash
    bunx create-mastra
    ```
  </TabItem>
</Tabs>

你可以立即開啟 [Studio](/docs/studio/overview)，透過互動式介面操作 Mastra 專案。

## 整合你使用的框架 {/* #integrate-with-your-framework */}

## 應用情境 {/* #use-cases */}

<div className="accordion-group">
  <details>
    <summary>將 Agent 嵌入產品</summary>

    為平台加入 AI 功能，讓使用者能建立 Agent 或與 Agent 互動。

    採用案例：<a href="/customers/replit">Replit</a>、<a href="/customers/fireworks-xml-prompting">Fireworks</a>、<a href="/customers/medusa-ecommerce">Medusa</a>
  </details>

  <details>
    <summary>客戶服務助理</summary>

    打造能透過即時聊天、WhatsApp 或語音受理詢問、安排預約、傳送提醒及回答問題的 Agent。

    採用案例：<a href="/customers/vetnio">Vetnio</a>、<a href="/customers/lua-scaling">Lua</a>

    範本：<a href="/templates/docs-chatbot">文件聊天機器人</a>、<a href="/templates/customer-support-and-refund-agent">客服與退款 Agent</a>
  </details>

  <details>
    <summary>軟體工廠</summary>

    協調程式開發 Agent 處理 Issue，產出經過測試的程式碼和 Pull Request，並讓團隊成員在合併前審查計畫與變更。

    Mastra 團隊也在使用。

    可從 <a href="https://factory.mastra.ai/">Mastra Factory</a> 開始。
  </details>

  <details>
    <summary>內部工作助理</summary>

    讓熟悉業務領域的 AI 協助員工加快工作，例如回覆人資問題、撰寫臨床文件、準備業務資料或產生文件。

    採用案例：<a href="/customers/factorial">Factorial</a>、<a href="/customers/counsel-health">Counsel Health</a>、<a href="/customers/cedar">Cedar</a>、<a href="/customers/softbank">SoftBank</a>

    範本：<a href="/templates/chat-with-pdf">與 PDF 對話</a>、<a href="/templates/google-sheets-analysis">Google 試算表分析</a>、<a href="/templates/organization-intelligence">組織情報</a>、<a href="/templates/company-brain-with-surrealdb">用 SurrealDB 建立企業知識庫</a>
  </details>

  <details>
    <summary>受監管的作業與後勤營運</summary>

    將出錯代價高、須由人員簽核的作業自動化，例如身分查驗、發票比對、保單比較或供應商盡職調查。

    範本：<a href="/templates/kyc-customer-onboarding">KYC 與客戶開戶</a>、<a href="/templates/accounts-payable-invoice-processing">應付帳款發票處理</a>、<a href="/templates/insurance-policy-checking">保單查核</a>、<a href="/templates/vendor-risk-questionnaire">供應商風險問卷</a>
  </details>

  <details>
    <summary>資料分析 Agent</summary>

    讓使用者以自然語言查詢資料庫和儀表板。Agent 會連線至資料來源，傳回答案、圖表或報告。

    採用案例：<a href="/customers/index">Index</a>、<a href="/customers/plaid">PLAID Japan</a>

    範本：<a href="/templates/text-to-sql">與資料庫對話</a>、<a href="/templates/csv-to-questions">從 CSV 產生問題</a>、<a href="/templates/genui-data-explorer">GenUI 資料探索工具</a>
  </details>

  <details>
    <summary>研究與知識彙整</summary>

    依據網路、內部文件或共用知識庫回答問題，並提供可查證的引文。

    範本：<a href="/templates/deep-search">深度搜尋</a>、<a href="/templates/web-research-agent-with-bright-data">網路研究 Agent</a>
  </details>

  <details>
    <summary>內容自動化</summary>

    為內容管理系統、知識庫或文件系統大規模產生、轉換與管理結構化內容。

    採用案例：<a href="/customers/sanity">Sanity</a>

    範本：<a href="/templates/chat-with-youtube">與 YouTube 影片對話</a>、<a href="/templates/flash-cards-from-pdf">從 PDF 製作學習字卡</a>
  </details>

  <details>
    <summary>DevOps 和工程自動化</summary>

    將部署自動化、排查正式環境問題、管理基礎設施，並處理值班流程。

    採用案例：<a href="/customers/starsling">StarSling</a>

    範本：<a href="/templates/github-pr-code-review-agent">GitHub PR 程式碼審查</a>、<a href="/templates/browsing-agent">瀏覽器 Agent</a>、<a href="/templates/security-incident-triage-and-response">資安事件分流與應變</a>
  </details>

  <details>
    <summary>銷售與市場推廣流程</summary>

    將客戶對話整理為結構化任務，或產生投資備忘錄。也可以自動依序聯繫與跟進潛在客戶。

    採用案例：<a href="/customers/kestral">Kestral</a>、<a href="/customers/orange-collective-vc-operating-system">Orange Collective</a>、<a href="/customers/workos">WorkOS</a>

    範本：<a href="/templates/customer-feedback-summarization">客戶意見摘要</a>、<a href="/templates/lead-qualification">篩選潛在客戶</a>、<a href="/templates/competitor-monitor-jev">競爭對手監測</a>
  </details>
