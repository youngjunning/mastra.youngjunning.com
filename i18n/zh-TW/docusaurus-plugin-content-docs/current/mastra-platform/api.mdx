## 回饋介面 {/* #feedback-api */}

回饋 API 列出並分析匯出到 Mastra Platform Observability 的回饋。由於 API 沒有版本控制，因此無法保證向後相容性。速率限制、保留和攝取到查詢的新鮮度不是已發布的合約。

端點與 Mastra 運行時回饋路由共享其查詢參數、請求正文和回應類型。請參閱[feedback reference](/reference/observability/feedback) for the full contract, including [list query parameters](/reference/observability/feedback#list-query-parameters) and [`FeedbackFilter`](/reference/observability/feedback#feedbackfilter).

使用您環境的資料駐留區域的根 URL：

|區 |根 URL |
| - | - |
|美國 |`https://observability.mastra.ai/api/observability` |
| European Union | `https://observability.eu.mastra.ai/api/observability` |

遙測留在其駐留區域。查詢其他區域不會傳回該環境的任何記錄。看[Observability co-location](/docs/mastra-platform/regions#observability-co-location) for the environment-to-region mapping.

### 認證及專案範圍 {/* #authentication-and-project-scope */}

每個請求都需要平台存取權令牌。創建一個在[Mastra Platform](https://projects.mastra.ai), or use the token written to `.env` during Platform setup.

包括`X-Mastra-Project-Id` to limit results to one project. If you omit it, the query covers feedback in every project available to the token's organization.

```bash
curl -sS "https://observability.mastra.ai/api/observability/feedback?page=0&perPage=20&feedbackType=rating" \
  -H "Authorization: Bearer $MASTRA_PLATFORM_ACCESS_TOKEN" \
  -H "X-Mastra-Project-Id: $MASTRA_PROJECT_ID" | jq
```

使用組織範圍的平台存取令牌。網關推理鍵，例如`mk_*` keys aren't accepted. Queries remain constrained to the token's organization even when you supply a project ID.

### 端點 {/* #endpoints */}

|方法|端點 |描述 |
| - | - | - |
|取得 |`/feedback` | List feedback records |
| POST | `/feedback/aggregate` | Return one aggregate value |
| POST | `/feedback/breakdown` | Group feedback by dimensions |
| POST | `/feedback/timeseries` | Bucket feedback by interval |
| POST | `/feedback/percentiles` | Return percentile series |

列表端點採用每個[`FeedbackFilter`](/reference/observability/feedback#feedbackfilter) field as a query parameter with the same name, for example `traceId`, `spanId`, `feedbackType`, `feedbackSource`, `environment`, `entityName`, `experimentId`, or `tags`. Repeat a parameter for multiple values, such as `feedbackType=rating&feedbackType=thumbs`.

```bash
curl -sS "https://observability.mastra.ai/api/observability/feedback?traceId=trace-123&environment=production" \
  -H "Authorization: Bearer $MASTRA_PLATFORM_ACCESS_TOKEN" \
  -H "X-Mastra-Project-Id: $MASTRA_PROJECT_ID" | jq
```

|參數|描述 |
| - | - |
|`page`, `perPage` | Zero-indexed page and page size (1 to 100). Default `0` and `10`. |
| `field`, `direction` | Sort by `timestamp` in `ASC` or `DESC` order. Default `DESC`. |
| `mode=delta` | Switch from paging to incremental delta polling. |
| `after` | Delta cursor from the previous delta response. Delta mode only. |
| `limit` | Maximum updates per delta poll (1 to 100). Delta mode only. |

回應包含`feedback` array and page or delta metadata. See [list query parameters](/reference/observability/feedback#list-query-parameters) in the feedback reference for the full parameter contract, including JSON-encoded object filters such as `timestamp`.

分析端點接受與[feedback reference](/reference/observability/feedback). Analytics operate only on numeric feedback values.

```bash
curl -sS "https://observability.mastra.ai/api/observability/feedback/aggregate" \
  -X POST \
  -H "Authorization: Bearer $MASTRA_PLATFORM_ACCESS_TOKEN" \
  -H "X-Mastra-Project-Id: $MASTRA_PROJECT_ID" \
  -H "Content-Type: application/json" \
  --data '{"feedbackType":"rating","feedbackSource":"user","aggregation":"avg"}' | jq
```

API回`401` for invalid credentials, `403` for organization authorization failures, and `400` for malformed query arguments or JSON bodies.

託管可觀察性不提供回饋建立途徑。從應用程式中匯出回饋，如中所述[Export feedback to Mastra Platform](/docs/observability/feedback#export-feedback-to-mastra-platform).

### 端點 {/* #endpoints-1 */}

|方法|端點 |描述 |
| - | - | - |
|取得 |`/metrics` | List raw metric records |
| POST | `/metrics/aggregate` | Return one aggregate value |
| POST | `/metrics/breakdown` | Group metrics by dimensions |
| POST | `/metrics/timeseries` | Bucket metrics by interval |
| POST | `/metrics/percentiles` | Return percentile series for one metric |
| GET | `/discovery/metric-names` | List metric names |
| GET | `/discovery/metric-label-keys` | List label keys for a metric |
| GET | `/discovery/metric-label-values` | List values for a metric label key |

列表和發現端點將它們的參數作為查詢參數。看[`listMetrics(args)`](/reference/observability/metrics/queries#listmetricsargs) and [metric discovery](/reference/observability/metrics/queries#metric-discovery) in the metric queries reference for the parameters each one accepts.

分析端點接受與[metric queries reference](/reference/observability/metrics/queries#analytics-methods), including `name`, `aggregation`, `filters`, `groupBy`, `interval`, `percentiles`, `comparePeriod`, `limit`, `orderDirection`, and `distinctColumn`.

```bash
curl -sS "https://observability.mastra.ai/api/observability/metrics/aggregate" \
  -X POST \
  -H "Authorization: Bearer $MASTRA_PLATFORM_ACCESS_TOKEN" \
  -H "X-Mastra-Project-Id: $MASTRA_PROJECT_ID" \
  -H "Content-Type: application/json" \
  --data '{"name":["mastra_model_total_input_tokens","mastra_model_total_output_tokens"],"aggregation":"sum","filters":{"timestamp":{"start":"2026-09-13T00:00:00Z","end":"2026-10-13T00:00:00Z"}},"comparePeriod":"previous_period"}' | jq
```

`filters.timestamp`是可選的。如果你省略`start` and `end`, the query covers all retained data. `comparePeriod` requires both `start` and `end`. Without them, the previous-period fields are `null`.

API回`401` for invalid credentials, `403` for organization authorization failures, and `400` for malformed query arguments or JSON bodies.

#### `MastraClient` {/* #mastraclient */}

`MastraClient`從`@mastra/client-js` exposes the analytics and discovery methods. Set `baseUrl` to the region's host without the `/api/observability` path:

```typescript
import { MastraClient } from '@mastra/client-js'

const mastraClient = new MastraClient({
  baseUrl: 'https://observability.mastra.ai',
  headers: {
    Authorization: `Bearer ${process.env.MASTRA_PLATFORM_ACCESS_TOKEN}`,
    'X-Mastra-Project-Id': process.env.MASTRA_PROJECT_ID!,
  },
})

const result = await mastraClient.getMetricAggregate({
  name: ['mastra_model_total_input_tokens', 'mastra_model_total_output_tokens'],
  aggregation: 'sum',
})
```

#### 命令列介面 {/* #cli */}

這[`mastra api metric`](/reference/cli/mastra#mastra-api-metric-aggregate) commands target the United States endpoint by default. Pass `--url` to query the European Union region:

```bash
mastra api --url https://observability.eu.mastra.ai metric aggregate '<json>'
```
