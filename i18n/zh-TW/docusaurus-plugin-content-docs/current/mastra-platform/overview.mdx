# 馬斯特拉平台

這[Mastra platform](https://projects.mastra.ai)提供了三種用於部署、監控和管理使用 Mastra 框架建置的 AI 應用程式的產品：

* [**可觀察性**](/docs/mastra-platform/observability)：每個平台專案的基準產品，具有跨 Mastra 專案和部署的可搜尋追蹤、日誌和指標
* [**工作室**](/docs/mastra-platform/studio)：用於測試Agent程式和運行Workflow的託管視覺環境，以及用於檢查追蹤的Tool。從 Studio 開始還可以為您提供可觀察性。
* [**伺服器**](/docs/mastra-platform/server)：作為 API 伺服器運行 Mastra 應用程式的生產部署目標。從伺服器開始還可以為您提供可觀察性。

[`mastra deploy`](/docs/mastra-platform/deploy), or connect a GitHub repository for push-to-deploy. See the [GitHub integration](/docs/mastra-platform/github) for the repository-linked flow.

[**Environments**](/docs/mastra-platform/environments) (for example `production` and `staging`) and provision [**Hosted databases**](/docs/mastra-platform/database) from the CLI or project settings to persist application data. Each environment also gets a managed [**Workspace**](/docs/mastra-platform/workspaces) that gives agents a filesystem and sandbox with no manual configuration.

組織層面[**Alerts**](/docs/mastra-platform/alerts) notify your team when deploys fail or running services stop. Alerts can cover every project or selected projects and environments, with notifications sent to Slack, email, or webhooks.

[**連接**](/docs/mastra-platform/connect)將您的帳戶儲存在 Linear、Slack 和 GitHub 等Provider上，因此Agent商可以將它們用作Tool和聊天管道，而無需您建立Provider應用程式或管理 API 金鑰。

[**追蹤情報**](/docs/mastra-platform/trace-intelligence)在您的座席軌跡中尋找重複出現的目標、結果、行為和情緒。 Trace Intelligence 已針對選定項目推出內測版。

## 開始使用 {/* #get-started */}

選擇與您想要執行的操作相符的路徑：

* **新增託管可觀察性**： 使用[Observability](/docs/mastra-platform/observability) to collect searchable traces, logs, and metrics across projects and deploys. Start here if you want monitoring without deploying Studio or Server first.
* **部署工作室**： 使用[Studio](/docs/mastra-platform/studio) to host the visual development environment for your team. Start here if you want a shared UI for testing agents and running workflows, as well as inspecting traces.
* **部署伺服器**： 使用[Server](/docs/mastra-platform/server) to run your Mastra application as a production API server. Start here when you’re ready to serve agents, tools, and workflows from the cloud.
* **建立一個軟體工廠：**&#x90E8;署[Mastra Factory](https://factory.mastra.ai) to Mastra platform and connect your repository to turn issues into plans, implementations, and reviewed pull requests.

## 關鍵概念 {/* #key-concepts */}

**專案**是所有產品的共用父實體。單一專案可以包含每個產品：Observability、Studio 和 Server。項目屬於**Organization**, which is the multi-tenant container for your team.

您的 Mastra 應用程式由三個構建塊構建：

* [Agent商](/docs/agents/overview)：人工智慧Agent可以使用Tool並遵循指令，同時保持上下文
* [Tool](/docs/agents/tools)：可供您的Agent使用的可調用功能和集成
* [Workflow](/docs/workflows/overview)：協調Agent商和Tool的多步驟編排管道

## 即將投入生產 {/* #going-to-production */}

在本地開發您的專案[`mastra dev`](/reference/cli/mastra#mastra-dev) and open [Studio](/docs/studio/overview) to test your agents, workflows, and tools in a visual environment.

準備好將應用程式部署到生產環境後，運行[`mastra deploy`](/reference/cli/mastra#mastra-deploy) to push your application to the cloud.

遵循[Deploy](/docs/mastra-platform/deploy) docs for step-by-step instructions.

如果您在自己的基礎架構上託管 Mastra 應用程序，您仍然可以使用以下方式將Observability資料傳送到 Mastra 平台：[MastraPlatformExporter](/docs/mastra-platform/observability).
