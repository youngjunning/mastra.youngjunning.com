# Mastra Platform

[Mastra Platform](https://projects.mastra.ai) 提供三項產品，可用來部署、監控及管理以 Mastra 框架建置的 AI 應用程式。

- [**Observability**](/docs/mastra-platform/observability)。所有平台專案的基礎產品，可跨 Mastra 專案及部署搜尋 Trace、日誌與指標。
- [**Studio**](/docs/mastra-platform/studio)。託管式視覺化環境，可測試 Agent、執行 Workflow，並提供檢視 Trace 的工具。從 Studio 開始也會一併取得 Observability。
- [**Server**](/docs/mastra-platform/server)。正式環境的部署目標，可將 Mastra 應用程式當作 API 伺服器執行。從 Server 開始也會一併取得 Observability。

執行 [`mastra deploy`](/docs/mastra-platform/deploy) 即可部署，也可以連結 GitHub 儲存庫，在推送時自動部署。儲存庫連結流程請參閱 [GitHub 整合](/docs/mastra-platform/github)。

每個專案可執行多個[**環境**](/docs/mastra-platform/environments)（例如 `production` 和 `staging`），並透過 CLI 或專案設定佈建[**託管資料庫**](/docs/mastra-platform/database)，以永久儲存應用程式資料。每個環境也有託管的 [**Workspace**](/docs/mastra-platform/workspaces)，可提供 Agent 檔案系統與 Sandbox，無須手動設定。

部署失敗或執行中的服務停止時，組織層級的[**警示**](/docs/mastra-platform/alerts)會通知團隊。警示可涵蓋所有專案，或只涵蓋指定的專案及環境，並透過 Slack、電子郵件或 Webhook 傳送通知。

[**Connect**](/docs/mastra-platform/connect) 會儲存你在 Linear、Slack 和 GitHub 等服務的帳號，讓 Agent 使用這些服務作為 Tool 或聊天管道，無須自行建立第三方應用程式或管理 API 金鑰。

[**Trace Intelligence**](/docs/mastra-platform/trace-intelligence) 會從 Agent 的 Trace 找出重複出現的目標、結果、行為與情緒。目前僅開放指定專案參與封閉測試。

## 開始使用 {/* #get-started */}

依照你的需求選擇起點。

- **加入託管可觀測性**。透過 [Observability](/docs/mastra-platform/observability) 收集跨專案及部署的 Trace、日誌與指標，並支援搜尋。如果想直接開始監控而不先部署 Studio 或 Server，可以從這裡開始。
- **部署 Studio**。使用 [Studio](/docs/mastra-platform/studio) 為團隊託管視覺化開發環境。若團隊需要共用介面來測試 Agent、執行 Workflow 及檢視 Trace，可以從這裡開始。
- **部署 Server**。使用 [Server](/docs/mastra-platform/server) 在正式環境中將 Mastra 應用程式當作 API 伺服器執行。準備好從雲端提供 Agent、Tool 及 Workflow 時，可以從這裡開始。
- **建立軟體工廠**。將 [Mastra Factory](https://factory.mastra.ai) 部署至 Mastra Platform 並連結儲存庫，把 Issue 轉成計畫、實作及審查過的 Pull Request。

## 核心概念 {/* #key-concepts */}

**專案**是各項產品共用的上層實體，一個專案可同時包含 Observability、Studio 和 Server。專案隸屬於**組織**，組織是團隊的多租戶容器。

Mastra 應用程式由三類元件組成。

- [Agent](/docs/agents/overview)。能保留上下文、遵循指令並使用 Tool 的 AI Agent。
- [Tool](/docs/agents/tools)。Agent 可以呼叫的函式與整合服務。
- [Workflow](/docs/workflows/overview)。協調 Agent 和 Tool 的多步驟編排流程。

## 部署至正式環境 {/* #going-to-production */}

使用 [`mastra dev`](/reference/cli/mastra#mastra-dev) 在本機開發專案，再開啟 [Studio](/docs/studio/overview)，在視覺化環境中測試 Agent、Workflow 和 Tool。

準備好部署至正式環境後，執行 [`mastra deploy`](/reference/cli/mastra#mastra-deploy) 將應用程式部署至雲端。

詳細步驟請參閱[部署文件](/docs/mastra-platform/deploy)。

即使 Mastra 應用程式架設在自有基礎架構上，仍可使用 [MastraPlatformExporter](/docs/mastra-platform/observability) 將可觀測性資料傳送至 Mastra Platform。
