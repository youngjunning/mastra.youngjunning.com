# 工作室部署

Studio 是一個基於 React 的單頁應用程式 (SPA)，它在瀏覽器中運行並連接到正在運行的[Mastra server](/docs/deployment/mastra-server).

您可以透過兩種主要方式部署 Studio：

* Mastra 平台為您提供託管工作室，並允許您透過連結與您的團隊共享存取權限
*

在此頁面上，您將了解如何在您自己的基礎架構上部署 Studio。由於部署的細節可能會根據您的需求和設定而有很大差異，因此我們將介紹您可用的一般原則和選項。

## 快速入門 {/* #quickstart */}

運行 Studio 最簡單的方法是[`mastra studio`](/reference/cli/mastra#mastra-studio) command.

然而`mastra dev` runs both Studio and an API for development purposes, the purpose of `mastra studio` is to serve a standalone, static UI that connects to an already-running Mastra server. You can deploy Studio separately from the Mastra server.

打開終端機並安裝`mastra` CLI globally:

```bash npm2yarn
npm install -g mastra
```

運行`mastra studio` command:

```bash
mastra studio
```

打開[localhost:3000](http://localhost:3000) in your browser to see the Studio UI. By default, it connects to a Mastra server at `http://localhost:4111`; when no server is available, the UI displays a form for entering your Mastra instance URL and API prefix.

該指令使用 Node 的內建`http` module and [`serve-handler`](https://www.npmjs.com/package/serve-handler) to serve the static files.



如果您在子路徑下託管 Studio（例如`/agents` behind Nginx), set `MASTRA_STUDIO_BASE_PATH` before starting Studio:

```bash
MASTRA_STUDIO_BASE_PATH=/agents mastra studio
```

這會更新 HTML 基本 URL 和靜態資源路由，以便獨立 Studio 在該子路徑下正常運作。

## 運行伺服器 {/* #running-a-server */}

跑步`mastra studio` as a long-running process is no different from running any other Node.js service. The same deployment practices and tools apply here. Use process managers such as PM2 or Docker. Cloud services that support Node.js applications are another option. As with any web service, configure CORS correctly and monitor errors.

：：：警告

Studio 連接到您的 Mastra 伺服器後，它可以完全存取您的Agent、Workflow和Tool。確保在生產中正確保護它（例如，在身份驗證、VPN 等後面），以防止未經授權的存取。

參觀[Authentication](/docs/studio/auth) docs to learn more.

:::

### 與您的 API 一起 {/* #alongside-your-api */}

或者，您可以將 Studio 與您的服務一起提供[Mastra server](/docs/deployment/mastra-server). This way you only have one service to deploy and manage.

`mastra build` with the `--studio` flag:

```bash
mastra build --studio
```

它將創建一個`.mastra/output/studio` folder with the built Studio assets. By defining the `MASTRA_STUDIO_PATH` environment variable, the Mastra server can serve the Studio UI, too.

```bash
MASTRA_STUDIO_PATH=.mastra/output/studio node .mastra/output/index.mjs
```

### 手動的 {/* #manual */}

您無法直接將建置的 Studio 資產部署到 CDN，因為 UI 依賴某些執行時間配置。透過一些額外的設置，您可以從建置的資產中建立一個獨立的 SPA，並將其部署到任何靜態託管服務。

請按照以下範例使用 Vite 建立 SPA。

<Steps>
  <StepItem>
    建立一個新資料夾並初始化一個新的 Node.js 專案：

    ```bash npm2yarn
    mkdir studio-spa
    cd studio-spa
    npm init
    ```
  </StepItem>

  <StepItem>
    安裝`vite` and `mastra` as dependencies:

    ```bash npm2yarn
    npm install vite mastra
    ```
  </StepItem>

  <StepItem>
    `package.json`:

    ```json title="package.json"
    {
      "scripts": {
        "build": "vite build"
      }
    }
    ```
  </StepItem>

  <StepItem>
    建立佔位符`index.html` file:

    ```html title="index.html"
    <!doctype html>
    <html>
      <head></head>
      <body></body>
    </html>
    ```
  </StepItem>

  <StepItem>
    創建一個`vite.config.js` file. It copies the built Studio assets to the `dist` folder and replaces any `%%PLACEHOLDER%%` values in the HTML with environment variable values.

    ```js title="vite.config.js"
    import { defineConfig, loadEnv } from 'vite'
    import { readFileSync, cpSync, writeFileSync } from 'node:fs'
    import { resolve, join } from 'node:path'

    const studioDir = resolve(import.meta.dirname, 'node_modules/mastra/dist/studio')

    export default defineConfig(({ mode }) => {
      const env = loadEnv(mode, process.cwd(), 'MASTRA_')

      return {
        plugins: [
          {
            name: 'mastra-studio',
            closeBundle() {
              const outDir = resolve(import.meta.dirname, 'dist')
              cpSync(studioDir, outDir, { recursive: true })

              const indexPath = join(outDir, 'index.html')
              const html = readFileSync(indexPath, 'utf-8')
              writeFileSync(
                indexPath,
                html.replaceAll(/%%(\w+)%%/g, (_, key) => env[key] ?? ''),
              )
            },
          },
        ],
        build: {
          emptyOutDir: true,
        },
      }
    })
    ```
  </StepItem>

  <StepItem>
    創建一個`.env` file with the necessary environment variables.

    ```env title=".env"
    MASTRA_SERVER_HOST=localhost
    MASTRA_SERVER_PORT=4111
    MASTRA_SERVER_PROTOCOL=http
    MASTRA_API_PREFIX=/api
    MASTRA_HIDE_CLOUD_CTA=false
    MASTRA_CLOUD_API_ENDPOINT=
    MASTRA_EXPERIMENTAL_FEATURES=false
    MASTRA_TEMPLATES=false
    MASTRA_TELEMETRY_DISABLED=true
    MASTRA_REQUEST_CONTEXT_PRESETS=
    MASTRA_EXPERIMENTAL_UI=false
    MASTRA_STUDIO_BASE_PATH=
    ```
  </StepItem>

  <StepItem>
    `dist` folder:

    ```bash npm2yarn
    npm run build
    ```
  </StepItem>

  <StepItem>
    將您的託管Provider指向`dist` folder and deploy!
  </StepItem>
</Steps>
