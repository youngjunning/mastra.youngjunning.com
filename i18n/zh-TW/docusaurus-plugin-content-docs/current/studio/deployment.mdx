# 工作室部署

Studio 是以 React 開發的單頁應用程式（SPA），會在瀏覽器中執行，並連到執行中的 [Mastra 伺服器](/docs/deployment/mastra-server)。

您可以透過兩種主要方式部署 Studio：

- 使用 Mastra 平台代管的 Studio，透過連結與團隊共用存取權。
- 在自己的基礎設施代管 Studio，與 Mastra 伺服器一起部署，或獨立部署為 SPA。

本頁說明如何在自有基礎設施部署 Studio。細節會因需求與環境而異，以下介紹通用原則及可用選項。

## 快速入門 {/* #quickstart */}

要啟動 Studio，最簡單的方式是使用 [`mastra studio`](/reference/cli/mastra#mastra-studio) 指令。

`mastra dev` 會一併啟動 Studio 和開發用 API。`mastra studio` 則提供獨立的靜態介面，連到已在執行的 Mastra 伺服器，因此可以單獨部署 Studio。

打開終端機並安裝`mastra` CLI globally:

```bash npm2yarn
npm install -g mastra
```

執行 `mastra studio` 指令：

```bash
mastra studio
```

在瀏覽器開啟 [localhost:3000](http://localhost:3000) 即可看到 Studio。預設會連到位於 `http://localhost:4111` 的 Mastra 伺服器。若無法連線，介面會顯示表單，讓你輸入 Mastra 執行個體的 URL 與 API 前綴。

這個指令使用 Node 內建的 `http` 模組與 [`serve-handler`](https://www.npmjs.com/package/serve-handler) 提供靜態檔案。

:::note

若將 Studio 代管在子路徑下，例如經 Nginx 代理的 `/agents`，請在啟動 Studio 前設定 `MASTRA_STUDIO_BASE_PATH`：

```bash
MASTRA_STUDIO_BASE_PATH=/agents mastra studio
```

這會更新 HTML 基本 URL 和靜態資源路由，以便獨立 Studio 在該子路徑下正常運作。

:::

## 馬斯特拉平台 {/* #mastra-platform */}

若要使用 Mastra 平台代管的 Studio，請參閱 [Mastra 平台上的 Studio](/docs/mastra-platform/studio)。

## 運行伺服器 {/* #running-a-server */}

將 `mastra studio` 做為常駐程序執行時，可沿用其他 Node.js 服務的部署方式和工具，例如用 PM2 或 Docker 管理程序，也能選用支援 Node.js 應用程式的雲端服務。和其他 Web 服務一樣，請正確設定 CORS 並監控錯誤。

:::warning

Studio 連到 Mastra 伺服器後，即可完整存取 Agent、Workflow 和 Tool。正式環境務必以身分驗證、VPN 等方式保護 Studio，防止未授權的存取。

更多資訊請參閱[身分驗證文件](/docs/studio/auth)。

:::

### 與 API 一起部署 {/* #alongside-your-api */}

也可以用 [Mastra 伺服器](/docs/deployment/mastra-server)一併提供 Studio，只需部署和管理一項服務。

執行 `mastra build` 時加上 `--studio` 旗標：

```bash
mastra build --studio
```

建置後，Studio 的靜態資源會放在 `.mastra/output/studio` 資料夾。設定環境變數 `MASTRA_STUDIO_PATH`，即可讓 Mastra 伺服器一併提供 Studio 介面。

```bash
MASTRA_STUDIO_PATH=.mastra/output/studio node .mastra/output/index.mjs
```

## 使用 CDN {/* #using-a-cdn */}

### 自動部署 {/* #automatic */}

部分[雲端服務供應商](/docs/deployment/cloud-providers)能將 Studio 與無伺服器函式一併部署。目前支援：

- [`VercelDeployer`](/reference/deployer/vercel)

### 手動部署 {/* #manual */}

Studio 介面依賴執行階段設定，無法直接將建置產物部署到 CDN。完成額外設定後，可以將建置產物做成獨立的 SPA，並部署到任一靜態代管服務。

請按照以下範例使用 Vite 建立 SPA。

<Steps>
  <StepItem>
    建立一個新資料夾並初始化一個新的 Node.js 專案：

    ```bash npm2yarn
    mkdir studio-spa
    cd studio-spa
    npm init
    ```
  </StepItem>

  <StepItem>
    安裝 `vite` 和 `mastra` 作為相依套件：

    ```bash npm2yarn
    npm install vite mastra
    ```
  </StepItem>

  <StepItem>
    在 `package.json` 加入建置指令碼：

    ```json title="package.json"
    {
      "scripts": {
        "build": "vite build"
      }
    }
    ```
  </StepItem>

  <StepItem>
    建立一個暫用的 `index.html` 檔案：

    ```html title="index.html"
    <!doctype html>
    <html>
      <head></head>
      <body></body>
    </html>
    ```
  </StepItem>

  <StepItem>
    建立 `vite.config.js` 檔案。這份設定會把建置後的 Studio 資源複製到 `dist` 資料夾，並以環境變數的值取代 HTML 中的所有 `%%PLACEHOLDER%%`。

    ```js title="vite.config.js"
    import { defineConfig, loadEnv } from 'vite'
    import { readFileSync, cpSync, writeFileSync } from 'node:fs'
    import { resolve, join } from 'node:path'

    const studioDir = resolve(import.meta.dirname, 'node_modules/mastra/dist/studio')

    export default defineConfig(({ mode }) => {
      const env = loadEnv(mode, process.cwd(), 'MASTRA_')

      return {
        plugins: [
          {
            name: 'mastra-studio',
            closeBundle() {
              const outDir = resolve(import.meta.dirname, 'dist')
              cpSync(studioDir, outDir, { recursive: true })

              const indexPath = join(outDir, 'index.html')
              const html = readFileSync(indexPath, 'utf-8')
              writeFileSync(
                indexPath,
                html.replaceAll(/%%(\w+)%%/g, (_, key) => env[key] ?? ''),
              )
            },
          },
        ],
        build: {
          emptyOutDir: true,
        },
      }
    })
    ```
  </StepItem>

  <StepItem>
    建立 `.env` 檔案，填入所需的環境變數。

    ```env title=".env"
    MASTRA_SERVER_HOST=localhost
    MASTRA_SERVER_PORT=4111
    MASTRA_SERVER_PROTOCOL=http
    MASTRA_API_PREFIX=/api
    MASTRA_HIDE_CLOUD_CTA=false
    MASTRA_CLOUD_API_ENDPOINT=
    MASTRA_EXPERIMENTAL_FEATURES=false
    MASTRA_TEMPLATES=false
    MASTRA_TELEMETRY_DISABLED=true
    MASTRA_REQUEST_CONTEXT_PRESETS=
    MASTRA_EXPERIMENTAL_UI=false
    MASTRA_STUDIO_BASE_PATH=
    ```
  </StepItem>

  <StepItem>
    執行建置指令碼，在 `dist` 資料夾產生靜態檔案：

    ```bash npm2yarn
    npm run build
    ```
  </StepItem>

  <StepItem>
    將代管服務的發布目錄設為 `dist`，然後部署。
  </StepItem>
</Steps>
