# 瀏覽器

瀏覽器讓 Agent 能瀏覽網站、操作頁面元素、填寫表單與擷取資料。Mastra 提供兩類瀏覽器 Provider：

- **SDK Provider** 封裝瀏覽器自動化程式庫，直接將瀏覽器 Tool 提供給 Agent。
- **CLI Provider** 啟動瀏覽器，由 Agent 透過命令列工具操作。

Mastra 內建三種 SDK Provider 和一種 CLI Provider：

- [**AgentBrowser**](/integrations/browsers/agent-browser)：以 Playwright 為基礎的 SDK Provider，使用無障礙資訊尋找頁面元素，適合一般網頁自動化和資料擷取。
- [**Stagehand**](/integrations/browsers/stagehand)：使用 Browserbase 的 Stagehand 程式庫，透過 AI 找到頁面元素。遇到複雜操作且自然語言比固定選擇器更好用時，可以選擇它。
- [**FirecrawlBrowser**](/integrations/browsers/firecrawl)：在代管的 Firecrawl Browser Sandbox 工作階段中執行 AgentBrowser Tool，不必自行架設瀏覽器。
- [**BrowserViewer**](/integrations/browsers/browser-viewer)：這個 CLI Provider 會啟動 Chrome，並將 Chrome DevTools Protocol（CDP）網址傳給 agent-browser、browser-use 和 browse 等 CLI 工具，適合透過 Shell 指令操控瀏覽器的 Workspace Agent。

## 何時使用瀏覽器 {/* #when-to-use-a-browser */}

Agent 若需要完成下列工作，可以為它設定瀏覽器：

- 瀏覽網站並與頁面元素交互
- 填寫並送出表單
- 從網頁中提取結構化數據
- 自動執行需要幾個步驟的 Web 任務
- 操作只能在實際瀏覽器中運作的頁面，例如透過 JavaScript 呈現內容或需要登入的頁面

## 它是如何運作的 {/* #how-it-works */}

為 Agent 設定瀏覽器後，Mastra 會將 Provider 的 Tool 加入 Agent 的工具組。Agent 可透過這些工具開啟網址、選取元素、輸入文字和讀取頁面內容。

各 Provider 提供配合自身操作方式的工具組。

## 快速入門 {/* #quickstart */}

先安裝選定的 Provider。以下範例使用 AgentBrowser。

```bash npm2yarn
npm install @mastra/agent-browser
```

建立一個新的瀏覽器實例：

```typescript title="src/mastra/browsers.ts"
import { AgentBrowser } from '@mastra/agent-browser'

export const browser = new AgentBrowser({
  headless: false,
})
```

將瀏覽器指派給Agent程式：

```typescript title="src/mastra/agents/web-agent.ts"
import { Agent } from '@mastra/core/agent'
import { browser } from '../browsers'

export const webAgent = new Agent({
  id: 'web-agent',
  name: 'Web Agent',
  description: 'A web automation assistant that can navigate websites and complete tasks.',
  model: '__GATEWAY_OPENAI_MODEL__',
  browser,
  instructions:
    'You are a web automation assistant. Use browser tools to navigate websites and complete tasks.',
})
```

Agent 會自動取得該 Provider 提供的所有瀏覽器 Tool。

## 雲端瀏覽器 Provider {/* #cloud-providers */}

所有 SDK Provider 都能連至雲端瀏覽器服務，不必啟動本機瀏覽器。

### Firecrawl Browser Sandbox（FirecrawlBrowser 原生支援） {/* #firecrawl-browser-sandbox-firecrawlbrowser-native */}

FirecrawlBrowser 透過 Firecrawl API 提供託管會話：

```typescript
import { FirecrawlBrowser } from '@mastra/browser-firecrawl'

const browser = new FirecrawlBrowser({
  apiKey: process.env.FIRECRAWL_API_KEY,
})
```

### Browserbase（Stagehand 原生支援） {/* #browserbase-stagehand-native */}

Stagehand 具有原生 Browserbase 整合：

```typescript
import { StagehandBrowser } from '@mastra/stagehand'

const browser = new StagehandBrowser({
  env: 'BROWSERBASE',
  apiKey: process.env.BROWSERBASE_API_KEY,
  projectId: process.env.BROWSERBASE_PROJECT_ID,
})
```

### Browser Use Cloud（AgentBrowser CDP） {/* #browser-use-cloud-agentbrowser-cdp */}

使用 Browser Use API 金鑰，將 AgentBrowser 連到 [Browser Use Cloud 瀏覽器](https://github.com/browser-use/browser-use/blob/main/skills/cloud/references/browser-api.md)：

```typescript
import { AgentBrowser } from '@mastra/agent-browser'

const browser = new AgentBrowser({
  cdpUrl: `wss://connect.browser-use.com?apiKey=${process.env.BROWSER_USE_API_KEY}`,
})
```

### CDP URL（任何Provider） {/* #cdp-url-any-provider */}

連接到公開 Chrome DevTools 協定 (CDP) 端點的任何瀏覽器：

```typescript
import { AgentBrowser } from '@mastra/agent-browser'

const browser = new AgentBrowser({
  cdpUrl: process.env.BROWSER_CDP_URL,
  headless: true,
})
```

任何[與 CDP 相容](https://chromedevtools.github.io/devtools-protocol/)的瀏覽器服務都適用。

## 即時畫面 {/* #screencast */}

瀏覽器 Provider 會將瀏覽器畫面串流到 Mastra Studio，讓你即時看到 Agent 如何操作頁面。

即時畫面需要 WebSocket 支援。請在專案中安裝下列套件：

```bash npm2yarn
npm install ws @hono/node-ws
```

:::note

這些套件與 Cloudflare Workers 等無伺服器環境不相容，因此預設不包含。未安裝時不會顯示即時畫面，其餘瀏覽器功能仍可正常使用。

:::

即時畫面預設開啟，可依需求設定：

```typescript
const browser = new AgentBrowser({
  screencast: {
    format: 'jpeg',
    quality: 80,
    maxWidth: 1280,
    maxHeight: 720,
  },
})
```

## 錄製瀏覽器工作階段 {/* #record-browser-sessions */}

AgentBrowser 和 StagehandBrowser 可選擇開啟錄影，方便回顧、分享或偵錯。設定 `outputDir` 即可加入錄影工具：

```typescript title="src/mastra/browsers.ts"
import { join } from 'node:path'
import { AgentBrowser } from '@mastra/agent-browser'

export const browser = new AgentBrowser({
  recording: {
    outputDir: join(process.cwd(), 'browser-recordings'),
  },
})
```

StagehandBrowser 支援相同的 `recording` 選項。Agent 使用 `browser_record` 開始、查詢或停止錄影，並以 `browser_record_caption` 標示重要操作。停止時會儲存影片，Agent 可以傳回檔案路徑。自訂 `outputPath` 可為絕對路徑或相對於目前工作目錄的路徑，但解析後必須位在 `recording.outputDir` 內。

錄影採用 Motion-JPEG AVI，不需要 `ffmpeg`。預設最長 30 秒，上限為 120 秒。預設畫面最大為 1024 × 720，字幕最多 80 個字元，每個程序一次只能錄製一段。
