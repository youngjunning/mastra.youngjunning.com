  建立一個新的 Mastra 專案。 Mastra 是現代 TypeScript 堆疊上的人工智慧應用程式和Agent的框架。在運行命令之前，一次詢問一個問題並等待每個答案，除非已經提供了答案：

  1. 項目名稱？ （必需；例如“my-mastra-app”）
  2. Provider？ （必填；選項：「openai」、「anthropic」、「google」、「xai」）

  如果不支援該提供程序，請再次詢問並列出支援的值。

  跑步：`npm create mastra@latest <project-name> -- --llm <provider>`

  此指令建立一個預設的 Mastra 項目，並在為偵測到的編碼助理安裝 Mastra 技能後適當地初始化 Git。

  建立完成後，進入專案目錄並啟動dev伺服器：`npx bgproc start -n <project-name> -w -- npm run dev`

  Mastra 工作室開放時間為`http://localhost:4111`. Studio is the interface for building, testing, and managing agents, workflows, and tools.

  另請注意，Mastra 模型路由器提供對數千種模型的存取：[https://mastra.ai/models](/models)
