  建立新的 Mastra 專案。Mastra 是以現代 TypeScript 技術堆疊開發 AI 應用程式和 Agent 的框架。執行指令前，請依序詢問下列問題，每次等使用者回答後再繼續。已回答的問題可略過：

  1. 專案名稱是什麼？（必填，例如「my-mastra-app」）

  建立完成後，切換到專案目錄並啟動開發伺服器：`npx bgproc start -n <project-name> -w -- npm run dev`

  前往 `http://localhost:4111` 開啟 Mastra Studio。你可以在 Studio 裡建立、測試及管理 Agent、Workflow 和 Tool。
