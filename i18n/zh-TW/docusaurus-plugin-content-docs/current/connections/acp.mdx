# Agent Client Protocol

Mastra 支援 [Agent Client Protocol (ACP)](https://agentclientprotocol.com/overview/introduction)，讓 Mastra Agent 呼叫相容的程式開發 Agent。透過 `@mastra/acp`，可將該程序封裝成 Mastra Tool 或子 Agent。

Claude Code、Cline、OpenCode、Amp、Codex 等程式開發 Agent 都可使用 ACP；任何透過標準輸入與輸出實作 ACP 的執行檔也適用。

## 何時使用 ACP {/* #when-to-use-acp */}

- Mastra Agent 需要將程式碼檢查、編輯或儲存庫作業委派給外部程式開發 Agent。
- 相容 ACP 的 Agent 程序需要在多次呼叫間繼續運作，以保留工作階段的上下文。
- 上層 Agent 需要在任務執行期間即時接收程式開發 Agent 的輸出。
- 相容 ACP 的 Agent 需要在讀寫檔案或執行動作前提示授權。
- 檔案存取需要經過 Mastra 的 Workspace 抽象層，而非直接由程序存取。

## ACP 的工作原理 {/* #how-acp-works */}

`@mastra/acp` 會將指定的 ACP Agent 指令啟動為子程序，雙方透過標準輸入與輸出交換以換行字元分隔的 JSON。

流程如下：

1. 設定 `command`、`args` 及選用的連線設定。
2. `@mastra/acp` 在首次使用時啟動 ACP Agent 程序。
3. 用戶端送出 ACP 的 `initialize` 與 `session/new` 請求。
4. Mastra 透過 `session/prompt` 把使用者的任務交給 ACP Agent。
5. ACP Agent 將工作階段更新和訊息片段以串流傳回 Mastra。
6. Mastra 傳回緩衝的輸出、送出串流片段，或處理權限選擇。
7. `persistSession` 為 `false` 時，ACP 連線會在提示處理完畢後停止程序。預設情況下，`AcpAgent` 可讓程序在呼叫之間繼續執行，供下次使用。

執行期間，ACP 用戶端也會處理權限請求與檔案操作。Agent 透過協定發出的檔案讀寫請求會經過 Mastra 的 `Workspace`。Workspace 僅涵蓋這些請求：Agent 程序會在設定的 `cwd` 下執行，沒有沙箱或其他隔離，仍可透過自己的工具和 Shell 指令存取檔案。

## 相容的 Agent {/* #compatible-agents */}

只要可執行檔透過標準輸入與輸出實作 ACP，就能搭配 `@mastra/acp` 使用，不必為每個 Agent 安裝專屬的 Mastra 套件。安裝 Agent 後，以 `command` 和 `args` 傳入啟動指令。

| Agent | `command` | `args` |
| - | - | - |
| Cline | `cline` | `['--acp']` |
| OpenCode | `opencode` | `['acp']` |
| Gemini CLI | `gemini` | `['--acp']` |

各 Agent 的文件會說明各自的 ACP 模式，啟動旗標也可能隨版本變更。請參閱 [Cline ACP](https://docs.cline.bot/usage/acp) 或 [OpenCode ACP](https://opencode.ai/docs/acp/) 等文件，確認目前的指令。

## 入門 {/* #getting-started */}

在已使用 `@mastra/core` 的專案安裝 `@mastra/acp`。此套件需要 `@mastra/core` `1.34.0` 以上版本。

```bash npm2yarn
npm install @mastra/acp
```

`@mastra/acp` 匯出兩個 API：

- [`createACPTool()`](/reference/acp/create-acp-tool)：建立 Mastra Tool，將 `task` 字串送給 ACP Agent，並傳回 `output` 字串。
- [`AcpAgent`](/reference/acp/acp-agent)：將 ACP Agent 封裝為 Mastra 子 Agent，支援 `generate()` 與 `stream()`。

## 將 ACP 用作子 Agent {/* #use-acp-as-a-subagent */}

若上層 Mastra Agent 要直接把任務委派給相容 ACP 的程式開發子 Agent，請使用 `AcpAgent`。

```typescript title="src/mastra/agents/code-supervisor.ts"
import { AcpAgent } from '@mastra/acp'
import { Agent } from '@mastra/core/agent'

const codeAgent = new AcpAgent({
  id: 'code-agent',
  name: 'Code Agent',
  description: 'An ACP-compatible coding agent that can inspect and edit files',
  command: 'opencode',
  args: ['acp'],
  cwd: process.cwd(),
})

export const codeSupervisor = new Agent({
  id: 'code-supervisor',
  name: 'Code Supervisor',
  instructions: 'Delegate code editing tasks to the code-agent subagent.',
  model: '__GATEWAY_OPENAI_MODEL__',
  agents: {
    codeAgent,
  },
})
```

完整選項、方法與設定請見 [AcpAgent 參考文件](/reference/acp/acp-agent)。

## 將 ACP 用作 Tool {/* #use-acp-as-a-tool */}

若要由上層 Mastra Agent 決定何時呼叫作為 Tool 的 ACP Agent，請使用 `createACPTool()`。

```typescript title="src/mastra/agents/code-supervisor.ts"
import { createACPTool } from '@mastra/acp'
import { Agent } from '@mastra/core/agent'

const codeAgentTool = createACPTool({
  id: 'code-agent',
  description: 'Use an ACP-compatible coding agent to inspect and edit code',
  command: 'opencode',
  args: ['acp'],
  cwd: process.cwd(),
})

export const codeSupervisor = new Agent({
  id: 'code-supervisor',
  name: 'Code Supervisor',
  instructions: 'Use the code-agent tool when a task requires repository inspection or code edits.',
  model: '__GATEWAY_OPENAI_MODEL__',
  tools: {
    codeAgentTool,
  },
})
```

完整選項與設定請見 [createACPTool() 參考文件](/reference/acp/create-acp-tool)。

## 選擇模型 {/* #model-selection */}

ACP Agent 可能提供可選的模型。在 ACP 設定中傳入 `model`，即可在建立工作階段後選擇模型；也可在執行期間透過 `AcpAgent.getAvailableModels()` 與 `AcpAgent.setModel()` 管理模型。

範例請見 [AcpAgent 的模型管理方法](/reference/acp/acp-agent#model-management)。

## 會話生命週期 {/* #session-lifecycle */}

`AcpAgent` 第一次使用時會執行設定的指令，並建立 ACP 工作階段。`persistSession` 預設為 `true`，子程序會在呼叫之間持續執行。若要讓每次提示各自使用獨立的程序，請設定 `persistSession: false`。

詳細說明請見 [AcpAgent 工作階段生命週期](/reference/acp/acp-agent#session-lifecycle)。

## 權限處理 {/* #permission-handling */}

ACP Agent 可能要求用戶端先選擇權限選項再繼續。`@mastra/acp` 預設選擇 ACP Agent 傳回的第一個選項。若要自訂權限處理方式，請傳入 `onPermissionRequest`。

完整範例請見 [createACPTool() 的權限處理](/reference/acp/create-acp-tool#permission-handling)。

## 與 Workspace 整合 {/* #workspace-integration */}

ACP 的檔案請求會經過 Mastra 的 Workspace 抽象層。`AcpAgent` 可指定 `workspace`；若 Tool 的執行環境提供目前的 Mastra Workspace，`createACPTool()` 就會使用它。沒有 Workspace 時，`@mastra/acp` 會改用由 `LocalFilesystem` 支援的 `Workspace`，根目錄為 `cwd` 或 `process.cwd()`。

自訂 Workspace 的範例請見 [AcpAgent 的 Workspace 整合](/reference/acp/acp-agent#workspace-integration)。
