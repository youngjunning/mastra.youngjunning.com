# 連線

透過連線，Mastra 可以搭配遠端 Agent、程式開發 Agent、提供者的軟體開發套件（SDK）執行階段，以及外部 Tool 和資源。請依管理 Agent 執行階段的系統及要交換的內容，選擇連線類型。

- [**模型上下文協定（MCP）**](/docs/connections/mcp)：讓 Agent 連接外部 Tool 與資源，或讓相容 MCP 的系統使用 Mastra 的 Agent、Tool、Workflow、提示與資源。
- [**Agent 對 Agent（A2A）**](/docs/connections/a2a)：跨服務、框架、供應商和程式語言提供或使用遠端 Agent。
- [**Agent 用戶端協定（ACP）**](/docs/connections/acp)：執行 Claude Code、Cline 或 OpenCode 等相容的程式開發 Agent 處理程序，作為 Mastra Tool 或子 Agent 使用。
- [**SDK Agent**](/docs/connections/sdk-agents)：註冊以 Claude、Cursor 或 OpenAI SDK 為基礎的 Agent，其執行階段、Tool、權限和 Agent 迴圈仍由提供者的 SDK 控管。

## 何時使用連線 {/* #when-to-use-connections */}

有下列需求時，可使用連線：

- 將工作交給在其他服務或執行階段中運作的 Agent。
- 讓程式開發 Agent 在專案的 Workspace 中運作。
- 加入提供者的原生 Agent，同時保留其 SDK 執行階段與 Agent 迴圈。
- 讓 Agent 連接外部 Tool 與資源，或將 Mastra 功能提供給其他系統使用。

## 開始使用 {/* #get-started */}

先確認要連接哪一類系統。遠端 Agent 端點使用 [A2A](/docs/connections/a2a)，程式開發 Agent 的處理程序使用 [ACP](/docs/connections/acp)，由提供者管理的執行階段使用 [SDK Agent](/docs/connections/sdk-agents)，Tool 與資源則使用 [MCP](/docs/connections/mcp)。

<Tabs>
  <TabItem value="a2a" label="A2A">
    ```typescript
    import { A2AAgent } from '@mastra/core/a2a'

    const agent = new A2AAgent({
      url: 'https://agent.example.com/.well-known/agent-card.json',
    })

    const result = await agent.generate('Summarize the latest report')
    console.log(result.text)
    ```
  </TabItem>

  <TabItem value="acp" label="ACP">
    ```typescript
    import { AcpAgent } from '@mastra/acp'

    const agent = new AcpAgent({
      id: 'coding-agent',
      description: 'Inspects and edits code',
      command: 'claude',
      args: ['--acp'],
      persistSession: false,
    })

    const result = await agent.generate('Review this project')
    console.log(result.text)
    ```
  </TabItem>

  <TabItem value="sdk-agents" label="SDK agents">
    ```typescript
    import { OpenAISDKAgent } from '@mastra/openai'

    const agent = new OpenAISDKAgent({
      id: 'openai-agent',
      description: 'Answers project questions',
      sdkOptions: {
        name: 'Project assistant',
        model: '__AI_SDK_OPENAI_MODEL_BASE__',
      },
    })

    const result = await agent.generate('Explain agent loops in one sentence')
    console.log(result.text)
    ```
  </TabItem>

  <TabItem value="mcp" label="MCP">
    ```typescript
    import { MCPClient } from '@mastra/mcp'

    const client = new MCPClient({
      id: 'wikipedia-client',
      servers: {
        wikipedia: {
          command: 'npx',
          args: ['-y', 'wikipedia-mcp'],
        },
      },
    })

    try {
      const tools = await client.listTools()
      console.log(Object.keys(tools))
    } finally {
      await client.disconnect()
    }
    ```
  </TabItem>
