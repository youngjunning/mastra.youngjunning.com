# 馬斯特拉客戶

Mastra Client SDK 提供了一個簡潔且類型安全的介面，用於與您的交互[Mastra Server](/docs/server/overview)來自您的客戶端環境。

## 先決條件 {/* #prerequisites */}

在開始本地開發之前，請先：

* Node.js`v22.13.0` or later
* 打字稿`v4.7` or higher (if using TypeScript)
* 您的本地 Mastra 伺服器正在運行（通常在連接埠`4111`)



`fetch` API for making HTTP requests to your Mastra server.

:::

## 安裝 {/* #installation */}

若要使用 Mastra Client SDK，請安裝所需的依賴項：

```bash npm2yarn
npm install @mastra/client-js@latest
```

### 初始化`MastraClient` {/* #initialize-the-mastraclient */}

一旦用a初始化`baseUrl`, `MastraClient` exposes a type-safe interface for calling agents, tools, and workflows.

```typescript title="lib/mastra-client.ts"
import { MastraClient } from '@mastra/client-js'

export const mastraClient = new MastraClient({
  baseUrl: process.env.MASTRA_API_URL || 'http://localhost:4111',
})
```

## 核心API {/* #core-apis */}

Mastra 用戶端 SDK 公開了 Mastra 伺服器提供的所有資源。

* **[Agent商](/reference/client-js/agents)**：產生回應並串流對話。
* **[A2A](/docs/connections/a2a)**：透過座席卡發現座席並使用基於任務的 A2A 流。
* **[記憶](/reference/client-js/memory)**：管理對話線程和訊息歷史記錄。
* **[Tool](/reference/client-js/tools)**：執行和管理的Tool。
* **[Workflow](/reference/client-js/workflows)**：觸發Workflow並追蹤其執行情況。
* **[向量](/reference/client-js/vectors)**：使用向量嵌入進行語義搜尋。
* **[回應](/reference/client-js/responses)**：使用 Mastra Agents 作為具有 OpenAI 相容、Agent支援的介面的回應 API。該 API 目前處於實驗階段。
* **[對話](/reference/client-js/conversations)**：使用 Mastra Agents 背後儲存的對話線程和專案歷史記錄作為回應 API。該 API 目前處於實驗階段。
* **[紀錄](/reference/client-js/logs)**：查看日誌並調試系統行為。
* **[可觀察性](/reference/client-js/observability)**

## 建立並執行動態Workflow {/* #create-and-run-dynamic-workflows */}

使用`upsertDynamicWorkflow()` to create or replace a persisted workflow definition. A successful upsert validates the complete definition and registers it with the running Mastra instance. The workflow then becomes available through the standard execution API.

以下範例顯示了映射Workflow的完整生命週期，從建立和檢查到執行和刪除：

```typescript title="lib/dynamic-workflow.ts"
import { MastraClient } from '@mastra/client-js'
import type { UpsertDynamicWorkflowParams } from '@mastra/client-js'

const client = new MastraClient({
  baseUrl: process.env.MASTRA_API_URL || 'http://localhost:4111',
})

const definition = {
  id: 'greeting-workflow',
  description: 'Returns a greeting for the supplied name',
  inputSchema: {
    type: 'object',
    properties: { name: { type: 'string' } },
    required: ['name'],
  },
  outputSchema: {
    type: 'object',
    properties: { message: { type: 'string' } },
    required: ['message'],
  },
  graph: [
    {
      type: 'mapping',
      id: 'create-greeting',
      mapConfig: JSON.stringify({
        message: { template: 'Hello, ${initData.name}!' },
      }),
    },
  ],
} satisfies UpsertDynamicWorkflowParams

await client.upsertDynamicWorkflow(definition)

const dynamicWorkflow = client.getDynamicWorkflow(definition.id)
const dynamicDefinition = await dynamicWorkflow.details()

const workflow = client.getWorkflow(dynamicDefinition.id)
const run = await workflow.createRun()
const result = await run.startAsync({ inputData: { name: 'Ada' } })

console.log(result)

await dynamicWorkflow.delete()
```

使用`listDynamicWorkflows()` to list persisted definitions. Calling `upsertDynamicWorkflow()` again with the same `id` replaces the stored definition and live workflow registration.

：：：警告

持久性儲存需要配置支援以下功能的儲存適配器`workflowDefinitions` domain. Without that domain, Core can register a workflow in memory, but the server's dynamic-workflow API can't preserve it across restarts.

儲存的定義支援聲明性Agent、Tool、映射、巢狀Workflow、並行、foreach、睡眠、睡眠直到、條件和循環條目。它們不能包含 JavaScript 閉包。條件和迴圈邏輯必須使用聲明性謂詞格式，且引用的Agent、Tool和巢狀Workflow必須已註冊。

經過身份驗證的伺服器需要`stored-workflows:read` or `stored-workflows:write` for definition operations and `workflows:execute` to run the workflow.

## 產生回應 {/* #generating-responses */}

稱呼`.generate()` with a string prompt:

```typescript
import { mastraClient } from 'lib/mastra-client'

const testAgent = async () => {
  try {
    const agent = mastraClient.getAgent('testAgent')

    const response = await agent.generate('Hello')

    console.log(response.text)
  } catch (error) {
    return 'Error occurred while generating response'
  }
}
```



您也可以致電`.generate()` with an array of message objects that include `role` and `content`. Visit the [.generate() reference](/reference/client-js/agents#generate) for more information.

:::

## 串流回應 {/* #streaming-responses */}

使用`.stream()` for real-time responses with a string prompt:

```typescript
import { mastraClient } from 'lib/mastra-client'

const testAgent = async () => {
  try {
    const agent = mastraClient.getAgent('testAgent')

    const stream = await agent.stream('Hello')

    stream.processDataStream({
      onTextPart: text => {
        console.log(text)
      },
    })
  } catch (error) {
    return 'Error occurred while generating response'
  }
}
```



您也可以致電`.stream()` with an array of message objects that include `role` and `content`. Visit the [.stream() reference](/reference/client-js/agents#stream) for more information.

:::

## 配置選項 {/* #configuration-options */}

`MastraClient`接受可選參數，例如`retries`, `backoffMs`, and `headers` to control request behavior. These parameters are useful for controlling retry behavior and including diagnostic metadata.

```typescript title="lib/mastra-client.ts"
import { MastraClient } from '@mastra/client-js'

export const mastraClient = new MastraClient({
  retries: 3,
  backoffMs: 300,
  maxBackoffMs: 5000,
  headers: {
    'X-Development': 'true',
  },
})
```

訪問[MastraClient](/reference/client-js/mastra-client) for more configuration options.

## 憑證和會話 cookie {/* #credentials-and-session-cookies */}

**使用會話 cookie 驗證 Mastra API 呼叫**當您的 UI 和 Mastra API 不在同一來源、不同主機、子網域或連接埠時（例如，Mastra Studio 在一個連接埠上，而自訂伺服器在另一個連接埠上）。添&#x52A0;**`credentials: 'include'`** to `MastraClient` so each request carries the cookies the user already has after sign-in. Skip this and you will often get **`401`** responses from Mastra even though login succeeded in the browser.

```typescript title="lib/mastra-client.ts"
import { MastraClient } from '@mastra/client-js'

export const mastraClient = new MastraClient({
  baseUrl: process.env.MASTRA_API_URL || 'http://localhost:4111',
  credentials: 'include',
})
```

**允許伺服器上經過憑證的跨來源請求**， 看[CORS: requests with credentials](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/CORS#requests_with_credentials). You need a concrete `Access-Control-Allow-Origin` (not `*`) and `Access-Control-Allow-Credentials: true`, or the browser will block the call before it reaches Mastra.

**使用`@mastra/react`?**&#x5305;裝你的應用程式`MastraReactProvider`, set `baseUrl` and `apiPrefix` to match your server, and rely on the default `credentials: 'include'`. Change `credentials` only when you want `same-origin` or `omit` behavior.

## 新增取消請求 {/* #adding-request-cancelling */}

`MastraClient``AbortSignal` API. Useful for canceling in-flight requests, such as when users abort an operation or to clean up stale network calls.

透過一個`AbortSignal` to the client constructor to enable cancellation across all requests.

```typescript {3,7} title="lib/mastra-client.ts"
import { MastraClient } from '@mastra/client-js'

export const controller = new AbortController()

export const mastraClient = new MastraClient({
  baseUrl: process.env.MASTRA_API_URL || 'http://localhost:4111',
  abortSignal: controller.signal,
})
```

### 使用`AbortController` {/* #using-the-abortcontroller */}

呼喚`.abort()` will cancel any ongoing requests tied to that signal.

```typescript
import { mastraClient, controller } from 'lib/mastra-client'

const handleAbort = () => {
  controller.abort()
}
```

## 客戶端Tool {/* #client-tools */}

使用以下命令直接在客戶端應用程式中定義Tool`createTool()` function. Pass them to agents via the `clientTools` parameter in `.generate()` or `.stream()` calls.

這使得Agent程式可以觸發瀏覽器端功能，例如 DOM 操作、本機儲存存取或其他 Web API，從而使Tool能夠在使用者環境中而不是在伺服器上執行。

```typescript {26}
import { createTool } from '@mastra/client-js'
import { z } from 'zod'

const handleClientTool = async () => {
  try {
    const agent = mastraClient.getAgent('colorAgent')

    const colorChangeTool = createTool({
      id: 'color-change-tool',
      description: 'Changes the HTML background color',
      inputSchema: z.object({
        color: z.string(),
      }),
      outputSchema: z.object({
        success: z.boolean(),
      }),
      execute: async inputData => {
        const { color } = inputData

        document.body.style.backgroundColor = color
        return { success: true }
      },
    })

    const response = await agent.generate('Change the background to blue', {
      clientTools: { colorChangeTool },
    })

    console.log(response)
  } catch (error) {
    console.error(error)
  }
}
```

### 客戶端ToolAgent {/* #client-tool-agent */}

這是標準的瑪斯特拉[agent](../agents/overview#quickstart) configured to return hex color codes, intended to work with the browser-based client tool defined above.

```typescript title="src/mastra/agents/color-agent"
import { Agent } from '@mastra/core/agent'

export const colorAgent = new Agent({
  id: 'color-agent',
  name: 'Color Agent',
  instructions: `You are a helpful CSS assistant.
  You can change the background color of web pages.
  Respond with a hex reference for the color requested by the user`,
  model: '__GATEWAY_OPENAI_MODEL__',
})
```

## 在伺服器上使用 MastraClient {/* #use-mastraclient-on-the-server */}

伺服器端 API 路由和無伺服器功能（包括操作）也可以使用`MastraClient`. The usage is unchanged, although you may need to recreate the response for your client:

```typescript {8}
export async function action() {
  const agent = mastraClient.getAgent('testAgent')

  const stream = await agent.stream('Hello')

  return new Response(stream.body)
}
```
