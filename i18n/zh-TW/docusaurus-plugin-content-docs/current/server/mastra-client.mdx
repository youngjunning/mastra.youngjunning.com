# Mastra 用戶端

Mastra Client SDK 提供簡潔且型別安全的介面，讓你在用戶端與 [Mastra Server](/docs/server/overview) 互動。

## 先決條件 {/* #prerequisites */}

開始在本機開發前，請確認：

- Node.js `v22.13.0` 或更新版本
- TypeScript `v4.7` 或更新版本（若使用 TypeScript）
- 本機 Mastra 伺服器已啟動（通常使用連接埠 `4111`）

:::note

Mastra Client SDK 專為瀏覽器環境設計，使用瀏覽器原生的 `fetch` API 向 Mastra 伺服器送出 HTTP 請求。

:::

## 安裝 {/* #installation */}

使用 Mastra Client SDK 前，請先安裝所需的相依套件：

```bash npm2yarn
npm install @mastra/client-js@latest
```

### 初始化 `MastraClient` {/* #initialize-the-mastraclient */}

以 `baseUrl` 初始化後，`MastraClient` 會提供型別安全的介面，供你呼叫 Agent、Tool 和 Workflow。

```typescript title="lib/mastra-client.ts"
import { MastraClient } from '@mastra/client-js'

export const mastraClient = new MastraClient({
  baseUrl: process.env.MASTRA_API_URL || 'http://localhost:4111',
})
```

## 核心 API {/* #core-apis */}

透過 Mastra Client SDK，可以存取 Mastra 伺服器提供的所有資源。

- **[Agent](/reference/client-js/agents)**：產生回應並串流傳送對話。
- **[A2A](/docs/connections/a2a)**：透過 Agent 卡片探索 Agent，並使用以工作為基礎的 A2A 串流。
- **[Memory](/reference/client-js/memory)**：管理對話執行緒與歷史訊息。
- **[Tool](/reference/client-js/tools)**：執行和管理 Tool。
- **[Workflow](/reference/client-js/workflows)**：觸發 Workflow 並追蹤執行情形。
- **[向量](/reference/client-js/vectors)**：使用嵌入向量進行語意搜尋。
- **[Responses](/reference/client-js/responses)**：透過與 OpenAI 相容的介面，將 Mastra Agent 用作 Responses API。這項 API 目前仍在實驗階段。
- **[Conversations](/reference/client-js/conversations)**：將 Mastra Agent 用作 Responses API 時，可存取其儲存的對話執行緒與對話項目歷程。這項 API 目前仍在實驗階段。
- **[日誌](/reference/client-js/logs)**：檢視日誌並對系統行為進行偵錯。
- **[可觀測性](/reference/client-js/observability)**：檢視應用程式效能與追蹤活動。

## 建立並執行動態 Workflow {/* #create-and-run-dynamic-workflows */}

使用 `upsertDynamicWorkflow()` 建立或取代持久儲存的 Workflow 定義。操作成功時，系統會驗證完整定義，並將其註冊到正在執行的 Mastra 執行個體。接著便能透過標準執行 API 執行該 Workflow。

以下範例示範映射 Workflow 的完整生命週期，包括建立、檢視、執行和刪除：

```typescript title="lib/dynamic-workflow.ts"
import { MastraClient } from '@mastra/client-js'
import type { UpsertDynamicWorkflowParams } from '@mastra/client-js'

const client = new MastraClient({
  baseUrl: process.env.MASTRA_API_URL || 'http://localhost:4111',
})

const definition = {
  id: 'greeting-workflow',
  description: 'Returns a greeting for the supplied name',
  inputSchema: {
    type: 'object',
    properties: { name: { type: 'string' } },
    required: ['name'],
  },
  outputSchema: {
    type: 'object',
    properties: { message: { type: 'string' } },
    required: ['message'],
  },
  graph: [
    {
      type: 'mapping',
      id: 'create-greeting',
      mapConfig: JSON.stringify({
        message: { template: 'Hello, ${initData.name}!' },
      }),
    },
  ],
} satisfies UpsertDynamicWorkflowParams

await client.upsertDynamicWorkflow(definition)

const dynamicWorkflow = client.getDynamicWorkflow(definition.id)
const dynamicDefinition = await dynamicWorkflow.details()

const workflow = client.getWorkflow(dynamicDefinition.id)
const run = await workflow.createRun()
const result = await run.startAsync({ inputData: { name: 'Ada' } })

console.log(result)

await dynamicWorkflow.delete()
```

使用 `listDynamicWorkflows()` 列出已持久儲存的定義。再次以相同的 `id` 呼叫 `upsertDynamicWorkflow()`，會取代已儲存的定義和執行中註冊的 Workflow。

:::warning

持久儲存需要設定支援 `workflowDefinitions` 網域的儲存配接器。缺少該網域時，Core 仍可在記憶體中註冊 Workflow，但伺服器的動態 Workflow API 無法在重新啟動後保留它。

已儲存的定義支援宣告式的 Agent、Tool、映射、巢狀 Workflow、平行執行、foreach、sleep、sleep-until、條件與迴圈項目。定義不可包含 JavaScript 閉包。條件與迴圈邏輯必須使用宣告式述詞格式，參照的 Agent、Tool 和巢狀 Workflow 也必須先註冊。

伺服器啟用身分驗證時，操作定義需要 `stored-workflows:read` 或 `stored-workflows:write` 權限，執行 Workflow 則需要 `workflows:execute`。

:::

## 產生回應 {/* #generating-responses */}

將字串提示傳入 `.generate()`：

```typescript
import { mastraClient } from 'lib/mastra-client'

const testAgent = async () => {
  try {
    const agent = mastraClient.getAgent('testAgent')

    const response = await agent.generate('Hello')

    console.log(response.text)
  } catch (error) {
    return 'Error occurred while generating response'
  }
}
```

:::note

呼叫 `.generate()` 時也可以傳入訊息物件陣列，每個物件都包含 `role` 和 `content`。詳情請參閱 [.generate() 參考](/reference/client-js/agents#generate)。

:::

## 串流回應 {/* #streaming-responses */}

將字串提示傳入 `.stream()`，即可即時接收回應：

```typescript
import { mastraClient } from 'lib/mastra-client'

const testAgent = async () => {
  try {
    const agent = mastraClient.getAgent('testAgent')

    const stream = await agent.stream('Hello')

    stream.processDataStream({
      onTextPart: text => {
        console.log(text)
      },
    })
  } catch (error) {
    return 'Error occurred while generating response'
  }
}
```

:::note

呼叫 `.stream()` 時也可以傳入訊息物件陣列，每個物件都包含 `role` 和 `content`。詳情請參閱 [.stream() 參考](/reference/client-js/agents#stream)。

:::

## 設定選項 {/* #configuration-options */}

`MastraClient` 接受 `retries`、`backoffMs` 和 `headers` 等選用參數，可以控制請求行為，例如設定重試或附加診斷中繼資料。

```typescript title="lib/mastra-client.ts"
import { MastraClient } from '@mastra/client-js'

export const mastraClient = new MastraClient({
  retries: 3,
  backoffMs: 300,
  maxBackoffMs: 5000,
  headers: {
    'X-Development': 'true',
  },
})
```

更多設定選項請參閱 [MastraClient](/reference/client-js/mastra-client)。

## 憑證與工作階段 Cookie {/* #credentials-and-session-cookies */}

UI 和 Mastra API 不同來源（主機、子網域或連接埠不同）時，例如 Mastra Studio 和自訂伺服器分別使用不同連接埠，可 **使用工作階段 Cookie 驗證 Mastra API 請求**。在 `MastraClient` 加上 **`credentials: 'include'`**，讓每個請求都帶上使用者登入後已有的 Cookie。未設定時，即使已在瀏覽器成功登入，仍常收到 Mastra 的 **`401`** 回應。

```typescript title="lib/mastra-client.ts"
import { MastraClient } from '@mastra/client-js'

export const mastraClient = new MastraClient({
  baseUrl: process.env.MASTRA_API_URL || 'http://localhost:4111',
  credentials: 'include',
})
```

**在伺服器上允許帶有憑證的跨來源請求**。請參閱 [CORS：帶有憑證的請求](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/CORS#requests_with_credentials)。請為 `Access-Control-Allow-Origin` 指定明確來源（不可用 `*`），並設定 `Access-Control-Allow-Credentials: true`，否則瀏覽器會在請求到達 Mastra 前封鎖它。

**如果使用 `@mastra/react`**，請以 `MastraReactProvider` 包住應用程式，將 `baseUrl` 和 `apiPrefix` 設成與伺服器相符，並採用預設的 `credentials: 'include'`。只有需要 `same-origin` 或 `omit` 行為時，才調整 `credentials`。

## 加入請求取消功能 {/* #adding-request-cancelling */}

`MastraClient` 透過 Node.js 標準的 `AbortSignal` API 支援取消請求。例如，使用者中止操作時可取消進行中的請求，也可以清理已失效的網路請求。

將 `AbortSignal` 傳入用戶端建構函式，就能讓所有請求都能取消。

```typescript {3,7} title="lib/mastra-client.ts"
import { MastraClient } from '@mastra/client-js'

export const controller = new AbortController()

export const mastraClient = new MastraClient({
  baseUrl: process.env.MASTRA_API_URL || 'http://localhost:4111',
  abortSignal: controller.signal,
})
```

### 使用 `AbortController` {/* #using-the-abortcontroller */}

呼叫 `.abort()` 會取消與該訊號相連的所有進行中請求。

```typescript
import { mastraClient, controller } from 'lib/mastra-client'

const handleAbort = () => {
  controller.abort()
}
```

## 用戶端 Tool {/* #client-tools */}

使用 `createTool()` 函式直接在用戶端應用程式中定義 Tool。呼叫 `.generate()` 或 `.stream()` 時，透過 `clientTools` 參數將這些 Tool 傳給 Agent。

如此一來，Agent 就能觸發瀏覽器功能，例如操作 DOM、存取本機儲存空間或使用其他 Web API。Tool 會在使用者的瀏覽器環境執行，無須在伺服器上執行。

```typescript {26}
import { createTool } from '@mastra/client-js'
import { z } from 'zod'

const handleClientTool = async () => {
  try {
    const agent = mastraClient.getAgent('colorAgent')

    const colorChangeTool = createTool({
      id: 'color-change-tool',
      description: 'Changes the HTML background color',
      inputSchema: z.object({
        color: z.string(),
      }),
      outputSchema: z.object({
        success: z.boolean(),
      }),
      execute: async inputData => {
        const { color } = inputData

        document.body.style.backgroundColor = color
        return { success: true }
      },
    })

    const response = await agent.generate('Change the background to blue', {
      clientTools: { colorChangeTool },
    })

    console.log(response)
  } catch (error) {
    console.error(error)
  }
}
```

### 使用用戶端 Tool 的 Agent {/* #client-tool-agent */}

這是標準的 Mastra [Agent](../agents/overview#quickstart)，設定為傳回十六進位色碼，以搭配上方定義的瀏覽器端 Tool。

```typescript title="src/mastra/agents/color-agent"
import { Agent } from '@mastra/core/agent'

export const colorAgent = new Agent({
  id: 'color-agent',
  name: 'Color Agent',
  instructions: `You are a helpful CSS assistant.
  You can change the background color of web pages.
  Respond with a hex reference for the color requested by the user`,
  model: '__GATEWAY_OPENAI_MODEL__',
})
```

## 在伺服器端使用 MastraClient {/* #use-mastraclient-on-the-server */}

伺服器端 API 路由與無伺服器函式（包括 action）也能使用 `MastraClient`。用法相同，但你可能需要為用戶端重新建立回應：

```typescript {8}
export async function action() {
  const agent = mastraClient.getAgent('testAgent')

  const stream = await agent.stream('Hello')

  return new Response(stream.body)
}
```
