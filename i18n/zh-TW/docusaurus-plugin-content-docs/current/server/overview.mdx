# 伺服器

Mastra 作為 HTTP 伺服器運行，將您的Agent、Workflow和其他功能公開為 API 端點。伺服器處理請求路由、中間件執行、身份驗證和流響應。



[`server`](/reference/configuration#server-options) configuration options passed to the `Mastra`構造函數。要使用您自己的 HTTP 伺服器（Hono、Express 等）運行 Mastra，請訪問[伺服器適配器](/docs/server/server-adapters).

:::

## 伺服器功能 {/* #server-features */}

* **[中介軟體](/docs/server/middleware)**：攔截身份驗證、日誌記錄、CORS 或註入請求特定上下文的請求。
* **[自訂 API 路由](/docs/server/custom-api-routes)**：使用您自己的可以存取 Mastra 實例的 HTTP 端點擴充伺服器。
* **[請求上下文](/docs/server/request-context)**：根據運行時條件將請求特定的值傳遞給Agent、Tool和Workflow。
* **[伺服器適配器](/docs/server/server-adapters)**：使用 Express、Hono 或您自己的 HTTP 伺服器而不是產生的伺服器來執行 Mastra。
* **[客製化適配器](/docs/server/custom-adapters)**：為未正式支援的框架建立適配器。
* **[Mastra 用戶端 SDK](/docs/server/mastra-client)**：類型安全的客戶端，用於從瀏覽器或伺服器環境呼叫Agent、Workflow和Tool。
* **[內建MCP伺服器](/docs/server/mcp)**：讓 Claude Code 和 Cursor 等 MCP 用戶端呼叫您的Agent商、Workflow和Tool：`/api/mcp`, with the same auth and permissions as the HTTP API.
* **[A2A](/docs/connections/a2a)**：透過 A2A Agent卡和任務流程以及推播通知公開Agent。
* **[驗證](/docs/auth/overview)**：使用 JWT、Clerk、Supabase、Firebase、Auth0 或 WorkOS 保護端點。

## 配置 {/* #configuration */}

透過傳遞配置伺服器`server` object to the `Mastra` constructor:

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'

export const mastra = new Mastra({
  server: {
    port: 3000, // Defaults to PORT env var or 4111
    host: '0.0.0.0', // Defaults to MASTRA_HOST env var or 'localhost'
  },
})
```

參觀[configuration reference](/reference/configuration#server-options) for a full list of available server options.

## 部署您的伺服器 {/* #deploy-your-server */}

Mastra 伺服器可以部署到任何 Node.js 相容環境。使用以下命令將其部署到生產環境[Mastra platform](/docs/mastra-platform/overview) or your own infrastructure. Visit the [deployment docs](/docs/deployment/overview) to learn how.

## 伺服器架構 {/* #server-architecture */}

馬斯特拉用途[Hono](https://hono.dev) as its underlying HTTP server framework. When you build a Mastra application using `mastra build`, it generates a Hono-based HTTP server in the `.mastra` directory.

伺服器提供：

* 所有註冊Agent程式和Workflow的 API 端點
* 自訂 API 路由和中介軟體
* 跨Provider的身份驗證
* 請求運行時配置的上下文
* 串流資料編輯以實現安全回應

## 休息API {/* #rest-api */}

您可以在下列位置探索 OpenAPI 規範中的所有可用端點：[http://localhost:4111/api/openapi.json](http://localhost:4111/api/openapi.json), which details every endpoint and its request and response schemas.

若要以互動方式探索 API，請造訪 Swagger UI：[http://localhost:4111/swagger-ui](http://localhost:4111/swagger-ui). Here, you can discover endpoints and test them directly from your browser.



預設情況下，OpenAPI 和 Swagger 端點在生產中處於停用狀態。若要啟用它們，請設定[`server.build.openAPIDocs`](/reference/configuration#serverbuild) and [`server.build.swaggerUI`](/reference/configuration#serverbuild) to `true` respectively.

## OpenAI 回應 API {/* #openai-responses-api */}

Mastra 公開了與 OpenAI 相容的回應和對話路由，讓您可以使用 Mastra Agent程式作為回應 API。這些路由是基於 Mastra Agent、記憶體和儲存的Agent程式支援的適配器，因此請求透過選定的 Mastra Agent程式運行，而不是充當原始ProviderAgent程式。

這些 API 目前處於實驗階段。

使用`agent_id` to select the Mastra agent that should handle the request. Initial requests target an agent directly. Stored follow-up turns can continue through `previous_response_id`. Pass `model` to override the configured model for one request, or omit it to use the agent's existing model.

回應路由支援串流、函數呼叫（Tool）、儲存的延續`previous_response_id`, conversation threads through `conversation_id`, provider-specific passthrough with `providerOptions`, and JSON output through `text.format`.

有關完整的請求和回應合同，請參閱[Responses API reference](/reference/client-js/responses) and [Conversations API reference](/reference/client-js/conversations). For the complete list of HTTP routes, see [server routes](/reference/server/routes#responses-api).

## 串流資料編輯 {/* #stream-data-redaction */}

當串流Agent回應時，HTTP 層會在將每個區塊傳送到用戶端之前編輯系統提示、Tool定義、API 金鑰和類似資料。預設情況下啟用此功能。

此行為只能透過使用進行配置[server adapters](/docs/server/server-adapters#stream-data-redaction). For server adapters, stream data redaction is enabled by default, too.

## TypeScript 配置 {/* #typescript-configuration */}

`module` and `moduleResolution` settings compatible with modern Node.js. Legacy options like `CommonJS` or `node` aren't supported.

這`types` option below requires `@types/node`, which is included in projects created with [`create-mastra`](/reference/cli/create-mastra). Add it if your project doesn't have it already:

```bash npm2yarn
npm install -D @types/node
```

```json {4-5} title="tsconfig.json"
{
  "compilerOptions": {
    "target": "ES2022",
    "module": "ES2022",
    "moduleResolution": "bundler",
    "esModuleInterop": true,
    "forceConsistentCasingInFileNames": true,
    "strict": true,
    "skipLibCheck": true,
    "types": ["node"],
    "noEmit": true,
    "outDir": "dist"
  },
  "include": ["src/**/*"]
}
```
