# incident.io

透過 Mastra Connect，為 Agent 提供可在 incident.io 中建立及更新事件、管理後續事項和行動，並讀取警示、值班表與目錄項目的 Tool。每次 Tool 呼叫都會經過 Mastra 平台，由平台加入該連線的憑證；你的應用程式不會儲存 incident.io 憑證。

## 連線 {/* #connect */}

開始前，請先完成 [Connect 設定](/docs/mastra-platform/connect#get-started)，安裝 `@mastra/connect` 並設定 Mastra 平台專案。

### 連結帳戶 {/* #connect-an-account */}

請在包含 `.env` 檔案的目錄中執行以下命令：

```bash
mastra connect add incident-io
```

CLI 會引導你完成 incident.io 授權，並等待連線啟用。

### 將 Tool 新增至 Agent {/* #add-tools-to-an-agent */}

將 [`tools()`](/reference/connect/tools) 傳給 Agent，並選取 `incident-io` Provider：

```typescript title="src/mastra/agents/incident-io-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const incidentIoAgent = new Agent({
  id: 'incident-io-agent',
  name: 'incident.io agent',
  instructions:
    'You help people create and update incidents, manage follow-ups and actions, and read alerts, schedules, and catalog entries in incident.io.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['incident-io'] }),
})
```

Agent 可使用 66 個 incident.io Tool，Tool key 包括 `incident_io_add_alert_tags`。完整清單請參閱 [incident.io Tool](/reference/connect/providers#incidentio)；如需限制可用 Tool，或要求每次呼叫在執行前取得核准，請參閱 [`tools()` 參數](/reference/connect/tools#parameters)。
