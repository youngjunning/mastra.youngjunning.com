# 事件.io

為Agent提供Tool來建立和更新事件、管理後續行動和操作，以及透過 Mastra Connect 讀取 Incident.io 中的警報、計劃和目錄項目。每個Tool呼叫都會透過 Mastra 平台，該平台會新增連接的憑證。您的應用程式從不儲存 event.io 憑證。

## 連接 {/* #connect */}

在開始之前，請完成[Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect`並配置您的平台項目。

### 連接帳戶 {/* #connect-an-account */}

從包含您的目錄的目錄執行此命令`.env` file:

```bash
mastra connect add incident-io
```

CLI 將引導您完成 event.io 的授權並等待連線啟動。

### 向Agent添加Tool {/* #add-tools-to-an-agent */}

經過[`tools()`](/reference/connect/tools) to the agent and select the `incident-io` provider:

```typescript title="src/mastra/agents/incident-io-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const incidentIoAgent = new Agent({
  id: 'incident-io-agent',
  name: 'incident.io agent',
  instructions:
    'You help people create and update incidents, manage follow-ups and actions, and read alerts, schedules, and catalog entries in incident.io.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['incident-io'] }),
})
```

Agent程式獲得 66 個 event.io Tool，其中包含以下金鑰：`incident_io_add_alert_tags`. See [incident.io tools](/reference/connect/providers#incidentio) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
