# 雪花

為Agent提供Tool來運行 SQL 語句並讀取其結果，並透過 Mastra Connect 列出 Snowflake 中的資料庫、模式、表、倉庫和角色。每個Tool呼叫都會透過 Mastra 平台，該平台會新增連接的憑證。您的應用程式從不儲存 Snowflake 憑證。

## 連接 {/* #connect */}

在開始之前，請完成[Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect`並配置您的平台項目。

### 連接帳戶 {/* #connect-an-account */}

從包含您的目錄的目錄執行此命令`.env` file:

```bash
mastra connect add snowflake
```

CLI 將引導您完成 Snowflake 的授權並等待連線啟動。

### 向Agent添加Tool {/* #add-tools-to-an-agent */}

經過[`tools()`](/reference/connect/tools) to the agent and select the `snowflake` provider:

```typescript title="src/mastra/agents/snowflake-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const snowflakeAgent = new Agent({
  id: 'snowflake-agent',
  name: 'Snowflake agent',
  instructions:
    'You help people run SQL statements and read their results, and list databases, schemas, tables, warehouses, and roles in Snowflake.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['snowflake'] }),
})
```

`snowflake_cancel_statement`. See [Snowflake tools](/reference/connect/providers#snowflake) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
