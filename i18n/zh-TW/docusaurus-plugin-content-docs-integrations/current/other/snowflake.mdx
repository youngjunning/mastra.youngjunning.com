# Snowflake

透過 Mastra Connect，為 Agent 提供可在 Snowflake 中執行 SQL 陳述式並讀取結果，以及列出資料庫、schema、資料表、warehouse 與角色的 Tool。每次 Tool 呼叫都會經過 Mastra 平台，由平台加入該連線的憑證；你的應用程式不會儲存 Snowflake 憑證。

## 連線 {/* #connect */}

開始前，請先完成 [Connect 設定](/docs/mastra-platform/connect#get-started)，安裝 `@mastra/connect` 並設定 Mastra 平台專案。

### 連結帳戶 {/* #connect-an-account */}

請在包含 `.env` 檔案的目錄中執行以下命令：

```bash
mastra connect add snowflake
```

CLI 會引導你完成 Snowflake 授權，並等待連線啟用。

### 將 Tool 新增至 Agent {/* #add-tools-to-an-agent */}

將 [`tools()`](/reference/connect/tools) 傳給 Agent，並選取 `snowflake` Provider：

```typescript title="src/mastra/agents/snowflake-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const snowflakeAgent = new Agent({
  id: 'snowflake-agent',
  name: 'Snowflake agent',
  instructions:
    'You help people run SQL statements and read their results, and list databases, schemas, tables, warehouses, and roles in Snowflake.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['snowflake'] }),
})
```

Agent 可使用 15 個 Snowflake Tool，Tool key 包括 `snowflake_cancel_statement`。完整清單請參閱 [Snowflake Tool](/reference/connect/providers#snowflake)；如需限制可用 Tool，或要求每次呼叫在執行前取得核准，請參閱 [`tools()` 參數](/reference/connect/tools#parameters)。
