# 螢火蟲.ai

為Agent商提供Tool來閱讀會議記錄和分析、詢問有關會議的問題、創建原聲片段以及透過 Mastra Connect 在 Fireflies.ai 中管理會議共享和隱私。每個Tool呼叫都會透過 Mastra 平台，該平台會新增連接的憑證。您的應用程式從不儲存 Fireflies.ai 憑證。

## 連接 {/* #connect */}

在開始之前，請完成[Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect`並配置您的平台項目。

### 連接帳戶 {/* #connect-an-account */}

從包含您的目錄的目錄執行此命令`.env` file:

```bash
mastra connect add fireflies
```

CLI 將引導您完成 Fireflies.ai 的授權並等待連線啟動。

### 向Agent添加Tool {/* #add-tools-to-an-agent */}

經過[`tools()`](/reference/connect/tools) to the agent and select the `fireflies` provider:

```typescript title="src/mastra/agents/fireflies-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const firefliesAgent = new Agent({
  id: 'fireflies-agent',
  name: 'Fireflies.ai agent',
  instructions:
    'You help people read meeting transcripts and analytics, ask questions about meetings, create soundbites, and manage meeting sharing and privacy in Fireflies.ai.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['fireflies'] }),
})
```

該Agent程式獲得 27 個 Fireflies.ai Tool，其中包含以下密鑰：`fireflies_add_to_live`. See [Fireflies.ai tools](/reference/connect/providers#firefliesai) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
