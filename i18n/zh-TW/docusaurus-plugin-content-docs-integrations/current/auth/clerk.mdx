# Clerk

你可以透過兩種方式在 Mastra 中使用 Clerk：

- **Agent 工具**讓 Agent 透過 [Mastra Connect](/docs/mastra-platform/connect) 管理 Clerk 使用者、組織和工作階段。
- **[伺服器身分驗證](#server-authentication)**透過 `@mastra/auth-clerk` 套件使用 Clerk 驗證送往 Mastra 伺服器的請求。

## Connect {/* #connect */}

開始前，請依照 [Connect 設定步驟](/docs/mastra-platform/connect#get-started) 安裝 `@mastra/connect`，並設定 Mastra Platform 專案。

## 伺服器身分驗證 {/* #server-authentication */}

`@mastra/auth-clerk` 套件透過 Clerk 的身分驗證系統驗證傳入請求。你可以使用 `auth` 選項將這個套件整合到 Mastra 伺服器。

### 事前準備 {/* #prerequisites */}

這個範例採用 Clerk 身分驗證。請確認 Clerk 專案已正確設定，並將 Clerk 憑證加入 `.env` 檔案。

```env title=".env"
CLERK_PUBLISHABLE_KEY=pk_test_...
CLERK_SECRET_KEY=sk_test_...
CLERK_JWKS_URI=https://your-clerk-domain.clerk.accounts.dev/.well-known/jwks.json
```

:::note

你可以在 Clerk Dashboard 的「API Keys」頁面找到這些金鑰。

:::

### 安裝 {/* #installation */}

使用 `MastraAuthClerk` 類別前，請先安裝 `@mastra/auth-clerk` 套件。

```bash npm2yarn
npm install @mastra/auth-clerk@latest
```

### 使用範例 {/* #usage-example */}

```typescript {2,6-10} title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraAuthClerk } from '@mastra/auth-clerk'

export const mastra = new Mastra({
  server: {
    auth: new MastraAuthClerk({
      publishableKey: process.env.CLERK_PUBLISHABLE_KEY,
      secretKey: process.env.CLERK_SECRET_KEY,
      jwksUri: process.env.CLERK_JWKS_URI,
    }),
  },
})
```

:::note

預設的 `authorizeUser` 方法會允許所有通過身分驗證的使用者存取。若要自行定義使用者授權規則，請在建立驗證提供者時傳入自訂的 `authorizeUser` 函式。

完整的設定選項請參閱 [MastraAuthClerk](/reference/auth/clerk)。

:::

### 客戶端設定 {/* #client-side-setup */}

使用 Clerk 進行身分驗證時，請在客戶端向 Clerk 取得存取權杖，並在送往 Mastra 的請求中附上權杖。

#### 取得存取權杖 {/* #retrieving-the-access-token */}

使用 Clerk 的 React Hook 驗證使用者身分，並取得該使用者的存取權杖：

```typescript title="lib/auth.ts"
import { useAuth } from '@clerk/nextjs'

export const useClerkAuth = () => {
  const { getToken } = useAuth()

  const getAccessToken = async () => {
    const token = await getToken()
    return token
  }

  return { getAccessToken }
}
```

詳情請參閱 [Clerk 文件](https://clerk.com/docs)。

### 設定 `MastraClient` {/* #configuring-mastraclient */}

啟用 `auth` 後，透過 `MastraClient` 送出的每個請求都必須在 `Authorization` 標頭中附上有效的 Clerk 存取權杖：

```typescript {6} title="lib/mastra/mastra-client.ts"
import { MastraClient } from '@mastra/client-js'

export const mastraClient = new MastraClient({
  baseUrl: 'https://<mastra-api-url>',
  headers: {
    Authorization: `Bearer ${accessToken}`,
  },
})
```

:::note

在 Authorization 標頭中，請在存取權杖前加上 `Bearer` 和一個空格。

更多設定選項請參閱 [Mastra Client SDK](/docs/server/mastra-client)。

:::

#### 送出經身分驗證的請求 {/* #making-authenticated-requests */}

將 Clerk 存取權杖加入 `MastraClient` 的設定後，就能送出經身分驗證的請求：

<Tabs>
  <TabItem value="react" label="React">
    ```tsx title="src/components/test-agent.tsx"
    'use client'

    import { useAuth } from '@clerk/nextjs'
    import { MastraClient } from '@mastra/client-js'

    export const TestAgent = () => {
      const { getToken } = useAuth()

      async function handleClick() {
        const token = await getToken()

        const client = new MastraClient({
          baseUrl: 'http://localhost:4111',
          headers: token ? { Authorization: `Bearer ${token}` } : undefined,
        })

        const weatherAgent = client.getAgent('weatherAgent')
        const response = await weatherAgent.generate("What's the weather like in New York")

        console.log({ response })
      }

      return <button onClick={handleClick}>Test Agent</button>
    }
    ```
  </TabItem>
