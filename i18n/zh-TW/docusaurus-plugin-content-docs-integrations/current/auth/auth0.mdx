# Auth0

`@mastra/auth-auth0` 套件讓 Mastra 使用 Auth0 進行身分驗證。套件會以 Auth0 簽發的 JWT 驗證傳入的請求。你可以透過 `auth` 選項將它整合至 Mastra 伺服器。

## 先決條件 {/* #prerequisites */}

這個範例使用 Auth0 驗證身分。開始之前，請完成下列設定：

1. 前往 [auth0.com](https://auth0.com/) 建立 Auth0 帳號。
2. 在 Auth0 管理介面中設定應用程式。
3. 在 Auth0 管理介面中設定 API，並指定識別碼（對象）。
4. 設定應用程式允許的回呼 URL、網頁來源和登出 URL。

```env title=".env"
AUTH0_DOMAIN=your-tenant.auth0.com
AUTH0_AUDIENCE=your-api-identifier
```

:::note

你可以在 Auth0 管理介面的 Applications > Settings 找到網域名稱。對象是你在管理介面的 APIs 頁面為 API 設定的識別碼。

如需詳細的設定步驟，請參閱 [Auth0 快速入門](https://auth0.com/docs/quickstarts)中適用於你所用平台的指南。

:::

## 安裝 {/* #installation */}

使用 `MastraAuthAuth0` 類別前，請先安裝 `@mastra/auth-auth0` 套件。

```bash npm2yarn
npm install @mastra/auth-auth0@latest
```

## 使用範例 {/* #usage-examples */}

### 使用環境變數進行基本設定 {/* #basic-usage-with-environment-variables */}

```typescript {2,6} title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraAuthAuth0 } from '@mastra/auth-auth0'

export const mastra = new Mastra({
  server: {
    auth: new MastraAuthAuth0(),
  },
})
```

### 自訂設定 {/* #custom-configuration */}

```typescript {2,6-9} title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraAuthAuth0 } from '@mastra/auth-auth0'

export const mastra = new Mastra({
  server: {
    auth: new MastraAuthAuth0({
      domain: process.env.AUTH0_DOMAIN,
      audience: process.env.AUTH0_AUDIENCE,
    }),
  },
})
```

## 設定 {/* #configuration */}

### 使用者授權 {/* #user-authorization */}

依照預設設定，只要使用者已通過身分驗證，且持有適用於指定對象的有效 Auth0 權杖，`MastraAuthAuth0` 就會允許存取。驗證權杖時會確認下列事項：

1. 權杖具有有效的 Auth0 簽章。
2. 權杖仍在有效期限內。
3. 權杖的對象與你設定的對象相符。
4. 權杖的簽發者與你的 Auth0 網域相符。

如要自訂使用者授權規則，請提供 `authorizeUser` 函式：

```typescript title="src/mastra/auth.ts"
import { MastraAuthAuth0 } from '@mastra/auth-auth0'

const auth0Provider = new MastraAuthAuth0({
  authorizeUser: async user => {
    // Custom authorization logic
    return user.email?.endsWith('@yourcompany.com') || false
  },
})
```

完整的設定選項請參閱 [MastraAuthAuth0](/reference/auth/auth0)。

## 用戶端設定 {/* #client-side-setup */}

採用 Auth0 身分驗證時，請設定 Auth0 React SDK，驗證使用者身分並取得存取權杖。向 Mastra 發出請求時，請一併傳送權杖。

### 設定 Auth0 React SDK {/* #setting-up-auth0-react-sdk */}

先在應用程式中安裝並設定 Auth0 React SDK：

```bash npm2yarn
npm install @auth0/auth0-react
```

```typescript title="src/auth0-provider.tsx" oxfmt:false
import React from 'react'
import { Auth0Provider } from '@auth0/auth0-react'

const Auth0ProviderWithHistory = ({ children }) => {
  return (
    <Auth0Provider
      domain={process.env.REACT_APP_AUTH0_DOMAIN}
      clientId={process.env.REACT_APP_AUTH0_CLIENT_ID}
      authorizationParams={{
        redirect_uri: window.location.origin,
        audience: process.env.REACT_APP_AUTH0_AUDIENCE,
        scope: 'read:current_user update:current_user_metadata',
      }}
    >
      {children}
    </Auth0Provider>
  )
}

export default Auth0ProviderWithHistory
```

### 取得存取權杖 {/* #retrieving-access-tokens */}

透過 Auth0 React SDK 驗證使用者身分，並取得該使用者的存取權杖：

```typescript title="lib/auth.ts"
import { useAuth0 } from '@auth0/auth0-react'

export const useAuth0Token = () => {
  const { getAccessTokenSilently } = useAuth0()

  const getAccessToken = async () => {
    const token = await getAccessTokenSilently()
    return token
  }

  return { getAccessToken }
}
```

:::note

如需其他身分驗證方式及設定選項，請參閱 [Auth0 React SDK 文件](https://auth0.com/docs/libraries/auth0-react)。

:::

## 設定 `MastraClient` {/* #configuring-mastraclient */}

啟用 `auth` 後，使用 `MastraClient` 送出的每個請求都必須在 `Authorization` 標頭中附上有效的 Auth0 存取權杖：

```typescript title="lib/mastra/mastra-client.ts"
import { MastraClient } from '@mastra/client-js'

export const createMastraClient = (accessToken: string) => {
  return new MastraClient({
    baseUrl: 'https://<mastra-api-url>',
    headers: {
      Authorization: `Bearer ${accessToken}`,
    },
  })
}
```

:::note

在 Authorization 標頭中，存取權杖前必須加上 `Bearer` 前綴。

更多設定選項請參閱 [Mastra Client SDK](/docs/server/mastra-client)。

:::

### 送出附有身分驗證資訊的請求 {/* #making-authenticated-requests */}

將 Auth0 存取權杖加入 `MastraClient` 的設定後，就可以送出附有身分驗證資訊的請求：

<Tabs>
  <TabItem value="react" label="React">
    ```tsx title="src/components/mastra-api-test.tsx"
    import React, { useState } from 'react'
    import { useAuth0 } from '@auth0/auth0-react'
    import { MastraClient } from '@mastra/client-js'

    export const MastraApiTest = () => {
      const { getAccessTokenSilently } = useAuth0()
      const [result, setResult] = useState(null)

      const callMastraApi = async () => {
        const token = await getAccessTokenSilently()

        const mastra = new MastraClient({
          baseUrl: 'http://localhost:4111',
          headers: {
            Authorization: `Bearer ${token}`,
          },
        })

        const weatherAgent = mastra.getAgent('weatherAgent')
        const response = await weatherAgent.generate("What's the weather like in New York")

        setResult(response.text)
      }

      return (
        <div>
          <button onClick={callMastraApi}>Test Mastra API</button>

          {result && (
            <div className="result">
              <h6>Result:</h6>
              <pre>{result}</pre>
            </div>
          )}
        </div>
      )
    }
    ```
