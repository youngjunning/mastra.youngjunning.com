# Supabase

你可以透過以下兩種方式搭配使用 Supabase 與 Mastra：

- **Agent 工具**讓 Agent 透過 [Mastra Connect](/docs/mastra-platform/connect) 查詢 Supabase 的資料表、呼叫資料庫函式，以及管理儲存空間和 Supabase Auth 使用者。
- **[伺服器身分驗證](#server-authentication)**透過 `@mastra/auth-supabase` 套件，使用 Supabase 驗證送往 Mastra 伺服器的請求。

## Connect {/* #connect */}

開始前，請依照 [Connect 設定步驟](/docs/mastra-platform/connect#get-started)安裝 `@mastra/connect` 並設定你的平台專案。

## 伺服器身分驗證 {/* #server-authentication */}

`@mastra/auth-supabase` 套件透過 `auth` 選項與 Mastra 伺服器整合，使用 Supabase Auth 驗證收到的請求。

### 先決條件 {/* #prerequisites */}

此範例使用 Supabase Auth。請確認 Supabase 專案已正確設定，並將 Supabase 憑證加到 `.env` 檔案中。

```env title=".env"
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_ANON_KEY=your-anon-key
```

:::note

請檢查 Supabase 的資料列層級安全性（RLS）設定，確認資料存取權限符合預期。

:::

### 安裝 {/* #installation */}

使用 `MastraAuthSupabase` 類別前，請先安裝 `@mastra/auth-supabase` 套件。

```bash npm2yarn
npm install @mastra/auth-supabase@latest
```

### 使用範例 {/* #usage-example */}

```typescript {2,6-9} title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraAuthSupabase } from '@mastra/auth-supabase'

export const mastra = new Mastra({
  server: {
    auth: new MastraAuthSupabase({
      url: process.env.SUPABASE_URL,
      anonKey: process.env.SUPABASE_ANON_KEY,
    }),
  },
})
```

:::note

預設的 `authorizeUser` 方法會檢查 `public` 結構描述中 `users` 資料表的 `isAdmin` 欄位。若要自訂使用者授權邏輯，請在建立身分驗證提供者的執行個體時傳入自訂的 `authorizeUser` 函式。

所有可用的設定選項請參閱 [MastraAuthSupabase](/reference/auth/supabase)。

:::

### 用戶端設定 {/* #client-side-setup */}

使用 Supabase Auth 時，你需要在用戶端向 Supabase 取得存取權杖，並在送往 Mastra 的請求中附上該權杖。

#### 取得存取權杖 {/* #retrieving-the-access-token */}

使用 Supabase 用戶端驗證使用者身分，並取得該使用者的存取權杖：

```typescript title="lib/auth.ts"
import { createClient } from '@supabase/supabase-js'

const supabase = createClient('<supabase-url>', '<supabase-key>')

const authTokenResponse = await supabase.auth.signInWithPassword({
  email: "<user's email>",
  password: "<user's password>",
})

const accessToken = authTokenResponse.data?.session?.access_token
```

:::note

如需瞭解 OAuth、免密碼登入連結（magic link）等其他身分驗證方式，請參閱 [Supabase 文件](https://supabase.com/docs/guides/auth)。

:::

### 設定 `MastraClient` {/* #configuring-mastraclient */}

啟用 `auth` 後，透過 `MastraClient` 送出的所有請求都必須在 `Authorization` 標頭中包含有效的 Supabase 存取權杖：

```typescript {6} title="lib/mastra/mastra-client.ts"
import { MastraClient } from '@mastra/client-js'

export const mastraClient = new MastraClient({
  baseUrl: 'https://<mastra-api-url>',
  headers: {
    Authorization: `Bearer ${accessToken}`,
  },
})
```

:::note

在 Authorization 標頭中，存取權杖前必須加上 `Bearer` 和一個空格。

更多設定選項請參閱 [Mastra Client SDK](/docs/server/mastra-client)。

:::

#### 送出附有驗證憑證的請求 {/* #making-authenticated-requests */}

為 `MastraClient` 設定 Supabase 存取權杖後，即可送出附有該權杖的請求：

  <TabItem value="react" label="React">

    ```tsx title="src/components/test-agent.tsx"
    import { mastraClient } from '../../lib/mastra-client'

    export const TestAgent = () => {
      async function handleClick() {
        const agent = mastraClient.getAgent('weatherAgent')

        const response = await agent.generate("What's the weather like in New York")

      }

      return <button onClick={handleClick}>Test Agent</button>
    }
    ```
