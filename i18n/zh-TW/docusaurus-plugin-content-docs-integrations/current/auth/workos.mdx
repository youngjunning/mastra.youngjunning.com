# WorkOS

WorkOS 與 Mastra 有兩種整合方式：

* **Agent Tool** 讓 Agent 透過 [Mastra Connect](/docs/mastra-platform/connect) 管理 WorkOS 組織、使用者及 SSO 連線。
* **[伺服器身分驗證](#server-authentication)** 使用 `@mastra/auth-workos` 套件，透過 WorkOS 驗證傳入 Mastra 伺服器的請求。

## Connect {/* #connect */}

開始前，請依照 [Connect 設定步驟](/docs/mastra-platform/connect#get-started)安裝 `@mastra/connect` 並設定平台專案。

## 伺服器身分驗證 {/* #server-authentication */}

`@mastra/auth-workos` 套件透過 WorkOS 為 Mastra 提供身分驗證。它使用 WorkOS 存取權杖驗證傳入的請求，並透過 `auth` 選項與 Mastra 伺服器整合。

### 先決條件 {/* #prerequisites */}

這個範例使用 WorkOS 進行身分驗證。請先完成下列設定：

1. 在 [workos.com](https://workos.com/) 建立 WorkOS 帳號
2. 在 WorkOS 控制台中設定應用程式
3. 設定重新導向 URI 與允許的來源
4. 視需要設定組織與使用者角色

```env title=".env"
WORKOS_API_KEY=sk_live_...
WORKOS_CLIENT_ID=client_...
```

:::note

你可以在 WorkOS 控制台的 API Keys 與 Applications 頁面分別找到 API 金鑰與用戶端 ID。

詳細設定方式請參閱 [WorkOS 文件](https://workos.com/docs)中對應所用平台的說明。

:::

### 安裝 {/* #installation */}

使用 `MastraAuthWorkos` 類別前，必須先安裝 `@mastra/auth-workos` 套件。

```bash npm2yarn
npm install @mastra/auth-workos@latest
```

### 使用範例 {/* #usage-examples */}

#### 使用環境變數 {/* #basic-usage-with-environment-variables */}

```typescript {2,6} title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraAuthWorkos } from '@mastra/auth-workos'

export const mastra = new Mastra({
  server: {
    auth: new MastraAuthWorkos(),
  },
})
```

#### 自訂設定 {/* #custom-configuration */}

```typescript {2,6-9} title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraAuthWorkos } from '@mastra/auth-workos'

export const mastra = new Mastra({
  server: {
    auth: new MastraAuthWorkos({
      apiKey: process.env.WORKOS_API_KEY,
      clientId: process.env.WORKOS_CLIENT_ID,
    }),
  },
})
```

### 設定 {/* #configuration */}

#### 預設授權 {/* #default-authorization */}

`MastraAuthWorkos` 預設允許所有通過身分驗證的 WorkOS 使用者存取。解析出的使用者物件同時包含 Mastra 使用者 ID 和 WorkOS 使用者 ID 時，便會通過授權檢查。

#### 為 FGA 載入組織成員資格 {/* #fga-membership-loading */}

:::note

在正式環境使用 FGA 需要 Mastra 企業版（EE）授權，開發環境則可直接使用。請參閱[哪些功能需要 EE 授權](/docs/license#what-requires-an-ee-license)。如需更多資訊，請[聯絡業務團隊](https://mastra.ai/contact)。

:::

使用 [`MastraFGAWorkos`](/docs/auth/fga) 時，請設定 `fetchMemberships: true`。身分驗證 Provider 會在驗證身分時載入使用者在 WorkOS 中的組織成員資格，讓 FGA 檢查能找出正確的組織成員資格 ID。

```typescript title="src/mastra/auth.ts"
import { MastraAuthWorkos, MastraFGAWorkos } from '@mastra/auth-workos'

const workosAuth = new MastraAuthWorkos({
  apiKey: process.env.WORKOS_API_KEY,
  clientId: process.env.WORKOS_CLIENT_ID,
  fetchMemberships: true,
})

const workosFga = new MastraFGAWorkos({
  apiKey: process.env.WORKOS_API_KEY,
  clientId: process.env.WORKOS_CLIENT_ID,
})
```

`fetchMemberships` 為 `false` 時，Mastra 處理每個通過身分驗證的請求時都會略過額外的 WorkOS `listOrganizationMemberships()` 呼叫。

#### 服務權杖與自訂 JWT 範本 {/* #service-tokens-and-custom-jwt-templates */}

若要支援機器對機器或服務帳戶的存取，可以設定 `MastraAuthWorkos`，讓它信任 WorkOS 自訂 JWT 範本所產生的持有人權杖中已驗證的宣告。

```typescript title="src/mastra/auth.ts"
import { MastraAuthWorkos } from '@mastra/auth-workos'

const workosAuth = new MastraAuthWorkos({
  apiKey: process.env.WORKOS_API_KEY,
  clientId: process.env.WORKOS_CLIENT_ID,
  redirectUri: process.env.WORKOS_REDIRECT_URI,
  trustJwtClaims: true,
  jwtClaims: {
    organizationId: 'org_id',
    organizationMembershipId: 'urn:mastra:organization_membership_id',
  },
})
```

當 JWT 範本已包含 Mastra 執行 FGA 檢查所需的資訊（例如 `organizationMembershipId`、租用戶 ID 或服務主體識別碼）時，這項設定就派得上用場。啟用 `trustJwtClaims` 後，若持有人權杖不適合透過 `workos.userManagement.getUser()` 查詢使用者，Mastra 可以改用這些已驗證的宣告。

#### 自訂授權 {/* #custom-authorization */}

如需更嚴格的授權規則，可建立 `MastraAuthWorkos` 的子類別並覆寫 `authorizeUser()`：

```typescript title="src/mastra/auth.ts"
import { MastraAuthWorkos } from '@mastra/auth-workos'
import type { HonoRequest } from 'hono'

class AdminOnlyWorkosAuth extends MastraAuthWorkos {
  async authorizeUser(user: any, _request: HonoRequest): Promise<boolean> {
    return user?.metadata?.role === 'admin'
  }
}

const workosAuth = new AdminOnlyWorkosAuth({
  apiKey: process.env.WORKOS_API_KEY,
  clientId: process.env.WORKOS_CLIENT_ID,
})
```

所有可用的設定選項請參閱 [MastraAuthWorkos](/reference/auth/workos)。

### 用戶端設定 {/* #client-side-setup */}

使用 WorkOS 進行身分驗證時，必須實作 WorkOS 的身分驗證流程，以授權碼換取存取權杖，再用該權杖向 Mastra 發出請求。

#### 安裝 WorkOS SDK {/* #installing-workos-sdk */}

先在應用程式中安裝 WorkOS SDK：

```bash npm2yarn
npm install @workos-inc/node
```

#### 以授權碼換取存取權杖 {/* #exchanging-code-for-access-token */}

使用者完成 WorkOS 身分驗證流程並帶著授權碼返回後，就能用該授權碼換取存取權杖：

```typescript title="lib/auth.ts"
import { WorkOS } from '@workos-inc/node'

const workos = new WorkOS(process.env.WORKOS_API_KEY)

export const authenticateWithWorkos = async (code: string, clientId: string) => {
  const authenticationResponse = await workos.userManagement.authenticateWithCode({
    code,
    clientId,
  })

  return authenticationResponse.accessToken
}
```

:::note

更多身分驗證方式及設定選項請參閱 [WorkOS 使用者管理文件](https://workos.com/docs/authkit/vanilla/nodejs)。

:::

### 設定 `MastraClient` {/* #configuring-mastraclient */}

啟用 `auth` 後，透過 `MastraClient` 發出的所有請求都必須在 `Authorization` 標頭中帶上有效的 WorkOS 存取權杖：

```typescript title="lib/mastra/mastra-client.ts"
import { MastraClient } from '@mastra/client-js'

export const createMastraClient = (accessToken: string) => {
  return new MastraClient({
    baseUrl: 'https://<mastra-api-url>',
    headers: {
      Authorization: `Bearer ${accessToken}`,
    },
  })
}
```

:::note

Authorization 標頭中的存取權杖必須加上 `Bearer` 前綴。

更多設定選項請參閱 [Mastra Client SDK](/docs/server/mastra-client)。

:::

#### 發出附帶身分驗證憑證的請求 {/* #making-authenticated-requests */}

在 `MastraClient` 設定 WorkOS 存取權杖後，就能發出附帶身分驗證憑證的請求：

<Tabs>
  <TabItem value="react" label="React">
    ```typescript title="src/api/agents.ts"
    import { WorkOS } from '@workos-inc/node'
    import { MastraClient } from '@mastra/client-js'

    const workos = new WorkOS(process.env.WORKOS_API_KEY)

    export const callMastraWithWorkos = async (code: string, clientId: string) => {
      const authenticationResponse = await workos.userManagement.authenticateWithCode({
        code,
        clientId,
      })

      const token = authenticationResponse.accessToken

      const mastra = new MastraClient({
        baseUrl: 'http://localhost:4111',
        headers: {
          Authorization: `Bearer ${token}`,
        },
      })

      const weatherAgent = mastra.getAgent('weatherAgent')
      const response = await weatherAgent.generate("What's the weather like in Nairobi")

      return response.text
    }
    ```
