# Telegram

透過 Telegram 頻道，使用者可以在 Telegram 裡傳送私訊、在群組發言或提及機器人，藉此與你的 Agent 對話。

[Mastra Connect](/docs/mastra-platform/connect) 會將 Telegram 機器人權杖儲存在 Mastra 平台，並代為註冊 webhook。你也可以自行管理機器人權杖和 webhook。

## Connect {/* #connect */}

開始前，請依照 [Connect 設定步驟](/docs/mastra-platform/connect#get-started) 安裝 `@mastra/connect`，並設定 Mastra 平台上的專案。

Connect 使用由 BotFather 提供的機器人權杖。連接 Agent 前，請在長期運作的正式環境伺服器上設定 `MASTRA_ENCRYPTION_KEY`。Mastra 會使用這把金鑰加密儲存的 webhook 密鑰。若未設定金鑰，webhook 密鑰會以未加密的方式儲存。

Webhook 模式需要可公開存取的 HTTPS 伺服器 URL，Mastra 平台會提供這個 URL。若在其他地方託管，請將 `MASTRA_SERVER_URL` 設為可公開存取的伺服器 URL。若在本機開發時沒有公開的 webhook URL，可參閱 [Telegram Provider 參考文件](/reference/channels/telegram-provider) 中的輪詢模式說明。

1. 開啟 [BotFather](https://t.me/botfather)，執行 `/newbot`，並依照提示操作。

1. 複製 BotFather 傳回的機器人權杖。

1. 執行 `mastra connect add telegram`，並輸入機器人權杖。

1. 將 [`channels()`](/reference/connect/channels) 傳給 `Mastra` 建構函式。這會註冊 Telegram 頻道的 Provider 及其路由：

   ```typescript title="src/mastra/index.ts"
   import { Mastra } from '@mastra/core'
   import { channels } from '@mastra/connect'
   import { assistant } from './agents/assistant'

   export const mastra = new Mastra({
     agents: { assistant },
     channels: await channels({ providers: ['telegram'] }),
   })
   ```

   若也要註冊其他頻道，請將這些頻道的 Provider ID 加入 `providers`。

1. 啟動 Mastra 應用程式。

1. 在 Studio 中將 Telegram 頻道連接至 Agent。Mastra 會驗證機器人、建立 webhook 密鑰，並向 Telegram 註冊該 Agent 的公開 webhook URL。

若要讓 Agent 改用另一個機器人，請先在 Studio 中解除連線，再重新連線。Mastra 不會將現有 Agent 的 webhook 移轉至另一個機器人。

## 自行管理的設定方式 {/* #self-managed-setup */}

使用 Chat SDK 的 Telegram 轉接器，搭配你自己的機器人權杖和 webhook。

### 安裝轉接器 {/* #install-the-adapter */}

安裝 Chat SDK 的 Telegram 轉接器：

```bash npm2yarn
npm install @chat-adapter/telegram
```

### Agent 設定 {/* #agent-configuration */}

將 `createTelegramAdapter()` 加入 Agent 的 `channels.adapters` 物件：

```typescript title="src/mastra/agents/telegram-agent.ts"
import { Agent } from '@mastra/core/agent'
import { createTelegramAdapter } from '@chat-adapter/telegram'

export const telegramAgent = new Agent({
  id: 'telegram-agent',
  name: 'Telegram Agent',
  instructions: 'Answer questions and help with tasks in Telegram.',
  model: '__GATEWAY_OPENAI_MODEL__',
  channels: {
    adapters: {
      telegram: createTelegramAdapter(),
    },
  },
})
```

在 Mastra 執行個體上註冊 Agent：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { telegramAgent } from './agents/telegram-agent'

export const mastra = new Mastra({
  agents: { telegramAgent },
})
```

### 設定轉接器 {/* #adapter-setup */}

請依照 [Chat SDK 的 Telegram 轉接器文件](https://chat-sdk.dev/adapters/official/telegram) 完成 Telegram 專用設定，包括 BotFather、webhook 註冊、密鑰權杖和輪詢模式。

轉接器會從環境變數讀取 Telegram 憑證，例如：

```bash title=".env"
TELEGRAM_BOT_TOKEN=your-telegram-bot-token
TELEGRAM_WEBHOOK_SECRET_TOKEN=your-webhook-secret-token
TELEGRAM_BOT_USERNAME=your_bot_username
```

### Webhook URL {/* #webhook-url */}

Mastra 會根據 Agent ID 和轉接器鍵值產生 Telegram 的 webhook 路由：

```text
/api/agents/telegram-agent/channels/telegram/webhook
```

以可公開存取的 Mastra 伺服器 URL 作為基底 URL：

```text
https://your-app.example.com/api/agents/telegram-agent/channels/telegram/webhook
```

凡是 Telegram 轉接器文件要求填入 webhook URL 的地方，都使用這個 URL。Telegram 也支援輪詢模式。若要在本機開發時使用輪詢，請依照 Chat SDK 的轉接器文件操作。
