# WhatsApp

WhatsApp 管道讓 Mastra Agent透過 WhatsApp Business Cloud 接收客戶訊息。 Mastra 處理Agent接線和 webhook 路由； Chat SDK WhatsApp 適配器文件涵蓋元應用程式設定、憑證和 Webhook 配置。

## 安裝適配器 {/* #install-the-adapter */}

從聊天 SDK 安裝 WhatsApp 轉接器：

```bash npm2yarn
npm install @chat-adapter/whatsapp
```

## Agent配置 {/* #agent-configuration */}

添加`createWhatsAppAdapter()` to the agent's `channels.adapters` object:

```typescript title="src/mastra/agents/whatsapp-agent.ts"
import { Agent } from '@mastra/core/agent'
import { createWhatsAppAdapter } from '@chat-adapter/whatsapp'

export const whatsappAgent = new Agent({
  id: 'whatsapp-agent',
  name: 'WhatsApp Agent',
  instructions: 'Answer customer questions and help with tasks in WhatsApp.',
  model: '__GATEWAY_OPENAI_MODEL__',
  channels: {
    adapters: {
      whatsapp: createWhatsAppAdapter(),
    },
  },
})
```

在 Mastra 實例上註冊Agent：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { whatsappAgent } from './agents/whatsapp-agent'

export const mastra = new Mastra({
  agents: { whatsappAgent },
})
```

## 適配器設定 {/* #adapter-setup */}

遵循[Chat SDK WhatsApp adapter docs](https://chat-sdk.dev/adapters/official/whatsapp) for WhatsApp-specific setup, including Meta app configuration, access tokens, phone number IDs, webhook verification, and message limits.

此適配器從環境變數中讀取 WhatsApp 憑證，例如：

```bash title=".env"
WHATSAPP_ACCESS_TOKEN=your-meta-access-token
WHATSAPP_APP_SECRET=your-meta-app-secret
WHATSAPP_PHONE_NUMBER_ID=your-whatsapp-phone-number-id
WHATSAPP_VERIFY_TOKEN=your-webhook-verify-token
```

## 網路鉤子 URL {/* #webhook-url */}

Mastra 根據Agent ID 和適配器金鑰產生 WhatsApp Webhook 路由：

```text
/api/agents/whatsapp-agent/channels/whatsapp/webhook
```

使用您的公用 Mastra 伺服器 URL 作為基本 URL：

```text
https://your-app.example.com/api/agents/whatsapp-agent/channels/whatsapp/webhook
```

使用此 URL 傳遞傳入的 WhatsApp 事件。產生的 Mastra 路由處理來自 WhatsApp 的 POST 事件；請遵循 Chat SDK WhatsApp 適配器文件以了解元回呼和 Webhook 驗證流程。
