# Discord

Mastra 提供兩種與 Discord 整合的方式：

- **Agent Tool** 讓 Agent 在 Discord 伺服器中執行操作，例如傳送訊息或管理頻道。
- **Agent 聊天**讓使用者在 Discord 中透過機器人訊息、斜線指令和按鈕等互動方式與你的 Agent 交談。

[Mastra Connect](/docs/mastra-platform/connect) 會使用同一個 Discord 機器人設定這兩項功能，並將機器人的權杖保存在 Mastra 平台上。如果使用 Agent 聊天功能，你也可以自行管理機器人憑證。

## Connect {/* #connect */}

開始前，請完成 [Connect 設定](/docs/mastra-platform/connect#get-started)，以安裝 `@mastra/connect` 並設定你的平台專案。

一個 `discord` 連線即可同時提供 Agent Tool 和 Agent 聊天功能。這個連線使用**機器人權杖**，而非使用者 OAuth 權杖。

### 建立 Discord 機器人 {/* #create-a-discord-bot */}

1. 在 [Discord 開發人員入口網站](https://discord.com/developers/applications)建立應用程式。
1. 開啟 **Bot**，新增機器人，接著選取 **Reset Token** 並複製機器人權杖。
1. 若要使用 Agent 聊天功能，請在 **Privileged Gateway Intents** 下啟用 **Message Content Intent**。

當 `mastra connect add discord` 提示輸入憑證時，請輸入機器人權杖。

### Agent 聊天 {/* #agent-chat */}

伺服器需要有 Discord 可存取的公開 URL，才能接收 webhook 請求和 OAuth 回呼。Mastra 平台會提供這個 URL。如果部署在其他地方，請將 `MASTRA_SERVER_URL` 設為伺服器的公開 URL。本機開發時，請使用公開的 HTTPS 通道。

1. 如果尚未新增連線，請執行 `mastra connect add discord` 並輸入機器人權杖。

1. 將 [`channels()`](/reference/connect/channels) 傳入 `Mastra` 建構函式，以註冊 Discord 頻道的 Provider 及其路由：

   ```typescript title="src/mastra/index.ts"
   import { Mastra } from '@mastra/core'
   import { channels } from '@mastra/connect'
   import { assistant } from './agents/assistant'

   export const mastra = new Mastra({
     agents: { assistant },
     channels: await channels({ providers: ['discord'] }),
   })
   ```

   若也要註冊其他頻道，請將各頻道的 Provider ID 加入 `providers`。

1. 啟動 Mastra 應用程式。

1. 在 Studio 中，將 Discord 頻道連結至 Agent。如果機器人尚未加入伺服器，請開啟產生的授權 URL，選取伺服器，並核准所要求的權限。

Discord 透過 Gateway 傳遞訊息，並透過 HTTP 互動路由處理斜線指令和按鈕互動。機器人邀請所要求的授權範圍和權限請參閱 [Discord 權限](/reference/connect/channels#discord-permissions)。

## 自行管理的設定 {/* #self-managed-setup */}

使用 Chat SDK 的 Discord 轉接器，搭配你自行管理的 Discord 應用程式和憑證。

### 安裝轉接器 {/* #install-the-adapter */}

從 Chat SDK 安裝 Discord 轉接器：

```bash npm2yarn
npm install @chat-adapter/discord
```

### Agent 設定 {/* #agent-configuration */}

將 `createDiscordAdapter()` 加入 Agent 的 `channels.adapters` 物件：

```typescript title="src/mastra/agents/discord-agent.ts"
import { Agent } from '@mastra/core/agent'
import { createDiscordAdapter } from '@chat-adapter/discord'

export const discordAgent = new Agent({
  id: 'discord-agent',
  name: 'Discord Agent',
  instructions: 'Answer questions and help with tasks in Discord.',
  model: '__GATEWAY_OPENAI_MODEL__',
  channels: {
    adapters: {
      discord: createDiscordAdapter(),
    },
  },
})
```

在 Mastra 執行個體中註冊 Agent：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { discordAgent } from './agents/discord-agent'

export const mastra = new Mastra({
  agents: { discordAgent },
})
```

### 轉接器設定 {/* #adapter-setup */}

請參閱 [Chat SDK 的 Discord 轉接器文件](https://chat-sdk.dev/adapters/official/discord)，依照 Discord 專用的步驟進行設定。文件涵蓋應用程式建立、機器人權杖、互動端點、權限及 Gateway 的運作方式。

轉接器會從環境變數讀取 Discord 憑證，例如：

```bash title=".env"
DISCORD_BOT_TOKEN=your-discord-bot-token
DISCORD_PUBLIC_KEY=your-discord-application-public-key
DISCORD_APPLICATION_ID=your-discord-application-id
```

### Webhook URL {/* #webhook-url */}

Mastra 會根據 Agent ID 和轉接器鍵值產生 Discord Webhook 路由：

```text
/api/agents/discord-agent/channels/discord/webhook
```

請以可公開存取的 Mastra 伺服器 URL 作為基底 URL：

```text
https://your-app.example.com/api/agents/discord-agent/channels/discord/webhook
```

凡是 Discord 轉接器文件要求填入互動端點或 Webhook URL 的地方，都請使用這個 URL。若要接收 Discord 的一般訊息事件，可能還需要在產生的 Webhook 路由之外另行設定 Gateway。請依照 Chat SDK 轉接器文件中的 Gateway 設定步驟操作。
