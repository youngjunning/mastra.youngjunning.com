# OpenSearch 向量儲存

OpenSearchVector 類別透過開放原始碼的搜尋與分析引擎 [OpenSearch](https://opensearch.org/) 提供向量搜尋，並利用 OpenSearch 的 k-NN 功能找出相似向量。

## 建構函數選項 {/* #constructor-options */}

建構函式支援 [OpenSearch ClientOptions](https://opensearch.org/docs/latest/clients/javascript/index/) 的所有選項，且必須提供 `id` 欄位。

### `createIndex()` {/* #createindex */}
