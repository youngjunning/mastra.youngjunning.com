# 凸向量存儲

這`ConvexVector`類別提供向量儲存和相似性搜尋使用[凸面](https://convex.dev)。它將嵌入儲存在 Convex 內，並在 Mastra 適配器中執行餘弦相似性搜尋。

:::警告\[開發規模搜尋]

`ConvexVector`透過 Mastra 儲存處理程序讀取匹配的向量並在 JavaScript 中過濾它們。然後，它計算餘弦相似度並對結果進行排序，然後傳回最匹配的結果。將其用於本地開發、測試和小型資料集。

對於凸上的生產向量搜索，請使用`ConvexNativeVector`. It uses the Convex native `vectorSearch` API, which requires a deployed Convex vector index and a Convex action.

:::

### 本機凸向量搜尋 {/* #native-convex-vector-search */}

使用`ConvexNativeVector` for production vector workloads. It stores vectors in a dedicated Convex table and queries a schema-defined Convex vector index.

在`convex/schema.ts`, define a dedicated table for each Mastra vector index:

```typescript title="convex/schema.ts"
import { defineSchema } from 'convex/server'
import { defineMastraNativeVectorTable } from '@mastra/convex/schema'

export default defineSchema({
  docs_vectors: defineMastraNativeVectorTable({
    dimensions: 1536,
  }),
})
```

在`convex/mastra/nativeVector.ts`, export the native vector handlers:

```typescript title="convex/mastra/nativeVector.ts"
import {
  mastraNativeVectorAction,
  mastraNativeVectorMutation,
  mastraNativeVectorQuery,
} from '@mastra/convex/server'

export const query = mastraNativeVectorAction
export const read = mastraNativeVectorQuery
export const write = mastraNativeVectorMutation
```

在您的 Mastra 應用程式中，配置`ConvexNativeVector` with the deployed table and vector index:

```typescript title="src/mastra/index.ts"
import { ConvexNativeVector } from '@mastra/convex'

const vectorStore = new ConvexNativeVector({
  id: 'convex-native-vectors',
  deploymentUrl: process.env.CONVEX_URL!,
  adminAuthToken: process.env.CONVEX_ADMIN_KEY!,
  indexes: {
    docs: {
      tableName: 'docs_vectors',
      vectorIndexName: 'by_embedding',
      dimension: 1536,
    },
  },
})

const results = await vectorStore.query({
  indexName: 'docs',
  queryVector: embedding,
  topK: 10,
})
```

對於本機過濾器支持，請在凸架構中聲明過濾器欄位。寫入向量時，本機向量處理程序將符合的元資料欄位複製到頂級文件欄位。

```typescript title="convex/schema.ts"
import { defineSchema, defineTable } from 'convex/server'
import { v } from 'convex/values'

export default defineSchema({
  docs_vectors: defineTable({
    id: v.string(),
    embedding: v.array(v.float64()),
    metadata: v.optional(v.any()),
    tenantId: v.string(),
  })
    .index('by_record_id', ['id'])
    .vectorIndex('by_embedding', {
      vectorField: 'embedding',
      dimensions: 1536,
      filterFields: ['tenantId'],
    }),
})
```

```typescript title="src/mastra/index.ts"
const vectorStore = new ConvexNativeVector({
  id: 'convex-native-vectors',
  deploymentUrl: process.env.CONVEX_URL!,
  adminAuthToken: process.env.CONVEX_ADMIN_KEY!,
  indexes: {
    docs: {
      tableName: 'docs_vectors',
      dimension: 1536,
      filterFields: ['tenantId'],
    },
  },
})

await vectorStore.upsert({
  indexName: 'docs',
  ids: ['chunk-1'],
  vectors: [embedding],
  metadata: [{ tenantId: 'acme', text: 'Account setup guide' }],
})

const results = await vectorStore.query({
  indexName: 'docs',
  queryVector: embedding,
  filter: { tenantId: 'acme' },
})
```

`ConvexNativeVector`支援凸本機向量濾波器形狀：一個等式場，或`$or` of equality fields. It doesn't support metadata-only queries, filter-based updates, or filter-based deletes. Use vector IDs for updates and deletes.

## 元資料過濾 {/* #metadata-filtering */}

`ConvexVector`支援使用運算子進行元資料過濾。從 Convex 載入向量後，適配器將套用這些過濾器。

```typescript
// Simple equality
const results = await vectorStore.query({
  indexName: 'my_vectors',
  queryVector: embedding,
  filter: { category: 'documents' },
})

// Comparison operators
const results = await vectorStore.query({
  indexName: 'my_vectors',
  queryVector: embedding,
  filter: {
    price: { $gt: 100 },
    status: { $in: ['active', 'pending'] },
  },
})

// Logical operators
const results = await vectorStore.query({
  indexName: 'my_vectors',
  queryVector: embedding,
  filter: {
    $and: [{ category: 'electronics' }, { price: { $lte: 500 } }],
  },
})
```

### 支援的過濾器運算符 {/* #supported-filter-operators */}

|操作員|說明 |
| - | - |
|`$ne` | Not equal to |
| `$gt` | Greater than |
| `$gte` | Greater than or equal |
| `$lt` | Less than |
| `$lte` | Less than or equal |
| `$in` | In array |
| `$nin` | Not in array |
| `$and` | Logical AND |
| `$or` | Logical OR |

## 建築學 {/* #architecture */}

`ConvexVector`將每個索引儲存在其自己的表中，名為`mastra_vector_{indexName}`. Each record has the following structure:

* `id`：唯一的向量標識符
* `embedding`：向量資料（浮點數數組）
* `metadata`：可選的 JSON 元數據

向量相似性搜尋是透過 Mastra 適配器中的餘弦相似性進行的。這保持了設定的靈活性，但它不適用於大型生產向量集合。

`ConvexNativeVector`將每個 Mastra 向量索引儲存在專用的凸表中。它的查詢調用一個凸操作，該操作使用`ctx.vectorSearch`, then load the matched documents through a Convex query. This follows the Convex native vector search model:

* 向量索引聲明於`convex/schema.ts`.
* 向量搜尋從凸操作運行。
* `topK`必須介於`1` and `256`.
* 過濾器必須針對凸向量索引中列出的字段`filterFields`.
* 每個 Mastra 向量索引使用一個專用表以避免交叉索引結果。

當您需要在執行時間建立執行時間定義的索引、僅元資料查詢、複雜的篩選器運算子、基於篩選器的批次更新或刪除，或結果限制高於 Convex 的本機向量搜尋上限時，請使用外部向量資料庫。
