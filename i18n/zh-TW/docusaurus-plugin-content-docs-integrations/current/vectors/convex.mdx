# Convex 向量儲存

`ConvexVector` 類別透過 [Convex](https://convex.dev) 提供向量儲存與相似度搜尋。它將嵌入向量儲存在 Convex，並由 Mastra 轉接器執行餘弦相似度搜尋。

:::warning[開發階段的搜尋]

`ConvexVector` 透過 Mastra 儲存處理常式讀取符合條件的向量，再於 JavaScript 中篩選。接著計算餘弦相似度、排序，並傳回最相符的結果。適用於本機開發、測試及小型資料集。

若要在 Convex 上執行正式環境的向量搜尋，請使用 `ConvexNativeVector`。它使用 Convex 原生 `vectorSearch` API，因此需要已部署的 Convex 向量索引及 Convex action。

:::

```bash npm2yarn
npm install @mastra/convex@latest
```

### Convex 原生向量搜尋 {/* #native-convex-vector-search */}

正式環境的向量工作負載請使用 `ConvexNativeVector`。它將向量儲存在專用的 Convex 資料表，並查詢在 schema 中定義的 Convex 向量索引。

在 `convex/schema.ts` 中，為每個 Mastra 向量索引定義專用資料表：

```typescript title="convex/schema.ts"
import { defineSchema } from 'convex/server'
import { defineMastraNativeVectorTable } from '@mastra/convex/schema'

export default defineSchema({
  docs_vectors: defineMastraNativeVectorTable({
    dimensions: 1536,
  }),
})
```

在 `convex/mastra/nativeVector.ts` 中匯出原生向量處理常式：

```typescript title="convex/mastra/nativeVector.ts"
import {
  mastraNativeVectorAction,
  mastraNativeVectorMutation,
  mastraNativeVectorQuery,
} from '@mastra/convex/server'

export const query = mastraNativeVectorAction
export const read = mastraNativeVectorQuery
export const write = mastraNativeVectorMutation
```

在 Mastra 應用程式中，以已部署的資料表與向量索引設定 `ConvexNativeVector`：

```typescript title="src/mastra/index.ts"
import { ConvexNativeVector } from '@mastra/convex'

const vectorStore = new ConvexNativeVector({
  id: 'convex-native-vectors',
  deploymentUrl: process.env.CONVEX_URL!,
  adminAuthToken: process.env.CONVEX_ADMIN_KEY!,
  indexes: {
    docs: {
      tableName: 'docs_vectors',
      vectorIndexName: 'by_embedding',
      dimension: 1536,
    },
  },
})

const results = await vectorStore.query({
  indexName: 'docs',
  queryVector: embedding,
  topK: 10,
})
```

若要支援原生篩選，請在 Convex schema 中宣告篩選欄位。寫入向量時，原生向量處理常式會將對應的中繼資料欄位複製為文件的頂層欄位。

```typescript title="convex/schema.ts"
import { defineSchema, defineTable } from 'convex/server'
import { v } from 'convex/values'

export default defineSchema({
  docs_vectors: defineTable({
    id: v.string(),
    embedding: v.array(v.float64()),
    metadata: v.optional(v.any()),
    tenantId: v.string(),
  })
    .index('by_record_id', ['id'])
    .vectorIndex('by_embedding', {
      vectorField: 'embedding',
      dimensions: 1536,
      filterFields: ['tenantId'],
    }),
})
```

```typescript title="src/mastra/index.ts"
const vectorStore = new ConvexNativeVector({
  id: 'convex-native-vectors',
  deploymentUrl: process.env.CONVEX_URL!,
  adminAuthToken: process.env.CONVEX_ADMIN_KEY!,
  indexes: {
    docs: {
      tableName: 'docs_vectors',
      dimension: 1536,
      filterFields: ['tenantId'],
    },
  },
})

await vectorStore.upsert({
  indexName: 'docs',
  ids: ['chunk-1'],
  vectors: [embedding],
  metadata: [{ tenantId: 'acme', text: 'Account setup guide' }],
})

const results = await vectorStore.query({
  indexName: 'docs',
  queryVector: embedding,
  filter: { tenantId: 'acme' },
})
```

`ConvexNativeVector` 支援 Convex 原生向量篩選形式：單一欄位的相等條件，或以 `$or` 組合的多個相等條件。它不支援僅依中繼資料查詢、依篩選條件更新或依篩選條件刪除。更新與刪除時請使用向量 ID。

## 元資料過濾 {/* #metadata-filtering */}

`ConvexVector` 支援使用運算子依中繼資料篩選。轉接器從 Convex 載入向量後，才會套用這些篩選條件。

```typescript
// Simple equality
const results = await vectorStore.query({
  indexName: 'my_vectors',
  queryVector: embedding,
  filter: { category: 'documents' },
})

// Comparison operators
const results = await vectorStore.query({
  indexName: 'my_vectors',
  queryVector: embedding,
  filter: {
    price: { $gt: 100 },
    status: { $in: ['active', 'pending'] },
  },
})

// Logical operators
const results = await vectorStore.query({
  indexName: 'my_vectors',
  queryVector: embedding,
  filter: {
    $and: [{ category: 'electronics' }, { price: { $lte: 500 } }],
  },
})
```

### 支援的篩選運算子 {/* #supported-filter-operators */}

| 運算子 | 說明 |
| - | - |
| `$ne` | 不等於 |
| `$gt` | 大於 |
| `$gte` | 大於或等於 |
| `$lt` | 小於 |
| `$lte` | 小於或等於 |
| `$in` | 包含於陣列 |
| `$nin` | 不包含於陣列 |
| `$and` | 邏輯且 |
| `$or` | 邏輯或 |

## 架構 {/* #architecture */}

`ConvexVector` 將每個索引儲存在獨立的資料表中，資料表名稱為 `mastra_vector_{indexName}`。每筆記錄包含以下欄位：

- `id`：唯一的向量識別碼
- `embedding`：向量資料（浮點數陣列）
- `metadata`：選填的 JSON 中繼資料

Mastra 轉接器以餘弦相似度執行向量相似度搜尋。這讓設定方式保有彈性，但不適合正式環境中的大型向量集合。

`ConvexNativeVector` 將每個 Mastra 向量索引儲存在專用的 Convex 資料表。查詢時，它先呼叫使用 `ctx.vectorSearch` 的 Convex action，再透過 Convex query 載入相符文件。這符合 Convex 原生向量搜尋模型：

- 在 `convex/schema.ts` 中宣告向量索引。
- 從 Convex action 執行向量搜尋。
- `topK` 必須介於 `1` 與 `256` 之間。
- 篩選條件只能針對 Convex 向量索引的 `filterFields` 中列出的欄位。
- 每個 Mastra 向量索引使用一個專用資料表，以免傳回其他索引的結果。

若需要在執行階段建立動態定義的索引、僅依中繼資料查詢、使用複雜的篩選運算子、依篩選條件大量更新或刪除，或傳回超過 Convex 原生向量搜尋上限的結果，請使用外部向量資料庫。
