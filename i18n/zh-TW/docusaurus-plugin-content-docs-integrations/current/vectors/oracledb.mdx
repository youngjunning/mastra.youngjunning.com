# OracleDB 向量儲存

`OracleVector` 將嵌入向量儲存在 Oracle Database 的 `VECTOR` 欄位，並透過 Mastra 的向量介面提供存取。每個 Mastra 邏輯向量索引都透過登錄表對應到一個 Oracle 向量資料表；中繼資料則以 Oracle JSON 格式儲存，供結構化篩選使用。

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/oracledb@latest
```

## 用法 {/* #usage */}

```ts
import { OracleVector } from '@mastra/oracledb'

const vector = new OracleVector({
  id: 'oracle-vector',
  user: process.env.ORACLE_DATABASE_USER,
  password: process.env.ORACLE_DATABASE_PASSWORD,
  connectString: process.env.ORACLE_DATABASE_CONNECT_STRING,
})

await vector.createIndex({
  indexName: 'memory_messages',
  dimension: 1536,
  metric: 'cosine',
})

await vector.upsert({
  indexName: 'memory_messages',
  vectors: [embedding],
  metadata: [{ resource_id: 'user-1', thread_id: 'thread-1' }],
})

const results = await vector.query({
  indexName: 'memory_messages',
  queryVector,
  topK: 5,
  filter: { resource_id: 'user-1' },
})
```

`OracleVector` 預設使用精確搜尋，不建立近似向量索引。若資料集規模及延遲需求需要近似搜尋，可設定 IVF 或 HNSW。

## 建構函式範例 {/* #constructor-examples */}

### 與 OracleStore 共用連線集區 {/* #shared-pool-with-oraclestore */}

```ts
import { OracleStore, OracleVector } from '@mastra/oracledb'

const storage = new OracleStore({ id: 'oracle-storage', user, password, connectString })

const vector = new OracleVector({
  id: 'oracle-vector',
  poolManager: storage.getPoolManager(),
})
```

對於 Autonomous Database 與 mTLS 連線，請在同一個建構函式中傳入 `walletLocation`、`walletPassword` 和 `configDir`。

#### 索引配置 {/* #index-configuration */}

```ts
await vector.createIndex({
  indexName: 'support_articles',
  dimension: 1536,
  metric: 'cosine',
  indexConfig: {
    type: 'ivf',
    accuracy: 95,
    ivf: {
      neighborPartitions: 32,
    },
  },
})
```

預設設定為 `indexConfig: { type: 'none' }`，使用精確搜尋，無須調整近似索引參數。只有在資料量及延遲需求適合近似搜尋時，才使用 IVF 或 HNSW。HNSW 透過 `indexConfig: { type: 'hnsw', hnsw: { neighbors, efConstruction } }` 設定，並需要 Oracle Vector Pool 記憶體。對於本機或自行管理的資料庫，可使用 `configureVectorMemory()` 分配這部分記憶體。

### `listIndexes()` {/* #listindexes */}

傳回 Oracle 向量登錄表中記錄的 Mastra 邏輯索引名稱。

### `describeIndex()` {/* #describeindex */}

傳回 Oracle 索引中繼資料，包括實體資料表名稱、維度、向量數量、距離度量、索引類型、向量格式及設定的準確率。

### `deleteIndex()` {/* #deleteindex */}

刪除 Oracle 向量資料表，並移除對應邏輯索引的登錄紀錄。

### `updateVector()` {/* #updatevector */}

依 ID 或中繼資料篩選條件更新向量。必須提供 `id` 或 `filter` 其中一個，但不可同時提供。`update` 物件可包含 `vector`、`metadata`，或同時包含兩者。

```ts
await vector.updateVector({
  indexName: 'support_articles',
  id: 'doc-1',
  update: { metadata: { status: 'reviewed' } },
})
```

### `deleteVector()` {/* #deletevector */}

按 ID 刪除單一向量。

### `deleteVectors()` {/* #deletevectors */}

依 ID 清單或中繼資料篩選條件刪除多個向量。必須提供 `ids` 或 `filter` 其中一個，但不可同時提供。

### `buildIndex()` {/* #buildindex */}

為現有邏輯索引建立 Oracle 向量索引。若最終決定的索引類型為 `none`，此方法不會執行任何操作。

### `rebuildIndex()` {/* #rebuildindex */}

刪除並重新建立現有邏輯索引的 Oracle 向量索引，通常用於調整近似索引參數之後。

### 索引診斷 {/* #index-diagnostics */}

使用 `getIndexStatus({ indexName })` 查看 Oracle 系統目錄中的索引狀態；使用 `indexAccuracyQuery({ indexName, queryVector, topK, targetAccuracy })` 對近似索引執行 `DBMS_VECTOR.INDEX_ACCURACY_QUERY`。

### `configureVectorMemory()` {/* #configurevectormemory */}

分配 HNSW 索引所需的 Oracle Vector Pool 記憶體。此方法會執行 `ALTER SYSTEM SET VECTOR_MEMORY_SIZE`，因此需要具備相應權限的連線，例如 `SYSDBA` 或 `SYSTEM`。

### `disconnect()` {/* #disconnect */}

若連線集區管理器由 `OracleVector` 建立，此方法會關閉 Oracle 連線集區。若傳入 `pool` 或 `poolManager`，則須自行管理其生命週期。

## 元資料過濾器 {/* #metadata-filters */}

`OracleVector` 支援 Mastra 的標準中繼資料篩選語法。篩選條件會轉換為使用繫結值的 Oracle JSON 述詞：

* 純量比較使用 `JSON_VALUE`
* 陣列、欄位存在性及元素比對檢查使用 `JSON_EXISTS`
* 規則運算式篩選使用 `REGEXP_LIKE`
* 字串包含篩選使用不區分大小寫的 `LIKE`

```ts
const results = await vector.query({
  indexName: 'memory_messages',
  queryVector,
  topK: 5,
  filter: {
    resource_id: 'user-1',
    tags: { $contains: 'support' },
    score: { $gte: 0.8 },
    $or: [{ source: 'docs' }, { source: 'tickets' }],
  },
})
```

中繼資料以 Oracle 原生 JSON 格式儲存，因此也可以使用 DBeaver、SQL Developer 等標準 Oracle JDBC 工具直接讀取資料列。

若需要 Agent 為 `createVectorQueryTool()` 產生相容於 Oracle 的中繼資料篩選條件，請使用 `ORACLEDB_PROMPT`：

```ts
import { Agent } from '@mastra/core/agent'
import { createVectorQueryTool } from '@mastra/rag'
import { fastembed } from '@mastra/fastembed'
import { ORACLEDB_PROMPT } from '@mastra/oracledb'

const vectorQueryTool = createVectorQueryTool({
  vectorStoreName: 'oracle',
  indexName: 'support_articles',
  model: fastembed,
  enableFilter: true,
})

export const ragAgent = new Agent({
  id: 'oracle-rag-agent',
  name: 'Oracle RAG Agent',
  model: '__GATEWAY_OPENAI_MODEL__',
  instructions: `
Use the retrieval tool when you need source context.
Available metadata fields: resource_id, thread_id, source, category, tags.
${ORACLEDB_PROMPT}
`,
  tools: { vectorQueryTool },
})
```

## 回應類型 {/* #response-types */}

查詢結果以如下格式傳回：

```ts
interface QueryResult {

  score: number

```

## 使用範例 {/* #usage-example */}

```ts title="src/mastra/agents/oracle-agent.ts"
import { Agent } from '@mastra/core/agent'
import { Memory } from '@mastra/memory'
import { fastembed } from '@mastra/fastembed'
import { OracleStore, OracleVector } from '@mastra/oracledb'

const storage = new OracleStore({
  id: 'oracle-storage',
  user: process.env.ORACLE_DATABASE_USER,
  password: process.env.ORACLE_DATABASE_PASSWORD,
  connectString: process.env.ORACLE_DATABASE_CONNECT_STRING,
})

const vector = new OracleVector({
  id: 'oracle-vector',
  poolManager: storage.getPoolManager(),
})

export const oracleAgent = new Agent({
  id: 'oracle-agent',
  name: 'Oracle Agent',
  instructions: 'You are an assistant with OracleDB-backed memory and semantic recall.',
  model: '__GATEWAY_OPENAI_MODEL__',
  memory: new Memory({
    storage,
    vector,
    embedder: fastembed,
    options: {
      semanticRecall: { topK: 3, messageRange: 2 },
    },
  }),
})
```
