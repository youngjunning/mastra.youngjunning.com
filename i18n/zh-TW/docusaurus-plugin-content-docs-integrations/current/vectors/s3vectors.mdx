# Amazon S3 Vectors 儲存

`S3Vectors` 類別透過 [Amazon S3 Vectors（預覽版）](https://docs.aws.amazon.com/AmazonS3/latest/userguide/s3-vectors.html)提供向量搜尋。它將向量存入**向量儲存貯體**，在**向量索引**中執行相似度搜尋，並支援以 JSON 為基礎的中繼資料篩選條件。

:::warning

Amazon S3 Vectors 仍處於預覽階段。預覽功能可能隨時變更或移除，恕不另行通知，且不受 AWS 服務等級協定（SLA）保障。其行為、限制及區域供應情況也可能隨時改變。為配合 AWS 的變更，此程式庫可能引入不相容的變更。


:::

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/s3vectors@latest
```

## 使用範例 {/* #usage-example */}

```typescript
import { S3Vectors } from '@mastra/s3vectors'

const store = new S3Vectors({
  id: 's3-vectors',
  vectorBucketName: process.env.S3_VECTORS_BUCKET_NAME!, // e.g. "my-vector-bucket"
  clientConfig: {
    region: process.env.AWS_REGION!, // credentials use the default AWS provider chain
  },
  // Optional: mark large/long-text fields as non-filterable at index creation time
  nonFilterableMetadataKeys: ['content'],
})

// Create an index (names are normalized: "_" → "-" and lowercased)
await store.createIndex({
  indexName: 'my_index',
  dimension: 1536,
  metric: 'cosine', // "euclidean" also supported; "dotproduct" is NOT supported
})

// Upsert vectors (ids auto-generated if omitted). Date values in metadata are serialized to epoch ms.
const ids = await store.upsert({
  indexName: 'my_index',
  vectors: [
    [0.1, 0.2 /* … */],
    [0.3, 0.4 /* … */],
  ],
  metadata: [
    {
      text: 'doc1',
      genre: 'documentary',
      year: 2023,
      createdAt: new Date('2024-01-01'),
    },
    { text: 'doc2', genre: 'comedy', year: 2021 },
  ],
})

// Query with metadata filters (implicit AND is canonicalized)
const results = await store.query({
  indexName: 'my-index',
  queryVector: [0.1, 0.2 /* … */],
  topK: 10, // Service-side limits may apply (commonly 30)
  filter: { genre: { $in: ['documentary', 'comedy'] }, year: { $gte: 2020 } },
  includeVector: false, // set true to include raw vectors (may trigger a secondary fetch)
})

// Clean up resources (closes the underlying HTTP handler)
await store.disconnect()
```

## 過濾語法 {/* #filter-syntax */}

S3 Vectors 僅支援部分運算子和值類型。Mastra 的篩選條件轉換器會：

* **將隱含的 AND 正規化**：`{a:1,b:2}` → `{ $and: [{a:1},{b:2}] }`。
* **將 Date 值轉為 Unix 紀元毫秒數**，用於數值比較或作為陣列元素。
* **禁止在相等比較中使用 Date**，包括 `field: value` 和 `$eq/$ne`。相等比較的值必須是 **string | number | boolean**。
* **拒絕**以 null 或 undefined 進行相等比較。也不支援**陣列相等比較**；請使用 `$in` 或 `$nin`。
* 頂層邏輯運算子僅允許 **`$and` / `$or`**。
* 邏輯運算子中必須包含**欄位條件**，不可直接放入運算子。

**支援的運算子：**

* **邏輯：** `$and`、`$or`（非空陣列）
* **基本比較：** `$eq`、`$ne`（string | number | boolean）
* **數值比較：** `$gt`、`$gte`、`$lt`、`$lte`（number，或轉為 Unix 紀元毫秒數的 `Date`）
* **陣列比對：** `$in`、`$nin`（由 string | number | boolean 組成的非空陣列；`Date` 會轉為 Unix 紀元毫秒數）
* **欄位存在性：** `$exists`（boolean）

**不支援且會遭拒絕的運算子：** `$not`、`$nor`、`$regex`、`$all`、`$elemMatch`、`$size`、`$text` 等。

**範例：**

```typescript oxfmt:false
// Implicit AND
{ genre: { $in: ["documentary", "comedy"] }, year: { $gte: 2020 } }

// Explicit logicals and ranges
{
  $and: [
    { price: { $gte: 100, $lte: 1000 } },
    { $or: [{ stock: { $gt: 0 } }, { preorder: true }] }
  ]
}

// Dates in range (converted to epoch ms)
{ timestamp: { $gt: new Date("2024-01-01T00:00:00Z") } }
```

:::note

如果在建立索引時設定了 `nonFilterableMetadataKeys`，這些鍵仍會儲存，但**不能**用於篩選。

:::

## 錯誤處理 {/* #error-handling */}

此向量儲存會擲出來自 `@mastra/core/error` 的 `MastraError` 執行個體：

```typescript
import { MastraError } from '@mastra/core/error'

try {
  await store.query({
    indexName: 'index-name',
    queryVector: queryVector,
  })
} catch (error) {
  if (error instanceof MastraError) {
    console.log(error.id) // 'MASTRA_VECTOR_S3VECTORS_QUERY_FAILED'
    console.log(error.domain) // 'STORAGE'
    console.log(error.category) // 'USER' | 'THIRD_PARTY'
    console.log(error.details) // Additional error context
  }
}
```

## 環境變數 {/* #environment-variables */}

在應用程式中設定此向量儲存時，通常需要以下環境變數：

* `S3_VECTORS_BUCKET_NAME`：S3 **向量儲存貯體**名稱，用於設定 `vectorBucketName`。
* `AWS_REGION`：S3 Vectors 儲存貯體所在的 AWS 區域。
* **AWS 憑證**：透過 AWS SDK 的標準憑證提供者鏈取得，例如 `AWS_ACCESS_KEY_ID`、`AWS_SECRET_ACCESS_KEY` 或 `AWS_PROFILE`。

## 最佳實踐 {/* #best-practices */}

* 選擇與嵌入模型相符的距離度量（`cosine` 或 `euclidean`）。不支援 `dotproduct`。
* 讓**可篩選的**中繼資料保持精簡、結構化，值使用 string、number 或 boolean。將 `content` 等長文字設為**不可篩選**。
* 對巢狀中繼資料使用**點分路徑**；對複雜條件明確使用 `$and` 或 `$or`。
* 避免在頻繁執行的路徑中呼叫 `describeIndex()`。`count` 透過分頁呼叫 `ListVectors` 計算，複雜度為 **O(n)**。
* 只有需要原始向量時才使用 `includeVector: true`。
