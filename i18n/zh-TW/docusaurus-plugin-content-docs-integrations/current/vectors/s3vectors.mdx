# Amazon S3 向量存儲

這`S3Vectors`類別提供向量搜尋使用[Amazon S3 向量（預覽）](https://docs.aws.amazon.com/AmazonS3/latest/userguide/s3-vectors.html)。它將向量儲存在**向量桶**並執行相似性搜索**向量索引**，具有基於 JSON 的元資料過濾器。

：：：警告



:::

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/s3vectors@latest
```

## 使用範例 {/* #usage-example */}

```typescript
import { S3Vectors } from '@mastra/s3vectors'

const store = new S3Vectors({
  id: 's3-vectors',
  vectorBucketName: process.env.S3_VECTORS_BUCKET_NAME!, // e.g. "my-vector-bucket"
  clientConfig: {
    region: process.env.AWS_REGION!, // credentials use the default AWS provider chain
  },
  // Optional: mark large/long-text fields as non-filterable at index creation time
  nonFilterableMetadataKeys: ['content'],
})

// Create an index (names are normalized: "_" → "-" and lowercased)
await store.createIndex({
  indexName: 'my_index',
  dimension: 1536,
  metric: 'cosine', // "euclidean" also supported; "dotproduct" is NOT supported
})

// Upsert vectors (ids auto-generated if omitted). Date values in metadata are serialized to epoch ms.
const ids = await store.upsert({
  indexName: 'my_index',
  vectors: [
    [0.1, 0.2 /* … */],
    [0.3, 0.4 /* … */],
  ],
  metadata: [
    {
      text: 'doc1',
      genre: 'documentary',
      year: 2023,
      createdAt: new Date('2024-01-01'),
    },
    { text: 'doc2', genre: 'comedy', year: 2021 },
  ],
})

// Query with metadata filters (implicit AND is canonicalized)
const results = await store.query({
  indexName: 'my-index',
  queryVector: [0.1, 0.2 /* … */],
  topK: 10, // Service-side limits may apply (commonly 30)
  filter: { genre: { $in: ['documentary', 'comedy'] }, year: { $gte: 2020 } },
  includeVector: false, // set true to include raw vectors (may trigger a secondary fetch)
})

// Clean up resources (closes the underlying HTTP handler)
await store.disconnect()
```

## 過濾語法 {/* #filter-syntax */}

S3 Vectors 支援運算子和值類型的嚴格子集。 Mastra 過濾器轉換器：

* **規範化隱式 AND**: `{a:1,b:2}` → `{ $and: [{a:1},{b:2}] }`.
* **標準化日期值**到 epoch ms 進行數值比較和數組元素。
* **不允許日期**處於平等地位（`field: value` or `$eq/$ne`). Equality values must be **string | number | boolean**.
* **拒絕**null/未定義的平等。**array equality** isn't supported (use `$in`/`$nin`).
* 僅有&#x7684;**`$and` / `$or`** are allowed as top-level logical operators.
* 邏輯運算子必須包含**field conditions** (not direct operators).

**支援的營運商：**

* **邏輯：** `$and`, `$or` (non-empty arrays)
* **基本的：** `$eq`, `$ne` (string | number | boolean)
* **數字：** `$gt`, `$gte`, `$lt`, `$lte` (number or `Date` → epoch ms)
* **大批：** `$in`, `$nin` (non-empty arrays of string | number | boolean; `Date` → epoch ms)
* **元素：** `$exists` (boolean)

**不支援/不允許（拒絕）：** `$not`, `$nor`, `$regex`, `$all`, `$elemMatch`, `$size`, `$text`, etc.

**範例：**

```typescript oxfmt:false
// Implicit AND
{ genre: { $in: ["documentary", "comedy"] }, year: { $gte: 2020 } }

// Explicit logicals and ranges
{
  $and: [
    { price: { $gte: 100, $lte: 1000 } },
    { $or: [{ stock: { $gt: 0 } }, { preorder: true }] }
  ]
}

// Dates in range (converted to epoch ms)
{ timestamp: { $gt: new Date("2024-01-01T00:00:00Z") } }
```

：：：筆記

如果你設定`nonFilterableMetadataKeys` at index creation, those keys are stored but **can't** be used in filters.

## 錯誤處理 {/* #error-handling */}

店裡丟`MastraError` instances from `@mastra/core/error`:

```typescript
import { MastraError } from '@mastra/core/error'

try {
  await store.query({
    indexName: 'index-name',
    queryVector: queryVector,
  })
} catch (error) {
  if (error instanceof MastraError) {
    console.log(error.id) // 'MASTRA_VECTOR_S3VECTORS_QUERY_FAILED'
    console.log(error.domain) // 'STORAGE'
    console.log(error.category) // 'USER' | 'THIRD_PARTY'
    console.log(error.details) // Additional error context
  }
}
```

## 環境變數 {/* #environment-variables */}

連接應用程式時的典型環境變數：

* `S3_VECTORS_BUCKET_NAME`：你的S3**vector bucket** name (used to populate `vectorBucketName`).
* `AWS_REGION`：S3 向量儲存桶的 AWS 區域。
* **AWS 憑證**：透過標準 AWS SDK Provider鏈（`AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY`, `AWS_PROFILE`, etc.).

## 最佳實踐 {/* #best-practices */}

* 選擇指標 (`cosine` or `euclidean`) to match your embedding model. `dotproduct` isn't supported.
* 保持**filterable** metadata small and structured (string/number/boolean). Store large text (e.g., `content`) as **non-filterable**.
* 使用**dotted paths** for nested metadata and explicit `$and`/`$or` for complex logic.
* 避免打電話`describeIndex()` on hot paths. `count` is computed with paginated `ListVectors` (**O(n)**).
* 使用`includeVector: true` only when you need raw vectors.
