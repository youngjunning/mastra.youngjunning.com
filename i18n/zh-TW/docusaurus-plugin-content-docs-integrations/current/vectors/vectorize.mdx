# Cloudflare 向量儲存

CloudflareVector 類別使用 [Cloudflare Vectorize](https://developers.cloudflare.com/vectorize/) 進行向量搜尋。這項向量資料庫服務與 Cloudflare 的邊緣網路整合。

查詢結果會以下列格式傳回：

```typescript
interface QueryResult {
  id: string
  score: number
  metadata?: Record<string, any>
  vector?: number[]
}
```

## 錯誤處理 {/* #error-handling */}

向量儲存會擲出 `@mastra/core/error` 所定義的 `MastraError` 執行個體：

```typescript
import { MastraError } from '@mastra/core/error'

try {
  await store.query({
    indexName: 'index_name',
    queryVector: queryVector,
  })
} catch (error) {
  if (error instanceof MastraError) {
    console.log(error.id) // 'MASTRA_VECTOR_VECTORIZE_QUERY_FAILED'
    console.log(error.domain) // 'STORAGE'
    console.log(error.category) // 'USER' | 'THIRD_PARTY'
    console.log(error.details) // Additional error context
  }
}
```

## 環境變數 {/* #environment-variables */}

必須設定下列環境變數：

* `CLOUDFLARE_ACCOUNT_ID`：你的 Cloudflare 帳號 ID
* `CLOUDFLARE_API_TOKEN`：具備 Vectorize 權限的 Cloudflare API 權杖
