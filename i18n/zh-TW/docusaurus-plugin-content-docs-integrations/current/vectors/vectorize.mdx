# Cloudflare 向量商店

CloudflareVector 類別提供向量搜索，使用[Cloudflare Vectorize](https://developers.cloudflare.com/vectorize/)，與 Cloudflare 邊緣網路整合的向量資料庫服務。


## 錯誤處理 {/* #error-handling */}

店裡丟`MastraError` instances from `@mastra/core/error`:

```typescript
import { MastraError } from '@mastra/core/error'

try {
  await store.query({
    indexName: 'index_name',
    queryVector: queryVector,
  })
} catch (error) {
  if (error instanceof MastraError) {
    console.log(error.id) // 'MASTRA_VECTOR_VECTORIZE_QUERY_FAILED'
    console.log(error.domain) // 'STORAGE'
    console.log(error.category) // 'USER' | 'THIRD_PARTY'
    console.log(error.details) // Additional error context
  }
}
```

## 環境變數 {/* #environment-variables */}

所需的環境變數：

* `CLOUDFLARE_ACCOUNT_ID`：您的 Cloudflare 帳戶 ID
* `CLOUDFLARE_API_TOKEN`：具有 Vectorize 權限的 Cloudflare API 令牌
