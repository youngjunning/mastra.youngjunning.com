# 色度向量商店

ChromaVector 類別提供向量搜索，使用[Chroma](https://docs.trychroma.com/docs/overview/getting-started)，一個開源嵌入資料庫。它提供具有元資料過濾和混合搜尋功能的高效向量搜尋。

## 運行 Chroma 伺服器 {/* #running-a-chroma-server */}

如果您是 Chroma Cloud 用戶，請提供`ChromaVector` constructor your API key, tenant, and database name.

當您安裝`@mastra/chroma` package, you get access to the [Chroma CLI](https://docs.trychroma.com/docs/cli/db), which can set these as environment variables for you: `chroma db connect [DB-NAME] --env-file`.

否則，您有多種選擇來設定單節點 Chroma 伺服器：

* `chroma run`. You can find more configuration options on the [Chroma docs](https://docs.trychroma.com/docs/cli/run).
* 繼續運行[Docker](https://docs.trychroma.com/guides/deploy/docker) using the official Chroma image.
* 在您選擇的Provider上部署您自己的 Chroma 伺服器。 Chroma 提供了範例模板[AWS](https://docs.trychroma.com/guides/deploy/aws), [Azure](https://docs.trychroma.com/guides/deploy/azure), and [GCP](https://docs.trychroma.com/guides/deploy/gcp).

<PropertiesTable
  content={[

  type: 'number[]',
  isOptional: true,
  description: 'New vector to replace the existing one',
},
{
  name: 'metadata',
  type: 'Record<string, any>',
  isOptional: true,

例子：

```typescript
// Update by ID
await vectorStore.updateVector({
  indexName: 'docs',
  id: 'vec_123',
  update: { metadata: { status: 'reviewed' } },
})

// Update by filter
await vectorStore.updateVector({
  indexName: 'docs',
  filter: { source_id: 'manual.pdf' },
  update: { metadata: { version: 2 } },
})
```

### `deleteVectors()` {/* #deletevectors */}

透過 ID 或元資料過濾器刪除多個向量。此方法支援批量刪除和基於來源的向量管理。任何一個`ids` or `filter` must be provided, but not both.

<PropertiesTable
  content={[
{
  name: 'indexName',
  type: 'string',
  description: 'Name of the index containing the vectors to delete',
},
{
  name: 'ids',
  type: 'string[]',
  isOptional: true,
  description: 'Array of vector IDs to delete (mutually exclusive with filter)',
},
{
  name: 'filter',
  type: 'Record<string, any>',
  isOptional: true,
  description: 'Metadata filter to identify vectors to delete (mutually exclusive with ids)',
},
]}
/>

例子：

```typescript
// Delete all chunks from a document
await vectorStore.deleteVectors({
  indexName: 'docs',
  filter: { source_id: 'manual.pdf' },
})

// Delete multiple vectors by ID
await vectorStore.deleteVectors({
  indexName: 'docs',
  ids: ['vec_1', 'vec_2', 'vec_3'],
})

// Delete old temporary documents
await vectorStore.deleteVectors({
  indexName: 'docs',
  filter: {
    $and: [{ bucket: 'temp' }, { indexed_at: { $lt: '2025-01-01' } }],
  },
})
```

## 錯誤處理 {/* #error-handling */}

店裡丟`MastraError` instances from `@mastra/core/error`:

```typescript
import { MastraError } from '@mastra/core/error'

try {
  await store.query({
    indexName: 'index_name',
    queryVector: queryVector,
  })
} catch (error) {
  if (error instanceof MastraError) {
    console.log(error.id) // 'MASTRA_VECTOR_CHROMA_QUERY_FAILED'
    console.log(error.domain) // 'MASTRA_VECTOR'
    console.log(error.category) // 'USER' | 'THIRD_PARTY'
    console.log(error.details) // Additional error context
  }
}
```
