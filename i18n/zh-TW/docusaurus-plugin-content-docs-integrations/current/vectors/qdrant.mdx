# Qdrant 向量儲存

`QdrantVector` 類別透過向量相似度搜尋引擎 [Qdrant](https://qdrant.tech/) 提供向量搜尋功能。
Qdrant 提供可用於正式環境的服務和便利的 API，可儲存、搜尋及管理向量，並支援額外的 payload 資料與擴充篩選功能。

#### 建立包含 `named vectors` 的集合 {/* #creating-a-named-vectors-collection */}

```typescript
// Create a collection with multiple named vector spaces
await store.createIndex({
  indexName: 'multi_modal',
  dimension: 768, // fallback
  namedVectors: {
    text: { size: 768, distance: 'cosine' },
    image: { size: 512, distance: 'euclidean' },
  },
})
```

#### `named vectors` {/* #named-vectors */}

Qdrant 支援[在一個集合中儲存多個向量](https://qdrant.tech/documentation/concepts/vectors/#named-vectors)，每個向量欄位都有自己的名稱。使用 `using` 參數選取要查詢的向量欄位：

```typescript
const results = await store.query({
  indexName: 'my_index',
  queryVector: embedding,
  topK: 10,
  using: 'title_embedding', // Query against a specific named vector
})
```

### `createPayloadIndex()` {/* #createpayloadindex */}

在集合欄位上建立 payload（中繼資料）索引，以便有效率地篩選。Qdrant Cloud 及任何設為 `strict_mode_config = true` 的 Qdrant 執行個體都**必須**建立此索引。

<PropertiesTable

  description: '是否等待作業完成',

```typescript
// Create a keyword index for filtering by source
await store.createPayloadIndex({
  indexName: 'my_index',
  fieldName: 'source',
  fieldSchema: 'keyword',
})

const results = await store.query({
  indexName: 'my_index',
  queryVector: queryVector,
  filter: { source: 'document-a' },
})
```

## 回應類型 {/* #response-types */}

查詢結果以如下格式傳回：

```typescript
interface QueryResult {
  id: string
  score: number
  metadata?: Record<string, any>
  vector?: number[] // Only included if includeVector is true
}
```

## 錯誤處理 {/* #error-handling */}

此向量儲存會擲出來自 `@mastra/core/error` 的 `MastraError` 執行個體：

```typescript
import { MastraError } from '@mastra/core/error'

try {
  await store.query({
    indexName: 'index_name',
    queryVector: queryVector,
  })
} catch (error) {
  if (error instanceof MastraError) {
    console.log(error.id) // 'MASTRA_VECTOR_QDRANT_QUERY_FAILED'
    console.log(error.domain) // 'STORAGE'
    console.log(error.category) // 'USER' | 'THIRD_PARTY'
    console.log(error.details) // Additional error context
  }
}
```
