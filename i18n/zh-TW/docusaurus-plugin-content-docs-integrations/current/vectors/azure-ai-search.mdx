# Azure AI 搜尋向量儲存

這`AzureAISearchVector`類別提供向量搜尋使用[Azure 人工智慧搜尋](https://learn.microsoft.com/azure/search/vector-search-overview)，微軟的雲端搜尋服務，具有原生向量搜尋支援。它在現有的 Azure AI 搜尋資源之上提供元資料過濾、混合（向量 + 文字）搜尋和語義排名。

## Azure 特定的查詢方法 {/* #azure-specific-query-methods */}

超出標準`query()` method, `AzureAISearchVector` exposes Azure AI Search-specific capabilities:

* **`advancedQuery()`**：直接公開 Azure AI 搜尋向量查詢參數，包括窮舉搜尋、查詢加權、過採樣、多向量搜尋的附加向量查詢、預/後過濾模式和基於文字的查詢類型（`semantic`, `hybrid`).
* **`semanticQuery()`**：方便的包裝`advancedQuery()` for semantic ranking with a configured semantic configuration.
* **`hybridQuery()`**：將向量搜尋與全文查詢結合的便捷包裝器。
* **`multiVectorQuery()`**：方便的包裝器，用於一次查詢多個加權向量。
* **`exactQuery()`**：方便包裝`advancedQuery()` with exhaustive (non-approximate) search enabled.

這些方法是附加的：`query()` remains the Memory-compatible entry point used by Mastra's semantic recall.

## 回應類型 {/* #response-types */}

查詢結果以如下格式傳回：

```typescript
interface QueryResult {
  id: string
  score: number
  metadata: Record<string, any>
  document?: string // Matched document content
  vector?: number[] // Only included if includeVector is true
}
```
