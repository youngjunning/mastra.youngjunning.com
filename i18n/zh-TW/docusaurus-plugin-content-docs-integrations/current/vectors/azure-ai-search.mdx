# Azure AI Search 向量儲存

`AzureAISearchVector` 類別使用 [Azure AI Search](https://learn.microsoft.com/azure/search/vector-search-overview) 執行向量搜尋。Azure AI Search 是 Microsoft 原生支援向量搜尋的雲端搜尋服務。已有 Azure AI Search 資源時，可透過此類別篩選中繼資料、混合搜尋向量與文字，並依語意排名。

## Azure AI Search 專用查詢方法 {/* #azure-specific-query-methods */}

除了標準的 `query()` 方法，`AzureAISearchVector` 還提供下列方法，可使用 Azure AI Search 專有的查詢功能。

* **`advancedQuery()`** 可直接設定 Azure AI Search 的向量查詢參數，包括窮舉搜尋、查詢權重、超取樣、多向量搜尋用的額外向量查詢、搜尋前或搜尋後的篩選模式，以及以文字為基礎的查詢類型（`semantic`、`hybrid`）。
* **`semanticQuery()`** 封裝 `advancedQuery()`，方便套用已建立的語意設定來進行語意排名。
* **`hybridQuery()`** 將向量搜尋與全文查詢封裝在同一個方法中。
* **`multiVectorQuery()`** 讓你在同一個查詢中使用多個各帶權重的向量。
* **`exactQuery()`** 封裝 `advancedQuery()`，並開啟窮舉搜尋以取得精確結果。

這些方法擴充了查詢功能。Mastra 的語意回溯仍採用與 Memory 相容的 `query()` 作為查詢入口。

## 回應類型 {/* #response-types */}

查詢結果會依下列格式傳回。

```typescript
interface QueryResult {
  id: string
  score: number
  metadata: Record<string, any>
  document?: string // Matched document content
  vector?: number[] // Only included if includeVector is true
}
```
