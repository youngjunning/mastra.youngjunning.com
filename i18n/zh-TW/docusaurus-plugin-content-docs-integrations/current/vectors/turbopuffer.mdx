# Turbopuffer 向量儲存

TurbopufferVector 類別透過 [Turbopuffer](https://turbopuffer.com/) 提供向量搜尋。Turbopuffer 是針對 RAG 應用程式最佳化的高效能向量資料庫，能快速搜尋相似向量，並提供進階篩選功能及高效率的儲存管理。

```typescript
  id: string
  score: number
  metadata?: Record<string, any>
  vector?: number[] // Only included if includeVector is true
}
```

## 結構描述設定 {/* #schema-configuration */}

你可以透過 `schemaConfigForIndex` 選項，為不同索引明確定義各自的結構描述：

```typescript
schemaConfigForIndex: (indexName: string) => {
  // Mastra's default embedding model and index for memory messages:
  if (indexName === 'memory_messages_384') {
    return {
      dimensions: 384,
      schema: {
        thread_id: {
          type: 'string',
          filterable: true,
        },
      },
    }
  } else {
    throw new Error(`TODO: add schema for index: ${indexName}`)
  }
}
```

## 錯誤處理 {/* #error-handling */}

這個向量儲存會擲出由 `@mastra/core/error` 定義的 `MastraError` 執行個體：

```typescript
import { MastraError } from '@mastra/core/error'

try {
  await store.query({
    indexName: 'index_name',
    queryVector: queryVector,
  })
} catch (error) {
  if (error instanceof MastraError) {
    console.log(error.id) // 'MASTRA_VECTOR_TURBOPUFFER_QUERY_FAILED'
    console.log(error.domain) // 'STORAGE'
    console.log(error.category) // 'USER' | 'THIRD_PARTY'
    console.log(error.details) // Additional error context
  }
}
```
