# Weaviate向量存儲

這`WeaviateVector`類別提供向量搜尋使用[韋維阿特](https://weaviate.io/)，一個開源向量資料庫。集合創建於`vectorizer: none`，因此 Mastra 提供嵌入，Mastra 代表您管理 id、距離指標和元資料過濾。

## 基本用法 {/* #basic-usage */}

```ts filename="index.ts" showLineNumbers copy
import { WeaviateVector } from '@mastra/weaviate'

const store = new WeaviateVector({ id: 'my-store' })

await store.createIndex({ indexName: 'my_index', dimension: 1536, metric: 'cosine' })

await store.upsert({
  indexName: 'my_index',
  vectors: [[0.1, 0.2 /* ... */]],
  metadata: [{ text: 'sample', category: 'docs' }],
})

const results = await store.query({
  indexName: 'my_index',
  queryVector: [0.1, 0.2 /* ... */],
  topK: 5,
  filter: { category: 'docs' },
})
```

## 連接Weaviate雲 {/* #connecting-to-weaviate-cloud */}

```ts showLineNumbers copy
const store = new WeaviateVector({
  id: 'my-store',
  httpHost: 'my-cluster.weaviate.network',
  httpPort: 443,
  httpSecure: true,
  grpcHost: 'grpc-my-cluster.weaviate.network',
  grpcPort: 443,
  grpcSecure: true,
  apiKey: process.env.WEAVIATE_API_KEY,
})
```

## 元資料過濾 {/* #metadata-filtering */}

過濾器使用 MongoDB 風格的語法並轉換為 Weaviate 的本機過濾器 API：

* 比較：`$eq`, `$ne`, `$gt`, `$gte`, `$lt`, `$lte`
* 大批：`$in`, `$nin`, `$all`
* 元素：`$exists`
* 邏輯：`$and`, `$or`, `$not`

```ts showLineNumbers copy
const results = await store.query({
  indexName: 'my_index',
  queryVector: [0.1, 0.2 /* ... */],
  filter: {
    $and: [{ category: { $in: ['docs', 'guides'] } }, { views: { $gt: 100 } }],
  },
})
```

### 注意事項和限制 {/* #notes-and-limitations */}

* Weaviate 不區分明確儲存的`null` from an absent field, so null round-tripping isn't supported.
* `$regex`, `$size`, `$elemMatch`, `$nor`, and `$contains` aren't supported.
* Weaviate 的集合名稱大寫。原始索引名稱保留在集合描述中並由`listIndexes()` and `describeIndex()`.
