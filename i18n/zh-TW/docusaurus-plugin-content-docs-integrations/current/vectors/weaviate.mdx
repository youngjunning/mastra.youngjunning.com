# Weaviate 向量儲存

`WeaviateVector` 類別透過開放原始碼向量資料庫 [Weaviate](https://weaviate.io/) 提供向量搜尋功能。建立集合時會設為 `vectorizer: none`，因此嵌入向量由 Mastra 提供。Mastra 也會代為處理 ID、距離度量及元資料篩選。

這個向量儲存也實作了 `listIndexes()`、`describeIndex()`、`deleteIndex()`、`updateVector()`、`deleteVector()` 和 `deleteVectors()`。

## 基本用法 {/* #basic-usage */}

```ts filename="index.ts" showLineNumbers copy
import { WeaviateVector } from '@mastra/weaviate'

const store = new WeaviateVector({ id: 'my-store' })

await store.createIndex({ indexName: 'my_index', dimension: 1536, metric: 'cosine' })

await store.upsert({
  indexName: 'my_index',
  vectors: [[0.1, 0.2 /* ... */]],
  metadata: [{ text: 'sample', category: 'docs' }],
})

const results = await store.query({
  indexName: 'my_index',
  queryVector: [0.1, 0.2 /* ... */],
  topK: 5,
  filter: { category: 'docs' },
})
```

## 連線至 Weaviate Cloud {/* #connecting-to-weaviate-cloud */}

```ts showLineNumbers copy
const store = new WeaviateVector({
  id: 'my-store',
  httpHost: 'my-cluster.weaviate.network',
  httpPort: 443,
  httpSecure: true,
  grpcHost: 'grpc-my-cluster.weaviate.network',
  grpcPort: 443,
  grpcSecure: true,
  apiKey: process.env.WEAVIATE_API_KEY,
})
```

## 元資料篩選 {/* #metadata-filtering */}

篩選條件採用類似 MongoDB 的語法。Mastra 會將條件轉換成 Weaviate 原生篩選 API 使用的格式：

* 比較運算子：`$eq`、`$ne`、`$gt`、`$gte`、`$lt`、`$lte`
* 陣列運算子：`$in`、`$nin`、`$all`
* 元素運算子：`$exists`
* 邏輯運算子：`$and`、`$or`、`$not`

```ts showLineNumbers copy
const results = await store.query({
  indexName: 'my_index',
  queryVector: [0.1, 0.2 /* ... */],
  filter: {
    $and: [{ category: { $in: ['docs', 'guides'] } }, { views: { $gt: 100 } }],
  },
})
```

### 注意事項與限制 {/* #notes-and-limitations */}

* Weaviate 無法區分明確儲存的 `null` 和不存在的欄位，因此寫入空值後，無法將它原樣讀回。
* 不支援 `$regex`、`$size`、`$elemMatch`、`$nor` 和 `$contains`。
* Weaviate 會將集合名稱的第一個字母轉成大寫。集合的描述會保留原始索引名稱，而 `listIndexes()` 和 `describeIndex()` 都會傳回這個原始名稱。
