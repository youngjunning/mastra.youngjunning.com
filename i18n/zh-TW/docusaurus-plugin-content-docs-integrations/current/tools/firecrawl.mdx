# Firecrawl

Firecrawl 是一套網頁資料 API，可將網站內容轉換為乾淨的 Markdown 或結構化 JSON。本指南會帶你將 Firecrawl 整合至 Mastra Tool，讓 Agent 和 Workflow 能在需要時搜尋及擷取即時網頁資料。

## 先決條件 {/* #prerequisites */}

- 已安裝 Node.js `v22.13.0` 或更新版本
- Firecrawl API 金鑰（可至 [https://firecrawl.dev](https://firecrawl.dev) 取得）
- 由受支援的 [Model Provider](/models) 核發的 API 金鑰
- 已建立的 Mastra 專案。若尚未建立，請依照[入門指南](/docs)建立專案。

## 安裝 {/* #installation */}

安裝 Firecrawl SDK：

```bash npm2yarn
npm install firecrawl
```

## 設定環境變數 {/* #configure-environment-variables */}

在專案根目錄建立 `.env` 檔案：

```bash title=".env"
FIRECRAWL_API_KEY=fc-your-api-key
# Optional: FIRECRAWL_API_URL=http://localhost:3002
```

## 建立 Firecrawl Tool {/* #build-the-firecrawl-tools */}

建立一個 Tool 檔案，讓 Mastra 能使用 Firecrawl 的搜尋和網頁擷取功能。

<Steps>
  <StepItem>
    建立 `src/mastra/tools/firecrawl.ts`，並設定 Firecrawl：

    ```ts title="src/mastra/tools/firecrawl.ts"
    import { Firecrawl } from 'firecrawl'
    import { createTool } from '@mastra/core/tools'
    import { z } from 'zod'

    const firecrawl = new Firecrawl({ apiKey: process.env.FIRECRAWL_API_KEY! })

    export const firecrawlSearch = createTool({
      id: 'firecrawl-search',
      description: 'Search the web and return top results.',
      inputSchema: z.object({ query: z.string().min(1) }),
      outputSchema: z.object({
        results: z.array(
          z.object({
            title: z.string().nullable(),
            url: z.string(),
          }),
        ),
      }),
      execute: async ({ query }) => {
        const results = await firecrawl.search(query, { limit: 3 })
        return {
          results: (results.web ?? []).map(item => ({
            title: item.title ?? null,
            url: item.url,
          })),
        }
      },
    })

    export const firecrawlScrape = createTool({
      id: 'firecrawl-scrape',
      description: 'Scrape a URL and return markdown content.',
      inputSchema: z.object({ url: z.string().url() }),
      outputSchema: z.object({ markdown: z.string() }),
      execute: async ({ url }) => {
        const result = await firecrawl.scrape(url, {
          formats: ['markdown'],
          onlyMainContent: true,
        })
        return { markdown: result.markdown ?? '' }
      },
    })
    ```
  </StepItem>

  <StepItem>
    在 `src/mastra/agents/web-agent.ts` 中建立新的 Agent：

    ```ts title="src/mastra/agents/web-agent.ts"
    import { Agent } from '@mastra/core/agent'
    import { firecrawlSearch, firecrawlScrape } from '../tools/firecrawl'

    export const webAgent = new Agent({
      id: 'web-agent',
      name: 'Web Agent',
      instructions: 'Use Firecrawl tools to search and scrape web pages, then summarize the results.',
      model: '__GATEWAY_OPENAI_MODEL__',
      tools: { firecrawlSearch, firecrawlScrape },
    })
    ```
  </StepItem>

  <StepItem>
    在 `src/mastra/index.ts` 中，將新建立的 Agent 註冊到你的 Mastra 執行個體：

    ```ts title="src/mastra/index.ts" {2, 5}
    import { Mastra } from '@mastra/core'
    import { webAgent } from './agents/web-agent'

    export const mastra = new Mastra({
      agents: { webAgent },
    })
    ```
  </StepItem>
</Steps>

## 在 Studio 中測試 {/* #test-in-studio */}

啟動開發伺服器並開啟 [Studio](/docs/studio/overview)：

```bash
mastra dev
```

在 Studio 中開啟 **Web Agent**，試著輸入以下指令：

- 「找出 Mastra 最新的變更記錄，並摘要最近一次發布的內容。」
- 「搜尋 Firecrawl 的定價資訊，並擷取各個方案等級。」

## 自行架設 Firecrawl {/* #self-hosted-firecrawl */}

如果你在本機執行 Firecrawl，請設定 `FIRECRAWL_API_URL`，或在用戶端傳入 `apiUrl`：

```ts title="src/mastra/tools/firecrawl.ts"
const firecrawl = new Firecrawl({
  apiKey: process.env.FIRECRAWL_API_KEY!,
  apiUrl: process.env.FIRECRAWL_API_URL,
})
```
