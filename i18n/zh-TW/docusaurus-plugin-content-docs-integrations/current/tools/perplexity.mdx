# Perplexity

`@mastra/perplexity` 套件將 [Perplexity Search API](https://docs.perplexity.ai/docs/search/quickstart) 封裝成與 Mastra 相容的 Tool。套件提供工廠函式，傳回以 [`createTool()`](/reference/tools/create-tool) 建立的 Tool，並附有完整的 Zod 輸入與輸出 Schema。

若要透過 Perplexity 產生聊天補全或執行由 Agent 驅動的 Workflow，請使用 Mastra 內建的 [Perplexity 模型 Provider](/models/providers/perplexity) 或 [Perplexity Agent Provider](/models/providers/perplexity-agent)。這兩個 Provider 與此搜尋 Tool 各自獨立。

## 安裝 {/* #installation */}

安裝此套件和 Zod：

```sh npm2yarn
npm install @mastra/perplexity zod
```

## 使用範例 {/* #usage-example */}

以下範例以預設設定建立搜尋 Tool。Tool 會先讀取環境變數 `PERPLEXITY_API_KEY`，未設定時改用 `PPLX_API_KEY`。若要覆寫預設行為，請明確傳入 `{ apiKey }`。

```typescript title="src/mastra/tools/index.ts"
import { createPerplexitySearchTool } from '@mastra/perplexity'

const searchTool = createPerplexitySearchTool()
```

以下範例直接傳入 API 金鑰：

```typescript title="src/mastra/tools/index.ts"
import { createPerplexitySearchTool } from '@mastra/perplexity'

const searchTool = createPerplexitySearchTool({ apiKey: 'pplx-...' })
```

## 方法 {/* #methods */}

### 工廠函式 {/* #factory-functions */}

#### `createPerplexityTools(config?)` {/* #createperplexitytoolsconfig */}

傳回包含所有 Perplexity Tool 的物件。這些 Tool 共用傳入的設定。

```typescript
import { createPerplexityTools } from '@mastra/perplexity'

const tools = createPerplexityTools({ apiKey: 'pplx-...' })
// tools.perplexitySearch
```

傳回值：`{ perplexitySearch }`

#### `createPerplexitySearchTool(config?)` {/* #createperplexitysearchtoolconfig */}

建立一個透過 Perplexity Search API 搜尋網頁的 Tool。搜尋結果依排名傳回，每筆結果包含標題、URL 和內容摘要，若有發布日期也會一併提供。

此 Tool 的註冊 ID 為 `perplexity-search`。

```typescript
import { createPerplexitySearchTool } from '@mastra/perplexity'

const searchTool = createPerplexitySearchTool()
```

## Agent 範例 {/* #agent-example */}

以下範例將搜尋 Tool 註冊到 Agent，讓它能在回答前取得最新的網頁搜尋結果。

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { createPerplexitySearchTool } from '@mastra/perplexity'

const agent = new Agent({
  id: 'research-agent',
  name: 'Research Agent',
  model: '__GATEWAY_ANTHROPIC_MODEL_SONNET__',
  instructions:
    'You are a research assistant. Use the perplexity-search tool to find up-to-date information from the web before answering.',
  tools: {
    search: createPerplexitySearchTool(),
  },
})
```

## 環境變數 {/* #environment-variables */}

| 變數 | 說明 |
| - | - |
| `PERPLEXITY_API_KEY` | 你的 Perplexity API 金鑰。呼叫工廠函式時若未傳入 `apiKey`，預設會使用這個變數。 |
| `PPLX_API_KEY` | `PERPLEXITY_API_KEY` 未設定時使用的備用變數。 |
