# Neon

將 Mastra 伺服器部署到 Neon 分支，以 [Neon Function](https://neon.com/docs/compute/functions/overview) 的形式持續執行 Node.js 程序。Neon 會為函式提供可公開存取的 HTTPS 網址，並根據該分支的 Postgres 資料庫注入 `DATABASE_URL`。

Neon Functions 透過 `fetch` 處理常式接收請求。本指南使用 [Hono 伺服器介面卡](/docs/server/server-adapters)，不必執行 `mastra build` / `mastra start`。如果應用程式使用 [Web 框架](/docs/deployment/web-framework)，請依該框架平常的部署流程操作。

Neon Functions 目前為 Beta 版，僅支援 AWS 美國東部（俄亥俄州）區域（`aws-us-east-2`）。請在該區域建立 Neon 專案。

## 開始之前 {/* #before-you-begin */}

請先備妥：

- 一個 [Mastra 應用程式](/docs)
- 一個 [Neon](https://neon.com) 帳號
- 位於 `aws-us-east-2` 區域的 Neon 專案
- Node.js `v22.13.0` 或更新版本

Neon Functions 可能回收閒置的隔離執行環境，讓其中的記憶體資料和本機檔案隨之遺失。請改用 [搭配 Neon 的 PostgresStore](/integrations/databases/neon)，取代以檔案 URL 設定的 [LibSQLStore](/integrations/databases/libsql)。工作區檔案請儲存在 [Neon Object Storage](/integrations/file-storage/neon)，以取代 [`LocalFilesystem`](/reference/workspace/local-filesystem)。

## 安裝 {/* #installation */}

安裝 [Neon CLI](https://neon.com/docs/cli/install)：

```bash npm2yarn
npm install -g neon
```

加入 Hono 介面卡、Hono 和 `@neon/config`：

```bash npm2yarn
npm install @mastra/hono@latest hono @neon/config
```

## 設定 `neon.ts` {/* #configure-neonts */}

在專案根目錄建立 `neon.ts`。執行 `neon deploy` 或 `neon dev` 時都會讀取這個檔案：

```typescript title="neon.ts"
import { defineConfig } from '@neon/config/v1'

export default defineConfig({
  preview: {
    aiGateway: true,
    functions: {
      mastra: {
        name: 'Mastra server',
        source: './src/index.ts',
      },
    },
  },
})
```

物件的鍵 `mastra` 就是函式的 slug。第一次部署後，這個名稱便無法變更。

設定 `aiGateway: true` 會在分支上啟用 [Neon AI Gateway](/models/gateways/neon)。部署時，`neon deploy` 會注入 `NEON_AI_GATEWAY_BASE_URL` 和 `NEON_AI_GATEWAY_TOKEN`。Mastra 使用 ID 以 `neon/` 開頭的模型時，會讀取這兩個變數。

若要直接使用模型供應商的 API 金鑰，請在函式的 `env` 欄位宣告金鑰，並將以 `neon/` 開頭的模型 ID 換成該供應商的模型 ID。執行 `neon deploy` 時，會從 `process.env` 讀取變數值：

```typescript title="neon.ts"
import { defineConfig } from '@neon/config/v1'

export default defineConfig({
  preview: {
    functions: {
      mastra: {
        name: 'Mastra server',
        source: './src/index.ts',
        env: {
          OPENAI_API_KEY: process.env.OPENAI_API_KEY!,
        },
      },
    },
  },
})
```

```bash
neon deploy --env .env
```

`--env` 會載入指定檔案，讓執行設定檔時能讀取其中的變數。部署時只會帶入 `env` 中列出的變數。詳情請參閱 [Neon Functions 環境變數](https://neon.com/docs/compute/functions/environment-variables)。

## 匯出 Hono 的 fetch 處理常式 {/* #export-a-hono-fetch-handler */}

使用 [Hono 介面卡](/reference/server/hono-adapter) 將 Mastra 接到 Hono，並將 Hono 應用程式設為預設匯出。Neon Functions 會呼叫預設匯出物件的 `fetch` 方法。

```typescript title="src/index.ts"
import { Hono } from 'hono'
import { HonoBindings, HonoVariables, MastraServer } from '@mastra/hono'
import { mastra } from './mastra'

const app = new Hono<{ Bindings: HonoBindings; Variables: HonoVariables }>()
const server = new MastraServer({ app, mastra })

await server.init()

export default app
```

在 `src/mastra/index.ts` 將 Agent 註冊到 `mastra` 執行個體。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core/mastra'
import { Agent } from '@mastra/core/agent'

const assistant = new Agent({
  id: 'assistant',
  name: 'Assistant',
  instructions: 'You are a helpful assistant',
  model: 'neon/claude-fable-5',
})

export const mastra = new Mastra({
  agents: { assistant },
})
```

模型清單請參閱 [Neon AI Gateway](/models/gateways/neon)。

## 部署 {/* #deploy */}

<Steps>
  <StepItem>
    在專案目錄執行下列指令，連結現有的 Neon 專案或建立新專案：

    ```bash
    neon link
    ```

    `neon link` 會將專案的上下文資訊寫入 `.neon`，並擷取目前分支的環境變數。
  </StepItem>

  <StepItem>
    部署函式：

    ```bash
    neon deploy
    ```

    CLI 會用 esbuild 打包處理常式，將打包結果上傳，並等到部署狀態變為 `completed`。若已在函式的 `env` 宣告環境變數，請加上 `--env <file>`，讓 `neon.ts` 能讀取變數值。
  </StepItem>

  <StepItem>
    取得公開網址：

    ```bash
    neon functions get mastra
    ```

    `invocation_url` 的格式為 `https://<branch-id>-mastra.compute.<cell>.us-east-2.aws.neon.tech/`。
  </StepItem>

  <StepItem>
    開啟 `https://<branch-id>-mastra.compute.<cell>.us-east-2.aws.neon.tech/api/agents` 驗證部署。這個端點應回傳 JSON 格式的 Agent 清單。

    Mastra 伺服器的每個 API 端點都有 `/api` 前綴，送出請求時請在網址路徑加上這個前綴。

    Neon 會從分支注入 `DATABASE_URL`。如果 `neon.ts` 設有 `aiGateway: true`，Neon 也會注入閘道的驗證憑證。
  </StepItem>

  <StepItem>
    現在可以透過 HTTP 呼叫 Mastra 端點。

    :::warning
    對外開放端點前，請先設定 [身分驗證](/docs/auth/overview)。函式網址可公開存取，詳情請參閱 [Neon Functions 身分驗證](https://neon.com/docs/compute/functions/authentication)。
    :::
  </StepItem>
</Steps>

## 本機開發 {/* #local-development */}

`neon dev` 會在本機啟動 `neon.ts` 中宣告的所有函式，支援熱重載，並注入已連結分支的環境變數：

```bash
neon dev
```

可在 `http://localhost:8787/api/agents` 呼叫 Mastra 伺服器的 Agent 清單端點。
