# Netlify

使用 `@mastra/deployer-netlify` 將 Mastra 伺服器部署到 Netlify。部署程式會將程式碼打包，並產生符合 Netlify [Frameworks API 規格](https://docs.netlify.com/build/frameworks/frameworks-api/)、可直接部署的 `.netlify` 目錄。你可以部署為無伺服器函式（預設），也可以部署為[邊緣函式](https://docs.netlify.com/build/edge-functions/overview/)，以降低延遲並延長可執行的時間。

:::note
本指南說明如何部署 [Mastra 伺服器](/docs/server/overview)。如果你使用[伺服器轉接器](/docs/server/server-adapters)或 [Web 框架](/docs/deployment/web-framework)，請依照該框架平常的方式部署。
:::

## 開始之前 {/* #before-you-begin */}

你需要一個 [Mastra 應用程式](/docs)和一個 [Netlify](https://www.netlify.com/) 帳號。

:::warning
Netlify Functions 使用暫時性的檔案系統，因此你設定的所有儲存空間（包括 Observability 的儲存空間）都必須託管在外部。如果你使用檔案 URL 連線至 [LibSQLStore](/integrations/databases/libsql)，請改用遠端託管的資料庫。
:::

## 安裝 {/* #installation */}

將 `@mastra/deployer-netlify` 套件加入專案：

```bash npm2yarn
npm install @mastra/deployer-netlify@latest
```

匯入 [`NetlifyDeployer`](/reference/deployer/netlify)，並在 Mastra 設定中將它指定為部署程式：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
// highlight-next-line
import { NetlifyDeployer } from '@mastra/deployer-netlify'

export const mastra = new Mastra({
  // highlight-next-line
  deployer: new NetlifyDeployer(),
})
```

若要改為部署成邊緣函式，請傳入 `{ target: 'edge' }`：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { NetlifyDeployer } from '@mastra/deployer-netlify'

export const mastra = new Mastra({
  deployer: new NetlifyDeployer({
    target: 'edge',
  }),
})
```

邊緣函式會在最靠近使用者的邊緣節點上透過 Deno 執行。邊緣函式沒有固定的執行逾時上限（只有 CPU 時間限制），因此更適合執行時間較長的 AI Workflow。詳情請參閱[建構函式選項](/reference/deployer/netlify#constructor-options)。

在專案根目錄建立 `netlify.toml` 檔案，並填入下列內容：

```toml
[build]
command = "mastra build"
```

## 部署 {/* #deploy */}

設定好專案後，將它推送到你選擇的遠端 Git Provider（例如 GitHub）。

<Steps>
  <StepItem>
    將儲存庫連接至 Netlify。設定過程中，Netlify 會偵測 `netlify.toml` 檔案，並將建置指令設為 `mastra build`。

    :::note

    請記得設定執行應用程式所需的環境變數，例如你的 [Model Provider](/models/providers) API 金鑰。

    :::
  </StepItem>

  <StepItem>
    準備就緒後，按一下 **Deploy** 按鈕，並等待首次部署完成。畫面會顯示已部署一個
    function has been deployed.
  </StepItem>

  <StepItem>
    前往 `https://<random-slug>.netlify.app/api/agents` 驗證部署；該網址應傳回 Agent 的 JSON 清單。

    [Mastra 伺服器](/docs/server/overview)的每個 API 端點都以 `/api` 為前綴，因此送出請求時，URL 必須包含這個前綴。

    :::note

    Netlify Functions 通常部署於 `https://<random-slug>.netlify.app/.netlify/functions/api`。`NetlifyDeployer` 會將來自 `/*` 的所有要求重新導向至 `/.netlify/functions/api/:splat`，因此 URL 不必包含 `.netlify/functions` 前置字串。

    :::
  </StepItem>

  <StepItem>
    現在可以透過 HTTP 呼叫 Mastra 端點。

    :::warning
    對外公開端點前，請先設定[身分驗證](/docs/auth/overview)。
    :::
  </StepItem>
</Steps>
