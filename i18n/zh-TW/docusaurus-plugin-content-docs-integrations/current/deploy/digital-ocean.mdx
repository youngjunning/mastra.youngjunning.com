# DigitalOcean

本指南介紹 DigitalOcean 的 App Platform 和 Droplets。兩項服務各有優勢，適合不同類型的專案，也能配合開發者不同的技術經驗。請參閱 [DigitalOcean 的比較說明](https://www.digitalocean.com/community/conceptual-articles/digitalocean-app-platform-vs-doks-vs-droplets)，了解兩者的差異，並為你的專案選擇最合適的方案。

:::note
本指南說明如何部署 [Mastra 伺服器](/docs/server/overview)。如果你使用了[伺服器轉接器](/docs/server/server-adapters)或 [Web 框架](/docs/deployment/web-framework)，請依所用框架的常規方式部署。
:::

## 開始之前 {/* #before-you-begin */}

你需要一個 [Mastra 應用程式](/docs)和一個 [DigitalOcean](https://www.digitalocean.com/) 帳號。

**App Platform** 使用暫存檔案系統，因此你設定的任何儲存空間（包括 Observability 資料的儲存空間）都必須由外部服務託管。如果你使用的是搭配檔案 URL 的 [LibSQLStore](/integrations/databases/libsql)，請改用遠端託管的資料庫。

## App Platform {/* #app-platform */}

設定好專案後，將專案推送至你選擇的遠端 Git Provider（例如 GitHub）。

<Steps>
  <StepItem>
    請依照官方的 [App Platform 快速入門指南](https://docs.digitalocean.com/products/app-platform/getting-started/quickstart/#create-an-app)，連結你的儲存庫、選擇要部署的分支，並視需要設定原始碼目錄。
  </StepItem>

  <StepItem>
    確認平台已偵測到「Node.js」建置。你需要依照使用的套件管理工具設定建置指令：

    ```bash npm2yarn
    npm run build
    ```
  </StepItem>

  <StepItem>
    新增 Mastra 應用程式所需的環境變數，包括 API 金鑰、資料庫 URL 和其他設定值。
  </StepItem>

  <StepItem>
    系統會自動建置並部署你的應用程式。DigitalOcean 會提供一個 URL，讓你存取部署完成的應用程式。
  </StepItem>

  <StepItem>
    現在您可以透過 HTTP 呼叫 Mastra 端點。

    :::warning
    對外公開端點之前，請先設定[驗證](/docs/auth/overview)。
    :::
  </StepItem>
</Steps>

## Droplets {/* #droplets */}

### 先決條件 {/* #prerequisites */}

- 一台執行 Ubuntu 24.04 LTS 或更新版本的 Droplet
- 一個網域名稱，其 A 記錄指向您的 Droplet
- 已設定的反向代理伺服器（例如使用 [nginx](https://nginx.org/)）
- 已設定的 SSL 憑證（例如使用 [Let's Encrypt](https://letsencrypt.org/)）
- 已在 Droplet 上安裝 Node.js 22.13.0 或更新版本

### 部署 {/* #deploy */}

設定好專案後，將專案推送到您選擇的遠端 Git 服務（例如 GitHub）。連線至您的 Droplet，並確認已安裝 `git`。

<Steps>
  <StepItem>
    複製您的儲存庫：

    <Tabs>
      <TabItem value="public" label="Public Repository">
        ```bash
        git clone https://github.com/<your-username>/<your-repository>.git
        ```
      </TabItem>

      <TabItem value="private" label="Private Repository">
        ```bash
        git clone https://<your-username>:<your-personal-access-token>@github.com/<your-username>/<your-repository>.git
        ```
      </TabItem>
    </Tabs>

    切換至儲存庫目錄：

    ```bash
    cd "<your-repository>"
    ```
  </StepItem>

  <StepItem>
    安裝專案的相依套件：

    ```bash npm2yarn
    npm install
    ```
  </StepItem>

  <StepItem>
    設定 Mastra 應用程式所需的環境變數。請在專案根目錄建立 `.env` 檔案：

    ```bash
    touch .env
    ```

    編輯 `.env` 檔案，加入您的環境變數：

    ```bash title=".env"
    OPENAI_API_KEY=your-api-key
    ```
  </StepItem>

  <StepItem>
    建置專案：

    ```bash npm2yarn
    npm run build
    ```

    此步驟會在 `.mastra/output` 目錄中產生供正式環境使用的 Mastra 伺服器建置產物。
  </StepItem>

  <StepItem>
    您可以執行 `mastra start` 指令來啟動 [Mastra 伺服器](/docs/deployment/mastra-server)：

    ```bash
    mastra start
    ```

    :::note
    您的 Mastra 應用程式預設會在連接埠 4111 上接收請求。請確認反向代理伺服器已設定為將請求轉送至這個連接埠。
    :::
  </StepItem>

  <StepItem>
    現在您可以透過 HTTP 呼叫 Mastra 端點。

    :::warning
    對外公開端點之前，請先設定[驗證](/docs/auth/overview)。
    :::
  </StepItem>
</Steps>
