# Amazon EC2

將您的 Mastra 伺服器部署至 Amazon EC2。伺服器會在您管理的基礎設施上執行，可支援長時間執行的 Agent 和 Workflow。

:::note
本指南說明如何部署 [Mastra 伺服器](/docs/server/overview)。如果您使用[伺服器轉接器](/docs/server/server-adapters)或 [Web 框架](/docs/deployment/web-framework)，請依該框架原有的方式部署。
:::

## 開始之前 {/* #before-you-begin */}

請先準備：

- 一個 [Mastra 應用程式](/docs)
- 一個 [EC2](https://aws.amazon.com/ec2/) 執行個體（Ubuntu 或 Amazon Linux），已安裝 Git 與 Node.js 22.13.0 或更新版本

若要部署至正式環境，還需要：

- 指向您的執行個體的網域名稱（SSL 憑證所需）
- 您網域的 SSL 憑證（例如透過 [Certbot](https://certbot.eff.org/) 向 Let's Encrypt 取得）
- 用來將流量轉送至應用程式的反向代理伺服器（例如 [nginx](https://nginx.org/)）

## 部署 {/* #deploy */}

<Steps>
  <StepItem>
    連線至您的 EC2 執行個體，並複製您的 Git 儲存庫：

    <Tabs>
      <TabItem value="public" label="Public Repository">
        ```bash
        git clone https://github.com/<your-username>/<your-repository>.git
        ```
      </TabItem>

      <TabItem value="private" label="Private Repository">
        ```bash
        git clone git@github.com:<your-username>/<your-repository>.git
        ```
      </TabItem>
    </Tabs>

    切換至儲存庫目錄：

    ```bash
    cd "<your-repository>"
    ```
  </StepItem>

  <StepItem>
    安裝相依套件：

    ```bash npm2yarn
    npm install
    ```
  </StepItem>

  <StepItem>
    建立 `.env` 檔案，並加入您的環境變數：

    ```bash
    touch .env
    ```

    請記得設定執行應用程式所需的環境變數（例如您的 Model Provider API 金鑰）：

    ```bash
    OPENAI_API_KEY=<your-openai-api-key>
    # Add other required environment variables
    ```
  </StepItem>

  <StepItem>
    建置應用程式：

    ```bash npm2yarn
    npm run build
    ```
  </StepItem>

  <StepItem>
    執行應用程式：

    ```bash
    node --env-file=".env" .mastra/output/index.mjs
    ```

    這是一個基本範例。在正式環境中，請使用 [PM2](https://pm2.keymetrics.io/) 或 [systemd](https://systemd.io/) 等程序管理工具，讓應用程式持續執行並處理重新啟動。

    :::warning
    對外公開端點前，請先設定[身分驗證](/docs/auth/overview)。
    :::
  </StepItem>

  <StepItem>
    您的 Mastra 伺服器目前在連接埠 4111 上執行，存取範圍僅限本機。

    您可以在 EC2 安全性群組中開放 4111 連接埠以便直接存取，也可以設定反向代理（如 nginx）監聽 80 和 443 連接埠，並將要求轉送至 `http://localhost:4111`。

    在正式環境中，應使用反向代理來設定 HTTPS。HTTPS 會加密傳輸流量，且大多數 webhook 整合及 Agent 所使用的外部服務都要求使用 HTTPS。
  </StepItem>

  <StepItem>
    前往 `https://<your-ec2-address>/api/agents` 驗證部署；該網址應傳回 Agent 的 JSON 清單。
  </StepItem>

  <StepItem>
    現在可以透過 HTTP 呼叫 Mastra 端點。
  </StepItem>
</Steps>
