# 亞馬遜EC2

將您的 Mastra 伺服器部署到 Amazon EC2。伺服器在您管理的基礎架構上運行，並且可以支援長時間運行的Agent程式和Workflow。

:::注意
本指南涵蓋了部署[Mastra server](/docs/server/overview). If you're using a [伺服器適配器](/docs/server/server-adapters)或者[網路框架](/docs/deployment/web-framework)，按照您通常為該框架部署的方式進行部署。
:::

## 開始之前 {/* #before-you-begin */}

你需要：

* 一個[Mastra application](/docs)
* 一個[EC2](https://aws.amazon.com/ec2/) instance (Ubuntu or Amazon Linux) with Git and Node.js 22.13.0+ installed

對於生產，您還需要：

* 指向您的實例的網域名稱（SSL 憑證所需）
* 您的網域的 SSL 憑證（例如，使用[Certbot](https://certbot.eff.org/) with Let's Encrypt)
* 反向Agent（例如，[nginx](https://nginx.org/)) to forward traffic to your application

## 部署 {/* #deploy */}

<Steps>
  <StepItem>
    連接到您的 EC2 執行個體並複製您的儲存庫：

    <Tabs>
      <TabItem value="public" label="Public Repository">
        ```bash
        git clone https://github.com/<your-username>/<your-repository>.git
        ```
      </TabItem>

      <TabItem value="private" label="Private Repository">
        ```bash
        git clone git@github.com:<your-username>/<your-repository>.git
        ```
      </TabItem>
    </Tabs>

    導航到儲存庫目錄：

    ```bash
    cd "<your-repository>"
    ```
  </StepItem>

  <StepItem>
    安裝依賴項：

    ```bash npm2yarn
    npm install
    ```
  </StepItem>

  <StepItem>
    創建一個`.env` file and add your environment variables:

    ```bash
    touch .env
    ```

    請記住設定運行應用程式所需的環境變數（例如模型Provider API 金鑰）：

    ```bash
    OPENAI_API_KEY=<your-openai-api-key>
    # Add other required environment variables
    ```
  </StepItem>

  <StepItem>
    建立應用程式：

    ```bash npm2yarn
    npm run build
    ```
  </StepItem>

  <StepItem>
    運行應用程式：

    ```bash
    node --env-file=".env" .mastra/output/index.mjs
    ```

    這是一個基本範例。在生產中，使用流程管理器，例如[PM2](https://pm2.keymetrics.io/) or [systemd](https://systemd.io/) to keep your application running and handle restarts.

    :::警告
    設定[authentication](/docs/auth/overview) before exposing your endpoints publicly.
    :::
  </StepItem>

  <StepItem>
    您的 Mastra 伺服器現在正在連接埠 4111 上運行，但只能在本地存取。

    您可以在 EC2 安全性群組中開放 4111 連接埠進行直接訪問，或者設定反向Agent（如 nginx）監聽 80 和 443 連接埠並將請求轉送到`http://localhost:4111`.


  </StepItem>

  <StepItem>
    驗證您的部署`https://<your-ec2-address>/api/agents`, which should return a JSON list of your agents.
  </StepItem>

  <StepItem>
    現在您可以透過 HTTP 呼叫 Mastra 端點。
  </StepItem>
</Steps>
