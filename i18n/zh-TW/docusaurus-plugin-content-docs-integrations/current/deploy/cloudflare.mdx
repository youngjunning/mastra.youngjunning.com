# Cloudflare

使用 `@mastra/deployer-cloudflare` 將 Mastra 伺服器部署到 Cloudflare Workers。部署工具會將程式碼打包，並產生符合 Cloudflare [Wrangler 設定規範](https://developers.cloudflare.com/workers/wrangler/configuration/)的 `wrangler.jsonc` 檔案，無須額外設定即可部署。

:::note

如果您使用[伺服器轉接器](/docs/server/server-adapters)或 [Web 框架](/docs/deployment/web-framework)，請依照該框架的一般流程部署。

:::

## 開始之前 {/* #before-you-begin */}

您需要一個 [Mastra 應用程式](/docs)和一個 [Cloudflare](https://cloudflare.com/) 帳號。

:::warning
Cloudflare Workers 使用暫時性的檔案系統，因此您設定的所有儲存服務（包括 Observability 的儲存服務）都必須託管在外部。如果您以檔案 URL 搭配 [LibSQLStore](/integrations/databases/libsql)，請改用託管於遠端的資料庫。
:::

## 安裝 {/* #installation */}

將 `@mastra/deployer-cloudflare` 套件加入您的專案：

```bash npm2yarn
npm install @mastra/deployer-cloudflare@latest
```

匯入 [`CloudflareDeployer`](/reference/deployer/cloudflare)，並在 Mastra 設定中將它指定為部署工具：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
// highlight-next-line
import { CloudflareDeployer } from '@mastra/deployer-cloudflare'

export const mastra = new Mastra({
  // highlight-start
  deployer: new CloudflareDeployer({
    name: 'your-project-name',
    vars: {
      NODE_ENV: 'production',
    },
  }),
  // highlight-end
})
```

若要在本機測試 Cloudflare Worker，還需要安裝 [`wrangler` CLI](https://developers.cloudflare.com/workers/wrangler/install-and-update/)：

```bash npm2yarn
npm install -D wrangler
```

## 使用方式 {/* #usage */}

完成專案設定後，將專案推送到您選擇的遠端 Git Provider（例如 GitHub）。

<Steps>
  <StepItem>
    將您的儲存庫連結至 Cloudflare。在「Workers & Pages」儀表板上，選取 **Create application**，再於下一步選擇您的 Git Provider。接著繼續設定，並選取要部署的儲存庫。

    :::note

    請記得設定執行應用程式所需的環境變數（例如 [Model Provider](/models/providers) 的 API 金鑰）。您可以使用 `npx wrangler secret bulk .env` 上傳 `.env` 檔案中的機密資料。詳情請參閱[機密資料](/reference/deployer/cloudflare#secrets)。

    :::
  </StepItem>

  <StepItem>
    準備就緒後，按一下 **Deploy** 按鈕，並等待首次部署完成。
  </StepItem>

  <StepItem>
    前往 `https://<your-project-name>.<slug>.workers.dev/api/agents`，試用剛部署的函式。頁面應傳回列出所有可用 Agent 的 JSON 回應。

    [Mastra 伺服器](/docs/server/overview)會在每個 API 端點的路徑前加上 `/api`，因此發出請求時，URL 必須包含此前綴。
  </StepItem>

  <StepItem>
    現在您可以透過 HTTP 呼叫 Mastra 端點。

    :::note

    請先設定[身分驗證](/docs/auth/overview)，再對外公開端點。

    :::
  </StepItem>
</Steps>
