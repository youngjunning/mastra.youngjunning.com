# OpenUI

[OpenUI](https://openui.com) 是生成式介面的開放標準。它將為串流設計的精簡語言 OpenUI Lang 搭配 React 執行環境與內建元件庫，讓模型的輸出能在串流過程中逐步呈現為結構化介面。

OpenUI 透過 [AG-UI 協定](https://docs.ag-ui.com) 與 Mastra 整合。`@ag-ui/mastra` 轉接器會封裝 Mastra `Agent` 並發出 AG-UI 事件，再由 OpenUI 的 `agUIAdapter()` 在用戶端解析。

:::tip

如需完整且可執行的範例，請參閱 OpenUI 儲存庫中的 [`mastra-chat`](https://github.com/thesysdev/openui/tree/main/examples/mastra-chat)。

:::

## 整合指南 {/* #integration-guide */}

將 Mastra 嵌入 Next.js API 路由，再透過 AG-UI 協定把 OpenUI 的 `<AgentInterface />` 聊天介面連到該路由。

<Steps>
  <StepItem>
    以專案範本建立 OpenUI 應用程式：

    ```bash npm2yarn
    npx @openuidev/cli@latest create --name openui-mastra-chat
    ```

    切換到新建的專案目錄：

    ```bash
    cd openui-mastra-chat
    ```

    建立後的 Next.js 專案結構如下：

    ```bash
    openui-mastra-chat
    └── src
        ├── app
        │   ├── api
        │   │   └── chat
        │   │       └── route.ts
        │   ├── globals.css
        │   ├── layout.tsx
        │   └── page.tsx
        ├── generated
        │   └── system-prompt.txt
        └── library.ts
    ```

    聊天路由位於 `src/app/api/chat/route.ts`，聊天介面位於 `src/app/page.tsx`，元件庫位於 `src/library.ts`。OpenUI CLI 會根據元件庫產生 `src/generated/system-prompt.txt`。每次變更元件庫後，請重新產生這個檔案。

    將 OpenAI 金鑰加入 `.env.local`：

    ```bash title=".env.local"
    OPENAI_API_KEY=sk-...
    ```

    :::note

    OpenUI 需要模型 Provider 的 API 金鑰。你可以選用 Mastra 支援的任一 Provider，並在下一步配合調整 Agent 設定。

    :::
  </StepItem>

  <StepItem>
    安裝 Mastra 套件與適用於 Mastra 的 AG-UI 轉接器：

    ```bash npm2yarn
    npm install @mastra/core @ag-ui/mastra @ag-ui/core zod
    ```

    `@ag-ui/mastra` 會將 Mastra `Agent` 封裝在 `MastraAgent` 裡，由後者發出 [AG-UI 協定](https://docs.ag-ui.com)事件。OpenUI 的 `agUIAdapter()` 會在用戶端接收這些事件。
  </StepItem>

  <StepItem>
    開啟 `src/app/api/chat/route.ts`，以 `@mastra/core/tools` 提供的 `createTool` 定義 Agent 需要的 Tool：

    ```typescript title="src/app/api/chat/route.ts"
    import { createTool } from '@mastra/core/tools'
    import { z } from 'zod'

    const getWeather = createTool({
      id: 'get_weather',
      description: 'Get current weather for a city.',
      inputSchema: z.object({ location: z.string().describe('City name') }),
      execute: async ({ location }) => {
        return { location, temperature_celsius: 22, condition: 'Clear' }
      },
    })
    ```

    將 Mastra `Agent` 封裝在 `MastraAgent` 裡，並加入產生的系統提示，讓 Agent 知道如何使用 OpenUI 元件庫：

    ```typescript title="src/app/api/chat/route.ts"
    import { MastraAgent } from '@ag-ui/mastra'
    import { Agent } from '@mastra/core/agent'
    import { readFileSync } from 'fs'
    import { join } from 'path'

    const systemPrompt = readFileSync(join(process.cwd(), 'src/generated/system-prompt.txt'), 'utf-8')

    const agent = new MastraAgent({
      agent: new Agent({
        id: 'openui-agent',
        name: 'OpenUI Agent',
        instructions: `You are a helpful assistant. Use tools when relevant.\n\n${systemPrompt}`,
        model: {
          id: '__GATEWAY_OPENAI_MODEL__',
          apiKey: process.env.OPENAI_API_KEY,
        },
        tools: { getWeather },
      }),
      resourceId: 'chat-user',
    })
    ```

    匯出 `POST` 處理函式，以伺服器發送事件（SSE）的形式串流傳送 Agent 的 AG-UI 事件：

    ```typescript title="src/app/api/chat/route.ts"
    import type { Message } from '@ag-ui/core'
    import { NextRequest } from 'next/server'

    export async function POST(req: NextRequest) {
      const { messages, threadId }: { messages: Message[]; threadId: string } = await req.json()
      const encoder = new TextEncoder()

      const stream = new ReadableStream({
        start(controller) {
          const subscription = agent
            .run({ messages, threadId, runId: crypto.randomUUID(), tools: [], context: [] })
            .subscribe({
              next: event => {
                controller.enqueue(encoder.encode(`data: ${JSON.stringify(event)}\n\n`))
              },
              complete: () => {
                controller.enqueue(encoder.encode('data: [DONE]\n\n'))
                controller.close()
              },
              error: error => {
                controller.enqueue(
                  encoder.encode(`data: ${JSON.stringify({ error: error.message })}\n\n`),
                )
                controller.close()
              },
            })

          req.signal.addEventListener('abort', () => subscription.unsubscribe())
        },
      })

      return new Response(stream, {
        headers: {
          'Content-Type': 'text/event-stream',
          'Cache-Control': 'no-cache, no-transform',
          Connection: 'keep-alive',
        },
      })
    }
    ```
  </StepItem>

  <StepItem>
    將 OpenUI 的 `<AgentInterface />` 聊天介面連到該路由。使用 `fetchLLM()` 建立 `llm` 轉接器，並將 `streamAdapter` 設為 `agUIAdapter()`，讓 OpenUI 能解析 AG-UI 事件。

    ```tsx title="src/app/page.tsx" {5,8-11,17}
    'use client'

    import '@openuidev/react-ui/components.css'

    import { AgentInterface, agUIAdapter, fetchLLM } from '@openuidev/react-ui'
    import { openuiChatLibrary } from '@openuidev/react-ui/genui-lib'

    const llm = fetchLLM({
      url: '/api/chat',
      streamAdapter: agUIAdapter(),
    })

    export default function Page() {
      return (
        <div className="relative h-screen w-screen overflow-hidden">
          <AgentInterface llm={llm} componentLibrary={openuiChatLibrary} />
        </div>
      )
    }
    ```

    `componentLibrary` 屬性決定模型可以產生哪些元件。以自訂元件庫取代 `openuiChatLibrary`，即可縮小或擴大模型可產生的元件範圍。
  </StepItem>

  <StepItem>
    啟動開發伺服器：

    ```bash npm2yarn
    npm run dev
    ```

    開啟 [http://localhost:3000](http://localhost:3000)。現在可以透過 OpenUI 聊天介面和 Mastra Agent 對話，結構化介面會隨模型的串流輸出逐步呈現。
  </StepItem>
</Steps>

## 透過 AG-UI 串流傳輸 {/* #streaming-with-ag-ui */}

OpenUI 接收 [AG-UI 協定](https://docs.ag-ui.com) 定義的事件串流。此協定為 AI Agent 定義了具型別的事件，且不限定傳輸方式。`@ag-ui/mastra` 會將 Mastra `Agent` 的輸出轉換成符合協定的事件：

* 伺服器呼叫 `agent.run({ messages, threadId, runId, ... })`，並將發出的每個事件序列化為一則 SSE 訊息。
* 用戶端將 `fetchLLM({ streamAdapter: agUIAdapter() })` 的回傳值傳給 `<AgentInterface />`。此元件會將 SSE 串流解析成內部事件，供 OpenUI Lang 算繪介面時使用。

`threadId` 讓多次請求能延續同一段對話，`runId` 則用來識別單次執行。每次請求都要產生新的 `runId`，並在用戶端持久保存 `threadId`。

## 元件庫 {/* #component-libraries */}

OpenUI 根據元件庫產生介面。元件庫定義可用的元件及其屬性，也定義如何指示模型使用這些元件。

### 內建元件庫 {/* #built-in-libraries */}

`@openuidev/react-ui` 提供兩個可直接使用的元件庫：

* `openuiChatLibrary`：聊天介面的元件（卡片、表單、表格、圖表）。
* `openuiDashboardLibrary`：適合儀表板與大量呈現資料的介面元件。

透過 `<AgentInterface componentLibrary={...} />` 傳入元件庫，模型就能使用其中的元件。

### 自訂元件庫 {/* #customizing-the-library */}

若要縮小或擴大模型可產生的元件範圍，請在 `src/library.ts` 定義自己的元件庫，並匯出選定的元件。將元件庫傳給 `<AgentInterface />`，每次變更元件庫後都要重新產生系統提示：

```bash npm2yarn
npx @openuidev/cli generate src/library.ts --out src/generated/system-prompt.txt
```

API 路由會讀取產生的系統提示，並將它併入 Agent 的 `instructions`，讓 Agent 清楚知道自己可以輸出哪些元件。
