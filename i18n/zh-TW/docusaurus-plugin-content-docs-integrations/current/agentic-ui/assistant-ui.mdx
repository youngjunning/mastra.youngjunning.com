# Assistant UI

[Assistant UI](https://assistant-ui.com) 是用來打造 AI 聊天介面的 TypeScript/React 函式庫。它以 shadcn/ui 和 Tailwind CSS 為基礎，讓開發者在幾分鐘內就能建立美觀的企業級聊天介面。

:::note

若要直接在 Next.js API 路由中執行 Mastra，請參閱 Assistant UI 文件中的[全端整合指南](https://www.assistant-ui.com/docs/integrations/frameworks/mastra/full-stack)。

:::

Mastra 的 [**UI Dojo**](https://ui-dojo.mastra.ai/) 提供 Assistant UI 與 Mastra 整合的實際應用範例。

## 整合指南 {/* #integration-guide */}

將 Mastra 部署為獨立執行的伺服器，讓採用 Assistant UI 的 Next.js 前端連線至該伺服器的 API 端點。

<Steps>
  <StepItem>
    先規劃專案的目錄結構。以下是一種安排方式：

    ```bash
    project-root
    ├── mastra-server
    │   ├── src
    │   │   └── mastra
    │   └── package.json
    └── my-app
        └── package.json
    ```

    初始化 Mastra 伺服器專案：

    ```bash
    npx create-mastra@latest
    ```

    這個指令會啟動互動式精靈。依照提示輸入專案名稱並完成基本設定，即可建立 Mastra 伺服器專案。

    切換到剛建立的 Mastra 伺服器目錄：

    ```bash
    cd mastra-server # Replace with the actual directory name you provided
    ```

    基本的 Mastra 伺服器專案已建立，裡面應有下列檔案和資料夾：

    ```bash
    src
    └── mastra
        ├── agents
        │   └── weather-agent.ts
        ├── scorers
        │   └── weather-scorer.ts
        ├── tools
        │   └── weather-tool.ts
        ├── workflows
        │   └── weather-workflow.ts
        └── index.ts
    ```

    :::note

    請確認已在 `.env` 檔案中設定所用 LLM Provider 需要的環境變數。

    :::
  </StepItem>

  <StepItem>
    使用 `@mastra/ai-sdk` 提供的 `chatRoute()` 輔助函式，為 Assistant UI 前端建立聊天路由。先在 Mastra 專案中安裝這個套件：

    ```bash npm2yarn
    npm install @mastra/ai-sdk@latest
    ```

    在 `src/mastra/index.ts` 檔案中註冊聊天路由：

    ```typescript title="src/mastra/index.ts" {2,7-13}
    import { Mastra } from '@mastra/core/mastra'
    import { chatRoute } from '@mastra/ai-sdk'
    // Rest of the imports...

    export const mastra = new Mastra({
      // Rest of the configuration...
      server: {
        apiRoutes: [
          chatRoute({
            path: '/chat/:agentId',
          }),
        ],
      },
    })
    ```

    註冊路由後，所有 Agent 都會以相容於 AI SDK 的格式回應。例如，可經由 `/chat/weatherAgent` 端點存取 `weatherAgent`。
  </StepItem>

  <StepItem>
    執行下列指令來啟動 Mastra 伺服器：

    ```bash
    npm run dev
    ```

    Mastra 伺服器預設在 `http://localhost:4111` 提供服務。接下來會設定 Assistant UI 前端連到這個位址，請讓伺服器繼續執行。
  </StepItem>

  <StepItem>
    往上一層回到專案根目錄。

    ```bash
    cd ..
    ```

    執行以下指令建立新的 `assistant-ui` 專案。

    ```bash
    npx assistant-ui@latest create
    ```

    :::note

    如需新增 API 金鑰、進行基本設定或手動設定的詳細步驟，請參閱 [Assistant UI 官方文件](https://assistant-ui.com/docs)。

    :::
  </StepItem>

  <StepItem>
    Assistant UI 的聊天執行環境預設使用 Next.js 專案內的 API 路由（`/api/chat`）。由於 Mastra Agent 在另一台獨立執行的伺服器上提供服務，請將前端設定為連線至該伺服器的端點。

    在 Assistant UI 前端專案中，開啟包含 `useChatRuntime` Hook 的檔案，通常是 `app/assistant.tsx` 或 `src/app/assistant.tsx`。找到呼叫 `useChatRuntime` 的位置，將 `api` 屬性改為 Mastra Agent 串流端點的完整網址：

    ```tsx {8} title="app/assistant.tsx"
    'use client'

    // Rest of the imports...

    export const Assistant = () => {
      const runtime = useChatRuntime({
        transport: new AssistantChatTransport({
          api: 'http://localhost:4111/chat/weatherAgent',
        }),
      })

      // Rest of the component...
    }
    ```

    設定完成後，Assistant UI 前端會直接將聊天請求送到正在執行的 Mastra 伺服器。
  </StepItem>

  <StepItem>
    確認 Mastra 伺服器仍在執行，再啟動 Next.js 開發伺服器，讓 Assistant UI 前端也開始運作：

    ```bash
    npm run dev
    ```

    現在應該可以在瀏覽器中和 Agent 聊天了。
  </StepItem>
</Steps>

整合完成後，Assistant UI 前端會與獨立執行的 Mastra Agent 伺服器通訊。
