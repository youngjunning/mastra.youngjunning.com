# HubSpot

透過 Mastra Connect，為 Agent 提供可在 HubSpot 中搜尋、建立及更新聯絡人、公司、交易與服務單，並管理備註、任務及行銷電子郵件的 Tool。每次 Tool 呼叫都會經過 Mastra 平台，由平台加入該連線的憑證；你的應用程式不會儲存 HubSpot 憑證。

## 連線 {/* #connect */}

開始前，請先完成 [Connect 設定](/docs/mastra-platform/connect#get-started)，安裝 `@mastra/connect` 並設定 Mastra 平台專案。

### 連結帳戶 {/* #connect-an-account */}

請在包含 `.env` 檔案的目錄中執行以下命令：

```bash
mastra connect add hubspot
```

CLI 會引導你完成 HubSpot 授權，並等待連線啟用。

### 將 Tool 新增至 Agent {/* #add-tools-to-an-agent */}

將 [`tools()`](/reference/connect/tools) 傳給 Agent，並選取 `hubspot` Provider：

```typescript title="src/mastra/agents/hubspot-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const hubspotAgent = new Agent({
  id: 'hubspot-agent',
  name: 'HubSpot agent',
  instructions:
    'You help people search, create, and update contacts, companies, deals, and tickets, and manage notes, tasks, and marketing emails in HubSpot.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['hubspot'] }),
})
```

Agent 可使用 50 個 HubSpot Tool，Tool key 包括 `hubspot_batch_create_companies`。完整清單請參閱 [HubSpot Tool](/reference/connect/providers#hubspot)；如需限制可用 Tool，或要求每次呼叫在執行前取得核准，請參閱 [`tools()` 參數](/reference/connect/tools#parameters)。
