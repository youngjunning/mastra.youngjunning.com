# Attio

透過 Mastra Connect，為 Agent 提供可在 Attio 中搜尋及更新 CRM 紀錄、備註、任務與清單的 Tool。Attio 透過託管的 Model Context Protocol (MCP) 伺服器提供這些 Tool；你的應用程式不會儲存 Attio 憑證。

## 連線 {/* #connect */}

開始前，請先完成 [Connect 設定](/docs/mastra-platform/connect#get-started)，安裝 `@mastra/connect` 並設定 Mastra 平台專案。

### 連結帳戶 {/* #connect-an-account */}

請在包含 `.env` 檔案的目錄中執行以下命令：

```bash
mastra connect add attio-mcp
```

CLI 會引導你完成 Attio 授權，並等待連線啟用。

### 將 Tool 新增至 Agent {/* #add-tools-to-an-agent */}

將 [`tools()`](/reference/connect/tools) 傳給 Agent，並選取 `attio-mcp` Provider：

```typescript title="src/mastra/agents/attio-mcp-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const attioMcpAgent = new Agent({
  id: 'attio-mcp-agent',
  name: 'Attio agent',
  instructions: 'You help people search and update CRM records, notes, tasks, and lists in Attio.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['attio-mcp'] }),
})
```

Agent 執行時，Mastra 會從 Attio 的 MCP 伺服器探索可用 Tool。這些 Tool 取決於伺服器和已連結的帳戶，而不是你的 `@mastra/connect` 版本。Tool key 以 `attio-mcp_` 開頭。

如需查看 Attio 提供的 Tool，請參閱 [Attio MCP](https://docs.attio.com/mcp/overview) 文件。如需要求每次呼叫在執行前取得核准，請參閱 `tools()` 參考中的 [MCP Provider](/reference/connect/tools#mcp-providers)。
