# Gladia

Gladia 只提供語音轉文字（STT）功能。Mastra 整合會上傳預錄音訊，等 Gladia 轉錄完成後，將合併後的轉錄文字以字串傳回。

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/voice-gladia@latest
```

## API 金鑰 {/* #api-key */}

設定 `GLADIA_API_KEY`，或透過 `listeningModel.apiKey` 傳入金鑰。若兩者都沒有可用的值，建構函式會擲出錯誤 `GLADIA_API_KEY is not set.`。

## 使用範例 {/* #usage-example */}

設定 `GLADIA_API_KEY` 即可使用預設設定：

```typescript
import { createReadStream } from 'node:fs'
import { GladiaVoice } from '@mastra/voice-gladia'

const voice = new GladiaVoice()
const audio = createReadStream('./audio.m4a')

const transcript = await voice.listen(audio, {
  fileName: 'audio.m4a',
  mimeType: 'audio/mp4',
  options: {
    diarization: true,
    detect_language: true,
  },
})
```

也可以直接傳入 API 金鑰：

```typescript
import { GladiaVoice } from '@mastra/voice-gladia'

const voice = new GladiaVoice({
  listeningModel: {
    apiKey: process.env.GLADIA_API_KEY,
  },
})
```

傳回 `Promise<string>`，其中包含完整的轉錄文字。

### `speak()` {/* #speak */}

Gladia 不支援文字轉語音。呼叫此方法會擲出錯誤 `Gladia does not support text-to-speech.`。

## 重要提示 {/* #important-notes */}

* 預錄音訊上傳後，Gladia 會執行轉錄作業。這個套件不提供串流轉錄。
* 上傳前會先將整個輸入串流存入緩衝區。
* `listen()` 只傳回 `full_transcript`，不會傳回依說話者區分的片段或回應中的其他中繼資料。
* 整合每秒查詢一次作業狀態，直到作業完成或失敗。輪詢沒有逾時限制。
* 必須提供 Gladia API 金鑰。
