# OpenAI

您可以透過三種方式在 Mastra 中使用 OpenAI：

- **Agent Tool** 讓 Agent 透過 [Mastra Connect](/docs/mastra-platform/connect) 呼叫 OpenAI API，例如產生圖片，或管理檔案與向量儲存空間。
- **[語音](#voice)** 透過 `OpenAIVoice` 加入文字轉語音與語音轉文字功能。
- **[即時語音](#realtime)** 透過 `OpenAIRealtimeVoice` 加入語音對話功能。

若要將 OpenAI 模型用作 Agent 的語言模型，請參閱 [OpenAI 模型](/models/providers/openai)。

## Connect {/* #connect */}

開始之前，請依照 [Connect 設定指南](/docs/mastra-platform/connect#get-started)安裝 `@mastra/connect`，並設定平台專案。

## 語音 {/* #voice */}

Mastra 中的 OpenAIVoice 類別使用 OpenAI 模型提供文字轉語音與語音轉文字功能。

### 使用範例 {/* #usage-example */}

```typescript
import { OpenAIVoice } from '@mastra/voice-openai'

// Initialize with default configuration using environment variables
const voice = new OpenAIVoice()

// Or initialize with specific configuration
const voiceWithConfig = new OpenAIVoice({
  speechModel: {
    name: 'tts-1-hd',
    apiKey: 'your-openai-api-key',
  },
  listeningModel: {
    name: 'whisper-1',
    apiKey: 'your-openai-api-key',
  },
  speaker: 'alloy', // Default voice
})

// Convert text to speech
const audioStream = await voice.speak('Hello, how can I help you?', {
  speaker: 'nova', // Override default voice
  speed: 1.2, // Adjust speech speed
})

// Convert speech to text
const text = await voice.listen(audioStream, {
  filetype: 'mp3',
})
```

### 注意事項 {/* #notes */}

- 可以透過建構函式選項或 `OPENAI_API_KEY` 環境變數提供 API 金鑰。
- `tts-1-hd` 模型產生的音訊品質較高，但處理時間可能較長。
- 語音辨識支援多種音訊格式，包括 mp3、wav 與 webm。

## 即時語音 {/* #realtime */}

OpenAIRealtimeVoice 類別透過 OpenAI 以 WebSocket 為基礎的 API 提供即時語音互動功能，支援即時語音對話、語音活動偵測，以及事件驅動的音訊串流傳輸。

### 使用範例 {/* #usage-example-1 */}

```typescript
import { OpenAIRealtimeVoice } from '@mastra/voice-openai-realtime'
import { playAudio, getMicrophoneStream } from '@mastra/node-audio'

// Initialize with default configuration using environment variables
const voice = new OpenAIRealtimeVoice()

// Or initialize with specific configuration
const voiceWithConfig = new OpenAIRealtimeVoice({
  apiKey: 'your-openai-api-key',
  model: 'gpt-realtime-2.1-mini',
  speaker: 'alloy', // Default voice
})

voiceWithConfig.updateSession({
  turn_detection: {
    type: 'server_vad',
    threshold: 0.6,
    silence_duration_ms: 1200,
  },
})

// Establish connection
await voice.connect()

// Set up event listeners
voice.on('speaker', ({ audio }) => {
  // Handle audio data (Int16Array) pcm format by default
  playAudio(audio)
})

voice.on('writing', ({ text, role }) => {
  // Handle transcribed text
  console.log(`${role}: ${text}`)
})

// Convert text to speech
await voice.speak('Hello, how can I help you today?', {
  speaker: 'echo', // Override default voice
})

// Process audio input
const microphoneStream = getMicrophoneStream()
await voice.send(microphoneStream)

// When done, disconnect
voice.connect()
```

### 可用聲音 {/* #available-voices */}

可使用以下語音選項：

- `alloy`：中性、均衡
- `ash`：清晰、精準
- `ballad`：富有旋律感、流暢
- `coral`：溫暖、親切
- `echo`：渾厚、低沉
- `sage`：沉穩、深思熟慮
- `shimmer`：明亮、充滿活力
- `verse`：風格多變、富有表現力

### 注意事項 {/* #notes-1 */}

- 可以透過建構函式選項或 `OPENAI_API_KEY` 環境變數提供 API 金鑰。
- OpenAI Realtime Voice API 使用 WebSocket 進行即時通訊。
- 伺服器端語音活動偵測（VAD）可提高語音偵測的準確度。
- 所有音訊資料均以 Int16Array 格式處理。
- 使用其他方法前，必須先呼叫 `connect()` 連接語音執行個體。
- 使用完畢後，務必呼叫 `close()`，以妥善清理資源。
- 記憶體管理由 OpenAI Realtime API 負責。
