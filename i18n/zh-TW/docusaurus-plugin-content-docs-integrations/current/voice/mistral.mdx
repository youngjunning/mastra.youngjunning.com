# Mistral

MistralVoice 類別採用 Mistral 的 Voxtral 音訊模型，提供文字轉語音（TTS）和語音轉文字（STT）功能。語音合成支援緩衝與串流輸出，批次轉錄時可區分不同的說話者，也可使用參考音訊複製聲音。

## 使用範例 {/* #usage-example */}

```typescript
import { MistralVoice } from '@mastra/voice-mistral'

const voice = new MistralVoice()

// Text-to-speech
const audioStream = await voice.speak('Hello, how can I help you?', {
  responseFormat: 'mp3',
})

// Speech-to-text
const text = await voice.listen(audioStream, {
  language: 'en',
})

// List available voices
const speakers = await voice.getSpeakers()
```

```typescript
import { MistralVoice } from '@mastra/voice-mistral'

// Initialize with specific configuration
const voice = new MistralVoice({
  speechModel: {
    name: 'voxtral-mini-tts-2603',
    apiKey: 'your-mistral-api-key',
  },
  listeningModel: {
    name: 'voxtral-mini-latest',
    apiKey: 'your-mistral-api-key',
  },
  speaker: 'en_paul_neutral',
})
```

## 注意事項 {/* #notes */}

* 可透過建構函式的選項或 `MISTRAL_API_KEY` 環境變數提供 API 金鑰。
* TTS 支援 9 種語言：英語、法語、西班牙語、葡萄牙語、義大利語、荷蘭語、德語、印地語、阿拉伯語。
* STT 支援 13 種語言：英語、中文、印地語、西班牙語、阿拉伯語、法語、葡萄牙語、俄語、德語、日語、韓語、義大利語、荷蘭語。
* 為了讓合成效果更好，建議每次 TTS 請求的輸入文字少於 300 個詞。
* 每次 STT 請求可處理最長 3 小時的音訊。
* 透過 `refAudio` 複製聲音時，至少需要 2 到 3 秒的參考音訊。
* `getSpeakers()` 傳回的預設音色以 UUID 識別。TTS 端點接受預設值 `en_paul_neutral` 作為音色別名，但清單中不會列出這個別名。
