# ModelsLab

ModelsLab 僅提供文字轉語音（TTS）。Mastra 整合會送出非同步合成工作，等候 ModelsLab 傳回音訊網址，再下載合成完成的音訊，並以 Node.js 可讀串流傳回。

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/voice-modelslab@latest
```

## API 金鑰 {/* #api-key */}

設定 `MODELSLAB_API_KEY` 環境變數，或透過 `speechModel.apiKey` 傳入金鑰。若兩處都未提供金鑰，建構函式會擲出 `MODELSLAB_API_KEY is not set` 錯誤。

## 使用範例 {/* #usage-example */}

```typescript
import { ModelsLabVoice } from '@mastra/voice-modelslab'

const voice = new ModelsLabVoice({
  speechModel: {
    apiKey: process.env.MODELSLAB_API_KEY,
  },
  speaker: '5',
})

const audioStream = await voice.speak('Hello, world!', {
  speaker: 'nova',
  language: 'english',
  speed: 1,
})

const speakers = await voice.getSpeakers()
```

## 音色 {/* #voices */}

ModelsLab 提供六種內建的英語音色：

| ID | 名稱 | 性別 | 語言 |
| - | - | - | - |
| `1` | 中性音色 | 中性 | `en` |
| `2` | 男聲 | 男 | `en` |
| `3` | 溫暖男聲 | 男 | `en` |
| `4` | 低沉男聲 | 男 | `en` |
| `5` | 女聲 | 女 | `en` |
| `6` | 清晰女聲 | 女 | `en` |

OpenAI 風格的別名與音色 ID 的對應如下：

| 別名 | 音色 ID |
| - | - |
|`alloy` | `1` |
| `echo` | `2` |
| `fable` | `3` |
| `onyx` | `4` |
| `nova` | `5` |
| `shimmer` | `6` |

## 方法 {/* #methods */}

### `speak()` {/* #speak */}

將文字轉成語音。若 ModelsLab 傳回處理工作的 ID，整合會每五秒查詢一次工作狀態，最多等待五分鐘。這個方法會等音訊下載完畢才傳回可讀串流，因此無法一邊下載一邊串流輸出音訊。

### `listen()` {/* #listen */}

ModelsLab 不支援語音轉文字。呼叫這個方法會擲出錯誤，提示可使用 `@mastra/voice-deepgram` 作為語音轉文字的 Provider。

## 重要提示 {/* #important-notes */}

* 向 ModelsLab 發出文字轉語音請求時，API 金鑰會放在請求本文中。
* 每五秒查詢一次合成工作狀態，等待達 300 秒就會逾時。
* 音訊會先完整下載才以串流傳回，無法邊下載邊輸出。
* 整合不限制輸出格式，會直接從 ModelsLab 傳回的網址下載音訊。
* 此套件在執行時不會檢查 `speed` 是否在有效範圍內。
* 若指定的音色值不是數字，也沒有對應的別名，就會使用音色 ID `1`。
* 不支援語音轉文字。
