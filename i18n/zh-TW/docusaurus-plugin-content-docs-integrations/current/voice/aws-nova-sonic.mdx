# AWS Nova Sonic

`NovaSonicVoice` 類別以 [AWS Bedrock Nova 2 Sonic](https://docs.aws.amazon.com/nova/latest/userguide/speech.html) 提供即時語音對話功能。它與模型建立雙向串流，並針對助理音訊、轉錄文字、Tool 呼叫、對話回合邊界與中斷發出事件。

## 使用範例 {/* #usage-example */}

```typescript title="src/mastra/voice.ts"
import { NovaSonicVoice } from '@mastra/voice-aws-nova-sonic'
import { playAudio, getMicrophoneStream } from '@mastra/node-audio'

// Initialize using the default AWS credential provider chain
const voice = new NovaSonicVoice({
  region: 'us-east-1',
  speaker: 'matthew',
})

// Or pass explicit credentials
const voiceWithCredentials = new NovaSonicVoice({
  region: 'us-east-1',
  speaker: 'tiffany',
  credentials: {
    accessKeyId: process.env.AWS_ACCESS_KEY_ID!,
    secretAccessKey: process.env.AWS_SECRET_ACCESS_KEY!,
  },
})

// Establish the bidirectional stream
await voice.connect()

// Listen for assistant audio (Int16Array PCM)
voice.on('speaking', ({ audioData }) => {
  if (audioData) playAudio(audioData)
})

// Listen for transcribed text from the user and assistant
voice.on('writing', ({ text, role, generationStage }) => {
  console.log(`${role} (${generationStage ?? 'FINAL'}): ${text}`)
})

// Stream microphone audio in real time
const microphoneStream = getMicrophoneStream()
await voice.send(microphoneStream)

// Disconnect when done
voice.close()
```

## 身分驗證 {/* #authentication */}

若未傳入 `credentials`，`NovaSonicVoice` 會使用 AWS SDK 的預設憑證提供者鏈。Mastra 呼叫 `@aws-sdk/credential-provider-node` 中的 `defaultProvider()`，依序檢查環境變數、共用憑證檔案、EC2 的 IAM 角色、ECS、EKS 與其他標準來源。

若要使用靜態憑證，請在建立實例時傳入：

```typescript
new NovaSonicVoice({
  region: 'us-east-1',
  credentials: {
    accessKeyId: process.env.AWS_ACCESS_KEY_ID!,
    secretAccessKey: process.env.AWS_SECRET_ACCESS_KEY!,
    sessionToken: process.env.AWS_SESSION_TOKEN,
  },
})
```

語音 Provider 不會記錄憑證值。

## 方法 {/* #methods */}

### `connect()` {/* #connect */}

建立與 AWS Bedrock 之間的雙向串流，並傳送初始工作階段、提示與系統事件。呼叫 `speak`、`listen` 或 `send` 前，須先呼叫此方法。

  isOptional: true,

]}

返回：`Promise<void>`

### `getSpeakers()` {/* #getspeakers */}

傳回 Nova 2 Sonic 支援的語音清單。

返回：`Promise<Array<{ voiceId: string; name: string; language: string; locale: string; gender: 'masculine' | 'feminine'; polyglot: boolean }>>`

傳回語音實例目前是否維持已建立的串流。

返回：`Promise<{ enabled: boolean }>`

### `close()` {/* #close */}

關閉雙向串流並銷毀底層 Bedrock 用戶端。對話結束時呼叫此方法。

返回：`void`

## 注意事項 {/* #notes */}

* 音訊以 16 位元 PCM 格式串流傳輸。助理音訊會透過 `speaking` 事件以 `Int16Array` 形式發出。
* 呼叫其他串流方法前，語音實例必須先呼叫 `connect()`。
* `close()` 會銷毀底層 `BedrockRuntimeClient`，以釋放 HTTP/2 工作階段。
* Nova 2 Sonic 可在 `us-east-1`、`us-west-2` 與 `ap-northeast-1` 區域使用。使用其他區域時，建構實例的過程會擲回設定錯誤。
