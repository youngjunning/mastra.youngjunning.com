# 語音化

Mastra 中的 Speechify 語音實作使用 Speechify 的 API 提供文字轉語音功能。

## 使用範例 {/* #usage-example */}

```typescript
import { SpeechifyVoice } from '@mastra/voice-speechify'

// Initialize with default configuration (uses SPEECHIFY_API_KEY environment variable)
const voice = new SpeechifyVoice()

// Initialize with custom configuration
const voice = new SpeechifyVoice({
  speechModel: {
    name: 'simba-3.5',
    apiKey: 'your-api-key',
  },
  speaker: 'harper_32', // Default voice
})

// Convert text to speech
const audioStream = await voice.speak('Hello, world!', {
  speaker: 'imogen_32', // Override default voice
})

// Any voice speaks any of simba-3.5's 48 languages
const portuguese = await voice.speak('Olá, mundo!', { language: 'pt-BR' })
```

### `listen()` {/* #listen */}

Speechify 不支援此方法，並且會引發錯誤。 Speechify 不提供語音轉文字功能。

## 筆記 {/* #notes */}

* Speechify 需要 API 金鑰進行身份驗證
* 預設模型是“simba-3.5”，Speechify 推薦模型：一個 id 48 種語言，每個目錄語音都講所有這些語言
* 「simba-3.2」僅有英文版；非英語語音回傳錯誤
* 「simba-3.0」涵蓋英語、德語、西班牙語、法語、義大利語和葡萄牙語
* 「simba-english」和「simba-multilingual」是舊版 ID。新Workspace出現「model\_retired」錯誤，從 2026 年 11 月 21 日起，它們由「simba-3.2」和「simba-3.5」提供服務
* 預設揚聲器遵循配置的型號：Simba 3 型號為“harper\_32”，否則為“george”
* 不支援語音轉文字功能
* 額外的音訊串流選項可以透過spoke()方法的options參數傳遞
