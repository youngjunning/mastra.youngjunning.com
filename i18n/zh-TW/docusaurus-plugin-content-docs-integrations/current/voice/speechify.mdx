# Speechify

Mastra 透過 Speechify API 提供文字轉語音功能。

## 使用範例 {/* #usage-example */}

```typescript
import { SpeechifyVoice } from '@mastra/voice-speechify'

// Initialize with default configuration (uses SPEECHIFY_API_KEY environment variable)
const voice = new SpeechifyVoice()

// Initialize with custom configuration
const voice = new SpeechifyVoice({
  speechModel: {
    name: 'simba-3.5',
    apiKey: 'your-api-key',
  },
  speaker: 'harper_32', // Default voice
})

// Convert text to speech
const audioStream = await voice.speak('Hello, world!', {
  speaker: 'imogen_32', // Override default voice
})

// Any voice speaks any of simba-3.5's 48 languages
const portuguese = await voice.speak('Olá, mundo!', { language: 'pt-BR' })
```

### `listen()` {/* #listen */}

Speechify 不提供語音轉文字功能，呼叫這個方法會擲出錯誤。

## 注意事項 {/* #notes */}

- Speechify 需要 API 金鑰才能驗證身分。
- Speechify 推薦使用預設模型 `simba-3.5`。這個模型 ID 支援 48 種語言，目錄中的每種音色都能朗讀這 48 種語言。
- `simba-3.2` 只支援英語。若指定非英語音色，請求會回傳錯誤。
- `simba-3.0` 支援英語、德語、西班牙語、法語、義大利語和葡萄牙語。
- `simba-english` 和 `simba-multilingual` 是舊版模型 ID。新 Workspace 使用這些 ID 時會收到 `model_retired` 錯誤。自 2026 年 11 月 21 日起，這兩個 ID 分別由 `simba-3.2` 和 `simba-3.5` 提供服務。
- 預設音色依模型而定。Simba 3 系列模型使用 `harper_32`，其餘模型使用 `george`。
- Speechify 不支援語音轉文字。
- 其他音訊串流選項可透過 `speak()` 方法的 `options` 參數傳入。
