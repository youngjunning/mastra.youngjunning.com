# 十一實驗室

Mastra 中的 ElevenLabs 語音實作使用 ElevenLabs API 提供高品質的文字轉語音 (TTS) 和語音轉文字 (STT) 功能。

## 使用範例 {/* #usage-example */}

```typescript
import { ElevenLabsVoice } from '@mastra/voice-elevenlabs'

// Initialize with default configuration (uses ELEVENLABS_API_KEY environment variable)
const voice = new ElevenLabsVoice()

// Initialize with custom configuration
const voice = new ElevenLabsVoice({
  speechModel: {
    name: 'eleven_multilingual_v2',
    apiKey: 'your-api-key',
  },
  speaker: 'custom-speaker-id',
})

// Text-to-Speech
const audioStream = await voice.speak('Hello, world!')

// Get available speakers
const speakers = await voice.getSpeakers()
```

## 重要提示 {/* #important-notes */}

1. 需要 ElevenLabs API 金鑰。透過設定它`ELEVENLABS_API_KEY` environment variable or pass it in the constructor.
2. 預設揚聲器設定為 Aria（ID：“9BWtsMINqrJLrRacOk9x”）。
3. ElevenLabs 不支援語音轉文字功能。
4. 可以使用以下命令檢索可用的發言者`getSpeakers()` method, which returns detailed information about each voice including language and gender.
