# Azure

Mastra 的 AzureVoice 類別透過 Microsoft Azure Cognitive Services 提供文字轉語音與語音轉文字功能。

## 使用範例 {/* #usage-example */}

使用前須提供 Azure Speech Services 的認證資訊。可透過環境變數提供，也可直接填入設定：

```typescript
import { AzureVoice } from '@mastra/voice-azure'

// Initialize with configuration
const voice = new AzureVoice({
  speechModel: {
    apiKey: 'your-azure-speech-api-key', // Or use AZURE_API_KEY env var
    region: 'eastus', // Or use AZURE_REGION env var
    voiceName: 'en-US-AriaNeural', // Optional: specific voice for TTS
  },
  listeningModel: {
    apiKey: 'your-azure-speech-api-key', // Or use AZURE_API_KEY env var
    region: 'eastus', // Or use AZURE_REGION env var
    language: 'en-US', // Optional: recognition language for STT
  },
  speaker: 'en-US-JennyNeural', // Optional: default voice
})

// Convert text to speech
const audioStream = await voice.speak('Hello, how can I help you?', {
  speaker: 'en-US-GuyNeural', // Optional: override default voice
})

// Convert speech to text
const text = await voice.listen(audioStream)
```

透過 Azure 的語音轉文字服務轉錄音訊。

## 重要提示 {/* #important-notes */}

### Azure Speech Services 與 Azure OpenAI 的差異 {/* #azure-speech-services-vs-azure-openai */}

**⚠️ 注意：** 這個套件使用 **Azure Speech Services**，與 **Azure OpenAI Services** 是不同的服務。

* **請勿**將 `AZURE_OPENAI_API_KEY` 用於此套件。
* **請使用** Azure Speech Services 的訂閱金鑰，可在 Azure 入口網站的「語音服務」中取得。
* 這兩項服務是各自獨立的 Azure 資源，使用不同的 API 金鑰與端點。

### 環境變數 {/* #environment-variables */}

可透過建構函式選項或下列環境變數指定 API 金鑰與區域：

* `AZURE_API_KEY`：Azure Speech Services 的訂閱金鑰。
* `AZURE_REGION`：Azure 區域，例如 eastus 或 westeurope。

### 語音功能 {/* #voice-capabilities */}

* Azure 提供超過 200 種類神經網路合成語音，涵蓋 50 多種語言。
* 語音 ID 採用 `{language}-{region}-{name}Neural` 格式，例如 en-US-JennyNeural。
* 部分語音支援多種語言，或提供高音質版本。
* 輸出音訊採用 WAV 格式。
* 用於語音辨識的輸入音訊必須是 WAV 格式。

## 可用語音 {/* #available-voices */}

Azure 提供超過 200 種類神經網路合成語音，涵蓋多種語言。以下列出幾個常用的英語語音：

* **美式英語：**
  * `en-US-AriaNeural`（女聲，預設）
  * `en-US-JennyNeural`（女聲）
  * `en-US-GuyNeural`（男聲）
  * `en-US-DavisNeural`（男聲）
  * `en-US-AvaNeural`（女聲）
  * `en-US-AndrewNeural`（男聲）

* **英式英語：**
  * `en-GB-SoniaNeural`（女聲）
  * `en-GB-RyanNeural`（男聲）
  * `en-GB-LibbyNeural`（女聲）

* **澳洲英語：**
  * `en-AU-NatashaNeural`（女聲）
  * `en-AU-WilliamNeural`（男聲）

若要取得全部 200 多種語音的完整清單，請執行：

```typescript
const voices = await voice.getSpeakers()
console.log(voices) // Array of { voiceId, language, region }
```

如需詳細資訊，請參閱 [Azure 類神經網路文字轉語音文件](https://learn.microsoft.com/en-us/azure/cognitive-services/speech-service/language-support?tabs=tts)。
