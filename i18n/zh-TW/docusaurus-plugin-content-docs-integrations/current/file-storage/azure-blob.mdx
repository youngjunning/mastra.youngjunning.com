# 蔚藍斑點

將檔案儲存在 Azure Blob 儲存容器中。接口詳情請參見[WorkspaceFilesystem Interface](/reference/workspace/filesystem).

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/azure
```

## 用法 {/* #usage */}

添加一個`AzureBlobFilesystem` to a workspace and assign it to an agent:

```typescript
import { Agent } from '@mastra/core/agent'
import { Workspace } from '@mastra/core/workspace'
import { AzureBlobFilesystem } from '@mastra/azure/blob'

const workspace = new Workspace({
  filesystem: new AzureBlobFilesystem({
    container: 'my-container',
    connectionString: process.env.AZURE_STORAGE_CONNECTION_STRING,
  }),
})

const agent = new Agent({
  id: 'file-agent',
  name: 'file-agent',
  model: '__GATEWAY_ANTHROPIC_MODEL_OPUS__',
  workspace,
})
```

### 帳戶金鑰 {/* #account-key */}

當您不想傳遞完整的連接字串時，請使用帳戶名稱和帳戶金鑰：

```typescript
import { AzureBlobFilesystem } from '@mastra/azure/blob'

const filesystem = new AzureBlobFilesystem({
  container: 'my-container',
  accountName: process.env.AZURE_STORAGE_ACCOUNT_NAME,
  accountKey: process.env.AZURE_STORAGE_ACCOUNT_KEY,
})
```

### 共享訪問簽名令牌 {/* #shared-access-signature-token */}

使用共用存取簽章 (SAS) 令牌`accountName` or `endpoint`:

```typescript
import { AzureBlobFilesystem } from '@mastra/azure/blob'

const filesystem = new AzureBlobFilesystem({
  container: 'my-container',
  accountName: process.env.AZURE_STORAGE_ACCOUNT_NAME,
  sasToken: process.env.AZURE_STORAGE_SAS_TOKEN,
})
```

### 預設Azure憑證 {/* #defaultazurecredential */}

使用`DefaultAzureCredential` when your environment provides Azure identity credentials:

```typescript
import { AzureBlobFilesystem } from '@mastra/azure/blob'

const filesystem = new AzureBlobFilesystem({
  container: 'my-container',
  accountName: process.env.AZURE_STORAGE_ACCOUNT_NAME,
  useDefaultCredential: true,
})
```

安裝`@azure/identity` when you use `DefaultAzureCredential`:

```bash npm2yarn
npm install @azure/identity
```

## 方法 {/* #methods */}

AzureBlobFilesystem 實作了[WorkspaceFilesystem interface](/reference/workspace/filesystem), providing all standard filesystem methods:

* `readFile(path, options?)`- 讀取文件內容
* `writeFile(path, content, options?)`- 將內容寫入文件
* `appendFile(path, content)`- 將內容附加到文件
* `deleteFile(path, options?)`- 刪除文件
* `copyFile(src, dest, options?)`- 複製文件
* `moveFile(src, dest, options?)`- 移動或重新命名文件
* `mkdir(path, options?)`- 建立目錄
* `rmdir(path, options?)`- 刪除目錄
* `readdir(path, options?)`- 列出目錄內容
* `exists(path)`- 檢查路徑是否存在
* `stat(path)`- 取得檔案或目錄元數據

### `init()` {/* #init */}

初始化檔案系統。验证容器访问和凭据。

```typescript
await filesystem.init()
```

### `getInfo()` {/* #getinfo */}

傳回有關此檔案系統實例的元資料。

```typescript
const info = filesystem.getInfo()
// { id: '...', name: 'AzureBlobFilesystem', provider: 'azure-blob', status: 'ready' }
```

### `getContainer()` {/* #getcontainer */}

返回底層 Azure Blob 儲存`ContainerClient`.

```typescript
const container = await filesystem.getContainer()
```

### `getMountConfig()` {/* #getmountconfig */}

傳回支援 Azure Blob 檔案系統掛載的沙箱Provider的掛載配置。

```typescript
const config = filesystem.getMountConfig()
// { type: 'azure-blob', container: 'my-container', ... }
```

：：：筆記

Azure Blob 沙箱安裝取決於沙箱支援`azure-blob` mount configs. Use `filesystem` for direct workspace file operations when your sandbox provider doesn't support Azure Blob mounts.
