# AgentFS

透過 [AgentFS](https://github.com/nichochar/agentfs) SDK 將檔案儲存在 Turso/SQLite 資料庫中。檔案會持久儲存在本機的 SQLite 資料庫，Agent 在後續工作階段仍可存取，無須依賴外部雲端服務。介面的詳細資訊請參閱 [WorkspaceFilesystem 介面](/reference/workspace/filesystem)。

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/agentfs
```

## 使用方式 {/* #usage */}

在 Workspace 中加入 `AgentFSFilesystem`，再將該 Workspace 指派給 Agent。建立執行個體時，必須提供 `agentId`、`path` 或 `agent` 至少一項，才能初始化 `AgentFSFilesystem`。

```typescript
import { Agent } from '@mastra/core/agent'
import { Workspace } from '@mastra/core/workspace'
import { AgentFSFilesystem } from '@mastra/agentfs'

const workspace = new Workspace({
  filesystem: new AgentFSFilesystem({
    agentId: 'my-agent',
  }),
})

const agent = new Agent({
  id: 'file-agent',
  name: 'file-agent',
  model: '__GATEWAY_OPENAI_MODEL__',
  workspace,
})
```

### 指定資料庫路徑 {/* #using-an-explicit-database-path */}

資料庫預設儲存在 `.agentfs` 目錄中，檔名依 `agentId` 產生。也可以依照下列範例指定自訂的資料庫路徑。

```typescript
import { AgentFSFilesystem } from '@mastra/agentfs'

const filesystem = new AgentFSFilesystem({
  path: '/data/my-agent.db',
})
```

### 使用已開啟的 AgentFS 執行個體 {/* #using-a-pre-opened-agentfs-instance */}

若要自行管理 AgentFS 的生命週期，可以傳入已開啟的執行個體。

```typescript
import { AgentFS } from 'agentfs-sdk'
import { AgentFSFilesystem } from '@mastra/agentfs'

const agent = await AgentFS.open({ id: 'my-agent' })

const filesystem = new AgentFSFilesystem({
  agent, // caller manages open/close
})
```
