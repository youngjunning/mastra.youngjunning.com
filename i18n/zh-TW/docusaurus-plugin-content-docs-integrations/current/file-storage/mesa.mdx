# Mesa

透過 Mastra 標準的 `WorkspaceFilesystem` 介面，將 Workspace 檔案儲存在 [Mesa](https://docs.mesa.dev/content/getting-started/introduction) 儲存庫中。

當 Agent 需要具備版本記錄的檔案儲存時，請使用 `MesaFilesystem`。本機目錄可使用 [`LocalFilesystem`](/reference/workspace/local-filesystem)；物件儲存可使用 [`S3Filesystem`](/integrations/file-storage/amazon-s3)、[`GCSFilesystem`](/integrations/file-storage/google-cloud-storage) 或 [`AzureBlobFilesystem`](/integrations/file-storage/azure-blob)。

:::note

`MesaFilesystem` 在 Mastra 程序中執行。

[Mesa 的 POSIX 掛載](https://docs.mesa.dev/content/mesafs/posix-mount)可用於在 Sandbox 中使用 Mesa 檔案系統，但目前尚未包含在 `@mastra/mesa` 套件中。相關支援即將推出。

:::

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/mesa
```

## 使用範例 {/* #usage-example */}

掛載一個 Mesa 儲存庫，並將檔案系統傳入 Workspace：

```typescript title="src/mastra/workspace.ts"
import { Agent } from '@mastra/core/agent'
import { Workspace } from '@mastra/core/workspace'
import { MesaFilesystem, repo } from '@mastra/mesa'

const workspace = new Workspace({
  filesystem: new MesaFilesystem({
    privateKey: process.env.MESA_PRIVATE_KEY,
    authors: [{ name: 'File Agent', email: 'agent@example.com' }],
    layout: {
      '/docs': repo('docs', { mode: 'rw', at: { bookmark: 'main' } }),
    },
  }),
})

const agent = new Agent({
  id: 'file-agent',
  name: 'file-agent',
  model: '__GATEWAY_ANTHROPIC_MODEL_OPUS__',
  workspace,
})
```

若省略 `privateKey`，則使用 `MESA_PRIVATE_KEY` 環境變數。配置使用從 [Mesa SDK](https://docs.mesa.dev/content/getting-started/introduction) 重新匯出的 `repo()`，指定要掛載的儲存庫及其位置。

## 方法 {/* #methods */}

`MesaFilesystem` 實作了 [WorkspaceFilesystem 介面](/reference/workspace/filesystem)。

### 檔案操作 {/* #file-operations */}

#### `readFile(path, options?)` {/* #readfilepath-options */}

從 Mesa 讀取檔案。

```typescript
const content = await filesystem.readFile('/docs/README.md', {
  encoding: 'utf-8',
})
```

返回：`Promise<string | Buffer>`

#### `writeFile(path, content, options?)` {/* #writefilepath-content-options */}

將檔案寫入 Mesa。

```typescript
await filesystem.writeFile('/docs/report.md', '# Report')
```

返回：`Promise<void>`

#### `appendFile(path, content)` {/* #appendfilepath-content */}

在檔案末尾附加內容。

```typescript
await filesystem.appendFile('/docs/log.txt', 'new line\n')
```

返回：`Promise<void>`

#### `deleteFile(path, options?)` {/* #deletefilepath-options */}

刪除一個檔案。

```typescript
await filesystem.deleteFile('/docs/old-report.md')
```

返回：`Promise<void>`

#### `copyFile(src, dest, options?)` {/* #copyfilesrc-dest-options */}

複製檔案。

```typescript
await filesystem.copyFile('/docs/report.md', '/docs/archive/report.md')
```

返回：`Promise<void>`

#### `moveFile(src, dest, options?)` {/* #movefilesrc-dest-options */}

移動或重新命名檔案。

```typescript
await filesystem.moveFile('/docs/draft.md', '/docs/final.md')
```

返回：`Promise<void>`

### 目錄操作 {/* #directory-operations */}

#### `mkdir(path, options?)` {/* #mkdirpath-options */}

建立目錄。

```typescript
await filesystem.mkdir('/docs/reports', { recursive: true })
```

返回：`Promise<void>`

#### `rmdir(path, options?)` {/* #rmdirpath-options */}

移除目錄。

```typescript
await filesystem.rmdir('/docs/reports', { recursive: true })
```

返回：`Promise<void>`

#### `readdir(path, options?)` {/* #readdirpath-options */}

列出目錄中的項目。

```typescript
const entries = await filesystem.readdir('/docs', {
  recursive: true,
  extension: '.md',
})
```

返回：`Promise<FileEntry[]>`

### 路徑操作 {/* #path-operations */}

#### `exists(path)` {/* #existspath */}

檢查路徑是否存在。

```typescript
const exists = await filesystem.exists('/docs/README.md')
```

返回：`Promise<boolean>`

#### `stat(path)` {/* #statpath */}

傳回檔案或目錄元資料。

```typescript
const stat = await filesystem.stat('/docs/README.md')
```

返回：`Promise<FileStat>`

#### `realpath(path)` {/* #realpathpath */}

傳回 Mesa 中的正規路徑。

```typescript
const realPath = await filesystem.realpath('/docs/README.md')
```

返回：`Promise<string>`

### Mesa 操作 {/* #mesa-operations */}

#### `bash(options?)` {/* #bashoptions */}

為此檔案系統建立以 Mesa 為後端的 Bash 執行環境。

```typescript
const bash = await filesystem.bash({
  cwd: '/docs',
})
```

返回：`Promise<Bash>`

## 路徑語意 {/* #path-semantics */}

這些方法需要絕對路徑。對 `MesaFilesystem` 而言，路徑以 Mesa 掛載點為根，並以配置中定義的路徑開頭：

```typescript
await filesystem.readFile('/docs/README.md')
```

不要省略前導斜線：

```typescript
await filesystem.readFile('docs/README.md') // Incorrect
await filesystem.readFile('/docs/README.md') // Correct
```

掛載多個儲存庫時，可透過各自的配置路徑存取：

```typescript
const filesystem = new MesaFilesystem({
  authors: [{ name: 'File Agent' }],
  layout: {
    '/docs': repo('docs', { mode: 'rw', at: { bookmark: 'main' } }),
    '/website': repo('website', { mode: 'rw', at: { bookmark: 'main' } }),
  },
})

await filesystem.readFile('/docs/README.md')
await filesystem.readFile('/website/package.json')
```

## Mesa 版本控制 API {/* #mesa-versioning-apis */}

透過底層 Mesa 檔案系統執行 Mesa 專屬的變更與書籤操作：

```typescript
await filesystem.writeFile('/docs/draft.md', 'Draft')

const current = await filesystem.change.current({
  repo: 'docs',
})

await filesystem.bookmark.move({
  repo: 'docs',
  name: 'main',
  changeId: current.changeId,
})
```

如需進一步了解版本控制語意，請參閱 [Mesa 文件](https://docs.mesa.dev/content/concepts/versioning)。

## 唯讀模式 {/* #read-only-mode */}

設定 `readOnly: true`，以唯讀方式掛載配置中的所有儲存庫，並封鎖透過 Mastra 執行的寫入操作：

```typescript
const filesystem = new MesaFilesystem({
  authors: [{ name: 'File Agent' }],
  layout: { '/docs': repo('docs', { mode: 'ro', at: { bookmark: 'main' } }) },
  readOnly: true,
})
```

讀取操作仍可執行。寫入操作會擲回 `WorkspaceReadOnlyError`。

## 並行操作 {/* #concurrency */}

`overwrite: false` 和 `expectedMtime` 會在寫入前執行預先檢查。除非 Mesa 為應用程式掛載提供原生條件式寫入，否則這些檢查並非不可分割的操作。
