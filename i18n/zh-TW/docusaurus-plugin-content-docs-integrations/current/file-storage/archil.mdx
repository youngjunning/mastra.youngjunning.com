# 阿爾奇爾

將檔案儲存在[Archil](https://docs.archil.com)彈性無伺服器磁碟。結合了 S3 相容的物件 API，可實現快速讀取/寫入`exec()`用於 POSIX shell 操作和`diskGrep()`用於並行伺服器端搜尋。接口詳情請參見[工作空間檔案系統接口](/reference/workspace/filesystem).

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/archil
```

## 用法 {/* #usage */}

添加一個`ArchilFilesystem` to a workspace and assign it to an agent:

```typescript
import { Agent } from '@mastra/core/agent'
import { Workspace } from '@mastra/core/workspace'
import { ArchilFilesystem } from '@mastra/archil'

const workspace = new Workspace({
  filesystem: new ArchilFilesystem({
    diskId: 'dsk-0123456789abcdef',
    apiKey: process.env.ARCHIL_API_KEY,
    region: 'aws-us-east-1',
  }),
})

const agent = new Agent({
  id: 'file-agent',
  name: 'file-agent',
  model: '__GATEWAY_ANTHROPIC_MODEL_OPUS__',
  workspace,
})
```

### 在 init 上建立新磁碟 {/* #creating-a-new-disk-on-init */}

如果您沒有現有磁碟，請提供`createDiskOptions` to create one automatically:

```typescript
import { ArchilFilesystem } from '@mastra/archil'

const filesystem = new ArchilFilesystem({
  apiKey: process.env.ARCHIL_API_KEY,
  region: 'aws-us-east-1',
  createDiskOptions: {
    name: 'my-agent-workspace',
  },
})

await filesystem.init()
// filesystem.diskId now contains the newly created disk ID
```

### 環境變數回退 {/* #environment-variable-fallbacks */}

什麼時候`apiKey` and `region` are omitted, the provider reads from environment variables:

* `ARCHIL_API_KEY`- API金鑰
* `ARCHIL_REGION`- 地區（例如`aws-us-east-1`)
* `ARCHIL_S3_BASE_URL`- 自訂S3端點（可選）

```typescript
import { ArchilFilesystem } from '@mastra/archil'

// Uses ARCHIL_API_KEY and ARCHIL_REGION from environment
const filesystem = new ArchilFilesystem({
  diskId: 'dsk-0123456789abcdef',
})
```

## 方法 {/* #methods */}

ArchilFilesystem 實作了[WorkspaceFilesystem interface](/reference/workspace/filesystem), providing all standard filesystem methods:

* `readFile(path, options?)`- 讀取文件內容
* `writeFile(path, content, options?)`- 將內容寫入文件
* `appendFile(path, content)`- 將內容附加到文件
* `deleteFile(path, options?)`- 刪除文件
* `copyFile(src, dest, options?)`- 複製文件
* `moveFile(src, dest, options?)`- 移動或重新命名文件
* `mkdir(path, options?)`- 建立目錄
* `rmdir(path, options?)`- 刪除目錄
* `readdir(path, options?)`- 列出目錄內容
* `exists(path)`- 檢查路徑是否存在
* `stat(path)`- 取得檔案或目錄元數據

### `init()` {/* #init */}

初始化檔案系統。連接到現有磁碟或建立新磁碟。

```typescript
await filesystem.init()
```

### `getInfo()` {/* #getinfo */}

傳回有關此檔案系統實例的元資料。

```typescript
const info = filesystem.getInfo()
// { id: '...', name: 'ArchilFilesystem', provider: 'archil', status: 'ready' }
```

### Archil 特定方法 {/* #archil-specific-methods */}

#### `exec(command)` {/* #execcommand */}

在磁碟上執行 shell 命令。返回退出代碼、stdout 和 stderr。

```typescript
const result = await filesystem.exec('ls -la /data')
// { exitCode: 0, stdout: '...', stderr: '' }
```

#### `diskGrep(options)` {/* #diskgrepoptions */}

對磁碟上的檔案執行並行伺服器端搜尋。

```typescript
const results = await filesystem.diskGrep({
  directory: '/logs',
  pattern: 'ERROR',
  recursive: true,
  glob: '*.log',
})
// { matches: [...], stoppedReason: null }
```

#### `share(path, options?)` {/* #sharepath-options */}

產生用於共享文件的簽名 URL。

```typescript
const { url } = await filesystem.share('/reports/output.pdf', {
  expiresIn: 3600,
})
```
