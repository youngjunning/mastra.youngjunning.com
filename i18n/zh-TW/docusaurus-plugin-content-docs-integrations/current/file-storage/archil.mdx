# Archil

這項整合將檔案存放在 [Archil](https://docs.archil.com) 的彈性無伺服器磁碟上。你可以透過與 S3 相容的物件 API 快速讀寫檔案，透過 `exec()` 執行 POSIX shell 操作，並用 `diskGrep()` 在伺服器端平行搜尋。介面細節請參閱 [WorkspaceFilesystem 介面](/reference/workspace/filesystem)。

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/archil
```

## 使用方式 {/* #usage */}

將 `ArchilFilesystem` 設為 Workspace 的檔案系統，再將這個 Workspace 指派給 Agent。

```typescript
import { Agent } from '@mastra/core/agent'
import { Workspace } from '@mastra/core/workspace'
import { ArchilFilesystem } from '@mastra/archil'

const workspace = new Workspace({
  filesystem: new ArchilFilesystem({
    diskId: 'dsk-0123456789abcdef',
    apiKey: process.env.ARCHIL_API_KEY,
    region: 'aws-us-east-1',
  }),
})

const agent = new Agent({
  id: 'file-agent',
  name: 'file-agent',
  model: '__GATEWAY_ANTHROPIC_MODEL_OPUS__',
  workspace,
})
```

### 初始化時建立磁碟 {/* #creating-a-new-disk-on-init */}

如果沒有現成的磁碟，可以提供 `createDiskOptions`，讓檔案系統在初始化時自動建立磁碟。

```typescript
import { ArchilFilesystem } from '@mastra/archil'

const filesystem = new ArchilFilesystem({
  apiKey: process.env.ARCHIL_API_KEY,
  region: 'aws-us-east-1',
  createDiskOptions: {
    name: 'my-agent-workspace',
  },
})

await filesystem.init()
// filesystem.diskId now contains the newly created disk ID
```

### 使用環境變數提供設定值 {/* #environment-variable-fallbacks */}

省略 `apiKey` 和 `region` 時，Provider 會讀取對應的環境變數。也可以用環境變數設定自訂的 S3 端點。

* `ARCHIL_API_KEY` — API 金鑰
* `ARCHIL_REGION` — 區域，例如 `aws-us-east-1`
* `ARCHIL_S3_BASE_URL` — 自訂 S3 端點（選填）

```typescript
import { ArchilFilesystem } from '@mastra/archil'

// Uses ARCHIL_API_KEY and ARCHIL_REGION from environment
const filesystem = new ArchilFilesystem({
  diskId: 'dsk-0123456789abcdef',
})
```

## 方法 {/* #methods */}

ArchilFilesystem 實作 [WorkspaceFilesystem 介面](/reference/workspace/filesystem)，支援下列所有標準檔案系統方法。

* `readFile(path, options?)` — 讀取檔案內容
* `writeFile(path, content, options?)` — 將內容寫入檔案
* `appendFile(path, content)` — 在檔案末尾附加內容
* `deleteFile(path, options?)` — 刪除檔案
* `copyFile(src, dest, options?)` — 複製檔案
* `moveFile(src, dest, options?)` — 移動檔案或重新命名
* `mkdir(path, options?)` — 建立目錄
* `rmdir(path, options?)` — 移除目錄
* `readdir(path, options?)` — 列出目錄內容
* `exists(path)` — 檢查路徑是否存在
* `stat(path)` — 取得檔案或目錄的中繼資料

### `init()` {/* #init */}

初始化檔案系統，並連線至現有磁碟或建立新磁碟。

```typescript
await filesystem.init()
```

### `getInfo()` {/* #getinfo */}

傳回這個檔案系統執行個體的中繼資料。

```typescript
const info = filesystem.getInfo()
// { id: '...', name: 'ArchilFilesystem', provider: 'archil', status: 'ready' }
```

### Archil 專用方法 {/* #archil-specific-methods */}

#### `exec(command)` {/* #execcommand */}

在磁碟上執行 shell 指令，並傳回結束代碼、標準輸出（stdout）和標準錯誤輸出（stderr）。

```typescript
const result = await filesystem.exec('ls -la /data')
// { exitCode: 0, stdout: '...', stderr: '' }
```

#### `diskGrep(options)` {/* #diskgrepoptions */}

在伺服器端平行搜尋磁碟上的檔案。

```typescript
const results = await filesystem.diskGrep({
  directory: '/logs',
  pattern: 'ERROR',
  recursive: true,
  glob: '*.log',
})
// { matches: [...], stoppedReason: null }
```

#### `share(path, options?)` {/* #sharepath-options */}

產生可用來分享檔案的簽署網址。

```typescript
const { url } = await filesystem.share('/reports/output.pdf', {
  expiresIn: 3600,
})
```
