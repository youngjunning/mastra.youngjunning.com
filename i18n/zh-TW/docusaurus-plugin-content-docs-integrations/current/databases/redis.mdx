# Redis

Redis 儲存實作透過 Node.js 的官方 Redis 用戶端 [`node-redis`](https://github.com/redis/node-redis) 直接連線至 Redis，提供高效能的資料儲存。除了支援單機 Redis，也能透過自訂用戶端搭配 Redis Sentinel 使用。不支援 Redis Cluster。

## 安裝 {/* #installation */}

```bash
npm install @mastra/redis
```

## 使用方式 {/* #usage */}

### 使用連線字串 {/* #using-connection-string */}

```typescript
import { RedisStore } from '@mastra/redis'

const storage = new RedisStore({
  id: 'redis-storage',
  connectionString: 'redis://localhost:6379',
})

await storage.init()
```

### 設定主機與連接埠 {/* #using-hostport-configuration */}

```typescript
import { RedisStore } from '@mastra/redis'

const storage = new RedisStore({
  id: 'redis-storage',
  host: 'localhost',
  port: 6379,
  password: 'your-password',
  db: 0,
})

await storage.init()
```

### 使用預先設定的用戶端 {/* #using-pre-configured-client */}

若要使用 Redis Sentinel 等進階設定，可以傳入已設定好的 Redis 用戶端。

```typescript
import { RedisStore } from '@mastra/redis'
import { createClient } from 'redis'

const client = createClient({
  url: 'redis://localhost:6379',
  socket: {
    reconnectStrategy: retries => Math.min(retries * 50, 2000),
  },
})

// Connect the client before passing to RedisStore
await client.connect()

const storage = new RedisStore({
  id: 'redis-storage',
  client,
})
```

## 附加說明 {/* #additional-notes */}

### 鍵名結構 {/* #key-structure */}

Redis 儲存實作使用下列鍵名格式。

* 對話串：`mastra_threads:id:{threadId}`
* 訊息：`mastra_messages:threadId:{threadId}:id:{messageId}`
* 訊息索引：`msg-idx:{messageId}`（用於快速查詢）
* 對話串訊息的排序集合：`thread:{threadId}:messages`
* Workflow 快照：`mastra_workflow_snapshot:namespace:{ns}:workflow_name:{name}:run_id:{id}`
* 評分：`mastra_scorers:id:{scoreId}`
* 資源：`mastra_resources:{resourceId}`

### Redis Sentinel {/* #redis-sentinel */}

若使用 Redis Sentinel 部署高可用性環境，請建立自訂用戶端。

```typescript
import { RedisStore } from '@mastra/redis'
import { createClient } from 'redis'

const client = createClient({
  url: 'redis://sentinel-host:26379',
  // Configure sentinel options as needed for your setup
})

await client.connect()

const storage = new RedisStore({
  id: 'redis-sentinel-storage',
  client,
})
```

### Redis Cluster {/* #redis-cluster */}

不支援 Redis Cluster。`RedisStore` 僅接受以 `createClient()` 建立的單機用戶端。此外，有些操作會讀寫雜湊至不同槽位的鍵，Redis Cluster 會拒絕這些操作並傳回 `CROSSSLOT` 錯誤。

### 存取底層用戶端 {/* #accessing-the-underlying-client */}

可以透過底層 Redis 用戶端執行自訂操作。

```typescript
const storage = new RedisStore({
  id: 'redis-storage',
  connectionString: 'redis://localhost:6379',
})

await storage.init()

const client = storage.getClient()

// Custom Redis operations
await client.set('custom-key', 'value')
const value = await client.get('custom-key')
```

### 關閉連線 {/* #closing-connections */}

關閉應用程式時，請一併關閉 Redis 連線。

```typescript
await storage.close()
```

## 使用範例 {/* #usage-example */}

### 為 Agent 加入記憶功能 {/* #adding-memory-to-an-agent */}

```typescript title="src/mastra/agents/redis-agent.ts"
import { Memory } from '@mastra/memory'
import { Agent } from '@mastra/core/agent'
import { RedisStore } from '@mastra/redis'

export const redisAgent = new Agent({
  id: 'redis-agent',
  name: 'Redis Agent',
  instructions:
    'You are an AI agent with the ability to automatically recall memories from previous interactions.',
  model: '__GATEWAY_OPENAI_MODEL__',
  memory: new Memory({
    storage: new RedisStore({
      id: 'redis-agent-storage',
      connectionString: process.env.REDIS_URL!,
    }),
    options: {
      lastMessages: 10,
    },
  }),
})
```

### 使用 Agent {/* #using-the-agent */}

```typescript title="src/test-redis-agent.ts"
import 'dotenv/config'

import { mastra } from './mastra'

const threadId = '123'
const resourceId = 'user-456'

const agent = mastra.getAgent('redisAgent')

const message = await agent.stream('My name is Mastra', {
  memory: {
    thread: threadId,
    resource: resourceId,
  },
})

await message.textStream.pipeTo(new WritableStream())

const stream = await agent.stream("What's my name?", {
  memory: {
    thread: threadId,
    resource: resourceId,
  },
  memoryOptions: {
    lastMessages: 5,
  },
})

for await (const chunk of stream.textStream) {
  process.stdout.write(chunk)
}
```

### 將 Redis 儲存傳入 Mastra 執行個體 {/* #using-with-mastra-instance */}

```typescript
import { Mastra } from '@mastra/core'
import { RedisStore } from '@mastra/redis'

const storage = new RedisStore({
  id: 'mastra-storage',
  host: 'localhost',
  port: 6379,
})

const mastra = new Mastra({
  storage, // init() called automatically
})
```

若未透過 Mastra 而直接使用儲存執行個體，請明確呼叫 `init()`。

```typescript
import { RedisStore } from '@mastra/redis'

const storage = new RedisStore({
  id: 'redis-storage',
  host: 'localhost',
  port: 6379,
})

await storage.init()

// Access domain-specific stores via getStore()
const memoryStore = await storage.getStore('memory')
const thread = await memoryStore?.getThreadById({ threadId: '...' })
```
