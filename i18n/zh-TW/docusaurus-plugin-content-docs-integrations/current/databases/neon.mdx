# 霓虹燈 Postgres

[氖](https://neon.com)是一個託管 PostgreSQL 服務。 Mastra 透過以下方式連接到 Neon[`PostgresStore`](/integrations/databases/postgresql)，它使用 Node.js`pg`司機。 Neon 不需要單獨的 Mastra 儲存包。

您還可以為Agent提供Tool來管理 Neon 專案和分支、運行 SQL 以及透過以下方式應用架構遷移：[Mastra Connect](#connect).

## 快速入門 {/* #quickstart */}

創建一個 Neon 項目，然後複製它[pooled connection string](https://neon.com/docs/connect/connect-from-any-app) into `DATABASE_URL`.

安裝 PostgreSQL 儲存包：

```bash npm2yarn
npm install @mastra/pg@latest
```

將池連接字串傳遞給`PostgresStore`:

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core/mastra'
import { PostgresStore } from '@mastra/pg'

export const mastra = new Mastra({
  storage: new PostgresStore({
    id: 'neon-storage',
    connectionString: process.env.DATABASE_URL!,
  }),
})
```

啟動時，Mastra 調用`storage.init()` and creates its tables and indexes in Neon.

## 使用 CLI 設定 Neon {/* #set-up-neon-with-the-cli */}

Neon CLI 需要 Node.js 20.19 或更高版本。

安裝[Neon CLI](https://neon.com/docs/cli/install):

```bash npm2yarn
npm install -g neon
```

從您的專案目錄中，連結現有 Neon 專案或建立一個：

```bash
neon link
```

`neon link`讓您登入並將項目上下文寫入`.neon`. It also pulls the current branch's environment variables. Run `neon env pull` again whenever you need to refresh them:

```bash
neon env pull
```

命令寫的是`DATABASE_URL` and `DATABASE_URL_UNPOOLED` to `.env.local` or to `.env` when that file already exists.

### 添加`neon.ts` {/* #add-neonts */}

若要管理儲存庫中的分支設置，請建立[`neon.ts`](https://neon.com/docs/reference/neon-ts) file:

```bash
neon config init
```

這將安裝`@neon/config` and `@neon/env` and creates a starter config. For example, the following policy expires new non-default branches after seven days:

```typescript title="neon.ts"
import { defineConfig } from '@neon/config/v1'

export default defineConfig({
  branch: branch => {
    if (branch.isDefault) {
      return {}
    }

    if (!branch.exists) {
      return { ttl: '7d' }
    }

    return {}
  },
})
```

應用程式配置：

```bash
neon deploy
```

## 安裝NeonAgent技巧 {/* #install-neon-agent-skills */}

安裝[`neon` and `neon-postgres` agent skills](https://neon.com/docs/ai/agent-skills) from your project directory:

```bash npm2yarn
npx skills add neondatabase/agent-skills --skill neon --skill neon-postgres -y
```

這些技能為相容的編碼Agent Neon 設定說明和 Postgres 特定的指導。

## 生產連接 {/* #production-connections */}

Neon 提供直接連接字串和池連接字串：

* `DATABASE_URL`使用 Neon 的池端點。將其用於正常的應用程式流量。
* `DATABASE_URL_UNPOOLED`直接連接到 Postgres。將其用於在應用程式外部運行的管理任務或架構變更。

對於大多數應用程序，使用池化`DATABASE_URL` shown in the quickstart and let Mastra initialize the schema at startup. `PostgresStore` supports initialization through a transaction-pooled connection.

### 單獨的模式初始化 {/* #separate-schema-initialization */}

如果執行時間資料庫角色不應建立資料表或索引，請在部署期間使用直接連線初始化架構：

```typescript title="scripts/init-storage.ts"
import { PostgresStore } from '@mastra/pg'

const storage = new PostgresStore({
  id: 'neon-storage-init',
  connectionString: process.env.DATABASE_URL_UNPOOLED!,
})

try {
  await storage.init()
} finally {
  await storage.close()
}
```

模式存在後，在運行時使用池連接並停用自動初始化：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core/mastra'
import { PostgresStore } from '@mastra/pg'

export const mastra = new Mastra({
  storage: new PostgresStore({
    id: 'neon-storage',
    connectionString: process.env.DATABASE_URL!,
    disableInit: true,
  }),
})
```

看[Neon connection pooling](https://neon.com/docs/connect/connection-pooling) for details.

## 向量搜尋 {/* #vector-search */}

霓虹燈支援[`pgvector` extension](https://neon.com/docs/extensions/pgvector). Use the direct `DATABASE_URL_UNPOOLED` connection while creating the extension and indexes. After setup, configure [`PgVector`](/integrations/vectors/pg) with the pooled connection for runtime queries:

```typescript
import { PgVector } from '@mastra/pg'

const vector = new PgVector({
  id: 'neon-vector',
  connectionString: process.env.DATABASE_URL!,
  disableInit: true,
})
```

環境`disableInit: true` prevents the runtime process from creating or changing the extension, tables and indexes.
