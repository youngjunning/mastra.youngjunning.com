# Neon Postgres

[Neon](https://neon.com) 是一項受管理的 PostgreSQL 服務。Mastra 透過 [`PostgresStore`](/integrations/databases/postgresql) 連線至 Neon，這個儲存介面使用 Node.js 的 `pg` 驅動程式。Neon 不需要另外安裝專用的 Mastra 儲存套件。

你也可以透過 [Mastra Connect](#connect) 讓 Agent 使用 Neon 工具，管理專案和分支、執行 SQL，以及套用資料庫結構遷移。

## 快速入門 {/* #quickstart */}

建立 Neon 專案，將專案的[連線集區連線字串](https://neon.com/docs/connect/connect-from-any-app)複製到 `DATABASE_URL`。

安裝 PostgreSQL 儲存套件：

```bash npm2yarn
npm install @mastra/pg@latest
```

將連線集區的連線字串傳給 `PostgresStore`：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core/mastra'
import { PostgresStore } from '@mastra/pg'

export const mastra = new Mastra({
  storage: new PostgresStore({
    id: 'neon-storage',
    connectionString: process.env.DATABASE_URL!,
  }),
})
```

Mastra 啟動時會呼叫 `storage.init()`，在 Neon 中建立所需的資料表和索引。

## 使用 CLI 設定 Neon {/* #set-up-neon-with-the-cli */}

Neon CLI 需要 Node.js 20.19 或更高版本。

安裝 [Neon CLI](https://neon.com/docs/cli/install)：

```bash npm2yarn
npm install -g neon
```

在專案目錄中執行以下指令，連結現有的 Neon 專案或建立新專案：

```bash
neon link
```

`neon link` 會引導你登入，將專案的相關資訊寫入 `.neon`，並擷取目前分支的環境變數。需要更新這些變數時，請再次執行 `neon env pull`：

```bash
neon env pull
```

這個指令會將 `DATABASE_URL` 和 `DATABASE_URL_UNPOOLED` 寫入 `.env.local`；若已有 `.env`，則寫入 `.env`。

### 新增 `neon.ts` {/* #add-neonts */}

若要在儲存庫中管理分支設定，請建立 [`neon.ts`](https://neon.com/docs/reference/neon-ts) 檔案：

```bash
neon config init
```

這個指令會安裝 `@neon/config` 和 `@neon/env`，並產生初始設定。例如，下列原則會讓新建的非預設分支在七天後到期：

```typescript title="neon.ts"
import { defineConfig } from '@neon/config/v1'

export default defineConfig({
  branch: branch => {
    if (branch.isDefault) {
      return {}
    }

    if (!branch.exists) {
      return { ttl: '7d' }
    }

    return {}
  },
})
```

套用設定：

```bash
neon deploy
```

## 安裝 Neon Agent Skills {/* #install-neon-agent-skills */}

在專案目錄中安裝 [`neon` 和 `neon-postgres` 這兩個 Agent Skills](https://neon.com/docs/ai/agent-skills)：

```bash npm2yarn
npx skills add neondatabase/agent-skills --skill neon --skill neon-postgres -y
```

相容的程式開發 Agent 可透過這兩個 Skill 取得 Neon 設定說明，以及 Postgres 專用的操作指引。

## 正式環境的連線 {/* #production-connections */}

Neon 提供直接連線與連線集區兩種連線字串：

- `DATABASE_URL` 使用 Neon 的連線集區端點，適合處理應用程式的日常流量。
- `DATABASE_URL_UNPOOLED` 直接連線至 Postgres，適合在應用程式之外執行管理作業或變更資料庫結構。

大多數應用程式只要沿用快速入門中的 `DATABASE_URL`，透過連線集區連線，再由 Mastra 在啟動時初始化資料庫結構即可。`PostgresStore` 支援透過交易層級的連線集區執行初始化。

### 另外初始化資料庫結構 {/* #separate-schema-initialization */}

如果應用程式執行時使用的資料庫角色不應建立資料表或索引，請在部署時直接連線至資料庫，完成結構初始化：

```typescript title="scripts/init-storage.ts"
import { PostgresStore } from '@mastra/pg'

const storage = new PostgresStore({
  id: 'neon-storage-init',
  connectionString: process.env.DATABASE_URL_UNPOOLED!,
})

try {
  await storage.init()
} finally {
  await storage.close()
}
```

資料庫結構建立後，請讓應用程式在執行時使用連線集區，並停用自動初始化：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core/mastra'
import { PostgresStore } from '@mastra/pg'

export const mastra = new Mastra({
  storage: new PostgresStore({
    id: 'neon-storage',
    connectionString: process.env.DATABASE_URL!,
    disableInit: true,
  }),
})
```

詳細資訊請參閱 [Neon 連線集區文件](https://neon.com/docs/connect/connection-pooling)。

## 向量搜尋 {/* #vector-search */}

Neon 支援 [`pgvector` 擴充功能](https://neon.com/docs/extensions/pgvector)。建立擴充功能和索引時，請使用 `DATABASE_URL_UNPOOLED` 直接連線。設定完成後，將 [`PgVector`](/integrations/vectors/pg) 設定為透過連線集區執行查詢：

```typescript
import { PgVector } from '@mastra/pg'

const vector = new PgVector({
  id: 'neon-vector',
  connectionString: process.env.DATABASE_URL!,
  disableInit: true,
})
```

設定 `disableInit: true` 後，應用程式的執行程序就不會建立或變更擴充功能、資料表和索引。
