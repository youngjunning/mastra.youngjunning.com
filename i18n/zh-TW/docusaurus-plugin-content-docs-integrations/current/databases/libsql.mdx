# libSQL

[libSQL](https://docs.turso.tech/libsql) 是與 SQLite 相容的開放原始碼資料庫，支援本機及遠端部署。你可以用它儲存歷史訊息、Workflow 快照、Trace 和評估分數。

若要在語意召回或傳統 RAG 中使用向量，請參閱 [libSQL Vector](/integrations/vectors/libsql)，其中說明如何使用嵌入向量與向量搜尋。

## 安裝 {/* #installation */}

儲存 Provider 必須另外安裝。以下指令會安裝 libSQL 的儲存套件。

```bash npm2yarn
npm install @mastra/libsql@latest
```

## 使用方式 {/* #usage */}

```typescript
import { LibSQLStore } from '@mastra/libsql'
import { Mastra } from '@mastra/core'

const mastra = new Mastra({
  storage: new LibSQLStore({
    id: 'libsql-storage',
    url: 'file:./storage.db',
  }),
})
```

你也可以為個別 Agent 設定檔案儲存。

```typescript
import { Memory } from '@mastra/memory'
import { Agent } from '@mastra/core/agent'
import { LibSQLStore } from '@mastra/libsql'

export const agent = new Agent({
  id: 'example-agent',
  memory: new Memory({
    storage: new LibSQLStore({
      id: 'libsql-storage',
      url: 'file:./agent.db',
    }),
  }),
})
```

:::warning
若無伺服器平台採用暫時性檔案系統，檔案儲存便無法運作。部署到這類平台時，請使用 [Turso](https://turso.tech) 或其他資料庫引擎。
:::

正式環境可以使用遠端資料庫。

```typescript
storage: new LibSQLStore({
  id: 'libsql-storage',
  url: 'libsql://your-db-name.aws-ap-northeast-1.turso.io',
  authToken: process.env.TURSO_AUTH_TOKEN,
})
```

在本機開發或測試時，可以將資料存放在記憶體中。

```typescript
storage: new LibSQLStore({
  id: 'libsql-storage',
  url: ':memory:',
})
```

:::warning
處理程序重新啟動或更換時，記憶體中的資料會清除。這種儲存方式僅適合開發。
:::

以下範例設定內嵌複本，讓它與遠端主資料庫同步，例如 Turso 上的資料庫。

```typescript
storage: new LibSQLStore({
  id: 'libsql-storage',
  url: 'file:./replica.db',
  syncUrl: 'libsql://your-db-name.aws-ap-northeast-1.turso.io',
  authToken: process.env.TURSO_AUTH_TOKEN,
  syncInterval: 60,
})
```

## 自動管理的資料表 {/* #managed-tables */}

儲存實作會自動建立核心資料表，其中 `mastra_notifications` 用來儲存通知收件匣紀錄及傳送中繼資料。

如要存取通知儲存區，請在 `LibSQLStore` 上呼叫 `getStore('notifications')`。

## 初始化 {/* #initialization */}

將儲存物件傳入 Mastra 類別時，Mastra 會自動呼叫 `init()`，建立[核心結構描述](/reference/storage/overview#core-schema)。

```typescript
import { Mastra } from '@mastra/core'
import { LibSQLStore } from '@mastra/libsql'

const storage = new LibSQLStore({
  id: 'libsql-storage',
  url: 'file:./storage.db',
})

const mastra = new Mastra({
  storage, // init() called automatically
})
```

若直接操作儲存物件，請自行呼叫 `init()`。

```typescript
import { LibSQLStore } from '@mastra/libsql'

const storage = new LibSQLStore({
  id: 'libsql-storage',
  url: 'file:./storage.db',
})

await storage.init()

// Access domain-specific stores via getStore()
const memoryStore = await storage.getStore('memory')
const thread = await memoryStore?.getThreadById({ threadId: '...' })
```

## 可觀察性 {/* #observability */}

libSQL 支援可觀察性，適合本機開發。除錯時可採用 `realtime` [追蹤策略](/docs/observability/integrations/exporters/mastra-storage#tracing-strategies)，即時查看 Trace。

如果正式環境會產生大量 Trace，可以考慮使用 [PostgreSQL](/integrations/databases/postgresql)，或[透過複合儲存搭配 ClickHouse](/reference/storage/composite#specialized-storage-for-observability)。
