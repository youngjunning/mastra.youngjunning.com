# LanceDB

LanceDB 儲存實作以 LanceDB 資料庫系統提供高效能儲存，擅長處理傳統資料儲存與向量運算。

:::warning[不支援 Observability]

LanceDB 儲存**不支援 Observability 領域**。`MastraStorageExporter` 匯出的 Trace 無法持久化儲存至 LanceDB。若 LanceDB 是唯一的儲存 Provider，[Studio](/docs/studio/overview) 的 Observability 功能將無法運作。若要啟用 Observability，請使用[複合儲存](/reference/storage/composite#specialized-storage-for-observability)，將 Observability 資料導向受支援的 Provider，例如 ClickHouse。

:::

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/lance@latest
```

## 使用方式 {/* #usage */}

### 基本儲存用法 {/* #basic-storage-usage */}

```typescript
import { LanceStorage } from '@mastra/lance'

// Connect to a local database
const storage = await LanceStorage.create('my-storage', '/path/to/db')

// Connect to a LanceDB cloud database
const storage = await LanceStorage.create('my-storage', 'db://host:port')

// Connect to a cloud database with custom options
const storage = await LanceStorage.create('my-storage', 's3://bucket/db', {
  storageOptions: { timeout: '60s' },
})
```

## 補充說明 {/* #additional-notes */}

### 結構描述管理 {/* #schema-management */}

LanceStorage 實作會自動建立及更新結構描述，並將 Mastra 結構描述中的型別對應至 LanceDB 內部使用的 Apache Arrow 資料型別：

- `text`, `uuid` → Utf8
- `int`, `integer` → Int32
- `float` → Float32
- `jsonb`, `json` → Utf8（序列化後）
- `binary` → Binary

### 初始化 {/* #initialization */}

將儲存執行個體傳入 Mastra 類別後，系統會在執行任何儲存操作之前自動呼叫 `init()`：

```typescript
import { Mastra } from '@mastra/core'
import { LanceStorage } from '@mastra/lance'

const storage = await LanceStorage.create('my-storage', '/path/to/db')

const mastra = new Mastra({
  storage, // init() is called automatically
})
```

若未透過 Mastra 而直接使用儲存執行個體，必須明確呼叫 `init()` 以建立資料表：

```typescript
import { LanceStorage } from '@mastra/lance'

const storage = await LanceStorage.create('my-storage', '/path/to/db')

// Required when using storage directly
await storage.init()

// Access domain-specific stores via getStore()
const memoryStore = await storage.getStore('memory')
const thread = await memoryStore?.getThreadById({ threadId: '...' })
```

:::warning
若未呼叫 `init()`，系統就不會建立資料表，儲存操作可能無聲失敗或擲出錯誤。
:::

### 部署選項 {/* #deployment-options */}

LanceDB 儲存可依不同的部署情境進行設定：

- **本機開發**：使用本機檔案路徑進行開發與測試
  ```text
  /path/to/db
  ```
- **雲端部署**：連線至託管的 LanceDB 執行個體
  ```text
  db://host:port
  ```
- **S3 儲存**：使用 Amazon S3 提供大容量的雲端儲存空間
  ```text
  s3://bucket/db
  ```

### 資料表管理 {/* #table-management */}

LanceStorage 提供下列資料表管理方法：

- 使用自訂結構描述建立資料表
- 刪除資料表
- 清空資料表（刪除所有記錄）
- 依鍵值載入記錄
- 插入單筆記錄或批次插入多筆記錄
