# Valkey

Valkey 儲存實作透過 [Valkey GLIDE](https://github.com/valkey-io/valkey-glide) 用戶端提供持久化儲存和伺服器端快取。當您的部署環境執行 Valkey，或需要 GLIDE 提供的 Valkey 原生設定、身分驗證等功能時，請使用此實作。

如果您的 Redis 部署使用官方的 `redis` 用戶端，請使用 [`@mastra/redis`](/integrations/databases/redis)。這些套件各自使用對應的伺服器獨立測試。

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/valkey
```

## 使用方式 {/* #usage */}

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { ValkeyStore } from '@mastra/valkey'

export const mastra = new Mastra({
  storage: new ValkeyStore({
    id: 'valkey-storage',
    host: 'localhost',
    port: 6379,
    password: process.env.VALKEY_PASSWORD,
  }),
})
```

您也可以提供 GLIDE 原生設定：

```typescript
import { ValkeyStore } from '@mastra/valkey'

const storage = new ValkeyStore({
  id: 'valkey-storage',
  config: {
    addresses: [{ host: 'localhost', port: 6379 }],
    useTLS: true,
  },
})
```

如果您已有 `GlideClient`，請先讓它建立連線，再傳入 `ValkeyStore`。呼叫端仍須負責關閉注入的用戶端。

`ValkeyStore` 需要獨立運作的 Valkey 伺服器，且不支援 Valkey Cluster 和 `GlideClusterClient`。

## 關閉連線 {/* #closing-connections */}

在正常關閉程序中，請關閉由 `ValkeyStore` 建立的用戶端：

```typescript
await storage.close()
```

`close()` 不會關閉注入的 `GlideClient`。
