# MSSQL

MSSQL 儲存實作以 Microsoft SQL Server 為後端，適用於正式環境。

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/mssql@latest
```

## 使用方式 {/* #usage */}

```typescript
import { MSSQLStore } from '@mastra/mssql'

const storage = new MSSQLStore({
  id: 'mssql-storage',
  connectionString: process.env.DATABASE_URL,
})
```

## 建構函式範例 {/* #constructor-examples */}

建立 `MSSQLStore` 執行個體時，可以提供連線字串，也可以逐一指定連線參數。這兩種方式都能搭配自訂的結構描述。

```ts
import { MSSQLStore } from '@mastra/mssql'

// Using a connection string only
const store1 = new MSSQLStore({
  id: 'mssql-storage-1',
  connectionString:
    'Server=localhost,1433;Database=mydb;User Id=sa;Password=password;Encrypt=true;TrustServerCertificate=true',
})

// Using a connection string with a custom schema name
const store2 = new MSSQLStore({
  id: 'mssql-storage-2',
  connectionString:
    'Server=localhost,1433;Database=mydb;User Id=sa;Password=password;Encrypt=true;TrustServerCertificate=true',
  schemaName: 'custom_schema', // optional
})

// Using individual connection parameters
const store4 = new MSSQLStore({
  id: 'mssql-storage-3',
  server: 'localhost',
  port: 1433,
  database: 'mydb',
  user: 'user',
  password: 'password',
})

// Individual parameters with schemaName
const store5 = new MSSQLStore({
  id: 'mssql-storage-4',
  server: 'localhost',
  port: 1433,
  database: 'mydb',
  user: 'user',
  password: 'password',
  schemaName: 'custom_schema', // optional
})
```

## 附加說明 {/* #additional-notes */}

### 結構描述管理 {/* #schema-management */}

儲存實作會自動建立及更新結構描述，並建立下列資料表。

- `mastra_workflow_snapshot`：儲存 Workflow 的狀態與執行資料
- `mastra_evals`：儲存評估結果與中繼資料
- `mastra_threads`：儲存對話串
- `mastra_messages`：儲存個別訊息
- `mastra_traces`：儲存遙測與追蹤資料
- `mastra_scorers`：儲存評分與評估資料
- `mastra_resources`：儲存資源的工作記憶資料

### 初始化 {/* #initialization */}

將儲存執行個體傳入 Mastra 類別後，Mastra 會在執行任何儲存作業之前自動呼叫 `init()`。

```typescript
import { Mastra } from '@mastra/core'
import { MSSQLStore } from '@mastra/mssql'

const storage = new MSSQLStore({
  connectionString: process.env.DATABASE_URL,
})

const mastra = new Mastra({
  storage, // init() is called automatically
})
```

若直接使用儲存執行個體，必須明確呼叫 `init()`，以建立資料表。

```typescript
import { MSSQLStore } from '@mastra/mssql'

const storage = new MSSQLStore({
  id: 'mssql-storage',
  connectionString: process.env.DATABASE_URL,
})

// Required when using storage directly
await storage.init()

// Access domain-specific stores via getStore()
const memoryStore = await storage.getStore('memory')
const thread = await memoryStore?.getThreadById({ threadId: '...' })
```

:::warning
若未呼叫 `init()`，資料表就不會建立，儲存作業可能在沒有提示的情況下失敗，也可能擲出錯誤。
:::

### 直接存取資料庫與連線集區 {/* #direct-database-and-pool-access */}

`MSSQLStore` 透過公開欄位提供 mssql 連線集區。

```typescript
store.pool // mssql connection pool instance
```

你可以透過連線集區直接執行查詢，或自行管理交易。

- 你必須自行妥善處理連線與交易。
- 呼叫 `store.close()` 關閉儲存執行個體時，會銷毀相關的連線集區。
- 直接存取會略過 MSSQLStore 方法提供的額外邏輯或驗證。

這種方式適用於需要直接操作底層資料庫介面的進階用法。
