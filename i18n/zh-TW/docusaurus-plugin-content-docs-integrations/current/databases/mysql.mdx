# MySQL

使用 `MySQLStore` 將 Mastra 應用程式資料持久保存於 MySQL 資料庫，包括訊息、Workflow、追蹤紀錄、評分，以及其他儲存領域的資料。

## 安裝 {/* #installation */}

儲存 Provider 必須以獨立套件安裝：

```bash npm2yarn
npm install @mastra/mysql@latest
```

## 使用方式 {/* #usage */}

在 Mastra 設定中加入 `MySQLStore`，並指定 MySQL 連線字串：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MySQLStore } from '@mastra/mysql'

export const mastra = new Mastra({
  storage: new MySQLStore({
    id: 'mysql-storage',
    connectionString: process.env.MYSQL_URL!,
  }),
})
```

例如，`MYSQL_URL` 可使用 `mysql://user:password@host:3306/database` 格式。

### 分別設定連線欄位 {/* #host-based-configuration */}

也可以逐一設定連線欄位，無須提供連線字串：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MySQLStore } from '@mastra/mysql'

export const mastra = new Mastra({
  storage: new MySQLStore({
    id: 'mysql-storage',
    host: process.env.MYSQL_HOST!,
    port: Number(process.env.MYSQL_PORT ?? 3306),
    user: process.env.MYSQL_USER!,
    password: process.env.MYSQL_PASSWORD,
    database: process.env.MYSQL_DATABASE!,
  }),
})
```

## 初始化 {/* #initialization */}

將儲存執行個體註冊至 `Mastra` 時，系統會自動呼叫 `init()`，建立[核心資料庫結構](/reference/storage/overview#core-schema)：

```typescript
const storage = new MySQLStore({
  id: 'mysql-storage',
  connectionString: process.env.MYSQL_URL!,
})

export const mastra = new Mastra({
  storage, // init() is called automatically
})
```

若直接使用儲存執行個體而未透過 `Mastra`，請先呼叫 `init()`，再存取各領域的儲存區：

```typescript
const storage = new MySQLStore({
  id: 'mysql-storage',
  connectionString: process.env.MYSQL_URL!,
})

await storage.init()

const memoryStore = await storage.getStore('memory')
```

## 正式環境 {/* #production */}

請使用能持久保存資料、且可從 Mastra 部署環境存取的 MySQL 資料庫。將連線憑證存放於環境變數，並在資料庫 Provider 要求時啟用 SSL。
