# OracleDB

OracleDB 儲存 Provider 會將 Mastra 應用程式的狀態儲存在 Oracle Database。這個 Provider 實作了 Mastra 的複合儲存介面，讓單一 `OracleStore` 執行個體就能儲存記憶、Workflow 快照、可觀測性資料、評分結果、評分器定義、MCP 用戶端中繼資料及 Agent 登錄資料。

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/oracledb@latest
```

## 使用方式 {/* #usage */}

```ts
import { OracleStore } from '@mastra/oracledb'

const storage = new OracleStore({
  id: 'oracle-storage',
  user: process.env.ORACLE_DATABASE_USER,
  password: process.env.ORACLE_DATABASE_PASSWORD,
  connectString: process.env.ORACLE_DATABASE_CONNECT_STRING,
})
```

接著在建立 Mastra 執行個體時傳入這個儲存執行個體：

```ts
import { Mastra } from '@mastra/core/mastra'

export const mastra = new Mastra({
  storage,
})
```

## 連線範例 {/* #connection-examples */}

前面的範例說明如何以使用者名稱和密碼建立儲存執行個體。若要連線到 Autonomous Database，請在同一個建構函式中加上錢包選項：

```ts
const storage = new OracleStore({
  id: 'oracle-storage',
  user: process.env.ORACLE_DATABASE_USER,
  password: process.env.ORACLE_DATABASE_PASSWORD,
  connectString: process.env.ORACLE_DATABASE_CONNECT_STRING,
  walletLocation: process.env.ORACLE_DATABASE_WALLET_DIR,
  walletPassword: process.env.ORACLE_DATABASE_WALLET_PASSWORD,
  configDir: process.env.ORACLE_DATABASE_CONFIG_DIR,
})
```

使用外部驗證時，請設定 `externalAuth: true`，並省略 `password`。若已有 `oracledb.Pool` 可供共用，請透過 `pool` 傳入。Mastra 會使用這個連線池，但不會將它關閉。

`OracleStore` 可儲存記憶、Workflow 快照、可觀測性資料、評分結果、評分器定義、MCP 用戶端中繼資料及 Agent 登錄資料。若未透過 `Mastra` 執行個體使用這個儲存實作，請先呼叫 `await storage.init()`，再透過 `await storage.getStore('memory')` 存取所需的儲存領域。

## 初始化 {/* #initialization */}

將 `OracleStore` 傳給 `Mastra` 時，Mastra 會在執行儲存作業前自動呼叫 `init()`。若直接使用 `OracleStore`，請在讀寫前先呼叫 `init()`：

```ts
await storage.init()
```

:::warning
如果停用或略過初始化，執行儲存作業前必須先備妥所需的 Oracle 資料表和索引。
:::

`OracleStore.init()` 會執行可重複執行的移轉，並將結果寫入移轉記錄表。預設的記錄表為 `MASTRA_ORACLE_MIGRATIONS`。

```ts
await storage.migrate()
const history = await storage.listMigrations()
```

這類移轉具有冪等性。啟動時，移轉會讓各儲存領域的資料表和索引符合預期狀態，因此不用修改應用程式程式碼，就能套用新增的領域索引或相容的結構描述擴充。

初始化也會建立這個 Provider 的預設索引，以支援 Mastra 的常見查詢。若索引由其他流程管理，請使用 `skipDefaultIndexes`；若要建立自訂 Oracle 索引，則傳入 `indexes`。自訂索引定義支援 `bitmap`、`online`、`invisible`、`parallel`、`compress`、`noLogging` 和 `reverse` 等 Oracle 選項，也支援 `JSON_VALUE(...)` 這類以函式為基礎的運算式。

如果應用程式經常依 JSON 中繼資料篩選，或資料庫管理員（DBA）想在查詢最佳化工具採用索引前先測試，自訂索引就能派上用場：

```ts
const storage = new OracleStore({
  id: 'oracle-storage',
  user,
  password,
  connectString,
  indexes: [
    {
      name: 'idx_messages_status',
      table: 'mastra_messages',
      columns: [
        "JSON_VALUE(metadata, '$.status' RETURNING VARCHAR2(32) NULL ON ERROR)",
        'thread_id',
      ],
      online: true,
      invisible: true,
    },
  ],
})
```

分階段部署索引時，請先使用 `invisible`，確認查詢計畫後再移除這個選項。只有在資料庫管理員維護的索引策略取代預設索引時，才使用 `skipDefaultIndexes: true`。

若由獨立的部署步驟或資料庫管理員套用結構描述變更，請使用 `disableInit: true`。

## 匯出結構描述 {/* #schema-export */}

使用 `exportSchemas()` 可在不連線至資料庫的情況下產生 Oracle DDL。需要在應用程式啟動流程之外審查或套用結構描述變更時，可以使用這個方法。

```ts
import { exportSchemas } from '@mastra/oracledb'

const ddl = exportSchemas({
  schemaName: 'MASTRA_APP',
  domains: [
    'memory',
    'workflows',
    'observability',
    'scores',
    'scorerDefinitions',
    'mcpClients',
    'agents',
  ],
})

console.log(ddl)
```

未指定 `domains` 時，預設會包含所有支援的領域，其中也包括 `vector`。

## 維運注意事項 {/* #operational-notes */}

若要讓 `OracleStore` 和 `OracleVector` 共用 Oracle 連線的生命週期管理，請讓兩者使用同一個 `OraclePoolManager`：

```ts
import { OracleStore, OracleVector } from '@mastra/oracledb'

const storage = new OracleStore({ id: 'oracle-storage', user, password, connectString })
const vector = new OracleVector({
  id: 'oracle-vector',
  poolManager: storage.getPoolManager(),
})
```

`OracleStore` 提供 `storage.db` 和 `await storage.getPool()` 供進階使用。直接使用這些 API 時，必須自行管理交易邊界和連線生命週期。

JSON 中繼資料、承載資料及快照會儲存在 Oracle 原生的 JSON 欄位，由伺服器端編碼。因此可用 DBeaver、SQL Developer 等標準 Oracle JDBC 工具直接讀取這些資料列。

## 使用範例 {/* #usage-example */}

### 為 Agent 加入由 OracleDB 儲存的記憶 {/* #adding-oracledb-memory-to-an-agent */}

```ts title="src/mastra/agents/oracle-agent.ts"
import { Agent } from '@mastra/core/agent'
import { Memory } from '@mastra/memory'
import { OracleStore } from '@mastra/oracledb'

const storage = new OracleStore({
  id: 'oracle-storage',
  user: process.env.ORACLE_DATABASE_USER,
  password: process.env.ORACLE_DATABASE_PASSWORD,
  connectString: process.env.ORACLE_DATABASE_CONNECT_STRING,
})

export const oracleAgent = new Agent({
  id: 'oracle-agent',
  name: 'Oracle Agent',
  instructions: 'You are an assistant with persistent OracleDB-backed memory.',
  model: '__GATEWAY_OPENAI_MODEL__',
  memory: new Memory({ storage }),
})
```
