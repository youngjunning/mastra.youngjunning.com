# Elasticsearch

Elasticsearch 儲存實作透過官方 [`@elastic/elasticsearch`](https://github.com/elastic/elasticsearch-js) 用戶端，將 Agent 記憶、Workflow 快照及評分儲存在 Elasticsearch 叢集中。它和 `ElasticSearchVector` 採用相同的連線設定，因此 Agent 記憶和語意檢索可共用同一個叢集，甚至同一個用戶端執行個體。

`ElasticSearchStore` 目前支援 `memory`、`workflows` 和 `scores` 三個儲存領域。

## 安裝 {/* #installation */}

```bash
npm install @mastra/elasticsearch
```

## 使用方式 {/* #usage */}

### 使用 URL {/* #using-a-url */}

```typescript
import { ElasticSearchStore } from '@mastra/elasticsearch'

const storage = new ElasticSearchStore({
  id: 'elasticsearch-storage',
  url: 'http://localhost:9200',
})

await storage.init()
```

### 使用身分驗證 {/* #using-authentication */}

```typescript
import { ElasticSearchStore } from '@mastra/elasticsearch'

const storage = new ElasticSearchStore({
  id: 'elasticsearch-storage',
  url: 'https://my-cluster.example.com:9200',
  auth: { apiKey: process.env.ELASTICSEARCH_API_KEY! },
})
```

`auth` 也接受 `{ username, password }` 或 `{ bearer }`。

### 使用預先設定的用戶端 {/* #using-a-pre-configured-client */}

如需指定雲端 ID、TLS 選項或自訂傳輸等進階設定，請傳入已完成設定的用戶端。`ElasticSearchVector` 可以共用這個用戶端。

```typescript
import { Client } from '@elastic/elasticsearch'
import { ElasticSearchStore, ElasticSearchVector } from '@mastra/elasticsearch'

const client = new Client({
  node: 'https://my-cluster.example.com:9200',
  auth: { apiKey: process.env.ELASTICSEARCH_API_KEY! },
})

const storage = new ElasticSearchStore({ id: 'elasticsearch-storage', client })
const vector = new ElasticSearchVector({ id: 'elasticsearch-vector', client })
```

自行提供的用戶端須由你管理其生命週期。呼叫 `storage.close()` 後，該用戶端仍會保持開啟。

## 附加說明 {/* #additional-notes */}

### 索引結構 {/* #index-structure */}

每張 Mastra 儲存資料表都會對應到同名的 Elasticsearch 索引，例如 `mastra_threads`、`mastra_messages`、`mastra_workflow_snapshot` 和 `mastra_scorers`。每筆資料都以 JSON 文件儲存，內部結構不會被解析，`key` 欄位的型別為 keyword。首次使用時會自動建立索引，因此不必手動管理索引對應。

### 一致性 {/* #consistency */}

Elasticsearch 搜尋是近即時的。每次寫入都會立即重新整理索引，讓後續讀取和搜尋取得寫入結果。讀取單筆資料時，會依 ID 即時取得文件。

### 關閉連線 {/* #closing-connections */}

關閉應用程式時，請呼叫下列方法關閉連線。

```typescript
await storage.close()
```

這個方法只會關閉 `ElasticSearchStore` 根據 `url` 建立的用戶端。自行提供的用戶端會保持開啟。

## 使用範例 {/* #usage-example */}

### 為 Agent 加入記憶 {/* #adding-memory-to-an-agent */}

```typescript title="src/mastra/agents/elasticsearch-agent.ts"
import { Memory } from '@mastra/memory'
import { Agent } from '@mastra/core/agent'
import { ElasticSearchStore } from '@mastra/elasticsearch'

export const elasticsearchAgent = new Agent({
  id: 'elasticsearch-agent',
  name: 'Elasticsearch Agent',
  instructions:
    'You are an AI agent with the ability to automatically recall memories from previous interactions.',
  model: '__GATEWAY_OPENAI_MODEL__',
  memory: new Memory({
    storage: new ElasticSearchStore({
      id: 'elasticsearch-agent-storage',
      url: process.env.ELASTICSEARCH_URL!,
      auth: { apiKey: process.env.ELASTICSEARCH_API_KEY! },
    }),
    options: {
      lastMessages: 10,
    },
  }),
})
```

### 在 Mastra 執行個體中使用 {/* #using-with-mastra-instance */}

```typescript
import { Mastra } from '@mastra/core'
import { ElasticSearchStore } from '@mastra/elasticsearch'

const storage = new ElasticSearchStore({
  id: 'mastra-storage',
  url: 'http://localhost:9200',
})

const mastra = new Mastra({
  storage, // init() called automatically
})
```

若直接使用儲存功能而未透過 Mastra 執行個體，請明確呼叫 `init()`。

```typescript
import { ElasticSearchStore } from '@mastra/elasticsearch'

const storage = new ElasticSearchStore({
  id: 'elasticsearch-storage',
  url: 'http://localhost:9200',
})

await storage.init()

// Access domain-specific stores via getStore()
const memoryStore = await storage.getStore('memory')
const thread = await memoryStore?.getThreadById({ threadId: '...' })
```
