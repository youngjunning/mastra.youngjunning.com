# Upstash

Mastra 透過 Upstash 提供的 Redis 相容鍵值儲存服務存放資料，適合無伺服器部署。

:::warning[計費方式]

Agent 在對話過程中會執行大量 Redis 指令。搭配使用 Mastra 和 Upstash 時，按用量計費可能讓費用超出預期。強烈建議選擇**固定費率方案**，讓費用更容易預估。方案詳情請參閱 [Upstash 定價](https://upstash.com/pricing/redis)，相關背景可見 [GitHub 議題 #5850](https://github.com/mastra-ai/mastra/issues/5850)。

:::

:::warning[不支援可觀測性]

Upstash 儲存後端**不支援可觀測性儲存領域**。`MastraStorageExporter` 匯出的 Trace 無法持久化儲存至 Upstash。若只使用 Upstash 作為儲存後端，[Studio](/docs/studio/overview) 的可觀測性功能將無法運作。若要啟用這些功能，請使用[複合式儲存](/reference/storage/composite#specialized-storage-for-observability)，將可觀測性資料導向 ClickHouse 等受支援的儲存後端。

:::


## 使用方式 {/* #usage */}

```typescript
import { UpstashStore } from '@mastra/upstash'

const storage = new UpstashStore({
  id: 'upstash-storage',
  url: process.env.UPSTASH_URL,
  token: process.env.UPSTASH_TOKEN,
})
```

## 附加說明 {/* #additional-notes */}

### 鍵的結構 {/* #key-structure */}

Upstash 以鍵值配對儲存資料，各類鍵的格式如下：

- 對話串鍵：`{prefix}thread:{threadId}`
- 訊息鍵：`{prefix}message:{messageId}`
- 元資料鍵：`{prefix}metadata:{entityId}`

### 無伺服器部署的優點 {/* #serverless-benefits */}

Upstash 儲存特別適合無伺服器部署：

- 無須管理連線
- 依請求次數計費
- 可選擇全球複寫
- 相容於邊緣運算環境

### 資料持久化 {/* #data-persistence */}

Upstash 提供下列資料持久化與復原功能：

- 自動持久化儲存資料
- 還原至指定時間點
- 可選擇跨區域複寫

### 效能考量 {/* #performance-considerations */}

若要改善效能，可採取以下做法：

- 選用合適的鍵前綴來整理資料
- 監控 Redis 的記憶體用量
- 視需要考慮設定資料到期規則

## 使用範例 {/* #usage-example */}

### 為 Agent 加入記憶功能 {/* #adding-memory-to-an-agent */}

若要讓 Agent 使用 Upstash 儲存記憶，請使用 `Memory` 類別，將 `UpstashStore` 執行個體指定給 `storage`，並將 `UpstashVector` 執行個體指定給 `vector`。這些設定可指向遠端服務或本機環境。

```typescript title="src/mastra/agents/example-upstash-agent.ts"
import { Memory } from '@mastra/memory'
import { Agent } from '@mastra/core/agent'
import { UpstashStore } from '@mastra/upstash'

export const upstashAgent = new Agent({
  id: 'upstash-agent',
  name: 'Upstash Agent',
  instructions:
    'You are an AI agent with the ability to automatically recall memories from previous interactions.',
  model: '__GATEWAY_OPENAI_MODEL__',
  memory: new Memory({
    storage: new UpstashStore({
      id: 'upstash-agent-storage',
      url: process.env.UPSTASH_REDIS_REST_URL!,
      token: process.env.UPSTASH_REDIS_REST_TOKEN!,
    }),
    options: {
      generateTitle: true, // Explicitly enable automatic title generation
    },
  }),
})
```

### 使用 Agent {/* #using-the-agent */}

透過 `memoryOptions` 設定這次請求的記憶檢索範圍。以 `lastMessages: 5` 將近期訊息的檢索範圍限制為最近 5 則，再透過 `semanticRecall` 進行語意檢索。`topK: 3` 會擷取最相關的 3 則訊息，`messageRange: 2` 則會一併納入每則相符訊息前後各 2 則訊息，補足脈絡。

```typescript title="src/test-upstash-agent.ts"
import 'dotenv/config'

import { mastra } from './mastra'

const threadId = '123'
const resourceId = 'user-456'

const agent = mastra.getAgent('upstashAgent')

const message = await agent.stream('My name is Mastra', {
  memory: {
    thread: threadId,
    resource: resourceId,
  },
})

await message.textStream.pipeTo(new WritableStream())

const stream = await agent.stream("What's my name?", {
  memory: {
    thread: threadId,
    resource: resourceId,
  },
  memoryOptions: {
    lastMessages: 5,
    semanticRecall: {
      topK: 3,
      messageRange: 2,
    },
  },
})

for await (const chunk of stream.textStream) {
  process.stdout.write(chunk)
}
```
