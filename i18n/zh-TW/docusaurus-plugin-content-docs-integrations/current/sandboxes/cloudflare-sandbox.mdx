# Cloudflare Sandbox

`CloudflareSandbox` 透過 [Sandbox Bridge HTTP API](https://developers.cloudflare.com/sandbox/bridge/http-api/) 在遠端 [Cloudflare Sandbox](https://developers.cloudflare.com/sandbox/) 中執行命令及管理檔案。

:::warning

使用此 Provider 前，請先部署 [Sandbox Bridge Worker](https://developers.cloudflare.com/sandbox/bridge/) 並妥善保護它。Bridge 可以代表呼叫端建立和刪除 Sandbox、執行命令，以及寫入檔案。

:::

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/cloudflare-sandbox
```

## 使用方式 {/* #usage */}

將 `CloudflareSandbox` 加入 Workspace，再將該 Workspace 指派給 Agent。

```typescript title="src/mastra/agents/dev-agent.ts"
import { Agent } from '@mastra/core/agent'
import { Workspace } from '@mastra/core/workspace'
import { CloudflareSandbox } from '@mastra/cloudflare-sandbox'

const workspace = new Workspace({
  sandbox: new CloudflareSandbox({
    baseUrl: process.env.CLOUDFLARE_SANDBOX_BRIDGE_URL!,
    apiToken: process.env.CLOUDFLARE_SANDBOX_API_KEY,
    workingDirectory: '/workspace',
    commandTimeout: 300_000,
  }),
})

export const agent = new Agent({
  id: 'dev-agent',
  name: 'Development agent',
  instructions: 'You are a helpful development assistant.',
  model: 'anthropic/claude-sonnet-4-6',
  workspace,
})
```

Workspace 啟動時，Provider 會建立遠端 Sandbox。若要重新連線至既有的 Sandbox，請傳入 `sandboxId`。

## 執行命令 {/* #execute-commands */}

呼叫 `executeCommand()` 時，可傳入命令引數、環境變數、工作目錄，以及處理串流輸出的回呼函式。Provider 會將命令以 `argv` 陣列傳送，由 Bridge 處理 Shell 跳脫字元。

```typescript
const result = await workspace.sandbox?.executeCommand?.('npm', ['test'], {
  cwd: '/workspace/project',
  env: {
    NODE_ENV: 'test',
  },
  onStdout: chunk => process.stdout.write(chunk),
  onStderr: chunk => process.stderr.write(chunk),
})
```

## 寫入檔案 {/* #write-files */}

相對路徑以 `/workspace` 為基準解析，絕對路徑解析後也必須位於 `/workspace` 內。每個檔案都會透過獨立的請求傳送至 Bridge，單一檔案的大小上限為 32 MiB。

Cloudflare Sandbox 無法個別設定檔案權限，因此會拒絕含有 `mode` 的 `writeFiles` 呼叫。

```typescript
await workspace.sandbox?.writeFiles?.([
  { path: 'src/index.ts', content: "console.log('hello')\n" },
  { path: '/workspace/package.json', content: JSON.stringify({ type: 'module' }) },
])
```

## 讀取檔案 {/* #read-files */}

從 `/workspace` 讀取單一檔案時，會傳回原始位元組。相對路徑以 `/workspace` 為基準解析，絕對路徑解析後也必須位於該目錄內。

```typescript
const bytes = await workspace.sandbox?.readFile?.('src/index.ts')
const source = new TextDecoder().decode(bytes)
```

## 在容器休眠後保留檔案 {/* #keep-files-across-container-sleep */}

容器閒置達 `sleepAfter` 設定的時間後，Cloudflare 會停止容器。預設為 10 分鐘。下一道命令會啟動全新的容器，先前直接寫入 `/workspace` 的內容會遺失。請將 `/workspace` 當作暫存空間，並將需要保留的檔案寫入已掛載的儲存桶。

透過 Workspace 的 `mounts` 選項指定與 S3 相容的儲存桶，例如 Cloudflare R2。Sandbox 會在 `start()` 時掛載儲存桶。容器從休眠中喚醒時，原有的掛載會消失，因此 Sandbox 會在下一次檔案系統作業前重新掛載這些路徑，讓儲存桶中的資料在休眠後仍可存取。

```typescript
import { Workspace } from '@mastra/core/workspace'
import { S3Filesystem } from '@mastra/s3'
import { CloudflareSandbox } from '@mastra/cloudflare-sandbox'

const workspace = new Workspace({
  sandbox: new CloudflareSandbox({
    baseUrl: process.env.CLOUDFLARE_SANDBOX_BRIDGE_URL!,
    apiToken: process.env.CLOUDFLARE_SANDBOX_BRIDGE_TOKEN!,
  }),
  mounts: {
    '/workspace/data': new S3Filesystem({
      bucket: 'agent-data',
      region: 'auto',
      endpoint: `https://${process.env.CLOUDFLARE_ACCOUNT_ID}.r2.cloudflarestorage.com`,
      accessKeyId: process.env.R2_ACCESS_KEY_ID,
      secretAccessKey: process.env.R2_SECRET_ACCESS_KEY,
    }),
  },
})
```

Bridge 使用 s3fs 掛載儲存桶，因此只接受 `type: 's3'` 的掛載設定。若使用 GCS 或 Azure 的檔案系統，或 S3 憑證含有 `sessionToken`，Provider 會直接傳回表示掛載失敗的 `MountResult`，不會向 Bridge 送出請求。

`getInstructions()` 預設傳回的說明會告知模型，`/workspace` 的資料可能在兩道命令之間遺失，並列出應寫入的掛載路徑。

## 備份與還原 Workspace {/* #persist-and-restore-the-workspace */}

`persistWorkspace()` 將 `/workspace` 封存為 tar 並傳回原始位元組。`hydrateWorkspace()` 可用這些位元組還原 Workspace。這兩個方法適合單次備份與還原，無法取代掛載。容器喚醒後，必須在執行第一道命令前完成還原。若在容器剛喚醒時就備份，空白的 Workspace 會覆寫原有的封存檔。

```typescript
// Back up before the container can sleep
const archive = await workspace.sandbox?.persistWorkspace?.({ excludes: ['node_modules'] })
await myStorage.put('workspace-backup', archive)

// Later, on a fresh or reconnected sandbox
const archive = await myStorage.get('workspace-backup')
await workspace.sandbox?.hydrateWorkspace?.(archive)
```

若要管理執行工作階段，請直接呼叫 `CloudflareSandboxBridgeClient` 的 `createSession` 和 `deleteSession` 方法。

## 生命週期行為 {/* #lifecycle-behavior */}

* `start()`：重新連線至 `sandboxId` 指定的 Sandbox，或建立遠端 Sandbox，接著套用 Workspace 的 `mounts` 掛載設定。
* `stop()`：解除遠端 Sandbox 與 Mastra 生命週期的關聯。由於 Bridge 未提供暫停操作，遠端 Sandbox 會保留。
* `destroy()`：刪除遠端 Sandbox。

## 限制 {/* #limitations */}

此 Provider 直接透過 Sandbox 介面提供命令執行、串流輸出、檔案讀寫、S3 相容儲存桶掛載和 Workspace 持久化功能。工作階段僅能透過 Bridge 用戶端（`CloudflareSandboxBridgeClient`）使用，`CloudflareSandbox` 介面未提供此功能。此 Provider 未提供 PTY 終端機，也不支援背景程序管理、標準輸入（stdin）、快照或連接埠 URL。
