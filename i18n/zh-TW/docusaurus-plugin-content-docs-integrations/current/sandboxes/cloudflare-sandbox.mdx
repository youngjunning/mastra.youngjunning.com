# Cloudflare 沙箱

`CloudflareSandbox`執行命令並管理遠端文件[Cloudflare 沙箱](https://developers.cloudflare.com/sandbox/)透過[Sandbox橋 HTTP API](https://developers.cloudflare.com/sandbox/bridge/http-api/).

：：：警告

部署並保護[Sandbox Bridge Worker](https://developers.cloudflare.com/sandbox/bridge/) before using this provider. The bridge can create and delete sandboxes, execute commands, and write files on behalf of its callers.

:::

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/cloudflare-sandbox
```

## 用法 {/* #usage */}

添加`CloudflareSandbox` to a workspace and assign it to an agent:

```typescript title="src/mastra/agents/dev-agent.ts"
import { Agent } from '@mastra/core/agent'
import { Workspace } from '@mastra/core/workspace'
import { CloudflareSandbox } from '@mastra/cloudflare-sandbox'

const workspace = new Workspace({
  sandbox: new CloudflareSandbox({
    baseUrl: process.env.CLOUDFLARE_SANDBOX_BRIDGE_URL!,
    apiToken: process.env.CLOUDFLARE_SANDBOX_API_KEY,
    workingDirectory: '/workspace',
    commandTimeout: 300_000,
  }),
})

export const agent = new Agent({
  id: 'dev-agent',
  name: 'Development agent',
  instructions: 'You are a helpful development assistant.',
  model: 'anthropic/claude-sonnet-4-6',
  workspace,
})
```

Provider在Workspace啟動時建立遠端沙箱。經過`sandboxId` to reconnect to an existing sandbox instead.

## 執行命令 {/* #execute-commands */}

透過傳遞命令參數、環境變數、工作目錄和串流回調`executeCommand()`. The provider sends the command as an `argv` array, so the bridge handles shell escaping:

```typescript
const result = await workspace.sandbox?.executeCommand?.('npm', ['test'], {
  cwd: '/workspace/project',
  env: {
    NODE_ENV: 'test',
  },
  onStdout: chunk => process.stdout.write(chunk),
  onStderr: chunk => process.stderr.write(chunk),
})
```

## 寫入文件 {/* #write-files */}

相對路徑在下解析`/workspace`. Absolute paths must also resolve within `/workspace`. Each file is sent as its own bridge request, and the bridge caps a single file at 32 MiB.

Cloudflare 沙箱無法設定每個檔案的權限，因此`writeFiles` call that includes a `mode` is rejected rather than silently ignored.

```typescript
await workspace.sandbox?.writeFiles?.([
  { path: 'src/index.ts', content: "console.log('hello')\n" },
  { path: '/workspace/package.json', content: JSON.stringify({ type: 'module' }) },
])
```

## 讀取文件 {/* #read-files */}

讀回單一文件`/workspace` as raw bytes. Relative paths resolve under `/workspace`, and absolute paths must also resolve within it.

```typescript
const bytes = await workspace.sandbox?.readFile?.('src/index.ts')
const source = new TextDecoder().decode(bytes)
```

## 讓檔案跨容器休眠 {/* #keep-files-across-container-sleep */}

`sleepAfter` (10 minutes by default). The next command starts a fresh container, so anything written under `/workspace` is gone. Treat `/workspace` as scratch space, and put files that must survive on a mounted bucket.

透過Workspace掛載 S3 相容儲存桶，例如 Cloudflare R2`mounts` option. The sandbox mounts it on `start()`. A slept container boots without its mounts, so the sandbox re-mounts any dropped paths before the next filesystem operation, keeping mounted data durable across sleep.

```typescript
import { Workspace } from '@mastra/core/workspace'
import { S3Filesystem } from '@mastra/s3'
import { CloudflareSandbox } from '@mastra/cloudflare-sandbox'

const workspace = new Workspace({
  sandbox: new CloudflareSandbox({
    baseUrl: process.env.CLOUDFLARE_SANDBOX_BRIDGE_URL!,
    apiToken: process.env.CLOUDFLARE_SANDBOX_BRIDGE_TOKEN!,
  }),
  mounts: {
    '/workspace/data': new S3Filesystem({
      bucket: 'agent-data',
      region: 'auto',
      endpoint: `https://${process.env.CLOUDFLARE_ACCOUNT_ID}.r2.cloudflarestorage.com`,
      accessKeyId: process.env.R2_ACCESS_KEY_ID,
      secretAccessKey: process.env.R2_SECRET_ACCESS_KEY,
    }),
  },
})
```

橋接器安裝帶有 s3fs 的儲存桶，因此只需`type: 's3'` mount configs are accepted. GCS and Azure filesystems, and S3 credentials that include a `sessionToken`, return a failed `MountResult` without contacting the bridge.

預設`getInstructions()` text tells the model that `/workspace` does not survive between commands and lists the mounted paths to write to instead.

## 保留並恢復Workspace {/* #persist-and-restore-the-workspace */}

`persistWorkspace()`檔案`/workspace` and returns the raw tar bytes; `hydrateWorkspace()` restores it from those bytes. Use this for one-off backups. It is not a substitute for mounts: restoring must happen before the first command after a wake, and a persist taken from a freshly woken container overwrites the archive with an empty workspace.

```typescript
// Back up before the container can sleep
const archive = await workspace.sandbox?.persistWorkspace?.({ excludes: ['node_modules'] })
await myStorage.put('workspace-backup', archive)

// Later, on a fresh or reconnected sandbox
const archive = await myStorage.get('workspace-backup')
await workspace.sandbox?.hydrateWorkspace?.(archive)
```

對於執行會話，請使用`CloudflareSandboxBridgeClient` methods (`createSession`, `deleteSession`) directly.

## 生命週期行為 {/* #lifecycle-behavior */}

* `start()`: 重新連線到`sandboxId` or creates a remote sandbox, then mounts any Workspace `mounts`.
* `stop()`：分離 Mastra 生命週期而不刪除遠端沙箱，因為橋接器不公開掛起操作。
* `destroy()`：刪除遠端沙箱。

## 限制 {/* #limitations */}

此Provider直接在沙箱上提供命令執行、串流輸出、檔案讀取和寫入、S3 相容儲存桶安裝以及Workspace持久性。會話在橋客戶端上可用（`CloudflareSandboxBridgeClient`) but not on the `CloudflareSandbox` surface. PTY terminals are not exposed, and the provider doesn't support background process management, stdin, snapshots, or port URLs.
