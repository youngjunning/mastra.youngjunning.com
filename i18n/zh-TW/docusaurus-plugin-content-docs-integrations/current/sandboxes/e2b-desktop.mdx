# E2B Desktop

在隔離的 [E2B](https://e2b.dev) 雲端 Sandbox 中執行完整的 Linux 桌面環境，支援擷取螢幕畫面及控制滑鼠與鍵盤。`E2BDesktopSandbox` 繼承自 [`E2BSandbox`](/integrations/sandboxes/e2b)，因此基礎 Provider 支援的所有功能，包括執行指令、執行背景程序、上傳檔案，以及暫停後恢復並重新連線，都可在同一台桌面機器上使用。介面細節請參閱 [WorkspaceSandbox 介面](/reference/workspace/sandbox)。

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/e2b-desktop
```

透過 `E2B_API_KEY` 環境變數或 `apiKey` 選項設定 E2B API 金鑰。

## 使用方式 {/* #usage */}

將 `E2BDesktopSandbox` 加入 Workspace，再將該 Workspace 指派給 Agent。由於此 Sandbox 支援[電腦操作功能](/docs/sandbox/computer)，Workspace 除了註冊 shell 和程序相關的 Tool，也會註冊 `mastra_workspace_computer_*` Tool：

```typescript
import { Agent } from '@mastra/core/agent'
import { Workspace } from '@mastra/core/workspace'
import { E2BDesktopSandbox } from '@mastra/e2b-desktop'

const workspace = new Workspace({
  sandbox: new E2BDesktopSandbox({
    resolution: [1280, 720],
  }),
})

const agent = new Agent({
  id: 'desktop-agent',
  name: 'Desktop Agent',
  instructions: 'You can control a Linux desktop and run shell commands.',
  model: '__GATEWAY_ANTHROPIC_MODEL_SONNET__',
  workspace,
})

const response = await agent.generate(
  'Take a screenshot, then create /tmp/hello.txt with the text "hello" and cat it.',
)
```

Agent 可以搭配使用桌面操作（點按、輸入文字、擷取螢幕畫面）與 shell 指令。這兩種操作都在同一台機器上執行。

### 直接控制桌面 {/* #direct-desktop-control */}

不透過 Agent，直接在程式碼中使用 `computer` 功能：

```typescript
const sandbox = new E2BDesktopSandbox()
await sandbox.start()

await sandbox.computer.leftClick(100, 200)
await sandbox.computer.type('hello')
const { data } = await sandbox.computer.screenshot() // PNG bytes

const size = await sandbox.computer.getScreenSize()
console.log(size) // { width: 1024, height: 768 }
```

### 即時檢視桌面 {/* #live-desktop-view */}

`streamUrl()` 會在 Sandbox 內啟動需要驗證的 noVNC 串流，並傳回檢視網址。在瀏覽器中開啟該網址，即可觀看 Agent 的操作：

```typescript
const url = await sandbox.computer.streamUrl()
// https://6080-<sandbox-id>.e2b.app/vnc.html?...&password=<auth-key>
```

### 直接使用 Desktop SDK {/* #desktop-sdk-escape-hatch */}

你可以透過底層的 [`@e2b/desktop`](https://github.com/e2b-dev/desktop) Sandbox 使用桌面專用 API，例如 `launch`、`open`、視窗輔助功能和自訂串流控制：

```typescript
await sandbox.desktop.launch('xfce4-terminal')
await sandbox.desktop.open('https://mastra.ai')
```

## 掛載雲端儲存空間 {/* #cloud-storage-mounting */}

預設的 `desktop` 範本未包含 FUSE 工具，因此若要[掛載雲端儲存空間](/integrations/sandboxes/e2b#mounting-cloud-storage)，必須使用已安裝 `s3fs` 或 `gcsfuse` 的自訂桌面範本。透過 `template` 選項指定該範本。
