# Modal

在隔離的 [Modal](https://modal.com) 雲端 Sandbox 執行指令。Modal 的基礎設施提供安全的暫時性執行環境。介面的詳細資訊請參閱 [WorkspaceSandbox 介面](/reference/workspace/sandbox)。

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/modal
```

## 使用方式 {/* #usage */}

將 `ModalSandbox` 加入 Workspace，再將這個 Workspace 指派給 Agent：

```typescript
import { Agent } from '@mastra/core/agent'
import { Workspace } from '@mastra/core/workspace'
import { ModalSandbox } from '@mastra/modal'

const workspace = new Workspace({
  sandbox: new ModalSandbox({
    id: 'dev-sandbox',
    baseImage: 'ubuntu:22.04',
    timeoutMs: 60_000,
  }),
})

const agent = new Agent({
  id: 'dev-agent',
  model: '__GATEWAY_ANTHROPIC_MODEL_OPUS__',
  workspace,
})
```

## 身分驗證 {/* #authentication */}

透過環境變數或建構函式的選項設定 Modal 憑證：

```bash
MODAL_TOKEN_ID=ak-...
MODAL_TOKEN_SECRET=as-...
```

也可以直接將憑證傳入建構函式：

```typescript
const sandbox = new ModalSandbox({
  tokenId: process.env.MODAL_TOKEN_ID,
  tokenSecret: process.env.MODAL_TOKEN_SECRET,
})
```

從 [Modal 控制台](https://modal.com/settings/tokens)取得憑證。

## Sandbox 生命週期 {/* #sandbox-lifecycle */}

* **`_start()`**：嘗試重新連線至已在執行的 Sandbox。找不到時，如果先前呼叫 `_stop()` 留有快照，就用最新的快照建立 Sandbox。若無可用快照，則以 `baseImage` 建立。
* **`_stop()`**：先擷取檔案系統的快照，再終止 Sandbox。快照會保留在同一個執行個體的記憶體中，供後續啟動使用。
* **`_destroy()`**：終止 Sandbox，並捨棄所有已保留的快照。

```typescript
const sandbox = new ModalSandbox({
  id: 'dev-sandbox',
  baseImage: 'ubuntu:22.04',
  timeoutMs: 300_000,
})

await sandbox._start()
await sandbox.processes.spawn('npm install')
await sandbox._stop()
await sandbox._start()
```

## 磁碟區與檔案持久化 {/* #volumes-and-persistent-files */}

使用 `volumes` 選項掛載 [Modal Volumes](https://modal.com/docs/guide/volumes)，再透過 `ModalFilesystem` 讓 Agent 的 Workspace 檔案 Tool 存取掛載路徑。Sandbox 重新啟動後，寫入該掛載路徑下的檔案仍會保留。

```typescript
import { Workspace } from '@mastra/core/workspace'
import { ModalFilesystem, ModalSandbox } from '@mastra/modal'
import { ModalClient } from 'modal'

const modal = new ModalClient()
const privateVolume = await modal.volumes.fromName('agent-user-123', { createIfMissing: true })
const teamVolume = await modal.volumes.fromName('agent-team', { createIfMissing: true })

const sandbox = new ModalSandbox({
  id: 'agent-sandbox',
  workingDirectory: '/workspace',
  volumes: {
    '/mnt/agent': privateVolume,
    '/mnt/team': teamVolume,
  },
})

const workspace = new Workspace({
  sandbox,
  filesystem: new ModalFilesystem({ sandbox, basePath: '/mnt/agent' }),
})
```

`ModalFilesystem` 在 Sandbox 內執行檔案操作，並將所有可存取的路徑限制在 `basePath` 的範圍內。設定 `readOnly: true` 即可禁止寫入。

其他 Sandbox 寫入同一磁碟區的變更，必須重新載入後才看得到。對於長時間執行的 Sandbox，可呼叫 `reloadVolumes()` 來讀取這些變更：

```typescript
await sandbox.reloadVolumes()
```

:::note

請將工作目錄設在所有磁碟區的掛載路徑之外，例如 `/workspace`。Modal 無法重新載入目前工作目錄所在的磁碟區，因此，若 `workingDirectory` 等於任一掛載路徑或位於其下，`ModalSandbox` 就會擲出例外。

:::

## 背景程序 {/* #background-processes */}

`ModalSandbox` 內建程序管理員，可啟動及管理背景程序。每次呼叫 `spawn()`，都會透過 Modal SDK 的 `Sandbox.exec()` API 建立一個新的 `ContainerProcess`。

```typescript
const sandbox = new ModalSandbox({ id: 'dev-sandbox' })
await sandbox._start()

// Spawn a background process
const handle = await sandbox.processes.spawn('node script.js', {
  env: { PORT: '3000' },
  onStdout: data => console.log(data),
})

// Wait for the process to complete
const result = await handle.wait()
console.log(result.exitCode)

// Kill the process
await handle.kill()
```

:::note

目前不支援 `sendStdin()`。Modal JS SDK 的 `Sandbox.exec()` 未提供存取標準輸入的介面。

:::

完整 API 請參閱 [`SandboxProcessManager` 參考文件](/reference/workspace/process-manager)。
