# Blaxel

在隔離的 [Blaxel](https://blaxel.ai/) 雲端 Sandbox 中執行命令。Blaxel 提供安全、隔離的程式碼執行環境，支援透過 FUSE 掛載 S3 或 GCS 雲端儲存空間。介面詳細資訊請參閱 [WorkspaceSandbox 介面](/reference/workspace/sandbox)。

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/blaxel
```

## 使用方式 {/* #usage */}

將 `BlaxelSandbox` 加入 Workspace，再將該 Workspace 指派給 Agent：

```typescript
import { Agent } from '@mastra/core/agent'
import { Workspace } from '@mastra/core/workspace'
import { BlaxelSandbox } from '@mastra/blaxel'

const workspace = new Workspace({
  sandbox: new BlaxelSandbox(),
})

const agent = new Agent({
  id: 'code-agent',
  name: 'Code Agent',
  instructions: 'You are a coding assistant working in this workspace.',
  model: '__GATEWAY_ANTHROPIC_MODEL_SONNET__',
  workspace,
})
```

### 自訂映像檔與資源配置 {/* #custom-image-with-resources */}

使用自訂 Docker 映像檔，並配置更多記憶體：

```typescript
const workspace = new Workspace({
  sandbox: new BlaxelSandbox({
    image: 'node:20-slim',
    memory: 8192,
    region: 'auto',
    timeout: '10m',
  }),
})
```

## 背景處理程序 {/* #background-processes */}

`BlaxelSandbox` 內建處理程序管理員，可啟動與管理背景處理程序。

```typescript
const sandbox = new BlaxelSandbox({ id: 'dev-sandbox' })
await sandbox.start()

// Spawn a background process
const handle = await sandbox.processes.spawn('node server.js', {
  env: { PORT: '3000' },
  onStdout: data => console.log(data),
})

// Interact with the process
await handle.sendStdin('hello\n')
await handle.closeStdin()
console.log(handle.stdout)
await handle.kill()
```

預設可以寫入已啟動處理程序的標準輸入。傳入 `stdinMode: 'ignore'` 可在啟動處理程序時關閉標準輸入，讓讀取標準輸入的命令立即收到 EOF（檔案結尾）。

完整的 API 請參閱 [`SandboxProcessManager` 參考文件](/reference/workspace/process-manager)。

## 掛載雲端儲存空間 {/* #mounting-cloud-storage */}

Blaxel Sandbox 可掛載 S3 或 GCS 檔案系統。掛載後，就能在 Sandbox 內像存取本機目錄一樣存取雲端儲存空間。

### S3 {/* #s3 */}

```typescript
import { Workspace } from '@mastra/core/workspace'
import { S3Filesystem } from '@mastra/s3'
import { BlaxelSandbox } from '@mastra/blaxel'

const workspace = new Workspace({
  mounts: {
    '/data': new S3Filesystem({
      bucket: 'my-bucket',
      region: 'us-east-1',
      accessKeyId: process.env.AWS_ACCESS_KEY_ID,
      secretAccessKey: process.env.AWS_SECRET_ACCESS_KEY,
    }),
  },
  sandbox: new BlaxelSandbox(),
})
```

### GCS {/* #gcs */}

```typescript
import { Workspace } from '@mastra/core/workspace'
import { GCSFilesystem } from '@mastra/gcs'
import { BlaxelSandbox } from '@mastra/blaxel'

const workspace = new Workspace({
  mounts: {
    '/data': new GCSFilesystem({
      bucket: 'my-bucket',
      credentials: JSON.parse(process.env.GCS_SERVICE_ACCOUNT_KEY!),
    }),
  },
  sandbox: new BlaxelSandbox(),
})
```
