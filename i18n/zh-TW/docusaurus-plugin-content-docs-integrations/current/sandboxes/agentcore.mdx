# AgentCore

使用 `InvokeAgentRuntimeCommand`，即可在 [AWS Bedrock AgentCore Runtime](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/runtime-execute-command.html) 工作階段中執行 shell 指令。

如果 Agent 已在 AgentCore Runtime 中執行，且你想讓 Mastra Workspace 沿用同一個工作階段執行指令，請使用 `AgentCoreRuntimeSandbox`。介面細節請參閱 [WorkspaceSandbox 介面](/reference/workspace/sandbox)。

:::warning

`AgentCoreRuntimeSandbox` 僅支援單次執行指令，不支援管理背景程序、標準輸入或掛載檔案系統。AgentCore Code Interpreter 是獨立的 AWS 服務，不包含在這個 Provider 中。

:::

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/agentcore
```

## 用法 {/* #usage */}

將 `AgentCoreRuntimeSandbox` 加入 Workspace，再將該 Workspace 指派給 Agent：

```typescript title="src/mastra/agents/dev-agent.ts"
import { Agent } from '@mastra/core/agent'
import { Workspace } from '@mastra/core/workspace'
import { AgentCoreRuntimeSandbox } from '@mastra/agentcore'

const workspace = new Workspace({
  sandbox: new AgentCoreRuntimeSandbox({
    region: 'us-west-2',
    agentRuntimeArn: process.env.AGENTCORE_RUNTIME_ARN!,
    runtimeSessionId: '12345678-1234-1234-1234-123456789012',
  }),
})

const agent = new Agent({
  id: 'dev-agent',
  name: 'dev-agent',
  model: 'anthropic/claude-sonnet-4-6',
  instructions: 'You are a helpful development assistant.',
  workspace,
})
```

透過 Sandbox 從程式中執行指令：

```typescript
const result = await workspace.sandbox?.executeCommand?.('npm', ['test'], {
  cwd: '/workspace',
  env: {
    NODE_ENV: 'test',
  },
  timeout: 300_000,
})

if (!result?.success) {
  console.error(result?.stderr)
}
```

## 方法 {/* #methods */}

### 執行指令 {/* #command-execution */}

#### `executeCommand(command, args?, options?)` {/* #executecommandcommand-args-options */}

在 AgentCore Runtime 工作階段中執行一次 shell 指令，並傳回標準輸出、標準錯誤、結束代碼，以及是否逾時。

```typescript
const result = await sandbox.executeCommand('npm', ['test'], {
  cwd: '/workspace',
  env: {
    NODE_ENV: 'test',
  },
  timeout: 300_000,
})
```

傳回：`Promise<CommandResult>`。

`options.timeout` 的單位是毫秒。AgentCore Runtime 接受 1 到 3600 秒的指令逾時設定。Provider 會先將毫秒換算成秒，再送出請求。

### 生命週期 {/* #lifecycle */}

#### `start()` {/* #start */}

執行 Sandbox 生命週期中的啟動掛鉤。這個 Provider 在執行 `start()` 時不會建立 AgentCore Runtime 工作階段。

```typescript
await sandbox.start()
```

#### `stop()` {/* #stop */}

只有在 `stopSessionOnLifecycle` 為 `true` 時，才會停止 AgentCore Runtime 工作階段。

```typescript
await sandbox.stop()
```

#### `stopRuntimeSession()` {/* #stopruntimesession */}

主動停止這個 Sandbox 使用的 AgentCore Runtime 工作階段。

如果工作階段由這個 Sandbox 擁有，而且你想直接清理該工作階段，請呼叫此方法。由於 Workspace 的 Sandbox 生命週期之外的 Agent 呼叫也可能共用 AgentCore Runtime 工作階段，`destroy()` 只有在 `stopSessionOnLifecycle` 為 `true` 時才會呼叫此方法。

```typescript
await sandbox.stopRuntimeSession()
```

#### `destroy()` {/* #destroy */}

銷毀 Sandbox 執行個體。如果該執行個體擁有 AWS SDK 用戶端，`destroy()` 也會銷毀該用戶端。若 `stopSessionOnLifecycle` 為 `true`，則會呼叫 `StopRuntimeSession`。

```typescript
await sandbox.destroy()
```

### 中繼資料 {/* #metadata */}

#### `getInfo()` {/* #getinfo */}

傳回 Sandbox 狀態及 AgentCore Runtime 的中繼資料。

```typescript
const info = await sandbox.getInfo()
```

傳回：`Promise<SandboxInfo>`。

## 限制 {/* #limitations */}

`AgentCoreRuntimeSandbox` 依照 AgentCore Runtime 的指令執行規則運作：

* **單次執行**：每道指令會執行到結束或逾時為止。
* **Shell 不會持續運作**：shell 狀態不會保留到下一道指令。請在每道指令中設定所需狀態，例如 `cd /workspace && npm test`。
* **不支援背景程序**：Provider 未提供 `processes` 管理器。
* **無法使用互動式標準輸入**：透過此 Provider 在執行階段執行指令時，不會提供互動式標準輸入串流。
* **不支援掛載 Workspace 檔案系統**：此 Provider 無法掛載 Workspace 的檔案系統。
* **Tool 取決於容器映像**：指令只能使用 AgentCore Runtime 容器映像中已安裝的 Tool。
