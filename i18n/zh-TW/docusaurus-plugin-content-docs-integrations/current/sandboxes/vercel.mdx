# Vercel Sandbox

在隔離的 Vercel 環境中執行指令，可選擇工作階段內持續運作的 Sandbox microVM，或無狀態的 Serverless Functions。

## Vercel Sandbox {/* #vercel-sandbox */}

在 [Vercel Sandbox](https://vercel.com/docs/vercel-sandbox) 中執行指令。它是以 [Firecracker](https://firecracker-microvm.github.io/) 為基礎、執行 Amazon Linux 2023 的暫時性 MicroVM，提供工作階段內持續存在的檔案系統、`sudo` 權限、對外開放的連接埠及背景程序。介面詳情請參閱 [WorkspaceSandbox 介面](/reference/workspace/sandbox)。

:::note

這與透過無狀態 Vercel serverless **Functions** 執行指令的 [`VercelServerlessSandbox`](#vercel-serverless-sandbox) 不同。`VercelSandbox` 執行完整的 Linux MicroVM，支援工作階段內持續存在的檔案系統及長時間執行的程序。

:::

### 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/vercel
```

### 身分驗證 {/* #authentication */}

未明確提供憑證時，`@vercel/sandbox` SDK 會自動使用 Vercel OIDC 權杖。如果提供 `token`、`teamId` 或 `projectId`，就必須同時提供這三個值。

<Tabs>
  <TabItem value="oidc" label="OIDC（建議）">

### 用法 {/* #usage */}

將 `VercelSandbox` 加入 Workspace，並將該 Workspace 指派給 Agent：

```typescript
import { Agent } from '@mastra/core/agent'
import { Workspace } from '@mastra/core/workspace'
import { VercelSandbox } from '@mastra/vercel'

const workspace = new Workspace({
  sandbox: new VercelSandbox({
    runtime: 'node24',
    timeout: 600_000,
  }),
})

const agent = new Agent({
  id: 'code-agent',
  name: 'Code Agent',
  instructions: 'You are a coding assistant working in this workspace.',
  model: '__GATEWAY_ANTHROPIC_MODEL_SONNET__',
  workspace,
})

const response = await agent.generate('Print "Hello, world!" and show the Node.js version.')

console.log(response.text)
```

#### 資源與對外開放的連接埠 {/* #resources-and-exposed-ports */}

分配 vCPU（每個 vCPU 配有 2048 MB 記憶體），並開放連接埠，以存取 Sandbox 內執行的網路服務：

```typescript
const sandbox = new VercelSandbox({
  runtime: 'node24',
  resources: { vcpus: 4 },
  ports: [3000],
})

const workspace = new Workspace({ sandbox })
await sandbox.start()

// The public HTTPS domain for an exposed port is available via getInfo()
const { metadata } = sandbox.getInfo()
console.log(metadata?.domains) // { 3000: 'https://....vercel.run' }
```

#### 串流輸出 {/* #streaming-output */}

透過 `onStdout` 與 `onStderr` 回呼，即時接收指令輸出：

```typescript
await sandbox.executeCommand('sh', ['-c', 'for i in 1 2 3; do echo "line $i"; sleep 1; done'], {
  onStdout: chunk => process.stdout.write(chunk),
  onStderr: chunk => process.stderr.write(chunk),
})
```

兩個回呼都是選填的，可以分別使用。

### 背景程序 {/* #background-processes */}

`VercelSandbox` 包含用來啟動及管理背景程序的程序管理器。每個程序都以 MicroVM 內的獨立指令執行，輸出會串流至指令日誌。

```typescript
const sandbox = new VercelSandbox({ runtime: 'node24', ports: [3000] })
await sandbox.start()

const handle = await sandbox.processes.spawn('node server.js', {
  env: { PORT: '3000' },
  onStdout: data => console.log(data),
})

console.log(handle.stdout)
await handle.kill()
```

完整 API 請參閱 [`SandboxProcessManager` 參考文件](/reference/workspace/process-manager)。

:::note

Vercel Sandbox SDK 未提供執行中指令的標準輸入通道，因此呼叫 `handle.sendStdin()` 會擲回例外。

Mastra 轉接器未實作 Workspace 檔案系統掛載 API。底層 Vercel Sandbox 產品支援[使用者空間檔案系統（FUSE）掛載](https://vercel.com/docs/sandbox/mount-remote-storage)。您可以透過 `sandbox.sandbox` 提供的底層 SDK 執行個體直接設定掛載，但 Mastra 不會管理其生命週期。

:::

### 限制 {/* #limits */}

* 最多 32 個 vCPU，每個 vCPU 具有 2048 MB 記憶體。
* 最多可對外開放 15 個連接埠。
* 檔案系統只在工作階段內保留；Sandbox 停止後，檔案就會遺失。
* 最長執行時間取決於方案（Hobby 為 45 分鐘，Pro 和 Enterprise 最長為 24 小時）；預設執行時間為 5 分鐘。

目前的限制與價格請參閱 [Vercel Sandbox 文件](https://vercel.com/docs/vercel-sandbox)。

## Vercel Serverless Sandbox {/* #vercel-serverless-sandbox */}

`VercelServerlessSandbox` 透過 [Vercel](https://vercel.com) Serverless Functions 執行指令，提供全球分散式、無須自行管理基礎架構且可自動擴充的執行環境。介面詳情請參閱 [WorkspaceSandbox 介面](/reference/workspace/sandbox)。

:::warning

`VercelServerlessSandbox` 是無狀態的，不提供持久檔案系統、互動式 shell 或長時間執行的背景程序。只有 `/tmp` 可寫入，而且其中的資料不會在呼叫之間保留。

:::

:::note

如果需要完整的 Linux MicroVM、工作階段內持續存在的檔案系統、`sudo` 權限、對外開放的連接埠及背景程序，請使用以 [Vercel Sandbox](https://vercel.com/docs/vercel-sandbox) 產品為基礎的 [`VercelSandbox`](#vercel-sandbox)。

:::

### 安裝 {/* #installation-1 */}

```bash npm2yarn
npm install @mastra/vercel
```

### 用法 {/* #usage-1 */}

將 `VercelServerlessSandbox` 加入 Workspace，並將該 Workspace 指派給 Agent：

```typescript
import { Agent } from '@mastra/core/agent'
import { Workspace } from '@mastra/core/workspace'
import { VercelServerlessSandbox } from '@mastra/vercel'

const workspace = new Workspace({
  sandbox: new VercelServerlessSandbox({
    token: process.env.VERCEL_TOKEN,
  }),
})

const agent = new Agent({
  id: 'dev-agent',
  name: 'dev-agent',
  instructions: 'You are a coding assistant working in this workspace.',
  model: '__GATEWAY_ANTHROPIC_MODEL_SONNET__',
  workspace,
})
```

### 限制 {/* #limitations */}

`VercelServerlessSandbox` 底層使用 Serverless Functions，因此有以下限制：

* **沒有持久檔案系統**：寫入 `/tmp` 的檔案是暫時性的，會在呼叫之間清除。
* **沒有互動式 shell**：指令透過 `/bin/sh -c` 執行，不支援標準輸入串流。
* **沒有背景程序**：不提供程序管理器、PID 或長時間執行的工作。
* **不支援掛載**：無法掛載雲端儲存空間（S3、GCS）。
* **逾時限制**：最長執行時間受 `maxDuration` 限制，預設值為 60 秒。
