# 吉拉

為Agent提供Tool來搜尋、建立、更新和轉換問題，並透過 Mastra Connect 管理 Jira 中的評論、工作日誌和問題連結。每個Tool呼叫都會透過 Mastra 平台，該平台會新增連接的憑證。您的應用程式從不儲存 Jira 憑證。

## 連接 {/* #connect */}

在開始之前，請完成[Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect`並配置您的平台項目。

### 連接帳戶 {/* #connect-an-account */}

從包含您的目錄的目錄執行此命令`.env` file:

```bash
mastra connect add jira
```

CLI 將引導您完成 Jira 的授權並等待連線啟動。

### 向Agent添加Tool {/* #add-tools-to-an-agent */}

經過[`tools()`](/reference/connect/tools) to the agent and select the `jira` provider:

```typescript title="src/mastra/agents/jira-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const jiraAgent = new Agent({
  id: 'jira-agent',
  name: 'Jira agent',
  instructions:
    'You help people search, create, update, and transition issues, and manage comments, worklogs, and issue links in Jira.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['jira'] }),
})
```

Agent程式獲得 38 個 Jira Tool，其中包含以下密鑰：`jira_add_comment`. See [Jira tools](/reference/connect/providers#jira) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
