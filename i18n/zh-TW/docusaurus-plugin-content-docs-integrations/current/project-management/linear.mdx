# 線性

為Agent提供Tool來搜尋、建立和更新問題，並透過 Mastra Connect 管理 Linear 中的專案、週期、註解和標籤。每個Tool呼叫都會透過 Mastra 平台，該平台會新增連接的憑證。您的應用程式從不儲存 Linear 憑證。

## 連接 {/* #connect */}

在開始之前，請完成[Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect`並配置您的平台項目。

### 連接帳戶 {/* #connect-an-account */}

從包含您的目錄的目錄執行此命令`.env` file:

```bash
mastra connect add linear
```

CLI 將引導您完成 Linear 的授權並等待連線啟動。

### 向Agent添加Tool {/* #add-tools-to-an-agent */}

經過[`tools()`](/reference/connect/tools) to the agent and select the `linear` provider:

```typescript title="src/mastra/agents/linear-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const linearAgent = new Agent({
  id: 'linear-agent',
  name: 'Linear agent',
  instructions:
    'You help people search, create, and update issues, and manage projects, cycles, comments, and labels in Linear.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['linear'] }),
})
```

Agent程式獲得 46 個線性Tool，其中包含諸如`linear_add_issue_label`. See [Linear tools](/reference/connect/providers#linear) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
