# Google文檔

透過 Mastra Connect 為Agent提供建立文件、插入和取代文字以及編輯 Google 文件中的表格、頁首、頁尾和樣式的Tool。每個Tool呼叫都會透過 Mastra 平台，該平台會新增連接的憑證。您的應用程式從不儲存 Google 文件憑證。

## 連接 {/* #connect */}

在開始之前，請完成[Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect`並配置您的平台項目。

### 連接帳戶 {/* #connect-an-account */}

從包含您的目錄的目錄執行此命令`.env` file:

```bash
mastra connect add google-docs
```

CLI 將引導您完成 Google Docs 的授權並等待連線啟動。

### 向Agent添加Tool {/* #add-tools-to-an-agent */}

經過[`tools()`](/reference/connect/tools) to the agent and select the `google-docs` provider:

```typescript title="src/mastra/agents/google-docs-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const googleDocsAgent = new Agent({
  id: 'google-docs-agent',
  name: 'Google Docs agent',
  instructions:
    'You help people create documents, insert and replace text, and edit tables, headers, footers, and styles in Google Docs.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['google-docs'] }),
})
```

該Agent程式可獲得 37 個 Google Docs Tool，其中包含以下密鑰：`google_docs_add_document_tab`. See [Google Docs tools](/reference/connect/providers#google-docs) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
