# 谷歌表格

為Agent程式提供Tool來讀取、追加、更新和清除儲存格值，並透過 Mastra Connect 在 Google 試算表中建立電子表格、行和工作表。每個Tool呼叫都會透過 Mastra 平台，該平台會新增連接的憑證。您的應用程式從不儲存 Google 試算表憑證。

## 連接 {/* #connect */}

在開始之前，請完成[Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect`並配置您的平台項目。

### 連接帳戶 {/* #connect-an-account */}

從包含您的目錄的目錄執行此命令`.env` file:

```bash
mastra connect add google-sheet
```

CLI 將引導您完成 Google 試算表的授權並等待連線啟動。

### 向Agent添加Tool {/* #add-tools-to-an-agent */}

經過[`tools()`](/reference/connect/tools) to the agent and select the `google-sheet` provider:

```typescript title="src/mastra/agents/google-sheet-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const googleSheetAgent = new Agent({
  id: 'google-sheet-agent',
  name: 'Google Sheets agent',
  instructions:
    'You help people read, append, update, and clear cell values, and create spreadsheets, rows, and worksheets in Google Sheets.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['google-sheet'] }),
})
```

該Agent程式可獲得 18 個 Google Sheets Tool，其中包含以下密鑰：`google_sheet_append_values_to_spreadsheet`. See [Google Sheets tools](/reference/connect/providers#google-sheets) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
