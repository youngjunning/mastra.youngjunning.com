# 線上SharePoint

為Agent商提供Tool來搜尋網站和文件、管理清單、清單項目和網站頁面，以及透過 Mastra Connect 在 SharePoint Online 中共用磁碟機專案。每個Tool呼叫都會透過 Mastra 平台，該平台會新增連接的憑證。您的應用程式從不儲存 SharePoint Online 憑證。

## 連接 {/* #connect */}

在開始之前，請完成[Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect`並配置您的平台項目。

### 連接帳戶 {/* #connect-an-account */}

從包含您的目錄的目錄執行此命令`.env` file:

```bash
mastra connect add sharepoint-online
```

CLI 將引導您完成 SharePoint Online 的授權並等待連線處於活動狀態。

### 向Agent添加Tool {/* #add-tools-to-an-agent */}

經過[`tools()`](/reference/connect/tools) to the agent and select the `sharepoint-online` provider:

```typescript title="src/mastra/agents/sharepoint-online-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const sharepointOnlineAgent = new Agent({
  id: 'sharepoint-online-agent',
  name: 'SharePoint Online agent',
  instructions:
    'You help people search sites and files, manage lists, list items, and site pages, and share drive items in SharePoint Online.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['sharepoint-online'] }),
})
```

Agent程式可取得 53 個 SharePoint Online Tool，其中包含下列金鑰：`sharepoint_online_add_content_type_to_list`. See [SharePoint Online tools](/reference/connect/providers#sharepoint-online) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
