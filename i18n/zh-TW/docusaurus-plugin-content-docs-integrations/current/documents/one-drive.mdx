# OneDrive

透過 Mastra Connect，為 Agent 提供可在 OneDrive 中搜尋、上傳、複製、移動及分享檔案與資料夾，並管理權限和版本的 Tool。每次 Tool 呼叫都會經過 Mastra 平台，由平台加入該連線的憑證；你的應用程式不會儲存 OneDrive 憑證。

## 連線 {/* #connect */}

開始前，請先完成 [Connect 設定](/docs/mastra-platform/connect#get-started)，安裝 `@mastra/connect` 並設定 Mastra 平台專案。

### 連結帳戶 {/* #connect-an-account */}

請在包含 `.env` 檔案的目錄中執行以下命令：

```bash
mastra connect add one-drive
```

CLI 會引導你完成 OneDrive 授權，並等待連線啟用。

### 將 Tool 新增至 Agent {/* #add-tools-to-an-agent */}

將 [`tools()`](/reference/connect/tools) 傳給 Agent，並選取 `one-drive` Provider：

```typescript title="src/mastra/agents/one-drive-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const oneDriveAgent = new Agent({
  id: 'one-drive-agent',
  name: 'OneDrive agent',
  instructions:
    'You help people search, upload, copy, move, and share files and folders, and manage permissions and versions in OneDrive.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['one-drive'] }),
})
```

Agent 可使用 20 個 OneDrive Tool，Tool key 包括 `one_drive_copy_item`。完整清單請參閱 [OneDrive Tool](/reference/connect/providers#onedrive)；如需限制可用 Tool，或要求每次呼叫在執行前取得核准，請參閱 [`tools()` 參數](/reference/connect/tools#parameters)。
