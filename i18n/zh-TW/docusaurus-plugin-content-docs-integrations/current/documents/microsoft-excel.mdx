# Microsoft Excel

透過 Mastra Connect，為 Agent 提供可在 Microsoft Excel 中尋找及建立活頁簿、讀取和更新範圍，以及管理工作表、表格與圖表的 Tool。每次 Tool 呼叫都會經過 Mastra 平台，由平台加入該連線的憑證；你的應用程式不會儲存 Microsoft Excel 憑證。

## 連線 {/* #connect */}

開始前，請先完成 [Connect 設定](/docs/mastra-platform/connect#get-started)，安裝 `@mastra/connect` 並設定 Mastra 平台專案。

:::note

工作表、範圍、表格、圖表和命名項目等活頁簿操作需要使用公司或學校帳戶。個人 Microsoft 帳戶可以尋找、建立、列出、取得及刪除活頁簿檔案，但 Microsoft Graph 會拒絕對個人 OneDrive 執行活頁簿操作。

:::

### 連結帳戶 {/* #connect-an-account */}

請在包含 `.env` 檔案的目錄中執行以下命令：

```bash
mastra connect add microsoft-excel
```

CLI 會引導你完成 Microsoft Excel 授權，並等待連線啟用。

### 將 Tool 新增至 Agent {/* #add-tools-to-an-agent */}

將 [`tools()`](/reference/connect/tools) 傳給 Agent，並選取 `microsoft-excel` Provider：

```typescript title="src/mastra/agents/microsoft-excel-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const microsoftExcelAgent = new Agent({
  id: 'microsoft-excel-agent',
  name: 'Microsoft Excel agent',
  instructions:
    'You help people find and create workbooks, read and update ranges, and manage worksheets, tables, and charts in Microsoft Excel.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['microsoft-excel'] }),
})
```

Agent 可使用 27 個 Microsoft Excel Tool，Tool key 包括 `microsoft_excel_add_chart`。完整清單請參閱 [Microsoft Excel Tool](/reference/connect/providers#microsoft-excel)；如需限制可用 Tool，或要求每次呼叫在執行前取得核准，請參閱 [`tools()` 參數](/reference/connect/tools#parameters)。
