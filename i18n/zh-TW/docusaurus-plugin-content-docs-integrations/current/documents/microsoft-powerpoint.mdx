# Microsoft PowerPoint

透過 Mastra Connect，為 Agent 提供可在 Microsoft PowerPoint 中尋找、建立、複製及移動簡報，讀取及更新內容，並分享簡報的 Tool。每次 Tool 呼叫都會經過 Mastra 平台，由平台加入該連線的憑證；你的應用程式不會儲存 Microsoft PowerPoint 憑證。

## 連線 {/* #connect */}

開始前，請先完成 [Connect 設定](/docs/mastra-platform/connect#get-started)，安裝 `@mastra/connect` 並設定 Mastra 平台專案。

### 連結帳戶 {/* #connect-an-account */}

請在包含 `.env` 檔案的目錄中執行以下命令：

```bash
mastra connect add microsoft-powerpoint
```

CLI 會引導你完成 Microsoft PowerPoint 授權，並等待連線啟用。

### 將 Tool 新增至 Agent {/* #add-tools-to-an-agent */}

將 [`tools()`](/reference/connect/tools) 傳給 Agent，並選取 `microsoft-powerpoint` Provider：

```typescript title="src/mastra/agents/microsoft-powerpoint-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const microsoftPowerpointAgent = new Agent({
  id: 'microsoft-powerpoint-agent',
  name: 'Microsoft PowerPoint agent',
  instructions:
    'You help people find, create, copy, and move presentations, read and update their content, and share them in Microsoft PowerPoint.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['microsoft-powerpoint'] }),
})
```

Agent 可使用 18 個 Microsoft PowerPoint Tool，Tool key 包括 `microsoft_powerpoint_copy_presentation`。完整清單請參閱 [Microsoft PowerPoint Tool](/reference/connect/providers#microsoft-powerpoint)；如需限制可用 Tool，或要求每次呼叫在執行前取得核准，請參閱 [`tools()` 參數](/reference/connect/tools#parameters)。
