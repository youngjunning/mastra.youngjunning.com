# 微軟PowerPoint

為Agent商提供Tool來尋找、建立、複製和移動演示文稿，閱讀和更新其內容，並透過 Mastra Connect 在 Microsoft PowerPoint 中共用它們。每個Tool呼叫都會透過 Mastra 平台，該平台會新增連接的憑證。您的應用程式從不儲存 Microsoft PowerPoint 憑證。

## 連接 {/* #connect */}

在開始之前，請完成[Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect`並配置您的平台項目。

### 連接帳戶 {/* #connect-an-account */}

從包含您的目錄的目錄執行此命令`.env` file:

```bash
mastra connect add microsoft-powerpoint
```

CLI 將引導您完成 Microsoft PowerPoint 的授權並等待連線啟動。

### 向Agent添加Tool {/* #add-tools-to-an-agent */}

經過[`tools()`](/reference/connect/tools) to the agent and select the `microsoft-powerpoint` provider:

```typescript title="src/mastra/agents/microsoft-powerpoint-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const microsoftPowerpointAgent = new Agent({
  id: 'microsoft-powerpoint-agent',
  name: 'Microsoft PowerPoint agent',
  instructions:
    'You help people find, create, copy, and move presentations, read and update their content, and share them in Microsoft PowerPoint.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['microsoft-powerpoint'] }),
})
```

Agent程式可取得 18 個 Microsoft PowerPoint Tool，其中包含下列金鑰：`microsoft_powerpoint_copy_presentation`. See [Microsoft PowerPoint tools](/reference/connect/providers#microsoft-powerpoint) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
