# Microsoft Word

透過 Mastra Connect，為 Agent 提供可在 Microsoft Word 中尋找、建立、複製及移動 Word 文件，讀取及更新內容，並分享文件的 Tool。每次 Tool 呼叫都會經過 Mastra 平台，由平台加入該連線的憑證；你的應用程式不會儲存 Microsoft Word 憑證。

## 連線 {/* #connect */}

開始前，請先完成 [Connect 設定](/docs/mastra-platform/connect#get-started)，安裝 `@mastra/connect` 並設定 Mastra 平台專案。

### 連結帳戶 {/* #connect-an-account */}

請在包含 `.env` 檔案的目錄中執行以下命令：

```bash
mastra connect add microsoft-word
```

CLI 會引導你完成 Microsoft Word 授權，並等待連線啟用。

### 將 Tool 新增至 Agent {/* #add-tools-to-an-agent */}

將 [`tools()`](/reference/connect/tools) 傳給 Agent，並選取 `microsoft-word` Provider：

```typescript title="src/mastra/agents/microsoft-word-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const microsoftWordAgent = new Agent({
  id: 'microsoft-word-agent',
  name: 'Microsoft Word agent',
  instructions:
    'You help people find, create, copy, and move Word documents, read and update their content, and share them in Microsoft Word.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['microsoft-word'] }),
})
```

Agent 可使用 18 個 Microsoft Word Tool，Tool key 包括 `microsoft_word_copy_word_document`。完整清單請參閱 [Microsoft Word Tool](/reference/connect/providers#microsoft-word)；如需限制可用 Tool，或要求每次呼叫在執行前取得核准，請參閱 [`tools()` 參數](/reference/connect/tools#parameters)。
