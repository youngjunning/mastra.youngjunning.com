# 微軟Word

為Agent提供Tool來尋找、建立、複製和移動 Word 文檔，閱讀和更新其內容，並透過 Mastra Connect 在 Microsoft Word 中共用它們。每個Tool呼叫都會透過 Mastra 平台，該平台會新增連接的憑證。您的應用程式從不儲存 Microsoft Word 憑證。

## 連接 {/* #connect */}

在開始之前，請完成[Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect`並配置您的平台項目。

### 連接帳戶 {/* #connect-an-account */}

從包含您的目錄的目錄執行此命令`.env` file:

```bash
mastra connect add microsoft-word
```

CLI 將引導您完成 Microsoft Word 的授權並等待連線啟動。

### 向Agent添加Tool {/* #add-tools-to-an-agent */}

經過[`tools()`](/reference/connect/tools) to the agent and select the `microsoft-word` provider:

```typescript title="src/mastra/agents/microsoft-word-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const microsoftWordAgent = new Agent({
  id: 'microsoft-word-agent',
  name: 'Microsoft Word agent',
  instructions:
    'You help people find, create, copy, and move Word documents, read and update their content, and share them in Microsoft Word.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['microsoft-word'] }),
})
```

`microsoft_word_copy_word_document`. See [Microsoft Word tools](/reference/connect/providers#microsoft-word) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
