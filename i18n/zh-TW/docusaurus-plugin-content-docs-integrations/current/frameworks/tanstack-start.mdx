# TanStack Start

在 TanStack Start 中建立可呼叫 Tool 的 Mastra Agent，再將 Mastra 伺服器掛載到萬用 API 路由。[伺服器轉接器](/docs/server/server-adapters)概觀說明各轉接器的共通概念，[TanStack Start 轉接器](/reference/server/tanstack-start-adapter)參考文件則說明套件的 API。

## 開始之前 {/* #before-you-begin */}

- 你需要一組受支援的 [Model Provider](/models) API 金鑰。如果沒有偏好的 Provider，可以使用 [OpenAI](/models/providers/openai)。
- 安裝 Node.js `v22.13.0` 或更新版本

## 建立新的 TanStack Start 應用程式（選用） {/* #create-a-new-tanstack-start-app-optional */}

你需要一個正在執行且包含 `src/routes` 目錄的 TanStack Start 應用程式。如果還沒有，請依照 [TanStack Start 快速入門指南](https://tanstack.com/start/latest/docs/framework/react/getting-started)建立並啟動應用程式，再繼續操作。

## 初始化 Mastra {/* #initialize-mastra */}

在 TanStack Start 專案目錄中執行 [`mastra init`](/reference/cli/mastra#mastra-init)。出現提示時，請選擇 Provider（例如 OpenAI），並輸入 API 金鑰：

```bash npm2yarn
npx mastra@latest init
```

這個指令會建立 `src/mastra` 目錄，其中包含一個天氣 Agent 範例和下列檔案：

- `index.ts`：Mastra 設定，其中包含 Memory 設定
- `tools/weather-tool.ts`：用來取得指定地點天氣資訊的 Tool
- `agents/weather-agent.ts`：包含使用該 Tool 之指示的天氣 Agent

接下來會將 `src/mastra/index.ts` 匯出的 Mastra 執行個體傳給伺服器轉接器。

## 設定 Vite 和 Nitro {/* #configure-vite-and-nitro */}

更新 `vite.config.ts`，讓 Vite 和 Nitro 在各自的處理流程中排除 DuckDB 和 `@mastra/core` 僅適用於 Node.js 的相依套件：

```diff title="vite.config.ts"
 const config = defineConfig({
   resolve: { tsconfigPaths: true },
+  optimizeDeps: {
+    exclude: ['@mastra/duckdb', 'execa'],
+  },
   plugins: [
     devtools(),
-    nitro({ rollupConfig: { external: [/^@sentry\//] } }),
+    nitro({
+      rollupConfig: {
+        external: [/^@sentry\//, /^@duckdb\//],
+      },
+    }),
```

`optimizeDeps.exclude` 設定可防止 Vite 的開發環境最佳化工具將 DuckDB 的原生 `.node` 二進位檔當成 JavaScript 開啟。排除 `execa` 可避免最佳化工具預先打包這個僅供伺服器使用的相依套件，`@mastra/core` 會用它執行本機程序。它間接依賴的 `npm-run-path` 和 `unicorn-magic` 套件使用 Node.js 專用的條件式匯出，最佳化工具在瀏覽器版本的建置過程中無法解析這些匯出。將 `/^@duckdb\//` 加入 Nitro 的 `rollupConfig.external`，可將 DuckDB 的 Node.js 原生套件排除在正式環境的打包產物之外，讓 Node.js 在執行時載入這些套件。

這些變更只涉及 `vite.config.ts`，無須修改應用程式或 Mastra 的原始碼檔案。

## 新增伺服器轉接器 {/* #add-the-server-adapter */}

安裝 TanStack Start 伺服器轉接器，以及它所需的同儕相依套件 Hono：

```bash npm2yarn
npm install @mastra/tanstack-start@latest hono
```

建立 splat 路由，將所有支援的 HTTP 方法轉交給轉接器：

```typescript title="src/routes/api/$.ts"
import { createStartRouteHandler } from '@mastra/tanstack-start'
import { createFileRoute } from '@tanstack/react-router'
import { mastra } from '../../mastra'

export const Route = createFileRoute('/api/$')({
  server: {
    handlers: createStartRouteHandler({ mastra }),
  },
})
```

`prefix` 選項預設為 `/api`，且必須與 splat 路由的掛載路徑一致。例如，將轉接器掛載在 `src/routes/api/mastra/$.ts` 時，請使用 `createStartRouteHandler({ mastra, prefix: '/api/mastra' })`。

轉接器會公開 Mastra 的 REST 和串流端點、自訂 API 路由、MCP 端點及 A2A 端點。A2A 任務會儲存在記憶體中。

## 測試 Agent {/* #test-your-agent */}

啟動 TanStack Start 應用程式：

```bash npm2yarn
npm run dev
```

在另一個終端機視窗中，使用 `curl` 向天氣 Agent 查詢：

```bash
curl -X POST http://localhost:3000/api/agents/weather-agent/generate -H "Content-Type: application/json" -d "{\"messages\":[{\"role\":\"user\",\"content\":\"What is the weather like in Seoul?\"}]}"
```

端點會傳回 Agent 的完整 JSON 回應。
