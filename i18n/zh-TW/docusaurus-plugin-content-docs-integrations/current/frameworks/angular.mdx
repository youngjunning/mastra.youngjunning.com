# Angular

先用 Mastra 建立可呼叫 Tool 的 AI Agent，再讓 Angular 透過 Mastra 的獨立伺服器呼叫這個 Agent。

你會使用 [AI SDK UI](https://ai-sdk.dev/docs/ai-sdk-ui/overview) 和它的 [Angular 繫結](https://ai-sdk.dev/docs/getting-started/angular)，讓聊天介面以串流方式接收回應。

## 開始之前 {/* #before-you-begin */}

* 你需要向支援的[模型 Provider](/models/) 取得 API 金鑰。如果沒有偏好，可以使用 [OpenAI](/models/providers/openai)。
* 安裝 Angular 22 支援的 Node.js 版本。使用 22.x 系列時，版本須為 `v22.22.3` 以上。24.x 系列須為 `v24.15.0` 以上，26.x 系列須為 `v26.0.0` 以上。

## 建立 Angular 應用程式（選用） {/* #create-a-new-angular-app-optional */}

如果你已經有 Angular 應用程式，請直接前往下一步。

執行下列指令以[建立 Angular 應用程式](https://angular.dev/cli/new)：

```bash npm2yarn
npm create @angular@latest mastra-angular -- --defaults --ssr=false
```

這個指令會建立名為 `mastra-angular` 的專案，採用用戶端算繪。你可以自行替換專案名稱。

切換至專案目錄：

```bash
cd mastra-angular
```

## 初始化 Mastra {/* #initialize-mastra */}

執行 [`mastra init`](/reference/cli/mastra#mastra-init)，依提示選擇 Provider（例如 OpenAI），再輸入 API 金鑰：

```bash npm2yarn
npx mastra@latest init
```

指令會建立 `src/mastra` 資料夾，內含天氣 Agent 範例和下列檔案：

* `index.ts`：Mastra 設定，包含記憶功能的設定
* `tools/weather-tool.ts`：取得指定地點天氣資訊的 Tool
* `agents/weather-agent.ts`：天氣 Agent，其提示詞會指示它使用這個 Tool

接下來，你會從聊天介面呼叫 `weather-agent.ts` 裡定義的 Agent。

## 將 Mastra 排除在 Angular 建置之外 {/* #exclude-mastra-from-the-angular-build */}

Angular 預設的 `tsconfig.app.json` 會編譯 `src/` 下的所有檔案，包括 `src/mastra` 中的伺服器端程式碼。預設的 `tsconfig.json` 也會啟用 `noPropertyAccessFromIndexSignature`，因此 `src/mastra/index.ts` 中自動產生的 `process.env` 存取程式碼會導致建置失敗。

在 `tsconfig.app.json` 的 `exclude` 清單中加入 `src/mastra/**`，即可將伺服器端程式碼排除在瀏覽器端的建置之外：

```json title="tsconfig.app.json" {7}
{
  "extends": "./tsconfig.json",
  "compilerOptions": {
    "types": []
  },
  "include": ["src/**/*.ts"],
  "exclude": ["src/**/*.spec.ts", "src/mastra/**"]
}
```

## 安裝 AI SDK UI {/* #install-ai-sdk-ui */}

一併安裝 AI SDK UI、Mastra 轉接器和 Angular 繫結：

```bash npm2yarn
npm install @mastra/ai-sdk@latest @ai-sdk/angular ai
```

## 建立聊天路由 {/* #create-a-chat-route */}

開啟 `src/mastra/index.ts`，在設定中加入 [chatRoute()](/reference/ai-sdk/chat-route)。這會建立一條 API 路由，讓 Angular 前端取得與 AI SDK 相容的聊天回應。下一步會用 `Chat` 類別呼叫這條路由。

```ts title="src/mastra/index.ts"
import { Mastra } from '@mastra/core/mastra'
// Existing imports...
import { chatRoute } from '@mastra/ai-sdk'

export const mastra = new Mastra({
  // Existing config...
  server: {
    apiRoutes: [
      chatRoute({
        path: '/chat/:agentId',
        version: 'v7',
      }),
    ],
  },
})
```

## 新增聊天介面 {/* #add-the-chat-ui */}

將 `src/app/app.ts` 的內容替換成下列元件：

```ts title="src/app/app.ts"
import { JsonPipe } from '@angular/common'
import { Component, signal } from '@angular/core'
import { Chat } from '@ai-sdk/angular'
import { DefaultChatTransport } from 'ai'

@Component({
  selector: 'app-root',
  imports: [JsonPipe],
  template: `
    <main class="chat">
      @for (message of chat.messages; track message.id) {
        <article class="message" [class.user]="message.role === 'user'">
          <strong>{{ message.role === 'user' ? 'You' : 'Assistant' }}</strong>
          @for (part of message.parts; track $index) {
            @if (part.type === 'text') {
              <p class="text">{{ part.text }}</p>
            } @else if (part.type.startsWith('tool-')) {
              <details class="tool">
                <summary>{{ part.type.replace('tool-', '') }}</summary>
                <pre>{{ part | json }}</pre>
              </details>
            }
          }
        </article>
      }

      @if (chat.status === 'submitted') {
        <p class="status">Waiting for a response...</p>
      }

      @if (chat.error; as error) {
        <p class="error" role="alert">{{ error.message }}</p>
      }

      <form (submit)="sendMessage($event)">
        <label for="message">Your message</label>
        <textarea
          id="message"
          #messageInput
          rows="2"
          [value]="input()"
          (input)="input.set(messageInput.value)"
          placeholder="Ask about the weather..."
        ></textarea>
        <button
          type="submit"
          [disabled]="chat.status === 'submitted' || chat.status === 'streaming'"
        >
          Send
        </button>
        @if (chat.status === 'submitted' || chat.status === 'streaming') {
          <button type="button" (click)="chat.stop()">Stop</button>
        }
      </form>
    </main>
  `,
  styles: `
    .chat {
      display: flex;
      flex-direction: column;
      gap: 1rem;
      max-width: 48rem;
      margin: 0 auto;
      padding: 1.5rem;
    }

    .message {
      display: flex;
      flex-direction: column;
      gap: 0.5rem;
      padding: 0.75rem 1rem;
      border: 1px solid #d4d4d8;
      border-radius: 0.5rem;
    }

    .message.user {
      background: #f4f4f5;
    }

    .text {
      margin: 0;
      white-space: pre-wrap;
    }

    .tool pre {
      overflow-x: auto;
      margin: 0.5rem 0 0;
    }

    .error {
      color: #b91c1c;
    }

    form {
      display: flex;
      flex-direction: column;
      gap: 0.5rem;
    }

    button {
      align-self: flex-start;
      padding: 0.5rem 1rem;
    }
  `,
})
export class App {
  readonly chat = new Chat({
    transport: new DefaultChatTransport({
      api: 'http://localhost:4111/chat/weather-agent',
    }),
  })

  readonly input = signal('')

  sendMessage(event: Event) {
    event.preventDefault()

    const text = this.input().trim()
    if (!text || this.chat.status === 'submitted' || this.chat.status === 'streaming') {
      return
    }

    this.chat.sendMessage({ text })
    this.input.set('')
  }
}
```

這個元件會建立 [`Chat`](https://ai-sdk.dev/docs/getting-started/angular) 執行個體，並將傳輸目標設為 `chat/weather-agent` 端點。`Chat` 類別會將提示詞送往該端點，並以串流方式把回應寫入 `chat.messages`。

元件會在收到文字片段時立即顯示，並將 Tool 呼叫呈現在可收合的 `<details>` 元素中。狀態與錯誤訊息分別取自反應式屬性 `chat.status` 和 `chat.error`。按下 **Stop**（停止）即可取消目前的回應。

:::note
較早建立的 Angular 專案可能將根元件檔案命名為 `app.component.ts`，類別命名為 `AppComponent`。若你使用既有專案，請沿用原本的檔名和類別名稱，讓 `src/main.ts` 中的匯入繼續正常運作。
:::

## 測試 Agent {/* #test-your-agent */}

若要透過聊天介面測試 Agent，請同時執行 Mastra 伺服器與 Angular 開發伺服器。

1. 啟動 Mastra 開發伺服器：

   ```bash npm2yarn
   npx mastra dev
   ```
2. 在另一個終端機視窗啟動 Angular 開發伺服器：

   ```bash npm2yarn
   npm start
   ```
3. 前往 [http://localhost:4200](http://localhost:4200) 開啟應用程式。
4. 試著詢問天氣。如果 API 金鑰設定正確，你就會收到回應。
