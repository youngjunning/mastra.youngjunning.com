# 霍諾

在本指南中，您將使用 Mastra 和 Hono 建立一個Tool來呼叫 AI Agent。使用[Hono server adapter](/reference/server/hono-adapter)，您可以將Agent程式公開為 HTTP 端點，而無需自行編寫路由或執行單獨的 Mastra 伺服器。

## 開始之前 {/* #before-you-begin */}

* 您需要來自受支援的 API 金鑰[model provider](/models). If you don't have a preference, use [OpenAI](/models/providers/openai).
* 安裝 Node.js`v22.13.0` or later

## 建立一個新的 Hono 應用程式（可選） {/* #create-a-new-hono-app-optional */}

如果您已有 Hono 應用程序，請跳至下一步。

運行以下命令[create a new Hono app](https://hono.dev/docs/getting-started/basic):

```bash npm2yarn
npm create hono@latest mastra-hono -- --template nodejs --install --pm npm
```

這將建立一個名為`mastra-hono`, but you can replace it with any name you want.

## 初始化瑪斯特拉 {/* #initialize-mastra */}

導航到您的 Hono 專案目錄：

```bash
cd mastra-hono
```

跑步[`mastra init`](/reference/cli/mastra#mastra-init). When prompted, choose a provider (e.g. OpenAI) and enter your key:

```bash npm2yarn
npx mastra@latest init
```

這創建了一個`src/mastra` folder with an example weather agent and the following files:

* `index.ts`：Mastra 配置，包括內存
* `tools/weather-tool.ts`：取得給定位置天氣的Tool
* `agents/weather-agent.ts`：帶有使用該Tool提示的天氣Agent

`src/mastra/index.ts` file to the Hono server adapter later.

## 新增伺服器適配器 {/* #add-server-adapter */}

安裝Hono伺服器適配器包：

```bash npm2yarn
npm install @mastra/hono@latest
```

開啟 Hono 條目文件`src/index.ts` and add the required import and initialization code:

```typescript title="src/index.ts" {3-8,10-11,13}
import { serve } from '@hono/node-server'
import { Hono } from 'hono'
import { type HonoBindings, type HonoVariables, MastraServer } from '@mastra/hono'
import { mastra } from './mastra/index.js'

const app = new Hono<{ Bindings: HonoBindings; Variables: HonoVariables }>()
const server = new MastraServer({ app, mastra })

await server.init()

app.get('/', c => {
  return c.text('Hello Hono!')
})

serve(
  {
    fetch: app.fetch,
    port: 3000,
  },
  info => {
    console.log(`Server is running on http://localhost:${info.port}`)
  },
)
```

⁠`MastraServer` is initialized with the existing Hono `app` and the root ⁠`mastra` instance. Calling `⁠init()` registers the Mastra middleware and exposes all available Mastra endpoints.

## 測試你的Agent {/* #test-your-agent */}

預設情況下，Mastra 的端點會新增在`/api` subpath and use your agent/workflow IDs. The default `weather-agent` created by `mastra init` is available at `/api/agents/weather-agent`.

啟動你的Hono伺服器：

```bash npm2yarn
npm run dev
```

在單獨的終端機視窗中，使用`curl` to ask the weather agent:

```bash
curl -X POST http://localhost:3000/api/agents/weather-agent/generate -H "Content-Type: application/json" -d "{\"messages\":[{\"role\":\"user\",\"content\":\"What is the weather like in Seoul?\"}]}"
```
