# Hono

本指南將帶您使用 Mastra 和 Hono 建立可呼叫 Tool 的 AI Agent。透過 [Hono 伺服器轉接器](/reference/server/hono-adapter)，您可以將 Agent 公開為 HTTP 端點，無須自行撰寫路由或另外執行 Mastra 伺服器。

## 開始之前 {/* #before-you-begin */}

- 您需要向受支援的 [Model Provider](/models) 取得 API 金鑰。若沒有特別偏好，可以使用 [OpenAI](/models/providers/openai)。
- 安裝 Node.js `v22.13.0` 或更新版本

## 建立新的 Hono 應用程式（選用） {/* #create-a-new-hono-app-optional */}

如果您已有 Hono 應用程式，請跳到下一步。

執行以下指令以[建立新的 Hono 應用程式](https://hono.dev/docs/getting-started/basic)：

```bash npm2yarn
npm create hono@latest mastra-hono -- --template nodejs --install --pm npm
```

這個指令會建立名為 `mastra-hono` 的專案，您也可以改用自己選擇的名稱。

## 初始化 Mastra {/* #initialize-mastra */}

切換至您的 Hono 專案目錄：

```bash
cd mastra-hono
```

執行 [`mastra init`](/reference/cli/mastra#mastra-init)。出現提示時，選擇 Provider（例如 OpenAI），並輸入您的金鑰：

```bash npm2yarn
npx mastra@latest init
```

這個指令會建立 `src/mastra` 資料夾，其中包含天氣查詢用的範例 Agent 和下列檔案：

- `index.ts`：Mastra 設定，包含 Memory 設定
- `tools/weather-tool.ts`：取得指定地點天氣資訊的 Tool
- `agents/weather-agent.ts`：天氣查詢 Agent，其 Prompt 會指示 Agent 使用該 Tool

稍後會將 `src/mastra/index.ts` 檔案傳給 Hono 伺服器轉接器。

## 新增伺服器轉接器 {/* #add-server-adapter */}

安裝 Hono 伺服器轉接器套件：

```bash npm2yarn
npm install @mastra/hono@latest
```

開啟 Hono 的進入點檔案 `src/index.ts`，並加入所需的匯入與初始化程式碼：

```typescript title="src/index.ts" {3-8,10-11,13}
import { serve } from '@hono/node-server'
import { Hono } from 'hono'
import { type HonoBindings, type HonoVariables, MastraServer } from '@mastra/hono'
import { mastra } from './mastra/index.js'

const app = new Hono<{ Bindings: HonoBindings; Variables: HonoVariables }>()
const server = new MastraServer({ app, mastra })

await server.init()

app.get('/', c => {
  return c.text('Hello Hono!')
})

serve(
  {
    fetch: app.fetch,
    port: 3000,
  },
  info => {
    console.log(`Server is running on http://localhost:${info.port}`)
  },
)
```

使用現有的 Hono `app` 和根層級的 ⁠`mastra` 執行個體來初始化 ⁠`MastraServer`。呼叫 `⁠init()` 會註冊 Mastra 中介軟體，並公開所有可用的 Mastra 端點。

## 測試您的 Agent {/* #test-your-agent */}

依預設，Mastra 會在 `/api` 子路徑下新增端點，並使用您的 Agent 或 Workflow ID。`mastra init` 建立的預設 `weather-agent` 可透過 `/api/agents/weather-agent` 存取。

啟動您的 Hono 伺服器：

```bash npm2yarn
npm run dev
```

在另一個終端機視窗中，使用 `curl` 向天氣查詢 Agent 提問：

```bash
curl -X POST http://localhost:3000/api/agents/weather-agent/generate -H "Content-Type: application/json" -d "{\"messages\":[{\"role\":\"user\",\"content\":\"What is the weather like in Seoul?\"}]}"
```
