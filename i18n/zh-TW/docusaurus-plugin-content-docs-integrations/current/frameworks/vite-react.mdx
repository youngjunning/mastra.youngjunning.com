# React + Vite

這篇指南帶你用 Mastra 建立可呼叫 Tool 的 AI Agent，再從 React 前端透過 Mastra 的獨立伺服器直接呼叫它。

你會搭配 [AI SDK UI](https://ai-sdk.dev/docs/ai-sdk-ui/overview) 與 [AI Elements](https://ai-sdk.dev/elements)，做出美觀的互動式聊天介面。

## 開始之前 {/* #before-you-begin */}

* 準備一組由支援的[模型 Provider](/models) 核發的 API 金鑰。如果還沒決定要用哪一家，可以選 [OpenAI](/models/providers/openai)。
* 安裝 Node.js `v22.13.0` 或更新版本。

## 建立 React + Vite 應用程式（選用） {/* #create-a-new-react--vite-app-optional */}

如果手上已有採用 Tailwind 的 React + Vite 應用程式，可直接跳到下一個步驟。

### 建立專案骨架 {/* #project-scaffold */}

執行下列指令[建立 React + Vite 應用程式](https://vite.dev/guide/#scaffolding-your-first-vite-project)。

```bash npm2yarn
npm create vite@latest mastra-react -- --template react-ts
```

指令會建立名為 `mastra-react` 的專案，你也可自行命名。

切換到專案目錄。

```bash
cd mastra-react
```

### Tailwind {/* #tailwind */}

接著安裝 Tailwind。

```bash npm2yarn
npm install tailwindcss @tailwindcss/vite
```

設定 Vite 外掛。

```typescript title="vite.config.ts" {3-4,7-12}
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import path from 'path'
import tailwindcss from '@tailwindcss/vite'

export default defineConfig({
  plugins: [react(), tailwindcss()],
  resolve: {
    alias: {
      '@': path.resolve(__dirname, './src'),
    },
  },
})
```

將 `src/index.css` 的內容全部換成下列程式碼。

```css title="src/index.css"
@import 'tailwindcss';
```

在 `tsconfig.json` 中加入下列 `compilerOptions` 設定。

```jsonc title="tsconfig.json"
{
  // ...
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"],
    },
  },
}
```

修改 `tsconfig.app.json`，讓應用程式能解析路徑別名。

```jsonc title="tsconfig.app.json"
{
  "compilerOptions": {
    // ...
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"],
    },
    // ...
  },
}
```

## 初始化 Mastra {/* #initialize-mastra */}

執行 [`mastra init`](/reference/cli/mastra#mastra-init)。依畫面提示選擇 Provider，例如 OpenAI，再輸入 API 金鑰。

```bash npm2yarn
npx mastra@latest init
```

指令會建立 `src/mastra` 資料夾，放入查詢天氣的 Agent 範例與下列檔案。

* `index.ts` 包含 Mastra 設定，其中也包括記憶設定。
* `tools/weather-tool.ts` 定義可取得指定地點天氣資訊的 Tool。
* `agents/weather-agent.ts` 定義天氣 Agent，並用提示詞指示它使用該 Tool。

稍後，你會從聊天介面呼叫在 `weather-agent.ts` 定義的 Agent。

## 安裝 AI SDK UI 與 AI Elements {/* #install-ai-sdk-ui--ai-elements */}

一併安裝 AI SDK UI 與 Mastra 轉接器。

```bash npm2yarn
npm install @mastra/ai-sdk@latest @ai-sdk/react ai
```

接著初始化 AI Elements。若畫面要求選取元件庫，請選 **Radix UI**，其餘提示沿用預設值。

```bash npm2yarn
npx ai-elements@latest
```

:::note
`ai-elements` 指令會執行 `shadcn add`，從 AI Elements 的登錄庫安裝元件。該登錄庫目前只發布 Radix UI 元件。將這些元件裝進 Base UI 專案會發生 TypeScript 錯誤，可到 [vercel/ai-elements#383](https://github.com/vercel/ai-elements/issues/383) 查看追蹤紀錄。

只有專案裡沒有 `components.json` 時，才會出現元件庫選單。若已有這個檔案，請先確認 `style` 採用 Radix 的選項，例如 `new-york` 或 `radix-*` 樣式，且未使用 `base-*` 樣式，再執行指令。
:::

指令會把整套 AI Elements UI 元件庫下載到 `@/components/ai-elements` 資料夾。

## 建立聊天路由 {/* #create-a-chat-route */}

開啟 `src/mastra/index.ts`，在設定中加入 [chatRoute()](/reference/ai-sdk/chat-route)。React 前端可呼叫這條 API 路由，取得與 AI SDK 相容的聊天回應。接下來會用 useChat() 呼叫它。

```ts title="src/mastra/index.ts"
import { Mastra } from '@mastra/core/mastra'
// Existing imports...
import { chatRoute } from '@mastra/ai-sdk'

export const mastra = new Mastra({
  // Existing config...
  server: {
    apiRoutes: [
      chatRoute({
        path: '/chat/:agentId',
      }),
    ],
  },
})
```

## 新增聊天介面 {/* #add-the-chat-ui */}

把 `src/App.tsx` 換成下列程式碼，建立聊天介面。

```tsx title="src/App.tsx"
import * as React from 'react'
import { DefaultChatTransport, type ToolUIPart } from 'ai'
import { useChat } from '@ai-sdk/react'

import {
  PromptInput,
  PromptInputBody,
  PromptInputTextarea,
} from '@/components/ai-elements/prompt-input'

import {
  Conversation,
  ConversationContent,
  ConversationScrollButton,
} from '@/components/ai-elements/conversation'

import { Message, MessageContent, MessageResponse } from '@/components/ai-elements/message'

import { Tool, ToolHeader, ToolContent, ToolInput, ToolOutput } from '@/components/ai-elements/tool'

export default function App() {
  const [input, setInput] = React.useState<string>('')

  const { messages, sendMessage, status } = useChat({
    transport: new DefaultChatTransport({
      api: 'http://localhost:4111/chat/weather-agent',
    }),
  })

  const handleSubmit = async () => {
    if (!input.trim()) return

    sendMessage({ text: input })
    setInput('')
  }

  return (
    <div className="relative mx-auto size-full h-screen max-w-4xl p-6">
      <div className="flex h-full flex-col">
        <Conversation className="h-full">
          <ConversationContent>
            {messages.map(message => (
              <div key={message.id}>
                {message.parts?.map((part, i) => {
                  if (part.type === 'text') {
                    return (
                      <Message key={`${message.id}-${i}`} from={message.role}>
                        <MessageContent>
                          <MessageResponse>{part.text}</MessageResponse>
                        </MessageContent>
                      </Message>
                    )
                  }

                  if (part.type?.startsWith('tool-')) {
                    return (
                      <Tool key={`${message.id}-${i}`}>
                        <ToolHeader
                          type={(part as ToolUIPart).type}
                          state={(part as ToolUIPart).state || 'output-available'}
                          className="cursor-pointer"
                        />
                        <ToolContent>
                          <ToolInput input={(part as ToolUIPart).input || {}} />
                          <ToolOutput
                            output={(part as ToolUIPart).output}
                            errorText={(part as ToolUIPart).errorText}
                          />
                        </ToolContent>
                      </Tool>
                    )
                  }

                  return null
                })}
              </div>
            ))}
            <ConversationScrollButton />
          </ConversationContent>
        </Conversation>
        <PromptInput onSubmit={handleSubmit} className="mt-20">
          <PromptInputBody>
            <PromptInputTextarea
              onChange={e => setInput(e.target.value)}
              className="md:leading-10"
              value={input}
              placeholder="Ask about the weather..."
              disabled={status !== 'ready'}
            />
          </PromptInputBody>
        </PromptInput>
      </div>
    </div>
  )
}
```

這個元件透過 [`useChat()`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/use-chat) 將提示詞送到 `chat/weather-agent` 端點，再以串流方式分段接收回應。

回應文字由 [`<MessageResponse>`](https://ai-sdk.dev/elements/components/message#messageresponse-) 元件呈現。如果 Agent 呼叫了 Tool，畫面會以 [`<Tool>`](https://ai-sdk.dev/elements/components/tool) 元件顯示這些呼叫。

## 測試 Agent {/* #test-your-agent */}

要從聊天介面測試 Agent，請同時執行 Mastra 伺服器與 Vite 開發伺服器。

1. 啟動 Mastra 開發伺服器。

   ```bash npm2yarn
   npx mastra dev
   ```
2. 另開一個終端機視窗，啟動 Vite 開發伺服器。

   ```bash npm2yarn
   npm run dev
   ```
3. 前往 [http://localhost:5173](http://localhost:5173) 開啟應用程式。
4. 試著問問天氣。API 金鑰若已正確設定，就會收到回應。
