# 表達

在本指南中，您將使用 Mastra 和 Express 建立一個Tool來呼叫 AI Agent程式。使用[Express server adapter](/reference/server/express-adapter)，您可以將Agent程式公開為 HTTP 端點，而無需自行編寫路由或執行單獨的 Mastra 伺服器。

## 開始之前 {/* #before-you-begin */}

* 您需要來自受支援的 API 金鑰[model provider](/models). If you don't have a preference, use [OpenAI](/models/providers/openai).
* 安裝 Node.js`v22.13.0` or later

## 建立一個新的 Express 應用程式（可選） {/* #create-a-new-express-app-optional */}

## 初始化瑪斯特拉 {/* #initialize-mastra */}

在 Express 專案目錄中，執行[`mastra init`](/reference/cli/mastra#mastra-init).

出現提示時，選擇Provider（例如 OpenAI）並輸入您的金鑰：

```bash
npx mastra@latest init
```

這創建了一個`src/mastra` folder with an example weather agent and the following files:

* `index.ts`：Mastra 配置，包括內存
* `tools/weather-tool.ts`：取得給定位置天氣的Tool
* `agents/weather-agent.ts`：帶有使用該Tool提示的天氣Agent

`src/mastra/index.ts` file to the Express server adapter later.

## 新增伺服器適配器 {/* #add-server-adapter */}

安裝 Express 伺服器適配器套件：

```bash npm2yarn
npm install @mastra/express@latest
```

開啟 Express 條目文件`src/index.ts` and add the required import and initialization code:

```typescript {2-3,11-12} title="src/index.ts"
import express, { type Request, type Response } from 'express'
import { MastraServer } from '@mastra/express'
import { mastra } from './mastra'

const app = express()
const PORT = process.env.PORT || 3000

// Middleware
app.use(express.json())

const server = new MastraServer({ app, mastra })
await server.init()

// Routes
app.get('/', (_req: Request, res: Response) => {
  res.json({ message: 'Hello, World!' })
})

// Start server
app.listen(PORT, () => {
  console.log(`Server is running on http://localhost:${PORT}`)
})
```

⁠`MastraServer` is initialized with the existing Express `app` and the root ⁠`mastra` instance. Calling `⁠init()` registers the Mastra middleware and exposes all available Mastra endpoints.

## 測試你的Agent {/* #test-your-agent */}

預設情況下，Mastra 的端點會新增在`/api` subpath and use your agent/workflow IDs. The default `weather-agent` created by `mastra init` is available at `/api/agents/weather-agent`.

啟動你的 Express 伺服器：

```bash
npm run start
```

在單獨的終端機視窗中，使用`curl` to ask the weather agent:

```bash
curl -X POST http://localhost:3000/api/agents/weather-agent/generate -H "Content-Type: application/json" -d "{\"messages\":[{\"role\":\"user\",\"content\":\"What is the weather like in Seoul?\"}]}"
```
