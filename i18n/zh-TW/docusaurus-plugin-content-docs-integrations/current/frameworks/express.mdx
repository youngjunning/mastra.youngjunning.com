# Express

本指南會帶你使用 Mastra 和 Express 建立可呼叫 Tool 的 AI Agent。透過 [Express 伺服器轉接器](/reference/server/express-adapter)，你可以將 Agent 公開為 HTTP 端點，無須自行撰寫路由或另外執行 Mastra 伺服器。

## 開始之前 {/* #before-you-begin */}

- 你需要向受支援的 [Model Provider](/models) 取得 API 金鑰。如果沒有偏好的 Provider，可以使用 [OpenAI](/models/providers/openai)。
- 安裝 Node.js `v22.13.0` 或更新版本

## 建立新的 Express 應用程式（選用） {/* #create-a-new-express-app-optional */}

如果你已有 Express 應用程式，請跳到下一步。

複製這個[範本儲存庫](https://github.com/mastra-ai/express-ts-boilerplate)，並安裝相依套件：

## 初始化 Mastra {/* #initialize-mastra */}

在 Express 專案目錄中執行 [`mastra init`](/reference/cli/mastra#mastra-init)。

出現提示時，選擇一個 Provider（例如 OpenAI），並輸入你的金鑰：

```bash
npx mastra@latest init
```

這會建立 `src/mastra` 資料夾，其中包含一個天氣查詢 Agent 範例和下列檔案：

- `index.ts`：Mastra 設定，其中包含 Memory 設定
- `tools/weather-tool.ts`：用來查詢指定地點天氣的 Tool
- `agents/weather-agent.ts`：天氣查詢 Agent，其 Prompt 會指示它使用該 Tool

稍後會將 `src/mastra/index.ts` 檔案傳給 Express 伺服器轉接器。

## 新增伺服器轉接器 {/* #add-server-adapter */}

安裝 Express 伺服器轉接器套件：

```bash npm2yarn
npm install @mastra/express@latest
```

開啟 Express 的進入點檔案 `src/index.ts`，加入必要的匯入和初始化程式碼：

```typescript {2-3,11-12} title="src/index.ts"
import express, { type Request, type Response } from 'express'
import { MastraServer } from '@mastra/express'
import { mastra } from './mastra'

const app = express()
const PORT = process.env.PORT || 3000

// Middleware
app.use(express.json())

const server = new MastraServer({ app, mastra })
await server.init()

// Routes
app.get('/', (_req: Request, res: Response) => {
  res.json({ message: 'Hello, World!' })
})

// Start server
app.listen(PORT, () => {
  console.log(`Server is running on http://localhost:${PORT}`)
})
```

⁠`MastraServer` 會使用現有的 Express `app` 和根層級的 ⁠`mastra` 執行個體進行初始化。呼叫 `⁠init()` 會註冊 Mastra 中介軟體，並公開所有可用的 Mastra 端點。

## 測試 Agent {/* #test-your-agent */}

Mastra 預設會將端點加在 `/api` 子路徑下，並使用你的 Agent 或 Workflow ID。你可以透過 `/api/agents/weather-agent` 存取 `mastra init` 建立的預設 `weather-agent`。

啟動 Express 伺服器：

```bash
npm run start
```

另開一個終端機視窗，使用 `curl` 向天氣查詢 Agent 提問：

```bash
curl -X POST http://localhost:3000/api/agents/weather-agent/generate -H "Content-Type: application/json" -d "{\"messages\":[{\"role\":\"user\",\"content\":\"What is the weather like in Seoul?\"}]}"
```
