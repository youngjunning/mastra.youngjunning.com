# Next.js

## 建立串流聊天介面 {/* #build-a-streaming-chat-interface */}

本指南會帶你用 Mastra 建立能呼叫 Tool 的 AI Agent，並在 Next.js 路由中直接匯入及呼叫這個 Agent。

你會使用 [AI SDK UI](https://ai-sdk.dev/docs/ai-sdk-ui/overview) 和 [AI Elements](https://ai-sdk.dev/elements) 打造美觀、可互動的聊天介面。

### 開始之前 {/* #before-you-begin */}

* 準備一組受支援的[模型 Provider](/models) 所提供的 API 金鑰。如果沒有特別偏好的 Provider，可以使用 [OpenAI](/models/providers/openai)。
* 安裝 Node.js `v22.13.0` 或更新版本。

### 建立 Next.js 應用程式（選用） {/* #create-a-new-nextjs-app-optional */}

如果你已有 Next.js 應用程式，可以直接進行下一步。

執行下列指令來[建立 Next.js 應用程式](https://nextjs.org/docs/app/getting-started/installation)：

```bash npm2yarn
npx create-next-app@latest my-nextjs-agent --yes --ts --eslint --tailwind --src-dir --app --turbopack --no-react-compiler --no-import-alias
```

這個指令會建立名為 `my-nextjs-agent` 的專案。你可以自行替換專案名稱。

### 初始化 Mastra {/* #initialize-mastra */}

切換到 Next.js 專案目錄：

```bash
cd my-nextjs-agent
```

執行 [`mastra init`](/reference/cli/mastra#mastra-init)，依提示選擇 Provider（例如 OpenAI）並輸入 API 金鑰：

```bash npm2yarn
npx mastra@latest init
```

初始化後會產生 `src/mastra` 資料夾，內含範例天氣查詢 Agent 和下列檔案：

* `index.ts`：Mastra 設定，包含記憶功能的設定。
* `tools/weather-tool.ts`：用來取得指定地點天氣資訊的 Tool。
* `agents/weather-agent.ts`：天氣查詢 Agent，其提示詞會引導它使用這個 Tool。

接下來會在 Next.js 路由中呼叫 `weather-agent.ts` 裡定義的 Agent。

:::tip[搭配 Next.js 使用 Studio]
如果要同時執行 [Studio](/docs/studio/overview) 和 Next.js 應用程式，並讓兩者共用同一個資料庫，請把 `src/mastra/index.ts` 中儲存 URL 的路徑改為絕對路徑：

```typescript
url: 'file:/absolute/path/to/your/project/mastra.db'
```

相對路徑會依各處理程序的工作目錄解析，而 `next dev` 和 `mastra dev` 的工作目錄不同。
:::

### 設定 Next.js {/* #configure-nextjs */}

Mastra 套件會載入 Node.js 原生模組，例如用來儲存可觀測性資料的 DuckDB 繫結。Next.js 的打包工具無法打包這些模組。請在 `next.config.ts` 加入 `serverExternalPackages`，讓 Next.js 在執行時從 `node_modules` 載入 Mastra 套件：

```ts title="next.config.ts"
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  serverExternalPackages: ['@mastra/*'],
}

export default nextConfig
```

如果 `next.config.ts` 已有其他設定，請將 `serverExternalPackages` 加在同一層。

### 安裝 AI SDK UI 和 AI Elements {/* #install-ai-sdk-ui--ai-elements */}

安裝 AI SDK UI 和 Mastra 轉接器：

```bash npm2yarn
npm install @mastra/ai-sdk@latest @ai-sdk/react ai
```

接著加入聊天頁面會用到的 AI Elements 元件。如果出現選擇元件庫的提示，請選 **Radix UI**，其餘提示沿用預設值：

```bash npm2yarn
npx ai-elements@latest add prompt-input conversation message tool
```

:::note
`ai-elements` 指令會透過 `shadcn add` 從 AI Elements 的元件登錄庫取得元件。目前該登錄庫只發布 Radix UI 元件；如果將這些元件裝到 Base UI 專案，會出現 TypeScript 錯誤。問題追蹤請見 [vercel/ai-elements#383](https://github.com/vercel/ai-elements/issues/383)。

專案沒有 `components.json` 時，才會出現選擇元件庫的提示。如果已有這個檔案，請先確認 `style` 設為 `new-york` 或 `radix-*` 等 Radix 樣式，而非 `base-*` 樣式，再執行指令。
:::

這個指令會將元件及其相依項目下載到 `@/components/ai-elements` 資料夾。

### 建立聊天路由 {/* #create-a-chat-route */}

建立 `src/app/api/chat/route.ts`：

```ts title="src/app/api/chat/route.ts"
import { handleChatStream } from '@mastra/ai-sdk'
import { toAISdkMessages } from '@mastra/ai-sdk/ui'
import { createUIMessageStreamResponse } from 'ai'
import { mastra } from '@/mastra'
import { NextResponse } from 'next/server'

const THREAD_ID = 'example-user-id'
const RESOURCE_ID = 'weather-chat'

export async function POST(req: Request) {
  const params = await req.json()
  const stream = await handleChatStream({
    mastra,
    agentId: 'weather-agent',
    version: 'v7',
    params: {
      ...params,
      memory: {
        ...params.memory,
        thread: THREAD_ID,
        resource: RESOURCE_ID,
      },
    },
  })
  return createUIMessageStreamResponse({ stream })
}

export async function GET() {
  const memory = await mastra.getAgentById('weather-agent').getMemory()
  let response = null

  try {
    response = await memory?.recall({
      threadId: THREAD_ID,
      resourceId: RESOURCE_ID,
    })
  } catch {
    console.log('No previous messages found.')
  }

  const uiMessages = toAISdkMessages(response?.messages || [], { version: 'v7' })

  return NextResponse.json(uiMessages)
}
```

`POST` 路由接收提示詞，並以 AI SDK 格式串流傳回 Agent 的回應。`GET` 路由則從記憶中讀取歷史訊息，讓用戶端重新載入時能把先前的對話帶回介面。

### 建立聊天頁面 {/* #create-a-chat-page */}

建立 `src/app/chat/page.tsx`：

```tsx title="src/app/chat/page.tsx"
'use client'

import '@/app/globals.css'
import { useEffect, useState } from 'react'
import { DefaultChatTransport, ToolUIPart } from 'ai'
import { useChat } from '@ai-sdk/react'

import {
  PromptInput,
  PromptInputBody,
  PromptInputTextarea,
} from '@/components/ai-elements/prompt-input'

import {
  Conversation,
  ConversationContent,
  ConversationScrollButton,
} from '@/components/ai-elements/conversation'

import { Message, MessageContent, MessageResponse } from '@/components/ai-elements/message'

import { Tool, ToolHeader, ToolContent, ToolInput, ToolOutput } from '@/components/ai-elements/tool'

function Chat() {
  const [input, setInput] = useState<string>('')

  const { messages, setMessages, sendMessage, status } = useChat({
    transport: new DefaultChatTransport({
      api: '/api/chat',
    }),
  })

  useEffect(() => {
    const fetchMessages = async () => {
      const res = await fetch('/api/chat')
      const data = await res.json()
      setMessages([...data])
    }
    fetchMessages()
  }, [setMessages])

  const handleSubmit = async () => {
    if (!input.trim()) return

    sendMessage({ text: input })
    setInput('')
  }

  return (
    <div className="relative size-full h-screen w-full p-6">
      <div className="flex h-full flex-col">
        <Conversation className="h-full">
          <ConversationContent>
            {messages.map(message => (
              <div key={message.id}>
                {message.parts?.map((part, i) => {
                  if (part.type === 'text') {
                    return (
                      <Message key={`${message.id}-${i}`} from={message.role}>
                        <MessageContent>
                          <MessageResponse>{part.text}</MessageResponse>
                        </MessageContent>
                      </Message>
                    )
                  }

                  if (part.type?.startsWith('tool-')) {
                    return (
                      <Tool key={`${message.id}-${i}`}>
                        <ToolHeader
                          type={(part as ToolUIPart).type}
                          state={(part as ToolUIPart).state || 'output-available'}
                          className="cursor-pointer"
                        />
                        <ToolContent>
                          <ToolInput input={(part as ToolUIPart).input || {}} />
                          <ToolOutput
                            output={(part as ToolUIPart).output}
                            errorText={(part as ToolUIPart).errorText}
                          />
                        </ToolContent>
                      </Tool>
                    )
                  }

                  return null
                })}
              </div>
            ))}
            <ConversationScrollButton />
          </ConversationContent>
        </Conversation>

        <PromptInput onSubmit={handleSubmit} className="mt-20">
          <PromptInputBody>
            <PromptInputTextarea
              onChange={e => setInput(e.target.value)}
              className="md:leading-10"
              value={input}
              placeholder="Type your message..."
              disabled={status !== 'ready'}
            />
          </PromptInputBody>
        </PromptInput>
      </div>
    </div>
  )
}

export default Chat
```

這個元件將 [`useChat()`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/use-chat) 接到 `api/chat` 端點，將提示詞送到該端點，再分批接收串流回應。

元件使用 [`<MessageResponse>`](https://ai-sdk.dev/elements/components/message#messageresponse-) 呈現回應文字，並透過 [`<Tool>`](https://ai-sdk.dev/elements/components/tool) 顯示所有 Tool 呼叫。

### 測試 Agent {/* #test-your-agent */}

1. 執行 `npm run dev`，啟動 Next.js 應用程式。
2. 開啟聊天頁面 [http://localhost:3000/chat](http://localhost:3000/chat)。
3. 試著問個天氣問題。如果 API 金鑰設定正確，就會收到回應。

## 公開 Mastra API {/* #expose-the-mastra-api */}

上面的聊天路由使用 `@mastra/ai-sdk` 的 `handleChatStream`，從自訂的 `/api/chat` 端點串流傳回 AI SDK UI 回應。如果要在同一個 Next.js 部署中公開 Mastra 的完整 HTTP API，包括 Agent、Tool、Workflow、記憶、自訂 API 路由、MCP 和 A2A，請將 `@mastra/next` [伺服器轉接器](/docs/server/server-adapters) 掛載到可比對所有剩餘路徑的 catch-all 路由。

安裝轉接器及其同儕相依套件 Hono：

```bash npm2yarn
npm install @mastra/next@latest hono
```

建立 catch-all 路由，並匯出各 HTTP 方法對應的處理函式：

```typescript title="src/app/api/[...mastra]/route.ts"
import { mastra } from '@/mastra'
import { createNextRouteHandler } from '@mastra/next'

export const { GET, POST, PUT, DELETE, PATCH, OPTIONS, HEAD } = createNextRouteHandler({
  mastra,
})
```

`prefix` 的預設值是 `/api`，且必須與 catch-all 路由的掛載路徑相符。例如，將轉接器掛載在 `src/app/api/mastra/[...mastra]/route.ts` 時，請使用 `createNextRouteHandler({ mastra, prefix: '/api/mastra' })`。

啟動應用程式：

```bash npm2yarn
npm run dev
```

另開一個終端機，向天氣查詢 Agent 提問，確認轉接器能正常運作：

```bash
curl -X POST http://localhost:3000/api/agents/weather-agent/generate -H "Content-Type: application/json" -d "{\"messages\":[{\"role\":\"user\",\"content\":\"What is the weather like in Seoul?\"}]}"
```

這個端點會傳回 Agent 的完整 JSON 回應。保留 AI SDK UI 路由供串流聊天介面使用，並透過 catch-all 路由公開完整的 Mastra API。轉接器的詳細用法請見 [Next.js 轉接器](/reference/server/next-adapter)參考文件。
