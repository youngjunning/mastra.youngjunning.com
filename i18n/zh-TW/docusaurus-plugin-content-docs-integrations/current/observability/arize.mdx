# Arize

[Arize AI](https://arize.com/?utm_source=mastra-docs\&utm_medium=partner\&utm_campaign=partner-docs\&utm_content=observability-arize) 透過 [Arize Phoenix](https://arize.com/phoenix/) 與 [Arize AX](https://arize.com/products/ax/) 為 AI 應用程式提供可觀測性與評估功能。在本機執行或自行架設開放原始碼的 Workflow 時，可使用 Phoenix；若要觀測部署於代管雲端或由企業自行架設的正式環境，則使用 Arize AX。Arize 匯出器透過 OpenTelemetry 傳送 Trace，遵循 [OpenInference](https://github.com/Arize-ai/openinference/tree/main/spec) 語意慣例，因此與任何支援 OpenInference 的 OpenTelemetry 平台相容。

若要在 Workflow 中運用 Trace 改善品質，請參閱 Arize 的 [Agent 評估指南](https://arize.com/ai-agents/agent-evaluation/)與 [LLM 評估指南](https://arize.com/resources/llm-evaluation/)。

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/arize@latest
```

## 設定 {/* #configuration */}

### 設定 Phoenix {/* #phoenix-setup */}

Phoenix 是開放原始碼的可觀測性平台，可在本機執行，也能自行架設。

#### 事前準備 {/* #prerequisites */}

1. **Phoenix 執行個體**：使用 Docker 在本機執行 Phoenix，或連線至自行架設的環境。
2. **端點**：準備 Phoenix 的端點 URL，網址須以 `/v1/traces` 結尾。
3. **API 金鑰**：若執行個體未啟用驗證，可省略金鑰；若已啟用驗證，則必須提供。
4. **環境變數**：透過下列環境變數填入設定值。

```bash title=".env"
# Required
PHOENIX_COLLECTOR_ENDPOINT=http://localhost:6006/v1/traces  # Or your self-hosted Phoenix URL

# Optional
PHOENIX_API_KEY=your-api-key  # For authenticated Phoenix instances
PHOENIX_PROJECT_NAME=mastra-service  # Defaults to 'mastra-service'
```

#### 使用環境變數設定 {/* #zero-config-setup */}

設好環境變數後，即可直接使用匯出器，無須傳入設定：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { ArizeExporter } from '@mastra/arize'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      arize: {
        serviceName: 'mastra-service',
        exporters: [new ArizeExporter()],
      },
    },
  }),
})
```

#### 直接指定設定值 {/* #explicit-configuration */}

也可以直接傳入憑證；傳入的值會優先於環境變數：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { ArizeExporter } from '@mastra/arize'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      arize: {
        serviceName: process.env.PHOENIX_PROJECT_NAME || 'mastra-service',
        exporters: [
          new ArizeExporter({
            endpoint: process.env.PHOENIX_COLLECTOR_ENDPOINT!,
            apiKey: process.env.PHOENIX_API_KEY,
            projectName: process.env.PHOENIX_PROJECT_NAME,
          }),
        ],
      },
    },
  }),
})
```

:::note[使用 Docker 快速上手]

若要在本機測試，可啟動使用記憶體儲存資料的 Phoenix 執行個體：

```bash
docker run --pull=always -d --name arize-phoenix -p 6006:6006 \
  -e PHOENIX_SQL_DATABASE_URL="sqlite:///:memory:" \
  arizephoenix/phoenix:latest
```

設定 `PHOENIX_COLLECTOR_ENDPOINT=http://localhost:6006/v1/traces` 後，執行 Mastra Agent，即可在 [localhost:6006](http://localhost:6006) 查看 Trace。

:::

### 設定 Arize AX {/* #arize-ax-setup */}

Arize AX 是可觀測性平台，可使用代管雲端服務或由企業自行架設，並提供適用於正式環境 AI 系統的進階功能。

#### 事前準備 {/* #prerequisites-1 */}

1. **Arize AX 帳號**：前往 [app.arize.com](https://app.arize.com/) 註冊。
2. **空間 ID**：準備組織的空間識別碼。
3. **API 金鑰**：在 Arize AX 的設定中產生金鑰。
4. **環境變數**：透過下列環境變數設定憑證。

```bash title=".env"
# Required
ARIZE_SPACE_ID=your-space-id
ARIZE_API_KEY=your-api-key

# Optional
ARIZE_PROJECT_NAME=mastra-service
```

#### 使用環境變數設定 {/* #zero-config-setup-1 */}

設好環境變數後，即可直接使用匯出器，無須傳入設定：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { ArizeExporter } from '@mastra/arize'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      arize: {
        serviceName: 'mastra-service',
        exporters: [new ArizeExporter()],
      },
    },
  }),
})
```

#### 直接指定設定值 {/* #explicit-configuration-1 */}

也可以直接傳入憑證；傳入的值會優先於環境變數：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { ArizeExporter } from '@mastra/arize'

  observability: new Observability({
    configs: {
      arize: {
        serviceName: process.env.ARIZE_PROJECT_NAME || 'mastra-service',
        exporters: [
          new ArizeExporter({
            apiKey: process.env.ARIZE_API_KEY!,
            spaceId: process.env.ARIZE_SPACE_ID!,
            projectName: process.env.ARIZE_PROJECT_NAME,
          }),
        ],
      },
    },
  }),
})
```

## 設定選項 {/* #configuration-options */}

透過 Arize 匯出器的進階設定，可以微調 OpenTelemetry 的運作方式：

### 完整設定 {/* #complete-configuration */}

```typescript
new ArizeExporter({
  // Phoenix Configuration
  endpoint: 'https://your-collector.example.com/v1/traces', // Required for Phoenix

  // Arize AX Configuration
  spaceId: 'your-space-id', // Required for Arize AX

  // Shared Configuration
  apiKey: 'your-api-key', // Required for authenticated endpoints
  projectName: 'mastra-service', // Optional project name

  // Optional OTLP settings
  headers: {
    'x-custom-header': 'value', // Additional headers for OTLP requests
  },

  // Debug and performance tuning
  logLevel: 'debug', // Logging: debug | info | warn | error
  batchSize: 512, // Batch size before exporting spans
  timeout: 30000, // Timeout in ms before exporting spans

  // Custom resource attributes
  resourceAttributes: {
    'deployment.environment': process.env.NODE_ENV,
    'service.version': process.env.APP_VERSION,
  },
})
```

### 批次處理選項 {/* #batch-processing-options */}

使用下列選項控制 Trace 的批次處理與匯出方式：

```typescript
new ArizeExporter({
  endpoint: process.env.PHOENIX_COLLECTOR_ENDPOINT!,
  apiKey: process.env.PHOENIX_API_KEY,

  // Batch processing configuration
  batchSize: 512, // Number of spans to batch (default: 512)
  timeout: 30000, // Max time in ms to wait before export (default: 30000)
})
```

### 資源屬性 {/* #resource-attributes */}

將自訂屬性加到每個匯出的 span：

```typescript
new ArizeExporter({
  endpoint: process.env.PHOENIX_COLLECTOR_ENDPOINT!,
  resourceAttributes: {
    'deployment.environment': process.env.NODE_ENV,
    'service.namespace': 'production',
    'service.instance.id': process.env.HOSTNAME,
    'custom.attribute': 'value',
  },
})
```

### 自訂中繼資料 {/* #custom-metadata */}

匯出器會將未保留的 span 屬性序列化至 OpenInference 的 `metadata` 資料內容，讓這些屬性顯示在 Arize 或 Phoenix 中。可透過 `tracingOptions.metadata` 加入這些屬性：

```ts
await agent.generate(input, {
  tracingOptions: {
    metadata: {
      companyId: 'acme-co',
      tier: 'enterprise',
    },
  },
})
```

保留欄位會自動排除，例如 `input`、`output`、`sessionId`、執行緒 ID、使用者 ID 和 OpenInference ID。
