# Confident AI

[Confident AI](https://www.confident-ai.com/) 是一個提供 LLM Observability 與評估功能的平台，協助團隊在開發與正式環境中建立可靠的 AI 應用程式。

[`confident-trace`](https://github.com/confident-ai/confident-trace) 套件中的 `ConfidentMastraExporter` 會將 Mastra Trace 傳送至 Confident AI。你可以在平台上查看 Agent 每次執行時完整的 Agent、Model 與 Tool 階層，也可以在平台收到執行資料時自動評分。

## 安裝 {/* #installation */}

```bash npm2yarn
npm install confident-trace@latest
```

## 設定 {/* #configuration */}

### 先決條件 {/* #prerequisites */}

1. **Confident AI 帳號**：前往 [confident-ai.com](https://app.confident-ai.com) 註冊
1. **API 金鑰**：在 Confident AI 的專案設定中產生金鑰
1. **環境變數**：透過以下環境變數設定憑證：

```bash title=".env"
CONFIDENT_API_KEY=confident_proj_xxxxxxxxxxxxx

# Optional. EU region, defaults to the US servers
CONFIDENT_OTEL_ENDPOINT=https://eu.otel.confident-ai.com/v1/traces
```

### 無須額外設定 {/* #zero-config-setup */}

設定好環境變數後，即可使用匯出器，無須再設定匯出器本身：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { ConfidentMastraExporter } from 'confident-trace/mastra'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      confidentAI: {
        serviceName: 'my-service',
        exporters: [new ConfidentMastraExporter()],
      },
    },
  }),
})
```

### 直接指定憑證 {/* #explicit-configuration */}

你也可以直接傳入憑證，其優先順序高於環境變數中的值：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { ConfidentMastraExporter } from 'confident-trace/mastra'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      confidentAI: {
        serviceName: 'my-service',
        exporters: [
          new ConfidentMastraExporter({
            apiKey: process.env.CONFIDENT_API_KEY,
            endpoint: process.env.CONFIDENT_OTEL_ENDPOINT,
          }),
        ],
      },
    },
  }),
})
```

可用選項如下：

```typescript
new ConfidentMastraExporter({
  apiKey: process.env.CONFIDENT_API_KEY, // Default: CONFIDENT_API_KEY
  endpoint: process.env.CONFIDENT_OTEL_ENDPOINT, // Default: US servers
  captureContent: false, // Omit inputs, outputs, and messages
  maxContentBytes: 512, // Truncate captured content
  timeoutMillis: 30000, // Flush and shutdown budget
  resourceAttributes: { 'service.name': 'my-agent' }, // Overrides serviceName
})
```

每筆 Trace 都會帶有 Mastra 設定的 `serviceName`，但 `resourceAttributes['service.name']` 可覆寫這個值。Mastra 會在匯出前執行取樣、套用篩選條件並執行 span 處理器，因此 Confident AI 收到的是通過這些處理步驟的資料。

## 支援的訊號 {/* #supported-signals */}

匯出器會將已結束的 Mastra span 轉換為 OTLP span，保留 Trace ID、span ID、上層 ID、外部上層 ID 和原始時間戳記。匯出器無須快取開始事件，因此可以正確匯出恢復執行的 Workflow span，以及未依順序完成的 span。

- **Agent 與 Workflow 的執行資訊**：操作名稱、時間資訊、狀態，以及步驟間的父子關係。
- **Model 呼叫**：Model 詳細資訊、訊息、結束原因與 [Token 用量](https://www.confident-ai.com/docs/llm-tracing/features/token-usage-cost)。
- **Tool 呼叫**：Tool 名稱及其[輸入與輸出](https://www.confident-ai.com/docs/llm-tracing/features/input-output)。
- **Trace 詳細資訊**：根操作的名稱、標籤、中繼資料，以及輸入與輸出。
- **錯誤**：失敗的操作會保留錯誤狀態，方便在 Trace 中辨識。

此整合會匯出 Trace 資料，範圍不包含 Mastra 的日誌、指標、評分和回饋。

## 自訂 Trace 中繼資料 {/* #custom-trace-metadata */}

透過 Mastra 的 `tracingOptions` 傳入的中繼資料和標籤，會轉送至 Confident AI 中的 Trace。你可以依這些資料篩選 Trace 並將其分組：

```typescript
const result = await mastra.getAgent('assistant').generate('How do you make the best coffee?', {
  tracingOptions: {
    metadata: { release: '2026-09', tier: 'enterprise' },
    tags: ['production', 'support'],
  },
})
```

你提供的中繼資料會與 Mastra 自行設定的欄位（例如 `runId`）合併。標籤會套用至根 span，因此會顯示在 Trace 層級，不會顯示在個別 span 上。

## 生命週期 {/* #lifecycle */}

此匯出器由 Mastra 管理。Mastra 會建立專用的 OTLP 處理器，且不會註冊、取代或關閉全域 OpenTelemetry Provider，因此無須呼叫 `init()`，也無須在啟動指令中加入預載入設定。

span 會在匯出器關閉時批次傳送。請等所有 Agent 執行與串流都結束後，再關閉匯出器一次。否則，短時間執行的指令碼可能會在送出任何資料之前就結束：

```typescript
await observability.shutdown()
```

對於長時間執行的伺服器，請在伺服器進行優雅關閉時關閉匯出器，無須在每次請求後關閉。Trace 送出後，最多可能需要 30 秒才會出現在 Observatory 中。

## 對話串與 Trace 屬性 {/* #threads-and-trace-properties */}

此匯出器會對應 Mastra 本身提供的追蹤資料，因此 Trace 的中繼資料和標籤取自前面示範的 `tracingOptions`。

若要將多輪對話歸入[對話串](https://www.confident-ai.com/docs/llm-tracing/features/threads)，或設定使用者 ID 等 Trace 層級的屬性，請使用 `confident-trace` SDK 的追蹤功能。這項功能會直接與 Mastra 整合，無須透過匯出器。設定方式請參閱 [Mastra 整合指南](https://www.confident-ai.com/docs/integrations/third-party/mastra)。

請選擇其中一種方式，避免同時使用兩者。
