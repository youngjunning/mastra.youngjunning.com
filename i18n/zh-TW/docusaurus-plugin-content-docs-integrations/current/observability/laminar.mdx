# Laminar

[Laminar](https://laminar.sh/) 是專為 AI Agent 打造的開放原始碼 Observability 平台，原生支援 OpenTelemetry。只要在 `Observability` 設定中接入一個 `MastraExporter`，就能追蹤、除錯及監控 Mastra 的每次 Agent 執行、每個 Model 步驟、每次 Tool 呼叫及每個子 Agent。

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @lmnr-ai/lmnr
```

## 設定 {/* #configuration */}

### 先決條件 {/* #prerequisites */}

1. **Laminar 專案**：在 Laminar 中建立或選取專案
1. **專案 API 金鑰**：從 Laminar 的專案設定中複製金鑰
1. **環境變數**：設定驗證憑證

```bash title=".env"
# Required
LMNR_PROJECT_API_KEY=lmnr_...

# Optional
LMNR_BASE_URL=https://api.lmnr.ai
```

### 免額外設定 {/* #zero-config-setup */}

設定環境變數後，即可直接使用匯出器，無須額外設定：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { Laminar, MastraExporter } from '@lmnr-ai/lmnr'

Laminar.initialize()

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      laminar: {
        serviceName: 'my-service',
        exporters: [new MastraExporter()],
      },
    },
  }),
})
```

### 直接指定設定 {/* #explicit-configuration */}

你也可以直接傳入驗證憑證，傳入的值會優先於環境變數：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { Laminar, MastraExporter } from '@lmnr-ai/lmnr'

Laminar.initialize({
  projectApiKey: process.env.LMNR_PROJECT_API_KEY!,
  baseUrl: process.env.LMNR_BASE_URL, // Optional
  // ...other options
})

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      laminar: {
        serviceName: 'my-service',
        exporters: [
          new MastraExporter({
            realtime: process.env.NODE_ENV === 'development', // Optional
          }),
        ],
      },
    },
  }),
})
```

:::note
如需進階用法，包括 `MastraExporter` 的完整選項和多 Agent Trace 的範例，請參閱 [Laminar 的 Mastra 整合指南](https://laminar.sh/docs/tracing/integrations/mastra)。
:::

Mastra 也在 `@mastra/laminar` 中提供獨立的 [`LaminarExporter`](/reference/observability/tracing/exporters/laminar)，透過 OTLP/HTTP 傳送 span。它無法繼承作用中的 OTel 內容，也無法將 Mastra 的 span 完整對應到 Laminar 的原生格式。因此，若要使用 `observe()` 包裝函式、建立多 Agent 的根 span，或讓 Laminar 正確呈現追蹤資料，請使用上述 `@lmnr-ai/lmnr` 整合方式。
