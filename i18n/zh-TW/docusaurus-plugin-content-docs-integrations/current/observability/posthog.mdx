# 郵差豬

[郵差豬](https://posthog.com/)是一個具有人工智慧可觀察性功能的分析平台，用於監控法學碩士申請。透過兩種方式將其與 Mastra 一起使用：

* **AgentTool**讓Agent透過以下方式處理 PostHog 數據，例如事件、見解和功能標誌[Mastra Connect](/docs/mastra-platform/connect).
* **[追蹤](#tracing)**&#x5C07;您的 Mastra 追蹤作為結構化事件匯出到 PostHog。

## 連接 {/* #connect */}

在開始之前，請完成[Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect` and configure your platform project.

## 追蹤 {/* #tracing */}

PostHog 匯出器將您的追蹤作為結構化事件發送到 PostHog，提供有關令牌使用、成本、延遲和對話流的見解。

### 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/posthog@latest
```

### 配置 {/* #configuration */}

#### 先決條件 {/* #prerequisites */}

1. **郵政豬帳戶**: 報名於[posthog.com](https://posthog.com/)
2. **專案 API 金鑰**：從 PostHog 設定 → 專案 API 金鑰取得您的專案 API 金鑰
3. **環境變數**：設定您的憑證

```bash title=".env"
# Required
POSTHOG_API_KEY=phc_xxxxxxxxxxxxxxxx

# Optional
POSTHOG_HOST=https://us.i.posthog.com  # or eu.i.posthog.com for EU region
```

#### 零配置設定 {/* #zero-config-setup */}

設定環境變數後，無需配置即可使用匯出器：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { PosthogExporter } from '@mastra/posthog'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      posthog: {
        serviceName: 'my-service',
        exporters: [new PosthogExporter()],
      },
    },
  }),
})
```

#### 明確配置 {/* #explicit-configuration */}

您也可以直接傳遞憑證（優先於環境變數）：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { PosthogExporter } from '@mastra/posthog'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      posthog: {
        serviceName: 'my-service',
        exporters: [
          new PosthogExporter({
            apiKey: process.env.POSTHOG_API_KEY,
          }),
        ],
      },
    },
  }),
})
```

### 配置選項 {/* #configuration-options */}

#### 配置齊全 {/* #complete-configuration */}

```typescript
new PosthogExporter({
  // Required credentials
  apiKey: process.env.POSTHOG_API_KEY!,

  // Optional settings
  host: 'https://us.i.posthog.com', // Default: US region
  // or "https://eu.i.posthog.com" for EU region
  // or your self-hosted URL

  // Batching configuration
  flushAt: 20, // Batch size (default: 20)
  flushInterval: 10000, // Flush interval in ms (default: 10000)
  serverless: false, // Serverless mode: flushAt=10, flushInterval=2000

  // User identification
  defaultDistinctId: 'anonymous', // Fallback if no userId in metadata

  // Privacy settings
  enablePrivacyMode: false, // Excludes input/output from generation events

  // Diagnostic logging
  logLevel: 'info', // debug | info | warn | error
})
```

#### 無伺服器模式 {/* #serverless-mode */}

針對無伺服器環境最佳化批次：

```typescript
new PosthogExporter({
  apiKey: process.env.POSTHOG_API_KEY!,
  serverless: true, // Configures smaller batches for faster flushing
})
```

#### 隱私模式 {/* #privacy-mode */}

從生成事件中排除輸入/輸出數據，同時保留令牌指標：

```typescript
new PosthogExporter({
  apiKey: process.env.POSTHOG_API_KEY!,
  enablePrivacyMode: true, // Removes $ai_input and $ai_output_choices
})
```

#### 集團分析 {/* #group-analytics */}

將事件附加到[PostHog group](https://posthog.com/docs/product-analytics/group-analytics), add a `$groups` object to `tracingOptions.metadata`. The exporter sends those values as the top-level `groups` field on the PostHog capture call, so you can slice analytics such as LLM cost by group.

```ts
await agent.generate(input, {
  tracingOptions: {
    metadata: {
      $groups: {
        publication: 'publication-1',
      },
    },
  },
})
```
