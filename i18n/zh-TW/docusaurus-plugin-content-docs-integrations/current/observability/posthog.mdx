# PostHog

[PostHog](https://posthog.com/) 是一個分析平台，提供 AI 可觀測性功能，可用來監控大型語言模型（LLM）應用程式。你可以透過下列兩種方式與 Mastra 整合：

- **Agent 工具**讓 Agent 透過 [Mastra Connect](/docs/mastra-platform/connect) 使用 PostHog 的事件、洞察資訊及功能旗標等資料。
- **[追蹤](#tracing)**會將 Mastra Trace 匯出成 PostHog 中的結構化事件。

## Connect {/* #connect */}

開始前，請依照 [Connect 設定指南](/docs/mastra-platform/connect#get-started)安裝 `@mastra/connect`，並設定 Mastra 平台上的專案。

## 追蹤 {/* #tracing */}

PostHog 匯出工具會將 Trace 以結構化事件的形式傳送至 PostHog，方便你分析 token 用量、成本、延遲及對話流程。

### 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/posthog@latest
```

### 設定 {/* #configuration */}

#### 先決條件 {/* #prerequisites */}

1. **PostHog 帳號**：到 [posthog.com](https://posthog.com/) 註冊。
2. **專案 API 金鑰**：在 PostHog 的 Settings（設定）→ Project API Key（專案 API 金鑰）中取得金鑰。
3. **環境變數**：透過環境變數設定憑證。

```bash title=".env"
# Required
POSTHOG_API_KEY=phc_xxxxxxxxxxxxxxxx

# Optional
POSTHOG_HOST=https://us.i.posthog.com  # or eu.i.posthog.com for EU region
```

#### 使用環境變數 {/* #zero-config-setup */}

設定好環境變數後，就能直接建立匯出工具，無須傳入設定：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { PosthogExporter } from '@mastra/posthog'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      posthog: {
        serviceName: 'my-service',
        exporters: [new PosthogExporter()],
      },
    },
  }),
})
```

#### 直接傳入設定 {/* #explicit-configuration */}

你也可以直接傳入憑證。匯出工具會優先採用傳入的值：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { PosthogExporter } from '@mastra/posthog'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      posthog: {
        serviceName: 'my-service',
        exporters: [
          new PosthogExporter({
            apiKey: process.env.POSTHOG_API_KEY,
          }),
        ],
      },
    },
  }),
})
```

### 設定選項 {/* #configuration-options */}

#### 完整設定範例 {/* #complete-configuration */}

```typescript
new PosthogExporter({
  // Required credentials
  apiKey: process.env.POSTHOG_API_KEY!,

  // Optional settings
  host: 'https://us.i.posthog.com', // Default: US region
  // or "https://eu.i.posthog.com" for EU region
  // or your self-hosted URL

  // Batching configuration
  flushAt: 20, // Batch size (default: 20)
  flushInterval: 10000, // Flush interval in ms (default: 10000)
  serverless: false, // Serverless mode: flushAt=10, flushInterval=2000

  // User identification
  defaultDistinctId: 'anonymous', // Fallback if no userId in metadata

  // Privacy settings
  enablePrivacyMode: false, // Excludes input/output from generation events

  // Diagnostic logging
  logLevel: 'info', // debug | info | warn | error
})
```

#### 無伺服器模式 {/* #serverless-mode */}

在無伺服器環境中，可啟用此模式，讓匯出工具以較小的批次和較短的間隔傳送待處理事件：

```typescript
new PosthogExporter({
  apiKey: process.env.POSTHOG_API_KEY!,
  serverless: true, // Configures smaller batches for faster flushing
})
```

#### 隱私模式 {/* #privacy-mode */}

啟用隱私模式後，匯出工具會省略模型生成事件中的輸入與輸出資料，並保留 token 用量指標：

```typescript
new PosthogExporter({
  apiKey: process.env.POSTHOG_API_KEY!,
  enablePrivacyMode: true, // Removes $ai_input and $ai_output_choices
})
```

#### 依群組分析 {/* #group-analytics */}

若要將事件與 [PostHog 群組](https://posthog.com/docs/product-analytics/group-analytics)建立關聯，請在 `tracingOptions.metadata` 中加入 `$groups` 物件。匯出工具呼叫 PostHog 的事件擷取介面時，會將這些值放在頂層的 `groups` 欄位，讓你依群組分析 LLM 成本等指標。

```ts
await agent.generate(input, {
  tracingOptions: {
    metadata: {
      $groups: {
        publication: 'publication-1',
      },
    },
  },
})
```
