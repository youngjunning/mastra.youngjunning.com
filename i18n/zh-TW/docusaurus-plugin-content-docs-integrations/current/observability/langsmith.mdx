# LangSmith

[LangSmith](https://smith.langchain.com/) 是 LangChain 用來監控與評估 LLM 應用程式的平台。LangSmith 匯出器會將 Trace 傳送至 LangSmith，方便你分析模型效能、偵錯及執行評估流程。

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/langsmith@latest
```

## 設定 {/* #configuration */}

### 先決條件 {/* #prerequisites */}

1. **LangSmith 帳號**：前往 [smith.langchain.com](https://smith.langchain.com) 註冊。
2. **API 金鑰**：在 LangSmith 的 Settings → API Keys 中產生 API 金鑰。
3. **環境變數**：透過環境變數設定憑證。

```bash title=".env"
# Required
LANGSMITH_API_KEY=ls-xxxxxxxxxxxx

# Optional
LANGCHAIN_PROJECT=my-project  # Default project for traces
LANGSMITH_BASE_URL=https://api.smith.langchain.com  # For self-hosted
```

### 透過環境變數設定 {/* #zero-config-setup */}

設定環境變數後，建立匯出器時就不必另外傳入設定：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { LangSmithExporter } from '@mastra/langsmith'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      langsmith: {
        serviceName: 'my-service',
        exporters: [new LangSmithExporter()],
      },
    },
  }),
})
```

### 直接傳入設定 {/* #explicit-configuration */}

你也可以直接將憑證傳給匯出器。直接傳入的值優先於環境變數：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { LangSmithExporter } from '@mastra/langsmith'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      langsmith: {
        serviceName: 'my-service',
        exporters: [
          new LangSmithExporter({
            apiKey: process.env.LANGSMITH_API_KEY,
          }),
        ],
      },
    },
  }),
})
```

## 設定選項 {/* #configuration-options */}

### 完整設定 {/* #complete-configuration */}

```typescript
new LangSmithExporter({
  // Required credentials
  apiKey: process.env.LANGSMITH_API_KEY!,

  // Optional settings
  apiUrl: process.env.LANGSMITH_BASE_URL, // Default: https://api.smith.langchain.com
  projectName: 'my-project', // Project to send traces to (overrides LANGCHAIN_PROJECT env var)
  callerOptions: {
    // HTTP client options
    timeout: 30000, // Request timeout in ms
    maxRetries: 3, // Retry attempts
  },
  logLevel: 'info', // Diagnostic logging: debug | info | warn | error

  // LangSmith-specific options
  hideInputs: false, // Hide input data in UI
  hideOutputs: false, // Hide output data in UI
})
```

### 環境變數 {/* #environment-variables */}

| 變數 | 說明 |
| - | - |
| `LANGSMITH_API_KEY` | LangSmith API 金鑰（必填） |
| `LANGCHAIN_PROJECT` | 接收 Trace 的預設專案名稱（選填，預設值為「default」） |
| `LANGSMITH_BASE_URL` | 自行架設的 LangSmith 執行個體所用的 API URL（選填） |

`projectName` 設定優先於 `LANGCHAIN_PROJECT` 環境變數，讓你能在程式中指定要將 Trace 傳送至哪個專案。

## 動態設定 {/* #dynamic-configuration */}

你可以用 `withLangsmithMetadata` 在執行時覆寫個別 span 的 LangSmith 設定，例如依客戶、環境或功能，將 Trace 傳送至不同專案。

### 使用輔助函式 {/* #using-the-helper */}

搭配使用 `withLangsmithMetadata` 和 `buildTracingOptions`，即可指定 LangSmith 專用的選項：

```typescript title="src/agents/support-agent.ts"
import { Agent } from '@mastra/core/agent'
import { buildTracingOptions } from '@mastra/observability'
import { withLangsmithMetadata } from '@mastra/langsmith'

export const supportAgent = new Agent({
  id: 'support-agent',
  name: 'support-agent',
  instructions: 'You are a helpful support agent.',
  model: '__GATEWAY_OPENAI_MODEL__',
  defaultOptions: {
    tracingOptions: buildTracingOptions(withLangsmithMetadata({ projectName: 'customer-support' })),
  },
})
```

### 動態選擇目標專案 {/* #dynamic-project-routing */}

使用 `requestContext`，依執行時的條件將 Trace 傳送至不同專案。

```typescript title="src/mastra/agents/support-agent.ts"
import { Agent } from '@mastra/core/agent'
import { buildTracingOptions } from '@mastra/observability'
import { withLangsmithMetadata } from '@mastra/langsmith'

export const supportAgent = new Agent({
  id: 'support-agent',
  name: 'support-agent',
  instructions: 'You are a helpful support agent.',
  model: '__GATEWAY_OPENAI_MODEL__',
  defaultOptions: ({ requestContext }) => {
    const userTier = requestContext?.get('user-tier') as string
    const userId = requestContext?.get('user-id') as string

    return {
      tracingOptions: buildTracingOptions(
        withLangsmithMetadata({
          projectName: userTier === 'enterprise' ? 'enterprise-traces' : 'standard-traces',
          sessionId: userId,
        }),
      ),
    }
  },
})
```

### 可用欄位 {/* #available-fields */}

`withLangsmithMetadata` 接受下列欄位：

| 欄位 | 型別 | 說明 |
| - | - | - |
| `projectName` | string | 覆寫此 Trace 的目標專案 |
| `sessionId` | string | 依工作階段將相關 Trace 分組 |
| `sessionName` | string | 工作階段的顯示名稱 |

所有欄位皆為選填。此函式會將傳入的欄位與既有中繼資料合併，因此可以重複呼叫，也可以搭配其他追蹤選項使用。

## 對話串 {/* #conversation-threads */}

LangSmith 依據 `session_id` 中繼資料鍵，將執行紀錄歸入同一個[對話串](https://docs.langchain.com/langsmith/threads)。匯出器會為 Trace 中的每筆執行紀錄設定這個鍵。根執行紀錄依序採用第一個可用的值，先看 `withLangsmithMetadata({ sessionId })` 是否有明確傳入值，再查 span 中繼資料的 `sessionId`，最後查 Mastra 記憶中的 `threadId`。子執行紀錄會沿用父執行紀錄的工作階段，因此受委派的子 Agent 即使在自己的衍生對話串執行，其紀錄仍會歸入原本的對話串。

啟用記憶功能的 Agent 每次執行都會設定 `threadId`，因此同一個記憶對話串中的多輪對話會在 LangSmith 中顯示於同一個對話串，無須額外設定：

```typescript
const memory = { thread: 'thread-123', resource: 'user-1' }

await agent.generate('hi', { memory })
await agent.generate('and again', { memory })
```

## 評分與回饋 {/* #scores-and-feedback */}

透過 `mastra.observability.addScore()` 送出的評分，會顯示為 LangSmith 中對應執行紀錄的回饋。若只提供 `traceId`，評分會附加到該 Trace 的根執行紀錄。若提供 `spanId`，評分會附加到該 span 對應的執行紀錄。

```typescript title="src/feedback.ts"
await mastra.observability.addScore({
  traceId,
  correlationContext: { traceId },
  score: { scorerId: 'user-feedback', scoreSource: 'user', score: 1, reason: 'Helpful answer' },
})
```

LangSmith 的執行紀錄 ID 由對應的 Mastra span ID 推算而得。因此，即使程序已重新啟動，或 Trace 已經匯出很久，你仍可從任何程序提交 span 層級的評分。提交 Trace 層級的評分時，匯出器會依據每筆執行紀錄中儲存的 `mastra_trace_id` 中繼資料，在自己的專案中查找根執行紀錄。舊版 `@mastra/langsmith` 匯出的執行紀錄會保留原本的 ID，只有當初匯出這些紀錄的程序可以提交評分。如果要在自己的介面提供執行紀錄的連結，可以呼叫 `langsmithRunIdFor()`，依相同規則算出該紀錄的 ID：

```typescript
import { langsmithRunIdFor } from '@mastra/langsmith'

const runId = langsmithRunIdFor(spanId)
```
