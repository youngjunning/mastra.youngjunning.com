# Braintrust

[Braintrust](https://www.braintrust.dev/) 是評估與監控平台，可用來衡量並改善 LLM 應用程式的品質。Braintrust 匯出器會將 Trace 傳送至 Braintrust，讓你有系統地進行評估、評分和實驗。

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/braintrust@latest
```

## 設定 {/* #configuration */}

### 事前準備 {/* #prerequisites */}

1. 到 [braintrust.dev](https://www.braintrust.dev/) 註冊 **Braintrust 帳號**。
2. 建立或選擇要接收 Trace 的 **專案**。
3. 在 Braintrust 的 **Settings → API Keys** 頁面產生 **API 金鑰**。
4. 如下所示，透過 **環境變數** 設定存取憑證。

```bash title=".env"
BRAINTRUST_API_KEY=sk-xxxxxxxxxxxxxxxx

# Optional
BRAINTRUST_ENDPOINT=https://api.braintrust.dev  # Custom endpoint if needed
```

### 僅使用環境變數 {/* #zero-config-setup */}

設定環境變數後，建立匯出器時就可以省略設定參數。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { BraintrustExporter } from '@mastra/braintrust'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      braintrust: {
        serviceName: 'my-service',
        exporters: [new BraintrustExporter()],
      },
    },
  }),
})
```

### 明確指定設定值 {/* #explicit-configuration */}

你也可以直接將存取憑證傳給匯出器。直接傳入的值優先於環境變數。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { BraintrustExporter } from '@mastra/braintrust'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      braintrust: {
        serviceName: 'my-service',
        exporters: [
          new BraintrustExporter({
            apiKey: process.env.BRAINTRUST_API_KEY,
            projectName: 'my-project',
          }),
        ],
      },
    },
  }),
})
```

### 完整設定 {/* #complete-configuration */}

```typescript
new BraintrustExporter({
  // Required
  apiKey: process.env.BRAINTRUST_API_KEY!,

  // Optional settings
  projectName: 'my-project', // Default: 'mastra-tracing'
  endpoint: 'https://api.braintrust.dev', // Custom endpoint if needed
  logLevel: 'info', // Diagnostic logging: debug | info | warn | error
})
```

## 將 Trace 附加至 Braintrust 評估 {/* #attach-traces-to-braintrust-evals */}

如果應用程式會使用 `Eval()`、`logger.traced()` 或 `currentSpan`，請直接安裝 Braintrust SDK。

```bash npm2yarn
npm install braintrust@latest
```

在 Braintrust 的 `Eval()` 或 `logger.traced()` 中執行 Mastra 時，請將 Braintrust 記錄器和 `currentSpan` 解析函式傳給匯出器。匯入 `currentSpan` 時，請使用建立該評估或受追蹤 Span 的同一個 `braintrust` 套件執行個體。

如果應用程式和 `@mastra/braintrust` 載入的是不同的 Braintrust SDK 副本，這項設定有助於將 Mastra 的 Span 附加到目前作用中的 Braintrust Span 下。

匯出器接受 Braintrust SDK v2 和 v3 提供的相容記錄器與 Span 物件。應用程式使用的 Braintrust SDK 可以和 `@mastra/braintrust` 安裝的 SDK 採用不同版本。

```typescript title="src/mastra/index.ts"
import { currentSpan, initLogger } from 'braintrust'
import { BraintrustExporter } from '@mastra/braintrust'

const logger = initLogger({
  projectName: 'my-project',
  apiKey: process.env.BRAINTRUST_API_KEY,
})

const exporter = new BraintrustExporter({
  braintrustLogger: logger,
  currentSpan,
})
```

在 Braintrust 的評估工作中使用已設定的 Mastra 執行個體。上方的 `currentSpan` 解析函式會讀取 `Eval()` 建立且目前作用中的 Span。

```typescript title="src/evals/braintrust.ts"
import { Eval } from 'braintrust'
import { mastra } from '../mastra'

await Eval('my-project', {
  data: () => [{ input: 'Say hello', expected: 'Hello' }],
  task: async input => {
    const agent = mastra.getAgent('assistant')
    return (await agent.generate(input)).text
  },
  scores: [],
})
```

如果應用程式使用 Nunjucks 提示詞範本，並且要將直接依賴的 Braintrust SDK 從 v2 升級到 v3，請依照 [Braintrust v2 至 v3 移轉指南](https://www.braintrust.dev/docs/sdks/typescript/migrations/v2-to-v3) 操作。

## 用傳回的 `spanId` 查詢 Braintrust {/* #querying-braintrust-with-returned-spanid */}

Mastra 傳回的 `spanId` 同時是 Braintrust 的資料列 ID 和 Span ID。你可以將這個值用於 `id` 或 `span_id` 欄位，找出對應的 Braintrust Span。

Braintrust v3 會在 `root_span_id` 儲存另一個 W3C Trace ID。用 Mastra 傳回的 `spanId` 查詢時，請使用前述兩個欄位之一，避免查詢 `root_span_id`。

```typescript title="src/mastra/usage.ts"
const result = await agent.stream('Summarize this ticket')

console.log('Mastra trace ID:', result.traceId)
console.log('Braintrust row and span ID:', result.spanId)

// Use result.spanId in your Braintrust lookup/query path
```

這個查詢方式也適用於 `agent.generate()` 的傳回結果，以及 Workflow 的執行結果，包括 `run.start()`、`run.stream()` 的最終狀態和 `run.resume()`。

## 成本追蹤 {/* #cost-tracking */}

OpenRouter 和 Vercel AI Gateway 等模型供應商會回報請求費用。供應商有回報時，匯出器會將該金額傳送至 Braintrust，讓 Braintrust 顯示實際收取的費用。若某次生成沒有回報費用，Braintrust 仍會依自己的模型定價顯示估算金額。

詳細規則請參閱 [`BraintrustExporter` 參考文件](/reference/observability/tracing/exporters/braintrust#cost-tracking)。
