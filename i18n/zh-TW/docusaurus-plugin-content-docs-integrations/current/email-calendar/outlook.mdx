# 微軟Outlook

為Agent商提供Tool來閱讀、傳送、起草和回覆電子郵件、管理郵件資料夾以及透過 Mastra Connect 在 Microsoft Outlook 中建立和更新行事曆事件。每個Tool呼叫都會透過 Mastra 平台，該平台會新增連接的憑證。您的應用程式從不儲存 Microsoft Outlook 憑證。

## 連接 {/* #connect */}

在開始之前，請完成[Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect`並配置您的平台項目。

### 連接帳戶 {/* #connect-an-account */}

從包含您的目錄的目錄執行此命令`.env` file:

```bash
mastra connect add outlook
```

CLI 將引導您完成 Microsoft Outlook 的授權並等待連線啟動。

### 向Agent添加Tool {/* #add-tools-to-an-agent */}

經過[`tools()`](/reference/connect/tools) to the agent and select the `outlook` provider:

```typescript title="src/mastra/agents/outlook-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const outlookAgent = new Agent({
  id: 'outlook-agent',
  name: 'Microsoft Outlook agent',
  instructions:
    'You help people read, send, draft, and reply to email, manage mail folders, and create and update calendar events in Microsoft Outlook.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['outlook'] }),
})
```

Agent程式可獲得 30 個 Microsoft Outlook Tool，其中包括下列金鑰：`outlook_add_event_attachment`. See [Microsoft Outlook tools](/reference/connect/providers#microsoft-outlook) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
