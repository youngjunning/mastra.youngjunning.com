# Microsoft Outlook

透過 Mastra Connect，為 Agent 提供可在 Microsoft Outlook 中讀取、傳送、撰寫及回覆電子郵件，管理郵件資料夾，以及建立和更新行事曆活動的 Tool。每次 Tool 呼叫都會經過 Mastra 平台，由平台加入該連線的憑證；你的應用程式不會儲存 Microsoft Outlook 憑證。

## 連線 {/* #connect */}

開始前，請先完成 [Connect 設定](/docs/mastra-platform/connect#get-started)，安裝 `@mastra/connect` 並設定 Mastra 平台專案。

### 連結帳戶 {/* #connect-an-account */}

請在包含 `.env` 檔案的目錄中執行以下命令：

```bash
mastra connect add outlook
```

CLI 會引導你完成 Microsoft Outlook 授權，並等待連線啟用。

### 將 Tool 新增至 Agent {/* #add-tools-to-an-agent */}

將 [`tools()`](/reference/connect/tools) 傳給 Agent，並選取 `outlook` Provider：

```typescript title="src/mastra/agents/outlook-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const outlookAgent = new Agent({
  id: 'outlook-agent',
  name: 'Microsoft Outlook agent',
  instructions:
    'You help people read, send, draft, and reply to email, manage mail folders, and create and update calendar events in Microsoft Outlook.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['outlook'] }),
})
```

Agent 可使用 30 個 Microsoft Outlook Tool，Tool key 包括 `outlook_add_event_attachment`。完整清單請參閱 [Microsoft Outlook Tool](/reference/connect/providers#microsoft-outlook)；如需限制可用 Tool，或要求每次呼叫在執行前取得核准，請參閱 [`tools()` 參數](/reference/connect/tools#parameters)。
