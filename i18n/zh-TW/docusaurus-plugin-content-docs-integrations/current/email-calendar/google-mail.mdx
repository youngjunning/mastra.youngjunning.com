# 信箱

為客服人員提供Tool來閱讀、發送和起草電子郵件、管理標籤、過濾器和線程，以及透過 Mastra Connect 更新 Gmail 中的郵箱設定。每個Tool呼叫都會透過 Mastra 平台，該平台會新增連接的憑證。您的應用程式從不儲存 Gmail 憑證。

## 連接 {/* #connect */}

在開始之前，請完成[Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect`並配置您的平台項目。

### 連接帳戶 {/* #connect-an-account */}

從包含您的目錄的目錄執行此命令`.env` file:

```bash
mastra connect add google-mail
```

CLI 將引導您完成 Gmail 授權並等待連線啟動。

### 向Agent添加Tool {/* #add-tools-to-an-agent */}

經過[`tools()`](/reference/connect/tools) to the agent and select the `google-mail` provider:

```typescript title="src/mastra/agents/google-mail-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const googleMailAgent = new Agent({
  id: 'google-mail-agent',
  name: 'Gmail agent',
  instructions:
    'You help people read, send, and draft email, manage labels, filters, and threads, and update mailbox settings in Gmail.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['google-mail'] }),
})
```

Agent程式獲得 52 個 Gmail Tool，其中包含以下密鑰：`google_mail_batch_delete_messages`. See [Gmail tools](/reference/connect/providers#gmail) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
