# Google Calendar

透過 Mastra Connect，為 Agent 提供可在 Google Calendar 中尋找、建立及更新活動、查看可用時間，以及管理日曆的 Tool。每次 Tool 呼叫都會經過 Mastra 平台，由平台加入該連線的憑證；你的應用程式不會儲存 Google Calendar 憑證。

## 連線 {/* #connect */}

開始前，請先完成 [Connect 設定](/docs/mastra-platform/connect#get-started)，安裝 `@mastra/connect` 並設定 Mastra 平台專案。

### 連結帳戶 {/* #connect-an-account */}

請在包含 `.env` 檔案的目錄中執行以下命令：

```bash
mastra connect add google-calendar
```

CLI 會引導你完成 Google Calendar 授權，並等待連線啟用。

### 將 Tool 新增至 Agent {/* #add-tools-to-an-agent */}

將 [`tools()`](/reference/connect/tools) 傳給 Agent，並選取 `google-calendar` Provider：

```typescript title="src/mastra/agents/google-calendar-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const googleCalendarAgent = new Agent({
  id: 'google-calendar-agent',
  name: 'Google Calendar agent',
  instructions:
    'You help people find, create, and update events, check availability, and manage calendars in Google Calendar.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['google-calendar'] }),
})
```

Agent 可使用 43 個 Google Calendar Tool，Tool key 包括 `google_calendar_add_attendee`。完整清單請參閱 [Google Calendar Tool](/reference/connect/providers#google-calendar)；如需限制可用 Tool，或要求每次呼叫在執行前取得核准，請參閱 [`tools()` 參數](/reference/connect/tools#parameters)。
