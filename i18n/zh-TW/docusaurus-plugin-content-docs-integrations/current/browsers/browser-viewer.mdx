# BrowserViewer

`@mastra/browser-viewer` 套件可搭配 [agent-browser](https://www.npmjs.com/package/agent-browser)、[browser-use](https://pypi.org/project/browser-use/) 和 [browse](https://www.npmjs.com/package/browse) 等 CLI Tool 執行瀏覽器自動化。BrowserViewer 透過 Playwright 啟動 Chrome，提供 Chrome DevTools Protocol（CDP）URL，並自動將該 URL 注入透過 [Sandbox Tool](/docs/sandbox/overview#using-the-sandbox) 執行的 CLI 指令。

## 何時使用 BrowserViewer {/* #when-to-use-browserviewer */}

若 Agent 透過 CLI Tool 而非 SDK 操控瀏覽器，請使用 BrowserViewer。BrowserViewer 負責下列工作：

- 啟動並管理 Chrome，供 CLI Tool 連線
- 呼叫 `workspace_execute_command` 時自動注入 CDP URL
- 將即時螢幕畫面串流至 Studio
- 依對話執行緒隔離瀏覽器

若透過 SDK 執行瀏覽器自動化，請改用 [AgentBrowser](/integrations/browsers/agent-browser) 或 [Stagehand](/integrations/browsers/stagehand)。

## 快速入門 {/* #quickstart */}

請安裝 `@mastra/browser-viewer` 和 Agent 將使用的 CLI Tool。BrowserViewer 負責管理 Chrome，CLI Tool 本身仍須另外安裝。

```bash npm2yarn
npm install @mastra/browser-viewer
```

請在 Workspace 環境中安裝 CLI Tool。本範例使用 `browser-use`：

```bash
pip install browser-use
```

安裝對應的[技能](/docs/sandbox/skills)，讓 Agent 知道如何使用 CLI：

```bash
npx skills add browser-use/browser-use --skill browser-use
```

使用 BrowserViewer 建立 Workspace，並將該 Workspace 指派給 Agent：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core/mastra'
import { Agent } from '@mastra/core/agent'
import { Memory } from '@mastra/memory'
import { LibSQLStore } from '@mastra/libsql'
import { Workspace, LocalSandbox } from '@mastra/core/workspace'
import { BrowserViewer } from '@mastra/browser-viewer'

const workspace = new Workspace({
  sandbox: new LocalSandbox({
    workingDirectory: './workspace',
  }),
  browser: new BrowserViewer({
    cli: 'browser-use',
    headless: false,
  }),
})

const browserAgent = new Agent({
  id: 'browser-agent',
  model: '__GATEWAY_OPENAI_MODEL__',
  workspace,
  instructions: `You are a web automation assistant.
Use browser-use commands to navigate and interact with websites.`,
  memory: new Memory(),
})

export const mastra = new Mastra({
  agents: { browserAgent },
  storage: new LibSQLStore({
    id: 'mastra-storage',
    url: 'file:./mastra.db',
  }),
})
```

當 Agent 執行瀏覽器 CLI 指令時，Mastra 會自動啟動 Chrome，將 CDP 連線資訊傳給 CLI，並開始將螢幕畫面串流至 Studio。使用 Browser Use 時，Agent 可以透過 stdin 傳入 Python 程式碼：

```bash
browser-use <<'PY'
print("Connected to the managed browser")
PY
```

## 運作方式 {/* #how-it-works */}

1. Agent 呼叫 `workspace_execute_command`，並傳入瀏覽器 CLI 指令。
1. Mastra 偵測到 CLI 指令後，會在 Chrome 尚未執行時透過 Playwright 啟動它。
1. Mastra 將 CDP URL 注入指令，讓 CLI 連線至受管理的瀏覽器。
1. 螢幕畫面的各影格從頁面層級的 CDP 工作階段串流至 Studio。

## 支援的 CLI {/* #supported-clis */}

BrowserViewer 支援三種 CLI Provider。每個 CLI 都必須在 Workspace 環境中個別安裝，也各自發布了[技能](/docs/sandbox/skills)，讓 Agent 瞭解其指令與操作流程。

請將 `cli` 選項設為 Agent 使用的 CLI：

```typescript
const viewer = new BrowserViewer({
  cli: 'browser-use',
  headless: false,
})
```

### `agent-browser` {/* #agent-browser */}

```bash
npm install -g agent-browser
npx skills add vercel-labs/agent-browser
```

CDP 命令列旗標：`--cdp`

### `browser-use` {/* #browser-use */}

```bash
pip install browser-use
npx skills add browser-use/browser-use --skill browser-use
```

直接透過 stdin 呼叫時（使用 `browser-use`、`browseruse`、`browser` 或 `bu`，後面可選擇加上 `<` 重新導向或 heredoc），Mastra 會將 `BU_CDP_WS` 設為受管理瀏覽器的 CDP URL，並將 `BU_NAME` 設為固定的背景程序名稱。每個對話執行緒與瀏覽器端點的組合都有唯一的名稱，因此重複呼叫會重複使用同一個背景程序，不同的對話執行緒或端點則維持隔離。Mastra 會原樣保留透過 stdin 傳入的指令碼，不會附加 CLI 引數。

為維持相容性，舊版子指令仍會注入 `--cdp-url` 和 `--session`。透過 stdin 呼叫時，則不會加入這些旗標。

### `browse` {/* #browse */}

```bash
npm install -g browse
browse skills install
```

CDP 命令列旗標：`--ws`。如需完整的設定選項、進階連線模式及方法細節，請參閱 [BrowserViewer 參考文件](/reference/browser/browser-viewer)。
