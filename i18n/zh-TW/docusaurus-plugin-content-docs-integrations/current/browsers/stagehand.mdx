# Stagehand

`@mastra/stagehand` 套件使用 Browserbase 的 [Stagehand SDK](https://docs.browserbase.com/stagehand/introduction) 提供瀏覽器自動化功能。Stagehand 會運用 AI 理解頁面脈絡，依照自然語言描述找出元素，無須明確指定選擇器。

## 何時使用 Stagehand {/* #when-to-use-stagehand */}

有下列需求時，可以使用 Stagehand：

- 以自然語言找出元素，例如「選取登入按鈕」
- 運用 AI 擷取頁面資料
- 使用 Browserbase 的原生雲端整合
- 透過較簡單的工具介面執行常見操作

## 快速入門 {/* #quickstart */}

安裝套件：

```bash npm2yarn
npm install @mastra/stagehand
```

建立瀏覽器執行個體，並將它傳給 Agent：

```typescript title="src/mastra/agents/stagehand-agent.ts"
import { Agent } from '@mastra/core/agent'
import { StagehandBrowser } from '@mastra/stagehand'

const browser = new StagehandBrowser({
  headless: false,
  model: '__GATEWAY_OPENAI_MODEL__',
})

export const stagehandAgent = new Agent({
  id: 'stagehand-agent',
  name: 'Stagehand Agent',
  model: '__GATEWAY_OPENAI_MODEL__',
  browser,
  instructions: `You are a web automation assistant.

Use stagehand tools to interact with pages:
- stagehand_navigate to go to URLs
- stagehand_act to perform actions described in natural language
- stagehand_extract to get structured data from the page
- stagehand_observe to find available actions on the page
- stagehand_screenshot to visually inspect the page`,
})
```

## 自然語言操作 {/* #natural-language-actions */}

Agent 可以將以自然語言描述的操作交給 `stagehand_act` 工具，例如：

- 「按一下登入按鈕」
- 「在電子郵件欄位輸入 `'[user@example.com](mailto:user@example.com)'`」
- 「從國家／地區下拉式清單中選取『美國』」

Stagehand 會運用 AI 判讀要執行的操作，並找出頁面上對應的元素。

## 資料擷取 {/* #data-extraction */}

Agent 可以使用 `stagehand_extract` 工具從頁面擷取結構化資料。

指令範例：「擷取商品名稱、價格和庫存狀態」

工具會依頁面內容傳回結構化資料：

```json
{
  "name": "Widget Pro",
  "price": "$29.99",
  "availability": "In Stock"
}
```

## 查詢可用操作 {/* #observing-actions */}

Agent 使用 `stagehand_observe` 工具時，工具會分析目前的頁面，並傳回可執行的操作。

指令範例：「我可以在這個登入表單中執行哪些操作？」

工具會傳回可用操作的清單：

```json
[
  { "action": "Press 'Sign In' button", "element": "button" },
  { "action": "Type in 'Email' field", "element": "input" },
  { "action": "Open 'Forgot Password' link", "element": "a" }
]
```

## 擷取畫面 {/* #screenshots */}

Agent 使用 `stagehand_screenshot` 工具時，工具會將目前的頁面擷取為 PNG，並以支援視覺輸入的模型可直接判讀的影像內容傳回。

需要檢查頁面上的圖片、版面配置或色彩時，可以擷取畫面。處理文字或結構化資料時，請使用 `stagehand_extract` 或 `stagehand_observe`。

```typescript
const browser = new StagehandBrowser({
  headless: false,
  model: '__GATEWAY_OPENAI_MODEL__',
})
```

如果模型不支援視覺輸入，可以用 `excludeTools` 停用畫面擷取工具：

```typescript
const browser = new StagehandBrowser({
  headless: false,
  model: '__GATEWAY_OPENAI_MODEL__',
  excludeTools: ['stagehand_screenshot'],
})
```

## Browserbase {/* #browserbase */}

Stagehand 原生整合 Browserbase，可使用其雲端瀏覽器基礎架構：

```typescript
const browser = new StagehandBrowser({
  env: 'BROWSERBASE',
  apiKey: process.env.BROWSERBASE_API_KEY,
  projectId: process.env.BROWSERBASE_PROJECT_ID,
  model: '__GATEWAY_OPENAI_MODEL__',
})
```

完整的設定選項請參閱 [StagehandBrowser 參考文件](/reference/browser/stagehand-browser)。

## 錄製瀏覽器工作階段 {/* #recording */}

你可以在 Stagehand 中啟用瀏覽器錄製工具（Beta）：

```typescript
const browser = new StagehandBrowser({
  headless: false,
  model: '__GATEWAY_OPENAI_MODEL__',
  recording: {
    outputDir: './browser-recordings',
  },
})
```

啟用後，Agent 就能使用 `browser_record` 和 `browser_record_caption` 工具。詳情請參閱[瀏覽器錄製（Beta）](/docs/browser#record-browser-sessions)。
