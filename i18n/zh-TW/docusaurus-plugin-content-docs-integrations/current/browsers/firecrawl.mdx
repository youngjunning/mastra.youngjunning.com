# 火行

這`@mastra/browser-firecrawl`包提供瀏覽器自動化使用[Firecrawl 瀏覽器沙箱](https://docs.firecrawl.dev/features/browser)。它透過 Firecrawl API 提供遠端瀏覽器會話，並使用與以下相同的確定性、可訪問性優先的Tool來驅動它們：[Agent瀏覽器](/integrations/browsers/agent-browser).

`FirecrawlBrowser`延伸`AgentBrowser`, so agents get the same toolset (`browser_goto`, `browser_snapshot`, `browser_click`等等），而瀏覽器本身則在 Firecrawl 的託管基礎設施中運行。不需要本地 Chromium 安裝。

## 何時使用Firecrawl {/* #when-to-use-firecrawl */}

當您需要時使用 Firecrawl：

* 託管瀏覽器會話，無需管理本地 Chromium 二進位文件
* 無法啟動本機瀏覽器的環境中的瀏覽器自動化
* 具有自動會話清理功能的每線程沙箱隔離
* 命名的 Firecrawl 設定檔可在會話之間保留 cookie 和登入狀態

## 快速入門 {/* #quickstart */}

安裝包：

```bash npm2yarn
npm install @mastra/browser-firecrawl
```

設定您的 Firecrawl API 金鑰：

```bash title=".env"
FIRECRAWL_API_KEY=fc-...
```

建立一個瀏覽器實例並將其指派給Agent：

```typescript title="src/mastra/agents/firecrawl-agent.ts"
import { Agent } from '@mastra/core/agent'
import { FirecrawlBrowser } from '@mastra/browser-firecrawl'

const browser = new FirecrawlBrowser({
  apiKey: process.env.FIRECRAWL_API_KEY,
})

export const firecrawlAgent = new Agent({
  id: 'firecrawl-agent',
  name: 'Firecrawl Agent',
  model: '__GATEWAY_OPENAI_MODEL__',
  browser,
  instructions: `You are a web automation assistant.

When interacting with pages:
1. Use browser_snapshot to get the current page state and element refs
2. Use the refs (like @e1, @e2) to target elements for clicks and typing
3. After actions, take another snapshot to verify the result`,
})
```

如果`apiKey` is omitted, the provider reads `FIRECRAWL_API_KEY` from the environment.

## 會話範圍 {/* #session-scope */}

`FirecrawlBrowser`遵循相同的`scope` option as `AgentBrowser`:

* `'thread'`（預設）：每個對話執行緒都有自己的 Firecrawl 沙箱會話。當執行緒的瀏覽器關閉時，會話將被刪除。
* `'shared'`：一個 Firecrawl 沙箱會話在所有執行緒之間共享，並在瀏覽器關閉時刪除。

```typescript
const browser = new FirecrawlBrowser({
  scope: 'shared',
})
```

## 會話選項 {/* #session-options */}

`firecrawl` key. These map to the Firecrawl `browser()` API:

```typescript
const browser = new FirecrawlBrowser({
  firecrawl: {
    ttl: 600,
    activityTtl: 120,
    profile: {
      name: 'my-profile',
      saveChanges: true,
    },
  },
})
```

* `ttl`：最大會話生命週期（以秒為單位）。
* `activityTtl`：Firecrawl 回收會話之前的空閒逾時（以秒為單位）。
* `profile`：命名為 Firecrawl 設定文件，保留 cookie 和登入狀態。放`saveChanges: true` to save profile changes when the session ends.

：：：筆記

嵌套的`firecrawl.profile` option refers to a profile stored in Firecrawl's infrastructure. It's different from the top-level `profile` option inherited from `AgentBrowser`, which is a local Playwright user-data directory path.

:::

## 自託管 Firecrawl {/* #self-hosted-firecrawl */}

若要使用自架 Firecrawl API，請設定`apiUrl`:

```typescript
const browser = new FirecrawlBrowser({
  apiUrl: 'https://firecrawl.internal.example.com',
})
```
