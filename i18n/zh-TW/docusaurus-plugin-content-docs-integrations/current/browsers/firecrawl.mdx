# Firecrawl

`@mastra/browser-firecrawl` 套件透過 [Firecrawl Browser Sandbox](https://docs.firecrawl.dev/features/browser) 提供瀏覽器自動化功能。它透過 Firecrawl API 建立遠端瀏覽器工作階段，並使用與 [AgentBrowser](/integrations/browsers/agent-browser) 相同的一組具確定性且優先考量無障礙的 Tool 來操控瀏覽器。

`FirecrawlBrowser` 繼承自 `AgentBrowser`，因此 Agent 可以使用同一組 Tool（例如 `browser_goto`、`browser_snapshot`、`browser_click`），而瀏覽器本身在 Firecrawl 的託管基礎設施上執行。無須在本機安裝 Chromium。

## 何時使用 Firecrawl {/* #when-to-use-firecrawl */}

有以下需求時可使用 Firecrawl：

- 使用託管的瀏覽器工作階段，無須管理本機的 Chromium 二進位檔
- 在無法啟動本機瀏覽器的環境中執行瀏覽器自動化
- 為每個對話執行緒提供獨立的 Sandbox，並自動清理工作階段
- 使用具名的 Firecrawl 設定檔，在不同工作階段之間保留 Cookie 和登入狀態

## 快速入門 {/* #quickstart */}

安裝套件：

```bash npm2yarn
npm install @mastra/browser-firecrawl
```

設定您的 Firecrawl API 金鑰：

```bash title=".env"
FIRECRAWL_API_KEY=fc-...
```

建立瀏覽器執行個體，並將其指派給 Agent：

```typescript title="src/mastra/agents/firecrawl-agent.ts"
import { Agent } from '@mastra/core/agent'
import { FirecrawlBrowser } from '@mastra/browser-firecrawl'

const browser = new FirecrawlBrowser({
  apiKey: process.env.FIRECRAWL_API_KEY,
})

export const firecrawlAgent = new Agent({
  id: 'firecrawl-agent',
  name: 'Firecrawl Agent',
  model: '__GATEWAY_OPENAI_MODEL__',
  browser,
  instructions: `You are a web automation assistant.

When interacting with pages:
1. Use browser_snapshot to get the current page state and element refs
2. Use the refs (like @e1, @e2) to target elements for clicks and typing
3. After actions, take another snapshot to verify the result`,
})
```

若省略 `apiKey`，Provider 會讀取環境變數 `FIRECRAWL_API_KEY`。

## 工作階段範圍 {/* #session-scope */}

`FirecrawlBrowser` 支援與 `AgentBrowser` 相同的 `scope` 選項：

- `'thread'`（預設）：每個對話執行緒都有獨立的 Firecrawl Sandbox 工作階段。執行緒的瀏覽器關閉時，系統會刪除該工作階段。
- `'shared'`：所有執行緒共用同一個 Firecrawl Sandbox 工作階段。瀏覽器關閉時，系統會刪除該工作階段。

```typescript
const browser = new FirecrawlBrowser({
  scope: 'shared',
})
```

## 工作階段選項 {/* #session-options */}

請在 `firecrawl` 鍵下傳入 Firecrawl 專用的工作階段選項。這些選項對應至 Firecrawl 的 `browser()` API：

```typescript
const browser = new FirecrawlBrowser({
  firecrawl: {
    ttl: 600,
    activityTtl: 120,
    profile: {
      name: 'my-profile',
      saveChanges: true,
    },
  },
})
```

- `ttl`：工作階段的最長存續時間，以秒為單位。
- `activityTtl`：工作階段閒置多久後由 Firecrawl 回收，以秒為單位。
- `profile`：可保留 Cookie 和登入狀態的具名 Firecrawl 設定檔。設定 `saveChanges: true` 可在工作階段結束時儲存設定檔的變更。

:::note

巢狀的 `firecrawl.profile` 選項指向儲存在 Firecrawl 基礎設施中的設定檔。從 `AgentBrowser` 繼承的頂層 `profile` 選項則指定本機 Playwright 使用者資料目錄的路徑。

:::

## 自架 Firecrawl {/* #self-hosted-firecrawl */}

若要使用自架的 Firecrawl API，請設定 `apiUrl`：

```typescript
const browser = new FirecrawlBrowser({
  apiUrl: 'https://firecrawl.internal.example.com',
})
```
