# Agent瀏覽器

這`@mastra/agent-browser`套件使用 Playwright 和可訪問性優先的元素定位來提供瀏覽器自動化。元素由頁面的輔助功能樹中的引用來標識，從而使跨不同頁面佈局的互動變得可靠。

## 何時使用 AgentBrowser {/* #when-to-use-agentbrowser */}

當您需要時使用 AgentBrowser：

* 透過可訪問性參考進行可靠的元素定位
* 對瀏覽器操作的細粒度控制
* Playwright 可靠的自動化能力
* 支援鍵盤快捷鍵和複雜的交互

## 快速入門 {/* #quickstart */}

安裝包：

```bash npm2yarn
npm install @mastra/agent-browser
```

建立一個瀏覽器實例並將其指派給Agent：

```typescript title="src/mastra/agents/browser-agent.ts"
import { Agent } from '@mastra/core/agent'
import { AgentBrowser } from '@mastra/agent-browser'

const browser = new AgentBrowser({
  headless: false,
})

export const browserAgent = new Agent({
  id: 'browser-agent',
  name: 'Browser Agent',
  model: '__GATEWAY_OPENAI_MODEL__',
  browser,
  instructions: `You are a web automation assistant.

When interacting with pages:
1. Use browser_snapshot to get the current page state and element refs
2. Use the refs (like @e1, @e2) to target elements for clicks and typing
3. After actions, take another snapshot to verify the result`,
})
```

：：：筆記

對於本機啟動（預設），AgentBrowser 需要透過 Playwright 安裝 Chromium 二進位。通常在安裝時會自動下載`@mastra/agent-browser`. If launching the browser fails with `"browser executable is missing"`, run `npx playwright install chromium`. If you connect to a remote browser using the [`cdpUrl`](/reference/browser/agent-browser) option, the remote browser provides Chromium.

## 截圖 {/* #screenshots */}

當Agent使用`browser_screenshot` tool, it captures a PNG image of the current page and returns it as image content that vision-capable models can interpret directly.

當您需要目視檢查頁面時，例如評估圖像、佈局或顏色，請使用螢幕截圖。對於文字或結構化數據，請使用`browser_snapshot` instead.

若要停用不支援視覺的模型的螢幕截圖Tool，請使用`excludeTools`:

```typescript
const browser = new AgentBrowser({
  headless: false,
  excludeTools: ['browser_screenshot'],
})
```

## 元素參考 {/* #element-refs */}

AgentBrowser 使用可訪問性樹參考來識別元素。當Agent打電話時`browser_snapshot`, it receives a text representation of the page with refs like `@e1`, `@e2`, etc. The agent then uses these refs with other tools to interact with elements.

## 記錄 {/* #recording */}

AgentBrowser 可以選擇 Beta 瀏覽器記錄Tool：

```typescript
const browser = new AgentBrowser({
  headless: false,
  recording: {
    outputDir: './browser-recordings',
  },
})
```

這增加了`browser_record` and `browser_record_caption` to the agent's toolset. See [Browser recording (Beta)](/docs/browser#record-browser-sessions) for details. See [AgentBrowser reference](/reference/browser/agent-browser) for all configuration options and tool details.
