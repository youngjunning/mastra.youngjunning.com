# AgentBrowser

`@mastra/agent-browser` 套件透過 Playwright 提供瀏覽器自動化功能，並優先依據無障礙資訊定位元素。套件使用頁面無障礙樹中的參照來識別元素，因此能在不同的頁面版面中可靠地操作元素。

## 何時使用 AgentBrowser {/* #when-to-use-agentbrowser */}

有下列需求時，可使用 AgentBrowser：

- 透過無障礙參照可靠地定位元素
- 精細控制瀏覽器操作
- 使用 Playwright 可靠的自動化功能
- 支援鍵盤快速鍵與複雜的互動操作

## 快速入門 {/* #quickstart */}

安裝套件：

```bash npm2yarn
npm install @mastra/agent-browser
```

建立瀏覽器執行個體，並將它指派給 Agent：

```typescript title="src/mastra/agents/browser-agent.ts"
import { Agent } from '@mastra/core/agent'
import { AgentBrowser } from '@mastra/agent-browser'

const browser = new AgentBrowser({
  headless: false,
})

export const browserAgent = new Agent({
  id: 'browser-agent',
  name: 'Browser Agent',
  model: '__GATEWAY_OPENAI_MODEL__',
  browser,
  instructions: `You are a web automation assistant.

When interacting with pages:
1. Use browser_snapshot to get the current page state and element refs
2. Use the refs (like @e1, @e2) to target elements for clicks and typing
3. After actions, take another snapshot to verify the result`,
})
```

:::note

在本機啟動瀏覽器時（預設行為），AgentBrowser 需要透過 Playwright 安裝的 Chromium 執行檔。安裝 `@mastra/agent-browser` 時，通常會自動下載這個執行檔。如果啟動瀏覽器時出現 `"browser executable is missing"` 錯誤，請執行 `npx playwright install chromium`。如果透過 [`cdpUrl`](/reference/browser/agent-browser) 選項連線至遠端瀏覽器，則由遠端瀏覽器提供 Chromium。

:::

## 截圖 {/* #screenshots */}

當 Agent 使用 `browser_screenshot` Tool 時，該 Tool 會擷取目前頁面的 PNG 截圖，並以支援視覺功能的 Model 可直接解讀的圖片內容傳回。

需要目視檢查頁面時，例如評估圖片、版面或色彩，請使用截圖。若要取得文字或結構化資料，請改用 `browser_snapshot`。

若要為不支援視覺功能的 Model 停用截圖 Tool，請使用 `excludeTools`：

```typescript
const browser = new AgentBrowser({
  headless: false,
  excludeTools: ['browser_screenshot'],
})
```

## 元素參照 {/* #element-refs */}

AgentBrowser 使用無障礙樹中的參照識別元素。Agent 呼叫 `browser_snapshot` 時，會收到以文字呈現的頁面內容，其中包含 `@e1`、`@e2` 等參照。接著，Agent 會搭配其他 Tool 使用這些參照來操作元素。

## 錄影 {/* #recording */}

您可以選擇在 AgentBrowser 中啟用 Beta 版的瀏覽器錄影 Tool：

```typescript
const browser = new AgentBrowser({
  headless: false,
  recording: {
    outputDir: './browser-recordings',
  },
})
```

啟用後，Agent 的 Tool 集合會新增 `browser_record` 和 `browser_record_caption`。詳情請參閱[瀏覽器錄影（Beta）](/docs/browser#record-browser-sessions)。完整設定選項與 Tool 詳情請參閱 [AgentBrowser 參考文件](/reference/browser/agent-browser)。
