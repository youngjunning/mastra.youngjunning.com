# Resend

通过 Mastra Connect 为 Agent 提供可在 Resend 中发送电子邮件和广播，并管理联系人、细分、域名、模板和 webhook 的 Tool。每次 Tool 调用都会经过 Mastra 平台，由平台添加该连接的凭据；你的应用不会存储 Resend 凭据。

## 连接 {/* #connect */}

开始前，请先完成 [Connect 设置](/docs/mastra-platform/connect#get-started)，安装 `@mastra/connect` 并配置 Mastra 平台项目。

:::note

请使用具有 **Full access** 权限的 API key 连接 Resend。只有 **Sending access** 权限的 key 无法完成连接，因为 Mastra 会通过列出域名来检查新 key，而此类 key 没有该权限。

:::

### 连接账户 {/* #connect-an-account */}

在包含 `.env` 文件的目录中运行以下命令：

```bash
mastra connect add resend
```

CLI 会引导你完成 Resend 的授权，并等待连接激活。

### 向 Agent 添加 Tool {/* #add-tools-to-an-agent */}

将 [`tools()`](/reference/connect/tools) 传给 Agent，并选择 `resend` Provider：

```typescript title="src/mastra/agents/resend-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const resendAgent = new Agent({
  id: 'resend-agent',
  name: 'Resend agent',
  instructions:
    'You help people send email and broadcasts, and manage contacts, segments, domains, templates, and webhooks in Resend.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['resend'] }),
})
```

Agent 可使用 80 个 Resend Tool，Tool key 包括 `resend_add_contact_to_segment`。完整列表请参阅 [Resend Tool](/reference/connect/providers#resend)；如需限制可用 Tool，或要求每次调用在运行前获得批准，请参阅 [`tools()` 参数](/reference/connect/tools#parameters)。
