# 重新发送

为Agent提供Tool来发送电子邮件和广播，并通过 Mastra Connect 管理 Resend 中的联系人、细分、域、模板和 Webhooks。每个Tool调用都会通过 Mastra 平台，该平台会添加连接的凭据。您的应用程序从不存储重新发送凭据。

## 连接 {/* #connect */}

在开始之前，请完成[Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect`并配置您的平台项目。

：：：笔记

使用具有以下功能的 API 密钥连接重新发送**Full access** permission. A **Sending access** key fails to connect because Mastra checks a new key by listing your domains, which sending access keys can't do.

:::

### 连接账户 {/* #connect-an-account */}

从包含您的目录的目录运行此命令`.env` file:

```bash
mastra connect add resend
```

CLI 将引导您完成重新发送的授权并等待连接激活。

### 向Agent添加Tool {/* #add-tools-to-an-agent */}

经过[`tools()`](/reference/connect/tools) to the agent and select the `resend` provider:

```typescript title="src/mastra/agents/resend-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const resendAgent = new Agent({
  id: 'resend-agent',
  name: 'Resend agent',
  instructions:
    'You help people send email and broadcasts, and manage contacts, segments, domains, templates, and webhooks in Resend.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['resend'] }),
})
```

Agent获得 80 个重新发送Tool，其中包含以下密钥`resend_add_contact_to_segment`. See [Resend tools](/reference/connect/providers#resend) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
