# Snowflake

通过 Mastra Connect 为 Agent 提供可在 Snowflake 中运行 SQL 语句并读取结果，以及列出数据库、schema、表、warehouse 和角色的 Tool。每次 Tool 调用都会经过 Mastra 平台，由平台添加该连接的凭据；你的应用不会存储 Snowflake 凭据。

## 连接 {/* #connect */}

开始前，请先完成 [Connect 设置](/docs/mastra-platform/connect#get-started)，安装 `@mastra/connect` 并配置 Mastra 平台项目。

### 连接账户 {/* #connect-an-account */}

在包含 `.env` 文件的目录中运行以下命令：

```bash
mastra connect add snowflake
```

CLI 会引导你完成 Snowflake 的授权，并等待连接激活。

### 向 Agent 添加 Tool {/* #add-tools-to-an-agent */}

将 [`tools()`](/reference/connect/tools) 传给 Agent，并选择 `snowflake` Provider：

```typescript title="src/mastra/agents/snowflake-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const snowflakeAgent = new Agent({
  id: 'snowflake-agent',
  name: 'Snowflake agent',
  instructions:
    'You help people run SQL statements and read their results, and list databases, schemas, tables, warehouses, and roles in Snowflake.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['snowflake'] }),
})
```

Agent 可使用 15 个 Snowflake Tool，Tool key 包括 `snowflake_cancel_statement`。完整列表请参阅 [Snowflake Tool](/reference/connect/providers#snowflake)；如需限制可用 Tool，或要求每次调用在运行前获得批准，请参阅 [`tools()` 参数](/reference/connect/tools#parameters)。
