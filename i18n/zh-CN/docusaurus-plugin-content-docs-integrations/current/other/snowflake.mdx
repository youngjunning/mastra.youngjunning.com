# 雪花

为Agent提供Tool来运行 SQL 语句并读取其结果，并通过 Mastra Connect 列出 Snowflake 中的数据库、模式、表、仓库和角色。每个Tool调用都会通过 Mastra 平台，该平台会添加连接的凭据。您的应用程序从不存储 Snowflake 凭据。

## 连接 {/* #connect */}

在开始之前，请完成[Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect`并配置您的平台项目。

### 连接账户 {/* #connect-an-account */}

从包含您的目录的目录运行此命令`.env` file:

```bash
mastra connect add snowflake
```

CLI 将引导您完成 Snowflake 的授权并等待连接激活。

### 向Agent添加Tool {/* #add-tools-to-an-agent */}

经过[`tools()`](/reference/connect/tools) to the agent and select the `snowflake` provider:

```typescript title="src/mastra/agents/snowflake-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const snowflakeAgent = new Agent({
  id: 'snowflake-agent',
  name: 'Snowflake agent',
  instructions:
    'You help people run SQL statements and read their results, and list databases, schemas, tables, warehouses, and roles in Snowflake.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['snowflake'] }),
})
```

Agent获得 15 个 Snowflake Tool，其中包含以下密钥：`snowflake_cancel_statement`. See [Snowflake tools](/reference/connect/providers#snowflake) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
