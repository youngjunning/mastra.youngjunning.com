# Canva

通过 Mastra Connect 为 Agent 提供可在 Canva 中创建、编辑、搜索和导出设计的 Tool。Canva 通过托管的 Model Context Protocol (MCP) 服务器提供这些 Tool；你的应用不会存储 Canva 凭据。

## 连接 {/* #connect */}

开始前，请先完成 [Connect 设置](/docs/mastra-platform/connect#get-started)，安装 `@mastra/connect` 并配置 Mastra 平台项目。

### 连接账户 {/* #connect-an-account */}

在包含 `.env` 文件的目录中运行以下命令：

```bash
mastra connect add canva-mcp
```

CLI 会引导你完成 Canva 的授权，并等待连接激活。

### 向 Agent 添加 Tool {/* #add-tools-to-an-agent */}

将 [`tools()`](/reference/connect/tools) 传给 Agent，并选择 `canva-mcp` Provider：

```typescript title="src/mastra/agents/canva-mcp-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const canvaMcpAgent = new Agent({
  id: 'canva-mcp-agent',
  name: 'Canva agent',
  instructions: 'You help people create, edit, search, and export designs in Canva.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['canva-mcp'] }),
})
```

Agent 运行时，Mastra 会从 Canva 的 MCP 服务器发现可用 Tool。这些 Tool 取决于服务器和已连接的账户，而不是你的 `@mastra/connect` 版本。Tool key 以 `canva-mcp_` 开头。

如需查看 Canva 提供的 Tool，请参阅 [Canva MCP](https://www.canva.dev/docs/apps/mcp/) 文档。如需要求每次调用在运行前获得批准，请参阅 `tools()` 参考中的 [MCP Provider](/reference/connect/tools#mcp-providers)。
