# 帆布

通过 Mastra Connect 为Agent提供在 Canva 中创建、编辑、搜索和导出设计的Tool。 Canva 从托管的模型上下文协议 (MCP) 服务器提供这些Tool。您的应用程序从不存储 Canva 凭据。

## 连接 {/* #connect */}

在开始之前，请完成[Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect`并配置您的平台项目。

### 连接账户 {/* #connect-an-account */}

从包含您的目录的目录运行此命令`.env` file:

```bash
mastra connect add canva-mcp
```

CLI 将引导您完成 Canva 的授权并等待连接激活。

### 向Agent添加Tool {/* #add-tools-to-an-agent */}

经过[`tools()`](/reference/connect/tools) to the agent and select the `canva-mcp` provider:

```typescript title="src/mastra/agents/canva-mcp-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const canvaMcpAgent = new Agent({
  id: 'canva-mcp-agent',
  name: 'Canva agent',
  instructions: 'You help people create, edit, search, and export designs in Canva.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['canva-mcp'] }),
})
```

当Agent运行时，Mastra 从其 MCP 服务器发现 Canva 的Tool。可用的Tool取决于服务器和连接的帐户，而不取决于您的`@mastra/connect` version. Tool keys start with `canva-mcp_`.

要查看 Canva 提供的Tool，请阅读[Canva MCP](https://www.canva.dev/docs/apps/mcp/) documentation. To require approval before a call runs, see [MCP providers](/reference/connect/tools#mcp-providers) in the `tools()` reference.
