# 事件.io

为Agent提供Tool来创建和更新事件、管理后续行动和操作，以及通过 Mastra Connect 读取 Incident.io 中的警报、计划和目录条目。每个Tool调用都会通过 Mastra 平台，该平台会添加连接的凭据。您的应用程序从不存储 event.io 凭据。

## 连接 {/* #connect */}

在开始之前，请完成[Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect`并配置您的平台项目。

### 连接账户 {/* #connect-an-account */}

从包含您的目录的目录运行此命令`.env` file:

```bash
mastra connect add incident-io
```

CLI 将引导您完成 event.io 的授权并等待连接激活。

### 向Agent添加Tool {/* #add-tools-to-an-agent */}

经过[`tools()`](/reference/connect/tools) to the agent and select the `incident-io` provider:

```typescript title="src/mastra/agents/incident-io-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const incidentIoAgent = new Agent({
  id: 'incident-io-agent',
  name: 'incident.io agent',
  instructions:
    'You help people create and update incidents, manage follow-ups and actions, and read alerts, schedules, and catalog entries in incident.io.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['incident-io'] }),
})
```

Agent获得 66 个 event.io Tool，其中包含以下密钥：`incident_io_add_alert_tags`. See [incident.io tools](/reference/connect/providers#incidentio) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
