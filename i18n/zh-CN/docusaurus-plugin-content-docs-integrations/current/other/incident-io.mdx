# incident.io

通过 Mastra Connect 为 Agent 提供可在 incident.io 中创建和更新事件、管理跟进事项和行动，并读取警报、排班和目录条目的 Tool。每次 Tool 调用都会经过 Mastra 平台，由平台添加该连接的凭据；你的应用不会存储 incident.io 凭据。

## 连接 {/* #connect */}

开始前，请先完成 [Connect 设置](/docs/mastra-platform/connect#get-started)，安装 `@mastra/connect` 并配置 Mastra 平台项目。

### 连接账户 {/* #connect-an-account */}

在包含 `.env` 文件的目录中运行以下命令：

```bash
mastra connect add incident-io
```

CLI 会引导你完成 incident.io 的授权，并等待连接激活。

### 向 Agent 添加 Tool {/* #add-tools-to-an-agent */}

将 [`tools()`](/reference/connect/tools) 传给 Agent，并选择 `incident-io` Provider：

```typescript title="src/mastra/agents/incident-io-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const incidentIoAgent = new Agent({
  id: 'incident-io-agent',
  name: 'incident.io agent',
  instructions:
    'You help people create and update incidents, manage follow-ups and actions, and read alerts, schedules, and catalog entries in incident.io.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['incident-io'] }),
})
```

Agent 可使用 66 个 incident.io Tool，Tool key 包括 `incident_io_add_alert_tags`。完整列表请参阅 [incident.io Tool](/reference/connect/providers#incidentio)；如需限制可用 Tool，或要求每次调用在运行前获得批准，请参阅 [`tools()` 参数](/reference/connect/tools#parameters)。
