# Fireflies.ai

通过 Mastra Connect 为 Agent 提供可在 Fireflies.ai 中读取会议转录和分析数据、就会议内容提问、创建精彩片段，以及管理会议共享和隐私设置的 Tool。每次 Tool 调用都会经过 Mastra 平台，由平台添加该连接的凭据；你的应用不会存储 Fireflies.ai 凭据。

## 连接 {/* #connect */}

开始前，请先完成 [Connect 设置](/docs/mastra-platform/connect#get-started)，安装 `@mastra/connect` 并配置 Mastra 平台项目。

### 连接账户 {/* #connect-an-account */}

在包含 `.env` 文件的目录中运行以下命令：

```bash
mastra connect add fireflies
```

CLI 会引导你完成 Fireflies.ai 的授权，并等待连接激活。

### 向 Agent 添加 Tool {/* #add-tools-to-an-agent */}

将 [`tools()`](/reference/connect/tools) 传给 Agent，并选择 `fireflies` Provider：

```typescript title="src/mastra/agents/fireflies-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const firefliesAgent = new Agent({
  id: 'fireflies-agent',
  name: 'Fireflies.ai agent',
  instructions:
    'You help people read meeting transcripts and analytics, ask questions about meetings, create soundbites, and manage meeting sharing and privacy in Fireflies.ai.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['fireflies'] }),
})
```

Agent 可使用 27 个 Fireflies.ai Tool，Tool key 包括 `fireflies_add_to_live`。完整列表请参阅 [Fireflies.ai Tool](/reference/connect/providers#firefliesai)；如需限制可用 Tool，或要求每次调用在运行前获得批准，请参阅 [`tools()` 参数](/reference/connect/tools#parameters)。
