# 萤火虫.ai

为Agent提供Tool来阅读会议记录和分析、询问有关会议的问题、创建原声片段以及通过 Mastra Connect 在 Fireflies.ai 中管理会议共享和隐私。每个Tool调用都会通过 Mastra 平台，该平台会添加连接的凭据。您的应用程序从不存储 Fireflies.ai 凭据。

## 连接 {/* #connect */}

在开始之前，请完成[Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect`并配置您的平台项目。

### 连接账户 {/* #connect-an-account */}

从包含您的目录的目录运行此命令`.env` file:

```bash
mastra connect add fireflies
```

CLI 将引导您完成 Fireflies.ai 的授权并等待连接激活。

### 向Agent添加Tool {/* #add-tools-to-an-agent */}

经过[`tools()`](/reference/connect/tools) to the agent and select the `fireflies` provider:

```typescript title="src/mastra/agents/fireflies-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const firefliesAgent = new Agent({
  id: 'fireflies-agent',
  name: 'Fireflies.ai agent',
  instructions:
    'You help people read meeting transcripts and analytics, ask questions about meetings, create soundbites, and manage meeting sharing and privacy in Fireflies.ai.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['fireflies'] }),
})
```

该Agent获得 27 个 Fireflies.ai Tool，其中包含以下密钥：`fireflies_add_to_live`. See [Fireflies.ai tools](/reference/connect/providers#firefliesai) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
