# 理智

为Agent提供Tool来通过 Mastra Connect 查询、创建和更新 Sanity 中的内容文档。 Sanity 从托管的模型上下文协议 (MCP) 服务器提供这些Tool。您的应用程序从不存储 Sanity 凭据。

## 连接 {/* #connect */}

在开始之前，请完成[Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect`并配置您的平台项目。

### 连接账户 {/* #connect-an-account */}

从包含您的目录的目录运行此命令`.env` file:

```bash
mastra connect add sanity-mcp
```

CLI 将引导您完成 Sanity 的授权并等待连接激活。

### 向Agent添加Tool {/* #add-tools-to-an-agent */}

经过[`tools()`](/reference/connect/tools) to the agent and select the `sanity-mcp` provider:

```typescript title="src/mastra/agents/sanity-mcp-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const sanityMcpAgent = new Agent({
  id: 'sanity-mcp-agent',
  name: 'Sanity agent',
  instructions: 'You help people query, create, and update content documents in Sanity.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['sanity-mcp'] }),
})
```

当Agent运行时，Mastra 从其 MCP 服务器发现 Sanity 的Tool。可用的Tool取决于服务器和连接的帐户，而不取决于您的`@mastra/connect` version. Tool keys start with `sanity-mcp_`.

要查看 Sanity 提供了哪些Tool，请阅读[Sanity MCP server](https://www.sanity.io/docs/ai/mcp-server) documentation. To require approval before a call runs, see [MCP providers](/reference/connect/tools#mcp-providers) in the `tools()` reference.
