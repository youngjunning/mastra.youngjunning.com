# 罗宾汉

为Agent提供Tool来读取帐户和市场数据，并通过 Mastra Connect 在 Robinhood 中进行交易。 Robinhood 通过托管模型上下文协议 (MCP) 服务器提供这些Tool。您的应用程序从不存储 Robinhood 凭据。

## 连接 {/* #connect */}

在开始之前，请完成[Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect`并配置您的平台项目。

：：：警告

这些Tool可以用真实的资金进行真实的交易。需要批准交易Tool`requireApproval` so a person confirms each order before it runs. See [MCP providers](/reference/connect/tools#mcp-providers).

:::

### 连接账户 {/* #connect-an-account */}

从包含您的目录的目录运行此命令`.env` file:

```bash
mastra connect add robinhood-mcp
```

CLI 将引导您完成 Robinhood 的授权并等待连接激活。

### 向Agent添加Tool {/* #add-tools-to-an-agent */}

经过[`tools()`](/reference/connect/tools) to the agent and select the `robinhood-mcp` provider:

```typescript title="src/mastra/agents/robinhood-mcp-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const robinhoodMcpAgent = new Agent({
  id: 'robinhood-mcp-agent',
  name: 'Robinhood agent',
  instructions: 'You help people read account and market data and place trades in Robinhood.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['robinhood-mcp'] }),
})
```

当Agent运行时，Mastra 从其 MCP 服务器发现 Robinhood 的Tool。可用的Tool取决于服务器和连接的帐户，而不取决于您的`@mastra/connect` version. Tool keys start with `robinhood-mcp_`.

要查看 Robinhood 提供了哪些Tool，请阅读[Agentic Trading](https://robinhood.com/us/en/support/agentic-trading) documentation. To require approval before a call runs, see [MCP providers](/reference/connect/tools#mcp-providers) in the `tools()` reference.
