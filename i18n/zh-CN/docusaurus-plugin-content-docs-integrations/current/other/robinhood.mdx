# Robinhood

通过 Mastra Connect 为 Agent 提供可在 Robinhood 中读取账户和市场数据，以及执行交易的 Tool。Robinhood 通过托管的 Model Context Protocol (MCP) 服务器提供这些 Tool；你的应用不会存储 Robinhood 凭据。

## 连接 {/* #connect */}

开始前，请先完成 [Connect 设置](/docs/mastra-platform/connect#get-started)，安装 `@mastra/connect` 并配置 Mastra 平台项目。

:::warning

这些 Tool 可以使用真实资金执行真实交易。请通过 `requireApproval` 要求交易 Tool 在运行前获得批准，确保每笔订单都由用户确认。详情请参阅 [MCP Provider](/reference/connect/tools#mcp-providers)。

:::

### 连接账户 {/* #connect-an-account */}

在包含 `.env` 文件的目录中运行以下命令：

```bash
mastra connect add robinhood-mcp
```

CLI 会引导你完成 Robinhood 的授权，并等待连接激活。

### 向 Agent 添加 Tool {/* #add-tools-to-an-agent */}

将 [`tools()`](/reference/connect/tools) 传给 Agent，并选择 `robinhood-mcp` Provider：

```typescript title="src/mastra/agents/robinhood-mcp-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const robinhoodMcpAgent = new Agent({
  id: 'robinhood-mcp-agent',
  name: 'Robinhood agent',
  instructions: 'You help people read account and market data and place trades in Robinhood.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['robinhood-mcp'] }),
})
```

Agent 运行时，Mastra 会从 Robinhood 的 MCP 服务器发现可用 Tool。这些 Tool 取决于服务器和已连接的账户，而不是你的 `@mastra/connect` 版本。Tool key 以 `robinhood-mcp_` 开头。

如需查看 Robinhood 提供的 Tool，请参阅 [Agentic Trading](https://robinhood.com/us/en/support/agentic-trading) 文档。如需要求每次调用在运行前获得批准，请参阅 `tools()` 参考中的 [MCP Provider](/reference/connect/tools#mcp-providers)。
