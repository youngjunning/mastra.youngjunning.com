# xAI 实时语音

`XAIRealtimeVoice` 类通过 xAI Grok Voice Agent API 提供实时语音交互。它实现了 Mastra 的 `MastraVoice` 实时接口，支持双向音频流、文本轮次、服务端 VAD、xAI 语音、函数 Tool 和 xAI 服务端 Tool。

## 使用示例 {/* #usage-example */}

```typescript
import { Agent } from '@mastra/core/agent'
import { getMicrophoneStream, playAudio } from '@mastra/node-audio'
import { XAIRealtimeVoice } from '@mastra/voice-xai-realtime'

const voice = new XAIRealtimeVoice({
  apiKey: process.env.XAI_API_KEY,
  model: 'grok-voice-think-fast-1.0',
  speaker: 'eve',
  instructions: 'You are a concise voice assistant.',
  turnDetection: { type: 'server_vad' },
})

const agent = new Agent({
  id: 'voice-agent',
  name: 'Voice Agent',
  instructions: 'You are a helpful voice assistant.',
  model: 'xai/grok-4.3',
  voice,
})

await agent.voice.connect()

agent.voice.on('speaker', audioStream => {
  playAudio(audioStream)
})

agent.voice.on('writing', ({ text, role }) => {
  console.log(`${role}: ${text}`)
})

await agent.voice.speak('How can I help you today?')

const microphoneStream = getMicrophoneStream()
await agent.voice.send(microphoneStream)

agent.voice.close()
```

### VoiceConfig 配置方式 {/* #voiceconfig-pattern */}

也可以使用 Mastra 通用的语音配置结构：

```typescript
const voice = new XAIRealtimeVoice({
  speaker: 'ara',
  realtimeConfig: {
    model: 'grok-voice-think-fast-1.0',
    apiKey: process.env.XAI_API_KEY,
    options: {
      instructions: 'Answer briefly.',
      turnDetection: { type: 'server_vad', threshold: 0.85 },
    },
  },
})
```

## 身份验证 {/* #authentication */}

服务端应用可使用 `apiKey` 或 `XAI_API_KEY`。此 Provider 面向 Node.js 服务端运行环境。如果服务器已签发 xAI 临时令牌，可通过 `ephemeralToken` 传入；Provider 将使用 `xai-client-secret.<token>` WebSocket 协议，而非授权请求头。如果同时配置了 `apiKey` 和 `ephemeralToken`，Provider 会使用临时令牌。

## 事件 {/* #events */}

`XAIRealtimeVoice` 将 xAI 实时服务端事件映射为 Mastra 语音事件：

* `speaker`：发出包含助手音频的可读流。
* `speaking`：发出助手音频的增量数据。
* `speaking.done`：助手音频响应完成时发出。
* `writing`：发出助手文本的增量数据和用户输入的转录文本。
* `error`：发出 xAI 错误和 Provider 执行错误，包括 Tool 执行错误及格式错误的函数调用参数。Tool 错误包含 `details.call_id` 和 `details.name`。
* `close`：WebSocket 关闭时发出。
* `tool-call-start`：执行 Mastra 函数 Tool 前发出。
* `tool-call-result`：Mastra 函数 Tool 返回后发出。

也会发出原始 xAI 事件，因此可以订阅 `response.output_audio.delta`、`response.text.delta`、`response.function_call_arguments.done` 和 `response.done` 等事件。

## Tool {/* #tools */}

### Mastra 函数 Tool {/* #mastra-function-tools */}

通过 `addTools()` 添加的 Tool 会转换为 xAI 函数 Tool，并包含在 `session.update` 中。

```typescript
import { createTool } from '@mastra/core/tools'
import { z } from 'zod'

const weatherTool = createTool({
  id: 'getWeather',
  description: 'Get current weather for a location.',
  inputSchema: z.object({
    location: z.string(),
  }),
  execute: async ({ location }) => {
    return { location, temperature: 22 }
  },
})

voice.addTools({ getWeather: weatherTool })
```

当 xAI 发出 `response.function_call_arguments.done` 时，Provider 会执行对应的 Mastra Tool，并发送一个 `function_call_output` 项。如果 xAI 在一次响应中发起多个函数调用，Provider 会等待所有 Tool 返回结果以及该响应的 `response.done` 事件，然后只发送一次用于继续对话的 `response.create`。

### xAI 服务端 Tool {/* #xai-server-side-tools */}

xAI 服务端 Tool 通过会话配置传递，并由 xAI 执行。`session.tools` 和 `serverTools` 中的 Tool 会合并：

```typescript
const voice = new XAIRealtimeVoice({
  apiKey: process.env.XAI_API_KEY,
  serverTools: [
    { type: 'web_search' },
    { type: 'x_search', allowed_x_handles: ['xai'] },
    { type: 'file_search', vector_store_ids: ['collection_123'], max_num_results: 10 },
    {
      type: 'mcp',
      server_url: 'https://mcp.example.com/mcp',
      server_label: 'business-tools',
      allowed_tools: ['lookup_order'],
    },
  ],
})
```

## 音频格式 {/* #audio-formats */}

默认输入和输出格式为 24 kHz PCM16。您还可以配置支持的 PCM 采样率或电话编解码器：

```typescript
const voice = new XAIRealtimeVoice({
  audio: {
    input: { format: { type: 'audio/pcm', rate: 16000 } },
    output: { format: { type: 'audio/pcm', rate: 16000 } },
  },
})
```

支持的格式类型包括 `audio/pcm`、`audio/pcmu` 和 `audio/pcma`。PCM 支持文档列出的 8 kHz 至 48 kHz 采样率。`audio/pcmu` 和 `audio/pcma` 是 G.711 电话音频编解码格式，采样率为 8 kHz。
