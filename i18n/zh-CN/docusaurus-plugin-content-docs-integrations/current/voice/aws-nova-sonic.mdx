# AWS Nova Sonic

`NovaSonicVoice` 类基于 [AWS Bedrock Nova 2 Sonic](https://docs.aws.amazon.com/nova/latest/userguide/speech.html) 提供实时语音对话功能。它与模型建立双向流，并针对助手音频、转录文本、Tool 调用、对话轮次边界和中断发出事件。

## 使用示例 {/* #usage-example */}

```typescript title="src/mastra/voice.ts"
import { NovaSonicVoice } from '@mastra/voice-aws-nova-sonic'
import { playAudio, getMicrophoneStream } from '@mastra/node-audio'

// Initialize using the default AWS credential provider chain
const voice = new NovaSonicVoice({
  region: 'us-east-1',
  speaker: 'matthew',
})

// Or pass explicit credentials
const voiceWithCredentials = new NovaSonicVoice({
  region: 'us-east-1',
  speaker: 'tiffany',
  credentials: {
    accessKeyId: process.env.AWS_ACCESS_KEY_ID!,
    secretAccessKey: process.env.AWS_SECRET_ACCESS_KEY!,
  },
})

// Establish the bidirectional stream
await voice.connect()

// Listen for assistant audio (Int16Array PCM)
voice.on('speaking', ({ audioData }) => {
  if (audioData) playAudio(audioData)
})

// Listen for transcribed text from the user and assistant
voice.on('writing', ({ text, role, generationStage }) => {
  console.log(`${role} (${generationStage ?? 'FINAL'}): ${text}`)
})

// Stream microphone audio in real time
const microphoneStream = getMicrophoneStream()
await voice.send(microphoneStream)

// Disconnect when done
voice.close()
```

## 身份验证 {/* #authentication */}

如果未传入 `credentials`，`NovaSonicVoice` 会使用 AWS SDK 的默认凭证提供者链。Mastra 调用 `@aws-sdk/credential-provider-node` 中的 `defaultProvider()`，依次检查环境变量、共享凭证文件、EC2 的 IAM 角色、ECS、EKS 及其他标准来源。

要使用静态凭据，请将它们传递给构造函数：

```typescript
new NovaSonicVoice({
  region: 'us-east-1',
  credentials: {
    accessKeyId: process.env.AWS_ACCESS_KEY_ID!,
    secretAccessKey: process.env.AWS_SECRET_ACCESS_KEY!,
    sessionToken: process.env.AWS_SESSION_TOKEN,
  },
})
```

语音 Provider 不会记录凭证值。

## 方法 {/* #methods */}

### `connect()` {/* #connect */}

建立与 AWS Bedrock 之间的双向流，并发送初始会话、提示词和系统事件。调用 `speak`、`listen` 或 `send` 前，须先调用此方法。

### `getSpeakers()` {/* #getspeakers */}

返回 Nova 2 Sonic 支持的语音列表。

返回：`Promise<Array<{ voiceId: string; name: string; language: string; locale: string; gender: 'masculine' | 'feminine'; polyglot: boolean }>>`

### `getListener()` {/* #getlistener */}

返回语音实例当前是否保持着已建立的流。

返回：`Promise<{ enabled: boolean }>`

### `close()` {/* #close */}

关闭双向流并销毁底层 Bedrock 客户端。对话结束时调用此方法。

返回：`void`

注册和移除事件监听器。共享事件 API 参见[语音事件](/reference/voice/voice.events)。

## 注意事项 {/* #notes */}

* 音频以 16 位 PCM 格式流式传输。助手音频通过 `speaking` 事件以 `Int16Array` 形式发出。
* 调用其他流式方法前，语音实例必须先调用 `connect()`。
* `close()` 会销毁底层 `BedrockRuntimeClient`，以释放 HTTP/2 会话。
* Nova 2 Sonic 可在 `us-east-1`、`us-west-2` 和 `ap-northeast-1` 区域使用。使用其他区域时，构造实例的过程会抛出配置错误。
