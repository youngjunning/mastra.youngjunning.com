# 语音化

Mastra 中的 Speechify 语音实现使用 Speechify 的 API 提供文本转语音功能。

## 使用示例 {/* #usage-example */}

```typescript
import { SpeechifyVoice } from '@mastra/voice-speechify'

// Initialize with default configuration (uses SPEECHIFY_API_KEY environment variable)
const voice = new SpeechifyVoice()

// Initialize with custom configuration
const voice = new SpeechifyVoice({
  speechModel: {
    name: 'simba-3.5',
    apiKey: 'your-api-key',
  },
  speaker: 'harper_32', // Default voice
})

// Convert text to speech
const audioStream = await voice.speak('Hello, world!', {
  speaker: 'imogen_32', // Override default voice
})

// Any voice speaks any of simba-3.5's 48 languages
const portuguese = await voice.speak('Olá, mundo!', { language: 'pt-BR' })
```

### `listen()` {/* #listen */}

Speechify 不支持此方法，并且会引发错误。 Speechify 不提供语音转文本功能。

## 笔记 {/* #notes */}

* Speechify 需要 API 密钥进行身份验证
* 默认模型为“simba-3.5”，Speechify 推荐模型：一个 id 48 种语言，每个目录语音都会说所有这些语言
* “simba-3.2”仅有英文版；非英语语音返回错误
* “simba-3.0”涵盖英语、德语、西班牙语、法语、意大利语和葡萄牙语
* “simba-english”和“simba-multilingual”是旧版 ID。新Workspace出现“model\_retired”错误，从 2026 年 11 月 21 日起，它们由“simba-3.2”和“simba-3.5”提供服务
* 默认扬声器遵循配置的型号：Simba 3 型号为“harper\_32”，否则为“george”
* 不支持语音转文本功能
* 额外的音频流选项可以通过spoke()方法的options参数传递
