# Speechify

Mastra 通过 Speechify API 将文本转换为语音。

## 使用示例 {/* #usage-example */}

```typescript
import { SpeechifyVoice } from '@mastra/voice-speechify'

// Initialize with default configuration (uses SPEECHIFY_API_KEY environment variable)
const voice = new SpeechifyVoice()

// Initialize with custom configuration
const voice = new SpeechifyVoice({
  speechModel: {
    name: 'simba-3.5',
    apiKey: 'your-api-key',
  },
  speaker: 'harper_32', // Default voice
})

// Convert text to speech
const audioStream = await voice.speak('Hello, world!', {
  speaker: 'imogen_32', // Override default voice
})

// Any voice speaks any of simba-3.5's 48 languages
const portuguese = await voice.speak('Olá, mundo!', { language: 'pt-BR' })
```

### `listen()` {/* #listen */}

Speechify 不提供语音转文本功能，调用此方法会抛出错误。

## 注意事项 {/* #notes */}

- Speechify 要求使用 API 密钥进行身份验证。
- 默认模型是 Speechify 推荐的 `simba-3.5`。同一个模型 ID 支持 48 种语言，目录中的每种音色都能朗读这 48 种语言。
- `simba-3.2` 仅支持英语。指定非英语音色会返回错误。
- `simba-3.0` 支持英语、德语、西班牙语、法语、意大利语和葡萄牙语。
- `simba-english` 和 `simba-multilingual` 是旧版模型 ID。新 Workspace 请求这些 ID 时会收到 `model_retired` 错误。自 2026 年 11 月 21 日起，这两个 ID 分别由 `simba-3.2` 和 `simba-3.5` 提供服务。
- 默认音色取决于配置的模型。Simba 3 系列模型默认使用 `harper_32`，其他模型默认使用 `george`。
- Speechify 不支持语音转文本。
- 可通过 `speak()` 方法的 `options` 参数传入其他音频流选项。
