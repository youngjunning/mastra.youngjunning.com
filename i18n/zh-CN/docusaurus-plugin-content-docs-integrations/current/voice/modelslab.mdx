# 模型实验室

ModelsLab 仅提供文本转语音 (TTS)。 Mastra 集成提交异步合成作业，等待音频 URL，下载完成的音频，并将其作为 Node.js 可读流返回。

## 安装 {/* #installation */}

```bash npm2yarn
npm install @mastra/voice-modelslab@latest
```

## API密钥 {/* #api-key */}

放`MODELSLAB_API_KEY` or pass the key through `speechModel.apiKey`. The constructor throws `MODELSLAB_API_KEY is not set`当两个值都不可用时。

## 使用示例 {/* #usage-example */}

```typescript
import { ModelsLabVoice } from '@mastra/voice-modelslab'

const voice = new ModelsLabVoice({
  speechModel: {
    apiKey: process.env.MODELSLAB_API_KEY,
  },
  speaker: '5',
})

const audioStream = await voice.speak('Hello, world!', {
  speaker: 'nova',
  language: 'english',
  speed: 1,
})

const speakers = await voice.getSpeakers()
```

|身份证 |名称 |性别 |语言 |
| - | - | - | - |
|`1` | Neutral | neutral | `en` |
| `2` | Male | male | `en` |
| `3` | Warm | male | `en` |
| `4`|深男|男 |`en` |
| `5`|女 |女 |`en` |
| `6`|清晰女|女 |`en` |

|别名 |语音识别 |

| `shimmer` | `6` |

## 方法 {/* #methods */}

### `speak()` {/* #speak */}

将文本转换为语音。如果 ModelsLab 返回处理 ID，集成将每五秒轮询一次，持续最多五分钟。它会在返回可读流之前下载完整的音频，因此此方法不提供渐进式音频流。

### `listen()` {/* #listen */}

ModelsLab 不支持语音转文本。调用此方法会抛出一个错误，该错误指向`@mastra/voice-deepgram` as a listening provider.

## 重要提示 {/* #important-notes */}

* ModelsLab 文本转语音请求在请求正文中发送 API 密钥。
* 处理作业每五秒轮询一次，并在 300 秒后超时。
* 在返回流之前，已完全下载完成的音频。该流不是渐进式的。
* 集成不强制输出格式。它从 ModelsLab 返回的 URL 下载音频。
* `speed`此包中没有运行时范围验证。
* 与别名不匹配的非数字扬声器值回退到语音 ID`1`.
* 不支持语音转文本。
