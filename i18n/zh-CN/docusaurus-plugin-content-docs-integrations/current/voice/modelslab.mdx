# ModelsLab

ModelsLab 仅提供文本转语音（TTS）。Mastra 集成会提交异步合成任务，等到 ModelsLab 返回音频 URL 后下载合成好的音频，再以 Node.js 可读流的形式返回。

## 安装 {/* #installation */}

```bash npm2yarn
npm install @mastra/voice-modelslab@latest
```

## API 密钥 {/* #api-key */}

设置环境变量 `MODELSLAB_API_KEY`，或通过 `speechModel.apiKey` 传入密钥。如果两处都没有提供密钥，构造函数会抛出 `MODELSLAB_API_KEY is not set` 错误。

## 使用示例 {/* #usage-example */}

```typescript
import { ModelsLabVoice } from '@mastra/voice-modelslab'

const voice = new ModelsLabVoice({
  speechModel: {
    apiKey: process.env.MODELSLAB_API_KEY,
  },
  speaker: '5',
})

const audioStream = await voice.speak('Hello, world!', {
  speaker: 'nova',
  language: 'english',
  speed: 1,
})

const speakers = await voice.getSpeakers()
```

## 音色 {/* #voices */}

ModelsLab 提供六种内置英语音色：

| ID | 名称 | 性别 | 语言 |
| - | - | - | - |
| `1` | 中性音色 | 中性 | `en` |
| `2` | 男声 | 男 | `en` |
| `3` | 温暖男声 | 男 | `en` |
| `4` | 低沉男声 | 男 | `en` |
| `5` | 女声 | 女 | `en` |
| `6` | 清晰女声 | 女 | `en` |

这些 OpenAI 风格的别名对应以下音色 ID：

| 别名 | 音色 ID |
| - | - |
|`alloy` | `1` |
| `echo` | `2` |
| `fable` | `3` |
| `onyx` | `4` |
| `nova` | `5` |
| `shimmer` | `6` |

## 方法 {/* #methods */}

### `speak()` {/* #speak */}

将文本转换为语音。如果 ModelsLab 返回任务 ID，集成会每隔五秒查询一次任务状态，最多等待五分钟。此方法会先下载完整的音频，再返回可读流，因此无法边下载边输出音频。

### `listen()` {/* #listen */}

ModelsLab 不支持语音转文本。调用此方法会抛出错误，提示可使用 `@mastra/voice-deepgram` 作为语音转文本 Provider。

## 重要提示 {/* #important-notes */}

* 向 ModelsLab 发送文本转语音请求时，API 密钥放在请求体中。
* 合成任务每隔五秒轮询一次，等待超过 300 秒即超时。
* 音频完整下载后才会返回为流，无法边下载边输出。
* 集成不限定输出格式，直接从 ModelsLab 返回的 URL 下载音频。
* 此包在运行时不检查 `speed` 的取值范围。
* 如果传入的音色参数是非数字值且未匹配任何别名，则使用音色 ID `1`。
* 不支持语音转文本。
