# Gladia

Gladia 仅提供语音转文本（STT）功能。Mastra 集成会上传预录音频，等待 Gladia 完成转录，然后将合并后的转录文本作为字符串返回。

## 安装 {/* #installation */}

```bash npm2yarn
npm install @mastra/voice-gladia@latest
```

## API 密钥 {/* #api-key */}

设置 `GLADIA_API_KEY`，或通过 `listeningModel.apiKey` 传入密钥。如果两处都未提供可用的密钥，构造函数会抛出错误 `GLADIA_API_KEY is not set.`。

## 使用示例 {/* #usage-example */}

设置 `GLADIA_API_KEY` 即可使用默认配置：

```typescript
import { createReadStream } from 'node:fs'
import { GladiaVoice } from '@mastra/voice-gladia'

const voice = new GladiaVoice()
const audio = createReadStream('./audio.m4a')

const transcript = await voice.listen(audio, {
  fileName: 'audio.m4a',
  mimeType: 'audio/mp4',
  options: {
    diarization: true,
    detect_language: true,
  },
})
```

也可以直接传入 API 密钥：

```typescript
import { GladiaVoice } from '@mastra/voice-gladia'

const voice = new GladiaVoice({
  listeningModel: {
    apiKey: process.env.GLADIA_API_KEY,
  },
})
```

返回 `Promise<string>`，包含完整的转录文本。

### `speak()` {/* #speak */}

Gladia 不支持文本转语音。调用此方法会抛出错误 `Gladia does not support text-to-speech.`。

## 重要提示 {/* #important-notes */}

* Gladia 会对上传的预录音频执行转录任务。此软件包不支持流式转录。
* 上传前会先缓冲整个输入流。
* `listen()` 只返回 `full_transcript`，不返回按说话人划分的片段或响应中的其他元数据。
* 集成每秒查询一次任务状态，直到任务完成或失败。轮询没有超时限制。
* 必须提供 Gladia API 密钥。
