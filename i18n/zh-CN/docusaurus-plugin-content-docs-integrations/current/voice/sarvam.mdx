# Sarvam

Mastra 的 SarvamVoice 类调用 Sarvam AI 模型，将文本合成为语音，也能将语音转为文本。

## 使用示例 {/* #usage-example */}

```typescript
import { SarvamVoice } from '@mastra/voice-sarvam'

// Initialize with default configuration using environment variables
const voice = new SarvamVoice()

// Or initialize with specific configuration
const voiceWithConfig = new SarvamVoice({
  speechModel: {
    model: 'bulbul:v3',
    apiKey: process.env.SARVAM_API_KEY!,
    language: 'en-IN',
    properties: {
      pace: 1.0,
      temperature: 0.6,
      speech_sample_rate: 24000,
      output_audio_codec: 'wav',
    },
  },
  listeningModel: {
    model: 'saarika:v2.5',
    apiKey: process.env.SARVAM_API_KEY!,
    languageCode: 'en-IN',
    filetype: 'wav',
  },
  speaker: 'shubh', // Default voice for bulbul:v3
})

// Convert text to speech
const audioStream = await voice.speak('Hello, how can I help you?')

// Convert speech to text
const text = await voice.listen(audioStream, {
  filetype: 'wav',
})
```

## 注意事项 {/* #notes */}

* 可通过构造函数选项或 `SARVAM_API_KEY` 环境变量提供 API 密钥。
* 未提供 API 密钥时，构造函数会抛出错误。
* 该服务通过 `https://api.sarvam.ai` 调用 Sarvam AI API。
* 返回的音频流包含二进制音频数据。
* 语音识别支持 MP3 和 WAV 格式。
* Sarvam 已弃用 `bulbul:v1`、`saarika:v1`、`saarika:v2` 和 `saarika:flash`，并停止支持这些版本。语音合成请使用 `bulbul:v3` 或 `bulbul:v2`，语音识别请使用 `saarika:v2.5` 或 `saaras:v3`。
* `bulbul:v2` 和 `bulbul:v3` 各有自己的发音人列表，发音人名称无法跨版本使用。
