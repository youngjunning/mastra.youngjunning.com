# 助理界面

[助理界面](https://assistant-ui.com)是用于 AI 聊天的 TypeScript/React 库。它基于 shadcn/ui 和 Tailwind CSS 构建，使开发人员能够在几分钟内创建精美的企业级聊天体验。

：：：笔记

对于 Mastra 直接在 Next.js API 路由中运行的全栈集成方法，请参阅[Full-Stack Integration Guide](https://www.assistant-ui.com/docs/integrations/frameworks/mastra/full-stack) on Assistant UI's documentation site.

:::

参观马斯特拉[**"UI Dojo"**](https://ui-dojo.mastra.ai/) to see real-world examples of Assistant UI integrated with Mastra.

## 集成指南 {/* #integration-guide */}

将 Mastra 作为独立服务器运行，并将 Next.js 前端（带有 Assistant UI）连接到其 API 端点。

<Steps>
  <StepItem>
    设置您的目录结构。可能的目录结构如下所示：

    ```bash
    project-root
    ├── mastra-server
    │   ├── src
    │   │   └── mastra
    │   └── package.json
    └── my-app
        └── package.json
    ```

    引导您的 Mastra 服务器：

    ```bash
    npx create-mastra@latest
    ```

    此命令将启动一个交互式向导来帮助您构建新的 Mastra 项目，包括提示您输入项目名称和设置基本配置。按照提示创建服务器项目。

    导航到新创建的 Mastra 服务器目录：

    ```bash
    cd mastra-server # Replace with the actual directory name you provided
    ```

    您现在已经准备好了一个基本的 Mastra 服务器项目。您应该拥有以下文件和文件夹：

    ```bash
    src
    └── mastra
        ├── agents
        │   └── weather-agent.ts
        ├── scorers
        │   └── weather-scorer.ts
        ├── tools
        │   └── weather-tool.ts
        ├── workflows
        │   └── weather-workflow.ts
        └── index.ts
    ```

    ：：：笔记

    确保您已在中为您的 LLM Provider设置了适当的环境变量`.env` file.

    :::
  </StepItem>

  <StepItem>
    使用以下命令为 Assistant UI 前端创建聊天路由`chatRoute()` helper from `@mastra/ai-sdk`. Add it to your Mastra project:

    ```bash npm2yarn
    npm install @mastra/ai-sdk@latest
    ```

    在你的`src/mastra/index.ts` file, register the chat route:

    ```typescript title="src/mastra/index.ts" {2,7-13}
    import { Mastra } from '@mastra/core/mastra'
    import { chatRoute } from '@mastra/ai-sdk'
    // Rest of the imports...

    export const mastra = new Mastra({
      // Rest of the configuration...
      server: {
        apiRoutes: [
          chatRoute({
            path: '/chat/:agentId',
          }),
        ],
      },
    })
    ```

    这将使所有Agent以 AI SDK 兼容的格式提供，包括`weatherAgent` at the endpoint `/chat/weatherAgent`.
  </StepItem>

  <StepItem>
    使用以下命令运行 Mastra 服务器：

    ```bash
    npm run dev
    ```

    默认情况下，Mastra 服务器将运行在`http://localhost:4111`. Keep this server running for the next steps where we'll set up the Assistant UI frontend to connect to it.
  </StepItem>

  <StepItem>
    上一层目录到您的项目根目录。

    ```bash
    cd ..
    ```

    创建一个新的`assistant-ui` project with the following command.

    ```bash
    npx assistant-ui@latest create
    ```

    ：：：笔记

    有关详细设置说明，包括添加 API 密钥、基本配置和手动设置步骤，请参阅[assistant-ui's official documentation](https://assistant-ui.com/docs).

    :::
  </StepItem>

  <StepItem>
    默认的 Assistant UI 设置将聊天运行时配置为使用本地 API 路由（`/api/chat`) within the Next.js project. Since our Mastra agent is running on a separate server, we need to update the frontend to point to that server's endpoint.

    在 Assistant-ui 前端项目中打开包含以下内容的文件`useChatRuntime` hook (usually `app/assistant.tsx` or `src/app/assistant.tsx`). Find the `useChatRuntime` hook and change the `api` property to the full URL of your Mastra agent's stream endpoint:

    ```tsx {8} title="app/assistant.tsx"
    'use client'

    // Rest of the imports...

    export const Assistant = () => {
      const runtime = useChatRuntime({
        transport: new AssistantChatTransport({
          api: 'http://localhost:4111/chat/weatherAgent',
        }),
      })

      // Rest of the component...
    }
    ```

    现在，Assistant UI 前端将直接向正在运行的 Mastra 服务器发送聊天请求。
  </StepItem>

  <StepItem>
    您已准备好连接各个部分了！确保 Mastra 服务器和 Assistant UI 前端都在运行。启动 Next.js 开发服务器：

    ```bash
    npm run dev
    ```

    您现在应该可以在浏览器中与您的Agent聊天。
  </StepItem>
</Steps>

恭喜！您已使用单独的服务器方法成功地将 Mastra 与 Assistant UI 集成。您的 Assistant UI 前端现在与独立的 Mastra Agent服务器进行通信。
