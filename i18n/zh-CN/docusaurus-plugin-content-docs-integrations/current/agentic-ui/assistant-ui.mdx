# Assistant UI

[Assistant UI](https://assistant-ui.com) 是一个用于构建 AI 聊天界面的 TypeScript/React 库。它基于 shadcn/ui 和 Tailwind CSS，可帮助你在几分钟内搭建美观的企业级聊天界面。

:::note

如果希望在 Next.js API 路由中直接运行 Mastra，请参阅 Assistant UI 文档中的[全栈集成指南](https://www.assistant-ui.com/docs/integrations/frameworks/mastra/full-stack)。

:::

访问 Mastra 的 [**UI Dojo**](https://ui-dojo.mastra.ai/)，查看 Assistant UI 与 Mastra 集成的实际示例。

## 集成指南 {/* #integration-guide */}

独立运行 Mastra 服务器，再将使用 Assistant UI 的 Next.js 前端连接到该服务器的 API 端点。

<Steps>
  <StepItem>
    规划项目的目录结构，例如：

    ```bash
    project-root
    ├── mastra-server
    │   ├── src
    │   │   └── mastra
    │   └── package.json
    └── my-app
        └── package.json
    ```

    初始化 Mastra 服务器项目：

    ```bash
    npx create-mastra@latest
    ```

    此命令会启动交互式向导。根据提示输入项目名称并完成基本配置，即可创建 Mastra 服务器项目。

    进入刚创建的 Mastra 服务器目录：

    ```bash
    cd mastra-server # Replace with the actual directory name you provided
    ```

    基础的 Mastra 服务器项目已创建，其中应包含以下文件和目录：

    ```bash
    src
    └── mastra
        ├── agents
        │   └── weather-agent.ts
        ├── scorers
        │   └── weather-scorer.ts
        ├── tools
        │   └── weather-tool.ts
        ├── workflows
        │   └── weather-workflow.ts
        └── index.ts
    ```

    :::note

    确保已在 `.env` 文件中为所用的 LLM Provider 设置相应的环境变量。

    :::
  </StepItem>

  <StepItem>
    使用 `@mastra/ai-sdk` 提供的 `chatRoute()` 辅助函数为 Assistant UI 前端创建聊天路由。先在 Mastra 项目中安装该包：

    ```bash npm2yarn
    npm install @mastra/ai-sdk@latest
    ```

    在 `src/mastra/index.ts` 中注册聊天路由：

    ```typescript title="src/mastra/index.ts" {2,7-13}
    import { Mastra } from '@mastra/core/mastra'
    import { chatRoute } from '@mastra/ai-sdk'
    // Rest of the imports...

    export const mastra = new Mastra({
      // Rest of the configuration...
      server: {
        apiRoutes: [
          chatRoute({
            path: '/chat/:agentId',
          }),
        ],
      },
    })
    ```

    注册后，所有 Agent 都会以兼容 AI SDK 的格式提供响应。例如，可以通过 `/chat/weatherAgent` 访问 `weatherAgent`。
  </StepItem>

  <StepItem>
    运行以下命令启动 Mastra 服务器：

    ```bash
    npm run dev
    ```

    Mastra 服务器默认运行在 `http://localhost:4111`。保持服务器运行，后续步骤会配置 Assistant UI 前端连接到该地址。
  </StepItem>

  <StepItem>
    返回上一级目录，也就是项目根目录。

    ```bash
    cd ..
    ```

    运行以下命令创建 `assistant-ui` 项目。

    ```bash
    npx assistant-ui@latest create
    ```

    :::note

    有关添加 API 密钥、基本配置和手动设置的详细步骤，请参阅 [Assistant UI 官方文档](https://assistant-ui.com/docs)。

    :::
  </StepItem>

  <StepItem>
    默认情况下，Assistant UI 的聊天运行时使用 Next.js 项目内的本地 API 路由（`/api/chat`）。由于 Mastra Agent 运行在独立服务器上，需要将前端改为使用该服务器的端点。

    在 Assistant UI 前端项目中，打开包含 `useChatRuntime` Hook 的文件，通常是 `app/assistant.tsx` 或 `src/app/assistant.tsx`。找到 `useChatRuntime` 的调用，将 `api` 属性设为 Mastra Agent 流式端点的完整 URL：

    ```tsx {8} title="app/assistant.tsx"
    'use client'

    // Rest of the imports...

    export const Assistant = () => {
      const runtime = useChatRuntime({
        transport: new AssistantChatTransport({
          api: 'http://localhost:4111/chat/weatherAgent',
        }),
      })

      // Rest of the component...
    }
    ```

    修改后，Assistant UI 前端会将聊天请求直接发送到正在运行的 Mastra 服务器。
  </StepItem>

  <StepItem>
    保持 Mastra 服务器运行，并启动 Next.js 开发服务器，让 Assistant UI 前端也运行起来：

    ```bash
    npm run dev
    ```

    现在应该可以在浏览器中与 Agent 聊天了。
  </StepItem>
</Steps>

集成完成后，Assistant UI 前端会与独立运行的 Mastra Agent 服务器通信。
