# 开放用户界面

[开放用户界面](https://openui.com)是生成式 UI 的开放标准。它将紧凑的流优先语言 (OpenUI Lang) 与 React 运行时和内置组件库配对，因此模型输出可以像流式传输一样呈现结构化 UI。

OpenUI 通过以下方式连接到 Mastra[AG-UI protocol](https://docs.ag-ui.com). The `@ag-ui/mastra`适配器包裹着 Mastra`Agent`并发出 AG-UI 事件，OpenUI 的`agUIAdapter()`在客户端解析。

：：：提示

有关完整的工作示例，请参阅[`mastra-chat`](https://github.com/thesysdev/openui/tree/main/examples/mastra-chat) example in the OpenUI repository.

:::

## 集成指南 {/* #integration-guide */}

将 Mastra 嵌入您的 Next.js API 路由并连接 OpenUI`<AgentInterface />` chat surface to it through the AG-UI protocol.

<Steps>
  <StepItem>
    搭建一个新的 OpenUI 应用程序：

    ```bash npm2yarn
    npx @openuidev/cli@latest create --name openui-mastra-chat
    ```

    导航到新创建的项目目录：

    ```bash
    cd openui-mastra-chat
    ```

    脚手架应用程序是一个 Next.js 项目，具有以下结构：

    ```bash
    openui-mastra-chat
    └── src
        ├── app
        │   ├── api
        │   │   └── chat
        │   │       └── route.ts
        │   ├── globals.css
        │   ├── layout.tsx
        │   └── page.tsx
        ├── generated
        │   └── system-prompt.txt
        └── library.ts
    ```

    聊天路由位于`src/app/api/chat/route.ts`, the chat surface in `src/app/page.tsx`, and the component library in `src/library.ts`. The OpenUI CLI writes `src/generated/system-prompt.txt` from your library; regenerate it whenever the library changes.

    将您的 OpenAI 密钥添加到`.env.local`:

    ```bash title=".env.local"
    OPENAI_API_KEY=sk-...
    ```

    ：：：笔记

    OpenUI 需要模型提供者密钥。使用 Mastra 支持的任何提供程序并在下一步中调整Agent配置。

    :::
  </StepItem>

  <StepItem>
    安装 Mastra 软件包和 Mastra 的 AG-UI 适配器：

    ```bash npm2yarn
    npm install @mastra/core @ag-ui/mastra @ag-ui/core zod
    ```

    `@ag-ui/mastra`包裹玛斯特拉`Agent` in a `MastraAgent` that emits [AG-UI protocol](https://docs.ag-ui.com) events. OpenUI's `agUIAdapter()` consumes those events on the client.
  </StepItem>

  <StepItem>
    打开`src/app/api/chat/route.ts`. Define any tools your agent needs with `createTool` from `@mastra/core/tools`:

    ```typescript title="src/app/api/chat/route.ts"
    import { createTool } from '@mastra/core/tools'
    import { z } from 'zod'

    const getWeather = createTool({
      id: 'get_weather',
      description: 'Get current weather for a city.',
      inputSchema: z.object({ location: z.string().describe('City name') }),
      execute: async ({ location }) => {
        return { location, temperature_celsius: 22, condition: 'Clear' }
      },
    })
    ```

    包裹玛斯特拉`Agent` in `MastraAgent`. Inject the generated system prompt so the agent knows how to use the OpenUI component library:

    ```typescript title="src/app/api/chat/route.ts"
    import { MastraAgent } from '@ag-ui/mastra'
    import { Agent } from '@mastra/core/agent'
    import { readFileSync } from 'fs'
    import { join } from 'path'

    const systemPrompt = readFileSync(join(process.cwd(), 'src/generated/system-prompt.txt'), 'utf-8')

    const agent = new MastraAgent({
      agent: new Agent({
        id: 'openui-agent',
        name: 'OpenUI Agent',
        instructions: `You are a helpful assistant. Use tools when relevant.\n\n${systemPrompt}`,
        model: {
          id: '__GATEWAY_OPENAI_MODEL__',
          apiKey: process.env.OPENAI_API_KEY,
        },
        tools: { getWeather },
      }),
      resourceId: 'chat-user',
    })
    ```

    导出一个`POST` handler that streams the agent's AG-UI events as Server-Sent Events (SSE):

    ```typescript title="src/app/api/chat/route.ts"
    import type { Message } from '@ag-ui/core'
    import { NextRequest } from 'next/server'

    export async function POST(req: NextRequest) {
      const { messages, threadId }: { messages: Message[]; threadId: string } = await req.json()
      const encoder = new TextEncoder()

      const stream = new ReadableStream({
        start(controller) {
          const subscription = agent
            .run({ messages, threadId, runId: crypto.randomUUID(), tools: [], context: [] })
            .subscribe({
              next: event => {
                controller.enqueue(encoder.encode(`data: ${JSON.stringify(event)}\n\n`))
              },
              complete: () => {
                controller.enqueue(encoder.encode('data: [DONE]\n\n'))
                controller.close()
              },
              error: error => {
                controller.enqueue(
                  encoder.encode(`data: ${JSON.stringify({ error: error.message })}\n\n`),
                )
                controller.close()
              },
            })

          req.signal.addEventListener('abort', () => subscription.unsubscribe())
        },
      })

      return new Response(stream, {
        headers: {
          'Content-Type': 'text/event-stream',
          'Cache-Control': 'no-cache, no-transform',
          Connection: 'keep-alive',
        },
      })
    }
    ```
  </StepItem>

  <StepItem>
    连接 OpenUI`<AgentInterface />` chat surface to the route. Build an `llm` adapter with `fetchLLM()` and set `streamAdapter` to `agUIAdapter()` so OpenUI knows to parse AG-UI events.

    ```tsx title="src/app/page.tsx" {5,8-11,17}
    'use client'

    import '@openuidev/react-ui/components.css'

    import { AgentInterface, agUIAdapter, fetchLLM } from '@openuidev/react-ui'
    import { openuiChatLibrary } from '@openuidev/react-ui/genui-lib'

    const llm = fetchLLM({
      url: '/api/chat',
      streamAdapter: agUIAdapter(),
    })

    export default function Page() {
      return (
        <div className="relative h-screen w-screen overflow-hidden">
          <AgentInterface llm={llm} componentLibrary={openuiChatLibrary} />
        </div>
      )
    }
    ```

    这`componentLibrary` prop controls which components the model can generate. Replace `openuiChatLibrary` with your own library to restrict or extend the output.
  </StepItem>

  <StepItem>
    启动开发服务器：

    ```bash npm2yarn
    npm run dev
    ```

    打开[http://localhost:3000](http://localhost:3000). You can now chat with your Mastra agent through the OpenUI chat surface, with structured UI rendered progressively as the model streams.
  </StepItem>
</Steps>

## 使用 AG-UI 进行流式传输 {/* #streaming-with-ag-ui */}

OpenUI 消耗[AG-UI protocol](https://docs.ag-ui.com), a transport-agnostic stream of typed events for AI agents. `@ag-ui/mastra` translates a Mastra `Agent` into this protocol:

* 服务器调用`agent.run({ messages, threadId, runId, ... })` and serializes each emitted event as an SSE message.
* 客户端通过`fetchLLM({ streamAdapter: agUIAdapter() })` to `<AgentInterface />`, which parses the SSE stream into the internal events that drive OpenUI Lang rendering.

`threadId`将跨请求的对话联系在一起，并且`runId` identifies a single execution. Generate a fresh `runId` per request and persist `threadId` on the client.

## 组件库 {/* #component-libraries */}

OpenUI 从组件库生成 UI。该库定义了哪些组件可用、它们的 props 以及如何指示模型使用它们。

### 内置库 {/* #built-in-libraries */}

`@openuidev/react-ui`提供了两个可以按原样使用的库：

* `openuiChatLibrary`：聊天界面的组件（卡片、表单、表格、图表）。
* `openuiDashboardLibrary`：仪表板和数据密集型表面的组件。

将库传递给`<AgentInterface componentLibrary={...} />` to make its components available to the model.

### 定制库 {/* #customizing-the-library */}

要限制或扩展输出，请在中定义您自己的库`src/library.ts` and export a subset of components. Pass that library to `<AgentInterface />` and regenerate the system prompt whenever the library changes:

```bash npm2yarn
npx @openuidev/cli generate src/library.ts --out src/generated/system-prompt.txt
```

生成的提示由 API 路由读取并合并到Agent的提示中`instructions`, so the agent knows exactly which components it can emit.
