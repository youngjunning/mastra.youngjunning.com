# OpenUI

[OpenUI](https://openui.com) 是生成式界面的一项开放标准。它结合了专为流式输出设计的精简语言 OpenUI Lang、React 运行时和内置组件库，让模型可以边输出，界面边渲染。

OpenUI 通过 [AG-UI 协议](https://docs.ag-ui.com) 接入 Mastra。`@ag-ui/mastra` 适配器封装 Mastra `Agent` 并发出 AG-UI 事件，OpenUI 的 `agUIAdapter()` 则在客户端解析这些事件。

:::tip

OpenUI 仓库中的 [`mastra-chat`](https://github.com/thesysdev/openui/tree/main/examples/mastra-chat) 是一个完整、可运行的示例。

:::

## 集成指南 {/* #integration-guide */}

将 Mastra 嵌入 Next.js API 路由，再通过 AG-UI 协议将 OpenUI 的 `<AgentInterface />` 聊天界面接入该路由。

<Steps>
  <StepItem>
    用脚手架创建 OpenUI 应用：

    ```bash npm2yarn
    npx @openuidev/cli@latest create --name openui-mastra-chat
    ```

    进入新建的项目目录：

    ```bash
    cd openui-mastra-chat
    ```

    生成的 Next.js 项目结构如下：

    ```bash
    openui-mastra-chat
    └── src
        ├── app
        │   ├── api
        │   │   └── chat
        │   │       └── route.ts
        │   ├── globals.css
        │   ├── layout.tsx
        │   └── page.tsx
        ├── generated
        │   └── system-prompt.txt
        └── library.ts
    ```

    聊天路由位于 `src/app/api/chat/route.ts`，聊天界面位于 `src/app/page.tsx`，组件库位于 `src/library.ts`。OpenUI CLI 根据组件库生成 `src/generated/system-prompt.txt`；每次修改组件库后，都要重新生成这个文件。

    将 OpenAI 密钥添加到 `.env.local`：

    ```bash title=".env.local"
    OPENAI_API_KEY=sk-...
    ```

    :::note

    OpenUI 需要模型 Provider 的 API 密钥。你可以选用 Mastra 支持的任意 Provider，并在下一步相应调整 Agent 配置。

    :::
  </StepItem>

  <StepItem>
    安装 Mastra 软件包和适用于 Mastra 的 AG-UI 适配器：

    ```bash npm2yarn
    npm install @mastra/core @ag-ui/mastra @ag-ui/core zod
    ```

    `@ag-ui/mastra` 将 Mastra `Agent` 封装在 `MastraAgent` 中，由后者发出 [AG-UI 协议](https://docs.ag-ui.com)事件。OpenUI 的 `agUIAdapter()` 在客户端接收这些事件。
  </StepItem>

  <StepItem>
    打开 `src/app/api/chat/route.ts`，使用 `@mastra/core/tools` 提供的 `createTool` 定义 Agent 所需的 Tool：

    ```typescript title="src/app/api/chat/route.ts"
    import { createTool } from '@mastra/core/tools'
    import { z } from 'zod'

    const getWeather = createTool({
      id: 'get_weather',
      description: 'Get current weather for a city.',
      inputSchema: z.object({ location: z.string().describe('City name') }),
      execute: async ({ location }) => {
        return { location, temperature_celsius: 22, condition: 'Clear' }
      },
    })
    ```

    用 `MastraAgent` 封装 Mastra `Agent`，并注入生成的系统提示词，告诉 Agent 如何使用 OpenUI 组件库：

    ```typescript title="src/app/api/chat/route.ts"
    import { MastraAgent } from '@ag-ui/mastra'
    import { Agent } from '@mastra/core/agent'
    import { readFileSync } from 'fs'
    import { join } from 'path'

    const systemPrompt = readFileSync(join(process.cwd(), 'src/generated/system-prompt.txt'), 'utf-8')

    const agent = new MastraAgent({
      agent: new Agent({
        id: 'openui-agent',
        name: 'OpenUI Agent',
        instructions: `You are a helpful assistant. Use tools when relevant.\n\n${systemPrompt}`,
        model: {
          id: '__GATEWAY_OPENAI_MODEL__',
          apiKey: process.env.OPENAI_API_KEY,
        },
        tools: { getWeather },
      }),
      resourceId: 'chat-user',
    })
    ```

    导出 `POST` 处理函数，通过服务器发送事件（SSE）将 Agent 的 AG-UI 事件流式传给客户端：

    ```typescript title="src/app/api/chat/route.ts"
    import type { Message } from '@ag-ui/core'
    import { NextRequest } from 'next/server'

    export async function POST(req: NextRequest) {
      const { messages, threadId }: { messages: Message[]; threadId: string } = await req.json()
      const encoder = new TextEncoder()

      const stream = new ReadableStream({
        start(controller) {
          const subscription = agent
            .run({ messages, threadId, runId: crypto.randomUUID(), tools: [], context: [] })
            .subscribe({
              next: event => {
                controller.enqueue(encoder.encode(`data: ${JSON.stringify(event)}\n\n`))
              },
              complete: () => {
                controller.enqueue(encoder.encode('data: [DONE]\n\n'))
                controller.close()
              },
              error: error => {
                controller.enqueue(
                  encoder.encode(`data: ${JSON.stringify({ error: error.message })}\n\n`),
                )
                controller.close()
              },
            })

          req.signal.addEventListener('abort', () => subscription.unsubscribe())
        },
      })

      return new Response(stream, {
        headers: {
          'Content-Type': 'text/event-stream',
          'Cache-Control': 'no-cache, no-transform',
          Connection: 'keep-alive',
        },
      })
    }
    ```
  </StepItem>

  <StepItem>
    将 OpenUI 的 `<AgentInterface />` 聊天界面接入该路由。用 `fetchLLM()` 创建 `llm` 适配器，并将 `streamAdapter` 设为 `agUIAdapter()`，让 OpenUI 能够解析 AG-UI 事件。

    ```tsx title="src/app/page.tsx" {5,8-11,17}
    'use client'

    import '@openuidev/react-ui/components.css'

    import { AgentInterface, agUIAdapter, fetchLLM } from '@openuidev/react-ui'
    import { openuiChatLibrary } from '@openuidev/react-ui/genui-lib'

    const llm = fetchLLM({
      url: '/api/chat',
      streamAdapter: agUIAdapter(),
    })

    export default function Page() {
      return (
        <div className="relative h-screen w-screen overflow-hidden">
          <AgentInterface llm={llm} componentLibrary={openuiChatLibrary} />
        </div>
      )
    }
    ```

    `componentLibrary` 属性决定模型能生成哪些组件。用自己的组件库替换 `openuiChatLibrary`，就能缩小或扩大可生成组件的范围。
  </StepItem>

  <StepItem>
    启动开发服务器：

    ```bash npm2yarn
    npm run dev
    ```

    打开 [http://localhost:3000](http://localhost:3000)。现在可以在 OpenUI 聊天界面中与 Mastra Agent 对话，结构化界面会随模型输出逐步渲染。
  </StepItem>
</Steps>

## 通过 AG-UI 流式传输 {/* #streaming-with-ag-ui */}

OpenUI 接收 [AG-UI 协议](https://docs.ag-ui.com)定义的事件流。该协议面向 AI Agent，事件带有类型，且不依赖特定的传输方式。`@ag-ui/mastra` 将 Mastra `Agent` 的输出转换为符合该协议的事件：

* 服务器调用 `agent.run({ messages, threadId, runId, ... })`，将发出的每个事件序列化为一条 SSE 消息。
* 客户端将 `fetchLLM({ streamAdapter: agUIAdapter() })` 的返回值传给 `<AgentInterface />`。该组件将 SSE 流解析为内部事件，用于驱动 OpenUI Lang 渲染。

`threadId` 用于在多次请求中标识同一场对话，`runId` 则标识单次执行。每次请求都要生成新的 `runId`，并在客户端持久保存 `threadId`。

## 组件库 {/* #component-libraries */}

OpenUI 根据组件库生成界面。组件库定义可用的组件、各组件的属性，以及指导模型使用这些组件的方式。

### 内置组件库 {/* #built-in-libraries */}

`@openuidev/react-ui` 提供两个可直接使用的组件库：

* `openuiChatLibrary`：聊天界面的组件（卡片、表单、表格、图表）。
* `openuiDashboardLibrary`：适用于仪表板和数据密集型界面的组件。

通过 `<AgentInterface componentLibrary={...} />` 传入组件库，模型就可以使用其中的组件。

### 自定义组件库 {/* #customizing-the-library */}

要缩小或扩大模型可生成组件的范围，请在 `src/library.ts` 中定义自己的组件库，并导出选定的组件。将该库传给 `<AgentInterface />`，并在每次修改组件库后重新生成系统提示词：

```bash npm2yarn
npx @openuidev/cli generate src/library.ts --out src/generated/system-prompt.txt
```

API 路由读取生成的系统提示词，并将其合并到 Agent 的 `instructions` 中，让 Agent 明确哪些组件可以出现在输出中。
