# 平行线

这`@mastra/parallel`封装暴露[并行搜索](https://docs.parallel.ai/search/search-quickstart)和[提炼](https://docs.parallel.ai/extract/extract-quickstart)作为 Mastra 兼容Tool。每个工厂返回一个创建的Tool[`createTool()`](/reference/tools/create-tool)以及类型化的 Zod 输入和输出模式。

## 安装 {/* #installation */}

```bash npm2yarn
npm install @mastra/parallel parallel-web zod
```

放`PARALLEL_API_KEY` in your environment. You can also pass an API key directly to any factory.

## 快速启动 {/* #quick-start */}

使用`createParallelTools()` to create both tools with shared client configuration:

```typescript title="src/mastra/tools/index.ts"
import { createParallelTools } from '@mastra/parallel'

export const parallelTools = createParallelTools()
// Or pass an explicit API key:
// export const parallelTools = createParallelTools({ apiKey: 'parallel-api-key' })
```

返回的对象包含`parallelSearch` and `parallelExtract`.

当Agent不需要同时创建这两个Tool时，请单独创建其中一个Tool：

```typescript title="src/mastra/tools/index.ts"
import { createParallelExtractTool, createParallelSearchTool } from '@mastra/parallel'

export const searchTool = createParallelSearchTool()
export const extractTool = createParallelExtractTool({ apiKey: 'parallel-api-key' })
```

在该Tool执行之前客户端不会初始化。因此，缺少 API 密钥会在执行时失败并出现配置错误。

## 与Agent一起使用Tool {/* #use-the-tools-with-an-agent */}

```typescript title="src/mastra/agents/research-agent.ts"
import { Agent } from '@mastra/core/agent'
import { createParallelTools } from '@mastra/parallel'

export const researchAgent = new Agent({
  id: 'research-agent',
  name: 'Research Agent',
  model: '__GATEWAY_ANTHROPIC_MODEL_SONNET__',
  instructions:
    'Search the web for current sources, then extract relevant content from the best pages.',
  tools: createParallelTools(),
})
```
