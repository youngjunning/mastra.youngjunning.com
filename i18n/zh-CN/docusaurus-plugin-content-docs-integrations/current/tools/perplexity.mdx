# 困惑

这`@mastra/perplexity`包装包裹着[困惑度搜索 API](https://docs.perplexity.ai/docs/search/quickstart)作为与 Mastra 兼容的Tool。它公开了一个工厂函数，该函数返回使用以下命令创建的Tool[`createTool()`](/reference/tools/create-tool)以及完整的 Zod 输入/输出模式。

对于由 Perplexity 支持的聊天完成或AgentWorkflow程，请使用 Mastra 的内置功能[Perplexity model provider](/models/providers/perplexity) or [Perplexity Agent provider](/models/providers/perplexity-agent). Those are separate from this Search tool.

## 安装 {/* #installation */}

与 Zod 一起安装该软件包：

```sh npm2yarn
npm install @mastra/perplexity zod
```

## 使用示例 {/* #usage-example */}

以下示例使用默认配置创建搜索Tool。默认情况下，该Tool读取`PERPLEXITY_API_KEY` (with `PPLX_API_KEY` as a fallback) from the environment. Pass `{ apiKey }` explicitly to override.

```typescript title="src/mastra/tools/index.ts"
import { createPerplexitySearchTool } from '@mastra/perplexity'

const searchTool = createPerplexitySearchTool()
```

要显式传递 API 密钥：

```typescript title="src/mastra/tools/index.ts"
import { createPerplexitySearchTool } from '@mastra/perplexity'

const searchTool = createPerplexitySearchTool({ apiKey: 'pplx-...' })
```

## 方法 {/* #methods */}

### 工厂功能 {/* #factory-functions */}

#### `createPerplexityTools(config?)` {/* #createperplexitytoolsconfig */}

返回一个对象，其中包含共享所提供配置的所有 Perplexity Tool。

```typescript
import { createPerplexityTools } from '@mastra/perplexity'

const tools = createPerplexityTools({ apiKey: 'pplx-...' })
// tools.perplexitySearch
```

返回：`{ perplexitySearch }`

#### `createPerplexitySearchTool(config?)` {/* #createperplexitysearchtoolconfig */}

创建一个使用 Perplexity Search API 搜索网络的Tool。返回带有标题、URL、摘要和可选发布日期的排名结果。

该Tool已使用 ID 注册`perplexity-search`.

```typescript
import { createPerplexitySearchTool } from '@mastra/perplexity'

const searchTool = createPerplexitySearchTool()
```

## Agent示例 {/* #agent-example */}

以下示例在Agent上注册搜索Tool，以便它可以在应答之前获取新的 Web 结果。

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { createPerplexitySearchTool } from '@mastra/perplexity'

const agent = new Agent({
  id: 'research-agent',
  name: 'Research Agent',
  model: '__GATEWAY_ANTHROPIC_MODEL_SONNET__',
  instructions:
    'You are a research assistant. Use the perplexity-search tool to find up-to-date information from the web before answering.',
  tools: {
    search: createPerplexitySearchTool(),
  },
})
```

## 环境变量 {/* #environment-variables */}

|变量|描述 |
| - | - |
|`PERPLEXITY_API_KEY` | Your Perplexity API key. Used as the default when `apiKey` isn't passed to a factory function. |
| `PPLX_API_KEY` | Fallback used when `PERPLEXITY_API_KEY` is unset. |
