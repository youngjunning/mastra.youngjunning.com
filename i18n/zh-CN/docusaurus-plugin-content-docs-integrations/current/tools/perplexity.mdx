# Perplexity

`@mastra/perplexity` 将 [Perplexity Search API](https://docs.perplexity.ai/docs/search/quickstart) 封装为与 Mastra 兼容的 Tool。该包提供一个工厂函数，返回通过 [`createTool()`](/reference/tools/create-tool) 创建的 Tool，并为输入和输出提供完整的 Zod Schema。

要使用 Perplexity 生成聊天补全或运行由 Agent 驱动的 Workflow，请使用 Mastra 内置的 [Perplexity 模型 Provider](/models/providers/perplexity) 或 [Perplexity Agent Provider](/models/providers/perplexity-agent)。这两个 Provider 独立于此搜索 Tool。

## 安装 {/* #installation */}

同时安装 `@mastra/perplexity` 和 Zod：

```sh npm2yarn
npm install @mastra/perplexity zod
```

## 使用示例 {/* #usage-example */}

以下示例使用默认配置创建搜索 Tool。Tool 优先读取环境变量 `PERPLEXITY_API_KEY`，未设置时改用 `PPLX_API_KEY`。显式传入 `{ apiKey }` 可覆盖这一默认行为。

```typescript title="src/mastra/tools/index.ts"
import { createPerplexitySearchTool } from '@mastra/perplexity'

const searchTool = createPerplexitySearchTool()
```

也可以显式传入 API 密钥：

```typescript title="src/mastra/tools/index.ts"
import { createPerplexitySearchTool } from '@mastra/perplexity'

const searchTool = createPerplexitySearchTool({ apiKey: 'pplx-...' })
```

## 方法 {/* #methods */}

### 工厂函数 {/* #factory-functions */}

#### `createPerplexityTools(config?)` {/* #createperplexitytoolsconfig */}

返回包含所有 Perplexity Tool 的对象，其中的 Tool 共用传入的配置。

```typescript
import { createPerplexityTools } from '@mastra/perplexity'

const tools = createPerplexityTools({ apiKey: 'pplx-...' })
// tools.perplexitySearch
```

返回：`{ perplexitySearch }`

#### `createPerplexitySearchTool(config?)` {/* #createperplexitysearchtoolconfig */}

创建一个通过 Perplexity Search API 搜索网页的 Tool。搜索结果按排名返回，每条结果包含标题、URL 和内容摘要，有发布日期时也会一并返回。

该 Tool 的注册 ID 为 `perplexity-search`。

```typescript
import { createPerplexitySearchTool } from '@mastra/perplexity'

const searchTool = createPerplexitySearchTool()
```

## Agent 示例 {/* #agent-example */}

以下示例将搜索 Tool 注册到 Agent，使它能在回答前获取最新的网页搜索结果。

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { createPerplexitySearchTool } from '@mastra/perplexity'

const agent = new Agent({
  id: 'research-agent',
  name: 'Research Agent',
  model: '__GATEWAY_ANTHROPIC_MODEL_SONNET__',
  instructions:
    'You are a research assistant. Use the perplexity-search tool to find up-to-date information from the web before answering.',
  tools: {
    search: createPerplexitySearchTool(),
  },
})
```

## 环境变量 {/* #environment-variables */}

| 变量 | 说明 |
| - | - |
| `PERPLEXITY_API_KEY` | 你的 Perplexity API 密钥。调用工厂函数时未传入 `apiKey`，默认使用此变量。 |
| `PPLX_API_KEY` | 未设置 `PERPLEXITY_API_KEY` 时使用的备用变量。 |
