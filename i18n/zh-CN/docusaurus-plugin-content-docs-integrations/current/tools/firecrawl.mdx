# Firecrawl

Firecrawl 是一个 Web 数据 API，可将网站内容转换为干净的 Markdown 或结构化 JSON。本指南将介绍如何将 Firecrawl 接入 Mastra Tool，让 Agent 和 Workflow 能按需搜索和抓取实时 Web 数据。

## 前置条件 {/* #prerequisites */}

- 已安装 Node.js `v22.13.0` 或更高版本
- Firecrawl API 密钥（可在 [https://firecrawl.dev](https://firecrawl.dev) 获取）
- 由受支持的 [Model Provider](/models) 提供的 API 密钥
- 一个已有的 Mastra 项目。可按[入门指南](/docs)创建。

## 安装 {/* #installation */}

安装 Firecrawl SDK：

```bash npm2yarn
npm install firecrawl
```

## 配置环境变量 {/* #configure-environment-variables */}

在项目根目录创建 `.env` 文件：

```bash title=".env"
FIRECRAWL_API_KEY=fc-your-api-key
# Optional: FIRECRAWL_API_URL=http://localhost:3002
```

## 构建 Firecrawl Tool {/* #build-the-firecrawl-tools */}

创建一个 Tool 文件，让 Mastra 可以调用 Firecrawl 的搜索和抓取功能。

<Steps>
  <StepItem>
    创建 `src/mastra/tools/firecrawl.ts` 并配置 Firecrawl：

    ```ts title="src/mastra/tools/firecrawl.ts"
    import { Firecrawl } from 'firecrawl'
    import { createTool } from '@mastra/core/tools'
    import { z } from 'zod'

    const firecrawl = new Firecrawl({ apiKey: process.env.FIRECRAWL_API_KEY! })

    export const firecrawlSearch = createTool({
      id: 'firecrawl-search',
      description: 'Search the web and return top results.',
      inputSchema: z.object({ query: z.string().min(1) }),
      outputSchema: z.object({
        results: z.array(
          z.object({
            title: z.string().nullable(),
            url: z.string(),
          }),
        ),
      }),
      execute: async ({ query }) => {
        const results = await firecrawl.search(query, { limit: 3 })
        return {
          results: (results.web ?? []).map(item => ({
            title: item.title ?? null,
            url: item.url,
          })),
        }
      },
    })

    export const firecrawlScrape = createTool({
      id: 'firecrawl-scrape',
      description: 'Scrape a URL and return markdown content.',
      inputSchema: z.object({ url: z.string().url() }),
      outputSchema: z.object({ markdown: z.string() }),
      execute: async ({ url }) => {
        const result = await firecrawl.scrape(url, {
          formats: ['markdown'],
          onlyMainContent: true,
        })
        return { markdown: result.markdown ?? '' }
      },
    })
    ```
  </StepItem>

  <StepItem>
    在 `src/mastra/agents/web-agent.ts` 中创建一个新的 Agent：

    ```ts title="src/mastra/agents/web-agent.ts"
    import { Agent } from '@mastra/core/agent'
    import { firecrawlSearch, firecrawlScrape } from '../tools/firecrawl'

    export const webAgent = new Agent({
      id: 'web-agent',
      name: 'Web Agent',
      instructions: 'Use Firecrawl tools to search and scrape web pages, then summarize the results.',
      model: '__GATEWAY_OPENAI_MODEL__',
      tools: { firecrawlSearch, firecrawlScrape },
    })
    ```
  </StepItem>

  <StepItem>
    在 `src/mastra/index.ts` 中将新创建的 Agent 注册到你的 Mastra 实例：

    ```ts title="src/mastra/index.ts" {2, 5}
    import { Mastra } from '@mastra/core'
    import { webAgent } from './agents/web-agent'

    export const mastra = new Mastra({
      agents: { webAgent },
    })
    ```
  </StepItem>
</Steps>

## 在 Studio 中测试 {/* #test-in-studio */}

启动开发服务器并打开 [Studio](/docs/studio/overview)：

```bash
mastra dev
```

在 Studio 中打开 **Web Agent**，试着输入以下内容：

- “查找 Mastra 最新的变更日志，并总结最近一次发布的内容。”
- “搜索 Firecrawl 的定价，并提取各个套餐档位。”

## 自托管 Firecrawl {/* #self-hosted-firecrawl */}

如果你在本地运行 Firecrawl，请设置 `FIRECRAWL_API_URL`，或向客户端传入 `apiUrl`：

```ts title="src/mastra/tools/firecrawl.ts"
const firecrawl = new Firecrawl({
  apiKey: process.env.FIRECRAWL_API_KEY!,
  apiUrl: process.env.FIRECRAWL_API_URL,
})
```
