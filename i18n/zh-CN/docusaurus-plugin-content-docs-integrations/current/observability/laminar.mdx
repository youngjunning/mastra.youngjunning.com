# Laminar

[Laminar](https://laminar.sh/) 是一个原生支持 OpenTelemetry 的开源 AI Agent Observability 平台。只需在 `Observability` 配置中接入一个 `MastraExporter`，即可跟踪、调试和监控 Mastra 中的每次 Agent 运行、每个 Model 步骤、每次 Tool 调用以及每个子 Agent。

## 安装 {/* #installation */}

```bash npm2yarn
npm install @lmnr-ai/lmnr
```

## 配置 {/* #configuration */}

### 前提条件 {/* #prerequisites */}

1. **Laminar 项目**：在 Laminar 中创建或选择一个项目
1. **项目 API 密钥**：从 Laminar 的项目设置中复制密钥
1. **环境变量**：通过环境变量设置凭据

```bash title=".env"
# Required
LMNR_PROJECT_API_KEY=lmnr_...

# Optional
LMNR_BASE_URL=https://api.lmnr.ai
```

### 零配置用法 {/* #zero-config-setup */}

设置环境变量后，无需额外配置即可使用导出器：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { Laminar, MastraExporter } from '@lmnr-ai/lmnr'

Laminar.initialize()

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      laminar: {
        serviceName: 'my-service',
        exporters: [new MastraExporter()],
      },
    },
  }),
})
```

### 显式配置 {/* #explicit-configuration */}

也可以直接传入凭据。直接传入的凭据优先于环境变量中的凭据：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { Laminar, MastraExporter } from '@lmnr-ai/lmnr'

Laminar.initialize({
  projectApiKey: process.env.LMNR_PROJECT_API_KEY!,
  baseUrl: process.env.LMNR_BASE_URL, // Optional
  // ...other options
})

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      laminar: {
        serviceName: 'my-service',
        exporters: [
          new MastraExporter({
            realtime: process.env.NODE_ENV === 'development', // Optional
          }),
        ],
      },
    },
  }),
})
```

:::note
有关高级用法，包括 `MastraExporter` 的完整选项和多 Agent Trace 示例，请参阅 [Laminar 的 Mastra 集成指南](https://laminar.sh/docs/tracing/integrations/mastra)。
:::

Mastra 还在 `@mastra/laminar` 中提供了独立的 [`LaminarExporter`](/reference/observability/tracing/exporters/laminar)，通过 OTLP/HTTP 发送 Span。它无法继承当前活动的 OTel 上下文，也无法将 Mastra 的 Span 完整映射到 Laminar 的原生格式。因此，如需使用 `observe()` 包装器、记录多 Agent 的根 Span，或在 Laminar 中准确呈现结果，请使用上文介绍的 `@lmnr-ai/lmnr` 集成。
