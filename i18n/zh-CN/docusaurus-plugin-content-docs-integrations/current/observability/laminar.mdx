# 层

[层](https://laminar.sh/)是一个面向 AI Agent的开源 OpenTelemetry 原生可观测平台。使用一个单一的跟踪、调试和监控每个 Mastra Agent运行、模型步骤、Tool调用和子Agent`MastraExporter`连接到你的`Observability`配置。

## 安装 {/* #installation */}

```bash npm2yarn
npm install @lmnr-ai/lmnr
```

## 配置 {/* #configuration */}

### 先决条件 {/* #prerequisites */}

1. **层流项目**：在 Laminar 中创建/选择项目
2. **项目 API 密钥**：从层流项目设置复制
3. **环境变量**：设置您的凭据

```bash title=".env"
# Required
LMNR_PROJECT_API_KEY=lmnr_...

# Optional
LMNR_BASE_URL=https://api.lmnr.ai
```

### 零配置设置 {/* #zero-config-setup */}

设置环境变量后，无需配置即可使用导出器：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { Laminar, MastraExporter } from '@lmnr-ai/lmnr'

Laminar.initialize()

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      laminar: {
        serviceName: 'my-service',
        exporters: [new MastraExporter()],
      },
    },
  }),
})
```

### 显式配置 {/* #explicit-configuration */}

您还可以直接传递凭据（优先于环境变量）：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { Laminar, MastraExporter } from '@lmnr-ai/lmnr'

Laminar.initialize({
  projectApiKey: process.env.LMNR_PROJECT_API_KEY!,
  baseUrl: process.env.LMNR_BASE_URL, // Optional
  // ...other options
})

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      laminar: {
        serviceName: 'my-service',
        exporters: [
          new MastraExporter({
            realtime: process.env.NODE_ENV === 'development', // Optional
          }),
        ],
      },
    },
  }),
})
```

:::注意
对于高级用法，包括完整的`MastraExporter` options and multi-agent trace examples, see [Laminar's Mastra integration guide](https://laminar.sh/docs/tracing/integrations/mastra).
:::

Mastra 还包括一个独立的[`LaminarExporter`](/reference/observability/tracing/exporters/laminar) in `@mastra/laminar` that sends spans over OTLP/HTTP. It can't inherit an active OTel context and doesn't fully map Mastra spans to Laminar's native format, so use the `@lmnr-ai/lmnr` integration above for `observe()` wrappers, multi-agent root spans, and accurate Laminar rendering.
