# Confident AI

[Confident AI](https://www.confident-ai.com/) 是一个面向 LLM 的 Observability 和评估平台，帮助团队在开发和生产环境中构建可靠的 AI 应用。

[`confident-trace`](https://github.com/confident-ai/confident-trace) 包中的 `ConfidentMastraExporter` 会将 Mastra Trace 发送到 Confident AI。Confident AI 会展示每次 Agent 运行中完整的 Agent、Model 和 Tool 层级结构，并可在收到运行数据时自动评分。

## 安装 {/* #installation */}

```bash npm2yarn
npm install confident-trace@latest
```

## 配置 {/* #configuration */}

### 前提条件 {/* #prerequisites */}

1. **Confident AI 账号**：在 [confident-ai.com](https://app.confident-ai.com) 注册账号
1. **API 密钥**：在 Confident AI 项目设置中生成密钥
1. **环境变量**：通过以下环境变量设置凭据：

```bash title=".env"
CONFIDENT_API_KEY=confident_proj_xxxxxxxxxxxxx

# Optional. EU region, defaults to the US servers
CONFIDENT_OTEL_ENDPOINT=https://eu.otel.confident-ai.com/v1/traces
```

### 零配置使用 {/* #zero-config-setup */}

设置环境变量后，无需额外配置即可使用导出器：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { ConfidentMastraExporter } from 'confident-trace/mastra'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      confidentAI: {
        serviceName: 'my-service',
        exporters: [new ConfidentMastraExporter()],
      },
    },
  }),
})
```

### 显式配置 {/* #explicit-configuration */}

也可以直接传入凭据，此时传入的凭据优先于环境变量中的凭据：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { ConfidentMastraExporter } from 'confident-trace/mastra'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      confidentAI: {
        serviceName: 'my-service',
        exporters: [
          new ConfidentMastraExporter({
            apiKey: process.env.CONFIDENT_API_KEY,
            endpoint: process.env.CONFIDENT_OTEL_ENDPOINT,
          }),
        ],
      },
    },
  }),
})
```

可以使用以下选项：

```typescript
new ConfidentMastraExporter({
  apiKey: process.env.CONFIDENT_API_KEY, // Default: CONFIDENT_API_KEY
  endpoint: process.env.CONFIDENT_OTEL_ENDPOINT, // Default: US servers
  captureContent: false, // Omit inputs, outputs, and messages
  maxContentBytes: 512, // Truncate captured content
  timeoutMillis: 30000, // Flush and shutdown budget
  resourceAttributes: { 'service.name': 'my-agent' }, // Overrides serviceName
})
```

Trace 使用 Mastra 配置的 `serviceName`，除非 `resourceAttributes['service.name']` 覆盖了该值。Mastra 自身的采样、过滤器和 Span 处理器都在导出前运行，因此 Confident AI 只会收到流水线放行的数据。

## 支持的信号 {/* #supported-signals */}

导出器将已结束的 Mastra Span 转换为 OTLP Span，并保留 Trace ID、Span ID、父级 ID、外部父级 ID 和原始时间戳。导出器无需缓存开始事件，因此即使 Workflow 恢复执行或 Span 未按顺序结束，也能正确导出这些 Span。

- **Agent 和 Workflow 的执行情况**：操作名称、时间信息、状态以及步骤之间的父子关系。
- **Model 调用**：Model 详情、消息、结束原因和 [Token 用量](https://www.confident-ai.com/docs/llm-tracing/features/token-usage-cost)。
- **Tool 调用**：Tool 的名称及其[输入和输出](https://www.confident-ai.com/docs/llm-tracing/features/input-output)。
- **Trace 详情**：根操作的名称、标签、元数据、输入和输出。
- **错误**：执行失败的操作会保留错误状态，以便在 Trace 中查看失败情况。

此集成导出 Trace 数据，不包含 Mastra 的日志、指标、评分和反馈。

## 自定义 Trace 元数据 {/* #custom-trace-metadata */}

通过 Mastra 的 `tracingOptions` 传入的元数据和标签会转发到 Confident AI 中的 Trace。你可以在 Confident AI 中按这些元数据和标签筛选和分组：

```typescript
const result = await mastra.getAgent('assistant').generate('How do you make the best coffee?', {
  tracingOptions: {
    metadata: { release: '2026-09', tier: 'enterprise' },
    tags: ['production', 'support'],
  },
})
```

你提供的元数据会与 Mastra 自行设置的字段（如 `runId`）合并。标签应用于根 Span，因此会显示在 Trace 层级，而不会附加到各个 Span 上。

## 生命周期 {/* #lifecycle */}

此导出器由 Mastra 管理。Mastra 会创建自己的 OTLP 处理器，且不会注册、替换或关闭全局 OpenTelemetry Provider，因此无需调用 `init()`，也无需在启动命令中添加预加载项。

导出器关闭时会批量发送 Span。请等所有 Agent 运行和流式传输都结束后，再关闭导出器一次；否则，短时运行的脚本可能在发送任何数据之前就退出：

```typescript
await observability.shutdown()
```

对于长期运行的服务器，请在服务器正常关停时关闭导出器，无需在每个请求结束时关闭。Trace 发送后，最多可能需要 30 秒才会在 Observatory 中显示。

## 对话线程与 Trace 属性 {/* #threads-and-trace-properties */}

此导出器映射的是 Mastra 自身提供的 Trace 数据，因此 Trace 的元数据和标签来自上文所示的 `tracingOptions`。

要将对话轮次归入[对话线程](https://www.confident-ai.com/docs/llm-tracing/features/threads)，或设置用户 ID 等 Trace 级属性，请使用 `confident-trace` SDK 的埋点功能。该 SDK 直接接入 Mastra，无需通过导出器。配置方法见 [Mastra 集成指南](https://www.confident-ai.com/docs/integrations/third-party/mastra)。

请选择其中一种方式，不要同时使用两种。
