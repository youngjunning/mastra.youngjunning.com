# LangSmith

[LangSmith](https://smith.langchain.com/) 是 LangChain 用于监控和评估 LLM 应用的平台。LangSmith 导出器会将 Trace 发送到 LangSmith，让你分析模型性能、调试问题并运行评估流程。

## 安装 {/* #installation */}

```bash npm2yarn
npm install @mastra/langsmith@latest
```

## 配置 {/* #configuration */}

### 先决条件 {/* #prerequisites */}

1. **LangSmith 账号**：在 [smith.langchain.com](https://smith.langchain.com) 注册。
2. **API 密钥**：在 LangSmith 的 Settings → API Keys 中生成 API 密钥。
3. **环境变量**：通过环境变量设置凭据。

```bash title=".env"
# Required
LANGSMITH_API_KEY=ls-xxxxxxxxxxxx

# Optional
LANGCHAIN_PROJECT=my-project  # Default project for traces
LANGSMITH_BASE_URL=https://api.smith.langchain.com  # For self-hosted
```

### 通过环境变量配置 {/* #zero-config-setup */}

设置环境变量后，实例化导出器时无需传入配置：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { LangSmithExporter } from '@mastra/langsmith'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      langsmith: {
        serviceName: 'my-service',
        exporters: [new LangSmithExporter()],
      },
    },
  }),
})
```

### 显式配置 {/* #explicit-configuration */}

也可以直接向导出器传入凭据。直接传入的值优先于环境变量：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { LangSmithExporter } from '@mastra/langsmith'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      langsmith: {
        serviceName: 'my-service',
        exporters: [
          new LangSmithExporter({
            apiKey: process.env.LANGSMITH_API_KEY,
          }),
        ],
      },
    },
  }),
})
```

## 配置选项 {/* #configuration-options */}

### 完整配置 {/* #complete-configuration */}

```typescript
new LangSmithExporter({
  // Required credentials
  apiKey: process.env.LANGSMITH_API_KEY!,

  // Optional settings
  apiUrl: process.env.LANGSMITH_BASE_URL, // Default: https://api.smith.langchain.com
  projectName: 'my-project', // Project to send traces to (overrides LANGCHAIN_PROJECT env var)
  callerOptions: {
    // HTTP client options
    timeout: 30000, // Request timeout in ms
    maxRetries: 3, // Retry attempts
  },
  logLevel: 'info', // Diagnostic logging: debug | info | warn | error

  // LangSmith-specific options
  hideInputs: false, // Hide input data in UI
  hideOutputs: false, // Hide output data in UI
})
```

### 环境变量 {/* #environment-variables */}

| 变量 | 说明 |
| - | - |
| `LANGSMITH_API_KEY` | LangSmith API 密钥（必填） |
| `LANGCHAIN_PROJECT` | 接收 Trace 的默认项目名称（可选，默认值为“default”） |
| `LANGSMITH_BASE_URL` | 自托管实例的 API URL（可选） |

`projectName` 配置项优先于 `LANGCHAIN_PROJECT` 环境变量，因此你可以通过代码将 Trace 发送到不同项目。

## 动态配置 {/* #dynamic-configuration */}

你可以使用 `withLangsmithMetadata` 在运行时为单个 span 覆盖 LangSmith 设置，例如根据客户、环境或功能将 Trace 发送到不同项目。

### 使用辅助函数 {/* #using-the-helper */}

将 `withLangsmithMetadata` 与 `buildTracingOptions` 搭配使用，为 LangSmith 设置专用选项：

```typescript title="src/agents/support-agent.ts"
import { Agent } from '@mastra/core/agent'
import { buildTracingOptions } from '@mastra/observability'
import { withLangsmithMetadata } from '@mastra/langsmith'

export const supportAgent = new Agent({
  id: 'support-agent',
  name: 'support-agent',
  instructions: 'You are a helpful support agent.',
  model: '__GATEWAY_OPENAI_MODEL__',
  defaultOptions: {
    tracingOptions: buildTracingOptions(withLangsmithMetadata({ projectName: 'customer-support' })),
  },
})
```

### 动态选择目标项目 {/* #dynamic-project-routing */}

使用 `requestContext` 根据运行时条件将 Trace 发送到不同项目。

```typescript title="src/mastra/agents/support-agent.ts"
import { Agent } from '@mastra/core/agent'
import { buildTracingOptions } from '@mastra/observability'
import { withLangsmithMetadata } from '@mastra/langsmith'

export const supportAgent = new Agent({
  id: 'support-agent',
  name: 'support-agent',
  instructions: 'You are a helpful support agent.',
  model: '__GATEWAY_OPENAI_MODEL__',
  defaultOptions: ({ requestContext }) => {
    const userTier = requestContext?.get('user-tier') as string
    const userId = requestContext?.get('user-id') as string

    return {
      tracingOptions: buildTracingOptions(
        withLangsmithMetadata({
          projectName: userTier === 'enterprise' ? 'enterprise-traces' : 'standard-traces',
          sessionId: userId,
        }),
      ),
    }
  },
})
```

### 可用字段 {/* #available-fields */}

辅助函数 `withLangsmithMetadata` 接受以下字段：

| 字段 | 类型 | 说明 |
| - | - | - |
| `projectName` | string | 覆盖此 Trace 的目标项目 |
| `sessionId` | string | 按会话将相关 Trace 分组 |
| `sessionName` | string | 会话的显示名称 |

所有字段均为可选。该函数会将传入的字段与已有元数据合并，因此可以多次调用，也可以与其他追踪选项搭配使用。

## 对话线程 {/* #conversation-threads */}

LangSmith 根据元数据键 `session_id` 将运行记录归入同一个[对话线程](https://docs.langchain.com/langsmith/threads)。导出器会为 Trace 中的每条运行记录设置该键。根运行记录按顺序取第一个可用值，依次是通过 `withLangsmithMetadata({ sessionId })` 显式传入的值、span 元数据中的 `sessionId`，以及 Mastra 记忆中的 `threadId`。子运行记录继承父运行记录的会话，因此即使受委派的子 Agent 在自己的派生线程上运行，它的运行记录仍会归入原对话线程。

启用记忆的 Agent 每次运行都会设置 `threadId`，因此同一记忆线程中的多轮对话会归入 LangSmith 中的同一个对话线程，无需额外配置：

```typescript
const memory = { thread: 'thread-123', resource: 'user-1' }

await agent.generate('hi', { memory })
await agent.generate('and again', { memory })
```

## 评分和反馈 {/* #scores-and-feedback */}

通过 `mastra.observability.addScore()` 发送的评分会在 LangSmith 中显示为对应运行记录的反馈。如果只提供 `traceId`，评分会关联到该 Trace 的根运行记录。如果提供了 `spanId`，评分会关联到该 span 对应的运行记录。

```typescript title="src/feedback.ts"
await mastra.observability.addScore({
  traceId,
  correlationContext: { traceId },
  score: { scorerId: 'user-feedback', scoreSource: 'user', score: 1, reason: 'Helpful answer' },
})
```

LangSmith 的每条运行记录 ID 都由对应的 Mastra span ID 推导得出。因此，你可以从任意进程提交 span 级评分，即使进程已经重启，或者 Trace 已经导出很久。提交 Trace 级评分时，导出器会根据它为每条运行记录保存的 `mastra_trace_id` 元数据，在自身配置的项目中查找根运行记录。早期版本的 `@mastra/langsmith` 导出的运行记录保留原有 ID，只能由当初导出它们的进程提交评分。如果需要在自己的界面中链接到某条运行记录，可以调用 `langsmithRunIdFor()`，按相同规则计算其 ID：

```typescript
import { langsmithRunIdFor } from '@mastra/langsmith'

const runId = langsmithRunIdFor(spanId)
```
