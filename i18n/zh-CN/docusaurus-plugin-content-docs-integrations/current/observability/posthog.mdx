# PostHog

[PostHog](https://posthog.com/) 是一个分析平台，提供用于监控大语言模型（LLM）应用的 AI 可观测性功能。Mastra 支持两种集成方式：

- **Agent 工具**让 Agent 通过 [Mastra Connect](/docs/mastra-platform/connect) 使用 PostHog 中的事件、洞察和功能标志等数据。
- **[追踪](#tracing)**将 Mastra Trace 以结构化事件的形式导出到 PostHog。

## Connect {/* #connect */}

开始前，请按 [Connect 设置指南](/docs/mastra-platform/connect#get-started)安装 `@mastra/connect`，并配置 Mastra 平台中的项目。

## 追踪 {/* #tracing */}

PostHog 导出器将 Trace 以结构化事件的形式发送到 PostHog，便于分析 token 用量、成本、延迟和对话流程。

### 安装 {/* #installation */}

```bash npm2yarn
npm install @mastra/posthog@latest
```

### 配置 {/* #configuration */}

#### 前置条件 {/* #prerequisites */}

1. **PostHog 账号**：在 [posthog.com](https://posthog.com/) 注册。
2. **项目 API 密钥**：在 PostHog 的 Settings（设置）→ Project API Key（项目 API 密钥）中获取密钥。
3. **环境变量**：通过环境变量设置凭据。

```bash title=".env"
# Required
POSTHOG_API_KEY=phc_xxxxxxxxxxxxxxxx

# Optional
POSTHOG_HOST=https://us.i.posthog.com  # or eu.i.posthog.com for EU region
```

#### 使用环境变量 {/* #zero-config-setup */}

设置环境变量后，直接创建导出器即可，无需传入配置：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { PosthogExporter } from '@mastra/posthog'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      posthog: {
        serviceName: 'my-service',
        exporters: [new PosthogExporter()],
      },
    },
  }),
})
```

#### 显式配置 {/* #explicit-configuration */}

也可以直接向导出器传入凭据。传入的凭据优先于环境变量中的值：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { PosthogExporter } from '@mastra/posthog'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      posthog: {
        serviceName: 'my-service',
        exporters: [
          new PosthogExporter({
            apiKey: process.env.POSTHOG_API_KEY,
          }),
        ],
      },
    },
  }),
})
```

### 配置选项 {/* #configuration-options */}

#### 完整配置示例 {/* #complete-configuration */}

```typescript
new PosthogExporter({
  // Required credentials
  apiKey: process.env.POSTHOG_API_KEY!,

  // Optional settings
  host: 'https://us.i.posthog.com', // Default: US region
  // or "https://eu.i.posthog.com" for EU region
  // or your self-hosted URL

  // Batching configuration
  flushAt: 20, // Batch size (default: 20)
  flushInterval: 10000, // Flush interval in ms (default: 10000)
  serverless: false, // Serverless mode: flushAt=10, flushInterval=2000

  // User identification
  defaultDistinctId: 'anonymous', // Fallback if no userId in metadata

  // Privacy settings
  enablePrivacyMode: false, // Excludes input/output from generation events

  // Diagnostic logging
  logLevel: 'info', // debug | info | warn | error
})
```

#### 无服务器模式 {/* #serverless-mode */}

启用无服务器模式后，导出器会减小批次大小并缩短发送间隔，以便更快发送待处理的事件：

```typescript
new PosthogExporter({
  apiKey: process.env.POSTHOG_API_KEY!,
  serverless: true, // Configures smaller batches for faster flushing
})
```

#### 隐私模式 {/* #privacy-mode */}

启用隐私模式后，模型生成事件会省略输入和输出数据，同时保留 token 用量指标：

```typescript
new PosthogExporter({
  apiKey: process.env.POSTHOG_API_KEY!,
  enablePrivacyMode: true, // Removes $ai_input and $ai_output_choices
})
```

#### 按群组分析 {/* #group-analytics */}

要将事件关联到 [PostHog 群组](https://posthog.com/docs/product-analytics/group-analytics)，请在 `tracingOptions.metadata` 中添加 `$groups` 对象。导出器调用 PostHog 的事件采集接口时，会将这些值放在顶层 `groups` 字段中，这样就可以按群组分析 LLM 成本等指标。

```ts
await agent.generate(input, {
  tracingOptions: {
    metadata: {
      $groups: {
        publication: 'publication-1',
      },
    },
  },
})
```
