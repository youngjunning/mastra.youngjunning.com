# 邮差猪

[邮差猪](https://posthog.com/)是一个具有人工智能可观察性功能的分析平台，用于监控法学硕士申请。通过两种方式将其与 Mastra 一起使用：

* **AgentTool**让Agent通过以下方式处理 PostHog 数据，例如事件、见解和功能标志[Mastra Connect](/docs/mastra-platform/connect).
* **[追踪](#tracing)**&#x5C06;您的 Mastra 跟踪作为结构化事件导出到 PostHog。

## 连接 {/* #connect */}

在开始之前，请完成[Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect` and configure your platform project.

## 追踪 {/* #tracing */}

PostHog 导出器将您的跟踪作为结构化事件发送到 PostHog，提供有关令牌使用、成本、延迟和对话流的见解。

### 安装 {/* #installation */}

```bash npm2yarn
npm install @mastra/posthog@latest
```

### 配置 {/* #configuration */}

#### 先决条件 {/* #prerequisites */}

1. **邮政猪账户**: 报名于[posthog.com](https://posthog.com/)
2. **项目 API 密钥**：从 PostHog 设置 → 项目 API 密钥获取您的项目 API 密钥
3. **环境变量**：设置您的凭据

```bash title=".env"
# Required
POSTHOG_API_KEY=phc_xxxxxxxxxxxxxxxx

# Optional
POSTHOG_HOST=https://us.i.posthog.com  # or eu.i.posthog.com for EU region
```

#### 零配置设置 {/* #zero-config-setup */}

设置环境变量后，无需配置即可使用导出器：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { PosthogExporter } from '@mastra/posthog'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      posthog: {
        serviceName: 'my-service',
        exporters: [new PosthogExporter()],
      },
    },
  }),
})
```

#### 显式配置 {/* #explicit-configuration */}

您还可以直接传递凭据（优先于环境变量）：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { PosthogExporter } from '@mastra/posthog'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      posthog: {
        serviceName: 'my-service',
        exporters: [
          new PosthogExporter({
            apiKey: process.env.POSTHOG_API_KEY,
          }),
        ],
      },
    },
  }),
})
```

### 配置选项 {/* #configuration-options */}

#### 配置齐全 {/* #complete-configuration */}

```typescript
new PosthogExporter({
  // Required credentials
  apiKey: process.env.POSTHOG_API_KEY!,

  // Optional settings
  host: 'https://us.i.posthog.com', // Default: US region
  // or "https://eu.i.posthog.com" for EU region
  // or your self-hosted URL

  // Batching configuration
  flushAt: 20, // Batch size (default: 20)
  flushInterval: 10000, // Flush interval in ms (default: 10000)
  serverless: false, // Serverless mode: flushAt=10, flushInterval=2000

  // User identification
  defaultDistinctId: 'anonymous', // Fallback if no userId in metadata

  // Privacy settings
  enablePrivacyMode: false, // Excludes input/output from generation events

  // Diagnostic logging
  logLevel: 'info', // debug | info | warn | error
})
```

#### 无服务器模式 {/* #serverless-mode */}

针对无服务器环境优化批处理：

```typescript
new PosthogExporter({
  apiKey: process.env.POSTHOG_API_KEY!,
  serverless: true, // Configures smaller batches for faster flushing
})
```

#### 隐私模式 {/* #privacy-mode */}

从生成事件中排除输入/输出数据，同时保留令牌指标：

```typescript
new PosthogExporter({
  apiKey: process.env.POSTHOG_API_KEY!,
  enablePrivacyMode: true, // Removes $ai_input and $ai_output_choices
})
```

#### 集团分析 {/* #group-analytics */}

将事件附加到[PostHog group](https://posthog.com/docs/product-analytics/group-analytics), add a `$groups` object to `tracingOptions.metadata`. The exporter sends those values as the top-level `groups` field on the PostHog capture call, so you can slice analytics such as LLM cost by group.

```ts
await agent.generate(input, {
  tracingOptions: {
    metadata: {
      $groups: {
        publication: 'publication-1',
      },
    },
  },
})
```
