# Braintrust

[Braintrust](https://www.braintrust.dev/) 是一个评估和监控平台，可帮助你衡量和改进 LLM 应用的质量。Braintrust 导出器将 Trace 发送到 Braintrust，便于系统地开展评估、评分和实验。

## 安装 {/* #installation */}

```bash npm2yarn
npm install @mastra/braintrust@latest
```

## 配置 {/* #configuration */}

### 准备工作 {/* #prerequisites */}

1. 在 [braintrust.dev](https://www.braintrust.dev/) 注册 **Braintrust 账号**。
2. 创建或选择一个用于接收 Trace 的 **项目**。
3. 在 Braintrust 的 **Settings → API Keys** 中生成 **API 密钥**。
4. 通过 **环境变量** 设置凭据，如下所示。

```bash title=".env"
BRAINTRUST_API_KEY=sk-xxxxxxxxxxxxxxxx

# Optional
BRAINTRUST_ENDPOINT=https://api.braintrust.dev  # Custom endpoint if needed
```

### 仅使用环境变量 {/* #zero-config-setup */}

设置环境变量后，可以直接实例化导出器，无需传入配置。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { BraintrustExporter } from '@mastra/braintrust'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      braintrust: {
        serviceName: 'my-service',
        exporters: [new BraintrustExporter()],
      },
    },
  }),
})
```

### 显式配置 {/* #explicit-configuration */}

也可以直接向导出器传入凭据。显式传入的凭据优先于环境变量中的值。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { BraintrustExporter } from '@mastra/braintrust'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      braintrust: {
        serviceName: 'my-service',
        exporters: [
          new BraintrustExporter({
            apiKey: process.env.BRAINTRUST_API_KEY,
            projectName: 'my-project',
          }),
        ],
      },
    },
  }),
})
```

### 完整配置 {/* #complete-configuration */}

```typescript
new BraintrustExporter({
  // Required
  apiKey: process.env.BRAINTRUST_API_KEY!,

  // Optional settings
  projectName: 'my-project', // Default: 'mastra-tracing'
  endpoint: 'https://api.braintrust.dev', // Custom endpoint if needed
  logLevel: 'info', // Diagnostic logging: debug | info | warn | error
})
```

## 将 Trace 关联到 Braintrust 评估 {/* #attach-traces-to-braintrust-evals */}

如果应用使用 `Eval()`、`logger.traced()` 或 `currentSpan`，请直接安装 Braintrust SDK。

```bash npm2yarn
npm install braintrust@latest
```

在 Braintrust 的 `Eval()` 或 `logger.traced()` 中运行 Mastra 时，请将 Braintrust 日志记录器和 `currentSpan` 解析函数传给导出器。请从创建该评估或被追踪的 Span 的同一个 `braintrust` 包实例中导入 `currentSpan`。

当应用和 `@mastra/braintrust` 各自加载了不同的 Braintrust SDK 副本时，这样配置有助于将 Mastra 的 Span 挂到当前活跃的 Braintrust Span 下。

导出器接受 Braintrust SDK v2 和 v3 中兼容的日志记录器和 Span 对象。应用使用的 Braintrust SDK 版本可以与 `@mastra/braintrust` 安装的版本不同。

```typescript title="src/mastra/index.ts"
import { currentSpan, initLogger } from 'braintrust'
import { BraintrustExporter } from '@mastra/braintrust'

const logger = initLogger({
  projectName: 'my-project',
  apiKey: process.env.BRAINTRUST_API_KEY,
})

const exporter = new BraintrustExporter({
  braintrustLogger: logger,
  currentSpan,
})
```

在 Braintrust 评估任务中使用已配置的 Mastra 实例。上面的 `currentSpan` 解析函数会读取 `Eval()` 创建的活跃 Span。

```typescript title="src/evals/braintrust.ts"
import { Eval } from 'braintrust'
import { mastra } from '../mastra'

await Eval('my-project', {
  data: () => [{ input: 'Say hello', expected: 'Hello' }],
  task: async input => {
    const agent = mastra.getAgent('assistant')
    return (await agent.generate(input)).text
  },
  scores: [],
})
```

如果应用使用 Nunjucks 提示词模板，并且要将直接依赖的 Braintrust SDK 从 v2 升级到 v3，请按 [Braintrust v2 到 v3 迁移指南](https://www.braintrust.dev/docs/sdks/typescript/migrations/v2-to-v3) 操作。

## 使用返回的 `spanId` 查询 Braintrust {/* #querying-braintrust-with-returned-spanid */}

Mastra 返回的 `spanId` 同时用作 Braintrust 的行 ID 和 Span ID。可以用这个值按 `id` 或 `span_id` 查找对应的 Braintrust Span。

在 Braintrust v3 中，`root_span_id` 存储的是独立的 W3C Trace ID。查询 Mastra 返回的 `spanId` 时，应使用上述字段，避开 `root_span_id`。

```typescript title="src/mastra/usage.ts"
const result = await agent.stream('Summarize this ticket')

console.log('Mastra trace ID:', result.traceId)
console.log('Braintrust row and span ID:', result.spanId)

// Use result.spanId in your Braintrust lookup/query path
```

同样的查询方式也适用于 `agent.generate()` 的返回结果和 Workflow 运行结果，包括 `run.start()`、`run.stream()` 的最终状态和 `run.resume()`。

## 成本追踪 {/* #cost-tracking */}

如果模型提供商返回请求费用，导出器会将该费用发送给 Braintrust。OpenRouter 和 Vercel AI Gateway 都会返回这项数据。Braintrust 收到费用后会显示提供商实际收取的金额。对于未返回费用的生成请求，Braintrust 仍会按自己的模型定价估算费用。

具体规则见 [`BraintrustExporter` 参考文档](/reference/observability/tracing/exporters/braintrust#cost-tracking)。
