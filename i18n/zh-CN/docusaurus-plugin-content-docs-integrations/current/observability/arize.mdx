# Arize

[Arize AI](https://arize.com/?utm_source=mastra-docs\&utm_medium=partner\&utm_campaign=partner-docs\&utm_content=observability-arize) 通过 [Arize Phoenix](https://arize.com/phoenix/) 和 [Arize AX](https://arize.com/products/ax/) 为 AI 应用提供可观测性与评估能力。对于在本地运行或自行托管的开源 Workflow，使用 Phoenix；对于托管云或企业自托管生产环境中的可观测性需求，使用 Arize AX。Arize 导出器通过 OpenTelemetry 发送 Trace，遵循 [OpenInference](https://github.com/Arize-ai/openinference/tree/main/spec) 语义约定，兼容所有支持 OpenInference 的 OpenTelemetry 平台。

如果要在 Workflow 中利用 Trace 改进质量，请参阅 Arize 的 [Agent 评估指南](https://arize.com/ai-agents/agent-evaluation/)和 [LLM 评估指南](https://arize.com/resources/llm-evaluation/)。

## 安装 {/* #installation */}

```bash npm2yarn
npm install @mastra/arize@latest
```

## 配置 {/* #configuration */}

### 配置 Phoenix {/* #phoenix-setup */}

Phoenix 是一个开源可观测性平台，可以在本地运行，也可以自行托管。

#### 准备工作 {/* #prerequisites */}

1. **Phoenix 实例**：使用 Docker 在本地运行 Phoenix，或连接到自行托管的实例。
2. **端点**：准备 Phoenix 的端点 URL，须以 `/v1/traces` 结尾。
3. **API 密钥**：未启用身份验证的实例可省略；启用身份验证的部署必须提供。
4. **环境变量**：通过以下环境变量填写配置。

```bash title=".env"
# Required
PHOENIX_COLLECTOR_ENDPOINT=http://localhost:6006/v1/traces  # Or your self-hosted Phoenix URL

# Optional
PHOENIX_API_KEY=your-api-key  # For authenticated Phoenix instances
PHOENIX_PROJECT_NAME=mastra-service  # Defaults to 'mastra-service'
```

#### 仅使用环境变量 {/* #zero-config-setup */}

设置环境变量后，即可使用导出器，无需传入配置：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { ArizeExporter } from '@mastra/arize'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      arize: {
        serviceName: 'mastra-service',
        exporters: [new ArizeExporter()],
      },
    },
  }),
})
```

#### 显式配置 {/* #explicit-configuration */}

也可以直接传入凭据。显式传入的值优先于环境变量：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { ArizeExporter } from '@mastra/arize'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      arize: {
        serviceName: process.env.PHOENIX_PROJECT_NAME || 'mastra-service',
        exporters: [
          new ArizeExporter({
            endpoint: process.env.PHOENIX_COLLECTOR_ENDPOINT!,
            apiKey: process.env.PHOENIX_API_KEY,
            projectName: process.env.PHOENIX_PROJECT_NAME,
          }),
        ],
      },
    },
  }),
})
```

:::note[使用 Docker 快速入门]

使用采用内存存储的 Phoenix 实例进行本地测试：

```bash
docker run --pull=always -d --name arize-phoenix -p 6006:6006 \
  -e PHOENIX_SQL_DATABASE_URL="sqlite:///:memory:" \
  arizephoenix/phoenix:latest
```

设置 `PHOENIX_COLLECTOR_ENDPOINT=http://localhost:6006/v1/traces` 后，运行 Mastra Agent，即可在 [localhost:6006](http://localhost:6006) 查看 Trace。

:::

### 配置 Arize AX {/* #arize-ax-setup */}

Arize AX 是一个可观测性平台，支持托管云和企业自托管部署，并为生产环境中的 AI 系统提供高级功能。

#### 准备工作 {/* #prerequisites-1 */}

1. **Arize AX 账户**：在 [app.arize.com](https://app.arize.com/) 注册。
2. **空间 ID**：准备组织的空间标识符。
3. **API 密钥**：在 Arize AX 的设置中生成。
4. **环境变量**：通过以下环境变量设置凭据。

```bash title=".env"
# Required
ARIZE_SPACE_ID=your-space-id
ARIZE_API_KEY=your-api-key

# Optional
ARIZE_PROJECT_NAME=mastra-service
```

#### 仅使用环境变量 {/* #zero-config-setup-1 */}

设置环境变量后，即可使用导出器，无需传入配置：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { ArizeExporter } from '@mastra/arize'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      arize: {
        serviceName: 'mastra-service',
        exporters: [new ArizeExporter()],
      },
    },
  }),
})
```

#### 显式配置 {/* #explicit-configuration-1 */}

也可以直接传入凭据。显式传入的值优先于环境变量：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { ArizeExporter } from '@mastra/arize'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      arize: {
        serviceName: process.env.ARIZE_PROJECT_NAME || 'mastra-service',
        exporters: [
          new ArizeExporter({
            apiKey: process.env.ARIZE_API_KEY!,
            spaceId: process.env.ARIZE_SPACE_ID!,
            projectName: process.env.ARIZE_PROJECT_NAME,
          }),
        ],
      },
    },
  }),
})
```

## 配置选项 {/* #configuration-options */}

可以通过 Arize 导出器的高级配置微调 OpenTelemetry 的行为：

### 完整配置 {/* #complete-configuration */}

```typescript
new ArizeExporter({
  // Phoenix Configuration
  endpoint: 'https://your-collector.example.com/v1/traces', // Required for Phoenix

  // Arize AX Configuration
  spaceId: 'your-space-id', // Required for Arize AX

  // Shared Configuration
  apiKey: 'your-api-key', // Required for authenticated endpoints
  projectName: 'mastra-service', // Optional project name

  // Optional OTLP settings
  headers: {
    'x-custom-header': 'value', // Additional headers for OTLP requests
  },

  // Debug and performance tuning
  logLevel: 'debug', // Logging: debug | info | warn | error
  batchSize: 512, // Batch size before exporting spans
  timeout: 30000, // Timeout in ms before exporting spans

  // Custom resource attributes
  resourceAttributes: {
    'deployment.environment': process.env.NODE_ENV,
    'service.version': process.env.APP_VERSION,
  },
})
```

### 批处理选项 {/* #batch-processing-options */}

通过以下选项控制 Trace 的分批处理和导出方式：

```typescript
new ArizeExporter({
  endpoint: process.env.PHOENIX_COLLECTOR_ENDPOINT!,
  apiKey: process.env.PHOENIX_API_KEY,

  // Batch processing configuration
  batchSize: 512, // Number of spans to batch (default: 512)
  timeout: 30000, // Max time in ms to wait before export (default: 30000)
})
```

### 资源属性 {/* #resource-attributes */}

为所有导出的 span 添加自定义属性：

```typescript
new ArizeExporter({
  endpoint: process.env.PHOENIX_COLLECTOR_ENDPOINT!,
  resourceAttributes: {
    'deployment.environment': process.env.NODE_ENV,
    'service.namespace': 'production',
    'service.instance.id': process.env.HOSTNAME,
    'custom.attribute': 'value',
  },
})
```

### 自定义元数据 {/* #custom-metadata */}

非保留的 span 属性会序列化到 OpenInference 的 `metadata` 载荷中，并显示在 Arize 或 Phoenix 中。可以通过 `tracingOptions.metadata` 添加这些属性：

```ts
await agent.generate(input, {
  tracingOptions: {
    metadata: {
      companyId: 'acme-co',
      tier: 'enterprise',
    },
  },
})
```

保留字段会自动排除，例如 `input`、`output`、`sessionId`、线程 ID、用户 ID 和 OpenInference ID。

## OpenInference 语义约定 {/* #openinference-semantic-conventions */}

此导出器实现了适用于生成式 AI 应用的 [OpenInference 语义约定](https://github.com/Arize-ai/openinference/tree/main/spec)，使不同可观测性平台上的 Trace 采用统一的结构。
