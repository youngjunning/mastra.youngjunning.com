# Valkey

Valkey 存储实现通过 [Valkey GLIDE](https://github.com/valkey-io/valkey-glide) 客户端提供持久化存储和服务器端缓存。如果你的部署运行 Valkey，或需要 Valkey 原生配置和身份验证等 GLIDE 功能，可以使用此实现。

对于使用官方 `redis` 客户端的 Redis 部署，请使用 [`@mastra/redis`](/integrations/databases/redis)。这两个包分别使用各自对应的服务器独立测试。

## 安装 {/* #installation */}

```bash npm2yarn
npm install @mastra/valkey
```

## 用法 {/* #usage */}

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { ValkeyStore } from '@mastra/valkey'

export const mastra = new Mastra({
  storage: new ValkeyStore({
    id: 'valkey-storage',
    host: 'localhost',
    port: 6379,
    password: process.env.VALKEY_PASSWORD,
  }),
})
```

也可以提供 GLIDE 原生配置：

```typescript
import { ValkeyStore } from '@mastra/valkey'

const storage = new ValkeyStore({
  id: 'valkey-storage',
  config: {
    addresses: [{ host: 'localhost', port: 6379 }],
    useTLS: true,
  },
})
```

如果使用已有的 `GlideClient`，请先建立连接，再将它传给 `ValkeyStore`。通过这种方式注入的客户端仍由调用方负责关闭。

`ValkeyStore` 需要单机 Valkey 服务器。不支持 Valkey Cluster 和 `GlideClusterClient`。

## 关闭连接 {/* #closing-connections */}

在应用正常关闭时，按以下方式关闭由 `ValkeyStore` 创建的客户端：

```typescript
await storage.close()
```

`close()` 不会关闭注入的 `GlideClient`。
