# 瓦尔基

Valkey 存储实现通过以下方式提供持久存储和服务器端缓存：[Valkey GLIDE](https://github.com/valkey-io/valkey-glide)客户。当您的部署运行 Valkey 或需要 GLIDE 功能（例如本机 Valkey 配置和身份验证）时，请使用它。

使用[`@mastra/redis`](/integrations/databases/redis) for Redis deployments that use the official `redis`客户。这些软件包针对各自的服务器进行独立测试。

## 安装 {/* #installation */}

```bash npm2yarn
npm install @mastra/valkey
```

## 用法 {/* #usage */}

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { ValkeyStore } from '@mastra/valkey'

export const mastra = new Mastra({
  storage: new ValkeyStore({
    id: 'valkey-storage',
    host: 'localhost',
    port: 6379,
    password: process.env.VALKEY_PASSWORD,
  }),
})
```

您还可以提供本机 GLIDE 配置：

```typescript
import { ValkeyStore } from '@mastra/valkey'

const storage = new ValkeyStore({
  id: 'valkey-storage',
  config: {
    addresses: [{ host: 'localhost', port: 6379 }],
    useTLS: true,
  },
})
```

对于现有的`GlideClient`, connect it before passing it to `ValkeyStore`. The caller remains responsible for closing injected clients.

`ValkeyStore`需要一个独立的 Valkey 服务器。 Valkey 集群和`GlideClusterClient` aren't supported.

## 关闭连接 {/* #closing-connections */}

关闭创建的客户`ValkeyStore` during graceful shutdown:

```typescript
await storage.close()
```

`close()`不关闭注入的`GlideClient`.
