# 雷迪斯

Redis 存储实现通过以下方式使用直接 Redis 连接提供高性能存储解决方案[`node-redis`](https://github.com/redis/node-redis)（Node.js 的官方 Redis 客户端）。它支持独立的 Redis，并通过自定义客户端支持 Redis Sentinel。不支持 Redis 集群。

## 安装 {/* #installation */}

```bash
npm install @mastra/redis
```

## 用法 {/* #usage */}

### 使用连接字符串 {/* #using-connection-string */}

```typescript
import { RedisStore } from '@mastra/redis'

const storage = new RedisStore({
  id: 'redis-storage',
  connectionString: 'redis://localhost:6379',
})

await storage.init()
```

### 使用主机/端口配置 {/* #using-hostport-configuration */}

```typescript
import { RedisStore } from '@mastra/redis'

const storage = new RedisStore({
  id: 'redis-storage',
  host: 'localhost',
  port: 6379,
  password: 'your-password',
  db: 0,
})

await storage.init()
```

### 使用预先配置的客户端 {/* #using-pre-configured-client */}

对于Sentinel等高级配置，可以通过预配置的Redis客户端：

```typescript
import { RedisStore } from '@mastra/redis'
import { createClient } from 'redis'

const client = createClient({
  url: 'redis://localhost:6379',
  socket: {
    reconnectStrategy: retries => Math.min(retries * 50, 2000),
  },
})

// Connect the client before passing to RedisStore
await client.connect()

const storage = new RedisStore({
  id: 'redis-storage',
  client,
})
```

## 附加说明 {/* #additional-notes */}

### 关键结构 {/* #key-structure */}

Redis 存储实现使用以下关键模式：

* 主题：`mastra_threads:id:{threadId}`
* 留言：`mastra_messages:threadId:{threadId}:id:{messageId}`
* 留言索引：`msg-idx:{messageId}` (for fast lookups)
* 线程消息排序集：`thread:{threadId}:messages`
* Workflow程快照：`mastra_workflow_snapshot:namespace:{ns}:workflow_name:{name}:run_id:{id}`
* 分数：`mastra_scorers:id:{scoreId}`
* 资源：`mastra_resources:{resourceId}`

### Redis哨兵 {/* #redis-sentinel */}

对于使用 Redis Sentinel 的高可用性部署，创建自定义客户端：

```typescript
import { RedisStore } from '@mastra/redis'
import { createClient } from 'redis'

const client = createClient({
  url: 'redis://sentinel-host:26379',
  // Configure sentinel options as needed for your setup
})

await client.connect()

const storage = new RedisStore({
  id: 'redis-sentinel-storage',
  client,
})
```

### Redis集群 {/* #redis-cluster */}

不支持 Redis 集群。`RedisStore` accepts only a standalone client from `createClient()`, and several operations read or write keys that hash to different slots, which Redis Cluster rejects with a `CROSSSLOT` error.

### 访问底层客户端 {/* #accessing-the-underlying-client */}

您可以访问底层Redis客户端进行自定义操作：

```typescript
const storage = new RedisStore({
  id: 'redis-storage',
  connectionString: 'redis://localhost:6379',
})

await storage.init()

const client = storage.getClient()

// Custom Redis operations
await client.set('custom-key', 'value')
const value = await client.get('custom-key')
```

### 关闭连接 {/* #closing-connections */}

关闭应用程序时，请关闭 Redis 连接：

```typescript
await storage.close()
```

## 使用示例 {/* #usage-example */}

### 为Agent添加内存 {/* #adding-memory-to-an-agent */}

```typescript title="src/mastra/agents/redis-agent.ts"
import { Memory } from '@mastra/memory'
import { Agent } from '@mastra/core/agent'
import { RedisStore } from '@mastra/redis'

export const redisAgent = new Agent({
  id: 'redis-agent',
  name: 'Redis Agent',
  instructions:
    'You are an AI agent with the ability to automatically recall memories from previous interactions.',
  model: '__GATEWAY_OPENAI_MODEL__',
  memory: new Memory({
    storage: new RedisStore({
      id: 'redis-agent-storage',
      connectionString: process.env.REDIS_URL!,
    }),
    options: {
      lastMessages: 10,
    },
  }),
})
```

### 使用Agent {/* #using-the-agent */}

```typescript title="src/test-redis-agent.ts"
import 'dotenv/config'

import { mastra } from './mastra'

const threadId = '123'
const resourceId = 'user-456'

const agent = mastra.getAgent('redisAgent')

const message = await agent.stream('My name is Mastra', {
  memory: {
    thread: threadId,
    resource: resourceId,
  },
})

await message.textStream.pipeTo(new WritableStream())

const stream = await agent.stream("What's my name?", {
  memory: {
    thread: threadId,
    resource: resourceId,
  },
  memoryOptions: {
    lastMessages: 5,
  },
})

for await (const chunk of stream.textStream) {
  process.stdout.write(chunk)
}
```

### 与 Mastra 实例一起使用 {/* #using-with-mastra-instance */}

```typescript
import { Mastra } from '@mastra/core'
import { RedisStore } from '@mastra/redis'

const storage = new RedisStore({
  id: 'mastra-storage',
  host: 'localhost',
  port: 6379,
})

const mastra = new Mastra({
  storage, // init() called automatically
})
```

如果不使用 Mastra 直接使用存储，请致电`init()` explicitly:

```typescript
import { RedisStore } from '@mastra/redis'

const storage = new RedisStore({
  id: 'redis-storage',
  host: 'localhost',
  port: 6379,
})

await storage.init()

// Access domain-specific stores via getStore()
const memoryStore = await storage.getStore('memory')
const thread = await memoryStore?.getThreadById({ threadId: '...' })
```
