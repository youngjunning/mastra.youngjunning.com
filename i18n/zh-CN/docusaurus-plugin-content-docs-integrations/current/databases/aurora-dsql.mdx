# 极光DSQL

Aurora DSQL 存储实施使用 Amazon Aurora DSQL 和 IAM 身份验证提供存储。

Aurora DSQL 不支持 PostgreSQL 扩展（`CREATE EXTENSION`), including `pgvector`。对于向量存储，请使用单独的向量存储，例如`@mastra/s3vectors`.

## 安装 {/* #installation */}

```bash copy
npm install @mastra/dsql@beta
```

## 先决条件 {/* #prerequisites */}

* Amazon Aurora DSQL 集群
* 有权访问 DSQL 集群的 AWS 凭证（IAM 身份验证）

## 用法 {/* #usage */}

```typescript copy showLineNumbers
import { DSQLStore } from '@mastra/dsql'

const storage = new DSQLStore({
  id: 'my-dsql-store',
  host: 'abc123.dsql.us-east-1.on.aws',
  // region is auto-detected from host, or specify explicitly:
  // region: 'us-east-1',
  // user: 'admin', // default
  // database: 'postgres', // default
})

// Initialize the store (creates tables if needed)
await storage.init()
```

## 构造函数示例 {/* #constructor-examples */}

你可以实例化`DSQLStore` in the following ways:

```typescript copy showLineNumbers
import { DSQLStore } from '@mastra/dsql'

// Basic configuration (region auto-detected from host)
const store1 = new DSQLStore({
  id: 'my-dsql-store',
  host: 'abc123.dsql.us-east-1.on.aws',
})

// With explicit region and schema
const store2 = new DSQLStore({
  id: 'my-dsql-store',
  host: 'abc123.dsql.us-east-1.on.aws',
  region: 'us-east-1',
  schemaName: 'my_app',
})

// With custom credentials provider
import { fromNodeProviderChain } from '@aws-sdk/credential-providers'

const store3 = new DSQLStore({
  id: 'my-dsql-store',
  host: 'abc123.dsql.us-east-1.on.aws',
  customCredentialsProvider: fromNodeProviderChain(),
})

// With connection pool settings
const store4 = new DSQLStore({
  id: 'my-dsql-store',
  host: 'abc123.dsql.us-east-1.on.aws',
  max: 20,
  min: 2,
  idleTimeoutMillis: 300000,
  maxLifetimeSeconds: 3000,
  connectionTimeoutMillis: 10000,
})

// Using a pre-configured pg.Pool
import { Pool } from 'pg'
import { AuroraDSQLClient } from '@aws/aurora-dsql-node-postgres-connector'

const pool = new Pool({
  host: 'abc123.dsql.us-east-1.on.aws',
  Client: AuroraDSQLClient,
  region: 'us-east-1',
})

const store5 = new DSQLStore({
  id: 'my-dsql-store',
  pool,
})
```

## 附加说明 {/* #additional-notes */}

### 模式管理 {/* #schema-management */}

存储实现自动处理模式创建和更新。它创建以下表：

* `mastra_workflow_snapshot`：存储Workflow状态和执行数据
* `mastra_threads`：存储对话线程
* `mastra_messages`：存储单独的消息
* `mastra_ai_spans`：存储跨度数据以供观察
* `mastra_scorers`：存储评分和评价数据
* `mastra_resources`：存储资源工作内存数据
* `mastra_agents`：存储Agent数据

### 初始化 {/* #initialization */}

当您将存储传递给 Mastra 类时，`init()` is called automatically before any storage operation:

```typescript copy showLineNumbers
import { Mastra } from '@mastra/core'
import { DSQLStore } from '@mastra/dsql'

const storage = new DSQLStore({
  id: 'my-dsql-store',
  host: 'abc123.dsql.us-east-1.on.aws',
})

const mastra = new Mastra({
  storage, // init() is called automatically
})
```

如果您直接使用存储而不使用 Mastra，则必须致电`init()` explicitly to create the tables:

```typescript copy showLineNumbers
import { DSQLStore } from '@mastra/dsql'

const storage = new DSQLStore({
  id: 'my-dsql-store',
  host: 'abc123.dsql.us-east-1.on.aws',
})

// Required when using storage directly
await storage.init()

// Access domain-specific stores via getStore()
const memoryStore = await storage.getStore('memory')
const thread = await memoryStore?.getThreadById({ threadId: '...' })
```

:::警告
如果`init()` isn't called, tables won't be created and storage operations will fail silently or throw errors.
:::

### 直接数据库和池访问 {/* #direct-database-and-pool-access */}

`DSQLStore`将底层数据库客户端和 pg.Pool 实例公开为公共字段：

```typescript copy showLineNumbers
storage.db // Database client for executing queries
storage.pool // Underlying pg.Pool instance
```

它支持直接查询和自定义事务管理。使用这些字段时：

* 您负责正确的连接和事务处理。
* 关闭商店（`storage.close()`) will destroy the connection pool if it was created by the store.
* 直接访问会绕过 DSQLStore 方法提供的任何附加逻辑或验证。

此方法适用于需要低级别访问的高级场景。

### Aurora DSQL 细节 {/* #aurora-dsql-specifics */}

#### 仅 IAM 身份验证 {/* #iam-only-authentication */}

连接通过 IAM 进行身份验证。不需要数据库密码。`@mastra/dsql` uses `@aws/aurora-dsql-node-postgres-connector` to generate short-lived auth tokens. You can provide a custom credentials provider via `customCredentialsProvider`.

#### 单一数据库、基于模式的隔离 {/* #single-database-schema-based-isolation */}

每个集群公开一个数据库`postgres`. Logical separation is done via schemas. The `schemaName` option controls where Mastra tables are created.

#### 没有 PostgreSQL 扩展 {/* #no-postgresql-extensions */}

`CREATE EXTENSION`不支持。这包括`pgvector`, `PostGIS`, and others. For vector storage, use a separate store such as `@mastra/s3vectors` alongside `DSQLStore`.

#### JSON 存储为文本 {/* #json-stored-as-text */}

JSON/JSONB 可用作查询类型，但不能用作列类型。`@mastra/dsql` stores structured fields (metadata, content, etc.) in `TEXT` columns and casts to JSON at query time.

#### 架构和 DDL 约束 {/* #schema-and-ddl-constraints */}

某些 PostgreSQL 功能不可用：

* 外键约束
* `TRUNCATE`
* 同步`CREATE INDEX`

索引是使用异步创建的`CREATE INDEX ASYNC`. The store's `init()` and index helper APIs respect these constraints.

#### 事务和乐观并发 {/* #transactions-and-optimistic-concurrency */}

Aurora DSQL 使用乐观并发控制 (OCC)，并且在争用情况下可能会返回可重试的 OCC 错误。交易持续时间和规模存在限制。大批量操作应在应用程序级别拆分为较小的批次。

#### 连接寿命 {/* #connection-lifetime */}

个人转机时间限制在 60 分钟左右。默认`maxLifetimeSeconds: 3300` ensures connections are recycled before hitting this limit.

## 使用示例 {/* #usage-example */}

### 为Agent添加内存 {/* #adding-memory-to-an-agent */}

要将 Aurora DSQL 内存添加到Agent，请使用`Memory` class and create a new `storage` key using `DSQLStore`. The `host` should point to your Aurora DSQL cluster endpoint.

```typescript title="src/mastra/agents/example-dsql-agent.ts" copy showLineNumbers
import { Memory } from '@mastra/memory'
import { Agent } from '@mastra/core/agent'
import { DSQLStore } from '@mastra/dsql'

export const dsqlAgent = new Agent({
  id: 'dsql-agent',
  name: 'DSQL Agent',
  instructions:
    'You are an AI agent with the ability to automatically recall memories from previous interactions.',
  model: '__GATEWAY_OPENAI_MODEL__',
  memory: new Memory({
    storage: new DSQLStore({
      id: 'dsql-agent-storage',
      host: process.env.DSQL_HOST!,
    }),
    options: {
      generateTitle: true, // Explicitly enable automatic title generation
    },
  }),
})
```

### 使用Agent {/* #using-the-agent */}

使用`memoryOptions` to scope recall for this request. Set `lastMessages: 5` to limit recency-based recall, and use `semanticRecall` to fetch the `topK: 3` most relevant messages, including `messageRange: 2` neighboring messages for context around each match.

```typescript title="src/test-dsql-agent.ts" copy showLineNumbers
import 'dotenv/config'

import { mastra } from './mastra'

const threadId = '123'
const resourceId = 'user-456'

const agent = mastra.getAgent('dsql-agent')

const message = await agent.stream('My name is Mastra', {
  memory: {
    thread: threadId,
    resource: resourceId,
  },
})

await message.textStream.pipeTo(new WritableStream())

const stream = await agent.stream("What's my name?", {
  memory: {
    thread: threadId,
    resource: resourceId,
  },
  memoryOptions: {
    lastMessages: 5,
    semanticRecall: {
      topK: 3,
      messageRange: 2,
    },
  },
})

for await (const chunk of stream.textStream) {
  process.stdout.write(chunk)
}
```

## 指数管理 {/* #index-management */}

Aurora DSQL 存储提供索引管理功能来优化查询性能。

### 自动性能指标 {/* #automatic-performance-indexes */}

Aurora DSQL 存储在初始化期间自动为常见查询模式创建复合索引：

* `mastra_threads_resourceid_createdat_idx`: (资源 ID、创建时间)
* `mastra_messages_thread_id_createdat_idx`: (thread\_id, 创建时间)
* `mastra_ai_spans_traceid_startedat_idx`: (traceId, 开始时间)
* `mastra_ai_spans_parentspanid_startedat_idx`: (parentSpanId, 开始时间)
* `mastra_ai_spans_name_idx`： （姓名）
* `mastra_ai_spans_spantype_startedat_idx`: (spanType, 开始时间)
* `mastra_scores_trace_id_span_id_created_at_idx`: (traceId、spanId、createAt)

Aurora DSQL 使用异步创建这些索引`CREATE INDEX ASYNC`. Because index creation is asynchronous, new indexes may not be immediately available after `init()`. The store will continue to function without them, but queries may be slower until index creation completes.

### 创建自定义索引 {/* #creating-custom-indexes */}

创建额外的索引来优化特定的查询模式：

```typescript copy showLineNumbers
await storage.createIndex({
  name: 'idx_threads_resource',
  table: 'mastra_threads',
  columns: ['resourceId'],
})

await storage.createIndex({
  name: 'idx_messages_composite',
  table: 'mastra_messages',
  columns: ['thread_id', 'createdAt'],
})
```

Aurora DSQL 不允许`ASC`/`DESC` in `CREATE INDEX ASYNC`. If you include them, they will be automatically stripped.

### 特定于模式的索引 {/* #schema-specific-indexes */}

使用自定义架构时，索引是使用架构前缀创建的：

```typescript copy showLineNumbers
const storage = new DSQLStore({
  id: 'my-dsql-store',
  host: 'abc123.dsql.us-east-1.on.aws',
  schemaName: 'custom_schema',
})

// Creates index as: custom_schema_idx_threads_status
await storage.createIndex({
  name: 'idx_threads_status',
  table: 'mastra_threads',
  columns: ['status'],
})
```
