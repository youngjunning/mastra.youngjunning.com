# ClickHouse 管理 Postgres

[ClickHouse 管理 Postgres](https://clickhouse.com/cloud/postgres)通过以下方式连接到 Mastra[`PostgresStore`](/integrations/databases/postgresql)，它使用 Node.js`pg`司机。

## 设置连接 {/* #set-up-the-connection */}

在 ClickHouse Cloud 控制台中，打开您的 Postgres 实例并选择**Connect**. Turn off **via PgBouncer** and copy the direct connection URL. Download the instance's CA certificate bundle from **Settings**.

在您的应用程序中设置这些环境变量：

```bash title=".env"
DATABASE_URL=postgresql://postgres:YOUR_PASSWORD@YOUR_HOST:5432/postgres
PG_CA_CERT_PATH=/absolute/path/to/ca-certificate.pem
```

使密码不受版本控制。使用来自的主机名**Connect** and leave SSL query parameters out of `DATABASE_URL`. The `ssl` object below configures certificate verification.

请参阅[connection documentation](https://clickhouse.com/docs/products/managed-postgres/connection) for connection details and certificates.

## 配置存储 {/* #configure-storage */}

安装 PostgreSQL 存储包：

```bash npm2yarn
npm install @mastra/pg@latest
```

在 Mastra 上注册商店：

```typescript title="src/mastra/index.ts"
import { readFileSync } from 'node:fs'
import { Mastra } from '@mastra/core/mastra'
import { PostgresStore } from '@mastra/pg'

export const mastra = new Mastra({
  storage: new PostgresStore({
    id: 'clickhouse-managed-postgres-storage',
    connectionString: process.env.DATABASE_URL!,
    ssl: {
      ca: readFileSync(process.env.PG_CA_CERT_PATH!, 'utf8'),
      rejectUnauthorized: true,
    },
  }),
})
```

CA 证书对于您的实例是唯一的。使其可供部署的应用程序使用`PG_CA_CERT_PATH`.

当应用程序启动时，Mastra 会初始化其存储表。数据库角色必须有权创建这些表和索引。运行您的应用程序，然后使用实例的 SQL 控制台检查表：

```sql
SELECT table_schema, table_name
FROM information_schema.tables
WHERE table_name LIKE 'mastra_%'
ORDER BY table_schema, table_name;
```

对于单独的模式初始化和运行时角色，请参阅[PostgreSQL storage guide](/integrations/databases/postgresql).
