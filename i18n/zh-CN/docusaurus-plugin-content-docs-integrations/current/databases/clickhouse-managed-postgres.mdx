# ClickHouse Managed Postgres

[ClickHouse Managed Postgres](https://clickhouse.com/cloud/postgres) 通过基于 Node.js `pg` 驱动的 [`PostgresStore`](/integrations/databases/postgresql) 连接到 Mastra。

## 设置连接 {/* #set-up-the-connection */}

在 ClickHouse Cloud 控制台中打开 Postgres 实例，选择 **Connect**。禁用 **via PgBouncer**，然后复制直连 URL。从 **Settings** 下载实例的 CA 证书包。

在应用中设置以下环境变量：

```bash title=".env"
DATABASE_URL=postgresql://postgres:YOUR_PASSWORD@YOUR_HOST:5432/postgres
PG_CA_CERT_PATH=/absolute/path/to/ca-certificate.pem
```

不要将密码纳入版本控制。使用 **Connect** 中显示的主机名，并确保 `DATABASE_URL` 中没有 SSL 查询参数。下方的 `ssl` 对象用于配置证书验证。

有关连接和证书的详细信息，请参阅[连接文档](https://clickhouse.com/docs/products/managed-postgres/connection)。

## 配置存储 {/* #configure-storage */}

安装 PostgreSQL 存储包：

```bash npm2yarn
npm install @mastra/pg@latest
```

在 Mastra 中注册存储实例：

```typescript title="src/mastra/index.ts"
import { readFileSync } from 'node:fs'
import { Mastra } from '@mastra/core/mastra'
import { PostgresStore } from '@mastra/pg'

export const mastra = new Mastra({
  storage: new PostgresStore({
    id: 'clickhouse-managed-postgres-storage',
    connectionString: process.env.DATABASE_URL!,
    ssl: {
      ca: readFileSync(process.env.PG_CA_CERT_PATH!, 'utf8'),
      rejectUnauthorized: true,
    },
  }),
})
```

CA 证书是实例专属的。确保部署后的应用可以从 `PG_CA_CERT_PATH` 指定的路径读取该证书。

应用启动时，Mastra 会初始化存储表。数据库角色必须有权创建这些表和索引。运行应用后，使用实例的 SQL Console 查看这些表：

```sql
SELECT table_schema, table_name
FROM information_schema.tables
WHERE table_name LIKE 'mastra_%'
ORDER BY table_schema, table_name;
```

如果需要为数据库模式初始化和应用运行分别设置角色，请参阅 [PostgreSQL 存储指南](/integrations/databases/postgresql)。
