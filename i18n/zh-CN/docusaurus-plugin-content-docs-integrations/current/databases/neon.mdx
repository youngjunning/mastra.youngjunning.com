# Neon Postgres

[Neon](https://neon.com) 是一项托管 PostgreSQL 服务。Mastra 通过 [`PostgresStore`](/integrations/databases/postgresql) 连接 Neon，后者使用 Node.js 的 `pg` 驱动。Neon 无需专用的 Mastra 存储包。

你还可以通过 [Mastra Connect](#connect) 为 Agent 提供工具，让它管理 Neon 项目和分支、执行 SQL 并应用数据库模式迁移。

## 快速入门 {/* #quickstart */}

创建 Neon 项目，然后将该项目的[连接池连接字符串](https://neon.com/docs/connect/connect-from-any-app)复制到 `DATABASE_URL`。

安装 PostgreSQL 存储包：

```bash npm2yarn
npm install @mastra/pg@latest
```

将连接池的连接字符串传给 `PostgresStore`：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core/mastra'
import { PostgresStore } from '@mastra/pg'

export const mastra = new Mastra({
  storage: new PostgresStore({
    id: 'neon-storage',
    connectionString: process.env.DATABASE_URL!,
  }),
})
```

Mastra 启动时会调用 `storage.init()`，在 Neon 中创建所需的表和索引。

## 使用 CLI 配置 Neon {/* #set-up-neon-with-the-cli */}

Neon CLI 需要 Node.js 20.19 或更高版本。

安装 [Neon CLI](https://neon.com/docs/cli/install)：

```bash npm2yarn
npm install -g neon
```

在项目目录中运行以下命令，关联现有的 Neon 项目或创建新项目：

```bash
neon link
```

`neon link` 会引导你登录，将项目上下文写入 `.neon`，并拉取当前分支的环境变量。需要刷新这些变量时，再运行 `neon env pull`：

```bash
neon env pull
```

该命令会将 `DATABASE_URL` 和 `DATABASE_URL_UNPOOLED` 写入 `.env.local`；如果 `.env` 已存在，则写入 `.env`。

### 添加 `neon.ts` {/* #add-neonts */}

要在代码仓库中管理分支配置，请创建 [`neon.ts`](https://neon.com/docs/reference/neon-ts) 文件：

```bash
neon config init
```

该命令会安装 `@neon/config` 和 `@neon/env`，并生成初始配置。例如，下面的策略会让新建的非默认分支在七天后过期：

```typescript title="neon.ts"
import { defineConfig } from '@neon/config/v1'

export default defineConfig({
  branch: branch => {
    if (branch.isDefault) {
      return {}
    }

    if (!branch.exists) {
      return { ttl: '7d' }
    }

    return {}
  },
})
```

应用配置：

```bash
neon deploy
```

## 安装 Neon Agent Skills {/* #install-neon-agent-skills */}

在项目目录中安装 [`neon` 和 `neon-postgres` 两个 Agent Skills](https://neon.com/docs/ai/agent-skills)：

```bash npm2yarn
npx skills add neondatabase/agent-skills --skill neon --skill neon-postgres -y
```

这些 Skill 为兼容的编程 Agent 提供 Neon 配置说明和针对 Postgres 的使用指导。

## 生产环境连接 {/* #production-connections */}

Neon 提供两种连接字符串：直连和连接池。

- `DATABASE_URL` 使用 Neon 的连接池端点，适用于应用的日常访问。
- `DATABASE_URL_UNPOOLED` 直接连接 Postgres，适用于在应用之外执行的管理任务或数据库模式变更。

对于大多数应用，使用快速入门中的 `DATABASE_URL` 通过连接池访问数据库，并让 Mastra 在启动时初始化数据库模式即可。`PostgresStore` 支持通过事务级连接池初始化数据库模式。

### 单独初始化数据库模式 {/* #separate-schema-initialization */}

如果应用在运行时使用的数据库角色不应创建表或索引，请在部署时通过直连初始化数据库模式：

```typescript title="scripts/init-storage.ts"
import { PostgresStore } from '@mastra/pg'

const storage = new PostgresStore({
  id: 'neon-storage-init',
  connectionString: process.env.DATABASE_URL_UNPOOLED!,
})

try {
  await storage.init()
} finally {
  await storage.close()
}
```

数据库模式创建后，让应用在运行时通过连接池访问数据库，并禁用自动初始化：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core/mastra'
import { PostgresStore } from '@mastra/pg'

export const mastra = new Mastra({
  storage: new PostgresStore({
    id: 'neon-storage',
    connectionString: process.env.DATABASE_URL!,
    disableInit: true,
  }),
})
```

详情请参阅 [Neon 连接池文档](https://neon.com/docs/connect/connection-pooling)。

## 向量搜索 {/* #vector-search */}

Neon 支持 [`pgvector` 扩展](https://neon.com/docs/extensions/pgvector)。创建扩展和索引时，通过 `DATABASE_URL_UNPOOLED` 直连数据库。配置完成后，让 [`PgVector`](/integrations/vectors/pg) 在运行时通过连接池执行查询：

```typescript
import { PgVector } from '@mastra/pg'

const vector = new PgVector({
  id: 'neon-vector',
  connectionString: process.env.DATABASE_URL!,
  disableInit: true,
})
```

设置 `disableInit: true` 可防止运行时进程创建或修改扩展、表和索引。
