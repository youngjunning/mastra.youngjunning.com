# MySQL

使用`MySQLStore`将 Mastra 应用程序数据（包括消息、Workflow程、跟踪、分数和其他存储域）保存在 MySQL 数据库中。

## 安装 {/* #installation */}

存储提供程序必须作为单独的包安装：

```bash npm2yarn
npm install @mastra/mysql@latest
```

## 用法 {/* #usage */}

添加`MySQLStore` to your Mastra configuration with a MySQL connection string:

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MySQLStore } from '@mastra/mysql'

export const mastra = new Mastra({
  storage: new MySQLStore({
    id: 'mysql-storage',
    connectionString: process.env.MYSQL_URL!,
  }),
})
```

例如，`MYSQL_URL` can use the format `mysql://user:password@host:3306/database`.

### 基于主机的配置 {/* #host-based-configuration */}

您可以提供单独的连接字段而不是连接字符串：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MySQLStore } from '@mastra/mysql'

export const mastra = new Mastra({
  storage: new MySQLStore({
    id: 'mysql-storage',
    host: process.env.MYSQL_HOST!,
    port: Number(process.env.MYSQL_PORT ?? 3306),
    user: process.env.MYSQL_USER!,
    password: process.env.MYSQL_PASSWORD,
    database: process.env.MYSQL_DATABASE!,
  }),
})
```

## 初始化 {/* #initialization */}

当您注册存储时`Mastra`, `init()` is called automatically to create the [core schema](/reference/storage/overview#core-schema):

```typescript
const storage = new MySQLStore({
  id: 'mysql-storage',
  connectionString: process.env.MYSQL_URL!,
})

export const mastra = new Mastra({
  storage, // init() is called automatically
})
```

直接使用存储时无需`Mastra`, call `init()` before accessing domain stores:

```typescript
const storage = new MySQLStore({
  id: 'mysql-storage',
  connectionString: process.env.MYSQL_URL!,
})

await storage.init()

const memoryStore = await storage.getStore('memory')
```

## 生产 {/* #production */}

使用 Mastra 部署可以访问的持久 MySQL 数据库。将凭据存储在环境变量中，并在数据库Provider需要时启用 SSL。
