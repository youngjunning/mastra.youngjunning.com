# MySQL

使用 `MySQLStore` 将 Mastra 应用数据持久化到 MySQL 数据库，包括消息、Workflow、追踪记录、评分以及其他存储域的数据。

## 安装 {/* #installation */}

存储 Provider 必须以独立的包安装：

```bash npm2yarn
npm install @mastra/mysql@latest
```

## 使用方式 {/* #usage */}

在 Mastra 配置中添加 `MySQLStore`，并传入 MySQL 连接字符串：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MySQLStore } from '@mastra/mysql'

export const mastra = new Mastra({
  storage: new MySQLStore({
    id: 'mysql-storage',
    connectionString: process.env.MYSQL_URL!,
  }),
})
```

例如，`MYSQL_URL` 可以采用 `mysql://user:password@host:3306/database` 格式。

### 按字段配置连接 {/* #host-based-configuration */}

也可以逐项指定连接参数，无需提供连接字符串：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MySQLStore } from '@mastra/mysql'

export const mastra = new Mastra({
  storage: new MySQLStore({
    id: 'mysql-storage',
    host: process.env.MYSQL_HOST!,
    port: Number(process.env.MYSQL_PORT ?? 3306),
    user: process.env.MYSQL_USER!,
    password: process.env.MYSQL_PASSWORD,
    database: process.env.MYSQL_DATABASE!,
  }),
})
```

## 初始化 {/* #initialization */}

将存储实例注册到 `Mastra` 时，系统会自动调用 `init()` 来创建[核心数据库结构](/reference/storage/overview#core-schema)：

```typescript
const storage = new MySQLStore({
  id: 'mysql-storage',
  connectionString: process.env.MYSQL_URL!,
})

export const mastra = new Mastra({
  storage, // init() is called automatically
})
```

如果不通过 `Mastra` 而直接使用存储实例，请先调用 `init()`，再访问各存储域的存储实例：

```typescript
const storage = new MySQLStore({
  id: 'mysql-storage',
  connectionString: process.env.MYSQL_URL!,
})

await storage.init()

const memoryStore = await storage.getStore('memory')
```

## 生产环境 {/* #production */}

使用支持持久化且可从 Mastra 部署环境访问的 MySQL 数据库。将凭据保存在环境变量中，并在数据库 Provider 要求时启用 SSL。
