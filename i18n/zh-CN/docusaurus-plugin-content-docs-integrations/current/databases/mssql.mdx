# MSSQL

MSSQL 存储实现以 Microsoft SQL Server 为后端，可在生产环境中使用。

## 安装 {/* #installation */}

```bash npm2yarn
npm install @mastra/mssql@latest
```

## 使用方法 {/* #usage */}

```typescript
import { MSSQLStore } from '@mastra/mssql'

const storage = new MSSQLStore({
  id: 'mssql-storage',
  connectionString: process.env.DATABASE_URL,
})
```

## 构造函数示例 {/* #constructor-examples */}

以下示例展示了如何用连接字符串或单独的连接参数创建 `MSSQLStore` 实例。两种方式都可以指定自定义架构。

```ts
import { MSSQLStore } from '@mastra/mssql'

// Using a connection string only
const store1 = new MSSQLStore({
  id: 'mssql-storage-1',
  connectionString:
    'Server=localhost,1433;Database=mydb;User Id=sa;Password=password;Encrypt=true;TrustServerCertificate=true',
})

// Using a connection string with a custom schema name
const store2 = new MSSQLStore({
  id: 'mssql-storage-2',
  connectionString:
    'Server=localhost,1433;Database=mydb;User Id=sa;Password=password;Encrypt=true;TrustServerCertificate=true',
  schemaName: 'custom_schema', // optional
})

// Using individual connection parameters
const store4 = new MSSQLStore({
  id: 'mssql-storage-3',
  server: 'localhost',
  port: 1433,
  database: 'mydb',
  user: 'user',
  password: 'password',
})

// Individual parameters with schemaName
const store5 = new MSSQLStore({
  id: 'mssql-storage-4',
  server: 'localhost',
  port: 1433,
  database: 'mydb',
  user: 'user',
  password: 'password',
  schemaName: 'custom_schema', // optional
})
```

## 附加说明 {/* #additional-notes */}

### 架构管理 {/* #schema-management */}

存储实现会自动创建和更新数据库架构，并创建下列数据表。

- `mastra_workflow_snapshot`：存储 Workflow 的状态和执行数据
- `mastra_evals`：存储评估结果和元数据
- `mastra_threads`：存储对话线程
- `mastra_messages`：逐条存储消息
- `mastra_traces`：存储遥测和跟踪数据
- `mastra_scorers`：存储评分和评估数据
- `mastra_resources`：存储资源的工作记忆数据

### 初始化 {/* #initialization */}

将存储实例传给 Mastra 类后，Mastra 会在执行任何存储操作之前自动调用 `init()`。

```typescript
import { Mastra } from '@mastra/core'
import { MSSQLStore } from '@mastra/mssql'

const storage = new MSSQLStore({
  connectionString: process.env.DATABASE_URL,
})

const mastra = new Mastra({
  storage, // init() is called automatically
})
```

如果绕过 Mastra 直接使用存储实例，必须显式调用 `init()` 来创建数据表。

```typescript
import { MSSQLStore } from '@mastra/mssql'

const storage = new MSSQLStore({
  id: 'mssql-storage',
  connectionString: process.env.DATABASE_URL,
})

// Required when using storage directly
await storage.init()

// Access domain-specific stores via getStore()
const memoryStore = await storage.getStore('memory')
const thread = await memoryStore?.getThreadById({ threadId: '...' })
```

:::warning
如果没有调用 `init()`，数据表就不会创建，存储操作可能静默失败或抛出错误。
:::

### 直接访问数据库和连接池 {/* #direct-database-and-pool-access */}

`MSSQLStore` 通过公开字段提供对 mssql 连接池的访问。

```typescript
store.pool // mssql connection pool instance
```

通过连接池可以直接执行查询，也可以自行管理事务。

- 你需要自行妥善管理连接和事务。
- 调用 `store.close()` 关闭存储实例时，会销毁关联的连接池。
- 直接访问会绕过 MSSQLStore 方法提供的任何附加逻辑或验证。

这种方式适用于需要访问底层数据库接口的高级用法。
