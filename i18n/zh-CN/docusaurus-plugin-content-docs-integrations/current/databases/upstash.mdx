# Upstash

Mastra 的 Upstash 存储基于 Upstash 提供的 Redis 兼容键值存储，适合无服务器部署。

:::warning[计费]

Agent 在对话过程中会执行大量 Redis 命令。将 Mastra 与 Upstash 搭配使用时，按量计费可能导致费用超出预期。强烈建议选择**固定价格套餐**，以便预估支出。计费详情请参阅 [Upstash 价格说明](https://upstash.com/pricing/redis)，相关背景见 [GitHub 议题 #5850](https://github.com/mastra-ai/mastra/issues/5850)。

:::

:::warning[不支持可观测性]

Upstash 存储**不支持可观测性存储域**。`MastraStorageExporter` 导出的 Trace 无法持久化到 Upstash。仅使用 Upstash 作为存储后端时，[Studio](/docs/studio/overview) 的可观测性功能不可用。要启用可观测性，请使用[组合存储](/reference/storage/composite#specialized-storage-for-observability)，将可观测性数据路由到 ClickHouse 等受支持的存储后端。

:::

## 附加说明 {/* #additional-notes */}

### 键结构 {/* #key-structure */}

Upstash 以键值对存储数据，各类键的格式如下：

- 会话线程键：`{prefix}thread:{threadId}`
- 消息键：`{prefix}message:{messageId}`
- 元数据键：`{prefix}metadata:{entityId}`

### 无服务器部署的优势 {/* #serverless-benefits */}

Upstash 存储特别适合无服务器部署：

- 无需管理连接
- 按请求次数计费
- 可选全球复制
- 兼容边缘运行环境

### 数据持久化 {/* #data-persistence */}

Upstash 提供以下数据持久化和恢复能力：

- 自动持久化数据
- 恢复到指定时间点
- 可选跨区域复制

### 性能建议 {/* #performance-considerations */}

为优化性能，可采取以下措施：

- 使用合适的键前缀组织数据
- 监控 Redis 的内存使用情况
- 根据需要考虑设置数据过期策略

## 使用示例 {/* #usage-example */}

### 为 Agent 添加记忆 {/* #adding-memory-to-an-agent */}

要为 Agent 添加基于 Upstash 的记忆，请使用 `Memory` 类，将 `storage` 配置为 `UpstashStore` 实例，并将 `vector` 配置为 `UpstashVector` 实例。配置可以指向远程服务，也可以指向本地环境。

```typescript title="src/mastra/agents/example-upstash-agent.ts"
import { Memory } from '@mastra/memory'
import { Agent } from '@mastra/core/agent'
import { UpstashStore } from '@mastra/upstash'

export const upstashAgent = new Agent({
  id: 'upstash-agent',
  name: 'Upstash Agent',
  instructions:
    'You are an AI agent with the ability to automatically recall memories from previous interactions.',
  model: '__GATEWAY_OPENAI_MODEL__',
  memory: new Memory({
    storage: new UpstashStore({
      id: 'upstash-agent-storage',
      url: process.env.UPSTASH_REDIS_REST_URL!,
      token: process.env.UPSTASH_REDIS_REST_TOKEN!,
    }),
    options: {
      generateTitle: true, // Explicitly enable automatic title generation
    },
  }),
})
```

### 使用 Agent {/* #using-the-agent */}

使用 `memoryOptions` 限定本次请求的记忆召回范围。通过 `lastMessages: 5` 将近期召回限制为最近 5 条消息，再使用 `semanticRecall` 进行语义召回。`topK: 3` 用于检索最相关的 3 条消息，`messageRange: 2` 为每条匹配消息补充前后各 2 条消息作为上下文。

```typescript title="src/test-upstash-agent.ts"
import 'dotenv/config'

import { mastra } from './mastra'

const threadId = '123'
const resourceId = 'user-456'

const agent = mastra.getAgent('upstashAgent')

const message = await agent.stream('My name is Mastra', {
  memory: {
    thread: threadId,
    resource: resourceId,
  },
})

await message.textStream.pipeTo(new WritableStream())

const stream = await agent.stream("What's my name?", {
  memory: {
    thread: threadId,
    resource: resourceId,
  },
  memoryOptions: {
    lastMessages: 5,
    semanticRecall: {
      topK: 3,
      messageRange: 2,
    },
  },
})

for await (const chunk of stream.textStream) {
  process.stdout.write(chunk)
}
```
