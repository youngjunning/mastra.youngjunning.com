# libSQL

[libSQL](https://docs.turso.tech/libsql) 是兼容 SQLite 的开源数据库，支持本地和远程部署。你可以用它存储消息历史记录、Workflow 快照、Trace 和评估分数。

如果要为语义召回或传统 RAG 使用向量，请参阅 [libSQL Vector](/integrations/vectors/libsql)，其中介绍了嵌入向量和向量搜索。

## 安装 {/* #installation */}

存储 Provider 必须单独安装。libSQL 的安装命令如下。

```bash npm2yarn
npm install @mastra/libsql@latest
```

## 使用方法 {/* #usage */}

```typescript
import { LibSQLStore } from '@mastra/libsql'
import { Mastra } from '@mastra/core'

const mastra = new Mastra({
  storage: new LibSQLStore({
    id: 'libsql-storage',
    url: 'file:./storage.db',
  }),
})
```

以下示例为单个 Agent 配置文件存储。

```typescript
import { Memory } from '@mastra/memory'
import { Agent } from '@mastra/core/agent'
import { LibSQLStore } from '@mastra/libsql'

export const agent = new Agent({
  id: 'example-agent',
  memory: new Memory({
    storage: new LibSQLStore({
      id: 'libsql-storage',
      url: 'file:./agent.db',
    }),
  }),
})
```

:::warning
使用临时文件系统的无服务器平台无法使用文件存储。部署到这类平台时，请使用 [Turso](https://turso.tech) 或其他数据库引擎。
:::

生产环境可以连接远程数据库。

```typescript
storage: new LibSQLStore({
  id: 'libsql-storage',
  url: 'libsql://your-db-name.aws-ap-northeast-1.turso.io',
  authToken: process.env.TURSO_AUTH_TOKEN,
})
```

在本地开发和测试时，可以将数据存储在内存中。

```typescript
storage: new LibSQLStore({
  id: 'libsql-storage',
  url: ':memory:',
})
```

:::warning
更换或重启进程时，内存存储会重置。此方式仅适合开发。
:::

以下示例配置了一个嵌入式副本，用于与远程主数据库（例如 Turso 上的数据库）同步。

```typescript
storage: new LibSQLStore({
  id: 'libsql-storage',
  url: 'file:./replica.db',
  syncUrl: 'libsql://your-db-name.aws-ap-northeast-1.turso.io',
  authToken: process.env.TURSO_AUTH_TOKEN,
  syncInterval: 60,
})
```

## 托管表 {/* #managed-tables */}

存储实现会自动创建核心存储表，其中 `mastra_notifications` 用于保存通知收件箱记录和投递元数据。

在 `LibSQLStore` 上调用 `getStore('notifications')` 即可访问通知存储。

## 初始化 {/* #initialization */}

将存储实例传给 Mastra 类时，Mastra 会自动调用 `init()` 创建[核心数据库结构](/reference/storage/overview#core-schema)。

```typescript
import { Mastra } from '@mastra/core'
import { LibSQLStore } from '@mastra/libsql'

const storage = new LibSQLStore({
  id: 'libsql-storage',
  url: 'file:./storage.db',
})

const mastra = new Mastra({
  storage, // init() called automatically
})
```

如果绕过 Mastra 直接使用存储实例，请显式调用 `init()`。

```typescript
import { LibSQLStore } from '@mastra/libsql'

const storage = new LibSQLStore({
  id: 'libsql-storage',
  url: 'file:./storage.db',
})

await storage.init()

// Access domain-specific stores via getStore()
const memoryStore = await storage.getStore('memory')
const thread = await memoryStore?.getThreadById({ threadId: '...' })
```

## 可观察性 {/* #observability */}

libSQL 支持可观察性，适合本地开发。调试时可以使用 `realtime` [追踪策略](/docs/observability/integrations/exporters/mastra-storage#tracing-strategies) 即时查看 Trace。

如果生产环境的 Trace 数据量较大，可以考虑使用 [PostgreSQL](/integrations/databases/postgresql)，或[通过组合存储使用 ClickHouse](/reference/storage/composite#specialized-storage-for-observability)。
