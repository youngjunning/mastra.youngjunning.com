# Elasticsearch

Elasticsearch 存储实现通过官方 [`@elastic/elasticsearch`](https://github.com/elastic/elasticsearch-js) 客户端，将 Agent 记忆、Workflow 快照和评分存储在 Elasticsearch 集群中。它与 `ElasticSearchVector` 使用相同的连接配置，因此 Agent 记忆和语义召回可以共用同一个集群，甚至共用同一个客户端实例。

`ElasticSearchStore` 目前支持 `memory`、`workflows` 和 `scores` 三个存储域。

## 安装 {/* #installation */}

```bash
npm install @mastra/elasticsearch
```

## 使用方法 {/* #usage */}

### 使用 URL {/* #using-a-url */}

```typescript
import { ElasticSearchStore } from '@mastra/elasticsearch'

const storage = new ElasticSearchStore({
  id: 'elasticsearch-storage',
  url: 'http://localhost:9200',
})

await storage.init()
```

### 使用身份验证 {/* #using-authentication */}

```typescript
import { ElasticSearchStore } from '@mastra/elasticsearch'

const storage = new ElasticSearchStore({
  id: 'elasticsearch-storage',
  url: 'https://my-cluster.example.com:9200',
  auth: { apiKey: process.env.ELASTICSEARCH_API_KEY! },
})
```

`auth` 也接受 `{ username, password }` 或 `{ bearer }`。

### 使用预配置的客户端 {/* #using-a-pre-configured-client */}

如果需要设置云 ID、TLS 选项或自定义传输等高级选项，请传入预配置的客户端。`ElasticSearchVector` 可以共用这个客户端。

```typescript
import { Client } from '@elastic/elasticsearch'
import { ElasticSearchStore, ElasticSearchVector } from '@mastra/elasticsearch'

const client = new Client({
  node: 'https://my-cluster.example.com:9200',
  auth: { apiKey: process.env.ELASTICSEARCH_API_KEY! },
})

const storage = new ElasticSearchStore({ id: 'elasticsearch-storage', client })
const vector = new ElasticSearchVector({ id: 'elasticsearch-vector', client })
```

自行传入的客户端需由你管理其生命周期。调用 `storage.close()` 后，该客户端仍保持打开。

## 附加说明 {/* #additional-notes */}

### 索引结构 {/* #index-structure */}

每个 Mastra 存储表都对应一个同名的 Elasticsearch 索引，例如 `mastra_threads`、`mastra_messages`、`mastra_workflow_snapshot` 和 `mastra_scorers`。记录以不解析内部结构的 JSON 文档形式存储，其中 `key` 字段的类型为 keyword。索引会在首次使用时自动创建，无需手动管理索引映射。

### 一致性 {/* #consistency */}

Elasticsearch 提供近实时搜索。每次写入都会立即刷新索引，因此后续读取和搜索都能看到写入结果。读取单条记录时，系统会按 ID 实时获取文档。

### 关闭连接 {/* #closing-connections */}

应用程序退出时，请调用以下方法关闭连接。

```typescript
await storage.close()
```

此方法只会关闭 `ElasticSearchStore` 根据 `url` 创建的客户端。自行传入的客户端仍保持打开。

## 使用示例 {/* #usage-example */}

### 为 Agent 添加记忆 {/* #adding-memory-to-an-agent */}

```typescript title="src/mastra/agents/elasticsearch-agent.ts"
import { Memory } from '@mastra/memory'
import { Agent } from '@mastra/core/agent'
import { ElasticSearchStore } from '@mastra/elasticsearch'

export const elasticsearchAgent = new Agent({
  id: 'elasticsearch-agent',
  name: 'Elasticsearch Agent',
  instructions:
    'You are an AI agent with the ability to automatically recall memories from previous interactions.',
  model: '__GATEWAY_OPENAI_MODEL__',
  memory: new Memory({
    storage: new ElasticSearchStore({
      id: 'elasticsearch-agent-storage',
      url: process.env.ELASTICSEARCH_URL!,
      auth: { apiKey: process.env.ELASTICSEARCH_API_KEY! },
    }),
    options: {
      lastMessages: 10,
    },
  }),
})
```

### 在 Mastra 实例中使用 {/* #using-with-mastra-instance */}

```typescript
import { Mastra } from '@mastra/core'
import { ElasticSearchStore } from '@mastra/elasticsearch'

const storage = new ElasticSearchStore({
  id: 'mastra-storage',
  url: 'http://localhost:9200',
})

const mastra = new Mastra({
  storage, // init() called automatically
})
```

如果绕过 Mastra 实例直接使用存储，请显式调用 `init()`。

```typescript
import { ElasticSearchStore } from '@mastra/elasticsearch'

const storage = new ElasticSearchStore({
  id: 'elasticsearch-storage',
  url: 'http://localhost:9200',
})

await storage.init()

// Access domain-specific stores via getStore()
const memoryStore = await storage.getStore('memory')
const thread = await memoryStore?.getThreadById({ threadId: '...' })
```
