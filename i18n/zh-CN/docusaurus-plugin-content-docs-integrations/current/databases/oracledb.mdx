# 甲骨文数据库

OracleDB 存储提供程序将 Mastra 应用程序状态存储在 Oracle 数据库中。它实现了Mastra的复合存储接口，所以一`OracleStore`实例可以支持内存、Workflow程快照、可观察性、分数、记分器定义、MCP 客户端元数据和Agent注册表数据。

## 安装 {/* #installation */}

```bash npm2yarn
npm install @mastra/oracledb@latest
```

## 用法 {/* #usage */}

```ts
import { OracleStore } from '@mastra/oracledb'

const storage = new OracleStore({
  id: 'oracle-storage',
  user: process.env.ORACLE_DATABASE_USER,
  password: process.env.ORACLE_DATABASE_PASSWORD,
  connectString: process.env.ORACLE_DATABASE_CONNECT_STRING,
})
```

与 Mastra 一起使用：

```ts
import { Mastra } from '@mastra/core/mastra'

export const mastra = new Mastra({
  storage,
})
```

## 连接示例 {/* #connection-examples */}

基本的用户名/密码构造函数如上所示。对于自治数据库，将钱包选项添加到同一构造函数中：

```ts
const storage = new OracleStore({
  id: 'oracle-storage',
  user: process.env.ORACLE_DATABASE_USER,
  password: process.env.ORACLE_DATABASE_PASSWORD,
  connectString: process.env.ORACLE_DATABASE_CONNECT_STRING,
  walletLocation: process.env.ORACLE_DATABASE_WALLET_DIR,
  walletPassword: process.env.ORACLE_DATABASE_WALLET_PASSWORD,
  configDir: process.env.ORACLE_DATABASE_CONFIG_DIR,
})
```

对于外部身份验证，设置`externalAuth: true` and omit `password`. To reuse an existing `oracledb.Pool`, pass it as `pool`. Mastra uses it but doesn't close it.

`OracleStore`支持内存、Workflow程快照、可观察性、分数、记分器定义、MCP 客户端元数据和座席注册数据。在室外使用商店时`Mastra` instance, call `await storage.init()` and access a domain with `await storage.getStore('memory')`.

## 初始化 {/* #initialization */}

当你通过时`OracleStore` to `Mastra`, `init()` is called automatically before storage operations run. If you use `OracleStore` directly, call `init()` before reading or writing:

```ts
await storage.init()
```

:::警告
如果禁用或跳过初始化，存储操作要求 Oracle 表和索引已存在。
:::

`OracleStore.init()`运行可重复的迁移并将结果记录在迁移分类帐表中。默认的账本表是`MASTRA_ORACLE_MIGRATIONS`.

```ts
await storage.migrate()
const history = await storage.listMigrations()
```

可重复的迁移是幂等的。它们在启动时协调每个存储域拥有的表和索引，这允许应用新的域索引或兼容的架构添加，而无需更改应用程序代码。

初始化还为常见 Mastra 查询路径创建提供程序的默认索引。使用`skipDefaultIndexes` when indexes are managed separately, or pass `indexes` for custom Oracle indexes. Custom definitions support Oracle options such as `bitmap`, `online`, `invisible`, `parallel`, `compress`, `noLogging`, and `reverse`，以及基于函数的表达式，例如`JSON_VALUE(...)`.

当您的应用程序重复过滤 JSON 元数据时，或者当数据库管理员 (DBA) 希望在优化器使用索引之前测试索引时，自定义索引非常有用：

```ts
const storage = new OracleStore({
  id: 'oracle-storage',
  user,
  password,
  connectString,
  indexes: [
    {
      name: 'idx_messages_status',
      table: 'mastra_messages',
      columns: [
        "JSON_VALUE(metadata, '$.status' RETURNING VARCHAR2(32) NULL ON ERROR)",
        'thread_id',
      ],
      online: true,
      invisible: true,
    },
  ],
})
```

使用`invisible` for staged rollout, then remove it after validating query plans. Use `skipDefaultIndexes: true` only when a DBA-managed indexing strategy replaces the defaults.

使用`disableInit: true` when schema changes are applied by a separate deployment step or by a database administrator.

## 架构导出 {/* #schema-export */}

使用`exportSchemas()` to generate Oracle DDL without connecting to a database. This is useful when schema changes are reviewed or applied outside application startup.

```ts
import { exportSchemas } from '@mastra/oracledb'

const ddl = exportSchemas({
  schemaName: 'MASTRA_APP',
  domains: [
    'memory',
    'workflows',
    'observability',
    'scores',
    'scorerDefinitions',
    'mcpClients',
    'agents',
  ],
})

console.log(ddl)
```

`domains`默认为每个受支持的域，包括`vector`, when omitted.

## 操作注意事项 {/* #operational-notes */}

使用相同的`OraclePoolManager` when `OracleStore` and `OracleVector` should share one Oracle connection lifecycle:

```ts
import { OracleStore, OracleVector } from '@mastra/oracledb'

const storage = new OracleStore({ id: 'oracle-storage', user, password, connectString })
const vector = new OracleVector({
  id: 'oracle-vector',
  poolManager: storage.getPoolManager(),
})
```

`OracleStore`暴露`storage.db` and `await storage.getPool()` for advanced use cases. When using these APIs directly, you're responsible for transaction boundaries and connection lifecycle.

JSON 元数据、有效负载和快照存储在本机 Oracle JSON 列中并在服务器端进行编码，因此可以使用标准 Oracle JDBC Tool（例如 DBeaver 和 SQL Developer）直接读取这些行。

## 使用示例 {/* #usage-example */}

### 将 OracleDB 内存添加到Agent {/* #adding-oracledb-memory-to-an-agent */}

```ts title="src/mastra/agents/oracle-agent.ts"
import { Agent } from '@mastra/core/agent'
import { Memory } from '@mastra/memory'
import { OracleStore } from '@mastra/oracledb'

const storage = new OracleStore({
  id: 'oracle-storage',
  user: process.env.ORACLE_DATABASE_USER,
  password: process.env.ORACLE_DATABASE_PASSWORD,
  connectString: process.env.ORACLE_DATABASE_CONNECT_STRING,
})

export const oracleAgent = new Agent({
  id: 'oracle-agent',
  name: 'Oracle Agent',
  instructions: 'You are an assistant with persistent OracleDB-backed memory.',
  model: '__GATEWAY_OPENAI_MODEL__',
  memory: new Memory({ storage }),
})
```
