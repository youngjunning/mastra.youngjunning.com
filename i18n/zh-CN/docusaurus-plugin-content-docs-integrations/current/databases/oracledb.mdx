# OracleDB

OracleDB 存储 Provider 将 Mastra 应用的状态保存到 Oracle Database。它实现了 Mastra 的复合存储接口，因此一个 `OracleStore` 实例就能存储记忆、Workflow 快照、可观测性数据、评分、评分器定义、MCP 客户端元数据和 Agent 注册表数据。

## 安装 {/* #installation */}

```bash npm2yarn
npm install @mastra/oracledb@latest
```

## 使用方法 {/* #usage */}

```ts
import { OracleStore } from '@mastra/oracledb'

const storage = new OracleStore({
  id: 'oracle-storage',
  user: process.env.ORACLE_DATABASE_USER,
  password: process.env.ORACLE_DATABASE_PASSWORD,
  connectString: process.env.ORACLE_DATABASE_CONNECT_STRING,
})
```

将存储实例传给 Mastra：

```ts
import { Mastra } from '@mastra/core/mastra'

export const mastra = new Mastra({
  storage,
})
```

## 连接示例 {/* #connection-examples */}

上面的示例展示了如何用用户名和密码创建存储实例。连接 Autonomous Database 时，在同一个构造函数中传入钱包选项：

```ts
const storage = new OracleStore({
  id: 'oracle-storage',
  user: process.env.ORACLE_DATABASE_USER,
  password: process.env.ORACLE_DATABASE_PASSWORD,
  connectString: process.env.ORACLE_DATABASE_CONNECT_STRING,
  walletLocation: process.env.ORACLE_DATABASE_WALLET_DIR,
  walletPassword: process.env.ORACLE_DATABASE_WALLET_PASSWORD,
  configDir: process.env.ORACLE_DATABASE_CONFIG_DIR,
})
```

要使用外部身份验证，请设置 `externalAuth: true` 并省略 `password`。要复用已有的 `oracledb.Pool`，请将其作为 `pool` 传入。Mastra 会使用该连接池，但不会关闭它。

`OracleStore` 可存储记忆、Workflow 快照、可观测性数据、评分、评分器定义、MCP 客户端元数据和 Agent 注册表数据。独立于 `Mastra` 实例使用存储时，先调用 `await storage.init()`，再通过 `await storage.getStore('memory')` 访问相应的存储域。

## 初始化 {/* #initialization */}

将 `OracleStore` 传给 `Mastra` 后，Mastra 会在执行存储操作前自动调用 `init()`。如果直接使用 `OracleStore`，请在读写前调用 `init()`：

```ts
await storage.init()
```

:::warning
如果禁用或跳过初始化，必须先确保所需的 Oracle 表和索引已存在，才能执行存储操作。
:::

`OracleStore.init()` 会执行可重复运行的迁移，并将结果写入迁移记录表。默认表名为 `MASTRA_ORACLE_MIGRATIONS`。

```ts
await storage.migrate()
const history = await storage.listMigrations()
```

可重复运行的迁移具有幂等性。应用启动时，迁移会将各存储域的表和索引调整到预期状态，因此无需修改应用代码，就能为存储域新增索引或应用兼容的模式扩展。

初始化时，Provider 还会为 Mastra 的常用查询创建默认索引。如果单独管理索引，请使用 `skipDefaultIndexes`；如果要创建自定义 Oracle 索引，请传入 `indexes`。自定义定义支持 `bitmap`、`online`、`invisible`、`parallel`、`compress`、`noLogging` 和 `reverse` 等 Oracle 选项，也支持 `JSON_VALUE(...)` 等基于函数的表达式。

如果应用经常按 JSON 元数据筛选，或者数据库管理员（DBA）想在优化器使用某个索引前先测试它，可以使用自定义索引：

```ts
const storage = new OracleStore({
  id: 'oracle-storage',
  user,
  password,
  connectString,
  indexes: [
    {
      name: 'idx_messages_status',
      table: 'mastra_messages',
      columns: [
        "JSON_VALUE(metadata, '$.status' RETURNING VARCHAR2(32) NULL ON ERROR)",
        'thread_id',
      ],
      online: true,
      invisible: true,
    },
  ],
})
```

分阶段上线索引时，先使用 `invisible`，验证查询计划后再移除该选项。只有在数据库管理员负责的索引策略取代默认索引时，才使用 `skipDefaultIndexes: true`。

如果模式变更由独立的部署步骤或数据库管理员执行，请使用 `disableInit: true`。

## 导出数据库模式 {/* #schema-export */}

使用 `exportSchemas()` 无需连接数据库即可生成 Oracle DDL。这样可以在应用启动流程之外审查或应用模式变更。

```ts
import { exportSchemas } from '@mastra/oracledb'

const ddl = exportSchemas({
  schemaName: 'MASTRA_APP',
  domains: [
    'memory',
    'workflows',
    'observability',
    'scores',
    'scorerDefinitions',
    'mcpClients',
    'agents',
  ],
})

console.log(ddl)
```

省略 `domains` 时，默认包含所有受支持的存储域，包括 `vector`。

## 运行注意事项 {/* #operational-notes */}

如果 `OracleStore` 和 `OracleVector` 需要共用同一套 Oracle 连接生命周期管理，请使用同一个 `OraclePoolManager`：

```ts
import { OracleStore, OracleVector } from '@mastra/oracledb'

const storage = new OracleStore({ id: 'oracle-storage', user, password, connectString })
const vector = new OracleVector({
  id: 'oracle-vector',
  poolManager: storage.getPoolManager(),
})
```

`OracleStore` 提供 `storage.db` 和 `await storage.getPool()`，以满足高级用法的需要。直接使用这些 API 时，需要自行管理事务边界和连接生命周期。

JSON 元数据、载荷和快照存放在 Oracle 原生 JSON 列中，由服务器端编码。因此，可以用 DBeaver、SQL Developer 等标准 Oracle JDBC 工具直接读取这些数据行。

## 使用示例 {/* #usage-example */}

### 为 Agent 添加由 OracleDB 存储的记忆 {/* #adding-oracledb-memory-to-an-agent */}

```ts title="src/mastra/agents/oracle-agent.ts"
import { Agent } from '@mastra/core/agent'
import { Memory } from '@mastra/memory'
import { OracleStore } from '@mastra/oracledb'

const storage = new OracleStore({
  id: 'oracle-storage',
  user: process.env.ORACLE_DATABASE_USER,
  password: process.env.ORACLE_DATABASE_PASSWORD,
  connectString: process.env.ORACLE_DATABASE_CONNECT_STRING,
})

export const oracleAgent = new Agent({
  id: 'oracle-agent',
  name: 'Oracle Agent',
  instructions: 'You are an assistant with persistent OracleDB-backed memory.',
  model: '__GATEWAY_OPENAI_MODEL__',
  memory: new Memory({ storage }),
})
```
