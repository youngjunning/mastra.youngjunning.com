# LanceDB

LanceDB 存储实现基于 LanceDB 数据库提供高性能存储，擅长处理传统数据存储和向量操作。

:::warning[不支持 Observability]

LanceDB 存储 **不支持 Observability 域**。`MastraStorageExporter` 导出的 Trace 无法持久化到 LanceDB。如果 LanceDB 是唯一的存储 Provider，[Studio](/docs/studio/overview) 的 Observability 功能将无法使用。要启用 Observability，请使用[复合存储](/reference/storage/composite#specialized-storage-for-observability)将 Observability 数据路由到 ClickHouse 等受支持的 Provider。

:::

## 安装 {/* #installation */}

```bash npm2yarn
npm install @mastra/lance@latest
```

## 用法 {/* #usage */}

### 存储的基本用法 {/* #basic-storage-usage */}

```typescript
import { LanceStorage } from '@mastra/lance'

// Connect to a local database
const storage = await LanceStorage.create('my-storage', '/path/to/db')

// Connect to a LanceDB cloud database
const storage = await LanceStorage.create('my-storage', 'db://host:port')

// Connect to a cloud database with custom options
const storage = await LanceStorage.create('my-storage', 's3://bucket/db', {
  storageOptions: { timeout: '60s' },
})
```

## 补充说明 {/* #additional-notes */}

### 数据模式管理 {/* #schema-management */}

LanceStorage 实现会自动创建和更新数据模式，并将 Mastra 的模式类型映射为 LanceDB 内部使用的 Apache Arrow 数据类型：

- `text`, `uuid` → Utf8
- `int`, `integer` → Int32
- `float` → Float32
- `jsonb`, `json` → Utf8（序列化后）
- `binary` → Binary

### 初始化 {/* #initialization */}

将存储实例传入 Mastra 类后，Mastra 会在执行任何存储操作前自动调用 `init()`：

```typescript
import { Mastra } from '@mastra/core'
import { LanceStorage } from '@mastra/lance'

const storage = await LanceStorage.create('my-storage', '/path/to/db')

const mastra = new Mastra({
  storage, // init() is called automatically
})
```

如果绕过 Mastra 直接使用存储实例，必须显式调用 `init()` 来创建表：

```typescript
import { LanceStorage } from '@mastra/lance'

const storage = await LanceStorage.create('my-storage', '/path/to/db')

// Required when using storage directly
await storage.init()

// Access domain-specific stores via getStore()
const memoryStore = await storage.getStore('memory')
const thread = await memoryStore?.getThreadById({ threadId: '...' })
```

:::warning
如果未调用 `init()`，系统就不会创建表，存储操作可能会静默失败或抛出错误。
:::

### 部署选项 {/* #deployment-options */}

可以根据部署场景配置 LanceDB 存储：

- **本地开发**：使用本地文件路径进行开发和测试
  ```text
  /path/to/db
  ```
- **云端部署**：连接到托管的 LanceDB 实例
  ```text
  db://host:port
  ```
- **S3 存储**：使用 Amazon S3 提供大容量云存储
  ```text
  s3://bucket/db
  ```

### 数据表管理 {/* #table-management */}

LanceStorage 提供以下数据表管理操作：

- 使用自定义数据模式创建表
- 删除表
- 清空表（删除所有记录）
- 根据键加载记录
- 逐条或批量插入记录
