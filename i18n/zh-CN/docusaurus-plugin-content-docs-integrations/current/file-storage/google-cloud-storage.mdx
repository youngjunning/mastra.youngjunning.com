# 谷歌云存储

将文件存储在 Google Cloud Storage 中。接口详情请参见[WorkspaceFilesystem Interface](/reference/workspace/filesystem).

## 安装 {/* #installation */}

```bash npm2yarn
npm install @mastra/gcs
```

## 用法 {/* #usage */}

添加一个`GCSFilesystem` to a workspace and assign it to an agent:

```typescript
import { Agent } from '@mastra/core/agent'
import { Workspace } from '@mastra/core/workspace'
import { GCSFilesystem } from '@mastra/gcs'

const workspace = new Workspace({
  filesystem: new GCSFilesystem({
    bucket: 'my-gcs-bucket',
    projectId: 'my-project-id',
    credentials: JSON.parse(process.env.GCS_SERVICE_ACCOUNT_KEY),
  }),
})

const agent = new Agent({
  id: 'file-agent',
  name: 'file-agent',
  model: '__GATEWAY_ANTHROPIC_MODEL_OPUS__',
  workspace,
})
```

### 使用应用程序默认凭据 {/* #using-application-default-credentials */}

如果在 Google Cloud 上运行或使用`gcloud` CLI configured, you can omit credentials:

```typescript
import { GCSFilesystem } from '@mastra/gcs'

const filesystem = new GCSFilesystem({
  bucket: 'my-gcs-bucket',
  // Uses Application Default Credentials automatically
})
```

[应用程序默认凭据 (ADC)](https://cloud.google.com/docs/authentication/application-default-credentials)按以下顺序自动发现凭据：

1. `GOOGLE_APPLICATION_CREDENTIALS`环境变量（服务帐户密钥文件的路径）
2. 在 GCP（Compute Engine、Cloud Run、GKE 等）上运行时的默认服务帐户
3. 用户凭据来自`gcloud auth application-default login` (for local development)

### 使用密钥文件路径 {/* #using-a-key-file-path */}

您还可以传递服务帐户密钥文件的路径：

```typescript
import { GCSFilesystem } from '@mastra/gcs'

const filesystem = new GCSFilesystem({
  bucket: 'my-gcs-bucket',
  projectId: 'my-project-id',
  credentials: '/path/to/service-account-key.json',
})
```

## 方法 {/* #methods */}

GCSFilesystem 实现了[WorkspaceFilesystem interface](/reference/workspace/filesystem), providing all standard filesystem methods:

* `readFile(path, options?)`- 读取文件内容
* `writeFile(path, content, options?)`- 将内容写入文件
* `appendFile(path, content)`- 将内容附加到文件
* `deleteFile(path, options?)`- 删除文件
* `copyFile(src, dest, options?)`- 复制文件
* `moveFile(src, dest, options?)`- 移动或重命名文件
* `mkdir(path, options?)`- 创建目录
* `rmdir(path, options?)`- 删除目录
* `readdir(path, options?)`- 列出目录内容
* `exists(path)`- 检查路径是否存在
* `stat(path)`- 获取文件或目录元数据

### `init()` {/* #init */}

初始化文件系统。验证存储桶访问和凭据。

```typescript
await filesystem.init()
```

### `getInfo()` {/* #getinfo */}

返回有关此文件系统实例的元数据。

```typescript
const info = filesystem.getInfo()
// { id: '...', name: 'GCSFilesystem', provider: 'gcs', status: 'ready' }
```

### `getMountConfig()` {/* #getmountconfig */}

返回支持挂载此文件系统类型的Sandbox的挂载配置。

```typescript
const config = filesystem.getMountConfig()
// { type: 'gcs', bucket: 'my-bucket', ... }
```

## 安装在 E2B Sandbox中 {/* #mounting-in-e2b-sandboxes */}

GCSFilesystem 可以挂载到 E2B Sandbox中，使存储桶可作为本地目录访问：

```typescript
import { Workspace } from '@mastra/core/workspace'
import { GCSFilesystem } from '@mastra/gcs'
import { E2BSandbox } from '@mastra/e2b'

const workspace = new Workspace({
  mounts: {
    '/data': new GCSFilesystem({
      bucket: 'my-gcs-bucket',
      projectId: 'my-project-id',
      credentials: JSON.parse(process.env.GCS_SERVICE_ACCOUNT_KEY),
    }),
  },
  sandbox: new E2BSandbox({ id: 'dev-sandbox' }),
})
```

看[E2BSandbox reference](/integrations/sandboxes/e2b) for more details on mounting.
