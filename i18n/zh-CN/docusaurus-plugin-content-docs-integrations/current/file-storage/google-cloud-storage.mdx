# Google Cloud Storage

此集成将文件存储在 Google Cloud Storage 中。接口详情请参见 [WorkspaceFilesystem 接口](/reference/workspace/filesystem)。

## 安装 {/* #installation */}

```bash npm2yarn
npm install @mastra/gcs
```

## 使用方法 {/* #usage */}

将 `GCSFilesystem` 配置为 Workspace 的文件系统，再将该 Workspace 分配给 Agent。

```typescript
import { Agent } from '@mastra/core/agent'
import { Workspace } from '@mastra/core/workspace'
import { GCSFilesystem } from '@mastra/gcs'

const workspace = new Workspace({
  filesystem: new GCSFilesystem({
    bucket: 'my-gcs-bucket',
    projectId: 'my-project-id',
    credentials: JSON.parse(process.env.GCS_SERVICE_ACCOUNT_KEY),
  }),
})

const agent = new Agent({
  id: 'file-agent',
  name: 'file-agent',
  model: '__GATEWAY_ANTHROPIC_MODEL_OPUS__',
  workspace,
})
```

### 使用应用程序默认凭据 {/* #using-application-default-credentials */}

如果应用在 Google Cloud 上运行，或已配置 `gcloud` CLI，可以省略凭据参数。

```typescript
import { GCSFilesystem } from '@mastra/gcs'

const filesystem = new GCSFilesystem({
  bucket: 'my-gcs-bucket',
  // Uses Application Default Credentials automatically
})
```

[应用程序默认凭据（ADC）](https://cloud.google.com/docs/authentication/application-default-credentials)会按以下顺序自动查找凭据。

1. `GOOGLE_APPLICATION_CREDENTIALS` 环境变量指向的服务账号密钥文件
2. 在 GCP（Compute Engine、Cloud Run、GKE 等）上运行时使用的默认服务账号凭据
3. 通过 `gcloud auth application-default login` 获取的用户凭据（用于本地开发）

### 使用密钥文件路径 {/* #using-a-key-file-path */}

也可以传入服务账号密钥文件的路径。

```typescript
import { GCSFilesystem } from '@mastra/gcs'

const filesystem = new GCSFilesystem({
  bucket: 'my-gcs-bucket',
  projectId: 'my-project-id',
  credentials: '/path/to/service-account-key.json',
})
```

## 方法 {/* #methods */}

GCSFilesystem 实现了 [WorkspaceFilesystem 接口](/reference/workspace/filesystem)，提供全部标准文件系统方法。

* `readFile(path, options?)` - 读取文件内容
* `writeFile(path, content, options?)` - 将内容写入文件
* `appendFile(path, content)` - 将内容追加到文件末尾
* `deleteFile(path, options?)` - 删除文件
* `copyFile(src, dest, options?)` - 复制文件
* `moveFile(src, dest, options?)` - 移动或重命名文件
* `mkdir(path, options?)` - 创建目录
* `rmdir(path, options?)` - 删除目录
* `readdir(path, options?)` - 列出目录内容
* `exists(path)` - 检查路径是否存在
* `stat(path)` - 获取文件或目录的元数据

### `init()` {/* #init */}

初始化文件系统，并检查凭据是否有效、存储桶是否可访问。

```typescript
await filesystem.init()
```

### `getInfo()` {/* #getinfo */}

返回此文件系统实例的元数据。

```typescript
const info = filesystem.getInfo()
// { id: '...', name: 'GCSFilesystem', provider: 'gcs', status: 'ready' }
```

### `getMountConfig()` {/* #getmountconfig */}

返回挂载配置，供支持挂载此类文件系统的 Sandbox 使用。

```typescript
const config = filesystem.getMountConfig()
// { type: 'gcs', bucket: 'my-bucket', ... }
```

## 在 E2B Sandbox 中挂载 {/* #mounting-in-e2b-sandboxes */}

将 GCSFilesystem 挂载到 E2B Sandbox 后，就可以像访问本地目录一样访问存储桶。

```typescript
import { Workspace } from '@mastra/core/workspace'
import { GCSFilesystem } from '@mastra/gcs'
import { E2BSandbox } from '@mastra/e2b'

const workspace = new Workspace({
  mounts: {
    '/data': new GCSFilesystem({
      bucket: 'my-gcs-bucket',
      projectId: 'my-project-id',
      credentials: JSON.parse(process.env.GCS_SERVICE_ACCOUNT_KEY),
    }),
  },
  sandbox: new E2BSandbox({ id: 'dev-sandbox' }),
})
```

有关挂载的详细说明，请参见 [E2BSandbox 参考文档](/integrations/sandboxes/e2b)。
