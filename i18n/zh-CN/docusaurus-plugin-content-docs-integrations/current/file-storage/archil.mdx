# Archil

此集成将文件存储在 [Archil](https://docs.archil.com) 的弹性无服务器磁盘上。通过兼容 S3 的对象 API 快速读写文件，通过 `exec()` 执行 POSIX shell 操作，并通过 `diskGrep()` 在服务端并行搜索。有关接口的详细信息，请参阅 [WorkspaceFilesystem 接口](/reference/workspace/filesystem)。

## 安装 {/* #installation */}

```bash npm2yarn
npm install @mastra/archil
```

## 使用方法 {/* #usage */}

将 `ArchilFilesystem` 配置为 Workspace 的文件系统，再将该 Workspace 分配给 Agent。

```typescript
import { Agent } from '@mastra/core/agent'
import { Workspace } from '@mastra/core/workspace'
import { ArchilFilesystem } from '@mastra/archil'

const workspace = new Workspace({
  filesystem: new ArchilFilesystem({
    diskId: 'dsk-0123456789abcdef',
    apiKey: process.env.ARCHIL_API_KEY,
    region: 'aws-us-east-1',
  }),
})

const agent = new Agent({
  id: 'file-agent',
  name: 'file-agent',
  model: '__GATEWAY_ANTHROPIC_MODEL_OPUS__',
  workspace,
})
```

### 初始化时创建磁盘 {/* #creating-a-new-disk-on-init */}

如果没有可用的现有磁盘，可以提供 `createDiskOptions`，让文件系统在初始化时自动创建磁盘。

```typescript
import { ArchilFilesystem } from '@mastra/archil'

const filesystem = new ArchilFilesystem({
  apiKey: process.env.ARCHIL_API_KEY,
  region: 'aws-us-east-1',
  createDiskOptions: {
    name: 'my-agent-workspace',
  },
})

await filesystem.init()
// filesystem.diskId now contains the newly created disk ID
```

### 从环境变量读取配置 {/* #environment-variable-fallbacks */}

省略 `apiKey` 和 `region` 时，Provider 会从环境变量读取相应的值。也可以通过环境变量指定自定义 S3 端点。

* `ARCHIL_API_KEY` — API 密钥
* `ARCHIL_REGION` — 区域，例如 `aws-us-east-1`
* `ARCHIL_S3_BASE_URL` — 自定义 S3 端点（可选）

```typescript
import { ArchilFilesystem } from '@mastra/archil'

// Uses ARCHIL_API_KEY and ARCHIL_REGION from environment
const filesystem = new ArchilFilesystem({
  diskId: 'dsk-0123456789abcdef',
})
```

## 方法 {/* #methods */}

ArchilFilesystem 实现了 [WorkspaceFilesystem 接口](/reference/workspace/filesystem)，提供以下所有标准文件系统方法。

* `readFile(path, options?)` — 读取文件内容
* `writeFile(path, content, options?)` — 将内容写入文件
* `appendFile(path, content)` — 将内容追加到文件末尾
* `deleteFile(path, options?)` — 删除文件
* `copyFile(src, dest, options?)` — 复制文件
* `moveFile(src, dest, options?)` — 移动或重命名文件
* `mkdir(path, options?)` — 创建目录
* `rmdir(path, options?)` — 删除目录
* `readdir(path, options?)` — 列出目录内容
* `exists(path)` — 检查路径是否存在
* `stat(path)` — 获取文件或目录的元数据

### `init()` {/* #init */}

初始化文件系统，并连接到现有磁盘或创建新磁盘。

```typescript
await filesystem.init()
```

### `getInfo()` {/* #getinfo */}

返回此文件系统实例的元数据。

```typescript
const info = filesystem.getInfo()
// { id: '...', name: 'ArchilFilesystem', provider: 'archil', status: 'ready' }
```

### Archil 专用方法 {/* #archil-specific-methods */}

#### `exec(command)` {/* #execcommand */}

在磁盘上运行 shell 命令，返回退出码、标准输出（stdout）和标准错误（stderr）。

```typescript
const result = await filesystem.exec('ls -la /data')
// { exitCode: 0, stdout: '...', stderr: '' }
```

#### `diskGrep(options)` {/* #diskgrepoptions */}

在服务端并行搜索磁盘上的文件。

```typescript
const results = await filesystem.diskGrep({
  directory: '/logs',
  pattern: 'ERROR',
  recursive: true,
  glob: '*.log',
})
// { matches: [...], stoppedReason: null }
```

#### `share(path, options?)` {/* #sharepath-options */}

生成可用于共享文件的签名 URL。

```typescript
const { url } = await filesystem.share('/reports/output.pdf', {
  expiresIn: 3600,
})
```
