# Azure Blob

将文件存储在 Azure Blob Storage 的容器中。有关接口的详细说明，请参阅 [WorkspaceFilesystem 接口](/reference/workspace/filesystem)。

## 安装 {/* #installation */}

```bash npm2yarn
npm install @mastra/azure
```

## 使用方法 {/* #usage */}

将 `AzureBlobFilesystem` 添加到 Workspace，再将该 Workspace 分配给 Agent：

```typescript
import { Agent } from '@mastra/core/agent'
import { Workspace } from '@mastra/core/workspace'
import { AzureBlobFilesystem } from '@mastra/azure/blob'

const workspace = new Workspace({
  filesystem: new AzureBlobFilesystem({
    container: 'my-container',
    connectionString: process.env.AZURE_STORAGE_CONNECTION_STRING,
  }),
})

const agent = new Agent({
  id: 'file-agent',
  name: 'file-agent',
  model: '__GATEWAY_ANTHROPIC_MODEL_OPUS__',
  workspace,
})
```

### 账户密钥 {/* #account-key */}

如果不想传入完整的连接字符串，可以改用账户名称和账户密钥：

```typescript
import { AzureBlobFilesystem } from '@mastra/azure/blob'

const filesystem = new AzureBlobFilesystem({
  container: 'my-container',
  accountName: process.env.AZURE_STORAGE_ACCOUNT_NAME,
  accountKey: process.env.AZURE_STORAGE_ACCOUNT_KEY,
})
```

### 共享访问签名令牌 {/* #shared-access-signature-token */}

使用共享访问签名（SAS）令牌时，请同时提供 `accountName` 或 `endpoint`：

```typescript
import { AzureBlobFilesystem } from '@mastra/azure/blob'

const filesystem = new AzureBlobFilesystem({
  container: 'my-container',
  accountName: process.env.AZURE_STORAGE_ACCOUNT_NAME,
  sasToken: process.env.AZURE_STORAGE_SAS_TOKEN,
})
```

### DefaultAzureCredential {/* #defaultazurecredential */}

如果运行环境提供 Azure 身份凭据，请使用 `DefaultAzureCredential`：

```typescript
import { AzureBlobFilesystem } from '@mastra/azure/blob'

const filesystem = new AzureBlobFilesystem({
  container: 'my-container',
  accountName: process.env.AZURE_STORAGE_ACCOUNT_NAME,
  useDefaultCredential: true,
})
```

使用 `DefaultAzureCredential` 时，请安装 `@azure/identity`：

```bash npm2yarn
npm install @azure/identity
```

## 方法 {/* #methods */}

AzureBlobFilesystem 实现了 [WorkspaceFilesystem 接口](/reference/workspace/filesystem)，提供以下标准文件系统方法：

* `readFile(path, options?)`：读取文件内容
* `writeFile(path, content, options?)`：将内容写入文件
* `appendFile(path, content)`：将内容追加到文件末尾
* `deleteFile(path, options?)`：删除文件
* `copyFile(src, dest, options?)`：复制文件
* `moveFile(src, dest, options?)`：移动或重命名文件
* `mkdir(path, options?)`：创建目录
* `rmdir(path, options?)`：删除目录
* `readdir(path, options?)`：列出目录内容
* `exists(path)`：检查路径是否存在
* `stat(path)`：获取文件或目录的元数据

### `init()` {/* #init */}

初始化文件系统，检查容器是否可访问，并验证凭据。

```typescript
await filesystem.init()
```

### `getInfo()` {/* #getinfo */}

返回此文件系统实例的元数据。

```typescript
const info = filesystem.getInfo()
// { id: '...', name: 'AzureBlobFilesystem', provider: 'azure-blob', status: 'ready' }
```

### `getContainer()` {/* #getcontainer */}

返回底层的 Azure Blob Storage `ContainerClient`。

```typescript
const container = await filesystem.getContainer()
```

### `getMountConfig()` {/* #getmountconfig */}

返回供支持挂载 Azure Blob 文件系统的 Sandbox Provider 使用的挂载配置。

```typescript
const config = filesystem.getMountConfig()
// { type: 'azure-blob', container: 'my-container', ... }
```

:::note

在 Sandbox 中挂载 Azure Blob 的前提是 Sandbox 支持 `azure-blob` 挂载配置。如果你的 Sandbox Provider 不支持挂载 Azure Blob，请使用 `filesystem` 直接操作 Workspace 中的文件。

:::
