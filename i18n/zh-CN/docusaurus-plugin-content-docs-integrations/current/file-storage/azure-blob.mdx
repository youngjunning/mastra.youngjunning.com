# 蔚蓝斑点

将文件存储在 Azure Blob 存储容器中。接口详情请参见[WorkspaceFilesystem Interface](/reference/workspace/filesystem).

## 安装 {/* #installation */}

```bash npm2yarn
npm install @mastra/azure
```

## 用法 {/* #usage */}

添加一个`AzureBlobFilesystem` to a workspace and assign it to an agent:

```typescript
import { Agent } from '@mastra/core/agent'
import { Workspace } from '@mastra/core/workspace'
import { AzureBlobFilesystem } from '@mastra/azure/blob'

const workspace = new Workspace({
  filesystem: new AzureBlobFilesystem({
    container: 'my-container',
    connectionString: process.env.AZURE_STORAGE_CONNECTION_STRING,
  }),
})

const agent = new Agent({
  id: 'file-agent',
  name: 'file-agent',
  model: '__GATEWAY_ANTHROPIC_MODEL_OPUS__',
  workspace,
})
```

### 账户密钥 {/* #account-key */}

当您不想传递完整的连接字符串时，请使用帐户名和帐户密钥：

```typescript
import { AzureBlobFilesystem } from '@mastra/azure/blob'

const filesystem = new AzureBlobFilesystem({
  container: 'my-container',
  accountName: process.env.AZURE_STORAGE_ACCOUNT_NAME,
  accountKey: process.env.AZURE_STORAGE_ACCOUNT_KEY,
})
```

### 共享访问签名令牌 {/* #shared-access-signature-token */}

使用共享访问签名 (SAS) 令牌`accountName` or `endpoint`:

```typescript
import { AzureBlobFilesystem } from '@mastra/azure/blob'

const filesystem = new AzureBlobFilesystem({
  container: 'my-container',
  accountName: process.env.AZURE_STORAGE_ACCOUNT_NAME,
  sasToken: process.env.AZURE_STORAGE_SAS_TOKEN,
})
```

### 默认Azure凭据 {/* #defaultazurecredential */}

使用`DefaultAzureCredential` when your environment provides Azure identity credentials:

```typescript
import { AzureBlobFilesystem } from '@mastra/azure/blob'

const filesystem = new AzureBlobFilesystem({
  container: 'my-container',
  accountName: process.env.AZURE_STORAGE_ACCOUNT_NAME,
  useDefaultCredential: true,
})
```

安装`@azure/identity` when you use `DefaultAzureCredential`:

```bash npm2yarn
npm install @azure/identity
```

## 方法 {/* #methods */}

AzureBlobFilesystem 实现了[WorkspaceFilesystem interface](/reference/workspace/filesystem), providing all standard filesystem methods:

* `readFile(path, options?)`- 读取文件内容
* `writeFile(path, content, options?)`- 将内容写入文件
* `appendFile(path, content)`- 将内容附加到文件
* `deleteFile(path, options?)`- 删除文件
* `copyFile(src, dest, options?)`- 复制文件
* `moveFile(src, dest, options?)`- 移动或重命名文件
* `mkdir(path, options?)`- 创建目录
* `rmdir(path, options?)`- 删除目录
* `readdir(path, options?)`- 列出目录内容
* `exists(path)`- 检查路径是否存在
* `stat(path)`- 获取文件或目录元数据

### `init()` {/* #init */}

初始化文件系统。验证容器访问和凭据。

```typescript
await filesystem.init()
```

### `getInfo()` {/* #getinfo */}

返回有关此文件系统实例的元数据。

```typescript
const info = filesystem.getInfo()
// { id: '...', name: 'AzureBlobFilesystem', provider: 'azure-blob', status: 'ready' }
```

### `getContainer()` {/* #getcontainer */}

返回底层 Azure Blob 存储`ContainerClient`.

```typescript
const container = await filesystem.getContainer()
```

### `getMountConfig()` {/* #getmountconfig */}

返回支持 Azure Blob 文件系统挂载的Sandbox提供程序的挂载配置。

```typescript
const config = filesystem.getMountConfig()
// { type: 'azure-blob', container: 'my-container', ... }
```

：：：笔记

Azure Blob Sandbox安装取决于Sandbox支持`azure-blob` mount configs. Use `filesystem` for direct workspace file operations when your sandbox provider doesn't support Azure Blob mounts.
