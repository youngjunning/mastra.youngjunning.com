# AgentFS

通过 [AgentFS](https://github.com/nichochar/agentfs) SDK 将文件存储到 Turso/SQLite 数据库。文件持久保存在本地 SQLite 数据库中，Agent 无需依赖外部云服务，即可在后续会话中访问这些文件。接口详情请参阅 [WorkspaceFilesystem 接口](/reference/workspace/filesystem)。

## 安装 {/* #installation */}

```bash npm2yarn
npm install @mastra/agentfs
```

## 使用方法 {/* #usage */}

将 `AgentFSFilesystem` 添加到 Workspace，然后将该 Workspace 分配给 Agent。创建 `AgentFSFilesystem` 实例时，必须在 `agentId`、`path` 和 `agent` 中至少提供一项。

```typescript
import { Agent } from '@mastra/core/agent'
import { Workspace } from '@mastra/core/workspace'
import { AgentFSFilesystem } from '@mastra/agentfs'

const workspace = new Workspace({
  filesystem: new AgentFSFilesystem({
    agentId: 'my-agent',
  }),
})

const agent = new Agent({
  id: 'file-agent',
  name: 'file-agent',
  model: '__GATEWAY_OPENAI_MODEL__',
  workspace,
})
```

### 指定数据库路径 {/* #using-an-explicit-database-path */}

默认情况下，数据库保存在 `.agentfs` 目录中，文件名根据 `agentId` 生成。也可以按以下方式指定自定义数据库路径。

```typescript
import { AgentFSFilesystem } from '@mastra/agentfs'

const filesystem = new AgentFSFilesystem({
  path: '/data/my-agent.db',
})
```

### 使用预先打开的 AgentFS 实例 {/* #using-a-pre-opened-agentfs-instance */}

如果需要自行管理 AgentFS 的生命周期，可以传入已打开的实例。

```typescript
import { AgentFS } from 'agentfs-sdk'
import { AgentFSFilesystem } from '@mastra/agentfs'

const agent = await AgentFS.open({ id: 'my-agent' })

const filesystem = new AgentFSFilesystem({
  agent, // caller manages open/close
})
```
