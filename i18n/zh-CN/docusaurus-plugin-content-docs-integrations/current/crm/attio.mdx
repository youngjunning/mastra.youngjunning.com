# 阿蒂奥

为客服人员提供Tool，用于通过 Mastra Connect 在 Attio 中搜索和更新 CRM 记录、注释、任务和列表。 Attio 从托管模型上下文协议 (MCP) 服务器提供这些Tool。您的应用程序从不存储 Attio 凭据。

## 连接 {/* #connect */}

在开始之前，请完成[Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect`并配置您的平台项目。

### 连接账户 {/* #connect-an-account */}

从包含您的目录的目录运行此命令`.env` file:

```bash
mastra connect add attio-mcp
```

CLI 将引导您完成 Attio 的授权并等待连接激活。

### 向Agent添加Tool {/* #add-tools-to-an-agent */}

经过[`tools()`](/reference/connect/tools) to the agent and select the `attio-mcp` provider:

```typescript title="src/mastra/agents/attio-mcp-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const attioMcpAgent = new Agent({
  id: 'attio-mcp-agent',
  name: 'Attio agent',
  instructions: 'You help people search and update CRM records, notes, tasks, and lists in Attio.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['attio-mcp'] }),
})
```

当Agent运行时，Mastra 会从其 MCP 服务器发现 Attio 的Tool。可用的Tool取决于服务器和连接的帐户，而不取决于您的`@mastra/connect` version. Tool keys start with `attio-mcp_`.

要查看 Attio 提供的Tool，请阅读[Attio MCP](https://docs.attio.com/mcp/overview) documentation. To require approval before a call runs, see [MCP providers](/reference/connect/tools#mcp-providers) in the `tools()` reference.
