# 黏土

为Agent提供Tool来查找和研究人员和公司，并通过 Mastra Connect 在 Clay 中运行Workflow程。 Clay 从托管的模型上下文协议 (MCP) 服务器提供这些Tool。您的应用程序从不存储 Clay 凭据。

## 连接 {/* #connect */}

在开始之前，请完成[Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect`并配置您的平台项目。

### 连接账户 {/* #connect-an-account */}

从包含您的目录的目录运行此命令`.env` file:

```bash
mastra connect add clay-mcp
```

CLI 将引导您完成 Clay 的授权并等待连接激活。

### 向Agent添加Tool {/* #add-tools-to-an-agent */}

经过[`tools()`](/reference/connect/tools) to the agent and select the `clay-mcp` provider:

```typescript title="src/mastra/agents/clay-mcp-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const clayMcpAgent = new Agent({
  id: 'clay-mcp-agent',
  name: 'Clay agent',
  instructions: 'You help people find and research people and companies and run workflows in Clay.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['clay-mcp'] }),
})
```

当Agent运行时，Mastra 从其 MCP 服务器发现 Clay 的Tool。可用的Tool取决于服务器和连接的帐户，而不取决于您的`@mastra/connect` version. Tool keys start with `clay-mcp_`.

要查看 Clay 提供的Tool，请阅读[MCP in Clay](https://university.clay.com/docs/mcp-settings) documentation. To require approval before a call runs, see [MCP providers](/reference/connect/tools#mcp-providers) in the `tools()` reference.
