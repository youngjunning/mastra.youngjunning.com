# Clay

通过 Mastra Connect 为 Agent 提供可在 Clay 中查找和研究人员及公司，并运行 Workflow 的 Tool。Clay 通过托管的 Model Context Protocol (MCP) 服务器提供这些 Tool；你的应用不会存储 Clay 凭据。

## 连接 {/* #connect */}

开始前，请先完成 [Connect 设置](/docs/mastra-platform/connect#get-started)，安装 `@mastra/connect` 并配置 Mastra 平台项目。

### 连接账户 {/* #connect-an-account */}

在包含 `.env` 文件的目录中运行以下命令：

```bash
mastra connect add clay-mcp
```

CLI 会引导你完成 Clay 的授权，并等待连接激活。

### 向 Agent 添加 Tool {/* #add-tools-to-an-agent */}

将 [`tools()`](/reference/connect/tools) 传给 Agent，并选择 `clay-mcp` Provider：

```typescript title="src/mastra/agents/clay-mcp-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const clayMcpAgent = new Agent({
  id: 'clay-mcp-agent',
  name: 'Clay agent',
  instructions: 'You help people find and research people and companies and run workflows in Clay.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['clay-mcp'] }),
})
```

Agent 运行时，Mastra 会从 Clay 的 MCP 服务器发现可用 Tool。这些 Tool 取决于服务器和已连接的账户，而不是你的 `@mastra/connect` 版本。Tool key 以 `clay-mcp_` 开头。

如需查看 Clay 提供的 Tool，请参阅 [MCP in Clay](https://university.clay.com/docs/mcp-settings) 文档。如需要求每次调用在运行前获得批准，请参阅 `tools()` 参考中的 [MCP Provider](/reference/connect/tools#mcp-providers)。
