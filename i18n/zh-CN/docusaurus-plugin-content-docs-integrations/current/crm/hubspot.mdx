# 集线点

为Agent提供Tool来搜索、创建和更新联系人、公司、交易和票证，并通过 Mastra Connect 在 HubSpot 中管理注释、任务和营销电子邮件。每个Tool调用都会通过 Mastra 平台，该平台会添加连接的凭据。您的应用程序从不存储 HubSpot 凭据。

## 连接 {/* #connect */}

在开始之前，请完成[Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect`并配置您的平台项目。

### 连接账户 {/* #connect-an-account */}

从包含您的目录的目录运行此命令`.env` file:

```bash
mastra connect add hubspot
```

CLI 将引导您完成 HubSpot 的授权并等待连接激活。

### 向Agent添加Tool {/* #add-tools-to-an-agent */}

经过[`tools()`](/reference/connect/tools) to the agent and select the `hubspot` provider:

```typescript title="src/mastra/agents/hubspot-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const hubspotAgent = new Agent({
  id: 'hubspot-agent',
  name: 'HubSpot agent',
  instructions:
    'You help people search, create, and update contacts, companies, deals, and tickets, and manage notes, tasks, and marketing emails in HubSpot.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['hubspot'] }),
})
```

Agent获得 50 个 HubSpot Tool，其中包含以下密钥`hubspot_batch_create_companies`. See [HubSpot tools](/reference/connect/providers#hubspot) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
