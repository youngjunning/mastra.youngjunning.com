# HubSpot

通过 Mastra Connect 为 Agent 提供可在 HubSpot 中搜索、创建和更新联系人、公司、交易及工单，并管理备注、任务和营销电子邮件的 Tool。每次 Tool 调用都会经过 Mastra 平台，由平台添加该连接的凭据；你的应用不会存储 HubSpot 凭据。

## 连接 {/* #connect */}

开始前，请先完成 [Connect 设置](/docs/mastra-platform/connect#get-started)，安装 `@mastra/connect` 并配置 Mastra 平台项目。

### 连接账户 {/* #connect-an-account */}

在包含 `.env` 文件的目录中运行以下命令：

```bash
mastra connect add hubspot
```

CLI 会引导你完成 HubSpot 的授权，并等待连接激活。

### 向 Agent 添加 Tool {/* #add-tools-to-an-agent */}

将 [`tools()`](/reference/connect/tools) 传给 Agent，并选择 `hubspot` Provider：

```typescript title="src/mastra/agents/hubspot-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const hubspotAgent = new Agent({
  id: 'hubspot-agent',
  name: 'HubSpot agent',
  instructions:
    'You help people search, create, and update contacts, companies, deals, and tickets, and manage notes, tasks, and marketing emails in HubSpot.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['hubspot'] }),
})
```

Agent 可使用 50 个 HubSpot Tool，Tool key 包括 `hubspot_batch_create_companies`。完整列表请参阅 [HubSpot Tool](/reference/connect/providers#hubspot)；如需限制可用 Tool，或要求每次调用在运行前获得批准，请参阅 [`tools()` 参数](/reference/connect/tools#parameters)。
