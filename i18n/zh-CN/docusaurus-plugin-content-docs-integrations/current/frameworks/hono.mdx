# Hono

本指南将带你使用 Mastra 和 Hono 构建一个能够调用 Tool 的 AI Agent。通过 [Hono 服务器适配器](/reference/server/hono-adapter)，你可以将 Agent 公开为 HTTP 端点，无需自行编写路由或单独运行 Mastra 服务器。

## 开始之前 {/* #before-you-begin */}

- 你需要一个受支持的 [Model Provider](/models) 提供的 API 密钥。如果没有偏好，可以使用 [OpenAI](/models/providers/openai)。
- 安装 Node.js `v22.13.0` 或更高版本

## 创建 Hono 应用（可选） {/* #create-a-new-hono-app-optional */}

如果你已有 Hono 应用，请跳到下一步。

运行以下命令[创建 Hono 应用](https://hono.dev/docs/getting-started/basic)：

```bash npm2yarn
npm create hono@latest mastra-hono -- --template nodejs --install --pm npm
```

这会创建一个名为 `mastra-hono` 的项目，你也可以换成自己喜欢的名称。

## 初始化 Mastra {/* #initialize-mastra */}

进入你的 Hono 项目目录：

```bash
cd mastra-hono
```

运行 [`mastra init`](/reference/cli/mastra#mastra-init)。按提示选择一个 Provider（例如 OpenAI），然后输入你的密钥：

```bash npm2yarn
npx mastra@latest init
```

这会创建 `src/mastra` 目录，其中包含一个天气 Agent 示例和以下文件：

- `index.ts`：Mastra 配置，包含 Memory 配置
- `tools/weather-tool.ts`：用于获取指定地点天气的 Tool
- `agents/weather-agent.ts`：天气 Agent，其 Prompt 指示它使用该 Tool

稍后，你会将 `src/mastra/index.ts` 文件传给 Hono 服务器适配器。

## 添加服务器适配器 {/* #add-server-adapter */}

安装 Hono 服务器适配器的软件包：

```bash npm2yarn
npm install @mastra/hono@latest
```

打开 Hono 的入口文件 `src/index.ts`，添加所需的导入和初始化代码：

```typescript title="src/index.ts" {3-8,10-11,13}
import { serve } from '@hono/node-server'
import { Hono } from 'hono'
import { type HonoBindings, type HonoVariables, MastraServer } from '@mastra/hono'
import { mastra } from './mastra/index.js'

const app = new Hono<{ Bindings: HonoBindings; Variables: HonoVariables }>()
const server = new MastraServer({ app, mastra })

await server.init()

app.get('/', c => {
  return c.text('Hello Hono!')
})

serve(
  {
    fetch: app.fetch,
    port: 3000,
  },
  info => {
    console.log(`Server is running on http://localhost:${info.port}`)
  },
)
```

使用现有的 Hono `app` 和根 ⁠`mastra` 实例初始化 ⁠`MastraServer`。调用 `⁠init()` 会注册 Mastra 中间件，并公开所有可用的 Mastra 端点。

## 测试 Agent {/* #test-your-agent */}

默认情况下，Mastra 会将端点添加到 `/api` 子路径下，并使用你的 Agent 或 Workflow ID。通过 `mastra init` 创建的默认 `weather-agent` 可通过 `/api/agents/weather-agent` 访问。

启动你的 Hono 服务器：

```bash npm2yarn
npm run dev
```

在另一个终端窗口中，使用 `curl` 向天气 Agent 提问：

```bash
curl -X POST http://localhost:3000/api/agents/weather-agent/generate -H "Content-Type: application/json" -d "{\"messages\":[{\"role\":\"user\",\"content\":\"What is the weather like in Seoul?\"}]}"
```
