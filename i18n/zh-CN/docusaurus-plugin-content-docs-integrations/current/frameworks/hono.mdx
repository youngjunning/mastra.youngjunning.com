# 霍诺

在本指南中，您将使用 Mastra 和 Hono 构建一个Tool调用 AI Agent。使用[Hono server adapter](/reference/server/hono-adapter)，您可以将Agent公开为 HTTP 端点，而无需自己编写路由或运行单独的 Mastra 服务器。

## 开始之前 {/* #before-you-begin */}

* 您需要来自受支持的 API 密钥[model provider](/models). If you don't have a preference, use [OpenAI](/models/providers/openai).
* 安装 Node.js`v22.13.0` or later

## 创建一个新的 Hono 应用程序（可选） {/* #create-a-new-hono-app-optional */}

如果您已有 Hono 应用程序，请跳至下一步。

运行以下命令[create a new Hono app](https://hono.dev/docs/getting-started/basic):

```bash npm2yarn
npm create hono@latest mastra-hono -- --template nodejs --install --pm npm
```

这将创建一个名为`mastra-hono`, but you can replace it with any name you want.

## 初始化玛斯特拉 {/* #initialize-mastra */}

导航到您的 Hono 项目目录：

```bash
cd mastra-hono
```

跑步[`mastra init`](/reference/cli/mastra#mastra-init). When prompted, choose a provider (e.g. OpenAI) and enter your key:

```bash npm2yarn
npx mastra@latest init
```

这创建了一个`src/mastra` folder with an example weather agent and the following files:

* `index.ts`：Mastra 配置，包括内存
* `tools/weather-tool.ts`：获取给定位置天气的Tool
* `agents/weather-agent.ts`：带有使用该Tool提示的天气Agent

你将通过`src/mastra/index.ts` file to the Hono server adapter later.

## 添加服务器适配器 {/* #add-server-adapter */}

安装Hono服务器适配器包：

```bash npm2yarn
npm install @mastra/hono@latest
```

打开 Hono 条目文件`src/index.ts` and add the required import and initialization code:

```typescript title="src/index.ts" {3-8,10-11,13}
import { serve } from '@hono/node-server'
import { Hono } from 'hono'
import { type HonoBindings, type HonoVariables, MastraServer } from '@mastra/hono'
import { mastra } from './mastra/index.js'

const app = new Hono<{ Bindings: HonoBindings; Variables: HonoVariables }>()
const server = new MastraServer({ app, mastra })

await server.init()

app.get('/', c => {
  return c.text('Hello Hono!')
})

serve(
  {
    fetch: app.fetch,
    port: 3000,
  },
  info => {
    console.log(`Server is running on http://localhost:${info.port}`)
  },
)
```

⁠`MastraServer` is initialized with the existing Hono `app` and the root ⁠`mastra` instance. Calling `⁠init()` registers the Mastra middleware and exposes all available Mastra endpoints.

## 测试你的Agent {/* #test-your-agent */}

默认情况下，Mastra 的端点添加在`/api` subpath and use your agent/workflow IDs. The default `weather-agent` created by `mastra init` is available at `/api/agents/weather-agent`.

启动你的Hono服务器：

```bash npm2yarn
npm run dev
```

在单独的终端窗口中，使用`curl` to ask the weather agent:

```bash
curl -X POST http://localhost:3000/api/agents/weather-agent/generate -H "Content-Type: application/json" -d "{\"messages\":[{\"role\":\"user\",\"content\":\"What is the weather like in Seoul?\"}]}"
```
