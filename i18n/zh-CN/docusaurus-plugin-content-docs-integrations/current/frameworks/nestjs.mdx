# NestJS

本指南将带你使用 Mastra 和 NestJS 构建一个能调用 Tool 的 AI Agent。[NestJS 服务器适配器](/reference/server/nestjs-adapter)通过 NestJS 模块注册 Mastra 的 Agent 和 Workflow 路由，让现有的 NestJS 应用可以直接处理这些路由。

## 开始之前 {/* #before-you-begin */}

* 准备一个受支持的[模型 Provider](/models) 的 API 密钥。如果没有偏好的 Provider，可以使用 [OpenAI](/models/providers/openai)。
* 安装 Node.js `v22.13.0` 或更高版本。
* 使用 NestJS 的 Express 平台（`@nestjs/platform-express`）。

## 创建 NestJS 应用（可选） {/* #create-a-new-nestjs-app-optional */}

如果已有 NestJS 应用，请跳到下一步。

运行以下命令创建 NestJS 应用：

```bash npm2yarn
npx @nestjs/cli new mastra-nest
```

该命令会创建名为 `mastra-nest` 的项目，你可以指定其他名称。

## 初始化 Mastra {/* #initialize-mastra */}

进入 NestJS 项目目录：

```bash
cd mastra-nest
```

运行 [`mastra init`](/reference/cli/mastra#mastra-init)，按提示选择一个 Provider（例如 OpenAI）并输入 API 密钥：

```bash npm2yarn
npx mastra@latest init
```

该命令会创建 `src/mastra` 目录，其中包含一个天气查询 Agent 示例及以下文件：

* `index.ts`：Mastra 配置，包含记忆配置。
* `tools/weather-tool.ts`：用于查询指定地点天气的 Tool。
* `agents/weather-agent.ts`：天气查询 Agent，其提示词会指示它使用该 Tool。

后续注册 NestJS 适配器时，需要传入 `src/mastra/index.ts` 中导出的 Mastra 实例。

## 按模块系统调整生成的文件 {/* #update-the-generated-files-for-your-module-system */}

要在 NestJS 项目中编译 `mastra init` 生成的文件，需要根据模块系统做一项调整。请检查 `package.json` 的 `type` 字段。NestJS CLI v12 创建的项目使用 ECMAScript 模块（ESM），并设置 `"type": "module"`。更早版本的 CLI 创建的是 CommonJS 项目。

<Tabs>
  <TabItem value="esm" label="ESM">
    ESM 项目使用 `"moduleResolution": "nodenext"`，因此相对导入路径必须包含文件扩展名。请为生成文件中的每条相对导入路径加上 `.js`，例如：

    ```typescript title="src/mastra/index.ts"
    import { weatherWorkflow } from './workflows/weather-workflow.js'
    import { weatherAgent } from './agents/weather-agent.js'
    ```

    ```typescript title="src/mastra/agents/weather-agent.ts"
    import { weatherTool } from '../tools/weather-tool.js'
    ```
  </TabItem>

  <TabItem value="commonjs" label="CommonJS">
    CommonJS 不支持顶层 `await`。打开 `src/mastra/index.ts`，移除 `DuckDBStore` 的导入以及 `MastraCompositeStore` 的 `domains` 选项：

    ```typescript title="src/mastra/index.ts" oxfmt:false
    import { DuckDBStore } from '@mastra/duckdb'

    // ...

    domains: {
      observability: await new DuckDBStore().getStore('observability'),
    },
    ```

    移除后，可观测性数据会保存在默认的 LibSQL 存储中。
  </TabItem>
</Tabs>

## 添加服务器适配器 {/* #add-server-adapter */}

安装 NestJS 服务器适配器包：

```bash npm2yarn
npm install @mastra/nestjs@latest
```

打开 `src/app.module.ts`，注册 `MastraModule`：

```typescript title="src/app.module.ts"
import { Module } from '@nestjs/common'
import { MastraModule } from '@mastra/nestjs'
import { mastra } from './mastra/index.js'

@Module({
  imports: [
    MastraModule.register({
      mastra,
    }),
  ],
})
export class AppModule {}
```

:::note

`MastraModule` 会注册一个匹配所有路由的控制器（`@All('*')`）。如果先于应用的其他模块导入，它可能拦截与 Mastra 无关的路由并返回 404。为避免冲突，请最后导入 `MastraModule`，或将其挂载到专用前缀下，例如 `/api/v1/mastra`。

:::

## 测试 Agent {/* #test-your-agent */}

Mastra 默认将端点注册在 `/api` 子路径下，路由中包含对应的 Agent 或 Workflow ID。`mastra init` 默认创建的 `weather-agent` 可通过 `/api/agents/weather-agent` 访问。

启动 NestJS 服务器：

```bash npm2yarn
npm run start
```

在另一个终端窗口中，用 `curl` 向天气查询 Agent 提问：

```bash
curl -X POST http://localhost:3000/api/agents/weather-agent/generate -H "Content-Type: application/json" -d "{\"messages\":[{\"role\":\"user\",\"content\":\"What is the weather like in Seoul?\"}]}"
```

## 在自定义服务中使用 Mastra {/* #use-mastra-in-your-own-services */}

在 NestJS 服务中，可以通过模块导出的 `MastraService` 封装类或 `MASTRA` 注入令牌访问 Mastra。

### MastraService {/* #mastraservice */}

`MastraService` 是一个可注入的封装类，为常见操作提供便捷方法：

```typescript title="src/agent.service.ts"
import { Injectable } from '@nestjs/common'
import { MastraService } from '@mastra/nestjs'

@Injectable()
export class AgentService {
  constructor(private readonly mastraService: MastraService) {}

  async chat(agentId: string, message: string) {
    const agent = this.mastraService.getAgent(agentId)
    return agent.generate({
      messages: [{ role: 'user', content: message }],
    })
  }

  async runWorkflow(workflowId: string, input: Record<string, unknown>) {
    const workflow = this.mastraService.getWorkflow(workflowId)
    return workflow.start({ inputData: input })
  }
}
```

`MastraService` 提供以下成员：

* `getMastra()`：返回底层 `Mastra` 实例。
* `getAgent(id)`：`mastra.getAgent(id)` 的简便调用方式。
* `getWorkflow(id)`：`mastra.getWorkflow(id)` 的简便调用方式。
* `getOptions()`：返回模块配置。
* `isShuttingDown`：开始优雅关闭后，值为 `true`。

### MASTRA 注入令牌 {/* #mastra-token */}

如果需要直接使用 `Mastra` 实例，例如访问存储、记忆或其他核心 API，请使用 `MASTRA` 令牌注入该实例：

```typescript title="src/memory.service.ts"
import { Injectable, Inject } from '@nestjs/common'
import { MASTRA } from '@mastra/nestjs'
import type { Mastra } from '@mastra/core/mastra'

@Injectable()
export class MemoryService {
  constructor(@Inject(MASTRA) private readonly mastra: Mastra) {}

  async getThreadMessages(threadId: string) {
    const memory = this.mastra.getMemory()
    return memory?.getMessages({ threadId })
  }
}
```

两种方式使用的都是 `MastraModule` 注册的同一个 `Mastra` 单例。
