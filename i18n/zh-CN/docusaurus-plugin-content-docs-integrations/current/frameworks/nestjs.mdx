# NestJS

在本指南中，您将使用 Mastra 和 NestJS 构建一个Tool调用 AI Agent。这[NestJS server adapter](/reference/server/nestjs-adapter)将 Mastra 的Agent和Workflow程路由注册为 NestJS 模块，以便它们在现有的 NestJS 应用程序中运行。

## 开始之前 {/* #before-you-begin */}

* 您需要来自受支持的 API 密钥[model provider](/models). If you don't have a preference, use [OpenAI](/models/providers/openai).
* 安装 Node.js`v22.13.0` or later
* 使用 NestJS Express 平台（`@nestjs/platform-express`)

## 创建一个新的 NestJS 应用程序（可选） {/* #create-a-new-nestjs-app-optional */}

如果您已经有 NestJS 应用程序，请跳到下一步。

运行以下命令创建一个新的 NestJS 应用程序：

```bash npm2yarn
npx @nestjs/cli new mastra-nest
```

这将创建一个名为`mastra-nest`, but you can replace it with any name you want.

## 初始化玛斯特拉 {/* #initialize-mastra */}

导航到您的 NestJS 项目目录：

```bash
cd mastra-nest
```

跑步[`mastra init`](/reference/cli/mastra#mastra-init). When prompted, choose a provider (e.g. OpenAI) and enter your key:

```bash npm2yarn
npx mastra@latest init
```

这创建了一个`src/mastra` folder with an example weather agent and the following files:

* `index.ts`：Mastra 配置，包括内存
* `tools/weather-tool.ts`：获取给定位置天气的Tool
* `agents/weather-agent.ts`：带有使用该Tool提示的天气Agent

你将通过`src/mastra/index.ts` file to the NestJS adapter in the next step.

## 更新为您的模块系统生成的文件 {/* #update-the-generated-files-for-your-module-system */}

这些文件`mastra init` generates need one change to compile in a NestJS project. Check the `type` field in your `package.json`. NestJS CLI v12 creates ECMAScript module (ESM) projects with `"type": "module"`. Earlier versions of the CLI create CommonJS projects.

<Tabs>
  <TabItem value="esm" label="ESM">
    ESM 项目使用`"moduleResolution": "nodenext"`, which requires file extensions on relative imports. Add `.js` to every relative import in the generated files, for example:

    ```typescript title="src/mastra/index.ts"
    import { weatherWorkflow } from './workflows/weather-workflow.js'
    import { weatherAgent } from './agents/weather-agent.js'
    ```

    ```typescript title="src/mastra/agents/weather-agent.ts"
    import { weatherTool } from '../tools/weather-tool.js'
    ```
  </TabItem>

  <TabItem value="commonjs" label="CommonJS">
    CommonJS 不支持顶级`await`. Open `src/mastra/index.ts` and remove the `DuckDBStore` import and the `domains` option of `MastraCompositeStore`:

    ```typescript title="src/mastra/index.ts" oxfmt:false
    import { DuckDBStore } from '@mastra/duckdb'

    // ...

    domains: {
      observability: await new DuckDBStore().getStore('observability'),
    },
    ```

    然后Observability数据存储在默认的 LibSQL 存储中。
  </TabItem>
</Tabs>

## 添加服务器适配器 {/* #add-server-adapter */}

安装 NestJS 服务器适配器包：

```bash npm2yarn
npm install @mastra/nestjs@latest
```

打开`src/app.module.ts` and register `MastraModule`:

```typescript title="src/app.module.ts"
import { Module } from '@nestjs/common'
import { MastraModule } from '@mastra/nestjs'
import { mastra } from './mastra/index.js'

@Module({
  imports: [
    MastraModule.register({
      mastra,
    }),
  ],
})
export class AppModule {}
```

：：：笔记

`MastraModule`注册一个包罗万象的控制器（`@All('*')`). If it's imported before your app modules, it can intercept unrelated routes and return 404s. To avoid conflicts, import `MastraModule` last or mount it under a dedicated prefix (e.g., `/api/v1/mastra`).

:::

## 测试你的Agent {/* #test-your-agent */}

默认情况下，Mastra 的端点添加在`/api` subpath and use your agent/workflow IDs. The default `weather-agent` created by `mastra init` is available at `/api/agents/weather-agent`.

启动你的 NestJS 服务器：

```bash npm2yarn
npm run start
```

在单独的终端窗口中，使用`curl` to ask the weather agent:

```bash
curl -X POST http://localhost:3000/api/agents/weather-agent/generate -H "Content-Type: application/json" -d "{\"messages\":[{\"role\":\"user\",\"content\":\"What is the weather like in Seoul?\"}]}"
```

## 在您自己的服务中使用 Mastra {/* #use-mastra-in-your-own-services */}

该模块导出两种从 NestJS 服务访问 Mastra 的方法：`MastraService` wrapper and the `MASTRA` injection token.

### 玛斯特拉服务 {/* #mastraservice */}

`MastraService`是一个可注入的包装器，具有用于常见操作的便捷方法：

```typescript title="src/agent.service.ts"
import { Injectable } from '@nestjs/common'
import { MastraService } from '@mastra/nestjs'

@Injectable()
export class AgentService {
  constructor(private readonly mastraService: MastraService) {}

  async chat(agentId: string, message: string) {
    const agent = this.mastraService.getAgent(agentId)
    return agent.generate({
      messages: [{ role: 'user', content: message }],
    })
  }

  async runWorkflow(workflowId: string, input: Record<string, unknown>) {
    const workflow = this.mastraService.getWorkflow(workflowId)
    return workflow.start({ inputData: input })
  }
}
```

`MastraService`暴露：

* `getMastra()`：返回底层`Mastra` instance
* `getAgent(id)`: 的简写`mastra.getAgent(id)`
* `getWorkflow(id)`: 的简写`mastra.getWorkflow(id)`
* `getOptions()`：返回模块配置
* `isShuttingDown`: `true` after graceful shutdown begins

### MASTRA 代币 {/* #mastra-token */}

如果您需要`Mastra` instance directly (e.g., to access storage, memory, or other core APIs), inject it with the `MASTRA` token:

```typescript title="src/memory.service.ts"
import { Injectable, Inject } from '@nestjs/common'
import { MASTRA } from '@mastra/nestjs'
import type { Mastra } from '@mastra/core/mastra'

@Injectable()
export class MemoryService {
  constructor(@Inject(MASTRA) private readonly mastra: Mastra) {}

  async getThreadMessages(threadId: string) {
    const memory = this.mastra.getMemory()
    return memory?.getMessages({ threadId })
  }
}
```

两种方法都使用相同的单例`Mastra` instance registered by `MastraModule`.
