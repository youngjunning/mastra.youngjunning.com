# Express

本指南将介绍如何使用 Mastra 和 Express 构建一个能够调用 Tool 的 AI Agent。通过 [Express 服务器适配器](/reference/server/express-adapter)，您可以将 Agent 作为 HTTP 端点提供访问，无需自行编写路由或单独运行 Mastra 服务器。

## 开始之前 {/* #before-you-begin */}

- 您需要从受支持的 [Model Provider](/models) 获取 API 密钥。如果没有偏好，可以使用 [OpenAI](/models/providers/openai)。
- 安装 Node.js `v22.13.0` 或更高版本

## 创建 Express 应用（可选） {/* #create-a-new-express-app-optional */}

如果您已有 Express 应用，请跳到下一步。

克隆此[模板仓库](https://github.com/mastra-ai/express-ts-boilerplate)并安装依赖：

## 初始化 Mastra {/* #initialize-mastra */}

在 Express 项目目录中运行 [`mastra init`](/reference/cli/mastra#mastra-init)。

按提示选择一个 Provider（例如 OpenAI），并输入您的密钥：

```bash
npx mastra@latest init
```

该命令会创建 `src/mastra` 目录，其中包含一个天气查询 Agent 示例和以下文件：

- `index.ts`：Mastra 配置，包括 Memory 配置
- `tools/weather-tool.ts`：用于查询指定地点天气的 Tool
- `agents/weather-agent.ts`：天气查询 Agent，其 Prompt 会指示它使用该 Tool

稍后会将 `src/mastra/index.ts` 文件传给 Express 服务器适配器。

## 添加服务器适配器 {/* #add-server-adapter */}

安装 Express 服务器适配器包：

```bash npm2yarn
npm install @mastra/express@latest
```

打开 Express 入口文件 `src/index.ts`，添加所需的导入和初始化代码：

```typescript {2-3,11-12} title="src/index.ts"
import express, { type Request, type Response } from 'express'
import { MastraServer } from '@mastra/express'
import { mastra } from './mastra'

const app = express()
const PORT = process.env.PORT || 3000

// Middleware
app.use(express.json())

const server = new MastraServer({ app, mastra })
await server.init()

// Routes
app.get('/', (_req: Request, res: Response) => {
  res.json({ message: 'Hello, World!' })
})

// Start server
app.listen(PORT, () => {
  console.log(`Server is running on http://localhost:${PORT}`)
})
```

使用现有的 Express `app` 和根 ⁠`mastra` 实例初始化 ⁠`MastraServer`。调用 `⁠init()` 会注册 Mastra 中间件，并公开所有可用的 Mastra 端点。

## 测试 Agent {/* #test-your-agent */}

默认情况下，Mastra 会将端点添加到 `/api` 子路径下，并使用您的 Agent 或 Workflow ID。通过 `mastra init` 创建的默认 `weather-agent` 可通过 `/api/agents/weather-agent` 访问。

启动 Express 服务器：

```bash
npm run start
```

在另一个终端窗口中，使用 `curl` 向天气查询 Agent 提问：

```bash
curl -X POST http://localhost:3000/api/agents/weather-agent/generate -H "Content-Type: application/json" -d "{\"messages\":[{\"role\":\"user\",\"content\":\"What is the weather like in Seoul?\"}]}"
```
