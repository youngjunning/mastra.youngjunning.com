# 表达

在本指南中，您将使用 Mastra 和 Express 构建一个Tool调用 AI Agent。使用[Express server adapter](/reference/server/express-adapter)，您可以将Agent公开为 HTTP 端点，而无需自己编写路由或运行单独的 Mastra 服务器。

## 开始之前 {/* #before-you-begin */}

* 您需要来自受支持的 API 密钥[model provider](/models). If you don't have a preference, use [OpenAI](/models/providers/openai).
* 安装 Node.js`v22.13.0` or later

## 创建一个新的 Express 应用程序（可选） {/* #create-a-new-express-app-optional */}

如果您已有 Express 应用程序，请跳至下一步。

## 初始化玛斯特拉 {/* #initialize-mastra */}

在 Express 项目目录中，运行[`mastra init`](/reference/cli/mastra#mastra-init).

出现提示时，选择Provider（例如 OpenAI）并输入您的密钥：

```bash
npx mastra@latest init
```

这创建了一个`src/mastra` folder with an example weather agent and the following files:

* `index.ts`：Mastra 配置，包括内存
* `tools/weather-tool.ts`：获取给定位置天气的Tool
* `agents/weather-agent.ts`：带有使用该Tool提示的天气Agent

你将通过`src/mastra/index.ts` file to the Express server adapter later.

## 添加服务器适配器 {/* #add-server-adapter */}

安装 Express 服务器适配器包：

```bash npm2yarn
npm install @mastra/express@latest
```

打开 Express 条目文件`src/index.ts` and add the required import and initialization code:

```typescript {2-3,11-12} title="src/index.ts"
import express, { type Request, type Response } from 'express'
import { MastraServer } from '@mastra/express'
import { mastra } from './mastra'

const app = express()
const PORT = process.env.PORT || 3000

// Middleware
app.use(express.json())

const server = new MastraServer({ app, mastra })
await server.init()

// Routes
app.get('/', (_req: Request, res: Response) => {
  res.json({ message: 'Hello, World!' })
})

// Start server
app.listen(PORT, () => {
  console.log(`Server is running on http://localhost:${PORT}`)
})
```

⁠`MastraServer` is initialized with the existing Express `app` and the root ⁠`mastra` instance. Calling `⁠init()` registers the Mastra middleware and exposes all available Mastra endpoints.

## 测试你的Agent {/* #test-your-agent */}

默认情况下，Mastra 的端点添加在`/api` subpath and use your agent/workflow IDs. The default `weather-agent` created by `mastra init` is available at `/api/agents/weather-agent`.

启动你的 Express 服务器：

```bash
npm run start
```

在单独的终端窗口中，使用`curl` to ask the weather agent:

```bash
curl -X POST http://localhost:3000/api/agents/weather-agent/generate -H "Content-Type: application/json" -d "{\"messages\":[{\"role\":\"user\",\"content\":\"What is the weather like in Seoul?\"}]}"
```
