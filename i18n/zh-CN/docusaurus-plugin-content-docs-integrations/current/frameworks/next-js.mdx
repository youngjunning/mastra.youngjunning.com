# Next.js

## 构建流式聊天界面 {/* #build-a-streaming-chat-interface */}

本指南将带你用 Mastra 构建一个能调用 Tool 的 AI Agent，然后在 Next.js 路由中直接导入并调用这个 Agent。

你将使用 [AI SDK UI](https://ai-sdk.dev/docs/ai-sdk-ui/overview) 和 [AI Elements](https://ai-sdk.dev/elements) 构建美观的交互式聊天界面。

### 开始之前 {/* #before-you-begin */}

* 准备一个受支持的[模型 Provider](/models) 提供的 API 密钥。如果没有偏好，可以使用 [OpenAI](/models/providers/openai)。
* 安装 Node.js `v22.13.0` 或更高版本。

### 创建 Next.js 应用（可选） {/* #create-a-new-nextjs-app-optional */}

如果已有 Next.js 应用，请跳到下一步。

运行以下命令[创建 Next.js 应用](https://nextjs.org/docs/app/getting-started/installation)：

```bash npm2yarn
npx create-next-app@latest my-nextjs-agent --yes --ts --eslint --tailwind --src-dir --app --turbopack --no-react-compiler --no-import-alias
```

这条命令会创建名为 `my-nextjs-agent` 的项目，你也可以换成自己想用的名称。

### 初始化 Mastra {/* #initialize-mastra */}

进入 Next.js 项目目录：

```bash
cd my-nextjs-agent
```

运行 [`mastra init`](/reference/cli/mastra#mastra-init)，根据提示选择 Provider（例如 OpenAI）并输入 API 密钥：

```bash npm2yarn
npx mastra@latest init
```

初始化命令会创建 `src/mastra` 目录，其中包含一个天气查询 Agent 示例及以下文件：

* `index.ts`：Mastra 配置，包含记忆功能的配置。
* `tools/weather-tool.ts`：查询指定地点天气的 Tool。
* `agents/weather-agent.ts`：天气查询 Agent，提示词会引导它使用这个 Tool。

接下来，你将在 Next.js 路由中调用 `weather-agent.ts` 中定义的 Agent。

:::tip[与 Next.js 一起运行 Studio]
如果你希望同时运行 [Studio](/docs/studio/overview) 和 Next.js 应用，并让两者共用同一个数据库，请将 `src/mastra/index.ts` 中存储 URL 的路径改为绝对路径：

```typescript
url: 'file:/absolute/path/to/your/project/mastra.db'
```

相对路径以各进程的工作目录为准，而 `next dev` 和 `mastra dev` 的工作目录不同。
:::

### 配置 Next.js {/* #configure-nextjs */}

Mastra 的包会加载 Node.js 原生模块，例如用于存储可观测性数据的 DuckDB 绑定。Next.js 的打包工具无法打包这些模块。请在 `next.config.ts` 中添加 `serverExternalPackages`，让 Next.js 在运行时从 `node_modules` 加载 Mastra 的包：

```ts title="next.config.ts"
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  serverExternalPackages: ['@mastra/*'],
}

export default nextConfig
```

如果 `next.config.ts` 已有其他配置项，将 `serverExternalPackages` 添加到同一级即可。

### 安装 AI SDK UI 和 AI Elements {/* #install-ai-sdk-ui--ai-elements */}

安装 AI SDK UI 和 Mastra 适配器：

```bash npm2yarn
npm install @mastra/ai-sdk@latest @ai-sdk/react ai
```

接下来，添加聊天页面所需的 AI Elements 组件。如果命令提示选择组件库，请选择 **Radix UI**，其余选项使用默认值：

```bash npm2yarn
npx ai-elements@latest add prompt-input conversation message tool
```

:::note
`ai-elements` 命令会运行 `shadcn add`，从 AI Elements 注册表获取组件。该注册表目前只发布 Radix UI 组件。将这些组件安装到 Base UI 项目中会导致 TypeScript 报错，详情见 [vercel/ai-elements#383](https://github.com/vercel/ai-elements/issues/383)。

只有项目中没有 `components.json` 时，命令才会提示选择组件库。如果已有该文件，请先确认其中的 `style` 是 `new-york` 或 `radix-*` 等 Radix 样式，而非 `base-*` 样式，再运行命令。
:::

这条命令会将组件及其依赖项下载到 `@/components/ai-elements` 目录。

### 创建聊天路由 {/* #create-a-chat-route */}

创建 `src/app/api/chat/route.ts`：

```ts title="src/app/api/chat/route.ts"
import { handleChatStream } from '@mastra/ai-sdk'
import { toAISdkMessages } from '@mastra/ai-sdk/ui'
import { createUIMessageStreamResponse } from 'ai'
import { mastra } from '@/mastra'
import { NextResponse } from 'next/server'

const THREAD_ID = 'example-user-id'
const RESOURCE_ID = 'weather-chat'

export async function POST(req: Request) {
  const params = await req.json()
  const stream = await handleChatStream({
    mastra,
    agentId: 'weather-agent',
    version: 'v7',
    params: {
      ...params,
      memory: {
        ...params.memory,
        thread: THREAD_ID,
        resource: RESOURCE_ID,
      },
    },
  })
  return createUIMessageStreamResponse({ stream })
}

export async function GET() {
  const memory = await mastra.getAgentById('weather-agent').getMemory()
  let response = null

  try {
    response = await memory?.recall({
      threadId: THREAD_ID,
      resourceId: RESOURCE_ID,
    })
  } catch {
    console.log('No previous messages found.')
  }

  const uiMessages = toAISdkMessages(response?.messages || [], { version: 'v7' })

  return NextResponse.json(uiMessages)
}
```

`POST` 路由接收提示词，并以 AI SDK 格式流式返回 Agent 的响应。`GET` 路由从记忆中读取历史消息，以便客户端重新加载时恢复聊天界面中的对话。

### 创建聊天页面 {/* #create-a-chat-page */}

创建 `src/app/chat/page.tsx`：

```tsx title="src/app/chat/page.tsx"
'use client'

import '@/app/globals.css'
import { useEffect, useState } from 'react'
import { DefaultChatTransport, ToolUIPart } from 'ai'
import { useChat } from '@ai-sdk/react'

import {
  PromptInput,
  PromptInputBody,
  PromptInputTextarea,
} from '@/components/ai-elements/prompt-input'

import {
  Conversation,
  ConversationContent,
  ConversationScrollButton,
} from '@/components/ai-elements/conversation'

import { Message, MessageContent, MessageResponse } from '@/components/ai-elements/message'

import { Tool, ToolHeader, ToolContent, ToolInput, ToolOutput } from '@/components/ai-elements/tool'

function Chat() {
  const [input, setInput] = useState<string>('')

  const { messages, setMessages, sendMessage, status } = useChat({
    transport: new DefaultChatTransport({
      api: '/api/chat',
    }),
  })

  useEffect(() => {
    const fetchMessages = async () => {
      const res = await fetch('/api/chat')
      const data = await res.json()
      setMessages([...data])
    }
    fetchMessages()
  }, [setMessages])

  const handleSubmit = async () => {
    if (!input.trim()) return

    sendMessage({ text: input })
    setInput('')
  }

  return (
    <div className="relative size-full h-screen w-full p-6">
      <div className="flex h-full flex-col">
        <Conversation className="h-full">
          <ConversationContent>
            {messages.map(message => (
              <div key={message.id}>
                {message.parts?.map((part, i) => {
                  if (part.type === 'text') {
                    return (
                      <Message key={`${message.id}-${i}`} from={message.role}>
                        <MessageContent>
                          <MessageResponse>{part.text}</MessageResponse>
                        </MessageContent>
                      </Message>
                    )
                  }

                  if (part.type?.startsWith('tool-')) {
                    return (
                      <Tool key={`${message.id}-${i}`}>
                        <ToolHeader
                          type={(part as ToolUIPart).type}
                          state={(part as ToolUIPart).state || 'output-available'}
                          className="cursor-pointer"
                        />
                        <ToolContent>
                          <ToolInput input={(part as ToolUIPart).input || {}} />
                          <ToolOutput
                            output={(part as ToolUIPart).output}
                            errorText={(part as ToolUIPart).errorText}
                          />
                        </ToolContent>
                      </Tool>
                    )
                  }

                  return null
                })}
              </div>
            ))}
            <ConversationScrollButton />
          </ConversationContent>
        </Conversation>

        <PromptInput onSubmit={handleSubmit} className="mt-20">
          <PromptInputBody>
            <PromptInputTextarea
              onChange={e => setInput(e.target.value)}
              className="md:leading-10"
              value={input}
              placeholder="Type your message..."
              disabled={status !== 'ready'}
            />
          </PromptInputBody>
        </PromptInput>
      </div>
    </div>
  )
}

export default Chat
```

这个组件将 [`useChat()`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/use-chat) 连接到 `api/chat` 端点，把提示词发送到该端点，再分块接收流式响应。

组件使用 [`<MessageResponse>`](https://ai-sdk.dev/elements/components/message#messageresponse-) 渲染响应文本，并用 [`<Tool>`](https://ai-sdk.dev/elements/components/tool) 显示发生的 Tool 调用。

### 测试 Agent {/* #test-your-agent */}

1. 运行 `npm run dev`，启动 Next.js 应用。
2. 打开聊天页面 [http://localhost:3000/chat](http://localhost:3000/chat)。
3. 试着问一个天气问题。如果 API 密钥配置正确，你就会收到响应。

## 公开 Mastra API {/* #expose-the-mastra-api */}

上面的聊天路由通过 `@mastra/ai-sdk` 提供的 `handleChatStream`，从自定义的 `/api/chat` 端点流式返回 AI SDK UI 响应。要在同一个 Next.js 部署中公开 Mastra 的整套 HTTP API（涵盖 Agent、Tool、Workflow、记忆、自定义 API 路由、MCP 和 A2A），请将 `@mastra/next` [服务端适配器](/docs/server/server-adapters) 挂载到一个捕获所有剩余路径的路由上。

安装适配器及其对等依赖 Hono：

```bash npm2yarn
npm install @mastra/next@latest hono
```

创建这个全匹配路由，并导出相应的 HTTP 方法处理函数：

```typescript title="src/app/api/[...mastra]/route.ts"
import { mastra } from '@/mastra'
import { createNextRouteHandler } from '@mastra/next'

export const { GET, POST, PUT, DELETE, PATCH, OPTIONS, HEAD } = createNextRouteHandler({
  mastra,
})
```

`prefix` 默认为 `/api`，必须与全匹配路由的挂载路径一致。例如，如果将适配器挂载在 `src/app/api/mastra/[...mastra]/route.ts`，请使用 `createNextRouteHandler({ mastra, prefix: '/api/mastra' })`。

启动应用：

```bash npm2yarn
npm run dev
```

另开一个终端，向天气查询 Agent 提问，验证适配器是否正常工作：

```bash
curl -X POST http://localhost:3000/api/agents/weather-agent/generate -H "Content-Type: application/json" -d "{\"messages\":[{\"role\":\"user\",\"content\":\"What is the weather like in Seoul?\"}]}"
```

该端点会返回 Agent 的完整 JSON 响应。保留 AI SDK UI 路由来支持流式聊天界面，并通过全匹配路由公开完整的 Mastra API。适配器的详细用法见 [Next.js 适配器](/reference/server/next-adapter)参考文档。
