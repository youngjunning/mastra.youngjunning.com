# Next.js

## 构建流媒体聊天界面 {/* #build-a-streaming-chat-interface */}

在本指南中，您将使用 Mastra 构建一个Tool调用 AI Agent，然后通过直接从路由导入和调用Agent将其连接到 Next.js。

你会使用[AI SDK UI](https://ai-sdk.dev/docs/ai-sdk-ui/overview) and [AI Elements](https://ai-sdk.dev/elements)创造优美的交互式聊天体验。

### 开始之前 {/* #before-you-begin */}

* 您需要来自受支持的 API 密钥[model provider](/models). If you don't have a preference, use [OpenAI](/models/providers/openai).
* 安装 Node.js`v22.13.0` or later

### 创建一个新的 Next.js 应用程序（可选） {/* #create-a-new-nextjs-app-optional */}

如果您已有 Next.js 应用程序，请跳至下一步。

运行以下命令[create a new Next.js app](https://nextjs.org/docs/app/getting-started/installation):

```bash npm2yarn
npx create-next-app@latest my-nextjs-agent --yes --ts --eslint --tailwind --src-dir --app --turbopack --no-react-compiler --no-import-alias
```

这将创建一个名为`my-nextjs-agent`, but you can replace it with any name you want.

### 初始化玛斯特拉 {/* #initialize-mastra */}

导航到您的 Next.js 项目：

```bash
cd my-nextjs-agent
```

跑步[`mastra init`](/reference/cli/mastra#mastra-init). When prompted, choose a provider (e.g. OpenAI) and enter your key:

```bash npm2yarn
npx mastra@latest init
```

这创建了一个`src/mastra` folder with an example weather agent and the following files:

* `index.ts`：Mastra 配置，包括内存
* `tools/weather-tool.ts`：获取给定位置天气的Tool
* `agents/weather-agent.ts`：带有使用该Tool提示的天气Agent

你会打电话`weather-agent.ts` from your Next.js routes in the next steps.

:::tip\[与 Next.js 一起使用 Studio]
如果你想跑步[Studio](/docs/studio/overview) alongside your Next.js app and have both share the same database, update the storage URL in `src/mastra/index.ts` to use an absolute path:

```typescript
url: 'file:/absolute/path/to/your/project/mastra.db'
```

相对路径根据每个进程的工作目录进行解析，不同进程的工作目录不同`next dev` and `mastra dev`.
:::

### 配置 Next.js {/* #configure-nextjs */}

Mastra 包加载本机 Node.js 模块，例如存储可观察性数据的 DuckDB 绑定，这是 Next.js 捆绑器无法捆绑的。添加`serverExternalPackages` to `next.config.ts` so Next.js loads Mastra packages from `node_modules` at runtime:

```ts title="next.config.ts"
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  serverExternalPackages: ['@mastra/*'],
}

export default nextConfig
```

如果你的`next.config.ts` already sets other options, add `serverExternalPackages` alongside them.

### 安装 AI SDK UI 和 AI 元素 {/* #install-ai-sdk-ui--ai-elements */}

安装 AI SDK UI 以及 Mastra 适配器：

```bash npm2yarn
npm install @mastra/ai-sdk@latest @ai-sdk/react ai
```

接下来，添加聊天页面使用的 AI Elements 组件。当提示选择组件库时，选择**Radix UI**, then accept the defaults for the remaining prompts:

```bash npm2yarn
npx ai-elements@latest add prompt-input conversation message tool
```

:::注意
的`ai-elements` command runs `shadcn add` against the AI Elements registry, which currently publishes Radix UI components only. Installing them into a Base UI project produces TypeScript errors, tracked in [vercel/ai-elements#383](https://github.com/vercel/ai-elements/issues/383).

只有当你的项目没有组件库时才会出现组件库提示`components.json`. If you already have one, check that its `style` is a Radix option, such as `new-york` or a `radix-*` style, and not a `base-*` style, before running the command.
:::

这会将这些组件及其依赖项下载到`@/components/ai-elements` folder.

### 创建聊天路径 {/* #create-a-chat-route */}

创造`src/app/api/chat/route.ts`:

```ts title="src/app/api/chat/route.ts"
import { handleChatStream } from '@mastra/ai-sdk'
import { toAISdkMessages } from '@mastra/ai-sdk/ui'
import { createUIMessageStreamResponse } from 'ai'
import { mastra } from '@/mastra'
import { NextResponse } from 'next/server'

const THREAD_ID = 'example-user-id'
const RESOURCE_ID = 'weather-chat'

export async function POST(req: Request) {
  const params = await req.json()
  const stream = await handleChatStream({
    mastra,
    agentId: 'weather-agent',
    version: 'v7',
    params: {
      ...params,
      memory: {
        ...params.memory,
        thread: THREAD_ID,
        resource: RESOURCE_ID,
      },
    },
  })
  return createUIMessageStreamResponse({ stream })
}

export async function GET() {
  const memory = await mastra.getAgentById('weather-agent').getMemory()
  let response = null

  try {
    response = await memory?.recall({
      threadId: THREAD_ID,
      resourceId: RESOURCE_ID,
    })
  } catch {
    console.log('No previous messages found.')
  }

  const uiMessages = toAISdkMessages(response?.messages || [], { version: 'v7' })

  return NextResponse.json(uiMessages)
}
```

这`POST` route accepts a prompt and streams the agent's response back in AI SDK format, while the `GET` route fetches message history from memory so the UI can be hydrated when the client reloads.

### 创建聊天页面 {/* #create-a-chat-page */}

创造`src/app/chat/page.tsx`:

```tsx title="src/app/chat/page.tsx"
'use client'

import '@/app/globals.css'
import { useEffect, useState } from 'react'
import { DefaultChatTransport, ToolUIPart } from 'ai'
import { useChat } from '@ai-sdk/react'

import {
  PromptInput,
  PromptInputBody,
  PromptInputTextarea,
} from '@/components/ai-elements/prompt-input'

import {
  Conversation,
  ConversationContent,
  ConversationScrollButton,
} from '@/components/ai-elements/conversation'

import { Message, MessageContent, MessageResponse } from '@/components/ai-elements/message'

import { Tool, ToolHeader, ToolContent, ToolInput, ToolOutput } from '@/components/ai-elements/tool'

function Chat() {
  const [input, setInput] = useState<string>('')

  const { messages, setMessages, sendMessage, status } = useChat({
    transport: new DefaultChatTransport({
      api: '/api/chat',
    }),
  })

  useEffect(() => {
    const fetchMessages = async () => {
      const res = await fetch('/api/chat')
      const data = await res.json()
      setMessages([...data])
    }
    fetchMessages()
  }, [setMessages])

  const handleSubmit = async () => {
    if (!input.trim()) return

    sendMessage({ text: input })
    setInput('')
  }

  return (
    <div className="relative size-full h-screen w-full p-6">
      <div className="flex h-full flex-col">
        <Conversation className="h-full">
          <ConversationContent>
            {messages.map(message => (
              <div key={message.id}>
                {message.parts?.map((part, i) => {
                  if (part.type === 'text') {
                    return (
                      <Message key={`${message.id}-${i}`} from={message.role}>
                        <MessageContent>
                          <MessageResponse>{part.text}</MessageResponse>
                        </MessageContent>
                      </Message>
                    )
                  }

                  if (part.type?.startsWith('tool-')) {
                    return (
                      <Tool key={`${message.id}-${i}`}>
                        <ToolHeader
                          type={(part as ToolUIPart).type}
                          state={(part as ToolUIPart).state || 'output-available'}
                          className="cursor-pointer"
                        />
                        <ToolContent>
                          <ToolInput input={(part as ToolUIPart).input || {}} />
                          <ToolOutput
                            output={(part as ToolUIPart).output}
                            errorText={(part as ToolUIPart).errorText}
                          />
                        </ToolContent>
                      </Tool>
                    )
                  }

                  return null
                })}
              </div>
            ))}
            <ConversationScrollButton />
          </ConversationContent>
        </Conversation>

        <PromptInput onSubmit={handleSubmit} className="mt-20">
          <PromptInputBody>
            <PromptInputTextarea
              onChange={e => setInput(e.target.value)}
              className="md:leading-10"
              value={input}
              placeholder="Type your message..."
              disabled={status !== 'ready'}
            />
          </PromptInputBody>
        </PromptInput>
      </div>
    </div>
  )
}

export default Chat
```

该组件连接[`useChat()`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/use-chat) to the `api/chat` endpoint, sending prompts there and streaming the response back in chunks.

它使用以下方式呈现响应文本[`<MessageResponse>`](https://ai-sdk.dev/elements/components/message#messageresponse-) component, and shows any tool invocations with the [`<Tool>`](https://ai-sdk.dev/elements/components/tool) component.

## 公开 Mastra API {/* #expose-the-mastra-api */}

上面的聊天路由使用`handleChatStream` from `@mastra/ai-sdk` to stream AI SDK UI responses from a custom `/api/chat` endpoint. To expose Mastra's full HTTP API for agents, tools, workflows, memory, custom API routes, MCP, and A2A through the same Next.js deployment, mount the `@mastra/next` [server adapter](/docs/server/server-adapters) on a catch-all route.

安装适配器及其 Hono 对等依赖项：

```bash npm2yarn
npm install @mastra/next@latest hono
```

创建 catch-all 路由并导出其 HTTP 方法处理程序：

```typescript title="src/app/api/[...mastra]/route.ts"
import { mastra } from '@/mastra'
import { createNextRouteHandler } from '@mastra/next'

export const { GET, POST, PUT, DELETE, PATCH, OPTIONS, HEAD } = createNextRouteHandler({
  mastra,
})
```

这`prefix` option defaults to `/api` and must match the catch-all route's mount path. For example, when mounting the adapter at `src/app/api/mastra/[...mastra]/route.ts`, use `createNextRouteHandler({ mastra, prefix: '/api/mastra' })`.

启动应用程序：

```bash npm2yarn
npm run dev
```

在单独的终端中，通过向天气Agent询问一个问题来验证适配器：

```bash
curl -X POST http://localhost:3000/api/agents/weather-agent/generate -H "Content-Type: application/json" -d "{\"messages\":[{\"role\":\"user\",\"content\":\"What is the weather like in Seoul?\"}]}"
```

端点从Agent返回完整的 JSON 响应。保留流媒体聊天界面的 AI SDK UI 路由，并使用 catch-all 路由公开完整的 Mastra API。该适配器完整记录在[Next.js adapter](/reference/server/next-adapter) reference page.
