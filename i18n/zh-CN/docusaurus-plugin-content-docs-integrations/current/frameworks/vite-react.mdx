# React + Vite

本指南将带你用 Mastra 构建一个能够调用 Tool 的 AI Agent，再让 React 前端通过 Mastra 的独立服务器直接调用该 Agent。

你将用 [AI SDK UI](https://ai-sdk.dev/docs/ai-sdk-ui/overview) 和 [AI Elements](https://ai-sdk.dev/elements) 打造美观的交互式聊天界面。

## 开始之前 {/* #before-you-begin */}

* 获取受支持的[模型 Provider](/models) 提供的 API 密钥。如果没有偏好的 Provider，可以使用 [OpenAI](/models/providers/openai)。
* 安装 Node.js `v22.13.0` 或更高版本。

## 新建 React + Vite 应用（可选） {/* #create-a-new-react--vite-app-optional */}

如果你已有使用 Tailwind 的 React + Vite 应用，可以跳过本节。

### 生成项目骨架 {/* #project-scaffold */}

运行以下命令[新建 React + Vite 应用](https://vite.dev/guide/#scaffolding-your-first-vite-project)。

```bash npm2yarn
npm create vite@latest mastra-react -- --template react-ts
```

这条命令会创建名为 `mastra-react` 的项目。你也可以换成自己想用的名称。

进入项目目录。

```bash
cd mastra-react
```

### Tailwind {/* #tailwind */}

接下来安装 Tailwind。

```bash npm2yarn
npm install tailwindcss @tailwindcss/vite
```

配置 Vite 插件。

```typescript title="vite.config.ts" {3-4,7-12}
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import path from 'path'
import tailwindcss from '@tailwindcss/vite'

export default defineConfig({
  plugins: [react(), tailwindcss()],
  resolve: {
    alias: {
      '@': path.resolve(__dirname, './src'),
    },
  },
})
```

将 `src/index.css` 的全部内容替换为以下代码。

```css title="src/index.css"
@import 'tailwindcss';
```

在 `tsconfig.json` 中添加以下 `compilerOptions` 配置。

```jsonc title="tsconfig.json"
{
  // ...
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"],
    },
  },
}
```

编辑 `tsconfig.app.json`，让应用能解析路径别名。

```jsonc title="tsconfig.app.json"
{
  "compilerOptions": {
    // ...
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"],
    },
    // ...
  },
}
```

## 初始化 Mastra {/* #initialize-mastra */}

运行 [`mastra init`](/reference/cli/mastra#mastra-init)。按提示选择 Provider（例如 OpenAI），然后输入 API 密钥。

```bash npm2yarn
npx mastra@latest init
```

这条命令会创建 `src/mastra` 目录，其中包含一个天气查询 Agent 示例及以下文件。

* `index.ts` 保存 Mastra 配置，包括记忆配置。
* `tools/weather-tool.ts` 定义用于查询指定地点天气的 Tool。
* `agents/weather-agent.ts` 定义天气查询 Agent，其提示词会引导它使用该 Tool。

接下来，你将在聊天界面中调用 `weather-agent.ts` 中定义的 Agent。

## 安装 AI SDK UI 和 AI Elements {/* #install-ai-sdk-ui--ai-elements */}

安装 AI SDK UI 和 Mastra 适配器。

```bash npm2yarn
npm install @mastra/ai-sdk@latest @ai-sdk/react ai
```

接下来初始化 AI Elements。如果出现选择组件库的提示，请选择 **Radix UI**，其余选项使用默认值。

```bash npm2yarn
npx ai-elements@latest
```

:::note
`ai-elements` 命令会运行 `shadcn add`，从 AI Elements 注册表安装组件。该注册表目前只发布 Radix UI 组件。在 Base UI 项目中安装这些组件会导致 TypeScript 错误，详见 [vercel/ai-elements#383](https://github.com/vercel/ai-elements/issues/383)。

只有项目中没有 `components.json` 时，才会提示选择组件库。如果文件已存在，请在运行命令前确认 `style` 使用 Radix 样式，例如 `new-york` 或 `radix-*`，并排除 `base-*` 样式。
:::

这条命令会将整个 AI Elements UI 组件库下载到 `@/components/ai-elements` 目录。

## 创建聊天路由 {/* #create-a-chat-route */}

打开 `src/mastra/index.ts`，在配置中添加 [chatRoute()](/reference/ai-sdk/chat-route)。这会创建一条 API 路由，供 React 前端获取与 AI SDK 兼容的聊天响应。接下来，你将通过 useChat() 调用这条路由。

```ts title="src/mastra/index.ts"
import { Mastra } from '@mastra/core/mastra'
// Existing imports...
import { chatRoute } from '@mastra/ai-sdk'

export const mastra = new Mastra({
  // Existing config...
  server: {
    apiRoutes: [
      chatRoute({
        path: '/chat/:agentId',
      }),
    ],
  },
})
```

## 添加聊天界面 {/* #add-the-chat-ui */}

将 `src/App.tsx` 的内容替换为以下代码，创建聊天界面。

```tsx title="src/App.tsx"
import * as React from 'react'
import { DefaultChatTransport, type ToolUIPart } from 'ai'
import { useChat } from '@ai-sdk/react'

import {
  PromptInput,
  PromptInputBody,
  PromptInputTextarea,
} from '@/components/ai-elements/prompt-input'

import {
  Conversation,
  ConversationContent,
  ConversationScrollButton,
} from '@/components/ai-elements/conversation'

import { Message, MessageContent, MessageResponse } from '@/components/ai-elements/message'

import { Tool, ToolHeader, ToolContent, ToolInput, ToolOutput } from '@/components/ai-elements/tool'

export default function App() {
  const [input, setInput] = React.useState<string>('')

  const { messages, sendMessage, status } = useChat({
    transport: new DefaultChatTransport({
      api: 'http://localhost:4111/chat/weather-agent',
    }),
  })

  const handleSubmit = async () => {
    if (!input.trim()) return

    sendMessage({ text: input })
    setInput('')
  }

  return (
    <div className="relative mx-auto size-full h-screen max-w-4xl p-6">
      <div className="flex h-full flex-col">
        <Conversation className="h-full">
          <ConversationContent>
            {messages.map(message => (
              <div key={message.id}>
                {message.parts?.map((part, i) => {
                  if (part.type === 'text') {
                    return (
                      <Message key={`${message.id}-${i}`} from={message.role}>
                        <MessageContent>
                          <MessageResponse>{part.text}</MessageResponse>
                        </MessageContent>
                      </Message>
                    )
                  }

                  if (part.type?.startsWith('tool-')) {
                    return (
                      <Tool key={`${message.id}-${i}`}>
                        <ToolHeader
                          type={(part as ToolUIPart).type}
                          state={(part as ToolUIPart).state || 'output-available'}
                          className="cursor-pointer"
                        />
                        <ToolContent>
                          <ToolInput input={(part as ToolUIPart).input || {}} />
                          <ToolOutput
                            output={(part as ToolUIPart).output}
                            errorText={(part as ToolUIPart).errorText}
                          />
                        </ToolContent>
                      </Tool>
                    )
                  }

                  return null
                })}
              </div>
            ))}
            <ConversationScrollButton />
          </ConversationContent>
        </Conversation>
        <PromptInput onSubmit={handleSubmit} className="mt-20">
          <PromptInputBody>
            <PromptInputTextarea
              onChange={e => setInput(e.target.value)}
              className="md:leading-10"
              value={input}
              placeholder="Ask about the weather..."
              disabled={status !== 'ready'}
            />
          </PromptInputBody>
        </PromptInput>
      </div>
    </div>
  )
}
```

该组件通过 [`useChat()`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/use-chat) 将提示词发送到 `chat/weather-agent` 端点，并以流式方式分块接收响应。

组件用 [`<MessageResponse>`](https://ai-sdk.dev/elements/components/message#messageresponse-) 渲染响应文本，并用 [`<Tool>`](https://ai-sdk.dev/elements/components/tool) 显示发生的 Tool 调用。

## 测试 Agent {/* #test-your-agent */}

要在聊天界面中测试 Agent，需要同时运行 Mastra 服务器和 Vite 开发服务器。

1. 启动 Mastra 开发服务器。

   ```bash npm2yarn
   npx mastra dev
   ```
2. 在另一个终端窗口中启动 Vite 开发服务器。

   ```bash npm2yarn
   npm run dev
   ```
3. 访问 [http://localhost:5173](http://localhost:5173) 打开应用。
4. 试着问一个关于天气的问题。如果 API 密钥配置正确，你就会收到回复。
