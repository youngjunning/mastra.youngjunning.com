# 反应 + 投票

在本指南中，您将使用 Mastra 构建一个Tool调用 AI Agent，然后通过直接从 Mastra 的独立服务器调用该Agent将其连接到 React。

你会使用[AI SDK UI](https://ai-sdk.dev/docs/ai-sdk-ui/overview) and [人工智能元素](https://ai-sdk.dev/elements)创造优美的交互式聊天体验。

## 开始之前 {/* #before-you-begin */}

* 您需要来自受支持的 API 密钥[model provider](/models). If you don't have a preference, use [OpenAI](/models/providers/openai).
* 安装 Node.js`v22.13.0` or later

## 创建一个新的 React + Vite 应用程序（可选） {/* #create-a-new-react--vite-app-optional */}

如果您已经有一个使用 Tailwind 的 React + Vite 应用程序，请跳到下一步。

### 工程脚手架 {/* #project-scaffold */}

运行以下命令[create a new React + Vite app](https://vite.dev/guide/#scaffolding-your-first-vite-project):

```bash npm2yarn
npm create vite@latest mastra-react -- --template react-ts
```

这将创建一个名为`mastra-react`, but you can replace it with any name you want.

导航到您的项目目录：

```bash
cd mastra-react
```

### 顺风 {/* #tailwind */}

接下来，安装 Tailwind：

```bash npm2yarn
npm install tailwindcss @tailwindcss/vite
```

配置Vite插件：

```typescript title="vite.config.ts" {3-4,7-12}
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import path from 'path'
import tailwindcss from '@tailwindcss/vite'

export default defineConfig({
  plugins: [react(), tailwindcss()],
  resolve: {
    alias: {
      '@': path.resolve(__dirname, './src'),
    },
  },
})
```

替换所有内容`src/index.css` with the following:

```css title="src/index.css"
@import 'tailwindcss';
```

添加这些`compilerOptions` to `tsconfig.json`:

```jsonc title="tsconfig.json"
{
  // ...
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"],
    },
  },
}
```

编辑`tsconfig.app.json` to resolve paths:

```jsonc title="tsconfig.app.json"
{
  "compilerOptions": {
    // ...
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"],
    },
    // ...
  },
}
```

## 初始化玛斯特拉 {/* #initialize-mastra */}

跑步[`mastra init`](/reference/cli/mastra#mastra-init). When prompted, choose a provider (e.g. OpenAI) and enter your key:

```bash npm2yarn
npx mastra@latest init
```

这创建了一个`src/mastra` folder with an example weather agent and the following files:

* `index.ts`：Mastra 配置，包括内存
* `tools/weather-tool.ts`：获取给定位置天气的Tool
* `agents/weather-agent.ts`：带有使用该Tool提示的天气Agent

你会打电话`weather-agent.ts` from your chat UI in the next steps.

## 安装 AI SDK UI 和 AI 元素 {/* #install-ai-sdk-ui--ai-elements */}

安装 AI SDK UI 以及 Mastra 适配器：

```bash npm2yarn
npm install @mastra/ai-sdk@latest @ai-sdk/react ai
```

接下来，初始化 AI 元素。当提示选择组件库时，选择**Radix UI**, then accept the defaults for the remaining prompts:

```bash npm2yarn
npx ai-elements@latest
```

:::注意
的`ai-elements` command runs `shadcn add` against the AI Elements registry, which currently publishes Radix UI components only. Installing them into a Base UI project produces TypeScript errors, tracked in [vercel/ai-elements#383](https://github.com/vercel/ai-elements/issues/383).

只有当你的项目没有组件库时才会出现组件库提示`components.json`. If you already have one, check that its `style` is a Radix option, such as `new-york` or a `radix-*` style, and not a `base-*` style, before running the command.
:::

这会将整个 AI Elements UI 组件库下载到`@/components/ai-elements` folder.

## 创建聊天路径 {/* #create-a-chat-route */}

打开 ⁠`src/mastra/index.ts` and add a [⁠chatRoute()](/reference/ai-sdk/chat-route) to your config. This creates an API route your React frontend can call for AI SDK-compatible chat responses, which you’ll use with ⁠useChat() next.

```ts title="src/mastra/index.ts"
import { Mastra } from '@mastra/core/mastra'
// Existing imports...
import { chatRoute } from '@mastra/ai-sdk'

export const mastra = new Mastra({
  // Existing config...
  server: {
    apiRoutes: [
      chatRoute({
        path: '/chat/:agentId',
      }),
    ],
  },
})
```

## 添加聊天界面 {/* #add-the-chat-ui */}

更换`src/App.tsx` file to create a chat interface:

```tsx title="src/App.tsx"
import * as React from 'react'
import { DefaultChatTransport, type ToolUIPart } from 'ai'
import { useChat } from '@ai-sdk/react'

import {
  PromptInput,
  PromptInputBody,
  PromptInputTextarea,
} from '@/components/ai-elements/prompt-input'

import {
  Conversation,
  ConversationContent,
  ConversationScrollButton,
} from '@/components/ai-elements/conversation'

import { Message, MessageContent, MessageResponse } from '@/components/ai-elements/message'

import { Tool, ToolHeader, ToolContent, ToolInput, ToolOutput } from '@/components/ai-elements/tool'

export default function App() {
  const [input, setInput] = React.useState<string>('')

  const { messages, sendMessage, status } = useChat({
    transport: new DefaultChatTransport({
      api: 'http://localhost:4111/chat/weather-agent',
    }),
  })

  const handleSubmit = async () => {
    if (!input.trim()) return

    sendMessage({ text: input })
    setInput('')
  }

  return (
    <div className="relative mx-auto size-full h-screen max-w-4xl p-6">
      <div className="flex h-full flex-col">
        <Conversation className="h-full">
          <ConversationContent>
            {messages.map(message => (
              <div key={message.id}>
                {message.parts?.map((part, i) => {
                  if (part.type === 'text') {
                    return (
                      <Message key={`${message.id}-${i}`} from={message.role}>
                        <MessageContent>
                          <MessageResponse>{part.text}</MessageResponse>
                        </MessageContent>
                      </Message>
                    )
                  }

                  if (part.type?.startsWith('tool-')) {
                    return (
                      <Tool key={`${message.id}-${i}`}>
                        <ToolHeader
                          type={(part as ToolUIPart).type}
                          state={(part as ToolUIPart).state || 'output-available'}
                          className="cursor-pointer"
                        />
                        <ToolContent>
                          <ToolInput input={(part as ToolUIPart).input || {}} />
                          <ToolOutput
                            output={(part as ToolUIPart).output}
                            errorText={(part as ToolUIPart).errorText}
                          />
                        </ToolContent>
                      </Tool>
                    )
                  }

                  return null
                })}
              </div>
            ))}
            <ConversationScrollButton />
          </ConversationContent>
        </Conversation>
        <PromptInput onSubmit={handleSubmit} className="mt-20">
          <PromptInputBody>
            <PromptInputTextarea
              onChange={e => setInput(e.target.value)}
              className="md:leading-10"
              value={input}
              placeholder="Ask about the weather..."
              disabled={status !== 'ready'}
            />
          </PromptInputBody>
        </PromptInput>
      </div>
    </div>
  )
}
```

该组件连接[`useChat()`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/use-chat) to the `chat/weather-agent` endpoint, sending prompts there and streaming the response back in chunks.

它使用以下方式呈现响应文本[`<MessageResponse>`](https://ai-sdk.dev/elements/components/message#messageresponse-) component, and shows any tool invocations with the [`<Tool>`](https://ai-sdk.dev/elements/components/tool) component.

## 测试你的Agent {/* #test-your-agent */}

要使用聊天界面测试您的Agent，请运行 Mastra 服务器和 Vite 开发服务器。

1. 启动 Mastra 开发服务器：

   ```bash npm2yarn
   npx mastra dev
   ```
2. 在单独的终端窗口中，启动Vite开发服务器：

   ```bash npm2yarn
   npm run dev
   ```
3. 打开您的申请表[http://localhost:5173](http://localhost:5173)
4. 尝试询问天气。如果您的 API 密钥设置正确，您将收到响应
