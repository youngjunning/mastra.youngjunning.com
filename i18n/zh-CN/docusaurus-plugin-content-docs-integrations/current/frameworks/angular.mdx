# Angular

使用 Mastra 构建一个能够调用 Tool 的 AI Agent，再让 Angular 通过 Mastra 的独立服务器调用该 Agent。

你将使用 [AI SDK UI](https://ai-sdk.dev/docs/ai-sdk-ui/overview) 及其 [Angular 绑定](https://ai-sdk.dev/docs/getting-started/angular)，将响应实时流式传输到聊天界面。

## 开始之前 {/* #before-you-begin */}

* 获取受支持的[模型 Provider](/models/) 提供的 API 密钥。如果没有偏好，可以使用 [OpenAI](/models/providers/openai)。
* 安装 Angular 22 支持的 Node.js 版本。22.x 系列需使用 `v22.22.3` 或更高版本，24.x 系列需使用 `v24.15.0` 或更高版本，26.x 系列需使用 `v26.0.0` 或更高版本。

## 创建 Angular 应用（可选） {/* #create-a-new-angular-app-optional */}

如果你已有 Angular 应用，请跳到下一步。

运行以下命令[创建 Angular 应用](https://angular.dev/cli/new)：

```bash npm2yarn
npm create @angular@latest mastra-angular -- --defaults --ssr=false
```

这条命令会创建一个名为 `mastra-angular` 的客户端渲染项目。你可以自行更改项目名称。

进入项目目录：

```bash
cd mastra-angular
```

## 初始化 Mastra {/* #initialize-mastra */}

运行 [`mastra init`](/reference/cli/mastra#mastra-init)，按提示选择 Provider（例如 OpenAI）并输入 API 密钥：

```bash npm2yarn
npx mastra@latest init
```

命令会创建 `src/mastra` 目录，其中包含一个天气 Agent 示例和以下文件：

* `index.ts`：Mastra 配置，包含记忆功能的配置
* `tools/weather-tool.ts`：用于查询指定地点天气的 Tool
* `agents/weather-agent.ts`：天气 Agent，其提示词指示它使用该 Tool

接下来，你会从聊天界面调用 `weather-agent.ts` 中定义的 Agent。

## 从 Angular 构建中排除 Mastra {/* #exclude-mastra-from-the-angular-build */}

Angular 默认通过 `tsconfig.app.json` 编译 `src/` 下的所有文件，包括 `src/mastra` 中的服务器端代码。默认的 `tsconfig.json` 还启用了 `noPropertyAccessFromIndexSignature`，因此 `src/mastra/index.ts` 中自动生成的 `process.env` 访问代码会导致构建失败。

将 `src/mastra/**` 添加到 `tsconfig.app.json` 的 `exclude` 列表，避免将服务器端代码编译到浏览器端：

```json title="tsconfig.app.json" {7}
{
  "extends": "./tsconfig.json",
  "compilerOptions": {
    "types": []
  },
  "include": ["src/**/*.ts"],
  "exclude": ["src/**/*.spec.ts", "src/mastra/**"]
}
```

## 安装 AI SDK UI {/* #install-ai-sdk-ui */}

安装 AI SDK UI、Mastra 适配器和 Angular 绑定：

```bash npm2yarn
npm install @mastra/ai-sdk@latest @ai-sdk/angular ai
```

## 创建聊天路由 {/* #create-a-chat-route */}

打开 `src/mastra/index.ts`，在配置中添加 [chatRoute()](/reference/ai-sdk/chat-route)。这会创建一条 API 路由，Angular 前端可以通过它获取与 AI SDK 兼容的聊天响应。下一步将使用 `Chat` 类调用这条路由。

```ts title="src/mastra/index.ts"
import { Mastra } from '@mastra/core/mastra'
// Existing imports...
import { chatRoute } from '@mastra/ai-sdk'

export const mastra = new Mastra({
  // Existing config...
  server: {
    apiRoutes: [
      chatRoute({
        path: '/chat/:agentId',
        version: 'v7',
      }),
    ],
  },
})
```

## 添加聊天界面 {/* #add-the-chat-ui */}

将 `src/app/app.ts` 的内容替换为以下组件：

```ts title="src/app/app.ts"
import { JsonPipe } from '@angular/common'
import { Component, signal } from '@angular/core'
import { Chat } from '@ai-sdk/angular'
import { DefaultChatTransport } from 'ai'

@Component({
  selector: 'app-root',
  imports: [JsonPipe],
  template: `
    <main class="chat">
      @for (message of chat.messages; track message.id) {
        <article class="message" [class.user]="message.role === 'user'">
          <strong>{{ message.role === 'user' ? 'You' : 'Assistant' }}</strong>
          @for (part of message.parts; track $index) {
            @if (part.type === 'text') {
              <p class="text">{{ part.text }}</p>
            } @else if (part.type.startsWith('tool-')) {
              <details class="tool">
                <summary>{{ part.type.replace('tool-', '') }}</summary>
                <pre>{{ part | json }}</pre>
              </details>
            }
          }
        </article>
      }

      @if (chat.status === 'submitted') {
        <p class="status">Waiting for a response...</p>
      }

      @if (chat.error; as error) {
        <p class="error" role="alert">{{ error.message }}</p>
      }

      <form (submit)="sendMessage($event)">
        <label for="message">Your message</label>
        <textarea
          id="message"
          #messageInput
          rows="2"
          [value]="input()"
          (input)="input.set(messageInput.value)"
          placeholder="Ask about the weather..."
        ></textarea>
        <button
          type="submit"
          [disabled]="chat.status === 'submitted' || chat.status === 'streaming'"
        >
          Send
        </button>
        @if (chat.status === 'submitted' || chat.status === 'streaming') {
          <button type="button" (click)="chat.stop()">Stop</button>
        }
      </form>
    </main>
  `,
  styles: `
    .chat {
      display: flex;
      flex-direction: column;
      gap: 1rem;
      max-width: 48rem;
      margin: 0 auto;
      padding: 1.5rem;
    }

    .message {
      display: flex;
      flex-direction: column;
      gap: 0.5rem;
      padding: 0.75rem 1rem;
      border: 1px solid #d4d4d8;
      border-radius: 0.5rem;
    }

    .message.user {
      background: #f4f4f5;
    }

    .text {
      margin: 0;
      white-space: pre-wrap;
    }

    .tool pre {
      overflow-x: auto;
      margin: 0.5rem 0 0;
    }

    .error {
      color: #b91c1c;
    }

    form {
      display: flex;
      flex-direction: column;
      gap: 0.5rem;
    }

    button {
      align-self: flex-start;
      padding: 0.5rem 1rem;
    }
  `,
})
export class App {
  readonly chat = new Chat({
    transport: new DefaultChatTransport({
      api: 'http://localhost:4111/chat/weather-agent',
    }),
  })

  readonly input = signal('')

  sendMessage(event: Event) {
    event.preventDefault()

    const text = this.input().trim()
    if (!text || this.chat.status === 'submitted' || this.chat.status === 'streaming') {
      return
    }

    this.chat.sendMessage({ text })
    this.input.set('')
  }
}
```

该组件创建一个 [`Chat`](https://ai-sdk.dev/docs/getting-started/angular) 实例，并将其传输目标设为 `chat/weather-agent` 端点。`Chat` 类会向该端点发送提示词，并将收到的响应流式写入 `chat.messages`。

组件会在收到文本片段时立即渲染，并在可折叠的 `<details>` 元素中显示 Tool 调用。状态和错误消息分别来自响应式属性 `chat.status` 和 `chat.error`。点击 **Stop**（停止）可取消正在生成的响应。

:::note
较早创建的 Angular 项目可能使用 `app.component.ts` 作为根组件文件名，并使用 `AppComponent` 作为类名。如果你在现有项目中操作，请保留原来的文件名和类名，确保 `src/main.ts` 中的导入仍然有效。
:::

## 测试 Agent {/* #test-your-agent */}

要通过聊天界面测试 Agent，请同时运行 Mastra 服务器和 Angular 开发服务器。

1. 启动 Mastra 开发服务器：

   ```bash npm2yarn
   npx mastra dev
   ```
2. 在另一个终端窗口中启动 Angular 开发服务器：

   ```bash npm2yarn
   npm start
   ```
3. 访问 [http://localhost:4200](http://localhost:4200) 打开应用。
4. 试着询问天气。如果 API 密钥配置正确，你就会收到响应。
