# 角

使用 Mastra 构建一个Tool调用 AI Agent，然后通过从 Mastra 的独立服务器调用该Agent将其连接到 Angular。

你会使用[AI SDK UI](https://ai-sdk.dev/docs/ai-sdk-ui/overview) and its [角度绑定](https://ai-sdk.dev/docs/getting-started/angular)将响应流式传输到聊天界面。

## 开始之前 {/* #before-you-begin */}

* 您需要来自受支持的 API 密钥[model provider](/models/). If you don't have a preference, use [OpenAI](/models/providers/openai).
* 安装 Node.js`v22.22.3` or later, or `v24.15.0` or later if you're on the 24.x line, or `v26.0.0` or later if you're on the 26.x line. These are the ranges Angular 22 supports.

## 创建一个新的 Angular 应用程序（可选） {/* #create-a-new-angular-app-optional */}

如果您已有 Angular 应用程序，请跳至下一步。

运行以下命令[create a new Angular app](https://angular.dev/cli/new):

```bash npm2yarn
npm create @angular@latest mastra-angular -- --defaults --ssr=false
```

这将创建一个名为的客户端渲染项目`mastra-angular`, but you can replace it with any name you want.

导航到您的项目目录：

```bash
cd mastra-angular
```

## 初始化玛斯特拉 {/* #initialize-mastra */}

跑步[`mastra init`](/reference/cli/mastra#mastra-init). When prompted, choose a provider (e.g. OpenAI) and enter your key:

```bash npm2yarn
npx mastra@latest init
```

这创建了一个`src/mastra` folder with an example weather agent and the following files:

* `index.ts`：Mastra 配置，包括内存
* `tools/weather-tool.ts`：获取给定位置天气的Tool
* `agents/weather-agent.ts`：带有使用该Tool提示的天气Agent

你会打电话`weather-agent.ts` from your chat UI in the next steps.

## 从 Angular 构建中排除 Mastra {/* #exclude-mastra-from-the-angular-build */}

Angular 的默认值`tsconfig.app.json` compiles every file under `src/`, including the `src/mastra` server code. Its default `tsconfig.json` also enables `noPropertyAccessFromIndexSignature`, which makes the generated `process.env` access in `src/mastra/index.ts` fail the build.

通过添加以下内容，将服务器代码排除在浏览器构建之外`src/mastra/**` to the `exclude` list in `tsconfig.app.json`:

```json title="tsconfig.app.json" {7}
{
  "extends": "./tsconfig.json",
  "compilerOptions": {
    "types": []
  },
  "include": ["src/**/*.ts"],
  "exclude": ["src/**/*.spec.ts", "src/mastra/**"]
}
```

## 安装AI SDK UI {/* #install-ai-sdk-ui */}

安装 AI SDK UI 以及 Mastra 适配器和 Angular 绑定：

```bash npm2yarn
npm install @mastra/ai-sdk@latest @ai-sdk/angular ai
```

## 创建聊天路径 {/* #create-a-chat-route */}

打开`src/mastra/index.ts` and add a [chatRoute()](/reference/ai-sdk/chat-route) to your config. This creates an API route your Angular frontend can call for AI SDK-compatible chat responses, which you'll use with the `Chat` class next.

```ts title="src/mastra/index.ts"
import { Mastra } from '@mastra/core/mastra'
// Existing imports...
import { chatRoute } from '@mastra/ai-sdk'

export const mastra = new Mastra({
  // Existing config...
  server: {
    apiRoutes: [
      chatRoute({
        path: '/chat/:agentId',
        version: 'v7',
      }),
    ],
  },
})
```

## 添加聊天界面 {/* #add-the-chat-ui */}

代替`src/app/app.ts` with the following component:

```ts title="src/app/app.ts"
import { JsonPipe } from '@angular/common'
import { Component, signal } from '@angular/core'
import { Chat } from '@ai-sdk/angular'
import { DefaultChatTransport } from 'ai'

@Component({
  selector: 'app-root',
  imports: [JsonPipe],
  template: `
    <main class="chat">
      @for (message of chat.messages; track message.id) {
        <article class="message" [class.user]="message.role === 'user'">
          <strong>{{ message.role === 'user' ? 'You' : 'Assistant' }}</strong>
          @for (part of message.parts; track $index) {
            @if (part.type === 'text') {
              <p class="text">{{ part.text }}</p>
            } @else if (part.type.startsWith('tool-')) {
              <details class="tool">
                <summary>{{ part.type.replace('tool-', '') }}</summary>
                <pre>{{ part | json }}</pre>
              </details>
            }
          }
        </article>
      }

      @if (chat.status === 'submitted') {
        <p class="status">Waiting for a response...</p>
      }

      @if (chat.error; as error) {
        <p class="error" role="alert">{{ error.message }}</p>
      }

      <form (submit)="sendMessage($event)">
        <label for="message">Your message</label>
        <textarea
          id="message"
          #messageInput
          rows="2"
          [value]="input()"
          (input)="input.set(messageInput.value)"
          placeholder="Ask about the weather..."
        ></textarea>
        <button
          type="submit"
          [disabled]="chat.status === 'submitted' || chat.status === 'streaming'"
        >
          Send
        </button>
        @if (chat.status === 'submitted' || chat.status === 'streaming') {
          <button type="button" (click)="chat.stop()">Stop</button>
        }
      </form>
    </main>
  `,
  styles: `
    .chat {
      display: flex;
      flex-direction: column;
      gap: 1rem;
      max-width: 48rem;
      margin: 0 auto;
      padding: 1.5rem;
    }

    .message {
      display: flex;
      flex-direction: column;
      gap: 0.5rem;
      padding: 0.75rem 1rem;
      border: 1px solid #d4d4d8;
      border-radius: 0.5rem;
    }

    .message.user {
      background: #f4f4f5;
    }

    .text {
      margin: 0;
      white-space: pre-wrap;
    }

    .tool pre {
      overflow-x: auto;
      margin: 0.5rem 0 0;
    }

    .error {
      color: #b91c1c;
    }

    form {
      display: flex;
      flex-direction: column;
      gap: 0.5rem;
    }

    button {
      align-self: flex-start;
      padding: 0.5rem 1rem;
    }
  `,
})
export class App {
  readonly chat = new Chat({
    transport: new DefaultChatTransport({
      api: 'http://localhost:4111/chat/weather-agent',
    }),
  })

  readonly input = signal('')

  sendMessage(event: Event) {
    event.preventDefault()

    const text = this.input().trim()
    if (!text || this.chat.status === 'submitted' || this.chat.status === 'streaming') {
      return
    }

    this.chat.sendMessage({ text })
    this.input.set('')
  }
}
```

该组件创建一个[`Chat`](https://ai-sdk.dev/docs/getting-started/angular) instance and points its transport at the `chat/weather-agent` endpoint. The `Chat` class sends prompts there and streams the response into `chat.messages`.

它会在文本部分到达时呈现它们，并以可折叠的方式显示Tool调用`<details>` element. The status and error messages use the reactive `chat.status` and `chat.error` properties, and the **Stop** option cancels the active response.

:::注意
较旧的 Angular 项目可能会命名根组件文件`app.component.ts` and its class `AppComponent`. If you're using an existing project, keep its file and class names so the imports in `src/main.ts` continue to work.
:::

## 测试你的Agent {/* #test-your-agent */}

要使用聊天界面测试Agent，请运行 Mastra 服务器和 Angular 开发服务器。

1. 启动 Mastra 开发服务器：

   ```bash npm2yarn
   npx mastra dev
   ```
2. 在单独的终端窗口中，启动 Angular 开发服务器：

   ```bash npm2yarn
   npm start
   ```
3. 打开您的申请表[http://localhost:4200](http://localhost:4200)
4. 尝试询问天气。如果您的 API 密钥设置正确，您将收到响应
