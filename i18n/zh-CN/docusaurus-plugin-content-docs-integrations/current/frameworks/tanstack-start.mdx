# TanStack Start

在 TanStack Start 中构建一个能调用 Tool 的 Mastra Agent，然后将 Mastra 服务器挂载到通配 API 路由上。[服务器适配器](/docs/server/server-adapters)概述介绍了各适配器的通用概念，[TanStack Start 适配器](/reference/server/tanstack-start-adapter)参考文档介绍了该包的 API。

## 开始之前 {/* #before-you-begin */}

- 你需要获取受支持的 [Model Provider](/models) 的 API 密钥。如果没有偏好的 Provider，请使用 [OpenAI](/models/providers/openai)。
- 安装 Node.js `v22.13.0` 或更高版本

## 创建新的 TanStack Start 应用（可选） {/* #create-a-new-tanstack-start-app-optional */}

你需要一个已在运行且包含 `src/routes` 目录的 TanStack Start 应用。如果还没有，请按照 [TanStack Start 快速入门指南](https://tanstack.com/start/latest/docs/framework/react/getting-started)创建并运行应用，然后继续。

## 初始化 Mastra {/* #initialize-mastra */}

在 TanStack Start 项目目录中运行 [`mastra init`](/reference/cli/mastra#mastra-init)。按提示选择一个 Provider（例如 OpenAI），然后输入 API 密钥：

```bash npm2yarn
npx mastra@latest init
```

该命令会创建 `src/mastra` 目录，其中包含一个示例天气 Agent 和以下文件：

- `index.ts`：Mastra 配置，包括 Memory 配置
- `tools/weather-tool.ts`：用于获取指定地点天气信息的 Tool
- `agents/weather-agent.ts`：带有指令、可按指令使用该 Tool 的天气 Agent

接下来，将 `src/mastra/index.ts` 导出的 Mastra 实例传给服务器适配器。

## 配置 Vite 和 Nitro {/* #configure-vite-and-nitro */}

更新 `vite.config.ts`，让 Vite 和 Nitro 在处理时跳过 DuckDB 和 `@mastra/core` 中仅适用于 Node.js 的依赖：

```diff title="vite.config.ts"
 const config = defineConfig({
   resolve: { tsconfigPaths: true },
+  optimizeDeps: {
+    exclude: ['@mastra/duckdb', 'execa'],
+  },
   plugins: [
     devtools(),
-    nitro({ rollupConfig: { external: [/^@sentry\//] } }),
+    nitro({
+      rollupConfig: {
+        external: [/^@sentry\//, /^@duckdb\//],
+      },
+    }),
```

`optimizeDeps.exclude` 可防止 Vite 的开发环境优化器将 DuckDB 的原生 `.node` 二进制文件当作 JavaScript 打开。排除 `execa` 可避免优化器预打包这个仅在服务器端使用的依赖。`@mastra/core` 用它执行本地进程，而它的传递依赖 `npm-run-path` 和 `unicorn-magic` 使用仅适用于 Node.js 的条件导出，优化器在浏览器构建中无法解析这些导出。将 `/^@duckdb\//` 添加到 Nitro 的 `rollupConfig.external`，可将 DuckDB 的原生 Node.js 包排除在生产构建产物之外，由 Node.js 在运行时加载。

这些改动只涉及 `vite.config.ts`，无需修改应用或 Mastra 的源文件。

## 添加服务器适配器 {/* #add-the-server-adapter */}

安装 TanStack Start 服务器适配器及其对等依赖 Hono：

```bash npm2yarn
npm install @mastra/tanstack-start@latest hono
```

创建一个通配路由，将所有受支持的 HTTP 方法交由适配器处理：

```typescript title="src/routes/api/$.ts"
import { createStartRouteHandler } from '@mastra/tanstack-start'
import { createFileRoute } from '@tanstack/react-router'
import { mastra } from '../../mastra'

export const Route = createFileRoute('/api/$')({
  server: {
    handlers: createStartRouteHandler({ mastra }),
  },
})
```

`prefix` 选项默认为 `/api`，且必须与通配路由的挂载路径一致。例如，将适配器挂载在 `src/routes/api/mastra/$.ts` 时，使用 `createStartRouteHandler({ mastra, prefix: '/api/mastra' })`。

适配器公开 Mastra 的 REST 端点、流式端点、自定义 API 路由、MCP 端点和 A2A 端点。A2A 任务使用内存中的任务存储。

## 测试 Agent {/* #test-your-agent */}

启动 TanStack Start 应用：

```bash npm2yarn
npm run dev
```

另开一个终端窗口，使用 `curl` 向天气 Agent 提问：

```bash
curl -X POST http://localhost:3000/api/agents/weather-agent/generate -H "Content-Type: application/json" -d "{\"messages\":[{\"role\":\"user\",\"content\":\"What is the weather like in Seoul?\"}]}"
```

该端点会返回 Agent 的完整 JSON 响应。
