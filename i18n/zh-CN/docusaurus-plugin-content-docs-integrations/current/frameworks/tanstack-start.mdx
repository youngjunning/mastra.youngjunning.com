# TanStack 启动

在 TanStack Start 中构建一个调用Tool的 Mastra Agent，然后将 Mastra 服务器安装在一个包罗万象的 API 路由上。这[Server Adapters](/docs/server/server-adapters)概述解释了共享概念，以及[TanStack 启动适配器](/reference/server/tanstack-start-adapter)参考文档包 API。

## 开始之前 {/* #before-you-begin */}

* 您需要来自受支持的 API 密钥[model provider](/models). If you don't have a preference, use [OpenAI](/models/providers/openai).
* 安装 Node.js`v22.13.0` or later

## 创建新的 TanStack Start 应用程序（可选） {/* #create-a-new-tanstack-start-app-optional */}

您需要一个正在运行的 TanStack Start 应用程序`src/routes` directory. If you don't already have one, follow the [TanStack Start quick start](https://tanstack.com/start/latest/docs/framework/react/getting-started) to create and run an app before continuing.

## 初始化玛斯特拉 {/* #initialize-mastra */}

从 TanStack Start 项目目录中，运行[`mastra init`](/reference/cli/mastra#mastra-init). When prompted, choose a provider, such as OpenAI, and enter your API key:

```bash npm2yarn
npx mastra@latest init
```

这创建了一个`src/mastra` directory with an example weather agent and the following files:

* `index.ts`：Mastra 配置，包括内存
* `tools/weather-tool.ts`：获取某个地点天气的Tool
* `agents/weather-agent.ts`：气象Agent以及该Tool的使用说明

您将传递从以下位置导出的 Mastra 实例`src/mastra/index.ts` to the server adapter.

## 配置 Vite 和 Nitro {/* #configure-vite-and-nitro */}

更新`vite.config.ts` so Vite and Nitro leave DuckDB's and `@mastra/core`'s Node-only dependencies out of their processing pipelines:

```diff title="vite.config.ts"
 const config = defineConfig({
   resolve: { tsconfigPaths: true },
+  optimizeDeps: {
+    exclude: ['@mastra/duckdb', 'execa'],
+  },
   plugins: [
     devtools(),
-    nitro({ rollupConfig: { external: [/^@sentry\//] } }),
+    nitro({
+      rollupConfig: {
+        external: [/^@sentry\//, /^@duckdb\//],
+      },
+    }),
```

这`optimizeDeps.exclude` setting prevents Vite's development optimizer from opening DuckDB's native `.node` binary as JavaScript. Excluding `execa` stops the optimizer from pre-bundling the server-only dependency `@mastra/core` uses for local process execution; its transitive `npm-run-path` and `unicorn-magic` packages use Node-only conditional exports that the optimizer cannot resolve in the browser build. Adding `/^@duckdb\//` to Nitro's `rollupConfig.external` keeps DuckDB's native Node packages out of the production bundle so Node.js can load them at runtime.

这些更改仅适用于`vite.config.ts`; you don't need to change your application or Mastra source files.

## 添加服务器适配器 {/* #add-the-server-adapter */}

安装 TanStack Start 服务器适配器及其 Hono 对等依赖项：

```bash npm2yarn
npm install @mastra/tanstack-start@latest hono
```

创建一个 splat 路由，将所有支持的 HTTP 方法传递给适配器：

```typescript title="src/routes/api/$.ts"
import { createStartRouteHandler } from '@mastra/tanstack-start'
import { createFileRoute } from '@tanstack/react-router'
import { mastra } from '../../mastra'

export const Route = createFileRoute('/api/$')({
  server: {
    handlers: createStartRouteHandler({ mastra }),
  },
})
```

这`prefix` option defaults to `/api` and must match the splat route's mount path. For example, when mounting the adapter at `src/routes/api/mastra/$.ts`, use `createStartRouteHandler({ mastra, prefix: '/api/mastra' })`.

该适配器公开 Mastra 的 REST 和流端点、自定义 API 路由、MCP 端点和 A2A 端点。 A2A 任务使用内存中的任务存储。

## 测试你的Agent {/* #test-your-agent */}

启动您的 TanStack Start 应用程序：

```bash npm2yarn
npm run dev
```

在单独的终端窗口中，使用`curl` to ask the weather agent:

```bash
curl -X POST http://localhost:3000/api/agents/weather-agent/generate -H "Content-Type: application/json" -d "{\"messages\":[{\"role\":\"user\",\"content\":\"What is the weather like in Seoul?\"}]}"
```

端点从Agent返回完整的 JSON 响应。
