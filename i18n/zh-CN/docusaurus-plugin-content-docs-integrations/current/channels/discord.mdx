# Discord

Mastra 可以通过两种方式与 Discord 集成：

- **Agent 的 Tool** 让 Agent 能够在 Discord 服务器中执行操作，例如发送消息或管理频道。
- **Agent 聊天**让用户能在 Discord 中通过机器人消息和交互操作（例如斜杠命令和按钮）与 Agent 对话。

[Mastra Connect](/docs/mastra-platform/connect) 使用同一个 Discord 机器人配置这两项功能，并将其令牌保存在 Mastra 平台上。对于 Agent 聊天，你也可以自行管理机器人凭据。

## Connect {/* #connect */}

开始之前，请先完成 [Connect 配置](/docs/mastra-platform/connect#get-started)，安装 `@mastra/connect` 并配置你的平台项目。

一个 `discord` 连接即可同时提供 Agent 的 Tool 和聊天功能。该连接使用**机器人令牌**，而非用户 OAuth 令牌。

### 创建 Discord 机器人 {/* #create-a-discord-bot */}

1. 在 [Discord 开发者门户](https://discord.com/developers/applications)中创建一个应用。
1. 打开 **Bot**，添加一个机器人，然后选择 **Reset Token** 并复制机器人令牌。
1. 如果要使用 Agent 聊天，请在 **Privileged Gateway Intents** 下启用 **Message Content Intent**。

当 `mastra connect add discord` 提示输入凭据时，输入机器人令牌。

### Agent 聊天 {/* #agent-chat */}

你的服务器需要一个 Discord 可以公开访问的 URL，用于投递 Webhook 和处理 OAuth 回调。Mastra 平台会提供此 URL。如果在其他地方托管，请将 `MASTRA_SERVER_URL` 设置为服务器的公开 URL。本地开发时，请使用可公开访问的 HTTPS 隧道。

1. 如果尚未添加连接，请运行 `mastra connect add discord` 并输入机器人令牌。

1. 将 [`channels()`](/reference/connect/channels) 传入 `Mastra` 构造函数。它会注册 Discord 渠道的 Provider 及其路由：

   ```typescript title="src/mastra/index.ts"
   import { Mastra } from '@mastra/core'
   import { channels } from '@mastra/connect'
   import { assistant } from './agents/assistant'

   export const mastra = new Mastra({
     agents: { assistant },
     channels: await channels({ providers: ['discord'] }),
   })
   ```

   如需同时注册其他渠道，请将其 Provider ID 添加到 `providers`。

1. 启动你的 Mastra 应用。

1. 在 Studio 中，将 Discord 渠道连接到一个 Agent。如果机器人尚未加入服务器，请打开生成的授权 URL，选择服务器并授予所请求的权限。

Discord 通过 Gateway 传递消息，并通过 HTTP 交互路由处理斜杠命令和按钮交互。有关邀请机器人时请求的授权范围和权限，请参阅 [Discord 权限](/reference/connect/channels#discord-permissions)。

## 自行配置 {/* #self-managed-setup */}

使用 Chat SDK 的 Discord 适配器，并使用你自己的 Discord 应用和凭据。

### 安装适配器 {/* #install-the-adapter */}

安装 Chat SDK 提供的 Discord 适配器：

```bash npm2yarn
npm install @chat-adapter/discord
```

### 配置 Agent {/* #agent-configuration */}

将 `createDiscordAdapter()` 添加到 Agent 的 `channels.adapters` 对象中：

```typescript title="src/mastra/agents/discord-agent.ts"
import { Agent } from '@mastra/core/agent'
import { createDiscordAdapter } from '@chat-adapter/discord'

export const discordAgent = new Agent({
  id: 'discord-agent',
  name: 'Discord Agent',
  instructions: 'Answer questions and help with tasks in Discord.',
  model: '__GATEWAY_OPENAI_MODEL__',
  channels: {
    adapters: {
      discord: createDiscordAdapter(),
    },
  },
})
```

在 Mastra 实例中注册该 Agent：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { discordAgent } from './agents/discord-agent'

export const mastra = new Mastra({
  agents: { discordAgent },
})
```

### 配置适配器 {/* #adapter-setup */}

有关 Discord 专用配置，请参阅 [Chat SDK 的 Discord 适配器文档](https://chat-sdk.dev/adapters/official/discord)，其中涵盖应用创建、机器人令牌、交互端点、权限和 Gateway 的运行机制。

适配器从以下环境变量读取 Discord 凭据：

```bash title=".env"
DISCORD_BOT_TOKEN=your-discord-bot-token
DISCORD_PUBLIC_KEY=your-discord-application-public-key
DISCORD_APPLICATION_ID=your-discord-application-id
```

### Webhook URL {/* #webhook-url */}

Mastra 根据 Agent ID 和适配器键生成 Discord Webhook 路由：

```text
/api/agents/discord-agent/channels/discord/webhook
```

将可公开访问的 Mastra 服务器 URL 用作基准 URL：

```text
https://your-app.example.com/api/agents/discord-agent/channels/discord/webhook
```

凡是 Discord 适配器文档要求填写交互端点或 Webhook URL 的地方，都使用此 URL。要接收 Discord 的常规消息事件，可能还需要在生成的 Webhook 路由之外单独配置 Gateway。具体配置请参阅 Chat SDK 适配器文档。
