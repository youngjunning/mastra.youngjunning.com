# WhatsApp

WhatsApp 渠道让 Mastra Agent 能够通过 WhatsApp Business Cloud 接收客户消息。Mastra 负责接入 Agent 并提供 Webhook 路由。有关如何设置 Meta 应用、准备凭据和配置 Webhook，请参阅 Chat SDK 的 WhatsApp 适配器文档。

## 安装适配器 {/* #install-the-adapter */}

安装 Chat SDK 提供的 WhatsApp 适配器：

```bash npm2yarn
npm install @chat-adapter/whatsapp
```

## Agent 配置 {/* #agent-configuration */}

将 `createWhatsAppAdapter()` 添加到 Agent 的 `channels.adapters` 对象中：

```typescript title="src/mastra/agents/whatsapp-agent.ts"
import { Agent } from '@mastra/core/agent'
import { createWhatsAppAdapter } from '@chat-adapter/whatsapp'

export const whatsappAgent = new Agent({
  id: 'whatsapp-agent',
  name: 'WhatsApp Agent',
  instructions: 'Answer customer questions and help with tasks in WhatsApp.',
  model: '__GATEWAY_OPENAI_MODEL__',
  channels: {
    adapters: {
      whatsapp: createWhatsAppAdapter(),
    },
  },
})
```

在 Mastra 实例中注册 Agent：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { whatsappAgent } from './agents/whatsapp-agent'

export const mastra = new Mastra({
  agents: { whatsappAgent },
})
```

## 配置适配器 {/* #adapter-setup */}

按照 [Chat SDK 的 WhatsApp 适配器文档](https://chat-sdk.dev/adapters/official/whatsapp)完成 WhatsApp 专属设置，包括 Meta 应用配置、访问令牌、电话号码 ID、Webhook 验证和消息限制。

适配器会从以下环境变量中读取 WhatsApp 凭据：

```bash title=".env"
WHATSAPP_ACCESS_TOKEN=your-meta-access-token
WHATSAPP_APP_SECRET=your-meta-app-secret
WHATSAPP_PHONE_NUMBER_ID=your-whatsapp-phone-number-id
WHATSAPP_VERIFY_TOKEN=your-webhook-verify-token
```

## Webhook URL {/* #webhook-url */}

Mastra 根据 Agent ID 和适配器的键生成 WhatsApp Webhook 路由：

```text
/api/agents/whatsapp-agent/channels/whatsapp/webhook
```

使用可从公网访问的 Mastra 服务器 URL 作为基础 URL：

```text
https://your-app.example.com/api/agents/whatsapp-agent/channels/whatsapp/webhook
```

使用此 URL 接收 WhatsApp 发送的事件。Mastra 生成的路由会处理 WhatsApp 通过 POST 发送的事件。有关 Meta 回调和 Webhook 验证流程，请参阅 Chat SDK 的 WhatsApp 适配器文档。
