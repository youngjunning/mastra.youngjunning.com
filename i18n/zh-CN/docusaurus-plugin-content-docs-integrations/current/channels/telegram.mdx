# Telegram

通过 Telegram 渠道，用户可以在 Telegram 中通过私信、群组消息或提及机器人与您的 Agent 对话。

[Mastra Connect](/docs/mastra-platform/connect) 会将您的 Telegram 机器人令牌存储在 Mastra 平台上，并为您注册 Webhook。您也可以自行管理机器人令牌和 Webhook。

## 连接 {/* #connect */}

开始前，请完成 [Connect 配置](/docs/mastra-platform/connect#get-started)，安装 `@mastra/connect` 并配置您的平台项目。

Connect 使用 BotFather 提供的机器人令牌。连接 Agent 前，请在长期运行的生产服务器上设置 `MASTRA_ENCRYPTION_KEY`。Mastra 使用该密钥加密存储的 Webhook 密钥。如果未设置，Webhook 密钥将以明文存储。

Webhook 模式需要一个可公开访问的 HTTPS 服务器 URL。Mastra 平台会提供此 URL。如果您在其他地方托管，请将 `MASTRA_SERVER_URL` 设为服务器的公开 URL。如果本地开发时没有公开的 Webhook URL，请参阅 [Telegram Provider 参考文档](/reference/channels/telegram-provider)了解轮询模式。

1. 打开 [BotFather](https://t.me/botfather)，运行 `/newbot`，然后按提示操作。

1. 复制 BotFather 返回的机器人令牌。

1. 运行 `mastra connect add telegram`，然后输入机器人令牌。

1. 将 [`channels()`](/reference/connect/channels) 传入 `Mastra` 构造函数。它会注册 Telegram 渠道的 Provider 及其路由：

   ```typescript title="src/mastra/index.ts"
   import { Mastra } from '@mastra/core'
   import { channels } from '@mastra/connect'
   import { assistant } from './agents/assistant'

   export const mastra = new Mastra({
     agents: { assistant },
     channels: await channels({ providers: ['telegram'] }),
   })
   ```

   如果还要注册其他渠道，请将对应的 Provider ID 添加到 `providers`。

1. 启动您的 Mastra 应用。

1. 在 Studio 中将 Telegram 渠道连接到一个 Agent。Mastra 会验证机器人、创建 Webhook 密钥，并向 Telegram 注册该 Agent 的公开 Webhook URL。

如果要为 Agent 更换机器人，请先在 Studio 中断开该 Agent 的连接，再重新连接。Mastra 不会将现有 Agent 的 Webhook 转移到其他机器人。

## 自行配置 {/* #self-managed-setup */}

使用 Chat SDK 的 Telegram 适配器，并提供您自己的机器人令牌和 Webhook。

### 安装适配器 {/* #install-the-adapter */}

安装 Chat SDK 的 Telegram 适配器：

```bash npm2yarn
npm install @chat-adapter/telegram
```

### 配置 Agent {/* #agent-configuration */}

将 `createTelegramAdapter()` 添加到 Agent 的 `channels.adapters` 对象中：

```typescript title="src/mastra/agents/telegram-agent.ts"
import { Agent } from '@mastra/core/agent'
import { createTelegramAdapter } from '@chat-adapter/telegram'

export const telegramAgent = new Agent({
  id: 'telegram-agent',
  name: 'Telegram Agent',
  instructions: 'Answer questions and help with tasks in Telegram.',
  model: '__GATEWAY_OPENAI_MODEL__',
  channels: {
    adapters: {
      telegram: createTelegramAdapter(),
    },
  },
})
```

在 Mastra 实例中注册该 Agent：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { telegramAgent } from './agents/telegram-agent'

export const mastra = new Mastra({
  agents: { telegramAgent },
})
```

### 配置适配器 {/* #adapter-setup */}

请按照 [Chat SDK 的 Telegram 适配器文档](https://chat-sdk.dev/adapters/official/telegram)完成 Telegram 专用配置，包括使用 BotFather、注册 Webhook、配置密钥令牌和使用轮询模式。

适配器从环境变量中读取 Telegram 凭证，例如：

```bash title=".env"
TELEGRAM_BOT_TOKEN=your-telegram-bot-token
TELEGRAM_WEBHOOK_SECRET_TOKEN=your-webhook-secret-token
TELEGRAM_BOT_USERNAME=your_bot_username
```

### Webhook URL {/* #webhook-url */}

Mastra 根据 Agent ID 和适配器键生成 Telegram Webhook 路由：

```text
/api/agents/telegram-agent/channels/telegram/webhook
```

以 Mastra 服务器的公开 URL 作为基础 URL：

```text
https://your-app.example.com/api/agents/telegram-agent/channels/telegram/webhook
```

凡是 Telegram 适配器文档要求填写 Webhook URL 的地方，都使用此 URL。Telegram 也支持轮询模式。如果想在本地开发时使用轮询，请按 Chat SDK 适配器文档操作。
