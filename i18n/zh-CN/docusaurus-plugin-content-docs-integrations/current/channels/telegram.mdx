# 电报

Telegram 频道让人们可以通过 Telegram 直接消息、群组和机器人提及与您的客服人员交谈。

[马斯特拉连接](/docs/mastra-platform/connect)将您的 Telegram 机器人令牌存储在 Mastra 平台上并为您注册 webhook。您还可以自己管理机器人令牌和 webhook。

## 连接 {/* #connect */}

在开始之前，请完成[Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect` and configure your platform project.

Connect 使用来自 BotFather 的机器人令牌。在连接Agent之前，请设置`MASTRA_ENCRYPTION_KEY` on a persistent production server. Mastra uses it to encrypt the stored webhook secret. Without a key, the secret is stored unencrypted.

Webhook 模式需要公共 HTTPS 服务器 URL。 Mastra 平台提供此 URL。当您在其他地方托管时，请设置`MASTRA_SERVER_URL` to your public server URL. For local development without a public webhook URL, the [Telegram provider reference](/reference/channels/telegram-provider) describes polling mode.

1. 打开[BotFather](https://t.me/botfather), run `/newbot`, and follow the prompts.

2. 复制 BotFather 返回的机器人令牌。

3. 跑步`mastra connect add telegram` and enter the bot token.

4. 经过[`channels()`](/reference/connect/channels) to the `Mastra` constructor. It registers the Telegram channel provider and its routes:

   ```typescript title="src/mastra/index.ts"
   import { Mastra } from '@mastra/core'
   import { channels } from '@mastra/connect'
   import { assistant } from './agents/assistant'

   export const mastra = new Mastra({
     agents: { assistant },
     channels: await channels({ providers: ['telegram'] }),
   })
   ```

   要也注册其他频道，请将其Provider ID 添加到`providers`.

5. 启动您的 Mastra 申请。

6. 在 Studio 中，将 Telegram 通道连接到Agent。 Mastra 验证机器人，创建 Webhook 机密，并使用 Telegram 注册Agent的公共 Webhook URL。

要将Agent更改为其他机器人，请在 Studio 中断开Agent的连接，然后重新连接。 Mastra 不会将现有Agent的 webhook 移动到另一个机器人。

## 自我管理设置 {/* #self-managed-setup */}

将 Chat SDK Telegram 适配器与您自己的机器人令牌和 Webhook 结合使用。

### 安装适配器 {/* #install-the-adapter */}

从 Chat SDK 安装 Telegram 适配器：

```bash npm2yarn
npm install @chat-adapter/telegram
```

### Agent配置 {/* #agent-configuration */}

添加`createTelegramAdapter()` to the agent's `channels.adapters` object:

```typescript title="src/mastra/agents/telegram-agent.ts"
import { Agent } from '@mastra/core/agent'
import { createTelegramAdapter } from '@chat-adapter/telegram'

export const telegramAgent = new Agent({
  id: 'telegram-agent',
  name: 'Telegram Agent',
  instructions: 'Answer questions and help with tasks in Telegram.',
  model: '__GATEWAY_OPENAI_MODEL__',
  channels: {
    adapters: {
      telegram: createTelegramAdapter(),
    },
  },
})
```

在 Mastra 实例上注册Agent：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { telegramAgent } from './agents/telegram-agent'

export const mastra = new Mastra({
  agents: { telegramAgent },
})
```

### 适配器设置 {/* #adapter-setup */}

遵循[Chat SDK Telegram adapter docs](https://chat-sdk.dev/adapters/official/telegram) for Telegram-specific setup, including BotFather, webhook registration, secret tokens, and polling mode.

适配器从环境变量中读取 Telegram 凭证，例如：

```bash title=".env"
TELEGRAM_BOT_TOKEN=your-telegram-bot-token
TELEGRAM_WEBHOOK_SECRET_TOKEN=your-webhook-secret-token
TELEGRAM_BOT_USERNAME=your_bot_username
```

### 网络钩子 URL {/* #webhook-url */}

Mastra 根据Agent ID 和适配器密钥生成 Telegram Webhook 路由：

```text
/api/agents/telegram-agent/channels/telegram/webhook
```

使用您的公共 Mastra 服务器 URL 作为基本 URL：

```text
https://your-app.example.com/api/agents/telegram-agent/channels/telegram/webhook
```

在 Telegram 适配器文档要求提供 Webhook URL 的任何地方都可以使用此 URL。 Telegram 还支持轮询模式。如果您想使用轮询进行本地开发，请遵循聊天 SDK 适配器文档。
