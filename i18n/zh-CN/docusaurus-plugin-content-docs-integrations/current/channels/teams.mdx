# Microsoft Teams

Mastra 可以通过两种方式与 Microsoft Teams 集成：

- **Agent 的 Tool** 让 Agent 能够在 Teams 中执行操作，例如读取和发送消息或管理频道。
- **Agent 聊天**让用户能通过 Teams 中的提及和会话事件与 Agent 对话。

[Mastra Connect](/docs/mastra-platform/connect) 会配置这两项功能并为你注册 Teams 机器人，因此你无需自行注册 Azure 应用。你也可以自行注册机器人并管理其凭据。

## Connect {/* #connect */}

开始之前，请先完成 [Connect 配置](/docs/mastra-platform/connect#get-started)，安装 `@mastra/connect` 并配置你的平台项目。

一个 `microsoft-teams` 连接即可同时提供 Agent 的 Tool 和聊天功能。请使用 Microsoft 工作或学校账户登录。部分请求的权限需要管理员同意，因此租户中的首次连接需要由 Microsoft Entra 管理员完成。

### Agent 聊天 {/* #agent-chat */}

连接 Agent 时，Mastra 会在 Teams 开发者门户中为其注册机器人，并加密存储机器人的凭据。设置 `MASTRA_ENCRYPTION_KEY` 即可使用专用密钥。如果未设置，`channels()` 会从平台访问令牌派生密钥并记录一条警告。此时如果轮换平台访问令牌，Mastra 将无法读取已存储的机器人凭据。请断开并重新连接该渠道，以创建新的凭据。

你的服务器需要一个可公开访问的 URL，用于接收 Teams Webhook 和 OAuth 回调。Mastra 平台会提供此 URL。如果在其他地方托管，请将 `MASTRA_SERVER_URL` 设置为服务器的公开 URL。本地开发时，请使用可公开访问的 HTTPS 隧道。

1. 如果尚未添加连接，请运行 `mastra connect add microsoft-teams` 并登录。

1. 将 [`channels()`](/reference/connect/channels) 传入 `Mastra` 构造函数。它会注册 Teams 渠道的 Provider 及其路由：

   ```typescript title="src/mastra/index.ts"
   import { Mastra } from '@mastra/core'
   import { channels } from '@mastra/connect'
   import { assistant } from './agents/assistant'

   export const mastra = new Mastra({
     agents: { assistant },
     channels: await channels({ providers: ['microsoft-teams'] }),
   })
   ```

   如需同时注册其他渠道，请将其 Provider ID 添加到 `providers`。

1. 启动你的 Mastra 应用。

1. 在 Studio 中，将 Teams 渠道连接到一个 Agent。Mastra 会为该 Agent 创建一条单租户机器人注册记录，并返回指向 [Teams 开发者门户](https://dev.teams.microsoft.com/bots)的链接。

1. 打开链接，在开发者门户中将机器人打包为 Teams 应用，然后将该应用添加到 Teams。

断开 Agent 的连接会删除机器人的注册记录及其 Entra 应用。

## 自行配置 {/* #self-managed-setup */}

使用 Chat SDK 的 Teams 适配器，并使用你自己的 Azure 机器人注册信息和凭据。

### 安装适配器 {/* #install-the-adapter */}

安装 Chat SDK 提供的 Teams 适配器：

```bash npm2yarn
npm install @chat-adapter/teams
```

### 配置 Agent {/* #agent-configuration */}

将 `createTeamsAdapter()` 添加到 Agent 的 `channels.adapters` 对象中：

```typescript title="src/mastra/agents/teams-agent.ts"
import { Agent } from '@mastra/core/agent'
import { createTeamsAdapter } from '@chat-adapter/teams'

export const teamsAgent = new Agent({
  id: 'teams-agent',
  name: 'Teams Agent',
  instructions: 'Answer questions and help with tasks in Microsoft Teams.',
  model: '__GATEWAY_OPENAI_MODEL__',
  channels: {
    adapters: {
      teams: createTeamsAdapter({
        appType: 'SingleTenant',
      }),
    },
  },
})
```

在 Mastra 实例中注册该 Agent：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { teamsAgent } from './agents/teams-agent'

export const mastra = new Mastra({
  agents: { teamsAgent },
})
```

### 配置适配器 {/* #adapter-setup */}

按照 [Chat SDK 的 Teams 适配器文档](https://chat-sdk.dev/adapters/official/teams)完成 Teams 专属配置，包括注册 Azure 机器人、使用 Teams CLI、设置身份验证选项以及配置所需权限。

适配器从环境变量中读取 Teams 凭据，例如：

```bash title=".env"
TEAMS_APP_ID=your-azure-bot-app-id
TEAMS_APP_PASSWORD=your-azure-bot-app-password
TEAMS_APP_TENANT_ID=your-azure-tenant-id
```

### Webhook URL {/* #webhook-url */}

Mastra 根据 Agent ID 和适配器的键生成 Teams Webhook 路由：

```text
/api/agents/teams-agent/channels/teams/webhook
```

使用 Mastra 服务器的公开 URL 作为基础 URL：

```text
https://your-app.example.com/api/agents/teams-agent/channels/teams/webhook
```

凡是 Teams 适配器文档要求填写机器人端点或 Webhook URL 的地方，都使用此 URL。本地开发时，通过隧道公开 Mastra 开发服务器，并将隧道的 URL 用作基础 URL。
