# 微软团队

通过两种方式将 Microsoft Teams 与 Mastra 结合使用：

* **AgentTool**让Agent在 Teams 中执行操作，例如读取和发送消息或管理频道。
* **Agent聊天**让人们通过 Teams 提及和对话事件与您的Agent交谈。

[马斯特拉连接](/docs/mastra-platform/connect)设置两者并为你注册 Teams 机器人，因此你不需要注册自己的 Azure 应用程序。您还可以注册机器人并自行管理其凭据。

## 连接 {/* #connect */}

在开始之前，请完成[Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect` and configure your platform project.

一`microsoft-teams` connection provides both agent tools and agent chat. Sign in with a Microsoft work or school account. Some requested permissions need admin consent, so the first connection in a tenant needs a Microsoft Entra administrator.

### Agent聊天 {/* #agent-chat */}

当您连接Agent时，Mastra 会在 Teams 开发人员门户中为其注册一个机器人。 Mastra 以加密方式存储机器人凭证。放`MASTRA_ENCRYPTION_KEY` to use a dedicated key. Without it, `channels()` derives a key from the platform access token and logs a warning. If you then rotate the platform access token, Mastra can't read the stored bot credentials. Disconnect and reconnect the channel to create new ones.

您的服务器需要团队 webhook 和 OAuth 回调的公共 URL。 Mastra 平台提供此 URL。当您在其他地方托管时，请设置`MASTRA_SERVER_URL` to your public server URL. For local development, use a public HTTPS tunnel.

1. 如果您尚未添加连接，请运行`mastra connect add microsoft-teams` and sign in.

2. 经过[`channels()`](/reference/connect/channels) to the `Mastra` constructor. It registers the Teams channel provider and its routes:

   ```typescript title="src/mastra/index.ts"
   import { Mastra } from '@mastra/core'
   import { channels } from '@mastra/connect'
   import { assistant } from './agents/assistant'

   export const mastra = new Mastra({
     agents: { assistant },
     channels: await channels({ providers: ['microsoft-teams'] }),
   })
   ```

   要也注册其他频道，请将其Provider ID 添加到`providers`.

3. 启动您的 Mastra 申请。

4. 在 Studio 中，将 Teams 通道连接到Agent。 Mastra 为Agent创建单租户机器人注册并返回指向[Teams Developer Portal](https://dev.teams.microsoft.com/bots).

5. 打开链接，将机器人打包到开发者门户中的 Teams 应用程序中，然后将该应用程序添加到 Teams。

断开Agent连接将删除机器人注册及其 Entra 应用程序。

## 自我管理设置 {/* #self-managed-setup */}

将聊天 SDK Teams 适配器与您自己的 Azure 机器人注册和凭据结合使用。

### 安装适配器 {/* #install-the-adapter */}

从聊天 SDK 安装 Teams 适配器：

```bash npm2yarn
npm install @chat-adapter/teams
```

### Agent配置 {/* #agent-configuration */}

添加`createTeamsAdapter()` to the agent's `channels.adapters` object:

```typescript title="src/mastra/agents/teams-agent.ts"
import { Agent } from '@mastra/core/agent'
import { createTeamsAdapter } from '@chat-adapter/teams'

export const teamsAgent = new Agent({
  id: 'teams-agent',
  name: 'Teams Agent',
  instructions: 'Answer questions and help with tasks in Microsoft Teams.',
  model: '__GATEWAY_OPENAI_MODEL__',
  channels: {
    adapters: {
      teams: createTeamsAdapter({
        appType: 'SingleTenant',
      }),
    },
  },
})
```

在 Mastra 实例上注册Agent：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { teamsAgent } from './agents/teams-agent'

export const mastra = new Mastra({
  agents: { teamsAgent },
})
```

### 适配器设置 {/* #adapter-setup */}

遵循[Chat SDK Teams adapter docs](https://chat-sdk.dev/adapters/official/teams) for Teams-specific setup, including Azure bot registration, Teams CLI usage, authentication options, and required permissions.

适配器从环境变量中读取 Teams 凭据，例如：

```bash title=".env"
TEAMS_APP_ID=your-azure-bot-app-id
TEAMS_APP_PASSWORD=your-azure-bot-app-password
TEAMS_APP_TENANT_ID=your-azure-tenant-id
```

### 网络钩子 URL {/* #webhook-url */}

Mastra 根据Agent ID 和适配器密钥生成 Teams Webhook 路由：

```text
/api/agents/teams-agent/channels/teams/webhook
```

使用您的公共 Mastra 服务器 URL 作为基本 URL：

```text
https://your-app.example.com/api/agents/teams-agent/channels/teams/webhook
```

在 Teams 适配器文档要求提供机器人终结点或 Webhook URL 的任何位置使用此 URL。对于本地开发，使用隧道公开 Mastra 开发服务器并使用隧道 URL 作为基本 URL。
