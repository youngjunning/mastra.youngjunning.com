# 微软PowerPoint

为Agent提供Tool来查找、创建、复制和移动演示文稿，阅读和更新其内容，并通过 Mastra Connect 在 Microsoft PowerPoint 中共享它们。每个Tool调用都会通过 Mastra 平台，该平台会添加连接的凭据。您的应用程序从不存储 Microsoft PowerPoint 凭据。

## 连接 {/* #connect */}

在开始之前，请完成[Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect`并配置您的平台项目。

### 连接账户 {/* #connect-an-account */}

从包含您的目录的目录运行此命令`.env` file:

```bash
mastra connect add microsoft-powerpoint
```

CLI 将引导您完成 Microsoft PowerPoint 的授权并等待连接激活。

### 向Agent添加Tool {/* #add-tools-to-an-agent */}

经过[`tools()`](/reference/connect/tools) to the agent and select the `microsoft-powerpoint` provider:

```typescript title="src/mastra/agents/microsoft-powerpoint-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const microsoftPowerpointAgent = new Agent({
  id: 'microsoft-powerpoint-agent',
  name: 'Microsoft PowerPoint agent',
  instructions:
    'You help people find, create, copy, and move presentations, read and update their content, and share them in Microsoft PowerPoint.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['microsoft-powerpoint'] }),
})
```

Agent获得 18 个 Microsoft PowerPoint Tool，其中包含以下密钥：`microsoft_powerpoint_copy_presentation`. See [Microsoft PowerPoint tools](/reference/connect/providers#microsoft-powerpoint) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
