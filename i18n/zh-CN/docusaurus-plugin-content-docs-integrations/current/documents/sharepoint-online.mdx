# 在线SharePoint

为Agent提供Tool来搜索网站和文件、管理列表、列表项和网站页面，以及通过 Mastra Connect 在 SharePoint Online 中共享驱动器项目。每个Tool调用都会通过 Mastra 平台，该平台会添加连接的凭据。您的应用程序从不存储 SharePoint Online 凭据。

## 连接 {/* #connect */}

在开始之前，请完成[Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect`并配置您的平台项目。

### 连接账户 {/* #connect-an-account */}

从包含您的目录的目录运行此命令`.env` file:

```bash
mastra connect add sharepoint-online
```

CLI 将引导您完成 SharePoint Online 的授权并等待连接处于活动状态。

### 向Agent添加Tool {/* #add-tools-to-an-agent */}

经过[`tools()`](/reference/connect/tools) to the agent and select the `sharepoint-online` provider:

```typescript title="src/mastra/agents/sharepoint-online-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const sharepointOnlineAgent = new Agent({
  id: 'sharepoint-online-agent',
  name: 'SharePoint Online agent',
  instructions:
    'You help people search sites and files, manage lists, list items, and site pages, and share drive items in SharePoint Online.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['sharepoint-online'] }),
})
```

Agent获得 53 个 SharePoint Online Tool，其中包含以下密钥：`sharepoint_online_add_content_type_to_list`. See [SharePoint Online tools](/reference/connect/providers#sharepoint-online) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
