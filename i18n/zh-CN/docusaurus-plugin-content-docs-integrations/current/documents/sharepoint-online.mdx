# SharePoint Online

通过 Mastra Connect 为 Agent 提供可在 SharePoint Online 中搜索站点和文件，管理列表、列表项和站点页面，以及共享驱动器项目的 Tool。每次 Tool 调用都会经过 Mastra 平台，由平台添加该连接的凭据；你的应用不会存储 SharePoint Online 凭据。

## 连接 {/* #connect */}

开始前，请先完成 [Connect 设置](/docs/mastra-platform/connect#get-started)，安装 `@mastra/connect` 并配置 Mastra 平台项目。

### 连接账户 {/* #connect-an-account */}

在包含 `.env` 文件的目录中运行以下命令：

```bash
mastra connect add sharepoint-online
```

CLI 会引导你完成 SharePoint Online 的授权，并等待连接激活。

### 向 Agent 添加 Tool {/* #add-tools-to-an-agent */}

将 [`tools()`](/reference/connect/tools) 传给 Agent，并选择 `sharepoint-online` Provider：

```typescript title="src/mastra/agents/sharepoint-online-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const sharepointOnlineAgent = new Agent({
  id: 'sharepoint-online-agent',
  name: 'SharePoint Online agent',
  instructions:
    'You help people search sites and files, manage lists, list items, and site pages, and share drive items in SharePoint Online.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['sharepoint-online'] }),
})
```

Agent 可使用 53 个 SharePoint Online Tool，Tool key 包括 `sharepoint_online_add_content_type_to_list`。完整列表请参阅 [SharePoint Online Tool](/reference/connect/providers#sharepoint-online)；如需限制可用 Tool，或要求每次调用在运行前获得批准，请参阅 [`tools()` 参数](/reference/connect/tools#parameters)。
