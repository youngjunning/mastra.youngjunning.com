# 谷歌表格

为Agent提供Tool来读取、追加、更新和清除单元格值，并通过 Mastra Connect 在 Google 表格中创建电子表格、行和工作表。每个Tool调用都会通过 Mastra 平台，该平台会添加连接的凭据。您的应用程序从不存储 Google 表格凭据。

## 连接 {/* #connect */}

在开始之前，请完成[Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect`并配置您的平台项目。

### 连接账户 {/* #connect-an-account */}

从包含您的目录的目录运行此命令`.env` file:

```bash
mastra connect add google-sheet
```

CLI 将引导您完成 Google 表格的授权并等待连接激活。

### 向Agent添加Tool {/* #add-tools-to-an-agent */}

经过[`tools()`](/reference/connect/tools) to the agent and select the `google-sheet` provider:

```typescript title="src/mastra/agents/google-sheet-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const googleSheetAgent = new Agent({
  id: 'google-sheet-agent',
  name: 'Google Sheets agent',
  instructions:
    'You help people read, append, update, and clear cell values, and create spreadsheets, rows, and worksheets in Google Sheets.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['google-sheet'] }),
})
```

该Agent获得 18 个 Google Sheets Tool，其中包含以下密钥：`google_sheet_append_values_to_spreadsheet`. See [Google Sheets tools](/reference/connect/providers#google-sheets) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
