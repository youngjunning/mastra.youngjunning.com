# Google Sheets

通过 Mastra Connect 为 Agent 提供可在 Google Sheets 中读取、追加、更新和清除单元格值，以及创建电子表格、行和工作表的 Tool。每次 Tool 调用都会经过 Mastra 平台，由平台添加该连接的凭据；你的应用不会存储 Google Sheets 凭据。

## 连接 {/* #connect */}

开始前，请先完成 [Connect 设置](/docs/mastra-platform/connect#get-started)，安装 `@mastra/connect` 并配置 Mastra 平台项目。

### 连接账户 {/* #connect-an-account */}

在包含 `.env` 文件的目录中运行以下命令：

```bash
mastra connect add google-sheet
```

CLI 会引导你完成 Google Sheets 的授权，并等待连接激活。

### 向 Agent 添加 Tool {/* #add-tools-to-an-agent */}

将 [`tools()`](/reference/connect/tools) 传给 Agent，并选择 `google-sheet` Provider：

```typescript title="src/mastra/agents/google-sheet-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const googleSheetAgent = new Agent({
  id: 'google-sheet-agent',
  name: 'Google Sheets agent',
  instructions:
    'You help people read, append, update, and clear cell values, and create spreadsheets, rows, and worksheets in Google Sheets.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['google-sheet'] }),
})
```

Agent 可使用 18 个 Google Sheets Tool，Tool key 包括 `google_sheet_append_values_to_spreadsheet`。完整列表请参阅 [Google Sheets Tool](/reference/connect/providers#google-sheets)；如需限制可用 Tool，或要求每次调用在运行前获得批准，请参阅 [`tools()` 参数](/reference/connect/tools#parameters)。
