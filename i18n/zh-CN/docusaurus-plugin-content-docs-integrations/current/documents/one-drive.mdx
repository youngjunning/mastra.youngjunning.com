# OneDrive

通过 Mastra Connect 为 Agent 提供可在 OneDrive 中搜索、上传、复制、移动和共享文件及文件夹，并管理权限和版本的 Tool。每次 Tool 调用都会经过 Mastra 平台，由平台添加该连接的凭据；你的应用不会存储 OneDrive 凭据。

## 连接 {/* #connect */}

开始前，请先完成 [Connect 设置](/docs/mastra-platform/connect#get-started)，安装 `@mastra/connect` 并配置 Mastra 平台项目。

### 连接账户 {/* #connect-an-account */}

在包含 `.env` 文件的目录中运行以下命令：

```bash
mastra connect add one-drive
```

CLI 会引导你完成 OneDrive 的授权，并等待连接激活。

### 向 Agent 添加 Tool {/* #add-tools-to-an-agent */}

将 [`tools()`](/reference/connect/tools) 传给 Agent，并选择 `one-drive` Provider：

```typescript title="src/mastra/agents/one-drive-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const oneDriveAgent = new Agent({
  id: 'one-drive-agent',
  name: 'OneDrive agent',
  instructions:
    'You help people search, upload, copy, move, and share files and folders, and manage permissions and versions in OneDrive.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['one-drive'] }),
})
```

Agent 可使用 20 个 OneDrive Tool，Tool key 包括 `one_drive_copy_item`。完整列表请参阅 [OneDrive Tool](/reference/connect/providers#onedrive)；如需限制可用 Tool，或要求每次调用在运行前获得批准，请参阅 [`tools()` 参数](/reference/connect/tools#parameters)。
