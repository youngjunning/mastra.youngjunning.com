# 云端硬盘

为Agent提供搜索、上传、复制、移动和共享文件和文件夹的Tool，并通过 Mastra Connect 管理 OneDrive 中的权限和版本。每个Tool调用都会通过 Mastra 平台，该平台会添加连接的凭据。您的应用程序从不存储 OneDrive 凭据。

## 连接 {/* #connect */}

在开始之前，请完成[Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect`并配置您的平台项目。

### 连接账户 {/* #connect-an-account */}

从包含您的目录的目录运行此命令`.env` file:

```bash
mastra connect add one-drive
```

CLI 将引导您完成 OneDrive 的授权并等待连接激活。

### 向Agent添加Tool {/* #add-tools-to-an-agent */}

经过[`tools()`](/reference/connect/tools) to the agent and select the `one-drive` provider:

```typescript title="src/mastra/agents/one-drive-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const oneDriveAgent = new Agent({
  id: 'one-drive-agent',
  name: 'OneDrive agent',
  instructions:
    'You help people search, upload, copy, move, and share files and folders, and manage permissions and versions in OneDrive.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['one-drive'] }),
})
```

Agent获得 20 个 OneDrive Tool，其中包含以下密钥`one_drive_copy_item`. See [OneDrive tools](/reference/connect/providers#onedrive) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
