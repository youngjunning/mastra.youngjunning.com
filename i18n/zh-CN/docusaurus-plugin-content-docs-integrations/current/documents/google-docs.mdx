# Google Docs

通过 Mastra Connect 为 Agent 提供可在 Google Docs 中创建文档、插入和替换文本，以及编辑表格、页眉、页脚和样式的 Tool。每次 Tool 调用都会经过 Mastra 平台，由平台添加该连接的凭据；你的应用不会存储 Google Docs 凭据。

## 连接 {/* #connect */}

开始前，请先完成 [Connect 设置](/docs/mastra-platform/connect#get-started)，安装 `@mastra/connect` 并配置 Mastra 平台项目。

### 连接账户 {/* #connect-an-account */}

在包含 `.env` 文件的目录中运行以下命令：

```bash
mastra connect add google-docs
```

CLI 会引导你完成 Google Docs 的授权，并等待连接激活。

### 向 Agent 添加 Tool {/* #add-tools-to-an-agent */}

将 [`tools()`](/reference/connect/tools) 传给 Agent，并选择 `google-docs` Provider：

```typescript title="src/mastra/agents/google-docs-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const googleDocsAgent = new Agent({
  id: 'google-docs-agent',
  name: 'Google Docs agent',
  instructions:
    'You help people create documents, insert and replace text, and edit tables, headers, footers, and styles in Google Docs.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['google-docs'] }),
})
```

Agent 可使用 37 个 Google Docs Tool，Tool key 包括 `google_docs_add_document_tab`。完整列表请参阅 [Google Docs Tool](/reference/connect/providers#google-docs)；如需限制可用 Tool，或要求每次调用在运行前获得批准，请参阅 [`tools()` 参数](/reference/connect/tools#parameters)。
