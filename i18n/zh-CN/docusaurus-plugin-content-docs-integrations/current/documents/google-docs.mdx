# 谷歌文档

为Agent提供Tool来通过 Mastra Connect 在 Google 文档中创建文档、插入和替换文本以及编辑表格、页眉、页脚和样式。每个Tool调用都会通过 Mastra 平台，该平台会添加连接的凭据。您的应用程序从不存储 Google 文档凭据。

## 连接 {/* #connect */}

在开始之前，请完成[Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect`并配置您的平台项目。

### 连接账户 {/* #connect-an-account */}

从包含您的目录的目录运行此命令`.env` file:

```bash
mastra connect add google-docs
```

CLI 将引导您完成 Google Docs 的授权并等待连接激活。

### 向Agent添加Tool {/* #add-tools-to-an-agent */}

经过[`tools()`](/reference/connect/tools) to the agent and select the `google-docs` provider:

```typescript title="src/mastra/agents/google-docs-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const googleDocsAgent = new Agent({
  id: 'google-docs-agent',
  name: 'Google Docs agent',
  instructions:
    'You help people create documents, insert and replace text, and edit tables, headers, footers, and styles in Google Docs.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['google-docs'] }),
})
```

该Agent获得 37 个 Google Docs Tool，其中包含以下密钥：`google_docs_add_document_tab`. See [Google Docs tools](/reference/connect/providers#google-docs) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
