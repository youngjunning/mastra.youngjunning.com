# 概念

为Agent提供Tool，用于通过 Mastra Connect 在 Notion 中搜索、读取、创建和更新页面、附加块以及查询数据库和数据源。每个Tool调用都会通过 Mastra 平台，该平台会添加连接的凭据。您的应用程序从不存储 Notion 凭据。

## 连接 {/* #connect */}

在开始之前，请完成[Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect`并配置您的平台项目。

### 连接账户 {/* #connect-an-account */}

从包含您的目录的目录运行此命令`.env` file:

```bash
mastra connect add notion
```

CLI 将引导您完成 Notion 的授权并等待连接激活。

### 向Agent添加Tool {/* #add-tools-to-an-agent */}

经过[`tools()`](/reference/connect/tools) to the agent and select the `notion` provider:

```typescript title="src/mastra/agents/notion-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const notionAgent = new Agent({
  id: 'notion-agent',
  name: 'Notion agent',
  instructions:
    'You help people search, read, create, and update pages, append blocks, and query databases and data sources in Notion.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['notion'] }),
})
```

Agent获得 44 个 Notion Tool，其中包含诸如`notion_append_block_children`. See [Notion tools](/reference/connect/providers#notion) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
