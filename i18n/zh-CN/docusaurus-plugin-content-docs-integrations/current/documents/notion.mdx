# Notion

通过 Mastra Connect 为 Agent 提供可在 Notion 中搜索、读取、创建和更新页面，追加内容块，以及查询数据库和数据源的 Tool。每次 Tool 调用都会经过 Mastra 平台，由平台添加该连接的凭据；你的应用不会存储 Notion 凭据。

## 连接 {/* #connect */}

开始前，请先完成 [Connect 设置](/docs/mastra-platform/connect#get-started)，安装 `@mastra/connect` 并配置 Mastra 平台项目。

### 连接账户 {/* #connect-an-account */}

在包含 `.env` 文件的目录中运行以下命令：

```bash
mastra connect add notion
```

CLI 会引导你完成 Notion 的授权，并等待连接激活。

### 向 Agent 添加 Tool {/* #add-tools-to-an-agent */}

将 [`tools()`](/reference/connect/tools) 传给 Agent，并选择 `notion` Provider：

```typescript title="src/mastra/agents/notion-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const notionAgent = new Agent({
  id: 'notion-agent',
  name: 'Notion agent',
  instructions:
    'You help people search, read, create, and update pages, append blocks, and query databases and data sources in Notion.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['notion'] }),
})
```

Agent 可使用 44 个 Notion Tool，Tool key 包括 `notion_append_block_children`。完整列表请参阅 [Notion Tool](/reference/connect/providers#notion)；如需限制可用 Tool，或要求每次调用在运行前获得批准，请参阅 [`tools()` 参数](/reference/connect/tools#parameters)。
