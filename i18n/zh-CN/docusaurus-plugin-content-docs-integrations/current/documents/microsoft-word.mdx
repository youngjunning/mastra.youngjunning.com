# 微软Word

为Agent提供Tool来查找、创建、复制和移动 Word 文档，阅读和更新其内容，并通过 Mastra Connect 在 Microsoft Word 中共享它们。每个Tool调用都会通过 Mastra 平台，该平台会添加连接的凭据。您的应用程序从不存储 Microsoft Word 凭据。

## 连接 {/* #connect */}

在开始之前，请完成[Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect`并配置您的平台项目。

### 连接账户 {/* #connect-an-account */}

从包含您的目录的目录运行此命令`.env` file:

```bash
mastra connect add microsoft-word
```

CLI 将引导您完成 Microsoft Word 的授权并等待连接激活。

### 向Agent添加Tool {/* #add-tools-to-an-agent */}

经过[`tools()`](/reference/connect/tools) to the agent and select the `microsoft-word` provider:

```typescript title="src/mastra/agents/microsoft-word-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const microsoftWordAgent = new Agent({
  id: 'microsoft-word-agent',
  name: 'Microsoft Word agent',
  instructions:
    'You help people find, create, copy, and move Word documents, read and update their content, and share them in Microsoft Word.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['microsoft-word'] }),
})
```

Agent获得 18 个 Microsoft Word Tool，其中包含以下密钥：`microsoft_word_copy_word_document`. See [Microsoft Word tools](/reference/connect/providers#microsoft-word) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
