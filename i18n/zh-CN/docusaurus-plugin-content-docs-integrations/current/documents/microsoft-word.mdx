# Microsoft Word

通过 Mastra Connect 为 Agent 提供可在 Microsoft Word 中查找、创建、复制和移动 Word 文档，读取和更新其内容，以及共享文档的 Tool。每次 Tool 调用都会经过 Mastra 平台，由平台添加该连接的凭据；你的应用不会存储 Microsoft Word 凭据。

## 连接 {/* #connect */}

开始前，请先完成 [Connect 设置](/docs/mastra-platform/connect#get-started)，安装 `@mastra/connect` 并配置 Mastra 平台项目。

### 连接账户 {/* #connect-an-account */}

在包含 `.env` 文件的目录中运行以下命令：

```bash
mastra connect add microsoft-word
```

CLI 会引导你完成 Microsoft Word 的授权，并等待连接激活。

### 向 Agent 添加 Tool {/* #add-tools-to-an-agent */}

将 [`tools()`](/reference/connect/tools) 传给 Agent，并选择 `microsoft-word` Provider：

```typescript title="src/mastra/agents/microsoft-word-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const microsoftWordAgent = new Agent({
  id: 'microsoft-word-agent',
  name: 'Microsoft Word agent',
  instructions:
    'You help people find, create, copy, and move Word documents, read and update their content, and share them in Microsoft Word.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['microsoft-word'] }),
})
```

Agent 可使用 18 个 Microsoft Word Tool，Tool key 包括 `microsoft_word_copy_word_document`。完整列表请参阅 [Microsoft Word Tool](/reference/connect/providers#microsoft-word)；如需限制可用 Tool，或要求每次调用在运行前获得批准，请参阅 [`tools()` 参数](/reference/connect/tools#parameters)。
