# Microsoft Excel

通过 Mastra Connect 为 Agent 提供可在 Microsoft Excel 中查找和创建工作簿、读取和更新区域，以及管理工作表、表格和图表的 Tool。每次 Tool 调用都会经过 Mastra 平台，由平台添加该连接的凭据；你的应用不会存储 Microsoft Excel 凭据。

## 连接 {/* #connect */}

开始前，请先完成 [Connect 设置](/docs/mastra-platform/connect#get-started)，安装 `@mastra/connect` 并配置 Mastra 平台项目。

:::note

工作表、区域、表格、图表和命名项等工作簿操作需要使用工作或学校账户。个人 Microsoft 账户可以查找、创建、列出、获取和删除工作簿文件，但 Microsoft Graph 会拒绝对个人 OneDrive 执行工作簿操作。

:::

### 连接账户 {/* #connect-an-account */}

在包含 `.env` 文件的目录中运行以下命令：

```bash
mastra connect add microsoft-excel
```

CLI 会引导你完成 Microsoft Excel 的授权，并等待连接激活。

### 向 Agent 添加 Tool {/* #add-tools-to-an-agent */}

将 [`tools()`](/reference/connect/tools) 传给 Agent，并选择 `microsoft-excel` Provider：

```typescript title="src/mastra/agents/microsoft-excel-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const microsoftExcelAgent = new Agent({
  id: 'microsoft-excel-agent',
  name: 'Microsoft Excel agent',
  instructions:
    'You help people find and create workbooks, read and update ranges, and manage worksheets, tables, and charts in Microsoft Excel.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['microsoft-excel'] }),
})
```

Agent 可使用 27 个 Microsoft Excel Tool，Tool key 包括 `microsoft_excel_add_chart`。完整列表请参阅 [Microsoft Excel Tool](/reference/connect/providers#microsoft-excel)；如需限制可用 Tool，或要求每次调用在运行前获得批准，请参阅 [`tools()` 参数](/reference/connect/tools#parameters)。
