# 微软Excel

为Agent提供Tool来查找和创建工作簿、读取和更新范围以及通过 Mastra Connect 管理 Microsoft Excel 中的工作表、表格和图表。每个Tool调用都会通过 Mastra 平台，该平台会添加连接的凭据。您的应用程序从不存储 Microsoft Excel 凭据。

## 连接 {/* #connect */}

在开始之前，请完成[Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect`并配置您的平台项目。

：：：笔记

工作簿操作（例如工作表、范围、表格、图表和命名项目）需要工作或学校帐户。个人 Microsoft 帐户可以查找、创建、列出、获取和删除工作簿文件，但 Microsoft Graph 拒绝个人 OneDrive 上的工作簿操作。

:::

### 连接账户 {/* #connect-an-account */}

从包含您的目录的目录运行此命令`.env` file:

```bash
mastra connect add microsoft-excel
```

CLI 将引导您完成 Microsoft Excel 的授权并等待连接激活。

### 向Agent添加Tool {/* #add-tools-to-an-agent */}

经过[`tools()`](/reference/connect/tools) to the agent and select the `microsoft-excel` provider:

```typescript title="src/mastra/agents/microsoft-excel-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const microsoftExcelAgent = new Agent({
  id: 'microsoft-excel-agent',
  name: 'Microsoft Excel agent',
  instructions:
    'You help people find and create workbooks, read and update ranges, and manage worksheets, tables, and charts in Microsoft Excel.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['microsoft-excel'] }),
})
```

Agent获得 27 个 Microsoft Excel Tool，其中包含以下密钥：`microsoft_excel_add_chart`. See [Microsoft Excel tools](/reference/connect/providers#microsoft-excel) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
