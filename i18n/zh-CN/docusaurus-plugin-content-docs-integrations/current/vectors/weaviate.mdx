# Weaviate 向量存储

`WeaviateVector` 类使用开源向量数据库 [Weaviate](https://weaviate.io/) 提供向量搜索。创建集合时会设置 `vectorizer: none`，因此嵌入向量由 Mastra 提供。Mastra 还负责管理 ID、距离度量和元数据过滤。

此向量存储还实现了 `listIndexes()`、`describeIndex()`、`deleteIndex()`、`updateVector()`、`deleteVector()` 和 `deleteVectors()`。

## 基本用法 {/* #basic-usage */}

```ts filename="index.ts" showLineNumbers copy
import { WeaviateVector } from '@mastra/weaviate'

const store = new WeaviateVector({ id: 'my-store' })

await store.createIndex({ indexName: 'my_index', dimension: 1536, metric: 'cosine' })

await store.upsert({
  indexName: 'my_index',
  vectors: [[0.1, 0.2 /* ... */]],
  metadata: [{ text: 'sample', category: 'docs' }],
})

const results = await store.query({
  indexName: 'my_index',
  queryVector: [0.1, 0.2 /* ... */],
  topK: 5,
  filter: { category: 'docs' },
})
```

## 连接到 Weaviate Cloud {/* #connecting-to-weaviate-cloud */}

```ts showLineNumbers copy
const store = new WeaviateVector({
  id: 'my-store',
  httpHost: 'my-cluster.weaviate.network',
  httpPort: 443,
  httpSecure: true,
  grpcHost: 'grpc-my-cluster.weaviate.network',
  grpcPort: 443,
  grpcSecure: true,
  apiKey: process.env.WEAVIATE_API_KEY,
})
```

## 元数据过滤 {/* #metadata-filtering */}

过滤条件采用 MongoDB 风格的语法，Mastra 会将其转换为 Weaviate 原生过滤 API 所需的格式：

* 比较运算符：`$eq`、`$ne`、`$gt`、`$gte`、`$lt`、`$lte`
* 数组运算符：`$in`、`$nin`、`$all`
* 元素运算符：`$exists`
* 逻辑运算符：`$and`、`$or`、`$not`

```ts showLineNumbers copy
const results = await store.query({
  indexName: 'my_index',
  queryVector: [0.1, 0.2 /* ... */],
  filter: {
    $and: [{ category: { $in: ['docs', 'guides'] } }, { views: { $gt: 100 } }],
  },
})
```

### 注意事项和限制 {/* #notes-and-limitations */}

* Weaviate 无法区分显式存储的 `null` 与缺失的字段，因此不支持写入后原样读回空值。
* 不支持 `$regex`、`$size`、`$elemMatch`、`$nor` 和 `$contains`。
* Weaviate 会将集合名称的首字母转为大写。原始索引名称保留在集合描述中，`listIndexes()` 和 `describeIndex()` 都会返回该名称。
