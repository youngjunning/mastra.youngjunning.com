# 凸向量存储

这`ConvexVector`类提供向量存储和相似性搜索使用[凸面](https://convex.dev)。它将嵌入存储在 Convex 内，并在 Mastra 适配器中执行余弦相似性搜索。

:::警告\[开发规模搜索]

`ConvexVector`通过 Mastra 存储处理程序读取匹配的向量并在 JavaScript 中过滤它们。然后，它计算余弦相似度并对结果进行排序，然后返回最匹配的结果。将其用于本地开发、测试和小型数据集。

对于凸上的生产向量搜索，请使用`ConvexNativeVector`. It uses the Convex native `vectorSearch` API, which requires a deployed Convex vector index and a Convex action.

:::

### 本机凸向量搜索 {/* #native-convex-vector-search */}

使用`ConvexNativeVector` for production vector workloads. It stores vectors in a dedicated Convex table and queries a schema-defined Convex vector index.

在`convex/schema.ts`, define a dedicated table for each Mastra vector index:

```typescript title="convex/schema.ts"
import { defineSchema } from 'convex/server'
import { defineMastraNativeVectorTable } from '@mastra/convex/schema'

export default defineSchema({
  docs_vectors: defineMastraNativeVectorTable({
    dimensions: 1536,
  }),
})
```

在`convex/mastra/nativeVector.ts`, export the native vector handlers:

```typescript title="convex/mastra/nativeVector.ts"
import {
  mastraNativeVectorAction,
  mastraNativeVectorMutation,
  mastraNativeVectorQuery,
} from '@mastra/convex/server'

export const query = mastraNativeVectorAction
export const read = mastraNativeVectorQuery
export const write = mastraNativeVectorMutation
```

在您的 Mastra 应用程序中，配置`ConvexNativeVector` with the deployed table and vector index:

```typescript title="src/mastra/index.ts"
import { ConvexNativeVector } from '@mastra/convex'

const vectorStore = new ConvexNativeVector({
  id: 'convex-native-vectors',
  deploymentUrl: process.env.CONVEX_URL!,
  adminAuthToken: process.env.CONVEX_ADMIN_KEY!,
  indexes: {
    docs: {
      tableName: 'docs_vectors',
      vectorIndexName: 'by_embedding',
      dimension: 1536,
    },
  },
})

const results = await vectorStore.query({
  indexName: 'docs',
  queryVector: embedding,
  topK: 10,
})
```

对于本机过滤器支持，请在凸架构中声明过滤器字段。写入向量时，本机向量处理程序将匹配的元数据字段复制到顶级文档字段。

```typescript title="convex/schema.ts"
import { defineSchema, defineTable } from 'convex/server'
import { v } from 'convex/values'

export default defineSchema({
  docs_vectors: defineTable({
    id: v.string(),
    embedding: v.array(v.float64()),
    metadata: v.optional(v.any()),
    tenantId: v.string(),
  })
    .index('by_record_id', ['id'])
    .vectorIndex('by_embedding', {
      vectorField: 'embedding',
      dimensions: 1536,
      filterFields: ['tenantId'],
    }),
})
```

```typescript title="src/mastra/index.ts"
const vectorStore = new ConvexNativeVector({
  id: 'convex-native-vectors',
  deploymentUrl: process.env.CONVEX_URL!,
  adminAuthToken: process.env.CONVEX_ADMIN_KEY!,
  indexes: {
    docs: {
      tableName: 'docs_vectors',
      dimension: 1536,
      filterFields: ['tenantId'],
    },
  },
})

await vectorStore.upsert({
  indexName: 'docs',
  ids: ['chunk-1'],
  vectors: [embedding],
  metadata: [{ tenantId: 'acme', text: 'Account setup guide' }],
})

const results = await vectorStore.query({
  indexName: 'docs',
  queryVector: embedding,
  filter: { tenantId: 'acme' },
})
```

`ConvexNativeVector`支持凸本机矢量滤波器形状：一个等式场，或`$or` of equality fields. It doesn't support metadata-only queries, filter-based updates, or filter-based deletes. Use vector IDs for updates and deletes.

## 元数据过滤 {/* #metadata-filtering */}

`ConvexVector`支持使用运算符进行元数据过滤。从 Convex 加载矢量后，适配器将应用这些过滤器。

```typescript
// Simple equality
const results = await vectorStore.query({
  indexName: 'my_vectors',
  queryVector: embedding,
  filter: { category: 'documents' },
})

// Comparison operators
const results = await vectorStore.query({
  indexName: 'my_vectors',
  queryVector: embedding,
  filter: {
    price: { $gt: 100 },
    status: { $in: ['active', 'pending'] },
  },
})

// Logical operators
const results = await vectorStore.query({
  indexName: 'my_vectors',
  queryVector: embedding,
  filter: {
    $and: [{ category: 'electronics' }, { price: { $lte: 500 } }],
  },
})
```

### 支持的过滤器运算符 {/* #supported-filter-operators */}

|操作员|描述 |
| - | - |
|`$ne` | Not equal to |
| `$gt` | Greater than |
| `$gte` | Greater than or equal |
| `$lt` | Less than |
| `$lte` | Less than or equal |
| `$in` | In array |
| `$nin` | Not in array |
| `$and` | Logical AND |
| `$or` | Logical OR |

## 建筑学 {/* #architecture */}

`ConvexVector`将每个索引存储在其自己的表中，名为`mastra_vector_{indexName}`. Each record has the following structure:

* `id`：唯一的向量标识符
* `embedding`：矢量数据（浮点数数组）
* `metadata`：可选的 JSON 元数据

矢量相似性搜索是通过 Mastra 适配器中的余弦相似性进行的。这保持了设置的灵活性，但它不适用于大型生产矢量集合。

`ConvexNativeVector`将每个 Mastra 向量索引存储在专用的凸表中。它的查询调用一个凸操作，该操作使用`ctx.vectorSearch`, then load the matched documents through a Convex query. This follows the Convex native vector search model:

* 向量索引声明于`convex/schema.ts`.
* 矢量搜索从凸操作运行。
* `topK`必须介于`1` and `256`.
* 过滤器必须针对凸向量索引中列出的字段`filterFields`.
* 每个 Mastra 向量索引使用一个专用表以避免交叉索引结果。

当您需要在运行时创建运行时定义的索引、仅元数据查询、复杂的过滤器运算符、基于过滤器的批量更新或删除，或者结果限制高于 Convex 的本机矢量搜索上限时，请使用外部矢量数据库。
