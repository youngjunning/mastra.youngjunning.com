# Convex 向量存储

`ConvexVector` 类使用 [Convex](https://convex.dev) 提供向量存储和相似性搜索。它将嵌入向量存储在 Convex 中，并由 Mastra 适配器执行余弦相似度搜索。

:::warning[开发规模的搜索]

`ConvexVector` 通过 Mastra 存储处理程序读取匹配的向量，并在 JavaScript 中进行过滤。随后，它计算余弦相似度、排序，并返回最匹配的结果。适合用于本地开发、测试和小型数据集。

在 Convex 上进行生产环境向量搜索时，请使用 `ConvexNativeVector`。它调用 Convex 原生 `vectorSearch` API，因此需要已部署的 Convex 向量索引和 Convex action。

:::

## 安装 {/* #installation */}

```bash npm2yarn
npm install @mastra/convex@latest
```

### Convex 原生向量搜索 {/* #native-convex-vector-search */}

生产环境中的向量工作负载请使用 `ConvexNativeVector`。它将向量存储在专用的 Convex 表中，并查询在 schema 中定义的 Convex 向量索引。

在 `convex/schema.ts` 中，为每个 Mastra 向量索引定义一张专用表：

```typescript title="convex/schema.ts"
import { defineSchema } from 'convex/server'
import { defineMastraNativeVectorTable } from '@mastra/convex/schema'

export default defineSchema({
  docs_vectors: defineMastraNativeVectorTable({
    dimensions: 1536,
  }),
})
```

在 `convex/mastra/nativeVector.ts` 中，导出原生向量处理程序：

```typescript title="convex/mastra/nativeVector.ts"
import {
  mastraNativeVectorAction,
  mastraNativeVectorMutation,
  mastraNativeVectorQuery,
} from '@mastra/convex/server'

export const query = mastraNativeVectorAction
export const read = mastraNativeVectorQuery
export const write = mastraNativeVectorMutation
```

在 Mastra 应用中，使用已部署的表和向量索引配置 `ConvexNativeVector`：

```typescript title="src/mastra/index.ts"
import { ConvexNativeVector } from '@mastra/convex'

const vectorStore = new ConvexNativeVector({
  id: 'convex-native-vectors',
  deploymentUrl: process.env.CONVEX_URL!,
  adminAuthToken: process.env.CONVEX_ADMIN_KEY!,
  indexes: {
    docs: {
      tableName: 'docs_vectors',
      vectorIndexName: 'by_embedding',
      dimension: 1536,
    },
  },
})

const results = await vectorStore.query({
  indexName: 'docs',
  queryVector: embedding,
  topK: 10,
})
```

要使用原生过滤功能，请在 Convex schema 中声明过滤字段。写入向量时，原生向量处理程序会将相应的元数据字段复制为文档的顶层字段。

```typescript title="convex/schema.ts"
import { defineSchema, defineTable } from 'convex/server'
import { v } from 'convex/values'

export default defineSchema({
  docs_vectors: defineTable({
    id: v.string(),
    embedding: v.array(v.float64()),
    metadata: v.optional(v.any()),
    tenantId: v.string(),
  })
    .index('by_record_id', ['id'])
    .vectorIndex('by_embedding', {
      vectorField: 'embedding',
      dimensions: 1536,
      filterFields: ['tenantId'],
    }),
})
```

```typescript title="src/mastra/index.ts"
const vectorStore = new ConvexNativeVector({
  id: 'convex-native-vectors',
  deploymentUrl: process.env.CONVEX_URL!,
  adminAuthToken: process.env.CONVEX_ADMIN_KEY!,
  indexes: {
    docs: {
      tableName: 'docs_vectors',
      dimension: 1536,
      filterFields: ['tenantId'],
    },
  },
})

await vectorStore.upsert({
  indexName: 'docs',
  ids: ['chunk-1'],
  vectors: [embedding],
  metadata: [{ tenantId: 'acme', text: 'Account setup guide' }],
})

const results = await vectorStore.query({
  indexName: 'docs',
  queryVector: embedding,
  filter: { tenantId: 'acme' },
})
```

`ConvexNativeVector` 支持 Convex 原生向量过滤形式：单个字段的相等条件，或通过 `$or` 组合的多个相等条件。它不支持仅按元数据查询、按过滤条件更新或按过滤条件删除。更新和删除时请使用向量 ID。

## 元数据过滤 {/* #metadata-filtering */}

`ConvexVector` 支持使用运算符按元数据过滤。适配器从 Convex 加载向量后，会应用这些过滤条件。

```typescript
// Simple equality
const results = await vectorStore.query({
  indexName: 'my_vectors',
  queryVector: embedding,
  filter: { category: 'documents' },
})

// Comparison operators
const results = await vectorStore.query({
  indexName: 'my_vectors',
  queryVector: embedding,
  filter: {
    price: { $gt: 100 },
    status: { $in: ['active', 'pending'] },
  },
})

// Logical operators
const results = await vectorStore.query({
  indexName: 'my_vectors',
  queryVector: embedding,
  filter: {
    $and: [{ category: 'electronics' }, { price: { $lte: 500 } }],
  },
})
```

### 支持的过滤运算符 {/* #supported-filter-operators */}

| 运算符 | 说明 |
| - | - |
| `$ne` | 不等于 |
| `$gt` | 大于 |
| `$gte` | 大于或等于 |
| `$lt` | 小于 |
| `$lte` | 小于或等于 |
| `$in` | 在数组中 |
| `$nin` | 不在数组中 |
| `$and` | 逻辑与 |
| `$or` | 逻辑或 |

## 架构 {/* #architecture */}

`ConvexVector` 将每个索引存储在一张独立的表中，表名为 `mastra_vector_{indexName}`。每条记录包含以下字段：

- `id`：唯一的向量标识符
- `embedding`：向量数据（浮点数数组）
- `metadata`：可选的 JSON 元数据

Mastra 适配器使用余弦相似度执行向量相似性搜索。这使设置方式保持灵活，但不适合大规模的生产环境向量集合。

`ConvexNativeVector` 将每个 Mastra 向量索引存储在专用的 Convex 表中。查询时，它先调用使用 `ctx.vectorSearch` 的 Convex action，再通过 Convex query 加载匹配的文档。这遵循 Convex 原生向量搜索模型：

- 在 `convex/schema.ts` 中声明向量索引。
- 从 Convex action 运行向量搜索。
- `topK` 必须介于 `1` 和 `256` 之间。
- 过滤条件只能针对 Convex 向量索引的 `filterFields` 中列出的字段。
- 每个 Mastra 向量索引使用一张专用表，避免返回其他索引的结果。

如果需要在运行时创建动态定义的索引、仅按元数据查询、使用复杂的过滤运算符、按过滤条件批量更新或删除，或者返回超过 Convex 原生向量搜索上限的结果，请使用外部向量数据库。
