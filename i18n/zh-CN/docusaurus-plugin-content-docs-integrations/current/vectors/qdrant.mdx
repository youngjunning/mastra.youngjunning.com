# Qdrant矢量商店

QdrantVector 类使用以下方式提供矢量搜索[Qdrant](https://qdrant.tech/)，一个向量相似度搜索引擎。
它提供了一种生产就绪的服务，具有方便的 API，用于存储、搜索和管理向量，并具有额外的有效负载和扩展的过滤支持。

#### 创建一个`named vectors` Collection {/* #creating-a-named-vectors-collection */}

```typescript
// Create a collection with multiple named vector spaces
await store.createIndex({
  indexName: 'multi_modal',
  dimension: 768, // fallback
  namedVectors: {
    text: { size: 768, distance: 'cosine' },
    image: { size: 512, distance: 'euclidean' },
  },
})
```

#### `named vectors` {/* #named-vectors */}

Qdrant 支持[multiple vectors per collection](https://qdrant.tech/documentation/concepts/vectors/#named-vectors), with a name assigned to each vector field. Use the `using` parameter to select the vector field to query:

```typescript
const results = await store.query({
  indexName: 'my_index',
  queryVector: embedding,
  topK: 10,
  using: 'title_embedding', // Query against a specific named vector
})
```

### `createPayloadIndex()` {/* #createpayloadindex */}

在集合字段上创建有效负载（元数据）索引以实现高效过滤。这是**required** for Qdrant Cloud and any Qdrant instance with `strict_mode_config = true`.

<PropertiesTable
  content={[

  type: 'string',
  description: 'Name of the collection to create the payload index on',

{
  name: 'fieldName',
  type: 'string',

},
{
  name: 'fieldSchema',
  type: "'keyword' | 'integer' | 'float' | 'geo' | 'text' | 'bool' | 'datetime' | 'uuid'",
  description: 'The schema type for the payload field',
},
{
  name: 'wait',
  type: 'boolean',
  isOptional: true,
  defaultValue: 'true',
  description: 'Whether to wait for the operation to complete',
},

/>

```typescript
// Create a keyword index for filtering by source
await store.createPayloadIndex({
  indexName: 'my_index',
  fieldName: 'source',
  fieldSchema: 'keyword',
})

const results = await store.query({
  indexName: 'my_index',
  queryVector: queryVector,
  filter: { source: 'document-a' },
})
```

## 错误处理 {/* #error-handling */}

店里扔`MastraError` instances from `@mastra/core/error`:

```typescript
import { MastraError } from '@mastra/core/error'

try {
  await store.query({
    indexName: 'index_name',
    queryVector: queryVector,
  })
} catch (error) {
  if (error instanceof MastraError) {
    console.log(error.id) // 'MASTRA_VECTOR_QDRANT_QUERY_FAILED'
    console.log(error.domain) // 'STORAGE'
    console.log(error.category) // 'USER' | 'THIRD_PARTY'
    console.log(error.details) // Additional error context
  }
}
```
