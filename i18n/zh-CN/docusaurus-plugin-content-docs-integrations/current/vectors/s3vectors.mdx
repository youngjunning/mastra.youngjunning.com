# Amazon S3 Vectors 存储

`S3Vectors` 类通过 [Amazon S3 Vectors（预览版）](https://docs.aws.amazon.com/AmazonS3/latest/userguide/s3-vectors.html)提供向量搜索。它将向量存入**向量存储桶**，在**向量索引**中执行相似性搜索，并支持基于 JSON 的元数据过滤器。

:::warning

Amazon S3 Vectors 仍处于预览阶段。预览功能可能随时更改或移除，恕不另行通知，且不受 AWS 服务等级协议（SLA）保障。其行为、限制和区域可用性也可能随时变化。为适应 AWS 的变更，此库可能引入不兼容的更改。

:::

## 使用示例 {/* #usage-example */}

```typescript
import { S3Vectors } from '@mastra/s3vectors'

const store = new S3Vectors({
  id: 's3-vectors',
  vectorBucketName: process.env.S3_VECTORS_BUCKET_NAME!, // e.g. "my-vector-bucket"
  clientConfig: {
    region: process.env.AWS_REGION!, // credentials use the default AWS provider chain
  },
  // Optional: mark large/long-text fields as non-filterable at index creation time
  nonFilterableMetadataKeys: ['content'],
})

// Create an index (names are normalized: "_" → "-" and lowercased)
await store.createIndex({
  indexName: 'my_index',
  dimension: 1536,
  metric: 'cosine', // "euclidean" also supported; "dotproduct" is NOT supported
})

// Upsert vectors (ids auto-generated if omitted). Date values in metadata are serialized to epoch ms.
const ids = await store.upsert({
  indexName: 'my_index',
  vectors: [
    [0.1, 0.2 /* … */],
    [0.3, 0.4 /* … */],
  ],
  metadata: [
    {
      text: 'doc1',
      genre: 'documentary',
      year: 2023,
      createdAt: new Date('2024-01-01'),
    },
    { text: 'doc2', genre: 'comedy', year: 2021 },
  ],
})

// Query with metadata filters (implicit AND is canonicalized)
const results = await store.query({
  indexName: 'my-index',
  queryVector: [0.1, 0.2 /* … */],
  topK: 10, // Service-side limits may apply (commonly 30)
  filter: { genre: { $in: ['documentary', 'comedy'] }, year: { $gte: 2020 } },
  includeVector: false, // set true to include raw vectors (may trigger a secondary fetch)
})

// Clean up resources (closes the underlying HTTP handler)
await store.disconnect()
```

## 过滤语法 {/* #filter-syntax */}

S3 Vectors 仅支持部分运算符和值类型。Mastra 的过滤器转换器会：

* **将隐式 AND 规范化**：`{a:1,b:2}` → `{ $and: [{a:1},{b:2}] }`。
* **将 Date 值转换为 Unix 纪元毫秒数**，用于数值比较或作为数组元素。
* **禁止在相等性比较中使用 Date**，包括 `field: value` 和 `$eq/$ne`。相等性比较的值必须是 **string | number | boolean**。
* **拒绝**以 null 或 undefined 进行相等性比较。也不支持**数组相等性比较**；请使用 `$in` 或 `$nin`。
* 顶层逻辑运算符仅允许 **`$and` / `$or`**。
* 逻辑运算符中必须包含**字段条件**，不能直接放入运算符。

**支持的运算符：**

* **逻辑：** `$and`、`$or`（非空数组）
* **基本比较：** `$eq`、`$ne`（string | number | boolean）
* **数值比较：** `$gt`、`$gte`、`$lt`、`$lte`（number，或转换为 Unix 纪元毫秒数的 `Date`）
* **数组匹配：** `$in`、`$nin`（由 string | number | boolean 组成的非空数组；`Date` 会转换为 Unix 纪元毫秒数）
* **字段存在性：** `$exists`（boolean）

**不支持并会拒绝的运算符：** `$not`、`$nor`、`$regex`、`$all`、`$elemMatch`、`$size`、`$text` 等。

**示例：**

```typescript oxfmt:false
// Implicit AND
{ genre: { $in: ["documentary", "comedy"] }, year: { $gte: 2020 } }

// Explicit logicals and ranges
{
  $and: [
    { price: { $gte: 100, $lte: 1000 } },
    { $or: [{ stock: { $gt: 0 } }, { preorder: true }] }
  ]
}

// Dates in range (converted to epoch ms)
{ timestamp: { $gt: new Date("2024-01-01T00:00:00Z") } }
```

:::note

如果在创建索引时设置了 `nonFilterableMetadataKeys`，这些键仍会存储，但**不能**用于过滤。

:::

## 错误处理 {/* #error-handling */}

此向量存储会抛出来自 `@mastra/core/error` 的 `MastraError` 实例：

```typescript
import { MastraError } from '@mastra/core/error'

try {
  await store.query({
    indexName: 'index-name',
    queryVector: queryVector,
  })
} catch (error) {
  if (error instanceof MastraError) {
    console.log(error.id) // 'MASTRA_VECTOR_S3VECTORS_QUERY_FAILED'
    console.log(error.domain) // 'STORAGE'
    console.log(error.category) // 'USER' | 'THIRD_PARTY'
    console.log(error.details) // Additional error context
  }
}
```

## 环境变量 {/* #environment-variables */}

在应用中配置此向量存储时，通常需要以下环境变量：

* `S3_VECTORS_BUCKET_NAME`：S3 **向量存储桶**名称，用于设置 `vectorBucketName`。
* `AWS_REGION`：S3 Vectors 存储桶所在的 AWS 区域。
* **AWS 凭证**：通过 AWS SDK 的标准凭证提供链获取，例如 `AWS_ACCESS_KEY_ID`、`AWS_SECRET_ACCESS_KEY` 或 `AWS_PROFILE`。

## 最佳实践 {/* #best-practices */}

* 选择与嵌入模型匹配的距离度量（`cosine` 或 `euclidean`）。不支持 `dotproduct`。
* 让**可过滤的**元数据保持精简、结构化，值使用 string、number 或 boolean。将 `content` 等长文本设为**不可过滤**。
* 对嵌套元数据使用**点分路径**；对复杂条件明确使用 `$and` 或 `$or`。
* 避免在频繁执行的路径中调用 `describeIndex()`。`count` 通过分页调用 `ListVectors` 计算，复杂度为 **O(n)**。
* 只有需要原始向量时才使用 `includeVector: true`。
