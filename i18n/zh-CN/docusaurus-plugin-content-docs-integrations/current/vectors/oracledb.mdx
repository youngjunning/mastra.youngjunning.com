# OracleDB 向量存储

`OracleVector` 将嵌入向量存储在 Oracle Database 的 `VECTOR` 列中，并通过 Mastra 的向量接口提供访问。每个 Mastra 逻辑向量索引都通过注册表映射到一张 Oracle 向量表；元数据则以 Oracle JSON 格式存储，供结构化筛选使用。

## 安装 {/* #installation */}

```bash npm2yarn
npm install @mastra/oracledb@latest
```

## 用法 {/* #usage */}

```ts
import { OracleVector } from '@mastra/oracledb'

const vector = new OracleVector({
  id: 'oracle-vector',
  user: process.env.ORACLE_DATABASE_USER,
  password: process.env.ORACLE_DATABASE_PASSWORD,
  connectString: process.env.ORACLE_DATABASE_CONNECT_STRING,
})

await vector.createIndex({
  indexName: 'memory_messages',
  dimension: 1536,
  metric: 'cosine',
})

await vector.upsert({
  indexName: 'memory_messages',
  vectors: [embedding],
  metadata: [{ resource_id: 'user-1', thread_id: 'thread-1' }],
})

const results = await vector.query({
  indexName: 'memory_messages',
  queryVector,
  topK: 5,
  filter: { resource_id: 'user-1' },
})
```

默认情况下，`OracleVector` 使用精确搜索，不创建近似向量索引。当数据集规模和延迟要求需要近似搜索时，可配置 IVF 或 HNSW。

## 构造函数示例 {/* #constructor-examples */}

### 与 OracleStore 共用连接池 {/* #shared-pool-with-oraclestore */}

```ts
import { OracleStore, OracleVector } from '@mastra/oracledb'

const storage = new OracleStore({ id: 'oracle-storage', user, password, connectString })

const vector = new OracleVector({
  id: 'oracle-vector',
  poolManager: storage.getPoolManager(),
})
```

对于 Autonomous Database 和 mTLS 连接，在同一个构造函数中传入 `walletLocation`、`walletPassword` 和 `configDir`。

#### 索引配置 {/* #index-configuration */}

```ts
await vector.createIndex({
  indexName: 'support_articles',
  dimension: 1536,
  metric: 'cosine',
  indexConfig: {
    type: 'ivf',
    accuracy: 95,
    ivf: {
      neighborPartitions: 32,
    },
  },
})
```

默认配置为 `indexConfig: { type: 'none' }`，使用精确搜索，无需调整近似索引参数。仅当数据量和延迟要求适合近似搜索时，才使用 IVF 或 HNSW。HNSW 通过 `indexConfig: { type: 'hnsw', hnsw: { neighbors, efConstruction } }` 配置，并需要 Oracle Vector Pool 内存。对于本地或自行管理的数据库，可通过 `configureVectorMemory()` 分配这部分内存。

### `listIndexes()` {/* #listindexes */}

返回 Oracle 向量注册表中记录的 Mastra 逻辑索引名称。

### `describeIndex()` {/* #describeindex */}

返回 Oracle 索引元数据，包括物理表名、维度、向量数量、距离度量、索引类型、向量格式和配置的准确率。

### `deleteIndex()` {/* #deleteindex */}

删除 Oracle 向量表，并移除对应逻辑索引的注册表记录。

### `updateVector()` {/* #updatevector */}

按 ID 或元数据筛选条件更新向量。必须提供 `id` 或 `filter` 中的一个，且不能同时提供。`update` 对象可以包含 `vector`、`metadata`，也可以同时包含两者。

```ts
await vector.updateVector({
  indexName: 'support_articles',
  id: 'doc-1',
  update: { metadata: { status: 'reviewed' } },
})
```

### `deleteVector()` {/* #deletevector */}

按 ID 删除单个向量。

### `deleteVectors()` {/* #deletevectors */}

按 ID 列表或元数据筛选条件删除多个向量。必须提供 `ids` 或 `filter` 中的一个，且不能同时提供。

### `buildIndex()` {/* #buildindex */}

为现有逻辑索引构建 Oracle 向量索引。如果最终确定的索引类型为 `none`，此方法不会执行任何操作。

### `rebuildIndex()` {/* #rebuildindex */}

删除并重新创建现有逻辑索引的 Oracle 向量索引，通常用于调整近似索引参数之后。

### 索引诊断 {/* #index-diagnostics */}

使用 `getIndexStatus({ indexName })` 查看 Oracle 系统目录中的索引状态；使用 `indexAccuracyQuery({ indexName, queryVector, topK, targetAccuracy })` 对近似索引运行 `DBMS_VECTOR.INDEX_ACCURACY_QUERY`。

### `configureVectorMemory()` {/* #configurevectormemory */}

分配 HNSW 索引所需的 Oracle Vector Pool 内存。此方法会执行 `ALTER SYSTEM SET VECTOR_MEMORY_SIZE`，因此需要具有相应权限的连接，例如 `SYSDBA` 或 `SYSTEM`。

### `disconnect()` {/* #disconnect */}

如果连接池管理器由 `OracleVector` 创建，此方法会关闭 Oracle 连接池。如果传入了 `pool` 或 `poolManager`，则需要自行管理其生命周期。

## 元数据过滤器 {/* #metadata-filters */}

`OracleVector` 支持 Mastra 的标准元数据筛选语法。筛选条件会转换为使用绑定值的 Oracle JSON 谓词：

* 标量比较使用 `JSON_VALUE`
* 数组、字段存在性和元素匹配检查使用 `JSON_EXISTS`
* 正则表达式筛选使用 `REGEXP_LIKE`
* 字符串包含筛选使用不区分大小写的 `LIKE`

```ts
const results = await vector.query({
  indexName: 'memory_messages',
  queryVector,
  topK: 5,
  filter: {
    resource_id: 'user-1',
    tags: { $contains: 'support' },
    score: { $gte: 0.8 },
    $or: [{ source: 'docs' }, { source: 'tickets' }],
  },
})
```

元数据以 Oracle 原生 JSON 格式存储，因此也可以使用 DBeaver、SQL Developer 等标准 Oracle JDBC 工具直接读取数据行。

如果需要 Agent 为 `createVectorQueryTool()` 生成兼容 Oracle 的元数据筛选条件，请使用 `ORACLEDB_PROMPT`：

```ts
import { Agent } from '@mastra/core/agent'
import { createVectorQueryTool } from '@mastra/rag'
import { fastembed } from '@mastra/fastembed'
import { ORACLEDB_PROMPT } from '@mastra/oracledb'

const vectorQueryTool = createVectorQueryTool({
  vectorStoreName: 'oracle',
  indexName: 'support_articles',
  model: fastembed,
  enableFilter: true,
})

export const ragAgent = new Agent({
  id: 'oracle-rag-agent',
  name: 'Oracle RAG Agent',
  model: '__GATEWAY_OPENAI_MODEL__',
  instructions: `
Use the retrieval tool when you need source context.
Available metadata fields: resource_id, thread_id, source, category, tags.
${ORACLEDB_PROMPT}
`,
  tools: { vectorQueryTool },
})
```

interface QueryResult {

## 使用示例 {/* #usage-example */}

```ts title="src/mastra/agents/oracle-agent.ts"
import { Agent } from '@mastra/core/agent'
import { Memory } from '@mastra/memory'
import { fastembed } from '@mastra/fastembed'
import { OracleStore, OracleVector } from '@mastra/oracledb'

const storage = new OracleStore({
  id: 'oracle-storage',
  user: process.env.ORACLE_DATABASE_USER,
  password: process.env.ORACLE_DATABASE_PASSWORD,
  connectString: process.env.ORACLE_DATABASE_CONNECT_STRING,
})

const vector = new OracleVector({
  id: 'oracle-vector',
  poolManager: storage.getPoolManager(),
})

export const oracleAgent = new Agent({
  id: 'oracle-agent',
  name: 'Oracle Agent',
  instructions: 'You are an assistant with OracleDB-backed memory and semantic recall.',
  model: '__GATEWAY_OPENAI_MODEL__',
  memory: new Memory({
    storage,
    vector,
    embedder: fastembed,
    options: {
      semanticRecall: { topK: 3, messageRange: 2 },
    },
  }),
})
```
