# Cloudflare 矢量商店

CloudflareVector 类提供矢量搜索，使用[Cloudflare Vectorize](https://developers.cloudflare.com/vectorize/)，与 Cloudflare 边缘网络集成的矢量数据库服务。

## 错误处理 {/* #error-handling */}

店里扔`MastraError` instances from `@mastra/core/error`:

```typescript
import { MastraError } from '@mastra/core/error'

try {
  await store.query({
    indexName: 'index_name',
    queryVector: queryVector,
  })
} catch (error) {
  if (error instanceof MastraError) {
    console.log(error.id) // 'MASTRA_VECTOR_VECTORIZE_QUERY_FAILED'
    console.log(error.domain) // 'STORAGE'
    console.log(error.category) // 'USER' | 'THIRD_PARTY'
    console.log(error.details) // Additional error context
  }
}
```

## 环境变量 {/* #environment-variables */}

所需的环境变量：

* `CLOUDFLARE_ACCOUNT_ID`：您的 Cloudflare 帐户 ID
* `CLOUDFLARE_API_TOKEN`：具有 Vectorize 权限的 Cloudflare API 令牌
