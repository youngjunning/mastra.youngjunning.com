# Cloudflare 向量存储

CloudflareVector 类通过 [Cloudflare Vectorize](https://developers.cloudflare.com/vectorize/) 提供向量搜索功能。Cloudflare Vectorize 是一项集成到 Cloudflare 边缘网络的向量数据库服务。

## 响应类型 {/* #response-types */}

查询结果采用以下格式：

```typescript
interface QueryResult {
  id: string
  score: number
  metadata?: Record<string, any>
  vector?: number[]
}
```

## 错误处理 {/* #error-handling */}

此向量存储会抛出 `@mastra/core/error` 中定义的 `MastraError` 实例：

```typescript
import { MastraError } from '@mastra/core/error'

try {
  await store.query({
    indexName: 'index_name',
    queryVector: queryVector,
  })
} catch (error) {
  if (error instanceof MastraError) {
    console.log(error.id) // 'MASTRA_VECTOR_VECTORIZE_QUERY_FAILED'
    console.log(error.domain) // 'STORAGE'
    console.log(error.category) // 'USER' | 'THIRD_PARTY'
    console.log(error.details) // Additional error context
  }
}
```

## 环境变量 {/* #environment-variables */}

必需的环境变量：

* `CLOUDFLARE_ACCOUNT_ID`：你的 Cloudflare 账号 ID
* `CLOUDFLARE_API_TOKEN`：具有 Vectorize 权限的 Cloudflare API 令牌
