# Chroma 向量存储

ChromaVector 类使用开源嵌入数据库 [Chroma](https://docs.trychroma.com/docs/overview/getting-started) 提供向量搜索，支持元数据过滤和混合搜索。

## 运行 Chroma 服务器 {/* #running-a-chroma-server */}

如果使用 Chroma Cloud，请向 `ChromaVector` 构造函数提供 API 密钥、租户名称和数据库名称。

安装 `@mastra/chroma` 包后，即可使用 [Chroma CLI](https://docs.trychroma.com/docs/cli/db)。它可以通过 `chroma db connect [DB-NAME] --env-file` 为您设置这些环境变量。

如需自行设置单节点 Chroma 服务器，可以选择以下方式：

* 使用 Chroma CLI 在本地运行：`chroma run`。更多配置选项请参阅 [Chroma 文档](https://docs.trychroma.com/docs/cli/run)。
* 使用 Chroma 官方镜像在 [Docker](https://docs.trychroma.com/guides/deploy/docker) 中运行。
* 在您选择的服务商平台上部署自己的 Chroma 服务器。Chroma 提供 [AWS](https://docs.trychroma.com/guides/deploy/aws)、[Azure](https://docs.trychroma.com/guides/deploy/azure) 和 [GCP](https://docs.trychroma.com/guides/deploy/gcp) 的示例模板。

### `deleteVectors()` {/* #deletevectors */}

通过 ID 或元数据过滤条件删除多个向量。此方法支持批量删除和按来源管理向量。必须提供 `ids` 或 `filter`，但不能同时提供。

<PropertiesTable
  content={[
{
  name: 'indexName',
  type: 'string',
  description: '包含待删除向量的索引名称',
},
{
  name: 'ids',
  type: 'string[]',
  isOptional: true,
  description: '待删除向量的 ID 数组（不能与 filter 同时使用）',
},
{
  name: 'filter',
  type: 'Record<string, any>',
  isOptional: true,
  description: '用于定位待删除向量的元数据过滤条件（不能与 ids 同时使用）',
},
]}
/>

例子：

```typescript
// Delete all chunks from a document
await vectorStore.deleteVectors({
  indexName: 'docs',
  filter: { source_id: 'manual.pdf' },
})

// Delete multiple vectors by ID
await vectorStore.deleteVectors({
  indexName: 'docs',
  ids: ['vec_1', 'vec_2', 'vec_3'],
})

// Delete old temporary documents
await vectorStore.deleteVectors({
  indexName: 'docs',
  filter: {
    $and: [{ bucket: 'temp' }, { indexed_at: { $lt: '2025-01-01' } }],
  },
})
```

## 错误处理 {/* #error-handling */}

此存储会抛出来自 `@mastra/core/error` 的 `MastraError` 实例：

```typescript
import { MastraError } from '@mastra/core/error'

try {
  await store.query({
    indexName: 'index_name',
    queryVector: queryVector,
  })
} catch (error) {
  if (error instanceof MastraError) {
    console.log(error.id) // 'MASTRA_VECTOR_CHROMA_QUERY_FAILED'
    console.log(error.domain) // 'MASTRA_VECTOR'
    console.log(error.category) // 'USER' | 'THIRD_PARTY'
    console.log(error.details) // Additional error context
  }
}
```
