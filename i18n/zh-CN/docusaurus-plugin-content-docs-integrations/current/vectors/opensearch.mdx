# OpenSearch 向量存储

OpenSearchVector 类使用开源搜索与分析引擎 [OpenSearch](https://opensearch.org/) 提供向量搜索。它通过 OpenSearch 的 k-NN 功能查找相似向量。

## 构造函数选项 {/* #constructor-options */}

构造函数支持 [OpenSearch ClientOptions](https://opensearch.org/docs/latest/clients/javascript/index/) 中的所有选项，另外还必须提供 `id` 字段。
