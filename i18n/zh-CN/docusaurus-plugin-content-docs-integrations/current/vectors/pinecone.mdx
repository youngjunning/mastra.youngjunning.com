# Pinecone 向量存储

`PineconeVector` 类提供访问 [Pinecone](https://www.pinecone.io/) 向量数据库的接口。
它支持实时向量搜索，以及混合搜索、元数据过滤和命名空间管理等功能。


## 错误处理 {/* #error-handling */}

此向量存储会抛出来自 `@mastra/core/error` 的 `MastraError` 实例：

```typescript
import { MastraError } from '@mastra/core/error'

try {
  await store.query({
    indexName: 'index_name',
    queryVector: queryVector,
  })
} catch (error) {
  if (error instanceof MastraError) {
    console.log(error.id) // 'MASTRA_VECTOR_PINECONE_QUERY_FAILED'
    console.log(error.domain) // 'STORAGE'
    console.log(error.category) // 'USER' | 'THIRD_PARTY'
    console.log(error.details) // Additional error context
  }
}
```

## 混合搜索 {/* #hybrid-search */}

Pinecone 通过结合密集向量和稀疏向量支持混合搜索。使用方法如下：

1. 创建索引时设置 `metric: 'dotproduct'`
2. 执行 upsert 时，通过 `sparseVectors` 参数提供稀疏向量
3. 查询时，通过 `sparseVector` 参数提供稀疏向量
