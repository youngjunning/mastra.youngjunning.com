# Couchbase 矢量商店

这`CouchbaseVector`类提供向量搜索使用[沙发底座矢量搜索](https://docs.couchbase.com/server/current/vector-search/vector-search.html)。它可以在您的 Couchbase 集合中进行高效的相似性搜索。

## 要求 {/* #requirements */}

* **Couchbase 服务器 7.6.4+**&#x6216;兼容的 Capella 集群
* **搜索服务已启用**在您的 Couchbase 部署上

## 安装 {/* #installation */}

```bash npm2yarn
npm install @mastra/couchbase@latest
```

## 使用示例 {/* #usage-example */}

```typescript
import { CouchbaseVector } from '@mastra/couchbase'

const store = new CouchbaseVector({
  id: 'couchbase-vector',
  connectionString: process.env.COUCHBASE_CONNECTION_STRING,
  username: process.env.COUCHBASE_USERNAME,
  password: process.env.COUCHBASE_PASSWORD,
  bucketName: process.env.COUCHBASE_BUCKET,
  scopeName: process.env.COUCHBASE_SCOPE,
  collectionName: process.env.COUCHBASE_COLLECTION,
})
```

## 错误处理 {/* #error-handling */}

商店抛出可以捕获的类型错误：

```typescript
try {
  await store.query({
    indexName: 'my_index',
    queryVector: queryVector,
  })
} catch (error) {
  // Handle specific error cases
  if (error.message.includes('Invalid index name')) {
    console.error(
      'Index name must start with a letter or underscore and contain only valid characters.',
    )
  } else if (error.message.includes('Index not found')) {
    console.error('The specified index does not exist')
  } else {
    console.error('Vector store error:', error.message)
  }
}
```

## 笔记 {/* #notes */}

* **索引删除警告：**&#x5220;除搜索索引不会删除关联的 Couchbase 集合中的向量/文档。除非明确删除，否则数据将保留。
* **所需权限：**&#x43;ouchbase 用户必须有权连接、读取/写入目标集合中的文档（`kv` role), and manage Search Indexes (`search_admin` role on the relevant bucket/scope).
* **指数定义详细信息和文档结构：**&#x8FD9;`createIndex` method builds a Search Index definition for documents in `scopeName.collectionName`. It indexes the `embedding` field as a vector and the `content` field as text. Each document stores its vector in `embedding`, with metadata kept in `metadata`. A `text` property within `metadata` is also copied to the top-level `content` field for text search.
* **复制和持久性：**&#x8003;虑使用 Couchbase 的内置复制和持久性功能来实现数据持久性。定期监控索引统计信息以确保高效搜索。

## 局限性 {/* #limitations */}

* 索引创建延迟可能会影响创建后的立即查询。
* 仅在以下时间后才在摄取时强制执行向量维度`createIndex()` creates a new index on the same `CouchbaseVector` instance. Calling `createIndex()` for an index that already exists doesn't turn on the ingest check. When the check is on, `upsert()` and `updateVector()` throw on a dimension mismatch. `query()` always checks the query vector against the index dimension.
* `deleteVectors()`仅支持通过ID删除。不支持元数据过滤器删除。
* 向量插入和索引更新最终是一致的。写入后不能立即保证强一致性。
