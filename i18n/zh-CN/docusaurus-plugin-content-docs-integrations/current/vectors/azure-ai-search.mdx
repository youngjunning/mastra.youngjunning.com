# Azure AI 搜索矢量存储

这`AzureAISearchVector`类提供向量搜索使用[Azure 人工智能搜索](https://learn.microsoft.com/azure/search/vector-search-overview)，微软的云搜索服务，具有原生矢量搜索支持。它在现有的 Azure AI 搜索资源之上提供元数据过滤、混合（矢量 + 文本）搜索和语义排名。

## Azure 特定的查询方法 {/* #azure-specific-query-methods */}

超出标准`query()` method, `AzureAISearchVector` exposes Azure AI Search-specific capabilities:

* **`advancedQuery()`**：直接公开 Azure AI 搜索向量查询参数，包括穷举搜索、查询加权、过采样、多向量搜索的附加向量查询、预/后过滤模式和基于文本的查询类型（`semantic`, `hybrid`).
* **`semanticQuery()`**：方便的包装`advancedQuery()` for semantic ranking with a configured semantic configuration.
* **`hybridQuery()`**：将矢量搜索与全文查询相结合的便捷包装器。
* **`multiVectorQuery()`**：方便的包装器，用于一次查询多个加权向量。
* **`exactQuery()`**：方便包装`advancedQuery()` with exhaustive (non-approximate) search enabled.

这些方法是附加的：`query()` remains the Memory-compatible entry point used by Mastra's semantic recall.
