# Azure AI Search 向量存储

`AzureAISearchVector` 类通过 [Azure AI Search](https://learn.microsoft.com/azure/search/vector-search-overview) 提供向量搜索。Azure AI Search 是 Microsoft 的云搜索服务，原生支持向量搜索。通过此类，你可以在现有的 Azure AI Search 资源上使用元数据过滤、向量与文本混合搜索及语义排序。

## Azure AI Search 专用查询方法 {/* #azure-specific-query-methods */}

除标准的 `query()` 方法外，`AzureAISearchVector` 还提供以下方法来调用 Azure AI Search 的专用查询功能。

* **`advancedQuery()`** 支持直接指定 Azure AI Search 的向量查询参数，包括穷举搜索、查询权重、过采样、多向量搜索所需的额外向量查询、前置或后置过滤模式，以及基于文本的查询类型（`semantic`、`hybrid`）。
* **`semanticQuery()`** 封装了 `advancedQuery()`，便于使用已设置的语义配置进行语义排序。
* **`hybridQuery()`** 封装了向量搜索和全文查询，可在一次查询中同时使用两者。
* **`multiVectorQuery()`** 提供便捷接口，可一次使用多个带权重的向量进行查询。
* **`exactQuery()`** 封装了 `advancedQuery()`，并启用穷举搜索以获得精确结果。

这些方法是对标准查询的补充。Mastra 的语义召回仍通过与 Memory 兼容的 `query()` 入口执行查询。

## 响应类型 {/* #response-types */}

查询结果采用以下格式。

```typescript
interface QueryResult {
  id: string
  score: number
  metadata: Record<string, any>
  document?: string // Matched document content
  vector?: number[] // Only included if includeVector is true
}
```
