# DuckDB向量存储

DuckDB 存储实现提供了一个嵌入式高性能矢量搜索解决方案，使用[DuckDB](https://duckdb.org/)，一个进程内分析数据库。它使用 VSS 扩展通过 HNSW 索引进行向量相似性搜索，提供不需要外部服务器的轻量级且高效的向量数据库。

它是的一部分`@mastra/duckdb` package and offers efficient vector similarity search with metadata filtering.

## 安装 {/* #installation */}

```bash npm2yarn
npm install @mastra/duckdb@latest
```

## 用法 {/* #usage */}

```typescript oxfmt:false
import { DuckDBVector } from "@mastra/duckdb";

// Create a new vector store instance
const store = new DuckDBVector({
  id: "duckdb-vector",
  path: ":memory:", // or './vectors.duckdb' for file persistence
});

// Create an index
await store.createIndex({
  indexName: "myCollection",
  dimension: 1536,
  metric: "cosine",
});

// Add vectors with metadata
const vectors = [[0.1, 0.2, ...], [0.3, 0.4, ...]];
const metadata = [
  { text: "first document", category: "A" },
  { text: "second document", category: "B" },
];
await store.upsert({
  indexName: "myCollection",
  vectors,
  metadata,
});

// Query similar vectors
const queryVector = [0.1, 0.2, ...];
const results = await store.query({
  indexName: "myCollection",
  queryVector,
  topK: 10,
  filter: { category: "A" },
});

// Clean up
await store.close();
```

## 过滤运算符 {/* #filter-operators */}

DuckDB向量存储支持类似MongoDB的过滤器运算符：

|类别 |运营商|
| - | - |
|比较|`$eq`, `$ne`, `$gt`, `$gte`, `$lt`, `$lte` |
| Logical | `$and`, `$or`, `$not`, `$nor` |
| Array | `$in`, `$nin`, `$all`|
|元素|`$exists`|
|文字|`$contains` |

### 过滤器示例 {/* #filter-examples */}

```typescript oxfmt:false
// Allegato operators
const results = await store.query({
  indexName: "docs",
  queryVector: [...],
  filter: {
    $and: [
      { category: "electronics" },
      { price: { $gte: 100, $lte: 500 } },
    ],
  },
});

// Nested field access
const results = await store.query({
  indexName: "docs",
  queryVector: [...],
  filter: { "user.profile.tier": "premium" },
});
```

## 距离度量 {/* #distance-metrics */}

|公制|描述 |分数解读 |最适合 |
| - | - | - | - |
|`cosine` | Cosine similarity | -1 to 1, computed as `1 - cosine distance` (1 = most similar) | Text embeddings, normalized vectors |
| `euclidean` | L2 distance | 0-1, computed as `1 / (1 + distance)` (1 = most similar) | Image embeddings, spatial data |
| `dotproduct` | Inner product | Higher = more similar | When vector magnitude matters |

## 错误处理 {/* #error-handling */}

商店针对不同的故障情况抛出特定的错误：

```typescript
try {
  await store.query({
    indexName: 'my-collection',
    queryVector: queryVector,
  })
} catch (error) {
  if (error.message.includes('not found')) {
    console.error('The specified index does not exist')
  } else if (error.message.includes('Invalid identifier')) {
    console.error('Index name contains invalid characters')
  } else {
    console.error('Vector store error:', error.message)
  }
}
```

常见错误情况包括：

* 索引名称格式无效
* 未找到索引/表
* 查询向量和索引之间的维度不匹配
* 删除/更新操作中的空过滤器或 ids 数组
* 违反相互排他性（同时提供`id` and `filter`)

## 使用案例 {/* #use-cases */}

### 嵌入式语义搜索 {/* #embedded-semantic-search */}

通过完全在进程中运行的语义搜索构建具有离线功能的 AI 应用程序：

```typescript
const store = new DuckDBVector({
  id: 'offline-search',
  path: './search.duckdb',
})
```

### 本地 RAG 管道 {/* #local-rag-pipelines */}

在本地处理敏感文档，无需将数据发送到云矢量数据库：

```typescript
const store = new DuckDBVector({
  id: 'private-rag',
  path: './confidential.duckdb',
  dimensions: 1536,
})
```

### 开发与测试 {/* #development-and-testing */}

以零基础设施快速构建矢量搜索功能原型：

```typescript
const store = new DuckDBVector({
  id: 'dev-store',
  path: ':memory:', // Fast in-memory for tests
})
```
