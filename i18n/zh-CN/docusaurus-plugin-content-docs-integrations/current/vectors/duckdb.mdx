# DuckDB 向量存储

DuckDB 存储实现基于进程内分析数据库 [DuckDB](https://duckdb.org/)，提供高性能嵌入式向量搜索。它使用 VSS 扩展和 HNSW 索引进行向量相似度搜索，无需外部服务器即可使用轻量、高效的向量数据库。

它属于 `@mastra/duckdb` 包，支持高效的向量相似度搜索和元数据过滤。

## 安装 {/* #installation */}

```bash npm2yarn
npm install @mastra/duckdb@latest
```

## 用法 {/* #usage */}

```typescript oxfmt:false
import { DuckDBVector } from "@mastra/duckdb";

// Create a new vector store instance
const store = new DuckDBVector({
  id: "duckdb-vector",
  path: ":memory:", // or './vectors.duckdb' for file persistence
});

// Create an index
await store.createIndex({
  indexName: "myCollection",
  dimension: 1536,
  metric: "cosine",
});

// Add vectors with metadata
const vectors = [[0.1, 0.2, ...], [0.3, 0.4, ...]];
const metadata = [
  { text: "first document", category: "A" },
  { text: "second document", category: "B" },
];
await store.upsert({
  indexName: "myCollection",
  vectors,
  metadata,
});

// Query similar vectors
const queryVector = [0.1, 0.2, ...];
const results = await store.query({
  indexName: "myCollection",
  queryVector,
  topK: 10,
  filter: { category: "A" },
});

// Clean up
await store.close();
```

## 过滤运算符 {/* #filter-operators */}

DuckDB 向量存储支持类似 MongoDB 的过滤运算符：

| 类别 | 运算符 |
| - | - |
| 比较 | `$eq`, `$ne`, `$gt`, `$gte`, `$lt`, `$lte` |
| 逻辑 | `$and`, `$or`, `$not`, `$nor` |
| 数组 | `$in`, `$nin`, `$all` |
| 元素 | `$exists` |
| 文本 | `$contains` |

### 过滤器示例 {/* #filter-examples */}

```typescript oxfmt:false
// Allegato operators
const results = await store.query({
  indexName: "docs",
  queryVector: [...],
  filter: {
    $and: [
      { category: "electronics" },
      { price: { $gte: 100, $lte: 500 } },
    ],
  },
});

// Nested field access
const results = await store.query({
  indexName: "docs",
  queryVector: [...],
  filter: { "user.profile.tier": "premium" },
});
```

## 距离度量 {/* #distance-metrics */}

| 度量 | 说明 | 分数解读 | 适用场景 |
| - | - | - | - |
| `cosine` | 余弦相似度 | -1 到 1，按 `1 - cosine distance` 计算（1 表示最相似） | 文本嵌入、归一化向量 |
| `euclidean` | L2 距离 | 0 到 1，按 `1 / (1 + distance)` 计算（1 表示最相似） | 图像嵌入、空间数据 |
| `dotproduct` | 内积 | 越高表示越相似 | 向量的模长有影响时 |

## 错误处理 {/* #error-handling */}

商店针对不同的故障情况抛出特定的错误：

```typescript
try {
  await store.query({
    indexName: 'my-collection',
    queryVector: queryVector,
  })
} catch (error) {
  if (error.message.includes('not found')) {
    console.error('The specified index does not exist')
  } else if (error.message.includes('Invalid identifier')) {
    console.error('Index name contains invalid characters')
  } else {
    console.error('Vector store error:', error.message)
  }
}
```

常见错误情况包括：

* 索引名称格式无效
* 未找到索引/表
* 查询向量和索引之间的维度不匹配
* 删除或更新操作中使用空过滤条件或空 `ids` 数组
* 同时提供互斥的 `id` 和 `filter`

## 使用案例 {/* #use-cases */}

### 嵌入式语义搜索 {/* #embedded-semantic-search */}

通过完全在进程中运行的语义搜索构建具有离线功能的 AI 应用程序：

```typescript
const store = new DuckDBVector({
  id: 'offline-search',
  path: './search.duckdb',
})
```

### 本地 RAG 管道 {/* #local-rag-pipelines */}

在本地处理敏感文档，无需将数据发送到云端向量数据库：

```typescript
const store = new DuckDBVector({
  id: 'private-rag',
  path: './confidential.duckdb',
  dimensions: 1536,
})
```

### 开发与测试 {/* #development-and-testing */}

无需额外基础设施，即可快速构建向量搜索功能原型：

```typescript
const store = new DuckDBVector({
  id: 'dev-store',
  path: ':memory:', // Fast in-memory for tests
})
```
