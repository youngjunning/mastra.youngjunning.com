# E2B桌面

在隔离的环境中运行完整的 Linux 桌面环境[E2B](https://e2b.dev)具有屏幕截图、鼠标和键盘控制的云Sandbox。`E2BDesktopSandbox`延伸[`E2BSandbox`](/integrations/sandboxes/e2b)，因此基础提供程序支持的所有内容（命令执行、后台进程、文件上传、暂停/恢复重新连接）都适用于同一台桌面计算机。接口详情请参见[Workspace沙盒界面](/reference/workspace/sandbox).

## 安装 {/* #installation */}

```bash npm2yarn
npm install @mastra/e2b-desktop
```

使用以下命令设置您的 E2B API 密钥`E2B_API_KEY` environment variable or the `apiKey` option.

## 用法 {/* #usage */}

添加一个`E2BDesktopSandbox` to a workspace and assign it to an agent. Because the sandbox supports the [computer capability](/docs/sandbox/computer), the workspace registers the `mastra_workspace_computer_*` tools alongside the shell and process tools:

```typescript
import { Agent } from '@mastra/core/agent'
import { Workspace } from '@mastra/core/workspace'
import { E2BDesktopSandbox } from '@mastra/e2b-desktop'

const workspace = new Workspace({
  sandbox: new E2BDesktopSandbox({
    resolution: [1280, 720],
  }),
})

const agent = new Agent({
  id: 'desktop-agent',
  name: 'Desktop Agent',
  instructions: 'You can control a Linux desktop and run shell commands.',
  model: '__GATEWAY_ANTHROPIC_MODEL_SONNET__',
  workspace,
})

const response = await agent.generate(
  'Take a screenshot, then create /tmp/hello.txt with the text "hello" and cat it.',
)
```

Agent可以将桌面操作（单击、键入、屏幕截图）与 shell 命令混合。两个表面在同一台机器上运行。

### 直接桌面控制 {/* #direct-desktop-control */}

使用`computer` capability programmatically without an agent:

```typescript
const sandbox = new E2BDesktopSandbox()
await sandbox.start()

await sandbox.computer.leftClick(100, 200)
await sandbox.computer.type('hello')
const { data } = await sandbox.computer.screenshot() // PNG bytes

const size = await sandbox.computer.getScreenSize()
console.log(size) // { width: 1024, height: 768 }
```

### 实时桌面视图 {/* #live-desktop-view */}

`streamUrl()`在Sandbox内启动经过身份验证的 noVNC 流并返回查看器 URL。在浏览器中打开它以观察Agent的工作情况：

```typescript
const url = await sandbox.computer.streamUrl()
// https://6080-<sandbox-id>.e2b.app/vnc.html?...&password=<auth-key>
```

### 桌面 SDK 逃生舱口 {/* #desktop-sdk-escape-hatch */}

仅限桌面的 API，例如`launch`, `open`, window helpers, and custom stream control are available on the underlying [`@e2b/desktop`](https://github.com/e2b-dev/desktop) sandbox:

```typescript
await sandbox.desktop.launch('xfce4-terminal')
await sandbox.desktop.open('https://mastra.ai')
```

## 云存储挂载 {/* #cloud-storage-mounting */}

默认`desktop` template has no FUSE tooling, so [cloud storage mounting](/integrations/sandboxes/e2b#mounting-cloud-storage) requires a custom desktop template with `s3fs` or `gcsfuse` installed. Pass it with the `template` option.
