# E2B Desktop

E2B Desktop 在隔离的 [E2B](https://e2b.dev) 云 Sandbox 中运行完整的 Linux 桌面环境，支持截图以及鼠标和键盘控制。`E2BDesktopSandbox` 继承自 [`E2BSandbox`](/integrations/sandboxes/e2b)，因此基础 Provider 支持的所有功能（命令执行、后台进程、文件上传、暂停后恢复并重新连接）都可在同一台桌面计算机上使用。有关接口详情，请参阅 [WorkspaceSandbox 接口](/reference/workspace/sandbox)。

## 安装 {/* #installation */}

```bash npm2yarn
npm install @mastra/e2b-desktop
```

通过 `E2B_API_KEY` 环境变量或 `apiKey` 选项设置 E2B API 密钥。

## 用法 {/* #usage */}

将 `E2BDesktopSandbox` 添加到 Workspace，再将该 Workspace 分配给一个 Agent。由于该 Sandbox 支持[计算机操作功能](/docs/sandbox/computer)，Workspace 除了注册 shell 和进程相关的 Tool，还会注册 `mastra_workspace_computer_*` 系列 Tool：

```typescript
import { Agent } from '@mastra/core/agent'
import { Workspace } from '@mastra/core/workspace'
import { E2BDesktopSandbox } from '@mastra/e2b-desktop'

const workspace = new Workspace({
  sandbox: new E2BDesktopSandbox({
    resolution: [1280, 720],
  }),
})

const agent = new Agent({
  id: 'desktop-agent',
  name: 'Desktop Agent',
  instructions: 'You can control a Linux desktop and run shell commands.',
  model: '__GATEWAY_ANTHROPIC_MODEL_SONNET__',
  workspace,
})

const response = await agent.generate(
  'Take a screenshot, then create /tmp/hello.txt with the text "hello" and cat it.',
)
```

Agent 可以结合使用桌面操作（单击、键入、截图）和 shell 命令。两种操作都在同一台机器上执行。

### 直接控制桌面 {/* #direct-desktop-control */}

无需通过 Agent，即可在代码中直接使用 `computer` 功能：

```typescript
const sandbox = new E2BDesktopSandbox()
await sandbox.start()

await sandbox.computer.leftClick(100, 200)
await sandbox.computer.type('hello')
const { data } = await sandbox.computer.screenshot() // PNG bytes

const size = await sandbox.computer.getScreenSize()
console.log(size) // { width: 1024, height: 768 }
```

### 实时查看桌面 {/* #live-desktop-view */}

`streamUrl()` 在 Sandbox 内启动需要身份验证的 noVNC 串流，并返回用于观看的 URL。在浏览器中打开该 URL，即可实时查看 Agent 的操作：

```typescript
const url = await sandbox.computer.streamUrl()
// https://6080-<sandbox-id>.e2b.app/vnc.html?...&password=<auth-key>
```

### 直接使用桌面 SDK {/* #desktop-sdk-escape-hatch */}

底层的 [`@e2b/desktop`](https://github.com/e2b-dev/desktop) Sandbox 提供桌面专用 API，包括 `launch`、`open`、窗口辅助方法以及自定义串流控制：

```typescript
await sandbox.desktop.launch('xfce4-terminal')
await sandbox.desktop.open('https://mastra.ai')
```

## 挂载云存储 {/* #cloud-storage-mounting */}

默认的 `desktop` 模板不包含 FUSE 工具，因此[挂载云存储](/integrations/sandboxes/e2b#mounting-cloud-storage)需要使用已安装 `s3fs` 或 `gcsfuse` 的自定义桌面模板。通过 `template` 选项指定该模板。
