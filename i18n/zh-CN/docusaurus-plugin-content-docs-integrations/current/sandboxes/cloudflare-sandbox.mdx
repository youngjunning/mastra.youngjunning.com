# Cloudflare Sandbox

`CloudflareSandbox` 通过 [Sandbox Bridge HTTP API](https://developers.cloudflare.com/sandbox/bridge/http-api/) 在远程 [Cloudflare Sandbox](https://developers.cloudflare.com/sandbox/) 中执行命令和管理文件。

:::warning

使用此 Provider 前，请先部署 [Sandbox Bridge Worker](https://developers.cloudflare.com/sandbox/bridge/) 并做好安全防护。Bridge 可以代表调用方创建和删除 Sandbox、执行命令以及写入文件。

:::

## 安装 {/* #installation */}

```bash npm2yarn
npm install @mastra/cloudflare-sandbox
```

## 使用方法 {/* #usage */}

将 `CloudflareSandbox` 添加到 Workspace，再将该 Workspace 分配给 Agent。

```typescript title="src/mastra/agents/dev-agent.ts"
import { Agent } from '@mastra/core/agent'
import { Workspace } from '@mastra/core/workspace'
import { CloudflareSandbox } from '@mastra/cloudflare-sandbox'

const workspace = new Workspace({
  sandbox: new CloudflareSandbox({
    baseUrl: process.env.CLOUDFLARE_SANDBOX_BRIDGE_URL!,
    apiToken: process.env.CLOUDFLARE_SANDBOX_API_KEY,
    workingDirectory: '/workspace',
    commandTimeout: 300_000,
  }),
})

export const agent = new Agent({
  id: 'dev-agent',
  name: 'Development agent',
  instructions: 'You are a helpful development assistant.',
  model: 'anthropic/claude-sonnet-4-6',
  workspace,
})
```

Workspace 启动时，Provider 会创建远程 Sandbox。若要重新连接到已有的 Sandbox，请传入 `sandboxId`。

## 执行命令 {/* #execute-commands */}

调用 `executeCommand()` 时，可以传入命令参数、环境变量、工作目录和处理流式输出的回调函数。Provider 以 `argv` 数组的形式发送命令，由 Bridge 处理 Shell 转义。

```typescript
const result = await workspace.sandbox?.executeCommand?.('npm', ['test'], {
  cwd: '/workspace/project',
  env: {
    NODE_ENV: 'test',
  },
  onStdout: chunk => process.stdout.write(chunk),
  onStderr: chunk => process.stderr.write(chunk),
})
```

## 写入文件 {/* #write-files */}

相对路径以 `/workspace` 为基准解析，绝对路径解析后也必须位于 `/workspace` 内。每个文件通过单独的请求发送给 Bridge，单个文件最大为 32 MiB。

Cloudflare Sandbox 无法为单个文件设置权限，因此会直接拒绝包含 `mode` 的 `writeFiles` 调用。

```typescript
await workspace.sandbox?.writeFiles?.([
  { path: 'src/index.ts', content: "console.log('hello')\n" },
  { path: '/workspace/package.json', content: JSON.stringify({ type: 'module' }) },
])
```

## 读取文件 {/* #read-files */}

从 `/workspace` 读取单个文件，返回原始字节。相对路径以 `/workspace` 为基准解析，绝对路径解析后也必须位于该目录内。

```typescript
const bytes = await workspace.sandbox?.readFile?.('src/index.ts')
const source = new TextDecoder().decode(bytes)
```

## 在容器休眠后保留文件 {/* #keep-files-across-container-sleep */}

容器空闲时间达到 `sleepAfter`（默认为 10 分钟）后，Cloudflare 会停止该容器。下一条命令会启动全新的容器，先前直接写入 `/workspace` 的内容会丢失。请将 `/workspace` 用作临时空间，将需要保留的文件存入已挂载的存储桶。

通过 Workspace 的 `mounts` 选项配置与 S3 兼容的存储桶，例如 Cloudflare R2。Sandbox 会在 `start()` 时挂载存储桶。容器从休眠中恢复时不会保留原有挂载，所以 Sandbox 会在下一次文件系统操作前重新挂载失去挂载的路径。存储桶中的数据因此能在容器休眠后继续使用。

```typescript
import { Workspace } from '@mastra/core/workspace'
import { S3Filesystem } from '@mastra/s3'
import { CloudflareSandbox } from '@mastra/cloudflare-sandbox'

const workspace = new Workspace({
  sandbox: new CloudflareSandbox({
    baseUrl: process.env.CLOUDFLARE_SANDBOX_BRIDGE_URL!,
    apiToken: process.env.CLOUDFLARE_SANDBOX_BRIDGE_TOKEN!,
  }),
  mounts: {
    '/workspace/data': new S3Filesystem({
      bucket: 'agent-data',
      region: 'auto',
      endpoint: `https://${process.env.CLOUDFLARE_ACCOUNT_ID}.r2.cloudflarestorage.com`,
      accessKeyId: process.env.R2_ACCESS_KEY_ID,
      secretAccessKey: process.env.R2_SECRET_ACCESS_KEY,
    }),
  },
})
```

Bridge 使用 s3fs 挂载存储桶，因此只接受 `type: 's3'` 的挂载配置。对于 GCS 或 Azure 文件系统，以及包含 `sessionToken` 的 S3 凭据，Provider 会直接返回表示挂载失败的 `MountResult`，无需向 Bridge 发送请求。

`getInstructions()` 默认返回的说明会告诉模型，`/workspace` 中的数据可能在两条命令之间丢失，并列出应该写入的挂载路径。

## 备份和恢复 Workspace {/* #persist-and-restore-the-workspace */}

`persistWorkspace()` 将 `/workspace` 打包并返回 tar 归档的原始字节，`hydrateWorkspace()` 根据这些字节恢复 Workspace。这种方式适用于一次性备份，无法替代挂载。容器唤醒后，必须在执行第一条命令前恢复数据。如果在容器刚唤醒时就保存备份，空的 Workspace 会覆盖原有归档。

```typescript
// Back up before the container can sleep
const archive = await workspace.sandbox?.persistWorkspace?.({ excludes: ['node_modules'] })
await myStorage.put('workspace-backup', archive)

// Later, on a fresh or reconnected sandbox
const archive = await myStorage.get('workspace-backup')
await workspace.sandbox?.hydrateWorkspace?.(archive)
```

要管理执行会话，请直接调用 `CloudflareSandboxBridgeClient` 的 `createSession` 和 `deleteSession` 方法。

## 生命周期行为 {/* #lifecycle-behavior */}

* `start()`：重新连接到 `sandboxId` 指定的 Sandbox，或创建远程 Sandbox，然后应用 Workspace 的 `mounts` 挂载配置。
* `stop()`：解除远程 Sandbox 与 Mastra 生命周期的关联，保留远程 Sandbox，因为 Bridge 没有提供挂起操作。
* `destroy()`：删除远程 Sandbox。

## 局限性 {/* #limitations */}

此 Provider 通过 Sandbox 接口直接提供命令执行、流式输出、文件读写、S3 兼容存储桶挂载和 Workspace 持久化功能。会话仅能通过 Bridge 客户端（`CloudflareSandboxBridgeClient`）使用，`CloudflareSandbox` 接口不提供会话功能。此 Provider 不提供 PTY 终端，也不支持后台进程管理、标准输入（stdin）、快照或端口 URL。
