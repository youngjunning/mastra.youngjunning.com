# AgentCore

通过 `InvokeAgentRuntimeCommand` 在 [AWS Bedrock AgentCore Runtime](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/runtime-execute-command.html) 会话中执行 shell 命令。

如果 Agent 已在 AgentCore Runtime 中运行，并且你希望 Mastra Workspace 在同一运行时会话中执行命令，请使用 `AgentCoreRuntimeSandbox`。有关接口的详细信息，请参阅 [WorkspaceSandbox 接口](/reference/workspace/sandbox)。

:::warning

`AgentCoreRuntimeSandbox` 仅支持一次性命令执行，不支持后台进程管理、标准输入或文件系统挂载。AgentCore Code Interpreter 是独立的 AWS 服务，不属于此 Provider。

:::

## 安装 {/* #installation */}

```bash npm2yarn
npm install @mastra/agentcore
```

## 用法 {/* #usage */}

将 `AgentCoreRuntimeSandbox` 添加到 Workspace，再将该 Workspace 分配给 Agent：

```typescript title="src/mastra/agents/dev-agent.ts"
import { Agent } from '@mastra/core/agent'
import { Workspace } from '@mastra/core/workspace'
import { AgentCoreRuntimeSandbox } from '@mastra/agentcore'

const workspace = new Workspace({
  sandbox: new AgentCoreRuntimeSandbox({
    region: 'us-west-2',
    agentRuntimeArn: process.env.AGENTCORE_RUNTIME_ARN!,
    runtimeSessionId: '12345678-1234-1234-1234-123456789012',
  }),
})

const agent = new Agent({
  id: 'dev-agent',
  name: 'dev-agent',
  model: 'anthropic/claude-sonnet-4-6',
  instructions: 'You are a helpful development assistant.',
  workspace,
})
```

通过 Sandbox 在代码中执行命令：

```typescript
const result = await workspace.sandbox?.executeCommand?.('npm', ['test'], {
  cwd: '/workspace',
  env: {
    NODE_ENV: 'test',
  },
  timeout: 300_000,
})

if (!result?.success) {
  console.error(result?.stderr)
}
```

## 方法 {/* #methods */}

### 命令执行 {/* #command-execution */}

#### `executeCommand(command, args?, options?)` {/* #executecommandcommand-args-options */}

在 AgentCore Runtime 会话中执行一次性 shell 命令，返回标准输出、标准错误、退出码以及是否超时。

```typescript
const result = await sandbox.executeCommand('npm', ['test'], {
  cwd: '/workspace',
  env: {
    NODE_ENV: 'test',
  },
  timeout: 300_000,
})
```

返回：`Promise<CommandResult>`。

`options.timeout` 以毫秒为单位。AgentCore Runtime 接受的命令超时时间为 1 至 3600 秒。Provider 会在发送请求前将毫秒转换为秒。

### 生命周期 {/* #lifecycle */}

#### `start()` {/* #start */}

执行 Sandbox 生命周期的启动钩子。此 Provider 在执行 `start()` 时不会创建 AgentCore Runtime 会话。

```typescript
await sandbox.start()
```

#### `stop()` {/* #stop */}

仅当 `stopSessionOnLifecycle` 为 `true` 时，才停止 AgentCore Runtime 会话。

```typescript
await sandbox.stop()
```

#### `stopRuntimeSession()` {/* #stopruntimesession */}

显式停止此 Sandbox 使用的 AgentCore Runtime 会话。

如果运行时会话归此 Sandbox 所有，并且你想直接清理该会话，请调用此方法。只有在 `stopSessionOnLifecycle` 为 `true` 时，`destroy()` 才会调用此方法，因为 AgentCore Runtime 会话也可能由 Workspace 的 Sandbox 生命周期之外的 Agent 调用共享。

```typescript
await sandbox.stopRuntimeSession()
```

#### `destroy()` {/* #destroy */}

销毁 Sandbox 实例。如果 AWS SDK 客户端归此实例所有，`destroy()` 也会销毁该客户端。如果 `stopSessionOnLifecycle` 为 `true`，还会调用 `StopRuntimeSession`。

```typescript
await sandbox.destroy()
```

### 元数据 {/* #metadata */}

#### `getInfo()` {/* #getinfo */}

返回 Sandbox 状态和 AgentCore Runtime 元数据。

```typescript
const info = await sandbox.getInfo()
```

返回：`Promise<SandboxInfo>`。

## 限制 {/* #limitations */}

`AgentCoreRuntimeSandbox` 遵循 AgentCore Runtime 的命令执行规则：

* **一次性命令**：每条命令会运行至结束或超时。
* **Shell 不会持续运行**：命令之间不会保留 shell 状态。请在每条命令中设置所需状态，例如 `cd /workspace && npm test`。
* **不支持后台进程**：此 Provider 不提供 `processes` 管理器。
* **不支持交互式标准输入**：通过此 Provider 在运行时执行命令时，无法使用交互式标准输入流。
* **不支持挂载 Workspace 文件系统**：此 Provider 不支持挂载 Workspace 的文件系统。
* **Tool 取决于容器镜像**：命令只能使用 AgentCore Runtime 容器镜像中已安装的 Tool。
