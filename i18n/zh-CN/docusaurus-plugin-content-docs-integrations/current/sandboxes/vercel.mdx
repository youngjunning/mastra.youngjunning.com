# Vercel Sandbox

在隔离的 Vercel 环境中运行命令，可选择会话内持续运行的 Sandbox microVM 或无状态 Serverless Functions。

## Vercel Sandbox {/* #vercel-sandbox */}

在 [Vercel Sandbox](https://vercel.com/docs/vercel-sandbox) 中执行命令。它是基于 [Firecracker](https://firecracker-microvm.github.io/)、运行 Amazon Linux 2023 的临时 MicroVM，提供在会话期间持续存在的文件系统、`sudo` 权限、对外开放的端口和后台进程。接口详情请参见 [WorkspaceSandbox 接口](/reference/workspace/sandbox)。

:::note

它与通过无状态 Vercel serverless **Functions** 执行命令的 [`VercelServerlessSandbox`](#vercel-serverless-sandbox) 不同。`VercelSandbox` 运行完整的 Linux MicroVM，支持会话期间持续存在的文件系统和长期运行的进程。

:::

### 安装 {/* #installation */}

```bash npm2yarn
npm install @mastra/vercel
```

### 身份验证 {/* #authentication */}

未明确提供凭据时，`@vercel/sandbox` SDK 会自动使用 Vercel OIDC 令牌。如果提供 `token`、`teamId` 或 `projectId`，则必须同时提供这三个值。

<Tabs>
  <TabItem value="oidc" label="OIDC（推荐）">

### 用法 {/* #usage */}

将 `VercelSandbox` 添加到 Workspace，并将该 Workspace 分配给 Agent：

```typescript
import { Agent } from '@mastra/core/agent'
import { Workspace } from '@mastra/core/workspace'
import { VercelSandbox } from '@mastra/vercel'

const workspace = new Workspace({
  sandbox: new VercelSandbox({
    runtime: 'node24',
    timeout: 600_000,
  }),
})

const agent = new Agent({
  id: 'code-agent',
  name: 'Code Agent',
  instructions: 'You are a coding assistant working in this workspace.',
  model: '__GATEWAY_ANTHROPIC_MODEL_SONNET__',
  workspace,
})

const response = await agent.generate('Print "Hello, world!" and show the Node.js version.')

console.log(response.text)
```

#### 资源和暴露的端口 {/* #resources-and-exposed-ports */}

分配 vCPU（每个 vCPU 配有 2048 MB 内存），并开放端口，以访问 Sandbox 内运行的网络服务：

```typescript
const sandbox = new VercelSandbox({
  runtime: 'node24',
  resources: { vcpus: 4 },
  ports: [3000],
})

const workspace = new Workspace({ sandbox })
await sandbox.start()

// The public HTTPS domain for an exposed port is available via getInfo()
const { metadata } = sandbox.getInfo()
console.log(metadata?.domains) // { 3000: 'https://....vercel.run' }
```

#### 流式输出 {/* #streaming-output */}

通过 `onStdout` 和 `onStderr` 回调实时接收命令输出：

```typescript
await sandbox.executeCommand('sh', ['-c', 'for i in 1 2 3; do echo "line $i"; sleep 1; done'], {
  onStdout: chunk => process.stdout.write(chunk),
  onStderr: chunk => process.stderr.write(chunk),
})
```

两个回调均为可选项，可以分别使用。

### 后台进程 {/* #background-processes */}

`VercelSandbox` 包含用于启动和管理后台进程的进程管理器。每个进程都作为 MicroVM 内的独立命令运行，其输出会流式写入命令日志。

```typescript
const sandbox = new VercelSandbox({ runtime: 'node24', ports: [3000] })
await sandbox.start()

const handle = await sandbox.processes.spawn('node server.js', {
  env: { PORT: '3000' },
  onStdout: data => console.log(data),
})

console.log(handle.stdout)
await handle.kill()
```

完整 API 请参见 [`SandboxProcessManager` 参考文档](/reference/workspace/process-manager)。

:::note

Vercel Sandbox SDK 不提供运行中命令的标准输入通道，因此调用 `handle.sendStdin()` 会抛出异常。

Mastra 适配器未实现 Workspace 文件系统挂载 API。底层 Vercel Sandbox 产品支持[用户空间文件系统（FUSE）挂载](https://vercel.com/docs/sandbox/mount-remote-storage)。可以通过 `sandbox.sandbox` 暴露的底层 SDK 实例直接配置挂载，但 Mastra 不管理其生命周期。

:::

### 限制 {/* #limits */}

* 最多 32 个 vCPU，每个 vCPU 具有 2048 MB 内存。
* 最多 15 个暴露端口。
* 文件系统仅在会话期间保留；Sandbox 停止后，文件会丢失。
* 最长运行时间取决于套餐（Hobby 为 45 分钟，Pro 和 Enterprise 最长为 24 小时）；默认运行时间为 5 分钟。

当前限制和价格请参见 [Vercel Sandbox 文档](https://vercel.com/docs/vercel-sandbox)。

## Vercel Serverless Sandbox {/* #vercel-serverless-sandbox */}

`VercelServerlessSandbox` 通过 [Vercel](https://vercel.com) Serverless Functions 执行命令，提供全球分布式、无需自行管理基础设施且可自动扩缩的执行环境。接口详情请参见 [WorkspaceSandbox 接口](/reference/workspace/sandbox)。

:::warning

`VercelServerlessSandbox` 是无状态的，不提供持久文件系统、交互式 shell 或长期运行的后台进程。只有 `/tmp` 可写，且其中的数据不会在调用之间保留。

:::

:::note

如需完整的 Linux MicroVM、会话期间持续存在的文件系统、`sudo` 权限、开放端口和后台进程，请使用基于 [Vercel Sandbox](https://vercel.com/docs/vercel-sandbox) 产品的 [`VercelSandbox`](#vercel-sandbox)。

:::

将 `VercelServerlessSandbox` 添加到 Workspace，并将该 Workspace 分配给 Agent：

```typescript
import { Agent } from '@mastra/core/agent'

  sandbox: new VercelServerlessSandbox({
    token: process.env.VERCEL_TOKEN,
  }),
})

const agent = new Agent({
  id: 'dev-agent',
  name: 'dev-agent',
  instructions: 'You are a coding assistant working in this workspace.',
  model: '__GATEWAY_ANTHROPIC_MODEL_SONNET__',
  workspace,
})
```

### 局限性 {/* #limitations */}

`VercelServerlessSandbox` 底层使用 Serverless Functions，因此存在以下限制：

* **没有持久文件系统**：写入 `/tmp` 的文件是临时的，会在调用之间清除。
* **没有交互式 shell**：命令通过 `/bin/sh -c` 运行，不支持标准输入流。
* **没有后台进程**：不提供进程管理器、PID 或长期运行的任务。
* **不支持挂载**：无法挂载云存储（S3、GCS）。
* **超时限制**：最长执行时间受 `maxDuration` 限制，默认值为 60 秒。
