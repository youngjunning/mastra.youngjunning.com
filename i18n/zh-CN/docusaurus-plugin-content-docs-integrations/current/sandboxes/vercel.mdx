# Vercel Sandbox

使用持久性 Sandbox microVM 或无状态 Serverless Functions 在隔离的 Vercel 环境中运行命令。

## 维塞尔Sandbox {/* #vercel-sandbox */}

执行里面的命令[Vercel Sandbox](https://vercel.com/docs/vercel-sandbox) which is an ephemeral [Firecracker](https://firecracker-microvm.github.io/)运行 Amazon Linux 2023 的 MicroVM。提供持久的会话中文件系统，`sudo`访问、暴露的端口和后台进程。接口详情请参见[Workspace沙盒界面](/reference/workspace/sandbox).

：：：笔记

这与[`VercelServerlessSandbox`](#vercel-serverless-sandbox), which runs commands as stateless Vercel serverless **Functions**. `VercelSandbox` runs a full Linux MicroVM with a persistent filesystem and long-running processes.

:::

### 安装 {/* #installation */}

```bash npm2yarn
npm install @mastra/vercel
```

### 验证 {/* #authentication */}

这`@vercel/sandbox` SDK uses a Vercel OIDC token automatically when no explicit credentials are provided. If you provide `token`, `teamId`, or `projectId`, provide all three values together.

### 用法 {/* #usage */}

添加一个`VercelSandbox` to a workspace and assign it to an agent:

```typescript
import { Agent } from '@mastra/core/agent'
import { Workspace } from '@mastra/core/workspace'
import { VercelSandbox } from '@mastra/vercel'

const workspace = new Workspace({
  sandbox: new VercelSandbox({
    runtime: 'node24',
    timeout: 600_000,
  }),
})

const agent = new Agent({
  id: 'code-agent',
  name: 'Code Agent',
  instructions: 'You are a coding assistant working in this workspace.',
  model: '__GATEWAY_ANTHROPIC_MODEL_SONNET__',
  workspace,
})

const response = await agent.generate('Print "Hello, world!" and show the Node.js version.')

console.log(response.text)
```

#### 资源和暴露的端口 {/* #resources-and-exposed-ports */}

分配 vCPU（每个 vCPU 2048 MB 内存）并公开端口以访问Sandbox内运行的网络服务：

```typescript
const sandbox = new VercelSandbox({
  runtime: 'node24',
  resources: { vcpus: 4 },
  ports: [3000],
})

const workspace = new Workspace({ sandbox })
await sandbox.start()

// The public HTTPS domain for an exposed port is available via getInfo()
const { metadata } = sandbox.getInfo()
console.log(metadata?.domains) // { 3000: 'https://....vercel.run' }
```

#### 流式输出 {/* #streaming-output */}

通过实时流命令输出`onStdout` and `onStderr` callbacks:

```typescript
await sandbox.executeCommand('sh', ['-c', 'for i in 1 2 3; do echo "line $i"; sleep 1; done'], {
  onStdout: chunk => process.stdout.write(chunk),
  onStderr: chunk => process.stderr.write(chunk),
})
```

两个回调都是可选的并且可以独立使用。

### 后台进程 {/* #background-processes */}

`VercelSandbox`包括用于生成和管理后台进程的进程管理器。每个生成的进程都作为 MicroVM 内的独立命令运行，并通过命令日志传输输出。

```typescript
const sandbox = new VercelSandbox({ runtime: 'node24', ports: [3000] })
await sandbox.start()

const handle = await sandbox.processes.spawn('node server.js', {
  env: { PORT: '3000' },
  onStdout: data => console.log(data),
})

console.log(handle.stdout)
await handle.kill()
```

请参阅[`SandboxProcessManager` reference](/reference/workspace/process-manager) for the full API.

：：：笔记

Vercel Sandbox SDK 不公开用于运行命令的标准输入通道，因此`handle.sendStdin()` throws.

Mastra 适配器不实现 Workspace 文件系统安装 API。底层 Vercel Sandbox 产品支持[Filesystem in Userspace (FUSE) mounts](https://vercel.com/docs/sandbox/mount-remote-storage). You can configure a mount directly through the underlying SDK instance exposed by `sandbox.sandbox`, but Mastra doesn't manage its lifecycle.

:::

### 限制 {/* #limits */}

* 最多 32 个 vCPU，每个 vCPU 具有 2048 MB 内存。
* 最多 15 个暴露端口。
* 文件系统是短暂的。它仅在会话内保留，并在Sandbox停止时丢失。
* 最长运行时间取决于计划（Hobby 为 45 分钟，Pro 和 Enterprise 最长为 24 小时），默认为 5 分钟。

请参阅[Vercel Sandbox documentation](https://vercel.com/docs/vercel-sandbox) for current limits and pricing.

## Vercel 无服务器Sandbox {/* #vercel-serverless-sandbox */}

`VercelServerlessSandbox`执行命令为[Vercel](https://vercel.com) serverless functions. It provides globally distributed, zero-infrastructure execution with automatic scaling. For interface details, see the [WorkspaceSandbox interface](/reference/workspace/sandbox).

：：：警告

`VercelServerlessSandbox`是无国籍的。它不提供持久文件系统、交互式 shell 或长时间运行的后台进程。仅有的`/tmp` is writable, and it's ephemeral between invocations.

:::

：：：笔记

对于具有持久文件系统的完整 Linux MicroVM，`sudo` access, exposed ports, and background processes, use [`VercelSandbox`](#vercel-sandbox), which is backed by the [Vercel Sandbox](https://vercel.com/docs/vercel-sandbox) product.

:::

### 局限性 {/* #limitations */}

`VercelServerlessSandbox`在底层使用无服务器功能，这意味着：

* **没有持久性文件系统**：写入的文件`/tmp` are ephemeral and cleared between invocations.
* **没有交互式 shell**：命令运行通过`/bin/sh -c` with no stdin streaming.
* **无后台进程**：没有进程管理器、PID 或长时间运行的任务。
* **无需安装**：不支持云存储安装（S3、GCS）。
* **超时限制**：最大执行时间受以下限制`maxDuration` (default 60s).
