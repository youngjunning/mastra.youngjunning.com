# 苹果容器

通过 Apple 在本地 OCI Linux 容器内执行命令[`container`](https://github.com/apple/container)命令行界面。提供者启动一个长期存在的容器并使用`container exec`用于Workspace命令。接口详情请参见[Workspace沙盒界面](/reference/workspace/sandbox).

## 安装 {/* #installation */}

```bash npm2yarn
npm install @mastra/apple-container
```

需要运行 macOS 26 或更高版本的 Apple Silicon Mac`container` CLI installed. Start the container system before using the provider:

```bash
container system start
```

## 用法 {/* #usage */}

添加一个`AppleContainerSandbox` to a workspace and assign it to an agent:

```typescript
import { Agent } from '@mastra/core/agent'
import { Workspace } from '@mastra/core/workspace'
import { AppleContainerSandbox } from '@mastra/apple-container'

const workspace = new Workspace({
  sandbox: new AppleContainerSandbox({
    image: 'node:22-slim',
    volumes: {
      '/Users/me/project': '/workspace',
    },
    workingDirectory: '/workspace',
  }),
})

const agent = new Agent({
  id: 'dev-agent',
  name: 'Dev Agent',
  instructions: 'You are a coding assistant working in this workspace.',
  model: '__GATEWAY_ANTHROPIC_MODEL_SONNET__',
  workspace,
})

const response = await agent.generate('Run `node --version`.')
console.log(response.text)
```

## 环境变量 {/* #environment-variables */}

在容器级别设置环境变量`env`. Per-command environment variables can also be passed through `executeCommand` options:

```typescript
const sandbox = new AppleContainerSandbox({
  image: 'node:22-slim',
  env: {
    NODE_ENV: 'development',
  },
})

await sandbox.executeCommand('node', ['-e', 'console.log(process.env.TASK_ID)'], {
  env: { TASK_ID: '42' },
})
```

## 绑定坐骑 {/* #bind-mounts */}

使用以下命令将主机目录挂载到容器中`volumes` option:

```typescript
const sandbox = new AppleContainerSandbox({
  image: 'node:22-slim',
  volumes: {
    '/Users/me/project': '/workspace/project',
    '/Users/me/.npm': '/root/.npm',
  },
})
```

绑定挂载在容器创建时应用。主机路径必须在Sandbox启动之前存在。

## 资源和平台选项 {/* #resource-and-platform-options */}

Apple 容器 CLI 选项可以通过构造函数传递：

```typescript
const sandbox = new AppleContainerSandbox({
  image: 'node:22-slim',
  volumes: {
    '/Users/me/project': '/workspace',
  },
  cpus: 2,
  memory: '2G',
  platform: 'linux/arm64',
  readonlyRootfs: true,
  tmpfs: ['/tmp'],
})
```

这些选项仅在创建新容器时应用。如果Sandbox重新连接到具有相同名称的现有容器，请销毁并重新创建Sandbox以应用更改的运行时选项。
苹果`--tmpfs` accepts container paths only, such as `/tmp`; it doesn't accept Docker-style option specs like `/tmp:rw,size=256m`.
When `readonlyRootfs` is enabled, make sure `workingDirectory` points to a path supplied by the image or a bind mount. A writable tmpfs is also supported.

## 安全模型 {/* #security-model */}

`AppleContainerSandbox`通过主机 Apple 运行本地容器`container` service. Treat constructor options as trusted server-side configuration:

* `volumes`, `mounts`, and `publishedSockets` can expose host paths to containerized code.
* `publishedPorts`可以在主机或网络上公开容器内服务。绑定到`127.0.0.1` when only local access is intended.
* `ssh`转发主机 SSH Agent套接字。
* `capAdd`和`virtualization` can expand what containerized code can do.
* `containerBinary`是受信任代码的仅构造函数逃生口，不是可序列化编辑器提供程序架构的一部分。

使用您的工作负载所需的最窄安装和功能。现有容器仅在带有Sandbox ID 的 Mastra 所有权标签时才会重新连接。该Provider创建的容器还包含配置哈希标签；当该标签存在时，如果不可变的运行时选项（例如图像、命令、挂载、端口、功能或工作目录发生更改），重新连接将失败。

## 局限性 {/* #limitations */}

`AppleContainerSandbox`实现前台Workspace命令执行`executeCommand()`. It doesn't yet expose a `SandboxProcessManager` for background processes or LSP sessions.

命令超时是在容器内强制执行的，因此容器运行时会清除超时的命令。中止信号会取消主机 CLI 等待路径，并且当容器内清理很重要时，不应将其用作命令超时的替代方法。

## 重连 {/* #reconnection */}

`AppleContainerSandbox`通过检查具有配置名称的容器来重新连接。什么时候`start()` is called:

* 正在运行的容器被重复使用。
* 已停止的容器将重新启动。
* 从配置的映像创建丢失的容器。
* 具有已配置名称但没有匹配 Mastra 所有权标签的容器会失败而不是受到管理。
* 如果 Mastra 拥有的容器的配置哈希标签与不可变运行时选项不匹配，则会失败而不是被重用。

```typescript
const sandbox = new AppleContainerSandbox({ id: 'persistent-sandbox' })
await sandbox.start()

const sandbox2 = new AppleContainerSandbox({ id: 'persistent-sandbox' })
await sandbox2.start()
```

## 编辑器Provider {/* #editor-provider */}

向Provider注册`MastraEditor` to hydrate stored sandbox configs:

```typescript
import { MastraEditor } from '@mastra/editor'
import { appleContainerSandboxProvider } from '@mastra/apple-container'

const editor = new MastraEditor({
  sandboxes: {
    [appleContainerSandboxProvider.id]: appleContainerSandboxProvider,
  },
})
```
