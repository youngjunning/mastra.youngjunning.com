# Google Calendar

通过 Mastra Connect 为 Agent 提供可在 Google Calendar 中查找、创建和更新事件，检查空闲时间，以及管理日历的 Tool。每次 Tool 调用都会经过 Mastra 平台，由平台添加该连接的凭据；你的应用不会存储 Google Calendar 凭据。

## 连接 {/* #connect */}

开始前，请先完成 [Connect 设置](/docs/mastra-platform/connect#get-started)，安装 `@mastra/connect` 并配置 Mastra 平台项目。

### 连接账户 {/* #connect-an-account */}

在包含 `.env` 文件的目录中运行以下命令：

```bash
mastra connect add google-calendar
```

CLI 会引导你完成 Google Calendar 的授权，并等待连接激活。

### 向 Agent 添加 Tool {/* #add-tools-to-an-agent */}

将 [`tools()`](/reference/connect/tools) 传给 Agent，并选择 `google-calendar` Provider：

```typescript title="src/mastra/agents/google-calendar-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const googleCalendarAgent = new Agent({
  id: 'google-calendar-agent',
  name: 'Google Calendar agent',
  instructions:
    'You help people find, create, and update events, check availability, and manage calendars in Google Calendar.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['google-calendar'] }),
})
```

Agent 可使用 43 个 Google Calendar Tool，Tool key 包括 `google_calendar_add_attendee`。完整列表请参阅 [Google Calendar Tool](/reference/connect/providers#google-calendar)；如需限制可用 Tool，或要求每次调用在运行前获得批准，请参阅 [`tools()` 参数](/reference/connect/tools#parameters)。
