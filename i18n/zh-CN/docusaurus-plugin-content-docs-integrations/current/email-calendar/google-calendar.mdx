# 谷歌日历

通过 Mastra Connect 为客服人员提供查找、创建和更新活动、检查可用性以及管理 Google 日历中的日历的Tool。每个Tool调用都会通过 Mastra 平台，该平台会添加连接的凭据。您的应用程序从不存储 Google 日历凭据。

## 连接 {/* #connect */}

在开始之前，请完成[Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect`并配置您的平台项目。

### 连接账户 {/* #connect-an-account */}

从包含您的目录的目录运行此命令`.env` file:

```bash
mastra connect add google-calendar
```

CLI 将引导您完成 Google 日历的授权并等待连接激活。

### 向Agent添加Tool {/* #add-tools-to-an-agent */}

经过[`tools()`](/reference/connect/tools) to the agent and select the `google-calendar` provider:

```typescript title="src/mastra/agents/google-calendar-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const googleCalendarAgent = new Agent({
  id: 'google-calendar-agent',
  name: 'Google Calendar agent',
  instructions:
    'You help people find, create, and update events, check availability, and manage calendars in Google Calendar.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['google-calendar'] }),
})
```

Agent获得 43 个 Google 日历Tool，其中包括以下键：`google_calendar_add_attendee`. See [Google Calendar tools](/reference/connect/providers#google-calendar) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
