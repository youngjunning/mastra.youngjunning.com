# 微软Outlook

为Agent提供Tool来阅读、发送、起草和回复电子邮件、管理邮件文件夹以及通过 Mastra Connect 在 Microsoft Outlook 中创建和更新日历事件。每个Tool调用都会通过 Mastra 平台，该平台会添加连接的凭据。您的应用程序从不存储 Microsoft Outlook 凭据。

## 连接 {/* #connect */}

在开始之前，请完成[Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect`并配置您的平台项目。

### 连接账户 {/* #connect-an-account */}

从包含您的目录的目录运行此命令`.env` file:

```bash
mastra connect add outlook
```

CLI 将引导您完成 Microsoft Outlook 的授权并等待连接激活。

### 向Agent添加Tool {/* #add-tools-to-an-agent */}

经过[`tools()`](/reference/connect/tools) to the agent and select the `outlook` provider:

```typescript title="src/mastra/agents/outlook-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const outlookAgent = new Agent({
  id: 'outlook-agent',
  name: 'Microsoft Outlook agent',
  instructions:
    'You help people read, send, draft, and reply to email, manage mail folders, and create and update calendar events in Microsoft Outlook.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['outlook'] }),
})
```

Agent获得 30 个 Microsoft Outlook Tool，其中包括以下密钥：`outlook_add_event_attachment`. See [Microsoft Outlook tools](/reference/connect/providers#microsoft-outlook) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
