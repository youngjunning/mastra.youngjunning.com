# Microsoft Outlook

通过 Mastra Connect 为 Agent 提供可在 Microsoft Outlook 中读取、发送、起草和回复电子邮件，管理邮件文件夹，以及创建和更新日历事件的 Tool。每次 Tool 调用都会经过 Mastra 平台，由平台添加该连接的凭据；你的应用不会存储 Microsoft Outlook 凭据。

## 连接 {/* #connect */}

开始前，请先完成 [Connect 设置](/docs/mastra-platform/connect#get-started)，安装 `@mastra/connect` 并配置 Mastra 平台项目。

### 连接账户 {/* #connect-an-account */}

在包含 `.env` 文件的目录中运行以下命令：

```bash
mastra connect add outlook
```

CLI 会引导你完成 Microsoft Outlook 的授权，并等待连接激活。

### 向 Agent 添加 Tool {/* #add-tools-to-an-agent */}

将 [`tools()`](/reference/connect/tools) 传给 Agent，并选择 `outlook` Provider：

```typescript title="src/mastra/agents/outlook-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const outlookAgent = new Agent({
  id: 'outlook-agent',
  name: 'Microsoft Outlook agent',
  instructions:
    'You help people read, send, draft, and reply to email, manage mail folders, and create and update calendar events in Microsoft Outlook.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['outlook'] }),
})
```

Agent 可使用 30 个 Microsoft Outlook Tool，Tool key 包括 `outlook_add_event_attachment`。完整列表请参阅 [Microsoft Outlook Tool](/reference/connect/providers#microsoft-outlook)；如需限制可用 Tool，或要求每次调用在运行前获得批准，请参阅 [`tools()` 参数](/reference/connect/tools#parameters)。
