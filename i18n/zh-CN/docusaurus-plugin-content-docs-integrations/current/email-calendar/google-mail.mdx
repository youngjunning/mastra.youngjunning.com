# 邮箱

为客服人员提供Tool来阅读、发送和起草电子邮件、管理标签、过滤器和线程，以及通过 Mastra Connect 更新 Gmail 中的邮箱设置。每个Tool调用都会通过 Mastra 平台，该平台会添加连接的凭据。您的应用程序从不存储 Gmail 凭据。

## 连接 {/* #connect */}

在开始之前，请完成[Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect`并配置您的平台项目。

### 连接账户 {/* #connect-an-account */}

从包含您的目录的目录运行此命令`.env` file:

```bash
mastra connect add google-mail
```

CLI 将引导您完成 Gmail 授权并等待连接激活。

### 向Agent添加Tool {/* #add-tools-to-an-agent */}

经过[`tools()`](/reference/connect/tools) to the agent and select the `google-mail` provider:

```typescript title="src/mastra/agents/google-mail-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const googleMailAgent = new Agent({
  id: 'google-mail-agent',
  name: 'Gmail agent',
  instructions:
    'You help people read, send, and draft email, manage labels, filters, and threads, and update mailbox settings in Gmail.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['google-mail'] }),
})
```

Agent获得 52 个 Gmail Tool，其中包含以下密钥：`google_mail_batch_delete_messages`. See [Gmail tools](/reference/connect/providers#gmail) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
