# Gmail

通过 Mastra Connect 为 Agent 提供可在 Gmail 中读取、发送和起草电子邮件，管理标签、过滤器和会话，以及更新邮箱设置的 Tool。每次 Tool 调用都会经过 Mastra 平台，由平台添加该连接的凭据；你的应用不会存储 Gmail 凭据。

## 连接 {/* #connect */}

开始前，请先完成 [Connect 设置](/docs/mastra-platform/connect#get-started)，安装 `@mastra/connect` 并配置 Mastra 平台项目。

### 连接账户 {/* #connect-an-account */}

在包含 `.env` 文件的目录中运行以下命令：

```bash
mastra connect add google-mail
```

CLI 会引导你完成 Gmail 的授权，并等待连接激活。

### 向 Agent 添加 Tool {/* #add-tools-to-an-agent */}

将 [`tools()`](/reference/connect/tools) 传给 Agent，并选择 `google-mail` Provider：

```typescript title="src/mastra/agents/google-mail-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const googleMailAgent = new Agent({
  id: 'google-mail-agent',
  name: 'Gmail agent',
  instructions:
    'You help people read, send, and draft email, manage labels, filters, and threads, and update mailbox settings in Gmail.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['google-mail'] }),
})
```

Agent 可使用 52 个 Gmail Tool，Tool key 包括 `google_mail_batch_delete_messages`。完整列表请参阅 [Gmail Tool](/reference/connect/providers#gmail)；如需限制可用 Tool，或要求每次调用在运行前获得批准，请参阅 [`tools()` 参数](/reference/connect/tools#parameters)。
