# 火行

这`@mastra/browser-firecrawl`包提供浏览器自动化使用[Firecrawl 浏览器Sandbox](https://docs.firecrawl.dev/features/browser)。它通过 Firecrawl API 提供远程浏览器会话，并使用与以下相同的确定性、可访问性优先的Tool来驱动它们：[Agent浏览器](/integrations/browsers/agent-browser).

`FirecrawlBrowser`延伸`AgentBrowser`, so agents get the same toolset (`browser_goto`, `browser_snapshot`, `browser_click`等），而浏览器本身则在 Firecrawl 的托管基础​​设施中运行。不需要本地 Chromium 安装。

## 何时使用Firecrawl {/* #when-to-use-firecrawl */}

当您需要时使用 Firecrawl：

* 托管浏览器会话，无需管理本地 Chromium 二进制文件
* 无法启动本地浏览器的环境中的浏览器自动化
* 具有自动会话清理功能的每线程Sandbox隔离
* 命名的 Firecrawl 配置文件可在会话之间保留 cookie 和登录状态

## 快速入门 {/* #quickstart */}

安装包：

```bash npm2yarn
npm install @mastra/browser-firecrawl
```

设置您的 Firecrawl API 密钥：

```bash title=".env"
FIRECRAWL_API_KEY=fc-...
```

创建一个浏览器实例并将其分配给Agent：

```typescript title="src/mastra/agents/firecrawl-agent.ts"
import { Agent } from '@mastra/core/agent'
import { FirecrawlBrowser } from '@mastra/browser-firecrawl'

const browser = new FirecrawlBrowser({
  apiKey: process.env.FIRECRAWL_API_KEY,
})

export const firecrawlAgent = new Agent({
  id: 'firecrawl-agent',
  name: 'Firecrawl Agent',
  model: '__GATEWAY_OPENAI_MODEL__',
  browser,
  instructions: `You are a web automation assistant.

When interacting with pages:
1. Use browser_snapshot to get the current page state and element refs
2. Use the refs (like @e1, @e2) to target elements for clicks and typing
3. After actions, take another snapshot to verify the result`,
})
```

如果`apiKey` is omitted, the provider reads `FIRECRAWL_API_KEY` from the environment.

## 会话范围 {/* #session-scope */}

`FirecrawlBrowser`遵循相同的`scope` option as `AgentBrowser`:

* `'thread'`（默认）：每个对话线程都有自己的 Firecrawl Sandbox会话。当线程的浏览器关闭时，会话将被删除。
* `'shared'`：一个 Firecrawl Sandbox会话在所有线程之间共享，并在浏览器关闭时删除。

```typescript
const browser = new FirecrawlBrowser({
  scope: 'shared',
})
```

## 会话选项 {/* #session-options */}

在下面传递 Firecrawl 特定的会话选项`firecrawl` key. These map to the Firecrawl `browser()` API:

```typescript
const browser = new FirecrawlBrowser({
  firecrawl: {
    ttl: 600,
    activityTtl: 120,
    profile: {
      name: 'my-profile',
      saveChanges: true,
    },
  },
})
```

* `ttl`：最大会话生命周期（以秒为单位）。
* `activityTtl`：Firecrawl 回收会话之前的空闲超时（以秒为单位）。
* `profile`：命名为 Firecrawl 配置文件，保留 cookie 和登录状态。放`saveChanges: true` to save profile changes when the session ends.

：：：笔记

嵌套的`firecrawl.profile` option refers to a profile stored in Firecrawl's infrastructure. It's different from the top-level `profile` option inherited from `AgentBrowser`, which is a local Playwright user-data directory path.

:::

## 自托管 Firecrawl {/* #self-hosted-firecrawl */}

要使用自托管 Firecrawl API，请设置`apiUrl`:

```typescript
const browser = new FirecrawlBrowser({
  apiUrl: 'https://firecrawl.internal.example.com',
})
```
