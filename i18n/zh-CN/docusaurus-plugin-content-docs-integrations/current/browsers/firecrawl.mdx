# Firecrawl

`@mastra/browser-firecrawl` 包使用 [Firecrawl Browser Sandbox](https://docs.firecrawl.dev/features/browser) 实现浏览器自动化。它通过 Firecrawl API 创建远程浏览器会话，并使用与 [AgentBrowser](/integrations/browsers/agent-browser) 相同的 Tool 控制这些会话。这些 Tool 的行为具有确定性，并优先考虑无障碍访问。

`FirecrawlBrowser` 继承自 `AgentBrowser`，因此 Agent 可以使用同一套 Tool（`browser_goto`、`browser_snapshot`、`browser_click` 等），而浏览器本身运行在 Firecrawl 的托管基础设施上。无需在本地安装 Chromium。

## 何时使用 Firecrawl {/* #when-to-use-firecrawl */}

如果有以下需求，可以使用 Firecrawl：

- 使用托管的浏览器会话，无需管理本地 Chromium 二进制文件
- 在无法启动本地浏览器的环境中实现浏览器自动化
- 为每个对话线程单独提供 Sandbox 隔离，并自动清理会话
- 使用具名的 Firecrawl 配置文件，在不同会话之间保留 Cookie 和登录状态

## 快速入门 {/* #quickstart */}

安装软件包：

```bash npm2yarn
npm install @mastra/browser-firecrawl
```

设置你的 Firecrawl API 密钥：

```bash title=".env"
FIRECRAWL_API_KEY=fc-...
```

创建一个浏览器实例，并将其分配给一个 Agent：

```typescript title="src/mastra/agents/firecrawl-agent.ts"
import { Agent } from '@mastra/core/agent'
import { FirecrawlBrowser } from '@mastra/browser-firecrawl'

const browser = new FirecrawlBrowser({
  apiKey: process.env.FIRECRAWL_API_KEY,
})

export const firecrawlAgent = new Agent({
  id: 'firecrawl-agent',
  name: 'Firecrawl Agent',
  model: '__GATEWAY_OPENAI_MODEL__',
  browser,
  instructions: `You are a web automation assistant.

When interacting with pages:
1. Use browser_snapshot to get the current page state and element refs
2. Use the refs (like @e1, @e2) to target elements for clicks and typing
3. After actions, take another snapshot to verify the result`,
})
```

如果省略 `apiKey`，Provider 会从环境变量中读取 `FIRECRAWL_API_KEY`。

## 会话作用范围 {/* #session-scope */}

`FirecrawlBrowser` 与 `AgentBrowser` 支持相同的 `scope` 选项：

- `'thread'`（默认）：每个对话线程都有独立的 Firecrawl Sandbox 会话。该线程的浏览器关闭时，对应的会话会被删除。
- `'shared'`：所有对话线程共享同一个 Firecrawl Sandbox 会话。浏览器关闭时，该会话会被删除。

```typescript
const browser = new FirecrawlBrowser({
  scope: 'shared',
})
```

## 会话选项 {/* #session-options */}

在 `firecrawl` 键下传入 Firecrawl 专用的会话选项。这些选项对应 Firecrawl 的 `browser()` API：

```typescript
const browser = new FirecrawlBrowser({
  firecrawl: {
    ttl: 600,
    activityTtl: 120,
    profile: {
      name: 'my-profile',
      saveChanges: true,
    },
  },
})
```

- `ttl`：会话的最长存续时间，单位为秒。
- `activityTtl`：会话空闲超时时间，单位为秒。超过该时间后，Firecrawl 会回收会话。
- `profile`：用于持久保留 Cookie 和登录状态的具名 Firecrawl 配置文件。设置 `saveChanges: true` 可在会话结束时保存对配置文件的更改。

:::note

嵌套选项 `firecrawl.profile` 指向存储在 Firecrawl 基础设施中的配置文件。与之不同，从 `AgentBrowser` 继承的顶层选项 `profile` 指定的是本地 Playwright 用户数据目录的路径。

:::

## 自托管 Firecrawl {/* #self-hosted-firecrawl */}

要使用自托管的 Firecrawl API，请设置 `apiUrl`：

```typescript
const browser = new FirecrawlBrowser({
  apiUrl: 'https://firecrawl.internal.example.com',
})
```
