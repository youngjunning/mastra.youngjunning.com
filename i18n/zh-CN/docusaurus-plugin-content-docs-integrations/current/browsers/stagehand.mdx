# 舞台工作人员

这`@mastra/stagehand`包提供浏览器自动化使用[舞台操作者​​SDK](https://docs.browserbase.com/stagehand/introduction)来自浏览器库。 Stagehand 使用人工智能来理解页面上下文并定位元素，从而实现自然语言描述而不是显式选择器。

## 何时使用舞台工作人员 {/* #when-to-use-stagehand */}

当您需要时使用 Stagehand：

* 自然语言元素定位（“选择登录按钮”）
* 由人工智能驱动的页面数据提取
* 原生 Browserbase 云集成
* 用于常见操作的更简单的Tool界面

## 快速入门 {/* #quickstart */}

安装包：

```bash npm2yarn
npm install @mastra/stagehand
```

创建一个浏览器实例并将其分配给Agent：

```typescript title="src/mastra/agents/stagehand-agent.ts"
import { Agent } from '@mastra/core/agent'
import { StagehandBrowser } from '@mastra/stagehand'

const browser = new StagehandBrowser({
  headless: false,
  model: '__GATEWAY_OPENAI_MODEL__',
})

export const stagehandAgent = new Agent({
  id: 'stagehand-agent',
  name: 'Stagehand Agent',
  model: '__GATEWAY_OPENAI_MODEL__',
  browser,
  instructions: `You are a web automation assistant.

Use stagehand tools to interact with pages:
- stagehand_navigate to go to URLs
- stagehand_act to perform actions described in natural language
- stagehand_extract to get structured data from the page
- stagehand_observe to find available actions on the page
- stagehand_screenshot to visually inspect the page`,
})
```

## 自然语言动作 {/* #natural-language-actions */}

当Agent使用`stagehand_act` tool, it accepts natural language descriptions of actions:

* “按下登录按钮”
* “类型`'[user@example.com](mailto:user@example.com)'` in the email field"
* “从国家/地区下拉列表中选择‘美国’”

Stagehand 的人工智能会解释该动作并在页面上找到适当的元素。

## 数据提取 {/* #data-extraction */}

当Agent使用`stagehand_extract` tool, it can pull structured data from pages.

示例说明：“提取产品名称、价格和供货情况”

该Tool根据页面内容返回结构化数据：

```json
{
  "name": "Widget Pro",
  "price": "$29.99",
  "availability": "In Stock"
}
```

## 观察行动 {/* #observing-actions */}

当Agent使用`stagehand_observe` tool, it analyzes the current page and returns possible actions.

示例说明：“我可以在此登录表单上执行哪些操作？”

返回可用操作的列表：

```json
[
  { "action": "Press 'Sign In' button", "element": "button" },
  { "action": "Type in 'Email' field", "element": "input" },
  { "action": "Open 'Forgot Password' link", "element": "a" }
]
```

## 截图 {/* #screenshots */}

当Agent使用`stagehand_screenshot` tool, it captures a PNG image of the current page and returns it as image content that vision-capable models can interpret directly.

当您需要目视检查页面时，例如评估图像、布局或颜色，请使用屏幕截图。对于文本或结构化数据，请使用`stagehand_extract` or `stagehand_observe` instead.

```typescript
const browser = new StagehandBrowser({
  headless: false,
  model: '__GATEWAY_OPENAI_MODEL__',
})
```

要禁用不支持视觉的模型的屏幕截图Tool，请使用`excludeTools`:

```typescript
const browser = new StagehandBrowser({
  headless: false,
  model: '__GATEWAY_OPENAI_MODEL__',
  excludeTools: ['stagehand_screenshot'],
})
```

## 浏览器库 {/* #browserbase */}

Stagehand 具有针对云浏览器基础架构的原生 Browserbase 集成：

```typescript
const browser = new StagehandBrowser({
  env: 'BROWSERBASE',
  apiKey: process.env.BROWSERBASE_API_KEY,
  projectId: process.env.BROWSERBASE_PROJECT_ID,
  model: '__GATEWAY_OPENAI_MODEL__',
})
```

看[StagehandBrowser reference](/reference/browser/stagehand-browser) for all configuration options.

## 记录 {/* #recording */}

舞台工作人员可以选择使用 Beta 浏览器录制Tool：

```typescript
const browser = new StagehandBrowser({
  headless: false,
  model: '__GATEWAY_OPENAI_MODEL__',
  recording: {
    outputDir: './browser-recordings',
  },
})
```

这增加了`browser_record` and `browser_record_caption` to the agent's toolset. See [Browser recording (Beta)](/docs/browser#record-browser-sessions) for details.
