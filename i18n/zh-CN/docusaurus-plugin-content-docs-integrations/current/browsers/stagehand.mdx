# Stagehand

`@mastra/stagehand` 包使用 Browserbase 的 [Stagehand SDK](https://docs.browserbase.com/stagehand/introduction) 实现浏览器自动化。Stagehand 利用 AI 理解页面上下文，根据自然语言描述定位元素，无需显式指定选择器。

## 何时使用 Stagehand {/* #when-to-use-stagehand */}

以下场景适合使用 Stagehand：

- 用自然语言定位元素，例如“选择登录按钮”
- 利用 AI 从页面提取数据
- 直接集成 Browserbase 云服务
- 通过更简单的工具接口执行常见操作

## 快速入门 {/* #quickstart */}

安装包：

```bash npm2yarn
npm install @mastra/stagehand
```

创建浏览器实例，并将其传给 Agent：

```typescript title="src/mastra/agents/stagehand-agent.ts"
import { Agent } from '@mastra/core/agent'
import { StagehandBrowser } from '@mastra/stagehand'

const browser = new StagehandBrowser({
  headless: false,
  model: '__GATEWAY_OPENAI_MODEL__',
})

export const stagehandAgent = new Agent({
  id: 'stagehand-agent',
  name: 'Stagehand Agent',
  model: '__GATEWAY_OPENAI_MODEL__',
  browser,
  instructions: `You are a web automation assistant.

Use stagehand tools to interact with pages:
- stagehand_navigate to go to URLs
- stagehand_act to perform actions described in natural language
- stagehand_extract to get structured data from the page
- stagehand_observe to find available actions on the page
- stagehand_screenshot to visually inspect the page`,
})
```

## 自然语言操作 {/* #natural-language-actions */}

Agent 可以向 `stagehand_act` 工具传入自然语言指令，例如：

- “点击登录按钮”
- “在电子邮箱字段中输入 `'[user@example.com](mailto:user@example.com)'`”
- “从国家/地区下拉列表中选择‘美国’”

Stagehand 利用 AI 理解指令，并在页面上找到对应的元素。

## 数据提取 {/* #data-extraction */}

Agent 可以使用 `stagehand_extract` 工具从页面提取结构化数据。

示例指令：“提取商品名称、价格和库存状态”

工具根据页面内容返回结构化数据：

```json
{
  "name": "Widget Pro",
  "price": "$29.99",
  "availability": "In Stock"
}
```

## 查看可用操作 {/* #observing-actions */}

Agent 可以使用 `stagehand_observe` 工具分析当前页面，了解可以执行哪些操作。

示例指令：“我可以在这个登录表单中执行哪些操作？”

工具返回可用操作列表：

```json
[
  { "action": "Press 'Sign In' button", "element": "button" },
  { "action": "Type in 'Email' field", "element": "input" },
  { "action": "Open 'Forgot Password' link", "element": "a" }
]
```

## 截图 {/* #screenshots */}

`stagehand_screenshot` 工具将当前页面截取为 PNG 图片，并以支持视觉输入的模型可直接解析的图片内容返回给 Agent。

需要检查页面的图片、布局或颜色时，可以使用截图。处理文本或结构化数据时，请使用 `stagehand_extract` 或 `stagehand_observe`。

```typescript
const browser = new StagehandBrowser({
  headless: false,
  model: '__GATEWAY_OPENAI_MODEL__',
})
```

如果模型不支持视觉输入，可以通过 `excludeTools` 禁用截图工具：

```typescript
const browser = new StagehandBrowser({
  headless: false,
  model: '__GATEWAY_OPENAI_MODEL__',
  excludeTools: ['stagehand_screenshot'],
})
```

## Browserbase {/* #browserbase */}

Stagehand 原生集成了 Browserbase，可使用其云浏览器基础设施：

```typescript
const browser = new StagehandBrowser({
  env: 'BROWSERBASE',
  apiKey: process.env.BROWSERBASE_API_KEY,
  projectId: process.env.BROWSERBASE_PROJECT_ID,
  model: '__GATEWAY_OPENAI_MODEL__',
})
```

完整的配置选项见 [StagehandBrowser 参考文档](/reference/browser/stagehand-browser)。

## 录制浏览器会话 {/* #recording */}

你可以在 Stagehand 中启用浏览器录制工具（Beta）：

```typescript
const browser = new StagehandBrowser({
  headless: false,
  model: '__GATEWAY_OPENAI_MODEL__',
  recording: {
    outputDir: './browser-recordings',
  },
})
```

启用后，Agent 可以使用 `browser_record` 和 `browser_record_caption` 工具。详情见[浏览器录制（Beta）](/docs/browser#record-browser-sessions)。
