# BrowserViewer

`@mastra/browser-viewer` 软件包为 [agent-browser](https://www.npmjs.com/package/agent-browser)、[browser-use](https://pypi.org/project/browser-use/) 和 [browse](https://www.npmjs.com/package/browse) 等 CLI Tool 提供浏览器自动化能力。BrowserViewer 通过 Playwright 启动 Chrome，提供 Chrome DevTools Protocol（CDP）URL，并将该 URL 自动注入通过 [Sandbox Tool](/docs/sandbox/overview#using-the-sandbox) 运行的 CLI 命令。

## 何时使用 BrowserViewer {/* #when-to-use-browserviewer */}

如果你的 Agent 通过 CLI Tool 控制浏览器，而非通过 SDK 控制，请使用 BrowserViewer。BrowserViewer 负责以下操作：

- 启动并管理 Chrome，供 CLI Tool 连接
- 将 CDP URL 自动注入 `workspace_execute_command` 调用
- 将浏览器画面实时传输到 Studio
- 按会话线程隔离浏览器

如果通过 SDK 实现浏览器自动化，请使用 [AgentBrowser](/integrations/browsers/agent-browser) 或 [Stagehand](/integrations/browsers/stagehand)。

## 快速入门 {/* #quickstart */}

安装 `@mastra/browser-viewer` 和 Agent 将使用的 CLI Tool。BrowserViewer 负责管理 Chrome，CLI Tool 本身需要单独安装。

```bash npm2yarn
npm install @mastra/browser-viewer
```

在 Workspace 环境中安装 CLI Tool。本示例使用 `browser-use`：

```bash
pip install browser-use
```

安装相应的[技能](/docs/sandbox/skills)，让 Agent 了解如何使用该 CLI：

```bash
npx skills add browser-use/browser-use --skill browser-use
```

创建一个配置了 BrowserViewer 的 Workspace，并将其分配给 Agent：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core/mastra'
import { Agent } from '@mastra/core/agent'
import { Memory } from '@mastra/memory'
import { LibSQLStore } from '@mastra/libsql'
import { Workspace, LocalSandbox } from '@mastra/core/workspace'
import { BrowserViewer } from '@mastra/browser-viewer'

const workspace = new Workspace({
  sandbox: new LocalSandbox({
    workingDirectory: './workspace',
  }),
  browser: new BrowserViewer({
    cli: 'browser-use',
    headless: false,
  }),
})

const browserAgent = new Agent({
  id: 'browser-agent',
  model: '__GATEWAY_OPENAI_MODEL__',
  workspace,
  instructions: `You are a web automation assistant.
Use browser-use commands to navigate and interact with websites.`,
  memory: new Memory(),
})

export const mastra = new Mastra({
  agents: { browserAgent },
  storage: new LibSQLStore({
    id: 'mastra-storage',
    url: 'file:./mastra.db',
  }),
})
```

当 Agent 运行浏览器 CLI 命令时，Mastra 会自动启动 Chrome，将 CDP 连接信息传给 CLI，并开始向 Studio 实时传输浏览器画面。使用 Browser Use 时，Agent 可以通过 stdin 传入 Python 代码：

```bash
browser-use <<'PY'
print("Connected to the managed browser")
PY
```

## 工作原理 {/* #how-it-works */}

1. Agent 调用 `workspace_execute_command`，并传入浏览器 CLI 命令。
1. Mastra 识别 CLI 命令，如果 Chrome 尚未运行，就通过 Playwright 启动它。
1. Mastra 将 CDP URL 注入命令，使 CLI 连接到受管理的浏览器。
1. 浏览器画面帧通过页面级 CDP 会话流式传输到 Studio。

## 支持的 CLI {/* #supported-clis */}

BrowserViewer 支持三种 CLI Provider。每种 CLI 都需要在 Workspace 环境中单独安装，并各自发布了一个[技能](/docs/sandbox/skills)，供 Agent 了解其命令和 Workflow。

将 `cli` 选项设为 Agent 使用的 CLI：

```typescript
const viewer = new BrowserViewer({
  cli: 'browser-use',
  headless: false,
})
```

### `agent-browser` {/* #agent-browser */}

```bash
npm install -g agent-browser
npx skills add vercel-labs/agent-browser
```

CDP 参数：`--cdp`

### `browser-use` {/* #browser-use */}

```bash
pip install browser-use
npx skills add browser-use/browser-use --skill browser-use
```

直接通过 stdin 调用时（使用 `browser-use`、`browseruse`、`browser` 或 `bu`，后面可接 `<` 重定向或 heredoc），Mastra 会将 `BU_CDP_WS` 设为受管理浏览器的 CDP URL，并将 `BU_NAME` 设为固定的守护进程名称。该名称由会话线程和浏览器端点的组合唯一确定，因此重复调用会复用同一个守护进程，不同线程或端点仍彼此隔离。Mastra 会原样保留 stdin 脚本，不添加 CLI 参数。

为保持兼容性，Mastra 仍会向旧版子命令注入 `--cdp-url` 和 `--session`。通过 stdin 调用时不会添加这两个参数。

### `browse` {/* #browse */}

```bash
npm install -g browse
browse skills install
```

CDP 参数：`--ws`。有关所有配置选项、高级连接模式和方法详情，请参阅 [BrowserViewer 参考文档](/reference/browser/browser-viewer)。
