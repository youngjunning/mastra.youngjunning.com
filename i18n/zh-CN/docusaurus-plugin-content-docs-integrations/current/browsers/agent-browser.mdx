# AgentBrowser

`@mastra/agent-browser` 包通过 Playwright 实现浏览器自动化，并优先利用无障碍信息定位元素。它通过页面无障碍树中的引用标识元素，使交互在不同页面布局下都能可靠运行。

## 何时使用 AgentBrowser {/* #when-to-use-agentbrowser */}

如果有以下需求，可以使用 AgentBrowser：

- 通过无障碍树中的引用可靠地定位元素
- 细粒度控制浏览器操作
- 使用 Playwright 可靠的自动化能力
- 支持键盘快捷键和复杂交互

## 快速入门 {/* #quickstart */}

安装此软件包：

```bash npm2yarn
npm install @mastra/agent-browser
```

创建浏览器实例并将其分配给一个 Agent：

```typescript title="src/mastra/agents/browser-agent.ts"
import { Agent } from '@mastra/core/agent'
import { AgentBrowser } from '@mastra/agent-browser'

const browser = new AgentBrowser({
  headless: false,
})

export const browserAgent = new Agent({
  id: 'browser-agent',
  name: 'Browser Agent',
  model: '__GATEWAY_OPENAI_MODEL__',
  browser,
  instructions: `You are a web automation assistant.

When interacting with pages:
1. Use browser_snapshot to get the current page state and element refs
2. Use the refs (like @e1, @e2) to target elements for clicks and typing
3. After actions, take another snapshot to verify the result`,
})
```

:::note

默认情况下，AgentBrowser 会在本地启动浏览器，需要通过 Playwright 安装 Chromium 二进制文件。安装 `@mastra/agent-browser` 时，通常会自动下载该文件。如果浏览器启动失败并提示 `"browser executable is missing"`，请运行 `npx playwright install chromium`。如果通过 [`cdpUrl`](/reference/browser/agent-browser) 选项连接到远程浏览器，则由远程浏览器提供 Chromium。

:::

## 截图 {/* #screenshots */}

Agent 使用 `browser_screenshot` Tool 时，该 Tool 会截取当前页面的 PNG 图像，并以图像内容的形式返回，使支持视觉输入的 Model 可以直接解读。

需要查看页面的视觉效果时，请使用截图，例如评估图像、布局或颜色。需要获取文本或结构化数据时，请使用 `browser_snapshot`。

要为不支持视觉输入的 Model 禁用截图 Tool，请使用 `excludeTools`：

```typescript
const browser = new AgentBrowser({
  headless: false,
  excludeTools: ['browser_screenshot'],
})
```

## 元素引用 {/* #element-refs */}

AgentBrowser 使用无障碍树中的引用标识元素。Agent 调用 `browser_snapshot` 时，会收到页面的文本表示，其中包含 `@e1`、`@e2` 等引用。随后，Agent 可以将这些引用传给其他 Tool，与相应的元素交互。

## 录制 {/* #recording */}

可以为 AgentBrowser 启用处于 Beta 阶段的浏览器录制 Tool：

```typescript
const browser = new AgentBrowser({
  headless: false,
  recording: {
    outputDir: './browser-recordings',
  },
})
```

启用后，`browser_record` 和 `browser_record_caption` 会加入 Agent 的 Tool 集合。详情请参阅[浏览器录制（Beta）](/docs/browser#record-browser-sessions)。所有配置选项和 Tool 的详细信息请参阅 [AgentBrowser 参考文档](/reference/browser/agent-browser)。
