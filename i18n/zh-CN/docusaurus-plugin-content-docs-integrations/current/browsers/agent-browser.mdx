# Agent浏览器

这`@mastra/agent-browser`包使用 Playwright 和可访问性优先的元素定位来提供浏览器自动化。元素由页面的辅助功能树中的引用来标识，从而使跨不同页面布局的交互变得可靠。

## 何时使用 AgentBrowser {/* #when-to-use-agentbrowser */}

当您需要时使用 AgentBrowser：

* 通过可访问性参考进行可靠的元素定位
* 对浏览器操作的细粒度控制
* Playwright 可靠的自动化能力
* 支持键盘快捷键和复杂的交互

## 快速入门 {/* #quickstart */}

安装包：

```bash npm2yarn
npm install @mastra/agent-browser
```

创建一个浏览器实例并将其分配给Agent：

```typescript title="src/mastra/agents/browser-agent.ts"
import { Agent } from '@mastra/core/agent'
import { AgentBrowser } from '@mastra/agent-browser'

const browser = new AgentBrowser({
  headless: false,
})

export const browserAgent = new Agent({
  id: 'browser-agent',
  name: 'Browser Agent',
  model: '__GATEWAY_OPENAI_MODEL__',
  browser,
  instructions: `You are a web automation assistant.

When interacting with pages:
1. Use browser_snapshot to get the current page state and element refs
2. Use the refs (like @e1, @e2) to target elements for clicks and typing
3. After actions, take another snapshot to verify the result`,
})
```

：：：笔记

对于本地启动（默认），AgentBrowser 需要通过 Playwright 安装 Chromium 二进制文件。通常在安装时会自动下载`@mastra/agent-browser`. If launching the browser fails with `"browser executable is missing"`, run `npx playwright install chromium`. If you connect to a remote browser using the [`cdpUrl`](/reference/browser/agent-browser) option, the remote browser provides Chromium.

## 截图 {/* #screenshots */}

当Agent使用`browser_screenshot` tool, it captures a PNG image of the current page and returns it as image content that vision-capable models can interpret directly.

当您需要目视检查页面时，例如评估图像、布局或颜色，请使用屏幕截图。对于文本或结构化数据，请使用`browser_snapshot` instead.

要禁用不支持视觉的模型的屏幕截图Tool，请使用`excludeTools`:

```typescript
const browser = new AgentBrowser({
  headless: false,
  excludeTools: ['browser_screenshot'],
})
```

## 元素参考 {/* #element-refs */}

AgentBrowser 使用可访问性树引用来标识元素。当Agent打电话时`browser_snapshot`, it receives a text representation of the page with refs like `@e1`, `@e2`, etc. The agent then uses these refs with other tools to interact with elements.

## 记录 {/* #recording */}

AgentBrowser 可以选择 Beta 浏览器记录Tool：

```typescript
const browser = new AgentBrowser({
  headless: false,
  recording: {
    outputDir: './browser-recordings',
  },
})
```

这增加了`browser_record` and `browser_record_caption` to the agent's toolset. See [Browser recording (Beta)](/docs/browser#record-browser-sessions) for details. See [AgentBrowser reference](/reference/browser/agent-browser) for all configuration options and tool details.
