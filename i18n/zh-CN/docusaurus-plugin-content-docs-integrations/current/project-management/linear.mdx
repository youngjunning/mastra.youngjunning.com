# 线性

为Agent提供Tool来搜索、创建和更新问题，并通过 Mastra Connect 管理 Linear 中的项目、周期、注释和标签。每个Tool调用都会通过 Mastra 平台，该平台会添加连接的凭据。您的应用程序从不存储 Linear 凭据。

## 连接 {/* #connect */}

在开始之前，请完成[Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect`并配置您的平台项目。

### 连接账户 {/* #connect-an-account */}

从包含您的目录的目录运行此命令`.env` file:

```bash
mastra connect add linear
```

CLI 将引导您完成 Linear 的授权并等待连接激活。

### 向Agent添加Tool {/* #add-tools-to-an-agent */}

经过[`tools()`](/reference/connect/tools) to the agent and select the `linear` provider:

```typescript title="src/mastra/agents/linear-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const linearAgent = new Agent({
  id: 'linear-agent',
  name: 'Linear agent',
  instructions:
    'You help people search, create, and update issues, and manage projects, cycles, comments, and labels in Linear.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['linear'] }),
})
```

Agent获得 46 个线性Tool，其中包含诸如`linear_add_issue_label`. See [Linear tools](/reference/connect/providers#linear) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
