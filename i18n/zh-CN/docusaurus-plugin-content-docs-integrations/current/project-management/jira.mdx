# Jira

通过 Mastra Connect 为 Agent 提供可在 Jira 中搜索、创建、更新和转换议题状态，并管理评论、工时日志和议题链接的 Tool。每次 Tool 调用都会经过 Mastra 平台，由平台添加该连接的凭据；你的应用不会存储 Jira 凭据。

## 连接 {/* #connect */}

开始前，请先完成 [Connect 设置](/docs/mastra-platform/connect#get-started)，安装 `@mastra/connect` 并配置 Mastra 平台项目。

### 连接账户 {/* #connect-an-account */}

在包含 `.env` 文件的目录中运行以下命令：

```bash
mastra connect add jira
```

CLI 会引导你完成 Jira 的授权，并等待连接激活。

### 向 Agent 添加 Tool {/* #add-tools-to-an-agent */}

将 [`tools()`](/reference/connect/tools) 传给 Agent，并选择 `jira` Provider：

```typescript title="src/mastra/agents/jira-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const jiraAgent = new Agent({
  id: 'jira-agent',
  name: 'Jira agent',
  instructions:
    'You help people search, create, update, and transition issues, and manage comments, worklogs, and issue links in Jira.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['jira'] }),
})
```

Agent 可使用 38 个 Jira Tool，Tool key 包括 `jira_add_comment`。完整列表请参阅 [Jira Tool](/reference/connect/providers#jira)；如需限制可用 Tool，或要求每次调用在运行前获得批准，请参阅 [`tools()` 参数](/reference/connect/tools#parameters)。
