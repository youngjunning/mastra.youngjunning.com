# 吉拉

为Agent提供Tool来搜索、创建、更新和转换问题，并通过 Mastra Connect 管理 Jira 中的评论、工作日志和问题链接。每个Tool调用都会通过 Mastra 平台，该平台会添加连接的凭据。您的应用程序从不存储 Jira 凭据。

## 连接 {/* #connect */}

在开始之前，请完成[Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect`并配置您的平台项目。

### 连接账户 {/* #connect-an-account */}

从包含您的目录的目录运行此命令`.env` file:

```bash
mastra connect add jira
```

CLI 将引导您完成 Jira 的授权并等待连接激活。

### 向Agent添加Tool {/* #add-tools-to-an-agent */}

经过[`tools()`](/reference/connect/tools) to the agent and select the `jira` provider:

```typescript title="src/mastra/agents/jira-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const jiraAgent = new Agent({
  id: 'jira-agent',
  name: 'Jira agent',
  instructions:
    'You help people search, create, update, and transition issues, and manage comments, worklogs, and issue links in Jira.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['jira'] }),
})
```

Agent获得 38 个 Jira Tool，其中包含以下密钥：`jira_add_comment`. See [Jira tools](/reference/connect/providers#jira) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
