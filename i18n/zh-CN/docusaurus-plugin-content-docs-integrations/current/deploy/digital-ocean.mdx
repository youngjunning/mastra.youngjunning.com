# 数字海洋

本指南涵盖 Digital Ocean 的应用程序平台和 Droplet。这些产品都有自己的优势，适合不同类型的项目和开发人员的专业知识。读[Digital Ocean's comparison](https://www.digitalocean.com/community/conceptual-articles/digitalocean-app-platform-vs-doks-vs-droplets)了解差异并为您的项目选择最佳选项。

:::注意
本指南涵盖了部署[Mastra server](/docs/server/overview). If you're using a [server adapter](/docs/server/server-adapters)或者[网络框架](/docs/deployment/web-framework)，按照您通常为该框架部署的方式进行部署。
:::

## 开始之前 {/* #before-you-begin */}

你需要一个[Mastra application](/docs) and a [Digital Ocean](https://www.digitalocean.com/) account.

这**App Platform** uses an ephemeral filesystem, so any storage you configure (including observability storage) must be hosted externally. If you're using [LibSQLStore](/integrations/databases/libsql) with a file URL, switch to a remotely hosted database.

## 应用平台 {/* #app-platform */}

设置项目后，将其推送到您选择的远程 Git Provider（例如 GitHub）。

<Steps>
  <StepItem>
    关注官方[App Platform quickstart](https://docs.digitalocean.com/products/app-platform/getting-started/quickstart/#create-an-app). It'll guide you through connecting your repository, selecting the branch to deploy from, and configuring the source directory if necessary.
  </StepItem>

  <StepItem>
    确保检测到“Node.js”构建。您需要配置构建命令。根据您的包管理器进行设置：

    ```bash npm2yarn
    npm run build
    ```
  </StepItem>

  <StepItem>
    为您的 Mastra 应用程序添加任何所需的环境变量。这包括 API 密钥、数据库 URL 和其他配置值。
  </StepItem>

  <StepItem>
    您的应用程序将自动构建和部署。 Digital Ocean 将为您提供一个 URL 来访问已部署的应用程序。
  </StepItem>

  <StepItem>
    您现在可以通过 HTTP 调用 Mastra 端点。

    :::警告
    设置[authentication](/docs/auth/overview) before exposing your endpoints publicly.
    :::
  </StepItem>
</Steps>

## 飞沫 {/* #droplets */}

### 先决条件 {/* #prerequisites */}

* 运行 Ubuntu 24.04 LTS 或更高版本的 Droplet
* 带有 A 记录的域名指向您的 Droplet
* 配置的反向Agent（例如，使用[nginx](https://nginx.org/))
* 配置的 SSL 证书（例如，使用[Let's Encrypt](https://letsencrypt.org/))
* 安装在 Droplet 上的 Node.js 22.13.0 或更高版本

### 部署 {/* #deploy */}

设置项目后，将其推送到您选择的远程 Git Provider（例如 GitHub）。连接到您的 Droplet 并确保`git` is installed.

<Steps>
  <StepItem>
    克隆您的存储库：

    <Tabs>
      <TabItem value="public" label="Public Repository">
        ```bash
        git clone https://github.com/<your-username>/<your-repository>.git
        ```
      </TabItem>

      <TabItem value="private" label="Private Repository">
        ```bash
        git clone https://<your-username>:<your-personal-access-token>@github.com/<your-username>/<your-repository>.git
        ```
      </TabItem>
    </Tabs>

    导航到存储库目录：

    ```bash
    cd "<your-repository>"
    ```
  </StepItem>

  <StepItem>
    安装项目依赖项：

    ```bash npm2yarn
    npm install
    ```
  </StepItem>

  <StepItem>
    为您的 Mastra 应用程序设置所需的环境变量。创建一个`.env` file in the root of your project:

    ```bash
    touch .env
    ```

    编辑`.env` file and add your environment variables:

    ```bash title=".env"
    OPENAI_API_KEY=your-api-key
    ```
  </StepItem>

  <StepItem>
    构建项目：

    ```bash npm2yarn
    npm run build
    ```

    这将在以下位置创建 Mastra 服务器的生产版本`.mastra/output` directory.
  </StepItem>

  <StepItem>
    您可以运行[Mastra Server](/docs/deployment/mastra-server) by running the `mastra start` command:

    ```bash
    mastra start
    ```

    :::注意
    默认情况下，您的 Mastra 应用程序将在端口 4111 上运行。确保您的反向Agent配置为将请求转发到此端口。
    :::
  </StepItem>

  <StepItem>
    您现在可以通过 HTTP 调用 Mastra 端点。

    :::警告
    设置[authentication](/docs/auth/overview) before exposing your endpoints publicly.
    :::
  </StepItem>
</Steps>
