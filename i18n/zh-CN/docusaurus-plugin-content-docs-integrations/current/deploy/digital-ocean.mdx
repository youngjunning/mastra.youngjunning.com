# DigitalOcean

本指南介绍 DigitalOcean 的 App Platform 和 Droplets。两种服务各有优势，适合不同类型的项目和不同技术经验的开发者。阅读 [DigitalOcean 的方案对比](https://www.digitalocean.com/community/conceptual-articles/digitalocean-app-platform-vs-doks-vs-droplets)，了解两者的差异，并为你的项目选择最合适的方案。

:::note
本指南介绍如何部署 [Mastra 服务器](/docs/server/overview)。如果你使用的是[服务器适配器](/docs/server/server-adapters)或 [Web 框架](/docs/deployment/web-framework)，请按相应框架的常规方式部署。
:::

## 开始之前 {/* #before-you-begin */}

你需要一个 [Mastra 应用](/docs)和一个 [DigitalOcean](https://www.digitalocean.com/) 账号。

**App Platform** 使用临时文件系统，因此你配置的所有存储（包括 Observability 存储）都必须托管在外部。如果你的 [LibSQLStore](/integrations/databases/libsql) 使用文件 URL，请改用远程托管的数据库。

## App Platform {/* #app-platform */}

配置好项目后，将其推送到你选择的远程 Git Provider（例如 GitHub）。

<Steps>
  <StepItem>
    按照官方的 [App Platform 快速入门指南](https://docs.digitalocean.com/products/app-platform/getting-started/quickstart/#create-an-app)操作。该指南会带你连接代码仓库、选择用于部署的分支，并在需要时配置源码目录。
  </StepItem>

  <StepItem>
    确保平台将构建类型识别为“Node.js”。接下来，根据所用的包管理器配置构建命令：

    ```bash npm2yarn
    npm run build
    ```
  </StepItem>

  <StepItem>
    添加 Mastra 应用所需的环境变量，包括 API 密钥、数据库 URL 和其他配置值。
  </StepItem>

  <StepItem>
    应用会自动构建并部署。DigitalOcean 会提供一个 URL，供你访问已部署的应用。
  </StepItem>

  <StepItem>
    现在可以通过 HTTP 调用你的 Mastra 端点。

    :::warning
    在向公众开放端点之前，请配置[身份验证](/docs/auth/overview)。
    :::
  </StepItem>
</Steps>

## Droplets {/* #droplets */}

### 前提条件 {/* #prerequisites */}

- 一台运行 Ubuntu 24.04 LTS 或更高版本的 Droplet
- 一个域名，其 A 记录指向你的 Droplet
- 已配置反向代理（例如使用 [nginx](https://nginx.org/)）
- 已配置 SSL 证书（例如使用 [Let's Encrypt](https://letsencrypt.org/)）
- 已在 Droplet 上安装 Node.js 22.13.0 或更高版本

### 部署 {/* #deploy */}

配置好项目后，将其推送到你选择的远程 Git Provider（例如 GitHub）。连接到你的 Droplet，并确认已安装 `git`。

<Steps>
  <StepItem>
    克隆你的仓库：

    <Tabs>
      <TabItem value="public" label="Public Repository">
        ```bash
        git clone https://github.com/<your-username>/<your-repository>.git
        ```
      </TabItem>

      <TabItem value="private" label="Private Repository">
        ```bash
        git clone https://<your-username>:<your-personal-access-token>@github.com/<your-username>/<your-repository>.git
        ```
      </TabItem>
    </Tabs>

    进入仓库目录：

    ```bash
    cd "<your-repository>"
    ```
  </StepItem>

  <StepItem>
    安装项目依赖：

    ```bash npm2yarn
    npm install
    ```
  </StepItem>

  <StepItem>
    设置 Mastra 应用所需的环境变量。先在项目根目录下创建 `.env` 文件：

    ```bash
    touch .env
    ```

    编辑 `.env` 文件，添加你的环境变量：

    ```bash title=".env"
    OPENAI_API_KEY=your-api-key
    ```
  </StepItem>

  <StepItem>
    构建项目：

    ```bash npm2yarn
    npm run build
    ```

    此命令会在 `.mastra/output` 目录中生成 Mastra 服务器的生产构建产物。
  </StepItem>

  <StepItem>
    运行 `mastra start` 命令即可启动 [Mastra 服务器](/docs/deployment/mastra-server)：

    ```bash
    mastra start
    ```

    :::note
    Mastra 应用默认监听 4111 端口。请确保反向代理已配置为将请求转发到该端口。
    :::
  </StepItem>

  <StepItem>
    现在可以通过 HTTP 调用你的 Mastra 端点。

    :::warning
    在向公众开放端点之前，请配置[身份验证](/docs/auth/overview)。
    :::
  </StepItem>
</Steps>
