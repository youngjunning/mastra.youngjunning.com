# 网络化

使用`@mastra/deployer-netlify`在 Netlify 上部署 Mastra 服务器。部署程序捆绑您的代码并生成`.netlify`符合 Netlify 的目录[框架API](https://docs.netlify.com/build/frameworks/frameworks-api/)，准备部署。您可以部署为无服务器功能（默认）或部署为[边缘函数](https://docs.netlify.com/build/edge-functions/overview/)以获得更低的延迟和更长的执行时间。

:::注意
本指南涵盖了部署[Mastra server](/docs/server/overview). If you're using a [server adapter](/docs/server/server-adapters) or [web framework](/docs/deployment/web-framework), deploy the way you normally would for that framework.
:::

## 开始之前 {/* #before-you-begin */}

你需要一个[Mastra application](/docs) and a [Netlify](https://www.netlify.com/) account.

:::警告
Netlify 函数使用临时文件系统，因此您配置的任何存储（包括可观察性存储）都必须托管在外部。如果您正在使用[LibSQLStore](/integrations/databases/libsql) with a file URL, switch to a remotely hosted database.
:::

## 安装 {/* #installation */}

添加`@mastra/deployer-netlify` package to your project:

```bash npm2yarn
npm install @mastra/deployer-netlify@latest
```

进口[`NetlifyDeployer`](/reference/deployer/netlify) and set it as the deployer in your Mastra configuration:

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
// highlight-next-line
import { NetlifyDeployer } from '@mastra/deployer-netlify'

export const mastra = new Mastra({
  // highlight-next-line
  deployer: new NetlifyDeployer(),
})
```

要部署为边缘函数，请传递`{ target: 'edge' }`:

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { NetlifyDeployer } from '@mastra/deployer-netlify'

export const mastra = new Mastra({
  deployer: new NetlifyDeployer({
    target: 'edge',
  }),
})
```

边缘函数在 Deno 上最靠近用户的边缘运行。它们没有硬执行超时（只有 CPU 时间限制），这使它们更适合运行时间较长的 AI Workflow程。请参阅[constructor options](/reference/deployer/netlify#constructor-options) for details.

创建一个`netlify.toml` file with the following contents in your project root:

```toml
[build]
command = "mastra build"
```

## 部署 {/* #deploy */}

设置项目后，将其推送到您选择的远程 Git Provider（例如 GitHub）。

<Steps>
  <StepItem>
    将您的存储库连接到 Netlify。在设置过程中，Netlify 会检测您的`netlify.toml` file and set the build command to `mastra build`.

    ：：：笔记

    请记住设置运行应用程序所需的环境变量（例如您的[model provider](/models/providers) API key).

    :::
  </StepItem>

  <StepItem>
    准备好后，单击**Deploy** button and wait for the first deployment to complete. It'll tell you that one
    function has been deployed.
  </StepItem>

  <StepItem>
    验证您的部署`https://<random-slug>.netlify.app/api/agents`, which should return a JSON list of your agents.

    自从[Mastra server](/docs/server/overview) prefixes every API endpoint with `/api`, you have to add it to your URLs when making requests.

    ：：：笔记

    Netlify 功能通常部署在`https://<random-slug>.netlify.app/.netlify/functions/api`. The `NetlifyDeployer` redirects any request from `/*` to `/.netlify/functions/api/:splat`, so you don't need to include the `.netlify/functions` prefix in your URLs.

    :::
  </StepItem>

  <StepItem>
    您现在可以通过 HTTP 调用 Mastra 端点。

    :::警告
    设置[authentication](/docs/auth/overview) before exposing your endpoints publicly.
    :::
  </StepItem>
</Steps>
