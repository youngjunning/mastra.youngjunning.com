# Netlify

使用 `@mastra/deployer-netlify` 将 Mastra 服务器部署到 Netlify。部署器会打包代码，并生成符合 Netlify [Frameworks API](https://docs.netlify.com/build/frameworks/frameworks-api/) 要求的 `.netlify` 目录，可直接用于部署。默认部署为无服务器函数，也可以部署为[边缘函数](https://docs.netlify.com/build/edge-functions/overview/)，以降低延迟并延长执行时间。

:::note
本指南介绍如何部署 [Mastra 服务器](/docs/server/overview)。如果使用了[服务器适配器](/docs/server/server-adapters)或 [Web 框架](/docs/deployment/web-framework)，请按对应框架的常规方式部署。
:::

## 开始之前 {/* #before-you-begin */}

你需要一个 [Mastra 应用](/docs)和一个 [Netlify](https://www.netlify.com/) 账号。

:::warning
Netlify Functions 使用临时文件系统，因此你配置的所有存储（包括 Observability 存储）都必须由外部服务托管。如果你通过文件 URL 使用 [LibSQLStore](/integrations/databases/libsql)，请改用远程托管的数据库。
:::

## 安装 {/* #installation */}

将 `@mastra/deployer-netlify` 包添加到项目中：

```bash npm2yarn
npm install @mastra/deployer-netlify@latest
```

导入 [`NetlifyDeployer`](/reference/deployer/netlify)，并在 Mastra 配置中将其设为部署器：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
// highlight-next-line
import { NetlifyDeployer } from '@mastra/deployer-netlify'

export const mastra = new Mastra({
  // highlight-next-line
  deployer: new NetlifyDeployer(),
})
```

如果要部署为边缘函数，请传入 `{ target: 'edge' }`：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { NetlifyDeployer } from '@mastra/deployer-netlify'

export const mastra = new Mastra({
  deployer: new NetlifyDeployer({
    target: 'edge',
  }),
})
```

边缘函数在距离用户最近的边缘节点上通过 Deno 运行。它们只限制 CPU 时间，没有硬性的执行超时限制，因此更适合运行时间较长的 AI Workflow。详情请参阅[构造函数选项](/reference/deployer/netlify#constructor-options)。

在项目根目录中创建 `netlify.toml` 文件，并写入以下内容：

```toml
[build]
command = "mastra build"
```

## 部署 {/* #deploy */}

配置好项目后，将代码推送到你选择的远程 Git 托管平台（例如 GitHub）。

<Steps>
  <StepItem>
    将代码仓库连接到 Netlify。配置过程中，Netlify 会检测 `netlify.toml` 文件，并将构建命令设为 `mastra build`。

    :::note

    请记得设置运行应用所需的环境变量，例如 [Model Provider](/models/providers) 的 API 密钥。

    :::
  </StepItem>

  <StepItem>
    准备就绪后，点击 **Deploy** 按钮并等待首次部署完成。Netlify 会提示你有一个
    function has been deployed.
  </StepItem>

  <StepItem>
    访问 `https://<random-slug>.netlify.app/api/agents` 验证部署；该地址应返回 Agent 的 JSON 列表。

    [Mastra 服务器](/docs/server/overview)会为每个 API 端点添加 `/api` 前缀，因此发起请求时，URL 中必须包含此前缀。

    :::note

    Netlify Functions 通常部署在 `https://<random-slug>.netlify.app/.netlify/functions/api`。`NetlifyDeployer` 会将来自 `/*` 的所有请求重定向到 `/.netlify/functions/api/:splat`，因此 URL 中无需包含 `.netlify/functions` 前缀。

    :::
  </StepItem>

  <StepItem>
    现在可以通过 HTTP 调用 Mastra 端点。

    :::warning
    请在公开端点前配置[身份验证](/docs/auth/overview)。
    :::
  </StepItem>
</Steps>
