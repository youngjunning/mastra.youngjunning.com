# Cloudflare

使用 `@mastra/deployer-cloudflare` 将 Mastra 服务器部署到 Cloudflare Workers。部署器会打包代码，并生成符合 Cloudflare [Wrangler 配置规范](https://developers.cloudflare.com/workers/wrangler/configuration/)的 `wrangler.jsonc` 文件，无需额外配置即可部署。

:::note

如果使用[服务器适配器](/docs/server/server-adapters)或 [Web 框架](/docs/deployment/web-framework)，请按该框架的常规方式部署。

:::

## 开始之前 {/* #before-you-begin */}

你需要一个 [Mastra 应用](/docs)和一个 [Cloudflare](https://cloudflare.com/) 账号。

:::warning
Cloudflare Workers 使用临时文件系统，因此配置的所有存储（包括 Observability 存储）都必须托管在外部。如果你为 [LibSQLStore](/integrations/databases/libsql) 配置了文件 URL，请改用远程托管的数据库。
:::

## 安装 {/* #installation */}

将 `@mastra/deployer-cloudflare` 包添加到项目中：

```bash npm2yarn
npm install @mastra/deployer-cloudflare@latest
```

导入 [`CloudflareDeployer`](/reference/deployer/cloudflare)，并在 Mastra 配置中将其设为部署器：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
// highlight-next-line
import { CloudflareDeployer } from '@mastra/deployer-cloudflare'

export const mastra = new Mastra({
  // highlight-start
  deployer: new CloudflareDeployer({
    name: 'your-project-name',
    vars: {
      NODE_ENV: 'production',
    },
  }),
  // highlight-end
})
```

要在本地测试 Cloudflare Worker，还需安装 [`wrangler` 命令行工具](https://developers.cloudflare.com/workers/wrangler/install-and-update/)：

```bash npm2yarn
npm install -D wrangler
```

## 用法 {/* #usage */}

配置好项目后，将其推送到所选的远程 Git Provider（例如 GitHub）。

<Steps>
  <StepItem>
    将仓库连接到 Cloudflare。在 "Workers & Pages" 控制面板中选择 **Create application**，然后在下一步选择 Git Provider。继续完成设置，并选择要部署的仓库。

    :::note

    请记得设置运行应用所需的环境变量，例如 [Model Provider](/models/providers) 的 API 密钥。可以使用 `npx wrangler secret bulk .env` 上传 `.env` 文件中的机密值。详情请参阅[机密值](/reference/deployer/cloudflare#secrets)。

    :::
  </StepItem>

  <StepItem>
    准备就绪后，点击 **Deploy** 按钮，等待首次部署完成。
  </StepItem>

  <StepItem>
    访问 `https://<your-project-name>.<slug>.workers.dev/api/agents`，试用刚部署的函数。页面应返回列出所有可用 Agent 的 JSON 响应。

    [Mastra 服务器](/docs/server/overview)会为所有 API 端点添加 `/api` 前缀，因此发起请求时，URL 必须包含此前缀。
  </StepItem>

  <StepItem>
    现在可以通过 HTTP 调用 Mastra 端点。

    :::note

    对外公开端点前，请先配置[身份验证](/docs/auth/overview)。

    :::
  </StepItem>
</Steps>
