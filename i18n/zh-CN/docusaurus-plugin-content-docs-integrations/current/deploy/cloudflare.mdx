# 云耀

使用`@mastra/deployer-cloudflare`将您的 Mastra 服务器部署到 Cloudflare Workers。部署程序捆绑您的代码并生成`wrangler.jsonc`符合 Cloudflare 的文件[牧马人配置](https://developers.cloudflare.com/workers/wrangler/configuration/)，无需额外配置即可部署。

：：：笔记

如果您使用的是[server adapter](/docs/server/server-adapters) or [web framework](/docs/deployment/web-framework), deploy the way you normally would for that framework.

:::

## 开始之前 {/* #before-you-begin */}

你需要一个[Mastra application](/docs) and a [Cloudflare](https://cloudflare.com/) account.

:::警告
Cloudflare Workers 使用临时文件系统，因此您配置的任何存储（包括可观察性存储）都必须托管在外部。如果您正在使用[LibSQLStore](/integrations/databases/libsql) with a file URL, switch to a remotely hosted database.
:::

## 安装 {/* #installation */}

添加`@mastra/deployer-cloudflare` package to your project:

```bash npm2yarn
npm install @mastra/deployer-cloudflare@latest
```

进口[`CloudflareDeployer`](/reference/deployer/cloudflare) and set it as the deployer in your Mastra configuration:

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
// highlight-next-line
import { CloudflareDeployer } from '@mastra/deployer-cloudflare'

export const mastra = new Mastra({
  // highlight-start
  deployer: new CloudflareDeployer({
    name: 'your-project-name',
    vars: {
      NODE_ENV: 'production',
    },
  }),
  // highlight-end
})
```

要在本地测试您的 Cloudflare Worker，还需安装[`wrangler` CLI](https://developers.cloudflare.com/workers/wrangler/install-and-update/):

```bash npm2yarn
npm install -D wrangler
```

## 用法 {/* #usage */}

设置项目后，将其推送到您选择的远程 Git Provider（例如 GitHub）。

<Steps>
  <StepItem>
    将您的存储库连接到 Cloudflare。在“工作人员和页面”仪表板上，选择**Create application** and choose your Git provider in the next step. Continue with the setup process and select the repository you want to deploy.

    ：：：笔记

    请记住设置运行应用程序所需的环境变量（例如您的[model provider](/models/providers) API key). You can upload secrets from your `.env` file using `npx wrangler secret bulk .env`. See [Secrets](/reference/deployer/cloudflare#secrets) for details.

    :::
  </StepItem>

  <StepItem>
    准备好后，单击**Deploy** button and wait for the first deployment to complete.
  </StepItem>

  <StepItem>
    尝试您新部署的功能，方法是：`https://<your-project-name>.<slug>.workers.dev/api/agents`. You should get a JSON response listing all available agents.

    自从[Mastra server](/docs/server/overview) prefixes every API endpoint with `/api`, you have to add it to your URLs when making requests.
  </StepItem>

  <StepItem>
    您现在可以通过 HTTP 调用 Mastra 端点。

    ：：：笔记

    设置[authentication](/docs/auth/overview) before exposing your endpoints publicly.

    :::
  </StepItem>
</Steps>
