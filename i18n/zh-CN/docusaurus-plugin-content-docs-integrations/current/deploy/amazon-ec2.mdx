# 亚马逊EC2

将您的 Mastra 服务器部署到 Amazon EC2。服务器在您管理的基础架构上运行，并且可以支持长时间运行的Agent和Workflow程。

:::注意
本指南涵盖了部署[Mastra server](/docs/server/overview). If you're using a [服务器适配器](/docs/server/server-adapters)或者[网络框架](/docs/deployment/web-framework)，按照您通常为该框架部署的方式进行部署。
:::

## 开始之前 {/* #before-you-begin */}

你需要：

* 一个[Mastra application](/docs)
* 一个[EC2](https://aws.amazon.com/ec2/) instance (Ubuntu or Amazon Linux) with Git and Node.js 22.13.0+ installed

对于生产，您还需要：

* 指向您的实例的域名（SSL 证书所需）
* 您的域的 SSL 证书（例如，使用[Certbot](https://certbot.eff.org/) with Let's Encrypt)
* 反向Agent（例如，[nginx](https://nginx.org/)) to forward traffic to your application

## 部署 {/* #deploy */}

<Steps>
  <StepItem>
    连接到您的 EC2 实例并克隆您的存储库：

    <Tabs>
      <TabItem value="public" label="Public Repository">
        ```bash
        git clone https://github.com/<your-username>/<your-repository>.git
        ```
      </TabItem>

      <TabItem value="private" label="Private Repository">
        ```bash
        git clone git@github.com:<your-username>/<your-repository>.git
        ```
      </TabItem>
    </Tabs>

    导航到存储库目录：

    ```bash
    cd "<your-repository>"
    ```
  </StepItem>

  <StepItem>
    安装依赖项：

    ```bash npm2yarn
    npm install
    ```
  </StepItem>

  <StepItem>
    创建一个`.env` file and add your environment variables:

    ```bash
    touch .env
    ```

    请记住设置运行应用程序所需的环境变量（例如模型提供程序 API 密钥）：

    ```bash
    OPENAI_API_KEY=<your-openai-api-key>
    # Add other required environment variables
    ```
  </StepItem>

  <StepItem>
    构建应用程序：

    ```bash npm2yarn
    npm run build
    ```
  </StepItem>

  <StepItem>
    运行应用程序：

    ```bash
    node --env-file=".env" .mastra/output/index.mjs
    ```

    这是一个基本示例。在生产中，使用流程管理器，例如[PM2](https://pm2.keymetrics.io/) or [systemd](https://systemd.io/) to keep your application running and handle restarts.

    :::警告
    设置[authentication](/docs/auth/overview) before exposing your endpoints publicly.
    :::
  </StepItem>

  <StepItem>
    您的 Mastra 服务器现在正在端口 4111 上运行，但只能在本地访问。

    您可以在 EC2 安全组中开放 4111 端口进行直接访问，或者配置反向Agent（如 nginx）监听 80 和 443 端口并将请求转发到`http://localhost:4111`.

    在生产中，您应该使用反向Agent，以便可以配置 HTTPS。 HTTPS 会对流量进行加密，并且是大多数 Webhook 集成和Agent与之交互的外部服务所必需的。
  </StepItem>

  <StepItem>
    验证您的部署`https://<your-ec2-address>/api/agents`, which should return a JSON list of your agents.
  </StepItem>

  <StepItem>
    您现在可以通过 HTTP 调用 Mastra 端点。
  </StepItem>
</Steps>
