# Amazon EC2

将 Mastra 服务器部署到 Amazon EC2。服务器在你管理的基础设施上运行，可支持长时间运行的 Agent 和 Workflow。

:::note
本指南介绍如何部署 [Mastra 服务器](/docs/server/overview)。如果你使用了[服务器适配器](/docs/server/server-adapters)或 [Web 框架](/docs/deployment/web-framework)，请按所用框架的常规方式部署。
:::

## 开始之前 {/* #before-you-begin */}

你需要准备以下内容：

- 一个 [Mastra 应用](/docs)
- 一个已安装 Git 和 Node.js 22.13.0 或更高版本的 [EC2](https://aws.amazon.com/ec2/) 实例，系统为 Ubuntu 或 Amazon Linux

部署到生产环境时，还需要准备：

- 一个指向你的实例的域名，用于申请 SSL 证书
- 一张用于该域名的 SSL 证书，例如可通过 [Certbot](https://certbot.eff.org/) 获取 Let's Encrypt 证书
- 一个反向代理（例如 [nginx](https://nginx.org/)），用于将流量转发到你的应用

## 部署 {/* #deploy */}

<Steps>
  <StepItem>
    连接到你的 EC2 实例并克隆你的代码仓库：

    <Tabs>
      <TabItem value="public" label="Public Repository">
        ```bash
        git clone https://github.com/<your-username>/<your-repository>.git
        ```
      </TabItem>

      <TabItem value="private" label="Private Repository">
        ```bash
        git clone git@github.com:<your-username>/<your-repository>.git
        ```
      </TabItem>
    </Tabs>

    进入代码仓库目录：

    ```bash
    cd "<your-repository>"
    ```
  </StepItem>

  <StepItem>
    安装依赖项：

    ```bash npm2yarn
    npm install
    ```
  </StepItem>

  <StepItem>
    创建 `.env` 文件，并添加你的环境变量：

    ```bash
    touch .env
    ```

    请记得设置运行应用所需的环境变量，例如 Model Provider 的 API 密钥：

    ```bash
    OPENAI_API_KEY=<your-openai-api-key>
    # Add other required environment variables
    ```
  </StepItem>

  <StepItem>
    构建应用：

    ```bash npm2yarn
    npm run build
    ```
  </StepItem>

  <StepItem>
    运行应用：

    ```bash
    node --env-file=".env" .mastra/output/index.mjs
    ```

    这是一个基础示例。在生产环境中，请使用 [PM2](https://pm2.keymetrics.io/) 或 [systemd](https://systemd.io/) 等进程管理器，让应用持续运行并处理重启。

    :::warning
    在向公网开放端点之前，请先配置[身份验证](/docs/auth/overview)。
    :::
  </StepItem>

  <StepItem>
    你的 Mastra 服务器现已在 4111 端口运行，目前仅能从本机访问。

    您可以在 EC2 安全组中开放 4111 端口以便直接访问，也可以配置反向代理（如 nginx）监听 80 和 443 端口，并将请求转发到 `http://localhost:4111`。

    在生产环境中，建议使用反向代理，以便配置 HTTPS。HTTPS 会加密流量，而且大多数 Webhook 集成以及 Agent 与之交互的外部服务都要求使用 HTTPS。
  </StepItem>

  <StepItem>
    访问 `https://<your-ec2-address>/api/agents` 验证部署；该地址应返回 Agent 的 JSON 列表。
  </StepItem>

  <StepItem>
    现在可以通过 HTTP 调用 Mastra 端点。
  </StepItem>
</Steps>
