# 氖

将您的 Mastra 服务器部署为[Neon Function](https://neon.com/docs/compute/functions/overview)（一个长期运行的 Node.js 进程）在您的 Neon 分支上。该函数获取公共 HTTPS URL 并`DATABASE_URL`从分支的 Postgres 数据库注入。

霓虹灯功能是`fetch` handler. This guide uses the [Hono server adapter](/docs/server/server-adapters) rather than `mastra build` / `mastra start`。如果您使用的是[网络框架](/docs/deployment/web-framework)，按照您通常为该框架部署的方式进行部署。

Neon Functions 处于测试阶段，仅在 AWS 美国东部（俄亥俄州）可用（`aws-us-east-2`). You'll need to create your project in that region.

## 开始之前 {/* #before-you-begin */}

你需要：

* 一个[Mastra application](/docs)
* 一个[Neon](https://neon.com) account
* 一个霓虹灯项目`aws-us-east-2`
* Node.js`v22.13.0` or later

Neon 函数可以驱逐空闲隔离，因此内存和本地文件存储会丢失。使用[PostgresStore with Neon](/integrations/databases/neon) instead of [LibSQLStore](/integrations/databases/libsql) with a file URL. For workspace files, use [Neon Object Storage](/integrations/file-storage/neon) instead of [`LocalFilesystem`](/reference/workspace/local-filesystem).

## 安装 {/* #installation */}

安装[Neon CLI](https://neon.com/docs/cli/install):

```bash npm2yarn
npm install -g neon
```

添加 Hono 适配器、Hono 和`@neon/config`:

```bash npm2yarn
npm install @mastra/hono@latest hono @neon/config
```

## 配置`neon.ts` {/* #configure-neonts */}

在项目的根目录下，创建一个名为`neon.ts`. `neon deploy` and `neon dev` read this file:

```typescript title="neon.ts"
import { defineConfig } from '@neon/config/v1'

export default defineConfig({
  preview: {
    aiGateway: true,
    functions: {
      mastra: {
        name: 'Mastra server',
        source: './src/index.ts',
      },
    },
  },
})
```

对象键 (`mastra`) is the function slug. It can't be renamed after the first deploy.

`aiGateway: true`规定[Neon AI Gateway](/models/gateways/neon) on the branch. `neon deploy` injects `NEON_AI_GATEWAY_BASE_URL` and `NEON_AI_GATEWAY_TOKEN`. Mastra reads those variables for `neon/` model ids.

对于提供者 API 密钥而不是网关，请在函数的下声明它`env` field and use that provider's model id, not a `neon/` id. Values are read from `process.env` when `neon deploy` runs:

```typescript title="neon.ts"
import { defineConfig } from '@neon/config/v1'

export default defineConfig({
  preview: {
    functions: {
      mastra: {
        name: 'Mastra server',
        source: './src/index.ts',
        env: {
          OPENAI_API_KEY: process.env.OPENAI_API_KEY!,
        },
      },
    },
  },
})
```

```bash
neon deploy --env .env
```

`--env`加载文件以进行配置评估。仅列出的键`env` are deployed. See [Neon Functions environment variables](https://neon.com/docs/compute/functions/environment-variables).

## 导出 Hono 获取处理程序 {/* #export-a-hono-fetch-handler */}

接线[Hono adapter](/reference/server/hono-adapter) and export the app. Neon Functions invoke the default export's `fetch` method.

```typescript title="src/index.ts"
import { Hono } from 'hono'
import { HonoBindings, HonoVariables, MastraServer } from '@mastra/hono'
import { mastra } from './mastra'

const app = new Hono<{ Bindings: HonoBindings; Variables: HonoVariables }>()
const server = new MastraServer({ app, mastra })

await server.init()

export default app
```

注册Agent`mastra` instance in `src/mastra/index.ts`.

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core/mastra'
import { Agent } from '@mastra/core/agent'

const assistant = new Agent({
  id: 'assistant',
  name: 'Assistant',
  instructions: 'You are a helpful assistant',
  model: 'neon/claude-fable-5',
})

export const mastra = new Mastra({
  agents: { assistant },
})
```

请参阅[Neon AI Gateway](/models/gateways/neon) for the model list.

## 部署 {/* #deploy */}

<Steps>
  <StepItem>
    从项目目录中，链接现有 Neon 项目（或创建一个）：

    ```bash
    neon link
    ```

    `neon link`将项目上下文写入`.neon` and pulls the current branch's environment variables.
  </StepItem>

  <StepItem>
    部署功能：

    ```bash
    neon deploy
    ```

    CLI 将处理程序与 esbuild 捆绑在一起，上传它，然后等待部署状态为`completed`. If you declared function `env` values, pass `--env <file>` so `neon.ts` can read them.
  </StepItem>

  <StepItem>
    获取公共网址：

    ```bash
    neon functions get mastra
    ```

    这`invocation_url` looks like `https://<branch-id>-mastra.compute.<cell>.us-east-2.aws.neon.tech/`.
  </StepItem>

  <StepItem>
    验证部署`https://<branch-id>-mastra.compute.<cell>.us-east-2.aws.neon.tech/api/agents`, which should return a JSON list of your agents.

    由于 Mastra 服务器为每个 API 端点添加前缀`/api`, add it to your URLs when making requests.

    `DATABASE_URL`从分支注入。网关凭据在以下情况下注入`aiGateway: true` is set in `neon.ts`.
  </StepItem>

  <StepItem>
    您现在可以通过 HTTP 调用 Mastra 端点。

    :::警告
    设置[authentication](/docs/auth/overview) before exposing your endpoints publicly. The function URL is public; see [Neon Functions authentication](https://neon.com/docs/compute/functions/authentication).
    :::
  </StepItem>
</Steps>

## 当地发展 {/* #local-development */}

`neon dev`服务于中声明的每个函数`neon.ts` with hot reload, and injects the linked branch's environment variables:

```bash
neon dev
```

Mastra 服务器位于`http://localhost:8787/api/agents`.
