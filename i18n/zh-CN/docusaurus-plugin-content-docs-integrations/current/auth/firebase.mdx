# Firebase

`@mastra/auth-firebase` 包通过 Firebase Authentication 为 Mastra 提供身份验证。它使用 Firebase ID 令牌验证传入请求，并通过 `auth` 选项接入 Mastra 服务器。

## 准备工作 {/* #prerequisites */}

本示例使用 Firebase Authentication。开始前请完成以下步骤：

1. 在 [Firebase 控制台](https://console.firebase.google.com/)中创建 Firebase 项目。
2. 启用身份验证，并配置所需的登录方式，例如 Google 登录或电子邮件地址和密码登录。
3. 在「项目设置」>「服务账号」中生成服务账号密钥。
4. 下载服务账号 JSON 文件。

```env title=".env"
FIREBASE_SERVICE_ACCOUNT=/path/to/your/service-account-key.json
FIRESTORE_DATABASE_ID=(default)
# Alternative environment variable names:
# FIREBASE_DATABASE_ID=(default)
```

:::note

请妥善保管服务账号 JSON 文件，切勿将其提交到版本控制系统。

:::

## 安装 {/* #installation */}

使用 `MastraAuthFirebase` 类之前，请先安装 `@mastra/auth-firebase` 包。

```bash npm2yarn
npm install @mastra/auth-firebase@latest
```

## 使用示例 {/* #usage-examples */}

### 使用环境变量初始化 {/* #basic-usage-with-environment-variables */}

设置所需的环境变量 `FIREBASE_SERVICE_ACCOUNT` 和 `FIRESTORE_DATABASE_ID` 后，初始化 `MastraAuthFirebase` 时无需传入构造函数参数。该类会自动读取这些环境变量作为配置。

```typescript {2,7} title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraAuthFirebase } from '@mastra/auth-firebase'

// Automatically uses FIREBASE_SERVICE_ACCOUNT and FIRESTORE_DATABASE_ID env vars
export const mastra = new Mastra({
  server: {
    auth: new MastraAuthFirebase(),
  },
})
```

### 自定义配置 {/* #custom-configuration */}

```typescript {2,6-9} title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraAuthFirebase } from '@mastra/auth-firebase'

export const mastra = new Mastra({
  server: {
    auth: new MastraAuthFirebase({
      serviceAccount: '/path/to/service-account.json',
      databaseId: 'your-database-id',
    }),
  },
})
```

## 配置 {/* #configuration */}

可以通过构造函数选项或环境变量配置 `MastraAuthFirebase` 类。

### 环境变量 {/* #environment-variables */}

* `FIREBASE_SERVICE_ACCOUNT`：Firebase 服务账号 JSON 文件的路径
* `FIRESTORE_DATABASE_ID` 或 `FIREBASE_DATABASE_ID`：Firestore 数据库 ID

:::note

未提供构造函数选项时，该类会自动读取这些环境变量。只要正确设置了环境变量，就可以直接调用 `new MastraAuthFirebase()`，无需传入参数。

:::

### 用户授权 {/* #user-authorization */}

默认情况下，`MastraAuthFirebase` 使用 Firestore 管理用户的访问权限。它会在 `user_access` 集合中以用户 UID 为文档 ID 查找对应文档。如果该文档存在，用户即获得授权。

```text title="firestore-structure.txt"
user_access/
  {user_uid_1}/     // Document exists = user authorized
  {user_uid_2}/     // Document exists = user authorized
```

如需自定义用户授权逻辑，请提供自己的 `authorizeUser` 函数。

```typescript title="src/mastra/auth.ts"
import { MastraAuthFirebase } from '@mastra/auth-firebase'

const firebaseAuth = new MastraAuthFirebase({
  authorizeUser: async user => {
    // Custom authorization logic
    return user.email?.endsWith('@yourcompany.com') || false
  },
})
```

所有可用的配置选项请参阅 [MastraAuthFirebase](/reference/auth/firebase)。

## 客户端设置 {/* #client-side-setup */}

使用 Firebase 身份验证时，请先在客户端初始化 Firebase，再验证用户身份并获取其 ID 令牌，以便在向 Mastra 发送请求时携带该令牌。

### 在客户端初始化 Firebase {/* #setting-up-firebase-on-the-client */}

首先，在客户端应用中初始化 Firebase。

```typescript title="lib/firebase.ts"
import { initializeApp } from 'firebase/app'
import { getAuth, GoogleAuthProvider } from 'firebase/auth'

const firebaseConfig = {
  apiKey: process.env.NEXT_PUBLIC_FIREBASE_API_KEY,
  authDomain: process.env.NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN,
  projectId: process.env.NEXT_PUBLIC_FIREBASE_PROJECT_ID,
}

const app = initializeApp(firebaseConfig)
export const auth = getAuth(app)
export const googleProvider = new GoogleAuthProvider()
```

### 验证用户身份并获取令牌 {/* #authenticating-users-and-retrieving-tokens */}

使用 Firebase Authentication 让用户登录，并获取该用户的 ID 令牌。

```typescript title="lib/auth.ts"
import { signInWithPopup, signOut, User } from 'firebase/auth'
import { auth, googleProvider } from './firebase'

export const signInWithGoogle = async () => {
  try {
    const result = await signInWithPopup(auth, googleProvider)
    return result.user
  } catch (error) {
    console.error('Error signing in:', error)
    throw error
  }
}

export const getIdToken = async (user: User) => {
  try {
    const idToken = await user.getIdToken()
    return idToken
  } catch (error) {
    console.error('Error getting ID token:', error)
    throw error
  }
}

export const signOutUser = async () => {
  try {
    await signOut(auth)
  } catch (error) {
    console.error('Error signing out:', error)
    throw error
  }
}
```

:::note

电子邮件地址和密码登录、手机号验证等其他身份验证方式，请参阅 [Firebase 文档](https://firebase.google.com/docs/auth)。

:::

## 配置 `MastraClient` {/* #configuring-mastraclient */}

启用 `auth` 后，通过 `MastraClient` 发送的每个请求都必须在 `Authorization` 请求头中携带有效的 Firebase ID 令牌。

```typescript {6} title="lib/mastra/mastra-client.ts"
import { MastraClient } from '@mastra/client-js'

export const createMastraClient = (idToken: string) => {
  return new MastraClient({
    baseUrl: 'https://<mastra-api-url>',
    headers: {
      Authorization: `Bearer ${idToken}`,
    },
  })
}
```

:::note

在 Authorization 请求头中，必须在 ID 令牌前加上 `Bearer` 和一个空格。

更多配置选项请参阅 [Mastra Client SDK](/docs/server/mastra-client)。

:::

### 发送经过身份验证的请求 {/* #making-authenticated-requests */}

为 `MastraClient` 配置 Firebase ID 令牌后，即可发送经过身份验证的请求。

    ```tsx title="src/components/test-agent.tsx"
    'use client'

    import { useAuthState } from 'react-firebase-hooks/auth'
    import { MastraClient } from '@mastra/client-js'
    import { auth } from '../lib/firebase'
    import { getIdToken } from '../lib/auth'

    export const TestAgent = () => {
      const [user] = useAuthState(auth)

      async function handleClick() {
        if (!user) return

        const token = await getIdToken(user)
        const client = createMastraClient(token)

        const weatherAgent = client.getAgent('weatherAgent')
        const response = await weatherAgent.generate("What's the weather like in New York")

        console.log({ response })
      }

      return (
        <button onClick={handleClick} disabled={!user}>
          Test Agent
        </button>
      )
    }
    ```

    ```typescript title="server.js"
    const express = require('express')
    const admin = require('firebase-admin')
    const { MastraClient } = require('@mastra/client-js')

    // Initialize Firebase Admin
    admin.initializeApp({
      credential: admin.credential.cert({
        // Your service account credentials
      }),
    })

    const app = express()
    app.use(express.json())

    app.post('/generate', async (req, res) => {
      try {
        const { idToken } = req.body

        // Verify the token
        await admin.auth().verifyIdToken(idToken)

        const mastra = new MastraClient({
          baseUrl: 'http://localhost:4111',
          headers: {
            Authorization: `Bearer ${idToken}`,
          },
        })

        const weatherAgent = mastra.getAgent('weatherAgent')
        const response = await weatherAgent.generate("What's the weather like in Nairobi")

        res.json({ response: response.text })
      } catch (error) {
        res.status(401).json({ error: 'Unauthorized' })
      }
    })
    ```
