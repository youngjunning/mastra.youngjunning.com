# Clerk

Mastra 支持两种 Clerk 集成方式：

- **Agent 工具**让 Agent 通过 [Mastra Connect](/docs/mastra-platform/connect) 管理 Clerk 用户、组织和会话。
- **[服务器身份验证](#server-authentication)**通过 `@mastra/auth-clerk` 包使用 Clerk 验证发送到 Mastra 服务器的请求。

## Connect {/* #connect */}

请先按照 [Connect 设置指南](/docs/mastra-platform/connect#get-started) 安装 `@mastra/connect` 并配置 Mastra Platform 项目。

## 服务器身份验证 {/* #server-authentication */}

`@mastra/auth-clerk` 包使用 Clerk 的身份验证系统验证传入请求。通过 `auth` 选项将其接入 Mastra 服务器。

### 前提条件 {/* #prerequisites */}

此示例使用 Clerk 进行身份验证。请确认 Clerk 项目已正确配置，并将 Clerk 凭据添加到 `.env` 文件中。

```env title=".env"
CLERK_PUBLISHABLE_KEY=pk_test_...
CLERK_SECRET_KEY=sk_test_...
CLERK_JWKS_URI=https://your-clerk-domain.clerk.accounts.dev/.well-known/jwks.json
```

:::note

可在 Clerk Dashboard 的“API Keys”页面找到这些密钥。

:::

### 安装 {/* #installation */}

使用 `MastraAuthClerk` 类之前，请先安装 `@mastra/auth-clerk` 包。

```bash npm2yarn
npm install @mastra/auth-clerk@latest
```

### 使用示例 {/* #usage-example */}

```typescript {2,6-10} title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraAuthClerk } from '@mastra/auth-clerk'

export const mastra = new Mastra({
  server: {
    auth: new MastraAuthClerk({
      publishableKey: process.env.CLERK_PUBLISHABLE_KEY,
      secretKey: process.env.CLERK_SECRET_KEY,
      jwksUri: process.env.CLERK_JWKS_URI,
    }),
  },
})
```

:::note

默认的 `authorizeUser` 方法会放行所有已通过身份验证的用户。如需自定义用户授权规则，请在创建身份验证提供程序时传入自定义的 `authorizeUser` 函数。

完整的配置选项请参阅 [MastraAuthClerk](/reference/auth/clerk)。

:::

### 客户端配置 {/* #client-side-setup */}

使用 Clerk 进行身份验证时，需要在客户端从 Clerk 获取访问令牌，并在向 Mastra 发送请求时携带该令牌。

#### 获取访问令牌 {/* #retrieving-the-access-token */}

使用 Clerk 的 React Hook 验证用户身份并获取该用户的访问令牌：

```typescript title="lib/auth.ts"
import { useAuth } from '@clerk/nextjs'

export const useClerkAuth = () => {
  const { getToken } = useAuth()

  const getAccessToken = async () => {
    const token = await getToken()
    return token
  }

  return { getAccessToken }
}
```

详情请参阅 [Clerk 文档](https://clerk.com/docs)。

### 配置 `MastraClient` {/* #configuring-mastraclient */}

启用 `auth` 后，通过 `MastraClient` 发送的所有请求都必须在 `Authorization` 请求头中包含有效的 Clerk 访问令牌：

```typescript {6} title="lib/mastra/mastra-client.ts"
import { MastraClient } from '@mastra/client-js'

export const mastraClient = new MastraClient({
  baseUrl: 'https://<mastra-api-url>',
  headers: {
    Authorization: `Bearer ${accessToken}`,
  },
})
```

:::note

在 Authorization 请求头中，访问令牌必须以 `Bearer` 加一个空格作为前缀。

更多配置选项请参阅 [Mastra Client SDK](/docs/server/mastra-client)。

:::

#### 发送经过身份验证的请求 {/* #making-authenticated-requests */}

为 `MastraClient` 配置 Clerk 访问令牌后，即可发送经过身份验证的请求：

<Tabs>
  <TabItem value="react" label="React">
    ```tsx title="src/components/test-agent.tsx"
    'use client'

    import { useAuth } from '@clerk/nextjs'
    import { MastraClient } from '@mastra/client-js'

    export const TestAgent = () => {
      const { getToken } = useAuth()

      async function handleClick() {
        const token = await getToken()

        const client = new MastraClient({
          baseUrl: 'http://localhost:4111',
          headers: token ? { Authorization: `Bearer ${token}` } : undefined,
        })

        const weatherAgent = client.getAgent('weatherAgent')
        const response = await weatherAgent.generate("What's the weather like in New York")

        console.log({ response })
      }

      return <button onClick={handleClick}>Test Agent</button>
    }
    ```
  </TabItem>
