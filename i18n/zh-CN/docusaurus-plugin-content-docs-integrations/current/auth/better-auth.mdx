# Better Auth

`@mastra/auth-better-auth` 包通过 Better Auth 为 Mastra 提供身份验证。它通过 `server.auth` 选项接入 Mastra 服务器，并使用你的 Better Auth 实例验证收到的请求。

## 先决条件 {/* #prerequisites */}

本示例使用 Better Auth。请先配置 Better Auth 实例并设置环境变量。

```env title=".env"
# Required by Better Auth
BETTER_AUTH_SECRET=...   # at least 32 chars
BETTER_AUTH_URL=http://localhost:3000

# Example DB URL used by the snippet below (adjust for your setup)
DATABASE_URL=postgres://...
```

:::note

为确保安全性和稳定性，Better Auth 建议显式设置 `baseURL`，也可以通过 `BETTER_AUTH_URL` 设置。

:::

如果尚未挂载 Better Auth 的处理程序，请按照 [Better Auth 安装指南](https://www.better-auth.com/docs/installation) 将其挂载到 `/api/auth/*` 路由或你配置的基础路径。应用挂载后即可让用户登录并创建会话。

## 安装 {/* #installation */}

安装 `@mastra/auth-better-auth` 包。

```bash npm2yarn
npm install @mastra/auth-better-auth
```

## 使用示例 {/* #usage-example */}

先创建 Better Auth 实例。

```ts title="lib/auth.ts"
import { betterAuth } from 'better-auth'

export const auth = betterAuth({
  database: {
    provider: 'postgresql',
    url: process.env.DATABASE_URL!,
  },
  emailAndPassword: {
    enabled: true,
  },
  baseURL: process.env.BETTER_AUTH_URL,
  secret: process.env.BETTER_AUTH_SECRET,
})
```

然后将该实例接入 Mastra。

```ts title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraAuthBetterAuth } from '@mastra/auth-better-auth'
import { auth } from '@/lib/auth'

const mastraAuth = new MastraAuthBetterAuth({
  auth,
})

export const mastra = new Mastra({
  server: {
    auth: mastraAuth,
  },
})
```

有关所有可用的配置选项，请参阅 [MastraAuthBetterAuth](/reference/auth/better-auth)。

## 自定义授权 {/* #custom-authorization */}

```ts
const mastraAuth = new MastraAuthBetterAuth({
  auth,
  async authorizeUser(user) {
    // Example: only allow verified emails
    return user?.user?.emailVerified === true
  },
})
```

## 路由配置 {/* #route-configuration */}

```ts
const mastraAuth = new MastraAuthBetterAuth({
  auth,
  public: ['/health', '/api/status'],
  protected: ['/api/*', '/admin/*'],
})
```

### 匹配规则 {/* #matching-rules */}

* `public` 和 `protected` 均支持精确路径、通配符模式（如 `/api/*`）和路径参数（如 `/users/:id`）。
* 要将规则限定在特定 HTTP 方法上，请使用 `["/api/agents", ["GET", "POST"]]` 这样的元组。
* 如果路由同时匹配 `public` 和 `protected`，则以 `public` 为准，无需身份验证。
* 如果路由不匹配任何一方，则默认受保护，除非显式将该路由标记为 `requiresAuth: false`。

## 客户端设置 {/* #client-side-setup */}

启用身份验证后，访问 Mastra 内置路由的请求必须经过身份验证。客户端需要随请求发送当前 Better Auth 配置所使用的凭据。

### Cookie 会话（推荐） {/* #cookie-session-recommended */}

如果 Better Auth 使用 Cookie，请配置客户端，使其随请求发送凭据。对于跨源请求，例如运行在 `:3000` 的 Next.js 调用运行在 `:4111` 的 Mastra，请在 Mastra 服务器的 CORS 配置中允许携带凭据。

```ts title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'

export const mastra = new Mastra({
  server: {
    auth: mastraAuth,
    cors: {
      origin: 'http://localhost:3000', // your frontend origin
      credentials: true,
    },
  },
})
```

接着配置客户端，让它随请求发送凭据。

```ts
import { MastraClient } from '@mastra/client-js'

export const mastraClient = new MastraClient({
  baseUrl: 'http://localhost:4111',
  credentials: 'include',
})
```

如果直接调用 API，也请配置 `fetch` 随请求发送凭据。

```ts
await fetch('http://localhost:4111/api/agents/weatherAgent/generate', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
  },
  credentials: 'include',
  body: JSON.stringify({ messages: 'Weather in London' }),
})
```

### Bearer 令牌 {/* #bearer-token */}

你可以将已签名的会话令牌作为 Bearer 令牌发送。从 Better Auth 客户端的会话中获取该令牌，并将其放入 `Authorization` 请求头。

```ts
import { MastraClient } from '@mastra/client-js'
import { authClient } from './auth-client' // your Better Auth client

const session = await authClient.getSession()

export const mastraClient = new MastraClient({
  baseUrl: 'http://localhost:4111',
  headers: {
    Authorization: `Bearer ${session.data?.session.token}`,
  },
})
```

更多配置选项请参阅 [Mastra Client SDK](/docs/server/mastra-client)。

## 故障排除 {/* #troubleshooting */}

* **每个请求都返回 401**。确认 Better Auth 的处理程序已挂载，且应用能创建有效会话。检查客户端是否发送了会话 Cookie 或 `Authorization: Bearer <signed-token>` 请求头。
* **跨源请求未发送 Cookie**。在 `MastraClient` 中设置 `credentials: "include"`，并在 `server.cors` 中配置前端源和 `credentials: true`。
* **Bearer 令牌被拒绝**。请发送从 `authClient.getSession()` 获取的完整、已签名的会话令牌，避免发送原始或未签名的令牌。
* **基础 URL 有误**。在 `betterAuth({ ... })` 中设置 `baseURL`，或设置 `BETTER_AUTH_URL`。
* **数据库连接错误**。检查 `DATABASE_URL` 和数据库提供程序的配置。
