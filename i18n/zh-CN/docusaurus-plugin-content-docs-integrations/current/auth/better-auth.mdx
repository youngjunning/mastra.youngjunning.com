# 更好的身份验证

这`@mastra/auth-better-auth`包使用 Better Auth 为 Mastra 提供身份验证。它使用您的 Better Auth 实例验证传入请求，并通过以下方式与 Mastra 服务器集成：`server.auth`选项。

## 先决条件 {/* #prerequisites */}

此示例使用更好的身份验证。确保您的 Better Auth 实例已配置并且环境变量已设置。

```env title=".env"
# Required by Better Auth
BETTER_AUTH_SECRET=...   # at least 32 chars
BETTER_AUTH_URL=http://localhost:3000

# Example DB URL used by the snippet below (adjust for your setup)
DATABASE_URL=postgres://...
```

：：：笔记

Better Auth 建议设置`baseURL` explicitly (or via `BETTER_AUTH_URL`) for security and stability.

:::

如果您尚未安装 Better Auth 的处理程序（以便您的应用程序可以让用户登录/创建会话），请按照[Better Auth installation guide](https://www.better-auth.com/docs/installation) to mount the `/api/auth/*` route (or your configured base path).

## 安装 {/* #installation */}

安装`@mastra/auth-better-auth` package:

```bash npm2yarn
npm install @mastra/auth-better-auth
```

## 使用示例 {/* #usage-example */}

首先，创建您的 Better Auth 实例：

```ts title="lib/auth.ts"
import { betterAuth } from 'better-auth'

export const auth = betterAuth({
  database: {
    provider: 'postgresql',
    url: process.env.DATABASE_URL!,
  },
  emailAndPassword: {
    enabled: true,
  },
  baseURL: process.env.BETTER_AUTH_URL,
  secret: process.env.BETTER_AUTH_SECRET,
})
```

然后，将其与 Mastra 一起使用：

```ts title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraAuthBetterAuth } from '@mastra/auth-better-auth'
import { auth } from '@/lib/auth'

const mastraAuth = new MastraAuthBetterAuth({
  auth,
})

export const mastra = new Mastra({
  server: {
    auth: mastraAuth,
  },
})
```

访问[MastraAuthBetterAuth](/reference/auth/better-auth) for all available configuration options.

## 定制授权 {/* #custom-authorization */}

```ts
const mastraAuth = new MastraAuthBetterAuth({
  auth,
  async authorizeUser(user) {
    // Example: only allow verified emails
    return user?.user?.emailVerified === true
  },
})
```

## 路由配置 {/* #route-configuration */}

```ts
const mastraAuth = new MastraAuthBetterAuth({
  auth,
  public: ['/health', '/api/status'],
  protected: ['/api/*', '/admin/*'],
})
```

### 匹配规则 {/* #matching-rules */}

* `public`和`protected` accept exact paths, wildcard patterns (like `/api/*`), and path params (like `/users/:id`).
* 对于特定于方法的规则，请使用元组，例如`["/api/agents", ["GET", "POST"]]`.
* 如果一条路线与两者都匹配`public` and `protected`, `public` wins and no auth is required.
* 如果两者都不匹配，则默认将路由视为受保护（除非路由被显式标记为`requiresAuth: false`).

## 客户端设置 {/* #client-side-setup */}

启用身份验证后，对 Mastra 内置路由的请求需要身份验证。实际上，这意味着您的客户端需要发送您的 Better Auth 设置用于经过身份验证的请求的任何凭据。

### Cookie 会话（推荐） {/* #cookie-session-recommended */}

如果您的 Better Auth 设置使用 cookie，请将客户端配置为发送凭据。对于跨源请求（例如 Next.js 上`:3000` calling Mastra on `:4111`), enable CORS credentials on the Mastra server:

```ts title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'

export const mastra = new Mastra({
  server: {
    auth: mastraAuth,
    cors: {
      origin: 'http://localhost:3000', // your frontend origin
      credentials: true,
    },
  },
})
```

然后配置客户端以包含凭据：

```ts
import { MastraClient } from '@mastra/client-js'

export const mastraClient = new MastraClient({
  baseUrl: 'http://localhost:4111',
  credentials: 'include',
})
```

如果您直接调用 API，请将凭据包含在`fetch` as well:

```ts
await fetch('http://localhost:4111/api/agents/weatherAgent/generate', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
  },
  credentials: 'include',
  body: JSON.stringify({ messages: 'Weather in London' }),
})
```

### 不记名令牌 {/* #bearer-token */}

您可以将签名的会话令牌作为承载令牌传递。从 Better Auth 客户端会话中检索它并将其包含在`Authorization` header:

```ts
import { MastraClient } from '@mastra/client-js'
import { authClient } from './auth-client' // your Better Auth client

const session = await authClient.getSession()

export const mastraClient = new MastraClient({
  baseUrl: 'http://localhost:4111',
  headers: {
    Authorization: `Bearer ${session.data?.session.token}`,
  },
})
```

访问[Mastra Client SDK](/docs/server/mastra-client) for more configuration options.

## 故障排除 {/* #troubleshooting */}

* **每个请求均返回 401**：确认您的 Better Auth 处理程序已安装并且您的应用程序可以创建有效的会话。检查您的客户端是否发送会话 cookie 或`Authorization: Bearer <signed-token>` header.
* **Cookie 未跨源发送**： 放`credentials: "include"` in `MastraClient` and configure `server.cors` with your frontend origin and `credentials: true`.
* **不记名令牌被拒绝**：确保您传递完整签名的会话令牌（来自`authClient.getSession()`), not a raw or unsigned token.
* **基本 URL 问题**： 放`baseURL` in `betterAuth({ ... })` or set `BETTER_AUTH_URL`.
* **数据库连接错误**： 核实`DATABASE_URL` and database provider configuration.
