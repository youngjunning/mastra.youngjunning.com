# WorkOS

WorkOS 可以通过两种方式与 Mastra 集成：

* **Agent Tool** 让 Agent 通过 [Mastra Connect](/docs/mastra-platform/connect) 管理 WorkOS 组织、用户和 SSO 连接。
* **[服务器身份验证](#server-authentication)** 使用 `@mastra/auth-workos` 包，通过 WorkOS 验证发送到 Mastra 服务器的请求。

## Connect {/* #connect */}

开始前，请按 [Connect 设置步骤](/docs/mastra-platform/connect#get-started)安装 `@mastra/connect` 并配置平台项目。

## 服务器身份验证 {/* #server-authentication */}

`@mastra/auth-workos` 包通过 WorkOS 为 Mastra 提供身份验证。它使用 WorkOS 访问令牌验证传入的请求，并通过 `auth` 选项接入 Mastra 服务器。

### 前提条件 {/* #prerequisites */}

本示例使用 WorkOS 进行身份验证。请先完成以下设置：

1. 在 [workos.com](https://workos.com/) 创建 WorkOS 账号
2. 在 WorkOS 控制台中设置应用
3. 配置重定向 URI 和允许的来源
4. 根据需要设置组织并配置用户角色

```env title=".env"
WORKOS_API_KEY=sk_live_...
WORKOS_CLIENT_ID=client_...
```

:::note

在 WorkOS 控制台的 API Keys 和 Applications 页面中，可以分别找到 API 密钥和客户端 ID。

有关详细设置步骤，请在 [WorkOS 文档](https://workos.com/docs)中查阅适用于所用平台的说明。

:::

### 安装 {/* #installation */}

使用 `MastraAuthWorkos` 类之前，必须先安装 `@mastra/auth-workos` 包。

```bash npm2yarn
npm install @mastra/auth-workos@latest
```

### 使用示例 {/* #usage-examples */}

#### 使用环境变量 {/* #basic-usage-with-environment-variables */}

```typescript {2,6} title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraAuthWorkos } from '@mastra/auth-workos'

export const mastra = new Mastra({
  server: {
    auth: new MastraAuthWorkos(),
  },
})
```

#### 自定义配置 {/* #custom-configuration */}

```typescript {2,6-9} title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraAuthWorkos } from '@mastra/auth-workos'

export const mastra = new Mastra({
  server: {
    auth: new MastraAuthWorkos({
      apiKey: process.env.WORKOS_API_KEY,
      clientId: process.env.WORKOS_CLIENT_ID,
    }),
  },
})
```

### 配置 {/* #configuration */}

#### 默认授权 {/* #default-authorization */}

默认情况下，`MastraAuthWorkos` 允许所有通过身份验证的 WorkOS 用户访问。如果解析出的用户对象同时包含 Mastra 用户 ID 和 WorkOS 用户 ID，授权检查就会通过。

#### 为 FGA 加载组织成员关系 {/* #fga-membership-loading */}

:::note

在生产环境中使用 FGA 需要 Mastra 企业版（EE）许可证，开发环境中无需许可证。请参阅[哪些功能需要 EE 许可证](/docs/license#what-requires-an-ee-license)。如需了解更多信息，请[联系销售团队](https://mastra.ai/contact)。

:::

使用 [`MastraFGAWorkos`](/docs/auth/fga) 时，请设置 `fetchMemberships: true`。身份验证 Provider 会在验证身份时加载用户在 WorkOS 中的组织成员关系，以便 FGA 检查确定正确的组织成员关系 ID。

```typescript title="src/mastra/auth.ts"
import { MastraAuthWorkos, MastraFGAWorkos } from '@mastra/auth-workos'

const workosAuth = new MastraAuthWorkos({
  apiKey: process.env.WORKOS_API_KEY,
  clientId: process.env.WORKOS_CLIENT_ID,
  fetchMemberships: true,
})

const workosFga = new MastraFGAWorkos({
  apiKey: process.env.WORKOS_API_KEY,
  clientId: process.env.WORKOS_CLIENT_ID,
})
```

当 `fetchMemberships` 为 `false` 时，Mastra 在处理每个通过身份验证的请求时都会跳过对 WorkOS `listOrganizationMemberships()` 的额外调用。

#### 服务令牌和自定义 JWT 模板 {/* #service-tokens-and-custom-jwt-templates */}

对于机器间访问或服务账号访问，可以配置 `MastraAuthWorkos`，使其信任由 WorkOS 自定义 JWT 模板生成的持有者令牌中已通过验证的声明。

```typescript title="src/mastra/auth.ts"
import { MastraAuthWorkos } from '@mastra/auth-workos'

const workosAuth = new MastraAuthWorkos({
  apiKey: process.env.WORKOS_API_KEY,
  clientId: process.env.WORKOS_CLIENT_ID,
  redirectUri: process.env.WORKOS_REDIRECT_URI,
  trustJwtClaims: true,
  jwtClaims: {
    organizationId: 'org_id',
    organizationMembershipId: 'urn:mastra:organization_membership_id',
  },
})
```

如果 JWT 模板已包含 Mastra 执行 FGA 检查所需的上下文（例如 `organizationMembershipId`、租户 ID 或服务主体标识符），就可以使用此配置。启用 `trustJwtClaims` 后，如果持有者令牌不适合通过 `workos.userManagement.getUser()` 查询用户，Mastra 可以改用这些已验证的声明。

#### 自定义授权 {/* #custom-authorization */}

如果需要更严格的授权，可以创建 `MastraAuthWorkos` 的子类并重写 `authorizeUser()`：

```typescript title="src/mastra/auth.ts"
import { MastraAuthWorkos } from '@mastra/auth-workos'
import type { HonoRequest } from 'hono'

class AdminOnlyWorkosAuth extends MastraAuthWorkos {
  async authorizeUser(user: any, _request: HonoRequest): Promise<boolean> {
    return user?.metadata?.role === 'admin'
  }
}

const workosAuth = new AdminOnlyWorkosAuth({
  apiKey: process.env.WORKOS_API_KEY,
  clientId: process.env.WORKOS_CLIENT_ID,
})
```

所有可用的配置选项请参阅 [MastraAuthWorkos](/reference/auth/workos)。

### 客户端配置 {/* #client-side-setup */}

使用 WorkOS 进行身份验证时，需要实现 WorkOS 身份验证流程，用授权码换取访问令牌，再携带该令牌向 Mastra 发送请求。

#### 安装 WorkOS SDK {/* #installing-workos-sdk */}

先在应用中安装 WorkOS SDK：

```bash npm2yarn
npm install @workos-inc/node
```

#### 用授权码换取访问令牌 {/* #exchanging-code-for-access-token */}

用户完成 WorkOS 身份验证流程并带着授权码返回后，用该授权码换取访问令牌：

```typescript title="lib/auth.ts"
import { WorkOS } from '@workos-inc/node'

const workos = new WorkOS(process.env.WORKOS_API_KEY)

export const authenticateWithWorkos = async (code: string, clientId: string) => {
  const authenticationResponse = await workos.userManagement.authenticateWithCode({
    code,
    clientId,
  })

  return authenticationResponse.accessToken
}
```

:::note

更多身份验证方式和配置选项请参阅 [WorkOS 用户管理文档](https://workos.com/docs/authkit/vanilla/nodejs)。

:::

### 配置 `MastraClient` {/* #configuring-mastraclient */}

启用 `auth` 后，通过 `MastraClient` 发送的所有请求都必须在 `Authorization` 请求头中包含有效的 WorkOS 访问令牌：

```typescript title="lib/mastra/mastra-client.ts"
import { MastraClient } from '@mastra/client-js'

export const createMastraClient = (accessToken: string) => {
  return new MastraClient({
    baseUrl: 'https://<mastra-api-url>',
    headers: {
      Authorization: `Bearer ${accessToken}`,
    },
  })
}
```

:::note

在 Authorization 请求头中，访问令牌必须带有 `Bearer` 前缀。

更多配置选项请参阅 [Mastra Client SDK](/docs/server/mastra-client)。

:::

#### 发送带有身份验证凭据的请求 {/* #making-authenticated-requests */}

为 `MastraClient` 配置 WorkOS 访问令牌后，即可发送带有身份验证凭据的请求：

<Tabs>
  <TabItem value="react" label="React">
    ```typescript title="src/api/agents.ts"
    import { WorkOS } from '@workos-inc/node'
    import { MastraClient } from '@mastra/client-js'

    const workos = new WorkOS(process.env.WORKOS_API_KEY)

    export const callMastraWithWorkos = async (code: string, clientId: string) => {
      const authenticationResponse = await workos.userManagement.authenticateWithCode({
        code,
        clientId,
      })

      const token = authenticationResponse.accessToken

      const mastra = new MastraClient({
        baseUrl: 'http://localhost:4111',
        headers: {
          Authorization: `Bearer ${token}`,
        },
      })

      const weatherAgent = mastra.getAgent('weatherAgent')
      const response = await weatherAgent.generate("What's the weather like in Nairobi")

      return response.text
    }
    ```
