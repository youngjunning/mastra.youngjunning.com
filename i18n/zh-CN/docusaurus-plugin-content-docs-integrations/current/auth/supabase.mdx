# Supabase

你可以通过两种方式将 Supabase 与 Mastra 结合使用：

- **Agent 工具**让 Agent 通过 [Mastra Connect](/docs/mastra-platform/connect) 查询 Supabase 中的表、调用数据库函数，以及管理存储和 Supabase Auth 用户。
- **[服务器身份验证](#server-authentication)**通过 `@mastra/auth-supabase` 包使用 Supabase 验证发往 Mastra 服务器的请求。

## Connect {/* #connect */}

开始前，请按 [Connect 设置指南](/docs/mastra-platform/connect#get-started)安装 `@mastra/connect` 并配置你的平台项目。

## 服务器身份验证 {/* #server-authentication */}

`@mastra/auth-supabase` 包通过 `auth` 选项接入 Mastra 服务器，使用 Supabase Auth 验证收到的请求。

### 前提条件 {/* #prerequisites */}

此示例使用 Supabase Auth。请确保 Supabase 项目已正确配置，并将 Supabase 凭据添加到 `.env` 文件中。

```env title=".env"
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_ANON_KEY=your-anon-key
```

:::note

请检查 Supabase 的行级安全性（RLS）设置，确保数据访问权限符合预期。

:::

### 安装 {/* #installation */}

使用 `MastraAuthSupabase` 类之前，请先安装 `@mastra/auth-supabase` 包。

```bash npm2yarn
npm install @mastra/auth-supabase@latest
```

### 使用示例 {/* #usage-example */}

```typescript {2,6-9} title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraAuthSupabase } from '@mastra/auth-supabase'

export const mastra = new Mastra({
  server: {
    auth: new MastraAuthSupabase({
      url: process.env.SUPABASE_URL,
      anonKey: process.env.SUPABASE_ANON_KEY,
    }),
  },
})
```

:::note

默认的 `authorizeUser` 方法会检查 `public` 模式下 `users` 表中的 `isAdmin` 列。要自定义用户授权逻辑，请在创建身份验证提供程序实例时传入自定义的 `authorizeUser` 函数。

所有可用的配置选项请参阅 [MastraAuthSupabase](/reference/auth/supabase)。

:::

### 客户端配置 {/* #client-side-setup */}

使用 Supabase Auth 时，需要在客户端从 Supabase 获取访问令牌，并在向 Mastra 发送请求时附上该令牌。

#### 获取访问令牌 {/* #retrieving-the-access-token */}

使用 Supabase 客户端验证用户身份并获取该用户的访问令牌：

```typescript title="lib/auth.ts"
import { createClient } from '@supabase/supabase-js'

const supabase = createClient('<supabase-url>', '<supabase-key>')

const authTokenResponse = await supabase.auth.signInWithPassword({
  email: "<user's email>",
  password: "<user's password>",
})

const accessToken = authTokenResponse.data?.session?.access_token
```

:::note

有关 OAuth、免密码登录链接（magic link）等其他身份验证方式，请参阅 [Supabase 文档](https://supabase.com/docs/guides/auth)。

:::

### 配置 `MastraClient` {/* #configuring-mastraclient */}

启用 `auth` 后，通过 `MastraClient` 发送的所有请求都必须在 `Authorization` 请求头中包含有效的 Supabase 访问令牌：

```typescript {6} title="lib/mastra/mastra-client.ts"
import { MastraClient } from '@mastra/client-js'

export const mastraClient = new MastraClient({
  baseUrl: 'https://<mastra-api-url>',
  headers: {
    Authorization: `Bearer ${accessToken}`,
  },
})
```

:::note

在 Authorization 请求头中，访问令牌必须以 `Bearer` 加一个空格开头。

更多配置选项请参阅 [Mastra Client SDK](/docs/server/mastra-client)。

:::

#### 发送带身份验证的请求 {/* #making-authenticated-requests */}

为 `MastraClient` 配置 Supabase 访问令牌后，即可发送带身份验证的请求：

      }
