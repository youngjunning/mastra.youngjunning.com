# Agent 与工具

Agent 有两种使用 Knowledge 的方式。它可以按需调用工具，搜索、读取和写入页面。也可以通过[固定上下文](/docs/knowledge/pinned-context)，在每轮对话中直接获得所选页面，无需调用工具。本页介绍工具的用法。你可以为 Agent 选择要启用的工具，并通过[作用域声明](/docs/knowledge/scopes-and-access)限定每次工具调用可以做什么。

:::alpha

Knowledge 目前处于 Alpha 阶段，API 可能随版本更新而变化。

:::

## 启用工具 {/* #turn-on-the-tools */}

读取工具让 Agent 浏览、搜索和读取页面。写入工具用于创建、修改页面和笔记。各工具的说明见 [Knowledge 工具参考](/reference/knowledge/knowledge-tools)。

工具默认停用。将 `tools: true` 加入配置，即可启用读取和写入工具：

```typescript title="src/mastra/knowledge.ts"
import { Knowledge, knowledgeMemoryScopes } from '@mastra/core/knowledge'

export const knowledge = new Knowledge({
  id: 'company',
  scopes: knowledgeMemoryScopes(),
  tools: true,
})
```

仅根据 Knowledge 回答问题的 Agent（例如文档问答 Agent）只需要读取工具：

```typescript
const knowledge = new Knowledge({
  id: 'docs',
  scopes: knowledgeMemoryScopes(),
  tools: { read: true },
})
```

固定上下文功能自带固定工具。要启用该工具，请设置 `pinnedContext: true`，详见[固定上下文](/docs/knowledge/pinned-context)。

## 为 Agent 配置工具 {/* #attach-the-tools-to-an-agent */}

将 Knowledge 实例传给 Agent 的 `knowledge` 选项。Agent 会获得已启用的工具及简短的使用说明，无需在自定义指令中再次介绍这些工具：

```typescript title="src/mastra/agents/support-agent.ts"
import { Agent } from '@mastra/core/agent'
import { knowledge } from '../knowledge'

export const supportAgent = new Agent({
  id: 'support-agent',
  name: 'Support agent',
  instructions: 'Help customers with their orders.',
  model: '__GATEWAY_OPENAI_MODEL__',
  knowledge,
})
```

要修改这些说明，请参阅[工具指令](/reference/knowledge/tool-instructions)。

### 手动添加工具 {/* #add-the-tools-yourself */}

你也可以将 Knowledge 工具与其他工具一并加入 Agent 的 `tools`。用 [`createTools()`](/reference/knowledge/knowledge-class#createtools) 创建工具，用 [`getInstructions()`](/reference/knowledge/knowledge-class#getinstructions) 取得使用说明，并为两者传入相同的选项：

```typescript title="src/mastra/agents/docs-agent.ts"
import { Agent } from '@mastra/core/agent'
import { knowledge } from '../knowledge'

export const docsAgent = new Agent({
  id: 'docs-agent',
  name: 'Docs agent',
  instructions: `Answer from the company docs.\n\n${knowledge.getInstructions({ write: false, pinnedContext: false })}`,
  model: '__GATEWAY_OPENAI_MODEL__',
  tools: {
    ...knowledge.createTools({ write: false, pinnedContext: false }),
  },
})
```

这些选项会覆盖 Knowledge 实例中适用于该 Agent 的设置。这里的 `{ write: false, pinnedContext: false }` 让 Agent 只获得读取工具。如果省略 `pinnedContext: false`，且实例已启用固定上下文，Agent 还会获得 `knowledge_pin`。两种方式的权限检查相同。

## 读取页面 {/* #read-pages */}

使用读取工具，Agent 可以：

- 浏览作用域的组织结构。
- 按关键词搜索页面和笔记；[添加语义搜索](/docs/knowledge/search#add-search-by-meaning)后也可以按含义搜索。
- 读取页面及其笔记，也可以读取其他页面上提到该页面的笔记。

较长的页面会分段返回。首次读取会显示页面的各级标题。Agent 可以接着读取所需的章节、从指定行继续读取，或只读取与某个词匹配的行。

如果没有匹配项，工具会在结果中说明。Agent 可以直接告诉用户自己不知道答案，避免猜测。

默认情况下，一次读取最多返回页面中的 1,000 个 token。对上下文窗口较大的模型可以提高上限，对较小的模型可以降低上限：

```typescript
const knowledge = new Knowledge({
  id: 'docs',
  scopes: knowledgeMemoryScopes(),
  tools: { read: { maxTokens: 3000 }, write: true },
})
```

## 写入页面 {/* #write-pages */}

使用写入工具，Agent 可以：

- 创建、编辑、移动、合并或删除页面。
- 添加和移除笔记。笔记记录页面上的简短事实，并注明作者。笔记可以链接到其他页面，由其[标记](/docs/knowledge/scopes-and-access#note-visibility)决定谁能看到它。

Agent 将页面放入与读者对应的作用域。面向整个团队的事实放在团队作用域；仅与某个用户相关的事实放在该用户的 `resource:` 作用域。

对于较长的页面，Agent 只能编辑读过的行，因此无法覆盖未读取的部分。如果有人在 Agent 读完这些行后更改了页面，这次编辑就会被拒绝。

## 权限检查 {/* #access-checks */}

启用工具本身不会授予访问权限。Agent 只能使用本次运行持有的作用域，以及由规则为本次运行分配了角色的作用域。其他作用域对它不可见。

每次调用工具时，Knowledge 会根据本次运行在所涉作用域中的角色检查权限。各角色允许的操作请参阅[角色权限表](/docs/knowledge/scopes-and-access#access-rules-and-roles)。

调用被拒绝时，代码不会抛出错误。模型会收到拒绝信息作为工具结果，并可据此作出回应。
