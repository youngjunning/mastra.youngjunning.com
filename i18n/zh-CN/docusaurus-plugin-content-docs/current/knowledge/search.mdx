# 搜索

Agent 使用 `knowledge_search` 查找页面，默认按关键词匹配。本页说明关键词搜索如何找到页面，以及如何添加语义搜索。

:::alpha

Knowledge 处于 Alpha 阶段，API 可能随版本变化。

:::

## 搜索如何找到页面 {/* #how-search-finds-pages */}

`knowledge_search` 将查询词与页面名称、描述、正文和笔记内容进行匹配。匹配到的查询词越多，页面排名越靠前。名称中的匹配权重高于描述，描述中的匹配权重又高于正文。页面排在笔记之前。

将用户常搜的词写进页面名称和描述，能让页面更容易被搜到。完整的排序规则见 [`knowledge_search`](/reference/knowledge/knowledge-tools#knowledge_search)。

搜索只返回本次运行有权读取的内容。

使用 `MongoDBStore` 时，如果一次运行可以读取多个作用域，请传入 `scope` 以保持搜索速度。不指定 `scope` 时，搜索会先收集本次运行可读取的全部作用域，数量越多，搜索越慢。

## 添加语义搜索 {/* #add-search-by-meaning */}

传入 `vector` 向量存储和 `embedder` 后，搜索除了按关键词匹配，还能按含义匹配页面和笔记。例如，搜索“报销”时，即使某个页面只提到如何拿回垫付的钱，也能找到它。

```typescript title="src/mastra/knowledge.ts"
import { Knowledge, knowledgeMemoryScopes } from '@mastra/core/knowledge'
import { ModelRouterEmbeddingModel } from '@mastra/core/llm'
import { LibSQLStore, LibSQLVector } from '@mastra/libsql'

export const knowledge = new Knowledge({
  id: 'company',
  storage: new LibSQLStore({ id: 'knowledge', url: 'file:./knowledge.db' }),
  vector: new LibSQLVector({ id: 'knowledge-vector', url: 'file:./knowledge.db' }),
  embedder: new ModelRouterEmbeddingModel('__GATEWAY_OPENAI_EMBEDDING_MODEL__'),
  scopes: { ...knowledgeMemoryScopes() },
  tools: true,
})
```

这两个参数必须同时传入或同时省略。[`embedderOptions`](/reference/knowledge/knowledge-class#constructor-options) 的用法与 Memory 中相同。

`knowledge_search` 会按排名合并关键词搜索和语义搜索的结果，因此语义高度相近的结果可能排在名称匹配的结果之前。每条语义命中加入结果前，都会按本次运行的权限重新读取。无法读取的命中会被丢弃，不占结果名额。与 Alpha 阶段的其他访问检查一样，这无法保证形成[隔离边界](/docs/knowledge/scopes-and-access)。搜索最多检查 1,000 条语义候选结果，因此如果大多数靠前的结果都不可读，排名较低的可读结果可能会被遗漏。

页面和笔记在写入时生成向量。作用域页面本身不会生成向量，但附在其上的笔记会。长页面会分段生成向量，但每个页面在结果中只出现一次。大小限制见[限制](/reference/knowledge/limits)。

Knowledge 不会为已有内容补建向量。在添加 `vector` 和 `embedder` 前写入的页面和笔记，只能通过关键词找到，直到内容发生变更。

如果存储中已有向量，请避免更换嵌入模型。Knowledge 暂不支持重新生成这些向量。

- **维度不同**。搜索会使用新索引，因此已有内容在变更前只能按关键词搜索。
- **维度相同**。搜索会继续用旧向量与新模型生成的查询向量比较。各页面更新前，匹配效果较差。

### 生成向量失败时 {/* #when-embedding-fails */}

写入页面或笔记时，如果生成或写入向量失败，Knowledge 会分别在约半秒、2 秒和 7.5 秒后重试。这覆盖了数据库缩容到零后需几秒唤醒的情况。对于供应商标记为不可重试的错误，例如 API 密钥无效，Knowledge 不会重试。

如果所有尝试都失败，页面或笔记仍会成功写入，Mastra 会记录警告。新增内容只能通过关键词找到。更新过的内容会保留原有向量，所以语义搜索仍匹配旧内容。这两种情况都会持续到下次写入时内容发生变更。如果调用 `upsertPage()` 返回 `unchanged`，就不会写入任何内容，也不会为页面生成向量。

如果搜索时嵌入模型或向量存储出现故障，搜索会返回关键词结果并记录警告。
