# 载入自有内容

Agent 工作时会向 Knowledge 写入内容。产品文档或公司政策等资料通常需要提前准备，可在自己的服务器代码中调用 [`upsertPage()`](/reference/knowledge/knowledge-class#upsertpage) 和 [`addNote()`](/reference/knowledge/knowledge-class#addnote) 写入初始内容。

Knowledge 暂未提供导入工具。计划提供的导入工具将使 Knowledge 与其他系统保持同步。在此之前，请按下文示例通过服务器代码写入初始内容。

:::alpha

Knowledge 处于 Alpha 阶段，API 可能随版本变更。

:::

## 声明内容的作用域 {/* #declare-a-scope-for-the-content */}

为初始内容指定专用的作用域类型，并定义谁可以读取这些内容：

```typescript title="src/mastra/knowledge.ts"
import { Knowledge, knowledgeMemoryScopes } from '@mastra/core/knowledge'
import { LibSQLStore } from '@mastra/libsql'

export const knowledge = new Knowledge({
  id: 'company',
  storage: new LibSQLStore({ id: 'knowledge', url: 'file:./knowledge.db' }),
  scopes: {
    ...knowledgeMemoryScopes(),
    'docs:$orgId': {
      description: 'Product docs',
      belongsTo: 'org:$orgId',
      access: [{ principal: 'org:$orgId', role: 'viewer' }],
    },
  },
  tools: true,
})
```

`belongsTo` 将文档放在作用域树的组织节点下。组织内的 Agent 可以读取这些页面，但不能修改。

## 写入页面 {/* #write-the-pages */}

将每份文档写入该作用域中的一个路径。例如，`guides/install` 对应页面 `docs:acme#guides/install`，路径上缺少的页面会自动创建：

```typescript title="src/seed-docs.ts"
import { knowledge } from './mastra/knowledge'

type Doc = { slug: string; title: string; markdown: string }

export async function seedDocs(orgId: string, docs: Doc[]) {
  for (const doc of docs) {
    await knowledge.upsertPage({
      scope: `docs:${orgId}`,
      path: doc.slug,
      name: doc.title,
      body: doc.markdown,
      author: 'seed:docs',
    })
  }
}
```

运行时持有 `org:acme` 作用域的 Agent 现在可以搜索并读取这些页面。如果配置了 `vector` 和 `embedder`，`upsertPage()` 还会为每个页面生成向量嵌入，以支持[语义搜索](/docs/knowledge/search#add-search-by-meaning)。

如需记录带日期的事实或为页面添加评论，可以新增一条笔记。目标页面创建后，引用 `[[docs:acme#releases/2026-12]]` 就会变成链接：

```typescript title="src/seed-docs.ts"
await knowledge.addNote({
  scope: 'docs:acme',
  path: 'guides/install',
  text: 'Node 18 support ends on [[docs:acme#releases/2026-12]].',
  when: new Date('2026-11-01'),
  author: 'seed:docs',
})
```

这些方法仅供受信任的服务器代码使用。它们不会检查运行的作用域或访问规则，因此请勿在 Agent Tool 或未经管理员级别身份验证的路由中调用。

## 保持内容同步 {/* #keep-content-in-sync */}

源内容变更时，重新运行初始化代码。`upsertPage()` 只更新有变化的页面，跳过未变更的页面，因此重复运行时不会重写未变更的页面，也不会为它们重新生成嵌入。

每次调用 `addNote()` 都会新增一条笔记，运行两次初始化代码会产生重复笔记。只添加一次，或通过 [`updateNote()`](/reference/knowledge/knowledge-class#updatenote) 修改现有笔记。

从源中删除的文档仍会留在 Knowledge 中，请通过 [`removePage()`](/reference/knowledge/knowledge-class#removepage) 删除。有子页面时，须先删除子页面再删除父页面。
