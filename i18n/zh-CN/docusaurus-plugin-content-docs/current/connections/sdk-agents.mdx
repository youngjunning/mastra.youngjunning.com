# SDKAgent

SDK Agent允许您在 Mastra 内使用其他Agent SDK 框架。使用它们在 Mastra 项目中注册 SDK 支持的Agent，而Provider SDK 保留自己的运行时、Tool、权限和Agent循环。

## 何时使用 SDK Agent {/* #when-to-use-sdk-agents */}

* Provider SDK 已拥有Agent循环、Tool、权限或本地运行时。
* 您想要在 Mastra 项目中注册 SDK 支持的Agent。
* 您需要与 Mastra 兼容`generate()` and `stream()` outputs.
* 您希望 SDK 运行中的使用情况、成本和Tool活动显示在 Mastra 可观察性中。

## 支持的 SDK Agent {/* #supported-sdk-agents */}

* [克劳德AgentSDK](#claude-agent-sdk)： 使用`@mastra/claude` to register a Claude SDK agent and call it with Mastra `generate()` and `stream()`.
* [光标AgentSDK](#cursor-agent-sdk)： 使用`@mastra/cursor` to register a Cursor SDK agent and call it with Mastra `generate()` and `stream()`.
* [OpenAI Agent SDK](#openai-agents-sdk)： 使用`@mastra/openai` to register an OpenAI SDK agent and call it with Mastra `generate()` and `stream()`.

没有专用 Mastra 包的编码Agent，例如 Cline 和 OpenCode，通过[Agent Client Protocol](/docs/connections/acp) instead.

## 克劳德AgentSDK {/* #claude-agent-sdk */}

使用`@mastra/claude` for Claude Code runtime configuration, permissions, tools, and agent-loop behavior.

### 安装克劳德软件包 {/* #install-claude-packages */}

安装 Mastra 包和 Claude Agent SDK 对等依赖项：

```bash npm2yarn
npm install @mastra/claude @anthropic-ai/claude-agent-sdk zod
```

设置 Claude SDK 凭证：

```bash
export ANTHROPIC_API_KEY="..."
```

### 创建 Claude SDK Agent {/* #create-a-claude-sdk-agent */}

通过配置Claude Agent SDK`sdkOptions`.

```typescript title="src/mastra/agents/claude-sdk-agent.ts"
import { ClaudeSDKAgent } from '@mastra/claude'

export const claudeSDKAgent = new ClaudeSDKAgent({
  id: 'claude-sdk-agent',
  name: 'Claude SDK Agent',
  description: 'Use Claude Agent SDK through Mastra.',
  sdkOptions: {
    model: '__AI_SDK_ANTHROPIC_MODEL_SONNET__',
    cwd: process.cwd(),
  },
})
```

### 添加Claude SDKTool {/* #add-claude-sdk-tools */}

Claude Agent SDK 自定义Tool通过 Claude SDK 模型上下文协议 (MCP) 服务器提供。`ClaudeSDKAgent` doesn't accept Mastra's `tools` option, and tools created with Mastra's `createTool()` aren't automatically available to it because the Claude SDK owns the agent loop. A Mastra tool can't be passed directly to `createSdkMcpServer()`.

使用 Claude Agent SDK 创建Tool`tool()` helper, add it to a server, then pass the server through `sdkOptions.mcpServers`. The helper takes a raw Zod shape, not a `z.object()`, and a handler that returns MCP content. This example returns sample temperature data:

```typescript title="src/mastra/agents/claude-sdk-agent.ts"
import { createSdkMcpServer, tool } from '@anthropic-ai/claude-agent-sdk'
import { ClaudeSDKAgent } from '@mastra/claude'
import { z } from 'zod'

const getTemperature = tool(
  'get_temperature',
  'Get the temperature for a city using sample data.',
  { city: z.string() },
  async ({ city }) => ({
    content: [{ type: 'text', text: `${city}: 27 C` }],
  }),
)

const weatherServer = createSdkMcpServer({
  name: 'weather',
  version: '1.0.0',
  tools: [getTemperature],
})

export const claudeSDKAgent = new ClaudeSDKAgent({
  id: 'claude-sdk-agent',
  name: 'Claude SDK Agent',
  description: 'Use Claude Agent SDK through Mastra.',
  sdkOptions: {
    model: '__AI_SDK_ANTHROPIC_MODEL_SONNET__',
    cwd: process.cwd(),
    mcpServers: {
      weather: weatherServer,
    },
    allowedTools: ['mcp__weather__get_temperature'],
  },
})
```

这`allowedTools` value uses Claude Agent SDK MCP tool naming: `mcp__<server name>__<tool name>`.

## 光标AgentSDK {/* #cursor-agent-sdk */}

使用`@mastra/cursor` to register a Cursor SDK agent in Mastra while keeping Cursor-specific setup in Cursor SDK options.

### 安装光标包 {/* #install-cursor-packages */}

安装 Mastra 包和 Cursor SDK 对等依赖项：

```bash npm2yarn
npm install @mastra/cursor @cursor/sdk
```

设置 Cursor SDK 凭据：

```bash
export CURSOR_API_KEY="..."
```

### 创建 Cursor SDK Agent {/* #create-a-cursor-sdk-agent */}

通过配置Cursor Agent SDK`sdkOptions`.

```typescript title="src/mastra/agents/cursor-sdk-agent.ts"
import { CursorSDKAgent } from '@mastra/cursor'

export const cursorSDKAgent = new CursorSDKAgent({
  id: 'cursor-sdk-agent',
  name: 'Cursor SDK Agent',
  description: 'Use Cursor Agent SDK through Mastra.',
  sdkOptions: {
    apiKey: process.env.CURSOR_API_KEY,
    model: {
      id: '__AI_SDK_OPENAI_MODEL_BASE__',
    },
    local: {
      cwd: process.cwd(),
    },
  },
})
```

游标本地Agent需要显式模型。将其设置为`sdkOptions.model`.

### 使用现有的 Cursor SDK Agent {/* #use-an-existing-cursor-sdk-agent */}

如果您的应用程序已创建 Cursor SDK Agent，请将该Agent传递给`CursorSDKAgent` instead:

```typescript title="src/mastra/agents/cursor-sdk-agent.ts"
import { Agent as CursorAgent } from '@cursor/sdk'
import { CursorSDKAgent } from '@mastra/cursor'

const cursorAgent = CursorAgent.create({
  apiKey: process.env.CURSOR_API_KEY,
  model: {
    id: '__AI_SDK_OPENAI_MODEL_BASE__',
  },
  local: {
    cwd: process.cwd(),
  },
})

export const cursorSDKAgent = new CursorSDKAgent({
  id: 'cursor-sdk-agent',
  name: 'Cursor SDK Agent',
  description: 'Use Cursor Agent SDK through Mastra.',
  agent: cursorAgent,
})
```

### 添加光标SDKTool {/* #add-cursor-sdk-tools */}

Cursor Agent SDK Tool使用 Cursor SDK 选项进行配置。通过模型上下文协议 (MCP) 服务器`sdkOptions.mcpServers`:

```typescript title="src/mastra/agents/cursor-sdk-agent.ts"
import { CursorSDKAgent } from '@mastra/cursor'
import { mcpServers } from '../mcp/cursor'

export const cursorSDKAgent = new CursorSDKAgent({
  id: 'cursor-sdk-agent',
  name: 'Cursor SDK Agent',
  description: 'Use Cursor Agent SDK through Mastra.',
  sdkOptions: {
    apiKey: process.env.CURSOR_API_KEY,
    model: {
      id: '__AI_SDK_OPENAI_MODEL_BASE__',
    },
    local: {
      cwd: process.cwd(),
    },
    mcpServers,
  },
})
```

## OpenAI Agent SDK {/* #openai-agents-sdk */}

使用`@mastra/openai` to register an OpenAI Agents SDK agent in Mastra while keeping OpenAI-specific agent settings in OpenAI SDK options.

### 安装 OpenAI 软件包 {/* #install-openai-packages */}

安装 Mastra 包和 OpenAI Agents SDK 对等依赖项：

```bash npm2yarn
npm install @mastra/openai @openai/agents zod
```

设置 OpenAI SDK 凭证：

```bash
export OPENAI_API_KEY="..."
```

### 创建 OpenAI SDK Agent {/* #create-an-openai-sdk-agent */}

通过配置 OpenAI Agents SDK`sdkOptions`. `OpenAISDKAgent` creates the OpenAI SDK agent on first use.

```typescript title="src/mastra/agents/openai-sdk-agent.ts"
import { OpenAISDKAgent } from '@mastra/openai'

export const openaiSDKAgent = new OpenAISDKAgent({
  id: 'openai-sdk-agent',
  name: 'OpenAI SDK Agent',
  description: 'Use OpenAI Agents SDK through Mastra.',
  sdkOptions: {
    name: 'Repository assistant',
    instructions: 'Answer clearly and cite the relevant files.',
    model: '__AI_SDK_OPENAI_MODEL_BASE__',
  },
})
```

### 使用现有的 OpenAI SDK Agent {/* #use-an-existing-openai-sdk-agent */}

如果您的应用程序已创建 OpenAI SDK Agent，请将该Agent传递给`OpenAISDKAgent` instead:

```typescript title="src/mastra/agents/openai-sdk-agent.ts"
import { Agent as OpenAIAgent } from '@openai/agents'
import { OpenAISDKAgent } from '@mastra/openai'

const sdkAgent = new OpenAIAgent({
  name: 'Repository assistant',
  instructions: 'Answer clearly and cite the relevant files.',
  model: '__AI_SDK_OPENAI_MODEL_BASE__',
})

export const openaiSDKAgent = new OpenAISDKAgent({
  id: 'openai-sdk-agent',
  name: 'OpenAI SDK Agent',
  description: 'Use OpenAI Agents SDK through Mastra.',
  agent: sdkAgent,
})
```

### 添加OpenAI SDKTool {/* #add-openai-sdk-tools */}

OpenAI Agents SDK Tool使用 OpenAI SDK 选项进行配置。使用 OpenAI SDK 创建Tool，然后传递它们`sdkOptions.tools`.

```typescript title="src/mastra/agents/openai-sdk-agent.ts"
import { tool } from '@openai/agents'
import { OpenAISDKAgent } from '@mastra/openai'
import { z } from 'zod'

const getTemperature = tool({
  name: 'get_temperature',
  description: 'Get the current temperature for a city.',
  parameters: z.object({
    city: z.string(),
  }),
  execute: async ({ city }) => {
    return `${city}: 27 C`
  },
})

export const openaiSDKAgent = new OpenAISDKAgent({
  id: 'openai-sdk-agent',
  name: 'OpenAI SDK Agent',
  description: 'Use OpenAI Agents SDK through Mastra.',
  sdkOptions: {
    name: 'Weather assistant',
    model: '__AI_SDK_OPENAI_MODEL_BASE__',
    tools: [getTemperature],
  },
})
```

## 注册SDKAgent {/* #register-sdk-agents */}

像其他Agent一样在 Mastra 实例中注册 SDK Agent：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { claudeSDKAgent } from './agents/claude-sdk-agent'
import { cursorSDKAgent } from './agents/cursor-sdk-agent'
import { openaiSDKAgent } from './agents/openai-sdk-agent'

export const mastra = new Mastra({
  agents: {
    claudeSDKAgent,
    cursorSDKAgent,
    openaiSDKAgent,
  },
})
```

注册后，请致电他们`mastra.getAgentById()`:

```typescript title="src/mastra/run-sdk-agent.ts"
import { mastra } from './index'

const agent = mastra.getAgentById('cursor-sdk-agent')
const stream = await agent.stream('Inspect this project and describe the test setup.')

for await (const chunk of stream.textStream) {
  process.stdout.write(chunk)
}
```

## 恢复 SDK 运行 {/* #resume-sdk-runs */}

SDKAgent支持Mastra`resumeGenerate()` and `resumeStream()` with provider-native resume data. Pass the message to continue with and the resume identifier used by the underlying SDK.

Claude SDK Agent可以恢复已知会话`sessionId`:

```typescript title="src/mastra/resume-claude.ts"
const result = await claudeSDKAgent.resumeGenerate({
  message: 'Continue the previous task.',
  sessionId: 'claude-session-id',
})

console.log(result.text)
```

OpenAI SDK Agent可以恢复之前的响应、对话或会话：

```typescript title="src/mastra/resume-openai.ts"
const stream = await openaiSDKAgent.resumeStream({
  message: 'Continue the previous task.',
  previousResponseId: 'resp_123',
})

for await (const chunk of stream.textStream) {
  process.stdout.write(chunk)
}
```

Cursor SDK Agent可以继续使用包装的 SDK Agent。如果需要通过 ID 恢复存储的 Cursor SDK Agent，请通过`agentId` in `resumeData`.

## 结构化输出 {/* #structured-output */}

Claude 和 OpenAI SDK Agent支持 Mastra`structuredOutput` through their provider-native structured output APIs. The validated value is available on `result.object`.

```typescript title="src/mastra/run-openai-structured-output.ts"
import { z } from 'zod'

const result = await openaiSDKAgent.generate<{ summary: string }>('Summarize this project.', {
  structuredOutput: {
    schema: z.object({
      summary: z.string(),
    }),
  },
})

console.log(result.object.summary)
```

Cursor SDK Agent在以下情况下会抛出明显的错误：`structuredOutput` is requested because the Cursor TypeScript SDK doesn't expose a schema-constrained output API.

## 可观察性 {/* #observability */}

SDKAgent创建MastraAgent和模型跨度`generate()` and `stream()` calls. Mastra records SDK-provided usage, tool activity, and provider metadata when the vendor SDK exposes those events.

Claude SDK 运行可以包括来自 Claude 结果消息的 SDK 估计成本。 Cursor SDK 运行包括来自 Cursor 交互更新的令牌使用情况。 OpenAI SDK 运行包括 OpenAI 运行状态中的令牌使用情况。

有关存储和仪表板设置，请参阅[Observability](/docs/observability/overview).
