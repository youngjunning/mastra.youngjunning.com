# SDK Agent

SDK Agent 让你在 Mastra 中使用其他 Agent SDK 框架。你可以将由 SDK 驱动的 Agent 注册到 Mastra 项目中，提供方的 SDK 仍负责自身的运行时、Tool、权限和 Agent 循环。

## 何时使用 SDK Agent {/* #when-to-use-sdk-agents */}

- 供应商 SDK 已负责 Agent 循环、Tool、权限或本地运行时。
- 你希望将由该 SDK 驱动的 Agent 注册到 Mastra 项目中。
- 你需要与 Mastra 兼容的 `generate()` 和 `stream()` 输出。
- 你希望在 Mastra 可观测性功能中看到 SDK 运行的用量、成本和 Tool 活动。

## 支持的 SDK Agent {/* #supported-sdk-agents */}

- [Claude Agent SDK](#claude-agent-sdk)：用 `@mastra/claude` 注册 Claude SDK Agent，再通过 Mastra 的 `generate()` 和 `stream()` 调用。
- [Cursor Agent SDK](#cursor-agent-sdk)：用 `@mastra/cursor` 注册 Cursor SDK Agent，再通过 Mastra 的 `generate()` 和 `stream()` 调用。
- [OpenAI Agents SDK](#openai-agents-sdk)：用 `@mastra/openai` 注册 OpenAI SDK Agent，再通过 Mastra 的 `generate()` 和 `stream()` 调用。

Cline 和 OpenCode 等没有专用 Mastra 包的编程 Agent 通过 [Agent Client Protocol](/docs/connections/acp) 运行。

## Claude Agent SDK {/* #claude-agent-sdk */}

使用 `@mastra/claude` 配置 Claude Code 的运行时、权限、Tool 和 Agent 循环行为。

### 安装 Claude 相关包 {/* #install-claude-packages */}

安装 Mastra 包以及作为对等依赖的 Claude Agent SDK：

```bash npm2yarn
npm install @mastra/claude @anthropic-ai/claude-agent-sdk zod
```

设置 Claude SDK 凭证：

```bash
export ANTHROPIC_API_KEY="..."
```

### 创建 Claude SDK Agent {/* #create-a-claude-sdk-agent */}

通过 `sdkOptions` 配置 Claude Agent SDK。

```typescript title="src/mastra/agents/claude-sdk-agent.ts"
import { ClaudeSDKAgent } from '@mastra/claude'

export const claudeSDKAgent = new ClaudeSDKAgent({
  id: 'claude-sdk-agent',
  name: 'Claude SDK Agent',
  description: 'Use Claude Agent SDK through Mastra.',
  sdkOptions: {
    model: '__AI_SDK_ANTHROPIC_MODEL_SONNET__',
    cwd: process.cwd(),
  },
})
```

### 添加 Claude SDK Tool {/* #add-claude-sdk-tools */}

Claude Agent SDK 通过 Claude SDK 的 Model Context Protocol（MCP）服务器提供自定义 Tool。`ClaudeSDKAgent` 不接受 Mastra 的 `tools` 选项。由于 Agent 循环由 Claude SDK 管理，使用 Mastra 的 `createTool()` 创建的 Tool 不会自动可用，也不能将 Mastra Tool 直接传入 `createSdkMcpServer()`。

使用 Claude Agent SDK 的辅助函数 `tool()` 创建 Tool，将其添加到服务器，再通过 `sdkOptions.mcpServers` 传入该服务器。辅助函数接受原始 Zod 形状定义（不要用 `z.object()` 包装）和一个返回 MCP 内容的处理函数。以下示例返回温度样本数据：

```typescript title="src/mastra/agents/claude-sdk-agent.ts"
import { createSdkMcpServer, tool } from '@anthropic-ai/claude-agent-sdk'
import { ClaudeSDKAgent } from '@mastra/claude'
import { z } from 'zod'

const getTemperature = tool(
  'get_temperature',
  'Get the temperature for a city using sample data.',
  { city: z.string() },
  async ({ city }) => ({
    content: [{ type: 'text', text: `${city}: 27 C` }],
  }),
)

const weatherServer = createSdkMcpServer({
  name: 'weather',
  version: '1.0.0',
  tools: [getTemperature],
})

export const claudeSDKAgent = new ClaudeSDKAgent({
  id: 'claude-sdk-agent',
  name: 'Claude SDK Agent',
  description: 'Use Claude Agent SDK through Mastra.',
  sdkOptions: {
    model: '__AI_SDK_ANTHROPIC_MODEL_SONNET__',
    cwd: process.cwd(),
    mcpServers: {
      weather: weatherServer,
    },
    allowedTools: ['mcp__weather__get_temperature'],
  },
})
```

`allowedTools` 的值采用 Claude Agent SDK 的 MCP Tool 命名格式 `mcp__<server name>__<tool name>`。

## Cursor Agent SDK {/* #cursor-agent-sdk */}

使用 `@mastra/cursor` 在 Mastra 中注册 Cursor SDK Agent，Cursor 专用配置仍由 Cursor SDK 选项管理。

### 安装 Cursor 相关包 {/* #install-cursor-packages */}

安装 Mastra 包以及作为对等依赖的 Cursor SDK：

```bash npm2yarn
npm install @mastra/cursor @cursor/sdk
```

设置 Cursor SDK 凭证：

```bash
export CURSOR_API_KEY="..."
```

### 创建 Cursor SDK Agent {/* #create-a-cursor-sdk-agent */}

通过 `sdkOptions` 配置 Cursor Agent SDK。

```typescript title="src/mastra/agents/cursor-sdk-agent.ts"
import { CursorSDKAgent } from '@mastra/cursor'

export const cursorSDKAgent = new CursorSDKAgent({
  id: 'cursor-sdk-agent',
  name: 'Cursor SDK Agent',
  description: 'Use Cursor Agent SDK through Mastra.',
  sdkOptions: {
    apiKey: process.env.CURSOR_API_KEY,
    model: {
      id: '__AI_SDK_OPENAI_MODEL_BASE__',
    },
    local: {
      cwd: process.cwd(),
    },
  },
})
```

Cursor 本地 Agent 必须显式指定模型。请在 `sdkOptions.model` 中设置。

### 使用现有的 Cursor SDK Agent {/* #use-an-existing-cursor-sdk-agent */}

如果应用已创建 Cursor SDK Agent，可以直接将它传给 `CursorSDKAgent`：

```typescript title="src/mastra/agents/cursor-sdk-agent.ts"
import { Agent as CursorAgent } from '@cursor/sdk'
import { CursorSDKAgent } from '@mastra/cursor'

const cursorAgent = CursorAgent.create({
  apiKey: process.env.CURSOR_API_KEY,
  model: {
    id: '__AI_SDK_OPENAI_MODEL_BASE__',
  },
  local: {
    cwd: process.cwd(),
  },
})

export const cursorSDKAgent = new CursorSDKAgent({
  id: 'cursor-sdk-agent',
  name: 'Cursor SDK Agent',
  description: 'Use Cursor Agent SDK through Mastra.',
  agent: cursorAgent,
})
```

### 添加 Cursor SDK Tool {/* #add-cursor-sdk-tools */}

在 Cursor SDK 选项中配置 Cursor Agent SDK 的 Tool。通过 `sdkOptions.mcpServers` 传入 Model Context Protocol（MCP）服务器：

```typescript title="src/mastra/agents/cursor-sdk-agent.ts"
import { CursorSDKAgent } from '@mastra/cursor'
import { mcpServers } from '../mcp/cursor'

export const cursorSDKAgent = new CursorSDKAgent({
  id: 'cursor-sdk-agent',
  name: 'Cursor SDK Agent',
  description: 'Use Cursor Agent SDK through Mastra.',
  sdkOptions: {
    apiKey: process.env.CURSOR_API_KEY,
    model: {
      id: '__AI_SDK_OPENAI_MODEL_BASE__',
    },
    local: {
      cwd: process.cwd(),
    },
    mcpServers,
  },
})
```

## OpenAI Agents SDK {/* #openai-agents-sdk */}

使用 `@mastra/openai` 在 Mastra 中注册 OpenAI Agents SDK Agent，OpenAI 专用的 Agent 设置仍由 OpenAI SDK 选项管理。

### 安装 OpenAI 相关包 {/* #install-openai-packages */}

安装 Mastra 包以及作为对等依赖的 OpenAI Agents SDK：

```bash npm2yarn
npm install @mastra/openai @openai/agents zod
```

设置 OpenAI SDK 凭证：

```bash
export OPENAI_API_KEY="..."
```

### 创建 OpenAI SDK Agent {/* #create-an-openai-sdk-agent */}

通过 `sdkOptions` 配置 OpenAI Agents SDK。`OpenAISDKAgent` 会在首次使用时创建 OpenAI SDK Agent。

```typescript title="src/mastra/agents/openai-sdk-agent.ts"
import { OpenAISDKAgent } from '@mastra/openai'

export const openaiSDKAgent = new OpenAISDKAgent({
  id: 'openai-sdk-agent',
  name: 'OpenAI SDK Agent',
  description: 'Use OpenAI Agents SDK through Mastra.',
  sdkOptions: {
    name: 'Repository assistant',
    instructions: 'Answer clearly and cite the relevant files.',
    model: '__AI_SDK_OPENAI_MODEL_BASE__',
  },
})
```

### 使用现有的 OpenAI SDK Agent {/* #use-an-existing-openai-sdk-agent */}

如果应用已创建 OpenAI SDK Agent，可以直接将它传给 `OpenAISDKAgent`：

```typescript title="src/mastra/agents/openai-sdk-agent.ts"
import { Agent as OpenAIAgent } from '@openai/agents'
import { OpenAISDKAgent } from '@mastra/openai'

const sdkAgent = new OpenAIAgent({
  name: 'Repository assistant',
  instructions: 'Answer clearly and cite the relevant files.',
  model: '__AI_SDK_OPENAI_MODEL_BASE__',
})

export const openaiSDKAgent = new OpenAISDKAgent({
  id: 'openai-sdk-agent',
  name: 'OpenAI SDK Agent',
  description: 'Use OpenAI Agents SDK through Mastra.',
  agent: sdkAgent,
})
```

### 添加 OpenAI SDK Tool {/* #add-openai-sdk-tools */}

在 OpenAI SDK 选项中配置 OpenAI Agents SDK 的 Tool。使用 OpenAI SDK 创建 Tool，再通过 `sdkOptions.tools` 传入。

```typescript title="src/mastra/agents/openai-sdk-agent.ts"
import { tool } from '@openai/agents'
import { OpenAISDKAgent } from '@mastra/openai'
import { z } from 'zod'

const getTemperature = tool({
  name: 'get_temperature',
  description: 'Get the current temperature for a city.',
  parameters: z.object({
    city: z.string(),
  }),
  execute: async ({ city }) => {
    return `${city}: 27 C`
  },
})

export const openaiSDKAgent = new OpenAISDKAgent({
  id: 'openai-sdk-agent',
  name: 'OpenAI SDK Agent',
  description: 'Use OpenAI Agents SDK through Mastra.',
  sdkOptions: {
    name: 'Weather assistant',
    model: '__AI_SDK_OPENAI_MODEL_BASE__',
    tools: [getTemperature],
  },
})
```

## 注册 SDK Agent {/* #register-sdk-agents */}

与其他 Agent 一样，将 SDK Agent 注册到 Mastra 实例：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { claudeSDKAgent } from './agents/claude-sdk-agent'
import { cursorSDKAgent } from './agents/cursor-sdk-agent'
import { openaiSDKAgent } from './agents/openai-sdk-agent'

export const mastra = new Mastra({
  agents: {
    claudeSDKAgent,
    cursorSDKAgent,
    openaiSDKAgent,
  },
})
```

注册后，通过 `mastra.getAgentById()` 获取并调用这些 Agent：

```typescript title="src/mastra/run-sdk-agent.ts"
import { mastra } from './index'

const agent = mastra.getAgentById('cursor-sdk-agent')
const stream = await agent.stream('Inspect this project and describe the test setup.')

for await (const chunk of stream.textStream) {
  process.stdout.write(chunk)
}
```

## 恢复 SDK 运行 {/* #resume-sdk-runs */}

SDK Agent 支持通过提供方的原生恢复数据使用 Mastra 的 `resumeGenerate()` 和 `resumeStream()`。传入用于继续对话的消息以及底层 SDK 使用的恢复标识符。

Claude SDK Agent 可以通过 `sessionId` 恢复已知会话：

```typescript title="src/mastra/resume-claude.ts"
const result = await claudeSDKAgent.resumeGenerate({
  message: 'Continue the previous task.',
  sessionId: 'claude-session-id',
})

console.log(result.text)
```

OpenAI SDK Agent 可以从先前的响应、对话或会话恢复运行：

```typescript title="src/mastra/resume-openai.ts"
const stream = await openaiSDKAgent.resumeStream({
  message: 'Continue the previous task.',
  previousResponseId: 'resp_123',
})

for await (const chunk of stream.textStream) {
  process.stdout.write(chunk)
}
```

Cursor SDK Agent 可以用其封装的 SDK Agent 继续运行。如需按 ID 恢复已保存的 Cursor SDK Agent，请在 `resumeData` 中传入 `agentId`。

## 结构化输出 {/* #structured-output */}

Claude 和 OpenAI 的 SDK Agent 通过各自提供方的原生结构化输出 API 支持 Mastra 的 `structuredOutput`。通过校验的值可从 `result.object` 获取。

```typescript title="src/mastra/run-openai-structured-output.ts"
import { z } from 'zod'

const result = await openaiSDKAgent.generate<{ summary: string }>('Summarize this project.', {
  structuredOutput: {
    schema: z.object({
      summary: z.string(),
    }),
  },
})

console.log(result.object.summary)
```

当请求 `structuredOutput` 时，Cursor SDK Agent 会抛出明确的错误，因为 Cursor TypeScript SDK 没有提供受模式约束的输出 API。

## 可观测性 {/* #observability */}

调用 `generate()` 和 `stream()` 时，SDK Agent 会创建 Mastra 的 Agent span 和模型 span。如果供应商 SDK 提供相应事件，Mastra 会记录 SDK 提供的用量、Tool 活动和提供方元数据。

Claude SDK 的运行记录可以包含 Claude 结果消息中由 SDK 估算的成本。Cursor SDK 的运行记录包含 Cursor 交互更新中的 token 用量。OpenAI SDK 的运行记录包含 OpenAI 运行状态中的 token 用量。

有关存储和仪表板的配置，请参阅[可观测性](/docs/observability/overview)。
