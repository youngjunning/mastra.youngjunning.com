# 连接

通过连接，Mastra 可以与远程 Agent、编码 Agent、提供方的软件开发工具包（SDK）运行时以及外部 Tool 和资源协作。选择连接类型时，请考虑由哪个系统管理 Agent 的运行时，以及需要交换什么。

- [**模型上下文协议（MCP）**](/docs/connections/mcp)：将 Agent 连接到外部 Tool 和资源，或向兼容 MCP 的系统公开 Mastra 的 Agent、Tool、Workflow、提示和资源。
- [**Agent 间协议（A2A）**](/docs/connections/a2a)：跨服务、框架、供应商或编程语言提供或调用远程 Agent。
- [**Agent 客户端协议（ACP）**](/docs/connections/acp)：运行 Claude Code、Cline 或 OpenCode 等兼容的编码 Agent 进程，将其用作 Mastra Tool 或子 Agent。
- [**SDK Agent**](/docs/connections/sdk-agents)：注册由 Claude、Cursor 或 OpenAI SDK 支持的 Agent，运行时、Tool、权限和 Agent 循环仍由提供方的 SDK 控制。

## 何时使用连接 {/* #when-to-use-connections */}

连接适用于以下场景：

- 将工作委派给在其他服务或运行时中运行的 Agent。
- 让编码 Agent 在项目的 Workspace 中工作。
- 接入提供方原生的 Agent，保留其 SDK 运行时和 Agent 循环。
- 将 Agent 连接到外部 Tool 和资源，或向其他系统提供 Mastra 的功能。

## 开始使用 {/* #get-started */}

根据需要对接的对象选择连接类型。远程 Agent 端点使用 [A2A](/docs/connections/a2a)，编码 Agent 进程使用 [ACP](/docs/connections/acp)，由提供方控制的运行时使用 [SDK Agent](/docs/connections/sdk-agents)，Tool 和资源使用 [MCP](/docs/connections/mcp)。

<Tabs>
  <TabItem value="a2a" label="A2A">
    ```typescript
    import { A2AAgent } from '@mastra/core/a2a'

    const agent = new A2AAgent({
      url: 'https://agent.example.com/.well-known/agent-card.json',
    })

    const result = await agent.generate('Summarize the latest report')
    console.log(result.text)
    ```
  </TabItem>

  <TabItem value="acp" label="ACP">
    ```typescript
    import { AcpAgent } from '@mastra/acp'

    const agent = new AcpAgent({
      id: 'coding-agent',
      description: 'Inspects and edits code',
      command: 'claude',
      args: ['--acp'],
      persistSession: false,
    })

    const result = await agent.generate('Review this project')
    console.log(result.text)
    ```
  </TabItem>

  <TabItem value="sdk-agents" label="SDK agents">
    ```typescript
    import { OpenAISDKAgent } from '@mastra/openai'

    const agent = new OpenAISDKAgent({
      id: 'openai-agent',
      description: 'Answers project questions',
      sdkOptions: {
        name: 'Project assistant',
        model: '__AI_SDK_OPENAI_MODEL_BASE__',
      },
    })

    const result = await agent.generate('Explain agent loops in one sentence')
    console.log(result.text)
    ```
  </TabItem>

  <TabItem value="mcp" label="MCP">
    ```typescript
    import { MCPClient } from '@mastra/mcp'

    const client = new MCPClient({
      id: 'wikipedia-client',
      servers: {
        wikipedia: {
          command: 'npx',
          args: ['-y', 'wikipedia-mcp'],
        },
      },
    })

    try {
      const tools = await client.listTools()
      console.log(Object.keys(tools))
    } finally {
      await client.disconnect()
    }
    ```
  </TabItem>
