# 连接

通过连接，Mastra 可以与远程Agent、编码Agent、Provider软件开发Tool包 (SDK) 运行时以及外部Tool和资源配合使用。根据拥有Agent运行时的系统以及您需要交换的内容来选择连接类型。

* [**模型上下文协议 (MCP)**](/docs/connections/mcp)：将Agent连接到外部Tool和资源，或将 Mastra Agent、Tool、Workflow程、提示和资源公开给 MCP 兼容系统。
* [**Agent对Agent (A2A)**](/docs/connections/a2a)：跨服务、框架、Provider和语言边界公开或使用远程Agent。
* [**Agent客户端协议 (ACP)**](/docs/connections/acp)：运行兼容的编码Agent进程，例如 Claude Code、Cline 或 OpenCode，作为 Mastra Tool或子Agent。
* [**SDKAgent**](/docs/connections/sdk-agents)：注册 Claude、Cursor 或 OpenAI SDK 支持的Agent，而Provider SDK 保留对运行时、Tool、权限和Agent循环的控制。

## 何时使用连接 {/* #when-to-use-connections */}

当您需要执行以下操作时使用连接：

* 将工作委托给在另一个服务或运行时中运行的Agent。
* 针对项目Workspace运行编码Agent。
* 添加Provider本机Agent，无需替换其 SDK 运行时或Agent循环。
* 将Agent连接到外部Tool和资源或将 Mastra 功能发布到其他系统。

## 开始使用 {/* #get-started */}

从你需要跨越的边界开始。使用[A2A](/docs/connections/a2a) for remote agent endpoints, [ACP](/docs/connections/acp) for coding-agent processes, [SDK agents](/docs/connections/sdk-agents) for provider-owned runtimes, or [MCP](/docs/connections/mcp) for tools and resources.

<Tabs>
  <TabItem value="a2a" label="A2A">
    ```typescript
    import { A2AAgent } from '@mastra/core/a2a'

    const agent = new A2AAgent({
      url: 'https://agent.example.com/.well-known/agent-card.json',
    })

    const result = await agent.generate('Summarize the latest report')
    console.log(result.text)
    ```
  </TabItem>

  <TabItem value="acp" label="ACP">
    ```typescript
    import { AcpAgent } from '@mastra/acp'

    const agent = new AcpAgent({
      id: 'coding-agent',
      description: 'Inspects and edits code',
      command: 'claude',
      args: ['--acp'],
      persistSession: false,
    })

    const result = await agent.generate('Review this project')
    console.log(result.text)
    ```
  </TabItem>

  <TabItem value="sdk-agents" label="SDK agents">
    ```typescript
    import { OpenAISDKAgent } from '@mastra/openai'

    const agent = new OpenAISDKAgent({
      id: 'openai-agent',
      description: 'Answers project questions',
      sdkOptions: {
        name: 'Project assistant',
        model: '__AI_SDK_OPENAI_MODEL_BASE__',
      },
    })

    const result = await agent.generate('Explain agent loops in one sentence')
    console.log(result.text)
    ```
  </TabItem>

  <TabItem value="mcp" label="MCP">
    ```typescript
    import { MCPClient } from '@mastra/mcp'

    const client = new MCPClient({
      id: 'wikipedia-client',
      servers: {
        wikipedia: {
          command: 'npx',
          args: ['-y', 'wikipedia-mcp'],
        },
      },
    })

    try {
      const tools = await client.listTools()
      console.log(Object.keys(tools))
    } finally {
      await client.disconnect()
    }
    ```
  </TabItem>
