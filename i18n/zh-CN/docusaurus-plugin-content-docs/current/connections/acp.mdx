# Agent Client Protocol

Mastra 支持 [Agent Client Protocol (ACP)](https://agentclientprotocol.com/overview/introduction)，可让 Mastra Agent 调用兼容 ACP 的编程 Agent。用 `@mastra/acp` 可将编程 Agent 的进程封装为 Mastra Tool 或子 Agent。

ACP 适用于 Claude Code、Cline、OpenCode、Amp 和 Codex 等编程 Agent，也适用于任何通过标准输入和输出实现 ACP 的可执行程序。

## 何时使用 ACP {/* #when-to-use-acp */}

- 需要让 Mastra Agent 把代码检查、编辑或仓库任务交给外部编程 Agent。
- 需要让兼容 ACP 的 Agent 进程在多次调用间保持运行，保留会话上下文。
- 上层 Agent 需要在任务执行期间实时接收编程 Agent 的输出。
- 兼容 ACP 的 Agent 需要在读写文件或执行操作之前请求授权。
- 文件访问需要经过 Mastra 的 Workspace 抽象层，而不是由进程直接访问。

## ACP 的工作原理 {/* #how-acp-works */}

`@mastra/acp` 将配置的 ACP Agent 命令作为子进程启动，通过标准输入和输出交换以换行符分隔的 JSON。

具体流程如下：

1. 配置 `command`、`args` 和可选的连接设置。
2. `@mastra/acp` 在首次使用时启动 ACP Agent 进程。
3. 客户端发送 ACP 的 `initialize` 和 `session/new` 请求。
4. Mastra 通过 `session/prompt` 将用户任务发送给 ACP Agent。
5. ACP Agent 将会话更新和消息片段流式传回 Mastra。
6. Mastra 返回缓冲的输出、发出流数据块，或处理用户的权限选择。
7. 若 `persistSession` 为 `false`，ACP 连接会在提示处理完毕后停止进程。默认情况下，`AcpAgent` 可以让进程在多次调用间保持运行，以便复用。

运行期间，ACP 客户端也会处理权限请求和文件操作。Agent 通过协议发出的文件读写请求由 Mastra 的 `Workspace` 处理。Workspace 只覆盖这些请求：Agent 进程在配置的 `cwd` 下运行，未经过沙箱或其他隔离，仍可通过自己的工具和 Shell 命令访问文件。

## 兼容的 Agent {/* #compatible-agents */}

凡是通过标准输入和输出实现 ACP 的可执行文件，都可以与 `@mastra/acp` 配合使用，无需为每个 Agent 安装专用的 Mastra 包。安装 Agent 后，通过 `command` 和 `args` 传入启动命令。

| Agent | `command` | `args` |
| - | - | - |
| Cline | `cline` | `['--acp']` |
| OpenCode | `opencode` | `['acp']` |
| Gemini CLI | `gemini` | `['--acp']` |

各 Agent 的文档会说明自己的 ACP 模式，启动选项可能随版本变化。当前命令请查阅相应文档，例如 [Cline ACP](https://docs.cline.bot/usage/acp) 或 [OpenCode ACP](https://opencode.ai/docs/acp/)。

## 入门 {/* #getting-started */}

在已使用 `@mastra/core` 的项目中安装 `@mastra/acp`，要求 `@mastra/core` 为 `1.34.0` 或更高版本。

```bash npm2yarn
npm install @mastra/acp
```

`@mastra/acp` 导出两个 API：

- [`createACPTool()`](/reference/acp/create-acp-tool)：创建 Mastra Tool，向 ACP Agent 发送 `task` 字符串并返回 `output` 字符串。
- [`AcpAgent`](/reference/acp/acp-agent)：将 ACP Agent 封装为支持 `generate()` 和 `stream()` 的 Mastra 子 Agent。

## 将 ACP 用作子 Agent {/* #use-acp-as-a-subagent */}

如果需要由上层 Mastra Agent 直接将任务交给兼容 ACP 的编程子 Agent，请使用 `AcpAgent`。

```typescript title="src/mastra/agents/code-supervisor.ts"
import { AcpAgent } from '@mastra/acp'
import { Agent } from '@mastra/core/agent'

const codeAgent = new AcpAgent({
  id: 'code-agent',
  name: 'Code Agent',
  description: 'An ACP-compatible coding agent that can inspect and edit files',
  command: 'opencode',
  args: ['acp'],
  cwd: process.cwd(),
})

export const codeSupervisor = new Agent({
  id: 'code-supervisor',
  name: 'Code Supervisor',
  instructions: 'Delegate code editing tasks to the code-agent subagent.',
  model: '__GATEWAY_OPENAI_MODEL__',
  agents: {
    codeAgent,
  },
})
```

完整的选项、方法和配置见 [AcpAgent 参考](/reference/acp/acp-agent)。

## 将 ACP 用作 Tool {/* #use-acp-as-a-tool */}

如需让上层 Mastra Agent 自行决定何时把 ACP Agent 当作 Tool 调用，请使用 `createACPTool()`。

```typescript title="src/mastra/agents/code-supervisor.ts"
import { createACPTool } from '@mastra/acp'
import { Agent } from '@mastra/core/agent'

const codeAgentTool = createACPTool({
  id: 'code-agent',
  description: 'Use an ACP-compatible coding agent to inspect and edit code',
  command: 'opencode',
  args: ['acp'],
  cwd: process.cwd(),
})

export const codeSupervisor = new Agent({
  id: 'code-supervisor',
  name: 'Code Supervisor',
  instructions: 'Use the code-agent tool when a task requires repository inspection or code edits.',
  model: '__GATEWAY_OPENAI_MODEL__',
  tools: {
    codeAgentTool,
  },
})
```

完整的选项和配置见 [createACPTool() 参考](/reference/acp/create-acp-tool)。

## 选择模型 {/* #model-selection */}

ACP Agent 可能提供多个模型供选择。在 ACP 配置中传入 `model`，可在创建会话后选择模型；也可在运行期间用 `AcpAgent.getAvailableModels()` 和 `AcpAgent.setModel()` 管理模型。

示例见 [AcpAgent 的模型管理方法](/reference/acp/acp-agent#model-management)。

## 会话生命周期 {/* #session-lifecycle */}

`AcpAgent` 首次使用时会执行配置的命令并创建 ACP 会话。`persistSession` 默认为 `true`，子进程在多次调用之间保持运行。若希望每次提示都在单独的进程中运行，请设置 `persistSession: false`。

详情见 [AcpAgent 会话生命周期](/reference/acp/acp-agent#session-lifecycle)。

## 权限处理 {/* #permission-handling */}

ACP Agent 可能要求客户端选择权限选项后才继续。默认情况下，`@mastra/acp` 会选中 ACP Agent 返回的第一个选项。要自定义权限处理，请传入 `onPermissionRequest`。

完整示例见 [createACPTool() 的权限处理](/reference/acp/create-acp-tool#permission-handling)。

## 与 Workspace 集成 {/* #workspace-integration */}

ACP 文件请求通过 Mastra 的 Workspace 抽象处理。`AcpAgent` 可以接收 `workspace` 选项；若 Tool 执行上下文中有当前 Mastra Workspace，`createACPTool()` 就会使用它。没有 Workspace 时，`@mastra/acp` 会回退到由 `LocalFilesystem` 支撑的 `Workspace`，根目录取自 `cwd` 或 `process.cwd()`。

自定义 Workspace 的示例见 [AcpAgent 的 Workspace 集成](/reference/acp/acp-agent#workspace-integration)。
