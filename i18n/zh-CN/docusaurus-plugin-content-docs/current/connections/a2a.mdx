# A2A（Agent对Agent）

Mastra 支持 0.3.0 版本[Agent-to-Agent (A2A) protocol](https://a2a-protocol.org/latest/)适用于跨平台多Agent系统。使用 A2A 将 Mastra Agent公开为远程Agent或使用远程 A2A Agent作为 Mastra 子Agent。您还可以使用 JavaScript 客户端 SDK 调用 A2A 端点。

A2A 是一种开放协议，用于跨网络、框架、Provider和语言边界将工作委托给Agent。远程Agent将其自己的Tool、提示、内存、Workflow程和基础设施保持私有，同时公开其他系统可以发现和调用的协议端点。

## 何时使用 A2A {/* #when-to-use-a2a */}

* 父Agent应将工作委托给专门的远程Agent。
* 远程Agent由另一个服务、团队、Provider或运行时拥有。
* 后端、浏览器应用程序或其他 A2A 兼容系统需要以编程方式访问 Mastra Agent。
* 长时间运行的远程工作需要任务 ID、状态更新、工件、取消、重新订阅或推送通知。

## A2A 的运作方式 {/* #how-a2a-works */}

A2A 使用Agent卡进行发现。该卡片是一个由众所周知的 URL 提供的 JSON 文档。它描述远程Agent并包含接受 A2A JSON-RPC 请求的执行 URL。

使用默认 Mastra 服务器时`apiPrefix` of `/api`, an agent registered as `weather-agent` exposes:

* Agent卡：`/api/.well-known/weather-agent/agent-card.json`
* 执行端点：`/api/a2a/weather-agent`

Agent卡包含Agent名称、描述、端点 URL、Provider、功能、安全元数据和技能等字段：

```json title="agent-card.json"
{
  "protocolVersion": "0.3.0",
  "name": "Weather Agent",
  "description": "Provides weather information.",
  "url": "https://agent.example.com/api/a2a/weather-agent",
  "version": "1.0",
  "provider": {
    "organization": "Acme",
    "url": "https://acme.example.com"
  },
  "capabilities": {
    "streaming": true,
    "pushNotifications": true,
    "stateTransitionHistory": false
  },
  "defaultInputModes": ["text/plain"],
  "defaultOutputModes": ["text/plain"],
  "skills": [
    {
      "id": "weather",
      "name": "weather",
      "description": "Gets weather conditions for a location.",
      "tags": ["tool"]
    }
  ]
}
```

A2A 将工作表示为消息和任务。消息携带文本、文件或结构化数据部分。

任务是具有 ID 和生命周期状态的有状态工作单元。客户可以跟踪长时间运行的工作并发送后续轮流。他们还可以在断开连接后取消工作或重新订阅。

## 协议版本 {/* #protocol-versions */}

Mastra 在同一Agent卡和执行 URL 上支持 A2A 协议 v0.3 和 v1.0。这`A2A-Version` request header selects the wire protocol:

* 缺失、空置或`0.3`: Uses the existing v0.3 API.
* `1.0`：使用 v1.0 API。
* 任何其他值：返回`VersionNotSupported` protocol error.

`A2AAgent`和`MastraClient.getA2A()` use v0.3 by default. Set `protocolVersion: '1.0'` on `A2AAgent` for v1.0 subagent delegation, or use `MastraClient.getA2AV1()` for direct v1.0 requests. Both v1.0 clients send `A2A-Version: 1.0` automatically. The direct v1.0 client also adds the `tasks/list` operation.

从以下位置导入 v1.0 协议类型和编解码器`@mastra/core/a2a/v1`. The existing `@mastra/core/a2a/client` export remains on v0.3.

## 开始使用 {/* #get-started */}

A2A 在 Mastra 中有两条常见路径：

* 使用远程 A2A Agent作为 Mastra 子Agent`A2AAgent`.
* 将请求发送到 Mastra A2A 端点`MastraClient.getA2A()`.

使用`A2AAgent` when another Mastra agent should delegate work to a remote agent. Use the client SDK when application code needs to call an A2A-enabled Mastra endpoint directly.

## 使用 A2A Agent作为子Agent {/* #consume-a2a-agents-as-subagents */}

使用`A2AAgent` to wrap a remote A2A agent, then add it to a parent agent with the [supervisor agents](/docs/subagents) pattern. Pass an explicit agent card URL when the remote server hosts multiple agents or uses a custom well-known path. Set `protocolVersion: '1.0'` when the remote agent requires A2A v1.0. Omit it to use v0.3.

```typescript title="src/mastra/agents/support-agent.ts"
import { Agent } from '@mastra/core/agent'
import { A2AAgent } from '@mastra/core/a2a'

const remoteWeatherAgent = new A2AAgent({
  url: 'https://weather.example.com/api/.well-known/weather-agent/agent-card.json',
  protocolVersion: '1.0',
  headers: {
    Authorization: `Bearer ${process.env.WEATHER_AGENT_TOKEN}`,
  },
})

export const supportAgent = new Agent({
  id: 'support-agent',
  name: 'Support Agent',
  instructions: 'Answer user questions and delegate weather questions when needed.',
  model: '__GATEWAY_OPENAI_MODEL__',
  agents: {
    remoteWeatherAgent,
  },
})
```

如果`url` points to a domain, `A2AAgent` fetches the agent card from `/.well-known/agent-card.json`. Use a domain URL for single-agent servers that follow that discovery path. For multi-agent servers, pass the full card URL, such as `https://agent.example.com/api/.well-known/weather-agent/agent-card.json`.

在执行过程中，`A2AAgent`:

* 获取并缓存远程Agent卡。
* 从卡中读取执行 URL 和功能。
* 通话`message/send` or `message/stream` with v0.3, and `SendMessage` or `SendStreamingMessage` with v1.0.
* 将远程消息、任务、工件和状态更新转换为 Mastra 子Agent结果。
* 支持`resumeGenerate()` and `resumeStream()` when the remote task requires follow-up input or resubscription.

如果远程卡不宣传流媒体支持，`A2AAgent.stream()` falls back to the non-streaming generate path and returns a buffered stream result.

## 使用客户端 SDK 发送请求 {/* #send-requests-with-the-client-sdk */}

使用`MastraClient.getA2A()` when you want application code to call an A2A-enabled Mastra agent. Configure `baseUrl` for the server origin and `apiPrefix` when the server doesn't use the default `/api` prefix.

```typescript title="src/a2a-client.ts"
import { MastraClient } from '@mastra/client-js'

const client = new MastraClient({
  baseUrl: 'https://agent.example.com',
  headers: {
    Authorization: `Bearer ${process.env.AGENT_API_TOKEN}`,
  },
})

const a2a = client.getA2A('weather-agent')
const card = await a2a.getAgentCard()

console.log(card.name, card.capabilities)
```

使用`sendMessageStream()` to send a message and receive task status and artifact updates over Server-Sent Events (SSE):

```typescript title="src/a2a-client.ts" oxfmt:false
const stream = a2a.sendMessageStream({
  message: {
    kind: 'message',
    role: 'user',
    messageId: crypto.randomUUID(),
    parts: [{ kind: 'text', text: "What's the weather in Prague?" }],
  },
})

for await (const event of stream) {
  if (event.kind === 'artifact-update') {
    console.log(event.artifact.parts)
  }
}
```

如果流在任务仍在运行时断开连接，请使用`resubscribeTask()` to receive live updates for the in-progress task:

```typescript title="src/a2a-client.ts" oxfmt:false
const updates = a2a.resubscribeTask({
  id: 'task-123',
})

for await (const event of updates) {
  console.log(event)
}
```

### 使用v1.0客户端 {/* #use-the-v10-client */}

使用`getA2AV1()` to opt into the A2A v1.0 wire protocol. The protocol package provides codecs for creating v1 request values from JSON-shaped input:

```typescript title="src/a2a-v1-client.ts"
import { ListTasksRequest } from '@mastra/core/a2a/v1'
import { MastraClient } from '@mastra/client-js'

const client = new MastraClient({
  baseUrl: 'https://agent.example.com',
})

const a2a = client.getA2AV1('weather-agent')
const response = await a2a.listTasks(
  ListTasksRequest.fromJSON({
    contextId: 'customer-support',
    pageSize: 20,
  }),
)

for (const task of response.tasks) {
  console.log(task.id, task.status)
}
```

v1.0客户端支持`getAgentCard()`, `sendMessage()`, `sendMessageStream()`, `getTask()`, `listTasks()`, `cancelTask()`, and `resubscribeTask()`.

## 配置子Agent呼叫 {/* #configure-subagent-calls */}

`A2AAgent`接受经过身份验证或受限环境的请求选项：

```typescript title="src/mastra/agents/support-agent.ts"
import { A2AAgent } from '@mastra/core/a2a'

const remoteWeatherAgent = new A2AAgent({
  url: 'https://weather.example.com/api/.well-known/weather-agent/agent-card.json',
  headers: {
    Authorization: `Bearer ${process.env.WEATHER_AGENT_TOKEN}`,
  },
  retries: 2,
  backoffMs: 250,
  maxBackoffMs: 1000,
  timeoutMs: 30_000,
})
```

您还可以通过`credentials`, `fetch`, and `abortSignal` when the runtime needs custom fetch behavior or request cancellation.

## 人在回路 {/* #human-in-the-loop */}

A2A 模型人机交互 (HITL) 与`input-required` task state. When a task pauses for input, the client provides the missing input by sending a follow-up message with the same `taskId`, and the server continues the task.

Mastra 将其Agent悬浮模型在两个方向上映射到此状态：

* **作为服务器**：当暴露的Agent挂起时，任务将转换为`input-required`. This includes suspensions caused by [tool approval](/docs/agents/human-in-the-loop) or a tool that calls `suspend()`. The task status message includes a text prompt and a data part with the structured `suspendPayload` and `resumeSchema`. A follow-up `message/send` or `message/stream` request with the same `taskId` resumes the suspended run with the provided input.
* **作为客户**：当远程任务到达时`input-required` or `auth-required`, `A2AAgent` returns a suspended result with `finishReason: 'suspended'` and a `suspendPayload`. Calling `resumeGenerate()` or `resumeStream()` sends the input or credentials back to the remote task with the original `taskId`.

```typescript title="src/a2a-hitl.ts"
import { A2AAgent } from '@mastra/core/a2a'

const agent = new A2AAgent({
  url: 'https://agent.example.com/api/.well-known/booking-agent/agent-card.json',
})

const result = await agent.generate('Book a flight to Paris', { runId: 'run-1' })

if (result.finishReason === 'suspended') {
  // Inspect result.suspendPayload, collect input from a human,
  // then resume the remote task.
  const resumed = await agent.resumeGenerate({ approved: true }, { runId: 'run-1' })
  console.log(resumed.text)
}
```

后续消息`input-required` task can carry the resume data as a structured data part, or as JSON or plain text in a text part.

当恢复运行需要额外输入时，任务返回到`input-required` and the flow repeats. Resuming a suspended run requires storage configured on the Mastra server so the suspended run state can be restored across requests.

:::注意
A2A 任务记录位于内存存储中，因此暂停的任务只能由暂停它的同一服务器进程恢复。服务器重新启动或没有粘性路由的水平扩展部署会丢失任务记录，并且后续消息会因任务未找到错误而失败。
:::

## 推送通知 {/* #push-notifications */}

Mastra 支持远程Agent的 A2A 推送通知`capabilities.pushNotifications`. Use push notifications when a client can't keep a stream open, or when a long-running task should update a callback URL after the original request ends.

客户端获得任务 ID 后，可以为该任务注册回调 URL：

```typescript title="src/a2a-client.ts"
await a2a.setTaskPushNotificationConfig({
  taskId: 'task-123',
  pushNotificationConfig: {
    url: 'https://app.example.com/a2a/tasks',
    token: process.env.A2A_WEBHOOK_TOKEN,
  },
})
```

当任务到达时，Mastra Server 将当前任务快照发送到已注册的回调`completed`, `failed`, `canceled`, `rejected`, `input-required`, or `auth-required`. Push notification delivery is best-effort. Protect callback URLs, validate notification tokens, and avoid exposing internal network targets as push notification destinations.

推送通知配置存储在内存中，服务器重启后必须重新注册。

## 签署并验证Agent卡 {/* #sign-and-verify-agent-cards */}

Mastra 支持签名的 A2A Agent卡，因此客户可以验证发现的卡是否来自受信任的发行商，并且在传输过程中未发生更改。在公开远程Agent的 Mastra 服务器上配置签名：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core/mastra'

export const mastra = new Mastra({
  server: {
    a2a: {
      agentCardSigning: {
        privateKey: process.env.A2A_AGENT_CARD_PRIVATE_KEY!,
        protectedHeader: {
          alg: 'ES256',
          kid: 'agent-card-key',
        },
      },
    },
  },
})
```

配置签名时，Mastra 包括`signatures` array on the agent card. Client verification is opt-in, and unsigned cards still return unchanged.

验证签名卡`MastraClient.getA2A()`:

```typescript title="src/a2a-client.ts"
const card = await a2a.getAgentCard({
  verifySignature: {
    algorithms: ['ES256'],
    keyProvider: async ({ kid, jku }) => {
      return fetchTrustedPublicJwk({ kid, jku })
    },
  },
})

if (!card.signatures?.length) {
  throw new Error('Expected a signed A2A agent card.')
}
```

当客户端在调用远程Agent之前必须强制执行可信密钥时，请使用客户端签名验证。

## 验证子Agent卡 {/* #verify-subagent-cards */}

使用`verifyAgentCard` when a parent agent should validate a remote agent before delegating work to it. The verification hook receives the fetched agent card and context about where and when it was fetched.

```typescript title="src/mastra/agents/support-agent.ts"
import { A2AAgent } from '@mastra/core/a2a'

const remoteWeatherAgent = new A2AAgent({
  url: 'https://weather.example.com/api/.well-known/weather-agent/agent-card.json',
  verifyAgentCard: {
    verify: async (card, context) => {
      if (card.provider?.organization !== 'Weather Inc') {
        throw new Error(`Unexpected provider for ${context.cardUrl}`)
      }
    },
  },
})
```

在父Agent委托给远程Agent之前，使用此挂钩可以强制执行预期提供者、预期端点、证书绑定身份、签名卡或其他信任要求。
