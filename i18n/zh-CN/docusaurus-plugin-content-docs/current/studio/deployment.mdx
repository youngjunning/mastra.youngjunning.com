# 工作室部署

Studio 是基于 React 的单页应用（SPA），在浏览器中运行，并连接到运行中的 [Mastra 服务器](/docs/deployment/mastra-server)。

您可以通过两种主要方式部署 Studio：

- 使用 Mastra 平台托管的 Studio，通过链接与团队共享访问权限。
- 自行托管 Studio，与 Mastra 服务器一起部署，或单独部署为 SPA。

本文介绍如何在自己的基础设施上部署 Studio。具体做法随需求和环境而变，以下说明通用原则及可选方式。

## 快速入门 {/* #quickstart */}

启动 Studio 最简单的方式是使用 [`mastra studio`](/reference/cli/mastra#mastra-studio) 命令。

`mastra dev` 会同时启动 Studio 和用于开发的 API。`mastra studio` 则提供独立的静态界面，连接到已运行的 Mastra 服务器，因此可以单独部署 Studio。

打开终端并安装`mastra` CLI globally:

```bash npm2yarn
npm install -g mastra
```

运行 `mastra studio` 命令：

```bash
mastra studio
```

在浏览器中访问 [localhost:3000](http://localhost:3000) 打开 Studio。它默认连接到 `http://localhost:4111` 的 Mastra 服务器；如果服务器不可用，界面会显示表单，让你输入 Mastra 实例 URL 和 API 前缀。

该命令使用 Node 内置的 `http` 模块和 [`serve-handler`](https://www.npmjs.com/package/serve-handler) 提供静态文件。

:::note

如果将 Studio 托管在子路径下（例如 Nginx 后面的 `/agents`），请在启动 Studio 前设置 `MASTRA_STUDIO_BASE_PATH`：

```bash
MASTRA_STUDIO_BASE_PATH=/agents mastra studio
```

这会更新 HTML 基本 URL 和静态资源路由，以便独立 Studio 在该子路径下正常工作。

:::

## 马斯特拉平台 {/* #mastra-platform */}

如需使用 Mastra 平台托管的 Studio，请参阅 [Mastra 平台上的 Studio](/docs/mastra-platform/studio)。

## 运行服务器 {/* #running-a-server */}

让 `mastra studio` 长期运行与运行其他 Node.js 服务一样，可沿用相同的部署实践和工具。可以用 PM2、Docker 等管理进程，也可以部署到支持 Node.js 应用的云服务。与其他 Web 服务一样，请正确配置 CORS 并监控错误。

:::warning

连接到 Mastra 服务器后，Studio 可完整访问 Agent、Workflow 和 Tool。生产环境务必采用身份验证、VPN 等措施保护 Studio，避免未经授权的访问。

详情见[身份验证文档](/docs/studio/auth)。

:::

### 与 API 一起部署 {/* #alongside-your-api */}

也可以让 [Mastra 服务器](/docs/deployment/mastra-server)同时提供 Studio，这样只需部署和管理一个服务。

运行 `mastra build` 时加上 `--studio` 参数：

```bash
mastra build --studio
```

构建命令会将 Studio 构建产物放在 `.mastra/output/studio`。设置环境变量 `MASTRA_STUDIO_PATH` 后，Mastra 服务器也可以提供 Studio 界面。

```bash
MASTRA_STUDIO_PATH=.mastra/output/studio node .mastra/output/index.mjs
```

## 使用 CDN {/* #using-a-cdn */}

### 自动部署 {/* #automatic */}

部分[云服务提供商](/docs/deployment/cloud-providers)支持将 Studio 与无服务器函数一起部署。目前支持的部署器有：

- [`VercelDeployer`](/reference/deployer/vercel)

### 手动部署 {/* #manual */}

Studio 界面依赖运行时配置，因此不能直接将构建产物部署到 CDN。完成以下额外配置后，就可以用这些产物构建独立 SPA，并将其部署到任何静态托管服务。

请按照以下示例使用 Vite 创建 SPA。

<Steps>
  <StepItem>
    创建一个新文件夹并初始化一个新的 Node.js 项目：

    ```bash npm2yarn
    mkdir studio-spa
    cd studio-spa
    npm init
    ```
  </StepItem>

  <StepItem>
    安装 `vite` 和 `mastra` 作为依赖：

    ```bash npm2yarn
    npm install vite mastra
    ```
  </StepItem>

  <StepItem>
    在 `package.json` 中添加构建脚本：

    ```json title="package.json"
    {
      "scripts": {
        "build": "vite build"
      }
    }
    ```
  </StepItem>

  <StepItem>
    创建一个占位用的 `index.html` 文件：

    ```html title="index.html"
    <!doctype html>
    <html>
      <head></head>
      <body></body>
    </html>
    ```
  </StepItem>

  <StepItem>
    创建 `vite.config.js` 文件。它将构建好的 Studio 资源复制到 `dist` 目录，并用环境变量的值替换 HTML 中的所有 `%%PLACEHOLDER%%`。

    ```js title="vite.config.js"
    import { defineConfig, loadEnv } from 'vite'
    import { readFileSync, cpSync, writeFileSync } from 'node:fs'
    import { resolve, join } from 'node:path'

    const studioDir = resolve(import.meta.dirname, 'node_modules/mastra/dist/studio')

    export default defineConfig(({ mode }) => {
      const env = loadEnv(mode, process.cwd(), 'MASTRA_')

      return {
        plugins: [
          {
            name: 'mastra-studio',
            closeBundle() {
              const outDir = resolve(import.meta.dirname, 'dist')
              cpSync(studioDir, outDir, { recursive: true })

              const indexPath = join(outDir, 'index.html')
              const html = readFileSync(indexPath, 'utf-8')
              writeFileSync(
                indexPath,
                html.replaceAll(/%%(\w+)%%/g, (_, key) => env[key] ?? ''),
              )
            },
          },
        ],
        build: {
          emptyOutDir: true,
        },
      }
    })
    ```
  </StepItem>

  <StepItem>
    创建 `.env` 文件，填入所需的环境变量。

    ```env title=".env"
    MASTRA_SERVER_HOST=localhost
    MASTRA_SERVER_PORT=4111
    MASTRA_SERVER_PROTOCOL=http
    MASTRA_API_PREFIX=/api
    MASTRA_HIDE_CLOUD_CTA=false
    MASTRA_CLOUD_API_ENDPOINT=
    MASTRA_EXPERIMENTAL_FEATURES=false
    MASTRA_TEMPLATES=false
    MASTRA_TELEMETRY_DISABLED=true
    MASTRA_REQUEST_CONTEXT_PRESETS=
    MASTRA_EXPERIMENTAL_UI=false
    MASTRA_STUDIO_BASE_PATH=
    ```
  </StepItem>

  <StepItem>
    运行构建脚本，在 `dist` 目录生成静态文件：

    ```bash npm2yarn
    npm run build
    ```
  </StepItem>

  <StepItem>
    将托管服务的发布目录设为 `dist`，然后部署。
  </StepItem>
</Steps>
