# 工作室部署

Studio 是一个基于 React 的单页应用程序 (SPA)，它在浏览器中运行并连接到正在运行的[Mastra server](/docs/deployment/mastra-server).

您可以通过两种主要方式部署 Studio：

* Mastra 平台为您提供托管工作室，并允许您通过链接与您的团队共享访问权限
* 在您自己的基础设施上自行托管 Studio，可以与您的 Mastra 服务器一起使用，也可以单独作为独立的 SPA

在此页面上，您将了解如何在您自己的基础架构上部署 Studio。由于部署的细节可能会根据您的需求和设置而有很大差异，因此我们将介绍您可用的一般原则和选项。

## 快速入门 {/* #quickstart */}

运行 Studio 最简单的方法是[`mastra studio`](/reference/cli/mastra#mastra-studio) command.

然而`mastra dev` runs both Studio and an API for development purposes, the purpose of `mastra studio` is to serve a standalone, static UI that connects to an already-running Mastra server. You can deploy Studio separately from the Mastra server.

打开终端并安装`mastra` CLI globally:

```bash npm2yarn
npm install -g mastra
```

运行`mastra studio` command:

```bash
mastra studio
```

打开[localhost:3000](http://localhost:3000) in your browser to see the Studio UI. By default, it connects to a Mastra server at `http://localhost:4111`; when no server is available, the UI displays a form for entering your Mastra instance URL and API prefix.

该命令使用 Node 的内置`http` module and [`serve-handler`](https://www.npmjs.com/package/serve-handler) to serve the static files.

：：：笔记

如果您在子路径下托管 Studio（例如`/agents` behind Nginx), set `MASTRA_STUDIO_BASE_PATH` before starting Studio:

```bash
MASTRA_STUDIO_BASE_PATH=/agents mastra studio
```

这会更新 HTML 基本 URL 和静态资源路由，以便独立 Studio 在该子路径下正常工作。

## 运行服务器 {/* #running-a-server */}

跑步`mastra studio` as a long-running process is no different from running any other Node.js service. The same deployment practices and tools apply here. Use process managers such as PM2 or Docker. Cloud services that support Node.js applications are another option. As with any web service, configure CORS correctly and monitor errors.

：：：警告

Studio 连接到您的 Mastra 服务器后，它就可以完全访问您的Agent、Workflow程和Tool。确保在生产中正确保护它（例如，在身份验证、VPN 等后面），以防止未经授权的访问。

参观[Authentication](/docs/studio/auth) docs to learn more.

:::

### 与您的 API 一起 {/* #alongside-your-api */}

或者，您可以将 Studio 与您的服务一起提供[Mastra server](/docs/deployment/mastra-server). This way you only have one service to deploy and manage.

为此，请运行`mastra build` with the `--studio` flag:

```bash
mastra build --studio
```

它将创建一个`.mastra/output/studio` folder with the built Studio assets. By defining the `MASTRA_STUDIO_PATH` environment variable, the Mastra server can serve the Studio UI, too.

```bash
MASTRA_STUDIO_PATH=.mastra/output/studio node .mastra/output/index.mjs
```

### 手动的 {/* #manual */}

您无法直接将构建的 Studio 资产部署到 CDN，因为 UI 依赖于某些运行时配置。通过一些额外的设置，您可以从构建的资产中创建一个独立的 SPA，并将其部署到任何静态托管服务。

请按照以下示例使用 Vite 创建 SPA。

<Steps>
  <StepItem>
    创建一个新文件夹并初始化一个新的 Node.js 项目：

    ```bash npm2yarn
    mkdir studio-spa
    cd studio-spa
    npm init
    ```
  </StepItem>

  <StepItem>
    安装`vite` and `mastra` as dependencies:

    ```bash npm2yarn
    npm install vite mastra
    ```
  </StepItem>

  <StepItem>
    将构建脚本添加到您的`package.json`:

    ```json title="package.json"
    {
      "scripts": {
        "build": "vite build"
      }
    }
    ```
  </StepItem>

  <StepItem>
    创建占位符`index.html` file:

    ```html title="index.html"
    <!doctype html>
    <html>
      <head></head>
      <body></body>
    </html>
    ```
  </StepItem>

  <StepItem>
    创建一个`vite.config.js` file. It copies the built Studio assets to the `dist` folder and replaces any `%%PLACEHOLDER%%` values in the HTML with environment variable values.

    ```js title="vite.config.js"
    import { defineConfig, loadEnv } from 'vite'
    import { readFileSync, cpSync, writeFileSync } from 'node:fs'
    import { resolve, join } from 'node:path'

    const studioDir = resolve(import.meta.dirname, 'node_modules/mastra/dist/studio')

    export default defineConfig(({ mode }) => {
      const env = loadEnv(mode, process.cwd(), 'MASTRA_')

      return {
        plugins: [
          {
            name: 'mastra-studio',
            closeBundle() {
              const outDir = resolve(import.meta.dirname, 'dist')
              cpSync(studioDir, outDir, { recursive: true })

              const indexPath = join(outDir, 'index.html')
              const html = readFileSync(indexPath, 'utf-8')
              writeFileSync(
                indexPath,
                html.replaceAll(/%%(\w+)%%/g, (_, key) => env[key] ?? ''),
              )
            },
          },
        ],
        build: {
          emptyOutDir: true,
        },
      }
    })
    ```
  </StepItem>

  <StepItem>
    创建一个`.env` file with the necessary environment variables.

    ```env title=".env"
    MASTRA_SERVER_HOST=localhost
    MASTRA_SERVER_PORT=4111
    MASTRA_SERVER_PROTOCOL=http
    MASTRA_API_PREFIX=/api
    MASTRA_HIDE_CLOUD_CTA=false
    MASTRA_CLOUD_API_ENDPOINT=
    MASTRA_EXPERIMENTAL_FEATURES=false
    MASTRA_TEMPLATES=false
    MASTRA_TELEMETRY_DISABLED=true
    MASTRA_REQUEST_CONTEXT_PRESETS=
    MASTRA_EXPERIMENTAL_UI=false
    MASTRA_STUDIO_BASE_PATH=
    ```
  </StepItem>

  <StepItem>
    运行构建脚本以生成静态文件`dist` folder:

    ```bash npm2yarn
    npm run build
    ```
  </StepItem>

  <StepItem>
    将您的托管Provider指向`dist` folder and deploy!
  </StepItem>
</Steps>
