# Agent Skill

Skill 是一组可复用的指令，用于指导 Agent 执行特定任务。Skill 遵循 [Agent Skills 规范](https://agentskills.io)。

可通过 Agent 的 `skills` 配置直接添加 Skill，也可以在 [Workspace](/docs/sandbox/skills) 中配置。Agent 级 Skill 只属于一个 Agent，可以直接用代码定义，无需 Workspace。Workspace 从文件系统发现 Skill，使用该 Workspace 的 Agent 共享这些 Skill。本文介绍如何定义和加载 Agent 级 Skill，以及如何按请求解析。

## 何时使用 Agent 级 Skill {/* #when-to-use-agent-level-skills */}

以下情况适合使用 Agent 级 Skill。

* 需要不依赖 Workspace 的独立 Agent。
* Skill 由代码定义，无需从文件系统发现。
* 正在构建包含 Agent 功能的软件包或库。
* 需要根据每次请求的上下文解析 Skill。

如果需要在整个项目中从文件系统发现 Skill，请使用 [Workspace Skill](/docs/sandbox/skills)。

## 快速入门 {/* #quickstart */}

内联定义一个 Skill，并将其添加到 Agent。

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { createSkill } from '@mastra/core/skills'

const codeReview = createSkill({
  name: 'code-review',
  description: 'Use when reviewing code changes.',
  instructions: `
    When reviewing code:
    1. Check for correctness and edge cases
    2. Verify style consistency
    3. Look for potential bugs
  `,
})

export const reviewer = new Agent({
  id: 'reviewer',
  model: '__GATEWAY_OPENAI_MODEL__',
  instructions: 'You are a code review assistant.',
  // highlight-next-line
  skills: [codeReview],
})
```

Agent 会自动获得 `skill`、`skill_read` 和 `skill_search` 工具，以便在对话中发现并加载 Skill。

## 定义内联 Skill {/* #defining-inline-skills */}

使用 `createSkill()` 完全通过代码创建 Skill。

```typescript title="src/mastra/skills.ts"
import { createSkill } from '@mastra/core/skills'

export const releaseChecklist = createSkill({
  name: 'release-checklist',
  description: 'Use when preparing a release.',
  instructions: `
    ## Release Checklist
    1. Run the full test suite
    2. Update CHANGELOG.md
    3. Bump version numbers
    4. Create a git tag
  `,
  references: {
    'changelog-format.md': '# Changelog Format\nUse Keep a Changelog...',
  },
})
```

`references` 字段用于附带参考文档，Agent 可通过 `skill_read` 工具读取，作用类似文件系统 Skill 中的 `references/` 文件。完整 API 见 [`createSkill()` 参考](/reference/agents/createSkill)。

## 通过文件系统路径加载 Skill {/* #filesystem-path-skills */}

无需配置 Workspace，直接指定磁盘上的 Skill 目录。

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { createSkill } from '@mastra/core/skills'

export const agent = new Agent({
  id: 'my-agent',
  model: '__GATEWAY_OPENAI_MODEL__',
  skills: [
    './skills/code-review', // path to a SKILL.md directory
    './skills/testing', // another filesystem skill
    createSkill({/* ... */}), // inline skill
  ],
})
```

文件系统路径由 `LocalSkillSource` 处理，它读取的 `SKILL.md` 文件与 [Workspace Skill](/docs/sandbox/skills#skillmd-format) 使用相同格式。

## 动态 Skill {/* #dynamic-skills */}

要按请求解析 Skill，请传入一个函数。

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { createSkill } from '@mastra/core/skills'

const devSkill = createSkill({
  name: 'dev-tools',
  description: 'Developer productivity tools.',
  instructions: '...',
})

const supportSkill = createSkill({
  name: 'support-guide',
  description: 'Customer support guidelines.',
  instructions: '...',
})

export const agent = new Agent({
  id: 'dynamic-agent',
  model: '__GATEWAY_OPENAI_MODEL__',
  // highlight-start
  skills: ({ requestContext }) => {
    const role = requestContext.get('userRole')
    if (role === 'developer') return [devSkill]
    return [supportSkill]
  },
  // highlight-end
})
```

解析函数接收 `{ requestContext, tracingContext }`，返回 `SkillInput[]` 数组或 `Promise<SkillInput[]>`。

每个 `RequestContext` 只运行一次解析函数。执行 Agent 时，解析函数在 `resolve-skills` span 中运行，可以像工具一样用 `tracingContext.currentSpan` 为自己的操作创建子 span。读取元数据时也会运行解析函数，例如调用 `agent.listSkills()` 或服务器的 Agent 端点。此时没有 span，`tracingContext.currentSpan` 为 `undefined`。请让解析函数尽快返回，并在使用 span 前检查它是否存在。

```typescript title="src/mastra/agents/index.ts"
skills: async ({ requestContext, tracingContext }) => {
  const span = tracingContext?.currentSpan?.createChildSpan({
    type: 'generic',
    name: 'entitlements-lookup',
  })
  const skills = await fetchSkillsFor(requestContext.get('userId'))
  span?.end()
  return skills
}
```

有关如何在 Agent 和 Workflow 中使用请求上下文，请参阅 [请求上下文](/docs/server/request-context)。

## 与 Workspace Skill 合并 {/* #merging-with-workspace-skills */}

当 Agent 配置了 `skills`，且其 Workspace 也配置了 Skill，两组 Skill 会合并。同名时优先使用 Agent 级 Skill。

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { Workspace, LocalFilesystem } from '@mastra/core/workspace'
import { createSkill } from '@mastra/core/skills'

const workspace = new Workspace({
  filesystem: new LocalFilesystem({ basePath: './workspace' }),
  skills: ['skills'], // provides "code-review" skill
})

const customReview = createSkill({
  name: 'code-review', // same name as workspace skill
  description: 'Custom review process.',
  instructions: '...',
})

export const reviewer = new Agent({
  id: 'reviewer',
  model: '__GATEWAY_OPENAI_MODEL__',
  workspace,
  skills: [customReview], // agent-level "code-review" wins
})
```

## 在代码中访问 Skill {/* #programmatic-skill-access */}

在应用代码中（例如 Workflow 或 API 路由）使用 `agent.getSkill()` 和 `agent.listSkills()` 访问 Skill。

```typescript title="src/routes/skills.ts"
import { reviewer } from '../mastra/agents'

// Get a specific skill by name
const skill = await reviewer.getSkill('code-review')
if (skill) {
  console.log(skill.instructions)
}

// List all available skills
const allSkills = await reviewer.listSkills()
for (const meta of allSkills) {
  console.log(`${meta.name}: ${meta.description}`)
}
```

完整 API 见 [`.getSkill()` 参考](/reference/agents/getSkill) 和 [`.listSkills()` 参考](/reference/agents/listSkills)。

## 保存前验证 Skill {/* #validating-skills-before-saving */}

如果应用会通过工具、上传或 shell 命令写入 `SKILL.md` 文件，请先用 `validateSkillContent()` 验证内容。它沿用加载 Skill 时的规则，包括检查 `name` 是否与目录名一致，并返回结构化结果，不抛出异常。

```typescript
import { validateSkillContent } from '@mastra/core/skills'

const result = validateSkillContent({ content: skillMarkdown, directoryName: 'code-review' })

if (!result.valid) {
  throw new Error(`Invalid skill:\n${result.errors.join('\n')}`)
}
// result.warnings lists non-blocking issues, such as very long instructions
```

要验证已解析的 frontmatter 对象，请使用 `validateSkillMetadata({ metadata, directoryName })`。
