# 发展

一旦您有了 Mastra 项目，您就可以开发、运行和测试您的Agent了。

## 在本地运行 Mastra {/* #run-mastra-locally */}

查看Agent工作的最快方式是[Mastra Studio](/docs/studio/overview). From your project root, start Studio and the local development server with [`mastra dev`](/reference/cli/mastra#mastra-dev):

```bash npm2yarn
npx mastra dev
```

开放工作室于[`http://localhost:4111`](http://localhost:4111) to test your agent and inspect its runs.

开发服务器还为您的Agent、Tool和Workflow程公开 API。打开[`http://localhost:4111/api`](http://localhost:4111/api) to browse what's available, then connect your frontend using the [Mastra Client](/docs/server/mastra-client).

你的变化`src/mastra/` directory automatically restart the development server, so you don't need to restart it manually as you build.

## 用人工智能构建 {/* #build-with-ai */}

Mastra 提供了一项技能和 CLI 来帮助您的编码Agent编写高质量的 Mastra 代码。

### 马斯特拉技能 {/* #mastra-skills */}

AI 模型可能不具备 Mastra API 的最新知识。使用[Mastra skills](https://github.com/mastra-ai/skills) to give your coding agent implementation guidance and best practices, including instructions for fetching the latest Mastra documentation. Your coding agent will also be able to interact with [Mastra Factory](https://factory.mastra.ai).

手动安装技能：

```bash npm2yarn
npx skills add mastra-ai/skills
```

定期更新技能以获得最新指导：

```bash npm2yarn
npx skills update mastra
```

：：：笔记

当您创建项目时[create mastra](/docs), the command automatically installs the Mastra skills so your coding agent can discover and use them.

:::

### 马斯特拉 CLI {/* #mastra-cli */}

使用[`mastra` CLI](/reference/cli/mastra) to give your coding agent a feedback loop for testing updates and inspecting results. The CLI gives it access to agents, workflows, tools, memory, evals, traces, and logs.

例如，您的编码Agent可以运行Agent，然后提取跟踪来检查结果：

```bash
npx mastra api --url http://localhost:4111 agent run agent '{"messages":"Hello"}'
npx mastra api --url http://localhost:4111 trace list
```

记得安装[Mastra skills](#mastra-skills) to teach your coding agent how to use the CLI.

## 项目结构 {/* #project-structure */}

采用框架时的首要决定之一是如何构建项目。我们建议将框架代码保留在`src/mastra/`, with related primitives grouped into their own files or folders. Use `src/mastra/index.ts` as the central place to configure and register them.

一个最小的项目可以如下所示：

```text
src/
  mastra/
    agents/
      agent.ts
    tools/
      tool.ts
    workflows/
      workflow.ts
    scorers/
      scorer.ts
    skills.ts
    index.ts
```

请参阅[project structure reference](/reference/project-structure) for the default layout and recommended conventions.

## 基于文件的Agent {/* #file-based-agents */}

：：：笔记

基于文件的发现仅贯穿`mastra dev` or `mastra build`. If your app imports `mastra` directly, including through a web framework or server adapter, file-based agents aren't discovered. Register those agents in code or run Mastra as a separate server.

:::

:::提示\[📹观看]

[如何创建您的第一个基于文件的Agent](https://www.youtube.com/watch?v=5Kfn-oYkJNg\&t=18s)

:::

通过基于文件的Agent，Mastra 自动[discovers](/reference/file-based-agents/config#discovery-lifecycle) agents and related primitives from supported files under `src/mastra/`. You organize those files by convention instead of importing and registering each primitive on your [`Mastra`](/reference/core/mastra-class) instance.

文件系统成为项目结构的直接表示，因此您和您的编码Agent可以了解项目如何组合在一起，而无需跟踪所有内容如何在代码中连接在一起。

您可以在整个项目中使用基于文件的Agent，或者与代码中定义的原语一起逐步采用它们。尚未支持所有 Mastra 功能或用例。

### 创建您的第一个Agent {/* #create-your-first-agent */}

基于文件的Agent位于其自己的目录中`src/mastra/agents/`. To create a working agent, add a `config.ts` file for its model and runtime options and an `instructions.md` file for its always-on prompt:

```text
src/mastra/agents/
  writing-assistant/
    config.ts
    instructions.md
```

目录名称成为Agent的默认名称`id` and `name`. In this example, Mastra registers the agent as `writing-assistant`.

```typescript title="src/mastra/agents/writing-assistant/config.ts"
import { agentConfig } from '@mastra/core/agent'

export default agentConfig({
  model: '__GATEWAY_OPENAI_MODEL__',
})
```

```markdown title="src/mastra/agents/writing-assistant/instructions.md"
Rewrite text clearly and concisely.
```

跑步`npx mastra dev`, open Studio, and select `writing-assistant` to test it.

### 发现如何运作 {/* #how-discovery-works */}

Mastra 使用路径来发现和命名基于文件的功能。Agent目录提供默认Agent`id` and `name`. For example, `tools/search_docs.ts` registers a tool as `search_docs`, while `skills/style-guide.md` registers a skill as `style-guide`. See the extension paths below.

### 延长您的Agent {/* #extend-your-agent */}

当您的Agent需要更多功能时添加文件或目录：

|路径|添加了什么 |
| - | - |
|[`tools/<tool-name>.ts`](/reference/file-based-agents/tools) | Functions the model can call |
| [`skills/<skill-name>.md`](/reference/file-based-agents/skills) | Detailed guidance the agent loads when relevant |
| [`memory.ts`](/reference/file-based-agents/memory) | Conversation history and working context |
| [`workspace.ts` and `workspace/`](/reference/file-based-agents/workspace) | Filesystem and shell access |
| [`subagents/<agent-id>/`](/reference/file-based-agents/subagents) | Specialist agents that the parent can delegate to |

将每个功能放在使用它的Agent旁边。当开发服务器启动或重新启动时，Mastra 会发现并注册这些文件。

浏览[file-based agents reference](/reference/file-based-agents/config) for all supported file conventions and configuration options.
