# 服务器

Mastra 作为 HTTP 服务器运行，将您的Agent、Workflow程和其他功能公开为 API 端点。服务器处理请求路由、中间件执行、身份验证和流响应。

：：：笔记

此页面涵盖[`server`](/reference/configuration#server-options) configuration options passed to the `Mastra`构造函数。要使用您自己的 HTTP 服务器（Hono、Express 等）运行 Mastra，请访问[服务器适配器](/docs/server/server-adapters).

:::

## 服务器功能 {/* #server-features */}

* **[中间件](/docs/server/middleware)**：拦截身份验证、日志记录、CORS 或注入请求特定上下文的请求。
* **[自定义 API 路由](/docs/server/custom-api-routes)**：使用您自己的可以访问 Mastra 实例的 HTTP 端点扩展服务器。
* **[请求上下文](/docs/server/request-context)**：根据运行时条件将请求特定的值传递给Agent、Tool和Workflow。
* **[服务器适配器](/docs/server/server-adapters)**：使用 Express、Hono 或您自己的 HTTP 服务器而不是生成的服务器运行 Mastra。
* **[定制适配器](/docs/server/custom-adapters)**：为未正式支持的框架构建适配器。
* **[Mastra 客户端 SDK](/docs/server/mastra-client)**：类型安全的客户端，用于从浏览器或服务器环境调用Agent、Workflow和Tool。
* **[内置MCP服务器](/docs/server/mcp)**：让 Claude Code 和 Cursor 等 MCP 客户端调用您的Agent、Workflow程和Tool：`/api/mcp`, with the same auth and permissions as the HTTP API.
* **[A2A](/docs/connections/a2a)**：通过 A2A Agent卡和任务流以及推送通知公开Agent。
* **[验证](/docs/auth/overview)**：使用 JWT、Clerk、Supabase、Firebase、Auth0 或 WorkOS 保护端点。

## 配置 {/* #configuration */}

通过传递配置服务器`server` object to the `Mastra` constructor:

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'

export const mastra = new Mastra({
  server: {
    port: 3000, // Defaults to PORT env var or 4111
    host: '0.0.0.0', // Defaults to MASTRA_HOST env var or 'localhost'
  },
})
```

参观[configuration reference](/reference/configuration#server-options) for a full list of available server options.

## 部署您的服务器 {/* #deploy-your-server */}

Mastra 服务器可以部署到任何 Node.js 兼容环境。使用以下命令将其部署到生产环境[Mastra platform](/docs/mastra-platform/overview) or your own infrastructure. Visit the [deployment docs](/docs/deployment/overview) to learn how.

## 服务器架构 {/* #server-architecture */}

马斯特拉用途[Hono](https://hono.dev) as its underlying HTTP server framework. When you build a Mastra application using `mastra build`, it generates a Hono-based HTTP server in the `.mastra` directory.

服务器提供：

* 所有注册Agent和Workflow程的 API 端点
* 自定义 API 路由和中间件
* 跨Provider的身份验证
* 请求运行时配置的上下文
* 流数据编辑以实现安全响应

## 休息API {/* #rest-api */}

您可以在以下位置探索 OpenAPI 规范中的所有可用端点：[http://localhost:4111/api/openapi.json](http://localhost:4111/api/openapi.json), which details every endpoint and its request and response schemas.

要以交互方式探索 API，请访问 Swagger UI：[http://localhost:4111/swagger-ui](http://localhost:4111/swagger-ui). Here, you can discover endpoints and test them directly from your browser.

：：：笔记

默认情况下，OpenAPI 和 Swagger 端点在生产中处于禁用状态。要启用它们，请设置[`server.build.openAPIDocs`](/reference/configuration#serverbuild) and [`server.build.swaggerUI`](/reference/configuration#serverbuild) to `true` respectively.

:::

## OpenAI 响应 API {/* #openai-responses-api */}

Mastra 公开了与 OpenAI 兼容的响应和对话路由，使您可以使用 Mastra Agent作为响应 API。这些路由是基于 Mastra Agent、内存和存储的Agent支持的适配器，因此请求通过选定的 Mastra Agent运行，而不是充当原始ProviderAgent。

这些 API 目前处于实验阶段。

使用`agent_id` to select the Mastra agent that should handle the request. Initial requests target an agent directly. Stored follow-up turns can continue through `previous_response_id`. Pass `model` to override the configured model for one request, or omit it to use the agent's existing model.

响应路由支持流式传输、函数调用（Tool）、存储的延续`previous_response_id`, conversation threads through `conversation_id`, provider-specific passthrough with `providerOptions`, and JSON output through `text.format`.

有关完整的请求和响应合同，请参阅[Responses API reference](/reference/client-js/responses) and [Conversations API reference](/reference/client-js/conversations). For the complete list of HTTP routes, see [server routes](/reference/server/routes#responses-api).

## 流数据编辑 {/* #stream-data-redaction */}

当流Agent响应时，HTTP 层会在将每个块发送到客户端之前编辑系统提示、Tool定义、API 密钥和类似数据。默认情况下启用此功能。

此行为只能通过使用进行配置[server adapters](/docs/server/server-adapters#stream-data-redaction). For server adapters, stream data redaction is enabled by default, too.

## TypeScript 配置 {/* #typescript-configuration */}

马斯特拉要求`module` and `moduleResolution` settings compatible with modern Node.js. Legacy options like `CommonJS` or `node` aren't supported.

这`types` option below requires `@types/node`, which is included in projects created with [`create-mastra`](/reference/cli/create-mastra). Add it if your project doesn't have it already:

```bash npm2yarn
npm install -D @types/node
```

```json {4-5} title="tsconfig.json"
{
  "compilerOptions": {
    "target": "ES2022",
    "module": "ES2022",
    "moduleResolution": "bundler",
    "esModuleInterop": true,
    "forceConsistentCasingInFileNames": true,
    "strict": true,
    "skipLibCheck": true,
    "types": ["node"],
    "noEmit": true,
    "outDir": "dist"
  },
  "include": ["src/**/*"]
}
```
