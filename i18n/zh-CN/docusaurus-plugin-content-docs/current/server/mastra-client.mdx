# 马斯特拉客户

Mastra Client SDK 提供了一个简洁且类型安全的界面，用于与您的交互[Mastra Server](/docs/server/overview)来自您的客户端环境。

## 先决条件 {/* #prerequisites */}

在开始本地开发之前，请先：

* Node.js`v22.13.0` or later
* 打字稿`v4.7` or higher (if using TypeScript)
* 您的本地 Mastra 服务器正在运行（通常在端口`4111`)

：：：笔记

Mastra Client SDK 专为浏览器环境而设计，并使用本机`fetch` API for making HTTP requests to your Mastra server.

:::

## 安装 {/* #installation */}

要使用 Mastra Client SDK，请安装所需的依赖项：

```bash npm2yarn
npm install @mastra/client-js@latest
```

### 初始化`MastraClient` {/* #initialize-the-mastraclient */}

一旦用a初始化`baseUrl`, `MastraClient` exposes a type-safe interface for calling agents, tools, and workflows.

```typescript title="lib/mastra-client.ts"
import { MastraClient } from '@mastra/client-js'

export const mastraClient = new MastraClient({
  baseUrl: process.env.MASTRA_API_URL || 'http://localhost:4111',
})
```

## 核心API {/* #core-apis */}

Mastra 客户端 SDK 公开了 Mastra 服务器提供的所有资源。

* **[Agent商](/reference/client-js/agents)**：生成响应并流式传输对话。
* **[A2A](/docs/connections/a2a)**：通过座席卡发现座席并使用基于任务的 A2A 流。
* **[记忆](/reference/client-js/memory)**：管理对话线程和消息历史记录。
* **[Tool](/reference/client-js/tools)**：执行和管理的Tool。
* **[Workflow程](/reference/client-js/workflows)**：触发​​Workflow程并跟踪其执行情况。
* **[向量](/reference/client-js/vectors)**：使用向量嵌入进行语义搜索。
* **[回应](/reference/client-js/responses)**：使用 Mastra Agents 作为具有 OpenAI 兼容、Agent支持的接口的响应 API。该 API 目前处于实验阶段。
* **[对话](/reference/client-js/conversations)**：使用 Mastra Agents 背后存储的对话线程和项目历史记录作为响应 API。该 API 目前处于实验阶段。
* **[日志](/reference/client-js/logs)**：查看日志并调试系统行为。
* **[可观察性](/reference/client-js/observability)**：查看应用程序性能和跟踪活动。

## 创建并运行动态Workflow程 {/* #create-and-run-dynamic-workflows */}

使用`upsertDynamicWorkflow()` to create or replace a persisted workflow definition. A successful upsert validates the complete definition and registers it with the running Mastra instance. The workflow then becomes available through the standard execution API.

以下示例显示了映射Workflow的完整生命周期，从创建和检查到执行和删除：

```typescript title="lib/dynamic-workflow.ts"
import { MastraClient } from '@mastra/client-js'
import type { UpsertDynamicWorkflowParams } from '@mastra/client-js'

const client = new MastraClient({
  baseUrl: process.env.MASTRA_API_URL || 'http://localhost:4111',
})

const definition = {
  id: 'greeting-workflow',
  description: 'Returns a greeting for the supplied name',
  inputSchema: {
    type: 'object',
    properties: { name: { type: 'string' } },
    required: ['name'],
  },
  outputSchema: {
    type: 'object',
    properties: { message: { type: 'string' } },
    required: ['message'],
  },
  graph: [
    {
      type: 'mapping',
      id: 'create-greeting',
      mapConfig: JSON.stringify({
        message: { template: 'Hello, ${initData.name}!' },
      }),
    },
  ],
} satisfies UpsertDynamicWorkflowParams

await client.upsertDynamicWorkflow(definition)

const dynamicWorkflow = client.getDynamicWorkflow(definition.id)
const dynamicDefinition = await dynamicWorkflow.details()

const workflow = client.getWorkflow(dynamicDefinition.id)
const run = await workflow.createRun()
const result = await run.startAsync({ inputData: { name: 'Ada' } })

console.log(result)

await dynamicWorkflow.delete()
```

使用`listDynamicWorkflows()` to list persisted definitions. Calling `upsertDynamicWorkflow()` again with the same `id` replaces the stored definition and live workflow registration.

：：：警告

持久存储需要配置支持以下功能的存储适配器`workflowDefinitions` domain. Without that domain, Core can register a workflow in memory, but the server's dynamic-workflow API can't preserve it across restarts.

存储的定义支持声明性Agent、Tool、映射、嵌套Workflow、并行、foreach、睡眠、睡眠直到、条件和循环条目。它们不能包含 JavaScript 闭包。条件和循环逻辑必须使用声明性谓词格式，并且引用的Agent、Tool和嵌套Workflow必须已注册。

经过身份验证的服务器需要`stored-workflows:read` or `stored-workflows:write` for definition operations and `workflows:execute` to run the workflow.

:::

## 生成响应 {/* #generating-responses */}

称呼`.generate()` with a string prompt:

```typescript
import { mastraClient } from 'lib/mastra-client'

const testAgent = async () => {
  try {
    const agent = mastraClient.getAgent('testAgent')

    const response = await agent.generate('Hello')

    console.log(response.text)
  } catch (error) {
    return 'Error occurred while generating response'
  }
}
```

：：：笔记

您也可以致电`.generate()` with an array of message objects that include `role` and `content`. Visit the [.generate() reference](/reference/client-js/agents#generate) for more information.

:::

## 流式响应 {/* #streaming-responses */}

使用`.stream()` for real-time responses with a string prompt:

```typescript
import { mastraClient } from 'lib/mastra-client'

const testAgent = async () => {
  try {
    const agent = mastraClient.getAgent('testAgent')

    const stream = await agent.stream('Hello')

    stream.processDataStream({
      onTextPart: text => {
        console.log(text)
      },
    })
  } catch (error) {
    return 'Error occurred while generating response'
  }
}
```

：：：笔记

您也可以致电`.stream()` with an array of message objects that include `role` and `content`. Visit the [.stream() reference](/reference/client-js/agents#stream) for more information.

:::

## 配置选项 {/* #configuration-options */}

`MastraClient`接受可选参数，例如`retries`, `backoffMs`, and `headers` to control request behavior. These parameters are useful for controlling retry behavior and including diagnostic metadata.

```typescript title="lib/mastra-client.ts"
import { MastraClient } from '@mastra/client-js'

export const mastraClient = new MastraClient({
  retries: 3,
  backoffMs: 300,
  maxBackoffMs: 5000,
  headers: {
    'X-Development': 'true',
  },
})
```

访问[MastraClient](/reference/client-js/mastra-client) for more configuration options.

## 凭证和会话 cookie {/* #credentials-and-session-cookies */}

**使用会话 cookie 验证 Mastra API 调用**当您的 UI 和 Mastra API 不在同一源、不同主机、子域或端口时（例如，Mastra Studio 在一个端口上，而自定义服务器在另一个端口上）。添&#x52A0;**`credentials: 'include'`** to `MastraClient` so each request carries the cookies the user already has after sign-in. Skip this and you will often get **`401`** responses from Mastra even though login succeeded in the browser.

```typescript title="lib/mastra-client.ts"
import { MastraClient } from '@mastra/client-js'

export const mastraClient = new MastraClient({
  baseUrl: process.env.MASTRA_API_URL || 'http://localhost:4111',
  credentials: 'include',
})
```

**允许服务器上经过凭据的跨源请求**， 看[CORS: requests with credentials](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/CORS#requests_with_credentials). You need a concrete `Access-Control-Allow-Origin` (not `*`) and `Access-Control-Allow-Credentials: true`, or the browser will block the call before it reaches Mastra.

**使用`@mastra/react`?**&#x5305;装你的应用程序`MastraReactProvider`, set `baseUrl` and `apiPrefix` to match your server, and rely on the default `credentials: 'include'`. Change `credentials` only when you want `same-origin` or `omit` behavior.

## 添加取消请求 {/* #adding-request-cancelling */}

`MastraClient`支持使用标准 Node.js 取消请求`AbortSignal` API. Useful for canceling in-flight requests, such as when users abort an operation or to clean up stale network calls.

通过一个`AbortSignal` to the client constructor to enable cancellation across all requests.

```typescript {3,7} title="lib/mastra-client.ts"
import { MastraClient } from '@mastra/client-js'

export const controller = new AbortController()

export const mastraClient = new MastraClient({
  baseUrl: process.env.MASTRA_API_URL || 'http://localhost:4111',
  abortSignal: controller.signal,
})
```

### 使用`AbortController` {/* #using-the-abortcontroller */}

呼唤`.abort()` will cancel any ongoing requests tied to that signal.

```typescript
import { mastraClient, controller } from 'lib/mastra-client'

const handleAbort = () => {
  controller.abort()
}
```

## 客户端Tool {/* #client-tools */}

使用以下命令直接在客户端应用程序中定义Tool`createTool()` function. Pass them to agents via the `clientTools` parameter in `.generate()` or `.stream()` calls.

这使得Agent可以触发浏览器端功能，例如 DOM 操作、本地存储访问或其他 Web API，从而使Tool能够在用户环境中而不是在服务器上执行。

```typescript {26}
import { createTool } from '@mastra/client-js'
import { z } from 'zod'

const handleClientTool = async () => {
  try {
    const agent = mastraClient.getAgent('colorAgent')

    const colorChangeTool = createTool({
      id: 'color-change-tool',
      description: 'Changes the HTML background color',
      inputSchema: z.object({
        color: z.string(),
      }),
      outputSchema: z.object({
        success: z.boolean(),
      }),
      execute: async inputData => {
        const { color } = inputData

        document.body.style.backgroundColor = color
        return { success: true }
      },
    })

    const response = await agent.generate('Change the background to blue', {
      clientTools: { colorChangeTool },
    })

    console.log(response)
  } catch (error) {
    console.error(error)
  }
}
```

### 客户端ToolAgent {/* #client-tool-agent */}

这是标准的玛斯特拉[agent](../agents/overview#quickstart) configured to return hex color codes, intended to work with the browser-based client tool defined above.

```typescript title="src/mastra/agents/color-agent"
import { Agent } from '@mastra/core/agent'

export const colorAgent = new Agent({
  id: 'color-agent',
  name: 'Color Agent',
  instructions: `You are a helpful CSS assistant.
  You can change the background color of web pages.
  Respond with a hex reference for the color requested by the user`,
  model: '__GATEWAY_OPENAI_MODEL__',
})
```

## 在服务器上使用 MastraClient {/* #use-mastraclient-on-the-server */}

服务器端 API 路由和无服务器功能（包括操作）也可以使用`MastraClient`. The usage is unchanged, although you may need to recreate the response for your client:

```typescript {8}
export async function action() {
  const agent = mastraClient.getAgent('testAgent')

  const stream = await agent.stream('Hello')

  return new Response(stream.body)
}
```
