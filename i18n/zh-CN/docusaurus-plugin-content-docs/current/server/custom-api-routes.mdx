# 自定义 API 路由

默认情况下，Mastra 会通过服务器自动公开已注册的 Agent 和 Workflow。要扩展服务器行为，可以自行定义 HTTP 路由。

使用 `@mastra/core/server` 提供的辅助函数 `registerApiRoute()` 注册路由。路由可以和 `Mastra` 实例放在同一文件中，分开定义有助于保持配置简洁。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { registerApiRoute } from '@mastra/core/server'

export const mastra = new Mastra({
  server: {
    apiRoutes: [
      registerApiRoute('/my-custom-route', {
        method: 'GET',
        handler: async c => {
          const mastra = c.get('mastra')
          const agent = await mastra.getAgent('my-agent')

          return c.json({ message: 'Custom route' })
        },
      }),
    ],
  },
})
```

自定义路由注册后，即可从服务器根路径访问。例如：

```bash
curl http://localhost:4111/my-custom-route
```

每个路由的处理函数都会收到 Hono 的 `Context`，并可在其中访问 `Mastra` 实例，获取或调用 Agent 和 Workflow。

## 模式校验 {/* #schema-validation */}

在 `apiRoutes` 中使用 [`createRoute()`](/reference/server/create-route)，通过 Zod 解析并校验路径参数、查询参数和请求体。这些模式也用于推断处理函数的参数类型并生成 OpenAPI 元数据。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { createRoute } from '@mastra/server/server-adapter'
import { z } from 'zod'

const createItemRoute = createRoute({
  method: 'POST',
  path: '/items',
  responseType: 'json',
  bodySchema: z.object({
    name: z.string().min(1),
  }),
  responseSchema: z.object({
    id: z.string(),
    name: z.string(),
  }),
  handler: async ({ name }) => ({
    id: crypto.randomUUID(),
    name,
  }),
})

export const mastra = new Mastra({
  server: {
    apiRoutes: [createItemRoute],
  },
})
```

校验失败时，Mastra 默认返回 `400` 响应。可通过 `onValidationError` 回调覆盖状态码和响应体。通过校验的值和 `Mastra` 服务器上下文会直接传给处理函数。

## 中间件 {/* #middleware */}

要为特定路由添加中间件，请在调用 `registerApiRoute()` 时传入 `middleware` 数组。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { registerApiRoute } from '@mastra/core/server'

export const mastra = new Mastra({
  server: {
    apiRoutes: [
      registerApiRoute('/my-custom-route', {
        method: 'GET',
        middleware: [
          async (c, next) => {
            console.log(`${c.req.method} ${c.req.url}`)
            await next()
          },
        ],
        handler: async c => {
          return c.json({ message: 'Custom route with middleware' })
        },
      }),
    ],
  },
})
```

## OpenAPI 文档 {/* #openapi-documentation */}

为自定义路由提供 OpenAPI 元数据后，它们就会与 Mastra 服务器的路由一起显示在 Swagger UI 中。`/api/openapi.json` 提供 OpenAPI 规范，其中列出了自定义路由和内置路由。传入 `openapi` 选项，并在其中填写标准的 OpenAPI 操作字段。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { registerApiRoute } from '@mastra/core/server'
import { z } from 'zod'

export const mastra = new Mastra({
  server: {
    apiRoutes: [
      registerApiRoute('/items/:itemId', {
        method: 'GET',
        openapi: {
          summary: 'Get item by ID',
          description: 'Retrieves a single item by its unique identifier',
          tags: ['Items'],
          parameters: [
            {
              name: 'itemId',
              in: 'path',
              required: true,
              description: 'The item ID',
              schema: { type: 'string' },
            },
          ],
          responses: {
            200: {
              description: 'Item found',
              content: {
                'application/json': {
                  schema: {
                    type: 'object',
                    properties: {
                      id: { type: 'string' },
                      name: { type: 'string' },
                    },
                  },
                },
              },
            },
            404: {
              description: 'Item not found',
            },
          },
        },
        handler: async c => {
          const itemId = c.req.param('itemId')
          return c.json({ id: itemId, name: 'Example Item' })
        },
      }),
    ],
  },
})
```

### 使用 Zod 模式 {/* #using-zod-schemas */}

生成 OpenAPI 文档时，`openapi` 配置中的 Zod 模式会转换为 JSON Schema：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { registerApiRoute } from '@mastra/core/server'
import { z } from 'zod'

const ItemSchema = z.object({
  id: z.string(),
  name: z.string(),
  price: z.number(),
})

const CreateItemSchema = z.object({
  name: z.string().min(1),
  price: z.number().positive(),
})

export const mastra = new Mastra({
  server: {
    apiRoutes: [
      registerApiRoute('/items', {
        method: 'POST',
        openapi: {
          summary: 'Create a new item',
          tags: ['Items'],
          requestBody: {
            required: true,
            content: {
              'application/json': {
                schema: CreateItemSchema,
              },
            },
          },
          responses: {
            201: {
              description: 'Item created',
              content: {
                'application/json': {
                  schema: ItemSchema,
                },
              },
            },
          },
        },
        handler: async c => {
          const body = await c.req.json()
          return c.json({ id: 'new-id', ...body }, 201)
        },
      }),
    ],
  },
})
```

### 在 Swagger UI 中查看 {/* #viewing-in-swagger-ui */}

以开发模式运行（`mastra dev`），或在构建选项中设置 `swaggerUI: true` 后，即可在 `/swagger-ui` 的 Swagger UI 中看到自定义路由。

```typescript
export const mastra = new Mastra({
  server: {
    build: {
      swaggerUI: true, // Enable in production builds
    },
    apiRoutes: [
      // Your routes...
    ],
  },
})
```

## 身份验证 {/* #authentication */}

如果 Mastra 服务器配置了身份验证，自定义 API 路由默认也需要验证。要公开某条路由，请设置 `requiresAuth: false`：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { registerApiRoute } from '@mastra/core/server'
import { MastraJwtAuth } from '@mastra/auth'

export const mastra = new Mastra({
  server: {
    auth: new MastraJwtAuth({
      secret: process.env.MASTRA_JWT_SECRET,
    }),
    apiRoutes: [
      // Protected route (default behavior)
      registerApiRoute('/protected-data', {
        method: 'GET',
        handler: async c => {
          // Access authenticated user from request context
          const user = c.get('requestContext').get('user')
          return c.json({ message: 'Authenticated user', user })
        },
      }),

      // Public route (no authentication required)
      registerApiRoute('/webhooks/github', {
        method: 'POST',
        requiresAuth: false, // Explicitly opt out of authentication
        handler: async c => {
          const payload = await c.req.json()
          // Process webhook without authentication
          return c.json({ received: true })
        },
      }),
    ],
  },
})
```

### 身份验证规则 {/* #authentication-behavior */}

- **未配置身份验证**：所有路由（内置和自定义）均可公开访问。
- **已配置身份验证**：
  - Mastra 提供的路由（如 `/api/agents/*`、`/api/workflows/*`）需要身份验证。
  - 自定义路由默认需要身份验证。
  - 自定义路由可以通过 `requiresAuth: false` 跳过身份验证。

### 访问用户信息 {/* #accessing-user-information */}

请求通过身份验证后，可以从请求上下文获取用户对象：

```typescript
registerApiRoute('/user-profile', {
  method: 'GET',
  handler: async c => {
    const requestContext = c.get('requestContext')
    const user = requestContext.get('user')

    return c.json({ user })
  },
})
```

有关身份验证提供方的更多信息，请参阅[身份验证文档](/docs/auth/overview)。

## 客户端断开连接后继续生成 {/* #continue-generation-after-client-disconnect */}

[`chatRoute()`](/reference/ai-sdk/chat-route) 等内置的流式传输辅助函数会把传入请求的 `AbortSignal` 转发给 `agent.stream()`。如果希望浏览器断开连接时取消模型调用，这一默认行为正好适用。

如果自定义流式路由应在客户端断开时停止，请将 `c.req.raw.signal` 传给 `agent.stream()` 等长时间运行的操作。客户端连接关闭后，Mastra 基于 Node 的适配器也会停止读取自定义路由返回的流式 `Response` 响应体。对于并非由客户端断开连接引起的响应体错误，适配器仍会按正常流程处理并传播。在 Hono 中，断线时的行为取决于宿主运行时是否将连接关闭通知传给 `request.signal`。

```typescript title="src/mastra/index.ts"
import { registerApiRoute } from '@mastra/core/server'

registerApiRoute('/stream', {
  method: 'GET',
  handler: async c => {
    const stream = await agent.stream(prompt, {
      abortSignal: c.req.raw.signal,
    })

    return stream.toTextStreamResponse()
  },
})
```

如果希望客户端断开后服务器继续生成并持久化最终响应，可以基于底层的 `MastraModelOutput` 构建自定义路由。启动 Agent 的流时省略 `c.req.raw.signal`，然后在后台调用 `consumeStream()`，让服务器继续生成。

```typescript title="src/mastra/index.ts"
import {
  createUIMessageStream,
  createUIMessageStreamResponse,
  InferUIMessageChunk,
  UIMessage,
} from 'ai'
import { toAISdkStream } from '@mastra/ai-sdk'
import { Mastra } from '@mastra/core'
import { registerApiRoute } from '@mastra/core/server'

export const mastra = new Mastra({
  server: {
    apiRoutes: [
      registerApiRoute('/chat/persist/:agentId', {
        method: 'POST',
        handler: async c => {
          const { messages, memory } = await c.req.json()
          const mastra = c.get('mastra')
          const agent = mastra.getAgent(c.req.param('agentId'))

          const stream = await agent.stream(messages, {
            memory,
            // Do not pass c.req.raw.signal if this route should keep running
            // after the client disconnects.
          })

          void stream.consumeStream().catch(error => {
            mastra.getLogger()?.error('Background stream consumption failed', { error })
          })

          const uiStream = createUIMessageStream({
            originalMessages: messages,
            execute: async ({ writer }) => {
              for await (const part of toAISdkStream(stream, { from: 'agent' })) {
                writer.write(part as InferUIMessageChunk<UIMessage>)
              }
            },
          })

          return createUIMessageStreamResponse({ stream: uiStream })
        },
      }),
    ],
  },
})
```

:::note

只有明确需要在 HTTP 客户端断开连接后继续执行时，才使用这种方式。如果需要在断开连接时取消生成，请继续使用 `chatRoute()`，或自行转发请求的 `AbortSignal`。

:::
