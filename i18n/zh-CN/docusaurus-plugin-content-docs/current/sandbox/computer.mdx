# 电脑

运行桌面环境的Sandbox可以公开屏幕截图、鼠标和键盘控制。当静态配置的Sandbox支持计算机功能时，Workspace会注册计算机Tool。

[`DaytonaSandbox`](/integrations/sandboxes/daytona)和[`E2BDesktopSandbox`](/integrations/sandboxes/e2b-desktop)支持此功能。其他Sandbox后端不注册计算机Tool。解析器支持的Sandbox不会注册它们，因为Workspace在创建Tool列表时无法检查已解析Sandbox的功能。

## 电脑Tool {/* #computer-tools */}

|Tool|是否 |
| - | - |
|`mastra_workspace_computer_screenshot` | Captures the desktop as a PNG image and returns it to the model as native media. |
| `mastra_workspace_computer_click` | Presses and releases the left mouse button at pixel coordinates. |
| `mastra_workspace_computer_double_click`|在像素坐标处按鼠标左键两次。 |
|`mastra_workspace_computer_right_click`|在像素坐标处按下并释放鼠标右键。 |
|`mastra_workspace_computer_move_mouse`|无需按按钮即可将光标移动到像素坐标。 |
|`mastra_workspace_computer_drag`|在两点之间按下、拖动和释放。 |
|`mastra_workspace_computer_type`|在焦点元素中键入文本。 |
|`mastra_workspace_computer_press_key`|按一个键或组合键，例如`Enter`或者`ctrl+s`. |
| `mastra_workspace_computer_scroll`|向上或向下滚动。 |
|`mastra_workspace_computer_get_screen_info`|获取屏幕尺寸和光标位置。 |
|`mastra_workspace_computer_wait`|等待界面稳定。 |

## 配置计算机Tool {/* #configure-computer-tools */}

默认情况下，操作Tool会在每次操作后截取屏幕截图。配置每个Tool的屏幕截图行为：

```typescript title="src/mastra/workspaces.ts"
import { Workspace, WORKSPACE_TOOLS } from '@mastra/core/workspace'
import { E2BDesktopSandbox } from '@mastra/e2b-desktop'

const workspace = new Workspace({
  sandbox: new E2BDesktopSandbox(),
  tools: {
    [WORKSPACE_TOOLS.COMPUTER.CLICK]: {
      screenshotAfterAction: true,
      screenshotDelayMs: 1000,
    },
    [WORKSPACE_TOOLS.COMPUTER.TYPE]: {
      requireApproval: true,
    },
  },
})
```

计算机Tool接受相同的每个Tool`enabled` and `requireApproval` configuration as other workspace tools.
