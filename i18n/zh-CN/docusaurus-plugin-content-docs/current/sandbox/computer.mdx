# 桌面控制

运行桌面环境的 Sandbox 可以提供截屏和鼠标、键盘控制功能。静态配置的 Sandbox 支持桌面控制时，Workspace 会注册相应的 Tool。

[`DaytonaSandbox`](/integrations/sandboxes/daytona) 和 [`E2BDesktopSandbox`](/integrations/sandboxes/e2b-desktop) 支持该功能。其他 Sandbox 后端不会注册桌面控制 Tool。通过解析器提供的 Sandbox 也不会注册这些 Tool，因为 Workspace 生成 Tool 列表时无法检查解析所得的 Sandbox 支持哪些功能。

## 桌面控制 Tool {/* #computer-tools */}

| Tool | 功能 |
| - | - |
| `mastra_workspace_computer_screenshot` | 将桌面截取为 PNG 图像，并以原生媒体形式返回给模型。 |
| `mastra_workspace_computer_click` | 在指定像素坐标处按下并松开鼠标左键。 |
| `mastra_workspace_computer_double_click` | 在指定像素坐标处双击鼠标左键。 |
| `mastra_workspace_computer_right_click` | 在指定像素坐标处按下并松开鼠标右键。 |
| `mastra_workspace_computer_move_mouse` | 将光标移到指定像素坐标，不按鼠标键。 |
| `mastra_workspace_computer_drag` | 在起点按下鼠标键，拖到终点后松开。 |
| `mastra_workspace_computer_type` | 在当前获得焦点的元素中输入文本。 |
| `mastra_workspace_computer_press_key` | 按下单个键或组合键，如 `Enter` 或 `ctrl+s`。 |
| `mastra_workspace_computer_scroll` | 向上或向下滚动。 |
| `mastra_workspace_computer_get_screen_info` | 获取屏幕尺寸和光标位置。 |
| `mastra_workspace_computer_wait` | 等待界面稳定。 |

## 配置桌面控制 Tool {/* #configure-computer-tools */}

执行操作的 Tool 默认在每次操作后截屏。可以为各个 Tool 单独配置截屏行为：

```typescript title="src/mastra/workspaces.ts"
import { Workspace, WORKSPACE_TOOLS } from '@mastra/core/workspace'
import { E2BDesktopSandbox } from '@mastra/e2b-desktop'

const workspace = new Workspace({
  sandbox: new E2BDesktopSandbox(),
  tools: {
    [WORKSPACE_TOOLS.COMPUTER.CLICK]: {
      screenshotAfterAction: true,
      screenshotDelayMs: 1000,
    },
    [WORKSPACE_TOOLS.COMPUTER.TYPE]: {
      requireApproval: true,
    },
  },
})
```

与其他 Workspace Tool 一样，每个桌面控制 Tool 都可单独设置 `enabled` 和 `requireApproval`。
