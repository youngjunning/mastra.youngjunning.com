# 快速检查

Quick Checks 是可组合的轻量评分器，可检查“输出包含 X”或“Agent 调用了工具 Y”等常见条件。无需调用 LLM 即可立即得到结果，并可与其他评分器放在同一个 `scorers: [...]` 数组中。

## 何时使用快速检查 {/* #when-to-use-quick-checks */}

需要快速、确定的断言时，可以使用 Quick Checks：

- 验证输出文本是否包含指定字符串
- 确认 Agent 是否调用了指定工具
- 检查工具调用的顺序及次数上限
- 用零成本的通过／不通过检查为 CI 流水线设定放行条件
- 搭配基于 LLM 的评分器进行分层评估

如果要做主观或语义评估，请使用[基于 LLM 的评分器](/docs/evals/built-in-scorers)。

## 快速入门 {/* #quickstart */}

```typescript title="src/evals/weather-checks.ts"
import { checks } from '@mastra/evals/checks'
import { runEvals } from '@mastra/core/evals'
import { weatherAgent } from '../agents'

const result = await runEvals({
  data: [{ input: 'What is the weather in Brooklyn?' }],
  target: weatherAgent,
  scorers: [checks.includes('Brooklyn'), checks.calledTool('get_weather'), checks.noToolErrors()],
})

console.log(result.scores)
// { 'check-includes': 1, 'check-called-tool': 1, 'check-no-tool-errors': 1 }
```

## 可用的检查 {/* #available-checks */}

Quick Checks 分为以下几类：

### 文本检查 {/* #text-checks */}

这些评分器检查 Agent 输出的文本：

| 检查 | 判定条件 | 分数 |
| - | - | - |
| `checks.includes(str)` | 输出包含子字符串 | 1 或 0 |
| `checks.excludes(str)` | 输出不包含子字符串 | 1 或 0 |
| `checks.equals(str)` | 输出等于指定字符串（默认不区分大小写；传入 `{ ignoreCase: false }` 可精确匹配） | 1 或 0 |
| `checks.matches(regex)` | 输出匹配正则表达式 | 1 或 0 |
| `checks.similarity(str)` | 用 Dice 系数衡量输出与指定字符串的相似度 | 0 至 1（使用 `threshold` 时为 1 或 0） |

### 工具调用检查 {/* #tool-call-checks */}

这些评分器检查 Agent 在运行过程中如何使用工具：

| 检查 | 判定条件 | 分数 |
| - | - | - |
| `checks.calledTool(name)` | 指定工具至少被调用 N 次 | 1 或 0 |
| `checks.didNotCall(name)` | 未调用指定工具 | 1 或 0 |
| `checks.toolOrder([...])` | 按预期顺序调用工具 | 1 或 0 |
| `checks.maxToolCalls(n)` | 工具调用总次数不超过 N | 1 或 0 |
| `checks.usedNoTools()` | 未调用任何工具 | 1 或 0 |
| `checks.noToolErrors()` | 所有工具调用均未出错 | 1 或 0 |

## 结合快速检查与 LLM 评分器 {/* #combining-checks-with-llm-scorers */}

一次 `runEvals` 调用可以同时使用 Quick Checks 和基于 LLM 的评分器。用 Quick Checks 判断是否满足明确的通过条件，用 LLM 评分器做定性评估：

```typescript title="src/evals/layered-eval.ts"
import { checks } from '@mastra/evals/checks'
import { createFaithfulnessScorer } from '@mastra/evals/scorers/prebuilt'
import { runEvals } from '@mastra/core/evals'
import { myAgent } from '../agents'

const result = await runEvals({
  data: [
    {
      input: 'What is the weather in Brooklyn?',
      context: ['Brooklyn weather data: sunny, 72°F'],
    },
  ],
  target: myAgent,
  scorers: [
    // Deterministic checks (instant, free)
    checks.includes('Brooklyn'),
    checks.calledTool('get_weather'),
    checks.excludes('error'),
    checks.noToolErrors(),

    // LLM-based scorer (semantic, costs tokens)
    createFaithfulnessScorer({ model: '__GATEWAY_OPENAI_MODEL_LUNA__' }),
  ],
})
```

## 在实时评分中使用快速检查 {/* #using-checks-in-live-scoring */}

将 Quick Checks 配置到 Agent 上，即可持续监控：

```typescript title="src/agents/weather-agent.ts"
import { Agent } from '@mastra/core/agent'
import { checks } from '@mastra/evals/checks'

export const weatherAgent = new Agent({
  id: 'weather-agent',
  name: 'Weather Agent',
  instructions: 'Answer weather questions using the get_weather tool.',
  model: '__GATEWAY_OPENAI_MODEL__',
  tools: { get_weather: weatherTool },
  scorers: {
    noErrors: {
      scorer: checks.noToolErrors(),
      sampling: { type: 'ratio', rate: 1 },
    },
    mentionCity: {
      scorer: checks.includes('Brooklyn'),
      sampling: { type: 'ratio', rate: 0.5 },
    },
  },
})
```

## 快速检查的工作原理 {/* #how-checks-work */}

每项检查都是标准的 `createScorer()` 实例，包含 `preprocess` 和 `generateScore` 两个步骤，与其他评分器共用同一套[四步流程](/docs/evals/custom-scorers#the-four-step-pipeline)：

1. **preprocess**：提取并规范化 Agent 本次运行的相关数据（文本内容、工具调用）。
1. **generateScore**：将预处理结果转换为分数（通常为 1 或 0）。

Quick Checks 跳过 `analyze` 和 `generateReason` 步骤，也不调用 LLM，因此几微秒即可完成。完整 API 及各项检查的参数和选项，请参阅[快速检查参考](/reference/evals/checks)。
