# 在 CI 中运行评分器

在 CI 流水线中运行评分器，可以用量化指标跟踪 Agent 的质量。`runEvals` 函数会让 Agent 或 Workflow 处理多个测试用例，并返回汇总得分。

## 基本设置 {/* #basic-setup */}

可以使用任何支持 ESM 模块的测试框架，例如 [Vitest](https://vitest.dev/)、[Jest](https://jestjs.io/) 或 [Mocha](https://mochajs.org/)。

## 创建测试用例 {/* #creating-test-cases */}

使用 `runEvals` 在多个测试用例上评估 Agent。该函数接收一个数据项数组，每项包含 `input`，也可以提供 `groundTruth` 供评分器验证。

请使用 `mastra.getAgent()` 或 `mastra.getWorkflow()` 获取 `target`，避免直接导入。直接导入的 Agent 或 Workflow 未绑定 Mastra 实例，因而无法在步骤或 Tool 内查询注册表（例如 `mastra.getAgent('weatherAgent')`），评分不会持久化，也无法基于 Trace 对执行轨迹评分。

```typescript title="tests/weather-agent.test.ts"
import { describe, it, expect } from 'vitest'
import { runEvals } from '@mastra/core/evals'
import { mastra } from '../src/mastra'
import { locationScorer } from '../src/mastra/scorers/location-scorer'

describe('Weather Agent Tests', () => {
  it('should correctly extract locations from queries', async () => {
    const result = await runEvals({
      data: [
        {
          input: 'weather in Berlin',
          groundTruth: { expectedLocation: 'Berlin', expectedCountry: 'DE' },
        },
        {
          input: 'weather in Berlin, Maryland',
          groundTruth: { expectedLocation: 'Berlin', expectedCountry: 'US' },
        },
        {
          input: 'weather in Berlin, Russia',
          groundTruth: { expectedLocation: 'Berlin', expectedCountry: 'RU' },
        },
      ],
      target: mastra.getAgent('weatherAgent'),
      scorers: [locationScorer],
    })

    // Assert aggregate score meets threshold
    expect(result.scores['location-accuracy']).toBe(1)
    expect(result.summary.totalItems).toBe(3)
  })
})
```

## 读懂评估结果 {/* #understanding-results */}

`runEvals` 函数返回一个对象，其中包含以下字段。

- `scores`。各评分器在所有测试用例上的平均分。
- `summary.totalItems`。已处理的测试用例总数。

```typescript oxfmt:false
{
  scores: {
    'location-accuracy': 1.0,  // Average score across all items
    'another-scorer': 0.85
  },
  summary: {
    totalItems: 3
  }
}
```

## 多种测试场景 {/* #multiple-test-scenarios */}

为不同的评估场景分别创建测试用例。

```typescript title="tests/weather-agent.test.ts"
describe('Weather Agent Tests', () => {
  const weatherAgent = mastra.getAgent('weatherAgent')

  it('should handle location disambiguation', async () => {
    const result = await runEvals({
      data: [
        {
          input: 'weather in Berlin',
          groundTruth: {/* ... */},
        },
        {
          input: 'weather in Berlin, Maryland',
          groundTruth: {/* ... */},
        },
      ],
      target: weatherAgent,
      scorers: [locationScorer],
    })

    expect(result.scores['location-accuracy']).toBe(1)
  })

  it('should handle typos and misspellings', async () => {
    const result = await runEvals({
      data: [
        {
          input: 'weather in Berln',
          groundTruth: { expectedLocation: 'Berlin', expectedCountry: 'DE' },
        },
        {
          input: 'weather in Parris',
          groundTruth: { expectedLocation: 'Paris', expectedCountry: 'FR' },
        },
      ],
      target: weatherAgent,
      scorers: [locationScorer],
    })

    expect(result.scores['location-accuracy']).toBe(1)
  })
})
```
