# 大门和判决

门和判决添加了严重性语义`runEvals`。盖茨是必须得分为 1.0 的得分手，这是阻止跑动的硬性要求。阈值是跟踪指标的平均分数的下限和/或上限。判决将结果总结为`passed`, `scored`， 或者`failed`.

## 何时使用门和判决 {/* #when-to-use-gates-and-verdicts */}

* 在 CI 中强制执行硬性要求（例如，“Agent必须调用正确的Tool”）
* 跟踪具有最小阈值的质量指标（例如，“忠实度高于 0.7”）
* 获取单个判决信号（`passed`, `scored`, or `failed`) from an eval run without writing custom assertion logic
* 将“必须通过”的关卡与“最好有”的跟踪指标分开

## 快速入门 {/* #quickstart */}

```typescript title="src/evals/weather-eval.ts"
import { runEvals } from '@mastra/core/evals'
import { checks } from '@mastra/evals/checks'
import { weatherAgent } from '../agents'
import { faithfulnessScorer } from '../scorers'

const result = await runEvals({
  data: [{ input: 'What is the weather in Brooklyn?' }],
  target: weatherAgent,

  // Gates: must all score 1.0 or the run fails
  gates: [checks.calledTool('get_weather'), checks.noToolErrors()],

  // Scorers: tracked with optional thresholds
  scorers: [
    { scorer: faithfulnessScorer, threshold: 0.7 },
    checks.includes('Brooklyn'), // no threshold = tracked only
  ],
})

console.log(result.verdict) // 'passed' | 'scored' | 'failed'
```

## 判决如何运作 {/* #how-verdicts-work */}

处理所有数据项后，根据门和阈值计算判决：

* `failed`：至少有一个门的数据项平均值低于 1.0
* `scored`：所有门都通过了，但至少有一个阈值得分者未达到阈值
* `passed`：所有门得分为 1.0，并且满足所有阈值

当没有提供门或阈值计分器时，以及当每个配置的门和阈值都返回时，判决字段将被省略`notScorable()` (no numeric evidence). In those cases `runEvals` still returns `scores` and `summary`.

## 盖茨 {/* #gates */}

门是得分者通过`gates` field. They run before regular scorers on each data item. A gate must average a score of 1.0 across the data items it could score to pass. Items where the gate returns `notScorable()` are excluded from the average, and a gate that throws an error counts as 0 for that item.

```typescript title="src/evals/tool-gate.ts"
import { runEvals } from '@mastra/core/evals'
import { checks } from '@mastra/evals/checks'

const result = await runEvals({
  data: [{ input: 'What is the weather?' }],
  target: weatherAgent,
  gates: [checks.calledTool('get_weather')],
  scorers: [qualityScorer],
})

// result.gateResults: [{ id: 'check-called-tool', passed: true, score: 1 }]
```

任何得分手都充当大门。快速检查非常适合，因为它们返回二进制 1/0 分数。访问[runEvals() reference](/reference/evals/run-evals) for the full parameter and return type documentation.

### 仅登机口运行 {/* #gate-only-runs */}

`scorers`当至少提供一个门时，该门是可选的。这对于确定性 CI 检查非常有用，您只关心通过/失败门，不需要跟踪任何质量指标。

```typescript title="src/evals/gate-only.ts"
import { runEvals } from '@mastra/core/evals'
import { checks } from '@mastra/evals/checks'

const result = await runEvals({
  data: [{ input: 'What is the weather in Brooklyn?' }],
  target: weatherAgent,
  gates: [checks.calledTool('get_weather'), checks.noToolErrors()],
})
```

您必须提供至少一名得分手或门将，两者都没有的跑动不会引发错误。

## 阈值 {/* #thresholds */}

将得分手包裹起来`{ scorer, threshold }` to set pass/fail bounds. The threshold is compared against the scorer's average score across scored data items. Results that return `notScorable()` are left out of the average.

一个`threshold` can be:

* **一个数字**：表示最低分数（分数等于或高于及格）：`{ scorer, threshold: 0.7 }`
* **一个对象与`min` and/or `max`**：对于基于范围的检查：`{ scorer, threshold: { max: 0.3 } }`

使用`max` for scorers where a high score is bad (e.g., hallucination, toxicity). Use `{ min, max }` when the score should fall within a specific band.

```typescript title="src/evals/threshold-example.ts"
import { runEvals } from '@mastra/core/evals'

const result = await runEvals({
  data: [{ input: 'Explain quantum computing' }],
  target: myAgent,
  scorers: [
    { scorer: faithfulnessScorer, threshold: 0.7 }, // min threshold (number shorthand)
    { scorer: hallucinationScorer, threshold: { max: 0.3 } }, // max threshold — high score = bad
    { scorer: verbosityScorer, threshold: { min: 0.3, max: 0.8 } }, // range threshold
    toneScorer, // bare scorer, no threshold — tracked only
  ],
})

// result.thresholdResults:
// [
//   { id: 'faithfulness', passed: true, averageScore: 0.85, threshold: 0.7 },
//   { id: 'hallucination', passed: true, averageScore: 0.1, threshold: { max: 0.3 } },
//   { id: 'verbosity', passed: false, averageScore: 0.9, threshold: { min: 0.3, max: 0.8 } },
// ]
```

裸得分手（无门槛）仍然出现在`result.scores` but doesn't affect the verdict.

## 在 CI 中使用判决 {/* #using-verdicts-in-ci */}

该判决为 CI 管道提供了一个信号：

```typescript title="src/evals/ci-check.ts"
import { runEvals } from '@mastra/core/evals'
import { checks } from '@mastra/evals/checks'

const result = await runEvals({
  data: testDataset,
  target: myAgent,
  gates: [checks.calledTool('search'), checks.noToolErrors()],
  scorers: [{ scorer: faithfulnessScorer, threshold: 0.7 }],
})

if (result.verdict === 'failed') {
  console.error(
    'Gate failures:',
    result.gateResults?.filter(g => !g.passed),
  )
  process.exit(1)
}

if (result.verdict === 'scored') {
  console.warn(
    'Threshold misses:',
    result.thresholdResults?.filter(t => !t.passed),
  )
}
```
