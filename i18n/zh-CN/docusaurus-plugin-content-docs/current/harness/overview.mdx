# 马具

安全带可以让Agent追求长期、复杂的目标，同时保持其工作持久、可见和可操纵。它可以在重试和中断时保留进度，同时为人员和其他系统提供检查进度、添加上下文、批准操作、重定向Agent或停止Agent的方法。

只要工作持续进行，Agent安全带就非常有用。常见的例子包括通过 CI 和审查进行更改的编码Agent、软件工厂（例如[Mastra Factory](https://factory.mastra.ai)) that coordinate many tasks in parallel, SRE agents that adapt as incidents evolve, and go-to-market agents that respond as accounts, signals, and conversations change.

在 Mastra 中，利用是指在单次不间断运行之外管理Agent的一组功能。您可以单独采用这些功能，也可以根据需要组合使用它们。

## 何时使用安全带 {/* #when-to-use-a-harness */}

根据Agent的需求选择起点。您可以使用一种或多种功能。

|如果你想|从这里开始 |为什么 |
| - | - | - |
|通过客户端断开连接或服务器重新启动保持运行可用 |[Durable Agents](/docs/harness/durable-agents) | Persist run state and let clients reconnect to its stream. |
| Run slow tools, workflows, or subagents without blocking | [Background Tasks](/docs/harness/background-tasks) | Finish work asynchronously and return its result to the agent. |
| Keep an agent working until it reaches an objective | [Goals](/docs/harness/goals) | Evaluate a thread-scoped objective until it's complete or reaches its run budget. |
| Start work automatically at recurring times | [时间表](/docs/harness/schedules)|按 cron 计划启动隔离运行或将提示发送到现有线程。 |
|添加上下文、重定向活动工作或唤醒空闲线程 |[信号](/docs/signals/overview)|现在提供输入或保留到下一回合。 |
|对 GitHub、Slack、持续集成或其他外部系统中的更改做出反应 |[信号Provider](/docs/signals/signal-providers)|跟踪订阅并将匹配事件转发到Agent线程。 |
|构建具有会话、模式、状态、批准和事件的交互式产品，或让用户引导、排队后续工作和停止运行 |[Agent控制器](/docs/harness/agent-controller)|围绕共享Agent运行时托管隔离会话，每个会话都有自己的运行控件。 |
|提供Agent文件、外壳以及编码Agent所需的默认设置 |[`createCodingAgent()`](/reference/coding-agent/create-coding-agent)|构建一个标准Agent，其中包含已配置的Workspace、任务跟踪和重试。 |
