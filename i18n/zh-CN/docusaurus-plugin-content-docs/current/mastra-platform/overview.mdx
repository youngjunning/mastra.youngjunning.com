# Mastra Platform

[Mastra Platform](https://projects.mastra.ai) 提供三款产品，用于部署、监控和管理基于 Mastra 框架构建的 AI 应用。

- [**Observability**](/docs/mastra-platform/observability)。每个平台项目的基础产品，支持跨 Mastra 项目和部署搜索 Trace、日志及指标。
- [**Studio**](/docs/mastra-platform/studio)。托管的可视化环境，用于测试 Agent、运行 Workflow，并提供查看 Trace 的工具。从 Studio 开始也会获得 Observability。
- [**Server**](/docs/mastra-platform/server)。生产部署环境，将 Mastra 应用作为 API 服务器运行。从 Server 开始也会获得 Observability。

只需运行 [`mastra deploy`](/docs/mastra-platform/deploy) 即可部署，也可以关联 GitHub 仓库，在推送时自动部署。仓库关联流程见 [GitHub 集成](/docs/mastra-platform/github)。

每个项目可以运行多个[**环境**](/docs/mastra-platform/environments)（如 `production` 和 `staging`），并通过 CLI 或项目设置开通[**托管数据库**](/docs/mastra-platform/database)，持久化应用数据。每个环境还配有托管的 [**Workspace**](/docs/mastra-platform/workspaces)，无需手动配置即可为 Agent 提供文件系统和 Sandbox。

组织级[**告警**](/docs/mastra-platform/alerts)会在部署失败或正在运行的服务停止时通知团队。告警可覆盖所有项目，也可仅覆盖选定的项目和环境。通知可发送到 Slack、邮箱或 Webhook。

[**Connect**](/docs/mastra-platform/connect) 保存你在 Linear、Slack 和 GitHub 等服务上的账号，让 Agent 把这些服务用作 Tool 或聊天渠道，无需自行创建第三方应用或管理 API 密钥。

[**Trace Intelligence**](/docs/mastra-platform/trace-intelligence) 从 Agent 的 Trace 中识别反复出现的目标、结果、行为和情绪。目前仅向部分项目开放私测。

## 开始使用 {/* #get-started */}

根据目标选择入门方式。

- **接入托管可观测性**。使用 [Observability](/docs/mastra-platform/observability) 收集多个项目和部署中可搜索的 Trace、日志和指标。如果希望直接开始监控，无需先部署 Studio 或 Server，请从这里开始。
- **部署 Studio**。使用 [Studio](/docs/mastra-platform/studio) 为团队托管可视化开发环境。如果需要一个共享界面来测试 Agent、运行 Workflow 和查看 Trace，请从这里开始。
- **部署 Server**。使用 [Server](/docs/mastra-platform/server) 将 Mastra 应用作为生产 API 服务器运行。准备好在云端提供 Agent、Tool 和 Workflow 时，请从这里开始。
- **搭建软件工厂**。将 [Mastra Factory](https://factory.mastra.ai) 部署到 Mastra Platform 并关联代码仓库，把 Issue 转化为计划、实现和经过审查的拉取请求。

## 核心概念 {/* #key-concepts */}

**项目**是所有产品共用的上层实体。一个项目可以同时包含 Observability、Studio 和 Server。项目隶属于**组织**，组织是团队的多租户容器。

Mastra 应用由三类组件组成。

- [Agent](/docs/agents/overview)。能够保持上下文、遵循指令和使用 Tool 的 AI Agent。
- [Tool](/docs/agents/tools)。可供 Agent 调用的函数和集成。
- [Workflow](/docs/workflows/overview)。协调 Agent 和 Tool 的多步骤编排流程。

## 部署到生产环境 {/* #going-to-production */}

使用 [`mastra dev`](/reference/cli/mastra#mastra-dev) 在本地开发项目，再打开 [Studio](/docs/studio/overview)，在可视化环境中测试 Agent、Workflow 和 Tool。

准备好部署到生产环境后，运行 [`mastra deploy`](/reference/cli/mastra#mastra-deploy) 将应用部署到云端。

具体步骤见[部署文档](/docs/mastra-platform/deploy)。

即使在自有基础设施上托管 Mastra 应用，也可以使用 [MastraPlatformExporter](/docs/mastra-platform/observability) 将可观测性数据发送到 Mastra Platform。
