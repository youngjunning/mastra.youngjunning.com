# Agent商

Agent使用法学硕士和Tool来解决开放式任务。他们推理目标并决定使用哪些Tool。和[memory](/docs/memory/overview)配置后，它们会保留对话历史记录。它们继续迭代，直到模型发出最终答案或满足可选的停止条件。

Agent生成结构化响应，您可以在 UI 中呈现或以编程方式处理。直接使用Agent或将它们组合到Workflow程或多Agent系统中。

## 何时使用Agent {/* #when-to-use-agents */}

当任务是开放式的并且事先不知道步骤时，使用Agent。Agent决定调用哪些Tool、循环多少次以及何时停止。您提供目标和约束，而不是定义每个步骤。对于具有明确控制流程的预定多步骤过程，请使用[workflows](/docs/workflows/overview) instead.

## 快速入门 {/* #quickstart */}

通过实例化创建Agent`Agent` class from `@mastra/core` and provide the required properties:

```typescript title="src/mastra/agents/test-agent.ts"
import { Agent } from '@mastra/core/agent'

export const testAgent = new Agent({
  id: 'test-agent',
  name: 'Test Agent',
  instructions: 'You are a helpful assistant.',
  model: '__GATEWAY_OPENAI_MODEL__',
})
```

这`instructions` define the agent's behavior, personality, and capabilities. They're system-level prompts that establish the agent's core identity and expertise. The `model` is specified as `'provider/model-name'` using Mastra's [model router](/models).

要使Agent在您的整个应用程序中可用，请将其注册到您的 Mastra 实例中（通常位于`src/mastra/index.ts`):

```typescript {5} title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { testAgent } from './agents/test-agent'

export const mastra = new Mastra({
  agents: { testAgent },
})
```

注册后，它可以从Workflow、Tool或其他Agent中调用，并且可以访问共享资源，例如内存、日志记录和可观察性功能。

参观[agent reference](/reference/agents/agent) for more information on available properties and configurations.

：：：提示

使用[Studio](/docs/studio/overview) to test your agent with different messages and inspect tool calls and responses, plus debug agent behavior.

使用[Agent Builder](https://agent-builder.mastra.ai) to create and manage a fully stored agent through a browser instead of defining it in TypeScript.

## 使用您的Agent {/* #use-your-agent */}

注册后，通过以下方式找回您的Agent[`mastra.getAgentById()`](/reference/core/getAgentById). Call `.generate()` for a complete response or `.stream()` to deliver tokens in real time. You can call agents from [workflow steps](/docs/workflows/agents-and-tools), [tools](/docs/agents/tools), the [Mastra Client](/reference/client-js/mastra-client), route handlers, [server adapters](/docs/server/server-adapters), or the command line. See [Integrations](/integrations) to use agents in your application framework.

从 Mastra 实例引用Agent时，请使用`mastra.getAgentById()` to ensure it has access to shared services such as instance-level storage, logging, and agent registry. A directly imported agent can still work with its own local configuration, but it won't have access to those shared services.

<Tabs>
  <TabItem value="generate" label=".generate()">
    所有Tool调用和步骤完成后返回完整响应。结果包括`text`, `toolCalls`, `toolResults`, `steps`, and token `usage` statistics.

    请参阅[`Agent.generate()` reference](/reference/agents/generate) for the response shape, including tool call and tool result payloads.

    ```ts
    const agent = mastra.getAgentById('test-agent')
    const response = await agent.generate('Help me organize my day')
    console.log(response.text)
    ```
  </TabItem>

  <TabItem value="stream" label=".stream()">
    返回一个您可以在令牌到达时使用的流。结果暴露了`textStream` for incremental output and promises for `toolCalls`, `toolResults`, `steps`, and token `usage` that resolve when the stream finishes.

    请参阅[`MastraModelOutput` reference](/reference/streaming/agents/MastraModelOutput) for the stream shape, including tool call and tool result payloads.

    ```ts
    const agent = mastra.getAgentById('test-agent')
    const stream = await agent.stream('Help me organize my day')

    for await (const chunk of stream.textStream) {
      process.stdout.write(chunk)
    }
    ```
  </TabItem>
</Tabs>

## 多Agent系统 {/* #multi-agent-systems */}

多Agent系统使用多个Agent来解决对于单个Agent而言过于广泛或过于专业的任务。您无需使用数十种Tool和一长串指令来构建一个Agent，而是将职责分配给各个重点Agent，并让协调员将结果汇总在一起。

阅读[conceptual overview of multi-agent systems](/docs/guides/multi-agent-systems) to learn how you can apply different patterns with Mastra.
