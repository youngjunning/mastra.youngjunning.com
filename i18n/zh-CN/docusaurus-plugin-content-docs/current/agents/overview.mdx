# Agent

Agent 使用 LLM 和 Tool 解决开放式任务。它们会围绕目标进行推理，并决定使用哪些 Tool。配置 [Memory](/docs/memory/overview) 后，Agent 可以保留对话历史。Agent 会持续迭代，直到模型给出最终答案或满足可选的停止条件。

Agent 可以生成结构化响应，供 UI 渲染或程序处理。既可以直接使用 Agent，也可以将多个 Agent 组合到 Workflow 或多 Agent 系统中。

## 何时使用 Agent {/* #when-to-use-agents */}

当任务是开放式的、无法预先确定执行步骤时，适合使用 Agent。Agent 会决定调用哪些 Tool、循环多少次以及何时停止；你只需提供目标和约束，不必逐步定义执行过程。对于控制流程明确、步骤预先确定的多阶段任务，请改用 [Workflow](/docs/workflows/overview)。

观看 [Mastra Agent 快速入门](https://www.youtube.com/watch?v=G8tXjcseNjg)，快速了解如何创建和测试 Mastra Agent。

:::

## 快速入门 {/* #quickstart */}

从 `@mastra/core` 导入并实例化 `Agent` 类，同时提供必需属性：

```typescript title="src/mastra/agents/test-agent.ts"
import { Agent } from '@mastra/core/agent'

export const testAgent = new Agent({
  id: 'test-agent',
  name: 'Test Agent',
  instructions: 'You are a helpful assistant.',
  model: '__GATEWAY_OPENAI_MODEL__',
})
```

`instructions` 用于定义 Agent 的行为、角色和能力。它属于系统级提示词，用来确立 Agent 的核心身份和专业范围。`model` 通过 Mastra 的[模型路由器](/models)，采用 `'provider/model-name'` 格式指定。

要让整个应用都能使用该 Agent，请将它注册到 Mastra 实例中。该实例通常位于 `src/mastra/index.ts`：

```typescript {5} title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { testAgent } from './agents/test-agent'

export const mastra = new Mastra({
  agents: { testAgent },
})
```

注册后，Workflow、Tool 或其他 Agent 都可以调用它；它也能访问 Memory、日志和可观测性等共享资源。

有关可用属性和配置的详细说明，请参阅 [Agent API 参考](/reference/agents/agent)。

:::tip

使用 [Studio](/docs/studio/overview) 可以通过不同消息测试 Agent，检查 Tool 调用和响应，并调试 Agent 行为。

使用 [Agent Builder](https://agent-builder.mastra.ai) 可以在浏览器中创建和管理完整持久化的 Agent，无需在 TypeScript 中定义。

:::

## 使用 Agent {/* #use-your-agent */}

注册后，通过 [`mastra.getAgentById()`](/reference/core/getAgentById) 获取 Agent。调用 `.generate()` 可等待并获得完整响应；调用 `.stream()` 可实时发送生成的 token。Agent 可以在 [Workflow 步骤](/docs/workflows/agents-and-tools)、[Tool](/docs/agents/tools)、[Mastra Client](/reference/client-js/mastra-client)、路由处理程序、[Server Adapter](/docs/server/server-adapters)或命令行中调用。要在应用框架中使用 Agent，请参阅[集成](/integrations)。

从 Mastra 实例引用 Agent 时，应使用 `mastra.getAgentById()`，确保它能够访问实例级存储、日志和 Agent 注册表等共享服务。直接导入的 Agent 仍可使用自身的本地配置运行，但无法访问这些共享服务。

<Tabs>
  <TabItem value="generate" label=".generate()">
    在所有 Tool 调用和步骤完成后返回完整响应。结果包含 `text`、`toolCalls`、`toolResults`、`steps` 和 token `usage` 统计信息。

    有关响应结构（包括 Tool 调用和 Tool 结果载荷），请参阅 [`Agent.generate()` API 参考](/reference/agents/generate)。

    ```ts
    const agent = mastra.getAgentById('test-agent')
    const response = await agent.generate('Help me organize my day')
    console.log(response.text)
    ```
  </TabItem>

  <TabItem value="stream" label=".stream()">
    返回一个可随 token 到达而消费的流。结果通过 `textStream` 提供增量输出，并通过 Promise 提供 `toolCalls`、`toolResults`、`steps` 和 token `usage`；这些 Promise 会在流结束时完成。

    有关流式响应结构（包括 Tool 调用和 Tool 结果载荷），请参阅 [`MastraModelOutput` API 参考](/reference/streaming/agents/MastraModelOutput)。

    ```ts
    const agent = mastra.getAgentById('test-agent')
    const stream = await agent.stream('Help me organize my day')

    for await (const chunk of stream.textStream) {
      process.stdout.write(chunk)
    }
    ```
  </TabItem>
</Tabs>

## 多 Agent 系统 {/* #multi-agent-systems */}

多 Agent 系统使用多个 Agent 共同解决对单个 Agent 而言范围过广或专业跨度过大的任务。与其为一个 Agent 配置几十个 Tool 和冗长的 instructions，不如将职责拆分给多个专注的 Agent，再由协调 Agent 汇总结果。

阅读[多 Agent 系统概念指南](/docs/guides/multi-agent-systems)，了解如何在 Mastra 中应用不同的协作模式。
