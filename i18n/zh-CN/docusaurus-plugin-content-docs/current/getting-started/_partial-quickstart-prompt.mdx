  创建一个新的 Mastra 项目。Mastra 是基于现代 TypeScript 技术栈构建 AI 应用和 Agent 的框架。运行命令前，请逐一询问以下问题，每次等用户回答后再继续。已经回答的问题无需再问：

  1. 项目名称是什么？（必填，例如“my-mastra-app”）

  项目创建完成后，进入项目目录并启动开发服务器：`npx bgproc start -n <project-name> -w -- npm run dev`

  在 `http://localhost:4111` 打开 Mastra Studio。可以在 Studio 中构建、测试和管理 Agent、Workflow 和 Tool。

  同时告诉用户，Mastra 模型路由器可以访问数千种模型：[https://mastra.ai/models](/models)
