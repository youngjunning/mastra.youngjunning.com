# 部署

Mastra 应用程序可以部署到任何 Node.js 兼容环境。您可以部署 Mastra 服务器或与现有 Web 框架集成。其他选项包括云Provider和[Mastra platform](/docs/mastra-platform/overview)用于可观察性、Studio 和服务器部署。

## 运行时支持 {/* #runtime-support */}

Mastra 可以在以下任何运行时环境中运行：

* Node.js`v22.13.0` or later
* 包子
* 德诺
* 云耀

## 部署选项 {/* #deployment-options */}

### 马斯特拉服务器 {/* #mastra-server */}

马斯特拉提供了[server](/docs/server/overview) powered by Hono that can be deployed independently. Use the `mastra build` command to build your application and deploy the output to your preferred VM, container, or PaaS platform.

当您需要完全控制基础架构、长时间运行的进程或 WebSocket 连接时，请使用此选项。这[Mastra server deployment guide](/docs/deployment/mastra-server) provides more details.

### 莫诺雷波 {/* #monorepo */}

将 Mastra 服务器部署为 monorepo 设置的一部分，遵循与独立部署相同的方法。

阅读有关[monorepo deployment](/docs/deployment/monorepo).

### 马斯特拉平台 {/* #mastra-platform */}

这[Mastra platform](/docs/mastra-platform/overview) provides three products for deploying, monitoring, and managing AI applications built with the Mastra framework:

* [**可观察性**](/docs/mastra-platform/observability)：一个独立的托管产品，用于跨 Mastra 项目和部署的可搜索跟踪、日志和指标
* [**工作室**](/docs/mastra-platform/studio)：用于测试Agent和运行Workflow程以及检查跟踪的托管可视环境
* [**服务器**](/docs/mastra-platform/server)：作为 API 服务器运行 Mastra 应用程序的生产部署目标

了解更多信息[Mastra platform overview](/docs/mastra-platform/overview).

### 云Provider {/* #cloud-providers */}

Mastra 应用程序可以部署到云Provider和无服务器平台。 Mastra 包括适用于 Vercel、Netlify 和 Cloudflare 的可选内置部署程序，可以为每个平台构建应用程序。然后，您可以通过平台本身部署构建输出。

使用此选项进行自动扩展、最小化基础设施管理，或者当您已经在使用这些平台之一时。

### 沙盒 {/* #sandbox */}

将 Mastra 服务器部署到临时WorkspaceSandbox（例如 Vercel Sandbox 或 E2B）中，并在几秒钟内获得实时公共 URL。

使用此选项进行即时预览、从 CI 管道部署、验证Agent构建的应用程序或运行不受信任的每用户实例。阅读[sandbox deployment guide](/docs/deployment/sandbox).

### 网络框架 {/* #web-framework */}

当 Mastra 与 Web 框架集成时，它会使用框架的标准部署流程与您的应用程序一起部署。以下指南涵盖了特定于框架的部署配置要求。

将 Mastra 添加到现有 Next.js 或 Astro 应用程序时，请使用这些指南。

* [在 Vercel 上使用 Next.js](/docs/deployment/web-framework#with-nextjs-on-vercel)
* [与 Vercel 上的 Astro 一起](/docs/deployment/web-framework#with-astro-on-vercel)
* [与 Netlify 上的 Astro 一起](/docs/deployment/web-framework#with-astro-on-netlify)

## Workflow程运行器 {/* #workflow-runners */}

默认情况下，Mastra Workflow程使用内置执行引擎运行。对于需要托管基础设施的生产工作负载，还可以将Workflow程部署到专用平台，例如[Inngest](https://www.inngest.com) that provide step memoization and automatic retries, with real-time monitoring.

参观[Workflow Runners guide](/docs/deployment/workflow-runners) for execution options and the [Inngest deployment guide](/integrations/deploy/inngest) for setup instructions.

## 工人 {/* #workers */}

对于生产部署，Mastra 可以运行Workflow编排和 cron 调度，以及在与 API 服务器分开的专用工作进程中执行后台Tool。这使您可以独立扩展每个问题并隔离故障。看[Workers](/docs/deployment/workers) for details.
