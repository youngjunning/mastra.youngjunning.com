# 云Provider

Mastra 应用程序可以部署到云Provider和无服务器平台。 Mastra 包括适用于 Vercel、Netlify 和 Cloudflare 的可选内置部署程序，用于自动化部署过程。

## 马斯特拉平台 {/* #mastra-platform */}

Mastra 提供了一个将服务器部署到云的平台。阅读[Mastra platform deployment guide](/docs/mastra-platform/overview) to learn more.
