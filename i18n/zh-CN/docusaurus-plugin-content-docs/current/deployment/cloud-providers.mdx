# 云服务商

你可以将 Mastra 应用部署到云服务商或无服务器平台。Mastra 为 Vercel、Netlify 和 Cloudflare 提供了可选的内置部署工具，可自动完成部署。

## Mastra 平台 {/* #mastra-platform */}

你可以通过 Mastra 平台将服务器部署到云端。详情请参阅 [Mastra 平台部署指南](/docs/mastra-platform/overview)。
