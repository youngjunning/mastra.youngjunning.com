# Workflow 运行器

Mastra 的 [Workflow](/docs/workflows/overview) 可以用内置运行器执行，也可以部署到专用平台，由平台负责编排、监控和可靠执行。

## Inngest {/* #inngest */}

Inngest 是一个无需自行管理基础设施即可运行后台 Workflow 的开发者平台。将 Mastra Workflow 部署到 Inngest 后，可以复用已完成步骤的结果，并在失败时自动重试。Inngest 还支持实时监控，以及暂停和恢复执行。

设置步骤见 [Inngest 部署指南](/integrations/deploy/inngest)，完整实现见 [Inngest Workflow 示例](https://github.com/mastra-ai/mastra/tree/main/examples/inngest)。

## Temporal {/* #temporal */}

Temporal 是一个用于编排长时间运行的 Workflow 的持久化执行平台。Mastra Workflow 可以在 Temporal Worker 上运行。每个通过 `createStep` 定义的步骤都会映射为一个 Temporal Activity，从而支持自动重试和状态持久化。

`@mastra/temporal` 仍处于实验阶段，尚不适用于生产环境。设置步骤见 [Temporal 部署指南](/integrations/deploy/temporal)。
