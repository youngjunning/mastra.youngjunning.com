# Workflow程运行器

马斯特拉[workflows](/docs/workflows/overview)可以使用内置的Workflow运行器执行，也可以部署到处理编排、监控和可靠性的专用Workflow执行平台。

## 因格斯特 {/* #inngest */}

Inngest 是一个开发者平台，用于运行后台Workflow程而无需管理基础设施。 Mastra Workflow程可以部署到 Inngest 以进行步骤记忆和自动重试。 Inngest 还提供实时监控和暂停/恢复功能。

参观[Inngest deployment guide](/integrations/deploy/inngest) for setup instructions and the [Inngest workflow example](https://github.com/mastra-ai/mastra/tree/main/examples/inngest) for a complete implementation.

## 颞 {/* #temporal */}

Temporal 是一个持久的执行平台，用于编排长时间运行的Workflow程。 Mastra Workflow程可以在 Temporal Workers 上运行，每个Workflow程`createStep` mapped to a Temporal activity for automatic retries and durable state.

这`@mastra/temporal` package is experimental and not ready for production use. Visit the [Temporal deployment guide](/integrations/deploy/temporal) for setup instructions.
