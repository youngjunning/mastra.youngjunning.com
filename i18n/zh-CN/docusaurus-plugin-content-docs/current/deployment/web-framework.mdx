# 网页框架

当 Mastra 与 Web 框架集成时，它会使用框架的标准部署流程与您的应用程序一起部署。请按照以下说明操作，确保您的 Mastra 集成正确部署。

:::警告
如果您要部署到云Provider，请勿使用[LibSQLStore](/integrations/databases/libsql) with a local `file:`或内存数据库。本地数据库需要文件系统访问权限，并且与无服务器平台不兼容。将 LibSQLStore 指向远程数据库，例如 Turso。
:::

集成指南：

* [使用 Next.js](/integrations/frameworks/next-js)
* [与阿斯特罗](/integrations/frameworks/astro)

## 在 Vercel 上使用 Next.js {/* #with-nextjs-on-vercel */}

如果您已将 Mastra 与 Next.js 集成并计划部署到 Vercel，请确保您的`next.config.ts` sets `serverExternalPackages: ["@mastra/*"]`. The [Next.js guide](/integrations/frameworks/next-js) adds it during setup. If your config doesn't have it, add it:

```typescript {4} title="next.config.ts"
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  serverExternalPackages: ['@mastra/*'],
}

export default nextConfig
```

## 与 Vercel 上的 Astro 一起 {/* #with-astro-on-vercel */}

如果您已将 Mastra 与 Astro 集成[by following our guide](/integrations/frameworks/astro) and plan to deploy to Vercel, add the Vercel adapter and server output to your `astro.config.mjs`:

```javascript {2,5-6} title="astro.config.mjs"
import { defineConfig } from 'astro/config'
import vercel from '@astrojs/vercel'

export default defineConfig({
  adapter: vercel(),
  output: 'server',
})
```

## 与 Netlify 上的 Astro 一起 {/* #with-astro-on-netlify */}

如果您已将 Mastra 与 Astro 集成[by following our guide](/integrations/frameworks/astro) and plan to deploy to Netlify, add the Netlify adapter and server output to your `astro.config.mjs`:

```javascript {2,5-6} title="astro.config.mjs"
import { defineConfig } from 'astro/config'
import netlify from '@astrojs/netlify'

export default defineConfig({
  adapter: netlify(),
  output: 'server',
})
```
