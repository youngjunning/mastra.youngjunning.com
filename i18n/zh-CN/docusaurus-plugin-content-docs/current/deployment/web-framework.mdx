# Web 框架

将 Mastra 集成到 Web 框架后，可按该框架的标准流程将 Mastra 和应用一起部署。请按下文配置，确保集成后的 Mastra 正常部署。

:::warning
部署到云服务时，请勿将 [LibSQLStore](/integrations/databases/libsql) 与本地 `file:` 数据库或内存数据库搭配使用。本地数据库需要访问文件系统，与无服务器平台不兼容。请将 LibSQLStore 指向 Turso 等远程数据库。
:::

集成指南：

- [集成 Next.js](/integrations/frameworks/next-js)
- [集成 Astro](/integrations/frameworks/astro)

## 将 Next.js 部署到 Vercel {/* #with-nextjs-on-vercel */}

如果已将 Mastra 集成到 Next.js，并计划部署到 Vercel，请确认 `next.config.ts` 中已设置 `serverExternalPackages: ["@mastra/*"]`。[Next.js 指南](/integrations/frameworks/next-js)会在配置过程中加入这一项。如果尚未设置，请添加：

```typescript {4} title="next.config.ts"
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  serverExternalPackages: ['@mastra/*'],
}

export default nextConfig
```

## 将 Astro 部署到 Vercel {/* #with-astro-on-vercel */}

如果已按[集成指南](/integrations/frameworks/astro)将 Mastra 集成到 Astro，并计划部署到 Vercel，请在 `astro.config.mjs` 中添加 Vercel 适配器并设置服务器输出：

```javascript {2,5-6} title="astro.config.mjs"
import { defineConfig } from 'astro/config'
import vercel from '@astrojs/vercel'

export default defineConfig({
  adapter: vercel(),
  output: 'server',
})
```

## 将 Astro 部署到 Netlify {/* #with-astro-on-netlify */}

如果已按[集成指南](/integrations/frameworks/astro)将 Mastra 集成到 Astro，并计划部署到 Netlify，请在 `astro.config.mjs` 中添加 Netlify 适配器并设置服务器输出：

```javascript {2,5-6} title="astro.config.mjs"
import { defineConfig } from 'astro/config'
import netlify from '@astrojs/netlify'

export default defineConfig({
  adapter: netlify(),
  output: 'server',
})
```
