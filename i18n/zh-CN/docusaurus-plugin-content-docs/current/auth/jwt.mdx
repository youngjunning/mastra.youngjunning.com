# JSON 网络令牌

这`MastraJwtAuth`类使用 JSON Web 令牌 (JWT) 为 Mastra 提供轻量级身份验证机制。它根据共享密钥验证传入请求，并使用以下命令与 Mastra 服务器集成`auth`选项。要验证身份Provider签名的令牌，请使用`jwksUri`和`issuer`中描述的选项[参考](/reference/auth/jwt).

## 安装 {/* #installation */}

在您可以使用之前`MastraJwtAuth` class you have to install the `@mastra/auth` package.

```bash npm2yarn
npm install @mastra/auth@latest
```

## 创建 JWT {/* #creating-a-jwt */}

要验证对 Mastra 服务器的请求，您需要使用您的签名的有效 JSON Web 令牌 (JWT)`MASTRA_JWT_SECRET`.

生成最简单的方法是使用[jwt.io](https://www.jwt.io/):

1. 选择**JWT Encoder**.
2. 向下滚动到**Sign JWT: Secret** section.
3. 输入您的秘密（例如：`supersecretdevkeythatishs256safe!`).
4. 点击**Generate example** to create a valid JWT.
5. 复制生成的token并将其设置为`MASTRA_JWT_TOKEN` in your `.env` file.

## 使用示例 {/* #usage-example */}

获取生成的 JWT 并使用它进行配置`MastraJwtAuth` in your Mastra server:

```typescript {2,6-8} title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraJwtAuth } from '@mastra/auth'

export const mastra = new Mastra({
  server: {
    auth: new MastraJwtAuth({
      secret: process.env.MASTRA_JWT_SECRET,
    }),
  },
})
```

访问[MastraJwtAuth](/reference/auth/jwt) for all available configuration options.

里面[Studio](/docs/studio/overview), go to **Settings** and under **Headers** select the **"Add Header"** button. Enter `Authorization` as the header name and `Bearer <your-jwt>` as the value.

## 配置`MastraClient` {/* #configuring-mastraclient */}

什么时候`auth` is enabled, requests to protected routes made with `MastraClient` must include a valid JWT in the `Authorization` header:

```typescript {6} title="lib/mastra/mastra-client.ts"
import { MastraClient } from '@mastra/client-js'

export const mastraClient = new MastraClient({
  baseUrl: 'https://<mastra-api-url>',
  headers: {
    Authorization: `Bearer ${process.env.MASTRA_JWT_TOKEN}`,
  },
})
```

访问[Mastra Client SDK](/docs/server/mastra-client) for more configuration options.

### 发出经过身份验证的请求 {/* #making-authenticated-requests */}

一次`MastraClient` is configured, you can send authenticated requests from your frontend application, or use `curl` for quick local testing:

<Tabs>
  <TabItem value="react" label="React">
    ```tsx title="src/components/test-agent.tsx"
    import { mastraClient } from '../../lib/mastra-client'

    export const TestAgent = () => {
      async function handleClick() {
        const agent = mastraClient.getAgent('weatherAgent')

        const response = await agent.generate('Weather in London')

        console.log(response)
      }

      return <button onClick={handleClick}>Test Agent</button>
    }
    ```
  </TabItem>

  <TabItem value="curl" label="cURL">
    ```bash
    curl -X POST http://localhost:4111/api/agents/weatherAgent/generate \
      -H "Content-Type: application/json" \
      -H "Authorization: Bearer <your-jwt>" \
      -d '{
        "messages": "Weather in London"
      }'
    ```
  </TabItem>
</Tabs>
