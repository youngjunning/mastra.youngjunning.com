# JSON Web Token

`MastraJwtAuth` 类采用 JSON Web Token（JWT）为 Mastra 提供轻量级身份验证。它用共享密钥验证传入请求，通过 `auth` 选项接入 Mastra 服务器。要验证由身份提供方签名的令牌，请使用[参考文档](/reference/auth/jwt)中介绍的 `jwksUri` 和 `issuer` 选项。

## 安装 {/* #installation */}

使用 `MastraJwtAuth` 类前，请先安装 `@mastra/auth` 包。

```bash npm2yarn
npm install @mastra/auth@latest
```

## 生成 JWT {/* #creating-a-jwt */}

要向 Mastra 服务器发送需要验证身份的请求，须提供用 `MASTRA_JWT_SECRET` 签名的有效 JSON Web Token（JWT）。

最简单的生成方式是使用 [jwt.io](https://www.jwt.io/)：

1. 选择 **JWT Encoder**。
1. 向下滚动至 **Sign JWT: Secret** 区域。
1. 输入密钥，例如 `supersecretdevkeythatishs256safe!`。
1. 点击 **Generate example**，生成有效的 JWT。
1. 复制生成的令牌，在 `.env` 文件中将其设为 `MASTRA_JWT_TOKEN`。

## 使用示例 {/* #usage-example */}

生成 JWT 后，按以下示例在 Mastra 服务器中配置 `MastraJwtAuth`：

```typescript {2,6-8} title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraJwtAuth } from '@mastra/auth'

export const mastra = new Mastra({
  server: {
    auth: new MastraJwtAuth({
      secret: process.env.MASTRA_JWT_SECRET,
    }),
  },
})
```

所有可用的配置选项见 [MastraJwtAuth](/reference/auth/jwt)。

在 [Studio](/docs/studio/overview) 中打开 **Settings**，在 **Headers** 下点击 **"Add Header"**。将请求头名称设为 `Authorization`，值设为 `Bearer <your-jwt>`。

## 配置 `MastraClient` {/* #configuring-mastraclient */}

启用 `auth` 后，通过 `MastraClient` 向受保护路由发送的请求，必须在 `Authorization` 请求头中包含有效的 JWT：

```typescript {6} title="lib/mastra/mastra-client.ts"
import { MastraClient } from '@mastra/client-js'

export const mastraClient = new MastraClient({
  baseUrl: 'https://<mastra-api-url>',
  headers: {
    Authorization: `Bearer ${process.env.MASTRA_JWT_TOKEN}`,
  },
})
```

更多配置选项见 [Mastra Client SDK](/docs/server/mastra-client)。

### 发送经过身份验证的请求 {/* #making-authenticated-requests */}

配置好 `MastraClient` 后，可以从前端应用发送经过身份验证的请求，也可以用 `curl` 在本地快速测试：

<Tabs>
  <TabItem value="react" label="React">
    ```tsx title="src/components/test-agent.tsx"
    import { mastraClient } from '../../lib/mastra-client'

    export const TestAgent = () => {
      async function handleClick() {
        const agent = mastraClient.getAgent('weatherAgent')

        const response = await agent.generate('Weather in London')

        console.log(response)
      }

      return <button onClick={handleClick}>Test Agent</button>
    }
    ```
  </TabItem>

  <TabItem value="curl" label="cURL">
    ```bash
    curl -X POST http://localhost:4111/api/agents/weatherAgent/generate \
      -H "Content-Type: application/json" \
      -H "Authorization: Bearer <your-jwt>" \
      -d '{
        "messages": "Weather in London"
      }'
    ```
  </TabItem>
