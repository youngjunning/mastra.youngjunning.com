# 简单认证

这`SimpleAuth`类使用基本令牌到用户映射提供基于令牌的身份验证。它包含在`@mastra/core/server`对于开发、测试和基本 API 密钥身份验证场景非常有用。

## 使用案例 {/* #use-cases */}

* 本地开发和测试
* 简单的API密钥认证
* 集成完整身份Provider之前进行原型设计
* 具有静态令牌的内部服务

## 安装 {/* #installation */}

`SimpleAuth`包含在`@mastra/core` and requires no additional packages.

```typescript
import { SimpleAuth } from '@mastra/core/server'
```

## 使用示例 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { SimpleAuth } from '@mastra/core/server'

// Define your user type
type User = {
  id: string
  name: string
  role: 'admin' | 'user'
}

export const mastra = new Mastra({
  server: {
    auth: new SimpleAuth<User>({
      tokens: {
        'sk-admin-token-123': {
          id: 'user-1',
          name: 'Admin User',
          role: 'admin',
        },
        'sk-user-token-456': {
          id: 'user-2',
          name: 'Regular User',
          role: 'user',
        },
      },
    }),
  },
})
```

## 配置选项 {/* #configuration-options */}

|选项 |类型 |必填|描述 |
| - | - | - | - |
|`tokens` | `Record<string, TUser>` | Yes | Map of tokens to user objects |
| `headers` | `string \| string[]` | No | Additional headers to check for tokens |
| `name` | `string` | No | Provider name for logging |
| `authorizeUser` | `(user, request) => boolean \| Promise<boolean>`|没有 |自定义授权功能 |
|`protected` | `(RegExp \| string)[]`|没有 |需要身份验证的路径 |
|`public` | `(RegExp \| string)[]`|没有 |绕过身份验证的路径 |

### 默认标头 {/* #default-headers */}

SimpleAuth 默认检查这些标头：

* `Authorization`（有或没有`Bearer` prefix)
* `X-Playground-Access`

使用添加自定义标头`headers` option:

```typescript
new SimpleAuth({
  tokens: {/* ... */},
  headers: ['X-API-Key', 'X-Custom-Auth'],
})
```

## 发出经过身份验证的请求 {/* #making-authenticated-requests */}

将您的令牌包含在`Authorization` header:

```bash
curl -X POST http://localhost:4111/api/agents/myAgent/generate \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-admin-token-123" \
  -d '{"messages": "Hello"}'
```

或者没有`Bearer` prefix:

```bash
curl -X POST http://localhost:4111/api/agents/myAgent/generate \
  -H "Content-Type: application/json" \
  -H "Authorization: sk-admin-token-123" \
  -d '{"messages": "Hello"}'
```

## 定制授权 {/* #custom-authorization */}

添加基于角色或自定义的授权逻辑：

```typescript
import { SimpleAuth, getWebRequest } from '@mastra/core/server'

new SimpleAuth<User>({
  tokens: {
    'sk-admin-token': { id: '1', name: 'Admin', role: 'admin' },
    'sk-user-token': { id: '2', name: 'User', role: 'user' },
  },
  authorizeUser: (user, request) => {
    const webRequest = getWebRequest(request)
    const path = webRequest ? new URL(webRequest.url).pathname : ''

    // Only admins can access /admin routes
    if (path.includes('/admin')) {
      return user.role === 'admin'
    }
    return true
  },
})
```

## 环境变量 {/* #environment-variables */}

对于类似生产的设置，从环境变量加载令牌：

```typescript
const tokens: Record<string, User> = {}

// Load from environment
const adminToken = process.env.ADMIN_API_KEY
if (adminToken) {
  tokens[adminToken] = { id: 'admin', name: 'Admin', role: 'admin' }
}

const userToken = process.env.USER_API_KEY
if (userToken) {
  tokens[userToken] = { id: 'user', name: 'User', role: 'user' }
}

export const mastra = new Mastra({
  server: {
    auth: new SimpleAuth({ tokens }),
  },
})
```

## 和`MastraClient` {/* #with-mastraclient */}

使用您的令牌配置客户端：

```typescript
import { MastraClient } from '@mastra/client-js'

const client = new MastraClient({
  baseUrl: 'http://localhost:4111',
  headers: {
    Authorization: 'Bearer sk-admin-token-123',
  },
})

const agent = client.getAgent('myAgent')
const response = await agent.generate('Hello')
```

## 局限性 {/* #limitations */}

SimpleAuth 的设计是为了简单性，而不是生产安全性：

* 令牌存储在内存中
* 没有令牌过期或刷新
* 没有加密验证
* 所有令牌在启动时必须已知

对于生产应用程序，请考虑使用[JWT](/docs/auth/jwt), [Clerk](/integrations/auth/clerk), [Auth0](/integrations/auth/auth0), or another identity provider.
