# 简单认证

`SimpleAuth` 类通过简单的令牌到用户映射进行身份验证。它包含在 `@mastra/core/server` 中，适用于开发、测试和基础的 API 密钥认证。

## 适用场景 {/* #use-cases */}

- 本地开发和测试
- 基础的 API 密钥认证
- 接入完整的身份提供商之前搭建原型
- 使用静态令牌的内部服务

## 安装 {/* #installation */}

`SimpleAuth` 随 `@mastra/core` 提供，无需安装其他包。

```typescript
import { SimpleAuth } from '@mastra/core/server'
```

## 使用示例 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { SimpleAuth } from '@mastra/core/server'

// Define your user type
type User = {
  id: string
  name: string
  role: 'admin' | 'user'
}

export const mastra = new Mastra({
  server: {
    auth: new SimpleAuth<User>({
      tokens: {
        'sk-admin-token-123': {
          id: 'user-1',
          name: 'Admin User',
          role: 'admin',
        },
        'sk-user-token-456': {
          id: 'user-2',
          name: 'Regular User',
          role: 'user',
        },
      },
    }),
  },
})
```

## 配置选项 {/* #configuration-options */}

| 选项 | 类型 | 必填 | 说明 |
| - | - | - | - |
| `tokens` | `Record<string, TUser>` | 是 | 从令牌到用户对象的映射。 |
| `headers` | `string \| string[]` | 否 | 额外用于查找令牌的请求头。 |
| `name` | `string` | 否 | 写入日志的认证提供商名称。 |
| `authorizeUser` | `(user, request) => boolean \| Promise<boolean>` | 否 | 自定义授权函数。 |
| `protected` | `(RegExp \| string)[]` | 否 | 需要身份验证的路径。 |
| `public` | `(RegExp \| string)[]` | 否 | 无需身份验证的路径。 |

### 默认检查的请求头 {/* #default-headers */}

SimpleAuth 默认检查以下请求头。

- `Authorization`（可带 `Bearer` 前缀，也可省略）
- `X-Playground-Access`

通过 `headers` 选项添加自定义请求头。

```typescript
new SimpleAuth({
  tokens: {/* ... */},
  headers: ['X-API-Key', 'X-Custom-Auth'],
})
```

## 发送带身份凭据的请求 {/* #making-authenticated-requests */}

在 `Authorization` 请求头中传入令牌。

```bash
curl -X POST http://localhost:4111/api/agents/myAgent/generate \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-admin-token-123" \
  -d '{"messages": "Hello"}'
```

也可以省略 `Bearer` 前缀。

```bash
curl -X POST http://localhost:4111/api/agents/myAgent/generate \
  -H "Content-Type: application/json" \
  -H "Authorization: sk-admin-token-123" \
  -d '{"messages": "Hello"}'
```

## 自定义授权 {/* #custom-authorization */}

可以添加基于角色的授权逻辑，也可以自定义授权逻辑。

```typescript
import { SimpleAuth, getWebRequest } from '@mastra/core/server'

new SimpleAuth<User>({
  tokens: {
    'sk-admin-token': { id: '1', name: 'Admin', role: 'admin' },
    'sk-user-token': { id: '2', name: 'User', role: 'user' },
  },
  authorizeUser: (user, request) => {
    const webRequest = getWebRequest(request)
    const path = webRequest ? new URL(webRequest.url).pathname : ''

    // Only admins can access /admin routes
    if (path.includes('/admin')) {
      return user.role === 'admin'
    }
    return true
  },
})
```

## 环境变量 {/* #environment-variables */}

如果配置需要接近生产环境，可以从环境变量加载令牌。

```typescript
const tokens: Record<string, User> = {}

// Load from environment
const adminToken = process.env.ADMIN_API_KEY
if (adminToken) {
  tokens[adminToken] = { id: 'admin', name: 'Admin', role: 'admin' }
}

const userToken = process.env.USER_API_KEY
if (userToken) {
  tokens[userToken] = { id: 'user', name: 'User', role: 'user' }
}

export const mastra = new Mastra({
  server: {
    auth: new SimpleAuth({ tokens }),
  },
})
```

## 搭配 `MastraClient` 使用 {/* #with-mastraclient */}

在客户端配置中提供令牌。

```typescript
import { MastraClient } from '@mastra/client-js'

const client = new MastraClient({
  baseUrl: 'http://localhost:4111',
  headers: {
    Authorization: 'Bearer sk-admin-token-123',
  },
})

const agent = client.getAgent('myAgent')
const response = await agent.generate('Hello')
```

## 限制 {/* #limitations */}

SimpleAuth 以易用为设计目标，无法满足生产环境的安全需求。

- 令牌存储在内存中
- 不支持令牌过期或刷新
- 不进行密码学验证
- 必须在启动时提供所有令牌

对于生产应用，可以考虑使用 [JWT](/docs/auth/jwt)、[Clerk](/integrations/auth/clerk)、[Auth0](/integrations/auth/auth0) 或其他身份提供商。
