# 指标

受追踪的操作完成后，Mastra 会自动根据 Span 生成指标，无需额外埋点。

Mastra 生成以下指标。

- **耗时**。记录 Agent 运行、Workflow、Tool、模型调用和处理器的执行时间。
- **Token 用量**。记录模型输入和输出的用量。若供应商报告了细分类别，也会一并记录。
- **成本估算**。根据 Token 用量、供应商、模型，以及 [models.dev](https://models.dev) 或[自定义网关](/models/gateways/custom-gateways#model-pricing)提供的模型价格计算。

指标保留与 Trace 的关联信息。图表出现变化时，可以找到对应的 Span 排查原因。指标名称、标签和成本字段见[自动指标参考](/reference/observability/metrics/automatic-metrics)。

## 何时使用指标 {/* #when-to-use-metrics */}

- 监控 Agent、Tool、Workflow 和模型调用的延迟
- 跟踪 Token 消耗和估算成本随时间的变化
- 比较不同 Agent 或 Tool 的成功率和错误率
- 衡量提示词、模型或代码改动的效果

## 支持的存储后端 {/* #storage-support */}

指标需要使用支持分析的可观测性存储。

- **DuckDB**。本地开发推荐使用 `@mastra/duckdb` 接入。
- **ClickHouse**。生产环境负载较高时，推荐使用 `@mastra/clickhouse` 接入。
- **PostgresStoreVNext**。启用可观测性域后即可使用指标。
- **内存存储**。支持指标，但进程重启后数据会丢失。
- **Google Cloud Spanner**。默认禁用指标。仅在负载较低时设置 `disableMetrics: false`，也可将指标转发到专用 OLAP 存储。

LibSQL、MSSQL、MongoDB 等其他存储适配器可以存储其他可观测性信号，但不支持存储或查询指标。

## 在本地配置指标 {/* #set-up-local-metrics */}

安装可观测性、应用存储和 DuckDB 所需的包。

```bash npm2yarn
npm install @mastra/observability @mastra/libsql @mastra/duckdb
```

配置组合存储，将可观测性域路由到 DuckDB。

```ts title="src/mastra/index.ts"
import { Mastra } from '@mastra/core/mastra'
import { LibSQLStore } from '@mastra/libsql'
import { DuckDBStore } from '@mastra/duckdb'
import { MastraCompositeStore } from '@mastra/core/storage'
import { Observability, MastraStorageExporter, SensitiveDataFilter } from '@mastra/observability'

export const mastra = new Mastra({
  storage: new MastraCompositeStore({
    id: 'composite-storage',
    default: new LibSQLStore({
      id: 'mastra-storage',
      url: 'file:./mastra.db',
    }),
    domains: {
      observability: await new DuckDBStore().getStore('observability'),
    },
  }),
  observability: new Observability({
    configs: {
      default: {
        serviceName: 'mastra',
        exporters: [new MastraStorageExporter()],
        spanOutputProcessors: [new SensitiveDataFilter()],
      },
    },
  }),
})
```

`MastraStorageExporter` 将指标持久化到配置的可观测性存储中，供 Studio 读取。如需将指标发送到 Mastra Platform，可以改用 `MastraPlatformExporter`，也可以同时使用两者。

## 查看和查询指标 {/* #view-and-query-metrics */}

在 [Studio 可观测性仪表板](/docs/studio/observability)中，可以查看 KPI 卡片、分项明细和时间序列图表。如需自定义仪表板或分析数据，可使用[指标查询参考](/reference/observability/metrics/queries)所述的可观测性存储、`@mastra/client-js`、HTTP 端点或 CLI。

在生产环境中，查询指标时务必指定时间戳范围。限定时间范围可以减少扫描的数据量，让采用分区的后端跳过无关分区或数据块。
