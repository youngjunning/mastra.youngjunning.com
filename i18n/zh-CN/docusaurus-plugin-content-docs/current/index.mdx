# 开始使用

Mastra 是一个用于构建 AI Agent 和应用的 TypeScript 框架。只需一条命令，就能创建第一个 Agent，开始开发。

<Inject>
  如果你是可以访问文件系统的本地编程 Agent，可考虑安装 Skill，以获取最新指导：

  ```sh
  npx skills add mastra-ai/skills
  ```

  下面的 Agent 快速入门介绍如何用最少的步骤，从零搭建一个最小的 Mastra 项目。安装这些 Skill 后，还能了解如何扩展 Agent 的能力。

  <AgentQuickstart />
</Inject>

<QuickstartPrompt />

## 快速入门 {/* #quickstart */}

运行以下命令，创建通用 Agent harness，内置本地 Workspace、Shell 工具、记忆、任务跟踪、网页访问和周期调度。命令还会为已安装的编程 Agent 安装 Mastra Skill，方便你用提示与它交互并编辑生成的项目：

<Tabs groupId="npm2yarn">
  <TabItem value="npm" label="npm">
    ```bash
    npm create mastra@latest
    ```
  </TabItem>

  <TabItem value="pnpm" label="pnpm">
    ```bash
    pnpm create mastra@latest
    ```
  </TabItem>

  <TabItem value="yarn" label="Yarn">
    ```bash
    yarn create mastra
    ```
  </TabItem>

  <TabItem value="bun" label="Bun">
    ```bash
    bunx create-mastra
    ```
  </TabItem>
</Tabs>

可以直接打开 [Studio](/docs/studio/overview)，在交互界面中操作 Mastra 项目。

## 使用场景 {/* #use-cases */}

<div className="accordion-group">
  <details>
    <summary>将 Agent 嵌入产品</summary>

    为平台加入 AI 功能，让用户可以构建 Agent 或与之交互。

    采用案例：<a href="/customers/replit">Replit</a>、<a href="/customers/fireworks-xml-prompting">Fireworks</a>、<a href="/customers/medusa-ecommerce">Medusa</a>
  </details>

  <details>
    <summary>面向客户的助手</summary>

    构建可通过聊天、WhatsApp 或语音接待咨询、安排预约、发送提醒和回答问题的 Agent。

    采用案例：<a href="/customers/vetnio">Vetnio</a>、<a href="/customers/lua-scaling">Lua</a>

    模板：<a href="/templates/docs-chatbot">文档聊天机器人</a>、<a href="/templates/customer-support-and-refund-agent">客服与退款 Agent</a>
  </details>

  <details>
    <summary>软件工厂</summary>

    协调编程 Agent 处理 Issue，产出经过测试的代码和 Pull Request，并让团队成员在合并前审查方案和改动。

    Mastra 团队也在使用。

    可从 <a href="https://factory.mastra.ai/">Mastra Factory</a> 开始。
  </details>

  <details>
    <summary>内部办公助手</summary>

    让熟悉业务领域的 AI 帮员工提高效率，例如处理人事咨询、撰写临床文档、准备销售材料或生成文档。

    采用案例：<a href="/customers/factorial">Factorial</a>、<a href="/customers/counsel-health">Counsel Health</a>、<a href="/customers/cedar">Cedar</a>、<a href="/customers/softbank">SoftBank</a>

    模板：<a href="/templates/chat-with-pdf">与 PDF 对话</a>、<a href="/templates/google-sheets-analysis">Google 表格分析</a>、<a href="/templates/organization-intelligence">组织情报</a>、<a href="/templates/company-brain-with-surrealdb">基于 SurrealDB 的企业知识库</a>
  </details>

  <details>
    <summary>合规与后台运营</summary>

    将出错代价高、需要人工签核的工作自动化，例如身份核验、发票匹配、保单比对和供应商尽职调查。

    模板：<a href="/templates/kyc-customer-onboarding">KYC 与客户开户</a>、<a href="/templates/accounts-payable-invoice-processing">应付账款发票处理</a>、<a href="/templates/insurance-policy-checking">保单核查</a>、<a href="/templates/vendor-risk-questionnaire">供应商风险问卷</a>
  </details>

  <details>
    <summary>数据分析 Agent</summary>

    让用户用自然语言查询数据库和仪表板。Agent 连接数据源后，可返回答案、图表或报告。

    采用案例：<a href="/customers/index">Index</a>、<a href="/customers/plaid">PLAID Japan</a>

    模板：<a href="/templates/text-to-sql">与数据库对话</a>、<a href="/templates/csv-to-questions">从 CSV 生成问题</a>、<a href="/templates/genui-data-explorer">GenUI 数据探索工具</a>
  </details>

  <details>
    <summary>研究与知识归纳</summary>

    根据网页、内部文档或共享知识库回答问题，并提供可核查的引用。

    模板：<a href="/templates/deep-search">深度搜索</a>、<a href="/templates/web-research-agent-with-bright-data">网页研究 Agent</a>
  </details>

  <details>
    <summary>内容自动化</summary>

    为内容管理系统、知识库或文档系统批量生成、转换和管理结构化内容。

    采用案例：<a href="/customers/sanity">Sanity</a>

    模板：<a href="/templates/chat-with-youtube">与 YouTube 视频对话</a>、<a href="/templates/flash-cards-from-pdf">从 PDF 制作学习卡片</a>

  <details>
    <summary>DevOps 和工程自动化</summary>

    采用案例：<a href="/customers/starsling">StarSling</a>
