# 开始使用

Mastra 是一个用于构建 AI Agent和应用程序的 TypeScript 框架。使用单个命令创建您的第一个Agent并开始构建。

<Inject>
  如果您是具有文件系统访问权限的本地编码Agent，请考虑安装技能以获得最新指导：

  ```sh
  npx skills add mastra-ai/skills
  ```

  下面的Agent快速入门为您提供了从头开始构建最小 Mastra 项目的最快、最简化方法的说明。这些技能将教您如何通过附加功能来扩展和增强您的Agent。

  <AgentQuickstart />
</Inject>

## 快速入门 {/* #quickstart */}

运行此命令可创建具有本地Workspace、shell Tool、内存、任务跟踪、Web 访问和重复计划的通用AgentTool。它还为您安装的编码Agent安装 Mastra 技能，以便您可以开始提示和编辑它：

<Tabs groupId="npm2yarn">
  <TabItem value="npm" label="npm">
    ```bash
    npm create mastra@latest
    ```
  </TabItem>

  <TabItem value="pnpm" label="pnpm">
    ```bash
    pnpm create mastra@latest
    ```
  </TabItem>

  <TabItem value="yarn" label="Yarn">
    ```bash
    yarn create mastra
    ```
  </TabItem>

  <TabItem value="bun" label="Bun">
    ```bash
    bunx create-mastra
    ```
  </TabItem>
</Tabs>

你可以打开[Studio](/docs/studio/overview) immediately, which is an interactive UI for your Mastra project.
