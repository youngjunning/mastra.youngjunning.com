# 浏览器

浏览器支持使Agent可以导航网站、与页面元素交互、填写表单和提取数据。 Mastra 提供两种浏览器Provider：

* **SDKProvider**包装浏览器自动化库并直接为Agent提供浏览器Tool。
* **CLI Provider**启动Agent通过命令行Tool控制的浏览器。

Mastra 包括 3 个 SDK 提供程序和 1 个 CLI 提供程序：

* [**Agent浏览器**](/integrations/browsers/agent-browser)：基于 Playwright 构建的 SDK 提供程序，可通过辅助功能信息查找页面元素。将其用于一般网络自动化和抓取。
* [**舞台工作人员**](/integrations/browsers/stagehand)：基于 Browserbase 的 Stagehand 库构建的 SDK 提供程序。它使用人工智能来查找页面元素。将其用于复杂的交互，其中用自然语言描述元素比固定选择器效果更好。
* [**Firecrawl浏览器**](/integrations/browsers/firecrawl)：在托管 Firecrawl 浏览器沙盒会话中运行 AgentBrowser Tool的 SDK 提供程序。使用它可以避免在您自己的基础设施上运行浏览器。
* [**浏览器查看器**](/integrations/browsers/browser-viewer)：CLI Provider，启动 Chrome 并将其 Chrome 开发Tool协议 (CDP) URL 传递给 CLI Tool，例如Agent浏览器、浏览器使用和浏览。将其用于通过 shell 命令控制浏览器的WorkspaceAgent。

## 何时使用浏览器 {/* #when-to-use-a-browser */}

在需要时为您的Agent提供浏览器：

* 浏览网站并与页面元素交互
* 填写并提交表格
* 从网页中提取结构化数据
* 自动执行需要几个步骤的 Web 任务
* 使用仅在真实浏览器中运行的页面，例如使用 JavaScript 呈现内容或需要登录的页面

## 它是如何运作的 {/* #how-it-works */}

当您将浏览器分配给Agent时，Mastra 会将Provider的Tool包含在Agent的Tool集中。Agent使用这些Tool来控制浏览器。它可以打开 URL 并选择元素。它还可以输入文本并阅读页面内容。

每个Provider都提供了一套不同的针对其方法进行优化的Tool。

## 快速入门 {/* #quickstart */}

安装您选择的提供程序，在本示例中您将使用 AgentBrowser 提供程序。

```bash npm2yarn
npm install @mastra/agent-browser
```

创建一个新的浏览器实例：

```typescript title="src/mastra/browsers.ts"
import { AgentBrowser } from '@mastra/agent-browser'

export const browser = new AgentBrowser({
  headless: false,
})
```

将浏览器分配给Agent：

```typescript title="src/mastra/agents/web-agent.ts"
import { Agent } from '@mastra/core/agent'
import { browser } from '../browsers'

export const webAgent = new Agent({
  id: 'web-agent',
  name: 'Web Agent',
  description: 'A web automation assistant that can navigate websites and complete tasks.',
  model: '__GATEWAY_OPENAI_MODEL__',
  browser,
  instructions:
    'You are a web automation assistant. Use browser tools to navigate websites and complete tasks.',
})
```

Agent自动从Provider处接收所有浏览器Tool。

## 云Provider {/* #cloud-providers */}

所有 SDK Provider都支持连接到云浏览器服务，而不是启动本地浏览器。

### Firecrawl 浏览器Sandbox（FirecrawlBrowser 原生） {/* #firecrawl-browser-sandbox-firecrawlbrowser-native */}

FirecrawlBrowser 通过 Firecrawl API 提供托管会话：

```typescript
import { FirecrawlBrowser } from '@mastra/browser-firecrawl'

const browser = new FirecrawlBrowser({
  apiKey: process.env.FIRECRAWL_API_KEY,
})
```

### Browserbase（舞台工作人员原生） {/* #browserbase-stagehand-native */}

Stagehand 具有原生 Browserbase 集成：

```typescript
import { StagehandBrowser } from '@mastra/stagehand'

const browser = new StagehandBrowser({
  env: 'BROWSERBASE',
  apiKey: process.env.BROWSERBASE_API_KEY,
  projectId: process.env.BROWSERBASE_PROJECT_ID,
})
```

### 浏览器使用云（AgentBrowser CDP） {/* #browser-use-cloud-agentbrowser-cdp */}

将 AgentBrowser 连接到[Browser Use Cloud browser](https://github.com/browser-use/browser-use/blob/main/skills/cloud/references/browser-api.md) using your Browser Use API key:

```typescript
import { AgentBrowser } from '@mastra/agent-browser'

const browser = new AgentBrowser({
  cdpUrl: `wss://connect.browser-use.com?apiKey=${process.env.BROWSER_USE_API_KEY}`,
})
```

### CDP URL（任何Provider） {/* #cdp-url-any-provider */}

连接到公开 Chrome DevTools 协议 (CDP) 端点的任何浏览器：

```typescript
import { AgentBrowser } from '@mastra/agent-browser'

const browser = new AgentBrowser({
  cdpUrl: process.env.BROWSER_CDP_URL,
  headless: true,
})
```

这适用于任何[CDP-compatible](https://chromedevtools.github.io/devtools-protocol/) browser service.

## 截屏视频 {/* #screencast */}

浏览器Provider将浏览器的实时视频源流式传输到 Mastra Studio UI。这使您可以实时观看Agent与页面的交互。

截屏视频需要 WebSocket 支持。在您的项目中安装这些包：

```bash npm2yarn
npm install ws @hono/node-ws
```

：：：笔记

默认情况下不包含这些包，因为它们与 Cloudflare Workers 等无服务器环境不兼容。如果未安装，截屏视频将被禁用，但所有其他浏览器功能都可以正常工作。

:::

默认情况下启用截屏并可以配置：

```typescript
const browser = new AgentBrowser({
  screencast: {
    format: 'jpeg',
    quality: 80,
    maxWidth: 1280,
    maxHeight: 720,
  },
})
```

## 记录浏览器会话 {/* #record-browser-sessions */}

AgentBrowser 和 StagehandBrowser 可以选择录制以供审阅、共享或调试浏览器运行。配置`outputDir` to add the recording tools:

```typescript title="src/mastra/browsers.ts"
import { join } from 'node:path'
import { AgentBrowser } from '@mastra/agent-browser'

export const browser = new AgentBrowser({
  recording: {
    outputDir: join(process.cwd(), 'browser-recordings'),
  },
})
```

StagehandBrowser 接受相同的`recording` option. The agent uses `browser_record` to start, check, and stop a recording, and `browser_record_caption` to label major actions. Stopping saves the video and lets the agent return its path. A custom `outputPath` can be absolute or relative to the current working directory, and must resolve to a path inside `recording.outputDir`.

录制使用 Motion-JPEG AVI，不需要`ffmpeg`. The default maximum duration is 30 seconds, with a 120-second hard cap. The default maximum frame size is 1024 × 720, captions are limited to 80 characters, and only one recording can be active per process.
