# 浏览器

有了浏览器，Agent 就能浏览网站、操作页面元素、填写表单和提取数据。Mastra 提供两类浏览器 Provider：

- **SDK Provider** 封装浏览器自动化库，直接为 Agent 提供操作浏览器的 Tool。
- **CLI Provider** 启动浏览器，Agent 通过命令行工具控制它。

Mastra 内置三种 SDK Provider 和一种 CLI Provider：

- [**AgentBrowser**](/integrations/browsers/agent-browser)：基于 Playwright 的 SDK Provider，利用无障碍信息查找页面元素。适合常规网页自动化和数据抓取。
- [**Stagehand**](/integrations/browsers/stagehand)：基于 Browserbase 的 Stagehand 库，使用 AI 查找页面元素。对于用自然语言描述元素比固定选择器更有效的复杂交互，可以选择它。
- [**FirecrawlBrowser**](/integrations/browsers/firecrawl)：在托管的 Firecrawl Browser Sandbox 会话中运行 AgentBrowser Tool，无需在自己的基础设施上运行浏览器。
- [**BrowserViewer**](/integrations/browsers/browser-viewer)：启动 Chrome 的 CLI Provider，将 Chrome DevTools Protocol（CDP）URL 传给 agent-browser、browser-use、browse 等 CLI 工具。适合通过 Shell 命令控制浏览器的 Workspace Agent。

## 何时使用浏览器 {/* #when-to-use-a-browser */}

如果 Agent 需要完成以下任务，可以为它配置浏览器：

- 浏览网站并与页面元素交互
- 填写并提交表单
- 从网页中提取结构化数据
- 自动执行需要几个步骤的 Web 任务
- 使用只能在真实浏览器中正常工作的页面，例如依靠 JavaScript 渲染内容或要求登录的页面

## 它是如何运作的 {/* #how-it-works */}

为 Agent 配置浏览器后，Mastra 会把 Provider 的 Tool 加入 Agent 的工具集。Agent 可用这些 Tool 打开 URL、选择元素、输入文字及读取页面内容。

每个 Provider 都有一套适合自身控制方式的工具。

## 快速入门 {/* #quickstart */}

先安装所选的 Provider。本例使用 AgentBrowser。

```bash npm2yarn
npm install @mastra/agent-browser
```

创建一个新的浏览器实例：

```typescript title="src/mastra/browsers.ts"
import { AgentBrowser } from '@mastra/agent-browser'

export const browser = new AgentBrowser({
  headless: false,
})
```

将浏览器分配给Agent：

```typescript title="src/mastra/agents/web-agent.ts"
import { Agent } from '@mastra/core/agent'
import { browser } from '../browsers'

export const webAgent = new Agent({
  id: 'web-agent',
  name: 'Web Agent',
  description: 'A web automation assistant that can navigate websites and complete tasks.',
  model: '__GATEWAY_OPENAI_MODEL__',
  browser,
  instructions:
    'You are a web automation assistant. Use browser tools to navigate websites and complete tasks.',
})
```

Agent 会自动获得该 Provider 提供的所有浏览器 Tool。

## 云浏览器 Provider {/* #cloud-providers */}

所有 SDK Provider 都可连接云浏览器服务，无需启动本地浏览器。

### Firecrawl Browser Sandbox（FirecrawlBrowser 原生支持） {/* #firecrawl-browser-sandbox-firecrawlbrowser-native */}

FirecrawlBrowser 通过 Firecrawl API 提供托管会话：

```typescript
import { FirecrawlBrowser } from '@mastra/browser-firecrawl'

const browser = new FirecrawlBrowser({
  apiKey: process.env.FIRECRAWL_API_KEY,
})
```

### Browserbase（Stagehand 原生支持） {/* #browserbase-stagehand-native */}

Stagehand 具有原生 Browserbase 集成：

```typescript
import { StagehandBrowser } from '@mastra/stagehand'

const browser = new StagehandBrowser({
  env: 'BROWSERBASE',
  apiKey: process.env.BROWSERBASE_API_KEY,
  projectId: process.env.BROWSERBASE_PROJECT_ID,
})
```

### Browser Use Cloud（AgentBrowser CDP） {/* #browser-use-cloud-agentbrowser-cdp */}

使用 Browser Use API 密钥将 AgentBrowser 连接到 [Browser Use Cloud 浏览器](https://github.com/browser-use/browser-use/blob/main/skills/cloud/references/browser-api.md)：

```typescript
import { AgentBrowser } from '@mastra/agent-browser'

const browser = new AgentBrowser({
  cdpUrl: `wss://connect.browser-use.com?apiKey=${process.env.BROWSER_USE_API_KEY}`,
})
```

### CDP URL（任何Provider） {/* #cdp-url-any-provider */}

连接到公开 Chrome DevTools 协议 (CDP) 端点的任何浏览器：

```typescript
import { AgentBrowser } from '@mastra/agent-browser'

const browser = new AgentBrowser({
  cdpUrl: process.env.BROWSER_CDP_URL,
  headless: true,
})
```

这适用于所有[兼容 CDP](https://chromedevtools.github.io/devtools-protocol/) 的浏览器服务。

## 实时画面 {/* #screencast */}

浏览器 Provider 会将实时画面传到 Mastra Studio 界面，你可以实时看到 Agent 如何操作页面。

实时画面需要 WebSocket 支持。请在项目中安装这些包：

```bash npm2yarn
npm install ws @hono/node-ws
```

:::note

这些包与 Cloudflare Workers 等无服务器环境不兼容，因此默认不安装。未安装时无法查看实时画面，其他浏览器功能仍可正常使用。

:::

实时画面默认启用，也可按需配置：

```typescript
const browser = new AgentBrowser({
  screencast: {
    format: 'jpeg',
    quality: 80,
    maxWidth: 1280,
    maxHeight: 720,
  },
})
```

## 录制浏览器会话 {/* #record-browser-sessions */}

AgentBrowser 和 StagehandBrowser 可以启用录制，方便回看、分享或调试浏览器运行过程。配置 `outputDir` 即可添加录制工具：

```typescript title="src/mastra/browsers.ts"
import { join } from 'node:path'
import { AgentBrowser } from '@mastra/agent-browser'

export const browser = new AgentBrowser({
  recording: {
    outputDir: join(process.cwd(), 'browser-recordings'),
  },
})
```

StagehandBrowser 也接受相同的 `recording` 选项。Agent 用 `browser_record` 开始、查询或停止录制，并用 `browser_record_caption` 标注关键操作。停止时会保存视频，Agent 可以返回文件路径。自定义 `outputPath` 可以是绝对路径，也可以相对于当前工作目录，但解析后必须位于 `recording.outputDir` 内。

录制采用 Motion-JPEG AVI，无需 `ffmpeg`。默认最长 30 秒，硬上限为 120 秒。默认最大画面尺寸为 1024 × 720，字幕最多 80 个字符，每个进程同一时间只能进行一项录制。
