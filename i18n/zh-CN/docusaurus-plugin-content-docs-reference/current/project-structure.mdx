# 项目结构

使用 `create mastra` 命令创建的 Mastra 项目包含一组预设文件和文件夹，帮助你快速开始。

Mastra 是一个框架，但对文件的组织方式和存放位置基本不作规定。CLI 提供适合大多数项目的默认结构，你可以按自己的工作流程或团队约定调整，甚至把整个项目写在一个文件中。无论采用哪种结构，都应保持一致，让代码易于维护和查找。

## 默认项目结构 {/* #default-project-structure */}

使用 `create mastra` 命令创建的项目结构如下：

```bash
├── src/
│   └── mastra/
│       ├── agents/
│       │   └── agent.ts
│       ├── tools/
│       │   └── schedule-tools.ts
│       └── index.ts
├── .env.example
├── AGENTS.md
├── package.json
└── tsconfig.json
```

默认项目基于 [Agent Harness 模板](https://github.com/mastra-ai/template-agent-harness)。你可以复制并调整这些预设文件，快速创建自己的 Agent、Tool 和 Workflow 等。

### 文件夹 {/* #folders */}

Mastra 建议将您的代码组织到以下文件夹中：

| 文件夹 | 说明 |
| - | - |
| `src/mastra` | Mastra 相关代码和配置的入口。 |
| `src/mastra/agents` | 定义并配置 Agent 的行为、目标和 Tool。 |
| `src/mastra/workflows` | 定义编排 Agent 与 Tool 的多步骤 Workflow。 |
| `src/mastra/tools` | 创建可供 Agent 调用的可复用 Tool。 |
| `src/mastra/mcp` | 实现自定义 MCP server，与外部 Agent 共享 Tool。 |
| `src/mastra/scorers` | 定义用于持续评估 Agent 表现的 scorer。 |

Mastra 有两个特殊的文件夹约定：

- `src/mastra/agents/<name>`：可以按文件约定定义 Agent，而无需在代码中构造。详见[基于文件的 Agent](/docs/develop#file-based-agents)文档。
- `src/mastra/public`：构建时，此目录的内容会复制到 `.mastra/output`，以便在运行时提供服务。

### 顶级文件 {/* #top-level-files */}

顶级文件定义如何配置、构建 Mastra 项目以及如何连接到其环境。

| 文件 | 说明 |
| - | - |
| `src/mastra/index.ts` | 配置和初始化 Mastra 的集中入口。 |
| `.env.example` | 环境变量模板；复制为 `.env` 并加入私密的[模型 Provider](/models)密钥。 |
| `AGENTS.md` | 供项目中的编码 Agent 使用的说明。 |
| `package.json` | 定义项目元数据、依赖项和可用的 npm 脚本。 |
| `tsconfig.json` | 配置 TypeScript 选项，例如路径别名、编译器设置和构建输出。 |
