# 项目结构

您的新 Mastra 项目，使用以下命令创建`create mastra`命令附带一组预定义的文件和文件夹来帮助您入门。

Mastra 是一个框架，但主要是**unopinionated** about how you organize or colocate your files. The CLI provides a sensible default structure that works well for most projects, but you're free to adapt it to your workflow or team conventions. You could even build your entire project in a single file if you wanted! Whatever structure you choose, keep it consistent to ensure your code stays maintainable and straightforward to browse.

## 默认项目结构 {/* #default-project-structure */}

使用创建的项目`create mastra` command looks like this:

```bash
├── src/
│   └── mastra/
│       ├── agents/
│       │   └── agent.ts
│       ├── tools/
│       │   └── schedule-tools.ts
│       └── index.ts
├── .env.example
├── AGENTS.md
├── package.json
└── tsconfig.json
```

默认项目基于[Agent Harness template](https://github.com/mastra-ai/template-agent-harness). Use the predefined files as templates. Duplicate and adapt them to quickly create your own agents, tools, workflows, etc.

### 文件夹 {/* #folders */}

Mastra 建议将您的代码组织到以下文件夹中：

|文件夹|描述 |
| - | - |
|`src/mastra` | Entry point for all Mastra-related code and configuration. |
| `src/mastra/agents` | Define and configure your agents - their behavior, goals, and tools. |
| `src/mastra/workflows` | Define multi-step workflows that orchestrate agents and tools together. |
| `src/mastra/tools` | Create reusable tools that your agents can call |
| `src/mastra/mcp`|实施自定义 MCP 服务器以与外部Agent共享您的Tool |
|`src/mastra/scorers`|定义用于评估Agent绩效随时间变化的评分者 |

Mastra 有两个特殊的文件夹约定：

* `src/mastra/agents/<name>`：您可以通过文件约定定义Agent，而不是在代码中构造它。了解更多信息[File-based Agents](/docs/develop#file-based-agents) docs.
* `src/mastra/public`: 内容复制到`.mastra/output` directory during the build process, making them available for serving at runtime.

### 顶级文件 {/* #top-level-files */}

顶级文件定义如何配置、构建 Mastra 项目以及如何连接到其环境。

|文件|描述 |
| - | - |
|`src/mastra/index.ts` | Central entry point where you configure and initialize Mastra. |
| `.env.example` | Template for environment variables - copy and rename to `.env` to add your secret [model provider](/models) keys. |
| `AGENTS.md` | Instructions for coding agents working in the project. |
| `package.json` | Defines project metadata, dependencies, and available npm scripts. |
| `tsconfig.json` | Configures TypeScript options such as path aliases, compiler settings, and build output. |
