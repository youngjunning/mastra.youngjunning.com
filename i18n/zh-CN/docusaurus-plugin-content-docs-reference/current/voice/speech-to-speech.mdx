# Mastra 中的语音转语音功能

## 介绍 {/* #introduction */}

Mastra 的语音转语音（STS）为跨多个 Provider 的实时交互提供统一接口。
STS 通过监听 Realtime 模型的事件，实现持续的双向音频通信。与分开的 TTS 和 STT 操作不同，STS 会保持连接，让语音在两个方向上连续处理。

## 配置 {/* #configuration */}

* **`apiKey`**：OpenAI API 密钥；未提供时使用 `OPENAI_API_KEY` 环境变量。
* **`model`**：用于实时语音交互的模型 ID（如 `gpt-5.1-realtime`）。
* **`speaker`**：语音合成使用的默认声音 ID；可指定语音输出使用的声音。

```typescript
const voice = new OpenAIRealtimeVoice({
  apiKey: 'your-openai-api-key',
  model: 'gpt-5.1-realtime',
  speaker: 'alloy', // Default voice
})

// If using default settings the configuration can be simplified to:
const voice = new OpenAIRealtimeVoice()
```

## 使用 STS {/* #using-sts */}

```typescript
import { Agent } from '@mastra/core/agent'
import { OpenAIRealtimeVoice } from '@mastra/voice-openai-realtime'
import { playAudio, getMicrophoneStream } from '@mastra/node-audio'

const agent = new Agent({
  id: 'agent',
  name: 'OpenAI Realtime Agent',
  instructions: `You are a helpful assistant with real-time voice capabilities.`,
  model: '__GATEWAY_OPENAI_MODEL__',
  voice: new OpenAIRealtimeVoice(),
})

// Connect to the voice service
await agent.voice.connect()

// Listen for agent audio responses
agent.voice.on('speaker', ({ audio }) => {
  playAudio(audio)
})

// Initiate the conversation
await agent.voice.speak('How can I help you today?')

// Send continuous audio from the microphone
const micStream = getMicrophoneStream()
await agent.voice.send(micStream)
```

有关 Agent 语音 Provider 的完整概述，请参阅 [Mastra 语音](/reference/voice/overview)。

## 在实时会话中使用 Tool {/* #use-tools-in-realtime-sessions */}

实时语音 Provider 可以使用 Agent 上配置的 Tool。先将 Tool 添加到 `Agent` 定义，再通过语音 Provider 建立连接并发送音频：

```typescript
import { Agent } from '@mastra/core/agent'
import { OpenAIRealtimeVoice } from '@mastra/voice-openai-realtime'
import { calculate, search } from '../tools'

export const agent = new Agent({
  id: 'speech-to-speech-agent',
  name: 'Speech-to-Speech Agent',
  instructions: 'You are a helpful assistant with speech-to-speech capabilities.',
  model: '__GATEWAY_OPENAI_MODEL__',
  tools: {
    search,
    calculate,
  },
  voice: new OpenAIRealtimeVoice(),
})
```

## 监听实时事件 {/* #listen-for-realtime-events */}

实时语音 Provider 会发出事件，可用于更新 UI、播放助手音频、记录转录结果及处理错误：

```typescript
agent.voice.on('speaking', ({ audio }) => {
  playAudio(audio)
})

agent.voice.on('writing', ({ text, role }) => {
  console.log(`${role}: ${text}`)
})

agent.voice.on('error', error => {
  console.error('Voice error:', error)
})
```

事件名称和载荷因 Provider 而异。完整列表请查看下方对应的 Provider 章节或 Provider 参考文档。

## 每个会话独立的语音实例 {/* #per-session-voice-instances */}

静态 `voice` 实例会由所有请求共享。这适合一次性的文本转语音，但实时和语音转语音 Provider 会保存 WebSocket 连接、Tool、指令及请求上下文等会话状态。如果同一个 Agent 同时处理多个实时会话，共享实例可能导致一个会话覆盖另一个会话的状态。

如果每个实时会话都需要独立的语音实例，请将 `voice` 配置为解析函数。Mastra 每次调用 `getVoice()` 时都会运行该函数，并为当前请求上下文返回一个新实例：

```typescript
import { Agent } from '@mastra/core/agent'
import { RequestContext } from '@mastra/core/request-context'
import { OpenAIRealtimeVoice } from '@mastra/voice-openai-realtime'

export const agent = new Agent({
  id: 'support-line',
  name: 'Support Line',
  instructions: ({ requestContext }) => `Help user ${requestContext.get('user')}.`,
  model: '__GATEWAY_OPENAI_MODEL__',
  voice: ({ requestContext }) =>
    new OpenAIRealtimeVoice({
      apiKey: requestContext.get('apiKey'),
    }),
})

const requestContext = new RequestContext()
requestContext.set('user', 'user-123')
requestContext.set('apiKey', process.env.OPENAI_API_KEY)

const voice = await agent.getVoice({ requestContext })
await voice.connect()
```

使用解析函数时：

* 每次调用 `getVoice()` 都会返回新实例，因此并发会话不会共享状态。
* Mastra 不会向解析函数创建的实例添加 Tool 或指令；应在解析函数或 Provider 上配置。
* 返回实例的生命周期由你管理，因此会话结束时应调用 `disconnect()` 或 `close()`。

`agent.voice` getter 没有请求上下文，因此当 `voice` 是解析函数时会抛出异常。请改用 `agent.getVoice({ requestContext })`。

## Google Gemini Live（实时） {/* #google-gemini-live-realtime */}

```typescript
import { Agent } from '@mastra/core/agent'
import { GeminiLiveVoice } from '@mastra/voice-google-gemini-live'
import { playAudio, getMicrophoneStream } from '@mastra/node-audio'

const agent = new Agent({
  id: 'agent',
  name: 'Gemini Live Agent',
  instructions: 'You are a helpful assistant with real-time voice capabilities.',
  // Model used for text generation; voice provider handles realtime audio
  model: '__GATEWAY_OPENAI_MODEL__',
  voice: new GeminiLiveVoice({
    apiKey: process.env.GOOGLE_API_KEY,
    model: 'gemini-2.0-flash-exp',
    speaker: 'Puck',
    debug: true,
    // Vertex AI option:
    // vertexAI: true,
    // project: 'your-gcp-project',
    // location: 'us-central1',
    // serviceAccountKeyFile: '/path/to/service-account.json',
  }),
})

await agent.voice.connect()

agent.voice.on('speaker', ({ audio }) => {
  playAudio(audio)
})

agent.voice.on('writing', ({ role, text }) => {
  console.log(`${role}: ${text}`)
})

await agent.voice.speak('How can I help you today?')

const micStream = getMicrophoneStream()
await agent.voice.send(micStream)
```

注意：

* Live API 需要 `GOOGLE_API_KEY`；Vertex AI 需要项目、位置和服务账号凭据。
* 事件：`speaker`（音频流）、`writing`（文本）、`turnComplete`、`usage` 和 `error`。

## AWS Nova Sonic（实时） {/* #aws-nova-sonic-realtime */}

```typescript
import { Agent } from '@mastra/core/agent'
import { NovaSonicVoice } from '@mastra/voice-aws-nova-sonic'
import { playAudio, getMicrophoneStream } from '@mastra/node-audio'

const agent = new Agent({
  id: 'agent',
  name: 'Nova Sonic Agent',
  instructions: 'You are a helpful assistant with real-time voice capabilities.',
  // Model used for text generation; voice provider handles realtime audio
  model: '__GATEWAY_OPENAI_MODEL__',
  voice: new NovaSonicVoice({
    region: 'us-east-1',
    speaker: 'matthew',
    // Static credentials are optional. The default AWS credential provider
    // chain is used when none are passed.
  }),
})

await agent.voice.connect()

// Assistant audio is emitted as 16-bit PCM on the `speaking` event
agent.voice.on('speaking', ({ audioData }) => {
  if (audioData) playAudio(audioData)
})

agent.voice.on('writing', ({ role, text }) => {
  console.log(`${role}: ${text}`)
})

await agent.voice.speak('How can I help you today?')

const micStream = getMicrophoneStream()
await agent.voice.send(micStream)
```

注意：

* 可用区域：`us-east-1`、`us-west-2` 和 `ap-northeast-1`。
* 通过标准 AWS 凭据 Provider 链进行身份验证；可传入 `credentials` 覆盖。
* 事件：`speaking`（Int16Array 音频）、`writing`（含 `generationStage` 的文本）、`toolCall`、`interrupt`、`turnComplete`、`usage`、`session` 和 `error`。

## Inworld Realtime {/* #inworld-realtime */}

```typescript
import { Agent } from '@mastra/core/agent'
import { InworldRealtimeVoice } from '@mastra/voice-inworld'
import { playAudio, getMicrophoneStream } from '@mastra/node-audio'

const agent = new Agent({
  id: 'agent',
  name: 'Inworld Realtime Agent',
  instructions: 'You are a helpful assistant with real-time voice capabilities.',
  // Model used for text generation; voice provider handles realtime audio
  model: '__GATEWAY_OPENAI_MODEL__',
  voice: new InworldRealtimeVoice({
    apiKey: process.env.INWORLD_API_KEY,
    model: 'inworld/models/gemma-4-26b-a4b-it',
    speaker: 'Sarah',
    // Typed Inworld realtime knobs (semantic VAD, playback speed, etc.)
    // session: {
    //   audio: {
    //     output: { speed: 1.1 },
    //     input: { turn_detection: { type: 'semantic_vad', eagerness: 'high' } },
    //   },
    // },
  }),
})

await agent.voice.connect()

agent.voice.on('speaker', stream => {
  playAudio(stream)
})

agent.voice.on('writing', ({ role, text }) => {
  console.log(`${role}: ${text}`)
})

await agent.voice.speak('How can I help you today?')

const micStream = getMicrophoneStream()
await agent.voice.send(micStream)
```

注意：

* 需要 `INWORLD_API_KEY`。Inworld API 密钥已经过 Basic 编码，请原样粘贴。
* WebSocket URL 会附加客户端生成的 `?key=...&protocol=realtime`。模型通过初始 `session.update` 配置，而不是放在 URL 中。
* Inworld 的线路协议遵循 OpenAI Realtime GA 规范，因此事件名称与 `@mastra/voice-openai-realtime` 一致。
* Inworld 的实时参数（MCP Tool 路由、语义 VAD 的触发积极程度、播放速度、转录模型、输出模态等）以类型化字段通过构造函数的 `session` 暴露。未定义类型的 `providerData` 扩展入口也会深度合并，以便兼容 Inworld 未来的新功能。
* 事件：`speaker`（PCM 音频流）、`speaking`（每个增量对应的音频 Buffer）、`writing`（文本）、`conversation.item.added`、`conversation.item.done`、`function_call.arguments`、`tool-call-start`、`tool-call-result` 和 `error`。
