# 文本转语音 (TTS)

Mastra 中的文本转语音 (TTS) 提供了一个统一的 API，用于使用提供程序从文本合成语音音频。
通过将 TTS 集成到您的应用程序中，您可以通过自然的语音交互增强用户体验，提高有视觉障碍的用户的可访问性，并创建更具吸引力的多模式界面。

TTS 是任何语音应用程序的核心组件。它与STT（语音转文本）相结合，构成了语音交互系统的基础。较新的型号支持 STS ([Speech-to-Speech](./speech-to-speech)) which can be used for real-time interactions but come at high cost ($).

## 配置 {/* #configuration */}

要在 Mastra 中使用 TTS，您需要提供`speechModel` when initializing the voice provider. This includes parameters such as:

* **`name`**：要使用的特定 TTS 模型。
* **`apiKey`**：您用于身份验证的 API 密钥。
* **特定于Provider的选项**：特定语音Provider可能需要或支持的其他选项。

&#x8FD9;**`speaker`** option allows you to select different voices for speech synthesis. Each provider offers voice options with distinct characteristics for **Voice diversity**, **Quality**, **Voice personality**, and **Multilingual support**

**行为**：所有这些参数都是可选的。您可以使用语音Provider提供的默认设置，这取决于您使用的特定Provider。

```typescript
const voice = new OpenAIVoice({
  speechModel: {
    name: 'tts-1-hd',
    apiKey: process.env.OPENAI_API_KEY,
  },
  speaker: 'alloy',
})

// If using default settings the configuration can be simplified to:
const voice = new OpenAIVoice()
```

## 可用的Provider {/* #available-providers */}

Mastra 支持文本转语音Provider，每个Provider都有自己独特的功能和语音选项。您可以选择最适合您的应用程序需求的Provider：

* [**开放人工智能**](/integrations/voice/openai#voice)：高品质的声音，语调和表情自然
* [**天蓝色**](/integrations/voice/azure)：微软的语音和语言语音服务
* [**十一实验室**](/integrations/voice/elevenlabs)：超真实的声音，带有情感和细粒度的控制
* [**谷歌**](/integrations/voice/google#speech)：谷歌的语音合成支持多语言
* [**云耀**](/integrations/voice/cloudflare)：针对低延迟应用的边缘优化语音合成
* [**深度图谱**](/integrations/voice/deepgram)：人工智能驱动的高精度语音技术
* [**语音化**](/integrations/voice/speechify)：文本转语音优化以提高可读性和可访问性
* [**萨尔瓦姆**](/integrations/voice/sarvam)：专门研究印度语言和口音
* [**默夫**](/integrations/voice/murf)：具有可自定义参数的录音室品质配音

每个提供程序都作为单独的包实现，您可以根据需要安装：

```bash
pnpm add @mastra/voice-openai@latest  # Example for OpenAI
```

## 使用说话方法 {/* #using-the-speak-method */}

TTS 的主要方法是`speak()` method, which converts text to speech. This method can accept options that allows you to specify the speaker and other provider-specific options. Here's how to use it:

```typescript
import { Agent } from '@mastra/core/agent'
import { OpenAIVoice } from '@mastra/voice-openai'

const voice = new OpenAIVoice()

const agent = new Agent({
  id: 'voice-agent',
  name: 'Voice Agent',
  instructions: 'You are a voice assistant that can help users with their tasks.',
  model: '__GATEWAY_OPENAI_MODEL__',
  voice,
})

const { text } = await agent.generate('What color is the sky?')

// Convert text to speech to an Audio Stream
const readableStream = await voice.speak(text, {
  speaker: 'default', // Optional: specify a speaker
  properties: {
    speed: 1.0, // Optional: adjust speech speed
    pitch: 'default', // Optional: specify pitch if supported
  },
})
```

## 保存语音输出 {/* #save-speech-output */}

这`speak()` method returns an audio stream. Pipe the stream to a file when you need to save generated speech for later playback or processing:

```typescript
import { createWriteStream } from 'fs'
import path from 'path'

const audio = await agent.voice.speak('Hello, world!')
const filePath = path.join(process.cwd(), 'agent.mp3')
const writer = createWriteStream(filePath)

audio.pipe(writer)

await new Promise<void>((resolve, reject) => {
  writer.on('finish', () => resolve())
  writer.on('error', reject)
})
```

有关Agent上的语音提供程序的更广泛概述，请参阅[Voice in Mastra](/reference/voice/overview).
