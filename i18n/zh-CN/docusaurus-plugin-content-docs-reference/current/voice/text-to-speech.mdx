# 文本转语音 (TTS)

Mastra 的文本转语音 (TTS) 功能提供统一 API，可通过不同 Provider 将文本合成为语音。
在应用中集成 TTS，可以通过自然的语音交互提升用户体验，方便视障用户使用，并构建更有吸引力的多模态界面。

TTS 是语音应用的核心组成部分，与 STT（语音转文本）共同构成语音交互系统的基础。较新的模型支持 STS（[语音转语音](./speech-to-speech)），可用于实时交互，但成本较高。

## 配置 {/* #configuration */}

要在 Mastra 中使用 TTS，初始化语音 Provider 时需要提供 `speechModel`，其中可包含以下参数：

- **`name`**: 要使用的 TTS 模型。
- **`apiKey`**: 用于身份验证的 API 密钥。
- **Provider 专属选项**: 相应语音 Provider 可能要求或支持的其他选项。

**`speaker`** 选项用于选择合成语音的音色。各 Provider 提供的音色在**声音多样性**、**质量**、**声音风格**和**多语言支持**方面各有特点。

**行为**：上述参数均为可选项。可以使用语音 Provider 的默认设置，具体默认值取决于所用的 Provider。

```typescript
const voice = new OpenAIVoice({
  speechModel: {
    name: 'tts-1-hd',
    apiKey: process.env.OPENAI_API_KEY,
  },
  speaker: 'alloy',
})

// If using default settings the configuration can be simplified to:
const voice = new OpenAIVoice()
```

## 可用的 Provider {/* #available-providers */}

Mastra 支持多种文本转语音 Provider，各自具有不同的功能和音色选项。可根据应用需求选择：

- [**OpenAI**](/integrations/voice/openai#voice): 提供语调和表现自然的高质量语音
- [**Azure**](/integrations/voice/azure): 微软语音服务，提供多种声音和语言
- [**ElevenLabs**](/integrations/voice/elevenlabs): 提供富有情感、可精细控制的逼真语音
- [**Google**](/integrations/voice/google#speech): Google 的语音合成服务，支持多种语言
- [**Cloudflare**](/integrations/voice/cloudflare): 针对低延迟应用优化的边缘语音合成服务
- [**Deepgram**](/integrations/voice/deepgram): 准确度高的 AI 语音技术
- [**Speechify**](/integrations/voice/speechify): 侧重易读性和无障碍体验的文本转语音服务
- [**Sarvam**](/integrations/voice/sarvam): 专注印度语系语言和口音
- [**Murf**](/integrations/voice/murf): 提供可自定义参数的录音室级配音

每个 Provider 都有独立的包，可按需安装：

```bash
pnpm add @mastra/voice-openai@latest  # Example for OpenAI
```

## 使用 speak 方法 {/* #using-the-speak-method */}

TTS 主要通过 `speak()` 方法将文本转换为语音。调用时可传入选项，指定声音及其他 Provider 专属设置：

```typescript
import { Agent } from '@mastra/core/agent'
import { OpenAIVoice } from '@mastra/voice-openai'

const voice = new OpenAIVoice()

const agent = new Agent({
  id: 'voice-agent',
  name: 'Voice Agent',
  instructions: 'You are a voice assistant that can help users with their tasks.',
  model: '__GATEWAY_OPENAI_MODEL__',
  voice,
})

const { text } = await agent.generate('What color is the sky?')

// Convert text to speech to an Audio Stream
const readableStream = await voice.speak(text, {
  speaker: 'default', // Optional: specify a speaker
  properties: {
    speed: 1.0, // Optional: adjust speech speed
    pitch: 'default', // Optional: specify pitch if supported
  },
})
```

## 保存语音输出 {/* #save-speech-output */}

`speak()` 方法返回音频流。如需保存生成的语音以供之后播放或处理，可将音频流通过管道写入文件：

```typescript
import { createWriteStream } from 'fs'
import path from 'path'

const audio = await agent.voice.speak('Hello, world!')
const filePath = path.join(process.cwd(), 'agent.mp3')
const writer = createWriteStream(filePath)

audio.pipe(writer)

await new Promise<void>((resolve, reject) => {
  writer.on('finish', () => resolve())
  writer.on('error', reject)
})
```

有关 Agent 语音 Provider 的更多信息，请参阅 [Mastra 语音概览](/reference/voice/overview)。
