# voice.send()

`send()` 方法向语音 Provider 实时传输音频数据，以供持续处理。它是实时语音对话的关键，可将麦克风输入直接发送到 AI 服务。

## 使用示例 {/* #usage-example */}

```typescript
import { OpenAIRealtimeVoice } from '@mastra/voice-openai-realtime'
import Speaker from '@mastra/node-speaker'
import { getMicrophoneStream } from '@mastra/node-audio'

const speaker = new Speaker({
  sampleRate: 24100, // Audio sample rate in Hz - standard for high-quality audio on MacBook Pro
  channels: 1, // Mono audio output (as opposed to stereo which would be 2)
  bitDepth: 16, // Bit depth for audio quality - CD quality standard (16-bit resolution)
})

// Initialize a real-time voice provider
const voice = new OpenAIRealtimeVoice({
  realtimeConfig: {
    model: 'gpt-5.1-realtime',
    apiKey: process.env.OPENAI_API_KEY,
  },
})

// Connect to the real-time service
await voice.connect()

// Set up event listeners for responses
voice.on('writing', ({ text, role }) => {
  console.log(`${role}: ${text}`)
})

voice.on('speaker', stream => {
  stream.pipe(speaker)
})

// Get microphone stream (implementation depends on your environment)
const microphoneStream = getMicrophoneStream()

// Send audio data to the voice provider
await voice.send(microphoneStream)

// You can also send audio data as Int16Array
const audioBuffer = getAudioBuffer() // Assume this returns Int16Array
await voice.send(audioBuffer)
```

## 返回值 {/* #return-value */}

返回 `Promise<void>`。对于支持实时音频的 Provider，当音频数据被接收后，Promise 会完成。默认实现不发送任何数据，并立即完成。

## 注意事项 {/* #notes */}

- 此方法仅由支持语音对话的实时语音 Provider 实现。
  如果语音 Provider 不支持此功能，默认实现会记录调试消息并立即完成。`CompositeVoice` 则会抛出 `MastraError`（`VOICE_COMPOSITE_NO_REALTIME_PROVIDER_SEND`），前提是未配置 `realtimeProvider`。
  必须先调用 `connect()` 建立 WebSocket 连接，才能使用 `send()`。
- 音频格式要求取决于具体的语音 Provider。
- 连续对话通常先调用 `send()` 传输用户音频，再调用 `answer()` 触发 AI 回复。
- Provider 处理音频时通常会发出包含转录文本的 'writing' 事件。
- AI 回复时，Provider 会发出包含音频回复的 'speaking' 事件。
