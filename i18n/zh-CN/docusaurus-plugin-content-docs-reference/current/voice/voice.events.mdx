# 语音事件

语音提供程序在实时语音交互期间发出事件。可以使用以下命令监听这些事件[voice.on()](./voice.on)方法，对于构建交互式语音应用程序尤其重要。

## 笔记 {/* #notes */}

* 并非所有语音Provider都支持所有事件
* 确切的有效负载结构可能因Provider而异
* 对于非实时提供程序，大多数事件不会被发出
* 事件对于构建响应对话状态的交互式 UI 非常有用
* 考虑使用[voice.off()](./voice.off) method to remove event listeners when they're no longer needed
