# 语音事件

语音 Provider 会在实时语音交互期间发出事件。你可以使用 [voice.on()](./voice.on) 方法监听这些事件；构建交互式语音应用时，这些事件尤其重要。

## 注意事项 {/* #notes */}

* 并非每个语音 Provider 都支持所有事件
* 确切的 payload 结构可能因 Provider 而异
* 对于非实时 Provider，大多数事件不会发出
* 事件对于构建响应对话状态的交互式 UI 非常有用
* 不再需要事件监听器时，建议使用 [voice.off()](./voice.off) 方法将其移除
