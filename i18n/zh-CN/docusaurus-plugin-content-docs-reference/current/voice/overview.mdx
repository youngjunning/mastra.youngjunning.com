# Mastra 中的语音

Mastra 的 Voice 系统为语音交互提供统一接口，让应用能够实现文本转语音 (TTS)、语音转文本 (STT) 和实时语音交互 (STS)。

## 为 Agent 添加语音 {/* #add-voice-to-agents */}

通过 `voice` 属性向 Agent 传入语音提供者。根据所配置的提供者，同一属性可支持文本转语音 (TTS)、语音转文本 (STT) 和实时语音交互 (STS)。

```typescript
import { Agent } from '@mastra/core/agent'
import { OpenAIVoice } from '@mastra/voice-openai'

// Initialize OpenAI voice for TTS

const voiceAgent = new Agent({
  id: 'voice-agent',
  name: 'Voice Agent',
  instructions: 'You are a voice assistant that can help users with their tasks.',
  model: '__GATEWAY_OPENAI_MODEL__',
  voice: new OpenAIVoice(),
})
```

随后即可使用以下语音功能：

### 文本转语音 (TTS) {/* #text-to-speech-tts */}

使用 Mastra 的 TTS 功能，将 Agent 的响应转换为自然的语音。
可以选择 OpenAI、ElevenLabs 等多种提供者。

详细配置和高级功能请参阅[文本转语音指南](./text-to-speech)。

### 语音交互 (STS) {/* #speech-to-speech-sts */}

通过语音转语音能力打造对话体验。统一 API 支持用户与 AI Agent 实时进行语音交互。
详细配置和高级功能请参阅[语音交互](./speech-to-speech)。

<Tabs>
  <TabItem value="openai" label="OpenAI">
    ```typescript
    import { Agent } from '@mastra/core/agent'
    import { playAudio, getMicrophoneStream } from '@mastra/node-audio'
    import { OpenAIRealtimeVoice } from '@mastra/voice-openai-realtime'

    const voiceAgent = new Agent({
      id: 'voice-agent',
      name: 'Voice Agent',
      instructions: 'You are a voice assistant that can help users with their tasks.',
      model: '__GATEWAY_OPENAI_MODEL__',
      voice: new OpenAIRealtimeVoice(),
    })

    // Listen for agent audio responses
    voiceAgent.voice.on('speaker', ({ audio }) => {
      playAudio(audio)
    })

    // Initiate the conversation
    await voiceAgent.voice.speak('How can I help you today?')

    // Send continuous audio from the microphone
    const micStream = getMicrophoneStream()
    await voiceAgent.voice.send(micStream)
    ```

    有关 OpenAI Voice 的配置与功能，请参阅 [OpenAI Voice 参考文档](/integrations/voice/openai#realtime)。

### 实时语音 {/* #realtime-voice */}

通过浏览器或电话进行实时通话，用户可以随时插话。Mastra 将音频处理循环交给 LiveKit，由它处理语音活动检测、语义轮次检测和打断；Agent 则使用自己的模型、Tool 和 Memory 生成每次回复。设置和配置选项请参阅[实时语音](/integrations/voice/livekit#quickstart)。

### 使用多个语音提供者 {/* #using-multiple-voice-providers */}

此示例展示如何在 Mastra 中同时使用两个语音提供者：OpenAI 负责语音转文本 (STT)，ElevenLabs 负责文本转语音 (TTS)。

首先根据需要配置并创建两个语音提供者实例。

```typescript
import { OpenAIVoice } from '@mastra/voice-openai'
import { ElevenLabsVoice } from '@mastra/voice-elevenlabs'
import { CompositeVoice } from '@mastra/core/voice'
import { playAudio, getMicrophoneStream } from '@mastra/node-audio'

// Initialize OpenAI voice for STT
const input = new OpenAIVoice({
  listeningModel: {
    name: 'whisper-1',
    apiKey: process.env.OPENAI_API_KEY,
  },
})

// Initialize ElevenLabs voice for TTS
const output = new ElevenLabsVoice()

// Combine the providers using CompositeVoice
const voice = new CompositeVoice({
  input,
  output,
})

// Implement voice interactions using the combined voice provider
const audioStream = getMicrophoneStream() // Assume this function gets audio input
const transcript = await voice.listen(audioStream)

// Log the transcribed text
console.log('Transcribed text:', transcript)

// Convert text to speech
const responseAudio = await voice.speak(`You said: ${transcript}`, {
  speaker: 'default', // Optional: specify a speaker,
  responseFormat: 'wav', // Optional: specify a response format
})

// Play the audio response
playAudio(responseAudio)
```

### 使用 AI SDK 模型提供者 {/* #using-ai-sdk-model-providers */}

也可以直接将 AI SDK 模型用于 `CompositeVoice`：

```typescript
import { CompositeVoice } from '@mastra/core/voice'
import { openai } from '@ai-sdk/openai'
import { elevenlabs } from '@ai-sdk/elevenlabs'
import { playAudio, getMicrophoneStream } from '@mastra/node-audio'

// Use AI SDK models directly - no provider setup needed
const voice = new CompositeVoice({
  input: openai.transcription('whisper-1'), // AI SDK transcription
  output: elevenlabs.speech('eleven_turbo_v2'), // AI SDK speech
})

// Works the same way as Mastra providers
const audioStream = getMicrophoneStream()
const transcript = await voice.listen(audioStream)

console.log('Transcribed text:', transcript)

// Convert text to speech
const responseAudio = await voice.speak(`You said: ${transcript}`, {
  speaker: 'Rachel', // ElevenLabs voice
})

playAudio(responseAudio)
```

也可以混合使用 AI SDK 模型和 Mastra 提供者：

```typescript
import { CompositeVoice } from '@mastra/core/voice'
import { ElevenLabsVoice } from '@mastra/voice-elevenlabs'
import { groq } from '@ai-sdk/groq'

const voice = new CompositeVoice({
  input: groq.transcription('whisper-large-v3'), // AI SDK for STT
  output: new ElevenLabsVoice(), // Mastra provider for TTS
})
```
