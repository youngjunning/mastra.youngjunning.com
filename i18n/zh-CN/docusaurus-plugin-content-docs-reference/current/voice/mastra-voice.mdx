# MastraVoice

MastraVoice 是定义 Mastra 语音服务核心接口的抽象基类。OpenAI、Deepgram、PlayAI、Speechify 等语音提供者都扩展该类以实现各自的功能。该类还支持通过 WebSocket 连接进行实时语音交互。

    audioStream: NodeJS.ReadableStream,
    options?: unknown,
  ): Promise<string | NodeJS.ReadableStream | void> {
    // Implement speech-to-text conversion
  }

  async getSpeakers(): Promise<Array<{ voiceId: string; [key: string]: unknown }>> {
    // Return list of available voices
  }

  // Optional speech-to-speech methods
  async connect(): Promise<void> {
    // Establish WebSocket connection for speech-to-speech communication
  }

  async send(audioData: NodeJS.ReadableStream | Int16Array): Promise<void> {
    // Stream audio data in speech-to-speech
  }

  async answer(): Promise<void> {
    // Trigger voice provider to respond
  }

  addTools(tools: Array<unknown>): void {
    // Add tools for the voice provider to use
  }

  close(): void {
    // Close WebSocket connection
  }

  on(event: string, callback: (data: unknown) => void): void {
    // Register event listener
  }

  off(event: string, callback: (data: unknown) => void): void {
    // Remove event listener
  }
}

## 抽象方法 {/* #abstract-methods */}

这些方法必须由扩展 MastraVoice 的类实现。

### `speak()` {/* #speak */}

使用配置的语音合成模型将文本转换为语音。

```typescript oxfmt:false
abstract speak(
  input: string | NodeJS.ReadableStream,
  options?: {
    speaker?: string;
    [key: string]: unknown;
  }
): Promise<NodeJS.ReadableStream | void>
```

目的：

* 接收文本输入，并通过提供者的文本转语音服务将其转换为语音
* 同时支持字符串和流输入
* 可通过选项覆盖默认说话人／语音
* 返回可播放或保存的音频数据流
* 若通过触发 'speaking' 事件处理音频，则可能返回 void

### `listen()` {/* #listen */}

使用配置的语音识别模型将语音转换为文本。

```typescript oxfmt:false
abstract listen(
  audioStream: NodeJS.ReadableStream | unknown,
  options?: {
    [key: string]: unknown;
  }
): Promise<string | NodeJS.ReadableStream | void>
```

目的：

* 接收音频流（或提供者专属的其他音频输入），并通过提供者的语音转文本服务将其转换为文本
* 支持提供者专属的转录配置选项
* 可返回完整的转录文本或转录文本流
* 并非所有提供者都支持此功能，例如 PlayAI 和 Speechify
* 若通过触发 'writing' 事件处理转录结果，则可能返回 void

## 可选方法 {/* #optional-methods */}

这些方法提供默认实现；支持实时语音交互的提供者可以覆盖它们。

### `getSpeakers()` {/* #getspeakers */}

返回提供者支持的可用语音列表。

```typescript oxfmt:false
getSpeakers(): Promise<Array<{ voiceId: string; [key: string]: unknown }>>
```

目的：

* 从提供者获取可用语音／说话人列表
* 默认实现返回空数组；提供者可覆盖该方法，列出自己的语音
* 每个语音至少必须具有 voiceId 属性
* 提供者可为每个语音添加其他元数据
* 用于发现可供文本转语音使用的语音

### `connect()` {/* #connect */}

建立 WebSocket 或 WebRTC 连接进行通信。

```typescript oxfmt:false
connect(config?: unknown): Promise<void>
```

目的：

* 初始化与语音服务的通信连接
* 使用 send() 或 answer() 等功能前必须调用
* 返回在连接建立后兑现的 Promise
* 配置取决于提供者

### `send()` {/* #send */}

将音频数据实时流式传输给语音提供者。

```typescript oxfmt:false
send(audioData: NodeJS.ReadableStream | Int16Array): Promise<void>
```

目的：

* 将音频数据发送给语音提供者进行实时处理
* 适用于麦克风持续输入等连续音频流场景
* 支持 ReadableStream 和 Int16Array 音频格式
* 调用此方法前必须先建立连接

### `answer()` {/* #answer */}

触发语音提供者生成响应。

```typescript oxfmt:false
answer(options?: Record<string, unknown>): Promise<void>
```

目的：

* 通知语音提供者生成响应
* 接受可选的提供者专属选项
* 用于实时对话中提示 AI 作出响应
* 响应会通过事件系统发出，例如 'speaking' 事件

### `addTools()` {/* #addtools */}

为语音提供者添加对话时可用的 Tool。

```typescript oxfmt:false
addTools(tools: Array<Tool>): void
```

目的：

* 添加语音提供者在对话期间可用的 Tool
* Tool 可扩展语音提供者的功能
* 具体实现取决于提供者

### `close()` {/* #close */}

断开 WebSocket 或 WebRTC 连接。

```typescript oxfmt:false
close(): void
```

目的：

* 关闭与语音服务的连接
* 清理资源并停止正在进行的实时处理
* 不再使用语音实例时应调用此方法

### `on()` {/* #on */}

注册语音事件监听器。

```typescript oxfmt:false
on<E extends VoiceEventType>(
  event: E,
  callback: (data: E extends keyof VoiceEventMap ? VoiceEventMap[E] : unknown) => void,
): void
```

目的：

* 注册在指定事件发生时调用的回调函数
* 标准事件包括 'speaking'、'writing' 和 'error'
* 提供者也可以触发自定义事件
* 事件数据结构取决于事件类型

### `off()` {/* #off */}

移除事件监听器。

```typescript oxfmt:false
off<E extends VoiceEventType>(
  event: E,
  callback: (data: E extends keyof VoiceEventMap ? VoiceEventMap[E] : unknown) => void,
): void
```

目的：

* 移除之前注册的事件监听器
* 不再需要事件处理函数时，用于清理它们

## 遥测支持 {/* #telemetry-support */}

MastraVoice 通过 `traced` 方法提供内置遥测支持，该方法在调用其他方法时记录性能并监控错误。

## 注意事项 {/* #notes */}

* MastraVoice 是抽象类，无法直接实例化
* 实现类必须具体实现抽象方法 `speak()` 和 `listen()`
* 该类为不同语音服务提供者提供一致的接口
* 语音交互功能是可选的，具体取决于提供者
* 事件系统支持实时交互中的异步通信
* 所有方法调用的遥测数据都会自动处理
