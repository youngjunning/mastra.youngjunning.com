# 马斯特拉之声

MastraVoice 类是一个抽象基类，它定义了 Mastra 中语音服务的核心接口。所有语音提供程序实现（例如 OpenAI、Deepgram、PlayAI、Speechify）都扩展此类以提供其特定功能。该类现在包括通过 WebSocket 连接支持实时语音到语音功能。

```typescript

// Create a voice provider implementation

  }) {
    super({
      speechModel: config.speechModel,
      listeningModel: config.listeningModel,
      speaker: config.speaker,
      realtimeConfig: config.realtimeConfig,
    })
  }

  // Implement required abstract methods
  async speak(
    input: string | NodeJS.ReadableStream,
    options?: { speaker?: string },
  ): Promise<NodeJS.ReadableStream | void> {
    // Implement text-to-speech conversion
  }

  async listen(
    audioStream: NodeJS.ReadableStream,
    options?: unknown,
  ): Promise<string | NodeJS.ReadableStream | void> {
    // Implement speech-to-text conversion
  }

  async getSpeakers(): Promise<Array<{ voiceId: string; [key: string]: unknown }>> {
    // Return list of available voices
  }

  // Optional speech-to-speech methods
  async connect(): Promise<void> {
    // Establish WebSocket connection for speech-to-speech communication
  }

  async send(audioData: NodeJS.ReadableStream | Int16Array): Promise<void> {
    // Stream audio data in speech-to-speech
  }

  async answer(): Promise<void> {
    // Trigger voice provider to respond
  }

  addTools(tools: Array<unknown>): void {
    // Add tools for the voice provider to use
  }

  close(): void {
    // Close WebSocket connection
  }

  on(event: string, callback: (data: unknown) => void): void {
    // Register event listener
  }

  off(event: string, callback: (data: unknown) => void): void {
    // Remove event listener
  }
}
```

## 抽象方法 {/* #abstract-methods */}

这些方法必须由扩展 MastraVoice 的未知类来实现。

### `speak()` {/* #speak */}

使用配置的语音模型将文本转换为语音。

```typescript oxfmt:false
abstract speak(
  input: string | NodeJS.ReadableStream,
  options?: {
    speaker?: string;
    [key: string]: unknown;
  }
): Promise<NodeJS.ReadableStream | void>
```

目的：

* 获取文本输入并使用Provider的文本转语音服务将其转换为语音
* 支持字符串和流输入以实现灵活性
* 允许通过选项覆盖默认扬声器/语音
* 返回可以播放或保存的音频数据流
* 如果通过发出“说话”事件处理音频，可能会返回 void

### `listen()` {/* #listen */}

使用配置的聆听模型将语音转换为文本。

```typescript oxfmt:false
abstract listen(
  audioStream: NodeJS.ReadableStream | unknown,
  options?: {
    [key: string]: unknown;
  }
): Promise<string | NodeJS.ReadableStream | void>
```

目的：

* 获取音频流（或其他特定于Provider的音频输入）并使用Provider的语音到文本服务将其转换为文本
* 支持特定于Provider的转录配置选项
* 可以返回完整的文本转录或转录文本流
* 并非所有Provider都支持此功能（例如 PlayAI、Speechify）
* 如果通过发出“写入”事件处理转录，则可能返回 void

## 可选方法 {/* #optional-methods */}

这些方法具有默认实现，但可以被支持语音到语音功能的语音Provider覆盖。

### `getSpeakers()` {/* #getspeakers */}

返回Provider支持的可用语音列表。

```typescript oxfmt:false
getSpeakers(): Promise<Array<{ voiceId: string; [key: string]: unknown }>>
```

目的：

* 从Provider处检索可用语音/发言者的列表
* 默认实现返回一个空数组；Provider覆盖它以列出他们的声音
* 每个语音必须至少有一个 voiceId 属性
* Provider可以包含有关每个语音的附加元数据
* 用于发现可用于文本到语音转换的语音

### `connect()` {/* #connect */}

建立 WebSocket 或 WebRTC 连接进行通信。

```typescript oxfmt:false
connect(config?: unknown): Promise<void>
```

目的：

* 初始化与语音服务的连接以进行通信
* 必须在使用 send() 或answer() 等功能之前调用
* 返回一个在连接建立时解析的 Promise
* 配置是特定于Provider的

### `send()` {/* #send */}

将音频数据实时传输到语音Provider。

```typescript oxfmt:false
send(audioData: NodeJS.ReadableStream | Int16Array): Promise<void>
```

目的：

* 将音频数据发送到语音Provider进行实时处理
* 适用于连续音频流场景，例如实时麦克风输入
* 支持 ReadableStream 和 Int16Array 音频格式
* 调用此方法之前必须处于连接状态

### `answer()` {/* #answer */}

触发语音提供者生成响应。

```typescript oxfmt:false
answer(options?: Record<string, unknown>): Promise<void>
```

目的：

* 向语音Provider发送信号以生成响应
* 接受可选的特定于Provider的选项
* 用于实时对话，提示AI做出响应
* 响应将通过事件系统发出（例如，“说话”事件）

### `addTools()` {/* #addtools */}

为语音Provider配备可在对话期间使用的Tool。

```typescript oxfmt:false
addTools(tools: Array<Tool>): void
```

目的：

* 添加语音Provider可以在对话期间使用的Tool
* Tool可以扩展语音Provider的功能
* 实施是特定于Provider的

### `close()` {/* #close */}

断开 WebSocket 或 WebRTC 连接。

```typescript oxfmt:false
close(): void
```

目的：

* 关闭与语音服务的连接
* 清理资源并停止任何正在进行的实时处理
* 当您完成语音实例时应该调用

### `on()` {/* #on */}

注册语音事件的事件侦听器。

```typescript oxfmt:false
on<E extends VoiceEventType>(
  event: E,
  callback: (data: E extends keyof VoiceEventMap ? VoiceEventMap[E] : unknown) => void,
): void
```

目的：

* 注册一个回调函数，当指定事件发生时调用
* 标准事件包括“说”、“写”和“错误”
* 提供者也可以发出自定义事件
* 事件数据结构取决于事件类型

### `off()` {/* #off */}

删除事件侦听器。

```typescript oxfmt:false
off<E extends VoiceEventType>(
  event: E,
  callback: (data: E extends keyof VoiceEventMap ? VoiceEventMap[E] : unknown) => void,
): void
```

目的：

* 删除之前注册的事件监听器
* 用于在不再需要事件处理程序时清理它们

## 遥测支持 {/* #telemetry-support */}

MastraVoice 包括内置遥测支持`traced` method, which wraps method calls with performance tracking and error monitoring.

## 笔记 {/* #notes */}

* MastraVoice是一个抽象类，不能直接实例化
* 实现必须提供抽象的具体实现`speak()` and `listen()` methods
* 该类在不同的语音服务Provider之间提供一致的接口
* 语音转语音功能是可选的且特定于Provider
* 事件系统支持异步通信，实现实时交互
* 自动处理所有方法调用的遥测
