# 复合语音

CompositeVoice 类允许您组合不同的语音提供程序以进行文本转语音和语音转文本操作。当您想要为每个操作使用最佳的提供程序时，这特别有用 - 例如，使用 OpenAI 进行语音转文本，使用 PlayAI 进行文本转语音。

CompositeVoice 支持 Mastra 语音Provider和 AI SDK 模型Provider

## 方法 {/* #methods */}

### `speak()` {/* #speak */}

使用配置的语音提供程序将文本转换为语音。

<PropertiesTable
  content={[
{
  name: 'input',
  type: 'string | NodeJS.ReadableStream',
  description: 'Text to convert to speech',
  isOptional: false,
},
{
  name: 'options',
  type: 'object',
  description: 'Provider-specific options passed to the speaking provider',
  isOptional: true,
},
]}
/>

笔记：

* 如果配置了实时提供程序，它将处理调用；否则使用说话的提供者
* 抛出一个`MastraError` only when neither a realtime nor a speaking provider is configured
* 选项被传递给处理调用的提供者
* 返回音频数据流，或者`void` when a realtime provider handles the call

### `listen()` {/* #listen */}

使用配置的监听提供程序将语音转换为文本。

{
  name: 'options',
  type: 'object',

  isOptional: true,

笔记：

* 如果配置了实时提供程序，它将处理调用；否则使用监听提供程序
* 抛出一个`MastraError` only when neither a realtime nor a listening provider is configured
* 选项被传递给处理调用的提供者
* 返回一个字符串或转录文本流，具体取决于提供者，或者`void` when a realtime provider emits results through events

### `getSpeakers()` {/* #getspeakers */}

返回来自实时提供程序的可用语音列表，或者在未配置实时提供程序时返回来自讲话提供程序的可用语音列表，其中每个节点包含：

<PropertiesTable
  content={[
{
  name: 'voiceId',
  type: 'string',
  description: 'Unique identifier for the voice',
  isOptional: false,
},
{
  name: 'key',
  type: 'value',
  description: 'Additional voice properties that vary by provider (e.g., name, language)',
  isOptional: true,
},
]}
/>

笔记：

* 如果已配置，则从实时Provider返回语音，否则从语音Provider返回语音
* 抛出一个`MastraError` when neither a realtime nor a speaking provider is configured
* 每个语音对象至少有一个 voiceId 属性
* 其他语音属性取决于Provider

## 使用示例 {/* #usage-examples */}

### 使用 Mastra 语音Provider {/* #using-mastra-voice-providers */}

```typescript
import { CompositeVoice } from '@mastra/core/voice'
import { OpenAIVoice } from '@mastra/voice-openai'
import { PlayAIVoice } from '@mastra/voice-playai'

// Create voice providers
const openai = new OpenAIVoice()
const playai = new PlayAIVoice()

// Use OpenAI for listening (speech-to-text) and PlayAI for speaking (text-to-speech)
const voice = new CompositeVoice({
  input: openai,
  output: playai,
})

// Convert speech to text using OpenAI
const text = await voice.listen(audioStream)

// Convert text to speech using PlayAI
const audio = await voice.speak('Hello, world!')
```

### 使用AI SDK模型提供者 {/* #using-ai-sdk-model-providers */}

您可以将 AI SDK 转录和语音模型直接传递给 CompositeVoice：

```typescript
import { CompositeVoice } from '@mastra/core/voice'
import { openai } from '@ai-sdk/openai'
import { elevenlabs } from '@ai-sdk/elevenlabs'

// Use AI SDK models directly - they will be auto-wrapped
const voice = new CompositeVoice({
  input: openai.transcription('whisper-1'), // AI SDK transcription
  output: elevenlabs.speech('eleven_turbo_v2'), // AI SDK speech
})

// Works the same way as with Mastra providers
const text = await voice.listen(audioStream)
const audio = await voice.speak('Hello from AI SDK!')
```

### 混合搭配 {/* #mix-and-match */}

您可以将 Mastra Provider与 AI SDK 模型结合起来：

```typescript
import { CompositeVoice } from '@mastra/core/voice'
import { PlayAIVoice } from '@mastra/voice-playai'
import { groq } from '@ai-sdk/groq'

const voice = new CompositeVoice({
  input: groq.transcription('whisper-large-v3'), // AI SDK for STT
  output: new PlayAIVoice(), // Mastra for TTS
})
```
