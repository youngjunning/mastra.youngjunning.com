# voice.connect()

`connect()` 方法建立 WebSocket 或 WebRTC 连接，以实现实时语音对话。使用 `send()` 或 `answer()` 等其他实时功能前，必须先调用此方法。

## 使用示例 {/* #usage-example */}

```typescript
import { OpenAIRealtimeVoice } from '@mastra/voice-openai-realtime'
import Speaker from '@mastra/node-speaker'

const speaker = new Speaker({
  sampleRate: 24000,
  channels: 1,
  bitDepth: 16,
})

const voice = new OpenAIRealtimeVoice({
  apiKey: process.env.OPENAI_API_KEY,
  speaker: 'alloy',
})
// Connect to the real-time service
await voice.connect()
// Now you can use real-time features
voice.on('speaker', stream => {
  stream.pipe(speaker)
})
```

## 连接失败 {/* #connection-failures */}

对于 OpenAI Realtime，`connect()` 会等待 WebSocket 打开且服务器创建会话。如果连接失败、服务器在握手期间报告错误，或会话就绪前套接字关闭，Promise 会被拒绝。握手无响应时，默认在 15,000 毫秒后超时。

请直接捕获连接失败。监听 `error` 事件不能代替处理被拒绝的 Promise：

```typescript
import { OpenAIRealtimeVoice } from '@mastra/voice-openai-realtime'

const voice = new OpenAIRealtimeVoice({
  apiKey: process.env.OPENAI_API_KEY,
  connectTimeoutMs: 30_000,
})

try {
  await voice.connect()
} catch (error) {
  console.error('Could not connect to the realtime service:', error)
}
```

握手失败后，套接字会关闭，待处理的等待也会清除。可以在同一实例上重新调用 `connect()`。

## 与 `CompositeVoice` 配合使用 {/* #using-with-compositevoice */}

使用 `CompositeVoice` 时，`connect()` 会将选项传递给已配置的实时 Provider；如果没有配置实时 Provider，则会抛出异常：

```typescript
import { CompositeVoice } from '@mastra/core/voice'
import { OpenAIRealtimeVoice } from '@mastra/voice-openai-realtime'
const realtimeVoice = new OpenAIRealtimeVoice()
const voice = new CompositeVoice({
  realtime: realtimeVoice,
})
// This will use the OpenAIRealtimeVoice provider
await voice.connect()
```

## 注意事项 {/* #notes */}

* 只有支持语音对话的实时语音 Provider 实现此方法
* 继承基础 `connect()` 实现的 Provider 只会记录调试消息并完成调用，不会建立连接
* 使用 `send()` 或 `answer()` 等其他实时方法前必须先建立连接
* 使用完语音实例后，请调用 `close()` 清理资源
* 部分 Provider 可能会在连接断开后自动重连，具体取决于其实现
* 连接错误通常以异常形式抛出，应捕获并处理
