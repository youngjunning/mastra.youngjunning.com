# 语音.connect()

这`connect()`方法建立 WebSocket 或 WebRTC 连接以进行实时语音到语音通信。在使用其他实时功能（例如`send()`或者`answer()`.

## 使用示例 {/* #usage-example */}

```typescript
import { OpenAIRealtimeVoice } from '@mastra/voice-openai-realtime'
import Speaker from '@mastra/node-speaker'

const speaker = new Speaker({
  sampleRate: 24000,
  channels: 1,
  bitDepth: 16,
})

const voice = new OpenAIRealtimeVoice({
  apiKey: process.env.OPENAI_API_KEY,
  speaker: 'alloy',
})
// Connect to the real-time service
await voice.connect()
// Now you can use real-time features
voice.on('speaker', stream => {
  stream.pipe(speaker)
})
```

## 连接失败 {/* #connection-failures */}

对于 OpenAI Realtime，`connect()` waits for both the WebSocket to open and the server to create a session. It rejects if the connection fails, the server reports an error during the handshake, or the socket closes before the session is ready. A silent handshake times out after 15,000 milliseconds by default.

直接捕获连接失败。一个`error` event listener doesn't replace handling the rejected promise:

```typescript
import { OpenAIRealtimeVoice } from '@mastra/voice-openai-realtime'

const voice = new OpenAIRealtimeVoice({
  apiKey: process.env.OPENAI_API_KEY,
  connectTimeoutMs: 30_000,
})

try {
  await voice.connect()
} catch (error) {
  console.error('Could not connect to the realtime service:', error)
}
```

失败的握手将关闭其套接字并清除其挂起的等待。您可以重试`connect()` on the same instance.

## 与使用`CompositeVoice` {/* #using-with-compositevoice */}

使用时`CompositeVoice`, the `connect()` method forwards its options to the configured real-time provider. It throws if no real-time provider is configured:

```typescript
import { CompositeVoice } from '@mastra/core/voice'
import { OpenAIRealtimeVoice } from '@mastra/voice-openai-realtime'
const realtimeVoice = new OpenAIRealtimeVoice()
const voice = new CompositeVoice({
  realtime: realtimeVoice,
})
// This will use the OpenAIRealtimeVoice provider
await voice.connect()
```

## 笔记 {/* #notes */}

* 此方法仅由支持语音转语音功能的实时语音Provider实现
* 继承基础的提供者`connect()` implementation log a debug message and resolve without establishing a connection
* 在使用其他实时方法（例如`send()` or `answer()`
* 完成语音实例后，请致电`close()` to properly clean up resources
* 某些Provider可能会在连接丢失时自动重新连接，具体取决于其实施情况
* 连接错误通常会作为异常抛出，应该捕获和处理
