# 不可评分()

声明当前运行没有任何内容可供该记分员评估。通常从记分器函数步骤返回它`preprocess`。其余步骤将被跳过，因此永远不会调用裁判，并且平均值、门限和阈值仅包括该记分员实际评估的跑分。

使用`notScorable()` when whether a run qualifies depends on the run's own input or output, such as whether a specific tool was called. Use an [eligibility filter](/docs/evals/overview#how-live-evaluations-work)相反，当条件可以从请求上下文或实体元数据表达时。看[自定义记分员：跳过跑动](/docs/evals/custom-scorers#skipping-runs-that-cant-be-scored)进行演练。

## 使用示例 {/* #usage-example */}

以下评分员以法学硕士来评判退款处理。从未调用过的运行`refundCustomer` are declared not scorable before the judge is asked anything:

```typescript title="src/mastra/scorers/refund-judge.ts"
import { createScorer, notScorable } from '@mastra/core/evals'
import { extractToolCalls } from '@mastra/evals/scorers/utils'

export const refundJudge = createScorer({
  id: 'refund-judge',
  description: 'Judges how well refund requests were handled',
  type: 'agent',
  judge: {
    model: '__GATEWAY_OPENAI_MODEL_LUNA__',
    instructions: 'You are a strict QA reviewer for customer-support refund handling.',
  },
})
  .preprocess(({ run }) => {
    const { tools } = extractToolCalls(run.output)
    return tools.includes('refundCustomer')
      ? { tools }
      : notScorable('refundCustomer was not called')
  })
  .generateScore({
    description: 'Score the refund handling from 0 to 1',
    createPrompt: ({ run }) =>
      `Rate this refund handling from 0 to 1:\n${JSON.stringify(run.output)}`,
  })
```

**返回：** `NotScorable`. An opaque value recognized by the scorer pipeline. Return it directly from the step. Don't wrap it in another object.

## 行为 {/* #behavior */}

* 从任何功能步骤接受：`preprocess`, `analyze`, `generateScore`, or `generateReason`. Prompt-object steps can't return it because their output is produced by the model.
* 已完成的步骤保留其结果。
* `scorer.run()`解决与`notScorable: { step, reason? }` and no `score` key. See [`MastraScorer`](/reference/evals/mastra-scorer).
* 实时计分不存储分数行。[`runEvals()`](/reference/evals/run-evals) leaves the run out of averages, gates, thresholds, and the verdict, and counts it in `summary.notScorable`. Experiments set `score: null`, `error: null`, and `notScorable`.
