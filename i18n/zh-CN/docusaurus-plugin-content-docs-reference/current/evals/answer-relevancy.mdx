## 评分详情 {/* #scoring-details */}

评分器通过查询-答案对齐来评估相关性，考虑完整性和详细程度，但不考虑事实正确性。

### 评分流程 {/* #scoring-process */}

1. **语句预处理：**
   * 将输出分解为有用的语句，同时保留上下文。
2. **相关性分析：**
   * 每个语句被评估为：
     * “yes”：直接匹配的全权重
     * “unsure”：近似匹配的部分权重（默认值：0.3）
     * “no”：不相关内容的权重为零
3. **分数计算：**
   * `((direct + uncertainty * partial) / total_statements) * scale`

### 分数解读 {/* #score-interpretation */}

相关性分数介于 0 和`scale` (0 to 1 with the default scale). The ranges below assume the default scale:

* **1.0**：响应通过相关且有重点的信息完全回答了查询。
* **0.7至0.9**：响应主要回答查询，但可能包含少量不相关的内容。
* **0.4至0.6**：响应部分回答了查询，混合了相关和不相关的信息。
* **0.1至0.3**：响应包含最少的相关内容，并且很大程度上错过了查询的意图。
* **0.0**：响应完全不相关，并且不回答查询。

## 例子 {/* #example */}

评估座席响应在不同场景中的相关性：

```typescript title="src/example-answer-relevancy.ts"
import { runEvals } from '@mastra/core/evals'
import { createAnswerRelevancyScorer } from '@mastra/evals/scorers/prebuilt'
import { myAgent } from './agent'

const scorer = createAnswerRelevancyScorer({ model: '__GATEWAY_OPENAI_MODEL__' })

const result = await runEvals({
  data: [
    {
      input: 'What are the health benefits of regular exercise?',
    },
    {
      input: 'What should a healthy breakfast include?',
    },
    {
      input: 'What are the benefits of meditation?',
    },
  ],
  scorers: [scorer],
  target: myAgent,
  onItemComplete: ({ scorerResults }) => {
    console.log({
      score: scorerResults[scorer.id].score,
      reason: scorerResults[scorer.id].reason,
    })
  },
})

console.log(result.scores)
```

欲了解更多详情`runEvals`, see the [runEvals reference](/reference/evals/run-evals).

要将此记分员添加到Agent，请参阅[Scorers overview](/docs/evals/overview) guide.
