# 快速对齐记分器

这`createPromptAlignmentScorerLLM()`函数创建一个评分器，用于评估Agent响应与用户提示在意图理解和需求满足方面的一致性，以及响应的完整性和格式的适当性。

## 评分详情 {/* #scoring-details */}

### 记分器配置 {/* #scorer-configuration */}

您可以通过调整比例参数和评估模式来自定义提示对齐评分器以满足您的评分需求。

```typescript
const scorer = createPromptAlignmentScorerLLM({
  model: '__GATEWAY_OPENAI_MODEL__',
  options: {
    scale: 10, // Score from 0-10 instead of 0-1
    evaluationMode: 'both', // 'user', 'system', or 'both' (default)
  },
})
```

### 多轮对话 {/* #multi-turn-conversations */}

默认情况下，记分员只能看到当前回合。在对话中，回复如下`"A"` is meaningless on its own, so the judge can't tell what the user asked for and scores the response as misaligned.

放`includeConversationHistory` to give the judge the prior turns from the agent's memory. The judge uses them to interpret the current prompt, but still scores only the current response.

```typescript
const scorer = createPromptAlignmentScorerLLM({
  model: '__GATEWAY_OPENAI_MODEL__',
  options: {
    evaluationMode: 'user',
    includeConversationHistory: { maxMessages: 6 }, // or `true` for the last 10 messages
  },
})
```

这仅影响Agent运行，其中记分器接收记住的消息。从简单的提示字符串中获得的分数没有变化。

### 多维度分析 {/* #multi-dimensional-analysis */}

提示对齐通过根据评估模式进行调整的加权评分来评估四个关键维度的响应：

#### 用户模式（“用户”） {/* #user-mode-user */}

仅评估与用户提示的一致性：

1. **意图一致**（40%权重）：响应是否解决了用户的核心请求
2. **要求履行**（30%权重）：如果满足所有用户要求
3. **完整性**（20%权重）：响应是否详细满足用户需求
4. **回应适当性**（10% 权重）：格式和语气是否符合用户期望

#### 系统模式（“系统”） {/* #system-mode-system */}

仅评估是否符合系统准则：

1. **意图一致**（35%权重）：响应是否遵循系统行为准则
2. **要求履行**（35% 权重）：如果遵守所有系统约束
3. **完整性**（15%权重）：响应是否遵守所有系统规则
4. **回应适当性**（15% 权重）：如果格式和音调符合系统规范

#### 两种模式（“两者”-默认） {/* #both-mode-both---default */}

在一次分析中一起评估用户和系统的一致性：

* 法官根据用户提示和系统指南评估每个维度
* 使用用户模式权重组合所得的维度分数
* 评分器不计算单独的系统分数，因此结果不是用户模式和系统模式分数的混合

### 评分公式 {/* #scoring-formula */}

**用户模式：**

```text
Weighted Score = (intent_score × 0.4) + (requirements_score × 0.3) +
                 (completeness_score × 0.2) + (appropriateness_score × 0.1)
Final Score = Weighted Score × scale
```

**系统模式：**

```text
Weighted Score = (intent_score × 0.35) + (requirements_score × 0.35) +
                 (completeness_score × 0.15) + (appropriateness_score × 0.15)
Final Score = Weighted Score × scale
```

**两种模式（默认）：**

```text
Weighted Score = (intent_score × 0.4) + (requirements_score × 0.3) +
                 (completeness_score × 0.2) + (appropriateness_score × 0.1)
Final Score = Weighted Score × scale
```

在这两种模式下，每个维度的得分均来自于用户提示和系统指引的综合分析。

**权重分配原理**:

* **用户模式**：优先考虑用户满意度的意图 (40%) 和要求 (30%)
* **系统模式**：平等地平衡行为合规性（35%）和约束（35%）
* **两种模式**：在组合分析中使用用户模式权重，因此用户需求保持主要，同时仍评估系统指南

### 分数解读 {/* #score-interpretation */}

* **0.9-1.0**= 所有尺寸均具有出色的对齐度
* **0.8-0.9**= 非常好对齐，有微小间隙
* **0.7-0.8**= 良好的一致性，但缺少一些要求或完整性
* **0.6-0.7**= 适度对齐，有明显间隙
* **0.4-0.6**= 与实质性问题的一致性不佳
* **0.0-0.4**= 对齐非常差，响应不能有效地解决提示问题

### 何时使用每种模式 {/* #when-to-use-each-mode */}

**用户模式（`'user'`)**- 在以下情况下使用：

* 评估客户服务响应以提高用户满意度
* 从用户角度测试内容生成质量
* 衡量响应解决用户问题的程度
* 纯粹专注于请求满足，不受系统限制

**系统模式（`'system'`)**- 在以下情况下使用：

* 审核人工智能安全性和行为准则合规性
* 确保Agent商遵循品牌声音和语气要求
* 验证对内容政策和约束的遵守情况
* 测试系统级行为一致性

**两种模式（`'both'`)**- 使用时（默认，推荐）：

* 在遵循系统指令的同时评估响应是否满足用户请求
* 用户和系统需求都很重要的生产监控

### 多智能体系统评估 {/* #multi-agent-system-evaluation */}

比较不同Agent商或型号：

```typescript oxfmt:false
const agents = [agent1, agent2, agent3];
const testPrompts = [...]; // Array of test prompts

for (const agent of agents) {
  let totalScore = 0;
  for (const prompt of testPrompts) {
    const response = await agent.run(prompt);
    const evaluation = await scorer.run({ input: prompt, output: response });
    totalScore += evaluation.score;
  }
  console.log(`${agent.name} average alignment: ${totalScore / testPrompts.length}`);
}
```

### 优秀的对齐示例 {/* #excellent-alignment-example */}

在此示例中，响应完全解决了用户的提示并满足了所有要求。

```typescript title="src/example-excellent-prompt-alignment.ts"
import { createPromptAlignmentScorerLLM } from '@mastra/evals/scorers/prebuilt'

const scorer = createPromptAlignmentScorerLLM({
  model: '__GATEWAY_OPENAI_MODEL__',
})

const inputMessages = [
  {
    role: 'user',
    content:
      'Write a Python function to calculate factorial with error handling for negative numbers',
  },
]

const outputMessage = {
  text: `def factorial(n):
    """Calculate factorial of a number."""
    if n < 0:
        raise ValueError("Factorial not defined for negative numbers")
    if n == 0 or n == 1:
        return 1
    return n * factorial(n - 1)`,
}

const result = await scorer.run({
  input: inputMessages,
  output: outputMessage,
})

console.log(result)
```

### 评估模式示例 {/* #evaluation-mode-examples */}

#### 用户模式 ​​- 仅关注用户提示 {/* #user-mode---focus-on-user-prompt-only */}

评估响应对用户请求的满足程度，忽略系统指令：

```typescript title="src/example-user-mode.ts"
const scorer = createPromptAlignmentScorerLLM({
  model: '__GATEWAY_OPENAI_MODEL__',
  options: { evaluationMode: 'user' },
})

const result = await scorer.run({
  input: {
    inputMessages: [
      {
        role: 'user',
        content: 'Explain recursion with an example',
      },
    ],
    systemMessages: [
      {
        role: 'system',
        content: 'Always provide code examples in Python',
      },
    ],
  },
  output: {
    text: 'Recursion is when a function calls itself. For example: factorial(5) = 5 * factorial(4)',
  },
})
// Scores high for addressing user request, even without Python code
```
