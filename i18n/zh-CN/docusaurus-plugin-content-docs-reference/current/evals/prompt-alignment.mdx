# 提示词对齐评分器

`createPromptAlignmentScorerLLM()` 创建一个评分器，从意图理解、要求满足、回答完整性和格式适当性几个方面，评估 Agent 的回答与用户提示词是否一致。

## 评分详情 {/* #scoring-details */}

### 评分器配置 {/* #scorer-configuration */}

可以调整 scale 参数和评估模式，以符合所需的评分方式。

```typescript
const scorer = createPromptAlignmentScorerLLM({
  model: '__GATEWAY_OPENAI_MODEL__',
  options: {
    scale: 10, // Score from 0-10 instead of 0-1
    evaluationMode: 'both', // 'user', 'system', or 'both' (default)
  },
})
```

### 多轮对话 {/* #multi-turn-conversations */}

默认情况下，评分器只看到当前轮次。在对话中，`"A"` 这样的简短回答脱离上下文就没有意义，评判模型无法知道用户问了什么，因此会将回答评为不一致。

设置 `includeConversationHistory`，将 Agent 记忆中的先前轮次提供给评判模型。它会利用历史轮次理解当前提示词，但仍只给当前回答评分。

```typescript
const scorer = createPromptAlignmentScorerLLM({
  model: '__GATEWAY_OPENAI_MODEL__',
  options: {
    evaluationMode: 'user',
    includeConversationHistory: { maxMessages: 6 }, // or `true` for the last 10 messages
  },
})
```

此选项只影响评分器能收到历史消息的 Agent 运行。根据普通提示词字符串进行评分的运行不受影响。

### 多维度分析 {/* #multi-dimensional-analysis */}

提示词对齐评分器从四个关键维度评估回答，并根据评估模式调整加权方式：

#### 用户模式（'user'） {/* #user-mode-user */}

仅评估回答与用户提示词的一致性：

1. **意图一致性**（权重 40%）：回答是否回应用户的核心请求
2. **要求满足度**（权重 30%）：是否满足用户的所有要求
3. **完整性**（权重 20%）：回答的详细程度是否满足用户需求
4. **回答适当性**（权重 10%）：格式和语气是否符合用户预期

#### 系统模式（'system'） {/* #system-mode-system */}

仅评估回答是否遵循系统指令：

1. **意图一致性**（权重 35%）：回答是否遵循系统行为准则
2. **要求满足度**（权重 35%）：是否遵守所有系统约束
3. **完整性**（权重 15%）：是否遵循所有系统规则
4. **回答适当性**（权重 15%）：格式和语气是否符合系统要求

#### 综合模式（'both'，默认） {/* #both-mode-both---default */}

在一次分析中同时评估用户提示词和系统指令：

* 评判模型同时对照用户提示词和系统指令评估每个维度
* 使用用户模式的权重合并各维度分数
* 评分器不会单独计算系统分数，因此结果并非用户模式分数与系统模式分数的混合

### 评分公式 {/* #scoring-formula */}

**用户模式：**

```text
Weighted Score = (intent_score × 0.4) + (requirements_score × 0.3) +
                 (completeness_score × 0.2) + (appropriateness_score × 0.1)
Final Score = Weighted Score × scale
```

**系统模式：**

```text
Weighted Score = (intent_score × 0.35) + (requirements_score × 0.35) +
                 (completeness_score × 0.15) + (appropriateness_score × 0.15)
Final Score = Weighted Score × scale
```

**综合模式（默认）：**

```text
Weighted Score = (intent_score × 0.4) + (requirements_score × 0.3) +
                 (completeness_score × 0.2) + (appropriateness_score × 0.1)
Final Score = Weighted Score × scale
```

在综合模式下，每个维度的分数均来自对用户提示词和系统指令的联合分析。

**权重分配依据**：

* **用户模式**：优先考虑意图（40%）和要求（30%），以反映用户满意度
* **系统模式**：同等重视行为准则（35%）和约束条件（35%）
* **综合模式**：联合分析时采用用户模式的权重，因此仍以用户需求为主，同时评估系统指令

### 分数解读 {/* #score-interpretation */}

* **0.9-1.0** = 所有维度都高度一致
* **0.8-0.9** = 一致性很好，只有少量不足
* **0.7-0.8** = 一致性良好，但遗漏部分要求或内容不够完整
* **0.6-0.7** = 一致性一般，存在明显不足
* **0.4-0.6** = 一致性较差，存在较多问题
* **0.0-0.4** = 一致性很差，回答未能有效回应提示词

### 何时使用每种模式 {/* #when-to-use-each-mode */}

**用户模式（`'user'`）**：适用于：

* 根据用户满意度评估客服回答
* 从用户视角测试内容生成质量
* 衡量回答是否切中用户问题
* 只关注请求是否得到满足，不考虑系统约束

**系统模式（`'system'`）**：适用于：

* 审核 AI 安全性和行为准则遵循情况
* 确保 Agent 遵循品牌用语和语气要求
* 验证是否遵守内容政策和约束
* 测试系统层面的行为一致性

**综合模式（`'both'`）**：适用于（默认、推荐）：

* 评估回答是否既满足用户请求又遵循系统指令
* 同时关注用户要求和系统要求的生产监控

const prompts = [

### 多智能体系统评估 {/* #multi-agent-system-evaluation */}

比较不同的 Agent 或模型：

```typescript oxfmt:false
const agents = [agent1, agent2, agent3];
const testPrompts = [...]; // Array of test prompts

for (const agent of agents) {
  let totalScore = 0;
  for (const prompt of testPrompts) {
    const response = await agent.run(prompt);
    const evaluation = await scorer.run({ input: prompt, output: response });
    totalScore += evaluation.score;
  }
  console.log(`${agent.name} average alignment: ${totalScore / testPrompts.length}`);
}
```

import { createPromptAlignmentScorerLLM } from '@mastra/evals/scorers/prebuilt'

const scorer = createPromptAlignmentScorerLLM({
  model: '__GATEWAY_OPENAI_MODEL__',
})

// Evaluate a code generation task
const result = await scorer.run({

      role: 'user',

### 高度一致的示例 {/* #excellent-alignment-example */}

此示例中，回答充分回应用户提示词，并满足所有要求。

```typescript title="src/example-excellent-prompt-alignment.ts"
import { createPromptAlignmentScorerLLM } from '@mastra/evals/scorers/prebuilt'

const scorer = createPromptAlignmentScorerLLM({
  model: '__GATEWAY_OPENAI_MODEL__',
})

const inputMessages = [
  {
    role: 'user',
    content:
      'Write a Python function to calculate factorial with error handling for negative numbers',
  },
]

const outputMessage = {
  text: `def factorial(n):
    """Calculate factorial of a number."""
    if n < 0:
        raise ValueError("Factorial not defined for negative numbers")
    if n == 0 or n == 1:
        return 1
    return n * factorial(n - 1)`,
}

const result = await scorer.run({
  input: inputMessages,
  output: outputMessage,
})

console.log(result)
```

### 高度一致的输出 {/* #excellent-alignment-output */}

回答提供了所要求的 Python 阶乘函数，并处理负数输入，因此获得高分。

```typescript oxfmt:false

The code format is appropriate and the implementation is complete.'
}
```

## 与其他评分器比较 {/* #comparison-with-other-scorers */}

| 方面 | 提示词对齐 | 答案相关性 | 忠实性 |
| - | - | - | - |
| **关注点** | 多维度的提示词遵循情况 | 问题与回答的相关性 | 是否有上下文依据 |
| **评估内容** | 意图、要求、完整性、格式 | 与问题的语义相似度 | 与上下文的事实一致性 |
| **适用场景** | 一般提示词遵循评估 | 信息检索 | RAG／基于上下文的系统 |
| **维度** | 四个加权维度 | 单一相关性维度 | 单一忠实性维度 |
