# 快速检查

Quick Checks 是零法学硕士、可组合的微型评分器，适用于常见断言。他们插入现有的`scorers: [...]`使用记分器的任何地方的数组：在`runEvals`、现场评分、实验和工作室。

在内部它们是标准的`createScorer()` instances, so they have the same observability, storage, and pipeline integration as any other scorer.

:::note\[注册检查以保留其分数]

仅当检查在 Mastra 实例上注册时，检查的分数才会写入分数存储，同时`storage`. Each check has a fixed id (`checks.includes()` is `check-includes`, `checks.calledTool()`是`check-called-tool`，等等），因此一个注册实例涵盖了该检查的每一次使用，无论其参数如何。看[分数持久性](/docs/evals/overview#score-persistence).

:::

## 使用示例 {/* #usage-example */}

```typescript title="src/evals/weather-checks.ts"
import { checks } from '@mastra/evals/checks'
import { runEvals } from '@mastra/core/evals'
import { myAgent } from '../agents'

const result = await runEvals({
  data: [{ input: 'What is the weather in Brooklyn?' }],
  target: myAgent,
  scorers: [
    checks.includes('sunny'),
    checks.calledTool('get_weather'),
    checks.toolOrder(['get_weather', 'summarize']),
    checks.noToolErrors(),
  ],
})

console.log(result.scores)
```

## 文本检查 {/* #text-checks */}

### `checks.includes(expected, options?)` {/* #checksincludesexpected-options */}

如果Agent的输出文本包含预期的子字符串，则得分 1，否则得分 0。


## Tool调用检查 {/* #tool-call-checks */}

如果按指定顺序调用Tool，则得分 1。使用宽松的匹配。允许预期Tool之间的其他Tool调用。

### `checks.maxToolCalls(max)` {/* #checksmaxtoolcallsmax */}

如果Agent使用的数量不超过，则得分 1`max` tool calls.


### `checks.usedNoTools()` {/* #checksusednotools */}

如果Agent根本没有调用任何Tool，则得分 1。

```typescript
checks.usedNoTools()
```

返回：`1` if no tools were called, `0` otherwise.

### `checks.noToolErrors()` {/* #checksnotoolerrors */}

如果没有任何Tool调用导致错误状态，则得分 1。检测到两个错误结果（`result.error` present) and incomplete tool calls (`state === 'call'`).

```typescript
checks.noToolErrors()
```

返回：`1` if all tool calls succeeded, `0` otherwise.

## 与其他记分员结合检查 {/* #combining-checks-with-other-scorers */}

检查使用基于 LLM 和基于代码的评分器在同一`scorers` array:

```typescript title="src/evals/combined-eval.ts"
import { checks } from '@mastra/evals/checks'
import { createAnswerRelevancyScorer } from '@mastra/evals/scorers/prebuilt'
import { runEvals } from '@mastra/core/evals'
import { myAgent } from '../agents'

const result = await runEvals({
  data: [{ input: 'What is the weather in Brooklyn?' }],
  target: myAgent,
  scorers: [
    // Zero-LLM checks
    checks.includes('Brooklyn'),
    checks.calledTool('get_weather'),
    checks.noToolErrors(),
    // LLM-based scorer
    createAnswerRelevancyScorer({ model: '__GATEWAY_OPENAI_MODEL_LUNA__' }),
  ],
})
```

## 多回合行为 {/* #multi-turn-behavior */}

检查读取累计`run.output`, so in a [multi-turn eval](/docs/evals/multi-turn) they see every turn. `checks.calledTool('get_weather', { times: 2 })` counts calls across the whole conversation, and `checks.includes()` searches all assistant text. Use per-turn `turns[].scorers` when a specific turn has to satisfy the check.
