# 上下文精确评分器

这`createContextPrecisionScorer()`函数创建一个评分器，用于评估检索到的上下文片段的相关性和位置，以生成预期输出。它使用**平均精度 (MAP)**&#x5956;励将相关上下文置于序列较早位置的系统。

它对于以下用例特别有用：

## RAG系统评估 {/* #rag-system-evaluation */}

非常适合评估 RAG 管道中检索到的上下文，其中：

* 上下文排序对于模型性能很重要
* 您需要衡量基本相关性之外的检索质量
* 早期相关背景比后期相关背景更有价值

## 上下文窗口优化 {/* #context-window-optimization */}

在优化上下文选择时使用：

* 有限的上下文窗口
* 代币预算限制
* 多步推理任务

任何一个`context` or `contextExtractor` must be provided. `contextExtractor` is only called when the run input and output have agent shapes: the input has `inputMessages`, `rememberedMessages` and `systemMessages` arrays plus a `taggedSystemMessages` object, and the output is an array of messages. For any other input/output shape the scorer uses `context`. When neither is provided, the scorer throws.

如果你通过了`context`, the array must be non-empty. The constructor throws `Context array cannot be empty if provided` even when `contextExtractor` is also configured. When only `contextExtractor` is configured and the run isn't agent-shaped, there's no context to score against and evaluation throws `No context available for evaluation`.

## 评分详情 {/* #scoring-details */}

### 平均精度 (MAP) {/* #mean-average-precision-map */}

上下文精度用途**Mean Average Precision** to evaluate both relevance and positioning:

1. **情境评估**：每个上下文片段都被分类为与生成预期输出相关或不相关
2. **精密计算**：对于位置处的每个相关上下文`i`, precision = `relevant_items_so_far / (i + 1)`
3. **平均精度**：将所有精度值相加并除以相关项目总数
4. **最终成绩**：乘以比例因子并四舍五入到小数点后两位

### 评分公式 {/* #scoring-formula */}

```text
MAP = (Σ Precision@k) / R

Where:
- Precision@k = (relevant items in positions 1...k) / k
- R = total number of relevant items
- Only calculated at positions where relevant items appear
```

### 分数解读 {/* #score-interpretation */}

* **0.9-1.0**：出色的精确度 - 所有相关上下文均按顺序排列
* **0.7-0.8**：精度高 - 最相关的上下文位置良好
* **0.4-0.6**：中等精度 - 相关上下文与不相关上下文混合在一起
* **0.1-0.3**：精度差 - 相关上下文很少或定位不当
* **0.0**: 没有找到相关上下文

### 原因分析 {/* #reason-analysis */}

原因字段解释：

* 哪些上下文片段被认为相关/不相关
* 定位如何影响 MAP 计算
* 评估中使用的具体相关性标准

### 优化见解 {/* #optimization-insights */}

使用结果来：

* **提高检索能力**：在排名前过滤掉不相关的上下文
* **优化排名**：确保相关背景尽早浮现
* **调整块大小**：平衡上下文细节与相关精度
* **评估嵌入**：测试不同的嵌入模型以获得更好的检索

### 计算示例 {/* #example-calculation */}

语境：`[relevant, irrelevant, relevant, irrelevant]`

* 位置 0：相关 → 精度 = 1/1 = 1.0
* 位置1：跳过（无关）
* 位置 2：相关 → 精度 = 2/3 = 0.67
* 位置3：跳过（无关）

平均MAP = (1.0 + 0.67) / 2 = 0.835 ≈**0.83**

## 记分器配置 {/* #scorer-configuration */}

### 动态上下文提取 {/* #dynamic-context-extraction */}

```typescript
const scorer = createContextPrecisionScorer({
  model: '__GATEWAY_OPENAI_MODEL__',
  options: {
    contextExtractor: (input, output) => {
      // Extract context dynamically based on the query
      const query = input?.inputMessages?.[0]?.content || ''

      // Example: Retrieve from a vector database
      const searchResults = vectorDB.search(query, { limit: 10 })
      return searchResults.map(result => result.content)
    },
    scale: 1,
  },
})
```

### 大上下文评估 {/* #large-context-evaluation */}

```typescript
const scorer = createContextPrecisionScorer({
  model: '__GATEWAY_OPENAI_MODEL__',
  options: {
    context: [
      // Simulate retrieved documents from vector database
      'Document 1: Highly relevant content...',
      'Document 2: Somewhat related content...',
      'Document 3: Tangentially related...',
      'Document 4: Not relevant...',
      'Document 5: Highly relevant content...',
      // ... up to dozens of context pieces
    ],
  },
})
```

## 例子 {/* #example */}

评估RAG系统上下文对不同查询的检索精度：

```typescript title="src/example-context-precision.ts"
import { runEvals } from '@mastra/core/evals'
import { createContextPrecisionScorer } from '@mastra/evals/scorers/prebuilt'
import { myAgent } from './agent'

const scorer = createContextPrecisionScorer({
  model: '__GATEWAY_OPENAI_MODEL__',
  options: {
    contextExtractor: (input, output) => {
      // Extract context from agent's retrieved documents
      return output.metadata?.retrievedContext || []
    },
  },
})

const result = await runEvals({
  data: [
    {
      input: 'How does photosynthesis work in plants?',
    },
    {
      input: 'What are the mental and physical benefits of exercise?',
    },
  ],
  scorers: [scorer],
  target: myAgent,
  onItemComplete: ({ scorerResults }) => {
    console.log({
      score: scorerResults[scorer.id].score,
      reason: scorerResults[scorer.id].reason,
    })
  },
})

console.log(result.scores)
```

欲了解更多详情`runEvals`, see the [runEvals reference](/reference/evals/run-evals).

要将此记分员添加到Agent，请参阅[Scorers overview](/docs/evals/overview#adding-scorers-to-agents) guide.

## 与上下文相关性的比较 {/* #comparison-with-context-relevance */}

选择适合您需求的记分器：

|使用案例|上下文相关性 |上下文精度 |
| - | - | - |
|**RAG evaluation** | When usage matters | When ranking matters |
| **Context quality** | Nuanced levels | Binary relevance |
| **Missing detection** | ✓ Identifies gaps | ✗ Not evaluated |
| **Usage tracking** | ✓ Tracks utilization | ✗ Not considered |
| **Position sensitivity** | ✗ Position agnostic | ✓ Rewards early placement |
