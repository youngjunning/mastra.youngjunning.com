# 上下文精度评分器

`createContextPrecisionScorer()` 函数创建一个评分器，评估检索到的上下文片段与生成预期输出的相关程度，以及这些片段在序列中的位置。它使用**平均精度均值 (MAP)**，对将相关上下文排在前面的系统给予更高评分。

它尤其适用于以下场景：

## RAG 系统评估 {/* #rag-system-evaluation */}

适合评估 RAG 流程中检索到的上下文，尤其在以下情况下：

* 上下文的排列顺序会影响模型表现
* 需要衡量基本相关性之外的检索质量
* 排在前面的相关上下文比排在后面的更有价值

## 上下文窗口优化 {/* #context-window-optimization */}

在为以下场景优化上下文选择时使用：

* 上下文窗口有限
* Token 预算受限
* 多步推理任务

`context` 和 `contextExtractor` 必须至少提供一个。只有运行输入和输出符合 Agent 的数据结构时，才会调用 `contextExtractor`：输入须包含 `inputMessages`、`rememberedMessages` 和 `systemMessages` 数组，以及 `taggedSystemMessages` 对象；输出须为消息数组。对于其他输入或输出结构，评分器会使用 `context`。两者均未提供时，评分器会抛出错误。

如果传入 `context`，数组不能为空。构造函数会对空数组抛出 `Context array cannot be empty if provided`，即使同时配置了 `contextExtractor` 也是如此。如果只配置了 `contextExtractor`，而运行数据不符合 Agent 的数据结构，就没有可用于评分的上下文，评估时会抛出 `No context available for evaluation`。

## 评分详情 {/* #scoring-details */}

### 平均精度均值 (MAP) {/* #mean-average-precision-map */}

上下文精度使用**平均精度均值 (MAP)**，同时评估上下文的相关性和排列位置：

1. **上下文评估**：判断每个上下文片段是否与生成预期输出相关
2. **精度计算**：对于位置为 `i` 的每个相关上下文，precision = `relevant_items_so_far / (i + 1)`
3. **平均精度**：将所有精度值相加，再除以相关片段总数
4. **最终分数**：乘以缩放系数，再四舍五入保留两位小数

### 评分公式 {/* #scoring-formula */}

```text
MAP = (Σ Precision@k) / R

Where:
- Precision@k = (relevant items in positions 1...k) / k
- R = total number of relevant items
- Only calculated at positions where relevant items appear
```

### 分数解读 {/* #score-interpretation */}

* **0.9-1.0**：精度极高，所有相关上下文都排在序列前面
* **0.7-0.8**：精度较高，大部分相关上下文都排在合适的位置
* **0.4-0.6**：精度中等，相关和不相关的上下文交错排列
* **0.1-0.3**：精度较低，相关上下文很少，或排序位置不佳
* **0.0**：未找到相关上下文

### 原因分析 {/* #reason-analysis */}

原因字段会说明：

* 哪些上下文片段被判定为相关或不相关
* 排列位置如何影响 MAP 计算
* 评估时采用了哪些具体的相关性标准

### 优化建议 {/* #optimization-insights */}

可以根据结果：

* **改进检索**：在排序前过滤不相关的上下文
* **优化排序**：让相关上下文尽量排在前面
* **调整分块大小**：在上下文细节和相关性精度之间取得平衡
* **评估嵌入模型**：测试不同的嵌入模型，以改进检索效果

### 计算示例 {/* #example-calculation */}

上下文：`[relevant, irrelevant, relevant, irrelevant]`

* 位置 0：相关 → 精度 = 1/1 = 1.0
* 位置 1：跳过（不相关）
* 位置 2：相关 → 精度 = 2/3 = 0.67
* 位置 3：跳过（不相关）

MAP = (1.0 + 0.67) / 2 = 0.835 ≈ **0.83**

## 评分器配置 {/* #scorer-configuration */}

### 动态上下文提取 {/* #dynamic-context-extraction */}

```typescript
const scorer = createContextPrecisionScorer({
  model: '__GATEWAY_OPENAI_MODEL__',
  options: {
    contextExtractor: (input, output) => {
      // Extract context dynamically based on the query
      const query = input?.inputMessages?.[0]?.content || ''

      // Example: Retrieve from a vector database
      const searchResults = vectorDB.search(query, { limit: 10 })
      return searchResults.map(result => result.content)
    },
    scale: 1,
  },
})
```

### 大量上下文的评估 {/* #large-context-evaluation */}

```typescript
const scorer = createContextPrecisionScorer({
  model: '__GATEWAY_OPENAI_MODEL__',
  options: {
    context: [

      'Document 1: Highly relevant content...',
      'Document 2: Somewhat related content...',
      'Document 3: Tangentially related...',
      'Document 4: Not relevant...',
      'Document 5: Highly relevant content...',
      // ... up to dozens of context pieces
    ],
  },
})
```

## 示例 {/* #example */}

评估 RAG 系统针对不同查询检索上下文的精度：

```typescript title="src/example-context-precision.ts"
import { runEvals } from '@mastra/core/evals'
import { createContextPrecisionScorer } from '@mastra/evals/scorers/prebuilt'
import { myAgent } from './agent'

const scorer = createContextPrecisionScorer({
  model: '__GATEWAY_OPENAI_MODEL__',
  options: {
    contextExtractor: (input, output) => {
      // Extract context from agent's retrieved documents
      return output.metadata?.retrievedContext || []
    },
  },
})

const result = await runEvals({
  data: [
    {
      input: 'How does photosynthesis work in plants?',
    },
    {
      input: 'What are the mental and physical benefits of exercise?',
    },
  ],
  scorers: [scorer],
  target: myAgent,
  onItemComplete: ({ scorerResults }) => {
    console.log({
      score: scorerResults[scorer.id].score,
      reason: scorerResults[scorer.id].reason,
    })
  },
})

console.log(result.scores)
```

有关 `runEvals` 的更多信息，请参阅 [runEvals 参考文档](/reference/evals/run-evals)。

要将此评分器添加到 Agent，请参阅[评分器概览](/docs/evals/overview#adding-scorers-to-agents)指南。

## 与上下文相关性的比较 {/* #comparison-with-context-relevance */}

根据需求选择合适的评分器：

|使用场景|上下文相关性 |上下文精度 |
| - | - | - |
|**RAG 评估** | 关注上下文是否被使用 | 关注上下文的排序 |
| **上下文质量** | 区分细致的相关性程度 | 只区分相关与不相关 |
| **缺失检测** | ✓ 识别信息缺口 | ✗ 不评估 |
| **使用情况跟踪** | ✓ 跟踪上下文的使用情况 | ✗ 不考虑 |
| **位置敏感性** | ✗ 不考虑排列位置 | ✓ 奖励靠前的位置 |
