# 答案相似度评分器

`createAnswerSimilarityScorer()` 函数创建一个评分器，用于评估 Agent 输出与标准答案的相似程度。它专为已知预期答案的 CI/CD 测试场景设计，帮助你检查结果是否长期保持一致。

此函数返回 MastraScorer 类的实例。`.run()` 方法接受与其他评分器相同的输入（参见 [MastraScorer 参考文档](./mastra-scorer)），但要求在 run 对象中提供标准答案。`options.requireGroundTruth` 为 `true`（默认值）时，缺少标准答案的 run 会抛出错误；设为 `false` 时，此类 run 得 0 分。

## 评分详情 {/* #scoring-details */}

评分器采用多步骤流程：

1. **提取**：将输出和标准答案拆分为语义单元。
1. **分析**：比较语义单元，找出匹配、矛盾和缺失之处。
1. **评分**：计算加权相似度，并对矛盾内容扣分。
1. **解释**：生成易读的得分说明。

得分计算方式：`max(0, min(1, base_score - contradiction_penalty - extra_info_penalty)) × scale`

`base_score` 是各项匹配得分之和，减去每个缺失单元对应的 `missingPenalty`，再除以 `ground_truth_units × (1 + exactMatchBonus)`。标准答案不含任何单元时，得分为 0。

## 例子 {/* #example */}

在不同场景下评估 Agent 响应与标准答案的相似度：

```typescript title="src/example-answer-similarity.ts"
import { runEvals } from '@mastra/core/evals'
import { createAnswerSimilarityScorer } from '@mastra/evals/scorers/prebuilt'
import { myAgent } from './agent'

const scorer = createAnswerSimilarityScorer({ model: '__GATEWAY_OPENAI_MODEL__' })

const result = await runEvals({
  data: [
    {
      input: 'What is 2+2?',
      groundTruth: '4',
    },
    {
      input: 'What is the capital of France?',
      groundTruth: 'The capital of France is Paris',
    },
    {
      input: 'What are the primary colors?',
      groundTruth: 'The primary colors are red, blue, and yellow',
    },
  ],
  scorers: [scorer],
  target: myAgent,
  onItemComplete: ({ scorerResults }) => {
    console.log({
      score: scorerResults[scorer.id].score,
      reason: scorerResults[scorer.id].reason,
    })
  },
})

console.log(result.scores)
```

有关 `runEvals` 的更多信息，请参阅 [runEvals 参考文档](/reference/evals/run-evals)。

要将此评分器添加到 Agent，请参阅 [Scorers 概览](/docs/evals/overview#adding-scorers-to-agents) 指南。
