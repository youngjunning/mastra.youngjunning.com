# 答案相似度评分器

这`createAnswerSimilarityScorer()`函数创建一个评分器，用于评估Agent的输出与真实答案的相似程度。该评分器专为 CI/CD 测试场景而设计，在这些场景中，您有预期的答案并希望确保随着时间的推移保持一致性。

## 评分详情 {/* #scoring-details */}

记分器使用多步骤过程：

1. **提炼**：将输出和基本事实分解为语义单元
2. **分析**：比较单位并识别匹配、矛盾和差距
3. **分数**：计算加权相似度并惩罚矛盾
4. **原因**：生成人类可读的解释

分数计算：`max(0, min(1, base_score - contradiction_penalty - extra_info_penalty)) × scale`

`base_score`是每场比赛的积分总和，减去`missingPenalty` for each missing unit, divided by `ground_truth_units × (1 + exactMatchBonus)`. The score is 0 when the ground truth has no units.

## 例子 {/* #example */}

评估Agent响应在不同场景中与真实情况的相似性：

```typescript title="src/example-answer-similarity.ts"
import { runEvals } from '@mastra/core/evals'
import { createAnswerSimilarityScorer } from '@mastra/evals/scorers/prebuilt'
import { myAgent } from './agent'

const scorer = createAnswerSimilarityScorer({ model: '__GATEWAY_OPENAI_MODEL__' })

const result = await runEvals({
  data: [
    {
      input: 'What is 2+2?',
      groundTruth: '4',
    },
    {
      input: 'What is the capital of France?',
      groundTruth: 'The capital of France is Paris',
    },
    {
      input: 'What are the primary colors?',
      groundTruth: 'The primary colors are red, blue, and yellow',
    },
  ],
  scorers: [scorer],
  target: myAgent,
  onItemComplete: ({ scorerResults }) => {
    console.log({
      score: scorerResults[scorer.id].score,
      reason: scorerResults[scorer.id].reason,
    })
  },
})

console.log(result.scores)
```

欲了解更多详情`runEvals`, see the [runEvals reference](/reference/evals/run-evals).

要将此记分员添加到Agent，请参阅[Scorers overview](/docs/evals/overview#adding-scorers-to-agents) guide.
