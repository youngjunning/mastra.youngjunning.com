# 幻觉记分员

这`createHallucinationScorer()`函数通过将其输出与提供的上下文进行比较来评估法学硕士是否生成事实上正确的信息。该评分器通过识别上下文和输出之间的直接矛盾来测量幻觉。

## 评分详情 {/* #scoring-details */}

评分者通过矛盾检测和无支持的主张分析来评估幻觉。

### 评分流程 {/* #scoring-process */}

1. 从输出中提取声明：
   * 将Agent的回应分解为事实主张
   * 包括数值和日期
2. 根据提供的上下文检查每个声明：
   * 将主张与上下文进行比较
   * 将直接冲突标记为幻觉
   * 将不受支持的主张视为幻觉
   * 评估数值准确性
   * 考虑近似上下文
3. 计算幻觉分数：
   * 计算幻觉陈述（矛盾和无根据的主张）
   * 除以报表总数
   * 缩放至配置范围

最终成绩：`min(1, hallucinated_statements / total_statements) * (scale || 1)`, rounded to two decimal places, when `total_statements > 0`, otherwise `0`.

### 重要考虑因素 {/* #important-considerations */}

* 上下文中不存在的主张被视为幻觉
* 除非明确支持，否则主观主张都是幻觉
* 允许对上下文中的事实使用推测性语言（“可能”、“可能”）
* 与上下文无关的事实的推测性语言被视为幻觉
* 空输出导致零幻觉
* 数值评估考虑：
  * 适合比例的精度
  * 上下文近似
  * 明确的精度指标

### 分数解读 {/* #score-interpretation */}

幻觉分数介于 0 和`scale` (0 to 1 with the default scale). The ranges below assume the default scale:

* **0.0**：没有幻觉，所有说法均符合上下文。
* **0.3至0.4**：低幻觉，一些矛盾。
* **0.5至0.6**：混合幻觉，几个矛盾。
* **0.7至0.8**：高度幻觉，很多矛盾。
* **0.9至1.0**：完全是幻觉，大多数或所有说法与上下文相矛盾。

分数代表幻觉的程度 - 分数越低表明事实与所提供的背景更好地吻合

## 示例 {/* #examples */}

### 静态上下文 {/* #static-context */}

当您知道基本事实以进行比较时，请使用静态上下文：

```typescript title="src/example-static-context.ts"
import { createHallucinationScorer } from '@mastra/evals/scorers/prebuilt'

const scorer = createHallucinationScorer({
  model: '__GATEWAY_OPENAI_MODEL__',
  options: {
    context: [
      'The first iPhone was announced on January 9, 2007.',
      'It was released on June 29, 2007.',
      'Steve Jobs introduced it at Macworld.',
    ],
  },
})
```

### 动态上下文`getContext` {/* #dynamic-context-with-getcontext */}

使用`getContext` for live scoring scenarios where context comes from tool results:

```typescript title="src/example-dynamic-context.ts"
import { createHallucinationScorer } from '@mastra/evals/scorers/prebuilt'
import { extractToolResults } from '@mastra/evals/scorers/utils'

const scorer = createHallucinationScorer({
  model: '__GATEWAY_OPENAI_MODEL__',
  options: {
    getContext: ({ run, step }) => {
      // Extract tool results as context
      const toolResults = extractToolResults(run.output)
      return toolResults.map(t => JSON.stringify({ tool: t.toolName, result: t.result }))
    },
  },
})
```

### 与Agent实时计分 {/* #live-scoring-with-agent */}

将记分器连接到Agent进行实时评估：

```typescript title="src/example-live-scoring.ts"
import { Agent } from '@mastra/core/agent'
import { createHallucinationScorer } from '@mastra/evals/scorers/prebuilt'
import { extractToolResults } from '@mastra/evals/scorers/utils'

const hallucinationScorer = createHallucinationScorer({
  model: '__GATEWAY_OPENAI_MODEL__',
  options: {
    getContext: ({ run }) => {
      const toolResults = extractToolResults(run.output)
      return toolResults.map(t => JSON.stringify({ tool: t.toolName, result: t.result }))
    },
  },
})

const agent = new Agent({
  id: 'my-agent',
  name: 'my-agent',
  model: '__GATEWAY_OPENAI_MODEL__',
  instructions: 'You are a helpful assistant.',
  evals: {
    scorers: [hallucinationScorer],
  },
})
```

### 批量评估`runEvals` {/* #batch-evaluation-with-runevals */}

```typescript title="src/example-batch-evals.ts"
import { runEvals } from '@mastra/core/evals'
import { createHallucinationScorer } from '@mastra/evals/scorers/prebuilt'
import { myAgent } from './agent'

const scorer = createHallucinationScorer({
  model: '__GATEWAY_OPENAI_MODEL__',
  options: {
    context: ['Known fact 1', 'Known fact 2'],
  },
})

const result = await runEvals({
  data: [{ input: 'Tell me about topic A' }, { input: 'Tell me about topic B' }],
  scorers: [scorer],
  target: myAgent,
  onItemComplete: ({ scorerResults }) => {
    console.log({
      score: scorerResults[scorer.id].score,
      reason: scorerResults[scorer.id].reason,
    })
  },
})

console.log(result.scores)
```

欲了解更多详情`runEvals`, see the [runEvals reference](/reference/evals/run-evals).

要将此记分员添加到Agent，请参阅[Scorers overview](/docs/evals/overview#adding-scorers-to-agents) guide.
