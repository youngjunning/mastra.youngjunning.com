# Hallucination 评分器

`createHallucinationScorer()` 函数将 LLM 输出与提供的上下文比较，评估生成的信息是否符合事实。此评分器通过识别上下文与输出之间的直接矛盾来衡量幻觉程度。

## 评分详情 {/* #scoring-details */}

评分器通过检测矛盾和分析缺乏依据的陈述来评估幻觉。

### 评分流程 {/* #scoring-process */}

1. 从输出中提取陈述：
   * 将 Agent 响应拆解为事实陈述
   * 包括数值和日期
2. 根据所提供的上下文核对每项陈述：
   * 比较陈述与上下文
   * 将直接矛盾标记为幻觉
   * 将缺乏依据的陈述识别为幻觉
   * 评估数值准确性
   * 考虑上下文中的近似表达
3. 计算幻觉分数：
   * 统计存在幻觉的陈述（相互矛盾或缺乏依据的陈述）
   * 除以陈述总数
   * 根据配置的范围缩放分数

最终分数为 `min(1, hallucinated_statements / total_statements) * (scale || 1)`；当 `total_statements > 0` 时四舍五入至小数点后两位，否则为 `0`。

### 重要考虑因素 {/* #important-considerations */}

* 上下文中未出现的陈述被视为幻觉
* 除非有明确依据，否则主观陈述也被视为幻觉
* 对上下文中已有的事实，可以使用推测性措辞（如“可能”“也许”）
* 对上下文中不存在的事实使用推测性措辞，仍会被视为幻觉
* 空输出的幻觉数量为零
* 数值评估会考虑：
  * 与数值规模相称的精度
  * 根据上下文允许的近似值
  * 明确的精度标识

### 分数解读 {/* #score-interpretation */}

幻觉分数介于 0 和 `scale` 之间（默认 scale 下为 0 到 1）。以下范围以默认 scale 为准：

* **0.0**：没有幻觉，所有陈述均与上下文一致。
* **0.3 至 0.4**：幻觉程度低，存在少量矛盾。
* **0.5 至 0.6**：幻觉程度中等，存在多处矛盾。
* **0.7 至 0.8**：幻觉程度高，存在大量矛盾。
* **0.9 至 1.0**：幻觉程度极高，大多数或全部陈述与上下文矛盾。

分数表示幻觉程度：分数越低，与所提供上下文的事实一致性越高。

## 示例 {/* #examples */}

### 静态上下文 {/* #static-context */}

已知可供比较的事实依据时，使用静态上下文：

```typescript title="src/example-static-context.ts"
import { createHallucinationScorer } from '@mastra/evals/scorers/prebuilt'

const scorer = createHallucinationScorer({
  model: '__GATEWAY_OPENAI_MODEL__',
  options: {
    context: [
      'The first iPhone was announced on January 9, 2007.',
      'It was released on June 29, 2007.',
      'Steve Jobs introduced it at Macworld.',
    ],
  },
})
```

### 使用 `getContext` 动态获取上下文 {/* #dynamic-context-with-getcontext */}

如果上下文来自工具结果，可使用 `getContext` 进行实时评分：

```typescript title="src/example-dynamic-context.ts"
import { createHallucinationScorer } from '@mastra/evals/scorers/prebuilt'
import { extractToolResults } from '@mastra/evals/scorers/utils'

const scorer = createHallucinationScorer({
  model: '__GATEWAY_OPENAI_MODEL__',
  options: {
    getContext: ({ run, step }) => {
      // Extract tool results as context
      const toolResults = extractToolResults(run.output)
      return toolResults.map(t => JSON.stringify({ tool: t.toolName, result: t.result }))
    },
  },
})
```

### 对 Agent 实时评分 {/* #live-scoring-with-agent */}

将评分器添加到 Agent，以进行实时评估：

```typescript title="src/example-live-scoring.ts"
import { Agent } from '@mastra/core/agent'
import { createHallucinationScorer } from '@mastra/evals/scorers/prebuilt'
import { extractToolResults } from '@mastra/evals/scorers/utils'

const hallucinationScorer = createHallucinationScorer({
  model: '__GATEWAY_OPENAI_MODEL__',
  options: {
    getContext: ({ run }) => {
      const toolResults = extractToolResults(run.output)
      return toolResults.map(t => JSON.stringify({ tool: t.toolName, result: t.result }))
    },
  },
})

const agent = new Agent({
  id: 'my-agent',
  name: 'my-agent',
  model: '__GATEWAY_OPENAI_MODEL__',
  instructions: 'You are a helpful assistant.',
  evals: {
    scorers: [hallucinationScorer],
  },
})
```

### 使用 `runEvals` 批量评估 {/* #batch-evaluation-with-runevals */}

```typescript title="src/example-batch-evals.ts"
import { runEvals } from '@mastra/core/evals'
import { createHallucinationScorer } from '@mastra/evals/scorers/prebuilt'
import { myAgent } from './agent'

const scorer = createHallucinationScorer({
  model: '__GATEWAY_OPENAI_MODEL__',
  options: {
    context: ['Known fact 1', 'Known fact 2'],
  },
})

const result = await runEvals({
  data: [{ input: 'Tell me about topic A' }, { input: 'Tell me about topic B' }],
  scorers: [scorer],
  target: myAgent,
  onItemComplete: ({ scorerResults }) => {
    console.log({
      score: scorerResults[scorer.id].score,
      reason: scorerResults[scorer.id].reason,
    })
  },
})

console.log(result.scores)
```

有关 `runEvals` 的详细信息，请参阅 [runEvals 参考文档](/reference/evals/run-evals)。

要将此评分器添加到 Agent，请参阅 [Scorers 概述](/docs/evals/overview#adding-scorers-to-agents)指南。
