# filterRun()

根据声明式选项创建 `prepareRun` 函数。将结果传给 `createScorer()`，以过滤消息并限制上下文大小。在评分器流水线运行前，还会移除不需要的字段。

使用 [`filterRun()`](#usage-example) 进行声明式过滤。如果需要命令式逻辑，可直接编写自定义 `prepareRun` 函数，处理 `filterRun()` 未涵盖的情况。详见[自定义评分器：输入过滤](/docs/evals/custom-scorers#input-filtering)。

## 使用示例 {/* #usage-example */}

以下示例创建的评分器只接收工具调用和文本消息，并将上下文限制为最近 20 条消息：

```typescript title="src/mastra/scorers/tool-scorer.ts"
import { createScorer, filterRun } from '@mastra/core/evals'

const toolScorer = createScorer({
  id: 'tool-usage',
  description: 'Evaluates tool usage patterns',
  type: 'agent',
  prepareRun: filterRun({
    partTypes: ['tool-invocation', 'text'],
    maxRememberedMessages: 20,
  }),
}).generateScore(({ run }) => {
  // run.input.rememberedMessages contains only tool and text messages
  // run.output contains only tool and text messages
  return 1
})
```

### 按工具名称过滤 {/* #filter-by-tool-name */}

只保留涉及特定工具的消息：

```typescript
import { createScorer, filterRun } from '@mastra/core/evals'

const fileEditScorer = createScorer({
  id: 'file-edit-quality',
  description: 'Evaluates file editing patterns',
  type: 'agent',
  prepareRun: filterRun({
    toolNames: ['write_file', 'string_replace_lsp', 'view'],
  }),
}).generateScore(({ run }) => {
  // Only messages with these tool calls remain
  return 1
})
```

### 移除字段 {/* #drop-fields */}

移除评分器不需要的字段：

```typescript
import { createScorer, filterRun } from '@mastra/core/evals'

const simpleScorer = createScorer({
  id: 'response-length',
  description: 'Checks response length',
  type: 'agent',
  prepareRun: filterRun({
    dropRequestContext: true,
    dropExpectedTrajectory: true,
    dropGroundTruth: true,
    maxOutputMessages: 5,
  }),
}).generateScore(({ run }) => {
  return run.output.length > 0 ? 1 : 0
})
```

**返回值：** `(run: ScorerRun) => ScorerRun`。此函数可作为 `prepareRun` 选项传给 [`createScorer()`](/reference/evals/create-scorer)。

## 片段类型 {/* #part-types */}

`partTypes` 选项接受 `MastraPartType` 值。每个值都按前缀匹配，因此 `'data-'` 可匹配所有数据片段类型。

| 类型 | 说明 |
| - | - |
| `'text'` | 文本内容片段 |
| `'tool-invocation'` | 工具调用及结果片段 |
| `'reasoning'` | 思维链推理片段 |
| `'step-start'` | 步骤标记片段 |
| `'image'` | 图片片段 |
| `'file'` | 文件片段 |
| `'source'` | 来源引用片段 |
| `'source-document'` | 来源文档片段 |
| `'data-'` | 所有数据片段（匹配任何 `data-*` 前缀） |
| `'data-om-'` | 观察记忆数据片段 |
| `'data-workspace-'` | Workspace 数据片段 |
| `'data-sandbox-'` | Sandbox 数据片段 |
| `'data-tool-'` | 工具相关数据片段 |

## 过滤行为 {/* #filtering-behavior */}

- **片段类型过滤**：当 `input.rememberedMessages` 和 `output` 包含 Agent 消息数组时，均会应用此过滤。
- **工具名称过滤**：仅影响包含工具调用的消息。不含工具调用的消息只按 `partTypes` 过滤；未设置 `partTypes` 时会直接保留。
- **系统消息**（`systemMessages`、`taggedSystemMessages`）：无论 `partTypes` 或 `toolNames` 如何设置，始终不会被过滤。
- **消息数量限制**（`maxRememberedMessages`、`maxOutputMessages`）：在按类型和工具过滤后应用，保留最近的消息。
- 同时设置 `partTypes` 和 `toolNames` 时，包含工具调用的消息必须同时满足两项过滤条件才会保留。
