# 忠实性评分器

`createFaithfulnessScorer()` 函数根据给定上下文评估 LLM 输出的事实准确性。它从输出中提取主张，并逐项对照上下文核验。可用它检查 RAG 回答是否有检索结果作为依据。

## 评分详情 {/* #scoring-details */}

评分器通过对照给定上下文核验各项主张，评估输出的忠实性。

### 评分流程 {/* #scoring-process */}

1. 分析主张和上下文：
   * 提取所有主张（包括事实性和推测性主张）
   * 对照上下文核验每项主张
   * 给出以下三种判定之一：
     * “yes”——上下文支持该主张
     * “no”——该主张与上下文矛盾
     * “unsure”——无法核验该主张
2. 计算忠实性分数：
   * 统计得到支持的主张
   * 除以主张总数
   * 按有效量表换算

最终分数：`(supported_claims / total_claims) * effective_scale`，其中 `effective_scale` 为 `scale || 1`。

### 分数解读 {/* #score-interpretation */}

忠实性分数介于 0 和有效最高分之间（默认最高分为 1）。采用默认量表时：

* **1.0**：所有主张都准确，并有上下文直接支持。
* **0.7 至 0.9**：大多数主张正确，只有少量补充或遗漏。
* **0.4 至 0.6**：部分主张得到支持，其他主张无法核验。
* **0.1 至 0.3**：大部分内容不准确，或缺乏上下文支持。
* **0.0**：所有主张都错误，或与上下文矛盾。

## 示例 {/* #example */}

评估 Agent 回答是否忠实于给定上下文：

```typescript title="src/example-faithfulness.ts"
import { runEvals } from '@mastra/core/evals'
import { createFaithfulnessScorer } from '@mastra/evals/scorers/prebuilt'
import { myAgent } from './agent'

// Context is typically populated from agent tool calls or RAG retrieval
const scorer = createFaithfulnessScorer({
  model: '__GATEWAY_OPENAI_MODEL__',
})

const result = await runEvals({
  data: [
    {
      input: 'Tell me about the Tesla Model 3.',
    },
    {
      input: 'What are the key features of this electric vehicle?',
    },
  ],
  scorers: [scorer],
  target: myAgent,
  onItemComplete: ({ scorerResults }) => {
    console.log({
      score: scorerResults[scorer.id].score,
      reason: scorerResults[scorer.id].reason,
    })
  },
})

console.log(result.scores)
```

有关 `runEvals` 的详细信息，请参见 [runEvals 参考文档](/reference/evals/run-evals)。

如需将此评分器添加到 Agent，请参见[评分器概览](/docs/evals/overview#adding-scorers-to-agents)指南。
