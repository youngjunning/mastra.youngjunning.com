# 忠诚得分手

这`createFaithfulnessScorer()`函数评估法学硕士输出与所提供的上下文相比的事实准确性。它从输出中提取声明并根据上下文验证它们。用它来检查检索到的信息是否支持 RAG 响应。

## 评分详情 {/* #scoring-details */}

评分者通过针对所提供的上下文进行声明验证来评估忠诚度。

### 评分流程 {/* #scoring-process */}

1. 分析主张和背景：
   * 提取所有主张（事实和推测）
   * 根据上下文验证每个声明
   * 指定三个判决之一：
     * “是”——上下文支持的主张
     * “不”——主张与上下文相矛盾
     * “不确定”- 声明无法验证
2. 计算忠诚度分数：
   * 支持的声明计数
   * 除以索赔总额
   * 缩放至有效范围

最终成绩：`(supported_claims / total_claims) * effective_scale`, where `effective_scale` is `scale || 1`

### 分数解读 {/* #score-interpretation */}

忠诚度得分介于 0 和有效等级（默认 1）之间。使用默认比例：

* **1.0**：所有主张均准确且有上下文直接支持。
* **0.7至0.9**：大多数说法都是正确的，仅有少量补充或遗漏。
* **0.4至0.6**：有些说法得到支持，但其他说法无法证实。
* **0.1至0.3**：大多数内容不准确或不受支持。
* **0.0**：所有说法都是错误的或与上下文相矛盾。

## 例子 {/* #example */}

评估Agent响应是否忠实于所提供的上下文：

```typescript title="src/example-faithfulness.ts"
import { runEvals } from '@mastra/core/evals'
import { createFaithfulnessScorer } from '@mastra/evals/scorers/prebuilt'
import { myAgent } from './agent'

// Context is typically populated from agent tool calls or RAG retrieval
const scorer = createFaithfulnessScorer({
  model: '__GATEWAY_OPENAI_MODEL__',
})

const result = await runEvals({
  data: [
    {
      input: 'Tell me about the Tesla Model 3.',
    },
    {
      input: 'What are the key features of this electric vehicle?',
    },
  ],
  scorers: [scorer],
  target: myAgent,
  onItemComplete: ({ scorerResults }) => {
    console.log({
      score: scorerResults[scorer.id].score,
      reason: scorerResults[scorer.id].reason,
    })
  },
})

console.log(result.scores)
```

欲了解更多详情`runEvals`, see the [runEvals reference](/reference/evals/run-evals).

要将此记分员添加到Agent，请参阅[Scorers overview](/docs/evals/overview#adding-scorers-to-agents) guide.
