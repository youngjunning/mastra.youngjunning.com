# 完整性评分器

`createCompletenessScorer()` 评估 LLM 输出对输入中关键元素的覆盖程度。它分析名词、动词、主题和词语，并给出详细的完整性分数。

## 参数 {/* #parameters */}

`createCompletenessScorer()` 不接受任何选项。

此函数返回 MastraScorer 类的实例。有关 `.run()` 方法及其输入和输出，参见 [MastraScorer 参考文档](./mastra-scorer)。

## 元素提取详情 {/* #element-extraction-details */}

评分器会提取并分析以下几类元素：

- 名词：关键对象、概念和实体
- 动词：动作和状态（转换为不定式）
- 主题：主要议题和主题
- 词语：单个有实际意义的词

提取过程包括：

- 文本规范化（去除变音符号并转为小写）
- 处理单词边界
- 特殊处理短词（不超过 3 个字符）
- 对元素去重

### `preprocessStepResult` {/* #preprocessstepresult */}

`.run()` 返回的 `preprocessStepResult` 对象包含以下属性：

- **inputElements**：输入中的关键元素（如名词、动词、主题和词语）。
- **outputElements**：输出中的关键元素。
- **missingElements**：输入中有、输出中没有的元素。
- **elementCounts**：输入和输出中的元素数量。

## 评分详情 {/* #scoring-details */}

评分器通过分析语言元素的覆盖情况来评估完整性。

### 评分过程 {/* #scoring-process */}

1. 提取关键元素：
   - 名词和名称等实体
   - 表示动作的动词
   - 与主题相关的词语
   - 规范化后的词形
1. 计算输入元素的覆盖率：
   - 对短词（≤3 个字符）进行精确匹配
   - 对较长词语检查是否有较大重合（>60%）

如果输入没有提取出任何元素，输出也没有元素时返回 `1`，否则返回 `0`。

最终分数：`covered_elements / total_input_elements`

完整性评分器没有 `scale` 选项，分数始终介于 0 和 1 之间。

### 分数解读 {/* #score-interpretation */}

完整性分数介于 0 和 1 之间：

- **1.0**：详细回应问题的各个方面。
- **0.7 至 0.9**：详细覆盖大部分重要方面，仅有少量遗漏。
- **0.4 至 0.6**：回应了部分要点，但遗漏重要方面或缺少细节。
- **0.1 至 0.3**：只回应了问题的一小部分，遗漏较多。
- **0.0**：没有回应问题，或只提供无关信息。

## 示例 {/* #example */}

评估 Agent 对不同复杂程度问题的回答是否完整：

```typescript title="src/example-completeness.ts"
import { runEvals } from '@mastra/core/evals'
import { createCompletenessScorer } from '@mastra/evals/scorers/prebuilt'
import { myAgent } from './agent'

const scorer = createCompletenessScorer()

const result = await runEvals({
  data: [
    {
      input:
        'Explain the process of photosynthesis, including the inputs, outputs, and stages involved.',
    },
    {
      input: 'What are the benefits and drawbacks of remote work for both employees and employers?',
    },
    {
      input:
        'Compare renewable and non-renewable energy sources in terms of cost, environmental impact, and sustainability.',
    },
  ],
  scorers: [scorer],
  target: myAgent,
  onItemComplete: ({ scorerResults }) => {
    console.log({
      score: scorerResults[scorer.id].score,
    })
  },
})

console.log(result.scores)
```

有关 `runEvals` 的更多信息，参见 [runEvals 参考文档](/reference/evals/run-evals)。

有关如何将此评分器添加到 Agent，参见[评分器概览](/docs/evals/overview#adding-scorers-to-agents)。
