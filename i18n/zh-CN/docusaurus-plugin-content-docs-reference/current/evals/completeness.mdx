# 完整性评分者

这`createCompletenessScorer()`函数评估法学硕士的输出涵盖输入中存在的关键要素的彻底程度。它分析名词、动词、主题和术语以确定覆盖范围并提供详细的完整性分数。

## 参数 {/* #parameters */}

这`createCompletenessScorer()` function doesn't take any options.

此函数返回 MastraScorer 类的实例。请参阅[MastraScorer reference](./mastra-scorer) for details on the `.run()` method and its input/output.

## 元素提取细节 {/* #element-extraction-details */}

记分器提取并分析几种类型的元素：

* 名词：关键对象、概念和实体
* 动词：动作和状态（转换为不定式形式）
* 主题：主要主题和主题
* 术语：单独的实质性单词

提取过程包括：

* 文本标准化（删除变音符号，转换为小写）
* 字边界的处理
* 对短单词（3 个字符或更少）的特殊处理
* 元素去重

### `preprocessStepResult` {/* #preprocessstepresult */}

从`.run()` method, you can get the `preprocessStepResult` object with the following properties:

* **输入元素**：输入中找到的关键元素（例如名词、动词、主题、术语）。
* **输出元素**：在输出中找到的关键元素。
* **缺失元素**：在输出中找不到输入元素。
* **元素计数**：输入和输出中的元素数量。

## 评分详情 {/* #scoring-details */}

评分者通过语言元素覆盖分析来评估完整性。

### 评分流程 {/* #scoring-process */}

1. 提取关键要素：
   * 名词和实体，例如名称
   * 动作动词
   * 特定主题术语
   * 规范化的词形
2. 计算输入元素的覆盖范围：
   * 短期精确匹配（≤3 个字符）
   * 长期的大量重叠 (>60%)

当输入没有产生任何元素时，记分器返回`1` if the output also has no elements and `0` otherwise.

最终成绩：`covered_elements / total_input_elements`

完整性评分者没有`scale` option. The score is always between 0 and 1.

### 分数解读 {/* #score-interpretation */}

完整性分数介于 0 和 1 之间：

* **1.0**：详细解决查询的各个方面。
* **0.7至0.9**：涵盖了最重要的方面，细节丰富，有细微的差距。
* **0.4至0.6**：解决了一些关键点，但缺少重要方面或缺乏细节。
* **0.1至0.3**：仅部分解决了存在重大差距的查询。
* **0.0**：无法解决查询或提供不相关的信息。

## 例子 {/* #example */}

评估Agent响应在不同查询复杂性下的完整性：

```typescript title="src/example-completeness.ts"
import { runEvals } from '@mastra/core/evals'
import { createCompletenessScorer } from '@mastra/evals/scorers/prebuilt'
import { myAgent } from './agent'

const scorer = createCompletenessScorer()

const result = await runEvals({
  data: [
    {
      input:
        'Explain the process of photosynthesis, including the inputs, outputs, and stages involved.',
    },
    {
      input: 'What are the benefits and drawbacks of remote work for both employees and employers?',
    },
    {
      input:
        'Compare renewable and non-renewable energy sources in terms of cost, environmental impact, and sustainability.',
    },
  ],
  scorers: [scorer],
  target: myAgent,
  onItemComplete: ({ scorerResults }) => {
    console.log({
      score: scorerResults[scorer.id].score,
    })
  },
})

console.log(result.scores)
```

欲了解更多详情`runEvals`, see the [runEvals reference](/reference/evals/run-evals).

要将此记分员添加到Agent，请参阅[Scorers overview](/docs/evals/overview#adding-scorers-to-agents) guide.
