# Rubric 评分器

**新增于：** `@mastra/evals@1.3.0`

`createRubricScorer()` 创建一个以 LLM 为评审的评分器，按 rubric（评分标准清单）评估 Agent 的输出。它返回**二元**分数：仅当所有必需标准均满足时为 `1`，否则为 `0`。`reason` 会列出每条标准的判定结果，让 Agent 明确知道需要改进什么。

此评分器可直接用于 [`isTaskComplete`](/reference/streaming/agents/stream)。`isTaskComplete` 将 `score === 1` 视为“任务完成”，并把 `reason` 作为反馈注入对话；因此 Agent 会持续迭代，直到满足 rubric 或达到 `maxSteps`。

## 与 isTaskComplete 配合使用 {/* #usage-with-istaskcomplete */}

定义一次 rubric，并将评分器接入 `isTaskComplete`。Agent 会自行修正输出，直到满足 rubric：

```typescript
import { Agent } from '@mastra/core/agent'
// highlight-next-line
import { createRubricScorer } from '@mastra/evals/scorers/prebuilt'

const supervisor = new Agent({
  id: 'supervisor',
  instructions: `You coordinate research and writing using specialized agents. Delegate to research-agent for facts, then writing-agent for content.`,
  model: '__GATEWAY_OPENAI_MODEL__',
  agents: { researchAgent, writingAgent },
})

// highlight-start
const rubricScorer = createRubricScorer({
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  criteria: [
    { description: 'The response includes an analysis section' },
    { description: 'The response includes concrete recommendations' },
  ],
})
// highlight-end

const stream = await supervisor.stream('Research AI in education', {
  maxSteps: 10,
  // highlight-start
  isTaskComplete: {
    scorers: [rubricScorer],
    strategy: 'all',
  },
  // highlight-end
})
```

## 字符串形式的 rubric {/* #string-rubric */}

以换行分隔的字符串会解析为各项标准，常见列表标记（`-`、`*`、`1.`）会被去掉。每行都是一项必需标准：

```typescript
const rubricScorer = createRubricScorer({
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  criteria: `- All tests pass in the test suite
- The function is named find_duplicates and accepts a single list argument`,
})
```

## 可选标准 {/* #optional-criteria */}

将标准标记为可选后，它仍会被评分并报告，但不会决定任务是否完成：

```typescript
const rubricScorer = createRubricScorer({
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  criteria: [
    { description: 'Includes an analysis section', required: true },
    { description: 'Includes citations', required: false },
  ],
})
```

## 每次运行使用动态 rubric {/* #dynamic-rubric-per-run */}

若创建评分器时未传入 `criteria`，评分器会从本次运行的请求上下文、附加上下文或输入中查找 `rubric` 值。因此，同一个评分器实例可以在不同运行中使用不同 rubric，无须重新创建：

```typescript
const rubricScorer = createRubricScorer({
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
})

await supervisor.stream('Write find_duplicates', {
  isTaskComplete: { scorers: [rubricScorer] },
  requestContext: {
    rubric: '- All tests pass\n- The function is named find_duplicates',
  },
})
```

若找不到 rubric，评分器返回 `1`，不会阻止循环结束。

## 评分细节 {/* #scoring-details */}

评分器分两个阶段运行：

1. **评估**：评审模型独立评估每项标准，并返回各项是否 `satisfied` 及其理由。
2. **计分**：仅当评分器才返回 `1`，前提是所有必需标准均为 `satisfied`；若没有标记任何必需标准，则将所有标准视为必需。其他情况均返回 `0`。

`reason` 汇总评分结果，列出每项标准的判定，让 Agent 在评分失败时得到具体反馈，而不是笼统的“再试一次”。
