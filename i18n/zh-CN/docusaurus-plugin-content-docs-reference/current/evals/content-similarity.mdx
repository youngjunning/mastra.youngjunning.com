# 内容相似度评分器

这`createContentSimilarityScorer()`函数测量两个字符串之间的文本相似性，提供表明它们匹配程度的分数。它支持区分大小写和空格处理的可配置选项。

## 评分详情 {/* #scoring-details */}

评分器通过字符级匹配和可配置的文本规范化来评估文本相似性。

### 评分流程 {/* #scoring-process */}

1. 规范化文本：
   * 大小写标准化（如果ignoreCase：true）
   * 空白标准化（如果ignoreWhitespace：true）
2. 使用字符串相似度算法比较处理后的字符串：
   * 分析字符序列
   * 对齐单词边界
   * 考虑相对位置
   * 考虑长度差异

最终成绩：`similarity_value` (0-1, returned directly from the string-similarity comparison)

## 例子 {/* #example */}

评估预期和实际Agent输出之间的文本相似性：

```typescript title="src/example-content-similarity.ts"
import { runEvals } from '@mastra/core/evals'
import { createContentSimilarityScorer } from '@mastra/evals/scorers/prebuilt'
import { myAgent } from './agent'

const scorer = createContentSimilarityScorer()

const result = await runEvals({
  data: [
    {
      input: 'Summarize the benefits of TypeScript',
      groundTruth:
        'TypeScript provides static typing, better tooling support, and improved code maintainability.',
    },
    {
      input: 'What is machine learning?',
      groundTruth:
        'Machine learning is a subset of AI that enables systems to learn from data without explicit programming.',
    },
  ],
  scorers: [scorer],
  target: myAgent,
  onItemComplete: ({ scorerResults }) => {
    console.log({
      score: scorerResults[scorer.id].score,
      groundTruth: scorerResults[scorer.id].groundTruth,
    })
  },
})

console.log(result.scores)
```

欲了解更多详情`runEvals`, see the [runEvals reference](/reference/evals/run-evals).

要将此记分员添加到Agent，请参阅[Scorers overview](/docs/evals/overview#adding-scorers-to-agents) guide.

### 分数解读 {/* #score-interpretation */}

0 到 1 之间的相似度分数：

* **1.0**：完美匹配，内容几乎相同。
* **0.7至0.9**：相似度高，词语选择或结构差异较小。
* **0.4至0.6**：中等相似，总体重叠，但有明显差异。
* **0.1至0.3**：相似度低，共同元素少或有共同含义。
* **0.0**：没有相似之处，完全不同的内容。
