# 关键词覆盖率评分器

这`createKeywordCoverageScorer()`函数评估法学硕士的输出覆盖输入中重要关键字的程度。它分析关键字的存在和匹配，同时忽略常用词和停用词。

## 参数 {/* #parameters */}

这`createKeywordCoverageScorer()` function doesn't take any options.

此函数返回 MastraScorer 类的实例。请参阅[MastraScorer reference](./mastra-scorer) for details on the `.run()` method and its input/output.

## 评分详情 {/* #scoring-details */}

评分器通过将关键词与以下特征进行匹配来评估关键词覆盖率：

* 常用词和停用词过滤（例如“the”、“a”、“and”）
* 不区分大小写的匹配
* 词形变异处理
* 对技术术语和复合词的特殊处理

### 评分流程 {/* #scoring-process */}

1. 处理输入和输出中的关键字：
   * 过滤掉常用词和停用词
   * 规范大小写和单词形式
   * 处理特殊术语和复合词
2. 计算关键词覆盖率：
   * 匹配文本之间的关键字
   * 计算成功匹配的次数
   * 计算覆盖率

最终成绩：`(matched_keywords / total_keywords) * scale`

### 分数解读 {/* #score-interpretation */}

覆盖率分数介于 0 和 1 之间：

* **1.0**：完整覆盖，所有关键词都存在。
* **0.7至0.9**：覆盖率高，收录最多关键词。
* **0.4至0.6**：部分覆盖，存在一些关键词。
* **0.1至0.3**：覆盖率低，匹配的关键词很少。
* **0.0**：响应中不包含任何关键字。

### 特殊情况 {/* #special-cases */}

记分员处理几种特殊情况：

* 空输入/输出：如果两者都为空，则返回 1.0，如果只有一个为空，则返回 0.0
* 单个单词：视为单个关键字
* 技术术语：保留复合技术术语（例如“React.js”、“机器学习”）
* 大小写差异：“JavaScript”匹配“javascript”
* 常用词：在评分时忽略以关注有用的关键词

## 例子 {/* #example */}

评估输入查询和Agent响应之间的关键字覆盖率：

```typescript title="src/example-keyword-coverage.ts"
import { runEvals } from '@mastra/core/evals'
import { createKeywordCoverageScorer } from '@mastra/evals/scorers/prebuilt'
import { myAgent } from './agent'

const scorer = createKeywordCoverageScorer()

const result = await runEvals({
  data: [
    {
      input: 'JavaScript frameworks like React and Vue',
    },
    {
      input: 'TypeScript offers interfaces, generics, and type inference',
    },
    {
      input:
        'Machine learning models require data preprocessing, feature engineering, and hyperparameter tuning',
    },
  ],
  scorers: [scorer],
  target: myAgent,
  onItemComplete: ({ scorerResults }) => {
    console.log({
      score: scorerResults[scorer.id].score,
    })
  },
})

console.log(result.scores)
```

欲了解更多详情`runEvals`, see the [runEvals reference](/reference/evals/run-evals).

要将此记分员添加到Agent，请参阅[Scorers overview](/docs/evals/overview#adding-scorers-to-agents) guide.
