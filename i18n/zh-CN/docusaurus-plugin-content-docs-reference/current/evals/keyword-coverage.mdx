# 关键词覆盖率评分器

`createKeywordCoverageScorer()` 函数评估 LLM 输出对输入中重要关键词的覆盖程度。它会检查关键词是否出现、是否匹配，并忽略常见词和停用词。

## 参数 {/* #parameters */}

`createKeywordCoverageScorer()` 函数不接受任何选项。

此函数返回 MastraScorer 类的实例。有关 `.run()` 方法及其输入和输出的详情，请参阅 [MastraScorer 参考文档](./mastra-scorer)。

## 评分细节 {/* #scoring-details */}

评分器通过匹配关键词评估覆盖率，具有以下特点：

- 过滤常见词和停用词（例如“the”“a”“and”）
- 不区分大小写地匹配
- 处理词形变化
- 特别处理技术术语和复合词

### 评分过程 {/* #scoring-process */}

1. 处理输入和输出中的关键词：
   - 过滤常见词和停用词
   - 统一大小写和词形
   - 处理特殊术语和复合词
1. 计算关键词覆盖率：
   - 匹配两段文本中的关键词
   - 统计成功匹配的数量
   - 计算覆盖比例

最终分数：`(matched_keywords / total_keywords) * scale`

### 分数解读 {/* #score-interpretation */}

覆盖率分数介于 0 和 1 之间：

- **1.0**：完全覆盖，所有关键词都出现。
- **0.7 到 0.9**：覆盖率高，包含大部分关键词。
- **0.4 到 0.6**：部分覆盖，包含一些关键词。
- **0.1 到 0.3**：覆盖率低，仅匹配少量关键词。
- **0.0**：响应中不包含任何关键词。

### 特殊情况 {/* #special-cases */}

评分器还会处理以下特殊情况：

- 输入和输出为空：两者都为空时返回 1.0，仅一者为空时返回 0.0
- 单个词：视为一个关键词
- 技术术语：保留复合技术术语（例如“React.js”“机器学习”）
- 大小写差异：“JavaScript”可以匹配“javascript”
- 常见词：评分时予以忽略，以聚焦有意义的关键词

## 示例 {/* #example */}

评估输入查询与 Agent 响应之间的关键词覆盖率：

```typescript title="src/example-keyword-coverage.ts"
import { runEvals } from '@mastra/core/evals'
import { createKeywordCoverageScorer } from '@mastra/evals/scorers/prebuilt'
import { myAgent } from './agent'

const scorer = createKeywordCoverageScorer()

const result = await runEvals({
  data: [
    {
      input: 'JavaScript frameworks like React and Vue',
    },
    {
      input: 'TypeScript offers interfaces, generics, and type inference',
    },
    {
      input:
        'Machine learning models require data preprocessing, feature engineering, and hyperparameter tuning',
    },
  ],
  scorers: [scorer],
  target: myAgent,
  onItemComplete: ({ scorerResults }) => {
    console.log({
      score: scorerResults[scorer.id].score,
    })
  },
})

console.log(result.scores)
```

有关 `runEvals` 的更多信息，请参阅 [runEvals 参考文档](/reference/evals/run-evals)。

如需将此评分器添加到 Agent，请参阅[评分器概览](/docs/evals/overview#adding-scorers-to-agents)指南。
