# 摘要评分器

`createSummarizationScorer()` 创建的评分器从两个方面评估摘要：每项陈述是否得到原文支持，以及摘要是否保留了原文信息。最终得分取两项中较低的一项。因此，摘要仅仅准确却空洞，或内容全面却不准确，都无法获得高分。

摘要取自 Agent 最后一条包含文本的消息；原文默认取自本次运行输入中的第一条用户消息。如果待摘要的文本位于其他位置，例如工具结果中，请传入 `source` 或 `sourceExtractor`。

## 使用示例 {/* #usage-example */}

根据摘要所概括的文档为摘要评分。

```typescript title="src/mastra/scorers/summarization.ts"
import { createSummarizationScorer } from '@mastra/evals/scorers/prebuilt'

const scorer = createSummarizationScorer({
  model: '__GATEWAY_OPENAI_MODEL__',
})

const result = await scorer.run({
  input: {
    inputMessages: [{ id: '1', role: 'user', content: sourceDocument }],
  },
  output: [{ id: '2', role: 'assistant', content: summary }],
})

console.log(result.score)
console.log(result.reason)
```

## 摘要评估 {/* #summarization-evaluation */}

- 文档和会议记录摘要
- 客服会话和电子邮件摘要
- 将长篇输入压缩为简短输出的任何步骤

两个维度的得分根据这些判断结果计算，而非直接存储：准确性得分是 `alignment` 中 `supported: true` 的占比；覆盖度得分是 `questions` 中其对应 `coverage` 条目标记为 `answered: true` 的占比。

## 评分细节 {/* #scoring-details */}

### 双维度评估 {/* #two-axis-evaluation */}

评分器分三步运行：

1. **原文判断**：提取摘要中的陈述并对照原文核实，同时从原文生成封闭式问题。每个问题都设定为可由原文回答“是”。
1. **覆盖度判断**：仅根据摘要回答每个问题。
1. **计算得分**：计算两个比例，取较低者作为得分。

覆盖度判断由单独一次模型调用完成，且这次调用不会收到原文。如果判断模型能看到原文，就可能直接从原文回答问题，掩盖摘要遗漏的信息。

### 评分公式 {/* #scoring-formula */}

```text
Alignment    = supported_claims / total_claims
Coverage     = answered_questions / total_questions
Summarization = min(Alignment, Coverage) × scale
```

如果摘要没有提出任何陈述，或原文无法生成问题，得分为 0。

### 得分解读 {/* #score-interpretation */}

以下区间以默认 `scale` 值 1 为前提；使用自定义值时，得分区间也要相应乘以该值。

- **0.9–1.0**：优秀；忠实于原文并覆盖主要内容
- **0.7–0.8**：良好；有少量遗漏或一处缺乏依据的细节
- **0.4–0.6**：一般；遗漏重要信息或偏离原文
- **0.1–0.3**：较差；原文大部分信息丢失或被错误表述
- **0.0**：摘要没有可供判断的内容，或所有陈述都缺乏依据；一个问题也未回答时同样得 0 分

### 如何查看两个维度 {/* #reading-the-two-axes */}

两个维度的判断结果都保存在运行结果中：准确性判断位于预处理步骤，覆盖度判断位于分析步骤。每条判断结果都包含对应的陈述或问题及其理由。低准确性得分与低覆盖度得分含义不同：

- 准确性低、覆盖度高，表示摘要编造或歪曲了细节
- 覆盖度低、准确性高，表示摘要虽然准确，却遗漏了太多内容

reason 字段会指出决定最终得分的维度。

### 得分未衡量的方面 {/* #what-the-score-leaves-out */}

摘要长度不计入得分。逐字复述原文的“摘要”能支持每项陈述并回答所有问题，因此可得 1 分。如果你还需要评估压缩程度，应自行增加长度检查。

### 成本 {/* #cost */}

每次评估会调用模型三次。`maxQuestions` 限制覆盖度评估所用的问题数量，否则工作量会随原文长度增长。对于无法用十个问题充分概括的长文档，可提高此上限。

## 评分器配置 {/* #scorer-configuration */}

### 为运行输入生成摘要 {/* #summarizing-the-run-input */}

```typescript
const scorer = createSummarizationScorer({
  model: '__GATEWAY_OPENAI_MODEL__',
})
```

### 为其他来源的文档生成摘要 {/* #summarizing-a-document-from-elsewhere */}

```typescript
import { extractToolResults } from '@mastra/evals/scorers/utils'

const scorer = createSummarizationScorer({
  model: '__GATEWAY_OPENAI_MODEL__',
  options: {
    sourceExtractor: (input, output) => {
      return extractToolResults(output)
        .filter(({ toolName }) => toolName === 'fetchDocument')
        .map(({ result }) => String(result))
        .join('\n\n')
    },
    maxQuestions: 20,
  },
})
```

## 示例 {/* #example */}

对照一组文档评估摘要 Agent：

```typescript title="src/example-summarization.ts"
import { runEvals } from '@mastra/core/evals'
import { createSummarizationScorer } from '@mastra/evals/scorers/prebuilt'
import { summarizerAgent } from './agent'

const scorer = createSummarizationScorer({
  model: '__GATEWAY_OPENAI_MODEL__',
  options: { maxQuestions: 10 },
})

const result = await runEvals({
  target: summarizerAgent,
  scorers: [scorer],
  data: [
    {
      input:
        'The company was founded in 1995 by John Smith. It started with 10 employees and grew to 500 by 2020. The company is based in Seattle.',
    },
  ],
  onItemComplete: ({ scorerResults }) => {
    console.log({
      score: scorerResults[scorer.id].score,
      reason: scorerResults[scorer.id].reason,
    })
  },
})

console.log(result.scores)
```

关于 `runEvals` 的更多信息，请参阅 [runEvals 参考文档](/reference/evals/run-evals)。

要将此评分器添加到 Agent，请参阅 [评分器概览](/docs/evals/overview#adding-scorers-to-agents) 指南。

## 与 faithfulness 评分器比较 {/* #comparison-with-faithfulness */}

| 使用场景 | 摘要评分器 | Faithfulness 评分器 |
| - | - | - |
| **衡量内容** | 同时衡量依据和覆盖度 | 仅衡量依据 |
| **对照材料** | 被概括的原文 | 检索到的上下文或工具结果 |
| **检测遗漏** | 是 | 否 |
| **需要完整原文** | 是 | 否，仅有上下文即可 |

如果要判断回答是否有检索上下文依据，请使用 `faithfulness`；如果输出旨在代替较长的原文，请使用 `summarization`。
