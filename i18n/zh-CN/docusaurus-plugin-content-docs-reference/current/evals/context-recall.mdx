# Context Recall 评分器

`createContextRecallScorer()` 函数创建的评分器，用于评估检索到的上下文在多大程度上覆盖标准参考答案中的陈述。它会计算参考答案中有多少比例的陈述能从检索到的上下文找到依据，以衡量检索的完整性。

此评分器需要标准参考答案，因此适合在 CI 或测试环境中评估带有正确答案的数据集。如果运行时未提供 `groundTruth`，评分器会返回 0 分，而不会抛出错误。

## RAG 检索评估 {/* #rag-retrieval-evaluation */}

适用于评估以下 RAG 流程中的检索完整性：

* 需要验证检索器是否取得全部必要信息
* 拥有附带已知正确答案的数据集
* 希望发现检索器返回结果的回归问题

## 数据集驱动测试 {/* #dataset-driven-testing */}

适用于使用精选测试集运行评估：

* 在 CI 流程中使用附有标准答案的问题
* 对检索策略进行 A/B 测试
* 对嵌入模型的信息覆盖能力进行基准测试

## 评分细节 {/* #scoring-details */}

### 陈述依据核对 {/* #claim-attribution */}

Context Recall 先由 LLM 分两步评估，再以确定性方式计算分数：

1. **提取陈述**：将标准答案拆解为独立的最小陈述
2. **核对依据**：检查检索到的上下文是否支持每项陈述

然后计算有上下文依据的陈述数占陈述总数的比例，并乘以 scale。

### 评分公式 {/* #scoring-formula */}

```text
Context Recall = attributed_claims / total_claims × scale

Where:
- attributed_claims = number of ground-truth claims supported by the context
- total_claims = total number of claims extracted from the ground truth
- Attribution is binary: a claim is either supported (yes) or not (no)
```

### 分数解读 {/* #score-interpretation */}

以下范围以 `scale` 的默认值 1 为准。使用自定义 scale 时，请相应调整。

* **0.9-1.0**：召回效果极佳，上下文几乎覆盖所有标准答案陈述
* **0.7-0.8**：召回效果良好，覆盖大多数陈述，仅有少量遗漏
* **0.4-0.6**：召回效果一般，上下文缺少较多信息
* **0.1-0.3**：召回效果较差，上下文未包含大多数标准答案陈述
* **0.0**：没有召回任何标准答案陈述

### 原因分析 {/* #reason-analysis */}

reason 字段说明：

* 哪些标准答案陈述在上下文中找到了依据
* 缺少哪些陈述，以及存在哪些信息缺口
* 哪些具体上下文片段支持了有依据的陈述

### 优化见解 {/* #optimization-insights */}

可利用评估结果：

* **改进检索**：找出检索器遗漏的信息类型
* **调整分块大小**：确保片段包含足够的细节，能够覆盖标准答案陈述
* **评估嵌入模型**：测试不同模型对信息的覆盖能力
* **扩展知识库**：添加涵盖常被遗漏的陈述的文档

### 计算示例 {/* #example-calculation */}

标准答案：“爱因斯坦出生于 1879 年。他发展了相对论。他获得过诺贝尔奖。”

提取出的陈述：3 项

* “爱因斯坦出生于 1879 年”→ 有依据（上下文提到了出生日期）
* “爱因斯坦发展了相对论”→ 有依据（上下文涵盖相对论）
* “爱因斯坦获得过诺贝尔奖”→ 无依据（上下文未提到诺贝尔奖）

召回率 = 2/3 = 0.67

## 评分器配置 {/* #scorer-configuration */}

### 动态提取上下文 {/* #dynamic-context-extraction */}

```typescript
const scorer = createContextRecallScorer({
  model: '__GATEWAY_OPENAI_MODEL__',
  options: {
    contextExtractor: (input, output) => {
      const query = input?.inputMessages?.[0]?.content || ''
      const searchResults = vectorDB.search(query, { limit: 10 })
      return searchResults.map(result => result.content)
    },
    scale: 1,
  },
})
```

### 静态上下文评估 {/* #static-context-evaluation */}

```typescript
const scorer = createContextRecallScorer({
  model: '__GATEWAY_OPENAI_MODEL__',
  options: {
    context: [
      'Document 1: Einstein was born on 14 March 1879 in Ulm, Germany.',
      'Document 2: Einstein published the theory of special relativity in 1905.',
      'Document 3: Einstein moved to the United States in 1933.',
    ],
  },
})
```

## 示例 {/* #example */}

根据带有标准答案的数据集，评估 RAG 检索的完整性：

```typescript title="src/example-context-recall.ts"
import { runEvals } from '@mastra/core/evals'
import { createContextRecallScorer } from '@mastra/evals/scorers/prebuilt'
import { myAgent } from './agent'

const scorer = createContextRecallScorer({
  model: '__GATEWAY_OPENAI_MODEL__',
  options: {
    contextExtractor: (input, output) => {
      // Extract context from tool invocation results in the agent output
      return output
        .filter(msg => msg?.role === 'assistant')
        .flatMap(msg => msg?.content?.toolInvocations ?? [])
        .filter((tool: any) => tool.state === 'result')
        .map((tool: any) => JSON.stringify(tool.result))
    },
  },
})

const result = await runEvals({
  data: [
    {
      input: 'What are the health benefits of green tea?',
      groundTruth:
        'Green tea contains antioxidants that reduce inflammation, L-theanine that improves focus, and catechins that boost metabolism.',
    },
    {
      input: 'How does photosynthesis work?',
      groundTruth:
        'Photosynthesis converts sunlight into chemical energy using chlorophyll in chloroplasts, producing glucose and oxygen from carbon dioxide and water.',
    },
  ],
  scorers: [scorer],
  target: myAgent,
  onItemComplete: ({ scorerResults }) => {
    console.log({
      score: scorerResults[scorer.id].score,
      reason: scorerResults[scorer.id].reason,
    })
  },
})

console.log(result.scores)
```

有关 `runEvals` 的详细信息，请参阅 [runEvals 参考文档](/reference/evals/run-evals)。

要将此评分器添加到 Agent，请参阅 [Scorers 概述](/docs/evals/overview#adding-scorers-to-agents)指南。

## 与 Context Precision 的比较 {/* #comparison-with-context-precision */}

请根据需要选择评分器：

| 用途 | Context Recall | Context Precision |
| - | - | - |
| **衡量内容** | 标准答案的覆盖程度 | 检索片段的相关性 |
| **比较方向** | 标准答案 → 上下文 | 上下文 → 标准答案 |
| **是否受位置影响** | 否 | 是（靠前的片段得分更高） |
| **是否需要标准答案** | 是 | 是 |
| **发现的问题** | 信息遗漏 | 无关内容 |

同时使用两者，可更全面地了解检索质量：Precision 可发现上下文中的无关内容，Recall 可发现遗漏的信息。
