# 情境回忆评分器

这`createContextRecallScorer()`函数创建一个评分器，用于评估检索到的上下文对真实参考答案中的主张的覆盖程度。它通过检查事实真相声明的哪一部分可归因于检索到的上下文来衡量检索完整性。

该评分器需要真实的参考答案，使其适合 CI 或测试环境中的标记数据集。什么时候`groundTruth` isn't provided in the run, the scorer returns a score of 0 rather than throwing an error.

## RAG检索评估 {/* #rag-retrieval-evaluation */}

非常适合评估 RAG 管道中的检索完整性，其中：

* 您需要验证检索器是否获取了所有必要的信息
* 您已用已知正确答案标记了数据集
* 您想要捕获检索器返回的回归

## 数据集驱动的测试 {/* #dataset-driven-testing */}

针对策划的测试集运行评估时使用：

* 带有真实标记问题的 CI 管道
* A/B 测试检索策略
* 对覆盖范围的嵌入模型进行基准测试

任何一个`context` or `contextExtractor` must be provided. When both are provided, `contextExtractor` is used only if the run input and output are agent-shaped: the input must be an agent run-input object (`{ inputMessages, rememberedMessages, systemMessages, taggedSystemMessages }`) and the output must be a `MastraDBMessage[]`. Otherwise the scorer falls back to `context`.

## 评分详情 {/* #scoring-details */}

### 声明归属 {/* #claim-attribution */}

Context Recall 使用两步 LLM 评估，然后进行确定性分数计算：

1. **索赔提取**：真实答案被分解为原子声明
2. **归因检查**：每个声明都会根据检索上下文进行检查以获取支持

然后将分数计算为归因索赔与总索赔的比率乘以规模。

### 评分公式 {/* #scoring-formula */}

```text
Context Recall = attributed_claims / total_claims × scale

Where:
- attributed_claims = number of ground-truth claims supported by the context
- total_claims = total number of claims extracted from the ground truth
- Attribution is binary: a claim is either supported (yes) or not (no)
```

### 分数解读 {/* #score-interpretation */}

这些范围采用默认值`scale` of 1. When using a custom scale, multiply accordingly.

* **0.9-1.0**：出色的回忆，上下文几乎涵盖了所有真实的说法
* **0.7-0.8**: 记得很好。大多数索赔均已涵盖，但存在微小差距
* **0.4-0.6**：回忆能力中等，上下文中缺少大量信息
* **0.1-0.3**：记忆力差，大多数真实的说法在上下文中找不到
* **0.0**：不记得，上下文中没有任何真实的说法

### 原因分析 {/* #reason-analysis */}

原因字段解释：

* 在上下文中发现了哪些真实的主张
* 缺少哪些声明以及存在哪些信息差距
* 支持归因声明的特定上下文片段

### 优化见解 {/* #optimization-insights */}

使用结果来：

* **提高检索能力**：识别检索器错过的信息类型
* **调整块大小**：确保块包含足够的细节来涵盖真实的声明
* **评估嵌入**：测试不同的嵌入模型以获得更好的信息覆盖
* **扩大知识库**：添加涵盖经常错过的索赔的文件

### 计算示例 {/* #example-calculation */}

基本事实：“爱因斯坦出生于 1879 年。他发展了相对论。他获得了诺贝尔奖。”

提取的索赔：3

* “爱因斯坦出生于 1879 年”→ 归因（上下文提到出生日期）
* “爱因斯坦发展了相对论”→归因（上下文涵盖相对论）
* “爱因斯坦获得诺贝尔奖” → 未注明来源（上下文未提及诺贝尔奖）

召回率 = 2/3 = 0.67

## 记分器配置 {/* #scorer-configuration */}

### 动态上下文提取 {/* #dynamic-context-extraction */}

```typescript
const scorer = createContextRecallScorer({
  model: '__GATEWAY_OPENAI_MODEL__',
  options: {
    contextExtractor: (input, output) => {
      const query = input?.inputMessages?.[0]?.content || ''
      const searchResults = vectorDB.search(query, { limit: 10 })
      return searchResults.map(result => result.content)
    },
    scale: 1,
  },
})
```

### 静态上下文评估 {/* #static-context-evaluation */}

```typescript
const scorer = createContextRecallScorer({
  model: '__GATEWAY_OPENAI_MODEL__',
  options: {
    context: [
      'Document 1: Einstein was born on 14 March 1879 in Ulm, Germany.',
      'Document 2: Einstein published the theory of special relativity in 1905.',
      'Document 3: Einstein moved to the United States in 1933.',
    ],
  },
})
```

## 例子 {/* #example */}

根据标记数据集评估 RAG 检索完整性：

```typescript title="src/example-context-recall.ts"
import { runEvals } from '@mastra/core/evals'
import { createContextRecallScorer } from '@mastra/evals/scorers/prebuilt'
import { myAgent } from './agent'

const scorer = createContextRecallScorer({
  model: '__GATEWAY_OPENAI_MODEL__',
  options: {
    contextExtractor: (input, output) => {
      // Extract context from tool invocation results in the agent output
      return output
        .filter(msg => msg?.role === 'assistant')
        .flatMap(msg => msg?.content?.toolInvocations ?? [])
        .filter((tool: any) => tool.state === 'result')
        .map((tool: any) => JSON.stringify(tool.result))
    },
  },
})

const result = await runEvals({
  data: [
    {
      input: 'What are the health benefits of green tea?',
      groundTruth:
        'Green tea contains antioxidants that reduce inflammation, L-theanine that improves focus, and catechins that boost metabolism.',
    },
    {
      input: 'How does photosynthesis work?',
      groundTruth:
        'Photosynthesis converts sunlight into chemical energy using chlorophyll in chloroplasts, producing glucose and oxygen from carbon dioxide and water.',
    },
  ],
  scorers: [scorer],
  target: myAgent,
  onItemComplete: ({ scorerResults }) => {
    console.log({
      score: scorerResults[scorer.id].score,
      reason: scorerResults[scorer.id].reason,
    })
  },
})

console.log(result.scores)
```

欲了解更多详情`runEvals`, see the [runEvals reference](/reference/evals/run-evals).

要将此记分员添加到Agent，请参阅[Scorers overview](/docs/evals/overview#adding-scorers-to-agents) guide.

## 与上下文精度的比较 {/* #comparison-with-context-precision */}

选择适合您需求的记分器：

|使用案例|情境回忆 |上下文精度 |
| - | - | - |
|**What it measures** | Coverage of ground truth | Relevance of retrieved chunks |
| **Direction** | Ground truth → context | Context → ground truth |
| **Position sensitive** | No | Yes (rewards early placement) |
| **Requires ground truth** | Yes | Yes |
| **Failure mode caught** | Missing information | Irrelevant noise |

将两者结合使用可以全面了解检索质量：精确度可以捕获上下文中的垃圾，召回可以捕获空白。
