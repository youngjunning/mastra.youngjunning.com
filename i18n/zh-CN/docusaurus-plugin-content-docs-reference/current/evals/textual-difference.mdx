# 文本差异评分器

这`createTextualDifferenceScorer()`函数使用序列匹配来测量两个字符串之间的文本差异。它提供有关更改的详细信息，包括将一种文本转换为另一种文本所需的操作数量。

## 参数 {/* #parameters */}

这`createTextualDifferenceScorer()` function doesn't take any options.

此函数返回 MastraScorer 类的实例。请参阅[MastraScorer reference](./mastra-scorer) for details on the `.run()` method and its input/output.

## 评分详情 {/* #scoring-details */}

记分员计算几个指标：

* **相似率**：基于文本之间的序列匹配（0-1）
* **变化**：需要的不匹配操作的计数
* **长度差**：文本长度的标准化差异
* **信心**：与长度差成反比

### 评分流程 {/* #scoring-process */}

1. 分析文本差异：
   * 执行输入和输出之间的序列匹配
   * 计算所需更改操作的数量
   * 测量长度差异
2. 计算指标：
   * 计算相似率
   * 确定置信度分数
   * 合并为加权分数

最终成绩：`(similarity_ratio * confidence) * scale`

### 分数解读 {/* #score-interpretation */}

0 和 1 之间的文本差异分数：

* **1.0**: 文字是一样的。
* **0.7至0.9**：细微差别，需要很少的改变。
* **0.4至0.6**：中等差异，需要显着改变。
* **0.1至0.3**：主要差异，需要进行大量更改。
* **0.0**: 完全不同的文字。

## 例子 {/* #example */}

测量预期和实际Agent输出之间的文本差异：

```typescript title="src/example-textual-difference.ts"
import { runEvals } from '@mastra/core/evals'
import { createTextualDifferenceScorer } from '@mastra/evals/scorers/prebuilt'
import { myAgent } from './agent'

const scorer = createTextualDifferenceScorer()

const result = await runEvals({
  data: [
    {
      input: 'Summarize the concept of recursion',
      groundTruth:
        'Recursion is when a function calls itself to solve a problem by breaking it into smaller subproblems.',
    },
    {
      input: 'What is the capital of France?',
      groundTruth: 'The capital of France is Paris.',
    },
  ],
  scorers: [scorer],
  target: myAgent,
  onItemComplete: ({ scorerResults }) => {
    console.log({
      score: scorerResults[scorer.id].score,
      groundTruth: scorerResults[scorer.id].groundTruth,
    })
  },
})

console.log(result.scores)
```

欲了解更多详情`runEvals`, see the [runEvals reference](/reference/evals/run-evals).

要将此记分员添加到Agent，请参阅[Scorers overview](/docs/evals/overview#adding-scorers-to-agents) guide.
