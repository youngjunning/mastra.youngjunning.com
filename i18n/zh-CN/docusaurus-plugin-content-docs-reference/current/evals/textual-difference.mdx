# 文本差异评分器

`createTextualDifferenceScorer()` 函数通过序列匹配衡量两个字符串之间的文本差异。它会提供差异的详细信息，包括将一段文本转换为另一段文本所需的操作次数。

## 参数 {/* #parameters */}

`createTextualDifferenceScorer()` 函数不接受任何选项。

此函数返回 MastraScorer 类的实例。有关 `.run()` 方法及其输入和输出的详情，请参阅 [MastraScorer 参考文档](./mastra-scorer)。

## 评分详情 {/* #scoring-details */}

评分器计算以下指标：

* **相似度比率**：基于文本间的序列匹配，取值为 0–1
* **变更次数**：不匹配操作的数量
* **长度差异**：文本长度的归一化差异
* **置信度**：与长度差异成反比

### 评分流程 {/* #scoring-process */}

1. 分析文本差异：
   * 对输入和输出进行序列匹配
   * 统计所需的变更操作次数
   * 衡量文本长度差异
2. 计算指标：
   * 计算相似度比率
   * 确定置信度分数
   * 组合得到加权分数

最终分数：`(similarity_ratio * confidence) * scale`

### 分数解读 {/* #score-interpretation */}

文本差异评分介于 0 和 1 之间：

* **1.0**：两段文本完全相同。
* **0.7 至 0.9**：差异较小，只需少量修改。
* **0.4 至 0.6**：存在中等程度的差异，需要明显修改。
* **0.1 至 0.3**：差异较大，需要大量修改。
* **0.0**：两段文本完全不同。

## 示例 {/* #example */}

衡量 Agent 的预期输出与实际输出之间的文本差异：

```typescript title="src/example-textual-difference.ts"
import { runEvals } from '@mastra/core/evals'
import { createTextualDifferenceScorer } from '@mastra/evals/scorers/prebuilt'
import { myAgent } from './agent'

const scorer = createTextualDifferenceScorer()

const result = await runEvals({
  data: [
    {
      input: 'Summarize the concept of recursion',
      groundTruth:
        'Recursion is when a function calls itself to solve a problem by breaking it into smaller subproblems.',
    },
    {
      input: 'What is the capital of France?',
      groundTruth: 'The capital of France is Paris.',
    },
  ],
  scorers: [scorer],
  target: myAgent,
  onItemComplete: ({ scorerResults }) => {
    console.log({
      score: scorerResults[scorer.id].score,
      groundTruth: scorerResults[scorer.id].groundTruth,
    })
  },
})

console.log(result.scores)
```

有关 `runEvals` 的详情，请参阅 [runEvals 参考文档](/reference/evals/run-evals)。

如需将此评分器添加到 Agent，请参阅[评分器概览](/docs/evals/overview#adding-scorers-to-agents)指南。
