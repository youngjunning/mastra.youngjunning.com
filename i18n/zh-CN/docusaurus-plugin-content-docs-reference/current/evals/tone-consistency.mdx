# 语气一致性评分器

这`createToneScorer()`函数评估文本的情感基调和情感一致性。它可以以两种模式运行：将Agent输出的情绪与非空进行比较`referenceTone`，或分析Agent输出句子中的语气稳定性。

## 评分详情 {/* #scoring-details */}

评分者通过语气模式分析和特定模式评分来评估情绪一致性。

### 评分流程 {/* #scoring-process */}

1. 分析音调模式：
   * 提取情感特征
   * 计算情绪分数
   * 测量音调变化
2. 计算特定于模式的分数：**Tone Consistency** (non-empty `referenceTone`):
   * 将输出的情绪与`referenceTone` sentiment
   * 计算绝对情绪差异
   * 分数 = max(0, 1 - 情感差异)**Tone Stability** (`referenceTone` omitted or empty):
   * 分析输出句子中的情绪
   * 计算情绪方差
   * 分数 = max(0, 1 - 情感方差)

最终成绩：`mode_specific_score`

### 分数解读 {/* #score-interpretation */}

(0-1)

* 1.0：完美的音色一致性/稳定性
* 0.7-0.9：一致性强，变化小
* 0.4-0.6：中等一致性，有明显变化
* 0.1-0.3：一致性较差，音调变化较大
* 0.0：没有一致性——完全不同的色调

### `preprocessStepResult` {/* #preprocessstepresult */}

具有音调指标的对象：

* **回应情绪**：响应的情绪分数（比较模式）。
* **参考情绪**: 的情绪得分`referenceTone` (comparison mode).
* **不同之处**：情绪分数之间的绝对差异（比较模式）。
* **平均情绪**：句子之间的平均情绪（稳定模式）。
* **情绪方差**：句子间情绪的方差（稳定模式）。

## 例子 {/* #example */}

评估座席响应是否与积极的参考语气匹配：

```typescript title="src/example-tone-consistency.ts"
import { runEvals } from '@mastra/core/evals'
import { createToneScorer } from '@mastra/evals/scorers/prebuilt'
import { myAgent } from './agent'

const scorer = createToneScorer({
  referenceTone: 'We are happy to help and glad you had a great experience!',
})

const result = await runEvals({
  data: [
    { input: 'How was your experience with our service?' },
    { input: 'Tell me about the customer support' },
  ],
  scorers: [scorer],
  target: myAgent,
  onItemComplete: ({ scorerResults }) => {
    console.log({
      score: scorerResults[scorer.id].score,
    })
  },
})

console.log(result.scores)
```

欲了解更多详情`runEvals`, see the [runEvals reference](/reference/evals/run-evals).

要将此记分员添加到Agent，请参阅[Scorers overview](/docs/evals/overview#adding-scorers-to-agents) guide.
