# 语气一致性评分器

`createToneScorer()` 函数评估文本的情感基调及其一致性。它有两种模式：将 Agent 输出的情感倾向与非空的 `referenceTone` 比较，或分析输出各句之间的语气稳定性。

`createToneScorer()` 函数接受一个可选配置对象，包含以下属性：

## 评分详情 {/* #scoring-details */}

评分器分析语气模式，并根据所选模式计算情感一致性评分。

### 评分流程 {/* #scoring-process */}

1. 分析语气模式：
   * 提取情感特征
   * 计算情绪分数
   * 测量音调变化
2. 按模式计算评分：
   **语气一致性**（`referenceTone` 非空）：
   * 比较输出与 `referenceTone` 的情感倾向
   * 计算绝对情绪差异
   * 评分 = max(0, 1 - 情感差异)
   **语气稳定性**（省略 `referenceTone` 或将其留空）：
   * 分析输出句子中的情绪
   * 计算情绪方差
   * 评分 = max(0, 1 - 情感方差)

最终评分：`mode_specific_score`

### 分数解读 {/* #score-interpretation */}

(0-1)

* 1.0：语气完全一致／稳定
* 0.7-0.9：一致性较高，变化很小
* 0.4-0.6：一致性中等，存在明显变化
* 0.1-0.3：一致性较差，语气变化较大
* 0.0：完全不一致，语气截然不同

### `preprocessStepResult` {/* #preprocessstepresult */}

包含语气指标的对象：

* **responseSentiment**：响应的情绪分数（比较模式）。
* **referenceSentiment**: `referenceTone` 的情感评分（比较模式）.
* **difference**：情绪分数之间的绝对差异（比较模式）。
* **avgSentiment**：句子之间的平均情绪（稳定模式）。
* **sentimentVariance**：句子间情绪的方差（稳定模式）。

## 示例 {/* #example */}

评估 Agent 回复是否符合积极的参考语气：

```typescript title="src/example-tone-consistency.ts"
import { runEvals } from '@mastra/core/evals'
import { createToneScorer } from '@mastra/evals/scorers/prebuilt'
import { myAgent } from './agent'

const scorer = createToneScorer({
  referenceTone: 'We are happy to help and glad you had a great experience!',
})

const result = await runEvals({
  data: [
    { input: 'How was your experience with our service?' },
    { input: 'Tell me about the customer support' },
  ],
  scorers: [scorer],
  target: myAgent,
  onItemComplete: ({ scorerResults }) => {
    console.log({
      score: scorerResults[scorer.id].score,
    })
  },
})

console.log(result.scores)
```

有关 `runEvals` 的详情，请参阅 [runEvals 参考文档](/reference/evals/run-evals)。

如需将此评分器添加到 Agent，请参阅[评分器概览](/docs/evals/overview#adding-scorers-to-agents)。
