# 技能搜索处理器

这`SkillSearchProcessor`是一个**输入处理器**这使得按需技能发现和加载成为可能。而不是预先将所有技能元数据注入系统提示符中（例如`SkillsProcessor`），它为Agent提供了两个元Tool（`search_skills`和`load_skill`）让它按需查找并加载技能。当Workspace具有许多技能时，这会减少上下文令牌的使用。

隐藏技能列表但保持标准`skill`, `skill_read`, and `skill_search` tools, use `SkillsProcessor` with `injectCatalog: false` instead. See [Turn off the skills list](/docs/sandbox/skills#turn-off-the-skills-list).

默认情况下，当您仅附加`SkillSearchProcessor` to an agent with a skill-enabled `Workspace`, the agent treats skills as on-demand:

* 默认急切`SkillsProcessor` isn't auto-added.
* `search_skills`和`load_skill` are exposed for discovery and instruction loading.
* 重叠`skill` and `skill_search` tools are hidden.
* `skill_read`保持可用，以便Agent可以读取支持技能文件，例如参考、脚本和资产。

如果您显式配置`SkillsProcessor` alongside `SkillSearchProcessor`, the agent preserves the eager `skill` and `skill_search` tools as an opt-in path.

## 使用示例 {/* #usage-example */}

```typescript
import { SkillSearchProcessor } from '@mastra/core/processors'

const skillSearch = new SkillSearchProcessor({
  workspace,
  search: {
    topK: 5,
    minScore: 0.1,
  },
})
```

## 扩展使用示例 {/* #extended-usage-example */}

```typescript title="src/mastra/agents/skill-agent.ts"
import { Agent } from '@mastra/core/agent'
import { SkillSearchProcessor } from '@mastra/core/processors'
import { Workspace, LocalFilesystem } from '@mastra/core/workspace'

const workspace = new Workspace({
  filesystem: new LocalFilesystem({ basePath: './project' }),
  skills: ['skills'],
  bm25: true,
})

const skillSearch = new SkillSearchProcessor({
  workspace,
  search: {
    topK: 5,
    minScore: 0.1,
  },
})

const agent = new Agent({
  id: 'skill-agent',
  name: 'skill-agent',
  instructions:
    'You are a helpful assistant. Use search_skills to find relevant skills, then load_skill to load their instructions.',
  model: '__GATEWAY_OPENAI_MODEL__',
  workspace,
  inputProcessors: [skillSearch],
})
```

AgentWorkflow程为：

1. Agent收到用户消息
2. Agent来电`search_skills` with keywords (e.g., "api design")
3. Agent审查结果和通话`load_skill` with the skill name
4. 该技能的说明将在下一回合显示为系统消息
5. Agent遵循加载技能的指示

## Workspace文件Tool {/* #workspace-file-tools */}

`SkillSearchProcessor`将技能说明加载到对话中。它不会阻止Workspace文件Tool读取文件。

使用`skill_read` for supporting files that belong to a loaded skill, such as files under `references/`, `scripts/`, or `assets/`.

保留Workspace文件Tool，例如`mastra_workspace_read_file` for explicit file inspection or editing workflows. During normal task execution, the agent doesn't need to read the same `SKILL.md` file after `load_skill` succeeds.

## 与技能处理器相比 {/* #compared-to-skillsprocessor */}

| |技能处理器 |技能搜索处理器 |
| - | - | - |
|缩放|预先注入所有技能 |按需发现|
|上下文使用 |随着技能数量的增加而增长 |恒定（仅加载技能）|
|AgentWorkflow程 |技能始终可见 |Agent根据需要进行搜索和加载 |
|最适合 |技能很少 (\< 10) |许多技能（10+）|
