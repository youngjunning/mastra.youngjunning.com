# TokenLimiterProcessor

`TokenLimiterProcessor` 限制消息中的 Token 数量。根据 `trimMode`，它可以充当提示处理器、输入处理器或输出处理器：

- **提示处理器**（`processLLMRequest`）：在默认的 `best-fit` 和 `contiguous` 裁剪模式下，每次模型调用前都会限制发送给 Provider 的提示 Token 数量，覆盖 Agent 执行循环的每一步。此前的提示处理器（例如 `ToolCallFilter`）完成转换后才会计量，因此只统计实际传给模型的 Token。工具调用与工具结果消息会作为一组保留或移除；裁剪仅对本次请求生效，不修改已存储的消息。
- **输入处理器**（`processInput`）：在 `memory-only` 裁剪模式下，于 Agent 执行循环开始前筛选历史消息，优先保留较新的消息，使其适合上下文窗口
- **输出处理器**：通过流式或非流式处理限制生成回复的 Token 数量，并可配置超限处理策略

## 使用示例 {/* #usage-example */}

```typescript
import { TokenLimiterProcessor } from '@mastra/core/processors'

const processor = new TokenLimiterProcessor({
  limit: 1000,
  strategy: 'truncate',
  countMode: 'cumulative',
})
```

## 输出流行为 {/* #output-stream-behavior */}

作为输出处理器，只有承载生成输出的部分会计入上限：`text-delta` 和 `object`。生命周期部分（例如 `step-start`）、推理增量、响应元数据以及工具部分（`tool-call`、`tool-result`）既不会计数，也不会被暂扣，因此工具调用始终会到达 Agent 执行循环并得到执行。

使用默认的 `truncate` 策略时，首次暂扣输出时，处理器会在流中发出一个临时的 `data-token-limit-reached` 部分：

```typescript oxfmt:false
for await (const part of stream.fullStream) {
  if (part.type === 'data-token-limit-reached') {
    console.log('output truncated at', part.data.limit, 'tokens')
  }
}
```

## 媒体 Token 计数 {/* #media-token-counting */}

图片和文件附件的 Token 数量通过估算得出，而非逐个分词统计；这包括 `file` 消息部分以及形如 `{ data, mediaType }` 的工具结果。图片按每张固定值估算；其他媒体按解码后的字节数估算。远程 URL 和 Provider 文件 ID 因为无法在本地获知大小，会使用固定的后备值。base64 等编码载荷不会被当作文本计数，以免虚高的计数导致历史记录被不必要地裁剪。

## 错误行为 {/* #error-behavior */}

裁剪输入时，`TokenLimiterProcessor` 会在以下情况下抛出 `TripWire` 错误：

- **消息为空**：如果没有可处理的非系统消息，则抛出 TripWire，因为不能在没有消息的情况下发送 LLM 请求。
- **系统消息超限**：如果仅系统消息就超过 Token 上限，则抛出 TripWire，因为不能只发送系统消息，而没有用户或助手消息。
- **没有消息可容纳**：如果剩余 Token 预算容纳不了任何消息，则抛出 TripWire，因为不能发送没有消息的 LLM 请求。

```typescript
import { TripWire } from '@mastra/core/agent'

try {
  await agent.generate('Hello')
} catch (error) {
  if (error instanceof TripWire) {
    console.log('Token limit error:', error.message)
  }
}
```

## 扩展示例 {/* #extended-usage-example */}

### 用作输入处理器（限制上下文窗口） {/* #as-an-input-processor-limit-context-window */}

使用 `inputProcessors` 限制发送给模型的历史消息数量，以保持在上下文窗口上限内：

```typescript title="src/mastra/agents/context-limited-agent.ts"
import { Agent } from '@mastra/core/agent'
import { Memory } from '@mastra/memory'
import { TokenLimiterProcessor } from '@mastra/core/processors'

export const agent = new Agent({
  id: 'context-limited-agent',
  name: 'context-limited-agent',
  instructions: 'You are a helpful assistant',
  model: '__GATEWAY_OPENAI_MODEL__',
  memory: new Memory({/* ... */}),
  inputProcessors: [
    new TokenLimiterProcessor({ limit: 4000 }), // Limits historical messages to ~4000 tokens
  ],
})
```

### 用作逐步处理器（限制多步骤 Token 增长） {/* #as-a-per-step-processor-limit-multi-step-token-growth */}

当 Agent 跨多个步骤使用工具时（例如 `maxSteps > 1`），每一步都会累积之前步骤的对话历史。`TokenLimiterProcessor` 会在每一步实施上限，并在此前的提示处理器运行后，计量即将发送的提示。要统计模型实际收到的提示，请将限制器注册在 `ToolCallFilter` 等会缩短提示的处理器之后：

```typescript title="src/mastra/agents/multi-step-agent.ts"
import { Agent } from '@mastra/core/agent'
import { TokenLimiterProcessor } from '@mastra/core/processors'

export const agent = new Agent({
  id: 'multi-step-agent',
  name: 'multi-step-agent',
  instructions: 'You are a helpful research assistant with access to tools',
  model: '__GATEWAY_OPENAI_MODEL__',
  inputProcessors: [
    new TokenLimiterProcessor({ limit: 8000 }), // Applied at every step
  ],
})

// Each tool call step will be limited to ~8000 input tokens
const result = await agent.generate('Research this topic using your tools', {
  maxSteps: 10,
})
```

处理器 Workflow 不会运行 `processLLMRequest`。因此，放在处理器 Workflow 中的 `TokenLimiterProcessor` 会在 `processInputStep` 中裁剪已存储的消息，此时 `ToolCallFilter` 等提示处理器尚未从请求中移除内容。要统计模型实际收到的提示，请将限制器直接添加到 `inputProcessors`。

### 用作输出处理器（限制回复长度） {/* #as-an-output-processor-limit-response-length */}

使用 `outputProcessors` 限制生成回复的长度：

```typescript title="src/mastra/agents/response-limited-agent.ts"
import { Agent } from '@mastra/core/agent'
import { TokenLimiterProcessor } from '@mastra/core/processors'

export const agent = new Agent({
  id: 'response-limited-agent',
  name: 'response-limited-agent',
  instructions: 'You are a helpful assistant',
  model: '__GATEWAY_OPENAI_MODEL__',
  outputProcessors: [
    new TokenLimiterProcessor({
      limit: 1000,
      strategy: 'truncate',
      countMode: 'cumulative',
    }),
  ],
})
```
