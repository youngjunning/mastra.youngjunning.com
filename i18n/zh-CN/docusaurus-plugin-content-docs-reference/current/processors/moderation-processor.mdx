# ModerationProcessor

`ModerationProcessor` 是一个**混合处理器**，既可处理输入，也可处理输出。它使用 LLM 检测多个类别的不当内容，根据可配置的审核类别评估消息，并按所选策略处理被标记的内容，以维护内容安全。

## 使用示例 {/* #usage-example */}

```typescript
import { ModerationProcessor } from '@mastra/core/processors'

const processor = new ModerationProcessor({
  model: 'openrouter/openai/gpt-oss-safeguard-20b',
  threshold: 0.7,
  strategy: 'block',
  categories: ['hate', 'harassment', 'violence'],
  lastMessageOnly: true,
})
```

## 扩展使用示例 {/* #extended-usage-example */}

### 输入处理 {/* #input-processing */}

```typescript title="src/mastra/agents/moderated-agent.ts"
import { Agent } from '@mastra/core/agent'
import { ModerationProcessor } from '@mastra/core/processors'

export const agent = new Agent({
  id: 'moderated-agent',
  name: 'moderated-agent',
  instructions: 'You are a helpful assistant',
  model: '__GATEWAY_OPENAI_MODEL__',
  inputProcessors: [
    new ModerationProcessor({
      model: 'openrouter/openai/gpt-oss-safeguard-20b',
      categories: ['hate', 'harassment', 'violence'],
      threshold: 0.7,
      strategy: 'block',
      instructions: 'Detect and flag inappropriate content in user messages',
      includeScores: true,
    }),
  ],
})
```

### 批量处理输出 {/* #output-processing-with-batching */}

对于生产环境中的流式输出，可设置 `bufferSize`（例如 `bufferSize: 200`），让 `ModerationProcessor` 按句子而非按文本块发起审核调用。缓冲还能检测跨文本块拆分的内容。文本随后以句子为单位发送给客户端。

将 `ModerationProcessor` 用作输出处理器时，建议与 `BatchPartsProcessor` 结合以优化性能。`BatchPartsProcessor` 会先合并流式文本块，再交给审核处理器，从而减少审核所需的 LLM 调用次数。

```typescript title="src/mastra/agents/output-moderated-agent.ts"
import { Agent } from '@mastra/core/agent'
import { BatchPartsProcessor, ModerationProcessor } from '@mastra/core/processors'

export const agent = new Agent({
  id: 'output-moderated-agent',
  name: 'output-moderated-agent',
  instructions: 'You are a helpful assistant',
  model: '__GATEWAY_OPENAI_MODEL__',
  outputProcessors: [
    // Batch stream parts first to reduce LLM calls
    new BatchPartsProcessor({
      batchSize: 10,
    }),
    // Then apply moderation on batched content
    new ModerationProcessor({
      model: 'openrouter/openai/gpt-oss-safeguard-20b',
      strategy: 'filter',
      chunkWindow: 1,
    }),
  ],
})
```
