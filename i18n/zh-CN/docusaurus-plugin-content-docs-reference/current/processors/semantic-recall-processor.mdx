# SemanticRecall

`SemanticRecall` 是**混合处理器**，通过向量嵌入对对话历史进行语义搜索。处理输入时，它搜索相关的历史消息；处理输出时，它为新消息生成嵌入，供后续语义检索使用。如果向量存储支持自行生成嵌入，且未配置 `embedder`，处理器会将消息文本交给存储，由存储生成嵌入。

## 使用示例 {/* #usage-example */}

```typescript
import { SemanticRecall } from '@mastra/core/processors'
import { openai } from '@ai-sdk/openai'

const processor = new SemanticRecall({
  storage: memoryStorage,
  vector: vectorStore,
  embedder: openai.embedding('text-embedding-3-small'),
  topK: 5,
  messageRange: 2,
  scope: 'resource',
})
```

## 扩展使用示例 {/* #extended-usage-example */}

```typescript title="src/mastra/agents/semantic-memory-agent.ts"
import { Agent } from '@mastra/core/agent'
import { SemanticRecall, MessageHistory } from '@mastra/core/processors'
import { PostgresStore, PgVector } from '@mastra/pg'
import { openai } from '@ai-sdk/openai'

const storage = new PostgresStore({
  id: 'pg-storage',
  connectionString: process.env.DATABASE_URL,
})

const vector = new PgVector({
  id: 'pg-vector',
  connectionString: process.env.DATABASE_URL,
})

const semanticRecall = new SemanticRecall({
  storage,
  vector,
  embedder: openai.embedding('text-embedding-3-small'),
  topK: 5,
  messageRange: { before: 2, after: 1 },
  scope: 'resource',
  threshold: 0.7,
})

export const agent = new Agent({
  id: 'semantic-memory-agent',
  name: 'semantic-memory-agent',
  instructions: 'You are a helpful assistant with semantic memory recall',
  model: '__GATEWAY_OPENAI_MODEL__',
  inputProcessors: [semanticRecall, new MessageHistory({ storage, lastMessages: 50 })],
  outputProcessors: [semanticRecall, new MessageHistory({ storage })],
})
```

## 行为 {/* #behavior */}

### 输入处理 {/* #input-processing */}

1. 从最后一条用户消息中提取查询
1. 为查询生成嵌入
1. 执行向量搜索，查找语义相近的消息
1. 根据 `messageRange` 检索匹配消息及其前后上下文
1. 当 `scope: 'resource'` 时，将跨线程消息格式化为带时间戳的系统消息
1. 将召回的消息加入列表，并标记 `source: 'memory'`

### 输出处理 {/* #output-processing */}

1. 提取新用户消息和助手消息中的文本，跳过同一次运行中已生成嵌入的消息
1. 将长消息拆分为不超过 `maxChunkChars` 个字符的块，并为每块生成嵌入
1. 为每块存储一条向量记录，附带线程元数据、消息 ID、线程 ID、资源 ID、角色、内容和时间戳。记录 ID 由消息 ID 派生（首块直接使用 UUID 格式的消息 ID），因此再次保存同一消息会替换原有记录，而不会新增记录
1. 使用 LRU 缓存保存嵌入，避免重复调用 API

### 跨线程召回 {/* #cross-thread-recall */}

当 `scope` 设为 `'resource'` 时，处理器可以召回其他线程的消息。这些跨线程消息会被格式化为系统消息，并附带时间戳和对话标签，说明对话发生的时间及位置。
