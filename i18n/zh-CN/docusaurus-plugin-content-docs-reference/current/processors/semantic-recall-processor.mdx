# 语义回忆

这`SemanticRecall`是一个**混合处理器**可以使用向量嵌入对对话历史进行语义搜索。输入时，它执行语义搜索以查找相关的历史消息。在输出时，它为新消息创建嵌入，以实现未来的语义检索。具有自嵌入向量存储并且没有`embedder`，它将消息文本发送到存储，存储创建嵌入。

## 使用示例 {/* #usage-example */}

```typescript
import { SemanticRecall } from '@mastra/core/processors'
import { openai } from '@ai-sdk/openai'

const processor = new SemanticRecall({
  storage: memoryStorage,
  vector: vectorStore,
  embedder: openai.embedding('text-embedding-3-small'),
  topK: 5,
  messageRange: 2,
  scope: 'resource',
})
```

## 扩展使用示例 {/* #extended-usage-example */}

```typescript title="src/mastra/agents/semantic-memory-agent.ts"
import { Agent } from '@mastra/core/agent'
import { SemanticRecall, MessageHistory } from '@mastra/core/processors'
import { PostgresStore, PgVector } from '@mastra/pg'
import { openai } from '@ai-sdk/openai'

const storage = new PostgresStore({
  id: 'pg-storage',
  connectionString: process.env.DATABASE_URL,
})

const vector = new PgVector({
  id: 'pg-vector',
  connectionString: process.env.DATABASE_URL,
})

const semanticRecall = new SemanticRecall({
  storage,
  vector,
  embedder: openai.embedding('text-embedding-3-small'),
  topK: 5,
  messageRange: { before: 2, after: 1 },
  scope: 'resource',
  threshold: 0.7,
})

export const agent = new Agent({
  id: 'semantic-memory-agent',
  name: 'semantic-memory-agent',
  instructions: 'You are a helpful assistant with semantic memory recall',
  model: '__GATEWAY_OPENAI_MODEL__',
  inputProcessors: [semanticRecall, new MessageHistory({ storage, lastMessages: 50 })],
  outputProcessors: [semanticRecall, new MessageHistory({ storage })],
})
```

## 行为 {/* #behavior */}

### 输入处理 {/* #input-processing */}

1. 从最后一条用户消息中提取用户查询
2. 为查询生成嵌入
3. 执行矢量搜索以查找语义相似的消息
4. 检索匹配的消息以及周围的上下文（基于`messageRange`)
5. 为了`scope: 'resource'`, formats cross-thread messages as a system message with timestamps
6. 添加召回消息`source: 'memory'` tag

### 输出处理 {/* #output-processing */}

1. 从新用户和助理消息中提取文本内容，跳过同一运行中先前已嵌入的消息
2. 将长消息分割成最多`maxChunkChars` characters and generates an embedding for each chunk
3. 每个块存储一个向量行以及元数据（线程元数据、消息 ID、线程 ID、资源 ID、角色、内容、时间戳）。行 ID 源自消息 ID（第一个块按原样使用 UUID 消息 ID），因此再次保存相同的消息会替换其行，而不是添加新行
4. 使用 LRU 缓存进行嵌入以避免冗余 API 调用

### 跨线程召回 {/* #cross-thread-recall */}

什么时候`scope` is set to `'resource'`, the processor can recall messages from other threads. These cross-thread messages are formatted as a system message with timestamps and conversation labels to provide context about when and where the conversation occurred.
