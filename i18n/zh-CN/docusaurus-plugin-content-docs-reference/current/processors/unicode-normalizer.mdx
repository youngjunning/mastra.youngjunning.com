# Unicode标准化器

这`UnicodeNormalizer`是一个**输入处理器**它规范 Unicode 文本以确保格式一致，并在消息发送到语言模型之前删除可能有问题的字符。该处理器始终将文本规范化为 Unicode NFKC 形式。规范化形式不可配置。它还标准化了空白格式。控制字符删除是可选的：设置`stripControlChars`到`true`来启用它。

## 使用示例 {/* #usage-example */}

```typescript
import { UnicodeNormalizer } from '@mastra/core/processors'

const processor = new UnicodeNormalizer({
  stripControlChars: true,
  collapseWhitespace: true,
})
```

## 扩展使用示例 {/* #extended-usage-example */}

```typescript title="src/mastra/agents/normalized-agent.ts"
import { Agent } from '@mastra/core/agent'
import { UnicodeNormalizer } from '@mastra/core/processors'

export const agent = new Agent({
  id: 'normalized-agent',
  name: 'normalized-agent',
  instructions: 'You are a helpful assistant',
  model: '__GATEWAY_OPENAI_MODEL__',
  inputProcessors: [
    new UnicodeNormalizer({
      stripControlChars: true,
      preserveEmojis: true,
      collapseWhitespace: true,
      trim: true,
    }),
  ],
})
```
