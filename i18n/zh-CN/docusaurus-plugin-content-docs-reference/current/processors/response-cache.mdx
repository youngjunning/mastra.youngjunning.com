# 响应缓存

:::beta

在 API 稳定之前，即使不提升主版本号，也可能引入破坏性变更。

:::

`ResponseCache` 是输入处理器，在 Agent 循环的请求与响应边界缓存 LLM 响应。它通过 `processLLMRequest` 查询缓存；命中时直接返回缓存结果，并通过 `processLLMResponse` 写入已完成的响应。

缓存键根据 Mastra 即将发送给模型的最终 `LanguageModelV2Prompt` 生成，也就是在加载记忆、先前的输入处理器修改提示词*之后*生成。因此，不同用户的记忆上下文不同，缓存键也不同。Agent 工具循环中的每一步都会单独缓存。

Agent 没有用于响应缓存的专门选项。请将 `ResponseCache` 显式注册到 `inputProcessors`。如需覆盖单次调用的配置，可通过 [`ResponseCache.context()`](#static-helpers) 和 [`ResponseCache.applyContext()`](#static-helpers) 将配置写入 `RequestContext`。

## 使用示例 {/* #usage-example */}

```typescript
import { Agent } from '@mastra/core/agent'
import { InMemoryServerCache } from '@mastra/core/cache'
import { ResponseCache } from '@mastra/core/processors'

const cache = new InMemoryServerCache()

const agent = new Agent({
  id: 'search-agent',
  name: 'Search Agent',
  instructions: 'You answer questions concisely.',
  model: '__GATEWAY_OPENAI_MODEL_BASE__',
  inputProcessors: [new ResponseCache({ cache, ttl: 600 })],
})

// First call hits the LLM and writes to the cache.
await agent.generate('What is the capital of France?')

// Second identical call replays the cached response.
await agent.generate('What is the capital of France?')

// Force a fresh call but still update the cache.
await agent.generate('What is the capital of France?', {
  requestContext: ResponseCache.context({ bust: true }),
})
```

有关概念说明、作用域规则和推荐的部署方式，请参阅[响应缓存](/docs/agents/processors#response-caching)。

## 静态助手 {/* #static-helpers */}

`ResponseCache` 提供两个静态辅助方法，用于在 `RequestContext` 中覆盖单次调用的配置。它们将底层上下文键保留为私有实现细节；请优先使用这两个方法，而不是直接读写原始键。

### `ResponseCache.context(options)` {/* #responsecachecontextoptions */}

创建一个新的 `RequestContext`，并预先写入单次调用的响应缓存覆盖配置。

```typescript
await agent.stream('hello', {
  requestContext: ResponseCache.context({ key: 'custom', bust: true }),
})
```

### `ResponseCache.applyContext(requestContext, options)` {/* #responsecacheapplycontextrequestcontext-options */}

将单次调用的响应缓存覆盖配置合并到已有的 `RequestContext`，并返回同一个上下文，便于链式调用。

```typescript
const ctx = new RequestContext()
ctx.set('caller-meta', { userId: 'u-123' })
ResponseCache.applyContext(ctx, { bust: true })
await agent.stream('hello', { requestContext: ctx })
```

## 助手导出 {/* #helper-exports */}

- `buildResponseCacheKey(inputs)`：默认使用的确定性哈希函数。重新导出后，可以覆盖个别字段，同时保留标准缓存键的其余字段。
- `DEFAULT_RESPONSE_CACHE_TTL_SECONDS`：默认 `ttl`（`300`）。
- `RESPONSE_CACHE_CONTEXT_KEY`：静态辅助方法写入的 `RequestContext` 键。此键可用于在流程中途清除覆盖配置等高级场景；一般请优先使用辅助方法。
