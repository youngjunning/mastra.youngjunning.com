# ToolCallFilter

`ToolCallFilter` 是一种**输入处理器**，可从发送给模型的提示中滤除工具调用及其结果。你可以用它从上下文中排除特定工具交互，也可以移除所有工具调用。

过滤发生在 `processLLMRequest` 钩子中，此时消息列表已转换为模型提示。改动仅在本次调用中生效，只影响发送给模型的内容；已存储的消息、记忆和 UI 历史仍保留原始工具调用及其结果。

## 使用示例 {/* #usage-example */}

```typescript
import { ToolCallFilter } from '@mastra/core/processors'

// Exclude all tool calls
const filterAll = new ToolCallFilter()

// Exclude specific tools by name
const filterSpecific = new ToolCallFilter({
  exclude: ['searchDatabase', 'sendEmail'],
})

// Enable filtering during agent loops and keep the two most recent tool-producing steps
const filterAfterRecentTools = new ToolCallFilter({
  filterAfterToolSteps: 2,
})

// Preserve compact model-facing output for filtered completed tool results
const filterWithCompactToolHistory = new ToolCallFilter({
  preserveModelOutput: true,
})
```

## 按步骤过滤 {/* #step-filtering */}

默认情况下，`ToolCallFilter` 会过滤历史中的工具调用，但保留当前 Agent 循环产生的工具调用。设置 `filterAfterToolSteps` 后，也会过滤当前循环产生的工具调用。

`filterAfterToolSteps` 统计产生工具调用的步骤。例如，`filterAfterToolSteps: 2` 保留最近两个此类步骤的工具调用及结果，并过滤更早的工具调用及结果。非工具文本仍留在上下文中。

设置 `filterAfterToolSteps: 0`，可在每个步骤中过滤此前所有工具调用及结果。

```typescript
const filter = new ToolCallFilter({
  filterAfterToolSteps: 2,
})
```

## 保留精简的模型输出 {/* #preserve-compact-model-output */}

设置 `preserveModelOutput: true`，可保留被过滤的工具结果对应的精简版 `toModelOutput` 历史。过滤器会用提示中的单个文本片段替换被移除的工具调用及结果，让模型看到输出，但看不到原始工具参数。

没有可表示为文本的模型输出时，工具结果会被完全移除。

```typescript
const filter = new ToolCallFilter({
  preserveModelOutput: true,
})
```

将 `preserveModelOutput` 与 `exclude` 结合使用，仅保留被过滤工具的精简输出：

```typescript
const filter = new ToolCallFilter({
  exclude: ['searchDatabase'],
  preserveModelOutput: true,
})
```

## 扩展使用示例 {/* #extended-usage-example */}

```typescript title="src/mastra/agents/filtered-agent.ts"
import { Agent } from '@mastra/core/agent'
import { ToolCallFilter } from '@mastra/core/processors'

export const agent = new Agent({
  id: 'filtered-agent',
  name: 'filtered-agent',
  instructions: 'You are a helpful assistant',
  model: '__GATEWAY_OPENAI_MODEL__',
  tools: {
    searchDatabase,
    sendEmail,
    getWeather,
  },
  inputProcessors: [
    // Filter out database search tool calls from context
    // to reduce token usage while keeping other tool interactions
    new ToolCallFilter({
      exclude: ['searchDatabase'],
    }),
  ],
})
```

## 过滤所有工具调用 {/* #filtering-all-tool-calls */}

```typescript
import { Agent } from '@mastra/core/agent'
import { ToolCallFilter } from '@mastra/core/processors'

export const agent = new Agent({
  id: 'no-tools-context-agent',
  name: 'no-tools-context-agent',
  instructions: 'You are a helpful assistant',
  model: '__GATEWAY_OPENAI_MODEL__',
  tools: {
    searchDatabase,
    sendEmail,
  },
  inputProcessors: [
    // Remove all tool calls from the message history
    // The agent can still use tools, but previous tool interactions
    // won't be included in the context
    new ToolCallFilter(),
  ],
})
```
