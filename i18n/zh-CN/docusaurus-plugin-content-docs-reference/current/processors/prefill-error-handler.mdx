# 预填充错误处理程序

这`PrefillErrorHandler`是一个**错误处理器**处理助理响应预填充错误。当对话以助理消息结束并且模型拒绝请求时，会发生此错误，因为它将其解释为预填充助理响应。

当检测到错误时，处理器会发送一个隐藏的`system-reminder` signal with `continue` as its contents and signals a retry. The reminder is persisted as signal metadata, which keeps it available for retry reconstruction and raw history while standard UI-facing message conversions hide it.

Mastra 将此处理器添加到每个Agent的`errorProcessors` by default, after `ProviderHistoryCompat` and before `StreamErrorRetryProcessor`. It only acts on the first retry attempt, so it needs no configuration. Supply your own instance to tune it. Anything already in your list is kept and the default is only added when its `id`缺席。

## 它是如何运作的 {/* #how-it-works */}

1. LLM API 调用失败，并显示已知的助理预填充拒绝消息
2. `PrefillErrorHandler`检查这是否是第一次重试尝试
3. 它发送一个隐藏的`system-reminder` signal with `continue` as its contents
4. 它返回`{ retry: true }` to signal the LLM call should be retried with the modified messages

处理器现在对 API 拒绝本身做出反应，而不是重新检查对话当前是否以助理消息结束。这使得它能够适应提供者拒绝预填充语义请求的情况，即使尾随消息形状已经被上游转换。

## 使用示例 {/* #usage-example */}

要调整预填充恢复或明确范围，请提供您自己的实例。默认`PrefillErrorHandler` isn't added when you do:

```typescript title="src/mastra/agents/my-agent.ts"
import { Agent } from '@mastra/core/agent'
import { PrefillErrorHandler } from '@mastra/core/processors'

export const agent = new Agent({
  id: 'my-agent',
  name: 'my-agent',
  instructions: 'You are a helpful assistant.',
  model: '__GATEWAY_ANTHROPIC_MODEL_OPUS__',
  errorProcessors: [new PrefillErrorHandler()],
})
```

如果您想要自定义恢复行为，请为您自己的错误处理器提供`processAPIError` method:

```typescript title="src/mastra/agents/custom-error-handling.ts"
import { Agent } from '@mastra/core/agent'
import type { Processor } from '@mastra/core/processors'

const customErrorHandler: Processor = {
  id: 'custom-prefill-error-handler',
  processAPIError({ error, messageList, retryCount }) {
    // Your custom logic here
  },
}

export const agent = new Agent({
  id: 'my-agent',
  name: 'my-agent',
  instructions: 'You are a helpful assistant.',
  model: '__GATEWAY_ANTHROPIC_MODEL_OPUS__',
  errorProcessors: [customErrorHandler],
})
```
