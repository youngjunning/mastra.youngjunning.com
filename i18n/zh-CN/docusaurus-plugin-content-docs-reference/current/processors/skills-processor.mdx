# SkillsProcessor

`SkillsProcessor` 是一个**输入处理器**，会以 `<available_skills>` 列表的形式将可用 Skill 加入系统消息，让模型知道有哪些 Skill，并能通过 `skill` 工具加载。若 Agent 的 Workspace 或自身的 `skills` 选项提供了 Skill，Agent 会自动添加此处理器；只有需要改变 Skill 的展示方式时，才需要自行配置。

设置 `injectCatalog: false` 后，处理器会用一条简短指令替代列表，引导 Agent 通过 `skill_search` 查找 Skill，再通过 `skill` 加载。列表占用过多 token 时可使用此模式。参见[关闭 Skill 列表](/docs/sandbox/skills#turn-off-the-skills-list)。

`skill`、`skill_search` 和 `skill_read` 工具由 Agent 提供，而非此处理器；两种模式下均可使用。如需改用按需提供的 `search_skills` 和 `load_skill` 工具，请使用 [`SkillSearchProcessor`](/reference/processors/skill-search-processor)。两种处理器只配置其一。

## 使用示例 {/* #usage-example */}

```typescript
import { SkillsProcessor } from '@mastra/core/processors'

const skills = new SkillsProcessor({
  workspace,
  format: 'markdown',
})
```

## 扩展示例 {/* #extended-usage-example */}

```typescript title="src/mastra/agents/skill-agent.ts"
import { Agent } from '@mastra/core/agent'
import { SkillsProcessor } from '@mastra/core/processors'
import { Workspace, LocalFilesystem } from '@mastra/core/workspace'

const workspace = new Workspace({
  filesystem: new LocalFilesystem({ basePath: './project' }),
  skills: ['skills'],
  bm25: true,
})

const agent = new Agent({
  id: 'skill-agent',
  name: 'skill-agent',
  instructions: 'You are a helpful assistant.',
  model: '__GATEWAY_OPENAI_MODEL__',
  workspace,
  inputProcessors: [new SkillsProcessor({ injectCatalog: false })],
})
```

关闭列表后，Agent 会通过搜索查找 Skill。无需配置搜索功能，`skill_search` 也能工作；Skill 数量较多时，可像上例一样在 Workspace 中配置 [BM25 或向量搜索](/docs/sandbox/search)，以改善排序。Agent 的工作流程如下：

1. Agent 收到用户消息
1. Agent 使用关键词（例如 "release notes"）调用 `skill_search`
1. Agent 查看结果，并使用 Skill 名称调用 `skill`
1. Agent 遵循已加载 Skill 的指令
