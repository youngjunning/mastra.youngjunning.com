# WorkingMemory

`WorkingMemory` 是一个**输入 Processor**，会将工作记忆数据作为系统消息注入。它从存储中读取持久化信息，并将其整理为给 LLM 的指令，使 Agent 能够在多次对话中保留有关用户的上下文。

## 使用示例 {/* #usage-example */}

```typescript
import { WorkingMemory } from '@mastra/core/processors'

const processor = new WorkingMemory({
  storage: memoryStorage,
  scope: 'resource',
  template: {
    format: 'markdown',
    content: `# User Profile
- **Name**:
- **Preferences**:
- **Goals**:
`,
  },
})
```

## 扩展使用示例 {/* #extended-usage-example */}

```typescript title="src/mastra/agents/personalized-agent.ts"
import { Agent } from '@mastra/core/agent'
import { WorkingMemory, MessageHistory } from '@mastra/core/processors'
import { PostgresStore } from '@mastra/pg'

const storage = new PostgresStore({
  id: 'pg-storage',
  connectionString: process.env.DATABASE_URL,
})

export const agent = new Agent({
  id: 'personalized-agent',
  name: 'personalized-agent',
  instructions: 'You are a helpful assistant that remembers user preferences',
  model: '__GATEWAY_OPENAI_MODEL__',
  inputProcessors: [
    new WorkingMemory({
      storage,
      scope: 'resource',
      template: {
        format: 'markdown',
        content: `# User Information
- **Name**:
- **Location**:
- **Preferences**:
- **Communication Style**:
- **Current Projects**:
`,
      },
    }),
    new MessageHistory({ storage, lastMessages: 50 }),
  ],
  outputProcessors: [new MessageHistory({ storage })],
})
```

## 行为 {/* #behavior */}

### 输入处理 {/* #input-processing */}

1. 从请求上下文中读取 `threadId` 和 `resourceId`
1. 根据作用范围，从以下位置之一读取工作记忆：
   - 线程元数据（`scope: 'thread'`）
   - 资源记录（`scope: 'resource'`）
1. 解析模板（来自 Provider、选项或默认值）
1. 根据模式生成系统指令：
   - **普通模式**：包含存储和更新信息的指导说明，以及模板结构和当前数据
   - **只读模式**（`readOnly: true`）：仅将当前数据作为上下文，不包含更新指令
1. 将指令作为带有 `source: 'memory'` 标记的系统消息添加到消息列表

### 更新工作记忆 {/* #working-memory-updates */}

工作记忆通过 Memory 类提供的 `updateWorkingMemory` 工具更新，而非通过此 Processor 更新。此 Processor 只负责将当前工作记忆状态注入对话。

### 默认模板 {/* #default-template */}

如果未提供模板，Processor 会使用默认的 Markdown 模板，包含以下字段：

- 名、姓
- 地点、职业
- 兴趣、目标
- 事件、事实、项目
