# AgentsMD注射器

`AgentsMDInjector`在模型步骤之前加载目录指令。它扫描消息列表中已完成的Tool调用，最新的在前，并搜索其路径参数`AGENTS.md`, `CLAUDE.md`， 或者`CONTEXT.md`在祖先目录中。

```typescript
import { AgentsMDInjector } from '@mastra/core/processors'

const injector = new AgentsMDInjector({ maxTokens: 1000 })
```

将处理器添加到Agent的`inputProcessors`. Each invocation injects at most one new instruction reminder as a persisted `reactive` signal. The search skips already loaded paths and continues until it finds an uncovered instruction file.

## `ReminderFileReader` {/* #reminderfilereader */}

读取器控制文件访问和可选路径标识。返回一张来自`getReader` when instruction files live in a virtual filesystem or a trusted git ref rather than the current checkout.

`getPathIdentity`适用于搜索内重复数据删除、忽略的静态路径以及持久提醒元数据或标记中的路径。它不会重写读取地址、发出路径、指令内容或存储。它必须接受先前提醒以及当前Tool调用的路径，包括当前结帐中不再存在的文件。

默认本地读取器解析文件系统别名以进行比较。提供任何实例级文件系统覆盖，或自定义读取器，无需`getPathIdentity`, keeps lexical path comparison without adding host filesystem lookups for identity.

对于受信任的 git-ref 读者，可以通过规范项目根目录及其相对于该根目录的路径来识别文件。不解析签出控制的后代符号链接：受信任引用中的两个不同文件保持不同，即使签出使它们指向同一物理文件。

## 可见性和信任 {/* #visibility-and-trust */}

当调用者使用时，提醒保留在模型上下文和存储中[stream exclusions](/reference/streaming/agents/stream) to hide its signal chunks. Exclusions aren't an instruction-trust boundary. Use `isEnabled` and a trusted reader to control whether checkout instructions can be loaded.
