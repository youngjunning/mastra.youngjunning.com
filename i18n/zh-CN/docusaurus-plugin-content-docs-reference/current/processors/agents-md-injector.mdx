# AgentsMDInjector

`AgentsMDInjector` 在模型执行步骤前加载目录指令。它从新到旧扫描消息列表中已完成的 Tool 调用，并根据调用的路径参数，在对应目录及其上级目录中查找 `AGENTS.md`、`CLAUDE.md` 或 `CONTEXT.md`。

```typescript
import { AgentsMDInjector } from '@mastra/core/processors'

const injector = new AgentsMDInjector({ maxTokens: 1000 })
```

将此处理器添加到 Agent 的 `inputProcessors`。每次调用最多注入一条新的指令提醒，并将其作为持久化的 `reactive` 信号保存。搜索会跳过已加载的路径，继续查找尚未覆盖的指令文件。

## `ReminderFileReader` {/* #reminderfilereader */}

读取器同时控制文件访问和可选的路径标识。如果指令文件位于虚拟文件系统或可信的 Git 引用中，而非当前检出目录，应通过 `getReader` 返回相应的读取器。

`getPathIdentity` 用于搜索过程中的去重、忽略静态指令中的路径，以及处理已持久化提醒的元数据或标记中的路径。它不会改写读取地址、输出的路径、指令内容或存储内容。它必须能处理先前提醒和当前 Tool 调用中的路径，包括当前检出目录中已不存在的文件。

默认的本地读取器会解析文件系统别名以便比较。如果在实例级覆写任一文件系统操作，或使用未实现 `getPathIdentity` 的自定义读取器，则仅按路径文本比较，不会为识别路径额外查询宿主文件系统。

对于可信 Git 引用读取器，应使用规范的项目根目录及文件相对该根目录的路径来标识文件。不要解析受检出目录控制的下级符号链接：即使检出目录使可信引用中的两个不同文件指向同一物理文件，它们仍应视为不同文件。

## 可见性与信任 {/* #visibility-and-trust */}

即使调用方使用[流排除选项](/reference/streaming/agents/stream)隐藏此提醒的信号块，它仍会保留在模型上下文和存储中。排除选项不能作为指令的信任边界。应通过 `isEnabled` 和可信读取器控制是否加载检出目录中的指令。
