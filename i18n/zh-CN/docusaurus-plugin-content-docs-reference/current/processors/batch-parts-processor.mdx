# 批量零件处理器

这`BatchPartsProcessor`是一个**输出处理器**将多个流部分一起批处理，以减少流期间的发射频率。该处理器可用于减少网络开销并为用户合并小文本块，同时控制排放以优化流媒体性能。

## 使用示例 {/* #usage-example */}

```typescript
import { BatchPartsProcessor } from '@mastra/core/processors'

const processor = new BatchPartsProcessor({
  batchSize: 5,
  maxWaitTime: 100,
  emitOnNonText: true,
})
```
