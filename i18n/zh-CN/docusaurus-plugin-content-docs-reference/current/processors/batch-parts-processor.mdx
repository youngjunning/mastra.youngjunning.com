# BatchPartsProcessor

`BatchPartsProcessor` 是一种**输出 Processor**，将多个流数据片段合并后发送，以减少流式传输时的发送频率。它可以降低网络开销，并将较小的文本片段合并后交给用户；你还可以控制发送时机，优化流式传输性能。

## 使用示例 {/* #usage-example */}

```typescript
import { BatchPartsProcessor } from '@mastra/core/processors'

const processor = new BatchPartsProcessor({
  batchSize: 5,
  maxWaitTime: 100,
  emitOnNonText: true,
})
```

## 扩展使用示例 {/* #extended-usage-example */}

```typescript title="src/mastra/agents/batched-agent.ts"
import { Agent } from '@mastra/core/agent'
import { BatchPartsProcessor } from '@mastra/core/processors'

export const agent = new Agent({
  id: 'batched-agent',
  name: 'batched-agent',
  instructions: 'You are a helpful assistant',
  model: '__GATEWAY_OPENAI_MODEL__',
  outputProcessors: [
    new BatchPartsProcessor({
      batchSize: 5,
      maxWaitTime: 100,
      emitOnNonText: true,
    }),
  ],
})
```
