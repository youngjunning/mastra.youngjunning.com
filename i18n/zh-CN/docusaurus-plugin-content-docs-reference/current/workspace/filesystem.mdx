# WorkspaceFilesystem

**引入版本：** `@mastra/core@1.1.0`

### `stat(path)` {/* #statpath */}

获取文件或目录元数据。

```typescript
const stat = await filesystem.stat('docs/guide.md')
// { name: 'guide.md', path: 'docs/guide.md', type: 'file', size: 1234, createdAt: Date, modifiedAt: Date }
```

**返回：** `Promise<FileStat>`

```typescript
interface FileStat {
  name: string // File or directory name (basename only)
  path: string // Path within the filesystem namespace; relative to basePath for LocalFilesystem
  type: 'file' | 'directory'
  size: number
  createdAt: Date
  modifiedAt: Date
  mimeType?: string
}
```

内置的 `read_file` Tool 根据 `mimeType` 决定如何返回文件。类型与 Tool 的 `mediaTypes` 选项匹配的文件会以原生媒体内容返回，大小上限为 `maxMediaBytes`。除非调用方传入 `encoding`，更大的文件只返回元数据。默认支持 PNG、JPEG、WebP 和 PDF。未匹配 `mediaTypes` 的文件，如果没有 `mimeType`、属于文本类类型，或类型为 `application/octet-stream`，则以文本返回。有关 `mediaTypes` 和 `maxMediaBytes` 选项，请参阅 [Agent Tool](/reference/workspace/workspace-class#filesystem-tools)。如果自定义文件系统始终不设置 `mimeType`，图像和 PDF 也会以文本返回。

只为文件设置 `mimeType`，目录不设置。`LocalFilesystem` 使用 `@mastra/core/workspace` 中的 `getMimeType()` 根据扩展名查找类型。对于未知扩展名，它返回 `application/octet-stream`。

```typescript
import { getMimeType } from '@mastra/core/workspace'

const mimeType = type === 'file' ? getMimeType(path) : undefined
```

### `walk(path, options?)` {/* #walkpath-options */}

由 Provider 原生执行递归目录树遍历，并尽量减少调用次数。实现此方法后，Workspace 的 `list_files` Tool 会使用它，无需对每个目录分别调用一次 `readdir`；这对远程 Provider（如 Sandbox、对象存储）尤其重要。如果 `walk` 抛出错误，Tool 会自动改用基于 `readdir` 的遍历，并通过 Workspace 日志记录警告，因为回退方式需要对每个目录分别调用一次。

```typescript
const entries = await filesystem.walk?.('.', { maxDepth: 3 })
// [{ name: 'index.ts', type: 'file', path: 'src/index.ts' }, ...]
```

### `grep(options)` {/* #grepoptions */}

由 Provider 原生执行内容搜索（例如在 Sandbox 内使用 `rg` 或 `grep`）。实现此方法后，Workspace 的 `grep` Tool 会将搜索交给它处理，无需下载所有文件并在宿主端搜索。如果某个模式无法原生执行，应抛出 `UnsupportedGrepPatternError`，以便调用方捕获后回退到宿主端实现。此类回退以 `info` 级别记录；`grep` 的其他错误也会触发回退，但会记录警告，因为宿主端搜索需要读取每个候选文件。

```typescript
const results = await filesystem.grep?.({
  pattern: 'TODO',
  path: '.',
  caseSensitive: true,
  includeHidden: false,
})
// [{ path: 'src/index.ts', matches: [{ line: 3, column: 6, text: '// TODO: fix' }] }]
```
