# 沙盒进程管理器

**添加于：** `@mastra/core@1.7.0`

用于管理Sandbox中后台进程的抽象基类。提供生成进程、列出进程、通过 PID 获取句柄以及终止进程的方法。

[`BlaxelSandbox`](/integrations/sandboxes/blaxel), [`DaytonaSandbox`](/integrations/sandboxes/daytona), [`E2BSandbox`](/integrations/sandboxes/e2b), [`ModalSandbox`](/integrations/sandboxes/modal)， 和[`LocalSandbox`](/reference/workspace/local-sandbox)所有这些都包含内置的流程管理器。除非您正在构建自定义Sandbox提供程序，否则不需要直接实例化此类。

## 使用示例 {/* #usage-example */}

通过Sandbox访问进程管理器`processes` property:

```typescript title="src/mastra/index.ts"
import { LocalSandbox } from '@mastra/core/workspace'

const sandbox = new LocalSandbox({ workingDirectory: './workspace' })
await sandbox.start()

// Spawn a background process
const handle = await sandbox.processes.spawn('node server.js', {
  env: { PORT: '3000' },
  onStdout: data => console.log(data),
})

// List all tracked processes
const procs = await sandbox.processes.list()

// Get a handle by PID
const proc = await sandbox.processes.get(handle.pid)

// Kill a process
await sandbox.processes.kill(handle.pid)
```

## 方法 {/* #methods */}

```typescript
const handle = await sandbox.processes.spawn('npm run dev', {
  cwd: '/app',
  env: { NODE_ENV: 'development' },
  onStdout: data => console.log(data),
})
```

### `list()` {/* #list */}

列出所有跟踪的进程。返回有关每个进程的信息，包括 PID、运行状态和退出代码。

已退出的进程将保留在列表中，直到有人用以下命令读取它`get(pid)`, so a finished command's output can still be read.

```typescript
const procs = await sandbox.processes.list()
for (const proc of procs) {
  console.log(proc.pid, proc.running, proc.exitCode)
}
```

**返回：** `Promise<ProcessInfo[]>`

### `get(pid, options?)` {/* #getpid-options */}

通过PID获取进程句柄。退货`undefined` if the process isn't found or has already been dismissed.

读取已退出的进程会将其解散：稍后调用 return`undefined` and it leaves `list()`. Pass `{ release: false }` to read it and leave it available, so one reader can look at a finished process's output without taking it from another, such as the agent that started it.

```typescript
const handle = await sandbox.processes.get('1234')
if (handle) {
  console.log(handle.stdout)
  await handle.kill()
}

// Read without dismissing an exited process
const peek = await sandbox.processes.get('1234', { release: false })
```

### `kill(pid)` {/* #killpid */}

通过PID杀死一个进程。返回之前等待进程终止。退货`true` if the process was killed, `false` if it wasn't found.

```typescript
const killed = await sandbox.processes.kill(handle.pid)
```

**返回：** `Promise<boolean>`

## `ProcessHandle` {/* #processhandle */}

生成的后台进程的句柄。提供读取输出、发送或关闭标准输入、等待完成以及终止进程的方法。

你不创造`ProcessHandle` instances directly. They're returned by `spawn()` and `get()`.

### 使用示例 {/* #usage-example-1 */}

```typescript
const handle = await sandbox.processes.spawn('npm run dev', {
  onStdout: data => console.log(data),
})

// Read accumulated output
console.log(handle.pid)
console.log(handle.stdout)
console.log(handle.stderr)
console.log(handle.exitCode) // undefined while running

// Wait for completion
const result = await handle.wait()

// Send stdin and signal EOF
await handle.sendStdin('input data\n')
await handle.closeStdin()

// Kill the process
await handle.kill()
```

### 方法 {/* #methods-1 */}

#### `wait(options?)` {/* #waitoptions */}

等待进程退出并返回结果。可选择通过`onStdout`/`onStderr` callbacks to stream output while waiting. Callbacks are automatically removed when `wait()` resolves.

```typescript
// Simple wait
const result = await handle.wait()
console.log(result.success, result.exitCode, result.stdout)

// Wait with streaming
const result = await handle.wait({
  onStdout: data => process.stdout.write(data),
  onStderr: data => process.stderr.write(data),
})
```

#### `kill()` {/* #kill */}

杀死进程。退货`true` if the process was killed, `false` if it had already exited.

```typescript
const killed = await handle.kill()
```

**返回：** `Promise<boolean>`

#### `sendStdin(data)` {/* #sendstdindata */}

将数据发送到进程的标准输入。如果进程已退出或标准输入不可用，则抛出此异常。

```typescript
await handle.sendStdin('console.log("hello")\n')
```

**返回：** `Promise<void>`

#### `closeStdin()` {/* #closestdin */}

关闭进程的标准输入以发出文件结束 (EOF) 信号。在将所有输入发送到读取的命令后使用此命令，直到 stdin 关闭。退出的进程或不可用的标准输入会导致抛出异常。没有标准输入的提供者关闭原语抛出`UnsupportedStdinCloseError`.

```typescript
const handle = await sandbox.processes.spawn('cat')
await handle.sendStdin('input data\n')
await handle.closeStdin()
const result = await handle.wait()
```

呼唤`handle.writer.end()` also closes stdin. On providers without stdin close support, `writer.end()` finishes the stream without an error.

**返回：** `Promise<void>`

## 流互操作 {/* #stream-interop */}

`ProcessHandle`暴露`reader` and `writer` properties for integration with Node.js stream-based protocols like LSP or JSON-RPC:

```typescript
import {
  createMessageConnection,
  StreamMessageReader,
  StreamMessageWriter,
} from 'vscode-jsonrpc/node'

const handle = await sandbox.processes.spawn('typescript-language-server --stdio')

const connection = createMessageConnection(
  new StreamMessageReader(handle.reader),
  new StreamMessageWriter(handle.writer),
)
connection.listen()
```

## 构建自定义流程管理器 {/* #building-a-custom-process-manager */}

要为自定义Sandbox提供程序构建流程管理器，请扩展`SandboxProcessManager` and implement `spawn()` and `list()`. The base class automatically wraps your methods with `ensureRunning()` so the sandbox starts before any process operation.

```typescript
import { SandboxProcessManager, ProcessHandle } from '@mastra/core/workspace'
import type { ProcessInfo, SpawnProcessOptions } from '@mastra/core/workspace'

class MyProcessManager extends SandboxProcessManager<MySandbox> {
  async spawn(command: string, options: SpawnProcessOptions = {}): Promise<ProcessHandle> {
    // Your spawn implementation
    const handle = new MyProcessHandle(/* ... */)
    this._tracked.set(handle.pid, handle)
    return handle
  }

  async list(): Promise<ProcessInfo[]> {
    return Array.from(this._tracked.values()).map(handle => ({
      pid: handle.pid,
      running: handle.exitCode === undefined,
      exitCode: handle.exitCode,
    }))
  }
}
```

通过以下方式将进程管理器传递到您的Sandbox`processes` option in `MastraSandbox`:

```typescript
class MySandbox extends MastraSandbox {
  constructor() {
    super({
      name: 'MySandbox',
      processes: new MyProcessManager(),
    })
  }
}
```

当提供流程管理器时，`MastraSandbox` automatically creates a default `executeCommand` implementation that uses `spawn()` + `wait()`, so you don't need to implement both.
