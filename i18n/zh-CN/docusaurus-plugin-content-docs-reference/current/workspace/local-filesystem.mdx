# 本地文件系统

**新增于：** `@mastra/core@1.1.0`

在本地文件系统的目录中存储文件。接口详情请参见 [WorkspaceFilesystem 接口](/reference/workspace/filesystem)。

## 用法 {/* #usage */}

将 `LocalFilesystem` 添加到 Workspace，并将 Workspace 分配给 Agent。Agent 随后便可在执行任务时读取、写入和管理文件：

```typescript
import { Agent } from '@mastra/core/agent'
import { Workspace, LocalFilesystem } from '@mastra/core/workspace'

const workspace = new Workspace({
  filesystem: new LocalFilesystem({
    basePath: './workspace',
  }),
})

const agent = new Agent({
  id: 'file-agent',
  model: '__GATEWAY_OPENAI_MODEL__',
  workspace,
})

// The agent now has filesystem tools available
const response = await agent.generate('List all files in the workspace')
```

## 方法 {/* #methods */}

### `init()` {/* #init */}

初始化文件系统。如果基本目录不存在，则创建它。

```typescript
await filesystem.init()
```

由 `workspace.init()` 调用。

### 延迟初始化 {/* #lazy-initialization */}

如果尚未初始化，LocalFilesystem 会在首次操作时自动初始化并创建基目录。无需显式调用 `init()`；如果希望在首次操作前预先创建目录，也可以调用它。

### `destroy()` {/* #destroy */}

清理文件系统资源。

```typescript
await filesystem.destroy()
```

由 `workspace.destroy()` 调用。

### `setAllowedPaths(pathsOrUpdater)` {/* #setallowedpathspathsorupdater */}

在运行时更新允许访问的路径。可传入新路径数组来替换现有路径，也可传入接收当前路径并返回新路径集合的回调函数。

```typescript
// Set directly
filesystem.setAllowedPaths(['/home/user/.config'])

// Update with callback
filesystem.setAllowedPaths(prev => [...prev, '/home/user/documents'])

// Clear all allowed paths
filesystem.setAllowedPaths([])
```

## 路径解析 {/* #path-resolution */}

### `basePath` 的工作方式 {/* #how-basepath-works */}

`basePath` 选项设置所有文件操作的根目录。传给 `readFile()` 等方法的路径按以下规则解析：

- 相对路径基于 `basePath` 解析：`docs/guide.md` → `<basePath>/docs/guide.md`
- 使用 `.` 表示 `basePath` 的根目录，例如 `readdir('.')`
- 绝对路径视为主机路径，而非 `basePath` 内部的路径。默认设置 `contained: true` 时，位于 `basePath` 和配置的 `allowedPaths` 之外的绝对路径会被拒绝，并抛出 `PermissionError`
- `~` 会展开为用户主目录，因此也是主机路径，并受相同的路径限制规则约束

```typescript
const filesystem = new LocalFilesystem({
  basePath: './workspace',
})

// Resolves to ./workspace/docs/guide.md
await filesystem.readFile('docs/guide.md')
await filesystem.readFile('./docs/guide.md')

// Root of basePath
await filesystem.readdir('.')

// Throws a PermissionError with the default contained: true
await filesystem.readFile('/docs/guide.md')
```

要读取 `basePath` 之外的主机绝对路径，可将其添加到 `allowedPaths`，或设置 `contained: false`。如果只需访问少数外部目录，建议使用 `allowedPaths`。

```typescript
const filesystem = new LocalFilesystem({
  basePath: './workspace',
  allowedPaths: ['/home/user/shared-docs'],
})

await filesystem.readFile('/home/user/shared-docs/guide.md')
```

### 挂载的文件系统 {/* #mounted-filesystems */}

通过 `CompositeFilesystem` 将 `LocalFilesystem` 挂载到 Workspace 时，Workspace 使用的路径包含挂载前缀。例如，挂载点为 `/workspace` 时，Workspace 路径 `/workspace/report.md` 会作为相对于 `basePath` 的 `report.md` 传给底层文件系统。挂载配置参见[文件系统挂载](/docs/sandbox/filesystem#mounts)。

### 相对路径和执行上下文 {/* #relative-paths-and-execution-context */}

如果 `basePath` 使用相对路径，它会相对于 `process.cwd()` 解析。在 Mastra 项目中，当前工作目录会随代码的运行方式而变化：

| 运行方式 | 工作目录 | `./workspace` 解析为 |
| - | - | - |
| `mastra dev` | `./src/mastra/public/` | `./src/mastra/public/workspace` |
| `mastra start` | `./.mastra/output/` | `./.mastra/output/workspace` |
| 直接运行脚本 | 执行命令时所在的目录 | 相对于该目录的路径 |

当相同的相对路径解析到不同的位置时，这可能会导致混乱。

### 建议使用绝对路径 {/* #recommended-use-absolute-paths */}

为了使所有执行上下文的路径保持一致，请使用带有绝对路径的环境变量：

```typescript
import { LocalFilesystem } from '@mastra/core/workspace'

const filesystem = new LocalFilesystem({
  basePath: process.env.WORKSPACE_PATH!,
})
```

将环境变量 `WORKSPACE_PATH` 设为 `/home/user/my-project/workspace` 这样的绝对路径。这样，无论以何种方式运行代码，Workspace 路径都保持一致。
