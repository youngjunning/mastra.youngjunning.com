# 从 AgentNetwork 迁移到 `.network()`

从 `v0.20.0` 版的 `@mastra/core` 起，适用以下变更。

## 从 AI SDK v4 升级到 v5 {/* #upgrade-from-ai-sdk-v4-to-v5 */}

* 将所有模型 Provider 包升级一个主版本。

:::note

这样可确保它们现在均使用 v5 模型。

:::

## 需要内存 {/* #memory-is-required */}

* Agent 网络现在必须配置内存才能正常运行。

:::note

必须为 Agent 配置内存。

:::

## 迁移路径 {/* #migration-paths */}

如果你正在使用 `AgentNetwork` primitive，可以将 `AgentNetwork` 替换为 `Agent`。

迁移前：

```typescript
import { AgentNetwork } from '@mastra/core/network'

const agent = new AgentNetwork({
  name: 'agent-network',
  agents: [agent1, agent2],
  tools: { tool1, tool2 },
  model: '__GATEWAY_OPENAI_MODEL__',
  instructions: 'You are a network agent that can help users with a variety of tasks.',
})

await agent.stream('Find me the weather in Tokyo.')
```

迁移后：

```typescript
import { Agent } from '@mastra/core/agent'
import { Memory } from '@mastra/memory'

const memory = new Memory()

const agent = new Agent({
  id: 'agent-network',
  name: 'agent-network',
  agents: { agent1, agent2 },
  tools: { tool1, tool2 },
  model: '__GATEWAY_OPENAI_MODEL__',
  instructions: 'You are a network agent that can help users with a variety of tasks.',
  memory,
})

await agent.network('Find me the weather in Tokyo.')
```

如果你正在使用 `NewAgentNetwork` primitive，可以将 `NewAgentNetwork` 替换为 `Agent`。

迁移前：

```typescript
import { NewAgentNetwork } from '@mastra/core/network/vnext'

const agent = new NewAgentNetwork({
  id: 'agent-network',
  name: 'agent-network',
  agents: { agent1, agent2 },
  workflows: { workflow1 },
  tools: { tool1, tool2 },
  model: '__GATEWAY_OPENAI_MODEL__',
  instructions: 'You are a network agent that can help users with a variety of tasks.',
})

await agent.loop('Find me the weather in Tokyo.')
```

迁移后：

```typescript
import { Agent } from '@mastra/core/agent'
import { Memory } from '@mastra/memory'

const memory = new Memory()

const agent = new Agent({
  id: 'agent-network',
  name: 'agent-network',
  agents: { agent1, agent2 },
  workflows: { workflow1 },
  tools: { tool1, tool2 },
  model: '__GATEWAY_OPENAI_MODEL__',
  instructions: 'You are a network agent that can help users with a variety of tasks.',
  memory,
})

await agent.network('Find me the weather in Tokyo.')
```
