# 从 VNext 迁移到标准 API

从 `@mastra/core` 的 `v0.20.0` 版本起，以下变更生效。

## 旧版 API（AI SDK v4） {/* #legacy-apis-ai-sdk-v4 */}

原有方法已更名，并继续兼容 **AI SDK v4** 和 `v1` 模型。

* `.stream()` → `.streamLegacy()`
* `.generate()` → `.generateLegacy()`

## 标准 API（AI SDK v5） {/* #standard-apis-ai-sdk-v5 */}

这些是当前的 API，完全兼容 **AI SDK v5** 和 `v2` 模型。

* `.streamVNext()` → `.stream()`
* `.generateVNext()` → `.generate()`

## 迁移路径 {/* #migration-paths */}

如果你已经在使用 `.streamVNext()` 和 `.generateVNext()`，可通过查找替换，分别将它们改为 `.stream()` 和 `.generate()`。

如果你使用的是旧版 `.stream()` 和 `.generate()`，先决定是否升级。如果暂不升级，可通过查找替换，分别将它们改为 `.streamLegacy()` 和 `.generateLegacy()`。

选择适合你需求的迁移路径：

### 继续使用 AI SDK v4 模型 {/* #keep-using-ai-sdk-v4-models */}

* 将所有 `.stream()` 和 `.generate()` 调用分别改为 `.streamLegacy()` 和 `.generateLegacy()`。

> 无需进一步更改。

### 继续使用 AI SDK v5 模型 {/* #keep-using-ai-sdk-v5-models */}

* 将所有 `.streamVNext()` 和 `.generateVNext()` 调用分别改为 `.stream()` 和 `.generate()`。

> 无需进一步更改。

### 从 AI SDK v4 升级到 v5 {/* #upgrade-from-ai-sdk-v4-to-v5 */}

* 将所有模型 Provider 包升级到下一个主版本。

> 这将确保它们都使用 v5 模型。请阅读下文，了解主要差异并相应更新代码。

## 主要差异 {/* #key-differences */}

更新后的 `.stream()` 和 `.generate()` 与旧版方法在行为、兼容性、返回类型和可用选项方面有所不同。本节介绍迁移时需要了解的主要变化。

### 模型版本支持 {/* #model-version-support */}

**旧版 API**

* `.generateLegacy()`
* `.streamLegacy()`

仅支持 **AI SDK v4** 模型（`specificationVersion: 'v1'`）。

**标准 API**

* `.generate()`
* `.stream()`

仅支持 **AI SDK v5** 模型（`specificationVersion: 'v2'`）。

> 运行时会检查模型版本，并在不兼容时给出明确的错误信息。

### 返回类型 {/* #return-types */}

**旧版 API**

* `.generateLegacy()` 返回：`GenerateTextResult` 或 `GenerateObjectResult`

* `.streamLegacy()` 返回：`StreamTextResult` 或 `StreamObjectResult`

有关详细信息，请参阅以下 API 参考：

* [Agent.generateLegacy()](/reference/agents/generateLegacy)
* [Agent.streamLegacy()](/reference/streaming/agents/streamLegacy)

**标准 API**

* `.generate()`
  * `format: 'mastra'`（默认）：返回 `MastraModelOutput.getFullOutput()`
  * `format: 'aisdk'`：返回 `AISDKV5OutputStream.getFullOutput()`
  * 内部调用 `.stream()`，并等待 `.getFullOutput()` 完成

* `.stream()`
  * `format: 'mastra'`（默认）：返回 `MastraModelOutput<OUTPUT>`
  * `format: 'aisdk'`：返回 `AISDKV5OutputStream<OUTPUT>`

有关详细信息，请参阅以下 API 参考：

* [Agent.generate()](/reference/agents/generate)
* [Agent.stream()](/reference/streaming/agents/stream)

### 格式控制 {/* #format-control */}

#### 旧版 API {/* #legacy-apis */}

没有 `format` 选项：始终返回 AI SDK v4 类型。

```typescript
// Mastra native format (default)
const result = await agent.stream(messages)
```

#### 标准 API {/* #standard-apis */}

使用 `format` 选项选择输出格式：

* `'mastra'`（默认）
* `'aisdk'`（兼容 AI SDK v5）

```typescript
// AI SDK v5 compatibility
const result = await agent.stream(messages, {
  format: 'aisdk',
})
```

### 标准 API 中的新选项 {/* #new-options-in-standard-apis */}

标准 `.stream()` 和 `.generate()` 支持以下选项，旧版方法**不支持**：

* `format` - 选择 `'mastra'` 或 `'aisdk'` 输出格式：

  ```typescript
  const result = await agent.stream(messages, {
    format: 'aisdk', // or 'mastra' (default)
  })
  ```

* `system` - 自定义系统消息（独立于指令）。

  ```typescript
  const result = await agent.stream(messages, {
    system: 'You are a helpful assistant',
  })
  ```

* `structuredOutput` - 支持覆盖模型和设置自定义选项的增强型结构化输出。
  * `jsonPromptInjection` - 覆盖默认向模型传递 `response_format` 的行为，改为在提示词中注入上下文，引导模型返回结构化输出。
  * `model` - 指定模型后，会创建一个子 Agent 来整理主 Agent 的响应。主 Agent 调用 Tool 并返回文本，子 Agent 则返回符合所提供 schema 的对象。此选项取代 `experimental_output`。
  * `errorStrategy` - 指定输出不符合 schema 时的处理方式：

    * 'warn' - 记录警告
    * 'strict' - 抛出错误
    * 'fallback' - 返回你提供的备用值

    ```typescript
    const result = await agent.generate(messages, {
      structuredOutput: {
        schema: z.object({
          name: z.string(),
          age: z.number(),
        }),
        model: '__GATEWAY_OPENAI_MODEL__', // Optional model override for structuring
        errorStrategy: 'fallback',
        fallbackValue: { name: 'unknown', age: 0 },
        instructions: 'Extract user information', // Override default structuring instructions
      },
    })
    ```

* `stopWhen` - 灵活设置停止条件（如步数、token 数量上限）。

  ```typescript
  const result = await agent.stream(messages, {
    stopWhen: ({ steps, totalTokens }) => steps >= 5 || totalTokens >= 10000,
  })
  ```

* `providerOptions` - Provider 专属选项（例如 OpenAI 专属设置）。

  ```typescript
  const result = await agent.stream(messages, {
    providerOptions: {
      openai: {
        store: true,
        metadata: { userId: '123' },
      },
    },
  })
  ```

* `onChunk` - 收到每个流式数据块时调用的回调。

  ```typescript
  const result = await agent.stream(messages, {
    onChunk: chunk => {
      console.log('Received chunk:', chunk)
    },
  })
  ```

* `onError` - 发生错误时调用的回调。

  ```typescript
  const result = await agent.stream(messages, {
    onError: error => {
      console.error('Stream error:', error)
    },
  })
  ```

* `onAbort` - 执行中止时调用的回调。

  ```typescript
  const result = await agent.stream(messages, {
    onAbort: () => {
      console.log('Stream aborted')
    },
  })
  ```

* `activeTools` - 指定本次执行可用的 Tool。

  ```typescript
  const result = await agent.stream(messages, {
    activeTools: ['search', 'calculator'], // Only these tools will be available
  })
  ```

* `abortSignal` - 用于取消执行的 AbortSignal。

  ```typescript
  const controller = new AbortController()
  const result = await agent.stream(messages, {
    abortSignal: controller.signal,
  })

  // Later: controller.abort();
  ```

* `prepareStep` - 多步执行中每一步开始前调用的回调。

  ```typescript
  const result = await agent.stream(messages, {
    prepareStep: ({ step, state }) => {
      console.log('About to execute step:', step)
      return {/* modified state */}
    },
  })
  ```

* `requireToolApproval` - 要求所有 Tool 调用都经过批准。

  ```typescript
  const result = await agent.stream(messages, {
    requireToolApproval: true,
  })
  ```

### 已迁移的旧版选项 {/* #legacy-options-that-moved */}

* `temperature` 和其他模型设置。

  现在统一放在 `modelSettings` 中。

  ```typescript
  const result = await agent.stream(messages, {
    modelSettings: {
      temperature: 0.7,
      maxTokens: 1000,
      topP: 0.9,
    },
  })
  ```

* `resourceId` 和 `threadId`。

  现在放在 `memory` 对象中。

  ```typescript
  const result = await agent.stream(messages, {
    memory: {
      resource: 'user-123',
      thread: 'thread-456',
    },
  })
  ```

### 已弃用或移除的选项 {/* #deprecated-or-removed-options */}

* `experimental_output`

  改用 `structuredOutput`，以便调用 Tool 并返回对象。

  ```typescript
  const result = await agent.generate(messages, {
    structuredOutput: {
      schema: z.object({
        summary: z.string(),
      }),
      model: '__GATEWAY_OPENAI_MODEL__',
    },
  })
  ```

* `output`

  `output` 属性已弃用，请改用 `structuredOutput`。要获得相同的结果，不要指定模型，只需传入 `structuredOutput.schema`；如果模型原生不支持 `response_format`，还可以设置 `jsonPromptInjection: true`。

  ```typescript
  const result = await agent.generate(messages, {
    structuredOutput: {
      schema: z.object({
        name: z.string(),
      }),
    },
  })
  ```

* `memoryOptions`

  改用 `memory`。

  ```typescript
  const result = await agent.generate(messages, {
    memory: {},
  })
  ```

### 类型变更 {/* #type-changes */}

**旧版 API**

* `CoreMessage[]`

有关详细信息，请参阅以下 API 参考：

* [Agent.generateLegacy()](/reference/agents/generateLegacy)
* [Agent.streamLegacy()](/reference/streaming/agents/streamLegacy)

**标准 API**

* `ModelMessage[]`

  `toolChoice` 使用 AI SDK v5 的 `ToolChoice` 类型。

  ```typescript
  type ToolChoice<TOOLS extends Record<string, unknown>> =
    | 'auto'
    | 'none'
    | 'required'
    | {
        type: 'tool'
        toolName: Extract<keyof TOOLS, string>
      }
  ```

有关详细信息，请参阅以下 API 参考：

* [Agent.generate()](/reference/agents/generate)
* [Agent.stream()](/reference/streaming/agents/stream)
