# 嗓音

语音包已从语音重命名为语音，并更新了类名称和 API 方法。

## 改变了 {/* #changed */}

### 语音配置属性名称 {/* #voice-configuration-property-names */}

为了保持一致性，语音配置属性已重命名。`speakProvider` is now `output`, `listenProvider`现在是`input`， 和`realtimeProvider`现在是`realtime`。新名称与每个属性在语音输入和输出中的角色相匹配。

要迁移，请在配置具有语音功能的Agent时更新配置属性名称。

```diff
  const agent = new Agent({
    id: 'agent',
    voice: {
-     speakProvider: murfVoice,
-     listenProvider: deepgramVoice,
-     realtimeProvider: openaiRealtime,
+     output: murfVoice,
+     input: deepgramVoice,
+     realtime: openaiRealtime,
    },
  });
```

:::提示\[代码修改]

您可以使用 Mastra 的 codemod CLI 自动更新您的代码：

```bash
npx @mastra/codemod@latest v1/voice-property-names .
```

:::
