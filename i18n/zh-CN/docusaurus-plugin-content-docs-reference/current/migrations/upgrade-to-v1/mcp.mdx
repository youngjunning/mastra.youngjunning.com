# MCP

MCP（模型上下文协议）Tool执行上下文已被重新组织，并且已弃用的客户端类已被删除。

## 改变了 {/* #changed */}

### `getMCPServers`到`listMCPServers` {/* #getmcpservers-to-listmcpservers */}

这`mastra.getMCPServers()` method has been renamed to `mastra.listMCPServers()`. This change aligns with the naming convention used across the API where plural getter methods use the `list`前缀。

要迁移，请将所有调用替换为`mastra.getMCPServers()` with `mastra.listMCPServers()`.

```diff
- const servers = await mastra.getMCPServers();
+ const servers = await mastra.listMCPServers();
```

:::提示\[代码修改]

您可以使用 Mastra 的 codemod CLI 自动更新您的代码：

```bash
npx @mastra/codemod@latest v1/mastra-plural-apis .
```

:::

### MCP Tool上下文属性组织 {/* #mcp-tool-context-properties-organization */}

MCP Tool中的上下文属性现在组织在`context.mcp` namespace. The namespace organizes MCP-specific functionality under a clear API surface.

要迁移，请访问 MCP 特定的属性，例如`elicitation` and `extra` through `context.mcp` instead of directly from the context parameter.

```diff
  createTool({
    id: 'account-balance',
-   execute: async ({ context, elicitation, extra }) => {
-     await checkAuth(extra.authInfo);
-     const result = await elicitation.sendRequest({
-       message: `Is it ok to fetch account ${context.accountId}?`,
-     });
-   },
+   execute: async (inputData, context) => {
+     await checkAuth(context?.mcp?.extra.authInfo);
+     const result = await context?.mcp?.elicitation.sendRequest({
+       message: `Is it ok to fetch account ${inputData.accountId}?`,
+     });
+   },
  });
```

：：：笔记

`context.mcp.elicitation.sendRequest()`已弃用。它会抛出运行的服务器`@mastra/mcp` 2.x, which serve the MCP `2026-07-28` revision. On those servers, call `context.suspend(payload)` and read the caller's answer from `context.resumeData` when the tool runs again. See [Tools that ask the caller for input suspend and resume](/reference/migrations/mcp-v2#tools-that-ask-the-caller-for-input-suspend-and-resume).

:::

## 已删除 {/* #removed */}

### 已弃用的 MCP 客户端类 {/* #deprecated-mcp-client-classes */}

这`MastraMCPClient` and related deprecated APIs have been removed from `@mastra/mcp`. This change consolidates on the new MCP client API.

要迁移，请使用新的`MCPClient` class instead of deprecated classes.

```diff
- import { MastraMCPClient, MCPConfiguration } from '@mastra/mcp/client';
+ import { MCPClient } from '@mastra/mcp/client';

- const client = new MastraMCPClient({ ... });
- const config = new MCPConfiguration({ ... });
+ const client = new MCPClient({ ... });
```
