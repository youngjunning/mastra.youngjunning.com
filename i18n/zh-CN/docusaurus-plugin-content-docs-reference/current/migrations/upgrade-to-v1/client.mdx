# Client SDK

Client SDK 的变更与服务端 API 更新保持一致，包括工具函数重命名、分页方式更新和类型命名规范调整。

## 变更 {/* #changed */}

### `messages` 现在采用与 `@mastra/core/agent` 相同的调用方式 {/* #messages-is-now-identical-to-mastracoreagent-syntax */}

调用 `generate`、`stream` 和 `network` 方法时，`messages` 现在是第一个参数，与 Node.js 版本的 `@mastra/core/agent` 类似。

迁移时，将 `messages` 移至方法调用的第一个参数：

**使用 `@mastra/client-js`：**

```diff
  const agent = client.getAgent('my-agent');

-  await agent.generate({
-    messages: [...]
+  await agent.generate([...], {
  });

-  await agent.stream({
-    messages: [...]
+  await agent.stream([...], {
  });

-  await agent.network({
-    messages: [...]
+  await agent.network([...], {
  });
```

:::tip[Codemod]

可以使用 Mastra 的 codemod CLI 自动更新代码：

```bash
npx @mastra/codemod@latest v1/client-msg-function-args .
```

:::

### 将 `threadId` 和 `resourceId` 移至 `memory` 选项 {/* #threadid-and-resourceid-to-memory-option */}

Agent 方法调用不再接受 `threadId` 和 `resourceId` 选项。请改用 `memory` 选项，以更简洁的 API 配置记忆功能。此变更同时适用于 `@mastra/client-js` 和 `@mastra/react` 包。

迁移时，将 `threadId` 和 `resourceId` 移至 `memory` 选项中：

**使用 `@mastra/client-js`：**

```diff
  const agent = client.getAgent('my-agent');

  await agent.generate([...], {
-   threadId: 'thread-123',
-   resourceId: 'user-456',
+   memory: {
+     thread: 'thread-123',
+     resource: 'user-456',
+   },
  });

+  await agent.stream([...], {
-   threadId: 'thread-123',
-   resourceId: 'user-456',
+   memory: {
+     thread: 'thread-123',
+     resource: 'user-456',
+   },
  });
```

#### 使用 `@mastra/react` 的 `useChat` hook {/* #using-mastrareact-usechat-hook */}

提供 `threadId` 时，`useChat` hook 会在内部传递 `memory` 选项。如果使用该 hook 内置的记忆处理功能，组件代码无需修改。不过，如果此前手动向 `sendMessage` 传递选项，则需相应更新：

```diff
  const { sendMessage } = useChat({ agentId: 'my-agent' });

  await sendMessage({
    message: 'Hello',
    mode: 'stream',
-   threadId: 'thread-123',
+   threadId: 'thread-123', // Still works - internally converted to memory option
  });
```

创建新线程时，`memory` 选项还支持传入线程元数据：

```typescript oxfmt:false
await agent.generate([...], {
  memory: {
    thread: {
      id: 'thread-123',
      title: 'Support conversation',
      metadata: { category: 'billing' },
    },
    resource: 'user-456',
  },
});
```

### Client SDK 类型由 `Get*` 更名为 `List*` {/* #client-sdk-types-from-get-to-list */}

Client SDK 类型已由 `Get*` 命名模式改为 `List*`，使类型名称与方法命名规范保持一致。

迁移时，请将类型导入更新为新的名称。

```diff
- import type {
-   GetWorkflowRunsParams,
-   GetWorkflowRunsResponse,
-   GetMemoryThreadParams,
- } from '@mastra/client-js';
+ import type {
+   ListWorkflowRunsParams,
+   ListWorkflowRunsResponse,
+   ListMemoryThreadsParams,
+ } from '@mastra/client-js';
```

### 分页参数由 `offset/limit` 改为 `page/perPage` {/* #pagination-parameters-from-offsetlimit-to-pageperpage */}

所有原先使用 `offset/limit` 的 Client SDK 方法现在都使用 `page/perPage`，与基于页码的网页分页方式一致。

迁移时，请更新所有 Client SDK 方法调用中的分页参数。例如：

```diff
  client.memory.listMessages({
    threadId: 'thread-123',
-   offset: 0,
-   limit: 20,
+   page: 0,
+   perPage: 20,
  });
```

- const thread = await client.getMemoryThread(threadId, agentId);

### Workflow 运行统一使用 `runById` API {/* #unified-runbyid-api-for-workflow-runs */}

`runById()` 方法现在返回统一的 `WorkflowState` 对象，其中既包含元数据（runId、workflowName、resourceId、createdAt、updatedAt），也包含处理后的执行状态（status、result、error、payload、steps）。此前分别由 `runById()` 和 `runExecutionResult()` 提供的信息现已合并。

该方法还接受选项对象，其中的 `fields` 和 `withNestedWorkflows` 参数均可选，可用于优化性能。

```diff
  const workflow = client.getWorkflow('my-workflow');

- // Previously: runById returned raw WorkflowRun with snapshot
- const run = await workflow.runById(runId, requestContext);
- // Separately: runExecutionResult returned processed execution state
- const result = await workflow.runExecutionResult(runId);

+ // Now: Single method returns unified WorkflowState
+ const run = await workflow.runById(runId, {
+   requestContext,  // Optional request context
+   fields: ['status', 'result'],  // Optional: request only specific fields
+   withNestedWorkflows: false,  // Optional: skip nested workflow data for performance
+ });
+ // Returns: { runId, workflowName, resourceId, createdAt, updatedAt, status, result, error, payload, steps }
```

## 移除 {/* #removed */}

### `runExecutionResult` 方法和 `GetWorkflowRunExecutionResultResponse` 类型 {/* #runexecutionresult-method-and-getworkflowrunexecutionresultresponse-type */}

`@mastra/client-js` 已移除 `runExecutionResult()` 方法和 `GetWorkflowRunExecutionResultResponse` 类型。`/execution-result` API 端点也已移除。

迁移时，请改用 `runById()`。它现在返回统一的 `WorkflowState`，同时包含元数据和处理后的执行状态。

```diff
- import type { GetWorkflowRunExecutionResultResponse } from '@mastra/client-js';
-
- const workflow = client.getWorkflow('my-workflow');
- const result = await workflow.runExecutionResult(runId);

+ const workflow = client.getWorkflow('my-workflow');
+ const result = await workflow.runById(runId);
+ // Or with options for performance optimization:
+ const result = await workflow.runById(runId, {
+   fields: ['status', 'result'],  // Only fetch specific fields
+   withNestedWorkflows: false,     // Skip expensive nested workflow data
+ });
```

### `toAISdkFormat` 函数 {/* #toaisdkformat-function */}

`@mastra/ai-sdk` 已移除 `toAISdkFormat()` 函数。请改用下方所示的流转换工具。

迁移时，请改用 `toAISdkStream()`。

```diff
- import { toAISdkFormat } from '@mastra/ai-sdk';
- const stream = toAISdkFormat(agentStream, { from: 'agent' });
+ import { toAISdkStream } from '@mastra/ai-sdk';
+ const stream = toAISdkStream(agentStream, { from: 'agent' });
```

### 网络记忆方法 {/* #network-memory-methods */}

`@mastra/client-js` 已移除网络记忆方法。`NetworkMemoryThread` 类及所有与网络记忆相关的方法均不再可用。移除这些专用功能后，记忆 API 更加简洁。

迁移时，请改用常规记忆 API。

```diff
- import { MastraClient } from '@mastra/client-js';
-
- const client = new MastraClient({ baseUrl: '...' });
- const networkThread = client.networkMemory.getThread('thread-id');
- const networkThread = client.memory.networkThread('thread-id', 'network-id');
- await networkThread.get();
- await networkThread.getMessages();

+ // Use regular memory thread APIs instead
+ const client = new MastraClient({ baseUrl: '...' });
+ const thread = client.memory.getThread('thread-id');
+ await thread.get();
+ const messages = await thread.listMessages();
```

### 与 watch 相关的类型 {/* #watch-related-types */}

`@mastra/client-js` 已移除与 watch 相关的类型，包括 `WorkflowWatchResult`、`WatchEvent` 等。此变更与弃用 watch API、转而使用流式传输相对应。

迁移时，请改用 Workflow 的流式传输 API。

```diff
- import type { WorkflowWatchResult, WatchEvent } from '@mastra/client-js';
-
- const workflow = client.getWorkflow('my-workflow');
- const run = await workflow.createRun();
- await run.watch((event: WatchEvent) => {
-   console.log('Event:', event);
- });

+ const workflow = client.getWorkflow('my-workflow');
+ const run = await workflow.createRun();
+ const stream = await run.stream({ inputData: { ... } });
+ for await (const chunk of stream) {
+   console.log('Event:', chunk);
+ }
```

### 无法直接在 Workflow 实例上调用运行相关方法 {/* #run-related-methods-cant-be-called-directly-on-workflow-instance */}

无法直接在 Workflow 实例上调用运行相关方法。必须先使用 `createRun()` 方法创建运行实例。

```diff
- const result = await workflow.start({ runId: '123', inputData: { ... } });
+ const run = await workflow.createRun({ runId: '123' });
+ const result = await run.start({ inputData: { ... } });
```

```diff
- const result = await workflow.stream({ runId: '123', inputData: { ... } });
+ const run = await workflow.createRun({ runId: '123' });
+ const stream = await run.stream({ inputData: { ... } });
```

### `streamVNext`、`resumeStreamVNext` 和 `observeStreamVNext` 方法 {/* #streamvnext-resumestreamvnext-and-observestreamvnext-methods */}

实验性的 `streamVNext()`、`resumeStreamVNext()` 和 `observeStreamVNext()` 方法已移除。它们的功能现已成为标准实现，同时更新了事件结构和返回类型。

迁移时，请改用标准的 `stream()`、`resumeStream()` 和 `observeStream()` 方法。

```diff
+ const run = await workflow.createRun({ runId: '123' });
- const stream = await run.streamVNext({ inputData: { ... } });
+ const stream = await run.stream({ inputData: { ... } });
```

### 已弃用的流式传输端点 {/* #deprecated-stream-endpoints */}

部分流式传输端点已弃用，将来会移除。`/api/agents/:agentId/stream/vnext` 端点返回 410 Gone，`/api/agents/:agentId/stream/ui` 也已弃用。流式传输将统一使用标准端点。

迁移时，请使用标准流式传输端点，或使用 `@mastra/ai-sdk` 转换 UI 消息。

```diff
- const response = await fetch('/api/agents/my-agent/stream/vnext', {
-   method: 'POST',
-   body: JSON.stringify({ messages: [...] }),
- });

+ const response = await fetch('/api/agents/my-agent/stream', {
+   method: 'POST',
+   body: JSON.stringify({ messages: [...] }),
+ });
+
+ // Or use @mastra/ai-sdk for UI message transformations
```

### 网络记忆 API 端点 {/* #network-memory-api-endpoints */}

网络记忆 API 端点（包括 `/api/memory/network/*`）已移除，使记忆 API 更加简洁。

迁移时，请改用常规记忆 API 端点。

```diff
- const networkThread = await fetch('/api/memory/network/threads/thread-123');
+ const thread = await fetch('/api/memory/threads/thread-123');
```

### Client SDK 中与评估相关的类型 {/* #eval-related-client-sdk-types */}

Client SDK 已移除多个与评估相关的类型，包括 `GetEvalsByAgentIdResponse`、`GetTelemetryResponse` 和 `GetTelemetryParams`。此变更与旧版评估功能的移除相对应。

迁移时，请改用新的评分器 API，替代旧版评估功能。
