# 抹布

RAG 包已重命名分块参数并缩小其类型。

## 改变了 {/* #changed */}

### `keepSeparator`到`separatorPosition` {/* #keepseparator-to-separatorposition */}

这`keepSeparator` parameter has been renamed to `separatorPosition` with a simplified type. The old parameter had a confusing `boolean | 'start' | 'end'`键入其中`true`是秘密的别名`'start'`。新参数使用显式`'start' | 'end'`值，省略参数会丢弃分隔符。

要迁移，请替换`keepSeparator` with `separatorPosition` using the mapping below:

|旧值 |新价值|
| - | - |
|`keepSeparator: true` | `separatorPosition: 'start'` |
| `keepSeparator: 'start'` | `separatorPosition: 'start'` |
| `keepSeparator: 'end'` | `separatorPosition: 'end'` |
| `keepSeparator: false` | Remove the parameter |
| Parameter omitted | No change needed |

```diff
  await doc.chunk({
    strategy: 'character',
    separator: '.',
-   keepSeparator: true,
+   separatorPosition: 'start',
  });

  await doc.chunk({
    strategy: 'character',
    separator: '.',
-   keepSeparator: 'end',
+   separatorPosition: 'end',
  });

  await doc.chunk({
    strategy: 'character',
    separator: '.',
-   keepSeparator: false,
+   // Parameter removed - separator is discarded by default
  });
```
