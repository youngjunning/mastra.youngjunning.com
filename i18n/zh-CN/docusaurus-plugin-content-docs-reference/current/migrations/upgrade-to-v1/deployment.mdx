# 部署

OpenAPI 规范端点已移至`/api/openapi.json`，以及`CloudflareDeployer`配置已更新为使用标准`wrangler.json`属性名称。

## 改变了 {/* #changed */}

### OpenAPI 规范端点移至`/api/openapi.json` {/* #openapi-spec-endpoint-moved-to-apiopenapijson */}

OpenAPI 规范端点已从`/openapi.json` to `/api/openapi.json` to align with the `/api` prefix used by all built-in Mastra routes.

如果您有使用 OpenAPI 规范的脚本或Tool，请更新 URL：

```diff
- GET /openapi.json
+ GET /api/openapi.json
```

### `CloudflareDeployer`使用标准`wrangler.json` property names {/* #cloudflaredeployer-uses-standard-wranglerjson-property-names */}

这`CloudflareDeployer` constructor now accepts standard `wrangler.json` property names instead of custom camelCase variants. This change aligns the deployer with Cloudflare's official configuration format and provides access to all wrangler configuration options.

已弃用的字段会在运行时自动迁移，并发出控制台警告，但您应该更新代码以使用新的字段名称。

```diff
  const deployer = new CloudflareDeployer({
-   projectName: 'my-worker',
+   name: 'my-worker',
-   d1Databases: [
+   d1_databases: [
      {
        binding: 'DB',
        database_name: 'my-db',
        database_id: 'xxx',
      },
    ],
-   kvNamespaces: [
+   kv_namespaces: [
      {
        binding: 'KV',
        id: 'yyy',
      },
    ],
  });
```

这`workerNamespace` field has been removed as it's no longer used.

有关所有可用的配置选项，请参阅[Wrangler configuration documentation](https://developers.cloudflare.com/workers/wrangler/configuration/).
