# 部署

OpenAPI 规范端点已迁移到 `/api/openapi.json`，`CloudflareDeployer` 配置已改用 `wrangler.json` 的标准字段名。

## 变更 {/* #changed */}

### OpenAPI 规范端点迁移到 `/api/openapi.json` {/* #openapi-spec-endpoint-moved-to-apiopenapijson */}

OpenAPI 规范端点已从 `/openapi.json` 迁移到 `/api/openapi.json`，与所有 Mastra 内置路由统一使用 `/api` 前缀。

如果脚本或工具会读取 OpenAPI 规范，请更新其中的 URL。

```diff
- GET /openapi.json
+ GET /api/openapi.json
```

### `CloudflareDeployer` 改用 `wrangler.json` 的标准字段名 {/* #cloudflaredeployer-uses-standard-wranglerjson-property-names */}

`CloudflareDeployer` 构造函数现在接受 `wrangler.json` 的标准字段名，取代自定义的 camelCase 字段名。这让部署器与 Cloudflare 官方配置格式保持一致，并支持 Wrangler 的所有配置项。

运行时会自动迁移已弃用的字段，并在控制台输出警告。请更新代码，改用新的字段名。

```diff
  const deployer = new CloudflareDeployer({
-   projectName: 'my-worker',
+   name: 'my-worker',
-   d1Databases: [
+   d1_databases: [
      {
        binding: 'DB',
        database_name: 'my-db',
        database_id: 'xxx',
      },
    ],
-   kvNamespaces: [
+   kv_namespaces: [
      {
        binding: 'KV',
        id: 'yyy',
      },
    ],
  });
```

`workerNamespace` 已不再使用，因此已移除。

所有可用配置项见 [Wrangler 配置文档](https://developers.cloudflare.com/workers/wrangler/configuration/)。
