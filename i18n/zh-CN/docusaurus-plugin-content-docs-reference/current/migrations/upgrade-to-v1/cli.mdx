# CLI

CLI 已移除部署命令、配置标志和初始文件，从而简化使用；同时新增迁移命令，协助升级数据库 schema。

## 新增 {/* #added */}

### `mastra migrate` 命令 {/* #mastra-migrate-command */}

新增的 `mastra migrate` 命令可在升级 Mastra 版本时执行数据库迁移。从可能存在数据不兼容问题的旧版本升级时，这项功能尤其有用。

```bash
npx mastra migrate
```

该命令会先打包项目并连接到已配置的存储，然后执行所有必要的迁移。目前，它支持迁移重复的 span 条目；这些重复条目可能会阻止创建唯一约束。

有关何时需要此迁移的详细说明，请参阅[存储迁移指南](/reference/migrations/upgrade-to-v1/storage#duplicate-spans-migration)。

## 已删除 {/* #removed */}

### `mastra deploy` 命令 {/* #mastra-deploy-command */}

CLI 已移除 `mastra deploy` 命令。此项变更通过移除特定厂商的部署逻辑来简化 CLI。

迁移时，请选择适合你的[部署平台](/docs/deployment/overview)。

### 移除 `--env` 标志（`mastra build`） {/* #--env-flag-from-mastra-build */}

`--env` 标志已从 `mastra build` 命令中移除，从而简化构建命令。

迁移时，请使用 `mastra start --env <env>`，以自定义环境启动构建产物。

```diff
- mastra build --env production
+ mastra build
+ mastra start --env production
```

### 移除 `--port` 标志（`mastra dev`） {/* #--port-flag-from-mastra-dev */}

`--port` 标志已从 `mastra dev` 命令中移除。端口现在通过 Mastra 实例配置统一管理。

迁移时，请在 Mastra 实例中设置 `server.port`，不要再使用 CLI 标志。

```ts
const mastra = new Mastra({
  server: {
    port: 3001,
  },
})
```

### CLI 中的遥测选项 {/* #telemetry-options-from-cli */}

CLI 命令已移除 `telemetry` 选项，包括 `--no-telemetry` / `-nt` 标志。遥测功能现已迁移至 observability 包，因此 CLI 不再提供遥测配置。

迁移时，请从 CLI 命令中删除遥测标志，并使用 `@mastra/observability` 提供的 tracing 功能。
