# 向量存储

向量存储的构造函数现在必须提供 `id` 属性，部分方法也已重命名，以统一命名规范。

## 变更 {/* #changed */}

### 向量存储实例必须提供 `id` {/* #required-id-property-for-vector-store-instances */}

向量存储实例现在必须提供 `id` 属性。Mastra 用这个唯一标识符跟踪和管理实例。应用中的每个向量存储都应使用描述清晰且不重复的字符串作为 `id`。

迁移时，在向量存储的构造函数中添加 `id` 字段。

```diff
  const vectorStore = new PgVector({
+   id: 'main-vector-store',
    connectionString: process.env.POSTGRES_CONNECTION_STRING,
  });

  const chromaStore = new ChromaVector({
+   id: 'chroma-embeddings',
    url: process.env.CHROMA_URL,
  });

  const pineconeStore = new PineconeVector({
+   id: 'pinecone-production',
    apiKey: process.env.PINECONE_API_KEY,
  });
```

### `getVectors` 改为 `listVectors` {/* #getvectors-to-listvectors */}

`getVectors()` 已重命名为 `listVectors()`，与 API 中对获取多个条目的方法使用 `list` 前缀的命名规范保持一致。

迁移时，将所有 `getVectors()` 调用替换为 `listVectors()`。

```diff
  const vectorStore = new VectorStore({ ... });

- const vectors = await vectorStore.getVectors({ ... });
+ const vectors = await vectorStore.listVectors({ ... });
```

### `LibSQLVector`：`connectionUrl` 改为 `url` {/* #libsqlvector-connectionurl-to-url */}

`connectionUrl` 参数已重命名为 `url`，以便与 `@libsql/client` API 及 LibSQLStorage 保持一致。

```diff
  const vectorStore = new LibSQLVector({
    id: 'my-vector',
-   connectionUrl: 'file:./db.sqlite',
+   url: 'file:./db.sqlite',
  });
```

### `OpenSearchVector`：`url` 改为 `node` {/* #opensearchvector-url-to-node */}

`url` 参数已重命名为 `node`，以匹配 OpenSearch 的 `ClientOptions` API。构造函数现在接受所有 OpenSearch 客户端选项，包括身份验证、SSL 和压缩。

```diff
  const vectorStore = new OpenSearchVector({
    id: 'my-vector',
-   url: 'http://localhost:9200',
+   node: 'http://localhost:9200',
  });
```

### `PineconeVector`：移除 `environment` {/* #pineconevector-environment-removed */}

`environment` 参数已移除。如果需要指定自定义控制器主机，请改用 `controllerHostUrl`。构造函数现在接受所有 Pinecone 配置选项。

```diff
  const vectorStore = new PineconeVector({
    id: 'my-vector',
    apiKey: process.env.PINECONE_API_KEY,
-   environment: process.env.PINECONE_ENVIRONMENT,
  });
```

如果需要自定义控制器主机：

```ts
const vectorStore = new PineconeVector({
  id: 'my-vector',
  apiKey: process.env.PINECONE_API_KEY,
  controllerHostUrl: 'https://api.pinecone.io',
})
```
