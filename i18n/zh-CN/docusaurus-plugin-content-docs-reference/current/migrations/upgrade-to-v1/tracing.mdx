# 追踪

Observability系统在 v1 中进行了重组，配备了专用的`@mastra/observability`包裹。本指南涵盖两种迁移路径，具体取决于您要升级的版本。

:::警告\[Observability数据在升级时停止流动]
如果您将 Mastra 软件包升级到 v1 而不迁移您的`telemetry:` config to `observability:`，旧的配置在运行时被忽略。您的服务将干净地启动，没有错误，但是**任何跟踪、日志或指标都不会发送到任何地方**。如果您将数据发送到 Mastra Cloud，仪表板将变为空。

在与您的 Mastra 包发生冲突的同一更改中完成此迁移，并验证跟踪是否出现在[Mastra Studio](/docs/studio/observability) before considering the upgrade complete. If you previously hosted on Mastra Cloud, also follow the [Mastra Cloud migration guide](/reference/migrations/mastra-cloud). The new platform requires a new access token and a Studio project before `MastraPlatformExporter` can route data to it.
:::

:::注意\[出口商重命名]

`MastraPlatformExporter`（发送数据到Mastra平台）取代之前的`CloudExporter`, and `MastraStorageExporter` (persists data to Mastra Storage) replaces the previous `DefaultExporter`. The original classes remain available from `@mastra/observability` and behave identically, but they're deprecated. New code should use `MastraPlatformExporter`和`MastraStorageExporter`。现有进口`CloudExporter`或者`DefaultExporter`继续工作，直到它们在未来的主要版本中被删除。

:::

## 迁移路径 {/* #migration-paths */}

### 来自基于 OTEL 的遥测 (0.x) {/* #from-otel-based-telemetry-0x */}

如果您使用的是旧版`telemetry:` configuration in Mastra, the system has been completely redesigned.

**之前（0.x，带有 OTEL 遥测）：**

```typescript
import { Mastra } from '@mastra/core'

export const mastra = new Mastra({
  telemetry: {
    serviceName: 'my-app',
    enabled: true,
    sampling: {
      type: 'always_on',
    },
    export: {
      type: 'otlp',
      endpoint: 'http://localhost:4318',
    },
  },
})
```

**之后（具有可观察性的 v1）：**

```typescript
import { Mastra } from '@mastra/core'
import {
  Observability,
  MastraStorageExporter,
  MastraPlatformExporter,
  SensitiveDataFilter,
} from '@mastra/observability'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      default: {
        serviceName: 'mastra',
        exporters: [
          new MastraStorageExporter(), // Persists observability events to Mastra Storage
          new MastraPlatformExporter(), // Sends observability events to Mastra platform (if MASTRA_PLATFORM_ACCESS_TOKEN is set)
        ],
        spanOutputProcessors: [
          new SensitiveDataFilter(), // Redacts sensitive data like passwords, tokens, keys
        ],
      },
    },
  }),
})
```

该配置包括`MastraStorageExporter`, `MastraPlatformExporter`, and `SensitiveDataFilter` processor. See the [observability tracing documentation](/docs/observability/tracing/overview) for full configuration options.

#### 之后（带有自定义配置的 v1） {/* #after-v1-with-custom-configuration */}

如果您需要配置特定的导出器（例如 OTLP），请安装导出器包并配置它：

```bash npm2yarn
npm install @mastra/otel-exporter@latest @opentelemetry/exporter-trace-otlp-proto
```

```typescript
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { OtelExporter } from '@mastra/otel-exporter'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      production: {
        serviceName: 'my-app',
        sampling: { type: 'always' },
        exporters: [
          new OtelExporter({
            provider: {
              custom: {
                endpoint: 'http://localhost:4318/v1/traces',
                protocol: 'http/protobuf',
              },
            },
          }),
        ],
      },
    },
  }),
})
```

主要变化：

1. 安装`@mastra/observability` package
2. 代替`telemetry:` with `observability: new Observability()`
3. 使用显式`configs:` with `MastraStorageExporter`, `MastraPlatformExporter`, and `SensitiveDataFilter`
4. 导出类型从字符串文字更改为 (`'otlp'`) to exporter class instances (`new OtelExporter()`)

### 来自人工智能追踪 {/* #from-ai-tracing */}

如果您已经升级到AI追踪（中间系统），则需要安装新包并使用显式配置。

**之前（AI追踪）：**

```typescript
import { Mastra } from '@mastra/core'

export const mastra = new Mastra({
  observability: {
    default: { enabled: true },
  },
})
```

**之后（v1 Observability）：**

```typescript
import { Mastra } from '@mastra/core'
import {
  Observability,
  MastraStorageExporter,
  MastraPlatformExporter,
  SensitiveDataFilter,
} from '@mastra/observability'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      default: {
        serviceName: 'mastra',
        exporters: [new MastraStorageExporter(), new MastraPlatformExporter()],
        spanOutputProcessors: [new SensitiveDataFilter()],
      },
    },
  }),
})
```

主要变化：

1. 安装`@mastra/observability` package
2. 进口`Observability`, exporters, and processors from `@mastra/observability`
3. 使用显式`configs` with `MastraStorageExporter`, `MastraPlatformExporter`, and `SensitiveDataFilter`

## 改变了 {/* #changed */}

### 包导入路径 {/* #package-import-path */}

Observability功能已转移到专用的`@mastra/observability` package.

要迁移，请安装包并更新导入语句：

```bash npm2yarn
npm install @mastra/observability@latest
```

```diff
- import { Tracing } from '@mastra/core/observability';
+ import { Observability } from '@mastra/observability';
```

### 注册表配置 {/* #registry-configuration */}

可观察性注册表现在使用以下配置`Observability` class instance with explicit configs instead of a plain object.

要迁移，请使用`new Observability()` with explicit exporters and processors.

```diff
+ import {
+   Observability,
+   MastraStorageExporter,
+   MastraPlatformExporter,
+   SensitiveDataFilter,
+ } from '@mastra/observability';

  export const mastra = new Mastra({
-   observability: {
-     default: { enabled: true },
-   },
+   observability: new Observability({
+     configs: {
+       default: {
+         serviceName: 'mastra',
+         exporters: [new MastraStorageExporter(), new MastraPlatformExporter()],
+         spanOutputProcessors: [new SensitiveDataFilter()],
+       },
+     },
+   }),
  });
```

### 配置属性`processors` to `spanOutputProcessors` {/* #configuration-property-processors-to-spanoutputprocessors */}

span 处理器的配置属性已重命名为`processors` to `spanOutputProcessors`.

要迁移，请重命名配置对象中的属性。

```diff
+ import { SensitiveDataFilter } from '@mastra/observability';

  export const mastra = new Mastra({
    observability: new Observability({
      configs: {
        production: {
          serviceName: 'my-app',
-         processors: [new SensitiveDataFilter()],
+         spanOutputProcessors: [new SensitiveDataFilter()],
          exporters: [...],
        },
      },
    }),
  });
```

### 出口商方法`exportEvent` to `exportTracingEvent` {/* #exporter-method-exportevent-to-exporttracingevent */}

如果您构建了自定义导出器，则导出器方法已重命名为`exportEvent` to `exportTracingEvent`.

要迁移，请更新自定义导出器中的方法实现。

```diff
  export class MyExporter implements ObservabilityExporter {
-   exportEvent(event: TracingEvent): void {
+   exportTracingEvent(event: TracingEvent): void {
      // export logic
    }
  }
```

## 已删除 {/* #removed */}

### 基于OTEL`telemetry` configuration {/* #otel-based-telemetry-configuration */}

OTEL为基础`telemetry` configuration from 0.x has been removed. The old system with `serviceName`, `sampling.type`, and `export.type` properties is no longer supported.

要迁移，请按照上面的“从基于 OTEL 的遥测”部分进行操作。有关详细配置选项，请参阅[observability tracing documentation](/docs/observability/tracing/overview).

### 自定义仪器文件 {/* #custom-instrumentation-files */}

自动检测仪器文件`/mastra` (with `.ts`, `.js`, or `.mjs` extensions) has been removed. Custom instrumentation is no longer supported through separate files.

要迁移，请使用内置导出器系统或使用`ObservabilityExporter` interface.

### `instrumentation.mjs`文件 {/* #instrumentationmjs-files */}

如果您正在使用`instrumentation.mjs` files to initialize OpenTelemetry instrumentation (common in deployment setups like AWS Lambda), these are no longer needed. The new observability system is configured directly in your Mastra instance.

#### 之前 (0.x) {/* #before-0x */}

您需要一个仪器文件：

```javascript
// instrumentation.mjs
import { NodeSDK } from '@opentelemetry/sdk-node'
// ... OTEL setup
```

并且必须在启动流程时导入它：

```bash
node --import=./.mastra/output/instrumentation.mjs --env-file=".env" .mastra/output/index.mjs
```

#### 之后（v1） {/* #after-v1 */}

只需删除`instrumentation.mjs` file and configure observability in your Mastra instance:

```typescript
// src/mastra/index.ts
import {
  Observability,
  MastraStorageExporter,
  MastraPlatformExporter,
  SensitiveDataFilter,
} from '@mastra/observability'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      default: {
        serviceName: 'mastra',
        exporters: [new MastraStorageExporter(), new MastraPlatformExporter()],
        spanOutputProcessors: [new SensitiveDataFilter()],
      },
    },
  }),
})
```

正常启动您的进程，无需`--import` flag:

```bash
node --env-file=".env" .mastra/output/index.mjs
```

不需要单独的检测文件或特殊的启动标志。

### 安装 {/* #installation */}

**专注的出口商**（Arize、Braintrust、Langfuse、LangSmith）：

```bash npm2yarn
npm install @mastra/[exporter-name]-exporter
```

**OpenTelemetry 导出器**（Dash0、Laminar、New Relic、SigNoz、Traceloop）：

```bash npm2yarn
npm install @mastra/otel-exporter@latest
```

加上您的Provider所需的协议包（请参阅[OTEL guide](/integrations/observability/opentelemetry#exporter)).
