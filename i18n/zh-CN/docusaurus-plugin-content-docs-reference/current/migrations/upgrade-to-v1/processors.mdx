# 处理器

处理器接口已更新为使用一致的命名模式和数据库消息类型。

## 变更 {/* #changed */}

### 处理器配置由 `name` 改为 `id` {/* #processor-configuration-from-name-to-id */}

处理器现在必须提供 `id` 字段，不再以 `name` 作为必填字段；`name` 现为可选字段。新字段使处理器与 Scorer、Agent 等其他 Mastra 实体保持一致。

迁移时，请更新处理器定义，将 `id` 设为必填字段。

```diff
  import type { InputProcessor } from '@mastra/core/processors';

  const processor: InputProcessor = {
-   name: 'my-processor',
+   id: 'my-processor',
+   name: 'My Processor', // optional
    processInput: async ({ messages }) => {
      // ...
    },
  };
```

### 处理器消息类型由 `MastraMessageV2` 改为 `MastraDBMessage` {/* #processor-message-types-from-mastramessagev2-to-mastradbmessage */}

处理器消息类型已由 `MastraMessageV2` 改为 `MastraDBMessage`。处理器和 Scorer 现在使用数据库消息格式及其类型。

迁移时，请更新处理器消息类型的导入和用法。

```diff
  import type { InputProcessor } from '@mastra/core/processors';
- import type { MastraMessageV2 } from '@mastra/core/agent';
+ import type { MastraDBMessage } from '@mastra/core/agent';

  const processor: InputProcessor = {
    id: 'my-processor',
-   processInput: async ({ messages }: { messages: MastraMessageV2[] }) => {
+   processInput: async ({ messages }: { messages: MastraDBMessage[] }) => {
      // ...
    },
  };
```

## 移除内容 {/* #removed */}

### 已弃用的输入处理器导出 {/* #deprecated-input-processor-exports */}

包含内置处理器在内的已弃用输入处理器导出，已从 `@mastra/core/agent/input-processors/processors` 中移除。请改用 `@mastra/core/processors`。此变更将处理器类型统一到 `Processor` 接口下。

如果你使用了 `InputProcessor`，请将其替换为 `Processor`，后者实现了 `processInput` 函数。

```diff
- import { InputProcessor, ModerationProcessor } from '@mastra/core/agent/input-processors/processors';
+ import { Processor, ModerationProcessor } from '@mastra/core/processors';
```

### Memory 处理器导出移至 core {/* #memory-processor-exports-moved-to-core */}

`@mastra/memory/processors` 导出已被移除。所有处理器现在都从 `@mastra/core/processors` 导出，以便将处理器导出集中在同一位置。

迁移时，请将导入路径从 `@mastra/memory/processors` 更新为 `@mastra/core/processors`。

```diff
- import { TokenLimiter, ToolCallFilter } from '@mastra/memory/processors';
+ import { TokenLimiter, ToolCallFilter } from '@mastra/core/processors';
```
