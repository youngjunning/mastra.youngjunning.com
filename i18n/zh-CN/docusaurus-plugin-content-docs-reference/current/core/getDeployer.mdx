# Mastra.getDeployer()

`.getDeployer()` 获取 Mastra 实例中配置的部署器实例。

## 使用示例 {/* #usage-example */}

```typescript
mastra.getDeployer()
```

## 参数 {/* #parameters */}

此方法不接受参数。
