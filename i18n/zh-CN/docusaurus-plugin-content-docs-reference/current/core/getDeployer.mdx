# Mastra.getDeployer()

这`.getDeployer()`方法用于检索已在 Mastra 实例中配置的部署程序实例。

## 使用示例 {/* #usage-example */}

```typescript
mastra.getDeployer()
```

## 参数 {/* #parameters */}

此方法不接受任何参数。
