# Mastra.getWorkflow()

`.getWorkflow()` 方法通过注册键获取 Workflow，并为其输入和输出 schema 提供完整的 TypeScript 类型推断。

## 使用示例 {/* #usage-example */}

```typescript
// Retrieve workflow by its registration key (recommended for type inference)
const workflow = mastra.getWorkflow('testWorkflow')
const run = await workflow.createRun()

// TypeScript will properly infer the input schema type
await run.startAsync({
  inputData: {/* properly typed */},
})
```

## 类型推断 {/* #type-inference */}

为获得最佳 TypeScript 支持，请将 Workflow 的**注册键**（将 Workflow 添加到 Mastra 时使用的键）传给 `getWorkflow()`。注册键可完整推断以下类型：

* 输入数据模式
* 输出数据模式
* 步骤结果

如果需要按 Workflow 的 `id` 属性而非注册键获取它，可以使用 `getWorkflowById()`，但其类型推断不够精确。
