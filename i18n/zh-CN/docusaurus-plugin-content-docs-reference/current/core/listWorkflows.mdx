# Mastra.listWorkflows()

`.listWorkflows()` 获取 Mastra 实例中配置的所有 Workflow。此方法接受一个可选的选项对象。

## 使用示例 {/* #usage-example */}

```typescript
mastra.listWorkflows()
```

## 参数 {/* #parameters */}

<PropertiesTable
  content={[
{
  name: 'options',
  type: '{ serialized?: boolean }',
  description:
    '可选的配置对象。将 `serialized` 设为 true 时，返回只包含 name 属性的简化 Workflow 对象，而非完整实例。',
  optional: true,
},
]}
/>

<PropertiesTable
  content={[

},
]}
