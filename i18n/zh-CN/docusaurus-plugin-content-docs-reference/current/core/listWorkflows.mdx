# Mastra.listWorkflows()

这`.listWorkflows()`方法用于检索已在 Mastra 实例中配置的所有Workflow程。该方法接受一个可选的选项对象。

## 使用示例 {/* #usage-example */}

```typescript
mastra.listWorkflows()
```

  content={[
{
  name: 'options',
  type: '{ serialized?: boolean }',

  optional: true,
},
]}
/>

},
]}
