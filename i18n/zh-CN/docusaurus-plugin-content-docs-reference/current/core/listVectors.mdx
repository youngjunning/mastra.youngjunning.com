# Mastra.listVectors()

这`.listVectors()`方法用于检索已在 Mastra 实例中配置的所有向量存储。

## 使用示例 {/* #usage-example */}

```typescript
mastra.listVectors()
```

## 参数 {/* #parameters */}

此方法不接受任何参数。
