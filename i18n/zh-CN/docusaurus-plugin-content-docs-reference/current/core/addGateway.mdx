# Mastra.addGateway()

动态添加到 Mastra 实例的网关。可以在初始化期间或之后使用。

## 使用示例 {/* #usage-example */}

```typescript
import { Mastra } from '@mastra/core'

const mastra = new Mastra()

// Add with explicit key
mastra.addGateway(new MyCustomGateway(), 'myGateway')

// Add using gateway's ID as the key
mastra.addGateway(new MyCustomGateway())
// Stored with key 'my-custom-gateway' (the gateway's id)
```

## 退货 {/* #returns */}

空白。网关已添加到内部注册表中。

## 行为 {/* #behavior */}

* 如果已经存在相同key的网关，则跳过添加
* 在开发模式下（`MASTRA_DEV=true`), automatically triggers type generation for custom gateways
* 网关立即可用于模型解析
