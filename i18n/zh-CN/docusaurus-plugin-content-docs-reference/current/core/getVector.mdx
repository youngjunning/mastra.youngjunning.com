# Mastra.getVector()

这`.getVector()`方法用于通过名称检索向量存储。该方法接受单个`string`矢量存储名称的参数。

## 使用示例 {/* #usage-example */}

```typescript
mastra.getVector('testVectorStore')
```

]}
