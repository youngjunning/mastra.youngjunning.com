# Mastra.listLogsByRunId()

这`.listLogsByRunId()`方法用于检索特定运行 ID 和传输 ID 的日志。此方法需要一个配置的记录器支持`listLogsByRunId`手术。

## 使用示例 {/* #usage-example */}

```typescript
mastra.listLogsByRunId({ runId: '123', transportId: '456' })
```
