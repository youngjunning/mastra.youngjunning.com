# Mastra.listLogsByRunId()

`.listLogsByRunId()` 方法获取指定运行 ID 和传输 ID 的日志。该方法要求已配置的 logger 支持 `listLogsByRunId` 操作。

## 使用示例 {/* #usage-example */}

```typescript
mastra.listLogsByRunId({ runId: '123', transportId: '456' })
```
