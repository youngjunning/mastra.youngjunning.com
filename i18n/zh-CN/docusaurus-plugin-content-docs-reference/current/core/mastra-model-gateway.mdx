# Mastra模型网关

用于实现自定义模型网关的抽象基类。网关处理用于访问语言模型的特定于提供者的逻辑，包括提供者配置、身份验证、URL 构造和模型实例化。

使用`MastraModelGatewayInterface` when you want to provide a plain object gateway instead of extending the base class.

## 班级概况 {/* #class-overview */}

安装本示例中使用的 OpenAI 兼容提供程序：

```bash npm2yarn
npm install @ai-sdk/openai-compatible
```

```typescript
import {
  MastraModelGateway,
  type GatewayLanguageModel,
  type ProviderConfig,
} from '@mastra/core/llm'
import { createOpenAICompatible } from '@ai-sdk/openai-compatible'

class MyCustomGateway extends MastraModelGateway {
  readonly id = 'custom'
  readonly name = 'My Custom Gateway'

  async fetchProviders(): Promise<Record<string, ProviderConfig>> {
    return {
      'my-provider': {
        name: 'My Provider',
        models: ['__GATEWAY_OPENAI_MODEL__', '__GATEWAY_ANTHROPIC_MODEL_SONNET__'],
        apiKeyEnvVar: 'MY_API_KEY',
        gateway: this.id,
      },
    }
  }

  buildUrl(modelId: string, envVars?: Record<string, string>): string {
    return 'https://api.my-provider.com/v1'
  }

  async getApiKey(modelId: string): Promise<string> {
    const apiKey = process.env.MY_API_KEY
    if (!apiKey) throw new Error('MY_API_KEY not set')
    return apiKey
  }

  async resolveLanguageModel({
    modelId,
    providerId,
    apiKey,
  }: {
    modelId: string
    providerId: string
    apiKey: string
  }): Promise<GatewayLanguageModel> {
    const baseURL = this.buildUrl(`${providerId}/${modelId}`)
    return createOpenAICompatible({
      name: providerId,
      apiKey,
      baseURL,
    }).chatModel(modelId)
  }
}
```

## 型号ID格式 {/* #model-id-format */}

对于真正的网关，网关 ID 用作前缀，并使用以下格式访问模型：

```text
[gateway-id]/[provider]/[model]
```

示例：

* 网关与`id = 'custom'`: `'custom/my-provider/model-1'`

也接受由两部分组成的 ID：

* `[gateway-id]/[model]`：对于ProviderID与网关ID相同的网关，例如`amazon-bedrock`. The provider ID resolves to the gateway ID, so `'custom/model-1'` resolves to provider `custom` and model `model-1`. The model segment can't be empty.
* `azure-openai/[deployment]`：Azure OpenAI 使用部署名称代替提供程序和模型。
