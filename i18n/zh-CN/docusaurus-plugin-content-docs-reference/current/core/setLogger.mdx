# Mastra.setLogger()

`.setLogger()` 为 Mastra 实例中的所有组件（如 Agent 和 Workflow）设置日志记录器。此方法只接受一个对象参数，日志记录器通过该对象的 logger 属性传入。

## 使用示例 {/* #usage-example */}

```typescript
mastra.setLogger({ logger: new PinoLogger({ name: 'testLogger' }) })
```
