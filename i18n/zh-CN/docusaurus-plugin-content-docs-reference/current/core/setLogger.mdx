# Mastra.setLogger()

这`.setLogger()`方法用于设置 Mastra 实例中所有组件（Agent、Workflow等）的记录器。此方法接受带有记录器属性的单个对象参数。

## 使用示例 {/* #usage-example */}

```typescript
mastra.setLogger({ logger: new PinoLogger({ name: 'testLogger' }) })
```
