# getClassifier()

`getClassifier()` 按注册键获取 Mastra 实例中已注册的分类器。找不到分类器时会抛出错误。

## 使用示例 {/* #usage-example */}

```typescript
import { mastra } from './mastra'

const safety = mastra.getClassifier('safety')

const result = await safety.decide({
  state: { content: 'A message to evaluate' },
})
```

## 错误处理 {/* #error-handling */}

如果指定键下没有已注册的分类器，此方法会抛出 ID 为 `MASTRA_GET_CLASSIFIER_NOT_FOUND` 的 `MastraError`。
