# 获取分类器()

这`getClassifier()`方法检索使用其注册密钥向 Mastra 实例注册的分类器。如果未找到请求的分类器，它将引发错误。

## 使用示例 {/* #usage-example */}

```typescript
import { mastra } from './mastra'

const safety = mastra.getClassifier('safety')

const result = await safety.decide({
  state: { content: 'A message to evaluate' },
})
```

## 错误处理 {/* #error-handling */}

这个方法抛出一个`MastraError` with id `MASTRA_GET_CLASSIFIER_NOT_FOUND` if no classifier is registered under the specified key.
