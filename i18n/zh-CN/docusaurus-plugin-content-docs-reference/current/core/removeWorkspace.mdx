# Mastra.removeWorkspace()

`.removeWorkspace()` 从 Mastra 的运行时注册表中移除 Workspace。传入 `{ destroy: true }` 可在移除前销毁它。

## 使用示例 {/* #usage-example */}

```typescript
await mastra.removeWorkspace('workspace-123', { destroy: true })
```

},
]}
/>

## 返回值 {/* #returns */}

<PropertiesTable
  content={[
{
  name: 'removed',
  type: 'Promise<boolean>',
  description: '成功移除时返回 `true`。该 ID 未对应任何 Workspace 时返回 `false`。',
},
]}
/>

如果 `destroy` 为 `true` 且 `workspace.destroy()` 抛出异常，本次调用会以该异常拒绝。Workspace 仍保留在注册表中，调用方可重试清理。
