# Mastra.removeWorkspace()

这`.removeWorkspace()`方法从 Mastra 运行时注册表中删除Workspace。经过`{ destroy: true }`在删除Workspace之前将其销毁。

## 使用示例 {/* #usage-example */}

```typescript
await mastra.removeWorkspace('workspace-123', { destroy: true })
```

什么时候`destroy` is `true` and `workspace.destroy()` throws, the call rejects with that error and the workspace remains registered so the caller can retry cleanup.
