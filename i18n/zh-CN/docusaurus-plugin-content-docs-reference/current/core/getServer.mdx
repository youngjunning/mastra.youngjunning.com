# Mastra.getServer()

这`.getServer()`方法用于检索已在 Mastra 实例中配置的服务器配置。

## 使用示例 {/* #usage-example */}

```typescript
mastra.getServer()
```

## 参数 {/* #parameters */}

此方法不接受任何参数。
