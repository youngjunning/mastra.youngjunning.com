# Mastra.getAgentById()

这`.getAgentById()`方法通过其检索注册Agent`id`。它首先通过搜索注册Agent`agent.id`。如果没有Agent匹配，则回退到[`Mastra.getAgent()`](/reference/core/getAgent)并将提供的值视为Agent注册表项。

使用`mastra.getAgentById(id)` to retrieve the code-defined agent. Use `await mastra.getAgentById(id, version)` to retrieve a versioned agent.

## 使用示例 {/* #usage-example */}

以下示例注册一个Agent并在使用返回的Agent之前通过 ID 检索它。

```typescript title="src/mastra/index.ts"
import { Agent } from '@mastra/core/agent'
import { Mastra } from '@mastra/core/mastra'

const supportAgent = new Agent({
  id: 'support-agent-id',
  name: 'Support Agent',
  instructions: 'Answer support questions clearly and concisely.',
  model: '__GATEWAY_OPENAI_MODEL__',
})

export const mastra = new Mastra({
  agents: {
    supportAgent,
  },
})

const agent = mastra.getAgentById('support-agent-id')

const response = await agent.generate('How can I reset my password?')
```
