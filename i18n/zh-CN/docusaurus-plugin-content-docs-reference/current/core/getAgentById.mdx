# Mastra.getAgentById()

`.getAgentById()` 根据 `id` 获取已注册的 Agent。它先按 `agent.id` 查找；若没有匹配项，则回退到 [`Mastra.getAgent()`](/reference/core/getAgent)，将传入值作为 Agent 注册表的键。

使用 `mastra.getAgentById(id)` 获取代码中定义的 Agent；使用 `await mastra.getAgentById(id, version)` 获取指定版本的 Agent。

## 使用示例 {/* #usage-example */}

以下示例先注册 Agent，再通过 ID 获取并使用它。

```typescript title="src/mastra/index.ts"
import { Agent } from '@mastra/core/agent'
import { Mastra } from '@mastra/core/mastra'

const supportAgent = new Agent({
  id: 'support-agent-id',
  name: 'Support Agent',
  instructions: 'Answer support questions clearly and concisely.',
  model: '__GATEWAY_OPENAI_MODEL__',
})

export const mastra = new Mastra({
  agents: {
    supportAgent,
  },
})

const agent = mastra.getAgentById('support-agent-id')

const response = await agent.generate('How can I reset my password?')
```
