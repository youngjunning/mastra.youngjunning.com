# getClassifierById()

这`getClassifierById()`方法通过搜索其来检索分类器`id`属性，然后回退到注册密钥。

## 使用示例 {/* #usage-example */}

```typescript
import { mastra } from './mastra'

const safety = mastra.getClassifierById('safety')
```

## 参数 {/* #parameters */}

<PropertiesTable
  content={[
{
  name: 'id',
  type: 'string',

  isOptional: false,
},
]}
/>

<PropertiesTable
  content={[
{

## 错误处理 {/* #error-handling */}

这个方法抛出一个`MastraError` with id `MASTRA_GET_CLASSIFIER_BY_ID_NOT_FOUND` if no classifier matches the specified id or key.
