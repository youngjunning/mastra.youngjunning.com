# getClassifierById()

`getClassifierById()` 先按 `id` 属性查找分类器，找不到时再按注册时使用的键查找。

## 使用示例 {/* #usage-example */}

```typescript
import { mastra } from './mastra'

const safety = mastra.getClassifierById('safety')
```

## 错误处理 {/* #error-handling */}

如果没有分类器匹配指定的 id 或注册键，此方法会抛出 `MastraError`，错误 ID 为 `MASTRA_GET_CLASSIFIER_BY_ID_NOT_FOUND`。
