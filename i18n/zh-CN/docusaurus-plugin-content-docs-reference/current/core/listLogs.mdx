# Mastra.listLogs()

`.listLogs()` 方法获取指定传输 ID 的所有日志。此方法要求已配置的 logger 支持 `listLogs` 操作。

## 使用示例 {/* #usage-example */}

```typescript
mastra.listLogs('456')
```
