# Mastra.setStorage()

`.setStorage()` 为 Mastra 实例设置存储实例，只接受一个 `MastraCompositeStore` 参数。

## 使用示例 {/* #usage-example */}

```typescript
mastra.setStorage(
  new LibSQLStore({
    id: 'mastra-storage',
    url: ':memory:',
  }),
)
```
