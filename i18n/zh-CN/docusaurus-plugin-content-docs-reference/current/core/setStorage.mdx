# Mastra.setStorage()

这`.setStorage()`方法用于设置Mastra实例的存储实例。该方法接受单个`MastraCompositeStore`范围。

## 使用示例 {/* #usage-example */}

```typescript
mastra.setStorage(
  new LibSQLStore({
    id: 'mastra-storage',
    url: ':memory:',
  }),
)
```

{

},
]}
/>

## 退货 {/* #returns */}

此方法不返回值。
