# Mastra.getAgent()

`.getAgent()` 按名称获取 Agent，可传入版本选择条件。指定版本选择条件时，此方法返回 Promise。

## 使用示例 {/* #usage-example */}

```typescript
mastra.getAgent('testAgent')
```
