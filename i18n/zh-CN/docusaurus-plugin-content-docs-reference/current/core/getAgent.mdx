# Mastra.getAgent()

这`.getAgent()`方法用于检索Agent。该方法接受Agent的名称和可选的版本选择器。传递版本选择器会返回一个承诺。

## 使用示例 {/* #usage-example */}

```typescript
mastra.getAgent('testAgent')
```
