# Mastra.getStorage()

这`.getStorage()`方法用于检索Mastra实例中已配置的存储实例。

## 使用示例 {/* #usage-example */}

```typescript
mastra.getStorage()
```

## 参数 {/* #parameters */}

此方法不接受任何参数。
