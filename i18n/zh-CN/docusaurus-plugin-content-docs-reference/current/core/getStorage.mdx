# Mastra.getStorage()

`.getStorage()` 获取 Mastra 实例中配置的存储实例。

## 使用示例 {/* #usage-example */}

```typescript
mastra.getStorage()
```

## 参数 {/* #parameters */}

此方法不接受参数。
