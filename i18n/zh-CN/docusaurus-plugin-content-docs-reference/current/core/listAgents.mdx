# Mastra.listAgents()

这`.listAgents()`方法用于检索已在 Mastra 实例中配置的所有Agent。

## 使用示例 {/* #usage-example */}

```typescript
mastra.listAgents()
```

## 参数 {/* #parameters */}

此方法不接受任何参数。
