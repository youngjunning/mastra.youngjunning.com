# Mastra.listAgents()

`.listAgents()` 获取 Mastra 实例中配置的所有 Agent。

## 使用示例 {/* #usage-example */}

```typescript
mastra.listAgents()
```

## 参数 {/* #parameters */}

此方法不接受参数。
