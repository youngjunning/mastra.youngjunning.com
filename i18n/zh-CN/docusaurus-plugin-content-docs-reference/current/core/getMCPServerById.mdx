# Mastra.getMCPServerById()

这`.getMCPServerById()`方法通过其内在属性检索 MCP 服务器实例`id`财产。要通过注册表项（配置中使用的密钥）检索，请使用`.getMCPServer()`反而。

## 使用示例 {/* #usage-example */}

```typescript
// Register an MCP server with a registry key
const myServer = new MCPServer({
  id: 'my-mcp-server',
  name: 'My Server',
  version: '1.0.0',
  tools: {/* ... */},
})

export const mastra = new Mastra({
  mcpServers: {
    customKey: myServer, // 'customKey' is the registry key
  },
})

// Retrieve by intrinsic ID
const server = mastra.getMCPServerById('my-mcp-server')

// Alternatively, retrieve by registry key
const serverByKey = mastra.getMCPServer('customKey')
```

## 笔记 {/* #notes */}

* 服务器的`id` is slugified during construction, so `'myMcpServer'` becomes `'my-mcp-server'`
* 如果多个服务器有相同的`id` but different versions, you must provide the `version` parameter to disambiguate
* 如果没有`version` is provided and multiple versions exist, the method returns the first match
