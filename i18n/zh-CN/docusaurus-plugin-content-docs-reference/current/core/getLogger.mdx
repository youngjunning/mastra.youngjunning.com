# Mastra.getLogger()

`.getLogger()` 返回 Mastra 实例中配置的日志记录器。

## 使用示例 {/* #usage-example */}

```typescript
mastra.getLogger()
```

## 参数 {/* #parameters */}

此方法不接受参数。
