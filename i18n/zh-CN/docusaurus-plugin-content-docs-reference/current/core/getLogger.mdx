# Mastra.getLogger()

这`.getLogger()`方法用于检索已在 Mastra 实例中配置的记录器实例。

## 使用示例 {/* #usage-example */}

```typescript
mastra.getLogger()
```

## 参数 {/* #parameters */}

此方法不接受任何参数。
