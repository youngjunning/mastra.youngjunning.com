# Mastra.getGatewayById()

通过其唯一 ID 检索网关（`id`网关实例的属性）。当您需要通过其固有标识符而不是注册密钥查找网关时，这非常有用。

## 使用示例 {/* #usage-example */}

```typescript
import { Mastra } from '@mastra/core'

const mastra = new Mastra({
  gateways: {
    customKey: new MyCustomGateway(), // id = 'my-custom-gateway'
  },
})

// Retrieve by ID (not registration key)
const gateway = mastra.getGatewayById('my-custom-gateway')
console.log(gateway.name) // 'My Custom Gateway'
```

## 使用案例 {/* #use-cases */}

* 网关版本控制：具有唯一 ID 的不同版本（`'gateway-v1'`, `'gateway-v2'`)
* 当注册密钥未知时查找网关
* 识别不同 Mastra 实例之间的网关

## 投掷 {/* #throws */}

抛出一个`MastraError` with ID `MASTRA_GET_GATEWAY_BY_ID_NOT_FOUND` if no registered gateway has the specified ID. Wrap the call in `try`/`catch` when the gateway might not be registered:

```typescript
let gateway
try {
  gateway = mastra.getGatewayById('my-custom-gateway')
} catch {
  // Gateway is not registered
}
```
