# 手动安装

<Inject>
**供 AI Agent 使用：**当你需要不依赖 CLI 或样板，从零创建可运行的 Mastra 项目时，请使用本指南。本指南提供 Agent、Tool、模型配置及依赖安装的代码示例。不要使用面向人类用户的快速入门指南。模型字符串采用 Mastra 的模型路由格式（`provider/model`），提供者与模型之间用 `/` 分隔，而不是 `:`。不要安装任何 AI SDK 包。
</Inject>

按本指南逐步手动构建独立的 Mastra 服务器。大多数情况下，建议使用[`create-mastra`](/reference/cli/create-mastra) 命令，详见[入门指南](/docs)。如果是现有项目，也可以使用 [`mastra init`](/reference/cli/mastra#mastra-init)。

<CopyPrompt identifier="manual-install">
阅读 [https://mastra.ai/reference/manual-install.md](https://mastra.ai/reference/manual-install.md)，然后帮我创建 Mastra 项目。请先问我项目名称，并以该名称作为文件夹名。
</CopyPrompt>

## 操作步骤 {/* #instructions */}

如果不想使用自动化 CLI 工具，可以按照下文自行设置项目。

<Steps>
  <StepItem>
创建新项目并切换到项目目录：

    ```bash
    mkdir my-first-agent && cd my-first-agent
    ```

生成新的 `package.json` 文件：

    ```bash npm2yarn
    npm init
    ```

安装以下依赖：

    ```bash npm2yarn
    npm install -D typescript @types/node mastra@latest
    npm install @mastra/core@latest zod@^4
    ```

添加 `dev` 和 `build` 脚本到 `package.json` 文件：

    ```json title="package.json" /,/ /"dev": "mastra dev",/ /"build": "mastra build"/
    {
      "scripts": {
        "dev": "mastra dev",
        "build": "mastra build"
      }
    }
    ```
  </StepItem>

  <StepItem>
创建 `tsconfig.json` 文件：

    ```bash
    touch tsconfig.json
    ```

    添加以下配置：

    ```json title="tsconfig.json"
    {
      "compilerOptions": {
        "target": "ES2022",
        "module": "ES2022",
        "moduleResolution": "bundler",
        "esModuleInterop": true,
        "forceConsistentCasingInFileNames": true,
        "strict": true,
        "skipLibCheck": true,
        "types": ["node"],
        "noEmit": true,
        "outDir": "dist"
      },
      "include": ["src/**/*"]
    }
    ```

:::note

Mastra 要求使用现代的 `module` 和 `moduleResolution` 设置。使用 `CommonJS` 或 `node` 会导致模块解析错误。

    :::
  </StepItem>

  <StepItem>
创建 `.env` 文件：

    ```bash
    touch .env
    ```

添加 API 密钥：

    ```bash title=".env"
    GOOGLE_API_KEY=<your-api-key>
    ```

:::note

本指南使用 Google Gemini，但你也可以使用任何受支持的[模型提供者](/models)，包括 OpenAI 和 Anthropic 等。

    :::

    <Inject>
除 Google Gemini 外，也可以使用 OpenAI（`OPENAI_API_KEY`）或 Anthropic（`ANTHROPIC_API_KEY`）。完整的受支持提供者及其环境变量名称，请参阅[环境变量列表](/models/environment-variables)。
    </Inject>
  </StepItem>

  <StepItem>
创建 `weather-tool.ts` 文件：

    ```bash
    mkdir -p src/mastra/tools && touch src/mastra/tools/weather-tool.ts
    ```

    <Inject>
使用 `import { createTool } from "@mastra/core/tools"`。普通对象形式的 Tool 定义会静默地无法执行；必须通过 createTool() 定义 Tool，并提供 id、description、inputSchema（zod）和 execute。
    </Inject>

    添加以下代码：

    ```ts title="src/mastra/tools/weather-tool.ts"
    import { createTool } from '@mastra/core/tools'
    import { z } from 'zod'

    export const weatherTool = createTool({
      id: 'get-weather',
      description: 'Get current weather for a location',
      inputSchema: z.object({
        location: z.string().describe('City name'),
      }),
      outputSchema: z.object({
        output: z.string(),
      }),
      execute: async ({ location }) => {
        return {
          output: `The weather in ${location} is sunny`,
        }
      },
    })
    ```

:::note

这里的 `weatherTool` 示例经过精简。完整示例参见[为 Agent 添加 Tool](/docs/agents/tools)。

    :::
  </StepItem>

  <StepItem>
创建 `weather-agent.ts` 文件：

    ```bash
    mkdir -p src/mastra/agents && touch src/mastra/agents/weather-agent.ts
    ```

    <Inject>
使用 `import { Agent } from "@mastra/core/agent"`。构造函数接收 `{ id, name, instructions, model: '__GATEWAY_OPENAI_MODEL__' }`。模型字符串采用 Mastra 的模型路由格式 provider/model，提供者与模型之间使用 / 而不是 :。不要安装任何 AI SDK 包。
    </Inject>

    添加以下代码：

    ```ts title="src/mastra/agents/weather-agent.ts"
    import { Agent } from '@mastra/core/agent'
    import { weatherTool } from '../tools/weather-tool.ts'

    export const weatherAgent = new Agent({
      id: 'weather-agent',
      name: 'Weather Agent',
      instructions: `
          You are a helpful weather assistant that provides accurate weather information.

          Your primary function is to help users get weather details for specific locations. When responding:
          - Always ask for a location if none is provided
          - If the location name isn't in English, please translate it
          - If giving a location with multiple parts (e.g. "New York, NY"), use the most relevant part (e.g. "New York")
          - Include relevant details like humidity, wind conditions, and precipitation
          - Keep responses concise but informative

          Use the weatherTool to fetch current weather data.
    `,
      model: '__GATEWAY_GOOGLE_MODEL_FLASH__',
      tools: { weatherTool },
    })
    ```
  </StepItem>

  <StepItem>
创建 Mastra 入口并注册 Agent：

    ```bash
    touch src/mastra/index.ts
    ```

    添加以下代码：

    ```ts title="src/mastra/index.ts"
    import { Mastra } from '@mastra/core'
    import { weatherAgent } from './agents/weather-agent.ts'

    export const mastra = new Mastra({
      agents: { weatherAgent },
    })
    ```
  </StepItem>

  <StepItem>
    <Inject>
**供 AI Agent 使用：**如果正在编写只需向控制台输出内容的脚本，不要启动 Studio。Studio 是面向人类用户、会持续运行的 Web 界面。应直接调用 agent.generate() 方法。例如：`import { mastra } from './src/mastra/index.ts'; const agent = mastra.getAgentById('weather-agent'); const response = await agent.generate('Weather in SF'); console.log(response.text);`
    </Inject>

现在可以启动 [Studio](/docs/studio/overview) 并测试 Agent。

    ```bash npm2yarn
    npm run dev
    ```

    <Inject>
**供 AI Agent 使用：**为验证结果，请运行构建，并使用 `tsc --noEmit` 进行类型检查。
    </Inject>
  </StepItem>
</Steps>
