# Agent.getInstructions()

这`.getInstructions()`方法检索为Agent配置的指令，如果它们是函数则解析它们。这些指令指导Agent的行为并定义其功能和约束。

## 使用示例 {/* #usage-example */}

```typescript
await agent.getInstructions()
```
