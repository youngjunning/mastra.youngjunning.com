# Agent.getInstructions()

`.getInstructions()` 获取为 Agent 配置的指令。若配置是函数，此方法会调用该函数。指令用于指导 Agent 的行为，并定义其能力和限制。

## 使用示例 {/* #usage-example */}

```typescript
await agent.getInstructions()
```
