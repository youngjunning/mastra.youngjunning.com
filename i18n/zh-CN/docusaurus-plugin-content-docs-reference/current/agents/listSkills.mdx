# `.listSkills()`

返回 Agent 可用的所有 Skill 的元数据，包括 Agent 级 Skill 和 Workspace Skill。

## 使用示例 {/* #usage-example */}

```typescript title="src/routes/skills.ts"
import { agent } from '../mastra/agents'

const skills = await agent.listSkills()

for (const skill of skills) {
  console.log(`${skill.name}: ${skill.description}`)
}
```

## 返回值 {/* #return-value */}

返回 `Promise<SkillMetadata[]>`。

每个条目包含一个已发现的 Skill 的元数据。

```typescript
interface SkillMetadata {
  name: string
  description: string
  path: string
  license?: string
  compatibility?: unknown
  'user-invocable'?: boolean
  metadata?: Record<string, unknown>
}
```

## 合并规则 {/* #merging-behavior */}

同时配置了 Agent 级 Skill 和 Workspace Skill 时，`.listSkills()` 返回合并后的结果。名称冲突时，以 Agent 级 Skill 为准。如果两边都定义了名为 `code-review` 的 Skill，则只返回 Agent 级版本。
