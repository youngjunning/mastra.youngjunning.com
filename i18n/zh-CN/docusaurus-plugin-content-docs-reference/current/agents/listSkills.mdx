# `.listSkills()`

返回客服人员可用的所有技能的元数据，包括客服人员级别和Workspace技能。

## 使用示例 {/* #usage-example */}

```typescript title="src/routes/skills.ts"
import { agent } from '../mastra/agents'

const skills = await agent.listSkills()

for (const skill of skills) {
  console.log(`${skill.name}: ${skill.description}`)
}
```

## 返回值 {/* #return-value */}

退货`Promise<SkillMetadata[]>`.

每个条目都包含已发现技能的元数据：

```typescript
interface SkillMetadata {
  name: string
  description: string
  path: string
  license?: string
  compatibility?: unknown
  'user-invocable'?: boolean
  metadata?: Record<string, unknown>
}
```

## 合并行为 {/* #merging-behavior */}

当座席级技能和Workspace技能都配置时，`.listSkills()` returns the merged set. Agent-level skills take precedence on name conflicts. If both define a skill called `code-review`, only the agent-level version is returned.
