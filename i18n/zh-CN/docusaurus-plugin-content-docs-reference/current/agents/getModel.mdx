# Agent.getModel()

`.getModel()` 方法获取为 Agent 配置的语言模型；如果模型由函数提供，则先解析该函数。此方法用于访问支撑 Agent 能力的底层模型。

## 使用示例 {/* #usage-example */}

```typescript
await agent.getModel()
```
