# Agent.getModel()

这`.getModel()`方法检索为Agent配置的语言模型，如果它是函数则解析它。此方法用于访问支持Agent功能的底层模型。

## 使用示例 {/* #usage-example */}

```typescript
await agent.getModel()
```
