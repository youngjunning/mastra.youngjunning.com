# Agent.getVoice()

`.getVoice()` 获取为 Agent 配置的语音 Provider。如果配置是函数，此方法会调用它来获取 Provider。可通过该 Provider 使用文本转语音和语音转文本功能。

## 使用示例 {/* #usage-example */}

```typescript
await agent.getVoice()
```
