# Agent.getVoice()

这`.getVoice()`方法检索为Agent配置的语音提供程序，如果它是函数，则解析它。此方法用于访问Agent的语音功能，以实现文本到语音和语音到文本的功能。

## 使用示例 {/* #usage-example */}

```typescript
await agent.getVoice()
```
