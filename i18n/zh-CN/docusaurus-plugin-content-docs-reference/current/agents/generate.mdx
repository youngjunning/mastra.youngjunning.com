# Agent.generate()

`.generate()` 方法让 Agent 以非流式方式生成响应，并支持更多生成选项。它接收消息和可选的生成选项。

## 使用示例 {/* #usage-example */}

向 Agent 发送消息以生成响应：

```ts
const result = await agent.generate('message for agent')
```

## 响应结构 {/* #response-structure */}

`Agent.generate()` 返回执行期间收集的最终数据。`steps` 是步骤对象数组。结果中的 Tool 数组（包括顶层的 `toolCalls` 和 `toolResults`，以及每个步骤中的 `step.toolCalls` 和 `step.toolResults` 数组）采用 Mastra 的数据块格式。

也就是说，Tool 数据封装在 `payload` 中：

```ts
const response = await agent.generate('Check the weather in Lagos')

for (const toolCall of response.toolCalls) {
  console.log(toolCall.type) // 'tool-call'
  console.log(toolCall.runId)
  console.log(toolCall.from)
  console.log(toolCall.payload.toolName)
  console.log(toolCall.payload.args)
}

for (const step of response.steps) {
  for (const toolResult of step.toolResults) {
    console.log(toolResult.type) // 'tool-result'
    console.log(toolResult.payload.toolName)
    console.log(toolResult.payload.result)
  }
}
```

相同数据块结构的流式版本，请参阅[数据块类型参考](/reference/streaming/ChunkType)。

## 更多示例 {/* #more-examples */}

### 恢复运行期间暂停的生成 {/* #resuming-a-runtime-suspended-generation */}

`generate()` 会在两种情况下返回 `finishReason: 'suspended'`：Tool 需要审批（参阅 [`requireToolApproval`](#parameters)），或 Tool 的 `execute` 函数调用了 `suspend()`。

本例展示调用 `suspend()` 的 Tool。该 Tool 使用 `suspendSchema` 声明传给 `suspend()` 的数据结构，并使用 `resumeSchema` 声明继续执行所需的数据结构：

```typescript title="src/mastra/tools/weather-tool.ts"
import { createTool } from '@mastra/core/tools'
import { z } from 'zod'

const weatherTool = createTool({
  id: 'get-weather',
  inputSchema: z.object({ location: z.string().optional() }),
  suspendSchema: z.object({ question: z.string() }),
  resumeSchema: z.object({ location: z.string() }),
  execute: async ({ location }, context) => {
    if (!location) {
      return await context?.agent?.suspend({
        question: 'Which city would you like the weather for?',
      })
    }
    return await fetchWeather(location)
  },
})
```

在暂停结果中，`suspendPayload.suspendPayload` 包含 Tool 传给 `suspend()` 的数据。调用 `resumeGenerate()` 恢复运行时，需传入符合该 Tool 的 `resumeSchema` 的数据，以及暂停的 `runId`：

```typescript
const output = await agent.generate("What's the weather in London?")

if (output.finishReason === 'suspended') {
  console.log(output.suspendPayload.toolCallId)
  console.log(output.suspendPayload.suspendPayload) // { question: 'Which city would you like the weather for?' }

  const resumed = await agent.resumeGenerate(
    { location: 'London' },
    {
      runId: output.runId!,
      // Pass per-call options again, for example requestContext or onStepFinish.
    },
  )

  console.log(resumed.text)
}
```

如果恢复数据不符合 Tool 的 `resumeSchema`，`resumeGenerate()` 会抛出 ID 为 `AGENT_RESUME_INVALID_DATA` 的错误，运行会保持暂停，可以修正数据后重试。如果有多个 Tool 调用处于暂停状态，请传入 `toolCallId` 指定要恢复的调用。

对于 Tool 审批，请使用 `approveToolCallGenerate()` 和 `declineToolCallGenerate()`，如[人工介入](/docs/agents/human-in-the-loop#tool-approval-with-generate)一节所示。要从 stream 恢复，请使用 `resumeStream()` 并传入相同数据。

### 使用模型设置 {/* #with-model-settings */}

以下示例限制输出 token 数并设置温度：

```ts
const limitedResult = await agent.generate('Write a short poem about coding', {
  modelSettings: {
    maxOutputTokens: 50,
    temperature: 0.7,
  },
})
```

### 使用 memory {/* #with-memory */}

配置 memory 选项，让 Agent 可以访问并持久保存对话历史记录，以便记住之前的交互并在多条消息之间保持上下文。

```ts
const memoryResult = await agent.generate('Remember my favorite color is blue', {
  memory: {
    thread: 'user-123-thread',
    resource: 'user-123',
  },
})
```

### 访问响应标头 {/* #accessing-response-headers */}

部分模型 Provider 会在响应标头中返回有用的信息，例如剩余 token 数或速率限制状态。生成完成后，可从结果对象中读取这些标头。

```ts
const result = await agent.generate('Hello!')
const remainingRequests = result.response?.headers?.['anthropic-ratelimit-requests-remaining']
const remainingTokens = result.response?.headers?.['x-ratelimit-remaining-tokens']
console.log(`Remaining requests: ${remainingRequests}, Remaining tokens: ${remainingTokens}`)
```

### 分析图像 {/* #analyzing-images */}

Agent 可以同时处理图像的视觉内容和其中的文字，对图像进行分析与描述。要启用图像分析，请在 `content` 数组中传入 `type: 'image'` 和图像 URL。可以将图像内容与文本提示词组合，引导 Agent 分析。

```typescript
const response = await agent.generate([
  {
    role: 'user',
    content: [
      {
        type: 'image',
        image: 'https://placebear.com/cache/395-205.jpg',
        mimeType: 'image/jpeg',
      },
      {
        type: 'text',
        text: 'Describe the image in detail, and extract all the text in the image.',
      },
    ],
  },
])

console.log(response.text)
```

`image` 的值，或 `type: 'file'` 内容部分的 `data`，应为绝对 URL、data URL 或 base64 内容。模型无法读取以 `/api/images/foo.png` 之类相对路径提供的附件，因此发送前要将其解析为绝对 URL。对于此类附件，Agent 会用占位符替换并记录警告，而不会直接失败。无法解码、与其媒体类型声明的图像或 PDF 不符的内联内容，以及无法下载的附件，也会采用相同处理方式。参阅[附件下载失败](/docs/agents/processors#recover-from-attachment-download-failures)。

### 使用 `maxSteps` {/* #using-maxsteps */}

`maxSteps` 参数限制 Agent 连续调用 LLM 的最大次数。每一步都会生成响应，执行所有 Tool 调用，然后再处理结果。限制步骤数有助于避免无限循环并降低延迟，也能控制使用 Tool 的 Agent 所消耗的 token。默认值为 5，可以提高：

```typescript
const response = await agent.generate('Help me organize my day', {
  maxSteps: 10,
})

console.log(response.text)
```

### 使用 `onStepFinish` {/* #using-onstepfinish */}

可以使用 `onStepFinish` 回调监控多步骤操作的进度。这有助于调试，或向用户提供进度更新。

只有流式输出或生成非结构化文本时，才能使用 `onStepFinish`。

```typescript
const response = await agent.generate('Help me organize my day', {
  onStepFinish: ({ text, toolCalls, toolResults, finishReason, usage }) => {
    console.log({ text, toolCalls, toolResults, finishReason, usage })
  },
})
```

### 使用 `onTitleGenerated` {/* #using-ontitlegenerated */}

在 memory 选项中启用 `generateTitle` 后，标题生成会在响应完成后异步运行。可使用 `onTitleGenerated` 在标题准备就绪时执行操作，例如通过 SSE 将标题推送给客户端。

```typescript
const response = await agent.generate('What is quantum computing?', {
  memory: {
    thread: threadId,
    resource: userId,
    onTitleGenerated: title => {
      console.log('Thread title:', title)
    },
  },
})
```
