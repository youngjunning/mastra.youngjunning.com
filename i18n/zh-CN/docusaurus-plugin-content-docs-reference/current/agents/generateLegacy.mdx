# Agent.generateLegacy()（旧版）

:::warning

**已弃用**：此方法已弃用，仅适用于旧版模型适配器。使用当前模型适配器时，请改用 [`.generate()`](./generate)。

:::

`.generateLegacy()` 是 Agent 生成 API 的旧版方法，配合旧版模型适配器生成文本或结构化响应。它接收消息和可选的生成选项。

## 使用示例 {/* #usage-example */}

```typescript
await agent.generateLegacy('message for agent')
```

## 处理器重试支持 {/* #processor-retry-support */}

`generateLegacy()` 不运行错误处理器，也不使用 `maxProcessorRetries`；它走的是旧版 AI SDK 生成路径。

使用旧版模型适配器的评分器评判模型会调用 `generateLegacy()`。它们无法共享使用 Mastra 当前生成 API 的评分器评判模型所用的 `StreamErrorRetryProcessor` 重试预算。需要错误处理器重试时，请使用当前模型适配器。旧版 `maxRetries` 选项与之独立，默认值为 `2`。

## 迁移到新 API {/* #migration-to-new-api */}

:::note

新的 `.generate()` 方法提供更强的能力，包括兼容 AI SDK v5 及更新版本、更完善的结构化输出处理，以及改进的流式响应支持。详细步骤请参阅[迁移指南](/reference/migrations/vnext-to-standard-apis)。

:::

### 快速迁移示例 {/* #quick-migration-example */}

#### 迁移前（旧版） {/* #before-legacy */}

```typescript
const result = await agent.generateLegacy('message', {
  temperature: 0.7,
  maxSteps: 3,
})
```

#### 迁移后（新 API） {/* #after-new-api */}

```typescript
const result = await agent.generate('message', {
  modelSettings: {
    temperature: 0.7,
  },
  maxSteps: 3,
})
```

## 扩展使用示例 {/* #extended-usage-example */}

```typescript
import { z } from 'zod'
import { ModerationProcessor, TokenLimiterProcessor } from '@mastra/core/processors'

await agent.generateLegacy(
  [
    { role: 'user', content: 'message for agent' },
    {
      role: 'user',
      content: [
        {
          type: 'text',
          text: 'message for agent',
        },
        {
          type: 'image',
          imageUrl: 'https://example.com/image.jpg',
          mimeType: 'image/jpeg',
        },
      ],
    },
  ],
  {
    temperature: 0.7,
    maxSteps: 3,
    memory: {
      thread: 'user-123',
      resource: 'test-app',
    },
    toolChoice: 'auto',
    providerOptions: {
      openai: {
        reasoningEffort: 'high',
      },
    },
    // Structured output alongside tool calls
    experimental_output: z.object({
      sentiment: z.enum(['positive', 'negative', 'neutral']),
      confidence: z.number(),
    }),
    // Output processors for response validation
    outputProcessors: [
      new ModerationProcessor({ model: '__GATEWAY_OPENAI_MODEL_LUNA__' }),
      new TokenLimiterProcessor({ maxTokens: 1000 }),
    ],
  },
)
```
