# Agent.listWorkflows()

`.listWorkflows()` 获取为 Agent 配置的 Workflow。如果配置是函数，此方法会调用它来获取 Workflow。这些 Workflow 让 Agent 能按预先定义的执行路径完成复杂的多步骤任务。

## 使用示例 {/* #usage-example */}

```typescript
await agent.listWorkflows()
```
