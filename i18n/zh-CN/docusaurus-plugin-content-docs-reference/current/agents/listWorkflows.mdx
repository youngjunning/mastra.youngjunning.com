# Agent.listWorkflows()

这`.listWorkflows()`方法检索为Agent配置的Workflow程，如果它们是函数，则解析它们。这些Workflow程使Agent能够通过定义的执行路径执行复杂的多步骤流程。

## 使用示例 {/* #usage-example */}

```typescript
await agent.listWorkflows()
```
