# Agent.listTools()

`.listTools()` 获取为 Agent 配置的 Tool。如果配置由函数提供，此方法会调用该函数。Tool 可让 Agent 执行特定操作或访问外部系统。

## 使用示例 {/* #usage-example */}

```typescript
await agent.listTools()
```
