# Agent.listTools()

这`.listTools()`方法检索为Agent配置的Tool，如果它们是函数，则解析它们。这些Tool扩展了Agent的功能，使其能够执行特定操作或访问外部系统。

## 使用示例 {/* #usage-example */}

```typescript
await agent.listTools()
```
