# `createInngestAgent()`

:::测试版

在 API 稳定之前，可能会在没有重大版本更新的情况下发生重大更改。

:::

`createInngestAgent()`包装现有的[`Agent`](/reference/agents/agent) with [因格斯特](https://www.inngest.com/docs)- 动力持久的执行力。喜欢[`createDurableAgent()`](/reference/agents/durable-agent#createdurableagentoptions)，它流式传输事件[发布订阅](/docs/server/pubsub)并支持可恢复流，但在 Inngest 的执行引擎上而不是在进程内运行Agent循环。当运行必须在进程重新启动后继续存在或在分布式环境中运行时使用它。

对于进程内持久执行，请使用[`createDurableAgent()`](/reference/agents/durable-agent#createdurableagentoptions). For fire-and-forget execution on the built-in workflow engine, use [`createEventedAgent()`](/reference/agents/durable-agent#createeventedagentoptions).

## 使用示例 {/* #usage-example */}

设置 Inngest 客户端，包装Agent，将其注册到 Mastra，并公开 Inngest 服务端点：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Agent } from '@mastra/core/agent'
import { createInngestAgent, serve as inngestServe } from '@mastra/inngest'
import { Inngest } from 'inngest'

const inngest = new Inngest({ id: 'my-app' })

const agent = new Agent({
  id: 'my-agent',
  name: 'My Agent',
  instructions: 'You are a helpful assistant',
  model: '__GATEWAY_OPENAI_MODEL__',
})

const durableAgent = createInngestAgent({ agent, inngest })

export const mastra = new Mastra({
  agents: { myAgent: durableAgent },
  server: {
    apiRoutes: [
      {
        path: '/inngest/api',
        method: 'ALL',
        createHandler: async ({ mastra }) => inngestServe({ mastra, inngest }),
      },
    ],
  },
})
```

流式传输响应并读取结果：

```typescript
const { output, runId, cleanup } = await durableAgent.stream('Hello!')

const text = await output.text

cleanup()
```

## `InngestAgent`界面 {/* #inngestagent-interface */}

返回的对象`createInngestAgent()`. It provides the durable execution methods below. Any property or method not explicitly defined (e.g., `listTools()` and `getMemory()`) is forwarded to the underlying agent via a Proxy. Thread APIs such as `sendSignal()`, `sendStateSignal()`, `sendNotificationSignal()`, and `subscribeToThread()` are forwarded too, but a signal that wakes an idle thread starts the run through the durable `stream()`.

## 方法 {/* #methods */}

### 执行 {/* #execution */}

#### `stream(messages, options?)` {/* #streammessages-options */}

使用 Inngest 的持久执行引擎流式传输响应。建立 PubSub 订阅后，通过 Inngest 事件触发Workflow程。

```typescript
const { output, runId, cleanup } = await durableAgent.stream('Hello!', {
  onChunk: chunk => console.log(chunk),
  onFinish: result => console.log('done', result),
})

const text = await output.text
cleanup()
```

返回：[`Promise<InngestAgentStreamResult>`](#inngestagentstreamresult)

#### `resume(runId, resumeData, options?)` {/* #resumerunid-resumedata-options */}

恢复暂停的 Ingest 运行，例如在Tool批准后。从存储加载Workflow快照并查找挂起的步骤，然后将恢复事件发送到 Inngest。

恢复的输出包括暂停之前的Tool调用和文本。为了恢复它们，`resume()` waits up to 10 seconds for the stored snapshot to include every suspended tool call. If the snapshot is still incomplete, `resume()` rejects with `Cannot resume run <runId>: ...` and doesn't send a resume event. The run stays suspended, so you can call `resume()` again.

```typescript
const { output, cleanup } = await durableAgent.resume(
  runId,
  {
    approved: true,
  },
  { threadId: 'thread-1', resourceId: 'user-1' },
)

await output.text
cleanup()
```

第三个参数接受`threadId` and `resourceId` in addition to the lifecycle callbacks:

#### `generate(messages, options?)` {/* #generatemessages-options */}

在 Inngest 的持久执行引擎上运行响应并使用单个`FullOutput`. If the run suspends, `generate()` resolves with `finishReason: 'suspended'`. The `runId` option is optional. If you omit it, `generate()` creates a run ID and returns it in `result.runId`. Continue the run with [`resumeGenerate()`](#resumegenerateresumedata-options). Use [`stream()`](#streammessages-options) with `onSuspended` when the caller needs a suspension callback.

```typescript
const result = await durableAgent.generate('Delete the old records', {
  requireToolApproval: true,
})

result.runId // Generated automatically
result.finishReason // 'suspended' when approval is required
```

返回：`Promise<FullOutput<TOutput>>`

#### `resumeGenerate(resumeData, options)` {/* #resumegenerateresumedata-options */}

恢复暂停状态`generate()` run and resolves with a single `FullOutput`. Pass the run ID as `options.runId`, the same as `Agent.resumeGenerate()`. The older `resumeGenerate(runId, resumeData, options?)` order still works but is deprecated.

```typescript
if (!result.runId) {
  throw new Error('Run ID is missing')
}

const resumedResult = await durableAgent.resumeGenerate({ approved: true }, { runId: result.runId })
```

返回：`Promise<FullOutput<TOutput>>`

#### `observe(runId, options?)` {/* #observerunid-options */}

重新连接到现有运行，在交付实时事件之前重播缓存的事件。网络断开后使用此功能。经过`offset` to start replay from a known position.

```typescript
const { output, cleanup } = await durableAgent.observe(runId, {
  offset: 0,
  onChunk: chunk => console.log(chunk),
})

await output.text
```

结果来自`observe()` doesn't include `threadId` or `resourceId`.

返回：`Promise<Omit<InngestAgentStreamResult, 'threadId' | 'resourceId'>>`

：：：警告

这`cleanup()` returned by `observe()` destroys the run's registry entries and cached events. Only call it when you are done with the run. If the run is suspended and you intend to resume later, don't call `cleanup()`.

:::

#### `prepare(messages, options?)` {/* #preparemessages-options */}

为持久执行准备运行而不触发它。返回可用于手动触发 Inngest Workflow事件的序列化Workflow输入。

```typescript
const { runId, messageId, workflowInput, threadId, resourceId } = await durableAgent.prepare(
  'Summarize the document',
  {
    memory: { threadId: 'thread-1', resourceId: 'user-1' },
  },
)
```

返回：

```typescript
interface PrepareResult {
  runId: string
  messageId: string
  workflowInput: any
  threadId?: string
  resourceId?: string
}
```

## 活动规模限制 {/* #event-size-limit */}

Inngest Realtime 将每条消息的大小限制为大约 512 KB。默认`InngestPubSub` keeps every stream event under 480 KB:

* 超大的`finish` event is sent without `output.steps`. The final text, usage, and finish reason still arrive, but `steps`, `toolCalls`, and `toolResults` on the stream result are empty for that run.
* 任何其他大型活动，例如`tool-result` chunk carrying a large tool result, is replaced with a `data-oversized-event` chunk. Its `data` holds the original `eventType`, `chunkType`, `bytes`, and `limit`. The chunk is transient, so it isn't saved to memory.

这两种情况都会记录警告。仅减少实时流：保存到内存的消息和运行的Workflow程快照保留完整数据。

为了避免限制：

* 返回小型Tool结果，例如 ID 或摘要，并单独获取大型数据。
* 从内存中读取完整结果或流完成后运行的Workflow程。
* 通过一个`pubsub` without the limit, such as [`RedisStreamsPubSub`](/reference/pubsub/redis-streams):

```typescript title="src/mastra/index.ts"
import { createInngestAgent } from '@mastra/inngest'
import { RedisStreamsPubSub } from '@mastra/redis-streams'

const durableAgent = createInngestAgent({
  agent,
  inngest,
  pubsub: new RedisStreamsPubSub({ url: 'redis://localhost:6379' }),
})
```

## 提供 Ingest 功能 {/* #serving-inngest-functions */}

这`@mastra/inngest` package provides `serve()` and `createServe()` to register Inngest workflow functions with your HTTP framework.

### `serve(options)` {/* #serveoptions */}

通过 Hono（默认框架）为 Mastra Workflow程提供服务。从 Mastra 收集所有 Inngest 支持的Workflow程并将它们注册为 Inngest 函数。

```typescript
import { serve } from '@mastra/inngest'

app.use('/inngest/api', async c => {
  return serve({ mastra, inngest })(c)
})
```

### `createServe(adapter)` {/* #createserveadapter */}

接受任何 Ingest 服务适配器的工厂 (`inngest/express`, `inngest/fastify`, `inngest/next`, etc.) and returns a serve function for that framework.

```typescript title="Express"
import { createServe } from '@mastra/inngest'
import { serve } from 'inngest/express'

const serveExpress = createServe(serve)
app.use('/inngest/api', serveExpress({ mastra, inngest }))
```

```typescript title="Next.js"
import { createServe } from '@mastra/inngest'
import { serve } from 'inngest/next'

const serveNext = createServe(serve)
export const { GET, POST, PUT } = serveNext({ mastra, inngest })
```
