# Agent.listScorers()

`.listScorers()` 获取 Agent 的评分配置。如果配置是函数，此方法会调用该函数。可通过此方法访问用于评估 Agent 回复和表现的评分系统。

## 使用示例 {/* #usage-example */}

```typescript
await agent.listScorers()
```
