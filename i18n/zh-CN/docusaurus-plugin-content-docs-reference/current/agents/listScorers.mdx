# Agent.listScorers()

这`.listScorers()`方法检索为Agent配置的评分配置，如果它是函数，则解析它。该方法提供对用于评估Agent响应和表现的评分系统的访问。

## 使用示例 {/* #usage-example */}

```typescript
await agent.listScorers()
```
