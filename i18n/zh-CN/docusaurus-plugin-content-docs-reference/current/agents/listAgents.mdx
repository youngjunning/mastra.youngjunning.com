# Agent.listAgents()

这`.listAgents()`方法检索为Agent配置的子Agent，如果它们是函数，则解析它们。这些子Agent使Agent能够访问其他Agent并执行复杂的操作。

## 使用示例 {/* #usage-example */}

```typescript
await agent.listAgents()
```
