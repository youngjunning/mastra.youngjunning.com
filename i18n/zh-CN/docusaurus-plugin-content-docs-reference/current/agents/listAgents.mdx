# Agent.listAgents()

`.listAgents()` 获取为 Agent 配置的子 Agent。如果配置是函数，此方法会调用它来获取子 Agent。主 Agent 可以借助这些子 Agent 执行复杂操作。

## 使用示例 {/* #usage-example */}

```typescript
await agent.listAgents()
```
