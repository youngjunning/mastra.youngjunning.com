# `createSkill()`

创建可以直接传递给座席的内联技能`skills`没有文件系统或Workspace的配置。

返回的对象实现了`Skill` interface and works anywhere a filesystem-discovered skill works.

## 使用示例 {/* #usage-example */}

```typescript title="src/mastra/skills.ts"
import { createSkill } from '@mastra/core/skills'

const reviewSkill = createSkill({
  name: 'code-review',
  description: 'Use when reviewing code changes.',
  instructions: `
    When reviewing code:
    1. Check for correctness
    2. Check for style consistency
    3. Look for potential bugs
  `,
  references: {
    'checklist.md': '# Review Checklist\n- No unused imports\n- Error handling present',
  },
})
```

## 返回值 {/* #return-value */}

返回一个`InlineSkill` object that implements the `Skill` interface:

```typescript
interface InlineSkill extends Skill {
  __inline: true
  __referenceContents: Record<string, string>
}
```

该技能被分配的合成路径为`inline/<name>` (e.g., `inline/code-review`).

## 验证 {/* #validation */}

`createSkill()`使用与文件系统技能相同的规则验证输入：

* `name`是必需的并且必须是有效的 slug
* `description`是必须的

如果验证失败，则会出现`Error` is thrown with details about the invalid fields.

```typescript
// Throws: Invalid skill "": name: Skill name cannot be empty
createSkill({ name: '', description: 'test', instructions: 'test' })
```
