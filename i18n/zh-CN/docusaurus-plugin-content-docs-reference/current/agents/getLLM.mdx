# Agent.getLLM()

`.getLLM()` 方法获取为 Agent 配置的语言模型实例；如果模型由函数提供，则先解析该函数。还可传入请求级 `model` 覆盖配置，而不会修改 Agent 已配置的模型。

## 使用示例 {/* #usage-example */}

```typescript
await agent.getLLM()
```

```typescript
await agent.getLLM({
  model: '__GATEWAY_OPENAI_MODEL__',
})
```
