# Agent.getLLM()

这`.getLLM()`方法检索为Agent配置的语言模型实例，如果它是函数则解析它。您还可以传递请求范围的`model`覆盖而不改变Agent的配置模型。

## 使用示例 {/* #usage-example */}

```typescript
await agent.getLLM()
```

```typescript
await agent.getLLM({
  model: '__GATEWAY_OPENAI_MODEL__',
})
```
