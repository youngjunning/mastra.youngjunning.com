# Agent.getDefaultStreamOptionsLegacy()

：：：警告

**已弃用**：此方法已弃用，仅适用于 V1 型号。对于 V2 型号，请使用新的[`.getDefaultOptions()`](./getDefaultOptions) method instead.

:::

可以为Agent配置内存使用和输出格式的默认流选项。迭代步骤也可以配置。这`.getDefaultStreamOptionsLegacy()` method returns these defaults, resolving them if they're functions. These options apply to all `streamLegacy()` calls unless overridden and are useful for inspecting an agent’s unknown defaults.

## 使用示例 {/* #usage-example */}

```typescript
await agent.getDefaultStreamOptionsLegacy()
```
