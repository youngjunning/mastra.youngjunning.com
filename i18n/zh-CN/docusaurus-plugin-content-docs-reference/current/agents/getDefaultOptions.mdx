# Agent.getDefaultOptions()

可为 Agent 配置内存使用、输出格式和迭代步数等默认选项。`.getDefaultOptions()` 会返回这些默认值；若选项由函数提供，则先解析函数。除非调用时覆盖，否则这些选项会应用于所有 `stream()` 和 `generate()` 调用，也可用于检查事先未知的 Agent 默认配置。

## 使用示例 {/* #usage-example */}

```typescript
await agent.getDefaultOptions()
```
