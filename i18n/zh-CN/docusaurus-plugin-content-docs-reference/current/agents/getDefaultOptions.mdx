# Agent.getDefaultOptions()

可以使用内存使用和输出格式的默认选项来配置Agent。迭代步骤也可以配置。这`.getDefaultOptions()`方法返回这些默认值，如果它们是函数则解析它们。这些选项适用于所有`stream()`和`generate()`除非被覆盖，否则调用，并且对于检查Agent的未知默认值很有用。

## 使用示例 {/* #usage-example */}

```typescript
await agent.getDefaultOptions()
```
