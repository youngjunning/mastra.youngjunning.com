# `.getSkill()`

按名称从 Agent 已配置的 Skill 中检索指定 Skill，包括 Agent 级和 Workspace Skill。

## 使用示例 {/* #usage-example */}

```typescript title="src/routes/skills.ts"
import { agent } from '../mastra/agents'

const skill = await agent.getSkill('code-review')

if (skill) {
  console.log(skill.name) // "code-review"
  console.log(skill.description) // "Use when reviewing code changes."
  console.log(skill.instructions) // Full markdown instructions
}
```

## 返回值 {/* #return-value */}

返回 `Promise<Skill | null>`。

如果找到对应 Skill，则返回 `Skill` 对象；如果不存在该名称的 Skill，则返回 `null`。

```typescript
interface Skill {
  name: string
  description: string
  instructions: string
  path: string
  source:
    | { type: 'external'; packagePath: string }
    | { type: 'local'; projectPath: string }
    | { type: 'managed'; mastraPath: string }
  references: string[]
  scripts: string[]
  assets: string[]
  license?: string
  compatibility?: unknown
  'user-invocable'?: boolean
  metadata?: Record<string, unknown>
}
```

`source` 描述 Mastra 从何处发现该 Skill。路径中包含 `node_modules` 的 Skill 属于 `external`，位于 `.mastra/skills` 下的 Skill 属于 `managed`，其余 Skill（包括使用 [`createSkill()`](/reference/agents/createSkill) 创建的 Skill）均属于 `local`。

## 合并行为 {/* #merging-behavior */}

同时配置 Agent 级 Skill 和 Workspace Skill 时，`.getSkill()` 会在合并后的集合中查找。如有同名冲突，Agent 级 Skill 优先。
