# Agent.getMemory()

这`.getMemory()`方法检索与Agent关联的存储系统。此方法用于访问Agent的内存功能，以便在对话中存储和检索信息。

## 使用示例 {/* #usage-example */}

```typescript
await agent.getMemory()
```
