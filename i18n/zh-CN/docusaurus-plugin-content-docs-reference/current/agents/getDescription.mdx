# Agent.getDescription()

`.getDescription()` 获取为 Agent 配置的描述，返回说明其用途和能力的字符串。

## 使用示例 {/* #usage-example */}

```typescript
agent.getDescription()
```

## 参数 {/* #parameters */}

此方法不接受参数。
