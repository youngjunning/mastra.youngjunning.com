# Agent.getDescription()

这`.getDescription()`方法检索为Agent配置的描述。此方法返回描述Agent的目的和功能的字符串描述。

## 使用示例 {/* #usage-example */}

```typescript
agent.getDescription()
```

## 参数 {/* #parameters */}

该方法不带参数。
