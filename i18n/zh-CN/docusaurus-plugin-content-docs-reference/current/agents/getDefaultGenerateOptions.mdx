# Agent.getDefaultGenerateOptionsLegacy()

：：：警告

**已弃用**：此方法已弃用且仅适用于 V1 模型。V2 模型请改用新的 [`.getDefaultOptions()`](./getDefaultOptions) 方法。

:::

可为 Agent 配置默认生成选项，以控制模型行为、输出格式以及 Tool 和 Workflow 调用。`.getDefaultGenerateOptionsLegacy()` 会获取这些默认值；若选项由函数提供，则先解析函数。除非调用时覆盖，否则这些选项会应用于所有 `generateLegacy()` 调用，也可用于检查事先未知的 Agent 默认配置。

## 使用示例 {/* #usage-example */}

```typescript
await agent.getDefaultGenerateOptionsLegacy()
```
