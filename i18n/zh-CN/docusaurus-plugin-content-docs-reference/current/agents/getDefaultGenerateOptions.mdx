# Agent.getDefaultGenerateOptionsLegacy()

：：：警告

**已弃用**：此方法已弃用，仅适用于 V1 型号。对于 V2 型号，请使用新的[`.getDefaultOptions()`](./getDefaultOptions) method instead.

:::

使用默认生成选项配置Agent，以控制模型行为和输出格式，包括Tool和Workflow调用。这`.getDefaultGenerateOptionsLegacy()` method retrieves these defaults and resolves any functions. These options apply to all `generateLegacy()` calls unless overridden and are useful for inspecting an agent’s unknown defaults.

## 使用示例 {/* #usage-example */}

```typescript
await agent.getDefaultGenerateOptionsLegacy()
```
