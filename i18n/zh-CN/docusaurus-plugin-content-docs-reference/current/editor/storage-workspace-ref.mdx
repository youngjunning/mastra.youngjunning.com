# StorageWorkspaceRef

`StorageWorkspaceRef` 是用于为已存储 Agent 关联 Workspace 的可辨识联合类型。它可以通过 ID 指向已在 Mastra 运行时注册的 Workspace、内联嵌入 Workspace 快照，或指定在 `MastraEditor.workspaces` 中注册的 Workspace Provider 来构建 Workspace。

[`BuilderAgentDefaults.workspace`](https://agent-builder.mastra.ai/reference/builder-agent-defaults) 和已存储的 Agent 记录都会使用此类型。

## 使用示例 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { MastraEditor } from '@mastra/editor'

// Variant 1 — reference a runtime workspace by id
new MastraEditor({
  builder: {
    enabled: true,
    configuration: {
      agent: {
        workspace: { type: 'id', workspaceId: 'builder-workspace' },
      },
    },
  },
})

// Variant 2 — inline a workspace snapshot
new MastraEditor({
  builder: {
    enabled: true,
    configuration: {
      agent: {
        workspace: {
          type: 'inline',
          config: {
            name: 'inline-builder-workspace',
            filesystem: {
              provider: 'local',
              config: { basePath: './agent-files' },
            },
          },
        },
      },
    },
  },
})

// Variant 3 — build the workspace with a registered workspace provider
new MastraEditor({
  workspaces: { 'my-provider': myWorkspaceProvider },
  builder: {
    enabled: true,
    configuration: {
      agent: {
        workspace: {
          type: 'provider',
          provider: 'my-provider',
          config: { region: 'us-east-1' },
        },
      },
    },
  },
})
```

## 恢复运行时对象 {/* #hydration */}

`StorageWorkspaceRef` 在调用 `mastra.editor.agent.getById()` 时才会延迟解析，调用 `list()` 时不会。Editor 会从 `MastraEditor.filesystems` / `MastraEditor.sandboxes` 查找文件系统与 Sandbox Provider，并实例化运行时 `Workspace`。若缺少 Provider，会发出警告并省略该 Workspace。对于 `{ type: 'provider' }` 引用，Editor 会调用 `createWorkspace(config)`，该方法属于在 `MastraEditor.workspaces` 中注册的 Provider；Provider 未注册时会抛出错误。
