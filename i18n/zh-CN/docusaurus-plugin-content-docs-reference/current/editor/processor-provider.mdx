# 处理器提供者

`ProcessorProvider`是一个包实现的用于注册可配置处理器的接口[`MastraEditor`](/reference/editor/mastra-editor)。处理器Provider有两个目的：

1. **发现：**&#x7528;户界面使用`info`, `configSchema`, and `availablePhases`呈现配置表单。
2. **运行时间：**&#x7F16;辑呼吁`createProcessor(config)` during agent hydration to instantiate processors from stored configuration.

提供者通过以下方式提供`MastraEditorConfig.processorProviders`.

## 使用示例 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { MastraEditor } from '@mastra/editor'
import { moderationProvider } from '@mastra/core/processor-provider'

new MastraEditor({
  processorProviders: {
    moderation: moderationProvider,
  },
})
```

## 实施提供者 {/* #implementing-a-provider */}

```typescript title="src/providers/my-processor.ts"
import type { ProcessorProvider } from '@mastra/core/processor-provider'
import { z } from 'zod'
import { MyProcessor } from './my-processor-impl'

export const myProcessorProvider: ProcessorProvider = {
  info: {
    id: 'my-processor',
    name: 'My Processor',
    description: 'Filters output for sensitive content.',
  },
  configSchema: z.object({
    threshold: z.number().min(0).max(1),
  }),
  availablePhases: ['processOutputStream', 'processOutputResult'],
  createProcessor(config) {
    return new MyProcessor(config as { threshold: number })
  },
}
```
