# MastraEditor 类

`MastraEditor` 类负责配置编辑器系统。将其实例传入 `Mastra` 构造函数，即可启用提示词块、Agent 代码覆盖、版本管理和 Tool Provider 等编辑器功能。

编辑器功能介绍请参阅 [Editor](/docs/studio/editor)。

## 使用示例 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraEditor } from '@mastra/editor'

export const mastra = new Mastra({
  agents: {/* your agents */},
  editor: new MastraEditor(),
})
```

## Agent Builder {/* #agent-builder */}

`builder` 字段用于启用 [Agent Builder](https://agent-builder.mastra.ai/)，这是创建和编辑已存储 Agent 的浏览器界面。相关文档包括：

* [Agent Builder 概述](https://agent-builder.mastra.ai/)：概念与入门指南。
* [AgentBuilderOptions](https://agent-builder.mastra.ai/reference/agent-builder-options)：完整的选项结构。
* [BuilderAgentDefaults](https://agent-builder.mastra.ai/reference/builder-agent-defaults)：管理员为新 Agent 固定的默认值。
* [builder.configuration.agent.models](https://agent-builder.mastra.ai/reference/builder-models)：允许使用的模型及默认模型。

### 注册 Builder Agent {/* #registering-the-builder-agent */}

Builder 界面使用 `createBuilderAgent()` 工厂函数（来自 `@mastra/editor/ee`）创建的 Agent。导入并调用该函数，然后在 Mastra 实例的 `agents` 字段中注册返回的 Agent：

```typescript filename="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraEditor } from '@mastra/editor'
import { createBuilderAgent } from '@mastra/editor/ee'

export const mastra = new Mastra({
  agents: { builderAgent: createBuilderAgent() },
  editor: new MastraEditor({
    builder: { enabled: true },
  }),
})
```

键名 `builderAgent` 只是惯例，也可以使用其他键名。`@mastra/editor/ee` 子路径在运行时受 Mastra 企业版许可证限制。

完整的设置清单请参阅 [Agent Builder 概述](https://agent-builder.mastra.ai/#prerequisites)。

### 已存储 Agent 的 Memory {/* #stored-agent-memory */}

已存储 Agent 的 `memory` 字段支持以下形式：

* `{ type: 'id', memoryId: string }`：使用已在 Mastra 实例中注册的 Memory 实例。编辑器先将 `memoryId` 作为注册表键查找，再将其作为 Memory 实例的 `id` 查找。Agent 使用找到的同一个实例，包括其存储、处理器和工作记忆设置。
* `{ type: 'inline', config: SerializedMemoryConfig }`：根据可序列化配置创建新的 Memory 实例。
* `SerializedMemoryConfig`：不带类型标记的内联配置。已有的已存储 Agent 仍可使用这种形式。

引用已注册的 Memory 实例，可让多个已存储 Agent 共用一份配置：

```typescript title="src/scripts/seed-agent.ts"
import { mastra } from '../mastra'

const editor = mastra.getEditor()!

await editor.agent.create({
  id: 'support-agent',
  name: 'Support agent',
  instructions: 'You are a friendly support agent for Acme.',
  model: { provider: 'openai', name: '__AI_SDK_OPENAI_MODEL_BASE__' },
  memory: { type: 'id', memoryId: 'supportMemory' },
})
```

编辑器加载 Agent 时会解析该引用。如果找不到与 `memoryId` 匹配的已注册 Memory，Agent 会在没有 Memory 的情况下加载，编辑器会记录一条包含缺失键名的警告，且不会修改已存储的引用。对于条件式 Memory，引用未注册的变体会被跳过。如果 Agent 加载后才通过 `mastra.addMemory()` 注册 Memory，请调用 `editor.agent.clearCache(id)`，让下次加载使用新注册的实例。重命名或删除 Mastra `memory` 配置中的键，会使引用该键的所有已存储 Agent 失去关联，因此部署之间应保持键名稳定。

当源 Agent 使用已注册的 Memory 实例时，`editor.agent.clone()` 会存储引用；否则会存储内联配置。

## 方法 {/* #methods */}

### 访问 Provider {/* #provider-access */}

#### `getToolProvider(id)` {/* #gettoolproviderid */}

按 ID 返回已注册的 Tool Provider。

```typescript
const composio = mastra.getEditor()?.getToolProvider('composio')
```

#### `getToolProviders()` {/* #gettoolproviders */}

以 `Record<string, ToolProvider>` 形式返回所有已注册的 Tool Provider。

#### `getProcessorProvider(id)` {/* #getprocessorproviderid */}

按 ID 返回已注册的 Processor Provider。

#### `getProcessorProviders()` {/* #getprocessorproviders */}

返回所有已注册的 Processor Provider。

#### `getFilesystemProviders()` {/* #getfilesystemproviders */}

返回所有已注册的 Filesystem Provider。

#### `getSandboxProviders()` {/* #getsandboxproviders */}

返回所有已注册的 Sandbox Provider。

#### `getBlobStoreProviders()` {/* #getblobstoreproviders */}

返回所有已注册的 Blob Store Provider。

### 来源 {/* #source */}

#### `getSource()` {/* #getsource */}

返回配置的来源（`'code'` 或 `'db'`）；未显式指定时返回 `undefined`（即构造时未传入 `source`）。

```typescript
const source = mastra.getEditor()?.getSource()
```

返回：`'code' | 'db' | undefined`

省略 `source` 时，即使 `getSource()` 返回 `undefined`，编辑器仍会使用已配置的数据库存储。存储流程请参阅 [编辑器存储选项](/docs/studio/editor#choose-where-changes-are-stored)；激活和 Git 历史记录的行为请参阅 [代码来源版本管理](/reference/editor/versioning#code-source)。
