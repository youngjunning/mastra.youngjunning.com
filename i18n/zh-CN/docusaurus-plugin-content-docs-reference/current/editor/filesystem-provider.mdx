# 文件系统提供者

`FilesystemProvider`是包实现的用于注册文件系统的接口[`MastraEditor`](/reference/editor/mastra-editor)。编辑呼吁`createFilesystem(config)`在工作空间补水时，使用`provider`存储的id[`StorageWorkspaceRef`](/reference/editor/storage-workspace-ref)文件系统配置作为查找键。

内置的`local` filesystem provider is auto-registered. External providers (for example, S3 or GCS) are supplied via `MastraEditorConfig.filesystems`.

## 使用示例 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { MastraEditor } from '@mastra/editor'
import { s3FilesystemProvider } from '@mastra/s3'

new MastraEditor({
  filesystems: {
    [s3FilesystemProvider.id]: s3FilesystemProvider,
  },
})
```

## 实施提供者 {/* #implementing-a-provider */}

```typescript title="src/providers/my-filesystem.ts"
import type { FilesystemProvider } from '@mastra/core/editor'
import type { WorkspaceFilesystem } from '@mastra/core/workspace'

export const myFilesystemProvider: FilesystemProvider<{ bucket: string; region: string }> = {
  id: 'my-fs',
  name: 'My Filesystem',
  description: 'Object-store-backed filesystem.',
  configSchema: {
    type: 'object',
    required: ['bucket', 'region'],
    properties: {
      bucket: { type: 'string' },
      region: { type: 'string' },
    },
  },
  async createFilesystem(config): Promise<WorkspaceFilesystem> {
    return createMyFilesystem({ bucket: config.bucket, region: config.region })
  },
}
```

注册后，管理员可以从内联Workspace配置或存储的配置中引用提供程序[`StorageWorkspaceRef`](/reference/editor/storage-workspace-ref).
