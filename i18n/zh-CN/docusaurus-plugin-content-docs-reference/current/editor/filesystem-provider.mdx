# FilesystemProvider

`FilesystemProvider` 是套件为向 [`MastraEditor`](/reference/editor/mastra-editor) 注册文件系统而实现的接口。编辑器在工作区初始化时调用 `createFilesystem(config)`，并以 `provider` ID（来自已存储的 [`StorageWorkspaceRef`](/reference/editor/storage-workspace-ref) 文件系统配置）作为查找键。

内置的 `local` 文件系统 Provider 会自动注册。外部 Provider（例如 S3 或 GCS）通过 `MastraEditorConfig.filesystems` 提供。

## 使用示例 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { MastraEditor } from '@mastra/editor'
import { s3FilesystemProvider } from '@mastra/s3'

new MastraEditor({
  filesystems: {
    [s3FilesystemProvider.id]: s3FilesystemProvider,
  },
})
```

## 实现 Provider {/* #implementing-a-provider */}

```typescript title="src/providers/my-filesystem.ts"
import type { FilesystemProvider } from '@mastra/core/editor'
import type { WorkspaceFilesystem } from '@mastra/core/workspace'

export const myFilesystemProvider: FilesystemProvider<{ bucket: string; region: string }> = {
  id: 'my-fs',
  name: 'My Filesystem',
  description: 'Object-store-backed filesystem.',
  configSchema: {
    type: 'object',
    required: ['bucket', 'region'],
    properties: {
      bucket: { type: 'string' },
      region: { type: 'string' },
    },
  },
  async createFilesystem(config): Promise<WorkspaceFilesystem> {
    return createMyFilesystem({ bucket: config.bucket, region: config.region })
  },
}
```

注册后，管理员可以在内联工作区配置或已存储的 [`StorageWorkspaceRef`](/reference/editor/storage-workspace-ref) 中引用该 Provider。
