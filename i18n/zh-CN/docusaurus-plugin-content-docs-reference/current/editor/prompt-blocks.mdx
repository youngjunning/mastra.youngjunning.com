# Prompt blocks

Prompt blocks 是由 Editor 管理、可复用的指令模板。Agent 指令可以同时包含内联文本、嵌入式 prompt blocks，以及对独立版本化 prompt blocks 的引用。

有关 Studio 中的操作流程和常见用途，请参见 [Prompt blocks](/docs/studio/editor#prompt-blocks)。

## 块类型 {/* #block-types */}

| 类型 | 说明 |
| - | - |
| `text` | 仅存储在 Agent 版本中的自由文本 |
| `prompt_block` | 嵌入 Agent 版本中的 prompt block |
| `prompt_block_ref` | 对单独存储且独立版本化的 prompt block 的引用 |

引用的块在运行时解析。缺失或未发布的引用不会出现在最终指令中。解析后非空的块用两个换行符连接。

以下示例将已存储的块和内联文本附加到 Agent：

```typescript title="src/scripts/attach-prompt.ts"
import { mastra } from '../mastra'

const editor = mastra.getEditor()!

await editor.agent.update({
  id: 'support-agent',
  instructions: [
    { type: 'prompt_block_ref', id: 'brand-voice' },
    { type: 'text', content: 'Answer only questions about Acme products.' },
  ],
})
```

## 模板值 {/* #template-values */}

模板在运行时从请求上下文解析值。

| 语法 | 请求上下文 | 输出 |
| - | - | - |
| <code>{'{{userName}}'}</code> | `{ userName: 'Maya' }` | `Maya` |
| <code>{'{{user.name}}'}</code> | `{ user: { name: 'Maya' } }` | `Maya` |
| <code>{"{{task \u007c\u007c 'request'}}"}</code> | `{}` | `request` |
| <code>{'{{missingValue}}'}</code> | `{}` | `{{missingValue}}` |

变量名必须以字母或下划线开头。回退值必须是单引号或双引号字符串。没有回退值的未解析占位符保持原样。对象和数组会序列化为 JSON；其他值会转换为字符串。

通过[请求上下文](/docs/server/request-context)传入值。Editor 不读取单独的 Agent `variables` 字段。

## 显示条件 {/* #display-conditions */}

Prompt block 可以包含显示条件，用来控制它是否进入最终指令。每个条件包含三个部分：

- **键**：要检查的请求上下文字段，例如 `user.role` 或 `account.plan`。
- **运算符**：要执行的比较，例如 `equals`、`contains` 或 `exists`。
- **值**：用于比较的值。`exists` 和 `not_exists` 运算符不需要此值。

例如，条件 `user.role` `equals` `admin` 只有在请求上下文包含 `{ user: { role: 'admin' } }` 时，才会将此块纳入指令。

| 运算符 | 示例 | 纳入块的条件 |
| - | - | - |
| `equals` / `not_equals` | `user.role` 等于 `admin` | 字段严格等于或不等于指定值 |
| `contains` / `not_contains` | `user.tags` 包含 `beta` | 字符串包含指定值，或数组包含指定元素 |
| `greater_than` / `less_than` | `order.total` 大于 `100` | 数值字段大于或小于指定值 |
| `greater_than_or_equal` / `less_than_or_equal` | `account.seats` 大于或等于 `10` | 数值字段大于或等于、小于或等于指定值 |
| `in` / `not_in` | `user.region` 属于 `['US', 'CA']` | 字段值属于或不属于给定数组 |
| `exists` / `not_exists` | `account.plan` 存在 | 字段具有或不具有非 null 值 |

条件组可用 `AND` 或 `OR` 组合条件。例如，以下条件组只会为使用付费方案的管理员纳入该块：

```typescript
const rules = {
  operator: 'AND',
  conditions: [
    {
      field: 'user.role',
      operator: 'equals',
      value: 'admin',
    },
    {
      field: 'account.plan',
      operator: 'in',
      value: ['pro', 'enterprise'],
    },
  ],
}
```

支持点分路径。空条件组的求值结果为 `true`，未知运算符的结果为 `false`。存储类型最多支持三层嵌套条件组。

没有条件的块始终会纳入指令。

`prompt_block_ref` 也可以有自己的 `rules`。这些规则仅作用于该 Agent 中的此条引用，因此同一个已存储块可在不同条件下复用。如果已存储块也有规则，则两者都必须满足。

### 带回退值的运行时插槽 {/* #runtime-slot-with-a-fallback */}

将内联 `prompt_block` 与带条件的 `prompt_block_ref` 组合，可从请求上下文插入值；如果该值缺失，则回退到共享的已存储块：

```typescript title="src/scripts/attach-prompt.ts"
await editor.agent.update({
  id: 'support-agent',
  instructions: [
    { type: 'text', content: 'Follow the platform safety policy.' },
    {
      type: 'prompt_block',
      content: '{{userPrompt}}',
      rules: {
        operator: 'AND',
        conditions: [
          { field: 'userPrompt', operator: 'exists' },
          { field: 'userPrompt', operator: 'not_equals', value: '' },
        ],
      },
    },
    {
      type: 'prompt_block_ref',
      id: 'default-user-prompt',
      rules: {
        operator: 'OR',
        conditions: [
          { field: 'userPrompt', operator: 'not_exists' },
          { field: 'userPrompt', operator: 'equals', value: '' },
        ],
      },
    },
  ],
})
```

当请求上下文包含非空的 `userPrompt` 时，Agent 会收到该值；否则会收到已发布的 `default-user-prompt` 块。已存储块无需知道 `userPrompt`。

：：：笔记

`exists` 运算符将空字符串视为存在。额外的 `''` 条件让空的 `userPrompt` 也使用回退块。

## 编程接口 {/* #programmatic-api */}

通过 `mastra.getEditor().prompt` 访问 prompt blocks。完整的方法签名请参见 [`prompt` 命名空间](/reference/editor/mastra-editor#namespaces)。

创建 prompt block：

```typescript title="src/scripts/seed-prompts.ts"
import { mastra } from '../mastra'

const editor = mastra.getEditor()!

await editor.prompt.create({
  id: 'brand-voice',
  name: 'Brand voice',
  description: 'Acme tone and style guidelines',
  content: 'Write in a friendly, concise tone. Address the user as {{userName || "there"}}.',
})
```

更新现有块：

```typescript title="src/scripts/update-prompt.ts"
await editor.prompt.update({
  id: 'brand-voice',
  content: 'Write in a friendly, concise tone. Greet the user by name when available.',
})
```

内容变化时，`update()` 会创建新草稿。使用 `list()` 分页读取已存储的块，使用 `getById()` 获取单个块，使用 `preview(blocks, context)` 以草稿引用解析模板和条件。

## REST API {/* #rest-api */}

Mastra 服务器的默认前缀为 `/api`。自定义服务器前缀会改变下列路径。

| 方法 | 路径 | 说明 |
| - | - | - |
| `GET` | `/api/stored/prompt-blocks` | 列出已存储的 prompt blocks |
| `POST` | `/api/stored/prompt-blocks` | 创建已存储的 prompt block |
| `GET` | `/api/stored/prompt-blocks/:storedPromptBlockId` | 获取已存储的 prompt block |
| `PATCH` | `/api/stored/prompt-blocks/:storedPromptBlockId` | 更新已存储的 prompt block |
| `DELETE` | `/api/stored/prompt-blocks/:storedPromptBlockId` | 删除已存储的 prompt block |

## 版本解析 {/* #version-resolution */}

运行时引用会解析到当前已发布的块；Editor 预览会解析到最新草稿。草稿、发布和恢复的通用生命周期，请参见 [Editor 版本管理](/docs/studio/editor#versioning)。
