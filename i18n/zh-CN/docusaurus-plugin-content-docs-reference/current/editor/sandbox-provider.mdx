# SandboxProvider

`SandboxProvider` 是包向 [`MastraEditor`](/reference/editor/mastra-editor) 注册 Sandbox 时实现的接口。Editor 在加载 Workspace 时调用 `createSandbox(config)`，并以存储的 Sandbox 配置中的 `provider` ID 为查找键；该配置来自 [`StorageWorkspaceRef`](/reference/editor/storage-workspace-ref)。

内置的 `local` Sandbox Provider 会自动注册。外部 Provider（例如 E2B）通过 `MastraEditorConfig.sandboxes` 提供。

## 使用示例 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { MastraEditor } from '@mastra/editor'
import { e2bSandboxProvider } from '@mastra/e2b'

new MastraEditor({
  sandboxes: {
    [e2bSandboxProvider.id]: e2bSandboxProvider,
  },
})
```

## 实现 Provider {/* #implementing-a-provider */}

```typescript title="src/providers/my-sandbox.ts"
import type { SandboxProvider } from '@mastra/core/editor'
import type { WorkspaceSandbox } from '@mastra/core/workspace'

export const mySandboxProvider: SandboxProvider<{ apiKey: string }> = {
  id: 'my-sandbox',
  name: 'My Sandbox',
  description: 'Cloud sandbox for command execution.',
  configSchema: {
    type: 'object',
    required: ['apiKey'],
    properties: {
      apiKey: { type: 'string' },
    },
  },
  async createSandbox(config): Promise<WorkspaceSandbox> {
    return createMySandbox({ apiKey: config.apiKey })
  },
}
```

注册后，管理员可以在内联 Workspace 配置或已保存的 [`StorageWorkspaceRef`](/reference/editor/storage-workspace-ref) 中引用该 Provider。
