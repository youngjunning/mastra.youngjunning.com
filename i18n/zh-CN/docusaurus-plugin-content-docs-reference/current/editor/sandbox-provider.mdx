# Sandbox提供者

`SandboxProvider`是包实现的用于注册Sandbox的接口[`MastraEditor`](/reference/editor/mastra-editor)。编辑呼吁`createSandbox(config)`在工作空间补水时，使用`provider`存储的id[`StorageWorkspaceRef`](/reference/editor/storage-workspace-ref)Sandbox配置作为查找键。

内置的`local` sandbox provider is auto-registered. External providers (for example, E2B) are supplied via `MastraEditorConfig.sandboxes`.

## 使用示例 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { MastraEditor } from '@mastra/editor'
import { e2bSandboxProvider } from '@mastra/e2b'

new MastraEditor({
  sandboxes: {
    [e2bSandboxProvider.id]: e2bSandboxProvider,
  },
})
```

## 实施提供者 {/* #implementing-a-provider */}

```typescript title="src/providers/my-sandbox.ts"
import type { SandboxProvider } from '@mastra/core/editor'
import type { WorkspaceSandbox } from '@mastra/core/workspace'

export const mySandboxProvider: SandboxProvider<{ apiKey: string }> = {
  id: 'my-sandbox',
  name: 'My Sandbox',
  description: 'Cloud sandbox for command execution.',
  configSchema: {
    type: 'object',
    required: ['apiKey'],
    properties: {
      apiKey: { type: 'string' },
    },
  },
  async createSandbox(config): Promise<WorkspaceSandbox> {
    return createMySandbox({ apiKey: config.apiKey })
  },
}
```

注册后，管理员可以从内联Workspace配置或存储的配置中引用提供程序[`StorageWorkspaceRef`](/reference/editor/storage-workspace-ref).
