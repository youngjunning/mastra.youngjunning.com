# Agent.streamUntilIdle()

**添加于：** `@mastra/core@1.29.0`

:::警告\[已弃用]

`streamUntilIdle()`已弃用。使用`stream()` with the `untilIdle`选项改为：

```ts
const result = await agent.stream('Research solana for me', {
  untilIdle: true,
  memory: { thread: 't1', resource: 'u1' },
})
```

经过`untilIdle: { maxIdleMs: 60_000 }` to configure the idle timeout.

:::

`streamUntilIdle()`流式传输Agent的响应并保持流打开，直到运行期间分派的每个后台任务完成。当任务完成时，其结果将被写入内存，并且Agent循环会自动重新进入，以便法学硕士可以对其做出反应。一旦没有任务正在运行并且没有完成排队，流就会关闭。

当Agent分派后台任务（通常是长时间运行的Tool或子Agent）并且您需要跨越初始响应的单个流时使用它**plus** every continuation triggered by a task completion. For foreground-only runs or if you prefer to manage the continuation manually (manually prompt agent to process the result), use [`Agent.stream()`](./stream).

## 使用示例 {/* #usage-example */}

```ts
const stream = await agent.streamUntilIdle('Research solana for me', {
  memory: { thread: 't1', resource: 'u1' },
})

for await (const chunk of stream.fullStream) {
  // chunks from the initial turn AND any continuation turns triggered by
  // background task completions flow through here
}
```

：：：笔记

`streamUntilIdle()`需要两个[`BackgroundTaskManager`](/reference/configuration#backgroundtasks) and a [memory](/docs/memory/overview) backend. Without either, it uses a plain `agent.stream()` call.

:::

### 聚合属性警告 {/* #aggregate-properties-caveat */}

`streamUntilIdle()`返回第一回合的Agent`MastraModelOutput`. Only `fullStream` is replaced with a combined stream that spans every continuation. Every other property (`text`, `toolCalls`, `toolResults`, `finishReason`, `messageList`, and `getFullOutput()`) resolves against the **first turn's** internal buffer.

如果您需要所有延续的聚合视图，请使用`fullStream` yourself and accumulate.

## 延续行为 {/* #continuation-behavior */}

在内部，`streamUntilIdle()`:

1. 通过运行初始转弯`agent.stream(...)` and pipes its `fullStream` into the outer stream.
2. 订阅已解析内存范围的后台任务完成事件。
3. 将每个终端事件排队（`background-task-completed`, `background-task-failed`, `background-task-cancelled`, `background-task-suspended`) and, when the outer wrapper is idle between turns, re-invokes `agent.stream([], ...)` with a directive listing the completed `toolCallId`s. The continuation turn flows into the same outer stream.
4. 一旦没有任务正在运行并且没有完成排队，则关闭外部流。

## 扩展使用示例 {/* #extended-usage-example */}

### 限制轮次之间的空闲时间 {/* #cap-idle-time-between-turns */}

```ts title="index.ts"
const stream = await agent.streamUntilIdle('Kick off the long jobs', {
  memory: { thread: 't1', resource: 'u1' },
  maxIdleMs: 60_000, // close the stream after 1 minute of idleness between turns
})

for await (const chunk of stream.fullStream) {
  if (chunk.type === 'background-task-completed') {
    console.log('Task complete:', chunk.payload.taskId)
  }
}
```

### 跨延续聚合文本 {/* #aggregate-text-across-continuations */}

```ts title="index.ts"
const stream = await agent.streamUntilIdle('Research and summarize', {
  memory: { thread: 't1', resource: 'u1' },
})

let fullText = ''
for await (const chunk of stream.fullStream) {
  if (chunk.type === 'text-delta') {
    fullText += chunk.payload.text
  }
}
```
