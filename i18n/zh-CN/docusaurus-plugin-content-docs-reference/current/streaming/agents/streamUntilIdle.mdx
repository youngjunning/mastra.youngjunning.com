# Agent.streamUntilIdle()

**新增于：** `@mastra/core@1.29.0`

:::warning[已弃用]

`streamUntilIdle()` 已弃用。请改用 `stream()`，并设置 `untilIdle` 选项：

```ts
const result = await agent.stream('Research solana for me', {
  untilIdle: true,
  memory: { thread: 't1', resource: 'u1' },
})
```

传入 `untilIdle: { maxIdleMs: 60_000 }` 可配置空闲超时。

:::

`streamUntilIdle()` 流式传输 Agent 的响应，并保持流打开，直到本次运行派发的所有后台任务完成。任务完成后，其结果会写入内存，Agent 循环会自动再次运行，让 LLM 可以处理该结果。当没有任务在运行、也没有待处理的完成事件时，流才会关闭。

当 Agent 派发后台任务（通常是耗时较长的 Tool 或子 Agent），且需要单个流同时涵盖初始响应**以及**任务完成后触发的所有续传时，可使用此方法。如果运行中只有前台任务，或你希望手动管理续传（手动提示 Agent 处理结果），请使用 [`Agent.stream()`](./stream)。

## 用法示例 {/* #usage-example */}

```ts
const stream = await agent.streamUntilIdle('Research solana for me', {
  memory: { thread: 't1', resource: 'u1' },
})

for await (const chunk of stream.fullStream) {
  // chunks from the initial turn AND any continuation turns triggered by
  // background task completions flow through here
}
```

:::note

`streamUntilIdle()` 同时需要 [`BackgroundTaskManager`](/reference/configuration#backgroundtasks) 和[内存](/docs/memory/overview)后端。缺少任一项时，它会改为调用普通的 `agent.stream()`。

:::

### 聚合属性注意事项 {/* #aggregate-properties-caveat */}

`streamUntilIdle()` 返回一个代理对象，底层是第一轮的 `MastraModelOutput`。只有 `fullStream` 被替换为涵盖所有续传的合并流。其他属性（`text`、`toolCalls`、`toolResults`、`finishReason`、`messageList` 和 `getFullOutput()`）都只读取**第一轮**的内部缓冲区。

如果需要汇总所有续传的结果，请自行消费并累积 `fullStream`。

## 续传行为 {/* #continuation-behavior */}

`streamUntilIdle()` 的内部流程：

1. 通过 `agent.stream(...)` 执行初始轮次，并将其 `fullStream` 接入外层流。
2. 订阅已确定的内存范围内后台任务的完成事件。
3. 将每个终态事件（`background-task-completed`、`background-task-failed`、`background-task-cancelled`、`background-task-suspended`）加入队列。外层包装器在两轮之间空闲时，会再次调用 `agent.stream([], ...)`，并附上列出已完成 `toolCallId` 的指令。续传轮次进入同一个外层流。
4. 当没有任务在运行且完成事件队列为空时，关闭外层流。

## 扩展示例 {/* #extended-usage-example */}

### 限制轮次之间的空闲时间 {/* #cap-idle-time-between-turns */}

```ts title="index.ts"
const stream = await agent.streamUntilIdle('Kick off the long jobs', {
  memory: { thread: 't1', resource: 'u1' },
  maxIdleMs: 60_000, // close the stream after 1 minute of idleness between turns
})

for await (const chunk of stream.fullStream) {
  if (chunk.type === 'background-task-completed') {
    console.log('Task complete:', chunk.payload.taskId)
  }
}
```

### 汇总各次续传的文本 {/* #aggregate-text-across-continuations */}

```ts title="index.ts"
const stream = await agent.streamUntilIdle('Research and summarize', {
  memory: { thread: 't1', resource: 'u1' },
})

let fullText = ''
for await (const chunk of stream.fullStream) {
  if (chunk.type === 'text-delta') {
    fullText += chunk.payload.text
  }
}
```
