# Agent.streamLegacy()（旧版）

:::warning

**已弃用**：此方法仅适用于 V1 模型。V2 模型请改用新的 [`.stream()`](./stream) 方法。升级详情参见[迁移指南](/reference/migrations/vnext-to-standard-apis)。

:::

`.streamLegacy()` 是 Agent 流式 API 的旧版方法，用于实时流式返回 V1 模型 Agent 的响应。它接受消息以及可选的流式处理选项。

## 用法示例 {/* #usage-example */}

```typescript
await agent.streamLegacy('message for agent')
```

```typescript
await agent.streamLegacy('message for agent', {
  temperature: 0.7,
  maxSteps: 3,
  memory: {

  toolChoice: 'auto',

```

## 迁移到新 API {/* #migration-to-new-api */}

:::note

新的 `.stream()` 方法提供更强的功能，包括兼容 AI SDK v5+、更完善地处理结构化输出，以及改进的回调机制。详细迁移步骤参见[迁移指南](/reference/migrations/vnext-to-standard-apis)。

:::

### 快速迁移示例 {/* #quick-migration-example */}

#### 迁移前（旧版） {/* #before-legacy */}

```typescript
const result = await agent.streamLegacy('message', {
  temperature: 0.7,
  maxSteps: 3,
  onFinish: result => console.log(result),
})
```

#### 迁移后（新 API） {/* #after-new-api */}

```typescript
const result = await agent.stream('message', {
  modelSettings: {
    temperature: 0.7,
  },
  maxSteps: 3,
  onFinish: result => console.log(result),
})
```
