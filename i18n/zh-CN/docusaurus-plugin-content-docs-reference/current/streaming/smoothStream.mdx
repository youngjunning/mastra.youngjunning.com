# `smoothStream()`

`smoothStream()` 创建实验性的转换流，先缓冲文本和推理增量，再以大小较一致的块输出。当模型输出的增量不均匀时，可用它让流式响应呈现得更平稳。

非文本块原样通过。遇到 Tool、控制或完成块时，会先输出已缓冲的内容。

## 使用示例 {/* #usage-example */}

将 Agent 的 `fullStream` 通过此转换流：

```typescript title="src/stream-agent.ts"
import { smoothStream } from '@mastra/core/stream'

const result = await agent.stream('Explain how rainbows form')

const stream = result.fullStream.pipeThrough(
  smoothStream({
    delayInMs: 20,
    chunking: 'word',
  }),
)

for await (const chunk of stream) {
  if (chunk.type === 'text-delta') {
    process.stdout.write(chunk.payload.text)
  }
}
```

此转换只影响通过管道传入的流。原始 `MastraModelOutput` 上的 Promise 属性和回调（如 `result.text` 和 `onChunk`）仍保持模型原有的块输出时间。

## AI SDK 路由 {/* #ai-sdk-routes */}

导入 `smoothStream()`，来源为 `@mastra/ai-sdk`，即可在 `handleChatStream()` 将 Agent 输出转换为 AI SDK UI 块之前，使输出更平滑：

```typescript title="app/api/chat/route.ts"
import { handleChatStream, smoothStream } from '@mastra/ai-sdk'
import { createUIMessageStreamResponse } from 'ai'
import { mastra } from '@/src/mastra'

export async function POST(req: Request) {
  const params = await req.json()
  const stream = await handleChatStream({
    mastra,
    agentId: 'weatherAgent',
    params,
    experimentalTransform: smoothStream({
      delayInMs: 20,
      chunking: 'word',
    }),
  })

  return createUIMessageStreamResponse({ stream })
}
```

`@mastra/ai-sdk` 导出的版本返回可复用的转换流工厂，因此路由配置会为每次请求创建新的 `TransformStream`。`@mastra/core/stream` 导出的版本直接返回 `TransformStream`，可用于 `pipeThrough()`。

也可以将此可复用工厂传给 `Agent.stream()`：

```typescript
import { smoothStream } from '@mastra/ai-sdk'

const result = await agent.stream('Explain how rainbows form', {
  experimentalTransform: smoothStream({ delayInMs: 20 }),
})

for await (const chunk of result.fullStream) {
  // Consume the transformed Mastra chunks.
}
```

`chunking` 选项支持：

- `'word'`：输出完整单词，包括末尾空白字符。
- `'line'`：输出直到每个换行符为止的内容。
- `RegExp`：输出直到第一个匹配项为止的内容。
- `Intl.Segmenter`：按语言区域规则分词，适用于词语之间没有空格的语言。
- `SmoothStreamChunkDetector`：将当前缓冲内容传给函数。函数返回非空前缀以供输出，或返回 `null`、`undefined` 以等待更多内容。

## 自定义分块 {/* #custom-chunking */}

使用正则表达式定义分块边界：

```typescript
const stream = result.fullStream.pipeThrough(
  smoothStream({
    chunking: /[^,]*,\s*/,
  }),
)
```

使用 `Intl.Segmenter` 按语言区域规则分词：

```typescript
const stream = result.fullStream.pipeThrough(
  smoothStream({
    chunking: new Intl.Segmenter('ja', { granularity: 'word' }),
  }),
)
```

当分块边界取决于自定义逻辑时，使用检测函数。返回值必须是缓冲内容的前缀：

```typescript
const stream = result.fullStream.pipeThrough(
  smoothStream({
    chunking: buffer => {
      const boundary = buffer.indexOf('. ')
      return boundary === -1 ? null : buffer.slice(0, boundary + 2)
    },
  }),
)
```

## 返回值 {/* #returns */}

`TransformStream<ChunkType<OUTPUT>, ChunkType<OUTPUT>>`

转换流输出经过平滑处理的 `text-delta` 和 `reasoning-delta` 块，同时保留块 ID、运行 ID、来源和元数据。
