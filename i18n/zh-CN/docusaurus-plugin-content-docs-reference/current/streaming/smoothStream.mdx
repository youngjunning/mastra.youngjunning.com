# `smoothStream()`

`smoothStream()`创建一个实验性转换流，在以一致的块形式发出文本和推理增量之前缓冲它们。当模型发出不均匀的增量时，使用它可以使流式响应以更稳定的速度显示。

非文本块不变地通过。任何缓冲的内容都会在Tool、控件或完成块之前发出。

## 使用示例 {/* #usage-example */}

管道Agent`fullStream` through the transform:

```typescript title="src/stream-agent.ts"
import { smoothStream } from '@mastra/core/stream'

const result = await agent.stream('Explain how rainbows form')

const stream = result.fullStream.pipeThrough(
  smoothStream({
    delayInMs: 20,
    chunking: 'word',
  }),
)

for await (const chunk of stream) {
  if (chunk.type === 'text-delta') {
    process.stdout.write(chunk.payload.text)
  }
}
```

转换仅更改管道流。原始 Promise 属性和回调`MastraModelOutput`, such as `result.text` and `onChunk`，保持模型的原始块计时。

## AI SDK路线 {/* #ai-sdk-routes */}

进口`smoothStream()` from `@mastra/ai-sdk` to smooth an agent before `handleChatStream()` converts its output to AI SDK UI chunks:

```typescript title="app/api/chat/route.ts"
import { handleChatStream, smoothStream } from '@mastra/ai-sdk'
import { createUIMessageStreamResponse } from 'ai'
import { mastra } from '@/src/mastra'

export async function POST(req: Request) {
  const params = await req.json()
  const stream = await handleChatStream({
    mastra,
    agentId: 'weatherAgent',
    params,
    experimentalTransform: smoothStream({
      delayInMs: 20,
      chunking: 'word',
    }),
  })

  return createUIMessageStreamResponse({ stream })
}
```

这`@mastra/ai-sdk` export returns a reusable transform factory so route configuration creates a fresh `TransformStream` for every request. The `@mastra/core/stream` export returns a `TransformStream` for direct use with `pipeThrough()`.

可重用工厂也可以传递给`Agent.stream()`:

```typescript
import { smoothStream } from '@mastra/ai-sdk'

const result = await agent.stream('Explain how rainbows form', {
  experimentalTransform: smoothStream({ delayInMs: 20 }),
})

for await (const chunk of result.fullStream) {
  // Consume the transformed Mastra chunks.
}
```

这`chunking` option accepts:

* `'word'`：发出完整的单词，包括尾随空格。
* `'line'`：通过每个换行符发出内容。
* `RegExp`：通过第一场比赛发出内容。
* `Intl.Segmenter`：使用区域设置感知分段，这对于单词之间没有空格的语言很有用。
* `SmoothStreamChunkDetector`：使用当前缓冲区调用函数。该函数返回一个要发出的非空前缀，或者`null` or `undefined` to wait for more content.

## 自定义分块 {/* #custom-chunking */}

使用正则表达式定义块边界：

```typescript
const stream = result.fullStream.pipeThrough(
  smoothStream({
    chunking: /[^,]*,\s*/,
  }),
)
```

使用`Intl.Segmenter` for locale-aware segmentation:

```typescript
const stream = result.fullStream.pipeThrough(
  smoothStream({
    chunking: new Intl.Segmenter('ja', { granularity: 'word' }),
  }),
)
```

当块边界取决于自定义逻辑时，使用检测器函数。返回值必须是缓冲区的前缀：

```typescript
const stream = result.fullStream.pipeThrough(
  smoothStream({
    chunking: buffer => {
      const boundary = buffer.indexOf('. ')
      return boundary === -1 ? null : buffer.slice(0, boundary + 2)
    },
  }),
)
```

## 退货 {/* #returns */}

`TransformStream<ChunkType<OUTPUT>, ChunkType<OUTPUT>>`

变换发出平滑的`text-delta` and `reasoning-delta` chunks. It preserves chunk identifiers, run identifiers, sources, and metadata.
