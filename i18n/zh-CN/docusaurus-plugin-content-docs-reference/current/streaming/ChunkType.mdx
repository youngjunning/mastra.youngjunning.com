# ChunkType

`ChunkType` 类型定义 Agent 流式响应期间可能发出的数据块的 Mastra 格式。

## 基础属性 {/* #base-properties */}

除自定义 data-* 数据块外，所有数据块都包含以下基础属性：

## 线程订阅数据块 {/* #thread-subscription-chunks */}

### data-user-message-pending {/* #data-user-message-pending */}

线程接受中途引导或排队中的后续输入后、Agent 消费前，会发出临时的用户消息映射。订阅者可立即显示输入，再与实际投递的 `data-user-message` 数据块按 `data.id` 对账。

此数据块不会保存到对话历史。加入当前运行的中途引导，其 `data.metadata.status` 为 `pending`；之后运行的后续输入则为 `queued`。

```typescript
type UserMessagePendingChunk = {
  type: 'data-user-message-pending'
  runId: string
  traceId?: string
  from: ChunkFrom
  metadata?: Record<string, any>
  transient: true
  data: AgentSignalDataPart['data'] & {
    metadata: Record<string, unknown> & {
      status: 'pending' | 'queued'
    }
  }
}
```

### data-user-message-cancelled {/* #data-user-message-cancelled */}

已接受的用户输入在投递前取消时，会发出临时移除事件。订阅者可按 `data.id` 移除对应的待处理消息映射。

只有输入已移除后才发出此数据块，因此它确认的是移除结果，而非取消请求。它是临时数据块，不保存到对话历史。

```typescript
type UserMessageCancelledChunk = {
  type: 'data-user-message-cancelled'
  runId: string
  traceId?: string
  from: ChunkFrom
  metadata?: Record<string, any>
  transient: true
  data: {
    id: string
  }
}
```

### thread-run-status {/* #thread-run-status */}

`ThreadRunStatusChunk` 独立于已存储消息的重放，报告运行结果。它由 `@mastra/core/stream` 导出；只有 `subscribeToThread()` 接收 `withRunStatus: true` 时才会发出。该选项默认为 `false`。

实时输出先于状态到达。`success`、`failed` 和 `aborted` 是最终结果；`suspended` 可恢复，因此同一次运行之后仍可能发出更多输出和最终结果。状态不会关闭订阅。

启用 `withInitialHistory` 时，`thread-history` 最先到达。选择接收状态的后续订阅者会收到每个仍被保留的已结束运行的一条结果，包括不在该页历史记录中的运行。最终结果在单次订阅内去重；暂停状态按执行片段去重。重新连接可能再次投递结果。恢复能力取决于 PubSub 的保留期限，不能将其视为永久审计日志。参见[线程流](/docs/signals/thread-streams#detect-when-a-run-finishes)。

## 用法示例 {/* #usage-example */}

```typescript
const stream = await agent.stream('Hello')

for await (const chunk of stream.fullStream) {
  switch (chunk.type) {
    case 'text-delta':
      console.log('Text:', chunk.payload.text)
      break

    case 'tool-call':
      console.log('Calling tool:', chunk.payload.toolName)
      break

    case 'tool-result':
      console.log('Tool result:', chunk.payload.result)
      break

    case 'reasoning-delta':
      console.log('Reasoning:', chunk.payload.text)
      break

    case 'finish':
      console.log('Finished:', chunk.payload.stepResult.reason)
      console.log('Usage:', chunk.payload.output.usage)
      break

    case 'error':
      console.error('Error:', chunk.payload.error)
      break
  }
}
```
