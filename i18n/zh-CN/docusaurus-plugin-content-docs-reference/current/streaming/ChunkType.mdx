# 块类型

这`ChunkType`type 定义了可以在Agent的流响应期间发出的流块的 Mastra 格式。

## 基本属性 {/* #base-properties */}

除自定义之外的所有块`data-*` chunks include these base properties:

```typescript
  runId: string
  traceId?: string
  from: ChunkFrom
  metadata?: Record<string, any>
  transient: true
  data: AgentSignalDataPart['data'] & {
    metadata: Record<string, unknown> & {
      status: 'pending' | 'queued'
    }
  }
}
```

### 线程运行状态 {/* #thread-run-status */}

`ThreadRunStatusChunk`独立于存储的消息重放来报告运行结果。它是从导出的`@mastra/core/stream` and emitted only when `subscribeToThread()` receives `withRunStatus: true`. The option defaults to `false`.

实时输出先于其状态。`success`, `failed`, and `aborted` are final outcomes. `suspended` is resumable, so the same run can later emit more output and a final outcome. A status doesn't close the subscription.

和`withInitialHistory`, `thread-history` arrives first. Opted-in late subscribers then receive one outcome per still-retained finished run, including runs outside that history page. Final outcomes are deduplicated within a subscription. Suspensions are deduplicated per execution segment. Reconnecting can redeliver outcomes. Recovery depends on PubSub retention and isn't a permanent audit log. See [Thread streams](/docs/signals/thread-streams#detect-when-a-run-finishes).

## 使用示例 {/* #usage-example */}

```typescript
const stream = await agent.stream('Hello')

for await (const chunk of stream.fullStream) {
  switch (chunk.type) {
    case 'text-delta':
      console.log('Text:', chunk.payload.text)
      break

    case 'tool-call':
      console.log('Calling tool:', chunk.payload.toolName)
      break

    case 'tool-result':
      console.log('Tool result:', chunk.payload.result)
      break

    case 'reasoning-delta':
      console.log('Reasoning:', chunk.payload.text)
      break

    case 'finish':
      console.log('Finished:', chunk.payload.stepResult.reason)
      console.log('Usage:', chunk.payload.output.usage)
      break

    case 'error':
      console.error('Error:', chunk.payload.error)
      break
  }
}
```
