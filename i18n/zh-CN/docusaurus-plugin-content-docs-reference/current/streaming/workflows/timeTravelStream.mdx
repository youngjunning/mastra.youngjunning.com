# Run.timeTravelStream()

`.timeTravelStream()` 方法从指定步骤重新执行 Workflow，并流式返回事件。执行期间，你可以实时接收更新，随时查看每个步骤的进度。

## 使用示例 {/* #usage-example */}

```typescript
const run = await workflow.createRun()

const output = run.timeTravelStream({
  step: 'step2',
  inputData: { value: 10 },
})

// Process events as they arrive
for await (const event of output.fullStream) {
  console.log(event.type, event.payload)
}

// Get the final result
const result = await output.result
```

## 参数 {/* #parameters */}

所有参数均与 [`Run.timeTravel()`](../../workflows/run-methods/timeTravel#parameters) 相同。详细说明请参阅 [timeTravel 参考文档](../../workflows/run-methods/timeTravel#parameters)。

## 流事件 {/* #stream-events */}

执行期间，流会发出以下 Workflow 事件：

- `workflow-step-start`：步骤开始执行时发出
- `workflow-step-result`：步骤产生结果时发出
- `workflow-step-error`：步骤发生错误时发出
- `workflow-step-suspended`：步骤暂停时发出
- 还可能根据步骤类型发出其他事件（如 Agent、Tool 事件）

## 更多使用示例 {/* #extended-usage-examples */}

### 在时间旅行执行期间处理事件 {/* #processing-events-during-time-travel */}

```typescript
const run = await workflow.createRun()

const output = run.timeTravelStream({
  step: 'step2',
  inputData: { value: 10 },
})

for await (const event of output.fullStream) {
  switch (event.type) {
    case 'workflow-step-start':
      console.log(`Starting step: ${event.payload.stepName}`)
      break
    case 'workflow-step-result':
      console.log(`Completed step: ${event.payload.id}`)
      break
    case 'workflow-step-error':
      console.error(`Error in step: ${event.payload.stepName}`, event.payload.error)
      break
  }
}

const result = await output.result
console.log('Time travel completed:', result)
```

### 使用上下文的时间旅行流 {/* #time-travel-stream-with-context */}

```typescript
const output = run.timeTravelStream({
  step: 'step2',
  context: {
    step1: {
      status: 'success',
      payload: { value: 0 },
      output: { step1Result: 2 },
      startedAt: Date.now(),
      endedAt: Date.now(),
    },
  },
})

for await (const event of output.fullStream) {
  // Handle events
  console.log(event)
}

const result = await output.result
```

### 使用嵌套 Workflow 的时间旅行流 {/* #time-travel-stream-with-nested-workflows */}

```typescript
const output = run.timeTravelStream({
  step: ['nestedWorkflow', 'step3'],
  inputData: { value: 10 },
  nestedStepsContext: {
    nestedWorkflow: {
      step2: {
        status: 'success',
        payload: { step1Result: 2 },
        output: { step2Result: 3 },
        startedAt: Date.now(),
        endedAt: Date.now(),
      },
    },
  },
})

for await (const event of output.fullStream) {
  console.log(event.type, event.payload)
}

const result = await output.result
```

## 注意事项 {/* #notes */}

- 时间旅行执行完成或出错时，流会自动关闭
- Workflow 仍在执行时，就可以处理流中的事件
- `result` Promise 只会在所有步骤完成后解析
- 流事件的格式与常规 Workflow 流相同
- 时间旅行流依赖持久化的 Workflow 快照，因此必须配置存储
