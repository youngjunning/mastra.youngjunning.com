# Run.timeTravelStream()

这`.timeTravelStream()`方法从具有流事件的任何特定步骤开始重新执行Workflow。您可以在时间旅行执行期间接收实时更新，同时保持对每个步骤进度的全面可见性。

## 使用示例 {/* #usage-example */}

```typescript
const run = await workflow.createRun()

const output = run.timeTravelStream({
  step: 'step2',
  inputData: { value: 10 },
})

// Process events as they arrive
for await (const event of output.fullStream) {
  console.log(event.type, event.payload)
}

// Get the final result
const result = await output.result
```

## 参数 {/* #parameters */}

所有参数都相同[`Run.timeTravel()`](../../workflows/run-methods/timeTravel#parameters). See the [timeTravel reference](../../workflows/run-methods/timeTravel#parameters) for detailed parameter documentation.

## 直播事件 {/* #stream-events */}

流在执行期间发出Workflow事件：

* `workflow-step-start`：当步骤开始执行时发出
* `workflow-step-result`：当步骤产生结果时发出
* `workflow-step-error`：当步骤遇到错误时发出
* `workflow-step-suspended`：当步骤暂停时发出
* 取决于步骤类型（Agent、Tool等）的附加事件

## 扩展使用示例 {/* #extended-usage-examples */}

### 处理时间旅行期间的事件 {/* #processing-events-during-time-travel */}

```typescript
const run = await workflow.createRun()

const output = run.timeTravelStream({
  step: 'step2',
  inputData: { value: 10 },
})

for await (const event of output.fullStream) {
  switch (event.type) {
    case 'workflow-step-start':
      console.log(`Starting step: ${event.payload.stepName}`)
      break
    case 'workflow-step-result':
      console.log(`Completed step: ${event.payload.id}`)
      break
    case 'workflow-step-error':
      console.error(`Error in step: ${event.payload.stepName}`, event.payload.error)
      break
  }
}

const result = await output.result
console.log('Time travel completed:', result)
```

### 具有上下文的时间旅行流 {/* #time-travel-stream-with-context */}

```typescript
const output = run.timeTravelStream({
  step: 'step2',
  context: {
    step1: {
      status: 'success',
      payload: { value: 0 },
      output: { step1Result: 2 },
      startedAt: Date.now(),
      endedAt: Date.now(),
    },
  },
})

for await (const event of output.fullStream) {
  // Handle events
  console.log(event)
}

const result = await output.result
```

### 具有嵌套Workflow程的时间旅行流 {/* #time-travel-stream-with-nested-workflows */}

```typescript
const output = run.timeTravelStream({
  step: ['nestedWorkflow', 'step3'],
  inputData: { value: 10 },
  nestedStepsContext: {
    nestedWorkflow: {
      step2: {
        status: 'success',
        payload: { step1Result: 2 },
        output: { step2Result: 3 },
        startedAt: Date.now(),
        endedAt: Date.now(),
      },
    },
  },
})

for await (const event of output.fullStream) {
  console.log(event.type, event.payload)
}

const result = await output.result
```

## 笔记 {/* #notes */}

* 当时间旅行执行完成或遇到错误时流自动关闭
* 您可以在Workflow仍在执行时处理流中的事件
* 这`result` promise resolves only after all steps have completed
* 流事件遵循与常规Workflow流相同的格式
* 时间旅行流需要配置存储，因为它依赖于持久的Workflow快照
