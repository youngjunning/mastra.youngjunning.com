# 运行.observeStream()

这`.observeStream()`方法打开一个新的`ReadableStream`到当前正在运行的Workflow运行，允许您在原始流不再可用时观察事件流。

## 使用示例 {/* #usage-example */}

```typescript
const run = await workflow.createRun()

run.stream({
  inputData: {
    value: 'initial data',
  },
})

const stream = await run.observeStream()

for await (const chunk of stream) {
  console.log(chunk)
}
```

## 退货 {/* #returns */}

`ReadableStream<ChunkType>`

## 直播事件 {/* #stream-events */}

流在Workflow执行期间发出事件类型。每个事件都有一个`type` field and a `payload` containing relevant data:

* **`workflow-start`**：Workflow程开始执行
* **`workflow-step-start`**: 一个步骤开始执行
* **`workflow-step-output`**：步骤的自定义输出
* **`workflow-step-result`**：步骤完成并有结果
* **`workflow-finish`**：Workflow程执行完成并带有使用情况统计信息。为了成功运行，`payload.finalWorkflowResult` carries the workflow's final result
