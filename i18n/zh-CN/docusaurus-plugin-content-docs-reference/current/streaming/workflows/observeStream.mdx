# Run.observeStream()

`.observeStream()` 为仍在执行的 Workflow 运行打开一个新的 `ReadableStream`，即使原来的流不可用，也能继续观察事件。

## 使用示例 {/* #usage-example */}

```typescript
const run = await workflow.createRun()

run.stream({
  inputData: {
    value: 'initial data',
  },
})

const stream = await run.observeStream()

for await (const chunk of stream) {
  console.log(chunk)
}
```

## 返回值 {/* #returns */}

`ReadableStream<ChunkType>`

## 流事件 {/* #stream-events */}

Workflow 执行期间，流会发出以下事件。每个事件包含 `type` 字段，以及承载相关数据的 `payload`。

* **`workflow-start`**：Workflow 开始执行
* **`workflow-step-start`**：某个步骤开始执行
* **`workflow-step-output`**：某个步骤发出的自定义输出
* **`workflow-step-result`**：某个步骤执行完毕并返回结果
* **`workflow-finish`**：Workflow 执行结束并提供用量统计。执行成功时，`payload.finalWorkflowResult` 包含 Workflow 的最终结果
