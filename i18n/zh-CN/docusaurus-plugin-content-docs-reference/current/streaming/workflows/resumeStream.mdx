# Run.resumeStream()

`.resumeStream()` 方法使用新数据恢复已暂停的 Workflow 运行，可从指定步骤继续执行并观察事件流。

## 使用示例 {/* #usage-example */}

```typescript
const run = await workflow.createRun()

const stream = run.stream({
  inputData: {
    value: 'initial data',
  },
})

const result = await stream.result

if (result!.status === 'suspended') {
  const resumedStream = await run.resumeStream({
    resumeData: {
      value: 'resume data',
    },
  })
}
```

## 流事件 {/* #stream-events */}

流会在 Workflow 执行期间发出多种事件。每个事件都有 `type` 字段，以及包含相关数据的 `payload`：

- **`workflow-start`**：Workflow 开始执行
- **`workflow-step-start`**：步骤开始执行
- **`workflow-step-output`**：步骤产生自定义输出
- **`workflow-step-result`**：步骤完成并返回结果
- **`workflow-finish`**：Workflow 执行完成，并附带用量统计。运行成功时，`payload.finalWorkflowResult` 包含 Workflow 的最终结果
