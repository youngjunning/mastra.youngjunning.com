# handleNetworkStream()

:::warning[已弃用]

Agent network 已弃用，将在未来版本中移除。请改用[监督 Agent](/docs/subagents)，并调用 `agent.stream()` 或 `agent.generate()`。升级步骤请参阅[迁移指南](/reference/migrations/network-to-supervisor)。

:::

此处理函数不依赖特定框架，以 AI SDK 兼容格式流式执行 Agent network。当你需要在 Hono 或 Mastra 自身的 [apiRoutes](/docs/server/custom-api-routes) 功能之外处理 network 流时，可直接使用此函数。

`handleNetworkStream()` 返回 `ReadableStream`，可用 [`createUIMessageStreamResponse()`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/create-ui-message-stream-response) 将其包装为响应。

`handleNetworkStream()` 默认保持现有的 AI SDK v5 行为。如果应用的类型定义基于 AI SDK v6，请传入 `version: 'v6'`。

如果要在 Mastra 服务器内创建 network 路由，请使用 [`networkRoute()`](/reference/ai-sdk/network-route)。

## 使用示例 {/* #usage-example */}

Next.js App Router 示例：

```typescript title="app/api/network/route.ts"
import { handleNetworkStream } from '@mastra/ai-sdk'
import { createUIMessageStreamResponse } from 'ai'
import { mastra } from '@/src/mastra'

export async function POST(req: Request) {
  const params = await req.json()
  const stream = await handleNetworkStream({
    mastra,
    agentId: 'routingAgent',
    params,
  })
  return createUIMessageStreamResponse({ stream })
}
```
