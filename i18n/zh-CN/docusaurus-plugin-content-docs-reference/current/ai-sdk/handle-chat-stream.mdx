# 处理聊天流()

与框架无关的处理程序，用于以 AI SDK 兼容格式进行流Agent聊天。当您需要在 Hono 或 Mastra 自己的外部处理聊天流时，直接使用此功能[apiRoutes](/docs/server/custom-api-routes)特征。

`handleChatStream()`返回一个`ReadableStream` that you can wrap with [`createUIMessageStreamResponse()`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/create-ui-message-stream-response).

`handleChatStream()`默认为 AI SDK v5 以实现向后兼容。传入与您安装的AI SDK匹配的版本，例如`version: 'v7'` for AI SDK v7.

使用[`chatRoute()`](/reference/ai-sdk/chat-route) if you want to create a chat route inside a Mastra server.

## UI 流中的结构化输出 {/* #structured-output-in-ui-streams */}

当你通过时`structuredOutput` to the underlying agent execution, the final structured output object is emitted in the AI SDK-compatible UI stream as a custom data part:

```json
{
  "type": "data-structured-output",
  "data": {
    "object": {}
  }
}
```

这`object` field contains your full structured output value. Mastra emits this event for the final structured output object only. Partial structured output chunks aren't exposed in the UI stream.

使用AI SDK UI的自定义数据处理读取此事件，例如`onData`, or render it from message data parts.

## 使用示例 {/* #usage-example */}

Next.js 应用程序路由器示例：

```typescript title="app/api/chat/route.ts"
import { handleChatStream } from '@mastra/ai-sdk'
import { createUIMessageStreamResponse } from 'ai'
import { mastra } from '@/src/mastra'

export async function POST(req: Request) {
  const params = await req.json()
  const stream = await handleChatStream({
    mastra,
    agentId: 'weatherAgent',
    version: 'v7',
    params,
    messageMetadata: () => ({ createdAt: new Date().toISOString() }),
  })
  return createUIMessageStreamResponse({ stream })
}
```

## 保持连接活跃 {/* #keeping-connections-alive */}

Agent和负载均衡器通常会关闭一段时间内不发送任何字节的连接，这会在长时间推理突发或缓慢的Tool调用期间丢弃响应。将编码后的响应包裹起来[`withSseHeartbeat()`](/reference/ai-sdk/with-sse-heartbeat) to emit periodic SSE comments while the stream is idle:

```typescript title="app/api/chat/route.ts"
import { handleChatStream, withSseHeartbeat } from '@mastra/ai-sdk'
import { createUIMessageStreamResponse } from 'ai'

return withSseHeartbeat(createUIMessageStreamResponse({ stream }), 15000)
```
