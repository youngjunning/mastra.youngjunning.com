# handleChatStream()

这是一个框架无关的处理函数，可将 Agent 聊天内容以兼容 AI SDK 的格式输出为流。如果需要在 Hono 或 Mastra 自带的 [apiRoutes](/docs/server/custom-api-routes) 功能之外处理聊天流，可直接使用它。

`handleChatStream()` 返回一个 `ReadableStream`，可用 [`createUIMessageStreamResponse()`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/create-ui-message-stream-response) 将其包装成响应。

为保持向后兼容，`handleChatStream()` 默认采用 AI SDK v5。请传入与你安装的 AI SDK 匹配的版本，例如 AI SDK v7 对应 `version: 'v7'`。

如需在 Mastra 服务器中创建聊天路由，请使用 [`chatRoute()`](/reference/ai-sdk/chat-route)。

## UI 流中的结构化输出 {/* #structured-output-in-ui-streams */}

向底层 Agent 执行传入 `structuredOutput` 后，最终的结构化输出对象会作为自定义数据片段，发送到兼容 AI SDK 的 UI 流中：

```json
{
  "type": "data-structured-output",
  "data": {
    "object": {}
  }
}
```

`object` 字段包含完整的结构化输出值。Mastra 仅对最终输出对象发出此事件；UI 流不会暴露部分结构化输出片段。

可通过 AI SDK UI 的自定义数据处理机制（如 `onData`）读取此事件，也可从消息的数据片段中渲染它。

## 使用示例 {/* #usage-example */}

Next.js App Router 示例：

```typescript title="app/api/chat/route.ts"
import { handleChatStream } from '@mastra/ai-sdk'
import { createUIMessageStreamResponse } from 'ai'
import { mastra } from '@/src/mastra'

export async function POST(req: Request) {
  const params = await req.json()
  const stream = await handleChatStream({
    mastra,
    agentId: 'weatherAgent',
    version: 'v7',
    params,
    messageMetadata: () => ({ createdAt: new Date().toISOString() }),
  })
  return createUIMessageStreamResponse({ stream })
}
```

## 保持连接活跃 {/* #keeping-connections-alive */}

代理服务器和负载均衡器通常会关闭一段时间内没有发送字节的连接，导致长时间推理或缓慢调用 Tool 时响应中断。可用 [`withSseHeartbeat()`](/reference/ai-sdk/with-sse-heartbeat) 包装已编码的响应，在流空闲时定期发送 SSE 注释：

```typescript title="app/api/chat/route.ts"
import { handleChatStream, withSseHeartbeat } from '@mastra/ai-sdk'
import { createUIMessageStreamResponse } from 'ai'

return withSseHeartbeat(createUIMessageStreamResponse({ stream }), 15000)
```
