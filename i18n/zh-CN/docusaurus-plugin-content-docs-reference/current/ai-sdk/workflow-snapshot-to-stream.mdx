# workflowSnapshotToStream()

将 `WorkflowState` 对象（由 `workflow.getWorkflowRunById()` 返回）转换为包含 AI SDK UIMessage 数据部分的 `ReadableStream`。该流包含 `WorkflowDataPart` 和 `WorkflowStepDataPart` 数据块，与实时 [`workflowRoute()`](/reference/ai-sdk/workflow-route) 生成的内容相同。

如果要使用渲染实时 Workflow 流的同一套 UI 组件来展示已完成或已暂停的 Workflow 运行，请使用此函数。

## 使用示例 {/* #usage-example */}

以下 Next.js App Router 端点将过去的 Workflow 运行重放为流：

```typescript title="app/api/workflow-replay/route.ts"
import { workflowSnapshotToStream } from '@mastra/ai-sdk'
import { createUIMessageStreamResponse } from 'ai'
import { mastra } from '@/src/mastra'

export async function GET(req: Request) {
  const { searchParams } = new URL(req.url)
  const runId = searchParams.get('runId')!

  const workflowRun = await mastra.getWorkflow('myWorkflow').getWorkflowRunById(runId)

  if (!workflowRun) {
    return new Response('Not found', { status: 404 })
  }

  const stream = workflowSnapshotToStream(workflowRun)
  return createUIMessageStreamResponse({ stream })
}
```

## 返回值 {/* #returns */}

`ReadableStream`：AI SDK UIMessage 数据部分的流，包含：

* 一个 `start` 标记
* 一个包含 Workflow 状态和所有步骤摘要的 `WorkflowDataPart`
* 每个步骤各有一个包含完整输出的 `WorkflowStepDataPart`
* 一个 `finish` 标记

将此流传递给 AI SDK 的 [`createUIMessageStreamResponse()`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/create-ui-message-stream-response) 或 `createUIMessageStream()`。
