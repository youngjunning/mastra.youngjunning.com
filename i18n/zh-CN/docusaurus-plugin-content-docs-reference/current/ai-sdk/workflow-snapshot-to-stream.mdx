# Workflow程SnapshotToStream()

转换一个`WorkflowState`对象（由返回`workflow.getWorkflowRunById()`) 变成`ReadableStream`AI SDK UIMessage 数据部分。该流包含相同的`WorkflowDataPart`和`WorkflowStepDataPart`活着的块[`workflowRoute()`](/reference/ai-sdk/workflow-route)产生。

当您想要使用渲染实时Workflow流的相同 UI 组件来显示已完成或暂停的Workflow运行时，请使用此选项。

## 使用示例 {/* #usage-example */}

Next.js App Router 端点，以流的形式重播过去的Workflow程：

```typescript title="app/api/workflow-replay/route.ts"
import { workflowSnapshotToStream } from '@mastra/ai-sdk'
import { createUIMessageStreamResponse } from 'ai'
import { mastra } from '@/src/mastra'

export async function GET(req: Request) {
  const { searchParams } = new URL(req.url)
  const runId = searchParams.get('runId')!

  const workflowRun = await mastra.getWorkflow('myWorkflow').getWorkflowRunById(runId)

  if (!workflowRun) {
    return new Response('Not found', { status: 404 })
  }

  const stream = workflowSnapshotToStream(workflowRun)
  return createUIMessageStreamResponse({ stream })
}
```

## 退货 {/* #returns */}

`ReadableStream`：AI SDK UIMessage 数据部分的流，包含：

* 一个`start` marker
* 一个`WorkflowDataPart` with the workflow status and all step summaries
* 一个`WorkflowStepDataPart` for each step with its full output
* 一个`finish` marker

将此流传递给[`createUIMessageStreamResponse()`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/create-ui-message-stream-response) or `createUIMessageStream()` from the AI SDK.
