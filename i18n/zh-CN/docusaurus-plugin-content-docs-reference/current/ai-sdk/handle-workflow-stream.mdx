# handleWorkflowStream()

此函数与框架无关，可将 Workflow 执行以兼容 AI SDK 的格式流式输出。如果需要在 Hono 或 Mastra 自带的 [apiRoutes](/docs/server/custom-api-routes) 功能之外处理 Workflow 流，可直接使用此函数。

`handleWorkflowStream()` 返回 `ReadableStream`，可使用 [`createUIMessageStreamResponse()`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/create-ui-message-stream-response) 将其封装为响应。

`handleWorkflowStream()` 默认沿用 AI SDK v5 的行为。如果应用的类型定义基于 AI SDK v6，请传入 `version: 'v6'`。

如果要在 Mastra 服务器内创建 Workflow 路由，请使用 [`workflowRoute()`](/reference/ai-sdk/workflow-route)。

:::tip Workflow 中的 Agent 流式输出

当 Workflow 步骤将 Agent 流传给 Workflow writer 时（例如 `await response.fullStream.pipeTo(writer)`），即使 Agent 在 Workflow 步骤内运行，其文本片段和 Tool 调用也会实时转发到 UI 流。

更多信息请参阅 [Workflow 流式处理](/docs/workflows/overview#inspecting-workflow-stream-payloads)。

:::

## 使用示例 {/* #usage-example */}

以下是 Next.js App Router 示例：

```typescript title="app/api/workflow/route.ts"
import { handleWorkflowStream } from '@mastra/ai-sdk'
import { createUIMessageStreamResponse } from 'ai'
import { mastra } from '@/src/mastra'

export async function POST(req: Request) {
  const params = await req.json()
  const stream = await handleWorkflowStream({
    mastra,
    workflowId: 'weatherWorkflow',
    params,
  })
  return createUIMessageStreamResponse({ stream })
}
```
