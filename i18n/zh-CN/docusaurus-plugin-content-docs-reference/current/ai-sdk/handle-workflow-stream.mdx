# 处理Workflow流()

与框架无关的处理程序，用于以 AI SDK 兼容格式流式处理Workflow执行。当您需要处理 Hono 或 Mastra 自己的Workflow之外的Workflow时，可以直接使用此功能[apiRoutes](/docs/server/custom-api-routes)特征。

`handleWorkflowStream()`返回一个`ReadableStream` that you can wrap with [`createUIMessageStreamResponse()`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/create-ui-message-stream-response).

`handleWorkflowStream()`保留现有的 AI SDK v5/默认行为。如果您的应用程序是针对 AI SDK v6 输入的，请传递`version: 'v6'`.

使用[`workflowRoute()`](/reference/ai-sdk/workflow-route) if you want to create a workflow route inside a Mastra server.

:::tip Workflow程中的Agent流式传输

当Workflow步骤将Agent的流传输到Workflow编写器时（例如，`await response.fullStream.pipeTo(writer)`), the agent's text chunks and tool calls are forwarded to the UI stream in real time, even when the agent runs inside workflow steps.

看[Workflow Streaming](/docs/workflows/overview#inspecting-workflow-stream-payloads) for more details.

:::

## 使用示例 {/* #usage-example */}

Next.js 应用程序路由器示例：

```typescript title="app/api/workflow/route.ts"
import { handleWorkflowStream } from '@mastra/ai-sdk'
import { createUIMessageStreamResponse } from 'ai'
import { mastra } from '@/src/mastra'

export async function POST(req: Request) {
  const params = await req.json()
  const stream = await handleWorkflowStream({
    mastra,
    workflowId: 'weatherWorkflow',
    params,
  })
  return createUIMessageStreamResponse({ stream })
}
```
