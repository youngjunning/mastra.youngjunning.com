# AI SDK

如果你已直接使用 [Vercel AI SDK](https://sdk.vercel.ai)，希望在不切换到完整 Mastra Agent API 的情况下加入 [Processor](/docs/agents/processors) 或 [Memory](/docs/memory/memory-processors) 等 Mastra 能力，可以使用 [`withMastra()`](/reference/ai-sdk/with-mastra) 包装任意 AI SDK 模型。这样既能保留现有 AI SDK 代码，又能加入输入/输出处理和对话持久化，包括内容过滤。

:::tip

如果要将 Mastra 与 AI SDK UI（如 `useChat()`）配合使用，请参阅 [AI SDK UI 指南](/integrations/agentic-ui/ai-sdk-ui)。

:::

## 安装 {/* #installation */}

安装 `@mastra/ai-sdk` 后即可使用 `withMastra()` 函数。

```bash npm2yarn
npm install @mastra/ai-sdk@latest
```

## 示例 {/* #examples */}

### 使用 Processor {/* #with-processors */}

Processor 可以在消息发送给模型前（`processInput`）和收到响应后（`processOutputResult`）处理消息。以下示例创建一个日志 Processor，记录各阶段的消息数量，然后用它包装 OpenAI 模型。

```typescript title="src/example.ts"
import { openai } from '@ai-sdk/openai'
import { generateText } from 'ai'
import { withMastra } from '@mastra/ai-sdk'
import type { Processor } from '@mastra/core/processors'

const loggingProcessor: Processor<'logger'> = {
  id: 'logger',
  async processInput({ messages }) {
    console.log('Input:', messages.length, 'messages')
    return messages
  },
  async processOutputResult({ messages }) {
    console.log('Output:', messages.length, 'messages')
    return messages
  },
}

const model = withMastra(openai('gpt-5.4'), {
  inputProcessors: [loggingProcessor],
  outputProcessors: [loggingProcessor],
})

const { text } = await generateText({
  model,
  prompt: 'What is 2 + 2?',
})
```

### 使用 Memory {/* #with-memory */}

Memory 会在调用 LLM 前自动从存储中加载历史消息，并在调用后保存新消息。以下示例配置 libSQL 存储后端来持久化对话历史，并加载最近 10 条消息作为上下文。

```typescript title="src/memory-example.ts"
import { openai } from '@ai-sdk/openai'
import { generateText } from 'ai'
import { withMastra } from '@mastra/ai-sdk'
import { LibSQLStore } from '@mastra/libsql'

const storage = new LibSQLStore({
  id: 'my-app',
  url: 'file:./data.db',
})
await storage.init()

const memoryStorage = await storage.getStore('memory')

const model = withMastra(openai('gpt-5.4'), {
  memory: {
    storage: memoryStorage!,
    threadId: 'user-thread-123',
    resourceId: 'user-123',
    lastMessages: 10,
  },
})

const { text } = await generateText({
  model,
  prompt: 'What did we talk about earlier?',
})
```

### 同时使用 Processor 和 Memory {/* #with-processors--memory */}

Processor 和 Memory 可以组合使用。输入 Processor 在 Memory 加载历史消息后运行；输出 Processor 在 Memory 保存响应前运行。

```typescript title="src/combined-example.ts"
import { openai } from '@ai-sdk/openai'
import { generateText } from 'ai'
import { withMastra } from '@mastra/ai-sdk'
import { LibSQLStore } from '@mastra/libsql'

const storage = new LibSQLStore({ id: 'my-app', url: 'file:./data.db' })
await storage.init()

const memoryStorage = await storage.getStore('memory')

const model = withMastra(openai('gpt-5.4'), {
  inputProcessors: [myGuardProcessor],
  outputProcessors: [myLoggingProcessor],
  memory: {
    storage: memoryStorage!,
    threadId: 'thread-123',
    resourceId: 'user-123',
    lastMessages: 10,
  },
})

const { text } = await generateText({
  model,
  prompt: 'Hello!',
})
```
