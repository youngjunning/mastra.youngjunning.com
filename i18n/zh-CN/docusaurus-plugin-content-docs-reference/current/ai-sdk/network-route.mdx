# networkRoute()

:::warning[已弃用]

Agent 网络已弃用，将在未来版本中移除。请改用[主管 Agent](/docs/subagents)，并调用 `agent.stream()` 或 `agent.generate()`。升级方法参见[迁移指南](/reference/migrations/network-to-supervisor)。

:::

创建一个网络路由处理器，以 AI SDK 格式流式返回网络执行结果。该函数会注册一个 HTTP `POST` 端点，接收消息并执行 Agent 网络，再以兼容 AI SDK 的格式将响应流式发送给客户端。Agent 网络允许路由 Agent 将任务委派给其他 Agent。请在[自定义 API 路由](/docs/server/custom-api-routes)中使用此函数。

如果需要与框架无关的处理器，请使用 [`handleNetworkStream()`](/reference/ai-sdk/handle-network-stream)。

`networkRoute()` 默认沿用 AI SDK v5 的现有行为。如果应用的类型定义基于 AI SDK v6，请传入 `version: 'v6'`。

## 使用示例 {/* #usage-example */}

以下示例在 `/network` 端点设置网络路由，使用 ID 为 `weatherAgent` 的 Agent。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { networkRoute } from '@mastra/ai-sdk'

export const mastra = new Mastra({
  server: {
    apiRoutes: [
      networkRoute({
        path: '/network',
        agent: 'weatherAgent',
      }),
    ],
  },
})
```

也可以根据运行时提供的 `agentId` 路由到对应 Agent。URL `/network/weatherAgent` 将解析到 ID 为 `weatherAgent` 的 Agent。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { networkRoute } from '@mastra/ai-sdk'

export const mastra = new Mastra({
  server: {
    apiRoutes: [
      networkRoute({
        path: '/network/:agentId',
      }),
    ],
  },
})
```

## 附加配置 {/* #additional-configuration */}

可以使用 [`prepareSendMessagesRequest`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/use-chat#transport.default-chat-transport.prepare-send-messages-request) 自定义发送到网络路由的请求，例如向 Agent 传递额外配置：

```typescript
const { error, status, sendMessage, messages, regenerate, stop } = useChat({
  transport: new DefaultChatTransport({
    api: 'http://localhost:4111/network',
    prepareSendMessagesRequest({ messages }) {
      return {
        body: {
          messages,
          // Pass memory config
          memory: {
            thread: 'user-1',
            resource: 'user-1',
          },
        },
      }
    },
  }),
})
```
