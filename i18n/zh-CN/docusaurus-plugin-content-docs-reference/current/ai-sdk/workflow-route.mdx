# workflowRoute()

创建以 AI SDK 格式流式传输 Workflow 执行结果的路由处理程序。该函数注册一个 HTTP `POST` 端点，接收输入数据并执行 Workflow，然后以兼容 AI SDK 的格式将响应流式传输至客户端。请在[自定义 API 路由](/docs/server/custom-api-routes)中使用。

如需与框架无关的处理程序，请使用 [`handleWorkflowStream()`](/reference/ai-sdk/handle-workflow-stream)。

`workflowRoute()` 保持现有的 AI SDK v5 默认行为。如果应用按 AI SDK v6 的类型定义编写，请传入 `version: 'v6'`。

:::tip Workflow 中的 Agent 流式传输

当 Workflow 步骤将 Agent 的流导入 Workflow writer 时（例如 `await response.fullStream.pipeTo(writer)`），即使 Agent 在 Workflow 步骤中运行，其文本片段和工具调用也会实时转发到 UI 流。

详情请参阅 [Workflow 流式传输](/docs/workflows/overview#inspecting-workflow-stream-payloads)。

:::

## 使用示例 {/* #usage-example */}

以下示例在 `/workflow` 端点设置 Workflow 路由，使用 ID 为 `weatherWorkflow` 的 Workflow。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { workflowRoute } from '@mastra/ai-sdk'

export const mastra = new Mastra({
  server: {
    apiRoutes: [
      workflowRoute({
        path: '/workflow',
        workflow: 'weatherWorkflow',
      }),
    ],
  },
})
```

也可以根据 `workflowId` 在运行时选择 Workflow。URL `/workflow/weatherWorkflow` 会对应 ID 为 `weatherWorkflow` 的 Workflow。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { workflowRoute } from '@mastra/ai-sdk'

export const mastra = new Mastra({
  server: {
    apiRoutes: [
      workflowRoute({
        path: '/workflow/:workflowId',
      }),
    ],
  },
})
```

## 附加配置 {/* #additional-configuration */}

可以使用 [`prepareSendMessagesRequest`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/use-chat#transport.default-chat-transport.prepare-send-messages-request) 自定义发送至 Workflow 路由的请求，例如向 Workflow 传入额外配置：

```typescript
const { error, status, sendMessage, messages, regenerate, stop } = useChat({
  transport: new DefaultChatTransport({
    api: 'http://localhost:4111/workflow',
    prepareSendMessagesRequest({ messages }) {
      return {
        body: {
          inputData: {
            city: messages[messages.length - 1].parts[0].text,
          },
          // Or resumeData for resuming a suspended workflow
          resumeData: {
            confirmation: messages[messages.length - 1].parts[0].text,
          },
        },
      }
    },
  }),
})
```
