# Workflow程路线()

创建Workflow程路由处理程序，用于以 AI SDK 格式进行流式Workflow程执行。该函数注册一个 HTTP`POST`端点，它接受输入数据并执行Workflow程，然后以 AI SDK 兼容格式将响应流式传输到客户端。在 a 内使用它[自定义API路由](/docs/server/custom-api-routes).

使用[`handleWorkflowStream()`](/reference/ai-sdk/handle-workflow-stream) if you need a framework-agnostic handler.

`workflowRoute()`保留现有的 AI SDK v5/默认行为。如果您的应用程序是针对 AI SDK v6 输入的，请传递`version: 'v6'`.

:::tip Workflow程中的Agent流式传输

当Workflow步骤将Agent的流传输到Workflow编写器时（例如，`await response.fullStream.pipeTo(writer)`), the agent's text chunks and tool calls are forwarded to the UI stream in real time, even when the agent runs inside workflow steps.

看[Workflow Streaming](/docs/workflows/overview#inspecting-workflow-stream-payloads) for more details.

:::

## 使用示例 {/* #usage-example */}

本例展示了如何设置Workflow程路线`/workflow` endpoint that uses a workflow with the ID `weatherWorkflow`.

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { workflowRoute } from '@mastra/ai-sdk'

export const mastra = new Mastra({
  server: {
    apiRoutes: [
      workflowRoute({
        path: '/workflow',
        workflow: 'weatherWorkflow',
      }),
    ],
  },
})
```

您还可以使用基于运行时定义的Workflow路由`workflowId`. The URL `/workflow/weatherWorkflow` will resolve to the workflow with the ID `weatherWorkflow`.

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { workflowRoute } from '@mastra/ai-sdk'

export const mastra = new Mastra({
  server: {
    apiRoutes: [
      workflowRoute({
        path: '/workflow/:workflowId',
      }),
    ],
  },
})
```

## 附加配置 {/* #additional-configuration */}

您可以使用[`prepareSendMessagesRequest`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/use-chat#transport.default-chat-transport.prepare-send-messages-request) to customize the request sent to the workflow route, for example to pass additional configuration to the workflow:

```typescript
const { error, status, sendMessage, messages, regenerate, stop } = useChat({
  transport: new DefaultChatTransport({
    api: 'http://localhost:4111/workflow',
    prepareSendMessagesRequest({ messages }) {
      return {
        body: {
          inputData: {
            city: messages[messages.length - 1].parts[0].text,
          },
          // Or resumeData for resuming a suspended workflow
          resumeData: {
            confirmation: messages[messages.length - 1].parts[0].text,
          },
        },
      }
    },
  }),
})
```
