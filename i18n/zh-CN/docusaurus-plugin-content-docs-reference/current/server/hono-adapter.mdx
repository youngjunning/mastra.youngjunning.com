# Hono 适配器

`@mastra/hono` 包提供了在 [Hono](https://hono.dev) 中运行 Mastra 的服务器适配器。有关构造函数选项、初始化流程等通用概念，请参阅[服务器适配器](/docs/server/server-adapters)。

## 安装 {/* #installation */}

安装 Hono 适配器和 Hono 框架：

```bash npm2yarn
npm install @mastra/hono@latest hono
```

## 使用示例 {/* #usage-example */}

```typescript title="server.ts"
import { Hono } from 'hono'
import { HonoBindings, HonoVariables, MastraServer } from '@mastra/hono'
import { mastra } from './mastra'

const app = new Hono<{ Bindings: HonoBindings; Variables: HonoVariables }>()
const server = new MastraServer({ app, mastra })

await server.init()

export default app
```

`init()` 不会启动 Mastra 的后台工作进程。若要运行[定时 Workflow](/docs/workflows/scheduled-workflows)、Agent 定时任务或事件监听器，请在服务器开始监听后调用 `await mastra.startWorkers()`。详见[启动后台工作进程](/docs/server/server-adapters#start-background-workers)。

## 添加自定义路由 {/* #adding-custom-routes */}

直接在 Hono 应用中添加路由：

```typescript title="server.ts"
import { Hono } from 'hono'
import { HonoBindings, HonoVariables, MastraServer } from '@mastra/hono'

const app = new Hono<{ Bindings: HonoBindings; Variables: HonoVariables }>()
const server = new MastraServer({ app, mastra })

// Before init - runs before Mastra middleware
app.get('/early-health', c => c.json({ status: 'ok' }))

await server.init()

// After init - has access to Mastra context
app.get('/custom', c => {
  const mastraInstance = c.get('mastra')
  return c.json({ agents: Object.keys(mastraInstance.listAgents()) })
})
```

:::tip

在 `init()` 之前添加的路由运行时没有 Mastra 上下文。若要访问 Mastra 实例和请求上下文，请在 `init()` 之后添加路由。

:::

如果需要由 Mastra 管理身份验证，以及 `requiresAuth` 等路由元数据，建议使用 [`registerApiRoute()`](/reference/server/register-api-route)。对于直接挂载到 `app` 的原生 Hono 路由，请使用 `createAuthMiddleware()`：

```typescript title="server.ts"
import { Hono } from 'hono'
import { createAuthMiddleware, HonoBindings, HonoVariables, MastraServer } from '@mastra/hono'
import { mastra } from './mastra'

const app = new Hono<{ Bindings: HonoBindings; Variables: HonoVariables }>()
const server = new MastraServer({ app, mastra })

await server.init()

app.get('/custom/protected', createAuthMiddleware({ mastra }), c => {
  const user = c.get('requestContext').get('user')
  return c.json({ user })
})

app.get('/custom/public', createAuthMiddleware({ mastra, requiresAuth: false }), c => {
  return c.json({ ok: true })
})
```

## 访问上下文 {/* #accessing-context */}

在 Hono 中间件和路由处理函数中，通过 `c.get()` 访问 Mastra 上下文：

```typescript
app.get('/custom', async c => {
  const mastra = c.get('mastra')
  const requestContext = c.get('requestContext')
  const abortSignal = c.get('abortSignal')

  const agent = mastra.getAgent('myAgent')
  return c.json({ agent: agent.name })
})
```

可用的上下文键：

| 键 | 描述 |
| - | - |
|`mastra` | Mastra 实例 |
| `requestContext` | 请求上下文映射 |
| `abortSignal` | 请求取消信号 |
| `registeredTools` | 向适配器注册的 Tool |
| `taskStore` | A2A 操作的任务存储 |
| `customRouteAuthConfig` | 逐路由的身份验证覆盖配置 |
| `user` | 已验证身份的用户（如果配置了身份验证） |

## 添加中间件 {/* #adding-middleware */}

在 `init()` 之前通过 `app.use()` 添加 Hono 中间件，使其在每个请求中运行。此时 Mastra 上下文尚不可用：

```typescript title="server.ts"
import { Hono } from 'hono'
import { HonoBindings, HonoVariables, MastraServer } from '@mastra/hono'

const app = new Hono<{ Bindings: HonoBindings; Variables: HonoVariables }>()

// Runs on every request, before Mastra context exists
app.use('*', async (c, next) => {
  console.log(`${c.req.method} ${c.req.url}`)
  await next()
})

const server = new MastraServer({ app, mastra })
await server.init()
```

在 `init()` 之后添加的中间件不会在 Mastra 路由上运行。Hono 按注册顺序分派处理函数，因此在路由之后注册的中间件只适用于随后添加的路由。

若要在 Mastra 路由上运行可访问 Mastra 上下文的中间件，请在 Mastra 配置中使用 [`server.middleware`](/docs/server/middleware)。适配器会在 `init()` 期间、上下文建立之后且所有路由注册之前注册这些中间件。对于通过 `requiresAuth: false` 声明为公开的路由，这些处理函数会被跳过，因此不会拦截 Studio 登录路由等端点：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'

export const mastra = new Mastra({
  server: {
    middleware: [
      async (c, next) => {
        c.get('requestContext').set('locale', c.req.header('accept-language') ?? 'en')
        await next()
      },
    ],
  },
})
```
