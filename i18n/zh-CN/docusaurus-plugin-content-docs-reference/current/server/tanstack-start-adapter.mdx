# TanStack Start 适配器

`@mastra/tanstack-start` 包可将 Mastra 挂载到 TanStack Start 应用中。适配器的一般概念请参阅[服务器适配器](/docs/server/server-adapters)。

## 安装 {/* #installation */}

安装 TanStack Start 适配器及其 Hono 对等依赖：

```bash npm2yarn
npm install @mastra/tanstack-start@latest hono
```

## 使用示例 {/* #usage-example */}

在捕获所有路径的 splat 路由中挂载适配器：

```typescript title="src/routes/api/$.ts"
import { createStartRouteHandler } from '@mastra/tanstack-start'
import { createFileRoute } from '@tanstack/react-router'
import { mastra } from '../../mastra'

export const Route = createFileRoute('/api/$')({
  server: {
    handlers: createStartRouteHandler({ mastra }),
  },
})
```

`prefix` 默认是 `/api`，且必须与 splat 路由的挂载路径一致。例如，挂载在 `src/routes/api/mastra/$.ts` 时，应使用 `createStartRouteHandler({ mastra, prefix: '/api/mastra' })`。

## 签名 {/* #signature */}

```typescript
function createStartRouteHandler(options: StartRouteHandlerOptions): StartRouteHandlers
```

## 返回值 {/* #return-value */}

返回 `StartRouteHandlers` 对象，包含 `GET`、`POST`、`PUT`、`DELETE`、`PATCH`、`OPTIONS` 和 `HEAD` 属性。每个属性都是符合以下签名的处理函数：

```typescript
(context: StartHandlerContext) => Response | Promise<Response>
```

上下文类型包含传入的请求和 splat 路由参数：

```typescript
type StartHandlerContext = {
  request: Request
  params: Record<string, string>
}
```

## Serverless 部署与延迟初始化 {/* #serverless-deployments--lazy-initialization */}

适配器会同步导出路由处理函数，并在收到首个请求时创建底层 Hono 应用和 `MastraServer`。初始化后的应用会在同一进程中处理后续请求，因此无需在顶层进行异步初始化即可支持 serverless 运行环境。

它与 [Next.js 适配器](/reference/server/next-adapter)共用基于 Hono 的 `MastraServer` 核心。A2A 端点使用内存任务存储，因此任务状态仅在进程存活期间保留，且不会在不同 serverless 实例之间共享。

## 请求体大小限制 {/* #body-size-limit */}

请求体的默认大小限制为 4.5 MB。超过限制的请求会收到 `{ error: 'Request body too large' }`。

设置 `server.bodySizeLimit` 可调整 `Mastra` 实例的请求体大小限制。

## 中间件 {/* #middleware */}

通过 `server.middleware` 或 `setServerMiddleware()` 配置的中间件会在适配器基于 Hono 的服务器中运行；标记为 `requiresAuth: false` 等框架公开路由除外。参阅[服务器中间件](/docs/server/middleware)。
