# TanStack 启动适配器

这`@mastra/tanstack-start`软件包将 Mastra 安装在 TanStack Start 应用程序中。看[服务器适配器](/docs/server/server-adapters)对于一般适配器概念。

## 安装 {/* #installation */}

安装 TanStack Start 适配器及其 Hono 对等依赖项：

```bash npm2yarn
npm install @mastra/tanstack-start@latest hono
```

## 使用示例 {/* #usage-example */}

将适配器安装在包罗万象的 splat 路线中：

```typescript title="src/routes/api/$.ts"
import { createStartRouteHandler } from '@mastra/tanstack-start'
import { createFileRoute } from '@tanstack/react-router'
import { mastra } from '../../mastra'

export const Route = createFileRoute('/api/$')({
  server: {
    handlers: createStartRouteHandler({ mastra }),
  },
})
```

这`prefix` option defaults to `/api` and must match the splat route's mount path. For example, when mounting at `src/routes/api/mastra/$.ts`, use `createStartRouteHandler({ mastra, prefix: '/api/mastra' })`.

## 签名 {/* #signature */}

```typescript
function createStartRouteHandler(options: StartRouteHandlerOptions): StartRouteHandlers
```

## 返回值 {/* #return-value */}

返回一个`StartRouteHandlers` object with `GET`, `POST`, `PUT`, `DELETE`, `PATCH`, `OPTIONS`， 和`HEAD`特性。每个属性都是具有以下签名的处理程序：

```typescript
(context: StartHandlerContext) => Response | Promise<Response>
```

上下文类型包含传入请求和 splat 路由参数：

```typescript
type StartHandlerContext = {
  request: Request
  params: Record<string, string>
}
```

## 无服务器部署和延迟初始化 {/* #serverless-deployments--lazy-initialization */}

适配器同步导出其路由处理程序，然后创建底层 Hono 应用程序并`MastraServer` when the first request arrives. That initialized app is reused for subsequent requests in the same process, which supports serverless runtimes without top-level asynchronous initialization.

它使用相同的基于Hono的`MastraServer` core as the [Next.js adapter](/reference/server/next-adapter). A2A endpoints use an in-memory task store, so task state lasts only for the lifetime of the process and isn't shared between serverless instances.

## 体型限制 {/* #body-size-limit */}

请求正文的默认限制为 4.5 MB。超过接收限制的请求`{ error: 'Request body too large' }`.

放`server.bodySizeLimit` on the `Mastra` instance to configure the limit.

## 中间件 {/* #middleware */}

中间件配置为`server.middleware` or `setServerMiddleware()` runs through the adapter's Hono-based server, except on framework-public routes such as those marked `requiresAuth: false`. See [Server middleware](/docs/server/middleware).
