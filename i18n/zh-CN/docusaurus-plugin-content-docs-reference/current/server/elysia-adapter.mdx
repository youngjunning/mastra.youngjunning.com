# Elysia 适配器

`@mastra/elysia` 包提供服务器适配器，让 Mastra 可以与 [Elysia](https://elysiajs.com) 一起运行。

:::info

有关适配器的通用概念、构造函数选项和初始化流程，请参阅[服务器适配器](/docs/server/server-adapters)。

:::

## 安装 {/* #installation */}

安装 Elysia 适配器和 Elysia 框架：

```bash npm2yarn
npm install @mastra/elysia@latest elysia
```

## 使用示例 {/* #usage-example */}

```typescript title="server.ts"
import { Elysia } from 'elysia'
import { MastraServer } from '@mastra/elysia'
import { mastra } from './mastra'

const app = new Elysia()
const server = new MastraServer({ app, mastra })

await server.init()

app.listen(3000)

console.log('Server running on http://localhost:3000')
```

`init()` 不会启动 Mastra 的后台工作进程。要运行[定时 Workflow](/docs/workflows/scheduled-workflows)、Agent 定时任务或事件监听器，请在服务器开始监听后调用 `await mastra.startWorkers()`。参阅[启动后台工作进程](/docs/server/server-adapters#start-background-workers)。

## 添加自定义路由 {/* #adding-custom-routes */}

直接在 Elysia 应用中添加路由：

```typescript title="server.ts"
import { Elysia } from 'elysia'
import { MastraServer } from '@mastra/elysia'
import { mastra } from './mastra'

const app = new Elysia()
const server = new MastraServer({ app, mastra })

// Before init - runs before Mastra middleware
app.get('/early-health', () => ({ status: 'ok' }))

await server.init()

// After init - has access to Mastra context
app.get('/custom', ({ mastra }) => {
  return { agents: Object.keys(mastra.listAgents()) }
})
```

:::tip

在 `init()` 之前添加的路由运行时没有 Mastra 上下文。如需访问 Mastra 实例和请求上下文，请在 `init()` 之后添加路由。

:::

如果需要 Mastra 管理的身份验证，以及 `requiresAuth` 等路由元数据，优先使用 [`registerApiRoute()`](/reference/server/register-api-route)。对于直接挂载到 `app` 的原生 Elysia 路由，请使用 `createAuthMiddleware()`：

```typescript title="server.ts"
import { Elysia } from 'elysia'
import { createAuthMiddleware, MastraServer } from '@mastra/elysia'
import { mastra } from './mastra'

const app = new Elysia()
const server = new MastraServer({ app, mastra })

await server.init()

app.get('/custom/protected', async ctx => {
  const authResponse = await createAuthMiddleware({ mastra })(ctx)
  if (authResponse) return authResponse

  const user = ctx.requestContext.get('user')
  return { user }
})

app.get('/custom/public', async ctx => {
  const authResponse = await createAuthMiddleware({ mastra, requiresAuth: false })(ctx)
  if (authResponse) return authResponse

  return { ok: true }
})
```

当身份验证 Provider 刷新过期会话时，`createAuthMiddleware()` 会将刷新后的会话响应头（如 `Set-Cookie`）附加到响应中，包括错误响应。`MastraServer` 会在 `init()` 期间注册 `applyAuthRefreshHeaders` 钩子，因此在 `init()` 之后添加的路由会同时返回这些响应头和路由自身设置的 Cookie。

如果不通过 `MastraServer` 使用 `createAuthMiddleware()`，请在定义路由之前自行注册该钩子：

```typescript title="server.ts"
import { Elysia } from 'elysia'
import { applyAuthRefreshHeaders, createAuthMiddleware } from '@mastra/elysia'
import { mastra } from './mastra'

const app = new Elysia()
  .onAfterHandle({ as: 'global' }, applyAuthRefreshHeaders)
  .onError({ as: 'global' }, applyAuthRefreshHeaders)

app.get('/custom/protected', () => ({ ok: true }), {
  beforeHandle: createAuthMiddleware({ mastra }),
})
```

## 访问上下文 {/* #accessing-context */}

对于在 `init()` 之后注册的 Elysia 处理函数，可从处理函数的上下文中访问 Mastra 上下文：

```typescript title="server.ts"
app.get('/custom', ({ mastra, requestContext, abortSignal }) => {
  const agent = mastra.getAgent('myAgent')
  const user = requestContext.get('user')

  return { agent: agent.name, user, aborted: abortSignal.aborted }
})
```

可用的上下文键：

| 键 | 描述 |
| - | - |
| `mastra` | Mastra 实例 |
| `requestContext` | 请求上下文映射 |
| `abortSignal` | 请求取消信号 |
| `registeredTools` | 可用的 Tool |
| `taskStore` | A2A 操作的任务存储 |
| `customRouteAuthConfig` | 针对各路由的身份验证覆盖设置 |
| `user` | 配置身份验证后，`requestContext` 中已通过身份验证的用户 |

## OpenAPI 辅助函数 {/* #openapi-helpers */}

如需将 Mastra 生成的 OpenAPI 文档传给 `@elysiajs/openapi` 等 Elysia 工具，请使用 `getMastraOpenAPIDoc()`：

```typescript title="server.ts"
import { openapi } from '@elysiajs/openapi'
import { Elysia } from 'elysia'
import { getMastraOpenAPIDoc, MastraServer } from '@mastra/elysia'
import { mastra } from './mastra'

const app = new Elysia()
const server = new MastraServer({ app, mastra })

await server.init()

app.use(
  openapi({
    documentation: getMastraOpenAPIDoc(server),
  }),
)
```

如需为同一服务器实例重新生成已缓存的文档，请调用 `clearMastraOpenAPICache(server)`。

## MCP 支持 {/* #mcp-support */}

Elysia 适配器通过 Streamable HTTP 在 `/api/mcp/:serverId/mcp` 路径提供每个已注册的 MCP 服务器。

## 手动初始化 {/* #manual-initialization */}

如需自定义中间件顺序，请分别调用各个方法，而不要调用 `init()`。详情参阅[手动初始化](/docs/server/server-adapters#manual-initialization)。
