# 主机服务器

这`MastraServer`抽象类是所有服务器适配器的基础。扩展此类来为 Hono 或 Express 以外的框架创建适配器。

## 进口 {/* #import */}

```typescript
import { MastraServer } from '@mastra/server/server-adapter'
```

## 类型参数 {/* #type-parameters */}

```typescript
MastraServer<TApp, TRequest, TResponse>
```

|参数|描述 |
| - | - |
|`TApp` | Framework app type (e.g., `Hono`, `Application`) |
| `TRequest`|框架请求类型 |
|`TResponse`|框架响应/上下文类型 |

## 构造函数 {/* #constructor */}


## 抽象方法 {/* #abstract-methods */}

这些方法必须由适配器实现：

### `registerContextMiddleware()` {/* #registercontextmiddleware */}

将 Mastra 上下文附加到每个请求。

```typescript oxfmt:false
abstract registerContextMiddleware(): void
```

**要附加的上下文：**

* `mastra`- 马斯特拉实例
* `requestContext`- 请求范围的上下文
* `tools`- 可用Tool
* `abortSignal`- 请求取消信号

### `registerAuthMiddleware()` {/* #registerauthmiddleware */}

在初始化期间运行适配器身份验证挂钩。当每个路由强制执行身份验证时，官方适配器可能会将其实现为无操作。

```typescript oxfmt:false
abstract registerAuthMiddleware(): void
```

### `registerRoute()` {/* #registerroute */}

向框架注册单个路由。

```typescript oxfmt:false
abstract registerRoute(
  app: TApp,
  route: ServerRoute,
  options: { prefix?: string }
): Promise<void>
```

### `getParams()` {/* #getparams */}

从请求中提取参数。

```typescript oxfmt:false
abstract getParams(
  route: ServerRoute,
  request: TRequest
): Promise<{
  urlParams: Record<string, string>;
  queryParams: Record<string, string | string[]>;
  body: unknown;
}>
```

### `sendResponse()` {/* #sendresponse */}

根据路由类型发送响应。

```typescript oxfmt:false
abstract sendResponse(
  route: ServerRoute,
  response: TResponse,
  result: unknown
): Promise<unknown>
```

### `stream()` {/* #stream */}

处理流响应。

```typescript oxfmt:false
abstract stream(
  route: ServerRoute,
  response: TResponse,
  result: unknown
): Promise<unknown>
```

## 实例方法 {/* #instance-methods */}

### `init()` {/* #init */}

通过注册所有中间件和路由来初始化服务器。

```typescript oxfmt:false
async init(): Promise<void>
```

按顺序调用：

1. `registerContextMiddleware()`
2. `registerAuthMiddleware()`
3. `registerRoutes()`

### `registerRoutes()` {/* #registerroutes */}

注册所有 Mastra 路线。

```typescript oxfmt:false
async registerRoutes(): Promise<void>
```

### `getApp()` {/* #getapp */}

获取框架应用程序实例。

```typescript oxfmt:false
getApp<T = TApp>(): T
```

### `parsePathParams()` {/* #parsepathparams */}

使用路由的 Zod 模式验证路径参数。

```typescript oxfmt:false

  route: ServerRoute,
  params: Record<string, string>
```

### `parseQueryParams()` {/* #parsequeryparams */}

使用路由的 Zod 架构验证查询参数。

```typescript oxfmt:false
async parseQueryParams(
  route: ServerRoute,
  params: Record<string, string>

```

使用路由的 Zod 架构验证请求正文。

## 例子 {/* #example */}

```typescript
import { MastraServer, ServerRoute } from '@mastra/server/server-adapter'
import type { Mastra } from '@mastra/core'

export class MyServer extends MastraServer<MyApp, MyRequest, MyResponse> {
  registerContextMiddleware(): void {
    this.app.use('*', (req, res, next) => {
      res.locals.mastra = this.mastra
      next()
    })
  }

  registerAuthMiddleware(): void {
    const auth = this.mastra.getServer()?.auth
    if (!auth) return
    // Register global auth middleware, or leave this empty and
    // enforce auth when routes are registered.
  }

  async registerRoute(app, route, { prefix }) {
    // Implement route registration
  }

  async getParams(route, request) {
    return {
      urlParams: request.params,
      queryParams: request.query,
      body: request.body,
    }
  }

  async sendResponse(route, response, result) {
    return response.json(result)
  }

  async stream(route, response, result) {
    // Implement streaming
  }
}
```
