# MastraServer

`MastraServer` 抽象类是所有服务器适配器的基类。继承此类可为 Hono 和 Express 以外的框架创建适配器。

## 导入 {/* #import */}

```typescript
import { MastraServer } from '@mastra/server/server-adapter'
```

## 类型参数 {/* #type-parameters */}

```typescript
MastraServer<TApp, TRequest, TResponse>
```

|参数|说明 |
| - | - |
|`TApp` | 框架应用类型（例如 `Hono`、`Application`） |
| `TRequest`|框架请求类型 |
|`TResponse`|框架响应或上下文类型 |

## 构造函数 {/* #constructor */}

```typescript oxfmt:false
constructor(options: MastraServerOptions<TApp>)
```

## 抽象方法 {/* #abstract-methods */}

这些方法必须由适配器实现：

### `registerContextMiddleware()` {/* #registercontextmiddleware */}

将 Mastra 上下文附加到每个请求。

```typescript oxfmt:false
abstract registerContextMiddleware(): void
```

**要附加的上下文：**

* `mastra` - Mastra 实例
* `requestContext` - 请求级上下文
* `tools` - 可用的 Tool
* `abortSignal` - 请求取消信号

### `registerAuthMiddleware()` {/* #registerauthmiddleware */}

在初始化期间运行适配器的身份验证钩子。如果身份验证由各路由执行，官方适配器可以将此方法实现为空操作。

```typescript oxfmt:false
abstract registerAuthMiddleware(): void
```

### `registerRoute()` {/* #registerroute */}

向框架注册单个路由。

```typescript oxfmt:false
abstract registerRoute(
  app: TApp,
  route: ServerRoute,
  options: { prefix?: string }
): Promise<void>
```

### `getParams()` {/* #getparams */}

从请求中提取参数。

```typescript oxfmt:false
abstract getParams(
  route: ServerRoute,
  request: TRequest
): Promise<{
  urlParams: Record<string, string>;
  queryParams: Record<string, string | string[]>;
  body: unknown;
}>
```

### `sendResponse()` {/* #sendresponse */}

根据路由类型发送响应。

```typescript oxfmt:false
abstract sendResponse(
  route: ServerRoute,
  response: TResponse,
  result: unknown
): Promise<unknown>
```

### `stream()` {/* #stream */}

处理流响应。

```typescript oxfmt:false
abstract stream(
  route: ServerRoute,
  response: TResponse,
  result: unknown
): Promise<unknown>
```

## 实例方法 {/* #instance-methods */}

### `init()` {/* #init */}

通过注册所有中间件和路由来初始化服务器。

```typescript oxfmt:false
async init(): Promise<void>
```

按顺序调用：

1. `registerContextMiddleware()`
2. `registerAuthMiddleware()`
3. `registerRoutes()`

### `registerRoutes()` {/* #registerroutes */}

注册所有 Mastra 路由。

```typescript oxfmt:false
async registerRoutes(): Promise<void>
```

### `getApp()` {/* #getapp */}

获取框架应用程序实例。

```typescript oxfmt:false
getApp<T = TApp>(): T
```

### `parsePathParams()` {/* #parsepathparams */}

使用路由的 Zod schema 验证路径参数。

```typescript oxfmt:false
async parsePathParams(
  route: ServerRoute,
  params: Record<string, string>
): Promise<Record<string, unknown>>
```

### `parseQueryParams()` {/* #parsequeryparams */}

使用路由的 Zod schema 验证查询参数。

```typescript oxfmt:false
async parseQueryParams(
  route: ServerRoute,
  params: Record<string, string>
): Promise<Record<string, unknown>>
```

### `parseBody()` {/* #parsebody */}

使用路由的 Zod schema 验证请求体。

```typescript oxfmt:false
async parseBody(
  route: ServerRoute,
  body: unknown
): Promise<unknown>
```

### `registerOpenAPIRoute()` {/* #registeropenapiroute */}

注册提供 OpenAPI 规范的端点。

```typescript oxfmt:false
async registerOpenAPIRoute(
```

### MCPOptions {/* #mcpoptions */}

```typescript
interface MCPOptions {
  serverless?: boolean
  sessionIdGenerator?: () => string
}
```

|属性 |说明 |
| - | - |
|`serverless` | 设为 `true` 时，MCP 以无状态模式运行，不管理会话。适用于 Cloudflare Workers 或 Vercel Edge 等无服务器环境。 |
| `sessionIdGenerator` | 用于生成会话 ID 的自定义函数。 |

```typescript
  registerContextMiddleware(): void {
    this.app.use('*', (req, res, next) => {
      res.locals.mastra = this.mastra
      next()
    })
  }

  registerAuthMiddleware(): void {
    const auth = this.mastra.getServer()?.auth
    if (!auth) return
```
