# Fastify 适配器

`@mastra/fastify` 包提供服务器适配器，可让 Mastra 与 [Fastify](https://fastify.dev) 一起运行。有关构造函数选项、初始化流程等适配器通用概念，请参阅[服务器适配器](/docs/server/server-adapters)。

## 安装 {/* #installation */}

安装 Fastify 适配器和 Fastify 框架：

```bash npm2yarn
npm install @mastra/fastify@latest fastify
```

## 使用示例 {/* #usage-example */}

```typescript title="server.ts"
import Fastify from 'fastify'
import { MastraServer } from '@mastra/fastify'
import { mastra } from './mastra'

const app = Fastify({ logger: true })
const server = new MastraServer({ app, mastra })

await server.init()

app.listen({ port: 3000 }, (err, address) => {
  if (err) {
    console.error(err)
    process.exit(1)
  }
  console.log(`Server running on ${address}`)
})
```

`init()` 不会启动 Mastra 的后台工作进程。要运行[定时 Workflow](/docs/workflows/scheduled-workflows)、Agent 定时任务或事件监听器，请在服务器开始监听后调用 `await mastra.startWorkers()`。详见[启动后台工作进程](/docs/server/server-adapters#start-background-workers)。

## 保护原始路由 {/* #protecting-raw-routes */}

如果需要由 Mastra 管理身份验证以及 `requiresAuth` 等路由元数据，优先使用 [`registerApiRoute()`](/reference/server/register-api-route)。对于直接注册到应用上的原生 Fastify 路由，请使用 `createAuthMiddleware()`：

```typescript title="server.ts"
import Fastify from 'fastify'
import { createAuthMiddleware, MastraServer } from '@mastra/fastify'
import { mastra } from './mastra'

const app = Fastify()
const server = new MastraServer({ app, mastra })

await server.init()

app.get('/custom/protected', { preHandler: createAuthMiddleware({ mastra }) }, async request => {
  const user = request.requestContext.get('user')
  return { user }
})

app.get(
  '/custom/public',
  { preHandler: createAuthMiddleware({ mastra, requiresAuth: false }) },
  async () => {
    return { ok: true }
  },
)
```
