# Fastify 适配器

这`@mastra/fastify`软件包提供了一个服务器适配器，用于运行 Mastra[快速化](https://fastify.dev)。有关一般适配器概念（构造函数选项、初始化流程等），请参阅[服务器适配器](/docs/server/server-adapters).

## 安装 {/* #installation */}

安装 Fastify 适配器和 Fastify 框架：

```bash npm2yarn
npm install @mastra/fastify@latest fastify
```

## 使用示例 {/* #usage-example */}

```typescript title="server.ts"
import Fastify from 'fastify'
import { MastraServer } from '@mastra/fastify'
import { mastra } from './mastra'

const app = Fastify({ logger: true })
const server = new MastraServer({ app, mastra })

await server.init()

app.listen({ port: 3000 }, (err, address) => {
  if (err) {
    console.error(err)
    process.exit(1)
  }
  console.log(`Server running on ${address}`)
})
```

`init()`不会启动 Mastra 的后台工作人员。运行[scheduled workflows](/docs/workflows/scheduled-workflows), agent schedules, or event listeners, call `await mastra.startWorkers()` after the server starts listening. See [Start background workers](/docs/server/server-adapters#start-background-workers).

## 保护原始路由 {/* #protecting-raw-routes */}

当您需要 Mastra 管理的身份验证和路由元数据时，例如`requiresAuth`, prefer [`registerApiRoute()`](/reference/server/register-api-route). For raw Fastify routes mounted directly on the app, use `createAuthMiddleware()`:

```typescript title="server.ts"
import Fastify from 'fastify'
import { createAuthMiddleware, MastraServer } from '@mastra/fastify'
import { mastra } from './mastra'

const app = Fastify()
const server = new MastraServer({ app, mastra })

await server.init()

app.get('/custom/protected', { preHandler: createAuthMiddleware({ mastra }) }, async request => {
  const user = request.requestContext.get('user')
  return { user }
})

app.get(
  '/custom/public',
  { preHandler: createAuthMiddleware({ mastra, requiresAuth: false }) },
  async () => {
    return { ok: true }
  },
)
```

## 手动初始化 {/* #manual-initialization */}

对于自定义中间件排序，请单独调用每个方法，而不是`init()`. See [manual initialization](/docs/server/server-adapters#manual-initialization) for details.
