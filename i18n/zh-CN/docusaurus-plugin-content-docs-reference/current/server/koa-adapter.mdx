# Koa 适配器

`@mastra/koa` 包提供了在 [Koa](https://koajs.com) 中运行 Mastra 的服务器适配器。有关构造函数选项、初始化流程等适配器通用概念，请参阅[服务器适配器](/docs/server/server-adapters)。

## 安装 {/* #installation */}

安装 Koa 适配器和 Koa 框架：

```bash npm2yarn
npm install @mastra/koa@latest koa koa-bodyparser
```

## 使用示例 {/* #usage-example */}

```typescript title="server.ts"
import Koa from 'koa'
import bodyParser from 'koa-bodyparser'
import { MastraServer } from '@mastra/koa'
import { mastra } from './mastra'

const app = new Koa()
app.use(bodyParser())

const server = new MastraServer({ app, mastra })

await server.init()

app.listen(3000, () => {
  console.log('Server running on http://localhost:3000')
})
```

`init()` 不会启动 Mastra 的后台工作进程。要运行[定时 Workflow](/docs/workflows/scheduled-workflows)、Agent 定时任务或事件监听器，请在服务器开始监听后调用 `await mastra.startWorkers()`。详情请参阅[启动后台工作进程](/docs/server/server-adapters#start-background-workers)。

## 错误处理 {/* #error-handling */}

Koa 适配器遵循 Koa 的标准错误处理方式：路由处理器抛出的错误会沿 Koa 中间件链向上传播。可以使用常规的 Koa 错误处理中间件：

```typescript title="server.ts"
const app = new Koa()
app.use(bodyParser())

// Your error middleware catches errors from Mastra route handlers
app.use(async (ctx, next) => {
  try {
    await next()
  } catch (err) {
    ctx.status = err.status || 500
    ctx.body = { error: err.message }
    // Log, report to Sentry, etc.
  }
})

const server = new MastraServer({ app, mastra })
await server.init()
```

适配器也支持 [`server.onError`](/reference/configuration#serveronerror) 钩子。配置后，该钩子会在错误传播到中间件前调用，并直接使用它返回的响应：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'

const mastra = new Mastra({
  server: {
    onError: (err, c) => {
      console.error('Unhandled error:', err)
      return c.json({ error: err.message }, 500)
    },
  },
})
```

调用 `init()` 时，还会注册一个全局错误处理中间件作为兜底。按照 Koa 的标准约定，到达该中间件的错误会通过 `ctx.app.emit('error', err, ctx)` 发出。对于路由处理器已记录的客户端错误（4xx）和 `501` 错误，只有注册了自己的 `error` 监听器时，才会将其作为 `error` 事件发出；否则只会通知 `errorMonitor` 监听器。

## 保护原始路由 {/* #protecting-raw-routes */}

如果需要 Mastra 管理的身份验证以及 `requiresAuth` 等路由元数据，优先使用 [`registerApiRoute()`](/reference/server/register-api-route)。对于直接挂载到应用上的原生 Koa 路由，请使用 `createAuthMiddleware()`：

```typescript title="server.ts"
import Koa from 'koa'
import { createAuthMiddleware, MastraServer } from '@mastra/koa'
import { mastra } from './mastra'

const app = new Koa()
const server = new MastraServer({ app, mastra })

await server.init()

app.use(createAuthMiddleware({ mastra }))
app.use(async ctx => {
  if (ctx.path !== '/custom/protected') return

  const user = ctx.state.requestContext.get('user')
  ctx.body = { user }
})
```

## 手动初始化 {/* #manual-initialization */}

如果需要自定义中间件顺序，请分别调用各个方法，而不是使用 `init()`。详情请参阅[手动初始化](/docs/server/server-adapters#manual-initialization)。
