# AcpAgent 类

这`AcpAgent`类将Agent客户端协议 (ACP) 兼容的编码Agent包装为 Mastra 子Agent。当父 Mastra Agent应委托存储库检查和代码编辑时使用它。它还可以将其他 ACP 支持的任务委托给子Agent。

如果您希望父Agent将 ACP Agent作为Tool调用，请使用[`createACPTool()`](/reference/acp/create-acp-tool).

## 使用示例 {/* #usage-example */}

在父Agent中注册与 ACP 兼容的编码Agent`agents` map:

```typescript title="src/mastra/agents/code-supervisor.ts"
import { AcpAgent } from '@mastra/acp'
import { Agent } from '@mastra/core/agent'

const codeAgent = new AcpAgent({
  id: 'code-agent',
  name: 'Code Agent',
  description: 'An ACP-compatible coding agent that can inspect and edit files',
  command: 'acp-agent',
  args: ['--stdio'],
  cwd: process.cwd(),
})

export const codeSupervisor = new Agent({
  id: 'code-supervisor',
  name: 'Code Supervisor',
  instructions: 'Delegate code editing tasks to the code-agent subagent.',
  model: '__GATEWAY_OPENAI_MODEL__',
  agents: {
    codeAgent,
  },
})
```

对于 Claude Code，ACP 支持由`@agentclientprotocol/claude-agent-acp` bridge package. Configure the ACP agent command to run the bridge, then select a Claude model after session creation:

```typescript title="src/mastra/agents/claude-code-agent.ts"
import { AcpAgent } from '@mastra/acp'

export const claudeCodeAgent = new AcpAgent({
  id: 'claude-code-agent',
  name: 'Claude Code Agent',
  description: 'Use Claude Code through ACP.',
  command: 'npx',
  args: ['@agentclientprotocol/claude-agent-acp'],
  cwd: process.cwd(),
  model: '__AI_SDK_ANTHROPIC_MODEL_SONNET__',
})
```

## 方法 {/* #methods */}

### 一代 {/* #generation */}

#### `generate(messages, options?)` {/* #generatemessages-options */}

将提示发送到 ACP Agent，并在返回 Mastra 子Agent生成结果之前缓冲响应中的文本块。

```typescript
const result = await codeAgent.generate('Inspect the repository and summarize the test setup')

console.log(result.text)
```

#### `stream(messages, options?)` {/* #streammessages-options */}

将提示发送到 ACP Agent并返回 Mastra 子Agent流结果。 ACP`agent_message_chunk` updates are emitted as Mastra `text-delta` chunks.

```typescript
const result = await codeAgent.stream('Refactor the selected module and explain each change')

for await (const chunk of result.fullStream) {
  if (chunk.type === 'text-delta') {
    process.stdout.write(chunk.payload.text)
  }
}
```

`resumeGenerate()`和`resumeStream()` aren't supported and throw an error when called.

### 模型管理 {/* #model-management */}

#### `getAvailableModels()` {/* #getavailablemodels */}

如果需要，启动 ACP 进程并返回 ACP 会话通告的模型列表。

```typescript
const models = await codeAgent.getAvailableModels()
// [{ modelId: '__AI_SDK_ANTHROPIC_MODEL_SONNET__', name: 'Claude Sonnet' }, ...]
```

#### `setModel(modelId)` {/* #setmodelmodelid */}

为活动 ACP 会话选择模型。如果 ACP Agent通告可用模型，则模型 ID 必须与其中之一匹配。

```typescript
await codeAgent.setModel('__AI_SDK_ANTHROPIC_MODEL_SONNET__')
```

## 会话生命周期 {/* #session-lifecycle */}

`AcpAgent`启动配置的`command` on first use and initializes the ACP client. It then creates an ACP session. By default, `persistSession` is `true`, so the process and session stay alive across `generate()`, `stream()`, `getAvailableModels()`, and `setModel()` calls.

放`persistSession: false` when each prompt should run in a fresh ACP process:

```typescript title="src/mastra/agents/code-agent.ts"
import { AcpAgent } from '@mastra/acp'

export const codeAgent = new AcpAgent({
  id: 'code-agent',
  description: 'Run one isolated ACP coding task',
  command: 'acp-agent',
  args: ['--stdio'],
  cwd: process.cwd(),
  persistSession: false,
})
```

和`persistSession: false`, `@mastra/acp` stops the ACP process after each prompt completes.

## 工作空间集成 {/* #workspace-integration */}

ACP文件操作通过Mastra的`Workspace` abstraction. If you don't pass `workspace`, `@mastra/acp` creates a `Workspace` backed by `LocalFilesystem` and uses `cwd` or `process.cwd()` as the filesystem base path.

通过定制`Workspace` when the ACP agent should read and write through a specific filesystem implementation:

```typescript title="src/mastra/agents/code-agent.ts"
import { AcpAgent } from '@mastra/acp'
import { LocalFilesystem, Workspace } from '@mastra/core/workspace'

const workspace = new Workspace({
  filesystem: new LocalFilesystem({
    basePath: process.cwd(),
  }),
})

export const codeAgent = new AcpAgent({
  id: 'code-agent',
  description: 'Run coding tasks in a controlled workspace',
  command: 'acp-agent',
  args: ['--stdio'],
  workspace,
})
```

使用`cwd` and `workspace` together when the ACP process should start in one directory but file operations should use an explicitly configured workspace root.

## 权限处理 {/* #permission-handling */}

ACP Agent可能会要求客户在继续之前选择一个权限选项。默认情况下，`AcpAgent` selects the first option returned by the ACP agent, or cancels when no option is available.

经过`onPermissionRequest` to inspect the request and return your own permission response:

```typescript title="src/mastra/agents/code-agent.ts"
import { AcpAgent } from '@mastra/acp'

export const codeAgent = new AcpAgent({
  id: 'code-agent',
  description: 'Use an ACP-compatible coding agent',
  command: 'acp-agent',
  args: ['--stdio'],
  async onPermissionRequest(request) {
    const allowOption = request.options.find(option => option.name === 'Allow')

    if (!allowOption) {
      return { outcome: { outcome: 'cancelled' } }
    }

    return {
      outcome: {
        outcome: 'selected',
        optionId: allowOption.optionId,
      },
    }
  },
})
```

使用此回调来强制执行本地策略或检查权限标题。它还可以将决策路由到您自己的批准流程。
