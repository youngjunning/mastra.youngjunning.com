# 创建ACPTool()

这`createACPTool()`函数创建一个 Mastra Tool，发送一个`task`字符串到与Agent客户端协议 (ACP) 兼容的编码Agent，并返回最终的 ACP 响应：`output`。当父Agent应决定何时调用 ACP Agent作为Tool时，请使用它。

如果您想将 ACP Agent注册为 Mastra 子Agent，请使用[`AcpAgent` class](/reference/acp/acp-agent).

## 使用示例 {/* #usage-example */}

创建代码编辑Tool并将其注册到父Agent上：

```typescript title="src/mastra/agents/code-supervisor.ts"
import { createACPTool } from '@mastra/acp'
import { Agent } from '@mastra/core/agent'

const codeAgentTool = createACPTool({
  id: 'code-agent',
  description: 'Use an ACP-compatible coding agent to inspect and edit code',
  command: 'acp-agent',
  args: ['--stdio'],
  cwd: process.cwd(),
})

export const codeSupervisor = new Agent({
  id: 'code-supervisor',
  name: 'Code Supervisor',
  instructions: 'Use the code-agent tool when a task requires repository inspection or code edits.',
  model: '__GATEWAY_OPENAI_MODEL__',
  tools: {
    codeAgentTool,
  },
})
```

## 会话生命周期 {/* #session-lifecycle */}

每个Tool执行都会创建一个 ACP 连接并启动配置的`command`. It initializes the ACP client and creates an ACP session before sending the `task` with ACP `session/prompt`.

默认情况下，`persistSession` is `true` for the ACP connection created during tool execution. Set `persistSession: false` when the ACP process should stop as soon as that prompt completes.

使用[`AcpAgent`](/reference/acp/acp-agent#session-lifecycle) when you need a reusable ACP subagent instance with explicit session lifecycle control across calls.

## 权限处理 {/* #permission-handling */}

ACP Agent可能会要求客户在继续之前选择一个权限选项。默认情况下，`@mastra/acp` selects the first option returned by the ACP agent, or cancels when no option is available.

经过`onPermissionRequest` to inspect the request and return your own permission response:

```typescript title="src/mastra/agents/code-agent.ts"
import { createACPTool } from '@mastra/acp'

export const codeAgentTool = createACPTool({
  id: 'code-agent',
  description: 'Use an ACP-compatible coding agent',
  command: 'acp-agent',
  args: ['--stdio'],
  async onPermissionRequest(request) {
    const allowOption = request.options.find(option => option.name === 'Allow')

    if (!allowOption) {
      return { outcome: { outcome: 'cancelled' } }
    }

    return {
      outcome: {
        outcome: 'selected',
        optionId: allowOption.optionId,
      },
    }
  },
})
```

使用此回调来强制执行本地策略或检查权限标题。它还可以将决策路由到您自己的批准流程。

## 扩展方法 {/* #extension-methods */}

某些 ACP Agent在标准 ACP 请求集之外调用客户端上的自定义扩展方法。默认客户端会拒绝未知方法，并显示“未找到方法”错误，这可能会中止Agent的轮次。

经过`createClient` to extend or replace the default client. The callback receives the default client and returns the client used for the connection:

```typescript title="src/mastra/agents/code-agent.ts"
import { createACPTool } from '@mastra/acp'

export const codeAgentTool = createACPTool({
  id: 'code-agent',
  description: 'Use an ACP-compatible coding agent',
  command: 'acp-agent',
  args: ['--stdio'],
  createClient: defaultClient =>
    Object.assign(defaultClient, {
      async extMethod(method: string, params: Record<string, unknown>) {
        return {}
      },
      async extNotification(method: string, params: Record<string, unknown>) {},
    }),
})
```

返回完全定制的`Client` implementation when you need to change the standard handlers as well. The `Client` type is re-exported from `@mastra/acp`.
