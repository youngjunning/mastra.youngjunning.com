# createACPTool()

`createACPTool()` 创建一个 Mastra Tool，将 `task` 字符串发送给兼容 Agent Client Protocol（ACP）的编程 Agent，并将最终 ACP 响应作为 `output` 返回。适用于由父 Agent 决定何时将 ACP Agent 作为 Tool 调用的场景。

如果想将 ACP Agent 注册为 Mastra 子 Agent，请使用 [`AcpAgent` 类](/reference/acp/acp-agent)。

## 使用示例 {/* #usage-example */}

创建代码编辑 Tool，并将其注册到父 Agent：

```typescript title="src/mastra/agents/code-supervisor.ts"
import { createACPTool } from '@mastra/acp'
import { Agent } from '@mastra/core/agent'

const codeAgentTool = createACPTool({
  id: 'code-agent',
  description: 'Use an ACP-compatible coding agent to inspect and edit code',
  command: 'acp-agent',
  args: ['--stdio'],
  cwd: process.cwd(),
})

export const codeSupervisor = new Agent({
  id: 'code-supervisor',
  name: 'Code Supervisor',
  instructions: 'Use the code-agent tool when a task requires repository inspection or code edits.',
  model: '__GATEWAY_OPENAI_MODEL__',
  tools: {
    codeAgentTool,
  },
})
```

## 会话生命周期 {/* #session-lifecycle */}

每次执行 Tool 都会创建 ACP 连接并启动配置的 `command`。它先初始化 ACP 客户端并创建 ACP 会话，然后发送 `task`，使用 ACP `session/prompt` 方法。

默认情况下，执行 Tool 时创建的 ACP 连接会将 `persistSession` 设为 `true`。如果希望每次提示完成后立即停止 ACP 进程，请设置 `persistSession: false`。

如果需要可跨多次调用复用，并能显式控制会话生命周期的 ACP 子 Agent 实例，请使用 [`AcpAgent`](/reference/acp/acp-agent#session-lifecycle)。

## 权限处理 {/* #permission-handling */}

ACP Agent 在继续前可能要求客户端选择一个权限选项。默认情况下，`@mastra/acp` 会选择 ACP Agent 返回的第一个选项，没有可用选项时则取消。

传入 `onPermissionRequest`，检查请求并返回自定义权限响应：

```typescript title="src/mastra/agents/code-agent.ts"
import { createACPTool } from '@mastra/acp'

export const codeAgentTool = createACPTool({
  id: 'code-agent',
  description: 'Use an ACP-compatible coding agent',
  command: 'acp-agent',
  args: ['--stdio'],
  async onPermissionRequest(request) {
    const allowOption = request.options.find(option => option.name === 'Allow')

    if (!allowOption) {
      return { outcome: { outcome: 'cancelled' } }
    }

    return {
      outcome: {
        outcome: 'selected',
        optionId: allowOption.optionId,
      },
    }
  },
})
```

使用此回调执行本地策略或检查权限请求标题。它也可以将决定交给自有审批流程。

## 扩展方法 {/* #extension-methods */}

某些 ACP Agent 会在标准 ACP 请求集之外调用客户端的自定义扩展方法。默认客户端会以“Method not found”错误拒绝未知方法，可能导致 Agent 的当前轮次中止。

传入 `createClient` 可扩展或替换默认客户端。此回调接收默认客户端，并返回连接要使用的客户端：

```typescript title="src/mastra/agents/code-agent.ts"
import { createACPTool } from '@mastra/acp'

export const codeAgentTool = createACPTool({
  id: 'code-agent',
  description: 'Use an ACP-compatible coding agent',
  command: 'acp-agent',
  args: ['--stdio'],
  createClient: defaultClient =>
    Object.assign(defaultClient, {
      async extMethod(method: string, params: Record<string, unknown>) {
        return {}
      },
      async extNotification(method: string, params: Record<string, unknown>) {},
    }),
})
```

如果还需修改标准处理程序，请返回完全自定义的 `Client` 实现。`Client` 类型由 `@mastra/acp` 重新导出。
