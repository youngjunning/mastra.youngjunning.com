# Agent浏览器类

这`AgentBrowser`类提供确定性浏览器自动化，使用[Agent浏览器](https://github.com/vercel-labs/agent-browser)图书馆。它使用可访问性树快照和元素引用（例如，`@e5`）以实现精确、可重复的交互。

使用`AgentBrowser` when you need reliable, deterministic browser automation. For AI-powered interactions using natural language, see [`StagehandBrowser`](/reference/browser/stagehand-browser).

## 使用示例 {/* #usage-example */}

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { AgentBrowser } from '@mastra/agent-browser'

const browser = new AgentBrowser({
  headless: true,
  viewport: { width: 1280, height: 720 },
  scope: 'thread',
})

export const browserAgent = new Agent({
  id: 'browser-agent',
  name: 'Browser Agent',
  instructions: `You can browse the web. Use browser_snapshot to see the page structure,
then interact with elements using their refs (e.g., @e5).`,
  model: '__GATEWAY_OPENAI_MODEL__',
  browser,
})
```

## Tool {/* #tools */}

`AgentBrowser`提供 16 个用于浏览器自动化的确定性Tool。所有与元素交互的Tool都使用可访问性树快照中的引用。

什么时候`recording` is configured, `AgentBrowser` also adds the Beta `browser_record` and `browser_record_caption` tools. See [Browser recording (Beta)](/docs/browser#record-browser-sessions).

### 核心Tool {/* #core-tools */}

|Tool|描述 |
| - | - |
|`browser_goto` | Navigate to a URL |
| `browser_snapshot` | Get accessibility tree snapshot with element refs |
| `browser_click` | Click an element by ref |
| `browser_type` | Type text into an element |
| `browser_press` | Press keyboard keys |
| `browser_select` | Select option from dropdown |
| `browser_scroll` | Scroll the page or element |
| `browser_screenshot`|以 PNG 格式截取屏幕截图（默认为视口；设置`fullPage: true`为整页）|
|`browser_close`|关闭浏览器 |

### 扩展Tool {/* #extended-tools */}

|Tool|描述 |
| - | - |
|`browser_hover` | Hover over an element |
| `browser_back` | Go back in browser history |
| `browser_dialog` | Handle browser dialogs (alert, confirm, prompt) |
| `browser_wait` | Wait for element state changes |
| `browser_tabs` | Manage browser tabs (list, new, switch, close) |
| `browser_drag` | Drag and drop elements |
| `browser_evaluate` | Execute JavaScript in the page (escape hatch) |

要排除特定Tool，请传递`excludeTools` in the constructor:

```typescript
const browser = new AgentBrowser({
  excludeTools: ['browser_screenshot'],
})
```

## Tool参考 {/* #tool-reference */}

### `browser_goto` {/* #browser_goto */}

导航到 URL。

```text
// Tool input
{
  "url": "https://example.com",
  "waitUntil": "domcontentloaded",
  "timeout": 30000
}
```

|参数|类型 |描述 |
| - | - | - |
|`url` | `string` | URL to open |
| `waitUntil` | `"load" \| "domcontentloaded" \| "networkidle"` | When to consider navigation complete (optional) |
| `timeout` | `number` | Navigation timeout in ms (optional) |

### `browser_snapshot` {/* #browser_snapshot */}

获取页面的可访问性树快照。返回元素引用，例如`@e5` that you use with other tools.

```text
// Tool input
{
  "interactiveOnly": true,
  "maxDepth": 10
}
```

|参数|类型 |描述 |
| - | - | - |
|`interactiveOnly` | `boolean` | Only include interactive elements (optional) |
| `maxDepth` | `number` | Maximum tree depth (optional) |

**输出示例：**

```text
[document] Example Page
  [banner]
    [link @e1] Home
    [link @e2] About
  [main]
    [heading @e3] Welcome
    [textbox @e4] Search...
    [button @e5] Submit
```

### `browser_click` {/* #browser_click */}

使用快照中的引用单击一个元素。

```text
{
  "ref": "@e5",
  "button": "left",
  "clickCount": 1,
  "modifiers": ["Control", "Shift"]
}
```

|参数|类型 |描述 |
| - | - | - |
|`ref` | `string` | Element ref from snapshot (required) |
| `button` | `"left" \| "right" \| "middle"` | Mouse button (optional) |
| `clickCount` | `number` | Number of activations, 2 for double (optional) |
| `modifiers` | `string[]` | Modifier keys (optional) |

### `browser_type` {/* #browser_type */}

在输入元素中键入文本。

```text
// Tool input
{
  "ref": "@e4",
  "text": "search query",
  "clear": true,
  "delay": 50
}
```

|参数|类型 |描述 |
| - | - | - |
|`ref` | `string` | Element ref from snapshot (required) |
| `text` | `string` | Text to type (required) |
| `clear` | `boolean` | Clear existing content first (optional) |
| `delay` | `number` | Delay between keystrokes in ms (optional) |

### `browser_press` {/* #browser_press */}

按键盘按键。

```text
// Tool input
{
  "key": "Enter",
  "modifiers": ["Control"]
}

// Key combinations
{ "key": "Control+a" }
{ "key": "Control+c" }
```

|参数|类型 |描述 |
| - | - | - |
|`key` | `string` | Key name (e.g., "Enter", "Tab", "Escape", "Control+a") (required) |
| `modifiers` | `string[]` | Modifier keys (optional) |

### `browser_select` {/* #browser_select */}

从下拉列表中选择一个选项。提供其中之一`value`, `label`, or `index`.

```text
// Tool input - by value
{
  "ref": "@e10",
  "value": "option-value"
}

// Tool input - by label
{
  "ref": "@e10",
  "label": "Option Text"
}

// Tool input - by index
{
  "ref": "@e10",
  "index": 0
}
```

### `browser_scroll` {/* #browser_scroll */}

滚动页面或特定元素。

```text
// Tool input
{
  "direction": "down",
  "amount": 300,
  "ref": "@e15"
}
```

|参数|类型 |描述 |
| - | - | - |
|`direction` | `"up" \| "down" \| "left" \| "right"` | Scroll direction (required) |
| `amount` | `number` | Pixels to scroll, default 300 (optional) |
| `ref` | `string` | Element to scroll, scrolls page if omitted (optional) |

### `browser_hover` {/* #browser_hover */}

将鼠标悬停在元素上可触发悬停效果。

```text
// Tool input
{
  "ref": "@e7"
}
```

### `browser_back` {/* #browser_back */}

返回浏览器历史记录。

```text
// Tool input (no parameters required)
{}
```

### `browser_dialog` {/* #browser_dialog */}

处理浏览器对话框（警报、确认、提示）。单击触发对话框的元素并对其进行处理。

```text
// Tool input
{
  "triggerRef": "@e5",
  "action": "accept",
  "text": "response"
}
```

|参数|类型 |描述 |
| - | - | - |
|`triggerRef` | `string` | Element that triggers the dialog (required) |
| `action` | `"accept" \| "dismiss"` | How to handle the dialog (required) |
| `text` | `string` | Text for prompt dialogs (optional) |

### `browser_wait` {/* #browser_wait */}

等待元素达到特定状态。

```text
// Tool input
{
  "ref": "@e20",
  "state": "visible",
  "timeout": 30000
}
```

|参数|类型 |描述 |
| - | - | - |
|`ref` | `string` | Element ref to wait for (optional) |
| `state` | `"visible" \| "hidden" \| "attached" \| "detached"` | State to wait for (optional) |
| `timeout` | `number` | Max wait time in ms (optional) |

### `browser_tabs` {/* #browser_tabs */}

管理浏览器选项卡。

```text
// List all tabs
{ "action": "list" }

// Open new tab
{ "action": "new", "url": "https://example.com" }

// Switch to tab by index
{ "action": "switch", "index": 0 }

// Close tab by index
{ "action": "close", "index": 1 }
```

### `browser_drag` {/* #browser_drag */}

将元素拖动到目标位置。

```text
// Tool input
{
  "sourceRef": "@e10",
  "targetRef": "@e20"
}
```

|参数|类型 |描述 |
| - | - | - |
|`sourceRef` | `string` | Element to drag (required) |
| `targetRef` | `string` | Drop target element (required) |

### `browser_evaluate` {/* #browser_evaluate */}

在页面上下文中执行 JavaScript。当其他Tool无法满足您的用例时，可将其用作逃生口。

```text
// Tool input
{
  "script": "document.title",
  "returnValue": true
}
```

|参数|类型 |描述 |
| - | - | - |
|`script` | `string` | JavaScript to execute (required) |
| `returnValue` | `boolean` | Whether to return the result (optional) |

### `browser_screenshot` {/* #browser_screenshot */}

将当前页面截图为PNG（默认为视口。设置`fullPage: true` for full-page capture). Returns image content that vision-capable models can interpret directly. Use `browser_snapshot` when you only need text or structured data.

```text
// Viewport only (default)
{}

// Full scrollable page
{ "fullPage": true }

// Also save the PNG to the workspace
{ "path": "screenshots/home.png" }
```

|参数|类型 |描述 |
| - | - | - |
|`fullPage` | `boolean` | Capture the full scrollable page instead of only the viewport (optional, default: false) |
| `path` | `string` | Also save the PNG to this path in the agent's workspace. Missing folders are created. The model is told where the file went, or why it couldn't be saved (for example, when the agent has no workspace). Follows the workspace's write-file settings: nothing is saved when writing is turned off, needs approval, or the filesystem is read-only. The screenshot is returned either way (optional) |

### `browser_close` {/* #browser_close */}

关闭浏览器并清理资源。

```text
// Tool input (no parameters required)
{}
```

## 裁判如何运作 {/* #how-refs-work */}

这`browser_snapshot` tool returns an accessibility tree with element refs like `@e1`, `@e2`, etc. These refs are stable identifiers you use with other tools:

1. 称呼`browser_snapshot` to see the page structure
2. 找到您想要交互的元素
3. 将其引用与交互Tool一起使用，例如`browser_type` or `browser_scroll`.

```text
// 1. Get snapshot
// Returns: [textbox @e4] Search... [link @e5] Home

// 2. Type in the search box
{ "tool": "browser_type", "input": { "ref": "@e4", "text": "mastra" } }

// 3. Navigate to home
{ "tool": "browser_goto", "input": { "url": "https://example.com" } }
```
