# AgentBrowser 类

`AgentBrowser` 类通过 [agent-browser](https://github.com/vercel-labs/agent-browser) 库提供确定性的浏览器自动化能力。它使用无障碍树快照和元素引用（如 `@e5`）实现精确、可复现的交互。

需要可靠、确定性的浏览器自动化时，可使用 `AgentBrowser`。如果需要通过自然语言执行 AI 驱动的交互，请参阅 [`StagehandBrowser`](/reference/browser/stagehand-browser)。

## 用法示例 {/* #usage-example */}

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { AgentBrowser } from '@mastra/agent-browser'

const browser = new AgentBrowser({
  headless: true,
  viewport: { width: 1280, height: 720 },
  scope: 'thread',
})

export const browserAgent = new Agent({
  id: 'browser-agent',
  name: 'Browser Agent',
  instructions: `You can browse the web. Use browser_snapshot to see the page structure,
then interact with elements using their refs (e.g., @e5).`,
  model: '__GATEWAY_OPENAI_MODEL__',
  browser,
})
```

## 工具 {/* #tools */}

`AgentBrowser` 提供 16 个用于浏览器自动化的确定性 Tool。所有与元素交互的 Tool 都使用无障碍树快照中的引用。

配置 `recording` 后，`AgentBrowser` 还会添加 Beta 版 `browser_record` 和 `browser_record_caption` Tool。请参阅[浏览器录制（Beta）](/docs/browser#record-browser-sessions)。

### 核心工具 {/* #core-tools */}

| 工具 | 说明 |
| - | - |
| `browser_goto` | 导航到 URL |
| `browser_snapshot` | 获取带有元素引用的无障碍树快照 |
| `browser_click` | 通过引用点击元素 |
| `browser_type` | 在元素中输入文本 |
| `browser_press` | 按下键盘按键 |
| `browser_select` | 从下拉菜单中选择选项 |
| `browser_scroll` | 滚动页面或元素 |
| `browser_screenshot` | 截取 PNG 屏幕截图（默认仅视口；设置 `fullPage: true` 可截取整页） |
| `browser_close` | 关闭浏览器 |

### 扩展工具 {/* #extended-tools */}

| 工具 | 说明 |
| - | - |
| `browser_hover` | 将鼠标悬停在元素上 |
| `browser_back` | 返回上一页 |
| `browser_dialog` | 处理浏览器对话框（alert、confirm、prompt） |
| `browser_wait` | 等待元素状态变化 |
| `browser_tabs` | 管理浏览器标签页（列出、新建、切换、关闭） |
| `browser_drag` | 拖放元素 |
| `browser_evaluate` | 在页面中执行 JavaScript（备用方式） |

要排除特定 Tool，请在构造函数中传入 `excludeTools`：

```typescript
const browser = new AgentBrowser({
  excludeTools: ['browser_screenshot'],
})
```

## 工具参考 {/* #tool-reference */}

### `browser_goto` {/* #browser_goto */}

导航到 URL。

```text
// Tool input
{
  "url": "https://example.com",
  "waitUntil": "domcontentloaded",
  "timeout": 30000
}
```

| 参数 | 类型 | 说明 |
| - | - | - |
| `url` | `string` | 要打开的 URL |
| `waitUntil` | `"load" \| "domcontentloaded" \| "networkidle"` | 将导航视为完成的时机（可选） |
| `timeout` | `number` | 导航超时时间，单位为毫秒（可选） |

### `browser_snapshot` {/* #browser_snapshot */}

获取页面的无障碍树快照。返回 `@e5` 这样的元素引用，供其他 Tool 使用。

```text
// Tool input
{
  "interactiveOnly": true,
  "maxDepth": 10
}
```

| 参数 | 类型 | 说明 |
| - | - | - |
| `interactiveOnly` | `boolean` | 仅包含可交互元素（可选） |
| `maxDepth` | `number` | 树的最大深度（可选） |

**输出示例：**

```text
[document] Example Page
  [banner]
    [link @e1] Home
    [link @e2] About
  [main]
    [heading @e3] Welcome
    [textbox @e4] Search...
    [button @e5] Submit
```

### `browser_click` {/* #browser_click */}

使用快照中的引用点击元素。

```text
{
  "ref": "@e5",
  "button": "left",
  "clickCount": 1,
  "modifiers": ["Control", "Shift"]
}
```

| 参数 | 类型 | 说明 |
| - | - | - |
| `ref` | `string` | 快照中的元素引用（必填） |
| `button` | `"left" \| "right" \| "middle"` | 鼠标按键（可选） |
| `clickCount` | `number` | 点击次数；双击时设为 2（可选） |
| `modifiers` | `string[]` | 修饰键（可选） |

### `browser_type` {/* #browser_type */}

在输入元素中输入文本。

```text
// Tool input
{
  "ref": "@e4",
  "text": "search query",
  "clear": true,
  "delay": 50
}
```

| 参数 | 类型 | 说明 |
| - | - | - |
| `ref` | `string` | 快照中的元素引用（必填） |
| `text` | `string` | 要输入的文本（必填） |
| `clear` | `boolean` | 是否先清除现有内容（可选） |
| `delay` | `number` | 每次按键之间的延迟，单位为毫秒（可选） |

### `browser_press` {/* #browser_press */}

按下键盘按键。

```text
// Tool input
{
  "key": "Enter",
  "modifiers": ["Control"]
}

// Key combinations
{ "key": "Control+a" }
{ "key": "Control+c" }
```

| 参数 | 类型 | 说明 |
| - | - | - |
| `key` | `string` | 按键名称（例如 "Enter"、"Tab"、"Escape"、"Control+a"）（必填） |
| `modifiers` | `string[]` | 辅助按键（可选） |

### `browser_select` {/* #browser_select */}

从下拉菜单中选择一个选项。提供 `value`、`label` 或 `index` 之一。

```text
// Tool input - by value
{
  "ref": "@e10",
  "value": "option-value"
}

// Tool input - by label
{
  "ref": "@e10",
  "label": "Option Text"
}

// Tool input - by index
{
  "ref": "@e10",
  "index": 0
}
```

### `browser_scroll` {/* #browser_scroll */}

滚动页面或指定元素。

```text
// Tool input
{
  "direction": "down",
  "amount": 300,
  "ref": "@e15"
}
```

| 参数 | 类型 | 说明 |
| - | - | - |
| `direction` | `"up" \| "down" \| "left" \| "right"` | 滚动方向（必填） |
| `amount` | `number` | 滚动的像素数，默认为 300（可选） |
| `ref` | `string` | 要滚动的元素；省略时滚动页面（可选） |

### `browser_hover` {/* #browser_hover */}

将鼠标悬停在元素上，以触发悬停效果。

```text
// Tool input
{
  "ref": "@e7"
}
```

### `browser_back` {/* #browser_back */}

返回浏览器历史记录中的上一页。

```text
// Tool input (no parameters required)
{}
```

### `browser_dialog` {/* #browser_dialog */}

处理浏览器对话框（alert、confirm、prompt）。点击触发对话框的元素，然后处理对话框。

```text
// Tool input
{
  "triggerRef": "@e5",
  "action": "accept",
  "text": "response"
}
```

| 参数 | 类型 | 说明 |
| - | - | - |
| `triggerRef` | `string` | 触发对话框的元素（必填） |
| `action` | `"accept" \| "dismiss"` | 处理对话框的操作（必填） |
| `text` | `string` | prompt 对话框的输入文本（可选） |

### `browser_wait` {/* #browser_wait */}

等待元素达到指定状态。

```text
// Tool input
{
  "ref": "@e20",
  "state": "visible",
  "timeout": 30000
}
```

| 参数 | 类型 | 说明 |
| - | - | - |
| `ref` | `string` | 要等待的元素引用（可选） |
| `state` | `"visible" \| "hidden" \| "attached" \| "detached"` | 要等待的状态（可选） |
| `timeout` | `number` | 最长等待时间，单位为毫秒（可选） |

### `browser_tabs` {/* #browser_tabs */}

管理浏览器标签页。

```text
// List all tabs
{ "action": "list" }

// Open new tab
{ "action": "new", "url": "https://example.com" }

// Switch to tab by index
{ "action": "switch", "index": 0 }

// Close tab by index
{ "action": "close", "index": 1 }
```

### `browser_drag` {/* #browser_drag */}

将元素拖放到目标位置。

```text
// Tool input
{
  "sourceRef": "@e10",
  "targetRef": "@e20"
}
```

| 参数 | 类型 | 说明 |
| - | - | - |
| `sourceRef` | `string` | 要拖动的元素（必填） |
| `targetRef` | `string` | 放置位置的目标元素（必填） |

### `browser_evaluate` {/* #browser_evaluate */}

在页面上下文中执行 JavaScript。其他 Tool 无法满足需求时，可将其用作备用方式。

```text
// Tool input
{
  "script": "document.title",
  "returnValue": true
}
```

| 参数 | 类型 | 说明 |
| - | - | - |
| `script` | `string` | 要执行的 JavaScript（必填） |
| `returnValue` | `boolean` | 是否返回执行结果（可选） |

### `browser_screenshot` {/* #browser_screenshot */}

将当前页面截取为 PNG 图片（默认仅截取视口；设置 `fullPage: true` 可截取整页）。返回的图片内容可供具备视觉能力的模型直接解读。如果只需要文本或结构化数据，请使用 `browser_snapshot`。

```text
// Viewport only (default)
{}

// Full scrollable page
{ "fullPage": true }

// Also save the PNG to the workspace
{ "path": "screenshots/home.png" }
```

| 参数 | 类型 | 说明 |
| - | - | - |
| `fullPage` | `boolean` | 截取整个可滚动页面，而不只是视口（可选，默认：false） |
| `path` | `string` | 同时将 PNG 保存到 Agent 的 Workspace 中的此路径。缺失的文件夹会自动创建。模型会得知文件保存位置，或无法保存的原因（例如 Agent 没有 Workspace）。此操作遵循 Workspace 的文件写入设置：关闭写入、需要审批或文件系统为只读时，不会保存文件。无论是否保存，都会返回截图（可选） |

### `browser_close` {/* #browser_close */}

关闭浏览器并清理资源。

```text
// Tool input (no parameters required)
{}
```

## 元素引用的工作原理 {/* #how-refs-work */}

`browser_snapshot` Tool 会返回包含 `@e1`、`@e2` 等元素引用的无障碍树。可通过这些稳定的标识符使用其他 Tool：

1. 调用 `browser_snapshot` 查看页面结构。
1. 找到要交互的元素。
1. 将该元素的引用传给 `browser_type` 或 `browser_scroll` 等交互 Tool。

```text
// 1. Get snapshot
// Returns: [textbox @e4] Search... [link @e5] Home

// 2. Type in the search box
{ "tool": "browser_type", "input": { "ref": "@e4", "text": "mastra" } }

// 3. Navigate to home
{ "tool": "browser_goto", "input": { "url": "https://example.com" } }
```
