# MastraBrowser 类

`MastraBrowser` 是浏览器自动化 Provider 的抽象基类。其通用接口涵盖浏览器启动、线程隔离、屏幕画面流及输入事件。

不要直接实例化 `MastraBrowser`，应使用具体的 Provider 实现：

- [`AgentBrowser`](/reference/browser/agent-browser)：使用 ref 进行确定性的浏览器自动化
- [`StagehandBrowser`](/reference/browser/stagehand-browser)：使用自然语言进行 AI 驱动的浏览器自动化
- [`BrowserViewer`](/reference/browser/browser-viewer)：通过 CLI 实现浏览器自动化，支持注入 CDP URL

## 使用示例 {/* #usage-example */}

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { AgentBrowser } from '@mastra/agent-browser'

const browser = new AgentBrowser({
  headless: true,
  viewport: { width: 1280, height: 720 },
  scope: 'thread',
})

export const browserAgent = new Agent({
  id: 'browser-agent',
  name: 'Browser Agent',
  instructions: 'You can browse the web to find information.',
  model: '__GATEWAY_OPENAI_MODEL__',
  browser,
})
```

## 方法 {/* #methods */}

### 生命周期 {/* #lifecycle */}

#### `ensureReady()` {/* #ensureready */}

确保浏览器已启动并准备好使用。执行工具前会自动调用，由基类实现。

```typescript
await browser.ensureReady()
```

#### `close()` {/* #close */}

关闭浏览器并清理全部资源。基类实现已处理并发竞态。

```typescript
await browser.close()
```

#### `isBrowserRunning()` {/* #isbrowserrunning */}

检查浏览器当前是否正在运行。

```typescript
const isRunning = browser.isBrowserRunning()
```

**返回：** `boolean`

### 线程管理 {/* #thread-management */}

#### `setCurrentThread(threadId)` {/* #setcurrentthreadthreadid */}

设置浏览器操作使用的当前线程 ID，供 Agent 运行时内部使用。

```typescript
browser.setCurrentThread('thread-123')
```

#### `getCurrentThread()` {/* #getcurrentthread */}

获取当前线程 ID。

```typescript
const threadId = browser.getCurrentThread()
```

**返回：** `string`

#### `hasThreadSession(threadId)` {/* #hasthreadsessionthreadid */}

检查某个线程是否有活跃的浏览器会话。

```typescript
const hasSession = browser.hasThreadSession('thread-123')
```

**返回：** `boolean`

#### `closeThreadSession(threadId)` {/* #closethreadsessionthreadid */}

关闭指定线程的浏览器会话。在 'thread' Scope 下会关闭该线程的浏览器实例；在 'shared' Scope 下会清除该线程的状态。

```typescript
await browser.closeThreadSession('thread-123')
```

### Cookie {/* #cookies */}

#### `setCookies(cookies, threadId?)` {/* #setcookiescookies-threadid */}

向线程的浏览器添加 Cookie。应用能够登录网站、Agent 却无法登录时（例如需要应用自身登录态的预览），可使用此方法。Cookie 值不会经过模型。若线程的浏览器尚未打开，Cookie 会在打开时加入。省略 `threadId` 时使用当前线程。

```typescript
await browser.setCookies(
  [
    {
      name: 'my_app_session',
      value: sessionToken,
      domain: 'app.example.com',
      path: '/',
      httpOnly: true,
      secure: true,
    },
  ],
  threadId,
)
```

每个 Cookie 都是 `BrowserCookie`，来自 `@mastra/core/browser`：包含 `name`、`value`，以及 `url` 或 `domain` 与 `path`；还可包含 `expires`（Unix 时间，单位为秒）、`httpOnly`、`secure` 和 `sameSite`。若需覆盖子域名，请让 `domain` 以点开头（`.example.com`）。

在 `'thread'` Scope 下，Cookie 只会加入对应线程的浏览器。在 `'shared'` Scope 下，所有线程共用浏览器，因此每个线程都能使用这些 Cookie。

尚未加入浏览器的 Cookie 会在调用 `close()` 时被丢弃；在 `'thread'` Scope 下，调用 `closeThreadSession()` 关闭对应线程时也会丢弃。在 `'shared'` Scope 下，它们会一直保留到共享浏览器打开。

Cookie 必须提供 `url`，或同时提供 `domain` 和 `path`；否则 `setCookies` 会抛出错误。

`AgentBrowser`、`BrowserViewer`、`FirecrawlBrowser` 和 `StagehandBrowser` 支持 Cookie；其他 Provider 会抛出错误。

**返回：** `Promise<void>`

### 工具 {/* #tools */}

#### `getTools()` {/* #gettools */}

返回供 Agent 使用的浏览器工具。各 Provider 会根据其模型返回不同工具。

```typescript
const tools = browser.getTools()
```

**返回：** `Record<string, Tool>`

### 屏幕画面流 {/* #screencast */}

#### `startScreencast(options?)` {/* #startscreencastoptions */}

开始流式输出浏览器画面帧，返回会发出帧事件的 `ScreencastStream`。

```typescript
const stream = await browser.startScreencast({ format: 'jpeg', quality: 80 })

stream.on('frame', frame => {
  console.log('Frame received:', frame.data.length, 'bytes')
})

stream.on('stop', reason => {
  console.log('Screencast stopped:', reason)
})
```

**返回：** `Promise<ScreencastStream>`

### 输入注入 {/* #input-injection */}

#### `injectMouseEvent(params, threadId?)` {/* #injectmouseeventparams-threadid */}

向浏览器注入鼠标事件，供 Studio 进行实时交互。

```typescript
await browser.injectMouseEvent({
  type: 'mousePressed',
  x: 100,
  y: 200,
  button: 'left',
  clickCount: 1,
})
```

#### `injectKeyboardEvent(params, threadId?)` {/* #injectkeyboardeventparams-threadid */}

向浏览器注入键盘事件，供 Studio 进行实时交互。

```typescript
await browser.injectKeyboardEvent({
  type: 'keyDown',
  key: 'Enter',
  code: 'Enter',
})
```

### 状态 {/* #state */}

#### `getBrowserState(threadId?)` {/* #getbrowserstatethreadid */}

获取当前浏览器状态，包括打开的标签页及活动标签页索引。没有可用状态时返回 `null`。

```typescript
const state = await browser.getBrowserState('thread-123')
if (state) {
  console.log('Active tab:', state.tabs[state.activeTabIndex]?.url)
  console.log('Tabs:', state.tabs)
}
```

**返回：** `Promise<BrowserState | null>`

```typescript
interface BrowserState {
  tabs: BrowserTabState[]
  activeTabIndex: number
  closeReason?: 'agent' | 'user' | 'process_restart' | 'error'
  activeUrlChangeSource?: 'agent' | 'user'
}

interface BrowserTabState {
  url: string
  title?: string
}
```

#### `getCurrentUrl(threadId?)` {/* #getcurrenturlthreadid */}

获取当前页面的 URL。

```typescript
const url = await browser.getCurrentUrl()
```

**返回：** `Promise<string | null>`

## 浏览器 Scope {/* #browser-scope */}

`scope` 选项控制浏览器实例在对话线程之间的共享方式：

| Scope | 说明 | 适用场景 |
| - | - | - |
| `'shared'` | 所有线程共用一个浏览器实例 | 适用于互不冲突的任务，可节约资源 |
| `'thread'` | 每个线程各有一个浏览器实例 | 为并发用户提供完全隔离 |

```typescript
// Shared browser for all threads
const sharedBrowser = new AgentBrowser({
  scope: 'shared',
})

// Isolated browser per thread
const isolatedBrowser = new AgentBrowser({
  scope: 'thread',
})
```

通过 `cdpUrl` 连接外部浏览器时，由于无法创建新的浏览器实例，Scope 会自动退回 `'shared'`。

## 云端浏览器 Provider {/* #cloud-browser-providers */}

使用 `cdpUrl` 选项连接云端浏览器服务：

```typescript
// Static CDP URL
const browser = new AgentBrowser({
  cdpUrl: 'wss://browser.example.com/ws',
})

// Dynamic CDP URL (e.g., session-based)
const browser = new AgentBrowser({
  cdpUrl: async () => {
    const session = await createBrowserSession()
    return session.wsUrl
  },
})
```
