# StagehandBrowser 类

`StagehandBrowser` 基于 [Stagehand](https://github.com/browserbase/stagehand) 提供 AI 浏览器自动化。它用自然语言指令完成交互，无需元素引用。

如果希望 AI 根据自然语言理解并执行浏览器操作，可使用 `StagehandBrowser`。如需基于元素引用进行确定性自动化，请参阅 [`AgentBrowser`](/reference/browser/agent-browser)。

## 使用示例 {/* #usage-example */}

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { StagehandBrowser } from '@mastra/stagehand'

const browser = new StagehandBrowser({
  headless: true,
  model: '__GATEWAY_OPENAI_MODEL__',
  selfHeal: true,
})

export const browserAgent = new Agent({
  id: 'browser-agent',
  name: 'Browser Agent',
  instructions: `You can browse the web using natural language.
Use stagehand_act to perform actions like "click the login button".
Use stagehand_extract to get data from pages.`,
  model: '__GATEWAY_OPENAI_MODEL__',
  browser,
})
```

## 工具 {/* #tools */}

`StagehandBrowser` 提供 7 个由 AI 驱动的浏览器自动化 Tool。

配置 `recording` 后，`StagehandBrowser` 还会添加 Beta 版的 `browser_record` 和 `browser_record_caption` Tool。参见[浏览器录制（Beta）](/docs/browser#record-browser-sessions)。

核心 Tool：

|Tool|描述 |
| - | - |
| `stagehand_act` | 根据自然语言指令执行操作 |
| `stagehand_extract` | 从页面提取结构化数据 |
| `stagehand_observe` | 找出页面上可用的元素 |
| `stagehand_navigate` | 导航至 URL |
| `stagehand_tabs` | 管理浏览器标签页 |
| `stagehand_screenshot` | 截取 PNG 图片（默认仅视口；设置 `fullPage: true` 可截取整页） |
| `stagehand_close` | 关闭浏览器 |

若要排除某些 Tool，请在构造函数中传入 `excludeTools`：

```typescript
const browser = new StagehandBrowser({
  excludeTools: ['stagehand_screenshot'],
})
```

## 工具参考 {/* #tool-reference */}

### `stagehand_act` {/* #stagehand_act */}

根据自然语言指令执行操作。AI 会理解指令并执行相应的浏览器操作。

```text
// Tool input
{
  "instruction": "click the login button",
  "variables": { "username": "john" },
  "useVision": true,
  "timeout": 30000
}

// With variable substitution
{
  "instruction": "type %email% into the email field",
  "variables": { "email": "user@example.com" }
}
```

|参数|类型 |描述 |
| - | - | - |
| `instruction` | `string` | 自然语言指令（必填） |
| `variables` | `Record<string, string>` | 用于替换 %variableName% 的变量（可选） |
| `useVision` | `boolean` | 启用视觉能力（可选） |
| `timeout` | `number` | 超时时间，单位为毫秒（可选） |

**返回：**

```typescript
interface ActResult {
  success: boolean
  message?: string
  action?: string
  url?: string
}
```

### `stagehand_extract` {/* #stagehand_extract */}

使用自然语言指令从页面提取结构化数据。

```text
// Basic extraction
{
  "instruction": "extract all product names and prices"
}

// With schema for structured output
{
  "instruction": "extract the product information",
  "schema": {
    "type": "object",
    "properties": {
      "name": { "type": "string" },
      "price": { "type": "number" },
      "inStock": { "type": "boolean" }
    }
  }
}
```

**返回：**

```typescript
interface ExtractResult<T = unknown> {
  success: boolean
  data?: T
  hint?: string
  error?: string
  url?: string
}
```

### `stagehand_observe` {/* #stagehand_observe */}

找出页面上可用的元素，返回其选择器和描述。

```text
// Find specific elements
{
  "instruction": "find all buttons related to checkout"
}

// Find all interactive elements
{
  "onlyVisible": true
}
```

|参数|类型 |描述 |
| - | - | - |
| `instruction` | `string` | 自然语言指令（可选；省略时查找所有元素） |
| `onlyVisible` | `boolean` | 仅包含可见元素（可选） |
| `timeout` | `number` | 超时时间，单位为毫秒（可选） |

**返回：**

```typescript
interface ObserveResult {
  success: boolean
  actions: StagehandAction[]
  url?: string
}

interface StagehandAction {
  selector: string
  description: string
  method?: string
  arguments?: string[]
}
```

### `stagehand_navigate` {/* #stagehand_navigate */}

导航到指定 URL。

```text
// Tool input
{
  "url": "https://example.com",
  "waitUntil": "domcontentloaded"
}
```

|参数|类型 |描述 |
| - | - | - |
| `url` | `string` | 要打开的 URL（必填） |
| `waitUntil` | `"load" \| "domcontentloaded" \| "networkidle"` | 判断导航完成的时机（可选） |

### `stagehand_tabs` {/* #stagehand_tabs */}

管理浏览器标签页。

```text
// List all tabs
{ "action": "list" }

// Open new tab
{ "action": "new", "url": "https://example.com" }

// Switch to tab by index
{ "action": "switch", "index": 0 }

// Close tab by index (or current if omitted)
{ "action": "close", "index": 1 }
```

### `stagehand_screenshot` {/* #stagehand_screenshot */}

将当前页面截取为 PNG 图片（默认仅视口；设置 `fullPage: true` 可截取整页）。返回的图片内容可由具备视觉能力的模型直接理解。如果只需文本或结构化数据，请使用 `stagehand_observe` 或 `stagehand_extract`。

```text
// Viewport only (default)
{}

// Full scrollable page
{ "fullPage": true }
```

|参数|类型 |描述 |
| - | - | - |
| `fullPage` | `boolean` | 截取完整可滚动页面，而非仅视口（可选；默认 false） |

### `stagehand_close` {/* #stagehand_close */}

关闭浏览器并释放资源。

```text
// Tool input (no parameters required)
{}
```

## 使用 Browserbase {/* #using-browserbase */}

使用 Browserbase 在云端运行 Stagehand：

```typescript
const browser = new StagehandBrowser({
  env: 'BROWSERBASE',
  apiKey: process.env.BROWSERBASE_API_KEY,
  projectId: process.env.BROWSERBASE_PROJECT_ID,
  model: '__GATEWAY_OPENAI_MODEL__',
})
```

## 模型配置 {/* #model-configuration */}

配置 Stagehand 操作使用的 AI 模型：

```typescript
// String format: "provider/model"
const browser = new StagehandBrowser({
  model: '__GATEWAY_OPENAI_MODEL__',
})

// Object format for custom configuration
const browser = new StagehandBrowser({
  model: {
    modelName: 'gpt-5.4',
    apiKey: process.env.OPENAI_API_KEY,
    baseURL: 'https://api.openai.com/v1',
  },
})
```

## AgentBrowser 与 StagehandBrowser {/* #agentbrowser-vs-stagehandbrowser */}

| 比较项 | AgentBrowser | StagehandBrowser |
| - | - | - |
| **操作方式** | 确定性元素引用（`@e5`） | 自然语言 |
| **精确度** | 精确定位元素 | AI 理解指令 |
| **灵活性** | 需先获取快照 | 可直接给出指令 |
| **适用场景** | 可重复的自动化 | 可适应变化的自动化 |
| **速度** | 较快（无需 AI 推理） | 较慢（需要 AI 推理） |

需要精确、可重复的自动化时，选择 `AgentBrowser`；需要灵活的自然语言交互时，选择 `StagehandBrowser`。
