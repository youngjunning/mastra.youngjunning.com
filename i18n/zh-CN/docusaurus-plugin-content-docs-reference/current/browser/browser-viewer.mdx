# 浏览器查看器

这`BrowserViewer`类为基于 CLI 的Tool提供浏览器自动化。它通过 Playwright 启动 Chrome 并公开 Chrome DevTools 协议 (CDP) URL。它会自动将该 URL 注入到通过WorkspaceTool运行的 CLI 命令中。

使用`BrowserViewer` when your agent drives a browser through a CLI tool like `browser-use`, `agent-browser`， 或者`browse`。对于基于 SDK 的浏览器自动化，请使用[`AgentBrowser`](/reference/browser/agent-browser)或者[`StagehandBrowser`](/reference/browser/stagehand-browser).

## 使用示例 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { Workspace, LocalSandbox } from '@mastra/core/workspace'
import { Memory } from '@mastra/memory'
import { BrowserViewer } from '@mastra/browser-viewer'
import { Agent } from '@mastra/core/agent'

const workspace = new Workspace({
  sandbox: new LocalSandbox({
    workingDirectory: './workspace',
  }),
  browser: new BrowserViewer({
    cli: 'browser-use',
    headless: false,
  }),
})

const browserAgent = new Agent({
  id: 'browser-agent',
  model: '__GATEWAY_OPENAI_MODEL__',
  workspace,
  instructions: 'You are a web automation assistant.',
  memory: new Memory(),
})
```

### 连接到现有浏览器 {/* #connecting-to-an-existing-browser */}

```typescript
const viewer = new BrowserViewer({
  cli: 'browser-use',
  cdpUrl: 'ws://127.0.0.1:9222/devtools/browser/abc123',
})
```

什么时候`cdpUrl` is provided, `BrowserViewer` connects to the existing browser instead of launching a new one. Scope defaults to `'shared'`.

## 方法 {/* #methods */}

### 生命周期 {/* #lifecycle */}

#### `launch(threadId?)` {/* #launchthreadid */}

使用单个共享浏览器启动 Chrome`'shared'` scope or a browser for the specified thread when using `'thread'` scope.

```typescript
await viewer.launch()
await viewer.launch('thread-123')
```

#### `ensureReady()` {/* #ensureready */}

确保浏览器已启动并准备就绪。为了`'thread'` scope, creates a new browser for the current thread if needed.

```typescript
await viewer.ensureReady()
```

#### `isBrowserRunning(threadId?)` {/* #isbrowserrunningthreadid */}

检查浏览器是否正在运行。为了`'thread'` scope, checks the specified thread.

```typescript
const running = viewer.isBrowserRunning()
const threadRunning = viewer.isBrowserRunning('thread-123')
```

返回：`boolean`

#### `close()` {/* #close */}

关闭所有浏览器实例并清理资源。

```typescript
await viewer.close()
```

### CDP 访问 {/* #cdp-access */}

#### `getCdpUrl(threadId?)` {/* #getcdpurlthreadid */}

返回当前或指定线程的 CDP WebSocket URL。 CLI Tool使用此 URL 连接到托管浏览器。

```typescript
const cdpUrl = viewer.getCdpUrl()
// => 'ws://127.0.0.1:52481/devtools/browser/abc...'
```

返回：`string | null`

#### `connectToExternalCdp(cdpUrl, threadId?)` {/* #connecttoexternalcdpcdpurl-threadid */}

通过 CDP URL 连接到外部浏览器进行截屏。当Agent提供自己的浏览器端点（例如，云浏览器服务）时使用此选项。 BrowserViewer 连接进行截屏播放，无需管理浏览器生命周期。

```typescript
await viewer.connectToExternalCdp('wss://cloud.example.com/session', 'thread-123')
```

### 截屏视频 {/* #screencast */}

#### `startScreencast(options?)` {/* #startscreencastoptions */}

开始流式传输浏览器框架。返回一个`ScreencastStream` that emits frame events. Handles tab switching automatically by creating fresh CDP sessions when tabs change.

```typescript
const stream = await viewer.startScreencast({
  format: 'jpeg',
  quality: 80,
})

stream.on('frame', frame => {
  console.log('Frame received:', frame.data.length, 'bytes')
})

stream.on('stop', reason => {
  console.log('Screencast stopped:', reason)
})
```

返回：`Promise<ScreencastStream>`

### 输入注入 {/* #input-injection */}

#### `injectMouseEvent(params, threadId?)` {/* #injectmouseeventparams-threadid */}

通过 CDP 将鼠标事件注入浏览器。 Studio 用于实时交互。

```typescript
await viewer.injectMouseEvent({
  type: 'mousePressed',
  x: 100,
  y: 200,
  button: 'left',
  clickCount: 1,
})
```

#### `injectKeyboardEvent(params, threadId?)` {/* #injectkeyboardeventparams-threadid */}

通过 CDP 将键盘事件注入浏览器。 Studio 用于实时交互。

```typescript
await viewer.injectKeyboardEvent({
  type: 'keyDown',
  key: 'Enter',
  code: 'Enter',
})
```

## 支持的 CLI {/* #supported-clis */}

每个 CLI 必须单独安装。每个还发布了[skill](/docs/sandbox/skills) that teaches the agent its commands and workflows. When a CLI command runs through `workspace_execute_command`, Mastra detects it and injects the CDP URL automatically using the correct flag.

与 SDK Provider不同，`BrowserViewer` doesn't provide agent tools. The agent uses CLI commands through `workspace_execute_command` instead.

### [`agent-browser`](https://www.npmjs.com/package/agent-browser) {/* #agent-browser */}

配置值：`'agent-browser'` · CDP flag: `--cdp`

```bash
npm install -g agent-browser
npx skills add vercel-labs/agent-browser
```

### [`browser-use`](https://pypi.org/project/browser-use/) {/* #browser-use */}

配置值：`'browser-use'` · CDP flag: `--cdp-url`

```bash
pip install browser-use
npx skills add browser-use/browser-use --skill browser-use
```

### [`browse`](https://www.npmjs.com/package/browse)（命令：`browse`) {/* #browse-command-browse */}

配置值：`'browse'` · CDP flag: `--ws`

```bash
npm install -g browse
browse skills install
```
