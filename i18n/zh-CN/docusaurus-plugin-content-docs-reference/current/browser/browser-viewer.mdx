# BrowserViewer

`BrowserViewer` 类为基于 CLI 的工具提供浏览器自动化。它通过 Playwright 启动 Chrome，并提供 Chrome DevTools Protocol（CDP）URL。通过 Workspace 工具运行 CLI 命令时，它会自动注入此 URL。

如果 Agent 使用 `BrowserViewer` 通过 `browser-use`、`agent-browser` 或 `browse` 等 CLI 工具控制浏览器，请使用此类。对于基于 SDK 的浏览器自动化，请使用 [`AgentBrowser`](/reference/browser/agent-browser) 或 [`StagehandBrowser`](/reference/browser/stagehand-browser)。

## 使用示例 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { Workspace, LocalSandbox } from '@mastra/core/workspace'
import { Memory } from '@mastra/memory'
import { BrowserViewer } from '@mastra/browser-viewer'
import { Agent } from '@mastra/core/agent'

const workspace = new Workspace({
  sandbox: new LocalSandbox({
    workingDirectory: './workspace',
  }),
  browser: new BrowserViewer({
    cli: 'browser-use',
    headless: false,
  }),
})

const browserAgent = new Agent({
  id: 'browser-agent',
  model: '__GATEWAY_OPENAI_MODEL__',
  workspace,
  instructions: 'You are a web automation assistant.',
  memory: new Memory(),
})
```

### 连接到现有浏览器 {/* #connecting-to-an-existing-browser */}

```typescript
const viewer = new BrowserViewer({
  cli: 'browser-use',
  cdpUrl: 'ws://127.0.0.1:9222/devtools/browser/abc123',
})
```

提供 `cdpUrl` 时，`BrowserViewer` 会连接现有浏览器，而不是启动新浏览器。作用域默认为 `'shared'`。

## 方法 {/* #methods */}

### 生命周期 {/* #lifecycle */}

#### `launch(threadId?)` {/* #launchthreadid */}

对于 `'shared'` 作用域，启动一个共享的 Chrome 浏览器；对于 `'thread'` 作用域，为指定线程启动浏览器。

```typescript
await viewer.launch()
await viewer.launch('thread-123')
```

#### `ensureReady()` {/* #ensureready */}

确保浏览器已启动并就绪。对于 `'thread'` 作用域，必要时会为当前线程创建新浏览器。

```typescript
await viewer.ensureReady()
```

#### `isBrowserRunning(threadId?)` {/* #isbrowserrunningthreadid */}

检查浏览器是否正在运行。对于 `'thread'` 作用域，检查指定线程。

```typescript
const running = viewer.isBrowserRunning()
const threadRunning = viewer.isBrowserRunning('thread-123')
```

返回：`boolean`

#### `close()` {/* #close */}

关闭所有浏览器实例并清理资源。

```typescript
await viewer.close()
```

### CDP 访问 {/* #cdp-access */}

#### `getCdpUrl(threadId?)` {/* #getcdpurlthreadid */}

返回当前或指定线程的 CDP WebSocket URL。CLI 工具通过此 URL 连接受管理的浏览器。

```typescript
const cdpUrl = viewer.getCdpUrl()
// => 'ws://127.0.0.1:52481/devtools/browser/abc...'
```

返回：`string | null`

#### `connectToExternalCdp(cdpUrl, threadId?)` {/* #connecttoexternalcdpcdpurl-threadid */}

通过 CDP URL 连接外部浏览器，以进行画面投放。当 Agent 提供自己的浏览器端点（例如云浏览器服务）时使用。BrowserViewer 只连接画面投放，不管理浏览器生命周期。

```typescript
await viewer.connectToExternalCdp('wss://cloud.example.com/session', 'thread-123')
```

### 浏览器画面投放 {/* #screencast */}

#### `startScreencast(options?)` {/* #startscreencastoptions */}

开始串流传输浏览器画面。返回会发出画面事件的 `ScreencastStream`。标签页切换时会创建新的 CDP 会话，自动处理切换。

```typescript
const stream = await viewer.startScreencast({
  format: 'jpeg',
  quality: 80,
})

stream.on('frame', frame => {
  console.log('Frame received:', frame.data.length, 'bytes')
})

stream.on('stop', reason => {
  console.log('Screencast stopped:', reason)
})
```

返回：`Promise<ScreencastStream>`

### 输入注入 {/* #input-injection */}

#### `injectMouseEvent(params, threadId?)` {/* #injectmouseeventparams-threadid */}

通过 CDP 向浏览器注入鼠标事件，供 Studio 实时交互使用。

```typescript
await viewer.injectMouseEvent({
  type: 'mousePressed',
  x: 100,
  y: 200,
  button: 'left',
  clickCount: 1,
})
```

#### `injectKeyboardEvent(params, threadId?)` {/* #injectkeyboardeventparams-threadid */}

通过 CDP 向浏览器注入键盘事件，供 Studio 实时交互使用。

```typescript
await viewer.injectKeyboardEvent({
  type: 'keyDown',
  key: 'Enter',
  code: 'Enter',
})
```

## 支持的 CLI {/* #supported-clis */}

每个 CLI 都需要单独安装。每个 CLI 也发布了介绍其命令和工作流程的[Skill](/docs/sandbox/skills)。通过 `workspace_execute_command` 运行 CLI 命令时，Mastra 会识别它，并自动使用正确的参数注入 CDP URL。

与基于 SDK 的提供者不同，`BrowserViewer` 不提供 Agent Tool。Agent 改用 `workspace_execute_command` 运行 CLI 命令。

### [`agent-browser`](https://www.npmjs.com/package/agent-browser) {/* #agent-browser */}

配置值：`'agent-browser'` · CDP 参数：`--cdp`

```bash
npm install -g agent-browser
npx skills add vercel-labs/agent-browser
```

### [`browser-use`](https://pypi.org/project/browser-use/) {/* #browser-use */}

配置值：`'browser-use'` · CDP 参数：`--cdp-url`

```bash
pip install browser-use
npx skills add browser-use/browser-use --skill browser-use
```

### [`browse`](https://www.npmjs.com/package/browse)（命令：`browse`） {/* #browse-command-browse */}

配置值：`'browse'` · CDP 参数：`--ws`

```bash
npm install -g browse
browse skills install
```
