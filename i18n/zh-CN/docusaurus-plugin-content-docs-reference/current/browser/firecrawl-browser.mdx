# FirecrawlBrowser 类

`FirecrawlBrowser` 类基于 [Firecrawl Browser Sandbox](https://docs.firecrawl.dev/features/browser) 提供浏览器自动化能力。它通过 Firecrawl API 创建远程浏览器会话，并使用 Chrome DevTools Protocol (CDP) 建立连接。

`FirecrawlBrowser` 继承 [`AgentBrowser`](/reference/browser/agent-browser)，提供相同的确定性 Tool 集。需要托管浏览器会话、无需在本地安装 Chromium 时可使用它。本地自动化请参阅 [`AgentBrowser`](/reference/browser/agent-browser)；使用自然语言进行 AI 驱动的交互，请参阅 [`StagehandBrowser`](/reference/browser/stagehand-browser)。

## 使用示例 {/* #usage-example */}

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { FirecrawlBrowser } from '@mastra/browser-firecrawl'

const browser = new FirecrawlBrowser({
  apiKey: process.env.FIRECRAWL_API_KEY,
  firecrawl: {
    ttl: 600,
  },
})

export const browserAgent = new Agent({
  id: 'browser-agent',
  name: 'Browser Agent',
  instructions: `You can browse the web. Use browser_snapshot to see the page structure,
then interact with elements using their refs (e.g., @e5).`,
  model: '__GATEWAY_OPENAI_MODEL__',
  browser,
})
```

## 会话生命周期 {/* #session-lifecycle */}

会话的创建方式取决于 `scope` 选项，该选项继承自 `AgentBrowser`：

- `'thread'` （默认）：每个对话线程都有独立的 Firecrawl 沙箱会话，首次使用时创建，在线程的浏览器会话销毁时删除。
- `'shared'`: 浏览器启动时创建一个 Firecrawl 沙箱会话，供所有线程共享；浏览器关闭时删除该会话。

无论使用哪种配置，浏览器关闭时 `FirecrawlBrowser` 都会删除远程 Firecrawl 会话，即使创建会话或建立连接的过程曾中途失败也是如此。

## Tool {/* #tools */}

`FirecrawlBrowser` 提供与 `AgentBrowser` 相同的 Tool 集，包括 `browser_goto`、`browser_snapshot`、`browser_click`、`browser_type` 和 `browser_screenshot`。完整列表和 Tool 参数请参阅 [`AgentBrowser` Tool 参考文档](/reference/browser/agent-browser)。
