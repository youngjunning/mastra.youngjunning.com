# 模板

本参考文档介绍如何使用现有 Mastra 模板、创建自己的模板，以及如何为社区生态贡献模板。

Mastra 模板是预构建的项目结构，用于展示特定用例和模式。它们提供：

* **可运行示例**：完整且功能齐全的 Mastra 应用
* **最佳实践**：合理的项目结构和编码约定
* **学习资源**：通过真实实现学习 Mastra 模式
* **快速入门**：通过脚手架快速启动项目，无需从零构建

## 可用模板 {/* #available-templates */}

以下模板展示以 Gateway 为优先入口的 Mastra 应用：

* `template-docs-expert`：结合 Gateway 网页搜索、引用、内存和结构化响应回答文档问题。
* `template-browser-agent`：使用 AgentBrowser 浏览、检查网页并与之交互。
* `template-meeting-notes`：将 Zoom 转录稿或上传的转录稿转换为包含决策和行动项的结构化笔记。
* `template-company-knowledge`：将 Linear 和 Notion 内容索引到 pgvector 中并回答内部知识问题。
* `template-claw-assistant`：使用文件系统、Sandbox、浏览器和网页搜索 Tool 操作 Workspace。

## 使用模板 {/* #using-templates */}

### 安装 {/* #installation */}

使用 `create-mastra` 命令安装模板：

```sh npm2yarn
npx create-mastra@latest my-project --template template-name
```

该命令会创建完整项目并安装依赖。模板作者负责定义模型、Provider 依赖、环境变量和源代码。

### 设置流程 {/* #setup-process */}

安装后：

1. **进入项目目录**：

   ```bash
   cd your-project-name
   ```

2. **配置环境变量**：

   ```bash
   cp .env.example .env
   ```

   按照模板 README 的说明编辑 `.env`，填入所需的 API 密钥。

3. **启动开发服务器**：

   ```sh npm2yarn
   npm run dev
   ```

### 模板结构 {/* #template-structure */}

所有模板都遵循以下标准化结构：

```text
your-template/
├── src/
│   └── mastra/
│       ├── agents/       # Agent definitions
│       ├── tools/        # Tool definitions
│       ├── workflows/    # Workflow definitions
│       └── index.ts      # Main Mastra config
├── .env.example          # Required environment variables
├── package.json
├── tsconfig.json
└── README.md
```
