# 模板

本参考资料解释了如何使用现有的 Mastra 模板并创建您自己的模板。它还涵盖了向社区生态系统贡献模板。

Mastra 模板是预先构建的项目结构，用于演示特定的用例和模式。他们提供：

* **工作示例**：完整、实用的 Mastra 应用程序
* **最佳实践**：正确的项目结构和编码约定
* **教育资源**：通过实际实施学习 Mastra 模式
* **快速入门**：引导项目比从头开始构建更快

## 可用模板 {/* #available-templates */}

以下模板演示了网关优先的 Mastra 应用程序：

* `template-docs-expert`：通过 Gateway 网络搜索、引文、记忆和结构化响应回答文档问题。
* `template-browser-agent`：使用 AgentBrowser 浏览、检查网页并与之交互。
* `template-meeting-notes`：将 Zoom 记录或上传的记录转换为包含决策和行动项目的结构化笔记。
* `template-company-knowledge`：将 Linear 和 Notion 内容索引到 pgvector 中并回答内部知识问题。
* `template-claw-assistant`：使用文件系统、Sandbox、浏览器和网络搜索Tool操作Workspace。

## 使用模板 {/* #using-templates */}

### 安装 {/* #installation */}

使用以下命令安装模板`create-mastra` command:

```sh npm2yarn
npx create-mastra@latest my-project --template template-name
```

这将创建一个完整的项目并安装其依赖项。模板作者控制模型、提供程序依赖项、环境变量和源代码。

### 设置过程 {/* #setup-process */}

安装后：

1. **导航到项目目录**:

   ```bash
   cd your-project-name
   ```

2. **配置环境变量**:

   ```bash
   cp .env.example .env
   ```

   编辑`.env` with required API keys as documented in the template's README.

3. **启动开发服务器**:

   ```sh npm2yarn
   npm run dev
   ```

### 模板结构 {/* #template-structure */}

所有模板都遵循以下标准化结构：

```text
your-template/
├── src/
│   └── mastra/
│       ├── agents/       # Agent definitions
│       ├── tools/        # Tool definitions
│       ├── workflows/    # Workflow definitions
│       └── index.ts      # Main Mastra config
├── .env.example          # Required environment variables
├── package.json
├── tsconfig.json
└── README.md
```
