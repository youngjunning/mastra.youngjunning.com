# 数据集.finalizeExperiment()

**添加于：** `@mastra/core@1.61.0`

完成使用以下命令创建的调用者驱动的实验[`createExperiment()`](/reference/datasets/createExperiment), with or without a target. Mastra computes the final counts server-side from the persisted result rows and marks the experiment `'completed'`。一个已经做过的实验`'failed'`返回原样并保持失败状态。调用者从不跟踪簿记的完成情况。

计数是每个项目的，所以`succeededCount + failedCount + skippedCount === totalItems` even when items have multiple attempts:

* `succeededCount`：至少完成一次尝试且未出现错误的项目
* `failedCount`：已提交但每次尝试都出错的项目
* `skippedCount`：从未提交的数据集项目（任何尝试）

尝试级别的详细信息仍然可以通过[`listExperimentResults()`](/reference/datasets/listExperimentResults).

终结是幂等的：在已经完成或失败的实验上调用它会返回存储的记录而无需重新计算。

## 使用示例 {/* #usage-example */}

```typescript
const experiment = await dataset.finalizeExperiment({ experimentId })

console.log(experiment.status) // 'completed'
console.log(experiment.succeededCount)
console.log(experiment.failedCount)
console.log(experiment.skippedCount)
```
