# 数据集.finalizeExperiment()

**引入版本：** `@mastra/core@1.61.0`

完成通过 [`createExperiment()`](/reference/datasets/createExperiment) 创建的调用方驱动实验，无论是否设置 target。Mastra 会根据持久化的结果行在服务端计算最终计数，并将实验标记为 `'completed'`。已经为 `'failed'` 的实验会原样返回并保持失败，调用方无需自行维护完成状态。

计数以数据项为单位，因此即使一个数据项有多次尝试，仍满足 `succeededCount + failedCount + skippedCount === totalItems`：

* `succeededCount`：至少完成一次尝试且未出现错误的项目
* `failedCount`：已提交但每次尝试都出错的项目
* `skippedCount`：从未提交过任何尝试的数据集数据项

尝试级别的详细信息仍然可以通过[`listExperimentResults()`](/reference/datasets/listExperimentResults).

终结是幂等的：在已经完成或失败的实验上调用它会返回存储的记录而无需重新计算。

## 使用示例 {/* #usage-example */}

```typescript
const experiment = await dataset.finalizeExperiment({ experimentId })

console.log(experiment.status) // 'completed'
console.log(experiment.succeededCount)
console.log(experiment.failedCount)
console.log(experiment.skippedCount)
```

## 返回值 {/* #returns */}
