# 删除实验()

**添加于：** `@mastra/core@1.4.0`

删除实验产生的Observability痕迹，然后删除实验及其结果记录。删除痕迹需要`@mastra/core@1.65.0` or later and cascades to spans, metrics, logs, scores, and feedback linked by trace ID. Unsupported observability storage leaves the traces in place and logs a warning.

使用`dataset.deleteExperiment()` when you have a `Dataset` instance. Use `mastra.datasets.deleteExperiment()`在没有数据集引用的情况下按实验 ID 进行删除，包括因数据集删除而孤立的实验。

## 从数据集中删除 {/* #delete-from-a-dataset */}

```typescript
import { Mastra } from '@mastra/core'

const mastra = new Mastra({/* storage config */})
const dataset = await mastra.datasets.get({ id: 'dataset-id' })

await dataset.deleteExperiment({ experimentId: 'experiment-id' })
```

实验必须属于数据集。缺少的实验或属于另一个数据集的实验会抛出异常`EXPERIMENT_NOT_FOUND`.

退货`Promise<void>`, which resolves when deletion completes.

## 在没有数据集引用的情况下删除 {/* #delete-without-a-dataset-reference */}

```typescript
import { Mastra } from '@mastra/core'

const mastra = new Mastra({/* storage config */})

await mastra.datasets.deleteExperiment({
  experimentId: 'experiment-id',
  organizationId: 'organization-id',
  projectId: 'project-id',
})
```

管理器方法不需要实验与数据集保持关联。用它来删除一个孤立的实验`datasetId` was cleared when its dataset was deleted.

什么时候`organizationId` or `projectId` is provided, deletion is scoped to those values. A tenancy mismatch is a silent no-op.

## 痕迹删除支持 {/* #trace-deletion-support */}

在删除结果记录之前，Mastra 会收集级联的跟踪 ID。没有可观察性或跟踪删除支持的存储会将这些跟踪保留在适当的位置，记录警告，并且仍然删除实验及其结果记录。

如果跟踪删除因任何其他原因失败，则调用会在实验之前被拒绝，并且其结果记录将被删除。痕迹会以 1,000 条为一批进行删除，因此某些痕迹可能已被删除。重复调用以完成删除。
