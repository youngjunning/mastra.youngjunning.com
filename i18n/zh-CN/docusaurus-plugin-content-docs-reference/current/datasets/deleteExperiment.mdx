# deleteExperiment()

**自以下版本引入：** `@mastra/core@1.4.0`

先删除实验产生的可观测性 Trace，再删除实验及其结果记录。删除 Trace 需要 `@mastra/core@1.65.0` 或更高版本，并会级联删除通过 Trace ID 关联的 Span、指标、日志、评分和反馈。如果可观测性存储不支持删除 Trace，Trace 会保留，系统会记录警告。

要使用 `dataset.deleteExperiment()`，须先取得 `Dataset` 实例。没有数据集引用时，使用 `mastra.datasets.deleteExperiment()` 按实验 ID 删除；这也适用于数据集删除后留下的孤立实验。

## 从数据集中删除 {/* #delete-from-a-dataset */}

```typescript
import { Mastra } from '@mastra/core'

const mastra = new Mastra({/* storage config */})
const dataset = await mastra.datasets.get({ id: 'dataset-id' })

await dataset.deleteExperiment({ experimentId: 'experiment-id' })
```

实验必须属于该数据集。实验不存在或属于其他数据集时，会抛出 `EXPERIMENT_NOT_FOUND`。

## 在没有数据集引用的情况下删除 {/* #delete-without-a-dataset-reference */}

```typescript
import { Mastra } from '@mastra/core'

const mastra = new Mastra({/* storage config */})

await mastra.datasets.deleteExperiment({
  experimentId: 'experiment-id',
  organizationId: 'organization-id',
  projectId: 'project-id',
})
```

管理器方法不要求实验仍与数据集关联。数据集删除时，若实验的 `datasetId` 已被清除，可用此方法删除该孤立实验。

提供 `organizationId` 或 `projectId` 时，删除操作限定在对应范围内。租户信息不匹配时，操作会静默跳过。

## Trace 删除支持 {/* #trace-deletion-support */}

删除结果记录前，Mastra 会收集其中的 Trace ID，以便级联删除。如果存储不支持可观测性功能或删除 Trace，Trace 会保留，系统会记录警告，但仍会删除实验及其结果记录。

如果删除 Trace 因其他原因失败，调用会在删除实验及其结果记录之前被拒绝。Trace 每批删除 1,000 条，因此失败前可能已有部分 Trace 被删除。再次调用即可完成删除。
