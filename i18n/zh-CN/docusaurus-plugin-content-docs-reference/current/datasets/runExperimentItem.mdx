# dataset.runExperimentItem()

**引入版本：** `@mastra/core@1.61.0`

在服务端运行一个实验条目：用该条目运行实验目标，执行解析后的评分器，并按 `(experimentId, itemId, attempt)` 更新或插入结果记录。

此方法适用于由调用方控制的循环：持久化编排器（例如 Temporal Workflow）为每个条目分发一次调用，并负责重试和超时。重试调用会写入同一条记录。实验必须通过 [`createExperiment()`](/reference/datasets/createExperiment) 创建并配置目标。

评分器的解析优先级与原生运行相同：实验的 `scorers` 优先于条目的 `scorerIds`，后者又优先于数据集的 `scorerIds`。

## 使用示例 {/* #usage-example */}

```typescript
const { experimentId } = await dataset.createExperiment({
  targetType: 'agent',
  targetId: 'translation-agent',
  scorers: ['accuracy'],
})

const { result, scores } = await dataset.runExperimentItem({
  experimentId,
  itemId: 'item-1',
})

console.log(result.output)
console.log(scores)
```

每次调用只执行该条目一次，内部没有重试循环。对未配置目标的实验调用时会抛出 `EXPERIMENT_HAS_NO_TARGET`；这类实验请使用 [`submitExperimentResult()`](/reference/datasets/submitExperimentResult)。实验结束后调用会抛出 `EXPERIMENT_ALREADY_FINALIZED`；如果 `itemId` 在固定的数据集版本中不可见，则会抛出 `DATASET_ITEM_NOT_FOUND`。
