# dataset.submitExperimentResult()

**新增于：** `@mastra/core@1.61.0`

为通过 [`createExperiment()`](/reference/datasets/createExperiment) 创建的无目标实验，提交（或重新提交）一条由外部计算的条目结果。

提交采用以 `(experimentId, itemId, attempt)` 为键的更新插入操作：工作进程重试时，即使再次提交相同的键，结果也会归并到同一行，而不会产生重复记录。使用不同的 `attempt` 值，可将重复试验记录为独立的行。

## 使用示例 {/* #usage-example */}

```typescript
const result = await dataset.submitExperimentResult({
  experimentId,
  itemId: 'item-1',
  output: { translation: 'Hola' },
  scores: [{ scorerId: 'accuracy', score: 0.92, reason: 'Faithful translation' }],
})
```

条目必须在实验固定的数据集版本中可见。向有目标的实验提交结果会抛出 `EXPERIMENT_HAS_TARGET`，以防两个写入方竞争同一批结果行。实验完成最终确定后提交会抛出 `EXPERIMENT_ALREADY_FINALIZED`。

## 返回值 {/* #returns */}

返回 `Promise<ExperimentResult>`，即已持久化的结果行，其中包含 `id`、`attempt` 和时间戳。
