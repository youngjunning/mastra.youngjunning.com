# 数据集.submitExperimentResult()

**添加于：** `@mastra/core@1.61.0`

为使用以下命令创建的无目标实验提交（或重新提交）一个外部计算的项目结果[`createExperiment()`](/reference/datasets/createExperiment).

提交的内容是更新插入的关键字`(experimentId, itemId, attempt)`: a retried worker that submits the same key converges on a single row instead of duplicating results. Use a different `attempt` value to record repeated trials as separate rows.

## 使用示例 {/* #usage-example */}

```typescript
const result = await dataset.submitExperimentResult({
  experimentId,
  itemId: 'item-1',
  output: { translation: 'Hola' },
  scores: [{ scorerId: 'accuracy', score: 0.92, reason: 'Faithful translation' }],
})
```

该项目必须在实验的固定数据集版本中可见。提交有目标投掷的实验`EXPERIMENT_HAS_TARGET`, which prevents two writers from racing on the same rows. Submissions after finalization throw `EXPERIMENT_ALREADY_FINALIZED`.

## 退货 {/* #returns */}

返回一个`Promise<ExperimentResult>`, the persisted result row, including its `id`, `attempt`, and timestamps.
