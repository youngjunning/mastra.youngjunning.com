# dataset.getDetails()

**引入版本：** `@mastra/core@1.4.0`

从存储中获取完整的数据集记录，包括元数据、schema 和版本信息。

## 使用示例 {/* #usage-example */}

```typescript
import { Mastra } from '@mastra/core'

const mastra = new Mastra({/* storage config */})

const dataset = await mastra.datasets.get({ id: 'dataset-id' })

// Get dataset details
const details = await dataset.getDetails()
console.log(details.name, details.version)
```

## 参数 {/* #parameters */}

此方法不接受参数。

## 返回值 {/* #returns */}

返回 `Promise<DatasetRecord>`。如果找不到数据集，则抛出 `MastraError`。
