# DatasetsManager.delete()

**引入版本** `@mastra/core@1.4.0`

按 ID 删除数据集，包括其中的所有条目和版本。曾使用该数据集运行的实验会保留，但会解除关联，实验的 `datasetId` 和 `datasetVersion` 均设为 `null`。以数据库为后端的存储适配器还会删除这些实验的结果。

## 使用示例 {/* #usage-example */}

```typescript
import { Mastra } from '@mastra/core'

const mastra = new Mastra({/* storage config */})

await mastra.datasets.delete({ id: 'dataset-id' })
```

如果提供了 `organizationId` 或 `projectId`，删除操作只在指定范围内生效。租户不匹配时，不会删除任何内容，也不会报错。
