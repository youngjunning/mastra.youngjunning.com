# 数据集管理器.delete()

**添加于：** `@mastra/core@1.4.0`

按 ID 删除数据集，包括其所有项目和版本。针对数据集运行的实验被保留但分离：它们`datasetId` and `datasetVersion`被设置为`null`。数据库支持的存储适配器也会删除这些实验的结果。

## 使用示例 {/* #usage-example */}

```typescript
import { Mastra } from '@mastra/core'

const mastra = new Mastra({/* storage config */})

await mastra.datasets.delete({ id: 'dataset-id' })
```

什么时候`organizationId` or `projectId` is provided, deletion is scoped to those values. A tenancy mismatch is a silent no-op.
