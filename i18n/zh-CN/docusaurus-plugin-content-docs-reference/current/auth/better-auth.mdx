# MastraAuthBetterAuth 类

`MastraAuthBetterAuth` 类通过 Better Auth 为 Mastra 应用提供身份验证。它使用 Better Auth 会话验证传入请求，并通过 `auth` 选项接入 Mastra 服务器。

## 使用示例 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraAuthBetterAuth } from '@mastra/auth-better-auth'
import { betterAuth } from 'better-auth'

// Create your Better Auth instance
const auth = betterAuth({
  database: {
    provider: 'postgresql',
    url: process.env.DATABASE_URL,
  },
  emailAndPassword: {
    enabled: true,
  },
  baseURL: process.env.BETTER_AUTH_URL,
  secret: process.env.BETTER_AUTH_SECRET,
})

export const mastra = new Mastra({
  server: {
    auth: new MastraAuthBetterAuth({
      auth,
    }),
  },
})
```

## `BetterAuthUser`类型 {/* #betterauthuser-type */}

`BetterAuthUser` 类型包含 Better Auth 返回的会话和用户信息：

```typescript
interface BetterAuthUser {
  session: Session & { activeOrganizationId?: string | null }
  user: User
}
```

* `session`：包含会话元数据的 Better Auth 会话对象。`activeOrganizationId` 来自 organization 插件。Provider 只会在自行创建的实例中注册该插件。如果传入 `auth` 并使用组织功能，请在该实例中添加此插件。
* `user`：包含用户详细信息的已认证用户对象

`Session` 和 `User` 类型由 Better Auth 包导出。

## 匹配规则 {/* #matching-rules */}

* `public` 和 `protected` 支持精确路径、通配符模式（如 `/api/*`）和路径参数（如 `/users/:id`）。
* 如需按 HTTP 方法匹配，请使用 `["/api/agents", ["GET", "POST"]]` 这样的元组。
* 如果路由同时匹配 `public` 和 `protected`，则以 `public` 为准，无需身份验证；但标记为 `requiresAuth: true` 的路由仍需验证。
* 如果两者都不匹配，位于 `/api/*` 下的路由（内置默认的 `protected` 模式），或通过 `registerApiRoute()` 注册且未标记为 `requiresAuth: false` 的自定义路由，仍需身份验证；其他路径则无需验证。
