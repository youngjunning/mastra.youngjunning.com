# MastraAuthBetterAuth 类

这`MastraAuthBetterAuth`类使用 Better Auth 为 Mastra 应用程序提供身份验证。它使用 Better Auth 会话验证传入请求，并使用`auth`选项。

## 使用示例 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraAuthBetterAuth } from '@mastra/auth-better-auth'
import { betterAuth } from 'better-auth'

// Create your Better Auth instance
const auth = betterAuth({
  database: {
    provider: 'postgresql',
    url: process.env.DATABASE_URL,
  },
  emailAndPassword: {
    enabled: true,
  },
  baseURL: process.env.BETTER_AUTH_URL,
  secret: process.env.BETTER_AUTH_SECRET,
})

export const mastra = new Mastra({
  server: {
    auth: new MastraAuthBetterAuth({
      auth,
    }),
  },
})
```

## `BetterAuthUser`类型 {/* #betterauthuser-type */}

这`BetterAuthUser` type contains the session and user information returned by Better Auth:

```typescript
interface BetterAuthUser {
  session: Session & { activeOrganizationId?: string | null }
  user: User
}
```

* `session`：包含会话元数据的 Better Auth 会话对象。`activeOrganizationId` comes from the organization plugin. The provider registers that plugin only on the instance it builds itself. When you pass `auth`, add the plugin to that instance if you use organization features.
* `user`：经过身份验证的用户对象，包含用户详细信息

这`Session` and `User` types are exported by the Better Auth package.

## 匹配规则 {/* #matching-rules */}

* `public`和`protected` accept exact paths, wildcard patterns (like `/api/*`), and path params (like `/users/:id`).
* 对于特定于方法的规则，请使用元组，例如`["/api/agents", ["GET", "POST"]]`.
* 如果一条路线与两者都匹配`public` and `protected`, `public` wins and no auth is required, unless the route is marked `requiresAuth: true`. Those routes still authenticate.
* 如果两者都不匹配，则路由在以下情况下需要身份验证`/api/*` (the built-in default `protected` pattern) or is a custom route registered with `registerApiRoute()` that isn't marked `requiresAuth: false`, and other paths don't require auth.
