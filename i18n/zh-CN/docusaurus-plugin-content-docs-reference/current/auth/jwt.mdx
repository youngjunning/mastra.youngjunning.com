# MastraJwtAuth 类

`MastraJwtAuth` 类通过 JSON Web Token（JWT）为 Mastra 提供轻量级身份验证机制。它使用共享密钥或 JSON Web Key Set（JWKS）端点提供的公钥验证传入请求，并通过 `auth` 选项接入 Mastra 服务器。

## 使用示例 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraJwtAuth } from '@mastra/auth'

export const mastra = new Mastra({
  server: {
    auth: new MastraJwtAuth({
      secret: '<your-secret>',
    }),
  },
})
```

要验证身份提供方签发的令牌，请传入其 JWKS URL 和签发方，而不是共享密钥：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraJwtAuth } from '@mastra/auth'

export const mastra = new Mastra({
  server: {
    auth: new MastraJwtAuth({
      jwksUri: 'https://auth.example.com/.well-known/jwks.json',
      issuer: 'https://auth.example.com/',
    }),
  },
})
```

## 用户 ID {/* #user-id */}

已认证用户的 `id` 取自令牌的 `id` 声明，或取自 `sub` 声明（当令牌没有 `id` 时）。RBAC 根据此 `id` 查找角色；除非设置了 `mapUserToResourceId`，用户创建的记录也归其所有。参见 [JWT 提供方的用户 ID](/docs/guides/authentication-identity#user-ids-from-jwt-providers)。
