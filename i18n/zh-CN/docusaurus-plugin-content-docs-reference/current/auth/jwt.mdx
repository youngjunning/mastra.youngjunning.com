# MastraJwtAuth 类

这`MastraJwtAuth`类使用 JSON Web 令牌 (JWT) 为 Mastra 提供轻量级身份验证机制。它使用共享密钥或来自 JSON Web 密钥集 (JWKS) 端点的公钥验证传入请求，并使用`auth`选项。

## 使用示例 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraJwtAuth } from '@mastra/auth'

export const mastra = new Mastra({
  server: {
    auth: new MastraJwtAuth({
      secret: '<your-secret>',
    }),
  },
})
```

要验证身份提供者签名的令牌，请传递其 JWKS URL 和颁发者而不是密钥：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraJwtAuth } from '@mastra/auth'

export const mastra = new Mastra({
  server: {
    auth: new MastraJwtAuth({
      jwksUri: 'https://auth.example.com/.well-known/jwks.json',
      issuer: 'https://auth.example.com/',
    }),
  },
})
```

## 用户身份 {/* #user-id */}

经过身份验证的用户的`id` is the token's `id` claim, or its `sub` claim when the token has no `id`. RBAC looks up roles by this `id`，并且它拥有用户创建的记录，除非`mapUserToResourceId`已设置。看[来自 JWT Provider的用户 ID](/docs/guides/authentication-identity#user-ids-from-jwt-providers).
