# MastraAuthOkta 和 MastraRBACOkta 类

## MastraAuthOkta 类 {/* #mastraauthokta-class */}

这`MastraAuthOkta` class provides authentication for Mastra using Okta. It implements an OAuth 2.0 / OIDC login flow with encrypted session cookies and integrates with the Mastra server using the `auth`选项。

### 使用示例 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraAuthOkta } from '@mastra/auth-okta'

export const mastra = new Mastra({
  server: {
    auth: new MastraAuthOkta({
      domain: process.env.OKTA_DOMAIN,
      clientId: process.env.OKTA_CLIENT_ID,
      clientSecret: process.env.OKTA_CLIENT_SECRET,
      redirectUri: process.env.OKTA_REDIRECT_URI,
    }),
  },
})
```

：：：笔记

如果设置了所需的环境变量，则可以省略构造函数参数。在这种情况下，使用`new MastraAuthOkta()` without any arguments.

:::

### 认证流程 {/* #authentication-flow */}

`MastraAuthOkta`按以下顺序验证请求：

1. **会话cookie**：读取加密的会话cookie并解密。如果会话有效且未过期，则用户通过身份验证。
2. **智威汤逊后备**：如果不存在会话 cookie，则验证`Authorization` header token against Okta's JWKS endpoint. The token's `iss` claim is checked against `issuer` and its `aud` claim against `audience`.

认证后，`authorizeUser` checks that the user has a valid `oktaId`. Provide a custom `authorizeUser` function to implement additional logic.

## MastraRBACOkta 类 {/* #mastrarbacokta-class */}

这`MastraRBACOkta` class maps Okta groups to Mastra permissions. It fetches user groups from the Okta API and resolves them against a configurable role mapping. Use it with `MastraAuthOkta` or any other auth provider.

：：：笔记

RBAC 在生产中需要 Mastra Enterprise Edition (EE) 许可证。它在开发过程中无需许可证即可运行。看[what requires an EE license](/docs/license#what-requires-an-ee-license). [Contact sales](https://mastra.ai/contact) for more information.

:::

### 使用示例 {/* #usage-example-1 */}

使用`MastraRBACOkta` alongside an auth provider by passing it to the `rbac` option:

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraAuthOkta, MastraRBACOkta } from '@mastra/auth-okta'

export const mastra = new Mastra({
  server: {
    auth: new MastraAuthOkta(),
    rbac: new MastraRBACOkta({
      roleMapping: {
        Admin: ['*'],
        Engineering: ['agents:*', 'workflows:*', 'tools:*'],
        Viewer: ['agents:read', 'workflows:read'],
        _default: [],
      },
    }),
  },
})
```

要将 Okta RBAC 与不同的身份验证提供程序一起使用，请传递`getUserId` function to resolve the Okta user ID from the other provider's user object:

```typescript title="src/mastra/index.ts"
import { MastraAuthAuth0 } from '@mastra/auth-auth0'
import { MastraRBACOkta } from '@mastra/auth-okta'
import { Mastra } from '@mastra/core'

export const mastra = new Mastra({
  server: {
    auth: new MastraAuthAuth0(),
    rbac: new MastraRBACOkta({
      getUserId: user => user.metadata?.oktaUserId || user.email,
      roleMapping: {
        Engineering: ['agents:*', 'workflows:*'],
        Admin: ['*'],
        _default: [],
      },
    }),
  },
})
```
