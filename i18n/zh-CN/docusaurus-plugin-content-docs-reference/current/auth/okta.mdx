# MastraAuthOkta 和 MastraRBACOkta 类

## MastraAuthOkta 类 {/* #mastraauthokta-class */}

`MastraAuthOkta` 类使用 Okta 为 Mastra 提供身份认证。它通过加密的会话 cookie 实现 OAuth 2.0 / OIDC 登录流程，并通过 `auth` 选项与 Mastra 服务器集成。

### 使用示例 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraAuthOkta } from '@mastra/auth-okta'

export const mastra = new Mastra({
  server: {
    auth: new MastraAuthOkta({
      domain: process.env.OKTA_DOMAIN,
      clientId: process.env.OKTA_CLIENT_ID,
      clientSecret: process.env.OKTA_CLIENT_SECRET,
      redirectUri: process.env.OKTA_REDIRECT_URI,
    }),
  },
})
```

:::note

如果已设置所需的环境变量，可以省略构造函数参数，直接使用 `new MastraAuthOkta()`。

:::

### 认证流程 {/* #authentication-flow */}

`MastraAuthOkta` 按以下顺序验证请求：

1. **会话 cookie**：读取并解密会话 cookie。会话有效且未过期时，用户通过身份认证。
2. **JWT 回退验证**：如果没有会话 cookie，则通过 Okta 的 JWKS 端点验证 `Authorization` 标头中的令牌。令牌的 `iss` 声明须与 `issuer` 匹配，`aud` 声明须与 `audience` 匹配。

身份认证后，`authorizeUser` 会检查用户是否具有有效的 `oktaId`。如需其他逻辑，请提供自定义的 `authorizeUser` 函数。

## MastraRBACOkta 类 {/* #mastrarbacokta-class */}

`MastraRBACOkta` 类将 Okta 群组映射到 Mastra 权限。它通过 Okta API 获取用户群组，并根据可配置的角色映射解析权限。它可与 `MastraAuthOkta` 或其他身份认证提供程序配合使用。

:::note

RBAC 在生产环境中需要 Mastra Enterprise Edition (EE) 许可证；开发环境无需许可证。详见[需要 EE 许可证的功能](/docs/license#what-requires-an-ee-license)。如需了解更多信息，请[联系销售团队](https://mastra.ai/contact)。

:::

### 使用示例 {/* #usage-example-1 */}

将 `MastraRBACOkta` 传给 `rbac` 选项，即可与身份认证提供程序配合使用：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraAuthOkta, MastraRBACOkta } from '@mastra/auth-okta'

export const mastra = new Mastra({
  server: {
    auth: new MastraAuthOkta(),
    rbac: new MastraRBACOkta({
      roleMapping: {
        Admin: ['*'],
        Engineering: ['agents:*', 'workflows:*', 'tools:*'],
        Viewer: ['agents:read', 'workflows:read'],
        _default: [],
      },
    }),
  },
})
```

若要将 Okta RBAC 与其他身份认证提供程序配合使用，请传入 `getUserId` 函数，从该提供程序的用户对象中取得 Okta 用户 ID：

```typescript title="src/mastra/index.ts"
import { MastraAuthAuth0 } from '@mastra/auth-auth0'
import { MastraRBACOkta } from '@mastra/auth-okta'
import { Mastra } from '@mastra/core'

export const mastra = new Mastra({
  server: {
    auth: new MastraAuthAuth0(),
    rbac: new MastraRBACOkta({
      getUserId: user => user.metadata?.oktaUserId || user.email,
      roleMapping: {
        Engineering: ['agents:*', 'workflows:*'],
        Admin: ['*'],
        _default: [],
      },
    }),
  },
})
```
