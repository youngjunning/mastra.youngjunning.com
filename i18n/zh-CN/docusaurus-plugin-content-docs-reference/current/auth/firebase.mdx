# MastraAuthFirebase 类

这`MastraAuthFirebase`类使用 Firebase 身份验证为 Mastra 提供身份验证。它使用 Firebase ID 令牌验证传入请求，并使用以下命令与 Mastra 服务器集成`auth`选项。

## 使用示例 {/* #usage-examples */}

### 环境变量的基本用法 {/* #basic-usage-with-environment-variables */}

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraAuthFirebase } from '@mastra/auth-firebase'

// Automatically uses FIREBASE_SERVICE_ACCOUNT and FIRESTORE_DATABASE_ID env vars
export const mastra = new Mastra({
  server: {
    auth: new MastraAuthFirebase(),
  },
})
```

### 自定义配置 {/* #custom-configuration */}

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraAuthFirebase } from '@mastra/auth-firebase'

export const mastra = new Mastra({
  server: {
    auth: new MastraAuthFirebase({
      serviceAccount: '/path/to/service-account-key.json',
      databaseId: 'your-database-id',
    }),
  },
})
```

## 默认授权行为 {/* #default-authorization-behavior */}

默认情况下，`MastraAuthFirebase` uses Firestore to manage user access:

1. 成功验证 Firebase ID 令牌后，`authorizeUser` method is called
2. 它检查文件中是否存在`user_access` collection with the user's UID as the document ID
3. 如果该文档存在，则用户被授权；否则，访问被拒绝
4. 使用的 Firestore 数据库由以下因素决定`databaseId` parameter or environment variables

## Firebase 用户类型 {/* #firebase-user-type */}

这`FirebaseUser` type used in the `authorizeUser` function corresponds to Firebase's `DecodedIdToken` interface, which includes:

* `uid`：用户的唯一标识符
* `email`：用户的电子邮件地址（如果有）
* `email_verified`: 邮箱是否验证
* `name`：用户的显示名称（如果有）
* `picture`：用户个人资料图片的 URL（如果有）
* `auth_time`: 当用户认证时
* 以及其他标准 JWT 声明
