# MastraAuthFirebase 类

`MastraAuthFirebase` 类通过 Firebase Authentication 为 Mastra 提供身份验证。它使用 Firebase ID 令牌验证传入的请求，并通过 `auth` 选项与 Mastra 服务器集成。

## 使用示例 {/* #usage-examples */}

### 环境变量的基本用法 {/* #basic-usage-with-environment-variables */}

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraAuthFirebase } from '@mastra/auth-firebase'

// Automatically uses FIREBASE_SERVICE_ACCOUNT and FIRESTORE_DATABASE_ID env vars
export const mastra = new Mastra({
  server: {
    auth: new MastraAuthFirebase(),
  },
})
```

### 自定义配置 {/* #custom-configuration */}

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraAuthFirebase } from '@mastra/auth-firebase'

export const mastra = new Mastra({
  server: {
    auth: new MastraAuthFirebase({
      serviceAccount: '/path/to/service-account-key.json',
      databaseId: 'your-database-id',
    }),
  },
})
```

## 默认授权行为 {/* #default-authorization-behavior */}

默认情况下，`MastraAuthFirebase` 使用 Firestore 管理用户访问权限：

1. 成功验证 Firebase ID 令牌后，调用 `authorizeUser` 方法
1. 检查 `user_access` 集合中是否存在以用户 UID 为文档 ID 的文档
1. 如果文档存在，则授权该用户；否则拒绝访问
1. 使用的 Firestore 数据库由 `databaseId` 参数或环境变量决定

## Firebase 用户类型 {/* #firebase-user-type */}

`FirebaseUser` 类型用于 `authorizeUser` 函数，对应 Firebase 的 `DecodedIdToken` 接口，其中包括：

- `uid`：用户的唯一标识符
- `email`：用户的电子邮箱地址（如果有）
- `email_verified`：邮箱是否已验证
- `name`：用户的显示名称（如果有）
- `picture`：用户头像的 URL（如果有）
- `auth_time`：用户完成身份验证的时间
- 以及其他标准 JWT 声明
