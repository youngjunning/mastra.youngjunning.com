# rerank()

`rerank()` 结合语义相关性、向量相似度和位置得分，对向量搜索结果进行重新排序。

```typescript
function rerank(
  results: QueryResult[],
  query: string,
  model: MastraLanguageModel,
  options: RerankerFunctionOptions,
): Promise<RerankResult[]>
```

## 使用示例 {/* #usage-example */}

```typescript
import { ModelRouterLanguageModel } from '@mastra/core/llm'
import { rerank } from '@mastra/rag'

const model = new ModelRouterLanguageModel('__GATEWAY_OPENAI_MODEL__')

const rerankedResults = await rerank(vectorSearchResults, 'How do I deploy to production?', model, {
  weights: {
    semantic: 0.5,
    vector: 0.3,
    position: 0.2,
  },
  topK: 3,
})
```

rerank 可以使用 Vercel AI SDK 中的任意 LanguageModel。使用 Cohere 的 `rerank-v3.5` 模型时，会自动调用 Cohere 的重排序能力。

:::note

要正确计算语义相关性得分，每条结果的 `metadata.text` 字段都必须包含文本内容。

:::
