# 重新排名（）

这`rerank()`函数通过结合语义相关性、向量相似性和基于位置的评分，为向量搜索结果提供高级重新排序功能。

```typescript
function rerank(
  results: QueryResult[],
  query: string,
  model: MastraLanguageModel,
  options: RerankerFunctionOptions,
): Promise<RerankResult[]>
```

## 使用示例 {/* #usage-example */}

```typescript
import { ModelRouterLanguageModel } from '@mastra/core/llm'
import { rerank } from '@mastra/rag'

const model = new ModelRouterLanguageModel('__GATEWAY_OPENAI_MODEL__')

const rerankedResults = await rerank(vectorSearchResults, 'How do I deploy to production?', model, {
  weights: {
    semantic: 0.5,
    vector: 0.3,
    position: 0.2,
  },
  topK: 3,
})
```

rerank 函数接受 Vercel AI SDK 中的任何 LanguageModel。使用 Cohere 模型时`rerank-v3.5`, it will automatically use Cohere's reranking capabilities.

：：：笔记

为了使语义评分在重新排名期间正常工作，每个结果必须包含其文本内容`metadata.text` field.
