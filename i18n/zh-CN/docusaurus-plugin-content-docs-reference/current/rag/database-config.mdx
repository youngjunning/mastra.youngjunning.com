# 数据库配置

这`DatabaseConfig`type 允许您在使用矢量查询Tool时指定特定于数据库的配置。这些配置使您能够使用不同矢量商店提供的功能和优化。

## 类型定义 {/* #type-definition */}

```typescript
export type DatabaseConfig = {
  pinecone?: PineconeConfig
  pgvector?: PgVectorConfig
  chroma?: ChromaConfig
  mongodb?: MongoDBConfig
  turbopuffer?: TurbopufferConfig
  [key: string]: any // Extensible for future databases
}
```

* **埃夫**：从 topK 值的 2-4 倍开始，增加以获得更好的准确性
* **探针**：从 1-10 开始，增加以更好地回忆
* **最低得分**：根据您的质量要求使用 0.5-0.9 之间的值

**使用案例：**

* 高负载场景的性能优化
* 质量过滤以删除不相关的结果
* 微调搜索精度与速度的权衡

    // Initial configuration
    const vectorTool = createVectorQueryTool({
      vectorStoreName: 'pinecone',

        namespace: 'production',
      },
    })

  <TabItem value="multi-database" label="Multi-Database">
    ### 多数据库配置 {/* #multi-database-configuration */}

    ```typescript
    import { RequestContext } from '@mastra/core/request-context'

    const vectorTool = createVectorQueryTool({
      vectorStoreName: 'pinecone',
      indexName: 'documents',
      model: embedModel,
    })

    // Select the store per request and pass only its matching config block
    const pineconeContext = new RequestContext()
    pineconeContext.set('vectorStoreName', 'pinecone')
    pineconeContext.set('databaseConfig', {
      pinecone: { namespace: 'default' },
    })

    const pgVectorContext = new RequestContext()
    pgVectorContext.set('vectorStoreName', 'pgVector')
    pgVectorContext.set('databaseConfig', {
      pgvector: { minScore: 0.8, ef: 150 },
    })

    await vectorTool.execute({ queryText: 'search query' }, { mastra, requestContext: pgVectorContext })
    ```

    ：：：笔记

    **多数据库支持**：无论查询哪个向量存储，您配置的每个数据库块的设置都会合并到查询参数中。共享密钥适用于运行查询的任何商店。例如，`pgvector.minScore` is passed as `minScore`, which other stores such as LibSQL also read to filter results. Pass only the block for the vector store you query.

    :::
  </TabItem>

## 可扩展性 {/* #extensibility */}

这`DatabaseConfig` type is designed to be extensible. To add support for a new vector database:

```typescript
// 1. Define the configuration interface
export interface NewDatabaseConfig {
  customParam1?: string
  customParam2?: number
}

// 2. Extend DatabaseConfig type
export type DatabaseConfig = {
  pinecone?: PineconeConfig
  pgvector?: PgVectorConfig
  chroma?: ChromaConfig
  newdatabase?: NewDatabaseConfig
  [key: string]: any
}

// 3. Use in vector query tool
const vectorTool = createVectorQueryTool({
  vectorStoreName: 'newdatabase',
  indexName: 'documents',
  model: embedModel,
  databaseConfig: {
    newdatabase: {
      customParam1: 'value',
      customParam2: 42,
    },
  },
})
```

## 最佳实践 {/* #best-practices */}

1. **环境配置**：针对不同的环境使用不同的命名空间或配置
2. **性能调优**：从默认值开始，然后根据您的具体需求进行调整
3. **质量过滤**：使用minScore过滤掉低质量结果
4. **运行时灵活性**：在运行时覆盖运行时定义的场景的配置
5. **文档**：为团队成员记录您的具体配置选择

## 迁移指南 {/* #migration-guide */}

现有的矢量查询Tool无需更改即可继续工作。添加数据库配置：

```diff
const vectorTool = createVectorQueryTool({
  vectorStoreName: 'pinecone',
  indexName: 'documents',
  model: embedModel,
+ databaseConfig: {
+   pinecone: {
+     namespace: 'production'
+   }
+ }
});
```
