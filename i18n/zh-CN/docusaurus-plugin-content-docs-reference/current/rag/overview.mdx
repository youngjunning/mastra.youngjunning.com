# Mastra 中的 RAG（检索增强生成）

Mastra 的 RAG 会引入自有数据源中的相关上下文，以增强 LLM 输出、提高准确性，并让回答以真实信息为依据。

Mastra 的 RAG 系统提供：

- 用于处理文档并生成 embedding 的标准化 API
- 对多种向量存储的支持
- 用于优化检索的分块与 embedding 策略
- 用于跟踪 embedding 与检索性能的可观测性

## 示例 {/* #example */}

实现 RAG 时，需要将文档处理为分块、生成 embedding 并存入向量数据库，然后在查询时检索相关上下文。

```ts
import { embedMany } from 'ai'
import { PgVector } from '@mastra/pg'
import { MDocument } from '@mastra/rag'
import { z } from 'zod'

// 1. Initialize document
const doc = MDocument.fromText(`Your document text here...`)

// 2. Create chunks
const chunks = await doc.chunk({
  strategy: 'recursive',
  size: 512,
  overlap: 50,
})

// 3. Generate embeddings; we need to pass the text of each chunk
import { ModelRouterEmbeddingModel } from '@mastra/core/llm'

const { embeddings } = await embedMany({
  values: chunks.map(chunk => chunk.text),
  model: new ModelRouterEmbeddingModel('openai/text-embedding-3-small'),
})

// 4. Store in vector database
const pgVector = new PgVector({
  id: 'pg-vector',
  connectionString: process.env.POSTGRES_CONNECTION_STRING,
})
await pgVector.upsert({
  indexName: 'embeddings',
  vectors: embeddings,
}) // using an index name of 'embeddings'

// 5. Query similar chunks
const results = await pgVector.query({
  indexName: 'embeddings',
  queryVector: queryVector,
  topK: 3,
}) // queryVector is the embedding of the query

console.log('Similar chunks:', results)
```

此示例展示了基本流程：初始化文档并创建分块，然后生成并存储 embedding，最后查询相似内容。

## 文档处理 {/* #document-processing */}

文档处理是 RAG 的基本构成。可以使用递归、滑动窗口等策略对文档分块，并用元数据加以丰富。请参阅[分块与 embedding 文档](../../reference/rag/chunking-and-embedding)。

## 向量存储 {/* #vector-storage */}

Mastra 支持多种用于持久化 embedding 和相似度搜索的向量存储，包括 pgvector、OracleDB、Pinecone、Qdrant 和 MongoDB。请参阅[向量数据库文档](./vector-databases)。
