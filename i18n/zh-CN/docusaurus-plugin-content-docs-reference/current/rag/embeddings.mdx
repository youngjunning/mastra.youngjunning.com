# 嵌入

Mastra 使用 AI SDK`embed`和`embedMany`为文本输入生成向量嵌入的函数，从而实现相似性搜索和 RAG Workflow程。

## 支持的嵌入模型 {/* #supported-embedding-models */}

内存和 RAG 向量查询Tool接受具有规范版本的嵌入模型`v1`, `v2`, `v3`, and `v4`。 Mastra 从模型中选择匹配的 AI SDK 实现`specificationVersion`。现有型号配置保持不变。

对于直接调用，请使用匹配的导出`@mastra/core/vector`: `embedV1`, `embedV2`, `embedV3`, or `embedV4`. For example, an AI SDK v7 provider exposes a specification `v4`嵌入模型：

```typescript
import { openai } from '@ai-sdk/openai'
import { embedV4 } from '@mastra/core/vector'

const { embedding } = await embedV4({
  model: openai.embedding('text-embedding-3-small'),
  value: 'Your text to embed',
})
```

这个例子需要`@ai-sdk/openai` v4. The model specification version and AI SDK package version are different: AI SDK v4 uses embedding specification `v1`, v5 uses `v2`, v6 uses `v3`, and v7 uses `v4`.

## 单次嵌入 {/* #single-embedding */}

这`embed` function generates a vector embedding for a single text input:

```typescript
import { embed } from 'ai'
import { ModelRouterEmbeddingModel } from '@mastra/core/llm'

const result = await embed({
  model: new ModelRouterEmbeddingModel('openai/text-embedding-3-small'),
  value: 'Your text to embed',
  maxRetries: 2, // optional, defaults to 2
})
```

## 多重嵌入 {/* #multiple-embeddings */}

要一次嵌入多个文本，请使用`embedMany` function:

```typescript
import { embedMany } from 'ai'

const result = await embedMany({
  model: new ModelRouterEmbeddingModel('openai/text-embedding-3-small'),
  values: ['First text', 'Second text', 'Third text'],
  maxRetries: 2, // optional, defaults to 2
})
```

## 用法示例 {/* #example-usage */}

```typescript
import { embed, embedMany } from 'ai'

// Single embedding
const singleResult = await embed({
  model: new ModelRouterEmbeddingModel('openai/text-embedding-3-small'),
  value: 'What is the meaning of life?',
})

// Multiple embeddings
const multipleResult = await embedMany({
  model: new ModelRouterEmbeddingModel('openai/text-embedding-3-small'),
  values: [
    'First question about life',
    'Second question about universe',
    'Third question about everything',
  ],
})
```
