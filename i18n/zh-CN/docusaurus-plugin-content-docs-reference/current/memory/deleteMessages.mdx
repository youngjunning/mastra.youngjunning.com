# Memory.deleteMessages()

`.deleteMessages()` 按消息 ID 批量删除消息。

## 使用示例 {/* #usage-example */}

```typescript
await memory?.deleteMessages(['671ae63f-3a91-4082-a907-fe7de78e10ec'])

// You can also pass message objects with an `id` property
await memory?.deleteMessages([{ id: '671ae63f-3a91-4082-a907-fe7de78e10ec' }])
```

## 更多用法示例 {/* #extended-usage-example */}

```typescript title="src/test-memory.ts"
import { mastra } from './mastra'
import type { MastraDBMessage } from '@mastra/core/agent'

const agent = mastra.getAgent('agent')
const memory = await agent.getMemory()

const { messages } = await memory!.recall({ threadId: 'thread-123' })

const messageIds = messages.map((message: MastraDBMessage) => message.id)
await memory?.deleteMessages([...messageIds])
```
