# SerializedMemoryConfig

`SerializedMemoryConfig` 是 [`Memory`](/reference/memory/memory-class) 配置中可序列化为 JSON 的部分，存储在 Agent 记录中。运行时会将其还原为 `Memory` 实例，所需的向量存储和嵌入模型 ID 则通过已配置的 `Mastra` 实例解析。

[`BuilderAgentDefaults.memory`](https://agent-builder.mastra.ai/reference/builder-agent-defaults) 和 `EditorAgentNamespace.create({ memory })` 都使用此类型。

## 使用示例 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { MastraEditor } from '@mastra/editor'

new MastraEditor({
  builder: {
    enabled: true,
    configuration: {
      agent: {
        memory: {
          observationalMemory: true,
          options: { lastMessages: 50 },
        },
      },
    },
  },
})
```
