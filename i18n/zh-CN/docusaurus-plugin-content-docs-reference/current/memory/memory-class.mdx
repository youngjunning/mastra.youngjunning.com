# Memory 类

`Memory` 类提供可靠的对话历史与线程消息管理能力，支持持久化存储、语义搜索和高效检索。必须为对话历史配置存储提供方；启用语义召回时，还需提供向量存储。如果向量存储本身不负责文本嵌入，则还需配置嵌入模型。

## 使用示例 {/* #usage-example */}

```typescript title="src/mastra/agents/test-agent.ts"
import { Memory } from '@mastra/memory'
import { Agent } from '@mastra/core/agent'

export const agent = new Agent({
  id: 'test-agent',
  name: 'test-agent',
  instructions: 'You are an agent with memory.',
  model: '__GATEWAY_OPENAI_MODEL__',
  memory: new Memory({
    options: {
      workingMemory: {
        enabled: true,
      },
    },
  }),
})
```

:::note

要为 Agent 启用 `workingMemory`，必须在主 Mastra 实例上配置存储提供方。详情参见 [Mastra 类](../core/mastra-class)。

:::

## `saveMessages()` {/* #savemessages */}

`agent.generate()` 和 `agent.stream()` 会自动持久化消息。需要自行写入消息时，例如预置线程、导入对话记录或保存来自 Mastra 之外的消息，请调用 `memory.saveMessages()`。每条消息都需要 `threadId` 和 `resourceId`，因此应先通过 [`createThread()`](/reference/memory/createThread) 创建线程，再保存消息。

```typescript
await memory.saveMessages({
  messages: [
    {
      id: 'msg-1',
      threadId: 'thread-123',
      resourceId: 'user-456',
      role: 'user',
      createdAt: new Date(),
      content: {
        format: 2,
        parts: [{ type: 'text', text: 'Where is my order?' }],
      },
    },
  ],
})
```

### `MastraDBMessage` {/* #mastradbmessage */}

存储层统一使用 `MastraDBMessage` 消息结构。接收或返回消息的方法（包括 `saveMessages()` 和 [`recall()`](/reference/memory/recall)）都使用这一结构。

`content.parts` 是 Agent 实际读取的内容。已存储消息的 `content.format` 始终为 `2`，`content.metadata` 可保存任意自定义数据。`content.toolInvocations`、`content.reasoning` 和 `content.experimental_attachments` 是为兼容 AI SDK v4 保留的扁平镜像字段；写入内容时应使用 `parts`。

```typescript
const assistantMessage = {
  id: 'msg-2',
  threadId: 'thread-123',
  resourceId: 'user-456',
  role: 'assistant',
  createdAt: new Date(),
  content: {
    format: 2,
    parts: [
      { type: 'text', text: 'It ships tomorrow.' },
      {
        type: 'tool-invocation',
        toolInvocation: {
          state: 'result',
          toolCallId: 'call-1',
          toolName: 'lookupOrder',
          args: { orderId: 'A-1' },
          result: { eta: '2026-10-30' },
        },
      },
    ],
    metadata: { source: 'import' },
  },
}
```

## 扩展使用示例 {/* #extended-usage-example */}

```typescript title="src/mastra/agents/test-agent.ts"
import { Memory } from '@mastra/memory'
import { Agent } from '@mastra/core/agent'
import { LibSQLStore, LibSQLVector } from '@mastra/libsql'

export const agent = new Agent({
  name: 'test-agent',
  instructions: 'You are an agent with memory.',
  model: '__GATEWAY_OPENAI_MODEL__',
  memory: new Memory({
    storage: new LibSQLStore({
      id: 'test-agent-storage',
      url: 'file:./working-memory.db',
    }),
    vector: new LibSQLVector({
      id: 'test-agent-vector',
      url: 'file:./vector-memory.db',
    }),
    options: {
      lastMessages: 10,
      semanticRecall: {
        topK: 3,
        messageRange: 2,
        scope: 'resource',
      },
      workingMemory: {
        enabled: true,
      },
      generateTitle: true,
    },
  }),
})
```

## 带有索引配置的 PostgreSQL {/* #postgresql-with-index-configuration */}

```typescript title="src/mastra/agents/pg-agent.ts"
import { Memory } from '@mastra/memory'
import { Agent } from '@mastra/core/agent'
import { ModelRouterEmbeddingModel } from '@mastra/core/llm'
import { PostgresStore, PgVector } from '@mastra/pg'

export const agent = new Agent({
  name: 'pg-agent',
  instructions: 'You are an agent with optimized PostgreSQL memory.',
  model: '__GATEWAY_OPENAI_MODEL__',
  memory: new Memory({
    storage: new PostgresStore({
      id: 'pg-agent-storage',
      connectionString: process.env.DATABASE_URL,
    }),
    vector: new PgVector({
      id: 'pg-agent-vector',
      connectionString: process.env.DATABASE_URL,
    }),
    embedder: new ModelRouterEmbeddingModel('openai/text-embedding-3-small'),
    options: {
      lastMessages: 20,
      semanticRecall: {
        topK: 5,
        messageRange: 3,
        scope: 'resource',
        indexConfig: {
          type: 'hnsw', // Use HNSW for better performance
          metric: 'dotproduct', // Optimal for OpenAI embeddings
          hnsw: {
            m: 16, // Number of bi-directional links
            efConstruction: 64, // Construction-time candidate list size
          },
        },
      },
      workingMemory: {
        enabled: true,
      },
    },
  }),
})
```
