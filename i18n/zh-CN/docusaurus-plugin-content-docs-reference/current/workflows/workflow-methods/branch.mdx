# Workflow.branch()

这`.branch()`方法在Workflow程步骤之间创建条件分支，允许根据上一步的结果采取不同的路径。每个分支的条件评估为`true`运行；条件是独立评估的，因此重叠条件运行多个分支。当只应运行一个分支时，请使用互斥条件。

## 使用示例 {/* #usage-example */}

```typescript
workflow.branch([
  [async () => true, step1],
  [async () => false, step2],
])
```
