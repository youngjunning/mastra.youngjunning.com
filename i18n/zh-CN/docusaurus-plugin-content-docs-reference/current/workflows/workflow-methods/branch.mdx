# Workflow\.branch()

`.branch()` 方法在 Workflow 步骤之间创建条件分支，可根据上一步结果选择不同路径。所有条件为 `true` 的分支都会运行；各条件独立求值，因此重叠条件会运行多个分支。只应运行一个分支时，请使用互斥条件。

## 使用示例 {/* #usage-example */}

```typescript
workflow.branch([
  [async () => true, step1],
  [async () => false, step2],
])
```
