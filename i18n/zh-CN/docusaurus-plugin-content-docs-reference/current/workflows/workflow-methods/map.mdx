# Workflow程.map()

这`.map()`方法将上一步的输出数据映射到后续步骤的输入，从而允许您在步骤之间转换数据。

## 使用示例 {/* #usage-example */}

```typescript
workflow.map(async ({ inputData }) => `${inputData.value} - map`)
```

## 使用`inputData` {/* #using-inputdata */}

使用`inputData` to access the full output of the previous step.

```typescript {3} filename="src/mastra/workflows/test-workflow.ts" oxfmt:false
  .then(step1)
  .map(async ({ inputData }) => {
    console.log(inputData);
  })
```

## 使用`getStepResultAsync()` {/* #using-getstepresultasync */}

使用`getStepResultAsync()` to access the full output of a specific step by referencing the step's instance or its ID.

```typescript {3} filename="src/mastra/workflows/test-workflow.ts" oxfmt:false
  .then(step1)
  .map(async ({ getStepResultAsync }) => {
    console.log(await getStepResultAsync(step1));
  })
```

`getStepResultAsync()`替换已弃用的`getStepResult()`, which returns the same value synchronously.

## 使用`getInitData()` {/* #using-getinitdata */}

使用`getInitData<typeof workflow>()` to access the initial input data provided to the workflow.

```typescript oxfmt:false {3} filename="src/mastra/workflows/test-workflow.ts"
  .then(step1)
  .map(async ({ getInitData }) => {
    console.log(getInitData<any>());
  })
```

## 使用`mapVariable()` {/* #using-mapvariable */}

对象形式为`.map()` provides an alternative declarative syntax for mapping fields. Instead of writing a function, you define an object where each key is a new field name and each value uses `mapVariable()` to extract data from previous steps or workflow input.
Import `mapVariable()` from the workflows module:

```typescript filename="src/mastra/workflows/test-workflow.ts"
import { mapVariable } from '@mastra/core/workflows'
```

### 从步骤输出中提取字段 {/* #extracting-fields-from-step-outputs */}

使用`mapVariable()` with `step` to extract a specific field from a step's output and map it to a new field name. The `path` parameter specifies which field to extract.
In this example, the `value` field from `step1`'s output is extracted and mapped to a new field called `details`:

```typescript oxfmt:false {3-6} filename="src/mastra/workflows/test-workflow.ts"
  .then(step1)
  .map({
    details: mapVariable({
      step: step1,
      path: "value"
    })
  })
```

### 从Workflow输入中提取字段 {/* #extracting-fields-from-workflow-input */}

使用`mapVariable()` with `initData` to extract a specific field from the workflow's initial input data. This is useful when you need to pass the original workflow input to a later step.
In this example, the `value` field from the workflow's input is extracted and mapped to a field called `details`:

```typescript oxfmt:false {8-11} filename="src/mastra/workflows/test-workflow.ts"
import { createWorkflow } from '@mastra/core/workflows';

export const testWorkflow = createWorkflow({...});

testWorkflow
  .then(step1)
  .map({
    details: mapVariable({
      initData: testWorkflow,
      path: "value"
    })
  })
```
