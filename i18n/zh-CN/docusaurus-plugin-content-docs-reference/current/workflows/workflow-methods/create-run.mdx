# Workflow.createRun()

这`.createRun()`方法创建一个新的Workflow运行实例，允许您使用特定的输入数据执行Workflow。它返回一个承诺，该承诺解析为`Run`实例。

## 使用示例 {/* #usage-example */}

```typescript
await workflow.createRun()
```

## 扩展使用示例 {/* #extended-usage-example */}

```typescript
const workflow = mastra.getWorkflow('workflow')

const run = await workflow.createRun()

const result = await run.start({
  inputData: {
    value: 10,
  },
})
```

## 使用`resourceId` {/* #using-resourceid */}

这`resourceId` parameter associates a workflow run with a specific resource, such as a user or tenant. This is useful for multi-tenant applications or when you need to track which user initiated a workflow.

```typescript
const workflow = mastra.getWorkflow('workflow')

// Create a run associated with a specific user
const run = await workflow.createRun({
  resourceId: 'user-123',
})

const result = await run.start({
  inputData: {
    value: 10,
  },
})

// Later, retrieve the run and access the resourceId
const storedRun = await workflow.getWorkflowRunById(run.runId)
console.log(storedRun.resourceId) // "user-123"
```
