# Workflow\.dowhile()

这`.dowhile()`方法在满足条件时执行步骤。在评估条件之前，它始终至少运行该步骤一次。第一次评估条件时，`iterationCount`是`1`.

## 使用示例 {/* #usage-example */}

```typescript
workflow.dowhile(step1, async ({ inputData }) => true)
```
