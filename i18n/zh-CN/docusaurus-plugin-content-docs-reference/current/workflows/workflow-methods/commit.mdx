# Workflow.commit()

`.commit()` 定稿 Workflow 定义，使其可执行。添加步骤后、创建运行实例前调用此方法。如果 Workflow 还有未提交的步骤变更，创建运行实例时会抛出错误。

## 使用示例 {/* #usage-example */}

```typescript
workflow.then(step1).commit()
```
