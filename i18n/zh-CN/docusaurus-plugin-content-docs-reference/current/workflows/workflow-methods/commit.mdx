# Workflow程.commit()

这`.commit()`方法最终确定Workflow定义并准备执行。添加步骤之后、创建运行之前调用它。在具有未提交步骤更改的Workflow上创建运行会引发错误。

## 使用示例 {/* #usage-example */}

```typescript
workflow.then(step1).commit()
```
