# Workflow\.foreach()

`.foreach()` 方法创建循环，对数组中的每个元素执行一个步骤。它始终返回各次迭代输出组成的数组，并保留输入元素的原始顺序。

## 使用示例 {/* #usage-example */}

```typescript
workflow.foreach(step1, { concurrency: 2 })
```

## 行为 {/* #behavior */}

### 执行与等待 {/* #execution-and-waiting */}

无论并发设置如何，`.foreach()` 都会先处理完所有元素，再执行下一个步骤。默认的 `concurrency: 1` 会顺序处理元素；较大的值会分批并行处理，但下一个步骤仍须等待所有批次完成。

如果每个元素都需要执行多项操作，请使用嵌套 Workflow 作为步骤。这样可以将同一元素的操作放在一起，比串联多个 `.foreach()` 调用更清晰。示例参见 [foreach 中的嵌套 Workflow](/docs/workflows/control-flow#nested-workflows-inside-foreach)。

### 输出结构 {/* #output-structure */}

`.foreach()` 始终输出数组。输出数组中的每个元素，对应输入数组中相同索引的元素的处理结果。

```typescript
// Input: [{ value: 1 }, { value: 2 }, { value: 3 }]
// Step adds 10 to each value
// Output: [{ value: 11 }, { value: 12 }, { value: 13 }]
```

### 在 `.foreach()` 后使用 `.then()` {/* #using-then-after-foreach */}

在 `.foreach()` 后链式调用 `.then()` 时，下一个步骤会将整个输出数组作为输入。可以在该步骤中汇总或统一处理所有结果。

```typescript
workflow
  .foreach(processItemStep) // Output: array of processed items
  .then(aggregateStep) // Input: the entire array
  .commit()
```

### 在 `.foreach()` 后使用 `.map()` {/* #using-map-after-foreach */}

使用 `.map()` 转换输出数组，再将结果传给下一个步骤：

```typescript
workflow
  .foreach(processItemStep)
  .map(async ({ inputData }) => ({
    total: inputData.reduce((sum, item) => sum + item.value, 0),
    count: inputData.length,
  }))
  .then(nextStep)
  .commit()
```

### 链式调用多个 `.foreach()` {/* #chaining-multiple-foreach-calls */}

链式调用多个 `.foreach()` 时，每次调用都会处理上一步输出的数组：

```typescript
workflow
  .foreach(stepA) // If input is [a, b, c], output is [A, B, C]
  .foreach(stepB) // Operates on [A, B, C], output is [A', B', C']
  .commit()
```

如果 `.foreach()` 内的步骤返回数组，整体输出就会成为二维数组。使用 `.map()` 配合 `.flat()` 将其展平：

```typescript
workflow
  .foreach(chunkStep) // Output: [[chunk1, chunk2], [chunk3, chunk4]]
  .map(async ({ inputData }) => inputData.flat()) // Output: [chunk1, chunk2, chunk3, chunk4]
  .foreach(embedStep)
  .commit()
```

### 流式执行时的进度事件 {/* #progress-events-during-streaming */}

使用 `run.stream()` 时，foreach 步骤会在每次迭代完成后发出 `workflow-step-progress` 事件。无需等待整个 foreach 结束，就能实时跟踪进度。

```typescript
const run = await workflow.createRun()
const stream = run.stream({ inputData })

for await (const chunk of stream) {
  if (chunk.type === 'workflow-step-progress') {
    console.log(`${chunk.payload.completedCount}/${chunk.payload.totalCount}`)
    // e.g. "1/3", "2/3", "3/3"
  }
}
```

### 恢复单次迭代 {/* #resuming-a-single-iteration */}

当 `.foreach()` 内的步骤暂停时，各次迭代会分别暂停。向 [`run.resume()`](../run-methods/resume) 传入 `forEachIndex`，即可使用对应的 `resumeData` 一次恢复一项迭代。省略 `forEachIndex` 则会用同一份数据恢复所有已暂停的迭代。

```typescript
await run.resume({
  step: 'approve',
  resumeData: { ok: true },
  forEachIndex: 1,
})
```
