# Workflow程.Tool()

这`.tool()`方法添加一个Tool作为声明性步骤。应用Tool自己的输入和输出模式，因此上一步的输出必须满足Tool的输入模式。使用`.map()`如果数据不匹配，则转换数据。

与包装Tool不同`createStep()`, `.tool()` records a declarative entry in the workflow graph. This makes the workflow portable: the same graph can be serialized and persisted as a [dynamic workflow](/docs/workflows/dynamic-workflows).

## 使用示例 {/* #usage-example */}

```typescript filename="src/mastra/workflows/test-workflow.ts"
workflow.tool(testTool).commit()
```

## 通过 ID 引用Tool {/* #referencing-a-tool-by-id */}

传递一个字符串来引用已注册的Tool而不导入它。当Workflow程运行时，必须在 Mastra 实例上注册该Tool：

```typescript filename="src/mastra/workflows/test-workflow.ts"
workflow.tool('lookup-customer', { retries: 2 }).commit()
```

## 保留Tool步骤 {/* #persisting-tool-steps */}

Workflow程构建`.tool()` serialize to the same declarative entries that [dynamic workflows](/docs/workflows/dynamic-workflows) use. Only `retries` and `metadata` round-trip through storage. A function-valued `scorers` option throws an error when the workflow is stored.
