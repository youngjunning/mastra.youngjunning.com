# Workflow\.tool()

`.tool()` 方法将 Tool 添加为声明式步骤。该 Tool 自身的输入和输出 schema 仍然适用，因此上一步的输出必须满足 Tool 的输入 schema。如两者不匹配，请使用 `.map()` 转换数据。

与使用 `createStep()` 包装 Tool 不同，`.tool()` 会在 Workflow 图中记录一个声明式条目。这使 Workflow 具备可移植性：同一个图可以序列化并持久化为[动态 Workflow](/docs/workflows/dynamic-workflows)。

## 使用示例 {/* #usage-example */}

```typescript filename="src/mastra/workflows/test-workflow.ts"
workflow.tool(testTool).commit()
```

## 通过 ID 引用 Tool {/* #referencing-a-tool-by-id */}

传入字符串即可引用已注册的 Tool，无需导入它。Workflow 运行时，该 Tool 必须已注册到 Mastra 实例：

```typescript filename="src/mastra/workflows/test-workflow.ts"
workflow.tool('lookup-customer', { retries: 2 }).commit()
```

## 持久化 Tool 步骤 {/* #persisting-tool-steps */}

使用 `.tool()` 构建的 Workflow 会序列化为[动态 Workflow](/docs/workflows/dynamic-workflows)所使用的相同声明式条目。只有 `retries` 和 `metadata` 能完整经过存储往返；如果 `scorers` 是函数值，存储 Workflow 时会抛出错误。
