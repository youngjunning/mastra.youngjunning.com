# Workflow\.classifier()

`.classifier()` 方法将已配置的 [`Classifier`](/reference/classifier/classifier) 添加为声明式 Workflow 步骤，并返回可继续链式调用的 Workflow。该步骤输出可安全序列化为 JSON 的 `{ answers, usage }` 对象，供后续步骤和 [`.branch()`](/reference/workflows/workflow-methods/branch) 等现有控制流方法使用。

## 使用示例 {/* #usage-example */}

```typescript filename="src/mastra/workflows/ticket-triage.ts"
import { createWorkflow } from '@mastra/core/workflows'
import { z } from 'zod'

const workflow = createWorkflow({
  id: 'ticket-triage',
  inputSchema: z.object({ message: z.string() }),
  outputSchema: z.any(),
})
  .map({ message: { initData: true, path: 'message' } })
  .classifier(router)
  .branch([
    [async ({ inputData }) => inputData.answers.route.choice === 'billing', billingStep],
    [async ({ inputData }) => inputData.answers.route.choice === 'support', supportStep],
    [async () => true, fallbackStep],
  ])
  .commit()
```

传入 Classifier 实例后，下游步骤可推断问题键和选项字面量类型。Classifier 的问题必须在构造时配置。

## 输入映射 {/* #input-mapping */}

Classifier 会评估上一步的完整输出。可插入 [`.map()`](/reference/workflows/workflow-methods/map) 并置于 `.classifier()` 之前，以选择或调整输入结构。

```typescript
workflow
  .map({
    message: { initData: true, path: 'message' },
    locale: { initData: true, path: 'locale' },
  })
  .classifier(router)
```

映射使用与其他 Workflow 步骤相同、经过验证的路径语法，并会保留在序列化后的 Workflow 图中。

## 输出 {/* #output */}

* 选项类答案通过 `answers.<question>.choice` 提供结果，也可能包含 `probabilities`。
* 评分类答案通过 `answers.<question>.score` 提供结果，也可能包含 `probabilities`。
* 布尔类答案将原始 `P(true)` 值作为 `answers.<question>.probability` 返回。用于路由时需明确设置阈值。
* 被拒答的问题返回 `{ type: 'refusal' }`，不包含 `choice`、`score` 或 `probability`。
* `usage` 包含标准化的 token 用量。

## 重试和错误 {/* #retries-and-errors */}

`maxRetries` 控制 Classifier 模型调用的重试次数。`retries` 控制 Workflow 步骤的重试次数。Workflow 的中止信号会传递给 Classifier；Classifier 出错会使步骤失败。`.classifier()` 不采用故障放行行为。

## 通过 ID 引用分类器 {/* #referencing-a-classifier-by-id */}

将 Classifier 注册到运行该 Workflow 的同一个 `Mastra` 实例上：

```typescript filename="src/mastra/index.ts"
import { Mastra } from '@mastra/core'

export const mastra = new Mastra({
  classifiers: { router },
  workflows: { workflow },
})
```

使用带类型的字符串引用时，需显式指定已配置的问题类型：

```typescript
workflow.classifier<typeof router.questions>('router')
```
