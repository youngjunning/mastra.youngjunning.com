# Workflow.分类器()

这`.classifier()`方法添加一个配置的[`Classifier`](/reference/classifier/classifier)作为声明性Workflow程步骤并返回链接的Workflow程。该步骤输出 JSON 安全的`{ answers, usage }`可由后续步骤和现有控制流方法使用的对象，例如[`.branch()`](/reference/workflows/workflow-methods/branch).

## 使用示例 {/* #usage-example */}

```typescript filename="src/mastra/workflows/ticket-triage.ts"
import { createWorkflow } from '@mastra/core/workflows'
import { z } from 'zod'

const workflow = createWorkflow({
  id: 'ticket-triage',
  inputSchema: z.object({ message: z.string() }),
  outputSchema: z.any(),
})
  .map({ message: { initData: true, path: 'message' } })
  .classifier(router)
  .branch([
    [async ({ inputData }) => inputData.answers.route.choice === 'billing', billingStep],
    [async ({ inputData }) => inputData.answers.route.choice === 'support', supportStep],
    [async () => true, fallbackStep],
  ])
  .commit()
```

当传递分类器实例时，会在下游步骤中推断问题键和选择文字。分类器必须包含构造函数配置的问题。

## 输入映射 {/* #input-mapping */}

分类器评估完整的上一步输出。插入[`.map()`](/reference/workflows/workflow-methods/map) before `.classifier()` to select or reshape its input.

```typescript
workflow
  .map({
    message: { initData: true, path: 'message' },
    locale: { initData: true, path: 'locale' },
  })
  .classifier(router)
```

映射使用与其他Workflow步骤相同的经过验证的路径语法，并保留在序列化Workflow图中。

## 输出 {/* #output */}

* 选择答案暴露`answers.<question>.choice` and may include `probabilities`.
* 分数答案揭晓`answers.<question>.score` and may include `probabilities`.
* 布尔答案揭示了原始的`P(true)` value as `answers.<question>.probability`. Apply an explicit threshold when routing.
* 被拒绝的问题有`{ type: 'refusal' }` and have no `choice`, `score`, or `probability`.
* `usage`包含规范化的令牌使用情况。

## 重试和错误 {/* #retries-and-errors */}

`maxRetries`控制分类器模型调用的重试。`retries` controls retries of the workflow step. The workflow abort signal is forwarded to the classifier. Classifier errors fail the step. `.classifier()` doesn't apply fail-open behavior.

## 通过 ID 引用分类器 {/* #referencing-a-classifier-by-id */}

在同一个上注册分类器`Mastra` instance that runs the workflow:

```typescript filename="src/mastra/index.ts"
import { Mastra } from '@mastra/core'

export const mastra = new Mastra({
  classifiers: { router },
  workflows: { workflow },
})
```

对于类型化字符串引用，请显式提供配置的问题类型：

```typescript
workflow.classifier<typeof router.questions>('router')
```
