# Workflow 类

`Workflow` 类可用于创建状态机，通过条件分支和数据校验组织复杂的操作流程。

## 使用示例 {/* #usage-example */}

```typescript title="src/mastra/workflows/test-workflow.ts"
import { createWorkflow } from '@mastra/core/workflows'
import { z } from 'zod'

export const workflow = createWorkflow({
  id: 'test-workflow',
  inputSchema: z.object({
    value: z.string(),
  }),
  outputSchema: z.object({
    value: z.string(),
  }),
})
```

## 定义 Schema {/* #define-schemas */}

您可以使用任何支持 [Standard JSON Schema](https://standardschema.dev/json-schema) 的库定义 Workflow 的 `inputSchema` 和 `outputSchema`，例如 [Zod](https://zod.dev/)、[Valibot](https://valibot.dev/) 和 [ArkType](https://arktype.io/)。

## 使用初始状态运行 {/* #running-with-initial-state */}

启动 Workflow 运行时，可以通过 `initialState` 设置 Workflow 状态的初始值：

```typescript
const run = await workflow.createRun()

const result = await run.start({
  inputData: { value: 'hello' },
  initialState: {
    counter: 0,
    items: [],
  },
})
```

`initialState` 对象应符合 Workflow 的 `stateSchema` 所定义的结构。详情参见 [Workflow 状态](/docs/workflows/workflow-state)。

### 处理 tripwire 状态 {/* #handling-tripwire-status */}

当 Workflow 中的 Agent 步骤触发 tripwire 时，Workflow 返回 `status: 'tripwire'`，并附带 tripwire 详情：

```typescript
const run = await workflow.createRun()
const result = await run.start({ inputData: { message: 'Hello' } })

if (result.status === 'tripwire') {
  console.log('Workflow terminated by tripwire:', result.tripwire?.reason)
  console.log('Processor ID:', result.tripwire?.processorId)
  console.log('Retry requested:', result.tripwire?.retry)
}
```

这与表示意外错误的 `status: 'failed'` 不同。tripwire 状态表示处理器有意停止执行，例如进行内容审核时。
