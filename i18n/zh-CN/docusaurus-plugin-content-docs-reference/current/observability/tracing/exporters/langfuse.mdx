# Langfuse出口商

将跟踪数据发送到 Langfuse 以实现可观察性。

## 构造函数 {/* #constructor */}

```typescript oxfmt:false
new LangfuseExporter(config?: LangfuseExporterConfig)
```

## `LangfuseExporterConfig` {/* #langfuseexporterconfig */}

```typescript
interface LangfuseExporterConfig extends BaseExporterConfig {
  publicKey?: string
  secretKey?: string
  baseUrl?: string
  additionalHeaders?: Record<string, string>
  realtime?: boolean
  flushAt?: number
  flushInterval?: number
  environment?: string
  release?: string
  resourceAttributes?: DetectedResourceAttributes
}
```

延伸`BaseExporterConfig`, which includes:

* `logger?: IMastraLogger`- 记录器实例
* `logLevel?: LogLevel | 'debug' | 'info' | 'warn' | 'error'`- 日志级别（默认：INFO）

## 特性 {/* #properties */}

### `client` {/* #client */}

```typescript oxfmt:false
get client(): LangfuseClient | undefined
```

这`LangfuseClient` instance for advanced Langfuse features. Returns `undefined` when the exporter is disabled (missing credentials). Use this for prompt management, evaluations, datasets, and direct API access.

## 方法 {/* #methods */}

### 冲水 {/* #flush */}

```typescript oxfmt:false
async flush(): Promise<void>
```

强制将任何缓冲的跨度和分数刷新到 Langfuse，而无需关闭。在无服务器环境中很有用，您需要确保在运行时终止之前导出数据。

### 关闭 {/* #shutdown */}

```typescript oxfmt:false
async shutdown(): Promise<void>
```

刷新挂起的数据并关闭跨度处理器和客户端。

## 用法 {/* #usage */}

### 零配置（使用环境变量） {/* #zero-config-using-environment-variables */}

```typescript
import { LangfuseExporter } from '@mastra/langfuse'

// Reads from LANGFUSE_PUBLIC_KEY, LANGFUSE_SECRET_KEY, LANGFUSE_BASE_URL
const exporter = new LangfuseExporter()
```

### 显式配置 {/* #explicit-configuration */}

```typescript
import { LangfuseExporter } from '@mastra/langfuse'

const exporter = new LangfuseExporter({
  publicKey: process.env.LANGFUSE_PUBLIC_KEY,
  secretKey: process.env.LANGFUSE_SECRET_KEY,
  baseUrl: 'https://cloud.langfuse.com',
  additionalHeaders: { 'x-custom-header': 'custom-value' },
  realtime: true,
})
```

## 跨度映射 {/* #span-mapping */}

Mastra 跨度转换为 OTel 格式并通过以下方式发送到 Langfuse`LangfuseSpanProcessor`. Langfuse automatically maps spans based on their `gen_ai.*` attributes:

* 跨度与`model` attribute → Langfuse generations
* 所有其他跨度 → Langfuse 跨度
* 父子关系通过 OTel 跟踪/跨度 ID 保留

## 成本追踪 {/* #cost-tracking */}

Langfuse 报告成本来自`langfuse.observation.cost_details`. The exporter sends that field only for model generation spans whose cost metadata meets all of these conditions:

* 跨度是一个`MODEL_GENERATION` span.
* `costContext.costMetadata.source`是`'provider_reported'`, meaning the model provider returned the cost. Estimated costs aren't exported, so Langfuse can apply its own model pricing instead.
* `costContext.costUnit`是`'USD'`.
* `costContext.estimatedCost`是一个有限的非负数。

当任何条件失败时，生成的数据将在没有成本详细信息的情况下导出，并且 Langfuse 会回退到其自己的定价模型，该模型还涵盖大多数自托管或直接模型 API 等Provider，这些Provider在您在 Langfuse 中配置模型价格之前不会报告成本。

## 提示链接 {/* #prompt-linking */}

将LLM世代链接到[Langfuse Prompt Management](https://langfuse.com/docs/prompt-management) using the `withLangfusePrompt` helper:

```typescript
import { buildTracingOptions } from '@mastra/observability'
import { LangfuseExporter, withLangfusePrompt } from '@mastra/langfuse'

const exporter = new LangfuseExporter()

// Fetch prompt via the Langfuse client
const prompt = await exporter.client.prompt.get('customer-support', { type: 'text' })

const agent = new Agent({
  id: 'support-agent',
  name: 'support-agent',
  instructions: prompt.compile(),
  model: '__GATEWAY_OPENAI_MODEL__',
  defaultGenerateOptions: {
    tracingOptions: buildTracingOptions(
      withLangfusePrompt({ name: prompt.name, version: prompt.version }),
    ),
  },
})
```

### 辅助函数 {/* #helper-functions */}

#### `withLangfusePrompt(prompt)` {/* #withlangfusepromptprompt */}

将 Langfuse 提示元数据添加到跟踪选项。

```typescript
// Link by name and version (required for Langfuse v5)
withLangfusePrompt({ name: 'my-prompt', version: 1 })
```

提示元数据作为跨度属性传递，Langfuse 将生成链接到相应的提示。
