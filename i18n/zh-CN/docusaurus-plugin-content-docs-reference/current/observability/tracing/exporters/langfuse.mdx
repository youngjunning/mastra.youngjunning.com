# LangfuseExporter

将 Tracing 数据发送到 Langfuse，以便进行可观测性分析。

## 构造函数 {/* #constructor */}

```typescript oxfmt:false
new LangfuseExporter(config?: LangfuseExporterConfig)
```

## `LangfuseExporterConfig` {/* #langfuseexporterconfig */}

```typescript
interface LangfuseExporterConfig extends BaseExporterConfig {
  publicKey?: string
  secretKey?: string
  baseUrl?: string
  additionalHeaders?: Record<string, string>
  realtime?: boolean
  flushAt?: number
  flushInterval?: number
  environment?: string
  release?: string
  resourceAttributes?: DetectedResourceAttributes
}
```

扩展 `BaseExporterConfig`，其中还包括：

- `logger?: IMastraLogger` - Logger 实例
- `logLevel?: LogLevel | 'debug' | 'info' | 'warn' | 'error'` - 日志级别（默认：INFO）

## 属性 {/* #properties */}

### `client` {/* #client */}

```typescript oxfmt:false
get client(): LangfuseClient | undefined
```

用于访问 Langfuse 高级功能的 `LangfuseClient` 实例。若因缺少凭据而禁用 Exporter，则返回 `undefined`。可用它管理提示词、评估和数据集，或直接访问 API。

## 方法 {/* #methods */}

### flush {/* #flush */}

```typescript oxfmt:false
async flush(): Promise<void>
```

强制将缓冲中的 span 和评分刷新到 Langfuse，而不关闭 Exporter。适用于需要在运行时结束前确保数据已导出的无服务器环境。

### shutdown {/* #shutdown */}

```typescript oxfmt:false
async shutdown(): Promise<void>
```

刷新待处理数据，并关闭 span 处理器和客户端。

## 用法 {/* #usage */}

### 零配置（使用环境变量） {/* #zero-config-using-environment-variables */}

```typescript
import { LangfuseExporter } from '@mastra/langfuse'

// Reads from LANGFUSE_PUBLIC_KEY, LANGFUSE_SECRET_KEY, LANGFUSE_BASE_URL
const exporter = new LangfuseExporter()
```

### 显式配置 {/* #explicit-configuration */}

```typescript
import { LangfuseExporter } from '@mastra/langfuse'

const exporter = new LangfuseExporter({
  publicKey: process.env.LANGFUSE_PUBLIC_KEY,
  secretKey: process.env.LANGFUSE_SECRET_KEY,
  baseUrl: 'https://cloud.langfuse.com',
  additionalHeaders: { 'x-custom-header': 'custom-value' },
  realtime: true,
})
```

## Span 映射 {/* #span-mapping */}

Mastra 的 span 会转换为 OTel 格式，并通过 `LangfuseSpanProcessor` 发送到 Langfuse。Langfuse 根据 `gen_ai.*` 属性自动映射 span：

- 具有 `model` 属性的 span → Langfuse generation
- 其他所有 span → Langfuse span
- 通过 OTel trace/span ID 保留父子关系

## 成本追踪 {/* #cost-tracking */}

Langfuse 从 `langfuse.observation.cost_details` 读取成本。Exporter 仅在模型生成 span 的成本元数据满足以下全部条件时发送该字段：

- 该 span 是 `MODEL_GENERATION` span。
- `costContext.costMetadata.source` 为 `'provider_reported'`，表示模型 Provider 返回了成本。估算成本不会导出，以便 Langfuse 使用自己的模型定价。
- `costContext.costUnit` 为 `'USD'`。
- `costContext.estimatedCost` 是有限的非负数。

只要有一项条件不满足，generation 就不会附带成本明细，Langfuse 会改用自己的定价模型。对于大多数自托管或直连模型 API 等不报告成本的 Provider，需要在 Langfuse 中配置模型价格，才能由其定价模型计算成本。

## 提示词关联 {/* #prompt-linking */}

使用 `withLangfusePrompt` 辅助函数，将 LLM generation 关联到 [Langfuse Prompt Management](https://langfuse.com/docs/prompt-management)：

```typescript
import { buildTracingOptions } from '@mastra/observability'
import { LangfuseExporter, withLangfusePrompt } from '@mastra/langfuse'

const exporter = new LangfuseExporter()

// Fetch prompt via the Langfuse client
const prompt = await exporter.client.prompt.get('customer-support', { type: 'text' })

const agent = new Agent({
  id: 'support-agent',
  name: 'support-agent',
  instructions: prompt.compile(),
  model: '__GATEWAY_OPENAI_MODEL__',
  defaultGenerateOptions: {
    tracingOptions: buildTracingOptions(
      withLangfusePrompt({ name: prompt.name, version: prompt.version }),
    ),
  },
})
```

### 辅助函数 {/* #helper-functions */}

#### `withLangfusePrompt(prompt)` {/* #withlangfusepromptprompt */}

将 Langfuse 提示词元数据添加到 Tracing 选项。

```typescript
// Link by name and version (required for Langfuse v5)
withLangfusePrompt({ name: 'my-prompt', version: 1 })
```

提示词元数据会作为 span 属性传递，Langfuse 据此将 generation 关联到对应提示词。
