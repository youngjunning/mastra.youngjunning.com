# 亚瑟出口商

将跟踪数据发送至[Arthur Engine](https://github.com/arthur-ai/arthur-engine)使用 OpenTelemetry 和 OpenInference 语义约定。

## 构造函数 {/* #constructor */}

```typescript oxfmt:false
new ArthurExporter(config: ArthurExporterConfig)
```

## `ArthurExporterConfig` {/* #arthurexporterconfig */}

```typescript
type ArthurExporterConfig = Omit<OtelExporterConfig, 'provider' | 'exporter'> & {
  apiKey?: string
  endpoint?: string
  taskId?: string
  headers?: Record<string, string>
}
```

继承自`OtelExporterConfig` (excluding `provider` and `exporter`），其中包括：

* `timeout?: number`- 导出超时以毫秒为单位（默认值：30000）
* `batchSize?: number`- 每批的跨度数（默认值：512）
* `logLevel?: LogLevel | 'debug' | 'info' | 'warn' | 'error'`- 日志级别（默认：警告）
* `resourceAttributes?: Record<string, any>`- 自定义资源属性

### 元数据透传 {/* #metadata-passthrough */}

非保留的跨度属性被序列化到 OpenInference 中`metadata` payload. Add them via `tracingOptions.metadata` (e.g., `companyId`, `tier`). Reserved fields such as `input`, `output`, `sessionId`、线程/用户 ID 和 OpenInference ID 会自动排除。

## 方法 {/* #methods */}

### `exportTracingEvent` {/* #exporttracingevent */}

```typescript oxfmt:false
async exportTracingEvent(event: TracingEvent): Promise<void>
```

将跟踪事件导出到配置的端点。

### 出口 {/* #export */}

```typescript oxfmt:false
async export(spans: ReadOnlySpan[]): Promise<void>
```

使用 OpenTelemetry 和 OpenInference 语义约定进行批量导出。

### 冲水 {/* #flush */}

```typescript oxfmt:false
async flush(): Promise<void>
```

强制将任何缓冲的跨度刷新到配置的端点，而不关闭导出器。在无服务器环境中很有用，您需要确保在运行时终止之前导出跨度。

### 关闭 {/* #shutdown */}

```typescript oxfmt:false
async shutdown(): Promise<void>
```

刷新待处理数据并关闭客户端。

## 用法 {/* #usage */}

### 零配置（使用环境变量） {/* #zero-config-using-environment-variables */}

```typescript
import { ArthurExporter } from '@mastra/arthur'

// Set ARTHUR_API_KEY and ARTHUR_BASE_URL (optionally ARTHUR_TASK_ID)
const exporter = new ArthurExporter()
```

### 显式配置 {/* #explicit-configuration */}

```typescript
import { ArthurExporter } from '@mastra/arthur'

const exporter = new ArthurExporter({
  apiKey: process.env.ARTHUR_API_KEY!,
  endpoint: 'http://localhost:3030',
  taskId: process.env.ARTHUR_TASK_ID, // Optional
})
```

## `OpenInference`语义约定 {/* #openinference-semantic-conventions */}

ArthurExporter 实现[OpenInference Semantic Conventions](https://github.com/Arize-ai/openinference/tree/main/spec) for generative AI applications, providing standardized trace structure across different observability platforms.

## 标签支持 {/* #tags-support */}

ArthurExporter 支持跟踪标记以进行分类和过滤。标签仅应用于根跨度并映射到本机 OpenInference`tag.tags` semantic convention.

### 用法 {/* #usage-1 */}

```typescript
const result = await agent.generate('Hello', {
  tracingOptions: {
    tags: ['production', 'experiment-v2', 'user-request'],
  },
})
```

### 标签如何存储 {/* #how-tags-are-stored */}

使用 OpenInference 存储标签`tag.tags` attribute:

```json
{
  "tag.tags": ["production", "experiment-v2", "user-request"]
}
```
