# ArthurExporter

使用 OpenTelemetry 和 OpenInference 语义约定，将 Tracing 数据发送到 [Arthur Engine](https://github.com/arthur-ai/arthur-engine)。

## 构造函数 {/* #constructor */}

```typescript oxfmt:false
new ArthurExporter(config: ArthurExporterConfig)
```

## `ArthurExporterConfig` {/* #arthurexporterconfig */}

```typescript
type ArthurExporterConfig = Omit<OtelExporterConfig, 'provider' | 'exporter'> & {
  apiKey?: string
  endpoint?: string
  taskId?: string
  headers?: Record<string, string>
}
```

继承 `OtelExporterConfig` 中除 `provider` 和 `exporter` 之外的配置项，包括：

- `timeout?: number` - 导出超时时间，单位为毫秒（默认值：30000）
- `batchSize?: number` - 每批的 Span 数量（默认值：512）
- `logLevel?: LogLevel | 'debug' | 'info' | 'warn' | 'error'` - 日志级别（默认值：WARN）
- `resourceAttributes?: Record<string, any>` - 自定义资源属性

### 元数据透传 {/* #metadata-passthrough */}

非保留的 Span 属性会序列化到 OpenInference 的 `metadata` 载荷中。可通过 `tracingOptions.metadata` 添加这些属性（例如 `companyId`、`tier`）。`input`、`output`、`sessionId`、线程和用户 ID，以及 OpenInference ID 等保留字段会自动排除。

## 方法 {/* #methods */}

### `exportTracingEvent` {/* #exporttracingevent */}

```typescript oxfmt:false
async exportTracingEvent(event: TracingEvent): Promise<void>
```

将 Tracing 事件导出到已配置的端点。

### export {/* #export */}

```typescript oxfmt:false
async export(spans: ReadOnlySpan[]): Promise<void>
```

使用 OpenTelemetry 按批次导出 Span，并遵循 OpenInference 语义约定。

### flush {/* #flush */}

```typescript oxfmt:false
async flush(): Promise<void>
```

立即将缓冲区中的所有 Span 刷新到已配置的端点，同时保持导出器运行。适用于无服务器环境，可确保运行时结束前完成导出。

### shutdown {/* #shutdown */}

```typescript oxfmt:false
async shutdown(): Promise<void>
```

刷新待处理数据并关闭客户端。

## 用法 {/* #usage */}

### 零配置（使用环境变量） {/* #zero-config-using-environment-variables */}

```typescript
import { ArthurExporter } from '@mastra/arthur'

// Set ARTHUR_API_KEY and ARTHUR_BASE_URL (optionally ARTHUR_TASK_ID)
const exporter = new ArthurExporter()
```

### 显式配置 {/* #explicit-configuration */}

```typescript
import { ArthurExporter } from '@mastra/arthur'

const exporter = new ArthurExporter({
  apiKey: process.env.ARTHUR_API_KEY!,
  endpoint: 'http://localhost:3030',
  taskId: process.env.ARTHUR_TASK_ID, // Optional
})
```

## `OpenInference` 语义约定 {/* #openinference-semantic-conventions */}

ArthurExporter 实现了面向生成式 AI 应用的 [OpenInference 语义约定](https://github.com/Arize-ai/openinference/tree/main/spec)，为不同可观测性平台提供标准化的 Trace 结构。

## 标签支持 {/* #tags-support */}

ArthurExporter 支持使用标签对 Trace 分类和筛选。标签仅应用于根 Span，并映射到 OpenInference 原生的 `tag.tags` 语义约定。

### 用法 {/* #usage-1 */}

```typescript
const result = await agent.generate('Hello', {
  tracingOptions: {
    tags: ['production', 'experiment-v2', 'user-request'],
  },
})
```

### 标签的存储方式 {/* #how-tags-are-stored */}

标签存储在 OpenInference 的 `tag.tags` 属性中：

```json
{
  "tag.tags": ["production", "experiment-v2", "user-request"]
}
```
