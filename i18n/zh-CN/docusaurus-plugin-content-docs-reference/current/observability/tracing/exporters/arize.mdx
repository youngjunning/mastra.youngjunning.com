# ArizeExporter

将 Tracing 数据发送到 Arize Phoenix、Arize AX，或其他支持 OpenInference 语义约定且兼容 OpenTelemetry 的可观测平台。

## 构造函数 {/* #constructor */}

```typescript oxfmt:false
new ArizeExporter(config: ArizeExporterConfig)
```

## `ArizeExporterConfig` {/* #arizeexporterconfig */}

```typescript
type ArizeExporterConfig = Omit<OtelExporterConfig, 'provider'> & {
  // Phoenix / OpenTelemetry configuration
  endpoint?: string
  apiKey?: string

  // Arize AX configuration
  spaceId?: string

  // Common configuration
  projectName?: string
  headers?: Record<string, string>
}
```

继承 `OtelExporterConfig`（不包括 `provider`），其中包括：

* `timeout?: number`- 导出超时时间，单位为毫秒（默认：30000）
* `batchSize?: number`- 每批导出的 Span 数量（默认：512）
* `logLevel?: LogLevel | 'debug' | 'info' | 'warn' | 'error'`- 日志级别（默认：WARN）
* `resourceAttributes?: Record<string, any>`- 自定义资源属性

### 元数据透传 {/* #metadata-passthrough */}

非保留的 Span 属性会序列化到 OpenInference 的 `metadata` 载荷中。可通过 `tracingOptions.metadata` 添加，例如 `companyId`、`tier`。`input`、`output`、`sessionId`、线程和用户 ID，以及 OpenInference ID 等保留字段会自动排除。

## 方法 {/* #methods */}

### `exportTracingEvent` {/* #exporttracingevent */}

```typescript oxfmt:false
async exportTracingEvent(event: TracingEvent): Promise<void>
```

将跟踪事件导出到配置的端点。

### export {/* #export */}

```typescript oxfmt:false
async export(spans: ReadOnlySpan[]): Promise<void>
```

使用 OpenTelemetry 按 OpenInference 语义约定批量导出 Span。

### flush {/* #flush */}

```typescript oxfmt:false
async flush(): Promise<void>
```

强制将缓冲中的 Span 发送到配置的端点，同时保持导出器运行。适用于需要在运行环境终止前确保 Span 已导出的 Serverless 环境。

### shutdown {/* #shutdown */}

```typescript oxfmt:false
async shutdown(): Promise<void>
```

发送待处理数据并关闭客户端。

## 用法 {/* #usage */}

### 零配置（使用环境变量） {/* #zero-config-using-environment-variables */}

```typescript
import { ArizeExporter } from '@mastra/arize'

// For Phoenix: Set PHOENIX_COLLECTOR_ENDPOINT, PHOENIX_API_KEY, PHOENIX_PROJECT_NAME
// For Arize AX: Set ARIZE_SPACE_ID, ARIZE_API_KEY, ARIZE_PROJECT_NAME
const exporter = new ArizeExporter()
```

### Phoenix 配置 {/* #phoenix-configuration */}

```typescript
import { ArizeExporter } from '@mastra/arize'

const exporter = new ArizeExporter({
  endpoint: 'http://localhost:6006/v1/traces',
  apiKey: process.env.PHOENIX_API_KEY, // Optional for local Phoenix
  projectName: 'my-ai-project',
})
```

### Arize AX 配置 {/* #arize-ax-configuration */}

```typescript
import { ArizeExporter } from '@mastra/arize'

const exporter = new ArizeExporter({
  spaceId: process.env.ARIZE_SPACE_ID!,
  apiKey: process.env.ARIZE_API_KEY!,
  projectName: 'my-ai-project',
})
```

## `OpenInference` 语义约定 {/* #openinference-semantic-conventions */}

ArizeExporter 遵循适用于生成式 AI 应用的 [OpenInference 语义约定](https://github.com/Arize-ai/openinference/tree/main/spec)，使不同可观测平台的 Trace 结构保持一致。

## 标签支持 {/* #tags-support */}

ArizeExporter 支持通过标签对 Trace 分类和筛选。标签仅应用于根 Span，并映射到 OpenInference 原生的 `tag.tags` 语义约定。

### 用法 {/* #usage-1 */}

```typescript
const result = await agent.generate('Hello', {
  tracingOptions: {
    tags: ['production', 'experiment-v2', 'user-request'],
  },
})
```

### 标签的存储方式 {/* #how-tags-are-stored */}

标签存储在 OpenInference 的 `tag.tags` 属性中：

```json
{
  "tag.tags": ["production", "experiment-v2", "user-request"]
}
```
