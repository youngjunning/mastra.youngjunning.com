# 哨兵导出器

使用 OpenTelemetry 语义约定将跟踪数据发送到 Sentry 以进行 AI 跟踪和监控。

## 构造函数 {/* #constructor */}

```typescript oxfmt:false
new SentryExporter(config: SentryExporterConfig)
```

## `SentryExporterConfig` {/* #sentryexporterconfig */}

```typescript
interface SentryExporterConfig extends BaseExporterConfig {
  dsn?: string
  environment?: string
  tracesSampleRate?: number
  release?: string
  options?: Partial<Sentry.NodeOptions>
}
```

延伸`BaseExporterConfig`, which includes:

* `logger?: IMastraLogger`- 记录器实例
* `logLevel?: LogLevel | 'debug' | 'info' | 'warn' | 'error'`- 日志级别（默认：INFO）

## 方法 {/* #methods */}

### `exportTracingEvent` {/* #exporttracingevent */}

```typescript oxfmt:false
async exportTracingEvent(event: TracingEvent): Promise<void>
```

将跟踪事件导出到 Sentry。处理 SPAN\_STARTED、SPAN\_UPDATED 和 SPAN\_ENDED 事件。

### 冲水 {/* #flush */}

```typescript oxfmt:false
async flush(): Promise<void>
```

强制将任何挂起的跨度刷新到 Sentry，而不关闭导出器。等待最多 2 秒以发送待处理的数据。在无服务器环境中很有用，您需要确保在运行时终止之前导出跨度。

### 关闭 {/* #shutdown */}

```typescript oxfmt:false
async shutdown(): Promise<void>
```

在关闭 Sentry 连接之前结束所有活动范围并清除内部状态。等待最多 2 秒以发送待处理的数据。

## 用法 {/* #usage */}

### 零配置（使用环境变量） {/* #zero-config-using-environment-variables */}

```typescript
import { SentryExporter } from '@mastra/sentry'

// Reads from SENTRY_DSN, SENTRY_ENVIRONMENT, SENTRY_RELEASE
const exporter = new SentryExporter()
```

### 显式配置 {/* #explicit-configuration */}

```typescript
import { SentryExporter } from '@mastra/sentry'

const exporter = new SentryExporter({
  dsn: process.env.SENTRY_DSN,
  environment: 'production',
  tracesSampleRate: 1.0,
  release: '1.0.0',
})
```

### 带采样 {/* #with-sampling */}

```typescript
const exporter = new SentryExporter({
  dsn: process.env.SENTRY_DSN,
  environment: 'production',
  tracesSampleRate: 0.1, // Send 10% of transactions to Sentry (recommended for high-load backends)
})
```

### 使用自定义哨兵选项 {/* #with-custom-sentry-options */}

```typescript
const exporter = new SentryExporter({
  dsn: process.env.SENTRY_DSN,
  environment: 'production',
  options: {
    integrations: [
      // Custom Sentry integrations
    ],
    beforeSend: event => {
      // Custom event processing
      return event
    },
  },
})
```

## 跨度映射 {/* #span-mapping */}

Mastra 跨度类型映射到 Sentry 操作：

|马斯特拉 SpanType |哨兵行动|
| - | - |
|`AGENT_RUN` | `gen_ai.invoke_agent` |
| `MODEL_GENERATION` | `gen_ai.chat` |
| `MODEL_STEP` | *(skipped)* |
| `MODEL_CHUNK` | *(skipped)* |
| `TOOL_CALL` | `gen_ai.execute_tool` |
| `MCP_TOOL_CALL` | `gen_ai.execute_tool` |
| `PROVIDER_TOOL_CALL` | `gen_ai.execute_tool` |
| `WORKFLOW_RUN` | `workflow.run` |
| `WORKFLOW_STEP` | `workflow.step` |
| `WORKFLOW_CONDITIONAL` | `workflow.conditional` |
| `WORKFLOW_CONDITIONAL_EVAL` | `workflow.conditional` |
| `WORKFLOW_PARALLEL` | `workflow.parallel` |
| `WORKFLOW_LOOP` | `workflow.loop` |
| `WORKFLOW_SLEEP` | `workflow.sleep` |
| `WORKFLOW_WAIT_EVENT` | `workflow.wait` |
| `PROCESSOR_RUN` | `ai.processor` |
| `GENERIC` | `ai.span` |

跳过 MODEL\_STEP 和 MODEL\_CHUNK 跨度以简化跟踪层次结构。他们的数据被聚合到 MODEL\_GENERATION 范围内。

## 环境变量 {/* #environment-variables */}

导出器从这些环境变量中读取配置：

|变量|描述 |
| - | - |
|`SENTRY_DSN` | Data Source Name - tells the SDK where to send events |
| `SENTRY_ENVIRONMENT` | Deployment environment name |
| `SENTRY_RELEASE` | Version of your code deployed |

## `OpenTelemetry`属性 {/* #opentelemetry-attributes */}

导出器设置这些标准 OpenTelemetry 属性：

**通用属性（所有跨度）：**

* `sentry.origin`: `auto.ai.mastra` (identifies spans from Mastra)
* `ai.span.type`：Mastra 跨度类型
* `gen_ai.conversation.id`：聊天线程标识符，设置自`metadata.threadId` to group spans in Sentry's Conversations view

**MODEL\_GENERATION 跨度：**

* `gen_ai.operation.name`: `chat`
* `gen_ai.system`: 模型提供者
* `gen_ai.request.model`：型号标识符
* `gen_ai.request.messages`：输入消息/提示（JSON）
* `gen_ai.response.model`：响应模型
* `gen_ai.response.text`：输出文本
* `gen_ai.response.tool_calls`：生成期间进行的Tool调用（JSON 数组）
* `gen_ai.usage.input_tokens`：输入令牌数量
* `gen_ai.usage.output_tokens`：输出令牌数
* `gen_ai.usage.total_tokens`: 代币总数
* `gen_ai.request.stream`: 流媒体标志
* `gen_ai.request.temperature`：温度参数
* `gen_ai.completion_start_time`：第一个令牌时间

**TOOL\_CALL 范围：**

* `gen_ai.operation.name`: `execute_tool`
* `gen_ai.tool.name`：Tool标识符
* `gen_ai.tool.type`: `function`
* `gen_ai.tool.call.id`：Tool调用ID
* `gen_ai.tool.input`：Tool输入
* `gen_ai.tool.output`：Tool输出
* `tool.success`：成功标志

**AGENT\_RUN 跨度：**

* `gen_ai.operation.name`: `invoke_agent`
* `gen_ai.agent.name`：Agent标识符
* `gen_ai.pipeline.name`: Agent姓名
* `gen_ai.agent.instructions`：Agent说明
* `gen_ai.response.model`：儿童时代的典范
* `gen_ai.response.text`：子代的输出
* `gen_ai.usage.*`：子代的代币使用情况
