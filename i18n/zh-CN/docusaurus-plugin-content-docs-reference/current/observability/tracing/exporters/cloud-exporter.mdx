# CloudExporter

**加入版本：** `@mastra/observability@1.8.0`。**自 `1.12.0` 起弃用**，请改用 [`MastraPlatformExporter`](/reference/observability/tracing/exporters/mastra-platform-exporter)。

:::warning[已弃用]

`CloudExporter` 仍可用于向后兼容，但会在未来的主版本中移除。新项目请使用 [`MastraPlatformExporter`](/reference/observability/tracing/exporters/mastra-platform-exporter)。两个类的构造函数相同，并共用环境变量和运行时行为。为了保留现有监控规则，`CloudExporter` 继续使用原有的导出器 `name` 值 `mastra-cloud-observability-exporter` 和 `CLOUD_EXPORTER_*` 错误 ID。

:::

将追踪 span、日志、指标、评分和反馈发送到 Mastra 平台，以便在线查看和监控。

## `CloudExporterConfig` {/* #cloudexporterconfig */}

```typescript
interface CloudExporterConfig extends BaseExporterConfig {
  /** Maximum number of spans per batch. Default: 1000 */
  maxBatchSize?: number

  /** Maximum wait time before flushing in milliseconds. Default: 5000 */
  maxBatchWaitMs?: number

  /** Maximum retry attempts. Default: 3 */
  maxRetries?: number

  /** Cloud access token (from env or config) */
  accessToken?: string

  /** Project ID for project-scoped collector routes (letters, numbers, hyphens, underscores) */
  projectId?: string

  /** Base cloud observability endpoint */
  endpoint?: string

  /** Explicit cloud traces endpoint override */
  tracesEndpoint?: string

  /** Explicit cloud logs endpoint override */
  logsEndpoint?: string

  /** Explicit cloud metrics endpoint override */
  metricsEndpoint?: string

  /** Explicit cloud scores endpoint override */
  scoresEndpoint?: string

  /** Explicit cloud feedback endpoint override */
  feedbackEndpoint?: string
}
```

继承 `BaseExporterConfig`，其中包含：

* `logger?: IMastraLogger` — 日志记录器实例
* `logLevel?: LogLevel | 'debug' | 'info' | 'warn' | 'error'` — 日志级别（默认：INFO）

## 环境变量 {/* #environment-variables */}

如果配置中未提供，导出器会读取以下环境变量：

* `MASTRA_CLOUD_ACCESS_TOKEN` — `CloudExporter` 请求使用的身份验证令牌
* `MASTRA_PROJECT_ID` — 推导项目级收集器路由时使用的项目 ID，例如 `/projects/:projectId/ai/spans/publish`
* `MASTRA_CLOUD_TRACES_ENDPOINT` — 覆盖追踪端点。可传入基础源地址，或以 `/spans/publish` 结尾的完整追踪发布 URL。其他信号的端点将据此推导。默认值为 `https://observability.mastra.ai`

`CloudExporter` 不读取 `MASTRA_PLATFORM_OBSERVABILITY_ENDPOINT`。如需使用此变量，请改用 [`MastraPlatformExporter`](/reference/observability/tracing/exporters/mastra-platform-exporter)。

## 方法 {/* #methods */}

### `exportTracingEvent` {/* #exporttracingevent */}

```typescript oxfmt:false
async exportTracingEvent(event: TracingEvent): Promise<void>
```

处理要导出到 Cloud 的追踪事件。

仅导出 `SPAN_ENDED` 追踪事件；忽略 `SPAN_STARTED` 和 `SPAN_UPDATED`。符合条件的 span 会先进入缓冲区，并在下次刷新时上传到 Cloud 追踪端点。

### `onLogEvent` {/* #onlogevent */}

```typescript oxfmt:false
async onLogEvent(event: LogEvent): Promise<void>
```

处理要导出到 Cloud 的日志信号。

传给此处理函数的每个 `LogEvent` 都会进入缓冲区，并导出到根据所配置基础端点推导出的 Cloud 日志端点。与追踪不同，`CloudExporter` 不会按事件状态进一步筛选。如果导出器已停用，此方法不执行任何操作。

### `flush` {/* #flush */}

```typescript oxfmt:false
async flush(): Promise<void>
```

强制将所有缓冲事件发送到 Mastra 平台，而不关闭导出器。适用于需要在运行时终止前确保 span 已导出的无服务器环境。

### `shutdown` {/* #shutdown */}

```typescript oxfmt:false
async shutdown(): Promise<void>
```

发送剩余事件并清理资源。

## 行为 {/* #behavior */}

### 身份验证 {/* #authentication */}

如果既没有通过配置也没有通过环境变量提供访问令牌，导出器会：

* 记录包含注册信息的警告。
* 不执行任何操作（丢弃所有事件）。

### 批处理 {/* #batching */}

导出器对追踪 span、日志、指标、评分和反馈进行批处理，以减少网络开销：

* 缓冲事件总数达到 `maxBatchSize` 时刷新。
* 自批次中的第一个缓冲信号起，经过 `maxBatchWaitMs` 时刷新。
* 调用 `shutdown()` 时刷新。

### 错误处理 {/* #error-handling */}

* 使用指数退避重试，最多尝试 `maxRetries` 次。
* 所有重试均失败后丢弃该批次。
* 记录错误，但继续处理新事件。

### 端点路由 {/* #endpoint-routing */}

* 根据基础源地址自动推导各信号端点。
* 未设置 `projectId` 时，推导出的路由使用 `/ai/{signal}/publish`。
* 设置 `projectId` 或 `MASTRA_PROJECT_ID` 时，推导出的路由使用 `/projects/:projectId/ai/{signal}/publish`。
* 显式提供的完整发布 URL 会原样使用，即使已配置 `projectId` 也是如此。

### 信号处理 {/* #signal-processing */}

* `exportTracingEvent()` 只导出 `SPAN_ENDED` 追踪事件。
* `onLogEvent()`、`onMetricEvent()`、`onScoreEvent()` 和 `onFeedbackEvent()` 会缓冲各自收到的所有对应类型事件。
* 所有受支持的信号批次都会在 `flush()` 和 `shutdown()` 期间上传到对应的 Cloud 发布端点。

## `MastraCloudSpanRecord` {/* #mastracloudspanrecord */}

Cloud span 的内部格式：

```typescript
interface MastraCloudSpanRecord {
  traceId: string
  spanId: string
  parentSpanId: string | null
  name: string
  spanType: string
  attributes: Record<string, any> | null
  metadata: Record<string, any> | null
  startedAt: Date
  endedAt: Date | null
  input: any
  output: any
  error: any
  isEvent: boolean
  createdAt: Date
  updatedAt: Date | null
}
```

## 用法 {/* #usage */}

```typescript
import { CloudExporter } from '@mastra/observability'

// Uses environment variable for token
const exporter = new CloudExporter()

// Explicit configuration
const customExporter = new CloudExporter({
  accessToken: 'your-token',
  projectId: 'project_123',
  maxBatchSize: 500,
  maxBatchWaitMs: 2000,
  logLevel: 'debug',
})
```
