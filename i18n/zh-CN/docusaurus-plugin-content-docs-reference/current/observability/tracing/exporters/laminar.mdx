# 层流导出器

通过 OTLP/HTTP (protobuf) 将跟踪数据发送到 Laminar。

## 构造函数 {/* #constructor */}

```typescript oxfmt:false
new LaminarExporter(config?: LaminarExporterConfig)
```

## `LaminarExporterConfig` {/* #laminarexporterconfig */}

```typescript
interface LaminarExporterConfig extends BaseExporterConfig {
  apiKey?: string
  baseUrl?: string
  endpoint?: string
  headers?: Record<string, string>
  realtime?: boolean
  disableBatch?: boolean
  batchSize?: number
  timeoutMillis?: number
}
```

延伸`BaseExporterConfig`, which includes:

* `logger?: IMastraLogger`- 记录器实例
* `logLevel?: LogLevel | 'debug' | 'info' | 'warn' | 'error'`- 日志级别（默认：INFO）

## 方法 {/* #methods */}

### `exportTracingEvent` {/* #exporttracingevent */}

```typescript oxfmt:false
async exportTracingEvent(event: TracingEvent): Promise<void>
```

将跟踪事件导出到 Laminar。

### 冲水 {/* #flush */}

```typescript oxfmt:false
async flush(): Promise<void>
```

强制将任何缓冲的跨度刷新到 Laminar，而不关闭导出器。在无服务器环境中很有用，您需要确保在运行时终止之前导出跨度。

### 关闭 {/* #shutdown */}

```typescript oxfmt:false
async shutdown(): Promise<void>
```

刷新待处理数据并关闭导出器。

## 用法 {/* #usage */}

### 零配置（使用环境变量） {/* #zero-config-using-environment-variables */}

```typescript
import { LaminarExporter } from '@mastra/laminar'

// Reads from LMNR_PROJECT_API_KEY, LMNR_BASE_URL, LAMINAR_ENDPOINT
const exporter = new LaminarExporter()
```

### 显式配置 {/* #explicit-configuration */}

```typescript
import { LaminarExporter } from '@mastra/laminar'

const exporter = new LaminarExporter({
  apiKey: process.env.LMNR_PROJECT_API_KEY,
  baseUrl: 'https://api.lmnr.ai',
  realtime: true,
})
```
