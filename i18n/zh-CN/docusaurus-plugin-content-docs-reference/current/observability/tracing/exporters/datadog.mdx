# DatadogExporter

将 Tracing 数据发送到 Datadog LLM Observability，用于监控与分析。

:::note
如果还使用 `dd-trace` 的 APM 自动插桩，并需要将其正确挂载在 Mastra Span 下，请改用 [DatadogBridge](/reference/observability/tracing/bridges/datadog)。此导出器在执行完成后才发送 LLM Observability 数据，因此不参与 `dd-trace` 的实时作用域。
:::

## 构造函数 {/* #constructor */}

```typescript oxfmt:false
new DatadogExporter(config: DatadogExporterConfig)
```

## 方法 {/* #methods */}

### `exportTracingEvent` {/* #exporttracingevent */}

```typescript oxfmt:false
async exportTracingEvent(event: TracingEvent): Promise<void>
```

将跟踪事件导出到 Datadog LLM Observability。

### flush {/* #flush */}

```typescript oxfmt:false
async flush(): Promise<void>
```

强制将缓冲中的 Span 发送到 Datadog，同时保持导出器运行。适用于需要在运行环境终止前确保 Span 已导出的 Serverless 环境。

flush 仅尽力保证发送：dd-trace 通过后台写入器发送 LLM Observability 数据，且无法等待请求完成，因此 `flush()` 在要求 dd-trace 发送后会等待 `flushGraceMs`（默认 2000 毫秒）。每次发送新数据的 flush 都会完整等待；若 Serverless 处理器对每个请求都等待 `flush()`，每个请求都会承担这段耗时。如果短生命周期进程的 Span 未出现在 Datadog 中，可调高该值；若有其他机制维持进程运行，可设为 `0` 跳过等待。

### shutdown {/* #shutdown */}

```typescript oxfmt:false
async shutdown(): Promise<void>
```

发送待处理数据并关闭导出器，同时取消尚未触发的清理定时器并禁用 LLM Observability。

## 用法 {/* #usage */}

### 零配置（使用环境变量） {/* #zero-config-using-environment-variables */}

```typescript
import { DatadogExporter } from '@mastra/datadog'

// Reads from DD_LLMOBS_ML_APP, DD_API_KEY, DD_SITE, DD_ENV
const exporter = new DatadogExporter()
```

### 显式配置 {/* #explicit-configuration */}

```typescript
import { DatadogExporter } from '@mastra/datadog'

const exporter = new DatadogExporter({
  mlApp: 'my-llm-app',
  apiKey: process.env.DD_API_KEY,
  site: 'datadoghq.com',
  env: 'production',
})
```

### 使用本地 Datadog Agent {/* #with-local-datadog-agent */}

```typescript
const exporter = new DatadogExporter({
  mlApp: 'my-llm-app',
  agentless: false, // Use local Datadog Agent
  env: 'production',
})
```

## Span 映射 {/* #span-mapping */}

Mastra 的 Span 类型映射到 Datadog LLM Observability 的 Span 种类：

| Mastra SpanType | Datadog Kind |
| - | - |
|`AGENT_RUN` | `agent` |
| `MODEL_GENERATION` | `workflow` |
| `MODEL_STEP` | `llm` |
| `TOOL_CALL` | `tool` |
| `MCP_TOOL_CALL` | `tool` |
| `PROVIDER_TOOL_CALL` | `tool` |
| `WORKFLOW_RUN` | `workflow`|
| 所有其他类型 | `task` |

所有未映射的 Span 类型（包括 `MODEL_CHUNK`、`WORKFLOW_STEP`、`GENERIC` 和未来新增的类型）都会默认映射为 `task`。

## 环境变量 {/* #environment-variables */}

导出器从这些环境变量中读取配置：

| 变量 | 说明 |
| - | - |
| `DD_API_KEY` | Datadog API 密钥 |
| `DD_LLMOBS_ML_APP` | ML 应用名称 |
| `DD_SITE` | Datadog 站点 |
| `DD_ENV` | 环境名称 |
| `DD_LLMOBS_AGENTLESS_ENABLED` | 设为 'false' 或 '0' 以使用本地 Agent |
