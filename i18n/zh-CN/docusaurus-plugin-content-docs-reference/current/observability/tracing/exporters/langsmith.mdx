# LangSmithExporter

将 Tracing 数据发送到 LangSmith，以便进行可观测性分析。

## 构造函数 {/* #constructor */}

```typescript oxfmt:false
new LangSmithExporter(config: LangSmithExporterConfig)
```

## `LangSmithExporterConfig` {/* #langsmithexporterconfig */}

```typescript
interface LangSmithExporterConfig extends ClientConfig, BaseExporterConfig {
  client?: Client
  projectName?: string
}
```

同时继承 LangSmith SDK 的 `ClientConfig` 和 `BaseExporterConfig`：

* 来自 `BaseExporterConfig`： `logger?: IMastraLogger`, `logLevel?: LogLevel | 'debug' | 'info' | 'warn' | 'error'`
* 来自 `ClientConfig`： `apiKey`, `apiUrl`, `callerOptions`, `hideInputs`, `hideOutputs` 等。

## 方法 {/* #methods */}

### `exportTracingEvent` {/* #exporttracingevent */}

```typescript oxfmt:false
async exportTracingEvent(event: TracingEvent): Promise<void>
```

将跟踪事件导出到 LangSmith。

### flush {/* #flush */}

```typescript oxfmt:false
async flush(): Promise<void>
```

强制将所有待处理的 Span 发送到 LangSmith，同时保持导出器运行。适用于需要在运行时结束前确保 Span 已导出的无服务器环境。

该方法会等待 LangSmith 客户端队列中和正在传输的批次。若客户端使用 `manualFlushMode: true`，它会代为调用 `client.flush()`，无需再手动刷新客户端。重叠调用会等待先前的上传完成。

### 关闭 {/* #shutdown */}

```typescript oxfmt:false
async shutdown(): Promise<void>
```

结束所有活动中的 Span 并清空 Trace 映射。尚未结束的 Span 会以关闭错误结束，其更新会在 Promise 完成前发送到 LangSmith。

## 用法 {/* #usage */}

```typescript
import { LangSmithExporter } from '@mastra/langsmith'

const exporter = new LangSmithExporter({
  apiKey: process.env.LANGSMITH_API_KEY,
  projectName: 'my-project', // Optional: specify which project to send traces to
  apiUrl: 'https://api.smith.langchain.com',
  logLevel: 'info',
})
```

## 环境变量 {/* #environment-variables */}

| 变量 | 说明 |
| - | - |
| `LANGSMITH_API_KEY` | LangSmith API 密钥 |
| `LANGCHAIN_PROJECT` | Trace 的默认项目名称（未指定 `projectName` 时使用） |
| `LANGSMITH_BASE_URL` | 自托管实例的 API 地址 |

## 跨度类型映射 {/* #span-type-mapping */}

| Span 类型 | LangSmith 类型 |
| - | - |
|`MODEL_GENERATION` | `llm` |
| `MODEL_CHUNK` | `llm` |
| `TOOL_CALL` | `tool` |
| `MCP_TOOL_CALL` | `tool` |
| `PROVIDER_TOOL_CALL` | `tool` |
| 其他所有类型 | `chain` |

## `langsmithRunIdFor` {/* #langsmithrunidfor */}

```typescript
function langsmithRunIdFor(spanId: string): string
```

返回导出器为 Mastra Span ID 使用的 LangSmith 运行 ID。通过 `mastra.observability.addScore()` 提交的评分会作为反馈关联到这些运行，因此无需保留进程内状态。

### 用法 {/* #usage-1 */}

```typescript
import { buildTracingOptions } from '@mastra/observability'
import { withLangsmithMetadata } from '@mastra/langsmith'

// Route to a specific project
const tracingOptions = buildTracingOptions(withLangsmithMetadata({ projectName: 'my-project' }))

// Set multiple fields
const tracingOptions = buildTracingOptions(
  withLangsmithMetadata({
    projectName: 'my-project',
    sessionId: 'user-123',
  }),
)
```
