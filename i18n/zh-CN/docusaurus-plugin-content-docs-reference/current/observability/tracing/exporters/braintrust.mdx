# 智囊团出口商

将跟踪数据发送到 Braintrust 进行评估和可观察。

## 构造函数 {/* #constructor */}

```typescript oxfmt:false
new BraintrustExporter(config: BraintrustExporterConfig)
```

## `BraintrustExporterConfig` {/* #braintrustexporterconfig */}

```typescript
interface BraintrustExporterConfig extends BaseExporterConfig {
  apiKey?: string
  endpoint?: string
  projectName?: string
  braintrustLogger?: Logger<true>
  currentSpan?: () => Span | undefined
  tuningParameters?: Record<string, any>
}
```

延伸`BaseExporterConfig`, which includes:

* `logger?: IMastraLogger`- 记录器实例
* `logLevel?: LogLevel | 'debug' | 'info' | 'warn' | 'error'`- 日志级别（默认：INFO）

## 方法 {/* #methods */}

### `exportTracingEvent` {/* #exporttracingevent */}

```typescript oxfmt:false
async exportTracingEvent(event: TracingEvent): Promise<void>
```

将跟踪事件导出到 Braintrust。

### 出口 {/* #export */}

```typescript oxfmt:false
async export(spans: ReadOnlySpan[]): Promise<void>
```

批量导出到 Braintrust。

### 冲水 {/* #flush */}

```typescript oxfmt:false
async flush(): Promise<void>
```

强制将所有缓冲跨度刷新到 Braintrust，而无需关闭导出器。在无服务器环境中很有用，您需要确保在运行时终止之前导出跨度。

### 关闭 {/* #shutdown */}

```typescript oxfmt:false
async shutdown(): Promise<void>
```

刷新待处理数据并关闭客户端。

## 用法 {/* #usage */}

### 零配置（使用环境变量） {/* #zero-config-using-environment-variables */}

```typescript
import { BraintrustExporter } from '@mastra/braintrust'

// Reads from BRAINTRUST_API_KEY, BRAINTRUST_ENDPOINT
const exporter = new BraintrustExporter()
```

### 显式配置 {/* #explicit-configuration */}

```typescript
import { BraintrustExporter } from '@mastra/braintrust'

const exporter = new BraintrustExporter({
  apiKey: process.env.BRAINTRUST_API_KEY,
  projectName: 'my-ai-project',
})
```

## 成本追踪 {/* #cost-tracking */}

智囊团使用跨度`metrics.estimated_cost` as its cost when the field is set, and estimates the cost from token metrics and its own model prices when it isn't. The exporter sets `metrics.estimated_cost` on a model generation span only when the generation's cost metadata meets every condition:

* `costContext.costMetadata.source`是`'provider_reported'`, meaning the model provider returned the cost, as OpenRouter and Vercel AI Gateway do.
* `costContext.costUnit`是`'USD'`.
* `costContext.estimatedCost`是一个大于的有限数`0`.

Mastra 自己的成本估算不会导出，因此 Braintrust 用其模型价格对这些跨度进行定价。报告的成本为`0` is skipped as well. Vercel AI Gateway reports `0` for bring-your-own-key requests, which your model provider still bills, and Braintrust's estimate is closer to that charge. The span metadata keeps the full `costContext` in every case.
