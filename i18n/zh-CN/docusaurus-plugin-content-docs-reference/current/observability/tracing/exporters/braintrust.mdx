# BraintrustExporter

将 Tracing 数据发送到 Braintrust，用于评估和可观测性。

## 构造函数 {/* #constructor */}

```typescript oxfmt:false
new BraintrustExporter(config: BraintrustExporterConfig)
```

## `BraintrustExporterConfig` {/* #braintrustexporterconfig */}

```typescript
interface BraintrustExporterConfig extends BaseExporterConfig {
  apiKey?: string
  endpoint?: string
  projectName?: string
  braintrustLogger?: Logger<true>
  currentSpan?: () => Span | undefined
  tuningParameters?: Record<string, any>
}
```

继承 `BaseExporterConfig`，其中包括：

- `logger?: IMastraLogger` - 日志记录器实例
- `logLevel?: LogLevel | 'debug' | 'info' | 'warn' | 'error'` - 日志级别（默认：INFO）

## 方法 {/* #methods */}

### `exportTracingEvent` {/* #exporttracingevent */}

```typescript oxfmt:false
async exportTracingEvent(event: TracingEvent): Promise<void>
```

将追踪事件导出到 Braintrust。

### export {/* #export */}

```typescript oxfmt:false
async export(spans: ReadOnlySpan[]): Promise<void>
```

批量将 Span 导出到 Braintrust。

### flush {/* #flush */}

```typescript oxfmt:false
async flush(): Promise<void>
```

强制将缓冲中的所有 Span 发送到 Braintrust，而不关闭导出器。适用于需要在运行环境终止前确保 Span 已导出的无服务器环境。

### shutdown {/* #shutdown */}

```typescript oxfmt:false
async shutdown(): Promise<void>
```

发送待处理数据并关闭客户端。

## 用法 {/* #usage */}

### 零配置（使用环境变量） {/* #zero-config-using-environment-variables */}

```typescript
import { BraintrustExporter } from '@mastra/braintrust'

// Reads from BRAINTRUST_API_KEY, BRAINTRUST_ENDPOINT
const exporter = new BraintrustExporter()
```

### 显式配置 {/* #explicit-configuration */}

```typescript
import { BraintrustExporter } from '@mastra/braintrust'

const exporter = new BraintrustExporter({
  apiKey: process.env.BRAINTRUST_API_KEY,
  projectName: 'my-ai-project',
})
```

## Span 类型映射 {/* #span-type-mapping */}

| Span 类型 | Braintrust 类型 |
| - | - |
| `MODEL_GENERATION` | `llm` |
| `MODEL_CHUNK` | `llm` |
| `TOOL_CALL` | `tool` |
| `MCP_TOOL_CALL` | `tool` |
| `PROVIDER_TOOL_CALL` | `tool` |
| `WORKFLOW_CONDITIONAL_EVAL` | `function` |
| `WORKFLOW_WAIT_EVENT` | `function` |
| 其他所有类型 | `task` |

## 成本追踪 {/* #cost-tracking */}

如果 Span 中设置了 `metrics.estimated_cost`，Braintrust 会将其作为成本；否则会根据 Token 用量指标和自身的模型价格估算成本。仅当模型生成的成本元数据同时满足以下条件时，导出器才会为该 Span 设置 `metrics.estimated_cost`：

- `costContext.costMetadata.source` 为 `'provider_reported'`，表示成本由模型提供商返回，例如 OpenRouter 和 Vercel AI Gateway。
- `costContext.costUnit` 为 `'USD'`。
- `costContext.estimatedCost` 是大于 `0` 的有限数。

Mastra 自己估算的成本不会导出，因此 Braintrust 会按自身的模型价格为这些 Span 估价。提供商报告的成本为 `0` 时也会跳过。Vercel AI Gateway 在自带密钥的请求中报告 `0`，但模型提供商仍会收费，此时 Braintrust 的估算更接近实际费用。无论哪种情况，Span 元数据都会保留完整的 `costContext`。
