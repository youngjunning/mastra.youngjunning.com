# 指标查询

指标查询从可观测性存储域读取原始和聚合指标数据。有关 Exporter 和存储设置，请参阅[指标概述](/docs/observability/metrics/overview)。有关自动生成的指标名称和标签，请参阅[自动指标参考](/reference/observability/metrics/automatic-metrics)。

## 访问方式 {/* #access */}

### 可观测性存储 {/* #observability-store */}

使用存储域进行进程内查询：

```typescript
const observability = await mastra.getStorage()?.getStore('observability')

if (!observability) {
  throw new Error('Observability storage is not configured')
}

const result = await observability.getMetricAggregate({
  name: ['mastra_agent_duration_ms'],
  aggregation: 'avg',
  filters: {
    timestamp: { start: new Date(Date.now() - 60 * 60 * 1000) },
  },
})
```

如果存储配置未提供可观测性存储域，`getStore('observability')` 会返回 `undefined`。

### 客户端 SDK {/* #client-sdk */}

`@mastra/client-js` 在 `MastraClient` 上提供分析和指标发现方法：

```typescript
import { MastraClient } from '@mastra/client-js'

const client = new MastraClient({
  baseUrl: 'http://localhost:4111',
})

const result = await client.getMetricAggregate({
  name: ['mastra_agent_duration_ms'],
  aggregation: 'avg',
})
```

客户端不提供原始记录的 `listMetrics()` 方法。要列出原始指标记录，请使用可观测性存储或 `GET /api/observability/metrics` 路由。

## 共用值 {/* #shared-values */}

### 聚合 {/* #aggregations */}

聚合、分组和时间序列方法接受以下 `aggregation` 值：

| 值 | 结果 |
| - | - |
| `sum` | 指标值之和 |
| `avg` | 指标值的平均值 |
| `min` | 最小指标值 |
| `max` | 最大指标值 |
| `count` | 匹配的指标记录数 |
| `count_distinct` | `distinctColumn` 中不同值的近似或精确数量，取决于存储后端 |
| `last`|最新匹配的指标值 |

当 `aggregation` 为 `count_distinct` 时，必须提供 `distinctColumn`。支持以下列：

```text
entityType
entityName
parentEntityType
parentEntityName
rootEntityType
rootEntityName
name
provider
model
environment
executionSource
serviceName
threadId
resourceId
```

### 间隔 {/* #intervals */}

时间序列和百分位数查询接受 `1m`、`5m`、`15m`、`1h` 或 `1d`。

### 过滤器 {/* #filters */}

所有指标操作都接受相同的可选 `filters` 对象。原始记录列表请求通过查询参数传递这些字段；分析方法则通过 JSON 请求体传递。

| 字段 | 类型 | 说明 |
| - | - | - |
| `timestamp` | `{ start?: Date; end?: Date; startExclusive?: boolean; endExclusive?: boolean }` | 时间戳范围。除非相应的排他标志为 `true`，否则边界均包含在范围内。HTTP 请求使用 ISO 日期字符串。 |
| `traceId` | `string` | 精确匹配的 trace ID |
| `traceIds` | `string[]` | 1 至 1,000 个 trace ID |
| `spanId` | `string` | 精确匹配的 span ID |
| `entityType` | `EntityType` | 实体类型 |
| `entityName` | `string`|实体名称 |
|`entityVersionId` | `string`|实体版本ID |
|`parentEntityType` | `EntityType`|父实体类型 |
|`parentEntityName` | `string`|父实体名称 |
|`parentEntityVersionId` | `string`|父实体版本 ID |
|`rootEntityType` | `EntityType`|根实体类型 |
|`rootEntityName` | `string`|根实体名称 |
|`rootEntityVersionId` | `string`|根实体版本 ID |
| `userId` | `string` | 用户 ID |
|`organizationId` | `string`|组织 ID |
|`experimentId` | `string`|实验或评估运行 ID |
|`experimentIds` | `string[]`| 1 到 1,000 个实验 ID |
|`serviceName` | `string`|服务名称|
|`environment` | `string`|环境名称 |
|`resourceId` | `string`|资源 ID |
|`runId` | `string`|运行 ID |
|`sessionId` | `string`|会话 ID |
|`threadId` | `string`|线程 ID |
|`requestId` | `string`|请求 ID |
| `executionSource` | `string` | 执行来源 |
|`tags` | `string[]`|记录必须包含所有指定的标签 |
|`name` | `string[]`|一个或多个指标名称 |
| `provider` | `string` | 模型 Provider |
| `model` | `string` | 模型 ID |
|`costUnit` | `string`|成本单位|
|`labels` | `Record<string, string>`|所有指定指标标签键值对的精确匹配 |
| `source` | `string` | 已弃用。请使用 `executionSource`。 |

## 分析方法 {/* #analytics-methods */}

### `getMetricAggregate(args)` {/* #getmetricaggregateargs */}

返回所有匹配记录聚合后的单个值。可观测性存储和 `MastraClient` 都提供此方法。

#### 参数 {/* #arguments */}

| 字段 | 类型 | 必填 | 说明 |
| - | - | - | - |
| `name` | `string[]` | Yes | 一个或多个指标名称 |
| `aggregation` | `AggregationType` | Yes | 要应用的聚合方式 |
| `distinctColumn` | `MetricDistinctColumn` | For `count_distinct` | 要统计不同值数量的列 |
| `filters` | `MetricsFilter` | No | 共用指标筛选条件 |
| `comparePeriod` | `'previous_period' \| 'previous_day' \| 'previous_week'` | No | 添加对比时段的值。`previous_period` 使用 `filters.timestamp` 的时长。 |

#### 返回值 {/* #returns */}

```typescript oxfmt:false
{
  value: number | null
  previousValue?: number | null
  changePercent?: number | null
  estimatedCost?: number | null
  costUnit?: string | null
  previousEstimatedCost?: number | null
  costChangePercent?: number | null
}
```

如果匹配记录没有共同的单位，`costUnit` 为 `null`。成本字段是可选的；记录不包含成本上下文时，这些字段也可能为 `null`。

```typescript
const result = await observability.getMetricAggregate({
  name: ['mastra_model_total_input_tokens', 'mastra_model_total_output_tokens'],
  aggregation: 'sum',
  filters: {
    timestamp: {
      start: new Date('2026-08-24T00:00:00Z'),
      end: new Date('2026-08-25T00:00:00Z'),
    },
  },
  comparePeriod: 'previous_period',
})
```

**HTTP：** `POST /api/observability/metrics/aggregate`

### `getMetricBreakdown(args)` {/* #getmetricbreakdownargs */}

按一个或多个维度对匹配记录分组，并聚合各组。可观测性存储和 `MastraClient` 都提供此方法。

#### 参数 {/* #arguments-1 */}

| 字段 | 类型 | 必填 | 说明 |
| - | - | - | - |
| `name` | `string[]` | Yes | 一个或多个指标名称 |
| `groupBy` | `string[]` | Yes | 一个或多个分组字段 |
| `aggregation` | `AggregationType` | Yes | 对每组应用的聚合方式 |
| `distinctColumn` | `MetricDistinctColumn` | For `count_distinct` | 要统计不同值数量的列 |
| `filters` | `MetricsFilter` | No | 共用指标筛选条件 |
| `limit` | `number` | No | 不超过 1,000 的正整数。按 `orderDirection` 排序后只保留前几个分组；省略时返回所有分组。对于 `threadId` 等高基数分组，请设置此值以限制响应大小。按标签键分组时，PostgreSQL 等部分存储会排除标签缺失或为空的记录，因此即使未设置 `limit`，各组之和也可能不等于总计。请使用 `getMetricAggregate()` 获取总计。 |
| `orderDirection` | `'ASC' \| 'DESC'` | No | 聚合值的排序方向。存储实现默认使用 `DESC`。 |

#### 返回值 {/* #returns-1 */}

```typescript
{
  groups: Array<{
    dimensions: Record<string, string | null>
    value: number
    estimatedCost?: number | null
    costUnit?: string | null
  }>
}
```

```typescript
const result = await client.getMetricBreakdown({
  name: ['mastra_model_total_input_tokens'],
  groupBy: ['entityName'],
  aggregation: 'sum',
  limit: 10,
  orderDirection: 'DESC',
})
```

**HTTP：** `POST /api/observability/metrics/breakdown`

### `getMetricTimeSeries(args)` {/* #getmetrictimeseriesargs */}

按时间间隔将匹配的值分桶，并可选择分组。可观测性存储和 `MastraClient` 都提供此方法。

#### 参数 {/* #arguments-2 */}

| 字段 | 类型 | 必填 | 说明 |
| - | - | - | - |
| `name` | `string[]` | Yes | 一个或多个指标名称 |
| `interval` | `AggregationInterval` | Yes | 时间桶的间隔 |
| `aggregation` | `AggregationType` | Yes | 对每个时间桶应用的聚合方式 |
| `distinctColumn` | `MetricDistinctColumn` | For `count_distinct` | 要统计不同值数量的列 |
| `filters` | `MetricsFilter` | No | 共用指标筛选条件 |
| `groupBy` | `string[]` | No | 用于将结果拆分为多个序列的字段 |

#### 返回值 {/* #returns-2 */}

```typescript
{
  series: Array<{
    name: string
    costUnit?: string | null
    points: Array<{
      timestamp: Date
      value: number
      estimatedCost?: number | null
    }>
  }>
}
```

```typescript
const result = await client.getMetricTimeSeries({
  name: ['mastra_model_total_input_tokens'],
  interval: '1h',
  aggregation: 'sum',
  filters: {
    timestamp: { start: new Date(Date.now() - 24 * 60 * 60 * 1000) },
  },
})
```

**HTTP：** `POST /api/observability/metrics/timeseries`

### `getMetricPercentiles(args)` {/* #getmetricpercentilesargs */}

计算各时间桶的百分位数值。可观测性存储和 `MastraClient` 都提供此方法。

#### 参数 {/* #arguments-3 */}

| 字段 | 类型 | 必填 | 说明 |
| - | - | - | - |
| `name` | `string` | Yes | 一个指标名称 |
| `percentiles` | `number[]` | Yes | 一个或多个介于 `0` 和 `1` 之间的值 |
| `interval` | `AggregationInterval` | Yes | 时间桶的间隔 |
| `filters` | `MetricsFilter` | No | 共用指标筛选条件 |

#### 返回值 {/* #returns-3 */}

```typescript
{
  series: Array<{
    percentile: number
    points: Array<{
      timestamp: Date
      value: number
    }>
  }>
}
```

```typescript
const result = await client.getMetricPercentiles({
  name: 'mastra_agent_duration_ms',
  percentiles: [0.5, 0.95, 0.99],
  interval: '1h',
})
```

**HTTP：** `POST /api/observability/metrics/percentiles`

## 原始指标记录 {/* #raw-metric-records */}

### `listMetrics(args)` {/* #listmetricsargs */}

返回已存储的指标观测记录，不进行聚合。此方法由可观测性存储提供；HTTP 路由以查询参数接收相同字段。

#### 参数 {/* #arguments-4 */}

默认使用分页模式：

```typescript oxfmt:false
{
  mode?: 'page'
  filters?: MetricsFilter
  pagination?: {
    page?: number // Default: 0
    perPage?: number // Default: 10; maximum: 100
  }
  orderBy?: {
    field?: 'timestamp' // Default: 'timestamp'
    direction?: 'ASC' | 'DESC' // Default: 'DESC'
  }
}
```

增量模式支持增量轮询：

```typescript oxfmt:false
{
  mode: 'delta'
  filters?: MetricsFilter
  after?: string
  limit?: number // Default: 10; maximum: 100
}
```

增量模式不允许使用 `pagination` 和 `orderBy`；分页模式不允许使用 `after` 和 `limit`。不支持增量轮询的后端会返回操作不受支持的错误。

#### 返回值 {/* #returns-4 */}

```typescript oxfmt:false
{
  metrics: MetricRecord[]
  pagination?: {
    total: number
    page: number
    perPage: number | false
    hasMore: boolean
  }
  delta?: {
    limit: number
    hasMore: boolean
  }
  deltaCursor?: string
}
```

`MetricRecord` 的结构如下：

```typescript oxfmt:false
{
  metricId?: string | null
  timestamp: Date
  name: string
  value: number
  traceId?: string | null
  spanId?: string | null
  entityType?: EntityType | null
  entityId?: string | null
  entityName?: string | null
  parentEntityType?: EntityType | null
  parentEntityId?: string | null
  parentEntityName?: string | null
  rootEntityType?: EntityType | null
  rootEntityId?: string | null
  rootEntityName?: string | null
  userId?: string | null
  organizationId?: string | null
  resourceId?: string | null
  runId?: string | null
  sessionId?: string | null
  threadId?: string | null
  requestId?: string | null
  environment?: string | null
  serviceName?: string | null
  scope?: Record<string, unknown> | null
  entityVersionId?: string | null
  parentEntityVersionId?: string | null
  rootEntityVersionId?: string | null
  experimentId?: string | null
  executionSource?: string | null
  tags?: string[] | null
  source?: string | null // Deprecated
  provider?: string | null
  model?: string | null
  estimatedCost?: number | null
  costUnit?: string | null
  costMetadata?: Record<string, unknown> | null
  labels: Record<string, string>
  metadata?: Record<string, unknown> | null
}
```

**HTTP：** `GET /api/observability/metrics`

## 指标发现 {/* #metric-discovery */}

可观测性存储和 `MastraClient` 都提供指标发现方法。HTTP 请求通过查询参数传递参数。

| 方法 | 参数 | 返回值 | HTTP 路由 |
| - | - | - | - |
|`getMetricNames(args?)` | `{ prefix?: string; limit?: number }` | `{ names: string[] }` | `GET /api/observability/discovery/metric-names` |
| `getMetricLabelKeys(args)` | `{ metricName: string }` | `{ keys: string[] }` | `GET /api/observability/discovery/metric-label-keys` |
| `getMetricLabelValues(args)` | `{ metricName: string; labelKey: string; prefix?: string; limit?: number }` | `{ values: string[] }` | `GET /api/observability/discovery/metric-label-values` |

提供 `limit` 时，其值必须是正整数。

```typescript
const { names } = await client.getMetricNames({ prefix: 'mastra_model_' })
const { keys } = await client.getMetricLabelKeys({ metricName: names[0] })
const { values } = await client.getMetricLabelValues({
  metricName: names[0],
  labelKey: keys[0],
  limit: 20,
})
```

可观测性发现 API 还提供 trace、日志和指标共用的维度：

| 存储或客户端方法 | 参数 | HTTP 路由 |
| - | - | - |
| `getEntityTypes()` | `MastraClient` 中无需参数；存储中为 `{}` | `GET /api/observability/discovery/entity-types` |
| `getEntityNames(args?)` | `{ entityType?: EntityType }` | `GET /api/observability/discovery/entity-names` |
| `getServiceNames()` | `MastraClient` 中无需参数；存储中为 `{}` | `GET /api/observability/discovery/service-names` |
| `getEnvironments()` | `MastraClient` 中无需参数；存储中为 `{}` | `GET /api/observability/discovery/environments` |
| `getTags(args?)` | `{ entityType?: EntityType }` | `GET /api/observability/discovery/tags` |

## HTTP 路由 {/* #http-routes */}

| 方法 | 路由 | 输入 |
| - | - | - |
| `GET` | `/api/observability/metrics` | 查询参数 |
| `POST` | `/api/observability/metrics/aggregate` | JSON 请求体 |
| `POST` | `/api/observability/metrics/breakdown` | JSON 请求体 |
| `POST` | `/api/observability/metrics/timeseries` | JSON 请求体 |
| `POST` | `/api/observability/metrics/percentiles` | JSON 请求体 |
| `GET` | `/api/observability/discovery/metric-names` | 查询参数 |
| `GET` | `/api/observability/discovery/metric-label-keys` | 查询参数 |
| `GET` | `/api/observability/discovery/metric-label-values` | 查询参数 |
| `GET` | `/api/observability/discovery/entity-types` | 无 |
| `GET` | `/api/observability/discovery/entity-names` | 查询参数 |
| `GET` | `/api/observability/discovery/service-names` | 无 |
| `GET` | `/api/observability/discovery/environments` | 无 |

所有路由都需要已配置的可观测性存储域。启用运行时授权后，聚合、分组、时间序列和百分位数路由均需要 `observability:read` 权限。

## 不支持的后端 {/* #unsupported-backends */}

基础可观测性存储实现会在原始记录列表、分析和发现方法上抛出 `*_NOT_IMPLEMENTED` 错误。因此，即使配置了可观测性存储域，其后端也可能不支持指标查询。

DuckDB、ClickHouse、Postgres v-next 可观测性存储和内存可观测性存储支持指标查询。Google Cloud Spanner 仅在 `disableMetrics` 为 `false` 时支持；指标默认禁用。其他存储适配器可能支持追踪，但不支持指标。

## CLI {/* #cli */}

`mastra api metric` 命令涵盖聚合、分组、时间序列、百分位数、指标名称、标签键和标签值查询。命令用法、目标选择、身份验证和 schema 查看方法请参阅 [`mastra api metric` CLI 参考](/reference/cli/mastra#mastra-api-metric-aggregate)。
