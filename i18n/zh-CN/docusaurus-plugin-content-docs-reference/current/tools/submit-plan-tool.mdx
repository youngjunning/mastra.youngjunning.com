# submitPlanTool

这个内置 Tool 不依赖特定 Agent，可提交实施计划供用户审阅。Agent 将计划写入 Markdown 文件，并将文件路径传给此 Tool。Tool 会暂停本次运行，直到用户批准或拒绝计划。

此 Tool 使用原生的 [Tool 暂停机制](/docs/agents/human-in-the-loop#runtime-suspension-with-suspend)：它调用 `suspend({ path })`，使 Agent 发出 `tool-call-suspended` 事件。宿主程序读取计划文件并展示给用户，然后根据用户的批准或拒绝恢复运行。

如果在 Agent 运行之外执行，无法使用 `suspend`，此 Tool 会返回一段包含文件路径、便于阅读的备用文本。

## 使用示例 {/* #usage-example */}

将 `submitPlanTool` 添加到 Agent 的 Tool 集合：

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { submitPlanTool } from '@mastra/core/tools'

const agent = new Agent({
  id: 'planner',
  name: 'Planner',
  instructions: 'Write a plan to a file before starting work, then submit it for approval.',
  model,
  tools: { submitPlanTool },
})
```

处理暂停和恢复：

```typescript title="src/run.ts"
import fs from 'node:fs'

const stream = await agent.stream('Refactor the auth module')

for await (const chunk of stream.fullStream) {
  if (chunk.type === 'tool-call-suspended' && chunk.payload.toolName === 'submit_plan') {
    const { path } = chunk.payload.suspendPayload
    const plan = fs.readFileSync(path, 'utf-8')
    console.log(plan)

    // Approve:
    const resumed = await agent.resumeStream({ action: 'approved' }, { runId: stream.runId })
    for await (const c of resumed.textStream) process.stdout.write(c)
  }
}
```

拒绝并反馈：

```typescript
await agent.resumeStream(
  { action: 'rejected', feedback: 'Add error handling steps' },
  { runId: stream.runId },
)
```

## 批准或拒绝后的行为 {/* #approval-behavior */}

* **批准：**Tool 向模型返回 `"Plan approved. Proceed with implementation following the approved plan."`，告知模型计划已获批准，并按该计划继续实施。
* **拒绝并提供反馈：**Tool 将反馈返回给模型，并要求模型修改计划后重新提交。
* **拒绝但未提供反馈：**Tool 告知模型先等待用户的下一条消息，再修改计划。

在 [AgentController](/docs/harness/agent-controller) 中使用时，计划获批后，控制器会从当前模式切换到 `transitionsTo` 配置的模式。如果未配置 `transitionsTo`，控制器会切换到其[解析出的默认模式](/reference/agent-controller/agent-controller-class#getdefaultmode)。详情请参阅[模式](/docs/harness/agent-controller#switch-modes-and-models)。
