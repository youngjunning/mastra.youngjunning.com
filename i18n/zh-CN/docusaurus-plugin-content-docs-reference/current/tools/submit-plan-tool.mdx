# 提交计划Tool

一个与Agent无关的内置Tool，可提交实施计划以供用户审核。Agent将计划写入 markdown 文件并将文件路径传递给该Tool。该Tool会暂停运行，直到用户批准或拒绝该计划。

该Tool通过本机暂停[tool suspension](/docs/agents/human-in-the-loop#runtime-suspension-with-suspend) primitive: it calls `suspend({ path })`，这使得Agent发出`tool-call-suspended`事件。主机读取计划文件并将其呈现给用户。然后它会以批准或拒绝的方式恢复。

当在Agent运行外部执行时（无`suspend` available), the tool returns a readable fallback string containing the file path.

## 使用示例 {/* #usage-example */}

添加`submitPlanTool` to an agent's toolset:

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { submitPlanTool } from '@mastra/core/tools'

const agent = new Agent({
  id: 'planner',
  name: 'Planner',
  instructions: 'Write a plan to a file before starting work, then submit it for approval.',
  model,
  tools: { submitPlanTool },
})
```

处理暂停和恢复：

```typescript title="src/run.ts"
import fs from 'node:fs'

const stream = await agent.stream('Refactor the auth module')

for await (const chunk of stream.fullStream) {
  if (chunk.type === 'tool-call-suspended' && chunk.payload.toolName === 'submit_plan') {
    const { path } = chunk.payload.suspendPayload
    const plan = fs.readFileSync(path, 'utf-8')
    console.log(plan)

    // Approve:
    const resumed = await agent.resumeStream({ action: 'approved' }, { runId: stream.runId })
    for await (const c of resumed.textStream) process.stdout.write(c)
  }
}
```

拒绝并反馈：

```typescript
await agent.resumeStream(
  { action: 'rejected', feedback: 'Add error handling steps' },
  { runId: stream.runId },
)
```

## 认可行为 {/* #approval-behavior */}

* **得到正式认可的：**&#x5DE5;具返回`"Plan approved. Proceed with implementation following the approved plan."` to the model.
* **被拒绝并反馈：**&#x8BE5;Tool返回反馈并要求模型修改计划并再次提交。
* **没有反馈就被拒绝：**&#x8BE5;Tool告诉模型在修改之前等待用户的下一条消息。

当在内部使用时[AgentController](/docs/harness/agent-controller), plan approval switches from the current mode to the mode configured by `transitionsTo`. When no `transitionsTo` is configured, the controller switches to its [resolved default mode](/reference/agent-controller/agent-controller-class#getdefaultmode). See [Modes](/docs/harness/agent-controller#switch-modes-and-models) for details.
