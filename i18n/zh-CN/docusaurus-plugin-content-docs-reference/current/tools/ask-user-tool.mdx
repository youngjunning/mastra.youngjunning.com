# 询问用户Tool

一种与Agent无关的内置Tool，可向用户询问问题并等待他们的响应。该Tool支持自由文本问题、单选提示和多选提示。

该Tool通过本机暂停[tool suspension](/docs/agents/human-in-the-loop#runtime-suspension-with-suspend) primitive: it calls `suspend()`带有问题有效负载，这使得Agent发出`tool-call-suspended`事件并持续运行状态。继续运行`agent.resumeStream(answer, { runId })`.

当在Agent运行外部执行时（无`suspend` available), the tool returns a readable fallback string containing the question and choices.

## 使用示例 {/* #usage-example */}

添加`askUserTool` to an agent's toolset:

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { askUserTool } from '@mastra/core/tools'

const agent = new Agent({
  id: 'assistant',
  name: 'Assistant',
  instructions: 'Ask the user for clarification when the request is ambiguous.',
  model,
  tools: { askUserTool },
})
```

处理暂停和恢复：

```typescript title="src/run.ts"
const stream = await agent.stream('Summarize my project')

for await (const chunk of stream.fullStream) {
  if (chunk.type === 'tool-call-suspended') {
    const { question, options, selectionMode } = chunk.payload.suspendPayload
    // Present the question to the user, collect their answer, then resume:
    const resumed = await agent.resumeStream('The main repo', { runId: stream.runId })
    for await (const c of resumed.textStream) process.stdout.write(c)
  }
}
```

对于多选提示，请使用字符串数组继续：

```typescript
await agent.resumeStream(['Add tests', 'Update docs'], { runId: stream.runId })
```

## 恢复数据 {/* #resume-data */}

将用户的答案传递给`agent.resumeStream()`:

* **自由文本和单选：**&#x4E00;个`string`.
* **多选：**&#x4E00;个`string[]` of selected option labels and any custom answer.

工厂和工作室报价**Other…** alongside the suggested options. Select it to turn that option into a text field and enter a custom answer, then select **Submit answer** or press Enter. Single-select prompts resume with the trimmed text as a string. Multi-select prompts resume with the selected labels followed by the trimmed custom text. You can submit custom text without selecting a suggested option.

如果**Other…** is selected, the text field must contain a non-empty answer. Leaving an empty or whitespace-only field unselects **Other…**. Unselecting **Other…** excludes the custom text from the response. The **Other…** label itself is never included in the resume data.
