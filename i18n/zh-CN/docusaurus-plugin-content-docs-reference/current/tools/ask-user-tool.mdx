# askUserTool

askUserTool 是一个不依赖特定 Agent 的内置 Tool，可向用户提问并等待回答。它支持自由文本问题、单选和多选。

该 Tool 通过原生的 [Tool 暂停机制](/docs/agents/human-in-the-loop#runtime-suspension-with-suspend)暂停运行：它调用 `suspend()` 并传入问题数据，使 Agent 发出 `tool-call-suspended` 事件并持久化运行状态。使用 `agent.resumeStream(answer, { runId })` 恢复运行。

如果在 Agent 运行之外执行（此时无法使用 `suspend`），该 Tool 会返回一段易读的备用文本，其中包含问题和选项。

## 使用示例 {/* #usage-example */}

将 `askUserTool` 添加到 Agent 的工具集中：

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { askUserTool } from '@mastra/core/tools'

const agent = new Agent({
  id: 'assistant',
  name: 'Assistant',
  instructions: 'Ask the user for clarification when the request is ambiguous.',
  model,
  tools: { askUserTool },
})
```

处理暂停和恢复：

```typescript title="src/run.ts"
const stream = await agent.stream('Summarize my project')

for await (const chunk of stream.fullStream) {
  if (chunk.type === 'tool-call-suspended') {
    const { question, options, selectionMode } = chunk.payload.suspendPayload
    // Present the question to the user, collect their answer, then resume:
    const resumed = await agent.resumeStream('The main repo', { runId: stream.runId })
    for await (const c of resumed.textStream) process.stdout.write(c)
  }
}
```

对于多选问题，使用字符串数组恢复运行：

```typescript
await agent.resumeStream(['Add tests', 'Update docs'], { runId: stream.runId })
```

## 恢复数据 {/* #resume-data */}

将用户的回答传给 `agent.resumeStream()`：

- **自由文本和单选：**一个 `string`。
- **多选：**一个 `string[]`，包含所选选项的标签以及任何自定义回答。

Factory 和 Studio 会在建议选项旁提供 **Other…**。选中后，该选项会变成文本框，可输入自定义回答；然后选择 **Submit answer** 或按 Enter 提交。对于单选，恢复运行时会传入去除首尾空白后的自定义文本字符串。对于多选，会先传入所选选项的标签，再传入去除首尾空白后的自定义文本。无需选择建议选项，也可以提交自定义文本。

如果选中 **Other…**，文本框中的回答不能为空。文本框为空或只包含空白字符时，**Other…** 会取消选中。取消选中 **Other…** 后，自定义文本不会包含在回答中。恢复数据始终不包含 **Other…** 标签本身。
