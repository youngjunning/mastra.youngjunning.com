# createDocumentChunkerTool()

`createDocumentChunkerTool()` 创建将文档拆分为较小分块的工具，以便高效处理和检索。它支持多种分块策略和可配置的参数。

## 基本用法 {/* #basic-usage */}

```typescript
import { createDocumentChunkerTool, MDocument } from '@mastra/rag'

const document = new MDocument({
  text: 'Your document content here...',
  metadata: { source: 'user-manual' },
})

const chunker = createDocumentChunkerTool({
  doc: document,
  params: {
    strategy: 'recursive',
    maxSize: 512,
    overlap: 50,
    separators: ['\n'],
  },
})

const { chunks } = await chunker.execute()
```

## 自定义参数示例 {/* #example-with-custom-parameters */}

```typescript
const technicalDoc = new MDocument({
  text: longDocumentContent,
  metadata: {
    type: 'technical',
    version: '1.0',
  },
})

const chunker = createDocumentChunkerTool({
  doc: technicalDoc,
  params: {
    strategy: 'recursive',
    maxSize: 1024, // Larger chunks
    overlap: 100, // More overlap
    separators: ['\n\n'], // Split on double newlines
  },
})

const { chunks } = await chunker.execute()

// Process the chunks
chunks.forEach((chunk, index) => {
  console.log(`Chunk ${index + 1} length: ${chunk.content.length}`)
})
```

## 工具详情 {/* #tool-details */}

文档分块器会创建为具有以下属性的 Mastra 工具：

- **工具 ID**：`Document Chunker {strategy} {maxSize}`
- **描述**：`Chunks document using {strategy} strategy with maxSize {maxSize} and {overlap} overlap`
- **输入 Schema**：空对象（无需其他输入）
- **输出 Schema**：包含分块数组的对象
