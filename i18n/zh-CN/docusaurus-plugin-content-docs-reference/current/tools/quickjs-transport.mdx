# QuickJsCodeMode传输

这`QuickJsCodeModeTransport`班级跑步[编码方式](/docs/agents/code-mode)进程中的程序[快速JS](https://bellard.org/quickjs/)运行时编译为 WebAssembly。运行时是执行边界，因此不需要WorkspaceSandbox：程序没有文件系统、网络、进程或模块访问权限。它唯一的能力是`external_*`函数，它回调主机上的真实Tool。

不像[`IsolatedVmCodeModeTransport`](/reference/tools/isolated-vm-transport), this transport installs no native binaries and needs no Node.js flags, so it runs on serverless platforms that disallow both. The tradeoff is speed: see [Choosing a transport](#choosing-a-transport).

## 安装 {/* #installation */}

```bash npm2yarn
npm install @mastra/quickjs
```

该软件包包含 WebAssembly 模块，因此安装它会复制文件并且不运行其他任何内容。

## 用法 {/* #usage */}

将传输作为第二个参数传递给`createCodeMode()`. No `sandbox` is needed:

```typescript
import { createCodeMode } from '@mastra/core/tools'
import { QuickJsCodeModeTransport } from '@mastra/quickjs'

const { tool, instructions } = createCodeMode(
  { tools: { getTopProducts, getProductRatings } },
  new QuickJsCodeModeTransport({ memoryLimitMb: 128 }),
)
```

## 选择交通Tool {/* #choosing-a-transport */}

所有三种传输在主机上强制执行相同的允许列表、Tool验证和跟踪。它们的不同之处在于程序本身可以达到的范围以及主机必须提供的范围。

| | `StdioCodeModeTransport` | `IsolatedVmCodeModeTransport` | `QuickJsCodeModeTransport` |
| - | - | - | - |
| Isolation boundary | Workspace sandbox | V8 isolate | QuickJS WebAssembly runtime |
| Requires a sandbox | Yes | No | No |
| Native binary | Node.js runtime in the sandbox | Yes | No |
| Node.js flags | None | `--no-node-snapshot` on Node.js 20 and later | None |
| Runs in the browser | No | No | Yes |
| Execution speed | Fastest | Fast | Slowest |

选择`QuickJsCodeModeTransport` when the host can't install native addons or set Node.js flags, which is common on serverless platforms. Choose `IsolatedVmCodeModeTransport` when the host allows both and programs do heavy computation.

速度差异在于程序主体，而不是Tool调用。 QuickJS 进行解释而不是 JIT 编译，因此计算量大的循环的运行速度可能比 V8 隔离中慢数十倍，而主要等待的程序`external_*` calls performs about the same because the time goes to the tools. Code Mode programs are usually the second kind.

## 它是如何运作的 {/* #how-it-works */}

每次运行都会创建一个具有自己的堆的新 QuickJS 运行时。 TypeScript 在主机上被剥离[ts-blank-space](https://github.com/bloomberg/ts-blank-space), which erases type annotations without a native compiler, then the program is evaluated inside the runtime. Every `external_*` call crosses the boundary as JSON strings in both directions, so no host object references leak into model-authored code.

一个`external_*` call returns a pending promise to the program and hands control straight back to the host, so many calls can be in flight at once and `Promise.all` behaves as expected.

这`timeout` configured on `createCodeMode()` applies to both asynchronous hangs and synchronous infinite loops, and the runtime is disposed after every run.
