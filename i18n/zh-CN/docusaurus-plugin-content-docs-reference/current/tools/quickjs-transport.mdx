# QuickJsCodeModeTransport

`QuickJsCodeModeTransport` 类在编译为 WebAssembly 的进程内 [QuickJS](https://bellard.org/quickjs/) 运行时中执行 [Code mode](/docs/agents/code-mode) 程序。运行时构成执行边界，因此无需 Workspace Sandbox：程序无法访问文件系统、网络、进程或模块。它只能通过 `external_*` 函数调用宿主环境中的实际 Tool。

与 [`IsolatedVmCodeModeTransport`](/reference/tools/isolated-vm-transport) 不同，这种传输方式无需安装原生二进制文件，也无需设置 Node.js 启动参数，因此可在不允许这两者的无服务器平台上运行。代价是执行速度较慢，详见[选择传输方式](#choosing-a-transport)。

## 安装 {/* #installation */}

```bash npm2yarn
npm install @mastra/quickjs
```

该包包含 WebAssembly 模块；安装时只会复制文件，不会执行其他操作。

## 用法 {/* #usage */}

将传输实例作为第二个参数传给 `createCodeMode()`，无需提供 `sandbox`：

```typescript
import { createCodeMode } from '@mastra/core/tools'
import { QuickJsCodeModeTransport } from '@mastra/quickjs'

const { tool, instructions } = createCodeMode(
  { tools: { getTopProducts, getProductRatings } },
  new QuickJsCodeModeTransport({ memoryLimitMb: 128 }),
)
```

## 选择传输方式 {/* #choosing-a-transport */}

三种传输方式都由宿主环境执行相同的允许列表检查、Tool 验证和追踪。区别在于程序本身能访问什么，以及宿主环境需要提供什么。

| | `StdioCodeModeTransport` | `IsolatedVmCodeModeTransport` | `QuickJsCodeModeTransport` |
| - | - | - | - |
| 隔离边界 | Workspace Sandbox | V8 隔离环境 | QuickJS WebAssembly 运行时 |
| 需要 Sandbox | 是 | 否 | 否 |
| 原生二进制文件 | Sandbox 中的 Node.js 运行时 | 需要 | 不需要 |
| Node.js 启动参数 | 无 | Node.js 20 及更高版本需要 `--no-node-snapshot` | 无 |
| 可在浏览器中运行 | 否 | 否 | 是 |
| 执行速度 | 最快 | 快 | 最慢 |

如果宿主环境无法安装原生扩展或设置 Node.js 启动参数（无服务器平台上常见），请选择 `QuickJsCodeModeTransport`。如果宿主环境允许这两项操作，且程序需要执行大量计算，请选择 `IsolatedVmCodeModeTransport`。

速度差异体现在程序本身，而非 Tool 调用。QuickJS 以解释方式执行代码，不进行 JIT 编译，因此计算密集型循环可能比在 V8 隔离环境中慢数十倍。主要等待 `external_*` 调用的程序则表现相近，因为大部分时间花在 Tool 上。Code mode 程序通常属于后一种。

## 工作原理 {/* #how-it-works */}

每次运行都会创建一个拥有独立堆内存的全新 QuickJS 运行时。宿主环境先使用 [ts-blank-space](https://github.com/bloomberg/ts-blank-space) 去除 TypeScript 类型注解，无需原生编译器，然后在运行时中执行程序。每次 `external_*` 调用都以 JSON 字符串的形式双向跨越执行边界，因此宿主对象的引用不会泄露到模型编写的代码中。

`external_*` 调用会向程序返回一个待完成的 Promise，并立即将控制权交还给宿主环境。因此，多个调用可以同时进行，`Promise.all` 也会按预期工作。

在 `createCodeMode()` 中配置的 `timeout` 同时适用于异步挂起和同步无限循环。每次运行结束后，运行时都会被释放。
