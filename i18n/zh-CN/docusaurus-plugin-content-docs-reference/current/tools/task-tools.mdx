# 任务Tool

四个与Agent无关的内置Tool，用于管理Agent运行的结构化任务列表。任务列表持久化在线程范围内`threadState`存储域并投影到Agent上[状态信号](/docs/signals/state-signals)车道，以便它生存[观察记忆](/docs/memory/observational-memory)截断。

任务跟踪需要内存支持的线程（`threadId` + `resourceId`). Without memory the tools return an error explaining that task tracking requires agent memory.

推荐的设置是[`TaskSignalProvider`](/reference/signals/task-signal-provider), which bundles all four tools and the `TaskStateProcessor` in a single registration. See [Built-in tools](/docs/agents/tools#task-tracking) for the conceptual guide.

## 使用示例 {/* #usage-example */}

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { Memory } from '@mastra/memory'
import { TaskSignalProvider } from '@mastra/core/signals'

const agent = new Agent({
  id: 'coder',
  name: 'Coder',
  instructions: 'Track your progress with the task tools.',
  model,
  memory: new Memory(),
  signals: [new TaskSignalProvider()],
})
```

或者直接导入Tool。`taskWriteTool`, `taskUpdateTool`, `taskCompleteTool`, and `taskCheckTool` are the export names; `task_write`, `task_update`, `task_complete`， 和`task_check`是模型在Tool调用和跟踪中看到的Tool ID：

```typescript title="src/mastra/agents/index.ts"
import { taskWriteTool, taskUpdateTool, taskCompleteTool, taskCheckTool } from '@mastra/core/tools'
import { Agent } from '@mastra/core/agent'
import { Memory } from '@mastra/memory'

const agent = new Agent({
  id: 'coder',
  name: 'Coder',
  instructions: 'Track your progress with the task tools.',
  model,
  memory: new Memory(),
  tools: { taskWriteTool, taskUpdateTool, taskCompleteTool, taskCheckTool },
})
```

## `task_write` {/* #task_write */}

创建或替换整个任务列表。每次调用都会替换之前的列表。

### 输入模式 {/* #input-schema */}

<PropertiesTable
  content={[
{
  name: 'tasks',
  type: 'TaskItemInput[]',
  description: 'The complete updated task list.',
  isOptional: false,
  properties: [
    {
      type: 'TaskItemInput',
      parameters: [
        {
          name: 'id',
          type: 'string',
          description:
            "Stable task identifier (e.g. 'task_investigate_tests'). Keep this unchanged across updates. Auto-generated when omitted.",
          isOptional: true,
        },
        {
          name: 'content',
          type: 'string',
          description: "Task description in imperative form (e.g. 'Fix authentication bug').",
        },
        {
          name: 'status',
          type: "'pending' | 'in_progress' | 'completed'",
          description: 'Current task status.',
        },
        {
          name: 'activeForm',
          type: 'string',
          description: "Present continuous form shown during execution (e.g. 'Fixing authentication bug').",
        },
      ],
    },
  ],
},
]}
/>

### 输出 {/* #output */}

返回一个`TaskToolResult` with a human-readable `content` summary, the full `tasks` array with assigned IDs, and an `isError` flag.

### 行为 {/* #behavior */}

* ID 在一次调用中必须是唯一的。重复的显式 ID 会生成一个后备。
* 当重写现有列表时省略 ID 时，一个明确的匹配任务将重用其先前的 ID 以保持稳定性。
* 只能有一项任务`in_progress` status at a time. Submitting multiple `in_progress` tasks returns an error.

## `task_update` {/* #task_update */}

通过其稳定 ID 更新一项任务。仅包括已更改的字段。

### 输入模式 {/* #input-schema-1 */}

<PropertiesTable
  content={[
{
  name: 'id',
  type: 'string',
  description: 'The stable task identifier to update.',
  isOptional: false,
},
{
  name: 'content',
  type: 'string',
  description: 'New task description in imperative form.',
  isOptional: true,
},
{
  name: 'status',
  type: "'pending' | 'in_progress' | 'completed'",
  description: 'New task status.',
  isOptional: true,
},
{
  name: 'activeForm',
  type: 'string',
  description: 'New present continuous form.',
  isOptional: true,
},
]}
/>

至少其中之一`content`, `status`, or `activeForm` is required.

### 行为 {/* #behavior-1 */}

* 当更新将任务设置为`in_progress`, any other `in_progress` task is automatically demoted to `pending`.
* 当未找到 ID 时，返回可用任务 ID 的错误。

## `task_complete` {/* #task_complete */}

通过其稳定 ID 标记已完成的一项任务。

### 输入模式 {/* #input-schema-2 */}

<PropertiesTable
  content={[
{
  name: 'id',
  type: 'string',
  description: 'The stable task identifier to mark completed.',
  isOptional: false,
},
]}
/>

### 行为 {/* #behavior-2 */}

当未找到 ID 时，返回可用任务 ID 的错误。
