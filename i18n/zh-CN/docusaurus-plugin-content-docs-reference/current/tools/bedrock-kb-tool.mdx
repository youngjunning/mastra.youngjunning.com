# createBedrockKBTool()

`createBedrockKBTool()` 函数创建一个 Tool，用于从 Amazon Bedrock 知识库检索相关文档。它支持托管搜索配置和代理式检索（查询分解与托管重排序）；代理式检索失败时会自动回退到标准检索。

## 使用示例 {/* #usage-example */}

```typescript
import { createBedrockKBTool } from '@mastra/rag'

const kbTool = createBedrockKBTool({
  knowledgeBaseId: 'YOUR_KB_ID',
  region: 'us-west-2',
  numberOfResults: 5,
  useAgenticRetrieval: true,
})
```

### 与 Agent 配合使用 {/* #with-an-agent */}

```typescript
import { Agent } from '@mastra/core/agent'
import { createBedrockKBTool } from '@mastra/rag'

const kbTool = createBedrockKBTool({
  knowledgeBaseId: 'YOUR_KB_ID',
})

const agent = new Agent({
  name: 'KnowledgeAssistant',
  instructions: 'Use the knowledge base tool to answer questions.',
  model: myModel,
  tools: { kb: kbTool },
})
```

| 字段 | 类型 | 描述 |

| `content` | `string` | 检索到的文本片段内容。 |

## 检索方式 {/* #retrieval-modes */}

### 代理式检索（默认） {/* #agentic-retrieval-default */}

当 `useAgenticRetrieval` 为 `true`（默认值）时，此 Tool 使用 `AgenticRetrieveStreamCommand`：

- 将复杂查询分解为子查询
- 分多轮进行检索
- 使用托管重排序改善结果

如果代理式检索失败（例如 SDK 版本过旧或权限不足），则自动回退到标准托管检索。

### 标准托管检索 {/* #standard-managed-retrieval */}

当 `useAgenticRetrieval` 为 `false` 时，此 Tool 使用带有 `managedSearchConfiguration` 的 `RetrieveCommand`，直接进行单轮检索。

## 基于用户的访问控制 {/* #user-based-access-control */}

在 Mastra 请求上下文中设置 `userId`，即可将其作为 Bedrock 的 `userContext.userId` 传递。这适用于实施文档级访问控制的知识库。请求上下文中的值会覆盖此 Tool 配置的默认 `userId`。

```typescript
import { RequestContext } from '@mastra/core/request-context'

const requestContext = new RequestContext()
requestContext.set('userId', 'user-123')

await agent.generate('Find my private documents', { requestContext })
```
