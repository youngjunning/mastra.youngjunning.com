# 创建BedrockKBTool()

这`createBedrockKBTool()`函数创建一个从 Amazon Bedrock 知识库检索相关文档的Tool。它支持托管搜索配置和Agent检索（查询分解和托管重新排名），并自动回退到标准检索。

## 使用示例 {/* #usage-example */}

```typescript
import { createBedrockKBTool } from '@mastra/rag'

const kbTool = createBedrockKBTool({
  knowledgeBaseId: 'YOUR_KB_ID',
  region: 'us-west-2',
  numberOfResults: 5,
  useAgenticRetrieval: true,
})
```

### 与Agent {/* #with-an-agent */}

```typescript
import { Agent } from '@mastra/core/agent'
import { createBedrockKBTool } from '@mastra/rag'

const kbTool = createBedrockKBTool({
  knowledgeBaseId: 'YOUR_KB_ID',
})

const agent = new Agent({
  name: 'KnowledgeAssistant',
  instructions: 'Use the knowledge base tool to answer questions.',
  model: myModel,
  tools: { kb: kbTool },
})
```

## 检索方式 {/* #retrieval-modes */}

### Agent检索（默认） {/* #agentic-retrieval-default */}

什么时候`useAgenticRetrieval` is `true` (default), the tool uses `AgenticRetrieveStreamCommand` which:

* 将复杂查询分解为子查询
* 跨多次检索
* 应用托管重新排名以获得更好的结果

如果Agent检索失败（例如，较旧的 SDK、权限），它会自动回退到标准托管检索。

### 标准托管检索 {/* #standard-managed-retrieval */}

什么时候`useAgenticRetrieval` is `false`, the tool uses `RetrieveCommand` with `managedSearchConfiguration` for direct single-pass retrieval.

## 基于用户的访问控制 {/* #user-based-access-control */}

放`userId` in the Mastra request context to forward it as the Bedrock `userContext.userId`. This supports knowledge bases that enforce document-level access control. The request context value overrides the default `userId` configured on the tool.

```typescript
import { RequestContext } from '@mastra/core/request-context'

const requestContext = new RequestContext()
requestContext.set('userId', 'user-123')

await agent.generate('Find my private documents', { requestContext })
```
