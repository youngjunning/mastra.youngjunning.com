# Netlify部署器

这`NetlifyDeployer`该类通过调整 Mastra 的输出来处理打包、配置和部署，以创建服务器的优化版本。它扩展了基础[`Deployer`](/reference/deployer/)具有 Netlify 特定功能的类。它使您能够在 Netlify 无服务器功能或边缘功能中运行 Mastra。

## 安装 {/* #installation */}

使用`NetlifyDeployer`, you need to install the `@mastra/deployer-netlify` package:

```bash npm2yarn
npm install @mastra/deployer-netlify@latest
```

## 使用示例 {/* #usage-example */}

进口`NetlifyDeployer` and set it as the deployer in your Mastra configuration:

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
// highlight-next-line
import { NetlifyDeployer } from '@mastra/deployer-netlify'

export const mastra = new Mastra({
  // highlight-next-line
  deployer: new NetlifyDeployer(),
})
```

## 构造函数选项 {/* #constructor-options */}

* `target?: 'serverless' | 'edge'`：为 Netlify 部署目标。默认为`'serverless'`.
  * `'serverless'`： 标准[Netlify Functions](https://docs.netlify.com/functions/overview/) (Node.js runtime, 60s default timeout).
  * `'edge'`: [Netlify Edge Functions](https://docs.netlify.com/build/edge-functions/overview/) (Deno-based runtime that runs at the edge closest to users without a fixed timeout).

### 边函数示例 {/* #edge-functions-example */}

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { NetlifyDeployer } from '@mastra/deployer-netlify'

export const mastra = new Mastra({
  deployer: new NetlifyDeployer({
    target: 'edge',
  }),
})
```

## 输出 {/* #output */}

运行后`mastra build`, the deployer generates a `.netlify` folder. The build output includes all agents, tools, and workflows of your project, alongside a `config.json` file that configures the [Netlify Frameworks API](https://docs.netlify.com/build/frameworks/frameworks-api/).

### 无服务器输出（默认） {/* #serverless-output-default */}

```bash
your-project/
└── .netlify/
    └── v1/
        ├── config.json
        └── functions/
            └── api/
                ├── index.mjs
                ├── package.json
                └── node_modules/
```

这`config.json` file contains:

```json
{
  "functions": {
    "directory": ".netlify/v1/functions",
    "node_bundler": "none",
    "included_files": [".netlify/v1/functions/**"]
  },
  "redirects": [
    {
      "force": true,
      "from": "/*",
      "to": "/.netlify/functions/api/:splat",
      "status": 200
    }
  ]
}
```

### 边缘输出 {/* #edge-output */}

```bash
your-project/
└── .netlify/
    └── v1/
        ├── config.json
        └── edge-functions/
            ├── index.mjs
            ├── package.json
            └── node_modules/
```

这`config.json` file contains:

```json
{
  "edge_functions": [
    {
      "function": "index",
      "path": "/*"
    }
  ]
}
```
