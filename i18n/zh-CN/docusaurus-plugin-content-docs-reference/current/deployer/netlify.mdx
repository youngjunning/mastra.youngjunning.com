# NetlifyDeployer

`NetlifyDeployer` 通过适配 Mastra 的构建产物，完成服务端的打包、配置和部署，并生成经过优化的服务端版本。它在基础 [`Deployer`](/reference/deployer/) 类上增加了 Netlify 专属功能，让 Mastra 可以运行在 Netlify Functions 或 Edge Functions 中。

## 安装 {/* #installation */}

要使用 `NetlifyDeployer`，请安装 `@mastra/deployer-netlify` 包：

```bash npm2yarn
npm install @mastra/deployer-netlify@latest
```

## 使用示例 {/* #usage-example */}

导入 `NetlifyDeployer`，并在 Mastra 配置中将其设为 deployer：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
// highlight-next-line
import { NetlifyDeployer } from '@mastra/deployer-netlify'

export const mastra = new Mastra({
  // highlight-next-line
  deployer: new NetlifyDeployer(),
})
```

## 构造函数选项 {/* #constructor-options */}

- `target?: 'serverless' | 'edge'`：Netlify 部署目标，默认为 `'serverless'`。
  - `'serverless'`：标准 [Netlify Functions](https://docs.netlify.com/functions/overview/)；使用 Node.js 运行时，默认超时时间为 60 秒。
  - `'edge'`：[Netlify Edge Functions](https://docs.netlify.com/build/edge-functions/overview/)；使用基于 Deno 的运行时，在靠近用户的边缘节点执行，且没有固定的超时时间。

### Edge Functions 示例 {/* #edge-functions-example */}

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { NetlifyDeployer } from '@mastra/deployer-netlify'

export const mastra = new Mastra({
  deployer: new NetlifyDeployer({
    target: 'edge',
  }),
})
```

## 输出 {/* #output */}

运行 `mastra build` 后，deployer 会生成 `.netlify` 文件夹。构建产物包含项目中的所有 Agent、Tool 和 Workflow，以及用于配置 [Netlify Frameworks API](https://docs.netlify.com/build/frameworks/frameworks-api/) 的 `config.json` 文件。

### Serverless 输出（默认） {/* #serverless-output-default */}

```bash
your-project/
└── .netlify/
    └── v1/
        ├── config.json
        └── functions/
            └── api/
                ├── index.mjs
                ├── package.json
                └── node_modules/
```

`config.json` 文件内容如下：

```json
{
  "functions": {
    "directory": ".netlify/v1/functions",
    "node_bundler": "none",
    "included_files": [".netlify/v1/functions/**"]
  },
  "redirects": [
    {
      "force": true,
      "from": "/*",
      "to": "/.netlify/functions/api/:splat",
      "status": 200
    }
  ]
}
```

### Edge 输出 {/* #edge-output */}

```bash
your-project/
└── .netlify/
    └── v1/
        ├── config.json
        └── edge-functions/
            ├── index.mjs
            ├── package.json
            └── node_modules/
```

`config.json` 文件内容如下：

```json
{
  "edge_functions": [
    {
      "function": "index",
      "path": "/*"
    }
  ]
}
```
