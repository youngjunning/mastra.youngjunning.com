# 部署者

Deployer 通过打包代码和管理环境文件来处理独立 Mastra 应用程序的部署，同时通过 Hono 框架为应用程序提供服务。具体实现必须为特定的部署目标定义部署方法。

## 使用示例 {/* #usage-example */}

如果您想创建自定义部署程序，您可以扩展抽象`Deployer` class and implement the `deploy`方法与您的特定部署逻辑。这是一个例子：

```typescript
import { Deployer } from '@mastra/deployer'

class CustomDeployer extends Deployer {
  constructor() {
    super({ name: 'custom-deployer' })
  }

  async deploy(outputDirectory: string): Promise<void> {
    // Prepare the output directory
    await this.prepare(outputDirectory)

    // Bundle the application
    await this._bundle('server.ts', 'mastra.ts', {
      projectRoot: process.cwd(),
      outputDirectory,
    })

    // Custom deployment logic
  }
}
```

## 核心理念 {/* #core-concepts */}

### 部署生命周期 {/* #deployment-lifecycle */}

Deployer 抽象类实现了结构化的部署生命周期：

1. **初始化**：部署器使用名称进行初始化，并创建一个 Deps 实例用于依赖管理。
2. **环境设置**： 这`getEnvFiles` method identifies the environment files (`.env`, `.env.local`, `.env.production`) to be used during deployment.
3. **准备**： 这`prepare` method (inherited from Bundler) cleans the output directory and creates necessary subdirectories.
4. **捆绑**： 这`_bundle` method (inherited from Bundler) packages the application code and its dependencies.
5. **部署**：摘要`deploy` method is implemented by subclasses to handle the actual deployment process.

### 环境档案管理 {/* #environment-file-management */}

Deployer 类包括通过以下方式对环境文件管理的内置支持`getEnvFiles` method. This method:

* 按预定义的顺序查找环境文件，优先级从最低到最高：`.env`, `.env.local`, `.env.production`
* 按该顺序返回存在的每个文件，因此后面的文件中的值会覆盖前面的文件
* 如果未找到环境文件，则返回空数组

```typescript oxfmt:false
getEnvFiles(): Promise<string[]> {
  const possibleFiles = ['.env', '.env.local', '.env.production'];
  const fileService = new FileService();

  return Promise.resolve(fileService.getExistingFiles(possibleFiles));
}
```

### 捆绑与部署关系 {/* #bundling-and-deployment-relationship */}

Deployer 类扩展了 Bundler 类，在捆绑和部署之间建立了明确的关系：

1. **捆绑作为先决条件**：捆绑是部署的先决步骤，其中应用程序代码被打包成可部署的格式。
2. **共享基础设施**：捆绑和部署共享公共基础设施，例如依赖管理和文件系统操作。
3. **专门的部署逻辑**：虽然捆绑侧重于代码打包，但部署添加了用于部署捆绑代码的特定于环境的逻辑。
4. **可扩展性**：摘要`deploy` method allows for creating specialized deployers for different target environments.
