# 日志 API

通过日志 API 可读取和查询 Mastra 的系统日志及调试信息。

## 获取日志 {/* #getting-logs */}

获取系统日志时，可以指定筛选条件：

```typescript
const logs = await mastraClient.listLogs({
  transportId: 'transport-1',
})
```

## 获取某次运行的日志 {/* #getting-logs-for-a-specific-run */}

获取指定运行的日志：

```typescript
const runLogs = await mastraClient.getLogForRun({
  runId: 'run-1',
  transportId: 'transport-1',
})
```
