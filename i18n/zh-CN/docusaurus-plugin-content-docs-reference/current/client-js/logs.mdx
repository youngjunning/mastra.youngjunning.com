# 日志API

日志 API 提供了访问和查询 Mastra 中的系统日志和调试信息的方法。

## 获取日志 {/* #getting-logs */}

使用可选过滤检索系统日志：

```typescript
const logs = await mastraClient.listLogs({
  transportId: 'transport-1',
})
```

## 获取特定运行的日志 {/* #getting-logs-for-a-specific-run */}

检索特定执行运行的日志：

```typescript
const runLogs = await mastraClient.getLogForRun({
  runId: 'run-1',
  transportId: 'transport-1',
})
```
