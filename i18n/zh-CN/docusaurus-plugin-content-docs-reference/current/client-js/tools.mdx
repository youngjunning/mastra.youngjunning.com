# ToolAPI

Tool API 提供了与 Mastra 平台中可用的Tool交互并执行Tool的方法。

## 获取所有Tool {/* #getting-all-tools */}

检索所有可用Tool的列表：

```typescript
const tools = await mastraClient.listTools()
```

## 使用特定Tool {/* #working-with-a-specific-tool */}

获取特定Tool的实例：

```typescript
const tool = mastraClient.getTool('tool-id')
```

## Tool方法 {/* #tool-methods */}

### 获取Tool详细信息 {/* #get-tool-details */}

检索有关Tool的详细信息：

```typescript
const details = await tool.details()
```

### 执行Tool {/* #execute-tool */}

执行具有特定参数的Tool：

```typescript
const result = await tool.execute({
  args: {
    param1: 'value1',
    param2: 'value2',
  },
  threadId: 'thread-1', // Optional: Thread context
  resourceId: 'resource-1', // Optional: Resource identifier
})
```
