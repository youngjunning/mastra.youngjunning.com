# OpenAI 响应 API

这个与 OpenAI 兼容、Agent支持的界面允许您使用 Mastra Agents 作为响应 API。它提供了通过 Mastra Agent创建、检索、流式传输和删除响应的方法。

这些路由是基于 Mastra Agent、内存和存储的Agent支持的适配器。使用`agent_id` to select the Mastra agent that should handle the request. You can pass `model`覆盖单个请求的Agent配置模型，或忽略它以使用Agent上已配置的模型。

存储的响应也会返回`conversation_id`. In Mastra, this is the raw memory `threadId`.

该 API 目前处于实验阶段。

## 使用示例 {/* #usage-example */}

```typescript
import { MastraClient } from '@mastra/client-js'

const client = new MastraClient({
  baseUrl: 'http://localhost:4111',
})

const response = await client.responses.create({
  agent_id: 'support-agent',
  input: 'Summarize this ticket',
  store: true,
})

console.log(response.output_text)
```

## 方法 {/* #methods */}

### 生命周期 {/* #lifecycle */}

#### `create(params)` {/* #createparams */}

创建响应。

```typescript
const response = await client.responses.create({
  agent_id: 'support-agent',
  input: 'Summarize this ticket',
})
```

**返回：** `Promise<ResponsesResponse>` when `stream` is omitted or `false`.

什么时候`stream: true`, `create()` returns an async iterable of SSE-style event payloads:

```typescript
const stream = await client.responses.create({
  agent_id: 'support-agent',
  input: 'Summarize this ticket',
  stream: true,
})

for await (const event of stream) {
  if (event.type === 'response.output_text.delta') {
    process.stdout.write(event.delta)
  }
}
```

流式响应还可以包括Tool事件。Tool调用流的使用`response.output_item.added`, `response.function_call_arguments.delta`, `response.function_call_arguments.done`, and `response.output_item.done` events. Tool results appear as `function_call_output` items with `<toolCallId>:output` IDs.

**返回：** `Promise<ResponsesStream>`.

#### `retrieve(responseId, requestContext?)` {/* #retrieveresponseid-requestcontext */}

检索存储的响应。

```typescript
const response = await client.responses.retrieve('msg_123')
```

**返回：** `Promise<ResponsesResponse>`.

#### `delete(responseId, requestContext?)` {/* #deleteresponseid-requestcontext */}

删除存储的响应。

```typescript
const deleted = await client.responses.delete('msg_123')
```

**返回：** `Promise<{ id: string; object: "response"; deleted: true }>`

#### `stream(params)` {/* #streamparams */}

创建流式响应。

```typescript
const stream = await client.responses.stream({
  agent_id: 'support-agent',
  input: 'Say hello',
})

for await (const event of stream) {
  console.log(event.type)
}
```

**返回：** `Promise<ResponsesStream>`.

## 存储的回复和对话 {/* #stored-responses-and-conversations */}

存储的响应包括`response.id` and `conversation_id`.

* `response.id`是响应 ID。对于存储的Agent支持的响应，这是持久的助理消息 ID。
* `conversation_id`是原始 Mastra 线程 ID。

使用`previous_response_id` when you want to continue from a previous stored response. Use `conversation_id` when you want to target a known thread directly.

```typescript
const first = await client.responses.create({
  agent_id: 'support-agent',
  input: 'Start a support thread',
  store: true,
})

const second = await client.responses.create({
  agent_id: 'support-agent',
  conversation_id: first.conversation_id!,
  input: 'Add a follow-up to the same thread',
  store: true,
})
```

使用[`client.conversations`](/reference/client-js/conversations) when you want to create, retrieve, delete, or inspect the underlying OpenAI Responses API conversation directly.

## 函数调用（Tool） {/* #function-calling-tools */}

`response.tools`包含可用于请求的已配置函数定义。

如果模型调用函数，则该活动包含在`response.output` as `function_call` and `function_call_output` items alongside the final assistant `message`.

什么时候`stream: true`, function calls are also emitted as Responses stream events. Read `response.function_call_arguments.delta` events for partial argument chunks and prefer `response.function_call_arguments.done` for the finalized arguments payload and tool name. Read `response.output_item.done` events for completed `function_call` and `function_call_output` items. Tool output items use `<toolCallId>:output` IDs.

## 结构化输出 {/* #structured-output */}

使用`text.format` when you want JSON output.

* `json_object`启用 JSON 模式。
* `json_schema`启用模式约束的结构化输出。

两种格式都会在助理消息内容中返回 JSON。使用`json_schema` when you need strict schema enforcement. Use `json_object` when you only need valid JSON output.

```typescript
const response = await client.responses.create({
  agent_id: 'support-agent',
  input: 'Return a structured support ticket summary.',
  text: {
    format: {
      type: 'json_schema',
      name: 'ticket_summary',
      schema: {
        type: 'object',
        properties: {
          summary: { type: 'string' },
          priority: { type: 'string' },
        },
        required: ['summary', 'priority'],
        additionalProperties: false,
      },
    },
  },
})
```

## Provider支持的请求 {/* #provider-backed-requests */}

使用`providerOptions` when you need provider-specific options that Mastra doesn't normalize at the Responses layer.

```typescript
const response = await client.responses.create({
  agent_id: 'support-agent',
  input: 'Continue this exchange',
  providerOptions: {
    openai: {
      previousResponseId: 'resp_123',
    },
  },
})
```

## 响应形状 {/* #response-shape */}

返回的响应对象包括：

* `id`：响应ID
* `output`：输出助手等物品`message`, `function_call`, and `function_call_output`
* `output_text`：连接辅助文本输出的便捷 getter
* `tools`：为请求配置的Tool定义
* `conversation_id`：存储响应的原始线程 ID
* `text`：请求的文本输出格式（如果提供）
