# OpenAI 响应 API

这个兼容 OpenAI、由 Agent 支持的接口让你能够通过响应 API 使用 Mastra Agent。它提供了通过 Mastra Agent 创建、检索、流式传输和删除响应的方法。

这些路由是基于 Mastra Agent、记忆和存储实现的适配器。使用 `agent_id` 选择处理请求的 Mastra Agent。你可以传入 `model`，为单次请求覆盖 Agent 配置的模型；省略该参数则使用 Agent 已配置的模型。

已存储的响应还会返回 `conversation_id`。在 Mastra 中，它是记忆中的原始 `threadId`。

此 API 目前处于实验阶段。

## 使用示例 {/* #usage-example */}

```typescript
import { MastraClient } from '@mastra/client-js'

const client = new MastraClient({
  baseUrl: 'http://localhost:4111',
})

const response = await client.responses.create({
  agent_id: 'support-agent',
  input: 'Summarize this ticket',
  store: true,
})

console.log(response.output_text)
```

## 方法 {/* #methods */}

### 生命周期 {/* #lifecycle */}

#### `create(params)` {/* #createparams */}

创建一个响应。

```typescript
const response = await client.responses.create({
  agent_id: 'support-agent',
  input: 'Summarize this ticket',
})
```

**返回：** 省略 `stream` 或将其设为 `false` 时，返回 `Promise<ResponsesResponse>`。

设置 `stream: true` 时，`create()` 返回由 SSE 风格的事件数据组成的异步可迭代对象：

```typescript
const stream = await client.responses.create({
  agent_id: 'support-agent',
  input: 'Summarize this ticket',
  stream: true,
})

for await (const event of stream) {
  if (event.type === 'response.output_text.delta') {
    process.stdout.write(event.delta)
  }
}
```

流式响应还可以包含 Tool 事件。Tool 调用流使用 `response.output_item.added`、`response.function_call_arguments.delta`、`response.function_call_arguments.done` 和 `response.output_item.done` 事件。Tool 结果以 `function_call_output` 项的形式出现，其 ID 为 `<toolCallId>:output`。

**返回：** `Promise<ResponsesStream>`.

#### `retrieve(responseId, requestContext?)` {/* #retrieveresponseid-requestcontext */}

检索已存储的响应。

```typescript
const response = await client.responses.retrieve('msg_123')
```

**返回：** `Promise<ResponsesResponse>`.

#### `delete(responseId, requestContext?)` {/* #deleteresponseid-requestcontext */}

删除已存储的响应。

```typescript
const deleted = await client.responses.delete('msg_123')
```

**返回：** `Promise<{ id: string; object: "response"; deleted: true }>`

#### `stream(params)` {/* #streamparams */}

创建一个流式响应。

```typescript
const stream = await client.responses.stream({
  agent_id: 'support-agent',
  input: 'Say hello',
})

for await (const event of stream) {
  console.log(event.type)
}
```

**返回：** `Promise<ResponsesStream>`.

## 已存储的响应和对话 {/* #stored-responses-and-conversations */}

已存储的响应同时包含 `response.id` 和 `conversation_id`。

* `response.id` 是响应 ID。对于已存储且由 Agent 支持的响应，它是持久化的助手消息 ID。
* `conversation_id` 是 Mastra 的原始线程 ID。

要从之前已存储的响应继续，请使用 `previous_response_id`。要直接指定已知线程，请使用 `conversation_id`。

```typescript
const first = await client.responses.create({
  agent_id: 'support-agent',
  input: 'Start a support thread',
  store: true,
})

const second = await client.responses.create({
  agent_id: 'support-agent',
  conversation_id: first.conversation_id!,
  input: 'Add a follow-up to the same thread',
  store: true,
})
```

要直接创建、检索、删除或查看底层 OpenAI 响应 API 对话，请使用 [`client.conversations`](/reference/client-js/conversations)。

## 函数调用（Tool） {/* #function-calling-tools */}

`response.tools` 包含此请求可用的已配置函数定义。

如果模型调用函数，该调用会与最终的助手 `message` 一起，以 `function_call` 和 `function_call_output` 项的形式出现在 `response.output` 中。

设置 `stream: true` 时，函数调用也会作为响应流事件发出。通过 `response.function_call_arguments.delta` 事件读取部分参数片段；要获取最终参数和 Tool 名称，优先使用 `response.function_call_arguments.done`。通过 `response.output_item.done` 事件读取已完成的 `function_call` 和 `function_call_output` 项。Tool 输出项使用 `<toolCallId>:output` 作为 ID。

## 结构化输出 {/* #structured-output */}

需要 JSON 输出时，使用 `text.format`。

* `json_object` 启用 JSON 模式。
* `json_schema` 启用受 schema 约束的结构化输出。

两种格式都会在助手消息内容中返回 JSON。需要严格执行 schema 约束时，使用 `json_schema`；只需有效的 JSON 输出时，使用 `json_object`。

```typescript
const response = await client.responses.create({
  agent_id: 'support-agent',
  input: 'Return a structured support ticket summary.',
  text: {
    format: {
      type: 'json_schema',
      name: 'ticket_summary',
      schema: {
        type: 'object',
        properties: {
          summary: { type: 'string' },
          priority: { type: 'string' },
        },
        required: ['summary', 'priority'],
        additionalProperties: false,
      },
    },
  },
})
```

## 由 Provider 支持的请求 {/* #provider-backed-requests */}

需要传入 Mastra 未在响应层统一处理的 Provider 专属选项时，使用 `providerOptions`。

```typescript
const response = await client.responses.create({
  agent_id: 'support-agent',
  input: 'Continue this exchange',
  providerOptions: {
    openai: {
      previousResponseId: 'resp_123',
    },
  },
})
```

## 响应结构 {/* #response-shape */}

返回的响应对象包含：

* `id`：响应 ID
* `output`：输出项，例如助手 `message`、`function_call` 和 `function_call_output`
* `output_text`：将助手文本输出拼接起来的便捷取值属性
* `tools`：为此请求配置的 Tool 定义
* `conversation_id`：已存储响应的原始线程 ID
* `text`：请求指定的文本输出格式（如有）
