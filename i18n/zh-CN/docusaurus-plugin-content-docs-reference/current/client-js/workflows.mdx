# Workflow程API

Workflow程 API 提供了与 Mastra 中的自动化Workflow程交互并执行自动化Workflow程的方法。

## 获取所有Workflow程 {/* #getting-all-workflows */}

检索所有可用Workflow程的列表：

```typescript
const workflows = await mastraClient.listWorkflows()
```

## 获取Workflow运行计数 {/* #getting-workflow-run-counts */}

检索每个Workflow的计数`running` and [`suspended`](/docs/workflows/suspend-and-resume) runs in a single request. The counts are computed on the server and keyed by the workflow's registry key, the key used when registering the workflow in the Mastra config, which can differ from the workflow's own `id`:

```typescript
const runCounts = await mastraClient.listWorkflowRunCounts()
// { "cityWorkflow": { running: 2, suspended: 1 }, ... }
```

返回：`Record<string, { running: number; suspended: number }>`

服务器可能会在请求之间将计数缓存几秒钟。早于该端点的服务器响应`404 Not Found`. Handle the error when the client can talk to older deployments.

## 使用特定的Workflow程 {/* #working-with-a-specific-workflow */}

通过 ID 获取特定Workflow的实例：

```typescript title="src/mastra/workflows/test-workflow.ts"
import { createWorkflow } from '@mastra/core/workflows'

export const testWorkflow = createWorkflow({
  id: 'city-workflow',
})
```

```typescript
const workflow = mastraClient.getWorkflow('city-workflow')
```

## Workflow程方法 {/* #workflow-methods */}

### `details()` {/* #details */}

检索有关Workflow程的详细信息：

```typescript
const details = await workflow.details()
```

### `createRun()` {/* #createrun */}

创建一个新的Workflow运行实例：

```typescript
const run = await workflow.createRun()

// Or with an existing runId
const run = await workflow.createRun({ runId: 'existing-run-id' })

// Or with a resourceId to associate the run with a specific resource
const run = await workflow.createRun({
  runId: 'my-run-id',
  resourceId: 'user-123',
})
```

这`resourceId` parameter associates the workflow run with a specific resource (e.g., user ID, tenant ID). This value is persisted with the run and can be used for filtering and querying runs later.

### `startAsync()` {/* #startasync */}

启动Workflow运行并等待其完成，返回完整结果作为Workflow输出。

```typescript
const run = await workflow.createRun()

const result = await run.startAsync({
  inputData: {
    city: 'New York',
  },
})
```

您还可以通过`initialState` to set the starting values for the workflow's state:

```typescript
const result = await run.startAsync({
  inputData: {
    city: 'New York',
  },
  initialState: {
    count: 0,
    items: [],
  },
})
```

这`initialState` object should match the structure defined in the workflow's `stateSchema`. See [Workflow State](/docs/workflows/workflow-state) for more details.

要将运行与特定资源关联起来，请传递`resourceId` to `createRun()`:

```typescript
const run = await workflow.createRun({ resourceId: 'user-123' })

const result = await run.startAsync({
  inputData: {
    city: 'New York',
  },
})
```

### `start()` {/* #start */}

启动Workflow程运行，无需等待完成（即发即忘）。立即返回成功消息。使用`runById()` on the workflow instance to check results later:

```typescript
const run = await workflow.createRun()

await run.start({
  inputData: {
    city: 'New York',
  },
})

// Poll for results later
const result = await workflow.runById(run.runId)
```

这对于您想要开始执行并稍后检查结果的长时间运行的Workflow程非常有用。

### `resumeAsync()` {/* #resumeasync */}

恢复暂停的Workflow程步骤并等待完整结果：

```typescript
const run = await workflow.createRun({ runId: prevRunId })

const result = await run.resumeAsync({
  step: 'step-id',
  resumeData: { key: 'value' },
})
```

### `resume()` {/* #resume */}

恢复挂起的Workflow程步骤而不等待完成：

```typescript
const run = await workflow.createRun({ runId: prevRunId })

await run.resume({
  step: 'step-id',
  resumeData: { key: 'value' },
})
```

当一个[`.foreach()`](/reference/workflows/workflow-methods/foreach) step suspends across multiple iterations, pass `forEachIndex` (zero-based. `0` targets the first iteration) to resume one iteration at a time. Iterations you don't target remain suspended.

```typescript
await run.resume({
  step: 'approve',
  resumeData: { ok: true },
  forEachIndex: 1, // resumes the second iteration
})
```

`forEachIndex`也得到了支持`resumeAsync()` and `resumeStream()`.

### `cancel()` {/* #cancel */}

取消正在运行的Workflow程：

```typescript
const run = await workflow.createRun({ runId: existingRunId })

const result = await run.cancel()
// Returns: { message: 'Workflow run canceled' }
```

此方法停止任何正在运行的步骤并阻止执行后续步骤。检查的步骤`abortSignal` parameter can respond to cancellation by cleaning up resources (timeouts, network requests, etc.).

请参阅[Run.cancel()](/reference/workflows/run-methods/cancel) reference for detailed information about how cancellation works and how to write steps that respond to cancellation.

### `stream()` {/* #stream */}

流式Workflow程执行以实现实时更新：

```typescript
const run = await workflow.createRun()

const stream = await run.stream({
  inputData: {
    city: 'New York',
  },
})

for await (const chunk of stream) {
  console.log(JSON.stringify(chunk, null, 2))
}
```

### `runById()` {/* #runbyid */}

获取Workflow运行的执行结果：

```typescript
const result = await workflow.runById(runId)

// Or with options for performance optimization:
const result = await workflow.runById(runId, {
  fields: ['status', 'result'], // Only fetch specific fields
  withNestedWorkflows: false, // Skip expensive nested workflow data
  requestContext: { userId: 'user-123' }, // Optional request context
})
```

## 动态Workflow程 {/* #dynamic-workflows */}

:::测试版

在 API 稳定之前，可能会在没有重大版本更新的情况下发生重大更改。

:::

动态Workflow程是以 JSON 表示的Workflow程定义。服务器保留每个定义并将其注册为可运行的Workflow。看[Dynamic workflows](/docs/workflows/dynamic-workflows) for the definition format.

### `listDynamicWorkflows()` {/* #listdynamicworkflows */}

列出动态Workflow定义，可以选择按以下条件过滤`status` (`'active' | 'archived'`) and `authorId`:

```typescript
const { definitions, total } = await mastraClient.listDynamicWorkflows({
  status: 'active',
})
```

### `upsertDynamicWorkflow()` {/* #upsertdynamicworkflow */}

创建或替换动态Workflow定义。服务器验证定义，保留它，并实时注册它以供执行：

```typescript
const stored = await mastraClient.upsertDynamicWorkflow({
  id: 'greeting-workflow',
  description: 'Returns a greeting for the supplied name',
  inputSchema: {
    type: 'object',
    properties: { name: { type: 'string' } },
    required: ['name'],
  },
  outputSchema: {
    type: 'object',
    properties: { message: { type: 'string' } },
    required: ['message'],
  },
  graph: [
    {
      type: 'mapping',
      id: 'create-greeting',
      mapConfig: JSON.stringify({
        message: { template: 'Hello, ${initData.name}!' },
      }),
    },
  ],
})
```

当根定义嵌套尚不存在的帮助程序Workflow时，将它们在同一请求中传递`dependencies`. The server validates and registers the bundle as a unit and echoes the helper ids back as `dependencyIds`:

```typescript
const stored = await mastraClient.upsertDynamicWorkflow({
  id: 'root-workflow',
  // ...schemas and graph referencing 'helper-workflow'...
  dependencies: [helperDefinition],
})

console.log(stored.dependencyIds) // ['helper-workflow']
```

### `getDynamicWorkflow()` {/* #getdynamicworkflow */}

获取用于定义管理的动态Workflow实例。要执行动态Workflow程，请使用`getWorkflow(id).createRun()` like any other workflow:

```typescript
const dynamicWorkflow = mastraClient.getDynamicWorkflow('greeting-workflow')
```

### `dynamicWorkflow.details()` {/* #dynamicworkflowdetails */}

检索持久定义，包括架构、图表、状态和时间戳：

```typescript
const definition = await dynamicWorkflow.details()
```

### `dynamicWorkflow.delete()` {/* #dynamicworkflowdelete */}

删除存储的定义并取消注册实时Workflow程：

```typescript
await dynamicWorkflow.delete()
```

### 执行动态Workflow程 {/* #executing-a-dynamic-workflow */}

注册后，动态Workflow将通过普通Workflow API 运行：

```typescript
const workflow = mastraClient.getWorkflow('greeting-workflow')
const run = await workflow.createRun()
const result = await run.startAsync({ inputData: { name: 'Ada' } })
```

## 时间表 {/* #schedules */}

时间表通过代码在代码中声明`schedule` field on `createWorkflow`. The client SDK exposes read and operational methods for managing workflow schedules at runtime. See [Scheduled workflows](/docs/workflows/scheduled-workflows).

### `createSchedule()` {/* #createschedule */}

通过传递创建Workflow程计划`workflowId`.

```typescript
const schedule = await mastraClient.createSchedule({
  workflowId: 'daily-report',
  cron: '0 9 * * *',
  inputData: { reportType: 'summary' },
})
```

### `listSchedules()` {/* #listschedules */}

列出Workflow程计划，可以选择按Workflow程 ID 或状态进行筛选。

```typescript
const schedules = await mastraClient.listSchedules({
  workflowId: 'daily-report',
  status: 'active',
})
```

### `getSchedule()` {/* #getschedule */}

按 ID 获取单个Workflow程计划。

```typescript
const schedule = await mastraClient.getSchedule('daily-report')
```

### `updateSchedule()` {/* #updateschedule */}

更新Workflow程计划。

```typescript
const updated = await mastraClient.updateSchedule('daily-report', {
  cron: '0 10 * * *',
  inputData: { reportType: 'summary' },
})
```

### `deleteSchedule()` {/* #deleteschedule */}

删除Workflow程计划。

```typescript
await mastraClient.deleteSchedule('daily-report')
```

### `runSchedule()` {/* #runschedule */}

立即触发Workflow程计划一次，而不更改其 cron 节奏。

```typescript
const run = await mastraClient.runSchedule('daily-report')
```

### `pauseSchedule()` {/* #pauseschedule */}

暂停计划，以便调度程序停止触发它。返回更新后的时间表。

```typescript
await mastraClient.pauseSchedule('daily-report')
```

### `resumeSchedule()` {/* #resumeschedule */}

恢复暂停的计划。从现在开始重新计算下一次触发时间，因此长时间暂停的计划不会触发积压。返回更新后的时间表。

```typescript
await mastraClient.resumeSchedule('daily-report')
```

### `listScheduleTriggers()` {/* #listscheduletriggers */}

列出Workflow计划的触发器历史记录，包括每次触发的联接运行摘要。

```typescript
const { triggers } = await mastraClient.listScheduleTriggers('daily-report', {
  limit: 50,
})
```
