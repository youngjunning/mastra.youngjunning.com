# Agent控制器API

Agent控制器 API 达到[`AgentController`](/reference/agent-controller/agent-controller-class)通过其 HTTP 路由在 Mastra 实例上注册。从浏览器或不拥有控制器的任何其他进程使用它。拥有控制器的进程使用进程内[`Session`](/reference/agent-controller/session)反而。

## 使用示例 {/* #usage-example */}

```typescript
import { MastraClient } from '@mastra/client-js'

const client = new MastraClient({ baseUrl: 'http://localhost:4111' })
const session = client.getAgentController('coding-controller').session('user-123')

await session.create()

const subscription = await session.subscribe({
  onEvent: event => handleEvent(event),
  onError: error => showDisconnected(error),
  onReconnect: () => {
    void session.state().then(resync).catch(showDisconnected)
  },
  reconnect: true,
})

await session.sendMessage('Summarize the open pull requests')

// Call when the UI disconnects.
subscription.unsubscribe()
```

## 上市Agent控制器 {/* #listing-agent-controllers */}

检索连接的 Mastra 实例上托管的Agent控制器：

```typescript
const controllers = await client.listAgentControllers()
```

每个条目的`id` is the key the controller is registered under in `new Mastra({ agentControllers })`, not the controller's own `id`.

## 使用特定Agent控制器 {/* #working-with-a-specific-agent-controller */}

通过注册的密钥获取Agent控制器的实例`new Mastra({ agentControllers })`. The key can differ from the controller's `id`. In this example, pass `'coding'`, not `'coding-controller'`:

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { AgentController } from '@mastra/core/agent-controller'

const codingController = new AgentController({ id: 'coding-controller', agent, modes })

export const mastra = new Mastra({
  agentControllers: { coding: codingController },
})
```

```typescript
const controller = client.getAgentController('coding')
```

### `listModes()` {/* #listmodes */}

列出控制器上配置的模式，例如`build` and `plan`.

返回：`Promise<AgentControllerModeInfo[]>`

### `listModels()` {/* #listmodels */}

列出控制器上可用的型号及其身份验证状态和使用计数。

返回：`Promise<AgentControllerAvailableModel[]>`

### `listActiveRuns()` {/* #listactiveruns */}

列出控制器上所有资源的运行中的运行。

返回：`Promise<AgentControllerActiveRun[]>`

### `workspaceStatus()` {/* #workspacestatus */}

返回控制器的Workspace状态。

返回：`Promise<AgentControllerWorkspaceStatus>`

### `session(sessionId)` {/* #sessionsessionid */}

返回一个`AgentControllerSession` addressed by its session id. Every request goes to `/agent-controller/:controllerId/sessions/:sessionId/...`. Sessions are get-or-create on the server, so calling `create()` with the same `sessionId` resumes the existing conversation instead of forking it.

共享资源但使用不同会话 ID 的会话各自拥有自己的运行循环、线程绑定、模式、模型和状态。它们存储的线程和资源范围的内存属于共享资源。将资源传递给`create()`:

```typescript
const runA = client.getAgentController('code').session('run-a')
await runA.create({ resourceId: 'factory-1' })

const runB = client.getAgentController('code').session('run-b')
await runB.create({ resourceId: 'factory-1' })
```

### `sendMessage(message, options?)` {/* #sendmessagemessage-options */}

向会话发送用户消息。传递一个字符串，或者`{ content, files }` to attach base64-encoded files, where each file is `{ data, mediaType, filename? }`. The reply arrives as `message_*` events on the subscription, not as the return value of the call.

经过`options.requestContext` to merge custom context into the run's request context. Server-controlled keys win.

### `steer(message, options?)` {/* #steermessage-options */}

中止正在进行的运行，然后作为新一轮发送消息。传递一个字符串，或者`{ content, files }` to attach files in the same shape as `sendMessage()`.

### `followUp(message, options?)` {/* #followupmessage-options */}

将后续消息排队。如果会话空闲，它会立即发送。如果运行处于活动状态，它将在运行完成后排队等待。传递一个字符串，或者`{ content, files }` to attach files in the same shape as `sendMessage()`.

### `abort()` {/* #abort */}

中止飞行中的运行。

### `approveTool(toolCallId, approved, options?)` {/* #approvetooltoolcallid-approved-options */}

批准或拒绝由某个人提出的待处理Tool调用`tool_approval_required` event.

### `respondToToolSuspension(toolCallId, resumeData, options?)` {/* #respondtotoolsuspensiontoolcallid-resumedata-options */}

恢复由 a 引发的暂停的交互Tool`tool_suspended` event. The `resumeData` shape depends on the tool: a `string` or `string[]` for `ask_user`, `"Yes"` or `"No"` for `request_access`, and a `PlanResume` for `submit_plan`.

```typescript
interface PlanResume {
  action: 'approved' | 'rejected'
  feedback?: string
  path?: string
  title?: string
  plan?: string
}
```

### `state(options?)` {/* #stateoptions */}

返回会话的当前模式、模型和线程，以进行初始 UI 水合作用以及重新连接后的重新同步。经过`{ threadId }` to read the state for a specific thread.

返回：`Promise<AgentControllerSessionState>`

### `switchMode(modeId)` {/* #switchmodemodeid */}

### `switchModel(modelId, options?)` {/* #switchmodelmodelid-options */}

## 活动 {/* #events */}

`onEvent`接收会话发出的每个事件，区分为`event.type`:

|集团|活动 |
| - | - |
|运行|`agent_start`, `agent_end`, `usage_update`, `goal_evaluation`, `follow_up_queued` |
| Messages | `message_start`, `message_update`, `message_end` |
| Tools | `tool_input_start`, `tool_input_delta`, `tool_input_end`, `tool_start`, `tool_update`, `tool_end`, `shell_output`, `command_exit`, `tool_approval_required`, `tool_suspended`, `tool_suspension_cancelled`, `task_updated` |
| Session | `state_changed`, `display_state_changed`, `mode_changed`, `model_changed`, `thread_changed`, `thread_created`, `thread_deleted`, `thread_title_updated` |
| Subagents | `subagent_start`, `subagent_text_delta`, `subagent_tool_start`, `subagent_tool_end`, `subagent_end`, `subagent_model_changed`|
|内存|`om_observation_start`, `om_observation_end`, `om_observation_failed`, `om_reflection_start`, `om_reflection_end`, `om_reflection_failed`, `om_buffering_start`, `om_buffering_end`, `om_buffering_failed`, `om_model_changed`, `om_activation`, `om_status`, `om_thread_title_updated`|
|工作空间 |`workspace_ready`, `workspace_error`, `workspace_status_changed`|
|诊断 |`info`, `error` |

通知作为消息上携带的Agent信号传递，而不是作为`notification` or `notification_summary` controller events.

消息生命周期使用三种事件形状：

* `message_start`带有初始的`MastraDBMessage`, with `createdAt` hydrated to `Date`.
* `message_update`携带消息`id` and a compact text, reasoning, or part update.
* `message_end`携带`id` of the completed message.

`thread_created`还带有一个带有时间戳的线程`Date`.

控制器可以发出 SDK 未键入的事件。`AgentControllerEvent` is the union of `KnownAgentControllerEvent` and `OtherAgentControllerEvent`. Because `OtherAgentControllerEvent.type` is `string`, comparing `event.type` to a literal doesn't narrow the union. Narrow with `isKnownAgentControllerEvent(event)` first, then reconstruct messages by ID:

```typescript
import {
  isKnownAgentControllerEvent,
  type AgentControllerEvent,
  type KnownAgentControllerEvent,
  type MastraDBMessage,
} from '@mastra/client-js'

type MessageUpdate = Extract<KnownAgentControllerEvent, { type: 'message_update' }>['event']

const activeMessages = new Map<string, MastraDBMessage>()

function applyUpdate(message: MastraDBMessage, update: MessageUpdate): MastraDBMessage {
  const parts = [...message.content.parts]

  if (update.type === 'text-delta') {
    const index = parts.findLastIndex(part => part.type === 'text')
    const part = parts[index]

    if (part?.type === 'text') {
      parts[index] = { ...part, text: part.text + update.delta }
    } else {
      parts.push({ type: 'text', text: update.delta })
    }
  } else if (update.type === 'reasoning-delta') {
    const part = parts[update.index]
    const reasoning = part?.type === 'reasoning' ? part.reasoning + update.delta : update.delta
    parts[update.index] = {
      ...(part?.type === 'reasoning' ? part : { type: 'reasoning' as const }),
      reasoning,
      details: [{ type: 'text', text: reasoning }],
    }
  } else {
    parts[update.index] = update.part
  }

  return { ...message, content: { ...message.content, parts } }
}

function handleEvent(event: AgentControllerEvent) {
  if (!isKnownAgentControllerEvent(event)) return

  switch (event.type) {
    case 'message_start':
      activeMessages.set(event.message.id, structuredClone(event.message))
      break
    case 'message_update': {
      const message = activeMessages.get(event.id)
      if (!message) break

      const updated = applyUpdate(message, event.event)
      activeMessages.set(event.id, updated)
      render(updated)
      break
    }
    case 'message_end': {
      const message = activeMessages.get(event.id)
      if (!message) break

      renderComplete(message)
      activeMessages.delete(event.id)
      break
    }
    case 'tool_approval_required':
      showApproval(event.toolCallId)
      break
  }
}
```

使用`agentControllerMessageText(message)` to pull the plain text out of a reconstructed message's nested content parts.
