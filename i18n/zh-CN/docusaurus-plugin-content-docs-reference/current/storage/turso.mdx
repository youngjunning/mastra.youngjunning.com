# 图尔索存储

使用`@mastra/turso`将 Mastra Agent、Workflow程、内存和其他存储域存储在本地[图尔索数据库](https://github.com/tursodatabase/turso)文件。

## 安装 {/* #installation */}

```bash npm2yarn
npm install @mastra/turso
```

## 用法 {/* #usage */}

```typescript
import { Mastra } from '@mastra/core/mastra'
import { TursoStore } from '@mastra/turso'

export const mastra = new Mastra({
  storage: new TursoStore({
    id: 'local-storage',
    path: './mastra.db',
  }),
})
```

## 构造函数选项 {/* #constructor-options */}

* `id`（必需）：存储实例的唯一标识符。
* `path`（必需，除非`client` is provided): Path to the local database file.
* `client`：使用兼容的 SQLite 客户端，而不是创建本机 Turso 客户端。
* `readonly`：以只读模式打开数据库。
* `fileMustExist`：打开数据库文件之前要求其存在。
* `timeout`：连接超时（以毫秒为单位）。
* `defaultQueryTimeout`：默认查询超时时间（以毫秒为单位）。
* `tracing`：本机驱动程序跟踪级别：`info`, `debug`, or `trace`.
* `experimental`：启用本机 Turso 数据库实验功能。
* `maxRetries`：可重试写入的最大重试次数。
* `initialBackoffMs`：初始重试延迟（以毫秒为单位）。
* `disableInit`：禁用自动存储初始化。
* `retention`：支持的存储域的保留策略。

## 平台支持 {/* #platform-support */}

本机驱动程序支持arm64上的macOS、x64上的Windows以及x64和arm64上基于glibc的Linux。使用`getTursoDatabaseSupport()` when your application needs to choose a fallback on unsupported systems.

```typescript
import { getTursoDatabaseSupport } from '@mastra/turso'

const support = getTursoDatabaseSupport()
if (!support.supported) {
  console.warn(support.reason)
}
```

## 实验特点 {/* #experimental-features */}

默认情况下禁用实验性 Turso 数据库功能。仅启用您的应用程序所需的功能。

```typescript
const storage = new TursoStore({
  id: 'multiprocess-storage',
  path: './mastra.db',
  experimental: ['multiprocess_wal'],
})
```

`@mastra/turso`提供本地文件 Mastra 存储。它不连接到远程 libSQL 数据库，也不包含向量存储。
