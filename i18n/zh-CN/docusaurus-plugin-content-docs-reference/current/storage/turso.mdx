# Turso 存储

使用 `@mastra/turso`，将 Mastra Agent、Workflow、内存及其他存储域保存到本地 [Turso Database](https://github.com/tursodatabase/turso) 文件。

## 安装 {/* #installation */}

```bash npm2yarn
npm install @mastra/turso
```

## 用法 {/* #usage */}

```typescript
import { Mastra } from '@mastra/core/mastra'
import { TursoStore } from '@mastra/turso'

export const mastra = new Mastra({
  storage: new TursoStore({
    id: 'local-storage',
    path: './mastra.db',
  }),
})
```

## 构造函数选项 {/* #constructor-options */}

* `id`（必需）：存储实例的唯一标识符。
* `path`（必需，除非提供 `client`）：本地数据库文件的路径。
* `client`：使用兼容的 SQLite 客户端，而不是创建原生 Turso 客户端。
* `readonly`：以只读模式打开数据库。
* `fileMustExist`：要求数据库文件在打开前已经存在。
* `timeout`：连接超时（以毫秒为单位）。
* `defaultQueryTimeout`：默认查询超时时间（以毫秒为单位）。
* `tracing`：原生驱动的 tracing 级别：`info`、`debug` 或 `trace`。
* `experimental`：要启用的 Turso Database 原生实验性功能。
* `maxRetries`：可重试写入的最大重试次数。
* `initialBackoffMs`：初始重试延迟（以毫秒为单位）。
* `disableInit`：禁用自动存储初始化。
* `retention`：支持的存储域的保留策略。

## 平台支持 {/* #platform-support */}

原生驱动支持 arm64 macOS、x64 Windows，以及 x64 和 arm64 的 glibc Linux。当应用需要在不受支持的系统上选择回退方案时，请使用 `getTursoDatabaseSupport()`。

```typescript
import { getTursoDatabaseSupport } from '@mastra/turso'

const support = getTursoDatabaseSupport()
if (!support.supported) {
  console.warn(support.reason)
}
```

## 实验性功能 {/* #experimental-features */}

Turso Database 的实验性功能默认关闭。请仅启用应用所需的功能。

```typescript
const storage = new TursoStore({
  id: 'multiprocess-storage',
  path: './mastra.db',
  experimental: ['multiprocess_wal'],
})
```

`@mastra/turso` 提供基于本地文件的 Mastra 存储。它不会连接远程 libSQL 数据库，也不包含向量存储。
