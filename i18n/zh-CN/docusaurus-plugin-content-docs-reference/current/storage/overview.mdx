# 存储

Mastra 存储按数据域组织，每个数据域管理一组表或集合。具体使用全部还是部分数据域，取决于适配器及配置。

## 存储数据域 {/* #storage-domains */}

`MastraCompositeStore` 可以路由以下数据域键：

并非所有存储适配器都实现了每个数据域。如果适配器包导出了相应数据域类，可以通过复合存储为不同数据域混用适配器。

| 数据域 | 说明 |
| - | - |
| `memory` | 对话持久化：消息、线程和资源（包括工作记忆）。 |
| `workflows` | 用于暂停和恢复的 Workflow 运行快照。 |
| `workflowDefinitions` | 持久化的[动态 Workflow](/docs/workflows/dynamic-workflows) 定义（Beta）；启动时加载并实时注册。 |
| `scores` | 评估运行产生的评分记录。 |
| `observability` | 可观测性导出器和 Studio 使用的 Trace 与 Span。 |
| `datasets` | 实验使用的数据集记录、带版本的条目及数据集版本。 |
| `experiments` | 实验运行及各条目的实验结果。 |
| `agents` | Mastra Editor 使用的已保存 Agent 定义及其版本。 |
| `promptBlocks` | Mastra Editor 使用的已保存提示块及其版本。 |
| `scorerDefinitions` | Mastra Editor 使用的已保存 Scorer 定义。 |
| `mcpClients` | Mastra Editor 使用的已保存 MCP 客户端配置。 |
| `mcpServers` | Mastra Editor 使用的已保存 MCP 服务器配置。 |
| `workspaces` | Mastra Editor 使用的已保存工作区配置。 |
| `skills` | Mastra Editor 使用的已保存 Skill 及其版本。 |
| `favorites` | 用户对已保存实体的收藏。 |
| `blobs` | 以 SHA-256 哈希为键的内容寻址 Blob，保存 Skill 版本所需的文件内容。 |
| `backgroundTasks` | 后台任务状态，包括创建、状态更新和清理。 |
| `schedules` | 调度器轮询的计划，用于触发 Workflow 和 Agent 运行。 |
| `channels` | 多平台集成的渠道安装项与配置。 |
| `harness` | Harness 会话记录。 |
| `toolProviderConnections` | 用户为 Tool Provider 连接指定的名称。 |
| `notifications` | 通知记录。 |
| `threadState` | 每个线程持久化的状态，例如任务列表和目标。 |
| `knowledge` | 知识图谱节点及记录（实验性）。 |

下面的 Schema 定义涵盖已记录的内置数据库表，分别属于 `memory`、`workflows`、`scores` 和 `observability`。其他数据域以及非数据库适配器使用各自实现的存储结构。
