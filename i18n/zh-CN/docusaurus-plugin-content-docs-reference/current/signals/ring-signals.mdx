# RingSignals

`RingSignals` 将 Ring 门铃和摄像头连接到 Agent。它接收 Ring Webhook，把每个事件作为[通知信号](/reference/signals/notifications)发送到 Agent 线程，并添加 `ring_snapshot` 和 `ring_clip` Tool，让 Agent 获取事件媒体。它还提供 Ring 账户关联和 Webhook 调用所需的路由。

有关 Ring Developer Console 和 ring.com 的配置，请参阅 [Ring 集成指南](/integrations/channels/ring)。

## 使用示例 {/* #usage-example */}

```typescript title="src/mastra/agents/home-agent.ts"
import { Agent } from '@mastra/core/agent'
import { Memory } from '@mastra/memory'
import { RingSignals } from '@mastra/ring-signals'

export const homeAgent = new Agent({
  id: 'home-agent',
  name: 'Home Agent',
  instructions: 'Watch the front door and say briefly whether each event needs attention.',
  model: '__GATEWAY_OPENAI_MODEL__',
  memory: new Memory(),
  signals: [
    new RingSignals({
      events: {
        device_offline: { priority: 'low', summary: 'Device went offline.', coalesce: true },
      },
      tools: {
        clip: { visibleToModel: true },
      },
    }),
  ],
})
```

关联账户保存在频道存储域中。Mastra 实例需要配置存储适配器。

## 事件 {/* #events */}

Ring 会发送以下事件类型。未在 `DEFAULT_RING_EVENTS` 中列出的事件默认禁用，只有在 `events` 中配置后才会启用。

| 事件 | 触发条件 | 默认优先级 | 默认摘要 |
| - | - | - | - |
| `button_press` | 门铃按钮被按下 | `high` | 门铃被按下。 |
| `motion_detected` | 设备摄像头检测到移动 | `medium` | 检测到移动。 |
| `device_added` | 应用获得设备访问权限 | 已禁用 | |
| `device_removed` | 应用失去设备访问权限 | 已禁用 | |
| `device_online` | 设备上线 | 已禁用 | |
| `device_offline` | 设备离线 | 已禁用 | |
| `app_integration_added` | Ring 账户关联应用 | 已禁用 | |
| `app_integration_removed` | Ring 账户取消关联应用 | 已禁用 | |
| `subscription_activated` | Ring 付费订阅或试用开始 | 已禁用 | |
| `subscription_deactivated` | Ring 付费订阅或试用结束 | 已禁用 | |

设备事件具有 `deviceId` 和 `timestamp` 属性。订阅事件没有 `timestamp`；应用集成事件和订阅事件没有 `deviceId`。移动事件还有 `motionType`：启用 Ring Smart Alerts 时为 `human`、`vehicle`、`package_delivery` 或 `other_motion`，未启用时为 `motion`。

部分事件即使未启用也会产生副作用。`app_integration_removed` 会删除该账户已存储的令牌；`subscription_deactivated` 会记录媒体不再可用的警告。

### `RingWebhookEvent` {/* #ringwebhookevent */}

Ring 为每个事件发送的 Webhook 载荷。`target` 函数和 `attributes` 函数都在 `events` 中接收它。

```typescript
type RingWebhookEvent = {
  meta: {
    version: string
    time: string
    request_id: string
    account_id?: string
  }
  data: {
    id: string
    type: RingEventType
    attributes: {
      source: string
      source_id?: string
      source_type?: string
      timestamp?: number
      sub_type?: RingMotionType | RingSubscriptionType
      plan_id?: string | null
      expires_at?: string
      component_ids?: string[]
    }
  }
}
```

- `meta.account_id`：与事件关联的 Ring 账户。
* `data.type`：事件类型，来自上表。
- `data.attributes.source`：设备事件使用设备 ID；`app_integration_added` 和 `app_integration_removed` 使用账户 ID；订阅事件使用 `subscriptions`。
* `data.attributes.source_id`：订阅 ID，针对订阅事件。
- `data.attributes.source_type`：来源类型；设备事件为 `devices`，应用集成事件为 `users`。
- `data.attributes.timestamp`：事件发生时间，以 Unix 纪元毫秒计。订阅事件没有此字段。
- `data.attributes.sub_type`：移动事件的原因：`human`、`vehicle`、`package_delivery`、`other_motion`；若未启用 Smart Alerts，则为 `motion`。订阅事件则为 `paid` 或 `trial`。
- `data.attributes.plan_id`：订阅事件中的订阅方案 ID；试用时为 `null`。
- `data.attributes.expires_at`：计费周期或试用结束的时间，使用 ISO 8601 日期格式。`subscription_activated` 事件始终包含此字段。
* `data.attributes.component_ids`：涉及的摄像头，在拥有多个摄像头的设备上。

## 路由 {/* #routes */}

注册 Agent 时，这些路由会添加到 Mastra 服务端。它们不使用 Mastra 身份验证：Webhook 由 Ring 签名验证，账户关联由 Ring 关联 nonce 验证，媒体链接由签名和到期时间验证。令牌路由本身没有验证机制；它将每个授权码发送给 Ring，由 Ring 拒绝非其签发的代码。请在服务端 Middleware 中对 `<routePrefix>/token` 进行限流。

每个实例都需要独立的 `routePrefix`。如果两个实例使用相同前缀，Mastra 只注册第一个实例的路由并记录警告，第二个实例不会收到 Ring 事件。

| 路由 | 用途 |
| - | - |
| `GET <routePrefix>/link` | 账户关联 URL：完成关联并显示结果。 |
| `GET <routePrefix>/home` | 应用主页 URL：以纯文本返回 `Ring Signals`。 |
| `POST <routePrefix>/token` | 令牌交换 URL：将授权码换成令牌。 |
| `POST <routePrefix>/webhook` | Webhook URL：接收 Ring 事件。 |
| `GET <routePrefix>/media/:kind/:deviceId/:timestamp` | 提供带签名的快照和视频片段链接。 |

## 方法 {/* #methods */}

### `subscribeThread(target, deviceId)` {/* #subscribethreadtarget-deviceid */}

将 Ring 设备的事件发送到指定线程。未订阅的设备使用 `target` 选项。多个线程可以订阅同一设备，每个线程都会收到所有事件。订阅保存在内存中，服务端重启后会丢失。

```typescript
ringSignals.subscribeThread({ resourceId: 'user-1', threadId: 'front-door' }, deviceId)
```

返回：`SignalSubscription`

### `unsubscribeThread(target, deviceId)` {/* #unsubscribethreadtarget-deviceid */}

停止将 Ring 设备的事件发送到指定线程。

返回：`boolean`；如果线程已订阅，则为 `true`。

## 导出内容 {/* #exports */}

`@mastra/ring-signals` 还导出：

- `DEFAULT_RING_EVENTS`：默认的 `events` 配置。
- `DEFAULT_RING_INSTRUCTIONS`：两个 Tool 的默认系统指令。
- `buildRingInstructions({ snapshot, clip })`：为启用的 Tool 生成系统指令，可用于扩展默认文本。
- `RingApiClient` 和 `RingApiError`：分别是 Ring Partner API 客户端和它抛出的错误。
- 类型：`RingSignalsOptions`、`RingEventType`、`RingEventNotification`、`RingMotionType`、`RingSubscriptionType`、`RingWebhookEvent`、`RingTargetResolver`、`RingToolsOptions`、`RingSnapshotToolOptions`、`RingClipToolOptions`、`RingAttachmentOption` 和 `RingMaxAttachmentBytesOption`。
