# 振铃信号

`RingSignals`将 Ring 门铃和摄像头连接到Agent。它接收 Ring webhooks，将每个事件作为Agent线程传递到Agent线程[通知信号](/reference/signals/notifications)，并添加`ring_snapshot`和`ring_clip`Tool，以便Agent可以获取事件的媒体。它还为帐户链接和 Webhooks 的路由 Ring 呼叫提供服务。

有关 Ring 开发者控制台和ring.com 中的设置，请参阅[Ring integration guide](/integrations/channels/ring).

## 使用示例 {/* #usage-example */}

```typescript title="src/mastra/agents/home-agent.ts"
import { Agent } from '@mastra/core/agent'
import { Memory } from '@mastra/memory'
import { RingSignals } from '@mastra/ring-signals'

export const homeAgent = new Agent({
  id: 'home-agent',
  name: 'Home Agent',
  instructions: 'Watch the front door and say briefly whether each event needs attention.',
  model: '__GATEWAY_OPENAI_MODEL__',
  memory: new Memory(),
  signals: [
    new RingSignals({
      events: {
        device_offline: { priority: 'low', summary: 'Device went offline.', coalesce: true },
      },
      tools: {
        clip: { visibleToModel: true },
      },
    }),
  ],
})
```

关联帐户保存在通道存储域中。 Mastra 实例需要存储适配器。

## 活动 {/* #events */}

Ring 发送这些事件类型。无需报名的活动`DEFAULT_RING_EVENTS` are disabled until you configure them in `events`.

|活动 |发送时间 |默认优先级 |默认摘要 |
| - | - | - | - |
|`button_press` | The doorbell button is pressed | `high` | Doorbell was pressed. |
| `motion_detected` | A device camera detects motion | `medium` | Motion was detected. |
| `device_added` | A device becomes accessible to your app | Disabled | |
| `device_removed` | A device is no longer accessible to your app | Disabled | |
| `device_online` | A device comes online | Disabled | |
| `device_offline`|设备离线 |已禁用 | |
|`app_integration_added`| Ring 帐户链接您的应用程序 |已禁用 | |
|`app_integration_removed`| Ring 帐户取消与您的应用程序的链接 |已禁用 | |
|`subscription_activated`| Ring 付费订阅或试用开始 |已禁用 | |
|`subscription_deactivated`| Ring 付费订阅或试用结束 |已禁用 | |

设备事件有`deviceId` and `timestamp` attributes. Subscription events have no `timestamp`, and app integration and subscription events have no `deviceId`. Motion events also have `motionType`: `human`, `vehicle`, `package_delivery`, or `other_motion` when Ring Smart Alerts are on, and `motion` when they're off.

有些事件也有副作用，无论是否启用。`app_integration_removed` deletes the account's stored tokens, and `subscription_deactivated` logs a warning that media is no longer available.

### `RingWebhookEvent` {/* #ringwebhookevent */}

Ring 为每个事件发送的 Webhook 负载。这`target` function and the `attributes` function in `events` receive it.

```typescript
type RingWebhookEvent = {
  meta: {
    version: string
    time: string
    request_id: string
    account_id?: string
  }
  data: {
    id: string
    type: RingEventType
    attributes: {
      source: string
      source_id?: string
      source_type?: string
      timestamp?: number
      sub_type?: RingMotionType | RingSubscriptionType
      plan_id?: string | null
      expires_at?: string
      component_ids?: string[]
    }
  }
}
```

* `meta.account_id`：与事件关联的环帐户。
* `data.type`：事件类型，来自上表。
* `data.attributes.source`：设备事件的设备ID、设备事件的账户ID`app_integration_added` and `app_integration_removed`, or `subscriptions` for subscription events.
* `data.attributes.source_id`：订阅 ID，针对订阅事件。
* `data.attributes.source_type`: 来源种类:`devices` for device events, `users` for app integration events.
* `data.attributes.timestamp`：事件发生的时间，以纪元毫秒为单位。它在订阅事件中丢失。
* `data.attributes.sub_type`：导致运动事件的原因：`human`, `vehicle`, `package_delivery`, `other_motion`, or `motion` when Smart Alerts are off. `paid` or `trial` on subscription events.
* `data.attributes.plan_id`：订阅计划 ID，关于订阅事件。`null` for trials.
* `data.attributes.expires_at`：计费周期或试用结束时，采用 ISO 8601 日期。始终存在于`subscription_activated`.
* `data.attributes.component_ids`：涉及的摄像头，在拥有多个摄像头的设备上。

## 路线 {/* #routes */}

当Agent注册时，这些路由将添加到 Mastra 服务器。他们不使用 Mastra 身份验证。 Webhook 使用 Ring 的签名进行验证，帐户链接使用 Ring 的链接随机数进行验证，媒体链接使用其签名和到期时间进行验证。令牌路由没有自己的检查：它将每个代码发送到 Ring，而 Ring 拒绝它未发出的代码。速率限制`<routePrefix>/token` in your server's middleware.

每个实例都需要自己的`routePrefix`. When two instances use the same prefix, Mastra registers only the first instance's routes and logs a warning. The second instance gets no Ring events.

|路线 |目的|
| - | - |
|`GET <routePrefix>/link` | Account Link URL. Finishes linking and shows the result. |
| `GET <routePrefix>/home` | App Homepage URL. Returns `Ring Signals` as plain text. |
| `POST <routePrefix>/token` | Token Exchange URL. Exchanges an authorization code for tokens. |
| `POST <routePrefix>/webhook` | Webhook URL. Receives Ring events. |
| `GET <routePrefix>/media/:kind/:deviceId/:timestamp` | Serves signed snapshot and clip links. |

## 方法 {/* #methods */}

### `subscribeThread(target, deviceId)` {/* #subscribethreadtarget-deviceid */}

将事件从环设备发送到特定线程。没有订阅的设备使用`target` option. Several threads can subscribe to the same device, and each one receives every event. Subscriptions are kept in memory and are lost when the server restarts.

```typescript
ringSignals.subscribeThread({ resourceId: 'user-1', threadId: 'front-door' }, deviceId)
```

返回：`SignalSubscription`

返回：`boolean`, `true` if the thread was subscribed.

## 出口 {/* #exports */}

`@mastra/ring-signals`还出口：

* `DEFAULT_RING_EVENTS`：默认`events` configuration.
* `DEFAULT_RING_INSTRUCTIONS`：两个Tool的默认系统指令。
* `buildRingInstructions({ snapshot, clip })`：为启用的Tool构建系统指令。使用它来扩展默认文本。
* `RingApiClient`和`RingApiError`: A client for the Ring Partner API and the error it throws.
* 类型：`RingSignalsOptions`, `RingEventType`, `RingEventNotification`, `RingMotionType`, `RingSubscriptionType`, `RingWebhookEvent`, `RingTargetResolver`, `RingToolsOptions`, `RingSnapshotToolOptions`, `RingClipToolOptions`, `RingAttachmentOption`, and `RingMaxAttachmentBytesOption`.
