# 创建通知收件箱Tool()

**添加于：** `@mastra/core@1.39.0`

`createNotificationInboxTool()`创建一个 Mastra Tool，让Agent检查和管理当前线程的通知收件箱记录。

将此Tool与持久的通知信号结合使用。发送通知记录，请参见[`Agent.sendNotificationSignal()`](/reference/agents/agent#sendnotificationsignalnotification-options). For record fields, priorities, statuses, and delivery policy, see the [Notifications reference](/reference/signals/notifications).

## 使用示例 {/* #usage-example */}

以下示例将收件箱Tool添加到Agent。

```typescript title="src/mastra/agents/support-agent.ts"
import { Agent } from '@mastra/core/agent'
import { createNotificationInboxTool } from '@mastra/core/notifications'

const notificationsStorage = await storage.getStore('notifications')

export const supportAgent = new Agent({
  id: 'support-agent',
  name: 'Support Agent',
  instructions: 'Help the user triage updates.',
  model: '__GATEWAY_OPENAI_MODEL__',
  tools: {
    notificationInbox: createNotificationInboxTool({ storage: notificationsStorage }),
  },
})
```

## 行动 {/* #actions */}

|行动|描述 |
| - | - |
|`list` | Returns matching notifications. Without `status`, returns pending, delivered, and failed notifications and marks them seen. |
| `read` | Delivers readable notification contents as signals and marks delivered records as seen. |
| `markSeen` | Marks one notification as seen. |
| `dismiss` | Marks one notification as dismissed. |
| `archive`|将一项通知标记为已存档。 |
|`search`|通过查询和可选过滤器搜索通知。 |

一条通知是`failed` when Mastra ran out of delivery attempts for it. The default `list` includes failed notifications. Any `list` or `search` that returns a failed notification shows it with `status: 'failed'` and its `lastDeliveryError`, then marks it seen, so later lists don't repeat it. Filtering by `status: 'failed'` finds the notification only until it's first returned; after that it's `seen`， 和`deliveryAttempts`和`lastDeliveryError`保留在记录中。

什么时候`read` finds pending or delivered notifications, the tool delivers their contents as notification signals instead of returning the full contents as normal tool output. Use this after a `<notification-summary>` signal when the agent needs the full records behind the summary.
