# createNotificationInboxTool()

**引入版本：** `@mastra/core@1.39.0`

`createNotificationInboxTool()` 创建一个 Mastra Tool，供 Agent 查看和管理当前线程的通知收件箱记录。

此 Tool 适用于持久化通知信号。要发送通知记录，请参阅 [`Agent.sendNotificationSignal()`](/reference/agents/agent#sendnotificationsignalnotification-options)；有关记录字段、优先级、状态和投递策略，请参阅[通知参考文档](/reference/signals/notifications)。

## 使用示例 {/* #usage-example */}

以下示例为 Agent 添加通知收件箱 Tool。

```typescript title="src/mastra/agents/support-agent.ts"
import { Agent } from '@mastra/core/agent'
import { createNotificationInboxTool } from '@mastra/core/notifications'

const notificationsStorage = await storage.getStore('notifications')

export const supportAgent = new Agent({
  id: 'support-agent',
  name: 'Support Agent',
  instructions: 'Help the user triage updates.',
  model: '__GATEWAY_OPENAI_MODEL__',
  tools: {
    notificationInbox: createNotificationInboxTool({ storage: notificationsStorage }),
  },
})
```

## 操作 {/* #actions */}

| 操作 | 说明 |
| - | - |
| `list` | 返回匹配的通知。未指定 `status` 时，返回待处理、已投递和投递失败的通知，并将其标记为已查看。 |
| `read` | 以信号形式投递可读取的通知内容，并将已投递的记录标记为已查看。 |
| `markSeen` | 将一条通知标记为已查看。 |
| `dismiss` | 将一条通知标记为已忽略。 |
| `archive` | 将一条通知标记为已归档。 |
| `search` | 按查询词和可选筛选条件搜索通知。 |

Mastra 用尽通知的投递尝试次数后，该通知的状态为 `failed`。默认的 `list` 结果包含投递失败的通知。如果 `list` 或 `search` 返回了失败通知，结果会显示其 `status: 'failed'` 和 `lastDeliveryError`，随后将其标记为已查看，以免后续列表重复显示。按 `status: 'failed'` 筛选时，只有首次返回前能找到该通知；之后其状态变为 `seen`，但记录仍保留 `deliveryAttempts` 和 `lastDeliveryError`。

`read` 找到待处理或已投递的通知时，会以通知信号形式投递内容，而不是在常规 Tool 输出中返回完整内容。Agent 收到 `<notification-summary>` 信号后，如需查看摘要对应的完整记录，可使用此操作。
