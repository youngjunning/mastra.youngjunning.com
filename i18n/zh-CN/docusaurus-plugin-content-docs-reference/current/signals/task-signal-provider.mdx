# 任务信号提供者

**添加于：** `@mastra/core@1.42.0`

捆绑内置任务Tool（`task_write`, `task_update`, `task_complete`, `task_check`）和`TaskStateProcessor`单一Agent注册背后。使用它可以向Agent添加结构化、持久的任务列表，而无需单独连接Tool和处理器。

延伸[`SignalProvider`](/reference/signals/signal-provider). The task list is stored under the `task` state type in the thread-scoped `threadState` storage domain, which is the source of truth, and projected onto the `tasks` agent state-signal lane by the processor, so it survives observational-memory truncation without invalidating the prompt cache.

## 使用示例 {/* #usage-example */}

在Agent上注册提供者`Memory` and a Mastra `storage`:

```typescript title="src/mastra/index.ts"
import { Agent } from '@mastra/core/agent'
import { TaskSignalProvider } from '@mastra/core/signals'

const agent = new Agent({
  id: 'coder',
  name: 'coder',
  instructions: '...',
  model,
  memory,
  signals: [new TaskSignalProvider()],
})
```

Agent自动将四个任务Tool合并到其Tool集中，并将处理器注册到其输入处理器链上。无需其他接线。

任务跟踪需要内存支持的线程（`threadId` + `resourceId`). Without memory the task tools no-op and return a result explaining that task tracking requires agent memory. The `threadState` storage domain is wired in-memory by default, so task tracking works without configuring a storage backend.

## 方法 {/* #methods */}

### Agent整合 {/* #agent-integration */}

当提供程序传递给Agent时，Agent会自动调用这些方法`signals`, so you normally don't call them directly.

#### `getTools()` {/* #gettools */}

返回由Tool ID 键入的四个任务Tool（`task_write`, `task_update`, `task_complete`, `task_check`). The Agent merges these into its toolset.

```typescript
const tools = new TaskSignalProvider().getTools()
// { task_write, task_update, task_complete, task_check }
```

返回：`Record<string, Tool>`

#### `getInputProcessors()` {/* #getinputprocessors */}

返回提供者的`TaskStateProcessor` instance. The Agent registers it on the input-processor chain, which propagates the Mastra instance so the processor can resolve the `threadState` store.

```typescript
const [processor] = new TaskSignalProvider().getInputProcessors()
// processor instanceof TaskStateProcessor
```

返回：`InputProcessorOrWorkflow[]`
