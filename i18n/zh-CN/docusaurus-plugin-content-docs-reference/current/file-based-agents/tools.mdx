# Tool

基于文件的Agent发现Tool`.ts`和`.js`直接位于其下的文件`tools/`目录。每个发现的文件都是在构建时导入的，并且必须默认导出一个Tool。Agent的任何Tool`tools`选项接受作品，例如[`createTool()`](/reference/tools/create-tool)结果或 Vercel AI SDK`tool()`。不带扩展名的文件名成为模型可以调用的Tool键。

使用此页面进行基于文件的约定。有关Tool架构、执行选项、输出整形和批准选项，请参阅[`createTool()` reference](/reference/tools/create-tool).

## 快速入门 {/* #quickstart */}

将每个文件一个Tool放置在`tools/`. This file is exposed to the agent as `get_weather`.

```typescript title="src/mastra/agents/weather/tools/get_weather.ts"
import { createTool } from '@mastra/core/tools'
import { z } from 'zod'

export default createTool({
  id: 'get_weather',
  description: 'Get the current weather for a location.',
  inputSchema: z.object({
    location: z.string(),
  }),
  outputSchema: z.object({
    location: z.string(),
    temperatureCelsius: z.number(),
    conditions: z.string(),
  }),
  execute: async ({ location }) => {
    return { location, temperatureCelsius: 21, conditions: 'sunny' }
  },
})
```

## 整理Tool {/* #organizing-tools */}

每个Tool使用一个文件。以模型应采取的操作命名文件：

* 使用`get_weather.ts`, `search_docs.ts`, or `create_ticket.ts`.
* 避免模​​糊的名称，例如`helper.ts`, `api.ts`, or `utils.ts`.
* 将测试放在Tool旁边`*.test.ts` or `*.spec.ts`. Discovery ignores those files.
* 将共享帮助程序代码保留在外部`tools/` or in files that don't match the discovered extensions under `tools/`.

由于嵌套目录不会被发现为Tool，因此请使用明确的文件名前缀而不是子文件夹对相关Tool进行分组，例如`calendar_create_event.ts` and `calendar_list_events.ts`.

## Tool选项 {/* #tool-options */}

基于文件的约定仅控制Tool所在的位置及其注册方式。选项来自Tool本身。对于使用以下Tool构建的Tool`createTool()`:

* 使用`description` to tell the model when to call the tool.
* 使用`inputSchema` and `outputSchema` for structured inputs and outputs.
* 使用`toModelOutput` when the model should see a different shape than the raw value returned from `execute`.
* 使用`requireApproval` when a tool needs human confirmation before execution.

请参阅[`createTool()` reference](/reference/tools/create-tool) for all options and [tool approval](/docs/harness/agent-controller#approve-tools-and-resume-suspensions) for the approval flow. Vercel AI SDK tools use the [AI SDK `tool()` API](https://ai-sdk.dev/docs/reference/ai-sdk-core/tool) instead.

## 运行时边界 {/* #runtime-boundary */}

当Agent调用Tool时，Tool代码在您的应用程序/服务器运行时运行。如果Tool需要文件系统或 shell 隔离，请调用[workspace](/reference/file-based-agents/workspace) or sandbox APIs explicitly.

## 配置的优先级 {/* #precedence-with-config */}

发现的Tool与任何Tool合并`tools` in [`config.ts`](/reference/file-based-agents/config). On a key collision, `config.tools` wins and a warning is logged.

如果`config.tools` is a function, discovered tools are ignored with a warning because function-valued tools can't be statically merged.
