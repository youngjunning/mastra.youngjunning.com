# 技能

基于文件的Agent从其自身中发现技能`skills/`目录并在构建时捆绑它们。技能是客服人员可以在相关时加载的可重用程序或参考材料，而不是将每个细节都放入始终在线的提示中。

使用此页面进行基于文件的约定。有关代码定义的技能，请参阅[Agent skills](/docs/skills). For the `SKILL.md`封装格式见[工作空间技能](/docs/sandbox/skills).

## 快速入门 {/* #quickstart */}

最简单的技巧就是下面的一个markdown文件`skills/`. The filename becomes the skill name unless the frontmatter sets `name`, which takes precedence. The `description` tells the agent when to load it.

```markdown title="src/mastra/agents/weather/skills/temperature-units.md"
---
description: Use when reporting temperatures or comparing forecast units.
---

Always report temperatures in Celsius and Fahrenheit. Include the user's preferred unit first when known.
```

## 技能 vs Tool vs 说明 {/* #skills-vs-tools-vs-instructions */}

|需要|使用|为什么 |
| - | - | - |
|始终在线的身份、语气或规则 |[`instructions.md`](/reference/file-based-agents/instructions) | The model should see the guidance every turn. |
| Callable action with inputs and outputs | [`tools/`](/reference/file-based-agents/tools) | The model needs to execute code or call APIs, including operations that perform side effects. |
| Detailed reference or procedure loaded when relevant | `skills/` | The model only needs the full guidance for specific tasks. |

## 技能形式 {/* #skill-formats */}

Mastra 支持三种基于文件的技能格式：

|格式|当 | 时使用它
| - | - |
| TypeScript/JavaScript 模块 |您想要默认导出[`createSkill()`](/reference/agents/createSkill) result from code. |
| Packaged `SKILL.md` directory | The skill has instructions plus supporting files under `references/`. |
| Flat markdown file | The skill is one markdown file with frontmatter and instructions. |

对于打包技能来说，`description` is required in `SKILL.md` frontmatter. Flat markdown skills also require `description` in frontmatter. Write when to use the skill, not only what the skill contains.

## 加载什么 {/* #what-gets-loaded */}

基于文件的Agent技能会在构建时添加到生成的捆绑包中，因此部署的Agent不会从磁盘读取它们。

对于打包技能，Mastra 写道：

* `SKILL.md`用于元数据和说明。
* 直接下的文件`references/` as supporting reference content.

参考文件按文件名键入。下的符号链接文件和目录`references/` are skipped during discovery.

## 配置的优先级 {/* #precedence-with-config */}

发现的技能可以与任何技能融合`skills` in [`config.ts`](/reference/file-based-agents/config). On a name collision, `config.skills` wins and a warning is logged.

如果`config.skills` is a function, discovered skills are ignored with a warning because function-valued skills can't be statically merged.
