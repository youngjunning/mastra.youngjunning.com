# Skills

基于文件的 Agent 从 `skills/` 目录发现 Skill，并在构建时将其打包。Skill 是可复用的流程或参考资料，Agent 可在需要时加载，无需把所有细节都放进始终生效的提示词。

本页介绍基于文件的约定。代码定义的 Skill 请参阅 [Agent Skill](/docs/skills)；`SKILL.md` 打包格式请参阅 [Workspace Skill](/docs/sandbox/skills)。

## 快速入门 {/* #quickstart */}

最简单的 Skill 是 `skills/` 下的一个 Markdown 文件。默认以文件名作为 Skill 名称；若 frontmatter 设置了 `name`，则以它为准。`description` 告诉 Agent 何时加载此 Skill。

```markdown title="src/mastra/agents/weather/skills/temperature-units.md"
---
description: Use when reporting temperatures or comparing forecast units.
---

Always report temperatures in Celsius and Fahrenheit. Include the user's preferred unit first when known.
```

## Skill、Tool 与 instructions {/* #skills-vs-tools-vs-instructions */}

| 需求 | 使用 | 原因 |
| - | - | - |
| 始终生效的身份、语气或规则 | [`instructions.md`](/reference/file-based-agents/instructions) | 模型每一轮都应看到这些指引。 |
| 具有输入和输出的可调用操作 | [`tools/`](/reference/file-based-agents/tools) | 模型需要执行代码或调用 API，包括会产生副作用的操作。 |
| 仅在需要时加载的详细参考资料或流程 | `skills/` | 模型只在特定任务中需要完整指引。 |

## Skill 格式 {/* #skill-formats */}

Mastra 支持三种基于文件的 Skill 格式：

| 格式 | 适用场景 |
| - | - |
| TypeScript/JavaScript 模块 | 希望通过代码默认导出 [`createSkill()`](/reference/agents/createSkill) 的结果。 |
| 包含 `SKILL.md` 的目录包 | Skill 除指引外，还有 `references/` 下的辅助文件。 |
| 单个 Markdown 文件 | Skill 是一个包含 frontmatter 和指引的 Markdown 文件。 |

打包的 Skill 必须提供 `description`，并将其写在 `SKILL.md` 的 frontmatter 中；单文件 Markdown Skill 的 frontmatter 也必须提供 `description`。描述应说明何时使用该 Skill，而不只是列出其内容。

## 加载内容 {/* #what-gets-loaded */}

基于文件的 Agent 的 Skill 会在构建时加入生成的包中，因此部署后的 Agent 不会再从磁盘读取它们。

对于打包的 Skill，Mastra 会读取：

- `SKILL.md`，获取元数据和指引。
- `references/` 下的直属文件，作为辅助参考内容。

参考文件以文件名为键。发现 Skill 时会跳过 `references/` 下的符号链接文件和目录。

## 与配置的优先级 {/* #precedence-with-config */}

发现的 Skill 会与 `skills` 配置中的 Skill 合并，该配置位于 [`config.ts`](/reference/file-based-agents/config)。若名称冲突，以 `config.skills` 为准，并记录警告。

如果 `config.skills` 是函数，发现的 Skill 会被忽略并记录警告，因为无法静态合并函数形式的 Skill。
