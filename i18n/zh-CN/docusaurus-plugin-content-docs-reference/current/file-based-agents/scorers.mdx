# 得分手

基于文件的Agent发现[scorers](/docs/evals/overview)从它的`scorers/`目录。使用此页面进行基于文件的约定；使用内置记分器、自定义记分器和采样的记分器指南。

下的每个文件`scorers/` default-exports one scorer, and the filename becomes its key. The default export is either a [`MastraScorer`](/reference/evals/create-scorer) or a `{ scorer, sampling }`入口。

## 快速入门 {/* #quickstart */}

通过将文件放置在特工的下方来添加记分员`scorers/` directory. This example uses a [custom scorer](/docs/evals/custom-scorers):

```typescript title="src/mastra/agents/weather/scorers/relevance.ts"
import { createScorer } from '@mastra/core/evals'

export default createScorer({
  id: 'relevance',
  description: 'Scores how relevant the response is',
}).generateScore(() => 1)
```

记分员已登记在`weather` agent under the key `relevance`, the same as adding it to `config.scorers`.

## 采样 {/* #sampling */}

要控制得分手的跑动频率，请默认导出`{ scorer, sampling }` entry instead of a bare scorer:

```typescript title="src/mastra/agents/weather/scorers/relevance.ts"
import { createScorer } from '@mastra/core/evals'

const relevance = createScorer({
  id: 'relevance',
  description: 'Scores how relevant the response is',
}).generateScore(() => 1)

export default {
  scorer: relevance,
  sampling: { type: 'ratio', rate: 0.5 },
}
```

## 配置的优先级 {/* #precedence-with-config */}

发现的记分器将与中定义的记分器合并[`config.ts`](/reference/file-based-agents/config). On a key collision, `config.scorers` wins with a warning. If `config.scorers` is a function, discovered scorers are ignored with a warning because function-valued scorers can't be statically merged.

当按键冲突时，优先级是：

1. 功能价值`config.scorers`
2. 创纪录的价值`config.scorers`
3. 发现以下文件`scorers/`

已发现的非碰撞记分器将被保留。

访问[`createScorer()`](/reference/evals/create-scorer) for the full scorer interface.
