# 服务器

Mastra 从 `src/mastra/` 目录下的 `server.ts` 文件读取 HTTP [服务器](/docs/server/overview)配置。服务器以 REST 端点的形式提供 Agent、Workflow 和其他已注册组件。该文件默认导出的 `ServerConfig` 与传入 [`new Mastra()`](/reference/core/mastra-class) 的配置结构相同。

本页介绍如何通过文件配置服务器。服务器功能、中间件、自定义路由、自动生成的 API 文档和部署行为见[服务器概览](/docs/server/overview)。

## 快速入门 {/* #quickstart */}

创建 `src/mastra/server.ts`，并默认导出一个 `ServerConfig` 对象。

```typescript title="src/mastra/server.ts"
import type { ServerConfig } from '@mastra/core/server'

export default {
  port: 4111,
  host: '0.0.0.0',
} satisfies ServerConfig
```

## 常用配置 {/* #common-configurations */}

`server.ts` 支持与代码注册相同的服务器配置项。

| 用途 | 配置项 |
| - | - |
| 绑定到部署平台的地址 | `host` 和 `port` |
| 限制浏览器访问 | `cors` |
| 添加 Webhook 或健康检查 | `apiRoutes` |
| 启用 API 文档生成 | `build.openAPIDocs` 和 `build.swaggerUI` |

相关示例见 [Mastra 服务器](/docs/server/overview)、[中间件](/docs/server/middleware)和[自定义 API 路由](/docs/server/custom-api-routes)。

## 文件配置与代码配置的优先级 {/* #precedence-with-code */}

通过代码注册的服务器配置优先于 `server.ts`。应用基于文件的服务器配置时，启动期间添加的路由（如渠道 Webhook）会保留。
