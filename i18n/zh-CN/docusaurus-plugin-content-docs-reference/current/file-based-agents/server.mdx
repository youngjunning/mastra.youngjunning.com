# 服务器

Mastra 配置其 HTTP[server](/docs/server/overview)从一个`server.ts`直接在下面的文件`src/mastra/`。服务器将Agent、Workflow和其他注册原语公开为 REST 端点，并且文件默认导出相同的内容`ServerConfig`你会传递给的形状[`new Mastra()`](/reference/core/mastra-class).

使用此页面进行基于文件的约定。有关服务器功能、中间件、自定义路由、生成的 API 文档和部署行为，请参阅[Server overview](/docs/server/overview).

## 快速入门 {/* #quickstart */}

创造`src/mastra/server.ts` and default-export a `ServerConfig` object:

```typescript title="src/mastra/server.ts"
import type { ServerConfig } from '@mastra/core/server'

export default {
  port: 4111,
  host: '0.0.0.0',
} satisfies ServerConfig
```

## 常用配置 {/* #common-configurations */}

`server.ts`可以配置与代码注册相同的服务器选项：

|需要|使用|
| - | - |
|绑定部署平台地址 |`host` and `port` |
| Restrict browser access | `cors` |
| Add webhooks or health checks | `apiRoutes` |
| Enable generated API docs | `build.openAPIDocs` and `build.swaggerUI` |

看[Mastra server](/docs/server/overview), [middleware](/docs/server/middleware), and [custom API routes](/docs/server/custom-api-routes) for examples.

## 代码优先级 {/* #precedence-with-code */}

代码注册服务器配置获胜`server.ts`. Routes added during startup, such as channel webhooks, are preserved when file-based server config is applied.
