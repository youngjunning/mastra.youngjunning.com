# 子Agent

基于文件的Agent可以声明**subagents**，它委托给的专业儿童Agent。父模型将每个子Agent视为以子Agent目录命名的委托Tool，并调用该Tool来移交任务。子Agent的结果返回到父对话。

使用此页面进行基于文件的约定。有关更广泛的委托模式、挂钩、内存隔离、Tool批准传播和评分，请参阅[Supervisor agents](/docs/subagents).

## 快速入门 {/* #quickstart */}

为每个子Agent声明一个目录`subagents/`:

```text title="Subagent layout"
src/mastra/agents/
└── supervisor/
    ├── config.ts
    ├── instructions.md
    └── subagents/
        └── researcher/
            ├── config.ts
            ├── instructions.md
            └── tools/
                └── search.ts
```

马斯特拉组装`researcher` as its own agent and wires it into the supervisor's `agents` map. The parent model can delegate to it by using the generated `researcher` delegation tool.

子Agent的`config.ts` must set a non-empty `description`. The parent model reads this when deciding whether to delegate.

```typescript title="src/mastra/agents/supervisor/subagents/researcher/config.ts"
import { agentConfig } from '@mastra/core/agent'

export default agentConfig({
  model: '__GATEWAY_OPENAI_MODEL__',
  description: 'Researches a topic and returns cited findings.',
})
```

## 模型如何委托 {/* #how-the-model-delegates */}

子Agent的`description` is routing text for the parent model. Write it like a [tool description](/reference/file-based-agents/tools#tool-options): explain what the subagent does and when to delegate to it.

当发现的子Agent未提供非空描述时，构建会失败。例外情况是父母的`config.ts` exports a `new Agent()`: its `subagents/` directory is ignored with a warning, so no description check runs. Set `agents` on the `Agent` instead.

## 隔离 {/* #isolation */}

子Agent是隔离的。子Agent不会继承其父Agent的Tool、技能、工作空间、内存、处理器或子Agent。每个孩子都是一个独立的Agent，有自己的目录。

如果多个Agent应共享相同的依赖项，请在代码中定义它并通过每个Agent的配置分配它。

## 嵌套 {/* #nesting */}

子Agent可以声明自己的`subagents/` directories, nesting up to three levels below the top-level agent. A `subagents/` directory nested deeper is ignored with a warning.

```text title="Nested subagents"
src/mastra/agents/
└── supervisor/            # depth 0
    └── subagents/
        └── researcher/    # depth 1
            └── subagents/
                └── summarizer/ # depth 2
```

## 命名规则 {/* #naming-rules */}

* 子Agent ID 与父Agent的Tool键之一冲突是一个构建错误。
* 同一父Agent下的重复子Agent ID 是一个构建错误。
* 如果子Agent ID 也存在于父Agent ID 中`config.agents`, the `config.agents` entry wins and logs a warning.
* 如果`config.agents` is a function, discovered subagents are ignored with a warning because they can't be statically merged.

## 例子 {/* #example */}

该主管负责协调研究和写作流程。这`researcher` subagent owns search tools, while the `writer` subagent owns a workspace for drafting files.

```text title="Research supervisor"
src/mastra/agents/
└── research-supervisor/
    ├── config.ts
    ├── instructions.md
    └── subagents/
        ├── researcher/
        │   ├── config.ts
        │   ├── instructions.md
        │   └── tools/
        │       └── search_web.ts
        └── writer/
            ├── config.ts
            ├── instructions.md
            └── workspace/
                └── draft-template.md
```

```typescript title="src/mastra/agents/research-supervisor/config.ts"
import { agentConfig } from '@mastra/core/agent'

export default agentConfig({
  model: '__GATEWAY_OPENAI_MODEL__',
})
```

```markdown title="src/mastra/agents/research-supervisor/instructions.md"
You coordinate research and writing.

Delegate fact gathering to `researcher`. Delegate final drafting to `writer`.
```

```typescript title="src/mastra/agents/research-supervisor/subagents/researcher/config.ts"
import { agentConfig } from '@mastra/core/agent'

export default agentConfig({
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  description: 'Use to gather facts, sources, and concise research notes for a topic.',
})
```

```typescript title="src/mastra/agents/research-supervisor/subagents/writer/config.ts"
import { agentConfig } from '@mastra/core/agent'

export default agentConfig({
  model: '__GATEWAY_OPENAI_MODEL__',
  description: 'Use to turn research notes into a structured draft.',
})
```
