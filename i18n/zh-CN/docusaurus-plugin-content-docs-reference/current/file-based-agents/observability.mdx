# 可观察性

马斯特拉配置[observability](/docs/observability/overview)从一个`observability.ts`直接在下面的文件`src/mastra/`。该文件默认导出一个`Observability`为项目设置跟踪、日志记录、指标和反馈的实例。

使用此页面进行基于文件的约定。有关信号模型、导出器、存储和多配置设置，请参阅[observability overview](/docs/observability/overview) and [observability configuration](/docs/observability/overview#configuration).

## 快速入门 {/* #quickstart */}

创造`src/mastra/observability.ts` and default-export an `Observability` instance:

```typescript title="src/mastra/observability.ts"
import { MastraStorageExporter, Observability } from '@mastra/observability'

export default new Observability({
  configs: {
    default: {
      serviceName: 'mastra',
      exporters: [new MastraStorageExporter()],
    },
  },
})
```

## Observability和存储 {/* #observability-and-storage */}

`observability.ts`配置收集哪些信号以及将其导出到何处。[`storage.ts`](/reference/file-based-agents/storage) configures the project store that can persist observability records. For storage support by signal, see [observability signal support](/docs/observability/overview#signal-support).

## 代码优先级 {/* #precedence-with-code */}

代码注册的Observability胜出`observability.ts`. Use `observability.ts` when one project-wide configuration is enough. Use code registration when setup depends on runtime wiring in `src/mastra/index.ts`.
