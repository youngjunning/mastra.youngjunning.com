# 可观测性

Mastra 从 `src/mastra/` 目录下的 `observability.ts` 文件读取[可观测性](/docs/observability/overview)配置。文件默认导出的 `Observability` 实例为项目配置追踪、日志、指标和反馈。

本页介绍如何通过文件配置可观测性。信号模型、导出器、存储和多配置的详情见[可观测性概览](/docs/observability/overview)及[可观测性配置](/docs/observability/overview#configuration)。

## 快速入门 {/* #quickstart */}

创建 `src/mastra/observability.ts`，并默认导出一个 `Observability` 实例。

```typescript title="src/mastra/observability.ts"
import { MastraStorageExporter, Observability } from '@mastra/observability'

export default new Observability({
  configs: {
    default: {
      serviceName: 'mastra',
      exporters: [new MastraStorageExporter()],
    },
  },
})
```

## 可观测性与存储 {/* #observability-and-storage */}

`observability.ts` 指定要收集哪些信号，以及将信号导出到哪里。[`storage.ts`](/reference/file-based-agents/storage) 配置项目的存储实例，可用于持久化可观测性记录。各信号的存储支持见[可观测性信号支持](/docs/observability/overview#signal-support)。

## 文件配置与代码配置的优先级 {/* #precedence-with-code */}

通过代码注册的可观测性配置优先于 `observability.ts`。整个项目只需一套配置时，可使用 `observability.ts`。如果配置取决于运行时的组件装配，请在 `src/mastra/index.ts` 中通过代码注册。
