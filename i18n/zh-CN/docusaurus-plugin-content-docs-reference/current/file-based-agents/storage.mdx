# 贮存

Mastra 设置项目的默认值[storage](/docs/storage)从一个`storage.ts`直接在下面的文件`src/mastra/`。该文件默认导出一个存储，它取代了用于内存、Workflow、可观察性和其他存储域的内置内存存储。

使用此页面进行基于文件的约定。有关后端选择、存储域、保留和Provider详细信息，请参阅[storage overview](/docs/storage).

## 快速入门 {/* #quickstart */}

使用[`LibSQLStore`](/integrations/databases/libsql) for a local file-backed store:

```typescript title="src/mastra/storage.ts"
import { LibSQLStore } from '@mastra/libsql'

export default new LibSQLStore({
  id: 'mastra-storage',
  url: 'file:./mastra.db',
})
```

Mastra 在基于文件的Agent和Workflow之前注册存储，因此依赖于存储的基元绑定到此存储而不是默认的内存中存储。

## 生产后端 {/* #production-backends */}

`storage.ts`可以导出任何 Mastra 存储适配器，例如 LibSQL、PostgreSQL 或 MongoDB。有关设置模式、提供程序支持和架构详细信息，请参阅[storage overview](/docs/storage), [observability signal support](/docs/observability/overview#signal-support), and the [storage reference](/reference/storage/overview).

## 代码优先级 {/* #precedence-with-code */}

代码注册存储胜出`storage.ts`. Use `storage.ts` when one project-wide store is enough. Use code registration when setup depends on runtime wiring in `src/mastra/index.ts`.
