# 记忆

基于文件的Agent得到[memory](/docs/memory/overview)从一个`memory.ts`默认导出的文件[`Memory`](/reference/memory/memory-class)实例。使用此页面进行基于文件的约定；使用内存文档进行消息历史记录、语义回忆、存储和处理器。

没有`memory.ts` or `config.memory`, the agent has no memory by default. Each `generate()` or `stream()`呼叫开始时不会记住对话状态，除非您自己传递先前的上下文。

## 快速入门 {/* #quickstart */}

创造`memory.ts` next to the agent's `config.ts`:

```typescript title="src/mastra/agents/weather/memory.ts"
import { Memory } from '@mastra/memory'

export default new Memory()
```

导出的实例成为Agent的实例`memory`. If your app configures a storage provider on the main Mastra instance, memory data is stored there. See [storage](/docs/storage) for more information.

使用相同的`resource` and `thread` values when calling the agent to continue a conversation:

```typescript title="src/app/weather-chat.ts"
const response = await weatherAgent.generate('Remember that I prefer Celsius.', {
  memory: {
    resource: 'user-123',
    thread: 'weather-chat',
  },
})
```

## 配置内存 {/* #configure-memory */}

将选项传递给`new Memory()` when the default behavior isn't enough.

```typescript title="src/mastra/agents/weather/memory.ts"
import { Memory } from '@mastra/memory'

export default new Memory({
  options: {
    lastMessages: 20,
    workingMemory: {
      enabled: true,
      scope: 'resource',
    },
  },
})
```

参观[`Memory` reference](/reference/memory/memory-class) for constructor options. Use these pages for related memory features:

* [贮存](/docs/storage)：配置内存数据的持久化。
* [语义回忆](/docs/memory/semantic-recall)：通过语义检索相关的过去消息。
* [内存处理器](/docs/memory/memory-processors)：在内存将消息添加到模型上下文之前过滤、修剪或转换消息。

## 配置的优先级 {/* #precedence-with-config */}

`config.memory`战胜`memory.ts`. If neither is present, the assembled file-based agent has no memory. See [`config.ts` precedence](/reference/file-based-agents/config#precedence) for the full merge table.
