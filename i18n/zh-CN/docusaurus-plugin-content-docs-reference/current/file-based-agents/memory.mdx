# 记忆

基于文件的 Agent 从 `memory.ts` 文件获取[内存](/docs/memory/overview)，该文件默认导出一个 [`Memory`](/reference/memory/memory-class) 实例。本页介绍基于文件的约定；消息历史记录、语义回忆、存储和处理器则参阅内存文档。

如果没有 `memory.ts` 或 `config.memory`，Agent 默认不具备内存。每次调用 `generate()` 或 `stream()` 时都不会保留之前的对话状态，除非你自行传入先前上下文。

## 快速入门 {/* #quickstart */}

创建 `memory.ts`，并将其放在 Agent 的 `config.ts` 旁：

```typescript title="src/mastra/agents/weather/memory.ts"
import { Memory } from '@mastra/memory'

export default new Memory()
```

导出的实例会成为 Agent 的 `memory`。如果应用在主 Mastra 实例中配置了存储 Provider，内存数据将保存在该存储中。详情请参阅[存储](/docs/storage)。

调用 Agent 时使用相同的 `resource` 和 `thread` 值，即可延续对话：

```typescript title="src/app/weather-chat.ts"
const response = await weatherAgent.generate('Remember that I prefer Celsius.', {
  memory: {
    resource: 'user-123',
    thread: 'weather-chat',
  },
})
```

## 配置内存 {/* #configure-memory */}

默认行为无法满足需求时，可向 `new Memory()` 传入选项。

```typescript title="src/mastra/agents/weather/memory.ts"
import { Memory } from '@mastra/memory'

export default new Memory({
  options: {
    lastMessages: 20,
    workingMemory: {
      enabled: true,
      scope: 'resource',
    },
  },
})
```

构造函数选项请参阅 [`Memory` 参考文档](/reference/memory/memory-class)。相关内存功能请参阅以下页面：

* [存储](/docs/storage)：配置内存数据的持久化。
* [语义回忆](/docs/memory/semantic-recall)：通过语义检索相关的过去消息。
* [内存处理器](/docs/memory/memory-processors)：在内存将消息添加到模型上下文之前过滤、修剪或转换消息。

## 配置的优先级 {/* #precedence-with-config */}

`config.memory` 的优先级高于 `memory.ts`。如果两者都不存在，组装后的基于文件的 Agent 将不具备内存。完整的合并规则请参阅 [`config.ts` 优先级](/reference/file-based-agents/config#precedence)。
