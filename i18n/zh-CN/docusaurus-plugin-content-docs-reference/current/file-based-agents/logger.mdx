# 记录器

Mastra 设定了该项目的[logger](/docs/observability/logging)从一个`logger.ts`直接在下面的文件`src/mastra/`。该文件默认导出一个记录器，它取代了内置的`ConsoleLogger`跨Agent、Workflow和其他组件使用。

使用此页面进行基于文件的约定。有关日志级别、传输和提供程序详细信息，请参阅[logging](/docs/observability/logging).

## 快速入门 {/* #quickstart */}

创造`src/mastra/logger.ts` and default-export a logger, such as [`PinoLogger`](/reference/logging/pino-logger):

```typescript title="src/mastra/logger.ts"
import { PinoLogger } from '@mastra/loggers'

export default new PinoLogger({
  name: 'Mastra',
  level: 'info',
})
```

Mastra 在存储、可观察性和基于文件的Agent之前注册记录器。这些原语在连接时通过此记录器进行记录。

## 代码优先级 {/* #precedence-with-code */}

代码注册日志胜出`logger.ts`. If you pass `logger` to `new Mastra({ logger })` in `src/mastra/index.ts` (or set `logger: false` to disable logging), `logger.ts` is ignored with a warning. Use `logger.ts` when one project-wide logger is enough. Use code registration when setup depends on runtime wiring.
