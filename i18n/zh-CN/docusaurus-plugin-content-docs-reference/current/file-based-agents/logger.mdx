# 日志记录器

Mastra 从 `src/mastra/` 目录下的 `logger.ts` 文件读取项目的[日志记录器](/docs/observability/logging)。该文件默认导出的记录器会取代 Agent、Workflow 和其他组件使用的内置 `ConsoleLogger`。

本页介绍如何通过文件配置记录器。日志级别、传输方式和 Provider 的详情见[日志记录](/docs/observability/logging)。

## 快速入门 {/* #quickstart */}

创建 `src/mastra/logger.ts`，并默认导出一个日志记录器，例如 [`PinoLogger`](/reference/logging/pino-logger)。

```typescript title="src/mastra/logger.ts"
import { PinoLogger } from '@mastra/loggers'

export default new PinoLogger({
  name: 'Mastra',
  level: 'info',
})
```

Mastra 会先注册日志记录器，再设置存储、可观测性和基于文件的 Agent。这些组件在初始化时会通过该记录器写入日志。

## 文件配置与代码配置的优先级 {/* #precedence-with-code */}

代码中的日志设置优先于 `logger.ts`。如果在 `src/mastra/index.ts` 中调用 `new Mastra({ logger })` 时传入 `logger`，或用 `logger: false` 禁用日志，Mastra 会忽略 `logger.ts` 并发出警告。整个项目只需一个记录器时，用 `logger.ts` 即可。如果日志设置依赖运行时的组件装配，请在代码中注册。
