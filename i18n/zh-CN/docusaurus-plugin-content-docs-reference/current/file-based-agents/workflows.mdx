# Workflow程

Mastra 发现项目级Workflow程`.ts`和`.js`文件下`src/mastra/workflows/`。此约定的范围不限于一个Agent：每个具有默认导出的文件都将成为已注册的Workflow程，并且文件名将成为Workflow程密钥。

使用此页面进行基于文件的约定。有关步骤、模式、控制流、流、状态和Workflow执行，请参阅[Workflows overview](/docs/workflows/overview).

## 快速入门 {/* #quickstart */}

下创建一个文件`src/mastra/workflows/`, build the workflow with [`createWorkflow()`](/reference/workflows/workflow), and default-export it.

```typescript title="src/mastra/workflows/daily-report.ts"
import { createStep, createWorkflow } from '@mastra/core/workflows'
import { z } from 'zod'

const collectInputs = createStep({
  id: 'collect-inputs',
  inputSchema: z.object({ topic: z.string() }),
  outputSchema: z.object({ topic: z.string(), audience: z.string() }),
  execute: async ({ inputData }) => ({
    topic: inputData.topic,
    audience: 'engineering',
  }),
})

const writeSummary = createStep({
  id: 'write-summary',
  inputSchema: z.object({ topic: z.string(), audience: z.string() }),
  outputSchema: z.object({ report: z.string() }),
  execute: async ({ inputData }) => ({
    report: `Daily report about ${inputData.topic} for ${inputData.audience}.`,
  }),
})

const dailyReport = createWorkflow({
  id: 'daily-report',
  inputSchema: z.object({ topic: z.string() }),
  outputSchema: z.object({ report: z.string() }),
})
  .then(collectInputs)
  .then(writeSummary)
  .commit()

export default dailyReport
```

Mastra 将此Workflow程注册在`daily-report` key.

## 代码优先级 {/* #precedence-with-code */}

基于文件的Workflow程与注册的Workflow程合并[`new Mastra()`](/reference/core/mastra-class). On a key collision, the code-registered workflow wins.
