# Workflow

Mastra 会从 `src/mastra/workflows/` 下的 `.ts` 和 `.js` 文件中发现项目级 Workflow。此约定不限于单个 Agent：每个具有默认导出的文件都会注册为 Workflow，文件名即为 Workflow 的键。

本页说明基于文件的约定。有关步骤、schema、控制流、流式输出、状态和 Workflow 执行，请参阅 [Workflow 概览](/docs/workflows/overview)。

## 快速入门 {/* #quickstart */}

在 `src/mastra/workflows/` 下创建文件，使用 [`createWorkflow()`](/reference/workflows/workflow) 构建 Workflow，并将其默认导出。

```typescript title="src/mastra/workflows/daily-report.ts"
import { createStep, createWorkflow } from '@mastra/core/workflows'
import { z } from 'zod'

const collectInputs = createStep({
  id: 'collect-inputs',
  inputSchema: z.object({ topic: z.string() }),
  outputSchema: z.object({ topic: z.string(), audience: z.string() }),
  execute: async ({ inputData }) => ({
    topic: inputData.topic,
    audience: 'engineering',
  }),
})

const writeSummary = createStep({
  id: 'write-summary',
  inputSchema: z.object({ topic: z.string(), audience: z.string() }),
  outputSchema: z.object({ report: z.string() }),
  execute: async ({ inputData }) => ({
    report: `Daily report about ${inputData.topic} for ${inputData.audience}.`,
  }),
})

const dailyReport = createWorkflow({
  id: 'daily-report',
  inputSchema: z.object({ topic: z.string() }),
  outputSchema: z.object({ report: z.string() }),
})
  .then(collectInputs)
  .then(writeSummary)
  .commit()

export default dailyReport
```

Mastra 会以 `daily-report` 为键注册此 Workflow。

## 代码优先级 {/* #precedence-with-code */}

基于文件的 Workflow 会与通过 [`new Mastra()`](/reference/core/mastra-class) 注册的 Workflow 合并。键冲突时，以代码注册的 Workflow 为准。
