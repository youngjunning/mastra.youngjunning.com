# 皮诺记录器

使用以下命令创建 Logger 实例`new PinoLogger()`并提供按严重级别记录事件的方法。

## 使用示例 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { PinoLogger } from '@mastra/loggers'

export const mastra = new Mastra({
  logger: new PinoLogger({
    name: 'Mastra',
    level: 'info',
  }),
})
```

## 日志丰富化`mixin` {/* #log-enrichment-with-mixin */}

使用`mixin` when you want the same structured fields on every line (for correlation with the rest of your services):

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { PinoLogger } from '@mastra/loggers'

function getTraceContext() {
  return { traceId: 'abc-123' }
}

export const mastra = new Mastra({
  logger: new PinoLogger({
    name: 'Mastra',
    level: 'info',
    mixin() {
      return getTraceContext()
    },
  }),
})
```

## 自定义级别 {/* #custom-levels */}

`customLevels`被传递给皮诺。`PinoLogger` only exposes `debug`, `info`, `warn`， 和`error`;对于任何额外的级别名称（例如`audit`)，子类化并转发到底层 Pino 实例：

```typescript title="src/mastra/logger.ts"
import { Mastra } from '@mastra/core'
import { PinoLogger } from '@mastra/loggers'

type AuditLevel = 'audit'

class MastraPinoWithAudit extends PinoLogger<AuditLevel> {
  audit(message: string, meta: Record<string, unknown> = {}) {
    this.logger.audit(meta, message)
  }
}

const logger = new MastraPinoWithAudit({
  name: 'Mastra',
  level: 'info',
  customLevels: { audit: 35 },
})

export const mastra = new Mastra({ logger })
```

数值遵循 Pino 的排序（内置级别使用 10 到 60）。一个级别`35` sits between `info` (30) and `warn` (40), so with `level: 'info'` both `info` and `audit` lines are emitted.

## 文件传输（结构化日志） {/* #file-transport-structured-logs */}

使用以下命令将结构化日志写入文件`FileTransport`. The logger accepts a plain message as the first argument and structured metadata as the second argument. These are internally converted to a `BaseLogMessage` and persisted to the configured file path.

```typescript title="src/mastra/loggers/file-transport.ts"
import { FileTransport } from '@mastra/loggers/file'
import { PinoLogger } from '@mastra/loggers'

export const fileLogger = new PinoLogger({
  name: 'Mastra',
  transports: { file: new FileTransport({ path: 'test-dir/test.log' }) },
  level: 'warn',
})
```

### 文件传输使用 {/* #file-transport-usage */}

```typescript
fileLogger.warn('Low disk space', {
  destinationPath: 'system',
  type: 'WORKFLOW',
})
```

## Upstash 传输（远程日志排出） {/* #upstash-transport-remote-log-drain */}

使用以下命令将结构化日志流式传输到远程 Redis 列表`UpstashTransport`. The logger accepts a string message and a structured metadata object. It supports centralized logging for distributed environments, supporting filtering by `destinationPath`, `type`, and `runId`.

```typescript title="src/mastra/loggers/upstash-transport.ts"
import { UpstashTransport } from '@mastra/loggers/upstash'
import { PinoLogger } from '@mastra/loggers'

export const upstashLogger = new PinoLogger({
  name: 'Mastra',
  transports: {
    upstash: new UpstashTransport({
      listName: 'production-logs',
      upstashUrl: process.env.UPSTASH_URL!,
      upstashToken: process.env.UPSTASH_TOKEN!,
    }),
  },
  level: 'info',
})
```

### Upstash 传输使用情况 {/* #upstash-transport-usage */}

```typescript
upstashLogger.info('User signed in', {
  destinationPath: 'auth',
  type: 'AGENT',
  runId: 'run_123',
})
```

## 定制运输 {/* #custom-transport */}

您可以使用以下命令创建自定义传输`createCustomTransport` utility to integrate with any logging service or stream.

### 哨兵运输示例 {/* #sentry-transport-example */}

使用创建自定义传输`createCustomTransport` and integrates it with a third-party logging stream such as `pino-sentry-transport`. The custom transport forwards logs to an external system such as Sentry for advanced monitoring and observability.

```typescript title="src/mastra/loggers/sentry-transport.ts"
import { createCustomTransport } from '@mastra/core/logger'
import { PinoLogger } from '@mastra/loggers'
import pinoSentry from 'pino-sentry-transport'

const sentryStream = await pinoSentry({
  sentry: {
    dsn: 'YOUR_SENTRY_DSN',
    _experiments: {
      enableLogs: true,
    },
  },
})

const customTransport = createCustomTransport(sentryStream)

export const sentryLogger = new PinoLogger({
  name: 'Mastra',
  level: 'info',
  transports: { sentry: customTransport },
})
```
