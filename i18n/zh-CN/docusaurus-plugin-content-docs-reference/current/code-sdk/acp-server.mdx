# ACP服务器

Mastra Code 通过Agent客户端协议 (ACP) 提供编码Agent对话服务。 ACP 客户端将服务器作为子进程启动，并通过标准输入和输出交换换行符分隔的 JSON-RPC 消息。标准错误带有诊断信息。

该服务器将编辑器或其他 ACP 客户端连接到 Mastra Code。要将 Mastra Agent连接到外部 ACP 服务器，请使用[ACP connection](/docs/connections/acp).

## 启动服务器 {/* #start-the-server */}

随着`mastracode` CLI installed, configure your client to launch:

```bash
mastracode --acp
```

接受命令和参数字段的客户端可以使用：

```json
{
  "command": "mastracode",
  "args": ["--acp"]
}
```

初始化后，客户端调用`session/new` with an absolute `cwd` and an `mcpServers` array. The response includes the session ID and configuration choices. Send that ID with subsequent prompts and configuration requests.

## 验证 {/* #authentication */}

`session/new`返回一个`auth_required` error when no model provider is configured, so clients can offer the methods from the `initialize` response:

|方法 ID |类型 |行为 |
| - | - | - |
|`openai-codex` | Agent | Opens the browser to sign in with a ChatGPT Plus or Pro subscription. |
| `kimi-for-coding` | Agent | Opens the browser to approve a Kimi For Coding device sign-in. |
| `xai` | Agent | Opens the browser to approve an xAI device sign-in. |
| `anthropic` | Terminal | Runs `mastracode login --provider anthropic`使用 Claude Pro 或 Max 订阅登录。 |
|`github-copilot`|终端|跑步`mastracode login --provider github-copilot`使用 GitHub Copilot 登录。 |
|`mastracode-login`|终端|跑步`mastracode login`选择任何Provider或保存 API 密钥。 |

终端方法仅提供给通告终端身份验证的客户端。

对于Agent方法，`authenticate` runs the sign-in inside the server process and returns after the credentials are saved. If a provider needs typed input, such as a code to paste, the request fails and asks you to run `mastracode login` in a terminal.

服务器进程环境中的 API 密钥也算作已配置的提供程序。 ACP 会话不加载项目`.env` files into the shared process environment. New sessions pick up saved credentials without restarting the server. When the default model's provider isn't configured, a new session starts on the default model of a provider that is, such as `anthropic/claude-fable-5` after an Anthropic sign-in.

## 会话和 MCP 服务器 {/* #sessions-and-mcp-servers */}

每个会话都有自己的运行时和工作目录。服务器使用 stdio 或 HTTP 连接客户端提供的模型上下文协议 (MCP) 服务器。旧版 SSE 服务器不受支持并返回无效参数错误。 Stdio 进程接收会话的工作目录和提供的环境变量。 HTTP 连接接收提供的标头。重复的服务器名称和失败的客户端-服务器初始化返回错误。

提示和配置更改在会话中按顺序运行。不同的会话可以同时运行。`session/cancel` stops the requested session's active turn and cancels its queued prompts.

## 模型和推理控制 {/* #model-and-reasoning-controls */}

这`session/new` response exposes `configOptions` for models, modes, and reasoning effort. Use values from the returned choices with `session/set_config_option`:

```typescript
await connection.setSessionConfigOption({
  sessionId,
  configId: 'thought_level',
  value: 'high',
})
```

模型选择保留其完整的Provider路由 ID，并忽略没有配置凭据的Provider。即使发现未返回会话的已保存模型，该模型仍然可用。模式和模型更改等待当前回合完成。

推理选择遵循所选模型的策略。Provider可以调整所请求的级别。每个会话在启动时都会读取一次默认设置。模式更改和显式推理选择仍然有效。启动一个新会话以获取对设置文件的编辑。

遗产`session/set_mode` and `session/set_model` requests are also supported.

## 技能指令 {/* #skill-commands */}

之后`session/new` response, the server advertises workspace skills through `available_commands_update`. Clients can offer `/skill/<name>` completions before the first prompt. The server refreshes the list before subsequent prompts and sends an update when it changes.

以文本提示形式发送命令，后跟可选说明：

```typescript
await connection.prompt({
  sessionId,
  prompt: [{ type: 'text', text: '/skill/review Check the current changes' }],
})
```

服务器将技能的说明和资源列表添加到回合中。它使用 Mastra Code 的项目和全局技能目录。重复名称选择Workspace目录顺序中的第一个用户可调用文件。技能标记`user-invocable: false` are hidden and rejected when explicitly invoked. Missing skills return an invalid-parameters error without starting inference.

终端命令如`/goal` aren't exposed as ACP commands.

## 权限和错误 {/* #permissions-and-errors */}

默认情况下，Tool批准和Sandbox访问请求通过客户端的权限 UI。被拒绝的Tool不会执行。取消挂起的权限请求会记录中止之前的拒绝，因此稍后的回合不会重播该请求。不支持自由文本Tool问题。这`ask_user` tool is disabled.

辅助块包含辅助输出。用户提示和内部系统信号不会作为助理回复发出。提供程序失败返回 JSON-RPC 错误。代币限制回报`max_tokens`, content-filter refusals return `refusal`, and cancellation returns `cancelled`.

## 支持的协议配置文件 {/* #supported-protocol-profile */}

服务器支持 ACP v1 初始化、新会话、文本提示、文本资源、助手和Tool更新、权限、取消、配置和命令发现。它不会通告会话加载。图像、音频和二进制资源提示返回无效参数错误。

存储库的 ACP 一致性门根据固定的上游模式验证消息，并使用本地模型和 MCP 装置来测试构建的 SDK。这些检查涵盖了已实施的配置文件。它们不是上游认证、每个可选 ACP 功能的保证，也不是在客户端中测试实时Provider身份验证的替代品。
