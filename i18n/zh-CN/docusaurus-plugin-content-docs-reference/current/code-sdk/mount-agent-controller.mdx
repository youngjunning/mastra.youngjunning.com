# mountAgentControllerOnMastra()

`mountAgentControllerOnMastra()` 会构建 Mastra Code 的 Agent 控制器（即 [Mastra Code](https://code.mastra.ai) 背后的编码 Agent，包含模式、工具、记忆和线程管理），并将其注册到由服务器管理的 [Mastra](/reference/core/mastra-class) 实例。你可以用它向自己的 UI（Web 应用、编辑器或机器人）提供 Mastra Code Agent；每个客户端通过返回的 [`AgentController`](/reference/agent-controller/agent-controller-class) 创建或恢复独立会话。

如果要自行构建 `Mastra` 实例（例如在可部署的入口文件中），请使用同一包中的 `prepareAgentControllerMount()`；它会返回构造参数和一个 `finalize()` 回调。

## 使用示例 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { mountAgentControllerOnMastra } from '@mastra/code-sdk'

const { mastra, controller } = await mountAgentControllerOnMastra({
  cwd: process.cwd(),
})

// Each client drives its own session
const session = await controller.createSession({ resourceId: 'user-123' })
```

## 提交署名 {/* #commit-attribution */}

使用 `coAuthor` 设置编码 Agent 提交指引中的 `Co-Authored-By` 尾注：

```typescript title="src/mastra/index.ts"
const { mastra, controller } = await mountAgentControllerOnMastra({
  cwd: process.cwd(),
  coAuthor: {
    name: 'my-coding-app',
    email: 'my-coding-app@example.com',
  },
})
```

两个字段都是可选的。省略字段时使用 SDK 默认值：名称为 `mastra-platform[bot]`，邮箱为 `284800079+mastra-platform[bot]@users.noreply.github.com`。

`mastracode` 终端应用将名称设为 `mastracode`，Factory 则设为 `mastra-platform[bot]`。两者使用相同的默认邮箱，因此 GitHub 会将它们的尾注解析为同一个机器人账号，而原始提交消息仍保留应用名称。

传入现有 `mastra`，可将控制器挂载到已承载其他组件的 Mastra 实例：

```typescript
import { Mastra } from '@mastra/core/mastra'
import { mountAgentControllerOnMastra } from '@mastra/code-sdk'

const mastra = new Mastra({/* ... */})

const { controller } = await mountAgentControllerOnMastra({ mastra })
```

## 插件中的嵌套控制器 {/* #nested-controllers-in-plugins */}

如果插件在同一进程中启动另一个控制器，必须借用宿主的存储，不能用自己的原生 SQLite 库再次打开相同的数据库文件。

### `context.getStorage()` {/* #contextgetstorage */}

`MastraCodePluginContext` 上这个可选的访问器会返回宿主的 `storage`（`MastraCompositeStore`）、`storageBackend`（`'libsql' | 'pg'`）和可选的 `vector`（`MastraVector`）。在工具运行时调用它，再将返回的对象传给 `bootLocalAgentController()`：

```typescript
import { bootLocalAgentController } from '@mastra/code-sdk'
import type { MastraCodePluginContext } from '@mastra/code-sdk/plugin'

async function bootNestedController(context: MastraCodePluginContext) {
  const sharedStorage = context.getStorage?.()
  if (!sharedStorage) {
    throw new Error('This plugin requires host-provided shared storage.')
  }
  return bootLocalAgentController({ cwd: context.cwd, ...sharedStorage })
}
```

这些实例由宿主拥有。用完后请停止嵌套控制器的 worker 并销毁其控制器，但不要关闭借用的存储，也不要调用它的存储维护方法。如果旧版宿主没有提供访问器，不要退回到再次打开相同数据库文件的做法。
