# create-mastra

创建独立的 Mastra 项目。默认情况下，`create-mastra` 会安装默认起始项目，并根据所选模型 Provider 完成配置。

```bash npm2yarn
npx create-mastra@latest
```

## 创建方式 {/* #creation-modes */}

### 默认起始项目 {/* #default-starter */}

默认起始项目会创建一个 Agent 运行框架，包含 Workspace 工具、记忆、任务跟踪、网页访问、定期调度、存储和可观测性。你可以选择 Mastra Gateway、OpenAI、Anthropic、Gemini 或 xAI 作为模型 Provider。

同时提供项目名称和 Provider，即可跳过交互提示创建项目。此示例使用 Anthropic；你也可以传入 `openai`、`google`、`xai` 或 `mastra`。如果使用 `mastra`，还需传入 `--llm-api-key` 才能跳过浏览器登录；参见 [Mastra Gateway](#mastra-gateway)：

```bash npm2yarn
npx create-mastra@latest my-mastra-project --llm anthropic
```

省略 `--llm` 可交互选择 Provider，并可选择输入其 API 密钥。交互设置还会询问是否将项目连接到 Mastra 平台。启用后，命令会在浏览器中打开身份验证流程，创建与本地项目同名的平台项目，再将 `MASTRA_PLATFORM_ACCESS_TOKEN` 和 `MASTRA_PROJECT_ID` 写入 `.env`。

### Mastra Gateway {/* #mastra-gateway */}

选择 **Mastra Gateway**，即可使用同一密钥调用所有模型。命令会打开浏览器供你登录 Mastra，创建 Gateway API 密钥，并将其写入 `.env`，变量名为 `MASTRA_GATEWAY_API_KEY`。Agent 使用的模型名称以 `mastra/` 为前缀，例如 `mastra/openai/gpt-6.1-sol`。

模型调用按 token 从 Gateway 额度中扣费。如果余额为 $0，命令会提示打开 Mastra 控制台的 Add credits 页面，你可以选择充值金额，并可开启自动充值。你操作时，设置流程会继续；最终摘要还会再次提供该页面的链接。

要在不登录的情况下使用现有 Gateway 密钥，请通过 `--llm-api-key` 传入：

```bash npm2yarn
npx create-mastra@latest my-mastra-project --llm mastra --llm-api-key <your-gateway-key>
```

### 模板 {/* #template */}

使用模板 slug 或公开的 GitHub URL：

```bash npm2yarn
npx create-mastra@latest my-mastra-project --template agent-harness
```

```bash npm2yarn
npx create-mastra@latest my-mastra-project --template https://github.com/mastra-ai/template-agent-harness
```

不填写模板值，即可交互选择模板：

```bash npm2yarn
npx create-mastra@latest my-mastra-project --template
```

模板作者自行管理其依赖、模型、环境变量和源代码。`create-mastra` 不会应用 `--llm` 或 `--llm-api-key`。

### 空项目骨架 {/* #empty-scaffold */}

使用 `--empty` 创建不含 Provider、Agent、示例、模型 SDK 或环境文件的项目：

```bash npm2yarn
npx create-mastra@latest my-empty-project --empty
```

## 自动设置 {/* #automatic-setup */}

安装依赖后，命令会：

1. 检测 `PATH` 中受支持的编程助手，并安装 Mastra Skills。如果未检测到，则安装通用 Skills。
1. 如果当前目录和生成的项目均不在 Git 仓库内，则创建初始 Git 提交。

使用 `--no-skills` 或 `--no-git` 可跳过对应步骤。Skills 或 Git 设置失败只会产生警告，不会删除已成功创建的项目。

## 冲突和验证 {/* #conflicts-and-validation */}

- `--empty` 和 `--template` 不能同时使用。
- `--llm` 和 `--llm-api-key` 仅适用于默认起始项目。
- 项目名称必须是安全的小写单层目录名，且目标目录不能已存在。

创建任何项目文件之前，命令会拒绝无效的选项、项目名称和 GitHub URL。未知的模板名称会在获取模板列表后被拒绝，CLI 随后会列出可用模板。

## 遥测 {/* #telemetry */}

Mastra 会收集匿名的 CLI 使用信息，例如操作系统、Mastra 版本和 Node.js 版本。你可以查看[分析功能的源代码](https://github.com/mastra-ai/mastra/blob/main/packages/cli/src/analytics/index.ts)。

设置 `MASTRA_TELEMETRY_DISABLED=1` 可退出遥测数据收集：

```bash
MASTRA_TELEMETRY_DISABLED=1 npx create-mastra@latest my-project --empty
```
