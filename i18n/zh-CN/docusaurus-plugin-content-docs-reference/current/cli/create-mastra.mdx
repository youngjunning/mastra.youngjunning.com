# 创建玛斯特拉

创建一个独立的 Mastra 项目。默认情况下，`create-mastra`安装默认启动器并为您选择的模型提供程序配置它。

```bash npm2yarn
npx create-mastra@latest
```

## 创作模式 {/* #creation-modes */}

### 默认启动器 {/* #default-starter */}

默认启动器创建一个具有WorkspaceTool、内存、任务跟踪、Web 访问、循环计划、存储和可观察性的AgentTool。选择 Mastra Gateway、OpenAI、Anthropic、Gemini 或 xAI 作为您的模型Provider。

提供项目名称和提供程序以在没有提示的情况下创建项目。这个例子使用了 Anthropic；你也可以通过`openai`, `google`, `xai`, or `mastra`。和`mastra`，也通过`--llm-api-key`要跳过浏览器登录，请参阅[马斯特拉网关](#mastra-gateway):

```bash npm2yarn
npx create-mastra@latest my-mastra-project --llm anthropic
```

忽略`--llm` to select the provider and optionally enter its API key interactively. The interactive setup also offers to connect your project to the Mastra platform. If enabled, the command opens the browser authentication flow and creates a platform project with the same name as the local project. It then writes `MASTRA_PLATFORM_ACCESS_TOKEN` and `MASTRA_PROJECT_ID` to `.env`.

### 马斯特拉网关 {/* #mastra-gateway */}

选择**Mastra Gateway** to call every model with one key. The command opens the browser to sign in to Mastra, creates a Gateway API key, and writes it to `.env` as `MASTRA_GATEWAY_API_KEY`. The agent's models use the `mastra/` prefix, for example `mastra/openai/gpt-6.1-sol`.

模型调用按您的网关积分中的代币支付。如果您的余额为 0 美元，该命令会打开 Mastra 仪表板的“添加积分”页面，您可以在其中选择金额并可以打开自动充值。当您执行此操作时，安装程​​序将继续，并且最终摘要会再次链接该页面。

要使用现有网关密钥而不登录，请将其传递给`--llm-api-key`:

```bash npm2yarn
npx create-mastra@latest my-mastra-project --llm mastra --llm-api-key <your-gateway-key>
```

### 模板 {/* #template */}

使用模板 slug 或公共 GitHub URL：

```bash npm2yarn
npx create-mastra@latest my-mastra-project --template agent-harness
```

```bash npm2yarn
npx create-mastra@latest my-mastra-project --template https://github.com/mastra-ai/template-agent-harness
```

将模板值留空以交互方式选择模板：

```bash npm2yarn
npx create-mastra@latest my-mastra-project --template
```

模板作者拥有自己的依赖项、模型、环境变量和源代码。`create-mastra` doesn't apply `--llm` or `--llm-api-key`.

### 空脚手架 {/* #empty-scaffold */}

使用`--empty` to create a provider-free project without agents, examples, model SDKs, or environment files:

```bash npm2yarn
npx create-mastra@latest my-empty-project --empty
```

## 自动设置 {/* #automatic-setup */}

安装依赖项后，命令：

1. 检测支持的编码助手`PATH` and installs Mastra skills. If none are detected, it installs universal skills.
2. 当当前目录和生成的项目尚未位于 Git 存储库中时创建初始 Git 提交。

使用`--no-skills` or `--no-git` to skip these steps. Skills and Git setup failures produce warnings but don't remove a successfully created project.

## 冲突和验证 {/* #conflicts-and-validation */}

* `--empty`和`--template` can't be used together.
* `--llm`和`--llm-api-key` are only valid for the default starter project.
* 项目名称必须是安全的、小写的、单目录名称，并且目标不能已存在。

在创建任何项目文件之前，无效的标志、项目名称和 GitHub URL 将被拒绝。获取模板列表后，未知的模板名称将被拒绝，并且 CLI 会打印可用的模板。

## 遥测 {/* #telemetry */}

Mastra 收集匿名 CLI 使用信息，例如操作系统、Mastra 版本和 Node.js 版本。您可以查看[analytics source](https://github.com/mastra-ai/mastra/blob/main/packages/cli/src/analytics/index.ts).

放`MASTRA_TELEMETRY_DISABLED=1` to opt out:

```bash
MASTRA_TELEMETRY_DISABLED=1 npx create-mastra@latest my-project --empty
```
