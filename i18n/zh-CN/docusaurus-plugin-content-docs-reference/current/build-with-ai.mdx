# 用人工智能构建

有关使用 Mastra 技能和 CLI 进行日常 AI 辅助开发的信息，请参阅[Develop](/docs/develop#build-with-ai)。本页介绍了让编码Agent访问 Mastra 文档的其他方法。

## 嵌入式包文档 {/* #embedded-package-docs */}

Mastra 软件包附带嵌入式文档`dist/docs`. When you install a Mastra package, your AI agent can read these files directly from `node_modules` to understand the package's APIs and patterns.

每个`dist/docs` includes:

* `SKILL.md`：符合技能标准的技能文件
* `references/`：包含与包相关的文档文件的文件夹
* `assets/SOURCE_MAP.json`：将公共导出链接到其位置的源映射文件`node_modules`

## 上下文文件 {/* #context-files */}

Mastra 提供根[`llms.txt`](https://mastra.ai/llms.txt) file that contains an overview of all available documentation pages.

要在一个请求中加载多个页面，请使用`llms-full.txt` bundles. They contain the full Markdown of every page in sidebar order:

* [`/llms-full.txt`](https://mastra.ai/llms-full.txt)：所有文档
* [`/docs/llms-full.txt`](https://mastra.ai/docs/llms-full.txt)：文档
* [`/models/llms-full.txt`](https://mastra.ai/models/llms-full.txt)： 型号
* [`/integrations/llms-full.txt`](https://mastra.ai/integrations/llms-full.txt)：集成
* [`/reference/llms-full.txt`](https://mastra.ai/reference/llms-full.txt)： 参考

完整的捆绑包很大，因此当您只需要部分文档时，最好选择部分捆绑包或单独的页面。

每个文档页面也有自己的`llms.txt` file. These files are streamlined markdown files. At the end of each docs page you'll find a link to the corresponding `llms.txt` file.

添加`/llms.txt` to any Mastra docs URL to access it. You can also request it by adding a `.md` extension to the end of the URL.

示例为[introduction page](/docs):

* [`/docs/llms.txt`](https://mastra.ai/docs/llms.txt)
* [`/docs.md`](https://mastra.ai/docs.md)

## MCP 文档服务器 {/* #mcp-docs-server */}

：：：警告

不建议将 MCP 文档服务器用于日常开发。使用[Mastra skill](/docs/develop#mastra-skills) instead because it's more up to date and performs better.

:::

这`@mastra/mcp-docs-server` package provides direct local access to Mastra’s full documentation via the [Model Context Protocol (MCP)](https://modelcontextprotocol.io/docs/getting-started/intro). It works with Cursor, Windsurf, Cline, Claude Code, VS Code, Codex or any tool that supports MCP.

这些Tool旨在帮助Agent检索精确的、特定于任务的信息，无论您是向Agent添加功能还是构建新项目，还是探索某些内容的工作原理。

如果您无法使用本地 MCP 服务器并需要连接到远程服务器，请使用以下 URL：`https://mastra.mcp.kapa.ai`. You need to authenticate with your Google Account (only an anonymous ID is transmitted) for rate-limiting purposes. If possible, Mastra recommends using a local MCP server for better performance and reliability.

### 安装 {/* #installation */}

这[`create-mastra`](/reference/cli/create-mastra) command doesn't configure the MCP docs server. Add the server manually when you need MCP-specific tools such as the migration tool.

如果下面没有针对您的Tool的具体说明，您也许可以使用此通用 JSON 配置添加 MCP 服务器。

```json title="mcp.json"
{
  "mcpServers": {
    "mastra": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "@mastra/mcp-docs-server@latest"]
    }
  }
}
```

#### 克劳德·代码 CLI {/* #claude-code-cli */}

使用终端命令安装：

```bash
claude mcp add --scope project mastra -- npx -y @mastra/mcp-docs-server@latest
```

这将创建一个项目范围的`.mcp.json` file if one doesn't already exist. You can use the same command when using Claude Code as a [Visual Studio Code extension](https://code.claude.com/docs/en/vs-code#connect-to-external-tools-with-mcp).

[有关将 MCP 服务器与 Claude Code 结合使用的更多信息](https://docs.claude.com/en/docs/claude-code/mcp)

#### OpenAI Codex CLI {/* #openai-codex-cli */}

1. 从终端注册：

   ```bash
   codex mcp add mastra-docs -- npx -y @mastra/mcp-docs-server@latest
   ```

2. 跑步`codex mcp list` to confirm the server shows as `enabled`.

[有关将 MCP 服务器与 OpenAI Codex 结合使用的更多信息](https://developers.openai.com/codex/mcp)

#### 光标 {/* #cursor */}

通过选择下面的按钮进行安装：

[![Install MCP Server](https://cursor.com/deeplink/mcp-install-light.svg)](cursor://anysphere.cursor-deeplink/mcp/install?name=mastra\&config=eyJjb21tYW5kIjoibnB4IC15IEBtYXN0cmEvbWNwLWRvY3Mtc2VydmVyIn0%3D)

[有关将 MCP 服务器与 Cursor 结合使用的更多信息](https://cursor.com/de/docs/context/mcp)

#### 反重力 {/* #antigravity */}

Google Antigravity 是一个Agent优先的开发平台，支持 MCP 服务器访问外部文档、API 和项目上下文。

1. 打开您的反重力 MCP 配置文件：

   * 点击**Agent session** and select the **“…” dropdown** at the top of the editor’s side panel, then select **MCP Servers** to access the **MCP Store**.
   * 您可以通过 Antigravity 中的 MCP Store 界面访问它。

2. 要添加自定义 MCP 服务器，请选择**Manage MCP Servers** at the top of the MCP Store and select **View raw config** in the main tab.

3. 添加 Mastra MCP 服务器配置：

   ```json
   {
     "mcpServers": {
       "mastra-docs": {
         "command": "npx",
         "args": ["-y", "@mastra/mcp-docs-server"]
       }
     }
   }
   ```

4. 保存配置并重新启动Antigravity

配置完成后，Mastra MCP 服务器会向反重力Agent公开以下内容：

* Mastra 的索引文档和 API 模式，支持在代码生成期间以编程方式检索相关上下文
* 访问 Mastra Docs 中存储的示例代码片段和使用模式
* 用于编辑器中错误处理和调试参考的结构化数据
* 有关当前 Mastra 项目模式的元数据，用于代码建议和完成

MCP 服务器将出现在 Antigravity 的 MCP 商店中，您可以在其中管理其连接状态和身份验证（如果需要）。

[有关使用具有反重力功能的 MCP 服务器的更多信息](https://antigravity.google)

#### 视觉工作室代码 {/* #visual-studio-code */}

1. 创建一个`.vscode/mcp.json` file in your workspace
2. 插入以下配置：

   ```json title=".vscode/mcp.json"
   {
     "servers": {
       "mastra": {
         "type": "stdio",
         "command": "npx",
         "args": ["-y", "@mastra/mcp-docs-server@latest"]
       }
     }
   }
   ```

保存配置后，启用服务器：

1. 打开命令面板。
2. 跑步**MCP: List Servers**.
3. 选择**mastra**, then select **Enable**.

MCP Tool可在 Visual Studio Code 的Agent模式下使用。选择 Copilot 窗格中的Tool按钮以查看可用的Tool。

[有关将 MCP 服务器与 Visual Studio Code 结合使用的详细信息](https://code.visualstudio.com/docs/copilot/customization/mcp-servers)

#### 开放代码 {/* #opencode */}

您可以在您的[OpenCode configuration](https://opencode.ai/docs/config/) under `mcp`. Create an `opencode.jsonc` file in your project root with the following content:

```json title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "mastra": {
      "type": "local",
      "command": ["npx", "-y", "@mastra/mcp-docs-server@latest"],
      "enabled": true
    }
  }
}
```

[有关将 MCP 服务器与 OpenCode 结合使用的更多信息](https://opencode.ai/docs/mcp-servers)

### 用法 {/* #usage */}

配置完成后，您可以向 AI Tool询问有关 Mastra 的问题或指示其采取行动。对于这些步骤，它将从 Mastra 的 MCP 服务器获取最新信息。

**添加功能：**

* “向我的Agent添加评估并编写测试”
* “给我写一个执行以下操作的Workflow程`[task]`"
* “制作一个新Tool，让我的Agent能够访问`[3rd party API]`"

**询问集成：**

* “Mastra 可以与 AI SDK 配合使用吗？
  我怎样才能在我的`[React/Svelte/etc]` project?"
* “马斯特拉是否支持`[provider]` speech and voice APIs? Show me an example in my code of how I can use it."

**调试或更新现有代码：**

* “我遇到了Agent内存错误，最近是否有任何相关更改或错误修复？”
* “工作记忆在 Mastra 中的表现如何以及我如何使用它来做`[task]`? It doesn't seem to work the way I expect."
* “我看到有新的Workflow程功能，请向我解释一下，然后更新`[workflow]` to use them."

### 故障排除 {/* #troubleshooting */}

1. **服务器未启动**
   * 确保[npx](https://docs.npmjs.com/cli/v11/commands/npx) is installed and working.
   * 检查是否存在冲突的 MCP 服务器。
   * 验证您的配置文件语法。

2. **Tool调用失败**
   * 重新启动 MCP 服务器和/或您的 IDE。
   * 更新到最新版本的 IDE。
