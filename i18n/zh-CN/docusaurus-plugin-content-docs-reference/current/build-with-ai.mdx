# 借助 AI 构建

日常使用 Mastra Skill 和 CLI 辅助开发时，请参阅[开发](/docs/develop#build-with-ai)。本页介绍让编码 Agent 访问 Mastra 文档的其他方式。

## 包内文档 {/* #embedded-package-docs */}

Mastra 包的 `dist/docs` 中包含内嵌文档。安装 Mastra 包后，AI Agent 可直接从 `node_modules` 读取这些文件，了解该包的 API 和用法。

每个 `dist/docs` 都包含：

- `SKILL.md`：遵循 skills 标准的 Skill 文件
- `references/`：与该包相关的文档目录
- `assets/SOURCE_MAP.json`：将公开导出项映射到其在 `node_modules` 中位置的源映射文件

## 上下文文件 {/* #context-files */}

Mastra 提供根目录的 [`llms.txt`](https://mastra.ai/llms.txt)，其中概览了所有可用文档页面。

要一次加载多个页面，请使用 `llms-full.txt` 汇总文件。它们按侧边栏顺序包含各页面的完整 Markdown：

- [`/llms-full.txt`](https://mastra.ai/llms-full.txt)：全部文档
- [`/docs/llms-full.txt`](https://mastra.ai/docs/llms-full.txt)：文档
- [`/models/llms-full.txt`](https://mastra.ai/models/llms-full.txt)：模型
- [`/integrations/llms-full.txt`](https://mastra.ai/integrations/llms-full.txt)：集成
- [`/reference/llms-full.txt`](https://mastra.ai/reference/llms-full.txt)：API 参考

完整汇总文件体积较大；如果只需要部分文档，优先使用对应栏目汇总文件或单个页面。

每个文档页面还有独立的 `llms.txt` 文件。这些文件是精简的 Markdown；页面末尾提供了对应 `llms.txt` 文件的链接。

在任意 Mastra 文档 URL 后添加 `/llms.txt` 即可访问；也可以在 URL 末尾添加 `.md`。

[简介页面](/docs)的示例：

* [`/docs/llms.txt`](https://mastra.ai/docs/llms.txt)
* [`/docs.md`](https://mastra.ai/docs.md)

## MCP 文档服务器 {/* #mcp-docs-server */}

:::warning

MCP 文档服务器不推荐用于日常开发。请改用 [Mastra Skill](/docs/develop#mastra-skills)，它更新更及时，性能也更好。

:::

`@mastra/mcp-docs-server` 包通过 [Model Context Protocol (MCP)](https://modelcontextprotocol.io/docs/getting-started/intro) 提供对 Mastra 完整文档的本地直接访问。它适用于 Cursor、Windsurf、Cline、Claude Code、VS Code、Codex，以及任何支持 MCP 的工具。

这些工具可帮助 Agent 获取与具体任务相关的准确信息，无论是为 Agent 添加功能、搭建新项目，还是了解某项功能的工作方式。

如果无法使用本地 MCP 服务器而需要连接远程服务器，请使用 `https://mastra.mcp.kapa.ai`。为控制请求速率，你需要使用 Google 账号认证（只会传输匿名 ID）。如果条件允许，Mastra 建议使用本地 MCP 服务器，以获得更好的性能和可靠性。

### 安装 {/* #installation */}

[`create-mastra`](/reference/cli/create-mastra) 命令不会配置 MCP 文档服务器。如果需要迁移工具等 MCP 专用工具，请手动添加该服务器。

如果下面没有针对你所用工具的具体说明，可以尝试使用以下通用 JSON 配置添加 MCP 服务器。

```json title="mcp.json"
{
  "mcpServers": {
    "mastra": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "@mastra/mcp-docs-server@latest"]
    }
  }
}
```

#### 克劳德·代码 CLI {/* #claude-code-cli */}

在终端运行以下命令安装：

```bash
claude mcp add --scope project mastra -- npx -y @mastra/mcp-docs-server@latest
```

如果项目中尚无 `.mcp.json`，此命令会创建一个项目级文件。将 Claude Code 作为 [Visual Studio Code 扩展](https://code.claude.com/docs/en/vs-code#connect-to-external-tools-with-mcp)使用时，也可以运行同一命令。

[了解如何在 Claude Code 中使用 MCP 服务器](https://docs.claude.com/en/docs/claude-code/mcp)

#### OpenAI Codex CLI {/* #openai-codex-cli */}

1. 在终端注册服务器：

   ```bash
   codex mcp add mastra-docs -- npx -y @mastra/mcp-docs-server@latest
   ```

1. 运行 `codex mcp list`，确认服务器显示为 `enabled`。

[了解如何在 OpenAI Codex 中使用 MCP 服务器](https://developers.openai.com/codex/mcp)

#### 光标 {/* #cursor */}

点击下方按钮安装：

[![Install MCP Server](https://cursor.com/deeplink/mcp-install-light.svg)](cursor://anysphere.cursor-deeplink/mcp/install?name=mastra\&config=eyJjb21tYW5kIjoibnB4IC15IEBtYXN0cmEvbWNwLWRvY3Mtc2VydmVyIn0%3D)

Cursor 也可能显示 **New MCP server detected: mastra** 弹窗。可选择 **Enable** 快速启用，或选择 **Skip**，稍后再从 **Customize** > **MCPs** 启用。

[了解如何在 Cursor 中使用 MCP 服务器](https://cursor.com/de/docs/context/mcp)

#### 反重力 {/* #antigravity */}

Google Antigravity 是一款以 Agent 为核心的开发平台，支持通过 MCP 服务器访问外部文档、API 和项目上下文。

1. 打开 Antigravity 的 MCP 配置文件：

      - 点击 **Agent session**，在编辑器侧边栏顶部选择 **“…” dropdown**，再选择 **MCP Servers** 进入 **MCP Store**。
      - 也可以通过 Antigravity 中的 MCP Store 界面访问。

1. 要添加自定义 MCP 服务器，请在 MCP Store 顶部选择 **Manage MCP Servers**，然后在主标签页中选择 **View raw config**。

1. 添加 Mastra MCP 服务器配置：

   ```json
   {
     "mcpServers": {
       "mastra-docs": {
         "command": "npx",
         "args": ["-y", "@mastra/mcp-docs-server"]
       }
     }
   }
   ```

1. 保存配置并重启 Antigravity。

配置完成后，Mastra MCP 服务器会向 Antigravity Agent 提供：

- Mastra 的索引文档和 API Schema，供生成代码时按需获取上下文
- Mastra 文档中的示例代码和使用模式
- 编辑器中用于错误处理和调试参考的结构化数据
- 关于当前 Mastra 项目模式的元数据，用于代码建议与补全

该 MCP 服务器会显示在 Antigravity 的 MCP Store 中；你可以按需管理连接状态和认证。

[了解如何在 Antigravity 中使用 MCP 服务器](https://antigravity.google)

#### 视觉工作室代码 {/* #visual-studio-code */}

1. 在工作区中创建 `.vscode/mcp.json` 文件。
1. 插入以下配置：

   ```json title=".vscode/mcp.json"
   {
     "servers": {
       "mastra": {
         "type": "stdio",
         "command": "npx",
         "args": ["-y", "@mastra/mcp-docs-server@latest"]
       }
     }
   }
   ```

保存配置后，启用服务器：

1. 打开命令面板。
1. 运行 **MCP: List Servers**。
1. 选择 **mastra**，再选择 **Enable**。

在 Visual Studio Code 的 Agent 模式中可以使用 MCP 工具。点击 Copilot 面板中的工具按钮，查看可用工具。

[了解如何在 Visual Studio Code 中使用 MCP 服务器](https://code.visualstudio.com/docs/copilot/customization/mcp-servers)

[了解如何在 Windsurf 中使用 MCP 服务器](https://docs.windsurf.com/windsurf/cascade/mcp#mcp-config-json)

#### 开放代码 {/* #opencode */}

你可以在[OpenCode 配置](https://opencode.ai/docs/config/)的 `mcp` 字段下定义 MCP 服务器。在项目根目录创建 `opencode.jsonc`，内容如下：

```json title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "mastra": {
      "type": "local",
      "command": ["npx", "-y", "@mastra/mcp-docs-server@latest"],
      "enabled": true
    }
  }
}
```

[了解如何在 OpenCode 中使用 MCP 服务器](https://opencode.ai/docs/mcp-servers)

### 用法 {/* #usage */}

配置完成后，你可以向 AI 工具询问 Mastra 相关问题，或要求它执行操作。在这些步骤中，它会从 Mastra MCP 服务器获取最新信息。

**添加功能：**

- “为我的 Agent 添加 Evals 并编写测试”
- “编写一个执行 `[task]` 的 Workflow”
- “创建一个工具，让我的 Agent 可以访问 `[3rd party API]`”

**询问集成方式：**

- “Mastra 能与 AI SDK 一起使用吗？
    如何在我的 `[React/Svelte/etc]` 项目中使用？”
- “Mastra 支持 `[provider]` 的语音 API 吗？请给出在我的代码中使用它的示例。”

**调试或更新现有代码：**

- “我的 Agent 记忆功能遇到错误，最近是否有相关改动或修复？”
- “Mastra 的工作记忆如何运作？怎样用它完成 `[task]`？它的表现似乎与我预期不同。”
- “我看到 Workflow 新增了功能。请解释这些功能，然后更新 `[workflow]` 以使用它们。”

### 故障排查 {/* #troubleshooting */}

1. **服务器无法启动**
      - 确保 [npx](https://docs.npmjs.com/cli/v11/commands/npx) 已安装且正常运行。
      - 检查是否有冲突的 MCP 服务器。
      - 验证配置文件的语法。

1. **工具调用失败**
      - 重启 MCP 服务器和/或 IDE。
      - 将 IDE 更新到最新版本。
