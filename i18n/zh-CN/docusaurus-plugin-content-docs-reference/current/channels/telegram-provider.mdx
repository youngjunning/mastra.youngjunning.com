# 电报Provider

`TelegramProvider`通过 Bot API 将 Mastra Agent连接到 Telegram 机器人。注册于`Mastra.channels`管理机器人安装、选择 Webhook 或轮询交付、验证 Webhook 机密、注册命令以及将 Telegram 对话路由至Agent。

使用`TelegramProvider` when you want Mastra to own the bot lifecycle. For the lower-level path where you configure the Telegram adapter and webhook yourself, use [`createTelegramAdapter`](/integrations/channels/telegram) on the agent's `channels.adapters`.

## 使用示例 {/* #usage-example */}

创建一个机器人[BotFather](https://t.me/botfather), set `TELEGRAM_BOT_TOKEN`, and register the provider with a public base URL for webhook delivery:

```typescript title="src/mastra/index.ts"
import { Agent } from '@mastra/core/agent'
import { Mastra } from '@mastra/core/mastra'
import { TelegramProvider } from '@mastra/telegram'

const supportAgent = new Agent({
  id: 'support',
  name: 'Support agent',
  instructions: 'Help users with product questions.',
  model: 'openai/gpt-5-mini',
})

const telegram = new TelegramProvider({
  baseUrl: 'https://your-app.example.com',
})

export const mastra = new Mastra({
  agents: { supportAgent },
  channels: { telegram },
})

await telegram.connect('support', {
  botToken: process.env.TELEGRAM_BOT_TOKEN,
})
```

什么时候`botToken` is omitted, `connect()` creates a pending installation and returns a BotFather deep link instead of activating the bot immediately.

## 方法 {/* #methods */}

### 安装生命周期 {/* #installation-lifecycle */}

#### `connect(agentId, options)` {/* #connectagentid-options */}

将Agent连接到 Telegram 机器人。Provider通过以下方式验证 BotFather 令牌`getMe`, prepares the selected delivery mode and commands, then stores the installation before activating the adapter.

```typescript
const result = await telegram.connect('support', {
  botToken: process.env.TELEGRAM_BOT_TOKEN,
  name: 'Support bot',
  commands: [
    { command: 'help', description: 'Show support options' },
    { command: 'status', description: 'Check service status' },
  ],
})
```

`TelegramConnectOptions`字段：

<PropertiesTable
  content={[
{
  name: 'botToken',
  type: 'string',
  isOptional: true,
  description:
    'BotFather token. When provided, the connection completes immediately. When omitted, connect() returns a BotFather deep link and a pending installation ID.',
},
{
  name: 'name',
  type: 'string',

返回：`Promise<ChannelConnectResult>`

#### `disconnect(agentId)` {/* #disconnectagentid */}

停止活动传输并删除其存储的安装。在 Webhook 模式下，它还会删除 Telegram Webhook。

```typescript
await telegram.disconnect('support')
```

返回：`Promise<void>`

#### `listInstallations()` {/* #listinstallations */}

列出活动和待处理的 Telegram 安装，而不会暴露机器人或 webhook 秘密令牌。

```typescript
const installations = await telegram.listInstallations()
```

返回：`Promise<ChannelInstallationInfo[]>`

#### `getInstallation(agentId)` {/* #getinstallationagentid */}

返回Agent的完整安装，包括敏感的机器人和 Webhook 令牌，或者`null` when no installation exists.

```typescript
const installation = await telegram.getInstallation('support')
```

返回：`Promise<TelegramInstallation | null>`

### 配置和状态 {/* #configuration-and-status */}

#### `configure(credentials)` {/* #configurecredentials */}

在运行时更新 Bot API 源或 Webhook 基本 URL。通过`null` is a no-op because Telegram credentials belong to individual bot installations.

```typescript
await telegram.configure({
  baseUrl: 'https://new-app.example.com',
  apiBaseUrl: 'https://api.telegram.org',
})
```

返回：`Promise<void>`

#### `initialize()` {/* #initialize */}

在重新连接注册Agent之前，从存储中恢复活动安装并重建其 Telegram 适配器。 Mastra 在启动期间调用此方法。

```typescript
await telegram.initialize()
```

返回：`Promise<void>`

#### `isConfigured()` {/* #isconfigured */}

返回是否存在至少一个活动的 Telegram 安装。

```typescript
const configured = telegram.isConfigured()
```

#### `getInfo()` {/* #getinfo */}

返回编辑器 UI 的通道发现元数据，包括连接状态和`botToken` and `name` connect-option schema.

```typescript
const info = telegram.getInfo()
```

返回：`ChannelPlatformInfo`

#### `getAdapter(installationId)` {/* #getadapterinstallationid */}

返回直播`TelegramAdapter` for an active installation.

```typescript
const adapter = telegram.getAdapter(installationId)
```

返回：`TelegramAdapter | undefined`

#### `getRoutes()` {/* #getroutes */}

返回Provider未经身份验证的`POST /telegram/events/:webhookId` route. Mastra registers this route automatically.

```typescript
const routes = telegram.getRoutes()
```

返回：`ApiRoute[]`

## 交付方式 {/* #delivery-modes */}

* **`webhook`**&#x5728;下注册每个机器人的 Webhook`/telegram/events/:webhookId` and verifies the `X-Telegram-Bot-Api-Secret-Token` header.
* **`polling`**&#x5728;启动 Telegram 之前删除任何现有的 webhook`getUpdates` loop.
* **`auto`**&#x5F53;公共基本 URL 可用时选择 Webhook，否则进行轮询。

在生产中，使用持久通道存储和设置`encryptionKey` or `MASTRA_ENCRYPTION_KEY`, because the in-memory fallback doesn't preserve installations across restarts.
