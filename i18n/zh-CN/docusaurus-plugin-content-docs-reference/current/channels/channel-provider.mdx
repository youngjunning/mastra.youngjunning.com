# ChannelProvider

`ChannelProvider` 是平台集成实现的接口，用于将 Agent 连接到消息平台。Provider 负责集成的完整生命周期，包括通过 OAuth 配置应用、路由 Webhook 并处理事件、创建适配器并关联 Agent，以及管理凭据。

在 `Mastra` 构造函数的 `channels` 配置中注册 Provider，并使用自定义 ID 作为键。各 Provider 的路由会自动合并到服务器的 API 路由中；Mastra 启动时会调用 `initialize()`。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core/mastra'
import { SlackProvider } from '@mastra/slack'

export const mastra = new Mastra({
  channels: {
    slack: new SlackProvider({
      refreshToken: process.env.SLACK_REFRESH_TOKEN!,
      baseUrl: process.env.MASTRA_BASE_URL,
    }),
  },
})
```

Provider 的 `baseUrl` 是平台发送 Webhook 和事件的公开 URL。在生产环境中，它是已部署的 Mastra 服务器 URL。本地开发时，平台无法访问 `http://localhost:4111`，因此需要运行隧道服务（如 [cloudflared](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/) 或 [ngrok](https://ngrok.com/)），并将 `baseUrl` 设为隧道 URL（例如 `https://abc123.trycloudflare.com`），让事件到达本地开发进程。

Mastra 提供 [`SlackProvider`](/reference/channels/slack-provider) 和 [`TelegramProvider`](/reference/channels/telegram-provider) 实现。也可以通过实现此接口构建自定义 Provider。

## 动态解析 {/* #dynamic-resolution */}

除了静态对象，`channels` 还接受解析器：一个返回当前 Provider 映射的异步函数，并带有同步的 `getRoutes()` 方法。Mastra 会在构造时挂载解析器提供的路由，并在运行时解析 Provider，因此启动后新增的连接无需重新部署即可使用。`channels()` 是 `@mastra/connect` 提供的辅助函数，会返回由 Mastra 平台支持的解析器。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core/mastra'
import { channels } from '@mastra/connect'

export const mastra = new Mastra({
  channels: await channels({ projectId: process.env.MASTRA_PROJECT_ID! }),
})
```

配置解析器后，调用 `resolveChannels()` 可获取当前的 Provider 映射。它也支持静态对象，此时直接返回该对象。

```typescript
const providers = await mastra.resolveChannels()
```

## 访问 Provider {/* #accessing-a-provider */}

通过 `channels` getter 和注册时使用的 ID 访问 Provider。getter 的类型由构造函数配置推断，因此 `mastra.channels.slack` 是具体的 Provider，可访问其全部方法。

```typescript
await mastra.channels.slack.configure({ refreshToken })
```

如果 ID 只在运行时才知道，可通过字符串 ID 查找 Provider。`getChannelProvider` 使用泛型指定具体类型，`getChannelProviders` 返回按 ID 索引的所有已注册 Provider。使用[解析器](#dynamic-resolution)时，两者都会返回最新解析得到的快照。需要反映当前平台状态的 Provider 时，请使用 `resolveChannels()`。

```typescript
import type { SlackProvider } from '@mastra/slack'

const slack = mastra.getChannelProvider<SlackProvider>('slack')
const all = mastra.getChannelProviders()
```
