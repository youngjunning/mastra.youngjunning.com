# TeamsProvider

`TeamsProvider` 通过 Bot Framework 将 Mastra Agent 接入 Microsoft Teams。将其注册到 `Mastra.channels` 后，它可管理机器人安装、接收经过 JWT 验证的活动 Webhook，并通过自适应卡片和流式回复，将 Teams 对话交给相应的 Agent。

该 Provider 支持两种互斥的凭据模式：

- **自行管理**：使用现有的 Azure Bot 注册，并提供其 `appId` 和 `appPassword`。将机器人的消息端点指向该安装的 Webhook URL。
- **委托创建**：提供能按 scope 获取管理凭据的 `tokenResolver`。调用 `connect(agentId)` 后，系统会为每个 Agent 创建专属机器人：通过 Microsoft Graph 创建 Entra 应用及客户端密钥，再通过 Teams Developer Portal API 注册机器人，并将消息端点指向 Mastra 服务器。

## 使用示例 {/* #usage-example */}

以下示例使用现有 Azure Bot 注册，以自行管理模式接入：

```typescript title="src/mastra/index.ts"
import { Agent } from '@mastra/core/agent'
import { Mastra } from '@mastra/core/mastra'
import { TeamsProvider } from '@mastra/teams'

const supportAgent = new Agent({
  id: 'support',
  name: 'Support agent',
  instructions: 'Help users with product questions.',
  model: 'openai/gpt-5-mini',
})

const teams = new TeamsProvider({
  baseUrl: 'https://your-app.example.com',
  appId: process.env.TEAMS_APP_ID,
  appPassword: process.env.TEAMS_APP_PASSWORD,
})

export const mastra = new Mastra({
  agents: { supportAgent },
  channels: { teams },
})

await teams.connect('support')
```

将机器人注册的消息端点指向该安装的 `messagingEndpoint`，例如 `https://your-app.example.com/teams/events/<webhookId>`。

委托创建模式使用管理凭据为每个 Agent 创建机器人：

```typescript title="src/mastra/index.ts"
import { TeamsProvider, TEAMS_GRAPH_SCOPE } from '@mastra/teams'

const teams = new TeamsProvider({
  baseUrl: 'https://your-app.example.com',
  tokenResolver: async scope => {
    // Return an access token minted for the requested audience:
    // Microsoft Graph or the Teams Developer Portal API.
    return fetchManagerToken(scope)
  },
})
```

## 凭据模式与令牌受众 {/* #credential-modes-and-token-audiences */}

创建 Teams 机器人涉及两种令牌受众，因此委托模式下的 `tokenResolver` 会收到需要为其申请令牌的 scope：

| Scope 常量 | 受众 | 用途 |
| - | - | - |
| `TEAMS_GRAPH_SCOPE` | Microsoft Graph | 为每个 Agent 创建 Entra 应用及客户端密钥 |
| `TEAMS_DEV_PORTAL_SCOPE` | Teams Developer Portal API | 创建和删除机器人注册 |

管理凭据仅用于创建机器人。每个新建机器人都有独立的客户端密钥，密钥会加密存入安装存储；运行时使用该 Agent 专属密钥向 Bot Framework 认证。

直接提供凭据（`appId`/`appPassword`）与使用 `tokenResolver` 互斥。类型检查以及 `configure()`、`connect()` 的运行时检查都会强制执行这一约束。

## 方法 {/* #methods */}

### 安装生命周期 {/* #installation-lifecycle */}

#### `connect(agentId, options?)` {/* #connectagentid-options */}

将 Agent 接入 Microsoft Teams。具体行为取决于凭据模式：

- **委托创建**（`tokenResolver`）：先通过 Microsoft Graph 为该 Agent 创建 Entra 应用和客户端密钥，再通过 Teams Developer Portal 注册机器人，并将消息端点指向当前服务器。返回指向 Developer Portal 的 `{ type: 'deep_link' }`，以便将机器人打包成 Teams 应用并安装。如果 Developer Portal 操作失败，会回滚 Entra 应用。
- **自行管理且已提供凭据**（本次调用传入或使用 Provider 默认值）：请求 Bot Framework 令牌以验证凭据，保存安装并返回 `{ type: 'immediate' }`。
- **自行管理但未提供凭据**：保存待完成的安装，并返回指向 Teams Developer Portal 的 `{ type: 'deep_link' }`。

返回：`Promise<ChannelConnectResult>`

以下情况会抛出错误：Agent 已连接、其他 Agent 已使用同一机器人、Microsoft 拒绝凭据，或委托创建模式缺少注册消息端点所需的 `baseUrl`。

#### `disconnect(agentId)` {/* #disconnectagentid */}

断开 Agent 与 Microsoft Teams 的连接。对于该 Provider 在委托模式下创建的机器人，会尽力删除 Developer Portal 中的注册和 Entra 应用。即使控制面操作失败，也会移除本地安装。

#### `listInstallations()` {/* #listinstallations */}

列出供编辑器 UI 使用的公开安装信息，不包含密钥。

返回：`Promise<ChannelInstallationInfo[]>`

#### `getInstallation(agentId)` {/* #getinstallationagentid */}

获取 Agent 的完整安装信息，包括客户端密钥。如果该 Agent 未安装 Teams 机器人，则返回 `null`。

返回：`Promise<TeamsInstallation | null>`

### 配置和状态 {/* #configuration-and-status */}

#### `configure(credentials)` {/* #configurecredentials */}

更新 Provider 的运行时设置。传入 `appId`/`appPassword` 可修改后续 `connect()` 调用默认使用的机器人凭据；传入 `baseUrl`/`apiUrl` 可让 Provider 或适配器指向其他主机；传入 `null` 可清除默认凭据。

在委托创建模式下，如果传入 `appId` 或 `appPassword`，此方法会抛出错误，因为每个 Agent 的机器人凭据由系统单独创建。

#### `initialize()` {/* #initialize */}

从存储中恢复安装：为每个活动机器人重建适配器，并注入 `AgentChannels`，使 Agent 能立即接收事件。重复调用不会产生额外效果。

#### `isConfigured()` {/* #isconfigured */}

检查是否至少有一个机器人已完成注册并处于活动状态。

返回：`boolean`

#### `getInfo()` {/* #getinfo */}

返回供编辑器 UI 发现 Provider 的元数据，包括 `connect()` 选项的 schema。存在可用凭据或活动安装时，`isConfigured` 为 `true`。

返回：`ChannelPlatformInfo`

#### `getAdapter(installationId)` {/* #getadapterinstallationid */}

如果指定安装处于活动状态，获取其正在使用的 `TeamsAdapter`。

返回：`TeamsAdapter | undefined`

#### `getRoutes()` {/* #getroutes */}

返回一条无需预先认证的 `POST /teams/events/:webhookId` 路由。适配器会验证入站请求的 Microsoft JWT 签名，并检查其受众是否为机器人的 `appId`。`webhookId` 仅用于路由，不包含密钥。

返回：`ApiRoute[]`
