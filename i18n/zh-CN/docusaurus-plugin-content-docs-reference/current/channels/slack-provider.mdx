# SlackProvider

`SlackProvider` 提供将 Agent 接入 Slack 的托管方式。将它注册到 `Mastra.channels` 后，它会通过 Manifest API 创建 Slack 应用并执行 OAuth 安装流程，还会轮换配置令牌并将 Slack 事件路由给 Agent。希望由 Mastra 负责创建和安装应用时使用它。如果要自行创建 Slack 应用、配置权限范围和 webhook，则使用底层的 [`createSlackAdapter`](/integrations/channels/slack)，将其配置在 Agent 的 `channels.adapters` 中。

## 使用示例 {/* #usage-example */}

在 `Mastra` 构造函数中注册 Provider。刷新令牌只能使用一次，并会在启动时轮换。生成的访问令牌会持久化到 `Mastra.storage`。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core/mastra'
import { SlackProvider } from '@mastra/slack'

export const mastra = new Mastra({
  storage,
  channels: {
    slack: new SlackProvider({
      refreshToken: process.env.SLACK_APP_CONFIG_REFRESH_TOKEN,
      baseUrl: process.env.MASTRA_BASE_URL,
    }),
  },
})
```

如果构造时尚无凭据（例如凭据由 Editor UI 输入或从密钥库加载），可以先不传凭据创建 Provider，之后再调用 [`configure()`](#configurecredentials)：

```typescript title="src/mastra/index.ts"
const slack = new SlackProvider()

await slack.configure({
  refreshToken: process.env.SLACK_APP_CONFIG_REFRESH_TOKEN,
})
```

## 方法 {/* #methods */}

### Agent 连接 {/* #agent-connections */}

#### `connect(agentId, options?)` {/* #connectagentid-options */}

通过 Manifest API 为 Agent 创建 Slack 应用，返回包含授权 URL 的 OAuth 结果，供用户跳转。必须设置 `baseUrl`。如果该 Agent 已有待完成的安装，则返回现有授权 URL，而不会重复创建应用。

```typescript
const result = await slack.connect('support-agent', {
  name: 'Support Bot',
})

// Redirect the user to result.authorizationUrl to install the app
```

返回：`Promise<ChannelConnectResult>`

```typescript
interface ChannelConnectResult {
  type: 'oauth'
  installationId: string
  authorizationUrl: string
}
```

#### `disconnect(agentId)` {/* #disconnectagentid */}

删除 Agent 的 Slack 应用并从存储中移除安装记录，以断开连接。

```typescript
await slack.disconnect('support-agent')
```

返回：`Promise<void>`

#### `getInstallation(agentId)` {/* #getinstallationagentid */}

返回 Agent 的 Slack 安装记录；不存在时返回 `null`。

```typescript
const installation = await slack.getInstallation('support-agent')
```

返回：`Promise<SlackInstallation | null>`

#### `listInstallations()` {/* #listinstallations */}

列出所有 Slack 安装记录，包括有效和待完成的安装；仅包含公开信息。

```typescript
const installations = await slack.listInstallations()
```

返回：`Promise<ChannelInstallationInfo[]>`

### 配置 {/* #configuration */}

#### `configure(credentials)` {/* #configurecredentials */}

在运行时提供或清除 Slack App Configuration 凭据。构造时凭据尚不可用时可使用此方法。传入 `null` 会清除凭据并删除已存储的令牌。

```typescript
// Provide credentials (persists to storage immediately)
await slack.configure({ refreshToken: 'xoxe-1-...' })

// Clear credentials and stored tokens
await slack.configure(null)
```

返回：`Promise<void>`

#### `setBaseUrl(baseUrl)` {/* #setbaseurlbaseurl */}

设置用于 webhook 和 OAuth 回调的公开基础 URL。构造时尚不知道 URL，且无法从服务器配置自动检测时使用。

```typescript
slack.setBaseUrl('https://abc123.trycloudflare.com')
```

#### `initialize()` {/* #initialize */}

为存储中的每条有效安装记录重新创建 `SlackAdapter`，并向对应 Agent 注入 `AgentChannels`，使其启动后能接收 Slack 事件。此方法不会自动创建新应用；要创建应用请调用 `connect()`。Mastra 会自动调用它，通常无需手动调用。

```typescript
await slack.initialize()
```

返回：`Promise<void>`

## 获取 Provider {/* #accessing-the-provider */}

通过带类型的 `channels` getter，以注册时使用的 ID 为键获取 Provider：

```typescript
const result = await mastra.channels.slack.connect('support-agent')
```

如果只有在运行时才知道键名，可按字符串 ID 查找并传入具体类型：

```typescript
const slack = mastra.getChannelProvider<SlackProvider>('slack')
const result = await slack.connect('support-agent')
```

## 存储要求 {/* #storage-requirement */}

`SlackProvider` 要求在 `Mastra` 上配置持久化存储，以加密并保存安装记录及轮换的配置令牌。如果没有持久化存储，也未传入自定义 `storage`，构造函数会抛出异常。
