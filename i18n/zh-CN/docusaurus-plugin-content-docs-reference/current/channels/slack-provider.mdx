# SlackProvider

`SlackProvider`是将Agent连接到 Slack 的托管路径。注册于`Mastra.channels`它通过 Manifest API 提供 Slack 应用程序并运行 OAuth 安装流程。它还轮换配置令牌并将 Slack 事件路由到您的Agent。当您希望 Mastra 拥有应用程序创建和安装的所有权时，请使用它。对于您创建 Slack 应用程序并自行配置范围和 webhooks 的较低级别路径，请使用[`createSlackAdapter`](/integrations/channels/slack)在Agent的`channels.adapters`反而。

## 使用示例 {/* #usage-example */}

在 上注册Provider`Mastra` constructor. The refresh token is single-use and rotates on startup. The resulting access tokens are persisted to `Mastra.storage`.

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core/mastra'
import { SlackProvider } from '@mastra/slack'

export const mastra = new Mastra({
  storage,
  channels: {
    slack: new SlackProvider({
      refreshToken: process.env.SLACK_APP_CONFIG_REFRESH_TOKEN,
      baseUrl: process.env.MASTRA_BASE_URL,
    }),
  },
})
```

当构造时凭证不可用（例如，通过编辑器 UI 输入或从保管库加载）时，构造没有它们的提供程序并调用[`configure()`](#configurecredentials) later:

```typescript title="src/mastra/index.ts"
const slack = new SlackProvider()

await slack.configure({
  refreshToken: process.env.SLACK_APP_CONFIG_REFRESH_TOKEN,
})
```

## 方法 {/* #methods */}

### Agent连接 {/* #agent-connections */}

#### `connect(agentId, options?)` {/* #connectagentid-options */}

通过 Manifest API 为Agent创建一个新的 Slack 应用程序，并返回 OAuth 结果以及用于将用户重定向到的授权 URL。需要`baseUrl` to be set. If a pending installation already exists for the agent, returns its existing authorization URL instead of creating a duplicate app.

```typescript
const result = await slack.connect('support-agent', {
  name: 'Support Bot',
})

// Redirect the user to result.authorizationUrl to install the app
```

返回：`Promise<ChannelConnectResult>`

```typescript
interface ChannelConnectResult {
  type: 'oauth'
  installationId: string
  authorizationUrl: string
}
```

#### `disconnect(agentId)` {/* #disconnectagentid */}

通过删除Agent的应用程序并从存储中删除安装来断开Agent与 Slack 的连接。

```typescript
await slack.disconnect('support-agent')
```

返回：`Promise<void>`

#### `getInstallation(agentId)` {/* #getinstallationagentid */}

返回Agent的 Slack 安装，或者`null` if none exists.

```typescript
const installation = await slack.getInstallation('support-agent')
```

返回：`Promise<SlackInstallation | null>`

#### `listInstallations()` {/* #listinstallations */}

列出所有 Slack 安装（仅限公共信息），包括活动的和待处理的。

```typescript
const installations = await slack.listInstallations()
```

返回：`Promise<ChannelInstallationInfo[]>`

### 配置 {/* #configuration */}

#### `configure(credentials)` {/* #configurecredentials */}

在运行时提供或清除 Slack 应用程序配置凭据。当构建时凭证不可用时，请使用此选项。经过`null` to clear credentials and delete stored tokens.

```typescript
// Provide credentials (persists to storage immediately)
await slack.configure({ refreshToken: 'xoxe-1-...' })

// Clear credentials and stored tokens
await slack.configure(null)
```

返回：`Promise<void>`

#### `setBaseUrl(baseUrl)` {/* #setbaseurlbaseurl */}

设置用于 webhook 和 OAuth 回调的公共基本 URL。当构造时 URL 未知且无法从服务器配置中自动检测时，请使用此选项。

```typescript
slack.setBaseUrl('https://abc123.trycloudflare.com')
```

#### `initialize()` {/* #initialize */}

重新创建一个`SlackAdapter` for each active installation in storage and injects `AgentChannels` into the corresponding agent so it receives Slack events on startup. Doesn't auto-provision new apps. Use `connect()` to create one. Mastra calls this automatically, so you rarely call it directly.

```typescript
await slack.initialize()
```

返回：`Promise<void>`

## 访问Provider {/* #accessing-the-provider */}

通过键入的内容访问注册的提供者`channels` getter, keyed by the id you registered it under:

```typescript
const result = await mastra.channels.slack.connect('support-agent')
```

当密钥仅在运行时已知时，通过字符串 id 查找它并传递具体类型：

```typescript
const slack = mastra.getChannelProvider<SlackProvider>('slack')
const result = await slack.connect('support-agent')
```

## 存储要求 {/* #storage-requirement */}

`SlackProvider`需要持久存储`Mastra` to encrypt and persist installations and rotating configuration tokens. The constructor throws if no persistent storage is available and no custom `storage` is passed.
