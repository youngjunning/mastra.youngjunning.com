# buildBasePrompt()

`buildBasePrompt()` 为 Coding Agent 构建共享的基础系统提示词，其中包含让 Agent 成为优秀编程助手的行为指令。它接收描述当前环境（项目、平台、Git 分支、模式和模型）的 `PromptContext`，并返回字符串形式的提示词。

产品相关文本通过 `productName`、`coAuthorName` 和 `coAuthorEmail` 参数配置，因此无需派生代码，就能更改提示词中的品牌名称和提交记录中的共同作者尾注。共同作者的默认名称和邮箱分别为 `"mastra-platform[bot]"` 和 `"284800079+mastra-platform[bot]@users.noreply.github.com"`。

构建 Agent 在运行时使用的指令时，可将此函数与 [`createCodingAgent()`](/reference/coding-agent/create-coding-agent) 配合使用。

## 使用示例 {/* #usage-example */}

根据 `PromptContext` 构建基础提示词：

```typescript title="src/mastra/prompt.ts"
import { buildBasePrompt } from '@mastra/core/coding-agent'

const prompt = buildBasePrompt({
  projectPath: process.cwd(),
  projectName: 'my-app',
  gitBranch: 'main',
  platform: process.platform,
  date: new Date().toDateString(),
  mode: 'build',
  modelId: '__GATEWAY_OPENAI_MODEL_BASE__',
  toolGuidance: '',
})
```

如需更改提示词中的品牌名称，请传入产品名称和共同作者字段：

```typescript
const prompt = buildBasePrompt({
  // ...environment fields
  productName: 'Acme Coder',
  coAuthorName: 'Acme Bot',
  coAuthorEmail: 'bot@acme.dev',
})
```
