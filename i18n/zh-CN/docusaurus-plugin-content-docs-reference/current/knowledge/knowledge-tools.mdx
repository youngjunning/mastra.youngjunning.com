# Knowledge 工具

Knowledge 为 Agent 提供六种 Tool。Agent 获得哪些 Tool，取决于 Knowledge 的 `tools` 和 `pinnedContext` 选项，或传给 [`createTools()`](/reference/knowledge/knowledge-class#createtools) 的工具组。有关 Agent 如何使用这些工具，请参阅 [Agent 与工具](/docs/knowledge/agents-and-tools)。

| 组 | 工具 | 启用条件 |
| - | - | - |
| 读取 | `knowledge_list`, `knowledge_search`, `knowledge_read` | `tools: true` 或 `tools: { read: true }` |
| 写入 | `knowledge_page`, `knowledge_note` | `tools: true` 或 `tools: { write: true }` |
| 固定上下文 | `knowledge_pin` | `pinnedContext` |

每种 Tool 都依据本次运行持有的作用域，以及 Knowledge 声明赋予的角色执行操作。没有任何作用域的运行会失败，并返回：

```text
Knowledge tools need run scopes: give the agent or the call `scopes`, or run it with Memory.
```

Tool 错误会作为工具结果返回给模型，而不会抛出异常。运行无权读取的页面或笔记会表现得像不存在：错误只会说未找到，不会说访问被拒绝。

:::alpha

Knowledge 目前处于 alpha 阶段，API 可能随版本变化。

:::

## 页面引用 {/* #page-references */}

名为 `page` 的参数（以及 `into`、`parent`、`from`）接受以下任一形式：

- 页面 ID。
- 作用域自身页面的作用域地址，例如 `org:acme`。
- 页面路径 `<scope>#<key>[/<key>…]`，例如 `policy:acme#refund-policy` 或 `org:acme#policies/refund`。
- 完全匹配的页面名称。

在页面路径中，`/` 位于 `#` 前时表示子作用域，`/` 位于其后时表示子页面。页面部分开头、结尾和重复的斜杠会被忽略，因此 `org:acme#policies/` 和 `org:acme#policies` 指向同一页面。路径在使用时解析；页面移动后，只能通过新路径访问。

如果名称匹配多个可读取页面，操作会被拒绝，并返回候选页面的引用：

```text
Knowledge page name "Chargeback Playbook" is ambiguous; use one of these refs: team:acme:billing#chargeback-playbook, team:acme:support#chargeback-playbook.
```

工具结果使用 `ref` 标识每个页面；上述参数均接受以下形式：

- 对于作用域页面，使用作用域地址。
- 对于每一级都有 key 的页面，使用完整路径，例如 `docs:acme#guides/observability/logging`。
- 其他情况使用页面 ID。

读取不存在的页面时，结果会按 `ref` 列出最多三个相近的匹配项。

## `knowledge_search` {/* #knowledge_search */}

搜索本次运行可读取的页面和笔记。

查询会拆分为单词，忽略引号。匹配时不区分大小写，每个查询词都可匹配单词的一部分，因此 `refund` 能匹配 `refunds`。页面的名称、描述或正文只要包含任一查询词就会匹配；笔记则根据自身文本匹配。

关键词结果按以下顺序排序：

1. 名称包含完整查询内容的页面。
1. 其他页面：先按匹配的查询词数量排序，再按出现位置排序（名称优先于描述，描述优先于正文），最后按最近更新时间排序。
1. 笔记：先按匹配的查询词数量排序，再按新旧排序。

访问权限和 `scope` 会在排序前筛选结果；`limit` 在筛选和排序后生效。如果 Knowledge 实例配置了 `vector` 和 `embedder`，关键词与语义搜索结果会按排名合并，上述顺序便不再适用。

- 如果没有搜索结果，会建议更换关键词或使用 `knowledge_list`：

`scope` 只接受作用域地址。传入 `docs:acme#billing` 这样的页面引用会被拒绝，并提示使用 `knowledge_list`。

完整读取返回 `{ page, notes, children, childScopes?, mentionedIn, nextCursor?, mentionedInCursor?, more? }`，正文位于 `page`。被截断的内容会列在 `more` 中，并说明如何继续读取：

- **正文。** 正文若未超出读取上限（默认 1,000 个 token，除非通过 [`tools.read.maxTokens`](/reference/knowledge/knowledge-class#constructor-options) 调整），会作为 `page.body` 返回。较长的正文会作为 `page.lines` 返回，带有行号（`12│text`），并包含所覆盖行的 `page.range` 和 `page.lineCount`。`more` 会提示从哪里继续读取，例如 `body: showing lines 1–40 of 412. Read on with from: {"line":41}.`
- **首次读取长页面。** 如果正文包含标题，普通读取（不指定 `section` 或 `from`）会先给出整页概览：`page.lines` 在读取上限内分配篇幅，显示每个标题及其行号、标题下的开头几行；省略的行以 `⋯ lines a–b` 标示，截断的行以 `…` 标示。结果包含 `page.lineCount`，但不包含 `page.range`，因此不能直接用于回写。请先按 `section` 或 `from` 读取，再用该次读取返回的 `range` 编辑。没有标题，或标题多到超出上限时，则返回带 `page.range` 的开头几行，并通过 `page.outline` 列出尚未读到的标题（最多约 500 个 token）。
- **笔记与提及。** 完整读取最多获取 `limit` 条笔记和 `limit` 条提及此页面的笔记。只要获取的笔记总量不超过 1,000 个 token，两份列表会随结果返回。较长的列表会改为 `notesLeftOut` 或 `mentionedInLeftOut`，表示已获取的笔记数；`more` 会提示用 `notes: true` 或 `mentionedIn: true` 单独读取。如果笔记总数超过 `limit`，`more` 中的数量和 token 估算只覆盖已获取的部分，实际列表更长。
- **子页面与子作用域。** 超过 `limit` 时，`more` 会提示使用 `knowledge_list` 列出其余内容。

`range` 的结构为 `{ start: { line, col? }, end: { line, col? } }`。行号从 1 开始。只有一行长到无法一次读完时，读取结果才会包含从 0 开始的 `col`；结束位置的 `col` 不包含在范围内。将该范围传给 `knowledge_page` 即可替换这些行。

`match` 返回 `matches`，每项包含 `{ range, lines }`。匹配结果超过读取上限（默认 1,000 个 token）时，`more` 会给出继续读取的行号，例如 `match: stopped at about 1,000 tokens; more matches from line 120. Read again with the same match and from: {"line":120}.`

`outline`、`section`、`match` 和 `from` 只返回对应的正文内容，不返回笔记、子页面或提及笔记。`outline`、`section` 和 `match` 最多只能传入一个。`notes`、`mentionedIn` 及两种游标只返回相应笔记，不返回正文，且不能与正文选项组合：

```text
knowledge_read: read notes or mentionedIn on their own, without outline, section, match or from.
```

对 `body` 的写入若未指定 `range`，且已存储的正文超过单次读取上限（默认 1,000 个 token），会被拒绝。以下情况也会拒绝 `range`：缺少 `expectedVersion`、起点晚于终点、范围超出正文末尾，或范围覆盖的内容超过从其首行开始单次读取所能返回的内容：

```text
Lines 1–150 run past what one knowledge_read from line 1 shows, so this can't be a range a read gave you. Edit the body part by part: write each part back with the range its own read returned.
```

如果 `body` 仍包含读取时添加的行号，写入会被拒绝：`This body still has the line numbers a knowledge_read put in front of each line ("12│"). Write the text without them.`

| 操作 | 所需角色 |
| - | - |
| 创建（`write` 未传入 `page`） | `contributor`，在 `scope` 上 |
| 编辑（`write` 传入 `page`） | 页面作用域上的 `editor` |
| 在同一作用域内移动 | 页面作用域上的 `editor` |
| 移动到其他作用域 | `owner`，在页面作用域和目标 `scope` 上 |
| 合并 | 被合并页面的作用域上需有 `owner`；保留页面 `into` 所在作用域若相同需有 `editor`，若不同则需有 `owner`，因为子页面会移至该处 |
| 删除 | 页面作用域上的 `owner` |

在作用域的 `pages` 中声明的模板页面，无论运行持有什么角色，都可以编辑、添加笔记或作为合并目标，但不能移动、作为被合并页面或删除。

作用域页面的名称和描述来自配置，因此对作用域页面执行 `write` 只会修改正文；作用域页面不能移动、合并或删除。

`delete` 会从读取、搜索和固定上下文中移除页面。存在子页面的页面、作用域页面和模板页面都不能删除。

错误示例：

```text
Creating a page needs scope and name.
Editing a page needs at least one of name, description or body.
Editing a page takes no scope, parent or key; use op "move" to relocate it.
Moving a page needs the destination scope.
Merging needs into: the page that remains.
"Escalation" has child pages; move or delete them first.
"org:acme" is a scope page; scope pages can't be moved, merged or deleted.
"org:acme" is a scope page; its name and description come from config, so only its body can be written.
Knowledge page "org:acme#policies/escalation" not found.
Knowledge page key "a/b" must not contain "/", "#" or "%"
Knowledge page key "escalation" already exists under page aa8f6099-6111-4952-b9cb-04cb97eb2bb5. Keys are unique among siblings; pick another key or move one of the pages.
"org:acme#policies/refund" is declared in config; change the scope's pages to move it.
"org:acme#policies/refund" is declared in config; change the scope's pages to remove it.
Editing a page needs editor on "team:acme:support"; this run has viewer there.
Moving a page across scopes needs owner on "org:acme"; this run has editor there.
Merging a page away needs owner on "team:acme:support"; this run has editor there.
Merging a page across scopes needs owner on "team-public:acme:support"; this run has editor there.
Deleting a page needs owner on "org:acme"; this run has editor there.
Knowledge page description exceeds the 100 token limit; put long-form text in the page body
Knowledge record version conflict: 37c1e879-b328-47a9-9d3c-5788ad35ca2d
```

| 操作 | 所需角色 |
| - | - |
| `add` | 页面作用域及每个标记作用域上的 `contributor` |

```text
Adding a note needs page and text.
Adding a note needs scope: the stamp scopes.
Adding a note needs contributor on "team:acme:support"; this run has viewer there.
Removing a note needs editor on "team:acme:support"; this run has viewer there.
Knowledge note text exceeds the 250 token limit; split it into separate notes or put long-form text in the page body
```

固定或取消固定页面时，需要页面作用域上的 `editor`，并且必须持有每个受众作用域，或在其上拥有 `editor`。固定的页面只会发给有权读取它的运行；固定的列表也只显示该运行可读取的页面。固定列表需要支持存储固定项类型的存储适配器版本。旧版适配器仍支持固定页面，但会在写入前拒绝固定列表。

```text
Pinning a page needs editor on "policy:acme"; this run has viewer there.
Pinning for "role:acme:sales" needs holding it or editor on it; this run has neither.
Pin audience "project:x" does not match a declared scope type.
```

## 各操作所需权限 {/* #what-each-operation-needs */}

| 操作 | 角色 | 适用范围 |
| - | - | - |
| 搜索、读取、列出 | `viewer` | 页面作用域 |
| 创建页面 | `contributor` | `scope` |
| 编辑页面 | `editor` | 页面作用域 |
| 在同一作用域内移动 | `editor` | 页面作用域 |
| 移动到其他作用域 | `owner` | 两个作用域 |
| 合并 | `owner` | 被合并的页面 |
| | `editor` | 同一作用域内保留的页面 |
| | `owner` | 其他作用域内保留的页面 |
| 删除页面 | `owner` | 页面作用域 |
| 添加笔记 | `contributor` | 页面作用域及每个标记作用域 |
| 重新标记或删除笔记 | `editor` | 页面作用域（每个新标记作用域还需 `contributor`） |
| 固定或取消固定页面或列表 | `editor` | 页面作用域，且须对每个受众拥有相应权限 |

调用目标在可访问范围内、但需要更高角色权限时，错误会指出所需角色：

```text
Adding a note needs contributor on "team:acme:support"; this run has viewer there.
```
