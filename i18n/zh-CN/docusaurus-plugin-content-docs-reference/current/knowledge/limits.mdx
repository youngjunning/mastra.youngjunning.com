# 限制

文本限制以标记计数。计数是估计值，因此请将数字视为近似值。

：：：阿尔法

知识处于阿尔法阶段。其 API 可能会在不同版本之间发生变化。

:::

|项目 |限制|
| - | - |
|备注文字| 250 个代币 |
|页面描述| 100 个代币 |
|页面嵌套| 10 个级别 |
|一次移动页面，计算移动页面下的所有内容 | 500 | 500
|`knowledge_search` results, and notes and child pages per `knowledge_read` | 10 by default, up to 50 |
| Page body or `match`结果每`knowledge_read`|默认1,000个代币，至少100 |
|注释以及提及该页面的注释，保持完整`knowledge_read`|每个列表 1,000 个代币 |
|`knowledge_list`条目 |默认50个，最多100个，默认1000个左右 |
|`knowledge_list`深度|默认1级，最多3级 |
|每页嵌入块，用于按含义搜索 | 100 个，每个约 2,000 个代币 |
|每回合固定上下文 |默认 500 个代币，无上限 |
|每轮固定页面 |默认 20 |
|固定列表深度 |默认1级，最多3级 |
|每个固定列表的页数|其代币份额最多可持有 1,000 个 |

超出限制的写入失败，并且模型将错误作为Tool结果。Tool架构不显示令牌限制，因为架构无法计算令牌。

页面主体没有令牌限制。`knowledge_read` returns a long body in parts, and an agent [edits it one part at a time](/reference/knowledge/knowledge-tools#knowledge_page) by line `range`. Pinned page bodies are cut to fit the pinned-context budget. See [what a run receives](/docs/knowledge/pinned-context#what-a-run-receives).

对于一次嵌入来说太长的页面会作为重叠块嵌入，在段落之间和标题之前进行剪切。每个块都以页面的名称和描述开头。搜索返回页面一次，并按其最佳块排名。超过 100 个块后，正文的其余部分只能通过关键字找到。重写页面会替换其块，删除页面则会删除它们。

不符合预算的固定页面的处理方式如下：

* 固定在配置中的页面永远不会被删除。当他们单独超出预算时，每个人都会获得平等的份额并被削减。
* 剪切的固定页面结尾为`[truncated — knowledge_read for the rest]`.
* 由不适合的Agent固定的页面将在一行中命名，最多十个，然后进行计数：`Also pinned (open with knowledge_read): Refund Policy, …and 3 more`.

固定列表算作一个 pin，并共享代币预算。不适合的页面一次填充一个级别，并且每个页面仍打印在其父页面下。当页面被省略时，它以`…and 4 more; knowledge_list from: "site:mastra"`, or `…and more` without a count when there are more pages than it fetched. Pinning a listing again sets its new depth, and a stored listing that repeats one from config is delivered once.

当范围声明更多内容时，Knowledge 会在启动时记录警告`pinnedContext` pages than `maxPins`, or so many that each would get under 50 tokens.

更改读取上限`tools: { read: { maxTokens } }`. See [`tools`](/reference/knowledge/knowledge-class#constructor-options). Change the pin limits with `pinnedContext: { maxPins, maxTokens }` on `Knowledge`.
