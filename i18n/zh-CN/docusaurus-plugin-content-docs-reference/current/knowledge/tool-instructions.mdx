# Tool 使用说明

Knowledge 将 Tool 附加到 Agent 时，还会添加一段简短的说明，解释这些 Tool 的用法。只有启用对应 Tool 时，才会包含相应部分：

* **读取**指示 Agent：
  * 回答前使用 `knowledge_search` 搜索；依赖某个页面前，先使用 `knowledge_read` 阅读该页面。
  * 使用 `knowledge_list` 列出 scope 或章节，了解其组织方式。
  * 对于长页面，先通读全文，再根据显示的标题读取所需章节。
  * 跟随 `more` 继续获取结果，不要假定当前结果已经完整。
  * 引用所使用的页面或 note；如果未找到任何内容，也应明确说明。
  * 如果两个 note 内容冲突，应同时展示它们及各自日期。
* **写入**指示 Agent：
  * 使用 `knowledge_note` 在相关页面中为每条 note 记录一个可长期保留的事实。
  * 创建新页面前，优先补充现有页面。
  * 使用 `knowledge_page` 将操作手册等长篇内容写入页面正文。
  * 将变更记录为带日期的新 note，并且只删除错误的 note。
* **固定内容**指示 Agent：
  * 只固定无需询问即可适用的长期指令、持久偏好和明确约束。
  * 保持固定页面简短；页面内容不再成立时，应取消固定。

这些文本只取决于启用的 Tool 和你的覆盖设置，不依赖本次运行的 scope、固定页面或搜索结果，因此不会破坏 prompt 缓存。

:::alpha

Knowledge 目前处于 alpha 阶段，其 API 可能在不同版本之间发生变化。

:::

## 覆盖指令 {/* #override-the-instructions */}

```typescript
import { Knowledge, knowledgeMemoryScopes } from '@mastra/core/knowledge'

const knowledge = new Knowledge({
  id: 'company',
  tools: true,
  scopes: { ...knowledgeMemoryScopes() },
  // instructions: false, to remove the block
  // instructions: 'Your own text', to replace it
  instructions: ({ read, write, pins }) => `${read}\n${write}\n${pins}\nAlways answer in French.`,
})
```

该函数通过 `read`、`write` 和 `pins` 接收各部分的默认文本；未启用的部分对应空字符串。相同输入必须返回相同字符串，否则 prompt 缓存将失效。

自行连接 Tool 时，如需添加这段说明，请调用 `knowledge.getInstructions({ read: true, write: true, pinnedContext: false })`。
