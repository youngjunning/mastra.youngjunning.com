# Tool使用说明

当知识将Tool附加到Agent时，它还会添加一个简短的指令块来解释如何使用它们。每个部件仅在其Tool打开时才包含在内：

* **读**告诉Agent：
  * 搜索方式`knowledge_search` before answering, and read a page with `knowledge_read` before relying on it.
  * 列出范围或部分`knowledge_list` to see how it's organized.
  * 首先阅读整个长页面，然后从显示的标题中阅读所需的部分。
  * 跟随`more` instead of assuming a result was complete.
  * 引用页面或注释它所使用的内容，并在没有找到任何内容时说明这一点。
  * 当他们意见不一致时，请显示两个注释及其日期。
* **写**告诉Agent：
  * 每条注释添加一个持久事实`knowledge_note`, on the page it's about.
  * 在创建页面之前添加到现有页面。
  * 将长文本（例如操作手册）放入页面正文中`knowledge_page`.
  * 将更改记录为新的注明日期的注释，并仅删除错误的注释。
* **针脚**告诉Agent：
  * 仅固定常设指示、持久偏好和严格约束，无需提出要求即可应用。
  * 保持固定页面简短，一旦页面不再真实，就取消固定页面。

文本仅取决于打开的Tool以及您的覆盖。它从不依赖于运行的范围、固定页面或搜索结果，因此它不会破坏提示缓存。

：：：阿尔法

知识处于阿尔法阶段。其 API 可能会在不同版本之间发生变化。

## 覆盖指令 {/* #override-the-instructions */}

```typescript
import { Knowledge, knowledgeMemoryScopes } from '@mastra/core/knowledge'

const knowledge = new Knowledge({
  id: 'company',
  tools: true,
  scopes: { ...knowledgeMemoryScopes() },
  // instructions: false, to remove the block
  // instructions: 'Your own text', to replace it
  instructions: ({ read, write, pins }) => `${read}\n${write}\n${pins}\nAlways answer in French.`,
})
```

该函数接收每个部分的默认文本为`read`, `write` and `pins`, with an empty string for parts that are off. Return the same string for the same inputs, or the prompt cache stops working.

要在您自己连接Tool时添加块，请调用`knowledge.getInstructions({ read: true, write: true, pinnedContext: false })`.
