# CachingPubSub

`CachingPubSub` 可包装任意 [`PubSub`](/reference/pubsub/base) 实现，增加事件缓存与重放功能。它按主题缓存每个已发布的事件，使较晚连接或断线重连的订阅者可以先重放错过的事件，再继续接收实时事件。

如果底层传输不保留历史记录，例如 [`EventEmitterPubSub`](/reference/pubsub/event-emitter)，可用它构建可恢复的流。已经持久化事件的传输（例如 [`RedisStreamsPubSub`](/reference/pubsub/redis-streams)）无需使用此包装器。

`CachingPubSub` 不改变底层的批处理能力：`subscribe()` 会将 `options.batch` 转发给内部 pub/sub，`supportsNativeBatching` 也与内部实现保持一致。若内部实现不支持批处理，即使传入 `options.batch`，事件仍会逐个交付。

## 使用示例 {/* #usage-example */}

包装内部 pub/sub，并提供用于存储事件的服务端缓存。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { CachingPubSub, EventEmitterPubSub } from '@mastra/core/events'
import { InMemoryServerCache } from '@mastra/core/cache'

const cache = new InMemoryServerCache()
const pubsub = new CachingPubSub(new EventEmitterPubSub(), cache)

export const mastra = new Mastra({
  pubsub,
})
```

使用 `withCaching` 辅助函数也会得到相同类型的实例；在行内包装时，代码更易读：

```typescript
import { withCaching, EventEmitterPubSub } from '@mastra/core/events'
import { InMemoryServerCache } from '@mastra/core/cache'

const pubsub = withCaching(new EventEmitterPubSub(), new InMemoryServerCache())
```

## 方法 {/* #methods */}

`CachingPubSub` 实现了 [`PubSub`](/reference/pubsub/base) 契约，并重写重放方法以读取缓存事件。以下方法说明其缓存行为。

### `publish(topic, event)` {/* #publishtopic-event */}

先以连续索引缓存事件，再将其发布到内部 pub/sub。

```typescript
await pubsub.publish('my-topic', {
  type: 'example',
  data: { value: 1 },
  runId: 'run-123',
})
```

### `subscribeWithReplay(topic, cb)` {/* #subscribewithreplaytopic-cb */}

先重放该主题的所有缓存事件，再订阅实时事件。

```typescript
await pubsub.subscribeWithReplay('my-topic', event => {
  console.log(event)
})
```

### `subscribeFromOffset(topic, offset, cb)` {/* #subscribefromoffsettopic-offset-cb */}

从 `offset` 开始重放缓存事件，再订阅实时事件。客户端已知上次接收位置时可使用此方法，避免重放全部历史事件。

```typescript
await pubsub.subscribeFromOffset('my-topic', 42, event => {
  console.log(event)
})
```

### `getHistory(topic, offset?)` {/* #gethistorytopic-offset */}

返回该主题从 `offset` 开始的缓存事件。

```typescript
const events = await pubsub.getHistory('my-topic', 0)
```

返回值：`Promise<Event[]>`

### `clearTopic(topic)` {/* #cleartopictopic */}

删除该主题的缓存事件和偏移量计数器，并将调用转发给内部 pub/sub，使持久化传输（例如 [`RedisStreamsPubSub`](/reference/pubsub/redis-streams)）也能清除其保留的状态。Mastra 的运行生命周期会在运行结束时自动调用此方法。

```typescript
await pubsub.clearTopic('my-topic')
```

## 函数 {/* #functions */}

### `withCaching(pubsub, cache, options?)` {/* #withcachingpubsub-cache-options */}

用于创建 `CachingPubSub` 的便捷包装函数。接受与构造函数相同的参数，并返回新实例。

```typescript
import { withCaching, EventEmitterPubSub } from '@mastra/core/events'
import { InMemoryServerCache } from '@mastra/core/cache'

const pubsub = withCaching(new EventEmitterPubSub(), new InMemoryServerCache(), {
  keyPrefix: 'events:',
})
```

返回值：`CachingPubSub`
