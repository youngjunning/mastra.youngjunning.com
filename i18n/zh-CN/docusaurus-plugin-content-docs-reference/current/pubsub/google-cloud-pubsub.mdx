# GoogleCloudPubSub

`GoogleCloudPubSub` 是 [`PubSub`](/reference/pubsub/base) 的一种实现，以 [Google Cloud Pub/Sub](https://cloud.google.com/pubsub/docs) 为基础。它通过 Google Cloud 的主题和订阅，在不同进程及主机间传递事件，并支持按序传递和消息确认。

适用于 Google Cloud 上的分布式部署。单进程传递可使用 [`EventEmitterPubSub`](/reference/pubsub/event-emitter)；Redis 场景可使用 [`RedisStreamsPubSub`](/reference/pubsub/redis-streams)。

每个 topic 都映射到一个 Google Cloud 主题。指定 group 的订阅会共享同一个订阅，组内成员竞争接收事件；未指定 group 时，每个实例都有自己的订阅，因而每个实例都会收到所有事件。

## 安装 {/* #installation */}

```bash npm2yarn
npm install @mastra/google-cloud-pubsub
```

## 使用示例 {/* #usage-example */}

传入 Google Cloud 客户端配置，例如项目 ID。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { GoogleCloudPubSub } from '@mastra/google-cloud-pubsub'

export const mastra = new Mastra({
  pubsub: new GoogleCloudPubSub({
    projectId: 'my-project',
  }),
})
```

## 方法 {/* #methods */}

`GoogleCloudPubSub` 实现了 [`PubSub`](/reference/pubsub/base) 契约。以下方法是此实现特有的。

### `init(topicName, group?)` {/* #inittopicname-group */}

如果主题和订阅尚不存在，则创建它们并返回订阅。`subscribe` 会在内部调用此方法，因此通常无需直接调用。

```typescript
await pubsub.init('workflow.events')
```

### `subscribe(topic, cb, options?)` {/* #subscribetopic-cb-options */}

订阅一个主题。设置 `options.group` 时，组内成员共享订阅并竞争接收事件；不设置 group 时，该实例通过自己的订阅接收每个事件。

```typescript
await pubsub.subscribe('workflow.events', (event, ack, nack) => {
  console.log(event)
})
```

### `flush()` {/* #flush */}

等待尚未完成的消息确认。

```typescript
await pubsub.flush()
```

### `destroy(topicName)` {/* #destroytopicname */}

删除指定主题名称对应的订阅和主题，用于清理 Google Cloud 资源。

```typescript
await pubsub.destroy('workflow.events')
```

## 消息确认 {/* #acknowledgment */}

每个传递的事件都包含 `ack` 和 `nack` 函数。处理成功后调用 `ack`，可从订阅中移除该事件。如果两者都未调用，Google Cloud 会在确认期限到期后重新传递事件。
