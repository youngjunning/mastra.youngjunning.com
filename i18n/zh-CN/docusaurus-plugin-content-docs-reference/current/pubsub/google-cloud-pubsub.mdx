# 谷歌云PubSub

`GoogleCloudPubSub`是一个[`PubSub`](/reference/pubsub/base)实施支持[谷歌云发布/订阅](https://cloud.google.com/pubsub/docs)。它使用 Google Cloud 主题和订阅跨进程和主机传送事件，并提供有序传送和消息确认。

将其用于 Google Cloud 上的分布式部署。对于单进程交付，请使用[`EventEmitterPubSub`](/reference/pubsub/event-emitter). For Redis, use [`RedisStreamsPubSub`](/reference/pubsub/redis-streams).

每个主题都映射到一个 Google Cloud 主题。与群组的订阅共享一个订阅。成员们参加活动。没有组的订阅会创建每个实例的订阅。每个实例都会接收每个事件。

## 安装 {/* #installation */}

```bash npm2yarn
npm install @mastra/google-cloud-pubsub
```

## 使用示例 {/* #usage-example */}

传递 Google Cloud 客户端配置，例如项目 ID。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { GoogleCloudPubSub } from '@mastra/google-cloud-pubsub'

export const mastra = new Mastra({
  pubsub: new GoogleCloudPubSub({
    projectId: 'my-project',
  }),
})
```

## 方法 {/* #methods */}

`GoogleCloudPubSub`实施[`PubSub`](/reference/pubsub/base) contract. The methods below are specific to this implementation.

### `init(topicName, group?)` {/* #inittopicname-group */}

创建主题和订阅（如果尚不存在）并返回订阅。`subscribe` calls this internally, so you rarely call it directly.

```typescript
await pubsub.init('workflow.events')
```

### `subscribe(topic, cb, options?)` {/* #subscribetopic-cb-options */}

订阅主题。和`options.group`, members of the group share a subscription and compete for events. Without a group, the instance receives every event through its own subscription.

```typescript
await pubsub.subscribe('workflow.events', (event, ack, nack) => {
  console.log(event)
})
```

### `flush()` {/* #flush */}

等待待处理的确认完成。

```typescript
await pubsub.flush()
```

### `destroy(topicName)` {/* #destroytopicname */}

删除主题名称的订阅和主题。使用它来清理 Google Cloud 资源。

```typescript
await pubsub.destroy('workflow.events')
```

## 致谢 {/* #acknowledgment */}

每个交付的事件包括`ack` and `nack` functions. Call `ack` after successful processing to remove the event from the subscription. When neither is called, Google Cloud redelivers the event after its acknowledgment deadline expires.
