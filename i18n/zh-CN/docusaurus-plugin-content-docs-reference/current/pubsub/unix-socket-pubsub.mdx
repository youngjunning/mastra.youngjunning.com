# UnixSocketPubSub

`UnixSocketPubSub` 是一种 [`PubSub`](/reference/pubsub/base) 实现，通过 Unix 域套接字在同一主机的多个进程间传递事件。它会选出一个进程作为代理，其他进程作为客户端连接。代理退出后，其余客户端会自动选出新代理。

多个本地进程需要共享流时可使用它，例如在 Mastra Code 终端界面中协调跨进程的线程流。单进程事件传递可使用 [`EventEmitterPubSub`](/reference/pubsub/event-emitter)；跨主机的分布式事件传递可使用 [`RedisStreamsPubSub`](/reference/pubsub/redis-streams) 或 [`GoogleCloudPubSub`](/reference/pubsub/google-cloud-pubsub)。

`UnixSocketPubSub` 采用推送式传输：事件无需读取循环即可到达，因此 Mastra 不会为它运行拉取工作进程。

## 使用示例 {/* #usage-example */}

传入所有参与进程共用的套接字路径。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { UnixSocketPubSub } from '@mastra/core/events'

export const mastra = new Mastra({
  pubsub: new UnixSocketPubSub('/tmp/mastra/events.sock'),
})
```

## 方法 {/* #methods */}

`UnixSocketPubSub` 实现了 [`PubSub`](/reference/pubsub/base) 契约。以下方法是此实现特有的。

### `close()` {/* #close */}

关闭套接字连接；如果此实例是代理，还会释放代理角色。应在优雅关闭时调用。`close()` 最多等待一秒，让此前已开始的租约释放操作完成。若操作在此后仍因其他进程持有锁而受阻，则会以 `UnixSocketPubSub is closed` 错误拒绝；在 `close()` 之后启动的租约操作会抛出错误。

```typescript
await pubsub.close()
```

## 代理选举 {/* #broker-election */}

第一个将自身套接字链接到共享路径的进程会成为代理。它在所有已连接客户端之间路由事件，其他进程作为客户端连接到它。每个候选进程先以私有名称绑定套接字，再将其硬链接到共享路径。如果该路径已有套接字，硬链接会失败，避免候选进程意外替换正在运行的代理。

代理正常退出时会移除共享路径。随后客户端重新连接，第一个成功将自身套接字链接到该路径的客户端成为新代理，其余客户端则重新向它订阅。

连接被拒绝不会立即触发接管。客户端会先进行退避重试；只有套接字持续拒绝连接时，客户端才会取得独占文件锁并替换该套接字。代理仅在共享路径仍指向自身套接字时才会移除它。如果代理发现该路径已被删除或替换，就会卸任并以客户端身份重新加入。因此，即使进程一度连接到不同套接字，最终仍会收敛到同一个代理，而不会持续分裂。
