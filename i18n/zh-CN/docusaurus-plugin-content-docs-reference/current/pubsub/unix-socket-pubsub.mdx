# UnixSocketPubSub

`UnixSocketPubSub`是一个[`PubSub`](/reference/pubsub/base)使用 Unix 域套接字在单个主机上跨进程传递事件的实现。它选择一个进程作为Agent，其他进程作为客户端连接到它。如果经纪人退出，剩余的客户端会自动选择新的经纪人。

当多个本地进程需要共享流时使用它，例如跨 Mastra Code 终端接口协调线程流。对于单进程交付，请使用[`EventEmitterPubSub`](/reference/pubsub/event-emitter). For distributed delivery across hosts, use [`RedisStreamsPubSub`](/reference/pubsub/redis-streams) or [`GoogleCloudPubSub`](/reference/pubsub/google-cloud-pubsub).

`UnixSocketPubSub`是推送传输：事件到达时没有读取循环，因此 Mastra 不会为其运行拉取工作程序。

## 使用示例 {/* #usage-example */}

传递每个参与进程共享的套接字路径。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { UnixSocketPubSub } from '@mastra/core/events'

export const mastra = new Mastra({
  pubsub: new UnixSocketPubSub('/tmp/mastra/events.sock'),
})
```

## 方法 {/* #methods */}

`UnixSocketPubSub`实施[`PubSub`](/reference/pubsub/base) contract. The method below is specific to this implementation.

### `close()` {/* #close */}

关闭套接字连接，并且当该实例是Agent时，释放Agent角色。在正常关闭期间调用此方法。`close()` waits up to one second for lease releases that started before it. A release still blocked on another process's lock after that rejects with `UnixSocketPubSub is closed`. Lease operations started after `close()` throw.

```typescript
await pubsub.close()
```

## 经纪商选举 {/* #broker-election */}

Agent是第一个将其套接字链接到共享路径的进程。它在所有连接的客户端之间路由事件，并且其他进程作为客户端连接到它。每个候选者都以私有名称绑定一个套接字，并将其硬链接到共享路径。如果套接字已经存在，则链接会失败，从而防止候选者意外替换活动Agent。

当Agent完全退出时，它会删除共享路径。然后客户端重新连接，第一个将其套接字链接到位的客户端将成为新的Agent。其余客户重新订阅它。

被拒绝的连接本身不会触发接管。客户端首先进行退避重试。仅当套接字不断拒绝连接时，客户端才会获取独占锁定文件并替换它。仅当共享路径仍指向其自己的套接字时，Agent才会删除该共享路径。如果Agent发现其路径被删除或替换，它将退出并作为客户端重新加入。因此，最终位于不同套接字上的进程会再次汇聚到一个Agent上，而不是保持分裂状态。
