# 凭据（）

获取平台连接的原始凭证，用于生成的Tool集未涵盖的自定义交互，例如您自己驱动Provider SDK 或 MCP 服务器。

```typescript
import { credential } from '@mastra/connect'

const cred = await credential('c_yourconnectionid')

if (cred.type === 'oauth2') {
  startSdkSession(cred.accessToken)
} else if (cred.type === 'api_key') {
  startSdkSession(cred.apiKey)
} else if (cred.type === 'two_step') {
  startSdkSession(cred.token)
}
```

返回：`Promise<ConnectionCredential>`, a discriminated union:

```typescript
type ConnectionCredential =
  | {
      type: 'oauth2'
      accessToken: string
      expiresAt: string | null
      secondaryAccessTokens?: Record<string, { accessToken: string; expiresAt: string | null }>
    }
  | { type: 'api_key'; apiKey: string }
  | { type: 'two_step'; token: string; expiresAt: string | null }
```

OAuth2 凭证可以包括`secondaryAccessTokens` for additional API audiences, keyed by the provider's connection-config field name. Each token has its own expiry.

大多数应用程序应该更喜欢[`tools()`](/reference/connect/tools), which keeps credentials entirely on the platform.

## 凭证处理 {/* #credential-handling */}

返回的凭据授予对Provider帐户的直接访问权限并绕过Agent的护栏。不要记录它们或将它们嵌入Agent输出中。 OAuth2 和`two_step` tokens can expire. Check their `expiresAt` fields, including those of secondary access tokens, and re-fetch the credential when needed.

使用此函数不支持的凭据类型的连接（例如基本身份验证）会抛出异常`unsupported_credential_type`.

## 错误 {/* #errors */}

投掷`MastraConnectError` with a `code` property:

|代码|当 |
| - | - |
|`invalid_options` | An option is invalid, for example an empty `resourceId` or one longer than 256 characters after trimming |
| `missing_access_token` | No platform token configured |
| `connection_not_found` | The connection doesn't exist or isn't accessible |
| `unsupported_credential_type` | The connection's credential type can't be returned |
| `unauthorized`|平台拒绝代币 (401/403) |
|`platform_error`|任何其他平台响应失败：非 2xx 状态或无法解析的正文。网络级获取失败不会被包装并显示为运行时自身的错误，而不会出现`code` |
