# credential()

获取平台连接的原始凭据，以便执行生成的工具集未覆盖的自定义操作，例如自行调用 Provider SDK 或 MCP 服务器。

```typescript
import { credential } from '@mastra/connect'

const cred = await credential('c_yourconnectionid')

if (cred.type === 'oauth2') {
  startSdkSession(cred.accessToken)
} else if (cred.type === 'api_key') {
  startSdkSession(cred.apiKey)
} else if (cred.type === 'two_step') {
  startSdkSession(cred.token)
}
```

返回 `Promise<ConnectionCredential>`，其值为可辨识联合类型：

```typescript
type ConnectionCredential =
  | {
      type: 'oauth2'
      accessToken: string
      expiresAt: string | null
      secondaryAccessTokens?: Record<string, { accessToken: string; expiresAt: string | null }>
    }
  | { type: 'api_key'; apiKey: string }
  | { type: 'two_step'; token: string; expiresAt: string | null }
```

OAuth2 凭据可能包含 `secondaryAccessTokens`，供其他 API 受众使用。各项以 Provider 连接配置中的字段名为键，且每个令牌都有独立的过期时间。

多数应用应优先使用 [`tools()`](/reference/connect/tools)，这样凭据会始终保留在平台上。

## 凭证处理 {/* #credential-handling */}

返回的凭据可直接访问 Provider 账户，并绕过代理的防护机制。不要记录凭据，也不要将其写入 Agent 输出。OAuth2 和 `two_step` 令牌可能过期；请检查各自的 `expiresAt`，包括次级访问令牌的过期时间，并在需要时重新获取凭据。

如果连接使用此函数不支持的凭据类型（例如基本身份验证），会抛出 `unsupported_credential_type`。

## 错误 {/* #errors */}

抛出 `MastraConnectError`，并带有 `code` 属性：

| 代码 | 触发条件 |
| - | - |
| `invalid_options` | 选项无效，例如 `resourceId` 为空，或去除首尾空白后超过 256 个字符 |
| `missing_access_token` | 未配置平台令牌 |
| `connection_not_found` | 连接不存在或无权访问 |
| `unsupported_credential_type` | 无法返回该连接的凭据类型 |
| `unauthorized` | 平台拒绝令牌（401/403） |
| `platform_error` | 其他平台响应失败：状态码非 2xx，或响应体无法解析。网络层面的 fetch 失败不会被包装，而是作为运行时自身的错误抛出，且不带 `code` |
