Neon 汇集了多个 Provider 的模型，并提供限流和故障转移等功能。你可以通过 Mastra 的模型路由器访问其中的 58 个模型。

详情请参阅 [Neon 文档](https://neon.com/docs)。

## 用法 {/* #usage */}

```typescript title="src/mastra/agents/my-agent.ts"
import { Agent } from "@mastra/core/agent";

const agent = new Agent({
  id: "my-agent",
  name: "My Agent",
  instructions: "You are a helpful assistant",
  model: "neon/claude-fable-5"
});
```

:::note

Mastra 使用兼容 OpenAI 的 `/chat/completions` 接口。部分 Provider 专有功能可能无法使用，详情请查阅 [Neon 文档](https://neon.com/docs)。

:::
