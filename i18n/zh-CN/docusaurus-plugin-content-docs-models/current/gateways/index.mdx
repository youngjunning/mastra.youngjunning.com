# Gateway Provider

Gateway Provider 汇集多个模型 Provider，并提供缓存、限流、分析和自动故障转移等功能。如果你需要可观测性、成本管理，或希望用同一种方式访问多个 Provider，可以使用网关。

## 自定义网关 {/* #custom-gateways */}

如果需要接入私有 LLM 部署或特定 Provider，可以创建自定义网关。实现方式见[自定义网关](/models/gateways/custom-gateways)。

## 需要手动注册的网关 {/* #gateways-you-register-yourself */}

这些网关默认不会注册。请将它们传入 `new Mastra({ gateways })`。只有注册在该 Mastra 实例上的 Agent 才能解析这些网关的模型 ID。

* [Azure OpenAI](/models/gateways/azure-openai)：通过 `AzureOpenAIGateway` 注册私有 Azure OpenAI 部署
