# 网关Provider

网关Provider聚合了多个模型Provider，并添加了缓存、速率限制、分析和自动故障转移等功能。当您需要可观察性、成本管理或简化的多Provider访问时，请使用网关。

## 自定义网关 {/* #custom-gateways */}

为私人 LLM 部署或专业Provider集成创建自定义网关。看[Custom Gateways](/models/gateways/custom-gateways) for implementation details.

## 您自己注册的网关 {/* #gateways-you-register-yourself */}

默认情况下，这些网关未注册。将它们传递给`new Mastra({ gateways })`. Their model IDs only resolve for agents registered on that instance.

* [Azure 开放人工智能](/models/gateways/azure-openai)：私有 Azure OpenAI 部署，已注册`AzureOpenAIGateway`
