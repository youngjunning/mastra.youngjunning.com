AI SDK 支持 Ollama。安装相应的 Provider 软件包，即可在 Mastra 中调用其模型。

有关此 Provider 的详细说明，请参阅 [AI SDK Ollama Provider 文档](https://ai-sdk.dev/providers/community-providers/ollama)。

Ollama 未接入模型路由器，因此无法解析 `ollama/<model>` 这类模型字符串。请将 `ollama-ai-provider-v2` 提供的模型实例传给 Agent 的 `model` 选项。

如需在 Mastra Agent 中使用此 Provider，请参阅[Agent 概览文档](/docs/agents/overview)。
