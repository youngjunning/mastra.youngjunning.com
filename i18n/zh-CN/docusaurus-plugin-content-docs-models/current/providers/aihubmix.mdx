有关此 Provider 的详细说明，请参阅 [AI SDK AIHubMix Provider 文档](https://ai-sdk.dev/providers/community-providers/aihubmix)。

AIHubMix isn't a model router provider, so model strings like `aihubmix/<model>` don't resolve. Pass a model instance from `@aihubmix/ai-sdk-provider` to the agent's `model` option instead.

如需在 Mastra Agent 中使用此 Provider，请参阅[Agent 概览文档](/docs/agents/overview)。
