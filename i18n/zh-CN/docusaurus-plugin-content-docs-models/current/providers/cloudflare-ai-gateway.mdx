Cloudflare AI Gateway 可通过 AI SDK 使用。安装相应的 Provider package 后，即可在 Mastra 中使用其模型。

有关此 Provider 的详细说明，请参阅 [AI SDK Cloudflare AI Gateway Provider 文档](https://ai-sdk.dev/providers/community-providers/cloudflare-ai-gateway)。

Cloudflare AI Gateway isn't a model router provider, so model strings like `cloudflare-ai-gateway/<model>` don't resolve. Pass a model instance from `ai-gateway-provider` to the agent's `model` option instead.

如需在 Mastra Agent 中使用此 Provider，请参阅[Agent 概览文档](/docs/agents/overview)。
