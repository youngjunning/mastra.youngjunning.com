QVAC 可通过 AI SDK 使用。安装相应的 Provider package 后，即可在 Mastra 中使用其模型。

有关此 Provider 的详细说明，请参阅 [AI SDK QVAC Provider 文档](https://ai-sdk.dev/providers/community-providers/qvac)。

QVAC isn't a model router provider, so model strings like `qvac/<model>` don't resolve. Pass a model instance from `@qvac/ai-sdk-provider` to the agent's `model` option instead.

如需在 Mastra Agent 中使用此 Provider，请参阅[Agent 概览文档](/docs/agents/overview)。
