# <img src="https://models.dev/logos/azure.svg" alt="Azure 标志" className="inline w-8 h-8 mr-2 align-middle dark:invert dark:brightness-0 dark:contrast-200" />Azure

AI SDK 支持 Azure。安装相应的 Provider 软件包，即可在 Mastra 中调用其模型。

有关此 Provider 的详细说明，请参阅 [AI SDK Azure Provider 文档](https://ai-sdk.dev/providers/ai-sdk-providers/azure)。

Azure 未接入模型路由器，因此无法解析 `azure/<model>` 这类模型字符串。请将 `@ai-sdk/azure` 提供的模型实例传给 Agent 的 `model` 选项。

部分接入路由器的 Provider 提供托管在 Azure 上的模型，例如 [LLM Gateway](/models/providers/llmgateway-providers) 的 `llmgateway-providers/azure/gpt-5.4`、[Eden AI](/models/providers/edenai) 的 `edenai/azure/gpt-4.1-nano`。请使用 Provider 列出的完整 ID。省略前缀会导致剩下的 `azure/...` 无法解析。要通过模型路由器调用自己的 Azure OpenAI 部署，请注册 [Azure OpenAI Gateway](/models/gateways/azure-openai)。

如需在 Mastra Agent 中使用此 Provider，请参阅[Agent 概览文档](/docs/agents/overview)。
