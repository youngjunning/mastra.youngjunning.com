# 連接

透過連接，Mastra 可以使用遠端 Agent、編碼 Agent、供應商的軟件開發套件（SDK）執行環境，以及外部 Tool 和資源。請按負責管理 Agent 執行環境的系統，以及需要交換的內容，選擇連接類型。

- [**模型上下文協議（MCP）**](/docs/connections/mcp)：讓 Agent 接駁外部 Tool 和資源，或向兼容 MCP 的系統提供 Mastra Agent、Tool、Workflow、提示及資源。
- [**Agent 對 Agent（A2A）**](/docs/connections/a2a)：跨服務、框架、供應商和語言提供或使用遠端 Agent。
- [**Agent 客戶端協議（ACP）**](/docs/connections/acp)：執行 Claude Code、Cline 或 OpenCode 等兼容的編碼 Agent 程序，作為 Mastra Tool 或子 Agent。
- [**SDK Agent**](/docs/connections/sdk-agents)：註冊以 Claude、Cursor 或 OpenAI SDK 運作的 Agent，執行環境、Tool、權限和 Agent 循環仍由供應商的 SDK 控制。

## 何時使用連接 {/* #when-to-use-connections */}

以下情況可使用連接：

- 將工作交由其他服務或執行環境中的 Agent 處理。
- 在項目的 Workspace 執行編碼 Agent。
- 加入供應商的原生 Agent，同時沿用其 SDK 執行環境和 Agent 循環。
- 將 Agent 接駁至外部 Tool 和資源，或向其他系統提供 Mastra 功能。

## 開始使用 {/* #get-started */}

按接駁對象選擇連接類型。遠端 Agent 端點用 [A2A](/docs/connections/a2a)，編碼 Agent 程序用 [ACP](/docs/connections/acp)，由供應商管理的執行環境用 [SDK Agent](/docs/connections/sdk-agents)，Tool 和資源則用 [MCP](/docs/connections/mcp)。

<Tabs>
  <TabItem value="a2a" label="A2A">
    ```typescript
    import { A2AAgent } from '@mastra/core/a2a'

    const agent = new A2AAgent({
      url: 'https://agent.example.com/.well-known/agent-card.json',
    })

    const result = await agent.generate('Summarize the latest report')
    console.log(result.text)
    ```
  </TabItem>

  <TabItem value="acp" label="ACP">
    ```typescript
    import { AcpAgent } from '@mastra/acp'

    const agent = new AcpAgent({
      id: 'coding-agent',
      description: 'Inspects and edits code',
      command: 'claude',
      args: ['--acp'],
      persistSession: false,
    })

    const result = await agent.generate('Review this project')
    console.log(result.text)
    ```
  </TabItem>

  <TabItem value="sdk-agents" label="SDK agents">
    ```typescript
    import { OpenAISDKAgent } from '@mastra/openai'

    const agent = new OpenAISDKAgent({
      id: 'openai-agent',
      description: 'Answers project questions',
      sdkOptions: {
        name: 'Project assistant',
        model: '__AI_SDK_OPENAI_MODEL_BASE__',
      },
    })

    const result = await agent.generate('Explain agent loops in one sentence')
    console.log(result.text)
    ```
  </TabItem>

  <TabItem value="mcp" label="MCP">
    ```typescript
    import { MCPClient } from '@mastra/mcp'

    const client = new MCPClient({
      id: 'wikipedia-client',
      servers: {
        wikipedia: {
          command: 'npx',
          args: ['-y', 'wikipedia-mcp'],
        },
      },
    })

    try {
      const tools = await client.listTools()
      console.log(Object.keys(tools))
    } finally {
      await client.disconnect()
    }
    ```
  </TabItem>
