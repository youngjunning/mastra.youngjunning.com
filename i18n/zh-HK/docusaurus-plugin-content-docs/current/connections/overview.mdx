# 連接

連線使 Mastra 能夠與遠端Agent、編碼Agent、提供者軟體開發Tool包 (SDK) 運行時以及外部Tool和資源配合使用。根據擁有Agent程式運行時的系統以及您需要交換的內容來選擇連線類型。

* [**模型上下文協定 (MCP)**](/docs/connections/mcp)：將Agent連接到外部Tool和資源，或將 Mastra Agent、Tool、Workflow、提示和資源公開給 MCP 相容系統。
* [**Agent對Agent (A2A)**](/docs/connections/a2a)：跨服務、框架、Provider和語言邊界公開或使用遠端Agent。
* [**Agent客戶端協定 (ACP)**](/docs/connections/acp)：運行相容的編碼Agent程式，例如 Claude Code、Cline 或 OpenCode，作為 Mastra Tool或子Agent程式。
* [**SDKAgent**](/docs/connections/sdk-agents)：註冊 Claude、Cursor 或 OpenAI SDK 支援的Agent，而提供者 SDK 保留對執行時間、Tool、權限和Agent循環的控制。

## 何時使用連接 {/* #when-to-use-connections */}

當您需要執行以下操作時使用連接：

* 將工作委託給在另一個服務或運行時中運行的Agent程式。
* 針對專案Workspace運行編碼Agent程式。
* 新增提供者本機Agent，無需取代其 SDK 執行時間或Agent循環。
* 將Agent連接到外部Tool和資源或將 Mastra 功能發佈到其他系統。

## 開始使用 {/* #get-started */}

從你需要跨越的邊界開始。使用[A2A](/docs/connections/a2a) for remote agent endpoints, [ACP](/docs/connections/acp) for coding-agent processes, [SDK agents](/docs/connections/sdk-agents) for provider-owned runtimes, or [MCP](/docs/connections/mcp) for tools and resources.

<Tabs>
  <TabItem value="a2a" label="A2A">
    ```typescript
    import { A2AAgent } from '@mastra/core/a2a'

    const agent = new A2AAgent({
      url: 'https://agent.example.com/.well-known/agent-card.json',
    })

    const result = await agent.generate('Summarize the latest report')
    console.log(result.text)
    ```
  </TabItem>

  <TabItem value="acp" label="ACP">
    ```typescript
    import { AcpAgent } from '@mastra/acp'

    const agent = new AcpAgent({
      id: 'coding-agent',
      description: 'Inspects and edits code',
      command: 'claude',
      args: ['--acp'],
      persistSession: false,
    })

    const result = await agent.generate('Review this project')
    console.log(result.text)
    ```
  </TabItem>

  <TabItem value="sdk-agents" label="SDK agents">
    ```typescript
    import { OpenAISDKAgent } from '@mastra/openai'

    const agent = new OpenAISDKAgent({
      id: 'openai-agent',
      description: 'Answers project questions',
      sdkOptions: {
        name: 'Project assistant',
        model: '__AI_SDK_OPENAI_MODEL_BASE__',
      },
    })

    const result = await agent.generate('Explain agent loops in one sentence')
    console.log(result.text)
    ```
  </TabItem>

  <TabItem value="mcp" label="MCP">
    ```typescript
    import { MCPClient } from '@mastra/mcp'

    const client = new MCPClient({
      id: 'wikipedia-client',
      servers: {
        wikipedia: {
          command: 'npx',
          args: ['-y', 'wikipedia-mcp'],
        },
      },
    })

    try {
      const tools = await client.listTools()
      console.log(Object.keys(tools))
    } finally {
      await client.disconnect()
    }
    ```
  </TabItem>
