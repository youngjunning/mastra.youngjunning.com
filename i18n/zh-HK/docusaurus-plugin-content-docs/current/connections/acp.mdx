# Agent Client Protocol

Mastra Agent 可透過 [Agent Client Protocol (ACP)](https://agentclientprotocol.com/overview/introduction) 執行兼容 ACP 的編程 Agent。使用 `@mastra/acp`，即可將其程序包裝成 Mastra Tool 或子 Agent。

ACP 適用於 Claude Code、Cline、OpenCode、Amp、Codex 等編程 Agent，以及任何透過標準輸入和輸出實作 ACP 的可執行檔。

## 何時使用 ACP {/* #when-to-use-acp */}

- Mastra Agent 需要把檢查程式碼、編輯或操作儲存庫的工作交給外部編程 Agent。
- 兼容 ACP 的 Agent 程序需要在多次呼叫之間保持運行，以保留會話的上下文。
- 上層 Agent 需要在工作執行期間即時取得編程 Agent 的輸出。
- 兼容 ACP 的 Agent 需要在讀寫檔案或執行操作前提示授權。
- 檔案存取需要經 Mastra 的 Workspace 抽象層處理，而非交由程序直接存取。

## ACP 的工作原理 {/* #how-acp-works */}

`@mastra/acp` 會以子程序執行指定的 ACP Agent 指令，並透過標準輸入及輸出交換以換行符號分隔的 JSON。

運作流程如下：

1. 指定 `command`、`args`，並按需要設定連線。
2. 首次使用時，`@mastra/acp` 會啟動 ACP Agent 程序。
3. 客戶端發出 ACP 的 `initialize` 和 `session/new` 請求。
4. Mastra 以 `session/prompt` 將用戶的任務交給 ACP Agent。
5. ACP Agent 透過串流將會話更新及訊息片段傳回 Mastra。
6. Mastra 傳回緩衝的輸出、送出串流片段，或處理權限選擇。
7. 如果 `persistSession` 為 `false`，ACP 連線會在處理完提示後停止程序。`AcpAgent` 預設可讓程序跨多次呼叫繼續運行，方便重用。

ACP 客戶端在執行期間亦會處理權限請求和檔案操作。Agent 經協議提出的檔案讀寫請求會交由 Mastra 的 `Workspace` 處理。Workspace 只涵蓋這類請求：Agent 程序在指定的 `cwd` 下運行，沒有沙箱或其他隔離，仍可利用本身的工具和 Shell 指令存取檔案。

## 兼容的 Agent {/* #compatible-agents */}

任何透過標準輸入和輸出實作 ACP 的可執行檔，都可配合 `@mastra/acp` 使用，毋須為每個 Agent 準備專用的 Mastra 套件。安裝 Agent 後，以 `command` 和 `args` 指定啟動指令。

| Agent | `command` | `args` |
| - | - | - |
| Cline | `cline` | `['--acp']` |
| OpenCode | `opencode` | `['acp']` |
| Gemini CLI | `gemini` | `['--acp']` |

每個 Agent 的文件會介紹其 ACP 模式，啟動選項亦可能因版本而異。請查閱 [Cline ACP](https://docs.cline.bot/usage/acp) 或 [OpenCode ACP](https://opencode.ai/docs/acp/) 等文件，確認現行指令。

## 入門 {/* #getting-started */}

請在已使用 `@mastra/core` 的項目安裝 `@mastra/acp`。套件需要 `@mastra/core` `1.34.0` 或更新版本。

```bash npm2yarn
npm install @mastra/acp
```

`@mastra/acp` 匯出兩個 API：

- [`createACPTool()`](/reference/acp/create-acp-tool)：建立 Mastra Tool，向 ACP Agent 傳送 `task` 字串，並傳回 `output` 字串。
- [`AcpAgent`](/reference/acp/acp-agent)：把 ACP Agent 包裝成 Mastra 子 Agent，支援 `generate()` 和 `stream()`。

## 以 ACP 接入子 Agent {/* #use-acp-as-a-subagent */}

若要讓上層 Mastra Agent 直接委派工作給兼容 ACP 的編程子 Agent，請使用 `AcpAgent`。

```typescript title="src/mastra/agents/code-supervisor.ts"
import { AcpAgent } from '@mastra/acp'
import { Agent } from '@mastra/core/agent'

const codeAgent = new AcpAgent({
  id: 'code-agent',
  name: 'Code Agent',
  description: 'An ACP-compatible coding agent that can inspect and edit files',
  command: 'opencode',
  args: ['acp'],
  cwd: process.cwd(),
})

export const codeSupervisor = new Agent({
  id: 'code-supervisor',
  name: 'Code Supervisor',
  instructions: 'Delegate code editing tasks to the code-agent subagent.',
  model: '__GATEWAY_OPENAI_MODEL__',
  agents: {
    codeAgent,
  },
})
```

所有選項、方法和設定請參閱 [AcpAgent 參考文件](/reference/acp/acp-agent)。

## 以 ACP 接入 Tool {/* #use-acp-as-a-tool */}

若由上層 Mastra Agent 決定何時將 ACP Agent 當作 Tool 呼叫，請用 `createACPTool()`。

```typescript title="src/mastra/agents/code-supervisor.ts"
import { createACPTool } from '@mastra/acp'
import { Agent } from '@mastra/core/agent'

const codeAgentTool = createACPTool({
  id: 'code-agent',
  description: 'Use an ACP-compatible coding agent to inspect and edit code',
  command: 'opencode',
  args: ['acp'],
  cwd: process.cwd(),
})

export const codeSupervisor = new Agent({
  id: 'code-supervisor',
  name: 'Code Supervisor',
  instructions: 'Use the code-agent tool when a task requires repository inspection or code edits.',
  model: '__GATEWAY_OPENAI_MODEL__',
  tools: {
    codeAgentTool,
  },
})
```

所有選項和設定請參閱 [createACPTool() 參考文件](/reference/acp/create-acp-tool)。

## 選擇模型 {/* #model-selection */}

ACP Agent 可以提供模型選項。在 ACP 設定中指定 `model`，即可在建立會話後選擇模型；亦可在執行期間以 `AcpAgent.getAvailableModels()` 和 `AcpAgent.setModel()` 管理模型。

例子請參閱 [AcpAgent 的模型管理方法](/reference/acp/acp-agent#model-management)。

## 會話生命週期 {/* #session-lifecycle */}

`AcpAgent` 首次使用時會執行指定的指令並建立 ACP 會話。`persistSession` 預設為 `true`，子程序在多次呼叫之間仍會運行。如要每次提示使用獨立程序，請設為 `persistSession: false`。

詳情請參閱 [AcpAgent 會話生命週期](/reference/acp/acp-agent#session-lifecycle)。

## 權限處理 {/* #permission-handling */}

ACP Agent 可能要求客戶端先選取權限選項，然後才繼續。`@mastra/acp` 預設採用 ACP Agent 傳回的第一個選項。需要自訂權限處理時，請傳入 `onPermissionRequest`。

完整例子請參閱 [createACPTool() 的權限處理](/reference/acp/create-acp-tool#permission-handling)。

## 整合 Workspace {/* #workspace-integration */}

ACP 檔案請求會經 Mastra 的 Workspace 抽象層處理。`AcpAgent` 可使用 `workspace` 選項；若 Tool 的執行上下文有目前的 Mastra Workspace，`createACPTool()` 便會採用它。如沒有 Workspace，`@mastra/acp` 會改用以 `LocalFilesystem` 為後端的 `Workspace`，位置為 `cwd` 或 `process.cwd()`。

自訂 Workspace 的例子請參閱 [AcpAgent 的 Workspace 整合](/reference/acp/acp-agent#workspace-integration)。
