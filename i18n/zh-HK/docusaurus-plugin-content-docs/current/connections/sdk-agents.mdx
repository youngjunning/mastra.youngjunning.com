# SDK Agent

SDK Agent 讓你在 Mastra 使用其他 Agent SDK 框架。你可在 Mastra 專案註冊由 SDK 驅動的 Agent，由提供者的 SDK 繼續管理本身的執行環境、Tool、權限及 Agent 迴圈。

## 何時使用 SDK Agent {/* #when-to-use-sdk-agents */}

- 供應商 SDK 已管理 Agent 迴圈、Tool、權限或本機執行環境。
- 你想在 Mastra 專案註冊由該 SDK 驅動的 Agent。
- 你需要與 Mastra 相容的 `generate()` 及 `stream()` 輸出。
- 你想在 Mastra 的可觀測性功能查看 SDK 執行的用量、成本及 Tool 活動。

## 支援的 SDK Agent {/* #supported-sdk-agents */}

- [Claude Agent SDK](#claude-agent-sdk)：以 `@mastra/claude` 註冊 Claude SDK Agent，並透過 Mastra 的 `generate()` 及 `stream()` 調用。
- [Cursor Agent SDK](#cursor-agent-sdk)：以 `@mastra/cursor` 註冊 Cursor SDK Agent，並透過 Mastra 的 `generate()` 及 `stream()` 調用。
- [OpenAI Agents SDK](#openai-agents-sdk)：以 `@mastra/openai` 註冊 OpenAI SDK Agent，並透過 Mastra 的 `generate()` 及 `stream()` 調用。

Cline 及 OpenCode 等沒有專用 Mastra 套件的編程 Agent，會經 [Agent Client Protocol](/docs/connections/acp) 執行。

## Claude Agent SDK {/* #claude-agent-sdk */}

使用 `@mastra/claude` 設定 Claude Code 的執行環境、權限、Tool 及 Agent 迴圈行為。

### 安裝 Claude 相關套件 {/* #install-claude-packages */}

安裝 Mastra 套件及其同儕依賴 Claude Agent SDK：

```bash npm2yarn
npm install @mastra/claude @anthropic-ai/claude-agent-sdk zod
```

設定 Claude SDK 憑證：

```bash
export ANTHROPIC_API_KEY="..."
```

### 建立 Claude SDK Agent {/* #create-a-claude-sdk-agent */}

在 `sdkOptions` 設定 Claude Agent SDK。

```typescript title="src/mastra/agents/claude-sdk-agent.ts"
import { ClaudeSDKAgent } from '@mastra/claude'

export const claudeSDKAgent = new ClaudeSDKAgent({
  id: 'claude-sdk-agent',
  name: 'Claude SDK Agent',
  description: 'Use Claude Agent SDK through Mastra.',
  sdkOptions: {
    model: '__AI_SDK_ANTHROPIC_MODEL_SONNET__',
    cwd: process.cwd(),
  },
})
```

### 加入 Claude SDK Tool {/* #add-claude-sdk-tools */}

Claude Agent SDK 經 Claude SDK 的 Model Context Protocol（MCP）伺服器提供自訂 Tool。`ClaudeSDKAgent` 不接受 Mastra 的 `tools` 選項。由於 Claude SDK 管理 Agent 迴圈，以 Mastra 的 `createTool()` 建立的 Tool 不會自動提供給它，而 Mastra Tool 亦不能直接傳入 `createSdkMcpServer()`。

使用 Claude Agent SDK 的輔助函數 `tool()` 建立 Tool，加入伺服器後，再經 `sdkOptions.mcpServers` 傳入該伺服器。輔助函數接收原始 Zod shape（毋須用 `z.object()` 包裹）和一個傳回 MCP 內容的處理函數。以下例子會傳回溫度樣本數據：

```typescript title="src/mastra/agents/claude-sdk-agent.ts"
import { createSdkMcpServer, tool } from '@anthropic-ai/claude-agent-sdk'
import { ClaudeSDKAgent } from '@mastra/claude'
import { z } from 'zod'

const getTemperature = tool(
  'get_temperature',
  'Get the temperature for a city using sample data.',
  { city: z.string() },
  async ({ city }) => ({
    content: [{ type: 'text', text: `${city}: 27 C` }],
  }),
)

const weatherServer = createSdkMcpServer({
  name: 'weather',
  version: '1.0.0',
  tools: [getTemperature],
})

export const claudeSDKAgent = new ClaudeSDKAgent({
  id: 'claude-sdk-agent',
  name: 'Claude SDK Agent',
  description: 'Use Claude Agent SDK through Mastra.',
  sdkOptions: {
    model: '__AI_SDK_ANTHROPIC_MODEL_SONNET__',
    cwd: process.cwd(),
    mcpServers: {
      weather: weatherServer,
    },
    allowedTools: ['mcp__weather__get_temperature'],
  },
})
```

`allowedTools` 的值沿用 Claude Agent SDK 的 MCP Tool 命名格式 `mcp__<server name>__<tool name>`。

## Cursor Agent SDK {/* #cursor-agent-sdk */}

使用 `@mastra/cursor` 在 Mastra 註冊 Cursor SDK Agent，並在 Cursor SDK 選項保留 Cursor 專用設定。

### 安裝 Cursor 相關套件 {/* #install-cursor-packages */}

安裝 Mastra 套件及其同儕依賴 Cursor SDK：

```bash npm2yarn
npm install @mastra/cursor @cursor/sdk
```

設定 Cursor SDK 憑證：

```bash
export CURSOR_API_KEY="..."
```

### 建立 Cursor SDK Agent {/* #create-a-cursor-sdk-agent */}

在 `sdkOptions` 設定 Cursor Agent SDK。

```typescript title="src/mastra/agents/cursor-sdk-agent.ts"
import { CursorSDKAgent } from '@mastra/cursor'

export const cursorSDKAgent = new CursorSDKAgent({
  id: 'cursor-sdk-agent',
  name: 'Cursor SDK Agent',
  description: 'Use Cursor Agent SDK through Mastra.',
  sdkOptions: {
    apiKey: process.env.CURSOR_API_KEY,
    model: {
      id: '__AI_SDK_OPENAI_MODEL_BASE__',
    },
    local: {
      cwd: process.cwd(),
    },
  },
})
```

Cursor 本機 Agent 須明確指定模型，請在 `sdkOptions.model` 設定。

### 使用已有的 Cursor SDK Agent {/* #use-an-existing-cursor-sdk-agent */}

如應用程式已建立 Cursor SDK Agent，可直接將它傳給 `CursorSDKAgent`：

```typescript title="src/mastra/agents/cursor-sdk-agent.ts"
import { Agent as CursorAgent } from '@cursor/sdk'
import { CursorSDKAgent } from '@mastra/cursor'

const cursorAgent = CursorAgent.create({
  apiKey: process.env.CURSOR_API_KEY,
  model: {
    id: '__AI_SDK_OPENAI_MODEL_BASE__',
  },
  local: {
    cwd: process.cwd(),
  },
})

export const cursorSDKAgent = new CursorSDKAgent({
  id: 'cursor-sdk-agent',
  name: 'Cursor SDK Agent',
  description: 'Use Cursor Agent SDK through Mastra.',
  agent: cursorAgent,
})
```

### 加入 Cursor SDK Tool {/* #add-cursor-sdk-tools */}

在 Cursor SDK 選項設定 Cursor Agent SDK 的 Tool，並經 `sdkOptions.mcpServers` 傳入 Model Context Protocol（MCP）伺服器：

```typescript title="src/mastra/agents/cursor-sdk-agent.ts"
import { CursorSDKAgent } from '@mastra/cursor'
import { mcpServers } from '../mcp/cursor'

export const cursorSDKAgent = new CursorSDKAgent({
  id: 'cursor-sdk-agent',
  name: 'Cursor SDK Agent',
  description: 'Use Cursor Agent SDK through Mastra.',
  sdkOptions: {
    apiKey: process.env.CURSOR_API_KEY,
    model: {
      id: '__AI_SDK_OPENAI_MODEL_BASE__',
    },
    local: {
      cwd: process.cwd(),
    },
    mcpServers,
  },
})
```

## OpenAI Agents SDK {/* #openai-agents-sdk */}

使用 `@mastra/openai` 在 Mastra 註冊 OpenAI Agents SDK Agent，並在 OpenAI SDK 選項保留 OpenAI 專用的 Agent 設定。

### 安裝 OpenAI 相關套件 {/* #install-openai-packages */}

安裝 Mastra 套件及其同儕依賴 OpenAI Agents SDK：

```bash npm2yarn
npm install @mastra/openai @openai/agents zod
```

設定 OpenAI SDK 憑證：

```bash
export OPENAI_API_KEY="..."
```

### 建立 OpenAI SDK Agent {/* #create-an-openai-sdk-agent */}

在 `sdkOptions` 設定 OpenAI Agents SDK。`OpenAISDKAgent` 會在首次使用時建立 OpenAI SDK Agent。

```typescript title="src/mastra/agents/openai-sdk-agent.ts"
import { OpenAISDKAgent } from '@mastra/openai'

export const openaiSDKAgent = new OpenAISDKAgent({
  id: 'openai-sdk-agent',
  name: 'OpenAI SDK Agent',
  description: 'Use OpenAI Agents SDK through Mastra.',
  sdkOptions: {
    name: 'Repository assistant',
    instructions: 'Answer clearly and cite the relevant files.',
    model: '__AI_SDK_OPENAI_MODEL_BASE__',
  },
})
```

### 使用已有的 OpenAI SDK Agent {/* #use-an-existing-openai-sdk-agent */}

如應用程式已建立 OpenAI SDK Agent，可直接將它傳給 `OpenAISDKAgent`：

```typescript title="src/mastra/agents/openai-sdk-agent.ts"
import { Agent as OpenAIAgent } from '@openai/agents'
import { OpenAISDKAgent } from '@mastra/openai'

const sdkAgent = new OpenAIAgent({
  name: 'Repository assistant',
  instructions: 'Answer clearly and cite the relevant files.',
  model: '__AI_SDK_OPENAI_MODEL_BASE__',
})

export const openaiSDKAgent = new OpenAISDKAgent({
  id: 'openai-sdk-agent',
  name: 'OpenAI SDK Agent',
  description: 'Use OpenAI Agents SDK through Mastra.',
  agent: sdkAgent,
})
```

### 加入 OpenAI SDK Tool {/* #add-openai-sdk-tools */}

在 OpenAI SDK 選項設定 OpenAI Agents SDK 的 Tool。用 OpenAI SDK 建立 Tool 後，經 `sdkOptions.tools` 傳入。

```typescript title="src/mastra/agents/openai-sdk-agent.ts"
import { tool } from '@openai/agents'
import { OpenAISDKAgent } from '@mastra/openai'
import { z } from 'zod'

const getTemperature = tool({
  name: 'get_temperature',
  description: 'Get the current temperature for a city.',
  parameters: z.object({
    city: z.string(),
  }),
  execute: async ({ city }) => {
    return `${city}: 27 C`
  },
})

export const openaiSDKAgent = new OpenAISDKAgent({
  id: 'openai-sdk-agent',
  name: 'OpenAI SDK Agent',
  description: 'Use OpenAI Agents SDK through Mastra.',
  sdkOptions: {
    name: 'Weather assistant',
    model: '__AI_SDK_OPENAI_MODEL_BASE__',
    tools: [getTemperature],
  },
})
```

## 註冊 SDK Agent {/* #register-sdk-agents */}

SDK Agent 可像其他 Agent 一樣註冊到 Mastra 實例：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { claudeSDKAgent } from './agents/claude-sdk-agent'
import { cursorSDKAgent } from './agents/cursor-sdk-agent'
import { openaiSDKAgent } from './agents/openai-sdk-agent'

export const mastra = new Mastra({
  agents: {
    claudeSDKAgent,
    cursorSDKAgent,
    openaiSDKAgent,
  },
})
```

註冊後，可經 `mastra.getAgentById()` 取得並調用這些 Agent：

```typescript title="src/mastra/run-sdk-agent.ts"
import { mastra } from './index'

const agent = mastra.getAgentById('cursor-sdk-agent')
const stream = await agent.stream('Inspect this project and describe the test setup.')

for await (const chunk of stream.textStream) {
  process.stdout.write(chunk)
}
```

## 繼續 SDK 執行 {/* #resume-sdk-runs */}

SDK Agent 可使用提供者的原生接續資料，配合 Mastra 的 `resumeGenerate()` 及 `resumeStream()`。請傳入用以繼續對話的訊息及底層 SDK 採用的接續識別碼。

Claude SDK Agent 可用 `sessionId` 繼續已知的工作階段：

```typescript title="src/mastra/resume-claude.ts"
const result = await claudeSDKAgent.resumeGenerate({
  message: 'Continue the previous task.',
  sessionId: 'claude-session-id',
})

console.log(result.text)
```

OpenAI SDK Agent 可從之前的回應、對話或工作階段繼續執行：

```typescript title="src/mastra/resume-openai.ts"
const stream = await openaiSDKAgent.resumeStream({
  message: 'Continue the previous task.',
  previousResponseId: 'resp_123',
})

for await (const chunk of stream.textStream) {
  process.stdout.write(chunk)
}
```

Cursor SDK Agent 可沿用其封裝的 SDK Agent 繼續執行。如需按 ID 繼續已儲存的 Cursor SDK Agent，請在 `resumeData` 傳入 `agentId`。

## 結構化輸出 {/* #structured-output */}

Claude 及 OpenAI 的 SDK Agent 經各自提供者的原生結構化輸出 API 支援 Mastra 的 `structuredOutput`。通過驗證的值可在 `result.object` 取得。

```typescript title="src/mastra/run-openai-structured-output.ts"
import { z } from 'zod'

const result = await openaiSDKAgent.generate<{ summary: string }>('Summarize this project.', {
  structuredOutput: {
    schema: z.object({
      summary: z.string(),
    }),
  },
})

console.log(result.object.summary)
```

要求 `structuredOutput` 時，Cursor SDK Agent 會拋出明確的錯誤，因為 Cursor TypeScript SDK 未提供受 schema 約束的輸出 API。

## 可觀測性 {/* #observability */}

調用 `generate()` 及 `stream()` 時，SDK Agent 會建立 Mastra 的 Agent span 及模型 span。若供應商 SDK 有提供相關事件，Mastra 會記錄 SDK 提供的用量、Tool 活動及提供者元數據。

Claude SDK 的執行記錄可包括 Claude 結果訊息中由 SDK 估算的成本。Cursor SDK 的執行記錄載有 Cursor 互動更新內的 token 用量。OpenAI SDK 的執行記錄載有 OpenAI 執行狀態內的 token 用量。

儲存及儀表板的設定方法見[可觀測性](/docs/observability/overview)。
