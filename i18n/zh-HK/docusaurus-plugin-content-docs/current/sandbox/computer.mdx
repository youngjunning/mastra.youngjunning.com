# 桌面控制

提供桌面環境的 Sandbox 可讓 Agent 擷取畫面並控制滑鼠和鍵盤。當靜態配置的 Sandbox 支援桌面控制時，Workspace 會註冊相關 Tool。

[`DaytonaSandbox`](/integrations/sandboxes/daytona) 和 [`E2BDesktopSandbox`](/integrations/sandboxes/e2b-desktop) 支援這項功能。其他 Sandbox 後端不會註冊桌面控制 Tool。經解析器取得的 Sandbox 亦不會註冊，因為 Workspace 建立 Tool 清單時，無法檢查解析所得的 Sandbox 有哪些功能。

## 桌面控制 Tool {/* #computer-tools */}

| Tool | 功能 |
| - | - |
| `mastra_workspace_computer_screenshot` | 將桌面畫面擷取為 PNG 圖像，並以原生媒體形式傳回模型。 |
| `mastra_workspace_computer_click` | 在指定像素座標按下及放開滑鼠左鍵。 |
| `mastra_workspace_computer_double_click` | 在指定像素座標按兩下滑鼠左鍵。 |
| `mastra_workspace_computer_right_click` | 在指定像素座標按下及放開滑鼠右鍵。 |
| `mastra_workspace_computer_move_mouse` | 將游標移到指定像素座標，期間不按任何滑鼠按鍵。 |
| `mastra_workspace_computer_drag` | 在第一點按下滑鼠，拖到第二點再放開。 |
| `mastra_workspace_computer_type` | 在目前有焦點的元素輸入文字。 |
| `mastra_workspace_computer_press_key` | 按下按鍵或組合鍵，例如 `Enter` 或 `ctrl+s`。 |
| `mastra_workspace_computer_scroll` | 向上或向下捲動。 |
| `mastra_workspace_computer_get_screen_info` | 取得屏幕尺寸和游標位置。 |
| `mastra_workspace_computer_wait` | 等待介面穩定下來。 |

## 設定桌面控制 Tool {/* #configure-computer-tools */}

執行操作的 Tool 預設每次操作後都會擷取畫面。你可逐個 Tool 設定擷取畫面的方式：

```typescript title="src/mastra/workspaces.ts"
import { Workspace, WORKSPACE_TOOLS } from '@mastra/core/workspace'
import { E2BDesktopSandbox } from '@mastra/e2b-desktop'

const workspace = new Workspace({
  sandbox: new E2BDesktopSandbox(),
  tools: {
    [WORKSPACE_TOOLS.COMPUTER.CLICK]: {
      screenshotAfterAction: true,
      screenshotDelayMs: 1000,
    },
    [WORKSPACE_TOOLS.COMPUTER.TYPE]: {
      requireApproval: true,
    },
  },
})
```

跟其他 Workspace Tool 一樣，每個桌面控制 Tool 均可個別設定 `enabled` 和 `requireApproval`。
