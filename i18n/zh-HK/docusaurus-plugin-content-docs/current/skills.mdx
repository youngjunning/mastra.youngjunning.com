# Agent Skill

Skill 是教導 Agent 執行指定任務的可重用指令，並遵循 [Agent Skills 規格](https://agentskills.io)。

可在 Agent 的 `skills` 設定中直接加入 Skill，或在 [Workspace](/docs/sandbox/skills) 配置。Agent 層級的 Skill 屬於單一 Agent，毋須 Workspace 也能在程式碼中定義。Workspace 會從檔案系統找出 Skill，供使用該 Workspace 的所有 Agent 共用。本文說明如何定義及載入 Agent 層級的 Skill，並按每次請求解析。

## 適合使用 Agent 層級 Skill 的情況 {/* #when-to-use-agent-level-skills */}

以下情況可採用 Agent 層級的 Skill。

* Agent 需要獨立運作，毋須依賴 Workspace。
* Skill 在程式碼內定義，毋須從檔案系統尋找。
* 正在建立提供 Agent 功能的套件或程式庫。
* 需要按個別請求的上下文解析 Skill。

如要在整個項目中從檔案系統尋找 Skill，請使用 [Workspace Skill](/docs/sandbox/skills)。

## 快速入門 {/* #quickstart */}

以內嵌方式定義 Skill，再加入 Agent。

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { createSkill } from '@mastra/core/skills'

const codeReview = createSkill({
  name: 'code-review',
  description: 'Use when reviewing code changes.',
  instructions: `
    When reviewing code:
    1. Check for correctness and edge cases
    2. Verify style consistency
    3. Look for potential bugs
  `,
})

export const reviewer = new Agent({
  id: 'reviewer',
  model: '__GATEWAY_OPENAI_MODEL__',
  instructions: 'You are a code review assistant.',
  // highlight-next-line
  skills: [codeReview],
})
```

Agent 會自動取得 `skill`、`skill_read` 和 `skill_search` 工具，可在對話期間尋找及載入 Skill。

## 以內嵌方式定義 Skill {/* #defining-inline-skills */}

用 `createSkill()` 直接在程式碼中完整建立 Skill。

```typescript title="src/mastra/skills.ts"
import { createSkill } from '@mastra/core/skills'

export const releaseChecklist = createSkill({
  name: 'release-checklist',
  description: 'Use when preparing a release.',
  instructions: `
    ## Release Checklist
    1. Run the full test suite
    2. Update CHANGELOG.md
    3. Bump version numbers
    4. Create a git tag
  `,
  references: {
    'changelog-format.md': '# Changelog Format\nUse Keep a Changelog...',
  },
})
```

`references` 欄位可附加參考文件，讓 Agent 透過 `skill_read` 工具讀取，與檔案系統 Skill 的 `references/` 檔案用途相同。完整 API 見 [`createSkill()` 參考](/reference/agents/createSkill)。

## 按檔案系統路徑載入 Skill {/* #filesystem-path-skills */}

毋須配置 Workspace，直接指定磁碟上的 Skill 目錄即可。

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { createSkill } from '@mastra/core/skills'

export const agent = new Agent({
  id: 'my-agent',
  model: '__GATEWAY_OPENAI_MODEL__',
  skills: [
    './skills/code-review', // path to a SKILL.md directory
    './skills/testing', // another filesystem skill
    createSkill({/* ... */}), // inline skill
  ],
})
```

檔案系統路徑由 `LocalSkillSource` 處理，它會讀取符合 [Workspace Skill](/docs/sandbox/skills#skillmd-format) 格式的 `SKILL.md` 檔案。

## 動態 Skill {/* #dynamic-skills */}

傳入函數，即可按每次請求解析 Skill。

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { createSkill } from '@mastra/core/skills'

const devSkill = createSkill({
  name: 'dev-tools',
  description: 'Developer productivity tools.',
  instructions: '...',
})

const supportSkill = createSkill({
  name: 'support-guide',
  description: 'Customer support guidelines.',
  instructions: '...',
})

export const agent = new Agent({
  id: 'dynamic-agent',
  model: '__GATEWAY_OPENAI_MODEL__',
  // highlight-start
  skills: ({ requestContext }) => {
    const role = requestContext.get('userRole')
    if (role === 'developer') return [devSkill]
    return [supportSkill]
  },
  // highlight-end
})
```

解析函數接收 `{ requestContext, tracingContext }`，並傳回 `SkillInput[]` 陣列或 `Promise<SkillInput[]>`。

每個 `RequestContext` 會執行解析函數一次。Agent 執行期間，函數在 `resolve-skills` span 內運行，可像工具一樣透過 `tracingContext.currentSpan` 為自己的操作建立子 span。讀取中繼資料也會執行函數，例如呼叫 `agent.listSkills()` 或伺服器的 Agent 端點。這時沒有 span，`tracingContext.currentSpan` 為 `undefined`。請保持函數快速，並在使用 span 前檢查它是否存在。

```typescript title="src/mastra/agents/index.ts"
skills: async ({ requestContext, tracingContext }) => {
  const span = tracingContext?.currentSpan?.createChildSpan({
    type: 'generic',
    name: 'entitlements-lookup',
  })
  const skills = await fetchSkillsFor(requestContext.get('userId'))
  span?.end()
  return skills
}
```

如要在 Agent 和 Workflow 使用請求上下文，請參閱 [Request Context](/docs/server/request-context)。

## 合併 Workspace Skill {/* #merging-with-workspace-skills */}

Agent 設有 `skills`，而其 Workspace 亦配置了 Skill 時，兩組 Skill 會合併。如有同名項目，Agent 層級的 Skill 優先。

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { Workspace, LocalFilesystem } from '@mastra/core/workspace'
import { createSkill } from '@mastra/core/skills'

const workspace = new Workspace({
  filesystem: new LocalFilesystem({ basePath: './workspace' }),
  skills: ['skills'], // provides "code-review" skill
})

const customReview = createSkill({
  name: 'code-review', // same name as workspace skill
  description: 'Custom review process.',
  instructions: '...',
})

export const reviewer = new Agent({
  id: 'reviewer',
  model: '__GATEWAY_OPENAI_MODEL__',
  workspace,
  skills: [customReview], // agent-level "code-review" wins
})
```

## 在程式碼中存取 Skill {/* #programmatic-skill-access */}

在應用程式碼中可用 `agent.getSkill()` 及 `agent.listSkills()` 存取 Skill，例如在 Workflow 或 API 路由中。

```typescript title="src/routes/skills.ts"
import { reviewer } from '../mastra/agents'

// Get a specific skill by name
const skill = await reviewer.getSkill('code-review')
if (skill) {
  console.log(skill.instructions)
}

// List all available skills
const allSkills = await reviewer.listSkills()
for (const meta of allSkills) {
  console.log(`${meta.name}: ${meta.description}`)
}
```

完整 API 見 [`.getSkill()` 參考](/reference/agents/getSkill) 及 [`.listSkills()` 參考](/reference/agents/listSkills)。

## 儲存 Skill 前先驗證 {/* #validating-skills-before-saving */}

應用程式如會經工具、上載或 shell 指令寫入 `SKILL.md` 檔案，請先以 `validateSkillContent()` 驗證內容。它採用載入 Skill 時的規則，包括核對 `name` 與目錄名稱是否相符，並傳回結構化結果，不會拋出例外。

```typescript
import { validateSkillContent } from '@mastra/core/skills'

const result = validateSkillContent({ content: skillMarkdown, directoryName: 'code-review' })

if (!result.valid) {
  throw new Error(`Invalid skill:\n${result.errors.join('\n')}`)
}
// result.warnings lists non-blocking issues, such as very long instructions
```

如需驗證已解析的 frontmatter 物件，可用 `validateSkillMetadata({ metadata, directoryName })`。
