# 搜尋

Agent 可用 `knowledge_search` 尋找頁面，預設按關鍵字配對。本頁說明關鍵字搜尋如何找出頁面，以及如何加入語義搜尋。

:::alpha

Knowledge 仍處於 Alpha 階段，API 可能會隨版本更新而改變。

:::

## 搜尋如何找出頁面 {/* #how-search-finds-pages */}

`knowledge_search` 會把查詢詞與頁面名稱、描述、正文及筆記文字配對。頁面配對到的查詢詞越多，排名便越高。名稱內的配對權重高於描述，描述則高於正文。頁面的排名先於筆記。

在頁面名稱及描述加入用戶會搜尋的字詞，可讓搜尋更容易找到該頁面。完整排名次序見 [`knowledge_search`](/reference/knowledge/knowledge-tools#knowledge_search)。

搜尋只會傳回本次執行可讀取的內容。

使用 `MongoDBStore` 時，如一次執行可讀取的範圍很多，請傳入 `scope` 以維持搜尋速度。省略 `scope` 時，搜尋會先收集該次執行可讀取的所有範圍，數量越多，搜尋便越慢。

## 加入語義搜尋 {/* #add-search-by-meaning */}

傳入 `vector` 向量儲存及 `embedder`，即可按關鍵字及語義配對頁面和筆記。例如，搜尋「報銷」時，即使頁面只提及如何取回代墊的款項，沒有用上同一字詞，也能找出該頁。

```typescript title="src/mastra/knowledge.ts"
import { Knowledge, knowledgeMemoryScopes } from '@mastra/core/knowledge'
import { ModelRouterEmbeddingModel } from '@mastra/core/llm'
import { LibSQLStore, LibSQLVector } from '@mastra/libsql'

export const knowledge = new Knowledge({
  id: 'company',
  storage: new LibSQLStore({ id: 'knowledge', url: 'file:./knowledge.db' }),
  vector: new LibSQLVector({ id: 'knowledge-vector', url: 'file:./knowledge.db' }),
  embedder: new ModelRouterEmbeddingModel('__GATEWAY_OPENAI_EMBEDDING_MODEL__'),
  scopes: { ...knowledgeMemoryScopes() },
  tools: true,
})
```

兩個參數必須一併提供，亦可一併省略。[`embedderOptions`](/reference/knowledge/knowledge-class#constructor-options) 的用法與 Memory 相同。

`knowledge_search` 會按排名合併關鍵字及語義搜尋結果，因此語義接近的結果可能比名稱相符的結果更靠前。每項語義配對必須先以本次執行的權限重新讀取，才可列入結果。無法讀取的項目會被剔除，亦不佔結果名額。與 Alpha 階段的其他存取檢查一樣，這項機制並不保證能形成[隔離邊界](/docs/knowledge/scopes-and-access)。搜尋最多檢查 1,000 個語義候選項目。如果排名靠前的相近項目大多不能讀取，較後而可讀取的項目便可能被略過。

頁面及筆記會在寫入時產生嵌入向量。範圍頁面不會產生向量，但頁面上的筆記會。較長的頁面會分段產生向量，每頁在搜尋結果仍只會出現一次。大小上限見[限制](/reference/knowledge/limits)。

Knowledge 不會為現有內容補建向量。在加入 `vector` 及 `embedder` 之前寫入的頁面和筆記，只能用關鍵字找到，直至內容有變動。

如儲存已有嵌入向量，請避免改用另一個嵌入模型。Knowledge 暫未能重新產生這些向量。

- **維度不同**。搜尋會使用新索引，現有內容要待變更後才可按語義搜尋。
- **維度相同**。搜尋會繼續用舊向量與新模型產生的查詢向量比較，各頁面要待變更後，配對結果才會改善。

### 嵌入失敗時 {/* #when-embedding-fails */}

寫入頁面或筆記時，如未能產生或寫入向量，Knowledge 會分別在約半秒、2 秒及 7.5 秒後重試，以應付資料庫縮減至零後要幾秒才恢復運作的情況。如供應商將錯誤標示為不可重試，例如 API 密鑰無效，Knowledge 便不會重試。

如所有嘗試都失敗，頁面或筆記仍會成功寫入，Mastra 會記錄警告。新內容只可用關鍵字找到，已更新的內容則保留原有向量，令語義搜尋仍然配對舊內容。兩種情況都要待下次寫入有變更時才會結束。如調用 `upsertPage()` 後收到 `unchanged`，便不會寫入任何內容，也不會為頁面建立向量。

搜尋期間如嵌入模型或向量儲存出錯，搜尋會傳回關鍵字結果，並記錄警告。
