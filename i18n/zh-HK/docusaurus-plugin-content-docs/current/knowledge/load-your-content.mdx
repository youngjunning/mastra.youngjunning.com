# 載入自有內容

Agent 工作期間會寫入 Knowledge，但產品文件或公司政策等資料往往需要預先準備。你可以透過自己的伺服器程式碼，使用 [`upsertPage()`](/reference/knowledge/knowledge-class#upsertpage) 和 [`addNote()`](/reference/knowledge/knowledge-class#addnote) 預載內容。

Knowledge 目前未有匯入工具。日後計劃推出的匯入工具會讓 Knowledge 與其他系統同步。在此之前，可按以下示例透過伺服器程式碼預載內容。

:::alpha

Knowledge 目前處於 Alpha 階段，API 可能在不同版本有所變動。

:::

## 宣告內容的範圍 {/* #declare-a-scope-for-the-content */}

為預載內容指定專用的範圍類型，並訂明誰可以讀取：

```typescript title="src/mastra/knowledge.ts"
import { Knowledge, knowledgeMemoryScopes } from '@mastra/core/knowledge'
import { LibSQLStore } from '@mastra/libsql'

export const knowledge = new Knowledge({
  id: 'company',
  storage: new LibSQLStore({ id: 'knowledge', url: 'file:./knowledge.db' }),
  scopes: {
    ...knowledgeMemoryScopes(),
    'docs:$orgId': {
      description: 'Product docs',
      belongsTo: 'org:$orgId',
      access: [{ principal: 'org:$orgId', role: 'viewer' }],
    },
  },
  tools: true,
})
```

`belongsTo` 會把文件放在範圍樹的組織節點下。該組織內的 Agent 可讀取這些頁面，但不能修改。

## 寫入頁面 {/* #write-the-pages */}

將每份文件寫入該範圍內的指定路徑。例如，`guides/install` 會成為頁面 `docs:acme#guides/install`，路徑上欠缺的頁面亦會建立：

```typescript title="src/seed-docs.ts"
import { knowledge } from './mastra/knowledge'

type Doc = { slug: string; title: string; markdown: string }

export async function seedDocs(orgId: string, docs: Doc[]) {
  for (const doc of docs) {
    await knowledge.upsertPage({
      scope: `docs:${orgId}`,
      path: doc.slug,
      name: doc.title,
      body: doc.markdown,
      author: 'seed:docs',
    })
  }
}
```

執行時持有 `org:acme` 範圍的 Agent 現在可搜尋和讀取這些頁面。如已設定 `vector` 和 `embedder`，`upsertPage()` 亦會為每個頁面建立嵌入向量，供[語義搜尋](/docs/knowledge/search#add-search-by-meaning)使用。

要為頁面補充註明日期的事實或留言，可加入一則筆記。目標頁面存在後，引用 `[[docs:acme#releases/2026-12]]` 便會成為連結：

```typescript title="src/seed-docs.ts"
await knowledge.addNote({
  scope: 'docs:acme',
  path: 'guides/install',
  text: 'Node 18 support ends on [[docs:acme#releases/2026-12]].',
  when: new Date('2026-11-01'),
  author: 'seed:docs',
})
```

這些方法供可信的伺服器程式碼使用。由於方法不會檢查執行範圍或存取規則，請勿在 Agent Tool 或未設管理員級別驗證的路由呼叫。

## 保持內容同步 {/* #keep-content-in-sync */}

來源有變動時，可重新執行預載程式。`upsertPage()` 只更新有改動的頁面，略過原封未動的頁面，重跑時便毋須重寫這些頁面或重新產生嵌入向量。

每次呼叫 `addNote()` 都會加入一則新筆記。預載程式執行兩次便會留下重複筆記。請只加入一次，或以 [`updateNote()`](/reference/knowledge/knowledge-class#updatenote) 修改現有筆記。

從來源刪除的文件仍會保留在 Knowledge，請用 [`removePage()`](/reference/knowledge/knowledge-class#removepage) 移除。如頁面有子頁面，須先移除所有子頁面。
