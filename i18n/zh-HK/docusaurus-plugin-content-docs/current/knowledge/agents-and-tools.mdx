# Agent 與工具

Agent 可以用兩種方式使用 Knowledge：一是按需要調用工具，搜尋、讀取和寫入頁面；二是透過[固定上下文](/docs/knowledge/pinned-context)，讓指定頁面在每輪都納入上下文，無須調用工具。本頁說明工具的用法。你可挑選 Agent 能使用的工具，再以[範圍宣告](/docs/knowledge/scopes-and-access)定明每次調用允許執行甚麼操作。

:::alpha

Knowledge 目前屬 Alpha 階段，API 可能會在不同版本間變更。

:::

## 啟用工具 {/* #turn-on-the-tools */}

Agent 可用讀取工具瀏覽、搜尋和讀取頁面，也可用寫入工具建立和修改頁面及筆記。個別工具的說明見 [Knowledge 工具參考](/reference/knowledge/knowledge-tools)。

工具預設不會啟用。要同時啟用讀取和寫入工具，請設定 `tools: true`：

```typescript title="src/mastra/knowledge.ts"
import { Knowledge, knowledgeMemoryScopes } from '@mastra/core/knowledge'

export const knowledge = new Knowledge({
  id: 'company',
  scopes: knowledgeMemoryScopes(),
  tools: true,
})
```

如果 Agent 只根據 Knowledge 內容回答問題，例如文件問答 Agent，就只需讀取工具：

```typescript
const knowledge = new Knowledge({
  id: 'docs',
  scopes: knowledgeMemoryScopes(),
  tools: { read: true },
})
```

固定上下文功能附有固定工具。要啟用工具，請按[固定上下文](/docs/knowledge/pinned-context)的說明設定 `pinnedContext: true`。

## 為 Agent 加入工具 {/* #attach-the-tools-to-an-agent */}

把 Knowledge 實例傳入 Agent 的 `knowledge` 選項。Agent 會取得你已啟用的工具，亦會收到簡短的使用指引，所以無須在自己的指示中再介紹這些工具：

```typescript title="src/mastra/agents/support-agent.ts"
import { Agent } from '@mastra/core/agent'
import { knowledge } from '../knowledge'

export const supportAgent = new Agent({
  id: 'support-agent',
  name: 'Support agent',
  instructions: 'Help customers with their orders.',
  model: '__GATEWAY_OPENAI_MODEL__',
  knowledge,
})
```

如需更改這些指引，請參閱[工具指引](/reference/knowledge/tool-instructions)。

### 自行加入工具 {/* #add-the-tools-yourself */}

你也可把 Knowledge 工具放進 Agent 的 `tools`，與其他工具一併使用。用 [`createTools()`](/reference/knowledge/knowledge-class#createtools) 建立工具，再用 [`getInstructions()`](/reference/knowledge/knowledge-class#getinstructions) 取得指引。兩者須傳入相同的選項：

```typescript title="src/mastra/agents/docs-agent.ts"
import { Agent } from '@mastra/core/agent'
import { knowledge } from '../knowledge'

export const docsAgent = new Agent({
  id: 'docs-agent',
  name: 'Docs agent',
  instructions: `Answer from the company docs.\n\n${knowledge.getInstructions({ write: false, pinnedContext: false })}`,
  model: '__GATEWAY_OPENAI_MODEL__',
  tools: {
    ...knowledge.createTools({ write: false, pinnedContext: false }),
  },
})
```

這些選項會覆寫實例對這個 Agent 的設定。此例以 `{ write: false, pinnedContext: false }` 讓 Agent 只取得讀取工具。如果沒有指定 `pinnedContext: false`，而實例已啟用固定上下文，Agent 還會取得 `knowledge_pin`。兩種情況的權限檢查方式相同。

## 讀取頁面 {/* #read-pages */}

讀取工具讓 Agent 可以：

- 查看範圍內的內容如何組織。
- 按關鍵字搜尋頁面和筆記，亦可在[加入語義搜尋](/docs/knowledge/search#add-search-by-meaning)後按意思搜尋。
- 讀取頁面及其筆記，並讀取其他頁面上提到該頁的筆記。

較長的頁面會分段傳回。首次讀取時會顯示頁內各節的標題。接下來 Agent 可讀取所需章節、從指定行繼續，或只讀取與搜尋字詞相符的行。

若找不到相符內容，結果會說明沒有配對項目。Agent 可直接告知用戶沒有答案，避免猜測。

預設每次讀取最多傳回頁面中的 1,000 個 token。模型的上下文視窗較大時可調高上限；使用較小的模型時則可調低：

```typescript
const knowledge = new Knowledge({
  id: 'docs',
  scopes: knowledgeMemoryScopes(),
  tools: { read: { maxTokens: 3000 }, write: true },
})
```

## 寫入頁面 {/* #write-pages */}

寫入工具讓 Agent 可以：

- 建立、編輯、移動、合併或刪除頁面。
- 加入或移除筆記。筆記是頁面上有作者署名的簡短事實記錄，可連結至其他頁面，並由其[標記](/docs/knowledge/scopes-and-access#note-visibility)決定誰能看見。

Agent 會按頁面的讀者把頁面放入相應範圍。整個團隊共用的事實放在團隊範圍，個別用戶的事實則放在該用戶的 `resource:` 範圍。

如果頁面較長，Agent 只可編輯已讀取的行，不能覆寫未看過的部分。如果在 Agent 讀取這些行後有人修改了頁面，系統便會拒絕編輯。

## 權限檢查 {/* #access-checks */}

啟用工具不會授予存取權。Agent 只可使用該次執行所持有的範圍，以及規則已為該次執行指派角色的範圍，其他範圍均不可見。

每次調用工具，Knowledge 都會按該次執行在相關範圍的角色檢查權限。[角色權限表](/docs/knowledge/scopes-and-access#access-rules-and-roles)列出各角色可執行的操作。

調用被拒絕時，程式碼不會拋出錯誤；模型會在工具結果中收到拒絕訊息，可以按結果回應。
