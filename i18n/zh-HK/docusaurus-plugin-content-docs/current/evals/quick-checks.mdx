# 快速檢查

Quick Checks 是可組合的輕量評分器，用來檢查「輸出包含 X」或「Agent 調用了工具 Y」等常見條件。這些檢查無須使用 LLM，可即時完成，跟其他評分器一樣放進 `scorers: [...]` 陣列。

## 快速檢查的適用情境 {/* #when-to-use-quick-checks */}

如需快速驗證有確定結果的條件，可使用 Quick Checks：

- 檢查輸出文字有否包含指定字串
- 確認 Agent 曾否調用指定工具
- 核對工具調用次序及次數限制
- 以零成本的二元檢查決定 CI 流程能否繼續
- 結合以 LLM 為基礎的評分器，分層評估

如需作主觀或語義評估，請改用[以 LLM 為基礎的評分器](/docs/evals/built-in-scorers)。

## 快速上手 {/* #quickstart */}

```typescript title="src/evals/weather-checks.ts"
import { checks } from '@mastra/evals/checks'
import { runEvals } from '@mastra/core/evals'
import { weatherAgent } from '../agents'

const result = await runEvals({
  data: [{ input: 'What is the weather in Brooklyn?' }],
  target: weatherAgent,
  scorers: [checks.includes('Brooklyn'), checks.calledTool('get_weather'), checks.noToolErrors()],
})

console.log(result.scores)
// { 'check-includes': 1, 'check-called-tool': 1, 'check-no-tool-errors': 1 }
```

## 可用檢查項目 {/* #available-checks */}

Quick Checks 分為以下類別：

### 文字檢查 {/* #text-checks */}

以下評分器檢查 Agent 輸出的文字：

| 檢查 | 條件 | 分數 |
| - | - | - |
| `checks.includes(str)` | 輸出含有子字串 | 1 或 0 |
| `checks.excludes(str)` | 輸出沒有該子字串 | 1 或 0 |
| `checks.equals(str)` | 輸出與指定字串相同（預設不分大小寫；傳入 `{ ignoreCase: false }` 可作精確配對） | 1 或 0 |
| `checks.matches(regex)` | 輸出符合正則表達式 | 1 或 0 |
| `checks.similarity(str)` | 按 Dice 係數計算輸出與指定字串的相似度 | 0 至 1（指定 `threshold` 時為二元分數） |

### 工具調用檢查 {/* #tool-call-checks */}

以下評分器會檢查 Agent 在一次執行中如何使用工具：

| 檢查 | 條件 | 分數 |
| - | - | - |
| `checks.calledTool(name)` | 指定工具獲調用至少 N 次 | 1 或 0 |
| `checks.didNotCall(name)` | 沒有調用指定工具 | 1 或 0 |
| `checks.toolOrder([...])` | 按預期次序調用工具 | 1 或 0 |
| `checks.maxToolCalls(n)` | 所有工具的調用次數合共不超過 N 次 | 1 或 0 |
| `checks.usedNoTools()` | 沒有調用任何工具 | 1 或 0 |
| `checks.noToolErrors()` | 每次工具調用都沒有出錯 | 1 或 0 |

## 配合 LLM 評分器使用 {/* #combining-checks-with-llm-scorers */}

同一次 `runEvals` 調用可同時採用 Quick Checks 和 LLM 評分器。用 Quick Checks 驗證明確的通過條件，再以 LLM 評分器作定性評估：

```typescript title="src/evals/layered-eval.ts"
import { checks } from '@mastra/evals/checks'
import { createFaithfulnessScorer } from '@mastra/evals/scorers/prebuilt'
import { runEvals } from '@mastra/core/evals'
import { myAgent } from '../agents'

const result = await runEvals({
  data: [
    {
      input: 'What is the weather in Brooklyn?',
      context: ['Brooklyn weather data: sunny, 72°F'],
    },
  ],
  target: myAgent,
  scorers: [
    // Deterministic checks (instant, free)
    checks.includes('Brooklyn'),
    checks.calledTool('get_weather'),
    checks.excludes('error'),
    checks.noToolErrors(),

    // LLM-based scorer (semantic, costs tokens)
    createFaithfulnessScorer({ model: '__GATEWAY_OPENAI_MODEL_LUNA__' }),
  ],
})
```

## 在即時評分中加入快速檢查 {/* #using-checks-in-live-scoring */}

為 Agent 加入 Quick Checks 以持續監察：

```typescript title="src/agents/weather-agent.ts"
import { Agent } from '@mastra/core/agent'
import { checks } from '@mastra/evals/checks'

export const weatherAgent = new Agent({
  id: 'weather-agent',
  name: 'Weather Agent',
  instructions: 'Answer weather questions using the get_weather tool.',
  model: '__GATEWAY_OPENAI_MODEL__',
  tools: { get_weather: weatherTool },
  scorers: {
    noErrors: {
      scorer: checks.noToolErrors(),
      sampling: { type: 'ratio', rate: 1 },
    },
    mentionCity: {
      scorer: checks.includes('Brooklyn'),
      sampling: { type: 'ratio', rate: 0.5 },
    },
  },
})
```

## 快速檢查的運作方式 {/* #how-checks-work */}

每項檢查都是標準的 `createScorer()` 實例，設有 `preprocess` 及 `generateScore` 兩個步驟，與其他評分器採用同一套[四步流程](/docs/evals/custom-scorers#the-four-step-pipeline)：

1. **preprocess**：擷取 Agent 執行時的相關資料（文字內容、工具調用）並加以正規化。
1. **generateScore**：根據預處理結果給出分數（通常是 1 或 0）。

Quick Checks 不執行 `analyze` 和 `generateReason`，也不會調用 LLM，因而可在微秒級時間內完成。完整 API 及每項檢查的參數與選項，見[快速檢查參考](/reference/evals/checks)。
