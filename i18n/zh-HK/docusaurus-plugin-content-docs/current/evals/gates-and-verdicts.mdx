# 必達條件與評估結果

必達條件和評估結果讓 `runEvals` 區分要求的嚴格程度。用作必達條件的評分器必須取得 1.0 分，否則該次評估不能通過。可按所追蹤指標的平均分設定下限、上限或兩者。評估結果以 `passed`、`scored` 或 `failed` 表示。

## 何時使用必達條件與評估結果 {/* #when-to-use-gates-and-verdicts */}

* 在 CI 中強制執行硬性要求（例如，「Agent必須呼叫正確的Tool」）
* 追蹤具有最小閾值的品質指標（例如，「忠實度高於 0.7」）
- 毋須編寫自訂斷言，便可取得該次評估的整體結果（`passed`、`scored` 或 `failed`）。
- 將必達條件和只供追蹤的質素指標分開。

## 快速入門 {/* #quickstart */}

```typescript title="src/evals/weather-eval.ts"
import { runEvals } from '@mastra/core/evals'
import { checks } from '@mastra/evals/checks'
import { weatherAgent } from '../agents'
import { faithfulnessScorer } from '../scorers'

const result = await runEvals({
  data: [{ input: 'What is the weather in Brooklyn?' }],
  target: weatherAgent,

  // Gates: must all score 1.0 or the run fails
  gates: [checks.calledTool('get_weather'), checks.noToolErrors()],

  // Scorers: tracked with optional thresholds
  scorers: [
    { scorer: faithfulnessScorer, threshold: 0.7 },
    checks.includes('Brooklyn'), // no threshold = tracked only
  ],
})

console.log(result.verdict) // 'passed' | 'scored' | 'failed'
```

## 如何判定評估結果 {/* #how-verdicts-work */}

處理完各個資料項目後，按必達條件及閾值判定結果：

- `failed`：至少一項必達條件在各資料項目的平均分低於 1.0。
- `scored`：所有必達條件均通過，但至少一個設有閾值的評分器未達標。
- `passed`：所有必達條件均取得 1.0 分，並符合全部閾值。

如果沒有設定必達條件或設有閾值的評分器，或所設定的這些項目全部回傳 `notScorable()`（沒有數值可供判斷），就會省略評估結果欄位。兩種情況下，`runEvals` 都仍會回傳 `scores` 和 `summary`。

## 必達條件 {/* #gates */}

以 `gates` 欄位傳入的評分器會用作必達條件。處理每項資料時，必達條件先於一般評分器執行。可評分項目的平均分須達 1.0 才算通過。回傳 `notScorable()` 的項目不計入平均分；如執行期間拋出錯誤，該項計 0 分。

```typescript title="src/evals/tool-gate.ts"
import { runEvals } from '@mastra/core/evals'
import { checks } from '@mastra/evals/checks'

const result = await runEvals({
  data: [{ input: 'What is the weather?' }],
  target: weatherAgent,
  gates: [checks.calledTool('get_weather')],
  scorers: [qualityScorer],
})

// result.gateResults: [{ id: 'check-called-tool', passed: true, score: 1 }]
```

任何評分器均可作為必達條件。快速檢查只會回傳 1 或 0，尤其適合這種用法。完整參數和回傳類型見 [runEvals() 參考](/reference/evals/run-evals)。

### 只執行必達條件 {/* #gate-only-runs */}

只要指定至少一項必達條件，便可省略 `scorers`。這適用於只需判斷條件是否通過、毋須追蹤質素指標的確定性 CI 檢查。

```typescript title="src/evals/gate-only.ts"
import { runEvals } from '@mastra/core/evals'
import { checks } from '@mastra/evals/checks'

const result = await runEvals({
  data: [{ input: 'What is the weather in Brooklyn?' }],
  target: weatherAgent,
  gates: [checks.calledTool('get_weather'), checks.noToolErrors()],
})
```

至少須提供一個評分器或必達條件。若兩者均未提供，執行時會拋出錯誤。

## 閾值 {/* #thresholds */}

用 `{ scorer, threshold }` 包裝評分器，以設定達標範圍。閾值會與該評分器在已評分項目所得的平均分比較。回傳 `notScorable()` 的結果不計入平均分。

`threshold` 可用以下形式表示：

* **一個數字**：表示最低分數（等於或高於及格分數）：`{ scorer, threshold: 0.7 }`
- **包含 `min`、`max` 或兩者的物件**：用於檢查分數範圍，例如 `{ scorer, threshold: { max: 0.3 } }`。

對於分數愈高代表表現愈差的評分器（例如幻覺和有害內容評分器），可用 `max`。如要求分數在指定範圍內，可用 `{ min, max }`。

```typescript title="src/evals/threshold-example.ts"
import { runEvals } from '@mastra/core/evals'

const result = await runEvals({
  data: [{ input: 'Explain quantum computing' }],
  target: myAgent,
  scorers: [
    { scorer: faithfulnessScorer, threshold: 0.7 }, // min threshold (number shorthand)
    { scorer: hallucinationScorer, threshold: { max: 0.3 } }, // max threshold — high score = bad
    { scorer: verbosityScorer, threshold: { min: 0.3, max: 0.8 } }, // range threshold
    toneScorer, // bare scorer, no threshold — tracked only
  ],
})

// result.thresholdResults:
// [
//   { id: 'faithfulness', passed: true, averageScore: 0.85, threshold: 0.7 },
//   { id: 'hallucination', passed: true, averageScore: 0.1, threshold: { max: 0.3 } },
//   { id: 'verbosity', passed: false, averageScore: 0.9, threshold: { min: 0.3, max: 0.8 } },
// ]
```

沒有設定閾值的評分器仍會在 `result.scores` 列出，但不影響評估結果。

## 在 CI 中使用評估結果 {/* #using-verdicts-in-ci */}

CI 流程可根據整體評估結果採取相應行動：

```typescript title="src/evals/ci-check.ts"
import { runEvals } from '@mastra/core/evals'
import { checks } from '@mastra/evals/checks'

const result = await runEvals({
  data: testDataset,
  target: myAgent,
  gates: [checks.calledTool('search'), checks.noToolErrors()],
  scorers: [{ scorer: faithfulnessScorer, threshold: 0.7 }],
})

if (result.verdict === 'failed') {
  console.error(
    'Gate failures:',
    result.gateResults?.filter(g => !g.passed),
  )
  process.exit(1)
}

if (result.verdict === 'scored') {
  console.warn(
    'Threshold misses:',
    result.thresholdResults?.filter(t => !t.passed),
  )
}
```
