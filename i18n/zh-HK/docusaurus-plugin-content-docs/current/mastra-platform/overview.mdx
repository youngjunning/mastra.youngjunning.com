# Mastra Platform

[Mastra Platform](https://projects.mastra.ai) 提供三項產品，讓你部署、監察及管理以 Mastra 框架建置的 AI 應用程式。

- [**Observability**](/docs/mastra-platform/observability)。每個平台項目的基本產品，讓你搜尋不同 Mastra 項目及部署的 Trace、日誌和指標。
- [**Studio**](/docs/mastra-platform/studio)。託管的視覺化環境，讓你測試 Agent、執行 Workflow，並提供查閱 Trace 的工具。由 Studio 開始使用亦會取得 Observability。
- [**Server**](/docs/mastra-platform/server)。正式環境的部署選項，讓 Mastra 應用程式以 API 伺服器形式運行。由 Server 開始使用亦會取得 Observability。

執行 [`mastra deploy`](/docs/mastra-platform/deploy) 一個指令即可部署，亦可連結 GitHub 儲存庫，在推送時自動部署。連結儲存庫的流程見 [GitHub 整合](/docs/mastra-platform/github)。

每個項目可運行多個[**環境**](/docs/mastra-platform/environments)（例如 `production` 和 `staging`），亦可經 CLI 或項目設定佈建[**託管資料庫**](/docs/mastra-platform/database)，持久儲存應用程式資料。每個環境都配有受管理的 [**Workspace**](/docs/mastra-platform/workspaces)，毋須手動設定便可為 Agent 提供檔案系統及 Sandbox。

部署失敗或運行中的服務停止時，組織層級的[**警報**](/docs/mastra-platform/alerts)會通知團隊。你可設定涵蓋所有項目，或只涵蓋指定項目和環境，並經 Slack、電郵或 Webhook 發送通知。

[**Connect**](/docs/mastra-platform/connect) 會儲存你在 Linear、Slack 和 GitHub 等服務的帳戶，讓 Agent 將這些服務用作 Tool 或聊天渠道，毋須自行建立第三方應用程式或管理 API 密鑰。

[**Trace Intelligence**](/docs/mastra-platform/trace-intelligence) 會在 Agent 的 Trace 找出反覆出現的目標、結果、行為和情緒。目前只向指定項目開放私人測試。

## 開始使用 {/* #get-started */}

按你想達成的目標選擇起點。

- **加入託管可觀測性**。使用 [Observability](/docs/mastra-platform/observability) 收集不同項目及部署的 Trace、日誌和指標，並可搜尋這些資料。如想直接開始監察，毋須先部署 Studio 或 Server，可由此開始。
- **部署 Studio**。以 [Studio](/docs/mastra-platform/studio) 為團隊託管視覺化開發環境。如需共用介面來測試 Agent、執行 Workflow 及查閱 Trace，可由此開始。
- **部署 Server**。讓 Mastra 應用程式透過 [Server](/docs/mastra-platform/server) 以正式 API 伺服器的形式運行。如已準備好在雲端提供 Agent、Tool 和 Workflow，可由此開始。
- **建立軟件工廠**。將 [Mastra Factory](https://factory.mastra.ai) 部署至 Mastra Platform，再連結儲存庫，將 Issue 轉化成計劃、實作和經審查的 Pull Request。

## 核心概念 {/* #key-concepts */}

**項目**是各項產品共用的上層實體，單一項目可同時包含 Observability、Studio 和 Server。項目隸屬於**組織**，組織是團隊的多租戶容器。

Mastra 應用程式由三類組件組成。

- [Agent](/docs/agents/overview)。能保留上下文、依照指令操作及使用 Tool 的 AI Agent。
- [Tool](/docs/agents/tools)。供 Agent 調用的函數及整合項目。
- [Workflow](/docs/workflows/overview)。以多個步驟編排 Agent 及 Tool 的流程。

## 部署至正式環境 {/* #going-to-production */}

以 [`mastra dev`](/reference/cli/mastra#mastra-dev) 在本機開發項目，再開啟 [Studio](/docs/studio/overview)，透過視覺化介面測試 Agent、Workflow 和 Tool。

應用程式準備好上線後，執行 [`mastra deploy`](/reference/cli/mastra#mastra-deploy) 部署至雲端。

逐步操作指引見[部署文件](/docs/mastra-platform/deploy)。

即使你在自有基礎設施託管 Mastra 應用程式，仍可經 [MastraPlatformExporter](/docs/mastra-platform/observability) 將可觀測性資料傳送至 Mastra Platform。
