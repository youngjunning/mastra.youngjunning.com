# 瀏覽器

瀏覽器支援可讓Agent商導航網站、與頁面元素互動、填寫表單和提取資料。 Mastra 提供兩種瀏覽器提供者：

* **SDK提供者**包裝瀏覽器自動化庫並直接為Agent商提供瀏覽器Tool。
* **CLI 提供者**啟動Agent程式透過命令列Tool控制的瀏覽器。

Mastra 包括 3 個 SDK 提供者和 1 個 CLI 提供者：

* [**Agent瀏覽器**](/integrations/browsers/agent-browser)：基於 Playwright 建構的 SDK 提供程序，可透過輔助使用資訊找到頁面元素。將其用於一般網路自動化和抓取。
* [**舞台工作人員**](/integrations/browsers/stagehand)：基於 Browserbase 的 Stagehand 庫建構的 SDK 提供者。它使用人工智慧來尋找頁面元素。將其用於複雜的交互，其中用自然語言描述元素比固定選擇器效果更好。
* [**Firecrawl瀏覽器**](/integrations/browsers/firecrawl)：在託管 Firecrawl 瀏覽器Sandbox會話中執行 AgentBrowser Tool的 SDK 提供者。使用它可以避免在您自己的基礎設施上運行瀏覽器。
* [**瀏覽器檢視器**](/integrations/browsers/browser-viewer)：CLI Provider，啟動 Chrome 並將其 Chrome 開發Tool協定 (CDP) URL 傳遞給 CLI Tool，例如Agent瀏覽器、瀏覽器使用和瀏覽。將其用於透過 shell 命令控制瀏覽器的WorkspaceAgent程式。

## 何時使用瀏覽器 {/* #when-to-use-a-browser */}

在需要時為您的Agent提供瀏覽器：

* 瀏覽網站並與頁面元素交互
* 填寫並提交表格
* 從網頁中提取結構化數據
* 自動執行需要幾個步驟的 Web 任務
* 使用僅在真實瀏覽器中執行的頁面，例如使用 JavaScript 呈現內容或需要登入的頁面

## 它是如何運作的 {/* #how-it-works */}

當您將瀏覽器指派給Agent程式時，Mastra 會將提供者的Tool包含在Agent程式的Tool集中。Agent程式使用這些Tool來控制瀏覽器。它可以打開 URL 並選擇元素。它還可以輸入文字並閱讀頁面內容。

每個提供者都提供了一套不同的針對其方法進行最佳化的Tool。

## 快速入門 {/* #quickstart */}

安裝您選擇的提供程序，在本範例中您將使用 AgentBrowser 提供者。

```bash npm2yarn
npm install @mastra/agent-browser
```

建立一個新的瀏覽器實例：

```typescript title="src/mastra/browsers.ts"
import { AgentBrowser } from '@mastra/agent-browser'

export const browser = new AgentBrowser({
  headless: false,
})
```

將瀏覽器指派給Agent程式：

```typescript title="src/mastra/agents/web-agent.ts"
import { Agent } from '@mastra/core/agent'
import { browser } from '../browsers'

export const webAgent = new Agent({
  id: 'web-agent',
  name: 'Web Agent',
  description: 'A web automation assistant that can navigate websites and complete tasks.',
  model: '__GATEWAY_OPENAI_MODEL__',
  browser,
  instructions:
    'You are a web automation assistant. Use browser tools to navigate websites and complete tasks.',
})
```

Agent程式會自動從提供者接收所有瀏覽器Tool。

## 雲端提供者 {/* #cloud-providers */}

所有 SDK Provider都支援連接到雲端瀏覽器服務，而不是啟動本機瀏覽器。

### Firecrawl 瀏覽器沙箱（FirecrawlBrowser 原生） {/* #firecrawl-browser-sandbox-firecrawlbrowser-native */}

FirecrawlBrowser 透過 Firecrawl API 提供託管會話：

```typescript
import { FirecrawlBrowser } from '@mastra/browser-firecrawl'

const browser = new FirecrawlBrowser({
  apiKey: process.env.FIRECRAWL_API_KEY,
})
```

### Browserbase（舞台工作人員原生） {/* #browserbase-stagehand-native */}

Stagehand 具有原生 Browserbase 整合：

```typescript
import { StagehandBrowser } from '@mastra/stagehand'

const browser = new StagehandBrowser({
  env: 'BROWSERBASE',
  apiKey: process.env.BROWSERBASE_API_KEY,
  projectId: process.env.BROWSERBASE_PROJECT_ID,
})
```

### 瀏覽器使用雲端（AgentBrowser CDP） {/* #browser-use-cloud-agentbrowser-cdp */}

將 AgentBrowser 連接到[Browser Use Cloud browser](https://github.com/browser-use/browser-use/blob/main/skills/cloud/references/browser-api.md) using your Browser Use API key:

```typescript
import { AgentBrowser } from '@mastra/agent-browser'

const browser = new AgentBrowser({
  cdpUrl: `wss://connect.browser-use.com?apiKey=${process.env.BROWSER_USE_API_KEY}`,
})
```

### CDP URL（任何提供者） {/* #cdp-url-any-provider */}

連接到公開 Chrome DevTools 協定 (CDP) 端點的任何瀏覽器：

```typescript
import { AgentBrowser } from '@mastra/agent-browser'

const browser = new AgentBrowser({
  cdpUrl: process.env.BROWSER_CDP_URL,
  headless: true,
})
```

這適用於任何[CDP-compatible](https://chromedevtools.github.io/devtools-protocol/) browser service.

## 螢幕截圖影片 {/* #screencast */}

瀏覽器提供者將瀏覽器的即時視訊來源串流傳輸到 Mastra Studio UI。這使您可以即時觀看Agent與頁面的互動。

截圖影片需要 WebSocket 支援。在您的專案中安裝這些套件：

```bash npm2yarn
npm install ws @hono/node-ws
```

：：：筆記

預設不包含這些套件，因為它們與 Cloudflare Workers 等無伺服器環境不相容。如果未安裝，截圖影片將被停用，但所有其他瀏覽器功能都可以正常運作。

:::



```typescript
const browser = new AgentBrowser({
  screencast: {
    format: 'jpeg',
    quality: 80,
    maxWidth: 1280,
    maxHeight: 720,
  },
})
```

## 記錄瀏覽器會話 {/* #record-browser-sessions */}

AgentBrowser 和 StagehandBrowser 可以選擇錄製以供審閱、分享或偵錯瀏覽器運行。配置`outputDir` to add the recording tools:

```typescript title="src/mastra/browsers.ts"
import { join } from 'node:path'
import { AgentBrowser } from '@mastra/agent-browser'

export const browser = new AgentBrowser({
  recording: {
    outputDir: join(process.cwd(), 'browser-recordings'),
  },
})
```

StagehandBrowser 接受相同的`recording` option. The agent uses `browser_record` to start, check, and stop a recording, and `browser_record_caption` to label major actions. Stopping saves the video and lets the agent return its path. A custom `outputPath` can be absolute or relative to the current working directory, and must resolve to a path inside `recording.outputDir`.

錄製使用 Motion-JPEG AVI，不需要`ffmpeg`. The default maximum duration is 30 seconds, with a 120-second hard cap. The default maximum frame size is 1024 × 720, captions are limited to 80 characters, and only one recording can be active per process.
