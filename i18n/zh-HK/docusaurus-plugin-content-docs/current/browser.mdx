# 瀏覽器

Agent 可用瀏覽器瀏覽網站、操作頁面元素、填寫表格和擷取資料。Mastra 提供兩種瀏覽器 Provider：

- **SDK Provider** 封裝瀏覽器自動化程式庫，直接為 Agent 提供瀏覽器 Tool。
- **CLI Provider** 啟動瀏覽器，讓 Agent 用命令列工具控制。

Mastra 內置三種 SDK Provider 及一種 CLI Provider：

- [**AgentBrowser**](/integrations/browsers/agent-browser)：以 Playwright 建置的 SDK Provider，透過無障礙資訊尋找頁面元素，適合一般網頁自動化及資料擷取。
- [**Stagehand**](/integrations/browsers/stagehand)：採用 Browserbase 的 Stagehand 程式庫，由 AI 尋找頁面元素。若操作較複雜，用自然語言描述元素比使用固定選擇器更合適，可選用此 Provider。
- [**FirecrawlBrowser**](/integrations/browsers/firecrawl)：在託管的 Firecrawl Browser Sandbox 工作階段執行 AgentBrowser Tool，毋須在自有基礎設施執行瀏覽器。
- [**BrowserViewer**](/integrations/browsers/browser-viewer)：這個 CLI Provider 啟動 Chrome，再把 Chrome DevTools Protocol（CDP）URL 傳給 agent-browser、browser-use 或 browse 等 CLI 工具，適合用 Shell 指令控制瀏覽器的 Workspace Agent。

## 何時使用瀏覽器 {/* #when-to-use-a-browser */}

如果 Agent 需要做以下工作，可為它設定瀏覽器：

- 瀏覽網站並與頁面元素交互
- 填寫並提交表格
- 從網頁中提取結構化數據
- 自動執行需要幾個步驟的 Web 任務
- 操作只在真正的瀏覽器中才能運作的頁面，例如以 JavaScript 呈現內容或需要登入的頁面

## 它是如何運作的 {/* #how-it-works */}

為 Agent 設定瀏覽器後，Mastra 會把 Provider 的 Tool 加入 Agent 的工具集，讓它開啟 URL、選取元素、輸入文字及讀取頁面內容。

各 Provider 都有配合其操作方式的工具。

## 快速入門 {/* #quickstart */}

先安裝所選的 Provider。以下以 AgentBrowser 為例。

```bash npm2yarn
npm install @mastra/agent-browser
```

建立一個新的瀏覽器實例：

```typescript title="src/mastra/browsers.ts"
import { AgentBrowser } from '@mastra/agent-browser'

export const browser = new AgentBrowser({
  headless: false,
})
```

將瀏覽器指派給Agent程式：

```typescript title="src/mastra/agents/web-agent.ts"
import { Agent } from '@mastra/core/agent'
import { browser } from '../browsers'

export const webAgent = new Agent({
  id: 'web-agent',
  name: 'Web Agent',
  description: 'A web automation assistant that can navigate websites and complete tasks.',
  model: '__GATEWAY_OPENAI_MODEL__',
  browser,
  instructions:
    'You are a web automation assistant. Use browser tools to navigate websites and complete tasks.',
})
```

Agent 會自動取得該 Provider 的全部瀏覽器 Tool。

## 雲端瀏覽器 Provider {/* #cloud-providers */}

所有 SDK Provider 均可連接雲端瀏覽器服務，毋須啟動本機瀏覽器。

### Firecrawl Browser Sandbox（FirecrawlBrowser 原生支援） {/* #firecrawl-browser-sandbox-firecrawlbrowser-native */}

FirecrawlBrowser 透過 Firecrawl API 提供託管會話：

```typescript
import { FirecrawlBrowser } from '@mastra/browser-firecrawl'

const browser = new FirecrawlBrowser({
  apiKey: process.env.FIRECRAWL_API_KEY,
})
```

### Browserbase（Stagehand 原生支援） {/* #browserbase-stagehand-native */}

Stagehand 具有原生 Browserbase 整合：

```typescript
import { StagehandBrowser } from '@mastra/stagehand'

const browser = new StagehandBrowser({
  env: 'BROWSERBASE',
  apiKey: process.env.BROWSERBASE_API_KEY,
  projectId: process.env.BROWSERBASE_PROJECT_ID,
})
```

### Browser Use Cloud（AgentBrowser CDP） {/* #browser-use-cloud-agentbrowser-cdp */}

用 Browser Use API 金鑰將 AgentBrowser 連接至 [Browser Use Cloud 瀏覽器](https://github.com/browser-use/browser-use/blob/main/skills/cloud/references/browser-api.md)：

```typescript
import { AgentBrowser } from '@mastra/agent-browser'

const browser = new AgentBrowser({
  cdpUrl: `wss://connect.browser-use.com?apiKey=${process.env.BROWSER_USE_API_KEY}`,
})
```

### CDP URL（任何提供者） {/* #cdp-url-any-provider */}

連接到公開 Chrome DevTools 協定 (CDP) 端點的任何瀏覽器：

```typescript
import { AgentBrowser } from '@mastra/agent-browser'

const browser = new AgentBrowser({
  cdpUrl: process.env.BROWSER_CDP_URL,
  headless: true,
})
```

所有[兼容 CDP](https://chromedevtools.github.io/devtools-protocol/) 的瀏覽器服務均適用。

## 即時畫面 {/* #screencast */}

瀏覽器 Provider 會把即時畫面串流至 Mastra Studio，讓你看到 Agent 如何操作頁面。

即時畫面需要 WebSocket 支援。請在項目安裝以下套件：

```bash npm2yarn
npm install ws @hono/node-ws
```

:::note

這些套件與 Cloudflare Workers 等無伺服器環境不兼容，因此預設不包含在內。如未安裝，即時畫面會停用，其他瀏覽器功能仍可正常運作。

:::

即時畫面預設啟用，可按需要設定：

```typescript
const browser = new AgentBrowser({
  screencast: {
    format: 'jpeg',
    quality: 80,
    maxWidth: 1280,
    maxHeight: 720,
  },
})
```

## 錄製瀏覽器工作階段 {/* #record-browser-sessions */}

AgentBrowser 和 StagehandBrowser 可按需要錄影，方便重看、分享或除錯。設定 `outputDir` 即可加入錄影工具：

```typescript title="src/mastra/browsers.ts"
import { join } from 'node:path'
import { AgentBrowser } from '@mastra/agent-browser'

export const browser = new AgentBrowser({
  recording: {
    outputDir: join(process.cwd(), 'browser-recordings'),
  },
})
```

StagehandBrowser 同樣接受 `recording` 選項。Agent 透過 `browser_record` 開始錄影、查看狀態或停止錄影，並用 `browser_record_caption` 標記主要操作。停止後會儲存影片，Agent 可回傳其路徑。自訂 `outputPath` 可使用絕對路徑，也可相對於目前的工作目錄，但解析後必須位於 `recording.outputDir` 之內。

錄影採用 Motion-JPEG AVI，毋須 `ffmpeg`。預設最長 30 秒，絕對上限為 120 秒。預設最大畫面尺寸為 1024 × 720，字幕最多 80 個字元，每個程序同一時間只可進行一項錄影。
