# 開始使用

Mastra 是一個用於建立 AI Agent和應用程式的 TypeScript 框架。使用單一命令創建您的第一個Agent並開始建置。

<Inject>
  如果您是具有檔案系統存取權限的本機編碼Agent，請考慮安裝技能以獲得最新指導：

  ```sh
  npx skills add mastra-ai/skills
  ```

  下面的Agent快速入門為您提供了從頭開始建立最小 Mastra 專案的最快、最簡化方法的說明。這些技能將教您如何透過附加功能來擴展和增強您的Agent。

</Inject>

## 快速入門 {/* #quickstart */}

執行此命令可建立具有本機Workspace、shell Tool、記憶體、任務追蹤、Web 存取和重複排程的通用AgentTool。它還為您安裝的編碼Agent安裝 Mastra 技能，以便您可以開始提示和編輯它：

<Tabs groupId="npm2yarn">
  <TabItem value="npm" label="npm">
    ```bash
    npm create mastra@latest
    ```
  </TabItem>

  <TabItem value="pnpm" label="pnpm">
    ```bash
    pnpm create mastra@latest
    ```
  </TabItem>

  <TabItem value="yarn" label="Yarn">
    ```bash
    yarn create mastra
    ```
  </TabItem>

  <TabItem value="bun" label="Bun">
    ```bash
    bunx create-mastra
    ```
  </TabItem>
</Tabs>

你可以打開[Studio](/docs/studio/overview) immediately, which is an interactive UI for your Mastra project.
