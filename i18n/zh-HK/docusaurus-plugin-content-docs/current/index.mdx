# 開始使用

Mastra 是用於開發 AI Agent 和應用程式的 TypeScript 框架。只需執行一條指令，即可建立第一個 Agent 並開始開發。

<Inject>
  如果你是在本機運行且可存取檔案系統的編程 Agent，可考慮安裝 Skill，以取得最新指引：

  ```sh
  npx skills add mastra-ai/skills
  ```

  下方的 Agent 快速入門會帶你用最少步驟從零建立一個精簡的 Mastra 項目。這些 Skill 會說明如何為 Agent 擴充功能。

  <AgentQuickstart />
</Inject>

<QuickstartPrompt />

## 快速入門 {/* #quickstart */}

執行以下指令可建立通用 Agent harness，配備本機 Workspace、Shell 工具、記憶、工作追蹤、網頁存取及定期排程。指令亦會為已安裝的編程 Agent 加入 Mastra Skill，讓你開始輸入提示及編輯生成的項目：

<Tabs groupId="npm2yarn">
  <TabItem value="npm" label="npm">
    ```bash
    npm create mastra@latest
    ```
  </TabItem>

  <TabItem value="pnpm" label="pnpm">
    ```bash
    pnpm create mastra@latest
    ```
  </TabItem>

  <TabItem value="yarn" label="Yarn">
    ```bash
    yarn create mastra
    ```
  </TabItem>

  <TabItem value="bun" label="Bun">
    ```bash
    bunx create-mastra
    ```
  </TabItem>
</Tabs>

你可直接開啟 [Studio](/docs/studio/overview)，使用互動介面操作 Mastra 項目。

## 應用場景 {/* #use-cases */}

<div className="accordion-group">
  <details>
    <summary>在產品內嵌入 Agent</summary>

    在平台加入 AI 功能，讓用戶建立 Agent 或與之互動。

    採用機構：<a href="/customers/replit">Replit</a>、<a href="/customers/fireworks-xml-prompting">Fireworks</a>、<a href="/customers/medusa-ecommerce">Medusa</a>
  </details>

  <details>
    <summary>面向客戶的助手</summary>

    建立可透過聊天、WhatsApp 或語音處理查詢、安排預約、發送提醒及回答問題的 Agent。

    採用機構：<a href="/customers/vetnio">Vetnio</a>、<a href="/customers/lua-scaling">Lua</a>

    範本：<a href="/templates/docs-chatbot">文件聊天機械人</a>、<a href="/templates/customer-support-and-refund-agent">客戶支援及退款 Agent</a>
  </details>

  <details>
    <summary>軟件工廠</summary>

    協調編程 Agent 處理 Issue，交付經測試的程式碼及 Pull Request，供團隊成員在合併前審閱計劃和改動。

    Mastra 團隊亦有採用。

    可使用 <a href="https://factory.mastra.ai/">Mastra Factory</a> 入門。
  </details>

  <details>
    <summary>內部工作助手</summary>

    透過了解業務領域的 AI 加快員工處理工作，例如解答人事查詢、撰寫臨床文件、準備銷售材料或生成文件。

    採用機構：<a href="/customers/factorial">Factorial</a>、<a href="/customers/counsel-health">Counsel Health</a>、<a href="/customers/cedar">Cedar</a>、<a href="/customers/softbank">SoftBank</a>

    範本：<a href="/templates/chat-with-pdf">透過對話查詢 PDF</a>、<a href="/templates/google-sheets-analysis">Google 試算表分析</a>、<a href="/templates/organization-intelligence">組織情報</a>、<a href="/templates/company-brain-with-surrealdb">以 SurrealDB 建立企業知識庫</a>
  </details>

  <details>
    <summary>受監管的業務與後勤營運</summary>

    將出錯代價高且需要人手批核的工作自動化，例如核實身分、配對發票、比較保單及供應商盡職審查。

    範本：<a href="/templates/kyc-customer-onboarding">KYC 及客戶開戶</a>、<a href="/templates/accounts-payable-invoice-processing">應付帳款發票處理</a>、<a href="/templates/insurance-policy-checking">查核保單</a>、<a href="/templates/vendor-risk-questionnaire">供應商風險問卷</a>
  </details>

  <details>
    <summary>數據分析 Agent</summary>

    讓用戶以自然語言查詢資料庫和儀表板。Agent 會連接數據來源，傳回答案、圖表或報告。

    採用機構：<a href="/customers/index">Index</a>、<a href="/customers/plaid">PLAID Japan</a>

    範本：<a href="/templates/text-to-sql">透過對話查詢資料庫</a>、<a href="/templates/csv-to-questions">從 CSV 生成問題</a>、<a href="/templates/genui-data-explorer">GenUI 數據探索工具</a>
  </details>

  <details>
    <summary>研究與知識整理</summary>

    根據網頁、內部文件或共用知識庫回答問題，並附上可核實的引用來源。

    範本：<a href="/templates/deep-search">深入搜尋</a>、<a href="/templates/web-research-agent-with-bright-data">網上資料搜集 Agent</a>
  </details>

  <details>
    <summary>內容自動化</summary>

    為內容管理系統、知識庫或文件系統大規模生成、轉換及管理結構化內容。

    採用機構：<a href="/customers/sanity">Sanity</a>

    範本：<a href="/templates/chat-with-youtube">透過對話查詢 YouTube 影片</a>、<a href="/templates/flash-cards-from-pdf">從 PDF 製作溫習卡</a>
  </details>

  <details>
    <summary>DevOps 和工程自動化</summary>

    自動部署、排查正式環境問題、管理基礎設施，並處理輪值工作流程。

    採用機構：<a href="/customers/starsling">StarSling</a>

    範本：<a href="/templates/github-pr-code-review-agent">GitHub PR 程式碼審查</a>、<a href="/templates/browsing-agent">瀏覽器 Agent</a>、<a href="/templates/security-incident-triage-and-response">保安事故分流及應對</a>
  </details>

  <details>
    <summary>銷售及市場拓展流程</summary>

    由客戶對話整理出結構化工作，或生成投資備忘錄。亦可自動執行一連串客戶聯絡和跟進工作。

    採用機構：<a href="/customers/kestral">Kestral</a>、<a href="/customers/orange-collective-vc-operating-system">Orange Collective</a>、<a href="/customers/workos">WorkOS</a>

    範本：<a href="/templates/customer-feedback-summarization">整理客戶意見</a>、<a href="/templates/lead-qualification">評估銷售線索</a>、<a href="/templates/competitor-monitor-jev">監察競爭對手</a>
  </details>
