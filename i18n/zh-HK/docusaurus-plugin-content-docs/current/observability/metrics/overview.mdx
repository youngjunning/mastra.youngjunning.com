# 指標

當追蹤操作完成時，Mastra 會自動從跨度中匯出指標。不需要單獨的計量儀器。

馬斯特拉發出：

* **持續時間指標**用於Agent運行、Workflow、Tool、模型呼叫和處理器
* **代幣使用指標**用於模型輸入和輸出，包括提供者報告時的詳細令牌類別
* **成本估算**根據代幣使用情況、提供者、模型和模型價格計算得出[models.dev](https://models.dev) or from a [custom gateway](/models/gateways/custom-gateways#model-pricing)

指標保留追蹤關聯上下文，因此您可以透過尋找相關跨度來調查圖表中的變更。請參閱[Automatic metrics reference](/reference/observability/metrics/automatic-metrics) for metric names, labels, and cost fields.

## 何時使用指標 {/* #when-to-use-metrics */}

* 監控Agent、Tool、Workflow和模型呼叫之間的延遲
* 隨著時間的推移追蹤代幣消耗和估計成本
* 比較不同Agent或Tool的成功率和錯誤率
* 衡量提示、模型或程式碼變更的效果

## 儲存支援 {/* #storage-support */}

指標需要具有分析能力的可觀察性儲存：

* **鴨資料庫**透過`@mastra/duckdb` is recommended for local development.
* **克利克屋**透過`@mastra/clickhouse` is recommended for high-volume production workloads.
* **PostgresStoreVNext**當其可觀測域啟用時支援指標。
* **記憶體儲存**支援指標，但當進程重新啟動時其資料會遺失。
* **谷歌雲端扳手**預設情況下禁用指標。放`disableMetrics: false` only for light workloads, or route metrics to a dedicated OLAP store.

其他儲存適配器（包括 LibSQL、MSSQL 和 MongoDB）可以儲存其他Observability訊號，但不會實現指標儲存和查詢。

## 設定本地指標 {/* #set-up-local-metrics */}

安裝Observability、應用程式儲存和 DuckDB 套件：

```bash npm2yarn
npm install @mastra/observability @mastra/libsql @mastra/duckdb
```

配置將可觀察域路由到 DuckDB 的組合儲存：

```ts title="src/mastra/index.ts"
import { Mastra } from '@mastra/core/mastra'
import { LibSQLStore } from '@mastra/libsql'
import { DuckDBStore } from '@mastra/duckdb'
import { MastraCompositeStore } from '@mastra/core/storage'
import { Observability, MastraStorageExporter, SensitiveDataFilter } from '@mastra/observability'

export const mastra = new Mastra({
  storage: new MastraCompositeStore({
    id: 'composite-storage',
    default: new LibSQLStore({
      id: 'mastra-storage',
      url: 'file:./mastra.db',
    }),
    domains: {
      observability: await new DuckDBStore().getStore('observability'),
    },
  }),
  observability: new Observability({
    configs: {
      default: {
        serviceName: 'mastra',
        exporters: [new MastraStorageExporter()],
        spanOutputProcessors: [new SensitiveDataFilter()],
      },
    },
  }),
})
```

`MastraStorageExporter`將指標儲存到配置的可觀察性儲存中並使它們可供 Studio 使用。使用`MastraPlatformExporter` instead, or alongside it, to send metrics to Mastra Platform.

## 查看和查詢指標 {/* #view-and-query-metrics */}

使用[Studio observability dashboard](/docs/studio/observability) to inspect KPI cards, breakdowns, and time-series charts. For custom dashboards and analysis, use the observability store, `@mastra/client-js`, HTTP endpoints, or CLI described in the [Metric queries reference](/reference/observability/metrics/queries).

在生產中，始終在指標查詢中包含時間戳範圍。時間限制限制了掃描的數據，並允許分區後端跳過不相關的分區或區塊。
