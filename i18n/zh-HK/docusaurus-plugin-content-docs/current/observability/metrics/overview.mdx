# 指標

每項受追蹤操作完成後，Mastra 都會從 Span 自動產生指標，毋須另行加入量度程式碼。

Mastra 會提供以下指標。

- **耗時**。量度 Agent 執行、Workflow、Tool、模型調用和處理器所需的時間。
- **Token 用量**。記錄模型輸入及輸出的用量，並納入供應商有回報的 Token 分類明細。
- **估算成本**。按 Token 用量、供應商、模型，以及來自 [models.dev](https://models.dev) 或[自訂閘道](/models/gateways/custom-gateways#model-pricing)的模型價格計算。

指標會保留與 Trace 的關聯資料，方便你從圖表上的變化追查至相關 Span。[自動指標參考](/reference/observability/metrics/automatic-metrics)列出指標名稱、標籤及成本欄位。

## 指標的用途 {/* #when-to-use-metrics */}

- 監察 Agent、Tool、Workflow 及模型調用的延遲
- 追蹤 Token 消耗及估算成本隨時間的變化
- 比較各個 Agent 或 Tool 的成功率及錯誤率
- 衡量修改提示詞、模型或程式碼的影響

## 支援的儲存後端 {/* #storage-support */}

指標需要使用具備分析功能的可觀測性儲存後端。

- **DuckDB**。本機開發建議使用 `@mastra/duckdb` 接駁 DuckDB。
- **ClickHouse**。如正式環境要處理大量工作負載，建議透過 `@mastra/clickhouse` 使用。
- **PostgresStoreVNext**。啟用可觀測性領域後即可處理指標。
- **記憶體儲存**。支援指標，但程序重啟後資料便會消失。
- **Google Cloud Spanner**。預設停用指標。只有輕量工作負載才應設定 `disableMetrics: false`，亦可將指標送往專用的 OLAP 儲存後端。

LibSQL、MSSQL 及 MongoDB 等其他儲存介面卡可儲存其他可觀測性訊號，但不提供指標儲存或查詢功能。

## 在本機設定指標 {/* #set-up-local-metrics */}

安裝可觀測性、應用程式儲存及 DuckDB 套件。

```bash npm2yarn
npm install @mastra/observability @mastra/libsql @mastra/duckdb
```

設定複合儲存，將可觀測性領域的資料交由 DuckDB 處理。

```ts title="src/mastra/index.ts"
import { Mastra } from '@mastra/core/mastra'
import { LibSQLStore } from '@mastra/libsql'
import { DuckDBStore } from '@mastra/duckdb'
import { MastraCompositeStore } from '@mastra/core/storage'
import { Observability, MastraStorageExporter, SensitiveDataFilter } from '@mastra/observability'

export const mastra = new Mastra({
  storage: new MastraCompositeStore({
    id: 'composite-storage',
    default: new LibSQLStore({
      id: 'mastra-storage',
      url: 'file:./mastra.db',
    }),
    domains: {
      observability: await new DuckDBStore().getStore('observability'),
    },
  }),
  observability: new Observability({
    configs: {
      default: {
        serviceName: 'mastra',
        exporters: [new MastraStorageExporter()],
        spanOutputProcessors: [new SensitiveDataFilter()],
      },
    },
  }),
})
```

`MastraStorageExporter` 會將指標儲存至指定的可觀測性儲存後端，供 Studio 查閱。如要將指標傳送至 Mastra Platform，可改用 `MastraPlatformExporter`，亦可同時使用兩者。

## 查閱及查詢指標 {/* #view-and-query-metrics */}

在 [Studio 可觀測性儀表板](/docs/studio/observability)查閱 KPI 卡片、細項數據及時間序列圖表。如需自訂儀表板或分析指標，可按[指標查詢參考](/reference/observability/metrics/queries)使用可觀測性儲存、`@mastra/client-js`、HTTP 端點或 CLI。

在正式環境查詢指標時，務必指定時間戳記範圍。這樣可減少掃描的資料量，讓採用分區的後端略過無關的分區或資料區塊。
