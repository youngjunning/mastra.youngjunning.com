# 開發

建立 Mastra 項目後，便可開發、執行及測試 Agent。

## 在本機執行 Mastra {/* #run-mastra-locally */}

要快速查看 Agent 如何運作，可使用 [Mastra Studio](/docs/studio/overview)。在項目根目錄執行 [`mastra dev`](/reference/cli/mastra#mastra-dev)，即可啟動 Studio 和本機開發伺服器。

```bash npm2yarn
npx mastra dev
```

前往 [`http://localhost:4111`](http://localhost:4111) 開啟 Studio，就可測試 Agent 和查閱執行記錄。

開發伺服器亦提供 Agent、Tool 和 Workflow 的 API。可到 [`http://localhost:4111/api`](http://localhost:4111/api) 查看可用端點，再用 [Mastra Client](/docs/server/mastra-client) 連接前端。

開發期間，`src/mastra/` 目錄如有改動，開發伺服器便會自動重新啟動，毋須手動處理。

## 使用 AI 輔助開發 {/* #build-with-ai */}

Mastra 提供 Skill 和 CLI，協助編程 Agent 編寫高質素的 Mastra 程式碼。

### Mastra Skills {/* #mastra-skills */}

AI 模型未必熟悉最新的 Mastra API。可透過 [Mastra Skills](https://github.com/mastra-ai/skills) 為編程 Agent 提供實作指引及最佳做法，包括如何取得最新的 Mastra 文件。編程 Agent 亦可與 [Mastra Factory](https://factory.mastra.ai) 互動。

如需手動安裝 Skill，可執行：

```bash npm2yarn
npx skills add mastra-ai/skills
```

請定期更新 Skill，以取得最新指引：

```bash npm2yarn
npx skills update mastra
```

:::note

使用 [create mastra](/docs) 建立項目時，指令會自動安裝 Mastra Skills，供編程 Agent 找到並使用。

:::

### Mastra CLI {/* #mastra-cli */}

[`mastra` CLI](/reference/cli/mastra) 讓編程 Agent 測試改動、查看結果，再按結果調整。CLI 可存取 Agent、Workflow、Tool、Memory、Evals、Trace 和日誌。

例如，編程 Agent 可先執行一個 Agent，再取得 Trace 查閱結果：

```bash
npx mastra api --url http://localhost:4111 agent run agent '{"messages":"Hello"}'
npx mastra api --url http://localhost:4111 trace list
```

記得安裝 [Mastra Skills](#mastra-skills)，讓編程 Agent 掌握 CLI 的用法。

## 項目結構 {/* #project-structure */}

採用框架時，首先要考慮如何組織項目。建議把框架程式碼放在 `src/mastra/` 下，將相關元件分到各自的檔案或資料夾，再在 `src/mastra/index.ts` 統一設定和註冊。

最基本的項目結構如下：

```text
src/
  mastra/
    agents/
      agent.ts
    tools/
      tool.ts
    workflows/
      workflow.ts
    scorers/
      scorer.ts
    skills.ts
    index.ts
```

預設目錄結構及建議慣例見[項目結構參考](/reference/project-structure)。

## 以檔案定義 Agent {/* #file-based-agents */}

:::note

只有使用 `mastra dev` 或 `mastra build`，Mastra 才會按檔案自動尋找 Agent。如果應用程式直接匯入 `mastra`，包括經 Web 框架或伺服器配接器匯入，便要在程式碼中註冊 Agent，或以獨立伺服器方式執行 Mastra。

:::

:::tip[📹 觀看短片]

[如何用檔案定義第一個 Agent](https://www.youtube.com/watch?v=5Kfn-oYkJNg\&t=18s)

:::

使用以檔案定義的 Agent 時，Mastra 會在 `src/mastra/` 下支援的檔案中自動[找出](/reference/file-based-agents/config#discovery-lifecycle) Agent 和相關元件。按慣例整理檔案即可，毋須逐一匯入元件再註冊到 [`Mastra`](/reference/core/mastra-class) 實例。

檔案佈局直接呈現項目結構。你和編程 Agent 可從目錄了解各部分如何配合，毋須逐一查找程式碼中的連接方式。

你可以在整個項目使用以檔案定義的 Agent，亦可逐步採用，與程式碼定義的元件一併使用。目前仍有部分 Mastra 功能和使用情況未獲支援。

### 建立第一個 Agent {/* #create-your-first-agent */}

每個以檔案定義的 Agent 在 `src/mastra/agents/` 下各有一個目錄。要建立可執行的 Agent，加入 `config.ts` 設定模型及執行時選項，再加入 `instructions.md` 定義一直生效的提示詞：

```text
src/mastra/agents/
  writing-assistant/
    config.ts
    instructions.md
```

Agent 預設的 `id` 和 `name` 取自目錄名稱。此例中，Mastra 會將 Agent 註冊為 `writing-assistant`。

```typescript title="src/mastra/agents/writing-assistant/config.ts"
import { agentConfig } from '@mastra/core/agent'

export default agentConfig({
  model: '__GATEWAY_OPENAI_MODEL__',
})
```

```markdown title="src/mastra/agents/writing-assistant/instructions.md"
Rewrite text clearly and concisely.
```

執行 `npx mastra dev` 後開啟 Studio，選擇 `writing-assistant` 測試。

### 自動尋找檔案的方式 {/* #how-discovery-works */}

Mastra 按路徑尋找以檔案定義的功能並為它們命名。Agent 的預設 `id` 和 `name` 取自目錄名稱。例如，`tools/search_docs.ts` 會把 Tool 註冊為 `search_docs`，`skills/style-guide.md` 則把 Skill 註冊為 `style-guide`。擴充路徑見下表。

### 擴充 Agent 功能 {/* #extend-your-agent */}

要為 Agent 加入更多功能，可新增相應檔案或目錄：

| 路徑 | 提供的功能 |
| - | - |
| [`tools/<tool-name>.ts`](/reference/file-based-agents/tools) | 模型可呼叫的函數 |
| [`skills/<skill-name>.md`](/reference/file-based-agents/skills) | Agent 在適用情況下載入的詳細指引 |
| [`memory.ts`](/reference/file-based-agents/memory) | 對話記錄和工作上下文 |
| [`workspace.ts` 和 `workspace/`](/reference/file-based-agents/workspace) | 存取檔案系統及 Shell |
| [`subagents/<agent-id>/`](/reference/file-based-agents/subagents) | 可接手上層 Agent 所委派工作的專責 Agent |

把各項功能放在使用它們的 Agent 旁。開發伺服器啟動或重新啟動時，Mastra 會找出並註冊這些檔案。

完整的檔案慣例和設定選項見[以檔案定義的 Agent 參考](/reference/file-based-agents/config)。
