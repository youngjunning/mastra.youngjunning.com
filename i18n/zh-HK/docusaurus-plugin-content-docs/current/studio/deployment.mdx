# 工作室部署

Studio 是以 React 開發的單頁應用程式（SPA），在瀏覽器內運作，並連接已運作的 [Mastra 伺服器](/docs/deployment/mastra-server)。

您可以透過兩種主要方式部署 Studio：

- 使用 Mastra 平台託管的 Studio，以連結讓團隊成員存取。
- 在自有基礎設施託管 Studio，與 Mastra 伺服器一併部署，或以獨立 SPA 部署。

本文說明如何在自有基礎設施部署 Studio。實際做法視乎需求和環境，以下介紹通用原則及可選方案。

## 快速入門 {/* #quickstart */}

啟動 Studio 最簡單的方法是執行 [`mastra studio`](/reference/cli/mastra#mastra-studio) 指令。

`mastra dev` 會啟動 Studio 和開發用 API。`mastra studio` 則提供獨立的靜態介面，連接已運作的 Mastra 伺服器，因此 Studio 可以分開部署。

打開終端機並安裝`mastra` CLI globally:

```bash npm2yarn
npm install -g mastra
```

執行 `mastra studio`：

```bash
mastra studio
```

在瀏覽器前往 [localhost:3000](http://localhost:3000) 即可開啟 Studio。Studio 預設連接 `http://localhost:4111` 的 Mastra 伺服器；如伺服器未能連線，介面會顯示表格供你輸入 Mastra 實例的 URL 和 API 前綴。

這個指令透過 Node 內置的 `http` 模組和 [`serve-handler`](https://www.npmjs.com/package/serve-handler) 提供靜態檔案。

:::note

如將 Studio 託管於子路徑，例如由 Nginx 代理的 `/agents`，請在啟動 Studio 前設定 `MASTRA_STUDIO_BASE_PATH`：

```bash
MASTRA_STUDIO_BASE_PATH=/agents mastra studio
```

這會更新 HTML 基本 URL 和靜態資源路由，以便獨立 Studio 在該子路徑下正常運作。

:::

## 馬斯特拉平台 {/* #mastra-platform */}

如需使用 Mastra 平台託管 Studio，請參閱 [Mastra 平台上的 Studio](/docs/mastra-platform/studio)。

## 運行伺服器 {/* #running-a-server */}

以長期運行的程序執行 `mastra studio` 時，可採用其他 Node.js 服務的部署方式和工具，例如用 PM2 或 Docker 管理程序，或選用支援 Node.js 應用程式的雲端服務。如同其他 Web 服務，請妥善設定 CORS 並監察錯誤。

:::warning

Studio 連接 Mastra 伺服器後，即可完整存取 Agent、Workflow 和 Tool。在正式環境務必以身份驗證、VPN 等措施保護 Studio，防止未獲授權的存取。

詳情請參閱[身份驗證文件](/docs/studio/auth)。

:::

### 與 API 一併部署 {/* #alongside-your-api */}

另一做法是把 Studio 與 [Mastra 伺服器](/docs/deployment/mastra-server)放在一起，這樣只需部署及管理一個服務。

執行 `mastra build` 時加入 `--studio` 選項：

```bash
mastra build --studio
```

建置後的 Studio 資源會放在 `.mastra/output/studio` 資料夾。設定環境變數 `MASTRA_STUDIO_PATH` 後，Mastra 伺服器亦可提供 Studio 介面。

```bash
MASTRA_STUDIO_PATH=.mastra/output/studio node .mastra/output/index.mjs
```

## 使用 CDN {/* #using-a-cdn */}

### 自動部署 {/* #automatic */}

部分[雲端服務供應商](/docs/deployment/cloud-providers)提供選項，讓 Studio 與無伺服器函數一併部署。目前支援：

- [`VercelDeployer`](/reference/deployer/vercel)

### 手動部署 {/* #manual */}

Studio 介面依賴執行時設定，因此不可把建置資源直接部署至 CDN。完成額外設定後，可用這些資源建立獨立 SPA，再部署至任何靜態託管服務。

請按照以下範例使用 Vite 建立 SPA。

<Steps>
  <StepItem>
    建立一個新資料夾並初始化一個新的 Node.js 專案：

    ```bash npm2yarn
    mkdir studio-spa
    cd studio-spa
    npm init
    ```
  </StepItem>

  <StepItem>
    安裝 `vite` 及 `mastra` 作為依賴套件：

    ```bash npm2yarn
    npm install vite mastra
    ```
  </StepItem>

  <StepItem>
    在 `package.json` 加入建置指令碼：

    ```json title="package.json"
    {
      "scripts": {
        "build": "vite build"
      }
    }
    ```
  </StepItem>

  <StepItem>
    建立一個作為佔位的 `index.html` 檔案：

    ```html title="index.html"
    <!doctype html>
    <html>
      <head></head>
      <body></body>
    </html>
    ```
  </StepItem>

  <StepItem>
    建立 `vite.config.js` 檔案。這項設定會把建置完成的 Studio 資源複製到 `dist` 資料夾，並用環境變數值取代 HTML 內的所有 `%%PLACEHOLDER%%`。

    ```js title="vite.config.js"
    import { defineConfig, loadEnv } from 'vite'
    import { readFileSync, cpSync, writeFileSync } from 'node:fs'
    import { resolve, join } from 'node:path'

    const studioDir = resolve(import.meta.dirname, 'node_modules/mastra/dist/studio')

    export default defineConfig(({ mode }) => {
      const env = loadEnv(mode, process.cwd(), 'MASTRA_')

      return {
        plugins: [
          {
            name: 'mastra-studio',
            closeBundle() {
              const outDir = resolve(import.meta.dirname, 'dist')
              cpSync(studioDir, outDir, { recursive: true })

              const indexPath = join(outDir, 'index.html')
              const html = readFileSync(indexPath, 'utf-8')
              writeFileSync(
                indexPath,
                html.replaceAll(/%%(\w+)%%/g, (_, key) => env[key] ?? ''),
              )
            },
          },
        ],
        build: {
          emptyOutDir: true,
        },
      }
    })
    ```
  </StepItem>

  <StepItem>
    建立 `.env` 檔案，加入所需的環境變數。

    ```env title=".env"
    MASTRA_SERVER_HOST=localhost
    MASTRA_SERVER_PORT=4111
    MASTRA_SERVER_PROTOCOL=http
    MASTRA_API_PREFIX=/api
    MASTRA_HIDE_CLOUD_CTA=false
    MASTRA_CLOUD_API_ENDPOINT=
    MASTRA_EXPERIMENTAL_FEATURES=false
    MASTRA_TEMPLATES=false
    MASTRA_TELEMETRY_DISABLED=true
    MASTRA_REQUEST_CONTEXT_PRESETS=
    MASTRA_EXPERIMENTAL_UI=false
    MASTRA_STUDIO_BASE_PATH=
    ```
  </StepItem>

  <StepItem>
    執行建置指令碼，在 `dist` 資料夾產生靜態檔案：

    ```bash npm2yarn
    npm run build
    ```
  </StepItem>

  <StepItem>
    把託管服務的發佈目錄設為 `dist`，再進行部署。
  </StepItem>
</Steps>
