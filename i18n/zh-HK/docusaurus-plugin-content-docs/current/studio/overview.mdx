# 工作室

Studio 提供了一個互動式 UI，用於建置、測試和管理Agent程式、Workflow和Tool。開發時本地運行，添加[authentication](/docs/studio/auth)， 或者[部署它](/docs/studio/deployment)到生產，以便您的團隊可以管理Agent和監控性能，並透過內建的可觀察性獲得見解。

:::提示\[📹觀看]

手錶[Mastra Studio overview](https://youtu.be/ojGu6Bi4wYk) for a short walkthrough of building, testing, and managing agents in Studio.

:::

## 開始工作室 {/* #start-studio */}

如果您使用以下命令建立應用程式`create mastra`, start the development server using the `dev` script. You can also run it directly with `mastra dev`.

```bash npm2yarn
npm run dev
```

伺服器運行後，您可以：

* 開啟 Studio 使用者介面[`localhost:4111`](http://localhost:4111/) to interact with your agents, workflows, and tools.
* 訪問[`localhost:4111/swagger-ui`](http://localhost:4111/swagger-ui) to discover and interact with the underlying REST API.

Studio 可讓您編輯您的[agents](/docs/agents/overview), [workflows](/docs/workflows/overview), and other parts of your Mastra application in real time.

## 部署工作室 {/* #deploy-studio */}

當您準備好與團隊共用 Studio 時，您可以使用以下命令將其部署到生產環境：[Studio on Mastra platform](/docs/mastra-platform/studio) or your own infrastructure. Visit the [deployment docs](/docs/studio/deployment) to learn how.

## 基元 {/* #primitives */}

### Agent商 {/* #agents */}

直接與您的Agent聊天，切換[models](/models), and tweak settings like temperature and top-p to understand how they affect the output.

當目錄包含發布日期時，模型選擇器首先在每個提供者中顯示較新的版本。具有相同發布日期或沒有發布日期的型號均按字母順序排列。沒有日期的型號出現在帶有日期的型號之後。

將模型選擇器限制為您自己的模型[custom gateways](/models/gateways/custom-gateways), set `AUTO_BLOCK_EXTERNAL_PROVIDERS=true`. See [Showing only custom gateways in Studio](/models/gateways/custom-gateways#showing-only-custom-gateways-in-studio).

當您與Agent程式互動時，您可以遵循其推理並查看Tool呼叫輸出。您還可以[observe](#observability) traces and logs to see how responses are generated.

對於響應中的降價表，請選擇**Copy table as markdown** above the table to copy it without the surrounding message. The copied table preserves markdown formatting and includes any link and footnote definitions it uses. To download the table as CSV, open the arrow beside the copy button and select **Download CSV**. Both actions become available once the text segment containing the table finishes streaming and displaying. The agent may still be running tools or writing later segments.

CSV 匯出包含純單元格文本，包括連結標籤而不是 URL。腳註標記會被保留，但它們的定義不包含在 CSV 中。可以解釋為電子表格公式的值帶有前導撇號，因此電子表格應用程式將它們視為文字。保留普通有符號數。

您也可以附上[scorers](#scorers) to measure and compare response quality over time.

若要詢問部分回复，請選擇訊息中的文本，然後選擇**Add to chat**, or press Tab to reach it from the keyboard. Each passage you add gets a numbered comment bubble in the chat, and the message box counts them, for example **2 annotations**. Select a bubble to write a comment on that passage or remove it, or open the count to find a passage in the chat. When you send, the agent receives a numbered list of the passages, each quoted with its comment, ahead of what you type. You can also send the annotations without typing anything. A selection that spans two messages doesn't offer **Add to chat**.

您可以在Agent響應流期間在同一線程中發送後續訊息。 Studio 將訊息顯示為待處理，直到串流確認訊息，然後繼續該後續訊息下方的回應。開啟相同執行緒的其他 Studio 標籤可以觀察活動流程。

使用[Editor](/docs/studio/editor) to let non-technical team members iterate on agents and version every change, plus run experiments without redeploying.

使用[Agent Builder](https://agent-builder.mastra.ai) to create and manage fully stored agents through a separate browser-based interface.

#### 型號面板 {/* #models-panel */}

開通Agent**Models** panel to view its primary model and fallback models in priority order. For static model lists, you can reorder models, enable or disable fallbacks, and change the provider or model. The panel stays synchronized when Studio refetches the agent.

當Agent設定`editor: { model: true }`, these edits are saved through [Editor](/docs/studio/editor#decide-what-collaborators-can-edit). This requires a configured `MastraEditor` and agent storage; without either, saving fails with HTTP 500. Otherwise they change the running server's in-memory agent and are lost when the server restarts. Persistent editing for other agents is tracked in [GitHub issue #27089](https://github.com/mastra-ai/mastra/issues/27089).

函數值模型清單可能會因請求上下文而異，因此 Studio 將它們顯示為唯讀。改為在程式碼中更改動態模型清單。

### Workflow {/* #workflows */}

將您的Workflow視覺化為圖表，並使用自訂輸入逐步運行它。在執行過程中，介面會即時更新以顯示活動步驟和所採取的路徑。

Workflow追蹤顯示Tool呼叫和原始 JSON 輸出，以及任何執行錯誤。

選擇**Run options** beside the run button to set a **Resource ID** for the runs you start. Studio remembers the value per workflow, and the runs it creates are listed by `GET /api/workflows/:workflowId/runs?resourceId=...`. Leave it empty to create runs without a resource. When your server derives the resource ID from the authenticated user, that value takes precedence over the one you type.

### 處理器 {/* #processors */}

查看連接到每個Agent程式的輸入和輸出處理器。Agent程式詳細資料面板按名稱和類型列出了每個處理器，因此您可以驗證護欄和令牌限制器，並且自訂處理器在測試前是否已正確連接。

看[processors](/docs/agents/processors) and [guardrails](/docs/agents/guardrails) for configuration details.

### MCP伺服器 {/* #mcp-servers */}

列出連接到您的 Mastra 實例的 MCP 伺服器並探索其可用Tool。該列表開頭為**Mastra (built-in)**, the [built-in MCP server](/docs/server/mcp#in-studio) at `/api/mcp`, with its endpoint URL, whether it needs a token, and setup for Claude Code, Cursor, VS Code, and the MCP Inspector.

### 工作空間 {/* #workspaces */}

使用內建文件瀏覽器瀏覽AgentWorkspace文件系統中的文件。在Workspace掛載之間切換、建立目錄以及使用語法突出顯示查看文件內容。可寫入工作空間允許建立目錄和刪除檔案；只讀Workspace有相應的標籤。技能出現在文件樹中。安裝社區技能[skills.sh](https://skills.sh), update installed skills, or delete a skill folder to remove that skill.

看[workspaces](/docs/sandbox/overview) for configuration details.

### 請求上下文 {/* #request-context */}

設定透過依賴項注入流入Agent指令和Tool的運行時變數。當您的Agent定義了請求上下文時，將請求上下文編輯為 JSON 或使用架構驅動的表單`requestContextSchema`. Values persist across test chats and experiments, so you can trigger conditional flows without restarting.

看[request context](/docs/server/request-context) for configuration details.

## 評估 {/* #evaluation */}

### 得分手 {/* #scorers */}

記分員標籤顯示Agent記分員運作時的結果。當訊息通過Agent程式時，定義的記分器會非同步評估每個輸出並在此處呈現其結果。您可以了解評分員如何回應不同的互動並比較測試案例的效能，並確定需要改進的領域。

### 數據集 {/* #datasets */}

建立和管理測試案例集合以評估您的Agent和Workflow。從 CSV 或 JSON 匯入專案並定義輸入和真實模式，並固定到特定版本，以便您可以準確地重現實驗。運行實驗[scorers](/docs/evals/overview) to compare quality across prompts, models, or code changes.

看[datasets overview](/docs/evals/datasets) for the full API and versioning details.

### 實驗 {/* #experiments */}

針對Agent程式、Workflow或記分機運行資料集中的所有項目，並將結果收集到一處。選擇一個目標，可選擇附加記分器，然後觸發實驗。結果視圖顯示每個項目的輸入、輸出、狀態和個人分數細分。將兩到十個實驗與基準並排比較，以衡量提示、模型或程式碼變更的影響。

看[datasets overview](/docs/evals/datasets) for setup details.

## 設定 {/* #settings */}

配置 Studio 和 Mastra 伺服器之間的連線。設定頁麵包括：

* **Mastra 實例 URL**：Mastra 伺服器的基本 URL（例如`http://localhost:4111`).
* **API前綴**`/api`).
* **自訂標頭**：新增隨每個請求發送的鍵值對，對於身份驗證令牌或路由標頭很有用。
* **主題**

## 程式碼配置 {/* #code-configuration */}

除了[settings](#settings) UI, you can configure the local development server and Studio also through the [`server`](/reference/configuration#server-options) option in your `src/mastra/index.ts`.

預設情況下，Studio 運行於[http://localhost:4111](http://localhost:4111). You can change the [`host`](/reference/configuration#serverhost) and [`port`](/reference/configuration#serverport).

Mastra 也透過以下方式支援 HTTPS 開發[`--https`](/reference/cli/mastra#--https) flag, which automatically creates and manages certificates for your project. When you run `mastra dev --https`, a private key and certificate are generated for localhost (or your configured host). Visit the [HTTPS reference](/reference/configuration#serverhttps) to learn more.
