# 簡易認證

`SimpleAuth` 類別以簡單的權杖與用戶對應關係驗證身份。它隨 `@mastra/core/server` 提供，適用於開發、測試和基本的 API 密鑰認證。

## 適用場景 {/* #use-cases */}

- 本機開發及測試
- 基本的 API 密鑰認證
- 整合功能完整的身份供應商前製作原型
- 使用靜態權杖的內部服務

## 安裝 {/* #installation */}

`SimpleAuth` 隨 `@mastra/core` 提供，毋須安裝額外套件。

```typescript
import { SimpleAuth } from '@mastra/core/server'
```

## 使用示例 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { SimpleAuth } from '@mastra/core/server'

// Define your user type
type User = {
  id: string
  name: string
  role: 'admin' | 'user'
}

export const mastra = new Mastra({
  server: {
    auth: new SimpleAuth<User>({
      tokens: {
        'sk-admin-token-123': {
          id: 'user-1',
          name: 'Admin User',
          role: 'admin',
        },
        'sk-user-token-456': {
          id: 'user-2',
          name: 'Regular User',
          role: 'user',
        },
      },
    }),
  },
})
```

## 設定選項 {/* #configuration-options */}

| 選項 | 類型 | 必填 | 說明 |
| - | - | - | - |
| `tokens` | `Record<string, TUser>` | 是 | 權杖與用戶物件的對應表。 |
| `headers` | `string \| string[]` | 否 | 額外檢查哪些標頭含有權杖。 |
| `name` | `string` | 否 | 用於日誌記錄的認證供應商名稱。 |
| `authorizeUser` | `(user, request) => boolean \| Promise<boolean>` | 否 | 自訂授權函數。 |
| `protected` | `(RegExp \| string)[]` | 否 | 必須驗證身份的路徑。 |
| `public` | `(RegExp \| string)[]` | 否 | 毋須驗證身份的路徑。 |

### 預設檢查的標頭 {/* #default-headers */}

SimpleAuth 預設會檢查以下標頭。

- `Authorization`（`Bearer` 前綴可省略）
- `X-Playground-Access`

使用 `headers` 選項加入自訂標頭。

```typescript
new SimpleAuth({
  tokens: {/* ... */},
  headers: ['X-API-Key', 'X-Custom-Auth'],
})
```

## 發送附有認證資料的請求 {/* #making-authenticated-requests */}

在 `Authorization` 標頭內提供權杖。

```bash
curl -X POST http://localhost:4111/api/agents/myAgent/generate \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-admin-token-123" \
  -d '{"messages": "Hello"}'
```

`Bearer` 前綴亦可省略。

```bash
curl -X POST http://localhost:4111/api/agents/myAgent/generate \
  -H "Content-Type: application/json" \
  -H "Authorization: sk-admin-token-123" \
  -d '{"messages": "Hello"}'
```

## 自訂授權 {/* #custom-authorization */}

你可按角色授權，亦可加入自訂授權邏輯。

```typescript
import { SimpleAuth, getWebRequest } from '@mastra/core/server'

new SimpleAuth<User>({
  tokens: {
    'sk-admin-token': { id: '1', name: 'Admin', role: 'admin' },
    'sk-user-token': { id: '2', name: 'User', role: 'user' },
  },
  authorizeUser: (user, request) => {
    const webRequest = getWebRequest(request)
    const path = webRequest ? new URL(webRequest.url).pathname : ''

    // Only admins can access /admin routes
    if (path.includes('/admin')) {
      return user.role === 'admin'
    }
    return true
  },
})
```

## 環境變數 {/* #environment-variables */}

如要採用接近正式環境的設定，可從環境變數載入權杖。

```typescript
const tokens: Record<string, User> = {}

// Load from environment
const adminToken = process.env.ADMIN_API_KEY
if (adminToken) {
  tokens[adminToken] = { id: 'admin', name: 'Admin', role: 'admin' }
}

const userToken = process.env.USER_API_KEY
if (userToken) {
  tokens[userToken] = { id: 'user', name: 'User', role: 'user' }
}

export const mastra = new Mastra({
  server: {
    auth: new SimpleAuth({ tokens }),
  },
})
```

## 配合 `MastraClient` 使用 {/* #with-mastraclient */}

在客戶端的設定中提供權杖。

```typescript
import { MastraClient } from '@mastra/client-js'

const client = new MastraClient({
  baseUrl: 'http://localhost:4111',
  headers: {
    Authorization: 'Bearer sk-admin-token-123',
  },
})

const agent = client.getAgent('myAgent')
const response = await agent.generate('Hello')
```

## 限制 {/* #limitations */}

SimpleAuth 的設計着重簡便，無法滿足正式環境的安全要求。

- 權杖儲存在記憶體內
- 權杖沒有到期或更新機制
- 不提供密碼學驗證
- 所有權杖必須在啟動時已知

正式環境的應用程式可考慮使用 [JWT](/docs/auth/jwt)、[Clerk](/integrations/auth/clerk)、[Auth0](/integrations/auth/auth0) 或其他身份供應商。
