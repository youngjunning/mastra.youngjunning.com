# JSON Web Token

`MastraJwtAuth` 類別以 JSON Web Token（JWT）為 Mastra 提供輕量的身份驗證。它透過 `auth` 選項接入 Mastra 伺服器，並用共享密鑰驗證收到的請求。要驗證由身份提供者簽署的權杖，請使用[參考文件](/reference/auth/jwt)所述的 `jwksUri` 和 `issuer` 選項。

## 安裝 {/* #installation */}

請先安裝 `@mastra/auth` 套件，然後使用 `MastraJwtAuth` 類別。

```bash npm2yarn
npm install @mastra/auth@latest
```

## 產生 JWT {/* #creating-a-jwt */}

要通過 Mastra 伺服器的請求驗證，你需要有效的 JSON Web Token（JWT），並以 `MASTRA_JWT_SECRET` 簽署。

最簡單的方法是在 [jwt.io](https://www.jwt.io/) 產生 JWT：

1. 選擇 **JWT Encoder**。
1. 向下捲動至 **Sign JWT: Secret** 部分。
1. 輸入你的密鑰，例如 `supersecretdevkeythatishs256safe!`。
1. 按 **Generate example** 產生有效的 JWT。
1. 複製產生的權杖，並在 `.env` 檔案中將它填入 `MASTRA_JWT_TOKEN`。

## 使用示例 {/* #usage-example */}

取得 JWT 後，可按以下示例在 Mastra 伺服器設定 `MastraJwtAuth`：

```typescript {2,6-8} title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraJwtAuth } from '@mastra/auth'

export const mastra = new Mastra({
  server: {
    auth: new MastraJwtAuth({
      secret: process.env.MASTRA_JWT_SECRET,
    }),
  },
})
```

有關所有可用的設定選項，請參閱 [MastraJwtAuth](/reference/auth/jwt)。

在 [Studio](/docs/studio/overview) 開啟 **Settings**，在 **Headers** 下按 **"Add Header"**。輸入標頭名稱 `Authorization`，並將值設為 `Bearer <your-jwt>`。

## 設定 `MastraClient` {/* #configuring-mastraclient */}

啟用 `auth` 後，以 `MastraClient` 向受保護路由發送請求時，必須在 `Authorization` 標頭附上有效的 JWT：

```typescript {6} title="lib/mastra/mastra-client.ts"
import { MastraClient } from '@mastra/client-js'

export const mastraClient = new MastraClient({
  baseUrl: 'https://<mastra-api-url>',
  headers: {
    Authorization: `Bearer ${process.env.MASTRA_JWT_TOKEN}`,
  },
})
```

如需其他設定選項，請參閱 [Mastra Client SDK](/docs/server/mastra-client)。

### 發送附有驗證資料的請求 {/* #making-authenticated-requests */}

完成 `MastraClient` 設定後，你可從前端應用程式發送附有驗證資料的請求，或用 `curl` 在本機快速測試：

<Tabs>
  <TabItem value="react" label="React">
    ```tsx title="src/components/test-agent.tsx"
    import { mastraClient } from '../../lib/mastra-client'

    export const TestAgent = () => {
      async function handleClick() {
        const agent = mastraClient.getAgent('weatherAgent')

        const response = await agent.generate('Weather in London')

        console.log(response)
      }

      return <button onClick={handleClick}>Test Agent</button>
    }
    ```
  </TabItem>

  <TabItem value="curl" label="cURL">
    ```bash
    curl -X POST http://localhost:4111/api/agents/weatherAgent/generate \
      -H "Content-Type: application/json" \
      -H "Authorization: Bearer <your-jwt>" \
      -d '{
        "messages": "Weather in London"
      }'
    ```
  </TabItem>
</Tabs>
