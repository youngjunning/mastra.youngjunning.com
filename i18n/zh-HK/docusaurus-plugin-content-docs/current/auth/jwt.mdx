# JSON 網路令牌

這`MastraJwtAuth`類別使用 JSON Web 令牌 (JWT) 為 Mastra 提供輕量級身份驗證機制。它根據共享密鑰驗證傳入請求，並使用以下命令與 Mastra 伺服器集成`auth`選項。若要驗證身分提供者簽署的令牌，請使用`jwksUri`和`issuer`中描述的選項[參考](/reference/auth/jwt).

## 安裝 {/* #installation */}

在您可以使用之前`MastraJwtAuth` class you have to install the `@mastra/auth` package.

```bash npm2yarn
npm install @mastra/auth@latest
```

## 創建 JWT {/* #creating-a-jwt */}

若要驗證 Mastra 伺服器的請求，您需要使用您的簽章的有效 JSON Web 令牌 (JWT)`MASTRA_JWT_SECRET`.

產生最簡單的方法是使用[jwt.io](https://www.jwt.io/):

1. 選擇**JWT Encoder**.
2. 向下捲動到**Sign JWT: Secret** section.
3. 輸入您的秘密（例如：`supersecretdevkeythatishs256safe!`).
4. 點選**Generate example** to create a valid JWT.
5. 複製生成的token並將其設為`MASTRA_JWT_TOKEN` in your `.env` file.

## 使用範例 {/* #usage-example */}

取得產生的 JWT 並使用它進行配置`MastraJwtAuth` in your Mastra server:

```typescript {2,6-8} title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraJwtAuth } from '@mastra/auth'

export const mastra = new Mastra({
  server: {
    auth: new MastraJwtAuth({
      secret: process.env.MASTRA_JWT_SECRET,
    }),
  },
})
```

訪問[MastraJwtAuth](/reference/auth/jwt) for all available configuration options.

裡面[Studio](/docs/studio/overview), go to **Settings** and under **Headers** select the **"Add Header"** button. Enter `Authorization` as the header name and `Bearer <your-jwt>` as the value.

## 配置`MastraClient` {/* #configuring-mastraclient */}

什麼時候`auth` is enabled, requests to protected routes made with `MastraClient` must include a valid JWT in the `Authorization` header:

```typescript {6} title="lib/mastra/mastra-client.ts"
import { MastraClient } from '@mastra/client-js'

export const mastraClient = new MastraClient({
  baseUrl: 'https://<mastra-api-url>',
  headers: {
    Authorization: `Bearer ${process.env.MASTRA_JWT_TOKEN}`,
  },
})
```

訪問[Mastra Client SDK](/docs/server/mastra-client) for more configuration options.

### 發出經過身份驗證的請求 {/* #making-authenticated-requests */}

一次`MastraClient` is configured, you can send authenticated requests from your frontend application, or use `curl` for quick local testing:

<Tabs>
  <TabItem value="react" label="React">
    ```tsx title="src/components/test-agent.tsx"
    import { mastraClient } from '../../lib/mastra-client'

    export const TestAgent = () => {
      async function handleClick() {
        const agent = mastraClient.getAgent('weatherAgent')

        const response = await agent.generate('Weather in London')

        console.log(response)
      }

      return <button onClick={handleClick}>Test Agent</button>
    }
    ```
  </TabItem>

  <TabItem value="curl" label="cURL">
    ```bash
    curl -X POST http://localhost:4111/api/agents/weatherAgent/generate \
      -H "Content-Type: application/json" \
      -H "Authorization: Bearer <your-jwt>" \
      -d '{
        "messages": "Weather in London"
      }'
    ```
  </TabItem>
