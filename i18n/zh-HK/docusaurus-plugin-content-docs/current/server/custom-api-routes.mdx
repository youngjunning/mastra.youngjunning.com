# 自訂 API 路由

Mastra 預設會經伺服器公開已註冊的 Agent 和 Workflow。如需加入其他功能，可自行定義 HTTP 路由。

透過 `@mastra/core/server` 提供的輔助函數 `registerApiRoute()` 註冊路由。路由可與 `Mastra` 實例放在同一檔案，分開定義則可令設定更簡潔。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { registerApiRoute } from '@mastra/core/server'

export const mastra = new Mastra({
  server: {
    apiRoutes: [
      registerApiRoute('/my-custom-route', {
        method: 'GET',
        handler: async c => {
          const mastra = c.get('mastra')
          const agent = await mastra.getAgent('my-agent')

          return c.json({ message: 'Custom route' })
        },
      }),
    ],
  },
})
```

註冊自訂路由後，即可從伺服器的根路徑存取。例如：

```bash
curl http://localhost:4111/my-custom-route
```

每條路由的處理函數都會收到 Hono 的 `Context`。處理函數可存取 `Mastra` 實例，以取得或調用 Agent 和 Workflow。

## Schema 驗證 {/* #schema-validation */}

在 `apiRoutes` 使用 [`createRoute()`](/reference/server/create-route)，由 Zod 解析及驗證路徑參數、查詢參數和請求主體。這些 schema 亦用於推斷處理函數的參數類型，以及產生 OpenAPI 元數據。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { createRoute } from '@mastra/server/server-adapter'
import { z } from 'zod'

const createItemRoute = createRoute({
  method: 'POST',
  path: '/items',
  responseType: 'json',
  bodySchema: z.object({
    name: z.string().min(1),
  }),
  responseSchema: z.object({
    id: z.string(),
    name: z.string(),
  }),
  handler: async ({ name }) => ({
    id: crypto.randomUUID(),
    name,
  }),
})

export const mastra = new Mastra({
  server: {
    apiRoutes: [createItemRoute],
  },
})
```

驗證失敗時，Mastra 預設會傳回 `400` 回應。可透過 `onValidationError` 回調覆寫狀態碼及回應主體。通過驗證的值及 `Mastra` 伺服器的上下文會直接傳給處理函數。

## 中介軟件 {/* #middleware */}

如要為個別路由加入中介軟件，可在調用 `registerApiRoute()` 時傳入 `middleware` 陣列。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { registerApiRoute } from '@mastra/core/server'

export const mastra = new Mastra({
  server: {
    apiRoutes: [
      registerApiRoute('/my-custom-route', {
        method: 'GET',
        middleware: [
          async (c, next) => {
            console.log(`${c.req.method} ${c.req.url}`)
            await next()
          },
        ],
        handler: async c => {
          return c.json({ message: 'Custom route with middleware' })
        },
      }),
    ],
  },
})
```

## OpenAPI 文件 {/* #openapi-documentation */}

自訂路由可附上 OpenAPI 元數據，在 Swagger UI 與 Mastra 伺服器路由一併顯示。`/api/openapi.json` 提供 OpenAPI 規格，列出自訂及內置路由。請傳入 `openapi` 選項，並填寫標準的 OpenAPI 操作欄位。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { registerApiRoute } from '@mastra/core/server'
import { z } from 'zod'

export const mastra = new Mastra({
  server: {
    apiRoutes: [
      registerApiRoute('/items/:itemId', {
        method: 'GET',
        openapi: {
          summary: 'Get item by ID',
          description: 'Retrieves a single item by its unique identifier',
          tags: ['Items'],
          parameters: [
            {
              name: 'itemId',
              in: 'path',
              required: true,
              description: 'The item ID',
              schema: { type: 'string' },
            },
          ],
          responses: {
            200: {
              description: 'Item found',
              content: {
                'application/json': {
                  schema: {
                    type: 'object',
                    properties: {
                      id: { type: 'string' },
                      name: { type: 'string' },
                    },
                  },
                },
              },
            },
            404: {
              description: 'Item not found',
            },
          },
        },
        handler: async c => {
          const itemId = c.req.param('itemId')
          return c.json({ id: itemId, name: 'Example Item' })
        },
      }),
    ],
  },
})
```

### 使用 Zod schema {/* #using-zod-schemas */}

產生 OpenAPI 文件時，`openapi` 設定內的 Zod schema 會轉換成 JSON Schema：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { registerApiRoute } from '@mastra/core/server'
import { z } from 'zod'

const ItemSchema = z.object({
  id: z.string(),
  name: z.string(),
  price: z.number(),
})

const CreateItemSchema = z.object({
  name: z.string().min(1),
  price: z.number().positive(),
})

export const mastra = new Mastra({
  server: {
    apiRoutes: [
      registerApiRoute('/items', {
        method: 'POST',
        openapi: {
          summary: 'Create a new item',
          tags: ['Items'],
          requestBody: {
            required: true,
            content: {
              'application/json': {
                schema: CreateItemSchema,
              },
            },
          },
          responses: {
            201: {
              description: 'Item created',
              content: {
                'application/json': {
                  schema: ItemSchema,
                },
              },
            },
          },
        },
        handler: async c => {
          const body = await c.req.json()
          return c.json({ id: 'new-id', ...body }, 201)
        },
      }),
    ],
  },
})
```

### 在 Swagger UI 查看路由 {/* #viewing-in-swagger-ui */}

以開發模式執行（`mastra dev`），或在建置選項設定 `swaggerUI: true`，即可在 `/swagger-ui` 的 Swagger UI 查看自訂路由。

```typescript
export const mastra = new Mastra({
  server: {
    build: {
      swaggerUI: true, // Enable in production builds
    },
    apiRoutes: [
      // Your routes...
    ],
  },
})
```

## 身分驗證 {/* #authentication */}

Mastra 伺服器設有身分驗證時，自訂 API 路由預設亦須驗證。如要公開某條路由，請設定 `requiresAuth: false`：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { registerApiRoute } from '@mastra/core/server'
import { MastraJwtAuth } from '@mastra/auth'

export const mastra = new Mastra({
  server: {
    auth: new MastraJwtAuth({
      secret: process.env.MASTRA_JWT_SECRET,
    }),
    apiRoutes: [
      // Protected route (default behavior)
      registerApiRoute('/protected-data', {
        method: 'GET',
        handler: async c => {
          // Access authenticated user from request context
          const user = c.get('requestContext').get('user')
          return c.json({ message: 'Authenticated user', user })
        },
      }),

      // Public route (no authentication required)
      registerApiRoute('/webhooks/github', {
        method: 'POST',
        requiresAuth: false, // Explicitly opt out of authentication
        handler: async c => {
          const payload = await c.req.json()
          // Process webhook without authentication
          return c.json({ received: true })
        },
      }),
    ],
  },
})
```

### 身分驗證規則 {/* #authentication-behavior */}

- **未設定身分驗證**：所有路由（內置及自訂）均可公開存取。
- **已設定身分驗證**：
  - Mastra 提供的路由（例如 `/api/agents/*`、`/api/workflows/*`）須通過身分驗證。
  - 自訂路由預設須通過身分驗證。
  - 自訂路由可設為 `requiresAuth: false`，免除身分驗證。

### 存取用戶資料 {/* #accessing-user-information */}

請求通過身分驗證後，可從請求的上下文取得用戶物件：

```typescript
registerApiRoute('/user-profile', {
  method: 'GET',
  handler: async c => {
    const requestContext = c.get('requestContext')
    const user = requestContext.get('user')

    return c.json({ user })
  },
})
```

有關身分驗證提供者的詳情，請參閱[身分驗證文件](/docs/auth/overview)。

## 客戶端斷線後繼續產生回應 {/* #continue-generation-after-client-disconnect */}

[`chatRoute()`](/reference/ai-sdk/chat-route) 等內置串流輔助函數會將傳入請求的 `AbortSignal` 轉交給 `agent.stream()`。如需在瀏覽器斷線時取消模型調用，便可沿用這項預設行為。

如自訂串流路由需要在客戶端斷線時停止，請將 `c.req.raw.signal` 傳給 `agent.stream()` 等需長時間執行的操作。客戶端連線關閉時，Mastra 的 Node 轉接器亦會停止讀取自訂路由傳回的串流 `Response` 主體。若串流回應主體的錯誤並非客戶端斷線所致，仍會循轉接器的一般錯誤處理流程傳遞。Hono 的斷線行為取決於宿主執行環境有否將連線關閉事件傳給 `request.signal`。

```typescript title="src/mastra/index.ts"
import { registerApiRoute } from '@mastra/core/server'

registerApiRoute('/stream', {
  method: 'GET',
  handler: async c => {
    const stream = await agent.stream(prompt, {
      abortSignal: c.req.raw.signal,
    })

    return stream.toTextStreamResponse()
  },
})
```

如需在客戶端斷線後繼續產生並保存最終回應，可使用底層的 `MastraModelOutput` 建立自訂路由。啟動 Agent 串流時省略 `c.req.raw.signal`，然後在背景調用 `consumeStream()`，讓伺服器繼續產生回應。

```typescript title="src/mastra/index.ts"
import {
  createUIMessageStream,
  createUIMessageStreamResponse,
  InferUIMessageChunk,
  UIMessage,
} from 'ai'
import { toAISdkStream } from '@mastra/ai-sdk'
import { Mastra } from '@mastra/core'
import { registerApiRoute } from '@mastra/core/server'

export const mastra = new Mastra({
  server: {
    apiRoutes: [
      registerApiRoute('/chat/persist/:agentId', {
        method: 'POST',
        handler: async c => {
          const { messages, memory } = await c.req.json()
          const mastra = c.get('mastra')
          const agent = mastra.getAgent(c.req.param('agentId'))

          const stream = await agent.stream(messages, {
            memory,
            // Do not pass c.req.raw.signal if this route should keep running
            // after the client disconnects.
          })

          void stream.consumeStream().catch(error => {
            mastra.getLogger()?.error('Background stream consumption failed', { error })
          })

          const uiStream = createUIMessageStream({
            originalMessages: messages,
            execute: async ({ writer }) => {
              for await (const part of toAISdkStream(stream, { from: 'agent' })) {
                writer.write(part as InferUIMessageChunk<UIMessage>)
              }
            },
          })

          return createUIMessageStreamResponse({ stream: uiStream })
        },
      }),
    ],
  },
})
```

:::note

只有確定需要在 HTTP 客戶端斷線後繼續執行，才使用這個做法。如需在斷線時停止產生回應，請繼續使用 `chatRoute()`，或自行轉交請求的 `AbortSignal`。

:::
