# Mastra 客戶端

Mastra Client SDK 提供簡潔且類型安全的介面，讓你從客戶端與 [Mastra Server](/docs/server/overview) 互動。

## 先決條件 {/* #prerequisites */}

開始本機開發前，請確認：

- Node.js `v22.13.0` 或以上版本
- TypeScript `v4.7` 或以上版本（如使用 TypeScript）
- 本機 Mastra 伺服器已啟動（通常使用連接埠 `4111`）

:::note

Mastra Client SDK 專為瀏覽器環境而設，使用瀏覽器原生的 `fetch` API 向 Mastra 伺服器傳送 HTTP 請求。

:::

## 安裝 {/* #installation */}

使用 Mastra Client SDK 前，請先安裝所需的依賴套件：

```bash npm2yarn
npm install @mastra/client-js@latest
```

### 初始化 `MastraClient` {/* #initialize-the-mastraclient */}

以 `baseUrl` 初始化後，`MastraClient` 會提供類型安全的介面，用於調用 Agent、Tool 及 Workflow。

```typescript title="lib/mastra-client.ts"
import { MastraClient } from '@mastra/client-js'

export const mastraClient = new MastraClient({
  baseUrl: process.env.MASTRA_API_URL || 'http://localhost:4111',
})
```

## 核心 API {/* #core-apis */}

Mastra Client SDK 讓你存取 Mastra 伺服器提供的所有資源。

- **[Agent](/reference/client-js/agents)**：產生回應並以串流傳送對話。
- **[A2A](/docs/connections/a2a)**：透過 Agent 卡片尋找 Agent，並使用以任務為基礎的 A2A 串流。
- **[Memory](/reference/client-js/memory)**：管理對話串及訊息記錄。
- **[Tool](/reference/client-js/tools)**：執行及管理 Tool。
- **[Workflow](/reference/client-js/workflows)**：觸發 Workflow 並追蹤執行情況。
- **[向量](/reference/client-js/vectors)**：用向量嵌入進行語義搜尋。
- **[Responses](/reference/client-js/responses)**：透過與 OpenAI 相容的介面，將 Mastra Agent 用作 Responses API。此 API 目前仍屬實驗性質。
- **[Conversations](/reference/client-js/conversations)**：將 Mastra Agent 用作 Responses API 時，可存取已儲存的對話串及對話項目記錄。此 API 目前仍屬實驗性質。
- **[日誌](/reference/client-js/logs)**：查看日誌並對系統行為進行偵錯。
- **[可觀測性](/reference/client-js/observability)**：查看應用程式效能及追蹤活動。

## 建立及執行動態 Workflow {/* #create-and-run-dynamic-workflows */}

使用 `upsertDynamicWorkflow()` 建立或取代持久儲存的 Workflow 定義。操作成功時，系統會驗證完整定義，並將它註冊到執行中的 Mastra 實例。之後可透過標準執行 API 執行該 Workflow。

以下例子展示映射 Workflow 的完整生命週期，包括建立、查看、執行及刪除：

```typescript title="lib/dynamic-workflow.ts"
import { MastraClient } from '@mastra/client-js'
import type { UpsertDynamicWorkflowParams } from '@mastra/client-js'

const client = new MastraClient({
  baseUrl: process.env.MASTRA_API_URL || 'http://localhost:4111',
})

const definition = {
  id: 'greeting-workflow',
  description: 'Returns a greeting for the supplied name',
  inputSchema: {
    type: 'object',
    properties: { name: { type: 'string' } },
    required: ['name'],
  },
  outputSchema: {
    type: 'object',
    properties: { message: { type: 'string' } },
    required: ['message'],
  },
  graph: [
    {
      type: 'mapping',
      id: 'create-greeting',
      mapConfig: JSON.stringify({
        message: { template: 'Hello, ${initData.name}!' },
      }),
    },
  ],
} satisfies UpsertDynamicWorkflowParams

await client.upsertDynamicWorkflow(definition)

const dynamicWorkflow = client.getDynamicWorkflow(definition.id)
const dynamicDefinition = await dynamicWorkflow.details()

const workflow = client.getWorkflow(dynamicDefinition.id)
const run = await workflow.createRun()
const result = await run.startAsync({ inputData: { name: 'Ada' } })

console.log(result)

await dynamicWorkflow.delete()
```

使用 `listDynamicWorkflows()` 列出已持久儲存的定義。再次以相同的 `id` 調用 `upsertDynamicWorkflow()`，便會取代已儲存的定義及目前註冊的 Workflow。

:::warning

持久儲存需要設定支援 `workflowDefinitions` 領域的儲存轉接器。如欠缺該領域，Core 仍可在記憶體註冊 Workflow，但伺服器的動態 Workflow API 無法在重新啟動後保留它。

已儲存的定義支援宣告式 Agent、Tool、映射、巢狀 Workflow、平行執行、foreach、sleep、sleep-until、條件及迴圈項目。定義不可包含 JavaScript 閉包。條件及迴圈邏輯須使用宣告式謂詞格式，引用的 Agent、Tool 及巢狀 Workflow 亦須先註冊。

伺服器啟用身分驗證時，操作定義須有 `stored-workflows:read` 或 `stored-workflows:write` 權限，執行 Workflow 則須有 `workflows:execute`。

:::

## 產生回應 {/* #generating-responses */}

以字串提示調用 `.generate()`：

```typescript
import { mastraClient } from 'lib/mastra-client'

const testAgent = async () => {
  try {
    const agent = mastraClient.getAgent('testAgent')

    const response = await agent.generate('Hello')

    console.log(response.text)
  } catch (error) {
    return 'Error occurred while generating response'
  }
}
```

:::note

調用 `.generate()` 時亦可傳入訊息物件陣列，每個物件均包含 `role` 及 `content`。詳情見 [.generate() 參考](/reference/client-js/agents#generate)。

:::

## 串流回應 {/* #streaming-responses */}

以字串提示調用 `.stream()`，即可即時接收回應：

```typescript
import { mastraClient } from 'lib/mastra-client'

const testAgent = async () => {
  try {
    const agent = mastraClient.getAgent('testAgent')

    const stream = await agent.stream('Hello')

    stream.processDataStream({
      onTextPart: text => {
        console.log(text)
      },
    })
  } catch (error) {
    return 'Error occurred while generating response'
  }
}
```

:::note

調用 `.stream()` 時亦可傳入訊息物件陣列，每個物件均包含 `role` 及 `content`。詳情見 [.stream() 參考](/reference/client-js/agents#stream)。

:::

## 設定選項 {/* #configuration-options */}

`MastraClient` 接受 `retries`、`backoffMs` 及 `headers` 等可選參數，可控制請求行為，例如設定重試或加入診斷元數據。

```typescript title="lib/mastra-client.ts"
import { MastraClient } from '@mastra/client-js'

export const mastraClient = new MastraClient({
  retries: 3,
  backoffMs: 300,
  maxBackoffMs: 5000,
  headers: {
    'X-Development': 'true',
  },
})
```

其他設定選項見 [MastraClient](/reference/client-js/mastra-client)。

## 憑證及工作階段 Cookie {/* #credentials-and-session-cookies */}

如 UI 與 Mastra API 來自不同來源（主機、子網域或連接埠不同），例如 Mastra Studio 與自訂伺服器使用不同連接埠，可 **使用工作階段 Cookie 驗證 Mastra API 請求**。在 `MastraClient` 加入 **`credentials: 'include'`**，令每個請求均帶有用戶登入後取得的 Cookie。欠缺此設定時，即使已在瀏覽器成功登入，亦經常會收到 Mastra 的 **`401`** 回應。

```typescript title="lib/mastra-client.ts"
import { MastraClient } from '@mastra/client-js'

export const mastraClient = new MastraClient({
  baseUrl: process.env.MASTRA_API_URL || 'http://localhost:4111',
  credentials: 'include',
})
```

**在伺服器允許帶憑證的跨來源請求**。請參閱 [CORS：帶憑證的請求](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/CORS#requests_with_credentials)。須為 `Access-Control-Allow-Origin` 指定明確來源（不可用 `*`），並設定 `Access-Control-Allow-Credentials: true`，否則瀏覽器會在請求到達 Mastra 前將其攔截。

**使用 `@mastra/react` 時**，用 `MastraReactProvider` 包住應用程式，將 `baseUrl` 及 `apiPrefix` 設至與伺服器相符，並沿用預設的 `credentials: 'include'`。只有需要 `same-origin` 或 `omit` 行為才更改 `credentials`。

## 加入取消請求功能 {/* #adding-request-cancelling */}

`MastraClient` 透過 Node.js 的標準 `AbortSignal` API 支援取消請求。例如，用戶中止操作時可取消進行中的請求，亦可用來清理過時的網絡請求。

將 `AbortSignal` 傳給客戶端建構函數，即可讓所有請求支援取消。

```typescript {3,7} title="lib/mastra-client.ts"
import { MastraClient } from '@mastra/client-js'

export const controller = new AbortController()

export const mastraClient = new MastraClient({
  baseUrl: process.env.MASTRA_API_URL || 'http://localhost:4111',
  abortSignal: controller.signal,
})
```

### 使用 `AbortController` {/* #using-the-abortcontroller */}

調用 `.abort()` 會取消與該訊號相關的所有進行中請求。

```typescript
import { mastraClient, controller } from 'lib/mastra-client'

const handleAbort = () => {
  controller.abort()
}
```

## 客戶端 Tool {/* #client-tools */}

使用 `createTool()` 函數直接在客戶端應用程式定義 Tool。調用 `.generate()` 或 `.stream()` 時，經 `clientTools` 參數將這些 Tool 傳給 Agent。

這樣一來，Agent 便可觸發瀏覽器端的功能，例如操作 DOM、存取本機儲存或使用其他 Web API。Tool 會在用戶的瀏覽器環境執行，毋須在伺服器執行。

```typescript {26}
import { createTool } from '@mastra/client-js'
import { z } from 'zod'

const handleClientTool = async () => {
  try {
    const agent = mastraClient.getAgent('colorAgent')

    const colorChangeTool = createTool({
      id: 'color-change-tool',
      description: 'Changes the HTML background color',
      inputSchema: z.object({
        color: z.string(),
      }),
      outputSchema: z.object({
        success: z.boolean(),
      }),
      execute: async inputData => {
        const { color } = inputData

        document.body.style.backgroundColor = color
        return { success: true }
      },
    })

    const response = await agent.generate('Change the background to blue', {
      clientTools: { colorChangeTool },
    })

    console.log(response)
  } catch (error) {
    console.error(error)
  }
}
```

### 使用客戶端 Tool 的 Agent {/* #client-tool-agent */}

這是標準的 Mastra [Agent](../agents/overview#quickstart)，設定為傳回十六進制色碼，以配合上文定義的瀏覽器端 Tool。

```typescript title="src/mastra/agents/color-agent"
import { Agent } from '@mastra/core/agent'

export const colorAgent = new Agent({
  id: 'color-agent',
  name: 'Color Agent',
  instructions: `You are a helpful CSS assistant.
  You can change the background color of web pages.
  Respond with a hex reference for the color requested by the user`,
  model: '__GATEWAY_OPENAI_MODEL__',
})
```

## 在伺服器端使用 MastraClient {/* #use-mastraclient-on-the-server */}

伺服器端 API 路由及無伺服器函數（包括 action）亦可使用 `MastraClient`。用法相同，但你可能需要為客戶端重建回應：

```typescript {8}
export async function action() {
  const agent = mastraClient.getAgent('testAgent')

  const stream = await agent.stream('Hello')

  return new Response(stream.body)
}
```
