# Web 框架

Mastra 與 Web 框架整合後，會按框架的標準流程隨應用程式一同部署。請依照以下說明設定，確保 Mastra 整合部分能正確部署。

:::warning
部署到雲端供應商時，請勿將 [LibSQLStore](/integrations/databases/libsql) 配合本機 `file:` 資料庫或記憶體內資料庫使用。本機資料庫需要存取檔案系統，無法在無伺服器平台使用。請將 LibSQLStore 指向 Turso 等遠端資料庫。
:::

整合指南：

- [整合 Next.js](/integrations/frameworks/next-js)
- [整合 Astro](/integrations/frameworks/astro)

## 在 Vercel 部署 Next.js {/* #with-nextjs-on-vercel */}

如已將 Mastra 整合到 Next.js，並打算部署到 Vercel，請確定 `next.config.ts` 已設定 `serverExternalPackages: ["@mastra/*"]`。[Next.js 指南](/integrations/frameworks/next-js)的設定流程包含這一項。如現有設定欠缺這一項，請加入：

```typescript {4} title="next.config.ts"
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  serverExternalPackages: ['@mastra/*'],
}

export default nextConfig
```

## 在 Vercel 部署 Astro {/* #with-astro-on-vercel */}

如已按[整合指南](/integrations/frameworks/astro)將 Mastra 與 Astro 整合，並打算部署到 Vercel，請在 `astro.config.mjs` 加入 Vercel 轉接器及設定伺服器輸出：

```javascript {2,5-6} title="astro.config.mjs"
import { defineConfig } from 'astro/config'
import vercel from '@astrojs/vercel'

export default defineConfig({
  adapter: vercel(),
  output: 'server',
})
```

## 在 Netlify 部署 Astro {/* #with-astro-on-netlify */}

如已按[整合指南](/integrations/frameworks/astro)將 Mastra 與 Astro 整合，並打算部署到 Netlify，請在 `astro.config.mjs` 加入 Netlify 轉接器及設定伺服器輸出：

```javascript {2,5-6} title="astro.config.mjs"
import { defineConfig } from 'astro/config'
import netlify from '@astrojs/netlify'

export default defineConfig({
  adapter: netlify(),
  output: 'server',
})
```
