# 部署

任何兼容 Node.js 的環境都可部署 Mastra 應用程式。你可部署 Mastra 伺服器，亦可將 Mastra 整合至現有的 Web 框架。其他選擇包括雲端供應商，以及提供可觀測性、Studio 和伺服器部署的 [Mastra Platform](/docs/mastra-platform/overview)。

## 支援的運行環境 {/* #runtime-support */}

Mastra 可在下列任何環境運行。

- Node.js `v22.13.0` 或以上版本
- Bun
- Deno
- Cloudflare

## 部署方式 {/* #deployment-options */}

### Mastra 伺服器 {/* #mastra-server */}

Mastra 提供以 Hono 為基礎的[伺服器](/docs/server/overview)，支援獨立部署。用 `mastra build` 建置應用程式，再把產物部署至你選用的虛擬機、容器或 PaaS 平台。

如需完全控制基礎設施、長時間運行的程序或 WebSocket 連線，可採用這種方式。詳見 [Mastra 伺服器部署指南](/docs/deployment/mastra-server)。

### Monorepo {/* #monorepo */}

如 Mastra 伺服器是 Monorepo 的一部分，可按獨立部署的方式處理。

詳情見 [Monorepo 部署文件](/docs/deployment/monorepo)。

### Mastra Platform {/* #mastra-platform */}

[Mastra Platform](/docs/mastra-platform/overview) 提供三項產品，讓你部署、監察及管理以 Mastra 框架建置的 AI 應用程式。

- [**Observability**](/docs/mastra-platform/observability)。獨立託管產品，可搜尋不同 Mastra 項目及部署的 Trace、日誌和指標。
- [**Studio**](/docs/mastra-platform/studio)。託管的視覺化環境，讓你測試 Agent、執行 Workflow 及查閱 Trace。
- [**Server**](/docs/mastra-platform/server)。正式環境的部署選項，讓 Mastra 應用程式以 API 伺服器形式運行。

詳情見 [Mastra Platform 概覽](/docs/mastra-platform/overview)。

### 雲端供應商 {/* #cloud-providers */}

Mastra 應用程式可部署至雲端供應商及無伺服器平台。你可選用 Mastra 內置的部署工具，為 Vercel、Netlify 或 Cloudflare 建置應用程式，再經相應平台部署產物。

如需自動擴縮、希望盡量減少基礎設施管理工作，或已在用其中一個平台，可選擇這種方式。

### Sandbox {/* #sandbox */}

將 Mastra 伺服器部署至短期使用的 Workspace Sandbox（例如 Vercel Sandbox 或 E2B），幾秒內便可取得可公開存取的 URL。

你可用這種方式即時預覽、經 CI 流水線部署、驗證 Agent 建置的應用程式，或為每位用戶運行不受信任的實例。詳見 [Sandbox 部署指南](/docs/deployment/sandbox)。

### Web 框架 {/* #web-framework */}

Mastra 整合至 Web 框架後，會按該框架的標準部署流程與應用程式一同部署。以下指南說明各框架所需的部署設定。

如要將 Mastra 加入現有的 Next.js 或 Astro 應用程式，可參考以下指南。

- [在 Vercel 使用 Next.js](/docs/deployment/web-framework#with-nextjs-on-vercel)
- [在 Vercel 使用 Astro](/docs/deployment/web-framework#with-astro-on-vercel)
- [在 Netlify 使用 Astro](/docs/deployment/web-framework#with-astro-on-netlify)

## Workflow 執行工具 {/* #workflow-runners */}

Mastra Workflow 預設採用內置執行引擎。如正式環境的工作負載需要託管基礎設施，可將 Workflow 部署至 [Inngest](https://www.inngest.com) 等專用平台，使用步驟結果快取、自動重試及即時監察功能。

執行選項見 [Workflow 執行工具指南](/docs/deployment/workflow-runners)，設定步驟見 [Inngest 部署指南](/integrations/deploy/inngest)。

## Workers {/* #workers */}

在正式環境，Mastra 可在 API 伺服器以外的專用 Worker 程序編排 Workflow、執行 Cron 排程及在背景執行 Tool，讓各項工作獨立擴縮，並隔離故障。詳見 [Workers](/docs/deployment/workers)。
