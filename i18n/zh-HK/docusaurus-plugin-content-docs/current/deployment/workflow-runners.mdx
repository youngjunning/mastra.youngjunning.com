# Workflow運行器

馬斯特拉[workflows](/docs/workflows/overview)可以使用內建的Workflow執行器執行，也可以部署到處理編排、監控和可靠性的專用Workflow執行平台。

## 因格斯特 {/* #inngest */}

Inngest 是一個開發者平台，用於運行後台Workflow而無需管理基礎架構。 Mastra Workflow可以部署到 Inngest 以進行步驟記憶和自動重試。 Inngest 還提供即時監控和暫停/恢復功能。

參觀[Inngest deployment guide](/integrations/deploy/inngest) for setup instructions and the [Inngest workflow example](https://github.com/mastra-ai/mastra/tree/main/examples/inngest) for a complete implementation.

## 顳 {/* #temporal */}

Temporal 是一個持久的執行平台，用於編排長時間運行的Workflow。 Mastra Workflow可以在 Temporal Workers 上運行，每個Workflow`createStep` mapped to a Temporal activity for automatic retries and durable state.

這`@mastra/temporal` package is experimental and not ready for production use. Visit the [Temporal deployment guide](/integrations/deploy/temporal) for setup instructions.
