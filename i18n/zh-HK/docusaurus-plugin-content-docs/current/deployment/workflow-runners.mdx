# Workflow 執行器

Mastra 的 [Workflow](/docs/workflows/overview) 可透過內置執行器執行，亦可部署到專用平台，由平台負責編排和監察，並維持執行的可靠性。

## Inngest {/* #inngest */}

Inngest 是供開發者執行背景 Workflow 的平台，毋須自行管理基礎設施。把 Mastra Workflow 部署到 Inngest 後，便可重用已完成步驟的結果，並在失敗時自動重試。Inngest 亦支援即時監察、暫停及恢復執行。

設定步驟可參閱 [Inngest 部署指南](/integrations/deploy/inngest)，完整實作可參考 [Inngest Workflow 示例](https://github.com/mastra-ai/mastra/tree/main/examples/inngest)。

## Temporal {/* #temporal */}

Temporal 是持久執行平台，可編排長時間運行的 Workflow。Mastra Workflow 可在 Temporal Worker 上執行。每個透過 `createStep` 定義的步驟均會對應一個 Temporal Activity，以支援自動重試及持久保存狀態。

`@mastra/temporal` 套件仍處於實驗階段，尚未適合在生產環境使用。設定步驟可參閱 [Temporal 部署指南](/integrations/deploy/temporal)。
