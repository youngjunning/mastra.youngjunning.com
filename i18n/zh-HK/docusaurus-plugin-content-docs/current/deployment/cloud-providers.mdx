# 雲端服務供應商

你可以將 Mastra 應用程式部署到雲端服務供應商或無伺服器平台。Mastra 為 Vercel、Netlify 及 Cloudflare 提供內置部署工具，可按需要使用這些工具自動完成部署。

## Mastra 平台 {/* #mastra-platform */}

你可以透過 Mastra 平台將伺服器部署到雲端。詳情請參閱 [Mastra 平台部署指引](/docs/mastra-platform/overview)。
