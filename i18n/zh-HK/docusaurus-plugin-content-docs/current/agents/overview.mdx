# Agent商

Agent使用法學碩士和Tool來解決開放式任務。他們推理目標並決定使用哪些Tool。和[memory](/docs/memory/overview)配置後，它們會保留對話歷史記錄。它們繼續迭代，直到模型發出最終答案或滿足可選的停止條件。

Agent程式產生結構化回應，您可以在 UI 中呈現或以程式處理。直接使用Agent或將它們組合到Workflow或多Agent系統中。

## 何時使用Agent {/* #when-to-use-agents */}

當任務是開放式的並且事先不知道步驟時，使用Agent。Agent決定呼叫哪些Tool、循環多少次、何時停止。您提供目標和約束，而不是定義每個步驟。對於具有明確控制流程的預定多步驟流程，請使用[workflows](/docs/workflows/overview) instead.

手錶[Mastra agent quickstart](https://www.youtube.com/watch?v=G8tXjcseNjg) for a short walkthrough of creating and testing a Mastra agent.

:::

## 快速入門 {/* #quickstart */}

透過實例化創建Agent`Agent` class from `@mastra/core` and provide the required properties:

```typescript title="src/mastra/agents/test-agent.ts"
import { Agent } from '@mastra/core/agent'

export const testAgent = new Agent({
  id: 'test-agent',
  name: 'Test Agent',
  instructions: 'You are a helpful assistant.',
  model: '__GATEWAY_OPENAI_MODEL__',
})
```

這`instructions` define the agent's behavior, personality, and capabilities. They're system-level prompts that establish the agent's core identity and expertise. The `model` is specified as `'provider/model-name'` using Mastra's [model router](/models).

若要使Agent程式在您的應用程式中可用，請將其註冊到您的 Mastra 實例中（通常位於`src/mastra/index.ts`):

```typescript {5} title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { testAgent } from './agents/test-agent'

export const mastra = new Mastra({
  agents: { testAgent },
})
```

註冊後，它可以從Workflow、Tool或其他Agent中調用，並且可以存取共享資源，例如記憶體、日誌記錄和可觀察性功能。

參觀[agent reference](/reference/agents/agent) for more information on available properties and configurations.

：：：提示

使用[Studio](/docs/studio/overview) to test your agent with different messages and inspect tool calls and responses, plus debug agent behavior.

使用[Agent Builder](https://agent-builder.mastra.ai) to create and manage a fully stored agent through a browser instead of defining it in TypeScript.

## 使用您的Agent {/* #use-your-agent */}

註冊後，透過以下方式找回您的Agent[`mastra.getAgentById()`](/reference/core/getAgentById). Call `.generate()` for a complete response or `.stream()` to deliver tokens in real time. You can call agents from [workflow steps](/docs/workflows/agents-and-tools), [tools](/docs/agents/tools), the [Mastra Client](/reference/client-js/mastra-client), route handlers, [server adapters](/docs/server/server-adapters), or the command line. See [Integrations](/integrations) to use agents in your application framework.

從 Mastra 實例引用Agent程式時，請使用`mastra.getAgentById()` to ensure it has access to shared services such as instance-level storage, logging, and agent registry. A directly imported agent can still work with its own local configuration, but it won't have access to those shared services.

<Tabs>
  <TabItem value="generate" label=".generate()">
    所有Tool呼叫和步驟完成後傳回完整回應。結果包括`text`, `toolCalls`, `toolResults`, `steps`, and token `usage` statistics.

    請參閱[`Agent.generate()` reference](/reference/agents/generate) for the response shape, including tool call and tool result payloads.

    ```ts
    const agent = mastra.getAgentById('test-agent')
    const response = await agent.generate('Help me organize my day')
    console.log(response.text)
    ```
  </TabItem>

  <TabItem value="stream" label=".stream()">
    傳回一個您可以在令牌到達時使用的流。結果暴露了`textStream` for incremental output and promises for `toolCalls`, `toolResults`, `steps`, and token `usage` that resolve when the stream finishes.

    請參閱[`MastraModelOutput` reference](/reference/streaming/agents/MastraModelOutput) for the stream shape, including tool call and tool result payloads.

    ```ts
    const agent = mastra.getAgentById('test-agent')
    const stream = await agent.stream('Help me organize my day')

    for await (const chunk of stream.textStream) {
      process.stdout.write(chunk)
    }
    ```
  </TabItem>
</Tabs>

## 多Agent系統 {/* #multi-agent-systems */}

多Agent系統使用多個Agent來解決對於單一Agent而言過於廣泛或過於專業的任務。您無需使用數十種Tool和一長串指令來建立一個Agent，而是將職責分配給各個重點Agent，並讓協調員將結果匯總在一起。

閱讀[conceptual overview of multi-agent systems](/docs/guides/multi-agent-systems) to learn how you can apply different patterns with Mastra.
