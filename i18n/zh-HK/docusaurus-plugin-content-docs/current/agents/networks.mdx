# Agent 網絡

:::warning[已棄用]

Agent 網絡已棄用，將於日後的主要版本移除。請改用以 `agent.stream()` 或 `agent.generate()` 執行的[監督 Agent](../subagents)。這種 Agent 同樣可協調多個 Agent，API 較簡單，方便控制和除錯。

升級方法見[遷移指南](/reference/migrations/network-to-supervisor)。

:::

**路由 Agent** 用 LLM 解讀請求，決定呼叫哪些元件（子 Agent、Workflow 或 Tool）、按甚麼次序呼叫，以及傳入哪些資料。

## 建立 Agent 網絡 {/* #create-an-agent-network */}

為路由 Agent 設定 `agents`、`workflows` 及 `tools`。必須啟用 Memory，因為 `.network()` 會用它儲存工作記錄並判斷工作是否完成。

各元件須有清晰的 `description`，讓路由 Agent 決定使用哪個。Workflow 和 Tool 的 `inputSchema` 和 `outputSchema` 亦有助路由 Agent 判斷適用的輸入。

```typescript title="src/mastra/agents/routing-agent.ts"
import { Agent } from '@mastra/core/agent'
import { Memory } from '@mastra/memory'
import { LibSQLStore } from '@mastra/libsql'

import { researchAgent } from './research-agent'
import { writingAgent } from './writing-agent'
import { cityWorkflow } from '../workflows/city-workflow'
import { weatherTool } from '../tools/weather-tool'

export const routingAgent = new Agent({
  id: 'routing-agent',
  name: 'Routing Agent',
  instructions: `
    You are a network of writers and researchers. The user will ask you to research a topic. Always respond with a complete report—no bullet points. Write in full paragraphs, like a blog post. Do not answer with incomplete or uncertain information.`,
  model: '__GATEWAY_OPENAI_MODEL__',
  agents: {
    // highlight-start
    researchAgent,
    writingAgent,
    // highlight-end
  },
  workflows: {
    // highlight-next-line
    cityWorkflow,
  },
  tools: {
    // highlight-next-line
    weatherTool,
  },
  memory: new Memory({
    storage: new LibSQLStore({
      id: 'mastra-storage',
      url: 'file:../mastra.db',
    }),
  }),
})
```

:::note

子 Agent 要在 `Agent` 實例設定 `description`。Workflow 和 Tool 則要在 `createWorkflow()` 或 `createTool()` 提供 `description`、`inputSchema` 和 `outputSchema`。

:::

## 呼叫 Agent 網絡 {/* #call-the-network */}

以用戶訊息呼叫 `.network()`，便會回傳可逐項讀取的事件串流。

```typescript
const result = await routingAgent.network('Tell me three cool ways to use Mastra')

for await (const chunk of result) {
  console.log(chunk.type)
  if (chunk.type === 'network-execution-event-step-finish') {
    console.log(chunk.payload.result)
  }
}
```

## 結構化輸出 {/* #structured-output */}

傳入 `structuredOutput` 可取得有型別且經驗證的結果。用 `objectStream` 可在物件逐步產生時讀取部分內容。

```typescript
import { z } from 'zod'

const resultSchema = z.object({
  summary: z.string().describe('A brief summary of the findings'),
  recommendations: z.array(z.string()).describe('List of recommendations'),
  confidence: z.number().min(0).max(1).describe('Confidence score'),
})

const stream = await routingAgent.network('Research AI trends', {
  structuredOutput: { schema: resultSchema },
})

for await (const partial of stream.objectStream) {
  console.log('Building result:', partial)
}

const final = await stream.object
console.log(final?.summary)
```

## 批准或拒絕 Tool 呼叫 {/* #approve-and-decline-tool-calls */}

元件需要審批時，串流會送出 `agent-execution-approval` 或 `tool-execution-approval` 資料區塊。透過 `approveNetworkToolCall()` 或 `declineNetworkToolCall()` 回應。

網絡審批以快照保存執行狀態。請確認 Mastra 實例已啟用[儲存 Provider](/docs/storage)。

```typescript title="src/approve-network.ts"
const stream = await routingAgent.network('Perform some sensitive action', {
  memory: {
    thread: 'user-123',
    resource: 'my-app',
  },
})

for await (const chunk of stream) {
  if (chunk.type === 'agent-execution-approval' || chunk.type === 'tool-execution-approval') {
    // Approve
    const approvedStream = await routingAgent.approveNetworkToolCall(chunk.payload.toolCallId, {
      runId: stream.runId,
      memory: { thread: 'user-123', resource: 'my-app' },
    })

    for await (const c of approvedStream) {
      if (c.type === 'network-execution-event-step-finish') {
        console.log(c.payload.result)
      }
    }
  }
}
```

如要拒絕，可用相同參數呼叫 `declineNetworkToolCall()`。

## 暫停和恢復 {/* #suspend-and-resume */}

元件呼叫 `suspend()` 時，串流會送出暫停資料區塊，例如 `tool-execution-suspended`。用 `resumeNetwork()` 提供要求的資料，即可繼續執行。

```typescript title="src/resume-network.ts"
const stream = await routingAgent.network('Delete the old records', {
  memory: { thread: 'user-123', resource: 'my-app' },
})

for await (const chunk of stream) {
  if (chunk.type === 'workflow-execution-suspended') {
    console.log(chunk.payload.suspendPayload)
  }
}

// Resume with user confirmation
const resumedStream = await routingAgent.resumeNetwork(
  { confirmed: true },
  {
    runId: stream.runId,
    memory: { thread: 'user-123', resource: 'my-app' },
  },
)

for await (const chunk of resumedStream) {
  if (chunk.type === 'network-execution-event-step-finish') {
    console.log(chunk.payload.result)
  }
}
```

### 自動恢復 {/* #automatic-resumption */}

將 `autoResumeSuspendedTools` 設為 `true`，網絡便可按用戶的下一則訊息繼續已暫停的元件，讓用戶直接在對話中提供所需資料。

```typescript
const stream = await routingAgent.network('Delete the old records', {
  autoResumeSuspendedTools: true,
  memory: { thread: 'user-123', resource: 'my-app' },
})
```

自動恢復的要求：

- **已設定 Memory**：Agent 要使用 Memory，才可在不同訊息之間追蹤已暫停的 Tool。
- **使用同一個執行緒**：後續訊息必須使用相同的 `thread` 和 `resource` 識別碼。
- **定義 `resumeSchema`**：Tool 必須定義 `resumeSchema`，讓網絡可從用戶訊息擷取資料。

| | 手動（`resumeNetwork`） | 自動（`autoResumeSuspendedTools`） |
| - | - | - |
| 適用情況 | 設有審批按鈕的自訂介面 | 聊天介面 |
| 控制方式 | 自行決定何時繼續及傳入甚麼資料 | 網絡從用戶訊息擷取資料 |
| 設定 | 處理暫停資料區塊，呼叫 `resumeNetwork` | 啟用選項，在 Tool 定義 `resumeSchema` |
