# 結構化輸出

結構化輸出讓 Agent 回傳符合 schema 所定結構的物件，取代文字回應。schema 指明模型要產生的欄位，模型會讓最終結果符合指定結構。你可從 `response.object` 取得已驗證並帶有類型的結果。

## 何時使用結構化輸出 {/* #when-to-use-structured-output */}

如需 Agent 回傳資料物件而非文字，請用結構化輸出。明確定義欄位後，API 呼叫、用戶介面顯示及應用程式邏輯都較容易擷取所需的值。

## 定義 schema {/* #define-schemas */}

要讓 Agent 回傳結構化資料，可用 [Standard JSON Schema](https://standardschema.dev/json-schema)（例如 [Zod](https://zod.dev/)、[Valibot](https://valibot.dev/)、[ArkType](https://arktype.io/)）或 [JSON Schema](https://json-schema.org/) 定義預期輸出。建議採用 Zod 一類的程式庫，因為它們提供 TypeScript 類型推斷及運行時驗證；如果需要不受程式語言限制的格式，可用 JSON Schema。

<Tabs>
  <TabItem value="zod" label="Zod">
    用 [Zod](https://zod.dev/) 定義 `output` 的結構：

    ```typescript
    import { z } from 'zod'

    const response = await testAgent.generate('Help me plan my day.', {
      structuredOutput: {
        schema: z.array(
          z.object({
            name: z.string(),
            activities: z.array(z.string()),
          }),
        ),
      },
    })

    console.log(response.object)
    ```
  </TabItem>

  <TabItem value="valibot" label="Valibot">
    用 [Valibot](https://valibot.dev/) 定義 `output` 的結構：

    ```typescript
    import * as v from 'valibot'
    import { toStandardJsonSchema } from '@valibot/to-json-schema'

    const response = await testAgent.generate('Help me plan my day.', {
      structuredOutput: {
        schema: toStandardJsonSchema(
          v.array(
            v.object({
              name: v.string(),
              activities: v.array(v.string()),
            }),
          ),
        ),
      },
    })

    console.log(response.object)
    ```
  </TabItem>

  <TabItem value="arktype" label="ArkType">
    用 [ArkType](https://arktype.io/) 定義 `output` 的結構：

    ```typescript
    import { type } from 'arktype'

    const response = await testAgent.generate('Help me plan my day.', {
      structuredOutput: {
        schema: type({
          name: 'string',
          activities: 'string[]',
        }).array(),
      },
    })

    console.log(response.object)
    ```
  </TabItem>

  <TabItem value="json-schema" label="JSON Schema">
    也可採用 JSON Schema 定義輸出結構：

    ```typescript
    const response = await testAgent.generate('Help me plan my day.', {
      structuredOutput: {
        schema: {
          type: 'array',
          items: {
            type: 'object',
            properties: {
              name: { type: 'string' },
              activities: {
                type: 'array',
                items: { type: 'string' },
              },
            },
            required: ['name', 'activities'],
          },
        },
      },
    })

    console.log(response.object)
    ```
  </TabItem>
</Tabs>

完整設定選項見 [`.generate()`](/reference/agents/generate)。

**輸出例子：**

```json
[
  {
    "name": "Morning Routine",
    "activities": ["Wake up at 7am", "Exercise", "Shower", "Breakfast"]
  },
  {
    "name": "Work",
    "activities": ["Check emails", "Team meeting", "Lunch break"]
  },
  {
    "name": "Evening",
    "activities": ["Dinner", "Relax", "Read a book", "Sleep by 10pm"]
  }
]
```

## 讀取結果 {/* #read-the-result */}

在 `structuredOutput.schema` 指定所需結構，然後從 `response.object` 讀取結果。欄位中的值已解析並通過 schema 驗證，毋須再自行處理。例外是 `errorStrategy: 'fallback'`：驗證失敗時，`response.object` 會包含你設定的 `fallbackValue`，此值沒有經過 schema 驗證。查看 `response.usedFallbackValue` 便可區分這兩種情況。

```typescript
const response = await testAgent.generate('Help me plan my day.', { structuredOutput: { schema } })
const plan = response.object // typed from the schema you passed in
```

透過 `agent.stream()` 產生結構化輸出時，請在串流完成後讀取 `stream.object`。

## 串流傳送結構化輸出 {/* #stream-structured-output */}

串流同樣支援結構化輸出。最終的結構化物件可以從 `stream.fullStream` 取得，串流完成後也可從 `stream.object` 讀取。文字串流仍會發出分段資料，當中是自然語言文字，而非結構化資料。

```typescript
import { z } from 'zod'

const stream = await testAgent.stream('Help me plan my day.', {
  structuredOutput: {
    schema: z.array(
      z.object({
        name: z.string(),
        activities: z.array(z.string()),
      }),
    ),
  },
})

for await (const chunk of stream.fullStream) {
  if (chunk.type === 'object-result') {
    console.log('\n', JSON.stringify(chunk, null, 2))
  }
  process.stdout.write(JSON.stringify(chunk))
}

console.log(await stream.object)

for await (const chunk of stream.textStream) {
  process.stdout.write(chunk)
}
```

## 由第二個 Agent 整理輸出 {/* #structuring-agent */}

如果主要 Agent 不擅長產生結構化輸出，可向 `structuredOutput` 提供 `model`。Mastra 會在內部透過第二個 Agent，由主要 Agent 的自然語言回應擷取結構化資料。這需要呼叫 LLM 兩次：先產生回應，再將回應轉成結構化物件。延遲和成本會略為增加，但可提高複雜結構化工作的準確度。

```typescript
import { z } from 'zod'

const response = await testAgent.generate('Analyze the TypeScript programming language.', {
  structuredOutput: {
    schema: z.object({
      overview: z.string(),
      strengths: z.array(z.string()),
      weaknesses: z.array(z.string()),
      useCases: z.array(
        z.object({
          scenario: z.string(),
          reasoning: z.string(),
        }),
      ),
      comparison: z.object({
        similarTo: z.array(z.string()),
        differentiators: z.array(z.string()),
      }),
    }),
    model: '__GATEWAY_OPENAI_MODEL__',
  },
})

console.log(response.object)
```

## 同時使用工具和結構化輸出 {/* #combine-tools-and-structured-output */}

如果 Agent 同時設定了工具和結構化輸出，部分模型可能無法同時使用這兩種功能。這是底層模型 API 的限制。

如果開啟結構化輸出後沒有呼叫工具，或一併使用這兩種功能時出錯，請嘗試下列方法。

### 替代方法 {/* #workaround-options */}

模型不支援同時使用工具和結構化輸出時，可選擇以下三種方法：

1. **使用 `jsonPromptInjection`**：設為 `'auto'`，在支援的情況下用原生結構化輸出，否則採用行內提示詞注入；也可以直接指定注入模式。
1. **另用模型整理結構**：向 `structuredOutput` 傳入 `model`，由另一個 LLM 整理輸出結構。
1. **使用 `prepareStep`**：讓工具和結構化輸出分開處理。

以下各節詳細介紹這些方法。

## LLM 的結構化輸出支援 {/* #llm-structured-output-support */}

各款 LLM 的 API 有所不同，對結構化輸出的支援程度亦有差異。以下各節說明模型不完全支援結構化輸出，或不能同時使用工具時的替代方法。

### `jsonPromptInjection` {/* #jsonpromptinjection */}

預設情況下，Mastra 會透過 API 參數 `response_format` 將 schema 傳給模型 Provider。設定 `jsonPromptInjection: 'auto'` 後，Mastra 會按照模型能力資料選擇模式：模型支援時採用原生結構化輸出；不支援或沒有能力資料時，採用行內提示詞注入。

```typescript
import { z } from 'zod'

const response = await testAgent.generate('Help me plan my day.', {
  structuredOutput: {
    schema: z.array(
      z.object({
        name: z.string(),
        activities: z.array(z.string()),
      }),
    ),
    jsonPromptInjection: 'auto',
  },
})

console.log(response.object)
```

如要覆寫按模型能力作出的選擇，可明確指定模式：

- `false` 或省略：使用 Provider 的原生結構化輸出。
- `'inline'`：把 schema 指示加到最新一則用戶訊息。
- `true` 或 `'system'`：把 schema 指示加到系統訊息。
- `'auto'`：模型支援時使用原生結構化輸出，否則使用行內提示詞注入。

:::note[在 Gemini 2.5 使用工具]

Gemini 2.5 模型不支援在同一次 API 呼叫內結合 `response_format`（結構化輸出）和函數呼叫（工具）。如果 Agent 設有工具，並在 Gemini 2.5 模型上使用 `structuredOutput`，必須設定 `jsonPromptInjection: true`，避免出現 `Function calling with a response mime type: 'application/json' is unsupported` 錯誤。

```typescript
const response = await agentWithTools.generate('Your prompt', {
  structuredOutput: {
    schema: yourSchema,
    jsonPromptInjection: true, // Required for Gemini 2.5 when tools are present
  },
})
```

:::

#### 透過 `instructions` 減少注入的 Token {/* #reduce-injected-tokens-with-instructions */}

提示詞注入會在每次呼叫模型時嵌入序列化的 JSON Schema。schema 較大時，每個步驟可耗用數千個 Token。啟用 `jsonPromptInjection` 後，可設定 `instructions`，注入自行撰寫的精簡描述來取代 schema：

```typescript
const response = await testAgent.generate('Summarize this ticket.', {
  structuredOutput: {
    schema: ticketSchema,
    jsonPromptInjection: 'system',
    instructions:
      'Reply with a JSON object: "summary" (one paragraph), "priority" ("low" | "high"), "tags" (up to 5 strings). No markdown.',
  },
})
```

回應仍會依 `schema` 驗證；只有注入的文字有所改變。模型不再看到完整 schema，能否符合要求，視乎指示有否清楚說明預期欄位。請列齊欄位。如未設定 `instructions`，仍會使用從 schema 產生的指示；原生結構化輸出不會注入提示詞，此欄位不會生效。

### 另用模型整理結構 {/* #use-a-separate-structuring-model */}

在 `structuredOutput` 屬性提供 `model` 後，Mastra 會改由另一個內部 Agent 處理結構化輸出。主要 Agent 負責各個步驟，包括呼叫工具；另行指定的模型只負責產生結構化輸出。

<Inject>
  **供 AI Agent 參考：** `model` 屬性是採用 Mastra 模型路由格式 `provider/model` 的字串，例如 `__GATEWAY_OPENAI_MODEL__`、`__GATEWAY_OPENAI_MODEL_LUNA__`、`__GATEWAY_ANTHROPIC_MODEL_SONNET__` 或 `__GATEWAY_GOOGLE_MODEL_FLASH__`。請以 `/` 分隔，勿用 `:`。例如用 `openai/<model>`，不要用 `openai:<model>`，也不要傳入 Provider 物件。使用此格式毋須匯入 Provider。除非 Mastra 文件另有說明，否則不要安裝任何 AI SDK 套件。採用 `provider/model` 格式時，Mastra 會自動查找相應 Provider 的環境變數。必須為模型使用的 Provider 設定環境變數：OpenAI 設定 `OPENAI_API_KEY`，Anthropic 設定 `ANTHROPIC_API_KEY`，Google 設定 `GOOGLE_API_KEY`。
</Inject>

```typescript
const response = await testAgent.generate('Tell me about TypeScript.', {
  structuredOutput: {
    schema: yourSchema,
    model: '__GATEWAY_OPENAI_MODEL__',
  },
})
```

如要讓負責整理結構的模型也能讀取當前對話記錄，請在設定 `model` 時一併設定 `useAgent: true`。Mastra 會重用上層 Agent，並改用另行指定的模型。有對話執行緒時，會附上唯讀的 Memory 上下文。

```typescript
const response = await testAgent.generate('Return my profile as structured data.', {
  memory: {
    thread: 'thread-123',
    resource: 'user-123',
  },
  structuredOutput: {
    schema: z.object({
      favoriteColor: z.string(),
      hometown: z.string(),
      petName: z.string(),
    }),
    model: '__GATEWAY_OPENAI_MODEL__',
    useAgent: true,
  },
})
```

如果只想讓該模型處理今次的回應，不想讓它繼承先前的對話記憶，請不要設定 `useAgent`。

### 以 `prepareStep` 分步處理 {/* #multi-step-approach-with-preparestep */}

如果模型無法同時使用工具及結構化輸出，可用 `prepareStep` 將兩者安排在不同步驟。

```typescript
const result = await agent.stream('weather in vancouver?', {
  prepareStep: async ({ stepNumber }) => {
    if (stepNumber === 0) {
      return {
        model: '__GATEWAY_OPENAI_MODEL__',
        tools: {
          weatherTool,
        },
        toolChoice: 'required',
      }
    }
    return {
      model: '__GATEWAY_OPENAI_MODEL__',
      tools: undefined,
      structuredOutput: {
        schema: z.object({
          temperature: z.number(),
          humidity: z.number(),
          windSpeed: z.number(),
        }),
      },
    }
  },
})
```

## 處理錯誤 {/* #handle-errors */}

schema 驗證失敗，或獨立處理結構化輸出的模型失敗時，可用 `errorStrategy` 指定處理方式。預設的 `strict` 會擲出錯誤；`warn` 會記錄警告後繼續；`fallback` 會回傳 `fallbackValue` 提供的值，並在結果中標記 `usedFallbackValue: true`，方便區分替代物件和模型產生的結果。

```typescript
const response = await testAgent.generate('Tell me about TypeScript.', {
  structuredOutput: {
    schema: z.object({
      summary: z.string(),
      keyFeatures: z.array(z.string()),
    }),
    errorStrategy: 'fallback',
    fallbackValue: {
      summary: 'TypeScript is a typed superset of JavaScript',
      keyFeatures: ['Static typing', 'Compiles to JavaScript', 'Better tooling'],
    },
  },
})

console.log(response.object)
console.log(response.usedFallbackValue) // true when the fallback value was substituted
```
