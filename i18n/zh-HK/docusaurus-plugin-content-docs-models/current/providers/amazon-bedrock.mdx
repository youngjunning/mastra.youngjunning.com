Amazon Bedrock 可透過 AI SDK 使用。請安裝相應的 Provider 套件，以便在 Mastra 使用其模型。

有關此 Provider 的詳細文件，請參閱 [AI SDK Amazon Bedrock Provider 文件](https://ai-sdk.dev/providers/ai-sdk-providers/amazon-bedrock)。

Amazon Bedrock isn't a model router provider, so model strings like `amazon-bedrock/<model>` don't resolve. Pass a model instance from `@ai-sdk/amazon-bedrock` to the agent's `model` option instead.

To use Bedrock models through a model router string, use the full ID that [LLM Gateway](/models/providers/llmgateway-providers) lists, including its provider prefix, for example `llmgateway-providers/aws-bedrock/claude-opus-4-6`. Dropping the `llmgateway-providers/` prefix leaves an ID that doesn't resolve.

如要在 Mastra Agent 使用此 Provider，請參閱 [Agent 概覽文件](/docs/agents/overview)。
