Cloudflare AI Gateway 可透過 AI SDK 使用。請安裝相應的 Provider 套件，以便在 Mastra 使用其模型。

有關此 Provider 的詳細文件，請參閱 [AI SDK Cloudflare AI Gateway Provider 文件](https://ai-sdk.dev/providers/community-providers/cloudflare-ai-gateway)。

Cloudflare AI Gateway 未有接入模型路由器，因此 `cloudflare-ai-gateway/<model>` 這類模型字串無法解析。請將 `ai-gateway-provider` 提供的模型實例傳入 Agent 的 `model` 選項。

如要在 Mastra Agent 使用此 Provider，請參閱 [Agent 概覽文件](/docs/agents/overview)。
