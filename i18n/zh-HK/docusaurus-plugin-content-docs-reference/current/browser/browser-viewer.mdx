# BrowserViewer

`BrowserViewer` 類別為 CLI 工具提供瀏覽器自動化。它透過 Playwright 啟動 Chrome，並提供 Chrome DevTools Protocol（CDP）URL。透過 Workspace 工具執行 CLI 指令時，它會自動注入此 URL。

如果 Agent 使用 `BrowserViewer` 透過 `browser-use`、`agent-browser` 或 `browse` 等 CLI 工具操作瀏覽器，請使用此類別。如要透過 SDK 自動化瀏覽器，請使用 [`AgentBrowser`](/reference/browser/agent-browser) 或 [`StagehandBrowser`](/reference/browser/stagehand-browser)。

## 使用範例 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { Workspace, LocalSandbox } from '@mastra/core/workspace'
import { Memory } from '@mastra/memory'
import { BrowserViewer } from '@mastra/browser-viewer'
import { Agent } from '@mastra/core/agent'

const workspace = new Workspace({
  sandbox: new LocalSandbox({
    workingDirectory: './workspace',
  }),
  browser: new BrowserViewer({
    cli: 'browser-use',
    headless: false,
  }),
})

const browserAgent = new Agent({
  id: 'browser-agent',
  model: '__GATEWAY_OPENAI_MODEL__',
  workspace,
  instructions: 'You are a web automation assistant.',
  memory: new Memory(),
})
```

### 連接到現有瀏覽器 {/* #connecting-to-an-existing-browser */}

```typescript
const viewer = new BrowserViewer({
  cli: 'browser-use',
  cdpUrl: 'ws://127.0.0.1:9222/devtools/browser/abc123',
})
```

提供 `cdpUrl` 時，`BrowserViewer` 會連接現有瀏覽器，而不會啟動新的瀏覽器。範圍預設為 `'shared'`。

## 方法 {/* #methods */}

### 生命週期 {/* #lifecycle */}

#### `launch(threadId?)` {/* #launchthreadid */}

對於 `'shared'` 範圍，啟動一個共用的 Chrome 瀏覽器；對於 `'thread'` 範圍，則為指定執行緒啟動瀏覽器。

```typescript
await viewer.launch()
await viewer.launch('thread-123')
```

#### `ensureReady()` {/* #ensureready */}

確保瀏覽器已啟動並就緒。對於 `'thread'` 範圍，必要時會為目前執行緒建立新瀏覽器。

```typescript
await viewer.ensureReady()
```

#### `isBrowserRunning(threadId?)` {/* #isbrowserrunningthreadid */}

檢查瀏覽器是否正在運行。對於 `'thread'` 範圍，檢查指定執行緒。

```typescript
const running = viewer.isBrowserRunning()
const threadRunning = viewer.isBrowserRunning('thread-123')
```

返回：`boolean`

#### `close()` {/* #close */}

關閉所有瀏覽器執行個體並清理資源。

```typescript
await viewer.close()
```

### CDP 訪問 {/* #cdp-access */}

#### `getCdpUrl(threadId?)` {/* #getcdpurlthreadid */}

傳回目前或指定執行緒的 CDP WebSocket URL。CLI 工具透過此 URL 連接受管理的瀏覽器。

```typescript
const cdpUrl = viewer.getCdpUrl()
// => 'ws://127.0.0.1:52481/devtools/browser/abc...'
```

返回：`string | null`

#### `connectToExternalCdp(cdpUrl, threadId?)` {/* #connecttoexternalcdpcdpurl-threadid */}

透過 CDP URL 連接外部瀏覽器以傳送畫面。當 Agent 提供自己的瀏覽器端點（例如雲端瀏覽器服務）時使用。BrowserViewer 只連接畫面傳送，不管理瀏覽器生命週期。

```typescript
await viewer.connectToExternalCdp('wss://cloud.example.com/session', 'thread-123')
```

### 瀏覽器畫面傳送 {/* #screencast */}

#### `startScreencast(options?)` {/* #startscreencastoptions */}

開始串流傳送瀏覽器畫面。傳回會發出畫面事件的 `ScreencastStream`。分頁切換時會建立新的 CDP 工作階段，自動處理切換。

```typescript
const stream = await viewer.startScreencast({
  format: 'jpeg',
  quality: 80,
})

stream.on('frame', frame => {
  console.log('Frame received:', frame.data.length, 'bytes')
})

stream.on('stop', reason => {
  console.log('Screencast stopped:', reason)
})
```

返回：`Promise<ScreencastStream>`

### 輸入註入 {/* #input-injection */}

#### `injectMouseEvent(params, threadId?)` {/* #injectmouseeventparams-threadid */}

透過 CDP 將滑鼠事件注入瀏覽器，供 Studio 即時互動使用。

```typescript
await viewer.injectMouseEvent({
  type: 'mousePressed',
  x: 100,
  y: 200,
  button: 'left',
  clickCount: 1,
})
```

#### `injectKeyboardEvent(params, threadId?)` {/* #injectkeyboardeventparams-threadid */}

透過 CDP 將鍵盤事件注入瀏覽器，供 Studio 即時互動使用。

```typescript
await viewer.injectKeyboardEvent({
  type: 'keyDown',
  key: 'Enter',
  code: 'Enter',
})
```

## 支援的 CLI {/* #supported-clis */}

每個 CLI 都需要獨立安裝。每個 CLI 亦發布介紹其指令和工作流程的[Skill](/docs/sandbox/skills)。透過 `workspace_execute_command` 執行 CLI 指令時，Mastra 會識別它，並自動以正確參數注入 CDP URL。

與透過 SDK 運作的提供者不同，`BrowserViewer` 不提供 Agent Tool。Agent 改用 `workspace_execute_command` 執行 CLI 指令。

### [`agent-browser`](https://www.npmjs.com/package/agent-browser) {/* #agent-browser */}

設定值：`'agent-browser'` · CDP 參數：`--cdp`

```bash
npm install -g agent-browser
npx skills add vercel-labs/agent-browser
```

### [`browser-use`](https://pypi.org/project/browser-use/) {/* #browser-use */}

設定值：`'browser-use'` · CDP 參數：`--cdp-url`

```bash
pip install browser-use
npx skills add browser-use/browser-use --skill browser-use
```

### [`browse`](https://www.npmjs.com/package/browse)（指令：`browse`） {/* #browse-command-browse */}

設定值：`'browse'` · CDP 參數：`--ws`

```bash
npm install -g browse
browse skills install
```
