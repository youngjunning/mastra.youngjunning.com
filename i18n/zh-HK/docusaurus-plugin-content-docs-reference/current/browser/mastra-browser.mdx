# MastraBrowser 類

`MastraBrowser` 是瀏覽器自動化 Provider 的抽象基類。其共通介面涵蓋瀏覽器啟動、線程隔離、畫面串流與輸入事件。

不要直接建立 `MastraBrowser` 實例，請使用具體的 Provider 實作：

* [`AgentBrowser`](/reference/browser/agent-browser)：使用 ref 執行具確定性的瀏覽器自動化
* [`StagehandBrowser`](/reference/browser/stagehand-browser)：透過自然語言執行 AI 驅動的瀏覽器自動化
* [`BrowserViewer`](/reference/browser/browser-viewer)：透過 CLI 執行瀏覽器自動化，並支援注入 CDP URL

## 使用範例 {/* #usage-example */}

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { AgentBrowser } from '@mastra/agent-browser'

const browser = new AgentBrowser({
  headless: true,
  viewport: { width: 1280, height: 720 },
  scope: 'thread',
})

export const browserAgent = new Agent({
  id: 'browser-agent',
  name: 'Browser Agent',
  instructions: 'You can browse the web to find information.',
  model: '__GATEWAY_OPENAI_MODEL__',
  browser,
})
```

## 方法 {/* #methods */}

### 生命週期 {/* #lifecycle */}

#### `ensureReady()` {/* #ensureready */}

確保瀏覽器已啟動且可使用。執行工具前會自動調用，由基類實作。

```typescript
await browser.ensureReady()
```

#### `close()` {/* #close */}

關閉瀏覽器並清理所有資源。基類的實作已妥善處理競爭條件。

```typescript
await browser.close()
```

#### `isBrowserRunning()` {/* #isbrowserrunning */}

檢查瀏覽器目前是否正在運作。

```typescript
const isRunning = browser.isBrowserRunning()
```

**返回：** `boolean`

### 線程管理 {/* #thread-management */}

#### `setCurrentThread(threadId)` {/* #setcurrentthreadthreadid */}

設定瀏覽器操作所使用的目前線程 ID，供 Agent 運行時內部使用。

```typescript
browser.setCurrentThread('thread-123')
```

#### `getCurrentThread()` {/* #getcurrentthread */}

取得目前的線程 ID。

```typescript
const threadId = browser.getCurrentThread()
```

**返回：** `string`

#### `hasThreadSession(threadId)` {/* #hasthreadsessionthreadid */}

檢查指定線程是否有使用中的瀏覽器工作階段。

```typescript
const hasSession = browser.hasThreadSession('thread-123')
```

**返回：** `boolean`

#### `closeThreadSession(threadId)` {/* #closethreadsessionthreadid */}

關閉指定線程的瀏覽器工作階段。在 'thread' scope 下，會關閉該線程的瀏覽器實例；在 'shared' scope 下，則會清除該線程的狀態。

```typescript
await browser.closeThreadSession('thread-123')
```

### Cookie {/* #cookies */}

#### `setCookies(cookies, threadId?)` {/* #setcookiescookies-threadid */}

將 Cookie 加入線程的瀏覽器。當應用程式能登入網站、Agent 卻無法登入時（例如預覽頁面需要應用程式本身的登入狀態），可使用此方法。Cookie 值不會經過模型。如果該線程的瀏覽器尚未開啟，Cookie 會在開啟時加入。省略 `threadId` 時，會使用目前的線程。

```typescript
await browser.setCookies(
  [
    {
      name: 'my_app_session',
      value: sessionToken,
      domain: 'app.example.com',
      path: '/',
      httpOnly: true,
      secure: true,
    },
  ],
  threadId,
)
```

每個 Cookie 都是 `BrowserCookie`，來自 `@mastra/core/browser`：包含 `name`、`value`，以及 `url` 或 `domain` 與 `path`；也可包含 `expires`（Unix 時間，以秒為單位）、`httpOnly`、`secure` 和 `sameSite`。若要涵蓋子網域，請讓 `domain` 以點號開頭（`.example.com`）。

在 `'thread'` scope 下，Cookie 只會加入對應線程的瀏覽器。在 `'shared'` scope 下，所有線程共用一個瀏覽器，因此每個線程都能使用這些 Cookie。

尚未加入瀏覽器的 Cookie 會在調用 `close()` 時捨棄；在 `'thread'` scope 下，調用 `closeThreadSession()` 關閉對應線程時也會捨棄。在 `'shared'` scope 下，它們會保留到共用瀏覽器開啟為止。

Cookie 必須提供 `url`，或同時提供 `domain` 和 `path`；否則 `setCookies` 會拋出錯誤。

`AgentBrowser`、`BrowserViewer`、`FirecrawlBrowser` 和 `StagehandBrowser` 支援 Cookie；其他 Provider 會拋出錯誤。

**返回：** `Promise<void>`

### 工具 {/* #tools */}

#### `getTools()` {/* #gettools */}

傳回供 Agent 使用的瀏覽器工具。各 Provider 會按其模型提供不同工具。

```typescript
const tools = browser.getTools()
```

**返回：** `Record<string, Tool>`

### 畫面串流 {/* #screencast */}

#### `startScreencast(options?)` {/* #startscreencastoptions */}

開始串流瀏覽器畫面，傳回會發出影格事件的 `ScreencastStream`。

```typescript
const stream = await browser.startScreencast({ format: 'jpeg', quality: 80 })

stream.on('frame', frame => {
  console.log('Frame received:', frame.data.length, 'bytes')
})

stream.on('stop', reason => {
  console.log('Screencast stopped:', reason)
})
```

**返回：** `Promise<ScreencastStream>`

### 輸入注入 {/* #input-injection */}

#### `injectMouseEvent(params, threadId?)` {/* #injectmouseeventparams-threadid */}

將滑鼠事件注入瀏覽器，供 Studio 進行即時互動。

```typescript
await browser.injectMouseEvent({
  type: 'mousePressed',
  x: 100,
  y: 200,
  button: 'left',
  clickCount: 1,
})
```

#### `injectKeyboardEvent(params, threadId?)` {/* #injectkeyboardeventparams-threadid */}

將鍵盤事件注入瀏覽器，供 Studio 進行即時互動。

```typescript
await browser.injectKeyboardEvent({
  type: 'keyDown',
  key: 'Enter',
  code: 'Enter',
})
```

### 狀態 {/* #state */}

#### `getBrowserState(threadId?)` {/* #getbrowserstatethreadid */}

取得目前瀏覽器狀態，包括已開啟的分頁及使用中分頁的索引。沒有可用狀態時傳回 `null`。

```typescript
const state = await browser.getBrowserState('thread-123')
if (state) {
  console.log('Active tab:', state.tabs[state.activeTabIndex]?.url)
  console.log('Tabs:', state.tabs)
}
```

**返回：** `Promise<BrowserState | null>`

```typescript
interface BrowserState {
  tabs: BrowserTabState[]
  activeTabIndex: number
  closeReason?: 'agent' | 'user' | 'process_restart' | 'error'
  activeUrlChangeSource?: 'agent' | 'user'
}

interface BrowserTabState {
  url: string
  title?: string
}
```

#### `getCurrentUrl(threadId?)` {/* #getcurrenturlthreadid */}

取得目前頁面的 URL。

```typescript
const url = await browser.getCurrentUrl()
```

**返回：** `Promise<string | null>`

## 瀏覽器 scope {/* #browser-scope */}

`scope` 選項控制瀏覽器實例在對話線程之間的共用方式：

| Scope | 說明 | 適用情境 |
| - | - | - |
| `'shared'` | 所有線程共用一個瀏覽器實例 | 適用於互不衝突的任務，可節省資源 |
| `'thread'` | 每個線程各有一個瀏覽器實例 | 為並行使用者提供完整隔離 |

```typescript
// Shared browser for all threads
const sharedBrowser = new AgentBrowser({
  scope: 'shared',
})

// Isolated browser per thread
const isolatedBrowser = new AgentBrowser({
  scope: 'thread',
})
```

透過 `cdpUrl` 連接外部瀏覽器時，由於無法建立新的瀏覽器實例，scope 會自動退回 `'shared'`。

## 雲端瀏覽器 Provider {/* #cloud-browser-providers */}

使用 `cdpUrl` 選項連接雲端瀏覽器服務：

```typescript
// Static CDP URL
const browser = new AgentBrowser({
  cdpUrl: 'wss://browser.example.com/ws',
})

// Dynamic CDP URL (e.g., session-based)
const browser = new AgentBrowser({
  cdpUrl: async () => {
    const session = await createBrowserSession()
    return session.wsUrl
  },
})
```
