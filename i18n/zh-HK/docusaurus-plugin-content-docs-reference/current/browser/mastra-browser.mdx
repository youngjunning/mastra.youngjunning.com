# MastraBrowser 類

這`MastraBrowser`class 是瀏覽器自動化提供者的抽象基底類別。其通用介面涵蓋瀏覽器啟動和執行緒隔離，以及截圖流和輸入事件。

你沒有實例化`MastraBrowser` directly. Instead, use a provider implementation:

* [`AgentBrowser`](/reference/browser/agent-browser)：使用 refs 確定性瀏覽器自動化
* [`StagehandBrowser`](/reference/browser/stagehand-browser)：使用自然語言的人工智慧驅動的瀏覽器自動化
* [`BrowserViewer`](/reference/browser/browser-viewer)：基於 CLI 的瀏覽器自動化，具有 CDP URL 注入

## 使用範例 {/* #usage-example */}

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { AgentBrowser } from '@mastra/agent-browser'

const browser = new AgentBrowser({
  headless: true,
  viewport: { width: 1280, height: 720 },
  scope: 'thread',
})

export const browserAgent = new Agent({
  id: 'browser-agent',
  name: 'Browser Agent',
  instructions: 'You can browse the web to find information.',
  model: '__GATEWAY_OPENAI_MODEL__',
  browser,
})
```

## 方法 {/* #methods */}

### 生命週期 {/* #lifecycle */}

#### `ensureReady()` {/* #ensureready */}

確保瀏覽器已啟動並可供使用。在Tool執行之前自動呼叫。在基類中實作。

```typescript
await browser.ensureReady()
```

#### `close()` {/* #close */}

關閉瀏覽器並清理所有資源。在基類中實現，具有競爭條件安全處理。

```typescript
await browser.close()
```

#### `isBrowserRunning()` {/* #isbrowserrunning */}

檢查瀏覽器目前是否正在運作。

```typescript
const isRunning = browser.isBrowserRunning()
```

**返回：** `boolean`

### 執行緒管理 {/* #thread-management */}

#### `setCurrentThread(threadId)` {/* #setcurrentthreadthreadid */}

設定瀏覽器操作的目前執行緒 ID。由Agent運行時在內部使用。

```typescript
browser.setCurrentThread('thread-123')
```

#### `getCurrentThread()` {/* #getcurrentthread */}

取得當前線程ID。

```typescript
const threadId = browser.getCurrentThread()
```

**返回：** `string`

#### `hasThreadSession(threadId)` {/* #hasthreadsessionthreadid */}

檢查線程是否有活動的瀏覽器會話。

```typescript
const hasSession = browser.hasThreadSession('thread-123')
```

**返回：** `boolean`

#### `closeThreadSession(threadId)` {/* #closethreadsessionthreadid */}

關閉特定執行緒的瀏覽器會話。對於「執行緒」範圍，它會關閉該執行緒的瀏覽器實例。對於“共享”範圍，它會清除線程狀態。

```typescript
await browser.closeThreadSession('thread-123')
```

### 餅乾 {/* #cookies */}

#### `setCookies(cookies, threadId?)` {/* #setcookiescookies-threadid */}

將 cookie 新增至執行緒的瀏覽器。當您的應用程式可以登入網站但Agent無法登入時使用它，例如您自己登入後的預覽。 cookie 值永遠不會通過模型。如果執行緒的瀏覽器尚未打開，則在開啟時新增 cookie。什麼時候`threadId` is omitted, the current thread is used.

```typescript
await browser.setCookies(
  [
    {
      name: 'my_app_session',
      value: sessionToken,
      domain: 'app.example.com',
      path: '/',
      httpOnly: true,
      secure: true,
    },
  ],
  threadId,
)
```

每個 cookie 都是一個`BrowserCookie` from `@mastra/core/browser`: `name` and `value`, plus either `url` or `domain` and `path`, and optionally `expires` (Unix time in seconds), `httpOnly`, `secure` and `sameSite`. To cover subdomains, start `domain` with a dot (`.example.com`).

和`'thread'` scope, the cookies reach only that thread's browser. With `'shared'` scope every thread uses one browser, so they reach every thread.

當您呼叫時，仍在等待瀏覽器的 Cookie 會被刪除`close()`, and with `'thread'` scope when you close that thread with `closeThreadSession()`. With `'shared'` scope they stay until the shared browser opens.

Cookie 必須具有`url` or both `domain` and `path`; otherwise, `setCookies` throws.

`AgentBrowser`, `BrowserViewer`, `FirecrawlBrowser` and `StagehandBrowser` support cookies. Other providers throw.

**返回：** `Promise<void>`

### Tool {/* #tools */}

#### `getTools()` {/* #gettools */}

傳回與Agent程式一起使用的瀏覽器Tool。每個提供者根據其型號返回不同的Tool。

```typescript
const tools = browser.getTools()
```

**返回：** `Record<string, Tool>`

### 螢幕截圖影片 {/* #screencast */}

#### `startScreencast(options?)` {/* #startscreencastoptions */}

開始串流瀏覽器框架。返回一個`ScreencastStream` that emits frame events.

```typescript
const stream = await browser.startScreencast({ format: 'jpeg', quality: 80 })

stream.on('frame', frame => {
  console.log('Frame received:', frame.data.length, 'bytes')
})

stream.on('stop', reason => {
  console.log('Screencast stopped:', reason)
})
```

**返回：** `Promise<ScreencastStream>`

### 輸入註入 {/* #input-injection */}

#### `injectMouseEvent(params, threadId?)` {/* #injectmouseeventparams-threadid */}

將滑鼠事件注入瀏覽器。 Studio 用於即時互動。

```typescript
await browser.injectMouseEvent({
  type: 'mousePressed',
  x: 100,
  y: 200,
  button: 'left',
  clickCount: 1,
})
```

#### `injectKeyboardEvent(params, threadId?)` {/* #injectkeyboardeventparams-threadid */}

将键盘事件注入浏览器。 Studio 用於即時互動。

```typescript
await browser.injectKeyboardEvent({
  type: 'keyDown',
  key: 'Enter',
  code: 'Enter',
})
```

### 狀態 {/* #state */}

#### `getBrowserState(threadId?)` {/* #getbrowserstatethreadid */}

取得目前瀏覽器狀態，包括開啟的選項卡和活動標籤索引。退貨`null` when no state is available.

```typescript
const state = await browser.getBrowserState('thread-123')
if (state) {
  console.log('Active tab:', state.tabs[state.activeTabIndex]?.url)
  console.log('Tabs:', state.tabs)
}
```

**返回：** `Promise<BrowserState | null>`

```typescript
interface BrowserState {
  tabs: BrowserTabState[]
  activeTabIndex: number
  closeReason?: 'agent' | 'user' | 'process_restart' | 'error'
  activeUrlChangeSource?: 'agent' | 'user'
}

interface BrowserTabState {
  url: string
  title?: string
}
```

#### `getCurrentUrl(threadId?)` {/* #getcurrenturlthreadid */}

取得目前頁面的 URL。

```typescript
const url = await browser.getCurrentUrl()
```

**返回：** `Promise<string | null>`

## 瀏覽器範圍 {/* #browser-scope */}

這`scope` option controls how browser instances are shared across conversation threads:

|範圍 |描述 |使用案例|
| - | - | - |
|`'shared'` | All threads share a single browser instance | Cost-efficient for non-conflicting tasks |
| `'thread'` | Each thread gets its own browser instance | Full isolation for concurrent users |

```typescript
// Shared browser for all threads
const sharedBrowser = new AgentBrowser({
  scope: 'shared',
})

// Isolated browser per thread
const isolatedBrowser = new AgentBrowser({
  scope: 'thread',
})
```

使用時`cdpUrl` to connect to an external browser, the scope automatically falls back to `'shared'` since you can't spawn new browser instances.

## 雲端瀏覽器Provider {/* #cloud-browser-providers */}

使用以下方式連線到雲端瀏覽器服務`cdpUrl` option:

```typescript
// Static CDP URL
const browser = new AgentBrowser({
  cdpUrl: 'wss://browser.example.com/ws',
})

// Dynamic CDP URL (e.g., session-based)
const browser = new AgentBrowser({
  cdpUrl: async () => {
    const session = await createBrowserSession()
    return session.wsUrl
  },
})
```
