# 馬斯特拉之聲

MastraVoice 類別是一個抽象基底類，它定義了 Mastra 中語音服務的核心介面。所有語音提供者實作（例如 OpenAI、Deepgram、PlayAI、Speechify）都擴展此類以提供其特定功能。該類別現在包括透過 WebSocket 連線支援即時語音到語音功能。

## 使用範例 {/* #usage-example */}

```typescript
import { MastraVoice } from '@mastra/core/voice'

// Create a voice provider implementation
class MyVoiceProvider extends MastraVoice {
  constructor(config: {
    speechModel?: BuiltInModelConfig
    listeningModel?: BuiltInModelConfig
    speaker?: string
    realtimeConfig?: {
      model?: string
      apiKey?: string
      options?: unknown
    }
  }) {
    super({
      speechModel: config.speechModel,
      listeningModel: config.listeningModel,
      speaker: config.speaker,
      realtimeConfig: config.realtimeConfig,
    })
  }

  // Implement required abstract methods
  async speak(
    input: string | NodeJS.ReadableStream,
    options?: { speaker?: string },
  ): Promise<NodeJS.ReadableStream | void> {
    // Implement text-to-speech conversion
  }

  async listen(
    audioStream: NodeJS.ReadableStream,
    options?: unknown,
  ): Promise<string | NodeJS.ReadableStream | void> {
    // Implement speech-to-text conversion
  }

  async getSpeakers(): Promise<Array<{ voiceId: string; [key: string]: unknown }>> {
    // Return list of available voices
  }

  // Optional speech-to-speech methods
  async connect(): Promise<void> {
    // Establish WebSocket connection for speech-to-speech communication
  }

  async send(audioData: NodeJS.ReadableStream | Int16Array): Promise<void> {
    // Stream audio data in speech-to-speech
  }

  async answer(): Promise<void> {
    // Trigger voice provider to respond
  }

  addTools(tools: Array<unknown>): void {
    // Add tools for the voice provider to use
  }

  close(): void {
    // Close WebSocket connection
  }

  on(event: string, callback: (data: unknown) => void): void {
    // Register event listener
  }

  off(event: string, callback: (data: unknown) => void): void {
    // Remove event listener
  }
}
```

## 抽象方法 {/* #abstract-methods */}

這些方法必須由擴展 MastraVoice 的未知類別來實作。

### `speak()` {/* #speak */}



```typescript oxfmt:false
abstract speak(
  input: string | NodeJS.ReadableStream,
  options?: {
    speaker?: string;
    [key: string]: unknown;
  }
): Promise<NodeJS.ReadableStream | void>
```

目的：

* 取得文字輸入並使用提供者的文字轉語音服務將其轉換為語音
* 支援字串和流輸入以實現靈活性
* 允許透過選項覆蓋預設揚聲器/語音
* 返回可以播放或儲存的音訊資料流
* 如果透過發出「說話」事件處理音頻，可能會返回 void

### `listen()` {/* #listen */}

使用配置的聆聽模型將語音轉換為文字。

```typescript oxfmt:false
abstract listen(
  audioStream: NodeJS.ReadableStream | unknown,
  options?: {
    [key: string]: unknown;
  }
): Promise<string | NodeJS.ReadableStream | void>
```

目的：

* 取得音訊串流（或其他特定於提供者的音訊輸入）並使用提供者的語音到文字服務將其轉換為文字
* 支援特定於提供者的轉錄配置選項
* 可以返回完整的文字轉錄或轉錄文字流
* 並非所有提供者都支援此功能（例如 PlayAI、Speechify）
* 如果透過發出「寫入」事件處理轉錄，則可能傳回 void

## 可選方法 {/* #optional-methods */}



### `getSpeakers()` {/* #getspeakers */}

傳回提供者支援的可用語音清單。

```typescript oxfmt:false
getSpeakers(): Promise<Array<{ voiceId: string; [key: string]: unknown }>>
```

目的：

* 從提供者檢索可用語音/發言人的列表
*
* 每個語音必須至少有一個 voiceId 屬性
* 提供者可以包含有關每個語音的附加元數據
* 用於發現可用於文字轉語音轉換的語音

### `connect()` {/* #connect */}

建立 WebSocket 或 WebRTC 連線進行通訊。

```typescript oxfmt:false
connect(config?: unknown): Promise<void>
```

目的：

* 初始化與語音服務的連接以進行通信
* 必須在使用 send() 或answer() 等功能之前調用
* 傳回一個在連線建立時解析的 Promise
* 配置是特定於提供者的

### `send()` {/* #send */}

將音訊資料即時傳輸到語音提供者。

```typescript oxfmt:false
send(audioData: NodeJS.ReadableStream | Int16Array): Promise<void>
```

目的：

* 將音訊資料傳送至語音提供者進行即時處理
* 適用於連續音訊串流場景，例如即時麥克風輸入
* 支援 ReadableStream 和 Int16Array 音訊格式
* 在呼叫此方法之前必須處於連線狀態

### `answer()` {/* #answer */}

觸發語音提供者產生回應。

```typescript oxfmt:false
answer(options?: Record<string, unknown>): Promise<void>
```

目的：

* 向語音提供者發送訊號以產生回應
* 接受可選的特定於提供者的選項
* 用於即時對話，提示AI做出回應
* 回應將透過事件系統發出（例如，「說話」事件）

### `addTools()` {/* #addtools */}

為語音提供者配備可在對話期間使用的Tool。

```typescript oxfmt:false
addTools(tools: Array<Tool>): void
```

目的：

* 新增語音提供者可以在對話期間使用的Tool
* Tool可以擴展語音提供者的功能
* 實施是特定於提供者的

### `close()` {/* #close */}

中斷 WebSocket 或 WebRTC 連線。

```typescript oxfmt:false
close(): void
```

目的：

* 關閉與語音服務的連接
* 清理資源並停止任何正在進行的即時處理
* 當您完成語音實例時應該調用

### `on()` {/* #on */}

註冊語音事件的事件偵聽器。

```typescript oxfmt:false
on<E extends VoiceEventType>(
  event: E,
  callback: (data: E extends keyof VoiceEventMap ? VoiceEventMap[E] : unknown) => void,
): void
```

目的：

* 註冊一個回呼函數，當指定事件發生時調用
* 標準事件包括“說”、“寫”和“錯誤”
* 提供者也可以發出自訂事件
* 事件資料結構取決於事件類型

### `off()` {/* #off */}

刪除事件偵聽器。

```typescript oxfmt:false
off<E extends VoiceEventType>(
  event: E,
  callback: (data: E extends keyof VoiceEventMap ? VoiceEventMap[E] : unknown) => void,
): void
```

目的：

* 刪除先前註冊的事件監聽器
* 用於在不再需要事件處理程序時清理它們

## 遙測支援 {/* #telemetry-support */}

MastraVoice 包括內建遙測支持`traced` method, which wraps method calls with performance tracking and error monitoring.

## 筆記 {/* #notes */}

* MastraVoice是一個抽象類，不能直接實例化
* 實現必須提供抽象的具體實現`speak()` and `listen()` methods
* 此類別在不同的語音服務提供者之間提供一致的接口
* 語音轉語音功能是可選的且特定於提供者
* 事件系統支援異步通信，實現即時交互
* 自動處理所有方法呼叫的遙測
