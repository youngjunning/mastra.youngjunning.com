# 語音事件

語音提供者在即時語音互動期間發出事件。可以使用以下命令監聽這些事件[voice.on()](./voice.on)方法，對於建立互動式語音應用程式尤其重要。

## 筆記 {/* #notes */}

* 並非所有語音提供者都支援所有事件
* 確切的有效負載結構可能因提供者而異
* 對於非即時提供程序，大多數事件不會被發出
* 事件對於建立響應對話狀態的互動式 UI 非常有用
* 考慮使用[voice.off()](./voice.off) method to remove event listeners when they're no longer needed
