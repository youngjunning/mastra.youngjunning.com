# 聲音.listen()

這`listen()`方法是所有 Mastra 語音提供者都提供的將語音轉換為文字的核心功能。它將音訊串流作為輸入並返回轉錄的文字。

## 傳回值 {/* #return-value */}

傳回下列值之一：

* `Promise<string>`：解析為轉錄文本的承諾
* `Promise<NodeJS.ReadableStream>`：解析為轉錄文字流的承諾（用於流轉錄）
* `Promise<void>`：對於發出“寫入”事件而不是直接返回文字的即時提供程序

## 使用範例 {/* #usage-example */}

```typescript
import { OpenAIVoice } from '@mastra/voice-openai'
import { getMicrophoneStream } from '@mastra/node-audio'
import { createReadStream } from 'fs'
import path from 'path'

// Initialize a voice provider
const voice = new OpenAIVoice({
  listeningModel: {
    name: 'whisper-1',
    apiKey: process.env.OPENAI_API_KEY,
  },
})

// Basic usage with a file stream
const audioFilePath = path.join(process.cwd(), 'audio.mp3')
const audioStream = createReadStream(audioFilePath)
const transcript = await voice.listen(audioStream, {
  filetype: 'mp3',
})
console.log('Transcribed text:', transcript)

// Using a microphone stream
const microphoneStream = getMicrophoneStream() // Assume this function gets audio input
const transcription = await voice.listen(microphoneStream)

// With provider-specific options
const transcriptWithOptions = await voice.listen(audioStream, {
  language: 'en',
  prompt: 'This is a conversation about artificial intelligence.',
})
```

## 與使用`CompositeVoice` {/* #using-with-compositevoice */}

使用時`CompositeVoice`, the `listen()` method delegates to the configured listening provider:

```typescript
import { CompositeVoice } from '@mastra/core/voice'
import { OpenAIVoice } from '@mastra/voice-openai'
import { PlayAIVoice } from '@mastra/voice-playai'

const voice = new CompositeVoice({
  input: new OpenAIVoice(),
  output: new PlayAIVoice(),
})

// This will use the OpenAIVoice provider
const transcript = await voice.listen(audioStream)
```

### 使用AI SDK模型提供者 {/* #using-ai-sdk-model-providers */}

您也可以直接使用 AI SDK 轉錄模型`CompositeVoice`:

```typescript
import { CompositeVoice } from '@mastra/core/voice'
import { openai } from '@ai-sdk/openai'
import { groq } from '@ai-sdk/groq'

// Use AI SDK transcription models
const voice = new CompositeVoice({
  input: openai.transcription('whisper-1'), // AI SDK model
  output: new PlayAIVoice(), // Mastra provider
})

// Works the same way
const transcript = await voice.listen(audioStream)

// Provider-specific options can be passed through
const transcriptWithOptions = await voice.listen(audioStream, {
  providerOptions: {
    openai: {
      language: 'en',
      prompt: 'This is about AI',
    },
  },
})
```

請參閱[CompositeVoice reference](/reference/voice/composite-voice) for more details on AI SDK integration.

## 即時語音提供者 {/* #realtime-voice-providers */}

當使用即時語音提供者時，例如`OpenAIRealtimeVoice`, the `listen()` method behaves differently:

* 它不返回轉錄文本，而是使用轉錄文本發出“寫入”事件
* 您需要註冊一個事件監聽器來接收轉錄

```typescript
import { OpenAIRealtimeVoice } from '@mastra/voice-openai-realtime'
import { getMicrophoneStream } from '@mastra/node-audio'

const voice = new OpenAIRealtimeVoice()
await voice.connect()

// Register event listener for transcription
voice.on('writing', ({ text, role }) => {
  console.log(`${role}: ${text}`)
})

// This will emit 'writing' events instead of returning text
const microphoneStream = getMicrophoneStream()
await voice.listen(microphoneStream)
```

## 筆記 {/* #notes */}

* 並非所有語音提供者都支援語音轉文字功能（例如 PlayAI、Speechify）
* 的行為`listen()` may vary slightly between providers, but all implementations follow the same basic interface
* 使用即時語音提供者時，該方法可能不會直接返回文本，而是發出「寫入」事件
* 支援的音訊格式取決於提供者。常見格式包括 MP3、WAV 和 M4A
* 一些提供者支援流式轉錄，其中文字在轉錄時返回
* 為了獲得最佳性能，請考慮在完成後關閉或結束音訊串流
