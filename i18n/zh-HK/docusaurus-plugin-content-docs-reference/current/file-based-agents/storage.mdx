# 貯存

Mastra 設定項目的預設值[storage](/docs/storage)從一個`storage.ts`直接在下面的文件`src/mastra/`。該檔案預設導出一個存儲，它取代了用於記憶體、Workflow、可觀察性和其他存儲域的內建記憶體存儲。

使用此頁面進行基於文件的約定。有關後端選擇、存儲域、保留和提供者詳細信息，請參閱[storage overview](/docs/storage).

## 快速入門 {/* #quickstart */}

使用[`LibSQLStore`](/integrations/databases/libsql) for a local file-backed store:

```typescript title="src/mastra/storage.ts"
import { LibSQLStore } from '@mastra/libsql'

export default new LibSQLStore({
  id: 'mastra-storage',
  url: 'file:./mastra.db',
})
```

Mastra 在基於檔案的Agent和Workflow之前註冊存儲，因此依賴存儲的基元綁定到此存儲而不是預設的內存中存儲。

## 生產後端 {/* #production-backends */}

`storage.ts`可以匯出任何 Mastra 儲存適配器，例如 LibSQL、PostgreSQL 或 MongoDB。有關設定模式、提供者支援和架構詳細信息，請參閱[storage overview](/docs/storage), [observability signal support](/docs/observability/overview#signal-support), and the [storage reference](/reference/storage/overview).

## 程式碼優先權 {/* #precedence-with-code */}

代碼註冊儲存勝出`storage.ts`. Use `storage.ts` when one project-wide store is enough. Use code registration when setup depends on runtime wiring in `src/mastra/index.ts`.
