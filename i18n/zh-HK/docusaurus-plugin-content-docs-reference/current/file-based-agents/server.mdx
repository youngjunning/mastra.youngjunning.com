# 伺服器

Mastra 從 `src/mastra/` 目錄下的 `server.ts` 檔案讀取 HTTP [伺服器](/docs/server/overview)設定。伺服器以 REST 端點提供 Agent、Workflow 及其他已註冊的組件。檔案預設匯出的 `ServerConfig` 與傳入 [`new Mastra()`](/reference/core/mastra-class) 的設定結構相同。

這頁說明如何以檔案設定伺服器。有關伺服器功能、中介軟件、自訂路由、自動產生的 API 文件及部署行為，請參閱[伺服器概覽](/docs/server/overview)。

## 快速入門 {/* #quickstart */}

建立 `src/mastra/server.ts`，並以預設匯出的方式提供 `ServerConfig` 物件。

```typescript title="src/mastra/server.ts"
import type { ServerConfig } from '@mastra/core/server'

export default {
  port: 4111,
  host: '0.0.0.0',
} satisfies ServerConfig
```

## 常用設定 {/* #common-configurations */}

`server.ts` 支援與程式碼註冊相同的伺服器設定項目。

| 用途 | 設定項目 |
| - | - |
| 綁定至部署平台的位址 | `host` 和 `port` |
| 限制瀏覽器存取 | `cors` |
| 新增 Webhook 或健康檢查 | `apiRoutes` |
| 啟用自動產生 API 文件功能 | `build.openAPIDocs` 和 `build.swaggerUI` |

例子請參閱 [Mastra 伺服器](/docs/server/overview)、[中介軟件](/docs/server/middleware)及[自訂 API 路由](/docs/server/custom-api-routes)。

## 檔案與程式碼設定的優先次序 {/* #precedence-with-code */}

以程式碼註冊的伺服器設定優先於 `server.ts`。套用檔案式伺服器設定時，會保留啟動期間加入的路由，例如頻道 Webhook。
