# 可觀測性

Mastra 從 `src/mastra/` 目錄下的 `observability.ts` 檔案讀取[可觀測性](/docs/observability/overview)設定。檔案預設匯出的 `Observability` 實例會為專案設定追蹤、日誌、指標和回饋。

這頁說明如何以檔案設定可觀測性。有關訊號模型、匯出器、儲存及多組設定的詳情，請參閱[可觀測性概覽](/docs/observability/overview)及[可觀測性設定](/docs/observability/overview#configuration)。

## 快速入門 {/* #quickstart */}

建立 `src/mastra/observability.ts`，並以預設匯出的方式提供 `Observability` 實例。

```typescript title="src/mastra/observability.ts"
import { MastraStorageExporter, Observability } from '@mastra/observability'

export default new Observability({
  configs: {
    default: {
      serviceName: 'mastra',
      exporters: [new MastraStorageExporter()],
    },
  },
})
```

## 可觀測性與儲存 {/* #observability-and-storage */}

`observability.ts` 指定收集哪些訊號，以及匯出至何處。[`storage.ts`](/reference/file-based-agents/storage) 設定專案的儲存實例，以持久保存可觀測性記錄。各訊號的儲存支援詳情請參閱[可觀測性訊號支援](/docs/observability/overview#signal-support)。

## 檔案與程式碼設定的優先次序 {/* #precedence-with-code */}

以程式碼註冊的可觀測性設定優先於 `observability.ts`。整個專案共用一組設定時，可使用 `observability.ts`。若設定取決於執行時如何組合組件，請在 `src/mastra/index.ts` 以程式碼註冊。
