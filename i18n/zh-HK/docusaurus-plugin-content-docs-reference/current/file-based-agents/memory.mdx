# 記憶

檔案式 Agent 從 `memory.ts` 檔案取得[記憶體](/docs/memory/overview)，該檔案預設匯出一個 [`Memory`](/reference/memory/memory-class) 實例。本頁說明檔案式慣例；訊息記錄、語意回憶、儲存及處理器則請參閱記憶體文件。

如果沒有 `memory.ts` 或 `config.memory`，Agent 預設不具備記憶體。每次呼叫 `generate()` 或 `stream()` 時都不會保留先前的對話狀態，除非你自行傳入先前內容。

## 快速入門 {/* #quickstart */}

建立 `memory.ts`，並將其放在 Agent 的 `config.ts` 旁：

```typescript title="src/mastra/agents/weather/memory.ts"
import { Memory } from '@mastra/memory'

export default new Memory()
```

匯出的實例會成為 Agent 的 `memory`。如果應用程式在主要 Mastra 實例中設定了儲存 Provider，記憶體資料將儲存在該處。詳情請參閱[儲存](/docs/storage)。

呼叫 Agent 時使用相同的 `resource` 和 `thread` 值，即可延續對話：

```typescript title="src/app/weather-chat.ts"
const response = await weatherAgent.generate('Remember that I prefer Celsius.', {
  memory: {
    resource: 'user-123',
    thread: 'weather-chat',
  },
})
```

## 配置記憶體 {/* #configure-memory */}

預設行為不足以滿足需要時，可將選項傳入 `new Memory()`。

```typescript title="src/mastra/agents/weather/memory.ts"
import { Memory } from '@mastra/memory'

export default new Memory({
  options: {
    lastMessages: 20,
    workingMemory: {
      enabled: true,
      scope: 'resource',
    },
  },
})
```

建構函式選項請參閱 [`Memory` 參考文件](/reference/memory/memory-class)。相關記憶體功能請參閱以下頁面：

* [儲存](/docs/storage)：設定記憶體資料的持久化。
* [語意回憶](/docs/memory/semantic-recall)：透過語意檢索相關的過去訊息。
* [記憶體處理器](/docs/memory/memory-processors)：在記憶體將訊息新增至模型上下文之前過濾、修剪或轉換訊息。

## 配置的優先權 {/* #precedence-with-config */}

`config.memory` 的優先次序高於 `memory.ts`。如果兩者都不存在，組裝後的檔案式 Agent 將不具備記憶體。完整的合併規則請參閱 [`config.ts` 優先次序](/reference/file-based-agents/config#precedence)。
