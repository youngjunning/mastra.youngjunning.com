# 日誌記錄器

Mastra 從 `src/mastra/` 目錄下的 `logger.ts` 檔案讀取專案的[日誌記錄器](/docs/observability/logging)。這個檔案預設匯出的記錄器會取代 Agent、Workflow 及其他組件使用的內置 `ConsoleLogger`。

這頁說明如何以檔案設定記錄器。有關日誌級別、傳輸方式及 Provider 的詳情，請參閱[日誌記錄](/docs/observability/logging)。

## 快速入門 {/* #quickstart */}

建立 `src/mastra/logger.ts`，並以預設匯出的方式提供日誌記錄器，例如 [`PinoLogger`](/reference/logging/pino-logger)。

```typescript title="src/mastra/logger.ts"
import { PinoLogger } from '@mastra/loggers'

export default new PinoLogger({
  name: 'Mastra',
  level: 'info',
})
```

Mastra 會先註冊日誌記錄器，然後才設定儲存、可觀測性及檔案式 Agent。這些組件在初始化期間會經由該記錄器寫入日誌。

## 檔案與程式碼設定的優先次序 {/* #precedence-with-code */}

程式碼的日誌設定優先於 `logger.ts`。如果在 `src/mastra/index.ts` 以 `new Mastra({ logger })` 傳入 `logger`，或用 `logger: false` 停用日誌，Mastra 會略過 `logger.ts` 並發出警告。整個專案共用一個記錄器時，可使用 `logger.ts`。若設定取決於執行時如何組合組件，請在程式碼中註冊。
