# 記錄器

Mastra 設定了該專案的[logger](/docs/observability/logging)從一個`logger.ts`直接在下面的文件`src/mastra/`。該檔案預設導出一個記錄器，它取代了內建的`ConsoleLogger`跨Agent程式、Workflow和其他元件使用。

使用此頁面進行基於文件的約定。有關日誌等級、傳輸和提供程序詳細信息，請參閱[logging](/docs/observability/logging).

## 快速入門 {/* #quickstart */}

創造`src/mastra/logger.ts` and default-export a logger, such as [`PinoLogger`](/reference/logging/pino-logger):

```typescript title="src/mastra/logger.ts"
import { PinoLogger } from '@mastra/loggers'

export default new PinoLogger({
  name: 'Mastra',
  level: 'info',
})
```

Mastra 在儲存、可觀察性和基於檔案的Agent之前註冊記錄器。這些原語在連接時透過此記錄器進行記錄。

## 程式碼優先權 {/* #precedence-with-code */}

代碼註冊日誌勝出`logger.ts`. If you pass `logger` to `new Mastra({ logger })` in `src/mastra/index.ts` (or set `logger: false` to disable logging), `logger.ts` is ignored with a warning. Use `logger.ts` when one project-wide logger is enough. Use code registration when setup depends on runtime wiring.
