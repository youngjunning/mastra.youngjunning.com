# 指令

Agent 的指令包含常駐的系統提示，模型每回合都會讀取。可用它定義 Agent 的身分、語氣、角色及固定規則。

請將指令寫在 Agent 根目錄下的兩種檔案之一：固定文字使用 `instructions.md`；需要透過程式碼建立提示（例如使用共用常數或按請求動態產生）時使用 `instructions.ts`。

指令會一直保留在上下文中，因此只應放入適用於每個請求的固定行為。有條件、篇幅較長或涉及具體操作的內容，請移至 [`tools/`](/reference/file-based-agents/tools) 或 [`skills/`](/reference/file-based-agents/skills)；模型只會在相關時使用。

## 快速開始 {/* #quickstart */}

在 Agent 根目錄加入 `instructions.md`。檔案內容會直接成為提示，因此最簡版本只需一句話。

```markdown title="src/mastra/agents/weather/instructions.md"
You are a helpful weather assistant. Answer questions about current conditions and forecasts.
```

## 指令應包含甚麼 {/* #what-goes-in-instructions */}

有效的指令應涵蓋 Agent 在不同請求之間保持不變的行為：

- 角色與身分
- 語氣與風格
- 固定規則
- 輸出格式

有條件、篇幅較長或涉及具體操作的指引，請移至 [`tools/`](/reference/file-based-agents/tools) 或 [`skills/`](/reference/file-based-agents/skills)；模型只會在相關時使用。

## 在 TypeScript 中編寫指令 {/* #instructions-in-typescript */}

當 Markdown 無法表達所需提示時，使用 `instructions.ts`。檔案預設匯出字串、系統訊息、由字串或系統訊息組成的非空陣列，或傳回其中一種值的函式。`agentInstructions()` 只為匯出值提供類型，不會修改它。

當提示由程式碼組合時，可以匯出字串，例如使用與應用程式其他部分共用的常數：

```typescript title="src/mastra/agents/weather/instructions.ts"
import { agentInstructions } from '@mastra/core/agent'
import { SUPPORTED_UNITS } from '../../constants'

export default agentInstructions(`
You are a helpful weather assistant.
Report conditions using one of these units: ${SUPPORTED_UNITS.join(', ')}.
`)
```

當提示取決於請求時，可以匯出函式。Mastra 每回合都會呼叫它，並傳入請求脈絡：

```typescript title="src/mastra/agents/support/instructions.ts"
import { agentInstructions } from '@mastra/core/agent'

export default agentInstructions(({ requestContext }) => {
  const tier = requestContext.get('tier') ?? 'standard'
  return `You are a support agent. Treat this as a ${tier}-tier customer.`
})
```

此函式可以是 `async`。除了 `requestContext`，它亦會收到 Agent 註冊所在的 Mastra 實例 `mastra`，因此可在傳回提示前從儲存空間或其他已註冊元件讀取資料。函式類型中的 `mastra` 屬選用，使用前須檢查，例如 `mastra?.getStorage()`。

這兩種檔案也可以放在 [subagent](/reference/file-based-agents/subagents) 目錄中，規則相同。

## 建置時的行為 {/* #build-time-behavior */}

`instructions.md` 和 `instructions.ts` 會以不同方式進入已部署的 Agent：

- `instructions.md`：Mastra 在建置時讀取檔案，並將內容內嵌至產生的程式碼中。
- `instructions.ts`：產生的程式碼會匯入該模組，因此它與其他 TypeScript 檔案一樣參與封裝，也可以匯入項目中的其他模組。

執行 `mastra dev` 時，編輯任一檔案都會觸發重新建置。應用程式部署後，執行期間不會從磁碟讀取這兩種檔案；修改要到下次建置後才會生效。

## 與設定的優先次序 {/* #precedence-with-config */}

指令可以來自 `instructions.ts`、`instructions.md`，亦可以來自 `instructions` 欄位（位於 [`config.ts`](/reference/file-based-agents/config)）：

- 執行期間定義的函式形式 `instructions`（位於 `config.ts`）優先於兩種檔案。
- 否則，`instructions.ts` 優先於 `instructions.md`。
- `instructions.md` 優先於靜態的 `instructions` 字串（位於 `config.ts`）。
- 如果三者都不存在，建置會失敗，並指出 Agent 目錄。

如果在多個位置定義指令，系統會記錄警告，列出衝突來源及生效的來源。每個 Agent 只保留一個指令來源。
