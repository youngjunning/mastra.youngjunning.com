# Studio

Mastra 從 `src/mastra/` 目錄下的 `studio.ts` 檔案讀取 [Studio](/docs/studio/overview) 設定。檔案預設匯出的 `StudioConfig` 物件用來設定身份驗證和授權，決定哪些用戶可存取 Studio，以及通過驗證後可執行哪些操作。

這頁說明如何以檔案設定 Studio。有關身份驗證 Provider、角色為本的存取控制（RBAC）及細粒度授權（FGA），請參閱 [Studio 身份驗證與授權](/docs/studio/auth)。

## 快速入門 {/* #quickstart */}

在本機開發時毋須設定 `studio.ts`。啟動開發伺服器後，便可開啟 Studio。

```bash npm2yarn
npm run dev
```

在本機開發時，開啟 Studio 毋須驗證身份。要保護共用或生產環境的部署，可加入 `studio.ts`。

## 加入身份驗證 {/* #add-authentication */}

使用身份驗證 Provider，規定用戶登入後才可存取 Studio。這個例子使用 [WorkOS](/integrations/auth/workos)。

```typescript title="src/mastra/studio.ts"
import { MastraAuthWorkos } from '@mastra/auth-workos'
import type { StudioConfig } from '@mastra/core/server'

export default {
  auth: new MastraAuthWorkos(),
} satisfies StudioConfig
```

身份驗證 Provider 負責核實用戶身份。要控制用戶登入後可做哪些操作，可在同一份設定加入 RBAC 或 FGA。完整例子請參閱 [Studio 身份驗證與授權](/docs/studio/auth)。

## 檔案與程式碼設定的優先次序 {/* #precedence-with-code */}

以程式碼註冊的 Studio 設定優先於 `studio.ts`。整個專案共用一組 Studio 設定時，可使用 `studio.ts`。若身份驗證取決於執行時如何組合組件，請在 `src/mastra/index.ts` 以程式碼註冊。
