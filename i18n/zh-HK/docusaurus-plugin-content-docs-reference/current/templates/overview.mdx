# 範本

本參考文件說明如何使用現有 Mastra 範本、建立自己的範本，以及如何為社群生態貢獻範本。

Mastra 範本是預先建立的專案結構，用於展示特定使用情況及模式。這些範本提供：

* **可執行範例**：完整且功能齊全的 Mastra 應用程式
* **最佳實務**：合適的專案結構及程式碼慣例
* **學習資源**：透過實際實作學習 Mastra 模式
* **快速入門**：以鷹架快速啟動專案，毋須從零建立

## 可用模板 {/* #available-templates */}

以下範本展示以 Gateway 為優先入口的 Mastra 應用程式：

* `template-docs-expert`：結合 Gateway 網頁搜尋、引用、記憶體及結構化回應回答文件問題。
* `template-browser-agent`：使用 AgentBrowser 瀏覽、檢查網頁並與之互動。
* `template-meeting-notes`：將 Zoom 文字記錄或上傳的文字記錄轉換為包含決策及行動項目的結構化筆記。
* `template-company-knowledge`：將 Linear 和 Notion 內容索引到 pgvector 中並回答內部知識問題。
* `template-claw-assistant`：使用檔案系統、Sandbox、瀏覽器及網頁搜尋 Tool 操作 Workspace。

## 使用模板 {/* #using-templates */}

### 安裝 {/* #installation */}

使用 `create-mastra` 指令安裝範本：

```sh npm2yarn
npx create-mastra@latest my-project --template template-name
```
此指令會建立完整專案並安裝依賴套件。範本作者負責定義模型、Provider 依賴套件、環境變數及源碼。

### 設定過程 {/* #setup-process */}

安裝後：

1. **進入專案目錄**：

   ```bash
   cd your-project-name
   ```

2. **設定環境變數**：

   ```bash
   cp .env.example .env
   ```

   按照範本 README 的說明編輯 `.env`，填入所需的 API 密鑰。

3. **啟動開發伺服器**：

   ```sh npm2yarn
   npm run dev
   ```

### 模板結構 {/* #template-structure */}

所有模板都遵循以下標準化結構：

```text
your-template/
├── src/
│   └── mastra/
│       ├── agents/       # Agent definitions
│       ├── tools/        # Tool definitions
│       ├── workflows/    # Workflow definitions
│       └── index.ts      # Main Mastra config
├── .env.example          # Required environment variables
├── package.json
├── tsconfig.json
└── README.md
```
