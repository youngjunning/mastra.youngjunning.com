# GoogleCloudPubSub

`GoogleCloudPubSub` 是 [`PubSub`](/reference/pubsub/base) 的一種實作，以 [Google Cloud Pub/Sub](https://cloud.google.com/pubsub/docs) 為基礎。它透過 Google Cloud 的主題及訂閱，在不同程序和主機之間傳送事件，並支援按序傳送及訊息確認。

適用於 Google Cloud 上的分散式部署。單一程序的傳送可使用 [`EventEmitterPubSub`](/reference/pubsub/event-emitter)；Redis 場景可使用 [`RedisStreamsPubSub`](/reference/pubsub/redis-streams)。

每個 topic 都對應一個 Google Cloud 主題。指定 group 的訂閱會共用同一個訂閱，由群組成員競爭接收事件；沒有指定 group 時，每個實例都有自己的訂閱，因此每個實例都會收到所有事件。

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/google-cloud-pubsub
```

## 使用例子 {/* #usage-example */}

傳入 Google Cloud 用戶端設定，例如項目 ID。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { GoogleCloudPubSub } from '@mastra/google-cloud-pubsub'

export const mastra = new Mastra({
  pubsub: new GoogleCloudPubSub({
    projectId: 'my-project',
  }),
})
```

## 方法 {/* #methods */}

`GoogleCloudPubSub` 實作了 [`PubSub`](/reference/pubsub/base) 契約。以下方法為此實作特有。

### `init(topicName, group?)` {/* #inittopicname-group */}

若主題及訂閱尚不存在，便會建立它們並傳回訂閱。`subscribe` 會在內部呼叫此方法，因此一般毋須直接呼叫。

```typescript
await pubsub.init('workflow.events')
```

### `subscribe(topic, cb, options?)` {/* #subscribetopic-cb-options */}

訂閱主題。設定 `options.group` 時，群組成員共用訂閱並競爭接收事件；沒有設定 group 時，實例會透過自己的訂閱接收每個事件。

```typescript
await pubsub.subscribe('workflow.events', (event, ack, nack) => {
  console.log(event)
})
```

### `flush()` {/* #flush */}

等待尚未完成的訊息確認。

```typescript
await pubsub.flush()
```

### `destroy(topicName)` {/* #destroytopicname */}

移除指定主題名稱對應的訂閱及主題，用來清理 Google Cloud 資源。

```typescript
await pubsub.destroy('workflow.events')
```

## 訊息確認 {/* #acknowledgment */}

每個傳送的事件都包含 `ack` 及 `nack` 函數。處理成功後呼叫 `ack`，即可從訂閱移除該事件。如兩者都沒有呼叫，Google Cloud 會在確認期限屆滿後重新傳送事件。
