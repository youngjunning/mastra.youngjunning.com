# Google雲端PubSub

`GoogleCloudPubSub`是一個[`PubSub`](/reference/pubsub/base)實施支持[谷歌雲端發布/訂閱](https://cloud.google.com/pubsub/docs)。它使用 Google Cloud 主題和訂閱跨進程和主機傳送事件，並提供有序傳送和訊息確認。

將其用於 Google Cloud 上的分散式部署。對於單一進程交付，請使用[`EventEmitterPubSub`](/reference/pubsub/event-emitter). For Redis, use [`RedisStreamsPubSub`](/reference/pubsub/redis-streams).

每個主題都會對應到一個 Google Cloud 主題。與群組的訂閱共享一個訂閱。成員們參加活動。沒有群組的訂閱會建立每個實例的訂閱。每個實例都會接收每個事件。

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/google-cloud-pubsub
```

## 使用範例 {/* #usage-example */}

傳遞 Google Cloud 用戶端配置，例如專案 ID。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { GoogleCloudPubSub } from '@mastra/google-cloud-pubsub'

export const mastra = new Mastra({
  pubsub: new GoogleCloudPubSub({
    projectId: 'my-project',
  }),
})
```

## 方法 {/* #methods */}

`GoogleCloudPubSub`實施[`PubSub`](/reference/pubsub/base) contract. The methods below are specific to this implementation.

### `init(topicName, group?)` {/* #inittopicname-group */}

建立主題和訂閱（如果尚不存在）並返回訂閱。`subscribe` calls this internally, so you rarely call it directly.

```typescript
await pubsub.init('workflow.events')
```

### `subscribe(topic, cb, options?)` {/* #subscribetopic-cb-options */}

訂閱主題。和`options.group`, members of the group share a subscription and compete for events. Without a group, the instance receives every event through its own subscription.

```typescript
await pubsub.subscribe('workflow.events', (event, ack, nack) => {
  console.log(event)
})
```

### `flush()` {/* #flush */}

等待待處理的確認完​​成。

```typescript
await pubsub.flush()
```

### `destroy(topicName)` {/* #destroytopicname */}

刪除主題名稱的訂閱和主題。使用它來清理 Google Cloud 資源。

```typescript
await pubsub.destroy('workflow.events')
```

## 致謝 {/* #acknowledgment */}

每個交付的事件包括`ack` and `nack` functions. Call `ack` after successful processing to remove the event from the subscription. When neither is called, Google Cloud redelivers the event after its acknowledgment deadline expires.
