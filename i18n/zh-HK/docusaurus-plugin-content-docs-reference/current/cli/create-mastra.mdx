# 創建瑪斯特拉

創建一個獨立的 Mastra 專案。預設情況下，`create-mastra`安裝預設啟動器並為您選擇的模型提供程式配置它。

```bash npm2yarn
npx create-mastra@latest
```

## 創作模式 {/* #creation-modes */}

### 預設啟動器 {/* #default-starter */}

預設啟動器會建立一個具有WorkspaceTool、記憶體、任務追蹤、Web 存取、循環計劃、儲存和可觀察性的AgentTool。選擇 Mastra Gateway、OpenAI、Anthropic、Gemini 或 xAI 作為您的模型提供者。

提供項目名稱和提供者以在沒有提示的情況下建立項目。這個例子使用了 Anthropic；你也可以透過`openai`, `google`, `xai`, or `mastra`。和`mastra`，也透過`--llm-api-key`若要跳過瀏覽器登錄，請參閱[馬斯特拉網關](#mastra-gateway):

```bash npm2yarn
npx create-mastra@latest my-mastra-project --llm anthropic
```

忽略`--llm` to select the provider and optionally enter its API key interactively. The interactive setup also offers to connect your project to the Mastra platform. If enabled, the command opens the browser authentication flow and creates a platform project with the same name as the local project. It then writes `MASTRA_PLATFORM_ACCESS_TOKEN` and `MASTRA_PROJECT_ID` to `.env`.

### 馬斯特拉網關 {/* #mastra-gateway */}

選擇**Mastra Gateway** to call every model with one key. The command opens the browser to sign in to Mastra, creates a Gateway API key, and writes it to `.env` as `MASTRA_GATEWAY_API_KEY`. The agent's models use the `mastra/` prefix, for example `mastra/openai/gpt-6.1-sol`.

模型調用按您的網關積分中的代幣支付。如果您的餘額為 0 美元，則該命令會開啟 Mastra 儀表板的「新增積分」頁面，您可以在其中選擇金額並可以開啟自動充值。當您執行此操作時，安裝程式將繼續，並且最終摘要會再次連結該頁面。

若要使用現有網關金鑰而不登錄，請將其傳遞給`--llm-api-key`:

```bash npm2yarn
npx create-mastra@latest my-mastra-project --llm mastra --llm-api-key <your-gateway-key>
```

### 範本 {/* #template */}

使用範本 slug 或公共 GitHub URL：

```bash npm2yarn
npx create-mastra@latest my-mastra-project --template agent-harness
```

```bash npm2yarn
npx create-mastra@latest my-mastra-project --template https://github.com/mastra-ai/template-agent-harness
```

將模板值留空以互動方式選擇模板：

```bash npm2yarn
npx create-mastra@latest my-mastra-project --template
```

模板作者擁有自己的依賴項、模型、環境變數和原始程式碼。`create-mastra` doesn't apply `--llm` or `--llm-api-key`.

### 空鷹架 {/* #empty-scaffold */}

使用`--empty` to create a provider-free project without agents, examples, model SDKs, or environment files:

```bash npm2yarn
npx create-mastra@latest my-empty-project --empty
```

## 自動設定 {/* #automatic-setup */}

安裝依賴項後，命令：

1. 檢測支援的編碼助手`PATH` and installs Mastra skills. If none are detected, it installs universal skills.
2. 噹噹前目錄和產生的項目尚未位於 Git 儲存庫中時建立初始 Git 提交。

使用`--no-skills` or `--no-git` to skip these steps. Skills and Git setup failures produce warnings but don't remove a successfully created project.

## 衝突和驗證 {/* #conflicts-and-validation */}

* `--empty`和`--template` can't be used together.
* `--llm`和`--llm-api-key` are only valid for the default starter project.
* 項目名稱必須是安全的、小寫的、單目錄名稱，且目標不能已存在。

在建立任何專案文件之前，無效的標誌、專案名稱和 GitHub URL 將被拒絕。取得範本清單後，未知的範本名稱將被拒絕，並且 CLI 會列印可用的範本。

## 遙測 {/* #telemetry */}

Mastra 收集匿名 CLI 使用信息，例如作業系統、Mastra 版本和 Node.js 版本。您可以查看[analytics source](https://github.com/mastra-ai/mastra/blob/main/packages/cli/src/analytics/index.ts).

放`MASTRA_TELEMETRY_DISABLED=1` to opt out:

```bash
MASTRA_TELEMETRY_DISABLED=1 npx create-mastra@latest my-project --empty
```
