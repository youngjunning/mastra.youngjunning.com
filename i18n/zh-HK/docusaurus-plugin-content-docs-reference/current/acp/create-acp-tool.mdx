# 創建ACPTool()

這`createACPTool()`函數建立一個 Mastra Tool，發送一個`task`字串到與Agent客戶端協定 (ACP) 相容的編碼Agent，並傳回最終的 ACP 回應：`output`。當父Agent應決定何時呼叫 ACP Agent作為Tool時，請使用它。

如果您想將 ACP Agent註冊為 Mastra 子Agent，請使用[`AcpAgent` class](/reference/acp/acp-agent).

## 使用範例 {/* #usage-example */}

建立程式碼編輯Tool並將其註冊到父Agent上：

```typescript title="src/mastra/agents/code-supervisor.ts"
import { createACPTool } from '@mastra/acp'
import { Agent } from '@mastra/core/agent'

const codeAgentTool = createACPTool({
  id: 'code-agent',
  description: 'Use an ACP-compatible coding agent to inspect and edit code',
  command: 'acp-agent',
  args: ['--stdio'],
  cwd: process.cwd(),
})

export const codeSupervisor = new Agent({
  id: 'code-supervisor',
  name: 'Code Supervisor',
  instructions: 'Use the code-agent tool when a task requires repository inspection or code edits.',
  model: '__GATEWAY_OPENAI_MODEL__',
  tools: {
    codeAgentTool,
  },
})
```

## 會話生命週期 {/* #session-lifecycle */}

每個Tool執行都會建立一個 ACP 連線並啟動設定的`command`. It initializes the ACP client and creates an ACP session before sending the `task` with ACP `session/prompt`.

預設情況下，`persistSession` is `true` for the ACP connection created during tool execution. Set `persistSession: false` when the ACP process should stop as soon as that prompt completes.

使用[`AcpAgent`](/reference/acp/acp-agent#session-lifecycle) when you need a reusable ACP subagent instance with explicit session lifecycle control across calls.

## 權限處理 {/* #permission-handling */}

ACP Agent程式可能會要求客戶在繼續之前選擇一個權限選項。預設情況下，`@mastra/acp` selects the first option returned by the ACP agent, or cancels when no option is available.

經過`onPermissionRequest` to inspect the request and return your own permission response:

```typescript title="src/mastra/agents/code-agent.ts"
import { createACPTool } from '@mastra/acp'

export const codeAgentTool = createACPTool({
  id: 'code-agent',
  description: 'Use an ACP-compatible coding agent',
  command: 'acp-agent',
  args: ['--stdio'],
  async onPermissionRequest(request) {
    const allowOption = request.options.find(option => option.name === 'Allow')

    if (!allowOption) {
      return { outcome: { outcome: 'cancelled' } }
    }

    return {
      outcome: {
        outcome: 'selected',
        optionId: allowOption.optionId,
      },
    }
  },
})
```

使用此回調來強制執行本機原則或檢查權限標題。它還可以將決策路由到您自己的批准流程。

## 擴展方法 {/* #extension-methods */}

某些 ACP Agent在標準 ACP 請求集之外呼叫客戶端上的自訂擴充方法。預設用戶端會拒絕未知方法，並顯示「未找到方法」錯誤，這可能會中止Agent的輪次。

經過`createClient` to extend or replace the default client. The callback receives the default client and returns the client used for the connection:

```typescript title="src/mastra/agents/code-agent.ts"
import { createACPTool } from '@mastra/acp'

export const codeAgentTool = createACPTool({
  id: 'code-agent',
  description: 'Use an ACP-compatible coding agent',
  command: 'acp-agent',
  args: ['--stdio'],
  createClient: defaultClient =>
    Object.assign(defaultClient, {
      async extMethod(method: string, params: Record<string, unknown>) {
        return {}
      },
      async extNotification(method: string, params: Record<string, unknown>) {},
    }),
})
```

返回完全定制的`Client` implementation when you need to change the standard handlers as well. The `Client` type is re-exported from `@mastra/acp`.
