# AcpAgent 類別

`AcpAgent` 類別會將兼容 Agent Client Protocol (ACP) 的編碼 Agent 封裝為 Mastra subagent。當上層 Mastra Agent 需要委派程式碼庫檢查和修改時，可以使用它；亦可以將其他由 ACP 支援的工作委派給該 subagent。

如果希望上層 Agent 將 ACP Agent 當作工具呼叫，請改用 [`createACPTool()`](/reference/acp/create-acp-tool)。

## 使用例子 {/* #usage-example */}

將兼容 ACP 的編碼 Agent 註冊到上層 Agent 的 `agents` 對應表中：

```typescript title="src/mastra/agents/code-supervisor.ts"
import { AcpAgent } from '@mastra/acp'
import { Agent } from '@mastra/core/agent'

const codeAgent = new AcpAgent({
  id: 'code-agent',
  name: 'Code Agent',
  description: 'An ACP-compatible coding agent that can inspect and edit files',
  command: 'acp-agent',
  args: ['--stdio'],
  cwd: process.cwd(),
})

export const codeSupervisor = new Agent({
  id: 'code-supervisor',
  name: 'Code Supervisor',
  instructions: 'Delegate code editing tasks to the code-agent subagent.',
  model: '__GATEWAY_OPENAI_MODEL__',
  agents: {
    codeAgent,
  },
})
```

Claude Code 的 ACP 支援由橋接套件 `@agentclientprotocol/claude-agent-acp` 提供。將 ACP Agent 指令設定為執行該橋接程式，然後在建立工作階段後選取 Claude 模型：

```typescript title="src/mastra/agents/claude-code-agent.ts"
import { AcpAgent } from '@mastra/acp'

export const claudeCodeAgent = new AcpAgent({
  id: 'claude-code-agent',
  name: 'Claude Code Agent',
  description: 'Use Claude Code through ACP.',
  command: 'npx',
  args: ['@agentclientprotocol/claude-agent-acp'],
  cwd: process.cwd(),
  model: '__AI_SDK_ANTHROPIC_MODEL_SONNET__',
})
```

## 方法 {/* #methods */}

### 生成 {/* #generation */}

#### `generate(messages, options?)` {/* #generatemessages-options */}

將提示傳給 ACP Agent，暫存回應中的文字片段，然後傳回 Mastra subagent 的 generate 結果。

```typescript
const result = await codeAgent.generate('Inspect the repository and summarize the test setup')

console.log(result.text)
```

#### `stream(messages, options?)` {/* #streammessages-options */}

將提示傳給 ACP Agent 並傳回 Mastra subagent 的串流結果。ACP `agent_message_chunk` 更新會以 Mastra `text-delta` 片段輸出。

```typescript
const result = await codeAgent.stream('Refactor the selected module and explain each change')

for await (const chunk of result.fullStream) {
  if (chunk.type === 'text-delta') {
    process.stdout.write(chunk.payload.text)
  }
}
```

不支援 `resumeGenerate()` 和 `resumeStream()`；呼叫時會拋出錯誤。

### 模型管理 {/* #model-management */}

#### `getAvailableModels()` {/* #getavailablemodels */}

必要時啟動 ACP 程序，並傳回 ACP 工作階段公布的模型清單。

```typescript
const models = await codeAgent.getAvailableModels()
// [{ modelId: '__AI_SDK_ANTHROPIC_MODEL_SONNET__', name: 'Claude Sonnet' }, ...]
```

#### `setModel(modelId)` {/* #setmodelmodelid */}

為目前的 ACP 工作階段選取模型。如果 ACP Agent 公布了可用模型，模型 ID 必須與其中之一相符。

```typescript
await codeAgent.setModel('__AI_SDK_ANTHROPIC_MODEL_SONNET__')
```

## 工作階段生命週期 {/* #session-lifecycle */}

首次使用時，`AcpAgent` 會啟動設定的 `command` 並初始化 ACP 客戶端，然後建立 ACP 工作階段。`persistSession` 預設為 `true`，因此程序和工作階段會在 `generate()`、`stream()`、`getAvailableModels()` 與 `setModel()` 呼叫之間持續運作。

如果希望每次提示都使用新的 ACP 程序，請設定 `persistSession: false`：

```typescript title="src/mastra/agents/code-agent.ts"
import { AcpAgent } from '@mastra/acp'

export const codeAgent = new AcpAgent({
  id: 'code-agent',
  description: 'Run one isolated ACP coding task',
  command: 'acp-agent',
  args: ['--stdio'],
  cwd: process.cwd(),
  persistSession: false,
})
```

設定 `persistSession: false` 後，`@mastra/acp` 會在每次提示完成後停止 ACP 程序。

## Workspace 整合 {/* #workspace-integration */}

ACP 檔案操作會透過 Mastra 的 `Workspace` 抽象層執行。如果未傳入 `workspace`，`@mastra/acp` 會建立一個 `Workspace`，由 `LocalFilesystem` 支援，並以 `cwd` 或 `process.cwd()` 作為檔案系統的基底路徑。

如果 ACP Agent 應透過特定檔案系統實作進行讀寫，請傳入自訂 `Workspace`：

```typescript title="src/mastra/agents/code-agent.ts"
import { AcpAgent } from '@mastra/acp'
import { LocalFilesystem, Workspace } from '@mastra/core/workspace'

const workspace = new Workspace({
  filesystem: new LocalFilesystem({
    basePath: process.cwd(),
  }),
})

export const codeAgent = new AcpAgent({
  id: 'code-agent',
  description: 'Run coding tasks in a controlled workspace',
  command: 'acp-agent',
  args: ['--stdio'],
  workspace,
})
```

當 ACP 程序應從一個目錄啟動，但檔案操作需要使用明確設定的 Workspace 根目錄時，請同時設定 `cwd` 和 `workspace`。

## 權限處理 {/* #permission-handling */}

ACP Agent 在繼續執行前，可能要求客戶端選擇一個權限選項。預設情況下，`AcpAgent` 會選取 ACP Agent 傳回的第一個選項；如果沒有可用選項，則取消請求。

傳入 `onPermissionRequest`，即可檢查請求並傳回自訂權限回應：

```typescript title="src/mastra/agents/code-agent.ts"
import { AcpAgent } from '@mastra/acp'

export const codeAgent = new AcpAgent({
  id: 'code-agent',
  description: 'Use an ACP-compatible coding agent',
  command: 'acp-agent',
  args: ['--stdio'],
  async onPermissionRequest(request) {
    const allowOption = request.options.find(option => option.name === 'Allow')

    if (!allowOption) {
      return { outcome: { outcome: 'cancelled' } }
    }

    return {
      outcome: {
        outcome: 'selected',
        optionId: allowOption.optionId,
      },
    }
  },
})
```

你可以在這個回呼中執行本機政策、檢查權限標題，或將決策交給自己的審批流程。
