# 專案結構

以 `create mastra` 指令建立的 Mastra 專案提供預設檔案及資料夾，協助你開始開發。

Mastra 是一個框架，但基本上不規定檔案如何組織或放在哪裏。CLI 提供適合大部分專案的預設結構，你可按工作流程或團隊慣例調整，甚至把整個專案放在單一檔案。無論選擇哪種結構，都應保持一致，方便維護及查找程式碼。

## 預設專案結構 {/* #default-project-structure */}

以 `create mastra` 指令建立的專案結構如下：

```bash
├── src/
│   └── mastra/
│       ├── agents/
│       │   └── agent.ts
│       ├── tools/
│       │   └── schedule-tools.ts
│       └── index.ts
├── .env.example
├── AGENTS.md
├── package.json
└── tsconfig.json
```

預設專案以 [Agent Harness 範本](https://github.com/mastra-ai/template-agent-harness)為基礎。你可複製並修改這些預設檔案，快速建立自己的 Agent、Tool 和 Workflow 等。

### 資料夾 {/* #folders */}

Mastra 建議將程式碼放在以下資料夾：

| 資料夾 | 說明 |
| - | - |
| `src/mastra` | Mastra 相關程式碼及設定的入口。 |
| `src/mastra/agents` | 定義及設定 Agent 的行為、目標與 Tool。 |
| `src/mastra/workflows` | 定義協調 Agent 與 Tool 的多步驟 Workflow。 |
| `src/mastra/tools` | 建立可供 Agent 呼叫的可重用 Tool。 |
| `src/mastra/mcp` | 實作自訂 MCP server，與外部 Agent 共用 Tool。 |
| `src/mastra/scorers` | 定義用於持續評估 Agent 表現的 scorer。 |

Mastra 有兩個特殊的資料夾約定：

- `src/mastra/agents/<name>`：可按檔案慣例定義 Agent，毋須在程式碼中建構。詳見[以檔案定義 Agent](/docs/develop#file-based-agents)文件。
- `src/mastra/public`：建置時，此資料夾的內容會複製到 `.mastra/output`，供執行時提供服務。

### 頂層檔案 {/* #top-level-files */}

頂層檔案定義 Mastra 專案的設定、建置方式，以及與環境的連接方式。

| 檔案 | 說明 |
| - | - |
| `src/mastra/index.ts` | 設定及初始化 Mastra 的主要入口。 |
| `.env.example` | 環境變數範本；複製為 `.env`，再加入私密的[模型 Provider](/models)金鑰。 |
| `AGENTS.md` | 供專案中的編程 Agent 使用的指示。 |
| `package.json` | 定義專案中繼資料、相依套件及可用的 npm scripts。 |
| `tsconfig.json` | 設定 TypeScript 選項，例如路徑別名、編譯器設定及建置輸出。 |
