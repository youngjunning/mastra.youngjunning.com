# 專案結構

您的新 Mastra 項目，使用以下命令創建`create mastra`命令附帶一組預先定義的檔案和資料夾來幫助您入門。

Mastra 是一個框架，但主要是**unopinionated** about how you organize or colocate your files. The CLI provides a sensible default structure that works well for most projects, but you're free to adapt it to your workflow or team conventions. You could even build your entire project in a single file if you wanted! Whatever structure you choose, keep it consistent to ensure your code stays maintainable and straightforward to browse.

## 預設項目結構 {/* #default-project-structure */}

使用已建立的項目`create mastra` command looks like this:

```bash
├── src/
│   └── mastra/
│       ├── agents/
│       │   └── agent.ts
│       ├── tools/
│       │   └── schedule-tools.ts
│       └── index.ts
├── .env.example
├── AGENTS.md
├── package.json
└── tsconfig.json
```

預設項目基於[Agent Harness template](https://github.com/mastra-ai/template-agent-harness). Use the predefined files as templates. Duplicate and adapt them to quickly create your own agents, tools, workflows, etc.

### 資料夾 {/* #folders */}

Mastra 建議將您的程式碼組織到以下資料夾：

|資料夾|描述 |
| - | - |
|`src/mastra` | Entry point for all Mastra-related code and configuration. |
| `src/mastra/agents` | Define and configure your agents - their behavior, goals, and tools. |
| `src/mastra/workflows` | Define multi-step workflows that orchestrate agents and tools together. |
| `src/mastra/tools` | Create reusable tools that your agents can call |
| `src/mastra/mcp`|實作自訂 MCP 伺服器以與外部Agent程式共用您的Tool |
|`src/mastra/scorers`|定義用於評估Agent績效隨時間變化的評分者 |

Mastra 有兩個特殊的資料夾約定：

* `src/mastra/agents/<name>`：您可以透過檔案約定定義Agent，而不是在程式碼中建構它。了解更多信息[File-based Agents](/docs/develop#file-based-agents) docs.
* `src/mastra/public`: 內容複製到`.mastra/output` directory during the build process, making them available for serving at runtime.

### 頂級文件 {/* #top-level-files */}

頂級檔案定義如何配置、建置 Mastra 專案以及如何連接到其環境。

|文件|描述 |
| - | - |
|`src/mastra/index.ts` | Central entry point where you configure and initialize Mastra. |
| `.env.example` | Template for environment variables - copy and rename to `.env` to add your secret [model provider](/models) keys. |
| `AGENTS.md` | Instructions for coding agents working in the project. |
| `package.json` | Defines project metadata, dependencies, and available npm scripts. |
| `tsconfig.json` | Configures TypeScript options such as path aliases, compiler settings, and build output. |
