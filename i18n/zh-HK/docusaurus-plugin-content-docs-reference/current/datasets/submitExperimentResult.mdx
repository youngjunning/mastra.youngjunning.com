# dataset.submitExperimentResult()

**新增於：** `@mastra/core@1.61.0`

為以 [`createExperiment()`](/reference/datasets/createExperiment) 建立的無目標實驗，提交（或重新提交）一項由外部計算的項目結果。

提交會以 `(experimentId, itemId, attempt)` 為鍵執行更新插入：工作程序重試並提交相同的鍵時，結果會合併到同一行，不會產生重複結果。如要將重複試驗記錄為獨立資料行，請使用不同的 `attempt` 值。

## 使用範例 {/* #usage-example */}

```typescript
const result = await dataset.submitExperimentResult({
  experimentId,
  itemId: 'item-1',
  output: { translation: 'Hola' },
  scores: [{ scorerId: 'accuracy', score: 0.92, reason: 'Faithful translation' }],
})
```

項目必須在實驗固定的資料集版本中可見。向已有目標的實驗提交結果會拋出 `EXPERIMENT_HAS_TARGET`，避免兩個寫入者競爭同一批資料行。實驗完成最終確認後提交會拋出 `EXPERIMENT_ALREADY_FINALIZED`。

## 傳回值 {/* #returns */}

傳回 `Promise<ExperimentResult>`，即已儲存的結果資料行，當中包括 `id`、`attempt` 及時間戳記。
