# 刪除實驗()

**添加於：** `@mastra/core@1.4.0`

刪除實驗產生的Observability痕跡，然後刪除實驗及其結果記錄。刪除痕跡需要`@mastra/core@1.65.0` or later and cascades to spans, metrics, logs, scores, and feedback linked by trace ID. Unsupported observability storage leaves the traces in place and logs a warning.

使用`dataset.deleteExperiment()` when you have a `Dataset` instance. Use `mastra.datasets.deleteExperiment()`在沒有資料集引用的情況下按實驗 ID 進行刪除，包括因資料集刪除而孤立的實驗。

## 從資料集中刪除 {/* #delete-from-a-dataset */}

```typescript
import { Mastra } from '@mastra/core'

const mastra = new Mastra({/* storage config */})
const dataset = await mastra.datasets.get({ id: 'dataset-id' })

await dataset.deleteExperiment({ experimentId: 'experiment-id' })
```

實驗必須屬於資料集。缺少的實驗或屬於另一個資料集的實驗會拋出異常`EXPERIMENT_NOT_FOUND`.

退貨`Promise<void>`, which resolves when deletion completes.

## 在沒有資料集引用的情況下刪除 {/* #delete-without-a-dataset-reference */}

```typescript
import { Mastra } from '@mastra/core'

const mastra = new Mastra({/* storage config */})

await mastra.datasets.deleteExperiment({
  experimentId: 'experiment-id',
  organizationId: 'organization-id',
  projectId: 'project-id',
})
```

管理器方法不需要實驗與資料集保持關聯。用它來刪除一個孤立的實驗`datasetId` was cleared when its dataset was deleted.

什麼時候`organizationId` or `projectId` is provided, deletion is scoped to those values. A tenancy mismatch is a silent no-op.

## 痕跡刪除支持 {/* #trace-deletion-support */}

在刪除結果記錄之前，Mastra 會收集級聯的追蹤 ID。沒有可觀察性或追蹤刪除支援的儲存體會將這些追蹤保留在適當的位置，記錄警告，並且仍然刪除實驗及其結果記錄。

如果追蹤刪除因任何其他原因失敗，則在實驗及其結果記錄被刪除之前呼叫將被拒絕。痕跡會以 1,000 條為一批進行刪除，因此某些痕跡可能已被刪除。重複呼叫以完成刪除。
