# DatasetsManager

**加入於：** `@mastra/core@1.4.0`

`DatasetsManager` 類別提供管理數據集的公開 API，包括 CRUD 操作及跨數據集的實驗比較。可透過 `mastra.datasets` 存取。

## 使用例子 {/* #usage-examples */}

### 建立及列出數據集 {/* #create-and-list-datasets */}

```typescript title="src/mastra/datasets/manage.ts"
import { Mastra } from '@mastra/core'

const mastra = new Mastra({/* storage config */})

// Create a dataset
const dataset = await mastra.datasets.create({
  name: 'QA pairs',
  description: 'Question-answer evaluation set',
})

// List all datasets
const { datasets } = await mastra.datasets.list()
```

### 取得及刪除數據集 {/* #get-and-delete-a-dataset */}

```typescript title="src/mastra/datasets/get-delete.ts"
import { Mastra } from '@mastra/core'

const mastra = new Mastra({/* storage config */})

// Get by ID
const dataset = await mastra.datasets.get({ id: 'dataset-id' })

// Delete by ID
await mastra.datasets.delete({ id: 'dataset-id' })
```

### 取得實驗 {/* #get-experiment */}

按 ID 取得指定實驗（一次執行）。與 `dataset.getExperiment()` 不同，此方法可跨所有數據集使用，毋須先取得數據集參照。

```typescript
import { Mastra } from '@mastra/core'

const mastra = new Mastra({/* storage config */})

// Get experiment directly without knowing the dataset
const experiment = await mastra.datasets.getExperiment({
  experimentId: 'exp-id',
})
if (!experiment) throw new Error('Experiment not found')

console.log(`Dataset: ${experiment.datasetId}`)
console.log(`Status: ${experiment.status}`)
```

### 刪除實驗 {/* #delete-experiment */}

直接按 ID 刪除實驗，包括因數據集被刪除而成為孤立記錄的實驗。Mastra 會先刪除實驗的可觀測性 Trace，再刪除實驗及其結果記錄。若可觀測性儲存不支援此操作，Trace 會保留，並記錄警告。

```typescript
await mastra.datasets.deleteExperiment({
  experimentId: 'experiment-id',
  organizationId: 'organization-id',
  projectId: 'project-id',
})
```

有關租戶行為及 Trace 級聯刪除的詳情，請參閱 [`DatasetsManager.deleteExperiment()`](/reference/datasets/deleteExperiment)。

### 比較實驗 {/* #compare-experiments */}

```typescript title="src/mastra/datasets/compare.ts"
import { Mastra } from '@mastra/core'

const mastra = new Mastra({/* storage config */})

const comparison = await mastra.datasets.compareExperiments({
  experimentIds: ['exp-1', 'exp-2'],
  baselineId: 'exp-1',
})
```

## 存取方式 {/* #access */}

請勿直接建立 `DatasetsManager` 實例；應從 `Mastra` 實例存取：

```typescript
const mastra = new Mastra({/* storage config */})
const datasetsManager = mastra.datasets
```
