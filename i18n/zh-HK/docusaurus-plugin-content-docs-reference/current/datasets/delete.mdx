# 資料集管理器.delete()

**添加於：** `@mastra/core@1.4.0`

按 ID 刪除資料集，包括其所有項目和版本。針對資料集運行的實驗被保留但分開：它們`datasetId` and `datasetVersion`被設定為`null`。資料庫支援的儲存適配器也會刪除這些實驗的結果。

## 使用範例 {/* #usage-example */}

```typescript
import { Mastra } from '@mastra/core'

const mastra = new Mastra({/* storage config */})

await mastra.datasets.delete({ id: 'dataset-id' })
```

什麼時候`organizationId` or `projectId` is provided, deletion is scoped to those values. A tenancy mismatch is a silent no-op.
