# DatasetsManager.delete()

**加入版本** `@mastra/core@1.4.0`

按 ID 刪除數據集，包括所有項目和版本。曾以該數據集執行的實驗會保留，但會解除連結，實驗的 `datasetId` 和 `datasetVersion` 都會設為 `null`。以資料庫為後端的儲存轉接器亦會刪除這些實驗的結果。

## 使用示例 {/* #usage-example */}

```typescript
import { Mastra } from '@mastra/core'

const mastra = new Mastra({/* storage config */})

await mastra.datasets.delete({ id: 'dataset-id' })
```

如有提供 `organizationId` 或 `projectId`，刪除操作只涵蓋指定範圍。租戶不符時，系統不會刪除任何資料，亦不會報錯。
