# 資料集.getDetails()

**添加於：** `@mastra/core@1.4.0`

從儲存中檢索完整的資料集記錄，包括元資料、架構和版本資訊。

## 使用範例 {/* #usage-example */}

```typescript
import { Mastra } from '@mastra/core'

const mastra = new Mastra({/* storage config */})

const dataset = await mastra.datasets.get({ id: 'dataset-id' })

// Get dataset details
const details = await dataset.getDetails()
console.log(details.name, details.version)
```

## 參數 {/* #parameters */}

此方法不帶參數。

## 退貨 {/* #returns */}

返回一個`Promise<DatasetRecord>`. Throws `MastraError` if the dataset isn't found.
