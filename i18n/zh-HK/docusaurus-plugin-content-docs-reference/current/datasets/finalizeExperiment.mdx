# 資料集.finalizeExperiment()

**添加於：** `@mastra/core@1.61.0`

[`createExperiment()`](/reference/datasets/createExperiment), with or without a target. Mastra computes the final counts server-side from the persisted result rows and marks the experiment `'completed'`。一個已經做過的實驗`'failed'`返回原樣並保持失敗狀態。呼叫者從不追蹤簿記的完成情況。

計數是每個項目的，所以`succeededCount + failedCount + skippedCount === totalItems` even when items have multiple attempts:

* `succeededCount`：至少完成一次嘗試且未出現錯誤的項目
* `failedCount`：已提交但每次嘗試都出錯的項目
* `skippedCount`：從未提交的資料集項目（任何嘗試）

嘗試級別的詳細資訊仍然可以透過[`listExperimentResults()`](/reference/datasets/listExperimentResults).



## 使用範例 {/* #usage-example */}

```typescript
const experiment = await dataset.finalizeExperiment({ experimentId })

console.log(experiment.status) // 'completed'
console.log(experiment.succeededCount)
console.log(experiment.failedCount)
console.log(experiment.skippedCount)
```
