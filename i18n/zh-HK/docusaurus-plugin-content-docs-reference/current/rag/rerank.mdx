# rerank()

`rerank()` 綜合語義相關性、向量相似度和位置評分，重新排序向量搜尋結果。

```typescript
function rerank(
  results: QueryResult[],
  query: string,
  model: MastraLanguageModel,
  options: RerankerFunctionOptions,
): Promise<RerankResult[]>
```

## 使用範例 {/* #usage-example */}

```typescript
import { ModelRouterLanguageModel } from '@mastra/core/llm'
import { rerank } from '@mastra/rag'

const model = new ModelRouterLanguageModel('__GATEWAY_OPENAI_MODEL__')

const rerankedResults = await rerank(vectorSearchResults, 'How do I deploy to production?', model, {
  weights: {
    semantic: 0.5,
    vector: 0.3,
    position: 0.2,
  },
  topK: 3,
})
```

rerank 可使用 Vercel AI SDK 中的任何 LanguageModel。使用 Cohere 的 `rerank-v3.5` 模型時，會自動使用 Cohere 的重新排序功能。

:::note

要正確計算語義相關性評分，每項結果的 `metadata.text` 欄位都必須包含文字內容。

:::
