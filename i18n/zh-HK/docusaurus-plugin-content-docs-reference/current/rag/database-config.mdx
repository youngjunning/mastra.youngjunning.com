# DatabaseConfig

`DatabaseConfig` 類型可在使用向量查詢 Tool 時指定資料庫專屬設定，善用不同向量儲存系統提供的功能和優化選項。

## 類型定義 {/* #type-definition */}

```typescript
export type DatabaseConfig = {
  pinecone?: PineconeConfig
  pgvector?: PgVectorConfig
  chroma?: ChromaConfig
  mongodb?: MongoDBConfig
  turbopuffer?: TurbopufferConfig
  [key: string]: any // Extensible for future databases
}
```

### `PgVectorConfig` {/* #pgvectorconfig */}

安裝 pgvector 擴充套件的 PostgreSQL 專屬設定選項。

  isOptional: true,
},
{
  name: 'probes',
  type: 'number',
  description:
    'IVFFlat 探測參數，指定搜尋時要走訪的索引儲存格數量。數值越高，召回率越高，但搜尋速度越慢。',
  isOptional: true,
},
]}
/>

**效能調整建議：**

* **ef**：先設為 topK 的 2～4 倍，需要更高準確度時再調高
* **probes**：先設為 1～10，需要更高召回率時再調高
* **minScore**：按結果質素要求，使用 0.5～0.9 之間的值

**適用情況：**

* 優化高負載情況下的效能
* 篩走不相關的結果
* 調整搜尋準確度與速度之間的取捨

  <TabItem value="runtime-override" label="執行時覆寫">
    ### 在執行時覆寫設定 {/* #runtime-configuration-override */}

    ```typescript
    import { RequestContext } from '@mastra/core/request-context'

    // Initial configuration
    const vectorTool = createVectorQueryTool({
      vectorStoreName: 'pinecone',
      indexName: 'documents',
      model: embedModel,
      databaseConfig: {
        pinecone: {
          namespace: 'development',
        },
      },
    })

    // Override at runtime
    const requestContext = new RequestContext()
    requestContext.set('databaseConfig', {
      pinecone: {
        namespace: 'production',
      },
    })

    await vectorTool.execute({ queryText: 'search query' }, { mastra, requestContext })
    ```
  </TabItem>

  <TabItem value="multi-database" label="多資料庫">
    ### 多資料庫配置 {/* #multi-database-configuration */}

    ```typescript
    import { RequestContext } from '@mastra/core/request-context'

    const vectorTool = createVectorQueryTool({
      vectorStoreName: 'pinecone',
      indexName: 'documents',
      model: embedModel,
    })

    // Select the store per request and pass only its matching config block
    const pineconeContext = new RequestContext()
    pineconeContext.set('vectorStoreName', 'pinecone')
    pineconeContext.set('databaseConfig', {
      pinecone: { namespace: 'default' },
    })

    const pgVectorContext = new RequestContext()
    pgVectorContext.set('vectorStoreName', 'pgVector')
    pgVectorContext.set('databaseConfig', {
      pgvector: { minScore: 0.8, ef: 150 },
    })

    await vectorTool.execute({ queryText: 'search query' }, { mastra, requestContext: pgVectorContext })
    ```

    :::note

    **多資料庫支援**：無論查詢哪個向量儲存系統，所有已設定的資料庫區塊都會合併至查詢參數。共用的參數名稱會影響實際執行查詢的儲存系統。例如，`pgvector.minScore` 會以 `minScore` 傳入；LibSQL 等其他儲存系統亦會讀取它來篩選結果。因此，只傳入與目前查詢所用向量儲存系統相符的設定區塊。

    :::
  </TabItem>

## 擴充性 {/* #extensibility */}

`DatabaseConfig` 類型可擴充。要支援新的向量資料庫：

```typescript
// 1. Define the configuration interface
export interface NewDatabaseConfig {
  customParam1?: string
  customParam2?: number
}

// 2. Extend DatabaseConfig type
export type DatabaseConfig = {
  pinecone?: PineconeConfig
  pgvector?: PgVectorConfig
  chroma?: ChromaConfig
  newdatabase?: NewDatabaseConfig
  [key: string]: any
}

// 3. Use in vector query tool
const vectorTool = createVectorQueryTool({
  vectorStoreName: 'newdatabase',
  indexName: 'documents',
  model: embedModel,
  databaseConfig: {
    newdatabase: {
      customParam1: 'value',
      customParam2: 42,
    },
  },
})
```

## 最佳做法 {/* #best-practices */}

1. **環境設定**：為不同環境使用不同的命名空間或設定
2. **效能調整**：從預設值開始，再按實際需要調整
3. **質素篩選**：使用 minScore 篩走低質素結果
4. **執行時彈性**：按執行時確定的需要覆寫設定
5. **文件記錄**：記錄設定選擇，方便團隊成員查閱

## 遷移指南 {/* #migration-guide */}

現有向量查詢 Tool 無須修改即可繼續使用。要加入資料庫設定：

```diff
const vectorTool = createVectorQueryTool({
  vectorStoreName: 'pinecone',
  indexName: 'documents',
  model: embedModel,
+ databaseConfig: {
+   pinecone: {
+     namespace: 'production'
+   }
+ }
});
```
