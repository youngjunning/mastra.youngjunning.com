# 圖RAG

基於圖表的檢索透過追蹤資訊區塊之間的關係來增強傳統的向量搜尋。當資訊分佈在多個文件中或文件相互引用時，此方法非常有用。

## 何時使用 GraphRAG {/* #when-to-use-graphrag */}

GraphRAG 在下列情況下特別有效：

* 資訊分佈在多個文件中
* 文件相互引用
* 你需要遍歷關係才能找到完整的答案
* 理解概念之間的連結很重要
* 簡單的向量相似性錯過了重要的上下文關係

對於無需關係遍歷的直接語義搜索，請使用[standard retrieval methods](/reference/rag/retrieval).

## GraphRAG 的工作原理 {/* #how-graphrag-works */}

GraphRAG 將向量相似度與知識圖遍歷結合：

1. 初始向量搜尋根據語義相似性檢索相關區塊
2. 當檢索找到區塊時，Tool會根據該請求的區塊建立知識圖。該圖不會在請求之間重複使用
3. 遍歷該圖以查找關聯信息
4. 結果包括直接相關的區塊和相關的內容

如果檢索沒有找到區塊，該Tool將傳回空白上下文和來源，而不建立圖表。

此過程有助於顯示語義上可能與查詢不相似但透過連接在上下文中相關的資訊。

## 建立圖形查詢Tool {/* #creating-a-graph-query-tool */}



```ts
import { createGraphRAGTool } from '@mastra/rag'
import { ModelRouterEmbeddingModel } from '@mastra/core/llm'

const graphQueryTool = createGraphRAGTool({
  vectorStoreName: 'pgVector',
  indexName: 'embeddings',
  model: new ModelRouterEmbeddingModel('openai/text-embedding-3-small'),
  graphOptions: {
    threshold: 0.7,
  },
})
```

### 配置選項 {/* #configuration-options */}

這`graphOptions` parameter controls how the knowledge graph is built and traversed:

* `threshold`：用於確定哪些區塊相關的相似度閾值（0-1）。較高的值會創建具有更強連接的稀疏圖形。較低的值會創建具有更多潛在關係的密集圖形。
* `dimension`：向量嵌入維度。必須符合嵌入模型的輸出維度（例如，OpenAI 的 text-embedding-3-small 為 1536）。

```ts
const graphQueryTool = createGraphRAGTool({
  vectorStoreName: 'pgVector',
  indexName: 'embeddings',
  model: new ModelRouterEmbeddingModel('openai/text-embedding-3-small'),
  graphOptions: {
    dimension: 1536,
    threshold: 0.7,
  },
})
```

## 將 GraphRAG 與Agent程式一起使用 {/* #using-graphrag-with-agents */}

將圖形查詢Tool與Agent程式整合以實現基於圖形的檢索：

```ts
import { Agent } from '@mastra/core/agent'

const ragAgent = new Agent({
  id: 'rag-agent',
  name: 'GraphRAG Agent',
  instructions: `You are a helpful assistant that answers questions based on the provided context.
When answering questions, use the graph query tool to find relevant information and relationships.
Base your answers on the context provided by the tool, and clearly state if the context doesn't contain enough information.`,
  model: '__GATEWAY_OPENAI_MODEL__',
  tools: {
    graphQueryTool,
  },
})
```

## 文件處理和存儲 {/* #document-processing-and-storage */}

在使用基於圖的檢索之前，將文件處理成區塊並儲存它們的嵌入：

```ts
import { MDocument } from '@mastra/rag'
import { embedMany } from 'ai'
import { ModelRouterEmbeddingModel } from '@mastra/core/llm'

// Create and chunk document
const doc = MDocument.fromText('Your document content here...')

const chunks = await doc.chunk({
  strategy: 'recursive',
  size: 512,
  overlap: 50,
  separator: '\n',
})

// Generate embeddings
const { embeddings } = await embedMany({
  model: new ModelRouterEmbeddingModel('openai/text-embedding-3-small'),
  values: chunks.map(chunk => chunk.text),
})

// Store in vector database
const vectorStore = mastra.getVector('pgVector')
await vectorStore.createIndex({
  indexName: 'embeddings',
  dimension: 1536,
})
await vectorStore.upsert({
  indexName: 'embeddings',
  vectors: embeddings,
  metadata: chunks?.map(chunk => ({ text: chunk.text })),
})
```

## 使用 GraphRAG 查詢 {/* #querying-with-graphrag */}

配置完成後，Agent可以執行基於圖形的查詢：

```ts
const query = 'What are the effects of infrastructure changes on local businesses?'
const response = await ragAgent.generate(query)
console.log(response.text)
```

Agent使用圖形查詢Tool來：

1. 將查詢轉換為嵌入
2. 在向量儲存中尋找語意相似的區塊
3. 從相關區塊建構知識圖
4. 遍歷圖表以尋找關聯資訊
5. 傳回用於產生回應的完整上下文

## 選擇正確的閾值 {/* #choosing-the-right-threshold */}

閾值參數顯著影響檢索品質：

* **高閾值（0.8-0.9）**：嚴格的聯繫和較少的關係，加上更精確但可能不完整的結果
* **中等閾值（0.6-0.8）**：平衡的方法，適合大多數用例
* **低閾值（0.4-0.6）**：更多的聯繫和更廣泛的背景，加上包含不太相關的資訊的風險

從 0.7 開始，然後根據您的特定用例進行調整：

```ts
// Strict connections for precise answers
const strictGraphTool = createGraphRAGTool({
  vectorStoreName: 'pgVector',
  indexName: 'embeddings',
  model: new ModelRouterEmbeddingModel('openai/text-embedding-3-small'),
  graphOptions: {
    threshold: 0.85,
  },
})

// Broader connections for exploratory queries
const broadGraphTool = createGraphRAGTool({
  vectorStoreName: 'pgVector',
  indexName: 'embeddings',
  model: new ModelRouterEmbeddingModel('openai/text-embedding-3-small'),
  graphOptions: {
    threshold: 0.5,
  },
})
```

## 與其他檢索方法結合 {/* #combining-with-other-retrieval-methods */}

GraphRAG 可以與其他檢索方法一起使用：

```ts
import { createVectorQueryTool } from '@mastra/rag'

const vectorQueryTool = createVectorQueryTool({
  vectorStoreName: 'pgVector',
  indexName: 'embeddings',
  model: new ModelRouterEmbeddingModel('openai/text-embedding-3-small'),
})

const graphQueryTool = createGraphRAGTool({
  vectorStoreName: 'pgVector',
  indexName: 'embeddings',
  model: new ModelRouterEmbeddingModel('openai/text-embedding-3-small'),
  graphOptions: {
    threshold: 0.7,
  },
})

const agent = new Agent({
  id: 'rag-agent',
  name: 'RAG Agent',
  instructions: `Use vector search for simple fact-finding queries.
Use graph search when you need to understand relationships or find connected information.`,
  model: '__GATEWAY_OPENAI_MODEL__',
  tools: {
    vectorQueryTool,
    graphQueryTool,
  },
})
```

這使得Agent可以根據查詢靈活地選擇適當的檢索方法。
