# 使用 AI 建立

日常使用 Mastra Skill 和 CLI 輔助開發時，請參閱[開發](/docs/develop#build-with-ai)。本頁介紹讓編碼 Agent 存取 Mastra 文件的其他方式。

## 套件內嵌文件 {/* #embedded-package-docs */}

Mastra 套件的 `dist/docs` 中包含內嵌文件。安裝 Mastra 套件後，AI Agent 可直接從 `node_modules` 讀取這些檔案，了解套件的 API 和使用方式。

每個 `dist/docs` 都包含：

- `SKILL.md`：遵循 skills 標準的 Skill 檔案
- `references/`：與該套件相關的文件目錄
- `assets/SOURCE_MAP.json`：將公開匯出項目對應至其在 `node_modules` 中位置的來源對應檔案

## 上下文檔案 {/* #context-files */}

Mastra 提供根目錄的 [`llms.txt`](https://mastra.ai/llms.txt)，其中概覽所有可用的文件頁面。

如需一次過載入多個頁面，請使用 `llms-full.txt` 整合檔案。它們按側邊欄順序包含各頁面的完整 Markdown：

- [`/llms-full.txt`](https://mastra.ai/llms-full.txt)：所有文件
- [`/docs/llms-full.txt`](https://mastra.ai/docs/llms-full.txt)：文件
- [`/models/llms-full.txt`](https://mastra.ai/models/llms-full.txt)：模型
- [`/integrations/llms-full.txt`](https://mastra.ai/integrations/llms-full.txt)：整合
- [`/reference/llms-full.txt`](https://mastra.ai/reference/llms-full.txt)：API 參考

完整整合檔案較大；如果只需要部分文件，請優先使用對應章節的整合檔案或單一頁面。

每個文件頁面也有獨立的 `llms.txt` 檔案。這些檔案是精簡版 Markdown；頁面末尾提供對應 `llms.txt` 檔案的連結。

在任一 Mastra 文件 URL 後加上 `/llms.txt` 即可存取；也可以在 URL 末尾加上 `.md`。

[簡介頁面](/docs)的例子：

* [`/docs/llms.txt`](https://mastra.ai/docs/llms.txt)
* [`/docs.md`](https://mastra.ai/docs.md)

## MCP 文件伺服器 {/* #mcp-docs-server */}

:::warning

不建議在日常開發中使用 MCP 文件伺服器。請改用 [Mastra Skill](/docs/develop#mastra-skills)，它的內容較新，效能亦較好。

:::

`@mastra/mcp-docs-server` 套件透過 [Model Context Protocol (MCP)](https://modelcontextprotocol.io/docs/getting-started/intro)，讓你從本機直接存取完整的 Mastra 文件。它適用於 Cursor、Windsurf、Cline、Claude Code、VS Code、Codex，以及任何支援 MCP 的工具。

這些工具可協助 Agent 取得與特定工作相關的準確資訊，例如為 Agent 加入功能、建立新項目，或了解某項功能的運作方式。

如果無法使用本機 MCP 伺服器而需要連接遠端伺服器，請使用 `https://mastra.mcp.kapa.ai`。為了限制請求速率，你需要使用 Google 帳戶驗證（只會傳送匿名 ID）。若條件允許，Mastra 建議使用本機 MCP 伺服器，以獲得較佳效能與可靠性。

### 安裝 {/* #installation */}

[`create-mastra`](/reference/cli/create-mastra) 指令不會設定 MCP 文件伺服器。如果需要遷移工具等 MCP 專用工具，請手動加入該伺服器。

如果下方沒有針對你所用工具的具體說明，可以嘗試使用以下通用 JSON 設定加入 MCP 伺服器。

```json title="mcp.json"
{
  "mcpServers": {
    "mastra": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "@mastra/mcp-docs-server@latest"]
    }
  }
}
```

#### 克勞德·代碼 CLI {/* #claude-code-cli */}

在終端機執行以下指令安裝：

```bash
claude mcp add --scope project mastra -- npx -y @mastra/mcp-docs-server@latest
```

如果項目中尚無 `.mcp.json`，此指令會建立一個項目範圍的檔案。將 Claude Code 當作 [Visual Studio Code 擴充功能](https://code.claude.com/docs/en/vs-code#connect-to-external-tools-with-mcp)使用時，亦可以執行同一指令。

[了解如何在 Claude Code 中使用 MCP 伺服器](https://docs.claude.com/en/docs/claude-code/mcp)

#### OpenAI Codex CLI {/* #openai-codex-cli */}

1. 在終端機註冊伺服器：

   ```bash
   codex mcp add mastra-docs -- npx -y @mastra/mcp-docs-server@latest
   ```

1. 執行 `codex mcp list`，確認伺服器顯示為 `enabled`。

[了解如何在 OpenAI Codex 中使用 MCP 伺服器](https://developers.openai.com/codex/mcp)

#### 游標 {/* #cursor */}

按下方按鈕安裝：

[![Install MCP Server](https://cursor.com/deeplink/mcp-install-light.svg)](cursor://anysphere.cursor-deeplink/mcp/install?name=mastra\&config=eyJjb21tYW5kIjoibnB4IC15IEBtYXN0cmEvbWNwLWRvY3Mtc2VydmVyIn0%3D)

安裝後，在 Cursor 中開啟 **Customize** > **MCPs**，啟用 **mastra** 伺服器。

Cursor 亦可能顯示 **New MCP server detected: mastra** 彈出視窗。可選取 **Enable** 直接啟用，或選取 **Skip**，稍後再從 **Customize** > **MCPs** 啟用。

[了解如何在 Cursor 中使用 MCP 伺服器](https://cursor.com/de/docs/context/mcp)

#### 反重力 {/* #antigravity */}

Google Antigravity 是以 Agent 為核心的開發平台，支援透過 MCP 伺服器存取外部文件、API 和項目上下文。

1. 開啟 Antigravity 的 MCP 設定檔案：

      - 選取 **Agent session**，在編輯器側邊面板頂端選取 **“…” dropdown**，再選取 **MCP Servers** 進入 **MCP Store**。
      - 也可以透過 Antigravity 的 MCP Store 介面存取。

1. 若要加入自訂 MCP 伺服器，請在 MCP Store 頂端選取 **Manage MCP Servers**，再於主分頁選取 **View raw config**。

1. 加入 Mastra MCP 伺服器設定：

   ```json
   {
     "mcpServers": {
       "mastra-docs": {
         "command": "npx",
         "args": ["-y", "@mastra/mcp-docs-server"]
       }
     }
   }
   ```

1. 儲存設定並重新啟動 Antigravity。

設定完成後，Mastra MCP 伺服器會向 Antigravity Agent 提供：

- Mastra 的索引文件和 API Schema，供產生程式碼時擷取相關上下文
- Mastra 文件中的程式碼例子和使用模式
- 編輯器中供錯誤處理與除錯參考的結構化資料
- 關於目前 Mastra 項目模式的元資料，用於程式碼建議與補全

該 MCP 伺服器會顯示在 Antigravity 的 MCP Store 中；你可以按需要管理連接狀態和驗證。

[了解如何在 Antigravity 中使用 MCP 伺服器](https://antigravity.google)

#### 視覺工作室程式碼 {/* #visual-studio-code */}

1. 在工作區中建立 `.vscode/mcp.json` 檔案。
1. 插入以下設定：

   ```json title=".vscode/mcp.json"
   {
     "servers": {
       "mastra": {
         "type": "stdio",
         "command": "npx",
         "args": ["-y", "@mastra/mcp-docs-server@latest"]
       }
     }
   }
   ```

儲存設定後，啟用伺服器：

1. 開啟命令面板。
1. 執行 **MCP: List Servers**。
1. 選取 **mastra**，再選取 **Enable**。

在 Visual Studio Code 的 Agent 模式中可使用 MCP 工具。按 Copilot 面板中的工具按鈕，即可查看可用工具。

[了解如何在 Visual Studio Code 中使用 MCP 伺服器](https://code.visualstudio.com/docs/copilot/customization/mcp-servers)

#### 風帆衝浪 {/* #windsurf */}

1. 在編輯器中開啟 `~/.codeium/windsurf/mcp_config.json`。

1. 插入以下設定：

   ```json title="~/.codeium/windsurf/mcp_config.json"
   {
     "mcpServers": {
       "mastra": {
         "command": "npx",
         "args": ["-y", "@mastra/mcp-docs-server@latest"]
       }
     }
   }
   ```

1. 儲存設定並重新啟動 Windsurf。

[了解如何在 Windsurf 中使用 MCP 伺服器](https://docs.windsurf.com/windsurf/cascade/mcp#mcp-config-json)

#### 開放程式碼 {/* #opencode */}

你可以在 [OpenCode 設定](https://opencode.ai/docs/config/)的 `mcp` 欄位中定義 MCP 伺服器。在項目根目錄建立 `opencode.jsonc`，內容如下：

```json title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "mastra": {
      "type": "local",
      "command": ["npx", "-y", "@mastra/mcp-docs-server@latest"],
      "enabled": true
    }
  }
}
```

[了解如何在 OpenCode 中使用 MCP 伺服器](https://opencode.ai/docs/mcp-servers)

#### 澤德 {/* #zed */}

1. 在編輯器中開啟 `~/.config/zed/settings.json`。
1. 插入以下設定：

```json title="~/.config/zed/settings.json"
{
  "context_servers": {
    "Mastra": {
      "command": "npx",
      "args": ["-y", "@mastra/mcp-docs-server@latest"]
    }
  }

```

### 用法 {/* #usage */}

設定完成後，你可以向 AI 工具詢問 Mastra 相關問題，或請它執行操作。在這些步驟中，它會從 Mastra MCP 伺服器取得最新資訊。

**加入功能：**

- 「為我的 Agent 加入 Evals 並撰寫測試」
- 「撰寫一個執行 `[task]` 的 Workflow」
- 「建立一個 Tool，讓我的 Agent 可以存取 `[3rd party API]`」

**詢問整合方式：**

- 「Mastra 能與 AI SDK 一起使用嗎？
    要如何在我的 `[React/Svelte/etc]` 項目中使用？」
- 「Mastra 支援 `[provider]` 的語音 API 嗎？請示範如何在我的程式碼中使用。」

**除錯或更新現有程式碼：**

- 「我的 Agent 記憶功能遇到錯誤，最近是否有相關變更或修正？」
- 「Mastra 的工作記憶如何運作？怎樣用它完成 `[task]`？它的行為似乎與我預期不同。」
- 「我看到 Workflow 有新功能。請先說明這些功能，再更新 `[workflow]` 以使用它們。」

### 疑難排解 {/* #troubleshooting */}

1. **伺服器無法啟動**
      - 確認 [npx](https://docs.npmjs.com/cli/v11/commands/npx) 已安裝且正常運作。
      - 檢查是否有衝突的 MCP 伺服器。
      - 驗證設定檔案的語法。

1. **工具呼叫失敗**
      - 重新啟動 MCP 伺服器和／或 IDE。
      - 將 IDE 更新至最新版本。
