# Workflow\.sleep()

這`.sleep()`方法將執行暫停指定的毫秒數。它接受靜態數字或回調函數來實現運行時定義的延遲。

## 使用範例 {/* #usage-example */}

```typescript
workflow.sleep(5000)
```

## 擴充使用範例 {/* #extended-usage-example */}

```typescript oxfmt:false
import { createWorkflow, createStep } from "@mastra/core/workflows";

const step1 = createStep({...});
const step2 = createStep({...});

export const testWorkflow = createWorkflow({...})
  .then(step1)
  .sleep(async ({ inputData }) => {
    const { delayInMs } = inputData;
    return delayInMs;
  })
  .then(step2)
  .commit();
```
