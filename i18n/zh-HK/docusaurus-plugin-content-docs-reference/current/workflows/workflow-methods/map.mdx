# Workflow.map()

`.map()` 方法將上一步的輸出資料對應至後續步驟的輸入，可在步驟之間轉換資料。

## 使用範例 {/* #usage-example */}

```typescript
workflow.map(async ({ inputData }) => `${inputData.value} - map`)
```

## 使用 `inputData` {/* #using-inputdata */}

使用 `inputData` 取得上一步的完整輸出。

```typescript {3} filename="src/mastra/workflows/test-workflow.ts" oxfmt:false
  .then(step1)
  .map(async ({ inputData }) => {
    console.log(inputData);
  })
```

## 使用 `getStepResultAsync()` {/* #using-getstepresultasync */}

使用 `getStepResultAsync()`，透過步驟實例或其 ID 取得指定步驟的完整輸出。

```typescript {3} filename="src/mastra/workflows/test-workflow.ts" oxfmt:false
  .then(step1)
  .map(async ({ getStepResultAsync }) => {
    console.log(await getStepResultAsync(step1));
  })
```

`getStepResultAsync()` 取代已棄用的 `getStepResult()`；後者會同步傳回相同的值。

## 使用 `getInitData()` {/* #using-getinitdata */}

使用 `getInitData<typeof workflow>()` 取得傳入 Workflow 的初始輸入資料。

```typescript oxfmt:false {3} filename="src/mastra/workflows/test-workflow.ts"
  .then(step1)
  .map(async ({ getInitData }) => {
    console.log(getInitData<any>());
  })
```

## 使用 `mapVariable()` {/* #using-mapvariable */}

`.map()` 的物件形式提供另一種宣告式欄位對應語法：無須編寫函式，只需定義一個物件。物件的每個鍵是新欄位名稱，每個值透過 `mapVariable()` 從先前步驟或 Workflow 輸入中擷取資料。
從 workflows 模組匯入 `mapVariable()`：

```typescript filename="src/mastra/workflows/test-workflow.ts"
import { mapVariable } from '@mastra/core/workflows'
```

### 從步驟輸出中提取字段 {/* #extracting-fields-from-step-outputs */}

將 `mapVariable()` 與 `step` 一起使用，可從步驟輸出擷取指定欄位，並對應至新欄位名稱。`path` 參數指定要擷取的欄位。
以下範例擷取 `value` 欄位（位於 `step1` 的輸出中），並對應至名為 `details` 的新欄位：

```typescript oxfmt:false {3-6} filename="src/mastra/workflows/test-workflow.ts"
  .then(step1)
  .map({
    details: mapVariable({
      step: step1,
      path: "value"
    })
  })
```

### 從Workflow輸入中提取字段 {/* #extracting-fields-from-workflow-input */}

將 `mapVariable()` 與 `initData` 一起使用，可從 Workflow 的初始輸入擷取指定欄位。需要將原始輸入傳給後續步驟時，這種方式很有用。
以下範例從 Workflow 輸入擷取 `value` 欄位，並對應至名為 `details` 的欄位：

```typescript oxfmt:false {8-11} filename="src/mastra/workflows/test-workflow.ts"
import { createWorkflow } from '@mastra/core/workflows';

export const testWorkflow = createWorkflow({...});

testWorkflow
  .then(step1)
  .map({
    details: mapVariable({
      initData: testWorkflow,
      path: "value"
    })
  })
```
