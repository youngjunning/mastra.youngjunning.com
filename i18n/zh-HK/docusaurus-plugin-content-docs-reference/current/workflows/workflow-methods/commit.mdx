# Workflow.commit()

`.commit()` 確認 Workflow 的最終定義，使其可供執行。加入步驟後、建立執行實例前，請呼叫此方法。若 Workflow 的步驟仍有未提交的變更，建立執行實例時會拋出錯誤。

## 使用示例 {/* #usage-example */}

```typescript
workflow.then(step1).commit()
```
