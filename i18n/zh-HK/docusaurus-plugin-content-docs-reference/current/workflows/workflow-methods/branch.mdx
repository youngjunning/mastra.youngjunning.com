# Workflow.branch()

這`.branch()`方法在Workflow步驟之間建立條件分支，允許根據上一個步驟的結果採取不同的路徑。每個分支的條件評估為`true`運行；條件是獨立評估的，因此重疊條件運行多個分支。當只應運行一個分支時，請使用互斥條件。

## 使用範例 {/* #usage-example */}

```typescript
workflow.branch([
  [async () => true, step1],
  [async () => false, step2],
])
```
