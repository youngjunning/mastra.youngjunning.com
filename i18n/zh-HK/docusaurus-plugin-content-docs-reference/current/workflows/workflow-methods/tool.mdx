# Workflow\.tool()

`.tool()` 方法會將 Tool 新增為宣告式步驟。該 Tool 自身的輸入及輸出 schema 仍然適用，因此上一步的輸出必須符合 Tool 的輸入 schema。如兩者不相符，請使用 `.map()` 轉換資料。

與使用 `createStep()` 包裝 Tool 不同，`.tool()` 會在 Workflow 圖中記錄一個宣告式項目。這令 Workflow 具備可攜性：同一張圖可以序列化並持久保存為[動態 Workflow](/docs/workflows/dynamic-workflows)。

## 使用範例 {/* #usage-example */}

```typescript filename="src/mastra/workflows/test-workflow.ts"
workflow.tool(testTool).commit()
```

## 透過 ID 參照 Tool {/* #referencing-a-tool-by-id */}

傳入字串即可參照已註冊的 Tool，毋須匯入它。Workflow 執行時，該 Tool 必須已註冊至 Mastra 實例：

```typescript filename="src/mastra/workflows/test-workflow.ts"
workflow.tool('lookup-customer', { retries: 2 }).commit()
```

## 持久保存 Tool 步驟 {/* #persisting-tool-steps */}

使用 `.tool()` 建立的 Workflow 會序列化為[動態 Workflow](/docs/workflows/dynamic-workflows)所使用的相同宣告式項目。只有 `retries` 及 `metadata` 能完整經過儲存往返；如果 `scorers` 是函數值，儲存 Workflow 時會拋出錯誤。
