# Memory.listThreads()

`listThreads()` 方法支援分頁查詢對話線程，並可按 `resourceId`、`metadata` 或兩者同時篩選。

## 使用範例 {/* #usage-examples */}

### 分頁列出所有對話線程 {/* #list-all-threads-with-pagination */}

```typescript
const result = await memory.listThreads({
  page: 0,
  perPage: 10,
})
```

### 不分頁取得所有對話線程 {/* #fetch-all-threads-without-pagination */}

設定 `perPage: false`，即可一次取得所有符合條件的對話線程。

:::warning

資料量較大時尤其建議使用分頁。請審慎使用不分頁選項。

:::

```typescript
const result = await memory.listThreads({
  filter: { resourceId: 'user-123' },
  perPage: false,
})
```

### 按 `resourceId` 篩選 {/* #filter-by-resourceid */}

```typescript
const result = await memory.listThreads({
  filter: { resourceId: 'user-123' },
  page: 0,
  perPage: 10,
})
```

### 按元數據篩選 {/* #filter-by-metadata */}

```typescript
const result = await memory.listThreads({
  filter: { metadata: { category: 'support', priority: 'high' } },
  page: 0,
  perPage: 10,
})
```

### 組合篩選（resourceId 與元數據） {/* #combined-filter-resourceid--metadata */}

```typescript
const result = await memory.listThreads({
  filter: {
    resourceId: 'user-123',
    metadata: { status: 'active' },
  },
  page: 0,
  perPage: 10,
})
```

傳回的物件包含：

- `threads`：對話線程物件陣列
- `total`：符合篩選條件的對話線程總數
- `page`：目前頁碼（與傳入的 `page` 參數相同）
- `perPage`：每頁項目數（與傳入的 `perPage` 參數相同）
- `hasMore`：布林值，表示是否還有更多結果

## 擴充使用範例 {/* #extended-usage-example */}

```typescript title="src/test-memory.ts"
import { mastra } from './mastra'

const agent = mastra.getAgent('agent')
const memory = await agent.getMemory()

let currentPage = 0
const perPage = 25
let hasMorePages = true

// Fetch all active threads for a user, sorted by creation date
while (hasMorePages) {
  const result = await memory?.listThreads({
    filter: {
      resourceId: 'user-123',
      metadata: { status: 'active' },
    },
    page: currentPage,
    perPage: perPage,
    orderBy: { field: 'createdAt', direction: 'ASC' },
  })

  if (!result) {
    console.log('No threads')
    break
  }

  result.threads.forEach(thread => {
    console.log(`Thread: ${thread.id}, Created: ${thread.createdAt}`)
  })

  hasMorePages = result.hasMore
  currentPage++ // Move to next page
}
```

## 元數據篩選 {/* #metadata-filtering */}

元數據篩選採用 AND 邏輯：對話線程必須符合所有指定的鍵值對，才會出現在結果中：

```typescript
// This will only return threads where BOTH conditions are true:
// - category === 'support'
// - priority === 'high'
await memory.listThreads({
  filter: {
    metadata: {
      category: 'support',
      priority: 'high',
    },
  },
})
```
