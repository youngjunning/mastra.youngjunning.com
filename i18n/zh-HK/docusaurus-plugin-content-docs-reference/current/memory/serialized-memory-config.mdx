# 序列化記憶體配置

`SerializedMemoryConfig`是 JSON 可序列化的子集[`Memory`](/reference/memory/memory-class)存在於儲存的Agent記錄上的配置。運轉時將其水化回`Memory`透過根據配置解析向量和嵌入器 ID 來實例化`Mastra`實例。

這是使用的類型[`BuilderAgentDefaults.memory`](https://agent-builder.mastra.ai/reference/builder-agent-defaults) and by `EditorAgentNamespace.create({ memory })`.

## 使用範例 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { MastraEditor } from '@mastra/editor'

new MastraEditor({
  builder: {
    enabled: true,
    configuration: {
      agent: {
        memory: {
          observationalMemory: true,
          options: { lastMessages: 50 },
        },
      },
    },
  },
})
```
