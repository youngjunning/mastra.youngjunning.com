# Memory 類別

`Memory` 類別提供可靠的對話紀錄及討論串訊息管理，支援持久儲存、語義搜尋及高效擷取訊息。對話紀錄必須設定儲存服務；如啟用語義召回，亦須提供向量儲存。如果向量儲存本身不會為文字產生嵌入向量，還須提供嵌入模型。

## 使用範例 {/* #usage-example */}

```typescript title="src/mastra/agents/test-agent.ts"
import { Memory } from '@mastra/memory'
import { Agent } from '@mastra/core/agent'

export const agent = new Agent({
  id: 'test-agent',
  name: 'test-agent',
  instructions: 'You are an agent with memory.',
  model: '__GATEWAY_OPENAI_MODEL__',
  memory: new Memory({
    options: {
      workingMemory: {
        enabled: true,
      },
    },
  }),
})
```

:::note

要為 Agent 啟用 `workingMemory`，主 Mastra 執行個體必須設定儲存服務。詳情請參閱 [Mastra 類別](../core/mastra-class)。

:::

## `saveMessages()` {/* #savemessages */}

`agent.generate()` 和 `agent.stream()` 會自動持久儲存訊息。如需自行寫入訊息，例如預設討論串內容、匯入對話紀錄，或儲存來自 Mastra 以外的訊息，請呼叫 `memory.saveMessages()`。每則訊息都需要 `threadId` 和 `resourceId`，所以儲存前須先以 [`createThread()`](/reference/memory/createThread) 建立討論串。

```typescript
await memory.saveMessages({
  messages: [
    {
      id: 'msg-1',
      threadId: 'thread-123',
      resourceId: 'user-456',
      role: 'user',
      createdAt: new Date(),
      content: {
        format: 2,
        parts: [{ type: 'text', text: 'Where is my order?' }],
      },
    },
  ],
})
```

### `MastraDBMessage` {/* #mastradbmessage */}

儲存層統一使用 `MastraDBMessage` 訊息格式。接收或傳回訊息的方法，包括 `saveMessages()` 和 [`recall()`](/reference/memory/recall)，都採用此格式。

`content.parts` 是 Agent 實際讀取的內容。已儲存訊息的 `content.format` 一律為 `2`，`content.metadata` 可包含任意自訂資料。`content.toolInvocations`、`content.reasoning` 及 `content.experimental_attachments` 是為兼容 AI SDK v4 保留的扁平對應欄位；寫入時請使用 `parts`。

```typescript
const assistantMessage = {
  id: 'msg-2',
  threadId: 'thread-123',
  resourceId: 'user-456',
  role: 'assistant',
  createdAt: new Date(),
  content: {
    format: 2,
    parts: [
      { type: 'text', text: 'It ships tomorrow.' },
      {
        type: 'tool-invocation',
        toolInvocation: {
          state: 'result',
          toolCallId: 'call-1',
          toolName: 'lookupOrder',
          args: { orderId: 'A-1' },
          result: { eta: '2026-10-30' },
        },
      },
    ],
    metadata: { source: 'import' },
  },
}
```

## 擴充使用範例 {/* #extended-usage-example */}

```typescript title="src/mastra/agents/test-agent.ts"
import { Memory } from '@mastra/memory'
import { Agent } from '@mastra/core/agent'
import { LibSQLStore, LibSQLVector } from '@mastra/libsql'

export const agent = new Agent({
  name: 'test-agent',
  instructions: 'You are an agent with memory.',
  model: '__GATEWAY_OPENAI_MODEL__',
  memory: new Memory({
    storage: new LibSQLStore({
      id: 'test-agent-storage',
      url: 'file:./working-memory.db',
    }),
    vector: new LibSQLVector({
      id: 'test-agent-vector',
      url: 'file:./vector-memory.db',
    }),
    options: {
      lastMessages: 10,
      semanticRecall: {
        topK: 3,
        messageRange: 2,
        scope: 'resource',
      },
      workingMemory: {
        enabled: true,
      },
      generateTitle: true,
    },
  }),
})
```

## 帶有索引配置的 PostgreSQL {/* #postgresql-with-index-configuration */}

```typescript title="src/mastra/agents/pg-agent.ts"
import { Memory } from '@mastra/memory'
import { Agent } from '@mastra/core/agent'
import { ModelRouterEmbeddingModel } from '@mastra/core/llm'
import { PostgresStore, PgVector } from '@mastra/pg'

export const agent = new Agent({
  name: 'pg-agent',
  instructions: 'You are an agent with optimized PostgreSQL memory.',
  model: '__GATEWAY_OPENAI_MODEL__',
  memory: new Memory({
    storage: new PostgresStore({
      id: 'pg-agent-storage',
      connectionString: process.env.DATABASE_URL,
    }),
    vector: new PgVector({
      id: 'pg-agent-vector',
      connectionString: process.env.DATABASE_URL,
    }),
    embedder: new ModelRouterEmbeddingModel('openai/text-embedding-3-small'),
    options: {
      lastMessages: 20,
      semanticRecall: {
        topK: 5,
        messageRange: 3,
        scope: 'resource',
        indexConfig: {
          type: 'hnsw', // Use HNSW for better performance
          metric: 'dotproduct', // Optimal for OpenAI embeddings
          hnsw: {
            m: 16, // Number of bi-directional links
            efConstruction: 64, // Construction-time candidate list size
          },
        },
      },
      workingMemory: {
        enabled: true,
      },
    },
  }),
})
```
