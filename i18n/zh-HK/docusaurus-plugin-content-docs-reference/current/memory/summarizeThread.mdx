# Memory.summarizeThread()

這`.summarizeThread()`方法一次性總結了線程的對話。它從存儲中加載線程的消息，並使用與支援相同的觀察者管道來提取它們[觀察記憶](/reference/memory/observational-memory)：作為獨立調用，沒有附加到Agent的觀察記憶。

訊息從最新的開始逐頁加載，邊界為`lastMessages` and `maxInputTokens`, so summarizing a long thread doesn't read its entire history from storage.

沒有任何內容被寫回記憶體。摘要和提取的值將返回給您（以及每個提取器的`onExtracted` hook), so you decide where they go: for example your own database.

當會話結束並且您想要整個對話的摘要或結構化提取（例如掛斷時的語音呼叫）時，請使用此功能。對於您已有的訊息（無需從線程加載它們），請使用獨立的[`summarizeConversation()`](/reference/memory/summarizeConversation) function instead. It takes the same options with `messages` in place of `threadId`.

## 使用範例 {/* #usage-example */}

```typescript
const result = await memory.summarizeThread({
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  threadId: 'thread-123',
  instructions: 'Summarize this voicemail call for the business owner.',
})
```

## 擴充使用範例 {/* #extended-usage-example */}

以下範例總結了已完成的語音通話並將結構化記錄儲存在應用程式自己的資料庫中：

```typescript title="src/call-summary.ts"
import { Extractor } from '@mastra/memory'
import { z } from 'zod'
import { memory } from './mastra/memory'
import { callRecords } from './db'

const callSummary = new Extractor({
  name: 'call-summary',
  instructions: 'Return a concise summary of the call.',
  schema: z.object({
    summary: z.string(),
    sentiment: z.enum(['positive', 'neutral', 'negative']),
    requestedServices: z.array(z.string()),
  }),
  metadataKeyPath: false, // don't persist into memory metadata — the hook owns storage
  onExtracted: async ({ current, threadId, resourceId }) => {
    await callRecords.upsert({ callId: threadId, callerId: resourceId, record: current })
  },
})

export async function onCallEnd(threadId: string, resourceId: string) {
  await memory.summarizeThread({
    model: '__GATEWAY_OPENAI_MODEL_LUNA__',
    threadId,
    resourceId,
    instructions: 'Summarize this voicemail call for the business owner.',
    extract: [callSummary],
  })
}
```
