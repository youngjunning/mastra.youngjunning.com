# Mastra.getServer()

這`.getServer()`方法用於檢索已在 Mastra 實例中配置的伺服器配置。

## 使用範例 {/* #usage-example */}

```typescript
mastra.getServer()
```

## 參數 {/* #parameters */}

此方法不接受任何參數。
