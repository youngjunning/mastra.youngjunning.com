# Mastra.getServer()

使用 `.getServer()` 可取得 Mastra 實例中的伺服器配置。

## 使用示例 {/* #usage-example */}

```typescript
mastra.getServer()
```

## 參數 {/* #parameters */}

此方法毋須傳入參數。
