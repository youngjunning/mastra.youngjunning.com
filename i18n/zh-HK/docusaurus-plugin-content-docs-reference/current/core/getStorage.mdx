# Mastra.getStorage()

這`.getStorage()`方法用於檢索Mastra實例中已配置的儲存實例。

## 使用範例 {/* #usage-example */}

```typescript
mastra.getStorage()
```

## 參數 {/* #parameters */}

此方法不接受任何參數。
