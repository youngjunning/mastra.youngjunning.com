# Mastra.getWorkflow()

`.getWorkflow()` 方法透過註冊鍵取得 Workflow，並為其輸入及輸出 schema 提供完整的 TypeScript 類型推斷。

## 使用範例 {/* #usage-example */}

```typescript
// Retrieve workflow by its registration key (recommended for type inference)
const workflow = mastra.getWorkflow('testWorkflow')
const run = await workflow.createRun()

// TypeScript will properly infer the input schema type
await run.startAsync({
  inputData: {/* properly typed */},
})
```

## 類型推斷 {/* #type-inference */}

為獲得最佳 TypeScript 支援，請將 Workflow 的**註冊鍵**（將 Workflow 加入 Mastra 時使用的鍵）傳給 `getWorkflow()`。註冊鍵可完整推斷以下類型：

* 輸入資料模式
* 輸出資料模式
* 步驟結果

如需按 Workflow 的 `id` 屬性而非註冊鍵取得它，可使用 `getWorkflowById()`，但其類型推斷較不精確。
