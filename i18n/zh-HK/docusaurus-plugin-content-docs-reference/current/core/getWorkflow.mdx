# Mastra.getWorkflow()

這`.getWorkflow()`方法用於透過其註冊密鑰檢索Workflow。此方法為Workflow輸入和輸出模式提供完整的 TypeScript 類型推斷。

## 使用範例 {/* #usage-example */}

```typescript
// Retrieve workflow by its registration key (recommended for type inference)
const workflow = mastra.getWorkflow('testWorkflow')
const run = await workflow.createRun()

// TypeScript will properly infer the input schema type
await run.startAsync({
  inputData: {/* properly typed */},
})
```

## 類型推斷 {/* #type-inference */}

為了獲得最佳的 TypeScript 支持，請使用`getWorkflow()` with the workflow's **registration key** (the key used when adding the workflow to Mastra). The registration key provides full type inference for:

* 輸入資料模式
* 輸出資料模式
* 步驟結果

如果您需要透過其檢索Workflow`id` property instead of its registration key, you can use `getWorkflowById()`, but note that type inference won't be as precise.
