# getClassifierById()

`getClassifierById()` 會先按 `id` 屬性查找分類器。如未找到，便改按註冊時所用的鍵查找。

## 使用示例 {/* #usage-example */}

```typescript
import { mastra } from './mastra'

const safety = mastra.getClassifierById('safety')
```

## 錯誤處理 {/* #error-handling */}

如沒有分類器符合指定的 id 或註冊鍵，此方法會拋出 `MastraError`，錯誤 ID 為 `MASTRA_GET_CLASSIFIER_BY_ID_NOT_FOUND`。
