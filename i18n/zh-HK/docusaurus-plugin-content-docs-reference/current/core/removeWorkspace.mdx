# Mastra.removeWorkspace()

這`.removeWorkspace()`方法從 Mastra 運行時註冊表中刪除Workspace。經過`{ destroy: true }`在刪除Workspace之前將其銷毀。

## 使用範例 {/* #usage-example */}

```typescript
await mastra.removeWorkspace('workspace-123', { destroy: true })
```

什麼時候`destroy` is `true` and `workspace.destroy()` throws, the call rejects with that error and the workspace remains registered so the caller can retry cleanup.
