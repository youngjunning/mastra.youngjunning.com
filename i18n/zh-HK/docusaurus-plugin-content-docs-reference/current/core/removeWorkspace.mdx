# Mastra.removeWorkspace()

`.removeWorkspace()` 會從 Mastra 的執行時登記表移除 Workspace。若要先銷毀 Workspace，再將它移除，可傳入 `{ destroy: true }`。

## 使用示例 {/* #usage-example */}

```typescript
await mastra.removeWorkspace('workspace-123', { destroy: true })
```

## 回傳值 {/* #returns */}

<PropertiesTable
  content={[
{
  name: 'removed',
  type: 'Promise<boolean>',
  description: '如已移除 Workspace，會回傳 `true`。如該 ID 沒有對應的 Workspace，則回傳 `false`。',
},

當 `destroy` 為 `true`，而 `workspace.destroy()` 擲出例外時，這次呼叫會以該例外拒絕 Promise。Workspace 仍保留在登記表內，呼叫端可再試清理。
