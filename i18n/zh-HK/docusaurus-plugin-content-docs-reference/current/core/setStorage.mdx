# Mastra.setStorage()

使用 `.setStorage()` 為 Mastra 實例設定儲存實例。此方法只接受一個 `MastraCompositeStore` 參數。

## 使用示例 {/* #usage-example */}

```typescript
mastra.setStorage(
  new LibSQLStore({
    id: 'mastra-storage',
    url: ':memory:',
  }),
)
```
