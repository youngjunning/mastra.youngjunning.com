# Mastra.setLogger()

這`.setLogger()`方法用於設定 Mastra 實例中所有元件（Agent程式、Workflow等）的記錄器。此方法接受帶有記錄器屬性的單一物件參數。

## 使用範例 {/* #usage-example */}

```typescript
mastra.setLogger({ logger: new PinoLogger({ name: 'testLogger' }) })
```
