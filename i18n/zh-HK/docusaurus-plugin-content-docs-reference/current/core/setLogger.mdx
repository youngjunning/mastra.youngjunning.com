# Mastra.setLogger()

使用 `.setLogger()` 可為 Mastra 實例內的所有組件（例如 Agent 和 Workflow）設定日誌記錄器。此方法只接受一個物件，透過 logger 屬性指定日誌記錄器。

## 使用示例 {/* #usage-example */}

```typescript
mastra.setLogger({ logger: new PinoLogger({ name: 'testLogger' }) })
```
