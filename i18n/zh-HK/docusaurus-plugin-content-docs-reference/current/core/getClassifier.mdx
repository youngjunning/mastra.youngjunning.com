# getClassifier()

`getClassifier()` 按註冊鍵查找 Mastra 實例中已註冊的分類器，找不到時會擲出錯誤。

## 使用示例 {/* #usage-example */}

```typescript
import { mastra } from './mastra'

const safety = mastra.getClassifier('safety')

const result = await safety.decide({
  state: { content: 'A message to evaluate' },
})
```

## 錯誤處理 {/* #error-handling */}

如指定鍵未有註冊分類器，此方法會擲出 `MastraError`，錯誤 ID 為 `MASTRA_GET_CLASSIFIER_NOT_FOUND`。
