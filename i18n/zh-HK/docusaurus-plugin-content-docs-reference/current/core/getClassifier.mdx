# 取得分類器()

這`getClassifier()`方法檢索使用其註冊密鑰向 Mastra 實例註冊的分類器。如果未找到請求的分類器，它將引發錯誤。

## 使用範例 {/* #usage-example */}

```typescript
import { mastra } from './mastra'

const safety = mastra.getClassifier('safety')

const result = await safety.decide({
  state: { content: 'A message to evaluate' },
})
```

## 錯誤處理 {/* #error-handling */}

這個方法拋出一個`MastraError` with id `MASTRA_GET_CLASSIFIER_NOT_FOUND` if no classifier is registered under the specified key.
