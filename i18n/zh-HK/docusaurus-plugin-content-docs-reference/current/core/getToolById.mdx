# Mastra.getToolById()

這`.getToolById()`方法首先在 Mastra 級註冊表中搜尋具有匹配內在的Tool`id`。如果沒有匹配的內在 ID，它將將該值視為註冊密鑰。

## 使用範例 {/* #usage-example */}

本範例使用`weather` as the registration key and `weather-tool` as the tool's intrinsic ID.

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core/mastra'
import { createTool } from '@mastra/core/tools'
import { z } from 'zod'

const weatherTool = createTool({
  id: 'weather-tool',
  description: 'Fetches weather for a location',
  inputSchema: z.object({
    location: z.string(),
  }),
  outputSchema: z.object({
    weather: z.string(),
  }),
  execute: async ({ location }) => ({
    weather: `Weather for ${location}`,
  }),
})

export const mastra = new Mastra({
  tools: {
    weather: weatherTool,
  },
})

const toolById = mastra.getToolById('weather-tool')
```
