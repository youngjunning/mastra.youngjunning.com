# Mastra.getAgent()

使用 `.getAgent()` 可按名稱取得 Agent，亦可選擇傳入版本選擇條件。如有傳入，此方法便會回傳 Promise。

## 使用示例 {/* #usage-example */}

```typescript
mastra.getAgent('testAgent')
```
