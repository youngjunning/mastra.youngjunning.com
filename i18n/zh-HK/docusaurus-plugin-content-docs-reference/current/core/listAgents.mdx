# Mastra.listAgents()

這`.listAgents()`方法用於檢索已在 Mastra 實例中配置的所有Agent程式。

## 使用範例 {/* #usage-example */}

```typescript
mastra.listAgents()
```

## 參數 {/* #parameters */}

此方法不接受任何參數。
