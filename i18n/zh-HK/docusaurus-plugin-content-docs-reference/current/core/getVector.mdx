# Mastra.getVector()

這`.getVector()`方法用於透過名稱檢索向量儲存。該方法接受單一`string`向量儲存名稱的參數。

## 使用範例 {/* #usage-example */}

```typescript
mastra.getVector('testVectorStore')
```
