# Mastra.getVector()

使用 `.getVector()` 可按名稱取得向量儲存。此方法只接受一個 `string` 參數，即向量儲存的名稱。

## 使用示例 {/* #usage-example */}

```typescript
mastra.getVector('testVectorStore')
```
