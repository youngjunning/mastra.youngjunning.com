# Mastra.listWorkflows()

這`.listWorkflows()`方法用於檢索已在 Mastra 實例中配置的所有Workflow。此方法接受一個可選的選項物件。

## 使用範例 {/* #usage-example */}

```typescript
mastra.listWorkflows()
```
