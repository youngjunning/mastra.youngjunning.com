# Mastra.listWorkflows()

使用 `.listWorkflows()` 可取得 Mastra 實例中已配置的所有 Workflow。此方法可接受選填的選項物件。

## 使用示例 {/* #usage-example */}

```typescript
mastra.listWorkflows()
```

  optional: true,
},
]}

},
