# Mastra.getGatewayById()

按 gateway 本身的唯一 ID（gateway 實例的 `id` 屬性）取得 gateway。需要按固有識別碼而非註冊鍵尋找 gateway 時，此方法很實用。

## 使用範例 {/* #usage-example */}

```typescript
import { Mastra } from '@mastra/core'

const mastra = new Mastra({
  gateways: {
    customKey: new MyCustomGateway(), // id = 'my-custom-gateway'
  },
})

// Retrieve by ID (not registration key)
const gateway = mastra.getGatewayById('my-custom-gateway')
console.log(gateway.name) // 'My Custom Gateway'
```

## 投擲 {/* #throws */}

如果没有已註冊的 gateway 使用指定 ID，则擲回 ID 為 `MASTRA_GET_GATEWAY_BY_ID_NOT_FOUND` 的 `MastraError`。gateway 可能未註冊时，請使用 `try`/`catch` 包住呼叫：

```typescript
let gateway
try {
  gateway = mastra.getGatewayById('my-custom-gateway')
} catch {
  // Gateway is not registered
}
```
