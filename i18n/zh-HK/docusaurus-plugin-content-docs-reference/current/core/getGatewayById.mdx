# Mastra.getGatewayById()

透過其唯一 ID 檢索網關（`id`網關實例的屬性）。當您需要透過其固有識別碼而不是註冊密鑰來尋找網關時，這非常有用。

## 使用範例 {/* #usage-example */}

```typescript
import { Mastra } from '@mastra/core'

const mastra = new Mastra({
  gateways: {
    customKey: new MyCustomGateway(), // id = 'my-custom-gateway'
  },
})

// Retrieve by ID (not registration key)
const gateway = mastra.getGatewayById('my-custom-gateway')
console.log(gateway.name) // 'My Custom Gateway'
```

## 使用案例 {/* #use-cases */}

* 網關版本控制：具有唯一 ID 的不同版本（`'gateway-v1'`, `'gateway-v2'`)
* 當註冊金鑰未知時尋找網關
* 辨識不同 Mastra 實例之間的網關

## 投擲 {/* #throws */}

拋出一個`MastraError` with ID `MASTRA_GET_GATEWAY_BY_ID_NOT_FOUND` if no registered gateway has the specified ID. Wrap the call in `try`/`catch` when the gateway might not be registered:

```typescript
let gateway
try {
  gateway = mastra.getGatewayById('my-custom-gateway')
} catch {
  // Gateway is not registered
}
```
