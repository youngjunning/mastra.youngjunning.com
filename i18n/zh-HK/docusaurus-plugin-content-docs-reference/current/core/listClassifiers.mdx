# 列表分類器()

這`listClassifiers()`方法傳回已在 Mastra 實例中註冊的所有分類器，以註冊密鑰為鍵。

## 使用範例 {/* #usage-example */}

```typescript
import { mastra } from './mastra'

const classifiers = mastra.listClassifiers()

for (const [key, classifier] of Object.entries(classifiers)) {
  console.log(key, classifier.id)
}
```
