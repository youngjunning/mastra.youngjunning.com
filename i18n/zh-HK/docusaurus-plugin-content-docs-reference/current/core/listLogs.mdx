# Mastra.listLogs()

這`.listLogs()`方法用於檢索特定傳輸 ID 的所有日誌。此方法需要一個配置的記錄器支持`listLogs`手術。

## 使用範例 {/* #usage-example */}

```typescript
mastra.listLogs('456')
```
