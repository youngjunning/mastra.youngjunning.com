# handleChatStream()

這個框架無關的處理函式會以兼容 AI SDK 的格式串流輸出 Agent 聊天內容。如需在 Hono 或 Mastra 內置的 [apiRoutes](/docs/server/custom-api-routes) 功能以外處理聊天串流，可直接使用它。

`handleChatStream()` 會傳回 `ReadableStream`，可使用 [`createUIMessageStreamResponse()`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/create-ui-message-stream-response) 將其封裝為回應。

為保持向後兼容，`handleChatStream()` 預設使用 AI SDK v5。請傳入與已安裝 AI SDK 相符的版本，例如 AI SDK v7 使用 `version: 'v7'`。

如需在 Mastra 伺服器中建立聊天路由，請使用 [`chatRoute()`](/reference/ai-sdk/chat-route)。

## UI 串流中的結構化輸出 {/* #structured-output-in-ui-streams */}

將 `structuredOutput` 傳入底層 Agent 執行時，最終的結構化輸出物件會以自訂資料片段的形式，送入兼容 AI SDK 的 UI 串流：

```json
{
  "type": "data-structured-output",
  "data": {
    "object": {}
  }
}
```

`object` 欄位包含完整的結構化輸出值。Mastra 只會針對最終輸出物件發出此事件；UI 串流不會提供部分結構化輸出片段。

可透過 AI SDK UI 的自訂資料處理機制（例如 `onData`）讀取此事件，也可以從訊息的資料片段呈現它。

## 使用範例 {/* #usage-example */}

Next.js App Router 範例：

```typescript title="app/api/chat/route.ts"
import { handleChatStream } from '@mastra/ai-sdk'
import { createUIMessageStreamResponse } from 'ai'
import { mastra } from '@/src/mastra'

export async function POST(req: Request) {
  const params = await req.json()
  const stream = await handleChatStream({
    mastra,
    agentId: 'weatherAgent',
    version: 'v7',
    params,
    messageMetadata: () => ({ createdAt: new Date().toISOString() }),
  })
  return createUIMessageStreamResponse({ stream })
}
```

## 保持連線 {/* #keeping-connections-alive */}

Proxy 與負載平衡器通常會關閉一段時間未傳送位元組的連線，導致長時間推理或緩慢呼叫 Tool 時回應中斷。可用 [`withSseHeartbeat()`](/reference/ai-sdk/with-sse-heartbeat) 封裝已編碼的回應，在串流閒置時定期送出 SSE 註解：

```typescript title="app/api/chat/route.ts"
import { handleChatStream, withSseHeartbeat } from '@mastra/ai-sdk'
import { createUIMessageStreamResponse } from 'ai'

return withSseHeartbeat(createUIMessageStreamResponse({ stream }), 15000)
```
