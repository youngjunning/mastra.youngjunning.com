# 處理聊天流程()

與框架無關的處理程序，用於以 AI SDK 相容格式進行串流Agent聊天。當您需要在 Hono 或 Mastra 自己的外部處理聊天流程時，直接使用此功能[apiRoutes](/docs/server/custom-api-routes)特徵。

`handleChatStream()`返回一個`ReadableStream` that you can wrap with [`createUIMessageStreamResponse()`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/create-ui-message-stream-response).

`handleChatStream()`預設為 AI SDK v5 以實現向後相容。傳入與您安裝的AI SDK相符的版本，例如`version: 'v7'` for AI SDK v7.

使用[`chatRoute()`](/reference/ai-sdk/chat-route) if you want to create a chat route inside a Mastra server.

## UI 流中的結構化輸出 {/* #structured-output-in-ui-streams */}

當你通過時`structuredOutput` to the underlying agent execution, the final structured output object is emitted in the AI SDK-compatible UI stream as a custom data part:

```json
{
  "type": "data-structured-output",
  "data": {
    "object": {}
  }
}
```

這`object` field contains your full structured output value. Mastra emits this event for the final structured output object only. Partial structured output chunks aren't exposed in the UI stream.

使用AI SDK UI的自訂資料處理讀取此事件，例如`onData`, or render it from message data parts.

## 使用範例 {/* #usage-example */}

Next.js 應用程式路由器範例：

```typescript title="app/api/chat/route.ts"
import { handleChatStream } from '@mastra/ai-sdk'
import { createUIMessageStreamResponse } from 'ai'
import { mastra } from '@/src/mastra'

export async function POST(req: Request) {
  const params = await req.json()
  const stream = await handleChatStream({
    mastra,
    agentId: 'weatherAgent',
    version: 'v7',
    params,
    messageMetadata: () => ({ createdAt: new Date().toISOString() }),
  })
  return createUIMessageStreamResponse({ stream })
}
```

## 保持連線活躍 {/* #keeping-connections-alive */}

Agent和負載平衡器通常會關閉一段時間內不發送任何位元組的連接，這會在長時間推理突發或緩慢的Tool呼叫期間丟棄回應。將編碼後的回應包裹起來[`withSseHeartbeat()`](/reference/ai-sdk/with-sse-heartbeat) to emit periodic SSE comments while the stream is idle:

```typescript title="app/api/chat/route.ts"
import { handleChatStream, withSseHeartbeat } from '@mastra/ai-sdk'
import { createUIMessageStreamResponse } from 'ai'

return withSseHeartbeat(createUIMessageStreamResponse({ stream }), 15000)
```
