# networkRoute()

:::warning[已棄用]

Agent 網絡已棄用，並會在未來版本移除。請改用[監督 Agent](/docs/subagents)，並呼叫 `agent.stream()` 或 `agent.generate()`。升級方法請參閱[遷移指南](/reference/migrations/network-to-supervisor)。

:::

建立網絡路由處理器，以 AI SDK 格式串流傳回網絡執行結果。此函式會註冊一個 HTTP `POST` 端點，接收訊息並執行 Agent 網絡，再以兼容 AI SDK 的格式將回應串流傳送至客戶端。Agent 網絡讓路由 Agent 可將工作委派給其他 Agent。請在[自訂 API 路由](/docs/server/custom-api-routes)中使用此函式。

如需與框架無關的處理器，請使用 [`handleNetworkStream()`](/reference/ai-sdk/handle-network-stream)。

`networkRoute()` 預設沿用 AI SDK v5 的現有行為。如應用程式的類型定義基於 AI SDK v6，請傳入 `version: 'v6'`。

## 使用範例 {/* #usage-example */}

以下範例在 `/network` 端點設定網絡路由，使用 ID 為 `weatherAgent` 的 Agent。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { networkRoute } from '@mastra/ai-sdk'

export const mastra = new Mastra({
  server: {
    apiRoutes: [
      networkRoute({
        path: '/network',
        agent: 'weatherAgent',
      }),
    ],
  },
})
```

亦可按執行時提供的 `agentId` 將請求路由至相應的 Agent。URL `/network/weatherAgent` 會解析至 ID 為 `weatherAgent` 的 Agent。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { networkRoute } from '@mastra/ai-sdk'

export const mastra = new Mastra({
  server: {
    apiRoutes: [
      networkRoute({
        path: '/network/:agentId',
      }),
    ],
  },
})
```

## 附加配置 {/* #additional-configuration */}

可使用 [`prepareSendMessagesRequest`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/use-chat#transport.default-chat-transport.prepare-send-messages-request) 自訂傳送至網絡路由的請求，例如向 Agent 傳入額外設定：

```typescript
const { error, status, sendMessage, messages, regenerate, stop } = useChat({
  transport: new DefaultChatTransport({
    api: 'http://localhost:4111/network',
    prepareSendMessagesRequest({ messages }) {
      return {
        body: {
          messages,
          // Pass memory config
          memory: {
            thread: 'user-1',
            resource: 'user-1',
          },
        },
      }
    },
  }),
})
```
