# toAISdkMessages()

將不同輸入格式的訊息轉換為 AI SDK UI 訊息格式。`toAISdkMessages()` 預設維持現有的 AI SDK v5 行為。如果應用程式使用 AI SDK v6 類型，請傳入 `version: 'v6'`。

`version: 'v6'` 使用 MessageList 的 AI SDK v6 UI 輸出路徑。MessageList 對輸入的偵測與接收方式維持不變。

## 使用範例 {/* #usage-example */}

```typescript title="app/chat/page.tsx" oxfmt:false
import { toAISdkMessages } from '@mastra/ai-sdk/ui'
import { useChat } from 'ai/react'

// Stored messages from your database, memory, or API
const storedMessages = [
  { id: '1', role: 'user', content: 'Hello', parts: [{ type: 'text', text: 'Hello' }] },
  {
    id: '2',
    role: 'assistant',
    content: 'Hi there!',
    parts: [{ type: 'text', text: 'Hi there!' }],
  },
]

export default function Chat() {
  const { messages } = useChat({
    initialMessages: toAISdkMessages(storedMessages, { version: 'v6' }),
  })

  return (
    <div>
      {messages.map(message => (
        <div key={message.id}>
          {message.role}: {message.parts.map(part => (part.type === 'text' ? part.text : null))}
        </div>
      ))}
    </div>
  )
}
```

## 終止錯誤部分 {/* #terminal-error-parts */}

當 v2 Agent 遇到導致該回合終止的錯誤時，Mastra 會在失敗的助理回合中儲存一個 `error` 部分。儲存的內容只包含錯誤名稱及訊息：

```typescript
const terminalErrorPart = {
  type: 'error',
  error: {
    name: 'Error',
    message: 'The model request failed.',
  },
}
```

`toAISdkMessages()` 會在 AI SDK UI 訊息中保留這個部分，讓應用程式顯示歷史記錄中失敗的回合。Mastra 將訊息轉換為 Provider 提示時會移除 `error` 部分。如果助理訊息只包含 `error` 部分，下一次模型請求便會略過該訊息。

## 範例 {/* #examples */}

### 使用預設的 AI SDK v5 類型 {/* #using-the-default-ai-sdk-v5-types */}

```typescript
import { toAISdkMessages } from '@mastra/ai-sdk/ui'

const messages = toAISdkMessages(['Hello', 'How can I help you today?'])
```

### 傳回 AI SDK v6 訊息類型 {/* #returning-ai-sdk-v6-message-types */}

```typescript
import { toAISdkMessages } from '@mastra/ai-sdk/ui'

const messages = toAISdkMessages(['Hello', 'How can I help you today?'], {
  version: 'v6',
})
```

### 使用 Mastra 客戶端載入訊息 {/* #loading-messages-with-mastra-client */}

```typescript
import { MastraClient } from '@mastra/client-js'
import { toAISdkMessages } from '@mastra/ai-sdk/ui'

const client = new MastraClient()

const { messages } = await client.listThreadMessages('thread-id', { agentId: 'myAgent' })
const uiMessages = toAISdkMessages(messages)
```
