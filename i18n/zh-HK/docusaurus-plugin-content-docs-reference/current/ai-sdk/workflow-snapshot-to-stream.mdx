# workflowSnapshotToStream()

將 `WorkflowState` 物件（由 `workflow.getWorkflowRunById()` 傳回）轉換為包含 AI SDK UIMessage 資料部分的 `ReadableStream`。該串流包含 `WorkflowDataPart` 及 `WorkflowStepDataPart` 資料區塊，與即時 [`workflowRoute()`](/reference/ai-sdk/workflow-route) 產生的內容相同。

如果要使用呈現即時 Workflow 串流的同一套 UI 元件來顯示已完成或已暫停的 Workflow 執行，請使用此函數。

## 使用範例 {/* #usage-example */}

以下 Next.js App Router 端點會將過去的 Workflow 執行重播為串流：

```typescript title="app/api/workflow-replay/route.ts"
import { workflowSnapshotToStream } from '@mastra/ai-sdk'
import { createUIMessageStreamResponse } from 'ai'
import { mastra } from '@/src/mastra'

export async function GET(req: Request) {
  const { searchParams } = new URL(req.url)
  const runId = searchParams.get('runId')!

  const workflowRun = await mastra.getWorkflow('myWorkflow').getWorkflowRunById(runId)

  if (!workflowRun) {
    return new Response('Not found', { status: 404 })
  }

  const stream = workflowSnapshotToStream(workflowRun)
  return createUIMessageStreamResponse({ stream })
}
```

## 傳回值 {/* #returns */}

`ReadableStream`：AI SDK UIMessage 資料部分的流，包含：

* 一個 `start` 標記
* 一個包含 Workflow 狀態及所有步驟摘要的 `WorkflowDataPart`
* 每個步驟各有一個包含完整輸出的 `WorkflowStepDataPart`
* 一個 `finish` 標記

將此串流傳遞給 AI SDK 的 [`createUIMessageStreamResponse()`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/create-ui-message-stream-response) 或 `createUIMessageStream()`。
