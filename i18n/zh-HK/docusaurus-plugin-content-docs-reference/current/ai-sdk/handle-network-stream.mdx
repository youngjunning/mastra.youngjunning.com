# handleNetworkStream()

:::warning[已棄用]

Agent network 已棄用，未來版本將會移除。請改用[監督 Agent](/docs/subagents)，並呼叫 `agent.stream()` 或 `agent.generate()`。升級步驟請參閱[遷移指南](/reference/migrations/network-to-supervisor)。

:::

此處理函數不依賴特定框架，會以 AI SDK 相容格式串流執行 Agent network。如需在 Hono 或 Mastra 本身的 [apiRoutes](/docs/server/custom-api-routes) 功能以外處理 network 串流，可直接使用此函數。

`handleNetworkStream()` 會傳回 `ReadableStream`，可使用 [`createUIMessageStreamResponse()`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/create-ui-message-stream-response) 將其包裝為回應。

`handleNetworkStream()` 預設維持現有的 AI SDK v5 行為。如果應用程式的型別定義以 AI SDK v6 為準，請傳入 `version: 'v6'`。

如要在 Mastra 伺服器內建立 network 路由，請使用 [`networkRoute()`](/reference/ai-sdk/network-route)。

## 使用示例 {/* #usage-example */}

Next.js App Router 示例：

```typescript title="app/api/network/route.ts"
import { handleNetworkStream } from '@mastra/ai-sdk'
import { createUIMessageStreamResponse } from 'ai'
import { mastra } from '@/src/mastra'

export async function POST(req: Request) {
  const params = await req.json()
  const stream = await handleNetworkStream({
    mastra,
    agentId: 'routingAgent',
    params,
  })
  return createUIMessageStreamResponse({ stream })
}
```
