# NetlifyDeployer

`NetlifyDeployer` 透過調整 Mastra 的建置輸出，完成伺服器的封裝、設定及部署，並產生經優化的伺服器版本。它在基礎 [`Deployer`](/reference/deployer/) 類別上加入 Netlify 專屬功能，讓 Mastra 可在 Netlify Functions 或 Edge Functions 中執行。

## 安裝 {/* #installation */}

要使用 `NetlifyDeployer`，請安裝 `@mastra/deployer-netlify` 套件：

```bash npm2yarn
npm install @mastra/deployer-netlify@latest
```

## 使用範例 {/* #usage-example */}

匯入 `NetlifyDeployer`，並在 Mastra 設定中將其設為 deployer：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
// highlight-next-line
import { NetlifyDeployer } from '@mastra/deployer-netlify'

export const mastra = new Mastra({
  // highlight-next-line
  deployer: new NetlifyDeployer(),
})
```

## 建構函數選項 {/* #constructor-options */}

- `target?: 'serverless' | 'edge'`：Netlify 部署目標，預設為 `'serverless'`。
  - `'serverless'`：標準 [Netlify Functions](https://docs.netlify.com/functions/overview/)；使用 Node.js 執行環境，預設逾時為 60 秒。
  - `'edge'`：[Netlify Edge Functions](https://docs.netlify.com/build/edge-functions/overview/)；使用以 Deno 為基礎的執行環境，在最接近用戶的邊緣節點執行，並無固定逾時。

### Edge Functions 範例 {/* #edge-functions-example */}

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { NetlifyDeployer } from '@mastra/deployer-netlify'

export const mastra = new Mastra({
  deployer: new NetlifyDeployer({
    target: 'edge',
  }),
})
```

## 輸出 {/* #output */}

執行 `mastra build` 後，deployer 會產生 `.netlify` 資料夾。建置輸出包含專案中的所有 Agent、Tool 及 Workflow，以及用來設定 [Netlify Frameworks API](https://docs.netlify.com/build/frameworks/frameworks-api/) 的 `config.json` 檔案。

### Serverless 輸出（預設） {/* #serverless-output-default */}

```bash
your-project/
└── .netlify/
    └── v1/
        ├── config.json
        └── functions/
            └── api/
                ├── index.mjs
                ├── package.json
                └── node_modules/
```

`config.json` 檔案內容如下：

```json
{
  "functions": {
    "directory": ".netlify/v1/functions",
    "node_bundler": "none",
    "included_files": [".netlify/v1/functions/**"]
  },
  "redirects": [
    {
      "force": true,
      "from": "/*",
      "to": "/.netlify/functions/api/:splat",
      "status": 200
    }
  ]
}
```

### Edge 輸出 {/* #edge-output */}

```bash
your-project/
└── .netlify/
    └── v1/
        ├── config.json
        └── edge-functions/
            ├── index.mjs
            ├── package.json
            └── node_modules/
```

`config.json` 檔案內容如下：

```json
{
  "edge_functions": [
    {
      "function": "index",
      "path": "/*"
    }
  ]
}
```
