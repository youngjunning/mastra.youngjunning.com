# Sandbox進程管理器

**添加於：** `@mastra/core@1.7.0`

用於管理沙箱中後台進程的抽象基底類別。提供產生進程、列出進程、透過 PID 取得句柄以及終止進程的方法。

[`BlaxelSandbox`](/integrations/sandboxes/blaxel), [`DaytonaSandbox`](/integrations/sandboxes/daytona), [`E2BSandbox`](/integrations/sandboxes/e2b), [`ModalSandbox`](/integrations/sandboxes/modal)， 和[`LocalSandbox`](/reference/workspace/local-sandbox)所有這些都包含內建的流程管理器。除非您正在建立自訂沙箱提供程序，否則不需要直接實例化此類。

## 使用範例 {/* #usage-example */}

透過沙箱存取進程管理器`processes` property:

```typescript title="src/mastra/index.ts"
import { LocalSandbox } from '@mastra/core/workspace'

const sandbox = new LocalSandbox({ workingDirectory: './workspace' })
await sandbox.start()

// Spawn a background process
const handle = await sandbox.processes.spawn('node server.js', {
  env: { PORT: '3000' },
  onStdout: data => console.log(data),
})

// List all tracked processes
const procs = await sandbox.processes.list()

// Get a handle by PID
const proc = await sandbox.processes.get(handle.pid)

// Kill a process
await sandbox.processes.kill(handle.pid)
```

## 方法 {/* #methods */}

### `spawn(command, options?)` {/* #spawncommand-options */}

產生一個後台進程。返回一個`ProcessHandle` immediately without waiting for the process to finish.

```typescript
const handle = await sandbox.processes.spawn('npm run dev', {
  cwd: '/app',
  env: { NODE_ENV: 'development' },
  onStdout: data => console.log(data),
})
```

### `list()` {/* #list */}

列出所有追蹤的進程。傳回有關每個進程的信息，包括 PID、運行狀態和退出代碼。

已退出的進程將保留在清單中，直到有人用以下命令讀取它`get(pid)`, so a finished command's output can still be read.

```typescript
const procs = await sandbox.processes.list()
for (const proc of procs) {
  console.log(proc.pid, proc.running, proc.exitCode)
}
```

**返回：** `Promise<ProcessInfo[]>`

### `get(pid, options?)` {/* #getpid-options */}

透過PID取得進程句柄。退貨`undefined` if the process isn't found or has already been dismissed.

讀取已退出的進程會將其解散：稍後呼叫 return`undefined` and it leaves `list()`. Pass `{ release: false }` to read it and leave it available, so one reader can look at a finished process's output without taking it from another, such as the agent that started it.

```typescript
const handle = await sandbox.processes.get('1234')
if (handle) {
  console.log(handle.stdout)
  await handle.kill()
}

// Read without dismissing an exited process
const peek = await sandbox.processes.get('1234', { release: false })
```

### `kill(pid)` {/* #killpid */}

透過PID殺死一個行程。返回之前等待進程終止。退貨`true` if the process was killed, `false` if it wasn't found.

```typescript
const killed = await sandbox.processes.kill(handle.pid)
```

**返回：** `Promise<boolean>`

## `ProcessHandle` {/* #processhandle */}

產生的後台程序的句柄。提供讀取輸出、發送或關閉標準輸入、等待完成、終止進程的方法。

你不創造`ProcessHandle` instances directly. They're returned by `spawn()` and `get()`.

### 使用範例 {/* #usage-example-1 */}

```typescript
const handle = await sandbox.processes.spawn('npm run dev', {
  onStdout: data => console.log(data),
})

// Read accumulated output
console.log(handle.pid)
console.log(handle.stdout)
console.log(handle.stderr)
console.log(handle.exitCode) // undefined while running

// Wait for completion
const result = await handle.wait()

// Send stdin and signal EOF
await handle.sendStdin('input data\n')
await handle.closeStdin()

// Kill the process
await handle.kill()
```

### 方法 {/* #methods-1 */}

#### `wait(options?)` {/* #waitoptions */}

等待進程退出並傳回結果。可選擇透過`onStdout`/`onStderr` callbacks to stream output while waiting. Callbacks are automatically removed when `wait()` resolves.

```typescript
// Simple wait
const result = await handle.wait()
console.log(result.success, result.exitCode, result.stdout)

// Wait with streaming
const result = await handle.wait({
  onStdout: data => process.stdout.write(data),
  onStderr: data => process.stderr.write(data),
})
```

#### `kill()` {/* #kill */}

殺死進程。退貨`true` if the process was killed, `false` if it had already exited.

```typescript
const killed = await handle.kill()
```

**返回：** `Promise<boolean>`

#### `sendStdin(data)` {/* #sendstdindata */}

將資料傳送到進程的標準輸入。如果進程已退出或標準輸入不可用，則拋出此例外。

```typescript
await handle.sendStdin('console.log("hello")\n')
```

**返回：** `Promise<void>`

#### `closeStdin()` {/* #closestdin */}

關閉進程的標準輸入以發出檔案結束 (EOF) 訊號。在將所有輸入發送到讀取的命令後使用此命令，直到 stdin 關閉。退出的進程或不可用的標準輸入會導致拋出例外。沒有標準輸入的提供者關閉原語拋出`UnsupportedStdinCloseError`.

```typescript
const handle = await sandbox.processes.spawn('cat')
await handle.sendStdin('input data\n')
await handle.closeStdin()
const result = await handle.wait()
```

呼喚`handle.writer.end()` also closes stdin. On providers without stdin close support, `writer.end()` finishes the stream without an error.

**返回：** `Promise<void>`

## 串流互通 {/* #stream-interop */}

`ProcessHandle`暴露`reader` and `writer` properties for integration with Node.js stream-based protocols like LSP or JSON-RPC:

```typescript
import {
  createMessageConnection,
  StreamMessageReader,
  StreamMessageWriter,
} from 'vscode-jsonrpc/node'

const handle = await sandbox.processes.spawn('typescript-language-server --stdio')

const connection = createMessageConnection(
  new StreamMessageReader(handle.reader),
  new StreamMessageWriter(handle.writer),
)
connection.listen()
```

## 建立自訂流程管理器 {/* #building-a-custom-process-manager */}

若要為自訂沙箱提供程式建立流程管理器，請擴展`SandboxProcessManager` and implement `spawn()` and `list()`. The base class automatically wraps your methods with `ensureRunning()` so the sandbox starts before any process operation.

```typescript
import { SandboxProcessManager, ProcessHandle } from '@mastra/core/workspace'
import type { ProcessInfo, SpawnProcessOptions } from '@mastra/core/workspace'

class MyProcessManager extends SandboxProcessManager<MySandbox> {
  async spawn(command: string, options: SpawnProcessOptions = {}): Promise<ProcessHandle> {
    // Your spawn implementation
    const handle = new MyProcessHandle(/* ... */)
    this._tracked.set(handle.pid, handle)
    return handle
  }

  async list(): Promise<ProcessInfo[]> {
    return Array.from(this._tracked.values()).map(handle => ({
      pid: handle.pid,
      running: handle.exitCode === undefined,
      exitCode: handle.exitCode,
    }))
  }
}
```

透過以下方式將進程管理器傳遞到您的沙箱`processes` option in `MastraSandbox`:

```typescript
class MySandbox extends MastraSandbox {
  constructor() {
    super({
      name: 'MySandbox',
      processes: new MyProcessManager(),
    })
  }
}
```

當提供流程管理器時，`MastraSandbox` automatically creates a default `executeCommand` implementation that uses `spawn()` + `wait()`, so you don't need to implement both.
