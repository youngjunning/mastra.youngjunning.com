# SandboxProcessManager

**新增於：** `@mastra/core@1.7.0`

用於管理沙盒背景程序的抽象基底類別。提供啟動程序、列出程序、按 PID 取得處理程序及終止程序的方法。

[`BlaxelSandbox`](/integrations/sandboxes/blaxel)、[`DaytonaSandbox`](/integrations/sandboxes/daytona)、[`E2BSandbox`](/integrations/sandboxes/e2b)、[`ModalSandbox`](/integrations/sandboxes/modal) 和 [`LocalSandbox`](/reference/workspace/local-sandbox) 都內置程序管理器。只有建立自訂沙盒 Provider 時才需要直接實例化此類。

## 使用範例 {/* #usage-example */}

透過沙盒的 `processes` 屬性存取程序管理器：

```typescript title="src/mastra/index.ts"
import { LocalSandbox } from '@mastra/core/workspace'

const sandbox = new LocalSandbox({ workingDirectory: './workspace' })
await sandbox.start()

// Spawn a background process
const handle = await sandbox.processes.spawn('node server.js', {
  env: { PORT: '3000' },
  onStdout: data => console.log(data),
})

// List all tracked processes
const procs = await sandbox.processes.list()

// Get a handle by PID
const proc = await sandbox.processes.get(handle.pid)

// Kill a process
await sandbox.processes.kill(handle.pid)
```

## 方法 {/* #methods */}

### `spawn(command, options?)` {/* #spawncommand-options */}

啟動背景程序，立即傳回 `ProcessHandle`，毋須等待程序結束。

```typescript
const handle = await sandbox.processes.spawn('npm run dev', {
  cwd: '/app',
  env: { NODE_ENV: 'development' },
  onStdout: data => console.log(data),
})
```

### `list()` {/* #list */}

列出所有受追蹤的程序。傳回每個程序的 PID、執行狀態和結束代碼等資訊。

已結束的程序會保留在清單中，直到透過 `get(pid)` 讀取，因此仍可讀取已完成命令的輸出。

```typescript
const procs = await sandbox.processes.list()
for (const proc of procs) {
  console.log(proc.pid, proc.running, proc.exitCode)
}
```

**返回：** `Promise<ProcessInfo[]>`

### `get(pid, options?)` {/* #getpid-options */}

按 PID 取得程序處理程序。如找不到該程序，或該程序已從追蹤清單中移除，則傳回 `undefined`。

讀取已結束的程序會將其從追蹤清單中移除：之後呼叫 `get()` 會傳回 `undefined`，`list()` 亦不再列出它。傳入 `{ release: false }` 可讀取程序並保留它，讓一位讀取者查看已完成程序的輸出，同時不影響其他讀取者（例如啟動該程序的 Agent）。

```typescript
const handle = await sandbox.processes.get('1234')
if (handle) {
  console.log(handle.stdout)
  await handle.kill()
}

// Read without dismissing an exited process
const peek = await sandbox.processes.get('1234', { release: false })
```

### `kill(pid)` {/* #killpid */}

按 PID 終止程序，並等待其結束後傳回。成功終止時傳回 `true`；找不到程序時傳回 `false`。

```typescript
const killed = await sandbox.processes.kill(handle.pid)
```

**返回：** `Promise<boolean>`

## `ProcessHandle` {/* #processhandle */}

已啟動背景程序的處理程序。可用於讀取輸出、傳送或關閉標準輸入、等待程序結束，以及終止程序。

毋須直接建立 `ProcessHandle` 實例；`spawn()` 和 `get()` 會傳回程序處理程序。

### 使用範例 {/* #usage-example-1 */}

```typescript
const handle = await sandbox.processes.spawn('npm run dev', {
  onStdout: data => console.log(data),
})

// Read accumulated output
console.log(handle.pid)
console.log(handle.stdout)
console.log(handle.stderr)
console.log(handle.exitCode) // undefined while running

// Wait for completion
const result = await handle.wait()

// Send stdin and signal EOF
await handle.sendStdin('input data\n')
await handle.closeStdin()

// Kill the process
await handle.kill()
```

### 方法 {/* #methods-1 */}

#### `wait(options?)` {/* #waitoptions */}

等待程序結束並傳回結果。可傳入 `onStdout` 和 `onStderr` 回調函式，在等待期間持續接收輸出。`wait()` 完成時會自動移除這些回調函式。

```typescript
// Simple wait
const result = await handle.wait()
console.log(result.success, result.exitCode, result.stdout)

// Wait with streaming
const result = await handle.wait({
  onStdout: data => process.stdout.write(data),
  onStderr: data => process.stderr.write(data),
})
```

#### `kill()` {/* #kill */}

終止程序。成功終止時傳回 `true`；程序已結束時傳回 `false`。

```typescript
const killed = await handle.kill()
```

**返回：** `Promise<boolean>`

#### `sendStdin(data)` {/* #sendstdindata */}

將數據傳送至程序的標準輸入。如果程序已結束或標準輸入不可用，則會拋出例外。

```typescript
await handle.sendStdin('console.log("hello")\n')
```

**返回：** `Promise<void>`

#### `closeStdin()` {/* #closestdin */}

關閉程序的標準輸入，以傳送檔案結束（EOF）訊號。對於持續讀取標準輸入直到其關閉的命令，請在傳送完所有數據後呼叫此方法。如果程序已結束或標準輸入不可用，則會拋出例外；如果 Provider 不支援關閉標準輸入，則會拋出 `UnsupportedStdinCloseError`。

```typescript
const handle = await sandbox.processes.spawn('cat')
await handle.sendStdin('input data\n')
await handle.closeStdin()
const result = await handle.wait()
```

呼叫 `handle.writer.end()` 亦會關閉標準輸入。如果 Provider 不支援關閉標準輸入，`writer.end()` 仍會正常結束串流，不會發生錯誤。

**返回：** `Promise<void>`

## 串流互通 {/* #stream-interop */}

`ProcessHandle` 提供 `reader` 和 `writer` 屬性，可用於整合 LSP 或 JSON-RPC 等以 Node.js 串流為基礎的協定：

```typescript
import {
  createMessageConnection,
  StreamMessageReader,
  StreamMessageWriter,
} from 'vscode-jsonrpc/node'

const handle = await sandbox.processes.spawn('typescript-language-server --stdio')

const connection = createMessageConnection(
  new StreamMessageReader(handle.reader),
  new StreamMessageWriter(handle.writer),
)
connection.listen()
```

## 建立自訂程序管理器 {/* #building-a-custom-process-manager */}

若要為自訂沙盒 Provider 建立程序管理器，請繼承 `SandboxProcessManager` 並實作 `spawn()` 和 `list()`。基底類別會自動以 `ensureRunning()` 包裝這些方法，確保執行任何程序操作前先啟動沙盒。

```typescript
import { SandboxProcessManager, ProcessHandle } from '@mastra/core/workspace'
import type { ProcessInfo, SpawnProcessOptions } from '@mastra/core/workspace'

class MyProcessManager extends SandboxProcessManager<MySandbox> {
  async spawn(command: string, options: SpawnProcessOptions = {}): Promise<ProcessHandle> {
    // Your spawn implementation
    const handle = new MyProcessHandle(/* ... */)
    this._tracked.set(handle.pid, handle)
    return handle
  }

  async list(): Promise<ProcessInfo[]> {
    return Array.from(this._tracked.values()).map(handle => ({
      pid: handle.pid,
      running: handle.exitCode === undefined,
      exitCode: handle.exitCode,
    }))
  }
}
```

透過 `MastraSandbox` 的 `processes` 選項，將程序管理器傳入沙盒：

```typescript
class MySandbox extends MastraSandbox {
  constructor() {
    super({
      name: 'MySandbox',
      processes: new MyProcessManager(),
    })
  }
}
```

提供程序管理器後，`MastraSandbox` 會自動建立使用 `spawn()` 和 `wait()` 的預設 `executeCommand` 實作，因此毋須另外實作此方法。
