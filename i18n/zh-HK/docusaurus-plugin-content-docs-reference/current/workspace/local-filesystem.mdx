# 本機檔案系統

**新增於：** `@mastra/core@1.1.0`

將檔案儲存在本機檔案系統的目錄中。介面詳情請參閱 [WorkspaceFilesystem 介面](/reference/workspace/filesystem)。

## 用法 {/* #usage */}

將 `LocalFilesystem` 加入 Workspace，再將 Workspace 指派給 Agent。Agent 之後便可在執行工作時讀取、寫入及管理檔案：

```typescript
import { Agent } from '@mastra/core/agent'
import { Workspace, LocalFilesystem } from '@mastra/core/workspace'

const workspace = new Workspace({
  filesystem: new LocalFilesystem({
    basePath: './workspace',
  }),
})

const agent = new Agent({
  id: 'file-agent',
  model: '__GATEWAY_OPENAI_MODEL__',
  workspace,
})

// The agent now has filesystem tools available
const response = await agent.generate('List all files in the workspace')
```

## 方法 {/* #methods */}

### `init()` {/* #init */}

初始化檔案系統。如果基本目錄不存在，則建立它。

```typescript
await filesystem.init()
```

由 `workspace.init()` 呼叫。

### 延遲初始化 {/* #lazy-initialization */}

如尚未初始化，LocalFilesystem 會在首次操作時自動初始化並建立基礎目錄。毋須明確呼叫 `init()`；如想在首次操作前預先建立目錄，也可呼叫它。

### `destroy()` {/* #destroy */}

清理檔案系統資源。

```typescript
await filesystem.destroy()
```

由 `workspace.destroy()` 呼叫。

### `setAllowedPaths(pathsOrUpdater)` {/* #setallowedpathspathsorupdater */}

在執行期間更新允許存取的路徑。可傳入新的路徑陣列以取代現有路徑，或傳入接收目前路徑並傳回新路徑集合的回呼函式。

```typescript
// Set directly
filesystem.setAllowedPaths(['/home/user/.config'])

// Update with callback
filesystem.setAllowedPaths(prev => [...prev, '/home/user/documents'])

// Clear all allowed paths
filesystem.setAllowedPaths([])
```

## 路徑解析 {/* #path-resolution */}

### `basePath` 的運作方式 {/* #how-basepath-works */}

`basePath` 選項設定所有檔案操作的根目錄。傳入 `readFile()` 等方法的路徑依以下規則解析：

- 相對路徑以 `basePath` 為基準解析：`docs/guide.md` → `<basePath>/docs/guide.md`
- 使用 `.` 表示 `basePath` 的根目錄，例如 `readdir('.')`
- 絕對路徑視為主機路徑，而非 `basePath` 內的路徑。預設設定 `contained: true` 時，位於 `basePath` 及設定的 `allowedPaths` 以外的絕對路徑會被拒絕，並擲出 `PermissionError`
- `~` 會展開為使用者的主目錄，因此也是主機路徑，並受相同的路徑限制規則約束

```typescript
const filesystem = new LocalFilesystem({
  basePath: './workspace',
})

// Resolves to ./workspace/docs/guide.md
await filesystem.readFile('docs/guide.md')
await filesystem.readFile('./docs/guide.md')

// Root of basePath
await filesystem.readdir('.')

// Throws a PermissionError with the default contained: true
await filesystem.readFile('/docs/guide.md')
```

如要讀取 `basePath` 以外的主機絕對路徑，可將其加入 `allowedPaths`，或設定 `contained: false`。如只需存取少數外部目錄，建議使用 `allowedPaths`。

```typescript
const filesystem = new LocalFilesystem({
  basePath: './workspace',
  allowedPaths: ['/home/user/shared-docs'],
})

await filesystem.readFile('/home/user/shared-docs/guide.md')
```

### 掛載的檔案系統 {/* #mounted-filesystems */}

透過 `CompositeFilesystem` 將 `LocalFilesystem` 掛載至 Workspace 時，Workspace 使用的路徑會包含掛載前綴。例如，掛載點為 `/workspace` 時，Workspace 路徑 `/workspace/report.md` 會以相對於 `basePath` 的 `report.md` 傳給底層檔案系統。掛載設定請參閱[檔案系統掛載](/docs/sandbox/filesystem#mounts)。

### 相對路徑和執行上下文 {/* #relative-paths-and-execution-context */}

如 `basePath` 使用相對路徑，該路徑會相對於 `process.cwd()` 解析。在 Mastra 專案中，目前工作目錄會隨程式碼的執行方式而改變：

| 執行方式 | 工作目錄 | `./workspace` 解析為 |
| - | - | - |
| `mastra dev` | `./src/mastra/public/` | `./src/mastra/public/workspace` |
| `mastra start` | `./.mastra/output/` | `./.mastra/output/workspace` |
| 直接執行腳本 | 執行命令時所在的目錄 | 相對於該目錄的路徑 |

當相同的相對路徑解析到不同的位置時，這可能會導致混亂。

### 建議使用絕對路徑 {/* #recommended-use-absolute-paths */}

為了使所有執行上下文的路徑保持一致，請使用具有絕對路徑的環境變數：

```typescript
import { LocalFilesystem } from '@mastra/core/workspace'

const filesystem = new LocalFilesystem({
  basePath: process.env.WORKSPACE_PATH!,
})
```

將環境變數 `WORKSPACE_PATH` 設為 `/home/user/my-project/workspace` 這類絕對路徑。這樣無論如何執行程式碼，Workspace 路徑都會保持一致。
