# ChannelProvider

`ChannelProvider` 是平台整合所實作的介面，用來將 Agent 連接至訊息平台。Provider 負責整合的整個生命週期，包括透過 OAuth 設定應用程式、路由 Webhook 並處理事件、建立適配器並連結 Agent，以及管理憑證。

在 `Mastra` 建構函數的 `channels` 設定中註冊 Provider，並以自訂 ID 作為鍵。各 Provider 的路由會自動併入伺服器的 API 路由；Mastra 啟動時會呼叫 `initialize()`。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core/mastra'
import { SlackProvider } from '@mastra/slack'

export const mastra = new Mastra({
  channels: {
    slack: new SlackProvider({
      refreshToken: process.env.SLACK_REFRESH_TOKEN!,
      baseUrl: process.env.MASTRA_BASE_URL,
    }),
  },
})
```

Provider 的 `baseUrl` 是平台傳送 Webhook 和事件的公開 URL。在正式環境中，它是已部署的 Mastra 伺服器 URL。本機開發時，平台無法連接 `http://localhost:4111`，因此需要運行通道服務（例如 [cloudflared](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/) 或 [ngrok](https://ngrok.com/)），並將 `baseUrl` 設為通道 URL（例如 `https://abc123.trycloudflare.com`），讓事件送達本機開發程序。

Mastra 提供 [`SlackProvider`](/reference/channels/slack-provider) 和 [`TelegramProvider`](/reference/channels/telegram-provider) 實作。你也可以實作此介面，建立自訂 Provider。

## 動態解析 {/* #dynamic-resolution */}

除了靜態物件，`channels` 亦接受解析器：一個傳回目前 Provider 對應表的非同步函數，並具有同步的 `getRoutes()` 方法。Mastra 會在建構時掛載解析器提供的路由，並在運行期間解析 Provider，因此啟動後新增的連接毋須重新部署即可使用。`channels()` 是 `@mastra/connect` 提供的輔助函數，會傳回由 Mastra 平台支援的解析器。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core/mastra'
import { channels } from '@mastra/connect'

export const mastra = new Mastra({
  channels: await channels({ projectId: process.env.MASTRA_PROJECT_ID! }),
})
```

設定解析器後，呼叫 `resolveChannels()` 可取得目前的 Provider 對應表。它亦支援靜態物件，此時會直接傳回該物件。

```typescript
const providers = await mastra.resolveChannels()
```

## 存取 Provider {/* #accessing-a-provider */}

透過 `channels` getter 和註冊時使用的 ID 存取 Provider。getter 的類型由建構函數設定推斷，因此 `mastra.channels.slack` 是具體的 Provider，可使用其所有方法。

```typescript
await mastra.channels.slack.configure({ refreshToken })
```

如果 ID 只有在運行期間才會得知，可透過字串 ID 查找 Provider。`getChannelProvider` 以泛型指定具體類型，`getChannelProviders` 則傳回按 ID 索引的所有已註冊 Provider。使用[解析器](#dynamic-resolution)時，兩者都會傳回最新解析的快照。如需反映目前平台狀態的 Provider，請使用 `resolveChannels()`。

```typescript
import type { SlackProvider } from '@mastra/slack'

const slack = mastra.getChannelProvider<SlackProvider>('slack')
const all = mastra.getChannelProviders()
```
