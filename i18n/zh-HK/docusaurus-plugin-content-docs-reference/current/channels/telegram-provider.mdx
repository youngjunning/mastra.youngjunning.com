# 電報提供者

`TelegramProvider`透過 Bot API 將 Mastra Agent連接到 Telegram 機器人。註冊於`Mastra.channels`管理機器人安裝、選擇 Webhook 或輪詢交付、驗證 Webhook 機密、註冊命令以及將 Telegram 對話路由至Agent程式。

使用`TelegramProvider` when you want Mastra to own the bot lifecycle. For the lower-level path where you configure the Telegram adapter and webhook yourself, use [`createTelegramAdapter`](/integrations/channels/telegram) on the agent's `channels.adapters`.

## 使用範例 {/* #usage-example */}

創建一個機器人[BotFather](https://t.me/botfather), set `TELEGRAM_BOT_TOKEN`, and register the provider with a public base URL for webhook delivery:

```typescript title="src/mastra/index.ts"
import { Agent } from '@mastra/core/agent'
import { Mastra } from '@mastra/core/mastra'
import { TelegramProvider } from '@mastra/telegram'

const supportAgent = new Agent({
  id: 'support',
  name: 'Support agent',
  instructions: 'Help users with product questions.',
  model: 'openai/gpt-5-mini',
})

const telegram = new TelegramProvider({
  baseUrl: 'https://your-app.example.com',
})

export const mastra = new Mastra({
  agents: { supportAgent },
  channels: { telegram },
})

await telegram.connect('support', {
  botToken: process.env.TELEGRAM_BOT_TOKEN,
})
```

什麼時候`botToken` is omitted, `connect()` creates a pending installation and returns a BotFather deep link instead of activating the bot immediately.

## 方法 {/* #methods */}

### 安裝生命週期 {/* #installation-lifecycle */}

#### `connect(agentId, options)` {/* #connectagentid-options */}

將Agent商連接到 Telegram 機器人。提供者透過以下方式驗證 BotFather 令牌`getMe`, prepares the selected delivery mode and commands, then stores the installation before activating the adapter.

```typescript
const result = await telegram.connect('support', {
  botToken: process.env.TELEGRAM_BOT_TOKEN,
  name: 'Support bot',
  commands: [
    { command: 'help', description: 'Show support options' },
    { command: 'status', description: 'Check service status' },
  ],
})
```

`TelegramConnectOptions`字段：

<PropertiesTable
  content={[
{
  name: 'botToken',
  type: 'string',
  isOptional: true,
  description:
    'BotFather token. When provided, the connection completes immediately. When omitted, connect() returns a BotFather deep link and a pending installation ID.',
},
{
  name: 'name',
  type: 'string',
  isOptional: true,
  description: "Display name for the bot. Defaults to the bot's Telegram username or first name.",
},
{
  name: 'commands',

返回：`Promise<ChannelConnectResult>`

#### `disconnect(agentId)` {/* #disconnectagentid */}

停止活動傳輸並刪除其儲存的安裝。在 Webhook 模式下，它也會刪除 Telegram Webhook。

```typescript
await telegram.disconnect('support')
```

返回：`Promise<void>`

#### `listInstallations()` {/* #listinstallations */}

列出活動和待處理的 Telegram 安裝，而不會暴露機器人或 webhook 秘密令牌。

```typescript
const installations = await telegram.listInstallations()
```

返回：`Promise<ChannelInstallationInfo[]>`

#### `getInstallation(agentId)` {/* #getinstallationagentid */}

返回Agent程式的完整安裝，包括敏感的機器人和 Webhook 令牌，或者`null` when no installation exists.

```typescript
const installation = await telegram.getInstallation('support')
```

返回：`Promise<TelegramInstallation | null>`

### 配置和狀態 {/* #configuration-and-status */}

#### `configure(credentials)` {/* #configurecredentials */}

在執行時間更新 Bot API 來源或 Webhook 基本 URL。透過`null` is a no-op because Telegram credentials belong to individual bot installations.

```typescript
await telegram.configure({
  baseUrl: 'https://new-app.example.com',
  apiBaseUrl: 'https://api.telegram.org',
})
```

返回：`Promise<void>`

#### `initialize()` {/* #initialize */}

在重新連接註冊Agent之前，從儲存中恢復活動安裝並重建其 Telegram 適配器。 Mastra 在啟動期間呼叫此方法。

```typescript
await telegram.initialize()
```

返回：`Promise<void>`

#### `isConfigured()` {/* #isconfigured */}

傳回是否存在至少一個活動的 Telegram 安裝。

```typescript
const configured = telegram.isConfigured()
```

#### `getInfo()` {/* #getinfo */}

傳回編輯器 UI 的通道發現元數據，包括連線狀態和`botToken` and `name` connect-option schema.

```typescript
const info = telegram.getInfo()
```

返回：`ChannelPlatformInfo`

#### `getAdapter(installationId)` {/* #getadapterinstallationid */}

返回直播`TelegramAdapter` for an active installation.

```typescript
const adapter = telegram.getAdapter(installationId)
```

返回：`TelegramAdapter | undefined`

#### `getRoutes()` {/* #getroutes */}

返回提供者未經身份驗證的`POST /telegram/events/:webhookId` route. Mastra registers this route automatically.

```typescript
const routes = telegram.getRoutes()
```

返回：`ApiRoute[]`

## 交付方式 {/* #delivery-modes */}

* **`webhook`**`/telegram/events/:webhookId` and verifies the `X-Telegram-Bot-Api-Secret-Token` header.
* **`polling`**&#x5728;啟動 Telegram 之前刪除任何現有的 webhook`getUpdates` loop.
* **`auto`**&#x7576;公共基本 URL 可用時選擇 Webhook，否則進行輪詢。

在生產中，使用持久通道儲存和設置`encryptionKey` or `MASTRA_ENCRYPTION_KEY`, because the in-memory fallback doesn't preserve installations across restarts.
