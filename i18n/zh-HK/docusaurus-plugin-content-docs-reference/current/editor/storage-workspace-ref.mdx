# 儲存工作空間參考

`StorageWorkspaceRef`是用於將Workspace附加到儲存的Agent程式的可區分聯合。它透過 ID 指向在 Mastra 運行時註冊的工作空間，內聯嵌入工作空間快照，或命名在 Mastra 運行時註冊的工作空間提供程序`MastraEditor.workspaces`建置Workspace。

這是使用的類型[`BuilderAgentDefaults.workspace`](https://agent-builder.mastra.ai/reference/builder-agent-defaults) and by stored agent records.

## 使用範例 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { MastraEditor } from '@mastra/editor'

// Variant 1 — reference a runtime workspace by id
new MastraEditor({
  builder: {
    enabled: true,
    configuration: {
      agent: {
        workspace: { type: 'id', workspaceId: 'builder-workspace' },
      },
    },
  },
})

// Variant 2 — inline a workspace snapshot
new MastraEditor({
  builder: {
    enabled: true,
    configuration: {
      agent: {
        workspace: {
          type: 'inline',
          config: {
            name: 'inline-builder-workspace',
            filesystem: {
              provider: 'local',
              config: { basePath: './agent-files' },
            },
          },
        },
      },
    },
  },
})

// Variant 3 — build the workspace with a registered workspace provider
new MastraEditor({
  workspaces: { 'my-provider': myWorkspaceProvider },
  builder: {
    enabled: true,
    configuration: {
      agent: {
        workspace: {
          type: 'provider',
          provider: 'my-provider',
          config: { region: 'us-east-1' },
        },
      },
    },
  },
})
```

## 保濕 {/* #hydration */}

`StorageWorkspaceRef`被懶惰地解決了`mastra.editor.agent.getById()`, not on `list()`. The editor looks up filesystem and sandbox providers on `MastraEditor.filesystems` / `MastraEditor.sandboxes` and materializes a runtime `Workspace`。缺少的提供者會以警告的形式出現，並且Workspace會被省略。為了`{ type: 'provider' }`參考文獻，編輯稱`createWorkspace(config)`在註冊的提供者上`MastraEditor.workspaces`。未註冊的提供者會拋出錯誤。
