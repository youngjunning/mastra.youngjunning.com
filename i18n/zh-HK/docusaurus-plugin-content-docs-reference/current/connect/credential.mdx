# credential()

取得平台連線的原始憑證，用於執行產生的工具集未涵蓋的自訂操作，例如自行呼叫 Provider SDK 或 MCP 伺服器。

```typescript
import { credential } from '@mastra/connect'

const cred = await credential('c_yourconnectionid')

if (cred.type === 'oauth2') {
  startSdkSession(cred.accessToken)
} else if (cred.type === 'api_key') {
  startSdkSession(cred.apiKey)
} else if (cred.type === 'two_step') {
  startSdkSession(cred.token)
}
```

傳回 `Promise<ConnectionCredential>`，其值為可辨識聯合類型：

```typescript
type ConnectionCredential =
  | {
      type: 'oauth2'
      accessToken: string
      expiresAt: string | null
      secondaryAccessTokens?: Record<string, { accessToken: string; expiresAt: string | null }>
    }
  | { type: 'api_key'; apiKey: string }
  | { type: 'two_step'; token: string; expiresAt: string | null }
```

OAuth2 憑證可能包含供其他 API 受眾使用的 `secondaryAccessTokens`，並以 Provider 連線設定中的欄位名稱作為鍵。每個權杖都有獨立的到期時間。

大部分應用程式應優先使用 [`tools()`](/reference/connect/tools)，讓憑證一直留在平台上。

## 憑證處理 {/* #credential-handling */}

傳回的憑證可直接存取 Provider 帳戶，並繞過代理的防護機制。請勿記錄憑證，亦不要將其放入 Agent 輸出。OAuth2 及 `two_step` 權杖可能到期；請檢查各自的 `expiresAt`，包括次要存取權杖的到期時間，並在需要時重新取得憑證。

如果連線使用此函式不支援的憑證類型（例如基本驗證），便會拋出 `unsupported_credential_type`。

## 錯誤 {/* #errors */}

拋出 `MastraConnectError`，並帶有 `code` 屬性：

| 代碼 | 觸發條件 |
| - | - |
| `invalid_options` | 選項無效，例如 `resourceId` 為空，或移除前後空白後超過 256 個字元 |
| `missing_access_token` | 未設定平台權杖 |
| `connection_not_found` | 連線不存在或無法存取 |
| `unsupported_credential_type` | 無法傳回該連線的憑證類型 |
| `unauthorized` | 平台拒絕權杖（401/403） |
| `platform_error` | 其他平台回應失敗：狀態碼非 2xx，或回應內容無法解析。網絡層的 fetch 失敗不會被包裝，而會以執行環境本身的錯誤呈現，且不帶 `code` |
