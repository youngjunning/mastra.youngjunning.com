# createCodeMode()

**新增於：** `@mastra/core@1.38.0`

`createCodeMode()` 會傳回一個 Tool 及產生的指令，讓 Agent 以單一 TypeScript 函式執行涉及多個 Tool 的運算。產生的程式碼在 Workspace 的 Sandbox 中執行；每次呼叫 `external_*`，都會在主機上執行對應的實際 Tool，並進行驗證、傳遞請求內容及記錄追蹤資訊。

概念介紹請參閱 [Code mode](/docs/agents/code-mode)。

## 使用範例 {/* #usage-example */}

建立程式碼模式 Tool，將產生的指令加入 Agent，並以相同的 id 註冊傳回的 Tool。

```typescript title="src/mastra/agents/shop-agent.ts"
import { Agent } from '@mastra/core/agent'
import { createCodeMode, createTool } from '@mastra/core/tools'
import { LocalSandbox } from '@mastra/core/workspace'
import { z } from 'zod'

const getTopProducts = createTool({
  id: 'getTopProducts',
  description: 'Get top selling products',
  inputSchema: z.object({ limit: z.number() }),
  outputSchema: z.object({
    products: z.array(z.object({ id: z.string(), name: z.string(), totalSales: z.number() })),
  }),
  execute: async ({ limit }) => fetchTopProducts(limit),
})

const getProductRatings = createTool({
  id: 'getProductRatings',
  description: 'Get ratings for a product',
  inputSchema: z.object({ productId: z.string() }),
  outputSchema: z.object({ ratings: z.array(z.object({ score: z.number() })) }),
  execute: async ({ productId }) => fetchRatings(productId),
})

const { tool, instructions } = createCodeMode({
  tools: { getTopProducts, getProductRatings },
  sandbox: new LocalSandbox(),
})

export const shopAgent = new Agent({
  id: 'shop-assistant',
  name: 'shop-assistant',
  instructions: ['You are a helpful shopping assistant.', instructions],
  model: '__GATEWAY_OPENAI_MODEL__',
  tools: { execute_typescript: tool },
})
```

## 查看產生的指令 {/* #inspecting-instructions */}

使用 `createCodeModeInstructions()` 查看為一組 Tool 產生的完整提示內容。

```typescript title="src/mastra/tools/code-mode-instructions.ts"
import { createCodeModeInstructions } from '@mastra/core/tools'

console.log(
  createCodeModeInstructions({
    tools: { getTopProducts, getProductRatings },
  }),
)
```

指令包含使用規範，並為每個已設定的 Tool 提供一行具型別的 `declare function external_<id>(...)` 宣告。Tool id 會轉換成有效的 TypeScript 函式名稱；如轉換後名稱衝突，就會拋出錯誤。

## createCodeModeTool() {/* #createcodemodetool */}

如果只需要 Tool，並希望另外管理指令，可以使用 `createCodeModeTool()`。大多數 Agent 應使用 `createCodeMode()`，以便同時取得 Tool 及其對應指令。

```typescript title="src/mastra/tools/code-mode-tool.ts"
import { createCodeModeTool } from '@mastra/core/tools'
import { LocalSandbox } from '@mastra/core/workspace'

export const codeModeTool = createCodeModeTool({
  tools: { getTopProducts, getProductRatings },
  sandbox: new LocalSandbox(),
})
```
