# QuickJsCodeModeTransport

`QuickJsCodeModeTransport` 類別在編譯為 WebAssembly 的進程內 [QuickJS](https://bellard.org/quickjs/) 執行環境中執行 [Code mode](/docs/agents/code-mode) 程式。執行環境構成執行邊界，因此毋須 Workspace Sandbox：程式無法存取檔案系統、網絡、進程或模組。程式只能透過 `external_*` 函式呼叫主機上的實際 Tool。

與 [`IsolatedVmCodeModeTransport`](/reference/tools/isolated-vm-transport) 不同，這種傳輸方式毋須安裝原生二進位檔，亦毋須設定 Node.js 啟動參數，因此可在禁止這兩項操作的無伺服器平台上運行。代價是執行速度較慢，詳見[選擇傳輸方式](#choosing-a-transport)。

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/quickjs
```

套件包含 WebAssembly 模組，因此安裝時只會複製檔案，不會執行其他操作。

## 用法 {/* #usage */}

將傳輸實例作為第二個參數傳給 `createCodeMode()`，毋須提供 `sandbox`：

```typescript
import { createCodeMode } from '@mastra/core/tools'
import { QuickJsCodeModeTransport } from '@mastra/quickjs'

const { tool, instructions } = createCodeMode(
  { tools: { getTopProducts, getProductRatings } },
  new QuickJsCodeModeTransport({ memoryLimitMb: 128 }),
)
```

## 選擇傳輸方式 {/* #choosing-a-transport */}

三種傳輸方式都由主機執行相同的允許清單檢查、Tool 驗證和追蹤。分別在於程式本身能存取甚麼，以及主機需要提供甚麼。

| | `StdioCodeModeTransport` | `IsolatedVmCodeModeTransport` | `QuickJsCodeModeTransport` |
| - | - | - | - |
| 隔離邊界 | Workspace Sandbox | V8 隔離環境 | QuickJS WebAssembly 執行環境 |
| 需要 Sandbox | 是 | 否 | 否 |
| 原生二進位檔 | Sandbox 內的 Node.js 執行環境 | 需要 | 不需要 |
| Node.js 啟動參數 | 無 | Node.js 20 或以上版本需要 `--no-node-snapshot` | 無 |
| 可在瀏覽器中執行 | 否 | 否 | 是 |
| 執行速度 | 最快 | 快 | 最慢 |

如果主機無法安裝原生附加元件或設定 Node.js 啟動參數（無伺服器平台常有這類限制），請選擇 `QuickJsCodeModeTransport`。如果主機允許這兩項操作，而程式需要大量運算，請選擇 `IsolatedVmCodeModeTransport`。

速度差異在於程式本身，而非 Tool 呼叫。QuickJS 以直譯方式執行程式碼，不進行 JIT 編譯，因此運算密集的循環可能比在 V8 隔離環境中慢數十倍。主要等待 `external_*` 呼叫的程式則表現相若，因為大部分時間都花在 Tool 上。Code mode 程式通常屬於後者。

## 運作方式 {/* #how-it-works */}

每次執行都會建立全新的 QuickJS 執行環境，並配置獨立的堆記憶體。主機先使用 [ts-blank-space](https://github.com/bloomberg/ts-blank-space) 移除 TypeScript 類型註解，毋須原生編譯器，再於執行環境內執行程式。每次 `external_*` 呼叫都以 JSON 字串的形式雙向跨越執行邊界，因此主機物件的參照不會洩漏到模型編寫的程式碼中。

`external_*` 呼叫會向程式傳回尚未完成的 Promise，並立即將控制權交還主機。因此，多個呼叫可以同時進行，`Promise.all` 亦會如預期運作。

在 `createCodeMode()` 設定的 `timeout` 同時適用於非同步停滯和同步無限循環。每次執行結束後，執行環境都會釋放。
