# createBedrockKBTool()

`createBedrockKBTool()` 函式建立一個 Tool，用來從 Amazon Bedrock 知識庫擷取相關文件。它支援託管搜尋設定及代理式檢索（查詢分解和託管重新排序）；代理式檢索失敗時會自動轉用標準檢索。

## 使用範例 {/* #usage-example */}

```typescript
import { createBedrockKBTool } from '@mastra/rag'

const kbTool = createBedrockKBTool({
  knowledgeBaseId: 'YOUR_KB_ID',
  region: 'us-west-2',
  numberOfResults: 5,
  useAgenticRetrieval: true,
})
```

### 配合 Agent 使用 {/* #with-an-agent */}

```typescript
import { Agent } from '@mastra/core/agent'
import { createBedrockKBTool } from '@mastra/rag'

const kbTool = createBedrockKBTool({
  knowledgeBaseId: 'YOUR_KB_ID',
})

const agent = new Agent({
  name: 'KnowledgeAssistant',
  instructions: 'Use the knowledge base tool to answer questions.',
  model: myModel,
  tools: { kb: kbTool },
})
```

### BedrockKBResult {/* #bedrockkbresult */}

| 欄位 | 類型 | 說明 |
| - | - | - |
| `content` | `string` | 擷取所得文字片段的內容。 |
| `source` | `string \| undefined` | Bedrock 提供的來源 URI。代理式檢索只會在結果元資料包含 `_source_uri` 時提供此欄位。 |

| `metadata` | `Record<string, unknown>` | 檢索結果中的其他元資料。 |

## 檢索方式 {/* #retrieval-modes */}

### 代理式檢索（預設） {/* #agentic-retrieval-default */}

當 `useAgenticRetrieval` 為 `true`（預設值）時，此 Tool 使用 `AgenticRetrieveStreamCommand`：

- 將複雜查詢分解為子查詢
- 分多輪進行檢索
- 使用託管重新排序改善結果

如代理式檢索失敗（例如 SDK 版本過舊或權限不足），便會自動轉用標準託管檢索。

### 標準託管檢索 {/* #standard-managed-retrieval */}

當 `useAgenticRetrieval` 為 `false` 時，此 Tool 使用配合 `managedSearchConfiguration` 的 `RetrieveCommand`，直接進行單輪檢索。

## 按用戶設定的存取控制 {/* #user-based-access-control */}

在 Mastra 請求上下文中設定 `userId`，即可將其作為 Bedrock 的 `userContext.userId` 傳遞。這適用於實施文件層級存取控制的知識庫。請求上下文中的值會覆蓋此 Tool 設定的預設 `userId`。

```typescript
import { RequestContext } from '@mastra/core/request-context'

const requestContext = new RequestContext()
requestContext.set('userId', 'user-123')

await agent.generate('Find my private documents', { requestContext })
```

## 所需的 IAM 權限 {/* #required-iam-permissions */}

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": ["bedrock:Retrieve", "bedrock:AgenticRetrieveStream"],
      "Resource": "arn:aws:bedrock:*:*:knowledge-base/*"
    }
  ]
}
```

## SDK 要求 {/* #sdk-requirements */}

- `@aws-sdk/client-bedrock-agent-runtime` >= 3.1000（AgenticRetrieveStreamCommand 需要 \~3.1000+）
