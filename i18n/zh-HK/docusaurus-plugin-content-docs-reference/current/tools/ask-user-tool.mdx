# askUserTool

askUserTool 是不依賴特定 Agent 的內置 Tool，可向用戶提問並等待回覆。它支援自由輸入文字、單選及多選。

此 Tool 透過原生的 [Tool 暫停機制](/docs/agents/human-in-the-loop#runtime-suspension-with-suspend)暫停執行：它調用 `suspend()` 並傳入問題資料，讓 Agent 發出 `tool-call-suspended` 事件並儲存執行狀態。使用 `agent.resumeStream(answer, { runId })` 恢復執行。

如果在 Agent 執行程序以外使用（此時無法使用 `suspend`），此 Tool 會傳回易於閱讀的備用文字，當中包含問題及選項。

## 使用範例 {/* #usage-example */}

將 `askUserTool` 加入 Agent 的工具集合：

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { askUserTool } from '@mastra/core/tools'

const agent = new Agent({
  id: 'assistant',
  name: 'Assistant',
  instructions: 'Ask the user for clarification when the request is ambiguous.',
  model,
  tools: { askUserTool },
})
```

處理暫停和恢復：

```typescript title="src/run.ts"
const stream = await agent.stream('Summarize my project')

for await (const chunk of stream.fullStream) {
  if (chunk.type === 'tool-call-suspended') {
    const { question, options, selectionMode } = chunk.payload.suspendPayload
    // Present the question to the user, collect their answer, then resume:
    const resumed = await agent.resumeStream('The main repo', { runId: stream.runId })
    for await (const c of resumed.textStream) process.stdout.write(c)
  }
}
```

多選時，使用字串陣列恢復執行：

```typescript
await agent.resumeStream(['Add tests', 'Update docs'], { runId: stream.runId })
```

## 恢復資料 {/* #resume-data */}

將用戶的回答傳給 `agent.resumeStream()`：

- **自由輸入文字及單選：**一個 `string`。
- **多選：**一個 `string[]`，包含已選選項的標籤及任何自訂回答。

Factory 和 Studio 會在建議選項旁提供 **Other…**。選取後，該選項會變成文字欄位，可輸入自訂回答；然後選取 **Submit answer** 或按 Enter 提交。單選時，恢復執行所用的字串是去除前後空白的自訂文字。多選時，會先傳入已選選項的標籤，再傳入去除前後空白的自訂文字。即使沒有選取建議選項，也可以提交自訂文字。

如果選取 **Other…**，文字欄位中的回答不可留空。欄位為空或只含空白字元時，**Other…** 會取消選取。取消選取 **Other…** 後，自訂文字不會包含在回覆中。恢復資料一律不包含 **Other…** 標籤本身。
