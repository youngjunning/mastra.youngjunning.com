# `.listSkills()`

回傳 Agent 可用的所有 Skill 中繼資料，涵蓋 Agent 層級和 Workspace 的 Skill。

## 使用示例 {/* #usage-example */}

```typescript title="src/routes/skills.ts"
import { agent } from '../mastra/agents'

const skills = await agent.listSkills()

for (const skill of skills) {
  console.log(`${skill.name}: ${skill.description}`)
}
```

## 回傳值 {/* #return-value */}

回傳 `Promise<SkillMetadata[]>`。

每個項目載有一個已找到的 Skill 的中繼資料。

```typescript
interface SkillMetadata {
  name: string
  description: string
  path: string
  license?: string
  compatibility?: unknown
  'user-invocable'?: boolean
  metadata?: Record<string, unknown>
}
```

## 合併規則 {/* #merging-behavior */}

如果同時設定 Agent 層級及 Workspace 的 Skill，`.listSkills()` 會回傳合併後的結果。若名稱相同，Agent 層級的 Skill 優先。例如兩邊都定義名為 `code-review` 的 Skill 時，只會回傳 Agent 層級的版本。
