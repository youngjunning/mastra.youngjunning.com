# Agent.listAgents()

`.listAgents()` 取得 Agent 所設定的子 Agent。若設定是函數，此方法會呼叫該函數。Agent 可藉此調用其他 Agent，完成複雜操作。

## 使用示例 {/* #usage-example */}

```typescript
await agent.listAgents()
```
