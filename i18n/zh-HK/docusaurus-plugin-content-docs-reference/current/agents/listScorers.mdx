# Agent.listScorers()

這`.listScorers()`方法檢索為Agent配置的評分配置，如果它是函數，則解析它。該方法提供對用於評估Agent回應和表現的評分系統的存取。

## 使用範例 {/* #usage-example */}

```typescript
await agent.listScorers()
```
