# Agent.listScorers()

`.listScorers()` 取得 Agent 的評分設定。若設定由函數提供，此方法會呼叫該函數。透過此方法，即可存取評估 Agent 回覆及表現所用的評分系統。

## 使用示例 {/* #usage-example */}

```typescript
await agent.listScorers()
```
