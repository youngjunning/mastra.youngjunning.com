# Agent.getMemory()

這`.getMemory()`方法檢索與Agent程式關聯的儲存系統。此方法用於存取Agent的記憶體功能，以便在對話中儲存和檢索資訊。

## 使用範例 {/* #usage-example */}

```typescript
await agent.getMemory()
```
