# Agent.getVoice()

`.getVoice()` 取得 Agent 所設定的語音 Provider。若設定由函數提供，便會呼叫該函數。這個 Provider 提供文字轉語音及語音轉文字功能。

## 使用示例 {/* #usage-example */}

```typescript
await agent.getVoice()
```
