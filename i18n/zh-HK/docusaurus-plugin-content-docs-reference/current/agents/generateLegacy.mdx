# Agent.generateLegacy()（舊版）

:::warning

**已棄用**：此方法已棄用，只適用於舊版模型適配器。使用現時的模型適配器時，請改用 [`.generate()`](./generate)。

:::

`.generateLegacy()` 是 Agent 生成 API 的舊版方法，配合舊版模型適配器產生文字或結構化回應。它接收訊息及可選的生成選項。

## 使用範例 {/* #usage-example */}

```typescript
await agent.generateLegacy('message for agent')
```

## 處理器重試支援 {/* #processor-retry-support */}

`generateLegacy()` 不會執行錯誤處理器，亦不使用 `maxProcessorRetries`；它改用舊版 AI SDK 的生成路徑。

使用舊版模型適配器的評分器評審模型會調用 `generateLegacy()`。它們不能共用使用 Mastra 現時生成 API 的評分器評審模型所獲的 `StreamErrorRetryProcessor` 重試額度。需要錯誤處理器重試時，請使用現時的模型適配器。舊版 `maxRetries` 選項獨立運作，預設值為 `2`。

## 遷移至新 API {/* #migration-to-new-api */}

:::note

新的 `.generate()` 方法提供更完整的功能，包括兼容 AI SDK v5 及更新版本、更完善的結構化輸出處理，以及改進的串流支援。詳細遷移步驟請參閱[遷移指南](/reference/migrations/vnext-to-standard-apis)。

:::

### 快速遷移範例 {/* #quick-migration-example */}

#### 遷移前（舊版） {/* #before-legacy */}

```typescript
const result = await agent.generateLegacy('message', {
  temperature: 0.7,
  maxSteps: 3,
})
```

#### 遷移後（新 API） {/* #after-new-api */}

```typescript
const result = await agent.generate('message', {
  modelSettings: {
    temperature: 0.7,
  },
  maxSteps: 3,
})
```

## 延伸使用範例 {/* #extended-usage-example */}

```typescript
import { z } from 'zod'
import { ModerationProcessor, TokenLimiterProcessor } from '@mastra/core/processors'

await agent.generateLegacy(
  [
    { role: 'user', content: 'message for agent' },
    {
      role: 'user',
      content: [
        {
          type: 'text',
          text: 'message for agent',
        },
        {
          type: 'image',
          imageUrl: 'https://example.com/image.jpg',
          mimeType: 'image/jpeg',
        },
      ],
    },
  ],
  {
    temperature: 0.7,
    maxSteps: 3,
    memory: {
      thread: 'user-123',
      resource: 'test-app',
    },
    toolChoice: 'auto',
    providerOptions: {
      openai: {
        reasoningEffort: 'high',
      },
    },
    // Structured output alongside tool calls
    experimental_output: z.object({
      sentiment: z.enum(['positive', 'negative', 'neutral']),
      confidence: z.number(),
    }),
    // Output processors for response validation
    outputProcessors: [
      new ModerationProcessor({ model: '__GATEWAY_OPENAI_MODEL_LUNA__' }),
      new TokenLimiterProcessor({ maxTokens: 1000 }),
    ],
  },
)
```
