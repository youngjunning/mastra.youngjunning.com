# Agent.generate()

`.generate()` 方法讓 Agent 以非串流方式產生回應，並支援更多產生選項。它接收訊息及可選的產生選項。
向 Agent 傳送訊息以產生回應：
## 使用範例 {/* #usage-example */}



```ts
const result = await agent.generate('message for agent')
```

## 響應結構 {/* #response-structure */}

`Agent.generate()` 回傳執行期間收集的最終資料。`steps` 是步驟物件陣列。結果中的 Tool 陣列（包括頂層的 `toolCalls` 及 `toolResults`，以及每個步驟中的 `step.toolCalls` 及 `step.toolResults` 陣列）採用 Mastra 的資料區塊格式。

換言之，Tool 資料封裝在 `payload` 中：

```ts
const response = await agent.generate('Check the weather in Lagos')

for (const toolCall of response.toolCalls) {
  console.log(toolCall.type) // 'tool-call'
  console.log(toolCall.runId)
  console.log(toolCall.from)
  console.log(toolCall.payload.toolName)
  console.log(toolCall.payload.args)
}

for (const step of response.steps) {
  for (const toolResult of step.toolResults) {
    console.log(toolResult.type) // 'tool-result'
    console.log(toolResult.payload.toolName)
    console.log(toolResult.payload.result)
  }
}
```

相同資料區塊結構的串流版本，請參閱[資料區塊類型參考](/reference/streaming/ChunkType)。

## 更多範例 {/* #more-examples */}

### 恢復執行期間暫停的產生作業 {/* #resuming-a-runtime-suspended-generation */}

`generate()` 會在兩種情況下回傳 `finishReason: 'suspended'`：Tool 需要批核（請參閱 [`requireToolApproval`](#parameters)），或 Tool 的 `execute` 函數呼叫了 `suspend()`。

此例展示會呼叫 `suspend()` 的 Tool。該 Tool 使用 `suspendSchema` 宣告傳給 `suspend()` 的資料結構，並使用 `resumeSchema` 宣告繼續執行所需的資料結構：

```typescript title="src/mastra/tools/weather-tool.ts"
import { createTool } from '@mastra/core/tools'
import { z } from 'zod'

const weatherTool = createTool({
  id: 'get-weather',
  inputSchema: z.object({ location: z.string().optional() }),
  suspendSchema: z.object({ question: z.string() }),
  resumeSchema: z.object({ location: z.string() }),
  execute: async ({ location }, context) => {
    if (!location) {
      return await context?.agent?.suspend({
        question: 'Which city would you like the weather for?',
      })
    }
    return await fetchWeather(location)
  },
})
```

在暫停結果中，`suspendPayload.suspendPayload` 包含 Tool 傳給 `suspend()` 的資料。呼叫 `resumeGenerate()` 恢復執行時，須傳入符合該 Tool 之 `resumeSchema` 的資料，以及暫停的 `runId`：

```typescript
const output = await agent.generate("What's the weather in London?")

if (output.finishReason === 'suspended') {
  console.log(output.suspendPayload.toolCallId)
  console.log(output.suspendPayload.suspendPayload) // { question: 'Which city would you like the weather for?' }

  const resumed = await agent.resumeGenerate(
    { location: 'London' },
    {
      runId: output.runId!,
      // Pass per-call options again, for example requestContext or onStepFinish.
    },
  )

  console.log(resumed.text)
}
```

如恢復資料不符合 Tool 的 `resumeSchema`，`resumeGenerate()` 會拋出 ID 為 `AGENT_RESUME_INVALID_DATA` 的錯誤，執行工作仍然暫停，可修正資料後重試。如有多個 Tool 呼叫暫停，請傳入 `toolCallId` 指定要恢復的呼叫。

Tool 批核請改用 `approveToolCallGenerate()` 及 `declineToolCallGenerate()`，如[人工介入](/docs/agents/human-in-the-loop#tool-approval-with-generate)一節所示。如要恢復串流，請使用 `resumeStream()` 並傳入相同資料。

### 使用 memory {/* #with-memory */}

設定 memory 選項，讓 Agent 可存取並持久儲存對話歷史記錄，以便記住先前的互動，並在多則訊息之間保留上下文。

```ts
const memoryResult = await agent.generate('Remember my favorite color is blue', {
  memory: {
    thread: 'user-123-thread',
    resource: 'user-123',
  },
})
```

### 存取回應標頭 {/* #accessing-response-headers */}

部分模型 Provider 會在回應標頭中提供實用資料，例如剩餘 token 數量或速率限制狀態。產生完成後，可從結果物件讀取這些標頭。

```ts
const result = await agent.generate('Hello!')
const remainingRequests = result.response?.headers?.['anthropic-ratelimit-requests-remaining']
const remainingTokens = result.response?.headers?.['x-ratelimit-remaining-tokens']
console.log(`Remaining requests: ${remainingRequests}, Remaining tokens: ${remainingTokens}`)
```

### 分析圖像 {/* #analyzing-images */}

Agent 可以同時處理圖像的視覺內容及其中的文字，對圖像進行分析及描述。如要啟用圖像分析，請在 `content` 陣列中傳入 `type: 'image'` 及圖像 URL。可結合圖像內容與文字提示詞，引導 Agent 分析。

```typescript
const response = await agent.generate([
  {
    role: 'user',
    content: [
      {
        type: 'image',
        image: 'https://placebear.com/cache/395-205.jpg',
        mimeType: 'image/jpeg',
      },
      {
        type: 'text',
        text: 'Describe the image in detail, and extract all the text in the image.',
      },
    ],
  },
])

console.log(response.text)
```

`image` 的值，或 `type: 'file'` 部分的 `data`，應為絕對 URL、data URL 或 base64 內容。模型無法讀取以 `/api/images/foo.png` 等相對路徑提供的附件，因此傳送前須將其解析為絕對 URL。遇到這類附件時，Agent 會以佔位符取代並記錄警告，而不會直接失敗。無法解碼、與媒體類型所宣告的圖像或 PDF 不符的行內內容，以及無法下載的附件，亦會以相同方式處理。請參閱[附件下載失敗](/docs/agents/processors#recover-from-attachment-download-failures)。

### 使用 `maxSteps` {/* #using-maxsteps */}

`maxSteps` 參數限制 Agent 連續呼叫 LLM 的最多次數。每個步驟都會產生回應、執行所有 Tool 呼叫，再處理結果。限制步驟數有助於避免無限循環並降低延遲，也能控制使用 Tool 的 Agent 所消耗的 token。預設值為 5，可以調高：

```typescript
const response = await agent.generate('Help me organize my day', {
  maxSteps: 10,
})

console.log(response.text)
```

### 使用 `onStepFinish` {/* #using-onstepfinish */}

可使用 `onStepFinish` 回調監察多步驟操作的進度，有助於偵錯或向用戶提供進度更新。

只有串流輸出或產生非結構化文字時，才能使用 `onStepFinish`。

```typescript
const response = await agent.generate('Help me organize my day', {
  onStepFinish: ({ text, toolCalls, toolResults, finishReason, usage }) => {
    console.log({ text, toolCalls, toolResults, finishReason, usage })
  },
})
```

### 使用 `onTitleGenerated` {/* #using-ontitlegenerated */}

在 memory 選項中啟用 `generateTitle` 後，標題產生會在回應完成後非同步執行。可使用 `onTitleGenerated` 在標題準備好時執行操作，例如透過 SSE 將標題推送給用戶端。

```typescript
const response = await agent.generate('What is quantum computing?', {
  memory: {
    thread: threadId,
    resource: userId,
    onTitleGenerated: title => {
      console.log('Thread title:', title)
    },
  },
})
```
