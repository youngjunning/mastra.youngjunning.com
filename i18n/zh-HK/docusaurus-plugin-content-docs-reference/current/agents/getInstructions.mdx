# Agent.getInstructions()

`.getInstructions()` 取得 Agent 所設定的指令。若設定由函數提供，此方法會呼叫該函數。指令會引導 Agent 的行為，並界定其能力和限制。

## 使用示例 {/* #usage-example */}

```typescript
await agent.getInstructions()
```
