# Agent.getInstructions()

這`.getInstructions()`方法檢索為Agent配置的指令，如果它們是函數則解析它們。這些指令指導Agent的行為並定義其功能和約束。

## 使用範例 {/* #usage-example */}

```typescript
await agent.getInstructions()
```
