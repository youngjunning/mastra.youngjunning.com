# Agent.listWorkflows()

`.listWorkflows()` 取得 Agent 所設定的 Workflow。如設定由函數提供，此方法會呼叫該函數。這些 Workflow 讓 Agent 可按指定的執行路徑完成複雜的多步驟流程。

## 使用示例 {/* #usage-example */}

```typescript
await agent.listWorkflows()
```
