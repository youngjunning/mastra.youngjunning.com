# Agent.getModel()

`.getModel()` 方法取得為 Agent 配置的語言模型；如模型由函式提供，則會先解析該函式。此方法用來存取支援 Agent 能力的底層模型。

## 使用範例 {/* #usage-example */}

```typescript
await agent.getModel()
```
