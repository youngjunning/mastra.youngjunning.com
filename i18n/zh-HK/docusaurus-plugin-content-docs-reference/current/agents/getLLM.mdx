# Agent.getLLM()

這`.getLLM()`方法檢索為Agent程式配置的語言模型實例，如果它是函數則解析它。您也可以傳遞請求範圍的`model`覆蓋而不改變Agent的配置模型。

## 使用範例 {/* #usage-example */}

```typescript
await agent.getLLM()
```

```typescript
await agent.getLLM({
  model: '__GATEWAY_OPENAI_MODEL__',
})
```
