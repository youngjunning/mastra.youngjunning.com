# Agent.getLLM()

`.getLLM()` 方法取得為 Agent 配置的語言模型實例；如模型由函式提供，則會先解析該函式。亦可傳入請求層級的 `model` 覆寫配置，而不會修改 Agent 已配置的模型。

## 使用範例 {/* #usage-example */}

```typescript
await agent.getLLM()
```

```typescript
await agent.getLLM({
  model: '__GATEWAY_OPENAI_MODEL__',
})
```
