# Agent.listTools()

`.listTools()` 取得 Agent 所設定的 Tool。若設定由函數提供，此方法會呼叫該函數。Agent 可藉助這些 Tool 執行特定操作或存取外部系統。

## 使用示例 {/* #usage-example */}

```typescript
await agent.listTools()
```
