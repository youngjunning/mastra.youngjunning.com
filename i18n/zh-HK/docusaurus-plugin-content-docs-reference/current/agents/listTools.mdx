# Agent.listTools()

這`.listTools()`方法檢索為Agent配置的Tool，如果它們是函數，則解析它們。這些Tool擴展了Agent的功能，使其能夠執行特定操作或存取外部系統。

## 使用範例 {/* #usage-example */}

```typescript
await agent.listTools()
```
