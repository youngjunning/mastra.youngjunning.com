# `.getSkill()`

依名稱從客服人員配置的技能（客服人員等級技能和Workspace技能）檢索特定技能。

## 使用範例 {/* #usage-example */}

```typescript title="src/routes/skills.ts"
import { agent } from '../mastra/agents'

const skill = await agent.getSkill('code-review')

if (skill) {
  console.log(skill.name) // "code-review"
  console.log(skill.description) // "Use when reviewing code changes."
  console.log(skill.instructions) // Full markdown instructions
}
```

## 傳回值 {/* #return-value */}

退貨`Promise<Skill | null>`.

返回`Skill` object if found, or `null` if no skill with that name exists.

```typescript
interface Skill {
  name: string
  description: string
  instructions: string
  path: string
  source:
    | { type: 'external'; packagePath: string }
    | { type: 'local'; projectPath: string }
    | { type: 'managed'; mastraPath: string }
  references: string[]
  scripts: string[]
  assets: string[]
  license?: string
  compatibility?: unknown
  'user-invocable'?: boolean
  metadata?: Record<string, unknown>
}
```

`source`描述了馬斯特拉發現這項技能的地點。來自一條路徑的技能`node_modules` segment are `external`, skills from a path under `.mastra/skills`是`managed`，以及所有其他技能，包括那些用[`createSkill()`](/reference/agents/createSkill)， 是`local`.

## 合併行為 {/* #merging-behavior */}

當座席級技能和Workspace技能都配置時，`.getSkill()` searches the merged set. Agent-level skills take precedence on name conflicts.
