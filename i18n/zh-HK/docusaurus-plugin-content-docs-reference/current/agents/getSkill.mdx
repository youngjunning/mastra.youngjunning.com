# `.getSkill()`

按名稱從 Agent 已設定的 Skill 中擷取指定 Skill，包括 Agent 層級及 Workspace Skill。

## 使用範例 {/* #usage-example */}

```typescript title="src/routes/skills.ts"
import { agent } from '../mastra/agents'

const skill = await agent.getSkill('code-review')

if (skill) {
  console.log(skill.name) // "code-review"
  console.log(skill.description) // "Use when reviewing code changes."
  console.log(skill.instructions) // Full markdown instructions
}
```

## 傳回值 {/* #return-value */}

傳回 `Promise<Skill | null>`。

如果找到對應 Skill，則傳回 `Skill` 物件；如果不存在該名稱的 Skill，則傳回 `null`。

```typescript
interface Skill {
  name: string
  description: string
  instructions: string
  path: string
  source:
    | { type: 'external'; packagePath: string }
    | { type: 'local'; projectPath: string }
    | { type: 'managed'; mastraPath: string }
  references: string[]
  scripts: string[]
  assets: string[]
  license?: string
  compatibility?: unknown
  'user-invocable'?: boolean
  metadata?: Record<string, unknown>
}
```

`source` 說明 Mastra 從何處找到該 Skill。路徑中包含 `node_modules` 的 Skill 屬於 `external`，位於 `.mastra/skills` 下的 Skill 屬於 `managed`，其餘 Skill（包括使用 [`createSkill()`](/reference/agents/createSkill) 建立的 Skill）均屬於 `local`。

## 合併行為 {/* #merging-behavior */}

同時設定 Agent 層級 Skill 及 Workspace Skill 時，`.getSkill()` 會在合併後的集合中搜尋。如名稱衝突，以 Agent 層級 Skill 為優先。
