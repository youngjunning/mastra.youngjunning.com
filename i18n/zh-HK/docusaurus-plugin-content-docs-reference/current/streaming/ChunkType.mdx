# ChunkType

`ChunkType` 類型定義 Agent 串流回應期間可能輸出的數據區塊所使用的 Mastra 格式。

## 基本屬性 {/* #base-properties */}

除自訂 data-* 數據區塊外，所有數據區塊均包含以下基本屬性：

## 線程訂閱數據區塊 {/* #thread-subscription-chunks */}

### data-user-message-pending {/* #data-user-message-pending */}

線程接受中途引導或排隊中的後續輸入後、Agent 消費前，會輸出暫時的用戶訊息投影。訂閱者可立即顯示輸入，再與實際送達的 `data-user-message` 數據區塊按 `data.id` 核對。

此數據區塊不會儲存至對話記錄。加入當前執行的中途引導，其 `data.metadata.status` 為 `pending`；之後才執行的後續輸入則為 `queued`。

```typescript
type UserMessagePendingChunk = {
  type: 'data-user-message-pending'
  runId: string
  traceId?: string
  from: ChunkFrom
  metadata?: Record<string, any>
  transient: true
  data: AgentSignalDataPart['data'] & {
    metadata: Record<string, unknown> & {
      status: 'pending' | 'queued'
    }
  }
}
```

### data-user-message-cancelled {/* #data-user-message-cancelled */}

已接受的用戶輸入在送達前取消時，會輸出暫時的移除事件。訂閱者可按 `data.id` 移除對應的待處理訊息投影。

只有輸入已移除後才會輸出此數據區塊，因此它確認的是移除結果，而非取消請求。此區塊是暫時性的，不會儲存至對話記錄。

```typescript
type UserMessageCancelledChunk = {
  type: 'data-user-message-cancelled'
  runId: string
  traceId?: string
  from: ChunkFrom
  metadata?: Record<string, any>
  transient: true
  data: {
    id: string
  }
}
```

### thread-run-status {/* #thread-run-status */}

`ThreadRunStatusChunk` 獨立於已儲存訊息的重播，報告執行結果。它由 `@mastra/core/stream` 匯出；只有 `subscribeToThread()` 收到 `withRunStatus: true` 時才會輸出。此選項預設為 `false`。

即時輸出會先於狀態送達。`success`、`failed` 及 `aborted` 是最終結果；`suspended` 可以恢復，因此同一次執行之後仍可能輸出更多內容及最終結果。狀態不會關閉訂閱。

啟用 `withInitialHistory` 時，`thread-history` 會最先送達。選擇接收狀態的較晚訂閱者，會收到每個仍保留的已結束執行各一項結果，包括不在該頁歷史記錄中的執行。最終結果在單次訂閱內會去重；暫停狀態則按執行區段去重。重新連接可能再次收到結果。恢復能力取決於 PubSub 的保留期限，不能視作永久審計記錄。請參閱[線程串流](/docs/signals/thread-streams#detect-when-a-run-finishes)。

## 使用示例 {/* #usage-example */}

```typescript
const stream = await agent.stream('Hello')

for await (const chunk of stream.fullStream) {
  switch (chunk.type) {
    case 'text-delta':
      console.log('Text:', chunk.payload.text)
      break

    case 'tool-call':
      console.log('Calling tool:', chunk.payload.toolName)
      break

    case 'tool-result':
      console.log('Tool result:', chunk.payload.result)
      break

    case 'reasoning-delta':
      console.log('Reasoning:', chunk.payload.text)
      break

    case 'finish':
      console.log('Finished:', chunk.payload.stepResult.reason)
      console.log('Usage:', chunk.payload.output.usage)
      break

    case 'error':
      console.error('Error:', chunk.payload.error)
      break
  }
}
```
