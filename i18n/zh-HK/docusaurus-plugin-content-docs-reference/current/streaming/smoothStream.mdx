# `smoothStream()`

`smoothStream()` 建立實驗性轉換串流，先緩衝文字及推理增量，再以大小較一致的區塊輸出。當模型輸出的增量不平均時，可用它令串流回覆顯示得更平穩。

非文字區塊會原樣通過。遇到 Tool、控制或完成區塊時，會先輸出已緩衝的內容。

## 使用範例 {/* #usage-example */}

將 Agent 的 `fullStream` 導入此轉換串流：

```typescript title="src/stream-agent.ts"
import { smoothStream } from '@mastra/core/stream'

const result = await agent.stream('Explain how rainbows form')

const stream = result.fullStream.pipeThrough(
  smoothStream({
    delayInMs: 20,
    chunking: 'word',
  }),
)

for await (const chunk of stream) {
  if (chunk.type === 'text-delta') {
    process.stdout.write(chunk.payload.text)
  }
}
```

此轉換只影響經管道傳入的串流。原始 `MastraModelOutput` 上的 Promise 屬性及回調（例如 `result.text` 和 `onChunk`）仍保留模型原本的區塊輸出時序。

## AI SDK 路由 {/* #ai-sdk-routes */}

匯入 `smoothStream()`，來源為 `@mastra/ai-sdk`，即可在 `handleChatStream()` 將 Agent 輸出轉換為 AI SDK UI 區塊前，令輸出更平順：

```typescript title="app/api/chat/route.ts"
import { handleChatStream, smoothStream } from '@mastra/ai-sdk'
import { createUIMessageStreamResponse } from 'ai'
import { mastra } from '@/src/mastra'

export async function POST(req: Request) {
  const params = await req.json()
  const stream = await handleChatStream({
    mastra,
    agentId: 'weatherAgent',
    params,
    experimentalTransform: smoothStream({
      delayInMs: 20,
      chunking: 'word',
    }),
  })

  return createUIMessageStreamResponse({ stream })
}
```

`@mastra/ai-sdk` 匯出的版本會傳回可重用的轉換串流工廠，因此路由設定會為每次請求建立新的 `TransformStream`。`@mastra/core/stream` 匯出的版本則直接傳回 `TransformStream`，可用於 `pipeThrough()`。

亦可將此可重用工廠傳給 `Agent.stream()`：

```typescript
import { smoothStream } from '@mastra/ai-sdk'

const result = await agent.stream('Explain how rainbows form', {
  experimentalTransform: smoothStream({ delayInMs: 20 }),
})

for await (const chunk of result.fullStream) {
  // Consume the transformed Mastra chunks.
}
```

`chunking` 選項支援：

- `'word'`：輸出完整詞語，包括尾隨空白字元。
- `'line'`：輸出直至每個換行符為止的內容。
- `RegExp`：輸出直至第一個符合項目為止的內容。
- `Intl.Segmenter`：按語言地區規則分詞，適用於詞語之間沒有空格的語言。
- `SmoothStreamChunkDetector`：將目前的緩衝內容傳入函式。函式傳回非空前綴以供輸出，或傳回 `null`、`undefined` 以等待更多內容。

## 自訂分塊 {/* #custom-chunking */}

使用正則表達式定義區塊邊界：

```typescript
const stream = result.fullStream.pipeThrough(
  smoothStream({
    chunking: /[^,]*,\s*/,
  }),
)
```

使用 `Intl.Segmenter` 按語言地區規則分詞：

```typescript
const stream = result.fullStream.pipeThrough(
  smoothStream({
    chunking: new Intl.Segmenter('ja', { granularity: 'word' }),
  }),
)
```

當區塊邊界取決於自訂邏輯時，請使用偵測函式。傳回值必須是緩衝內容的前綴：

```typescript
const stream = result.fullStream.pipeThrough(
  smoothStream({
    chunking: buffer => {
      const boundary = buffer.indexOf('. ')
      return boundary === -1 ? null : buffer.slice(0, boundary + 2)
    },
  }),
)
```

## 傳回值 {/* #returns */}

`TransformStream<ChunkType<OUTPUT>, ChunkType<OUTPUT>>`

轉換串流會輸出經平滑處理的 `text-delta` 及 `reasoning-delta` 區塊，並保留區塊 ID、執行 ID、來源及中繼資料。
