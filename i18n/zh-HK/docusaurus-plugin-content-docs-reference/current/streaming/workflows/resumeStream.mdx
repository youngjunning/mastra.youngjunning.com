# Run.resumeStream()

`.resumeStream()` 方法以新資料恢復已暫停的 Workflow 執行，可從指定步驟繼續執行並觀察事件串流。

## 使用範例 {/* #usage-example */}

```typescript
const run = await workflow.createRun()

const stream = run.stream({
  inputData: {
    value: 'initial data',
  },
})

const result = await stream.result

if (result!.status === 'suspended') {
  const resumedStream = await run.resumeStream({
    resumeData: {
      value: 'resume data',
    },
  })
}
```

## 串流事件 {/* #stream-events */}

串流會在 Workflow 執行期間發出不同類型的事件。每個事件都有 `type` 欄位，以及載有相關資料的 `payload`：

- **`workflow-start`**：Workflow 開始執行
- **`workflow-step-start`**：步驟開始執行
- **`workflow-step-output`**：步驟產生自訂輸出
- **`workflow-step-result`**：步驟完成並傳回結果
- **`workflow-finish`**：Workflow 執行完成，並附有用量統計。執行成功時，`payload.finalWorkflowResult` 載有 Workflow 的最終結果
