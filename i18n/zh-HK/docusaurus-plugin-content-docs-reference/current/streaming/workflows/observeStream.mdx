# Run.observeStream()

`.observeStream()` 為仍在執行的 Workflow 開啟新的 `ReadableStream`。即使原有串流已無法使用，也可以繼續觀察事件。

## 使用示例 {/* #usage-example */}

```typescript
const run = await workflow.createRun()

run.stream({
  inputData: {
    value: 'initial data',
  },
})

const stream = await run.observeStream()

for await (const chunk of stream) {
  console.log(chunk)
}
```

## 回傳值 {/* #returns */}

`ReadableStream<ChunkType>`

## 串流事件 {/* #stream-events */}

Workflow 執行期間，串流會發出以下事件。每個事件都有 `type` 欄位，而 `payload` 則載有相關資料。

* **`workflow-start`**：Workflow 開始執行
* **`workflow-step-start`**：有步驟開始執行
* **`workflow-step-output`**：步驟發出的自訂輸出
* **`workflow-step-result`**：步驟執行完畢並回傳結果
* **`workflow-finish`**：Workflow 執行完畢並提供用量統計。如執行成功，`payload.finalWorkflowResult` 會載有 Workflow 的最終結果
