# 運行.observeStream()

這`.observeStream()`方法開啟一個新的`ReadableStream`到目前正在運行的Workflow運行，允許您在原始流不再可用時觀察事件流。

## 使用範例 {/* #usage-example */}

```typescript
const run = await workflow.createRun()

run.stream({
  inputData: {
    value: 'initial data',
  },
})

const stream = await run.observeStream()

for await (const chunk of stream) {
  console.log(chunk)
}
```

## 退貨 {/* #returns */}

`ReadableStream<ChunkType>`

## 直播事件 {/* #stream-events */}

流程在Workflow執行期間發出事件類型。每個事件都有一個`type` field and a `payload` containing relevant data:

* **`workflow-start`**：Workflow開始執行
* **`workflow-step-start`**: 一個步驟開始執行
* **`workflow-step-output`**：步驟的自訂輸出
* **`workflow-step-result`**：步驟完成並有結果
* **`workflow-finish`**：Workflow執行完成並帶有使用情況統計資料。為了成功運行，`payload.finalWorkflowResult` carries the workflow's final result
