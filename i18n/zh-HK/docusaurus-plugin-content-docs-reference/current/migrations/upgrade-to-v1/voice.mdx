# 語音

語音套件的命名由 speech 改為 voice，類別名稱和 API 方法亦已更新。

## 變更 {/* #changed */}

### 語音配置屬性名稱 {/* #voice-configuration-property-names */}

為統一命名，語音配置屬性已改名：`speakProvider` 改為 `output`，`listenProvider` 改為 `input`，`realtimeProvider` 改為 `realtime`。新名稱對應各屬性在語音輸入和輸出中的用途。

遷移時，請更新支援語音功能的 Agent 所用的配置屬性名稱。

```diff
  const agent = new Agent({
    id: 'agent',
    voice: {
-     speakProvider: murfVoice,
-     listenProvider: deepgramVoice,
-     realtimeProvider: openaiRealtime,
+     output: murfVoice,
+     input: deepgramVoice,
+     realtime: openaiRealtime,
    },
  });
```

:::tip[Codemod]

可使用 Mastra 的 codemod CLI 自動更新程式碼：

```bash
npx @mastra/codemod@latest v1/voice-property-names .
```

:::
