# 嗓音

語音包已從語音重新命名為語音，並更新了類別名稱和 API 方法。

## 改變了 {/* #changed */}

### 語音配置屬性名稱 {/* #voice-configuration-property-names */}

為了保持一致性，語音配置屬性已重新命名。`speakProvider` is now `output`, `listenProvider`現在是`input`， 和`realtimeProvider`現在是`realtime`。新名稱與每個屬性在語音輸入和輸出中的角色相符。

若要遷移，請在配置具有語音功能的Agent程式時更新配置屬性名稱。

```diff
  const agent = new Agent({
    id: 'agent',
    voice: {
-     speakProvider: murfVoice,
-     listenProvider: deepgramVoice,
-     realtimeProvider: openaiRealtime,
+     output: murfVoice,
+     input: deepgramVoice,
+     realtime: openaiRealtime,
    },
  });
```

:::提示\[程式碼修改]

您可以使用 Mastra 的 codemod CLI 自動更新您的程式碼：

```bash
npx @mastra/codemod@latest v1/voice-property-names .
```

:::
