# 追蹤

Observability系統在 v1 中進行了重組，並配備了專用的`@mastra/observability`包裹。本指南涵蓋兩種遷移路徑，具體取決於您要升級的版本。

:::警告\[Observability資料在升級時停止流動]
如果您將 Mastra 軟體包升級到 v1 而不遷移您的`telemetry:` config to `observability:`，舊的配置在運行時被忽略。您的服務將乾淨地啟動，沒有錯誤，但是**任何追蹤、日誌或指標都不會發送到任何地方**。如果您將資料傳送至 Mastra Cloud，儀表板將變為空。

在與您的 Mastra 套件發生衝突的相同變更中完成此遷移，並驗證追蹤是否出現在[Mastra Studio](/docs/studio/observability) before considering the upgrade complete. If you previously hosted on Mastra Cloud, also follow the [Mastra Cloud migration guide](/reference/migrations/mastra-cloud). The new platform requires a new access token and a Studio project before `MastraPlatformExporter` can route data to it.
:::

:::注意\[出口商重新命名]

`MastraPlatformExporter`（發送資料到Mastra平台）取代之前的`CloudExporter`, and `MastraStorageExporter` (persists data to Mastra Storage) replaces the previous `DefaultExporter`. The original classes remain available from `@mastra/observability` and behave identically, but they're deprecated. New code should use `MastraPlatformExporter`和`MastraStorageExporter`。現有進口`CloudExporter`或者`DefaultExporter`繼續工作，直到它們在未來的主要版本中被刪除。

:::

## 遷移路徑 {/* #migration-paths */}

### 來自基於 OTEL 的遙測 (0.x) {/* #from-otel-based-telemetry-0x */}

如果您使用的是舊版`telemetry:` configuration in Mastra, the system has been completely redesigned.

**之前（0.x，帶有 OTEL 遙測）：**

```typescript
import { Mastra } from '@mastra/core'

export const mastra = new Mastra({
  telemetry: {
    serviceName: 'my-app',
    enabled: true,
    sampling: {
      type: 'always_on',
    },
    export: {
      type: 'otlp',
      endpoint: 'http://localhost:4318',
    },
  },
})
```

**之後（具有可觀察性的 v1）：**

```typescript
import { Mastra } from '@mastra/core'
import {
  Observability,
  MastraStorageExporter,
  MastraPlatformExporter,
  SensitiveDataFilter,
} from '@mastra/observability'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      default: {
        serviceName: 'mastra',
        exporters: [
          new MastraStorageExporter(), // Persists observability events to Mastra Storage
          new MastraPlatformExporter(), // Sends observability events to Mastra platform (if MASTRA_PLATFORM_ACCESS_TOKEN is set)
        ],
        spanOutputProcessors: [
          new SensitiveDataFilter(), // Redacts sensitive data like passwords, tokens, keys
        ],
      },
    },
  }),
})
```

此配置包括`MastraStorageExporter`, `MastraPlatformExporter`, and `SensitiveDataFilter` processor. See the [observability tracing documentation](/docs/observability/tracing/overview) for full configuration options.

#### 之後（帶有自訂配置的 v1） {/* #after-v1-with-custom-configuration */}

如果您需要配置特定的導出器（例如 OTLP），請安裝導出器包並配置它：

```bash npm2yarn
npm install @mastra/otel-exporter@latest @opentelemetry/exporter-trace-otlp-proto
```

```typescript
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { OtelExporter } from '@mastra/otel-exporter'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      production: {
        serviceName: 'my-app',
        sampling: { type: 'always' },
        exporters: [
          new OtelExporter({
            provider: {
              custom: {
                endpoint: 'http://localhost:4318/v1/traces',
                protocol: 'http/protobuf',
              },
            },
          }),
        ],
      },
    },
  }),
})
```

主要變化：

1. 安裝`@mastra/observability` package
2. 代替`telemetry:` with `observability: new Observability()`
3. 使用顯式`configs:` with `MastraStorageExporter`, `MastraPlatformExporter`, and `SensitiveDataFilter`
4. 導出類型從字串文字更改為 (`'otlp'`) to exporter class instances (`new OtelExporter()`)

### 來自人工智慧追蹤 {/* #from-ai-tracing */}

如果您已經升級到AI追蹤（中間系統），則需要安裝新套件並使用明確設定。

**之前（AI追蹤）：**

```typescript
import { Mastra } from '@mastra/core'

export const mastra = new Mastra({
  observability: {
    default: { enabled: true },
  },
})
```

**之後（v1 Observability）：**

```typescript
import { Mastra } from '@mastra/core'
import {
  Observability,
  MastraStorageExporter,
  MastraPlatformExporter,
  SensitiveDataFilter,
} from '@mastra/observability'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      default: {
        serviceName: 'mastra',
        exporters: [new MastraStorageExporter(), new MastraPlatformExporter()],
        spanOutputProcessors: [new SensitiveDataFilter()],
      },
    },
  }),
})
```

主要變化：

1. 安裝`@mastra/observability` package
2. 進口`Observability`, exporters, and processors from `@mastra/observability`
3. 使用顯式`configs` with `MastraStorageExporter`, `MastraPlatformExporter`, and `SensitiveDataFilter`

## 改變了 {/* #changed */}

### 包導入路徑 {/* #package-import-path */}

Observability功能已轉移到專用的`@mastra/observability` package.

若要遷移，請安裝套件並更新導入語句：

```bash npm2yarn
npm install @mastra/observability@latest
```

```diff
- import { Tracing } from '@mastra/core/observability';
+ import { Observability } from '@mastra/observability';
```

### 註冊表配置 {/* #registry-configuration */}

可觀察性註冊表現在使用以下配置`Observability` class instance with explicit configs instead of a plain object.

要遷移，請使用`new Observability()` with explicit exporters and processors.

```diff
+ import {
+   Observability,
+   MastraStorageExporter,
+   MastraPlatformExporter,
+   SensitiveDataFilter,
+ } from '@mastra/observability';

  export const mastra = new Mastra({
-   observability: {
-     default: { enabled: true },
-   },
+   observability: new Observability({
+     configs: {
+       default: {
+         serviceName: 'mastra',
+         exporters: [new MastraStorageExporter(), new MastraPlatformExporter()],
+         spanOutputProcessors: [new SensitiveDataFilter()],
+       },
+     },
+   }),
  });
```

### 配置屬性`processors` to `spanOutputProcessors` {/* #configuration-property-processors-to-spanoutputprocessors */}

span 處理器的配置屬性已重新命名為`processors` to `spanOutputProcessors`.

若要遷移，請重新命名配置物件中的屬性。

```diff
+ import { SensitiveDataFilter } from '@mastra/observability';

  export const mastra = new Mastra({
    observability: new Observability({
      configs: {
        production: {
          serviceName: 'my-app',
-         processors: [new SensitiveDataFilter()],
+         spanOutputProcessors: [new SensitiveDataFilter()],
          exporters: [...],
        },
      },
    }),
  });
```

### 出口商方法`exportEvent` to `exportTracingEvent` {/* #exporter-method-exportevent-to-exporttracingevent */}

如果您建立了自訂導出器，則導出器方法已重新命名為`exportEvent` to `exportTracingEvent`.

若要遷移，請更新自訂匯出器中的方法實作。

```diff
  export class MyExporter implements ObservabilityExporter {
-   exportEvent(event: TracingEvent): void {
+   exportTracingEvent(event: TracingEvent): void {
      // export logic
    }
  }
```

## 已刪除 {/* #removed */}

### 基於OTEL`telemetry` configuration {/* #otel-based-telemetry-configuration */}

OTEL為基礎`telemetry` configuration from 0.x has been removed. The old system with `serviceName`, `sampling.type`, and `export.type` properties is no longer supported.

要遷移，請按照上面的“從基於 OTEL 的遙測”部分進行操作。有關詳細配置選項，請參閱[observability tracing documentation](/docs/observability/tracing/overview).

### 自訂儀器文件 {/* #custom-instrumentation-files */}

自動偵測儀器文件`/mastra` (with `.ts`, `.js`, or `.mjs` extensions) has been removed. Custom instrumentation is no longer supported through separate files.

若要遷移，請使用內建匯出器系統或使用`ObservabilityExporter` interface.

### `instrumentation.mjs`文件 {/* #instrumentationmjs-files */}

如果您正在使用`instrumentation.mjs` files to initialize OpenTelemetry instrumentation (common in deployment setups like AWS Lambda), these are no longer needed. The new observability system is configured directly in your Mastra instance.

#### 之前 (0.x) {/* #before-0x */}

您需要一個儀器文件：

```javascript
// instrumentation.mjs
import { NodeSDK } from '@opentelemetry/sdk-node'
// ... OTEL setup
```

並且必須在啟動流程時導入它：

```bash
node --import=./.mastra/output/instrumentation.mjs --env-file=".env" .mastra/output/index.mjs
```

#### 之後（v1） {/* #after-v1 */}

只需刪除`instrumentation.mjs` file and configure observability in your Mastra instance:

```typescript
// src/mastra/index.ts
import {
  Observability,
  MastraStorageExporter,
  MastraPlatformExporter,
  SensitiveDataFilter,
} from '@mastra/observability'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      default: {
        serviceName: 'mastra',
        exporters: [new MastraStorageExporter(), new MastraPlatformExporter()],
        spanOutputProcessors: [new SensitiveDataFilter()],
      },
    },
  }),
})
```

正常啟動您的進程，無需`--import` flag:

```bash
node --env-file=".env" .mastra/output/index.mjs
```

不需要單獨的偵測文件或特殊的啟動標誌。

### 安裝 {/* #installation */}

**專注的出口商**（Arize、Braintrust、Langfuse、LangSmith）：

```bash npm2yarn
npm install @mastra/[exporter-name]-exporter
```

**OpenTelemetry 匯出器**（Dash0、Laminar、New Relic、SigNoz、Traceloop）：

```bash npm2yarn
npm install @mastra/otel-exporter@latest
```

加上您的提供者所需的協議包（請參閱[OTEL guide](/integrations/observability/opentelemetry#exporter)).
