# 部署

OpenAPI 規格端點已移至 `/api/openapi.json`，而 `CloudflareDeployer` 設定已改用 `wrangler.json` 的標準欄位名稱。

## 變更 {/* #changed */}

### OpenAPI 規格端點已移至 `/api/openapi.json` {/* #openapi-spec-endpoint-moved-to-apiopenapijson */}

OpenAPI 規格端點已由 `/openapi.json` 移至 `/api/openapi.json`，與所有 Mastra 內置路由一樣採用 `/api` 前綴。

如指令碼或工具需要讀取 OpenAPI 規格，請更新相關 URL。

```diff
- GET /openapi.json
+ GET /api/openapi.json
```

### `CloudflareDeployer` 採用 `wrangler.json` 的標準欄位名稱 {/* #cloudflaredeployer-uses-standard-wranglerjson-property-names */}

`CloudflareDeployer` 建構函數現已接受 `wrangler.json` 的標準欄位名稱，取代自訂的 camelCase 名稱。這項變更讓部署器符合 Cloudflare 的官方設定格式，並可使用 Wrangler 的所有設定項目。

系統執行時會自動遷移已棄用的欄位，並在控制台顯示警告。請更新程式碼，使用新欄位名稱。

```diff
  const deployer = new CloudflareDeployer({
-   projectName: 'my-worker',
+   name: 'my-worker',
-   d1Databases: [
+   d1_databases: [
      {
        binding: 'DB',
        database_name: 'my-db',
        database_id: 'xxx',
      },
    ],
-   kvNamespaces: [
+   kv_namespaces: [
      {
        binding: 'KV',
        id: 'yyy',
      },
    ],
  });
```

`workerNamespace` 欄位已停止使用並移除。

所有可用設定項目請參閱 [Wrangler 設定文件](https://developers.cloudflare.com/workers/wrangler/configuration/)。
