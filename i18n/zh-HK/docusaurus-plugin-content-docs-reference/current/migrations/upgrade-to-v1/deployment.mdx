# 部署

OpenAPI 規範端點已移至`/api/openapi.json`，以及`CloudflareDeployer`配置已更新為使用標準`wrangler.json`屬性名稱。

## 改變了 {/* #changed */}

### OpenAPI 規範端點移至`/api/openapi.json` {/* #openapi-spec-endpoint-moved-to-apiopenapijson */}

OpenAPI 規格端點已從`/openapi.json` to `/api/openapi.json` to align with the `/api` prefix used by all built-in Mastra routes.

如果您有使用 OpenAPI 規格的腳本或Tool，請更新 URL：

```diff
- GET /openapi.json
+ GET /api/openapi.json
```

### `CloudflareDeployer`使用標準`wrangler.json` property names {/* #cloudflaredeployer-uses-standard-wranglerjson-property-names */}

這`CloudflareDeployer` constructor now accepts standard `wrangler.json` property names instead of custom camelCase variants. This change aligns the deployer with Cloudflare's official configuration format and provides access to all wrangler configuration options.

已棄用的欄位會在執行時間自動遷移，並發出控制台警告，但您應該更新程式碼以使用新的欄位名稱。

```diff
  const deployer = new CloudflareDeployer({
-   projectName: 'my-worker',
+   name: 'my-worker',
-   d1Databases: [
+   d1_databases: [
      {
        binding: 'DB',
        database_name: 'my-db',
        database_id: 'xxx',
      },
    ],
-   kvNamespaces: [
+   kv_namespaces: [
      {
        binding: 'KV',
        id: 'yyy',
      },
    ],
  });
```

這`workerNamespace` field has been removed as it's no longer used.

有關所有可用的配置選項，請參閱[Wrangler configuration documentation](https://developers.cloudflare.com/workers/wrangler/configuration/).
