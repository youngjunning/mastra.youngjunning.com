# 處理器

處理器介面已更新為使用一致的命名模式和資料庫訊息類型。

## 改變了 {/* #changed */}

### 處理器配置來自`name` to `id` {/* #processor-configuration-from-name-to-id */}

處理器現在需要一個`id` field instead of `name`. The `name`字段現在是可選的。新領域將處理者與其他 Mastra 實體（例如記分者和Agent）結合起來。

若要遷移，請更新要使用的處理器定義`id` as the required field.

```diff
  import type { InputProcessor } from '@mastra/core/processors';

  const processor: InputProcessor = {
-   name: 'my-processor',
+   id: 'my-processor',
+   name: 'My Processor', // optional
    processInput: async ({ messages }) => {
      // ...
    },
  };
```

### 處理器訊息類型來自`MastraMessageV2` to `MastraDBMessage` {/* #processor-message-types-from-mastramessagev2-to-mastradbmessage */}

處理器訊息類型已變更為`MastraMessageV2` to `MastraDBMessage`. Processors and scorers now use the database message format and its types.

若要遷移，請更新處理器訊息類型匯入和使用。

```diff
  import type { InputProcessor } from '@mastra/core/processors';
- import type { MastraMessageV2 } from '@mastra/core/agent';
+ import type { MastraDBMessage } from '@mastra/core/agent';

  const processor: InputProcessor = {
    id: 'my-processor',
-   processInput: async ({ messages }: { messages: MastraMessageV2[] }) => {
+   processInput: async ({ messages }: { messages: MastraDBMessage[] }) => {
      // ...
    },
  };
```

## 已刪除 {/* #removed */}

### 已棄用的輸入處理器導出 {/* #deprecated-input-processor-exports */}

已棄用的輸入處理器導出（包括內建處理器）已從`@mastra/core/agent/input-processors/processors`. Use `@mastra/core/processors` instead. This change consolidates processor types under the unified `Processor` interface.

如果您使用過`InputProcessor`, replace it with `Processor` which implements a `processInput` function.

```diff
- import { InputProcessor, ModerationProcessor } from '@mastra/core/agent/input-processors/processors';
+ import { Processor, ModerationProcessor } from '@mastra/core/processors';
```

### 內存處理器出口轉移至核心 {/* #memory-processor-exports-moved-to-core */}

這`@mastra/memory/processors` export has been removed. All processors are now exported from `@mastra/core/processors`. This change consolidates all processor exports in a single location.

若要遷移，請更新您的匯入路徑`@mastra/memory/processors` to `@mastra/core/processors`.

```diff
- import { TokenLimiter, ToolCallFilter } from '@mastra/memory/processors';
+ import { TokenLimiter, ToolCallFilter } from '@mastra/core/processors';
```
