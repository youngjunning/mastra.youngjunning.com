# 向量儲存

向量儲存的建構函數現在必須提供 `id` 屬性，部分方法亦已重新命名，以統一命名方式。

## 變更 {/* #changed */}

### 向量儲存實例必須提供 `id` {/* #required-id-property-for-vector-store-instances */}

向量儲存實例現在必須提供 `id` 屬性。Mastra 會用這個唯一識別碼追蹤及管理實例。應用程式中的每個向量儲存，都應以描述清晰而且不重複的字串作為 `id`。

遷移時，請在向量儲存的建構函數中加入 `id` 欄位。

```diff
  const vectorStore = new PgVector({
+   id: 'main-vector-store',
    connectionString: process.env.POSTGRES_CONNECTION_STRING,
  });

  const chromaStore = new ChromaVector({
+   id: 'chroma-embeddings',
    url: process.env.CHROMA_URL,
  });

  const pineconeStore = new PineconeVector({
+   id: 'pinecone-production',
    apiKey: process.env.PINECONE_API_KEY,
  });
```

### `getVectors` 改為 `listVectors` {/* #getvectors-to-listvectors */}

`getVectors()` 已重新命名為 `listVectors()`，與 API 中使用 `list` 前綴命名讀取多個項目方法的慣例一致。

遷移時，請將所有 `getVectors()` 呼叫改為 `listVectors()`。

```diff
  const vectorStore = new VectorStore({ ... });

- const vectors = await vectorStore.getVectors({ ... });
+ const vectors = await vectorStore.listVectors({ ... });
```

### `LibSQLVector`：`connectionUrl` 改為 `url` {/* #libsqlvector-connectionurl-to-url */}

`connectionUrl` 參數已重新命名為 `url`，以與 `@libsql/client` API 及 LibSQLStorage 保持一致。

```diff
  const vectorStore = new LibSQLVector({
    id: 'my-vector',
-   connectionUrl: 'file:./db.sqlite',
+   url: 'file:./db.sqlite',
  });
```

### `OpenSearchVector`：`url` 改為 `node` {/* #opensearchvector-url-to-node */}

`url` 參數已重新命名為 `node`，以符合 OpenSearch 的 `ClientOptions` API。建構函數現在接受所有 OpenSearch 用戶端選項，包括驗證、SSL 及壓縮。

```diff
  const vectorStore = new OpenSearchVector({
    id: 'my-vector',
-   url: 'http://localhost:9200',
+   node: 'http://localhost:9200',
  });
```

### `PineconeVector`：移除 `environment` {/* #pineconevector-environment-removed */}

`environment` 參數已移除。如需指定自訂控制器主機，請改用 `controllerHostUrl`。建構函數現在接受所有 Pinecone 設定選項。

```diff
  const vectorStore = new PineconeVector({
    id: 'my-vector',
    apiKey: process.env.PINECONE_API_KEY,
-   environment: process.env.PINECONE_ENVIRONMENT,
  });
```

如需自訂控制器主機：

```ts
const vectorStore = new PineconeVector({
  id: 'my-vector',
  apiKey: process.env.PINECONE_API_KEY,
  controllerHostUrl: 'https://api.pinecone.io',
})
```
