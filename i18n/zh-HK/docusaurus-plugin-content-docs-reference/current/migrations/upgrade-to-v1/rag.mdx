# RAG

RAG 套件更改了分塊參數的名稱，亦收窄了參數可接受的類型。

## 變更 {/* #changed */}

### 由 `keepSeparator` 改為 `separatorPosition` {/* #keepseparator-to-separatorposition */}

參數 `keepSeparator` 已改名為 `separatorPosition`，類型亦已簡化。舊類型是 `boolean | 'start' | 'end'`，當中 `true` 等同 `'start'`。新參數只接受明確指定的 `'start' | 'end'`，省略時會捨棄分隔符號。

遷移時，請按下表把 `keepSeparator` 改為 `separatorPosition`。

| 舊值 | 新值 |
| - | - |
|`keepSeparator: true` | `separatorPosition: 'start'` |
| `keepSeparator: 'start'` | `separatorPosition: 'start'` |
| `keepSeparator: 'end'` | `separatorPosition: 'end'` |
| `keepSeparator: false` | 移除此參數 |
| 已省略參數 | 毋須更改 |

```diff
  await doc.chunk({
    strategy: 'character',
    separator: '.',
-   keepSeparator: true,
+   separatorPosition: 'start',
  });

  await doc.chunk({
    strategy: 'character',
    separator: '.',
-   keepSeparator: 'end',
+   separatorPosition: 'end',
  });

  await doc.chunk({
    strategy: 'character',
    separator: '.',
-   keepSeparator: false,
+   // Parameter removed - separator is discarded by default
  });
```
