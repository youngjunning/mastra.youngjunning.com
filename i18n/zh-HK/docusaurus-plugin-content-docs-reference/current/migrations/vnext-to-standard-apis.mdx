# 由 VNext 轉用標準 API

由 `@mastra/core` 的 `v0.20.0` 版本起，以下變更生效。

## 舊版 API（AI SDK v4） {/* #legacy-apis-ai-sdk-v4 */}

原有方法已更名，並繼續兼容 **AI SDK v4** 及 `v1` 模型。

* `.stream()` → `.streamLegacy()`
* `.generate()` → `.generateLegacy()`

## 標準 API（AI SDK v5） {/* #standard-apis-ai-sdk-v5 */}

這些是目前的 API，完全兼容 **AI SDK v5** 及 `v2` 模型。

* `.streamVNext()` → `.stream()`
* `.generateVNext()` → `.generate()`

## 遷移路徑 {/* #migration-paths */}

如果你已在使用 `.streamVNext()` 及 `.generateVNext()`，可透過搜尋及取代，分別將它們改為 `.stream()` 及 `.generate()`。

如果你使用的是舊版 `.stream()` 及 `.generate()`，請先決定是否升級。如果暫不升級，可透過搜尋及取代，分別將它們改為 `.streamLegacy()` 及 `.generateLegacy()`。

選擇適合您需求的遷移路徑：

### 繼續使用 AI SDK v4 模型 {/* #keep-using-ai-sdk-v4-models */}

* 將所有 `.stream()` 及 `.generate()` 呼叫分別改為 `.streamLegacy()` 及 `.generateLegacy()`。

> 無需進一步更改。

### 繼續使用 AI SDK v5 模型 {/* #keep-using-ai-sdk-v5-models */}

* 將所有 `.streamVNext()` 及 `.generateVNext()` 呼叫分別改為 `.stream()` 及 `.generate()`。

> 無需進一步更改。

### 由 AI SDK v4 升級至 v5 {/* #upgrade-from-ai-sdk-v4-to-v5 */}

* 將所有模型 Provider 套件升級至下一個主版本。

> 這會確保它們都使用 v5 模型。請閱讀下文，了解主要差異並據此更新程式碼。

## 主要差異 {/* #key-differences */}

更新後的 `.stream()` 及 `.generate()`，在行為、相容性、回傳類型及可用選項方面，與舊版方法不同。本節介紹遷移時需要了解的主要變更。

### 模型版本支援 {/* #model-version-support */}

**舊版 API**

* `.generateLegacy()`
* `.streamLegacy()`

僅支援 **AI SDK v4** 模型（`specificationVersion: 'v1'`）。

**標準 API**

* `.generate()`
* `.stream()`

僅支援 **AI SDK v5** 模型（`specificationVersion: 'v2'`）。

> 執行時會檢查模型版本，並在不兼容時顯示明確的錯誤訊息。

### 回傳類型 {/* #return-types */}

**舊版 API**

* `.generateLegacy()` 回傳：`GenerateTextResult` 或 `GenerateObjectResult`

* `.streamLegacy()` 回傳：`StreamTextResult` 或 `StreamObjectResult`

詳情請參閱以下 API 參考文件：

* [Agent.generateLegacy()](/reference/agents/generateLegacy)
* [Agent.streamLegacy()](/reference/streaming/agents/streamLegacy)

**標準 API**

* `.generate()`
  * `format: 'mastra'`（預設）：回傳 `MastraModelOutput.getFullOutput()`
  * `format: 'aisdk'`：回傳 `AISDKV5OutputStream.getFullOutput()`
  * 內部呼叫 `.stream()`，並等待 `.getFullOutput()` 完成

* `.stream()`
  * `format: 'mastra'`（預設）：回傳 `MastraModelOutput<OUTPUT>`
  * `format: 'aisdk'`：回傳 `AISDKV5OutputStream<OUTPUT>`

詳情請參閱以下 API 參考文件：

* [Agent.generate()](/reference/agents/generate)
* [Agent.stream()](/reference/streaming/agents/stream)

### 格式控制 {/* #format-control */}

#### 舊版 API {/* #legacy-apis */}

沒有 `format` 選項：一律回傳 AI SDK v4 類型。

```typescript
// Mastra native format (default)
const result = await agent.stream(messages)
```

#### 標準 API {/* #standard-apis */}

使用 `format` 選項選擇輸出格式：

* `'mastra'`（預設）
* `'aisdk'`（兼容 AI SDK v5）

```typescript
// AI SDK v5 compatibility
const result = await agent.stream(messages, {
  format: 'aisdk',
})
```

### 標準 API 中的新選項 {/* #new-options-in-standard-apis */}

標準 `.stream()` 及 `.generate()` 支援以下選項，舊版方法則**不支援**：

* `format` - 選擇 `'mastra'` 或 `'aisdk'` 輸出格式：

  ```typescript
  const result = await agent.stream(messages, {
    format: 'aisdk', // or 'mastra' (default)
  })
  ```

* `system` - 自訂系統訊息（與指令分開設定）。

  ```typescript
  const result = await agent.stream(messages, {
    system: 'You are a helpful assistant',
  })
  ```

* `structuredOutput` - 支援覆寫模型及設定自訂選項的增強型結構化輸出。
  * `jsonPromptInjection` - 覆寫預設將 `response_format` 傳給模型的行為，改為在提示詞中加入上下文，引導模型回傳結構化輸出。
  * `model` - 指定模型後，會建立子 Agent 整理主 Agent 的回應。主 Agent 呼叫 Tool 並回傳文字，子 Agent 則回傳符合所提供 schema 的物件。此選項取代 `experimental_output`。
  * `errorStrategy` - 指定輸出不符合 schema 時的處理方式：

    * 'warn' - 記錄警告
    * 'strict' - 擲出錯誤
    * 'fallback' - 回傳你提供的備用值

    ```typescript
    const result = await agent.generate(messages, {
      structuredOutput: {
        schema: z.object({
          name: z.string(),
          age: z.number(),
        }),
        model: '__GATEWAY_OPENAI_MODEL__', // Optional model override for structuring
        errorStrategy: 'fallback',
        fallbackValue: { name: 'unknown', age: 0 },
        instructions: 'Extract user information', // Override default structuring instructions
      },
    })
    ```

* `stopWhen` - 靈活設定停止條件（例如步數、token 數量上限）。

  ```typescript
  const result = await agent.stream(messages, {
    stopWhen: ({ steps, totalTokens }) => steps >= 5 || totalTokens >= 10000,
  })
  ```

* `providerOptions` - Provider 專屬選項（例如 OpenAI 專屬設定）。

  ```typescript
  const result = await agent.stream(messages, {
    providerOptions: {
      openai: {
        store: true,
        metadata: { userId: '123' },
      },
    },
  })
  ```

* `onChunk` - 收到每個串流資料區塊時呼叫的回呼。

  ```typescript
  const result = await agent.stream(messages, {
    onChunk: chunk => {
      console.log('Received chunk:', chunk)
    },
  })
  ```

* `onError` - 發生錯誤時呼叫的回呼。

  ```typescript
  const result = await agent.stream(messages, {
    onError: error => {
      console.error('Stream error:', error)
    },
  })
  ```

* `onAbort` - 執行中止時呼叫的回呼。

  ```typescript
  const result = await agent.stream(messages, {
    onAbort: () => {
      console.log('Stream aborted')
    },
  })
  ```

* `activeTools` - 指定這次執行可用的 Tool。

  ```typescript
  const result = await agent.stream(messages, {
    activeTools: ['search', 'calculator'], // Only these tools will be available
  })
  ```

* `abortSignal` - 用於取消執行的 AbortSignal。

  ```typescript
  const controller = new AbortController()
  const result = await agent.stream(messages, {
    abortSignal: controller.signal,
  })

  // Later: controller.abort();
  ```

* `prepareStep` - 多步驟執行中，每個步驟開始前呼叫的回呼。

  ```typescript
  const result = await agent.stream(messages, {
    prepareStep: ({ step, state }) => {
      console.log('About to execute step:', step)
      return {/* modified state */}
    },
  })
  ```

* `requireToolApproval` - 要求所有 Tool 呼叫都經過批准。

  ```typescript
  const result = await agent.stream(messages, {
    requireToolApproval: true,
  })
  ```

### 已遷移的舊版選項 {/* #legacy-options-that-moved */}

* `temperature` 及其他模型設定。

  現在統一放在 `modelSettings` 中。

  ```typescript
  const result = await agent.stream(messages, {
    modelSettings: {
      temperature: 0.7,
      maxTokens: 1000,
      topP: 0.9,
    },
  })
  ```

* `resourceId` 及 `threadId`。

  現在放在 `memory` 物件中。

  ```typescript
  const result = await agent.stream(messages, {
    memory: {
      resource: 'user-123',
      thread: 'thread-456',
    },
  })
  ```

### 已棄用或移除的選項 {/* #deprecated-or-removed-options */}

* `experimental_output`

  改用 `structuredOutput`，以便呼叫 Tool 並回傳物件。

  ```typescript
  const result = await agent.generate(messages, {
    structuredOutput: {
      schema: z.object({
        summary: z.string(),
      }),
      model: '__GATEWAY_OPENAI_MODEL__',
    },
  })
  ```

* `output`

  `output` 屬性已棄用，請改用 `structuredOutput`。若要取得相同結果，請勿指定模型，只需傳入 `structuredOutput.schema`；如果模型原生不支援 `response_format`，亦可設定 `jsonPromptInjection: true`。

  ```typescript
  const result = await agent.generate(messages, {
    structuredOutput: {
      schema: z.object({
        name: z.string(),
      }),
    },
  })
  ```

* `memoryOptions`

  改用 `memory`。

  ```typescript
  const result = await agent.generate(messages, {
    memory: {},
  })
  ```

### 類型變更 {/* #type-changes */}

**舊版 API**

* `CoreMessage[]`

詳情請參閱以下 API 參考文件：

* [Agent.generateLegacy()](/reference/agents/generateLegacy)
* [Agent.streamLegacy()](/reference/streaming/agents/streamLegacy)

**標準 API**

* `ModelMessage[]`

  `toolChoice` 使用 AI SDK v5 的 `ToolChoice` 類型。

  ```typescript
  type ToolChoice<TOOLS extends Record<string, unknown>> =
    | 'auto'
    | 'none'
    | 'required'
    | {
        type: 'tool'
        toolName: Extract<keyof TOOLS, string>
      }
  ```

詳情請參閱以下 API 參考文件：

* [Agent.generate()](/reference/agents/generate)
* [Agent.stream()](/reference/streaming/agents/stream)
