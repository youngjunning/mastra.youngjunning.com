# 從 `.network()` 遷移至監督 Agent

建議使用透過 `Agent.stream()` 和 `Agent.generate()` 呼叫的監督 Agent 協調多個 Agent，以取代舊版 `.network()` API。本指南會逐步說明遷移流程。

:::warning[.network() 已棄用]

`.network()` 已棄用，並將在未來版本移除。在此之前，現有程式碼仍可運作，但後續開發重點已轉向監督 Agent。請盡快遷移至監督 Agent。

:::

## 使用 `.stream()` 或 `.generate()` 取代 `.network()` {/* #replace-network-with-stream-or-generate */}

主要變更是將 `.network()` 呼叫改為 `.stream()`（串流輸出）或 `.generate()`（非串流輸出）。Agent 設定維持不變：您仍須在 Agent 上定義 `agents`、`workflows`、`tools` 和 `memory`。改變的是呼叫方式和結果處理方式。

使用 `.network()` 時，您需要逐一處理 `network-execution-event-step-finish` 等自訂事件類型。使用 `.stream()` 時，則透過標準的 `textStream` 或 `fullStream` 迭代器處理結果。

**前：**

```typescript
const result = await routingAgent.network('Research AI in education')

for await (const chunk of result) {
  if (chunk.type === 'network-execution-event-step-finish') {
    console.log(chunk.payload.result)
  }
}
```

**後：**

```typescript
const stream = await supervisorAgent.stream('Research AI in education', {
  maxSteps: 10,
})

for await (const chunk of stream.textStream) {
  process.stdout.write(chunk)
}
```

`maxSteps` 選項會限制監督 Agent 可執行的迭代次數，取代 `.network()` 中隱含的迭代次數限制。

如無需串流輸出，請使用 `generate()`，並傳入相同的選項：

```typescript
const result = await supervisorAgent.generate('Research AI in education', {
  maxSteps: 10,
})

console.log(result.text)
```

## 撰寫清晰的監督 Agent 指示 {/* #write-clear-supervisor-instructions */}

使用 `.network()` 時，路由 Agent 會根據一般指示及各資源的描述，決定要呼叫哪個資源。監督 Agent 的運作方式相同，但清晰、具體的指示有助提高委派準確度。

監督 Agent 的 `instructions` 應列明可用資源及各自的使用時機，並說明如何協調這些資源，以及如何判斷任務已完成。

**前：**

```typescript
const routingAgent = new Agent({
  id: 'routing-agent',
  instructions: 'You are a network of researchers and writers...',
  agents: { researchAgent, writingAgent },
  memory: new Memory(),
})
```

**後：**

```typescript
const supervisorAgent = new Agent({
  id: 'supervisor-agent',
  instructions: `You coordinate research and writing tasks using specialized agents.

Available resources:
- researchAgent: Gathers factual data and sources (returns bullet points)
- writingAgent: Transforms research into narrative content (returns full paragraphs)

Delegation strategy:
1. For research requests: Delegate to researchAgent first
2. For writing requests: Delegate to writingAgent (provide research if available)
3. For complex requests: Delegate to researchAgent first, then writingAgent

Success criteria:
- All user questions are fully answered
- Response is well-formatted and complete
- If information is incomplete, continue iterating`,
  agents: { researchAgent, writingAgent },
  memory: new Memory(),
})
```

## 為子 Agent 加入描述 {/* #add-descriptions-to-subagents */}

每個子 Agent 都應設定 `description` 欄位，說明其用途、傳回內容的格式及適用時機。監督 Agent 會根據這些描述，決定將任務委派給哪個 Agent。

```typescript
const researchAgent = new Agent({
  id: 'research-agent',
  description: `Specializes in gathering factual information and data on any topic.
    Returns concise bullet-point summaries with key facts and sources.
    Does not write full articles or narrative content.`,
})

const writingAgent = new Agent({
  id: 'writing-agent',
  description: `Transforms research material into well-structured written content.
    Produces full paragraphs and complete articles.
    Best used after research has been gathered.`,
})
```

## 更新事件處理 {/* #update-event-handling */}

如果您的程式碼會處理特定的 `.network()` 事件，請改為處理標準的串流資料區塊類型：

| `.network()` 事件 | 監督 Agent 的資料區塊 |
| - | - |
| `routing-agent-start` | `step-start` |
| `routing-agent-end` | `step-finish` |
| `agent-execution-start` | `step-start`（委派時） |
| `agent-execution-event-text-delta` | `text-delta` |
| `agent-execution-event-finish` | `step-finish` |
| `network-execution-event-step-finish` | `step-finish` + `finishReason: 'stop'` |
| `network-object` | `object-delta`（使用 structuredOutput 時） |
| `network-object-result` | `object`（使用 structuredOutput 時） |

## 加入委派鉤子 {/* #add-delegation-hooks */}

監督 Agent 提供委派生命週期鉤子，可用於監察、修改或拒絕委派。您可以在 Agent 的 `defaultOptions` 中設定這些鉤子，亦可以在每次呼叫時傳入。

監督 Agent 將任務委派給子 Agent 前，會呼叫 `onDelegationStart`。您可以在此修改提示詞、限制子 Agent 的執行步數，或直接拒絕這次委派：

```typescript
const stream = await supervisorAgent.stream('Research AI in education', {
  maxSteps: 10,
  delegation: {
    onDelegationStart: async context => {
      console.log(`Delegating to: ${context.primitiveId}`)

      if (context.primitiveId === 'research-agent') {
        return {
          proceed: true,
          modifiedPrompt: `${context.prompt}\n\nFocus on 2024-2025 data.`,
          modifiedMaxSteps: 5,
        }
      }

      if (context.iteration > 8) {
        return {
          proceed: false,
          rejectionReason: 'Max iterations reached. Synthesize current findings.',
        }
      }

      return { proceed: true }
    },
  },
})
```

委派完成後，會呼叫 `onDelegationComplete`。您可以檢查結果，並在需要停止監督 Agent 的循環時呼叫 `context.bail()`；亦可以傳回回饋，將其儲存至監督 Agent 的記憶中：

```typescript
const stream = await supervisorAgent.stream('Research AI in education', {
  maxSteps: 10,
  delegation: {
    onDelegationComplete: async context => {
      if (context.error) {
        context.bail() // Stop further delegations
        return {
          feedback: `Delegation to ${context.primitiveId} failed: ${context.error}. Try a different approach.`,
        }
      }
    },
  },
})
```

## 加入訊息過濾 {/* #add-message-filtering */}

預設情況下，子 Agent 會收到監督 Agent 的完整對話內容。您可以使用 `messageFilter` 控制要分享哪些訊息，例如移除敏感資料或限制訊息數量：

```typescript
const stream = await supervisorAgent.stream('Research AI in education', {
  maxSteps: 10,
  delegation: {
    messageFilter: ({ messages, primitiveId, prompt }) => {
      return messages
        .filter(msg => {
          const content =
            typeof msg.content === 'string' ? msg.content : JSON.stringify(msg.content)
          return !content.includes('confidential')
        })
        .slice(-10)
    },
  },
})
```

## 監察迭代進度 {/* #add-iteration-monitoring */}

監督 Agent 的循環每完成一次迭代，就會呼叫 `onIterationComplete`。您可以用它記錄進度，或提供回饋以引導 Agent；這個鉤子亦可提前停止執行：

```typescript
const stream = await supervisorAgent.stream('Research AI in education', {
  maxSteps: 10,
  onIterationComplete: async context => {
    console.log(`Iteration ${context.iteration}/${context.maxIterations}`)

    if (!context.text.includes('recommendations')) {
      return {
        continue: true,
        feedback: 'Please include specific recommendations in your analysis.',
      }
    }

    if (context.text.length > 1000 && context.finishReason === 'stop') {
      return { continue: false }
    }

    return { continue: true }
  },
})
```

## 加入任務完成度評分 {/* #add-task-completion-scoring */}

任務完成度評分器會自動驗證任務是否完成。如果驗證未通過，監督 Agent 會繼續迭代。未通過評分器的回饋會加入對話內容，讓子 Agent 知道還缺少哪些資料：

```typescript
import { createScorer } from '@mastra/core/evals'

const taskCompleteScorer = createScorer({
  id: 'task-complete',
  name: 'Task Completeness',
}).generateScore(async context => {
  const text = (context.run.output || '').toString()
  const hasAnalysis = text.includes('analysis')
  const hasRecommendations = text.includes('recommendation')
  return hasAnalysis && hasRecommendations ? 1 : 0
})

const stream = await supervisorAgent.stream('Research AI in education', {
  maxSteps: 10,
  isTaskComplete: {
    scorers: [taskCompleteScorer],
    strategy: 'all',
    onComplete: async result => {
      console.log('Task complete:', result.complete)
    },
  },
})
```
