# 線程事件

`subscribeThreadEvents()`[`subscribeToThread()`](/reference/agents/agent#subscribetothreadoptions)，它串流Agent輸出。

## `subscribeThreadEvents(scope, listener)` {/* #subscribethreadeventsscope-listener */}

訂閱一個資源和線程的線程事件。

```typescript
const scope = {
  resourceId: 'user-123',
  threadId: 'thread-abc',
}

const unsubscribe = agent.subscribeThreadEvents(scope, event => {
  if (event.type === 'queue-count-changed') {
    console.log(`${event.count} messages are pending`)
  }
})

// Later, when you no longer need updates:
unsubscribe()
```

當您撥打電話時，計數會發生變化[`queueMessage()`](/reference/agents/agent#queuemessagemessage-options) or [`queueSignal()`](/reference/agents/agent#queuesignalsignal-options) while a run is active on the thread.

計數是運行時本地的。此計數包括使用相同執行時間和 PubSub 實例的其他會話或Agent程式提交的訊息。

該計數包括在本地 FIFO 中等待的訊息以及獲取或轉移其租約時未取消的訊息。它會在取消、執行切換、轉發給另一個所有者或失敗時下降，而不是在模型生成完成時下降。閒著的`queueMessage()` handoff is immediate and isn't represented as a cancellable pending slot.

此計數僅涵蓋共享佇列中的條目[`queueMessage()`](/reference/agents/agent#queuemessagemessage-options) and [`queueSignal()`](/reference/agents/agent#queuesignalsignal-options). It doesn't include signals waiting for delivery into an active run.

所有者範圍的觀察與呼叫Agent、其本地運行時、資源、執行緒和所有者 ID 相符。使用[`cancelQueuedMessages()`](/reference/agents/agent#cancelqueuedmessagesoptions) to cancel selected pending input or an owner group.

`session.steer()` aborts the current run before sending the new input without clearing queued follow-ups. Session cleanup stops observation and cancels unfinished local preparation, but leaves submitted messages in the Agent queue.

## `AgentThreadEvent` {/* #agentthreadevent */}

今天發出的唯一事件類型是`queue-count-changed`.

```typescript
type AgentThreadEvent = {
  type: 'queue-count-changed'
  count: number
}
```

`count`是觀察佇列中本地待處理訊息的數量。複合線程狀態、單一訊息生命週期、運行和批准事件不會作為公共線程事件發出。 Mastra 將來可能會將它們新增為單獨的事件類型。
