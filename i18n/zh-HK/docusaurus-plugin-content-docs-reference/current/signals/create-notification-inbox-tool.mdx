# createNotificationInboxTool()

**加入版本：** `@mastra/core@1.39.0`

`createNotificationInboxTool()` 建立一個 Mastra Tool，讓 Agent 查看及管理目前執行緒的通知收件匣紀錄。

此 Tool 適用於持久化通知訊號。要傳送通知紀錄，請參閱 [`Agent.sendNotificationSignal()`](/reference/agents/agent#sendnotificationsignalnotification-options)；有關紀錄欄位、優先級、狀態及傳遞政策，請參閱[通知參考文件](/reference/signals/notifications)。

## 使用範例 {/* #usage-example */}

以下範例為 Agent 加入通知收件匣 Tool。

```typescript title="src/mastra/agents/support-agent.ts"
import { Agent } from '@mastra/core/agent'
import { createNotificationInboxTool } from '@mastra/core/notifications'

const notificationsStorage = await storage.getStore('notifications')

export const supportAgent = new Agent({
  id: 'support-agent',
  name: 'Support Agent',
  instructions: 'Help the user triage updates.',
  model: '__GATEWAY_OPENAI_MODEL__',
  tools: {
    notificationInbox: createNotificationInboxTool({ storage: notificationsStorage }),
  },
})
```

## 操作 {/* #actions */}

| 操作 | 說明 |
| - | - |
| `list` | 傳回符合條件的通知。未指定 `status` 時，會傳回待處理、已傳遞及傳遞失敗的通知，並將其標記為已查看。 |
| `read` | 以訊號形式傳遞可讀取的通知內容，並將已傳遞的紀錄標記為已查看。 |
| `markSeen` | 將一則通知標記為已查看。 |
| `dismiss` | 將一則通知標記為已忽略。 |
| `archive` | 將一則通知標記為已封存。 |
| `search` | 按查詢字詞及可選的篩選條件搜尋通知。 |

Mastra 用盡通知的傳遞嘗試次數後，該通知的狀態為 `failed`。預設的 `list` 結果包含傳遞失敗的通知。若 `list` 或 `search` 傳回失敗通知，結果會顯示其 `status: 'failed'` 及 `lastDeliveryError`，然後將其標記為已查看，避免之後的清單重複顯示。按 `status: 'failed'` 篩選時，只有首次傳回前能找到該通知；之後其狀態變為 `seen`，但紀錄仍保留 `deliveryAttempts` 及 `lastDeliveryError`。

`read` 找到待處理或已傳遞的通知時，會以通知訊號傳遞內容，而非在一般 Tool 輸出中傳回完整內容。Agent 收到 `<notification-summary>` 訊號後，如需查看摘要對應的完整紀錄，可使用此操作。
