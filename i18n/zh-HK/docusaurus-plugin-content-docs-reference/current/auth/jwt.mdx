# MastraJwtAuth 類

這`MastraJwtAuth`類別使用 JSON Web 令牌 (JWT) 為 Mastra 提供輕量級身份驗證機制。它使用共用金鑰或來自 JSON Web 金鑰集 (JWKS) 端點的公鑰驗證傳入請求，並使用`auth`選項。

## 使用範例 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraJwtAuth } from '@mastra/auth'

export const mastra = new Mastra({
  server: {
    auth: new MastraJwtAuth({
      secret: '<your-secret>',
    }),
  },
})
```

若要驗證身分提供者簽署的令牌，請傳遞其 JWKS URL 和頒發者而不是金鑰：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraJwtAuth } from '@mastra/auth'

export const mastra = new Mastra({
  server: {
    auth: new MastraJwtAuth({
      jwksUri: 'https://auth.example.com/.well-known/jwks.json',
      issuer: 'https://auth.example.com/',
    }),
  },
})
```

## 使用者身分 {/* #user-id */}

經過身份驗證的用戶的`id` is the token's `id` claim, or its `sub` claim when the token has no `id`. RBAC looks up roles by this `id`，並且它擁有用戶創建的記錄，除非`mapUserToResourceId`已設定。看[來自 JWT 提供者的用戶 ID](/docs/guides/authentication-identity#user-ids-from-jwt-providers).
