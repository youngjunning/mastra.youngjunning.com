# MastraJwtAuth 類別

`MastraJwtAuth` 類別透過 JSON Web Token（JWT）為 Mastra 提供輕量級身份驗證機制。它使用共享密鑰或 JSON Web Key Set（JWKS）端點提供的公鑰驗證收到的請求，並透過 `auth` 選項與 Mastra 伺服器整合。

## 使用範例 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraJwtAuth } from '@mastra/auth'

export const mastra = new Mastra({
  server: {
    auth: new MastraJwtAuth({
      secret: '<your-secret>',
    }),
  },
})
```

要驗證身份提供者簽發的權杖，請提供其 JWKS URL 和簽發者，而非共享密鑰：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraJwtAuth } from '@mastra/auth'

export const mastra = new Mastra({
  server: {
    auth: new MastraJwtAuth({
      jwksUri: 'https://auth.example.com/.well-known/jwks.json',
      issuer: 'https://auth.example.com/',
    }),
  },
})
```

## 用戶 ID {/* #user-id */}

已驗證用戶的 `id` 取自權杖的 `id` 聲明，或取自 `sub` 聲明（當權杖沒有 `id` 時）。RBAC 根據此 `id` 查找角色；除非設定了 `mapUserToResourceId`，用戶建立的紀錄亦歸其所有。詳見 [JWT 提供者的用戶 ID](/docs/guides/authentication-identity#user-ids-from-jwt-providers)。
