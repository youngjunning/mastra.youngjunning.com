# MastraAuthOkta 與 MastraRBACOkta 類別

## MastraAuthOkta 類別 {/* #mastraauthokta-class */}

`MastraAuthOkta` 類別使用 Okta 為 Mastra 提供身分驗證。它透過加密的工作階段 cookie 實現 OAuth 2.0 / OIDC 登入流程，並透過 `auth` 選項與 Mastra 伺服器整合。

### 使用範例 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraAuthOkta } from '@mastra/auth-okta'

export const mastra = new Mastra({
  server: {
    auth: new MastraAuthOkta({
      domain: process.env.OKTA_DOMAIN,
      clientId: process.env.OKTA_CLIENT_ID,
      clientSecret: process.env.OKTA_CLIENT_SECRET,
      redirectUri: process.env.OKTA_REDIRECT_URI,
    }),
  },
})
```

:::note

如果已設定所需的環境變數，可以省略建構函式參數，直接使用 `new MastraAuthOkta()`。

:::

### 認證流程 {/* #authentication-flow */}

`MastraAuthOkta` 按以下順序驗證請求：

1. **工作階段 cookie**：讀取並解密加密的工作階段 cookie。工作階段有效且尚未過期時，用戶即通過身分驗證。
2. **JWT 後備驗證**：如沒有工作階段 cookie，則透過 Okta 的 JWKS 端點驗證 `Authorization` 標頭中的權杖。權杖的 `iss` 聲明須與 `issuer` 相符，`aud` 聲明須與 `audience` 相符。

完成身分驗證後，`authorizeUser` 會檢查用戶是否具有有效的 `oktaId`。如需額外邏輯，請提供自訂的 `authorizeUser` 函式。

## MastraRBACOkta 類別 {/* #mastrarbacokta-class */}

`MastraRBACOkta` 類別將 Okta 群組對應至 Mastra 權限。它透過 Okta API 取得用戶群組，並根據可設定的角色對應解析權限。它可配合 `MastraAuthOkta` 或其他身分驗證提供者使用。

:::note

RBAC 在正式環境中需要 Mastra Enterprise Edition (EE) 授權；開發環境毋須授權。詳見[需要 EE 授權的功能](/docs/license#what-requires-an-ee-license)。如需更多資訊，請[聯絡銷售團隊](https://mastra.ai/contact)。

:::

### 使用範例 {/* #usage-example-1 */}

將 `MastraRBACOkta` 傳入 `rbac` 選項，即可配合身分驗證提供者使用：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraAuthOkta, MastraRBACOkta } from '@mastra/auth-okta'

export const mastra = new Mastra({
  server: {
    auth: new MastraAuthOkta(),
    rbac: new MastraRBACOkta({
      roleMapping: {
        Admin: ['*'],
        Engineering: ['agents:*', 'workflows:*', 'tools:*'],
        Viewer: ['agents:read', 'workflows:read'],
        _default: [],
      },
    }),
  },
})
```

如要將 Okta RBAC 與其他身分驗證提供者配合使用，請傳入 `getUserId` 函式，從該提供者的用戶物件取得 Okta 用戶 ID：

```typescript title="src/mastra/index.ts"
import { MastraAuthAuth0 } from '@mastra/auth-auth0'
import { MastraRBACOkta } from '@mastra/auth-okta'
import { Mastra } from '@mastra/core'

export const mastra = new Mastra({
  server: {
    auth: new MastraAuthAuth0(),
    rbac: new MastraRBACOkta({
      getUserId: user => user.metadata?.oktaUserId || user.email,
      roleMapping: {
        Engineering: ['agents:*', 'workflows:*'],
        Admin: ['*'],
        _default: [],
      },
    }),
  },
})
```
