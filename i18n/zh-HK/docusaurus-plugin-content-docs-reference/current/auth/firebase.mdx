# MastraAuthFirebase 類

這`MastraAuthFirebase`類別使用 Firebase 身份驗證為 Mastra 提供身份驗證。它使用 Firebase ID 令牌驗證傳入請求，並使用以下命令與 Mastra 伺服器集成`auth`選項。

## 使用範例 {/* #usage-examples */}

### 環境變數的基本用法 {/* #basic-usage-with-environment-variables */}

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraAuthFirebase } from '@mastra/auth-firebase'

// Automatically uses FIREBASE_SERVICE_ACCOUNT and FIRESTORE_DATABASE_ID env vars
export const mastra = new Mastra({
  server: {
    auth: new MastraAuthFirebase(),
  },
})
```

### 自訂配置 {/* #custom-configuration */}

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraAuthFirebase } from '@mastra/auth-firebase'

export const mastra = new Mastra({
  server: {
    auth: new MastraAuthFirebase({
      serviceAccount: '/path/to/service-account-key.json',
      databaseId: 'your-database-id',
    }),
  },
})
```

## 預設授權行為 {/* #default-authorization-behavior */}

預設情況下，`MastraAuthFirebase` uses Firestore to manage user access:

1. 成功驗證 Firebase ID 令牌後，`authorizeUser` method is called
2. 它檢查文件中是否存在`user_access` collection with the user's UID as the document ID
3. 如果該文件存在，則使用者被授權；否則，存取被拒絕
4. 使用的 Firestore 資料庫由以下因素決定`databaseId` parameter or environment variables

## Firebase 使用者類型 {/* #firebase-user-type */}

這`FirebaseUser` type used in the `authorizeUser` function corresponds to Firebase's `DecodedIdToken` interface, which includes:

* `uid`：使用者的唯一識別符
* `email`：使用者的電子郵件地址（如果有）
* `email_verified`: 信箱是否驗證
* `name`：使用者的顯示名稱（如果有）
* `picture`：使用者個人資料圖片的 URL（如果有）
* `auth_time`: 當使用者認證時
* 以及其他標準 JWT 聲明
