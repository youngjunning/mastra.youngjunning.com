# MastraAuthFirebase 類

`MastraAuthFirebase` 類別透過 Firebase Authentication 為 Mastra 提供身份驗證。它使用 Firebase ID token 驗證傳入的請求，並透過 `auth` 選項與 Mastra 伺服器整合。

## 使用範例 {/* #usage-examples */}

### 環境變數的基本用法 {/* #basic-usage-with-environment-variables */}

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraAuthFirebase } from '@mastra/auth-firebase'

// Automatically uses FIREBASE_SERVICE_ACCOUNT and FIRESTORE_DATABASE_ID env vars
export const mastra = new Mastra({
  server: {
    auth: new MastraAuthFirebase(),
  },
})
```

### 自訂配置 {/* #custom-configuration */}

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraAuthFirebase } from '@mastra/auth-firebase'

export const mastra = new Mastra({
  server: {
    auth: new MastraAuthFirebase({
      serviceAccount: '/path/to/service-account-key.json',
      databaseId: 'your-database-id',
    }),
  },
})
```

## 預設授權行為 {/* #default-authorization-behavior */}

預設情況下，`MastraAuthFirebase` 使用 Firestore 管理用戶的存取權：

1. 成功驗證 Firebase ID token 後，呼叫 `authorizeUser` 方法
1. 檢查 `user_access` 集合中是否有以用戶 UID 作為文件 ID 的文件
1. 如文件存在，便授予用戶存取權；否則拒絕存取
1. 使用的 Firestore 資料庫由 `databaseId` 參數或環境變數決定

## Firebase 使用者類型 {/* #firebase-user-type */}

`FirebaseUser` 類型用於 `authorizeUser` 函式，對應 Firebase 的 `DecodedIdToken` 介面，其中包括：

- `uid`：用戶的唯一識別碼
- `email`：用戶的電郵地址（如有）
- `email_verified`：電郵是否已驗證
- `name`：用戶的顯示名稱（如有）
- `picture`：用戶個人頭像的 URL（如有）
- `auth_time`：用戶完成身份驗證的時間
- 以及其他標準 JWT 聲明
