# MastraAuthBetterAuth 類

`MastraAuthBetterAuth` 類別透過 Better Auth 為 Mastra 應用程式提供身份驗證。它使用 Better Auth session 驗證傳入請求，並透過 `auth` 選項接入 Mastra 伺服器。

## 使用範例 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraAuthBetterAuth } from '@mastra/auth-better-auth'
import { betterAuth } from 'better-auth'

// Create your Better Auth instance
const auth = betterAuth({
  database: {
    provider: 'postgresql',
    url: process.env.DATABASE_URL,
  },
  emailAndPassword: {
    enabled: true,
  },
  baseURL: process.env.BETTER_AUTH_URL,
  secret: process.env.BETTER_AUTH_SECRET,
})

export const mastra = new Mastra({
  server: {
    auth: new MastraAuthBetterAuth({
      auth,
    }),
  },
})
```

## `BetterAuthUser` 類型 {/* #betterauthuser-type */}

`BetterAuthUser` 類型包含 Better Auth 傳回的 session 及用戶資料：

```typescript
interface BetterAuthUser {
  session: Session & { activeOrganizationId?: string | null }
  user: User
}
```

* `session`：包含 session 元數據的 Better Auth session 物件。`activeOrganizationId` 來自 organization 插件。Provider 只會在自行建立的實例中註冊該插件。如果傳入 `auth` 並使用組織功能，請在該實例中加入此插件。
* `user`：包含用戶詳細資料的已認證用戶物件

`Session` 和 `User` 類型由 Better Auth 套件匯出。

## 匹配規則 {/* #matching-rules */}

* `public` 和 `protected` 支援精確路徑、萬用字元模式（如 `/api/*`）及路徑參數（如 `/users/:id`）。
* 如需按 HTTP 方法比對，請使用 `["/api/agents", ["GET", "POST"]]` 這類元組。
* 如果路由同時符合 `public` 和 `protected`，以 `public` 為準，毋須身份驗證；但標記為 `requiresAuth: true` 的路由仍須驗證。
* 如果兩者都不符合，位於 `/api/*` 下的路由（內置預設的 `protected` 模式），或透過 `registerApiRoute()` 註冊且未標記為 `requiresAuth: false` 的自訂路由，仍須身份驗證；其他路徑則毋須驗證。
