# Agent控制器

這`AgentController`類別是一個或多個的共享主機[`Session`](/reference/agent-controller/session)實例。初始化控制器，建立會話，然後使用`session.*`用於對話狀態和運行控制的 API。

有關指導性介紹，請參閱[AgentController overview](/docs/harness/agent-controller).

## 使用範例 {/* #usage-example */}

以下範例初始化控制器並建立會話。它在發送訊息之前訂閱會話事件。

```typescript title="src/mastra/agent-controller.ts"
import { Agent } from '@mastra/core/agent'
import { AgentController } from '@mastra/core/agent-controller'
import { Workspace } from '@mastra/core/workspace'

const agent = new Agent({
  id: 'coding-agent',
  name: 'Coding agent',
  instructions: 'Help with software engineering tasks.',
  model: '__GATEWAY_ANTHROPIC_MODEL_SONNET__',
})

const controller = new AgentController({
  id: 'coding-controller',
  agent,
  workspace: new Workspace({ id: 'coding-workspace' }),
  modes: [{ id: 'build', name: 'Build', metadata: { default: true } }],
})

await controller.init()

const session = await controller.createSession({ resourceId: 'project-42' })
const unsubscribe = session.subscribe(event => {
  if (event.type === 'message_update' && event.event.type === 'text-delta') {
    process.stdout.write(event.event.delta)
  }
})

await session.sendMessage({ content: 'Review the project structure.' })
unsubscribe()
```

訊息生命週期從初始訊息開始`message_start`. Compact `message_update` events address the message by ID and carry text, reasoning, or part changes. `message_end` carries the ID to finalize.

## 方法 {/* #methods */}

### 會議 {/* #sessions */}

#### `createSession(options)` {/* #createsessionoptions */}

取得或建立在下面註冊的即時會話`id`. Call `init()` before this method.

```typescript
const session = await controller.createSession({
  id: 'run-a',
  resourceId: 'project-42',
  threadId: 'thread-7',
})
```

相同`id` returns the same `Session` instance. Sessions with different ids are independent even when they share a `resourceId`: each has its own run loop, thread binding, mode, model, and state, while their stored threads and resource-scoped memory belong to the shared resource. When `id` is omitted, it defaults to `resourceId`, so one session per resource needs no id. When `threadId` is supplied, the method switches a cached session to that thread or creates the thread when it doesn't exist.

#### `onSessionCreated(listener, options?)` {/* #onsessioncreatedlistener-options */}

之後訂閱進程本地通知`createSession()` materializes a new live session, with isolated listener errors prevented from affecting other listeners. Call the returned function to unsubscribe.

預設情況下，偵聽器是「即發即忘」的。經過`{ blocking: true }` to make `createSession()` await the listener before resolving the new session, so the host can prepare session state before the caller can start a run. Blocking listeners run sequentially in registration order, before fire-and-forget listeners are notified. A blocking listener must not call `createSession()` for the same session `id`. That call would await its own hydration and deadlock.

```typescript
const unsubscribe = controller.onSessionCreated(
  async session => {
    const settings = await loadSettings(session.identity.getResourceId())
    if (settings) await session.state.set(settings)
  },
  { blocking: true },
)

// Default listeners stay fire-and-forget.
controller.onSessionCreated(session => {
  console.log(`Created ${session.identity.getResourceId()}`)
})
```

偵聽器在每個新實現的會話中運行一次，而不是為稍後返回的快取會話運行一次`createSession()` calls. They run only in the current process and aren't persisted events.

返回：`() => void`

#### `onSessionDeleted(listener)` {/* #onsessiondeletedlistener */}

之後訂閱進程本地通知`deleteSession()` tears down a live session, with isolated listener errors prevented from affecting other listeners. Call the returned function to unsubscribe.

```typescript
const unsubscribe = controller.onSessionDeleted(session => {
  console.log(`Closed ${session.identity.getResourceId()}`)
})

await controller.createSession({ resourceId: 'project-42' })
await controller.deleteSession({ sessionId: 'project-42' })
unsubscribe()
```

此監聽器是盡力而為的並且僅在當前進程中運行。這不是持久刪除事件。

返回：`() => void`

#### `deleteSession({ sessionId })` {/* #deletesession-sessionid- */}

拆除在下面註冊的物化會話`sessionId`. The method aborts active work, then removes thread subscriptions, the active thread lock, and the live session from the controller registry. It doesn't delete persisted threads or messages.

```typescript
const deleted = await controller.deleteSession({ sessionId: 'run-a' })
```

返回：`Promise<boolean>`. The result is `true` when a live session was removed and `false` when no matching live session exists or when another deletion is already in progress for the same session.


### 儲存查詢 {/* #storage-queries */}

這些方法讀取儲存的執行緒和訊息，而無需建立會話或配置其Workspace。

#### `queryThreadById({ threadId })` {/* #querythreadbyid-threadid- */}

傳回一個儲存的線程，或者`null` when the thread or storage doesn't exist.

```typescript
const thread = await controller.queryThreadById({ threadId: 'thread-7' })
```

返回：`Promise<AgentControllerThread | null>`

#### `queryThreads(options)` {/* #querythreadsoptions */}

列出儲存的線程。`resourceId` and `metadata` filter the results. Forked subagent threads are excluded unless `includeForkedSubagents` is `true`.

```typescript
const threads = await controller.queryThreads({
  resourceId: 'project-42',
  includeForkedSubagents: false,
  metadata: { repository: 'mastra' },
})
```

所有選項都是可選的。返回：`Promise<AgentControllerThread[]>`

#### `queryThreadMessages(options)` {/* #querythreadmessagesoptions */}

列出一個執行緒的儲存訊息，包括分頁、排序​​、包含和過濾選項`StorageListMessagesInput`. `threadId` is required. The default order is newest first by `createdAt`. When `perPage` is omitted, storage uses 40 messages per page.

```typescript
const result = await controller.queryThreadMessages({
  threadId: 'thread-7',
  page: 0,
  perPage: 20,
  orderBy: { field: 'createdAt', direction: 'DESC' },
})
```

返回：`Promise<StorageListMessagesOutput>` with controller-format messages.

#### `generateThreadTitle(options)` {/* #generatethreadtitleoptions */}

從線程的對話中產生並儲存標題，而無需建立會話。`threadId` is required. Optional fields include `sessionId`, `model`, and `requestContext`. Passing `sessionId` borrows a live session's agent and request context. The method throws when the thread doesn't exist and returns `undefined` when the model produces no title.

```typescript
const title = await controller.generateThreadTitle({
  threadId: 'thread-7',
  sessionId: 'run-a',
})
```

返回：`Promise<string | undefined>`

### 生命週期 {/* #lifecycle */}


```typescript

```

#### `listAvailableModels()` {/* #listavailablemodels */}

列出已設定和內建網關的型號。每個型號的`useCount` comes from `modelUseCountProvider` when you configure one.

內建網關下載公共目錄（models.dev 和 Netlify）。只有當尚未下載任何目錄時，呼叫才會等待目錄。之後，呼叫將傳回上次下載的目錄，包括下載失敗時的情況。一旦超過 5 分鐘，下一次呼叫就會在背景下載新的，而無需等待。 10 秒後再次檢查已設定的網關和 API 金鑰可用性。

```typescript
const models = await controller.listAvailableModels()
```

返回：`Promise<AvailableModel[]>`

#### `invalidateAvailableModelsCache()` {/* #invalidateavailablemodelscache */}

進行下一個`listAvailableModels()` call check configured gateways and API key availability again, and download the models.dev and Netlify catalogs again in the background. Call it after your app stores or removes a credential or changes a custom provider.

```typescript
controller.invalidateAvailableModelsCache()
```
