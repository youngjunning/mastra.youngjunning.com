# MastraServer

`MastraServer` 抽象類別是所有伺服器適配器的基礎。繼承此類別，可為 Hono 和 Express 以外的框架建立適配器。

## 匯入 {/* #import */}

```typescript
import { MastraServer } from '@mastra/server/server-adapter'
```

## 類型參數 {/* #type-parameters */}

```typescript
MastraServer<TApp, TRequest, TResponse>
```

|參數|說明 |
| - | - |
|`TApp` | 框架應用程式類型（例如 `Hono`、`Application`） |
| `TRequest`|框架請求類型 |
|`TResponse`|框架回應或上下文類型 |

## 建構函式 {/* #constructor */}

```typescript oxfmt:false
constructor(options: MastraServerOptions<TApp>)
```

## 抽象方法 {/* #abstract-methods */}

這些方法必須由適配器實作：

### `registerContextMiddleware()` {/* #registercontextmiddleware */}

將 Mastra 上下文附加到每個請求。

```typescript oxfmt:false
abstract registerContextMiddleware(): void
```

**要附加的上下文：**

* `mastra` - Mastra 實例
* `requestContext` - 請求級別的上下文
* `tools` - 可用的 Tool
* `abortSignal` - 請求取消訊號

### `registerAuthMiddleware()` {/* #registerauthmiddleware */}

初始化時執行適配器的認證掛鉤。若認證由各路由執行，官方適配器可將此方法實作為空操作。

```typescript oxfmt:false
abstract registerAuthMiddleware(): void
```

### `registerRoute()` {/* #registerroute */}

向框架註冊單一路由。

```typescript oxfmt:false
abstract registerRoute(
  app: TApp,
  route: ServerRoute,
  options: { prefix?: string }
): Promise<void>
```

### `getParams()` {/* #getparams */}

從請求擷取參數。

```typescript oxfmt:false
abstract getParams(
  route: ServerRoute,
  request: TRequest
): Promise<{
  urlParams: Record<string, string>;
  queryParams: Record<string, string | string[]>;
  body: unknown;
}>
```

### `sendResponse()` {/* #sendresponse */}

按路由類型傳送回應。

```typescript oxfmt:false
abstract sendResponse(
  route: ServerRoute,
  response: TResponse,
  result: unknown
): Promise<unknown>
```

### `stream()` {/* #stream */}

處理串流回應。

```typescript oxfmt:false
abstract stream(
  route: ServerRoute,
  response: TResponse,
  result: unknown
): Promise<unknown>
```

## 實例方法 {/* #instance-methods */}

### `init()` {/* #init */}

註冊所有中介軟件和路由，以初始化伺服器。

```typescript oxfmt:false
async init(): Promise<void>
```

依次呼叫：

1. `registerContextMiddleware()`
2. `registerAuthMiddleware()`
3. `registerRoutes()`

### `registerRoutes()` {/* #registerroutes */}

註冊所有 Mastra 路由。

```typescript oxfmt:false
async registerRoutes(): Promise<void>
```

### `getApp()` {/* #getapp */}

取得框架應用程式實例。

```typescript oxfmt:false
getApp<T = TApp>(): T
```

### `parsePathParams()` {/* #parsepathparams */}

使用路由的 Zod schema 驗證路徑參數。

```typescript oxfmt:false
async parsePathParams(
  route: ServerRoute,
  params: Record<string, string>
): Promise<Record<string, unknown>>
```

### `parseQueryParams()` {/* #parsequeryparams */}

使用路由的 Zod schema 驗證查詢參數。

```typescript oxfmt:false
async parseQueryParams(
  route: ServerRoute,
  params: Record<string, string>
): Promise<Record<string, unknown>>
```

### `parseBody()` {/* #parsebody */}

使用路由的 Zod schema 驗證請求主體。

```typescript oxfmt:false
async parseBody(
  route: ServerRoute,
  body: unknown
): Promise<unknown>
```

### `registerOpenAPIRoute()` {/* #registeropenapiroute */}

註冊提供 OpenAPI 規格的端點。

```typescript oxfmt:false
async registerOpenAPIRoute(
  app: TApp,

  options: { prefix?: string }

```

### MCPOptions {/* #mcpoptions */}

```typescript
interface MCPOptions {
  serverless?: boolean
  sessionIdGenerator?: () => string
}
```

|屬性 |說明 |
| - | - |
|`serverless` | 設為 `true` 時，MCP 會以無狀態模式運行，不管理工作階段。適用於 Cloudflare Workers 或 Vercel Edge 等無伺服器環境。 |
| `sessionIdGenerator` | 用於產生工作階段 ID 的自訂函式。 |

  registerContextMiddleware(): void {
    this.app.use('*', (req, res, next) => {
      res.locals.mastra = this.mastra
      next()
    })
  }

  registerAuthMiddleware(): void {
    const auth = this.mastra.getServer()?.auth
    if (!auth) return
