# TanStack 啟動適配器

這`@mastra/tanstack-start`軟體包將 Mastra 安裝在 TanStack Start 應用程式中。看[伺服器適配器](/docs/server/server-adapters)對於一般適配器概念。

## 安裝 {/* #installation */}

安裝 TanStack Start 適配器及其 Hono 對等相依性：

```bash npm2yarn
npm install @mastra/tanstack-start@latest hono
```

## 使用範例 {/* #usage-example */}

將轉接器安裝在包羅萬象的 splat 路線中：

```typescript title="src/routes/api/$.ts"
import { createStartRouteHandler } from '@mastra/tanstack-start'
import { createFileRoute } from '@tanstack/react-router'
import { mastra } from '../../mastra'

export const Route = createFileRoute('/api/$')({
  server: {
    handlers: createStartRouteHandler({ mastra }),
  },
})
```

這`prefix` option defaults to `/api` and must match the splat route's mount path. For example, when mounting at `src/routes/api/mastra/$.ts`, use `createStartRouteHandler({ mastra, prefix: '/api/mastra' })`.

## 簽名 {/* #signature */}

```typescript
function createStartRouteHandler(options: StartRouteHandlerOptions): StartRouteHandlers
```

## 傳回值 {/* #return-value */}

返回一個`StartRouteHandlers` object with `GET`, `POST`, `PUT`, `DELETE`, `PATCH`, `OPTIONS`， 和`HEAD`特性。每個屬性都是具有以下簽名的處理程序：

```typescript
(context: StartHandlerContext) => Response | Promise<Response>
```

上下文類型包含傳入請求和 splat 路由參數：

```typescript
type StartHandlerContext = {
  request: Request
  params: Record<string, string>
}
```

## 無伺服器部署和延遲初始化 {/* #serverless-deployments--lazy-initialization */}

適配器同步導出其路由處理程序，然後建立底層 Hono 應用程式並`MastraServer` when the first request arrives. That initialized app is reused for subsequent requests in the same process, which supports serverless runtimes without top-level asynchronous initialization.

它使用相同的基於Hono的`MastraServer` core as the [Next.js adapter](/reference/server/next-adapter). A2A endpoints use an in-memory task store, so task state lasts only for the lifetime of the process and isn't shared between serverless instances.

## 體型限制 {/* #body-size-limit */}

請求正文的預設限制為 4.5 MB。超過接收限制的請求`{ error: 'Request body too large' }`.

放`server.bodySizeLimit` on the `Mastra` instance to configure the limit.

## 中介軟體 {/* #middleware */}

中介軟體配置為`server.middleware` or `setServerMiddleware()` runs through the adapter's Hono-based server, except on framework-public routes such as those marked `requiresAuth: false`. See [Server middleware](/docs/server/middleware).
