# Fastify 適配器

`@mastra/fastify` 套件提供伺服器適配器，讓 Mastra 可以配合 [Fastify](https://fastify.dev) 運行。有關建構函數選項、初始化流程等適配器通用概念，請參閱[伺服器適配器](/docs/server/server-adapters)。

## 安裝 {/* #installation */}

安裝 Fastify 適配器和 Fastify 框架：

```bash npm2yarn
npm install @mastra/fastify@latest fastify
```

## 使用範例 {/* #usage-example */}

```typescript title="server.ts"
import Fastify from 'fastify'
import { MastraServer } from '@mastra/fastify'
import { mastra } from './mastra'

const app = Fastify({ logger: true })
const server = new MastraServer({ app, mastra })

await server.init()

app.listen({ port: 3000 }, (err, address) => {
  if (err) {
    console.error(err)
    process.exit(1)
  }
  console.log(`Server running on ${address}`)
})
```

`init()` 不會啟動 Mastra 的背景工作程序。如要運行[排程 Workflow](/docs/workflows/scheduled-workflows)、Agent 排程或事件監聽器，請在伺服器開始監聽後呼叫 `await mastra.startWorkers()`。詳見[啟動背景工作程序](/docs/server/server-adapters#start-background-workers)。

## 保護原始路由 {/* #protecting-raw-routes */}

如需由 Mastra 管理身份驗證，以及 `requiresAuth` 等路由中繼資料，建議使用 [`registerApiRoute()`](/reference/server/register-api-route)。對於直接註冊在應用程式上的原生 Fastify 路由，請使用 `createAuthMiddleware()`：

```typescript title="server.ts"
import Fastify from 'fastify'
import { createAuthMiddleware, MastraServer } from '@mastra/fastify'
import { mastra } from './mastra'

const app = Fastify()
const server = new MastraServer({ app, mastra })

await server.init()

app.get('/custom/protected', { preHandler: createAuthMiddleware({ mastra }) }, async request => {
  const user = request.requestContext.get('user')
  return { user }
})

app.get(
  '/custom/public',
  { preHandler: createAuthMiddleware({ mastra, requiresAuth: false }) },
  async () => {
    return { ok: true }
  },
)
```
