# Koa 適配器

`@mastra/koa` 套件提供在 [Koa](https://koajs.com) 中運行 Mastra 的伺服器適配器。關於建構函數選項、初始化流程等適配器的一般概念，請參閱[伺服器適配器](/docs/server/server-adapters)。

## 安裝 {/* #installation */}

安裝 Koa 適配器和 Koa 框架：

```bash npm2yarn
npm install @mastra/koa@latest koa koa-bodyparser
```

## 使用例子 {/* #usage-example */}

```typescript title="server.ts"
import Koa from 'koa'
import bodyParser from 'koa-bodyparser'
import { MastraServer } from '@mastra/koa'
import { mastra } from './mastra'

const app = new Koa()
app.use(bodyParser())

const server = new MastraServer({ app, mastra })

await server.init()

app.listen(3000, () => {
  console.log('Server running on http://localhost:3000')
})
```

`init()` 不會啟動 Mastra 的背景工作程序。要運行[排程 Workflow](/docs/workflows/scheduled-workflows)、Agent 排程或事件監聽器，請在伺服器開始監聽後調用 `await mastra.startWorkers()`。詳情請參閱[啟動背景工作程序](/docs/server/server-adapters#start-background-workers)。

## 錯誤處理 {/* #error-handling */}

Koa 適配器遵循 Koa 的標準錯誤處理方式：路由處理程式拋出的錯誤會沿 Koa 中介軟件鏈向上傳遞。你可以使用一般的 Koa 錯誤處理中介軟件：

```typescript title="server.ts"
const app = new Koa()
app.use(bodyParser())

// Your error middleware catches errors from Mastra route handlers
app.use(async (ctx, next) => {
  try {
    await next()
  } catch (err) {
    ctx.status = err.status || 500
    ctx.body = { error: err.message }
    // Log, report to Sentry, etc.
  }
})

const server = new MastraServer({ app, mastra })
await server.init()
```

適配器亦支援 [`server.onError`](/reference/configuration#serveronerror) 掛鈎。設定後，系統會在錯誤傳遞至中介軟件前調用該掛鈎，並直接使用其返回的回應：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'

const mastra = new Mastra({
  server: {
    onError: (err, c) => {
      console.error('Unhandled error:', err)
      return c.json({ error: err.message }, 500)
    },
  },
})
```

調用 `init()` 時，系統亦會註冊全域錯誤處理中介軟件作為最後一道防線。按照 Koa 的標準慣例，到達該中介軟件的錯誤會透過 `ctx.app.emit('error', err, ctx)` 發出。對於路由處理程式已記錄的客戶端錯誤（4xx）及 `501` 錯誤，只有在你自行註冊 `error` 監聽器時，才會將其作為 `error` 事件發出；否則只會通知 `errorMonitor` 監聽器。

## 保護原始路由 {/* #protecting-raw-routes */}

需要 Mastra 管理的身份驗證及 `requiresAuth` 等路由元資料時，優先使用 [`registerApiRoute()`](/reference/server/register-api-route)。對於直接掛載到應用程式的原生 Koa 路由，請使用 `createAuthMiddleware()`：

```typescript title="server.ts"
import Koa from 'koa'
import { createAuthMiddleware, MastraServer } from '@mastra/koa'
import { mastra } from './mastra'

const app = new Koa()
const server = new MastraServer({ app, mastra })

await server.init()

app.use(createAuthMiddleware({ mastra }))
app.use(async ctx => {
  if (ctx.path !== '/custom/protected') return

  const user = ctx.state.requestContext.get('user')
  ctx.body = { user }
})
```

## 手動初始化 {/* #manual-initialization */}

如需自訂中介軟件順序，請分別調用各個方法，而非使用 `init()`。詳情請參閱[手動初始化](/docs/server/server-adapters#manual-initialization)。
