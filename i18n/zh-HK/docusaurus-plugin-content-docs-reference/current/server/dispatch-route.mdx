# 調度路由()

這`dispatchRoute()`函數作為呼叫使用者在進程中運行伺服器路由。它期望 Mastra 伺服器身份驗證已經驗證了請求上下文，然後將伺服器適配器應用於該路由的 HTTP 請求：您的身份驗證提供者的`authorize`, `authorizeUser`， 和`rules`、架構驗證、RBAC 權限和細粒度授權 (FGA)。它絕不允許 HTTP 請求拒絕的呼叫。

使用它在內建路由（包括流路由）之上建立另一個傳輸。對於從Tool呼叫的 JSON 路由，[`invokeRoute()`](/reference/server/invoke-route) is the smaller API.

## 使用範例 {/* #usage-example */}

```typescript title="src/server/run-tool.ts"
import type { Mastra } from '@mastra/core/mastra'
import type { RequestContext } from '@mastra/core/request-context'
import { SERVER_ROUTES, dispatchRoute } from '@mastra/server/server-adapter'

const executeTool = SERVER_ROUTES.find(
  route => route.method === 'POST' && route.path === '/tools/:toolId/execute',
)!

export async function runWeatherTool(
  mastra: Mastra,
  requestContext: RequestContext,
  request: Request,
) {
  const outcome = await dispatchRoute(
    executeTool,
    { pathParams: { toolId: 'weather' }, body: { data: { city: 'Paris' } } },
    { mastra, requestContext, abortSignal: request.signal, request },
  )
  if (!outcome.ok) throw new Error(`Tool route failed with status ${outcome.status}`)
  return outcome.result
}
```

## 行為 {/* #behavior */}

* **不會重新運行身份驗證。**&#x8A2D;定伺服器或 Studio 驗證時，請求上下文必須已包含已解析的使用者 Mastra 伺服器身份驗證。否則`dispatchRoute()` returns `401`, unless the route's path is public.
* **授權掛鉤查看 HTTP 路徑。** `authorize()`, `authorizeUser()`, and `rules` receive the route's method and the path it's served under: the adapter's prefix plus the route path with path parameters filled in.
* **服務適配器的路徑和檢查適用。**&#x6BCF;個適配器將自己綁定到它創建的請求上下文，在上下文的條目之外，因此Agent和Tool代碼無法讀取它，因此使用該請求上下文分派的路由會獲取該適配器的前綴並覆蓋，即使另一個適配器在相同的前綴下提供相同的 Mastra 實例也是如此。在請求之外，為 Mastra 實例提供服務的唯一適配器（或`context.routePrefix`) is used. If the adapter can't be told, or no adapter serves `routePrefix`, `dispatchRoute()` returns `401` for a caller without a user and throws otherwise. It never picks one of several adapters on its own.
* **像 URL 一樣檢查路徑參數。**&#x7F3A;失的、空的、非字串的，`.`, or `..` value returns `400`. An optional `:param?` can be left out.
* **路徑參數獲勝。**&#x8207;路徑參數同名的正文或查詢欄位將被覆寫，因此授權和處理程序將作用於路徑中指定的資源。
* **受保護的模式不會開啟其他路徑。**&#x914D;置身份驗證後，路由需要用戶，除非其路徑被聲明為公共，即使它位於您的外部`protected` patterns.
* **適配器覆蓋適用。**&#x4E00;個`checkRoutePermission()` override on the serving `MastraServer` subclass also runs for dispatched routes.
* **`authorizeUser()`收到替代請求。**&#x5B83;接收對調度路由的路徑和方法的請求，其中包含以下標頭`context.request` and no body.
* **伺服器上下文不能來自輸入。** `request`, `routePrefix`, `registeredTools`, and `taskStore` reach the handler only from `context`, never from body or query fields with those names.

## 客製化適配器 {/* #custom-adapters */}

可擴充的適配器`MastraServer` tell `dispatchRoute()` where they serve routes. An adapter that doesn't must register itself, and bind the returned handle to each request context it creates:

```typescript
import { bindDispatchAdapter, registerDispatchAdapter } from '@mastra/server/server-adapter'

const handle = registerDispatchAdapter(mastra, { prefix: '/api' })

// For each request:
bindDispatchAdapter(requestContext, handle)
```

不擴充的適配器`MastraServer` can run the route permission and FGA checks of the built-in adapters with `authorizeRoute()`, after authenticating the request and validating its parameters. It resolves to `null` when the call is allowed, or to a `403` error to send back. `checkRouteRBAC()` runs the permission check alone.

```typescript
import { authorizeRoute } from '@mastra/server/server-adapter'

const denied = await authorizeRoute(mastra, route, params, requestContext)
if (denied)
  return Response.json({ error: denied.error, message: denied.message }, { status: denied.status })
```
