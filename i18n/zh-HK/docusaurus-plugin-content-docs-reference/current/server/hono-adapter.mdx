# Hono 適配器

`@mastra/hono` 套件提供在 [Hono](https://hono.dev) 上運行 Mastra 的伺服器適配器。有關建構函式選項、初始化流程等通用概念，請參閱[伺服器適配器](/docs/server/server-adapters)。

## 安裝 {/* #installation */}

安裝 Hono 適配器及 Hono 框架：

```bash npm2yarn
npm install @mastra/hono@latest hono
```

## 使用範例 {/* #usage-example */}

```typescript title="server.ts"
import { Hono } from 'hono'
import { HonoBindings, HonoVariables, MastraServer } from '@mastra/hono'
import { mastra } from './mastra'

const app = new Hono<{ Bindings: HonoBindings; Variables: HonoVariables }>()
const server = new MastraServer({ app, mastra })

await server.init()

export default app
```

`init()` 不會啟動 Mastra 的背景工作程序。如需運行[排程 Workflow](/docs/workflows/scheduled-workflows)、Agent 排程或事件監聽器，請在伺服器開始監聽後呼叫 `await mastra.startWorkers()`。詳見[啟動背景工作程序](/docs/server/server-adapters#start-background-workers)。

## 新增自訂路由 {/* #adding-custom-routes */}
直接在 Hono 應用程式中新增路由：

```typescript title="server.ts"
import { Hono } from 'hono'
import { HonoBindings, HonoVariables, MastraServer } from '@mastra/hono'

const app = new Hono<{ Bindings: HonoBindings; Variables: HonoVariables }>()
const server = new MastraServer({ app, mastra })

// Before init - runs before Mastra middleware
app.get('/early-health', c => c.json({ status: 'ok' }))

await server.init()

// After init - has access to Mastra context
app.get('/custom', c => {
  const mastraInstance = c.get('mastra')
  return c.json({ agents: Object.keys(mastraInstance.listAgents()) })
})
```

:::tip

在 `init()` 之前新增的路由運行時沒有 Mastra 上下文。如需存取 Mastra 實例及請求上下文，請在 `init()` 之後新增路由。

:::

如需由 Mastra 管理身份驗證，以及 `requiresAuth` 等路由中繼資料，建議使用 [`registerApiRoute()`](/reference/server/register-api-route)。對於直接掛載在 `app` 上的原生 Hono 路由，請使用 `createAuthMiddleware()`：

```typescript title="server.ts"
import { Hono } from 'hono'
import { createAuthMiddleware, HonoBindings, HonoVariables, MastraServer } from '@mastra/hono'
import { mastra } from './mastra'

const app = new Hono<{ Bindings: HonoBindings; Variables: HonoVariables }>()
const server = new MastraServer({ app, mastra })

await server.init()

app.get('/custom/protected', createAuthMiddleware({ mastra }), c => {
  const user = c.get('requestContext').get('user')
  return c.json({ user })
})

app.get('/custom/public', createAuthMiddleware({ mastra, requiresAuth: false }), c => {
  return c.json({ ok: true })
})
```

## 存取上下文 {/* #accessing-context */}

在 Hono 中介軟體及路由處理函式中，透過 `c.get()` 存取 Mastra 上下文：

```typescript
app.get('/custom', async c => {
  const mastra = c.get('mastra')
  const requestContext = c.get('requestContext')
  const abortSignal = c.get('abortSignal')

  const agent = mastra.getAgent('myAgent')
  return c.json({ agent: agent.name })
})
```

可用的上下文鍵：

| 鍵 | 說明 |
| - | - |
|`mastra` | Mastra 實例 |
| `requestContext` | 請求上下文映射 |
| `abortSignal` | 請求取消訊號 |
| `registeredTools` | 向適配器註冊的 Tool |
| `taskStore` | A2A 操作的任務儲存區 |
| `customRouteAuthConfig` | 個別路由的身份驗證覆寫設定 |
| `user` | 已驗證身份的用戶（如已設定身份驗證） |

## 新增中介軟體 {/* #adding-middleware */}

在 `init()` 之前透過 `app.use()` 新增 Hono 中介軟體，讓它在每個請求中運行。此時 Mastra 上下文尚未可用：

```typescript title="server.ts"
import { Hono } from 'hono'
import { HonoBindings, HonoVariables, MastraServer } from '@mastra/hono'

const app = new Hono<{ Bindings: HonoBindings; Variables: HonoVariables }>()

// Runs on every request, before Mastra context exists
app.use('*', async (c, next) => {
  console.log(`${c.req.method} ${c.req.url}`)
  await next()
})

const server = new MastraServer({ app, mastra })
await server.init()
```

在 `init()` 之後新增的中介軟體不會在 Mastra 路由上運行。Hono 按註冊次序分派處理函式，因此在路由之後註冊的中介軟體只適用於其後新增的路由。

如需在 Mastra 路由上運行可存取 Mastra 上下文的中介軟體，請在 Mastra 設定中使用 [`server.middleware`](/docs/server/middleware)。適配器會在 `init()` 期間、建立上下文之後及註冊任何路由之前，註冊這些中介軟體。對於透過 `requiresAuth: false` 宣告為公開的路由，這些處理函式會略過，因此不會阻擋 Studio 登入路由等端點：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'

export const mastra = new Mastra({
  server: {
    middleware: [
      async (c, next) => {
        c.get('requestContext').set('locale', c.req.header('accept-language') ?? 'en')
        await next()
      },
    ],
  },
})
```

## 手動初始化 {/* #manual-initialization */}

如需自訂中介軟體次序，請分別呼叫各個方法，而不要呼叫 `init()`。詳見[手動初始化](/docs/server/server-adapters#manual-initialization)。
