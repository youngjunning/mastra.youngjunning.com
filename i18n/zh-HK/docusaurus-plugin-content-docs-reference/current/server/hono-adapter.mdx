# 榮譽適配器

這`@mastra/hono`軟體包提供了一個伺服器適配器，用於運行 Mastra[霍諾](https://hono.dev)。有關一般適配器概念（建構函數選項、初始化流程等），請參閱[伺服器適配器](/docs/server/server-adapters).

## 安裝 {/* #installation */}

安裝Hono適配器和Hono框架：

```bash npm2yarn
npm install @mastra/hono@latest hono
```

## 使用範例 {/* #usage-example */}

```typescript title="server.ts"
import { Hono } from 'hono'
import { HonoBindings, HonoVariables, MastraServer } from '@mastra/hono'
import { mastra } from './mastra'

const app = new Hono<{ Bindings: HonoBindings; Variables: HonoVariables }>()
const server = new MastraServer({ app, mastra })

await server.init()

export default app
```

`init()`不會啟動 Mastra 的後台工作人員。運行[scheduled workflows](/docs/workflows/scheduled-workflows), agent schedules, or event listeners, call `await mastra.startWorkers()` after the server starts listening. See [Start background workers](/docs/server/server-adapters#start-background-workers).

## 新增自訂路線 {/* #adding-custom-routes */}



```typescript title="server.ts"
import { Hono } from 'hono'
import { HonoBindings, HonoVariables, MastraServer } from '@mastra/hono'

const app = new Hono<{ Bindings: HonoBindings; Variables: HonoVariables }>()
const server = new MastraServer({ app, mastra })

// Before init - runs before Mastra middleware
app.get('/early-health', c => c.json({ status: 'ok' }))

await server.init()

// After init - has access to Mastra context
app.get('/custom', c => {
  const mastraInstance = c.get('mastra')
  return c.json({ agents: Object.keys(mastraInstance.listAgents()) })
})
```

：：：提示

之前新增的路線`init()` run without Mastra context. Add routes after `init()` to access the Mastra instance and request context.

:::

當您需要 Mastra 管理的身份驗證和路由元資料時，例如`requiresAuth`, prefer [`registerApiRoute()`](/reference/server/register-api-route). For raw Hono routes mounted directly on `app`, use `createAuthMiddleware()`:

```typescript title="server.ts"
import { Hono } from 'hono'
import { createAuthMiddleware, HonoBindings, HonoVariables, MastraServer } from '@mastra/hono'
import { mastra } from './mastra'

const app = new Hono<{ Bindings: HonoBindings; Variables: HonoVariables }>()
const server = new MastraServer({ app, mastra })

await server.init()

app.get('/custom/protected', createAuthMiddleware({ mastra }), c => {
  const user = c.get('requestContext').get('user')
  return c.json({ user })
})

app.get('/custom/public', createAuthMiddleware({ mastra, requiresAuth: false }), c => {
  return c.json({ ok: true })
})
```

## 存取上下文 {/* #accessing-context */}

在 Hono 中介軟體和路由處理程序中，透過以下方式存取 Mastra 上下文`c.get()`:

```typescript
app.get('/custom', async c => {
  const mastra = c.get('mastra')
  const requestContext = c.get('requestContext')
  const abortSignal = c.get('abortSignal')

  const agent = mastra.getAgent('myAgent')
  return c.json({ agent: agent.name })
})
```

可用的上下文鍵：

|關鍵|描述 |
| - | - |
|`mastra` | Mastra instance |
| `requestContext` | Request context map |
| `abortSignal` | Request cancellation signal |
| `registeredTools` | Tools registered with the adapter |
| `taskStore` | Task store for A2A operations |
| `customRouteAuthConfig` | Per-route auth overrides |
| `user` | Authenticated user (if auth configured) |

## 新增中介軟體 {/* #adding-middleware */}

新增 Hono 中介軟體`app.use()` before `init()` to run it on every request. Mastra context isn't available at that point:

```typescript title="server.ts"
import { Hono } from 'hono'
import { HonoBindings, HonoVariables, MastraServer } from '@mastra/hono'

const app = new Hono<{ Bindings: HonoBindings; Variables: HonoVariables }>()

// Runs on every request, before Mastra context exists
app.use('*', async (c, next) => {
  console.log(`${c.req.method} ${c.req.url}`)
  await next()
})

const server = new MastraServer({ app, mastra })
await server.init()
```

之後加入中間件`init()` never runs for Mastra's routes. Hono dispatches handlers in registration order, so middleware registered after the routes only applies to routes added later.

要在 Mastra 的路由上運行具有 Mastra 上下文的中間件，請使用[`server.middleware`](/docs/server/middleware) in the Mastra config. The adapter registers it during `init()`, after the context step and before any route. These handlers are skipped for routes declared public with `requiresAuth: false`, so they can't block endpoints such as the Studio sign-in routes:

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'

export const mastra = new Mastra({
  server: {
    middleware: [
      async (c, next) => {
        c.get('requestContext').set('locale', c.req.header('accept-language') ?? 'en')
        await next()
      },
    ],
  },
})
```
