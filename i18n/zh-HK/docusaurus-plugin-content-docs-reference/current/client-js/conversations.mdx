# OpenAI 回應 API 對話

OpenAI Responses API 對話式介面為您提供 Mastra Agents 的對話管理端作為回應 API。它提供了在 Mastra 中建立、檢索、刪除和檢查線程支援的對話的方法。

該 API 後續[OpenAI Responses API](/reference/client-js/responses). Stored Responses calls return `conversation_id`，在 Mastra 中，該值是原始內存`threadId`。使用`client.conversations`當您想要直接使用該線程時。

該 API 目前處於實驗階段。

## 與 OpenAI 響應的關係 {/* #relationship-to-openai-responses */}

使用 OpenAI Responses API 進行產生和延續：

```typescript
const response = await client.responses.create({
  agent_id: 'support-agent',
  input: 'Start a support thread',
  store: true,
})

console.log(response.conversation_id)
```

當您想要檢查或管理儲存的執行緒時，請使用對話 API：

```typescript
const conversation = await client.conversations.retrieve(response.conversation_id!)
const items = await client.conversations.items.list(response.conversation_id!)
```

## 使用範例 {/* #usage-example */}

```typescript
import { MastraClient } from '@mastra/client-js'

const client = new MastraClient({
  baseUrl: 'http://localhost:4111',
})

const conversation = await client.conversations.create({
  agent_id: 'support-agent',
})

console.log(conversation.id)
```

## 方法 {/* #methods */}

### 生命週期 {/* #lifecycle */}

#### `create(params)` {/* #createparams */}

為選定的Agent程式建立新的對話執行緒。

```typescript
const conversation = await client.conversations.create({
  agent_id: 'support-agent',
  title: 'Billing support',
})
```

**返回：** `Promise<Conversation>`.

#### `retrieve(conversationId, requestContext?)` {/* #retrieveconversationid-requestcontext */}

按線程 ID 檢索對話。

```typescript
const conversation = await client.conversations.retrieve('thread_123')

console.log(conversation.thread)
```

**返回：** `Promise<Conversation>`.

#### `delete(conversationId, requestContext?)` {/* #deleteconversationid-requestcontext */}

透過對話的線程 ID 刪除對話。

```typescript
const deleted = await client.conversations.delete('thread_123')

console.log(deleted.deleted)
```

**返回：** `Promise<ConversationDeleted>`.

### 專案 {/* #items */}

#### `items.list(conversationId, requestContext?)` {/* #itemslistconversationid-requestcontext */}

列出對話的儲存項目。

```typescript
const items = await client.conversations.items.list('thread_123')

console.log(items.data)
```

**返回：** `Promise<ConversationItemsPage>`.

## 回應形狀 {/* #response-shape */}

`create()`和`retrieve()` return a conversation object with:

* `id`：原始線程ID
* `object`： 總是`'conversation'`
* `thread`：儲存的線程記錄

`delete()`返回：

* `id`：原始線程ID
* `object`： 總是`'conversation.deleted'`
* `deleted`： 總是`true`

`items.list()`返回：

* `object`： 總是`'list'`
* `data`：對話項目，例如`message`, `function_call`, and `function_call_output`
* `first_id`：頁面中的第一個項目ID
* `last_id`：頁面中最後一個項目ID
* `has_more`: 目前總是`false`. `items.list()` returns up to 1000 items in a single response.
