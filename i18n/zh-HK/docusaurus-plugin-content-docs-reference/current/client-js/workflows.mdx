# WorkflowAPI

Workflow API 提供了與 Mastra 中的自動化Workflow互動並執行自動化Workflow的方法。

## 取得所有Workflow {/* #getting-all-workflows */}

檢索所有可用Workflow的清單：

```typescript
const workflows = await mastraClient.listWorkflows()
```

## 取得Workflow運行計數 {/* #getting-workflow-run-counts */}

檢索每個Workflow的計數`running` and [`suspended`](/docs/workflows/suspend-and-resume) runs in a single request. The counts are computed on the server and keyed by the workflow's registry key, the key used when registering the workflow in the Mastra config, which can differ from the workflow's own `id`:

```typescript
const runCounts = await mastraClient.listWorkflowRunCounts()
// { "cityWorkflow": { running: 2, suspended: 1 }, ... }
```

返回：`Record<string, { running: number; suspended: number }>`

伺服器可能會在請求之間將計數快取幾秒鐘。早於該端點的伺服器回應`404 Not Found`. Handle the error when the client can talk to older deployments.

## 使用特定的Workflow {/* #working-with-a-specific-workflow */}

透過 ID 取得特定Workflow的實例：

```typescript title="src/mastra/workflows/test-workflow.ts"
import { createWorkflow } from '@mastra/core/workflows'

export const testWorkflow = createWorkflow({
  id: 'city-workflow',
})
```

```typescript
const workflow = mastraClient.getWorkflow('city-workflow')
```

## Workflow方法 {/* #workflow-methods */}

### `details()` {/* #details */}

檢索有關Workflow的詳細資訊：

```typescript
const details = await workflow.details()
```

### `createRun()` {/* #createrun */}

建立一個新的Workflow運行實例：

```typescript
const run = await workflow.createRun()

// Or with an existing runId
const run = await workflow.createRun({ runId: 'existing-run-id' })

// Or with a resourceId to associate the run with a specific resource
const run = await workflow.createRun({
  runId: 'my-run-id',
  resourceId: 'user-123',
})
```

這`resourceId` parameter associates the workflow run with a specific resource (e.g., user ID, tenant ID). This value is persisted with the run and can be used for filtering and querying runs later.

### `startAsync()` {/* #startasync */}

啟動Workflow運行並等待其完成，返回完整結果作為Workflow輸出。

```typescript
const run = await workflow.createRun()

const result = await run.startAsync({
  inputData: {
    city: 'New York',
  },
})
```

您也可以透過`initialState` to set the starting values for the workflow's state:

```typescript
const result = await run.startAsync({
  inputData: {
    city: 'New York',
  },
  initialState: {
    count: 0,
    items: [],
  },
})
```

這`initialState` object should match the structure defined in the workflow's `stateSchema`. See [Workflow State](/docs/workflows/workflow-state) for more details.

若要將運行與特定資源關聯起來，請傳遞`resourceId` to `createRun()`:

```typescript
const run = await workflow.createRun({ resourceId: 'user-123' })

const result = await run.startAsync({
  inputData: {
    city: 'New York',
  },
})
```

### `start()` {/* #start */}

啟動Workflow運行，無需等待完成（即發即忘）。立即返回成功訊息。使用`runById()` on the workflow instance to check results later:

```typescript
const run = await workflow.createRun()

await run.start({
  inputData: {
    city: 'New York',
  },
})

// Poll for results later
const result = await workflow.runById(run.runId)
```

這對於您想要開始執行並稍後檢查結果的長時間運行的Workflow非常有用。

### `resumeAsync()` {/* #resumeasync */}

恢復暫停的Workflow步驟並等待完整結果：

```typescript
const run = await workflow.createRun({ runId: prevRunId })

const result = await run.resumeAsync({
  step: 'step-id',
  resumeData: { key: 'value' },
})
```

### `resume()` {/* #resume */}

恢復掛起的Workflow步驟而不等待完成：

```typescript
const run = await workflow.createRun({ runId: prevRunId })

await run.resume({
  step: 'step-id',
  resumeData: { key: 'value' },
})
```

當一個[`.foreach()`](/reference/workflows/workflow-methods/foreach) step suspends across multiple iterations, pass `forEachIndex` (zero-based. `0` targets the first iteration) to resume one iteration at a time. Iterations you don't target remain suspended.

```typescript
await run.resume({
  step: 'approve',
  resumeData: { ok: true },
  forEachIndex: 1, // resumes the second iteration
})
```

`forEachIndex`也得到了支持`resumeAsync()` and `resumeStream()`.

### `cancel()` {/* #cancel */}

取消正在運作的Workflow：

```typescript
const run = await workflow.createRun({ runId: existingRunId })

const result = await run.cancel()
// Returns: { message: 'Workflow run canceled' }
```

此方法停止任何正在運行的步驟並阻止執行後續步驟。檢查的步驟`abortSignal` parameter can respond to cancellation by cleaning up resources (timeouts, network requests, etc.).

請參閱[Run.cancel()](/reference/workflows/run-methods/cancel) reference for detailed information about how cancellation works and how to write steps that respond to cancellation.

### `stream()` {/* #stream */}

串流Workflow執行以實現即時更新：

```typescript
const run = await workflow.createRun()

const stream = await run.stream({
  inputData: {
    city: 'New York',
  },
})

for await (const chunk of stream) {
  console.log(JSON.stringify(chunk, null, 2))
}
```

### `runById()` {/* #runbyid */}

取得Workflow運行的執行結果：

```typescript
const result = await workflow.runById(runId)

// Or with options for performance optimization:
const result = await workflow.runById(runId, {
  fields: ['status', 'result'], // Only fetch specific fields
  withNestedWorkflows: false, // Skip expensive nested workflow data
  requestContext: { userId: 'user-123' }, // Optional request context
})
```

## 動態Workflow {/* #dynamic-workflows */}

:::測試版

在 API 穩定之前，可能會在沒有重大版本更新的情況下發生重大變更。

:::

動態Workflow是以 JSON 表示的Workflow定義。伺服器保留每個定義並將其註冊為可運行的Workflow。看[Dynamic workflows](/docs/workflows/dynamic-workflows) for the definition format.

### `listDynamicWorkflows()` {/* #listdynamicworkflows */}

列出動態Workflow定義，可選擇依下列條件篩選`status` (`'active' | 'archived'`) and `authorId`:

```typescript
const { definitions, total } = await mastraClient.listDynamicWorkflows({
  status: 'active',
})
```

### `upsertDynamicWorkflow()` {/* #upsertdynamicworkflow */}

建立或取代動態Workflow定義。伺服器驗證定義，保留它，並即時註冊它以供執行：

```typescript
const stored = await mastraClient.upsertDynamicWorkflow({
  id: 'greeting-workflow',
  description: 'Returns a greeting for the supplied name',
  inputSchema: {
    type: 'object',
    properties: { name: { type: 'string' } },
    required: ['name'],
  },
  outputSchema: {
    type: 'object',
    properties: { message: { type: 'string' } },
    required: ['message'],
  },
  graph: [
    {
      type: 'mapping',
      id: 'create-greeting',
      mapConfig: JSON.stringify({
        message: { template: 'Hello, ${initData.name}!' },
      }),
    },
  ],
})
```

當根定義嵌套尚不存在的幫助程式Workflow時，將它們在相同請求中傳遞`dependencies`. The server validates and registers the bundle as a unit and echoes the helper ids back as `dependencyIds`:

```typescript
const stored = await mastraClient.upsertDynamicWorkflow({
  id: 'root-workflow',
  // ...schemas and graph referencing 'helper-workflow'...
  dependencies: [helperDefinition],
})

console.log(stored.dependencyIds) // ['helper-workflow']
```

### `getDynamicWorkflow()` {/* #getdynamicworkflow */}

取得用於定義管理的動態Workflow實例。若要執行動態Workflow，請使用`getWorkflow(id).createRun()` like any other workflow:

```typescript
const dynamicWorkflow = mastraClient.getDynamicWorkflow('greeting-workflow')
```

### `dynamicWorkflow.details()` {/* #dynamicworkflowdetails */}

檢索持久定義，包括架構、圖表、狀態和時間戳記：

```typescript
const definition = await dynamicWorkflow.details()
```

### `dynamicWorkflow.delete()` {/* #dynamicworkflowdelete */}

刪除儲存的定義並取消註冊即時Workflow：

```typescript
await dynamicWorkflow.delete()
```

### 執行動態Workflow {/* #executing-a-dynamic-workflow */}

註冊後，動態Workflow將透過普通Workflow API 運作：

```typescript
const workflow = mastraClient.getWorkflow('greeting-workflow')
const run = await workflow.createRun()
const result = await run.startAsync({ inputData: { name: 'Ada' } })
```

## 時間表 {/* #schedules */}

時間表透過程式碼在程式碼中聲明`schedule` field on `createWorkflow`. The client SDK exposes read and operational methods for managing workflow schedules at runtime. See [Scheduled workflows](/docs/workflows/scheduled-workflows).

### `createSchedule()` {/* #createschedule */}

透過傳遞來創建Workflow計劃`workflowId`.

```typescript
const schedule = await mastraClient.createSchedule({
  workflowId: 'daily-report',
  cron: '0 9 * * *',
  inputData: { reportType: 'summary' },
})
```

### `listSchedules()` {/* #listschedules */}

列出Workflow計劃，可選擇依Workflow ID 或狀態進行篩選。

```typescript
const schedules = await mastraClient.listSchedules({
  workflowId: 'daily-report',
  status: 'active',
})
```

### `getSchedule()` {/* #getschedule */}

按 ID 取得單一Workflow計畫。

```typescript
const schedule = await mastraClient.getSchedule('daily-report')
```

### `updateSchedule()` {/* #updateschedule */}

更新Workflow計劃。

```typescript
const updated = await mastraClient.updateSchedule('daily-report', {
  cron: '0 10 * * *',
  inputData: { reportType: 'summary' },
})
```

### `deleteSchedule()` {/* #deleteschedule */}

刪除Workflow計劃。

```typescript
await mastraClient.deleteSchedule('daily-report')
```

### `runSchedule()` {/* #runschedule */}

立即觸發Workflow計劃一次，而不更改其 cron 節奏。

```typescript
const run = await mastraClient.runSchedule('daily-report')
```

### `pauseSchedule()` {/* #pauseschedule */}

暫停計劃，以便調度程序停止觸發它。返回更新後的時間表。

```typescript
await mastraClient.pauseSchedule('daily-report')
```

### `resumeSchedule()` {/* #resumeschedule */}

恢復暫停的計劃。從現在開始重新計算下一次觸發時間，因此長時間暫停的計畫不會觸發積壓。返回更新後的時間表。

```typescript
await mastraClient.resumeSchedule('daily-report')
```

### `listScheduleTriggers()` {/* #listscheduletriggers */}

列出Workflow計畫的觸發器歷史記錄，包括每次觸發的聯接運行摘要。

```typescript
const { triggers } = await mastraClient.listScheduleTriggers('daily-report', {
  limit: 50,
})
```
