# 日誌 API

日誌 API 可讀取及查詢 Mastra 的系統日誌和偵錯資訊。

## 取得日誌 {/* #getting-logs */}

取得系統日誌時，可按需要指定篩選條件：

```typescript
const logs = await mastraClient.listLogs({
  transportId: 'transport-1',
})
```

## 取得某次執行的日誌 {/* #getting-logs-for-a-specific-run */}

查閱指定執行的日誌：

```typescript
const runLogs = await mastraClient.getLogForRun({
  runId: 'run-1',
  transportId: 'transport-1',
})
```
