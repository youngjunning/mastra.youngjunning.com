# OpenAI 回應 API

這個與 OpenAI 相容、Agent支援的介面允許您使用 Mastra Agents 作為回應 API。它提供了透過 Mastra Agent程式創建、檢索、串流和刪除回應的方法。

這些路由是基於 Mastra Agent、記憶體和儲存的Agent程式支援的適配器。使用`agent_id` to select the Mastra agent that should handle the request. You can pass `model`覆寫單一請求的Agent配置模型，或忽略它以使用Agent上已配置的模型。

儲存的響應也會返回`conversation_id`. In Mastra, this is the raw memory `threadId`.

該 API 目前處於實驗階段。

## 使用範例 {/* #usage-example */}

```typescript
import { MastraClient } from '@mastra/client-js'

const client = new MastraClient({
  baseUrl: 'http://localhost:4111',
})

const response = await client.responses.create({
  agent_id: 'support-agent',
  input: 'Summarize this ticket',
  store: true,
})

console.log(response.output_text)
```

## 方法 {/* #methods */}

### 生命週期 {/* #lifecycle */}

#### `create(params)` {/* #createparams */}

建立響應。

```typescript
const response = await client.responses.create({
  agent_id: 'support-agent',
  input: 'Summarize this ticket',
})
```

**返回：** `Promise<ResponsesResponse>` when `stream` is omitted or `false`.

什麼時候`stream: true`, `create()` returns an async iterable of SSE-style event payloads:

```typescript
const stream = await client.responses.create({
  agent_id: 'support-agent',
  input: 'Summarize this ticket',
  stream: true,
})

for await (const event of stream) {
  if (event.type === 'response.output_text.delta') {
    process.stdout.write(event.delta)
  }
}
```

串流響應還可以包括Tool事件。Tool調用流的使用`response.output_item.added`, `response.function_call_arguments.delta`, `response.function_call_arguments.done`, and `response.output_item.done` events. Tool results appear as `function_call_output` items with `<toolCallId>:output` IDs.

**返回：** `Promise<ResponsesStream>`.

#### `retrieve(responseId, requestContext?)` {/* #retrieveresponseid-requestcontext */}

檢索儲存的回應。

```typescript
const response = await client.responses.retrieve('msg_123')
```

**返回：** `Promise<ResponsesResponse>`.

#### `delete(responseId, requestContext?)` {/* #deleteresponseid-requestcontext */}

刪除儲存的回應。

```typescript
const deleted = await client.responses.delete('msg_123')
```

**返回：** `Promise<{ id: string; object: "response"; deleted: true }>`

#### `stream(params)` {/* #streamparams */}

建立串流響應。

```typescript
const stream = await client.responses.stream({
  agent_id: 'support-agent',
  input: 'Say hello',
})

for await (const event of stream) {
  console.log(event.type)
}
```

**返回：** `Promise<ResponsesStream>`.

## 儲存的回覆和對話 {/* #stored-responses-and-conversations */}

儲存的回應包括`response.id` and `conversation_id`.

* `response.id`是響應 ID。對於儲存的Agent支援的回應，這是持久的助理訊息 ID。
* `conversation_id`是原始 Mastra 線程 ID。

使用`previous_response_id` when you want to continue from a previous stored response. Use `conversation_id` when you want to target a known thread directly.

```typescript
const first = await client.responses.create({
  agent_id: 'support-agent',
  input: 'Start a support thread',
  store: true,
})

const second = await client.responses.create({
  agent_id: 'support-agent',
  conversation_id: first.conversation_id!,
  input: 'Add a follow-up to the same thread',
  store: true,
})
```

使用[`client.conversations`](/reference/client-js/conversations) when you want to create, retrieve, delete, or inspect the underlying OpenAI Responses API conversation directly.

## 函數呼叫（Tool） {/* #function-calling-tools */}

`response.tools`包含可用於請求的已配置函數定義。

如果模型呼叫函數，則該活動包含在`response.output` as `function_call` and `function_call_output` items alongside the final assistant `message`.

什麼時候`stream: true`, function calls are also emitted as Responses stream events. Read `response.function_call_arguments.delta` events for partial argument chunks and prefer `response.function_call_arguments.done` for the finalized arguments payload and tool name. Read `response.output_item.done` events for completed `function_call` and `function_call_output` items. Tool output items use `<toolCallId>:output` IDs.

## 結構化輸出 {/* #structured-output */}

使用`text.format` when you want JSON output.

* `json_object`啟用 JSON 模式。
* `json_schema`啟用模式約束的結構化輸出。

兩種格式都會在助理訊息內容中傳回 JSON。使用`json_schema` when you need strict schema enforcement. Use `json_object` when you only need valid JSON output.

```typescript
const response = await client.responses.create({
  agent_id: 'support-agent',
  input: 'Return a structured support ticket summary.',
  text: {
    format: {
      type: 'json_schema',
      name: 'ticket_summary',
      schema: {
        type: 'object',
        properties: {
          summary: { type: 'string' },
          priority: { type: 'string' },
        },
        required: ['summary', 'priority'],
        additionalProperties: false,
      },
    },
  },
})
```

## 提供者支援的請求 {/* #provider-backed-requests */}

使用`providerOptions` when you need provider-specific options that Mastra doesn't normalize at the Responses layer.

```typescript
const response = await client.responses.create({
  agent_id: 'support-agent',
  input: 'Continue this exchange',
  providerOptions: {
    openai: {
      previousResponseId: 'resp_123',
    },
  },
})
```

## 回應形狀 {/* #response-shape */}

傳回的響應對象包括：

* `id`：回應ID
* `output`：輸出助手等物品`message`, `function_call`, and `function_call_output`
* `output_text`：連接輔助文字輸出的便利 getter
* `tools`：為請求配置的Tool定義
* `conversation_id`：儲存回應的原始線程 ID
* `text`：請求的文字輸出格式（如果提供）
