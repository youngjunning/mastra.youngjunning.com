# 限制

文字限制以標記計數。計數是估計值，因此請將數字視為近似值。

：：：阿爾法

知識處於阿爾法階段。其 API 可能會在不同版本之間變更。

:::

|項目 |限制|
| - | - |
|備註文字| 250 個代幣 |
|頁面描述| 100 個代幣 |
|頁面嵌套| 10 個層級 |
|一次行動頁面，計算行動頁面下的所有內容 | 500 | 500
|`knowledge_search` results, and notes and child pages per `knowledge_read` | 10 by default, up to 50 |
| Page body or `match`結果每`knowledge_read`|預設1,000個代幣，至少100 |
|註釋以及提及該頁面的註釋，保持完整`knowledge_read`|每個列表 1,000 個代幣 |
|`knowledge_list`條目 |預設50個，最多100個，預設1000個左右 |
|`knowledge_list`深度|預設1級，最多3級 |
|每頁嵌入區塊，用於按含義搜尋 | 100 個，每個約 2,000 個代幣 |
|每回合固定上下文 |預設 500 個代幣，無上限 |
|每輪固定頁面 |預設 20 |
|固定列表深度 |預設1級，最多3級 |
|每個固定清單的頁數|其代幣份額最多可持有 1,000 個 |

超出限制的寫入失敗，並且模型將錯誤作為Tool結果。Tool架構不顯示令牌限制，因為架構無法計算令牌。

頁面主體沒有令牌限制。`knowledge_read` returns a long body in parts, and an agent [edits it one part at a time](/reference/knowledge/knowledge-tools#knowledge_page) by line `range`. Pinned page bodies are cut to fit the pinned-context budget. See [what a run receives](/docs/knowledge/pinned-context#what-a-run-receives).

對於一次嵌入來說太長的頁面會作為重疊塊嵌入，在段落之間和標題之前進行剪切。每個區塊都以頁面的名稱和描述開頭。搜尋返回頁面一次，並按其最佳區塊排名。超過 100 個區塊後，正文的其餘部分只能透過關鍵字找到。重寫頁面會取代其區塊，刪除頁面則會刪除它們。

不符合預算的固定頁面的處理方式如下：

* 固定在配置中的頁面永遠不會被刪除。當他們單獨超出預算時，每個人都會獲得平等的份額並被削減。
* 剪切的固定頁面結尾為`[truncated — knowledge_read for the rest]`.
* 由不適合的Agent固定的頁面將在一行中命名，最多十個，然後進行計數：`Also pinned (open with knowledge_read): Refund Policy, …and 3 more`.

固定列表算作一個 pin，並共享代幣預算。不適合的頁面一次填充一個級別，並且每個頁面仍列印在其父頁面下。當頁面被省略時，它以`…and 4 more; knowledge_list from: "site:mastra"`, or `…and more` without a count when there are more pages than it fetched. Pinning a listing again sets its new depth, and a stored listing that repeats one from config is delivered once.

當範圍聲明更多內容時，Knowledge 會在啟動時記錄警告`pinnedContext` pages than `maxPins`, or so many that each would get under 50 tokens.

更改讀取上限`tools: { read: { maxTokens } }`. See [`tools`](/reference/knowledge/knowledge-class#constructor-options). Change the pin limits with `pinnedContext: { maxPins, maxTokens }` on `Knowledge`.
