# buildBasePrompt()

`buildBasePrompt()` 為 Coding Agent 建立共用的基本系統提示詞，當中包含令 Agent 成為出色編程助手的行為指引。它接收描述目前環境（項目、平台、Git 分支、模式和模型）的 `PromptContext`，並以字串形式傳回提示詞。

產品相關文字可透過 `productName`、`coAuthorName` 和 `coAuthorEmail` 參數設定，因此毋須另行分叉程式碼，也能更改提示詞中的品牌名稱及提交紀錄的共同作者註記。共同作者的預設名稱及電郵地址分別為 `"mastra-platform[bot]"` 和 `"284800079+mastra-platform[bot]@users.noreply.github.com"`。

建立 Agent 在執行時使用的指引時，可將此函式與 [`createCodingAgent()`](/reference/coding-agent/create-coding-agent) 一併使用。

## 使用範例 {/* #usage-example */}

根據 `PromptContext` 建立基本提示詞：

```typescript title="src/mastra/prompt.ts"
import { buildBasePrompt } from '@mastra/core/coding-agent'

const prompt = buildBasePrompt({
  projectPath: process.cwd(),
  projectName: 'my-app',
  gitBranch: 'main',
  platform: process.platform,
  date: new Date().toDateString(),
  mode: 'build',
  modelId: '__GATEWAY_OPENAI_MODEL_BASE__',
  toolGuidance: '',
})
```

如需更改提示詞中的品牌名稱，請傳入產品名稱及共同作者欄位：

```typescript
const prompt = buildBasePrompt({
  // ...environment fields
  productName: 'Acme Coder',
  coAuthorName: 'Acme Bot',
  coAuthorEmail: 'bot@acme.dev',
})
```
