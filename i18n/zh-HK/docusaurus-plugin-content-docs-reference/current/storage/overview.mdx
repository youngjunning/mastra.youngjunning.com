# 貯存

Mastra 儲存體被組織成域。每個網域都擁有一組表或集合。根據您的適配器和配置，您可以使用所有網域或僅使用其中的子集。

## 儲存域 {/* #storage-domains */}

`MastraCompositeStore`可以路由以下域密鑰：

並非每個儲存適配器都實作每個網域。當適配器包匯出對應的網域類別時，複合儲存可讓您混合每個網域的適配器。

|網域 |描述 |
| - | - |
|`memory` | Conversation persistence: messages, threads, and resources (including working memory). |
| `workflows` | Workflow run snapshots used for suspend and resume. |
| `workflowDefinitions`|堅持[動態Workflow](/docs/workflows/dynamic-workflows)定義（測試版）。在啟動時載入並即時註冊。 |
|`scores`|評估運行的評估分數記錄。 |
|`observability`|Observability導出器和 Studio 使用的追蹤和跨度。 |
|`datasets`|實驗使用的資料集記錄、版本化專案和資料集版本。 |
|`experiments`|實驗運行和每個項目的實驗結果。 |
|`agents`|儲存的Agent定義及其版本，供 Mastra 編輯器使用。 |
|`promptBlocks`|儲存的提示區塊及其版本，供 Mastra 編輯器使用。 |
|`scorerDefinitions`|儲存的記分器定義，供 Mastra 編輯器使用。 |
|`mcpClients`|儲存的 MCP 用戶端配置，供 Mastra 編輯器使用。 |
|`mcpServers`|儲存的 MCP 伺服器配置，供 Mastra 編輯器使用。 |
|`workspaces`|儲存的Workspace配置，供 Mastra 編輯器使用。 |
|`skills`|儲存的技能及其版本，供 Mastra 編輯器使用。 |
|`favorites`|每個使用者對儲存實體的收藏夾。 |
|`blobs`|由 SHA-256 雜湊鍵控的內容可尋址 blob。儲存用於技能版本控制的文件內容。 |
|`backgroundTasks`|後台任務狀態：建立、狀態更新與清理。 |
|`schedules`|由調度程序輪詢以觸發Workflow和Agent運行的調度。 |
|`channels`|多平台整合的通道安裝和配置。 |
|`harness`|利用會話記錄。 |
|`toolProviderConnections`|使用者為Tool提供者連線指派的名稱。 |
|`notifications`|通知記錄。 |
|`threadState`|持久的每執行緒狀態，例如任務清單和目標。 |
|`knowledge`|知識圖節點與記錄（實驗）。 |

下面的模式定義涵蓋了記錄的內建資料庫支援的表`memory`, `workflows`, `scores`, and `observability`. Other domains, and non-database adapters, use implementation-specific storage structures.
