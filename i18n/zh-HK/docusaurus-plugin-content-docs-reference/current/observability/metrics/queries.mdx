# 指標查詢

指標查詢從可觀測性儲存領域讀取原始及彙總指標資料。Exporter 及儲存設定請參閱[指標概覽](/docs/observability/metrics/overview)；自動產生的指標名稱及標籤請參閱[自動指標參考](/reference/observability/metrics/automatic-metrics)。

## 存取方式 {/* #access */}

### 可觀測性儲存空間 {/* #observability-store */}

使用儲存域進行進程內查詢：

```typescript
const observability = await mastra.getStorage()?.getStore('observability')

if (!observability) {
  throw new Error('Observability storage is not configured')
}

const result = await observability.getMetricAggregate({
  name: ['mastra_agent_duration_ms'],
  aggregation: 'avg',
  filters: {
    timestamp: { start: new Date(Date.now() - 60 * 60 * 1000) },
  },
})
```

如儲存設定未提供可觀測性領域，`getStore('observability')` 會傳回 `undefined`。

### 用戶端 SDK {/* #client-sdk */}

`@mastra/client-js` 在 `MastraClient` 上提供分析及指標探索方法：

```typescript
import { MastraClient } from '@mastra/client-js'

const client = new MastraClient({
  baseUrl: 'http://localhost:4111',
})

const result = await client.getMetricAggregate({
  name: ['mastra_agent_duration_ms'],
  aggregation: 'avg',
})
```

用戶端不提供列出原始紀錄的 `listMetrics()` 方法。要列出原始指標紀錄，請使用可觀測性儲存空間或 `GET /api/observability/metrics` 路由。

## 共用值 {/* #shared-values */}

### 聚合 {/* #aggregations */}

彙總、分組及時間序列方法接受以下 `aggregation` 值：

| 值 | 結果 |
| - | - |
| `sum` | 指標值總和 |
| `avg` | 指標值平均數 |
| `min` | 最小指標值 |
| `max` | 最大指標值 |
| `count` | 符合條件的指標紀錄數 |
| `count_distinct` | `distinctColumn` 中不同值的近似或準確數量，視乎儲存後端而定 |
| `last`|最新匹配的指標值 |

當 `aggregation` 為 `count_distinct` 時，必須提供 `distinctColumn`。支援以下欄位：

```text
entityType
entityName
parentEntityType
parentEntityName
rootEntityType
rootEntityName
name
provider
model
environment
executionSource
serviceName
threadId
resourceId
```

### 間隔 {/* #intervals */}

時間序列及百分位數查詢接受 `1m`、`5m`、`15m`、`1h` 或 `1d`。

### 過濾器 {/* #filters */}

所有指標操作都接受相同的可選 `filters` 物件。原始紀錄清單請求以查詢參數傳遞這些欄位；分析方法則以 JSON 請求內文傳遞。

| 欄位 | 類型 | 說明 |
| - | - | - |
| `timestamp` | `{ start?: Date; end?: Date; startExclusive?: boolean; endExclusive?: boolean }` | 時間戳範圍。除非對應的排除標誌為 `true`，否則範圍包含邊界。HTTP 請求使用 ISO 日期字串。 |
| `traceId` | `string` | 完全相符的 trace ID |
| `traceIds` | `string[]` | 1 至 1,000 個 trace ID |
| `spanId` | `string` | 完全相符的 span ID |
| `entityType` | `EntityType` | 實體類型 |
| `entityName` | `string`|實體名稱 |
|`entityVersionId` | `string`|實體版本ID |
|`parentEntityType` | `EntityType`|父實體類型 |
|`parentEntityName` | `string`|父實體名稱 |
|`parentEntityVersionId` | `string`|父實體版本 ID |
|`rootEntityType` | `EntityType`|根實體類型 |
|`rootEntityName` | `string`|根實體名稱 |
|`rootEntityVersionId` | `string`|根實體版本 ID |
| `userId` | `string` | 用戶 ID |
|`organizationId` | `string`|組織 ID |
|`experimentId` | `string`|實驗或評估運行 ID |
|`experimentIds` | `string[]`| 1 到 1,000 個實驗 ID |
|`serviceName` | `string`|服務名稱|
|`environment` | `string`|環境名稱 |
|`resourceId` | `string`|資源 ID |
|`runId` | `string`|運行 ID |
|`sessionId` | `string`|會話 ID |
|`threadId` | `string`|線程 ID |
|`requestId` | `string`|請求 ID |
| `executionSource` | `string` | 執行來源 |
|`tags` | `string[]`|記錄必須包含所有指定的標籤 |
|`name` | `string[]`|一個或多個指標名稱 |
| `provider` | `string` | 模型 Provider |
| `model` | `string` | 模型 ID |
|`costUnit` | `string`|成本單位|
|`labels` | `Record<string, string>`|所有指定指標標籤鍵值對的精確比對 |
| `source` | `string` | 已棄用。請使用 `executionSource`。 |

## 分析方法 {/* #analytics-methods */}

### `getMetricAggregate(args)` {/* #getmetricaggregateargs */}

傳回所有符合條件紀錄彙總後的單一值。可觀測性儲存空間及 `MastraClient` 都提供此方法。

#### 參數 {/* #arguments */}

| 欄位 | 類型 | 必填 | 說明 |
| - | - | - | - |
| `name` | `string[]` | Yes | 一個或多個指標名稱 |
| `aggregation` | `AggregationType` | Yes | 要套用的彙總方式 |
| `distinctColumn` | `MetricDistinctColumn` | For `count_distinct` | 要計算不同值數量的欄位 |
| `filters` | `MetricsFilter` | No | 共用指標篩選條件 |
| `comparePeriod` | `'previous_period' \| 'previous_day' \| 'previous_week'` | No | 加入比較時段的值。`previous_period` 使用 `filters.timestamp` 的時長。 |

#### 傳回值 {/* #returns */}

```typescript oxfmt:false
{
  value: number | null
  previousValue?: number | null
  changePercent?: number | null
  estimatedCost?: number | null
  costUnit?: string | null
  previousEstimatedCost?: number | null
  costChangePercent?: number | null
}
```

如符合條件的紀錄沒有共同單位，`costUnit` 為 `null`。成本欄位屬可選；紀錄未包含成本上下文時，亦可能為 `null`。

```typescript
const result = await observability.getMetricAggregate({
  name: ['mastra_model_total_input_tokens', 'mastra_model_total_output_tokens'],
  aggregation: 'sum',
  filters: {
    timestamp: {
      start: new Date('2026-08-24T00:00:00Z'),
      end: new Date('2026-08-25T00:00:00Z'),
    },
  },
  comparePeriod: 'previous_period',
})
```

**HTTP：** `POST /api/observability/metrics/aggregate`

### `getMetricBreakdown(args)` {/* #getmetricbreakdownargs */}

按一個或多個維度將符合條件的紀錄分組，並彙總各組。可觀測性儲存空間及 `MastraClient` 都提供此方法。

#### 參數 {/* #arguments-1 */}

| 欄位 | 類型 | 必填 | 說明 |
| - | - | - | - |
| `name` | `string[]` | Yes | 一個或多個指標名稱 |
| `groupBy` | `string[]` | Yes | 一個或多個分組欄位 |
| `aggregation` | `AggregationType` | Yes | 套用至各組的彙總方式 |
| `distinctColumn` | `MetricDistinctColumn` | For `count_distinct` | 要計算不同值數量的欄位 |
| `filters` | `MetricsFilter` | No | 共用指標篩選條件 |
| `limit` | `number` | No | 不超過 1,000 的正整數。按 `orderDirection` 排序後只保留前幾組；省略時傳回所有組。對 `threadId` 等高基數分組，請設定此值以限制回應大小。按標籤鍵分組時，PostgreSQL 等部分儲存系統會排除標籤缺失或空白的紀錄，因此即使未設定 `limit`，各組加總亦可能不等於總計。請使用 `getMetricAggregate()` 取得總計。 |
| `orderDirection` | `'ASC' \| 'DESC'` | No | 彙總值的排序方向。儲存實作預設使用 `DESC`。 |

#### 傳回值 {/* #returns-1 */}

```typescript
{
  groups: Array<{
    dimensions: Record<string, string | null>
    value: number
    estimatedCost?: number | null
    costUnit?: string | null
  }>
}
```

```typescript
const result = await client.getMetricBreakdown({
  name: ['mastra_model_total_input_tokens'],
  groupBy: ['entityName'],
  aggregation: 'sum',
  limit: 10,
  orderDirection: 'DESC',
})
```

**HTTP：** `POST /api/observability/metrics/breakdown`

### `getMetricTimeSeries(args)` {/* #getmetrictimeseriesargs */}

按時間間隔將符合條件的值分桶，亦可選擇分組。可觀測性儲存空間及 `MastraClient` 都提供此方法。

#### 參數 {/* #arguments-2 */}

| 欄位 | 類型 | 必填 | 說明 |
| - | - | - | - |
| `name` | `string[]` | Yes | 一個或多個指標名稱 |
| `interval` | `AggregationInterval` | Yes | 時間區間的間隔 |
| `aggregation` | `AggregationType` | Yes | 套用至各時間區間的彙總方式 |
| `distinctColumn` | `MetricDistinctColumn` | For `count_distinct` | 要計算不同值數量的欄位 |
| `filters` | `MetricsFilter` | No | 共用指標篩選條件 |
| `groupBy` | `string[]` | No | 用於將結果拆分為多個序列的欄位 |

#### 傳回值 {/* #returns-2 */}

```typescript
{
  series: Array<{
    name: string
    costUnit?: string | null
    points: Array<{
      timestamp: Date
      value: number
      estimatedCost?: number | null
    }>
  }>
}
```

```typescript
const result = await client.getMetricTimeSeries({
  name: ['mastra_model_total_input_tokens'],
  interval: '1h',
  aggregation: 'sum',
  filters: {
    timestamp: { start: new Date(Date.now() - 24 * 60 * 60 * 1000) },
  },
})
```

**HTTP：** `POST /api/observability/metrics/timeseries`

### `getMetricPercentiles(args)` {/* #getmetricpercentilesargs */}

計算各時間區間的百分位數值。可觀測性儲存空間及 `MastraClient` 都提供此方法。

#### 參數 {/* #arguments-3 */}

| 欄位 | 類型 | 必填 | 說明 |
| - | - | - | - |
| `name` | `string` | Yes | 一個指標名稱 |
| `percentiles` | `number[]` | Yes | 一個或多個介乎 `0` 與 `1` 之間的值 |
| `interval` | `AggregationInterval` | Yes | 時間區間的間隔 |
| `filters` | `MetricsFilter` | No | 共用指標篩選條件 |

#### 傳回值 {/* #returns-3 */}

```typescript
{
  series: Array<{
    percentile: number
    points: Array<{
      timestamp: Date
      value: number
    }>
  }>
}
```

```typescript
const result = await client.getMetricPercentiles({
  name: 'mastra_agent_duration_ms',
  percentiles: [0.5, 0.95, 0.99],
  interval: '1h',
})
```

**HTTP：** `POST /api/observability/metrics/percentiles`

## 原始指標記錄 {/* #raw-metric-records */}

### `listMetrics(args)` {/* #listmetricsargs */}

傳回已儲存的指標觀測紀錄，不進行彙總。此方法由可觀測性儲存空間提供；HTTP 路由以查詢參數接收相同欄位。

#### 參數 {/* #arguments-4 */}

預設使用分頁模式：

```typescript oxfmt:false
{
  mode?: 'page'
  filters?: MetricsFilter
  pagination?: {
    page?: number // Default: 0
    perPage?: number // Default: 10; maximum: 100
  }
  orderBy?: {
    field?: 'timestamp' // Default: 'timestamp'
    direction?: 'ASC' | 'DESC' // Default: 'DESC'
  }
}
```

增量模式支援增量輪詢：

```typescript oxfmt:false
{
  mode: 'delta'
  filters?: MetricsFilter
  after?: string
  limit?: number // Default: 10; maximum: 100
}
```

增量模式不允許使用 `pagination` 及 `orderBy`；分頁模式不允許使用 `after` 及 `limit`。不支援增量輪詢的後端會傳回不支援此操作的錯誤。

#### 傳回值 {/* #returns-4 */}

```typescript oxfmt:false
{
  metrics: MetricRecord[]
  pagination?: {
    total: number
    page: number
    perPage: number | false
    hasMore: boolean
  }
  delta?: {
    limit: number
    hasMore: boolean
  }
  deltaCursor?: string
}
```

`MetricRecord` 的結構如下：

```typescript oxfmt:false
{
  metricId?: string | null
  timestamp: Date
  name: string
  value: number
  traceId?: string | null
  spanId?: string | null
  entityType?: EntityType | null
  entityId?: string | null
  entityName?: string | null
  parentEntityType?: EntityType | null
  parentEntityId?: string | null
  parentEntityName?: string | null
  rootEntityType?: EntityType | null
  rootEntityId?: string | null
  rootEntityName?: string | null
  userId?: string | null
  organizationId?: string | null
  resourceId?: string | null
  runId?: string | null
  sessionId?: string | null
  threadId?: string | null
  requestId?: string | null
  environment?: string | null
  serviceName?: string | null
  scope?: Record<string, unknown> | null
  entityVersionId?: string | null
  parentEntityVersionId?: string | null
  rootEntityVersionId?: string | null
  experimentId?: string | null
  executionSource?: string | null
  tags?: string[] | null
  source?: string | null // Deprecated
  provider?: string | null
  model?: string | null
  estimatedCost?: number | null
  costUnit?: string | null
  costMetadata?: Record<string, unknown> | null
  labels: Record<string, string>
  metadata?: Record<string, unknown> | null
}
```

**HTTP：** `GET /api/observability/metrics`

## 指標發現 {/* #metric-discovery */}

可觀測性儲存空間及 `MastraClient` 都提供指標探索方法。HTTP 請求以查詢參數傳遞參數。

| 方法 | 參數 | 傳回值 | HTTP 路由 |
| - | - | - | - |
|`getMetricNames(args?)` | `{ prefix?: string; limit?: number }` | `{ names: string[] }` | `GET /api/observability/discovery/metric-names` |
| `getMetricLabelKeys(args)` | `{ metricName: string }` | `{ keys: string[] }` | `GET /api/observability/discovery/metric-label-keys` |
| `getMetricLabelValues(args)` | `{ metricName: string; labelKey: string; prefix?: string; limit?: number }` | `{ values: string[] }` | `GET /api/observability/discovery/metric-label-values` |

提供 `limit` 時，其值必須是正整數。

```typescript
const { names } = await client.getMetricNames({ prefix: 'mastra_model_' })
const { keys } = await client.getMetricLabelKeys({ metricName: names[0] })
const { values } = await client.getMetricLabelValues({
  metricName: names[0],
  labelKey: keys[0],
  limit: 20,
})
```

可觀測性探索 API 亦提供 trace、日誌及指標共用的維度：

| 儲存空間或用戶端方法 | 參數 | HTTP 路由 |
| - | - | - |
| `getEntityTypes()` | `MastraClient` 中無需參數；儲存空間中為 `{}` | `GET /api/observability/discovery/entity-types` |
| `getEntityNames(args?)` | `{ entityType?: EntityType }` | `GET /api/observability/discovery/entity-names` |
| `getServiceNames()` | `MastraClient` 中無需參數；儲存空間中為 `{}` | `GET /api/observability/discovery/service-names` |
| `getEnvironments()` | `MastraClient` 中無需參數；儲存空間中為 `{}` | `GET /api/observability/discovery/environments` |
| `getTags(args?)` | `{ entityType?: EntityType }` | `GET /api/observability/discovery/tags` |

| 方法 | 路由 | 輸入 |
| - | - | - |

| `POST` | `/api/observability/metrics/aggregate` | JSON 請求內文 |
| `POST` | `/api/observability/metrics/breakdown` | JSON 請求內文 |
| `POST` | `/api/observability/metrics/timeseries` | JSON 請求內文 |
| `POST` | `/api/observability/metrics/percentiles` | JSON 請求內文 |
| `GET` | `/api/observability/discovery/metric-names` | 查詢參數 |
| `GET` | `/api/observability/discovery/metric-label-keys` | 查詢參數 |
| `GET` | `/api/observability/discovery/metric-label-values` | 查詢參數 |
| `GET` | `/api/observability/discovery/entity-types` | 無 |
| `GET` | `/api/observability/discovery/entity-names` | 查詢參數 |

所有路由都需要已設定的可觀測性儲存領域。啟用執行階段授權後，彙總、分組、時間序列及百分位數路由均需要 `observability:read` 權限。

## 不支援的後端 {/* #unsupported-backends */}

基本可觀測性儲存實作會在原始紀錄清單、分析及探索方法上擲出 `*_NOT_IMPLEMENTED` 錯誤。因此，即使已設定可觀測性儲存領域，後端仍可能不支援指標查詢。

DuckDB、ClickHouse、Postgres v-next 可觀測性儲存空間及記憶體內可觀測性儲存空間支援指標查詢。Google Cloud Spanner 只在 `disableMetrics` 為 `false` 時支援；指標預設停用。其他儲存適配器可能支援追蹤，但不支援指標。

## CLI {/* #cli */}

`mastra api metric` 指令涵蓋彙總、分組、時間序列、百分位數、指標名稱、標籤鍵及標籤值查詢。指令用法、目標選擇、身份驗證及 schema 檢視方式請參閱 [`mastra api metric` CLI 參考](/reference/cli/mastra#mastra-api-metric-aggregate)。
