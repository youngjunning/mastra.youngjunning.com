# 跨距

## `BaseSpan` {/* #basespan */}

所有跨度類型的基本介面。

```typescript
interface BaseSpan<TType extends SpanType> {
  /** Unique span identifier */
  id: string

  /** OpenTelemetry-compatible trace ID (32 hex chars) */
  traceId: string

  /** Name of the span */
  name: string

  /** Type of the span */
  type: TType

  /** When span started */
  startTime: Date

  /** When span ended */
  endTime?: Date

  /** Type-specific attributes */
  attributes?: SpanTypeMap[TType]

  /** User-defined metadata */
  metadata?: Record<string, any>

  /** Input passed at the start of the span */
  input?: SpanInput<TType>

  /** Output generated at the end of the span */
  output?: SpanOutput<TType>

  /** Error information if span failed */
  errorInfo?: {
    message: string
    id?: string
    domain?: string
    category?: string
    details?: Record<string, any>
  }

  /** Snapshot of the RequestContext */
  requestContext?: Record<string, any>
  /** Is an event span? (point-in-time: endTime equals startTime) */
  isEvent: boolean
}
```

## 跨距 {/* #span */}

Span接口，內部用於追蹤。使用生命週期方法和屬性來擴展 BaseSpan。

```typescript
interface Span<TType extends SpanType> extends BaseSpan<TType> {
  /** Is an internal span? (spans internal to the operation of mastra) */
  isInternal: boolean

  /** Parent span reference (undefined for root spans) */
  parent?: AnySpan

  /** Pointer to the ObservabilityInstance instance */
  observabilityInstance: ObservabilityInstance
}
```

## `ExportedSpan` {/* #exportedspan */}

導出的Span接口，用於追蹤導出器。 Span 的輕量級版本，沒有方法或循環引用。

```typescript
interface ExportedSpan<TType extends SpanType> extends BaseSpan<TType> {
  /** Parent span id reference (undefined for root spans) */
  parentSpanId?: string

  /** Parent span owned by an external tracing system, such as an ambient OpenTelemetry span. A resumed run keeps the external parent of the run it continues, unless the resume passes its own `tracingOptions.parentSpanId` */
  externalParentSpanId?: string

  /** Span id of the first run that a resumed run continues. Not set on the first run. `metadata.resumedFromSpanId` can differ: it holds the span the resume attaches under, which is the previous run when a workflow suspends more than once */
  resumedFromSpanId?: string

  /** Requested model and its provider, from this span's own model and provider attributes. Set only when both are present */
  model?: string
  provider?: string

  /** How this execution ended, and the machine-readable cause of stopping */
  outcome?: string
  stopReason?: string

  /** Structured details behind stopReason, such as the limit that was hit */
  stopReasonContext?: Record<string, unknown>

  /** Milliseconds from the start of the model inference that streamed the first chunk to that chunk */
  timeToFirstTokenMs?: number

  /** Failures originating directly on this span; unset when the count is unknown */
  errorCount?: number

  /** TRUE if the span is the root span of a trace */
  isRootSpan: boolean
}
```

### 本地錯誤計數 {/* #local-error-counts */}

`errorCount`計算源自跨度的故障。它排除了子級計數以及父級跨度上相同故障的重複報告。已恢復的故障仍會對計數產生影響，因此成功的跨度可以具有正計數。

未設定`errorCount` means the count is unavailable, not necessarily zero.

## 跨生命週期事件 {/* #span-lifecycle-events */}

在 span 生命週期期間發出的事件。

### `TracingEventType` {/* #tracingeventtype */}

```typescript
enum TracingEventType {
  /** Emitted when a span is created and started */
  SPAN_STARTED = 'span_started',

  /** Emitted when a span is updated via update() */
  SPAN_UPDATED = 'span_updated',

  /** Emitted when a span is ended via end() or error() */
  SPAN_ENDED = 'span_ended',
}
```

### `TracingEvent` {/* #tracingevent */}

```typescript
type TracingEvent =
  | { type: 'span_started'; exportedSpan: AnyExportedSpan }
  | { type: 'span_updated'; exportedSpan: AnyExportedSpan }
  | { type: 'span_ended'; exportedSpan: AnyExportedSpan }
```

導出器接收這些事件來處理追蹤資料並將其發送到可觀察平台。

## 無操作跨度 {/* #no-op-spans */}

當追蹤被停用時（採樣返回 false），將返回 NO-OP 跨度：

### `NoOpSpan` {/* #noopspan */}

```typescript oxfmt:false
class NoOpSpan<TType extends SpanType> extends BaseSpan<TType>
```

`NoOpSpan`導出自`@mastra/observability`. It extends that package's abstract `BaseSpan` class, which implements the `Span` interface. That class is different from the `BaseSpan` interface described on this page.

不執行任何操作的跨度。所有方法都是無操作的：

* `id`回報`'no-op'`
* `traceId`回報`'no-op-trace'`
* `isValid`回報`false`
* `end()`, `error()`, `update()` do nothing
* `createChildSpan()`返回另一個 NO-OP 跨度
