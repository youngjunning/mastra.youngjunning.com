# CloudExporter

**加入版本：** `@mastra/observability@1.8.0`。**自 `1.12.0` 起棄用**，請改用 [`MastraPlatformExporter`](/reference/observability/tracing/exporters/mastra-platform-exporter)。

:::warning[已棄用]

`CloudExporter` 仍可用於向後相容，但會在未來的主要版本移除。新項目請使用 [`MastraPlatformExporter`](/reference/observability/tracing/exporters/mastra-platform-exporter)。兩個類別的建構函數相同，亦共用環境變數及執行時行為。為保留現有監控規則，`CloudExporter` 繼續使用原有的匯出器 `name` 值 `mastra-cloud-observability-exporter` 及 `CLOUD_EXPORTER_*` 錯誤 ID。

:::

將追蹤 span、日誌、指標、評分及意見回饋傳送至 Mastra 平台，以便在線查看及監控。

## `CloudExporterConfig` {/* #cloudexporterconfig */}

```typescript
interface CloudExporterConfig extends BaseExporterConfig {
  /** Maximum number of spans per batch. Default: 1000 */
  maxBatchSize?: number

  /** Maximum wait time before flushing in milliseconds. Default: 5000 */
  maxBatchWaitMs?: number

  /** Maximum retry attempts. Default: 3 */
  maxRetries?: number

  /** Cloud access token (from env or config) */
  accessToken?: string

  /** Project ID for project-scoped collector routes (letters, numbers, hyphens, underscores) */
  projectId?: string

  /** Base cloud observability endpoint */
  endpoint?: string

  /** Explicit cloud traces endpoint override */
  tracesEndpoint?: string

  /** Explicit cloud logs endpoint override */
  logsEndpoint?: string

  /** Explicit cloud metrics endpoint override */
  metricsEndpoint?: string

  /** Explicit cloud scores endpoint override */
  scoresEndpoint?: string

  /** Explicit cloud feedback endpoint override */
  feedbackEndpoint?: string
}
```

繼承 `BaseExporterConfig`，其中包含：

* `logger?: IMastraLogger` — 日誌記錄器實例
* `logLevel?: LogLevel | 'debug' | 'info' | 'warn' | 'error'` — 日誌等級（預設：INFO）

## 環境變數 {/* #environment-variables */}

若設定中未提供，匯出器會讀取以下環境變數：

* `MASTRA_CLOUD_ACCESS_TOKEN` — `CloudExporter` 請求使用的驗證權杖
* `MASTRA_PROJECT_ID` — 推導項目範圍收集器路由時使用的項目 ID，例如 `/projects/:projectId/ai/spans/publish`
* `MASTRA_CLOUD_TRACES_ENDPOINT` — 覆寫追蹤端點。可傳入基本來源網址，或以 `/spans/publish` 結尾的完整追蹤發佈 URL。其他訊號端點會據此推導。預設值為 `https://observability.mastra.ai`

`CloudExporter` 不會讀取 `MASTRA_PLATFORM_OBSERVABILITY_ENDPOINT`。如需使用此變數，請改用 [`MastraPlatformExporter`](/reference/observability/tracing/exporters/mastra-platform-exporter)。

## 方法 {/* #methods */}

### `exportTracingEvent` {/* #exporttracingevent */}

```typescript oxfmt:false
async exportTracingEvent(event: TracingEvent): Promise<void>
```

處理要匯出到 Cloud 的追蹤事件。

只匯出 `SPAN_ENDED` 追蹤事件；忽略 `SPAN_STARTED` 及 `SPAN_UPDATED`。符合條件的 span 會先進入緩衝區，並在下次寫入時上傳至 Cloud 追蹤端點。

**傳回：** 追蹤事件進入緩衝區或被忽略後，傳回 `Promise<void>`。

### `onLogEvent` {/* #onlogevent */}

```typescript oxfmt:false
async onLogEvent(event: LogEvent): Promise<void>
```

處理要匯出到 Cloud 的日誌訊號。

傳給此處理函數的每個 `LogEvent` 都會進入緩衝區，並匯出至按設定的基本端點推導出的 Cloud 日誌端點。與追蹤不同，`CloudExporter` 不會按事件狀態進一步篩選。如果匯出器已停用，此方法不會執行任何操作。

### `flush` {/* #flush */}

```typescript oxfmt:false
async flush(): Promise<void>
```

強制將所有緩衝事件傳送至 Mastra 平台，而不關閉匯出器。適用於需要在執行環境結束前確保 span 已匯出的無伺服器環境。

### `shutdown` {/* #shutdown */}

```typescript oxfmt:false
async shutdown(): Promise<void>
```

傳送剩餘事件並清理資源。

## 行為 {/* #behavior */}

### 身份驗證 {/* #authentication */}

若設定及環境變數都未提供存取權杖，匯出器會：

* 記錄包含註冊資訊的警告。
* 不執行任何操作（丟棄所有事件）。

### 批次處理 {/* #batching */}

匯出器會批次處理追蹤 span、日誌、指標、評分及意見回饋，以減少網絡開銷：

* 緩衝事件總數達到 `maxBatchSize` 時寫入。
* 自批次中的第一個緩衝訊號起，經過 `maxBatchWaitMs` 時寫入。
* 呼叫 `shutdown()` 時寫入。

### 錯誤處理 {/* #error-handling */}

* 使用指數退避重試，最多嘗試 `maxRetries` 次。
* 所有重試均失敗後丟棄該批次。
* 記錄錯誤，但繼續處理新事件。

### 端點路由 {/* #endpoint-routing */}

* 按基本來源網址自動推導各訊號端點。
* 未設定 `projectId` 時，推導出的路由使用 `/ai/{signal}/publish`。
* 設定 `projectId` 或 `MASTRA_PROJECT_ID` 時，推導出的路由使用 `/projects/:projectId/ai/{signal}/publish`。
* 明確提供的完整發佈 URL 會原樣使用，即使已設定 `projectId` 也是如此。

### 訊號處理 {/* #signal-processing */}

* `exportTracingEvent()` 只匯出 `SPAN_ENDED` 追蹤事件。
* `onLogEvent()`、`onMetricEvent()`、`onScoreEvent()` 及 `onFeedbackEvent()` 會緩衝各自收到的所有對應類型事件。
* 所有支援的訊號批次都會在 `flush()` 及 `shutdown()` 期間上傳至對應的 Cloud 發佈端點。

## `MastraCloudSpanRecord` {/* #mastracloudspanrecord */}

Cloud span 的內部格式：

```typescript
interface MastraCloudSpanRecord {
  traceId: string
  spanId: string
  parentSpanId: string | null
  name: string
  spanType: string
  attributes: Record<string, any> | null
  metadata: Record<string, any> | null
  startedAt: Date
  endedAt: Date | null
  input: any
  output: any
  error: any
  isEvent: boolean
  createdAt: Date
  updatedAt: Date | null
}
```

## 用法 {/* #usage */}

```typescript
import { CloudExporter } from '@mastra/observability'

// Uses environment variable for token
const exporter = new CloudExporter()

// Explicit configuration
const customExporter = new CloudExporter({
  accessToken: 'your-token',
  projectId: 'project_123',
  maxBatchSize: 500,
  maxBatchWaitMs: 2000,
  logLevel: 'debug',
})
```
