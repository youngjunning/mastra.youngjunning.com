# LangfuseExporter

將 Tracing 資料傳送到 Langfuse，以便進行可觀測性分析。

## 建構函式 {/* #constructor */}

```typescript oxfmt:false
new LangfuseExporter(config?: LangfuseExporterConfig)
```

## `LangfuseExporterConfig` {/* #langfuseexporterconfig */}

```typescript
interface LangfuseExporterConfig extends BaseExporterConfig {
  publicKey?: string
  secretKey?: string
  baseUrl?: string
  additionalHeaders?: Record<string, string>
  realtime?: boolean
  flushAt?: number
  flushInterval?: number
  environment?: string
  release?: string
  resourceAttributes?: DetectedResourceAttributes
}
```

擴展 `BaseExporterConfig`，其中還包括：

- `logger?: IMastraLogger` - Logger 執行個體
- `logLevel?: LogLevel | 'debug' | 'info' | 'warn' | 'error'` - 記錄級別（預設：INFO）

## 屬性 {/* #properties */}

### `client` {/* #client */}

```typescript oxfmt:false
get client(): LangfuseClient | undefined
```

用於存取 Langfuse 進階功能的 `LangfuseClient` 執行個體。如因缺少憑證而停用 Exporter，則傳回 `undefined`。可用它管理提示詞、評估及資料集，或直接存取 API。

## 方法 {/* #methods */}

### flush {/* #flush */}

```typescript oxfmt:false
async flush(): Promise<void>
```

強制將緩衝中的 span 及評分立即送到 Langfuse，且不關閉 Exporter。適用於需要在運行時終止前確保資料已匯出的無伺服器環境。

### shutdown {/* #shutdown */}

```typescript oxfmt:false
async shutdown(): Promise<void>
```

送出待處理資料，並關閉 span 處理器及用戶端。

## 用法 {/* #usage */}

### 零設定（使用環境變數） {/* #zero-config-using-environment-variables */}

```typescript
import { LangfuseExporter } from '@mastra/langfuse'

// Reads from LANGFUSE_PUBLIC_KEY, LANGFUSE_SECRET_KEY, LANGFUSE_BASE_URL
const exporter = new LangfuseExporter()
```

### 顯式設定 {/* #explicit-configuration */}

```typescript
import { LangfuseExporter } from '@mastra/langfuse'

const exporter = new LangfuseExporter({
  publicKey: process.env.LANGFUSE_PUBLIC_KEY,
  secretKey: process.env.LANGFUSE_SECRET_KEY,
  baseUrl: 'https://cloud.langfuse.com',
  additionalHeaders: { 'x-custom-header': 'custom-value' },
  realtime: true,
})
```

## Span 映射 {/* #span-mapping */}

Mastra 的 span 會轉換為 OTel 格式，並透過 `LangfuseSpanProcessor` 傳送到 Langfuse。Langfuse 根據 `gen_ai.*` 屬性自動映射 span：

- 具有 `model` 屬性的 span → Langfuse generation
- 其他所有 span → Langfuse span
- 透過 OTel trace/span ID 保留父子關係

## 成本追蹤 {/* #cost-tracking */}

Langfuse 從 `langfuse.observation.cost_details` 讀取成本。Exporter 只在模型生成 span 的成本元資料符合以下全部條件時傳送該欄位：

- 該 span 是 `MODEL_GENERATION` span。
- `costContext.costMetadata.source` 為 `'provider_reported'`，表示模型 Provider 傳回了成本。估算成本不會匯出，以便 Langfuse 使用自己的模型定價。
- `costContext.costUnit` 為 `'USD'`。
- `costContext.estimatedCost` 是有限的非負數。

只要有一項條件不符合，generation 就不會附帶成本明細，Langfuse 會改用自己的定價模型。對於大多數自行託管或直接連線模型 API 等不回報成本的 Provider，需要在 Langfuse 中設定模型價格，才能由其定價模型計算成本。

## 提示詞關聯 {/* #prompt-linking */}

使用 `withLangfusePrompt` 輔助函式，將 LLM generation 關聯到 [Langfuse Prompt Management](https://langfuse.com/docs/prompt-management)：

```typescript
import { buildTracingOptions } from '@mastra/observability'
import { LangfuseExporter, withLangfusePrompt } from '@mastra/langfuse'

const exporter = new LangfuseExporter()

// Fetch prompt via the Langfuse client
const prompt = await exporter.client.prompt.get('customer-support', { type: 'text' })

const agent = new Agent({
  id: 'support-agent',
  name: 'support-agent',
  instructions: prompt.compile(),
  model: '__GATEWAY_OPENAI_MODEL__',
  defaultGenerateOptions: {
    tracingOptions: buildTracingOptions(
      withLangfusePrompt({ name: prompt.name, version: prompt.version }),
    ),
  },
})
```

### 輔助函式 {/* #helper-functions */}

#### `withLangfusePrompt(prompt)` {/* #withlangfusepromptprompt */}

將 Langfuse 提示詞元資料添加到 Tracing 選項。

```typescript
// Link by name and version (required for Langfuse v5)
withLangfusePrompt({ name: 'my-prompt', version: 1 })
```

提示詞元資料會作為 span 屬性傳遞，Langfuse 據此將 generation 關聯到對應提示詞。
