# Langfuse出口商

將追蹤資料傳送到 Langfuse 以實現可觀察性。

## 建構函數 {/* #constructor */}

```typescript oxfmt:false
new LangfuseExporter(config?: LangfuseExporterConfig)
```

## `LangfuseExporterConfig` {/* #langfuseexporterconfig */}

```typescript
interface LangfuseExporterConfig extends BaseExporterConfig {
  publicKey?: string
  secretKey?: string
  baseUrl?: string
  additionalHeaders?: Record<string, string>
  realtime?: boolean
  flushAt?: number
  flushInterval?: number
  environment?: string
  release?: string
  resourceAttributes?: DetectedResourceAttributes
}
```

延伸`BaseExporterConfig`, which includes:

* `logger?: IMastraLogger`- 記錄器實例
* `logLevel?: LogLevel | 'debug' | 'info' | 'warn' | 'error'`- 日誌等級（預設：INFO）

## 特性 {/* #properties */}

### `client` {/* #client */}

```typescript oxfmt:false
get client(): LangfuseClient | undefined
```

這`LangfuseClient` instance for advanced Langfuse features. Returns `undefined` when the exporter is disabled (missing credentials). Use this for prompt management, evaluations, datasets, and direct API access.

## 方法 {/* #methods */}

### 沖水 {/* #flush */}

```typescript oxfmt:false
async flush(): Promise<void>
```

強制將任何緩衝的跨度和分數刷新到 Langfuse，而無需關閉。在無伺服器環境中很有用，您需要確保在執行時間終止之前匯出資料。

### 關閉 {/* #shutdown */}

```typescript oxfmt:false
async shutdown(): Promise<void>
```

刷新掛起的資料並關閉跨度處理器和客戶端。

## 用法 {/* #usage */}

### 零配置（使用環境變數） {/* #zero-config-using-environment-variables */}

```typescript
import { LangfuseExporter } from '@mastra/langfuse'

// Reads from LANGFUSE_PUBLIC_KEY, LANGFUSE_SECRET_KEY, LANGFUSE_BASE_URL
const exporter = new LangfuseExporter()
```

### 明確配置 {/* #explicit-configuration */}

```typescript
import { LangfuseExporter } from '@mastra/langfuse'

const exporter = new LangfuseExporter({
  publicKey: process.env.LANGFUSE_PUBLIC_KEY,
  secretKey: process.env.LANGFUSE_SECRET_KEY,
  baseUrl: 'https://cloud.langfuse.com',
  additionalHeaders: { 'x-custom-header': 'custom-value' },
  realtime: true,
})
```

## 跨距映射 {/* #span-mapping */}

Mastra 跨度轉換為 OTel 格式並透過以下方式傳送至 Langfuse`LangfuseSpanProcessor`. Langfuse automatically maps spans based on their `gen_ai.*` attributes:

* 跨距與`model` attribute → Langfuse generations
* 所有其他跨度 → Langfuse 跨度
* 父子關係透過 OTel 追蹤/跨度 ID 保留

## 成本追蹤 {/* #cost-tracking */}

Langfuse 報告成本來自`langfuse.observation.cost_details`. The exporter sends that field only for model generation spans whose cost metadata meets all of these conditions:

* 跨度是一個`MODEL_GENERATION` span.
* `costContext.costMetadata.source`是`'provider_reported'`, meaning the model provider returned the cost. Estimated costs aren't exported, so Langfuse can apply its own model pricing instead.
* `costContext.costUnit`是`'USD'`.
* `costContext.estimatedCost`是一個有限的非負數。

當任何條件失敗時，產生的數據將在沒有成本詳細資訊的情況下匯出，並且 Langfuse 會回退到其自己的定價模型，該模型還涵蓋大多數自託管或直接模型 API 等提供商，這些提供者在您在 Langfuse 中配置模型價格之前不會報告成本。

## 提示連結 {/* #prompt-linking */}

將LLM世代連結到[Langfuse Prompt Management](https://langfuse.com/docs/prompt-management) using the `withLangfusePrompt` helper:

```typescript
import { buildTracingOptions } from '@mastra/observability'
import { LangfuseExporter, withLangfusePrompt } from '@mastra/langfuse'

const exporter = new LangfuseExporter()

// Fetch prompt via the Langfuse client
const prompt = await exporter.client.prompt.get('customer-support', { type: 'text' })

const agent = new Agent({
  id: 'support-agent',
  name: 'support-agent',
  instructions: prompt.compile(),
  model: '__GATEWAY_OPENAI_MODEL__',
  defaultGenerateOptions: {
    tracingOptions: buildTracingOptions(
      withLangfusePrompt({ name: prompt.name, version: prompt.version }),
    ),
  },
})
```

### 輔助函數 {/* #helper-functions */}

#### `withLangfusePrompt(prompt)` {/* #withlangfusepromptprompt */}

將 Langfuse 提示元資料新增至追蹤選項。

```typescript
// Link by name and version (required for Langfuse v5)
withLangfusePrompt({ name: 'my-prompt', version: 1 })
```

提示元資料作為跨度屬性傳遞，Langfuse 將產生連結到對應的提示。
