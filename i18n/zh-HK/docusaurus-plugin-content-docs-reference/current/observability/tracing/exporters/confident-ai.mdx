# 深度評估導出器

將追蹤資料傳送至[Confident AI](https://www.confident-ai.com/)用於評估和可觀察性。導出者`@mastra/deepeval`，它基於 DeepEval SDK 構建。

看[Confident AI exporter](/integrations/observability/confident-ai) for setup and usage.

## 建構函數 {/* #constructor */}

```typescript oxfmt:false
new DeepEvalExporter(config?: DeepEvalExporterConfig)
```

## `DeepEvalExporterConfig` {/* #deepevalexporterconfig */}

```typescript
interface DeepEvalExporterConfig extends BaseExporterConfig {
  apiKey?: string
  environment?: string
  name?: string
  tags?: string[]
  metadata?: Record<string, any>
  threadId?: string
  userId?: string
  testCaseId?: string
  turnId?: string
  metricCollection?: string
  traceMetricCollection?: string
  llmMetricCollection?: string
  agentMetricCollection?: string
  toolMetricCollectionMap?: Record<string, string>
  prompt?: Prompt
  debug?: boolean
  traceCaptureSink?: (trace: Trace) => void
}
```

延伸`BaseExporterConfig`, which includes:

* `logger?: IMastraLogger`- 記錄器實例
* `logLevel?: LogLevel | 'debug' | 'info' | 'warn' | 'error'`- 日誌等級（預設：INFO）

## 方法 {/* #methods */}

### `exportTracingEvent` {/* #exporttracingevent */}

```typescript oxfmt:false
async exportTracingEvent(event: TracingEvent): Promise<void>
```

將追蹤事件匯出到 Confident AI。從 Mastra 跨度流建立追蹤樹，並在根跨度結束時發布追蹤。

### `flush` {/* #flush */}

```typescript oxfmt:false
async flush(): Promise<void>
```

等待任何運行中的追蹤帖子穩定下來，而不關閉導出器。

### `shutdown` {/* #shutdown */}

```typescript oxfmt:false
async shutdown(): Promise<void>
```

完成所有開啟的追蹤並刷新待處理的貼文。

## 用法 {/* #usage */}

### 零配置（使用環境變數） {/* #zero-config-using-environment-variables */}

```typescript
import { DeepEvalExporter } from '@mastra/deepeval'

// Reads from CONFIDENT_API_KEY, CONFIDENT_TRACE_ENVIRONMENT
const exporter = new DeepEvalExporter()
```

### 明確配置 {/* #explicit-configuration */}

```typescript
import { DeepEvalExporter } from '@mastra/deepeval'

const exporter = new DeepEvalExporter({
  apiKey: process.env.CONFIDENT_API_KEY,
  environment: 'production',
})
```

## 跨度類型映射 {/* #span-type-mapping */}

| Mastra 跨距類型 |自信AI跨距型|
| - | - |
|`AGENT_RUN`, `WORKFLOW_RUN` | `AGENT` |
| `MODEL_GENERATION` | `LLM` |
| `TOOL_CALL`, `MCP_TOOL_CALL`, `PROVIDER_TOOL_CALL`, `CLIENT_TOOL_CALL` | `TOOL` |
| `RAG_EMBEDDING`, `RAG_VECTOR_OPERATION` | `RETRIEVER`|
|所有其他導出的跨度類型 |`CUSTOM` |

事件跨度（例如`MODEL_CHUNK`) are dropped.
