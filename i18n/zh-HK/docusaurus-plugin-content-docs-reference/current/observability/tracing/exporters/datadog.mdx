# DatadogExporter

將 Tracing 資料傳送至 Datadog LLM Observability，以供監控與分析。

:::note
如果也使用 `dd-trace` 的 APM 自動插樁，並需要將其正確掛在 Mastra Span 之下，請改用 [DatadogBridge](/reference/observability/tracing/bridges/datadog)。此導出器會在執行完成後才傳送 LLM Observability 資料，因此不會參與 `dd-trace` 的即時作用域。
:::

## 建構函數 {/* #constructor */}

```typescript oxfmt:false
new DatadogExporter(config: DatadogExporterConfig)
```

## 方法 {/* #methods */}

### `exportTracingEvent` {/* #exporttracingevent */}

```typescript oxfmt:false
async exportTracingEvent(event: TracingEvent): Promise<void>
```

將追蹤事件匯出到 Datadog LLM Observability。

### flush {/* #flush */}

```typescript oxfmt:false
async flush(): Promise<void>
```

強制將緩衝中的 Span 傳送至 Datadog，同時保持導出器運作。適用於需要在執行環境終止前確保 Span 已導出的 Serverless 環境。

flush 僅盡力傳送：dd-trace 透過背景寫入器傳送 LLM Observability 資料，且無法等待請求完成，因此 `flush()` 要求 dd-trace 傳送後，會等待 `flushGraceMs`（預設 2000 毫秒）。每次傳送新資料的 flush 都會完整等待；若 Serverless 處理器對每個請求都等待 `flush()`，每個請求都會承擔這段耗時。若短暫執行的進程所產生的 Span 未出現在 Datadog，可提高此值；若有其他機制維持進程運作，可設為 `0` 略過等待。

### shutdown {/* #shutdown */}

```typescript oxfmt:false
async shutdown(): Promise<void>
```

傳送待處理資料並關閉導出器，同時取消尚未執行的清理計時器並停用 LLM Observability。

## 用法 {/* #usage */}

### 零配置（使用環境變數） {/* #zero-config-using-environment-variables */}

```typescript
import { DatadogExporter } from '@mastra/datadog'

// Reads from DD_LLMOBS_ML_APP, DD_API_KEY, DD_SITE, DD_ENV
const exporter = new DatadogExporter()
```

### 明確配置 {/* #explicit-configuration */}

```typescript
import { DatadogExporter } from '@mastra/datadog'

const exporter = new DatadogExporter({
  mlApp: 'my-llm-app',
  apiKey: process.env.DD_API_KEY,
  site: 'datadoghq.com',
  env: 'production',
})
```

### 使用本地 Datadog Agent {/* #with-local-datadog-agent */}

```typescript
const exporter = new DatadogExporter({
  mlApp: 'my-llm-app',
  agentless: false, // Use local Datadog Agent
  env: 'production',
})
```

## Span 對應 {/* #span-mapping */}

Mastra 的 Span 類型對應至 Datadog LLM Observability 的 Span 種類：

| Mastra SpanType | Datadog Kind |
| - | - |
|`AGENT_RUN` | `agent` |
| `MODEL_GENERATION` | `workflow` |
| `MODEL_STEP` | `llm` |
| `TOOL_CALL` | `tool` |
| `MCP_TOOL_CALL` | `tool` |
| `PROVIDER_TOOL_CALL` | `tool` |
| `WORKFLOW_RUN` | `workflow`|
| 所有其他類型 | `task` |

所有未對應的 Span 類型（包括 `MODEL_CHUNK`、`WORKFLOW_STEP`、`GENERIC` 及未來新增的類型）都會預設對應為 `task`。

## 環境變數 {/* #environment-variables */}

導出器從以下環境變數讀取配置：

| 變數 | 說明 |
| - | - |
| `DD_API_KEY` | Datadog API 金鑰 |
| `DD_LLMOBS_ML_APP` | ML 應用名稱 |
| `DD_SITE` | Datadog 站點 |
| `DD_ENV` | 環境名稱 |
| `DD_LLMOBS_AGENTLESS_ENABLED` | 設為 'false' 或 '0' 以使用本地 Agent |
