# ArizeExporter

將 Tracing 資料傳送至 Arize Phoenix、Arize AX，或其他支援 OpenInference 語義規範且相容 OpenTelemetry 的可觀測平台。

## 建構函數 {/* #constructor */}

```typescript oxfmt:false
new ArizeExporter(config: ArizeExporterConfig)
```

## `ArizeExporterConfig` {/* #arizeexporterconfig */}

```typescript
type ArizeExporterConfig = Omit<OtelExporterConfig, 'provider'> & {
  // Phoenix / OpenTelemetry configuration
  endpoint?: string
  apiKey?: string

  // Arize AX configuration
  spaceId?: string

  // Common configuration
  projectName?: string
  headers?: Record<string, string>
}
```

繼承 `OtelExporterConfig`（不包含 `provider`），其中包括：

* `timeout?: number`- 導出逾時時間，單位為毫秒（預設：30000）
* `batchSize?: number`- 每批導出的 Span 數量（預設：512）
* `logLevel?: LogLevel | 'debug' | 'info' | 'warn' | 'error'`- 日誌級別（預設：WARN）
* `resourceAttributes?: Record<string, any>`- 自訂資源屬性

### 元數據透傳 {/* #metadata-passthrough */}

非保留的 Span 屬性會序列化至 OpenInference 的 `metadata` 資料載荷中。可透過 `tracingOptions.metadata` 加入，例如 `companyId`、`tier`。`input`、`output`、`sessionId`、線程與用戶 ID，以及 OpenInference ID 等保留欄位會自動排除。

## 方法 {/* #methods */}

### `exportTracingEvent` {/* #exporttracingevent */}

```typescript oxfmt:false
async exportTracingEvent(event: TracingEvent): Promise<void>
```

將追蹤事件導出至配置的端點。

### export {/* #export */}

```typescript oxfmt:false
async export(spans: ReadOnlySpan[]): Promise<void>
```

使用 OpenTelemetry 依 OpenInference 語義規範批次導出 Span。

### flush {/* #flush */}

```typescript oxfmt:false
async flush(): Promise<void>
```

強制將緩衝中的 Span 傳送至配置的端點，同時保持導出器運作。適用於需要在執行環境終止前確保 Span 已導出的 Serverless 環境。

### shutdown {/* #shutdown */}

```typescript oxfmt:false
async shutdown(): Promise<void>
```

傳送待處理資料並關閉客戶端。

## 用法 {/* #usage */}

### 零配置（使用環境變數） {/* #zero-config-using-environment-variables */}

```typescript
import { ArizeExporter } from '@mastra/arize'

// For Phoenix: Set PHOENIX_COLLECTOR_ENDPOINT, PHOENIX_API_KEY, PHOENIX_PROJECT_NAME
// For Arize AX: Set ARIZE_SPACE_ID, ARIZE_API_KEY, ARIZE_PROJECT_NAME
const exporter = new ArizeExporter()
```

### Phoenix 配置 {/* #phoenix-configuration */}

```typescript
import { ArizeExporter } from '@mastra/arize'

const exporter = new ArizeExporter({
  endpoint: 'http://localhost:6006/v1/traces',
  apiKey: process.env.PHOENIX_API_KEY, // Optional for local Phoenix
  projectName: 'my-ai-project',
})
```

### Arize AX 配置 {/* #arize-ax-configuration */}

```typescript
import { ArizeExporter } from '@mastra/arize'

const exporter = new ArizeExporter({
  spaceId: process.env.ARIZE_SPACE_ID!,
  apiKey: process.env.ARIZE_API_KEY!,
  projectName: 'my-ai-project',
})
```

## `OpenInference` 語義規範 {/* #openinference-semantic-conventions */}

ArizeExporter 遵循適用於生成式 AI 應用的 [OpenInference 語義規範](https://github.com/Arize-ai/openinference/tree/main/spec)，讓不同可觀測平台的 Trace 結構一致。

## 標籤支援 {/* #tags-support */}

ArizeExporter 支援使用標籤分類與篩選 Trace。標籤只套用於根 Span，並對應至 OpenInference 原生的 `tag.tags` 語義規範。

### 用法 {/* #usage-1 */}

```typescript
const result = await agent.generate('Hello', {
  tracingOptions: {
    tags: ['production', 'experiment-v2', 'user-request'],
  },
})
```

### 標籤的儲存方式 {/* #how-tags-are-stored */}

標籤儲存在 OpenInference 的 `tag.tags` 屬性中：

```json
{
  "tag.tags": ["production", "experiment-v2", "user-request"]
}
```
