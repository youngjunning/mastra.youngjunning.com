# MessageHistory

`MessageHistory` 是一種**混合處理器**，同時負責擷取及持久化訊息歷史紀錄。處理輸入時，它從儲存空間擷取歷史訊息並加到對話開頭；處理輸出時，它將新訊息持久化至儲存空間。

## 使用範例 {/* #usage-example */}

```typescript
import { MessageHistory } from '@mastra/core/processors'

const processor = new MessageHistory({
  storage: memoryStorage,
  lastMessages: 50,
})
```

## 擴充使用範例 {/* #extended-usage-example */}

```typescript title="src/mastra/agents/memory-agent.ts"
import { Agent } from '@mastra/core/agent'
import { MessageHistory } from '@mastra/core/processors'
import { PostgresStore } from '@mastra/pg'

const storage = new PostgresStore({
  id: 'pg-storage',
  connectionString: process.env.DATABASE_URL,
})

export const agent = new Agent({
  id: 'memory-agent',
  name: 'memory-agent',
  instructions: 'You are a helpful assistant with conversation memory',
  model: '__GATEWAY_OPENAI_MODEL__',
  inputProcessors: [
    new MessageHistory({
      storage,
      lastMessages: 100,
    }),
  ],
  outputProcessors: [
    new MessageHistory({
      storage,
    }),
  ],
})
```

## 行為 {/* #behavior */}

### 輸入處理 {/* #input-processing */}

1. 從請求上下文取得 `threadId`
1. 從儲存空間擷取歷史訊息（按建立時間由新到舊排序）
1. 篩走系統訊息（系統訊息不應儲存在資料庫中）
1. 合併歷史訊息與傳入訊息，並按 ID 去除重複項目
1. 為歷史訊息加上 `source: 'memory'` 標記

### 輸出處理 {/* #output-processing */}

1. 從請求上下文取得 `threadId`
1. 如記憶體設定設有 `readOnly`，則略過持久化
1. 篩走訊息中尚未完成的 Tool 呼叫
1. 將新的用戶輸入及助手回覆持久化至儲存空間
1. 更新對話線程的 `updatedAt` 時間戳
