# SkillsProcessor

`SkillsProcessor` 是一種**輸入處理器**，會以 `<available_skills>` 清單形式將可用的 Skill 加入系統訊息，讓模型知道有哪些 Skill，並可透過 `skill` 工具載入。若 Agent 的 Workspace 或本身的 `skills` 選項提供 Skill，Agent 會自動加入此處理器；只有需要改變 Skill 的呈現方式時，才須自行設定。

設定 `injectCatalog: false` 後，處理器會以簡短指示取代清單，引導 Agent 透過 `skill_search` 尋找 Skill，再透過 `skill` 載入。清單耗用太多 token 時可使用此模式。請參閱[關閉 Skill 清單](/docs/sandbox/skills#turn-off-the-skills-list)。

`skill`、`skill_search` 及 `skill_read` 工具由 Agent 提供，並非此處理器提供；兩種模式下均可使用。如要改用按需提供的 `search_skills` 及 `load_skill` 工具，請使用 [`SkillSearchProcessor`](/reference/processors/skill-search-processor)。兩種處理器只需設定其中一種。

## 使用例子 {/* #usage-example */}

```typescript
import { SkillsProcessor } from '@mastra/core/processors'

const skills = new SkillsProcessor({
  workspace,
  format: 'markdown',
})
```

## 進階使用例子 {/* #extended-usage-example */}

```typescript title="src/mastra/agents/skill-agent.ts"
import { Agent } from '@mastra/core/agent'
import { SkillsProcessor } from '@mastra/core/processors'
import { Workspace, LocalFilesystem } from '@mastra/core/workspace'

const workspace = new Workspace({
  filesystem: new LocalFilesystem({ basePath: './project' }),
  skills: ['skills'],
  bm25: true,
})

const agent = new Agent({
  id: 'skill-agent',
  name: 'skill-agent',
  instructions: 'You are a helpful assistant.',
  model: '__GATEWAY_OPENAI_MODEL__',
  workspace,
  inputProcessors: [new SkillsProcessor({ injectCatalog: false })],
})
```

關閉清單後，Agent 會透過搜尋尋找 Skill。即使未設定搜尋功能，`skill_search` 亦可運作；Skill 數量較多時，可如上例在 Workspace 中設定 [BM25 或向量搜尋](/docs/sandbox/search)，以改善排序。Agent 的運作流程如下：

1. Agent 收到用戶訊息
1. Agent 使用關鍵字（例如 "release notes"）呼叫 `skill_search`
1. Agent 檢視結果，並使用 Skill 名稱呼叫 `skill`
1. Agent 遵循已載入 Skill 的指示
