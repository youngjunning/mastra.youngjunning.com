# 回應快取

:::beta

在 API 穩定之前，即使不提升主版本號，也可能出現不兼容的改動。

:::

`ResponseCache` 是輸入處理器，在 Agent 循環的請求與回應邊界快取 LLM 回應。它透過 `processLLMRequest` 查詢快取；命中時直接返回快取結果，並透過 `processLLMResponse` 寫入已完成的回應。

快取鍵根據 Mastra 即將傳送給模型的最終 `LanguageModelV2Prompt` 產生，即在載入記憶、先前的輸入處理器修改提示詞*之後*產生。因此，不同用戶的記憶上下文不同時，快取鍵也不同。Agent 工具循環中的每個步驟都會分別快取。

Agent 沒有專門的回應快取選項。請將 `ResponseCache` 明確註冊至 `inputProcessors`。如要覆寫單次調用的設定，可透過 [`ResponseCache.context()`](#static-helpers) 和 [`ResponseCache.applyContext()`](#static-helpers) 將設定寫入 `RequestContext`。

## 使用範例 {/* #usage-example */}

```typescript
import { Agent } from '@mastra/core/agent'
import { InMemoryServerCache } from '@mastra/core/cache'
import { ResponseCache } from '@mastra/core/processors'

const cache = new InMemoryServerCache()

const agent = new Agent({
  id: 'search-agent',
  name: 'Search Agent',
  instructions: 'You answer questions concisely.',
  model: '__GATEWAY_OPENAI_MODEL_BASE__',
  inputProcessors: [new ResponseCache({ cache, ttl: 600 })],
})

// First call hits the LLM and writes to the cache.
await agent.generate('What is the capital of France?')

// Second identical call replays the cached response.
await agent.generate('What is the capital of France?')

// Force a fresh call but still update the cache.
await agent.generate('What is the capital of France?', {
  requestContext: ResponseCache.context({ bust: true }),
})
```

概念說明、作用範圍規則及建議的部署方式，請參閱[回應快取](/docs/agents/processors#response-caching)。

## 靜態助手 {/* #static-helpers */}

`ResponseCache` 提供兩個靜態輔助方法，用於在 `RequestContext` 中覆寫單次調用的設定。這些方法將底層上下文鍵保留為私有實作細節；請優先使用它們，避免直接讀寫原始鍵。

### `ResponseCache.context(options)` {/* #responsecachecontextoptions */}

建立新的 `RequestContext`，並預先寫入單次調用的回應快取覆寫設定。

```typescript
await agent.stream('hello', {
  requestContext: ResponseCache.context({ key: 'custom', bust: true }),
})
```

### `ResponseCache.applyContext(requestContext, options)` {/* #responsecacheapplycontextrequestcontext-options */}

將單次調用的回應快取覆寫設定合併到現有的 `RequestContext`，並返回同一個上下文，方便鏈式調用。

```typescript
const ctx = new RequestContext()
ctx.set('caller-meta', { userId: 'u-123' })
ResponseCache.applyContext(ctx, { bust: true })
await agent.stream('hello', { requestContext: ctx })
```

## 助手導出 {/* #helper-exports */}

- `buildResponseCacheKey(inputs)`：預設使用的確定性雜湊函式。重新匯出後，可覆寫個別欄位，同時保留標準快取鍵的其餘欄位。
- `DEFAULT_RESPONSE_CACHE_TTL_SECONDS`：預設 `ttl`（`300`）。
- `RESPONSE_CACHE_CONTEXT_KEY`：靜態輔助方法寫入的 `RequestContext` 鍵。此鍵可用於在流程中途清除覆寫設定等進階情況；一般請優先使用輔助方法。
