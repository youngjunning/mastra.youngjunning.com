# 分類器處理器

這`ClassifierProcessor`是一個混合處理器，運行[`Classifier`](/reference/classifier/classifier)透過訊息文字並將鍵入的答案傳遞給`onResult`。在`onResult`， 稱呼`abort(reason)`若要使用絆線停止請求，請致電`filter()`放棄內容並繼續，或不執行任何操作以使其通過。分類器提供機率、選擇和分數等證據。`onResult`擁有應用程式策略。

中止原因始終是呼叫者提供的字串。提供者產生的文字永遠不會包含在中止訊息中。

## 使用範例 {/* #usage-example */}

```typescript
import { Classifier } from '@mastra/core/classifier'
import { typeSafeAi } from '@ai-sdk/typesafe-ai'
import { ClassifierProcessor } from '@mastra/core/processors'

const safety = new Classifier({
  id: 'safety',
  model: typeSafeAi.decisionModel('__AI_SDK_TYPESAFE_DECISION_MODEL__'),
  questions: {
    unsafe: {
      type: 'boolean',
      criteria: { true: 'The message is unsafe', false: 'The message is safe' },
    },
  },
})

const processor = new ClassifierProcessor({
  classifier: safety,
  onResult: (answers, { abort }) => {
    if ((answers.unsafe.probability ?? 1) > 0.8) abort('Message rejected by safety policy')
  },
  lastMessageOnly: true,
})
```

決策模式可以拒絕一個問題。拒絕的答案是`{ type: 'refusal' }` and has no `choice`, `score`, or `probability`. The example treats a refusal as unsafe.

多個條件可以共用一個`onResult`, or use separate processors when they need different classifiers. Give each processor a unique `id`. Processor instances with the same `id` share per-run state, including accumulated stream chunks.

```typescript
inputProcessors: [
  new ClassifierProcessor({
    id: 'safety-check',
    classifier: safety,
    onResult: (a, { abort }) => {
      if ((a.unsafe.probability ?? 1) > 0.8) abort('Rejected by safety policy')
    },
  }),
  new ClassifierProcessor({
    id: 'topic-check',
    classifier: topic,
    onResult: (a, { abort }) => {
      if (a.topic.type === 'refusal' || a.topic.choice === 'other') abort('Support questions only')
    },
  }),
]
```

## 各階段的行為 {/* #behavior-by-phase */}

|相|沒有電話|`abort(reason)` | `filter()` |
| - | - | - | - |
| Input (`inputProcessors`) | message passes | abort before the LLM | message removed from context |
| Output result (`outputProcessors`) | message passes | abort the response | message removed from the response |
| Stream (`outputProcessors`) | chunk emitted | abort the stream | chunk not emitted |

沒有文字內容的訊息將被傳遞，而不呼叫分類器。

## 審計決定 {/* #audit-decisions */}

`onDecision`收到一個`ClassifierProcessorDecision` after each classifier call, once `onResult` has run. A failed classifier call produces a decision too.

```typescript
const processor = new ClassifierProcessor({
  classifier: safety,
  onResult: (answers, { abort }) => {
    if ((answers.unsafe.probability ?? 1) > 0.8) {
      abort('Message rejected by safety policy', { metadata: { policy: 'unsafe' } })
    }
  },
  onDecision: async decision => {
    await auditLog.insert({
      threadId: decision.ids.threadId,
      messageId: decision.ids.messageId,
      tenantId: decision.requestContext?.get('tenantId'),
      outcome: decision.outcome,
      answers: decision.result ? decision.result.answers : null,
      error: decision.result ? null : String(decision.error),
      durationMs: decision.durationMs,
    })
  },
})
```

`ClassifierProcessorDecision`有這些字段：

```typescript
type ClassifierProcessorDecision = {
  processorId: string
  classifierId: string
  phase: 'input' | 'output' | 'stream'
  // 'aborted' when onResult called abort(), or when the call failed under errorStrategy 'strict'
  outcome: 'allowed' | 'filtered' | 'aborted'
  // Text sent to the classifier, after maxInputLength truncation
  state: ClassifierState
  // Set when the classifier answered
  result?: ClassifierResult
  // Set when the classifier call failed
  error?: unknown
  // Set when outcome is 'aborted', with the same reason and metadata as the tripwire the caller receives
  tripwire?: { reason: string; metadata?: unknown }
  // Duration of the classifier call, including retries
  durationMs: number
  ids: {
    runId?: string
    threadId?: string
    resourceId?: string
    messageId?: string
    traceId?: string
    spanId?: string
  }
  requestContext?: RequestContext
}
```



|相| ID |
| - | - |
|輸入輸出結果|`messageId`, and `threadId` and `resourceId` when the agent uses memory |
| Stream | `runId`, and `threadId` and `resourceId` when the agent uses memory |

`threadId`和`resourceId` come from the agent's memory options. Without memory, the processor reads them from the message, then from the `MASTRA_THREAD_ID_KEY` and `MASTRA_RESOURCE_ID_KEY` request context keys. `traceId` and `spanId` are set when the run is traced, and `spanId` is the processor span.

處理器等待`onDecision` before it passes the content on. In the stream phase it runs once per text chunk. A slow write delays every chunk. Queue writes that take long instead of awaiting them. Errors thrown by `onDecision` are logged and don't change the outcome.

`onDecision`沒有被呼叫時`onResult` throws an error that isn't a tripwire, or when the user stops a streaming reply during the classifier call. Stopping the reply also cancels the classifier call, except on durable agents.

## 擴充使用範例 {/* #extended-usage-examples */}

### 主題範圍界定 {/* #topic-scoping */}

```typescript title="src/mastra/agents/support-agent.ts"
import { Agent } from '@mastra/core/agent'
import { Classifier } from '@mastra/core/classifier'
import { typeSafeAi } from '@ai-sdk/typesafe-ai'
import { ClassifierProcessor } from '@mastra/core/processors'

const topic = new Classifier({
  id: 'topic',
  model: typeSafeAi.decisionModel('__AI_SDK_TYPESAFE_DECISION_MODEL__'),
  questions: {
    topic: {
      type: 'choice',
      criteria: {
        billing: 'Questions about invoices or payments',
        account: 'Questions about account settings',
        other: 'Anything else',
      },
    },
  },
})

export const agent = new Agent({
  id: 'support-agent',
  name: 'support-agent',
  instructions: 'You help customers with billing and account questions.',
  model: '__GATEWAY_OPENAI_MODEL__',
  inputProcessors: [
    new ClassifierProcessor({
      classifier: topic,
      lastMessageOnly: true,
      onResult: (answers, { abort }) => {
        if (answers.topic.type === 'refusal' || answers.topic.choice === 'other') {
          abort('This assistant only handles billing and account questions')
        }
      },
    }),
  ],
})
```

### 輸出質量閘 {/* #output-quality-gate */}

```typescript title="src/mastra/agents/quality-gated-agent.ts"
import { Agent } from '@mastra/core/agent'
import { Classifier } from '@mastra/core/classifier'
import { typeSafeAi } from '@ai-sdk/typesafe-ai'
import { ClassifierProcessor } from '@mastra/core/processors'

const quality = new Classifier({
  id: 'quality',
  model: typeSafeAi.decisionModel('__AI_SDK_TYPESAFE_DECISION_MODEL__'),
  questions: {
    quality: {
      type: 'score',
      instructions: 'Rate how well the response answers the user',
      criteria: ['Off-topic', 'Partial', 'Complete'],
    },
  },
})

export const agent = new Agent({
  id: 'quality-gated-agent',
  name: 'quality-gated-agent',
  instructions: 'You are a helpful assistant',
  model: '__GATEWAY_OPENAI_MODEL__',
  outputProcessors: [
    new ClassifierProcessor({
      classifier: quality,
      onResult: (answers, { filter }) => {
        if ((answers.quality.score ?? 0) < 1) filter()
      },
    }),
  ],
})
```

### 註冊分類器 {/* #registered-classifier */}

將分類器註冊到`Mastra` instance and reference it by key or ID. The processor resolves it on first use.

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Classifier } from '@mastra/core/classifier'
import { typeSafeAi } from '@ai-sdk/typesafe-ai'

export const mastra = new Mastra({
  classifiers: {
    safety: new Classifier({
      id: 'safety',
      model: typeSafeAi.decisionModel('__AI_SDK_TYPESAFE_DECISION_MODEL__'),
      questions: {/* ... */},
    }),
  },
})
```

```typescript title="src/mastra/processors/safety-processor.ts"
import { ClassifierProcessor } from '@mastra/core/processors'

type SafetyQuestions = {
  unsafe: { type: 'boolean' }
}

const processor = new ClassifierProcessor<SafetyQuestions>({
  classifier: 'safety',
  onResult: (answers, { abort }) => {
    if ((answers.unsafe.probability ?? 1) > 0.8) abort('Message rejected by safety policy')
  },
})
```

當透過字串使用註冊的分類器時，不會從註冊的實例推斷答案類型。將其問題圖傳遞為`ClassifierProcessor` type argument to type the `answers` parameter.
