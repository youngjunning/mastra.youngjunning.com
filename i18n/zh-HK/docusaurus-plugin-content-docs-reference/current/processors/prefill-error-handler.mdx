# 預填錯誤處理程序

這`PrefillErrorHandler`是一個**錯誤處理器**處理助理響應預填充錯誤。當對話以助理訊息結束並且模型拒絕請求時，會發生此錯誤，因為它將其解釋為預填充助理回應。

當偵測到錯誤時，處理器會發送一個隱藏的`system-reminder` signal with `continue` as its contents and signals a retry. The reminder is persisted as signal metadata, which keeps it available for retry reconstruction and raw history while standard UI-facing message conversions hide it.

Mastra 將此處理器添加到每個Agent的`errorProcessors` by default, after `ProviderHistoryCompat` and before `StreamErrorRetryProcessor`. It only acts on the first retry attempt, so it needs no configuration. Supply your own instance to tune it. Anything already in your list is kept and the default is only added when its `id`缺席。

## 它是如何運作的 {/* #how-it-works */}

1. LLM API 呼叫失敗，並顯示已知的助理預填拒絕訊息
2. `PrefillErrorHandler`檢查這是否是第一次重試嘗試
3. 它發送一個隱藏的`system-reminder` signal with `continue` as its contents
4. 它返回`{ retry: true }` to signal the LLM call should be retried with the modified messages

處理器現在會對 API 拒絕本身做出反應，而不是重新檢查對話目前是否以助理訊息結束。這使得它能夠適應提供者拒絕預先填充語義請求的情況，即使尾隨訊息形狀已經被上游轉換。

## 使用範例 {/* #usage-example */}

若要調整預填恢復或明確範圍，請提供您自己的實例。預設`PrefillErrorHandler` isn't added when you do:

```typescript title="src/mastra/agents/my-agent.ts"
import { Agent } from '@mastra/core/agent'
import { PrefillErrorHandler } from '@mastra/core/processors'

export const agent = new Agent({
  id: 'my-agent',
  name: 'my-agent',
  instructions: 'You are a helpful assistant.',
  model: '__GATEWAY_ANTHROPIC_MODEL_OPUS__',
  errorProcessors: [new PrefillErrorHandler()],
})
```

如果您想要自訂恢復行為，請為您自己的錯誤處理器提供`processAPIError` method:

```typescript title="src/mastra/agents/custom-error-handling.ts"
import { Agent } from '@mastra/core/agent'
import type { Processor } from '@mastra/core/processors'

const customErrorHandler: Processor = {
  id: 'custom-prefill-error-handler',
  processAPIError({ error, messageList, retryCount }) {
    // Your custom logic here
  },
}

export const agent = new Agent({
  id: 'my-agent',
  name: 'my-agent',
  instructions: 'You are a helpful assistant.',
  model: '__GATEWAY_ANTHROPIC_MODEL_OPUS__',
  errorProcessors: [customErrorHandler],
})
```
