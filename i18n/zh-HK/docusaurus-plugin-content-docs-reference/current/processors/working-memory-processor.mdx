# WorkingMemory

`WorkingMemory` 是一個**輸入 Processor**，會將工作記憶資料作為系統訊息注入。它從儲存中讀取持久化資訊，並將其整理為給 LLM 的指令，使 Agent 能夠在多次對話中保留有關使用者的脈絡。

## 使用範例 {/* #usage-example */}

```typescript
import { WorkingMemory } from '@mastra/core/processors'

const processor = new WorkingMemory({
  storage: memoryStorage,
  scope: 'resource',
  template: {
    format: 'markdown',
    content: `# User Profile
- **Name**:
- **Preferences**:
- **Goals**:
`,
  },
})
```

## 延伸使用範例 {/* #extended-usage-example */}

```typescript title="src/mastra/agents/personalized-agent.ts"
import { Agent } from '@mastra/core/agent'
import { WorkingMemory, MessageHistory } from '@mastra/core/processors'
import { PostgresStore } from '@mastra/pg'

const storage = new PostgresStore({
  id: 'pg-storage',
  connectionString: process.env.DATABASE_URL,
})

export const agent = new Agent({
  id: 'personalized-agent',
  name: 'personalized-agent',
  instructions: 'You are a helpful assistant that remembers user preferences',
  model: '__GATEWAY_OPENAI_MODEL__',
  inputProcessors: [
    new WorkingMemory({
      storage,
      scope: 'resource',
      template: {
        format: 'markdown',
        content: `# User Information
- **Name**:
- **Location**:
- **Preferences**:
- **Communication Style**:
- **Current Projects**:
`,
      },
    }),
    new MessageHistory({ storage, lastMessages: 50 }),
  ],
  outputProcessors: [new MessageHistory({ storage })],
})
```

## 行為 {/* #behavior */}

### 輸入處理 {/* #input-processing */}

1. 從請求脈絡中讀取 `threadId` 及 `resourceId`
1. 根據作用範圍，從以下位置之一讀取工作記憶：
   - 執行緒元資料（`scope: 'thread'`）
   - 資源記錄（`scope: 'resource'`）
1. 解析模板（來自 Provider、選項或預設值）
1. 根據模式產生系統指令：
   - **普通模式**：包含儲存及更新資訊的指引，以及模板結構及目前資料
   - **唯讀模式**（`readOnly: true`）：僅將目前資料作為脈絡，不包含更新指令
1. 將指令作為帶有 `source: 'memory'` 標記的系統訊息加入到訊息清單

### 更新工作記憶 {/* #working-memory-updates */}

工作記憶透過 Memory 類別提供的 `updateWorkingMemory` 工具更新，而非透過此 Processor 更新。此 Processor 只負責將目前工作記憶狀態注入對話。

### 預設模板 {/* #default-template */}

如未提供模板，Processor 會使用預設的 Markdown 模板，包含以下欄位：

- 名、姓
- 地點、職業
- 興趣、目標
- 事件、事實、專案
