# 忠誠得分手

這`createFaithfulnessScorer()`函數評估法學碩士輸出與所提供的上下文相比的事實準確性。它從輸出中提取聲明並根據上下文驗證它們。用它來檢查檢索到的信息是否支援 RAG 回應。

## 評分詳情 {/* #scoring-details */}

評分者透過針對所提供的上下文進行聲明驗證來評估忠誠度。

### 評分流程 {/* #scoring-process */}

1. 分析主張與背景：
   * 提取所有主張（事實和推測）
   * 根據上下文驗證每個聲明
   * 指定三個判決之一：
     * 「是」——上下文支持的主張
     * 「不」——主張與上下文相矛盾
     * “不確定”- 聲明無法驗證
2. 計算忠誠度分數：
   * 支援的聲明計數
   * 除以索賠總額
   * 縮放至有效範圍

最終成績：`(supported_claims / total_claims) * effective_scale`, where `effective_scale` is `scale || 1`

### 分數解讀 {/* #score-interpretation */}

忠誠度分數介於 0 和有效等級（預設 1）之間。使用預設比例：

* **1.0**：所有主張均準確且有上下文直接支持。
* **0.7至0.9**：大多數說法都是正確的，僅有少量補充或遺漏。
* **0.4至0.6**：有些說法得到支持，但其他說法無法證實。
* **0.1至0.3**：大多數內容不準確或不受支援。
* **0.0**：所有說法都是錯誤的或與上​​下文相矛盾。

## 例子 {/* #example */}

評估Agent回應是否忠於所提供的脈絡：

```typescript title="src/example-faithfulness.ts"
import { runEvals } from '@mastra/core/evals'
import { createFaithfulnessScorer } from '@mastra/evals/scorers/prebuilt'
import { myAgent } from './agent'

// Context is typically populated from agent tool calls or RAG retrieval
const scorer = createFaithfulnessScorer({
  model: '__GATEWAY_OPENAI_MODEL__',
})

const result = await runEvals({
  data: [
    {
      input: 'Tell me about the Tesla Model 3.',
    },
    {
      input: 'What are the key features of this electric vehicle?',
    },
  ],
  scorers: [scorer],
  target: myAgent,
  onItemComplete: ({ scorerResults }) => {
    console.log({
      score: scorerResults[scorer.id].score,
      reason: scorerResults[scorer.id].reason,
    })
  },
})

console.log(result.scores)
```

欲了解更多詳情`runEvals`, see the [runEvals reference](/reference/evals/run-evals).

若要將此記分員新增至Agent，請參閱[Scorers overview](/docs/evals/overview#adding-scorers-to-agents) guide.
