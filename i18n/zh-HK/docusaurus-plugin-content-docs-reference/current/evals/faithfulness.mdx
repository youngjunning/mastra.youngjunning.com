# 忠實度評分器

`createFaithfulnessScorer()` 函式根據提供的上下文評估 LLM 輸出的事實準確性。它從輸出擷取主張，逐項對照上下文核驗。可用來檢查 RAG 回答是否有檢索結果作為依據。

## 評分詳情 {/* #scoring-details */}

評分器透過對照提供的上下文核驗各項主張，評估輸出的忠實度。

### 評分流程 {/* #scoring-process */}

1. 分析主張與上下文：
   * 擷取所有主張（包括事實性及推測性主張）
   * 對照上下文核驗每項主張
   * 給出以下三種判定之一：
     * 「yes」——上下文支持該主張
     * 「no」——該主張與上下文矛盾
     * 「unsure」——無法核驗該主張
2. 計算忠實度分數：
   * 計算獲得支持的主張數
   * 除以主張總數
   * 按有效量表換算

最終分數：`(supported_claims / total_claims) * effective_scale`，其中 `effective_scale` 為 `scale || 1`。

### 分數解讀 {/* #score-interpretation */}

忠實度分數介乎 0 與有效最高分之間（預設最高分為 1）。使用預設量表時：

* **1.0**：所有主張都準確，且有上下文直接支持。
* **0.7 至 0.9**：大多數主張正確，只有少量補充或遺漏。
* **0.4 至 0.6**：部分主張獲得支持，其他主張無法核驗。
* **0.1 至 0.3**：大部分內容不準確，或缺乏上下文支持。
* **0.0**：所有主張都錯誤，或與上下文矛盾。

## 例子 {/* #example */}

評估 Agent 回答是否忠於提供的上下文：

```typescript title="src/example-faithfulness.ts"
import { runEvals } from '@mastra/core/evals'
import { createFaithfulnessScorer } from '@mastra/evals/scorers/prebuilt'
import { myAgent } from './agent'

// Context is typically populated from agent tool calls or RAG retrieval
const scorer = createFaithfulnessScorer({
  model: '__GATEWAY_OPENAI_MODEL__',
})

const result = await runEvals({
  data: [
    {
      input: 'Tell me about the Tesla Model 3.',
    },
    {
      input: 'What are the key features of this electric vehicle?',
    },
  ],
  scorers: [scorer],
  target: myAgent,
  onItemComplete: ({ scorerResults }) => {
    console.log({
      score: scorerResults[scorer.id].score,
      reason: scorerResults[scorer.id].reason,
    })
  },
})

console.log(result.scores)
```

如需了解 `runEvals` 的詳細資料，請參閱 [runEvals 參考文件](/reference/evals/run-evals)。

如需將此評分器加入 Agent，請參閱[評分器概覽](/docs/evals/overview#adding-scorers-to-agents)指南。
