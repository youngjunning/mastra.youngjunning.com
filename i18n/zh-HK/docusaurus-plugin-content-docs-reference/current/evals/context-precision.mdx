# 上下文精確度評分器

`createContextPrecisionScorer()` 函數建立一個評分器，評估檢索到的上下文片段與產生預期輸出的相關程度，以及這些片段在序列中的位置。它使用**平均精確度均值 (MAP)**，讓將相關上下文排在前面的系統獲得較高分數。

它特別適用於以下情境：

## RAG 系統評估 {/* #rag-system-evaluation */}

適合評估 RAG 流程中檢索到的上下文，尤其在以下情況：

* 上下文的排列順序會影響模型效能
* 需要衡量基本相關性以外的檢索質素
* 排在前面的相關上下文比排在後面的更有價值

## 上下文視窗優化 {/* #context-window-optimization */}

在為以下情況優化上下文選擇時使用：

* 上下文視窗有限
* Token 預算受限
* 多步驟推理任務

`context` 與 `contextExtractor` 至少須提供其中一個。只有運行輸入及輸出符合 Agent 的資料結構時，才會調用 `contextExtractor`：輸入須包含 `inputMessages`、`rememberedMessages` 與 `systemMessages` 陣列，以及 `taggedSystemMessages` 物件；輸出須為訊息陣列。若輸入或輸出採用其他結構，評分器會使用 `context`。兩者都未提供時，評分器會拋出錯誤。

若傳入 `context`，陣列不得為空。建構函數會對空陣列拋出 `Context array cannot be empty if provided`，即使同時配置 `contextExtractor` 也是如此。若只配置 `contextExtractor`，但運行資料不符合 Agent 的資料結構，就沒有可供評分的上下文，評估時會拋出 `No context available for evaluation`。

## 評分詳情 {/* #scoring-details */}

### 平均精確度均值 (MAP) {/* #mean-average-precision-map */}

上下文精確度使用**平均精確度均值 (MAP)**，同時評估上下文的相關性與排列位置：

1. **上下文評估**：判斷每個上下文片段是否與產生預期輸出相關
2. **精確度計算**：對於位置為 `i` 的每個相關上下文，precision = `relevant_items_so_far / (i + 1)`
3. **平均精確度**：將所有精確度值加總，再除以相關片段總數
4. **最終分數**：乘以縮放係數，再四捨五入至小數點後兩位

### 評分公式 {/* #scoring-formula */}

```text
MAP = (Σ Precision@k) / R

Where:
- Precision@k = (relevant items in positions 1...k) / k
- R = total number of relevant items
- Only calculated at positions where relevant items appear
```

### 分數解讀 {/* #score-interpretation */}

* **0.9-1.0**：精確度極高，所有相關上下文都排在序列前面
* **0.7-0.8**：精確度較高，大部分相關上下文都排在合適的位置
* **0.4-0.6**：精確度中等，相關與不相關的上下文交錯排列
* **0.1-0.3**：精確度較低，相關上下文很少，或排序位置不佳
* **0.0**：未找到相關上下文

### 原因分析 {/* #reason-analysis */}

原因欄位會說明：

* 哪些上下文片段被判定為相關或不相關
* 排列位置如何影響 MAP 計算
* 評估時採用了哪些具體的相關性標準

### 優化建議 {/* #optimization-insights */}

可以依據結果：

* **改善檢索**：在排序前過濾不相關的上下文
* **優化排序**：讓相關上下文盡量排在前面
* **調整分塊大小**：兼顧上下文細節與相關性精確度
* **評估嵌入模型**：測試不同的嵌入模型，以改善檢索效果

### 計算範例 {/* #example-calculation */}

上下文：`[relevant, irrelevant, relevant, irrelevant]`

* 位置 0：相關 → 精度 = 1/1 = 1.0
* 位置 1：跳過（不相關）
* 位置 2：相關 → 精度 = 2/3 = 0.67
* 位置 3：跳過（不相關）

MAP = (1.0 + 0.67) / 2 = 0.835 ≈ **0.83**

## 評分器配置 {/* #scorer-configuration */}

### 動態上下文提取 {/* #dynamic-context-extraction */}

```typescript
const scorer = createContextPrecisionScorer({
  model: '__GATEWAY_OPENAI_MODEL__',
  options: {
    contextExtractor: (input, output) => {
      // Extract context dynamically based on the query
      const query = input?.inputMessages?.[0]?.content || ''

      // Example: Retrieve from a vector database
      const searchResults = vectorDB.search(query, { limit: 10 })
      return searchResults.map(result => result.content)
    },
    scale: 1,
  },
})
```

### 大量上下文的評估 {/* #large-context-evaluation */}

```typescript
const scorer = createContextPrecisionScorer({
  model: '__GATEWAY_OPENAI_MODEL__',

    context: [

      'Document 1: Highly relevant content...',
      'Document 2: Somewhat related content...',
      'Document 3: Tangentially related...',
      'Document 4: Not relevant...',
      'Document 5: Highly relevant content...',
      // ... up to dozens of context pieces
    ],
  },
})
```

## 示例 {/* #example */}

評估 RAG 系統針對不同查詢檢索上下文的精確度：

```typescript title="src/example-context-precision.ts"
import { runEvals } from '@mastra/core/evals'
import { createContextPrecisionScorer } from '@mastra/evals/scorers/prebuilt'
import { myAgent } from './agent'

const scorer = createContextPrecisionScorer({
  model: '__GATEWAY_OPENAI_MODEL__',
  options: {
    contextExtractor: (input, output) => {
      // Extract context from agent's retrieved documents
      return output.metadata?.retrievedContext || []
    },
  },
})

const result = await runEvals({
  data: [
    {
      input: 'How does photosynthesis work in plants?',
    },
    {
      input: 'What are the mental and physical benefits of exercise?',
    },
  ],
  scorers: [scorer],
  target: myAgent,
  onItemComplete: ({ scorerResults }) => {
    console.log({
      score: scorerResults[scorer.id].score,
      reason: scorerResults[scorer.id].reason,
    })
  },
})

console.log(result.scores)
```

如欲進一步了解 `runEvals`，請參閱 [runEvals 參考文件](/reference/evals/run-evals)。

若要將此評分器加入 Agent，請參閱[評分器概覽](/docs/evals/overview#adding-scorers-to-agents)指南。

## 與上下文相關性比較 {/* #comparison-with-context-relevance */}

依需求選擇合適的評分器：

|使用場景|上下文相關性 |上下文精確度 |
| - | - | - |
|**RAG 評估** | 著重上下文是否被使用 | 著重上下文的排序 |
| **上下文質素** | 區分細緻的相關性程度 | 只區分相關與不相關 |
| **缺漏檢測** | ✓ 識別資訊缺口 | ✗ 不評估 |
| **使用情況追蹤** | ✓ 追蹤上下文的使用情況 | ✗ 不考慮 |
| **位置敏感性** | ✗ 不考慮排列位置 | ✓ 對靠前的位置給予較高分數 |
