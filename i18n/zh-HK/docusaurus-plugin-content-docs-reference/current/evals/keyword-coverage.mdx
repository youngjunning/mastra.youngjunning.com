# 關鍵字覆蓋率評分器

這`createKeywordCoverageScorer()`函數評估法學碩士的輸出涵蓋輸入中重要關鍵字的程度。它分析關鍵字的存在和匹配，同時忽略常用字和停用詞。

## 參數 {/* #parameters */}

這`createKeywordCoverageScorer()` function doesn't take any options.

此函數傳回 MastraScorer 類別的實例。請參閱[MastraScorer reference](./mastra-scorer) for details on the `.run()` method and its input/output.

## 評分詳情 {/* #scoring-details */}

評分器透過將關鍵字與以下特徵進行配對來評估關鍵字覆蓋率：

* 常用字和停用詞過濾（例如“the”、“a”、“and”）
* 不區分大小寫的匹配
* 詞形變異處理
* 對技術術語和複合詞的特殊處理

### 評分流程 {/* #scoring-process */}

1. 處理輸入和輸出中的關鍵字：
   * 過濾掉常用詞和停用詞
   * 規範大小寫和單字形式
   * 處理特殊術語和複合詞
2. 計算關鍵字覆蓋率：
   * 匹配文字之間的關鍵字
   * 計算成功匹配的次數
   * 計算覆蓋率

最終成績：`(matched_keywords / total_keywords) * scale`

### 分數解讀 {/* #score-interpretation */}

覆蓋率分數介於 0 和 1 之間：

* **1.0**：完整覆蓋，所有關鍵字都存在。
* **0.7至0.9**：覆蓋率高，收錄最多關鍵字。
* **0.4至0.6**：部分覆蓋，存在一些關鍵字。
* **0.1至0.3**：覆蓋率低，配對的關鍵字很少。
* **0.0**：回應中不包含任何關鍵字。

### 特殊情況 {/* #special-cases */}

記分員處理幾種特殊情況：

* 空輸入/輸出：如果兩者都為空，則傳回 1.0，如果只有一個為空，則傳回 0.0
* 單字：視為單一關鍵字
* 技術術語：保留複合技術術語（例如“React.js”、“機器學習”）
* 大小寫差異：“JavaScript”匹配“javascript”
* 常用詞：在評分時忽略以專注於有用的關鍵字

## 例子 {/* #example */}

評估輸入查詢和Agent回應之間的關鍵字覆蓋率：

```typescript title="src/example-keyword-coverage.ts"
import { runEvals } from '@mastra/core/evals'
import { createKeywordCoverageScorer } from '@mastra/evals/scorers/prebuilt'
import { myAgent } from './agent'

const scorer = createKeywordCoverageScorer()

const result = await runEvals({
  data: [
    {
      input: 'JavaScript frameworks like React and Vue',
    },
    {
      input: 'TypeScript offers interfaces, generics, and type inference',
    },
    {
      input:
        'Machine learning models require data preprocessing, feature engineering, and hyperparameter tuning',
    },
  ],
  scorers: [scorer],
  target: myAgent,
  onItemComplete: ({ scorerResults }) => {
    console.log({
      score: scorerResults[scorer.id].score,
    })
  },
})

console.log(result.scores)
```

欲了解更多詳情`runEvals`, see the [runEvals reference](/reference/evals/run-evals).

若要將此記分員新增至Agent，請參閱[Scorers overview](/docs/evals/overview#adding-scorers-to-agents) guide.
