# 關鍵字覆蓋率評分器

`createKeywordCoverageScorer()` 函式評估 LLM 輸出覆蓋輸入中重要關鍵字的程度。它會檢查關鍵字是否出現及是否匹配，並忽略常見字詞和停用詞。

## 參數 {/* #parameters */}

`createKeywordCoverageScorer()` 函式不接受任何選項。

此函式傳回 MastraScorer 類別的實例。有關 `.run()` 方法及其輸入與輸出，請參閱 [MastraScorer 參考文件](./mastra-scorer)。

## 評分詳情 {/* #scoring-details */}

評分器透過匹配關鍵字評估覆蓋率，具備以下特點：

- 過濾常見字詞和停用詞（例如「the」、「a」、「and」）
- 匹配時不區分大小寫
- 處理詞形變化
- 特別處理技術術語和複合字詞

### 評分流程 {/* #scoring-process */}

1. 處理輸入及輸出中的關鍵字：
   - 過濾常見字詞和停用詞
   - 統一大小寫及詞形
   - 處理特殊術語及複合字詞
1. 計算關鍵字覆蓋率：
   - 匹配兩段文字中的關鍵字
   - 計算成功匹配的數量
   - 計算覆蓋比例

最終分數：`(matched_keywords / total_keywords) * scale`

### 分數解讀 {/* #score-interpretation */}

覆蓋率分數介乎 0 至 1：

- **1.0**：完全覆蓋，所有關鍵字都出現。
- **0.7 至 0.9**：覆蓋率高，包含大部分關鍵字。
- **0.4 至 0.6**：部分覆蓋，包含部分關鍵字。
- **0.1 至 0.3**：覆蓋率低，僅匹配到少量關鍵字。
- **0.0**：回應中不包含任何關鍵字。

### 特殊情況 {/* #special-cases */}

評分器亦會處理以下特殊情況：

- 輸入及輸出為空：兩者皆為空時傳回 1.0，只有其中一者為空時傳回 0.0
- 單一字詞：視為一個關鍵字
- 技術術語：保留複合技術術語（例如「React.js」、「機器學習」）
- 大小寫差異：「JavaScript」可匹配「javascript」
- 常見字詞：評分時予以忽略，以聚焦有用的關鍵字

## 範例 {/* #example */}

評估輸入查詢與 Agent 回應之間的關鍵字覆蓋率：

```typescript title="src/example-keyword-coverage.ts"
import { runEvals } from '@mastra/core/evals'
import { createKeywordCoverageScorer } from '@mastra/evals/scorers/prebuilt'
import { myAgent } from './agent'

const scorer = createKeywordCoverageScorer()

const result = await runEvals({
  data: [
    {
      input: 'JavaScript frameworks like React and Vue',
    },
    {
      input: 'TypeScript offers interfaces, generics, and type inference',
    },
    {
      input:
        'Machine learning models require data preprocessing, feature engineering, and hyperparameter tuning',
    },
  ],
  scorers: [scorer],
  target: myAgent,
  onItemComplete: ({ scorerResults }) => {
    console.log({
      score: scorerResults[scorer.id].score,
    })
  },
})

console.log(result.scores)
```

有關 `runEvals` 的詳情，請參閱 [runEvals 參考文件](/reference/evals/run-evals)。

如需將此評分器加入 Agent，請參閱[評分器概覽](/docs/evals/overview#adding-scorers-to-agents)指南。
