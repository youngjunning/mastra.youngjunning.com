# Hallucination 評分器

`createHallucinationScorer()` 函式會比較 LLM 輸出與所提供的上下文，評估產生的資訊是否符合事實。此評分器透過找出上下文與輸出之間的直接矛盾，衡量幻覺程度。

## 評分詳情 {/* #scoring-details */}

評分器透過檢測矛盾並分析缺乏依據的陳述，評估幻覺。

### 評分流程 {/* #scoring-process */}

1. 從輸出中擷取陳述：
   * 將 Agent 回應拆解為事實陳述
   * 包括數值和日期
2. 按所提供的上下文核對每項陳述：
   * 比較陳述與上下文
   * 將直接矛盾標記為幻覺
   * 將缺乏依據的陳述識別為幻覺
   * 評估數值準確性
   * 考慮上下文中的近似表達
3. 計算幻覺分數：
   * 統計存在幻覺的陳述（相互矛盾或缺乏依據的陳述）
   * 除以陳述總數
   * 按設定的範圍縮放分數

最終分數為 `min(1, hallucinated_statements / total_statements) * (scale || 1)`；當 `total_statements > 0` 時四捨五入至小數點後兩位，否則為 `0`。

### 重要考慮因素 {/* #important-considerations */}

* 上下文中未出現的陳述會視為幻覺
* 除非有明確依據，否則主觀陳述亦會視為幻覺
* 對上下文中已有的事實，可以使用推測性措辭（如「可能」、「或許」）
* 對上下文中不存在的事實使用推測性措辭，仍會視為幻覺
* 空輸出的幻覺數量為零
* 數值評估會考慮：
  * 與數值規模相稱的精確度
  * 按上下文可接受的近似值
  * 明確的精確度標示

### 分數解讀 {/* #score-interpretation */}

幻覺分數介乎 0 與 `scale` 之間（預設 scale 下為 0 到 1）。以下範圍以預設 scale 為準：

* **0.0**：沒有幻覺，所有陳述都與上下文一致。
* **0.3 至 0.4**：幻覺程度低，只有少量矛盾。
* **0.5 至 0.6**：幻覺程度中等，存在多處矛盾。
* **0.7 至 0.8**：幻覺程度高，存在大量矛盾。
* **0.9 至 1.0**：幻覺程度極高，大部分或全部陳述與上下文矛盾。

分數代表幻覺程度：分數越低，與所提供上下文的事實一致程度越高。

## 範例 {/* #examples */}

### 靜態上下文 {/* #static-context */}

已有可供比較的事實依據時，請使用靜態上下文：

```typescript title="src/example-static-context.ts"
import { createHallucinationScorer } from '@mastra/evals/scorers/prebuilt'

const scorer = createHallucinationScorer({
  model: '__GATEWAY_OPENAI_MODEL__',
  options: {
    context: [
      'The first iPhone was announced on January 9, 2007.',
      'It was released on June 29, 2007.',
      'Steve Jobs introduced it at Macworld.',
    ],
  },
})
```

### 使用 `getContext` 動態取得上下文 {/* #dynamic-context-with-getcontext */}

如上下文來自工具結果，可使用 `getContext` 進行即時評分：

```typescript title="src/example-dynamic-context.ts"
import { createHallucinationScorer } from '@mastra/evals/scorers/prebuilt'
import { extractToolResults } from '@mastra/evals/scorers/utils'

const scorer = createHallucinationScorer({
  model: '__GATEWAY_OPENAI_MODEL__',
  options: {
    getContext: ({ run, step }) => {
      // Extract tool results as context
      const toolResults = extractToolResults(run.output)
      return toolResults.map(t => JSON.stringify({ tool: t.toolName, result: t.result }))
    },
  },
})
```

### 對 Agent 即時評分 {/* #live-scoring-with-agent */}

將評分器加入 Agent，以進行即時評估：

```typescript title="src/example-live-scoring.ts"
import { Agent } from '@mastra/core/agent'
import { createHallucinationScorer } from '@mastra/evals/scorers/prebuilt'
import { extractToolResults } from '@mastra/evals/scorers/utils'

const hallucinationScorer = createHallucinationScorer({
  model: '__GATEWAY_OPENAI_MODEL__',
  options: {
    getContext: ({ run }) => {
      const toolResults = extractToolResults(run.output)
      return toolResults.map(t => JSON.stringify({ tool: t.toolName, result: t.result }))
    },
  },
})

const agent = new Agent({
  id: 'my-agent',
  name: 'my-agent',
  model: '__GATEWAY_OPENAI_MODEL__',
  instructions: 'You are a helpful assistant.',
  evals: {
    scorers: [hallucinationScorer],
  },
})
```

### 使用 `runEvals` 批量評估 {/* #batch-evaluation-with-runevals */}

```typescript title="src/example-batch-evals.ts"
import { runEvals } from '@mastra/core/evals'
import { createHallucinationScorer } from '@mastra/evals/scorers/prebuilt'
import { myAgent } from './agent'

const scorer = createHallucinationScorer({
  model: '__GATEWAY_OPENAI_MODEL__',
  options: {
    context: ['Known fact 1', 'Known fact 2'],
  },
})

const result = await runEvals({
  data: [{ input: 'Tell me about topic A' }, { input: 'Tell me about topic B' }],
  scorers: [scorer],
  target: myAgent,
  onItemComplete: ({ scorerResults }) => {
    console.log({
      score: scorerResults[scorer.id].score,
      reason: scorerResults[scorer.id].reason,
    })
  },
})

console.log(result.scores)
```

如需進一步了解 `runEvals`，請參閱 [runEvals 參考文件](/reference/evals/run-evals)。

如要將此評分器加入 Agent，請參閱 [Scorers 概覽](/docs/evals/overview#adding-scorers-to-agents)指南。
