# 幻覺記分員

這`createHallucinationScorer()`函數透過將其輸出與提供的上下文進行比較來評估法學碩士是否產生事實上正確的資訊。此評分器透過識別上下文和輸出之間的直接矛盾來測量幻覺。

## 評分詳情 {/* #scoring-details */}

評分者透過矛盾檢測和無支持的主張分析來評估幻覺。

### 評分流程 {/* #scoring-process */}

1. 從輸出中提取聲明：
   * 將Agent的回應分解為事實主張
   * 包括數值和日期
2. 根據提供的上下文檢查每個聲明：
   * 將主張與上下文進行比較
   * 將直接衝突標記為幻覺
   * 將不受支持的主張視為幻覺
   * 評估數值準確性
   * 考慮近似上下文
3. 計算幻覺分數：
   * 計算幻覺陳述（矛盾和無根據的主張）
   * 除以報表總數
   * 縮放至配置範圍

最終成績：`min(1, hallucinated_statements / total_statements) * (scale || 1)`, rounded to two decimal places, when `total_statements > 0`, otherwise `0`.

### 重要考慮因素 {/* #important-considerations */}

* 上下文中不存在的主張被視為幻覺
*
*
* 與上下文無關的事實的推測性語言被視為幻覺
* 空輸出導致零幻覺
*
  * 適合比例的精度
  * 上下文近似
  * 明確的精度指標

### 分數解讀 {/* #score-interpretation */}

幻覺分數介於 0 和`scale` (0 to 1 with the default scale). The ranges below assume the default scale:

* **0.0**：沒有幻覺，所有說法都符合上下文。
* **0.3至0.4**：低幻覺，一些矛盾。
* **0.5至0.6**：混合幻覺，幾個矛盾。
* **0.7至0.8**：高度幻覺，很多矛盾。
* **0.9至1.0**：完全是幻覺，大多數或所有說法與上下文相矛盾。

分數代表幻覺的程度 - 分數越低表示事實與所提供的背景更好地吻合

## 範例 {/* #examples */}

### 靜態情境 {/* #static-context */}

當您知道基本事實以進行比較時，請使用靜態上下文：

```typescript title="src/example-static-context.ts"
import { createHallucinationScorer } from '@mastra/evals/scorers/prebuilt'

const scorer = createHallucinationScorer({
  model: '__GATEWAY_OPENAI_MODEL__',
  options: {
    context: [
      'The first iPhone was announced on January 9, 2007.',
      'It was released on June 29, 2007.',
      'Steve Jobs introduced it at Macworld.',
    ],
  },
})
```

### 動態情境`getContext` {/* #dynamic-context-with-getcontext */}

使用`getContext` for live scoring scenarios where context comes from tool results:

```typescript title="src/example-dynamic-context.ts"
import { createHallucinationScorer } from '@mastra/evals/scorers/prebuilt'
import { extractToolResults } from '@mastra/evals/scorers/utils'

const scorer = createHallucinationScorer({
  model: '__GATEWAY_OPENAI_MODEL__',
  options: {
    getContext: ({ run, step }) => {
      // Extract tool results as context
      const toolResults = extractToolResults(run.output)
      return toolResults.map(t => JSON.stringify({ tool: t.toolName, result: t.result }))
    },
  },
})
```

### 與Agent即時計分 {/* #live-scoring-with-agent */}

將記分器連接到Agent進行即時評估：

```typescript title="src/example-live-scoring.ts"
import { Agent } from '@mastra/core/agent'
import { createHallucinationScorer } from '@mastra/evals/scorers/prebuilt'
import { extractToolResults } from '@mastra/evals/scorers/utils'

const hallucinationScorer = createHallucinationScorer({
  model: '__GATEWAY_OPENAI_MODEL__',
  options: {
    getContext: ({ run }) => {
      const toolResults = extractToolResults(run.output)
      return toolResults.map(t => JSON.stringify({ tool: t.toolName, result: t.result }))
    },
  },
})

const agent = new Agent({
  id: 'my-agent',
  name: 'my-agent',
  model: '__GATEWAY_OPENAI_MODEL__',
  instructions: 'You are a helpful assistant.',
  evals: {
    scorers: [hallucinationScorer],
  },
})
```

### 批量評估`runEvals` {/* #batch-evaluation-with-runevals */}

```typescript title="src/example-batch-evals.ts"
import { runEvals } from '@mastra/core/evals'
import { createHallucinationScorer } from '@mastra/evals/scorers/prebuilt'
import { myAgent } from './agent'

const scorer = createHallucinationScorer({
  model: '__GATEWAY_OPENAI_MODEL__',
  options: {
    context: ['Known fact 1', 'Known fact 2'],
  },
})

const result = await runEvals({
  data: [{ input: 'Tell me about topic A' }, { input: 'Tell me about topic B' }],
  scorers: [scorer],
  target: myAgent,
  onItemComplete: ({ scorerResults }) => {
    console.log({
      score: scorerResults[scorer.id].score,
      reason: scorerResults[scorer.id].reason,
    })
  },
})

console.log(result.scores)
```

欲了解更多詳情`runEvals`, see the [runEvals reference](/reference/evals/run-evals).

若要將此記分員新增至Agent，請參閱[Scorers overview](/docs/evals/overview#adding-scorers-to-agents) guide.
