# 文字差異評分器

這`createTextualDifferenceScorer()`函數使用序列匹配來測量兩個字串之間的文字差異。它提供有關更改的詳細信息，包括將一種文字轉換為另一種文字所需的操作數量。

## 參數 {/* #parameters */}

這`createTextualDifferenceScorer()` function doesn't take any options.

此函數傳回 MastraScorer 類別的實例。請參閱[MastraScorer reference](./mastra-scorer) for details on the `.run()` method and its input/output.

## 評分詳情 {/* #scoring-details */}

記分員計算幾個指標：

* **相似率**：基於文字之間的序列匹配（0-1）
* **變化**：需要的不匹配操作的計數
* **長度差**：文字長度的標準化差異
* **信心**：與長度差成反比

### 評分流程 {/* #scoring-process */}

1. 分析文本差異：
   * 執行輸入和輸出之間的序列匹配
   * 計算所需更改操作的數量
   * 測量長度差異
2. 計算指標：
   * 計算相似率
   * 確定置信度分數
   * 合併為加權分數

最終成績：`(similarity_ratio * confidence) * scale`

### 分數解讀 {/* #score-interpretation */}

0 和 1 之間的文字差異分數：

* **1.0**: 文字是一樣的。
* **0.7至0.9**：細微差別，需要很少的改變。
* **0.4至0.6**：中等差異，需要顯著改變。
* **0.1至0.3**：主要差異，需要進行大量更改。
* **0.0**: 完全不同的文字。

## 例子 {/* #example */}

測量預期和實際Agent輸出之間的文字差異：

```typescript title="src/example-textual-difference.ts"
import { runEvals } from '@mastra/core/evals'
import { createTextualDifferenceScorer } from '@mastra/evals/scorers/prebuilt'
import { myAgent } from './agent'

const scorer = createTextualDifferenceScorer()

const result = await runEvals({
  data: [
    {
      input: 'Summarize the concept of recursion',
      groundTruth:
        'Recursion is when a function calls itself to solve a problem by breaking it into smaller subproblems.',
    },
    {
      input: 'What is the capital of France?',
      groundTruth: 'The capital of France is Paris.',
    },
  ],
  scorers: [scorer],
  target: myAgent,
  onItemComplete: ({ scorerResults }) => {
    console.log({
      score: scorerResults[scorer.id].score,
      groundTruth: scorerResults[scorer.id].groundTruth,
    })
  },
})

console.log(result.scores)
```

欲了解更多詳情`runEvals`, see the [runEvals reference](/reference/evals/run-evals).

若要將此記分員新增至Agent，請參閱[Scorers overview](/docs/evals/overview#adding-scorers-to-agents) guide.
