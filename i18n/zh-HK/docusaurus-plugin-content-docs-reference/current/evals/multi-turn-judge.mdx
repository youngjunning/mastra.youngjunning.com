# 多輪裁判記分員

**添加於：** `@mastra/evals@1.9.0`

這`createMultiTurnJudgeScorer()` function creates an LLM-as-judge scorer that grades a whole conversation against a single plain-English criterion. It returns a **binary**分數：`1`當滿足標準時，否則`0`，以及`reason`與法官的解釋相呼應。

與其他預置的 LLM 法官讀取一條助理訊息不同，該記分員會讀取累積的每個助理輪次。`run.output`, so it works with the [multi-turn `inputs`](/docs/evals/multi-turn) form of [`runEvals()`](/reference/evals/run-evals).

## 多輪評估的用法 {/* #usage-with-multi-turn-evals */}

將得分手傳給`runEvals` alongside an `inputs` array. Every assistant turn is included in the prompt sent to the judge:

```typescript title="src/evals/trip-planning-eval.ts"
import { runEvals } from '@mastra/core/evals'
// highlight-next-line
import { createMultiTurnJudgeScorer } from '@mastra/evals/scorers/prebuilt'
import { weatherAgent } from '../agents'

const result = await runEvals({
  data: [
    {
      inputs: [
        "I'm planning a trip to London, Paris, and Tokyo next week.",
        "How's the weather looking in London?",
        'And Paris?',
        'Tokyo too?',
        'Should I pack an umbrella for the London leg?',
      ],
    },
  ],
  target: weatherAgent,
  scorers: [
    {
      // highlight-start
      scorer: createMultiTurnJudgeScorer({
        model: '__GATEWAY_ANTHROPIC_MODEL_HAIKU__',
        criterion:
          'The agent provided weather forecasts for London, Paris, and Tokyo, and gave weather-appropriate packing or clothing advice.',
      }),
      // highlight-end
      threshold: 1,
    },
  ],
})
```

使用`threshold: 1` to turn the verdict into a pass or fail: the score is binary, so any lower threshold always passes.

## 持續分數 {/* #persisting-scores */}

只有當具有相同 ID 的記分器在 Mastra 實例上註冊時，分數才會寫入分數存儲，因為持久性透過以下方式解析記分器元資料：`Mastra.getScorerById()`. Only the ID is looked up, so the registered instance's `criterion` can be a placeholder:

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { LibSQLStore } from '@mastra/libsql'
import { createMultiTurnJudgeScorer } from '@mastra/evals/scorers/prebuilt'

export const mastra = new Mastra({
  agents: { weatherAgent },
  storage: new LibSQLStore({ url: 'file:./mastra.db' }),
  scorers: {
    // highlight-start
    'multi-turn-judge-scorer': createMultiTurnJudgeScorer({
      model: '__GATEWAY_ANTHROPIC_MODEL_HAIKU__',
      criterion: 'placeholder',
    }),
    // highlight-end
  },
})
```

看[Score persistence](/docs/evals/overview#score-persistence) for the full requirement and the warning you get when a scorer isn't registered.

## 評分詳情 {/* #scoring-details */}

記分器分兩個階段運作：

1. **年級**: 助理訊息`run.output` form a numbered transcript that the judge evaluates as a whole against the criterion. Turns containing only tool calls or otherwise lacking text are skipped.
2. **分數**: 一個`satisfied` verdict scores `1` and anything else scores `0`, multiplied by `scale`.

法官只看到助理說的話。不包括用戶的回合和任何Tool結果，因此根據Agent的回應編寫標準。這使得評分文字僅限於Agent自己的輸出，但這也意味著只有在提示它的問題旁邊才有意義的答案（「是的，帶一個。」）不能單獨判斷。對於取決於使用者回合的標準，對每個回合進行評分`turns[].scorers` or write a [custom scorer](/docs/evals/multi-turn) that renders both roles.

記錄作為不受信任的資料傳遞給法官，並用明確的分隔符號和忽略其中任何讀取為指令的指令的指令進行隔離，因此Agent回應無法透過對話形成通過的判決。
