# 快速檢查

Quick Checks 是零法學碩士、可組合的微型評分器，適用於常見斷言。他們插入現有的`scorers: [...]`使用記分器的任何地方的陣列：在`runEvals`、現場評分、實驗和工作室。

在內部它們是標準的`createScorer()` instances, so they have the same observability, storage, and pipeline integration as any other scorer.

:::note\[註冊檢查以保留其分數]

僅當檢查在 Mastra 實例上註冊時，檢查的分數才會寫入分數存儲，同時`storage`. Each check has a fixed id (`checks.includes()` is `check-includes`, `checks.calledTool()`是`check-called-tool`，等等），因此一個註冊實例涵蓋了該檢查的每一次使用，無論其參數為何。看[分數持久性](/docs/evals/overview#score-persistence).

:::

## 使用範例 {/* #usage-example */}

```typescript title="src/evals/weather-checks.ts"
import { checks } from '@mastra/evals/checks'
import { runEvals } from '@mastra/core/evals'
import { myAgent } from '../agents'

const result = await runEvals({
  data: [{ input: 'What is the weather in Brooklyn?' }],
  target: myAgent,
  scorers: [
    checks.includes('sunny'),
    checks.calledTool('get_weather'),
    checks.toolOrder(['get_weather', 'summarize']),
    checks.noToolErrors(),
  ],
})

console.log(result.scores)
```

## 文字檢查 {/* #text-checks */}

如果Agent的輸出文字包含預期的子字串，則得分 1，否則得分 0。

## Tool呼叫檢查 {/* #tool-call-checks */}

### `checks.calledTool(toolName, options?)` {/* #checkscalledtooltoolname-options */}

如果Agent呼叫指定Tool至少達到要求的次數，則得分 1。

如果按指定順序呼叫Tool，則得分 1。使用寬鬆的匹配。允許預期Tool之間的其他Tool呼叫。

### `checks.maxToolCalls(max)` {/* #checksmaxtoolcallsmax */}

如果Agent使用的數量不超過，則得分 1`max` tool calls.


### `checks.usedNoTools()` {/* #checksusednotools */}

如果Agent根本沒有呼叫任何Tool，則得分 1。

```typescript
checks.usedNoTools()
```

返回：`1` if no tools were called, `0` otherwise.

### `checks.noToolErrors()` {/* #checksnotoolerrors */}

如果沒有任何Tool呼叫導致錯誤狀態，則得分 1。偵測到兩個錯誤結果（`result.error` present) and incomplete tool calls (`state === 'call'`).

```typescript
checks.noToolErrors()
```

返回：`1` if all tool calls succeeded, `0` otherwise.

## 與其他記分員結合檢查 {/* #combining-checks-with-other-scorers */}

檢查使用基於 LLM 和基於代碼的評分器在同一`scorers` array:

```typescript title="src/evals/combined-eval.ts"
import { checks } from '@mastra/evals/checks'
import { createAnswerRelevancyScorer } from '@mastra/evals/scorers/prebuilt'
import { runEvals } from '@mastra/core/evals'
import { myAgent } from '../agents'

const result = await runEvals({
  data: [{ input: 'What is the weather in Brooklyn?' }],
  target: myAgent,
  scorers: [
    // Zero-LLM checks
    checks.includes('Brooklyn'),
    checks.calledTool('get_weather'),
    checks.noToolErrors(),
    // LLM-based scorer
    createAnswerRelevancyScorer({ model: '__GATEWAY_OPENAI_MODEL_LUNA__' }),
  ],
})
```

## 多回合行為 {/* #multi-turn-behavior */}

檢查讀取累計`run.output`, so in a [multi-turn eval](/docs/evals/multi-turn) they see every turn. `checks.calledTool('get_weather', { times: 2 })` counts calls across the whole conversation, and `checks.includes()` searches all assistant text. Use per-turn `turns[].scorers` when a specific turn has to satisfy the check.
