# filterRun()

根據宣告式選項建立 `prepareRun` 函式。將結果傳給 `createScorer()`，以篩選訊息及限制上下文大小。在評分器流程執行前，亦會移除不需要的欄位。

使用 [`filterRun()`](#usage-example) 進行宣告式篩選。如需命令式邏輯，可直接編寫自訂 `prepareRun` 函式，處理 `filterRun()` 未涵蓋的情況。詳見[自訂評分器：輸入篩選](/docs/evals/custom-scorers#input-filtering)。

## 使用例子 {/* #usage-example */}

以下例子建立的評分器只會收到工具呼叫及文字訊息，並將上下文限制為最近 20 則訊息：

```typescript title="src/mastra/scorers/tool-scorer.ts"
import { createScorer, filterRun } from '@mastra/core/evals'

const toolScorer = createScorer({
  id: 'tool-usage',
  description: 'Evaluates tool usage patterns',
  type: 'agent',
  prepareRun: filterRun({
    partTypes: ['tool-invocation', 'text'],
    maxRememberedMessages: 20,
  }),
}).generateScore(({ run }) => {
  // run.input.rememberedMessages contains only tool and text messages
  // run.output contains only tool and text messages
  return 1
})
```

### 按工具名稱篩選 {/* #filter-by-tool-name */}

只保留涉及特定工具的訊息：

```typescript
import { createScorer, filterRun } from '@mastra/core/evals'

const fileEditScorer = createScorer({
  id: 'file-edit-quality',
  description: 'Evaluates file editing patterns',
  type: 'agent',
  prepareRun: filterRun({
    toolNames: ['write_file', 'string_replace_lsp', 'view'],
  }),
}).generateScore(({ run }) => {
  // Only messages with these tool calls remain
  return 1
})
```

### 移除欄位 {/* #drop-fields */}

移除評分器不需要的欄位：

```typescript
import { createScorer, filterRun } from '@mastra/core/evals'

const simpleScorer = createScorer({
  id: 'response-length',
  description: 'Checks response length',
  type: 'agent',
  prepareRun: filterRun({
    dropRequestContext: true,
    dropExpectedTrajectory: true,
    dropGroundTruth: true,
    maxOutputMessages: 5,
  }),
}).generateScore(({ run }) => {
  return run.output.length > 0 ? 1 : 0
})
```

**傳回值：** `(run: ScorerRun) => ScorerRun`。此函式可作為 `prepareRun` 選項傳給 [`createScorer()`](/reference/evals/create-scorer)。

## 片段類型 {/* #part-types */}

`partTypes` 選項接受 `MastraPartType` 值。每個值都會按前綴比對，因此 `'data-'` 可比對所有資料片段類型。

| 類型 | 說明 |
| - | - |
| `'text'` | 文字內容片段 |
| `'tool-invocation'` | 工具呼叫及結果片段 |
| `'reasoning'` | 思維鏈推理片段 |
| `'step-start'` | 步驟標記片段 |
| `'image'` | 圖片片段 |
| `'file'` | 檔案片段 |
| `'source'` | 來源參照片段 |
| `'source-document'` | 來源文件片段 |
| `'data-'` | 所有資料片段（比對任何 `data-*` 前綴） |
| `'data-om-'` | 觀察記憶資料片段 |
| `'data-workspace-'` | Workspace 資料片段 |
| `'data-sandbox-'` | Sandbox 資料片段 |
| `'data-tool-'` | 工具相關資料片段 |

## 篩選行為 {/* #filtering-behavior */}

- **片段類型篩選**：當 `input.rememberedMessages` 及 `output` 包含 Agent 訊息陣列時，兩者都會套用此篩選。
- **工具名稱篩選**：只影響含有工具呼叫的訊息。不含工具呼叫的訊息只按 `partTypes` 篩選；未設定 `partTypes` 時會直接保留。
- **系統訊息**（`systemMessages`、`taggedSystemMessages`）：不論 `partTypes` 或 `toolNames` 如何設定，一律不會被篩選。
- **訊息數目限制**（`maxRememberedMessages`、`maxOutputMessages`）：在按類型及工具篩選後套用，保留最新訊息。
- 同時設定 `partTypes` 及 `toolNames` 時，含有工具呼叫的訊息必須同時符合兩項篩選條件才會保留。
