# 完整性評分者

這`createCompletenessScorer()`函數評估法學碩士的輸出涵蓋輸入中存在的關鍵要素的徹底程度。它分析名詞、動詞、主題和術語以確定覆蓋範圍並提供詳細的完整性分數。

## 參數 {/* #parameters */}

這`createCompletenessScorer()` function doesn't take any options.

此函數傳回 MastraScorer 類別的實例。請參閱[MastraScorer reference](./mastra-scorer) for details on the `.run()` method and its input/output.

## 元素提取細節 {/* #element-extraction-details */}

記分器提取並分析幾種類型的元素：

* 名詞：關鍵對象、概念與實體
* 動詞：動作和狀態（轉換為不定式形式）
* 主題：主要主題和主題
* 術語：單獨的實質單字

提取過程包括：

*
* 字邊界的處理
* 對短單字（3 個字元或更少）的特殊處理
* 元素去重

### `preprocessStepResult` {/* #preprocessstepresult */}

從`.run()` method, you can get the `preprocessStepResult` object with the following properties:

* **輸入元素**：輸入中找到的關鍵元素（例如名詞、動詞、主題、術語）。
* **輸出元素**：在輸出中找到的關鍵元素。
* **缺失元素**：在輸出中找不到輸入元素。
* **元素計數**：輸入和輸出中的元素數量。

## 評分詳情 {/* #scoring-details */}

評分者透過語言元素覆蓋分析來評估完整性。

### 評分流程 {/* #scoring-process */}

1. 提取關鍵要素：
   * 名詞和實體，例如名稱
   * 動作動詞
   * 特定主題術語
   * 規範化的詞形
2. 計算輸入元素的覆蓋範圍：
   * 短期精確匹配（≤3 個字元）
   * 長期的大量重疊 (>60%)

當輸入沒有產生任何元素時，記分器會返回`1` if the output also has no elements and `0` otherwise.

最終成績：`covered_elements / total_input_elements`

完整性評分者沒有`scale` option. The score is always between 0 and 1.

### 分數解讀 {/* #score-interpretation */}

完整性分數介於 0 和 1 之間：

* **1.0**：詳細解決查詢的各個方面。
* **0.7至0.9**：涵蓋了最重要的方面，細節豐富，有細微的差距。
* **0.4至0.6**：解決了一些關鍵點，但缺少重要方面或缺乏細節。
* **0.1至0.3**：僅部分解決了存在重大差距的查詢。
* **0.0**：無法解決查詢或提供不相關的資訊。

## 例子 {/* #example */}

評估Agent回應在不同查詢複雜度下的完整性：

```typescript title="src/example-completeness.ts"
import { runEvals } from '@mastra/core/evals'
import { createCompletenessScorer } from '@mastra/evals/scorers/prebuilt'
import { myAgent } from './agent'

const scorer = createCompletenessScorer()

const result = await runEvals({
  data: [
    {
      input:
        'Explain the process of photosynthesis, including the inputs, outputs, and stages involved.',
    },
    {
      input: 'What are the benefits and drawbacks of remote work for both employees and employers?',
    },
    {
      input:
        'Compare renewable and non-renewable energy sources in terms of cost, environmental impact, and sustainability.',
    },
  ],
  scorers: [scorer],
  target: myAgent,
  onItemComplete: ({ scorerResults }) => {
    console.log({
      score: scorerResults[scorer.id].score,
    })
  },
})

console.log(result.scores)
```

欲了解更多詳情`runEvals`, see the [runEvals reference](/reference/evals/run-evals).

若要將此記分員新增至Agent，請參閱[Scorers overview](/docs/evals/overview#adding-scorers-to-agents) guide.
