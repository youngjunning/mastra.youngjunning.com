# 完整性評分器

`createCompletenessScorer()` 評估 LLM 輸出涵蓋輸入中關鍵元素的程度。它分析名詞、動詞、主題和詞語，並提供詳細的完整性分數。

## 參數 {/* #parameters */}

`createCompletenessScorer()` 不接受任何選項。

此函式會傳回 MastraScorer 類別的實例。有關 `.run()` 方法及其輸入和輸出，請參閱 [MastraScorer 參考文件](./mastra-scorer)。

## 元素擷取詳情 {/* #element-extraction-details */}

評分器會擷取並分析以下幾類元素：

- 名詞：關鍵物件、概念和實體
- 動詞：動作和狀態（轉換為不定詞形式）
- 主題：主要議題和主題
- 詞語：個別有實際意義的詞

擷取過程包括：

- 文字標準化（移除變音符號並轉為小寫）
- 處理詞語邊界
- 特別處理短詞（不超過 3 個字元）
- 將元素去重

### `preprocessStepResult` {/* #preprocessstepresult */}

`.run()` 傳回的 `preprocessStepResult` 物件包含以下屬性：

- **inputElements**：輸入中的關鍵元素（例如名詞、動詞、主題和詞語）。
- **outputElements**：輸出中的關鍵元素。
- **missingElements**：輸入中有、輸出中沒有的元素。
- **elementCounts**：輸入和輸出中的元素數量。

## 評分詳情 {/* #scoring-details */}

評分器透過分析語言元素的涵蓋情況來評估完整性。

### 評分流程 {/* #scoring-process */}

1. 擷取關鍵元素：
   - 名詞及名稱等實體
   - 表示動作的動詞
   - 與主題相關的詞語
   - 標準化後的詞形
1. 計算輸入元素的涵蓋率：
   - 對短詞（≤3 個字元）進行完全比對
   - 對較長詞語檢查是否有大量重疊（>60%）

如果輸入沒有擷取出任何元素，輸出也沒有元素時會傳回 `1`，否則傳回 `0`。

最終分數：`covered_elements / total_input_elements`

完整性評分器沒有 `scale` 選項，分數始終介乎 0 和 1 之間。

### 分數解讀 {/* #score-interpretation */}

完整性分數介乎 0 和 1 之間：

- **1.0**：詳細回應問題的各個方面。
- **0.7 至 0.9**：詳細涵蓋大部分重要方面，僅有少量遺漏。
- **0.4 至 0.6**：回應了部分重點，但遺漏重要方面或缺少細節。
- **0.1 至 0.3**：只回應了問題的一小部分，遺漏甚多。
- **0.0**：沒有回應問題，或只提供無關資料。

## 範例 {/* #example */}

評估 Agent 對不同複雜程度問題的回覆是否完整：

```typescript title="src/example-completeness.ts"
import { runEvals } from '@mastra/core/evals'
import { createCompletenessScorer } from '@mastra/evals/scorers/prebuilt'
import { myAgent } from './agent'

const scorer = createCompletenessScorer()

const result = await runEvals({
  data: [
    {
      input:
        'Explain the process of photosynthesis, including the inputs, outputs, and stages involved.',
    },
    {
      input: 'What are the benefits and drawbacks of remote work for both employees and employers?',
    },
    {
      input:
        'Compare renewable and non-renewable energy sources in terms of cost, environmental impact, and sustainability.',
    },
  ],
  scorers: [scorer],
  target: myAgent,
  onItemComplete: ({ scorerResults }) => {
    console.log({
      score: scorerResults[scorer.id].score,
    })
  },
})

console.log(result.scores)
```

有關 `runEvals` 的詳情，請參閱 [runEvals 參考文件](/reference/evals/run-evals)。

如需將此評分器加入 Agent，請參閱[評分器概覽](/docs/evals/overview#adding-scorers-to-agents)。
