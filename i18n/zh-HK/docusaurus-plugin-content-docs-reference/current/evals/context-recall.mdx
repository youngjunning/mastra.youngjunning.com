# Context Recall 評分器

`createContextRecallScorer()` 函式建立的評分器，會評估檢索所得的上下文涵蓋標準參考答案中各項陳述的程度。它計算參考答案中有多少比例的陳述能從檢索所得的上下文找到依據，以衡量檢索的完整程度。

此評分器需要標準參考答案，因此適合在 CI 或測試環境中評估附有正確答案的數據集。如執行時沒有提供 `groundTruth`，評分器會傳回 0 分，而不會拋出錯誤。

## RAG 檢索評估 {/* #rag-retrieval-evaluation */}

適合評估以下 RAG 流程中的檢索完整程度：

* 需要確認檢索器是否取得所有必要資訊
* 擁有附有已知正確答案的數據集
* 希望找出檢索器傳回結果的退步情況

## 數據集驅動測試 {/* #dataset-driven-testing */}

適用於使用精選測試集執行評估：

* 在 CI 流程中使用附有標準答案的問題
* 對檢索策略進行 A/B 測試
* 對嵌入模型的資訊涵蓋能力進行基準測試

## 評分細節 {/* #scoring-details */}

### 陳述依據核對 {/* #claim-attribution */}

Context Recall 先由 LLM 分兩步評估，再以確定性方式計算分數：

1. **擷取陳述**：將標準答案拆解為獨立的最小陳述
2. **核對依據**：檢查檢索所得的上下文是否支持每項陳述

之後計算有上下文依據的陳述數佔陳述總數的比例，再乘以 scale。

### 評分公式 {/* #scoring-formula */}

```text
Context Recall = attributed_claims / total_claims × scale

Where:
- attributed_claims = number of ground-truth claims supported by the context
- total_claims = total number of claims extracted from the ground truth
- Attribution is binary: a claim is either supported (yes) or not (no)
```

### 分數解讀 {/* #score-interpretation */}

以下範圍以 `scale` 的預設值 1 為準。使用自訂 scale 時，請相應調整。

* **0.9-1.0**：召回效果極佳，上下文幾乎涵蓋所有標準答案陳述
* **0.7-0.8**：召回效果良好，涵蓋大多數陳述，只有少量遺漏
* **0.4-0.6**：召回效果一般，上下文缺少不少資訊
* **0.1-0.3**：召回效果欠佳，上下文未包含大多數標準答案陳述
* **0.0**：未召回任何標準答案陳述

### 原因分析 {/* #reason-analysis */}

reason 欄位說明：

* 哪些標準答案陳述在上下文中找到了依據
* 缺少哪些陳述，以及存在哪些資訊缺口
* 哪些具體上下文片段支持了有依據的陳述

### 優化見解 {/* #optimization-insights */}

可利用評估結果：

* **改善檢索**：找出檢索器遺漏的資訊類型
* **調整分塊大小**：確保片段包含足夠細節，能涵蓋標準答案陳述
* **評估嵌入模型**：測試不同模型對資訊的涵蓋能力
* **擴充知識庫**：加入涵蓋常被遺漏陳述的文件

### 計算範例 {/* #example-calculation */}

標準答案：「愛因斯坦出生於 1879 年。他發展了相對論。他曾獲得諾貝爾獎。」

擷取出的陳述：3 項

* 「愛因斯坦出生於 1879 年」→ 有依據（上下文提到出生日期）
* 「愛因斯坦發展了相對論」→ 有依據（上下文涵蓋相對論）
* 「愛因斯坦曾獲得諾貝爾獎」→ 無依據（上下文未提到諾貝爾獎）

召回率 = 2/3 = 0.67

## 評分器設定 {/* #scorer-configuration */}

### 動態擷取上下文 {/* #dynamic-context-extraction */}

```typescript
const scorer = createContextRecallScorer({
  model: '__GATEWAY_OPENAI_MODEL__',
  options: {
    contextExtractor: (input, output) => {
      const query = input?.inputMessages?.[0]?.content || ''
      const searchResults = vectorDB.search(query, { limit: 10 })
      return searchResults.map(result => result.content)
    },
    scale: 1,
  },
})
```

### 靜態上下文評估 {/* #static-context-evaluation */}

```typescript
const scorer = createContextRecallScorer({
  model: '__GATEWAY_OPENAI_MODEL__',
  options: {
    context: [
      'Document 1: Einstein was born on 14 March 1879 in Ulm, Germany.',
      'Document 2: Einstein published the theory of special relativity in 1905.',
      'Document 3: Einstein moved to the United States in 1933.',
    ],
  },
})
```

## 範例 {/* #example */}

使用附有標準答案的數據集，評估 RAG 檢索的完整程度：

```typescript title="src/example-context-recall.ts"
import { runEvals } from '@mastra/core/evals'
import { createContextRecallScorer } from '@mastra/evals/scorers/prebuilt'
import { myAgent } from './agent'

const scorer = createContextRecallScorer({
  model: '__GATEWAY_OPENAI_MODEL__',
  options: {
    contextExtractor: (input, output) => {
      // Extract context from tool invocation results in the agent output
      return output
        .filter(msg => msg?.role === 'assistant')
        .flatMap(msg => msg?.content?.toolInvocations ?? [])
        .filter((tool: any) => tool.state === 'result')
        .map((tool: any) => JSON.stringify(tool.result))
    },
  },
})

const result = await runEvals({
  data: [
    {
      input: 'What are the health benefits of green tea?',
      groundTruth:
        'Green tea contains antioxidants that reduce inflammation, L-theanine that improves focus, and catechins that boost metabolism.',
    },
    {
      input: 'How does photosynthesis work?',
      groundTruth:
        'Photosynthesis converts sunlight into chemical energy using chlorophyll in chloroplasts, producing glucose and oxygen from carbon dioxide and water.',
    },
  ],
  scorers: [scorer],
  target: myAgent,
  onItemComplete: ({ scorerResults }) => {
    console.log({
      score: scorerResults[scorer.id].score,
      reason: scorerResults[scorer.id].reason,
    })
  },
})

console.log(result.scores)
```

如需進一步了解 `runEvals`，請參閱 [runEvals 參考文件](/reference/evals/run-evals)。

如要將此評分器加入 Agent，請參閱 [Scorers 概覽](/docs/evals/overview#adding-scorers-to-agents)指南。

## 與 Context Precision 比較 {/* #comparison-with-context-precision */}

請按需要選擇評分器：

| 使用情境 | Context Recall | Context Precision |
| - | - | - |
| **衡量內容** | 標準答案的涵蓋程度 | 檢索片段的相關程度 |
| **比較方向** | 標準答案 → 上下文 | 上下文 → 標準答案 |
| **是否受位置影響** | 否 | 是（位置越前，得分越高） |
| **是否需要標準答案** | 是 | 是 |
| **找出的問題** | 資訊遺漏 | 無關內容 |

同時使用兩者，可更全面了解檢索質素：Precision 能找出上下文中的無關內容，Recall 能找出遺漏的資訊。
