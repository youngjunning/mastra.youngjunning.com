# 答案相似度評分器

`createAnswerSimilarityScorer()` 函式會建立評分器，用來評估 Agent 輸出與標準答案的相似程度。它專為已有預期答案的 CI/CD 測試情境設計，協助你檢查結果能否長期保持一致。

此函式會傳回 MastraScorer 類別的實例。`.run()` 方法接受與其他評分器相同的輸入（參閱 [MastraScorer 參考文件](./mastra-scorer)），但預期 run 物件中有標準答案。`options.requireGroundTruth` 為 `true`（預設值）時，缺少標準答案的 run 會擲出錯誤；設為 `false` 時，此類 run 得 0 分。

## 評分詳情 {/* #scoring-details */}

評分器採用多步驟流程：

1. **擷取**：將輸出及標準答案拆分成語義單元。
1. **分析**：比較語義單元，找出匹配、矛盾及缺漏。
1. **評分**：計算加權相似度，並對矛盾內容扣分。
1. **解釋**：產生容易理解的分數說明。

分數計算方式：`max(0, min(1, base_score - contradiction_penalty - extra_info_penalty)) × scale`

`base_score` 是各項匹配得分之和，減去每個缺漏單元對應的 `missingPenalty`，再除以 `ground_truth_units × (1 + exactMatchBonus)`。標準答案沒有任何單元時，分數為 0。

## 例子 {/* #example */}

在不同情境下評估 Agent 回應與標準答案的相似度：

```typescript title="src/example-answer-similarity.ts"
import { runEvals } from '@mastra/core/evals'
import { createAnswerSimilarityScorer } from '@mastra/evals/scorers/prebuilt'
import { myAgent } from './agent'

const scorer = createAnswerSimilarityScorer({ model: '__GATEWAY_OPENAI_MODEL__' })

const result = await runEvals({
  data: [
    {
      input: 'What is 2+2?',
      groundTruth: '4',
    },
    {
      input: 'What is the capital of France?',
      groundTruth: 'The capital of France is Paris',
    },
    {
      input: 'What are the primary colors?',
      groundTruth: 'The primary colors are red, blue, and yellow',
    },
  ],
  scorers: [scorer],
  target: myAgent,
  onItemComplete: ({ scorerResults }) => {
    console.log({
      score: scorerResults[scorer.id].score,
      reason: scorerResults[scorer.id].reason,
    })
  },
})

console.log(result.scores)
```

如需進一步了解 `runEvals`，請參閱 [runEvals 參考文件](/reference/evals/run-evals)。

如要將此評分器加入 Agent，請參閱 [Scorers 概覽](/docs/evals/overview#adding-scorers-to-agents) 指南。
