# ElevenLabs

Mastra 利用 ElevenLabs API 提供高質素的文字轉語音（TTS）及語音轉文字（STT）功能。

## 用法示例 {/* #usage-example */}

```typescript
import { ElevenLabsVoice } from '@mastra/voice-elevenlabs'

// Initialize with default configuration (uses ELEVENLABS_API_KEY environment variable)
const voice = new ElevenLabsVoice()

// Initialize with custom configuration
const voice = new ElevenLabsVoice({
  speechModel: {
    name: 'eleven_multilingual_v2',
    apiKey: 'your-api-key',
  },
  speaker: 'custom-speaker-id',
})

// Text-to-Speech
const audioStream = await voice.speak('Hello, world!')

// Get available speakers
const speakers = await voice.getSpeakers()
```

## 重要提示 {/* #important-notes */}

1. 必須提供 ElevenLabs API 密鑰。可設定環境變數 `ELEVENLABS_API_KEY`，或在建構函數中傳入密鑰。
2. 預設聲線是 Aria（ID：`9BWtsMINqrJLrRacOk9x`）。
3. ElevenLabs 不支援語音轉文字功能。
4. 可透過 `getSpeakers()` 取得可用聲線的詳細資料，包括各聲線的語言及性別。
