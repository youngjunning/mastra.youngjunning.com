# ModelsLab

ModelsLab 只提供文字轉語音（TTS）。Mastra 整合會提交非同步合成任務，待 ModelsLab 傳回音頻 URL 後下載已合成的音頻，再以 Node.js 可讀串流傳回。

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/voice-modelslab@latest
```

## API 密鑰 {/* #api-key */}

設定環境變數 `MODELSLAB_API_KEY`，或經 `speechModel.apiKey` 傳入密鑰。如兩處均未提供密鑰，建構函數會拋出 `MODELSLAB_API_KEY is not set` 錯誤。

## 使用示例 {/* #usage-example */}

```typescript
import { ModelsLabVoice } from '@mastra/voice-modelslab'

const voice = new ModelsLabVoice({
  speechModel: {
    apiKey: process.env.MODELSLAB_API_KEY,
  },
  speaker: '5',
})

const audioStream = await voice.speak('Hello, world!', {
  speaker: 'nova',
  language: 'english',
  speed: 1,
})

const speakers = await voice.getSpeakers()
```

## 音色 {/* #voices */}

ModelsLab 提供六款內置英語音色：

| ID | 名稱 | 性別 | 語言 |
| - | - | - | - |
| `1` | 中性音色 | 中性 | `en` |
| `2` | 男聲 | 男 | `en` |
| `3` | 溫暖男聲 | 男 | `en` |
| `4` | 低沉男聲 | 男 | `en` |
| `5` | 女聲 | 女 | `en` |
| `6` | 清晰女聲 | 女 | `en` |

以下是 OpenAI 風格的別名及其對應的音色 ID：

| 別名 | 音色 ID |
| - | - |
|`alloy` | `1` |
| `echo` | `2` |
| `fable` | `3` |
| `onyx` | `4` |
| `nova` | `5` |
| `shimmer` | `6` |

## 方法 {/* #methods */}

### `speak()` {/* #speak */}

將文字轉為語音。如 ModelsLab 傳回任務 ID，整合會每隔五秒查詢一次任務狀態，最多等候五分鐘。此方法會下載完整的音頻後才傳回可讀串流，因此無法在下載期間串流輸出音頻。

### `listen()` {/* #listen */}

ModelsLab 不支援語音轉文字。呼叫此方法會拋出錯誤，提示可用 `@mastra/voice-deepgram` 作為語音轉文字的 Provider。

## 重要提示 {/* #important-notes */}

* 向 ModelsLab 發出文字轉語音請求時，API 密鑰會隨請求內文傳送。
* 合成任務每隔五秒輪詢一次，等候達 300 秒便會逾時。
* 音頻完整下載後才會以串流傳回，無法在下載期間輸出。
* 整合不指定輸出格式，而是直接從 ModelsLab 傳回的 URL 下載音頻。
* 此套件在執行期間不會驗證 `speed` 的取值範圍。
* 如傳入的音色值並非數字，亦不符合任何別名，便會使用音色 ID `1`。
* 不支援語音轉文字。
