# 模型實驗室

ModelsLab 僅提供文字轉語音 (TTS)。 Mastra 整合提交非同步合成作業，等待音頻 URL，下載完成的音頻，並將其作為 Node.js 可讀流返回。

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/voice-modelslab@latest
```

## API金鑰 {/* #api-key */}

放`MODELSLAB_API_KEY` or pass the key through `speechModel.apiKey`. The constructor throws `MODELSLAB_API_KEY is not set`當兩個值都不可用時。

## 使用範例 {/* #usage-example */}

```typescript
import { ModelsLabVoice } from '@mastra/voice-modelslab'

const voice = new ModelsLabVoice({
  speechModel: {
    apiKey: process.env.MODELSLAB_API_KEY,
  },
  speaker: '5',
})

const audioStream = await voice.speak('Hello, world!', {
  speaker: 'nova',
  language: 'english',
  speed: 1,
})

const speakers = await voice.getSpeakers()
```

## 聲音 {/* #voices */}

ModelsLab 公開了六種內建英語語音：

|身分證 |姓名 |性別 |語言 |
| - | - | - | - |
|`1` | Neutral | neutral | `en` |
| `2` | Male | male | `en` |
| `3` | Warm | male | `en` |
| `4`|深男|男 |`en` |
| `5`|女 |女 |`en` |
| `6`|清晰女|女 |`en` |

OpenAI 風格的別名會對應到這些聲音：

|別名 |語音辨識 |
| - | - |
|`alloy` | `1` |
| `echo` | `2` |
| `fable` | `3` |
| `onyx` | `4` |
| `nova` | `5` |
| `shimmer` | `6` |

## 方法 {/* #methods */}

### `speak()` {/* #speak */}

將文字轉換為語音。如果 ModelsLab 返回處理 ID，整合將每五秒輪詢一次，持續最多五分鐘。它會在返回可讀流之前下載完整的音頻，因此此方法不提供漸進式音頻流。

### `listen()` {/* #listen */}

ModelsLab 不支援語音轉文字。呼叫此方法會拋出一個錯誤，該錯誤指向`@mastra/voice-deepgram` as a listening provider.

## 重要提示 {/* #important-notes */}

* ModelsLab 文字轉語音請求在請求正文中傳送 API 金鑰。
*
* 在返回串流之前，已完全下載完成的音訊。該流不是漸進式的。
* 整合不強制輸出格式。它從 ModelsLab 返回的 URL 下載音訊。
* `speed`此套件中沒有運行時範圍驗證。
* 與別名不符的非數位揚聲器值回退到語音 ID`1`.
* 不支援語音轉文字。
