# xAI 即時語音

`XAIRealtimeVoice` 類別透過 xAI Grok Voice Agent API 提供即時語音互動。它實作 Mastra 的 `MastraVoice` 即時介面，支援雙向音訊串流、文字對話輪次、伺服器端 VAD、xAI 語音、函式 Tool 及 xAI 伺服器端 Tool。

## 使用範例 {/* #usage-example */}

```typescript
import { Agent } from '@mastra/core/agent'
import { getMicrophoneStream, playAudio } from '@mastra/node-audio'
import { XAIRealtimeVoice } from '@mastra/voice-xai-realtime'

const voice = new XAIRealtimeVoice({
  apiKey: process.env.XAI_API_KEY,
  model: 'grok-voice-think-fast-1.0',
  speaker: 'eve',
  instructions: 'You are a concise voice assistant.',
  turnDetection: { type: 'server_vad' },
})

const agent = new Agent({
  id: 'voice-agent',
  name: 'Voice Agent',
  instructions: 'You are a helpful voice assistant.',
  model: 'xai/grok-4.3',
  voice,
})

await agent.voice.connect()

agent.voice.on('speaker', audioStream => {
  playAudio(audioStream)
})

agent.voice.on('writing', ({ text, role }) => {
  console.log(`${role}: ${text}`)
})

await agent.voice.speak('How can I help you today?')

const microphoneStream = getMicrophoneStream()
await agent.voice.send(microphoneStream)

agent.voice.close()
```

### VoiceConfig 設定方式 {/* #voiceconfig-pattern */}

亦可使用 Mastra 共用的語音設定結構：

```typescript
const voice = new XAIRealtimeVoice({
  speaker: 'ara',
  realtimeConfig: {
    model: 'grok-voice-think-fast-1.0',
    apiKey: process.env.XAI_API_KEY,
    options: {
      instructions: 'Answer briefly.',
      turnDetection: { type: 'server_vad', threshold: 0.85 },
    },
  },
})
```

## 身份驗證 {/* #authentication */}

伺服器端應用程式可使用 `apiKey` 或 `XAI_API_KEY`。此 Provider 適用於 Node.js 伺服器端執行環境。如伺服器已簽發 xAI 短效權杖，可透過 `ephemeralToken` 傳入；Provider 會使用 `xai-client-secret.<token>` WebSocket 協定，而非授權標頭。如同時設定 `apiKey` 及 `ephemeralToken`，Provider 會使用短效權杖。

## 事件 {/* #events */}

`XAIRealtimeVoice` 將 xAI 即時伺服器事件對應至 Mastra 語音事件：

* `speaker`：發出包含助理音訊的可讀串流。
* `speaking`：發出助理音訊的增量資料。
* `speaking.done`：助理音訊回應完成時發出。
* `writing`：發出助理文字的增量資料及用戶輸入的轉錄文字。
* `error`：發出 xAI 錯誤及 Provider 執行錯誤，包括 Tool 執行錯誤及格式錯誤的函式呼叫參數。Tool 錯誤包含 `details.call_id` 及 `details.name`。
* `close`：WebSocket 關閉時發出。
* `tool-call-start`：執行 Mastra 函式 Tool 前發出。
* `tool-call-result`：Mastra 函式 Tool 返回後發出。

亦會發出原始 xAI 事件，因此可訂閱 `response.output_audio.delta`、`response.text.delta`、`response.function_call_arguments.done` 及 `response.done` 等事件。

## Tool {/* #tools */}

### Mastra 函式 Tool {/* #mastra-function-tools */}

透過 `addTools()` 加入的 Tool 會轉換為 xAI 函式 Tool，並包含在 `session.update` 中。

```typescript
import { createTool } from '@mastra/core/tools'
import { z } from 'zod'

const weatherTool = createTool({
  id: 'getWeather',
  description: 'Get current weather for a location.',
  inputSchema: z.object({
    location: z.string(),
  }),
  execute: async ({ location }) => {
    return { location, temperature: 22 }
  },
})

voice.addTools({ getWeather: weatherTool })
```

當 xAI 發出 `response.function_call_arguments.done` 時，Provider 會執行對應的 Mastra Tool，並傳送一個 `function_call_output` 項目。如 xAI 在單次回應中發起多個函式呼叫，Provider 會等待所有 Tool 的結果及該回應的 `response.done` 事件，然後只傳送一次用於繼續對話的 `response.create`。

### xAI 伺服器端 Tool {/* #xai-server-side-tools */}

xAI 伺服器端 Tool 透過工作階段設定傳入，並由 xAI 執行。`session.tools` 及 `serverTools` 中的 Tool 會合併：

```typescript
const voice = new XAIRealtimeVoice({
  apiKey: process.env.XAI_API_KEY,
  serverTools: [
    { type: 'web_search' },
    { type: 'x_search', allowed_x_handles: ['xai'] },
    { type: 'file_search', vector_store_ids: ['collection_123'], max_num_results: 10 },
    {
      type: 'mcp',
      server_url: 'https://mcp.example.com/mcp',
      server_label: 'business-tools',
      allowed_tools: ['lookup_order'],
    },
  ],
})
```

## 音訊格式 {/* #audio-formats */}

預設輸入和輸出格式為 24 kHz PCM16。您也可以設定支援的 PCM 取樣率或電話編解碼器：

```typescript
const voice = new XAIRealtimeVoice({
  audio: {
    input: { format: { type: 'audio/pcm', rate: 16000 } },
    output: { format: { type: 'audio/pcm', rate: 16000 } },
  },
})
```

支援的格式類型包括 `audio/pcm`、`audio/pcmu` 及 `audio/pcma`。PCM 支援文件列出的 8 kHz 至 48 kHz 取樣率。`audio/pcmu` 及 `audio/pcma` 是 G.711 電話音訊編解碼格式，取樣率為 8 kHz。
