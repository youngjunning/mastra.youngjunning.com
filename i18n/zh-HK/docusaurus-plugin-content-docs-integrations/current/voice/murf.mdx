# Murf

Mastra 利用 Murf 的 AI 語音服務提供文字轉語音（TTS）功能，支援多種語言的聲線。

## 使用示例 {/* #usage-example */}

```typescript
import { MurfVoice } from '@mastra/voice-murf'

// Initialize with default configuration (uses MURF_API_KEY environment variable)
const voice = new MurfVoice()

// Initialize with custom configuration
const voice = new MurfVoice({
  speechModel: {
    name: 'GEN2',
    apiKey: 'your-api-key',
    properties: {
      format: 'MP3',
      rate: 1.0,
      pitch: 1.0,
      sampleRate: 48000,
      channelType: 'STEREO',
    },
  },
  speaker: 'en-US-cooper',
})

// Text-to-Speech with default settings
const audioStream = await voice.speak('Hello, world!')

// Text-to-Speech with custom properties
const audioStream = await voice.speak('Hello, world!', {
  speaker: 'en-UK-hazel',
  properties: {
    format: 'WAV',
    rate: 1.2,
    style: 'casual',
  },
})

// Get available voices
const voices = await voice.getSpeakers()
```

### `listen()` {/* #listen */}

Murf 不提供語音轉文字功能，呼叫此方法會拋出錯誤。

## 重要提示 {/* #important-notes */}

1. 使用服務時必須提供 Murf API 密鑰。可設定 `MURF_API_KEY` 環境變數，或在建構函數中傳入密鑰。
2. 服務預設使用 GEN2 模型。
3. 可在建構函數中設定預設語音屬性，並在個別請求中指定其他設定。
4. 可按需要設定輸出音頻的格式、採樣率及聲道類型等屬性。
5. Murf 不支援語音轉文字。
