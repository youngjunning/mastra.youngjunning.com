# 米斯特拉爾

MistralVoice 類別使用 Mistral 的 Voxtral 音訊模型提供文字轉語音和語音到文字的功能。它支援緩衝和流式 TTS、帶分類的批量轉錄以及透過參考音訊進行語音克隆。

## 使用範例 {/* #usage-example */}

```typescript
import { MistralVoice } from '@mastra/voice-mistral'

const voice = new MistralVoice()

// Text-to-speech
const audioStream = await voice.speak('Hello, how can I help you?', {
  responseFormat: 'mp3',
})

// Speech-to-text
const text = await voice.listen(audioStream, {
  language: 'en',
})

// List available voices
const speakers = await voice.getSpeakers()
```

```typescript
import { MistralVoice } from '@mastra/voice-mistral'

// Initialize with specific configuration
const voice = new MistralVoice({
  speechModel: {
    name: 'voxtral-mini-tts-2603',
    apiKey: 'your-mistral-api-key',
  },
  listeningModel: {
    name: 'voxtral-mini-latest',
    apiKey: 'your-mistral-api-key',
  },
  speaker: 'en_paul_neutral',
})
```

## 筆記 {/* #notes */}

* API 金鑰可以透過建構函數選項或`MISTRAL_API_KEY` environment variable
* TTS 支援 9 種語言：英語、法語、西班牙語、葡萄牙語、義大利語、荷蘭語、德語、印地語、阿拉伯語
*
* 為了獲得最佳結果，TTS 輸入文字應保持在每個請求 300 個字以下
*
* 語音克隆透過`refAudio` requires a minimum of 2-3 seconds of reference audio
* `getSpeakers()`傳回帶有 UUID 識別碼的預設語音。預設`en_paul_neutral` is a named alias accepted by the TTS endpoint but not included in the list
