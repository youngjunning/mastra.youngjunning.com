# Google Sheets

透過 Mastra Connect，為 Agent 提供可在 Google Sheets 中讀取、附加、更新及清除儲存格值，以及建立試算表、列與工作表的 Tool。每次 Tool 呼叫都會經過 Mastra 平台，由平台加入該連接的憑證；你的應用程式不會儲存 Google Sheets 憑證。

## 連接 {/* #connect */}

開始前，請先完成 [Connect 設定](/docs/mastra-platform/connect#get-started)，安裝 `@mastra/connect` 並設定 Mastra 平台項目。

### 連接帳戶 {/* #connect-an-account */}

請在包含 `.env` 檔案的目錄中執行以下指令：

```bash
mastra connect add google-sheet
```

CLI 會引導你完成 Google Sheets 授權，並等待連接啟用。

### 將 Tool 加入 Agent {/* #add-tools-to-an-agent */}

將 [`tools()`](/reference/connect/tools) 傳給 Agent，並選擇 `google-sheet` Provider：

```typescript title="src/mastra/agents/google-sheet-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const googleSheetAgent = new Agent({
  id: 'google-sheet-agent',
  name: 'Google Sheets agent',
  instructions:
    'You help people read, append, update, and clear cell values, and create spreadsheets, rows, and worksheets in Google Sheets.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['google-sheet'] }),
})
```

Agent 可使用 18 個 Google Sheets Tool，Tool key 包括 `google_sheet_append_values_to_spreadsheet`。完整清單請參閱 [Google Sheets Tool](/reference/connect/providers#google-sheets)；如需限制可用 Tool，或要求每次呼叫在執行前取得批准，請參閱 [`tools()` 參數](/reference/connect/tools#parameters)。
