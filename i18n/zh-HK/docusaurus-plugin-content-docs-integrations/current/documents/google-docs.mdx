# Google Docs

透過 Mastra Connect，為 Agent 提供可在 Google Docs 中建立文件、插入及取代文字，以及編輯表格、頁首、頁尾與樣式的 Tool。每次 Tool 呼叫都會經過 Mastra 平台，由平台加入該連接的憑證；你的應用程式不會儲存 Google Docs 憑證。

## 連接 {/* #connect */}

開始前，請先完成 [Connect 設定](/docs/mastra-platform/connect#get-started)，安裝 `@mastra/connect` 並設定 Mastra 平台項目。

### 連接帳戶 {/* #connect-an-account */}

請在包含 `.env` 檔案的目錄中執行以下指令：

```bash
mastra connect add google-docs
```

CLI 會引導你完成 Google Docs 授權，並等待連接啟用。

### 將 Tool 加入 Agent {/* #add-tools-to-an-agent */}

將 [`tools()`](/reference/connect/tools) 傳給 Agent，並選擇 `google-docs` Provider：

```typescript title="src/mastra/agents/google-docs-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const googleDocsAgent = new Agent({
  id: 'google-docs-agent',
  name: 'Google Docs agent',
  instructions:
    'You help people create documents, insert and replace text, and edit tables, headers, footers, and styles in Google Docs.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['google-docs'] }),
})
```

Agent 可使用 37 個 Google Docs Tool，Tool key 包括 `google_docs_add_document_tab`。完整清單請參閱 [Google Docs Tool](/reference/connect/providers#google-docs)；如需限制可用 Tool，或要求每次呼叫在執行前取得批准，請參閱 [`tools()` 參數](/reference/connect/tools#parameters)。
