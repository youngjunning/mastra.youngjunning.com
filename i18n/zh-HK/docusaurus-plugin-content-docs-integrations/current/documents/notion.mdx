# Notion

透過 Mastra Connect，為 Agent 提供可在 Notion 中搜尋、讀取、建立及更新頁面，附加內容區塊，以及查詢資料庫與資料來源的 Tool。每次 Tool 呼叫都會經過 Mastra 平台，由平台加入該連接的憑證；你的應用程式不會儲存 Notion 憑證。

## 連接 {/* #connect */}

開始前，請先完成 [Connect 設定](/docs/mastra-platform/connect#get-started)，安裝 `@mastra/connect` 並設定 Mastra 平台項目。

### 連接帳戶 {/* #connect-an-account */}

請在包含 `.env` 檔案的目錄中執行以下指令：

```bash
mastra connect add notion
```

CLI 會引導你完成 Notion 授權，並等待連接啟用。

### 將 Tool 加入 Agent {/* #add-tools-to-an-agent */}

將 [`tools()`](/reference/connect/tools) 傳給 Agent，並選擇 `notion` Provider：

```typescript title="src/mastra/agents/notion-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const notionAgent = new Agent({
  id: 'notion-agent',
  name: 'Notion agent',
  instructions:
    'You help people search, read, create, and update pages, append blocks, and query databases and data sources in Notion.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['notion'] }),
})
```

Agent 可使用 44 個 Notion Tool，Tool key 包括 `notion_append_block_children`。完整清單請參閱 [Notion Tool](/reference/connect/providers#notion)；如需限制可用 Tool，或要求每次呼叫在執行前取得批准，請參閱 [`tools()` 參數](/reference/connect/tools#parameters)。
