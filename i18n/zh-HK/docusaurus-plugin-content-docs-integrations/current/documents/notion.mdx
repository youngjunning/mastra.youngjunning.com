# 概念

為Agent提供Tool，用於透過 Mastra Connect 在 Notion 中搜尋、讀取、建立和更新頁面、附加區塊以及查詢資料庫和資料來源。每個Tool呼叫都會透過 Mastra 平台，該平台會新增連接的憑證。您的應用程式從不儲存 Notion 憑證。

## 連接 {/* #connect */}

在開始之前，請完成[Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect`並配置您的平台項目。

### 連接帳戶 {/* #connect-an-account */}

從包含您的目錄的目錄執行此命令`.env` file:

```bash
mastra connect add notion
```

CLI 將引導您完成 Notion 的授權並等待連線啟動。

### 向Agent添加Tool {/* #add-tools-to-an-agent */}

經過[`tools()`](/reference/connect/tools) to the agent and select the `notion` provider:

```typescript title="src/mastra/agents/notion-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const notionAgent = new Agent({
  id: 'notion-agent',
  name: 'Notion agent',
  instructions:
    'You help people search, read, create, and update pages, append blocks, and query databases and data sources in Notion.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['notion'] }),
})
```

Agent商獲得 44 個 Notion Tool，其中包含諸如`notion_append_block_children`. See [Notion tools](/reference/connect/providers#notion) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
