# 微軟Excel

為Agent提供Tool來尋找和建立工作簿、讀取和更新範圍以及透過 Mastra Connect 管理 Microsoft Excel 中的工作表、表格和圖表。每個Tool呼叫都會透過 Mastra 平台，該平台會新增連接的憑證。您的應用程式從不儲存 Microsoft Excel 憑證。

## 連接 {/* #connect */}

在開始之前，請完成[Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect`並配置您的平台項目。

：：：筆記

工作簿操作（例如工作表、範圍、表格、圖表和命名項目）需要工作或學校帳戶。個人 Microsoft 帳戶可以尋找、建立、列出、取得和刪除工作簿文件，但 Microsoft Graph 拒絕個人 OneDrive 上的工作簿操作。

:::

### 連接帳戶 {/* #connect-an-account */}

從包含您的目錄的目錄執行此命令`.env` file:

```bash
mastra connect add microsoft-excel
```

CLI 將引導您完成 Microsoft Excel 的授權並等待連線啟動。

### 向Agent添加Tool {/* #add-tools-to-an-agent */}

經過[`tools()`](/reference/connect/tools) to the agent and select the `microsoft-excel` provider:

```typescript title="src/mastra/agents/microsoft-excel-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const microsoftExcelAgent = new Agent({
  id: 'microsoft-excel-agent',
  name: 'Microsoft Excel agent',
  instructions:
    'You help people find and create workbooks, read and update ranges, and manage worksheets, tables, and charts in Microsoft Excel.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['microsoft-excel'] }),
})
```

Agent程式可獲得 27 個 Microsoft Excel Tool，其中包含以下密鑰：`microsoft_excel_add_chart`. See [Microsoft Excel tools](/reference/connect/providers#microsoft-excel) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
