# 雲端硬碟

為Agent提供搜尋、上傳、複製、移動和共用檔案和資料夾的Tool，並透過 Mastra Connect 管理 OneDrive 中的權限和版本。每個Tool呼叫都會透過 Mastra 平台，該平台會新增連接的憑證。您的應用程式從不儲存 OneDrive 憑證。

## 連接 {/* #connect */}

在開始之前，請完成[Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect`並配置您的平台項目。

### 連接帳戶 {/* #connect-an-account */}

從包含您的目錄的目錄執行此命令`.env` file:

```bash
mastra connect add one-drive
```

CLI 將引導您完成 OneDrive 的授權並等待連線啟動。

### 向Agent添加Tool {/* #add-tools-to-an-agent */}

經過[`tools()`](/reference/connect/tools) to the agent and select the `one-drive` provider:

```typescript title="src/mastra/agents/one-drive-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const oneDriveAgent = new Agent({
  id: 'one-drive-agent',
  name: 'OneDrive agent',
  instructions:
    'You help people search, upload, copy, move, and share files and folders, and manage permissions and versions in OneDrive.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['one-drive'] }),
})
```

Agent程式獲得 20 個 OneDrive Tool，其中包含以下密鑰`one_drive_copy_item`. See [OneDrive tools](/reference/connect/providers#onedrive) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
