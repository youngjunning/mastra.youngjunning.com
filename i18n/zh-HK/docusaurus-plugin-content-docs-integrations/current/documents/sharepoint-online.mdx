# SharePoint Online

透過 Mastra Connect，為 Agent 提供可在 SharePoint Online 中搜尋網站與檔案，管理清單、清單項目和網站頁面，以及分享磁碟機項目的 Tool。每次 Tool 呼叫都會經過 Mastra 平台，由平台加入該連接的憑證；你的應用程式不會儲存 SharePoint Online 憑證。

## 連接 {/* #connect */}

開始前，請先完成 [Connect 設定](/docs/mastra-platform/connect#get-started)，安裝 `@mastra/connect` 並設定 Mastra 平台項目。

### 連接帳戶 {/* #connect-an-account */}

請在包含 `.env` 檔案的目錄中執行以下指令：

```bash
mastra connect add sharepoint-online
```

CLI 會引導你完成 SharePoint Online 授權，並等待連接啟用。

### 將 Tool 加入 Agent {/* #add-tools-to-an-agent */}

將 [`tools()`](/reference/connect/tools) 傳給 Agent，並選擇 `sharepoint-online` Provider：

```typescript title="src/mastra/agents/sharepoint-online-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const sharepointOnlineAgent = new Agent({
  id: 'sharepoint-online-agent',
  name: 'SharePoint Online agent',
  instructions:
    'You help people search sites and files, manage lists, list items, and site pages, and share drive items in SharePoint Online.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['sharepoint-online'] }),
})
```

Agent 可使用 53 個 SharePoint Online Tool，Tool key 包括 `sharepoint_online_add_content_type_to_list`。完整清單請參閱 [SharePoint Online Tool](/reference/connect/providers#sharepoint-online)；如需限制可用 Tool，或要求每次呼叫在執行前取得批准，請參閱 [`tools()` 參數](/reference/connect/tools#parameters)。
