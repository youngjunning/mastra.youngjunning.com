# Couchbase 向量商店

這`CouchbaseVector`類別提供向量搜尋使用[沙發底座向量搜尋](https://docs.couchbase.com/server/current/vector-search/vector-search.html)。它可以在您的 Couchbase 集合中進行高效的相似性搜尋。

## 要求 {/* #requirements */}

* **Couchbase 伺服器 7.6.4+**&#x6216;相容的 Capella 集群
* **搜尋服務已啟用**在您的 Couchbase 部署上

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/couchbase@latest
```

## 使用範例 {/* #usage-example */}

```typescript
import { CouchbaseVector } from '@mastra/couchbase'

const store = new CouchbaseVector({
  id: 'couchbase-vector',
  connectionString: process.env.COUCHBASE_CONNECTION_STRING,
  username: process.env.COUCHBASE_USERNAME,
  password: process.env.COUCHBASE_PASSWORD,
  bucketName: process.env.COUCHBASE_BUCKET,
  scopeName: process.env.COUCHBASE_SCOPE,
  collectionName: process.env.COUCHBASE_COLLECTION,
})
```

## 錯誤處理 {/* #error-handling */}

商店拋出可以捕獲的類型錯誤：

```typescript
try {
  await store.query({
    indexName: 'my_index',
    queryVector: queryVector,
  })
} catch (error) {
  // Handle specific error cases
  if (error.message.includes('Invalid index name')) {
    console.error(
      'Index name must start with a letter or underscore and contain only valid characters.',
    )
  } else if (error.message.includes('Index not found')) {
    console.error('The specified index does not exist')
  } else {
    console.error('Vector store error:', error.message)
  }
}
```

## 筆記 {/* #notes */}

* **索引刪除警告：**&#x522A;除搜尋索引不會刪除關聯的 Couchbase 集合中的向量/文件。除非明確刪除，否則資料將保留。
* **所需權限：**&#x43;ouchbase 使用者必須有權利連接、讀取/寫入目標集合中的文件（`kv` role), and manage Search Indexes (`search_admin` role on the relevant bucket/scope).
* **指數定義詳細資訊和文件結構：**&#x9019;`createIndex` method builds a Search Index definition for documents in `scopeName.collectionName`. It indexes the `embedding` field as a vector and the `content` field as text. Each document stores its vector in `embedding`, with metadata kept in `metadata`. A `text` property within `metadata` is also copied to the top-level `content` field for text search.
* **複製和持久性：**&#x8003;慮使用 Couchbase 的內建複製和持久性功能來實現資料持久性。定期監控索引統計資料以確保高效率搜尋。

## 限制 {/* #limitations */}

* 索引建立延遲可能會影響建立後的立即查詢。
* 僅在以下時間後才在攝取時強制執行向量維度`createIndex()` creates a new index on the same `CouchbaseVector` instance. Calling `createIndex()` for an index that already exists doesn't turn on the ingest check. When the check is on, `upsert()` and `updateVector()` throw on a dimension mismatch. `query()` always checks the query vector against the index dimension.
* `deleteVectors()`僅支援透過ID刪除。不支援元資料過濾器刪除。
* 向量插入和索引更新最終是一致的。寫入後不能立即保證強一致性。
