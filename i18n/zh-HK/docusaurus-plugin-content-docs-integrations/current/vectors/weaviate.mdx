# Weaviate 向量儲存

`WeaviateVector` 類別使用開源向量資料庫 [Weaviate](https://weaviate.io/) 進行向量搜尋。建立集合時會指定 `vectorizer: none`，由 Mastra 提供嵌入向量。ID、距離度量及元資料過濾亦由 Mastra 代為處理。

此向量儲存亦實作了 `listIndexes()`、`describeIndex()`、`deleteIndex()`、`updateVector()`、`deleteVector()` 和 `deleteVectors()`。

## 基本用法 {/* #basic-usage */}

```ts filename="index.ts" showLineNumbers copy
import { WeaviateVector } from '@mastra/weaviate'

const store = new WeaviateVector({ id: 'my-store' })

await store.createIndex({ indexName: 'my_index', dimension: 1536, metric: 'cosine' })

await store.upsert({
  indexName: 'my_index',
  vectors: [[0.1, 0.2 /* ... */]],
  metadata: [{ text: 'sample', category: 'docs' }],
})

const results = await store.query({
  indexName: 'my_index',
  queryVector: [0.1, 0.2 /* ... */],
  topK: 5,
  filter: { category: 'docs' },
})
```

## 連接 Weaviate Cloud {/* #connecting-to-weaviate-cloud */}

```ts showLineNumbers copy
const store = new WeaviateVector({
  id: 'my-store',
  httpHost: 'my-cluster.weaviate.network',
  httpPort: 443,
  httpSecure: true,
  grpcHost: 'grpc-my-cluster.weaviate.network',
  grpcPort: 443,
  grpcSecure: true,
  apiKey: process.env.WEAVIATE_API_KEY,
})
```

## 元資料過濾 {/* #metadata-filtering */}

過濾條件採用 MongoDB 風格的語法，Mastra 會將其轉換為 Weaviate 原生過濾 API 所用的格式：

* 比較運算符：`$eq`、`$ne`、`$gt`、`$gte`、`$lt`、`$lte`
* 陣列運算符：`$in`、`$nin`、`$all`
* 元素運算符：`$exists`
* 邏輯運算符：`$and`、`$or`、`$not`

```ts showLineNumbers copy
const results = await store.query({
  indexName: 'my_index',
  queryVector: [0.1, 0.2 /* ... */],
  filter: {
    $and: [{ category: { $in: ['docs', 'guides'] } }, { views: { $gt: 100 } }],
  },
})
```

### 注意事項及限制 {/* #notes-and-limitations */}

* Weaviate 無法分辨欄位是明確儲存為 `null`，還是根本不存在，因此不支援寫入空值後再原樣讀取。
* 不支援 `$regex`、`$size`、`$elemMatch`、`$nor` 和 `$contains`。
* Weaviate 會將集合名稱的首字母改為大寫。原有索引名稱會保留在集合描述內，並由 `listIndexes()` 和 `describeIndex()` 返回。
