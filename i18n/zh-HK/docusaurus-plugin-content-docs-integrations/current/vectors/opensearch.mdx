# OpenSearch 向量儲存

OpenSearchVector 類別利用開源搜尋及分析引擎 [OpenSearch](https://opensearch.org/) 提供向量搜尋，並使用 OpenSearch 的 k-NN 功能尋找相似向量。

## 建構函數選項 {/* #constructor-options */}

建構函數接受 [OpenSearch ClientOptions](https://opensearch.org/docs/latest/clients/javascript/index/) 的所有選項，另外必須提供 `id` 欄位。
