# Azure AI Search 向量儲存

`AzureAISearchVector` 類別透過 [Azure AI Search](https://learn.microsoft.com/azure/search/vector-search-overview) 執行向量搜尋。這項 Microsoft 雲端搜尋服務原生支援向量搜尋。你可透過此類別使用現有的 Azure AI Search 資源篩選元數據、混合搜尋向量與文字，並按語義排序。

## Azure AI Search 專用查詢方法 {/* #azure-specific-query-methods */}

除標準的 `query()` 外，`AzureAISearchVector` 亦提供以下方法，供你使用 Azure AI Search 的專用查詢功能。

* **`advancedQuery()`** 讓你直接指定 Azure AI Search 向量查詢的參數，包括窮舉搜尋、查詢權重、過度取樣、多向量搜尋所用的額外向量查詢、前置或後置篩選模式，以及文字查詢類型（`semantic`、`hybrid`）。
* **`semanticQuery()`** 是 `advancedQuery()` 的便捷封裝，可按已配置的語義設定排序。
* **`hybridQuery()`** 提供便捷的呼叫方式，把向量搜尋與全文查詢合併為一次查詢。
* **`multiVectorQuery()`** 提供便捷的呼叫方式，可同時以多個附有權重的向量進行查詢。
* **`exactQuery()`** 是 `advancedQuery()` 的便捷封裝，會啟用窮舉搜尋以取得精確結果。

這些方法是標準查詢以外的補充。Mastra 的語義檢索繼續使用與 Memory 兼容的 `query()` 作為查詢入口。

## 回應類型 {/* #response-types */}

查詢結果按以下格式回傳。

```typescript
interface QueryResult {
  id: string
  score: number
  metadata: Record<string, any>
  document?: string // Matched document content
  vector?: number[] // Only included if includeVector is true
}
```
