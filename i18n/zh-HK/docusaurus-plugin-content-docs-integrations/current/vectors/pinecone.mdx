# Pinecone 向量儲存

`PineconeVector` 類別提供存取 [Pinecone](https://www.pinecone.io/) 向量資料庫的介面。
它支援即時向量搜尋，以及混合搜尋、元資料篩選和命名空間管理等功能。

查詢結果以如下格式傳回：

```typescript
interface QueryResult {
  id: string
  score: number
  metadata?: Record<string, any>
  vector?: number[] // Only included if includeVector is true
}
```

## 錯誤處理 {/* #error-handling */}

此向量儲存會拋出來自 `@mastra/core/error` 的 `MastraError` 實例：

```typescript
import { MastraError } from '@mastra/core/error'

try {
  await store.query({
    indexName: 'index_name',
    queryVector: queryVector,
  })
} catch (error) {
  if (error instanceof MastraError) {
    console.log(error.id) // 'MASTRA_VECTOR_PINECONE_QUERY_FAILED'
    console.log(error.domain) // 'STORAGE'
    console.log(error.category) // 'USER' | 'THIRD_PARTY'
    console.log(error.details) // Additional error context
  }
}
```

## 混合搜尋 {/* #hybrid-search */}

Pinecone 結合密集向量和稀疏向量來支援混合搜尋。使用方法如下：

1. 建立索引時設定 `metric: 'dotproduct'`
2. 執行 upsert 時，透過 `sparseVectors` 參數提供稀疏向量
3. 查詢時，透過 `sparseVector` 參數提供稀疏向量
