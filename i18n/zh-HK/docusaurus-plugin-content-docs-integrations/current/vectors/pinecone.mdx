# 松果向量商店

PineconeVector 類別提供了一個介面[Pinecone](https://www.pinecone.io/)的向量資料庫。
它提供即時向量搜索，具有混合搜索、元資料過濾和命名空間管理等功能。

## 回應類型 {/* #response-types */}

查詢結果以如下格式傳回：

```typescript
interface QueryResult {
  id: string
  score: number
  metadata?: Record<string, any>
  vector?: number[] // Only included if includeVector is true
}
```

## 錯誤處理 {/* #error-handling */}

店裡丟`MastraError` instances from `@mastra/core/error`:

```typescript
import { MastraError } from '@mastra/core/error'

try {
  await store.query({
    indexName: 'index_name',
    queryVector: queryVector,
  })
} catch (error) {
  if (error instanceof MastraError) {
    console.log(error.id) // 'MASTRA_VECTOR_PINECONE_QUERY_FAILED'
    console.log(error.domain) // 'STORAGE'
    console.log(error.category) // 'USER' | 'THIRD_PARTY'
    console.log(error.details) // Additional error context
  }
}
```

## 混合搜尋 {/* #hybrid-search */}

Pinecone 透過組合密集向量和稀疏向量來支援混合搜尋。要使用混合搜尋：

1. 建立索引`metric: 'dotproduct'`
2. 在更新插入期間，使用提供稀疏向量`sparseVectors` parameter
3. 在查詢期間，使用以下方法提供稀疏向量`sparseVector` parameter
