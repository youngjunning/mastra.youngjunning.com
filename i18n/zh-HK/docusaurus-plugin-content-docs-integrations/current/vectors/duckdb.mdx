# DuckDB 向量儲存

DuckDB 儲存實作以進程內分析數據庫 [DuckDB](https://duckdb.org/) 為基礎，提供高效能的嵌入式向量搜尋。它使用 VSS 擴充功能及 HNSW 索引進行向量相似度搜尋，無需外部伺服器即可使用輕量、高效的向量數據庫。

它屬於 `@mastra/duckdb` 套件，支援高效的向量相似度搜尋及元數據篩選。

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/duckdb@latest
```

## 用法 {/* #usage */}

```typescript oxfmt:false
import { DuckDBVector } from "@mastra/duckdb";

// Create a new vector store instance
const store = new DuckDBVector({
  id: "duckdb-vector",
  path: ":memory:", // or './vectors.duckdb' for file persistence
});

// Create an index
await store.createIndex({
  indexName: "myCollection",
  dimension: 1536,
  metric: "cosine",
});

// Add vectors with metadata
const vectors = [[0.1, 0.2, ...], [0.3, 0.4, ...]];
const metadata = [
  { text: "first document", category: "A" },
  { text: "second document", category: "B" },
];
await store.upsert({
  indexName: "myCollection",
  vectors,
  metadata,
});

// Query similar vectors
const queryVector = [0.1, 0.2, ...];
const results = await store.query({
  indexName: "myCollection",
  queryVector,
  topK: 10,
  filter: { category: "A" },
});

// Clean up
await store.close();
```

## 篩選運算子 {/* #filter-operators */}

DuckDB 向量儲存支援類似 MongoDB 的篩選運算子：

| 類別 | 運算子 |
| - | - |
| 比較 | `$eq`, `$ne`, `$gt`, `$gte`, `$lt`, `$lte` |
| 邏輯 | `$and`, `$or`, `$not`, `$nor` |
| 陣列 | `$in`, `$nin`, `$all` |
| 元素 | `$exists` |
| 文字 | `$contains` |

### 篩選條件範例 {/* #filter-examples */}

```typescript oxfmt:false
// Allegato operators
const results = await store.query({
  indexName: "docs",
  queryVector: [...],
  filter: {
    $and: [
      { category: "electronics" },
      { price: { $gte: 100, $lte: 500 } },
    ],
  },
});

// Nested field access
const results = await store.query({
  indexName: "docs",
  queryVector: [...],
  filter: { "user.profile.tier": "premium" },
});
```

## 距離度量 {/* #distance-metrics */}

| 度量 | 說明 | 分數解讀 | 適用情況 |
| - | - | - | - |
| `cosine` | 餘弦相似度 | -1 至 1，按 `1 - cosine distance` 計算（1 代表最相似） | 文字嵌入、正規化向量 |
| `euclidean` | L2 距離 | 0 至 1，按 `1 / (1 + distance)` 計算（1 代表最相似） | 圖像嵌入、空間數據 |
| `dotproduct` | 內積 | 越高代表越相似 | 向量長度會影響結果時 |

## 錯誤處理 {/* #error-handling */}

此向量儲存會因應不同的失敗情況拋出特定錯誤：

```typescript
try {
  await store.query({
    indexName: 'my-collection',
    queryVector: queryVector,
  })
} catch (error) {
  if (error.message.includes('not found')) {
    console.error('The specified index does not exist')
  } else if (error.message.includes('Invalid identifier')) {
    console.error('Index name contains invalid characters')
  } else {
    console.error('Vector store error:', error.message)
  }
}
```

常見錯誤狀況包括：

* 索引名稱格式無效
* 找不到索引或資料表
* 查詢向量與索引的維度不符
* 刪除或更新操作使用空的篩選條件或 `ids` 陣列
* 同時提供互斥的 `id` 與 `filter`

## 使用案例 {/* #use-cases */}

### 嵌入式語義搜尋 {/* #embedded-semantic-search */}

透過完全在進程內執行的語意搜尋，建立可離線運作的 AI 應用程式：

```typescript
const store = new DuckDBVector({
  id: 'offline-search',
  path: './search.duckdb',
})
```

### 本機 RAG 流程 {/* #local-rag-pipelines */}

在本機處理敏感文件，無需將數據傳送到雲端向量數據庫：

```typescript
const store = new DuckDBVector({
  id: 'private-rag',
  path: './confidential.duckdb',
  dimensions: 1536,
})
```

### 開發與測試 {/* #development-and-testing */}

無需額外基礎設施，即可快速製作向量搜尋功能原型：

```typescript
const store = new DuckDBVector({
  id: 'dev-store',
  path: ':memory:', // Fast in-memory for tests
})
```
