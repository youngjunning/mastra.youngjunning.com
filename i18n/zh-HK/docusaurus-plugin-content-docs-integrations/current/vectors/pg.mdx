# PG 向量儲存

PgVector 類別透過 [PostgreSQL](https://www.postgresql.org/) 的 [pgvector](https://github.com/pgvector/pgvector) 擴充功能提供向量搜尋，讓現有的 PostgreSQL 資料庫具備可靠的向量相似度搜尋能力。

#### 記憶體需求 {/* #memory-requirements */}

HNSW 索引在建立期間需要大量共享記憶體。以 100K 個向量為例：

* 低維度（64d）：預設設定下約 60 MB
* 中等維度（256d）：預設設定下約 180 MB
* 高維度（384d+）：預設設定下約 250 MB 或以上

較高的 M 值或 efConstruction 值會大幅增加記憶體需求。有需要時請調整系統的共享記憶體限制。

  dimension: number
  count: number
  metric: 'cosine' | 'euclidean' | 'dotproduct' | 'hamming' | 'jaccard'
  type: 'flat' | 'hnsw' | 'ivfflat'

## 索引設定指南 {/* #index-configuration-guide */}

### 效能優化 {/* #performance-optimization */}

#### IVFFlat 參數調整 {/* #ivfflat-tuning */}

* **lists 參數**：設為 `sqrt(n) * 2`，其中 n 是向量數目
* 清單越多，準確度越高，但建立時間越長
* 清單越少，建立速度越快，但準確度可能越低

#### HNSW 調整 {/* #hnsw-tuning */}

* **m 參數**：
  * 8-16：準確度適中，記憶體用量較低
  * 16-32：準確度高，記憶體用量適中
  * 32-64：準確度非常高，記憶體用量較高
* **efConstruction**：
  * 32-64：建立速度快，索引質素良好
  * 64-128：建立較慢，索引質素更好
  * 128-256：建立最慢，索引質素最好

### 索引重建行為 {/* #index-recreation-behavior */}

系統會自動偵測設定變更，只在有需要時重建索引：

* 設定相同：保留索引，不重新建立
* 設定已變更：刪除並重建索引
* 這可避免不必要的索引重建造成效能問題

## 最佳實踐 {/* #best-practices */}

* 定期評估索引設定，確保效能達到最佳。
* 按數據集大小及查詢需求調整 `lists`、`m` 等參數。
* 使用 `describeIndex()` **監察索引效能**並追蹤使用情況。
* 定期重建索引以維持效率，尤其是在數據有大量變更後。

## 直接存取連線池 {/* #direct-pool-access */}

`PgVector` 類別透過公開欄位提供其底層 PostgreSQL 連線池：

```typescript
pgVector.pool // instance of pg.Pool
```

直接存取連線池可用於執行 SQL 查詢、交易或監察連線池狀態等進階操作。直接使用連線池時：

* 使用用戶端後，您須自行呼叫 `client.release()` 釋放它。
* 呼叫 `disconnect()` 後仍可存取連線池，但新的查詢會失敗。
* 直接存取會略過 PgVector 方法提供的驗證或交易邏輯。

這項設計支援進階使用情境，但用戶須謹慎管理資源。

## 使用範例 {/* #usage-example */}

### 使用 fastembed 產生本機嵌入向量 {/* #local-embeddings-with-fastembed */}

嵌入是數值向量，Memory 的 `semanticRecall` 會用它按語義而非關鍵字擷取相關訊息。這項設定使用 `@mastra/fastembed` 產生嵌入向量。

請先安裝 `fastembed`：

```bash npm2yarn
npm install @mastra/fastembed@latest
```

將以下內容加入您的 Agent：

```typescript title="src/mastra/agents/example-pg-agent.ts"
import { Memory } from '@mastra/memory'
import { Agent } from '@mastra/core/agent'
import { PostgresStore, PgVector } from '@mastra/pg'
import { fastembed } from '@mastra/fastembed'

export const pgAgent = new Agent({
  id: 'pg-agent',
  name: 'PG Agent',
  instructions:
    'You are an AI agent with the ability to automatically recall memories from previous interactions.',
  model: '__GATEWAY_OPENAI_MODEL__',
  memory: new Memory({
    storage: new PostgresStore({
      id: 'pg-agent-storage',
      connectionString: process.env.DATABASE_URL!,
    }),
    vector: new PgVector({
      id: 'pg-agent-vector',
      connectionString: process.env.DATABASE_URL!,
    }),
    embedder: fastembed,
    options: {
      lastMessages: 10,
      semanticRecall: {
        topK: 3,
        messageRange: 2,
      },
    },
  }),
})
```
