# PG向量存儲

PgVector 類別提供向量搜索[PostgreSQL](https://www.postgresql.org/)和[PG向量](https://github.com/pgvector/pgvector)擴大。它在您現有的 PostgreSQL 資料庫中提供可靠的向量相似性搜尋功能。

## 構造函數範例 {/* #constructor-examples */}

### 連接字串 {/* #connection-string */}

```ts
import { PgVector } from '@mastra/pg'

const vectorStore = new PgVector({
  id: 'pg-vector',
  connectionString: 'postgresql://user:password@localhost:5432/mydb',
})
```

### 主機/連接埠/資料庫配置 {/* #hostportdatabase-configuration */}

```ts
const vectorStore = new PgVector({
  id: 'pg-vector',
  host: 'localhost',
  port: 5432,
  database: 'mydb',
  user: 'postgres',
  password: 'password',
})
```

### 進階配置 {/* #advanced-configuration */}

```ts
const vectorStore = new PgVector({
  id: 'pg-vector',
  connectionString: 'postgresql://user:password@localhost:5432/mydb',
```

#### 記憶體需求 {/* #memory-requirements */}

HNSW 索引在建置期間需要大量共享記憶體。對於 100K 向量：

* 小尺寸 (64d)：預設設定約 60MB
* 中等尺寸 (256d)：預設約 180MB
* 大尺寸 (384d+)：預設值約 250MB+

較高的 M 值或 efConstruction 值將顯著增加記憶體需求。如果需要，調整系統的共享記憶體限制。

<PropertiesTable
  content={[
{

返回：

```typescript
interface PGIndexStats {
  dimension: number
  count: number
  metric: 'cosine' | 'euclidean' | 'dotproduct' | 'hamming' | 'jaccard'
  type: 'flat' | 'hnsw' | 'ivfflat'
  vectorType: 'vector' | 'halfvec' | 'bit' | 'sparsevec'
  config: {
    m?: number
    efConstruction?: number
    lists?: number
    probes?: number
  }
}
```

`count`是一個精確的`SELECT COUNT(*)`, which scans the whole table, so avoid calling `describeIndex()` on a hot path for a large index. Reads and writes never pay for it: they only use the index metadata, which comes from the Postgres catalog.

```typescript

  type: 'hnsw',
  hnsw: {
    m: 8,
    efConstruction: 32,
  },
})

// Define IVF index
await pgVector.buildIndex('my_vectors', 'cosine', {
  type: 'ivfflat',
  ivf: {
    lists: 100,
  },
})

// Define flat index
await pgVector.buildIndex('my_vectors', 'cosine', {
  type: 'flat',
})
```

## 索引配置指南 {/* #index-configuration-guide */}

### 效能最佳化 {/* #performance-optimization */}

#### IVF平面調諧 {/* #ivfflat-tuning */}

* **列出參數**：設定為`sqrt(n) * 2` where n is the number of vectors
* 更多列表 = 更高的準確性，但構建時間更慢
* 更少的列表 = 更快的構建，但可能會降低準確性

#### HNSW 調整 {/* #hnsw-tuning */}

* **m參數**:
  * 8-16：中等精度，較低內存
  * 16-32：精度高，記憶體適中
  * 32-64：非常高精度，高內存
* **ef建築**:
  * 32-64：建造速度快，品質好
  * 64-128：建造速度較慢，品質較好
  * 128-256：最慢的構建，最好的質量

### 休閒行為指數 {/* #index-recreation-behavior */}

系統自動偵測配置更改，僅在必要時重建索引：

* 相同配置：保留索引（不重新建立）
* 更改的配置：索引被刪除並重建
* 這可以防止不必要的索引重新建立帶來的效能問題

## 最佳實踐 {/* #best-practices */}

* 定期評估您的索引配置以確保最佳效能。
* 調整參數如`lists` and `m` based on dataset size and query requirements.
* **監控指數表現**使用`describeIndex()` to track usage
* 定期重建索引以保持效率，尤其是在大量資料變更之後

## 直接訪問泳池 {/* #direct-pool-access */}

這`PgVector` class exposes its underlying PostgreSQL connection pool as a public field:

```typescript
pgVector.pool // instance of pg.Pool
```

直接池存取支援進階操作，例如直接 SQL 查詢、交易或池狀態監視。直接使用池時：

* 您負責釋放客戶（`client.release()`) after use.
* 呼叫後泳池仍可訪問`disconnect()`, but new queries will fail.
* 直接存取繞過 PgVector 方法提供的任何驗證或事務邏輯。

此設計支援高階用例，但需要使用者仔細管理資源。

## 使用範例 {/* #usage-example */}

### 使用 fastembed 進行本地嵌入 {/* #local-embeddings-with-fastembed */}

嵌入是記憶體使用的數字向量`semanticRecall` to retrieve related messages by meaning (not keywords). This setup uses `@mastra/fastembed` to generate vector embeddings.

安裝`fastembed` to get started:

```bash npm2yarn
npm install @mastra/fastembed@latest
```

將以下內容新增至您的Agent程式：

```typescript title="src/mastra/agents/example-pg-agent.ts"
import { Memory } from '@mastra/memory'
import { Agent } from '@mastra/core/agent'
import { PostgresStore, PgVector } from '@mastra/pg'
import { fastembed } from '@mastra/fastembed'

export const pgAgent = new Agent({
  id: 'pg-agent',
  name: 'PG Agent',
  instructions:
    'You are an AI agent with the ability to automatically recall memories from previous interactions.',
  model: '__GATEWAY_OPENAI_MODEL__',
  memory: new Memory({
    storage: new PostgresStore({
      id: 'pg-agent-storage',
      connectionString: process.env.DATABASE_URL!,
    }),
    vector: new PgVector({
      id: 'pg-agent-vector',
      connectionString: process.env.DATABASE_URL!,
    }),
    embedder: fastembed,
    options: {
      lastMessages: 10,
      semanticRecall: {
        topK: 3,
        messageRange: 2,
      },
    },
  }),
})
```
