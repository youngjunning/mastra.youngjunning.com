# Astra 向量儲存

AstraVector 類別使用 [DataStax Astra DB](https://www.datastax.com/products/datastax-astra) 進行向量搜尋。Astra DB 是建基於 Apache Cassandra 的雲端原生無伺服器數據庫，提供具備企業級容量及高可用性的向量搜尋功能。

### `deleteVectors()` {/* #deletevectors */}

Astra 未有實作此方法。呼叫時會拋出 ID 為 `MASTRA_VECTOR_ASTRA_DELETE_VECTORS_NOT_SUPPORTED` 的 `MastraError`。如要刪除多個向量，請使用 `deleteVector()` 逐個刪除。

## 回應類型 {/* #response-types */}

查詢結果會以以下格式回傳。

```typescript
interface QueryResult {
  id: string
  score: number
  metadata?: Record<string, any>
  vector?: number[] // Only included if includeVector is true
  document?: string // Only returned by stores that keep document content
}
```

## 錯誤處理 {/* #error-handling */}

向量儲存會拋出由 `@mastra/core/error` 定義的 `MastraError` 實例。

```typescript
import { MastraError } from '@mastra/core/error'

try {
  await store.query({
    indexName: 'index_name',
    queryVector: queryVector,
  })
} catch (error) {
  if (error instanceof MastraError) {
    console.log(error.id) // 'MASTRA_VECTOR_ASTRA_QUERY_DB_ERROR'
    console.log(error.domain) // 'MASTRA_VECTOR'
    console.log(error.category) // 'USER' | 'THIRD_PARTY'
    console.log(error.details) // Additional error context
  }
}
```
