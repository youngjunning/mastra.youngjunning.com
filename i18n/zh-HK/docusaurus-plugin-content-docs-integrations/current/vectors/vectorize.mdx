# Cloudflare 向量儲存

CloudflareVector 類別透過 [Cloudflare Vectorize](https://developers.cloudflare.com/vectorize/) 提供向量搜尋。Cloudflare Vectorize 是一項整合至 Cloudflare 邊緣網絡的向量數據庫服務。

## 錯誤處理 {/* #error-handling */}

此向量儲存會拋出 `@mastra/core/error` 中定義的 `MastraError` 實例：

```typescript
import { MastraError } from '@mastra/core/error'

try {
  await store.query({
    indexName: 'index_name',
    queryVector: queryVector,
  })
} catch (error) {
  if (error instanceof MastraError) {
    console.log(error.id) // 'MASTRA_VECTOR_VECTORIZE_QUERY_FAILED'
    console.log(error.domain) // 'STORAGE'
    console.log(error.category) // 'USER' | 'THIRD_PARTY'
    console.log(error.details) // Additional error context
  }
}
```

## 環境變量 {/* #environment-variables */}

所需的環境變量：

* `CLOUDFLARE_ACCOUNT_ID`：您的 Cloudflare 帳戶 ID
* `CLOUDFLARE_API_TOKEN`：具備 Vectorize 權限的 Cloudflare API 權杖
