# Chroma 向量儲存

ChromaVector 類別使用開源嵌入資料庫 [Chroma](https://docs.trychroma.com/docs/overview/getting-started) 提供向量搜尋，支援元資料篩選及混合搜尋。

## 執行 Chroma 伺服器 {/* #running-a-chroma-server */}

如果使用 Chroma Cloud，請向 `ChromaVector` 建構函式提供 API 金鑰、租戶名稱及資料庫名稱。

安裝 `@mastra/chroma` 套件後，即可使用 [Chroma CLI](https://docs.trychroma.com/docs/cli/db)。它可透過 `chroma db connect [DB-NAME] --env-file` 為你設定這些環境變數。

如需自行設定單節點 Chroma 伺服器，可選擇以下方式：

* 使用 Chroma CLI 在本機執行：`chroma run`。更多設定選項請參閱 [Chroma 文件](https://docs.trychroma.com/docs/cli/run)。
* 使用 Chroma 官方映像檔，在 [Docker](https://docs.trychroma.com/guides/deploy/docker) 中執行。
* 在你選擇的雲端服務平台部署自己的 Chroma 伺服器。Chroma 提供 [AWS](https://docs.trychroma.com/guides/deploy/aws)、[Azure](https://docs.trychroma.com/guides/deploy/azure) 及 [GCP](https://docs.trychroma.com/guides/deploy/gcp) 的示例範本。

### `deleteVectors()` {/* #deletevectors */}

根據 ID 或元資料篩選條件刪除多個向量。此方法支援批量刪除及按來源管理向量。必須提供 `ids` 或 `filter`，但不可同時提供。

<PropertiesTable
  content={[
{
  name: 'indexName',
  type: 'string',
  description: '包含待刪除向量的索引名稱',
},
{
  name: 'ids',
  type: 'string[]',
  isOptional: true,
  description: '待刪除向量的 ID 陣列（不可與 filter 同時使用）',
},
{
  name: 'filter',
  type: 'Record<string, any>',
  isOptional: true,
  description: '用作找出待刪除向量的元資料篩選條件（不可與 ids 同時使用）',
},
]}
/>

例子：

```typescript
// Delete all chunks from a document
await vectorStore.deleteVectors({
  indexName: 'docs',
  filter: { source_id: 'manual.pdf' },
})

// Delete multiple vectors by ID
await vectorStore.deleteVectors({
  indexName: 'docs',
  ids: ['vec_1', 'vec_2', 'vec_3'],
})

// Delete old temporary documents
await vectorStore.deleteVectors({
  indexName: 'docs',
  filter: {
    $and: [{ bucket: 'temp' }, { indexed_at: { $lt: '2025-01-01' } }],
  },
})
```


## 錯誤處理 {/* #error-handling */}

此儲存會拋出來自 `@mastra/core/error` 的 `MastraError` 實例：

```typescript
import { MastraError } from '@mastra/core/error'

try {
  await store.query({
    indexName: 'index_name',
    queryVector: queryVector,
  })
} catch (error) {
  if (error instanceof MastraError) {
    console.log(error.id) // 'MASTRA_VECTOR_CHROMA_QUERY_FAILED'
    console.log(error.domain) // 'MASTRA_VECTOR'
    console.log(error.category) // 'USER' | 'THIRD_PARTY'
    console.log(error.details) // Additional error context
  }
}
```
