# 集線點

為Agent商提供Tool來搜尋、建立和更新聯絡人、公司、交易和票證，並透過 Mastra Connect 在 HubSpot 中管理註釋、任務和行銷電子郵件。每個Tool呼叫都會透過 Mastra 平台，該平台會新增連接的憑證。您的應用程式從不儲存 HubSpot 憑證。

## 連接 {/* #connect */}

在開始之前，請完成[Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect`並配置您的平台項目。

### 連接帳戶 {/* #connect-an-account */}

從包含您的目錄的目錄執行此命令`.env` file:

```bash
mastra connect add hubspot
```

CLI 將引導您完成 HubSpot 的授權並等待連線啟動。

### 向Agent添加Tool {/* #add-tools-to-an-agent */}

經過[`tools()`](/reference/connect/tools) to the agent and select the `hubspot` provider:

```typescript title="src/mastra/agents/hubspot-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const hubspotAgent = new Agent({
  id: 'hubspot-agent',
  name: 'HubSpot agent',
  instructions:
    'You help people search, create, and update contacts, companies, deals, and tickets, and manage notes, tasks, and marketing emails in HubSpot.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['hubspot'] }),
})
```

Agent商獲得 50 個 HubSpot Tool，其中包含以下密鑰`hubspot_batch_create_companies`. See [HubSpot tools](/reference/connect/providers#hubspot) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
