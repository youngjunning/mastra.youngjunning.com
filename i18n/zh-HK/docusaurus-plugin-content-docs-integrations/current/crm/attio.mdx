# 阿蒂奧

為客服人員提供Tool，可透過 Mastra Connect 在 Attio 中搜尋和更新 CRM 記錄、註釋、任務和清單。 Attio 從託管模型上下文協定 (MCP) 伺服器提供這些Tool。您的應用程式從不儲存 Attio 憑證。

## 連接 {/* #connect */}

在開始之前，請完成[Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect`並配置您的平台項目。

### 連接帳戶 {/* #connect-an-account */}

從包含您的目錄的目錄執行此命令`.env` file:

```bash
mastra connect add attio-mcp
```

CLI 將引導您完成 Attio 的授權並等待連線啟動。

### 向Agent添加Tool {/* #add-tools-to-an-agent */}

經過[`tools()`](/reference/connect/tools) to the agent and select the `attio-mcp` provider:

```typescript title="src/mastra/agents/attio-mcp-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const attioMcpAgent = new Agent({
  id: 'attio-mcp-agent',
  name: 'Attio agent',
  instructions: 'You help people search and update CRM records, notes, tasks, and lists in Attio.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['attio-mcp'] }),
})
```

當Agent程式運行時，Mastra 會從其 MCP 伺服器發現 Attio 的Tool。可用的Tool取決於伺服器和連接的帳戶，而不取決於您的`@mastra/connect` version. Tool keys start with `attio-mcp_`.

要查看 Attio 提供的Tool，請閱讀[Attio MCP](https://docs.attio.com/mcp/overview) documentation. To require approval before a call runs, see [MCP providers](/reference/connect/tools#mcp-providers) in the `tools()` reference.
