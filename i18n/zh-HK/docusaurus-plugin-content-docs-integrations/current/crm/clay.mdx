# Clay

透過 Mastra Connect，為 Agent 提供可在 Clay 中尋找及研究人員與公司，並執行 Workflow 的 Tool。Clay 透過託管的 Model Context Protocol (MCP) 伺服器提供這些 Tool；你的應用程式不會儲存 Clay 憑證。

## 連接 {/* #connect */}

開始前，請先完成 [Connect 設定](/docs/mastra-platform/connect#get-started)，安裝 `@mastra/connect` 並設定 Mastra 平台項目。

### 連接帳戶 {/* #connect-an-account */}

請在包含 `.env` 檔案的目錄中執行以下指令：

```bash
mastra connect add clay-mcp
```

CLI 會引導你完成 Clay 授權，並等待連接啟用。

### 將 Tool 加入 Agent {/* #add-tools-to-an-agent */}

將 [`tools()`](/reference/connect/tools) 傳給 Agent，並選擇 `clay-mcp` Provider：

```typescript title="src/mastra/agents/clay-mcp-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const clayMcpAgent = new Agent({
  id: 'clay-mcp-agent',
  name: 'Clay agent',
  instructions: 'You help people find and research people and companies and run workflows in Clay.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['clay-mcp'] }),
})
```

Agent 執行時，Mastra 會從 Clay 的 MCP 伺服器探索可用 Tool。這些 Tool 取決於伺服器和已連接的帳戶，而不是你的 `@mastra/connect` 版本。Tool key 以 `clay-mcp_` 開頭。

如需查看 Clay 提供的 Tool，請參閱 [MCP in Clay](https://university.clay.com/docs/mcp-settings) 文件。如需要求每次呼叫在執行前取得批准，請參閱 `tools()` 參考中的 [MCP Provider](/reference/connect/tools#mcp-providers)。
