# 黏土

為Agent商提供Tool來尋找和研究人員和公司，並透過 Mastra Connect 在 Clay 中運行Workflow。 Clay 從託管的模型上下文協定 (MCP) 伺服器提供這些Tool。您的應用程式從不儲存 Clay 憑證。

## 連接 {/* #connect */}

在開始之前，請完成[Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect`並配置您的平台項目。

### 連接帳戶 {/* #connect-an-account */}

從包含您的目錄的目錄執行此命令`.env` file:

```bash
mastra connect add clay-mcp
```

CLI 將引導您完成 Clay 的授權並等待連線啟動。

### 向Agent添加Tool {/* #add-tools-to-an-agent */}

經過[`tools()`](/reference/connect/tools) to the agent and select the `clay-mcp` provider:

```typescript title="src/mastra/agents/clay-mcp-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const clayMcpAgent = new Agent({
  id: 'clay-mcp-agent',
  name: 'Clay agent',
  instructions: 'You help people find and research people and companies and run workflows in Clay.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['clay-mcp'] }),
})
```

當Agent程式運行時，Mastra 從其 MCP 伺服器發現 Clay 的Tool。可用的Tool取決於伺服器和連接的帳戶，而不取決於您的`@mastra/connect` version. Tool keys start with `clay-mcp_`.

若要查看 Clay 提供的Tool，請閱讀[MCP in Clay](https://university.clay.com/docs/mcp-settings) documentation. To require approval before a call runs, see [MCP providers](/reference/connect/tools#mcp-providers) in the `tools()` reference.
