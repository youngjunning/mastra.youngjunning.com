# WhatsApp

WhatsApp 頻道讓 Mastra Agent 透過 WhatsApp Business Cloud 接收客戶訊息。Mastra 負責串接 Agent 及處理 webhook 路由。Meta 應用程式、憑證及 webhook 的設定方法載於 Chat SDK 的 WhatsApp 轉接器文件。

## 安裝轉接器 {/* #install-the-adapter */}

安裝 Chat SDK 提供的 WhatsApp 轉接器：

```bash npm2yarn
npm install @chat-adapter/whatsapp
```

## Agent 設定 {/* #agent-configuration */}

將 `createWhatsAppAdapter()` 加入 Agent 的 `channels.adapters` 物件：

```typescript title="src/mastra/agents/whatsapp-agent.ts"
import { Agent } from '@mastra/core/agent'
import { createWhatsAppAdapter } from '@chat-adapter/whatsapp'

export const whatsappAgent = new Agent({
  id: 'whatsapp-agent',
  name: 'WhatsApp Agent',
  instructions: 'Answer customer questions and help with tasks in WhatsApp.',
  model: '__GATEWAY_OPENAI_MODEL__',
  channels: {
    adapters: {
      whatsapp: createWhatsAppAdapter(),
    },
  },
})
```

在 Mastra 實例中註冊 Agent：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { whatsappAgent } from './agents/whatsapp-agent'

export const mastra = new Mastra({
  agents: { whatsappAgent },
})
```

## 設定轉接器 {/* #adapter-setup */}

按照 [Chat SDK 的 WhatsApp 轉接器文件](https://chat-sdk.dev/adapters/official/whatsapp)完成 WhatsApp 專用設定，包括 Meta 應用程式設定、存取權杖、電話號碼 ID、webhook 驗證及訊息限制。

轉接器會從環境變數讀取 WhatsApp 憑證，例如：

```bash title=".env"
WHATSAPP_ACCESS_TOKEN=your-meta-access-token
WHATSAPP_APP_SECRET=your-meta-app-secret
WHATSAPP_PHONE_NUMBER_ID=your-whatsapp-phone-number-id
WHATSAPP_VERIFY_TOKEN=your-webhook-verify-token
```

## Webhook URL {/* #webhook-url */}

Mastra 會根據 Agent ID 和轉接器的鍵名產生 WhatsApp webhook 路由：

```text
/api/agents/whatsapp-agent/channels/whatsapp/webhook
```

使用可公開存取的 Mastra 伺服器 URL 作為基礎 URL：

```text
https://your-app.example.com/api/agents/whatsapp-agent/channels/whatsapp/webhook
```

使用此 URL 接收 WhatsApp 傳送的事件。Mastra 產生的路由會處理來自 WhatsApp 的 POST 事件。Meta 回調及 webhook 驗證流程請按照 Chat SDK 的 WhatsApp 轉接器文件操作。
