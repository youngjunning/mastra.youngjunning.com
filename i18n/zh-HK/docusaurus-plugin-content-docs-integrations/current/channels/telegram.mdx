# 電報

Telegram 頻道讓人們可以透過 Telegram 直接訊息、群組和機器人提及與您的客服人員交談。

[馬斯特拉連接](/docs/mastra-platform/connect)將您的 Telegram 機器人令牌儲存在 Mastra 平台上並為您註冊 webhook。您還可以自行管理機器人令牌和 webhook。

## 連接 {/* #connect */}

在開始之前，請完成[Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect` and configure your platform project.

Connect 使用 BotFather 的機器人令牌。在連接Agent之前，請設定`MASTRA_ENCRYPTION_KEY` on a persistent production server. Mastra uses it to encrypt the stored webhook secret. Without a key, the secret is stored unencrypted.

Webhook 模式需要公用 HTTPS 伺服器 URL。 Mastra 平台提供此 URL。當您在其他地方託管時，請設定`MASTRA_SERVER_URL` to your public server URL. For local development without a public webhook URL, the [Telegram provider reference](/reference/channels/telegram-provider) describes polling mode.

1. 打開[BotFather](https://t.me/botfather), run `/newbot`, and follow the prompts.

2. 複製 BotFather 返回的機器人令牌。

3. 跑步`mastra connect add telegram` and enter the bot token.

4. 經過[`channels()`](/reference/connect/channels) to the `Mastra` constructor. It registers the Telegram channel provider and its routes:

   ```typescript title="src/mastra/index.ts"
   import { Mastra } from '@mastra/core'
   import { channels } from '@mastra/connect'
   import { assistant } from './agents/assistant'

   export const mastra = new Mastra({
     agents: { assistant },
     channels: await channels({ providers: ['telegram'] }),
   })
   ```

   若要也註冊其他頻道，請將其提供者 ID 新增至`providers`.

5. 啟動您的 Mastra 申請。

6. 在 Studio 中，將 Telegram 通道連接到Agent程式。 Mastra 驗證機器人，建立 Webhook 機密，並使用 Telegram 註冊Agent程式的公共 Webhook URL。

若要將Agent程式變更為其他機器人，請在 Studio 中斷開Agent程式的連接，然後重新連接。 Mastra 不會將現有Agent的 webhook 移到另一個機器人。

## 自我管理設定 {/* #self-managed-setup */}

將 Chat SDK Telegram 適配器與您自己的機器人令牌和 Webhook 結合使用。

### 安裝適配器 {/* #install-the-adapter */}

從 Chat SDK 安裝 Telegram 轉接器：

```bash npm2yarn
npm install @chat-adapter/telegram
```

### Agent配置 {/* #agent-configuration */}

添加`createTelegramAdapter()` to the agent's `channels.adapters` object:

```typescript title="src/mastra/agents/telegram-agent.ts"
import { Agent } from '@mastra/core/agent'
import { createTelegramAdapter } from '@chat-adapter/telegram'

export const telegramAgent = new Agent({
  id: 'telegram-agent',
  name: 'Telegram Agent',
  instructions: 'Answer questions and help with tasks in Telegram.',
  model: '__GATEWAY_OPENAI_MODEL__',
  channels: {
    adapters: {
      telegram: createTelegramAdapter(),
    },
  },
})
```

在 Mastra 實例上註冊Agent：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { telegramAgent } from './agents/telegram-agent'

export const mastra = new Mastra({
  agents: { telegramAgent },
})
```

### 適配器設定 {/* #adapter-setup */}

遵循[Chat SDK Telegram adapter docs](https://chat-sdk.dev/adapters/official/telegram) for Telegram-specific setup, including BotFather, webhook registration, secret tokens, and polling mode.

適配器從環境變數中讀取 Telegram 憑證，例如：

```bash title=".env"
TELEGRAM_BOT_TOKEN=your-telegram-bot-token
TELEGRAM_WEBHOOK_SECRET_TOKEN=your-webhook-secret-token
TELEGRAM_BOT_USERNAME=your_bot_username
```

### 網路鉤子 URL {/* #webhook-url */}

Mastra 根據Agent ID 和適配器金鑰產生 Telegram Webhook 路由：

```text
/api/agents/telegram-agent/channels/telegram/webhook
```

使用您的公用 Mastra 伺服器 URL 作為基本 URL：

```text
https://your-app.example.com/api/agents/telegram-agent/channels/telegram/webhook
```

在 Telegram 適配器文件要求提供 Webhook URL 的任何地方都可以使用此 URL。 Telegram 也支援輪詢模式。如果您想使用輪詢進行本機開發，請遵循聊天 SDK 適配器文件。
