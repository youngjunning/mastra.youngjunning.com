# Telegram

Telegram 頻道讓用戶可以透過 Telegram 私人訊息、群組及提及機械人與您的 Agent 對話。

[Mastra Connect](/docs/mastra-platform/connect) 會將您的 Telegram 機械人權杖儲存在 Mastra 平台，並代您註冊 webhook。您也可以自行管理機械人權杖和 webhook。

## Connect {/* #connect */}

開始前，請完成 [Connect 設定](/docs/mastra-platform/connect#get-started)，安裝 `@mastra/connect` 並設定您在平台上的項目。

Connect 使用 BotFather 提供的機械人權杖。連接 Agent 前，請在長期運行的正式環境伺服器上設定 `MASTRA_ENCRYPTION_KEY`。Mastra 會使用此密鑰加密儲存的 webhook 密鑰。如果未設定加密密鑰，webhook 密鑰會以未加密的形式儲存。

Webhook 模式需要可公開存取的 HTTPS 伺服器 URL。Mastra 平台會提供這個 URL。如在其他地方託管，請將 `MASTRA_SERVER_URL` 設為可公開存取的伺服器 URL。如在本機開發而沒有可公開存取的 webhook URL，可參閱 [Telegram Provider 參考文件](/reference/channels/telegram-provider) 了解輪詢模式。

1. 開啟 [BotFather](https://t.me/botfather)，執行 `/newbot`，然後按照提示操作。

1. 複製 BotFather 回傳的機械人權杖。

1. 執行 `mastra connect add telegram`，然後輸入機械人權杖。

1. 將 [`channels()`](/reference/connect/channels) 傳入 `Mastra` 建構函數，以註冊 Telegram 頻道的 Provider 及其路由：

   ```typescript title="src/mastra/index.ts"
   import { Mastra } from '@mastra/core'
   import { channels } from '@mastra/connect'
   import { assistant } from './agents/assistant'

   export const mastra = new Mastra({
     agents: { assistant },
     channels: await channels({ providers: ['telegram'] }),
   })
   ```

   如需一併註冊其他頻道，請將其 Provider ID 加到 `providers`。

1. 啟動您的 Mastra 應用程式。

1. 在 Studio 將 Telegram 頻道連接至 Agent。Mastra 會驗證機械人、建立 webhook 密鑰，並向 Telegram 註冊該 Agent 可公開存取的 webhook URL。

如需為 Agent 更換機械人，請在 Studio 中斷該 Agent 的連線，然後重新連接。Mastra 不會將現有 Agent 的 webhook 轉移至另一個機械人。

## 自行管理設定 {/* #self-managed-setup */}

使用 Chat SDK 的 Telegram 轉接器，並提供您自己的機械人權杖和 webhook。

### 安裝轉接器 {/* #install-the-adapter */}

從 Chat SDK 安裝 Telegram 轉接器：

```bash npm2yarn
npm install @chat-adapter/telegram
```

### Agent 設定 {/* #agent-configuration */}

將 `createTelegramAdapter()` 加到 Agent 的 `channels.adapters` 物件：

```typescript title="src/mastra/agents/telegram-agent.ts"
import { Agent } from '@mastra/core/agent'
import { createTelegramAdapter } from '@chat-adapter/telegram'

export const telegramAgent = new Agent({
  id: 'telegram-agent',
  name: 'Telegram Agent',
  instructions: 'Answer questions and help with tasks in Telegram.',
  model: '__GATEWAY_OPENAI_MODEL__',
  channels: {
    adapters: {
      telegram: createTelegramAdapter(),
    },
  },
})
```

在 Mastra 實例中註冊 Agent：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { telegramAgent } from './agents/telegram-agent'

export const mastra = new Mastra({
  agents: { telegramAgent },
})
```

### 設定轉接器 {/* #adapter-setup */}

按照 [Chat SDK 的 Telegram 轉接器文件](https://chat-sdk.dev/adapters/official/telegram) 完成 Telegram 專用設定，包括 BotFather、webhook 註冊、秘密權杖及輪詢模式。

轉接器會從以下環境變數等來源讀取 Telegram 憑證：

```bash title=".env"
TELEGRAM_BOT_TOKEN=your-telegram-bot-token
TELEGRAM_WEBHOOK_SECRET_TOKEN=your-webhook-secret-token
TELEGRAM_BOT_USERNAME=your_bot_username
```

### Webhook URL {/* #webhook-url */}

Mastra 會根據 Agent ID 和轉接器鍵值產生 Telegram webhook 路由：

```text
/api/agents/telegram-agent/channels/telegram/webhook
```

以可公開存取的 Mastra 伺服器 URL 作為基礎 URL：

```text
https://your-app.example.com/api/agents/telegram-agent/channels/telegram/webhook
```

凡 Telegram 轉接器文件要求提供 webhook URL，均可使用此 URL。Telegram 亦支援輪詢模式。如需在本機開發時使用輪詢，請按照 Chat SDK 的轉接器文件操作。
