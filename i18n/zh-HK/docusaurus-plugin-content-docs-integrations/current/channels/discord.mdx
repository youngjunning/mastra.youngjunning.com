# Discord

你可以透過以下兩種方式在 Mastra 中使用 Discord：

- **Agent 的 Tool** 讓 Agent 在 Discord 伺服器中執行操作，例如傳送訊息或管理頻道。
- **Agent 聊天**讓使用者在 Discord 透過機械人訊息，以及斜線指令和按鈕等互動方式，與你的 Agent 交談。

[Mastra Connect](/docs/mastra-platform/connect) 使用同一個 Discord 機械人設定這兩項功能，並將機械人的權杖保存在 Mastra 平台上。使用 Agent 聊天功能時，你也可以自行管理機械人的憑證。

## Connect {/* #connect */}

開始前，請完成 [Connect 設定](/docs/mastra-platform/connect#get-started)，以安裝 `@mastra/connect` 並設定你的平台項目。

一條 `discord` 連線可同時提供 Agent 的 Tool 和 Agent 聊天功能。此連線使用的是**機械人權杖**，而非使用者 OAuth 權杖。

### 建立 Discord 機械人 {/* #create-a-discord-bot */}

1. 在 [Discord 開發人員入口網站](https://discord.com/developers/applications)建立應用程式。
1. 開啟 **Bot**，加入機械人，然後選擇 **Reset Token** 並複製機械人權杖。
1. 如要使用 Agent 聊天，請在 **Privileged Gateway Intents** 下啟用 **Message Content Intent**。

當 `mastra connect add discord` 提示輸入憑證時，請輸入機械人權杖。

### Agent 聊天 {/* #agent-chat */}

你的伺服器需要一個 Discord 可存取的公開 URL，以接收 webhook 和 OAuth 回調。Mastra 平台會提供此 URL。如果在其他地方託管，請將 `MASTRA_SERVER_URL` 設為伺服器的公開 URL。本機開發時，請使用公開的 HTTPS 通道。

1. 如果尚未加入連線，請執行 `mastra connect add discord` 並輸入機械人權杖。

1. 將 [`channels()`](/reference/connect/channels) 傳入 `Mastra` 建構函式，以註冊 Discord 頻道的 Provider 及其路由：

   ```typescript title="src/mastra/index.ts"
   import { Mastra } from '@mastra/core'
   import { channels } from '@mastra/connect'
   import { assistant } from './agents/assistant'

   export const mastra = new Mastra({
     agents: { assistant },
     channels: await channels({ providers: ['discord'] }),
   })
   ```

   如需同時註冊其他頻道，請將相應的 Provider ID 加入 `providers`。

1. 啟動你的 Mastra 應用程式。

1. 在 Studio 中，將 Discord 頻道連接至 Agent。如果機械人尚未加入伺服器，請開啟產生的授權 URL，選擇伺服器並授予所要求的權限。

Discord 透過 Gateway 處理訊息，並透過 HTTP 互動路由處理斜線指令和按鈕互動。機械人邀請所要求的授權範圍和權限，請參閱 [Discord 權限](/reference/connect/channels#discord-permissions)。

## 自行管理的設定 {/* #self-managed-setup */}

使用 Chat SDK 的 Discord 配接器，配合你自己的 Discord 應用程式及憑證。

### 安裝配接器 {/* #install-the-adapter */}

從 Chat SDK 安裝 Discord 配接器：

```bash npm2yarn
npm install @chat-adapter/discord
```

### Agent 設定 {/* #agent-configuration */}

將 `createDiscordAdapter()` 加入 Agent 的 `channels.adapters` 物件：

```typescript title="src/mastra/agents/discord-agent.ts"
import { Agent } from '@mastra/core/agent'
import { createDiscordAdapter } from '@chat-adapter/discord'

export const discordAgent = new Agent({
  id: 'discord-agent',
  name: 'Discord Agent',
  instructions: 'Answer questions and help with tasks in Discord.',
  model: '__GATEWAY_OPENAI_MODEL__',
  channels: {
    adapters: {
      discord: createDiscordAdapter(),
    },
  },
})
```

在 Mastra 執行個體上註冊 Agent：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { discordAgent } from './agents/discord-agent'

export const mastra = new Mastra({
  agents: { discordAgent },
})
```

### 適配器設定 {/* #adapter-setup */}

請參閱 [Chat SDK 的 Discord 適配器文件](https://chat-sdk.dev/adapters/official/discord)，了解 Discord 專用設定，包括建立應用程式、機械人權杖、互動端點、權限及 Gateway 的運作方式。

適配器會從環境變數讀取 Discord 憑證，例如：

```bash title=".env"
DISCORD_BOT_TOKEN=your-discord-bot-token
DISCORD_PUBLIC_KEY=your-discord-application-public-key
DISCORD_APPLICATION_ID=your-discord-application-id
```

### Webhook URL {/* #webhook-url */}

Mastra 根據 Agent ID 和適配器鍵值產生 Discord Webhook 路由：

```text
/api/agents/discord-agent/channels/discord/webhook
```

使用可公開存取的 Mastra 伺服器 URL 作為基礎 URL：

```text
https://your-app.example.com/api/agents/discord-agent/channels/discord/webhook
```

凡 Discord 適配器文件要求填寫互動端點或 Webhook URL，均使用此 URL。處理 Discord 的一般訊息事件時，可能需要在已產生的 Webhook 路由以外另行設定 Gateway。相關設定請參閱 Chat SDK 的適配器文件。
