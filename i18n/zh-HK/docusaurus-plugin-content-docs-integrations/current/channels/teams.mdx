# Microsoft Teams

你可以透過以下兩種方式在 Mastra 中使用 Microsoft Teams：

- **Agent 的 Tool** 讓 Agent 在 Teams 中執行操作，例如讀取和傳送訊息，或管理頻道。
- **Agent 聊天**讓使用者透過 Teams 的提及和對話事件與你的 Agent 交談。

[Mastra Connect](/docs/mastra-platform/connect) 會設定這兩項功能，並代你註冊 Teams 機械人，因此你毋須自行註冊 Azure 應用程式。你也可以自行註冊機械人並管理其憑證。

## Connect {/* #connect */}

開始前，請完成 [Connect 設定](/docs/mastra-platform/connect#get-started)，以安裝 `@mastra/connect` 並設定你的平台項目。

一條 `microsoft-teams` 連線可同時提供 Agent 的 Tool 和 Agent 聊天功能。請使用 Microsoft 公司或學校帳戶登入。部分要求的權限須經管理員同意，因此在租戶內首次建立連線時，需要由 Microsoft Entra 管理員操作。

### Agent 聊天 {/* #agent-chat */}

連接 Agent 時，Mastra 會在 Teams 開發人員入口網站為它註冊機械人，並加密儲存機械人的憑證。設定 `MASTRA_ENCRYPTION_KEY` 即可使用專用金鑰。如果未設定，`channels()` 會從平台存取權杖衍生金鑰，並記錄警告。如果其後輪換平台存取權杖，Mastra 將無法讀取已儲存的機械人憑證。請中斷頻道連線，再重新連接以建立新憑證。

你的伺服器需要一個公開 URL，以接收 Teams webhook 和 OAuth 回調。Mastra 平台會提供此 URL。如果在其他地方託管，請將 `MASTRA_SERVER_URL` 設為伺服器的公開 URL。本機開發時，請使用公開的 HTTPS 通道。

1. 如果尚未加入連線，請執行 `mastra connect add microsoft-teams` 並登入。

1. 將 [`channels()`](/reference/connect/channels) 傳入 `Mastra` 建構函式，以註冊 Teams 頻道的 Provider 及其路由：

   ```typescript title="src/mastra/index.ts"
   import { Mastra } from '@mastra/core'
   import { channels } from '@mastra/connect'
   import { assistant } from './agents/assistant'

   export const mastra = new Mastra({
     agents: { assistant },
     channels: await channels({ providers: ['microsoft-teams'] }),
   })
   ```

   如需同時註冊其他頻道，請將相應的 Provider ID 加入 `providers`。

1. 啟動你的 Mastra 應用程式。

1. 在 Studio 中，將 Teams 頻道連接至 Agent。Mastra 會為該 Agent 建立單一租戶的機械人註冊，並傳回前往 [Teams 開發人員入口網站](https://dev.teams.microsoft.com/bots)的連結。

1. 開啟連結，在開發人員入口網站中將機械人封裝為 Teams 應用程式，然後將應用程式加入 Teams。

中斷 Agent 的連線會刪除機械人註冊及其 Entra 應用程式。

## 自行管理的設定 {/* #self-managed-setup */}

使用 Chat SDK 的 Teams 配接器，配合你自行建立的 Azure 機械人註冊及憑證。

### 安裝配接器 {/* #install-the-adapter */}

從 Chat SDK 安裝 Teams 配接器：

```bash npm2yarn
npm install @chat-adapter/teams
```

### Agent 設定 {/* #agent-configuration */}

將 `createTeamsAdapter()` 加入 Agent 的 `channels.adapters` 物件：

```typescript title="src/mastra/agents/teams-agent.ts"
import { Agent } from '@mastra/core/agent'
import { createTeamsAdapter } from '@chat-adapter/teams'

export const teamsAgent = new Agent({
  id: 'teams-agent',
  name: 'Teams Agent',
  instructions: 'Answer questions and help with tasks in Microsoft Teams.',
  model: '__GATEWAY_OPENAI_MODEL__',
  channels: {
    adapters: {
      teams: createTeamsAdapter({
        appType: 'SingleTenant',
      }),
    },
  },
})
```

在 Mastra 執行個體上註冊 Agent：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { teamsAgent } from './agents/teams-agent'

export const mastra = new Mastra({
  agents: { teamsAgent },
})
```

### 配接器設定 {/* #adapter-setup */}

按照 [Chat SDK Teams 配接器文件](https://chat-sdk.dev/adapters/official/teams)完成 Teams 專用設定，包括 Azure 機械人註冊、Teams CLI 的用法、身分驗證選項及所需權限。

配接器會從環境變數讀取 Teams 憑證，例如：

```bash title=".env"
TEAMS_APP_ID=your-azure-bot-app-id
TEAMS_APP_PASSWORD=your-azure-bot-app-password
TEAMS_APP_TENANT_ID=your-azure-tenant-id
```

### Webhook URL {/* #webhook-url */}

Mastra 根據 Agent ID 和配接器的鍵名產生 Teams webhook 路由：

```text
/api/agents/teams-agent/channels/teams/webhook
```

以 Mastra 伺服器的公開 URL 作為基礎 URL：

```text
https://your-app.example.com/api/agents/teams-agent/channels/teams/webhook
```

凡 Teams 配接器文件要求填寫機械人端點或 webhook URL，均使用此 URL。本機開發時，請透過通道公開 Mastra 開發伺服器，並以通道的 URL 作為基礎 URL。
