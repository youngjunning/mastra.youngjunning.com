# 谷歌雲端儲存

將檔案儲存在 Google Cloud Storage 中。接口詳情請參見[WorkspaceFilesystem Interface](/reference/workspace/filesystem).

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/gcs
```

## 用法 {/* #usage */}

添加一個`GCSFilesystem` to a workspace and assign it to an agent:

```typescript
import { Agent } from '@mastra/core/agent'
import { Workspace } from '@mastra/core/workspace'
import { GCSFilesystem } from '@mastra/gcs'

const workspace = new Workspace({
  filesystem: new GCSFilesystem({
    bucket: 'my-gcs-bucket',
    projectId: 'my-project-id',
    credentials: JSON.parse(process.env.GCS_SERVICE_ACCOUNT_KEY),
  }),
})

const agent = new Agent({
  id: 'file-agent',
  name: 'file-agent',
  model: '__GATEWAY_ANTHROPIC_MODEL_OPUS__',
  workspace,
})
```

### 使用應用程式預設憑證 {/* #using-application-default-credentials */}

如果在 Google Cloud 上運作或使用`gcloud` CLI configured, you can omit credentials:

```typescript
import { GCSFilesystem } from '@mastra/gcs'

const filesystem = new GCSFilesystem({
  bucket: 'my-gcs-bucket',
  // Uses Application Default Credentials automatically
})
```

[應用程式預設憑證 (ADC)](https://cloud.google.com/docs/authentication/application-default-credentials)依下列順序自動發現憑證：

1. `GOOGLE_APPLICATION_CREDENTIALS`環境變數（服務帳戶金鑰檔案的路徑）
2. 在 GCP（Compute Engine、Cloud Run、GKE 等）上執行時的預設服務帳戶
3. 用戶憑證來自`gcloud auth application-default login` (for local development)

### 使用密鑰檔案路徑 {/* #using-a-key-file-path */}

您也可以傳遞服務帳戶金鑰檔案的路徑：

```typescript
import { GCSFilesystem } from '@mastra/gcs'

const filesystem = new GCSFilesystem({
  bucket: 'my-gcs-bucket',
  projectId: 'my-project-id',
  credentials: '/path/to/service-account-key.json',
})
```

## 方法 {/* #methods */}

GCSFilesystem 實作了[WorkspaceFilesystem interface](/reference/workspace/filesystem), providing all standard filesystem methods:

* `readFile(path, options?)`- 讀取文件內容
* `writeFile(path, content, options?)`- 將內容寫入文件
* `appendFile(path, content)`- 將內容附加到文件
* `deleteFile(path, options?)`- 刪除文件
* `copyFile(src, dest, options?)`- 複製文件
* `moveFile(src, dest, options?)`- 移動或重新命名文件
* `mkdir(path, options?)`- 建立目錄
* `rmdir(path, options?)`- 刪除目錄
* `readdir(path, options?)`- 列出目錄內容
* `exists(path)`- 檢查路徑是否存在
* `stat(path)`- 取得檔案或目錄元數據

### `init()` {/* #init */}

初始化檔案系統。驗證儲存桶存取和憑證。

```typescript
await filesystem.init()
```

### `getInfo()` {/* #getinfo */}

傳回有關此檔案系統實例的元資料。

```typescript
const info = filesystem.getInfo()
// { id: '...', name: 'GCSFilesystem', provider: 'gcs', status: 'ready' }
```

### `getMountConfig()` {/* #getmountconfig */}

傳回支援掛載此檔案系統類型的沙箱的掛載配置。

```typescript
const config = filesystem.getMountConfig()
// { type: 'gcs', bucket: 'my-bucket', ... }
```

## 安裝在 E2B 沙箱中 {/* #mounting-in-e2b-sandboxes */}

GCSFilesystem 可以掛載到 E2B 沙箱中，使儲存桶可作為本機目錄存取：

```typescript
import { Workspace } from '@mastra/core/workspace'
import { GCSFilesystem } from '@mastra/gcs'
import { E2BSandbox } from '@mastra/e2b'

const workspace = new Workspace({
  mounts: {
    '/data': new GCSFilesystem({
      bucket: 'my-gcs-bucket',
      projectId: 'my-project-id',
      credentials: JSON.parse(process.env.GCS_SERVICE_ACCOUNT_KEY),
    }),
  },
  sandbox: new E2BSandbox({ id: 'dev-sandbox' }),
})
```

看[E2BSandbox reference](/integrations/sandboxes/e2b) for more details on mounting.
