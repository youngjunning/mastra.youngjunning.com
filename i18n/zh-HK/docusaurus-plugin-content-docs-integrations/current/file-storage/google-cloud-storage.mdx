# Google Cloud Storage

此整合可將檔案儲存在 Google Cloud Storage。介面詳情見 [WorkspaceFilesystem 介面](/reference/workspace/filesystem)。

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/gcs
```

## 使用方法 {/* #usage */}

在 Workspace 加入 `GCSFilesystem`，然後將這個 Workspace 指派給 Agent。

```typescript
import { Agent } from '@mastra/core/agent'
import { Workspace } from '@mastra/core/workspace'
import { GCSFilesystem } from '@mastra/gcs'

const workspace = new Workspace({
  filesystem: new GCSFilesystem({
    bucket: 'my-gcs-bucket',
    projectId: 'my-project-id',
    credentials: JSON.parse(process.env.GCS_SERVICE_ACCOUNT_KEY),
  }),
})

const agent = new Agent({
  id: 'file-agent',
  name: 'file-agent',
  model: '__GATEWAY_ANTHROPIC_MODEL_OPUS__',
  workspace,
})
```

### 使用應用程式預設憑證 {/* #using-application-default-credentials */}

如應用程式在 Google Cloud 上運行，或已設定 `gcloud` CLI，便可省略憑證。

```typescript
import { GCSFilesystem } from '@mastra/gcs'

const filesystem = new GCSFilesystem({
  bucket: 'my-gcs-bucket',
  // Uses Application Default Credentials automatically
})
```

[應用程式預設憑證（ADC）](https://cloud.google.com/docs/authentication/application-default-credentials)會按以下次序自動尋找憑證。

1. `GOOGLE_APPLICATION_CREDENTIALS` 環境變數所指定的服務帳戶密鑰檔案
2. 在 GCP（Compute Engine、Cloud Run、GKE 等）上運行時的預設服務帳戶憑證
3. 以 `gcloud auth application-default login` 取得的用戶憑證（用於本機開發）

### 使用密鑰檔案路徑 {/* #using-a-key-file-path */}

亦可傳入服務帳戶密鑰檔案的路徑。

```typescript
import { GCSFilesystem } from '@mastra/gcs'

const filesystem = new GCSFilesystem({
  bucket: 'my-gcs-bucket',
  projectId: 'my-project-id',
  credentials: '/path/to/service-account-key.json',
})
```

## 方法 {/* #methods */}

GCSFilesystem 實作 [WorkspaceFilesystem 介面](/reference/workspace/filesystem)，並提供所有標準檔案系統方法。

* `readFile(path, options?)` - 讀取檔案內容
* `writeFile(path, content, options?)` - 將內容寫入檔案
* `appendFile(path, content)` - 將內容加到檔案末尾
* `deleteFile(path, options?)` - 刪除檔案
* `copyFile(src, dest, options?)` - 複製檔案
* `moveFile(src, dest, options?)` - 移動或重新命名檔案
* `mkdir(path, options?)` - 建立目錄
* `rmdir(path, options?)` - 刪除目錄
* `readdir(path, options?)` - 列出目錄內容
* `exists(path)` - 檢查路徑是否存在
* `stat(path)` - 取得檔案或目錄的元數據

### `init()` {/* #init */}

初始化檔案系統，並驗證憑證及檢查能否存取儲存桶。

```typescript
await filesystem.init()
```

### `getInfo()` {/* #getinfo */}

傳回此檔案系統實例的元數據。

```typescript
const info = filesystem.getInfo()
// { id: '...', name: 'GCSFilesystem', provider: 'gcs', status: 'ready' }
```

### `getMountConfig()` {/* #getmountconfig */}

傳回掛載設定，供可掛載此類檔案系統的 Sandbox 使用。

```typescript
const config = filesystem.getMountConfig()
// { type: 'gcs', bucket: 'my-bucket', ... }
```

## 在 E2B Sandbox 內掛載 {/* #mounting-in-e2b-sandboxes */}

可將 GCSFilesystem 掛載至 E2B Sandbox，讓 Sandbox 以本機目錄的方式存取儲存桶。

```typescript
import { Workspace } from '@mastra/core/workspace'
import { GCSFilesystem } from '@mastra/gcs'
import { E2BSandbox } from '@mastra/e2b'

const workspace = new Workspace({
  mounts: {
    '/data': new GCSFilesystem({
      bucket: 'my-gcs-bucket',
      projectId: 'my-project-id',
      credentials: JSON.parse(process.env.GCS_SERVICE_ACCOUNT_KEY),
    }),
  },
  sandbox: new E2BSandbox({ id: 'dev-sandbox' }),
})
```

掛載詳情見 [E2BSandbox 參考文件](/integrations/sandboxes/e2b)。
