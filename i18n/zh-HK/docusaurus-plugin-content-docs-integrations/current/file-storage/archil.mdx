# Archil

這項整合把檔案儲存到 [Archil](https://docs.archil.com) 的彈性無伺服器磁碟。兼容 S3 的物件 API 可快速讀寫檔案，`exec()` 可執行 POSIX shell 操作，`diskGrep()` 則可在伺服器端並行搜尋。介面詳情請參閱 [WorkspaceFilesystem 介面](/reference/workspace/filesystem)。

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/archil
```

## 使用方法 {/* #usage */}

為 Workspace 加入 `ArchilFilesystem`，再將該 Workspace 指派給 Agent。

```typescript
import { Agent } from '@mastra/core/agent'
import { Workspace } from '@mastra/core/workspace'
import { ArchilFilesystem } from '@mastra/archil'

const workspace = new Workspace({
  filesystem: new ArchilFilesystem({
    diskId: 'dsk-0123456789abcdef',
    apiKey: process.env.ARCHIL_API_KEY,
    region: 'aws-us-east-1',
  }),
})

const agent = new Agent({
  id: 'file-agent',
  name: 'file-agent',
  model: '__GATEWAY_ANTHROPIC_MODEL_OPUS__',
  workspace,
})
```

### 在初始化時建立新磁碟 {/* #creating-a-new-disk-on-init */}

如未有現成的磁碟，可提供 `createDiskOptions`，在初始化時自動建立磁碟。

```typescript
import { ArchilFilesystem } from '@mastra/archil'

const filesystem = new ArchilFilesystem({
  apiKey: process.env.ARCHIL_API_KEY,
  region: 'aws-us-east-1',
  createDiskOptions: {
    name: 'my-agent-workspace',
  },
})

await filesystem.init()
// filesystem.diskId now contains the newly created disk ID
```

### 從環境變數讀取設定 {/* #environment-variable-fallbacks */}

如省略 `apiKey` 和 `region`，Provider 會從環境變數讀取相應的值。自訂 S3 端點也可透過環境變數設定。

* `ARCHIL_API_KEY` — API 密鑰
* `ARCHIL_REGION` — 區域，例如 `aws-us-east-1`
* `ARCHIL_S3_BASE_URL` — 自訂 S3 端點（可選）

```typescript
import { ArchilFilesystem } from '@mastra/archil'

// Uses ARCHIL_API_KEY and ARCHIL_REGION from environment
const filesystem = new ArchilFilesystem({
  diskId: 'dsk-0123456789abcdef',
})
```

## 方法 {/* #methods */}

ArchilFilesystem 實作 [WorkspaceFilesystem 介面](/reference/workspace/filesystem)，提供以下所有標準檔案系統方法。

* `readFile(path, options?)` — 讀取檔案內容
* `writeFile(path, content, options?)` — 把內容寫入檔案
* `appendFile(path, content)` — 在檔案末端加入內容
* `deleteFile(path, options?)` — 刪除檔案
* `copyFile(src, dest, options?)` — 複製檔案
* `moveFile(src, dest, options?)` — 移動或重新命名檔案
* `mkdir(path, options?)` — 建立目錄
* `rmdir(path, options?)` — 移除目錄
* `readdir(path, options?)` — 列出目錄內容
* `exists(path)` — 檢查路徑是否存在
* `stat(path)` — 取得檔案或目錄的元數據

### `init()` {/* #init */}

初始化檔案系統，並連接現有磁碟或建立新磁碟。

```typescript
await filesystem.init()
```

### `getInfo()` {/* #getinfo */}

回傳這個檔案系統實例的元數據。

```typescript
const info = filesystem.getInfo()
// { id: '...', name: 'ArchilFilesystem', provider: 'archil', status: 'ready' }
```

### Archil 專用方法 {/* #archil-specific-methods */}

#### `exec(command)` {/* #execcommand */}

在磁碟上執行 shell 指令，並回傳退出代碼、標準輸出（stdout）及標準錯誤輸出（stderr）。

```typescript
const result = await filesystem.exec('ls -la /data')
// { exitCode: 0, stdout: '...', stderr: '' }
```

#### `diskGrep(options)` {/* #diskgrepoptions */}

在伺服器端對磁碟上的檔案進行並行搜尋。

```typescript
const results = await filesystem.diskGrep({
  directory: '/logs',
  pattern: 'ERROR',
  recursive: true,
  glob: '*.log',
})
// { matches: [...], stoppedReason: null }
```

#### `share(path, options?)` {/* #sharepath-options */}

產生可供分享檔案的已簽署 URL。

```typescript
const { url } = await filesystem.share('/reports/output.pdf', {
  expiresIn: 3600,
})
```
