# AgentFS

使用 [AgentFS](https://github.com/nichochar/agentfs) SDK 將檔案儲存至 Turso/SQLite 資料庫。工作階段結束後，檔案仍會保留在本機 SQLite 資料庫，讓 Agent 日後存取，毋須依賴外部雲端服務。接口詳情請參閱 [WorkspaceFilesystem 接口](/reference/workspace/filesystem)。

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/agentfs
```

## 用法 {/* #usage */}

將 `AgentFSFilesystem` 加入 Workspace，再將該 Workspace 分配給 Agent。建立實例時，必須提供 `agentId`、`path` 或 `agent` 中的至少一項，供 `AgentFSFilesystem` 初始化。

```typescript
import { Agent } from '@mastra/core/agent'
import { Workspace } from '@mastra/core/workspace'
import { AgentFSFilesystem } from '@mastra/agentfs'

const workspace = new Workspace({
  filesystem: new AgentFSFilesystem({
    agentId: 'my-agent',
  }),
})

const agent = new Agent({
  id: 'file-agent',
  name: 'file-agent',
  model: '__GATEWAY_OPENAI_MODEL__',
  workspace,
})
```

### 自訂資料庫路徑 {/* #using-an-explicit-database-path */}

資料庫預設存放於 `.agentfs` 目錄，並按 `agentId` 命名檔案。你亦可按以下範例指定所需的資料庫路徑。

```typescript
import { AgentFSFilesystem } from '@mastra/agentfs'

const filesystem = new AgentFSFilesystem({
  path: '/data/my-agent.db',
})
```

### 傳入已開啟的 AgentFS 實例 {/* #using-a-pre-opened-agentfs-instance */}

如需自行管理 AgentFS 的生命週期，可傳入已開啟的實例。

```typescript
import { AgentFS } from 'agentfs-sdk'
import { AgentFSFilesystem } from '@mastra/agentfs'

const agent = await AgentFS.open({ id: 'my-agent' })

const filesystem = new AgentFSFilesystem({
  agent, // caller manages open/close
})
```
