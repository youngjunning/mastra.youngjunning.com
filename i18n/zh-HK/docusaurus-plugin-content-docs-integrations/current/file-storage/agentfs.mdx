# AgentFS

透過以下方式將檔案儲存在 Turso/SQLite 資料庫中[AgentFS](https://github.com/nichochar/agentfs)SDK。檔案跨會話保存在本機 SQLite 資料庫中，為Agent提供持久存儲，無需外部雲端服務。接口詳情請參見[工作空間檔案系統接口](/reference/workspace/filesystem).

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/agentfs
```

## 用法 {/* #usage */}

添加一個`AgentFSFilesystem` to a workspace and assign it to an agent. You must provide at least one of `agentId`, `path`, or `agent`當實例化時`AgentFSFilesystem`班級。

```typescript
import { Agent } from '@mastra/core/agent'
import { Workspace } from '@mastra/core/workspace'
import { AgentFSFilesystem } from '@mastra/agentfs'

const workspace = new Workspace({
  filesystem: new AgentFSFilesystem({
    agentId: 'my-agent',
  }),
})

const agent = new Agent({
  id: 'file-agent',
  name: 'file-agent',
  model: '__GATEWAY_OPENAI_MODEL__',
  workspace,
})
```

### 使用顯式資料庫路徑 {/* #using-an-explicit-database-path */}

預設情況下，資料庫儲存在`.agentfs` directory with the `agentId` as filename. You can specify a custom database path:

```typescript
import { AgentFSFilesystem } from '@mastra/agentfs'

const filesystem = new AgentFSFilesystem({
  path: '/data/my-agent.db',
})
```

### 使用預先開啟的 AgentFS 實例 {/* #using-a-pre-opened-agentfs-instance */}

如果您需要自行管理 AgentFS 生命週期：

```typescript
import { AgentFS } from 'agentfs-sdk'
import { AgentFSFilesystem } from '@mastra/agentfs'

const agent = await AgentFS.open({ id: 'my-agent' })

const filesystem = new AgentFSFilesystem({
  agent, // caller manages open/close
})
```
