# 亞馬遜S3

將檔案儲存在 Amazon S3 或 S3 相容的儲存服務中，例如 Cloudflare R2、Neon Object Storage、MinIO、DigitalOcean Spaces 和 Tigris。接口詳情請參見[WorkspaceFilesystem Interface](/reference/workspace/filesystem).

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/s3
```

## 用法 {/* #usage */}

添加一個`S3Filesystem` to a workspace and assign it to an agent:

```typescript
import { Agent } from '@mastra/core/agent'
import { Workspace } from '@mastra/core/workspace'
import { S3Filesystem } from '@mastra/s3'

const workspace = new Workspace({
  filesystem: new S3Filesystem({
    bucket: 'my-bucket',
    region: 'us-east-1',
    accessKeyId: process.env.AWS_ACCESS_KEY_ID,
    secretAccessKey: process.env.AWS_SECRET_ACCESS_KEY,
  }),
})

const agent = new Agent({
  id: 'file-agent',
  name: 'file-agent',
  model: '__GATEWAY_ANTHROPIC_MODEL_OPUS__',
  workspace,
})
```

### AWS憑證提供者鏈 {/* #aws-credential-provider-chain */}

當沒有提供憑證時，`S3Filesystem` uses the AWS SDK default credential provider chain. This discovers credentials automatically from environment variables, `~/.aws` config files, ECS container credentials, EC2 instance profiles, and other standard sources.

```typescript
import { S3Filesystem } from '@mastra/s3'

// SDK discovers credentials from the environment automatically
const filesystem = new S3Filesystem({
  bucket: 'my-bucket',
  region: 'us-east-1',
})
```

傳遞憑證提供者函數以自動刷新憑證。這對於 ECS、Lambda 上的部署或使用臨時憑證過期且需要刷新的 SSO/AssumeRole 時非常有用。

呼叫時安裝 AWS SDK 憑證提供者包`fromNodeProviderChain()` directly:

```bash npm2yarn
npm install @aws-sdk/credential-providers
```

```typescript
import { S3Filesystem } from '@mastra/s3'
import { fromNodeProviderChain } from '@aws-sdk/credential-providers'

const filesystem = new S3Filesystem({
  bucket: 'my-bucket',
  region: 'us-east-1',
  credentials: fromNodeProviderChain(),
})
```

提供者功能僅適用於`S3Filesystem` API calls. When mounting the filesystem into an E2B or Daytona sandbox, mount configuration only supports static `accessKeyId`, `secretAccessKey`, and `sessionToken` values, so credential refresh must be handled outside the mount. See [temporary credentials in Daytona](/integrations/sandboxes/daytona#temporary-s3-credentials) for mount lifetime and isolation requirements.

### 前綴範圍的權限 {/* #prefix-scoped-permissions */}

什麼時候`prefix` is set, initialization calls `ListObjectsV2` with the normalized prefix, including its trailing `/`, and `MaxKeys: 1`. Credentials must permit listing that prefix. Without a prefix, initialization uses `HeadBucket`. These checks verify access, not whether a directory exists.

前綴限制了檔案系統位址的鍵。它不是授權邊界。為了進行隔離，請使用其儲存提供者政策限制對該前綴的存取的憑證。將家長憑證保存在您的後端。僅讀取和寫入權限不足以進行前綴檔案系統初始化。

### Cloudflare R2 {/* #cloudflare-r2 */}

```typescript
import { S3Filesystem } from '@mastra/s3'

const filesystem = new S3Filesystem({
  bucket: 'my-r2-bucket',
  region: 'auto',
  endpoint: `https://${process.env.R2_ACCOUNT_ID}.r2.cloudflarestorage.com`,
  accessKeyId: process.env.R2_ACCESS_KEY_ID,
  secretAccessKey: process.env.R2_SECRET_ACCESS_KEY,
})
```

### Neon 物件存儲 {/* #neon-object-storage */}

```typescript
import { S3Filesystem } from '@mastra/s3'

const filesystem = new S3Filesystem({
  bucket: 'agent-files',
  region: process.env.AWS_REGION!,
  endpoint: process.env.AWS_ENDPOINT_URL_S3,
  accessKeyId: process.env.AWS_ACCESS_KEY_ID,
  secretAccessKey: process.env.AWS_SECRET_ACCESS_KEY,
})
```

`neon deploy`和`neon env pull` write these variables for the current Neon branch. Keep the default path-style addressing. Each branch has its own endpoint and its own copy of the files. See [Neon Object Storage](/integrations/file-storage/neon) for bucket setup and branching.

### 最小IO {/* #minio */}

```typescript
import { S3Filesystem } from '@mastra/s3'

const filesystem = new S3Filesystem({
  bucket: 'my-bucket',
  region: 'us-east-1',
  endpoint: 'http://localhost:9000',
  accessKeyId: 'minioadmin',
  secretAccessKey: 'minioadmin',
})
```

### 底格里斯河 {/* #tigris */}

```typescript
import { S3Filesystem } from '@mastra/s3'

const filesystem = new S3Filesystem({
  bucket: 'my-bucket',
  region: 'auto',
  endpoint: 'https://t3.storage.dev',
  accessKeyId: process.env.TIGRIS_ACCESS_KEY_ID,
  secretAccessKey: process.env.TIGRIS_SECRET_ACCESS_KEY,
  forcePathStyle: false,
})
```

Tigris 使用虛擬託管式定址，因此`forcePathStyle` must be set to `false` (the default is `true` when a custom endpoint is provided). Create credentials from the [Tigris Dashboard](https://console.tigris.dev/). Access keys are prefixed `tid_` and secrets `tsec_`.

## 方法 {/* #methods */}

S3檔案系統實作了[WorkspaceFilesystem interface](/reference/workspace/filesystem), providing all standard filesystem methods:

* `readFile(path, options?)`- 讀取文件內容
* `writeFile(path, content, options?)`- 將內容寫入文件
* `appendFile(path, content)`- 將內容附加到文件
* `deleteFile(path, options?)`- 刪除文件
* `copyFile(src, dest, options?)`- 複製文件
* `moveFile(src, dest, options?)`- 移動或重新命名文件
* `mkdir(path, options?)`- 建立目錄
* `rmdir(path, options?)`- 刪除目錄
* `readdir(path, options?)`- 列出目錄內容
* `exists(path)`- 檢查路徑是否存在
* `stat(path)`- 取得檔案或目錄元數據

### `init()` {/* #init */}

初始化檔案系統。驗證儲存桶存取和憑證。

```typescript
await filesystem.init()
```

### `getInfo()` {/* #getinfo */}

傳回有關此檔案系統實例的元資料。

```typescript
const info = filesystem.getInfo()
// { id: '...', name: 'S3Filesystem', provider: 's3', status: 'ready' }
```

### `getMountConfig()` {/* #getmountconfig */}

傳回支援掛載此檔案系統類型的沙箱的掛載配置。

```typescript
const config = filesystem.getMountConfig()
// { type: 's3', bucket: 'my-bucket', region: 'us-east-1', ... }
```

## 安裝在 E2B 沙箱中 {/* #mounting-in-e2b-sandboxes */}

S3Filesystem 可以掛載到 E2B 沙箱中，使儲存桶可作為本機目錄存取：

```typescript
import { Workspace } from '@mastra/core/workspace'
import { S3Filesystem } from '@mastra/s3'
import { E2BSandbox } from '@mastra/e2b'

const workspace = new Workspace({
  mounts: {
    '/data': new S3Filesystem({
      bucket: 'my-bucket',
      region: 'us-east-1',
      accessKeyId: process.env.AWS_ACCESS_KEY_ID,
      secretAccessKey: process.env.AWS_SECRET_ACCESS_KEY,
    }),
  },
  sandbox: new E2BSandbox({ id: 'dev-sandbox' }),
})
```

看[E2BSandbox reference](/integrations/sandboxes/e2b) for more details on mounting.
