# Azure Blob

將檔案儲存到 Azure Blob Storage 容器。介面詳情請參閱 [WorkspaceFilesystem 介面](/reference/workspace/filesystem)。

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/azure
```

## 使用方法 {/* #usage */}

將 `AzureBlobFilesystem` 加入 Workspace，然後把該 Workspace 指派給 Agent：

```typescript
import { Agent } from '@mastra/core/agent'
import { Workspace } from '@mastra/core/workspace'
import { AzureBlobFilesystem } from '@mastra/azure/blob'

const workspace = new Workspace({
  filesystem: new AzureBlobFilesystem({
    container: 'my-container',
    connectionString: process.env.AZURE_STORAGE_CONNECTION_STRING,
  }),
})

const agent = new Agent({
  id: 'file-agent',
  name: 'file-agent',
  model: '__GATEWAY_ANTHROPIC_MODEL_OPUS__',
  workspace,
})
```

### 帳戶金鑰 {/* #account-key */}

如不想傳入完整的連線字串，可改用帳戶名稱及帳戶金鑰：

```typescript
import { AzureBlobFilesystem } from '@mastra/azure/blob'

const filesystem = new AzureBlobFilesystem({
  container: 'my-container',
  accountName: process.env.AZURE_STORAGE_ACCOUNT_NAME,
  accountKey: process.env.AZURE_STORAGE_ACCOUNT_KEY,
})
```

### 共用存取簽章權杖 {/* #shared-access-signature-token */}

使用共用存取簽章（SAS）權杖時，須同時指定 `accountName` 或 `endpoint`：

```typescript
import { AzureBlobFilesystem } from '@mastra/azure/blob'

const filesystem = new AzureBlobFilesystem({
  container: 'my-container',
  accountName: process.env.AZURE_STORAGE_ACCOUNT_NAME,
  sasToken: process.env.AZURE_STORAGE_SAS_TOKEN,
})
```

### DefaultAzureCredential {/* #defaultazurecredential */}

如執行環境已提供 Azure 身分驗證憑證，請使用 `DefaultAzureCredential`：

```typescript
import { AzureBlobFilesystem } from '@mastra/azure/blob'

const filesystem = new AzureBlobFilesystem({
  container: 'my-container',
  accountName: process.env.AZURE_STORAGE_ACCOUNT_NAME,
  useDefaultCredential: true,
})
```

使用 `DefaultAzureCredential` 須安裝 `@azure/identity`：

```bash npm2yarn
npm install @azure/identity
```

## 方法 {/* #methods */}

AzureBlobFilesystem 實作 [WorkspaceFilesystem 介面](/reference/workspace/filesystem)，提供以下標準檔案系統方法：

* `readFile(path, options?)`：讀取檔案內容
* `writeFile(path, content, options?)`：把內容寫入檔案
* `appendFile(path, content)`：在檔案末尾加上內容
* `deleteFile(path, options?)`：刪除檔案
* `copyFile(src, dest, options?)`：複製檔案
* `moveFile(src, dest, options?)`：移動檔案或更改檔名
* `mkdir(path, options?)`：建立目錄
* `rmdir(path, options?)`：移除目錄
* `readdir(path, options?)`：列出目錄內容
* `exists(path)`：檢查路徑是否存在
* `stat(path)`：取得檔案或目錄的元數據

### `init()` {/* #init */}

初始化檔案系統，檢查能否存取容器，並驗證憑證。

```typescript
await filesystem.init()
```

### `getInfo()` {/* #getinfo */}

傳回此檔案系統實例的元數據。

```typescript
const info = filesystem.getInfo()
// { id: '...', name: 'AzureBlobFilesystem', provider: 'azure-blob', status: 'ready' }
```

### `getContainer()` {/* #getcontainer */}

傳回底層的 Azure Blob Storage `ContainerClient`。

```typescript
const container = await filesystem.getContainer()
```

### `getMountConfig()` {/* #getmountconfig */}

傳回掛載配置，供支援掛載 Azure Blob 檔案系統的 Sandbox Provider 使用。

```typescript
const config = filesystem.getMountConfig()
// { type: 'azure-blob', container: 'my-container', ... }
```

:::note

Sandbox 須支援 `azure-blob` 掛載配置，才能掛載 Azure Blob。如你的 Sandbox Provider 不支援掛載 Azure Blob，請透過 `filesystem` 直接操作 Workspace 內的檔案。

:::
