# Fireflies.ai

透過 Mastra Connect，為 Agent 提供可在 Fireflies.ai 中讀取會議逐字稿與分析資料、就會議內容提問、建立精彩片段，以及管理會議分享與私隱設定的 Tool。每次 Tool 呼叫都會經過 Mastra 平台，由平台加入該連接的憑證；你的應用程式不會儲存 Fireflies.ai 憑證。

## 連接 {/* #connect */}

開始前，請先完成 [Connect 設定](/docs/mastra-platform/connect#get-started)，安裝 `@mastra/connect` 並設定 Mastra 平台項目。

### 連接帳戶 {/* #connect-an-account */}

請在包含 `.env` 檔案的目錄中執行以下指令：

```bash
mastra connect add fireflies
```

CLI 會引導你完成 Fireflies.ai 授權，並等待連接啟用。

### 將 Tool 加入 Agent {/* #add-tools-to-an-agent */}

將 [`tools()`](/reference/connect/tools) 傳給 Agent，並選擇 `fireflies` Provider：

```typescript title="src/mastra/agents/fireflies-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const firefliesAgent = new Agent({
  id: 'fireflies-agent',
  name: 'Fireflies.ai agent',
  instructions:
    'You help people read meeting transcripts and analytics, ask questions about meetings, create soundbites, and manage meeting sharing and privacy in Fireflies.ai.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['fireflies'] }),
})
```

Agent 可使用 27 個 Fireflies.ai Tool，Tool key 包括 `fireflies_add_to_live`。完整清單請參閱 [Fireflies.ai Tool](/reference/connect/providers#firefliesai)；如需限制可用 Tool，或要求每次呼叫在執行前取得批准，請參閱 [`tools()` 參數](/reference/connect/tools#parameters)。
