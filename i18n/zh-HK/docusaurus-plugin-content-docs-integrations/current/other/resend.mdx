# Resend

透過 Mastra Connect，為 Agent 提供可在 Resend 中傳送電郵和廣播，並管理聯絡人、細分、網域、範本與 webhook 的 Tool。每次 Tool 呼叫都會經過 Mastra 平台，由平台加入該連接的憑證；你的應用程式不會儲存 Resend 憑證。

## 連接 {/* #connect */}

開始前，請先完成 [Connect 設定](/docs/mastra-platform/connect#get-started)，安裝 `@mastra/connect` 並設定 Mastra 平台項目。

:::note

請使用具有 **Full access** 權限的 API 金鑰連接 Resend。只有 **Sending access** 權限的金鑰無法完成連接，因為 Mastra 會透過列出網域來檢查新金鑰，而此類金鑰沒有該權限。

:::

### 連接帳戶 {/* #connect-an-account */}

請在包含 `.env` 檔案的目錄中執行以下指令：

```bash
mastra connect add resend
```

CLI 會引導你完成 Resend 授權，並等待連接啟用。

### 將 Tool 加入 Agent {/* #add-tools-to-an-agent */}

將 [`tools()`](/reference/connect/tools) 傳給 Agent，並選擇 `resend` Provider：

```typescript title="src/mastra/agents/resend-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const resendAgent = new Agent({
  id: 'resend-agent',
  name: 'Resend agent',
  instructions:
    'You help people send email and broadcasts, and manage contacts, segments, domains, templates, and webhooks in Resend.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['resend'] }),
})
```

Agent 可使用 80 個 Resend Tool，Tool key 包括 `resend_add_contact_to_segment`。完整清單請參閱 [Resend Tool](/reference/connect/providers#resend)；如需限制可用 Tool，或要求每次呼叫在執行前取得批准，請參閱 [`tools()` 參數](/reference/connect/tools#parameters)。
