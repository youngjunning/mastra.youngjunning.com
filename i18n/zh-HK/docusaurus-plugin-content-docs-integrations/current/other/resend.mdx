# 重新發送

為Agent商提供Tool來發送電子郵件和廣播，並透過 Mastra Connect 管理 Resend 中的聯絡人、細分、網域、範本和 Webhooks。每個Tool呼叫都會透過 Mastra 平台，該平台會新增連接的憑證。您的應用程式從不儲存重新傳送憑證。

## 連接 {/* #connect */}

在開始之前，請完成[Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect`並配置您的平台項目。

：：：筆記

使用具有以下功能的 API 金鑰連線重新傳送**Full access** permission. A **Sending access** key fails to connect because Mastra checks a new key by listing your domains, which sending access keys can't do.

:::

### 連接帳戶 {/* #connect-an-account */}

從包含您的目錄的目錄執行此命令`.env` file:

```bash
mastra connect add resend
```

CLI 將引導您完成重新發送的授權並等待連線啟動。

### 向Agent添加Tool {/* #add-tools-to-an-agent */}

經過[`tools()`](/reference/connect/tools) to the agent and select the `resend` provider:

```typescript title="src/mastra/agents/resend-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const resendAgent = new Agent({
  id: 'resend-agent',
  name: 'Resend agent',
  instructions:
    'You help people send email and broadcasts, and manage contacts, segments, domains, templates, and webhooks in Resend.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['resend'] }),
})
```

Agent程式獲得 80 個重新發送Tool，其中包含以下密鑰`resend_add_contact_to_segment`. See [Resend tools](/reference/connect/providers#resend) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
