# 羅賓漢

為Agent商提供Tool來讀取帳戶和市場數據，並透過 Mastra Connect 在 Robinhood 中進行交易。 Robinhood 透過託管模型上下文協定 (MCP) 伺服器提供這些Tool。您的應用程式從不儲存 Robinhood 憑證。

## 連接 {/* #connect */}

在開始之前，請完成[Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect`並配置您的平台項目。

：：：警告

這些Tool可以用真實的資金進行真實的交易。需要核准交易Tool`requireApproval` so a person confirms each order before it runs. See [MCP providers](/reference/connect/tools#mcp-providers).

:::

### 連接帳戶 {/* #connect-an-account */}

從包含您的目錄的目錄執行此命令`.env` file:

```bash
mastra connect add robinhood-mcp
```

CLI 將引導您完成 Robinhood 的授權並等待連線啟動。

### 向Agent添加Tool {/* #add-tools-to-an-agent */}

經過[`tools()`](/reference/connect/tools) to the agent and select the `robinhood-mcp` provider:

```typescript title="src/mastra/agents/robinhood-mcp-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const robinhoodMcpAgent = new Agent({
  id: 'robinhood-mcp-agent',
  name: 'Robinhood agent',
  instructions: 'You help people read account and market data and place trades in Robinhood.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['robinhood-mcp'] }),
})
```

當Agent程式運行時，Mastra 從其 MCP 伺服器發現 Robinhood 的Tool。可用的Tool取決於伺服器和連接的帳戶，而不取決於您的`@mastra/connect` version. Tool keys start with `robinhood-mcp_`.

要查看 Robinhood 提供了哪些Tool，請閱讀[Agentic Trading](https://robinhood.com/us/en/support/agentic-trading) documentation. To require approval before a call runs, see [MCP providers](/reference/connect/tools#mcp-providers) in the `tools()` reference.
