# Robinhood

透過 Mastra Connect，為 Agent 提供可在 Robinhood 中讀取帳戶和市場數據，以及執行交易的 Tool。Robinhood 透過託管的 Model Context Protocol (MCP) 伺服器提供這些 Tool；你的應用程式不會儲存 Robinhood 憑證。

## 連接 {/* #connect */}

開始前，請先完成 [Connect 設定](/docs/mastra-platform/connect#get-started)，安裝 `@mastra/connect` 並設定 Mastra 平台項目。

:::warning

這些 Tool 可以使用真實資金執行真實交易。請透過 `requireApproval` 要求交易 Tool 在執行前取得批准，確保每張訂單都由用戶確認。詳情請參閱 [MCP Provider](/reference/connect/tools#mcp-providers)。

:::

### 連接帳戶 {/* #connect-an-account */}

請在包含 `.env` 檔案的目錄中執行以下指令：

```bash
mastra connect add robinhood-mcp
```

CLI 會引導你完成 Robinhood 授權，並等待連接啟用。

### 將 Tool 加入 Agent {/* #add-tools-to-an-agent */}

將 [`tools()`](/reference/connect/tools) 傳給 Agent，並選擇 `robinhood-mcp` Provider：

```typescript title="src/mastra/agents/robinhood-mcp-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const robinhoodMcpAgent = new Agent({
  id: 'robinhood-mcp-agent',
  name: 'Robinhood agent',
  instructions: 'You help people read account and market data and place trades in Robinhood.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['robinhood-mcp'] }),
})
```

Agent 執行時，Mastra 會從 Robinhood 的 MCP 伺服器探索可用 Tool。這些 Tool 取決於伺服器和已連接的帳戶，而不是你的 `@mastra/connect` 版本。Tool key 以 `robinhood-mcp_` 開頭。

如需查看 Robinhood 提供的 Tool，請參閱 [Agentic Trading](https://robinhood.com/us/en/support/agentic-trading) 文件。如需要求每次呼叫在執行前取得批准，請參閱 `tools()` 參考中的 [MCP Provider](/reference/connect/tools#mcp-providers)。
