# 帆布

透過 Mastra Connect 為Agent商提供在 Canva 中建立、編輯、搜尋和匯出設計的Tool。 Canva 從託管的模型上下文協定 (MCP) 伺服器提供這些Tool。您的應用程式從不儲存 Canva 憑證。

## 連接 {/* #connect */}

在開始之前，請完成[Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect`並配置您的平台項目。

### 連接帳戶 {/* #connect-an-account */}

從包含您的目錄的目錄執行此命令`.env` file:

```bash
mastra connect add canva-mcp
```

CLI 將引導您完成 Canva 的授權並等待連線啟動。

### 向Agent添加Tool {/* #add-tools-to-an-agent */}

經過[`tools()`](/reference/connect/tools) to the agent and select the `canva-mcp` provider:

```typescript title="src/mastra/agents/canva-mcp-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const canvaMcpAgent = new Agent({
  id: 'canva-mcp-agent',
  name: 'Canva agent',
  instructions: 'You help people create, edit, search, and export designs in Canva.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['canva-mcp'] }),
})
```

當Agent程式運行時，Mastra 從其 MCP 伺服器發現 Canva 的Tool。可用的Tool取決於伺服器和連接的帳戶，而不取決於您的`@mastra/connect` version. Tool keys start with `canva-mcp_`.

要查看 Canva 提供的Tool，請閱讀[Canva MCP](https://www.canva.dev/docs/apps/mcp/) documentation. To require approval before a call runs, see [MCP providers](/reference/connect/tools#mcp-providers) in the `tools()` reference.
