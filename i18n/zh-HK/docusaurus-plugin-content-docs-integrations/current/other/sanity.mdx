# 理智

為Agent提供Tool來透過 Mastra Connect 查詢、建立和更新 Sanity 中的內容文件。 Sanity 從託管的模型上下文協定 (MCP) 伺服器提供這些Tool。您的應用程式從不儲存 Sanity 憑證。

## 連接 {/* #connect */}

在開始之前，請完成[Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect`並配置您的平台項目。

### 連接帳戶 {/* #connect-an-account */}

從包含您的目錄的目錄執行此命令`.env` file:

```bash
mastra connect add sanity-mcp
```

CLI 將引導您完成 Sanity 的授權並等待連線啟動。

### 向Agent添加Tool {/* #add-tools-to-an-agent */}

經過[`tools()`](/reference/connect/tools) to the agent and select the `sanity-mcp` provider:

```typescript title="src/mastra/agents/sanity-mcp-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const sanityMcpAgent = new Agent({
  id: 'sanity-mcp-agent',
  name: 'Sanity agent',
  instructions: 'You help people query, create, and update content documents in Sanity.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['sanity-mcp'] }),
})
```

當Agent程式運行時，Mastra 從其 MCP 伺服器發現 Sanity 的Tool。可用的Tool取決於伺服器和連接的帳戶，而不取決於您的`@mastra/connect` version. Tool keys start with `sanity-mcp_`.

要查看 Sanity 提供了哪些Tool，請閱讀[Sanity MCP server](https://www.sanity.io/docs/ai/mcp-server) documentation. To require approval before a call runs, see [MCP providers](/reference/connect/tools#mcp-providers) in the `tools()` reference.
