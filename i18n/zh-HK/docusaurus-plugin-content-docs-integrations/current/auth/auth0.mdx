# 驗證0

這`@mastra/auth-auth0`套件使用 Auth0 為 Mastra 提供身份驗證。它使用 Auth0 頒發的 JWT 令牌驗證傳入請求，並使用`auth`選項。

## 先決條件 {/* #prerequisites */}

本範例使用 Auth0 驗證。確保：

1. 建立一個 Auth0 帳戶[auth0.com](https://auth0.com/)
2. 在 Auth0 儀表板中設定應用程式
3. 使用識別碼（受眾）在 Auth0 儀表板中設定 API
4. 設定應用程式允許的回調 URL、Web 來源和登出 URL

```env title=".env"
AUTH0_DOMAIN=your-tenant.auth0.com
AUTH0_AUDIENCE=your-api-identifier
```

：：：筆記

您可以在 Auth0 儀表板的「應用程式」>「設定」下找到您的網域。受眾是在 Auth0 儀表板 > API 中配置的 API 的識別碼。

有關詳細設定說明，請參閱[Auth0 quickstarts](https://auth0.com/docs/quickstarts) for your specific platform.

:::

## 安裝 {/* #installation */}

在您可以使用之前`MastraAuthAuth0` class you have to install the `@mastra/auth-auth0` package.

```bash npm2yarn
npm install @mastra/auth-auth0@latest
```

## 使用範例 {/* #usage-examples */}

### 環境變數的基本用法 {/* #basic-usage-with-environment-variables */}

```typescript {2,6} title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraAuthAuth0 } from '@mastra/auth-auth0'

export const mastra = new Mastra({
  server: {
    auth: new MastraAuthAuth0(),
  },
})
```

### 自訂配置 {/* #custom-configuration */}

```typescript {2,6-9} title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraAuthAuth0 } from '@mastra/auth-auth0'

export const mastra = new Mastra({
  server: {
    auth: new MastraAuthAuth0({
      domain: process.env.AUTH0_DOMAIN,
      audience: process.env.AUTH0_AUDIENCE,
    }),
  },
})
```

## 配置 {/* #configuration */}

### 使用者授權 {/* #user-authorization */}

預設情況下，`MastraAuthAuth0` allows all authenticated users who have valid Auth0 tokens for the specified audience. The token verification ensures that:

1. 令牌已由 Auth0 正確簽名
2. 令牌未過期
3. 令牌受眾與您配置的受眾相匹配
4. 令牌頒發者與您的 Auth0 網域匹配

若要自訂使用者授權，請提供自訂`authorizeUser` function:

```typescript title="src/mastra/auth.ts"
import { MastraAuthAuth0 } from '@mastra/auth-auth0'

const auth0Provider = new MastraAuthAuth0({
  authorizeUser: async user => {
    // Custom authorization logic
    return user.email?.endsWith('@yourcompany.com') || false
  },
})
```

訪問[MastraAuthAuth0](/reference/auth/auth0) for all available configuration options.

## 客戶端設定 {/* #client-side-setup */}

使用 Auth0 身份驗證時，您需要設定 Auth0 React SDK、對使用者進行身份驗證並檢索其存取權杖以傳遞給您的 Mastra 請求。

### 設定 Auth0 React SDK {/* #setting-up-auth0-react-sdk */}

首先，在您的應用程式中安裝並設定 Auth0 React SDK：

```bash npm2yarn
npm install @auth0/auth0-react
```

```typescript title="src/auth0-provider.tsx" oxfmt:false
import React from 'react'
import { Auth0Provider } from '@auth0/auth0-react'

const Auth0ProviderWithHistory = ({ children }) => {
  return (
    <Auth0Provider
      domain={process.env.REACT_APP_AUTH0_DOMAIN}
      clientId={process.env.REACT_APP_AUTH0_CLIENT_ID}
      authorizationParams={{
        redirect_uri: window.location.origin,
        audience: process.env.REACT_APP_AUTH0_AUDIENCE,
        scope: 'read:current_user update:current_user_metadata',
      }}
    >
      {children}
    </Auth0Provider>
  )
}

export default Auth0ProviderWithHistory
```

### 檢索訪問令牌 {/* #retrieving-access-tokens */}

使用 Auth0 React SDK 對使用者進行身份驗證並檢索其存取權杖：

```typescript title="lib/auth.ts"
import { useAuth0 } from '@auth0/auth0-react'

export const useAuth0Token = () => {
  const { getAccessTokenSilently } = useAuth0()

  const getAccessToken = async () => {
    const token = await getAccessTokenSilently()
    return token
  }

  return { getAccessToken }
}
```

：：：筆記

請參閱[Auth0 React SDK documentation](https://auth0.com/docs/libraries/auth0-react) for more authentication methods and configuration options.

## 配置`MastraClient` {/* #configuring-mastraclient */}

什麼時候`auth` is enabled, all requests made with `MastraClient` must include a valid Auth0 access token in the `Authorization` header:

```typescript title="lib/mastra/mastra-client.ts"
import { MastraClient } from '@mastra/client-js'

export const createMastraClient = (accessToken: string) => {
  return new MastraClient({
    baseUrl: 'https://<mastra-api-url>',
    headers: {
      Authorization: `Bearer ${accessToken}`,
    },
  })
}
```

：：：筆記

訪問令牌必須帶有前綴`Bearer` in the Authorization header.

訪問[Mastra Client SDK](/docs/server/mastra-client) for more configuration options.

:::

### 發出經過身份驗證的請求 {/* #making-authenticated-requests */}

一次`MastraClient` is configured with the Auth0 access token, you can send authenticated requests:

<Tabs>
  <TabItem value="react" label="React">
    ```tsx title="src/components/mastra-api-test.tsx"
    import React, { useState } from 'react'
    import { useAuth0 } from '@auth0/auth0-react'
    import { MastraClient } from '@mastra/client-js'

    export const MastraApiTest = () => {
      const { getAccessTokenSilently } = useAuth0()
      const [result, setResult] = useState(null)

      const callMastraApi = async () => {
        const token = await getAccessTokenSilently()

        const mastra = new MastraClient({
          baseUrl: 'http://localhost:4111',
          headers: {
            Authorization: `Bearer ${token}`,
          },
        })

        const weatherAgent = mastra.getAgent('weatherAgent')
        const response = await weatherAgent.generate("What's the weather like in New York")

        setResult(response.text)
      }

      return (
        <div>
          <button onClick={callMastraApi}>Test Mastra API</button>

          {result && (
            <div className="result">
              <h6>Result:</h6>
              <pre>{result}</pre>
            </div>
          )}
        </div>
      )
    }
    ```
  </TabItem>
