# Clerk

Clerk 可以用於 Mastra 的兩個部分：

- **Agent 工具**讓 Agent 透過 [Mastra Connect](/docs/mastra-platform/connect) 管理 Clerk 用戶、組織及工作階段。
- **[伺服器身份驗證](#server-authentication)**使用 `@mastra/auth-clerk` 套件，透過 Clerk 驗證傳送至 Mastra 伺服器的請求。

## Connect {/* #connect */}

請先按 [Connect 設定指引](/docs/mastra-platform/connect#get-started) 安裝 `@mastra/connect`，並設定 Mastra Platform 項目。

## 伺服器身份驗證 {/* #server-authentication */}

`@mastra/auth-clerk` 套件利用 Clerk 的身份驗證系統核實傳入的請求。透過 `auth` 選項，便可將套件接駁至 Mastra 伺服器。

### 開始前的準備 {/* #prerequisites */}

這個例子採用 Clerk 身份驗證。請確認 Clerk 項目的設定正確，並將 Clerk 憑證加入 `.env` 檔案。

```env title=".env"
CLERK_PUBLISHABLE_KEY=pk_test_...
CLERK_SECRET_KEY=sk_test_...
CLERK_JWKS_URI=https://your-clerk-domain.clerk.accounts.dev/.well-known/jwks.json
```

:::note

這些密鑰可在 Clerk Dashboard 的「API Keys」頁面找到。

:::

### 安裝 {/* #installation */}

要使用 `MastraAuthClerk` 類別，請先安裝 `@mastra/auth-clerk` 套件。

```bash npm2yarn
npm install @mastra/auth-clerk@latest
```

### 使用示例 {/* #usage-example */}

```typescript {2,6-10} title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraAuthClerk } from '@mastra/auth-clerk'

export const mastra = new Mastra({
  server: {
    auth: new MastraAuthClerk({
      publishableKey: process.env.CLERK_PUBLISHABLE_KEY,
      secretKey: process.env.CLERK_SECRET_KEY,
      jwksUri: process.env.CLERK_JWKS_URI,
    }),
  },
})
```

:::note

預設的 `authorizeUser` 方法會容許所有已通過身份驗證的用戶存取。如需自行設定用戶授權規則，請在建立身份驗證提供者時傳入自訂的 `authorizeUser` 函數。

所有可用的設定選項均載於 [MastraAuthClerk](/reference/auth/clerk)。

:::

### 用戶端設定 {/* #client-side-setup */}

採用 Clerk 身份驗證時，用戶端須向 Clerk 取得存取權杖，再隨請求一併傳送至 Mastra。

#### 取得存取權杖 {/* #retrieving-the-access-token */}

透過 Clerk 的 React Hook 驗證用戶身份，並取得該用戶的存取權杖：

```typescript title="lib/auth.ts"
import { useAuth } from '@clerk/nextjs'

export const useClerkAuth = () => {
  const { getToken } = useAuth()

  const getAccessToken = async () => {
    const token = await getToken()
    return token
  }

  return { getAccessToken }
}
```

詳情可參閱 [Clerk 文件](https://clerk.com/docs)。

### 設定 `MastraClient` {/* #configuring-mastraclient */}

啟用 `auth` 後，經 `MastraClient` 發出的所有請求，均須在 `Authorization` 標頭內附上有效的 Clerk 存取權杖：

```typescript {6} title="lib/mastra/mastra-client.ts"
import { MastraClient } from '@mastra/client-js'

export const mastraClient = new MastraClient({
  baseUrl: 'https://<mastra-api-url>',
  headers: {
    Authorization: `Bearer ${accessToken}`,
  },
})
```

:::note

在 Authorization 標頭內，存取權杖前必須加上 `Bearer` 和一個空格。

其他設定選項可參閱 [Mastra Client SDK](/docs/server/mastra-client)。

:::

#### 發出經身份驗證的請求 {/* #making-authenticated-requests */}

在 `MastraClient` 設定好 Clerk 存取權杖後，便可發出經身份驗證的請求：

<Tabs>
  <TabItem value="react" label="React">
    ```tsx title="src/components/test-agent.tsx"
    'use client'

    import { useAuth } from '@clerk/nextjs'
    import { MastraClient } from '@mastra/client-js'

    export const TestAgent = () => {
      const { getToken } = useAuth()

      async function handleClick() {
        const token = await getToken()

        const client = new MastraClient({
          baseUrl: 'http://localhost:4111',
          headers: token ? { Authorization: `Bearer ${token}` } : undefined,
        })

        const weatherAgent = client.getAgent('weatherAgent')
        const response = await weatherAgent.generate("What's the weather like in New York")

        console.log({ response })
      }

      return <button onClick={handleClick}>Test Agent</button>
    }
    ```
