# WorkOS

你可以用兩種方式將 WorkOS 整合到 Mastra：

* **Agent Tool** 讓 Agent 經 [Mastra Connect](/docs/mastra-platform/connect) 管理 WorkOS 組織、用戶及 SSO 連接。
* **[伺服器身份驗證](#server-authentication)** 透過 `@mastra/auth-workos` 套件，使用 WorkOS 驗證送往 Mastra 伺服器的請求。

## Connect {/* #connect */}

開始前，請按 [Connect 設定指引](/docs/mastra-platform/connect#get-started)安裝 `@mastra/connect`，並設定你的平台項目。

## 伺服器身份驗證 {/* #server-authentication */}

`@mastra/auth-workos` 套件讓 Mastra 使用 WorkOS 進行身份驗證。套件以 WorkOS 存取令牌驗證收到的請求，並經 `auth` 選項接入 Mastra 伺服器。

### 先決條件 {/* #prerequisites */}

這個示例採用 WorkOS 身份驗證。請先完成以下步驟：

1. 在 [workos.com](https://workos.com/) 開設 WorkOS 帳戶
2. 在 WorkOS 管理介面設定應用程式
3. 設定重新導向 URI 及允許的來源
4. 按需要設定組織及用戶角色

```env title=".env"
WORKOS_API_KEY=sk_live_...
WORKOS_CLIENT_ID=client_...
```

:::note

你可在 WorkOS 管理介面的 API Keys 和 Applications 頁面，分別找到 API 密鑰和客戶端 ID。

有關詳細設定步驟，請參閱 [WorkOS 文件](https://workos.com/docs)中適用於你所用平台的指引。

:::

### 安裝 {/* #installation */}

使用 `MastraAuthWorkos` 類別前，必須先安裝 `@mastra/auth-workos` 套件。

```bash npm2yarn
npm install @mastra/auth-workos@latest
```

### 使用示例 {/* #usage-examples */}

#### 使用環境變數 {/* #basic-usage-with-environment-variables */}

```typescript {2,6} title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraAuthWorkos } from '@mastra/auth-workos'

export const mastra = new Mastra({
  server: {
    auth: new MastraAuthWorkos(),
  },
})
```

#### 自訂設定 {/* #custom-configuration */}

```typescript {2,6-9} title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraAuthWorkos } from '@mastra/auth-workos'

export const mastra = new Mastra({
  server: {
    auth: new MastraAuthWorkos({
      apiKey: process.env.WORKOS_API_KEY,
      clientId: process.env.WORKOS_CLIENT_ID,
    }),
  },
})
```

### 設定 {/* #configuration */}

#### 預設授權 {/* #default-authorization */}

預設情況下，`MastraAuthWorkos` 允許任何已通過身份驗證的 WorkOS 用戶存取。當解析所得的用戶物件同時包含 Mastra 用戶 ID 和 WorkOS 用戶 ID，授權檢查便會通過。

#### 載入 FGA 所需的組織成員關係 {/* #fga-membership-loading */}

:::note

在生產環境使用 FGA 須具備 Mastra 企業版（EE）授權，開發環境則毋須授權。請參閱[哪些功能需要 EE 授權](/docs/license#what-requires-an-ee-license)。如欲了解詳情，請[聯絡銷售團隊](https://mastra.ai/contact)。

:::

使用 [`MastraFGAWorkos`](/docs/auth/fga) 時，請設定 `fetchMemberships: true`。身份驗證 Provider 會在驗證身份時載入用戶在 WorkOS 的組織成員關係，讓 FGA 檢查能找出正確的組織成員關係 ID。

```typescript title="src/mastra/auth.ts"
import { MastraAuthWorkos, MastraFGAWorkos } from '@mastra/auth-workos'

const workosAuth = new MastraAuthWorkos({
  apiKey: process.env.WORKOS_API_KEY,
  clientId: process.env.WORKOS_CLIENT_ID,
  fetchMemberships: true,
})

const workosFga = new MastraFGAWorkos({
  apiKey: process.env.WORKOS_API_KEY,
  clientId: process.env.WORKOS_CLIENT_ID,
})
```

如果 `fetchMemberships` 設為 `false`，Mastra 處理每個已通過身份驗證的請求時，都會省略對 WorkOS `listOrganizationMemberships()` 的額外呼叫。

#### 服務令牌及自訂 JWT 範本 {/* #service-tokens-and-custom-jwt-templates */}

如需讓機器之間通訊或讓服務帳戶存取，可設定 `MastraAuthWorkos`，信任由 WorkOS 自訂 JWT 範本產生的持有人令牌內已核實的聲明。

```typescript title="src/mastra/auth.ts"
import { MastraAuthWorkos } from '@mastra/auth-workos'

const workosAuth = new MastraAuthWorkos({
  apiKey: process.env.WORKOS_API_KEY,
  clientId: process.env.WORKOS_CLIENT_ID,
  redirectUri: process.env.WORKOS_REDIRECT_URI,
  trustJwtClaims: true,
  jwtClaims: {
    organizationId: 'org_id',
    organizationMembershipId: 'urn:mastra:organization_membership_id',
  },
})
```

如果 JWT 範本已包含 Mastra 進行 FGA 檢查所需的資料，例如 `organizationMembershipId`、租戶 ID 或服務主體識別碼，這項設定便能派上用場。啟用 `trustJwtClaims` 後，如持有人令牌並非用於經 `workos.userManagement.getUser()` 查詢用戶，Mastra 可改用這些已核實的聲明。

#### 自訂授權 {/* #custom-authorization */}

如需更嚴格的授權，可建立 `MastraAuthWorkos` 的子類別，並覆寫 `authorizeUser()`：

```typescript title="src/mastra/auth.ts"
import { MastraAuthWorkos } from '@mastra/auth-workos'
import type { HonoRequest } from 'hono'

class AdminOnlyWorkosAuth extends MastraAuthWorkos {
  async authorizeUser(user: any, _request: HonoRequest): Promise<boolean> {
    return user?.metadata?.role === 'admin'
  }
}

const workosAuth = new AdminOnlyWorkosAuth({
  apiKey: process.env.WORKOS_API_KEY,
  clientId: process.env.WORKOS_CLIENT_ID,
})
```

所有可用的設定選項均載於 [MastraAuthWorkos](/reference/auth/workos)。

### 客戶端設定 {/* #client-side-setup */}

採用 WorkOS 身份驗證時，你需要實作 WorkOS 的驗證流程，將授權碼換成存取令牌，再以該令牌向 Mastra 發送請求。

#### 安裝 WorkOS SDK {/* #installing-workos-sdk */}

先在你的應用程式內安裝 WorkOS SDK：

```bash npm2yarn
npm install @workos-inc/node
```

#### 用授權碼換取存取令牌 {/* #exchanging-code-for-access-token */}

用戶完成 WorkOS 身份驗證流程並帶同授權碼返回後，便可用該授權碼換取存取令牌：

```typescript title="lib/auth.ts"
import { WorkOS } from '@workos-inc/node'

const workos = new WorkOS(process.env.WORKOS_API_KEY)

export const authenticateWithWorkos = async (code: string, clientId: string) => {
  const authenticationResponse = await workos.userManagement.authenticateWithCode({
    code,
    clientId,
  })

  return authenticationResponse.accessToken
}
```

:::note

其他身份驗證方法及設定選項，可參閱 [WorkOS 用戶管理文件](https://workos.com/docs/authkit/vanilla/nodejs)。

:::

### 設定 `MastraClient` {/* #configuring-mastraclient */}

啟用 `auth` 後，所有經 `MastraClient` 發出的請求，均須在 `Authorization` 標頭內附上有效的 WorkOS 存取令牌：

```typescript title="lib/mastra/mastra-client.ts"
import { MastraClient } from '@mastra/client-js'

export const createMastraClient = (accessToken: string) => {
  return new MastraClient({
    baseUrl: 'https://<mastra-api-url>',
    headers: {
      Authorization: `Bearer ${accessToken}`,
    },
  })
}
```

:::note

在 Authorization 標頭內，存取令牌前必須加上 `Bearer`。

更多設定選項可參閱 [Mastra Client SDK](/docs/server/mastra-client)。

:::

#### 發送附有身份驗證憑據的請求 {/* #making-authenticated-requests */}

為 `MastraClient` 設定 WorkOS 存取令牌後，便可發送附有身份驗證憑據的請求：

<Tabs>
  <TabItem value="react" label="React">
    ```typescript title="src/api/agents.ts"
    import { WorkOS } from '@workos-inc/node'
    import { MastraClient } from '@mastra/client-js'

    const workos = new WorkOS(process.env.WORKOS_API_KEY)

    export const callMastraWithWorkos = async (code: string, clientId: string) => {
      const authenticationResponse = await workos.userManagement.authenticateWithCode({
        code,
        clientId,
      })

      const token = authenticationResponse.accessToken

      const mastra = new MastraClient({
        baseUrl: 'http://localhost:4111',
        headers: {
          Authorization: `Bearer ${token}`,
        },
      })

      const weatherAgent = mastra.getAgent('weatherAgent')
      const response = await weatherAgent.generate("What's the weather like in Nairobi")

      return response.text
    }
    ```
