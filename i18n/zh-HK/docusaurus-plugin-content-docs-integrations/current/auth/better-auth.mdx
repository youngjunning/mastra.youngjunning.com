# Better Auth

`@mastra/auth-better-auth` 套件透過 Better Auth 為 Mastra 提供身份驗證。套件經由 `server.auth` 選項與 Mastra 伺服器整合，並以你的 Better Auth 實例驗證傳入的請求。

## 先決條件 {/* #prerequisites */}

此示例採用 Better Auth。請先完成 Better Auth 實例的設定，並設好所需的環境變數。

```env title=".env"
# Required by Better Auth
BETTER_AUTH_SECRET=...   # at least 32 chars
BETTER_AUTH_URL=http://localhost:3000

# Example DB URL used by the snippet below (adjust for your setup)
DATABASE_URL=postgres://...
```

:::note

考慮到安全性和穩定性，Better Auth 建議明確設定 `baseURL`，亦可透過 `BETTER_AUTH_URL` 設定。

:::

如未掛載 Better Auth 的處理程式，請按 [Better Auth 安裝指南](https://www.better-auth.com/docs/installation)，將處理程式掛載至 `/api/auth/*` 路由或你已設定的基礎路徑。掛載後，應用程式便可讓用戶登入並建立會話。

## 安裝 {/* #installation */}

安裝 `@mastra/auth-better-auth` 套件。

```bash npm2yarn
npm install @mastra/auth-better-auth
```

## 使用示例 {/* #usage-example */}

先建立 Better Auth 實例。

```ts title="lib/auth.ts"
import { betterAuth } from 'better-auth'

export const auth = betterAuth({
  database: {
    provider: 'postgresql',
    url: process.env.DATABASE_URL!,
  },
  emailAndPassword: {
    enabled: true,
  },
  baseURL: process.env.BETTER_AUTH_URL,
  secret: process.env.BETTER_AUTH_SECRET,
})
```

再將這個實例接入 Mastra。

```ts title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraAuthBetterAuth } from '@mastra/auth-better-auth'
import { auth } from '@/lib/auth'

const mastraAuth = new MastraAuthBetterAuth({
  auth,
})

export const mastra = new Mastra({
  server: {
    auth: mastraAuth,
  },
})
```

完整的設定選項見 [MastraAuthBetterAuth](/reference/auth/better-auth)。

## 自訂授權 {/* #custom-authorization */}

```ts
const mastraAuth = new MastraAuthBetterAuth({
  auth,
  async authorizeUser(user) {
    // Example: only allow verified emails
    return user?.user?.emailVerified === true
  },
})
```

## 路由設定 {/* #route-configuration */}

```ts
const mastraAuth = new MastraAuthBetterAuth({
  auth,
  public: ['/health', '/api/status'],
  protected: ['/api/*', '/admin/*'],
})
```

### 匹配規則 {/* #matching-rules */}

* `public` 和 `protected` 均支援精確路徑、萬用字元模式（如 `/api/*`）及路徑參數（如 `/users/:id`）。
* 如規則只適用於指定的 HTTP 方法，請使用元組，例如 `["/api/agents", ["GET", "POST"]]`。
* 路由如同時符合 `public` 和 `protected`，以 `public` 為準，毋須驗證身份。
* 如兩者均不符合，路由預設受保護，除非你明確將該路由標記為 `requiresAuth: false`。

## 客戶端設定 {/* #client-side-setup */}

啟用身份驗證後，向 Mastra 內置路由發出的請求均需驗證身份。客戶端須隨請求傳送 Better Auth 目前設定所採用的憑證。

### Cookie 會話（建議） {/* #cookie-session-recommended */}

如果 Better Auth 使用 Cookie，請設定客戶端隨請求傳送憑證。如需發出跨來源請求，例如由在 `:3000` 運行的 Next.js 呼叫在 `:4111` 運行的 Mastra，請在 Mastra 伺服器的 CORS 設定中允許附帶憑證。

```ts title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'

export const mastra = new Mastra({
  server: {
    auth: mastraAuth,
    cors: {
      origin: 'http://localhost:3000', // your frontend origin
      credentials: true,
    },
  },
})
```

然後設定客戶端，讓它隨請求附上憑證。

```ts
import { MastraClient } from '@mastra/client-js'

export const mastraClient = new MastraClient({
  baseUrl: 'http://localhost:4111',
  credentials: 'include',
})
```

如直接呼叫 API，亦須設定 `fetch` 隨請求傳送憑證。

```ts
await fetch('http://localhost:4111/api/agents/weatherAgent/generate', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
  },
  credentials: 'include',
  body: JSON.stringify({ messages: 'Weather in London' }),
})
```

### Bearer 令牌 {/* #bearer-token */}

你可以用已簽署的會話令牌作為 Bearer 令牌。從 Better Auth 客戶端的會話取得令牌，再將它加入 `Authorization` 請求標頭。

```ts
import { MastraClient } from '@mastra/client-js'
import { authClient } from './auth-client' // your Better Auth client

const session = await authClient.getSession()

export const mastraClient = new MastraClient({
  baseUrl: 'http://localhost:4111',
  headers: {
    Authorization: `Bearer ${session.data?.session.token}`,
  },
})
```

更多設定選項見 [Mastra Client SDK](/docs/server/mastra-client)。

## 故障排除 {/* #troubleshooting */}

* **所有請求均傳回 401**。確認 Better Auth 的處理程式已掛載，應用程式亦能建立有效會話。檢查客戶端有否傳送會話 Cookie 或 `Authorization: Bearer <signed-token>` 請求標頭。
* **跨來源請求沒有附上 Cookie**。在 `MastraClient` 設定 `credentials: "include"`，並在 `server.cors` 設定前端來源及 `credentials: true`。
* **Bearer 令牌被拒絕**。請傳送從 `authClient.getSession()` 取得、帶有簽署的完整會話令牌，避免使用原始或未簽署的令牌。
* **基礎 URL 有問題**。在 `betterAuth({ ... })` 中設定 `baseURL`，或設定 `BETTER_AUTH_URL`。
* **資料庫連線出錯**。檢查 `DATABASE_URL` 及資料庫供應商的設定。
