# Supabase

你可以用以下兩種方式將 Supabase 和 Mastra 一併使用：

- **Agent 工具**讓 Agent 透過 [Mastra Connect](/docs/mastra-platform/connect) 查詢 Supabase 的資料表、呼叫資料庫函數，以及管理儲存空間和 Supabase Auth 用戶。
- **[伺服器身份驗證](#server-authentication)**透過 `@mastra/auth-supabase` 套件，使用 Supabase 驗證發往 Mastra 伺服器的請求。

## Connect {/* #connect */}

開始前，請按照 [Connect 設定指引](/docs/mastra-platform/connect#get-started)安裝 `@mastra/connect`，並設定你的平台項目。

## 伺服器身份驗證 {/* #server-authentication */}

`@mastra/auth-supabase` 套件透過 `auth` 選項整合至 Mastra 伺服器，並使用 Supabase Auth 驗證收到的請求。

### 事前準備 {/* #prerequisites */}

這個例子使用 Supabase Auth。請確保 Supabase 項目已正確設定，並將 Supabase 憑證加入 `.env` 檔案。

```env title=".env"
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_ANON_KEY=your-anon-key
```

:::note

請檢查 Supabase 的資料列層級安全性（RLS）設定，確保資料存取權限符合預期。

:::

### 安裝 {/* #installation */}

使用 `MastraAuthSupabase` 類別之前，請先安裝 `@mastra/auth-supabase` 套件。

```bash npm2yarn
npm install @mastra/auth-supabase@latest
```

### 用法示例 {/* #usage-example */}

```typescript {2,6-9} title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraAuthSupabase } from '@mastra/auth-supabase'

export const mastra = new Mastra({
  server: {
    auth: new MastraAuthSupabase({
      url: process.env.SUPABASE_URL,
      anonKey: process.env.SUPABASE_ANON_KEY,
    }),
  },
})
```

:::note

預設的 `authorizeUser` 方法會檢查 `public` schema 內 `users` 資料表的 `isAdmin` 欄位。如要自訂用戶授權邏輯，請在建立身份驗證提供者的實例時傳入自訂的 `authorizeUser` 函數。

所有可用的設定選項請參閱 [MastraAuthSupabase](/reference/auth/supabase)。

:::

### 客戶端設定 {/* #client-side-setup */}

使用 Supabase Auth 時，你需要在客戶端向 Supabase 取得存取權杖，並在向 Mastra 發出請求時附上該權杖。

#### 取得存取權杖 {/* #retrieving-the-access-token */}

使用 Supabase 客戶端驗證用戶身份，並取得該用戶的存取權杖：

```typescript title="lib/auth.ts"
import { createClient } from '@supabase/supabase-js'

const supabase = createClient('<supabase-url>', '<supabase-key>')

const authTokenResponse = await supabase.auth.signInWithPassword({
  email: "<user's email>",
  password: "<user's password>",
})

const accessToken = authTokenResponse.data?.session?.access_token
```

:::note

如要了解 OAuth、免密碼登入連結（magic link）等其他身份驗證方式，請參閱 [Supabase 文件](https://supabase.com/docs/guides/auth)。

:::

### 設定 `MastraClient` {/* #configuring-mastraclient */}

啟用 `auth` 後，經 `MastraClient` 發出的所有請求都必須在 `Authorization` 標頭內附上有效的 Supabase 存取權杖：

```typescript {6} title="lib/mastra/mastra-client.ts"
import { MastraClient } from '@mastra/client-js'

export const mastraClient = new MastraClient({
  baseUrl: 'https://<mastra-api-url>',
  headers: {
    Authorization: `Bearer ${accessToken}`,
  },
})
```

:::note

在 Authorization 標頭內，存取權杖前必須加上 `Bearer` 和一個空格。

更多設定選項請參閱 [Mastra Client SDK](/docs/server/mastra-client)。

:::

#### 發出附有驗證憑證的請求 {/* #making-authenticated-requests */}

為 `MastraClient` 設定 Supabase 存取權杖後，便可發出附有該權杖的請求：

    }
