# Linear

透過 Mastra Connect，為 Agent 提供可在 Linear 中搜尋、建立及更新議題，並管理項目、週期、留言與標籤的 Tool。每次 Tool 呼叫都會經過 Mastra 平台，由平台加入該連接的憑證；你的應用程式不會儲存 Linear 憑證。

## 連接 {/* #connect */}

開始前，請先完成 [Connect 設定](/docs/mastra-platform/connect#get-started)，安裝 `@mastra/connect` 並設定 Mastra 平台項目。

### 連接帳戶 {/* #connect-an-account */}

請在包含 `.env` 檔案的目錄中執行以下指令：

```bash
mastra connect add linear
```

CLI 會引導你完成 Linear 授權，並等待連接啟用。

### 將 Tool 加入 Agent {/* #add-tools-to-an-agent */}

將 [`tools()`](/reference/connect/tools) 傳給 Agent，並選擇 `linear` Provider：

```typescript title="src/mastra/agents/linear-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const linearAgent = new Agent({
  id: 'linear-agent',
  name: 'Linear agent',
  instructions:
    'You help people search, create, and update issues, and manage projects, cycles, comments, and labels in Linear.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['linear'] }),
})
```

Agent 可使用 46 個 Linear Tool，Tool key 包括 `linear_add_issue_label`。完整清單請參閱 [Linear Tool](/reference/connect/providers#linear)；如需限制可用 Tool，或要求每次呼叫在執行前取得批准，請參閱 [`tools()` 參數](/reference/connect/tools#parameters)。
