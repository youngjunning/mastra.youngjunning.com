# Jira

透過 Mastra Connect，為 Agent 提供可在 Jira 中搜尋、建立、更新及轉換議題狀態，並管理留言、工時記錄和議題連結的 Tool。每次 Tool 呼叫都會經過 Mastra 平台，由平台加入該連接的憑證；你的應用程式不會儲存 Jira 憑證。

## 連接 {/* #connect */}

開始前，請先完成 [Connect 設定](/docs/mastra-platform/connect#get-started)，安裝 `@mastra/connect` 並設定 Mastra 平台項目。

### 連接帳戶 {/* #connect-an-account */}

請在包含 `.env` 檔案的目錄中執行以下指令：

```bash
mastra connect add jira
```

CLI 會引導你完成 Jira 授權，並等待連接啟用。

### 將 Tool 加入 Agent {/* #add-tools-to-an-agent */}

將 [`tools()`](/reference/connect/tools) 傳給 Agent，並選擇 `jira` Provider：

```typescript title="src/mastra/agents/jira-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const jiraAgent = new Agent({
  id: 'jira-agent',
  name: 'Jira agent',
  instructions:
    'You help people search, create, update, and transition issues, and manage comments, worklogs, and issue links in Jira.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['jira'] }),
})
```

Agent 可使用 38 個 Jira Tool，Tool key 包括 `jira_add_comment`。完整清單請參閱 [Jira Tool](/reference/connect/providers#jira)；如需限制可用 Tool，或要求每次呼叫在執行前取得批准，請參閱 [`tools()` 參數](/reference/connect/tools#parameters)。
