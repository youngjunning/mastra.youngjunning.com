# Perplexity

`@mastra/perplexity` 套件把 [Perplexity Search API](https://docs.perplexity.ai/docs/search/quickstart) 封裝成兼容 Mastra 的 Tool。套件提供一個工廠函數，回傳透過 [`createTool()`](/reference/tools/create-tool) 建立的 Tool，並為輸入及輸出提供完整的 Zod Schema。

如果要以 Perplexity 生成聊天補全，或執行由 Agent 驅動的 Workflow，可使用 Mastra 內置的 [Perplexity 模型 Provider](/models/providers/perplexity) 或 [Perplexity Agent Provider](/models/providers/perplexity-agent)。兩者均獨立於此搜尋 Tool。

## 安裝 {/* #installation */}

一併安裝此套件及 Zod：

```sh npm2yarn
npm install @mastra/perplexity zod
```

## 使用示例 {/* #usage-example */}

以下示例以預設設定建立搜尋 Tool。Tool 會先讀取環境變數 `PERPLEXITY_API_KEY`，如未設定便改用 `PPLX_API_KEY`。如要覆寫預設行為，可明確傳入 `{ apiKey }`。

```typescript title="src/mastra/tools/index.ts"
import { createPerplexitySearchTool } from '@mastra/perplexity'

const searchTool = createPerplexitySearchTool()
```

以下示例直接傳入 API 密鑰：

```typescript title="src/mastra/tools/index.ts"
import { createPerplexitySearchTool } from '@mastra/perplexity'

const searchTool = createPerplexitySearchTool({ apiKey: 'pplx-...' })
```

## 方法 {/* #methods */}

### 工廠函數 {/* #factory-functions */}

#### `createPerplexityTools(config?)` {/* #createperplexitytoolsconfig */}

回傳一個包含所有 Perplexity Tool 的物件，各個 Tool 共用傳入的設定。

```typescript
import { createPerplexityTools } from '@mastra/perplexity'

const tools = createPerplexityTools({ apiKey: 'pplx-...' })
// tools.perplexitySearch
```

回傳值：`{ perplexitySearch }`

#### `createPerplexitySearchTool(config?)` {/* #createperplexitysearchtoolconfig */}

建立一個透過 Perplexity Search API 搜尋網頁的 Tool。結果按排名回傳，每項均包含標題、URL 及內容摘錄，並在有資料時附上發佈日期。

此 Tool 以 `perplexity-search` 為註冊 ID。

```typescript
import { createPerplexitySearchTool } from '@mastra/perplexity'

const searchTool = createPerplexitySearchTool()
```

## Agent 示例 {/* #agent-example */}

以下示例把搜尋 Tool 註冊到 Agent，讓 Agent 可以先取得最新的網頁搜尋結果，再作答。

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { createPerplexitySearchTool } from '@mastra/perplexity'

const agent = new Agent({
  id: 'research-agent',
  name: 'Research Agent',
  model: '__GATEWAY_ANTHROPIC_MODEL_SONNET__',
  instructions:
    'You are a research assistant. Use the perplexity-search tool to find up-to-date information from the web before answering.',
  tools: {
    search: createPerplexitySearchTool(),
  },
})
```

## 環境變數 {/* #environment-variables */}

| 變數 | 說明 |
| - | - |
| `PERPLEXITY_API_KEY` | 你的 Perplexity API 密鑰。呼叫工廠函數時如未傳入 `apiKey`，便預設使用此變數。 |
| `PPLX_API_KEY` | `PERPLEXITY_API_KEY` 未設定時使用的後備變數。 |
