# 明亮的數據

這`@mastra/brightdata`包裝包裹著[光明數據SDK](https://github.com/brightdata/bright-data-sdk-node)作為 Mastra 相容Tool。它公開了用於網路搜尋和網路取得的工廠函數。每個函數傳回一個使用以下命令建立的Tool[`createTool()`](/reference/tools/create-tool)其中包括完整的 Zod 輸入/輸出模式。

該搜尋Tool由 Bright Data 提供支援[SERP API](https://brightdata.com/products/serp-api) and the fetch tool by [Web Unlocker](https://brightdata.com/products/web-unlocker). Both bypass bot detection and CAPTCHAs.

## 安裝 {/* #installation */}

```sh npm2yarn
npm install @mastra/brightdata zod
```

## 快速啟動 {/* #quick-start */}

使用`createBrightDataTools()` to get both tools with shared configuration:

```typescript title="src/mastra/tools/index.ts"
import { createBrightDataTools } from '@mastra/brightdata'

const { webSearch, webFetch } = createBrightDataTools()
// Or pass an explicit API key:
// const { webSearch, webFetch } = createBrightDataTools({ apiKey: 'brd-...' })
```

每個Tool也可以單獨建立：

```typescript title="src/mastra/tools/index.ts"
import { createBrightDataSearchTool, createBrightDataFetchTool } from '@mastra/brightdata'

const searchTool = createBrightDataSearchTool()
const fetchTool = createBrightDataFetchTool({ apiKey: 'brd-...' })
```

預設情況下，所有Tool都會讀取`BRIGHTDATA_API_TOKEN` from the environment. You can pass `{ apiKey }` explicitly to override.

## `createBrightDataTools()` {/* #createbrightdatatools */}

傳回一個對象，其中包含具有共享配置的兩個Tool。

```typescript
import { createBrightDataTools } from '@mastra/brightdata'

const tools = createBrightDataTools({ apiKey: 'brd-...' })
// tools.webSearch, tools.webFetch
```

**返回：** `{ webSearch, webFetch }`

## `createBrightDataSearchTool()` {/* #createbrightdatasearchtool */}

建立一個透過 Bright Data 的 SERP API 搜尋 Google 的Tool。傳回解析的有機結果。

**Tool編號：** `brightdata-search`

## Agent範例 {/* #agent-example */}

以下範例示範了結合搜尋和獲取的研究Agent：

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { createBrightDataTools } from '@mastra/brightdata'

const { webSearch, webFetch } = createBrightDataTools()

const agent = new Agent({
  id: 'research-agent',
  name: 'Research Agent',
  model: '__GATEWAY_ANTHROPIC_MODEL_SONNET__',
  instructions:
    'You are a research assistant. Use the search tool to find relevant pages, then use the fetch tool to read full Markdown content from the best results.',
  tools: {
    webSearch,
    webFetch,
  },
})
```
