# Parallel

`@mastra/parallel` 套件提供與 Mastra 相容的 [Parallel Search](https://docs.parallel.ai/search/search-quickstart) 和 [Extract](https://docs.parallel.ai/extract/extract-quickstart) Tool。每個工廠函式都會傳回透過 [`createTool()`](/reference/tools/create-tool) 建立的 Tool，並附有具類型的 Zod 輸入與輸出 schema。

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/parallel parallel-web zod
```

在環境中設定 `PARALLEL_API_KEY`。亦可直接向任何工廠函式傳入 API key。

## 快速啟動 {/* #quick-start */}

使用 `createParallelTools()` 建立共用客戶端設定的兩個 Tool：

```typescript title="src/mastra/tools/index.ts"
import { createParallelTools } from '@mastra/parallel'

export const parallelTools = createParallelTools()
// Or pass an explicit API key:
// export const parallelTools = createParallelTools({ apiKey: 'parallel-api-key' })
```

傳回的物件包含 `parallelSearch` 和 `parallelExtract`。

如 Agent 毋須同時使用兩個 Tool，可以個別建立所需的 Tool：

```typescript title="src/mastra/tools/index.ts"
import { createParallelExtractTool, createParallelSearchTool } from '@mastra/parallel'

export const searchTool = createParallelSearchTool()
export const extractTool = createParallelExtractTool({ apiKey: 'parallel-api-key' })
```

客戶端要到 Tool 執行時才會初始化。因此，如缺少 API key，執行時才會出現設定錯誤。

## `createParallelSearchTool()` {/* #createparallelsearchtool */}

建立 `parallel-search` Tool。Search 根據提供的查詢和目標，傳回按相關程度排序的 URL 及內容摘錄。

```typescript

const searchTool = createParallelSearchTool()
```

## 在 Agent 中使用這些 Tool {/* #use-the-tools-with-an-agent */}

```typescript title="src/mastra/agents/research-agent.ts"
import { Agent } from '@mastra/core/agent'
import { createParallelTools } from '@mastra/parallel'

export const researchAgent = new Agent({
  id: 'research-agent',
  name: 'Research Agent',
  model: '__GATEWAY_ANTHROPIC_MODEL_SONNET__',
  instructions:
    'Search the web for current sources, then extract relevant content from the best pages.',
  tools: createParallelTools(),
})
```
