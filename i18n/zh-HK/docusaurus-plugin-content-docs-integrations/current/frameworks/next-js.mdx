# Next.js

## 建立串流聊天介面 {/* #build-a-streaming-chat-interface */}

按本指南，你會用 Mastra 建立一個可呼叫 Tool 的 AI Agent，再在 Next.js 路由內直接匯入並呼叫該 Agent，完成整合。

聊天介面會用到 [AI SDK UI](https://ai-sdk.dev/docs/ai-sdk-ui/overview) 及 [AI Elements](https://ai-sdk.dev/elements)，讓使用者在美觀的頁面上互動。

### 開始之前 {/* #before-you-begin */}

* 你需要一個由受支援的[模型 Provider](/models) 提供的 API 金鑰。如沒有指定要用哪一家，可選用 [OpenAI](/models/providers/openai)。
* 安裝 Node.js `v22.13.0` 或以上版本。

### 建立 Next.js 應用程式（可略過） {/* #create-a-new-nextjs-app-optional */}

如已有 Next.js 應用程式，可直接跳到下一步。

執行以下指令，[建立 Next.js 應用程式](https://nextjs.org/docs/app/getting-started/installation)：

```bash npm2yarn
npx create-next-app@latest my-nextjs-agent --yes --ts --eslint --tailwind --src-dir --app --turbopack --no-react-compiler --no-import-alias
```

這條指令會建立名為 `my-nextjs-agent` 的項目，你可以按需要更改名稱。

### 初始化 Mastra {/* #initialize-mastra */}

切換到 Next.js 項目的目錄：

```bash
cd my-nextjs-agent
```

執行 [`mastra init`](/reference/cli/mastra#mastra-init)，按提示選擇 Provider（例如 OpenAI），然後輸入 API 金鑰：

```bash npm2yarn
npx mastra@latest init
```

初始化會建立 `src/mastra` 資料夾，當中有一個查詢天氣的 Agent 範例以及以下檔案：

* `index.ts`：Mastra 設定，包括記憶功能的設定。
* `tools/weather-tool.ts`：查詢指定地點天氣的 Tool。
* `agents/weather-agent.ts`：查詢天氣的 Agent，提示詞會指示它使用這個 Tool。

稍後你會從 Next.js 路由呼叫 `weather-agent.ts` 內定義的 Agent。

:::tip[同時執行 Studio 和 Next.js]
如要同時執行 [Studio](/docs/studio/overview) 和 Next.js 應用程式，並共用同一個資料庫，請在 `src/mastra/index.ts` 的儲存 URL 使用絕對路徑：

```typescript
url: 'file:/absolute/path/to/your/project/mastra.db'
```

相對路徑會以各程序的工作目錄為準。`next dev` 和 `mastra dev` 使用不同的工作目錄。
:::

### 設定 Next.js {/* #configure-nextjs */}

Mastra 套件會載入 Node.js 原生模組，例如用於儲存可觀測性數據的 DuckDB 綁定。Next.js 的打包工具無法打包這類模組，因此要在 `next.config.ts` 加入 `serverExternalPackages`，讓 Next.js 在執行時從 `node_modules` 載入 Mastra 套件：

```ts title="next.config.ts"
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  serverExternalPackages: ['@mastra/*'],
}

export default nextConfig
```

如果 `next.config.ts` 已有其他設定，將 `serverExternalPackages` 加入同一層便可。

### 安裝 AI SDK UI 及 AI Elements {/* #install-ai-sdk-ui--ai-elements */}

一併安裝 AI SDK UI 和 Mastra 適配器：

```bash npm2yarn
npm install @mastra/ai-sdk@latest @ai-sdk/react ai
```

然後加入聊天頁面所需的 AI Elements 元件。如提示選擇元件庫，請選 **Radix UI**，其餘選項保留預設值：

```bash npm2yarn
npx ai-elements@latest add prompt-input conversation message tool
```

:::note
`ai-elements` 指令會執行 `shadcn add`，從 AI Elements 元件登記庫取得元件。這個登記庫目前只發佈 Radix UI 元件；如把這些元件安裝到 Base UI 項目，便會出現 TypeScript 錯誤，詳見 [vercel/ai-elements#383](https://github.com/vercel/ai-elements/issues/383)。

只有項目沒有 `components.json` 時，才會出現選擇元件庫的提示。如已有這個檔案，請在執行指令前確認 `style` 選用的是 `new-york` 或 `radix-*` 一類的 Radix 樣式，而非 `base-*` 樣式。
:::

指令會把這些元件及其依賴項下載到 `@/components/ai-elements` 資料夾。

### 建立聊天路由 {/* #create-a-chat-route */}

建立 `src/app/api/chat/route.ts`：

```ts title="src/app/api/chat/route.ts"
import { handleChatStream } from '@mastra/ai-sdk'
import { toAISdkMessages } from '@mastra/ai-sdk/ui'
import { createUIMessageStreamResponse } from 'ai'
import { mastra } from '@/mastra'
import { NextResponse } from 'next/server'

const THREAD_ID = 'example-user-id'
const RESOURCE_ID = 'weather-chat'

export async function POST(req: Request) {
  const params = await req.json()
  const stream = await handleChatStream({
    mastra,
    agentId: 'weather-agent',
    version: 'v7',
    params: {
      ...params,
      memory: {
        ...params.memory,
        thread: THREAD_ID,
        resource: RESOURCE_ID,
      },
    },
  })
  return createUIMessageStreamResponse({ stream })
}

export async function GET() {
  const memory = await mastra.getAgentById('weather-agent').getMemory()
  let response = null

  try {
    response = await memory?.recall({
      threadId: THREAD_ID,
      resourceId: RESOURCE_ID,
    })
  } catch {
    console.log('No previous messages found.')
  }

  const uiMessages = toAISdkMessages(response?.messages || [], { version: 'v7' })

  return NextResponse.json(uiMessages)
}
```

`POST` 路由接收提示詞，再以 AI SDK 格式串流傳送 Agent 的回應。`GET` 路由從記憶中讀取過往訊息，讓客戶端重新載入時可在介面還原對話。

### 建立聊天頁面 {/* #create-a-chat-page */}

建立 `src/app/chat/page.tsx`：

```tsx title="src/app/chat/page.tsx"
'use client'

import '@/app/globals.css'
import { useEffect, useState } from 'react'
import { DefaultChatTransport, ToolUIPart } from 'ai'
import { useChat } from '@ai-sdk/react'

import {
  PromptInput,
  PromptInputBody,
  PromptInputTextarea,
} from '@/components/ai-elements/prompt-input'

import {
  Conversation,
  ConversationContent,
  ConversationScrollButton,
} from '@/components/ai-elements/conversation'

import { Message, MessageContent, MessageResponse } from '@/components/ai-elements/message'

import { Tool, ToolHeader, ToolContent, ToolInput, ToolOutput } from '@/components/ai-elements/tool'

function Chat() {
  const [input, setInput] = useState<string>('')

  const { messages, setMessages, sendMessage, status } = useChat({
    transport: new DefaultChatTransport({
      api: '/api/chat',
    }),
  })

  useEffect(() => {
    const fetchMessages = async () => {
      const res = await fetch('/api/chat')
      const data = await res.json()
      setMessages([...data])
    }
    fetchMessages()
  }, [setMessages])

  const handleSubmit = async () => {
    if (!input.trim()) return

    sendMessage({ text: input })
    setInput('')
  }

  return (
    <div className="relative size-full h-screen w-full p-6">
      <div className="flex h-full flex-col">
        <Conversation className="h-full">
          <ConversationContent>
            {messages.map(message => (
              <div key={message.id}>
                {message.parts?.map((part, i) => {
                  if (part.type === 'text') {
                    return (
                      <Message key={`${message.id}-${i}`} from={message.role}>
                        <MessageContent>
                          <MessageResponse>{part.text}</MessageResponse>
                        </MessageContent>
                      </Message>
                    )
                  }

                  if (part.type?.startsWith('tool-')) {
                    return (
                      <Tool key={`${message.id}-${i}`}>
                        <ToolHeader
                          type={(part as ToolUIPart).type}
                          state={(part as ToolUIPart).state || 'output-available'}
                          className="cursor-pointer"
                        />
                        <ToolContent>
                          <ToolInput input={(part as ToolUIPart).input || {}} />
                          <ToolOutput
                            output={(part as ToolUIPart).output}
                            errorText={(part as ToolUIPart).errorText}
                          />
                        </ToolContent>
                      </Tool>
                    )
                  }

                  return null
                })}
              </div>
            ))}
            <ConversationScrollButton />
          </ConversationContent>
        </Conversation>

        <PromptInput onSubmit={handleSubmit} className="mt-20">
          <PromptInputBody>
            <PromptInputTextarea
              onChange={e => setInput(e.target.value)}
              className="md:leading-10"
              value={input}
              placeholder="Type your message..."
              disabled={status !== 'ready'}
            />
          </PromptInputBody>
        </PromptInput>
      </div>
    </div>
  )
}

export default Chat
```

這個元件把 [`useChat()`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/use-chat) 連接到 `api/chat` 端點，將提示詞送到該端點，再分段接收串流回應。

回應文字由 [`<MessageResponse>`](https://ai-sdk.dev/elements/components/message#messageresponse-) 元件顯示；如有 Tool 呼叫，則由 [`<Tool>`](https://ai-sdk.dev/elements/components/tool) 元件顯示。

### 測試 Agent {/* #test-your-agent */}

1. 用 `npm run dev` 啟動 Next.js 應用程式。
2. 前往 [http://localhost:3000/chat](http://localhost:3000/chat) 開啟聊天頁面。
3. 試問一條有關天氣的問題。如 API 金鑰設定正確，便會收到回應。

## 公開 Mastra API {/* #expose-the-mastra-api */}

上述聊天路由使用 `@mastra/ai-sdk` 的 `handleChatStream`，經自訂的 `/api/chat` 端點串流傳送 AI SDK UI 回應。如要透過同一個 Next.js 部署公開整套 Mastra HTTP API，涵蓋 Agent、Tool、Workflow、記憶、自訂 API 路由、MCP 及 A2A，請將 `@mastra/next` [伺服器適配器](/docs/server/server-adapters) 掛載到配對所有餘下路徑的 catch-all 路由。

安裝適配器及其對等依賴項 Hono：

```bash npm2yarn
npm install @mastra/next@latest hono
```

建立 catch-all 路由，並匯出各 HTTP 方法的處理函數：

```typescript title="src/app/api/[...mastra]/route.ts"
import { mastra } from '@/mastra'
import { createNextRouteHandler } from '@mastra/next'

export const { GET, POST, PUT, DELETE, PATCH, OPTIONS, HEAD } = createNextRouteHandler({
  mastra,
})
```

`prefix` 預設為 `/api`，必須與 catch-all 路由的掛載路徑一致。例如，若把適配器掛載到 `src/app/api/mastra/[...mastra]/route.ts`，便要使用 `createNextRouteHandler({ mastra, prefix: '/api/mastra' })`。

啟動應用程式：

```bash npm2yarn
npm run dev
```

另開一個終端機，向查詢天氣的 Agent 提問，以驗證適配器：

```bash
curl -X POST http://localhost:3000/api/agents/weather-agent/generate -H "Content-Type: application/json" -d "{\"messages\":[{\"role\":\"user\",\"content\":\"What is the weather like in Seoul?\"}]}"
```

端點會傳回 Agent 的完整 JSON 回應。請保留 AI SDK UI 路由供串流聊天介面使用，再經 catch-all 路由公開整套 Mastra API。適配器的完整說明可參閱 [Next.js 適配器](/reference/server/next-adapter)參考文件。
