# Hono

本指南會示範如何使用 Mastra 和 Hono 建立可調用 Tool 的 AI Agent。透過 [Hono 伺服器適配器](/reference/server/hono-adapter)，你可以將 Agent 公開為 HTTP 端點，無需自行編寫路由或另外運行 Mastra 伺服器。

## 開始之前 {/* #before-you-begin */}

- 你需要一個由受支援的 [Model Provider](/models) 發出的 API 密鑰。如果沒有特定偏好，可使用 [OpenAI](/models/providers/openai)。
- 安裝 Node.js `v22.13.0` 或更新版本

## 建立新的 Hono 應用程式（可選） {/* #create-a-new-hono-app-optional */}

如果已有 Hono 應用程式，請跳至下一步。

執行以下指令以[建立新的 Hono 應用程式](https://hono.dev/docs/getting-started/basic)：

```bash npm2yarn
npm create hono@latest mastra-hono -- --template nodejs --install --pm npm
```

這會建立一個名為 `mastra-hono` 的項目，你可以改用任何名稱。

## 初始化 Mastra {/* #initialize-mastra */}

切換至 Hono 項目目錄：

```bash
cd mastra-hono
```

執行 [`mastra init`](/reference/cli/mastra#mastra-init)。出現提示時，選擇一個 Provider（例如 OpenAI），並輸入你的密鑰：

```bash npm2yarn
npx mastra@latest init
```

這會建立 `src/mastra` 資料夾，內含一個天氣 Agent 範例及以下檔案：

- `index.ts`：Mastra 設定，包括 Memory 設定
- `tools/weather-tool.ts`：用來取得指定地點天氣資訊的 Tool
- `agents/weather-agent.ts`：一個天氣 Agent，其 Prompt 會指示它使用該 Tool

稍後會將 `src/mastra/index.ts` 檔案傳給 Hono 伺服器適配器。

## 加入伺服器適配器 {/* #add-server-adapter */}

安裝 Hono 伺服器適配器套件：

```bash npm2yarn
npm install @mastra/hono@latest
```

開啟 Hono 的入口檔案 `src/index.ts`，加入所需的匯入和初始化程式碼：

```typescript title="src/index.ts" {3-8,10-11,13}
import { serve } from '@hono/node-server'
import { Hono } from 'hono'
import { type HonoBindings, type HonoVariables, MastraServer } from '@mastra/hono'
import { mastra } from './mastra/index.js'

const app = new Hono<{ Bindings: HonoBindings; Variables: HonoVariables }>()
const server = new MastraServer({ app, mastra })

await server.init()

app.get('/', c => {
  return c.text('Hello Hono!')
})

serve(
  {
    fetch: app.fetch,
    port: 3000,
  },
  info => {
    console.log(`Server is running on http://localhost:${info.port}`)
  },
)
```

使用現有的 Hono `app` 和根 ⁠`mastra` 實例初始化 ⁠`MastraServer`。調用 `⁠init()` 會註冊 Mastra 中介軟件，並公開所有可用的 Mastra 端點。

## 測試你的 Agent {/* #test-your-agent */}

預設情況下，Mastra 端點會加到 `/api` 子路徑下，並使用你的 Agent 或 Workflow ID。`mastra init` 建立的預設 `weather-agent` 可透過 `/api/agents/weather-agent` 存取。

啟動 Hono 伺服器：

```bash npm2yarn
npm run dev
```

在另一個終端視窗中，使用 `curl` 向天氣 Agent 查詢天氣：

```bash
curl -X POST http://localhost:3000/api/agents/weather-agent/generate -H "Content-Type: application/json" -d "{\"messages\":[{\"role\":\"user\",\"content\":\"What is the weather like in Seoul?\"}]}"
```
