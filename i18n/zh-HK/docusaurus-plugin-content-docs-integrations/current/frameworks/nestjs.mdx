# NestJS

在本指南中，你會用 Mastra 和 NestJS 建立一個可以調用 Tool 的 AI Agent。[NestJS 伺服器適配器](/reference/server/nestjs-adapter)透過 NestJS 模組註冊 Mastra 的 Agent 和 Workflow 路由，讓現有的 NestJS 應用程式處理這些路由。

## 開始之前 {/* #before-you-begin */}

* 準備由受支援的[模型 Provider](/models) 提供的 API 密鑰。如無特定偏好，可使用 [OpenAI](/models/providers/openai)。
* 安裝 Node.js `v22.13.0` 或以上版本。
* 使用 NestJS 的 Express 平台（`@nestjs/platform-express`）。

## 建立 NestJS 應用程式（可選） {/* #create-a-new-nestjs-app-optional */}

如果已有 NestJS 應用程式，可直接跳到下一步。

執行以下指令，建立 NestJS 應用程式：

```bash npm2yarn
npx @nestjs/cli new mastra-nest
```

這項指令會建立名為 `mastra-nest` 的項目，你亦可自訂名稱。

## 初始化 Mastra {/* #initialize-mastra */}

進入 NestJS 項目的目錄：

```bash
cd mastra-nest
```

執行 [`mastra init`](/reference/cli/mastra#mastra-init)。出現提示時，選擇一個 Provider（例如 OpenAI），然後輸入 API 密鑰：

```bash npm2yarn
npx mastra@latest init
```

這項指令會建立 `src/mastra` 資料夾，裏面有一個天氣查詢 Agent 範例和以下檔案：

* `index.ts`：Mastra 設定，包括記憶設定。
* `tools/weather-tool.ts`：用於查詢指定地點天氣的 Tool。
* `agents/weather-agent.ts`：天氣查詢 Agent，內含指示它使用該 Tool 的提示詞。

稍後註冊 NestJS 適配器時，會把 `src/mastra/index.ts` 匯出的 Mastra 實例傳入適配器。

## 按模組系統調整產生的檔案 {/* #update-the-generated-files-for-your-module-system */}

要在 NestJS 項目編譯 `mastra init` 產生的檔案，須按所用的模組系統作一項修改。請查看 `package.json` 的 `type` 欄位。NestJS CLI v12 建立的項目採用 ECMAScript 模組（ESM），並設有 `"type": "module"`。較早版本的 CLI 建立的則是 CommonJS 項目。

<Tabs>
  <TabItem value="esm" label="ESM">
    ESM 項目使用 `"moduleResolution": "nodenext"`，相對匯入路徑因此須包含檔案副檔名。請在產生的檔案中，為每條相對匯入路徑加上 `.js`，例如：

    ```typescript title="src/mastra/index.ts"
    import { weatherWorkflow } from './workflows/weather-workflow.js'
    import { weatherAgent } from './agents/weather-agent.js'
    ```

    ```typescript title="src/mastra/agents/weather-agent.ts"
    import { weatherTool } from '../tools/weather-tool.js'
    ```
  </TabItem>

  <TabItem value="commonjs" label="CommonJS">
    CommonJS 不支援頂層 `await`。開啟 `src/mastra/index.ts`，移除 `DuckDBStore` 的匯入和 `MastraCompositeStore` 的 `domains` 選項：

    ```typescript title="src/mastra/index.ts" oxfmt:false
    import { DuckDBStore } from '@mastra/duckdb'

    // ...

    domains: {
      observability: await new DuckDBStore().getStore('observability'),
    },
    ```

    移除後，可觀測性數據會儲存到預設的 LibSQL 儲存空間。
  </TabItem>
</Tabs>

## 新增伺服器適配器 {/* #add-server-adapter */}

安裝 NestJS 伺服器適配器套件：

```bash npm2yarn
npm install @mastra/nestjs@latest
```

開啟 `src/app.module.ts` 並註冊 `MastraModule`：

```typescript title="src/app.module.ts"
import { Module } from '@nestjs/common'
import { MastraModule } from '@mastra/nestjs'
import { mastra } from './mastra/index.js'

@Module({
  imports: [
    MastraModule.register({
      mastra,
    }),
  ],
})
export class AppModule {}
```

:::note

`MastraModule` 會註冊一個匹配所有路由的控制器（`@All('*')`）。如在應用程式的其他模組之前匯入，該控制器可能攔截與 Mastra 無關的路由並回傳 404。為免衝突，請最後才匯入 `MastraModule`，或將它掛載到專用路徑前綴下，例如 `/api/v1/mastra`。

:::

## 測試 Agent {/* #test-your-agent */}

Mastra 的端點預設設於 `/api` 子路徑下，並採用相應的 Agent 或 Workflow ID。你可以經 `/api/agents/weather-agent` 存取 `mastra init` 預設建立的 `weather-agent`。

啟動 NestJS 伺服器：

```bash npm2yarn
npm run start
```

在另一個終端視窗使用 `curl`，向天氣查詢 Agent 提問：

```bash
curl -X POST http://localhost:3000/api/agents/weather-agent/generate -H "Content-Type: application/json" -d "{\"messages\":[{\"role\":\"user\",\"content\":\"What is the weather like in Seoul?\"}]}"
```

## 在自己的服務中使用 Mastra {/* #use-mastra-in-your-own-services */}

這個模組匯出兩種方式，讓 NestJS 服務存取 Mastra，分別是 `MastraService` 封裝類別和 `MASTRA` 注入權杖。

### MastraService {/* #mastraservice */}

`MastraService` 是一個可注入的封裝類別，讓你更方便地執行常用操作：

```typescript title="src/agent.service.ts"
import { Injectable } from '@nestjs/common'
import { MastraService } from '@mastra/nestjs'

@Injectable()
export class AgentService {
  constructor(private readonly mastraService: MastraService) {}

  async chat(agentId: string, message: string) {
    const agent = this.mastraService.getAgent(agentId)
    return agent.generate({
      messages: [{ role: 'user', content: message }],
    })
  }

  async runWorkflow(workflowId: string, input: Record<string, unknown>) {
    const workflow = this.mastraService.getWorkflow(workflowId)
    return workflow.start({ inputData: input })
  }
}
```

`MastraService` 提供以下成員：

* `getMastra()`：回傳底層的 `Mastra` 實例。
* `getAgent(id)`：調用 `mastra.getAgent(id)` 的簡便方式。
* `getWorkflow(id)`：調用 `mastra.getWorkflow(id)` 的簡便方式。
* `getOptions()`：回傳模組設定。
* `isShuttingDown`：有序關閉程序一開始，值即為 `true`。

### MASTRA 注入權杖 {/* #mastra-token */}

如需直接使用 `Mastra` 實例，例如存取儲存空間、記憶或其他核心 API，可用 `MASTRA` 權杖注入該實例：

```typescript title="src/memory.service.ts"
import { Injectable, Inject } from '@nestjs/common'
import { MASTRA } from '@mastra/nestjs'
import type { Mastra } from '@mastra/core/mastra'

@Injectable()
export class MemoryService {
  constructor(@Inject(MASTRA) private readonly mastra: Mastra) {}

  async getThreadMessages(threadId: string) {
    const memory = this.mastra.getMemory()
    return memory?.getMessages({ threadId })
  }
}
```

兩種方式均使用由 `MastraModule` 註冊的同一個 `Mastra` 單例。
