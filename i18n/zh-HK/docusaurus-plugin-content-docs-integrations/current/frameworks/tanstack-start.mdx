# TanStack Start

在 TanStack Start 建立可呼叫 Tool 的 Mastra Agent，然後將 Mastra 伺服器掛載至萬用 API 路由。[伺服器轉接器](/docs/server/server-adapters)概覽說明共通概念，而 [TanStack Start 轉接器](/reference/server/tanstack-start-adapter)參考文件則介紹套件的 API。

## 開始之前 {/* #before-you-begin */}

- 你需要一個受支援的 [Model Provider](/models) 所提供的 API 金鑰。如果沒有偏好的 Provider，可使用 [OpenAI](/models/providers/openai)。
- 安裝 Node.js `v22.13.0` 或更新版本

## 建立新的 TanStack Start 應用程式（選用） {/* #create-a-new-tanstack-start-app-optional */}

你需要一個正在執行且包含 `src/routes` 目錄的 TanStack Start 應用程式。如果尚未建立，請按照 [TanStack Start 快速入門指南](https://tanstack.com/start/latest/docs/framework/react/getting-started)建立並執行應用程式，然後再繼續。

## 初始化 Mastra {/* #initialize-mastra */}

在 TanStack Start 項目目錄執行 [`mastra init`](/reference/cli/mastra#mastra-init)。出現提示時，選擇一個 Provider（例如 OpenAI），然後輸入你的 API 金鑰：

```bash npm2yarn
npx mastra@latest init
```

這個指令會建立 `src/mastra` 目錄，其中包含一個天氣 Agent 範例和以下檔案：

- `index.ts`：Mastra 設定，包括 Memory 設定
- `tools/weather-tool.ts`：用於擷取指定地點天氣資訊的 Tool
- `agents/weather-agent.ts`：內含指示其使用該 Tool 的指令的天氣 Agent

你會將 `src/mastra/index.ts` 匯出的 Mastra 實例傳入伺服器轉接器。

## 設定 Vite 和 Nitro {/* #configure-vite-and-nitro */}

更新 `vite.config.ts`，讓 Vite 和 Nitro 在各自的處理流程中略過 DuckDB 和 `@mastra/core` 僅限 Node.js 使用的依賴套件：

```diff title="vite.config.ts"
 const config = defineConfig({
   resolve: { tsconfigPaths: true },
+  optimizeDeps: {
+    exclude: ['@mastra/duckdb', 'execa'],
+  },
   plugins: [
     devtools(),
-    nitro({ rollupConfig: { external: [/^@sentry\//] } }),
+    nitro({
+      rollupConfig: {
+        external: [/^@sentry\//, /^@duckdb\//],
+      },
+    }),
```

`optimizeDeps.exclude` 設定可防止 Vite 的開發環境最佳化工具將 DuckDB 的原生 `.node` 二進位檔案當作 JavaScript 開啟。排除 `execa` 可防止最佳化工具預先打包這個僅供伺服器使用的依賴套件，`@mastra/core` 依靠它執行本機程序。它間接依賴的 `npm-run-path` 和 `unicorn-magic` 套件使用僅限 Node.js 的條件式匯出，最佳化工具在為瀏覽器建置時無法解析這些匯出。將 `/^@duckdb\//` 加入 Nitro 的 `rollupConfig.external`，可將 DuckDB 的原生 Node.js 套件排除於正式環境的打包結果之外，讓 Node.js 在執行時載入這些套件。

這些變更只需在 `vite.config.ts` 中進行，應用程式及 Mastra 的原始檔案均無需修改。

## 加入伺服器轉接器 {/* #add-the-server-adapter */}

安裝 TanStack Start 伺服器轉接器及其對等依賴套件 Hono：

```bash npm2yarn
npm install @mastra/tanstack-start@latest hono
```

建立一條 splat 路由，將所有支援的 HTTP 方法交由轉接器處理：

```typescript title="src/routes/api/$.ts"
import { createStartRouteHandler } from '@mastra/tanstack-start'
import { createFileRoute } from '@tanstack/react-router'
import { mastra } from '../../mastra'

export const Route = createFileRoute('/api/$')({
  server: {
    handlers: createStartRouteHandler({ mastra }),
  },
})
```

`prefix` 選項預設為 `/api`，並且必須與 splat 路由的掛載路徑一致。例如，將轉接器掛載至 `src/routes/api/mastra/$.ts` 時，請使用 `createStartRouteHandler({ mastra, prefix: '/api/mastra' })`。

轉接器會提供 Mastra 的 REST 和串流端點、自訂 API 路由、MCP 端點和 A2A 端點。A2A 任務使用記憶體內的任務儲存。

## 測試 Agent {/* #test-your-agent */}

啟動你的 TanStack Start 應用程式：

```bash npm2yarn
npm run dev
```

在另一個終端機視窗中，使用 `curl` 向天氣 Agent 提問：

```bash
curl -X POST http://localhost:3000/api/agents/weather-agent/generate -H "Content-Type: application/json" -d "{\"messages\":[{\"role\":\"user\",\"content\":\"What is the weather like in Seoul?\"}]}"
```

端點會以 JSON 格式傳回 Agent 的完整回應。
