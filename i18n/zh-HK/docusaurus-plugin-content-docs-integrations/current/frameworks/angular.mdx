# Angular

用 Mastra 建立一個可調用 Tool 的 AI Agent，再由 Angular 經 Mastra 的獨立伺服器調用這個 Agent。

你會透過 [AI SDK UI](https://ai-sdk.dev/docs/ai-sdk-ui/overview) 及其 [Angular 綁定](https://ai-sdk.dev/docs/getting-started/angular)，把回應以串流方式傳送至聊天介面。

## 開始之前 {/* #before-you-begin */}

* 你需要向受支援的[模型 Provider](/models/) 取得 API 密鑰。如沒有特定偏好，可使用 [OpenAI](/models/providers/openai)。
* 安裝 Angular 22 支援的 Node.js 版本。22.x 系列由 `v22.22.3` 起受支援，24.x 系列由 `v24.15.0` 起受支援，26.x 系列則由 `v26.0.0` 起受支援。

## 建立新的 Angular 應用程式（可選） {/* #create-a-new-angular-app-optional */}

如已有 Angular 應用程式，可以跳到下一步。

執行以下指令，[建立新的 Angular 應用程式](https://angular.dev/cli/new)：

```bash npm2yarn
npm create @angular@latest mastra-angular -- --defaults --ssr=false
```

這個指令會建立名為 `mastra-angular` 的項目，並在客戶端渲染頁面。你可以自訂項目名稱。

進入項目目錄：

```bash
cd mastra-angular
```

## 初始化 Mastra {/* #initialize-mastra */}

執行 [`mastra init`](/reference/cli/mastra#mastra-init)，按提示選擇 Provider（例如 OpenAI）並輸入 API 密鑰：

```bash npm2yarn
npx mastra@latest init
```

指令會建立 `src/mastra` 資料夾，當中包含天氣 Agent 範例及以下檔案：

* `index.ts`：Mastra 設定，包括記憶功能的設定
* `tools/weather-tool.ts`：查詢指定地點天氣的 Tool
* `agents/weather-agent.ts`：天氣 Agent，其提示詞會指示它使用這個 Tool

在接下來的步驟中，聊天介面會調用 `weather-agent.ts` 內定義的 Agent。

## 將 Mastra 排除於 Angular 構建之外 {/* #exclude-mastra-from-the-angular-build */}

Angular 預設的 `tsconfig.app.json` 會編譯 `src/` 下的所有檔案，包括 `src/mastra` 內的伺服器端程式碼。預設的 `tsconfig.json` 亦會啟用 `noPropertyAccessFromIndexSignature`，令 `src/mastra/index.ts` 內自動產生的 `process.env` 存取程式碼導致構建失敗。

把 `src/mastra/**` 加入 `tsconfig.app.json` 的 `exclude` 清單，便可在構建瀏覽器端應用程式時排除伺服器端程式碼：

```json title="tsconfig.app.json" {7}
{
  "extends": "./tsconfig.json",
  "compilerOptions": {
    "types": []
  },
  "include": ["src/**/*.ts"],
  "exclude": ["src/**/*.spec.ts", "src/mastra/**"]
}
```

## 安裝 AI SDK UI {/* #install-ai-sdk-ui */}

安裝 AI SDK UI，並一併安裝 Mastra 配接器及 Angular 綁定：

```bash npm2yarn
npm install @mastra/ai-sdk@latest @ai-sdk/angular ai
```

## 建立聊天路由 {/* #create-a-chat-route */}

開啟 `src/mastra/index.ts`，在設定中加入 [chatRoute()](/reference/ai-sdk/chat-route)。這會建立一條 API 路由，供 Angular 前端取得與 AI SDK 相容的聊天回應。下一步會透過 `Chat` 類別使用這條路由。

```ts title="src/mastra/index.ts"
import { Mastra } from '@mastra/core/mastra'
// Existing imports...
import { chatRoute } from '@mastra/ai-sdk'

export const mastra = new Mastra({
  // Existing config...
  server: {
    apiRoutes: [
      chatRoute({
        path: '/chat/:agentId',
        version: 'v7',
      }),
    ],
  },
})
```

## 新增聊天介面 {/* #add-the-chat-ui */}

用以下元件取代 `src/app/app.ts` 的內容：

```ts title="src/app/app.ts"
import { JsonPipe } from '@angular/common'
import { Component, signal } from '@angular/core'
import { Chat } from '@ai-sdk/angular'
import { DefaultChatTransport } from 'ai'

@Component({
  selector: 'app-root',
  imports: [JsonPipe],
  template: `
    <main class="chat">
      @for (message of chat.messages; track message.id) {
        <article class="message" [class.user]="message.role === 'user'">
          <strong>{{ message.role === 'user' ? 'You' : 'Assistant' }}</strong>
          @for (part of message.parts; track $index) {
            @if (part.type === 'text') {
              <p class="text">{{ part.text }}</p>
            } @else if (part.type.startsWith('tool-')) {
              <details class="tool">
                <summary>{{ part.type.replace('tool-', '') }}</summary>
                <pre>{{ part | json }}</pre>
              </details>
            }
          }
        </article>
      }

      @if (chat.status === 'submitted') {
        <p class="status">Waiting for a response...</p>
      }

      @if (chat.error; as error) {
        <p class="error" role="alert">{{ error.message }}</p>
      }

      <form (submit)="sendMessage($event)">
        <label for="message">Your message</label>
        <textarea
          id="message"
          #messageInput
          rows="2"
          [value]="input()"
          (input)="input.set(messageInput.value)"
          placeholder="Ask about the weather..."
        ></textarea>
        <button
          type="submit"
          [disabled]="chat.status === 'submitted' || chat.status === 'streaming'"
        >
          Send
        </button>
        @if (chat.status === 'submitted' || chat.status === 'streaming') {
          <button type="button" (click)="chat.stop()">Stop</button>
        }
      </form>
    </main>
  `,
  styles: `
    .chat {
      display: flex;
      flex-direction: column;
      gap: 1rem;
      max-width: 48rem;
      margin: 0 auto;
      padding: 1.5rem;
    }

    .message {
      display: flex;
      flex-direction: column;
      gap: 0.5rem;
      padding: 0.75rem 1rem;
      border: 1px solid #d4d4d8;
      border-radius: 0.5rem;
    }

    .message.user {
      background: #f4f4f5;
    }

    .text {
      margin: 0;
      white-space: pre-wrap;
    }

    .tool pre {
      overflow-x: auto;
      margin: 0.5rem 0 0;
    }

    .error {
      color: #b91c1c;
    }

    form {
      display: flex;
      flex-direction: column;
      gap: 0.5rem;
    }

    button {
      align-self: flex-start;
      padding: 0.5rem 1rem;
    }
  `,
})
export class App {
  readonly chat = new Chat({
    transport: new DefaultChatTransport({
      api: 'http://localhost:4111/chat/weather-agent',
    }),
  })

  readonly input = signal('')

  sendMessage(event: Event) {
    event.preventDefault()

    const text = this.input().trim()
    if (!text || this.chat.status === 'submitted' || this.chat.status === 'streaming') {
      return
    }

    this.chat.sendMessage({ text })
    this.input.set('')
  }
}
```

這個元件會建立 [`Chat`](https://ai-sdk.dev/docs/getting-started/angular) 實例，並將傳輸目標指向 `chat/weather-agent` 端點。`Chat` 類別會將提示詞送到該端點，並把回應以串流方式寫入 `chat.messages`。

元件收到文字片段後便會顯示內容，並在可摺疊的 `<details>` 元素中顯示 Tool 調用。狀態及錯誤訊息分別使用響應式屬性 `chat.status` 和 `chat.error`。按下 **Stop**（停止）可取消目前的回應。

:::note
較舊的 Angular 項目可能會以 `app.component.ts` 作為根元件檔案名稱，以 `AppComponent` 作為類別名稱。如沿用現有項目，請保留原有的檔案及類別名稱，讓 `src/main.ts` 內的匯入繼續有效。
:::

## 測試 Agent {/* #test-your-agent */}

要在聊天介面測試 Agent，請同時運行 Mastra 伺服器及 Angular 開發伺服器。

1. 啟動 Mastra 開發伺服器：

   ```bash npm2yarn
   npx mastra dev
   ```
2. 另開一個終端機視窗，啟動 Angular 開發伺服器：

   ```bash npm2yarn
   npm start
   ```
3. 到 [http://localhost:4200](http://localhost:4200) 開啟應用程式。
4. 試問天氣如何。如 API 密鑰設定正確，你便會收到回應。
