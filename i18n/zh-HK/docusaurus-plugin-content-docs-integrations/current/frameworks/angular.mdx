# 角

使用 Mastra 建立一個Tool呼叫 AI Agent，然後透過從 Mastra 的獨立伺服器呼叫該Agent將其連接到 Angular。

你會使用[AI SDK UI](https://ai-sdk.dev/docs/ai-sdk-ui/overview) and its [角度綁定](https://ai-sdk.dev/docs/getting-started/angular)將回應串流傳輸到聊天介面。

## 開始之前 {/* #before-you-begin */}

* 您需要來自受支援的 API 金鑰[model provider](/models/). If you don't have a preference, use [OpenAI](/models/providers/openai).
* 安裝 Node.js`v22.22.3` or later, or `v24.15.0` or later if you're on the 24.x line, or `v26.0.0` or later if you're on the 26.x line. These are the ranges Angular 22 supports.

## 建立一個新的 Angular 應用程式（可選） {/* #create-a-new-angular-app-optional */}

如果您已有 Angular 應用程序，請跳至下一步。

運行以下命令[create a new Angular app](https://angular.dev/cli/new):

```bash npm2yarn
npm create @angular@latest mastra-angular -- --defaults --ssr=false
```

這將創建一個名為的客戶端渲染項目`mastra-angular`, but you can replace it with any name you want.

導航到您的專案目錄：

```bash
cd mastra-angular
```

## 初始化瑪斯特拉 {/* #initialize-mastra */}

跑步[`mastra init`](/reference/cli/mastra#mastra-init). When prompted, choose a provider (e.g. OpenAI) and enter your key:

```bash npm2yarn
npx mastra@latest init
```

這創建了一個`src/mastra` folder with an example weather agent and the following files:

* `index.ts`：Mastra 配置，包括內存
* `tools/weather-tool.ts`：取得給定位置天氣的Tool
* `agents/weather-agent.ts`

你會打電話`weather-agent.ts` from your chat UI in the next steps.

## 從 Angular 建置中排除 Mastra {/* #exclude-mastra-from-the-angular-build */}

Angular 的預設值`tsconfig.app.json` compiles every file under `src/`, including the `src/mastra` server code. Its default `tsconfig.json` also enables `noPropertyAccessFromIndexSignature`, which makes the generated `process.env` access in `src/mastra/index.ts` fail the build.

透過新增以下內容，將伺服器程式碼排除在瀏覽器建置之外`src/mastra/**` to the `exclude` list in `tsconfig.app.json`:

```json title="tsconfig.app.json" {7}
{
  "extends": "./tsconfig.json",
  "compilerOptions": {
    "types": []
  },
  "include": ["src/**/*.ts"],
  "exclude": ["src/**/*.spec.ts", "src/mastra/**"]
}
```

## 安裝AI SDK UI {/* #install-ai-sdk-ui */}

安裝 AI SDK UI 以及 Mastra 轉接器和 Angular 綁定：

```bash npm2yarn
npm install @mastra/ai-sdk@latest @ai-sdk/angular ai
```

## 建立聊天路徑 {/* #create-a-chat-route */}

打開`src/mastra/index.ts` and add a [chatRoute()](/reference/ai-sdk/chat-route) to your config. This creates an API route your Angular frontend can call for AI SDK-compatible chat responses, which you'll use with the `Chat` class next.

```ts title="src/mastra/index.ts"
import { Mastra } from '@mastra/core/mastra'
// Existing imports...
import { chatRoute } from '@mastra/ai-sdk'

export const mastra = new Mastra({
  // Existing config...
  server: {
    apiRoutes: [
      chatRoute({
        path: '/chat/:agentId',
        version: 'v7',
      }),
    ],
  },
})
```

## 新增聊天介面 {/* #add-the-chat-ui */}

代替`src/app/app.ts` with the following component:

```ts title="src/app/app.ts"
import { JsonPipe } from '@angular/common'
import { Component, signal } from '@angular/core'
import { Chat } from '@ai-sdk/angular'
import { DefaultChatTransport } from 'ai'

@Component({
  selector: 'app-root',
  imports: [JsonPipe],
  template: `
    <main class="chat">
      @for (message of chat.messages; track message.id) {
        <article class="message" [class.user]="message.role === 'user'">
          <strong>{{ message.role === 'user' ? 'You' : 'Assistant' }}</strong>
          @for (part of message.parts; track $index) {
            @if (part.type === 'text') {
              <p class="text">{{ part.text }}</p>
            } @else if (part.type.startsWith('tool-')) {
              <details class="tool">
                <summary>{{ part.type.replace('tool-', '') }}</summary>
                <pre>{{ part | json }}</pre>
              </details>
            }
          }
        </article>
      }

      @if (chat.status === 'submitted') {
        <p class="status">Waiting for a response...</p>
      }

      @if (chat.error; as error) {
        <p class="error" role="alert">{{ error.message }}</p>
      }

      <form (submit)="sendMessage($event)">
        <label for="message">Your message</label>
        <textarea
          id="message"
          #messageInput
          rows="2"
          [value]="input()"
          (input)="input.set(messageInput.value)"
          placeholder="Ask about the weather..."
        ></textarea>
        <button
          type="submit"
          [disabled]="chat.status === 'submitted' || chat.status === 'streaming'"
        >
          Send
        </button>
        @if (chat.status === 'submitted' || chat.status === 'streaming') {
          <button type="button" (click)="chat.stop()">Stop</button>
        }
      </form>
    </main>
  `,
  styles: `
    .chat {
      display: flex;
      flex-direction: column;
      gap: 1rem;
      max-width: 48rem;
      margin: 0 auto;
      padding: 1.5rem;
    }

    .message {
      display: flex;
      flex-direction: column;
      gap: 0.5rem;
      padding: 0.75rem 1rem;
      border: 1px solid #d4d4d8;
      border-radius: 0.5rem;
    }

    .message.user {
      background: #f4f4f5;
    }

    .text {
      margin: 0;
      white-space: pre-wrap;
    }

    .tool pre {
      overflow-x: auto;
      margin: 0.5rem 0 0;
    }

    .error {
      color: #b91c1c;
    }

    form {
      display: flex;
      flex-direction: column;
      gap: 0.5rem;
    }

    button {
      align-self: flex-start;
      padding: 0.5rem 1rem;
    }
  `,
})
export class App {
  readonly chat = new Chat({
    transport: new DefaultChatTransport({
      api: 'http://localhost:4111/chat/weather-agent',
    }),
  })

  readonly input = signal('')

  sendMessage(event: Event) {
    event.preventDefault()

    const text = this.input().trim()
    if (!text || this.chat.status === 'submitted' || this.chat.status === 'streaming') {
      return
    }

    this.chat.sendMessage({ text })
    this.input.set('')
  }
}
```

該組件創建一個[`Chat`](https://ai-sdk.dev/docs/getting-started/angular) instance and points its transport at the `chat/weather-agent` endpoint. The `Chat` class sends prompts there and streams the response into `chat.messages`.

它會在文字部分到達時呈現它們，並以可折疊的方式顯示Tool調用`<details>` element. The status and error messages use the reactive `chat.status` and `chat.error` properties, and the **Stop** option cancels the active response.

:::注意
較舊的 Angular 專案可能會命名根元件文件`app.component.ts` and its class `AppComponent`. If you're using an existing project, keep its file and class names so the imports in `src/main.ts` continue to work.
:::

## 測試你的Agent {/* #test-your-agent */}

若要使用聊天介面測試Agent，請執行 Mastra 伺服器和 Angular 開發伺服器。

1. 啟動 Mastra 開發伺服器：

   ```bash npm2yarn
   npx mastra dev
   ```
2. 在單獨的終端機視窗中，啟動 Angular 開發伺服器：

   ```bash npm2yarn
   npm start
   ```
3. 打開您的申請表[http://localhost:4200](http://localhost:4200)
4. 試著詢問天氣。如果您的 API 金鑰設定正確，您將收到回應
