# React + Vite

跟隨本指南，你會先以 Mastra 建立可調用 Tool 的 AI Agent，再經 Mastra 的獨立伺服器直接調用該 Agent，將它接駁至 React 前端。

這個聊天介面會用到 [AI SDK UI](https://ai-sdk.dev/docs/ai-sdk-ui/overview) 和 [AI Elements](https://ai-sdk.dev/elements)，讓介面兼具視覺效果與互動功能。

## 開始前的準備 {/* #before-you-begin */}

* 你需要一個由受支援的[模型 Provider](/models) 提供的 API 密鑰。如未選定 Provider，可使用 [OpenAI](/models/providers/openai)。
* 安裝 Node.js `v22.13.0` 或以上版本。

## 建立新的 React + Vite 應用程式（可選） {/* #create-a-new-react--vite-app-optional */}

如果現有的 React + Vite 應用程式已採用 Tailwind，可直接前往下一步。

### 產生項目骨架 {/* #project-scaffold */}

執行以下指令，[建立新的 React + Vite 應用程式](https://vite.dev/guide/#scaffolding-your-first-vite-project)。

```bash npm2yarn
npm create vite@latest mastra-react -- --template react-ts
```

指令會建立名為 `mastra-react` 的項目，你可以按需要更改名稱。

進入項目目錄。

```bash
cd mastra-react
```

### Tailwind {/* #tailwind */}

然後安裝 Tailwind。

```bash npm2yarn
npm install tailwindcss @tailwindcss/vite
```

配置 Vite 插件。

```typescript title="vite.config.ts" {3-4,7-12}
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import path from 'path'
import tailwindcss from '@tailwindcss/vite'

export default defineConfig({
  plugins: [react(), tailwindcss()],
  resolve: {
    alias: {
      '@': path.resolve(__dirname, './src'),
    },
  },
})
```

以以下程式碼取代 `src/index.css` 的全部內容。

```css title="src/index.css"
@import 'tailwindcss';
```

將以下 `compilerOptions` 設定加入 `tsconfig.json`。

```jsonc title="tsconfig.json"
{
  // ...
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"],
    },
  },
}
```

修改 `tsconfig.app.json`，讓應用程式可以解析路徑別名。

```jsonc title="tsconfig.app.json"
{
  "compilerOptions": {
    // ...
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"],
    },
    // ...
  },
}
```

## 初始化 Mastra {/* #initialize-mastra */}

執行 [`mastra init`](/reference/cli/mastra#mastra-init)。收到提示後，選擇 Provider（例如 OpenAI），並輸入 API 密鑰。

```bash npm2yarn
npx mastra@latest init
```

指令會建立 `src/mastra` 資料夾，當中有一個天氣查詢 Agent 範例及以下檔案。

* `index.ts` 包含 Mastra 的配置，包括記憶功能的設定。
* `tools/weather-tool.ts` 定義用來擷取指定地點天氣資料的 Tool。
* `agents/weather-agent.ts` 定義天氣查詢 Agent，並以提示詞指示它使用這個 Tool。

在接下來的步驟，你會由聊天介面調用 `weather-agent.ts` 所定義的 Agent。

## 安裝 AI SDK UI 和 AI Elements {/* #install-ai-sdk-ui--ai-elements */}

同時安裝 AI SDK UI 和 Mastra 轉接套件。

```bash npm2yarn
npm install @mastra/ai-sdk@latest @ai-sdk/react ai
```

然後初始化 AI Elements。如系統提示選擇組件庫，請選 **Radix UI**，其餘設定可保留預設值。

```bash npm2yarn
npx ai-elements@latest
```

:::note
`ai-elements` 指令會執行 `shadcn add`，從 AI Elements 登錄庫安裝組件。該登錄庫現時只發佈 Radix UI 組件。在 Base UI 項目安裝這些組件會引致 TypeScript 錯誤，相關進度見 [vercel/ai-elements#383](https://github.com/vercel/ai-elements/issues/383)。

只有項目未有 `components.json` 時，系統才會提示選擇組件庫。如已有這個檔案，請在執行指令前檢查 `style`，確認它採用 Radix 選項（例如 `new-york` 或 `radix-*` 樣式），並排除 `base-*` 樣式。
:::

執行指令後，整套 AI Elements UI 組件庫會下載至 `@/components/ai-elements` 資料夾。

## 建立聊天路由 {/* #create-a-chat-route */}

開啟 `src/mastra/index.ts`，在配置內加入 [chatRoute()](/reference/ai-sdk/chat-route)。這條 API 路由會提供與 AI SDK 兼容的聊天回應，稍後 React 前端會用 useChat() 調用這條路由。

```ts title="src/mastra/index.ts"
import { Mastra } from '@mastra/core/mastra'
// Existing imports...
import { chatRoute } from '@mastra/ai-sdk'

export const mastra = new Mastra({
  // Existing config...
  server: {
    apiRoutes: [
      chatRoute({
        path: '/chat/:agentId',
      }),
    ],
  },
})
```

## 新增聊天介面 {/* #add-the-chat-ui */}

以以下程式碼取代 `src/App.tsx` 的內容，建立聊天介面。

```tsx title="src/App.tsx"
import * as React from 'react'
import { DefaultChatTransport, type ToolUIPart } from 'ai'
import { useChat } from '@ai-sdk/react'

import {
  PromptInput,
  PromptInputBody,
  PromptInputTextarea,
} from '@/components/ai-elements/prompt-input'

import {
  Conversation,
  ConversationContent,
  ConversationScrollButton,
} from '@/components/ai-elements/conversation'

import { Message, MessageContent, MessageResponse } from '@/components/ai-elements/message'

import { Tool, ToolHeader, ToolContent, ToolInput, ToolOutput } from '@/components/ai-elements/tool'

export default function App() {
  const [input, setInput] = React.useState<string>('')

  const { messages, sendMessage, status } = useChat({
    transport: new DefaultChatTransport({
      api: 'http://localhost:4111/chat/weather-agent',
    }),
  })

  const handleSubmit = async () => {
    if (!input.trim()) return

    sendMessage({ text: input })
    setInput('')
  }

  return (
    <div className="relative mx-auto size-full h-screen max-w-4xl p-6">
      <div className="flex h-full flex-col">
        <Conversation className="h-full">
          <ConversationContent>
            {messages.map(message => (
              <div key={message.id}>
                {message.parts?.map((part, i) => {
                  if (part.type === 'text') {
                    return (
                      <Message key={`${message.id}-${i}`} from={message.role}>
                        <MessageContent>
                          <MessageResponse>{part.text}</MessageResponse>
                        </MessageContent>
                      </Message>
                    )
                  }

                  if (part.type?.startsWith('tool-')) {
                    return (
                      <Tool key={`${message.id}-${i}`}>
                        <ToolHeader
                          type={(part as ToolUIPart).type}
                          state={(part as ToolUIPart).state || 'output-available'}
                          className="cursor-pointer"
                        />
                        <ToolContent>
                          <ToolInput input={(part as ToolUIPart).input || {}} />
                          <ToolOutput
                            output={(part as ToolUIPart).output}
                            errorText={(part as ToolUIPart).errorText}
                          />
                        </ToolContent>
                      </Tool>
                    )
                  }

                  return null
                })}
              </div>
            ))}
            <ConversationScrollButton />
          </ConversationContent>
        </Conversation>
        <PromptInput onSubmit={handleSubmit} className="mt-20">
          <PromptInputBody>
            <PromptInputTextarea
              onChange={e => setInput(e.target.value)}
              className="md:leading-10"
              value={input}
              placeholder="Ask about the weather..."
              disabled={status !== 'ready'}
            />
          </PromptInputBody>
        </PromptInput>
      </div>
    </div>
  )
}
```

這個組件利用 [`useChat()`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/use-chat) 將提示詞傳送至 `chat/weather-agent` 端點，並透過串流分段接收回應。

它會以 [`<MessageResponse>`](https://ai-sdk.dev/elements/components/message#messageresponse-) 組件顯示回應文字，並以 [`<Tool>`](https://ai-sdk.dev/elements/components/tool) 組件顯示任何 Tool 調用。

## 測試 Agent {/* #test-your-agent */}

要在聊天介面測試 Agent，你需要同時啟動 Mastra 伺服器及 Vite 開發伺服器。

1. 啟動 Mastra 開發伺服器。

   ```bash npm2yarn
   npx mastra dev
   ```
2. 在另一個終端機視窗啟動 Vite 開發伺服器。

   ```bash npm2yarn
   npm run dev
   ```
3. 瀏覽 [http://localhost:5173](http://localhost:5173)，開啟應用程式。
4. 試問一條關於天氣的問題。只要 API 密鑰配置正確，你便會收到回應。
