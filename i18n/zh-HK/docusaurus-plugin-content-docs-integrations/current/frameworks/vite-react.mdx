# 反應 + 投票

在本指南中，您將使用 Mastra 建立一個Tool呼叫 AI Agent，然後透過直接從 Mastra 的獨立伺服器呼叫該Agent將其連接到 React。

你會使用[AI SDK UI](https://ai-sdk.dev/docs/ai-sdk-ui/overview) and [人工智慧元素](https://ai-sdk.dev/elements)創造優美的互動式聊天體驗。

## 開始之前 {/* #before-you-begin */}

* 您需要來自受支援的 API 金鑰[model provider](/models). If you don't have a preference, use [OpenAI](/models/providers/openai).
* 安裝 Node.js`v22.13.0` or later

## 建立一個新的 React + Vite 應用程式（可選） {/* #create-a-new-react--vite-app-optional */}

如果您已經有一個使用 Tailwind 的 React + Vite 應用程序，請跳到下一步。

### 工程鷹架 {/* #project-scaffold */}

運行以下命令[create a new React + Vite app](https://vite.dev/guide/#scaffolding-your-first-vite-project):

```bash npm2yarn
npm create vite@latest mastra-react -- --template react-ts
```

這將建立一個名為`mastra-react`, but you can replace it with any name you want.

導航到您的專案目錄：

```bash
cd mastra-react
```

### 順風 {/* #tailwind */}

接下來，安裝 Tailwind：

```bash npm2yarn
npm install tailwindcss @tailwindcss/vite
```

配置Vite插件：

```typescript title="vite.config.ts" {3-4,7-12}
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import path from 'path'
import tailwindcss from '@tailwindcss/vite'

export default defineConfig({
  plugins: [react(), tailwindcss()],
  resolve: {
    alias: {
      '@': path.resolve(__dirname, './src'),
    },
  },
})
```

替換所有內容`src/index.css` with the following:

```css title="src/index.css"
@import 'tailwindcss';
```

添加這些`compilerOptions` to `tsconfig.json`:

```jsonc title="tsconfig.json"
{
  // ...
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"],
    },
  },
}
```

編輯`tsconfig.app.json` to resolve paths:

```jsonc title="tsconfig.app.json"
{
  "compilerOptions": {
    // ...
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"],
    },
    // ...
  },
}
```

## 初始化瑪斯特拉 {/* #initialize-mastra */}

跑步[`mastra init`](/reference/cli/mastra#mastra-init). When prompted, choose a provider (e.g. OpenAI) and enter your key:

```bash npm2yarn
npx mastra@latest init
```

這創建了一個`src/mastra` folder with an example weather agent and the following files:

* `index.ts`：Mastra 配置，包括內存
* `tools/weather-tool.ts`：取得給定位置天氣的Tool
* `agents/weather-agent.ts`

你會打電話`weather-agent.ts` from your chat UI in the next steps.

## 安裝 AI SDK UI 和 AI 元素 {/* #install-ai-sdk-ui--ai-elements */}

安裝 AI SDK UI 以及 Mastra 轉接器：

```bash npm2yarn
npm install @mastra/ai-sdk@latest @ai-sdk/react ai
```

接下來，初始化 AI 元素。當提示選擇元件庫時，選擇**Radix UI**, then accept the defaults for the remaining prompts:

```bash npm2yarn
npx ai-elements@latest
```

:::注意
的`ai-elements` command runs `shadcn add` against the AI Elements registry, which currently publishes Radix UI components only. Installing them into a Base UI project produces TypeScript errors, tracked in [vercel/ai-elements#383](https://github.com/vercel/ai-elements/issues/383).

只有當你的專案沒有元件庫時才會出現元件庫提示`components.json`. If you already have one, check that its `style` is a Radix option, such as `new-york` or a `radix-*` style, and not a `base-*` style, before running the command.
:::

這會將整個 AI Elements UI 元件庫下載到`@/components/ai-elements` folder.

## 建立聊天路徑 {/* #create-a-chat-route */}

打開 ⁠`src/mastra/index.ts` and add a [⁠chatRoute()](/reference/ai-sdk/chat-route) to your config. This creates an API route your React frontend can call for AI SDK-compatible chat responses, which you’ll use with ⁠useChat() next.

```ts title="src/mastra/index.ts"
import { Mastra } from '@mastra/core/mastra'
// Existing imports...
import { chatRoute } from '@mastra/ai-sdk'

export const mastra = new Mastra({
  // Existing config...
  server: {
    apiRoutes: [
      chatRoute({
        path: '/chat/:agentId',
      }),
    ],
  },
})
```

## 新增聊天介面 {/* #add-the-chat-ui */}

更換`src/App.tsx` file to create a chat interface:

```tsx title="src/App.tsx"
import * as React from 'react'
import { DefaultChatTransport, type ToolUIPart } from 'ai'
import { useChat } from '@ai-sdk/react'

import {
  PromptInput,
  PromptInputBody,
  PromptInputTextarea,
} from '@/components/ai-elements/prompt-input'

import {
  Conversation,
  ConversationContent,
  ConversationScrollButton,
} from '@/components/ai-elements/conversation'

import { Message, MessageContent, MessageResponse } from '@/components/ai-elements/message'

import { Tool, ToolHeader, ToolContent, ToolInput, ToolOutput } from '@/components/ai-elements/tool'

export default function App() {
  const [input, setInput] = React.useState<string>('')

  const { messages, sendMessage, status } = useChat({
    transport: new DefaultChatTransport({
      api: 'http://localhost:4111/chat/weather-agent',
    }),
  })

  const handleSubmit = async () => {
    if (!input.trim()) return

    sendMessage({ text: input })
    setInput('')
  }

  return (
    <div className="relative mx-auto size-full h-screen max-w-4xl p-6">
      <div className="flex h-full flex-col">
        <Conversation className="h-full">
          <ConversationContent>
            {messages.map(message => (
              <div key={message.id}>
                {message.parts?.map((part, i) => {
                  if (part.type === 'text') {
                    return (
                      <Message key={`${message.id}-${i}`} from={message.role}>
                        <MessageContent>
                          <MessageResponse>{part.text}</MessageResponse>
                        </MessageContent>
                      </Message>
                    )
                  }

                  if (part.type?.startsWith('tool-')) {
                    return (
                      <Tool key={`${message.id}-${i}`}>
                        <ToolHeader
                          type={(part as ToolUIPart).type}
                          state={(part as ToolUIPart).state || 'output-available'}
                          className="cursor-pointer"
                        />
                        <ToolContent>
                          <ToolInput input={(part as ToolUIPart).input || {}} />
                          <ToolOutput
                            output={(part as ToolUIPart).output}
                            errorText={(part as ToolUIPart).errorText}
                          />
                        </ToolContent>
                      </Tool>
                    )
                  }

                  return null
                })}
              </div>
            ))}
            <ConversationScrollButton />
          </ConversationContent>
        </Conversation>
        <PromptInput onSubmit={handleSubmit} className="mt-20">
          <PromptInputBody>
            <PromptInputTextarea
              onChange={e => setInput(e.target.value)}
              className="md:leading-10"
              value={input}
              placeholder="Ask about the weather..."
              disabled={status !== 'ready'}
            />
          </PromptInputBody>
        </PromptInput>
      </div>
    </div>
  )
}
```

此組件連接[`useChat()`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/use-chat) to the `chat/weather-agent` endpoint, sending prompts there and streaming the response back in chunks.

它使用以下方式呈現回應文本[`<MessageResponse>`](https://ai-sdk.dev/elements/components/message#messageresponse-) component, and shows any tool invocations with the [`<Tool>`](https://ai-sdk.dev/elements/components/tool) component.

## 測試你的Agent {/* #test-your-agent */}

若要使用聊天介面測試您的Agent，請執行 Mastra 伺服器和 Vite 開發伺服器。

1. 啟動 Mastra 開發伺服器：

   ```bash npm2yarn
   npx mastra dev
   ```
2. 在單獨的終端機視窗中，啟動Vite開發伺服器：

   ```bash npm2yarn
   npm run dev
   ```
3. 打開您的申請表[http://localhost:5173](http://localhost:5173)
4. 試著詢問天氣。如果您的 API 金鑰設定正確，您將收到回應
