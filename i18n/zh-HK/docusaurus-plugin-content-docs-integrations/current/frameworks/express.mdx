# Express

本指南會示範如何使用 Mastra 和 Express 建立可呼叫 Tool 的 AI Agent。透過 [Express 伺服器轉接器](/reference/server/express-adapter)，您可以將 Agent 公開為 HTTP 端點，無須自行編寫路由或另行運行 Mastra 伺服器。

## 開始前 {/* #before-you-begin */}

- 您需要向受支援的 [Model Provider](/models) 取得 API 密鑰。如無特定偏好，可使用 [OpenAI](/models/providers/openai)。
- 安裝 Node.js `v22.13.0` 或更新版本

## 建立新的 Express 應用程式（選用） {/* #create-a-new-express-app-optional */}

如果已有 Express 應用程式，請跳至下一步。

複製這個 [範本儲存庫](https://github.com/mastra-ai/express-ts-boilerplate)，並安裝相依套件：

## 初始化 Mastra {/* #initialize-mastra */}

在 Express 項目目錄中執行 [`mastra init`](/reference/cli/mastra#mastra-init)。

出現提示時，選擇 Provider（例如 OpenAI），並輸入您的密鑰：

```bash
npx mastra@latest init
```

這會建立 `src/mastra` 資料夾，當中包含一個天氣 Agent 範例及以下檔案：

- `index.ts`：Mastra 設定，包括 Memory
- `tools/weather-tool.ts`：用於取得指定地點天氣資訊的 Tool
- `agents/weather-agent.ts`：天氣 Agent，其 Prompt 會指示它使用該 Tool

稍後，您會將 `src/mastra/index.ts` 檔案傳給 Express 伺服器轉接器。

## 新增伺服器轉接器 {/* #add-server-adapter */}

安裝 Express 伺服器轉接器套件：

```bash npm2yarn
npm install @mastra/express@latest
```

開啟 Express 的入口檔案 `src/index.ts`，並加入所需的匯入及初始化程式碼：

```typescript {2-3,11-12} title="src/index.ts"
import express, { type Request, type Response } from 'express'
import { MastraServer } from '@mastra/express'
import { mastra } from './mastra'

const app = express()
const PORT = process.env.PORT || 3000

// Middleware
app.use(express.json())

const server = new MastraServer({ app, mastra })
await server.init()

// Routes
app.get('/', (_req: Request, res: Response) => {
  res.json({ message: 'Hello, World!' })
})

// Start server
app.listen(PORT, () => {
  console.log(`Server is running on http://localhost:${PORT}`)
})
```

使用現有的 Express `app` 和根層級的 ⁠`mastra` 實例初始化 ⁠`MastraServer`。呼叫 `⁠init()` 會註冊 Mastra 中介軟件，並公開所有可用的 Mastra 端點。

## 測試 Agent {/* #test-your-agent */}

預設情況下，Mastra 端點會加入 `/api` 子路徑，並使用您的 Agent 或 Workflow ID。由 `mastra init` 建立的預設 `weather-agent` 可透過 `/api/agents/weather-agent` 存取。

啟動 Express 伺服器：

```bash
npm run start
```

在另一個終端機視窗中，使用 `curl` 向天氣 Agent 查詢：

```bash
curl -X POST http://localhost:3000/api/agents/weather-agent/generate -H "Content-Type: application/json" -d "{\"messages\":[{\"role\":\"user\",\"content\":\"What is the weather like in Seoul?\"}]}"
```
