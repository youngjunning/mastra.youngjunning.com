# Fly.io精靈

以持久方式執行指令[Fly.io Sprites](https://sprites.dev)透過官方`@fly/sprites`SDK。 Sprite 是一種 Linux VM，它在運行之間保持其檔案系統，並在空閒時自行休眠。`SpritesSandbox`透過名稱取得或建立 Sprite，以便新進程可以重新連接到相同的檔案。支援具有流輸出、逾時、取消、具有標準輸入的後台進程以及檢查點捕獲的命令執行。接口詳情請參見[WorkspaceSandbox介面](/reference/workspace/sandbox).

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/sprites
```

：：：筆記`@mastra/sprites` requires Node.js 24 or later because the `@fly/sprites` SDK does.
:::

## 用法 {/* #usage */}

添加一個`SpritesSandbox` to a workspace and assign it to an agent:

```typescript
import { Agent } from '@mastra/core/agent'
import { Workspace } from '@mastra/core/workspace'
import { SpritesSandbox } from '@mastra/sprites'

const workspace = new Workspace({
  sandbox: new SpritesSandbox({
    id: 'mastra-project',
    // token read from SPRITES_TOKEN
  }),
})

const agent = new Agent({
  id: 'code-agent',
  name: 'Code Agent',
  instructions: 'You are a coding assistant working in this workspace.',
  model: '__GATEWAY_ANTHROPIC_MODEL_SONNET__',
  workspace,
})

const response = await agent.generate(
  'Print "Hello, world!" and show the current working directory.',
)

console.log(response.text)
```

### 重複使用精靈 {/* #reusing-a-sprite */}

這`id` is the Sprite name. On `start()`, `SpritesSandbox` looks up a Sprite with that name and reconnects to it, or creates one when none exists. Files written in an earlier session are still there:

```typescript
const first = new SpritesSandbox({ id: 'mastra-project' })
await first.executeCommand('sh', ['-c', 'echo hello > notes.txt'])
await first.stop()

// Later, possibly in another process
const second = new SpritesSandbox({ id: 'mastra-project' })
const result = await second.executeCommand('cat', ['notes.txt'])
console.log(result.stdout) // hello
```

您帳戶中任何同名的現有 Sprite 都會被採用，因此請選擇項目唯一的名稱。什麼時候`id` is omitted, a random name is generated.

`spriteConfig`（RAM、CPU、區域、儲存）僅在建立 Sprite 時套用。

### 停止並摧毀 {/* #stopping-and-destroying */}

`stop()`和`destroy()` do different things:

* `stop()`終止此實例啟動的背景程序並關閉 SDK 連線。 Sprite 及其檔案系統被保留。精靈在空閒時會自行冬眠，因此無需暫停任何內容。
* `destroy()`永久刪除 Sprite 及其檔案系統。無需調用即可工作`start()` first, and a Sprite that no longer exists is treated as already deleted.

```typescript
const sandbox = new SpritesSandbox({ id: 'mastra-project' })

// Remove the Sprite when the project is finished
await sandbox.destroy()
```

### 檢查站 {/* #checkpoints */}

`snapshot()`捕獲 Sprite 目前狀態的檢查點並等待捕獲完成：

```typescript
await sandbox.snapshot()
```

檢查點位於精靈內部。它們不能用於啟動或播種另一個沙箱，所以`supportsCheckpoints` is `false` and `SpritesSandbox` doesn't implement `clone()`. Use the `@fly/sprites` SDK through `sandbox.sprite` to list or restore checkpoints.

### 串流輸出 {/* #streaming-output */}

經過`onStdout` and `onStderr` to receive output as it arrives:

```typescript
await sandbox.executeCommand('npm', ['install'], {
  onStdout: data => process.stdout.write(data),
  onStderr: data => process.stderr.write(data),
  timeout: 120_000,
})
```

當命令逾時或其`abortSignal` fires, the command is killed and the result reports `killed: true`.

## 後台程式 {/* #background-processes */}

`SpritesSandbox`包括用於產生和管理後台進程的進程管理器。每個進程都在自己的 Sprites exec 會話中運行並支援 stdin。

```typescript
const sandbox = new SpritesSandbox({ id: 'mastra-project' })
await sandbox.start()

const handle = await sandbox.processes.spawn('node server.js', {
  env: { PORT: '3000' },
  onStdout: data => console.log(data),
})

await handle.sendStdin('reload\n')
await handle.kill()
```

由一個進程啟動的進程`SpritesSandbox` instance are not visible to another instance, and `stop()` kills them.

看[`SandboxProcessManager` reference](/reference/workspace/process-manager) for the full API.

## 編輯器提供者 {/* #editor-provider */}

向提供者註冊`MastraEditor` to hydrate stored sandbox configs into runtime instances:

```typescript
import { MastraEditor } from '@mastra/editor'
import { spritesSandboxProvider } from '@mastra/sprites'

const editor = new MastraEditor({
  sandboxes: { [spritesSandboxProvider.id]: spritesSandboxProvider },
})
```

請參閱[Sandbox provider reference](/reference/editor/sandbox-provider) for details on registering custom sandbox providers.
