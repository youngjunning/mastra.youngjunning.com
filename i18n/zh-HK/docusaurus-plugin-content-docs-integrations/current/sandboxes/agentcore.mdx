# AgentCore

透過 `InvokeAgentRuntimeCommand`，在 [AWS Bedrock AgentCore Runtime](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/runtime-execute-command.html) 工作階段內執行 shell 指令。

如果 Agent 已在 AgentCore Runtime 運行，而你希望 Mastra Workspace 在同一個工作階段執行指令，可使用 `AgentCoreRuntimeSandbox`。有關介面詳情，請參閱 [WorkspaceSandbox 介面](/reference/workspace/sandbox)。

:::warning

`AgentCoreRuntimeSandbox` 只支援一次性指令執行，不支援背景程序管理、標準輸入或檔案系統掛載。AgentCore Code Interpreter 是另一項 AWS 服務，不屬於此 Provider。

:::

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/agentcore
```

## 用法 {/* #usage */}

先把 `AgentCoreRuntimeSandbox` 加入 Workspace，再把該 Workspace 分配給 Agent：

```typescript title="src/mastra/agents/dev-agent.ts"
import { Agent } from '@mastra/core/agent'
import { Workspace } from '@mastra/core/workspace'
import { AgentCoreRuntimeSandbox } from '@mastra/agentcore'

const workspace = new Workspace({
  sandbox: new AgentCoreRuntimeSandbox({
    region: 'us-west-2',
    agentRuntimeArn: process.env.AGENTCORE_RUNTIME_ARN!,
    runtimeSessionId: '12345678-1234-1234-1234-123456789012',
  }),
})

const agent = new Agent({
  id: 'dev-agent',
  name: 'dev-agent',
  model: 'anthropic/claude-sonnet-4-6',
  instructions: 'You are a helpful development assistant.',
  workspace,
})
```

在程式碼中透過 Sandbox 執行指令：

```typescript
const result = await workspace.sandbox?.executeCommand?.('npm', ['test'], {
  cwd: '/workspace',
  env: {
    NODE_ENV: 'test',
  },
  timeout: 300_000,
})

if (!result?.success) {
  console.error(result?.stderr)
}
```

## 方法 {/* #methods */}

### 指令執行 {/* #command-execution */}

#### `executeCommand(command, args?, options?)` {/* #executecommandcommand-args-options */}

在 AgentCore Runtime 工作階段內執行一次 shell 指令，並傳回標準輸出、標準錯誤、退出代碼及逾時狀態。

```typescript
const result = await sandbox.executeCommand('npm', ['test'], {
  cwd: '/workspace',
  env: {
    NODE_ENV: 'test',
  },
  timeout: 300_000,
})
```

傳回：`Promise<CommandResult>`。

`options.timeout` 以毫秒為單位。AgentCore Runtime 接受的指令逾時範圍是 1 至 3600 秒。Provider 會在發送請求前把毫秒轉換為秒。

### 生命週期 {/* #lifecycle */}

#### `start()` {/* #start */}

執行 Sandbox 生命週期的啟動掛鈎。此 Provider 不會在執行 `start()` 時建立 AgentCore Runtime 工作階段。

```typescript
await sandbox.start()
```

#### `stop()` {/* #stop */}

只會在 `stopSessionOnLifecycle` 設為 `true` 時停止 AgentCore Runtime 工作階段。

```typescript
await sandbox.stop()
```

#### `stopRuntimeSession()` {/* #stopruntimesession */}

直接停止此 Sandbox 所用的 AgentCore Runtime 工作階段。

如果該工作階段由此 Sandbox 擁有，而你想直接清理該工作階段，便可呼叫此方法。AgentCore Runtime 工作階段可能與 Workspace 的 Sandbox 生命週期以外的 Agent 呼叫共用，因此 `destroy()` 只會在 `stopSessionOnLifecycle` 為 `true` 時呼叫此方法。

```typescript
await sandbox.stopRuntimeSession()
```

#### `destroy()` {/* #destroy */}

銷毀 Sandbox 實例。如果 AWS SDK 客戶端屬於此實例，`destroy()` 亦會銷毀該客戶端。如 `stopSessionOnLifecycle` 為 `true`，便會呼叫 `StopRuntimeSession`。

```typescript
await sandbox.destroy()
```

### 元資料 {/* #metadata */}

#### `getInfo()` {/* #getinfo */}

傳回 Sandbox 的狀態及 AgentCore Runtime 的元資料。

```typescript
const info = await sandbox.getInfo()
```

傳回：`Promise<SandboxInfo>`。

## 限制 {/* #limitations */}

`AgentCoreRuntimeSandbox` 按照 AgentCore Runtime 的規則執行指令：

* **一次性指令**：每項指令會一直執行，直至結束或逾時。
* **Shell 不會持續運行**：每次執行指令時，shell 都不會沿用上一項指令的狀態。請在每項指令內設定所需狀態，例如 `cd /workspace && npm test`。
* **不支援背景程序**：此 Provider 沒有提供 `processes` 管理器。
* **沒有互動式標準輸入**：經此 Provider 在執行環境內執行指令時，無法使用互動式標準輸入串流。
* **不支援掛載 Workspace 檔案系統**：此 Provider 無法掛載 Workspace 的檔案系統。
* **可用的 Tool 視乎容器映像**：指令只可使用已安裝在 AgentCore Runtime 容器映像內的 Tool。
