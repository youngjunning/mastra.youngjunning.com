# Vercel 沙箱

使用持久性 Sandbox microVM 或無狀態 Serverless Functions 在隔離的 Vercel 環境中執行指令。

## 維塞爾沙箱 {/* #vercel-sandbox */}

執行裡面的命令[Vercel Sandbox](https://vercel.com/docs/vercel-sandbox) which is an ephemeral [Firecracker](https://firecracker-microvm.github.io/)運行 Amazon Linux 2023 的 MicroVM。提供持久的會話中檔案系統，`sudo`存取、暴露的連接埠和後台進程。接口詳情請參見[WorkspaceSandbox介面](/reference/workspace/sandbox).

：：：筆記

這與[`VercelServerlessSandbox`](#vercel-serverless-sandbox), which runs commands as stateless Vercel serverless **Functions**. `VercelSandbox` runs a full Linux MicroVM with a persistent filesystem and long-running processes.

:::

### 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/vercel
```

### 驗證 {/* #authentication */}

這`@vercel/sandbox` SDK uses a Vercel OIDC token automatically when no explicit credentials are provided. If you provide `token`, `teamId`, or `projectId`, provide all three values together.

  <TabItem value="oidc" label="OIDC (recommended)">

### 用法 {/* #usage */}

添加一個`VercelSandbox` to a workspace and assign it to an agent:

```typescript
import { Agent } from '@mastra/core/agent'
import { Workspace } from '@mastra/core/workspace'
import { VercelSandbox } from '@mastra/vercel'

const workspace = new Workspace({
  sandbox: new VercelSandbox({
    runtime: 'node24',
    timeout: 600_000,
  }),
})

const agent = new Agent({
  id: 'code-agent',
  name: 'Code Agent',
  instructions: 'You are a coding assistant working in this workspace.',
  model: '__GATEWAY_ANTHROPIC_MODEL_SONNET__',
  workspace,
})

const response = await agent.generate('Print "Hello, world!" and show the Node.js version.')

console.log(response.text)
```

#### 資源和暴露的端口 {/* #resources-and-exposed-ports */}

分配 vCPU（每個 vCPU 2048 MB 記憶體）並公開連接埠以存取沙箱內運行的網路服務：

```typescript
const sandbox = new VercelSandbox({
  runtime: 'node24',
  resources: { vcpus: 4 },
  ports: [3000],
})

const workspace = new Workspace({ sandbox })
await sandbox.start()

// The public HTTPS domain for an exposed port is available via getInfo()
const { metadata } = sandbox.getInfo()
console.log(metadata?.domains) // { 3000: 'https://....vercel.run' }
```

#### 串流輸出 {/* #streaming-output */}

透過即時串流命令輸出`onStdout` and `onStderr` callbacks:

```typescript
await sandbox.executeCommand('sh', ['-c', 'for i in 1 2 3; do echo "line $i"; sleep 1; done'], {
  onStdout: chunk => process.stdout.write(chunk),
  onStderr: chunk => process.stderr.write(chunk),
})
```

兩個回調都是可選的並且可以獨立使用。

### 後台程式 {/* #background-processes */}

`VercelSandbox`包括用於產生和管理後台進程的進程管理器。每個產生的進程都以 MicroVM 內的獨立命令執行，並透過命令日誌傳輸輸出。

```typescript
const sandbox = new VercelSandbox({ runtime: 'node24', ports: [3000] })
await sandbox.start()

const handle = await sandbox.processes.spawn('node server.js', {
  env: { PORT: '3000' },
  onStdout: data => console.log(data),
})

console.log(handle.stdout)
await handle.kill()
```

請參閱[`SandboxProcessManager` reference](/reference/workspace/process-manager) for the full API.

：：：筆記

Vercel Sandbox SDK 不公開用於運行命令的標準輸入通道，因此`handle.sendStdin()` throws.

Mastra 適配器不實作 Workspace 檔案系統安裝 API。底層 Vercel Sandbox 產品支持[Filesystem in Userspace (FUSE) mounts](https://vercel.com/docs/sandbox/mount-remote-storage). You can configure a mount directly through the underlying SDK instance exposed by `sandbox.sandbox`, but Mastra doesn't manage its lifecycle.

:::

### 限制 {/* #limits */}

* 最多 32 個 vCPU，每個 vCPU 具有 2048 MB 記憶體。
* 最多 15 個暴露連接埠。
* 文件系統是短暫的。它僅在會話內保留，並在沙箱停止時丟失。
* 最長運行時間取決於計劃（Hobby 為 45 分鐘，Pro 和 Enterprise 最長為 24 小時），預設為 5 分鐘。

請參閱[Vercel Sandbox documentation](https://vercel.com/docs/vercel-sandbox) for current limits and pricing.

## Vercel 無伺服器沙箱 {/* #vercel-serverless-sandbox */}

`VercelServerlessSandbox`執行命令為[Vercel](https://vercel.com) serverless functions. It provides globally distributed, zero-infrastructure execution with automatic scaling. For interface details, see the [WorkspaceSandbox interface](/reference/workspace/sandbox).

：：：警告

`VercelServerlessSandbox`是無國籍的。它不提供持久檔案系統、互動式 shell 或長時間運行的背景進程。僅有的`/tmp` is writable, and it's ephemeral between invocations.

:::

：：：筆記

對於具有持久檔案系統的完整 Linux MicroVM，`sudo` access, exposed ports, and background processes, use [`VercelSandbox`](#vercel-sandbox), which is backed by the [Vercel Sandbox](https://vercel.com/docs/vercel-sandbox) product.

:::

### 限制 {/* #limitations */}

`VercelServerlessSandbox`在底層使用無伺服器功能，這意味著：

* **沒有持久性檔案系統**：寫入的文件`/tmp` are ephemeral and cleared between invocations.
* **沒有互動式 shell**：命令運行通過`/bin/sh -c` with no stdin streaming.
* **無後台程式**：沒有進程管理器、PID 或長時間運行的任務。
* **無需安裝**：不支援雲端儲存安裝（S3、GCS）。
* **逾時限制**：最大執行時間受以下限制`maxDuration` (default 60s).
