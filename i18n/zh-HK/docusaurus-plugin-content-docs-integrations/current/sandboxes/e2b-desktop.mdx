# E2B桌面

在隔離的環境中運行完整的 Linux 桌面環境[E2B](https://e2b.dev)具有螢幕截圖、滑鼠和鍵盤控制的雲沙箱。`E2BDesktopSandbox`延伸[`E2BSandbox`](/integrations/sandboxes/e2b)，因此基礎提供者支援的所有內容（命令執行、後台程序、檔案上傳、暫停/恢復重新連線）都適用於同一台桌面電腦。接口詳情請參見[WorkspaceSandbox介面](/reference/workspace/sandbox).

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/e2b-desktop
```

使用以下命令設定您的 E2B API 金鑰`E2B_API_KEY` environment variable or the `apiKey` option.

## 用法 {/* #usage */}

添加一個`E2BDesktopSandbox` to a workspace and assign it to an agent. Because the sandbox supports the [computer capability](/docs/sandbox/computer), the workspace registers the `mastra_workspace_computer_*` tools alongside the shell and process tools:

```typescript
import { Agent } from '@mastra/core/agent'
import { Workspace } from '@mastra/core/workspace'
import { E2BDesktopSandbox } from '@mastra/e2b-desktop'

const workspace = new Workspace({
  sandbox: new E2BDesktopSandbox({
    resolution: [1280, 720],
  }),
})

const agent = new Agent({
  id: 'desktop-agent',
  name: 'Desktop Agent',
  instructions: 'You can control a Linux desktop and run shell commands.',
  model: '__GATEWAY_ANTHROPIC_MODEL_SONNET__',
  workspace,
})

const response = await agent.generate(
  'Take a screenshot, then create /tmp/hello.txt with the text "hello" and cat it.',
)
```

Agent程式可以將桌面操作（點擊、鍵入、螢幕截圖）與 shell 命令混合。兩個表面在同一台機器上運作。

### 直接桌面控制 {/* #direct-desktop-control */}

使用`computer` capability programmatically without an agent:

```typescript
const sandbox = new E2BDesktopSandbox()
await sandbox.start()

await sandbox.computer.leftClick(100, 200)
await sandbox.computer.type('hello')
const { data } = await sandbox.computer.screenshot() // PNG bytes

const size = await sandbox.computer.getScreenSize()
console.log(size) // { width: 1024, height: 768 }
```

### 即時桌面視圖 {/* #live-desktop-view */}

`streamUrl()`在沙箱內啟動經過驗證的 noVNC 串流並返回檢視器 URL。在瀏覽器中打開它以觀察Agent的工作情況：

```typescript
const url = await sandbox.computer.streamUrl()
// https://6080-<sandbox-id>.e2b.app/vnc.html?...&password=<auth-key>
```

### 桌面 SDK 逃生艙口 {/* #desktop-sdk-escape-hatch */}

僅限桌面的 API，例如`launch`, `open`, window helpers, and custom stream control are available on the underlying [`@e2b/desktop`](https://github.com/e2b-dev/desktop) sandbox:

```typescript
await sandbox.desktop.launch('xfce4-terminal')
await sandbox.desktop.open('https://mastra.ai')
```

## 雲端儲存掛載 {/* #cloud-storage-mounting */}

預設`desktop` template has no FUSE tooling, so [cloud storage mounting](/integrations/sandboxes/e2b#mounting-cloud-storage) requires a custom desktop template with `s3fs` or `gcsfuse` installed. Pass it with the `template` option.
