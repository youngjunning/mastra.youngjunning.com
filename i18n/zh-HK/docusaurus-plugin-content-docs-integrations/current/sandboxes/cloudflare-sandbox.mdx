# Cloudflare Sandbox

`CloudflareSandbox` 透過 [Sandbox Bridge HTTP API](https://developers.cloudflare.com/sandbox/bridge/http-api/) 在遠端 [Cloudflare Sandbox](https://developers.cloudflare.com/sandbox/) 執行指令和管理檔案。

:::warning

使用此 Provider 前，請先部署 [Sandbox Bridge Worker](https://developers.cloudflare.com/sandbox/bridge/) 並做好保安設定。Bridge 可代呼叫方建立和刪除 Sandbox、執行指令及寫入檔案。

:::

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/cloudflare-sandbox
```

## 用法 {/* #usage */}

把 `CloudflareSandbox` 加入 Workspace，再將該 Workspace 指派給 Agent。

```typescript title="src/mastra/agents/dev-agent.ts"
import { Agent } from '@mastra/core/agent'
import { Workspace } from '@mastra/core/workspace'
import { CloudflareSandbox } from '@mastra/cloudflare-sandbox'

const workspace = new Workspace({
  sandbox: new CloudflareSandbox({
    baseUrl: process.env.CLOUDFLARE_SANDBOX_BRIDGE_URL!,
    apiToken: process.env.CLOUDFLARE_SANDBOX_API_KEY,
    workingDirectory: '/workspace',
    commandTimeout: 300_000,
  }),
})

export const agent = new Agent({
  id: 'dev-agent',
  name: 'Development agent',
  instructions: 'You are a helpful development assistant.',
  model: 'anthropic/claude-sonnet-4-6',
  workspace,
})
```

Workspace 啟動時，Provider 會建立遠端 Sandbox。如需重新連接現有的 Sandbox，可傳入 `sandboxId`。

## 執行指令 {/* #execute-commands */}

呼叫 `executeCommand()` 時，可傳入指令參數、環境變數、工作目錄及處理串流輸出的回調函數。Provider 會以 `argv` 陣列傳送指令，並由 Bridge 處理 Shell 跳脫。

```typescript
const result = await workspace.sandbox?.executeCommand?.('npm', ['test'], {
  cwd: '/workspace/project',
  env: {
    NODE_ENV: 'test',
  },
  onStdout: chunk => process.stdout.write(chunk),
  onStderr: chunk => process.stderr.write(chunk),
})
```

## 寫入檔案 {/* #write-files */}

相對路徑按 `/workspace` 解析，絕對路徑解析後亦必須位於 `/workspace` 內。每個檔案都會以獨立請求傳送至 Bridge，每個檔案的大小上限為 32 MiB。

Cloudflare Sandbox 無法逐個檔案設定權限，因此會直接拒絕包含 `mode` 的 `writeFiles` 呼叫。

```typescript
await workspace.sandbox?.writeFiles?.([
  { path: 'src/index.ts', content: "console.log('hello')\n" },
  { path: '/workspace/package.json', content: JSON.stringify({ type: 'module' }) },
])
```

## 讀取檔案 {/* #read-files */}

從 `/workspace` 讀取單一檔案會傳回原始位元組。相對路徑按 `/workspace` 解析，絕對路徑解析後亦必須位於該目錄內。

```typescript
const bytes = await workspace.sandbox?.readFile?.('src/index.ts')
const source = new TextDecoder().decode(bytes)
```

## 容器休眠後保留檔案 {/* #keep-files-across-container-sleep */}

容器閒置時間達到 `sleepAfter`（預設為 10 分鐘）後，Cloudflare 便會停止容器。執行下一條指令時，會啟動全新的容器，先前直接寫入 `/workspace` 的內容會遺失。請將 `/workspace` 用作臨時存放空間，並把需要保留的檔案存入已掛載的儲存桶。

可透過 Workspace 的 `mounts` 選項設定兼容 S3 的儲存桶，例如 Cloudflare R2。Sandbox 會在 `start()` 時掛載儲存桶。休眠過的容器重新啟動時不會保留原有掛載，Sandbox 會在下次檔案系統操作前重新掛載已失去掛載的路徑，因此容器休眠後仍可存取儲存桶內的資料。

```typescript
import { Workspace } from '@mastra/core/workspace'
import { S3Filesystem } from '@mastra/s3'
import { CloudflareSandbox } from '@mastra/cloudflare-sandbox'

const workspace = new Workspace({
  sandbox: new CloudflareSandbox({
    baseUrl: process.env.CLOUDFLARE_SANDBOX_BRIDGE_URL!,
    apiToken: process.env.CLOUDFLARE_SANDBOX_BRIDGE_TOKEN!,
  }),
  mounts: {
    '/workspace/data': new S3Filesystem({
      bucket: 'agent-data',
      region: 'auto',
      endpoint: `https://${process.env.CLOUDFLARE_ACCOUNT_ID}.r2.cloudflarestorage.com`,
      accessKeyId: process.env.R2_ACCESS_KEY_ID,
      secretAccessKey: process.env.R2_SECRET_ACCESS_KEY,
    }),
  },
})
```

Bridge 使用 s3fs 掛載儲存桶，因此只接受 `type: 's3'` 的掛載設定。如使用 GCS 或 Azure 檔案系統，或 S3 憑證包含 `sessionToken`，Provider 會直接傳回表示掛載失敗的 `MountResult`，不會向 Bridge 發出請求。

`getInstructions()` 預設傳回的說明會提醒模型，`/workspace` 內的資料可能在兩條指令之間遺失，並列出應寫入的掛載路徑。

## 備份及還原 Workspace {/* #persist-and-restore-the-workspace */}

`persistWorkspace()` 將 `/workspace` 封存為 tar 並傳回原始位元組。`hydrateWorkspace()` 會利用這些位元組還原 Workspace。這套方法適合一次性備份，不能取代掛載。容器喚醒後，必須在執行第一條指令前完成還原。如果在容器剛喚醒時備份，空白的 Workspace 便會覆蓋原有封存檔。

```typescript
// Back up before the container can sleep
const archive = await workspace.sandbox?.persistWorkspace?.({ excludes: ['node_modules'] })
await myStorage.put('workspace-backup', archive)

// Later, on a fresh or reconnected sandbox
const archive = await myStorage.get('workspace-backup')
await workspace.sandbox?.hydrateWorkspace?.(archive)
```

如要管理執行會話，請直接呼叫 `CloudflareSandboxBridgeClient` 的 `createSession` 和 `deleteSession` 方法。

## 生命週期行為 {/* #lifecycle-behavior */}

* `start()`：重新連接 `sandboxId` 指定的 Sandbox，或建立遠端 Sandbox，然後套用 Workspace 的 `mounts` 掛載設定。
* `stop()`：解除遠端 Sandbox 與 Mastra 生命週期的關聯。由於 Bridge 沒有提供暫停操作，遠端 Sandbox 會保留。
* `destroy()`：刪除遠端 Sandbox。

## 限制 {/* #limitations */}

此 Provider 直接透過 Sandbox 介面提供指令執行、串流輸出、檔案讀寫、兼容 S3 的儲存桶掛載及 Workspace 持久化功能。會話只可透過 Bridge 客戶端（`CloudflareSandboxBridgeClient`）使用，`CloudflareSandbox` 介面沒有提供此功能。此 Provider 沒有提供 PTY 終端，亦不支援背景程序管理、標準輸入（stdin）、快照或連接埠 URL。
