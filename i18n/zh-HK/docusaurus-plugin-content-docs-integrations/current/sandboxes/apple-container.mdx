# 蘋果容器

透過 Apple 在本機 OCI Linux 容器內執行命令[`container`](https://github.com/apple/container)命令列介面。提供者啟動一個長期存在的容器並使用`container exec`用於Workspace命令。接口詳情請參見[WorkspaceSandbox介面](/reference/workspace/sandbox).

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/apple-container
```

需要運行 macOS 26 或更高版本的 Apple Silicon Mac`container` CLI installed. Start the container system before using the provider:

```bash
container system start
```

## 用法 {/* #usage */}

添加一個`AppleContainerSandbox` to a workspace and assign it to an agent:

```typescript
import { Agent } from '@mastra/core/agent'
import { Workspace } from '@mastra/core/workspace'
import { AppleContainerSandbox } from '@mastra/apple-container'

const workspace = new Workspace({
  sandbox: new AppleContainerSandbox({
    image: 'node:22-slim',
    volumes: {
      '/Users/me/project': '/workspace',
    },
    workingDirectory: '/workspace',
  }),
})

const agent = new Agent({
  id: 'dev-agent',
  name: 'Dev Agent',
  instructions: 'You are a coding assistant working in this workspace.',
  model: '__GATEWAY_ANTHROPIC_MODEL_SONNET__',
  workspace,
})

const response = await agent.generate('Run `node --version`.')
console.log(response.text)
```

## 環境變數 {/* #environment-variables */}

在容器層級設定環境變數`env`. Per-command environment variables can also be passed through `executeCommand` options:

```typescript
const sandbox = new AppleContainerSandbox({
  image: 'node:22-slim',
  env: {
    NODE_ENV: 'development',
  },
})

await sandbox.executeCommand('node', ['-e', 'console.log(process.env.TASK_ID)'], {
  env: { TASK_ID: '42' },
})
```

## 綁定坐騎 {/* #bind-mounts */}

使用以下命令將主機目錄掛載到容器中`volumes` option:

```typescript
const sandbox = new AppleContainerSandbox({
  image: 'node:22-slim',
  volumes: {
    '/Users/me/project': '/workspace/project',
    '/Users/me/.npm': '/root/.npm',
  },
})
```

綁定掛載在容器建立時應用。主機路徑必須在沙箱啟動之前存在。

## 資源和平台選項 {/* #resource-and-platform-options */}

Apple 容器 CLI 選項可以透過建構函式傳遞：

```typescript
const sandbox = new AppleContainerSandbox({
  image: 'node:22-slim',
  volumes: {
    '/Users/me/project': '/workspace',
  },
  cpus: 2,
  memory: '2G',
  platform: 'linux/arm64',
  readonlyRootfs: true,
  tmpfs: ['/tmp'],
})
```

這些選項僅在建立新容器時套用。如果沙箱重新連接到具有相同名稱的現有容器，請銷毀並重新建立沙箱以套用變更的執行時間選項。
蘋果`--tmpfs` accepts container paths only, such as `/tmp`; it doesn't accept Docker-style option specs like `/tmp:rw,size=256m`.
When `readonlyRootfs` is enabled, make sure `workingDirectory` points to a path supplied by the image or a bind mount. A writable tmpfs is also supported.

## 安全模型 {/* #security-model */}

`AppleContainerSandbox`透過主機 Apple 運行本機容器`container` service. Treat constructor options as trusted server-side configuration:

* `volumes`, `mounts`, and `publishedSockets` can expose host paths to containerized code.
* `publishedPorts`可以在主機或網路上公開容器內服務。綁定到`127.0.0.1` when only local access is intended.
* `ssh`轉送主機 SSH Agent套接字。
* `capAdd`和`virtualization` can expand what containerized code can do.
* `containerBinary`是受信任程式碼的僅建構函數逃生口，不是可序列化編輯器提供者架構的一部分。

使用您的工作負載所需的最窄安裝和功能。現有容器僅在帶有沙箱 ID 的 Mastra 所有權標籤時才會重新連接。該提供者建立的容器還包含配置雜湊標籤；當該標籤存在時，如果不可變的執行時間選項（例如映像、命令、掛載、連接埠、功能或工作目錄發生變更），重新連接將會失敗。

## 限制 {/* #limitations */}

`AppleContainerSandbox`實現前台Workspace指令執行`executeCommand()`. It doesn't yet expose a `SandboxProcessManager` for background processes or LSP sessions.



## 重連 {/* #reconnection */}

`AppleContainerSandbox`透過檢查具有配置名稱的容器來重新連接。什麼時候`start()` is called:

* 正在運行的容器被重複使用。
* 已停止的容器將重新啟動。
* 從配置的映像建立遺失的容器。
* 具有已配置名稱但沒有符合 Mastra 所有權標籤的容器會失敗而不是受到管理。
* 如果 Mastra 擁有的容器的配置哈希標籤與不可變運行時選項不匹配，則會失敗而不是被重複使用。

```typescript
const sandbox = new AppleContainerSandbox({ id: 'persistent-sandbox' })
await sandbox.start()

const sandbox2 = new AppleContainerSandbox({ id: 'persistent-sandbox' })
await sandbox2.start()
```

## 編輯器提供者 {/* #editor-provider */}

向提供者註冊`MastraEditor` to hydrate stored sandbox configs:

```typescript
import { MastraEditor } from '@mastra/editor'
import { appleContainerSandboxProvider } from '@mastra/apple-container'

const editor = new MastraEditor({
  sandboxes: {
    [appleContainerSandboxProvider.id]: appleContainerSandboxProvider,
  },
})
```
