# 布萊克塞爾

在隔離中執行命令[Blaxel](https://blaxel.ai/)雲沙箱。提供安全、隔離的程式碼執行環境，支援透過 FUSE 掛載雲端儲存（S3、GCS）。接口詳情請參見[WorkspaceSandbox介面](/reference/workspace/sandbox).

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/blaxel
```

## 用法 {/* #usage */}

添加一個`BlaxelSandbox` to a workspace and assign it to an agent:

```typescript
import { Agent } from '@mastra/core/agent'
import { Workspace } from '@mastra/core/workspace'
import { BlaxelSandbox } from '@mastra/blaxel'

const workspace = new Workspace({
  sandbox: new BlaxelSandbox(),
})

const agent = new Agent({
  id: 'code-agent',
  name: 'Code Agent',
  instructions: 'You are a coding assistant working in this workspace.',
  model: '__GATEWAY_ANTHROPIC_MODEL_SONNET__',
  workspace,
})
```

### 帶有資源的自訂圖像 {/* #custom-image-with-resources */}

使用具有額外記憶體的自訂 Docker 映像：

```typescript
const workspace = new Workspace({
  sandbox: new BlaxelSandbox({
    image: 'node:20-slim',
    memory: 8192,
    region: 'auto',
    timeout: '10m',
  }),
})
```

## 後台程式 {/* #background-processes */}

`BlaxelSandbox`包括一個內建的進程管理器，用於產生和管理後台進程。

```typescript
const sandbox = new BlaxelSandbox({ id: 'dev-sandbox' })
await sandbox.start()

// Spawn a background process
const handle = await sandbox.processes.spawn('node server.js', {
  env: { PORT: '3000' },
  onStdout: data => console.log(data),
})

// Interact with the process
await handle.sendStdin('hello\n')
await handle.closeStdin()
console.log(handle.stdout)
await handle.kill()
```

預設情況下，產生的進程有一個可寫入的標準輸入。經過`stdinMode: 'ignore'` to start a process with stdin closed so commands that read stdin get EOF immediately.

看[`SandboxProcessManager` reference](/reference/workspace/process-manager) for the full API.

## 安裝雲端儲存 {/* #mounting-cloud-storage */}

Blaxel 沙箱可以掛載 S3 或 GCS 檔案系統，讓雲端儲存可以作為沙箱內的本機目錄存取。

### S3 {/* #s3 */}

```typescript
import { Workspace } from '@mastra/core/workspace'
import { S3Filesystem } from '@mastra/s3'
import { BlaxelSandbox } from '@mastra/blaxel'

const workspace = new Workspace({
  mounts: {
    '/data': new S3Filesystem({
      bucket: 'my-bucket',
      region: 'us-east-1',
      accessKeyId: process.env.AWS_ACCESS_KEY_ID,
      secretAccessKey: process.env.AWS_SECRET_ACCESS_KEY,
    }),
  },
  sandbox: new BlaxelSandbox(),
})
```

### 地面站 {/* #gcs */}

```typescript
import { Workspace } from '@mastra/core/workspace'
import { GCSFilesystem } from '@mastra/gcs'
import { BlaxelSandbox } from '@mastra/blaxel'

const workspace = new Workspace({
  mounts: {
    '/data': new GCSFilesystem({
      bucket: 'my-bucket',
      credentials: JSON.parse(process.env.GCS_SERVICE_ACCOUNT_KEY!),
    }),
  },
  sandbox: new BlaxelSandbox(),
})
```
