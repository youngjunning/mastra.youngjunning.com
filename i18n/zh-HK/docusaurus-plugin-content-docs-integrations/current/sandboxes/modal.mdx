# 莫代爾

在隔離中執行命令[Modal](https://modal.com)雲沙箱。提供由 Modal 基礎設施支援的安全、臨時環境。接口詳情請參見[WorkspaceSandbox介面](/reference/workspace/sandbox).

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/modal
```

## 用法 {/* #usage */}

添加一個`ModalSandbox` to a workspace and assign it to an agent:

```typescript
import { Agent } from '@mastra/core/agent'
import { Workspace } from '@mastra/core/workspace'
import { ModalSandbox } from '@mastra/modal'

const workspace = new Workspace({
  sandbox: new ModalSandbox({
    id: 'dev-sandbox',
    baseImage: 'ubuntu:22.04',
    timeoutMs: 60_000,
  }),
})

const agent = new Agent({
  id: 'dev-agent',
  model: '__GATEWAY_ANTHROPIC_MODEL_OPUS__',
  workspace,
})
```

## 驗證 {/* #authentication */}

透過環境變數或建構函式選項設定模態憑證：

```bash
MODAL_TOKEN_ID=ak-...
MODAL_TOKEN_SECRET=as-...
```

或直接傳遞它們：

```typescript
const sandbox = new ModalSandbox({
  tokenId: process.env.MODAL_TOKEN_ID,
  tokenSecret: process.env.MODAL_TOKEN_SECRET,
})
```

從下列位置取得您的憑證[Modal dashboard](https://modal.com/settings/tokens).

## Sandbox生命週期 {/* #sandbox-lifecycle */}

* **`_start()`**：嘗試重新連線到現有正在運作的沙箱。如果沒有找到，則從最新快照建立一個沙箱（如果可以從先前的快照中取得）`_stop()`), or from the baseImage.
* **`_stop()`**：對檔案系統進行快照，然後終止沙箱。快照保存在同一實例的記憶體中以供將來啟動。
* **`_destroy()`**：終止沙箱並丟棄任何快照。

```typescript
const sandbox = new ModalSandbox({
  id: 'dev-sandbox',
  baseImage: 'ubuntu:22.04',
  timeoutMs: 300_000,
})

await sandbox._start()
await sandbox.processes.spawn('npm install')
await sandbox._stop()
await sandbox._start()
```

## 捲和持久文件 {/* #volumes-and-persistent-files */}

山[Modal Volumes](https://modal.com/docs/guide/volumes) with the `volumes` option, then use `ModalFilesystem` to expose a mounted path to the agent's workspace file tools. Files written under the mount persist across sandbox restarts.

```typescript
import { Workspace } from '@mastra/core/workspace'
import { ModalFilesystem, ModalSandbox } from '@mastra/modal'
import { ModalClient } from 'modal'

const modal = new ModalClient()
const privateVolume = await modal.volumes.fromName('agent-user-123', { createIfMissing: true })
const teamVolume = await modal.volumes.fromName('agent-team', { createIfMissing: true })

const sandbox = new ModalSandbox({
  id: 'agent-sandbox',
  workingDirectory: '/workspace',
  volumes: {
    '/mnt/agent': privateVolume,
    '/mnt/team': teamVolume,
  },
})

const workspace = new Workspace({
  sandbox,
  filesystem: new ModalFilesystem({ sandbox, basePath: '/mnt/agent' }),
})
```

`ModalFilesystem`在沙箱內運行文件操作並將所有路徑限制為`basePath`. Set `readOnly: true` to reject writes.

其他沙箱對同一卷的寫入僅在重新載入後可見。稱呼`reloadVolumes()` on a long-lived sandbox to pick them up:

```typescript
await sandbox.reloadVolumes()
```

：：：筆記

將工作目錄保留在每個磁碟區掛載之外（例如`/workspace`). Modal can't reload a Volume that is the current working directory, so `ModalSandbox` throws if `workingDirectory` is at or inside a mount path.

:::

## 後台程式 {/* #background-processes */}

`ModalSandbox`包括一個內建的進程管理器，用於產生和管理後台進程。每個`spawn()` call creates a new `ContainerProcess` via the Modal SDK's `Sandbox.exec()` API.

```typescript
const sandbox = new ModalSandbox({ id: 'dev-sandbox' })
await sandbox._start()

// Spawn a background process
const handle = await sandbox.processes.spawn('node script.js', {
  env: { PORT: '3000' },
  onStdout: data => console.log(data),
})

// Wait for the process to complete
const result = await handle.wait()
console.log(result.exitCode)

// Kill the process
await handle.kill()
```

：：：筆記

`sendStdin()`不支援。 Modal JS SDK 不公開標準輸入`Sandbox.exec()`.

:::

看[`SandboxProcessManager` reference](/reference/workspace/process-manager) for the full API.
