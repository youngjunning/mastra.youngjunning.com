# Modal

在隔離的 [Modal](https://modal.com) 雲端 Sandbox 內執行指令。執行環境由 Modal 的基礎設施提供，安全且只供臨時使用。介面詳情見 [WorkspaceSandbox 介面](/reference/workspace/sandbox)。

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/modal
```

## 使用方法 {/* #usage */}

在 Workspace 加入 `ModalSandbox`，然後將該 Workspace 指派給 Agent：

```typescript
import { Agent } from '@mastra/core/agent'
import { Workspace } from '@mastra/core/workspace'
import { ModalSandbox } from '@mastra/modal'

const workspace = new Workspace({
  sandbox: new ModalSandbox({
    id: 'dev-sandbox',
    baseImage: 'ubuntu:22.04',
    timeoutMs: 60_000,
  }),
})

const agent = new Agent({
  id: 'dev-agent',
  model: '__GATEWAY_ANTHROPIC_MODEL_OPUS__',
  workspace,
})
```

## 身份驗證 {/* #authentication */}

可透過環境變數或建構函數的選項設定 Modal 憑證：

```bash
MODAL_TOKEN_ID=ak-...
MODAL_TOKEN_SECRET=as-...
```

也可將憑證直接傳入建構函數：

```typescript
const sandbox = new ModalSandbox({
  tokenId: process.env.MODAL_TOKEN_ID,
  tokenSecret: process.env.MODAL_TOKEN_SECRET,
})
```

憑證可在 [Modal 管理介面](https://modal.com/settings/tokens)取得。

## Sandbox 生命週期 {/* #sandbox-lifecycle */}

* **`_start()`**：嘗試重新連線至正在運行的 Sandbox。如找不到，便以先前呼叫 `_stop()` 時留下的最新快照建立 Sandbox。如沒有可用的快照，便以 `baseImage` 建立。
* **`_stop()`**：為檔案系統建立快照後終止 Sandbox。快照會留在同一實例的記憶體內，供日後啟動時使用。
* **`_destroy()`**：終止 Sandbox，並丟棄已保存的所有快照。

```typescript
const sandbox = new ModalSandbox({
  id: 'dev-sandbox',
  baseImage: 'ubuntu:22.04',
  timeoutMs: 300_000,
})

await sandbox._start()
await sandbox.processes.spawn('npm install')
await sandbox._stop()
await sandbox._start()
```

## 儲存卷及檔案保留 {/* #volumes-and-persistent-files */}

透過 `volumes` 選項掛載 [Modal Volumes](https://modal.com/docs/guide/volumes)，再用 `ModalFilesystem` 開放掛載路徑，讓 Agent 的 Workspace 檔案 Tool 存取。寫入掛載路徑下的檔案會在 Sandbox 重新啟動後保留。

```typescript
import { Workspace } from '@mastra/core/workspace'
import { ModalFilesystem, ModalSandbox } from '@mastra/modal'
import { ModalClient } from 'modal'

const modal = new ModalClient()
const privateVolume = await modal.volumes.fromName('agent-user-123', { createIfMissing: true })
const teamVolume = await modal.volumes.fromName('agent-team', { createIfMissing: true })

const sandbox = new ModalSandbox({
  id: 'agent-sandbox',
  workingDirectory: '/workspace',
  volumes: {
    '/mnt/agent': privateVolume,
    '/mnt/team': teamVolume,
  },
})

const workspace = new Workspace({
  sandbox,
  filesystem: new ModalFilesystem({ sandbox, basePath: '/mnt/agent' }),
})
```

`ModalFilesystem` 會在 Sandbox 內執行檔案操作，並將可存取的路徑全部限制在 `basePath` 範圍內。設定 `readOnly: true` 可阻止寫入。

只有重新載入後，才可看到其他 Sandbox 寫入同一儲存卷的變更。Sandbox 如需長期運行，可呼叫 `reloadVolumes()` 以讀取這些變更：

```typescript
await sandbox.reloadVolumes()
```

:::note

工作目錄應設於所有儲存卷的掛載路徑以外，例如 `/workspace`。Modal 無法重新載入目前工作目錄所在的儲存卷。因此，如 `workingDirectory` 是掛載路徑本身或其下的目錄，`ModalSandbox` 會拋出例外。

:::

## 背景程序 {/* #background-processes */}

`ModalSandbox` 內置程序管理器，可啟動和管理背景程序。每次呼叫 `spawn()`，都會經由 Modal SDK 的 `Sandbox.exec()` API 建立一個新的 `ContainerProcess`。

```typescript
const sandbox = new ModalSandbox({ id: 'dev-sandbox' })
await sandbox._start()

// Spawn a background process
const handle = await sandbox.processes.spawn('node script.js', {
  env: { PORT: '3000' },
  onStdout: data => console.log(data),
})

// Wait for the process to complete
const result = await handle.wait()
console.log(result.exitCode)

// Kill the process
await handle.kill()
```

:::note

`sendStdin()` 不受支援。Modal JS SDK 並無透過 `Sandbox.exec()` 提供存取標準輸入的方式。

:::

完整 API 見 [`SandboxProcessManager` 參考文件](/reference/workspace/process-manager)。
