# BrowserViewer

`@mastra/browser-viewer` 套件為 [agent-browser](https://www.npmjs.com/package/agent-browser)、[browser-use](https://pypi.org/project/browser-use/) 和 [browse](https://www.npmjs.com/package/browse) 等 CLI Tool 提供瀏覽器自動化功能。BrowserViewer 透過 Playwright 啟動 Chrome，提供 Chrome DevTools Protocol（CDP）URL，並自動將 URL 注入透過 [Sandbox Tool](/docs/sandbox/overview#using-the-sandbox) 執行的 CLI 命令。

## 何時使用 BrowserViewer {/* #when-to-use-browserviewer */}

如果 Agent 透過 CLI Tool 而非 SDK 控制瀏覽器，請使用 BrowserViewer。BrowserViewer 負責：

- 啟動及管理 Chrome，供 CLI Tool 連線
- 將 CDP URL 自動注入 `workspace_execute_command` 呼叫
- 將螢幕畫面即時串流至 Studio
- 按對話串隔離瀏覽器

如果透過 SDK 進行瀏覽器自動化，請改用 [AgentBrowser](/integrations/browsers/agent-browser) 或 [Stagehand](/integrations/browsers/stagehand)。

## 快速入門 {/* #quickstart */}

安裝 `@mastra/browser-viewer` 和 Agent 將使用的 CLI Tool。BrowserViewer 負責管理 Chrome，但 CLI Tool 必須另行安裝。

```bash npm2yarn
npm install @mastra/browser-viewer
```

在 Workspace 環境中安裝 CLI Tool。此例使用 `browser-use`：

```bash
pip install browser-use
```

安裝相應的[技能](/docs/sandbox/skills)，讓 Agent 知道如何使用該 CLI：

```bash
npx skills add browser-use/browser-use --skill browser-use
```

建立一個使用 BrowserViewer 的 Workspace，並將它指派給 Agent：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core/mastra'
import { Agent } from '@mastra/core/agent'
import { Memory } from '@mastra/memory'
import { LibSQLStore } from '@mastra/libsql'
import { Workspace, LocalSandbox } from '@mastra/core/workspace'
import { BrowserViewer } from '@mastra/browser-viewer'

const workspace = new Workspace({
  sandbox: new LocalSandbox({
    workingDirectory: './workspace',
  }),
  browser: new BrowserViewer({
    cli: 'browser-use',
    headless: false,
  }),
})

const browserAgent = new Agent({
  id: 'browser-agent',
  model: '__GATEWAY_OPENAI_MODEL__',
  workspace,
  instructions: `You are a web automation assistant.
Use browser-use commands to navigate and interact with websites.`,
  memory: new Memory(),
})

export const mastra = new Mastra({
  agents: { browserAgent },
  storage: new LibSQLStore({
    id: 'mastra-storage',
    url: 'file:./mastra.db',
  }),
})
```

當 Agent 執行瀏覽器 CLI 命令時，Mastra 會自動啟動 Chrome、將 CDP 連線傳給 CLI，並開始將螢幕畫面串流至 Studio。使用 Browser Use 時，Agent 可以透過 stdin 傳入 Python 程式碼：

```bash
browser-use <<'PY'
print("Connected to the managed browser")
PY
```

## 運作方式 {/* #how-it-works */}

1. Agent 呼叫 `workspace_execute_command`，並傳入瀏覽器 CLI 命令。
1. Mastra 偵測到 CLI 命令後，如果 Chrome 尚未執行，便會透過 Playwright 啟動 Chrome。
1. 系統將 CDP URL 注入命令，讓 CLI 連線至受管理的瀏覽器。
1. 螢幕畫面逐幀從頁面層級的 CDP 工作階段串流至 Studio。

## 支援的 CLI {/* #supported-clis */}

BrowserViewer 支援三個 CLI Provider。每個 CLI 都必須在 Workspace 環境中另行安裝。每個 CLI 亦有發佈一項[技能](/docs/sandbox/skills)，教 Agent 使用其命令和 Workflow。

將 `cli` 選項設定為 Agent 所使用的 CLI：

```typescript
const viewer = new BrowserViewer({
  cli: 'browser-use',
  headless: false,
})
```

### `agent-browser` {/* #agent-browser */}

```bash
npm install -g agent-browser
npx skills add vercel-labs/agent-browser
```

CDP 命令列選項：`--cdp`

### `browser-use` {/* #browser-use */}

```bash
pip install browser-use
npx skills add browser-use/browser-use --skill browser-use
```

直接透過 stdin 呼叫時（使用 `browser-use`、`browseruse`、`browser` 或 `bu`，後面可加上 `<` 重新導向或 heredoc），Mastra 會將 `BU_CDP_WS` 設定為受管理瀏覽器的 CDP URL，並將 `BU_NAME` 設定為固定的常駐程序名稱。每個對話串與瀏覽器端點的組合都有唯一名稱，因此重複呼叫會重用同一個常駐程序，而不同的對話串或端點則互相隔離。Mastra 會保留原有的 stdin 指令碼，並且不會加入 CLI 引數。

為維持相容性，Mastra 仍會為舊版子命令注入 `--cdp-url` 和 `--session`。透過 stdin 呼叫時，不會加入這些選項。

### `browse` {/* #browse */}

```bash
npm install -g browse
browse skills install
```

CDP 命令列選項：`--ws`。所有設定選項、進階連線模式及方法詳情，請參閱 [BrowserViewer 參考文件](/reference/browser/browser-viewer)。
