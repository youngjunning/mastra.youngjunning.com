# Firecrawl

`@mastra/browser-firecrawl` 套件透過 [Firecrawl Browser Sandbox](https://docs.firecrawl.dev/features/browser) 提供瀏覽器自動化功能。它透過 Firecrawl API 建立遠端瀏覽器工作階段，並使用與 [AgentBrowser](/integrations/browsers/agent-browser) 相同的 Tool 操控這些工作階段；這些 Tool 的行為具確定性，並以無障礙設計為優先。

`FirecrawlBrowser` 繼承 `AgentBrowser`，因此 Agent 可以使用同一組 Tool（例如 `browser_goto`、`browser_snapshot`、`browser_click`），而瀏覽器本身則在 Firecrawl 託管的基礎設施上運行。無需在本機安裝 Chromium。

## 何時使用 Firecrawl {/* #when-to-use-firecrawl */}

如有以下需要，可使用 Firecrawl：

- 使用託管的瀏覽器工作階段，無需管理本機的 Chromium 二進制檔案
- 在無法啟動本機瀏覽器的環境中執行瀏覽器自動化
- 為每個對話串提供獨立的 Sandbox，並自動清理工作階段
- 使用具名稱的 Firecrawl 設定檔，在不同工作階段之間保留 Cookie 和登入狀態

## 快速入門 {/* #quickstart */}

安裝套件：

```bash npm2yarn
npm install @mastra/browser-firecrawl
```

設定你的 Firecrawl API 密鑰：

```bash title=".env"
FIRECRAWL_API_KEY=fc-...
```

建立一個瀏覽器實例，並將它指派給 Agent：

```typescript title="src/mastra/agents/firecrawl-agent.ts"
import { Agent } from '@mastra/core/agent'
import { FirecrawlBrowser } from '@mastra/browser-firecrawl'

const browser = new FirecrawlBrowser({
  apiKey: process.env.FIRECRAWL_API_KEY,
})

export const firecrawlAgent = new Agent({
  id: 'firecrawl-agent',
  name: 'Firecrawl Agent',
  model: '__GATEWAY_OPENAI_MODEL__',
  browser,
  instructions: `You are a web automation assistant.

When interacting with pages:
1. Use browser_snapshot to get the current page state and element refs
2. Use the refs (like @e1, @e2) to target elements for clicks and typing
3. After actions, take another snapshot to verify the result`,
})
```

如未指定 `apiKey`，Provider 會讀取環境變數 `FIRECRAWL_API_KEY`。

## 工作階段範圍 {/* #session-scope */}

`FirecrawlBrowser` 的 `scope` 選項與 `AgentBrowser` 相同：

- `'thread'`（預設）：每個對話串都有獨立的 Firecrawl Sandbox 工作階段。對話串的瀏覽器關閉時，該工作階段便會被刪除。
- `'shared'`：所有對話串共用同一個 Firecrawl Sandbox 工作階段。瀏覽器關閉時，該工作階段便會被刪除。

```typescript
const browser = new FirecrawlBrowser({
  scope: 'shared',
})
```

## 工作階段選項 {/* #session-options */}

透過 `firecrawl` 鍵傳入 Firecrawl 專用的工作階段選項。這些選項對應 Firecrawl 的 `browser()` API：

```typescript
const browser = new FirecrawlBrowser({
  firecrawl: {
    ttl: 600,
    activityTtl: 120,
    profile: {
      name: 'my-profile',
      saveChanges: true,
    },
  },
})
```

- `ttl`：工作階段的最長存續時間，以秒為單位。
- `activityTtl`：工作階段可閒置的時間，以秒為單位。超過此時間後，Firecrawl 便會回收該工作階段。
- `profile`：具名稱的 Firecrawl 設定檔，用於保留 Cookie 和登入狀態。設定 `saveChanges: true`，即可在工作階段結束時儲存對設定檔的修改。

:::note

巢狀選項 `firecrawl.profile` 指向儲存在 Firecrawl 基礎設施上的設定檔。從 `AgentBrowser` 繼承的頂層 `profile` 選項則是本機 Playwright 使用者資料目錄的路徑。

:::

## 自行託管 Firecrawl {/* #self-hosted-firecrawl */}

要使用自行託管的 Firecrawl API，請設定 `apiUrl`：

```typescript
const browser = new FirecrawlBrowser({
  apiUrl: 'https://firecrawl.internal.example.com',
})
```
