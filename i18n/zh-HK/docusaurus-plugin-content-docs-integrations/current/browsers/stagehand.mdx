# Stagehand

`@mastra/stagehand` 套件透過 Browserbase 的 [Stagehand SDK](https://docs.browserbase.com/stagehand/introduction) 提供瀏覽器自動化功能。Stagehand 利用 AI 理解網頁的上下文，按自然語言描述定位元素，毋須明確指定選擇器。

## 何時使用 Stagehand {/* #when-to-use-stagehand */}

如有以下需要，可使用 Stagehand：

- 用自然語言定位元素，例如「選取登入按鈕」
- 利用 AI 從網頁擷取資料
- 使用原生的 Browserbase 雲端整合
- 透過較簡單的工具介面執行常用操作

## 快速入門 {/* #quickstart */}

安裝套件：

```bash npm2yarn
npm install @mastra/stagehand
```

建立瀏覽器實例，並將它傳給 Agent：

```typescript title="src/mastra/agents/stagehand-agent.ts"
import { Agent } from '@mastra/core/agent'
import { StagehandBrowser } from '@mastra/stagehand'

const browser = new StagehandBrowser({
  headless: false,
  model: '__GATEWAY_OPENAI_MODEL__',
})

export const stagehandAgent = new Agent({
  id: 'stagehand-agent',
  name: 'Stagehand Agent',
  model: '__GATEWAY_OPENAI_MODEL__',
  browser,
  instructions: `You are a web automation assistant.

Use stagehand tools to interact with pages:
- stagehand_navigate to go to URLs
- stagehand_act to perform actions described in natural language
- stagehand_extract to get structured data from the page
- stagehand_observe to find available actions on the page
- stagehand_screenshot to visually inspect the page`,
})
```

## 自然語言操作 {/* #natural-language-actions */}

Agent 可透過 `stagehand_act` 工具執行以自然語言描述的操作，例如：

- 「按一下登入按鈕」
- 「在電郵欄位輸入 `'[user@example.com](mailto:user@example.com)'`」
- 「在國家或地區下拉選單中選擇『美國』」

Stagehand 會利用 AI 理解指令，並找出網頁上相應的元素。

## 資料擷取 {/* #data-extraction */}

Agent 可使用 `stagehand_extract` 工具從網頁擷取結構化資料。

示例指令：「擷取產品名稱、價格及供貨狀況」

工具會根據網頁內容傳回結構化資料：

```json
{
  "name": "Widget Pro",
  "price": "$29.99",
  "availability": "In Stock"
}
```

## 查看可用操作 {/* #observing-actions */}

Agent 可使用 `stagehand_observe` 工具分析目前的網頁，並取得可執行的操作。

示例指令：「我可以在這個登入表格上做哪些操作？」

工具會傳回可用操作的列表：

```json
[
  { "action": "Press 'Sign In' button", "element": "button" },
  { "action": "Type in 'Email' field", "element": "input" },
  { "action": "Open 'Forgot Password' link", "element": "a" }
]
```

## 螢幕截圖 {/* #screenshots */}

Agent 使用 `stagehand_screenshot` 工具時，工具會擷取目前網頁的 PNG 截圖，並以支援視覺輸入的模型可直接解讀的圖片內容傳回。

如需查看網頁的圖片、版面或顏色，可使用螢幕截圖。處理文字或結構化資料時，請使用 `stagehand_extract` 或 `stagehand_observe`。

```typescript
const browser = new StagehandBrowser({
  headless: false,
  model: '__GATEWAY_OPENAI_MODEL__',
})
```

如模型不支援視覺輸入，可透過 `excludeTools` 停用截圖工具：

```typescript
const browser = new StagehandBrowser({
  headless: false,
  model: '__GATEWAY_OPENAI_MODEL__',
  excludeTools: ['stagehand_screenshot'],
})
```

## Browserbase {/* #browserbase */}

Stagehand 原生整合 Browserbase，可使用其雲端瀏覽器基礎設施：

```typescript
const browser = new StagehandBrowser({
  env: 'BROWSERBASE',
  apiKey: process.env.BROWSERBASE_API_KEY,
  projectId: process.env.BROWSERBASE_PROJECT_ID,
  model: '__GATEWAY_OPENAI_MODEL__',
})
```

所有設定選項均可參閱 [StagehandBrowser 參考文件](/reference/browser/stagehand-browser)。

## 錄製瀏覽器操作 {/* #recording */}

你可在 Stagehand 啟用瀏覽器錄製工具（Beta）：

```typescript
const browser = new StagehandBrowser({
  headless: false,
  model: '__GATEWAY_OPENAI_MODEL__',
  recording: {
    outputDir: './browser-recordings',
  },
})
```

啟用後，Agent 可使用 `browser_record` 和 `browser_record_caption` 工具。詳情請參閱[瀏覽器錄製（Beta）](/docs/browser#record-browser-sessions)。
