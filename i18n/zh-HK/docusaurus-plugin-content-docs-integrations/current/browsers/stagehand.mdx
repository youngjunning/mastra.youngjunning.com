# 舞台工作人員

這`@mastra/stagehand`包提供瀏覽器自動化使用[舞台操作者​​SDK](https://docs.browserbase.com/stagehand/introduction)來自瀏覽器庫。 Stagehand 使用人工智慧來理解頁面上下文並定位元素，從而實現自然語言描述而不是明確選擇器。

## 何時使用舞台工作人員 {/* #when-to-use-stagehand */}

當您需要時使用 Stagehand：

* 自然語言元素定位（“選擇登入按鈕”）
* 由人工智慧驅動的頁面資料提取
* 原生 Browserbase 雲端集成
* 用於常見操作的更簡單的Tool介面

## 快速入門 {/* #quickstart */}

安裝包：

```bash npm2yarn
npm install @mastra/stagehand
```

建立一個瀏覽器實例並將其指派給Agent：

```typescript title="src/mastra/agents/stagehand-agent.ts"
import { Agent } from '@mastra/core/agent'
import { StagehandBrowser } from '@mastra/stagehand'

const browser = new StagehandBrowser({
  headless: false,
  model: '__GATEWAY_OPENAI_MODEL__',
})

export const stagehandAgent = new Agent({
  id: 'stagehand-agent',
  name: 'Stagehand Agent',
  model: '__GATEWAY_OPENAI_MODEL__',
  browser,
  instructions: `You are a web automation assistant.

Use stagehand tools to interact with pages:
- stagehand_navigate to go to URLs
- stagehand_act to perform actions described in natural language
- stagehand_extract to get structured data from the page
- stagehand_observe to find available actions on the page
- stagehand_screenshot to visually inspect the page`,
})
```

## 自然語言動作 {/* #natural-language-actions */}

當Agent使用`stagehand_act` tool, it accepts natural language descriptions of actions:

* “按下登入按鈕”
* 「類型`'[user@example.com](mailto:user@example.com)'` in the email field"
* “從國家/地區下拉清單中選擇‘美國’”

Stagehand 的人工智慧會解釋該動作並在頁面上找到適當的元素。

## 資料擷取 {/* #data-extraction */}

當Agent使用`stagehand_extract` tool, it can pull structured data from pages.

範例說明：“提取產品名稱、價格和供貨情況”

該Tool根據頁面內容返回結構化資料：

```json
{
  "name": "Widget Pro",
  "price": "$29.99",
  "availability": "In Stock"
}
```

## 觀察行動 {/* #observing-actions */}

當Agent使用`stagehand_observe` tool, it analyzes the current page and returns possible actions.

範例說明：“我可以在此登入表單上執行哪些操作？”

傳回可用操作的清單：

```json
[
  { "action": "Press 'Sign In' button", "element": "button" },
  { "action": "Type in 'Email' field", "element": "input" },
  { "action": "Open 'Forgot Password' link", "element": "a" }
]
```

## 截圖 {/* #screenshots */}

當Agent使用`stagehand_screenshot` tool, it captures a PNG image of the current page and returns it as image content that vision-capable models can interpret directly.

當您需要目視檢查頁面時，例如評估圖像、佈局或顏色，請使用螢幕截圖。對於文字或結構化數據，請使用`stagehand_extract` or `stagehand_observe` instead.

```typescript
const browser = new StagehandBrowser({
  headless: false,
  model: '__GATEWAY_OPENAI_MODEL__',
})
```

若要停用不支援視覺的模型的螢幕截圖Tool，請使用`excludeTools`:

```typescript
const browser = new StagehandBrowser({
  headless: false,
  model: '__GATEWAY_OPENAI_MODEL__',
  excludeTools: ['stagehand_screenshot'],
})
```

## 瀏覽器庫 {/* #browserbase */}

Stagehand 具有針對雲端瀏覽器基礎架構的原生 Browserbase 整合：

```typescript
const browser = new StagehandBrowser({
  env: 'BROWSERBASE',
  apiKey: process.env.BROWSERBASE_API_KEY,
  projectId: process.env.BROWSERBASE_PROJECT_ID,
  model: '__GATEWAY_OPENAI_MODEL__',
})
```

看[StagehandBrowser reference](/reference/browser/stagehand-browser) for all configuration options.

## 記錄 {/* #recording */}

舞台工作人員可以選擇使用 Beta 瀏覽器錄製Tool：

```typescript
const browser = new StagehandBrowser({
  headless: false,
  model: '__GATEWAY_OPENAI_MODEL__',
  recording: {
    outputDir: './browser-recordings',
  },
})
```

這增加了`browser_record` and `browser_record_caption` to the agent's toolset. See [Browser recording (Beta)](/docs/browser#record-browser-sessions) for details.
