# AgentBrowser

`@mastra/agent-browser` 套件使用 Playwright 提供瀏覽器自動化功能，並優先透過無障礙資訊定位元素。套件以頁面無障礙樹中的引用識別元素，讓操作在不同頁面版面配置下保持可靠。

## 何時使用 AgentBrowser {/* #when-to-use-agentbrowser */}

如有以下需要，可使用 AgentBrowser：

- 透過無障礙樹中的引用可靠地定位元素
- 精細控制瀏覽器操作
- 使用 Playwright 可靠的自動化功能
- 支援鍵盤快速鍵及複雜互動

## 快速入門 {/* #quickstart */}

安裝套件：

```bash npm2yarn
npm install @mastra/agent-browser
```

建立瀏覽器實例，並將它指派給 Agent：

```typescript title="src/mastra/agents/browser-agent.ts"
import { Agent } from '@mastra/core/agent'
import { AgentBrowser } from '@mastra/agent-browser'

const browser = new AgentBrowser({
  headless: false,
})

export const browserAgent = new Agent({
  id: 'browser-agent',
  name: 'Browser Agent',
  model: '__GATEWAY_OPENAI_MODEL__',
  browser,
  instructions: `You are a web automation assistant.

When interacting with pages:
1. Use browser_snapshot to get the current page state and element refs
2. Use the refs (like @e1, @e2) to target elements for clicks and typing
3. After actions, take another snapshot to verify the result`,
})
```

:::note

在本機啟動瀏覽器時（預設方式），AgentBrowser 需要透過 Playwright 安裝的 Chromium 執行檔。安裝 `@mastra/agent-browser` 時，通常會自動下載此執行檔。如果瀏覽器啟動失敗並顯示 `"browser executable is missing"`，請執行 `npx playwright install chromium`。如果透過 [`cdpUrl`](/reference/browser/agent-browser) 選項連線至遠端瀏覽器，則由遠端瀏覽器提供 Chromium。

:::

## 截圖 {/* #screenshots */}

Agent 使用 `browser_screenshot` Tool 時，該 Tool 會擷取目前頁面的 PNG 截圖，並以圖像內容傳回，讓具備視覺能力的 Model 直接解讀。

需要檢查頁面的視覺效果時，例如評估圖像、版面配置或顏色，請使用截圖。如需文字或結構化資料，請改用 `browser_snapshot`。

如要為不支援視覺的 Model 停用截圖 Tool，請使用 `excludeTools`：

```typescript
const browser = new AgentBrowser({
  headless: false,
  excludeTools: ['browser_screenshot'],
})
```

## 元素引用 {/* #element-refs */}

AgentBrowser 使用無障礙樹中的引用識別元素。Agent 呼叫 `browser_snapshot` 時，會收到頁面的文字表示，其中包含 `@e1`、`@e2` 等引用。Agent 隨後可將這些引用與其他 Tool 一併使用，以操作相關元素。

## 錄影 {/* #recording */}

你可以為 AgentBrowser 啟用 Beta 版瀏覽器錄影 Tool：

```typescript
const browser = new AgentBrowser({
  headless: false,
  recording: {
    outputDir: './browser-recordings',
  },
})
```

這會將 `browser_record` 和 `browser_record_caption` 加入 Agent 的 Tool 集合。詳情請參閱[瀏覽器錄影（Beta）](/docs/browser#record-browser-sessions)。所有設定選項和 Tool 詳情請參閱 [AgentBrowser 參考文件](/reference/browser/agent-browser)。
