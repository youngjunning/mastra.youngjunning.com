# OpenUI

[OpenUI](https://openui.com) 是生成式介面的開放標準。它以串流為優先，將精簡的 OpenUI Lang 語言、React 運行環境和內置組件庫結合起來，讓模型輸出在串流期間逐步渲染成結構化介面。

OpenUI 透過 [AG-UI 協議](https://docs.ag-ui.com) 連接 Mastra。`@ag-ui/mastra` 適配器封裝 Mastra `Agent`，並發出 AG-UI 事件；OpenUI 的 `agUIAdapter()` 則在客戶端解析這些事件。

:::tip

OpenUI 代碼庫的 [`mastra-chat`](https://github.com/thesysdev/openui/tree/main/examples/mastra-chat) 提供完整、可運行的示例。

:::

## 整合指引 {/* #integration-guide */}

將 Mastra 嵌入 Next.js API 路由，然後透過 AG-UI 協議把 OpenUI 的 `<AgentInterface />` 聊天介面接駁至該路由。

<Steps>
  <StepItem>
    用樣板建立新的 OpenUI 應用程式：

    ```bash npm2yarn
    npx @openuidev/cli@latest create --name openui-mastra-chat
    ```

    進入剛建立的項目目錄：

    ```bash
    cd openui-mastra-chat
    ```

    產生的應用程式是 Next.js 項目，結構如下：

    ```bash
    openui-mastra-chat
    └── src
        ├── app
        │   ├── api
        │   │   └── chat
        │   │       └── route.ts
        │   ├── globals.css
        │   ├── layout.tsx
        │   └── page.tsx
        ├── generated
        │   └── system-prompt.txt
        └── library.ts
    ```

    `src/app/api/chat/route.ts` 是聊天路由，`src/app/page.tsx` 是聊天介面，而 `src/library.ts` 是組件庫。OpenUI CLI 會按組件庫產生 `src/generated/system-prompt.txt`；每次修改組件庫後，請重新產生這個檔案。

    將 OpenAI 密鑰加到 `.env.local`：

    ```bash title=".env.local"
    OPENAI_API_KEY=sk-...
    ```

    :::note

    OpenUI 需要模型 Provider 的 API 密鑰。你可以使用 Mastra 支援的任何 Provider，並在下一步相應調整 Agent 設定。

    :::
  </StepItem>

  <StepItem>
    安裝 Mastra 套件及供 Mastra 使用的 AG-UI 適配器：

    ```bash npm2yarn
    npm install @mastra/core @ag-ui/mastra @ag-ui/core zod
    ```

    `@ag-ui/mastra` 把 Mastra `Agent` 封裝在 `MastraAgent` 內，由 `MastraAgent` 發出 [AG-UI 協議](https://docs.ag-ui.com)事件。OpenUI 的 `agUIAdapter()` 會在客戶端接收這些事件。
  </StepItem>

  <StepItem>
    打開 `src/app/api/chat/route.ts`，以 `@mastra/core/tools` 提供的 `createTool` 定義 Agent 所需的 Tool：

    ```typescript title="src/app/api/chat/route.ts"
    import { createTool } from '@mastra/core/tools'
    import { z } from 'zod'

    const getWeather = createTool({
      id: 'get_weather',
      description: 'Get current weather for a city.',
      inputSchema: z.object({ location: z.string().describe('City name') }),
      execute: async ({ location }) => {
        return { location, temperature_celsius: 22, condition: 'Clear' }
      },
    })
    ```

    將 Mastra `Agent` 封裝在 `MastraAgent` 內，再注入產生的系統提示，指示 Agent 如何使用 OpenUI 組件庫：

    ```typescript title="src/app/api/chat/route.ts"
    import { MastraAgent } from '@ag-ui/mastra'
    import { Agent } from '@mastra/core/agent'
    import { readFileSync } from 'fs'
    import { join } from 'path'

    const systemPrompt = readFileSync(join(process.cwd(), 'src/generated/system-prompt.txt'), 'utf-8')

    const agent = new MastraAgent({
      agent: new Agent({
        id: 'openui-agent',
        name: 'OpenUI Agent',
        instructions: `You are a helpful assistant. Use tools when relevant.\n\n${systemPrompt}`,
        model: {
          id: '__GATEWAY_OPENAI_MODEL__',
          apiKey: process.env.OPENAI_API_KEY,
        },
        tools: { getWeather },
      }),
      resourceId: 'chat-user',
    })
    ```

    匯出 `POST` 處理函數，以伺服器發送事件（SSE）的形式串流傳送 Agent 的 AG-UI 事件：

    ```typescript title="src/app/api/chat/route.ts"
    import type { Message } from '@ag-ui/core'
    import { NextRequest } from 'next/server'

    export async function POST(req: NextRequest) {
      const { messages, threadId }: { messages: Message[]; threadId: string } = await req.json()
      const encoder = new TextEncoder()

      const stream = new ReadableStream({
        start(controller) {
          const subscription = agent
            .run({ messages, threadId, runId: crypto.randomUUID(), tools: [], context: [] })
            .subscribe({
              next: event => {
                controller.enqueue(encoder.encode(`data: ${JSON.stringify(event)}\n\n`))
              },
              complete: () => {
                controller.enqueue(encoder.encode('data: [DONE]\n\n'))
                controller.close()
              },
              error: error => {
                controller.enqueue(
                  encoder.encode(`data: ${JSON.stringify({ error: error.message })}\n\n`),
                )
                controller.close()
              },
            })

          req.signal.addEventListener('abort', () => subscription.unsubscribe())
        },
      })

      return new Response(stream, {
        headers: {
          'Content-Type': 'text/event-stream',
          'Cache-Control': 'no-cache, no-transform',
          Connection: 'keep-alive',
        },
      })
    }
    ```
  </StepItem>

  <StepItem>
    將 OpenUI 的 `<AgentInterface />` 聊天介面接駁至該路由。用 `fetchLLM()` 建立 `llm` 適配器，並將 `streamAdapter` 設為 `agUIAdapter()`，讓 OpenUI 可以解析 AG-UI 事件。

    ```tsx title="src/app/page.tsx" {5,8-11,17}
    'use client'

    import '@openuidev/react-ui/components.css'

    import { AgentInterface, agUIAdapter, fetchLLM } from '@openuidev/react-ui'
    import { openuiChatLibrary } from '@openuidev/react-ui/genui-lib'

    const llm = fetchLLM({
      url: '/api/chat',
      streamAdapter: agUIAdapter(),
    })

    export default function Page() {
      return (
        <div className="relative h-screen w-screen overflow-hidden">
          <AgentInterface llm={llm} componentLibrary={openuiChatLibrary} />
        </div>
      )
    }
    ```

    `componentLibrary` 屬性控制模型可生成哪些組件。若要限制或擴展輸出，可用自己的組件庫取代 `openuiChatLibrary`。
  </StepItem>

  <StepItem>
    啟動開發伺服器：

    ```bash npm2yarn
    npm run dev
    ```

    打開 [http://localhost:3000](http://localhost:3000)，即可在 OpenUI 聊天介面與 Mastra Agent 對話。模型一邊串流輸出，結構化介面一邊渲染。
  </StepItem>
</Steps>

## 使用 AG-UI 串流 {/* #streaming-with-ag-ui */}

OpenUI 接收 [AG-UI 協議](https://docs.ag-ui.com)所定義的事件串流。這套協議為 AI Agent 提供有類型的事件，不受特定傳輸方式限制。`@ag-ui/mastra` 會將 Mastra `Agent` 的輸出轉成符合協議的事件：

* 伺服器呼叫 `agent.run({ messages, threadId, runId, ... })`，並將發出的每個事件序列化成一則 SSE 訊息。
* 客戶端把 `fetchLLM({ streamAdapter: agUIAdapter() })` 的傳回值交給 `<AgentInterface />`。該組件會把 SSE 串流解析成內部事件，用來驅動 OpenUI Lang 渲染。

`threadId` 將屬於同一段對話的請求連起來，`runId` 則標識單次執行。每次請求都要產生新的 `runId`，並在客戶端持久儲存 `threadId`。

## 組件庫 {/* #component-libraries */}

OpenUI 按組件庫生成介面。組件庫定義可用的組件及其屬性，亦定義怎樣指示模型使用這些組件。

### 內置組件庫 {/* #built-in-libraries */}

`@openuidev/react-ui` 提供兩個可直接使用的組件庫：

* `openuiChatLibrary`：適合聊天介面的組件，包括卡片、表單、表格和圖表。
* `openuiDashboardLibrary`：適合儀表板及需要展示大量數據的介面組件。

透過 `<AgentInterface componentLibrary={...} />` 傳入組件庫，模型便可使用庫內的組件。

### 自訂組件庫 {/* #customizing-the-library */}

如要限制或擴展輸出，可在 `src/library.ts` 定義自己的組件庫，並匯出選定的組件。把組件庫傳給 `<AgentInterface />`，每次修改組件庫後都要重新產生系統提示：

```bash npm2yarn
npx @openuidev/cli generate src/library.ts --out src/generated/system-prompt.txt
```

API 路由會讀取產生的系統提示，並合併到 Agent 的 `instructions`，讓 Agent 清楚知道可以輸出哪些組件。
