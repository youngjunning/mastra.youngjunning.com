# Assistant UI

[Assistant UI](https://assistant-ui.com) 是用於開發 AI 聊天功能的 TypeScript/React 程式庫。它建基於 shadcn/ui 和 Tailwind CSS，讓開發人員在數分鐘內建立美觀的企業級聊天介面。

:::note

如要在 Next.js API 路由內直接運行 Mastra，請參閱 Assistant UI 文件網站的[全棧整合指南](https://www.assistant-ui.com/docs/integrations/frameworks/mastra/full-stack)。

:::

到 Mastra 的 [**UI Dojo**](https://ui-dojo.mastra.ai/) 可查看 Assistant UI 與 Mastra 整合的實際例子。

## 整合指南 {/* #integration-guide */}

獨立運行 Mastra 伺服器，再把採用 Assistant UI 的 Next.js 前端接駁到該伺服器的 API 端點。

<Steps>
  <StepItem>
    先安排項目的目錄結構，例如：

    ```bash
    project-root
    ├── mastra-server
    │   ├── src
    │   │   └── mastra
    │   └── package.json
    └── my-app
        └── package.json
    ```

    初始化 Mastra 伺服器項目：

    ```bash
    npx create-mastra@latest
    ```

    這個指令會啟動互動式設定嚮導。按照提示輸入項目名稱並完成基本設定，即可建立 Mastra 伺服器項目。

    進入剛建立的 Mastra 伺服器目錄：

    ```bash
    cd mastra-server # Replace with the actual directory name you provided
    ```

    基本的 Mastra 伺服器項目已建立，目錄內應包含以下檔案和資料夾：

    ```bash
    src
    └── mastra
        ├── agents
        │   └── weather-agent.ts
        ├── scorers
        │   └── weather-scorer.ts
        ├── tools
        │   └── weather-tool.ts
        ├── workflows
        │   └── weather-workflow.ts
        └── index.ts
    ```

    :::note

    確認已在 `.env` 檔案內為所用的 LLM Provider 設定所需的環境變數。

    :::
  </StepItem>

  <StepItem>
    利用 `@mastra/ai-sdk` 的 `chatRoute()` 輔助函數，為 Assistant UI 前端建立聊天路由。先把套件安裝到 Mastra 項目：

    ```bash npm2yarn
    npm install @mastra/ai-sdk@latest
    ```

    在 `src/mastra/index.ts` 內註冊聊天路由：

    ```typescript title="src/mastra/index.ts" {2,7-13}
    import { Mastra } from '@mastra/core/mastra'
    import { chatRoute } from '@mastra/ai-sdk'
    // Rest of the imports...

    export const mastra = new Mastra({
      // Rest of the configuration...
      server: {
        apiRoutes: [
          chatRoute({
            path: '/chat/:agentId',
          }),
        ],
      },
    })
    ```

    註冊後，所有 Agent 都會以兼容 AI SDK 的格式回應。例如，透過 `/chat/weatherAgent` 端點便可存取 `weatherAgent`。
  </StepItem>

  <StepItem>
    執行以下指令啟動 Mastra 伺服器：

    ```bash
    npm run dev
    ```

    Mastra 伺服器預設在 `http://localhost:4111` 運行。請保持伺服器運行，稍後會設定 Assistant UI 前端連接到這個位址。
  </StepItem>

  <StepItem>
    返回上一層目錄，即項目的根目錄。

    ```bash
    cd ..
    ```

    用以下指令建立新的 `assistant-ui` 項目。

    ```bash
    npx assistant-ui@latest create
    ```

    :::note

    有關加入 API 密鑰、基本設定及手動設定的詳細步驟，請參閱 [Assistant UI 官方文件](https://assistant-ui.com/docs)。

    :::
  </StepItem>

  <StepItem>
    Assistant UI 的聊天執行環境預設使用 Next.js 項目內的本機 API 路由（`/api/chat`）。由於 Mastra Agent 在獨立的伺服器上運行，需要修改前端設定，使其連接到該伺服器的端點。

    在 Assistant UI 前端項目中，開啟包含 `useChatRuntime` Hook 的檔案，通常是 `app/assistant.tsx` 或 `src/app/assistant.tsx`。找到 `useChatRuntime` 的呼叫位置，將 `api` 屬性改為 Mastra Agent 串流端點的完整 URL：

    ```tsx {8} title="app/assistant.tsx"
    'use client'

    // Rest of the imports...

    export const Assistant = () => {
      const runtime = useChatRuntime({
        transport: new AssistantChatTransport({
          api: 'http://localhost:4111/chat/weatherAgent',
        }),
      })

      // Rest of the component...
    }
    ```

    完成設定後，Assistant UI 前端會直接向正在運行的 Mastra 伺服器發送聊天請求。
  </StepItem>

  <StepItem>
    確保 Mastra 伺服器繼續運行，並啟動 Next.js 開發伺服器，讓 Assistant UI 前端同時運行：

    ```bash
    npm run dev
    ```

    現在應該可以在瀏覽器裏與 Agent 聊天。
  </StepItem>
</Steps>

整合完成後，Assistant UI 前端會與獨立運行的 Mastra Agent 伺服器通訊。
