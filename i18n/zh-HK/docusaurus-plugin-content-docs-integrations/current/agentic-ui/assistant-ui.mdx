# 助理介面

[助理介面](https://assistant-ui.com)是用於 AI 聊天的 TypeScript/React 函式庫。它基於 shadcn/ui 和 Tailwind CSS 構建，使開發人員能夠在幾分鐘內創建精美的企業級聊天體驗。

：：：筆記

對於 Mastra 直接在 Next.js API 路由中運行的全端整合方法，請參閱[Full-Stack Integration Guide](https://www.assistant-ui.com/docs/integrations/frameworks/mastra/full-stack) on Assistant UI's documentation site.

:::

參觀馬斯特拉[**"UI Dojo"**](https://ui-dojo.mastra.ai/) to see real-world examples of Assistant UI integrated with Mastra.

## 整合指南 {/* #integration-guide */}

將 Mastra 作為獨立伺服器運行，並將 Next.js 前端（帶有 Assistant UI）連接到其 API 端點。

<Steps>
  <StepItem>
    設定您的目錄結構。可能的目錄結構如下圖所示：

    ```bash
    project-root
    ├── mastra-server
    │   ├── src
    │   │   └── mastra
    │   └── package.json
    └── my-app
        └── package.json
    ```

    引導您的 Mastra 伺服器：

    ```bash
    npx create-mastra@latest
    ```

    此命令將啟動一個互動式精靈來幫助您建立新的 Mastra 項目，包括提示您輸入項目名稱和設定基本配置。依照提示建立伺服器項目。

    導航到新建立的 Mastra 伺服器目錄：

    ```bash
    cd mastra-server # Replace with the actual directory name you provided
    ```

    您現在已經準備好了一個基本的 Mastra 伺服器專案。您應該擁有以下文件和資料夾：

    ```bash
    src
    └── mastra
        ├── agents
        │   └── weather-agent.ts
        ├── scorers
        │   └── weather-scorer.ts
        ├── tools
        │   └── weather-tool.ts
        ├── workflows
        │   └── weather-workflow.ts
        └── index.ts
    ```

    ：：：筆記

    確保您已在中為您的 LLM 提供者設定了適當的環境變量`.env` file.

    :::
  </StepItem>

  <StepItem>
    使用以下命令為 Assistant UI 前端建立聊天路由`chatRoute()` helper from `@mastra/ai-sdk`. Add it to your Mastra project:

    ```bash npm2yarn
    npm install @mastra/ai-sdk@latest
    ```

    在你的`src/mastra/index.ts` file, register the chat route:

    ```typescript title="src/mastra/index.ts" {2,7-13}
    import { Mastra } from '@mastra/core/mastra'
    import { chatRoute } from '@mastra/ai-sdk'
    // Rest of the imports...

    export const mastra = new Mastra({
      // Rest of the configuration...
      server: {
        apiRoutes: [
          chatRoute({
            path: '/chat/:agentId',
          }),
        ],
      },
    })
    ```

    這將使所有Agent程式以 AI SDK 相容的格式提供，包括`weatherAgent` at the endpoint `/chat/weatherAgent`.
  </StepItem>

  <StepItem>
    使用以下命令運行 Mastra 伺服器：

    ```bash
    npm run dev
    ```

    預設情況下，Mastra 伺服器將運行在`http://localhost:4111`. Keep this server running for the next steps where we'll set up the Assistant UI frontend to connect to it.
  </StepItem>

  <StepItem>
    上一層目錄到您的專案根目錄。

    ```bash
    cd ..
    ```

    創建一個新的`assistant-ui` project with the following command.

    ```bash
    npx assistant-ui@latest create
    ```

    ：：：筆記

    有關詳細設定說明，包括新增 API 金鑰、基本配置和手動設定步驟，請參閱[assistant-ui's official documentation](https://assistant-ui.com/docs).

    :::
  </StepItem>

  <StepItem>
    預設的 Assistant UI 設定將聊天執行時間配置為使用本機 API 路由（`/api/chat`) within the Next.js project. Since our Mastra agent is running on a separate server, we need to update the frontend to point to that server's endpoint.

    在 Assistant-ui 前端專案中開啟包含以下內容的文件`useChatRuntime` hook (usually `app/assistant.tsx` or `src/app/assistant.tsx`). Find the `useChatRuntime` hook and change the `api` property to the full URL of your Mastra agent's stream endpoint:

    ```tsx {8} title="app/assistant.tsx"
    'use client'

    // Rest of the imports...

    export const Assistant = () => {
      const runtime = useChatRuntime({
        transport: new AssistantChatTransport({
          api: 'http://localhost:4111/chat/weatherAgent',
        }),
      })

      // Rest of the component...
    }
    ```

    現在，Assistant UI 前端將直接向您正在執行的 Mastra 伺服器發送聊天請求。
  </StepItem>

  <StepItem>
    您已準備好連接各個部分了！確保 Mastra 伺服器和 Assistant UI 前端都在運作。啟動 Next.js 開發伺服器：

    ```bash
    npm run dev
    ```

    現在您應該可以在瀏覽器中與您的Agent程式聊天。
  </StepItem>
</Steps>

恭喜！您已使用單獨的伺服器方法成功地將 Mastra 與 Assistant UI 整合。您的 Assistant UI 前端現在與獨立的 Mastra Agent伺服器進行通訊。
