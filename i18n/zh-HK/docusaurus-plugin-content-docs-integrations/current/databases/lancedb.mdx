# LanceDB

LanceDB 的儲存實作以 LanceDB 資料庫系統提供高效能儲存，擅長處理傳統資料儲存和向量操作。

:::warning[不支援 Observability]

LanceDB 儲存**不支援 Observability 領域**。來自 `MastraStorageExporter` 的 Trace 無法持久儲存至 LanceDB。如果 LanceDB 是唯一的儲存 Provider，[Studio](/docs/studio/overview) 的 Observability 功能將無法運作。要啟用 Observability，請使用[複合儲存](/reference/storage/composite#specialized-storage-for-observability)，將 Observability 資料轉送至支援這類資料的 Provider，例如 ClickHouse。

:::

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/lance@latest
```

## 用法 {/* #usage */}

### 基本儲存用法 {/* #basic-storage-usage */}

```typescript
import { LanceStorage } from '@mastra/lance'

// Connect to a local database
const storage = await LanceStorage.create('my-storage', '/path/to/db')

// Connect to a LanceDB cloud database
const storage = await LanceStorage.create('my-storage', 'db://host:port')

// Connect to a cloud database with custom options
const storage = await LanceStorage.create('my-storage', 's3://bucket/db', {
  storageOptions: { timeout: '60s' },
})
```

## 補充說明 {/* #additional-notes */}

### 資料結構管理 {/* #schema-management */}

LanceStorage 會自動建立及更新資料結構，並將 Mastra 的資料結構類型對應至 LanceDB 內部使用的 Apache Arrow 資料類型：

- `text`, `uuid` → Utf8
- `int`, `integer` → Int32
- `float` → Float32
- `jsonb`, `json` → Utf8（已序列化）
- `binary` → Binary

### 初始化 {/* #initialization */}

將儲存實例傳入 Mastra 類別後，系統會在執行任何儲存操作之前自動呼叫 `init()`：

```typescript
import { Mastra } from '@mastra/core'
import { LanceStorage } from '@mastra/lance'

const storage = await LanceStorage.create('my-storage', '/path/to/db')

const mastra = new Mastra({
  storage, // init() is called automatically
})
```

如果不經 Mastra 而直接使用儲存實例，必須明確呼叫 `init()` 來建立資料表：

```typescript
import { LanceStorage } from '@mastra/lance'

const storage = await LanceStorage.create('my-storage', '/path/to/db')

// Required when using storage directly
await storage.init()

// Access domain-specific stores via getStore()
const memoryStore = await storage.getStore('memory')
const thread = await memoryStore?.getThreadById({ threadId: '...' })
```

:::warning
如果沒有呼叫 `init()`，系統便不會建立資料表，而儲存操作可能會在沒有提示的情況下失敗，或拋出錯誤。
:::

### 部署選項 {/* #deployment-options */}

你可以按不同的部署情境設定 LanceDB 儲存：

- **本機開發**：使用本機檔案路徑進行開發和測試
  ```text
  /path/to/db
  ```
- **雲端部署**：連線至託管的 LanceDB 實例
  ```text
  db://host:port
  ```
- **S3 儲存**：使用 Amazon S3 提供大容量雲端儲存
  ```text
  s3://bucket/db
  ```

### 資料表管理 {/* #table-management */}

LanceStorage 提供以下資料表管理方法：

- 使用自訂資料結構建立資料表
- 刪除資料表
- 清空資料表（刪除所有記錄）
- 按鍵值載入記錄
- 插入單筆記錄或批量插入記錄
