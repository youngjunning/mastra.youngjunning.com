# 瓦爾基

Valkey 儲存實作透過以下方式提供持久性儲存和伺服器端快取：[Valkey GLIDE](https://github.com/valkey-io/valkey-glide)客戶。當您的部署運行 Valkey 或需要 GLIDE 功能（例如本機 Valkey 配置和身份驗證）時，請使用它。

使用[`@mastra/redis`](/integrations/databases/redis) for Redis deployments that use the official `redis`客戶。這些軟體包針對各自的伺服器進行獨立測試。

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/valkey
```

## 用法 {/* #usage */}

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { ValkeyStore } from '@mastra/valkey'

export const mastra = new Mastra({
  storage: new ValkeyStore({
    id: 'valkey-storage',
    host: 'localhost',
    port: 6379,
    password: process.env.VALKEY_PASSWORD,
  }),
})
```

您也可以提供本機 GLIDE 配置：

```typescript
import { ValkeyStore } from '@mastra/valkey'

const storage = new ValkeyStore({
  id: 'valkey-storage',
  config: {
    addresses: [{ host: 'localhost', port: 6379 }],
    useTLS: true,
  },
})
```

對於現有的`GlideClient`, connect it before passing it to `ValkeyStore`. The caller remains responsible for closing injected clients.

`ValkeyStore`需要一個獨立的 Valkey 伺服器。 Valkey 集群和`GlideClusterClient` aren't supported.

## 關閉連接 {/* #closing-connections */}

關閉已建立的客戶`ValkeyStore` during graceful shutdown:

```typescript
await storage.close()
```

`close()`不關閉注入的`GlideClient`.
