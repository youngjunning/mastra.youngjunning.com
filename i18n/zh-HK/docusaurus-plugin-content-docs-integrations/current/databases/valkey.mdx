# Valkey

Valkey 的儲存實作透過 [Valkey GLIDE](https://github.com/valkey-io/valkey-glide) 用戶端提供持久化儲存和伺服器端快取。如果部署環境運行 Valkey，或需要 GLIDE 提供的功能，例如 Valkey 原生設定及身份驗證，請使用此實作。

如果部署的 Redis 使用官方 `redis` 用戶端，請使用 [`@mastra/redis`](/integrations/databases/redis)。這些套件各自在對應的伺服器上獨立測試。

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/valkey
```

## 用法 {/* #usage */}

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { ValkeyStore } from '@mastra/valkey'

export const mastra = new Mastra({
  storage: new ValkeyStore({
    id: 'valkey-storage',
    host: 'localhost',
    port: 6379,
    password: process.env.VALKEY_PASSWORD,
  }),
})
```

你也可以提供 GLIDE 原生設定：

```typescript
import { ValkeyStore } from '@mastra/valkey'

const storage = new ValkeyStore({
  id: 'valkey-storage',
  config: {
    addresses: [{ host: 'localhost', port: 6379 }],
    useTLS: true,
  },
})
```

如果使用現有的 `GlideClient`，請先建立連線，再將它傳入 `ValkeyStore`。注入的用戶端仍由呼叫方負責關閉。

`ValkeyStore` 需要獨立運行的 Valkey 伺服器。目前不支援 Valkey Cluster 或 `GlideClusterClient`。

## 關閉連線 {/* #closing-connections */}

在正常關閉程序期間，關閉由 `ValkeyStore` 建立的用戶端：

```typescript
await storage.close()
```

`close()` 不會關閉注入的 `GlideClient`。
