# 極光DSQL

Aurora DSQL 儲存實作使用 Amazon Aurora DSQL 和 IAM 驗證提供儲存。

Aurora DSQL 不支援 PostgreSQL 擴充（`CREATE EXTENSION`), including `pgvector`。對於向量存儲，請使用單獨的向量存儲，例如`@mastra/s3vectors`.

## 安裝 {/* #installation */}

```bash copy
npm install @mastra/dsql@beta
```

## 先決條件 {/* #prerequisites */}

* Amazon Aurora DSQL 叢集
* 有權存取 DSQL 叢集的 AWS 憑證（IAM 驗證）

## 用法 {/* #usage */}

```typescript copy showLineNumbers
import { DSQLStore } from '@mastra/dsql'

const storage = new DSQLStore({
  id: 'my-dsql-store',
  host: 'abc123.dsql.us-east-1.on.aws',
  // region is auto-detected from host, or specify explicitly:
  // region: 'us-east-1',
  // user: 'admin', // default
  // database: 'postgres', // default
})

// Initialize the store (creates tables if needed)
await storage.init()
```

## 構造函數範例 {/* #constructor-examples */}

你可以實例化`DSQLStore` in the following ways:

```typescript copy showLineNumbers
import { DSQLStore } from '@mastra/dsql'

// Basic configuration (region auto-detected from host)
const store1 = new DSQLStore({
  id: 'my-dsql-store',
  host: 'abc123.dsql.us-east-1.on.aws',
})

// With explicit region and schema
const store2 = new DSQLStore({
  id: 'my-dsql-store',
  host: 'abc123.dsql.us-east-1.on.aws',
  region: 'us-east-1',
  schemaName: 'my_app',
})

// With custom credentials provider
import { fromNodeProviderChain } from '@aws-sdk/credential-providers'

const store3 = new DSQLStore({
  id: 'my-dsql-store',
  host: 'abc123.dsql.us-east-1.on.aws',
  customCredentialsProvider: fromNodeProviderChain(),
})

// With connection pool settings
const store4 = new DSQLStore({
  id: 'my-dsql-store',
  host: 'abc123.dsql.us-east-1.on.aws',
  max: 20,
  min: 2,
  idleTimeoutMillis: 300000,
  maxLifetimeSeconds: 3000,
  connectionTimeoutMillis: 10000,
})

// Using a pre-configured pg.Pool
import { Pool } from 'pg'
import { AuroraDSQLClient } from '@aws/aurora-dsql-node-postgres-connector'

const pool = new Pool({
  host: 'abc123.dsql.us-east-1.on.aws',
  Client: AuroraDSQLClient,
  region: 'us-east-1',
})

const store5 = new DSQLStore({
  id: 'my-dsql-store',
  pool,
})
```

## 附加說明 {/* #additional-notes */}

### 模式管理 {/* #schema-management */}

儲存實作自動處理模式建立和更新。它會建立以下表：

* `mastra_workflow_snapshot`：儲存Workflow狀態和執行數據
* `mastra_threads`：儲存對話線程
* `mastra_messages`：儲存單獨的訊息
* `mastra_ai_spans`：儲存跨度資料以供觀察
* `mastra_scorers`：儲存評分和評價數據
* `mastra_resources`：儲存資源工作記憶體數據
* `mastra_agents`：儲存Agent數據

### 初始化 {/* #initialization */}

當您將儲存空間傳遞給 Mastra 類別時，`init()` is called automatically before any storage operation:

```typescript copy showLineNumbers
import { Mastra } from '@mastra/core'
import { DSQLStore } from '@mastra/dsql'

const storage = new DSQLStore({
  id: 'my-dsql-store',
  host: 'abc123.dsql.us-east-1.on.aws',
})

const mastra = new Mastra({
  storage, // init() is called automatically
})
```

如果您直接使用儲存空間而不使用 Mastra，則必須致電`init()` explicitly to create the tables:

```typescript copy showLineNumbers
import { DSQLStore } from '@mastra/dsql'

const storage = new DSQLStore({
  id: 'my-dsql-store',
  host: 'abc123.dsql.us-east-1.on.aws',
})

// Required when using storage directly
await storage.init()

// Access domain-specific stores via getStore()
const memoryStore = await storage.getStore('memory')
const thread = await memoryStore?.getThreadById({ threadId: '...' })
```

:::警告
如果`init()` isn't called, tables won't be created and storage operations will fail silently or throw errors.
:::

### 直接資料庫和池訪問 {/* #direct-database-and-pool-access */}

`DSQLStore`將底層資料庫用戶端和 pg.Pool 執行個體公開為公用欄位：

```typescript copy showLineNumbers
storage.db // Database client for executing queries
storage.pool // Underlying pg.Pool instance
```

它支援直接查詢和自訂事務管理。使用這些欄位時：

* 您負責正確的連接和事務處理。
* 關閉商店（`storage.close()`) will destroy the connection pool if it was created by the store.
* 直接存取會繞過 DSQLStore 方法提供的任何附加邏輯或驗證。

此方法適用於需要低階存取的高階場景。

### Aurora DSQL 細節 {/* #aurora-dsql-specifics */}

#### 僅 IAM 身份驗證 {/* #iam-only-authentication */}

連線透過 IAM 進行身份驗證。不需要資料庫密碼。`@mastra/dsql` uses `@aws/aurora-dsql-node-postgres-connector` to generate short-lived auth tokens. You can provide a custom credentials provider via `customCredentialsProvider`.

#### 單一資料庫、基於模式的隔離 {/* #single-database-schema-based-isolation */}

每個集群公開一個資料庫`postgres`. Logical separation is done via schemas. The `schemaName` option controls where Mastra tables are created.

#### 沒有 PostgreSQL 擴展 {/* #no-postgresql-extensions */}

`CREATE EXTENSION`不支援。這包括`pgvector`, `PostGIS`, and others. For vector storage, use a separate store such as `@mastra/s3vectors` alongside `DSQLStore`.

#### JSON 儲存為文字 {/* #json-stored-as-text */}

JSON/JSONB 可用作查詢類型，但不能用作列類型。`@mastra/dsql` stores structured fields (metadata, content, etc.) in `TEXT` columns and casts to JSON at query time.

#### 架構和 DDL 約束 {/* #schema-and-ddl-constraints */}

某些 PostgreSQL 功能不可用：

* 外鍵約束
* `TRUNCATE`
* 同步`CREATE INDEX`

索引是使用非同步建立的`CREATE INDEX ASYNC`. The store's `init()` and index helper APIs respect these constraints.

#### 事務和樂觀並發 {/* #transactions-and-optimistic-concurrency */}

Aurora DSQL 使用樂觀並發控制 (OCC)，並且在爭用情況下可能會傳回可重試的 OCC 錯誤。交易持續時間和規模有限制。大批量操作應在應用程式層級拆分為較小的批次。

#### 連接壽命 {/* #connection-lifetime */}

個人轉機時間限制在 60 分鐘左右。預設`maxLifetimeSeconds: 3300` ensures connections are recycled before hitting this limit.

## 使用範例 {/* #usage-example */}

### 為Agent添加內存 {/* #adding-memory-to-an-agent */}

若要將 Aurora DSQL 記憶體新增至Agent，請使用`Memory` class and create a new `storage` key using `DSQLStore`. The `host` should point to your Aurora DSQL cluster endpoint.

```typescript title="src/mastra/agents/example-dsql-agent.ts" copy showLineNumbers
import { Memory } from '@mastra/memory'
import { Agent } from '@mastra/core/agent'
import { DSQLStore } from '@mastra/dsql'

export const dsqlAgent = new Agent({
  id: 'dsql-agent',
  name: 'DSQL Agent',
  instructions:
    'You are an AI agent with the ability to automatically recall memories from previous interactions.',
  model: '__GATEWAY_OPENAI_MODEL__',
  memory: new Memory({
    storage: new DSQLStore({
      id: 'dsql-agent-storage',
      host: process.env.DSQL_HOST!,
    }),
    options: {
      generateTitle: true, // Explicitly enable automatic title generation
    },
  }),
})
```

### 使用Agent {/* #using-the-agent */}

使用`memoryOptions` to scope recall for this request. Set `lastMessages: 5` to limit recency-based recall, and use `semanticRecall` to fetch the `topK: 3` most relevant messages, including `messageRange: 2` neighboring messages for context around each match.

```typescript title="src/test-dsql-agent.ts" copy showLineNumbers
import 'dotenv/config'

import { mastra } from './mastra'

const threadId = '123'
const resourceId = 'user-456'

const agent = mastra.getAgent('dsql-agent')

const message = await agent.stream('My name is Mastra', {
  memory: {
    thread: threadId,
    resource: resourceId,
  },
})

await message.textStream.pipeTo(new WritableStream())

const stream = await agent.stream("What's my name?", {
  memory: {
    thread: threadId,
    resource: resourceId,
  },
  memoryOptions: {
    lastMessages: 5,
    semanticRecall: {
      topK: 3,
      messageRange: 2,
    },
  },
})

for await (const chunk of stream.textStream) {
  process.stdout.write(chunk)
}
```

## 指數管理 {/* #index-management */}

Aurora DSQL 儲存提供索引管理功能來最佳化查詢效能。

### 自動性能指標 {/* #automatic-performance-indexes */}

Aurora DSQL 儲存在初始化期間會自動為常見查詢模式建立複合索引：

* `mastra_threads_resourceid_createdat_idx`: (資源 ID、創建時間)
* `mastra_messages_thread_id_createdat_idx`: (thread\_id, 創建時間)
* `mastra_ai_spans_traceid_startedat_idx`: (traceId, 開始時間)
* `mastra_ai_spans_parentspanid_startedat_idx`: (parentSpanId, 開始時間)
* `mastra_ai_spans_name_idx`： （姓名）
* `mastra_ai_spans_spantype_startedat_idx`: (spanType, 開始時間)
* `mastra_scores_trace_id_span_id_created_at_idx`: (traceId、spanId、createAt)

Aurora DSQL 使用非同步建立這些索引`CREATE INDEX ASYNC`. Because index creation is asynchronous, new indexes may not be immediately available after `init()`. The store will continue to function without them, but queries may be slower until index creation completes.

### 建立自訂索引 {/* #creating-custom-indexes */}

建立額外的索引來優化特定的查詢模式：

```typescript copy showLineNumbers
await storage.createIndex({
  name: 'idx_threads_resource',
  table: 'mastra_threads',
  columns: ['resourceId'],
})

await storage.createIndex({
  name: 'idx_messages_composite',
  table: 'mastra_messages',
  columns: ['thread_id', 'createdAt'],
})
```

Aurora DSQL 不允許`ASC`/`DESC` in `CREATE INDEX ASYNC`. If you include them, they will be automatically stripped.

### 特定於模式的索引 {/* #schema-specific-indexes */}

使用自訂架構時，索引是使用架構前綴建立的：

```typescript copy showLineNumbers
const storage = new DSQLStore({
  id: 'my-dsql-store',
  host: 'abc123.dsql.us-east-1.on.aws',
  schemaName: 'custom_schema',
})

// Creates index as: custom_schema_idx_threads_status
await storage.createIndex({
  name: 'idx_threads_status',
  table: 'mastra_threads',
  columns: ['status'],
})
```
