# MSSQL

MSSQL 儲存實作採用 Microsoft SQL Server，可用於生產環境。

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/mssql@latest
```

## 用法 {/* #usage */}

```typescript
import { MSSQLStore } from '@mastra/mssql'

const storage = new MSSQLStore({
  id: 'mssql-storage',
  connectionString: process.env.DATABASE_URL,
})
```

## 建構函數示例 {/* #constructor-examples */}

你可以用連線字串建立 `MSSQLStore` 實例，也可以分別提供各項連線參數。兩種做法均可配合自訂 Schema。

```ts
import { MSSQLStore } from '@mastra/mssql'

// Using a connection string only
const store1 = new MSSQLStore({
  id: 'mssql-storage-1',
  connectionString:
    'Server=localhost,1433;Database=mydb;User Id=sa;Password=password;Encrypt=true;TrustServerCertificate=true',
})

// Using a connection string with a custom schema name
const store2 = new MSSQLStore({
  id: 'mssql-storage-2',
  connectionString:
    'Server=localhost,1433;Database=mydb;User Id=sa;Password=password;Encrypt=true;TrustServerCertificate=true',
  schemaName: 'custom_schema', // optional
})

// Using individual connection parameters
const store4 = new MSSQLStore({
  id: 'mssql-storage-3',
  server: 'localhost',
  port: 1433,
  database: 'mydb',
  user: 'user',
  password: 'password',
})

// Individual parameters with schemaName
const store5 = new MSSQLStore({
  id: 'mssql-storage-4',
  server: 'localhost',
  port: 1433,
  database: 'mydb',
  user: 'user',
  password: 'password',
  schemaName: 'custom_schema', // optional
})
```

## 附加說明 {/* #additional-notes */}

### Schema 管理 {/* #schema-management */}

儲存實作會自動建立和更新 Schema，並建立以下資料表。

- `mastra_workflow_snapshot`：儲存 Workflow 的狀態及執行資料
- `mastra_evals`：儲存評估結果及元資料
- `mastra_threads`：儲存對話線程
- `mastra_messages`：儲存每則訊息
- `mastra_traces`：儲存遙測及追蹤資料
- `mastra_scorers`：儲存評分及評估資料
- `mastra_resources`：儲存資源的工作記憶資料

### 初始化 {/* #initialization */}

將儲存實例傳給 Mastra 類別後，Mastra 會先自動呼叫 `init()`，然後才執行儲存操作。

```typescript
import { Mastra } from '@mastra/core'
import { MSSQLStore } from '@mastra/mssql'

const storage = new MSSQLStore({
  connectionString: process.env.DATABASE_URL,
})

const mastra = new Mastra({
  storage, // init() is called automatically
})
```

如直接使用儲存實例而不經 Mastra，就必須自行呼叫 `init()` 來建立資料表。

```typescript
import { MSSQLStore } from '@mastra/mssql'

const storage = new MSSQLStore({
  id: 'mssql-storage',
  connectionString: process.env.DATABASE_URL,
})

// Required when using storage directly
await storage.init()

// Access domain-specific stores via getStore()
const memoryStore = await storage.getStore('memory')
const thread = await memoryStore?.getThreadById({ threadId: '...' })
```

:::warning
如未呼叫 `init()`，資料表便不會建立，儲存操作可能無聲失敗，亦可能拋出錯誤。
:::

### 直接存取資料庫及連線池 {/* #direct-database-and-pool-access */}

`MSSQLStore` 以公開欄位提供 mssql 連線池。

```typescript
store.pool // mssql connection pool instance
```

透過連線池，你可以直接執行查詢，亦可自行管理交易。

- 你須自行妥善處理連線及交易。
- 呼叫 `store.close()` 關閉儲存實例時，相關的連線池亦會被銷毀。
- 直接存取會繞過 MSSQLStore 方法提供的額外邏輯或驗證。

此做法適用於需要直接使用底層資料庫介面的進階情況。
