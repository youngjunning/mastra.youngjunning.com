# Neon Postgres

[Neon](https://neon.com) 是託管式 PostgreSQL 服務。Mastra 使用 [`PostgresStore`](/integrations/databases/postgresql) 連接 Neon；它採用 Node.js 的 `pg` 驅動程式，毋須為 Neon 另外安裝專用的 Mastra 儲存套件。

透過 [Mastra Connect](#connect)，Agent 亦可使用工具管理 Neon 項目及分支、執行 SQL，以及套用資料庫結構遷移。

## 快速入門 {/* #quickstart */}

建立 Neon 項目，然後將項目的[連線池連線字串](https://neon.com/docs/connect/connect-from-any-app)複製到 `DATABASE_URL`。

安裝 PostgreSQL 儲存套件：

```bash npm2yarn
npm install @mastra/pg@latest
```

將連線池的連線字串傳入 `PostgresStore`：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core/mastra'
import { PostgresStore } from '@mastra/pg'

export const mastra = new Mastra({
  storage: new PostgresStore({
    id: 'neon-storage',
    connectionString: process.env.DATABASE_URL!,
  }),
})
```

Mastra 啟動時會呼叫 `storage.init()`，在 Neon 建立所需的資料表及索引。

## 使用 CLI 設定 Neon {/* #set-up-neon-with-the-cli */}

Neon CLI 需要 Node.js 20.19 或更高版本。

安裝 [Neon CLI](https://neon.com/docs/cli/install)：

```bash npm2yarn
npm install -g neon
```

在項目目錄下執行以下指令，以連結現有 Neon 項目或建立新項目：

```bash
neon link
```

`neon link` 會提示你登入，將項目資訊寫入 `.neon`，並取得目前分支的環境變數。如需更新這些變數，再執行 `neon env pull`：

```bash
neon env pull
```

指令會將 `DATABASE_URL` 及 `DATABASE_URL_UNPOOLED` 寫入 `.env.local`。如已有 `.env` 檔案，則寫入該檔案。

### 加入 `neon.ts` {/* #add-neonts */}

如要在程式碼倉庫內管理分支設定，請建立 [`neon.ts`](https://neon.com/docs/reference/neon-ts) 檔案：

```bash
neon config init
```

這項指令會安裝 `@neon/config` 及 `@neon/env`，並建立一份初始設定。以下策略為例，新建的非預設分支會在七日後到期：

```typescript title="neon.ts"
import { defineConfig } from '@neon/config/v1'

export default defineConfig({
  branch: branch => {
    if (branch.isDefault) {
      return {}
    }

    if (!branch.exists) {
      return { ttl: '7d' }
    }

    return {}
  },
})
```

套用設定：

```bash
neon deploy
```

## 安裝 Neon Agent Skills {/* #install-neon-agent-skills */}

在項目目錄下安裝 [`neon` 及 `neon-postgres` Agent Skills](https://neon.com/docs/ai/agent-skills)：

```bash npm2yarn
npx skills add neondatabase/agent-skills --skill neon --skill neon-postgres -y
```

這些 Skill 為兼容的編程 Agent 提供 Neon 的設定步驟及 Postgres 專用指引。

## 正式環境的資料庫連線 {/* #production-connections */}

Neon 提供兩種連線字串，分別用於直接連線及經連線池連線：

- `DATABASE_URL` 經 Neon 的連線池端點連線，用於處理應用程式的日常流量。
- `DATABASE_URL_UNPOOLED` 直接連接到 Postgres，用於在應用程式以外執行的管理工作或資料庫結構變更。

大部分應用程式可沿用快速入門的 `DATABASE_URL`，經連線池連線，並由 Mastra 在啟動時初始化資料庫結構。`PostgresStore` 支援經事務級連線池執行初始化。

### 獨立初始化資料庫結構 {/* #separate-schema-initialization */}

如應用程式運行時所用的資料庫角色不應建立資料表或索引，請在部署時透過直接連線初始化資料庫結構：

```typescript title="scripts/init-storage.ts"
import { PostgresStore } from '@mastra/pg'

const storage = new PostgresStore({
  id: 'neon-storage-init',
  connectionString: process.env.DATABASE_URL_UNPOOLED!,
})

try {
  await storage.init()
} finally {
  await storage.close()
}
```

資料庫結構建立後，應用程式運行時可改用連線池，並停用自動初始化：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core/mastra'
import { PostgresStore } from '@mastra/pg'

export const mastra = new Mastra({
  storage: new PostgresStore({
    id: 'neon-storage',
    connectionString: process.env.DATABASE_URL!,
    disableInit: true,
  }),
})
```

詳情請參閱 [Neon 連線池文件](https://neon.com/docs/connect/connection-pooling)。

## 向量搜尋 {/* #vector-search */}

Neon 支援 [`pgvector` 擴充功能](https://neon.com/docs/extensions/pgvector)。建立擴充功能及索引時，請使用 `DATABASE_URL_UNPOOLED` 直接連線。完成設定後，請設定 [`PgVector`](/integrations/vectors/pg)，讓應用程式在運行時經連線池執行查詢：

```typescript
import { PgVector } from '@mastra/pg'

const vector = new PgVector({
  id: 'neon-vector',
  connectionString: process.env.DATABASE_URL!,
  disableInit: true,
})
```

設定 `disableInit: true` 後，應用程式的程序在運行時不會建立或修改擴充功能、資料表及索引。
