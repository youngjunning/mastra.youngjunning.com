# OracleDB

OracleDB 儲存 Provider 把 Mastra 應用程式的狀態存入 Oracle Database。由於它實現了 Mastra 的複合儲存介面，只需一個 `OracleStore` 實例，便可儲存記憶、Workflow 快照、可觀測性資料、評分、評分器定義、MCP 客戶端元資料和 Agent 登記冊資料。

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/oracledb@latest
```

## 用法 {/* #usage */}

```ts
import { OracleStore } from '@mastra/oracledb'

const storage = new OracleStore({
  id: 'oracle-storage',
  user: process.env.ORACLE_DATABASE_USER,
  password: process.env.ORACLE_DATABASE_PASSWORD,
  connectString: process.env.ORACLE_DATABASE_CONNECT_STRING,
})
```

將這個儲存實例交給 Mastra 使用：

```ts
import { Mastra } from '@mastra/core/mastra'

export const mastra = new Mastra({
  storage,
})
```

## 連線示例 {/* #connection-examples */}

上面的例子以用戶名稱和密碼建立儲存實例。如要連接 Autonomous Database，只須在同一個建構函數中加入錢包選項：

```ts
const storage = new OracleStore({
  id: 'oracle-storage',
  user: process.env.ORACLE_DATABASE_USER,
  password: process.env.ORACLE_DATABASE_PASSWORD,
  connectString: process.env.ORACLE_DATABASE_CONNECT_STRING,
  walletLocation: process.env.ORACLE_DATABASE_WALLET_DIR,
  walletPassword: process.env.ORACLE_DATABASE_WALLET_PASSWORD,
  configDir: process.env.ORACLE_DATABASE_CONFIG_DIR,
})
```

如要使用外部身分驗證，請設定 `externalAuth: true`，並略去 `password`。要沿用現有的 `oracledb.Pool`，可將它作為 `pool` 傳入。Mastra 會使用該連線池，但不會關閉它。

`OracleStore` 可儲存記憶、Workflow 快照、可觀測性資料、評分、評分器定義、MCP 客戶端元資料和 Agent 登記冊資料。如不經 `Mastra` 實例而直接使用這個儲存實例，請先呼叫 `await storage.init()`，再用 `await storage.getStore('memory')` 存取相應的儲存範疇。

## 初始化 {/* #initialization */}

把 `OracleStore` 傳給 `Mastra` 後，Mastra 會在執行儲存操作前自動呼叫 `init()`。如直接使用 `OracleStore`，便須在讀寫前呼叫 `init()`：

```ts
await storage.init()
```

:::warning
如停用或略過初始化，必須先建立所需的 Oracle 資料表和索引，才可執行儲存操作。
:::

`OracleStore.init()` 會執行可重複運行的遷移，並把結果寫入遷移記錄表。預設表名是 `MASTRA_ORACLE_MIGRATIONS`。

```ts
await storage.migrate()
const history = await storage.listMigrations()
```

這些可重複執行的遷移具備冪等性。啟動時，遷移會把各個儲存範疇的資料表和索引調整至預期狀態，讓你毋須修改應用程式碼，便可加入新的範疇索引或相容的資料庫結構擴充。

初始化期間亦會建立這個 Provider 的預設索引，供 Mastra 的常用查詢使用。如索引另行管理，請使用 `skipDefaultIndexes`；要加入自訂 Oracle 索引，則傳入 `indexes`。自訂索引定義支援 `bitmap`、`online`、`invisible`、`parallel`、`compress`、`noLogging` 和 `reverse` 等 Oracle 選項，以及 `JSON_VALUE(...)` 等以函數為基礎的表達式。

如應用程式經常按 JSON 元資料篩選，或者資料庫管理員（DBA）想在查詢優化器採用索引前先測試，便可使用自訂索引：

```ts
const storage = new OracleStore({
  id: 'oracle-storage',
  user,
  password,
  connectString,
  indexes: [
    {
      name: 'idx_messages_status',
      table: 'mastra_messages',
      columns: [
        "JSON_VALUE(metadata, '$.status' RETURNING VARCHAR2(32) NULL ON ERROR)",
        'thread_id',
      ],
      online: true,
      invisible: true,
    },
  ],
})
```

分階段推出索引時，可先使用 `invisible`，驗證查詢計劃後再移除該選項。只有在資料庫管理員負責的索引策略已取代預設索引的情況下，才使用 `skipDefaultIndexes: true`。

如資料庫結構變更由獨立部署步驟執行，或由資料庫管理員處理，請使用 `disableInit: true`。

## 匯出資料庫結構 {/* #schema-export */}

用 `exportSchemas()` 產生 Oracle DDL，毋須連接資料庫。若要在應用程式啟動流程以外審核或執行資料庫結構變更，這個方法尤其有用。

```ts
import { exportSchemas } from '@mastra/oracledb'

const ddl = exportSchemas({
  schemaName: 'MASTRA_APP',
  domains: [
    'memory',
    'workflows',
    'observability',
    'scores',
    'scorerDefinitions',
    'mcpClients',
    'agents',
  ],
})

console.log(ddl)
```

如略去 `domains`，則預設涵蓋全部受支援的儲存範疇，包括 `vector`。

## 運作注意事項 {/* #operational-notes */}

如要統一管理 `OracleStore` 和 `OracleVector` 的 Oracle 連線生命週期，請讓兩者共用同一個 `OraclePoolManager`：

```ts
import { OracleStore, OracleVector } from '@mastra/oracledb'

const storage = new OracleStore({ id: 'oracle-storage', user, password, connectString })
const vector = new OracleVector({
  id: 'oracle-vector',
  poolManager: storage.getPoolManager(),
})
```

在較進階的使用情況下，可透過 `OracleStore` 提供的 `storage.db` 和 `await storage.getPool()` 存取資料庫和連線池。直接使用這些 API 時，須自行管理交易邊界和連線生命週期。

JSON 元資料、承載資料及快照存於 Oracle 原生 JSON 欄位，並在伺服器端編碼。因此，可用 DBeaver 和 SQL Developer 等標準 Oracle JDBC 工具直接讀取這些資料列。

## 使用示例 {/* #usage-example */}

### 為 Agent 加入以 OracleDB 儲存的記憶 {/* #adding-oracledb-memory-to-an-agent */}

```ts title="src/mastra/agents/oracle-agent.ts"
import { Agent } from '@mastra/core/agent'
import { Memory } from '@mastra/memory'
import { OracleStore } from '@mastra/oracledb'

const storage = new OracleStore({
  id: 'oracle-storage',
  user: process.env.ORACLE_DATABASE_USER,
  password: process.env.ORACLE_DATABASE_PASSWORD,
  connectString: process.env.ORACLE_DATABASE_CONNECT_STRING,
})

export const oracleAgent = new Agent({
  id: 'oracle-agent',
  name: 'Oracle Agent',
  instructions: 'You are an assistant with persistent OracleDB-backed memory.',
  model: '__GATEWAY_OPENAI_MODEL__',
  memory: new Memory({ storage }),
})
```
