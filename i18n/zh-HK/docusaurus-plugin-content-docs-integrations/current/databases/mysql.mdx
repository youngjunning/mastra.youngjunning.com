# MySQL

使用`MySQLStore`將 Mastra 應用程式資料（包括訊息、Workflow、追蹤、分數和其他儲存域）保存在 MySQL 資料庫中。

## 安裝 {/* #installation */}

儲存提供者必須作為單獨的套件安裝：

```bash npm2yarn
npm install @mastra/mysql@latest
```

## 用法 {/* #usage */}

添加`MySQLStore` to your Mastra configuration with a MySQL connection string:

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MySQLStore } from '@mastra/mysql'

export const mastra = new Mastra({
  storage: new MySQLStore({
    id: 'mysql-storage',
    connectionString: process.env.MYSQL_URL!,
  }),
})
```

例如，`MYSQL_URL` can use the format `mysql://user:password@host:3306/database`.

### 基於主機的配置 {/* #host-based-configuration */}

您可以提供單獨的連接字段而不是連接字串：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MySQLStore } from '@mastra/mysql'

export const mastra = new Mastra({
  storage: new MySQLStore({
    id: 'mysql-storage',
    host: process.env.MYSQL_HOST!,
    port: Number(process.env.MYSQL_PORT ?? 3306),
    user: process.env.MYSQL_USER!,
    password: process.env.MYSQL_PASSWORD,
    database: process.env.MYSQL_DATABASE!,
  }),
})
```

## 初始化 {/* #initialization */}

當您註冊儲存空間時`Mastra`, `init()` is called automatically to create the [core schema](/reference/storage/overview#core-schema):

```typescript
const storage = new MySQLStore({
  id: 'mysql-storage',
  connectionString: process.env.MYSQL_URL!,
})

export const mastra = new Mastra({
  storage, // init() is called automatically
})
```

直接使用儲存時無需`Mastra`, call `init()` before accessing domain stores:

```typescript
const storage = new MySQLStore({
  id: 'mysql-storage',
  connectionString: process.env.MYSQL_URL!,
})

await storage.init()

const memoryStore = await storage.getStore('memory')
```

## 生產 {/* #production */}

使用 Mastra 部署可以存取的持久性 MySQL 資料庫。將憑證儲存在環境變數中，並在資料庫提供者需要時啟用 SSL。
