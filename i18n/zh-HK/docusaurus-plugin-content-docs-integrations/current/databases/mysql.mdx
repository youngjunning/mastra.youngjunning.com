# MySQL

透過 `MySQLStore`，可在 MySQL 資料庫持久儲存 Mastra 應用程式的訊息、Workflow、追蹤記錄、評分及其他儲存範疇的資料。

## 安裝 {/* #installation */}

儲存 Provider 必須以獨立套件安裝：

```bash npm2yarn
npm install @mastra/mysql@latest
```

## 使用方法 {/* #usage */}

在 Mastra 配置中加入 `MySQLStore`，並提供 MySQL 連接字串：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MySQLStore } from '@mastra/mysql'

export const mastra = new Mastra({
  storage: new MySQLStore({
    id: 'mysql-storage',
    connectionString: process.env.MYSQL_URL!,
  }),
})
```

例如，`MYSQL_URL` 可採用 `mysql://user:password@host:3306/database` 格式。

### 按欄位配置連接 {/* #host-based-configuration */}

如不使用連接字串，可分別填寫各個連接欄位：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MySQLStore } from '@mastra/mysql'

export const mastra = new Mastra({
  storage: new MySQLStore({
    id: 'mysql-storage',
    host: process.env.MYSQL_HOST!,
    port: Number(process.env.MYSQL_PORT ?? 3306),
    user: process.env.MYSQL_USER!,
    password: process.env.MYSQL_PASSWORD,
    database: process.env.MYSQL_DATABASE!,
  }),
})
```

## 初始化 {/* #initialization */}

向 `Mastra` 註冊儲存實例時，系統會自動呼叫 `init()`，建立[核心資料庫結構](/reference/storage/overview#core-schema)：

```typescript
const storage = new MySQLStore({
  id: 'mysql-storage',
  connectionString: process.env.MYSQL_URL!,
})

export const mastra = new Mastra({
  storage, // init() is called automatically
})
```

如不經 `Mastra` 直接使用儲存實例，須先呼叫 `init()`，才可存取各範疇的儲存區：

```typescript
const storage = new MySQLStore({
  id: 'mysql-storage',
  connectionString: process.env.MYSQL_URL!,
})

await storage.init()

const memoryStore = await storage.getStore('memory')
```

## 正式運行環境 {/* #production */}

請使用可持久儲存資料、並可從 Mastra 部署環境存取的 MySQL 資料庫。把連接憑證存放在環境變數內，並按資料庫 Provider 的要求啟用 SSL。
