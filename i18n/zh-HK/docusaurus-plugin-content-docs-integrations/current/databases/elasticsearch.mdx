# Elasticsearch

Elasticsearch 儲存功能使用官方 [`@elastic/elasticsearch`](https://github.com/elastic/elasticsearch-js) 客戶端，在 Elasticsearch 叢集中儲存 Agent 記憶、Workflow 快照及評分。它與 `ElasticSearchVector` 採用相同的連線設定，因此同一個叢集，甚至同一個客戶端實例，都可以同時支援 Agent 記憶及語義檢索。

`ElasticSearchStore` 目前支援三個儲存域，分別是 `memory`、`workflows` 和 `scores`。

## 安裝 {/* #installation */}

```bash
npm install @mastra/elasticsearch
```

## 用法 {/* #usage */}

### 使用 URL {/* #using-a-url */}

```typescript
import { ElasticSearchStore } from '@mastra/elasticsearch'

const storage = new ElasticSearchStore({
  id: 'elasticsearch-storage',
  url: 'http://localhost:9200',
})

await storage.init()
```

### 使用身份驗證 {/* #using-authentication */}

```typescript
import { ElasticSearchStore } from '@mastra/elasticsearch'

const storage = new ElasticSearchStore({
  id: 'elasticsearch-storage',
  url: 'https://my-cluster.example.com:9200',
  auth: { apiKey: process.env.ELASTICSEARCH_API_KEY! },
})
```

`auth` 亦可接受 `{ username, password }` 或 `{ bearer }`。

### 使用預先設定的客戶端 {/* #using-a-pre-configured-client */}

如需指定雲端 ID、TLS 選項或自訂傳輸方式等進階設定，請傳入預先設定的客戶端。你可以讓 `ElasticSearchVector` 共用同一個客戶端。

```typescript
import { Client } from '@elastic/elasticsearch'
import { ElasticSearchStore, ElasticSearchVector } from '@mastra/elasticsearch'

const client = new Client({
  node: 'https://my-cluster.example.com:9200',
  auth: { apiKey: process.env.ELASTICSEARCH_API_KEY! },
})

const storage = new ElasticSearchStore({ id: 'elasticsearch-storage', client })
const vector = new ElasticSearchVector({ id: 'elasticsearch-vector', client })
```

如果你自行提供客戶端，就需要負責管理其生命週期。執行 `storage.close()` 後，該客戶端仍然開啟。

## 附加說明 {/* #additional-notes */}

### 索引結構 {/* #index-structure */}

每個 Mastra 儲存表都對應一個同名的 Elasticsearch 索引，例如 `mastra_threads`、`mastra_messages`、`mastra_workflow_snapshot` 和 `mastra_scorers`。記錄會以 JSON 文件形式整體儲存，內部結構不作解析，並帶有 keyword 類型的 `key` 欄位。索引在首次使用時自動建立，毋須手動管理索引映射。

### 一致性 {/* #consistency */}

Elasticsearch 的搜尋接近即時。每次寫入都會即時刷新索引，其後的讀取和搜尋都能取得寫入結果。如只讀取一筆記錄，系統會按 ID 即時擷取文件。

### 關閉連線 {/* #closing-connections */}

應用程式結束時，請執行以下方法關閉連線。

```typescript
await storage.close()
```

此方法只會關閉 `ElasticSearchStore` 按 `url` 建立的客戶端。你自行提供的客戶端會繼續保持開啟。

## 使用示例 {/* #usage-example */}

### 為 Agent 加入記憶 {/* #adding-memory-to-an-agent */}

```typescript title="src/mastra/agents/elasticsearch-agent.ts"
import { Memory } from '@mastra/memory'
import { Agent } from '@mastra/core/agent'
import { ElasticSearchStore } from '@mastra/elasticsearch'

export const elasticsearchAgent = new Agent({
  id: 'elasticsearch-agent',
  name: 'Elasticsearch Agent',
  instructions:
    'You are an AI agent with the ability to automatically recall memories from previous interactions.',
  model: '__GATEWAY_OPENAI_MODEL__',
  memory: new Memory({
    storage: new ElasticSearchStore({
      id: 'elasticsearch-agent-storage',
      url: process.env.ELASTICSEARCH_URL!,
      auth: { apiKey: process.env.ELASTICSEARCH_API_KEY! },
    }),
    options: {
      lastMessages: 10,
    },
  }),
})
```

### 在 Mastra 實例中使用 {/* #using-with-mastra-instance */}

```typescript
import { Mastra } from '@mastra/core'
import { ElasticSearchStore } from '@mastra/elasticsearch'

const storage = new ElasticSearchStore({
  id: 'mastra-storage',
  url: 'http://localhost:9200',
})

const mastra = new Mastra({
  storage, // init() called automatically
})
```

如直接使用儲存功能而沒有經過 Mastra 實例，請明確呼叫 `init()`。

```typescript
import { ElasticSearchStore } from '@mastra/elasticsearch'

const storage = new ElasticSearchStore({
  id: 'elasticsearch-storage',
  url: 'http://localhost:9200',
})

await storage.init()

// Access domain-specific stores via getStore()
const memoryStore = await storage.getStore('memory')
const thread = await memoryStore?.getThreadById({ threadId: '...' })
```
