# ClickHouse Managed Postgres

[ClickHouse Managed Postgres](https://clickhouse.com/cloud/postgres) 透過採用 Node.js `pg` 驅動程式的 [`PostgresStore`](/integrations/databases/postgresql) 連線至 Mastra。

## 設定連線 {/* #set-up-the-connection */}

在 ClickHouse Cloud 控制台開啟 Postgres 實例，然後選擇 **Connect**。停用 **via PgBouncer**，並複製直接連線的 URL。從 **Settings** 下載該實例的 CA 憑證套件。

在應用程式中設定以下環境變數：

```bash title=".env"
DATABASE_URL=postgresql://postgres:YOUR_PASSWORD@YOUR_HOST:5432/postgres
PG_CA_CERT_PATH=/absolute/path/to/ca-certificate.pem
```

請勿將密碼納入版本控制。使用 **Connect** 顯示的主機名稱，並確保 `DATABASE_URL` 不含 SSL 查詢參數。下方的 `ssl` 物件用於設定憑證驗證。

有關連線和憑證的詳情，請參閱[連線文件](https://clickhouse.com/docs/products/managed-postgres/connection)。

## 設定儲存 {/* #configure-storage */}

安裝 PostgreSQL 儲存套件：

```bash npm2yarn
npm install @mastra/pg@latest
```

在 Mastra 註冊儲存實例：

```typescript title="src/mastra/index.ts"
import { readFileSync } from 'node:fs'
import { Mastra } from '@mastra/core/mastra'
import { PostgresStore } from '@mastra/pg'

export const mastra = new Mastra({
  storage: new PostgresStore({
    id: 'clickhouse-managed-postgres-storage',
    connectionString: process.env.DATABASE_URL!,
    ssl: {
      ca: readFileSync(process.env.PG_CA_CERT_PATH!, 'utf8'),
      rejectUnauthorized: true,
    },
  }),
})
```

每個實例都有專屬的 CA 憑證。請確保已部署的應用程式可從 `PG_CA_CERT_PATH` 指定的路徑讀取該憑證。

應用程式啟動時，Mastra 會初始化儲存資料表。資料庫角色必須有權建立這些資料表和索引。執行應用程式後，使用該實例的 SQL Console 檢查資料表：

```sql
SELECT table_schema, table_name
FROM information_schema.tables
WHERE table_name LIKE 'mastra_%'
ORDER BY table_schema, table_name;
```

如需以不同角色初始化資料庫結構和執行應用程式，請參閱 [PostgreSQL 儲存指南](/integrations/databases/postgresql)。
