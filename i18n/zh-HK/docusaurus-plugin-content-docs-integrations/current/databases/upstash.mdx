# Upstash

Mastra 的 Upstash 儲存整合採用 Upstash 的鍵值儲存服務。該服務兼容 Redis，適用於無伺服器部署。

:::warning[收費]

配合 Upstash 使用 Mastra 時，Agent 在對話期間會發出大量 Redis 指令，按用量收費可能令開支超出預算。強烈建議選用**固定收費計劃**，方便預算開支。收費詳情見 [Upstash 收費](https://upstash.com/pricing/redis)，相關背景見 [GitHub 議題 #5850](https://github.com/mastra-ai/mastra/issues/5850)。

:::

:::warning[不支援可觀測性]

Upstash 儲存服務**不支援可觀測性儲存領域**。`MastraStorageExporter` 匯出的 Trace 無法持久儲存至 Upstash。只採用 Upstash 作為儲存服務時，[Studio](/docs/studio/overview) 的可觀測性功能將無法使用。如要啟用可觀測性，可透過[組合儲存](/reference/storage/composite#specialized-storage-for-observability)將相關數據轉送至 ClickHouse 等受支援的儲存服務。

:::

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/upstash@latest
```

## 使用方法 {/* #usage */}

```typescript
import { UpstashStore } from '@mastra/upstash'

const storage = new UpstashStore({
  id: 'upstash-storage',
  url: process.env.UPSTASH_URL,
  token: process.env.UPSTASH_TOKEN,
})
```

## 附加說明 {/* #additional-notes */}

### 鍵的結構 {/* #key-structure */}

Upstash 以鍵值對儲存數據，各類鍵的格式如下：

- 對話串鍵：`{prefix}thread:{threadId}`
- 消息鍵：`{prefix}message:{messageId}`
- 元數據鍵：`{prefix}metadata:{entityId}`

### 無伺服器部署的優點 {/* #serverless-benefits */}

Upstash 儲存特別適合無伺服器部署：

- 毋須管理連線
- 按請求次數收費
- 可選用全球複製
- 兼容邊緣運算環境

### 數據持久化 {/* #data-persistence */}

Upstash 提供以下數據儲存及還原功能：

- 自動持久儲存數據
- 還原至指定時間點
- 可選用跨區域複製

### 效能考量 {/* #performance-considerations */}

可透過以下做法改善效能：

- 選用合適的鍵前綴來組織數據
- 監察 Redis 的記憶體用量
- 按需要考慮設定數據到期策略

## 使用範例 {/* #usage-example */}

### 為 Agent 加入記憶功能 {/* #adding-memory-to-an-agent */}

如要讓 Agent 以 Upstash 儲存記憶，請使用 `Memory` 類別，將 `storage` 設為 `UpstashStore` 實例，並將 `vector` 設為 `UpstashVector` 實例。設定可指向遠端服務或本機環境。

```typescript title="src/mastra/agents/example-upstash-agent.ts"
import { Memory } from '@mastra/memory'
import { Agent } from '@mastra/core/agent'
import { UpstashStore } from '@mastra/upstash'

export const upstashAgent = new Agent({
  id: 'upstash-agent',
  name: 'Upstash Agent',
  instructions:
    'You are an AI agent with the ability to automatically recall memories from previous interactions.',
  model: '__GATEWAY_OPENAI_MODEL__',
  memory: new Memory({
    storage: new UpstashStore({
      id: 'upstash-agent-storage',
      url: process.env.UPSTASH_REDIS_REST_URL!,
      token: process.env.UPSTASH_REDIS_REST_TOKEN!,
    }),
    options: {
      generateTitle: true, // Explicitly enable automatic title generation
    },
  }),
})
```

### 使用 Agent {/* #using-the-agent */}

以 `memoryOptions` 設定這次請求的記憶檢索範圍。設定 `lastMessages: 5`，即可將近期消息的檢索範圍限於最近 5 條。語義檢索則透過 `semanticRecall` 設定。`topK: 3` 會擷取最相關的 3 條消息，`messageRange: 2` 會為每條配對結果加入前後各 2 條消息作為上下文。

```typescript title="src/test-upstash-agent.ts"
import 'dotenv/config'

import { mastra } from './mastra'

const threadId = '123'
const resourceId = 'user-456'

const agent = mastra.getAgent('upstashAgent')

const message = await agent.stream('My name is Mastra', {
  memory: {
    thread: threadId,
    resource: resourceId,
  },
})

await message.textStream.pipeTo(new WritableStream())

const stream = await agent.stream("What's my name?", {
  memory: {
    thread: threadId,
    resource: resourceId,
  },
  memoryOptions: {
    lastMessages: 5,
    semanticRecall: {
      topK: 3,
      messageRange: 2,
    },
  },
})

for await (const chunk of stream.textStream) {
  process.stdout.write(chunk)
}
```
