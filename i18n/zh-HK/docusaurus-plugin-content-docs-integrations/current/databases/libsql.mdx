# libSQL

[libSQL](https://docs.turso.tech/libsql) 是兼容 SQLite 的開源資料庫，可在本機或遠端部署。你可以用它儲存過往訊息、Workflow 快照、Trace 及評估分數。

如需用向量實作語義召回或傳統 RAG，可參閱 [libSQL Vector](/integrations/vectors/libsql) 的嵌入向量及向量搜尋說明。

## 安裝 {/* #installation */}

儲存 Provider 必須另行安裝。以下指令會安裝 libSQL 套件。

```bash npm2yarn
npm install @mastra/libsql@latest
```

## 使用方法 {/* #usage */}

```typescript
import { LibSQLStore } from '@mastra/libsql'
import { Mastra } from '@mastra/core'

const mastra = new Mastra({
  storage: new LibSQLStore({
    id: 'libsql-storage',
    url: 'file:./storage.db',
  }),
})
```

以下示例為個別 Agent 設定檔案儲存。

```typescript
import { Memory } from '@mastra/memory'
import { Agent } from '@mastra/core/agent'
import { LibSQLStore } from '@mastra/libsql'

export const agent = new Agent({
  id: 'example-agent',
  memory: new Memory({
    storage: new LibSQLStore({
      id: 'libsql-storage',
      url: 'file:./agent.db',
    }),
  }),
})
```

:::warning
採用臨時檔案系統的無伺服器平台無法使用檔案儲存。在這類平台部署時，請使用 [Turso](https://turso.tech) 或其他資料庫引擎。
:::

以下設定可在生產環境連接遠端資料庫。

```typescript
storage: new LibSQLStore({
  id: 'libsql-storage',
  url: 'libsql://your-db-name.aws-ap-northeast-1.turso.io',
  authToken: process.env.TURSO_AUTH_TOKEN,
})
```

在本機開發和測試時，可以把資料存放在記憶體內。

```typescript
storage: new LibSQLStore({
  id: 'libsql-storage',
  url: ':memory:',
})
```

:::warning
程序重新啟動或更換時，記憶體內的資料會被清除。這種儲存方式只適用於開發。
:::

以下設定會建立嵌入式副本，並與遠端主資料庫同步，例如由 Turso 託管的資料庫。

```typescript
storage: new LibSQLStore({
  id: 'libsql-storage',
  url: 'file:./replica.db',
  syncUrl: 'libsql://your-db-name.aws-ap-northeast-1.turso.io',
  authToken: process.env.TURSO_AUTH_TOKEN,
  syncInterval: 60,
})
```

## 自動管理的資料表 {/* #managed-tables */}

儲存實作會自動建立核心資料表，包括用來儲存通知收件箱記錄及送遞元資料的 `mastra_notifications`。

你可以透過 `LibSQLStore` 的 `getStore('notifications')` 存取通知儲存。

## 初始化 {/* #initialization */}

把儲存物件傳入 Mastra 類別後，Mastra 會自動呼叫 `init()` 建立[核心資料庫結構](/reference/storage/overview#core-schema)。

```typescript
import { Mastra } from '@mastra/core'
import { LibSQLStore } from '@mastra/libsql'

const storage = new LibSQLStore({
  id: 'libsql-storage',
  url: 'file:./storage.db',
})

const mastra = new Mastra({
  storage, // init() called automatically
})
```

如直接使用儲存物件，須自行呼叫 `init()`。

```typescript
import { LibSQLStore } from '@mastra/libsql'

const storage = new LibSQLStore({
  id: 'libsql-storage',
  url: 'file:./storage.db',
})

await storage.init()

// Access domain-specific stores via getStore()
const memoryStore = await storage.getStore('memory')
const thread = await memoryStore?.getThreadById({ threadId: '...' })
```

## 可觀察性 {/* #observability */}

libSQL 支援可觀察性，適合本機開發。偵錯時可使用 `realtime` [追蹤策略](/docs/observability/integrations/exporters/mastra-storage#tracing-strategies) 即時查看 Trace。

如生產環境的 Trace 數量較多，可考慮使用 [PostgreSQL](/integrations/databases/postgresql)，或[透過複合儲存使用 ClickHouse](/reference/storage/composite#specialized-storage-for-observability)。
