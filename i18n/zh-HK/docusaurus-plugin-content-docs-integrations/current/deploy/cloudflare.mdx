# 雲耀

使用`@mastra/deployer-cloudflare`將您的 Mastra 伺服器部署到 Cloudflare Workers。部署程式捆綁您的程式碼並生成`wrangler.jsonc`符合 Cloudflare 的文件[牧馬人配置](https://developers.cloudflare.com/workers/wrangler/configuration/)，無需額外配置即可部署。

：：：筆記

如果您使用的是[server adapter](/docs/server/server-adapters) or [web framework](/docs/deployment/web-framework), deploy the way you normally would for that framework.

:::

## 開始之前 {/* #before-you-begin */}

你需要一個[Mastra application](/docs) and a [Cloudflare](https://cloudflare.com/) account.

:::警告
Cloudflare Workers 使用暫存檔案系統，因此您配置的任何儲存（包括可觀察性儲存）都必須託管在外部。如果您正在使用[LibSQLStore](/integrations/databases/libsql) with a file URL, switch to a remotely hosted database.
:::

## 安裝 {/* #installation */}

添加`@mastra/deployer-cloudflare` package to your project:

```bash npm2yarn
npm install @mastra/deployer-cloudflare@latest
```

進口[`CloudflareDeployer`](/reference/deployer/cloudflare) and set it as the deployer in your Mastra configuration:

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
// highlight-next-line
import { CloudflareDeployer } from '@mastra/deployer-cloudflare'

export const mastra = new Mastra({
  // highlight-start
  deployer: new CloudflareDeployer({
    name: 'your-project-name',
    vars: {
      NODE_ENV: 'production',
    },
  }),
  // highlight-end
})
```

若要在本機測試您的 Cloudflare Worker，還需安裝[`wrangler` CLI](https://developers.cloudflare.com/workers/wrangler/install-and-update/):

```bash npm2yarn
npm install -D wrangler
```

## 用法 {/* #usage */}

設定專案後，將其推送到您選擇的遠端 Git 提供者（例如 GitHub）。

<Steps>
  <StepItem>
    將您的儲存庫連接到 Cloudflare。在「工作人員和頁面」儀表板上，選擇**Create application** and choose your Git provider in the next step. Continue with the setup process and select the repository you want to deploy.

    ：：：筆記

    請記住設定運行應用程式所需的環境變數（例如您的[model provider](/models/providers) API key). You can upload secrets from your `.env` file using `npx wrangler secret bulk .env`. See [Secrets](/reference/deployer/cloudflare#secrets) for details.

    :::
  </StepItem>

  <StepItem>
    準備好後，點擊**Deploy** button and wait for the first deployment to complete.
  </StepItem>

  <StepItem>
    嘗試您新部署的功能，方法是：`https://<your-project-name>.<slug>.workers.dev/api/agents`. You should get a JSON response listing all available agents.

    自從[Mastra server](/docs/server/overview) prefixes every API endpoint with `/api`, you have to add it to your URLs when making requests.
  </StepItem>

  <StepItem>
    現在您可以透過 HTTP 呼叫 Mastra 端點。

    ：：：筆記

    設定[authentication](/docs/auth/overview) before exposing your endpoints publicly.

    :::
  </StepItem>
</Steps>
