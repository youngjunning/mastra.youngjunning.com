# Cloudflare

使用 `@mastra/deployer-cloudflare` 將 Mastra 伺服器部署至 Cloudflare Workers。部署工具會打包程式碼，並產生符合 Cloudflare [Wrangler 設定規格](https://developers.cloudflare.com/workers/wrangler/configuration/)的 `wrangler.jsonc` 檔案，無需額外設定即可部署。

:::note

如果使用[伺服器轉接器](/docs/server/server-adapters)或 [Web 框架](/docs/deployment/web-framework)，請按照該框架的一般方式部署。

:::

## 開始之前 {/* #before-you-begin */}

你需要一個 [Mastra 應用程式](/docs)和一個 [Cloudflare](https://cloudflare.com/) 帳戶。

:::warning
Cloudflare Workers 使用暫存檔案系統，因此設定的所有儲存服務（包括 Observability 儲存）都必須託管在外部。如果 [LibSQLStore](/integrations/databases/libsql) 使用檔案 URL，請改用遠端託管的資料庫。
:::

## 安裝 {/* #installation */}

將 `@mastra/deployer-cloudflare` 套件加入項目：

```bash npm2yarn
npm install @mastra/deployer-cloudflare@latest
```

匯入 [`CloudflareDeployer`](/reference/deployer/cloudflare)，並在 Mastra 設定中將它指定為部署工具：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
// highlight-next-line
import { CloudflareDeployer } from '@mastra/deployer-cloudflare'

export const mastra = new Mastra({
  // highlight-start
  deployer: new CloudflareDeployer({
    name: 'your-project-name',
    vars: {
      NODE_ENV: 'production',
    },
  }),
  // highlight-end
})
```

如要在本機測試 Cloudflare Worker，請同時安裝 [`wrangler` CLI](https://developers.cloudflare.com/workers/wrangler/install-and-update/)：

```bash npm2yarn
npm install -D wrangler
```

## 用法 {/* #usage */}

完成項目設定後，將項目推送至所選的遠端 Git 服務（例如 GitHub）。

<Steps>
  <StepItem>
    將儲存庫連線至 Cloudflare。在「Workers & Pages」控制面板選擇 **Create application**，然後在下一步選擇 Git 服務。繼續設定，並選擇要部署的儲存庫。

    :::note

    請記得設定應用程式執行所需的環境變數（例如 [Model Provider](/models/providers) 的 API 金鑰）。你可以執行 `npx wrangler secret bulk .env`，上載 `.env` 檔案中的機密資料。詳情請參閱[機密資料](/reference/deployer/cloudflare#secrets)。

    :::
  </StepItem>

  <StepItem>
    準備就緒後，按下 **Deploy** 按鈕，並等待首次部署完成。
  </StepItem>

  <StepItem>
    前往 `https://<your-project-name>.<slug>.workers.dev/api/agents`，試用剛部署的函式。頁面應傳回列出所有可用 Agent 的 JSON 回應。

    [Mastra 伺服器](/docs/server/overview)會為每個 API 端點加上 `/api` 前綴，因此發出請求時，URL 必須包含這個前綴。
  </StepItem>

  <StepItem>
    現在可以透過 HTTP 呼叫 Mastra 端點。

    :::note

    對外公開端點前，請先設定[身份驗證](/docs/auth/overview)。

    :::
  </StepItem>
</Steps>
