# 數位海洋

本指南涵蓋 Digital Ocean 的應用程式平台和 Droplet。這些產品都有自己的優勢，適合不同類型的專案和開發人員的專業知識。讀[Digital Ocean's comparison](https://www.digitalocean.com/community/conceptual-articles/digitalocean-app-platform-vs-doks-vs-droplets)了解差異並為您的項目選擇最佳選項。

:::注意
本指南涵蓋了部署[Mastra server](/docs/server/overview). If you're using a [server adapter](/docs/server/server-adapters)或者[網路框架](/docs/deployment/web-framework)，按照您通常為該框架部署的方式進行部署。
:::

## 開始之前 {/* #before-you-begin */}

你需要一個[Mastra application](/docs) and a [Digital Ocean](https://www.digitalocean.com/) account.

這**App Platform** uses an ephemeral filesystem, so any storage you configure (including observability storage) must be hosted externally. If you're using [LibSQLStore](/integrations/databases/libsql) with a file URL, switch to a remotely hosted database.

## 應用平台 {/* #app-platform */}

設定專案後，將其推送到您選擇的遠端 Git 提供者（例如 GitHub）。

<Steps>
  <StepItem>
    [App Platform quickstart](https://docs.digitalocean.com/products/app-platform/getting-started/quickstart/#create-an-app). It'll guide you through connecting your repository, selecting the branch to deploy from, and configuring the source directory if necessary.
  </StepItem>

  <StepItem>
    確保偵測到“Node.js”建置。您需要配置建置命令。根據您的套件管理器進行設定：

    ```bash npm2yarn
    npm run build
    ```
  </StepItem>

  <StepItem>
    為您的 Mastra 應用程式添加任何所需的環境變數。這包括 API 金鑰、資料庫 URL 和其他配置值。
  </StepItem>

  <StepItem>
    您的應用程式將自動建置和部署。 Digital Ocean 將為您提供一個 URL 來存取已部署的應用程式。
  </StepItem>

  <StepItem>
    現在您可以透過 HTTP 呼叫 Mastra 端點。

    :::警告
    設定[authentication](/docs/auth/overview) before exposing your endpoints publicly.
    :::
  </StepItem>
</Steps>

## 液滴 {/* #droplets */}

### 先決條件 {/* #prerequisites */}

* 運行 Ubuntu 24.04 LTS 或更高版本的 Droplet
* 帶有 A 記錄的網域指向您的 Droplet
* 配置的反向Agent（例如，使用[nginx](https://nginx.org/))
* 配置的 SSL 憑證（例如，使用[Let's Encrypt](https://letsencrypt.org/))
* 安裝在 Droplet 上的 Node.js 22.13.0 或更高版本

### 部署 {/* #deploy */}

設定專案後，將其推送到您選擇的遠端 Git 提供者（例如 GitHub）。連接到您的 Droplet 並確保`git` is installed.

<Steps>
  <StepItem>
    克隆您的儲存庫：

    <Tabs>
      <TabItem value="public" label="Public Repository">
        ```bash
        git clone https://github.com/<your-username>/<your-repository>.git
        ```
      </TabItem>

      <TabItem value="private" label="Private Repository">
        ```bash
        git clone https://<your-username>:<your-personal-access-token>@github.com/<your-username>/<your-repository>.git
        ```
      </TabItem>
    </Tabs>

    導航到儲存庫目錄：

    ```bash
    cd "<your-repository>"
    ```
  </StepItem>

  <StepItem>
    安裝專案依賴項：

    ```bash npm2yarn
    npm install
    ```
  </StepItem>

  <StepItem>
    為您的 Mastra 應用程式設定所需的環境變數。創建一個`.env` file in the root of your project:

    ```bash
    touch .env
    ```

    編輯`.env` file and add your environment variables:

    ```bash title=".env"
    OPENAI_API_KEY=your-api-key
    ```
  </StepItem>

  <StepItem>
    建構專案：

    ```bash npm2yarn
    npm run build
    ```

    這將在以下位置建立 Mastra 伺服器的生產版本`.mastra/output` directory.
  </StepItem>

  <StepItem>
    您可以運行[Mastra Server](/docs/deployment/mastra-server) by running the `mastra start` command:

    ```bash
    mastra start
    ```

    :::注意
    預設情況下，您的 Mastra 應用程式將在連接埠 4111 上運行。確保您的反向Agent配置為將請求轉送至此連接埠。
    :::
  </StepItem>

  <StepItem>
    現在您可以透過 HTTP 呼叫 Mastra 端點。

    :::警告
    設定[authentication](/docs/auth/overview) before exposing your endpoints publicly.
    :::
  </StepItem>
</Steps>
