# Neon

在 Neon 分支上，把 Mastra 伺服器部署為 [Neon Function](https://neon.com/docs/compute/functions/overview)，以長時間運行的 Node.js 程序提供服務。Neon 會為函數分配可公開存取的 HTTPS 網址，並根據分支的 Postgres 資料庫注入 `DATABASE_URL`。

Neon Functions 以 `fetch` 處理程式接收請求。本指南使用 [Hono 伺服器適配器](/docs/server/server-adapters)，毋須執行 `mastra build` / `mastra start`。如使用 [Web 框架](/docs/deployment/web-framework)，請沿用該框架的日常部署流程。

Neon Functions 現正處於 Beta 階段，只在 AWS 美國東部（俄亥俄州）區域（`aws-us-east-2`）提供。你需要在該區域建立 Neon 項目。

## 開始之前 {/* #before-you-begin */}

開始前，請準備：

- 一個 [Mastra 應用程式](/docs)
- 一個 [Neon](https://neon.com) 帳戶
- 位於 `aws-us-east-2` 區域的 Neon 項目
- Node.js `v22.13.0` 或以上版本

Neon Functions 可回收閒置的隔離執行環境，當中的記憶體資料和本機檔案亦會隨之遺失。請以 [連接 Neon 的 PostgresStore](/integrations/databases/neon) 取代使用檔案 URL 的 [LibSQLStore](/integrations/databases/libsql)。工作區的檔案則應改用 [Neon Object Storage](/integrations/file-storage/neon) 儲存，以取代 [`LocalFilesystem`](/reference/workspace/local-filesystem)。

## 安裝 {/* #installation */}

安裝 [Neon CLI](https://neon.com/docs/cli/install)：

```bash npm2yarn
npm install -g neon
```

加入 Hono 適配器、Hono 及 `@neon/config`：

```bash npm2yarn
npm install @mastra/hono@latest hono @neon/config
```

## 設定 `neon.ts` {/* #configure-neonts */}

在項目的根目錄建立 `neon.ts`，供 `neon deploy` 和 `neon dev` 讀取：

```typescript title="neon.ts"
import { defineConfig } from '@neon/config/v1'

export default defineConfig({
  preview: {
    aiGateway: true,
    functions: {
      mastra: {
        name: 'Mastra server',
        source: './src/index.ts',
      },
    },
  },
})
```

物件的鍵 `mastra` 用作函數的 slug，首次部署後便不能更改。

`aiGateway: true` 會為該分支啟用 [Neon AI Gateway](/models/gateways/neon)。`neon deploy` 會注入 `NEON_AI_GATEWAY_BASE_URL` 和 `NEON_AI_GATEWAY_TOKEN`。指定以 `neon/` 開頭的模型 ID 時，Mastra 會讀取這兩個變數。

如要透過模型供應商的 API 密鑰直接使用模型，請在函數的 `env` 欄位宣告密鑰，並用供應商的模型 ID 取代以 `neon/` 開頭的 ID。`neon deploy` 執行時會從 `process.env` 讀取變數值：

```typescript title="neon.ts"
import { defineConfig } from '@neon/config/v1'

export default defineConfig({
  preview: {
    functions: {
      mastra: {
        name: 'Mastra server',
        source: './src/index.ts',
        env: {
          OPENAI_API_KEY: process.env.OPENAI_API_KEY!,
        },
      },
    },
  },
})
```

```bash
neon deploy --env .env
```

`--env` 會載入指定檔案，供執行設定檔時讀取環境變數。只有在 `env` 列出的變數才會隨函數部署。詳情見 [Neon Functions 環境變數](https://neon.com/docs/compute/functions/environment-variables)。

## 匯出 Hono 的 fetch 處理程式 {/* #export-a-hono-fetch-handler */}

接入 [Hono 適配器](/reference/server/hono-adapter)，並將 Hono 應用程式設為預設匯出。Neon Functions 會調用預設匯出物件的 `fetch` 方法。

```typescript title="src/index.ts"
import { Hono } from 'hono'
import { HonoBindings, HonoVariables, MastraServer } from '@mastra/hono'
import { mastra } from './mastra'

const app = new Hono<{ Bindings: HonoBindings; Variables: HonoVariables }>()
const server = new MastraServer({ app, mastra })

await server.init()

export default app
```

在 `src/mastra/index.ts` 內，將 Agent 註冊到 `mastra` 實例。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core/mastra'
import { Agent } from '@mastra/core/agent'

const assistant = new Agent({
  id: 'assistant',
  name: 'Assistant',
  instructions: 'You are a helpful assistant',
  model: 'neon/claude-fable-5',
})

export const mastra = new Mastra({
  agents: { assistant },
})
```

可用模型載於 [Neon AI Gateway](/models/gateways/neon)。

## 部署 {/* #deploy */}

<Steps>
  <StepItem>
    在項目目錄執行以下指令，連結現有 Neon 項目，或建立新項目：

    ```bash
    neon link
    ```

    `neon link` 會把項目的上下文資料寫入 `.neon`，並取得目前分支的環境變數。
  </StepItem>

  <StepItem>
    部署函數：

    ```bash
    neon deploy
    ```

    CLI 會以 esbuild 將處理程式打包並上載，直至部署狀態顯示為 `completed` 才結束。如已在函數的 `env` 宣告環境變數，請傳入 `--env <file>`，讓 `neon.ts` 讀取這些變數的值。
  </StepItem>

  <StepItem>
    取得可公開存取的網址：

    ```bash
    neon functions get mastra
    ```

    `invocation_url` 的格式是 `https://<branch-id>-mastra.compute.<cell>.us-east-2.aws.neon.tech/`。
  </StepItem>

  <StepItem>
    瀏覽 `https://<branch-id>-mastra.compute.<cell>.us-east-2.aws.neon.tech/api/agents` 以驗證部署。該端點應傳回 JSON 格式的 Agent 清單。

    Mastra 伺服器的每個 API 端點都有 `/api` 前綴。發送請求時，請將此前綴加到網址路徑。

    Neon 會從分支注入 `DATABASE_URL`。如在 `neon.ts` 設定 `aiGateway: true`，Neon 亦會注入網關憑證。
  </StepItem>

  <StepItem>
    現在可以透過 HTTP 調用 Mastra 端點。

    :::warning
    公開端點前，請先設定 [身分驗證](/docs/auth/overview)。函數網址可公開存取，詳情見 [Neon Functions 身分驗證](https://neon.com/docs/compute/functions/authentication)。
    :::
  </StepItem>
</Steps>

## 本地開發 {/* #local-development */}

`neon dev` 會在本機提供 `neon.ts` 內宣告的所有函數，支援熱重載，並注入已連結分支的環境變數：

```bash
neon dev
```

Mastra 伺服器的 Agent 清單端點位於 `http://localhost:8787/api/agents`。
