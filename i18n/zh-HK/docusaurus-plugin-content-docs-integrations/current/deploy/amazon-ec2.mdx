# Amazon EC2

將 Mastra 伺服器部署至 Amazon EC2。伺服器會在你管理的基礎設施上運行，並可支援需要長時間運行的 Agent 和 Workflow。

:::note
本指南介紹如何部署 [Mastra 伺服器](/docs/server/overview)。如果你使用[伺服器適配器](/docs/server/server-adapters)或 [Web 框架](/docs/deployment/web-framework)，請按該框架的常規方式部署。
:::

## 開始之前 {/* #before-you-begin */}

你需要準備：

- 一個 [Mastra 應用程式](/docs)
- 一個已安裝 Git 和 Node.js 22.13.0 或以上版本的 [EC2](https://aws.amazon.com/ec2/) 實例（Ubuntu 或 Amazon Linux）

如要部署至正式環境，還需要：

- 一個指向你的實例的網域名稱（SSL 證書所需）
- 你的網域所用的 SSL 證書（例如透過 [Certbot](https://certbot.eff.org/) 向 Let's Encrypt 取得）
- 一個反向代理（例如 [nginx](https://nginx.org/)），用來將流量轉發至你的應用程式

## 部署 {/* #deploy */}

<Steps>
  <StepItem>
    連線至你的 EC2 實例，並複製你的程式碼儲存庫：

    <Tabs>
      <TabItem value="public" label="Public Repository">
        ```bash
        git clone https://github.com/<your-username>/<your-repository>.git
        ```
      </TabItem>

      <TabItem value="private" label="Private Repository">
        ```bash
        git clone git@github.com:<your-username>/<your-repository>.git
        ```
      </TabItem>
    </Tabs>

    切換至程式碼儲存庫目錄：

    ```bash
    cd "<your-repository>"
    ```
  </StepItem>

  <StepItem>
    安裝相依套件：

    ```bash npm2yarn
    npm install
    ```
  </StepItem>

  <StepItem>
    建立 `.env` 檔案，並加入你的環境變數：

    ```bash
    touch .env
    ```

    記得設定運行應用程式所需的環境變數（例如你的 Model Provider API 密鑰）：

    ```bash
    OPENAI_API_KEY=<your-openai-api-key>
    # Add other required environment variables
    ```
  </StepItem>

  <StepItem>
    構建應用程式：

    ```bash npm2yarn
    npm run build
    ```
  </StepItem>

  <StepItem>
    運行應用程式：

    ```bash
    node --env-file=".env" .mastra/output/index.mjs
    ```

    這是一個基本範例。在正式環境中，請使用 [PM2](https://pm2.keymetrics.io/) 或 [systemd](https://systemd.io/) 等進程管理工具，讓應用程式持續運行並處理重啟。

    :::warning
    在公開端點之前，請先設定[身分驗證](/docs/auth/overview)。
    :::
  </StepItem>

  <StepItem>
    你的 Mastra 伺服器現已在端口 4111 運行，但只可從本機存取。

    您可以在 EC2 安全性群組中開放 4111 連接埠以便直接存取，也可以設定反向代理（例如 nginx）監聽 80 和 443 連接埠，並將請求轉送至 `http://localhost:4111`。

    在正式環境中，應使用反向代理，以便設定 HTTPS。HTTPS 會加密流量，大部分 webhook 整合及與您的 Agent 互動的外部服務都需要 HTTPS。
  </StepItem>

  <StepItem>
    前往 `https://<your-ec2-address>/api/agents` 驗證部署；該網址應傳回 Agent 的 JSON 清單。
  </StepItem>

  <StepItem>
    現在您可以透過 HTTP 呼叫 Mastra 端點。
  </StepItem>
</Steps>
