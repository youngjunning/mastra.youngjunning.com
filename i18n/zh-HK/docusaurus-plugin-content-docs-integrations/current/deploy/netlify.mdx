# Netlify

使用 `@mastra/deployer-netlify` 將 Mastra 伺服器部署至 Netlify。部署工具會打包程式碼，並產生符合 Netlify [Frameworks API](https://docs.netlify.com/build/frameworks/frameworks-api/) 規格的 `.netlify` 目錄，可直接部署。預設會部署為無伺服器函式，也可部署為[邊緣函式](https://docs.netlify.com/build/edge-functions/overview/)，以縮短延遲並延長執行時間。

:::note
本指南說明如何部署 [Mastra 伺服器](/docs/server/overview)。如果使用[伺服器轉接器](/docs/server/server-adapters)或 [Web 框架](/docs/deployment/web-framework)，請按該框架的一般做法部署。
:::

## 開始之前 {/* #before-you-begin */}

你需要一個 [Mastra 應用程式](/docs)和一個 [Netlify](https://www.netlify.com/) 帳戶。

:::warning
Netlify Functions 使用臨時檔案系統，因此你設定的所有儲存服務（包括 Observability 儲存）均須託管在外部。如果你透過檔案 URL 使用 [LibSQLStore](/integrations/databases/libsql)，請改用遠端託管的資料庫。
:::

## 安裝 {/* #installation */}

將 `@mastra/deployer-netlify` 套件加入項目：

```bash npm2yarn
npm install @mastra/deployer-netlify@latest
```

匯入 [`NetlifyDeployer`](/reference/deployer/netlify)，並在 Mastra 設定中指定它為部署工具：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
// highlight-next-line
import { NetlifyDeployer } from '@mastra/deployer-netlify'

export const mastra = new Mastra({
  // highlight-next-line
  deployer: new NetlifyDeployer(),
})
```

如要改為部署成邊緣函式，請傳入 `{ target: 'edge' }`：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { NetlifyDeployer } from '@mastra/deployer-netlify'

export const mastra = new Mastra({
  deployer: new NetlifyDeployer({
    target: 'edge',
  }),
})
```

邊緣函式會在最接近用戶的邊緣節點上透過 Deno 執行。除了 CPU 時間限制外，邊緣函式並無硬性的執行逾時上限，因此更適合執行時間較長的 AI Workflow。詳情請參閱[建構函式選項](/reference/deployer/netlify#constructor-options)。

在項目根目錄建立 `netlify.toml` 檔案，並加入以下內容：

```toml
[build]
command = "mastra build"
```

## 部署 {/* #deploy */}

設定好項目後，將項目推送至你選用的遠端 Git Provider（例如 GitHub）。

<Steps>
  <StepItem>
    將你的程式碼儲存庫連接至 Netlify。設定期間，Netlify 會偵測 `netlify.toml` 檔案，並將建置指令設為 `mastra build`。

    :::note

    請記得設定執行應用程式所需的環境變數，例如你的 [Model Provider](/models/providers) 的 API 金鑰。

    :::
  </StepItem>

  <StepItem>
    準備就緒後，按下 **Deploy** 按鈕並等待首次部署完成。系統會顯示已部署一個
    function has been deployed.
  </StepItem>

  <StepItem>
    前往 `https://<random-slug>.netlify.app/api/agents` 驗證部署；該網址應傳回 Agent 的 JSON 清單。

    [Mastra 伺服器](/docs/server/overview)會為每個 API 端點加上 `/api` 前綴，因此發出請求時，必須在 URL 中加上此前綴。

    :::note

    Netlify Functions 通常部署於 `https://<random-slug>.netlify.app/.netlify/functions/api`。`NetlifyDeployer` 會將來自 `/*` 的所有請求重新導向至 `/.netlify/functions/api/:splat`，因此 URL 不必包含 `.netlify/functions` 前綴。

    :::
  </StepItem>

  <StepItem>
    現在可以透過 HTTP 呼叫 Mastra 端點。

    :::warning
    請先設定[身分驗證](/docs/auth/overview)，再對外公開端點。
    :::
  </StepItem>
</Steps>
