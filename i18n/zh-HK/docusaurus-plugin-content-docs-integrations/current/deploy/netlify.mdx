# 網路化

使用`@mastra/deployer-netlify`在 Netlify 上部署 Mastra 伺服器。部署程式捆綁您的程式碼並生成`.netlify`符合 Netlify 的目錄[框架API](https://docs.netlify.com/build/frameworks/frameworks-api/)，準備部署。您可以部署為無伺服器功能（預設）或部署為[邊緣函數](https://docs.netlify.com/build/edge-functions/overview/)以獲得更低的延遲和更長的執行時間。

:::注意
本指南涵蓋了部署[Mastra server](/docs/server/overview). If you're using a [server adapter](/docs/server/server-adapters) or [web framework](/docs/deployment/web-framework), deploy the way you normally would for that framework.
:::

## 開始之前 {/* #before-you-begin */}

你需要一個[Mastra application](/docs) and a [Netlify](https://www.netlify.com/) account.

:::警告
Netlify 函數使用暫存檔案系統，因此您配置的任何儲存空間（包括可觀察性儲存）都必須託管在外部。如果您正在使用[LibSQLStore](/integrations/databases/libsql) with a file URL, switch to a remotely hosted database.
:::

## 安裝 {/* #installation */}

添加`@mastra/deployer-netlify` package to your project:

```bash npm2yarn
npm install @mastra/deployer-netlify@latest
```

進口[`NetlifyDeployer`](/reference/deployer/netlify) and set it as the deployer in your Mastra configuration:

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
// highlight-next-line
import { NetlifyDeployer } from '@mastra/deployer-netlify'

export const mastra = new Mastra({
  // highlight-next-line
  deployer: new NetlifyDeployer(),
})
```

若要部署為邊緣函數，請傳遞`{ target: 'edge' }`:

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { NetlifyDeployer } from '@mastra/deployer-netlify'

export const mastra = new Mastra({
  deployer: new NetlifyDeployer({
    target: 'edge',
  }),
})
```

邊緣函數在 Deno 上最靠近使用者的邊緣運行。它們沒有硬執行逾時（只有 CPU 時間限制），這使它們更適合運行時間較長的 AI Workflow。請參閱[constructor options](/reference/deployer/netlify#constructor-options) for details.

創建一個`netlify.toml` file with the following contents in your project root:

```toml
[build]
command = "mastra build"
```

## 部署 {/* #deploy */}

設定專案後，將其推送到您選擇的遠端 Git 提供者（例如 GitHub）。

<Steps>
  <StepItem>
    將您的儲存庫連接到 Netlify。在設定過程中，Netlify 會偵測您的`netlify.toml` file and set the build command to `mastra build`.

    ：：：筆記

    請記住設定運行應用程式所需的環境變數（例如您的[model provider](/models/providers) API key).

    :::
  </StepItem>

  <StepItem>
    準備好後，點擊**Deploy** button and wait for the first deployment to complete. It'll tell you that one
    function has been deployed.
  </StepItem>

  <StepItem>
    驗證您的部署`https://<random-slug>.netlify.app/api/agents`, which should return a JSON list of your agents.

    自從[Mastra server](/docs/server/overview) prefixes every API endpoint with `/api`, you have to add it to your URLs when making requests.

    ：：：筆記

    Netlify 功能通常部署在`https://<random-slug>.netlify.app/.netlify/functions/api`. The `NetlifyDeployer` redirects any request from `/*` to `/.netlify/functions/api/:splat`, so you don't need to include the `.netlify/functions` prefix in your URLs.

    :::
  </StepItem>

  <StepItem>
    現在您可以透過 HTTP 呼叫 Mastra 端點。

    :::警告
    設定[authentication](/docs/auth/overview) before exposing your endpoints publicly.
    :::
  </StepItem>
</Steps>
