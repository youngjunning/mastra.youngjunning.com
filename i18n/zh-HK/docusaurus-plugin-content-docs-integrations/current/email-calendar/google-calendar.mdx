# 谷歌日曆

透過 Mastra Connect 為客服人員提供尋找、建立和更新活動、檢查可用性以及管理 Google 日曆中的日曆的Tool。每個Tool呼叫都會透過 Mastra 平台，該平台會新增連接的憑證。您的應用程式從不儲存 Google 日曆憑證。

## 連接 {/* #connect */}

在開始之前，請完成[Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect`並配置您的平台項目。

### 連接帳戶 {/* #connect-an-account */}

從包含您的目錄的目錄執行此命令`.env` file:

```bash
mastra connect add google-calendar
```

CLI 將引導您完成 Google 日曆的授權並等待連線啟動。

### 向Agent添加Tool {/* #add-tools-to-an-agent */}

經過[`tools()`](/reference/connect/tools) to the agent and select the `google-calendar` provider:

```typescript title="src/mastra/agents/google-calendar-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const googleCalendarAgent = new Agent({
  id: 'google-calendar-agent',
  name: 'Google Calendar agent',
  instructions:
    'You help people find, create, and update events, check availability, and manage calendars in Google Calendar.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['google-calendar'] }),
})
```

Agent程式獲得 43 個 Google 日曆Tool，其中包括以下按鍵：`google_calendar_add_attendee`. See [Google Calendar tools](/reference/connect/providers#google-calendar) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
