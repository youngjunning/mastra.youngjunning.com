# Gmail

透過 Mastra Connect，為 Agent 提供可在 Gmail 中讀取、傳送及撰寫電郵，管理標籤、篩選器和郵件討論串，以及更新郵箱設定的 Tool。每次 Tool 呼叫都會經過 Mastra 平台，由平台加入該連接的憑證；你的應用程式不會儲存 Gmail 憑證。

## 連接 {/* #connect */}

開始前，請先完成 [Connect 設定](/docs/mastra-platform/connect#get-started)，安裝 `@mastra/connect` 並設定 Mastra 平台項目。

### 連接帳戶 {/* #connect-an-account */}

請在包含 `.env` 檔案的目錄中執行以下指令：

```bash
mastra connect add google-mail
```

CLI 會引導你完成 Gmail 授權，並等待連接啟用。

### 將 Tool 加入 Agent {/* #add-tools-to-an-agent */}

將 [`tools()`](/reference/connect/tools) 傳給 Agent，並選擇 `google-mail` Provider：

```typescript title="src/mastra/agents/google-mail-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const googleMailAgent = new Agent({
  id: 'google-mail-agent',
  name: 'Gmail agent',
  instructions:
    'You help people read, send, and draft email, manage labels, filters, and threads, and update mailbox settings in Gmail.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['google-mail'] }),
})
```

Agent 可使用 52 個 Gmail Tool，Tool key 包括 `google_mail_batch_delete_messages`。完整清單請參閱 [Gmail Tool](/reference/connect/providers#gmail)；如需限制可用 Tool，或要求每次呼叫在執行前取得批准，請參閱 [`tools()` 參數](/reference/connect/tools#parameters)。
