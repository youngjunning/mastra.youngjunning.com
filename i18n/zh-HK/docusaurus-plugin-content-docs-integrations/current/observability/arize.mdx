# Arize

[Arize AI](https://arize.com/?utm_source=mastra-docs\&utm_medium=partner\&utm_campaign=partner-docs\&utm_content=observability-arize) 透過 [Arize Phoenix](https://arize.com/phoenix/) 和 [Arize AX](https://arize.com/products/ax/) 為 AI 應用提供可觀測性和評估功能。開源 Workflow 如在本機運行或自行託管，可使用 Phoenix；如需觀測託管雲端或企業自行託管的生產環境，則使用 Arize AX。Arize 匯出器透過 OpenTelemetry 傳送 Trace，並遵循 [OpenInference](https://github.com/Arize-ai/openinference/tree/main/spec) 語義慣例，因此兼容所有支援 OpenInference 的 OpenTelemetry 平台。

如要在 Workflow 中利用 Trace 改善質素，可參閱 Arize 的 [Agent 評估指南](https://arize.com/ai-agents/agent-evaluation/)和 [LLM 評估指南](https://arize.com/resources/llm-evaluation/)。

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/arize@latest
```

## 配置 {/* #configuration */}

### 設定 Phoenix {/* #phoenix-setup */}

Phoenix 是開源的可觀測性平台，可在本機運行，亦可自行託管。

#### 所需條件 {/* #prerequisites */}

1. **Phoenix 實例**：用 Docker 在本機運行 Phoenix，或連接至自行託管的實例。
2. **端點**：準備 Phoenix 的端點 URL，網址須以 `/v1/traces` 結尾。
3. **API 密鑰**：實例如未啟用身份驗證，可省略密鑰；部署如已啟用身份驗證，則必須提供。
4. **環境變數**：在以下環境變數填入配置值。

```bash title=".env"
# Required
PHOENIX_COLLECTOR_ENDPOINT=http://localhost:6006/v1/traces  # Or your self-hosted Phoenix URL

# Optional
PHOENIX_API_KEY=your-api-key  # For authenticated Phoenix instances
PHOENIX_PROJECT_NAME=mastra-service  # Defaults to 'mastra-service'
```

#### 只透過環境變數設定 {/* #zero-config-setup */}

設定環境變數後，便可使用匯出器，毋須再傳入配置：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { ArizeExporter } from '@mastra/arize'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      arize: {
        serviceName: 'mastra-service',
        exporters: [new ArizeExporter()],
      },
    },
  }),
})
```

#### 直接傳入配置 {/* #explicit-configuration */}

亦可直接傳入憑證；傳入的值優先於環境變數：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { ArizeExporter } from '@mastra/arize'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      arize: {
        serviceName: process.env.PHOENIX_PROJECT_NAME || 'mastra-service',
        exporters: [
          new ArizeExporter({
            endpoint: process.env.PHOENIX_COLLECTOR_ENDPOINT!,
            apiKey: process.env.PHOENIX_API_KEY,
            projectName: process.env.PHOENIX_PROJECT_NAME,
          }),
        ],
      },
    },
  }),
})
```

:::note[透過 Docker 快速入門]

如要在本機測試，可啟動將資料儲存在記憶體中的 Phoenix 實例：

```bash
docker run --pull=always -d --name arize-phoenix -p 6006:6006 \
  -e PHOENIX_SQL_DATABASE_URL="sqlite:///:memory:" \
  arizephoenix/phoenix:latest
```

設定 `PHOENIX_COLLECTOR_ENDPOINT=http://localhost:6006/v1/traces`，然後運行 Mastra Agent，便可到 [localhost:6006](http://localhost:6006) 查看 Trace。

:::

### 設定 Arize AX {/* #arize-ax-setup */}

Arize AX 是可觀測性平台，提供託管雲端和企業自行託管兩種部署方式，並為生產環境中的 AI 系統提供進階功能。

#### 所需條件 {/* #prerequisites-1 */}

1. **Arize AX 帳戶**：到 [app.arize.com](https://app.arize.com/) 登記。
2. **空間 ID**：準備所屬機構的空間識別碼。
3. **API 密鑰**：在 Arize AX 設定內產生密鑰。
4. **環境變數**：在以下環境變數填入憑證。

```bash title=".env"
# Required
ARIZE_SPACE_ID=your-space-id
ARIZE_API_KEY=your-api-key

# Optional
ARIZE_PROJECT_NAME=mastra-service
```

#### 只透過環境變數設定 {/* #zero-config-setup-1 */}

設定環境變數後，便可使用匯出器，毋須再傳入配置：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { ArizeExporter } from '@mastra/arize'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      arize: {
        serviceName: 'mastra-service',
        exporters: [new ArizeExporter()],
      },
    },
  }),
})
```

#### 直接傳入配置 {/* #explicit-configuration-1 */}

亦可直接傳入憑證；傳入的值優先於環境變數：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { ArizeExporter } from '@mastra/arize'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      arize: {
        serviceName: process.env.ARIZE_PROJECT_NAME || 'mastra-service',
        exporters: [
          new ArizeExporter({
            apiKey: process.env.ARIZE_API_KEY!,
            spaceId: process.env.ARIZE_SPACE_ID!,
            projectName: process.env.ARIZE_PROJECT_NAME,
          }),
        ],
      },
    },
  }),
})
```

## 配置選項 {/* #configuration-options */}

Arize 匯出器提供進階配置，可用來微調 OpenTelemetry 的運作方式：

### 完整配置 {/* #complete-configuration */}

```typescript
new ArizeExporter({
  // Phoenix Configuration
  endpoint: 'https://your-collector.example.com/v1/traces', // Required for Phoenix

  // Arize AX Configuration
  spaceId: 'your-space-id', // Required for Arize AX

  // Shared Configuration
  apiKey: 'your-api-key', // Required for authenticated endpoints
  projectName: 'mastra-service', // Optional project name

  // Optional OTLP settings
  headers: {
    'x-custom-header': 'value', // Additional headers for OTLP requests
  },

  // Debug and performance tuning
  logLevel: 'debug', // Logging: debug | info | warn | error
  batchSize: 512, // Batch size before exporting spans
  timeout: 30000, // Timeout in ms before exporting spans

  // Custom resource attributes
  resourceAttributes: {
    'deployment.environment': process.env.NODE_ENV,
    'service.version': process.env.APP_VERSION,
  },
})
```

### 批量處理選項 {/* #batch-processing-options */}

以下選項可控制 Trace 如何分批處理和匯出：

```typescript
new ArizeExporter({
  endpoint: process.env.PHOENIX_COLLECTOR_ENDPOINT!,
  apiKey: process.env.PHOENIX_API_KEY,

  // Batch processing configuration
  batchSize: 512, // Number of spans to batch (default: 512)
  timeout: 30000, // Max time in ms to wait before export (default: 30000)
})
```

### 資源屬性 {/* #resource-attributes */}

為所有匯出的 span 加上自訂屬性：

```typescript
new ArizeExporter({
  endpoint: process.env.PHOENIX_COLLECTOR_ENDPOINT!,
  resourceAttributes: {
    'deployment.environment': process.env.NODE_ENV,
    'service.namespace': 'production',
    'service.instance.id': process.env.HOSTNAME,
    'custom.attribute': 'value',
  },
})
```

### 自訂元資料 {/* #custom-metadata */}

非保留的 span 屬性會序列化至 OpenInference 的 `metadata` 資料內容，並在 Arize 或 Phoenix 中顯示。可透過 `tracingOptions.metadata` 加入這些屬性：

```ts
await agent.generate(input, {
  tracingOptions: {
    metadata: {
      companyId: 'acme-co',
      tier: 'enterprise',
    },
  },
})
```

系統會自動排除保留欄位，例如 `input`、`output`、`sessionId`、執行緒 ID、用戶 ID 和 OpenInference ID。

## OpenInference 語義慣例 {/* #openinference-semantic-conventions */}
