# LangSmith

[LangSmith](https://smith.langchain.com/) 是 LangChain 提供的 LLM 應用程式監察及評估平台。LangSmith 匯出器會將 Trace 傳送到 LangSmith，讓你查看模型效能、調試問題，以及執行評估流程。

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/langsmith@latest
```

## 配置 {/* #configuration */}

### 先決條件 {/* #prerequisites */}

1. **LangSmith 帳戶**：到 [smith.langchain.com](https://smith.langchain.com) 登記帳戶。
2. **API 密鑰**：在 LangSmith 的 Settings → API Keys 產生 API 密鑰。
3. **環境變數**：透過環境變數設定憑證。

```bash title=".env"
# Required
LANGSMITH_API_KEY=ls-xxxxxxxxxxxx

# Optional
LANGCHAIN_PROJECT=my-project  # Default project for traces
LANGSMITH_BASE_URL=https://api.smith.langchain.com  # For self-hosted
```

### 透過環境變數配置 {/* #zero-config-setup */}

設定環境變數後，建立匯出器時毋須另外傳入配置：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { LangSmithExporter } from '@mastra/langsmith'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      langsmith: {
        serviceName: 'my-service',
        exporters: [new LangSmithExporter()],
      },
    },
  }),
})
```

### 直接傳入配置 {/* #explicit-configuration */}

你亦可以直接將憑證傳入匯出器。直接傳入的值優先於環境變數：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { LangSmithExporter } from '@mastra/langsmith'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      langsmith: {
        serviceName: 'my-service',
        exporters: [
          new LangSmithExporter({
            apiKey: process.env.LANGSMITH_API_KEY,
          }),
        ],
      },
    },
  }),
})
```

## 配置選項 {/* #configuration-options */}

### 完整配置 {/* #complete-configuration */}

```typescript
new LangSmithExporter({
  // Required credentials
  apiKey: process.env.LANGSMITH_API_KEY!,

  // Optional settings
  apiUrl: process.env.LANGSMITH_BASE_URL, // Default: https://api.smith.langchain.com
  projectName: 'my-project', // Project to send traces to (overrides LANGCHAIN_PROJECT env var)
  callerOptions: {
    // HTTP client options
    timeout: 30000, // Request timeout in ms
    maxRetries: 3, // Retry attempts
  },
  logLevel: 'info', // Diagnostic logging: debug | info | warn | error

  // LangSmith-specific options
  hideInputs: false, // Hide input data in UI
  hideOutputs: false, // Hide output data in UI
})
```

### 環境變數 {/* #environment-variables */}

| 變數 | 說明 |
| - | - |
| `LANGSMITH_API_KEY` | LangSmith API 密鑰（必須提供） |
| `LANGCHAIN_PROJECT` | 接收 Trace 的預設項目名稱（可選，預設值為「default」） |
| `LANGSMITH_BASE_URL` | 自行託管的 LangSmith 實例的 API URL（可選） |

`projectName` 配置選項優先於 `LANGCHAIN_PROJECT` 環境變數，因此可以透過程式碼將 Trace 傳送到不同項目。

## 動態配置 {/* #dynamic-configuration */}

你可利用 `withLangsmithMetadata` 在執行期間覆寫個別 span 的 LangSmith 設定，例如按客戶、環境或功能將 Trace 傳送到不同項目。

### 使用輔助函數 {/* #using-the-helper */}

配合 `withLangsmithMetadata` 和 `buildTracingOptions`，便可設定 LangSmith 專用選項：

```typescript title="src/agents/support-agent.ts"
import { Agent } from '@mastra/core/agent'
import { buildTracingOptions } from '@mastra/observability'
import { withLangsmithMetadata } from '@mastra/langsmith'

export const supportAgent = new Agent({
  id: 'support-agent',
  name: 'support-agent',
  instructions: 'You are a helpful support agent.',
  model: '__GATEWAY_OPENAI_MODEL__',
  defaultOptions: {
    tracingOptions: buildTracingOptions(withLangsmithMetadata({ projectName: 'customer-support' })),
  },
})
```

### 動態選擇目標項目 {/* #dynamic-project-routing */}

使用 `requestContext`，按執行期間的條件將 Trace 傳送到不同項目。

```typescript title="src/mastra/agents/support-agent.ts"
import { Agent } from '@mastra/core/agent'
import { buildTracingOptions } from '@mastra/observability'
import { withLangsmithMetadata } from '@mastra/langsmith'

export const supportAgent = new Agent({
  id: 'support-agent',
  name: 'support-agent',
  instructions: 'You are a helpful support agent.',
  model: '__GATEWAY_OPENAI_MODEL__',
  defaultOptions: ({ requestContext }) => {
    const userTier = requestContext?.get('user-tier') as string
    const userId = requestContext?.get('user-id') as string

    return {
      tracingOptions: buildTracingOptions(
        withLangsmithMetadata({
          projectName: userTier === 'enterprise' ? 'enterprise-traces' : 'standard-traces',
          sessionId: userId,
        }),
      ),
    }
  },
})
```

### 可用欄位 {/* #available-fields */}

輔助函數 `withLangsmithMetadata` 接受以下欄位：

| 欄位 | 類型 | 說明 |
| - | - | - |
| `projectName` | string | 覆寫此 Trace 的目標項目 |
| `sessionId` | string | 按會話將相關 Trace 分組 |
| `sessionName` | string | 會話的顯示名稱 |

所有欄位均可省略。此函數會將傳入的欄位與現有元資料合併，因此可以多次呼叫，亦可配合其他追蹤選項使用。

## 對話串 {/* #conversation-threads */}

LangSmith 使用元資料鍵 `session_id`，把執行記錄歸入同一個[對話串](https://docs.langchain.com/langsmith/threads)。匯出器會在 Trace 內每項執行記錄設定這個鍵。根執行記錄會按優先次序取用第一個可用的值，依次是經 `withLangsmithMetadata({ sessionId })` 明確傳入的值、span 元資料中的 `sessionId`，以及 Mastra 記憶中的 `threadId`。子執行記錄會沿用上層執行記錄的會話，因此受委派的子 Agent 即使在自己衍生的對話串上執行，其記錄仍會歸入原有的對話串。

已啟用記憶功能的 Agent 每次執行都會設定 `threadId`。同一記憶對話串內的多輪對話因此會在 LangSmith 顯示於同一個對話串，毋須額外配置：

```typescript
const memory = { thread: 'thread-123', resource: 'user-1' }

await agent.generate('hi', { memory })
await agent.generate('and again', { memory })
```

## 評分及反饋 {/* #scores-and-feedback */}

透過 `mastra.observability.addScore()` 提交的評分，會在 LangSmith 顯示為相應執行記錄的反饋。只提供 `traceId` 時，評分會附加至該 Trace 的根執行記錄。提供 `spanId` 時，評分會附加至該 span 對應的執行記錄。

```typescript title="src/feedback.ts"
await mastra.observability.addScore({
  traceId,
  correlationContext: { traceId },
  score: { scorerId: 'user-feedback', scoreSource: 'user', score: 1, reason: 'Helpful answer' },
})
```

每項 LangSmith 執行記錄的 ID 均由對應的 Mastra span ID 推算。因此，即使進程已重新啟動，或 Trace 已匯出多時，仍可從任何進程提交 span 層級的評分。提交 Trace 層級的評分時，匯出器會利用每項執行記錄所儲存的 `mastra_trace_id` 元資料，在所配置的項目內找出根執行記錄。較早版本的 `@mastra/langsmith` 匯出的執行記錄會保留原有 ID，只可由當初匯出這些記錄的進程提交評分。若要在自己的介面連結到某項執行記錄，可呼叫 `langsmithRunIdFor()` 按相同規則推算該記錄的 ID：

```typescript
import { langsmithRunIdFor } from '@mastra/langsmith'

const runId = langsmithRunIdFor(spanId)
```
