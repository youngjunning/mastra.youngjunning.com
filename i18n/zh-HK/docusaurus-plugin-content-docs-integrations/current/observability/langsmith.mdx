# 蘭史密斯

[蘭史密斯](https://smith.langchain.com/)是LangChain用於監控和評估LLM申請的平台。 LangSmith 匯出器將您的追蹤發送到 LangSmith，提供有關模型效能和調試功能以及評估Workflow的見解。

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/langsmith@latest
```

## 配置 {/* #configuration */}

### 先決條件 {/* #prerequisites */}

1. **朗史密斯帳戶**: 報名於[smith.langchain.com](https://smith.langchain.com)
2. **API金鑰**：在 LangSmith 設定 → API 金鑰中產生 API 金鑰
3. **環境變數**：設定您的憑證

```bash title=".env"
# Required
LANGSMITH_API_KEY=ls-xxxxxxxxxxxx

# Optional
LANGCHAIN_PROJECT=my-project  # Default project for traces
LANGSMITH_BASE_URL=https://api.smith.langchain.com  # For self-hosted
```

### 零配置設定 {/* #zero-config-setup */}

設定環境變數後，無需配置即可使用匯出器：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { LangSmithExporter } from '@mastra/langsmith'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      langsmith: {
        serviceName: 'my-service',
        exporters: [new LangSmithExporter()],
      },
    },
  }),
})
```

### 明確配置 {/* #explicit-configuration */}

您也可以直接傳遞憑證（優先於環境變數）：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { LangSmithExporter } from '@mastra/langsmith'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      langsmith: {
        serviceName: 'my-service',
        exporters: [
          new LangSmithExporter({
            apiKey: process.env.LANGSMITH_API_KEY,
          }),
        ],
      },
    },
  }),
})
```

## 配置選項 {/* #configuration-options */}

### 完整配置 {/* #complete-configuration */}

```typescript
new LangSmithExporter({
  // Required credentials
  apiKey: process.env.LANGSMITH_API_KEY!,

  // Optional settings
  apiUrl: process.env.LANGSMITH_BASE_URL, // Default: https://api.smith.langchain.com
  projectName: 'my-project', // Project to send traces to (overrides LANGCHAIN_PROJECT env var)
  callerOptions: {
    // HTTP client options
    timeout: 30000, // Request timeout in ms
    maxRetries: 3, // Retry attempts
  },
  logLevel: 'info', // Diagnostic logging: debug | info | warn | error

  // LangSmith-specific options
  hideInputs: false, // Hide input data in UI
  hideOutputs: false, // Hide output data in UI
})
```

### 環境變數 {/* #environment-variables */}

|變數|描述 |
| - | - |
|`LANGSMITH_API_KEY` | Your LangSmith API key (required) |
| `LANGCHAIN_PROJECT` | Default project name for traces (optional, defaults to "default") |
| `LANGSMITH_BASE_URL` | API URL for self-hosted instances (optional) |

這`projectName` config option takes precedence over the `LANGCHAIN_PROJECT` environment variable, allowing you to programmatically route traces to different projects.

## 動態配置 {/* #dynamic-configuration */}

您可以使用以下命令在運行時覆蓋每個跨度的 LangSmith 設置`withLangsmithMetadata`. This is useful for routing traces to different projects based on runtime conditions (e.g., customer, environment, or feature).

### 使用助手 {/* #using-the-helper */}

使用`withLangsmithMetadata` with `buildTracingOptions` to set LangSmith-specific options:

```typescript title="src/agents/support-agent.ts"
import { Agent } from '@mastra/core/agent'
import { buildTracingOptions } from '@mastra/observability'
import { withLangsmithMetadata } from '@mastra/langsmith'

export const supportAgent = new Agent({
  id: 'support-agent',
  name: 'support-agent',
  instructions: 'You are a helpful support agent.',
  model: '__GATEWAY_OPENAI_MODEL__',
  defaultOptions: {
    tracingOptions: buildTracingOptions(withLangsmithMetadata({ projectName: 'customer-support' })),
  },
})
```

### 動態項目路由 {/* #dynamic-project-routing */}

使用`requestContext` to route traces to different projects based on runtime conditions.

```typescript title="src/mastra/agents/support-agent.ts"
import { Agent } from '@mastra/core/agent'
import { buildTracingOptions } from '@mastra/observability'
import { withLangsmithMetadata } from '@mastra/langsmith'

export const supportAgent = new Agent({
  id: 'support-agent',
  name: 'support-agent',
  instructions: 'You are a helpful support agent.',
  model: '__GATEWAY_OPENAI_MODEL__',
  defaultOptions: ({ requestContext }) => {
    const userTier = requestContext?.get('user-tier') as string
    const userId = requestContext?.get('user-id') as string

    return {
      tracingOptions: buildTracingOptions(
        withLangsmithMetadata({
          projectName: userTier === 'enterprise' ? 'enterprise-traces' : 'standard-traces',
          sessionId: userId,
        }),
      ),
    }
  },
})
```

### 可用字段 {/* #available-fields */}

這`withLangsmithMetadata` helper accepts these fields:

|領域 |類型 |描述 |
| - | - | - |
|`projectName` | string | Override the project for this trace |
| `sessionId` | string | Group related traces by session |
| `sessionName` | string | Display name for the session |

所有欄位都是可選的。此幫助器與任何現有元資料合併，因此您可以多次呼叫它或與其他追蹤選項結合使用。

## 對話主題 {/* #conversation-threads */}

LangSmith 集團遇到了[Thread](https://docs.langchain.com/langsmith/threads) using the `session_id` metadata key. The exporter sets it on every run of a trace. The root run takes the first value it finds: an explicit `withLangsmithMetadata({ sessionId })`, then `sessionId` in span metadata, then the Mastra memory `threadId`. Child runs take the session of their parent run, so a delegated sub-agent stays in the conversation's Thread even though it runs on its own derived thread.

具有記憶設定的Agent`threadId` on each run, so turns on the same memory thread appear as one Thread in LangSmith without extra configuration:

```typescript
const memory = { thread: 'thread-123', resource: 'user-1' }

await agent.generate('hi', { memory })
await agent.generate('and again', { memory })
```

## 分數和回饋 {/* #scores-and-feedback */}

成績已發送`mastra.observability.addScore()` show up in LangSmith as feedback on the matching run. A score with only a `traceId` is attached to the trace's root run; a score with a `spanId` is attached to that span's run.

```typescript title="src/feedback.ts"
await mastra.observability.addScore({
  traceId,
  correlationContext: { traceId },
  score: { scorerId: 'user-feedback', scoreSource: 'user', score: 1, reason: 'Helpful answer' },
})
```

每個 LangSmith 運行 ID 均源自其 Mastra 跨度 ID，因此跨度級別分數適用於任何進程、重新啟動後以及在導出追蹤後很長時間。追蹤級別分數透過以下方式找到導出器項目中的根運行`mastra_trace_id` metadata the exporter stores on every run. Runs exported by earlier versions of `@mastra/langsmith` keep their original ids and can only be scored from the process that exported them. The same derivation is exported as `langsmithRunIdFor()` if you need to link to a run from your own UI:

```typescript
import { langsmithRunIdFor } from '@mastra/langsmith'

const runId = langsmithRunIdFor(spanId)
```
