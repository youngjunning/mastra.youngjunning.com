# Confident AI

[Confident AI](https://www.confident-ai.com/) 是一個提供 LLM Observability 和評估功能的平台，協助團隊在開發和正式環境中建立可靠的 AI 應用程式。

[`confident-trace`](https://github.com/confident-ai/confident-trace) 提供的 `ConfidentMastraExporter` 會將 Mastra 的 Trace 傳送至 Confident AI。平台會顯示每次 Agent 執行時完整的 Agent、Model 和 Tool 層級結構，並可在收到執行紀錄時自動評分。

## 安裝 {/* #installation */}

```bash npm2yarn
npm install confident-trace@latest
```

## 設定 {/* #configuration */}

### 先決條件 {/* #prerequisites */}

1. **Confident AI 帳戶**：在 [confident-ai.com](https://app.confident-ai.com) 註冊
1. **API 密鑰**：在 Confident AI 的項目設定中產生密鑰
1. **環境變數**：設定憑證：

```bash title=".env"
CONFIDENT_API_KEY=confident_proj_xxxxxxxxxxxxx

# Optional. EU region, defaults to the US servers
CONFIDENT_OTEL_ENDPOINT=https://eu.otel.confident-ai.com/v1/traces
```

### 無需額外設定 {/* #zero-config-setup */}

設定環境變數後，無需額外設定即可使用匯出器：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { ConfidentMastraExporter } from 'confident-trace/mastra'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      confidentAI: {
        serviceName: 'my-service',
        exporters: [new ConfidentMastraExporter()],
      },
    },
  }),
})
```

### 直接設定 {/* #explicit-configuration */}

也可以直接傳入憑證，直接提供的憑證會優先於環境變數中的憑證：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { ConfidentMastraExporter } from 'confident-trace/mastra'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      confidentAI: {
        serviceName: 'my-service',
        exporters: [
          new ConfidentMastraExporter({
            apiKey: process.env.CONFIDENT_API_KEY,
            endpoint: process.env.CONFIDENT_OTEL_ENDPOINT,
          }),
        ],
      },
    },
  }),
})
```

可使用以下選項：

```typescript
new ConfidentMastraExporter({
  apiKey: process.env.CONFIDENT_API_KEY, // Default: CONFIDENT_API_KEY
  endpoint: process.env.CONFIDENT_OTEL_ENDPOINT, // Default: US servers
  captureContent: false, // Omit inputs, outputs, and messages
  maxContentBytes: 512, // Truncate captured content
  timeoutMillis: 30000, // Flush and shutdown budget
  resourceAttributes: { 'service.name': 'my-agent' }, // Overrides serviceName
})
```

Trace 會帶有 Mastra 設定的 `serviceName`，除非 `resourceAttributes['service.name']` 覆寫該值。Mastra 會在匯出前執行自身的取樣、篩選器和 span 處理器，因此 Confident AI 只會收到處理流程放行的資料。

## 支援的訊號 {/* #supported-signals */}

匯出器會將已結束的 Mastra span 轉換為 OTLP span，並保留 Trace ID、span ID、父級 ID、外部父級 ID 和原始時間戳。匯出器無需快取開始事件，因此 Workflow 恢復執行後的 span 和未按順序完成的 span 均可正確匯出。

- **Agent 和 Workflow 的執行**：操作名稱、時間資訊、狀態，以及各步驟之間的父子關係。
- **Model 調用**：Model 詳情、訊息、結束原因，以及 [token 用量](https://www.confident-ai.com/docs/llm-tracing/features/token-usage-cost)。
- **Tool 調用**：Tool 名稱及其[輸入和輸出](https://www.confident-ai.com/docs/llm-tracing/features/input-output)。
- **Trace 詳情**：根操作的名稱、標籤、元資料、輸入和輸出。
- **錯誤**：失敗的操作會保留其錯誤狀態，方便在 Trace 中查看失敗情況。

此整合會匯出 Trace 資料，當中不包括 Mastra 的日誌、指標、分數和意見回饋。

## 自訂 Trace 元資料 {/* #custom-trace-metadata */}

透過 Mastra 的 `tracingOptions` 傳入的元資料和標籤會轉送至 Confident AI 的 Trace，你可以在 Confident AI 根據這些資料篩選和分組：

```typescript
const result = await mastra.getAgent('assistant').generate('How do you make the best coffee?', {
  tracingOptions: {
    metadata: { release: '2026-09', tier: 'enterprise' },
    tags: ['production', 'support'],
  },
})
```

你的元資料會與 Mastra 自行設定的欄位合併，例如 `runId`。標籤會套用至根 span，因此會顯示在 Trace 層級，而非個別 span 上。

## 生命週期 {/* #lifecycle */}

此匯出器由 Mastra 管理。Mastra 會建立自己的 OTLP 處理器，且不會註冊、取代或關閉全域 OpenTelemetry Provider。因此無需調用 `init()`，也無需在啟動指令中加入預載設定。

匯出器關閉時會批次傳送 span。請等所有 Agent 執行和串流均已完成後，再關閉匯出器一次，以免短時間執行的指令碼在任何資料送出前便結束：

```typescript
await observability.shutdown()
```

對於長時間運行的伺服器，請在伺服器正常關閉的過程中關閉匯出器，避免在每次請求後關閉。Trace 送出後，最多可能需要 30 秒才會在 Observatory 顯示。

## 對話串及 Trace 屬性 {/* #threads-and-trace-properties */}

此匯出器會對應 Mastra 自身提供的追蹤資料，因此 Trace 的元資料和標籤均來自上文所示的 `tracingOptions`。

若要將多輪對話歸入[對話串](https://www.confident-ai.com/docs/llm-tracing/features/threads)，或設定使用者 ID 等 Trace 層級的屬性，請使用 `confident-trace` SDK 的追蹤功能。此功能會直接接入 Mastra，無需透過匯出器。設定步驟請參閱 [Mastra 整合指南](https://www.confident-ai.com/docs/integrations/third-party/mastra)。

請選用其中一種方式，切勿同時使用兩種。
