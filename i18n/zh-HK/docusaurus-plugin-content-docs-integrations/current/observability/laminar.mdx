# Laminar

[Laminar](https://laminar.sh/) 是專為 AI Agent 而設、原生支援 OpenTelemetry 的開源 Observability 平台。只需在 `Observability` 設定中接入一個 `MastraExporter`，即可追蹤、偵錯和監察 Mastra 中每次 Agent 執行、每個 Model 步驟、每次 Tool 呼叫和每個子 Agent。

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @lmnr-ai/lmnr
```

## 設定 {/* #configuration */}

### 先決條件 {/* #prerequisites */}

1. **Laminar 項目**：在 Laminar 建立或選擇一個項目
1. **項目 API 金鑰**：從 Laminar 的項目設定複製 API 金鑰
1. **環境變數**：設定驗證憑證

```bash title=".env"
# Required
LMNR_PROJECT_API_KEY=lmnr_...

# Optional
LMNR_BASE_URL=https://api.lmnr.ai
```

### 無需額外設定 {/* #zero-config-setup */}

設定環境變數後，無需額外設定即可使用匯出器：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { Laminar, MastraExporter } from '@lmnr-ai/lmnr'

Laminar.initialize()

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      laminar: {
        serviceName: 'my-service',
        exporters: [new MastraExporter()],
      },
    },
  }),
})
```

### 直接指定設定 {/* #explicit-configuration */}

也可以直接傳入憑證（優先於環境變數中的設定）：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { Laminar, MastraExporter } from '@lmnr-ai/lmnr'

Laminar.initialize({
  projectApiKey: process.env.LMNR_PROJECT_API_KEY!,
  baseUrl: process.env.LMNR_BASE_URL, // Optional
  // ...other options
})

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      laminar: {
        serviceName: 'my-service',
        exporters: [
          new MastraExporter({
            realtime: process.env.NODE_ENV === 'development', // Optional
          }),
        ],
      },
    },
  }),
})
```

:::note
如需進階用法，包括 `MastraExporter` 的完整選項和多 Agent Trace 範例，請參閱 [Laminar 的 Mastra 整合指南](https://laminar.sh/docs/tracing/integrations/mastra)。
:::

Mastra 亦在 `@mastra/laminar` 中提供獨立的 [`LaminarExporter`](/reference/observability/tracing/exporters/laminar)，透過 OTLP/HTTP 傳送 span。此匯出器無法繼承目前生效的 OTel 上下文，也無法將 Mastra span 完整對應至 Laminar 的原生格式。因此，如需使用 `observe()` 包裝函式、支援多 Agent 的根 span，以及在 Laminar 中準確呈現追蹤資料，請使用上文的 `@lmnr-ai/lmnr` 整合。
