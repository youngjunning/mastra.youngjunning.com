# PostHog

[PostHog](https://posthog.com/) 是一個分析平台，具備 AI 可觀測性功能，方便監察大型語言模型（LLM）應用程式。PostHog 可透過以下兩種方式與 Mastra 整合：

- **Agent 工具**讓 Agent 透過 [Mastra Connect](/docs/mastra-platform/connect) 使用 PostHog 數據，包括事件、洞察結果及功能旗標。
- **[追蹤](#tracing)**會把 Mastra Trace 以結構化事件的形式匯出至 PostHog。

## Connect {/* #connect */}

開始前，請按 [Connect 設定指引](/docs/mastra-platform/connect#get-started)安裝 `@mastra/connect`，再設定 Mastra 平台上的項目。

## 追蹤 {/* #tracing */}

PostHog 匯出器會將 Trace 作為結構化事件傳送至 PostHog，讓你查看 token 用量、成本和延遲，以及分析對話流程。

### 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/posthog@latest
```

### 設定 {/* #configuration */}

#### 先決條件 {/* #prerequisites */}

1. **PostHog 帳戶**：在 [posthog.com](https://posthog.com/) 登記開立帳戶。
2. **項目 API 密鑰**：在 PostHog 的 Settings（設定）→ Project API Key（項目 API 密鑰）取得密鑰。
3. **環境變數**：將認證資料設為環境變數。

```bash title=".env"
# Required
POSTHOG_API_KEY=phc_xxxxxxxxxxxxxxxx

# Optional
POSTHOG_HOST=https://us.i.posthog.com  # or eu.i.posthog.com for EU region
```

#### 使用環境變數 {/* #zero-config-setup */}

設好環境變數後，建立匯出器時毋須另行傳入設定：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { PosthogExporter } from '@mastra/posthog'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      posthog: {
        serviceName: 'my-service',
        exporters: [new PosthogExporter()],
      },
    },
  }),
})
```

#### 直接提供認證資料 {/* #explicit-configuration */}

你亦可直接向匯出器提供認證資料。匯出器會優先使用這些資料，其次才讀取環境變數：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { PosthogExporter } from '@mastra/posthog'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      posthog: {
        serviceName: 'my-service',
        exporters: [
          new PosthogExporter({
            apiKey: process.env.POSTHOG_API_KEY,
          }),
        ],
      },
    },
  }),
})
```

### 設定選項 {/* #configuration-options */}

#### 完整設定示例 {/* #complete-configuration */}

```typescript
new PosthogExporter({
  // Required credentials
  apiKey: process.env.POSTHOG_API_KEY!,

  // Optional settings
  host: 'https://us.i.posthog.com', // Default: US region
  // or "https://eu.i.posthog.com" for EU region
  // or your self-hosted URL

  // Batching configuration
  flushAt: 20, // Batch size (default: 20)
  flushInterval: 10000, // Flush interval in ms (default: 10000)
  serverless: false, // Serverless mode: flushAt=10, flushInterval=2000

  // User identification
  defaultDistinctId: 'anonymous', // Fallback if no userId in metadata

  // Privacy settings
  enablePrivacyMode: false, // Excludes input/output from generation events

  // Diagnostic logging
  logLevel: 'info', // debug | info | warn | error
})
```

#### 無伺服器模式 {/* #serverless-mode */}

在無伺服器環境啟用此模式後，匯出器會減少每批事件的數量，並縮短批次傳送的間隔：

```typescript
new PosthogExporter({
  apiKey: process.env.POSTHOG_API_KEY!,
  serverless: true, // Configures smaller batches for faster flushing
})
```

#### 隱私模式 {/* #privacy-mode */}

啟用私隱模式後，匯出器會在模型生成事件中略去輸入及輸出數據，同時保留 token 用量指標：

```typescript
new PosthogExporter({
  apiKey: process.env.POSTHOG_API_KEY!,
  enablePrivacyMode: true, // Removes $ai_input and $ai_output_choices
})
```

#### 按群組分析 {/* #group-analytics */}

要將事件連結至 [PostHog 群組](https://posthog.com/docs/product-analytics/group-analytics)，可在 `tracingOptions.metadata` 加入 `$groups` 物件。匯出器呼叫 PostHog 的事件收集介面時，會透過最外層的 `groups` 欄位傳送這些值，讓你按群組查看 LLM 成本等分析數據。

```ts
await agent.generate(input, {
  tracingOptions: {
    metadata: {
      $groups: {
        publication: 'publication-1',
      },
    },
  },
})
```
