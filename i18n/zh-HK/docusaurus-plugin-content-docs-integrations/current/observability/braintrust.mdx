# Braintrust

[Braintrust](https://www.braintrust.dev/) 是一個評估和監察平台，可協助你量度及改善 LLM 應用程式的質素。Braintrust 匯出器會把 Trace 傳送到 Braintrust，讓你有系統地評估、評分和進行實驗。

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/braintrust@latest
```

## 設定 {/* #configuration */}

### 開始前的準備 {/* #prerequisites */}

1. 在 [braintrust.dev](https://www.braintrust.dev/) 登記 **Braintrust 帳戶**。
2. 建立或選擇一個用來接收 Trace 的 **項目**。
3. 前往 Braintrust 的 **Settings → API Keys**，產生 **API 密鑰**。
4. 按以下範例透過 **環境變數** 設定認證資料。

```bash title=".env"
BRAINTRUST_API_KEY=sk-xxxxxxxxxxxxxxxx

# Optional
BRAINTRUST_ENDPOINT=https://api.braintrust.dev  # Custom endpoint if needed
```

### 只使用環境變數 {/* #zero-config-setup */}

設好環境變數後，便可直接建立匯出器，毋須傳入設定。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { BraintrustExporter } from '@mastra/braintrust'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      braintrust: {
        serviceName: 'my-service',
        exporters: [new BraintrustExporter()],
      },
    },
  }),
})
```

### 直接傳入設定 {/* #explicit-configuration */}

你亦可直接把認證資料傳入匯出器。直接傳入的值會優先於環境變數。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { BraintrustExporter } from '@mastra/braintrust'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      braintrust: {
        serviceName: 'my-service',
        exporters: [
          new BraintrustExporter({
            apiKey: process.env.BRAINTRUST_API_KEY,
            projectName: 'my-project',
          }),
        ],
      },
    },
  }),
})
```

### 完整設定 {/* #complete-configuration */}

```typescript
new BraintrustExporter({
  // Required
  apiKey: process.env.BRAINTRUST_API_KEY!,

  // Optional settings
  projectName: 'my-project', // Default: 'mastra-tracing'
  endpoint: 'https://api.braintrust.dev', // Custom endpoint if needed
  logLevel: 'info', // Diagnostic logging: debug | info | warn | error
})
```

## 將 Trace 加入 Braintrust 評估 {/* #attach-traces-to-braintrust-evals */}

如果應用程式會用到 `Eval()`、`logger.traced()` 或 `currentSpan`，請直接安裝 Braintrust SDK。

```bash npm2yarn
npm install braintrust@latest
```

如果在 Braintrust 的 `Eval()` 或 `logger.traced()` 內執行 Mastra，請把 Braintrust 日誌記錄器和 `currentSpan` 解析函數傳入匯出器。匯入 `currentSpan` 時，須使用建立該評估或受追蹤 Span 的同一個 `braintrust` 套件實例。

如果應用程式和 `@mastra/braintrust` 各自載入了不同的 Braintrust SDK 副本，這項設定有助 Mastra 把自身的 Span 掛在當前的 Braintrust Span 之下。

匯出器接受 Braintrust SDK v2 和 v3 的兼容日誌記錄器及 Span 物件。應用程式可以使用與 `@mastra/braintrust` 所安裝版本不同的 Braintrust SDK。

```typescript title="src/mastra/index.ts"
import { currentSpan, initLogger } from 'braintrust'
import { BraintrustExporter } from '@mastra/braintrust'

const logger = initLogger({
  projectName: 'my-project',
  apiKey: process.env.BRAINTRUST_API_KEY,
})

const exporter = new BraintrustExporter({
  braintrustLogger: logger,
  currentSpan,
})
```

在 Braintrust 評估任務內使用已設定的 Mastra 實例。上面的 `currentSpan` 解析函數會讀取由 `Eval()` 建立、目前生效的 Span。

```typescript title="src/evals/braintrust.ts"
import { Eval } from 'braintrust'
import { mastra } from '../mastra'

await Eval('my-project', {
  data: () => [{ input: 'Say hello', expected: 'Hello' }],
  task: async input => {
    const agent = mastra.getAgent('assistant')
    return (await agent.generate(input)).text
  },
  scores: [],
})
```

如果應用程式使用 Nunjucks 提示詞範本，並將直接依賴的 Braintrust SDK 從 v2 升級至 v3，請按 [Braintrust v2 至 v3 遷移指南](https://www.braintrust.dev/docs/sdks/typescript/migrations/v2-to-v3) 操作。

## 以傳回的 `spanId` 查詢 Braintrust {/* #querying-braintrust-with-returned-spanid */}

Mastra 傳回的 `spanId` 同時用作 Braintrust 的記錄列 ID 和 Span ID。你可以用這個值查詢 `id` 或 `span_id` 欄位，找出相應的 Braintrust Span。

Braintrust v3 的 `root_span_id` 儲存獨立的 W3C Trace ID。因此，以 Mastra 傳回的 `spanId` 查詢時，請用上面兩個欄位之一，避免使用 `root_span_id`。

```typescript title="src/mastra/usage.ts"
const result = await agent.stream('Summarize this ticket')

console.log('Mastra trace ID:', result.traceId)
console.log('Braintrust row and span ID:', result.spanId)

// Use result.spanId in your Braintrust lookup/query path
```

`agent.generate()` 的傳回結果和 Workflow 的執行結果也可用同一方式查詢，包括 `run.start()`、`run.stream()` 的最終狀態及 `run.resume()`。

## 成本追蹤 {/* #cost-tracking */}

如果模型供應商有提供請求的收費金額，例如 OpenRouter 和 Vercel AI Gateway，匯出器會把該金額傳送到 Braintrust。Braintrust 會顯示供應商實際收取的費用。若某次生成沒有回報費用，Braintrust 仍會按自身的模型定價顯示估算金額。

具體規則載於 [`BraintrustExporter` 參考文件](/reference/observability/tracing/exporters/braintrust#cost-tracking)。
