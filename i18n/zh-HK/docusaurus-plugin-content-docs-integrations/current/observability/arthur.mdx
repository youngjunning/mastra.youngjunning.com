# 亞瑟

[亞瑟](https://arthur.ai/)[Arthur Engine](https://github.com/arthur-ai/arthur-engine)（開源）。 Arthur 匯出器使用 OpenTelemetry 發送追蹤訊息[開放推理](https://github.com/Arize-ai/openinference/tree/main/spec)語義約定。

## 安裝 {/* #installation */}

```bash npm2yarn
npm install @mastra/arthur@latest
```

## 配置 {/* #configuration */}

### 先決條件 {/* #prerequisites */}

1. **亞瑟引擎實例**: 遵循[Docker Compose deployment guide](https://docs.arthur.ai/docs/arthur-genai-engine-docker-compose-deployment-guide) to start an Arthur Engine
2. **API金鑰**: [Generate an API key](https://docs.arthur.ai/docs/api-keys-management) from the Arthur Engine UI at `http://localhost:3030`
3. **任務編號**（選修的）：[Create a task](https://docs.arthur.ai/docs/create-a-task) to route traces to a specific task

### 任務路由 {/* #task-routing */}

Arthur Engine 以兩種方式將追蹤與任務關聯起來：

* **按服務名稱**： 放`serviceName` in the observability config. Arthur Engine automatically routes traces to the task matching that name, creating it if needed.
* **按任務ID**：透過預先存在的`taskId` to the exporter to send traces to a specific task directly.

如果兩者都提供，`taskId` takes precedence.

### 環境變數 {/* #environment-variables */}

```bash title=".env"
# Required
ARTHUR_API_KEY=your-api-key
ARTHUR_BASE_URL=http://localhost:3030

# Optional - route traces to a pre-existing task by ID
ARTHUR_TASK_ID=your-task-id
```

### 零配置設定 {/* #zero-config-setup */}

設定環境變數後，無需配置即可使用匯出器：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { ArthurExporter } from '@mastra/arthur'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      arthur: {
        serviceName: 'my-service',
        exporters: [new ArthurExporter()],
      },
    },
  }),
})
```

### 明確配置 {/* #explicit-configuration */}

您也可以直接傳遞憑證（優先於環境變數）：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { ArthurExporter } from '@mastra/arthur'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      arthur: {
        serviceName: 'my-service',
        exporters: [
          new ArthurExporter({
            apiKey: process.env.ARTHUR_API_KEY!,
            endpoint: process.env.ARTHUR_BASE_URL!,
            taskId: process.env.ARTHUR_TASK_ID,
          }),
        ],
      },
    },
  }),
})
```

## 配置選項 {/* #configuration-options */}

### 完整配置 {/* #complete-configuration */}

```typescript
new ArthurExporter({
  // Arthur Configuration
  apiKey: 'your-api-key', // Required
  endpoint: 'http://localhost:3030', // Required
  taskId: 'your-task-id', // Optional

  // Optional OTLP settings
  headers: {
    'x-custom-header': 'value', // Additional headers for OTLP requests
  },

  // Debug and performance tuning
  logLevel: 'debug', // Logging: debug | info | warn | error
  batchSize: 512, // Batch size before exporting spans
  timeout: 30000, // Timeout in ms before exporting spans

  // Custom resource attributes
  resourceAttributes: {
    'deployment.environment': process.env.NODE_ENV,
    'service.version': process.env.APP_VERSION,
  },
})
```

### 自訂元數據 {/* #custom-metadata */}

非保留的跨距屬性被序列化到 OpenInference 中`metadata` payload and surface in Arthur. You can add them via `tracingOptions.metadata`:

```ts
await agent.generate(input, {
  tracingOptions: {
    metadata: {
      companyId: 'acme-co',
      tier: 'enterprise',
    },
  },
})
```

保留字段，例如`input`, `output`, `sessionId`, thread/user IDs, and OpenInference IDs are excluded automatically.
