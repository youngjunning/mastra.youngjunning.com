主題樂園 Agent 已經查得到樂園 ID 和即時排隊時間，但 QTimes JSON API 沒有提供部分規劃行程所需的資訊。這堂課會接入外部工具，讓 Agent 也能回答營業時間、預估人潮等問題。

把 Agent 連到 MCP 伺服器，讓網頁資料擷取工具和既有的本機工具一同供 Agent 使用。接著修改 Agent 的指令，讓它知道什麼時候要先查樂園 ID，什麼時候該從樂園網頁擷取結構化資訊。

實務上，助理很少能靠單一 API 取得所有資訊。結合即時 API 資料與從網頁擷取的結構化內容，必要時再納入天氣資訊，Agent 就能補足資料缺口，不用為每個需求另外寫網頁爬蟲。

> 「工具接好不代表 Agent 就會用對。你得告訴它何時該用這項工具，以及理由。」
>
> — Guil Hernandez
