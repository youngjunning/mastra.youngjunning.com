做到這一步，編輯器裡的程式開發 Agent 已經開始和你一起寫程式。這堂課由 Guil 示範實用的設定方式，讓 Agent 有資料可依循，避免自行猜測或採用舊版 Mastra 的寫法。

你會查看 Mastra Skills 在專案裡如何存放、Agent 實際讀了哪些檔案，以及這些參考資料如何引導它產生和修改程式碼。接著，你會知道何時該用 MCP 文件伺服器補足 Skills，直接查詢最新文件和遷移指引。

AI 輔助開發常因 Mastra 用法過時或遭到杜撰而出錯。提供可靠的本機資料，必要時再查線上文件，能讓你在繼續開發主題樂園 Agent 的工具時少做一些重工，也能讓實作符合 Mastra 的實際 API 與慣用寫法。

> 「最怕的是寫程式的 Agent 很有把握地把 Mastra 的用法編出來。所以我們把 Skills 放在儲存庫裡，讓它寫程式時就能查到真正的寫法。」
>
> — Guil Hernandez
