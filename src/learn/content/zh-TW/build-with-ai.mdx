您正處於構建階段，編輯器的編碼Agent開始與您一起進行實際工作，本課程的重點是保持幫助的準確性。 Guil 介紹了防止Agent猜測或使用過時的 Mastra 模式的實用設定。

您將檢查 Mastra Skills 如何在專案中運行、Agent實際讀取哪些文件，以及這些引用如何指導程式碼產生和編輯。然後，您將了解何時使用 MCP 樣式的文件伺服器來補充技能，以便直接、可查詢地存取目前文件和遷移協助。

這很重要，因為「陳舊或虛構的 Mastra 細節」是人工智慧輔助編碼脫軌的最常見原因之一。透過為Agent提供可靠的本地知識來源（以及需要時的即時文件回退），您可以在繼續為主題公園Agent專案建立Tool時減少返工並使實施與 Mastra 的真實 API 和模式保持一致。

> “最大的失敗模式是當您的編碼Agent自信地發明 Mastra 細節時，因此我們在存儲庫中為它提供了技能，讓它可以在工作時讀取真實的模式。”
>
> — 吉爾·埃爾南德斯
