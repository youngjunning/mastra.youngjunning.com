主題樂園 Agent 已部署完成，可透過 HTTP 存取。這堂課會用 Mastra 的 Channels 功能串接 Slack，讓你在任何能使用 Slack 的地方傳訊息給 Agent。

先安裝 `@chat-adapter/slack` 套件，在主題樂園 Agent 中加入 `channels` 設定，並建立具備所需權限範圍的 Slack 應用程式。Mastra 會自動公開 webhook 路由。把 Slack 的 Event Subscriptions 指向該路由，訊息就會直接傳給 Agent。

用 Slack 私訊也能使用同一套工具、記憶和需要核准的購票 Workflow。Discord 和 Telegram 也能用 Channels 以同樣方式串接：安裝轉接器、加到 `channels.adapters`、設定環境變數並部署，再把平台的 webhook 指向 Mastra 產生的路由。

> 「Webhook 處理程式不用自己寫，Slack 簽章也不用自己驗證。轉接器都會處理。」
>
> — Guil Hernandez
