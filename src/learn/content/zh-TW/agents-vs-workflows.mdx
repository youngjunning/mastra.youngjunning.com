購票 Workflow 做好後，正適合釐清 Agent 和 Workflow 的分工。這兩個詞的用法不一定一致，本課著重它們實際怎麼運作，以及如何在專案中搭配使用。

Agent 就像系統裡「會說話的大腦」：它是能使用工具和記憶的語言模型。模型會自行決定要做什麼、呼叫哪些工具、什麼時候結束，沒有預先排好的路徑。Workflow 則由你訂出步驟、順序和完成條件。拿購票來說，結帳流程是你定義的，不必交給模型判斷。Mastra 支援兩種搭配方式：在 Workflow 中使用 Agent，或讓 Agent 把 Workflow 當成工具。

知道何時該用哪一種，就不會為簡單任務設計不必要的 Workflow，也不會把應依固定規則執行、必須可控的工作交給模型。

> 「結帳流程由我們自己定義，不需要模型想出做法。」
>
> — Guil Hernandez
