您已經開始進行樂園查找，現在您將採取下一步，讓主題樂園Agent真正為您提供協助。在本課程中，您將添加一項新功能，以獲取公園當前發生情況的即時快照。

您將建立一個接受公園 ID 並返回精選景點清單的Tool，其中包含位置/土地、開放狀態和當前發布的等待時間等關鍵欄位。您還將確保結果經過排序，以便最短的等待時間上升到頂部，從而使輸出立即可用於建議。

這很重要，因為公園的實際情況變化很快，Agent商需要新鮮的結構化資料來規劃一天中的實際路線。您還將將該Tool連接到Agent中，並在 Mastra Studio 內測試完整的「尋找 → 即時快照」鏈，以便Agent始終在正確的時間呼叫正確的Tool。

> “等待時間變化很快，因此在獲取數據時始終返回。該時間戳使快照值得信賴。”
>
> — 吉爾·埃爾南德斯
