樂園查詢已經可以用了，接下來要讓主題樂園 Agent 提供更實用的建議。這堂課會新增一項功能，讓它取得樂園當下狀況的快照。

你會建立一個接收樂園 ID 的工具，傳回篩選過的遊樂設施清單，包含位置或園區、是否開放，以及目前公告的排隊時間。把排隊時間最短的設施放在最前面，結果就能直接拿來做推薦。

園內狀況變得很快，Agent 得用最新的結構化資料，才能排出走得完的一日遊路線。把工具接上 Agent 後，你會在 Mastra Studio 測試從查詢樂園到取得即時快照的完整流程，確認它每次都能在適當時機呼叫正確的工具。

> 「排隊時間變動很快，所以一定要一併傳回取得資料的時間。有了時間戳記，才知道這份快照可不可靠。」
>
> — Guil Hernandez
