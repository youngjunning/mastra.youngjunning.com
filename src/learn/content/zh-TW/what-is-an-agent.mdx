這是課程的第一站。Guil 會先打好後續課程的基礎，讓你看看 Agent 在實務上如何運作。這堂課會帶你認識什麼是 Agent、只靠提示有哪些限制，以及 Mastra 如何組織各項基本元件。

你會看到 Agent 從頭到尾跑完一次任務：它怎麼呼叫工具、用先前的上下文回答追問，以及你如何藉由更換模型和調整指令改變它的行為。你也會先了解這門課要做的專案：一個會取得即時資料、提供建議，還能引導使用者完成多步驟任務的主題樂園助理。

後面的課程需要你分辨單輪聊天回應，以及能可靠執行動作的系統。了解工具、Workflow、記憶和可觀測性如何搭配之後，你就能開發在開發期間可測試、可部署到正式環境的功能，也不必猜模型到底做了什麼。
