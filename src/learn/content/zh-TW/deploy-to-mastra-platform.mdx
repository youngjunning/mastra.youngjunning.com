您一直在 Studio 中建立主題公園Agent程式。為了與其他人分享，它需要在公共地方運作。在本課程中，您將把它部署到Mastra Server，Mastra 的Agent雲端部署產品。一個命令可將您的本地專案帶到即時端點，並為您管理路由、擴展和基礎設施。

在部署之前，您將在以下位置探索 Swagger UI：`http://localhost:4111/swagger-ui`。主題樂園Agent程式和本課程中的所有其他Agent程式都已作為 HTTP 端點公開：用於產生回應、串流和運行Workflow的路由。然後`mastra server deploy`

Mastra 已經是一個 HTTP 伺服器。 Studio 只是在本地與其對話的一種方式。 Mastra 伺服器將同一台伺服器放在公共 URL 上，主題樂園Agent程式成為任何服務都可以呼叫的端點。

> “Mastra 已經是一個 HTTP 伺服器。Studio 只是在本地與其通信的一種方式。Mastra Server 將同一台伺服器放在公共的地方。”
>
> — 吉爾·埃爾南德斯
