你已經在 Studio 裡開發了主題樂園 Agent。要分享給其他人使用，就得把它放到可公開存取的環境。這堂課會部署到 Mastra Server，也就是 Mastra 為 Agent 提供的雲端部署服務。只要一行指令，就能把本機專案部署成可連線的端點，路由、自動擴充所需的管理和基礎設施由平台負責。

部署前，先到 `http://localhost:4111/swagger-ui` 看看 Swagger UI。課程中的主題樂園 Agent 和其他 Agent 都已提供 HTTP 端點，有產生回應、串流及執行 Workflow 的路由。接下來，`mastra server deploy` 會驗證身分、建置並部署 Docker 映像檔，最後印出穩定的 URL。

Mastra 本身就是 HTTP 伺服器；Studio 是在本機與它互動的其中一種方式。Mastra Server 讓同一個伺服器有公開網址，其他服務就能呼叫主題樂園 Agent 的端點。

> 「Mastra 本身就是 HTTP 伺服器。Studio 是在本機與它互動的一種方式。Mastra Server 則把同一個伺服器放到可公開存取的環境。」
>
> — Guil Hernandez
