基本訊息歷史記錄有限制。隨著對話的增長，原始歷史記錄會快速堆積：Tool調用、等待時間查找、天氣檢查、抓取的公園資料。在本課程中，您將啟用觀察記憶，它將不斷增長的歷史記錄壓縮為Agent可以實際使用的更密集的上下文。

您將把Agent切換到`observationalMemory`，將範圍設定為`resource`因此，記憶體會跨線程跟隨用戶，並透過在一個線程中啟動對話並在新線程中重新拾取它來在 Studio 中測試它。儘管線程是新鮮的，但早期的偏好仍然存在。

> **筆記：**&#x89C0;察記憶`scope: 'resource'`, used in this lesson, is now deprecated. For cross-thread continuity, keep the default thread scope and enable [retrieval mode](/docs/memory/observational-memory#retrieval-mode) or [resource-scoped working memory](/docs/memory/working-memory#resource-scoped-memory-default).

`lastMessages` tuning with automatic compression. The conversation stays coherent across long sessions and multiple threads without dragging all the raw history forward on every call.
