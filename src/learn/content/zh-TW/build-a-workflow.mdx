Agent 已能查詢樂園、取得即時排隊時間、擷取網頁上的樂園詳細資訊，也能納入天氣考量。但有些任務無法靠一次工具呼叫完成。這堂課會建立多步驟的購票 Workflow，安排在扣款前暫停，讓使用者核准。

模擬購票有三個明確的步驟：產生報價、暫停等使用者核准、處理扣款。每一步各自定義輸入與輸出的 schema，讓資料順利傳給下一步。把 Workflow 接到 Mastra 進入點後，在 Studio 執行，就能觀察步驟依序完成，以及何時暫停、如何繼續。

計算費用、驗證輸入、核對金額都有固定規則，不必經過語言模型。用 Workflow 可以掌握執行順序，在任何款項移轉之前暫停並等候核准。

> 「有固定規則可循的工作，直接寫進 Workflow 步驟就好，不用請模型推理。」
>
> — Guil Hernandez
