主題樂園 Agent 已能使用工具、保留對話脈絡，也能規劃一整天的遊園行程。開放給真實使用者後，安全性就成了實際問題。使用者不一定會照預期使用，有些人還會刻意操弄 Agent 或嘗試讓它越獄。

這堂課會為輸入階段加上兩道防護：`PromptInjectionDetector` 會在模型收到訊息之前，攔截提示注入、越獄及企圖覆寫系統指令的訊息；`ModerationProcessor` 則會檢查傳入訊息是否包含仇恨或騷擾內容。

這兩個處理器都只在輸入階段執行，並且會在呼叫大型語言模型（LLM）之前執行。你也可以把自訂處理器接到同一個處理流程。訊息如果在輸入階段遭到攔截，LLM 就不會被呼叫，該請求的內容也完全不會寫入記憶。

> 「這個請求過不了輸入處理器，所以模型不會被引導去做與任務無關的事。」
>
> — Guil Hernandez
