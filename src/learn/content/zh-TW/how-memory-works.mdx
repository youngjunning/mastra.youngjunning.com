主題樂園 Agent 已經啟用記憶。這堂課會看看背後的運作方式：為什麼模型在兩次呼叫之間仍不保留狀態，以及 Mastra 怎麼讓模型接續回答追問。

你會在 Studio 追蹤一次實際的追問，確認 Agent 收到哪些上下文，並看看 `lastMessages` 如何控制每次呼叫要帶入幾則近期的對話訊息。Mastra 會將訊息持久化儲存，再於後續輪次帶入，提供模型需要的資訊。

記憶的實作其實就是上下文工程：決定模型在每次呼叫時會看到什麼。了解這個機制，就更容易解釋 Agent 的行為，遇到異常時也比較容易除錯。

> 「模型仍然是無狀態的。Mastra 會儲存上下文，並在之後的呼叫中再次帶入。」
>
> — Guil Hernandez
