這堂課會在 Mastra 專案中新增主題樂園 Agent，並讓它出現在 Mastra Studio 裡。先不加工具或 Workflow，專心做出一個可以執行、調整和除錯的基本版本。

建立 Agent 檔案，寫一段精簡的指令來設定語氣和行為，再將 Agent 接進應用程式，就能在 Studio 裡使用。接著用一則測試提示確認回應是否符合預期。

指令會影響後續所有功能。先讓 Agent 的預設行為穩定下來，工具、Workflow 和外部資料才派得上用場。你也會從 Studio 的可觀測性畫面確認模型實際看見了什麼、輸出了什麼，並觀察啟用記憶後，原本無狀態的追問如何串成連貫的對話。

> 「一開始越簡單越好。先確定 Agent 的行為與輸出格式，基本版本能運作之後，再加上工具等功能。」
>
> — Guil Hernandez
