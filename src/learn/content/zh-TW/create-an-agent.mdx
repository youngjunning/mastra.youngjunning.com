在本課程中，您將向您的 Mastra 專案添加一個全新的主題樂園Agent，並使其顯示在 Mastra Studio 中。這是一個「保持簡單」的步驟——還沒有Tool或Workflow——因此您可以專注於獲得可以運行、調整和調試的乾淨基準。

您將建立Agent文件，編寫控制語氣和行為的嚴格指令區塊，然後將Agent連接到應用程序，以便它在 Studio 中可用。之後，您將執行快速測試提示以確認Agent程式按您預期的方式回應。

這很重要，因為說明是您稍後添加的所有內容的基礎 - Tool、Workflow和外部資料只有在Agent的預設行為已經可靠的情況下才有幫助。您還將使用 Studio 的可觀察性視圖來驗證模型實際看到和產生的內容，並且您將看到啟用記憶體如何將後續操作從「無狀態」變更為一致、持續的對話。

> “從簡單開始——首先鎖定Agent的行為和輸出格式。然後在知道基線正常工作後添加Tool等功能。”
>
> — 吉爾·埃爾南德斯
