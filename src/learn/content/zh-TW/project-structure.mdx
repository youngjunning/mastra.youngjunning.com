你剛在 Mastra Studio 執行過 Weather Agent。這堂課會帶你認識開發時最常編輯的核心檔案，先弄懂專案結構，再著手擴充。

先開啟 Agent 檔案，看看指令、所選的模型、可使用的工具和記憶如何決定它的行為。接著查看工具檔案，了解工具的輸入和輸出如何定義、如何在執行時驗證。最後看看 Workflow 檔案如何串起多個步驟，以及如何在 Studio 預覽。

Mastra 應用程式由少數可互相組合的基本元件構成，這些限制是刻意設計的：Agent 只能用你接上的工具，也只能根據那些工具傳回的資料結構推理。看懂這三種檔案之後，除錯會更快，你也能循著同樣的做法開發自己的主題樂園 Agent。

> 「Agent 只能呼叫你接上的工具，而且只能使用工具傳回的資料。這些界線和資料結構定義得好，後面的工作就容易得多。」
>
> — Guil Hernandez
