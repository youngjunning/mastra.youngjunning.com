您剛剛在 Mastra Studio 中運行了 Weather Agent，在本課程中，您將在指導下瀏覽在建置時不斷編輯的核心檔案。這是一個「您正在查看的內容」演練，可讓專案結構在開始擴展之前變得明顯。

您將開啟Agent檔案以查看如何透過指令、模型選擇、Tool存取和記憶體來定義行為。然後，您將檢查Tool文件，以了解如何使用清晰的輸入/輸出來塑造Tool並在運行時進行驗證。最後，您將瀏覽Workflow文件，以了解多步驟邏輯如何連接在一起並在 Studio 內預覽。

這很重要，因為 Mastra 應用程式是由一小組可組合基元構建的，並且限制是有意的：Agent只能使用您附加的Tool，並且它們只能對這些Tool返回的資料形狀進行推理。一旦您可以快速讀取這三種文件類型，您將能夠更快地調試並自信地開始在相同的模式之上建立自己的主題公園Agent。

> “您的Agent只能調用您附加的Tool，並且只能與您的Tool返回的內容配合使用。因此，正確設置這些邊界和數據形狀可以使下游的一切變得更容易。”
>
> — 吉爾·埃爾南德斯
