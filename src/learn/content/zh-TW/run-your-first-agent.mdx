課程剛起步，這堂課要先讓 Mastra 開發環境運作起來，之後開發主題樂園 Agent 時才能快速迭代。你會產生一個全新的獨立專案，設定模型供應商，並驗證從頭到尾都能正常運作。

啟動開發伺服器後，你會用 Mastra Studio 和預設 Agent 互動、單獨測試工具，再逐步跑完範例 Workflow。還不用做前端，就可以在 Studio 檢查輸出，看看系統實際做了什麼。

接下來幾堂課的 Agent、工具、Workflow 和設定都會放進 CLI 產生的專案架構。現在先熟悉 Studio 和可觀測性功能，等 Agent 變得複雜時，就有一套可靠的方法可查出非預期的輸出並追蹤品質。

> 「你可以在 Studio 開發和測試 Mastra 應用程式。還沒寫前端，就能執行各項功能、檢查執行結果並快速迭代。」
>
> — Guil Hernandez
