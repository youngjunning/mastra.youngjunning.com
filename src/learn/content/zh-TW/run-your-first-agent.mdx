您處於課程的早期階段，本課程主要是關於如何啟動並運行您的 Mastra 環境，以便您可以在我們建立主題樂園Agent時快速迭代。您將建立一個新的獨立項目，配置模型提供程序，並驗證一切都可以端到端運行。

您將運行開發伺服器並使用 Mastra Studio 與預設Agent程式互動、單獨測試Tool並逐步執行範例Workflow。在此過程中，您將看到 Studio 如何幫助您檢查輸出並了解系統在做什麼，而無需建立任何前端。

這很重要，因為隨著課程的進展，CLI 產生的專案結構將成為所有Agent商、Tool、Workflow和配置的所在地。現在透過熟悉 Studio 和可觀察性，您將擁有一種可靠的方法來調試令人驚訝的輸出並隨著Agent變得更加複雜而追蹤品質。

> “Studio 是您開發和測試 Mastra 應用程式的地方 - 您可以運行所有內容，檢查發生的情況，並在接觸前端之前快速迭代。”
>
> — 吉爾·埃爾南德斯
