隨著課程進展，主題樂園 Agent 會從依指令聊天，逐步學會可靠地處理真實資料。這堂課先做第一件事：提供一個工具，讓 Agent 能根據使用者說的樂園名稱，找出對應的正式樂園 ID。

你會建立專用的樂園查詢工具，向遠端端點查詢，用 schema 驗證輸入和輸出，並在名稱有歧義時，傳回少數符合的結果。先在 Mastra Studio 單獨測試，再接到主題樂園 Agent，讓它能在對話中自動呼叫。

後續每個 Q Times 請求都需要正確的樂園 ID，光猜名稱並不可靠。確認工具傳回的資料結構，並在可觀測性介面檢查工具呼叫，接下來才有可靠的基礎可查詢即時排隊時間。

> 「Agent 需要真實資訊時，就用工具。比方說，用樂園名稱查出其他 API 呼叫都要用到的 ID。」
>
> — Guil Hernandez
