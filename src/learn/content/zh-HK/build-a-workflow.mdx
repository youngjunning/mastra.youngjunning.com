Agent 已懂得查詢樂園、取得即時輪候時間、從網頁擷取更多樂園資料，並考慮天氣。不過，有些工作調用一次工具仍做不完。今課會建立包含多個步驟的購票流程，在扣款之前停下來等用戶批核。

模擬購票分三步：提供報價、暫停等候用戶批准、處理扣款。每步均有自己的輸入和輸出 schema，資料可以按指定格式交給下一步。將流程接駁至 Mastra 的入口，在 Studio 執行，便可看到每個步驟按次序運行，包括何時暫停及恢復。

計算費用、驗證輸入、確認金額，都有明確規則可循，毋須交由語言模型處理。用工作流程可以控制執行次序，在款項轉移之前暫停等候批准。

> 「只要有固定規則，就寫成流程中的一步，毋須模型推理。」
>
> — Guil Hernandez
