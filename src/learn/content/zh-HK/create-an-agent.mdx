今課會在 Mastra 項目新增主題樂園 Agent，讓它在 Mastra Studio 顯示。這一步先不接工具或工作流程，集中做好一個可執行、可調整、也方便除錯的基本版本。

先建立 Agent 檔案，用簡短指令設定它的語氣和行為，再把它連接到應用程式，就可以在 Studio 使用。然後用一則測試提示，看看回覆是否符合預期。

指令是後續功能的基礎。Agent 的預設行為穩定，工具、工作流程和外部資料才有用。你還會在 Studio 的可觀測性畫面核對模型實際收到甚麼、輸出甚麼，並看看啟用記憶後，原本無狀態的追問怎樣接成連貫對話。

> 「先做簡單的版本，定好 Agent 的行為和輸出格式。確定基本版本可以運作，再加入工具等功能。」
>
> — Guil Hernandez
