開發到這個階段，編輯器內的編程 Agent 已開始協助你寫程式。今課 Guil 會示範如何設定，讓 Agent 有資料可查，避免胡亂猜測或沿用過時的 Mastra 寫法。

你會看看 Mastra Skills 在項目內怎樣存放、Agent 實際會讀取哪些檔案，以及這些資料怎樣指引它產生和修改程式碼。你亦會了解何時應該以 MCP 文件伺服器補充 Skills，直接查詢現行文件及遷移指引。

AI 輔助編程很容易因沿用過時或虛構的 Mastra 用法而出錯。有可靠的本機資料可參照，需要時又能查閱網上文件，繼續為主題樂園 Agent 開發工具時，就能減少返工，並沿用 Mastra 實際提供的 API 和慣用寫法。

> 「最怕編程 Agent 煞有介事地捏造 Mastra 的用法，所以我們將 Skills 放在程式碼倉庫內，讓它做事時可以查到真正的用法。」
>
> — Guil Hernandez
