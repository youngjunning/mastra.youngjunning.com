課程剛開始，今課會先把 Mastra 開發環境設定好，方便之後快速改進主題樂園 Agent。你會用工具建立一個獨立項目的骨架，設定模型供應商，並確認整個項目從頭到尾都可以運作。

啟動開發伺服器後，在 Mastra Studio 與預設 Agent 互動、獨立測試工具，再逐步執行一個工作流程示例。暫時未有前端，也可在 Studio 檢查輸出，了解系統實際做了甚麼。

隨課程推進，所有 Agent、工具、工作流程和設定都會放在 CLI 產生的項目結構內。趁現在熟習 Studio 和可觀測性功能，日後 Agent 愈來愈複雜時，就有可靠的方法排查異常輸出及追蹤質素。

> 「你可以在 Studio 開發和測試 Mastra 應用程式。在開始做前端之前，就能執行各部分、查看實際情況，然後快速改進。」
>
> — Guil Hernandez
