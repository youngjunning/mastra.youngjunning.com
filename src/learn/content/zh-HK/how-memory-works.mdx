主題樂園 Agent 已啟用記憶。今課會拆解背後的做法：為甚麼模型在每次調用之間仍然不保留狀態，以及 Mastra 如何讓它接着回答追問。

你會在 Studio 追蹤一次實際的追問，查看 Agent 收到哪些語境資料，再了解 `lastMessages` 如何設定每次調用應帶入多少則近期對話訊息。Mastra 會把訊息持久保存，之後再在對話中帶回這些訊息，讓模型有足夠資料回應。

記憶背後是語境工程：由你決定每次調用時，模型可以看到哪些資料。掌握這一點，分析 Agent 的行為會容易得多，發現異常時也較容易除錯。

> 「模型依然是無狀態的。Mastra 將語境資料儲存起來，在之後的調用中再次傳入。」
>
> — Guil Hernandez
