此前你一直在 Studio 開發主題樂園 Agent。要讓其他人使用，就需要將它放到可公開存取的環境。今課會部署到 Mastra Server，即 Mastra 為 Agent 提供的雲端部署服務。一條指令便可將本機項目部署成可用的端點，路由、伸縮調整及基礎設施均由平台管理。

部署之前，先到 `http://localhost:4111/swagger-ui` 查看 Swagger UI。主題樂園 Agent 和課程內其餘 Agent 都已提供 HTTP 端點，有路由可用來產生回覆、串流輸出和執行工作流程。然後執行 `mastra server deploy`，它會驗證身分、建置和部署 Docker 映像，並輸出一個穩定的 URL。

Mastra 本身已是 HTTP 伺服器，Studio 是在本機與它互動的其中一種方式。Mastra Server 為同一個伺服器提供公開網址，讓任何服務都可調用主題樂園 Agent 的端點。

> 「Mastra 本身就是 HTTP 伺服器。Studio 只是在本機連接它的一種方式；Mastra Server 則將同一個伺服器放到可公開存取的環境。」
>
> — Guil Hernandez
