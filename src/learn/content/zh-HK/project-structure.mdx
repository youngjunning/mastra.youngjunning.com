你剛在 Mastra Studio 執行了 Weather Agent。今課會帶你認識開發期間經常要修改的核心檔案，先看清楚項目結構，再開始擴充。

先打開 Agent 檔案，看看指令、模型選擇、可用工具和記憶如何設定 Agent 的行為。再看工具檔案，了解怎樣明確定義輸入和輸出，以及如何在執行時驗證。最後從工作流程檔案看看多個步驟如何串起來，並在 Studio 預覽。

Mastra 應用程式由幾種可組合的基本元件構成，限制是刻意設下的：Agent 只可使用你接入的工具，也只能按工具傳回的資料結構推理。熟悉這三類檔案之後，你就能更快除錯，也有把握按同一做法開發自己的主題樂園 Agent。

> 「Agent 只可調用你接入的工具，也只能使用工具傳回的資料。劃清這些界線、定好資料結構，之後的工作就會順利得多。」
>
> — Guil Hernandez
