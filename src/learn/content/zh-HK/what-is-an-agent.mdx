在課程開首，Guil 會為後續內容打好基礎，示範 Agent 實際怎樣運作。今課會帶你認識 Agent、了解單靠提示有甚麼局限，以及 Mastra 如何組織各種基本元件。

你會看到 Agent 由頭到尾執行一次任務，包括怎樣調用工具、參考上文回答追問，以及如何透過更換模型和修改指令來調整行為。你亦會預覽今次課程的項目：一個主題樂園助理，可以擷取即時資料、提供建議，並帶用戶逐步完成任務。

往後的課程會用到這個區別：單輪聊天可以給出回覆，但能可靠採取行動的系統有不同的能力。掌握工具、工作流程、記憶和可觀測性怎樣配合，就能建立在開發時可測試、在生產環境可推出的功能，也毋須猜測模型實際做了甚麼。

>
> — Guil Hernandez
