樂園查詢已可使用，下一步是讓主題樂園 Agent 提供更實用的建議。今課會加入擷取樂園即時狀況快照的功能。

你會建立一個接受樂園 ID 的工具，傳回經篩選的遊樂設施清單，列出所在位置或園區、開放狀態，以及當前公布的輪候時間。清單由輪候時間最短的設施排起，可以直接用來作推薦。

園內情況變化很快，要排出可行的一日遊路線，Agent 需要最新的結構化資料。你亦會將工具接入 Agent，在 Mastra Studio 測試由查詢樂園到取得即時快照的整個流程，確保它每次都能在適當時候調用正確的工具。

> 「輪候時間變得很快，記得一併傳回擷取資料的時間。有了時間戳，就能判斷快照是否可靠。」
>
> — Guil Hernandez
