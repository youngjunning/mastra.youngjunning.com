經過一堂課，您的主題樂園Agent正在從「根據指示聊天」轉變為可靠地處理現實世界的資料。在本課程中，您將添加第一個缺少的構建塊：Agent可用於將人類公園名稱轉換為規範公園 ID 的Tool。

您將建立一個專用的公園查找Tool，用於查詢遠端端點、使用架構驗證輸入/輸出，並在名稱不明確時傳回一組符合項目。然後，您將直接在 Mastra Studio 中測試該Tool，最後將其連接到您的主題公園Agent，以便它可以在對話期間自動呼叫該Tool。

這很重要，因為每個下游 Q Times 請求都取決於正確的公園 ID，而不僅僅是猜測的公園名稱。透過驗證Tool的返回形狀並檢查可觀察性中的Tool調用，您可以為接下來獲取實時等待時間奠定可靠的基礎。

> “Tool適用於您的Agent需要真實上下文的時刻，例如將公園名稱轉換為每個其他 API 呼叫所依賴的 ID。”
>
> — 吉爾·埃爾南德斯
