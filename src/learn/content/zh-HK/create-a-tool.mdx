隨着課程推進，主題樂園 Agent 會由按指令聊天，逐步學會可靠地使用真實資料。今課先補上第一件工具：把用戶說的樂園名稱，對應到該樂園的正式 ID。

你會建立專用的樂園查詢工具，向遠端端點查詢，按 schema 驗證輸入和輸出；如果名稱有歧義，就傳回幾個吻合的結果。先在 Mastra Studio 直接測試工具，再接到主題樂園 Agent，讓它在對話中自動調用。

之後每次向 Q Times 發出請求，都依賴正確的樂園 ID，單憑猜測名稱並不足夠。核對工具傳回的資料結構，再到可觀測性介面檢查工具的調用情況，就能為下一課查即時輪候時間做好準備。

> 「Agent 要用真實資料時，工具就能派上用場，例如由樂園名稱查出其餘 API 調用所需的 ID。」
>
> — Guil Hernandez
