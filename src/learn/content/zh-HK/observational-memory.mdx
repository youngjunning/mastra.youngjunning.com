基本訊息記錄有其限制。對話愈長，工具調用、輪候時間查詢、天氣查詢和從網頁擷取的樂園資料就愈容易堆積。今課會啟用 Observational Memory（觀察記憶），將不斷累積的原始記錄壓縮成更精簡、Agent 可用的語境資料。

你會改用 `observationalMemory`，將範圍設為 `resource`，讓同一用戶在不同對話串都可以沿用記憶。你會在 Studio 開始一段對話，再開一個新的對話串繼續，看看之前的偏好如何保留下來。

> **注意：** 今課用到的 Observational Memory 設定 `scope: 'resource'` 已棄用。如要在不同對話串之間延續語境，請保留預設的對話串範圍，並啟用[檢索模式](/docs/memory/observational-memory#retrieval-mode)或[資源範圍的工作記憶](/docs/memory/working-memory#resource-scoped-memory-default)。

Observational Memory 會自動壓縮記錄，毋須人手調校 `lastMessages`。即使對話持續很久，或分散在幾個對話串，也能前後連貫，毋須在每次調用時帶上所有原始記錄。

> 「你不會記得每次對話的每一個字。你會留意發生過甚麼事，久而久之，這些觀察會凝聚成更有用的資料。OM 就是以這個概念設計的。」
>
> — Guil Hernandez
