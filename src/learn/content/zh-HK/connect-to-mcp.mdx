現在，主題樂園Agent程式已經可以提取公園 ID 和即時等待時間，但缺少 QTimes JSON API 中不可用的關鍵規劃資訊。在本課程中，您將使用外部Tool來源擴展Agent，以便它可以回答公園開放時間和人群預測等問題。

您將Agent連接到 MCP 伺服器，引入 Web 提取Tool，並使這些Tool與現有的本機Tool一起可用。然後，您將更新Agent的指南，以便它知道何時首先查找公園 ID 以及何時從公園網頁獲取結構化詳細資訊。

這很重要，因為現實世界中的助手很少能從單一 API 中取得所有內容。透過將即時 API 資料與網頁中的結構化提取相結合，並在相關時添加天氣輸入，您可以將Agent轉變為可靠地填補資訊空白的Tool，而無需建立一次性抓取Tool。

> “僅使用Tool存取並不能保證正確的行為 - 您必須教導Agent何時使用該Tool以及為什麼。”
>
> — 吉爾·埃爾南德斯
