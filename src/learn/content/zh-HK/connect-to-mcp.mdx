主題樂園 Agent 已懂得查樂園 ID 和即時輪候時間，不過 QTimes JSON API 沒有提供部分行程規劃所需的資料。今課會加入外部工具，讓 Agent 可以解答開放時間、預計人流等問題。

將 Agent 接駁到 MCP 伺服器，引入網頁資料擷取工具，與現有的本機工具並用。之後修改 Agent 的指令，說明何時要先查樂園 ID，以及何時應從樂園網頁擷取結構化資料。

實際使用時，助理很少能從同一個 API 取得所有資料。將 API 的即時資料與網頁的結構化資料合用，有需要時再參考天氣，Agent 就能可靠地補足資料，毋須每次另寫專用的網頁爬蟲。

> 「有工具不代表用得對。你要讓 Agent 知道甚麼時候該用，以及為甚麼。」
>
> — Guil Hernandez
