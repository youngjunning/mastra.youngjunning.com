完成購票流程後，就可以看看 Agent 和工作流程有何分工。兩個詞的用法有時比較寬泛，這裏重點是它們實際怎樣運作，以及在這個項目中如何配合。

Agent 是系統中「懂得說話的腦袋」：一個有工具和記憶的語言模型。沒有預設路徑，模型自行決定做甚麼、調用哪些工具，以及何時完成。工作流程的步驟、次序和完成條件則由你訂明。購票就是好例子：付款結算的步驟由你定義，毋須模型自行摸索。在 Mastra，你可以在工作流程中使用 Agent，也可以將工作流程當作工具交給 Agent 使用。

選得合適，就不會為簡單的工作設計過於複雜的流程，也不會將本應按固定規則執行、需要受控的工作交給模型。

> 「我們會訂明結帳流程，毋須模型自行想辦法。」
>
> — Guil Hernandez
