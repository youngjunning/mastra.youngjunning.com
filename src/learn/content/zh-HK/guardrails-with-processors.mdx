主題樂園 Agent 已可使用工具、保留語境，並規劃一整天的遊園行程。交給真實用戶使用後，就要正視安全問題。用戶未必會按預期操作，有些更會刻意操控 Agent 或嘗試令它越獄。

今課會用兩個處理器在輸入階段加設防護：`PromptInjectionDetector` 在模型收到訊息前，攔截提示注入、越獄及嘗試覆寫系統指令的訊息；`ModerationProcessor` 則檢查輸入訊息有沒有仇恨或騷擾內容。

兩個處理器都只在輸入階段運行，並在調用大型語言模型（LLM）之前執行。你也可以將自訂處理器加到同一套處理流程。若訊息在輸入階段被攔截，就不會調用 LLM，請求的任何內容也不會寫入記憶。

> 「請求無法通過輸入處理器，模型也就不會因此偏離原本的任務。」
>
> — Guil Hernandez
