主題樂園Agent程式已部署並可透過 HTTP 存取。在本課程中，您將使用 Mastra 的通道功能將其連接到 Slack，以便您可以從 Slack 運行的任何地方向其發送訊息。

您將安裝`@chat-adapter/slack`包，添加一個`channels`配置到主題樂園Agent，並建立具有正確範圍的 Slack 應用程式。 Mastra 自動公開 webhook 路由。將 Slack 的事件訂閱指向它，訊息就會直接傳送給Agent。

相同的Tool、記憶體和購票Workflow及其審批門從 DM 運行。 Channels 還透過相同的模式支援 Discord 和 Telegram：安裝適配器，將其添加到`channels.adapters`, set the env vars, deploy, and point the platform webhook at Mastra's generated route.

> “您不需要自己建立 webhook 處理程序。您不需要自行驗證 Slack 簽名。適配器會處理所有這些。”
>
> — 吉爾·埃爾南德斯
