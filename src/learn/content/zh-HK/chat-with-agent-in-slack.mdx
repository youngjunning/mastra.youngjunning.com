主題樂園 Agent 已經部署，可以經 HTTP 存取。今課會用 Mastra 的 Channels 功能接駁 Slack；只要用到 Slack，就可以向 Agent 發送訊息。

安裝 `@chat-adapter/slack` 套件，替主題樂園 Agent 加上 `channels` 設定，然後建立 Slack 應用程式並授予所需權限範圍。Mastra 會自動開放 webhook 路由。在 Slack 的 Event Subscriptions 指定該路由，訊息就會直接傳到 Agent。

透過私人訊息，仍可使用原有的工具、記憶和設有批核步驟的購票流程。Channels 亦以同一做法支援 Discord 和 Telegram：安裝適配器，加到 `channels.adapters`，設定環境變數並部署，最後把平台的 webhook 指向 Mastra 產生的路由。

> 「毋須自行編寫 webhook 處理程式，也毋須驗證 Slack 簽署；適配器會代為處理。」
>
> — Guil Hernandez
