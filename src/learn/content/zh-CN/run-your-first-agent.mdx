课程刚开始，本课会先把 Mastra 开发环境跑起来，方便之后快速迭代主题乐园 Agent。你会用脚手架创建一个新的独立项目，配置模型提供商，并验证整个项目能端到端运行。

启动开发服务器后，你会用 Mastra Studio 与默认 Agent 交互、单独测试工具，并逐步执行一个示例工作流。即使还没写前端，也可以在 Studio 中查看输出，了解系统正在做什么。

随着课程推进，你会把 Agent、工具、工作流和配置都放进 CLI 生成的项目结构里。现在熟悉 Studio 和可观测性功能，等 Agent 变得更复杂时，就能可靠地调试意外输出、跟踪质量。

> “Studio 是开发和测试 Mastra 应用的地方。还没开始写前端，你就可以把各部分跑起来，检查执行情况并快速迭代。”
>
> — Guil Hernandez
