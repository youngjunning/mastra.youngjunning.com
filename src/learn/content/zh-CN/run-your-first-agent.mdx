您处于课程的早期阶段，本课程主要是关于如何启动并运行您的 Mastra 环境，以便您可以在我们构建主题公园Agent时快速迭代。您将构建一个新的独立项目，配置模型提供程序，并验证一切都可以端到端运行。

您将运行开发服务器并使用 Mastra Studio 与默认Agent交互、单独测试Tool并逐步执行示例Workflow程。在此过程中，您将看到 Studio 如何帮助您检查输出并了解系统在做什么，而无需构建任何前端。

这很重要，因为随着课程的进展，CLI 生成的项目结构将成为所有Agent、Tool、Workflow程和配置的所在地。现在通过熟悉 Studio 和可观察性，您将拥有一种可靠的方法来调试令人惊讶的输出并随着Agent变得更加复杂而跟踪质量。

> “Studio 是您开发和测试 Mastra 应用程序的地方 - 您可以运行所有内容，检查发生的情况，并在接触前端之前快速迭代。”
>
> — 吉尔·埃尔南德斯
