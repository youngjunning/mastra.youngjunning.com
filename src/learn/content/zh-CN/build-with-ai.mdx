您正处于构建阶段，编辑器的编码Agent开始与您一起进行实际工作，本课程的重点是保持帮助的准确性。 Guil 介绍了防止Agent猜测或使用过时的 Mastra 模式的实用设置。

您将检查 Mastra Skills 如何在项目中运行、Agent实际读取哪些文件，以及这些引用如何指导代码生成和编辑。然后，您将了解何时使用 MCP 样式的文档服务器来补充技能，以便直接、可查询地访问当前文档和迁移帮助。

这很重要，因为“陈旧或虚构的 Mastra 细节”是人工智能辅助编码脱轨的最常见原因之一。通过为Agent提供可靠的本地知识源（以及需要时的实时文档回退），您可以在继续为主题公园Agent项目构建Tool时减少返工并使实施与 Mastra 的真实 API 和模式保持一致。

> “最大的失败模式是当您的编码Agent自信地发明 Mastra 细节时，因此我们在存储库中为它提供了技能，让它可以在工作时读取真实的模式。”
>
> — 吉尔·埃尔南德斯
