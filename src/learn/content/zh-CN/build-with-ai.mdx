开发到了这一步，编辑器里的编程 Agent 已经开始帮你写代码。本课中，Guil 会演示怎样配置项目，让 Agent 有据可查，少靠猜测，也不照搬过时的 Mastra 用法。

你会看到 Mastra Skills 如何放在项目里、Agent 实际读取哪些文件，以及这些资料怎样指导它生成和修改代码。接着，你会了解何时该用基于 MCP 的文档服务器补充 Skills，直接查询最新文档和迁移指引。

过时或凭空编造的 Mastra 用法，是 AI 辅助编程出错的常见原因。让 Agent 优先参考可靠的本地资料，必要时再查在线文档，就能在继续为主题乐园 Agent 开发工具时减少返工，让实现符合 Mastra 的实际 API 和惯用写法。

> “最容易出问题的是编程 Agent 一本正经地编造 Mastra 的用法。所以我们把 Skills 放进仓库里，让它边写代码边参考真实的用法。”
>
> — Guil Hernandez
