本课将为 Mastra 项目新建一个主题乐园 Agent，并让它出现在 Mastra Studio 中。先不加工具和工作流，这样你可以专注于搭好一个能运行、调整和调试的基础版本。

创建 Agent 文件，写一段简明的指令来规定语气和行为，再将 Agent 注册到应用，让它能在 Studio 中使用。接着用一条测试提示词，快速确认它的回复符合预期。

指令是后续开发的基础。只有默认行为可靠，工具、工作流和外部数据才能发挥作用。你还会用 Studio 的可观测性视图核对模型实际收到和生成的内容，并看到启用记忆后，原本无状态的追问如何变成连贯的对话。

> “先从简单的做起，确定 Agent 的行为和输出格式。基础版本跑通了，再加工具之类的能力。”
>
> — Guil Hernandez
