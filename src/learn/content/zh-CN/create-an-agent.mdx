在本课程中，您将向您的 Mastra 项目添加一个全新的主题公园Agent，并使其显示在 Mastra Studio 中。这是一个“保持简单”的步骤——还没有Tool或Workflow程——因此您可以专注于获得可以运行、调整和调试的干净基线。

您将创建Agent文件，编写控制语气和行为的严格指令块，然后将Agent连接到应用程序，以便它在 Studio 中可用。之后，您将运行快速测试提示以确认Agent按您预期的方式响应。

这很重要，因为说明是您稍后添加的所有内容的基础 - Tool、Workflow程和外部数据只有在Agent的默认行为已经可靠的情况下才有帮助。您还将使用 Studio 的可观察性视图来验证模型实际看到和生成的内容，并且您将看到启用内存如何将后续操作从“无状态”更改为一致、持续的对话。

> “从简单开始——首先锁定Agent的行为和输出格式。然后在知道基线正常工作后添加Tool等功能。”
>
> — 吉尔·埃尔南德斯
