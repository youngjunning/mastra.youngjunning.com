Agent 已经能查询乐园、获取实时排队时间、从网页抓取更多乐园详情，并把天气考虑进去。但有些任务靠一次工具调用做不完。本课会构建一个多步骤购票工作流，在扣款前暂停，由用户确认。

模拟购票分为三个明确步骤：生成报价、暂停等待用户批准、处理扣款。每一步都有独立的输入和输出 schema，明确交给下一步的数据格式。将工作流接入 Mastra 的入口后，在 Studio 中运行，就能看到各步骤依次执行，包括暂停和恢复。

计算费用、校验输入、核对金额等逻辑都有确定的规则，无须经由语言模型。借助工作流，你可以控制执行顺序，并在动用资金前暂停等待批准。

> “有明确规则的逻辑，直接写成工作流步骤就好，不需要模型来推理。”
>
> — Guil Hernandez
