您一直在 Studio 中构建主题公园Agent。要与其他人共享它，它需要在公共地方运行。在本课程中，您将把它部署到Mastra Server，Mastra 的Agent云部署产品。一个命令可将您的本地项目带到实时端点，并为您管理路由、扩展和基础设施。

在部署之前，您将在以下位置探索 Swagger UI：`http://localhost:4111/swagger-ui`。主题公园Agent和本课程中的所有其他Agent都已作为 HTTP 端点公开：用于生成响应、流式传输和运行Workflow的路由。然后`mastra server deploy`进行身份验证、构建 Docker 映像、部署它并打印稳定的 URL。

Mastra 已经是一个 HTTP 服务器。 Studio 只是在本地与其对话的一种方式。 Mastra 服务器将同一服务器放在公共 URL 上，主题公园Agent成为任何服务都可以调用的端点。

> “Mastra 已经是一个 HTTP 服务器。Studio 只是在本地与其通信的一种方式。Mastra Server 将同一服务器放在公共的地方。”
>
> — 吉尔·埃尔南德斯
