到目前为止，你一直在 Studio 中开发主题乐园 Agent。要与他人分享，需要让它运行在可以公开访问的环境里。本课会把它部署到 Mastra 的 Agent 云部署产品 Mastra Server。只需一条命令，本地项目就能变成可访问的端点，路由、扩缩容和基础设施都由平台管理。

部署前，先访问 `http://localhost:4111/swagger-ui` 查看 Swagger UI。主题乐园 Agent 和本课程中的其他 Agent 已经通过 HTTP 端点对外提供服务，包括生成回复、流式输出和运行工作流的路由。随后，`mastra server deploy` 会完成身份验证、构建并部署 Docker 镜像，最后输出一个稳定的 URL。

Mastra 本身就是 HTTP 服务器，Studio 只是本地访问它的一种方式。Mastra Server 让同一个服务器可以通过公开 URL 访问，这样任何服务都能调用主题乐园 Agent 的端点。

> “Mastra 本身就是 HTTP 服务器，Studio 只是本地访问它的一种方式。Mastra Server 把同一个服务器部署到可以公开访问的地方。”
>
> — Guil Hernandez
