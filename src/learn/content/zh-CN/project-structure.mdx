刚才你在 Mastra Studio 中运行了 Weather Agent。本课将带你逐个查看开发过程中会反复编辑的核心文件，在着手扩展前先弄清项目结构。

先打开 Agent 文件，看看指令、模型选择、可用工具和记忆如何定义它的行为。然后查看工具文件，了解如何定义清晰的输入和输出，以及如何在运行时校验。最后浏览工作流文件，看看如何串联多个步骤并在 Studio 中预览。

Mastra 应用由少数几种可组合的基础模块构成，其中的限制是有意设计的：Agent 只能用你接入的工具，也只能基于这些工具返回的数据结构进行推理。熟悉这三类文件后，就能更快调试，也能用同样的方式着手开发自己的主题乐园 Agent。

> “Agent 只能调用你接入的工具，也只能使用工具返回的数据。把这些边界和数据结构定义清楚，后面的工作就容易多了。”
>
> — Guil Hernandez
