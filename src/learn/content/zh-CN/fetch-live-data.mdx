乐园查询已经跑通，下一步是让主题乐园 Agent 能提供实用的游园建议。本课会添加一项能力：获取乐园的实时状况快照。

你会创建一个接收乐园 ID 的工具，返回筛选后的游乐项目列表，其中包括所在位置或园区、开放状态和当前公布的排队时间。结果按排队时间从短到长排列，可直接用于推荐。

园内情况变化很快。要规划一条可行的一日游路线，Agent 需要最新的结构化数据。你还会把工具接入 Agent，在 Mastra Studio 里测试从查询乐园到获取实时快照的完整链路，确保 Agent 在合适的时机调用正确的工具。

> “排队时间变得很快，所以一定要返回数据的获取时间。有了时间戳，才能判断这份快照是否可信。”
>
> — Guil Hernandez
