您已经开始进行公园查找，现在您将采取下一步，让主题公园Agent真正为您提供帮助。在本课程中，您将添加一项新功能，用于获取公园当前发生情况的实时快照。

您将创建一个接受公园 ID 并返回精选景点列表的Tool，其中包含位置/土地、开放状态和当前发布的等待时间等关键字段。您还将确保结果经过排序，以便最短的等待时间上升到顶部，从而使输出立即可用于推荐。

这很重要，因为公园的实际情况变化很快，Agent商需要新鲜的结构化数据来规划一天中的实际路线。您还将将该Tool连接到Agent中，并在 Mastra Studio 内测试完整的“查找 → 实时快照”链，以便Agent始终在正确的时间调用正确的Tool。

> “等待时间变化很快，因此在获取数据时始终返回。该时间戳使快照值得信赖。”
>
> — 吉尔·埃尔南德斯
