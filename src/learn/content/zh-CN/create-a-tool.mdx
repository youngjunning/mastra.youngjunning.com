随着课程推进，主题乐园 Agent 将从只能按指令聊天，逐步变成能可靠使用真实数据的助手。本课先补上第一块拼图：让 Agent 能把用户说的乐园名称查成对应的标准乐园 ID。

你会创建一个专用查询工具，调用远程端点，用 schema 校验输入和输出，并在名称有歧义时返回少量匹配项。先在 Mastra Studio 中单独测试，再接入主题乐园 Agent，让它能在对话中自动调用。

后续每次向 Q Times 发请求，都要用正确的乐园 ID，不能靠猜测名称。验证工具返回的数据结构，并在可观测性视图中检查工具调用，就能为下一课获取实时排队时间打好基础。

> “当 Agent 需要真实信息时，就该用工具。例如，通过乐园名称查到后续每次 API 调用都要用的那个 ID。”
>
> — Guil Hernandez
