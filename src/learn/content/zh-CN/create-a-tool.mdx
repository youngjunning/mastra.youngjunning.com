经过一堂课，您的主题公园Agent正在从“根据指令聊天”转变为可靠地处理现实世界的数据。在本课程中，您将添加第一个缺失的构建块：Agent可以使用该Tool将人类公园名称转换为规范公园 ID。

您将创建一个专用的公园查找Tool，用于查询远程端点、使用架构验证输入/输出，并在名称不明确时返回一小组匹配项。然后，您将直接在 Mastra Studio 中测试该Tool，最后将其连接到您的主题公园Agent，以便它可以在对话期间自动调用该Tool。

这很重要，因为每个下游 Q Times 请求都取决于正确的公园 ID，而不仅仅是猜测的公园名称。通过验证Tool的返回形状并检查可观察性中的Tool调用，您可以为接下来获取实时等待时间奠定可靠的基础。

> “Tool适用于您的Agent需要真实上下文的时刻，例如将公园名称转换为每个其他 API 调用所依赖的 ID。”
>
> — 吉尔·埃尔南德斯
