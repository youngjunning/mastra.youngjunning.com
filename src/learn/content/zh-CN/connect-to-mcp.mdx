主题乐园 Agent 已经能查询乐园 ID 和实时排队时间，但 QTimes JSON API 没有提供一些规划行程所需的关键信息。本课会为 Agent 接入外部工具，让它能回答营业时间和预计客流等问题。

将 Agent 连接到 MCP 服务器，引入网页数据提取工具，与原有的本地工具一起使用。然后更新 Agent 的指令，告诉它何时先查乐园 ID，何时从乐园网页提取结构化详情。

实际应用中的助手很少能从一个 API 拿到所有信息。把实时 API 数据与网页上提取的结构化信息结合起来，需要时再查天气，Agent 就能可靠地补齐信息，不必为每种需求单独编写爬虫。

> “有工具可用，不代表 Agent 就知道怎么做。你得告诉它什么时候该用这个工具，以及为什么。”
>
> — Guil Hernandez
