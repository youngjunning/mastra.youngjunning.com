现在，主题公园Agent已经可以提取公园 ID 和实时等待时间，但缺少 QTimes JSON API 中不可用的关键规划信息。在本课程中，您将使用外部Tool源扩展Agent，以便它可以回答公园开放时间和人群预测等问题。

您将Agent连接到 MCP 服务器，引入 Web 提取Tool，并使这些Tool与现有的本地Tool一起可用。然后，您将更新Agent的指南，以便它知道何时首先查找公园 ID 以及何时从公园网页获取结构化详细信息。

这很重要，因为现实世界中的助手很少能从单个 API 中获取所有内容。通过将实时 API 数据与网页中的结构化提取相结合，并在相关时添加天气输入，您可以将Agent转变为能够可靠地填补信息空白的Tool，而无需构建一次性抓取Tool。

> “仅使用Tool访问并不能保证正确的行为 - 您必须教Agent何时使用该Tool以及为什么。”
>
> — 吉尔·埃尔南德斯
