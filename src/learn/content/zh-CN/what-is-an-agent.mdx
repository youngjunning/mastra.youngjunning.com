这是课程的第一课。Guil 会为后面的内容打好基础，演示 Agent 在实际运行中是什么样的。你会了解什么是 Agent、只靠提示词有哪些局限，以及 Mastra 如何组织各个基础模块。

你会看到 Agent 从头到尾完成一次任务，包括如何调用工具、利用已有上下文回答追问，以及如何通过更换模型和调整指令来改变行为。你还会预览本课程要做的项目：一个能获取实时数据、给出建议，并引导用户完成多步骤任务的主题乐园助手。

后续课程建立在一个区别之上：单轮聊天可以给出回复，Agent 系统则能可靠地执行操作。掌握工具、工作流、记忆和可观测性如何配合后，就能构建可在开发时测试、可部署到生产环境的功能，也不用猜测模型到底做了什么。
