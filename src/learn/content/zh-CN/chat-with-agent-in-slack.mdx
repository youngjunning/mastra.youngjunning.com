主题公园Agent已部署并可通过 HTTP 访问。在本课程中，您将使用 Mastra 的通道功能将其连接到 Slack，以便您可以从 Slack 运行的任何地方向其发送消息。

您将安装`@chat-adapter/slack`包，添加一个`channels`配置到主题公园Agent，并创建具有正确范围的 Slack 应用程序。 Mastra 自动公开 webhook 路由。将 Slack 的事件订阅指向它，消息就会直接发送给Agent。

相同的Tool、内存和购票Workflow程及其审批门从 DM 运行。 Channels 还通过相同的模式支持 Discord 和 Telegram：安装适配器，将其添加到`channels.adapters`, set the env vars, deploy, and point the platform webhook at Mastra's generated route.

> “您不需要自己构建 webhook 处理程序。您不需要自己验证 Slack 签名。适配器会处理所有这些。”
>
> — 吉尔·埃尔南德斯
