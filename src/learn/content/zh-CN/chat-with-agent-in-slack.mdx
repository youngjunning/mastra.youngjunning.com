主题乐园 Agent 已部署，可以通过 HTTP 访问。本课将用 Mastra 的 Channels 功能把它接入 Slack，这样只要能用 Slack，就能给它发消息。

安装 `@chat-adapter/slack` 包，为主题乐园 Agent 添加 `channels` 配置，再创建一个拥有所需权限范围的 Slack 应用。Mastra 会自动开放 webhook 路由。把 Slack 的 Event Subscriptions 指向这条路由，消息就会直接送到 Agent。

在 Slack 私聊中，Agent 仍可使用原有的工具、记忆和带审批环节的购票工作流。Channels 也以相同方式支持 Discord 和 Telegram：安装适配器，将其加入 `channels.adapters`，设置环境变量并部署，再把平台的 webhook 指向 Mastra 生成的路由。

> “不用自己写 webhook 处理程序，也不用自行验证 Slack 签名。适配器会处理这些事。”
>
> — Guil Hernandez
