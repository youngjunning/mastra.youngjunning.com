主题公园Agent上已启用内存。在本课程中，您将深入了解这实际上意味着什么：为什么模型在调用之间仍然是无状态的，以及 Mastra 正在做什么来使后续工作正常进行。

您将在 Studio 中跟踪真实的后续提示，以准确查看Agent收到的上下文，并查看`lastMessages`：控制每次通话包含多少最近对话历史记录的设置。 Mastra 将消息保存到存储中，然后在以后的回合中重新包含它们，以便模型拥有所需的内容。

这很重要，因为记忆不是魔法。您真正要做的是上下文工程：决定模型在每次调用时看到什么。了解这一点可以更轻松地推理Agent行为并在感觉不对劲时对其进行调试。

> “该模型仍然是无状态的。Mastra 存储上下文，然后在以后的调用中再次包含它。”
>
> — 吉尔·埃尔南德斯
