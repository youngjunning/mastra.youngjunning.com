主题乐园 Agent 已经启用了记忆。本课会解释记忆在底层是怎么实现的：为什么模型在两次调用之间仍然不保留状态，以及 Mastra 怎样让模型接得住追问。

你会在 Studio 中追踪一次实际的追问，查看 Agent 究竟收到了哪些上下文，并了解 `lastMessages` 如何控制每次调用带上多少条最近的对话消息。Mastra 会持久化保存消息，在后续轮次中重新带上这些消息，给模型提供所需信息。

记忆并不是凭空产生的。这实际上是上下文工程：你决定每次调用时模型能看到什么。弄清这一点，就更容易分析 Agent 为什么这么做，也更容易在行为异常时调试。

> “模型仍然是无状态的。Mastra 会保存上下文，并在后续调用中再次传入。”
>
> — Guil Hernandez
